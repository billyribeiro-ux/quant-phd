Spread Decomposition

When a transaction occurs, the observed price reflects both frictionless economic value and market frictions. A dealer quoting bids and asks incurs inventory carrying costs and order-processing expenses, while facing informed traders whose orders permanently move fundamental value. This project investigates the structural decomposition of the effective bid–ask spread into order-processing and adverse-selection components. You will prove the population covariance and regression identities under a repeated trade model, implement an autograded Python solver (decompose.py), evaluate the classical Roll serial covariance estimator against structural regression estimates across parameter grids, and author an analytical research memo (report.md) evaluated by rubric against annotated exemplars.

Lab 1 · Worked example: step-by-step trade decomposition

Under true parameters \(\theta = 0.10\), \(c = 0.15\), and \(\sigma = 0.03\) with \(n = 500\) trades, the theoretical population values are: effective half-spread \(H = \theta + c = 0.25\), order-processing component \(c = 0.15\), adverse-selection component \(\theta = 0.10\), and adverse share \(\theta / H = 0.40\). The lag-1 covariance is strictly negative, yielding a finite Roll spread estimate near \(2\sqrt{c(\theta+c)} = 2\sqrt{0.15 \times 0.25} = 2\sqrt{0.0375} \approx 0.3873\), which strictly exceeds the true spread \(2c = 0.30\).

"""Lab MS1-project-1: Rung 1 worked example of trade-level spread decomposition.

SIMULATED: generates one sample of trade prices and signs (n=500, theta=0.10, c=0.15, sigma=0.05).
Solves the decomposition step by step, annotating why each mathematical step is taken:
price changes, lag-1 autocovariance, Roll spread, normal equations, components, and adverse share.
"""

from __future__ import annotations

import math
import random


def main() -> None:
    # Step 1: Generate simulated instance
    # Why: Demonstrates the estimator on a controlled path with known true parameters.
    rng = random.Random(42)
    n = 500
    theta_true = 0.10
    c_true = 0.15
    sigma = 0.05
    m = 100.0

    prices: list[float] = []
    signs: list[int] = []
    for _ in range(n):
        q = rng.choice([-1, 1])
        eta = rng.gauss(0.0, sigma)
        m += theta_true * q + eta
        prices.append(m + c_true * q)
        signs.append(q)

    print(f"Step 1 | Generated {n} trades with true theta = {theta_true:.4f}, c = {c_true:.4f}")

    # Step 2: Calculate price changes d_t = p_t - p_{t-1}
    # Why: Stationarizes the price series; removes the random-walk level of fundamental value.
    d = [prices[i] - prices[i - 1] for i in range(1, n)]
    mean_d = sum(d) / len(d)
    print(f"Step 2 | Computed {len(d)} price changes. Mean price change: {mean_d:.6f}")

    # Step 3: Compute sample lag-1 autocovariance and Roll spread
    # Why: Negative autocovariance reflects bid-ask bounce; Roll's formula assumes theta = 0.
    cov1 = sum((d[i] - mean_d) * (d[i - 1] - mean_d) for i in range(1, len(d))) / (len(d) - 1)
    roll = 2.0 * math.sqrt(-cov1) if cov1 < 0.0 else float("nan")
    print(f"Step 3 | Lag-1 covariance: {cov1:.6f}, Roll spread estimate: {roll:.4f}")

    # Step 4: Assemble normal equations for regression without intercept
    # Why: In population, E[d_t | q_t, q_{t-1}] = (theta + c) q_t - c q_{t-1}.
    q_curr = [float(signs[i]) for i in range(1, n)]
    q_lag = [float(signs[i - 1]) for i in range(1, n)]

    s00 = sum(x * x for x in q_curr)
    s11 = sum(x * x for x in q_lag)
    s01 = sum(x * y for x, y in zip(q_curr, q_lag, strict=False))
    det = s00 * s11 - s01 * s01
    print(f"Step 4 | Design matrix determinant: {det:.1f} (non-singular)")

    y0 = sum(di * qi for di, qi in zip(d, q_curr, strict=False))
    y1 = sum(di * qi for di, qi in zip(d, q_lag, strict=False))

    b0 = (s11 * y0 - s01 * y1) / det
    b1 = (s00 * y1 - s01 * y0) / det
    print(f"Step 5 | OLS regression slopes: b_0 = {b0:.4f}, b_1 = {b1:.4f}")

    # Step 6: Recover structural spread components
    # Why: b_0 identifies total half-spread H; -b_1 identifies order processing c;
    # b_0 + b_1 identifies adverse selection theta.
    half_spread = b0
    order_processing = -b1
    adverse_selection = b0 + b1
    adverse_share = adverse_selection / half_spread if half_spread != 0.0 else float("nan")

    true_share = theta_true / (theta_true + c_true)
    print(f"Step 6 | Effective half-spread H:       {half_spread:.4f} (true: {theta_true + c_true:.4f})")
    print(f"       | Order-processing cost c:       {order_processing:.4f} (true: {c_true:.4f})")
    print(f"       | Adverse-selection cost theta:  {adverse_selection:.4f} (true: {theta_true:.4f})")
    print(f"       | Adverse selection share:       {adverse_share:.4f} (true: {true_share:.4f})")

The structural model and theoretical identities

The project investigates a discrete-time repeated trading economy with asymmetric information and order-handling costs, as established in Lesson 4. The economy evolves over trade ticks \(t = 1, \dots, n\).

Assumptions

  1. A1 · Trade signs. Trade signs \(q_t \in \{-1, +1\}\) are independently and identically distributed (i.i.d.) with \(P(q_t = +1) = P(q_t = -1) = 1/2\). Thus \(\E[q_t] = 0\), \(\Var(q_t) = 1\), and \(\Cov(q_t, q_s) = 0\) for \(t \ne s\).
  2. A2 · Efficient price and adverse selection. The unobserved fundamental efficient price \(m_t\) follows a random walk with trade impact: \[m_t = m_{t-1} + \theta q_t + \eta_t,\] where \(\theta \ge 0\) is the permanent price impact per trade (adverse-selection parameter), and \(\eta_t\) are i.i.d. innovations with mean zero and variance \(\sigma^2\), independent of current and past trade signs.
  3. A3 · Transaction price and order processing. Transaction prices \(p_t\) are executed at the efficient price plus a transitory half-spread: \[p_t = m_t + c q_t,\] where \(c > 0\) represents the constant order-processing and inventory-holding half-spread.
  4. A4 · Price changes. Differencing consecutive transaction prices yields the observable price change: \[d_t = p_t - p_{t-1} = (\theta + c) q_t - c q_{t-1} + \eta_t.\]

Theoretical propositions

Proposition 1 · Serial covariance and Roll estimator bias. Under Assumptions A1–A4, the price changes have zero mean, \(\E[d_t] = 0\), and autocovariance structure: \[\Var(d_t) = (\theta + c)^2 + c^2 + \sigma^2,\] \[\Cov(d_t, d_{t-1}) = -c(\theta + c), \qquad \Cov(d_t, d_{t-k}) = 0 \quad \text{for } k \ge 2.\] When adverse selection is absent (\(\theta = 0\)), \(\Cov(d_t, d_{t-1}) = -c^2\), so the Roll spread estimator \(2\sqrt{-\Cov(d_t, d_{t-1})} = 2c\) recovers the true bid–ask spread. When \(\theta > 0\), the population Roll estimator yields \(2\sqrt{c(\theta + c)} > 2c\), overestimating the spread due to information-driven price revision.

Proposition 2 · Regression identification of spread components. Under Assumptions A1–A4, consider the no-intercept linear projection of price change \(d_t\) onto current sign \(q_t\) and lagged sign \(q_{t-1}\): \[d_t = b_0 q_t + b_1 q_{t-1} + e_t.\] Because \(\Cov(q_t, q_{t-1}) = 0\) and \(\Var(q_t) = \Var(q_{t-1}) = 1\), the population regression coefficients satisfy: \[b_0 = \E[d_t q_t] = \theta + c = H,\] \[b_1 = \E[d_t q_{t-1}] = -c.\] The structural parameters are uniquely identified from the regression coefficients by: \[H = b_0, \qquad c = -b_1, \qquad \theta = b_0 + b_1, \qquad \text{Adverse Share} = \frac{\theta}{H} = \frac{b_0 + b_1}{b_0}.\]

"""Lab MS1-project-3: Rung 3 verification check on the report parameter grid.

SIMULATED: generates trade series on the parameter grid (theta in {0.0, 0.1, 0.2},
c = 0.10, sigma = 0.05, n = 2000, seed 1).
Produces the reference output table required for the student report.

from __future__ import annotations

import math
import random


def generate_trade_series(n: int, theta: float, c: float, sigma: float, seed: int) -> tuple[list[float], list[int]]:
    """Simulate trade-level data under repeated trade model."""
    rng = random.Random(seed)
    m = 100.0
    prices: list[float] = []
    signs: list[int] = []
    for _ in range(n):
        q = rng.choice([-1, 1])
        eta = rng.gauss(0.0, sigma)
        m += theta * q + eta
        prices.append(m + c * q)
        signs.append(q)
    return prices, signs


def run_decomposition(prices: list[float], signs: list[int]) -> tuple[float, float, float, float, float]:
    """Execute full decomposition and return roll spread, H, c, theta, and share."""
    n = len(prices)
    d = [prices[i] - prices[i - 1] for i in range(1, n)]
    mean_d = sum(d) / len(d)
    cov1 = sum((d[i] - mean_d) * (d[i - 1] - mean_d) for i in range(1, len(d))) / (len(d) - 1)
    roll = 2.0 * math.sqrt(-cov1) if cov1 < 0.0 else float("nan")

    q_curr = [float(signs[i]) for i in range(1, n)]
    q_lag = [float(signs[i - 1]) for i in range(1, n)]

    s00 = sum(x * x for x in q_curr)
    s11 = sum(x * x for x in q_lag)
    s01 = sum(x * y for x, y in zip(q_curr, q_lag, strict=False))
    det = s00 * s11 - s01 * s01

    y0 = sum(di * qi for di, qi in zip(d, q_curr, strict=False))
    y1 = sum(di * qi for di, qi in zip(d, q_lag, strict=False))

    b0 = (s11 * y0 - s01 * y1) / det
    b1 = (s00 * y1 - s01 * y0) / det

    half_spread = b0
    order_proc = -b1
    adv_sel = b0 + b1
    adv_share = adv_sel / half_spread if half_spread != 0.0 else float("nan")

    return roll, half_spread, order_proc, adv_sel, adv_share


def main() -> None:
    c_fixed = 0.10
    sigma_fixed = 0.05
    n_fixed = 2000
    seed_fixed = 1
    thetas = [0.0, 0.1, 0.2]

    print("Project Report Benchmark Grid (n=2000, c=0.10, sigma=0.05, seed=1):")
    print("theta |     c |     Roll |  Half-Sp | Order-Pr |  Adv-Sel | Adv-Share")
    for theta in thetas:
        prices, signs = generate_trade_series(n_fixed, theta, c_fixed, sigma_fixed, seed_fixed)
        roll, h, c_est, th_est, share = run_decomposition(prices, signs)
        print(f"{theta:5.2f} | {c_fixed:5.2f} | {roll:8.4f} | {h:8.4f} | {c_est:8.4f} | {th_est:8.4f} | {share:9.4f}")

Exemplar B

Official scoring: C1 4 · C2 4 · C3 4 · C4 4 · C5 4. Complete mathematical rigor: assumptions are numbered and mapped to propositions; estimators and exception conditions are derived; benchmark grid results are thoroughly analyzed; unrounded calculations are verified; and structural limitations are graded with literature citations.

Model specification

Under Assumption A1, trade signs \(q_t \in \{-1, +1\}\) are i.i.d. with mean zero and unit variance. Under A2, the unobserved efficient price evolves as \(m_t = m_{t-1} + \theta q_t + \eta_t\), where \(\theta \ge 0\) represents permanent adverse-selection impact and \(\eta_t \sim \Normal(0, \sigma^2)\) is independent public news. Under A3, transaction prices satisfy \(p_t = m_t + c q_t\), where \(c > 0\) is the transitory order-processing half-spread. Under A4, differencing yields observable price changes \(\Delta p_t = (\theta + c) q_t - c q_{t-1} + \eta_t\). Assumption A1 ensures orthogonality \(\Cov(q_t, q_{t-1}) = 0\), enabling identification of \(\theta\) and \(c\).

  • Meets C1 level 4: explicitly defines Assumptions A1–A4 and explains the theoretical mechanism of identification.
Estimators and identities

Proposition 1 proves that \(\Cov(d_t, d_{t-1}) = -c(\theta + c)\). When \(\theta = 0\), the Roll spread \(s = 2\sqrt{-\text{cov}_1} = 2c\) is exact. When \(\theta > 0\), the population Roll estimator converges to \(2\sqrt{c(\theta + c)} > 2c\). The sample covariance utilizes divisor \(n-2\) across the \(n-2\) adjacent pairs of changes. Proposition 2 establishes that no-intercept OLS estimates satisfy \(b_0 = \theta + c\) and \(b_1 = -c\), recovering \(c = -b_1\), \(\theta = b_0 + b_1\), and adverse share \(\theta / b_0\). Input validation strictly raises ValueError if \(n < 3\), if any sign \(q_t \notin \{-1, +1\}\), or if all signs are equal (singular normal equations).

  • Meets C2 level 4: proves autocovariance and regression identities, explains sample divisors, and documents all three exception triggers.

Numerical rigour and rounding

All calculations operate on 64-bit IEEE floating-point values without intermediate truncation. Reporting follows a strict four-decimal-place display policy. Manual verification of the \(\theta = 0.10\) regression: cross products \(s_{00} = 1999.0\), \(s_{11} = 1999.0\), \(s_{01} = 3.0\), \(\det = 1999.0^2 - 3.0^2 = 3995992.0\); inner products \(y_0 = 397.0987\), \(y_1 = -201.9987\); yielding \(b_0 = (1999.0 \times 397.0987 - 3.0 \times (-201.9987)) / 3995992.0 = 0.1987\) and \(b_1 = (1999.0 \times (-201.9987) - 3.0 \times 397.0987) / 3995992.0 = -0.1011\), confirming solver output.

  • Meets C4 level 4: specifies rounding policy, proves unrounded execution, and demonstrates exact manual normal equation solution.
Limits and evidence

The structural model embodies three major limitations: (1) constant spread components \(c\) and \(\theta\), abstracting from intraday volatility clustering; (2) i.i.d. order flow (Assumption A1), ignoring autocorrelation in trade signs caused by institutional order splitting; and (3) absence of dealer inventory control penalties (Ho & Stoll 1981). All mathematical derivations are Proposition Grade T; empirical grid properties on SIMULATED trades are Grade C. The finding that serial covariance estimators overestimate spreads under adverse selection is Grade B, substantiated by Roll (1984) and Glosten & Milgrom (1985).

  • Meets C5 level 4: evaluates three structural limits, assigns explicit evidence grades (T, B, C), and cites verified literature keys.
