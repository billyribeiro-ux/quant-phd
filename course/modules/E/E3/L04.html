Two lotteries can be compared without a utility function. If one finite lottery puts no more probability at or below every level of wealth than the other, then every nondecreasing utility on the support ranks it no lower. If the means are equal, the second test, second-order dominance, can rank a pair that the first test leaves unranked, and then every nondecreasing concave utility on the support agrees with that ranking (Theorem 2.3). This lesson defines both tests for finite lotteries, proves that each is equivalent to a family of expected-utility comparisons, and checks the verdicts in Lab 1 on seeded pairs against expected utilities.

1Distribution functions and the integrated test

Assumptions A1 and A2 (finite support and equal means)
  • A1 (finite support). The lotteries \(X\) and \(Y\) take values in one finite set \(S = \{s_{1} < s_{2} < \dots < s_{m}\}\) of wealth levels in cents. Each \(X\) and \(Y\) is a finite lottery in the sense of Lesson L01, Definition 1.1, with probabilities that sum to 1.
  • A2 (equal means). \(\E X = \E Y\). A2 is assumed from Definition 2.1 on, in Section 2, and not in Section 1.
Definition 1.1 (distribution function and integrated distribution function)

The distribution function of \(X\) is \(F_{X}(t) = \Prob(X \le t)\) for real \(t\). Its integrated distribution function is \(I_{X}(t) = \int_{-\infty}^{t} F_{X}(s)\, ds\). Both are defined for every real \(t\), and the second is a finite integral because \(F_{X}(s) = 0\) for \(s < s_{1}\).

Lemma 1.2 (the integrated distribution is a shortfall)

Under A1, for every real \(t\), \(I_{X}(t) = \E\big[(t - X)^{+}\big]\), where \(z^{+} = \max(z, 0)\).

Proof

For a real \(x\), \((t - x)^{+} = \int_{-\infty}^{t} \indic\{x \le s\}\, ds\), because the set of \(s \le t\) with \(x \le s\) is the interval \([x, t]\), which has length \((t - x)^{+}\), or is empty when \(x > t\). Taking expectations, \(\E(t - X)^{+} = \int_{-\infty}^{t} \Prob(X \le s)\, ds = I_{X}(t)\). The interchange of expectation and integral is elementary here, because \(X\) takes finitely many values, so the expectation is a finite sum of integrals of step functions. \(\blacksquare\)

Definition 1.3 (first-order dominance)

Under A1, the lottery \(X\) dominates \(Y\) in the first order when \(F_{X}(t) \le F_{Y}(t)\) for every real \(t\). \(X\) is then at least as likely as \(Y\) to exceed every level \(t\).

Definition 1.4 (the test utilities on S)

A function \(u : S \to \R\) is nondecreasing when \(u(s_{j}) \le u(s_{j+1})\) for every \(j\). It is concave on S when its chord slopes \(\sigma_{j} = \big(u(s_{j+1}) - u(s_{j})\big)/(s_{j+1} - s_{j})\), for \(j = 1, \dots, m-1\), never increase: \(\sigma_{1} \ge \sigma_{2} \ge \dots \ge \sigma_{m-1}\). Both notions use only the values of \(u\) on \(S\), and the expected utility of a lottery on \(S\) is \(\E u(X) = \sum_{j} \Prob(X = s_{j}) u(s_{j})\).

Theorem 1.5 (first-order dominance on a finite support)

Assume A1. Then \(F_{X}(t) \le F_{Y}(t)\) for every real \(t\) if and only if \(\E u(X) \ge \E u(Y)\) for every nondecreasing \(u : S \to \R\).

Proof

Only if. Let \(u\) be nondecreasing on \(S\). Put \(d_{j} = u(s_{j}) - u(s_{j-1}) \ge 0\) for \(j = 2, \dots, m\). For each \(s_{k}\) in \(S\), \(u(s_{k}) = u(s_{1}) + \sum_{j=2}^{k} d_{j}\), so \(u(x) = u(s_{1}) + \sum_{j=2}^{m} d_{j} \indic\{x \ge s_{j}\}\) for every \(x \in S\). Taking expectations, \(\E u(X) = u(s_{1}) + \sum_{j=2}^{m} d_{j} \Prob(X \ge s_{j})\). Because \(X\) takes values in \(S\) and no point of \(S\) lies strictly between \(s_{j-1}\) and \(s_{j}\), \(\{X \ge s_{j}\} = \{X > s_{j-1}\}\), so \(\Prob(X \ge s_{j}) = 1 - F_{X}(s_{j-1})\). The same holds for \(Y\). Subtracting,

\[ \E u(X) - \E u(Y) = \sum_{j=2}^{m} d_{j}\big(F_{Y}(s_{j-1}) - F_{X}(s_{j-1})\big). \]

Each \(d_{j} \ge 0\), and each \(F_{Y}(s_{j-1}) - F_{X}(s_{j-1}) \ge 0\) by hypothesis, so \(\E u(X) \ge \E u(Y)\).

If. Suppose \(F_{X}(t) > F_{Y}(t)\) for some real \(t\). Let \(u_{t}(s) = \indic\{s > t\}\), which is nondecreasing on \(S\); we call \(u_{t}\) the witness for \(t\). Then \(\E u_{t}(X) = 1 - F_{X}(t) < 1 - F_{Y}(t) = \E u_{t}(Y)\), which contradicts the hypothesis. So \(F_{X}(t) \le F_{Y}(t)\) for every real \(t\). \(\blacksquare\)

Lemma 1.6 (the test needs only the support points)

Under A1, \(F_{X}(t) \le F_{Y}(t)\) for every real \(t\) if and only if \(F_{X}(s) \le F_{Y}(s)\) for every \(s \in S\).

Proof

The "only if" direction is immediate. For the other, let \(t\) be real. If \(t < s_{1}\), both distribution functions are \(0\) at \(t\). Otherwise let \(s_{j}\) be the largest point of \(S\) with \(s_{j} \le t\). Then \(X\) takes no value in \((s_{j}, t]\), so \(F_{X}(t) = \Prob(X \le s_{j}) = F_{X}(s_{j})\), and likewise \(F_{Y}(t) = F_{Y}(s_{j})\). So the inequality at \(t\) is the inequality at \(s_{j} \in S\). \(\blacksquare\)

Example 1.7 (a shift of probability upward)

Let \(X\) put probability \(1/2\) on 2000 cents and \(1/2\) on 4000 cents, and let \(Y\) put probability \(1/2\) on 3000 cents and \(1/2\) on 4000 cents. On \(S = \{2000, 3000, 4000\}\), \(F_{X} = (1/2, 1/2, 1)\) and \(F_{Y} = (0, 1/2, 1)\). So \(F_{Y}(t) \le F_{X}(t)\) at every support point, and by Lemma 1.6, \(Y\) dominates \(X\) in the first order. The means are 3000 and 3500 cents. The example is an instance of Theorem 1.5, not a separate argument.

Proposition 1.8 (first-order dominance implies the integrated order)

Under A1, if \(F_{X}(t) \le F_{Y}(t)\) for every real \(t\), then \(I_{X}(t) \le I_{Y}(t)\) for every real \(t\). This holds without A2.

Proof

For each real \(s\), \(F_{X}(s) \le F_{Y}(s)\) by hypothesis. Both integrals \(\int_{-\infty}^{t} F_{X}(s)\, ds\) and \(\int_{-\infty}^{t} F_{Y}(s)\, ds\) are finite, because each integrand is \(0\) for \(s < s_{1}\) and lies in \([0, 1]\) elsewhere. Integrating the pointwise inequality over \((-\infty, t]\) gives \(I_{X}(t) \le I_{Y}(t)\). \(\blacksquare\)

2Second-order dominance

Definition 2.1 (second-order dominance)

Under A1 and A2, the lottery \(X\) dominates \(Y\) in the second order when \(I_{X}(t) \le I_{Y}(t)\) for every real \(t\). By Lemma 1.2 this says \(\E(t - X)^{+} \le \E(t - Y)^{+}\) for every \(t\), so \(X\) has the smaller expected shortfall below every level.

Lemma 2.2 (the integrated test needs only the support points)

Under A1 and A2, \(I_{X}(t) \le I_{Y}(t)\) for every real \(t\) if and only if it holds for every \(s \in S\).

Proof

Let \(D(t) = I_{Y}(t) - I_{X}(t)\). By Lemma 1.2, \(D(t) = \E(t - Y)^{+} - \E(t - X)^{+}\). Between two consecutive points of \(S\), each \((t - x)^{+}\) is an affine function of \(t\), so \(D\) is affine on each interval \([s_{j}, s_{j+1}]\). For \(t \le s_{1}\), \(D(t) = 0\), and for \(t \ge s_{m}\), \((t - X)^{+} = t - X\) and \(D(t) = (t - \E Y) - (t - \E X) = 0\) by A2. So if \(D \ge 0\) on \(S\), then on each interval \(D\) is an affine function that is nonnegative at both ends, hence nonnegative throughout, and \(D \ge 0\) on \(\R\). \(\blacksquare\)

Theorem 2.3 (second-order dominance on a finite support)

Assume A1 and A2. Then \(I_{X}(t) \le I_{Y}(t)\) for every real \(t\) if and only if \(\E u(X) \ge \E u(Y)\) for every nondecreasing concave \(u : S \to \R\) (Definition 1.4).

Proof

If. Fix \(t\) and let \(u_{t}(s) = \min(s - t, 0)\) on \(S\). It is nondecreasing, and its chord slopes are \(1\) on the intervals left of \(t\), \(0\) on the intervals right of \(t\), and a value in \([0, 1]\) on the interval that contains \(t\), so they never increase and \(u_{t}\) is concave on \(S\). Since \(\min(x - t, 0) = -(t - x)^{+}\), Lemma 1.2 gives \(\E u_{t}(X) = -I_{X}(t)\) and \(\E u_{t}(Y) = -I_{Y}(t)\). So \(\E u_{t}(X) \ge \E u_{t}(Y)\) says \(I_{X}(t) \le I_{Y}(t)\).

Only if. Let \(u\) be concave on \(S\) with chord slopes \(\sigma_{1} \ge \dots \ge \sigma_{m-1}\). Let \(L\) be the piecewise linear function that equals \(u\) at each \(s_{j}\) and is affine on each \([s_{j}, s_{j+1}]\). Its slope on \((s_{k}, s_{k+1})\) is \(\sigma_{k}\), so for \(s \in [s_{1}, s_{m}]\),

\[ L(s) = u(s_{1}) + \sigma_{1}(s - s_{1}) + \sum_{j=2}^{m-1} (\sigma_{j} - \sigma_{j-1})\,(s - s_{j})^{+}. \]

Write \((s - s_{j})^{+} = (s - s_{j}) - \min(s - s_{j}, 0)\), and put \(c_{j} = \sigma_{j-1} - \sigma_{j} \ge 0\), which is nonnegative by concavity. Then \(L(s) = b_{0} + b_{1} s + \sum_{j=2}^{m-1} c_{j} \min(s - s_{j}, 0)\) for constants \(b_{0}\) and \(b_{1}\). Since \(X\) and \(Y\) take values in \(S\), \(\E u(X) = \E L(X)\) and \(\E u(Y) = \E L(Y)\). By the expression of \(\E \min(x - t, 0)\) in the "if" part,

\[ \E u(X) - \E u(Y) = b_{1}(\E X - \E Y) +\sum_{j=2}^{m-1} c_{j}\big(I_{Y}(s_{j}) - I_{X}(s_{j})\big). \]

The first term is \(0\) by A2, and each \(c_{j} \ge 0\) with \(I_{Y}(s_{j}) - I_{X}(s_{j}) \ge 0\) by hypothesis. So \(\E u(X) \ge \E u(Y)\). \(\blacksquare\)

Remark 2.4 (what the proof uses)

The "only if" proof uses concavity through \(c_{j} \ge 0\) and A2 through the vanishing of the affine term. It does not use monotonicity. So the same conclusion holds for every concave \(u\) on \(S\). The statement keeps nondecreasing utilities because the "if" direction uses the nondecreasing witnesses \(u_{t}\). Research problem R3 shows where monotonicity enters when the means are not equal.

Example 2.5 (a spread that keeps the mean)

Let \(X\) put probability \(1/2\) on 2000 cents and \(1/2\) on 4000 cents, and let \(Y\) put probability \(1/4\) on 1000, \(1/2\) on 3000 and \(1/4\) on 5000 cents. Both means are 3000 cents, so A2 holds. Y is a mean-preserving spread of X: each outcome of X is replaced by two outcomes, one below and one above it, that each carry half of its probability and whose average is the original outcome. Here 2000 cents is replaced by 1000 and 3000 cents, and 4000 cents by 3000 and 5000 cents. On \(S = \{1000, 2000, 3000, 4000, 5000\}\), the integrated distribution functions are computed from Lemma 1.2 as sums of probability times shortfall.

For \(X\): \(I_{X}(1000) = 0\), \(I_{X}(2000) = 0\), \(I_{X}(3000) = \tfrac12 \cdot 1000 = 500\), \(I_{X}(4000) = \tfrac12 \cdot 2000 = 1000\), and \(I_{X}(5000) = \tfrac12 \cdot 3000 + \tfrac12 \cdot 1000 = 2000\).

For \(Y\): \(I_{Y}(1000) = 0\), \(I_{Y}(2000) = \tfrac14 \cdot 1000 = 250\), \(I_{Y}(3000) = \tfrac14 \cdot 2000 = 500\), \(I_{Y}(4000) = \tfrac14 \cdot 3000 + \tfrac12 \cdot 1000 = 1250\), and \(I_{Y}(5000) = \tfrac14 \cdot 4000 + \tfrac12 \cdot 2000 = 2000\).

So \(I_{X} \le I_{Y}\) at every support point, and by Theorem 2.3 and Lemma 2.2, \(X\) dominates \(Y\) in the second order. The first-order test fails in both directions. At 2000 cents, \(F_{X} = 1/2 > 1/4 = F_{Y}\), so \(F_{X} \le F_{Y}\) fails. At 3000 cents, \(F_{Y} = 3/4 > 1/2 = F_{X}\), so \(F_{Y} \le F_{X}\) fails. The pair is ranked in the second order and not in the first.

Example 2.6 (equal means and no first-order ranking)

Let \(X\) put probability \(1/2\) on 1000 cents and \(1/2\) on 5000 cents, and let \(Y\) put probability 1 on 3000 cents. Both means are 3000 cents. At 1000 cents, \(F_{X} = 1/2 > 0 = F_{Y}\), and at 3000 cents, \(F_{Y} = 1 > 1/2 = F_{X}\). So neither \(F_{X} \le F_{Y}\) nor \(F_{Y} \le F_{X}\) holds, and there is no first-order ranking. The integrated distribution functions give \(I_{Y}(t) = (t - 3000)^{+} \le I_{X}(t)\) at every support point, so \(Y\) dominates \(X\) in the second order. Here the lottery that is ranked is the one with no spread.

Lab 1 · First- and second-order dominance on seeded pairs

Predicted from Theorems 1.5 and 2.3 and Lemmas 1.6 and 2.2 before running. The three named pairs, A (the spread of Example 2.5), B (the shift of Example 1.7) and C (Example 2.6), should give the verdicts stated there. For the 24 seeded pairs, the distribution-function verdict and the expected-utility verdict over the finite test set should agree on every pair, because the test set contains the utilities that the proofs of Theorems 1.5 and 2.3 use, and the verdicts reduce to support points by Lemma 1.6 and Lemma 2.2. The integrated verdict and the expected-utility verdict should agree on every equal-mean pair. Each pair is SIMULATED, except the named pairs.

"""E3 lab L04: first- and second-order stochastic dominance on finite-support lotteries, checked by utilities.

SIMULATED: 24 pairs of lotteries on one support of five wealth levels, in cents, are drawn with random.Random(SEED).
Each first lottery places 12 balls on the five levels uniformly at random, so its probabilities are multiples of 1/12.
The second lottery is a shifted copy (one ball moved up, so still multiples of 1/12), a fresh draw, or a mean-matched
lottery (match_mean), whose probabilities are multiples of 1/48.
Three named pairs are fixed in the code and are not SIMULATED. Every integrated distribution function and every
dominance verdict from the distribution functions is exact (fractions.Fraction). The expected utilities of the CRRA
utilities are floating-point, and their differences are compared with a tolerance of 1e-12. Standard library only,
no network.

The check of the expected-utility side uses a finite set of test utilities, not all nondecreasing or all concave
utilities. The set holds the indicator utilities 1{s > t} (first order) or the utilities min(s - t, 0) (second order)
at each support point t, which are the witnesses for the verdicts, together with three CRRA utilities.
"""

from __future__ import annotations

import itertools
import math
import random
from collections import Counter
from fractions import Fraction

SUPPORT = (1000, 2000, 3000, 4000, 5000)
SEED = 20261028
N_BALLS = 12
N_PAIRS = 24
GAMMAS = (0.5, 1.0, 2.0)
TOL = 1e-12

PMF = tuple[Fraction, ...]


def crra_utility(w: float, gamma: float) -> float:
    """CRRA utility of positive wealth w in cents: (w**(1 - gamma) - 1) / (1 - gamma) for gamma != 1, ln(w) at 1."""
    if w <= 0.0:
        raise ValueError(f"CRRA utility needs positive wealth, got {w}")
    if gamma == 1.0:
        return math.log(w)
    return float((w ** (1.0 - gamma) - 1.0) / (1.0 - gamma))


def from_dict(masses: dict[int, Fraction]) -> PMF:
    """A pmf on SUPPORT from a dict of outcome -> probability; every key must lie on SUPPORT."""
    if not set(masses) <= set(SUPPORT):
        raise ValueError("every outcome must lie on SUPPORT")
    return tuple(masses.get(x, Fraction(0)) for x in SUPPORT)


def mean(pmf: PMF) -> Fraction:
    """Expected value in cents, exact."""
    return sum((p * x for p, x in zip(pmf, SUPPORT, strict=True)), Fraction(0))


def cdf(pmf: PMF, t: int) -> Fraction:
    """F(t) = P(X <= t), exact."""
    return sum((p for p, x in zip(pmf, SUPPORT, strict=True) if x <= t), Fraction(0))


def integrated_cdf(pmf: PMF, t: int) -> Fraction:
    """I(t) = integral of F from minus infinity to t, which equals E[(t - X)^+] for a finite support. Exact."""
    return sum((p * max(t - x, 0) for p, x in zip(pmf, SUPPORT, strict=True)), Fraction(0))


def verdict(x_first: bool, y_first: bool) -> str:
    """Name the ordering from the two one-way tests: X at least as good as Y, Y at least as good as X, or both."""
    if x_first and y_first:
        return "identical"
    if x_first:
        return "X dominates Y"
    if y_first:
        return "Y dominates X"
    return "no ranking"


def fosd_cdf_verdict(px: PMF, py: PMF) -> str:
    """First-order verdict from distribution functions: X dominates Y when F_X(t) <= F_Y(t) at every support point."""
    fx = [cdf(px, t) for t in SUPPORT]
    fy = [cdf(py, t) for t in SUPPORT]
    return verdict(all(a <= b for a, b in zip(fx, fy, strict=True)), all(b <= a for a, b in zip(fx, fy, strict=True)))


def sosd_cdf_verdict(px: PMF, py: PMF) -> str:
    """Second-order verdict from integrated distribution functions, for equal means. X dominates Y when I_X <= I_Y."""
    if mean(px) != mean(py):
        raise ValueError("the second-order test in this lab needs equal means")
    ix = [integrated_cdf(px, t) for t in SUPPORT]
    iy = [integrated_cdf(py, t) for t in SUPPORT]
    return verdict(all(a <= b for a, b in zip(ix, iy, strict=True)), all(b <= a for a, b in zip(ix, iy, strict=True)))


def eu_verdict(diffs: list[Fraction | float]) -> str:
    """Verdict from the expected-utility differences E u(X) - E u(Y) over a set of test utilities."""
    return verdict(all(d >= -TOL for d in diffs), all(d <= TOL for d in diffs))


def exact_diffs(px: PMF, py: PMF, utilities: list[tuple[Fraction, ...]]) -> list[Fraction | float]:
    """E u(X) - E u(Y) for exact-valued utilities, computed as Fractions."""
    return [sum(((a - b) * v for a, b, v in zip(px, py, u, strict=True)), Fraction(0)) for u in utilities]


def float_diffs(px: PMF, py: PMF, utilities: list[tuple[float, ...]]) -> list[Fraction | float]:
    """E u(X) - E u(Y) for floating-point utilities."""
    return [sum(float(a - b) * v for a, b, v in zip(px, py, u, strict=True)) for u in utilities]


def indicator_utilities() -> list[tuple[Fraction, ...]]:
    """The first-order witnesses 1{s > t} at each support point t."""
    return [tuple(Fraction(1 if x > t else 0) for x in SUPPORT) for t in SUPPORT]


def min_utilities() -> list[tuple[Fraction, ...]]:
    """The second-order witnesses min(s - t, 0) at each support point t: nondecreasing and concave in s."""
    return [tuple(Fraction(min(x - t, 0)) for x in SUPPORT) for t in SUPPORT]


def crra_values() -> list[tuple[float, ...]]:
    """CRRA utilities at the support points, for the gamma values in GAMMAS."""
    return [tuple(crra_utility(float(x), g) for x in SUPPORT) for g in GAMMAS]


def chord_slopes_nonincreasing(values: tuple[Fraction | float, ...]) -> bool:
    """True when the chord slopes of the function through (SUPPORT, values) never increase: concavity on the support."""
    slopes = [(values[j + 1] - values[j]) / (SUPPORT[j + 1] - SUPPORT[j]) for j in range(len(SUPPORT) - 1)]
    return all(a >= b for a, b in itertools.pairwise(slopes))


def draw_pmf(rng: random.Random) -> PMF:
    """A SIMULATED lottery: N_BALLS balls, each placed on a uniformly chosen support point."""
    counts = [0] * len(SUPPORT)
    for _ in range(N_BALLS):
        counts[rng.randrange(len(SUPPORT))] += 1
    return tuple(Fraction(c, N_BALLS) for c in counts)


def shift_up(px: PMF, rng: random.Random) -> PMF | None:
    """Move one ball's probability, 1/N_BALLS, from a lower support point to a higher one. None if no ball can move."""
    step = Fraction(1, N_BALLS)
    eligible = [i for i in range(len(SUPPORT) - 1) if px[i] >= step]
    if not eligible:
        return None
    i = rng.choice(eligible)
    j = rng.randrange(i + 1, len(SUPPORT))
    q = list(px)
    q[i] -= step
    q[j] += step
    return tuple(q)


def match_mean(pmf: PMF, target: Fraction) -> PMF | None:
    """Move mass between the lowest and highest support points until the mean equals target. None if infeasible."""
    move = (target - mean(pmf)) / (SUPPORT[-1] - SUPPORT[0])
    q = list(pmf)
    if move >= 0:
        if q[0] < move:
            return None
        q[0] -= move
        q[-1] += move
    else:
        m = -move
        if q[-1] < m:
            return None
        q[-1] -= m
        q[0] += m
    return tuple(q)


def describe(pmf: PMF) -> str:
    """The pmf as outcome:probability pairs, exact."""
    return ", ".join(f"{x}:{p}" for x, p in zip(SUPPORT, pmf, strict=True) if p)


def main() -> None:
    print(f"support in cents: {list(SUPPORT)}; seed {SEED}; {N_PAIRS} SIMULATED pairs")
    ind, mins, crra = indicator_utilities(), min_utilities(), crra_values()
    concave_ok = all(chord_slopes_nonincreasing(u) for u in mins) and all(chord_slopes_nonincreasing(v) for v in crra)
    print(f"min and CRRA test utilities have nonincreasing chord slopes on the support: {concave_ok}")

    fixed = {
        "A (spread)": (
            from_dict({2000: Fraction(1, 2), 4000: Fraction(1, 2)}),
            from_dict({1000: Fraction(1, 4), 3000: Fraction(1, 2), 5000: Fraction(1, 4)}),
        ),
        "B (shift)": (
            from_dict({2000: Fraction(1, 2), 4000: Fraction(1, 2)}),
            from_dict({3000: Fraction(1, 2), 4000: Fraction(1, 2)}),
        ),
        "C (equal means)": (from_dict({1000: Fraction(1, 2), 5000: Fraction(1, 2)}), from_dict({3000: Fraction(1)})),
    }
    for name, (px, py) in fixed.items():
        print(f"named pair {name}: X = {describe(px)}; Y = {describe(py)}; means {mean(px)} and {mean(py)}")
        fv = fosd_cdf_verdict(px, py)
        fe = eu_verdict(exact_diffs(px, py, ind) + float_diffs(px, py, crra))
        print(f"named pair {name}: FOSD verdict {fv}; expected-utility verdict {fe}; agree: {fv == fe}")
        if mean(px) == mean(py):
            sv = sosd_cdf_verdict(px, py)
            se = eu_verdict(exact_diffs(px, py, mins) + float_diffs(px, py, crra))
            print(f"named pair {name}: SOSD verdict {sv}; expected-utility verdict {se}; agree: {sv == se}")
        print(
            f"named pair {name}: integrated CDF of X at the support points: "
            f"{[str(integrated_cdf(px, t)) for t in SUPPORT]}"
        )
        print(
            f"named pair {name}: integrated CDF of Y at the support points: "
            f"{[str(integrated_cdf(py, t)) for t in SUPPORT]}"
        )

    rng = random.Random(SEED)
    kinds = ("shift", "equal-mean", "random")
    pairs: list[tuple[str, PMF, PMF]] = []
    while len(pairs) < N_PAIRS:
        kind = kinds[len(pairs) % 3]
        px = draw_pmf(rng)
        if kind == "shift":
            py_opt = shift_up(px, rng)
        elif kind == "equal-mean":
            py_opt = match_mean(draw_pmf(rng), mean(px))
        else:
            py_opt = draw_pmf(rng)
        if py_opt is not None:
            pairs.append((kind, px, py_opt))

    fosd_counts: Counter[str] = Counter()
    fosd_agree = 0
    sosd_counts: Counter[str] = Counter()
    sosd_total = 0
    sosd_agree = 0
    integrated_ok = True
    for n, (kind, px, py) in enumerate(pairs):
        fv = fosd_cdf_verdict(px, py)

3Where the canon breaks

Dominance is a partial ranking, not a total one, and four limits apply to this lesson.

  • The support is finite. Theorems 1.5 and 2.3 are proved here for lotteries with finite support, under A1. The statement for general distributions is not proved on this page, and this lesson cites no source for it.
  • Second-order dominance needs equal means. Theorem 2.3 assumes A2. Research problem R3 gives the monotone case when the means differ, and the lesson does not state a general result beyond it.
  • Some pairs are not ranked. In Lab 1, 10 of the 24 seeded pairs have no first-order ranking, and 2 of the 8 equal-mean pairs have no second-order ranking. A verdict of "no ranking" is a result, not an error: the test does not order that pair, and by the proof of Theorem 1.5, some nondecreasing utility prefers X to Y and some nondecreasing utility prefers Y to X.
  • The test set is finite. Lab 1 checks verdicts against the utilities that the proofs of Theorems 1.5 and 2.3 use, and three CRRA utilities. The theorems quantify over every nondecreasing or concave utility on \(S\), and the lab does not check that quantifier.

4Misconceptions

  1. “Equal means make one lottery dominate the other.”

    Equal means are a hypothesis of the second-order theorem, not a ranking. Example 2.6 has equal means of 3000 cents and no first-order ranking, and Example 2.5 has equal means and a second-order ranking in one direction only. The mean says nothing about the shape, so a ranking needs one of the two tests.

  2. “Second-order dominance is a weaker test, so it ranks every pair.”

    The second-order test applies only to pairs with equal means (A2), and it ranks a pair only when the integrated distribution functions are ordered at every support point. Lab 1 finds 2 equal-mean pairs with no second-order ranking, pairs 16 and 19 in its list. The lab does not apply the second-order test to its unequal-mean pairs.

  3. “The second-order test is the first-order test under another name.”

    The first-order test compares distribution functions, and the second-order test compares their integrals. Example 2.5 has a second-order ranking and no first-order ranking, so the two tests are different. Proposition 1.8 shows that whenever the first-order test ranks a pair, the integrated distribution functions order it in the same direction, so for equal-mean pairs the second-order test ranks every pair that the first-order test ranks.

Mechanics

M1 · Distribution functions of two lotteries

Let \(X\) put probability \(1/2\) on 1000 cents and \(1/2\) on 4000 cents, and let \(Y\) put probability 1 on 2000 cents. Find \(F_{X}\) and \(F_{Y}\) at 1000, 2000 and 4000 cents, and state the first-order verdict.

Solution

\(F_{X}(1000) = 1/2\), \(F_{X}(2000) = 1/2\), \(F_{X}(4000) = 1\). \(F_{Y}(1000) = 0\), \(F_{Y}(2000) = 1\), \(F_{Y}(4000) = 1\). Then \(F_{X}(1000) > F_{Y}(1000)\), so \(F_{X} \le F_{Y}\) fails. Also \(F_{Y}(2000) > F_{X}(2000)\), so \(F_{Y} \le F_{X}\) fails. There is no first-order ranking. The means are 2500 and 2000 cents, so the means alone would suggest an ordering that the first-order test does not give.

M2 · An integrated distribution value

For the pair of Example 2.5, compute \(I_{X}(3000)\) and \(I_{Y}(3000)\) from the definition \(I(t) = \E(t - X)^{+}\).

Solution

For \(X\), \((3000 - 2000)^{+} = 1000\) with probability \(1/2\) and \((3000 - 4000)^{+} = 0\) with probability \(1/2\), so \(I_{X}(3000) = 500\). For \(Y\), \((3000 - 1000)^{+} = 2000\) with probability \(1/4\), and the other two outcomes are at or above 3000, so \(I_{Y}(3000) = 500\). Both equal 500, which agrees with the table in Example 2.5.

M3 · Two ways to compute an integrated value

Let \(X\) put probability \(1/4\) on 1000 cents and \(3/4\) on 5000 cents. Compute \(I_{X}(3000)\) once as the integral of \(F_{X}\) and once as \(\E(3000 - X)^{+}\), and check that they agree.

Solution

\(F_{X}(s) = 0\) for \(s < 1000\), \(F_{X}(s) = 1/4\) for \(1000 \le s < 5000\). So \(\int_{-\infty}^{3000} F_{X}(s)\,ds = \tfrac14 (3000 - 1000) = 500\). The expectation is \(\tfrac14 (3000 - 1000)^{+} + \tfrac34 (3000 - 5000)^{+} = \tfrac14 \cdot 2000 + 0 = 500\). The two computations agree, as Lemma 1.2 requires.

Proof

P1 · The test needs only support points

Prove Lemma 1.6 without citing it, for a point \(t\) between two consecutive points of \(S\).

Solution

Let \(s_{j} < t < s_{j+1}\). Neither \(X\) nor \(Y\) takes a value in \((s_{j}, t]\), because that interval contains no point of \(S\). So \(\Prob(X \le t) = \Prob(X \le s_{j})\) and \(\Prob(Y \le t) = \Prob(Y \le s_{j})\). The inequality \(F_{X}(t) \le F_{Y}(t)\) is therefore the inequality \(F_{X}(s_{j}) \le F_{Y}(s_{j})\) at a point of \(S\). If \(t > s_{m}\), no point of \(S\) lies in \((s_{m}, t]\), so \(F_{X}(t) = F_{X}(s_{m})\) and \(F_{Y}(t) = F_{Y}(s_{m})\), and both equal 1 because every outcome is at most \(s_{m}\). The argument is then complete for every \(t\) with \(s_{1} \le t\). For \(t < s_{1}\), both distribution functions are 0.

P2 · First-order dominance implies the integrated order

Prove Proposition 1.8 in one line of integration, and say which hypothesis is not needed.

Solution

If \(F_{X} \le F_{Y}\) everywhere, then \(\int_{-\infty}^{t} F_{X}(s)\,ds \le \int_{-\infty}^{t} F_{Y}(s)\,ds\), because the integral of a pointwise smaller function over the same interval is smaller. Both integrals are finite since each integrand is 0 below \(s_{1}\) and lies in \([0, 1]\). The equal-means hypothesis A2 is not needed, because the integrated order does not involve the means.

P3 · The witness utility is nondecreasing and concave

For a fixed \(t \in S\), show that \(u_{t}(s) = \min(s - t, 0)\) is nondecreasing and concave on \(S\) in the sense of Definition 1.4, and that \(\E u_{t}(X) = -I_{X}(t)\).

Solution

The values \(u_{t}(s)\) are \(s - t\) for \(s < t\) and 0 for \(s \ge t\), so they never decrease in \(s\). The chord slope between consecutive points left of \(t\) is 1, and between consecutive points at or to the right of \(t\) it is 0, and the slope across \(t\) lies between them, so the chord slopes are nonincreasing. Finally \(\min(x - t, 0) = -(t - x)^{+}\), so \(\E u_{t}(X) = -\E(t - X)^{+} = -I_{X}(t)\) by Lemma 1.2.

Research

R1 · The converse of first-order dominance

Show that the integrated ordering of Proposition 1.8 does not imply the first-order ordering, using Example 2.5.

Solution

In Example 2.5, \(I_{X}(t) \le I_{Y}(t)\) at every support point, so the integrated ordering holds. But the first-order ordering fails, because \(F_{X}(2000) = 1/2 > 1/4 = F_{Y}(2000)\). So the integrated ordering is strictly weaker, and the first-order ordering does not follow from it.

R2 · Where the equal-means hypothesis enters

Explain in one paragraph why Theorem 2.3 needs A2 in its "only if" direction, and identify the term of the proof that A2 removes.

Solution

The proof writes \(\E u(X) - \E u(Y)\) as \(b_{1}(\E X - \E Y)\) plus a sum of nonnegative terms weighted by the integrated distributions. The coefficient \(b_{1}\) is the slope of the piecewise linear function \(L\) of the proof on the last interval, and the term \(b_{1}(\E X - \E Y)\) is nonzero in general when the means differ. A2 removes that term, so the sum of nonnegative terms alone decides the ordering.

R3 · Unequal means under a nondecreasing concave utility

Suppose \(I_{X}(t) \le I_{Y}(t)\) for every \(t\) but A2 fails, and \(u\) is nondecreasing and concave on \(S\). Show that \(\E u(X) \ge \E u(Y)\) still holds.

Solution

Use the representation of the "only if" proof. The slope of \(L\) on the last interval is \(b_{1} = \sigma_{m-1} \ge 0\), because \(u\) is nondecreasing. At \(t = s_{m}\), every outcome is at most \(t\), so \(I_{X}(s_{m}) = s_{m} - \E X\) and \(I_{Y}(s_{m}) = s_{m} - \E Y\). The hypothesis \(I_{X}(s_{m}) \le I_{Y}(s_{m})\) then gives \(\E X \ge \E Y\), so the affine term \(b_{1}(\E X - \E Y)\) is nonnegative. The sum of nonnegative terms is nonnegative as before, so \(\E u(X) \ge \E u(Y)\). This is where monotonicity enters.
