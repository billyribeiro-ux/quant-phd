Rung 1 · Worked Example

In this worked example, we solve the three-equation New Keynesian model for standard quarterly parameters. We first check whether the generalized Taylor principle holds to ensure equilibrium determinacy. We then solve for the impact coefficients of an AR(1) demand shock and policy shock by the method of undetermined coefficients, and project the forward impulse response paths.

Lab 1 · Solved NK Model Instance

For parameters \(\beta=0.99\), \(\sigma=1.0\), \(\kappa=0.1\), \(\phi_\pi=1.5\), \(\phi_y=0.5\), and \(\rho=0.5\), the Taylor metric is positive, the system is determinate, and impulse responses decay geometrically. Model output, no data.

"""Lab E6-project-1: Project Rung 1 worked example for the New Keynesian model solver.

Step-by-step fully annotated walkthrough solving:
1. Equilibrium determinacy via the generalized Taylor principle.
2. Undetermined coefficients for demand and policy disturbances.
3. Impulse response functions over horizon H = 3.
Model output, no data.
"""

from __future__ import annotations


def main() -> None:
    # Model parameters
    beta = 0.99
    sigma = 1.0
    kappa = 0.1
    phi_pi = 1.5
    phi_y = 0.5
    rho = 0.5
    horizon = 3

    print("Rung 1: Worked Example - Solving the Canonical New Keynesian Model")
    print("Parameters: beta=0.99, sigma=1.0, kappa=0.1, phi_pi=1.5, phi_y=0.5, rho=0.5")

    # Step 1: Check equilibrium determinacy
    # Why: In a forward-looking model, determinacy requires that nominal rate policy raises
    # the real interest rate in response to inflation, eliminating self-fulfilling sunspot fluctuations.
    taylor_metric = kappa * (phi_pi - 1.0) + (1.0 - beta) * phi_y
    is_determinate = taylor_metric > 0.0
    print(f"\nStep 1: Determinacy check: metric = {taylor_metric:.4f} > 0 -> {is_determinate}")

    # Step 2: Undetermined coefficients
    # Why: Substituting linear guesses x_t = b * u_t and pi_t = a * u_t into the dynamic IS and NKPC
    # gives a 2x2 linear system with determinant Delta.
    delta = (1.0 - beta * rho) * (sigma * (1.0 - rho) + phi_y) + kappa * (phi_pi - rho)
    b_demand = (1.0 - beta * rho) / delta
    a_demand = kappa / delta

    b_policy = -(1.0 - beta * rho) / delta
    a_policy = -kappa / delta

    print(f"Step 2: Denominator Delta = {delta:.6f}")
    print(f"  Demand shock coefficients: b_d = {b_demand:.6f}, a_d = {a_demand:.6f}")
    print(f"  Policy shock coefficients: b_v = {b_policy:.6f}, a_v = {a_policy:.6f}")

    # Step 3: Compute impulse response paths
    # Why: For an AR(1) shock u_t = rho^t, variables decay along geometric paths.
    print(f"\nStep 3: Impulse response paths for horizon H = {horizon}:")
    print("  Date | Demand: x_t    pi_t     i_t    | Policy: x_t    pi_t     i_t")
    print("  -----+--------------------------------+-------------------------------")
    for t in range(horizon + 1):
        u_t = rho**t
        # Demand shock
        xd = b_demand * u_t
        pid = a_demand * u_t
        id_val = phi_pi * pid + phi_y * xd
        # Policy shock
        xv = b_policy * u_t
        piv = a_policy * u_t
        iv_val = phi_pi * piv + phi_y * xv + u_t

        print(f"  {t:4d} |        {xd:7.4f}  {pid:7.4f}  {id_val:7.4f} |        {xv:7.4f}  {piv:7.4f}  {iv_val:7.4f}")


main()

Rung 3 · Independent Project Specification

In this independent capstone project, you implement a full New Keynesian general equilibrium solver module nk_solver.py and produce the canonical impulse response dataset irf.csv.

Context
A monetary policy researcher requires an automated, robust rational-expectations solver for the canonical three-equation New Keynesian model under contemporary Taylor rules. The solver must rigorously verify equilibrium determinacy, compute structural impact coefficients via undetermined coefficients, and simulate multi-period impulse response trajectories for demand and monetary policy disturbances while rejecting inadmissible parameters.
Inputs
One parameter dictionary per seed generated deterministically by make_instance(seed). The dictionary contains:
  • beta: quarterly discount factor \(\beta \in (0, 1)\)
  • sigma: intertemporal elasticity of substitution / CRRA risk aversion \(\sigma > 0\)
  • kappa: slope of the New Keynesian Phillips curve \(\kappa > 0\)
  • phi_pi: Taylor rule inflation response \(\phi_\pi \ge 0\)
  • phi_y: Taylor rule output gap response \(\phi_y \ge 0\)
  • rho: shock persistence \(|\rho| < 1\)
  • horizon: non-negative integer forecast horizon
Required outputs
  • A python module nk_solver.py implementing:
    • is_determinate(params: dict) -> bool: returns True if the generalized Taylor condition \(\kappa(\phi_\pi - 1) + (1 - \beta)\phi_y > 0\) holds strictly, False otherwise.
    • solve_undetermined(params: dict, shock: str = "demand") -> tuple[float, float]: returns \((b, a)\), where \(x_t = b u_t\) and \(\pi_t = a u_t\). Raises ValueError if indeterminate or invalid.
    • impulse_responses(params: dict, horizon: int) -> dict[str, list[float]]: returns dictionary with keys date, x_demand, pi_demand, i_demand, x_policy, pi_policy, i_policy for dates \(0, 1, \dots, H\).
  • irf.csv containing header date,x_demand,pi_demand,i_demand,x_policy,pi_policy,i_policy and rows matching impulse_responses.
  • A figure set visualizing the demand shock and monetary policy shock impulse responses.
Constraints
Standard library, NumPy, and SciPy. The solver must be warning-free under python -I -W error. All functions must be pure and never mutate input dictionaries in place. Floating-point residuals must satisfy tolerance \(10^{-8} \times \max(1, |\text{expected}|)\).
Grading
Graded by an automated autograder test suite evaluated across 50 seeds, testing input domain validation, determinacy boundary precision, rational expectations equation residuals, and impulse response shapes.

"""

from __future__ import annotations


def solve_undetermined_coefficients(
    beta: float, sigma: float, kappa: float, phi_pi: float, phi_y: float, rho: float
) -> tuple[bool, float, float, float, float]:
    det_metric = kappa * (phi_pi - 1.0) + (1.0 - beta) * phi_y
    is_det = det_metric > 0.0

    delta = (1.0 - beta * rho) * (sigma * (1.0 - rho) + phi_y) + kappa * (phi_pi - rho)
    b_demand = (1.0 - beta * rho) / delta
    a_demand = kappa / delta

    b_policy = -(1.0 - beta * rho) / delta
    a_policy = -kappa / delta

    return is_det, b_demand, a_demand, b_policy, a_policy

    sigma = 1.27
    kappa = 0.319
    phi_pi = 1.861

    horizon = 4

Rung 4 · Stretch: Cost-Push Supply Shocks

In standard macroeconomic policy analysis, monetary authorities face a benign divine coincidence under demand shocks (stabilizing inflation also stabilizes the output gap). Extend your solver to incorporate an exogenous cost-push supply disturbance \(u_{s,t} = \rho_s u_{s,t-1} + \varepsilon_{s,t}\) in the NKPC:

\[ \pi_t = \beta \E_t[\pi_{t+1}] + \kappa x_t + u_{s,t} \]

Analyze how a positive cost-push shock forces a trade-off between inflation and output gap stabilization under alternative policy preferences.
