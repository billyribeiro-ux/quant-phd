Arrow–Debreu securities and state-contingent payoffs

  • Uses: random variable, expectation, linear map, vector space
  • Introduces: Arrow–Debreu (state-contingent) security
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study or finite check
  • Dlore
  • Xrefuted

A price is attached to a payment due only in some future state of the world. A market can value such a payment only after the model says what the states are, what a payment in each state is, and how payments are priced. This lesson fixes those objects on a finite state space. It defines the Arrow–Debreu security (Definition 1.3), which pays in a single state, and proves that every claim (Definition 1.2) is a weighted sum of these securities. Under the linear valuation of Assumption A2 (§3), a claim's value is the sum of security prices times payoffs. Lesson L02 uses these prices to define equilibrium.

1States, claims and probabilities

Definition 1.1 (state space)

A state space is a finite set \(\Omega = \{1, \ldots, S\}\) of states, one of which is realized. Each state \(s\) has a probability \(\pi_s\). Probabilities are numbers with \(\pi_s > 0\) and \(\sum_{s=1}^{S} \pi_s = 1\).

Assumption A1 (finite, strictly positive states)

The state space \(\Omega\) of Definition 1.1 has \(S < \infty\) states, and \(\pi_s > 0\) for every \(s\). Every result of this lesson that writes a sum over states uses A1. No result here allows infinitely many states.

Definition 1.2 (claim)

A claim is a vector \(x = (x_1, \ldots, x_S) \in \R^{S}\). Its entry \(x_s\) is the payoff in cents that the claim delivers in state \(s\). A claim is the random variable \(X\) on \(\Omega\) with \(X(s) = x_s\), so \(X\) takes the value \(x_s\) in state \(s\). \(\Prob(X = x_s)\) equals \(\pi_s\) exactly when no other state has the same payoff. Payoffs may be negative, which is a promise to pay.

2Arrow–Debreu securities and decomposition

Definition 1.3 (Arrow–Debreu security)

For a state \(s\), the Arrow–Debreu security of state \(s\) is the claim \(e_s\) with entries \((e_s)_t = 1\) when \(t = s\) and \((e_s)_t = 0\) when \(t \ne s\). It pays one cent in state \(s\) and nothing in any other state.

Proposition 1.4 (decomposition into securities)

Assume A1. Every claim \(x \in \R^{S}\) satisfies \[ x = \sum_{s=1}^{S} x_s\, e_s . \] The coefficient of the security of state \(s\) is the payoff \(x_s\) of the claim in that state.

Proof

Fix a state \(t\). The entry of the right-hand side in state \(t\) is \(\sum_{s=1}^{S} x_s (e_s)_t\). By Definition 1.3, \((e_s)_t\) equals 1 when \(s = t\) and 0 otherwise, so the sum has the single nonzero term \(x_t\). The entry of the left-hand side in state \(t\) is \(x_t\). The two vectors agree in every state. The sum is finite because A1 gives \(S < \infty\). The proof uses no probability, so it holds for any positive \(\pi\).

Example 1.5 (a claim on four states)

Let \(S = 4\), with \(\pi = (\tfrac18, \tfrac38, \tfrac38, \tfrac18)\), and let the claim be \(x = (100, 40, 0, 250)\) cents. Proposition 1.4 gives \(x = 100\, e_1 + 40\, e_2 + 0\, e_3 + 250\, e_4\). The coefficient on \(e_3\) is zero because the claim pays nothing in state 3. Lab 1 uses these four states, numbered 0 to 3 in its code, and prints the same decomposition.

3Valuation and the prices of the securities

Assumption A2 (linear valuation)

A valuation is a map \(V\) from claims to cents, and it is linear: for all claims \(x\) and \(y\) and all real numbers \(a\) and \(b\), \[ V(a x + b y) = a\, V(x) + b\, V(y). \] A2 excludes quantity discounts, bid-ask spreads and price impact, because each of those makes \(V\) nonlinear. A2 is an assumption about the market, and this lesson does not derive it.

Definition 1.6 (security price vector)

Under A2, the security price of state \(s\) is \(q_s = V(e_s)\), in cents of value per cent of payoff, and it is a dimensionless number. The price vector is \(q = (q_1, \ldots, q_S)\). The vector \(q\) is called the Arrow–Debreu security price vector.

Proposition 1.7 (value formula)

Assume A1 and A2. For every claim \(x\), \[ V(x) = \sum_{s=1}^{S} q_s\, x_s . \] Assuming A2 for the valuation \(V\), the value of a claim is determined by the security prices and the payoffs alone.

Proof

By Proposition 1.4, \(x = \sum_{s} x_s e_s\). A2 with two terms gives \(V(a x + b y) = a V(x) + b V(y)\). Applying it repeatedly, by induction on the number of summands, gives \(V\bigl(\sum_{s} x_s e_s\bigr) = \sum_{s} x_s V(e_s)\), which is finite because A1 gives \(S < \infty\). Substituting \(q_s = V(e_s)\) from Definition 1.6 gives the formula.

Proposition 1.8 (the prices are unique)

Assume A1 and A2. Suppose a vector \(r \in \R^{S}\) satisfies \(V(x) = \sum_{s} r_s x_s\) for every claim \(x\). Then \(r_s = q_s\) for every state \(s\), where \(q\) is the price vector of Definition 1.6 under A2.

Proof

Take \(x = e_s\) in the hypothesis. Then \(V(e_s) = \sum_t r_t (e_s)_t = r_s\), by Definition 1.3. Also \(V(e_s) = q_s\) by Definition 1.6. Hence \(r_s = q_s\).

Definition 1.9 (expected payoff)

The expected payoff of a claim is \(\E x = \sum_{s} \pi_s x_s\), the average payoff weighted by the probabilities of Definition 1.1. It is the expectation of the random variable of Definition 1.2.

Proposition 1.10 (value equals expected payoff exactly when prices are probabilities)

Assume A1 and A2. The following two statements are equivalent. (a) \(V(x) = \E x\) for every claim \(x\). (b) \(q_s = \pi_s\) for every state \(s\).

Proof

Assume (b). Proposition 1.7 gives \(V(x) = \sum_s \pi_s x_s = \E x\) for every \(x\), which is (a). Now assume (a). For the security \(e_s\), Definition 1.9 gives \(\E e_s = \sum_t \pi_t (e_s)_t = \pi_s\). Taking \(x = e_s\) in (a) gives \(q_s = V(e_s) = \E e_s = \pi_s\), which is (b).

Remark 1.11 (a price is not a probability)

Proposition 1.10 says that prices and probabilities coincide only in the special case (b). Nothing in A1 or A2 forces (b). A security price \(q_s\) depends on how the market values state \(s\), and the probability \(\pi_s\) is an input to the model. Lab 1 Part D shows that the value under the prices differs from the expected payoff for the claim of Example 1.5, so by Proposition 1.10 the prices differ from the probabilities.

Lab 1 · Decomposition and valuation of a four-state claim

The lab uses no data. It computes exactly, with Fraction values, on the four states of Example 1.5, numbered 0 to 3 in the code. Before running it, the hypothesis is this. The printed decomposition gives coefficients 100, 40, 0 and 250 on the four securities, and it rebuilds the claim exactly (Proposition 1.4). Under the prices \((\tfrac12, \tfrac13, \tfrac14, \tfrac15)\), the claim has value \(340/3\) cents, and the second claim has value 56 cents (Proposition 1.7). Linearity holds exactly on a combination with weights 2 and \(-\tfrac12\) (A2). The expected payoff of the claim is \(235/4\) cents, and it differs from the value under these prices (Proposition 1.10). A probability vector with a negative entry, and one whose entries sum to \(9/8\), are each rejected with a ValueError. No random draws are used, so every run prints the same lines.

"""E4 L01 lab 1: Arrow-Debreu decomposition and valuation of a claim on four states, computed exactly.

Inputs are illustrative numbers, not data. The state space has four states. State s has the probability
STATE_PROBABILITIES[s], a positive exact Fraction, and the probabilities sum to exactly 1. A claim is a payoff vector
in whole cents, one entry per state. An Arrow-Debreu security s pays 1 in state s and 0 in every other state. Its
price PRICES[s] is a dimensionless exact Fraction, so a claim's value in cents is the sum of price times payoff.

Part A: the decomposition of the claim into Arrow-Debreu securities, checked state by state.
Part B: the value of the claim under the prices, and of a second claim.
Part C: linearity of the value map in the payoff, checked exactly on a combination with a negative weight.
Part D: the expected payoff under the probabilities, and the value when the prices are the probabilities.
Part E: a probability vector with a negative entry, and one whose entries do not sum to 1, are rejected.

No random draws are used, so every run prints the same lines.
"""

from __future__ import annotations

from fractions import Fraction

Payoff = tuple[Fraction, ...]

STATE_PROBABILITIES: Payoff = (Fraction(1, 8), Fraction(3, 8), Fraction(3, 8), Fraction(1, 8))
PRICES: Payoff = (Fraction(1, 2), Fraction(1, 3), Fraction(1, 4), Fraction(1, 5))
CLAIM: Payoff = (Fraction(100), Fraction(40), Fraction(0), Fraction(250))
OTHER: Payoff = (Fraction(0), Fraction(60), Fraction(120), Fraction(30))


def check_probabilities(probabilities: Payoff) -> None:
    """Raise ValueError unless every probability is positive and the probabilities sum to exactly 1."""
    if any(p <= 0 for p in probabilities):
        raise ValueError("state probabilities must be positive")
    if sum(probabilities, Fraction(0)) != 1:
        raise ValueError("state probabilities must sum to 1")


def security(state: int, n_states: int) -> Payoff:
    """The payoff vector of the Arrow-Debreu security for one state: 1 in that state and 0 in every other state."""
    return tuple(Fraction(1 if t == state else 0) for t in range(n_states))


def value(payoff: Payoff, prices: Payoff) -> Fraction:
    """The value of a claim, the sum over states of price times payoff, in cents, as an exact Fraction."""
    if len(payoff) != len(prices):
        raise ValueError("payoff and prices must have one entry per state")
    return sum((q * x for q, x in zip(prices, payoff, strict=True)), Fraction(0))


def expected_payoff(payoff: Payoff, probabilities: Payoff) -> Fraction:
    """The probability-weighted average payoff in cents, the sum over states of probability times payoff."""
    return sum((p * x for p, x in zip(probabilities, payoff, strict=True)), Fraction(0))


def combine(a: Fraction, x: Payoff, b: Fraction, y: Payoff) -> Payoff:
    """The payoff a times x plus b times y, state by state, with exact Fractions."""
    return tuple(a * xi + b * yi for xi, yi in zip(x, y, strict=True))


def main() -> None:
    """Print Parts A to E. Every value is an exact Fraction, so the output is reproducible."""
    n_states = len(STATE_PROBABILITIES)
    check_probabilities(STATE_PROBABILITIES)

    print("Part A: decomposition of the claim into Arrow-Debreu securities")
    rebuilt = [Fraction(0)] * n_states
    for state in range(n_states):
        payoff_of_security = security(state, n_states)
        coefficient = CLAIM[state]
        print(f"security {state} coefficient {coefficient} pays {tuple(str(z) for z in payoff_of_security)}")
        for t in range(n_states):
            rebuilt[t] += coefficient * payoff_of_security[t]
    print(f"rebuilt payoff {tuple(str(z) for z in rebuilt)} claim {tuple(str(z) for z in CLAIM)}")
    print(f"decomposition_exact {tuple(rebuilt) == CLAIM}")

    print("Part B: value under the prices, in cents")
    print(f"value_of_claim {value(CLAIM, PRICES)} value_of_other {value(OTHER, PRICES)}")

    print("Part C: linearity of the value in the payoff")
    combined = combine(Fraction(2), CLAIM, Fraction(-1, 2), OTHER)
    lhs = value(combined, PRICES)
    rhs = 2 * value(CLAIM, PRICES) - Fraction(1, 2) * value(OTHER, PRICES)
    print(f"combined_payoff {tuple(str(z) for z in combined)}")
    print(f"value_of_combination {lhs} linear_combination_of_values {rhs} equal {lhs == rhs}")

    print("Part D: expected payoff and value at the probabilities")
    expected = expected_payoff(CLAIM, STATE_PROBABILITIES)
    print(f"expected_payoff_claim {expected}")
    print(f"value_at_probability_prices {value(CLAIM, STATE_PROBABILITIES)}")
    print(f"value_at_prices {value(CLAIM, PRICES)} equal_to_expected_payoff {value(CLAIM, PRICES) == expected}")

    print("Part E: invalid probability vectors are rejected")
    negative = (Fraction(1, 2), Fraction(1, 2), Fraction(1, 2), Fraction(-1, 2))
    short = (Fraction(1, 8), Fraction(3, 8), Fraction(3, 8), Fraction(1, 4))
    for label, bad in (("negative", negative), ("short", short)):
        try:
            check_probabilities(bad)
        except ValueError as exc:
            print(f"rejected {label} message {exc}")

Part A prints four securities, each with its coefficient, and a rebuilt payoff equal to the claim, so the decomposition is exact (Proposition 1.4). Part B prints the value of the claim, \(340/3\) cents, and of the other claim, 56 cents, under the same four prices. 4Where the canon breaks

  • Finitely many states. Proposition 1.4 is a finite sum, and Proposition 1.7 applies A2 finitely many times (A1). With countably many states, the decomposition still holds coordinate by coordinate, but the step from finite to infinite sums in Proposition 1.7 is not justified by this lesson, and the formula for infinite \(S\) is not derived here. Research problem R1 identifies that step.
  • Linearity is an assumption. A2 says that a combination of claims is worth the same combination of values, with no discount for size. Under a quantity discount or a size premium, \(V(2x) \ne 2V(x)\), so A2 fails and Proposition 1.7 does not apply (Problem R2).
  • Every security must be priced. Definition 1.6 needs \(V(e_s)\) for each state. If the market cannot deliver the security of some state, \(q_s\) is not defined by this lesson. Lesson L04 treats this case through the rank of the payoff matrix.
  • Probabilities are given. The lesson takes \(\pi\) as an input and does not derive it from beliefs or data. Proposition 1.7 makes the value of a claim depend on \(q\), and Proposition 1.10 shows that \(q\) need not equal \(\pi\).

5Misconceptions

  1. “The price of the security for a state is that state's probability.”

    Proposition 1.10 says the two coincide only under condition (b), and Remark 1.11 says nothing in A1 or A2 forces it. Lab 1 uses prices \((\tfrac12, \tfrac13, \tfrac14, \tfrac15)\) and probabilities \((\tfrac18, \tfrac38, \tfrac38, \tfrac18)\), which differ in every state. Part D prints the line that reads False.

  2. “A claim that pays in several states needs its own price, so a market with \(S\) states must price every combination of states.”

    Proposition 1.7 gives the value of every claim from the \(S\) security prices. Lab 1 Part B values two different claims, 340/3 and 56 cents, from the same four prices, with no further price needed.

  3. “The decomposition works only when the states are equally likely.”

    Proposition 1.4 uses no probability, so it holds for every positive \(\pi\). Lab 1 checks its unequal probabilities \((\tfrac18, \tfrac38, \tfrac38, \tfrac18)\) once, at the start of main(), before Part A. Part A's decomposition uses only the claim, so the rebuilt payoff equals the claim exactly.

6Problem set

Attempt each problem before opening its solution.

Mechanics

M1 · Decompose and value a three-state claim

Let \(S = 3\), \(\pi = (\tfrac12, \tfrac14, \tfrac14)\), and the claim \(x = (10, 0, 30)\) cents. Write \(x\) as a combination of securities. Under the prices \(q = (\tfrac13, \tfrac15, \tfrac12)\), find \(V(x)\) and \(\E x\), and compare them.

Solution

By Proposition 1.4, \(x = 10\, e_1 + 0\, e_2 + 30\, e_3\). By Proposition 1.7, \(V(x) = 10 \cdot \tfrac13 + 0 \cdot \tfrac15 + 30 \cdot \tfrac12 = \tfrac{10}{3} + 15 = \tfrac{55}{3}\) cents, which is about 18.33 cents to two decimal places. The expected payoff is \(\E x = 10 \cdot \tfrac12 + 0 \cdot \tfrac14 + 30 \cdot \tfrac14 = 5 + 7.5 = 12.5\) cents. The value exceeds the expected payoff by \(\tfrac{55}{3} - \tfrac{25}{2} = \tfrac{35}{6}\) cents. By Proposition 1.10, this difference shows that \(q \ne \pi\).

M2 · Value of a claim that pays in one state

A two-state claim pays 0 cents in state 1 and 50 cents in state 2. The security prices are \(q_1 = 0.4\) and \(q_2 = 0.5\). Find the value of the claim, and state which proposition gives it.

Solution

The claim is \(x = (0, 50) = 50\, e_2\), by Proposition 1.4. Proposition 1.7 gives \(V(x) = 0.4 \cdot 0 + 0.5 \cdot 50 = 25\) cents. The price of state 1 does not enter, because the claim pays nothing in state 1, which is the reason the value depends only on \(q_2\) here.

M3 · A combination of two claims

Let \(x = (1, 2, 3)\), \(y = (4, 0, 1)\) and \(q = (\tfrac12, \tfrac14, \tfrac18)\). Compute \(V(3x - 2y)\) directly from its payoffs, and again from \(V(x)\) and \(V(y)\) using A2, and check that the two answers agree.

Solution

The combination is \(3x - 2y = (3 - 8, 6 - 0, 9 - 2) = (-5, 6, 7)\). By Proposition 1.7, \(V = -5 \cdot \tfrac12 + 6 \cdot \tfrac14 + 7 \cdot \tfrac18 = -\tfrac{20}{8} + \tfrac{12}{8} + \tfrac{7}{8} = -\tfrac18\). Separately, \(V(x) = \tfrac12 + \tfrac12 + \tfrac38 = \tfrac{11}{8}\) and \(V(y) = 2 + 0 + \tfrac18 = \tfrac{17}{8}\). Then A2 gives \(3 \cdot \tfrac{11}{8} - 2 \cdot \tfrac{17}{8} = \tfrac{33 - 34}{8} = -\tfrac18\). The two answers agree.

Proof

P1 · The riskless one-cent claim

Let \(\iota\) be the vector of ones, \(\iota = (1, \ldots, 1)\), which is the claim that pays one cent in every state. Show that \(\iota = \sum_{s} e_s\), and that \(V(\iota) = \sum_{s} q_s\) under A1 and A2.

Solution

For each state \(t\), the entry of \(\sum_{s} e_s\) in state \(t\) is \(\sum_{s} (e_s)_t\). By Definition 1.3 exactly one term, the one with \(s = t\), equals 1, so the entry is 1 in every state, and \(\sum_{s} e_s = \iota\). Proposition 1.7 applied to \(x = \iota\) gives \(V(\iota) = \sum_{s} q_s \cdot 1 = \sum_{s} q_s\). The value of a sure cent is the sum of the security prices.

P2 · Value of the zero claim and of a reversed claim

Under A2, show that \(V(0) = 0\) for the zero claim, and that \(V(-x) = -V(x)\) for every claim \(x\).

Solution

Take \(a = 0\) and \(b = 0\) in A2 with any claim \(x\) and \(y = x\): \(V(0 \cdot x + 0 \cdot x) = 0 \cdot V(x) + 0 \cdot V(x) = 0\), so \(V(0) = 0\). Take \(a = -1\) and \(b = 0\): \(V(-x) = -1 \cdot V(x) + 0 \cdot V(x) = -V(x)\). Both follow from A2 alone.

P3 · Prices that differ from probabilities, two states

Let \(S = 2\), \(\pi = (\tfrac13, \tfrac23)\) and \(q = (\tfrac14, \tfrac12)\), with \(V\) linear and defined by Proposition 1.7. Show that \(V(x) \ne \E x\) for some claim \(x\), and identify the claim.

Solution

Take \(x = e_1\), which pays one cent in state 1. Then \(V(e_1) = q_1 = \tfrac14\), while \(\E e_1 = \pi_1 = \tfrac13\). Since \(\tfrac14 \ne \tfrac13\), the equality of Proposition 1.10 fails for \(x = e_1\), and so statement (a) fails. This is the contrapositive of Proposition 1.10, which says that (a) forces \(q = \pi\). It is not a counterexample to a converse, because Proposition 1.10 proves both directions.

Empirical

E1 · Reading the decomposition from Lab 1

In Part A of Lab 1, what coefficient and what payoff does the printed line for security 2 show? Which state of Example 1.5 does security 2 correspond to, and why does its coefficient vanish?

Solution

The line reads "security 2 coefficient 0 pays ('0', '0', '1', '0')". Security 2 in the code is the security of state 3 in the text, because the lab numbers states from 0. Its coefficient is 0, which equals the claim's payoff in state 3, and its payoff vector has its 1 in the third entry. A zero coefficient means the decomposition uses no units of that security.

E2 · Checking linearity from Lab 1

Part C of Lab 1 prints a value for a combination of the two claims and a linear combination of their values. What are the two printed numbers, and what does the equal flag check?

Solution

The line reads "value_of_combination 596/3 linear_combination_of_values 596/3 equal True". Both numbers are \(596/3\) cents. The flag checks A2 for the combination \(2x - \tfrac12 y\) under the four prices. It checks one combination with these weights, and it does not establish linearity for every pair of claims.

E3 · What Part D shows about prices and probabilities

Part D of Lab 1 prints an expected payoff, a value at the probabilities, and a value at the prices with a flag. What do the three printed numbers equal, and what does the flag say?

Solution

The expected payoff is \(235/4 = 58.75\) cents, and the value at the probabilities is also \(235/4\), as Proposition 1.10 (b) predicts. The value at the prices is \(340/3 \approx 113.33\) cents, rounded to two decimal places from \(340/3\), and the flag reads False. So the prices are not the probabilities, and the value under the prices differs from the expected payoff.

Research

R1 · Infinitely many states

Let the state space be countable, with \(\pi_s > 0\) and \(\sum_s \pi_s = 1\). Identify the step of the proof of Proposition 1.7 that is not justified when \(S\) is infinite.

Solution

The decomposition still holds coordinate by coordinate, because in each state only one term of \(\sum_s x_s e_s\) is nonzero. The step that is not justified is the application of A2 to an infinite sum, since A2 is stated for two terms and induction on the number of summands gives finite sums only. This lesson therefore derives the formula \(V(x) = \sum_s q_s x_s\) for finite \(S\) only, and it does not derive that formula for infinite \(S\).

R2 · A size effect breaks linearity

Let \(V(x) = \bigl(\sum_s q_s x_s\bigr)^2\), which applies a size effect to the value. With \(q_1 = \tfrac12\), compute \(V(e_1)\) and \(V(2 e_1)\), and state which assumption fails.

Solution

We have \(V(e_1) = (\tfrac12)^2 = \tfrac14\) and \(V(2e_1) = (2 \cdot \tfrac12)^2 = 1\). Linearity would require \(V(2e_1) = 2V(e_1) = \tfrac12\), which fails. So A2 fails, and Proposition 1.7 does not apply to this \(V\). The formula \(\sum_s q_s x_s\) is then not the value of the claim.

R3 · When nonnegative claims have nonnegative value

Under A1 and A2, show that \(V(x) \ge 0\) for every claim with \(x_s \ge 0\) for all \(s\) if and only if \(q_s \ge 0\) for all \(s\).

Solution

If every \(q_s \ge 0\) and every \(x_s \ge 0\), then \(V(x) = \sum_s q_s x_s \ge 0\) by Proposition 1.7. Conversely, if \(V(x) \ge 0\) for every nonnegative claim, take \(x = e_s\), which is nonnegative. Then \(q_s = V(e_s) \ge 0\) by Definition 1.6. Both directions use only Proposition 1.7 and the definition of the prices.

  1. In a two-state model, what is the coefficient of the claim \((5, 7)\) on the Arrow–Debreu security of state 2?

    Options

    Proposition 1.4 says the coefficient on \(e_s\) is the payoff \(x_s\) in state \(s\). For state 2 that payoff is 7.

  2. A claim pays 5 cents in state 1 and 7 cents in state 2. The security prices are \(q_1 = \tfrac12\) and \(q_2 = \tfrac14\). What is its value, in cents?

    \(V(x) = \tfrac12 \cdot 5 + \tfrac14 \cdot 7 = 2.5 + 1.75 = 4.25\) cents (Proposition 1.7).

  3. Under A2, what is \(V(2x)\) in terms of \(V(x)\)?

    Options

    A2 with \(a = 2\) and \(b = 0\) gives \(V(2x) = 2V(x)\). Problem R2 shows what happens when A2 fails.

  4. A claim pays 0 in state 1 and 4 in state 2, with probabilities \(\pi_1 = \tfrac14\) and \(\pi_2 = \tfrac34\). What is its expected payoff, in cents?

    \(\E x = 0 \cdot \tfrac14 + 4 \cdot \tfrac34 = 3\) cents (Definition 1.9).

  5. Which property holds for an Arrow–Debreu security?

    Options

    Definition 1.3 gives the payoff vector \(e_s\), with a 1 in state \(s\) and 0 elsewhere.

  6. Which assumption does the decomposition \(x = \sum_s x_s e_s\) of Proposition 1.4 require?

    Options

    Proposition 1.4 is an identity about payoff vectors. It uses A1 for the finiteness of the sum, and it uses no probability and no utility.

  7. A claim pays one cent in each of three states. The security prices are \(0.2\), \(0.3\) and \(0.1\). What is its value, in cents?

    \(V(\iota) = \sum_s q_s = 0.2 + 0.3 + 0.1 = 0.6\) cents (Problem P1).

  8. Two vectors \(r\) and \(q\) both satisfy \(V(x) = \sum_s r_s x_s\) and \(V(x) = \sum_s q_s x_s\) for every claim \(x\). What follows?

    Options

    Proposition 1.8: taking \(x = e_s\) gives \(r_s = V(e_s) = q_s\) for every state.

  9. Which feature of a market would make the value of a claim nonlinear in its payoff?

    Options

    A size discount violates A2, which is the linearity that Proposition 1.7 uses (Problem R2). Neither the number of states nor the probabilities alone affects linearity.
