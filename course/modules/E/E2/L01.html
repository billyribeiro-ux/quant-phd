Strategic Form and Nash Equilibrium

  • Uses: quantifiers (M1), Cournot competition and Pareto efficiency (E1)

  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study or lab result
  • Dlore

A game is a set of players whose payoffs depend on each other's actions. The test studied here asks whether a profile of actions is stable, in the sense that no player gains by changing its own action alone. Bayesian games and auctions in L02 apply this test to games with private information. Adverse selection, signaling, screening and moral hazard follow in later lessons. This lesson defines the test, proves three results, on dominance, on games without a pure equilibrium, and on the symmetric pair of the quantity game, and checks three finite games and a grid-based quantity game by exhaustive enumeration in Lab 1.

1Strategic-form games and best responses

Definition 1.1 (two-player game in strategic form)

A two-player game in strategic form has a nonempty action set \(A_1\) for player 1 and a nonempty action set \(A_2\) for player 2, and payoff functions \(u_1 : A_1 \times A_2 \to \R\) and \(u_2 : A_1 \times A_2 \to \R\). The players choose at the same time. Player \(i\) receives \(u_i(a_1, a_2)\), where \((a_1, a_2)\) is the pair of chosen actions, and the payoffs are the players' objectives.

A pair \((a_1, a_2)\) with \(a_1 \in A_1\) and \(a_2 \in A_2\) is a profile of pure actions. Pure actions are chosen with certainty. Mixed strategies, which randomize over actions, are outside this lesson, so every equilibrium named here is an equilibrium in pure actions.

Definition 1.2 (best response)

Action \(a_1 \in A_1\) is a best response to \(a_2 \in A_2\) when \(u_1(a_1, a_2) \ge u_1(a_1', a_2)\) for every \(a_1' \in A_1\). Symmetrically, \(a_2\) is a best response to \(a_1\) when \(u_2(a_1, a_2) \ge u_2(a_1, a_2')\) for every \(a_2' \in A_2\). A best response may tie with another action. Lesson text states the strict case separately where it matters.

Definition 1.3 (pure-strategy Nash equilibrium)

A profile \((\hat a_1, \hat a_2)\) is a Nash equilibrium in pure actions when \(\hat a_1\) is a best response to \(\hat a_2\) and \(\hat a_2\) is a best response to \(\hat a_1\). Written out, the profile is an equilibrium when \(u_1(\hat a_1, \hat a_2) \ge u_1(a_1, \hat a_2)\) for every \(a_1 \in A_1\), and \(u_2(\hat a_1, \hat a_2) \ge u_2(\hat a_1, a_2)\) for every \(a_2 \in A_2\).

The definition is a consistency condition on a proposed profile. It does not say how the players arrive at the profile, and it does not say that the profile is the best one for them. Example 2.3 shows that an equilibrium need not be the best profile for the players, and Proposition 3.2 shows that a game can have no pure equilibrium.

Remark 1.4 (the registry entry)

The registry entry for the equilibrium concept of Definition 1.3 is nash1950equilibrium, a 1950 paper titled "Equilibrium points in n-person games". This lesson attributes no result to that paper. The definition and every result below are proved on this page or read from Lab 1.

Remark 1.5 (the Cournot equilibrium is a Nash equilibrium)

Let the quantity game have action sets equal to the output levels of two firms, and let each firm's payoff be its profit. Then a pure Nash equilibrium of this game is a pair of outputs, each of which is a best response to the other. Each such pair is a Cournot equilibrium, the Cournot competition concept of E1, written as a game. This follows from Definition 1.3 with profits as payoffs.

2Strict dominance and the prisoner's dilemma

Definition 2.1 (strictly dominant action)

Action \(d_1 \in A_1\) is a strictly dominant action for player 1 when \(u_1(d_1, a_2) > u_1(a_1, a_2)\) for every \(a_2 \in A_2\) and every \(a_1 \in A_1\) with \(a_1 \ne d_1\). The strictly dominant action for player 2 is defined in the same way with the roles of the players exchanged.

Proposition 2.2 (a strictly dominant profile is the only pure equilibrium)

Assumption 1. Each action set is nonempty, and each payoff is a real number.

Assumption 2. Players choose simultaneously and in pure actions, and each player's payoff is its objective.

Assumption 3. Each player takes the other player's action as given when it chooses its own.

Under Assumptions 1 to 3, suppose \(d_1\) is strictly dominant for player 1 and \(d_2\) is strictly dominant for player 2. Then \((d_1, d_2)\) is a pure Nash equilibrium, and it is the only pure Nash equilibrium of the game.

Proof

First, \((d_1, d_2)\) is an equilibrium. Take any \(a_1 \in A_1\) with \(a_1 \ne d_1\). Definition 2.1 with \(a_2 = d_2\) gives \(u_1(d_1, d_2) > u_1(a_1, d_2)\). So \(u_1(d_1, d_2) \ge u_1(a_1, d_2)\) holds for every \(a_1\), which is the first condition of Definition 1.3. The same argument for player 2 gives the second condition.

Second, no other profile is an equilibrium. Let \((a_1, a_2)\) be a pure equilibrium and suppose \(a_1 \ne d_1\). Definition 2.1 with the opponent's action \(a_2\) gives \(u_1(d_1, a_2) > u_1(a_1, a_2)\). So \(a_1\) is not a best response to \(a_2\), which contradicts Definition 1.3. Hence \(a_1 = d_1\). The same argument gives \(a_2 = d_2\). \(\blacksquare\)

Example 2.3 (the prisoner's dilemma)

Let \(A_1 = A_2 = \{C, D\}\) with payoffs \(u_1(C, C) = u_2(C, C) = 3\), \(u_1(C, D) = u_2(D, C) = 0\), \(u_1(D, C) = u_2(C, D) = 5\), and \(u_1(D, D) = u_2(D, D) = 1\). Action \(D\) is strictly dominant for player 1, because \(u_1(D, C) = 5 > 3 = u_1(C, C)\) and \(u_1(D, D) = 1 > 0 = u_1(C, D)\). The same comparisons with the roles exchanged show that \(D\) is strictly dominant for player 2. Proposition 2.2 gives \((D, D)\) as the only pure equilibrium. Both players receive 1 there, while \((C, C)\) gives each player 3. So \((C, C)\) gives both players more than \((D, D)\), and the equilibrium is not Pareto efficient: the profile \((C, C)\) makes both players better off than \((D, D)\) does.

The first block of Lab 1 prints the equilibrium set of this game and its strictly dominant row action.

3A game with no pure equilibrium

Example 3.1 (matching pennies)

Let \(A_1 = A_2 = \{\text{Heads}, \text{Tails}\}\), let \(u_1(a_1, a_2) = 1\) when \(a_1 = a_2\) and \(-1\) otherwise, and let \(u_2 = -u_1\). Player 1 wins when the actions match, and player 2 wins when they differ.

Proposition 3.2 (matching pennies has no pure equilibrium)

Assumption 1. The payoffs of Example 3.1 are the players' objectives, and each player takes the other's action as given (Assumptions 2 and 3 of Proposition 2.2).

Under Assumption 1, the game of Example 3.1 has no pure Nash equilibrium.

Proof

Take any profile. If the actions match, player 2 receives \(-1\), and changing its own action makes them differ, which gives player 2 the payoff \(+1 > -1\). So player 2 is not best responding. If the actions differ, player 1 receives \(-1\), and changing its own action makes them match, which gives player 1 the payoff \(+1 > -1\). So player 1 is not best responding. Every profile therefore fails Definition 1.3. \(\blacksquare\)

Remark 3.3 (what the proposition does not say)

Proposition 3.2 is a statement about pure actions only. This lesson does not claim that a mixed equilibrium exists in Example 3.1, and it does not use an existence theorem anywhere. The empty list that Lab 1 prints for this game is a statement about the four pure profiles.

4A quantity game on an integer grid

Example 4.1 (a two-firm quantity game)

Each firm chooses an output \(q_i\) in units, where \(q_i\) is a real number in \([0, 90]\). The price in cents per unit is \(\max(0, 100 - q_1 - q_2)\), and each unit costs 10 cents to make. Firm \(i\)'s profit in cents is \(\pi_i = q_i\bigl(\max(0, 100 - q_1 - q_2) - 10\bigr)\). Profits are integers when both outputs are integers. For real outputs they need not be whole cents: for \(q_1 = 1/2\) and \(q_2 = 30\), the price is \(139/2\) cents and the profit is \(119/4\) cents.

Proposition 4.2 (the symmetric pair (30, 30) is an equilibrium)

Assumption 1. The game of Example 4.1 is played in pure outputs, with the two firms choosing at the same time and each firm taking the other's output as given.

Assumption 2. The outputs are real numbers in \([0, 90]\), and the profit formula of Example 4.1 applies to every pair of outputs.

Under Assumptions 1 and 2, the profile \((30, 30)\) is a pure Nash equilibrium of the game of Example 4.1.

Proof

Fix firm 2 at \(q_2 = 30\), and let \(q_1 \in [0, 90]\) be any output for firm 1. Split the range into two cases.

Case 1, \(0 \le q_1 \le 70\). The price is \(100 - q_1 - 30 = 70 - q_1\), which is at least 0, so \(\pi_1 = q_1\bigl((70 - q_1) - 10\bigr) = q_1(60 - q_1)\). Then \(900 - \pi_1 = 900 - 60 q_1 + q_1^2 = (q_1 - 30)^2 \ge 0\), so \(\pi_1 \le 900\) with equality only at \(q_1 = 30\).

Case 2, \(70 < q_1 \le 90\). The price is 0, so \(\pi_1 = -10 q_1 < -700 < 900\).

In both cases \(\pi_1\) is at most \(\pi_1(30) = 30 \times 30 = 900\), so \(30\) is a best response to \(30\). The payoff function of firm 2 is the same with the roles exchanged, so \(30\) is also firm 2's best response to \(30\). Definition 1.3 then gives the equilibrium. \(\blacksquare\)

Example 4.3 (ties on the grid)

Restrict the outputs to the whole numbers 0 to 90. Let firm 2 produce 31 units. Then the price is \(100 - q_1 - 31 = 69 - q_1\), and firm 1's profit is \(q_1(59 - q_1)\). At \(q_1 = 29\) the profit is \(29 \times 30 = 870\), and at \(q_1 = 30\) it is \(30 \times 29 = 870\). The two outputs tie, so both are best responses to 31 when ties are allowed. Symmetrically, against 29 firm 2's profit \(q_2(61 - q_2)\) gives 930 at both \(q_2 = 30\) and \(q_2 = 31\). The pairs \((29, 31)\) and \((31, 29)\) therefore pass the tie-allowed test, and they fail the strict test, in which a best response must beat every other grid output.

Lab 1 runs both tests on the grid, and its Cournot lines print the results of each.

Lab 1 · Pure equilibria by exhaustive best-response checks

Predicted before running. The prisoner's dilemma of Example 2.3 has one pure equilibrium, \((D, D)\). Matching pennies has none, by Proposition 3.2. The three-action coordination game, whose profits are 4, 2 and 1 on the diagonal and 0 elsewhere, has the three diagonal profiles, because no player gains by moving to another action when the other player stays on the diagonal. On the Cournot grid of Example 4.1 the symmetric pair \((30, 30)\) is an equilibrium by Proposition 4.2. The tie-allowed test also admits \((29, 31)\) and \((31, 29)\), by Example 4.3, and the strict test admits only \((30, 30)\). The enumeration counts 4, 4, 9 and 8281 profiles, and the lab reports each count.

"""E2 lab L01: pure-strategy Nash equilibria of finite two-player games, by exhaustive best-response checks.

Standard library only. No randomness and no network: every profile of every game is enumerated, so the
output is the same on every run. Games 1 to 3 have integer payoffs in abstract payoff units. The Cournot
part has profits in integer cents. A profile is a pure-strategy Nash equilibrium when neither player can
raise its own payoff by changing only its own action. The check compares each payoff with every
action of that player, the one played included, so each printed set is exact for the game listed. The enumeration
covers only the listed games and the listed quantity grid; it says nothing about other games.
"""

from __future__ import annotations

from collections.abc import Sequence

Payoffs = dict[tuple[int, int], tuple[int, int]]


def equilibria(rows: Sequence[str], cols: Sequence[str], payoff: Payoffs) -> list[tuple[str, str]]:
    """Pure-strategy Nash equilibria: profiles where each action is a best response to the other."""
    found: list[tuple[str, str]] = []
    for i, row in enumerate(rows):
        for j, col in enumerate(cols):
            u1, u2 = payoff[(i, j)]
            row_best = all(payoff[(k, j)][0] <= u1 for k in range(len(rows)))
            col_best = all(payoff[(i, k)][1] <= u2 for k in range(len(cols)))
            if row_best and col_best:
                found.append((row, col))
    return found


def strictly_dominant_row(rows: Sequence[str], cols: Sequence[str], payoff: Payoffs) -> str | None:
    """The row action that beats every other row action against every column, or None if there is none."""
    for i, row in enumerate(rows):
        beats_all = all(
            payoff[(i, j)][0] > payoff[(k, j)][0] for k in range(len(rows)) if k != i for j in range(len(cols))
        )
        if beats_all:
            return row
    return None


def cournot_profit(own: int, rival: int) -> int:
    """Profit in cents of a firm that sells own units when the rival sells rival units.

    Price is max(0, 100 - (own + rival)) cents per unit and marginal cost is 10 cents per unit.
    """
    price = max(0, 100 - (own + rival))
    return own * (price - 10)


def cournot_equilibria(grid: Sequence[int], strict: bool) -> list[tuple[int, int]]:
    """Quantity pairs on the grid where each firm's profit is maximal against the other firm's quantity.

    With strict False a best response may tie with another grid quantity. With strict True it must beat
    every other grid quantity, so a tie is not a best response.
    """
    found: list[tuple[int, int]] = []
    for q1 in grid:
        for q2 in grid:
            p1 = cournot_profit(q1, q2)
            p2 = cournot_profit(q2, q1)
            row_ok = all(cournot_profit(k, q2) < p1 if strict else cournot_profit(k, q2) <= p1 for k in grid if k != q1)
            col_ok = all(cournot_profit(k, q1) < p2 if strict else cournot_profit(k, q1) <= p2 for k in grid if k != q2)
            if row_ok and col_ok:
                found.append((q1, q2))
    return found


def main() -> None:
    prisoners: Payoffs = {(0, 0): (3, 3), (0, 1): (0, 5), (1, 0): (5, 0), (1, 1): (1, 1)}
    pennies: Payoffs = {(0, 0): (1, -1), (0, 1): (-1, 1), (1, 0): (-1, 1), (1, 1): (1, -1)}
    diagonal = (4, 2, 1)
    coordination: Payoffs = {
        (i, j): ((diagonal[i], diagonal[i]) if i == j else (0, 0)) for i in range(3) for j in range(3)
    }
    games = [
        ("1 prisoner's dilemma", ["C", "D"], ["C", "D"], prisoners),
        ("2 matching pennies", ["Heads", "Tails"], ["Heads", "Tails"], pennies),
        ("3 coordination on three actions", ["a", "b", "c"], ["a", "b", "c"], coordination),
    ]
    for label, rows, cols, payoff in games:
        print(f"game {label}: profiles checked {len(rows) * len(cols)}")
        print(f"pure equilibria: {equilibria(rows, cols, payoff)}")
        dominant = strictly_dominant_row(rows, cols, payoff)
        print(f"strictly dominant row action: {dominant if dominant is not None else 'none'}")

    grid = list(range(91))
    found = cournot_equilibria(grid, strict=False)
    print(f"cournot grid 0 to 90 units: quantity pairs checked {len(grid) * len(grid)}")
    print(f"cournot equilibria on the grid, ties allowed: {found}")
    print(f"profit in cents at each: {[(cournot_profit(a, b), cournot_profit(b, a)) for a, b in found]}")
    print(f"cournot equilibria on the grid, strict best responses: {cournot_equilibria(grid, strict=True)}")

5Where the canon breaks

The definition above is the standard one for pure actions, and the results in Sections 2 to 4 hold under its assumptions. Four limits matter for the rest of the unit.

  • An equilibrium is not a prediction of a unique outcome. Lab 1 prints three equilibria for the coordination game. The definition does not choose among them, and the lessons that follow use the equilibrium concept, and some of them, such as the auction in L02, do not claim uniqueness. L03 shows that a pricing rule can leave several consistent prices.
  • Pure equilibria may not exist. Proposition 3.2 gives a finite game with none. This lesson does not claim that a mixed equilibrium exists in that game, because it proves no existence result.
  • Ties matter. Example 4.3 shows that the weak and strict best-response definitions give different equilibrium sets on the same grid. A result stated with one definition does not carry over to the other without a check.
  • Simultaneous choice is an assumption. Assumption 2 of Proposition 2.2 fixes the timing. Sequential games, in which one player observes the other's action, can change the set of profiles that are stable, and they are not treated here.

6Misconceptions

  1. “A Nash equilibrium is the outcome that is best for the players.”

    In Example 2.3, \((D, D)\) is the unique pure equilibrium, and both players receive 1 there. The profile \((C, C)\) gives each player 3, so it is better for both. Lab 1 prints \((D, D)\) for the prisoner's dilemma and does not compare payoffs across profiles, because the definition does not ask for that comparison.

  2. “Every finite game has a pure Nash equilibrium.”

    Proposition 3.2 gives a finite game in which no pure profile passes Definition 1.3. Lab 1 prints the empty list for matching pennies. The lab checks four profiles, and the claim is about those four profiles, so the misconception is refuted by one example.

  3. “A profile is an equilibrium when no player gains from a nearby change.”

    Definition 1.3 compares each payoff with every alternative action. Take a game in which player 2 has one action, so player 2 cannot deviate, and player 1 has actions 1, 2 and 3 with payoffs 5, 3 and 6. Action 1 is the current action. A change to the neighboring action 2 does not pay, since \(3 < 5\), but a change to action 3 gives \(6 > 5\), so the profile \((1, \cdot)\) is not an equilibrium. The lab compares each payoff with every action of that player, which is why its results are complete for the game it lists.

7Problem set

Attempt each problem before opening its solution. Problems marked E use the output of Lab 1.

Mechanics

M1 · Pure equilibria of a 2 by 2 game

Players 1 and 2 each choose A or B. Payoffs \((u_1, u_2)\) are \((2, 1)\) at \((A, A)\), \((0, 0)\) at \((A, B)\) and \((B, A)\), and \((1, 2)\) at \((B, B)\). Find every pure Nash equilibrium.

Solution

At \((A, A)\): \(u_1(A, A) = 2 \ge u_1(B, A) = 0\), and \(u_2(A, A) = 1 \ge u_2(A, B) = 0\). Both conditions hold, so \((A, A)\) is an equilibrium. At \((B, B)\): \(u_1(B, B) = 1 \ge u_1(A, B) = 0\), and \(u_2(B, B) = 2 \ge u_2(B, A) = 0\). So \((B, B)\) is also an equilibrium. At \((A, B)\), player 1 gets 0 against 1 from switching to B, so it fails. At \((B, A)\), player 2 gets 0 and would get 2 by switching to B, so it fails. The equilibria are \((A, A)\) and \((B, B)\).

M2 · Strict dominance

Player 1 chooses S or X and player 2 chooses L or R. Payoffs to player 1 are 4 at \((S, L)\), 3 at \((S, R)\), 3 at \((X, L)\) and 2 at \((X, R)\). Is S strictly dominant for player 1? Is X?

Solution

Definition 2.1 asks for \(u_1(S, a_2) > u_1(X, a_2)\) for each \(a_2\). Against L, \(4 > 3\). Against R, \(3 > 2\). So S is strictly dominant. X is not: Definition 2.1 needs \(u_1(X, a_2) > u_1(S, a_2)\) for each \(a_2\), and against L the comparison is \(3 < 4\), so X is not strictly dominant.

M3 · Counting profiles and comparisons

A game has 3 actions for player 1 and 4 for player 2. How many pure profiles are there, and how many single payoff comparisons does a check against every alternative action make for each profile?

Solution

There are \(3 \times 4 = 12\) pure profiles. At a given profile, player 1 compares its payoff with the 2 other actions, and player 2 compares its payoff with the 3 other actions, so each profile needs \(2 + 3 = 5\) comparisons. The total is \(12 \times 5 = 60\). Lab 1's code counts differently: it compares each payoff with every action of that player, including the one played, and it stops a check at the first action that does better. So a profile in a 3 by 4 game takes at most \(3 + 4 = 7\) comparisons, and fewer when a check fails early.

Proof

P1 · The best response to a strictly dominant action

Let \(d_1\) be strictly dominant for player 1 under Definition 2.1. Show that for each \(a_2 \in A_2\), the action \(d_1\) is the unique best response to \(a_2\).

Solution

Fix \(a_2\). Definition 2.1 gives \(u_1(d_1, a_2) > u_1(a_1, a_2)\) for every \(a_1 \ne d_1\). So \(d_1\) is a best response to \(a_2\), since it is at least as good as every action, by Definition 1.2. No other action is a best response, because each \(a_1 \ne d_1\) earns strictly less than \(d_1\) against \(a_2\). The best response is therefore unique.

P2 · A common-payoff game has a pure equilibrium

Let \(A_1\) and \(A_2\) be finite and nonempty, and let \(u_1 = u_2 = u\). Show that there is a pure Nash equilibrium.

Solution

A finite nonempty set of profiles has a profile \((a_1^\circ, a_2^\circ)\) at which \(u\) is largest. For any \(a_1\), \(u_1(a_1, a_2^\circ) = u(a_1, a_2^\circ) \le u(a_1^\circ, a_2^\circ) = u_1(a_1^\circ, a_2^\circ)\), so \(a_1^\circ\) is a best response to \(a_2^\circ\). The same argument with the roles exchanged shows that \(a_2^\circ\) is a best response to \(a_1^\circ\). By Definition 1.3 the profile is an equilibrium.

P3 · The profit at a deviation on the grid

In Example 4.1, show that firm 1 earns less than 900 cents by producing 31 units when firm 2 produces 30 units.

Solution

The price is \(100 - 31 - 30 = 39\) cents per unit, so the profit is \(31 \times (39 - 10) = 31 \times 29 = 899\) cents. Since \(899 < 900\), the deviation does not pay. The value agrees with the formula \(q_1(60 - q_1)\) from Case 1 of the proof of Proposition 4.2, since \(31 \times 29 = 899\) again.

Empirical

E1 · Where the extra grid pairs come from

Lab 1 prints three grid equilibria with ties allowed and one with strict best responses. Explain which profit values produce the two extra pairs.

Solution

Against 31, firm 1's profit is \(q_1(59 - q_1)\), which equals 870 at both 29 and 30. Against 29, firm 2's profit is \(q_2(61 - q_2)\), which equals 930 at both 30 and 31. Each tie makes one of the two outputs a best response under the tie-allowed test, which gives \((29, 31)\) and \((31, 29)\). Under the strict test neither tie qualifies, so only \((30, 30)\) remains. The printed profits \((870, 930)\) and \((930, 870)\) match these values.

E2 · What the coordination output does not rank

Lab 1 prints the three diagonal profiles of the coordination game as equilibria. Does the printed output say which of them the players prefer?

Solution

No. The output lists the set of equilibria and nothing else. The diagonal payoffs are 4, 2 and 1 for each player, so \((a, a)\) gives 4 each and \((c, c)\) gives 1 each, but the enumeration does not compare them, and Definition 1.3 does not require a comparison. The ranking is a separate fact that the lab does not print.

E3 · What an empty list establishes

Lab 1 prints an empty list of pure equilibria for matching pennies. What does that output establish, and what does it leave open?

Solution

It establishes that none of the four pure profiles passes Definition 1.3, which agrees with Proposition 3.2. It does not establish whether a mixed equilibrium exists, because the lab does not enumerate mixed strategies. It also does not establish anything about a game with more actions, since the enumeration covers only this one.

Research

R1 · Choosing the best-response definition

A model author proposes that a profile counts as an equilibrium only when every best response is strict. Explain what that choice changes on the Cournot grid, and say which of Proposition 4.2's claims it affects.

Solution

On the grid, the strict test removes \((29, 31)\) and \((31, 29)\), as Example 4.3 shows, and keeps \((30, 30)\). Proposition 4.2 is a statement that \((30, 30)\) is an equilibrium, and its proof shows that 30 is the strict best response to 30: in Case 1, \(900 - \pi_1 = (q_1 - 30)^2\) is positive for every \(q_1 \ne 30\), and in Case 2 the profit is below 900. So the proposition holds under the strict test as well. The strict definition changes the grid result and leaves Proposition 4.2 unchanged.

R2 · What dominance does not guard against

Proposition 2.2 predicts a unique equilibrium when each player has a strictly dominant action. Name one reason a practitioner would still doubt that prediction, and say what the proposition does and does not show about it.

Solution

The proposition relies on the payoffs being the players' true objectives, which is Assumption 2 of Proposition 2.2. If the modeler has the payoffs wrong, the dominance comparisons are about the wrong game, and the predicted profile can differ from behavior. The proposition shows that the predicted profile is the only pure equilibrium of the modelled game. It does not show that the model describes the players.

R3 · How the comparison count grows

For a game with \(m\) actions for player 1 and \(n\) actions for player 2, find the number of pure profiles and the number of single payoff comparisons that a check against every alternative action makes. Explain why the second number matters for a large game.

Solution

There are \(mn\) profiles. At each one, player 1 makes \(m - 1\) comparisons and player 2 makes \(n - 1\), so the total is \(mn(m + n - 2)\). With \(m = 3\) and \(n = 4\), this gives \(12 \times 5 = 60\), which agrees with Problem M3. Lab 1's code also compares each payoff with the action played, so its checks make at most \(mn(m + n)\) comparisons, which is \(12 \times 7 = 84\) for this game, and fewer when a check fails early. For large \(m\) and \(n\) both counts are asymptotically \(mn(m + n)\), so an exhaustive check of a game with many actions costs far more than a check of a small one, and an analytic argument such as Proposition 2.2 can avoid the enumeration when its hypotheses hold.

  1. Which condition defines a pure Nash equilibrium of a two-player game?

    \(3 \times 4 = 12\) profiles, one for each pair of actions.

  4. What does Proposition 3.2 say about matching pennies?

    Options

    At a matching profile player 2 gains by mismatching, and at a mismatched profile player 1 gains by matching, so no profile passes Definition 1.3.

  5. In Example 4.1, what is each firm's profit in cents at the symmetric pair (30, 30)?

    The price is \(100 - 60 = 40\) cents, so the profit is \(30 \times (40 - 10) = 900\) cents.

  6. Which statement matches Definition 2.1 of a strictly dominant action?

    Options

    Definition 2.1 needs a strict inequality against every other action and every opponent action.
