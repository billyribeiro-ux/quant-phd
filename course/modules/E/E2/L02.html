Bayesian Games and Bayesian–Nash Equilibrium

  • Uses: Nash equilibrium (L01), expectation, independence and conditional expectation (M4)
  • Introduces: Bayesian–Nash equilibrium
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study or lab result
  • Dlore
  • Xrefuted

In many games a player does not know the others' payoffs or information. Adverse selection, signaling and auctions all depend on that gap. The model studied here gives each player a private type and a common prior over the types, and it asks that each type choose a best response to its expected payoff, given its own type. This lesson defines the object, proves that a symmetric first-price auction with independent uniform values has a symmetric equilibrium, and checks the closed-form bid exactly on a grid in Lab 2.

1Bayesian games and strategies

Definition 1.1 (two-player Bayesian game)

A Bayesian game has, for each player \(i\), a finite nonempty set of types \(\Theta_i\) and a nonempty action set \(A_i\). It has a prior probability \(p\) over the type profiles \((\theta_1, \theta_2) \in \Theta_1 \times \Theta_2\), and payoff functions \(u_i(a_1, a_2, \theta_1, \theta_2)\). Player \(i\) knows its own type \(\theta_i\) and does not know the other player's type. The prior and the payoff functions are common knowledge: every player knows them, knows that the others know them, and so on.

Write \(\Theta_{-i}\) for the set of types of the other player. Type sets are always written \(\Theta_i\), so the letter \(T\) never stands for a type set in this lesson.

Definition 1.2 (pure strategy and interim expected payoff)

A pure strategy of player \(i\) is a function \(\sigma_i : \Theta_i \to A_i\), which gives the action taken by each type. Given the other player's strategy \(\sigma_{-i}\), the interim expected payoff of action \(a_i\) for type \(\theta_i\) is

\[U_i(a_i \mid \theta_i, \sigma_{-i}) = \E\bigl[u_i\bigl(a_i, \sigma_{-i}(\Theta_{-i}), \theta_i, \Theta_{-i}\bigr) \,\big|\, \Theta_i = \theta_i\bigr].\]

The conditional expectation averages over the other player's type, using the prior conditioned on \(\theta_i\). In plain words, the type updates its belief about the other type by Bayes' rule, and then takes the expectation of the payoff under the updated belief.

Definition 1.3 (Bayesian–Nash equilibrium)

A profile of pure strategies \((\sigma_1, \sigma_2)\) is a Bayesian–Nash equilibrium when, for each player \(i\) and each type \(\theta_i\) that has positive prior probability, the action \(\sigma_i(\theta_i)\) maximizes \(U_i(a_i \mid \theta_i, \sigma_{-i})\) over \(a_i \in A_i\).

Proposition 1.4 (one type per player gives Definition 1.3 of L01)

Assumption 1. Each set of types \(\Theta_i\) has exactly one element, so the prior puts probability 1 on a single type profile.

Under Assumption 1, a profile of pure strategies is a Bayesian–Nash equilibrium if and only if it is a pure Nash equilibrium of the game with payoffs \(u_i(a_1, a_2)\).

Proof

Under Assumption 1 the conditional distribution of the other type given \(\theta_i\) puts probability 1 on the one other type, so \(U_i(a_i \mid \theta_i, \sigma_{-i}) = u_i(a_i, \sigma_{-i}(\theta_{-i}))\). Each type's condition in Definition 1.3 then reads: \(\sigma_i(\theta_i)\) maximizes \(a_i \mapsto u_i(a_i, \sigma_{-i}(\theta_{-i}))\). That is the best-response condition of Definition 1.2 in L01, applied to the single profile, so the two definitions agree. \(\blacksquare\)

Proposition 1.4 is the bridge from L01. It shows that, with one type per player, the new definition reduces to the old one. The rest of the lesson concerns games with a continuum of types.

2A first-price auction with private values

Example 2.1 (the single-unit first-price auction)

There are \(n\) bidders, \(n \ge 2\). Bidder \(i\) has a value \(V_i\) for one unit, and submits a bid \(b_i \ge 0\). The highest bid wins and pays its own bid. Bidder \(i\) earns \(V_i - b_i\) if it wins and 0 otherwise. Bids are in units of value, so the payoff is a difference of two values and is in the same units.

The auction is a Bayesian game in which each bidder's type is its value. The values are continuous, so the game is not a finite Bayesian game. Definitions 1.2 and 1.3 still apply, with the sums over types replaced by integrals over the value distribution. The proof below states each integral it uses.

Proposition 2.2 (the symmetric bid is an equilibrium)

Assumption 1. Bidders are risk neutral: each maximizes the expected value of its payoff.

Assumption 2. Values are independent, and each \(V_i\) is uniform on \([0, 1]\). Each bidder knows its own value and the distribution of the others' values.

Assumption 3. Every bidder uses the same strategy \(b(\cdot)\), so that bidder \(i\) bids \(b(V_i)\). Only the symmetric profile is considered.

Assumption 4. Each bidder wants one unit, and the probability that two bids are equal is 0.

Let \(n \ge 2\) and \(\beta = (n - 1)/n\). Under Assumptions 1 to 4, the strategy \(b(v) = \beta v\) is a Bayesian–Nash equilibrium of the auction. The proof does not claim that it is the only one.

Proof

Step 1, the win probability. Suppose bidder \(i\) bids \(b\) and each of the other \(n - 1\) bidders uses \(b(V_j) = \beta V_j\). Bidder \(i\) wins exactly when \(\beta V_j < b\) for every \(j \ne i\), by Assumption 4 with ties ignored. If \(0 \le b \le \beta\), this is the event \(V_j < b/\beta\) for every \(j\), and by Assumption 2 and the independence of the values, its probability is \((b/\beta)^{n-1}\). If \(b \ge \beta\), every \(\beta V_j\) is at most \(\beta \le b\), so the probability is 1. Write \(W(b)\) for this probability, so that \(W(b) = (b/\beta)^{n-1}\) on \([0, \beta]\) and \(W(b) = 1\) on \([\beta, \infty)\). The two formulas agree at \(b = \beta\).

Step 2, the payoff. By Assumption 1, a bidder with value \(v\) who bids \(b\) earns in expectation \(f_v(b) = (v - b)\,W(b)\).

Step 3, the maximum on \([0, \beta]\). For \(0 < b < \beta\), \(f_v(b) = (v - b)\,b^{n-1}/\beta^{n-1}\). Differentiating the product gives

\[f_v'(b) = \frac{1}{\beta^{n-1}}\Bigl(-b^{n-1} + (n-1)(v - b)\,b^{n-2}\Bigr) = \frac{b^{n-2}}{\beta^{n-1}}\bigl((n-1)v - n\,b\bigr).\]

Since \(b^{n-2} > 0\) for \(b > 0\), the sign of \(f_v'\) is the sign of \((n-1)v - nb\). That is positive for \(b < b^\ast_v\) and negative for \(b > b^\ast_v\), where \(b^\ast_v = (n-1)v/n = \beta v\). For \(v \in [0, 1]\), \(b^\ast_v \in [0, \beta]\). So \(f_v\) rises up to \(\beta v\) and falls after it on \([0, \beta]\), and \(\beta v\) is its maximum there.

Step 4, bids above \(\beta\). For \(b \ge \beta\), \(f_v(b) = v - b\), which is less than \(v - \beta = f_v(\beta)\). Since \(f_v(\beta) \le f_v(\beta v)\) by Step 3, no bid above \(\beta\) does better than \(\beta v\).

Step 5, conclusion. By Steps 3 and 4, \(\beta v\) maximizes the interim expected payoff \(f_v\) over all bids \(b \ge 0\), for every value \(v\) in \([0, 1]\). Since the other bidders use the same symmetric strategy, the profile is a Bayesian–Nash equilibrium by Definition 1.3. \(\blacksquare\)

Example 2.3 (two bidders)

For \(n = 2\), \(\beta = 1/2\), so the equilibrium bid is \(v/2\). A bidder with value \(0.8\) bids \(0.4\) and wins with probability \(W(0.4) = (0.4/0.5)^1 = 0.8\), so its expected payoff is \((0.8 - 0.4) \times 0.8 = 0.32\). Bidding its value, \(0.8\), wins with probability 1 and earns \(0.8 - 0.8 = 0\). At this value the equilibrium bid earns more than the value bid, so bidding the value is not a best response here.

Remark 2.4 (the equilibrium payoff)

At the equilibrium bid \(b = \beta v\), the win probability is \(W(\beta v) = (\beta v / \beta)^{n-1} = v^{n-1}\), so the expected payoff is \((v - \beta v)\,v^{n-1} = (1 - \beta)\,v \cdot v^{n-1} = v^n / n\), because \(1 - \beta = 1/n\). For \(n = 2\) and \(v = 0.8\) this is \(0.8^2/2 = 0.32\), which agrees with Example 2.3.

Proposition 2.5 (first-price revenue and the second-highest value)

Let \(n \ge 2\), and let the bidders follow the equilibrium of Proposition 2.2. Under Assumptions 1 to 4 of Proposition 2.2, the expected winning bid, which is the seller's expected revenue, is \((n - 1)/(n + 1)\). The mean of the second-highest of \(n\) independent uniform values on \([0, 1]\) is also \((n - 1)/(n + 1)\).

Proof

The highest of \(n\) independent uniform values has distribution function \(x^n\), so its density is \(n x^{n-1}\) on \([0, 1]\). Since \(b(v) = \beta v\) is strictly increasing, the highest bid belongs to the highest value, and ties have probability 0 by Assumption 4, so the winner is the bidder with the highest value. It pays \(\beta\) times that value. So the expected payment is \(\beta \int_0^1 x \cdot n x^{n-1}\,dx = \beta n \int_0^1 x^n\,dx = (n-1)/(n+1)\), since \(\beta n = n - 1\) and \(\int_0^1 x^n\,dx = 1/(n+1)\).

For the second-highest value, the probability that it is at most \(x\) is the probability that at most one value exceeds \(x\), namely \(x^n + n(1-x)x^{n-1}\). Differentiating gives the density \(n(n-1)x^{n-2}(1-x)\) on \([0, 1]\). Its integral is \(n(n-1)\bigl(\tfrac{1}{n-1} - \tfrac{1}{n}\bigr) = 1\), so it is a density. Its mean is \(n(n-1)\int_0^1 x^{n-1}(1 - x)\,dx = n(n-1)\bigl(\tfrac{1}{n} - \tfrac{1}{n+1}\bigr) = \tfrac{n-1}{n+1}\). \(\blacksquare\)

Proposition 2.5 computes the first-price payment and the mean of the second-highest value. It does not claim that the second-highest mean is a second-price revenue, because that identity needs a proof about the second-price rule, which this lesson does not give.

3Checking the bid on an exact grid

Lab 2 tests the closed-form bid against a grid of bids and integrates both revenue expressions exactly, with rational arithmetic.

Lab 2 · The closed-form bid on an exact bid grid

Predicted before running. For each \(n\) from 2 to 5 and each of the 21 values \(k/20\), the closed-form bid \(\beta v\) earns at least as much as each of the 1201 grid bids, so each count printed is 21 of 21. Proposition 2.5 gives the first-price revenue \((n-1)/(n+1)\), which is \(1/3\), \(1/2\), \(3/5\) and \(2/3\) for \(n = 2, 3, 4, 5\). The mean of the second-highest value is the same number, and the density integrates to 1, so the printed line for each \(n\) should read equal True and density mass 1.

"""E2 lab L02: symmetric first-price auction. The closed-form bid is checked on an exact bid grid.

Standard library only: exact rational arithmetic with fractions.Fraction. No randomness and no network.
Model: n bidders, n from 2 to 5. Each bidder's value is an independent draw from the uniform distribution
on [0, 1], and every other bidder uses the symmetric bid beta * value, with beta = (n - 1) / n. A bidder
with value v who bids b earns (v - b) times the probability that b is the highest bid. That probability is
(b / beta) ** (n - 1) for 0 <= b <= beta, because the other n - 1 bids are below b exactly when their values
are below b / beta, and it is 1 for b >= beta.

The lab tests the closed-form bid beta * v against every bid j / 1200 for j = 0 to 1200, on values k / 20
for k = 0 to 20. A check passes when the closed-form bid earns at least as much as every grid bid. The lab
also integrates exactly, term by term, the first-price revenue and the mean of the second-highest
value, for n from 2 to 5.
A grid check is a finite test of deviations on one grid. It is not a proof, and the page states the proof.
"""

from __future__ import annotations

from fractions import Fraction

GRID_STEPS = 1200
VALUE_STEPS = 20


def beta(n: int) -> Fraction:
    """The symmetric bid multiplier (n - 1) / n."""
    return Fraction(n - 1, n)


def win_probability(bid: Fraction, n: int) -> Fraction:
    """Probability that bid is the highest of n bids when the other n - 1 bidders use beta times their values."""
    if bid >= beta(n):
        return Fraction(1)
    return (bid / beta(n)) ** (n - 1)


def payoff(value: Fraction, bid: Fraction, n: int) -> Fraction:
    """Expected payoff of bidding bid with the given value, in units of value."""
    return (value - bid) * win_probability(bid, n)


def closed_form_is_grid_best(n: int, value: Fraction) -> bool:
    """True when beta * value earns at least as much as every bid on the grid."""
    closed = beta(n) * value
    closed_payoff = payoff(value, closed, n)
    best_grid = max(payoff(value, Fraction(j, GRID_STEPS), n) for j in range(GRID_STEPS + 1))
    return closed_payoff >= best_grid


def integrate(terms: dict[int, Fraction]) -> Fraction:
    """Exact integral over [0, 1] of the polynomial sum of coefficient * x ** exponent."""
    return sum((c / (e + 1) for e, c in terms.items()), Fraction(0))


def first_price_revenue(n: int) -> Fraction:
    """E[beta * highest value], with highest-value density n x ** (n - 1): beta * n times the integral of x ** n."""
    return integrate({n: Fraction(n - 1)})


def second_highest_mean(n: int) -> Fraction:
    """E[second-highest value], with density n (n - 1) x ** (n - 2) (1 - x)."""
    return integrate({n - 1: Fraction(n * (n - 1)), n: Fraction(-n * (n - 1))})


def second_density_mass(n: int) -> Fraction:
    """Integral of the density n (n - 1) x ** (n - 2) (1 - x) over [0, 1], which must equal 1."""
    return integrate({n - 2: Fraction(n * (n - 1)), n - 1: Fraction(-n * (n - 1))})


def main() -> None:
    print(f"symmetric first-price auction: value grid k/{VALUE_STEPS}, bid grid j/{GRID_STEPS}")
    for n in range(2, 6):
        values = [Fraction(k, VALUE_STEPS) for k in range(VALUE_STEPS + 1)]
        passed = sum(closed_form_is_grid_best(n, v) for v in values)
        print(f"n = {n}, beta = {beta(n)}: closed-form bid best on the grid for {passed} of {len(values)} values")
    for n in range(2, 6):
        first = first_price_revenue(n)
        second = second_highest_mean(n)
        print(
            f"n = {n}: first-price revenue {first}, mean second-highest value {second}, "
            f"equal {first == second}, density mass {second_density_mass(n)}"
        )


main()

n = 2, beta = 1/2: closed-form bid best on the grid for 21 of 21 values
n = 3, beta = 2/3: closed-form bid best on the grid for 21 of 21 values
n = 4, beta = 3/4: closed-form bid best on the grid for 21 of 21 values
n = 5, beta = 4/5: closed-form bid best on the grid for 21 of 21 values

The first four lines count, for each \(n\), the values at which the closed-form bid is a best grid bid, using exact fractions. A count of 21 of 21 says that no grid bid beats \(\beta v\) on these values, which is what Steps 3 and 4 of Proposition 2.2 predict. It does not prove that the bid is optimal for every value and every bid, because the grid is finite. The proof does that. The last four lines confirm Proposition 2.5 for \(n = 2\) to 5, and they say nothing about \(n\) above 5. 4Where the canon breaks

Proposition 2.2 rests on four assumptions. The bullets below cover the choice of the symmetric strategy (Assumption 3), private values and the known distribution (Assumption 2), and risk neutrality (Assumption 1). Assumption 4, which excludes ties, is not discussed here.

  • The proof does not establish uniqueness. The proof shows that \(\beta v\) is an equilibrium. It does not show uniqueness, and the lesson makes no uniqueness claim.
  • Values are private. Assumption 2 says that each bidder's value is independent of the others'. When the true value is common to all bidders and each bidder sees only a noisy signal of it, the best response changes, and the winner's curse, which L08 defines, enters. That case is treated in L08.
  • Risk neutrality is assumed. Assumption 1 treats the payoff as a difference of values with no concave utility. Risk-averse bidders may bid differently from the risk-neutral bid. This lesson does not compute that case.
  • The distribution is known. Each bidder knows the uniform distribution of the others' values. If beliefs about the others are uncertain, the common prior of Definition 1.1 must be replaced by a richer model, which is not treated here.

5Misconceptions

  1. “In a first-price auction, bidding one's value is the equilibrium.”

    Example 2.3 gives the bidder with value 0.8 and two bidders an expected payoff of 0 from bidding 0.8, and 0.32 from bidding 0.4. Bidding the value wins for sure but leaves nothing to gain, so it is not a best response. The equilibrium bid is \(\beta v\), which is below the value for every positive \(v\) when \(n \ge 2\).

  2. “A Bayesian–Nash equilibrium needs each player to know the other players' realized types.”

    Definition 1.3 conditions only on the player's own type, through the conditional expectation of Definition 1.2. In the auction, a bidder does not know the others' values, and the equilibrium bid uses only its own value and the prior. Conditioning on the realized others' values would give a different and incorrect test, because a bidder cannot condition on information it does not have.

  3. “Lab 2 proves that the closed-form bid is optimal.”

    Lab 2 tests 21 values against 1201 grid bids for each \(n\). Its result is a finite check. Proposition 2.2 covers every value in \([0, 1]\) and every bid in \([0, \infty)\), by the derivative sign in Step 3. The lab is a check of the proof, not a substitute for it.

6Problem set

Attempt each problem before opening its solution. Problems marked E use the output of Lab 2.

Mechanics

M1 · The equilibrium bid and payoff with three bidders

Three bidders with independent uniform values. A bidder has value 0.6. Find the equilibrium bid and the expected payoff of that bid.

Solution

Here \(n = 3\) and \(\beta = 2/3\), so the equilibrium bid is \(\beta \times 0.6 = 0.4\). The win probability is \(W(0.4) = (0.4/(2/3))^2 = 0.6^2 = 0.36\). The expected payoff is \((0.6 - 0.4) \times 0.36 = 0.072\). Remark 2.4 gives the same value as \(v^n/n = 0.6^3/3 = 0.216/3 = 0.072\).

M2 · Value bidding against the equilibrium bid with two bidders

Two bidders with independent uniform values. A bidder has value 0.8. Compare the expected payoff of bidding 0.8 with that of the equilibrium bid.

Solution

Bidding 0.8 wins with probability \(W(0.8) = 1\) because \(0.8 \ge \beta = 1/2\), and earns \(0.8 - 0.8 = 0\). The equilibrium bid is \(0.4\), which wins with probability \(W(0.4) = (0.4/0.5)^1 = 0.8\) and earns \((0.8 - 0.4) \times 0.8 = 0.32\). The equilibrium bid earns 0.32 and the value bid earns 0, so the value bid is not a best response.

M3 · Win probability with five bidders

Five bidders with independent uniform values. A bidder with value 0.5 bids its equilibrium bid. What is that bid, and what is the probability that a bid of 0.4 wins against the other four equilibrium bidders?

Solution

Here \(\beta = 4/5\), so the equilibrium bid is \(0.8 \times 0.5 = 0.4\). A bid of 0.4 wins with probability \(W(0.4) = (0.4/0.8)^4 = 0.5^4 = 1/16\), which is 0.0625. The result follows from Step 1 of Proposition 2.2 with \(n - 1 = 4\) rival bidders.

Proof

P1 · The win probability on the bid range

Under Assumptions 2 to 4 of Proposition 2.2, show that a bid \(b\) in \([0, \beta]\) wins with probability \((b/\beta)^{n-1}\).

Solution

Bidder \(i\) wins when its bid \(b\) exceeds every rival bid \(\beta V_j\). By Assumption 4 ties have probability zero, so this is the event that \(\beta V_j < b\) for each of the \(n - 1\) rivals. That is the event \(V_j < b/\beta\) for each rival. The values are independent by Assumption 2, so the probabilities multiply, and each factor is \(P(V_j < b/\beta) = b/\beta\) because \(b/\beta\) lies in \([0, 1]\). The product is \((b/\beta)^{n-1}\).

P2 · The sign of the derivative

For \(0 < b < \beta\), verify the derivative formula in Step 3 of Proposition 2.2, and state where the derivative is zero.

Solution

Write \(f_v(b) = (v - b)\,b^{n-1}\beta^{-(n-1)}\). The product rule gives \(\frac{d}{db}\bigl[(v - b)b^{n-1}\bigr] = -b^{n-1} + (v - b)(n-1)b^{n-2}\). Factoring out \(b^{n-2}\) gives \(b^{n-2}\bigl[-b + (n-1)(v - b)\bigr] = b^{n-2}\bigl[(n-1)v - nb\bigr]\). Multiplying by \(\beta^{-(n-1)}\) gives the formula. The derivative is zero at \(b = (n-1)v/n = \beta v\), and it is positive below and negative above that point.

P3 · The payoff at the equilibrium bid

Show that the expected payoff of the equilibrium bid \(\beta v\) equals \(v^n/n\).

Solution

At \(b = \beta v\), the win probability is \((\beta v/\beta)^{n-1} = v^{n-1}\), since \(\beta v \le \beta\) for \(v \le 1\). The payoff is \((v - \beta v)\,v^{n-1} = (1 - \beta)\,v^n\). Since \(1 - \beta = 1/n\), this is \(v^n/n\). Remark 2.4 states the same result.

Empirical

E1 · What the grid count does and does not show

Lab 2 prints 21 of 21 for each \(n\). Explain what this count tests, and state one thing it does not test.

Solution

The count tests whether the closed-form bid earns at least as much as each of the 1201 grid bids on each of the 21 values. It does not test bids between grid points, values between grid points, or bids and values outside the listed ranges. Those cases are covered by the proof in Steps 3 and 4 of Proposition 2.2, not by the lab.

E2 · Checking a printed revenue by hand

Lab 2 prints first-price revenue 1/2 for \(n = 3\). Check this value from the formula of Proposition 2.5 without running the code.

Solution

The formula gives \((n-1)/(n+1) = 2/4 = 1/2\) for \(n = 3\), which matches the printed value. The lab's value comes from integrating \((n-1)x^n\) over \([0, 1]\), which for \(n = 3\) is \(2 \times 1/4 = 1/2\).

E3 · The second-highest mean for four bidders

Lab 2 prints a mean second-highest value of 3/5 for \(n = 4\). Show that this matches the density \(n(n-1)x^{n-2}(1-x)\).

Solution

For \(n = 4\) the density is \(12x^2(1-x)\). Its mean is \(12\int_0^1 x^3(1-x)\,dx = 12\bigl(\tfrac14 - \tfrac15\bigr) = 12 \times \tfrac{1}{20} = \tfrac{3}{5}\), which matches the printed value and the formula \((n-1)/(n+1) = 3/5\).

Research

R1 · Values uniform on a larger interval

Suppose each value is uniform on \([0, H]\) for some \(H > 0\), with the other assumptions unchanged. Show that the symmetric bid \(b(v) = \beta v\) is still an equilibrium.

Solution

Let \(V_j = H U_j\) with each \(U_j\) uniform on \([0, 1]\). A rival's bid \(\beta V_j = H\beta U_j\) is below \(b\) when \(U_j < b/(H\beta)\), so the win probability is \((b/(H\beta))^{n-1}\) for \(b \le H\beta\). For \(b \ge H\beta\) every rival bid is at most \(H\beta \le b\), so the win probability is 1. Write \(c = b/H\) and \(u = v/H\), with \(u\in[0, 1]\). For \(c \le \beta\) the payoff is \(H(u - c)(c/\beta)^{n-1}\), and for \(c \ge \beta\) it is \(H(u - c)\). Up to the positive factor \(H\), these are the payoffs of the \([0, 1]\) model with value \(u\) and bid \(c\). Step 3 of Proposition 2.2 gives the maximizer \(c = \beta u\) on \([0, \beta]\). Step 4 covers \(c \ge \beta\): there \(H(u - c) \le H(u - \beta)\), which is at most the payoff at \(c = \beta u\) by Step 3. So \(c = \beta u\) is the best bid, and \(b = H c = \beta H u = \beta v\). The symmetric bid is unchanged, and this confirms that the equilibrium scales with the value.

R2 · A second bidder with a different distribution

Let \(n = 2\), with bidder 1's value uniform on \([0, 1]\) and bidder 2's value uniform on \([0, 2]\). Explain why the symmetric bid \(v/2\) is no longer the natural candidate, and state what the lesson does and does not establish for this case.

Solution

The symmetric argument of Proposition 2.2 needs Assumption 3, which says that both bidders use one strategy. With different value distributions, a rival's bid function is not the bidder's own, and Step 1 does not apply as written. The lesson states no equilibrium for this asymmetric case, and it does not solve it.

R3 · Why the test conditions on one's own type

Explain why Definition 1.3 uses the interim expected payoff, conditioned on the player's own type, rather than the payoff given the realized types of all players.

Solution

A player chooses its action before it learns the other players' types, so the payoff it can evaluate is the expectation over those types, given its own type. A test based on the realized types would ask the player to best respond to information it does not have, and the strategy it could use would depend on variables it cannot observe. The interim form is the one that a player can compute from its own type and the prior, using the conditional expectation of Definition 1.2.

  1. In a Bayesian game, what does a player condition on when it evaluates its payoff of an action?

  2. With two bidders and value 0.8, what is the equilibrium bid?

    \(\beta = 1/2\), so the bid is \(0.8/2 = 0.4\).

  3. With three bidders and value 0.6, what is the expected payoff of the equilibrium bid?

    \(v^n/n = 0.6^3/3 = 0.072\), as in Problem M1.

  5. With five bidders, what is the probability that a bid of 0.4 beats four equilibrium rival bids, when rivals bid \(4/5\) of their values?
