Validation & Resampling: Purged & Combinatorial K-Fold

Standard machine learning cross-validation assumes that samples are independent and identically distributed. In financial asset pricing, labels are formed over multi-day forward holding periods, causing adjacent observations to share identical underlying price trajectories. Applying unpurged cross-validation leaks forward price information directly into training sets, producing spuriously inflated Sharpe ratios that collapse upon live deployment. Rigorous temporal purging and embargoing restore mathematical honesty to model selection.

1. Overlapping Labels and the Failure of Standard K-Fold Cross-Validation

In standard statistical learning, an observational unit \((\mathbf{x}_i, y_i)\) has point-in-time features \(\mathbf{x}_i\) and a contemporaneous or immediate label \(y_i\). In financial trading strategies, the predictive target is almost universally defined as a forward cumulative return over an investment horizon of \(h\) bars:

\[ y_t = \frac{P_{t+h} - P_t}{P_t} \]

When returns are sampled at higher frequency than the holding horizon \(h\) (e.g. daily features predicting 20-day forward returns), adjacent labels \(y_t\) and \(y_{t+1}\) span overlapping time windows \([t, t+h]\) and \([t+1, t+1+h]\). Both labels share \(h-1\) days of identical price movements.

Purged K-fold cross-validation

Purged K-fold cross-validation is a resampling scheme designed for serially dependent time series with overlapping forward target labels. The temporal sequence of \(T\) observations is partitioned into \(K\) contiguous blocks. For each test block \(\mathcal{T}_k = [j_{\text{start}}, j_{\text{end}}]\), the training partition \(\mathcal{S}_k\) is constructed by removing any observation \(i\) whose label formation window \([i, i + h - 1]\) intersects \([j_{\text{start}}, j_{\text{end}}]\) (purging), and removing observations immediately following the test block to eliminate autoregressive feature memory (embargoing).

Theorem 2.1 · Information Leakage Under Unpurged K-Fold

Let forward return labels have horizon \(h > 1\). If test fold \(\mathcal{T}\) spans indices \([j_1, j_2]\), any unpurged training observation \(i \in [j_1 - h + 1, j_1 - 1]\) contains label \(y_i = \sum_{u=i}^{i+h-1} r_{u+1}\). Because \(i + h - 1 \ge j_1\), label \(y_i\) is partially computed from forward return innovations realized inside test fold \(\mathcal{T}\). Consequently, the conditional training error is correlated with the test error, violating out-of-sample orthogonality.

Proof

Consider the covariance between training label \(y_i\) for \(i = j_1 - 1\) and test label \(y_{j_1}\). Under a random walk price process \(P_t = P_0 + \sum_{s=1}^t \epsilon_s\) with i.i.d. innovations \(\E[\epsilon_s] = 0\) and \(\operatorname{Var}(\epsilon_s) = \sigma^2\):

\[ y_{j_1-1} = \sum_{u=j_1-1}^{j_1+h-2} \epsilon_{u+1} = \epsilon_{j_1} + \sum_{u=j_1}^{j_1+h-2} \epsilon_{u+1} \] \[ y_{j_1} = \sum_{u=j_1}^{j_1+h-1} \epsilon_{u+1} = \left(\sum_{u=j_1}^{j_1+h-2} \epsilon_{u+1}\right) + \epsilon_{j_1+h} \]

The shared sum spans \(h-1\) innovations. Their covariance is \(\operatorname{Cov}(y_{j_1-1}, y_{j_1}) = (h-1)\sigma^2 > 0\). Training on \(y_{j_1-1}\) allows an unconstrained model to memorize realizations of \(\{\epsilon_{j_1}, \dots, \epsilon_{j_1+h-2}\}\), which directly compose the test targets in \(\mathcal{T}\).

2. Mathematical Mechanics: Left-Purging and Post-Test Embargo

To eliminate information leakage, two distinct mechanisms must be applied to candidate training sets: left-purging and post-test embargoing [prado2018advances].

Left-Purging Operator

For a test fold defined on index set \(\mathcal{T} = [j_{\text{start}}, j_{\text{end}}]\) with forward label horizon \(h\), the left-purge set \(\mathcal{P}_{\text{left}}\) comprises all prior candidate training indices whose forward label evaluation touches the test start index:

\[ \mathcal{P}_{\text{left}} = \left\{ i \in \{0, \dots, T-1\} \mid i \le j_{\text{end}} \text{ and } i + h - 1 \ge j_{\text{start}} \right\} \]

Removing \(\mathcal{P}_{\text{left}}\) guarantees that zero training labels contain price returns realized after \(j_{\text{start}}\).

Post-Test Embargo Operator

Even when forward labels do not overlap, financial features \(\mathbf{x}_i\) (such as rolling realized volatility, exponential moving averages, or book-to-market ratios) exhibit high autoregressive persistence: \(\mathbf{x}_t = \phi \mathbf{x}_{t-1} + \mathbf{w}_t\) with \(\phi \approx 0.98\). Testing on \([j_{\text{start}}, j_{\text{end}}]\) and immediately training on \(j_{\text{end}} + 1\) leaks test-period state information into the post-test training set. The embargo set \(\mathcal{E}_{\text{post}}\) removes an additional buffer of \(h_{\text{embargo}} = \lceil \alpha_{\text{embargo}} T \rceil\) observations:

\[ \mathcal{E}_{\text{post}} = \left\{ i \in \{0, \dots, T-1\} \mid j_{\text{end}} < i \le \min(T-1, j_{\text{end}} + h_{\text{embargo}}) \right\} \]

Typically, practitioners set \(\alpha_{\text{embargo}} = 0.01\) to \(0.05\) (1% to 5% of total sample length).

Remark 2.1 · Clean Training Mask

Given total index set \(\mathcal{I} = \{0, 1, \dots, T-1\}\) and test partition \(\mathcal{T}_k = [j_{\text{start}}, j_{\text{end}}]\), the valid purged training index set is:

\[ \mathcal{S}_k = \mathcal{I} \setminus \left( [ \max(0, j_{\text{start}} - h + 1), \min(T-1, j_{\text{end}} + h_{\text{embargo}}) ] \right) \]

3. Combinatorial Purged Cross-Validation (CPCV)

A major critique of traditional walk-forward backtesting is that it evaluates a single historical path. The realized historical sequence might represent a unique macroeconomic regime (such as a 40-year bond bull market), leading to extreme model selection bias.

Combinatorial Purged Cross-Validation (CPCV) addresses this limitation by generating a distribution of out-of-sample paths while strictly preventing leakage [prado2018advances].

Combinatorial Purged CV Formulation

Let the dataset of \(T\) observations be split into \(N\) contiguous temporal groups. We select all subsets of \(k\) groups to serve as test folds, yielding a total number of splits:

\[ M = \binom{N}{k} = \frac{N!}{k!(N-k)!} \]

For each split \(m \in \{1, \dots, M\}\), the test set is \(\mathcal{T}_m = \bigcup_{g \in \mathcal{G}_m} \text{Group}_g\). The training set \(\mathcal{S}_m\) is constructed by removing all test groups and applying purging and embargoing around each test group boundary.

Theorem 2.2 · Backtest Path Redundancy in CPCV

In CPCV with \(N\) groups and test size \(k\), each temporal observation belongs to exactly:

\[ \Lambda = \binom{N-1}{k-1} \]

distinct test folds. By recombining predictions across folds chronologically, CPCV yields \(\Lambda\) distinct, non-overlapping out-of-sample backtest paths spanning the entire sample history.

Proof

Consider an arbitrary observation in group \(g^*\). In how many combinations of \(k\) test groups chosen from \(N\) does group \(g^*\) participate? Choosing group \(g^*\) leaves \(k-1\) slots to be filled from the remaining \(N-1\) groups. The number of such combinations is \(\binom{N-1}{k-1}\). Because every group is tested \(\Lambda\) times, we can assemble \(\Lambda\) complete time series of out-of-sample forecasts by assigning predictions from different split combinations without temporal overlap.

4. Empirical Lab · Overlapping Label Leakage: Standard vs. Purged K-Fold

We now execute Lab 1 to empirically demonstrate how unpurged K-fold creates false out-of-sample predictability under a pure geometric Brownian motion (zero true signal).

Lab 1 · Overlapping Label Leakage: Standard vs. Purged K-Fold

Under a pure random walk with overlapping forward returns, standard K-fold cross-validation produces spurious out-of-sample explanatory power, while purged K-fold restores negative honest R-squared.

"""Lab QR3-L02-1: Overlapping Label Leakage: Standard vs. Purged K-Fold Cross-Validation.

Demonstrates that standard K-fold cross-validation artificially inflates
apparent out-of-sample predictability when multi-day holding period returns
overlap fold boundaries, whereas Purged K-Fold with embargo restores honest error estimates.
"""

from __future__ import annotations

import math

import numpy as np


def compute_overlapping_labels(prices: np.ndarray, horizon: int) -> tuple[np.ndarray, np.ndarray]:
    """Generates features and forward multi-period overlapping return labels."""
    n = len(prices)
    features = np.zeros(n - horizon)
    labels = np.zeros(n - horizon)
    for t in range(n - horizon):
        features[t] = (prices[t] - prices[t - 5]) / prices[t - 5] if t >= 5 else 0.0
        labels[t] = (prices[t + horizon] - prices[t]) / prices[t]
    return features, labels


def evaluate_standard_cv(
    x: np.ndarray,
    y: np.ndarray,
    n_splits: int = 5,
) -> float:
    """Standard K-fold cross validation with i.i.d. shuffle assumption."""
    n = len(y)
    fold_size = n // n_splits
    errors: list[float] = []

    for k in range(n_splits):
        test_start = k * fold_size
        test_end = (k + 1) * fold_size if k < n_splits - 1 else n
        test_idx = np.arange(test_start, test_end)
        train_idx = np.setdiff1d(np.arange(n), test_idx)

        # OLS on training set
        x_tr, y_tr = x[train_idx], y[train_idx]
        x_te, y_te = x[test_idx], y[test_idx]

        slope = float(np.cov(x_tr, y_tr)[0, 1] / (np.var(x_tr) + 1e-12))
        preds = slope * x_te
        errors.append(float(np.mean((y_te - preds) ** 2)))

    return float(np.mean(errors))


def evaluate_purged_cv(
    x: np.ndarray,
    y: np.ndarray,
    horizon: int,
    n_splits: int = 5,
    embargo_pct: float = 0.02,
) -> float:
    """Purged K-fold cross validation with label purging and post-test embargo."""
    n = len(y)
    fold_size = n // n_splits
    errors: list[float] = []
    h_embargo = math.ceil(embargo_pct * n)

    for k in range(n_splits):
        test_start = k * fold_size
        test_end = (k + 1) * fold_size - 1 if k < n_splits - 1 else n - 1
        test_idx = np.arange(test_start, test_end + 1)

        # Purge training observations whose forward horizon [i, i + horizon - 1] touches test
        purge_start = max(0, test_start - horizon + 1)
        embargo_end = min(n - 1, test_end + h_embargo)

        train_mask = np.ones(n, dtype=bool)
        train_mask[purge_start : embargo_end + 1] = False
        train_idx = np.where(train_mask)[0]

        x_tr, y_tr = x[train_idx], y[train_idx]
        x_te, y_te = x[test_idx], y[test_idx]

        slope = float(np.cov(x_tr, y_tr)[0, 1] / (np.var(x_tr) + 1e-12))
        preds = slope * x_te
        errors.append(float(np.mean((y_te - preds) ** 2)))

    return float(np.mean(errors))


def main() -> None:
    rng = np.random.default_rng(77)
    n_bars = 400
    horizon = 5  # 5-day holding period

    # Price path under pure geometric random walk (zero true predictability)
    innovations = rng.normal(0.0002, 0.015, size=n_bars)
    prices = 100.0 * np.exp(np.cumsum(innovations))

    features, labels = compute_overlapping_labels(prices, horizon)
    baseline_var = float(np.var(labels))

    mse_standard = evaluate_standard_cv(features, labels, n_splits=5)
    r2_standard = 1.0 - (mse_standard / baseline_var)

    mse_purged = evaluate_purged_cv(features, labels, horizon=horizon, n_splits=5, embargo_pct=0.02)
    r2_purged = 1.0 - (mse_purged / baseline_var)

    print(f"Sample size: {len(labels)} overlapping {horizon}-day bars")
    print(f"Target variance: {baseline_var:.6f}")
    print(f"Standard K-Fold CV MSE: {mse_standard:.6f} | Apparent R2: {r2_standard:.4f}")
    print(f"Purged K-Fold CV MSE:   {mse_purged:.6f} | Honest R2:   {r2_purged:.4f}")
    print(f"Apparent Predictability Bias: {r2_standard - r2_purged:.4f}")
    print("Verification Invariant: Overlapping label leakage creates spurious apparent R2.")

Under standard K-fold cross-validation, test fold predictions borrow information from training observations whose forward 5-day return overlaps the test boundary. Purged K-fold eliminates this boundary contamination, revealing that true predictive power on pure noise is strictly non-positive.

5. Where the Canon Breaks

The standard machine learning validation literature treats cross-validation as an established science governed by Stone's theorem and leave-one-out consistency. In quantitative finance, the standard canon breaks in several key dimensions:

  • Non-IID Violations: The central limit theorem for cross-validation error relies on asymptotic independence between folds. In financial markets, volatility clustering and regime shifts induce persistent long-memory cross-fold dependence [prado2018advances].
  • Selection Bias Under Multiple Testing: Evaluating thousands of hyperparameter configurations via cross-validation maximizes the expectation of maximum sample Sharpe ratio. The expected maximum Sharpe ratio of \(M\) independent trials is strictly positive even when all strategies have zero true alpha (the false discovery rate) [prado2018advances].
  • Single-Path Walk-Forward Failure: Traditional quant lore asserts that walk-forward optimization is immune to overfitting. However, walk-forward produces only one sample trajectory, making it vulnerable to regime over-fitting on specific historical bull or bear cycles.

6. Misconceptions

  1. Walk-forward validation is the only statistically sound testing method for financial time series.

    Walk-forward validation evaluates only a single historical trajectory, confounding true strategy edge with path dependency. Combinatorial Purged Cross-Validation (CPCV) produces a distribution of out-of-sample paths while preserving strict temporal causality via boundary purging.

  2. Random shuffling is acceptable in cross-validation if daily asset returns pass white noise tests.

    Even if returns are serially uncorrelated, financial features (like volatility, value ratios, or momentum) exhibit high autocorrelation, and multi-day forward holding return targets overlap. Shuffling leaks forward price trajectories across folds.

  3. Post-test embargoing is unnecessary if the forward return label horizon h is properly purged.

    Purging only removes overlapping target labels. Highly persistent autoregressive features (e.g. rolling 60-day volatility) remain contaminated across the test-to-training transition unless an embargo buffer separates them.

7. Problem Set

Tier 1 · Mechanics

In a dataset of \(T = 1,000\) daily bars, a model predicts \(h = 10\)-day forward returns. Fold 3 evaluates the test block \([j_{\text{start}}, j_{\text{end}}] = [400, 499]\). Compute the exact index range of candidate training observations removed by left-purging.

Worked solution

Left-purging removes any candidate training index \(i\) such that \(i \le j_{\text{end}}\) and \(i + h - 1 \ge j_{\text{start}}\). Here \(j_{\text{start}} = 400\) and \(h = 10\), so the condition becomes \(i \ge 400 - 10 + 1 = 391\). Since test fold indices \([400, 499]\) are already excluded from training, the left-purged training indices are \([391, 399]\), comprising exactly \(h - 1 = 9\) observations.

For the setup in Problem 1, an embargo parameter \(\alpha_{\text{embargo}} = 0.02\) is applied. Calculate the total number of bars excluded from the training set across the test fold, left-purge window, and post-test embargo window.

Worked solution

The embargo length is \(h_{\text{embargo}} = \lceil 0.02 \times 1,000 \rceil = 20\) bars, spanning indices \([500, 519]\). The left-purge window spans \([391, 399]\) (9 bars), the test fold spans \([400, 499]\) (100 bars), and the embargo window spans \([500, 519]\) (20 bars). The total contiguous block excluded from training is \([391, 519]\), which comprises \(519 - 391 + 1 = 129\) bars.

A quant partitions a dataset into \(N = 6\) groups and applies Combinatorial Purged Cross-Validation with test size \(k = 2\). Calculate the total number of CV splits \(M\) and the number of backtest paths \(\Lambda\) generated.

Worked solution

The total number of CV splits is \(M = \binom{N}{k} = \binom{6}{2} = \frac{6 \times 5}{2 \times 1} = 15\) splits. The number of independent backtest paths generated is \(\Lambda = \binom{N-1}{k-1} = \binom{5}{1} = 5\) paths. Each observation appears in exactly 5 test folds.

Tier 2 · Proof

Prove that under a stationary Gaussian AR(1) process \(x_t = \phi x_{t-1} + \epsilon_t\) with \(|\phi| < 1\), the correlation between test point \(x_{j_{\text{end}}}\) and training point \(x_{j_{\text{end}} + d}\) decays as \(\phi^d\), and derive the required embargo length \(d^*\) such that correlation drops below threshold \(\delta > 0\).

Worked solution

For an AR(1) process, the autocorrelation at lag \(d\) is \(\rho(d) = \phi^d\). To ensure that the feature correlation across the test-to-training boundary does not exceed threshold \(\delta\), we require \(|\phi|^d \le \delta \iff d \ln |\phi| \le \ln \delta\). Since \(\ln |\phi| < 0\), dividing reverses the inequality: \(d \ge \frac{\ln \delta}{\ln |\phi|}\). Hence the minimum integer embargo length is \(d^* = \left\lceil \frac{\ln \delta}{\ln |\phi|} \right\rceil\).

Prove that for any CPCV scheme with \(N\) groups and test size \(k\), the total number of model evaluations across all observations in all folds equals \(k \cdot M \cdot \frac{T}{N}\), and show that this equals \(\Lambda \cdot T\).

Worked solution

Each group contains \(T/N\) observations. In each of the \(M = \binom{N}{k}\) splits, \(k\) groups are evaluated as test data, testing \(k \frac{T}{N}\) observations per split. Total evaluations across all splits is \(M \times k \frac{T}{N} = \binom{N}{k} \frac{k}{N} T\). Using the combinatorial identity \(\binom{N}{k} \frac{k}{N} = \frac{N!}{k!(N-k)!} \frac{k}{N} = \frac{(N-1)!}{(k-1)!(N-k)!} = \binom{N-1}{k-1} = \Lambda\), the total evaluations simplify directly to \(\Lambda \cdot T\).

Prove that if forward labels \(y_t\) are formed over non-overlapping windows (\(h = 1\)) and features are strictly i.i.d., the expected cross-validation error under purged K-fold is identical to standard K-fold.

Worked solution

When \(h = 1\), the left-purge condition \(i \le j_{\text{end}}\) and \(i + 1 - 1 \ge j_{\text{start}}\) simplifies to \(j_{\text{start}} \le i \le j_{\text{end}}\), which is exactly the test fold index set \(\mathcal{T}\). No training observations outside the test fold satisfy this condition, so \(\mathcal{P}_{\text{left}} \setminus \mathcal{T} = \emptyset\). When features are i.i.d., feature persistence \(\phi = 0\), requiring zero embargo (\(h_{\text{embargo}} = 0\)). Thus the purged training set \(\mathcal{S}\) is identical to the standard K-fold training complement \(\mathcal{I} \setminus \mathcal{T}\).

Tier 3 · Empirical

In Lab 1, why does standard K-fold produce an apparent \(R^2\) that is higher than purged K-fold even though the underlying data is a pure random walk?

Worked solution

Under a pure random walk, true predictability is zero. However, 5-day overlapping forward labels cause the training fold to share up to 4 days of identical return innovations with the boundary test observations. This boundary leakage allows the linear regression slope to capture the shared innovation, creating a spuriously elevated apparent \(R^2\). Purging eliminates this leakage, revealing the true non-positive \(R^2\).

How does increasing the forward holding horizon \(h\) from 1 day to 20 days affect the severity of lookahead bias under standard unpurged cross-validation?

Worked solution

As horizon \(h\) increases from 1 to 20 days, the number of contaminated observations at each fold boundary scales from 0 to 19 days. Furthermore, the proportion of shared variance between adjacent labels scales as \((h - \Delta t) / h\). This magnifies the spurious correlation between training and test sets, severely distorting hyperparameter tuning and model selection.

In backtesting a cross-sectional equity factor strategy, why can cross-sectional shuffling across stocks create leakage even if time is partitioned chronologically?

Worked solution

Stocks in the same sector or market share common factor shocks (e.g. macro interest rate shifts, industry momentum). If stock A is in the training set and stock B is in the test set on the exact same date \(t\), the model learns the cross-sectional market shock on date \(t\) and uses it to predict stock B, violating temporal out-of-sample separation.

Tier 4 · Research

Explain the Deflated Sharpe Ratio (DSR) framework of Bailey & López de Prado (2014) and how it corrects for multiple testing in cross-validation model selection.

Worked solution

The Deflated Sharpe Ratio computes the probability that the estimated annualized Sharpe ratio of the selected model exceeds zero, after adjusting for the maximum expected Sharpe ratio across \(K\) independent trials, non-normal return skewness and kurtosis, and sample length. When a researcher selects the best model among thousands of CV configurations, DSR adjusts the significance threshold upward according to extreme value theory to prevent false discoveries.

What structural advantages does CPCV provide over traditional rolling walk-forward validation when analyzing trading strategy drawdowns?

Worked solution

Rolling walk-forward validation produces only a single realized drawdown trajectory, which may reflect the idiosyncrasies of specific historical regimes. CPCV generates \(\Lambda = \binom{N-1}{k-1}\) distinct backtest paths by combining different validation folds. This produces an empirical distribution of drawdowns and maximum drawdown durations, providing statistical confidence bounds rather than a point estimate.

How does label purging interact with asymmetric execution costs and turnover in dynamic portfolio rebalancing?

Worked solution

Because purging drops contiguous blocks of training observations, the time series of training signals contains artificial gaps if not handled carefully. However, when evaluating the out-of-sample backtest paths generated by CPCV, each path is continuous in calendar time. This ensures that simulated turnover, bid-ask spread costs, and market impact are evaluated along continuous portfolio trajectories without distortion.

9. Retrieval Quiz

  1. Why does standard K-fold cross-validation fail when applied to financial time series?

    Options

    When forward labels span \(h\) bars, adjacent labels share \(h-1\) days of identical price movements, violating sample independence.

  2. What observations are eliminated by the left-purging operation for test fold \([j_{\text{start}}, j_{\text{end}}]\) with forward horizon \(h\)?

    Options

    Left-purging removes prior candidate observations whose forward return window extends into the test evaluation period.

  3. What is the primary motivation for applying a post-test embargo period in financial cross-validation?

    Options

    Persistent features (such as moving averages or volatility estimators) carry forward state memory across the test boundary unless suppressed by an embargo.

  4. How many distinct chronological backtest paths does Combinatorial Purged CV generate with \(N\) groups and test size \(k\)?

    Options

    Each observation participates in \(\binom{N-1}{k-1}\) test splits, allowing assembly of that exact number of complete out-of-sample backtest paths.

  5. What is the total number of CV splits evaluated in CPCV when partitioning into \(N = 5\) groups with \(k = 2\) test groups?

    Options

    \(M = \binom{5}{2} = \frac{5 \times 4}{2} = 10\) splits.

  6. What limitation of single-path walk-forward validation is overcome by Combinatorial Purged CV?

    Options

    CPCV produces a distribution of out-of-sample paths, enabling statistical confidence intervals around performance metrics.

  7. Under a random walk price process with 5-day holding period returns, what is the theoretical true out-of-sample \(R^2\)?

    Options

    Because the true conditional expectation is constant, any estimated slope fits sample noise, producing expected out-of-sample \(R^2 \le 0\).

  8. In a dataset of \(N = 500\) bars, if test fold is \([100, 199]\), label horizon is \(h = 5\), and embargo is \(2\%\), what is the first valid post-test training index?

    Options

    Embargo length is \(\lceil 0.02 \times 500 \rceil = 10\) bars. The embargo window is \([200, 209]\), so the first valid post-test index is 210.

  9. Why does cross-sectional shuffling across equities on the same calendar day leak information?

    Options

    Common systematic factors expose all stocks to contemporaneous innovations, leaking information if the same date is split across train and test folds.

  10. What does the Deflated Sharpe Ratio (DSR) adjust for when evaluating backtested strategies?

    Options

    DSR uses extreme value theory to discount backtest Sharpe ratios based on the number of hyperparameter trials conducted.
