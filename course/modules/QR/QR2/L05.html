Purged & Embargoed Cross-Validation, CPCV

Standard machine learning cross-validation fails in quantitative finance because financial labels span multi-day holding periods and features exhibit autoregressive memory. When test fold boundaries sit adjacent to training samples, forward label horizons leak future price outcomes directly into the training set. Purged cross-validation eliminates overlapping label windows, while embargo buffers insulate against feature memory. Extending this framework to Combinatorial Purged Cross-Validation generates multiple out-of-sample testing paths, enabling rigorous measurement of backtest overfitting.

1. The Label Overlap Problem & Purging

In financial machine learning, target labels \(y_t\) are rarely instantaneous one-bar returns. They represent multi-period returns, triple-barrier outcomes, or trend labels spanning an evaluation horizon of \(h_{\text{label}} \ge 1\) bars: \(y_t = f(P_t, P_{t+1}, \dots, P_{t+h_{\text{label}}-1})\).

Purged Cross-Validation

Let test fold \(k\) span observation indices \([j_{\text{start}}, j_{\text{end}})\). An observation \(i\) with label horizon \([i, i + h_{\text{label}} - 1]\) contains information from the test fold if their label evaluation windows intersect. Purged cross-validation removes every training sample \(i\) that satisfies:

\[ i \le j_{\text{end}} - 1 \quad \text{and} \quad i + h_{\text{label}} - 1 \ge j_{\text{start}} \]

Specifically, for training samples prior to the test fold (\(i < j_{\text{start}}\)), left-purging discards all indices in the interval:

\[ \mathcal{I}_{\text{purge}}^{\text{left}} = [\max(0, j_{\text{start}} - h_{\text{label}} + 1), j_{\text{start}}) \]

Embargo Period

Financial features (such as rolling realized volatility, moving averages, or AR filters) exhibit autoregressive serial memory. To eliminate auto-correlated feature leakage following a test fold, an embargo period of duration \(h_{\text{embargo}} = \lceil \text{embargo\_pct} \times T \rceil\) bars is applied immediately following \(j_{\text{end}}\). All training samples in the post-test interval:

\[ \mathcal{I}_{\text{embargo}} = [j_{\text{end}}, \min(T, j_{\text{end}} + h_{\text{embargo}})) \]

are removed from the training set.

Theorem 5.1 · Purged Boundary Information Disjointness

Let \(\mathcal{F}_{[a, b]} = \sigma(\{P_t : t \in [a, b]\})\). If training set indices \(\mathcal{I}_{\text{train}}\) are formed by purging overlapping label windows \([i, i + h_{\text{label}} - 1]\) and embargoing post-test memory against test set \(\mathcal{I}_{\text{test}} = [j_{\text{start}}, j_{\text{end}})\), then the label \(\sigma\)-algebras are conditionally independent under the no-long-memory null:

\[ \sigma(\{y_i : i \in \mathcal{I}_{\text{train}}\}) \cap \sigma(\{y_j : j \in \mathcal{I}_{\text{test}}\}) = \emptyset \]

Proof

For any \(i \in \mathcal{I}_{\text{train}}\) with \(i < j_{\text{start}}\), left-purging enforces \(i < j_{\text{start}} - h_{\text{label}} + 1\), which implies \(i + h_{\text{label}} - 1 < j_{\text{start}}\). Hence \([i, i + h_{\text{label}} - 1] \cap [j_{\text{start}}, j_{\text{end}} + h_{\text{label}} - 1] = \emptyset\). For \(i > j_{\text{end}}\), embargoing enforces \(i \ge j_{\text{end}} + h_{\text{embargo}} > j_{\text{end}}\). Neither the forward label evaluation intervals nor the feature lookback intervals intersect the test evaluation span, precluding index-level information overlap.

2. Combinatorial Purged Cross-Validation (CPCV)

A critical flaw of standard walk-forward analysis is that it produces only a single out-of-sample path. Following López de Prado (2018, Ch. 12), Combinatorial Purged Cross-Validation solves this limitation by generating an entire distribution of out-of-sample paths.

Combinatorial Purged Cross-Validation

Combinatorial Purged Cross-Validation (CPCV) partitions \(T\) observations into \(N\) contiguous chronological blocks. For a chosen integer \(k \in \{1, \dots, N-1\}\), CPCV evaluates all \(\binom{N}{k}\) combinations of \(k\) blocks as the test set:

\[ \binom{N}{k} = \frac{N!}{k!(N-k)!} \]

For each combination, the remaining \(N-k\) blocks form the training set, subject to pairwise left-purging and post-test embargoing applied against each test block. Each observation index is evaluated out-of-sample across \(\binom{N-1}{k-1}\) distinct models.

Theorem 5.2 · CPCV Out-of-Sample Path Identity

In a CPCV partitioning with \(N\) groups and \(k\) test groups per split, the total number of independent contiguous out-of-sample backtest paths generated by recombining non-overlapping test folds is:

\[ \varphi = \binom{N}{k} \frac{k}{N} = \binom{N-1}{k-1} \]

Proof

Each split tests \(k\) blocks. The total number of tested blocks across all \(\binom{N}{k}\) splits is \(k \binom{N}{k}\). By combinatorial symmetry across the \(N\) groups, each individual block is tested exactly \(k \binom{N}{k} / N\) times. Expanding factorials:

\[ \frac{k}{N} \binom{N}{k} = \frac{k}{N} \frac{N!}{k!(N-k)!} = \frac{(N-1)!}{(k-1)!(N-k)!} = \binom{N-1}{k-1} \]

Because each group is tested \(\binom{N-1}{k-1}\) times, these group test predictions can be assembled into exactly \(\binom{N-1}{k-1}\) complete, non-overlapping out-of-sample equity curves covering the full time span.

3. Empirical Lab · Purging, Embargoing & CPCV Partitions

We audit a 5-fold cross-validation scheme on 200 synthetic trading bars with a 5-day label lookahead horizon and 2% embargo, verifying boundary insulation and CPCV path generation.

Lab 1 · Purged & Embargoed Cross-Validation (CPCV) vs Standard K-Fold

Left-purging removes all training samples whose forward label horizons intersect the test fold, while post-test embargo buffers eliminate autoregressive feature leakage, producing zero boundary leakage across all cross-validation folds.

"""Lab QR2-L05-1: Purged & Embargoed Cross-Validation (CPCV) vs Standard K-Fold.

Demonstrates information leakage across fold boundaries in standard K-fold CV
when labels overlap, and verifies purging and post-test embargoing (López de Prado 2018).
"""

from __future__ import annotations

import math

import numpy as np


def generate_purged_embargo_splits(
    n_samples: int,
    n_splits: int,
    label_lookahead: int,
    embargo_pct: float,
) -> list[tuple[np.ndarray, np.ndarray, int, int]]:
    """Generates purged and embargoed CV splits, counting purged and embargoed samples."""
    indices = np.arange(n_samples)
    fold_bounds = np.linspace(0, n_samples, n_splits + 1, dtype=int)
    h_embargo = math.ceil(embargo_pct * n_samples)

    splits: list[tuple[np.ndarray, np.ndarray, int, int]] = []
    for k in range(n_splits):
        t_start = fold_bounds[k]
        t_end = fold_bounds[k + 1]
        test_idx = indices[t_start:t_end]

        train_mask = np.ones(n_samples, dtype=bool)
        train_mask[t_start:t_end] = False

        # Left purge
        left_purge_start = max(0, t_start - label_lookahead + 1)
        n_purged = t_start - left_purge_start
        train_mask[left_purge_start:t_start] = False

        # Right embargo
        right_embargo_end = min(n_samples, t_end + h_embargo)
        n_embargoed = right_embargo_end - t_end
        train_mask[t_end:right_embargo_end] = False

        train_idx = indices[train_mask]
        splits.append((train_idx, test_idx, n_purged, n_embargoed))

    return splits


def main() -> None:
    n_samples = 200
    n_splits = 5
    label_lookahead = 5  # 5-day holding period return labels
    embargo_pct = 0.02  # 2% of sample = 4 bars

    splits = generate_purged_embargo_splits(n_samples, n_splits, label_lookahead, embargo_pct)

    print(f"Purged & Embargoed CV Audit (N={n_samples}, K={n_splits}, Label Horizon={label_lookahead}d):")
    print("----------------------------------------------------------------------")
    print(f"{'Fold':<8}{'Test Range':<16}{'Train Size':<14}{'Purged':<12}{'Embargoed':<12}{'Leakage Audit'}")
    print("----------------------------------------------------------------------")

    for k, (train_idx, test_idx, n_purged, n_embargo) in enumerate(splits, start=1):
        t_start, t_end = int(test_idx.min()), int(test_idx.max()) + 1

        # Check if any training observation i has label window overlapping test
        overlap_left = [i for i in train_idx if i < t_start and i + label_lookahead - 1 >= t_start]
        overlap_test = np.intersect1d(train_idx, test_idx)
        leakage_detected = len(overlap_left) > 0 or len(overlap_test) > 0
        status = "FAIL (Leak)" if leakage_detected else "PASS (Clean)"

        test_str = f"[{t_start}:{t_end}]"
        print(f"{k:<8}{test_str:<16}{len(train_idx):<14}{n_purged:<12}{n_embargo:<12}{status}")

    # Combinatorial Purged CV (CPCV) setup: N=6 groups, k=2 test groups
    n_groups = 6
    k_test = 2
    n_combs = math.comb(n_groups, k_test)
    n_paths = int(n_combs * (k_test / n_groups))

    print("----------------------------------------------------------------------")
    print(f"CPCV Partitioning: N={n_groups} groups, k={k_test} test groups per split")
    print(f"Combinations generated: C({n_groups}, {k_test}) = {n_combs}")
    print(f"Independent testing paths generated: {n_paths}")
    print("Invariant Verified: Purging eliminates overlapping label leakage across all boundaries.")


main()

4. Where the Canon Breaks

Standard scikit-learn cross-validation (KFold, TimeSeriesSplit) is ubiquitous in data science, but breaks down fundamentally when applied to financial time series [prado2018advances]:

  • Boundary information bleeding: In standard KFold, training sample \(t_{\text{test,start}}-1\) uses return \(r_{t_{\text{test,start}} + 3}\) as its label, allowing the model to train on the very price motion it is evaluated on during the test fold.
  • Feature memory leakage: Features computed over long rolling lookback windows (e.g. 200-day moving average or 60-day realized volatility) carry memory from the test fold into subsequent training folds unless an embargo is enforced.
  • Overfitting under trial selection: While CPCV eliminates boundary leakage, evaluating thousands of combinatorial model variations across multiple hyperparameters still creates selection bias, requiring Deflated Sharpe Ratio (DSR) or Probability of Backtest Overfitting (PBO) adjustments [bailey2014deflated].

5. Misconceptions

  1. Purged cross-validation eliminates the need to adjust for multiple testing across model search iterations.

    Purged CV eliminates information leakage across fold boundaries within a single backtest run. However, if a researcher evaluates 1,000 different model architectures or feature sets using CPCV, selection bias over multiple trials still inflates performance, requiring DSR or PBO corrections.

  2. Embargoing is redundant if left-purging has already been applied to overlapping label windows.

    Left-purging addresses label lookahead before the test fold. Embargoing addresses autoregressive feature memory after the test fold, preventing high-memory features evaluated on test prices from leaking into post-test training data.

  3. Purging removes too many training observations, causing models to underfit from lack of sample data.

    Purging typically removes only a small fraction of data (e.g. 4 samples out of 160 per fold for a 5-day horizon). Retaining those 4 samples creates massive forward leakage that severely inflates test accuracy, leading to catastrophic live trading failure.

6. Practice Problems

Tier 1 · Mechanics

In a dataset of \(T = 200\) bars partitioned into 5 equal folds (40 bars each), test fold 2 spans indices [40:80]. If labels are computed over a 5-bar forward horizon (\(h_{\text{label}} = 5\)), calculate the left-purge index interval.

Worked solution

The test fold starts at \(j_{\text{start}} = 40\). The left purge starts at \(\max(0, j_{\text{start}} - h_{\text{label}} + 1) = \max(0, 40 - 5 + 1) = 36\). The purged interval is \([36, 40)\), containing exactly \(40 - 36 = 4\) samples (indices 36, 37, 38, and 39).

For the setup in Problem 1, if an embargo of 2% is applied to the sample of \(T = 200\) bars, calculate the embargo duration and the post-test embargo interval for fold 2.

Worked solution

The embargo duration is \(h_{\text{embargo}} = \lceil 0.02 \times 200 \rceil = 4\) bars. The test fold ends at \(j_{\text{end}} = 80\). The embargoed interval is \([80, \min(200, 80 + 4)) = [80, 84)\), containing exactly 4 samples (indices 80, 81, 82, and 83).

In a CPCV partitioning with \(N = 6\) groups and \(k = 2\) test groups per split, how many total model combinations and how many independent out-of-sample paths are generated?

Worked solution

The number of combinations is \(\binom{6}{2} = \frac{6 \times 5}{2 \times 1} = 15\) model splits. The number of independent out-of-sample paths is \(\varphi = \binom{6-1}{2-1} = \binom{5}{1} = 5\) paths. This can also be verified via \(\binom{6}{2} \times \frac{2}{6} = 15 \times \frac{1}{3} = 5\).

Tier 2 · Proof

Prove that for the first fold of a \(k\)-fold cross-validation scheme where \(j_{\text{start}} = 0\), the left-purging set \(\mathcal{I}_{\text{purge}}^{\text{left}}\) is identically empty.

Worked solution

For fold 1, the test fold starts at \(j_{\text{start}} = 0\). The left-purge start index is \(\max(0, 0 - h_{\text{label}} + 1) = \max(0, 1 - h_{\text{label}})\). Since \(h_{\text{label}} \ge 1\), \(1 - h_{\text{label}} \le 0\), so the purge start index is 0. The purged interval is \([0, 0) = \emptyset\). No training samples precede the first test fold, so left-purging is identically empty.

Prove that for the final fold where \(j_{\text{end}} = T\), the post-test embargo set \(\mathcal{I}_{\text{embargo}}\) is identically empty.

Worked solution

For the final fold, \(j_{\text{end}} = T\). The embargoed interval is \([T, \min(T, T + h_{\text{embargo}})) = [T, T) = \emptyset\). Because no training samples follow the end of the historical dataset, the post-test embargo interval contains zero samples.

Prove that in CPCV, every pair of distinct groups \(\{g_a, g_b\}\) appears together in the test set of exactly \(\binom{N-2}{k-2}\) model combinations for \(k \ge 2\).

Worked solution

Fix any two distinct groups \(g_a\) and \(g_b\) in the test set. To form a complete test set of size \(k\), the remaining \(k-2\) groups must be chosen from the remaining \(N-2\) available groups. The number of ways to choose these remaining groups is \(\binom{N-2}{k-2}\). Thus, pairwise group co-occurrence is constant across all pairs by symmetry.

Tier 3 · Empirical

In Lab 1, why did Fold 1 have 156 training samples while Folds 2, 3, and 4 had exactly 152 training samples?

Worked solution

In Lab 1, total sample size was 200 and each fold had 40 test samples, leaving 160 potential training samples. Fold 1 has no preceding samples, so left-purged is 0, but embargo removes 4 samples, leaving \(160 - 4 = 156\). Folds 2, 3, and 4 have both left-purging (4 samples) and post-test embargo (4 samples), removing 8 samples and leaving \(160 - 8 = 152\). Fold 5 has 4 left-purged and 0 embargoed, leaving 156 samples.

Suppose a quantitative strategy calculates trend labels over a 20-day horizon on daily data. In a 5-fold CV with 250 bars, what percentage of training data is purged?

Worked solution

Each fold has 50 test bars. For an interior fold (e.g. fold 2 starting at bar 50), left-purging removes \(\min(50, 20 - 1) = 19\) samples. Out of 200 non-test samples, 19 purged samples represent \(19 / 200 = 9.5\%\) of available training data. Purging removes roughly 10% of training data per interior fold to preserve clean boundary isolation.

Why does Combinatorial Purged Cross-Validation provide a richer overfitting diagnostic than standard walk-forward analysis?

Worked solution

Standard walk-forward yields a single out-of-sample Sharpe ratio, leaving uncertainty about whether performance was lucky. CPCV generates \(\binom{N-1}{k-1}\) independent out-of-sample paths, creating an empirical distribution of out-of-sample Sharpe ratios and correlations, directly enabling the calculation of the Probability of Backtest Overfitting (PBO).

Tier 4 · Research

Explain the relationship between Combinatorial Purged Cross-Validation (CPCV) and the Probability of Backtest Overfitting (PBO) defined by Bailey et al. (2016).

Worked solution

Bailey et al. (2016) define PBO as the probability that the model selected as best in-sample ranks below the median out-of-sample. CPCV generates \(\binom{N}{k}\) in-sample and out-of-sample performance pairs across multiple strategy configurations. By evaluating the relative rank of the in-sample optimal strategy across all combinatorial test sets, researchers compute the empirical frequency of post-selection underperformance.

How does triple-barrier labeling interact with purged cross-validation compared to fixed-time horizon returns?

Worked solution

Under fixed-time labeling, the horizon \(h_{\text{label}}\) is deterministic. Under triple-barrier labeling (upper profit target, lower stop-loss, vertical time limit), each observation \(i\) has a variable holding period \(\tau_i \in [1, h_{\max}]\). In variable-horizon purging, an observation \(i\) is purged if its specific event window \([i, i + \tau_i]\) intersects the test fold, requiring observation-specific timestamp intervals rather than uniform index offsets.

Propose an optimal algorithm for setting the embargo duration \(h_{\text{embargo}}\) based on empirical feature autocorrelation decay.

Worked solution

Instead of a heuristic percentage (e.g. 1%), the algorithm computes the empirical autocorrelation function \(\rho_f(l)\) for all engineered features. The embargo length is set to \(h_{\text{embargo}} = \max_f \{l : |\rho_f(l)| \ge \epsilon\}\) where \(\epsilon = 2 / \sqrt{T}\) is the 95% Bartlett confidence bound under white noise. This guarantees that feature memory has statistically decayed to zero before subsequent training begins.
