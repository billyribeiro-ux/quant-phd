Rung 1 · Worked example

Before implementing the full milestone, inspect the minimal discrete-event execution cycle below. The snippet demonstrates the key separation between signal observation at bar \(t\) and physical execution at bar \(t + \tau_{\text{lag}}\):

# Minimal Causal Execution Cycle
def simulate_causal_step(t: int, signal_t: float, price_t: float, pending_order: dict | None, lag: int = 1):
    executed_fill = None
    # 1. Fill pending order if lag period has elapsed
    if pending_order is not None and t >= pending_order["submitted_bar"] + lag:
        qty = pending_order["qty"]
        executed_fill = {"bar": t, "price": price_t, "qty": qty}
        pending_order = None

    # 2. Generate new order based on current bar signal (cannot fill on bar t)
    new_order = {"submitted_bar": t, "qty": signal_t}
    return executed_fill, new_order

In this workflow, an order generated using information from bar \(t\) can never participate in bar \(t\)'s prices. The engine guarantees \(\tau_{\text{lag}} \ge 1\), eliminating the trade-on-close lookahead leak.

Rung 3 · Independent project deliverable

Context
A quantitative trading desk designs, validates, and deploys systematic alpha strategies across equities and futures. Academic factor research frequently claims high Sharpe ratios that disappear upon live trading due to hidden lookahead bias, unmodeled execution latency, and naive cross-validation leakage. Atlas milestone A9 provides the institutional backtesting core that enforces strict lag causality, realistic nonlinear execution costs, and purged cross-validation before capital allocation.
Inputs
  • prices: 1D NumPy array of length \(T \ge 4\) containing strictly positive, finite historical prices.
  • signals: 1D NumPy array of length \(T\) containing target portfolio weights in \([-1.0, 1.0]\) or order lot directions.
  • volumes: Optional 1D NumPy array of length \(T\) containing positive average daily volume (default 1,000,000 shares).
  • volatilities: Optional 1D NumPy array of length \(T\) containing daily price return volatility estimates (default 0.02).
  • trial_returns: Optional 2D NumPy array of shape \((T, N)\) representing excess return streams across \(N\) evaluated trial configurations for research integrity reporting.
Required outputs
A single Python module atlas/backtest.py exporting:
  • BacktestEngine(initial_cash, lag_bars, cost_model, min_lag_bars) with method run(...) -> BacktestResult.
  • CostModel(commission_bps, half_spread_bps, impact_coeff) with method calculate_cost(...) -> tuple[float, float, float].
  • walk_forward_splits(n_samples, train_size, test_size, step_size, expanding) -> list[tuple[np.ndarray, np.ndarray]].
  • purged_kfold_splits(n_samples, n_splits, label_lookahead, embargo_pct) -> list[tuple[np.ndarray, np.ndarray]].
  • cpcv_splits(n_samples, n_groups, k_test_groups, label_lookahead, embargo_pct) -> list[tuple[np.ndarray, np.ndarray, tuple[int, ...]]].
  • planted_lookahead_audit(engine, prices, legitimate_signal, planted_signal) -> dict[str, Any].
Constraints
  • All functions and classes must validate inputs, raising ValueError on invalid values.
  • Execution lag \(\tau_{\text{lag}}\) must be strictly positive: \(\tau_{\text{lag}} \ge \text{min\_lag\_bars} \ge 1\). Any attempt to initialize or execute with \(\tau_{\text{lag}} < 1\) must raise ValueError.
  • Every BacktestResult must carry an attached integrity report computed via Atlas A8 (atlas.integrity.integrity_report).
  • Code must be fully typed, warning-free, and clean under mypy --strict and ruff.
Grading
The module is evaluated by an automated autograder test suite across 50 consecutive pseudo-random market seeds (seeds 0–49). To pass, all tests must succeed within 60 seconds.
