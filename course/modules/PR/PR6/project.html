Compare optimal stochastic policies against institutional target-date fund (TDF) glide paths to quantify certainty equivalent welfare loss and sequence-of-returns drawdown risk.

  • Evaluation: Both (autograder suite across 50 seeds, plus expert rubric scoring of research memo)

Lab 1 · Lifecycle Dynamic Benchmark Solution

Dynamic lifecycle allocation adjusting for human capital leverage and predictability hedging generates higher expected terminal wealth than fixed glide paths, while late sequence-of-returns risk varies systematically across policies.

"""Lab PR6-project-1: Project Rung 1 Worked Example - Lifecycle Dynamic Solver.

SIMULATED: Fully solved numerical instance of dynamic lifecycle allocation with
labour income and return predictability compared against target-date glide paths.
"""

from __future__ import annotations

import math

import numpy as np


def compute_human_capital(wages: np.ndarray, r_discount: float) -> np.ndarray:
    """Compute backward-discounted present value of labour income at each age."""
    n = len(wages)
    hc = np.zeros(n)
    for t in range(n):
        discounts = (1.0 + r_discount) ** (-np.arange(n - t))
        hc[t] = float(np.sum(wages[t:] * discounts))
    return hc


def run_lifecycle_benchmark(
    initial_age: int = 25,
    retire_age: int = 65,
    initial_wealth: float = 25000.0,
    initial_wage: float = 50000.0,
    wage_growth: float = 0.02,
    savings_rate: float = 0.15,
    r_free: float = 0.02,
    equity_premium: float = 0.05,
    equity_vol: float = 0.18,
    phi: float = 0.85,
    sigma_eta: float = 0.10,
    rho: float = -0.75,
    wage_beta: float = 0.0,
    gamma: float = 4.0,
    n_paths: int = 10000,
    seed: int = 42,
) -> dict[str, float]:
    """Run full numerical lifecycle benchmark comparing dynamic optimal vs target-date glide paths."""
    rng = np.random.default_rng(seed)
    years = retire_age - initial_age

    # 1. Deterministic career wage profile
    wages = np.zeros(years + 1)
    for t in range(years + 1):
        wages[t] = initial_wage * math.exp(wage_growth * t - 0.0003 * t**2)

    # 2. Human capital trajectory
    hc = compute_human_capital(wages, r_discount=r_free)

    # 3. Simulate market environment with return predictability
    # Innovations for [return, state]
    cov_eps_eta = rho * equity_vol * sigma_eta
    cov_mat = np.array([[equity_vol**2, cov_eps_eta], [cov_eps_eta, sigma_eta**2]])
    chol = np.linalg.cholesky(cov_mat)

    z = rng.standard_normal((n_paths, years, 2))
    shocks = np.einsum("ij,nyj->nyi", chol, z)
    eps = shocks[:, :, 0]
    eta = shocks[:, :, 1]

    # Pre-compute state variable x_t and equity return r_t
    beta_pred = 0.06
    x = np.zeros((n_paths, years + 1))
    r_equity = np.zeros((n_paths, years))

    for t in range(years):
        r_equity[:, t] = r_free + equity_premium + beta_pred * x[:, t] + eps[:, t]
        x[:, t + 1] = phi * x[:, t] + eta[:, t]

    # 4. Compare Dynamic Optimal vs "To-Retirement" Glide Path
    wealth_opt = np.zeros((n_paths, years + 1))
    wealth_tdf = np.zeros((n_paths, years + 1))
    wealth_opt[:, 0] = initial_wealth
    wealth_tdf[:, 0] = initial_wealth

    for t in range(years):
        age = initial_age + t
        # Dynamic policy: adjusts for H_t / W_t and return predictability hedging
        # Effective financial wealth
        w_safe = np.maximum(wealth_opt[:, t], 1000.0)
        hc_ratio = hc[t] / w_safe
        # Myopic demand: (mu_t - r) / (gamma * sigma^2)
        myopic_t = (equity_premium + beta_pred * x[:, t]) / (gamma * equity_vol**2)
        # Hedging demand: Campbell-Viceira predictability factor with finite horizon attenuation
        tau = float(years - t)
        horizon_factor = (1.0 - (phi**tau)) / (1.0 - phi) if (1.0 - phi) > 1e-6 else tau
        hedge_t = (1.0 - 1.0 / gamma) * (-rho * sigma_eta / equity_vol) * horizon_factor * (beta_pred / equity_vol**2)
        # Optimal total wealth risky share: alpha_tot = myopic_t + hedge_t
        alpha_tot = myopic_t + hedge_t
        # Financial equity allocation: alpha_F = alpha_tot * (1 + H/W) - beta_H * (H/W)
        alpha_dynamic = alpha_tot + (alpha_tot - wage_beta) * hc_ratio
        # Realistic lifecycle constraint: clamp to [0.0, 1.0]
        alpha_dynamic = np.clip(alpha_dynamic, 0.0, 1.0)

        # TDF "To-Retirement" linear glide path (90% to 30%)
        alpha_tdf_t = 0.90 if age <= 40 else 0.90 - (0.90 - 0.30) * ((age - 40) / (65 - 40))

        # Evolve portfolios
        port_ret_opt = (1.0 - alpha_dynamic) * r_free + alpha_dynamic * r_equity[:, t]
        port_ret_tdf = (1.0 - alpha_tdf_t) * r_free + alpha_tdf_t * r_equity[:, t]

        savings = savings_rate * wages[t]
        wealth_opt[:, t + 1] = wealth_opt[:, t] * (1.0 + port_ret_opt) + savings
        wealth_tdf[:, t + 1] = wealth_tdf[:, t] * (1.0 + port_ret_tdf) + savings

    # Terminal outcomes
    w_term_opt = np.maximum(wealth_opt[:, -1], 1.0)
    w_term_tdf = np.maximum(wealth_tdf[:, -1], 1.0)

    u_opt = float(np.mean((w_term_opt ** (1.0 - gamma)) / (1.0 - gamma)))
    u_tdf = float(np.mean((w_term_tdf ** (1.0 - gamma)) / (1.0 - gamma)))

    ce_opt = float(((1.0 - gamma) * u_opt) ** (1.0 / (1.0 - gamma)))
    ce_tdf = float(((1.0 - gamma) * u_tdf) ** (1.0 / (1.0 - gamma)))

    return {
        "mean_wealth_opt": float(np.mean(w_term_opt)),
        "mean_wealth_tdf": float(np.mean(w_term_tdf)),
        "p5_wealth_opt": float(np.percentile(w_term_opt, 5)),
        "p5_wealth_tdf": float(np.percentile(w_term_tdf, 5)),
        "ce_wealth_opt": ce_opt,
        "ce_wealth_tdf": ce_tdf,
        "welfare_gain_pct": float((ce_opt / ce_tdf - 1.0) * 100.0),
    }


def main() -> None:
    res = run_lifecycle_benchmark(
        initial_age=25,
        retire_age=65,
        initial_wealth=25000.0,
        initial_wage=50000.0,
        wage_growth=0.02,
        savings_rate=0.15,
        r_free=0.02,
        equity_premium=0.05,
        equity_vol=0.18,
        phi=0.85,
        sigma_eta=0.10,
        rho=-0.75,
        wage_beta=0.0,
        gamma=4.0,
        n_paths=15000,
        seed=42,
    )

    print("Project Rung 1: Dynamic Lifecycle Allocation Benchmark Results:")
    print("=" * 76)
    print(f"{'Metric':<36} {'Dynamic Policy':<20} {'Target-Date Fund':<18}")
    print("-" * 76)
    print(f"{'Expected Terminal Wealth ($)':<36} {res['mean_wealth_opt']:<20.1f} {res['mean_wealth_tdf']:<18.1f}")
    print(f"{'5th Percentile Wealth ($)':<36} {res['p5_wealth_opt']:<20.1f} {res['p5_wealth_tdf']:<18.1f}")
    print(f"{'Certainty Equivalent Wealth ($)':<36} {res['ce_wealth_opt']:<20.1f} {res['ce_wealth_tdf']:<18.1f}")
    print("-" * 76)
    print(f"Dynamic Policy Certainty Equivalent Premium: {res['welfare_gain_pct']:+.2f}%")
    print("=" * 76)


main()

Annotated research report exemplars

Exemplar A · Level 4 (Distinguished)

Context: Excerpt from an executive research report submitted to an Institutional Investment Committee.

1. Theoretical Risk Framework: The portfolio choice of a long-horizon investor subject to state-dependent investment opportunities satisfies the Merton (1971) Hamilton-Jacobi-Bellman dynamic programming PDE. When log excess stock returns \(r_{t+1}\) are predicted by an AR(1) valuation state variable \(x_t\) with innovation correlation \(\rho < 0\), the optimal portfolio weight decomposes additively into a static myopic component \(\alpha_{\mathrm{myopic}} = \frac{\mu - r}{\gamma \sigma^2}\) and an intertemporal hedging demand \(\alpha_{\mathrm{hedge}} = (1 - 1/\gamma) (-\frac{\rho \sigma_\eta}{\sigma}) \frac{1 - \phi^\tau}{1 - \phi} \frac{\beta}{\sigma^2}\), confirming Campbell & Viceira (2002). Furthermore, non-tradable human capital \(H_t = \sum_{s=t}^R \frac{Y_s}{(1+r)^{s-t}}\) acts as an implicit asset, scaling financial equity demand to \(\alpha_t^F = \alpha_t^{\mathrm{tot}} + (\alpha_t^{\mathrm{tot}} - \beta_H) \frac{H_t}{W_t}\).

2. Empirical Policy Benchmark & Sequence-of-Returns Risk: Simulating 10,000 paths over a 40-year career under CRRA utility (\(\gamma = 4.0\)), the 'To-Retirement' glide path (gliding from 90% equity at age 40 to 30% at age 65) limits the 95th percentile late sequence-of-returns drawdown (ages 60–65) to 11.89%, with certainty equivalent wealth of \(\$957,533\). In contrast, the 'Through-Retirement' glide path (landing at 50% equity at 65) expands the 95th percentile late drawdown to 18.47% (+55.3% higher downside tail ruin), yielding a slightly lower CE wealth of \(\$952,709\). The Static 60/40 allocation exhibits acute sequence-of-returns vulnerability (95th percentile drawdown of 20.44%) and the lowest CE wealth (\(\$941,934\), a welfare loss of 1.63%). The Dynamic Optimal policy, by adapting to realized valuation state shocks and individual wealth accumulation, achieves superior welfare, demonstrating that mechanical deterministic glide paths impose substantial certainty equivalent penalties by ignoring intertemporal hedging dynamics.

Rubric mapping: Meets Level 4 on C1 (rigorous Merton/Campbell-Viceira HJB decomposition with exact locators), C2 (human capital discounting and wage beta formula), C3 (complete 4-policy simulation isolating late sequence drawdown), C4 (exact CRRA certainty equivalent reporting with percentage welfare losses), and C5 (concrete policy comparison for pension plan sponsors).

Adversarial Defense Question Bank

Prepare to defend your research report and simulation findings against the following 15 adversarial defense angles during executive committee review:

  1. By Samuelson's (1969, 1979) theorem, optimal equity weights under i.i.d. returns and CRRA utility are strictly horizon-invariant. Why does your model generate declining equity glide paths?
  2. If human capital is non-tradable and cannot be pledged as collateral, how do you handle borrowing constraints when unconstrained allocation exceeds 100%?
  3. Empirical estimates of labour income beta \(\beta_H\) are noisy. If a worker in a cyclical industry is mistakenly modeled as having safe wages, what is the welfare cost?
  4. The Campbell & Viceira (2002) analytical framework relies on log-linear approximations around the unconditional mean. Where does this approximation break down?
  5. Stambaugh (1999) proved that predictive regressions with persistent regressors and correlated shocks suffer severe finite-sample upward bias. How does parameter uncertainty alter your hedging demand?
  6. Why is a 30% drawdown at age 62 fatal to a retiree, whereas the identical percentage drawdown at age 28 is easily absorbed?
  7. Commercial TDFs face tracking error, cash-flow friction, and trading spreads. How do rebalancing transaction costs alter your dynamic policy advantage?
  8. 'To-Retirement' glide paths minimize sequence-of-returns drawdown but maximize post-retirement inflation and longevity ruin. How does your model balance these offsetting risks?
  9. Prove mathematically why an investor with \(\gamma = 1\) (log utility) holds zero intertemporal hedging demand even when returns are highly predictable and \(\rho = -0.90\).
  10. Real-world earnings feature uninsurable idiosyncratic shocks, unemployment spells, and health shocks. Why does uninsurable labour risk reduce risky asset demand?
  11. Power utility equates risk aversion \(\gamma\) to the reciprocal of the elasticity of intertemporal substitution (\(1/\psi\)). How would separating risk aversion from EIS alter consumption smoothing?
  12. Why does cash subject long-horizon retirees to substantial reinvestment risk, and why does a duration-matched bond portfolio provide the true riskless benchmark?
  13. For the median household, residential real estate is the largest asset. How should owner-occupied housing be integrated alongside human capital?
  14. In a 401(k) auto-enrollment plan, participants differ widely in wealth, wage growth, and risk aversion. Can any single deterministic glide path be optimal for a heterogeneous population?
  15. Welch & Goyal (2008) showed that predictive regressions often fail to beat the historical mean out-of-sample. If return predictability is spurious, does the hedging demand become toxic?
