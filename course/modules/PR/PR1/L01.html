Mean-Variance Inputs and the Estimation Error

  • Introduces: mean-variance estimation error

Markowitz mean-variance optimization assumes known expected returns and covariances. In real markets, these quantities must be estimated from finite sample histories. Because portfolio weights invert the sample covariance matrix, minor estimation errors in expected returns are amplified into violent weight swings, extreme leverage, and severe out-of-sample disappointment.

1The Mean-Variance Allocation Framework

Consider an investment universe of \(N \ge 2\) risky assets evaluated over a single holding period. Let \(r = (r_1, \dots, r_N)^\top\) denote the vector of simple returns with population expected return vector \(\mu = \E[r] \in \R^N\) and population covariance matrix \(\Sigma = \Cov(r) \in \R^{N \times N}\). Throughout this unit, all return quantities are per-period simple returns without annualization.

A portfolio is defined by its allocation weight vector \(w = (w_1, \dots, w_N)^\top \in \R^N\). The full-investment budget constraint requires \(\iota^\top w = 1\), where \(\iota = (1, \dots, 1)^\top \in \R^N\) is the vector of ones. The investor maximizes quadratic risk tolerance with risk aversion parameter \(\gamma > 0\), or equivalently minimizes the quadratic cost objective:

\[ \begin{aligned} \min_{w \in \R^N} \quad & \frac{\gamma}{2} w^\top \Sigma w - \mu^\top w \\ \text{subject to} \quad & \iota^\top w = 1 \end{aligned} \]
Definition 1.1 (Mean-Variance Estimation Error)

In empirical portfolio construction, the true population parameters \((\mu, \Sigma)\) are unobservable and are replaced by sample estimators \((\hat{\mu}, S)\) computed over a historical window of \(T\) observations. Mean-variance estimation error is the deviation between the plug-in sample weight vector \(\hat{w} = w(\hat{\mu}, S)\) and the true optimal allocation \(w^* = w(\mu, \Sigma)\), defined by \(\Delta w = \hat{w} - w^*\).

Theorem 1.1 (Unconstrained Mean-Variance Weights)

Assumption A1 (Positive Definite Covariance): The covariance matrix \(\Sigma \in \R^{N \times N}\) is symmetric and strictly positive definite, so \(\Sigma^{-1}\) exists and \(w^\top \Sigma w > 0\) for all \(w \neq 0\).

Under Assumption A1, the unique analytical solution to the unconstrained budget-constrained mean-variance optimization problem is given by

\[ \begin{aligned} w^* = \frac{\Sigma^{-1} \iota}{\iota^\top \Sigma^{-1} \iota} + \frac{1}{\gamma} \left( \Sigma^{-1} \mu - \frac{\iota^\top \Sigma^{-1} \mu}{\iota^\top \Sigma^{-1} \iota} \Sigma^{-1} \iota \right) \end{aligned} \]
Proof

Formulate the Lagrangian with scalar multiplier \(\nu \in \R\) corresponding to the budget constraint \(\iota^\top w = 1\):

\[ \begin{aligned} \mathcal{L}(w, \nu) = \frac{\gamma}{2} w^\top \Sigma w - \mu^\top w + \nu (\iota^\top w - 1) \end{aligned} \]

By the KKT conditions for strictly convex quadratic programming, the stationarity condition requires

\[ \begin{aligned} \nabla_w \mathcal{L}(w, \nu) = \gamma \Sigma w - \mu + \nu \iota = 0 \implies w = \frac{1}{\gamma} \Sigma^{-1} (\mu - \nu \iota) \end{aligned} \]

Premultiplying by \(\iota^\top\) and enforcing the primal feasibility condition \(\iota^\top w = 1\):

\[ \begin{aligned} 1 = \frac{1}{\gamma} \left( \iota^\top \Sigma^{-1} \mu - \nu \iota^\top \Sigma^{-1} \iota \right) \implies \nu = \frac{\iota^\top \Sigma^{-1} \mu - \gamma}{\iota^\top \Sigma^{-1} \iota} \end{aligned} \]

Substituting \(\nu\) back into the stationarity expression yields the stated two-fund decomposition.

2Sensitivity of Weights to Return and Covariance Perturbations

To analyze how statistical errors in \(\hat{\mu}\) perturb portfolio weights, we evaluate the gradient of \(w^*(\mu)\) with respect to the expected return vector \(\mu\). Differentiating the closed-form weight expression yields

\[ \begin{aligned} \frac{\partial w^*}{\partial \mu^\top} = \frac{1}{\gamma} \left( \Sigma^{-1} - \frac{\Sigma^{-1} \iota \iota^\top \Sigma^{-1}}{\iota^\top \Sigma^{-1} \iota} \right) \end{aligned} \]

The sensitivity matrix \(\partial w^* / \partial \mu^\top\) is proportional to the inverse covariance matrix \(\Sigma^{-1}\) projected onto the subspace orthogonal to \(\iota\). If two assets have high correlation, the smallest eigenvalue of \(\Sigma\) is close to zero, causing the eigenvalues of \(\Sigma^{-1}\) to become enormous. Consequently, a tiny perturbation in expected returns produces massive, offsetting allocations across correlated assets.

Remark 1.1 (Relative Severity: Means vs Covariances)

Chopra and Ziemba demonstrated through cash-equivalent loss metrics that errors in expected returns are an order of magnitude more damaging than errors in variances, which in turn are more critical than errors in covariances. Intuitively, estimating the mean of a return process requires an order of magnitude more historical data than estimating its second central moments.

3Numerical Verification: Two-Asset Perturbation Lab

The following inline lab computes exact unconstrained mean-variance weights in Fraction arithmetic for a two-asset universe. It measures the weight dislocation induced by a single 1% perturbation in the expected return of Asset 1.

Lab 1 · Estimation error sensitivity in a two-asset universe

Verifies that a 1% perturbation in expected returns produces an amplified 4.55% dislocation in optimal weights due to covariance matrix inversion.

"""Lab 1: Estimation error sensitivity in two-asset mean-variance allocation.

Illustrative inputs in exact Fraction arithmetic.
Computes unconstrained mean-variance weights at the true expected return vector
and at a perturbed estimate (+1% on asset 1), demonstrating the amplification
of input estimation errors into portfolio weights.
"""

from __future__ import annotations

from fractions import Fraction


def mv_weights(sigma: list[list[Fraction]], mu: list[Fraction], gamma: Fraction) -> list[Fraction]:
    """Compute unconstrained mean-variance weights for a two-asset universe."""
    det = sigma[0][0] * sigma[1][1] - sigma[0][1] * sigma[1][0]
    inv = [
        [sigma[1][1] / det, -sigma[0][1] / det],
        [-sigma[1][0] / det, sigma[0][0] / det],
    ]
    inv_iota = [inv[0][0] + inv[0][1], inv[1][0] + inv[1][1]]
    iota_inv_iota = inv_iota[0] + inv_iota[1]
    inv_mu = [
        inv[0][0] * mu[0] + inv[0][1] * mu[1],
        inv[1][0] * mu[0] + inv[1][1] * mu[1],
    ]
    iota_inv_mu = inv_mu[0] + inv_mu[1]
    nu = (iota_inv_mu - gamma) / iota_inv_iota
    return [(inv_mu[i] - nu * inv_iota[i]) / gamma for i in range(2)]


def main() -> None:
    sigma = [
        [Fraction(4, 100), Fraction(1, 100)],
        [Fraction(1, 100), Fraction(9, 100)],
    ]
    mu_true = [Fraction(5, 100), Fraction(3, 100)]
    mu_pert = [Fraction(6, 100), Fraction(3, 100)]
    gamma = Fraction(2)

    w_true = mv_weights(sigma, mu_true, gamma)
    w_pert = mv_weights(sigma, mu_pert, gamma)
    delta_w = [w_pert[i] - w_true[i] for i in range(2)]

    print(f"True weights: {[str(x) for x in w_true]}")
    print(f"Perturbed weights: {[str(x) for x in w_pert]}")
    print(f"Weight change: {[str(x) for x in delta_w]}")
    print(f"Weight change decimal: {[round(float(x), 6) for x in delta_w]}")


main()
True weights: ['9/11', '2/11']
Perturbed weights: ['19/22', '3/22']
Weight change: ['1/22', '-1/22']
Weight change decimal: [0.045455, -0.045455]

Under true inputs \(\mu = (0.05, 0.03)\) and \(\gamma = 2\), the optimal allocation is \(w^* = (9/11, 2/11) \approx (0.8182, 0.1818)\). When \(\mu_1\) is perturbed upward by 1% to 0.06, the weights shift to \((19/22, 3/22) \approx (0.8636, 0.1364)\). The weight dislocation is exactly \(\Delta w = (1/22, -1/22) \approx (+0.045455, -0.045455)\). The 1% estimation error is magnified by a factor of 4.55 in the portfolio weights.

4Where the canon breaks

The textbook Markowitz formulation implicitly assumes that sample moments converge rapidly to population parameters. However, in financial time series:

  • Non-stationarity: Financial distributions undergo structural breaks, regime switches, and time-varying volatility. Extending the sample window \(T\) introduces obsolete data regimes, increasing bias while reducing sampling variance.
  • Ill-conditioning: As the universe size \(N\) grows relative to sample size \(T\), the condition number of the sample covariance matrix \(\kappa(S) = \lambda_{\max}(S) / \lambda_{\min}(S)\) explodes toward infinity, compounding weight volatility.
  • Out-of-sample breakdown: A portfolio optimized on sample inputs maximizes in-sample Sharpe ratio but almost universally underperforms simple heuristics like 1/N out of sample due to parameter estimation error.

5Misconceptions

  1. Increasing the historical sample size T will always eliminate mean-variance estimation error in practice.

    While the law of large numbers guarantees asymptotic consistency for stationary i.i.d. processes, empirical financial returns exhibit structural changes, corporate events, and shifting macroeconomic regimes. Using 30 years of equity data to estimate contemporary expected returns incorporates obsolete economic environments, introducing severe model bias.

  2. Covariance estimation errors are more dangerous than expected return errors because the covariance matrix contains N(N+1)/2 parameters.

    Chopra and Ziemba proved that expected return errors exert an effect an order of magnitude larger than covariance errors on portfolio utility loss. Although the covariance matrix has more parameters, expected returns enter the objective linearly and directly govern directional asset tilts.

  3. Imposing a long-only constraint (w >= 0) eliminates estimation error.

    Non-negativity constraints prevent infinite short leverage and dampen extreme corner solutions, but they do not eliminate estimation error. In fact, long-only optimizers frequently peg multiple assets at 0% allocation based purely on downward statistical noise, producing severe under-diversification.

6Problem set

M1 · Two-asset analytical weights

For two uncorrelated assets with variances \(\sigma_1^2 = 0.04\) and \(\sigma_2^2 = 0.09\), risk aversion \(\gamma = 2\), and expected returns \(\mu_1 = 0.08\) and \(\mu_2 = 0.04\), calculate the unconstrained optimal weight \(w_1\).

Solution

For uncorrelated assets, \(\Sigma = \diag(0.04, 0.09)\). The inverse covariance is \(\Sigma^{-1} = \diag(25, 11.1111)\). The GMV weight is \(w_{\text{GMV}, 1} = 25 / (25 + 11.1111) = 25 / 36.1111 = 0.6923\). The speculative component is \((1/\gamma) (\sigma_1^{-2} \mu_1 - \bar{\mu}_{\Sigma} \sigma_1^{-2})\), where \(\iota^\top \Sigma^{-1} \mu = 25(0.08) + 11.1111(0.04) = 2.0 + 0.4444 = 2.4444\). The multiplier is \(\nu = (2.4444 - 2) / 36.1111 = 0.0123\). Thus \(w_1 = (25 / 2) [0.08 - 0.0123] = 12.5(0.0677) = 0.8462\). Exactly, \(w_1 = 11/13\).

M2 · Weight sensitivity calculation

Using the sensitivity matrix formula \(\partial w^* / \partial \mu^\top\), compute the derivative \(\partial w_1 / \partial \mu_1\) for two uncorrelated assets with equal variance \(\sigma^2 = 0.04\) and \(\gamma = 2\).

Solution

When \(\Sigma = \sigma^2 I_2\), \(\Sigma^{-1} = (1/\sigma^2) I_2\). Then \(\iota^\top \Sigma^{-1} \iota = 2 / \sigma^2\). The projection term is \(\Sigma^{-1} \iota \iota^\top \Sigma^{-1} / (2/\sigma^2) = (1 / 2\sigma^2) \iota \iota^\top\). Thus \(\partial w^* / \partial \mu^\top = (1 / 2\gamma \sigma^2) (2 I_2 - \iota \iota^\top)\). For the diagonal entry \((1, 1)\), the matrix value is \(2 - 1 = 1\). Therefore, \(\partial w_1 / \partial \mu_1 = 1 / (2 \gamma \sigma^2) = 1 / (2 \times 2 \times 0.04) = 1 / 0.16 = 6.25\). A 1% increase in \(\mu_1\) increases \(w_1\) by 6.25%.

M3 · Cash-equivalent loss of suboptimality

An investor with utility \(U(w) = w^\top \mu - \frac{\gamma}{2} w^\top \Sigma w\) implements weights \(\hat{w}\) instead of optimal weights \(w^*\). Derive the utility loss \(U(w^*) - U(\hat{w})\) in terms of \(\Delta w = \hat{w} - w^*\).

Solution

Expand the utility function around \(w^*\): \(U(\hat{w}) = (\mu - \gamma \Sigma w^*)^\top \Delta w - \frac{\gamma}{2} \Delta w^\top \Sigma \Delta w + U(w^*)\). By the first-order condition, \(\mu - \gamma \Sigma w^* = \nu \iota\). Because both \(w^*\) and \(\hat{w}\) satisfy the budget constraint \(\iota^\top w = 1\), the difference satisfies \(\iota^\top \Delta w = 0\). Thus the linear term vanishes: \(\nu \iota^\top \Delta w = 0\). The exact cash-equivalent utility loss is \(\Delta U = \frac{\gamma}{2} \Delta w^\top \Sigma \Delta w\), which is strictly positive for any non-zero \(\Delta w\).

P1 · Invariance to return shifts

Prove that shifting all expected returns by a constant scalar \(c \in \R\) (\(\mu \to \mu + c \iota\)) leaves unconstrained mean-variance portfolio weights completely unchanged.

Solution

Consider the speculative portfolio component \(w_{\text{spec}} = (1/\gamma) [\Sigma^{-1} \mu - \frac{\iota^\top \Sigma^{-1} \mu}{\iota^\top \Sigma^{-1} \iota} \Sigma^{-1} \iota]\). Replace \(\mu\) with \(\mu + c \iota\). The first term becomes \(\Sigma^{-1} \mu + c \Sigma^{-1} \iota\). The second term becomes \(\frac{\iota^\top \Sigma^{-1} (\mu + c \iota)}{\iota^\top \Sigma^{-1} \iota} \Sigma^{-1} \iota = \frac{\iota^\top \Sigma^{-1} \mu}{\iota^\top \Sigma^{-1} \iota} \Sigma^{-1} \iota + c \frac{\iota^\top \Sigma^{-1} \iota}{\iota^\top \Sigma^{-1} \iota} \Sigma^{-1} \iota = \frac{\iota^\top \Sigma^{-1} \mu}{\iota^\top \Sigma^{-1} \iota} \Sigma^{-1} \iota + c \Sigma^{-1} \iota\). The scalar terms \(+ c \Sigma^{-1} \iota\) exactly cancel in the subtraction, leaving \(w^*\) invariant.

P2 · Orthogonality of weight errors

Prove that for any two valid budget-constrained portfolios \(w_a\) and \(w_b\), the weight difference vector \(\Delta w = w_a - w_b\) lies in the null space of \(\iota^\top\).

Solution

Since both portfolios satisfy the budget constraint, \(\iota^\top w_a = 1\) and \(\iota^\top w_b = 1\). By the linearity of the inner product, \(\iota^\top \Delta w = \iota^\top (w_a - w_b) = \iota^\top w_a - \iota^\top w_b = 1 - 1 = 0\). Thus, \(\Delta w \in \ker(\iota^\top)\), proving that all rebalancing dislocations represent zero-net-investment long-short arbitrage vectors.

P3 · Positive semidefiniteness of sensitivity

Prove that the sensitivity matrix \(M = \Sigma^{-1} - \frac{\Sigma^{-1} \iota \iota^\top \Sigma^{-1}}{\iota^\top \Sigma^{-1} \iota}\) is symmetric and positive semidefinite with rank \(N - 1\).

Solution

Symmetry follows from \(\Sigma = \Sigma^\top\). For any \(x \in \R^N\), let \(y = \Sigma^{-1/2} x\) and \(u = \Sigma^{-1/2} \iota\). Then \(x^\top M x = y^\top y - \frac{(y^\top u)^2}{u^\top u} = \|y\|_2^2 - \frac{\langle y, u \rangle^2}{\|u\|_2^2}\). By the Cauchy-Schwarz inequality, \(\langle y, u \rangle^2 \le \|y\|_2^2 \|u\|_2^2\), which implies \(x^\top M x \ge 0\) for all \(x\). Equality holds if and only if \(y\) is collinear with \(u\), meaning \(x \propto \iota\). Thus \(\ker(M) = \operatorname{span}(\iota)\), confirming that \(M\) is positive semidefinite with rank \(N - 1\).

E1 · Required sample size for mean estimation

For an equity index with true expected return \(\mu = 0.08\) and annual volatility \(\sigma = 0.20\), how many years of data \(T\) are required to reject the null hypothesis \(H_0: \mu = 0\) at the 5% significance level (\(z = 1.96\))?

Solution

The standard error of the sample mean is \(\text{SE}(\hat{\mu}) = \sigma / \sqrt{T}\). To achieve a t-statistic of 1.96: \(\frac{\mu}{\sigma / \sqrt{T}} \ge 1.96 \implies \sqrt{T} \ge 1.96 \frac{\sigma}{\mu} = 1.96 \left(\frac{0.20}{0.08}\right) = 1.96(2.5) = 4.90\). Squaring both sides yields \(T \ge 4.90^2 = 24.01\) years. Over two decades of stationary return data are needed simply to statistically distinguish equity expected returns from zero.

E2 · Condition number and eigenvalue dispersion

A sample covariance matrix of 4 assets has eigenvalues \((0.16, 0.04, 0.01, 0.001)\). Compute its condition number \(\kappa(S)\) and discuss its implications for inversion stability.

Solution

The condition number in the \(L_2\) norm is \(\kappa(S) = \lambda_{\max} / \lambda_{\min} = 0.16 / 0.001 = 160\). In matrix inversion, relative errors in input data can be amplified by up to \(\kappa(S)\). An eigenvalue of 0.001 means a linear combination of assets has nearly zero estimated variance, causing the optimizer to place massive leveraged bets along that eigenvector.

E3 · Tracking error of perturbed weights

In Lab 1, true weights are \(w^* = (9/11, 2/11)\) and perturbed weights are \(\hat{w} = (19/22, 3/22)\). Compute the variance of the tracking error portfolio \(w_{\text{diff}} = \hat{w} - w^*\) under the true covariance matrix \(\Sigma\).

Solution

The weight difference is \(\Delta w = (1/22, -1/22)\). The tracking error variance is \(\Var(\Delta w^\top r) = \Delta w^\top \Sigma \Delta w\). Computing the quadratic form: \(\Sigma \Delta w = \begin{pmatrix} 0.04 & 0.01 \\ 0.01 & 0.09 \end{pmatrix} \begin{pmatrix} 1/22 \\ -1/22 \end{pmatrix} = \begin{pmatrix} 0.03/22 \\ -0.08/22 \end{pmatrix}\). Then \(\Delta w^\top \Sigma \Delta w = \frac{1}{22}(0.03/22) - \frac{1}{22}(-0.08/22) = \frac{0.03 + 0.08}{484} = \frac{0.11}{484} = \frac{11}{48400} = \frac{1}{4400} \approx 0.00022727\). The tracking volatility is \(\sqrt{1/4400} \approx 0.015075\) (1.51% per period).

R1 · Michaud's enigma

Critique Michaud's assertion that mean-variance optimizers act as 'error maximizers'. How does this statistical property relate to order statistics?

Solution

When selecting assets based on sample rankings, extreme estimates in the upper tail of the sampling distribution are predominantly driven by positive estimation noise rather than high true parameters. Because the optimizer solves an unconstrained argmax over linear combinations of sample means, it naturally assigns the largest positive weights to the highest positive sampling errors. This aligns directly with extreme value theory and winner's curse phenomena in econometric selection.

R2 · Shrinkage vs constraints

Compare how non-negativity constraints (\(w \ge 0\)) and ridge shrinkage (\(\Sigma + \lambda I\)) mitigate estimation error.

Solution

Non-negativity constraints act as endogenously generated, data-dependent shrinkage: Jagannathan and Ma (2003) proved that imposing \(w_i \ge 0\) is mathematically equivalent to optimizing without constraints on a shrunk covariance matrix where elements with binding bounds have adjusted covariances. Ridge shrinkage directly lifts the spectrum by \(\lambda\), bounding the condition number \(\kappa(\Sigma_\lambda) \le (\lambda_{\max} + \lambda) / (\lambda_{\min} + \lambda)\). While ridge regularizes all directions symmetrically, constraints prune extreme short leverage.

R3 · Asymmetric loss functions

Why is the quadratic utility loss function \(\Delta U = \frac{\gamma}{2} \Delta w^\top \Sigma \Delta w\) symmetric, and why might an institutional fund manager face an asymmetric loss function in practice?

Solution

The mathematical quadratic objective is symmetric because deviations above and below optimal variance are penalized equally. In practice, fund managers operate under institutional mandates with benchmark tracking, drawdown covenants, and asymmetric incentive fees (option-like compensation). Underperforming a benchmark threatens career survival (reputational risk), whereas outperforming produces linear upside, creating strongly convex, downside-averse empirical loss functions.

8Retrieval quiz

  1. What is the primary mathematical reason that mean-variance portfolio weights are highly sensitive to expected return estimation errors?

    Options

    Optimal weights depend on \(\Sigma^{-1} \mu\). When assets are correlated, \(\Sigma\) possesses small eigenvalues whose inverses are large, massively amplifying sampling errors in \(\mu\).

  2. In Lab 1, what is the ratio of the percentage weight dislocation to the 1% percentage return perturbation (expressed as a scalar amplification factor)?

    A 1% perturbation (0.01) creates a weight dislocation of \(1/22 \approx 0.045455\) (4.55%), giving an amplification factor of 4.55.

  3. According to Chopra and Ziemba (1993), which type of parameter error causes the greatest cash-equivalent utility loss in portfolio choice?

    Options

    Errors in expected returns are an order of magnitude more damaging to portfolio utility than errors in variances or covariances.

  4. What happens to the optimal unconstrained mean-variance portfolio if all asset expected returns increase by exactly 2% (\(\mu \to \mu + 0.02 \iota\))?

    Options

    Because the speculative portfolio component projects \(\mu\) onto the subspace orthogonal to \(\iota\), shifting \(\mu\) by a constant scalar cancel out exactly.

  5. What is the exact cash-equivalent utility loss \(\Delta U\) incurred by implementing an arbitrary budget-constrained portfolio \(\hat{w}\) instead of the true optimal portfolio \(w^*\)?

    Options

    By expanding the quadratic objective around \(w^*\) and utilizing \(\iota^\top (\hat{w} - w^*) = 0\), the linear term vanishes and the loss equals \(\frac{\gamma}{2} \Delta w^\top \Sigma \Delta w\).

  6. For an asset with annual expected return 8% and volatility 20%, roughly how many years of historical data are required to achieve a t-statistic of 1.96 for testing \(\mu = 0\)?

    \(T \ge (1.96 \times 0.20 / 0.08)^2 = (4.9)^2 = 24.01\) years.

  7. Why does adding a non-negativity constraint (\(w \ge 0\)) fail to completely solve the problem of estimation error?

    Options

    While non-negativity prevents extreme leverage, it causes the optimizer to prune assets whose expected returns are slightly underestimated, resulting in concentrated portfolios.

  8. What is the null space of the weight sensitivity matrix \(M = \Sigma^{-1} - \frac{\Sigma^{-1} \iota \iota^\top \Sigma^{-1}}{\iota^\top \Sigma^{-1} \iota}\)?

    Options

    \(M \iota = \Sigma^{-1} \iota - \frac{\Sigma^{-1} \iota (\iota^\top \Sigma^{-1} \iota)}{\iota^\top \Sigma^{-1} \iota} = 0\), so any vector proportional to \(\iota\) is mapped to zero.
