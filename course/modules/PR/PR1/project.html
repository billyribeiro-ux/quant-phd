Allocator Shoot-Out

Compare sample mean-variance, shrinkage mean-variance, the Black-Litterman model, global minimum variance, and 1/N naive diversification out of sample under realistic turnover costs, and evaluate the credibility of empirical allocator rankings.

  • Deliverables: Python allocation module (allocators.py) and evaluation memo (report.md)
  • Evaluation: Dual mode (autograder for code; rubric for evaluation memo)
  • Time budget: 20 hours (28.6% of module hours)

The project follows a four-rung ladder from concrete worked examples to independent implementation and open-ended research extension.

  1. Worked example

    A complete, annotated derivation of 1/N and global minimum-variance weights on a three-asset window in exact Fraction arithmetic.

Rung 1 · Worked example

Lab 1 · Worked example: 1/N benchmark and minimum-variance weights

Computes 1/N equal weighting and global minimum-variance portfolio weights on a fixed 3-asset, 6-observation return window in exact Fraction arithmetic.

"""Rung 1 worked example: 1/N equal weighting and global minimum variance.

Illustrative inputs in exact Fraction arithmetic.
Fully solves a three-asset, six-observation investment window:
1. 1/N equal weight benchmark.
2. Sample mean return vector.
3. Unbiased sample covariance matrix S with divisor T - 1 = 5.
4. Analytical global minimum-variance (GMV) portfolio weights.
"""

from __future__ import annotations

from fractions import Fraction


def main() -> None:
    # 3 assets over 6 observation periods (T = 6, N = 3)
    returns = [
        [Fraction(2, 100), Fraction(1, 100), Fraction(3, 100)],
        [Fraction(4, 100), Fraction(2, 100), Fraction(-1, 100)],
        [Fraction(-1, 100), Fraction(3, 100), Fraction(2, 100)],
        [Fraction(3, 100), Fraction(-1, 100), Fraction(4, 100)],
        [Fraction(1, 100), Fraction(4, 100), Fraction(1, 100)],
        [Fraction(3, 100), Fraction(3, 100), Fraction(3, 100)],
    ]
    t_obs = len(returns)
    n_assets = len(returns[0])

    # Step 1: 1/N equal weight allocation
    w_1n = [Fraction(1, n_assets)] * n_assets
    print("Step 1 1/N weights:", [str(x) for x in w_1n])

    # Step 2: Sample mean return vector mu_hat
    mu_hat = [sum((returns[t][i] for t in range(t_obs)), Fraction(0)) / Fraction(t_obs) for i in range(n_assets)]
    print("Step 2 sample mean mu_hat:", [str(x) for x in mu_hat])

    # Step 3: Unbiased sample covariance matrix (divisor T - 1)
    s_cov = [[Fraction(0)] * n_assets for _ in range(n_assets)]
    for t in range(t_obs):
        diff = [returns[t][i] - mu_hat[i] for i in range(n_assets)]
        for i in range(n_assets):
            for j in range(n_assets):
                s_cov[i][j] += diff[i] * diff[j]
    for i in range(n_assets):
        for j in range(n_assets):
            s_cov[i][j] /= Fraction(t_obs - 1)
    print("Step 3 sample covariance diagonal:", [str(s_cov[i][i]) for i in range(n_assets)])

    # Step 4: Minimum variance portfolio weights w_gmv = S^-1 iota / (iota' S^-1 iota)
    size = n_assets
    a_mat = [row[:] for row in s_cov]
    inv = [[Fraction(1 if i == j else 0) for j in range(size)] for i in range(size)]
    for col in range(size):
        pivot = next(r for r in range(col, size) if a_mat[r][col] != 0)
        a_mat[col], a_mat[pivot] = a_mat[pivot], a_mat[col]
        inv[col], inv[pivot] = inv[pivot], inv[col]
        p = a_mat[col][col]
        for j in range(size):
            a_mat[col][j] /= p
            inv[col][j] /= p
        for r in range(size):
            if r != col and a_mat[r][col] != 0:
                factor = a_mat[r][col]
                for j in range(size):
                    a_mat[r][j] -= factor * a_mat[col][j]
                    inv[r][j] -= factor * inv[col][j]

    inv_iota = [sum((inv[i][j] for j in range(n_assets)), Fraction(0)) for i in range(n_assets)]
    denom = sum(inv_iota, Fraction(0))
    w_gmv = [inv_iota[i] / denom for i in range(n_assets)]
    print("Step 4 GMV weights:", [str(x) for x in w_gmv])

Rung 3 · Independent project

In this independent project, you build an automated multi-asset portfolio allocator module (allocators.py) and write an executive evaluation memo (report.md) analyzing an out-of-sample shoot-out between five portfolio construction methods.

Context
A quantitative asset management firm requires an objective out-of-sample evaluation of five portfolio construction methodologies: (1) 1/N naive diversification, (2) sample mean-variance optimization, (3) linear covariance shrinkage mean-variance, (4) the Black-Litterman model, and (5) global minimum variance. You must test these allocators in an honest rolling backtest with transaction costs, explain the resulting performance ranking, and quantify statistical uncertainty.
Inputs
The evaluation harness provides a synthetic multi-asset investment environment via make_instance(seed: int) (SIMULATED data). The returned dictionary contains:
  • names: List of \(N \in \{4, 5, 6\}\) asset identifiers.
  • returns: Matrix of \(H = 120\) monthly returns across \(N\) assets.
  • window: Historical estimation window length \(T = 60\) periods.
  • gamma: Investor risk aversion parameter \(\gamma \in [2.0, 5.0]\).
  • delta: Covariance shrinkage intensity \(\delta \in [0.2, 0.8]\).
  • tau: Black-Litterman prior uncertainty scalar \(\tau \in [0.02, 0.10]\).
  • w_mkt: Market capitalization weight vector summing to 1.0.
  • P, q, omega: View pick matrix (\(k \times N\)), view return vector (\(k\)), and diagonal view error variances.
  • cost_rate: Proportional fee rate per unit of one-way turnover (\(c \in \{0.0005, 0.0010, 0.0020\}\)).
Required outputs
  • allocators.py: Exposes six standard-library functions:
    • equal_weight(n: int) -> list[float]
    • sample_mv(window: list[list[float]], gamma: float) -> list[float]
    • shrinkage_mv(window: list[list[float]], gamma: float, delta: float) -> list[float]
    • black_litterman(window: list[list[float]], w_mkt: list[float], tau: float, p: list[list[float]], q: list[float], omega: list[float], gamma: float) -> list[float]
    • min_variance(window: list[list[float]]) -> list[float]
    • run_backtest(instance: dict[str, Any], method: str) -> dict[str, Any]
  • report.md: A two-page executive memo reporting out-of-sample results on seed 3, tabulating gross and net Sharpe ratios, detailing turnover drag, computing standard errors for performance differences, and identifying core model limitations.
Constraints
  • Long-only full investment: All portfolio weights must satisfy \(\iota^\top w = 1.0\) (tolerance \(10^{-8}\)) and \(w_i \ge 0.0\) (tolerance \(10^{-11}\)).
  • Strict rolling timing: Rebalancing at date \(t \in \{T, \dots, H - 1\}\) conditions strictly on historical returns \(r_{t-T}\) through \(r_{t-1}\). Conditioning on \(r_t\) is prohibited (look-ahead defect).
  • Turnover and cost conventions: One-way turnover is \(\tau_t = \sum_{i=1}^N |w_{t,i} - w_{t-1,i}|\) (sum of absolute changes, not halved). Initial allocation is \(w_0 = \iota / N\). Net return is \(n_t = w_t^\top r_t - c \tau_t\).
  • Sharpe ratio: Per-period net Sharpe ratio uses the sample standard deviation with divisor \(K - 1\): \(\SR = \bar{n} / s_n\). No annualization factor is applied.
  • Failure handling: Windows with \(T \le N\) must raise ValueError in sample_mv, min_variance, and black_litterman. In shrinkage_mv, \(T \le N\) raises ValueError only when \(\delta = 0.0\). Values of \(\delta \notin [0, 1]\), ragged windows, non-finite values, and negative cost rates must raise ValueError.

Lab 3 · Reference benchmark: Allocator shoot-out on seed 3

Executes the reference backtest on instance seed 3 and prints the benchmark out-of-sample performance table.

"""Lab PR1-project-3: Rung 3 independent project reference benchmark (seed 3).

SIMULATED: generates the reference instance for seed 3 and executes the full
out-of-sample backtest across all five allocation methods under proportional
turnover costs (10 bps). Prints the benchmark allocator shoot-out table
against which the student report is compared.
"""

from __future__ import annotations

import itertools
import math
import random
from typing import Any


def _solve_linear(a_mat: list[list[float]], b: list[float]) -> list[float]:
    n = len(b)
    m_sys = [[*a_mat[i], b[i]] for i in range(n)]
    for i in range(n):
        max_row = max(range(i, n), key=lambda r: abs(m_sys[r][i]))
        if abs(m_sys[max_row][i]) < 1e-14:
            raise ValueError("Singular matrix encountered.")
        if max_row != i:
            m_sys[i], m_sys[max_row] = m_sys[max_row], m_sys[i]
        pivot = m_sys[i][i]
        for j in range(i, n + 1):
            m_sys[i][j] /= pivot
        for r in range(n):
            if r != i:
                factor = m_sys[r][i]
                if factor != 0.0:
                    for j in range(i, n + 1):
                        m_sys[r][j] -= factor * m_sys[i][j]
    return [m_sys[i][n] for i in range(n)]


def _invert_matrix(a_mat: list[list[float]]) -> list[list[float]]:
    n = len(a_mat)
    inv: list[list[float]] = [[0.0] * n for _ in range(n)]
    for j in range(n):
        e_j = [1.0 if i == j else 0.0 for i in range(n)]
        col = _solve_linear(a_mat, e_j)
        for i in range(n):
            inv[i][j] = col[i]
    return inv


def _mean_and_cov(window: list[list[float]]) -> tuple[list[float], list[list[float]]]:
    t = len(window)
    n = len(window[0])
    means = [sum(window[s][i] for s in range(t)) / t for i in range(n)]
    cov = [[0.0] * n for _ in range(n)]
    for s in range(t):
        diff = [window[s][i] - means[i] for i in range(n)]
        for i in range(n):
            for j in range(n):
                cov[i][j] += diff[i] * diff[j]
    for i in range(n):
        for j in range(n):
            cov[i][j] /= t - 1
    return means, cov


def _solve_long_only_qp(q_mat: list[list[float]], c: list[float]) -> list[float]:
    n = len(c)
    for k in range(n):
        for z in itertools.combinations(range(n), k):
            z_set = set(z)
            a = [i for i in range(n) if i not in z_set]
            m = len(a)
            sys_a = [[0.0] * (m + 1) for _ in range(m + 1)]
            sys_b = [0.0] * (m + 1)
            for i_idx, i in enumerate(a):
                for j_idx, j in enumerate(a):
                    sys_a[i_idx][j_idx] = q_mat[i][j]
                sys_a[i_idx][m] = 1.0
                sys_b[i_idx] = c[i]
            for j_idx in range(m):
                sys_a[m][j_idx] = 1.0
            sys_b[m] = 1.0
            try:
                sol = _solve_linear(sys_a, sys_b)
            except ValueError:
                continue
            w_a = sol[:m]
            nu = sol[m]
            if any(x < -1e-9 for x in w_a):
                continue
            w = [0.0] * n
            for idx, i in enumerate(a):
                w[i] = max(w_a[idx], 0.0)
            tot = sum(w)
            if tot <= 1e-12:
                continue
            w = [x / tot for x in w]
            dual_ok = True
            for i in z:
                grad_i = sum(q_mat[i][j] * w[j] for j in range(n)) - c[i] + nu
                if grad_i < -1e-8:
                    dual_ok = False
                    break
            if dual_ok:
                return w
    raise RuntimeError("No KKT solution found.")


def equal_weight(n: int) -> list[float]:
    return [1.0 / n] * n


def sample_mv(window: list[list[float]], gamma: float) -> list[float]:
    mu, s = _mean_and_cov(window)
    n = len(mu)
    q = [[gamma * s[i][j] for j in range(n)] for i in range(n)]
    return _solve_long_only_qp(q, mu)


def shrinkage_mv(window: list[list[float]], gamma: float, delta: float) -> list[float]:
    mu, s = _mean_and_cov(window)
    n = len(mu)
    tr_s = sum(s[i][i] for i in range(n))
    target_scale = tr_s / n
    sigma_delta = [
        [(1.0 - delta) * s[i][j] + (delta * target_scale if i == j else 0.0) for j in range(n)] for i in range(n)
    ]
    q = [[gamma * sigma_delta[i][j] for j in range(n)] for i in range(n)]
    return _solve_long_only_qp(q, mu)


def min_variance(window: list[list[float]]) -> list[float]:
    _, s = _mean_and_cov(window)
    n = len(s)
    c = [0.0] * n
    return _solve_long_only_qp(s, c)


def black_litterman(
    window: list[list[float]],
    w_mkt: list[float],
    tau: float,
    p: list[list[float]],
    q: list[float],
    omega: list[float],
    gamma: float,
) -> list[float]:
    n = len(w_mkt)
    k = len(q)
    _, s = _mean_and_cov(window)
    s_inv = _invert_matrix(s)
    mu_eq = [gamma * sum(s[i][j] * w_mkt[j] for j in range(n)) for i in range(n)]
    tau_inv = 1.0 / tau
    m_bl = [[tau_inv * s_inv[i][j] for j in range(n)] for i in range(n)]
    for r in range(k):
        inv_om = 1.0 / omega[r]
        for i in range(n):
            for j in range(n):
                m_bl[i][j] += p[r][i] * p[r][j] * inv_om
    v_bl = [0.0] * n
    for i in range(n):
        v_bl[i] = sum(tau_inv * s_inv[i][j] * mu_eq[j] for j in range(n))
        for r in range(k):
            v_bl[i] += p[r][i] * q[r] / omega[r]
    mu_bl = _solve_linear(m_bl, v_bl)
    q_mat = [[gamma * s[i][j] for j in range(n)] for i in range(n)]
    return _solve_long_only_qp(q_mat, mu_bl)


def make_instance_seed3() -> dict[str, Any]:
    seed = 3
    rng = random.Random(seed)
    n = 4 + (seed % 3)  # n = 4
    h = 120
    window = 60
    gamma = 2.0 + (seed % 4) * 0.8
    delta = 0.25 + (seed % 5) * 0.12
    tau = 0.03 + (seed % 4) * 0.02
    cost_rates = [0.0005, 0.001, 0.002]
    cost_rate = cost_rates[seed % len(cost_rates)]
    names = [f"Asset_{chr(65 + i)}" for i in range(n)]

    raw_mkt = [1.0 + rng.random() for _ in range(n)]
    tot_mkt = sum(raw_mkt)
    w_mkt = [round(x / tot_mkt, 6) for x in raw_mkt]
    w_mkt[0] += round(1.0 - sum(w_mkt), 6)

    drift = [0.004 + 0.008 * rng.random() for _ in range(n)]
    vol = [0.03 + 0.02 * rng.random() for _ in range(n)]
    beta1 = [0.6 + 0.8 * rng.random() for _ in range(n)]
    beta2 = [-0.3 + 0.6 * rng.random() for _ in range(n)]

    returns: list[list[float]] = []
    for _ in range(h):

        f2 = rng.gauss(0.0, 0.03)
        row: list[float] = []
        for i in range(n):

            r = drift[i] + beta1[i] * f1 + beta2[i] * f2 + idio
            row.append(round(r, 6))

    # Views for seed 3 (odd seed: 2 views)

    p[0][0] = 1.0
    p[0][1] = -1.0

    q = [
        round(0.004 + 0.004 * rng.random(), 5),

    omega = [
        round(0.0003 + 0.0001 * rng.random(), 6),
        round(0.0005 + 0.0002 * rng.random(), 6),
    ]

    return {

        "returns": returns,
        "window": window,

    methods = [
        "sample_mv",

        "black_litterman",
        "min_variance",
    ]

    results: list[tuple[str, float, float, float, float]] = []

    for m in methods:
        w_prev = [1.0 / n_assets] * n_assets
        gross_list: list[float] = []
        net_list: list[float] = []
        turnover_list: list[float] = []

        for step in range(k_dates):
            t = window_len + step
            win = returns[t - window_len : t]
            if m == "equal_weight":
                w = equal_weight(n_assets)
            elif m == "sample_mv":
                w = sample_mv(win, gamma)
            elif m == "shrinkage_mv":
                w = shrinkage_mv(win, gamma, delta)
            elif m == "black_litterman":
                w = black_litterman(win, w_mkt, tau, p, q, omega, gamma)
            elif m == "min_variance":
                w = min_variance(win)

            turnover = sum(abs(w[i] - w_prev[i]) for i in range(n_assets))
            cost = cost_rate * turnover
            gross = sum(w[i] * returns[t][i] for i in range(n_assets))
            net = gross - cost

            gross_list.append(gross)
            net_list.append(net)
            turnover_list.append(turnover)
            w_prev = w

        mean_net = sum(net_list) / k_dates
        var_net = sum((x - mean_net) ** 2 for x in net_list) / (k_dates - 1)
        sr_net = mean_net / math.sqrt(var_net) if var_net > 1e-14 else 0.0

        mean_gross = sum(gross_list) / k_dates
        var_gross = sum((x - mean_gross) ** 2 for x in gross_list) / (k_dates - 1)
        sr_gross = mean_gross / math.sqrt(var_gross) if var_gross > 1e-14 else 0.0

        mean_turnover = sum(turnover_list) / k_dates
        results.append((m, sr_net, sr_gross, mean_turnover, mean_net))

    results.sort(key=lambda r: r[1], reverse=True)

    print("Rank Method              Net SR      Gross SR    Turnover    Net Return")
    print("-" * 72)
    for rank, (m_name, ns, gs, to, nr) in enumerate(results, 1):
        print(f"{rank:<5}{m_name:<20}{ns:<12.4f}{gs:<12.4f}{to:<12.4f}{nr:<12.4f}")

Exemplar A · Distinguished performance (Level 4)

Executive Evaluation Memo: Out-of-Sample Allocator Shoot-Out (Seed 3)

Input Parameter Classification: The five portfolio allocators utilize distinct input sets. The equal-weight benchmark \(w = \iota / N\) requires only asset count \(N = 4\) and zero estimation. Global minimum variance depends solely on the sample covariance matrix \(S \in \R^{4 \times 4}\). Sample mean-variance requires both the sample mean return vector \(\hat{\mu} \in \R^4\) and \(S\), together with risk aversion \(\gamma = 4.40\). Linear shrinkage mean-variance replaces \(S\) with \(\Sigma_\delta = (1 - \delta) S + \delta (\tr(S)/N) I\), utilizing shrinkage intensity \(\delta = 0.61\). The Black-Litterman model integrates the equilibrium prior \(\mu_{\text{eq}} = \gamma S w_{\text{mkt}}\) with market weights \(w_{\text{mkt}}\), scalar \(\tau = 0.09\), view matrix \(P \in \R^{2 \times 4}\), view vector \(q \in \R^2\), and diagonal uncertainty \(\Omega\). A local 10 bps perturbation in \(\hat{\mu}_1\) shifts unconstrained sample MV weights by over 45 bps, confirming the severe sensitivity proven in Lesson 1.

Rolling Out-of-Sample Protocol: Backtesting is performed across \(H = 120\) monthly periods with estimation window \(T = 60\), yielding \(K = 60\) out-of-sample evaluation dates (\(t = 60, \dots, 119\)). At each date \(t\), the optimizer conditions strictly on historical returns \(r_{t-60}\) through \(r_{t-1}\). Information realized at period \(t\) is quarantined until after portfolio weights \(w_t\) are committed. Portfolio holdings are initialized at \(w_0 = \iota / N = (0.25, 0.25, 0.25, 0.25)\). Rebalancing turnover is charged against the previous target weight \(w_{t-1}\) without intraday drift.

Turnover Frictions and Cost Drag: One-way rebalancing turnover is computed as \(\tau_t = \sum_{i=1}^4 |w_{t,i} - w_{t-1,i}|\). Transaction costs are deducted at \(c = 0.0010\) (10 basis points per unit of one-way turnover), yielding net simple return \(n_t = w_t^\top r_t - c \tau_t\). Sample MV generates substantial monthly turnover (17.39%), resulting in a 1.74 bps average monthly cost drag that depresses its Sharpe ratio from 0.2348 gross to 0.2329 net. In contrast, 1/N incurs zero rebalancing turnover after inception, preserving identical gross and net Sharpe ratios (0.1831). Linear shrinkage reduces monthly turnover from 17.39% to 13.50%, mitigating trading frictions.

Out-of-Sample Performance Ranking and Statistical Uncertainty: Over the 60 out-of-sample months on seed 3, the allocators rank by per-period net Sharpe ratio (\(\text{SR} = \bar{n} / s_n\), divisor \(K - 1 = 59\)) as follows: (1) Sample MV: \(\text{SR}_{\text{net}} = 0.2329\) (Gross 0.2348, Turnover 0.1739, Mean Net Return 0.0111); (2) Shrinkage MV: \(\text{SR}_{\text{net}} = 0.2165\) (Gross 0.2180, Turnover 0.1350, Mean Net Return 0.0101); (3) Equal Weight (1/N): \(\text{SR}_{\text{net}} = 0.1831\) (Gross 0.1831, Turnover 0.0000, Mean Net Return 0.0081); (4) Black-Litterman: \(\text{SR}_{\text{net}} = 0.1809\) (Gross 0.1811, Turnover 0.0246, Mean Net Return 0.0081); (5) Global Minimum Variance: \(\text{SR}_{\text{net}} = 0.1703\) (Gross 0.1711, Turnover 0.0735, Mean Net Return 0.0074). Under the i.i.d. delta-method formulation from Lesson 8, the standard error of the Sharpe difference between Sample MV and 1/N (\(\Delta \SR = 0.0498\)) is \(\operatorname{SE}(\Delta \SR) \approx 0.115\), yielding an asymptotic t-statistic of \(t = 0.43\). Thus, despite the apparent numerical advantage, the superiority of Sample MV over naive 1/N is statistically indistinguishable from zero over a 5-year evaluation sample.

Model Limitations and Published Counter-Evidence: All conclusions are subject to crucial model boundaries: returns are generated from a stationary multi-factor Gaussian model (SIMULATED), the shrinkage intensity is fixed rather than dynamically estimated, and turnover costs are purely linear. While DeMiguel et al. show that 1/N frequently dominates optimizing models out of sample due to parameter instability, published counter-evidence by Ledoit and Wolf demonstrates that nonlinear covariance shrinkage consistently outperforms 1/N in realistic equity panels by dampening extreme eigenvalues without incurring excessive turnover. Furthermore, as established by Chopra and Ziemba and Michaud, the ranking is highly sensitive to the sample window length \(T\): when \(T\) is small relative to \(N\), error maximization severely penalizes unregularized sample optimizers.

Exemplar B · Developing performance (Level 2)

Project Report: Portfolio Allocation Performance

We tested five portfolio strategies: 1/N, sample mean-variance, shrinkage, Black-Litterman, and minimum variance. The models use historical return data to estimate average returns and covariances. Everyone knows estimation error makes portfolios suboptimal, but we ran the optimization anyway.

We split the 120 months into two halves: the first 60 months are used to train the models, and the remaining 60 months are used to test how the portfolios perform. We updated the portfolios each month.

We deducted transaction costs from the portfolio returns. Trading costs money because whenever you change asset weights you pay fees. The sample mean-variance portfolio traded more than 1/N because 1/N does not trade.

The results show that sample mean-variance is the best model with a Sharpe ratio of 0.23, shrinkage is second at 0.22, 1/N is third at 0.18, Black-Litterman is fourth at 0.18, and minimum variance is last at 0.17. Sample mean-variance beats 1/N in our backtest.

A limitation is that market returns might change in the future. In conclusion, investors should use sample mean-variance optimization because it achieved the highest Sharpe ratio in our simulation.
