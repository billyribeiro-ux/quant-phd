Extreme Value Theory: Peaks Over Threshold & GPD

Standard risk models break down precisely where accurate estimation is vital: the deep, sparsely observed loss tail. Global parametric distributions force tail behavior to conform to central curvature, while historical simulation cannot extrapolate beyond the sample maximum. Extreme value theory provides the unique asymptotic limit law for threshold exceedances, enabling rigorous semi-parametric Value-at-Risk and Expected Shortfall estimation in the presence of heavy-tailed asset returns.

1The Peaks Over Threshold Framework

Let \(L\) be a continuous loss random variable with cumulative distribution function \(F(x) = \Prob(L \le x)\). For a chosen high threshold \(u\), the excess distribution function \(F_u\) above \(u\) is defined as:

\[ \begin{aligned} F_u(y) = \Prob(L - u \le y \mid L > u) = \frac{F(u + y) - F(u)}{1 - F(u)}, \quad y \ge 0 \end{aligned} \]

Whereas the Central Limit Theorem characterizes sample sums, extreme value theory characterizes tail exceedances.

Definition 1.1 (Generalized Pareto Distribution)

The Generalized Pareto Distribution (GPD) \(G_{\xi, \beta}\) with shape parameter \(\xi \in \mathbb{R}\) and scale parameter \(\beta > 0\) is given by:

\[ \begin{aligned} G_{\xi, \beta}(y) = \begin{cases} 1 - \left(1 + \xi \frac{y}{\beta}\right)^{-1/\xi}, & \text{if } \xi \ne 0 \\ 1 - \exp\left(-\frac{y}{\beta}\right), & \text{if } \xi = 0 \end{cases} \end{aligned} \]

where \(y \ge 0\) if \(\xi \ge 0\), and \(0 \le y \le -\beta/\xi\) if \(\xi < 0\).

Theorem 1.1 (Pickands-Balkema-de Haan Theorem)

For a vast class of underlying distributions \(F \in \text{MDA}(H_\xi)\), there exists a positive scaling function \(\beta(u) > 0\) such that as \(u \to x_F\) (the right endpoint of \(F\)):

\[ \begin{aligned} \lim_{u \to x_F} \sup_{0 \le y < x_F - u} \left| F_u(y) - G_{\xi, \beta(u)}(y) \right| = 0 \end{aligned} \]

The parameter \(\xi\) is invariant to the choice of threshold \(u\), while \(\beta(u)\) scales with \(u\).

Remark 1.1 (Domains of Attraction)

Financial asset returns universally exhibit \(\xi > 0\) (the Fréchet domain of attraction), corresponding to power-law decay \(1 - F(x) \sim x^{-1/\xi}\). Moments \(\E[L^k]\) diverge for all \(k \ge 1/\xi\). Empirical studies find \(\xi \in [0.1, 0.4]\), implying finite mean and variance, but heavy kurtosis as verified by McNeil and Frey (2000).

2Semi-Parametric Tail Risk: VaR and Expected Shortfall

Combining the empirical distribution for the body below threshold \(u\) with the GPD tail for exceedances above \(u\) yields a semi-parametric tail estimator. Let \(n\) be the total sample size and \(N_u = \sum_{i=1}^n \mathbf{1}_{\{L_i > u\}}\) be the number of exceedances.

Theorem 2.1 (Semi-Parametric EVT VaR and ES)

For confidence level \(\alpha > 1 - N_u / n\), the semi-parametric Value-at-Risk is:

\[ \begin{aligned} \mathrm{VaR}_\alpha(L) = u + \frac{\hat{\beta}}{\hat{\xi}} \left( \left(\frac{n}{N_u}(1 - \alpha)\right)^{-\hat{\xi}} - 1 \right) \end{aligned} \]

For \(\hat{\xi} < 1\), the semi-parametric Expected Shortfall is given in closed form by:

\[ \begin{aligned} \mathrm{ES}_\alpha(L) = \frac{\mathrm{VaR}_\alpha(L) + \hat{\beta} - \hat{\xi} u}{1 - \hat{\xi}} \end{aligned} \]
Proof

By Bayes' rule, the unconditional survival function for \(x > u\) is \(\Prob(L > x) = \Prob(L > u) \Prob(L > x \mid L > u) = (1 - F(u))(1 - F_u(x - u))\). Substituting the empirical proportion \(\hat{F}(u) = 1 - N_u/n\) and the GPD tail gives \(\hat{F}(x) = 1 - \frac{N_u}{n} (1 + \hat{\xi}\frac{x-u}{\hat{\beta}})^{-1/\hat{\xi}}\). Inverting \(\hat{F}(\mathrm{VaR}_\alpha) = \alpha\) directly yields the VaR formula. For Expected Shortfall, using the GPD memoryless property, the excess over \(\mathrm{VaR}_\alpha\) is \(\text{GPD}(\xi, \beta + \xi(\mathrm{VaR}_\alpha - u))\). Its expectation is \((\beta + \xi(\mathrm{VaR}_\alpha - u))/(1 - \xi)\). Adding \(\mathrm{VaR}_\alpha\) yields \(\frac{\mathrm{VaR}_\alpha + \beta - \xi u}{1 - \xi}\) as detailed in McNeil, Frey and Embrechts (2015).

Example 2.1 (Hosking-Wallis Method of Moments)

Let sample exceedances \(Y = L - u\) have mean \(\bar{y} = 0.0200\) and sample variance \(s^2 = 0.0008\). The Hosking-Wallis estimators are:

\[ \begin{aligned} \hat{\xi} = \frac{1}{2}\left(1 - \frac{\bar{y}^2}{s^2}\right) = \frac{1}{2}\left(1 - \frac{0.0004}{0.0008}\right) = 0.25, \quad \hat{\beta} = \bar{y}(1 - \hat{\xi}) = 0.0200(0.75) = 0.0150 \end{aligned} \]

3McNeil-Frey Two-Stage Conditional EVT

Financial return series violate the \(i.i.d.\) assumption due to volatility clustering. Applying unconditional EVT directly to raw returns leads to severe exception clustering during volatile regimes.

McNeil & Frey (2000) resolved this via Two-Stage Conditional EVT:

  1. Filtering: Fit AR(1)-GARCH(1,1) to returns \(r_t = \mu_t + \sigma_t Z_t\) to extract standardized innovations \(\hat{Z}_t = (r_t - \hat{\mu}_t)/\hat{\sigma}_t\).
  2. EVT on Residuals: Fit the GPD to standardized loss innovations \(L_t = -\hat{Z}_t\) above threshold \(u\) to obtain \(\mathrm{VaR}_\alpha(Z)\) and \(\mathrm{ES}_\alpha(Z)\).
  3. Dynamic Forecast: Scale by the conditional 1-step ahead forecasts: \(\mathrm{VaR}_{t+1}^\alpha = -\hat{\mu}_{t+1} + \hat{\sigma}_{t+1} \mathrm{VaR}_\alpha(Z)\) and \(\mathrm{ES}_{t+1}^\alpha = -\hat{\mu}_{t+1} + \hat{\sigma}_{t+1} \mathrm{ES}_\alpha(Z)\).

Lab 5 · Peaks Over Threshold and GPD Tail Estimation

Calibrating a GPD model via POT on heavy-tailed financial losses (Student-t with df=3) will demonstrate that the Gaussian model severely underestimates 99.5% Value-at-Risk and Expected Shortfall by over 30%.

"""Lab 5: Peaks Over Threshold (POT) and Generalized Pareto Distribution (GPD) Estimation.

Demonstrates extreme value theory tail modeling under the Pickands-Balkema-de Haan theorem
and quantifies the severe underestimation of tail risk under the Gaussian assumption.
"""

from __future__ import annotations

import math

import numpy as np


def main() -> None:
    rng = np.random.default_rng(42)

    # 1. Simulate heavy-tailed financial returns (Student-t with df=3)
    n_obs = 2000
    daily_vol = 0.015
    losses = rng.standard_t(df=3, size=n_obs) * daily_vol

    # 2. Peaks Over Threshold (POT) at 90th percentile threshold u
    threshold = float(np.quantile(losses, 0.90, method="linear"))
    excesses = losses[losses > threshold] - threshold
    n_u = len(excesses)

    mean_exc = float(np.mean(excesses))
    var_exc = float(np.var(excesses, ddof=1))

    # Method of Moments GPD parameter estimates (Hosking & Wallis 1987)
    ratio = (mean_exc**2) / var_exc
    xi_gpd = 0.5 * (1.0 - ratio)
    beta_gpd = mean_exc * (1.0 - xi_gpd)

    # 3. High-confidence tail quantiles (alpha = 99.5%)
    alpha = 0.995
    factor = (n_obs / n_u) * (1.0 - alpha)

    var_evt = threshold + (beta_gpd / xi_gpd) * (factor ** (-xi_gpd) - 1.0)
    es_evt = (var_evt + beta_gpd - xi_gpd * threshold) / (1.0 - xi_gpd)

    # 4. Compare with Gaussian benchmark
    mu = float(np.mean(losses))
    sigma = float(np.std(losses, ddof=1))
    z_995 = 2.575829  # standard normal quantile for 0.995
    phi_z = (1.0 / math.sqrt(2.0 * math.pi)) * math.exp(-0.5 * z_995**2)

    var_norm = mu + sigma * z_995
    es_norm = mu + sigma * (phi_z / (1.0 - alpha))

    print(f"Sample Observations: {n_obs} | POT Exceedances (u={threshold:.6f}): {n_u}")
    print(f"GPD Shape Parameter xi (tail heaviness): {xi_gpd:.4f}")
    print(f"GPD Scale Parameter beta: {beta_gpd:.6f}")
    print("-" * 65)
    print(f"EVT POT 99.5% VaR: {var_evt:.6f} | Gaussian 99.5% VaR: {var_norm:.6f}")
    print(f"EVT POT 99.5% ES:  {es_evt:.6f} | Gaussian 99.5% ES:  {es_norm:.6f}")
    underest_es = (es_evt - es_norm) / es_evt * 100.0
    print(f"Gaussian Expected Shortfall Underestimation: {underest_es:.1f}%")


main()

4Where the canon breaks

While EVT eliminates the Gaussian delusion in deep tails, it introduces a critical econometric dilemma: threshold selection. Choosing \(u\) balances asymptotic bias against sample variance. If \(u\) is set too low, non-tail body observations contaminate the exceedance sample, causing severe parameter bias. If \(u\) is set too high, too few exceedances remain, resulting in massive parameter variance and capital instability as analyzed by McNeil et al. (2015). Diagnostic stability plots and mean excess plots are mandatory to establish a stable plateau.

5Misconceptions

  1. “EVT assumes the entire return distribution follows a Generalized Pareto Distribution.”

    The Peaks Over Threshold method models only the conditional excess distribution above threshold \(u\) (\(L - u \mid L > u\)). The body below \(u\) is modeled non-parametrically via the empirical distribution.

  2. “A positive shape parameter \(\xi = 0.30\) implies infinite variance.”

    For a GPD, moment \(\E[Y^k]\) exists if and only if \(\xi < 1/k\). At \(\xi = 0.30\), \(1/\xi \approx 3.33\), so both the mean (\(k=1\)) and variance (\(k=2\)) are strictly finite. Only moments \(k \ge 4\) diverge.

  3. “EVT can be applied directly to raw asset returns without volatility filtering.”

    The Pickands-Balkema-de Haan theorem assumes \(i.i.d.\) observations. Raw asset returns exhibit strong volatility clustering. Applying EVT without GARCH volatility filtering violates independence and causes clustered tail breaches as established by McNeil and Frey (2000).

6Problem set

Mechanics

M1 · Semi-Parametric EVT VaR Calculation

A risk engine sets threshold \(u = 0.0300\) on \(n = 2000\) daily loss observations, finding \(N_u = 100\) exceedances. Method of moments calibration yields \(\hat{\xi} = 0.25\) and \(\hat{\beta} = 0.0150\). Calculate the semi-parametric EVT Value-at-Risk at confidence level \(\alpha = 0.995\).

Solution

We evaluate the semi-parametric EVT VaR formula: \(\mathrm{VaR}_{0.995} = u + \frac{\hat{\beta}}{\hat{\xi}} \left( \left(\frac{n}{N_u}(1 - \alpha)\right)^{-\hat{\xi}} - 1 \right) = 0.0300 + \frac{0.0150}{0.25} \left( \left(\frac{2000}{100} \cdot 0.005\right)^{-0.25} - 1 \right) = 0.0300 + 0.0600 \cdot (0.10^{-0.25} - 1)\). Since \(0.10^{-0.25} = 10^{0.25} \approx 1.77828\), \(\mathrm{VaR}_{0.995} = 0.0300 + 0.0600(0.77828) = 0.0300 + 0.04670 = 0.07670\) (7.67%).

M2 · Closed-Form Expected Shortfall under GPD

Using \(\mathrm{VaR}_{0.995} = 0.07670\), \(\hat{\xi} = 0.25\), \(\hat{\beta} = 0.0150\), and \(u = 0.0300\), compute the semi-parametric Expected Shortfall \(\mathrm{ES}_{0.995}\).

Solution

Applying the closed-form GPD Expected Shortfall formula: \(\mathrm{ES}_{0.995} = \frac{\mathrm{VaR}_{0.995} + \hat{\beta} - \hat{\xi} u}{1 - \hat{\xi}} = \frac{0.07670 + 0.0150 - (0.25)(0.0300)}{1 - 0.25} = \frac{0.07670 + 0.0150 - 0.0075}{0.75} = \frac{0.08420}{0.75} \approx 0.11227\) (11.23%). Expected tail severity is substantially higher than the 99.5% VaR threshold.

M3 · Hosking-Wallis Parameter Estimation

Given exceedances \(Y = L - u\) with sample mean \(\bar{y} = 0.0200\) and sample variance \(s^2 = 0.0008\), calculate the Hosking-Wallis method of moments parameter estimates \(\hat{\xi}\) and \(\hat{\beta}\).

Solution

Under the Hosking-Wallis (1987) estimators: \(\text{ratio} = \bar{y}^2 / s^2 = 0.0200^2 / 0.0008 = 0.0004 / 0.0008 = 0.50\). The shape parameter is \(\hat{\xi} = 0.5(1 - \text{ratio}) = 0.5(1 - 0.50) = 0.25\). The scale parameter is \(\hat{\beta} = \bar{y}(1 - \hat{\xi}) = 0.0200(1 - 0.25) = 0.0150\).

Proof

P1 · Derivation of Closed-Form Expected Shortfall

Derive the closed-form expression \(\mathrm{ES}_\alpha(L) = \frac{\mathrm{VaR}_\alpha(L) + \beta - \xi u}{1 - \xi}\) for a loss distribution whose tail above \(u \le \mathrm{VaR}_\alpha\) follows a GPD with \(\xi < 1\).

Solution

By the memoryless property of the GPD, if \(L - u \mid L > u \sim \text{GPD}(\xi, \beta)\), then for any higher threshold \(v \ge u\), the excess \(L - v \mid L > v\) follows \(\text{GPD}(\xi, \beta + \xi(v - u))\). Setting \(v = \mathrm{VaR}_\alpha\), the modified scale is \(\beta_v = \beta + \xi(\mathrm{VaR}_\alpha - u)\). The expected excess is \(\E[L - v \mid L > v] = \beta_v / (1 - \xi)\) for \(\xi < 1\). Therefore: \(\mathrm{ES}_\alpha(L) = \mathrm{VaR}_\alpha + \frac{\beta + \xi(\mathrm{VaR}_\alpha - u)}{1 - \xi} = \frac{(1 - \xi)\mathrm{VaR}_\alpha + \beta + \xi\mathrm{VaR}_\alpha - \xi u}{1 - \xi} = \frac{\mathrm{VaR}_\alpha + \beta - \xi u}{1 - \xi}\).

P2 · Limiting Behavior as Shape Approaches Zero

Prove that as \(\xi \to 0\), the GPD Expected Shortfall formula recovers the exponential tail expectation \(\mathrm{ES}_\alpha = \mathrm{VaR}_\alpha + \beta\).

Solution

Taking the limit as \(\xi \to 0\) of the closed-form ES expression: \(\lim_{\xi \to 0} \frac{\mathrm{VaR}_\alpha + \beta - \xi u}{1 - \xi} = \frac{\mathrm{VaR}_\alpha + \beta - 0 \cdot u}{1 - 0} = \mathrm{VaR}_\alpha + \beta\). For an exponential tail with rate parameter \(\lambda = 1/\beta\), memorylessness implies the mean excess is constant at \(1/\lambda = \beta\), exactly matching the limit.

P3 · Moment Existence Condition for GPD

Prove that the \(k\)-th raw moment of a GPD random variable \(Y \sim G_{\xi, \beta}\) with \(\xi > 0\) exists if and only if \(\xi < 1/k\).

Solution

The probability density function is \(g(y) = \frac{1}{\beta}(1 + \xi y / \beta)^{-(1 + 1/\xi)}\). The \(k\)-th raw moment is \(\E[Y^k] = \int_0^\infty y^k \frac{1}{\beta}(1 + \frac{\xi y}{\beta})^{-(1 + 1/\xi)} dy\). For large \(y\), the integrand decays asymptotically as \(y^{k - 1 - 1/\xi}\). Convergence requires the exponent to be strictly less than \(-1\): \(k - 1 - 1/\xi < -1 \iff k < 1/\xi \iff \xi < 1/k\). When \(\xi \ge 1/k\), the integral diverges to infinity.

Empirical

E1 · Bias-Variance Trade-Off in Threshold Selection

A risk desk evaluates two thresholds on 2,500 trading days: \(u_1\) (95th percentile, 125 exceedances) with \(\hat{\xi}_1 = 0.28 \pm 0.08\), and \(u_2\) (99th percentile, 25 exceedances) with \(\hat{\xi}_2 = 0.35 \pm 0.22\). Evaluate the trade-off for regulatory capital.

Solution

Threshold \(u_1\) provides 125 observations, ensuring low parameter standard error (\(\pm 0.08\)) and stable capital charges, but risks asymptotic bias if the 95th percentile contains central-body dynamics. Threshold \(u_2\) satisfies asymptotic convergence more cleanly, but 25 observations yield high parameter uncertainty (\(\pm 0.22\)), which translates into wild fluctuations in regulatory capital. Best practice selects the lowest threshold where the mean excess function remains strictly linear.

E2 · Failure of Unconditional EVT under Volatility Shocks

Why does static unconditional EVT fail during sudden volatility regime shifts such as September 2008 compared to McNeil-Frey conditional EVT?

Solution

Static unconditional EVT assumes stationary dispersion and constant threshold exceedance probabilities. When market volatility doubles overnight, static risk bounds are repeatedly breached on consecutive days, violating independence. The McNeil-Frey conditional framework updates dynamic volatility \(\sigma_{t+1}\) daily via GARCH, widening risk bands immediately and maintaining proper coverage through crisis spikes.

E3 · Instability of the Hill Estimator

Compare the practical stability of the Hill estimator against the Peaks Over Threshold GPD estimator on real financial returns.

Solution

The Hill estimator assumes exact strict Pareto behavior across all upper order statistics. Plotting the Hill estimate against order statistics produces the notorious "Hill horror plot", with dramatic volatility and no identifiable stable plateau. In contrast, the GPD incorporates both shape \(\xi\) and scale \(\beta\), providing robust and stable parameter estimates across wide threshold ranges.

Research

R1 · Structural Breaks in Tail Dynamics

How do structural regime shifts in macroeconomic volatility affect the asymptotic properties of the Pickands-Balkema-de Haan theorem?

Solution

Structural regime breaks violate the identical distribution assumption for the standardized innovations. If residual kurtosis shifts between regimes, the true tail index \(\xi\) varies over time. Risk engines address this by incorporating Markov-switching GARCH processes or exponential downweighting of historical exceedances to reflect the current volatility regime.

R2 · Multivariate EVT versus Copula Decoupling

Why is multivariate EVT rarely applied directly to high-dimensional portfolios, necessitating copula modeling instead?

Solution

Multivariate EVT requires estimating an infinite-dimensional spectral measure to capture joint tail dependence. Non-parametric spectral estimation suffers from the curse of dimensionality beyond 2 or 3 assets. Financial engineering therefore decouples univariate EVT for individual asset tails from copula functions for multi-asset dependence.

R3 · Tail Index Sensitivity on Regulatory Capital

Quantify the sensitivity of regulatory Expected Shortfall to parameter estimation error in \(\xi\) when \(\xi\) approaches 0.50.

Solution

As \(\xi \to 0.50\), the variance of the underlying process approaches infinity, and the denominator \((1 - \xi)\) in the ES formula drives explosive sensitivity: \(\frac{\partial \mathrm{ES}}{\partial \xi} \approx \frac{\mathrm{ES}}{1 - \xi}\). An estimation error of \(+0.05\) on \(\xi = 0.45\) increases the denominator from \(0.55\) to \(0.50\), triggering an immediate \(10\%\) to \(25\%\) surge in required capital purely from parameter uncertainty.

8Quiz

  1. Under the Pickands-Balkema-de Haan theorem, what distribution asymptotically models threshold exceedances?

    Options

    Threshold excesses converge asymptotically to the Generalized Pareto Distribution (GPD). Block maxima converge to the GEV distribution under Fisher-Tippett-Gnedenko.

  2. A fitted GPD has shape parameter \(\xi = 0.35\). Which moments of the excess distribution exist?

    Options

    Moments \(\E[Y^k]\) are finite if and only if \(\xi < 1/k\). For \(\xi = 0.35\), \(1/\xi \approx 2.86\), ensuring finite mean and variance, but infinite skewness and kurtosis.

  3. Why does the McNeil-Frey two-stage conditional EVT approach filter returns with GARCH before fitting the GPD?

    Options

    EVT limit theorems require independent observations. Financial returns exhibit volatility clustering; GARCH filtering standardizes innovations so they satisfy the \(i.i.d.\) requirement.

  4. What is the condition on the GPD shape parameter \(\xi\) for Expected Shortfall to be finite?

    Options

    Expected Shortfall is a conditional first moment. For the first moment of a GPD to exist, we require \(\xi < 1/1 = 1.0\). If \(\xi \ge 1.0\), Expected Shortfall is infinite.

  5. In Peaks Over Threshold modeling, what error is introduced when threshold \(u\) is set too low?

    Options

    Setting \(u\) too low contaminates the tail sample with central-body observations, violating the asymptotic condition and introducing severe estimation bias.

  6. What does a GPD shape parameter \(\xi = 0\) indicate?

    Options

    When \(\xi = 0\), the GPD reduces to the exponential distribution \(1 - \exp(-y/\beta)\), characterizing thin exponential tails in the Gumbel domain.

  7. What is the typical calibrated range for the GPD shape parameter \(\xi\) across empirical financial returns?

    Options

    Extensive empirical studies by McNeil & Frey (2000) and others show asset return tails have \(\xi \in [0.1, 0.4]\), indicating heavy tails with finite variance.

  8. Which graphical diagnostic tool is primarily used to identify a suitable threshold \(u\) for POT modeling?

    Options

    The mean excess function of a GPD is strictly linear in \(u\). The empirical mean excess plot should appear linear above a valid threshold \(u\).
