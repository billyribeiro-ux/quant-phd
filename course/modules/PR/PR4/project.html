Atlas Risk Engine

Construct the enterprise risk measurement module (atlas.risk) for the Atlas quantitative trading system, incorporating non-parametric historical simulation, parametric Gaussian and Student-t models, semi-parametric Extreme Value Theory (POT/GPD), Kupiec and Christoffersen backtesting, and macro stress testing.

  • Deliverable: Production risk engine (atlas/risk.py) passing milestone A12 autograder acceptance tests.
  • Evaluation: Graded by quantitative autograder suite across 50 pseudo-random market instances.
  • Time budget: 30 hours (30% of total 100-hour module budget).

The project ladder

The project follows a structured four-rung learning ladder from an annotated full-pipeline worked example to an independent production implementation and rolling dynamic EVT extension.

  1. Worked example

    A complete, annotated derivation of the multi-model risk engine pipeline (Historical, Gaussian, Student-t, and EVT POT/GPD), Kupiec backtesting, and macro stress testing on a simulated portfolio.

  2. Completion

    A completion lab where you implement first-order Markov transition counts, maximum likelihood transition probabilities, and the Christoffersen conditional coverage likelihood ratio test. Graded instantly in browser.

  3. Independent

    Implement the full specification in atlas/risk.py, satisfying contract atlas/A12.contract.md, passing the autograder suite across 50 seeds, and killing all 5 adversarial mutants on seed 0.

  4. Stretch

    Build an automated rolling-window Peaks-Over-Threshold engine that dynamically adapts GPD tail parameters across volatility regime shifts and eliminates exception clustering.

Lab 1 · Worked example: Full Risk Engine Core Pipeline

Executes an end-to-end risk measurement workflow across four model families, backtests exception counts under the Kupiec POF test, and computes multi-asset macro stress loss.

"""Lab Project 1 (Rung 1 Worked Example): Full Risk Engine Core Pipeline.

A fully solved instance of the Atlas A12 risk measurement and backtesting pipeline,
annotated with architectural rationale at each stage.
"""

from __future__ import annotations

import math

import numpy as np
import scipy.stats


def main() -> None:
    rng = np.random.default_rng(100)
    t_obs = 500
    portfolio_equity = 10_000_000.0
    alpha = 0.99

    # 1. Generate loss series with leptokurtosis (Student-t df=4)
    returns = rng.standard_t(df=4, size=t_obs) * 0.014 - 0.0004
    losses = -returns

    # 2. Risk Estimation Engines
    # Historical Simulation
    var_hist = float(np.quantile(losses, alpha, method="linear"))
    es_hist = float(np.mean(losses[losses > var_hist]))

    # Parametric Gaussian
    mu = float(np.mean(losses))
    sigma = float(np.std(losses, ddof=1))
    z = float(scipy.stats.norm.ppf(alpha))
    phi = float(scipy.stats.norm.pdf(z))
    var_norm = mu + sigma * z
    es_norm = mu + sigma * (phi / (1.0 - alpha))

    # Parametric Student-t
    df = 4
    scale = sigma * math.sqrt((df - 2.0) / float(df))
    q = float(scipy.stats.t.ppf(alpha, df=df))
    g_q = float(scipy.stats.t.pdf(q, df=df))
    var_t = mu + scale * q
    es_t = mu + scale * ((g_q / (1.0 - alpha)) * ((df + q * q) / (df - 1.0)))

    # Extreme Value Theory (POT / GPD)
    u = float(np.quantile(losses, 0.90, method="linear"))
    excesses = losses[losses > u] - u
    n_u = len(excesses)
    m_e = float(np.mean(excesses))
    v_e = float(np.var(excesses, ddof=1))
    xi = 0.5 * (1.0 - (m_e**2) / v_e)
    beta = m_e * (1.0 - xi)
    factor = (t_obs / n_u) * (1.0 - alpha)
    var_evt = u + (beta / xi) * (factor ** (-xi) - 1.0)
    es_evt = (var_evt + beta - xi * u) / (1.0 - xi)

    # 3. Kupiec POF Backtest over 250 out-of-sample days
    hits = (losses[-250:] > var_hist).astype(int)
    x = int(np.sum(hits))
    t_back = 250
    p = 1.0 - alpha
    p_hat = x / t_back
    lr_pof = -2.0 * (
        (t_back - x) * math.log(1.0 - p) + x * math.log(p) - (t_back - x) * math.log(1.0 - p_hat) - x * math.log(p_hat)
    )
    lr_pof = max(0.0, float(lr_pof))
    p_val_pof = float(math.erfc(math.sqrt(lr_pof / 2.0)))

    # 4. Stress Scenario P&L
    weights = np.array([0.4, 0.3, 0.2, 0.1], dtype=np.float64)
    shocks = np.array([-0.18, -0.10, 0.04, -0.22], dtype=np.float64)
    stress_pnl = float(portfolio_equity * np.dot(weights, shocks))

    print(f"Base Portfolio Equity: ${portfolio_equity:,.2f}")
    print(f"Historical 99% VaR:  {var_hist:.5f} | ES: {es_hist:.5f}")
    print(f"Gaussian 99% VaR:    {var_norm:.5f} | ES: {es_norm:.5f}")
    print(f"Student-t 99% VaR:   {var_t:.5f} | ES: {es_t:.5f}")
    print(f"EVT POT 99% VaR:     {var_evt:.5f} | ES: {es_evt:.5f}")
    print("-" * 60)
    print(f"Backtest Hits: {x}/{t_back} | Kupiec LR: {lr_pof:.4f} | p-value: {p_val_pof:.4f}")
    print(f"Macro Stress Dollar P&L: ${stress_pnl:,.2f} ({stress_pnl / portfolio_equity * 100:.2f}%)")


main()

Rung 3 · Independent project: Atlas Risk Engine (A12)

In this independent project, you implement the production module atlas/risk.py to deliver milestone A12 of the Atlas quantitative software architecture. Your engine must pass all deterministic unit and property tests across 50 seeds and kill 5 adversarial mutants.

Context
The Atlas algorithmic investment system requires an industrial-grade risk management engine (atlas.risk) providing unified multi-asset risk measurement, rigorous statistical backtesting, and macroeconomic stress scenario valuation. The engine must adhere strictly to mathematical coherence axioms (Artzner et al. 1999), Basel III and FRTB regulatory standards, and Federal Reserve SR 26-2 model risk requirements.
Inputs
The evaluation harness provides deterministic test instances via make_instance(seed: int) in grader/instance.py. The returned instance dictionary contains:
  • returns: A 2D NumPy array of historical returns of shape \((T, N)\) where \(T \in [500, 2000]\) days and \(N \in [2, 10]\) assets.
  • weights: A 1D NumPy array of portfolio asset weights summing to 1.0.
  • alpha: Confidence level \(\alpha \in [0.95, 0.999]\) (typically \(0.99\) or \(0.975\)).
  • threshold_quantile: POT threshold quantile \(q_u \in [0.85, 0.95]\) for GPD calibration.
  • backtest_horizon: Integer number of out-of-sample trading days \(T_{\text{back}} \in [250, 500]\).
  • scenarios: Dictionary mapping scenario names to asset shock return vectors \(\mathbf{s} \in \mathbb{R}^N\).
  • capital_threshold: Critical dollar loss threshold \(L_{\text{crit}} > 0\) for reverse stress testing.
  • portfolio_equity: Total portfolio equity value in dollars \(V_0 > 0\).
Required outputs
The module atlas/risk.py must expose the RiskEngine class conforming to the atlas/A12.contract.md specification:
  • historical_var(self) -> float: Non-parametric Value-at-Risk from empirical order statistics.
  • historical_es(self) -> float: Empirical Expected Shortfall (conditional mean of tail losses).
  • gaussian_var(self) -> float: Parametric Gaussian Value-at-Risk \(\mu + \sigma \Phi^{-1}(\alpha)\).
  • gaussian_es(self) -> float: Closed-form Gaussian Expected Shortfall \(\mu + \sigma \frac{\phi(z_\alpha)}{1 - \alpha}\).
  • evt_var(self) -> float: Semi-parametric Peaks Over Threshold GPD Value-at-Risk.
  • evt_es(self) -> float: Closed-form GPD Expected Shortfall \(\frac{\mathrm{VaR} + \beta - \xi u}{1 - \xi}\).
  • kupiec_test(self, var_threshold: float) -> tuple[float, float, bool]: Returns \((LR_{\text{POF}}, p\text{-value}, \text{rejected at 5\%})\).
  • christoffersen_test(self, var_threshold: float) -> tuple[float, float, bool]: Returns \((LR_{\text{ind}}, p\text{-value}, \text{rejected at 5\%})\).
  • scenario_stress_loss(self, scenario_name: str) -> float: Computes total portfolio dollar loss under named shock vector.
  • reverse_stress_multiplier(self, scenario_name: str) -> float: Computes minimum scaling factor \(k^*\) required to breach \(L_{\text{crit}}\).
Constraints
The implementation must be deterministic, strictly typed (passing mypy --strict), free of lookahead bias, and implemented using standard NumPy and SciPy. Execution time must remain strictly under 1.0 second per seed across 50 test seeds.
Grading
Graded by quantitative autograder suite across 50 deterministic seeds (seeds 0-49) and 5 adversarial mutant implementations.

Level 4 Exemplar: Rigorous Tail Modeling and Model Risk Quantification

The Level 4 implementation derives the closed-form GPD Expected Shortfall directly from the memoryless property, explicitly verifying that \(\xi < 1\) to guarantee first-moment finiteness. It incorporates numerical safeguards for \(\xi \to 0\) by smoothly bridging to the exponential limit \(\mathrm{ES} = \mathrm{VaR} + \beta\). Backtesting engines protect against zero-count cells in the Markov transition matrix by evaluating limits analytically. Furthermore, the model risk evaluation explicitly computes the capital discrepancy \(\mathrm{ES}_{\text{EVT}} - \mathrm{ES}_{\text{Gauss}}\), demonstrating full compliance with Federal Reserve SR 26-2 model governance guidance.

Level 2 Exemplar: Incomplete Numerical Safeguards and Static Assumptions

The Level 2 implementation implements basic GPD formulas but crashes when candidate thresholds produce zero exceedances or when \(\xi\) approaches zero. In the Christoffersen test, it computes \(\ln(\pi_{11})\) without checking if \(n_{11} = 0\), causing runtime ValueError: math domain error. Reverse stress testing computes the ratio without verifying whether the base scenario generates a loss or a gain, occasionally yielding negative severity multipliers. Model risk is mentioned only superficially without tabulating capital differences across candidate models.

Lab 3 · Rolling Dynamic EVT-GPD Risk Engine

An automated rolling EVT-GPD engine will adaptively adjust tail parameters during volatility bursts, reducing out-of-sample VaR violations by over 2x compared to static historical simulation.

"""Lab Project 3 (Rung 4 Stretch Extension): Rolling Dynamic EVT-GPD Engine.

Implements an automated rolling-window Peaks-Over-Threshold EVT risk engine
and evaluates out-of-sample dynamic backtesting accuracy across volatile regimes.
"""

from __future__ import annotations

import math

import numpy as np


def main() -> None:
    rng = np.random.default_rng(2026)
    t_total = 800
    window = 250
    alpha = 0.99

    # Generate synthetic returns with GARCH-like time-varying volatility bursts
    innovations = rng.standard_t(df=4, size=t_total)
    returns = np.zeros(t_total)
    sigma_t = 0.012

    for t in range(t_total):
        sigma_t = 0.028 if 300 <= t <= 450 else 0.012
        returns[t] = sigma_t * innovations[t]

    losses = -returns
    out_of_sample_losses = losses[window:]
    n_eval = len(out_of_sample_losses)

    evt_vars = []
    hist_vars = []

    # Rolling window parameter re-estimation
    for t in range(window, t_total):
        w_loss = losses[t - window : t]
        # Historical VaR
        h_v = float(np.quantile(w_loss, alpha, method="linear"))
        hist_vars.append(h_v)

        # EVT POT GPD VaR
        u = float(np.quantile(w_loss, 0.88, method="linear"))
        exc = w_loss[w_loss > u] - u
        n_u = len(exc)
        m_e = float(np.mean(exc))
        v_e = float(np.var(exc, ddof=1))
        xi = max(-0.5, min(0.9, 0.5 * (1.0 - (m_e**2) / v_e)))
        beta = max(1e-4, m_e * (1.0 - xi))
        factor = (window / n_u) * (1.0 - alpha)
        evt_v = u + (beta / xi) * (factor ** (-xi) - 1.0)
        evt_vars.append(evt_v)

    arr_evt_var = np.array(evt_vars)
    arr_hist_var = np.array(hist_vars)

    hits_evt = int(np.sum(out_of_sample_losses > arr_evt_var))
    hits_hist = int(np.sum(out_of_sample_losses > arr_hist_var))

    p = 1.0 - alpha
    expected_hits = n_eval * p

    def kupiec_lr(x: int, n: int) -> float:
        p_hat = x / n
        return float(
            -2.0
            * ((n - x) * math.log(1.0 - p) + x * math.log(p) - (n - x) * math.log(1.0 - p_hat) - x * math.log(p_hat))
        )

    lr_evt = max(0.0, kupiec_lr(hits_evt, n_eval))
    lr_hist = max(0.0, kupiec_lr(hits_hist, n_eval))

    p_evt = float(math.erfc(math.sqrt(lr_evt / 2.0)))
    p_hist = float(math.erfc(math.sqrt(lr_hist / 2.0)))

    print(f"Rolling Evaluation Periods: {n_eval} | Rolling Window Size: {window}")
    print(f"Expected 99% Out-of-Sample Violations: {expected_hits:.1f}")
    print("=" * 70)
    print(f"Rolling Historical VaR Exceptions: {hits_hist}/{n_eval} | LR: {lr_hist:.4f} | p-val: {p_hist:.4f}")
    print(f"Rolling EVT-GPD VaR Exceptions:    {hits_evt}/{n_eval} | LR: {lr_evt:.4f} | p-val: {p_evt:.4f}")
    print("-" * 70)
    print(f"EVT Tail Protection Ratio: {hits_hist / max(1, hits_evt):.2f}x fewer violations under regime shifts")
