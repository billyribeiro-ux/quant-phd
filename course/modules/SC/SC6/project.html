HJB Solver: Constrained Merton Problem

In portfolio management and systematic asset allocation, investors face statutory leverage limits, borrowing constraints, and non-linear funding costs that prevent unconstrained continuous rebalancing. While unconstrained constant relative risk aversion (CRRA) portfolio choice yields the elegant closed-form Merton fraction \(\pi^* = \frac{\mu - r}{\gamma \sigma^2}\), practical constraints require solving non-linear Hamilton–Jacobi–Bellman partial differential equations numerically. In this project you build a robust numerical HJB solver using monotone upwind finite differences and Howard's policy iteration algorithm, enforce borrowing limits, and verify the numerical value function and optimal policy against exact analytical benchmarks.

  • Deliverable: Tested Python solver module hjb_solver.py
  • Grading: Autograder (10 acceptance tests across 50 pseudorandom seeds)
  • Time budget: 24 hours total

Rung 1 · Worked example

Lab 1 · Worked example: HJB policy iteration on seed 0

Under seed 0 (SIMULATED), policy iteration terminates in under 15 iterations, achieving a relative value function error under 1% and recovering the analytical allocation within 0.01.

r"""Rung 1 worked example: numerical HJB policy iteration on seed 0 (SIMULATED).

Solves the continuous-time Merton problem with a borrowing constraint on a 101-node wealth grid,
verifying that policy iteration terminates in under 15 iterations and recovers the analytical
solution to within discretization error.
"""

from __future__ import annotations


def solve_tridiagonal(sub: list[float], diag: list[float], sup: list[float], rhs: list[float]) -> list[float]:
    n = len(diag)
    c_prime = [0.0] * n
    d_prime = [0.0] * n
    c_prime[0] = sup[0] / diag[0]
    d_prime[0] = rhs[0] / diag[0]
    for i in range(1, n):
        denom = diag[i] - sub[i] * c_prime[i - 1]
        if i < n - 1:
            c_prime[i] = sup[i] / denom
        d_prime[i] = (rhs[i] - sub[i] * d_prime[i - 1]) / denom
    x = [0.0] * n
    x[-1] = d_prime[-1]
    for i in range(n - 2, -1, -1):
        x[i] = d_prime[i] - c_prime[i] * x[i + 1]
    return x


def main() -> None:
    # Seed 0 instance parameters (SIMULATED)
    r = 0.0369
    mu = 0.0874
    sigma = 0.1653
    gamma = 2.13
    rho = 0.0745
    pi_max = 0.6496
    w_min = 0.92
    w_max = 4.66
    n_points = 101

    dw = (w_max - w_min) / (n_points - 1)
    w = [w_min + i * dw for i in range(n_points)]

    print(f"seed 0 parameters (SIMULATED): r={r:.4f}, mu={mu:.4f}, sigma={sigma:.4f}, gamma={gamma:.2f}, rho={rho:.4f}")
    print(f"borrowing limit pi_max: {pi_max:.4f}, wealth grid: [{w_min:.2f}, {w_max:.2f}] with {n_points} nodes")

    # Analytical benchmark
    pi_star = (mu - r) / (gamma * (sigma**2))
    pi_eff = pi_star if pi_max >= pi_star else pi_max
    k_eff = r + pi_eff * (mu - r) - 0.5 * gamma * (pi_eff**2) * (sigma**2)
    nu_eff = (rho - (1.0 - gamma) * k_eff) / gamma
    v_exact = [(nu_eff ** (-gamma)) / (1.0 - gamma) * (x ** (1.0 - gamma)) for x in w]

    # Policy iteration
    pi = [min(pi_max, pi_eff)] * n_points
    c = [nu_eff * x for x in w]
    v = list(v_exact)

    converged = False
    iterations_completed = 0
    max_iter = 50
    tol = 1e-7

    for it in range(1, max_iter + 1):
        iterations_completed = it
        sub = [0.0] * n_points
        diag = [0.0] * n_points
        sup = [0.0] * n_points
        rhs = [0.0] * n_points

        diag[0] = 1.0
        rhs[0] = v_exact[0]
        diag[-1] = 1.0
        rhs[-1] = v_exact[-1]

        for i in range(1, n_points - 1):
            drift = (r + pi[i] * (mu - r)) * w[i] - c[i]
            diff = 0.5 * (pi[i] ** 2) * (sigma**2) * (w[i] ** 2)

            if drift >= 0.0:
                alpha_i = diff / (dw**2)
                beta_i = rho + 2.0 * diff / (dw**2) + drift / dw
                gamma_i = diff / (dw**2) + drift / dw
            else:
                alpha_i = diff / (dw**2) - drift / dw
                beta_i = rho + 2.0 * diff / (dw**2) - drift / dw
                gamma_i = diff / (dw**2)

            sub[i] = -alpha_i
            diag[i] = beta_i
            sup[i] = -gamma_i
            rhs[i] = (c[i] ** (1.0 - gamma)) / (1.0 - gamma)

        v_new = solve_tridiagonal(sub, diag, sup, rhs)

        # Update policy
        vp = [0.0] * n_points
        vpp = [0.0] * n_points
        for i in range(1, n_points - 1):
            vp[i] = (v_new[i + 1] - v_new[i - 1]) / (2.0 * dw)
            vpp[i] = (v_new[i + 1] - 2.0 * v_new[i] + v_new[i - 1]) / (dw**2)
        vp[0] = (v_new[1] - v_new[0]) / dw
        vpp[0] = vpp[1]
        vp[-1] = (v_new[-1] - v_new[-2]) / dw
        vpp[-1] = vpp[-2]

        c_new = [max(vp[i], 1e-12) ** (-1.0 / gamma) for i in range(n_points)]
        pi_new = [0.0] * n_points
        for i in range(n_points):
            curv = min(vpp[i], -1e-12)
            pi_unc = -(mu - r) / (sigma**2) * (vp[i] / (w[i] * curv))
            pi_new[i] = max(0.0, min(pi_max, pi_unc))

        diff_v = max(abs(v_new[i] - v[i]) for i in range(n_points))
        v = v_new
        c = c_new
        pi = pi_new

        if diff_v < tol:
            converged = True
            break

    # Error analysis
    rel_errors = [abs(v[i] - v_exact[i]) / abs(v_exact[i]) for i in range(n_points)]
    max_rel_error = max(rel_errors)
    mid_idx = n_points // 2

    print("solver results:")
    print(f"  converged: {converged} in {iterations_completed} iterations")
    print(f"  max relative value function error: {max_rel_error:.2e}")
    print(f"  interior allocation at w={w[mid_idx]:.2f}: numerical={pi[mid_idx]:.4f}, exact={pi_eff:.4f}")
    print(f"  value function error within 2.0% tolerance: {max_rel_error < 0.02}")
    print(f"  interior allocation matches target within 0.01: {abs(pi[mid_idx] - pi_eff) < 0.01}")

Rung 3 · Independent project specification

This is the graded deliverable for SC6. Implement hjb_solver.py to satisfy the specification below.

Context
A long-term institutional investor allocates wealth dynamically between a cash bond earning risk-free rate \(r\) and a market index following geometric Brownian motion with drift \(\mu\) and volatility \(\sigma\). The investor consumes at continuous rate \(c_t\) under CRRA power utility \(U(c) = \frac{c^{1-\gamma}}{1-\gamma}\) with subjective discount rate \(\rho > 0\). Due to prime brokerage covenants, the investor faces an upper borrowing limit \(\pi_t \le \pi_{\max}\) and is prohibited from short-selling stock (\(\pi_t \ge 0\)). Your task is to build a high-performance numerical HJB solver using monotone finite-difference policy iteration, and verify that the numerical solution converges to the theoretical continuous-time solution.
Inputs
A parameter dictionary generated deterministically by make_instance(seed) in grader/instance.py, containing keys:
  • r (float): risk-free rate, \(0.015 \le r \le 0.045\);
  • mu (float): risky asset drift, \(r + 0.03 \le \mu \le r + 0.08\);
  • sigma (float): volatility, \(0.15 \le \sigma \le 0.30\);
  • gamma (float): relative risk aversion, \(1.5 \le \gamma \le 4.0\);
  • rho (float): subjective discount rate, \(0.04 \le \rho \le 0.08\);
  • pi_max (float): borrowing constraint upper bound;
  • w_min, w_max (float): wealth grid endpoints;
  • n_points (int): number of spatial grid nodes;
  • wealth_grid (list of float): strictly increasing array of wealth coordinates.
Required outputs
A single Python module hjb_solver.py exporting:
  • def merton_fraction(r: float, mu: float, sigma: float, gamma: float) -> float: computes \(\pi^* = \frac{\mu - r}{\gamma \sigma^2}\);
  • def exact_merton_solution(w: list[float], r: float, mu: float, sigma: float, gamma: float, rho: float, pi_bound: float | None = None) -> dict[str, Any]: computes exact closed-form CRRA value function and consumption on grid w;
  • def solve_tridiagonal(sub: list[float], diag: list[float], sup: list[float], rhs: list[float]) -> list[float]: solves a tridiagonal linear system \(A x = b\) in \(O(n)\) time via the Thomas algorithm;
  • def solve_merton_hjb(instance: dict[str, Any], max_iter: int = 100, tol: float = 1e-7) -> dict[str, Any]: solves the constrained HJB equation on the wealth grid via policy iteration, returning a dictionary with keys "w", "v", "c", "pi", "iterations", "converged", and "max_residual".
Constraints
  • Use only Python 3 standard library and NumPy. No SciPy or external optimization packages.
  • Discretize the convection drift term using an upwind scheme to guarantee M-matrix stability and satisfy the discrete maximum principle.
  • Execute within 5.0 seconds per seed in Pyodide and under 60.0 seconds across the entire 50-seed test suite.
  • Validate inputs: raise ValueError for non-positive \(\sigma, \rho, \gamma\), for \(\gamma = 1.0\), for non-positive wealth, or for non-increasing grids.
Grading
The project is evaluated by an autograder running the acceptance test suite in grader/test_project.py across 50 independent pseudorandom seeds (0 to 49).
