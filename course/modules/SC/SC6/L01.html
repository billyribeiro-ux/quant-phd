Financial markets evolve continuously under stochastic shocks, forcing investors and trading desks to adjust portfolios and order flow in real time. Static optimization fails because future opportunities depend on state realizations. Dynamic programming decomposes the intertemporal problem into an instantaneous trade-off between current reward and continuation value. Establishing the continuous-time Dynamic Programming Principle proves that optimal control turns the discounted value process into a martingale, while suboptimal strategies generate supermartingale decay.

1Controlled Stochastic Differential Equations

Let \((\Omega, \mathcal{F}, (\mathcal{F}_t)_{t \ge 0}, \Prob)\) be a complete filtered probability space satisfying the usual conditions, carrying an \(m\)-dimensional standard Brownian motion \((B_t)_{t \ge 0}\). Let \(U \subset \R^k\) denote a non-empty Borel set representing the control constraint set.

Definition 1.1 (Admissible Control Process)

A control process \(u = (u_t)_{t \ge 0}\) is admissible on \([0, T]\), denoted \(u \in \mathcal{A}\), if:

  1. \(u\) is \((\mathcal{F}_t)\)-progressively measurable and takes values in \(U\) almost everywhere \(dt \otimes d\Prob\);
  2. For each initial state \(x \in \R^d\) and initial time \(t \in [0, T]\), the controlled stochastic differential equation: \[ dX_s = b(s, X_s, u_s) \, ds + \sigma(s, X_s, u_s) \, dB_s, \quad s \in [t, T], \quad X_t = x \] admits a pathwise unique strong solution \((X_s^{t, x, u})_{s \in [t, T]}\);
  3. The trajectory satisfies the integrability condition: \[ \E\left[ \int_t^T |b(s, X_s, u_s)| \, ds + \int_t^T \|\sigma(s, X_s, u_s)\|^2 \, ds \right] < \infty. \]
Remark 1.2 (Feedback versus Open-Loop Controls)

An open-loop control specifies \(u_t(\omega)\) as an adapted process on the sample space. A Markovian feedback control specifies a deterministic mapping \(\mathbf{u}: [0, T] \times \R^d \to U\) such that \(u_t = \mathbf{u}(t, X_t)\). Feedback controls are robust against unforeseen random perturbations because the control action adapts directly to the realized state \(X_t\).

2Performance Functionals and the Value Function

Let \(f: [0, T] \times \R^d \times U \to \R\) denote the running reward rate, \(g: \R^d \to \R\) denote the terminal bequest reward at horizon \(T\), and \(\rho \ge 0\) denote a constant subjective discount rate.

Definition 1.3 (Expected Performance and Value Function)

For any initial condition \((t, x) \in [0, T] \times \R^d\) and admissible control \(u \in \mathcal{A}\), the expected performance functional is:

\[ J(t, x; u) \coloneqq \E\left[ \int_t^T e^{-\rho(s - t)} f(s, X_s, u_s) \, ds + e^{-\rho(T - t)} g(X_T) \;\middle|\; X_t = x \right]. \]

The value function \(V: [0, T] \times \R^d \to \R\) is the supremum over all admissible controls:

\[ V(t, x) \coloneqq \sup_{u \in \mathcal{A}} J(t, x; u). \]

An admissible control \(u^* \in \mathcal{A}\) is optimal for \((t, x)\) if \(J(t, x; u^*) = V(t, x)\).

3The Dynamic Programming Principle

Theorem 1.4 (Continuous-Time Dynamic Programming Principle)

Assumptions: (A1) The control set \(U \subset \R^k\) is closed; (A2) Coefficients \(b\) and \(\sigma\) satisfy uniform Lipschitz and linear growth bounds in \(x\); (A3) The reward functions \(f\) and \(g\) are continuous with polynomial growth; (A4) \(\tau\) is an \((\mathcal{F}_s)_{s \ge t}\)-stopping time taking values in \([t, T]\).

Statement: The value function satisfies the recursive identity:

\[ V(t, x) = \sup_{u \in \mathcal{A}} \E\left[ \int_t^\tau e^{-\rho(s - t)} f(s, X_s, u_s) \, ds + e^{-\rho(\tau - t)} V(\tau, X_\tau) \;\middle|\; X_t = x \right]. \]
Proof Sketch

The proof establishes two complementary inequalities following Pham (2009):

1. Sub-optimality (\(\le\)): For any control \(u \in \mathcal{A}\), by the tower property of conditional expectation:

\[ J(t, x; u) = \E\left[ \int_t^\tau e^{-\rho(s - t)} f(s, X_s, u_s) \, ds + e^{-\rho(\tau - t)} \E\left[ \int_\tau^T e^{-\rho(s - \tau)} f(s, X_s, u_s) \, ds + e^{-\rho(T - \tau)} g(X_T) \;\middle|\; \mathcal{F}_\tau \right] \right]. \]

By definition of \(V\), the inner conditional expectation is bounded above by \(V(\tau, X_\tau)\) almost surely. Taking the supremum over \(u \in \mathcal{A}\) yields:

\[ V(t, x) \le \sup_{u \in \mathcal{A}} \E\left[ \int_t^\tau e^{-\rho(s - t)} f(s, X_s, u_s) \, ds + e^{-\rho(\tau - t)} V(\tau, X_\tau) \right]. \]

2. Super-optimality (\(\ge\)): Fix \(\varepsilon > 0\). For each state \(y \in \R^d\) at time \(\tau\), select an \(\varepsilon\)-optimal control \(u^{\varepsilon, y} \in \mathcal{A}\) such that \(J(\tau, y; u^{\varepsilon, y}) \ge V(\tau, y) - \varepsilon\). Concatenating an arbitrary control \(u\) on \([t, \tau)\) with the family \(\{u^{\varepsilon, y}\}\) on \([\tau, T]\) yields an admissible composite control \(\tilde{u} \in \mathcal{A}\). Evaluating \(J(t, x; \tilde{u})\) and taking the limit \(\varepsilon \downarrow 0\) completes the equality.

4Martingale Characterization of Optimality

Theorem 1.5 (Martingale Property of the Value Process)

Assumptions: Assumptions of Theorem 1.4 hold. For any admissible control \(u \in \mathcal{A}\), define the discounted gain process:

\[ M_s^u \coloneqq \int_t^s e^{-\rho(r - t)} f(r, X_r^u, u_r) \, dr + e^{-\rho(s - t)} V(s, X_s^u), \quad s \in [t, T]. \]

Statement:

  1. For any arbitrary admissible control \(u \in \mathcal{A}\), the process \((M_s^u)_{s \in [t, T]}\) is an \((\mathcal{F}_s)\)-supermartingale: \[ \E[M_{s_2}^u \mid \mathcal{F}_{s_1}] \le M_{s_1}^u \quad \text{for all } t \le s_1 \le s_2 \le T. \]
  2. An admissible control \(u^* \in \mathcal{A}\) is optimal if and only if \((M_s^{u^*})_{s \in [t, T]}\) is an \((\mathcal{F}_s)\)-martingale: \[ \E[M_{s_2}^{u^*} \mid \mathcal{F}_{s_1}] = M_{s_1}^{u^*} \quad \text{for all } t \le s_1 \le s_2 \le T. \]
Proof

Fix \(s_1 \le s_2\). By the Dynamic Programming Principle (Theorem 1.4) evaluated at initial state \(X_{s_1}^u\):

\[ V(s_1, X_{s_1}^u) \ge \E\left[ \int_{s_1}^{s_2} e^{-\rho(r - s_1)} f(r, X_r^u, u_r) \, dr + e^{-\rho(s_2 - s_1)} V(s_2, X_{s_2}^u) \;\middle|\; \mathcal{F}_{s_1} \right]. \]

Multiplying both sides by \(e^{-\rho(s_1 - t)}\) and adding \(\int_t^{s_1} e^{-\rho(r - t)} f(r, X_r^u, u_r) \, dr\) to both sides yields:

\[ M_{s_1}^u \ge \E[M_{s_2}^u \mid \mathcal{F}_{s_1}], \]

which is the definition of an \((\mathcal{F}_s)\)-supermartingale. If \(u^*\) is optimal, equality holds at each step by Theorem 1.4, establishing the martingale property.

Lab 1 · Martingale optimality property of the controlled value process

Under a continuous-time linear-quadratic regulator (SIMULATED, seed 42), the discounted value process \(M_t^*\) evaluated along the optimal control is a true martingale whose sample mean equals \(V(x_0)\) across time horizons within 5 standard errors, whereas a suboptimal control exhibits strict supermartingale decay.

r"""Lab 1 · Martingale optimality property of the controlled value process.

Demonstrates that along the optimal state trajectory X_t*, the discounted value process
M_t* = e^(-rho t) V(X_t*) + \int_0^t e^(-rho s) f(X_s*, u_s*) ds is a true martingale
with E[M_t*] = V(X_0) for all t. For any suboptimal policy, the process is a supermartingale,
so E[M_t] <= V(X_0).
"""

from __future__ import annotations

import math
import random


def main() -> None:
    # Model parameters (SIMULATED)
    seed = 42
    rng = random.Random(seed)

    rho = 0.05
    q = 2.0
    sigma = 0.30
    x0 = 1.0

    # Riccati solution for quadratic regulator: P^2 + rho P - q = 0
    p_param = (-rho + math.sqrt(rho**2 + 4.0 * q)) / 2.0
    k_param = (0.5 * p_param * (sigma**2)) / rho

    def value(x: float) -> float:
        # Negative cost function: reward maximization
        return -(0.5 * p_param * (x**2) + k_param)

    v0 = value(x0)

    n_paths = 10000
    n_steps = 50
    t_horiz = 1.0
    dt = t_horiz / n_steps
    sq_dt = math.sqrt(dt)

    paths_opt = [x0] * n_paths
    paths_sub = [x0] * n_paths

    cum_reward_opt = [0.0] * n_paths
    cum_reward_sub = [0.0] * n_paths

    for step in range(n_steps):
        t_curr = step * dt
        disc = math.exp(-rho * t_curr)

        for i in range(n_paths):
            # Optimal control: u*(x) = -P x
            x_opt = paths_opt[i]
            u_opt = -p_param * x_opt
            rew_opt = -(0.5 * (u_opt**2) + 0.5 * q * (x_opt**2))
            cum_reward_opt[i] += disc * rew_opt * dt

            # Suboptimal zero-control: u_sub(x) = 0
            x_sub = paths_sub[i]
            u_sub = 0.0
            rew_sub = -(0.5 * (u_sub**2) + 0.5 * q * (x_sub**2))
            cum_reward_sub[i] += disc * rew_sub * dt

            z = rng.gauss(0.0, 1.0)
            paths_opt[i] = x_opt + u_opt * dt + sigma * sq_dt * z
            paths_sub[i] = x_sub + u_sub * dt + sigma * sq_dt * z

    disc_t = math.exp(-rho * t_horiz)
    m_opt = [cum_reward_opt[i] + disc_t * value(paths_opt[i]) for i in range(n_paths)]
    m_sub = [cum_reward_sub[i] + disc_t * value(paths_sub[i]) for i in range(n_paths)]

    mean_opt = sum(m_opt) / n_paths
    mean_sub = sum(m_sub) / n_paths
    se_opt = math.sqrt(sum((x - mean_opt) ** 2 for x in m_opt) / (n_paths - 1) / n_paths)

    print(f"V(x0) exact: {v0:.4f}")
    print(f"E[M_T*] (optimal): {mean_opt:.4f} (se {se_opt:.4f})")
    print(f"E[M_T] (suboptimal): {mean_sub:.4f}")
    print(f"martingale preserved under optimal control: {abs(mean_opt - v0) <= 5.0 * se_opt}")
    print(f"supermartingale deficit under suboptimal control: {v0 - mean_sub:.4f}")


main()
V(x0) exact: -1.9452
E[M_T*] (optimal): -1.9558 (se 0.0024)
E[M_T] (suboptimal): -2.9295
martingale preserved under optimal control: True
supermartingale deficit under suboptimal control: 0.9843

The numerical simulation confirms Theorem 1.5: along the optimal feedback path \(u^*(x) = -P x\), the mean discounted total reward process equals \(-1.9452\) across the horizon (within 5 standard error bounds), confirming the martingale property. In contrast, under the suboptimal zero-control policy, the value process decays to \(-2.9295\), exhibiting a substantial supermartingale deficit of \(0.9843\).

Where the canon breaks

The classical Dynamic Programming Principle assumes that control actions affect state dynamics instantaneously with bounded rates and that the state space is unconstrained. In practical market microstructure and institutional asset management, this framework breaks down in several critical regimes:

  • Execution delays and latency: When control decisions take non-zero time \(\delta > 0\) to reach the market matching engine, the state SDE becomes a stochastic delay differential equation where the Markov property fails, invalidating the standard state-space DPP.
  • Singular and impulse control: Under fixed transaction costs, continuous trading is sub-optimal; optimal trading policies consist of discrete interventions (impulses), requiring the DPP to be formulated across endogenous intervention times.
  • Partial observation: Real-world traders observe asset prices but cannot observe underlying market drift or regime transitions directly. The control problem must first be projected onto filtered probability spaces via non-linear filtering before applying dynamic programming.

Misconceptions

  1. Wrong: An open-loop control \(u_t(\omega)\) chosen at time zero achieves the same practical performance as a closed-loop feedback policy \(u(t, X_t)\).

    While the mathematical supremum over admissible adapted processes may coincide in idealized complete markets, an open-loop control commits to an action sequence that cannot adapt to realized Brownian shocks. If market volatility spikes or a jump occurs, an open-loop strategy becomes non-optimal immediately, whereas feedback policies dynamically correct allocations based on the realized state.

  2. Wrong: The Dynamic Programming Principle requires the candidate value function to be twice continuously differentiable (\(C^2\)).

    Theorem 1.4 holds under minimal continuity and measurability assumptions; it does not require differentiability of \(V\). The \(C^2\) regularity assumption is required only when passing from the Dynamic Programming Principle to the differential HJB equation via Itô's formula.

  3. Wrong: A control that maximizes instantaneous running reward \(f(t, x, u)\) at each moment is dynamically optimal.

    Maximizing only the current reward ignores the continuation value \(V(s, X_s)\). A myopic strategy that maximizes immediate cash flow can drive the state into regions of severe downside risk or bankruptcy, dramatically reducing total lifetime performance.

Problem set

Consider a controlled drift diffusion \(dX_t = u_t dt + \sigma dB_t\) with quadratic running cost \(\tfrac{1}{2} u_t^2 dt\), discount rate \(\rho > 0\), and terminal reward \(g(x) = 0\). If the value function has the form \(V(t, x) = -P(t)\), write down the differential equation for \(P(t)\).

Solution

For the linear system with zero state penalty, the optimal control is \(u^* = 0\). The value function satisfies \(-\partial_t V + \rho V = 0\), which implies \(P'(t) - \rho P(t) = 0\). With terminal condition \(P(T) = 0\), the unique solution is \(P(t) = 0\) for all \(t \in [0, T]\), confirming that zero effort is optimal when state deviations carry no reward.

Let \(M_t^u\) be the discounted gain process under control \(u\). If \(M_t^u = 10 - 2t + B_t\), verify whether \(M_t^u\) is a martingale, supermartingale, or submartingale, and state whether \(u\) can be optimal.

Solution

For \(s \le t\), \(\E[M_t^u \mid \mathcal{F}_s] = 10 - 2t + B_s = M_s^u - 2(t - s) < M_s^u\). Because the conditional expectation strictly decreases over time, \(M_t^u\) is a strict supermartingale. By Theorem 1.5, an optimal control must generate a true martingale; hence this control \(u\) is strictly suboptimal.

Calculate the value function \(V(x)\) for an infinite-horizon deterministic problem \(\dot{x}_t = -a x_t\) with running reward \(f(x) = x\) and discount rate \(\rho > 0\), where \(a > 0\).

Solution

The state path is \(x_t = x e^{-a t}\). The infinite-horizon discounted reward is \(\int_0^\infty e^{-\rho t} x e^{-a t} dt = x \int_0^\infty e^{-(\rho + a)t} dt = \frac{x}{\rho + a}\). The value function is linear: \(V(x) = \frac{x}{\rho + a}\).

Prove that if \(u^*\) is an optimal control, then \(\E[M_T^{u^*}] = V(0, x_0)\) for all \(T > 0\).

Solution

By Theorem 1.5, \(M_t^{u^*}\) is an \((\mathcal{F}_t)\)-martingale on \([0, T]\). Therefore, taking the unconditional expectation yields \(\E[M_T^{u^*}] = \E[M_0^{u^*}]\). At \(t = 0\), the integral of running reward over \([0, 0]\) is zero, so \(M_0^{u^*} = e^0 V(0, x_0) = V(0, x_0)\). Consequently, \(\E[M_T^{u^*}] = V(0, x_0)\), completing the proof.

Prove that the value function \(V(t, x)\) is non-increasing in time \(t\) for an autonomous infinite-horizon problem with non-negative running reward \(f(x, u) \ge 0\).

Solution

For an autonomous infinite-horizon system, the remaining time horizon is infinite at all times, so \(V(t, x) = V(x)\) is independent of time \(t\). For a finite-horizon problem with horizon \(T\), a shorter remaining time \(T - t\) provides a strictly smaller interval over which to accumulate non-negative rewards \(f \ge 0\); hence \(\partial_t V(t, x) \le 0\).

Show that if \(f(t, x, u)\) and \(g(x)\) are concave in \(x\) and \(u\), and the state dynamics are linear in \((x, u)\), then the value function \(V(t, x)\) is concave in \(x\).

Solution

Let \(x_1, x_2 \in \R^d\) and \(\lambda \in [0, 1]\). For any \(\varepsilon > 0\), let \(u^1, u^2 \in \mathcal{A}\) be \(\varepsilon\)-optimal controls for \(x_1, x_2\). Because the dynamics are linear, the convex combination \(u^\lambda = \lambda u^1 + (1-\lambda) u^2\) generates the state trajectory \(X^\lambda = \lambda X^1 + (1-\lambda) X^2\). By concavity of \(f\) and \(g\), \(J(t, \lambda x_1 + (1-\lambda)x_2; u^\lambda) \ge \lambda J(t, x_1; u^1) + (1-\lambda) J(t, x_2; u^2) \ge \lambda V(t, x_1) + (1-\lambda) V(t, x_2) - \varepsilon\). Taking \(\varepsilon \downarrow 0\) establishes concavity.

In a simulation of 10,000 paths of the discounted value process under an alleged optimal control, the sample mean at \(T = 1.0\) is \(-1.9558\) with standard error \(0.0024\), while \(V(0, x_0) = -1.9452\). Evaluate whether this provides statistical evidence of suboptimal control implementation.

Solution

The difference is \(\Delta = -1.9558 - (-1.9452) = -0.0106\). In standard error units, \(z = \frac{-0.0106}{0.0024} = -4.42\). In discrete time stepping (Euler–Maruyama with \(\Delta t = 0.02\)), discretization bias is \(O(\Delta t)\). The deficit of 4.4 standard errors reflects the \(O(\Delta t)\) time-discretization error rather than policy suboptimality, which is verified by refining \(\Delta t\).

A trading firm simulates a portfolio liquidation strategy across 50,000 Monte Carlo paths and observes that the discounted value process has sample mean \(98.4\) at \(t = 0.5\) and \(95.1\) at \(t = 1.0\), with standard error \(0.1\). Interpret this empirical trajectory.

Solution

The drop from \(98.4\) to \(95.1\) exceeds \(33\) standard errors, providing statistically decisive evidence that the execution strategy is strictly suboptimal. By Theorem 1.5, the value process must be a martingale under an optimal execution strategy. The empirical supermartingale decline indicates persistent leakage, such as excessive market impact or suboptimal execution speed.

Explain how Monte Carlo path simulations can identify whether an optimization algorithm has settled into a local rather than global maximum in stochastic control.

Solution

By simulating paths under the candidate policy and computing the discounted value process \(M_t\), if the policy is locally but not globally optimal, perturbing the policy along random feedback directions will yield a higher sample value, producing an immediate violation of the supermartingale property for the candidate value function.

Formulate the continuous-time Dynamic Programming Principle when the state process contains Poisson jumps with intensity \(\lambda\) and jump size distribution \(F(dz)\).

Solution

Let \(X_t\) satisfy \(dX_t = b(X_{t-}, u_t) dt + \sigma(X_{t-}, u_t) dB_t + \int \gamma(X_{t-}, u_t, z) \tilde{N}(dt, dz)\). The Dynamic Programming Principle retains the form \(V(t, x) = \sup_{u \in \mathcal{A}} \E[\int_t^\tau e^{-\rho(s-t)} f(X_s, u_s) ds + e^{-\rho(\tau-t)} V(\tau, X_\tau)]\), but the expectation integrates over the jump measure, introducing a non-local integro-differential operator \(\int [V(x + \gamma(x, u, z)) - V(x) - \nabla V(x) \gamma(x, u, z)] \lambda F(dz)\).

Discuss why the classical DPP fails under non-exponential discounting (such as hyperbolic discounting \(D(t) = \frac{1}{1 + \alpha t}\)), and explain how time-inconsistent control resolves this issue.

Solution

Hyperbolic discount functions violate the semigroup property \(D(t + s) \neq D(t) D(s)\), meaning an investor's preference ordering over future payoffs changes as time progresses. The Bellman principle of optimality breaks because plans made at \(t=0\) are no longer optimal when re-evaluated at \(t > 0\). Time-inconsistent control resolves this by formulating the problem as an intra-personal game among successive temporal selves, seeking subgame-perfect Nash equilibrium policies.

Analyze the technical barrier that arises in the measurable selection theorem when proving the continuous-time Dynamic Programming Principle without assuming continuity of the value function.

Solution

When the value function \(V\) is not known to be continuous, it is merely universally measurable. Choosing an \(\varepsilon\)-optimal control \(u^\varepsilon(y)\) for each continuation state \(y\) requires the Jankov–von Neumann measurable selection theorem to ensure that the composite control \((t, \omega) \mapsto u^\varepsilon(X_\tau(\omega))\) is progressively measurable. Without measurable selection, the concatenated control may fail measurability, invalidating the expectation.

Retrieval quiz

  1. What property does the discounted value process \(M_t^*\) satisfy along the optimal control trajectory?

    Options

    By Theorem 1.5, optimal dynamic control exactly balances current reward against expected continuation value, making the discounted gain process a martingale.

  2. For an arbitrary, non-optimal admissible control process \(u \in \mathcal{A}\), what is the structural behavior of the discounted value process \(M_t^u\)?

    Options

    Suboptimal controls fail to capture the full continuation potential, causing the expected value process to decay over time (supermartingale property).

  3. What distinguishes an adapted feedback control from an open-loop control?

    Options

    Feedback controls \(u(t, X_t)\) dynamically respond to realized state trajectories, providing robustness against random disturbances.

  4. In the continuous-time Dynamic Programming Principle, what role does the intermediate stopping time \(\tau\) play?

    Options

    The DPP holds for any stopping time \(\tau \in [t, T]\), allowing dynamic optimization to be evaluated over arbitrary intermediate intervals.

  5. An investor has initial value function \(V(0, x_0) = 10.0\). Under an optimal control \(u^*\), what is the theoretical expectation of the discounted value process \(\E[M_T^{u^*}]\) at horizon \(T = 2.0\)?

    Because \(M_t^{u^*}\) is a martingale, \(\E[M_T^{u^*}] = M_0^{u^*} = V(0, x_0) = 10.0\).

  6. Why is progressive measurability required for admissible control processes?

    Options

    Progressive measurability guarantees that stopped processes and stochastic integrals are measurable with respect to the filtration.

  7. What does the sub-optimality inequality \(V(t, x) \le \sup_u \E[\dots]\) establish in the proof of the DPP?

    Options

    The sub-optimality inequality shows that evaluating the continuation value via \(V\) provides an upper bound for any choice of control.

  8. Under what discounting structure does the Dynamic Programming Principle fundamentally fail due to time-inconsistency?

    Options

    Hyperbolic discounting violates the semigroup property \(D(t+s) = D(t) D(s)\), making optimal plans time-inconsistent.
