Why Policy Iteration Matters

Continuous-time portfolio optimization rarely yields closed-form solutions once realistic trading frictions, short-sale bans, or borrowing caps are imposed. While value iteration (explicit pseudo-time stepping) suffers severe diffusion stiffness requiring \(\mathcal{O}(\Delta w^2)\) time steps, Howard's policy iteration alternates between linear sparse tridiagonal solves (policy evaluation) and pointwise Hamiltonian maximization (policy improvement). Policy iteration converges monotonically and exhibits local quadratic convergence as a generalized Newton–Kantorovich method. In quantitative trading and asset management, this enables solving multi-asset portfolio choice and consumption models with binding leverage constraints in milliseconds.

1The Non-Linear Bellman Operator & Computational Complexity

Let \(\Omega = (w_{\min}, w_{\max})\) with \(0 < w_{\min} < w_{\max} < \infty\) be the bounded state space for investor wealth. Consider the stationary Hamilton–Jacobi–Bellman equation for the Merton model:

\[ \rho V(w) - \sup_{(\pi, c) \in U} \left\{ \left[ (r + \pi(\mu - r)) w - c \right] V'(w) + \frac{1}{2} \pi^2 \sigma^2 w^2 V''(w) + U(c) \right\} = 0, \quad w \in \Omega. \]

We represent this non-linear boundary value problem compactly as \(\mathcal{F}(V) = 0\), where the non-linear Bellman operator \(\mathcal{F}\) acts on candidate value functions \(V \in C^2(\Omega)\):

\[ \mathcal{F}(V)(w) \coloneqq \rho V(w) - \sup_{u \in U} \left\{ \mathcal{L}^u V(w) + f(w, u) \right\}, \]

with drift-diffusion generator \(\mathcal{L}^u V(w) = b(w, u) V'(w) + \frac{1}{2} \sigma(w, u)^2 V''(w)\) and running utility \(f(w, u) = U(c)\) under control vector \(u = (\pi, c)\).

In discrete-time dynamic programming, the standard technique is value function iteration (VFI), which computes successive Picard iterates \(V^{(k+1)} = \mathcal{T}(V^{(k)})\) where \(\mathcal{T}\) is the Bellman contraction mapping. In continuous-time finite differences, naive value iteration corresponds to explicit Euler pseudo-time stepping:

\[ \frac{V^{(k+1)} - V^{(k)}}{\Delta \tau} + \rho V^{(k)} = \max_{u \in U} \left\{ A[u] V^{(k)} + f[u] \right\}. \]

However, the explicit parabolic stability condition dictates:

\[ \Delta \tau \le \frac{\Delta w^2}{\sup_u \sigma(w, u)^2} = \frac{\Delta w^2}{\pi_{\max}^2 \sigma^2 w_{\max}^2}. \]

On a mesh with \(N = 200\) nodes spanning \([1, 10]\), \(\Delta w = 0.045\), requiring \(\Delta \tau \approx 10^{-4}\). To reach stationary equilibrium (\(\tau \to \infty\)), explicit value iteration requires over \(100{,}000\) iterations, each bounded by the linear convergence rate \(\mathcal{O}(1 - \rho \Delta \tau)\). This extreme stiffness motivates an implicit, operator-level solution strategy: Howard's policy iteration.

2Howard's Policy Iteration Algorithm

The central insight of Ronald Howard (1960) is that the non-linearity in the HJB equation stems entirely from the supremum over controls \(u \in U\). For any fixed policy \(\mathbf{u}: \Omega \to U\), the operator \(\rho I - \mathcal{L}^{\mathbf{u}}\) is strictly linear and invertible.

Definition 2.1 (Policy Iteration)

Policy iteration is an iterative algorithm for solving non-linear HJB and Bellman equations by alternating between policy evaluation (solving a linear boundary value problem for the value function under a frozen policy) and policy improvement (pointwise maximization of the Hamiltonian given the current value function gradient and curvature).

Algorithm 2.2 (Continuous-State Policy Iteration on Finite-Difference Mesh)

Input: Mesh \(\{w_i\}_{i=0}^N\), boundary conditions \(V(w_0), V(w_N)\), tolerance \(\varepsilon_{\mathrm{tol}} > 0\), initial policy \(u^{(0)} = (\pi^{(0)}, c^{(0)})\).

For iteration \(k = 0, 1, 2, \dots\):

  1. Policy Evaluation: Given fixed policy \(u^{(k)} = \{(\pi_i^{(k)}, c_i^{(k)})\}_{i=1}^{N-1}\), construct the tridiagonal generator matrix \(A[u^{(k)}] \in \R^{(N-1) \times (N-1)}\) using upwind drift differencing and central diffusion differencing. Solve the linear system for the interior value vector \(V^{(k)} \in \R^{N-1}\): \[ \left( \rho I - A[u^{(k)}] \right) V^{(k)} = f[u^{(k)}]. \] Because \(\rho I - A[u^{(k)}]\) is a strictly diagonally dominant M-matrix, this tridiagonal system is solved in \(\mathcal{O}(N)\) operations via the Thomas algorithm.
  2. Policy Improvement: Using finite differences of \(V^{(k)}\), compute discrete approximations for the first derivative \(V_i'^{(k)}\) and second derivative \(V_i''^{(k)}\) at each interior node \(i = 1, \dots, N-1\). Update the policy pointwise: \[ u_i^{(k+1)} = \arg\max_{u \in U} \left\{ b(w_i, u) V_i'^{(k)} + \frac{1}{2} \sigma(w_i, u)^2 V_i''^{(k)} + f(w_i, u) \right\}. \]
  3. Stopping Criterion: Compute the maximum absolute policy and value update: \[ \|V^{(k)} - V^{(k-1)}\|_\infty \coloneqq \max_{1 \le i \le N-1} |V_i^{(k)} - V_i^{(k-1)}|. \] If \(\|V^{(k)} - V^{(k-1)}\|_\infty < \varepsilon_{\mathrm{tol}}\) (or if the discrete policy stabilizes \(u^{(k+1)} = u^{(k)}\)), terminate and return \(V^* = V^{(k)}\) and \(u^* = u^{(k+1)}\).
Theorem 2.3 (Monotone Convergence of Policy Iteration)

Let the spatial discretization matrix \(M[u] \coloneqq \rho I - A[u]\) be an M-matrix for all admissible controls \(u \in U\), so that \(M[u]^{-1} \ge 0\) entrywise. Let \(V^{(k)}\) be the sequence of iterates generated by Algorithm 2.2 starting from an arbitrary initial policy \(u^{(0)}\). Then:

  1. Monotonicity: The value sequence is non-decreasing pointwise: \[ V_i^{(0)} \le V_i^{(1)} \le V_i^{(2)} \le \dots \le V_i^* \quad \text{for all } i = 1, \dots, N-1. \]
  2. Finite Convergence on Finite Action Sets: If the admissible control set \(U\) is finite with \(|U| < \infty\), the policy iteration algorithm terminates in a finite number of steps with the exact solution to the discretized Bellman equation.
  3. Global Convergence for Compact Controls: If \(U\) is compact and the Hamiltonian is strictly concave, \(V^{(k)}\) converges globally to the unique discrete viscosity solution \(V^*\) as proved in Pham (2009).
Proof of Monotonicity

Let \(V^{(k)}\) satisfy the policy evaluation equation for policy \(u^{(k)}\):

\[ M[u^{(k)}] V^{(k)} = f[u^{(k)}]. \]

In the policy improvement step, \(u^{(k+1)}\) is chosen to maximize the Hamiltonian pointwise node-by-node. Therefore, at each interior node:

\[ A[u^{(k+1)}] V^{(k)} + f[u^{(k+1)}] \ge A[u^{(k)}] V^{(k)} + f[u^{(k)}] = \rho V^{(k)}. \]

Rearranging this inequality in matrix notation:

\[ f[u^{(k+1)}] - (\rho I - A[u^{(k+1)}]) V^{(k)} \ge 0 \implies f[u^{(k+1)}] - M[u^{(k+1)}] V^{(k)} \ge 0. \]

Now consider the next iterate \(V^{(k+1)}\), which satisfies \(M[u^{(k+1)}] V^{(k+1)} = f[u^{(k+1)}]\). Subtracting \(M[u^{(k+1)}] V^{(k)}\) from both sides yields:

\[ M[u^{(k+1)}] \left( V^{(k+1)} - V^{(k)} \right) = f[u^{(k+1)}] - M[u^{(k+1)}] V^{(k)} \ge 0. \]

Because the spatial discretization guarantees that \(M[u^{(k+1)}]\) is an M-matrix, its inverse is entrywise non-negative (\(M[u^{(k+1)}]^{-1} \ge 0\)). Multiplying both sides by \(M[u^{(k+1)}]^{-1}\) preserves the inequality:

\[ V^{(k+1)} - V^{(k)} = M[u^{(k+1)}]^{-1} \left( f[u^{(k+1)}] - M[u^{(k+1)}] V^{(k)} \right) \ge 0. \]

Hence \(V^{(k+1)} \ge V^{(k)}\) at every node. Since the discrete value function is bounded from above by the true supremum, the monotone sequence must converge to the unique solution of the discrete HJB equation.

3Newton's Method Interpretation & Quadratic Local Convergence

Policy iteration is not merely an intuitive heuristic; it is mathematically equivalent to the generalized Newton–Kantorovich method applied to the non-linear discrete Bellman operator studied in continuous-time optimal control.

Define the discrete non-linear mapping \(\mathcal{F}: \R^{N-1} \to \R^{N-1}\) by:

\[ \mathcal{F}(V) \coloneqq \rho V - \max_{u \in U} \left\{ A[u] V + f[u] \right\}. \]

For any vector \(V\), let \(\mathbf{u}^*(V) = \arg\max_{u \in U} \{ A[u] V + f[u] \}\). By Danskin's theorem, whenever the maximizer is unique, the directional derivative (Jacobian) of \(\mathcal{F}\) with respect to \(V\) is given by the linear operator associated with the optimal policy:

\[ D\mathcal{F}(V) = \rho I - A[\mathbf{u}^*(V)] = M[\mathbf{u}^*(V)]. \]

The standard Newton step for solving \(\mathcal{F}(V) = 0\) given current guess \(V^{(k)}\) is:

\[ V^{(k+1)} = V^{(k)} - \left[ D\mathcal{F}(V^{(k)}) \right]^{-1} \mathcal{F}(V^{(k)}). \]

Substituting \(D\mathcal{F}(V^{(k)}) = M[u^{(k+1)}]\) and \(\mathcal{F}(V^{(k)}) = M[u^{(k+1)}] V^{(k)} - f[u^{(k+1)}]\):

\[ V^{(k+1)} = V^{(k)} - M[u^{(k+1)}]^{-1} \left( M[u^{(k+1)}] V^{(k)} - f[u^{(k+1)}] \right) = M[u^{(k+1)}]^{-1} f[u^{(k+1)}]. \]

This is precisely the policy evaluation step of Howard's algorithm! Because policy iteration is a realization of Newton's method:

  • Local Quadratic Convergence: In the neighborhood of the solution \(V^*\), the error decays quadratically: \[ \|V^{(k+1)} - V^*\| \le C \|V^{(k)} - V^*\|^2. \]
  • Global Monotonicity: Unlike standard Newton methods for general non-linear equations—which frequently diverge or cycle if initialized far from the root—policy iteration possesses global convergence with unconditional monotonic increase, guaranteed by the concavity of the Hamiltonian and the M-matrix inverse positivity.

4Enforcing Portfolio & Borrowing Constraints

In practical quantitative portfolio management, leverage and borrowing are restricted by regulatory margins or risk mandates. Consider the constrained control set:

\[ U = [0, \pi_{\max}] \times (0, \infty), \quad \text{where } \pi_{\max} \ge 0. \]

The unconstrained first-order condition for the optimal portfolio fraction in the HJB Hamiltonian yields:

\[ \pi_{\mathrm{unc}}(w) = -\frac{\mu - r}{\sigma^2 w} \frac{V'(w)}{V''(w)}. \]

Because the Hamiltonian \(\pi \mapsto (\mu - r) \pi w V'(w) + \frac{1}{2} \pi^2 \sigma^2 w^2 V''(w)\) is strictly concave in \(\pi\) (as \(V''(w) < 0\)), the constrained maximizer over the compact interval \([0, \pi_{\max}]\) is obtained by simple projection (clamping):

\[ \pi^*(w) = \min\left( \max\left( \pi_{\mathrm{unc}}(w), 0 \right), \pi_{\max} \right). \]
Theorem 4.1 (Analytical Solution under Binding Borrowing Constraint)

Suppose the unconstrained Merton fraction exceeds the borrowing bound, \(\pi^*_{\mathrm{unc}} = \frac{\mu - r}{\gamma \sigma^2} > \pi_{\max}\). If the investor is constrained to \(\pi_t \le \pi_{\max}\) for all \(t \ge 0\), the optimal portfolio weight is constant and clamped to the upper bound:

\[ \pi^*(w) = \pi_{\max} \quad \text{for all } w > 0. \]

The constrained value function retains the power-law homothetic form \(V(w) = \frac{A_{\mathrm{constr}}}{1 - \gamma} w^{1 - \gamma}\), with constant:

\[ A_{\mathrm{constr}} = \nu_{\mathrm{constr}}^{-\gamma}, \quad \text{where } \nu_{\mathrm{constr}} \coloneqq \frac{1}{\gamma} \left[ \rho - (1 - \gamma) k_{\mathrm{constr}} \right], \]

and the effective growth rate under the constrained portfolio is:

\[ k_{\mathrm{constr}} \coloneqq r + \pi_{\max}(\mu - r) - \frac{1}{2} \gamma \pi_{\max}^2 \sigma^2. \]

The optimal consumption policy remains strictly linear in wealth: \(c^*(w) = \nu_{\mathrm{constr}} w\).

Notice that when \(\pi_{\max} = \pi^*_{\mathrm{unc}}\), \(k_{\mathrm{constr}}\) attains its global maximum \(k = r + \frac{(\mu - r)^2}{2 \gamma \sigma^2}\), reducing exactly to Merton's unconstrained solution. When \(\pi_{\max} < \pi^*_{\mathrm{unc}}\), \(k_{\mathrm{constr}} < k\), reducing the effective risk-adjusted growth rate and decreasing total investor welfare (\(V_{\mathrm{constr}}(w) < V_{\mathrm{unc}}(w)\)).

Where Canonical Assumptions Break Down

In academic finance textbooks, Merton's problem is frequently presented as an idealized closed-form equation. In production quantitative finance, canonical assumptions fail in three critical dimensions:

  • Homotheticity Collapse under Asymmetric Margin Borrowing: When borrowing costs exceed lending rates (\(r_{\mathrm{borrow}} > r_{\mathrm{lend}}\)), the wealth process is no longer homothetic. The value function ceases to be a simple power law \(A w^{1-\gamma}\); instead, it develops three distinct economic regimes: a lending regime (\(\pi < 1\)), an unleveraged equity regime (\(\pi = 1\)), and a leveraged borrowing regime (\(\pi > 1\)). Closed-form solutions do not exist, and numerical policy iteration is required to resolve the free boundaries between regimes.
  • Catastrophic Stiffness of Value Iteration: Relying on explicit pseudo-time stepping (VFI) to solve continuous-time HJB equations requires an unfeasible number of time steps (\(\Delta \tau \le \mathcal{O}(\Delta w^2)\)). Attempting to accelerate VFI with larger time steps creates severe numerical oscillations that violate the discrete maximum principle, whereas policy iteration solves the implicit system directly in 5 to 15 iterations.
  • Degeneracy of Gradient at Domain Boundaries: Standard central differencing for \(\partial_w V\) at the wealth boundaries \(w_{\min}\) and \(w_{\max}\) evaluates ghost points outside the admissible domain. If the boundary conditions are not strictly enforced via one-sided upwind stencils, the policy improvement step produces unconstrained feedback controls that drive simulated wealth into negative territory, terminating execution.

Common Misconceptions

  • Misconception 1: "Policy iteration requires solving a non-linear system at every step."

    Correction: Policy iteration completely decouples the non-linearity from the spatial differential operator. Step 1 (Policy Evaluation) solves a strictly linear sparse tridiagonal system \((\rho I - A) V = f\), which is solved in \(\mathcal{O}(N)\) operations via forward-backward substitution. Step 2 (Policy Improvement) performs uncoupled 1D scalar maximizations independently at each spatial node. At no point is a non-linear multivariate algebraic system solved.

  • Misconception 2: "Because policy iteration is Newton's method, it requires a close initial guess to avoid divergence."

    Correction: Standard Newton methods for arbitrary non-linear equations can diverge or cycle from poor initializations. However, for HJB equations discretized with an M-matrix stencil, the operator \(\mathcal{F}\) is concave. Under concavity and M-matrix monotonicity, the Newton–Howard iteration enjoys global monotone convergence starting from any arbitrary initial policy, such as \(\pi^{(0)} = 0\).

  • Misconception 3: "Adding borrowing constraints requires solving a quadratic program with Lagrange multipliers at each node."

    Correction: For 1D portfolio selection with CRRA utility, the Hamiltonian is a strictly concave parabola in the risky asset weight \(\pi\). The unconstrained vertex is \(\pi_{\mathrm{unc}} = -\frac{\mu - r}{\sigma^2 w} \frac{V'}{V''}\). By Karush–Kuhn–Tucker (KKT) theory for 1D bound constraints, the constrained maximizer is simply the projection (clamping) of \(\pi_{\mathrm{unc}}\) onto \([0, \pi_{\max}]\), computable in \(\mathcal{O}(1)\) arithmetic operations without iterative quadratic programming solvers.

Practice Problems

Tier 1: Warmup & Foundational Mechanics

  1. Problem 1.1: Under policy evaluation, a frozen policy \(\pi(w) = 0.40\) generates an upwind drift \(b_i = 0.08 w_i\) and diffusion \(a_i = 0.5 \times (0.40)^2 \times (0.20)^2 w_i^2 = 0.0032 w_i^2\). For \(w_i = 2.0\), \(\Delta w = 0.05\), and \(\rho = 0.05\), compute the central diffusion coefficient \(\alpha_i = \frac{a_i}{\Delta w^2}\) and upwind drift coefficient \(\beta_i = \frac{b_i}{\Delta w}\).

    Solution: First compute the state-dependent coefficients at \(w_i = 2.0\): \(a_i = 0.0032 \times (2.0)^2 = 0.0128\), and \(b_i = 0.08 \times 2.0 = 0.16\). The central diffusion coefficient is \(\alpha_i = \frac{a_i}{\Delta w^2} = \frac{0.0128}{0.0025} = 5.12\). The forward upwind drift coefficient is \(\beta_i = \frac{b_i}{\Delta w} = \frac{0.16}{0.05} = 3.20\). Both coefficients are strictly positive, ensuring diagonal dominance.

  2. Problem 1.2: An investor with \(\gamma = 2.0\) faces market parameters \(r = 0.03\), \(\mu = 0.09\), and \(\sigma = 0.20\). The borrowing mandate restricts \(\pi \le 0.60\). Calculate the unconstrained Merton fraction and determine whether the borrowing constraint binds.

    Solution: The unconstrained Merton fraction is \(\pi^* = \frac{\mu - r}{\gamma \sigma^2} = \frac{0.09 - 0.03}{2.0 \times 0.04} = \frac{0.06}{0.08} = 0.75\). Because the borrowing mandate caps risky exposure at \(\pi_{\max} = 0.60\), the constraint binds strictly, forcing the constrained optimal allocation to \(\pi^*(w) = 0.60\).

  3. Problem 1.3: State the computational complexity of solving an \(N\)-node tridiagonal linear system using the Thomas algorithm, and explain why this makes policy evaluation efficient.

    Solution: The Thomas algorithm solves an \(N \times N\) tridiagonal system in exactly \(\mathcal{O}(N)\) floating point operations and \(\mathcal{O}(N)\) memory storage, compared to \(\mathcal{O}(N^3)\) for dense Gaussian elimination. This linear complexity allows policy evaluation on fine meshes with hundreds of grid points to execute in under one millisecond.

Tier 2: Core Procedural & Algorithmic Tasks

  1. Problem 2.1: At mesh node \(i\), numerical differentiation yields \(V_i' = 0.50\) and \(V_i'' = -1.25\) at wealth \(w_i = 1.0\). For market parameters \(\mu = 0.08\), \(r = 0.02\), and \(\sigma = 0.20\), evaluate the unconstrained portfolio update \(\pi_{\mathrm{unc}}\). If the policy constraint is \(0 \le \pi \le 0.50\), find the updated control \(\pi_i^{(k+1)}\).

    Solution: The unconstrained policy update evaluates the vertex of the quadratic Hamiltonian: \(\pi_{\mathrm{unc}} = -\frac{\mu - r}{\sigma^2 w_i} \frac{V_i'}{V_i''} = -\frac{0.06}{0.04 \times 1.0} \frac{0.50}{-1.25} = (-1.5) \times (-0.40) = 0.60\). Projecting onto the admissible interval \([0, 0.50]\) yields \(\pi_i^{(k+1)} = \min(0.60, 0.50) = 0.50\).

  2. Problem 2.2: Consider the constrained effective growth rate \(k_{\mathrm{constr}} = r + \pi_{\max}(\mu - r) - \frac{1}{2} \gamma \pi_{\max}^2 \sigma^2\). For \(r = 0.04\), \(\mu = 0.10\), \(\sigma = 0.20\), \(\gamma = 3.0\), and \(\pi_{\max} = 0.40\), calculate \(k_{\mathrm{constr}}\) and compare it to the unconstrained growth rate \(k_{\mathrm{unc}}\).

    Solution: First compute unconstrained \(\pi^* = \frac{0.06}{3.0 \times 0.04} = 0.50\), yielding \(k_{\mathrm{unc}} = 0.04 + \frac{(0.06)^2}{2 \times 3.0 \times 0.04} = 0.04 + \frac{0.0036}{0.24} = 0.0550\). For constrained \(\pi_{\max} = 0.40\), \(k_{\mathrm{constr}} = 0.04 + 0.40 \times 0.06 - 0.5 \times 3.0 \times (0.40)^2 \times 0.04 = 0.04 + 0.0240 - 0.0096 = 0.0544\). The leverage constraint causes a welfare drag of \(0.0550 - 0.0544 = 0.0006\) (6 basis points in annualized growth rate).

  3. Problem 2.3: In a numerical HJB solver, the maximum iterate difference satisfies \(\|V^{(k+1)} - V^{(k)}\|_\infty = 0.015\) at \(k = 4\), and \(\|V^{(k+2)} - V^{(k+1)}\|_\infty = 0.000225\) at \(k = 5\). Demonstrate whether this behavior is consistent with quadratic convergence.

    Solution: Quadratic convergence requires \(\|e_{k+1}\| \approx C \|e_k\|^2\). Here, \(\|e_4\|^2 = (0.015)^2 = 0.000225\), which exactly matches \(\|e_5\| = 0.000225\) with constant \(C = 1.0\). This rapid squaring of the residual error is the signature of Newton–Kantorovich quadratic convergence inherent to policy iteration.

Tier 3: Proof & Mathematical Rigor

  1. Problem 3.1: Prove that if \(\rho > 0\) and \(A[u]\) is a continuous-time Markov generator matrix satisfying \(A_{ii} < 0\), \(A_{ij} \ge 0\) for \(j \ne i\), and \(\sum_j A_{ij} \le 0\), then \(M[u] = \rho I - A[u]\) is an M-matrix with strictly positive diagonal elements and entrywise non-negative inverse.

    Solution: The diagonal entries are \(M_{ii} = \rho - A_{ii} > \rho > 0\). The off-diagonal entries are \(M_{ij} = -A_{ij} \le 0\) for \(i \ne j\), establishing that \(M\) is a Z-matrix. Furthermore, the row sums satisfy \(\sum_j M_{ij} = \rho - \sum_j A_{ij} \ge \rho > 0\). Thus \(M\) is strictly row diagonally dominant with positive diagonal entries. By the standard M-matrix characterization theorem, \(M\) is non-singular and its inverse is entrywise non-negative (\(M^{-1} \ge 0\)).

  2. Problem 3.2: Prove that the policy improvement step is guaranteed to find the unique global maximum of the Hamiltonian \(\mathcal{H}(\pi; w, V', V'') = (\mu - r) \pi w V' + \frac{1}{2} \pi^2 \sigma^2 w^2 V''\) over \(\pi \in [0, \pi_{\max}]\) whenever \(V'' < 0\).

    Solution: Compute the second derivative with respect to \(\pi\): \(\frac{\partial^2 \mathcal{H}}{\partial \pi^2} = \sigma^2 w^2 V''\). Since \(\sigma > 0\), \(w > 0\), and \(V'' < 0\), we have \(\frac{\partial^2 \mathcal{H}}{\partial \pi^2} < 0\) strictly. Hence \(\mathcal{H}\) is strictly concave in \(\pi\). A strictly concave continuous function on a closed interval \([0, \pi_{\max}]\) possesses a unique global maximum, which is either the unconstrained stationary point \(\pi_{\mathrm{unc}}\) if \(\pi_{\mathrm{unc}} \in [0, \pi_{\max}]\), or the boundary endpoint closest to \(\pi_{\mathrm{unc}}\).

  3. Problem 3.3: Prove that the sequence of value functions \(V^{(k)}\) in policy iteration is bounded above by the optimal discrete value function \(V^*\).

    Solution: For any iterate \(k\), \(M[u^*] V^* = f[u^*] \ge M[u^{(k)}] V^* + f[u^{(k)}] - M[u^{(k)}] V^*\). By definition of policy evaluation, \(M[u^{(k)}] V^{(k)} = f[u^{(k)}]\). Therefore, \(M[u^{(k)}] (V^* - V^{(k)}) = M[u^{(k)}] V^* - f[u^{(k)}] \ge M[u^*] V^* - f[u^*] = 0\). Multiplying by \(M[u^{(k)}]^{-1} \ge 0\) yields \(V^* - V^{(k)} \ge 0\), proving \(V^{(k)} \le V^*\) for all \(k\).

Tier 4: Applied Diagnostic & Implementation Debugging

  1. Problem 4.1: A quantitative researcher implements policy iteration but finds that on coarse grids (\(N = 30\)), the algorithm cycles between two policies \(\pi_A\) and \(\pi_B\) and never terminates. Inspecting the code reveals central differencing was used for the drift term. Explain the root cause of this failure.

    Solution: When central differencing is used for the convective drift on a coarse grid, the mesh Peclet number \(P_e = \frac{|b_i| \Delta w}{2 a_i} > 1\). This causes off-diagonal elements in the discretization matrix to become positive, violating the Z-matrix condition. As a result, \(M[u]^{-1}\) is no longer entrywise non-negative, destroying the monotone property of policy iteration and permitting limit cycles and policy oscillation.

  2. Problem 4.2: Suppose your solver produces \(\pi^*(w)\) that exceeds \(\pi_{\max}\) by \(0.001\) at the rightmost boundary node \(w_N\). Diagnosing the boundary condition implementation, what error is most likely present?

    Solution: The policy improvement step was mistakenly executed at the boundary node \(i = N\) using a centered difference stencil that sampled an undefined ghost node \(w_{N+1}\). Boundary nodes are Dirichlet nodes whose values and policies must be fixed analytically from the asymptotic boundary conditions; the policy improvement step should only be executed at interior nodes \(1 \le i \le N-1\).

  3. Problem 4.3: In evaluating \(V_i''^{(k)}\) during policy improvement, what safeguard should be applied before dividing by \(V_i''^{(k)}\) in the unconstrained Merton fraction formula, and why?

    Solution: Numerical rounding errors or initial transients can cause \(V_i''^{(k)}\) to become positive or zero (\(V_i'' \ge -\varepsilon\)), which would invert the sign of the policy or cause a division-by-zero exception. The implementation must safeguard against this by enforcing strict negativity, for example by clipping \(V_i'' \le -\delta\) with \(\delta = 10^{-12}\), or directly evaluating the Hamiltonian on a discrete control grid if curvature degenerates.
