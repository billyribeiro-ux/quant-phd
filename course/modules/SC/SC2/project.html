Itô Derivations Workbook

A quantitative researcher must reliably derive the exact stochastic differential dynamics of transformed nonlinear financial processes and verify the analytical drift and diffusion against numerical simulation. This project develops a formal mathematical workbook of ten transformations spanning geometric Brownian motion and Ornstein–Uhlenbeck diffusions alongside a modular numerical validation engine.

The ladder

  1. Rung 1 · Worked example

    A fully solved derivation and numerical verification of Transform 1 (log price of geometric Brownian motion) on the seed 0 SIMULATED instance, annotated with the justification for every step.

  2. Rung 2 · Completion problem

    Complete the missing Itô correction and exact residual comparison lines in the verification script, graded instantly in the browser.

  3. Rung 3 · Independent project

    Derive the continuous-time dynamics of ten transformed processes, implement the numerical verification module ito_checks.py, and produce a formal derivations report. Graded by the autograder and rubric.

  4. Rung 4 · Stretch

    Extend the Itô framework to two-dimensional coupled diffusions, deriving the dynamics of a stochastic ratio \(Y = S_1 / S_2\) for correlated geometric Brownian motions driven by planar Wiener noise.

Lab 1 · Worked example: log-price transform on geometric Brownian motion

Applying Itô's lemma to \(Y = \log S\) for \(dS_t = \mu S_t dt + \sigma S_t dB_t\) yields \(dY_t = (\mu - \sigma^2/2) dt + \sigma dB_t\). On the seed 0 SIMULATED instance, the discrete Itô residual vanishes pathwise across all simulated paths within floating-point tolerance 1e-10.

"""Rung 1 worked example: derivation and verification of the log-price transform on seed 0.

For a geometric Brownian motion dS_t = mu S_t dt + sigma S_t dB_t with S_0 = s0 > 0, applying Itô's lemma to
Y_t = f(S_t) = log S_t yields:
    df = f'(S) dS + (1/2) f''(S) (dS)^2 = (1/S)(mu S dt + sigma S dB) + (1/2)(-1/S^2)(sigma^2 S^2 dt)
       = (mu - sigma^2/2) dt + sigma dB.
On the seed 0 SIMULATED instance, this lab evaluates the drift mu_Y = mu - sigma^2/2 and diffusion sigma_Y = sigma,
simulates the exact base GBM paths, and verifies that the discrete Itô residual vanishes pathwise across all paths.
"""

from __future__ import annotations

import math
import random


def main() -> None:
    # Seed 0 instance parameters (SIMULATED)
    s0 = 0.815
    mu = 0.065
    sigma = 0.107
    horizon = 0.427
    n_steps = 58
    n_paths = 387
    seed = 0

    # Itô coefficients for Y = log S
    drift_y = mu - 0.5 * sigma * sigma
    diff_y = sigma

    dt = horizon / n_steps
    sq_dt = math.sqrt(dt)
    gbm_drift = (mu - 0.5 * sigma * sigma) * dt
    gbm_vol = sigma * sq_dt

    rng = random.Random(seed)
    residuals: list[float] = []

    for _ in range(n_paths):
        s = s0
        y0 = math.log(s)
        ito_sum = 0.0
        for _ in range(n_steps):
            z = rng.gauss(0.0, 1.0)
            db = sq_dt * z
            ito_sum += drift_y * dt + diff_y * db
            s *= math.exp(gbm_drift + gbm_vol * z)
        yn = math.log(s)
        residuals.append((yn - y0) - ito_sum)

    max_abs_residual = max(abs(r) for r in residuals)
    mean_residual = sum(residuals) / n_paths

    print(f"seed 0 parameters: s0 = {s0:.3f}, mu = {mu:.3f}, sigma = {sigma:.3f}, H = {horizon:.3f}")
    print(f"derived coefficients: drift = {drift_y:.6f}, diffusion = {diff_y:.6f}")
    print(f"maximum absolute residual across {n_paths} paths: {max_abs_residual:.2e}")
    print(f"mean residual: {mean_residual:.2e}")
    print("residual vanishes within 1e-10:", max_abs_residual < 1e-10)

Step 1 derives the analytical coefficients: \(\partial_t f = 0\), \(f'(S) = 1/S\), and \(f''(S) = -1/S^2\), yielding drift \(\mu - \sigma^2/2\) and diffusion \(\sigma\). Step 2 simulates exact GBM paths on the discrete grid. Step 3 computes the discrete Itô residual:

\[ R = (Y_N - Y_0) - \sum [\mu_Y \Delta t + \sigma_Y \Delta B] \]

Because the exact log increment matches the discretized Itô sum algebraically, the maximum absolute residual across all paths is on the order of 1e-15, confirming the analytical derivation.

Lab 3 · Rung 3 reference verification: contract-pinned simulation values

Evaluates Transform 1 (exact zero residual on GBM) and Transform 7 (\(Y = X^2\) on Euler OU) on seed 0 under the path-major draw order. Pinned reference numbers for seed 0 are mean -6.042148e-05 and standard error 4.397907e-05.

"""Rung 3 reference numbers: contract-pinned simulation values on seed 0.

Evaluates the Itô derivations engine on seed 0 (SIMULATED) under the frozen path-major draw-order contract.
Transform 1 (log price on GBM) produces an exact pathwise residual of zero to machine precision.
Transform 7 (square of OU process Y = X^2) produces sample residual statistics pinned by the acceptance suite:
mean -6.042148e-05 and standard error 4.397907e-05 across 387 paths and 58 steps.

from __future__ import annotations

import math
import random


def main() -> None:
    # Seed 0 parameters (SIMULATED)
    s0 = 0.815
    x0 = -0.085
    mu = 0.065
    sigma = 0.107
    kappa = 0.948
    theta = -0.169
    horizon = 0.427
    n_steps = 58
    n_paths = 387
    seed = 0

    dt = horizon / n_steps
    sq_dt = math.sqrt(dt)

    # 1. Transform 1: Y = log S
    drift_1 = mu - 0.5 * (sigma**2)
    diff_1 = sigma
    gbm_drift = (mu - 0.5 * (sigma**2)) * dt
    gbm_vol = sigma * sq_dt

    rng1 = random.Random(seed)
    res_1: list[float] = []
    for _ in range(n_paths):
        s = s0
        y0 = math.log(s)
        ito_sum = 0.0
        for _ in range(n_steps):
            z = rng1.gauss(0.0, 1.0)
            db = sq_dt * z
            ito_sum += drift_1 * dt + diff_1 * db
            s *= math.exp(gbm_drift + gbm_vol * z)
        yn = math.log(s)
        res_1.append((yn - y0) - ito_sum)

    max_abs_1 = max(abs(r) for r in res_1)

    # 2. Transform 7: Y = X^2 on OU base
    rng7 = random.Random(seed)
    res_7: list[float] = []
    for _ in range(n_paths):
        x = x0
        y0 = x * x
        ito_sum = 0.0
        for _ in range(n_steps):
            z = rng7.gauss(0.0, 1.0)
            db = sq_dt * z
            drift_7 = 2.0 * kappa * x * (theta - x) + (sigma**2)
            diff_7 = 2.0 * sigma * x
            ito_sum += drift_7 * dt + diff_7 * db
            x += kappa * (theta - x) * dt + sigma * db
        yn = x * x
        res_7.append((yn - y0) - ito_sum)

    mean_7 = sum(res_7) / n_paths
    var_7 = sum((r - mean_7) ** 2 for r in res_7) / (n_paths - 1)
    se_7 = math.sqrt(var_7 / n_paths)

    print(f"seed 0 transform 1 maximum absolute residual: {max_abs_1:.2e}")
    print(f"seed 0 transform 7 residual mean: {mean_7:.6e}")
    print(f"seed 0 transform 7 residual se: {se_7:.6e}")
    print("pinned agreement within 1e-11:", abs(mean_7 - (-6.0421482183347994e-05)) < 1e-11)

Rung 3 · Specification

Context
In financial derivatives modeling and risk management, analysts frequently apply smooth non-linear transformations to base stochastic state variables such as equity prices and short interest rates. Every such transformation modifies both the drift and the diffusion coefficients of the process. You must mathematically derive the Itô dynamics for ten canonical transformations and construct a software verification engine that numerically computes and checks the discrete Itô residuals against simulated paths.
Inputs
A deterministic instance dictionary generated by make_instance(seed) carrying base parameters s0, x0, mu, sigma, kappa, theta, r, p, a, b, c, a0, a1, H, tbar, n_steps, n_paths, and seed. All instance data is labeled SIMULATED.
Base processes and ten transformations

Base processes:

  • Geometric Brownian Motion (GBM): \(dS_t = \mu S_t dt + \sigma S_t dB_t\), \(S_0 = s0 > 0\).
  • Ornstein–Uhlenbeck (OU): \(dX_t = \kappa(\theta - X_t) dt + \sigma dB_t\), \(X_0 = x0 \in \R\).

The ten transforms \(Y_t = f(t, \cdot)\):

  1. \(Y = \log S\) (base GBM; domain \(S > 0\)).
  2. \(Y = S^p\) (base GBM; \(p \in \{0.5, 2.0, 3.0\}\); domain \(S > 0\)).
  3. \(Y = 1 / S\) (base GBM; domain \(S > 0\)).
  4. \(Y = e^{-rt} S\) (base GBM; domain \(S > 0\)).
  5. \(Y = S / (a + S)\) (base GBM; \(a > 0\); domain \(S > 0\)).
  6. \(Y = c + bX\) (base OU; \(b \neq 0\)).
  7. \(Y = X^2\) (base OU).
  8. \(Y = \exp(X)\) (base OU).
  9. \(Y = P(t, X_t) = \exp(-A(\bar t - t) - B(\bar t - t) X_t)\) (base OU; maturity \(\bar t > H\)), where \(B(\tau) = (1 - e^{-\kappa \tau})/\kappa\) and \(A(\tau) = a_0(B(\tau) - \tau) - a_1 B(\tau)^2\).
  10. \(Y = e^{\kappa t} X_t\) (base OU; time-dependent integrating factor).
Required outputs
  1. ito_checks.py containing three functions:
    • value(transform: str, t: float, x: float, instance: dict) -> float
    • coefficients(transform: str, t: float, x: float, instance: dict) -> tuple[float, float]
    • residual(transform: str, instance: dict, n_steps: int) -> tuple[float, float]
  2. workbook.html or workbook.md: a comprehensive derivations workbook presenting the full mathematical derivation for each of the ten transformations, explicitly identifying the drift contribution from \(\tfrac{1}{2} \sigma(X)^2 f''(X)\), the diffusion term \(\sigma(X) f'(X)\), and time partial \(\partial_t f\).
  3. A printed numerical residual report for seed 0 across all ten transformations, documenting sample mean, standard error, tolerance band, and discretization bias commentary.
Constraints
Standard library only (math, random, fractions). No third-party numerical packages (NumPy, SciPy). All random increments must be drawn path-major using random.Random(instance["seed"]).gauss(0.0, 1.0). Invalid transform names, non-positive states \(x \le 0\) for transforms 1–5, \(n_{\text{steps}} < 1\), and \(n_{\text{paths}} < 2\) must raise ValueError.
Grading mode
This project is evaluated under dual-mode assessment: graded by both an automated test runner (autograder) verifying algebraic invariants, boundary cases, and contract-pinned numerical residuals, and an expert rubric scoring the clarity, mathematical rigor, and completeness of the derivations workbook.

Transform 1 Derivation: Logarithm of GBM

Let \(S_t\) satisfy the geometric Brownian motion SDE \(dS_t = \mu S_t dt + \sigma S_t dB_t\) with \(S_0 = s0 > 0\). Define \(Y_t = f(S_t) = \log S_t\) on domain \(S_t \in (0, \infty)\). The function \(f \in C^2((0, \infty))\) with partial derivatives \(\partial_t f = 0\), \(f'(s) = 1/s\), and \(f''(s) = -1/s^2\). By Itô's lemma, the differential of \(Y_t\) is:

\[ dY_t = \left(\partial_t f + \mu S_t f'(S_t) + \tfrac{1}{2} \sigma^2 S_t^2 f''(S_t)\right) dt + \sigma S_t f'(S_t) dB_t \]

Substituting the derivatives yields:

\[ dY_t = \left(0 + \mu S_t \frac{1}{S_t} + \tfrac{1}{2} \sigma^2 S_t^2 \left(-\frac{1}{S_t^2}\right)\right) dt + \sigma S_t \frac{1}{S_t} dB_t = \left(\mu - \frac{1}{2}\sigma^2\right) dt + \sigma dB_t. \]

Thus \(\mu_Y = \mu - \tfrac{1}{2}\sigma^2\) and \(\sigma_Y = \sigma\). On seed 0 (s0 = 0.815, mu = 0.065, sigma = 0.107, H = 0.427, 58 steps, 387 paths), the discrete Itô residual \(R = (Y_H - Y_0) - \sum [\mu_Y \Delta t + \sigma_Y \Delta B]\) has maximum absolute value \(1.35 \times 10^{-15}\) and mean \(1.76 \times 10^{-18}\) with standard error \(2.59 \times 10^{-17}\). This vanishes to machine precision because the exact log increment \(\log(S_{k+1}/S_k) = (\mu - \sigma^2/2)\Delta t + \sigma \Delta B_k\) is identically equal to the discrete Itô sum pathwise.

Transform 7 Derivation: Square of OU Process

Let \(X_t\) satisfy the Ornstein–Uhlenbeck SDE \(dX_t = \kappa(\theta - X_t) dt + \sigma dB_t\) with \(X_0 = x0 \in \R\). Define \(Y_t = f(X_t) = X_t^2\) for \(X_t \in \R\). The function \(f \in C^2(\R)\) with derivatives \(\partial_t f = 0\), \(f'(x) = 2x\), and \(f''(x) = 2\). By Itô's lemma:

\[ d(X_t^2) = \left(0 + \kappa(\theta - X_t)(2 X_t) + \tfrac{1}{2} \sigma^2(2)\right) dt + \sigma (2 X_t) dB_t = \left(2\kappa X_t(\theta - X_t) + \sigma^2\right) dt + 2\sigma X_t dB_t. \]

Thus \(\mu_Y(t, x) = 2\kappa x(\theta - x) + \sigma^2\) and \(\sigma_Y(t, x) = 2\sigma x\). On seed 0 with 58 steps and 387 paths, the simulated residual mean is \(-6.042 \times 10^{-5}\) with standard error \(4.398 \times 10^{-5}\). Because \(X_{k+1}^2 - X_k^2 = 2 X_k \Delta X_k + (\Delta X_k)^2\), and \((\Delta X_k)^2\) has mean \(\sigma^2 \Delta t + O(\Delta t^2)\), a discrete bias of order \(O(\Delta t)\) remains. The residual lies well within the tolerance band \(5\,\se + 0.05 = 0.0502\).

  • Meets C2 level 4: displays intermediate derivative substitutions and simplifies to final coefficients with stated domains.
  • Meets C3 level 4: quotes exact seed 0 numerical values, standard errors, path counts, and grid parameters.
  • Meets C4 level 4: explains why Transform 1 is an exact pathwise algebraic cancellation while Transform 7 exhibits discrete \(O(\Delta t)\) bias.
  • Meets C5 level 4: uses \(H\) for horizon, standard notation, and links concepts cleanly.

Transform 1 and 7 Work

For log price, we take \(d\log S = dS / S\), but by Itô's rule we subtract \(\sigma^2/2\), so the drift is \(\mu - \sigma^2/2\) and diffusion is \(\sigma\). Simulating this gives a residual of basically zero.

For \(X^2\), the derivative is \(2X\), so \(d(X^2) = 2X dX + \sigma^2 dt = (2\kappa X(\theta - X) + \sigma^2)dt + 2\sigma X dB\). The residual on the computer was around -0.00006, which shows the theorem is true.
