The Itô Integral for Simple Integrands

  • Uses: Brownian motion, filtration, martingale, random variable, expectation, variance, independence
  • Introduces: Itô integral
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study
  • Dlore
  • Xrefuted

Asset prices fluctuate continuously in response to information arrivals, but Brownian paths have infinite total variation on every interval. Standard Riemann–Stieltjes integration fails pathwise. Defining integration with respect to Brownian motion requires non-anticipating Riemann sums evaluated at left endpoints, yielding the Itô integral. This construction preserves the martingale property, ensuring that gains from trade in efficient markets have zero expected drift.

1Adapted Step Processes and Non-Anticipating Partitions

Let \((\Omega, \mathcal{F}, (\mathcal{F}_t)_{t \ge 0}, \Prob)\) be a filtered probability space satisfying the usual conditions, carrying a standard one-dimensional Brownian motion \((B_t)_{t \ge 0}\) adapted to \((\mathcal{F}_t)\). Fix a deterministic time horizon \(H > 0\). We consider partitions of \([0, H]\):

\[ \Pi: 0 = t_0 < t_1 < t_2 < \dots < t_n = H, \quad \Delta t_k = t_{k+1} - t_k, \quad \Delta B_k = B_{t_{k+1}} - B_{t_k}. \]
Definition 1.1 (Simple Adapted Process)

A stochastic process \(H_t(\omega)\) on \([0, H] \times \Omega\) is a simple adapted process (or step process) with respect to partition \(\Pi\) if there exist square-integrable random variables \(H_k \in L^2(\Omega, \mathcal{F}_{t_k}, \Prob)\) such that:

\[ H_t(\omega) = \sum_{k=0}^{n-1} H_k(\omega) \indic_{(t_k, t_{k+1}]}(t). \]

Each coefficient \(H_k\) is \(\mathcal{F}_{t_k}\)-measurable, depending only on history up to the start of the interval \((t_k, t_{k+1}]\). The space of such simple processes is denoted \(\mathcal{H}_0^2\).

Remark 1.2 (Left Endpoint Evaluation)

The defining restriction is that \(H_t\) is constant on \((t_k, t_{k+1}]\) and equal to its value at the left endpoint \(t_k\). This guarantees that \(H_k\) is independent of the forward Brownian increment \(\Delta B_k = B_{t_{k+1}} - B_{t_k}\). If an intermediate point \(\tau_k = (1-\alpha)t_k + \alpha t_{k+1}\) with \(\alpha > 0\) were selected, the integrand would anticipate future moves, destroying the martingale property.

2Definition of the Itô Integral for Simple Processes

Definition 1.3 (Itô Stochastic Integral)

For a simple adapted process \(H \in \mathcal{H}_0^2\) on partition \(\Pi\), the Itô integral over \([0, H]\) with respect to Brownian motion \(B\) is defined as the discrete sum:

\[ I(H) = \int_0^H H_s \, dB_s \coloneqq \sum_{k=0}^{n-1} H_k \Delta B_k = \sum_{k=0}^{n-1} H_k (B_{t_{k+1}} - B_{t_k}). \]

For any \(t \in [0, H]\), the indefinite integral is defined by truncating the partition at \(t\):

\[ I_t(H) = \int_0^t H_s \, dB_s \coloneqq \int_0^H H_s \indic_{[0, t]}(s) \, dB_s. \]
Theorem 1.4 (Linearity of the Itô Integral)

Assumptions: (A1) \(H, G \in \mathcal{H}_0^2\) are simple adapted processes on \([0, H]\); (A2) \(\alpha, \beta \in \R\) are constants.

Statement: The linear combination \(\alpha H + \beta G\) belongs to \(\mathcal{H}_0^2\) and:

\[ \int_0^H (\alpha H_s + \beta G_s) \, dB_s = \alpha \int_0^H H_s \, dB_s + \beta \int_0^H G_s \, dB_s. \]
Proof

Refine the partitions underlying \(H\) and \(G\) to a common partition \(\Pi = \{t_0, \dots, t_n\}\). On each subinterval \((t_k, t_{k+1}]\), the processes have values \(H_k\) and \(G_k\). The linear combination has value \(\alpha H_k + \beta G_k\). By linearity of finite summation:

\[ \sum_{k=0}^{n-1} (\alpha H_k + \beta G_k)\Delta B_k = \alpha \sum_{k=0}^{n-1} H_k \Delta B_k + \beta \sum_{k=0}^{n-1} G_k \Delta B_k. \]

This equals \(\alpha I(H) + \beta I(G)\), establishing linearity.

3Martingale Property and Zero Expectation

Theorem 1.5 (Zero Expectation and Martingale Property)

Assumptions: (A1) \((B_t)_{t \ge 0}\) is standard Brownian motion with filtration \((\mathcal{F}_t)_{t \ge 0}\); (A2) \(H \in \mathcal{H}_0^2\) is a simple adapted process with \(\E[H_k^2] < \infty\) for all \(k\).

Statement: The stochastic integral \(I(H) = \int_0^H H_s \, dB_s\) has zero expectation:

\[ \E\left[\int_0^H H_s \, dB_s\right] = 0. \]

Moreover, the running integral process \(M_t = \int_0^t H_s \, dB_s\) is a continuous-time square-integrable martingale with respect to \((\mathcal{F}_t)\).

Proof

We compute the expectation of each summand using the tower property of conditional expectation. Since \(H_k\) is \(\mathcal{F}_{t_k}\)-measurable and \(\Delta B_k = B_{t_{k+1}} - B_{t_k}\) is independent of \(\mathcal{F}_{t_k}\) with \(\E[\Delta B_k] = 0\):

\[ \E[H_k \Delta B_k] = \E\left[\E[H_k \Delta B_k \mid \mathcal{F}_{t_k}]\right] = \E\left[H_k \E[\Delta B_k \mid \mathcal{F}_{t_k}]\right] = \E[H_k \cdot 0] = 0. \]

Summing over \(k=0, \dots, n-1\) gives \(\E[I(H)] = \sum_{k=0}^{n-1} 0 = 0\).

To verify the martingale property, choose \(s < t\). Without loss of generality, assume \(s = t_j\) and \(t = t_m\) for partition points \(j < m\). The increment of the integral is:

\[ M_t - M_s = \sum_{k=j}^{m-1} H_k \Delta B_k. \]

Taking conditional expectation with respect to \(\mathcal{F}_s\):

\[ \E[M_t - M_s \mid \mathcal{F}_s] = \sum_{k=j}^{m-1} \E\left[\E[H_k \Delta B_k \mid \mathcal{F}_{t_k}] \;\middle|\; \mathcal{F}_s\right] = \sum_{k=j}^{m-1} \E[0 \mid \mathcal{F}_s] = 0. \]

Hence \(\E[M_t \mid \mathcal{F}_s] = M_s\), proving that \(M_t\) is a martingale.

Example 1.6 (Constant and Deterministic Integrands)

If \(H_t = c\) is a deterministic constant, then \(\int_0^H c \, dB_s = c (B_H - B_0) = c B_H\), which is distributed as \(\Normal(0, c^2 H)\). If \(H_t\) is a deterministic step function taking value \(c_k\) on \((t_k, t_{k+1}]\), the integral is a sum of independent Gaussians: \(\sum_k c_k \Delta B_k \sim \Normal(0, \sum_k c_k^2 \Delta t_k)\). When \(H_k\) is stochastic, the integral is generally non-Gaussian, but its expectation remains identically zero.

Lab 1 · Variance of the Itô integral for a simple step integrand

For a deterministic step integrand \(H_t\) with values \([2, -1, 3]\) on partition intervals of lengths \([1/4, 1/4, 1/2]\), the exact variance in rational arithmetic is \(\sum_k H_k^2 \Delta t_k = 4(1/4) + 1(1/4) + 9(1/2) = 23/4 = 5.75\). A Monte Carlo sample of 5,000 paths (SIMULATED) produces sample mean near 0 and sample variance near 5.75 within 5 standard errors.

"""Lab 1 · Variance of the Itô integral for a simple step integrand.

A step integrand H_s takes constant values on intervals [t_k, t_{k+1}]. The Itô integral is defined as the sum
sum_k H_{t_k} Delta B_k. By the independence and stationarity of Brownian increments, its expectation is zero and its
variance equals sum_k H_{t_k}^2 Delta t_k exactly. This lab computes the exact rational variance with
fractions.Fraction, simulates 5,000 independent realization paths from seed 42 (SIMULATED), and checks that the sample
mean and variance agree with the theoretical values within their standard error bands.
"""

from __future__ import annotations

import math
import random
from fractions import Fraction


def main() -> None:
    # Partition of [0, 1] with 3 intervals
    t = [Fraction(0), Fraction(1, 4), Fraction(1, 2), Fraction(1)]
    dt = [t[k + 1] - t[k] for k in range(3)]
    h_vals = [Fraction(2), Fraction(-1), Fraction(3)]

    # Exact variance in Fraction
    exact_var_frac = sum(h_vals[k] ** 2 * dt[k] for k in range(3))
    exact_var_float = float(exact_var_frac)

    # Seeded Monte Carlo simulation (SIMULATED)
    seed = 42
    rng = random.Random(seed)
    n_paths = 5000
    mc_values: list[float] = []

    dt_floats = [float(d) for d in dt]
    sq_dts = [math.sqrt(d) for d in dt_floats]
    h_floats = [float(h) for h in h_vals]

    for _ in range(n_paths):
        val = sum(h_floats[k] * rng.gauss(0.0, sq_dts[k]) for k in range(3))
        mc_values.append(val)

    sample_mean = sum(mc_values) / n_paths
    sample_var = sum((x - sample_mean) ** 2 for x in mc_values) / (n_paths - 1)
    se_mean = math.sqrt(sample_var / n_paths)
    se_var = math.sqrt(2.0 * (sample_var**2) / (n_paths - 1))

    print(f"exact variance (Fraction): {exact_var_frac} = {exact_var_float:.6f}")
    print(f"sample mean: {sample_mean:.6f} (se {se_mean:.6f})")
    print(f"sample variance: {sample_var:.6f} (se {se_var:.6f})")
    print("mean inside 5*se band:", abs(sample_mean) <= 5.0 * se_mean)
    print("variance inside 5*se band:", abs(sample_var - exact_var_float) <= 5.0 * se_var)


main()

sample mean: -0.006177 (se 0.033665)
sample variance: 5.666632 (se 0.113344)
mean inside 5*se band: True
variance inside 5*se band: True

The exact variance of 23/4 is derived from the orthogonality of Brownian increments. The simulated sample variance 5.667 falls comfortably within the five-standard-error sampling band (standard error 0.113), confirming both the zero expectation and the additive variance formula for simple integrands.

4Where the canon breaks

Classical calculus assumes that integrator paths have bounded first variation. For a continuously differentiable function \(g\), the Riemann–Stieltjes integral \(\int_0^H f(t) dg(t)\) is well-defined as the limit of Riemann sums regardless of whether the evaluation point is chosen at the left endpoint, right endpoint, or midpoint. Brownian motion paths violate this premise everywhere: almost every Brownian trajectory has infinite total variation on every subinterval, meaning \(\sup_\Pi \sum_k |B_{t_{k+1}} - B_{t_k}| = \infty\). Consequently, the limit of Riemann sums depends crucially on the evaluation point. If one evaluates at the right endpoint \(t_{k+1}\), the resulting sum does not converge to the Itô integral and fails to have zero expectation. If one evaluates at the midpoint \((t_k + t_{k+1})/2\), one obtains the Stratonovich integral, which satisfies ordinary chain rules but lacks the martingale property essential for arbitrage-free pricing.

5Misconceptions

  1. “The Itô integral can be defined pathwise for each fixed realization \(\omega\) using Riemann–Stieltjes integration.”

    Because Brownian motion paths almost surely have infinite variation on every interval, the Riemann–Stieltjes sums diverge for generic continuous integrands. The Itô integral can only be constructed as an \(L^2(\Omega)\) limit across the ensemble of paths, relying essentially on probability measure and filtration structure.

  2. “The choice of evaluation point within each interval \([t_k, t_{k+1}]\) is arbitrary and produces the same integral in the limit.”

    In stochastic calculus, the choice of evaluation point determines the expectation of the integral. The left endpoint yields the Itô integral with \(\E[I] = 0\); the right endpoint produces an anticipating sum with \(\E[\sum B_{t_{k+1}}\Delta B_k] = H\); the midpoint yields the Stratonovich integral with \(\E[\sum B_{(t_k+t_{k+1})/2}\Delta B_k] = H/2\).

  3. “The Itô integral \(\int_0^H H_s \, dB_s\) is always normally distributed.”

    The integral is Gaussian if and only if the integrand \(H_s\) is a deterministic function of time. When \(H_s\) is a stochastic process (such as \(H_s = B_s\)), the resulting integral is non-Gaussian (for example, \(\int_0^H B_s \, dB_s = \tfrac{1}{2}(B_H^2 - H)\), which follows a shifted chi-squared distribution).

6Problem set

Mechanics

M1 · Simple step integral variance

Let partition \(\Pi = \{0, 1, 3, 4\}\) divide \([0, 4]\), with step integrand values \(H_0 = 1\), \(H_1 = -2\), and \(H_2 = 3\). Compute the exact expectation and variance of \(I = \int_0^4 H_s \, dB_s\).

Solution

The interval lengths are \(\Delta t_0 = 1 - 0 = 1\), \(\Delta t_1 = 3 - 1 = 2\), and \(\Delta t_2 = 4 - 3 = 1\). By Theorem 1.5, \(\E[I] = 0\). The variance is given by the sum of squares formula \(\sum_k H_k^2 \Delta t_k\):

\[ \Var(I) = (1)^2(1) + (-2)^2(2) + (3)^2(1) = 1 + 8 + 9 = 18. \]
M2 · Stochastic step integrand expectation

Let \(H_t = B_1\) for \(t \in (1, 2]\) and \(H_t = 0\) elsewhere on \([0, 2]\). Verify that \(H\) is a simple adapted process on \(\{0, 1, 2\}\), and compute \(\E[\int_0^2 H_s \, dB_s]\) and \(\Var(\int_0^2 H_s \, dB_s)\).

Solution

The coefficient on \((1, 2]\) is \(H_1 = B_1\), which is \(\mathcal{F}_1\)-measurable and in \(L^2\) since \(\E[B_1^2] = 1 < \infty\). Thus \(H \in \mathcal{H}_0^2\). The integral is \(I = B_1(B_2 - B_1)\). Its expectation is \(\E[I] = \E[B_1]\E[B_2 - B_1] = 0 \cdot 0 = 0\). For the variance, by independence of \(B_1\) and \(B_2 - B_1\): \(\Var(I) = \E[B_1^2(B_2 - B_1)^2] = \E[B_1^2]\E[(B_2 - B_1)^2] = 1 \cdot (2 - 1) = 1\).

M3 · Linear combination of simple integrals

Let \(H_s = 2\) on \((0, 1]\) and \(G_s = -1\) on \((0, 1]\). Compute the Itô integral of \(3H + 2G\) directly and verify linearity.

Solution

Direct evaluation: \(3H_s + 2G_s = 3(2) + 2(-1) = 4\) on \((0, 1]\). The integral is \(4(B_1 - B_0) = 4 B_1\). By linearity: \(3 \int_0^1 H_s dB_s + 2 \int_0^1 G_s dB_s = 3(2 B_1) + 2(-1 B_1) = 6 B_1 - 2 B_1 = 4 B_1\). Both expressions agree identically.

Proof

P1 · Uncorrelated increments of Itô integrals

Let \(H \in \mathcal{H}_0^2\) on partition \(\{t_0, \dots, t_n\}\). Prove that for \(j < k\), the summands \(Y_j = H_j \Delta B_j\) and \(Y_k = H_k \Delta B_k\) are uncorrelated, i.e., \(\E[Y_j Y_k] = 0\).

Solution

Since \(j < k\), we have \(t_{j+1} \le t_k\). Both \(H_j\), \(\Delta B_j\), and \(H_k\) are \(\mathcal{F}_{t_k}\)-measurable. Using the tower property:

\[ \E[Y_j Y_k] = \E\left[\E[H_j \Delta B_j H_k \Delta B_k \mid \mathcal{F}_{t_k}]\right] = \E\left[H_j \Delta B_j H_k \E[\Delta B_k \mid \mathcal{F}_{t_k}]\right]. \]

Since \(\Delta B_k\) is independent of \(\mathcal{F}_{t_k}\), \(\E[\Delta B_k \mid \mathcal{F}_{t_k}] = \E[\Delta B_k] = 0\). Thus the conditional expectation is zero almost surely, proving \(\E[Y_j Y_k] = 0\).

P2 · Square-integrability of the simple Itô integral

Prove that if \(H \in \mathcal{H}_0^2\), then \(\int_0^H H_s \, dB_s \in L^2(\Omega, \mathcal{F}_H, \Prob)\).

Solution

Expanding the squared sum: \((I(H))^2 = (\sum_{k=0}^{n-1} H_k \Delta B_k)^2 = \sum_k H_k^2 (\Delta B_k)^2 + 2 \sum_{j < k} H_j \Delta B_j H_k \Delta B_k\). By Problem P1, the cross terms have expectation zero. For the diagonal terms, conditioning on \(\mathcal{F}_{t_k}\) gives \(\E[H_k^2 (\Delta B_k)^2] = \E[H_k^2 \E[(\Delta B_k)^2 \mid \mathcal{F}_{t_k}]] = \E[H_k^2] \Delta t_k\). Therefore \(\E[(I(H))^2] = \sum_k \E[H_k^2] \Delta t_k < \infty\) because each \(H_k \in L^2(\Omega)\), confirming square-integrability.

P3 · Independence of partition refinement

Prove that inserting an additional partition point \(t^* \in (t_k, t_{k+1})\) leaves the value of the Itô integral \(I(H)\) unchanged for a simple adapted process.

Solution

On the interval \((t_k, t_{k+1}]\), the process takes the constant value \(H_k\). When the interval is split into \((t_k, t^*]\) and \((t^*, t_{k+1}]\), the integrand takes value \(H_k\) on both subintervals. The corresponding contribution to the Riemann sum is \(H_k(B_{t^*} - B_{t_k}) + H_k(B_{t_{k+1}} - B_{t^*}) = H_k(B_{t^*} - B_{t_k} + B_{t_{k+1}} - B_{t^*}) = H_k(B_{t_{k+1}} - B_{t_k})\). The sum is unchanged, proving that the integral is invariant under common refinements.

Empirical

E1 · Monte Carlo variance check

A step integrand has value 1 on \([0, 0.5]\) and 2 on \((0.5, 1.0]\). What is its theoretical variance, and what is the standard error of a Monte Carlo variance estimate across \(M = 10{,}000\) paths?

Solution

Exact variance: \(1^2(0.5) + 2^2(0.5) = 0.5 + 2.0 = 2.5\). For a normal random variable \(I \sim \Normal(0, \sigma^2)\) with \(\sigma^2 = 2.5\), the sample variance has variance \(\Var(s^2) \approx 2 \sigma^4 / (M - 1)\). Here \(\sigma^4 = 6.25\), so \(\Var(s^2) \approx 2(6.25)/9999 \approx 0.00125\). The standard error is \(\sqrt{0.00125} \approx 0.0354\).

E2 · Empirical distribution skewness

For the integrand \(H_t = B_1\) on \((1, 2]\), evaluate whether the distribution of \(I = B_1(B_2 - B_1)\) is symmetric around 0.

Solution

Let \(X = B_1 \sim \Normal(0, 1)\) and \(Y = B_2 - B_1 \sim \Normal(0, 1)\), independent. The product \(I = XY\) has odd moments \(\E[I^k] = \E[X^k]\E[Y^k]\). For \(k = 1, 3\), \(\E[X^k] = 0\) by Gaussian symmetry. The skewness is therefore zero. The distribution is symmetric around zero with heavy tails (product of two independent Gaussians, having a modified Bessel probability density).

E3 · Impact of non-adapted integrand

Suppose an analyst erroneously defines the sum using the right endpoint: \(S_R = \sum_{k=0}^{n-1} B_{t_{k+1}}\Delta B_k\) on \([0, 1]\) with \(n = 100\) equal steps. What is \(\E[S_R]\)?

Solution

Write \(B_{t_{k+1}} = B_{t_k} + \Delta B_k\). Then \(B_{t_{k+1}}\Delta B_k = B_{t_k}\Delta B_k + (\Delta B_k)^2\). Taking expectation: \(\E[B_{t_k}\Delta B_k] = 0\), while \(\E[(\Delta B_k)^2] = \Delta t_k = 1/100 = 0.01\). Summing over \(k=0, \dots, 99\) gives \(\E[S_R] = \sum_{k=0}^{99} 0.01 = 1.0\). The right-endpoint sum has positive bias equal to the horizon \(H = 1.0\).

Research

R1 · Generalization to vector Brownian motion

Formulate the Itô integral for a simple adapted row-vector process \(\mathbf{H}_t \in \R^{1 \times d}\) with respect to a \(d\)-dimensional standard Brownian motion \(\mathbf{B}_t \in \R^d\). Prove zero expectation.

Solution

Let \(\Pi = \{t_0, \dots, t_n\}\). For \(\mathbf{H}_t = \sum_k \mathbf{H}_k \indic_{(t_k, t_{k+1}]}(t)\) with \(\mathbf{H}_k \in L^2(\Omega, \mathcal{F}_{t_k}, \R^{1 \times d})\), define \(\int_0^H \mathbf{H}_s \, d\mathbf{B}_s \coloneqq \sum_{k=0}^{n-1} \mathbf{H}_k \Delta \mathbf{B}_k = \sum_{k=0}^{n-1} \sum_{i=1}^d H_{k, i} \Delta B_{k, i}\). By independence of \(\Delta \mathbf{B}_k\) and \(\mathcal{F}_{t_k}\) and because \(\E[\Delta \mathbf{B}_k] = \mathbf{0}\), \(\E[\mathbf{H}_k \Delta \mathbf{B}_k \mid \mathcal{F}_{t_k}] = \mathbf{H}_k \E[\Delta \mathbf{B}_k \mid \mathcal{F}_{t_k}] = 0\). The expectation vanishes identically.

R2 · Doob maximal inequality on simple integrals

State how Doob's \(L^2\) maximal inequality bounds the running supremum \(\E[\sup_{t \le H} |\int_0^t H_s dB_s|^2]\) for a simple process \(H \in \mathcal{H}_0^2\).

Solution

Since \(M_t = \int_0^t H_s dB_s\) is an \((\mathcal{F}_t)\)-martingale by Theorem 1.5, Doob's \(L^p\) maximal inequality for \(p = 2\) states that \(\E[\sup_{0 \le t \le H} |M_t|^2] \le \left(\frac{2}{2-1}\right)^2 \E[|M_H|^2] = 4 \E[|M_H|^2] = 4 \sum_k \E[H_k^2]\Delta t_k\). The running maximum is bounded by four times the terminal variance.

R3 · Comparison with pathwise Young integrals

Explain why Young integration theory can define \(\int_0^H f(t) dg(t)\) pathwise when \(f \in C^\alpha\) and \(g \in C^\beta\) with \(\alpha + \beta > 1\), and why this fails for Brownian motion against itself.

Solution

Young integration requires the sum of Hölder exponents to strictly exceed 1: \(\alpha + \beta > 1\). Brownian paths almost surely have optimal Hölder regularity \(\beta < 1/2\) (Kolmogorov continuity theorem). If both integrand and integrator are Brownian paths (\(\alpha, \beta < 1/2\)), their sum is \(\alpha + \beta < 1\), falling strictly outside the Young regime. This failure necessitates stochastic calculus (Itô or rough paths theory).

8Retrieval quiz

  1. What defining property characterizes a simple adapted process \(H \in \mathcal{H}_0^2\)?

    Options

    By Definition 1.1, a simple adapted process is constant on each interval \((t_k, t_{k+1}]\) with value determined at the left endpoint \(t_k\).

  2. What is the expectation \(\E[\int_0^H H_s dB_s]\) for any simple adapted process \(H \in \mathcal{H}_0^2\)?

    By Theorem 1.5, the Itô integral of any square-integrable adapted simple process has expectation exactly 0.

  3. Why does the Itô integral sum evaluate the integrand at the left endpoint \(t_k\) rather than the right endpoint \(t_{k+1}\)?

    Options

    Left-endpoint evaluation guarantees \(H_k \in \mathcal{F}_{t_k}\), making it independent of \(\Delta B_k = B_{t_{k+1}} - B_{t_k}\).

  4. If \(H_t = 1\) on \((0, 1]\) and \(H_t = 2\) on \((1, 2]\), what is the exact variance of \(\int_0^2 H_s dB_s\)?

    \(\Var = 1^2(1) + 2^2(1) = 1 + 4 = 5\).

  5. Which mathematical property fails for Brownian motion, preventing pathwise Riemann–Stieltjes integration?

    Options

    Brownian sample paths have infinite total variation on every interval almost surely.

  6. What type of stochastic process is the running Itô integral \(M_t = \int_0^t H_s dB_s\) for \(H \in \mathcal{H}_0^2\)?

    Options

    By Theorem 1.5, \(M_t\) is a continuous-time square-integrable martingale with respect to the Brownian filtration.

  7. For the right-endpoint sum \(S_R = \sum_{k=0}^{n-1} B_{t_{k+1}}(B_{t_{k+1}} - B_{t_k})\) on \([0, 1]\), what is \(\E[S_R]\)?

    Because \(\E[B_{t_{k+1}}\Delta B_k] = \Delta t_k\), the expectation sums to the interval length \(H = 1\).

  8. Under what condition is the Itô integral \(\int_0^H H_s dB_s\) normally distributed?

    Options

    When \(H_s\) is deterministic, the integral is a linear combination of independent Gaussians, hence Gaussian. For stochastic integrands it is generally non-Gaussian.
