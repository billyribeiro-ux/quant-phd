The Crank–Nicolson Scheme & Von Neumann Stability Analysis

  • Introduces: Crank–Nicolson scheme, Von Neumann stability analysis

In quantitative derivative pricing, speed and accuracy are twin imperatives. Explicit FTCS is first-order in time and conditionally stable; implicit BTCS is unconditionally stable but remains first-order in time, requiring small time steps to limit temporal smearing. The Crank–Nicolson scheme achieves the holy grail: it combines unconditional stability with second-order temporal and spatial accuracy \(O(\Delta t^2 + \Delta x^2)\) by centering the discretization at the temporal midpoint \(\tau_{n+1/2}\). However, this second-order precision harbors a subtle vulnerability: for large mesh ratios, high-frequency spatial modes invert sign with amplification factor approaching \(-1\), leading to persistent, non-decaying numerical oscillations when initial conditions possess non-smooth kinks.

1The \(\theta\)-Family & the Crank–Nicolson Discretization

Consider the linear parabolic operator \(u_\tau = \mathcal{L} u\), where \(\mathcal{L}\) is the spatial differential operator. The general \(\theta\)-weighted discretization in time approximates the time derivative by a forward difference and the spatial operator by a convex combination of time levels \(n\) and \(n+1\):

\[ \frac{u^{n+1} - u^n}{\Delta t} = (1 - \theta) \mathcal{L} u^n + \theta \mathcal{L} u^{n+1}, \quad \theta \in [0, 1]. \]
  • \(\theta = 0\): Explicit Forward-Time Central-Space (FTCS) scheme (Lesson 5).
  • \(\theta = 1\): Fully Implicit Backward-Time Central-Space (BTCS) scheme (Lesson 6).
  • \(\theta = 1/2\): The Crank–Nicolson scheme.
Definition 7.1 (Crank–Nicolson scheme)

The Crank–Nicolson scheme is the \(\theta\)-weighted finite-difference method with \(\theta = 1/2\). For the diffusion equation \(u_\tau = D u_{xx}\), it evaluates the central second difference at the arithmetic midpoint between levels \(n\) and \(n+1\):

\[ \frac{u_j^{n+1} - u_j^n}{\Delta t} = \frac{D}{2}\left( \frac{u_{j+1}^{n+1} - 2u_j^{n+1} + u_{j-1}^{n+1}}{\Delta x^2} + \frac{u_{j+1}^n - 2u_j^n + u_{j-1}^n}{\Delta x^2} \right). \]
Theorem 7.2 (Second-Order Truncation Error of Crank–Nicolson)

Statement: For smooth solutions \(u \in C^{4,3}\), the local truncation error of the Crank–Nicolson scheme is second-order in both time and space: \(O(\Delta t^2 + \Delta x^2)\).

Proof

Expand all terms via Taylor series about the temporal midpoint \((\tau_n + \tau_{n+1})/2 = \tau_{n+1/2}\) and spatial point \(x_j\). The time difference quotient is centered at \(\tau_{n+1/2}\):

\[ \frac{u(x_j, \tau_{n+1}) - u(x_j, \tau_n)}{\Delta t} = \frac{\partial u}{\partial \tau}\bigg|_{j}^{n+1/2} + \frac{\Delta t^2}{24}\frac{\partial^3 u}{\partial \tau^3}\bigg|_{j}^{n+1/2} + O(\Delta t^4). \]

Because the temporal difference is centered, all odd powers of \(\Delta t / 2\) cancel identically, eliminating the \(O(\Delta t)\) error. Similarly, averaging the spatial central differences at \(\tau_n\) and \(\tau_{n+1}\):

\[ \frac{1}{2}\left( \frac{\partial^2 u}{\partial x^2}\bigg|_j^{n+1} + \frac{\partial^2 u}{\partial x^2}\bigg|_j^n \right) = \frac{\partial^2 u}{\partial x^2}\bigg|_j^{n+1/2} + \frac{\Delta t^2}{8}\frac{\partial^4 u}{\partial \tau^2 \partial x^2}\bigg|_j^{n+1/2} + O(\Delta t^4). \]

Each spatial central difference contributes \(O(\Delta x^2)\) spatial error. Subtracting the PDE evaluated at \(\tau_{n+1/2}\) leaves:

\[ T_j^{n+1/2} = O(\Delta t^2) + O(\Delta x^2) = O(\Delta t^2 + \Delta x^2). \]

2Von Neumann Stability Analysis

Definition 7.3 (Von Neumann stability analysis)

Von Neumann stability analysis evaluates the stability of a linear finite-difference scheme by expanding the discrete spatial solution into a Fourier series (or integral):

\[ u_j^n = \sum_k \hat{u}^n(k) e^{i k x_j}, \quad x_j = j \Delta x. \]

The time evolution of each spatial Fourier mode with dimensionless phase angle \(\xi \coloneqq k \Delta x \in [-\pi, \pi]\) is governed by a scalar amplification factor \(G(\xi) \in \mathbb{C}\):

\[ \hat{u}^{n+1}(\xi) = G(\xi) \hat{u}^n(\xi). \]

The scheme is Von Neumann stable in \(L^2\) if and only if:

\[ |G(\xi)| \le 1 + C \Delta t \quad \text{for all } \xi \in [-\pi, \pi]. \]

For autonomous diffusion equations, the strict stability criterion is \(|G(\xi)| \le 1\).

Theorem 7.4 (Amplification Factor of the \(\theta\)-Family)

Statement: For the \(\theta\)-weighted scheme with mesh ratio \(\lambda = \frac{D \Delta t}{\Delta x^2}\), the Von Neumann amplification factor is:

\[ G(\xi) = \frac{1 - 4(1 - \theta)\lambda \sin^2\left(\frac{\xi}{2}\right)}{1 + 4\theta \lambda \sin^2\left(\frac{\xi}{2}\right)}. \]

Consequently:

  1. If \(0 \le \theta < 1/2\), the scheme is conditionally stable if and only if \(\lambda \le \frac{1}{2(1 - 2\theta)}\).
  2. If \(1/2 \le \theta \le 1\), the scheme is unconditionally stable (\(A\)-stable) for all \(\lambda > 0\).
Proof

Substitute \(u_j^n = G^n e^{i j \xi}\) into the \(\theta\)-weighted difference equation:

\[ G^{n+1} e^{i j \xi} - G^n e^{i j \xi} = \lambda \left[ (1 - \theta) G^n + \theta G^{n+1} \right] \left( e^{i(j+1)\xi} - 2e^{ij\xi} + e^{i(j-1)\xi} \right). \]

Divide by \(G^n e^{i j \xi}\) and note that \(e^{i\xi} - 2 + e^{-i\xi} = 2(\cos \xi - 1) = -4\sin^2(\xi / 2)\):

\[ G - 1 = -4\lambda \sin^2\left(\frac{\xi}{2}\right) \left[ (1 - \theta) + \theta G \right]. \]

Let \(z \coloneqq 4\lambda \sin^2(\xi / 2) \ge 0\). Rearranging for \(G\):

\[ G(1 + \theta z) = 1 - (1 - \theta) z \implies G(\xi) = \frac{1 - (1 - \theta) z}{1 + \theta z}. \]

For unconditional stability, we require \(-1 \le G \le 1\) for all \(z \ge 0\). The upper bound \(G \le 1\) holds because \(1 - (1 - \theta) z \le 1 + \theta z \iff z \ge 0\), which is always true. The lower bound requires:

\[ \frac{1 - (1 - \theta) z}{1 + \theta z} \ge -1 \iff 1 - (1 - \theta) z \ge -1 - \theta z \iff (1 - 2\theta) z \le 2. \]

If \(\theta \ge 1/2\), then \(1 - 2\theta \le 0\), so \((1 - 2\theta) z \le 0 \le 2\) holds for all \(z \ge 0\) and all \(\lambda > 0\). This proves unconditional stability for \(\theta \ge 1/2\). For Crank–Nicolson (\(\theta = 1/2\)):

\[ G_{\text{CN}}(\xi) = \frac{1 - 2\lambda \sin^2(\xi / 2)}{1 + 2\lambda \sin^2(\xi / 2)}. \]

Since the numerator and denominator have identical absolute magnitudes when \(2\lambda \sin^2(\xi/2) \to \infty\), \(|G_{\text{CN}}(\xi)| \le 1\) for all \(\xi\) and all \(\lambda > 0\).

3The High-Frequency Paradox: \(A\)-Stability vs. \(L\)-Stability

Although the Crank–Nicolson scheme is unconditionally stable in the sense of Von Neumann (\(|G| \le 1\)), its behavior on high-frequency spatial modes contains a critical practical flaw. Consider the highest spatial frequency on the grid—the Nyquist mode \(\xi = \pi\) where adjacent grid nodes oscillate as \((-1)^j\):

\[ G_{\text{CN}}(\pi) = \frac{1 - 2\lambda \sin^2(\pi / 2)}{1 + 2\lambda \sin^2(\pi / 2)} = \frac{1 - 2\lambda}{1 + 2\lambda}. \]

As the mesh ratio \(\lambda = \frac{D \Delta t}{\Delta x^2}\) becomes large (\(\lambda \gg 1\)):

\[ \lim_{\lambda \to \infty} G_{\text{CN}}(\pi) = \lim_{\lambda \to \infty} \frac{1/\lambda - 2}{1/\lambda + 2} = -1. \]

Compare this with the analytical diffusion operator. In continuous diffusion, high-frequency spatial modes decay almost instantaneously: the exact analytical mode \(e^{i k x}\) evolves as \(\exp(-D k^2 \tau)\), which decays to zero exponentially fast.

The Paradox of Spurious Oscillations

When \(\lambda > 1\), the Crank–Nicolson amplification factor for the Nyquist mode is negative: \(G(\pi) < 0\). At every time step, the mode inverts its sign: \(u_j^{n+1} \approx -u_j^n\). For large \(\lambda\), \(|G(\pi)| \approx 1\), meaning high-frequency noise is neither damped nor eliminated. It persists indefinitely as an undamped, sign-alternating checkerboard oscillation across the spatial grid.

In the language of numerical ODE analysis, the Crank–Nicolson scheme is \(A\)-stable (stable on the entire left half-plane), but it is not \(L\)-stable because \(\lim_{\text{Re}(z) \to -\infty} R(z) = -1 \neq 0\). In contrast, fully implicit Euler (BTCS) is \(L\)-stable: \(\lim_{\lambda \to \infty} G_{\text{BTCS}}(\pi) = 0\).

4Implementation via Tridiagonal Systems

In operator form, the Crank–Nicolson step is:

\[ \left( \mathbf{I} - \frac{\Delta t}{2} \mathcal{L} \right) \mathbf{u}^{n+1} = \left( \mathbf{I} + \frac{\Delta t}{2} \mathcal{L} \right) \mathbf{u}^n. \]

For the 1D diffusion operator \(\mathcal{L} u = D \frac{u_{j+1} - 2u_j + u_{j-1}}{\Delta x^2}\), let \(\mu \coloneqq \frac{D \Delta t}{2\Delta x^2} = \frac{\lambda}{2}\). The left-hand side is a tridiagonal matrix \(\mathbf{A}_{\text{lhs}}\) acting on \(\mathbf{u}^{n+1}\):

\[ a_j = -\mu, \quad b_j = 1 + 2\mu, \quad c_j = -\mu. \]

The right-hand side is a tridiagonal matrix-vector product \(\mathbf{d}^n = \mathbf{A}_{\text{rhs}} \mathbf{u}^n\):

\[ d_j^n = \mu u_{j-1}^n + (1 - 2\mu) u_j^n + \mu u_{j+1}^n. \]

Boundary conditions at \(j = 0\) and \(j = N\) are added to \(d_1^n\) and \(d_{N-1}^n\). The resulting tridiagonal system \(\mathbf{A}_{\text{lhs}} \mathbf{u}^{n+1} = \mathbf{d}^n\) is solved via the Thomas algorithm in strictly \(O(N)\) operations.

Lab 1 · Von Neumann Stability Analysis and Crank–Nicolson Amplification Factor

Validates the theoretical Von Neumann amplification factor G(xi) for the Crank-Nicolson scheme against empirical discrete steps across spatial Fourier frequencies xi in [0, pi], confirming unconditional A-stability and high-frequency sign inversion (SIMULATED).

"""Lab SC4-L07-1 · Von Neumann Stability Analysis and Crank-Nicolson Amplification Factor.

Validates the theoretical Von Neumann amplification factor G(xi) for the Crank-Nicolson scheme
against empirical discrete steps across spatial Fourier frequencies xi in [0, pi] (SIMULATED).
"""

from __future__ import annotations

import math

import numpy as np


def thomas_periodic_or_solve(a: np.ndarray, b: np.ndarray, c: np.ndarray, d: np.ndarray) -> np.ndarray:
    n = len(d)
    cp = np.zeros(n, dtype=np.float64)
    dp = np.zeros(n, dtype=np.float64)
    cp[0] = c[0] / b[0]
    dp[0] = d[0] / b[0]
    for i in range(1, n):
        denom = b[i] - a[i] * cp[i - 1]
        cp[i] = c[i] / denom
        dp[i] = (d[i] - a[i] * dp[i - 1]) / denom
    x = np.zeros(n, dtype=np.float64)
    x[-1] = dp[-1]
    for i in range(n - 2, -1, -1):
        x[i] = dp[i] - cp[i] * x[i + 1]
    return x


def main() -> None:
    n_space = 100
    dx = 1.0 / n_space
    x = np.linspace(0.0, 1.0, n_space + 1)
    lambda_mesh = 2.5  # Large mesh ratio

    # Frequencies m = 1, 5, 20, 50 (Nyquist mode is m = 50, xi = pi)
    modes_m = [1, 5, 20, 50]

    print(f"Von Neumann amplification analysis for Crank-Nicolson (theta = 0.5, lambda = {lambda_mesh:.1f}):")

    for m in modes_m:
        xi = m * math.pi * dx  # phase angle per cell
        g_theory = (1.0 - lambda_mesh * (1.0 - math.cos(xi))) / (1.0 + lambda_mesh * (1.0 - math.cos(xi)))

        # Initial eigenmode u_j = sin(m * pi * x_j)
        u0 = np.sin(m * math.pi * x)

        # Crank-Nicolson step: (I - 0.5 * dt * L) u1 = (I + 0.5 * dt * L) u0
        m_int = n_space - 1
        a_diag = np.full(m_int, -0.5 * lambda_mesh)
        b_diag = np.full(m_int, 1.0 + lambda_mesh)
        c_diag = np.full(m_int, -0.5 * lambda_mesh)

        d = (1.0 - lambda_mesh) * u0[1:-1] + 0.5 * lambda_mesh * u0[:-2] + 0.5 * lambda_mesh * u0[2:]
        u1_int = thomas_periodic_or_solve(a_diag, b_diag, c_diag, d)
        u1 = np.concatenate([[0.0], u1_int, [0.0]])

        # Empirical amplification at the peak
        idx_peak = np.argmax(np.abs(u0[1:-1])) + 1
        g_emp = float(u1[idx_peak] / u0[idx_peak])
        diff = abs(g_emp - g_theory)

        print(f"  Mode m = {m:2d} (xi = {xi:.4f}): G_theory = {g_theory:+.6f}, G_emp = {g_emp:+.6f}, diff = {diff:.2e}")

    # Check high-frequency limit: G(pi) = (1 - 2*lambda) / (1 + 2*lambda)
    g_nyquist = (1.0 - 2.0 * lambda_mesh) / (1.0 + 2.0 * lambda_mesh)
    print(f"Nyquist mode amplification factor G(pi): {g_nyquist:.6f}")
    print(f"Unconditional A-stability verified (|G| <= 1 for all modes): {abs(g_nyquist) <= 1.0}")
    print(f"High-frequency mode inverts sign (G < 0): {g_nyquist < 0.0}")


main()

5Where the canon breaks

The second-order convergence guarantee of Crank–Nicolson breaks down completely when applied to non-smooth financial contracts:

  • Digital / Binary Options: The payoff of a digital call option \(\psi(S) = \indic_{\{S > K\}}\) possesses a jump discontinuity at the strike. The initial derivative \(\psi'(S)\) is a Dirac delta, and the initial Gamma \(\psi''(S)\) is a doublet derivative. This discontinuity excites every Fourier mode on the grid with equal energy \(O(1)\). Since Crank–Nicolson does not damp the Nyquist mode (\(G(\pi) \approx -1\)), the jump generates severe sign-alternating spurious oscillations that fail to decay, producing wildly oscillating, negative option prices and completely invalid Greeks.
  • Convergence Rate Degradation: For vanilla European call options, the payoff \((S - K)^+\) has a continuous price but a discontinuous first derivative (Delta kink) and a Dirac delta second derivative (Gamma). This weak singularity degrades the global Crank–Nicolson convergence rate from theoretical second-order \(O(\Delta t^2)\) down to fractional order \(O(\Delta t^{1/2})\) or \(O(\Delta t)\).
  • Barrier Options: Knockout boundaries introduce sudden Dirichlet clamping \(V(B, \tau) = 0\). When the barrier is close to the initial spot, high-frequency modes bounce repeatedly off the Dirichlet wall without dissipation.

6Misconceptions

  1. “Because Crank–Nicolson is unconditionally stable, the numerical solution cannot exhibit wild oscillations.”

    Von Neumann stability means \(|G| \le 1\), which prevents exponential blow-up toward infinity. It does not prevent bounded, order-unity oscillations. Because \(G(\pi) \to -1\) for large \(\lambda\), high-frequency modes invert signs every step without decaying, creating severe, visible numerical ringing.

  2. “Crank–Nicolson always achieves second-order convergence \(O(\Delta t^2)\) for all derivative contracts.”

    The Taylor series proof of Theorem 7.2 explicitly assumes \(u \in C^{4,3}\). Financial payoffs (vanilla call kinks, digital jumps, barrier steps) are not smooth. For non-smooth initial data, Crank–Nicolson's lack of \(L\)-stability destroys second-order convergence unless smoothing techniques are applied.

  3. “A-stability and L-stability are interchangeable terms for implicit schemes.”

    \(A\)-stability requires only that the stability region contains the entire left half-plane: \(|R(z)| \le 1\) for \(\text{Re}(z) \le 0\). \(L\)-stability adds the crucial asymptotic requirement that stiff, infinitely fast decaying modes vanish completely: \(\lim_{\text{Re}(z) \to -\infty} |R(z)| = 0\). Crank–Nicolson is \(A\)-stable but not \(L\)-stable; fully implicit Euler (BTCS) is \(L\)-stable.

Mechanics

M1 · Crank–Nicolson amplification factor calculation

Compute the Crank–Nicolson amplification factor \(G(\xi)\) for \(\lambda = 3.0\) at phase angles \(\xi = 0, \pi/3, \pi/2, \pi\).

Solution

The Crank–Nicolson amplification factor is \(G(\xi) = \frac{1 - 2\lambda \sin^2(\xi/2)}{1 + 2\lambda \sin^2(\xi/2)}\). For \(\lambda = 3.0\), \(2\lambda = 6.0\):

  • \(\xi = 0\): \(\sin^2(0) = 0 \implies G(0) = \frac{1 - 0}{1 + 0} = +1.0\).
  • \(\xi = \pi/3\): \(\sin(\pi/6) = 1/2 \implies \sin^2(\pi/6) = 1/4\). \(G(\pi/3) = \frac{1 - 6(0.25)}{1 + 6(0.25)} = \frac{1 - 1.5}{1 + 1.5} = \frac{-0.5}{2.5} = -0.20\).
  • \(\xi = \pi/2\): \(\sin(\pi/4) = 1/\sqrt{2} \implies \sin^2(\pi/4) = 1/2\). \(G(\pi/2) = \frac{1 - 6(0.5)}{1 + 6(0.5)} = \frac{1 - 3}{1 + 3} = \frac{-2}{4} = -0.50\).
  • \(\xi = \pi\): \(\sin(\pi/2) = 1 \implies \sin^2(\pi/2) = 1\). \(G(\pi) = \frac{1 - 6(1)}{1 + 6(1)} = \frac{-5}{7} \approx -0.7143\).
M2 · Critical mesh ratio for sign inversion

Determine the threshold value of the mesh ratio \(\lambda = D \Delta t / \Delta x^2\) above which the Nyquist mode \(\xi = \pi\) inverts sign in the Crank–Nicolson scheme.

Solution

The Nyquist mode amplification factor is \(G(\pi) = \frac{1 - 2\lambda}{1 + 2\lambda}\). Sign inversion occurs when \(G(\pi) < 0\):

\[ \frac{1 - 2\lambda}{1 + 2\lambda} < 0 \iff 1 - 2\lambda < 0 \iff \lambda > \frac{1}{2}. \]

Whenever \(\lambda > 0.5\), the Nyquist mode flips sign at each time step. While stable, this oscillatory behavior pollutes non-smooth data.

M3 · Crank–Nicolson matrix coefficients

Write down the tridiagonal matrix coefficients \(a_j, b_j, c_j\) for the left-hand side \(\mathbf{A}_{\text{lhs}}\) of the Crank–Nicolson scheme on \(u_\tau = 0.5 u_{xx}\) with \(\Delta x = 0.1\) and \(\Delta t = 0.05\).

Solution

Here \(D = 0.5\), so \(\lambda = \frac{D \Delta t}{\Delta x^2} = \frac{0.5 \times 0.05}{0.01} = 2.5\). The parameter \(\mu = \lambda / 2 = 1.25\). The left-hand side coefficients are:

\[ a_j = -\mu = -1.25, \quad b_j = 1 + 2\mu = 1 + 2(1.25) = 3.50, \quad c_j = -\mu = -1.25. \]

The diagonal dominance margin is \(3.50 - (1.25 + 1.25) = 1.0 > 0\).

P1 · General theta-scheme stability boundary

Prove that for any \(\theta < 1/2\), the scheme \(u^{n+1} - u^n = \Delta t \mathcal{L}((1-\theta)u^n + \theta u^{n+1})\) is conditionally stable if and only if \(\lambda \le \frac{1}{2(1 - 2\theta)}\).

Solution

From Theorem 7.4, \(G(\xi) = \frac{1 - (1-\theta)z}{1 + \theta z}\) with \(z = 4\lambda \sin^2(\xi/2)\). The stability bound \(|G| \le 1\) requires \(G \ge -1\):

\[ \frac{1 - (1-\theta)z}{1 + \theta z} \ge -1 \iff 1 - (1-\theta)z \ge -1 - \theta z \iff (1 - 2\theta) z \le 2. \]

When \(\theta < 1/2\), \(1 - 2\theta > 0\), so \(z \le \frac{2}{1 - 2\theta}\). The maximum of \(z\) occurs at \(\xi = \pi\) where \(\sin^2(\pi/2) = 1\), giving \(z_{\max} = 4\lambda\). Thus:

\[ 4\lambda \le \frac{2}{1 - 2\theta} \iff \lambda \le \frac{1}{2(1 - 2\theta)}. \]

For \(\theta = 0\) (FTCS), this recovers \(\lambda \le 1/2\). As \(\theta \to 1/2^-\), the stability threshold tends to \(+\infty\), proving unconditional stability at \(\theta = 1/2\).

P2 · Padé approximation of the exponential

Show that the Crank–Nicolson amplification factor \(G(z) = \frac{1 - z/2}{1 + z/2}\) is the \([1/1]\) diagonal Padé rational approximation of \(\exp(-z)\), and derive its order of accuracy.

Solution

The exact analytical evolution operator for the system \(\frac{du}{d\tau} = \mathbf{L} u\) over a time step \(\Delta t\) is \(\exp(\Delta t \mathbf{L})\). The \([1/1]\) Padé approximation of \(e^{-z}\) is the rational function \(R_{1,1}(z) = \frac{1 - z/2}{1 + z/2}\). Expanding via Taylor series for small \(z\):

\[ \frac{1 - z/2}{1 + z/2} = (1 - z/2)\left( 1 - \frac{z}{2} + \frac{z^2}{4} - \frac{z^3}{8} + \dots \right) = 1 - z + \frac{z^2}{2} - \frac{z^3}{4} + O(z^4). \]

The exact exponential series is \(e^{-z} = 1 - z + \frac{z^2}{2} - \frac{z^3}{6} + O(z^4)\). The Padé approximation matches the exact exponential through terms of order \(z^2\), with difference \(-\frac{z^3}{4} - (-\frac{z^3}{6}) = -\frac{z^3}{12} = O(z^3)\). Over \(M = T / \Delta t\) time steps, the global error compounds as \(M \cdot O(\Delta t^3) = O(\Delta t^2)\), proving second-order temporal convergence.

P3 · Conservation of energy under Crank–Nicolson

For the wave equation / advection equation \(u_\tau + c u_x = 0\) with periodic boundary conditions, prove that Crank–Nicolson preserves the discrete \(L^2\) energy exactly: \(|G(\xi)| = 1\) for all \(\xi\).

Solution

For pure advection, central differencing gives the skew-symmetric spatial operator \(\frac{u_{j+1} - u_{j-1}}{2\Delta x}\), whose Fourier symbol is \(i \frac{c}{\Delta x} \sin \xi\). The Crank–Nicolson update is \((1 + i \alpha) \hat{u}^{n+1} = (1 - i \alpha) \hat{u}^n\), where \(\alpha = \frac{c \Delta t}{2\Delta x}\sin \xi \in \R\). The amplification factor is:

\[ G(\xi) = \frac{1 - i \alpha}{1 + i \alpha}. \]

The complex modulus is:

\[ |G(\xi)| = \left| \frac{1 - i \alpha}{1 + i \alpha} \right| = \frac{\sqrt{1 + \alpha^2}}{\sqrt{1 + \alpha^2}} = 1 \quad \text{for all } \xi. \]

The scheme is strictly unitary (isometry on \(L^2\)), perfectly conserving discrete energy without numerical damping.

Empirical

E1 · Empirical convergence order certification

An option pricing model is tested on four successively refined grids with \(\Delta t = [0.1, 0.05, 0.025, 0.0125]\) and fixed ratio \(\Delta t / \Delta x = \text{const}\). The errors against an analytical benchmark are \([0.0402, 0.0101, 0.00253, 0.000633]\). Calculate the empirical convergence order \(\alpha\).

Solution

Compute the error ratios between successive refinements (each halving \(\Delta t\)):

  • Ratio 1: \(0.0402 / 0.0101 \approx 3.9802 \implies \alpha_1 = \log_2(3.9802) \approx 1.993\).
  • Ratio 2: \(0.0101 / 0.00253 \approx 3.9921 \implies \alpha_2 = \log_2(3.9921) \approx 1.997\).
  • Ratio 3: \(0.00253 / 0.000633 \approx 3.9968 \implies \alpha_3 = \log_2(3.9968) \approx 1.999\).

The empirical convergence order is \(\alpha \approx 2.00\), confirming second-order convergence \(O(\Delta t^2 + \Delta x^2)\).

E2 · Oscillation decay rate comparison

Compare the damping factor of the Nyquist mode after 10 time steps with \(\lambda = 4.0\) under fully implicit BTCS versus Crank–Nicolson.

Solution

For \(\lambda = 4.0\):

  • BTCS: \(G_{\text{BTCS}}(\pi) = \frac{1}{1 + 4(4)} = \frac{1}{17} \approx 0.0588\). After 10 steps: \((1/17)^{10} \approx 4.97 \times 10^{-13}\). The Nyquist mode is completely erased.
  • Crank–Nicolson: \(G_{\text{CN}}(\pi) = \frac{1 - 2(4)}{1 + 2(4)} = \frac{-7}{9} \approx -0.7778\). After 10 steps: \((-7/9)^{10} \approx 0.0818\). Over \(8\%\) of the initial high-frequency error remains alive.

BTCS dampens high-frequency noise \(10^{11}\) times more aggressively than Crank–Nicolson.

E3 · Sign-alternating Gamma diagnosis

A risk manager computes discrete option Gamma \(\Gamma_j = (V_{j+1} - 2V_j + V_{j-1})/\Delta S^2\) from a Crank–Nicolson solver and observes that \(\Gamma\) alternates signs \(\{+15.2, -14.8, +14.5, -14.1\}\) around the strike. Explain why this happens and what physical risk this creates.

Solution

The payoff kink at the strike excites the Nyquist mode with \(G(\pi) \approx -1\). Because Gamma involves dividing by \(\Delta S^2\), the high-frequency oscillation is magnified by \(1/\Delta S^2\), creating massive sign-alternating spikes. In trading practice, this causes algorithmic hedging to oscillate violently between massive long and short positions on adjacent grid nodes, creating non-physical transaction costs and risk reports.

Research

R1 · Dahlquist's second barrier theorem

State Dahlquist's Second Barrier Theorem regarding the order of accuracy of linear multistep and multistage methods and explain its implications for \(A\)-stable PDE schemes.

Solution

Dahlquist's Second Barrier Theorem: No linear multistep method that is \(A\)-stable can have an order of accuracy greater than 2. Furthermore, the trapezoidal rule (Crank–Nicolson) is the unique \(A\)-stable linear method with the smallest asymptotic error constant \((C = 1/12)\). Implication for finance: within the class of linear unconditional methods, second-order accuracy is the absolute theoretical maximum. Achieving higher-order accuracy (e.g., 4th order) unconditionally requires implicit Runge–Kutta (such as Gauss–Legendre or Radau IIA) with multiple internal coupled stages.

R2 · Lawson–Swayne damping schemes

Describe the Lawson–Swayne modification to Crank–Nicolson, which uses two sub-steps with complex or fractional weights to recover \(L\)-stability while retaining second-order accuracy.

Solution

Lawson and Swayne (1989) replace the single Crank–Nicolson step with a two-stage diagonally implicit Runge–Kutta (DIRK) scheme using parameter \(\gamma = 1 - 1/\sqrt{2} \approx 0.2929\):

\[ \begin{aligned} (I - \gamma \Delta t \mathcal{L}) u^{(1)} &= u^n, \\ (I - \gamma \Delta t \mathcal{L}) u^{n+1} &= u^{(1)} + (1 - 2\gamma) \Delta t \mathcal{L} u^{(1)}. \end{aligned} \]

The stability rational function is \(R(z) = \frac{1 + (1-2\gamma)z}{(1 - \gamma z)^2}\). As \(z \to -\infty\), \(R(z) \to 0\). The scheme is both \(L\)-stable and second-order accurate \(O(\Delta t^2)\), entirely eliminating spurious oscillations without sacrificing asymptotic quadratic convergence.

R3 · Craig–Sneyd scheme with mixed derivatives

In multi-asset pricing with asset correlation \(\rho\), write out the Craig–Sneyd ADI scheme and explain how cross-diffusion \(\mathcal{L}_0 u = \rho \sigma_1 \sigma_2 S_1 S_2 V_{S_1 S_2}\) is treated to maintain second-order accuracy.

Solution

The Craig–Sneyd scheme decomposes \(\mathcal{L} = \mathcal{L}_0 + \mathcal{L}_1 + \mathcal{L}_2\) into mixed terms \(\mathcal{L}_0\) and directional terms \(\mathcal{L}_1, \mathcal{L}_2\). It executes four sub-steps per time interval:

\[ \begin{aligned} Y_0 &= u^n + \Delta t (\mathcal{L}_0 + \mathcal{L}_1 + \mathcal{L}_2) u^n, \\ (I - \theta \Delta t \mathcal{L}_1) Y_1 &= Y_0 - \theta \Delta t \mathcal{L}_1 u^n, \\ (I - \theta \Delta t \mathcal{L}_2) Y_2 &= Y_1 - \theta \Delta t \mathcal{L}_2 u^n, \\ \tilde{Y}_0 &= Y_0 + \frac{1}{2}\Delta t \mathcal{L}_0 (Y_2 - u^n), \\ (I - \theta \Delta t \mathcal{L}_1) \tilde{Y}_1 &= \tilde{Y}_0 - \theta \Delta t \mathcal{L}_1 u^n, \\ (I - \theta \Delta t \mathcal{L}_2) u^{n+1} &= \tilde{Y}_1 - \theta \Delta t \mathcal{L}_2 u^n. \end{aligned} \]

By using a predictor-corrector on the mixed derivative \(\mathcal{L}_0\), Craig–Sneyd preserves second-order convergence \(O(\Delta t^2 + \Delta x_1^2 + \Delta x_2^2)\) while requiring only 1D tridiagonal solves.

9Retrieval quiz

  1. What weighting parameter \(\theta\) corresponds to the Crank–Nicolson scheme in the general \(\theta\)-family?

    Options

    \(\theta = 1/2\) places equal weight on levels \(n\) and \(n+1\), centering the discretization at \(\tau_{n+1/2}\).

  2. What is the local truncation error of the Crank–Nicolson scheme for smooth solutions?

    Options

    By centering the time difference at \(\tau_{n+1/2}\), odd powers of \(\Delta t\) cancel, achieving second-order temporal and spatial accuracy.

  3. What is the limit of the Crank–Nicolson Nyquist mode amplification factor \(G(\pi)\) as \(\lambda \to \infty\)?

    Options

    \(G(\pi) = \frac{1 - 2\lambda}{1 + 2\lambda}\). Dividing numerator and denominator by \(\lambda\) shows \(\lim_{\lambda \to \infty} G(\pi) = -1\).

  4. Why does Crank–Nicolson exhibit non-decaying oscillations when pricing digital options?

    Options

    The lack of \(L\)-stability means modes with \(G \approx -1\) persist indefinitely, alternating signs each step.

  5. Above what value of \(\lambda = D \Delta t / \Delta x^2\) does the Nyquist amplification factor \(G(\pi)\) become negative in Crank–Nicolson?

    \(G(\pi) = \frac{1 - 2\lambda}{1 + 2\lambda} < 0 \iff 1 - 2\lambda < 0 \iff \lambda > 0.5\).

  6. What distinguishes an \(L\)-stable scheme from an \(A\)-stable scheme?

    Options

    \(L\)-stability requires \(\lim_{\text{Re}(z) \to -\infty} R(z) = 0\), completely extinguishing high-frequency noise.

  7. What is the Padé approximation order of the Crank–Nicolson rational function \(\frac{1 - z/2}{1 + z/2}\)?

    Options

    The function is degree 1 in numerator and denominator: the diagonal \([1/1]\) Padé approximant of \(e^{-z}\).

  8. By Dahlquist's Second Barrier Theorem, what is the maximum possible order of accuracy for an \(A\)-stable linear multistep method?
