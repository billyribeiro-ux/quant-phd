Poisson & Compound Poisson Processes

Asset prices undergo sudden discontinuous shocks during earnings releases, central bank announcements, and liquidity runs that continuous diffusion paths cannot capture. The Poisson process and its compound generalization provide the mathematical foundation for modeling discrete arrivals. Subtracting deterministic compensators converts counting processes into continuous-time martingales, enabling rigorous arbitrage-free pricing.

1Counting Processes and the Poisson Process

Let \((\Omega, \mathcal{F}, (\mathcal{F}_t)_{t \ge 0}, \Prob)\) be a filtered probability space satisfying the usual conditions. A stochastic process \(N = (N_t)_{t \ge 0}\) taking values in \(\N_0 = \{0, 1, 2, \dots\}\) is a counting process if \(N_0 = 0\) almost surely, its paths \(t \mapsto N_t(\omega)\) are non-decreasing, and they are right-continuous with left limits (càdlàg).

Definition 1.1 (Poisson Process)

A counting process \(N = (N_t)_{t \ge 0}\) adapted to \((\mathcal{F}_t)\) is a Poisson process with constant intensity \(\lambda > 0\) if:

  1. \(N_0 = 0\) almost surely;
  2. For any \(0 \le s < t\), the increment \(N_t - N_s\) is independent of \(\mathcal{F}_s\) (independent increments);
  3. For any \(0 \le s < t\), the increment \(N_t - N_s\) follows a Poisson distribution with parameter \(\lambda(t - s)\):
\[ \Prob(N_t - N_s = k) = \frac{(\lambda (t - s))^k}{k!} e^{-\lambda (t - s)}, \quad k \in \N_0. \]
Theorem 1.2 (Inter-Arrival Times and Memoryless Property)

Assumptions: (A1) \(N = (N_t)_{t \ge 0}\) is a Poisson process with intensity \(\lambda > 0\); (A2) \(T_1, T_2, \dots\) are the jump arrival times, \(T_n = \inf\{t > 0 : N_t = n\}\), with inter-arrival durations \(\tau_1 = T_1\) and \(\tau_k = T_k - T_{k-1}\) for \(k \ge 2\).

Statement: The inter-arrival times \((\tau_k)_{k \ge 1}\) are independent and identically distributed exponential random variables with rate parameter \(\lambda\):

\[ \Prob(\tau_k > t) = e^{-\lambda t}, \quad t \ge 0, \quad \E[\tau_k] = \frac{1}{\lambda}, \quad \Var(\tau_k) = \frac{1}{\lambda^2}. \]

Furthermore, they satisfy the memoryless property: \(\Prob(\tau_k > t + s \mid \tau_k > s) = \Prob(\tau_k > t)\) for all \(s, t \ge 0\).

Proof

For the first arrival \(\tau_1 = T_1\), the event \(\{\tau_1 > t\}\) occurs if and only if no jumps occur in \([0, t]\), which means \(N_t = 0\). Using the Poisson increment distribution with \(s = 0\):

\[ \Prob(\tau_1 > t) = \Prob(N_t = 0) = \frac{(\lambda t)^0}{0!} e^{-\lambda t} = e^{-\lambda t}. \]

Differentiating \(F(t) = 1 - e^{-\lambda t}\) yields probability density \(f(t) = \lambda e^{-\lambda t} \indic_{\{t \ge 0\}}\). The memoryless property follows from conditional probability:

\[ \Prob(\tau_1 > t + s \mid \tau_1 > s) = \frac{\Prob(\tau_1 > t + s)}{\Prob(\tau_1 > s)} = \frac{e^{-\lambda(t+s)}}{e^{-\lambda s}} = e^{-\lambda t} = \Prob(\tau_1 > t). \]

By the strong Markov property of \(N\) applied at stopping time \(T_{k-1}\), the restarted process \(\widetilde{N}_t = N_{T_{k-1} + t} - N_{T_{k-1}}\) is an independent Poisson process with intensity \(\lambda\). Hence \(\tau_k\) is identically distributed to \(\tau_1\) and independent of \(\mathcal{F}_{T_{k-1}}\).

Remark 1.3 (Càdlàg Paths and Pure Jumps)

Unlike Brownian paths, which are continuous everywhere and almost nowhere differentiable with non-zero quadratic variation on every interval, the paths of a Poisson process are piecewise constant step functions with unit positive discontinuities: \(\Delta N_t \coloneqq N_t - N_{t-} \in \{0, 1\}\). On any finite horizon \([0, H]\), the number of jumps \(N_H\) is almost surely finite.

2Compensated Poisson Process and Martingale Invariants

Because \(N_t\) has strictly increasing paths with expectation \(\E[N_t] = \lambda t > 0\), the raw Poisson process is a submartingale, not a martingale. To construct martingales suitable for continuous-time asset pricing, we subtract the deterministic compensator \(\lambda t\).

Theorem 2.1 (Compensated Poisson Martingale)

Assumptions: (A1) \(N = (N_t)_{t \ge 0}\) is a Poisson process with intensity \(\lambda > 0\) adapted to filtration \((\mathcal{F}_t)_{t \ge 0}\); (A2) \(M_t \coloneqq N_t - \lambda t\).

Statement: The compensated process \(M = (M_t)_{t \ge 0}\) is a continuous-time square-integrable martingale starting at zero: \(\E[M_t] = 0\) and \(\E[M_t \mid \mathcal{F}_s] = M_s\) for all \(0 \le s \le t\).

Proof

First, \(\E[|M_t|] \le \E[N_t] + \lambda t = 2\lambda t < \infty\), so \(M_t\) is integrable. Next, choose \(0 \le s \le t\). Express the increment \(M_t - M_s\) as:

\[ M_t - M_s = (N_t - N_s) - \lambda (t - s). \]

Taking conditional expectation with respect to \(\mathcal{F}_s\), and using the independence of increment \(N_t - N_s\) from \(\mathcal{F}_s\):

\[ \E[M_t - M_s \mid \mathcal{F}_s] = \E[(N_t - N_s) - \lambda (t - s) \mid \mathcal{F}_s] = \E[N_t - N_s] - \lambda (t - s) = \lambda (t - s) - \lambda (t - s) = 0. \]

Adding \(M_s\) to both sides yields \(\E[M_t \mid \mathcal{F}_s] = M_s\), establishing the martingale property.

Theorem 2.2 (Quadratic Variation and Predictable Bracket)

Assumptions: (A1) \(M_t = N_t - \lambda t\) is the compensated Poisson process.

Statement: The pathwise quadratic variation \([M, M]_t\) and the predictable quadratic variation (angle bracket) \(\langle M, M \rangle_t\) are given by:

\[ [M, M]_t = [N, N]_t = \sum_{0 < s \le t} (\Delta N_s)^2 = N_t, \quad \text{and} \quad \langle M, M \rangle_t = \lambda t. \]

Consequently, \(M_t^2 - \lambda t\) is a continuous-time martingale.

Proof

Because the compensator \(t \mapsto \lambda t\) is deterministic and continuous with finite first variation, it contributes zero quadratic variation. Since all jumps of \(N\) are of size \(\Delta N_s = 1\), the sum of squared jumps is \(\sum_{s \le t} 1^2 = N_t\). For the predictable bracket, the compensator of \(N_t\) is \(\lambda t\), so \(N_t - \lambda t\) is a martingale. Hence:

\[ M_t^2 - \lambda t = (N_t - \lambda t)^2 - \lambda t = N_t^2 - 2\lambda t N_t + \lambda^2 t^2 - \lambda t. \]

Evaluating the conditional increment for \(s < t\), standard algebraic expansion using \(\Var(N_t - N_s) = \lambda(t-s)\) shows that \(\E[M_t^2 - M_s^2 \mid \mathcal{F}_s] = \lambda(t - s)\), which verifies \(\langle M, M \rangle_t = \lambda t\).

3Compound Poisson Processes and Jump Differentials

In quantitative finance, market shocks do not have unit magnitude. A realistic jump model must allow random jump sizes arriving at Poisson times.

Definition 3.1 (Compound Poisson Process)

Let \(N = (N_t)_{t \ge 0}\) be a Poisson process with intensity \(\lambda > 0\), and let \((Y_k)_{k \ge 1}\) be a sequence of independent and identically distributed random variables with distribution \(F_Y\) on \(\R\), independent of \(N\). The compound Poisson process \(X = (X_t)_{t \ge 0}\) is defined by:

\[ X_t \coloneqq \sum_{k=1}^{N_t} Y_k, \quad \text{with } X_t = 0 \text{ when } N_t = 0. \]
Theorem 3.2 (Characteristic Function and Moments of Compound Poisson)

Assumptions: (A1) \(X_t = \sum_{k=1}^{N_t} Y_k\) is a compound Poisson process with intensity \(\lambda\) and jump size distribution \(F_Y\); (A2) \(\phi_Y(u) \coloneqq \E[e^{i u Y}]\) is the characteristic function of the jump size.

Statement: The characteristic function of \(X_t\) is given by:

\[ \phi_{X_t}(u) \coloneqq \E[e^{i u X_t}] = \exp\left( \lambda t (\phi_Y(u) - 1) \right). \]

If \(\E[Y^2] < \infty\), the first two moments are:

\[ \E[X_t] = \lambda t \E[Y], \quad \Var(X_t) = \lambda t \E[Y^2] = \lambda t \left(\Var(Y) + (\E[Y])^2\right). \]
Proof

Condition on the number of jumps \(N_t = n\). Since the jump sizes \((Y_k)\) are i.i.d. and independent of \(N_t\):

\[ \E\left[e^{i u X_t} \;\middle|\; N_t = n\right] = \E\left[\exp\left(i u \sum_{k=1}^n Y_k\right)\right] = \prod_{k=1}^n \E[e^{i u Y_k}] = (\phi_Y(u))^n. \]

By the law of total expectation:

\[ \E[e^{i u X_t}] = \sum_{n=0}^\infty \E\left[e^{i u X_t} \;\middle|\; N_t = n\right] \Prob(N_t = n) = \sum_{n=0}^\infty (\phi_Y(u))^n \frac{(\lambda t)^n}{n!} e^{-\lambda t} = e^{-\lambda t} \sum_{n=0}^\infty \frac{(\lambda t \phi_Y(u))^n}{n!}. \]

Summing the Taylor series for the exponential gives \(e^{-\lambda t} e^{\lambda t \phi_Y(u)} = \exp(\lambda t (\phi_Y(u) - 1))\).

For the moments, differentiate the log-characteristic function \(\ln \phi_{X_t}(u) = \lambda t (\phi_Y(u) - 1)\) at \(u = 0\):

\[ \frac{d}{du}\ln \phi_{X_t}(0) = \lambda t \phi_Y'(0) = \lambda t (i \E[Y]) = i (\lambda t \E[Y]) \implies \E[X_t] = \lambda t \E[Y]. \]

The second derivative yields \(\frac{d^2}{du^2}\ln \phi_{X_t}(0) = \lambda t \phi_Y''(0) = -\lambda t \E[Y^2] = -\Var(X_t)\), proving the variance formula.

Theorem 3.3 (Itô's Formula for Pure Jump Processes)

Assumptions: (A1) \(X_t = \sum_{k=1}^{N_t} Y_k\) is a compound Poisson process; (A2) \(f: \R \to \R\) is a continuously differentiable function.

Statement: The pathwise change in \(f(X_t)\) is governed entirely by the discrete jumps:

\[ f(X_t) - f(X_0) = \sum_{0 < s \le t} \left[ f(X_s) - f(X_{s-}) \right] = \sum_{k=1}^{N_t} \left[ f(X_{T_k-} + Y_k) - f(X_{T_k-}) \right]. \]

In differential notation, \(df(X_t) = [f(X_{t-} + \Delta X_t) - f(X_{t-})]\). No second-order derivative term \(\tfrac{1}{2} f''(X_t) dt\) appears because pure jump processes have zero continuous quadratic variation.

4Where the canon breaks

In standard Itô calculus for continuous diffusions, Taylor expansion truncated at second order yields the celebrated Itô correction \(\tfrac{1}{2} f''(S_t) (dS_t)^2 = \tfrac{1}{2} \sigma^2 S_t^2 f''(S_t) dt\), because Brownian increments scale as \(\Delta B \sim O(\sqrt{\Delta t})\). For jump processes, this entire paradigm breaks down. When a jump occurs at time \(\tau\), the increment \(\Delta X_\tau = X_\tau - X_{\tau-}\) is \(O(1)\), meaning it does not vanish as \(\Delta t \to 0\). Truncating a Taylor series at second order is completely invalid; instead, the exact non-local difference \(\Delta f(X_\tau) = f(X_{\tau-} + \Delta X_\tau) - f(X_{\tau-})\) must be retained. Furthermore, markets driven by jump processes are intrinsically incomplete: a single underlying stock and a risk-free cash bond cannot replicate arbitrary option payoffs because the jump magnitude \(Y\) introduces a continuum of potential state outcomes at every jump instant (Cont & Tankov 2004).

5Misconceptions

  1. “The Poisson process \(N_t\) is a continuous-time martingale because jump arrivals are unpredictable.”

    A martingale must have constant expectation: \(\E[M_t] = \E[M_0]\). Because jump arrivals are non-negative, \(\E[N_t] = \lambda t > 0\), meaning \(N_t\) has strictly positive drift and is a submartingale. Only the compensated process \(N_t - \lambda t\) is a martingale.

  2. “Because Poisson paths are discontinuous, their quadratic variation \([N, N]_t\) is infinite.”

    On any finite interval \([0, H]\), a Poisson process has almost surely a finite number of jumps \(N_H < \infty\). The quadratic variation is the finite sum of squared jumps: \([N, N]_t = \sum_{s \le t} (\Delta N_s)^2 = N_t < \infty\). In fact, the sample paths of a compound Poisson process have finite total (first) variation on every bounded interval.

  3. “The variance of a compound Poisson process \(X_t = \sum_{k=1}^{N_t} Y_k\) is simply \(\lambda t \Var(Y)\).”

    This formula ignores the variance contributed by the randomness in the number of jumps itself. By the law of total variance, \(\Var(X_t) = \E[\Var(X_t \mid N_t)] + \Var(\E[X_t \mid N_t]) = \E[N_t \Var(Y)] + \Var(N_t \E[Y]) = \lambda t \Var(Y) + \lambda t (\E[Y])^2 = \lambda t \E[Y^2]\). If jumps have non-zero mean, neglecting \((\E[Y])^2\) underestimates total risk.

M1 · Inter-arrival probability calculation

A Poisson counter \(N_t\) records corporate credit default events with arrival intensity \(\lambda = 0.4\) defaults per year. Compute the exact probability that no defaults occur during the first 2.5 years, and find the median waiting time until the first default.

Solution

The waiting time \(\tau_1\) until the first default follows an exponential distribution with parameter \(\lambda = 0.4\). The probability of no defaults on \([0, 2.5]\) is:

\[ \Prob(\tau_1 > 2.5) = \Prob(N_{2.5} = 0) = e^{-\lambda t} = e^{-0.4 \times 2.5} = e^{-1.0} \approx 0.367879. \]

The median waiting time \(t_{\text{med}}\) satisfies \(F(t_{\text{med}}) = 1 - e^{-\lambda t_{\text{med}}} = 0.5 \implies e^{-\lambda t_{\text{med}}} = 0.5\). Solving yields \(t_{\text{med}} = \frac{\ln 2}{\lambda} = \frac{0.693147}{0.4} \approx 1.732868\) years.

M2 · Compound Poisson variance decomposition

A financial shock process has jump arrival intensity \(\lambda = 1.5\) per year. Jump sizes \(Y\) are discrete: \(Y = +0.10\) with probability \(0.7\), and \(Y = -0.20\) with probability \(0.3\). Compute the expectation \(\E[X_1]\) and variance \(\Var(X_1)\) of the cumulative shock \(X_1\) over one year.

Solution

Compute the raw moments of the jump size distribution \(Y\):

\[ \E[Y] = 0.7(0.10) + 0.3(-0.20) = 0.07 - 0.06 = 0.01. \] \[ \E[Y^2] = 0.7(0.10^2) + 0.3(-0.20^2) = 0.7(0.01) + 0.3(0.04) = 0.007 + 0.012 = 0.019. \]

Using Theorem 3.2 for \(t = 1.0\):

\[ \E[X_1] = \lambda t \E[Y] = 1.5 \times 1.0 \times 0.01 = 0.015. \] \[ \Var(X_1) = \lambda t \E[Y^2] = 1.5 \times 1.0 \times 0.019 = 0.0285. \]
M3 · Compensated jump expectation

Let \(X_t = \sum_{k=1}^{N_t} Y_k\) be a compound Poisson process with \(\lambda = 4.0\), \(\E[Y] = -0.05\), and \(\Var(Y) = 0.04\). Define the compensated process \(M_t = X_t + 0.20 t\). Evaluate \(\E[M_3]\) and \(\Var(M_3)\).

Solution

The compensator of \(X_t\) is \(\lambda t \E[Y] = 4.0 \times (-0.05) t = -0.20 t\). Thus \(M_t = X_t - (-0.20 t) = X_t + 0.20 t\) is the compensated martingale. By Theorem 2.1, its expectation is identically zero:

\[ \E[M_3] = 0. \]

Because adding a deterministic function does not affect variance, \(\Var(M_3) = \Var(X_3)\). We compute \(\E[Y^2] = \Var(Y) + (\E[Y])^2 = 0.04 + (-0.05)^2 = 0.0425\). Therefore:

\[ \Var(M_3) = \lambda t \E[Y^2] = 4.0 \times 3.0 \times 0.0425 = 12.0 \times 0.0425 = 0.51. \]

P1 · Superposition of independent Poisson processes

Let \(N^{(1)}\) and \(N^{(2)}\) be independent Poisson processes with intensities \(\lambda_1 > 0\) and \(\lambda_2 > 0\). Prove that their sum \(N_t = N_t^{(1)} + N_t^{(2)}\) is a Poisson process with intensity \(\lambda = \lambda_1 + \lambda_2\).

Solution

We check the three defining conditions of Definition 1.1:

  1. \(N_0 = N_0^{(1)} + N_0^{(2)} = 0 + 0 = 0\) almost surely.
  2. Because \(N^{(1)}\) and \(N^{(2)}\) are independent and both have independent increments, for any \(s < t\), the combined increment \(N_t - N_s = (N_t^{(1)} - N_s^{(1)}) + (N_t^{(2)} - N_s^{(2)})\) is a sum of random variables independent of \(\mathcal{F}_s\), hence independent of \(\mathcal{F}_s\).
  3. Compute the characteristic function of the increment \(\Delta N = N_t - N_s\). By independence:
\[ \E\left[e^{i u (N_t - N_s)}\right] = \E\left[e^{i u (N_t^{(1)} - N_s^{(1)})}\right] \E\left[e^{i u (N_t^{(2)} - N_s^{(2)})}\right]. \]

For a Poisson random variable with parameter \(\alpha\), the characteristic function is \(\exp(\alpha(e^{i u} - 1))\). Substituting \(\alpha_1 = \lambda_1(t-s)\) and \(\alpha_2 = \lambda_2(t-s)\):

\[ \E\left[e^{i u \Delta N}\right] = e^{\lambda_1 (t-s)(e^{i u}-1)} e^{\lambda_2 (t-s)(e^{i u}-1)} = \exp\left((\lambda_1 + \lambda_2)(t - s)(e^{i u} - 1)\right). \]

By uniqueness of characteristic functions, \(N_t - N_s \sim \text{Poisson}((\lambda_1 + \lambda_2)(t - s))\), confirming that \(N\) is a Poisson process with intensity \(\lambda_1 + \lambda_2\).

P2 · Martingale property of the exponential jump process

Let \(N_t\) be a Poisson process with intensity \(\lambda\). For any constant \(\theta \in \R\), find the deterministic function \(g(t)\) such that \(Z_t = \exp(\theta N_t - g(t))\) is a continuous-time martingale.

Solution

For \(Z_t\) to be a martingale, we require \(\E[Z_t \mid \mathcal{F}_s] = Z_s\) for all \(s \le t\). Compute:

\[ \E[Z_t \mid \mathcal{F}_s] = \E\left[e^{\theta N_t - g(t)} \;\middle|\; \mathcal{F}_s\right] = e^{\theta N_s - g(t)} \E\left[e^{\theta (N_t - N_s)} \;\middle|\; \mathcal{F}_s\right]. \]

Since \(N_t - N_s \sim \text{Poisson}(\lambda(t-s))\) is independent of \(\mathcal{F}_s\), its moment generating function evaluated at \(\theta\) is:

\[ \E\left[e^{\theta(N_t - N_s)}\right] = \sum_{k=0}^\infty e^{\theta k} \frac{(\lambda(t-s))^k}{k!} e^{-\lambda(t-s)} = e^{-\lambda(t-s)} e^{\lambda(t-s)e^\theta} = \exp\left( \lambda(t-s)(e^\theta - 1) \right). \]

Substituting this back into the conditional expectation:

\[ \E[Z_t \mid \mathcal{F}_s] = \exp\left(\theta N_s - g(t) + \lambda(t-s)(e^\theta - 1)\right). \]

Setting this equal to \(Z_s = \exp(\theta N_s - g(s))\) requires \(-g(t) + \lambda t(e^\theta - 1) = -g(s) + \lambda s(e^\theta - 1)\). Choosing \(g(0) = 0\) yields the exact compensator \(g(t) = \lambda t (e^\theta - 1)\). Hence \(Z_t = \exp(\theta N_t - \lambda t (e^\theta - 1))\) is a martingale.

P3 · Compound Poisson martingale condition

Let \(X_t = \sum_{k=1}^{N_t} Y_k\) be a compound Poisson process with i.i.d. jump sizes \(Y_k \sim F_Y\). Prove that \(X_t\) is a continuous-time martingale if and only if \(\E[Y] = 0\).

Solution

By the tower property and independent increments of compound Poisson processes:

\[ \E[X_t - X_s \mid \mathcal{F}_s] = \E[X_t - X_s] = \E\left[\sum_{k=N_s + 1}^{N_t} Y_k\right] = \E[N_t - N_s] \E[Y] = \lambda(t - s) \E[Y]. \]

For \(X\) to be a martingale, this conditional increment must equal zero for all \(0 \le s < t\). Because \(\lambda > 0\) and \(t - s > 0\), \(\lambda(t - s) \E[Y] = 0\) if and only if \(\E[Y] = 0\).

Empirical

E1 · Estimating jump intensity from discrete financial time series

Daily returns for an equity index over 500 trading days (2 years) show 6 discrete daily moves whose absolute magnitude exceeds 4 standard deviations (\(|r_t| > 4\sigma\)), identified as jump events. Estimate the annualized jump intensity \(\hat{\lambda}\) and its 95% Poisson confidence interval.

Solution

The observation window is \(\Delta T = 500 / 252 \approx 1.984\) years. The point estimate of the arrival rate is:

\[ \hat{\lambda} = \frac{k}{\Delta T} = \frac{6}{1.984} \approx 3.024 \text{ jumps per year}. \]

Under the Poisson law, an exact 95% confidence interval for the count \(k = 6\) is given by \(\tfrac{1}{2} \chi^2(2k, 0.025)\) and \(\tfrac{1}{2} \chi^2(2k+2, 0.975)\), yielding \([2.202, 13.060]\) jumps. Dividing by \(\Delta T = 1.984\) years produces the annualized intensity confidence interval \([1.11, 6.58]\) jumps per year.

E2 · Impact of asymmetric jump sizes on skewness

Suppose jump arrival intensity is \(\lambda = 1.0\). In Market A, jumps are symmetric: \(Y \sim \Normal(0, 0.2^2)\). In Market B, jumps have negative skew: \(Y \sim \Normal(-0.1, 0.2^2)\). Compute the third central moment \(\mu_3(X_1) = \E[(X_1 - \E[X_1])^3]\) for both markets and explain the economic significance for out-of-the-money put options.

Solution

For a compound Poisson process, the third central moment is \(\mu_3(X_t) = \lambda t \E[Y^3]\). In Market A, \(Y \sim \Normal(0, 0.2^2)\) is symmetric around 0, so \(\E[Y^3] = 0 \implies \mu_3(X_1) = 0\).

In Market B, \(Y = \mu_Y + \sigma_Y Z\) where \(Z \sim \Normal(0, 1)\). Expanding \(\E[Y^3] = \E[(\mu_Y + \sigma_Y Z)^3] = \mu_Y^3 + 3\mu_Y \sigma_Y^2 = (-0.1)^3 + 3(-0.1)(0.04) = -0.001 - 0.012 = -0.013\). Thus:

\[ \mu_3(X_1) = 1.0 \times (-0.013) = -0.013. \]

Economically, negative skewness generates an asymmetric left tail (crash risk), dramatically elevating the implied volatility of out-of-the-money put options compared to out-of-the-money calls.

E3 · Probability of multiple jumps on high-frequency trading horizons

On an algorithmic trading horizon of \(\Delta t = 5\) minutes (where 1 trading day = 6.5 hours = 78 five-minute intervals), assume \(\lambda = 50\) jumps per year (252 trading days). Calculate the probability of observing exactly 1 jump versus 2 or more jumps in a 5-minute bar.

Solution

Total 5-minute intervals per year is \(252 \times 78 = 19,656\). The Poisson parameter per 5-minute bar is:

\[ \mu = \lambda \Delta t = \frac{50}{19,656} \approx 0.0025437. \]

The probability of exactly 1 jump is \(\Prob(N = 1) = \mu e^{-\mu} \approx 0.0025437 \times e^{-0.0025437} \approx 0.0025372\) (approx 0.254%). The probability of 2 or more jumps is:

\[ \Prob(N \ge 2) = 1 - e^{-\mu} - \mu e^{-\mu} \approx 1 - (1 - \mu + \tfrac{1}{2}\mu^2) - \mu(1 - \mu) \approx \tfrac{1}{2}\mu^2 = \tfrac{1}{2}(0.0025437)^2 \approx 3.23 \times 10^{-6}. \]

The ratio \(\Prob(N \ge 2) / \Prob(N = 1) \approx 0.00127\); multiple jumps within a single 5-minute window occur fewer than once every 800 jump events, validating Bernoulli approximations at ultra-high frequency.

R1 · Inhomogeneous Poisson processes and intraday seasonality

High-frequency market data exhibits a classic U-shaped intraday volatility pattern, with jump arrivals heavily concentrated near market open (9:30 AM) and close (4:00 PM). Formulate the inhomogeneous Poisson process with time-varying intensity \(\lambda(t)\), and derive its compensator and characteristic function.

Solution

An inhomogeneous Poisson process has independent increments where \(N_t - N_s \sim \text{Poisson}(\Lambda(s, t))\) with integrated intensity \(\Lambda(s, t) = \int_s^t \lambda(u) du\). The compensator is the continuous deterministic process \(A_t = \int_0^t \lambda(u) du\), ensuring that \(M_t = N_t - \int_0^t \lambda(u) du\) is a martingale. The characteristic function of \(N_t\) is \(\E[e^{i u N_t}] = \exp\left( \Lambda(0, t)(e^{i u} - 1) \right)\). By defining a deterministic time change \(\tau(t) = \Lambda(0, t)\), the inhomogeneous process can be represented as a standard homogeneous Poisson process running on transformed clock \(\tau\).

R2 · Jump activity versus sample path variation

Compare the total path variation of standard Brownian motion versus a compound Poisson process on \([0, H]\). Explain why compound Poisson processes have finite variation while Brownian motion has infinite variation, and state the implications for pathwise integration.

Solution

Total variation on \([0, H]\) is \(\sup_\Pi \sum_k |X_{t_{k+1}} - X_{t_k}|\). For a compound Poisson process with \(N_H < \infty\) jumps, the paths are constant between jump times, so the total variation equals the finite sum of absolute jump sizes: \(\sum_{k=1}^{N_H} |Y_k| < \infty\) almost surely. Consequently, pathwise Lebesgue–Stieltjes integrals \(\int_0^H f(t) dX_t = \sum_{k=1}^{N_H} f(T_k) Y_k\) are well-defined for any bounded measurable integrand without requiring Itô limits. In contrast, Brownian paths almost surely have infinite variation on every interval, which forces integration to rely on \(L^2\) limits and non-anticipating filtrations.

R3 · Marked point processes and self-exciting Hawkes dynamics

In financial panic episodes, a large market jump often increases the likelihood of subsequent aftershock jumps. Contrast the memoryless compound Poisson process with a self-exciting Hawkes process whose intensity satisfies \(\lambda_t = \lambda_0 + \int_0^t \alpha e^{-\beta(t-s)} dN_s\). Explain how Hawkes processes violate the independent increments property of Lévy processes.

Solution

Under a compound Poisson process, increments \(N_t - N_s\) are independent of history \(\mathcal{F}_s\), and inter-arrival times are memoryless. In a Hawkes process, each jump at time \(T_k < t\) produces an instantaneous jump in intensity of size \(\alpha > 0\), which decays exponentially at rate \(\beta\). Thus, observing a jump in \([0, s]\) strictly increases \(\lambda_t\) for \(t > s\), making future increments conditionally dependent on past arrivals: \(\E[N_t - N_s \mid \mathcal{F}_s] > \E[N_t - N_s \mid N_s = 0]\). This feedback creates jump clustering and volatility persistence, violating the independent increments axiom that defines the Lévy process class.

8Retrieval quiz

  1. What is the distribution of the inter-arrival times \(\tau_k = T_k - T_{k-1}\) between consecutive jumps in a Poisson process with intensity \(\lambda\)?

    Options

    By Theorem 1.2, \(\Prob(\tau_k > t) = \Prob(N_t = 0) = e^{-\lambda t}\), which is the survival function of an exponential random variable with parameter \(\lambda\).

  2. What is the expectation \(\E[N_t - \lambda t]\) of the compensated Poisson process at any horizon \(t > 0\)?

    Because \(\E[N_t] = \lambda t\), the compensated process \(M_t = N_t - \lambda t\) has expectation \(\lambda t - \lambda t = 0\).

  3. Why is the raw Poisson process \(N_t\) a submartingale rather than a martingale?

    Options

    By Theorem 2.1, \(N_t\) has strictly positive drift \(\lambda(t - s) > 0\), violating the constant conditional expectation requirement of a martingale.

  4. For a compound Poisson process with \(\lambda = 2.5\), \(H = 1.0\), \(\E[Y] = -0.05\), and \(\Var(Y) = 0.0475\), what is the total variance \(\Var(X_H)\)?

    \(\E[Y^2] = \Var(Y) + (\E[Y])^2 = 0.0475 + (-0.05)^2 = 0.0475 + 0.0025 = 0.05\). Then \(\Var(X_H) = \lambda H \E[Y^2] = 2.5 \times 1.0 \times 0.05 = 0.125\).

  5. What is the log-characteristic function \(\ln \E[e^{i u X_t}]\) of a compound Poisson process \(X_t = \sum_{k=1}^{N_t} Y_k\)?

    Options

    By Theorem 3.2, \(\E[e^{i u X_t}] = \exp(\lambda t (\phi_Y(u) - 1))\), so taking the natural logarithm yields \(\lambda t (\phi_Y(u) - 1)\).

  6. In Itô's formula for a pure jump process \(X_t\), why is there no second-derivative term \(\tfrac{1}{2} f''(X_t) dt\)?

    Options

    By Theorem 3.3, pure jump processes have zero continuous diffusion part, so \((dX_t^c)^2 = 0\); all change occurs in discrete steps \(\Delta f(X_s)\).

  7. For standard Poisson counter \(N_t\) with intensity \(\lambda = 1.0\), what is the quadratic variation \([N, N]_1\) if exactly 1 jump occurred by time \(t = 1\)?

    By Theorem 2.2, \([N, N]_t = \sum_{s \le t}(\Delta N_s)^2 = N_t = 1\).

  8. What property guarantees that the inter-arrival time \(\tau_k\) until the next jump does not depend on how much time has elapsed since the previous jump?

    Options

    The exponential distribution satisfies \(\Prob(\tau > t + s \mid \tau > s) = \Prob(\tau > t)\), meaning past waiting time provides no information about future arrival.

  9. Under what condition on the jump size \(Y\) is a compound Poisson process \(X_t = \sum_{k=1}^{N_t} Y_k\) a continuous-time martingale?

    Options

    Because \(\E[X_t - X_s \mid \mathcal{F}_s] = \lambda(t - s)\E[Y]\), the expected increment is zero for all intervals if and only if \(\E[Y] = 0\).
