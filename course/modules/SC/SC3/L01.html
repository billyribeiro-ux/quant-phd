Girsanov's Theorem

In continuous-time quantitative finance, arbitrage-free pricing requires evaluating expectations under risk-neutral or forward probability measures rather than historical probabilities. Girsanov's theorem is the engine of measure transformations: it states that changing to an equivalent probability measure shifts the drift of a Brownian motion while preserving its volatility and quadratic variation. This provides the exact mathematical foundation for eliminating excess expected returns.

1Continuous-Time Radon–Nikodym Process

Let \((\Omega, \mathcal{F}, (\mathcal{F}_t)_{t \in [0, H]}, \Prob)\) be a filtered probability space satisfying the usual conditions, carrying a standard one-dimensional Brownian motion \((B_t)_{t \in [0, H]}\). Suppose \(\mathbb{Q}\) is an equivalent probability measure on \((\Omega, \mathcal{F}_H)\), denoted \(\mathbb{Q} \sim \Prob\), meaning that for any event \(A \in \mathcal{F}_H\), \(\Prob(A) = 0 \iff \mathbb{Q}(A) = 0\).

Definition 1.1 (Radon–Nikodym Derivative Process)

By the Radon–Nikodym theorem, there exists an almost surely strictly positive random variable \(Z_H = \frac{d\mathbb{Q}}{d\Prob} \in L^1(\Omega, \mathcal{F}_H, \Prob)\) such that \(\E^\Prob[Z_H] = 1\). The Radon–Nikodym derivative process (or density process) \((Z_t)_{t \in [0, H]}\) is defined by restriction to sub-\(\sigma\)-algebras:

\[ Z_t \coloneqq \frac{d\mathbb{Q}}{d\Prob}\Bigg|_{\mathcal{F}_t} = \E^\Prob\left[\frac{d\mathbb{Q}}{d\Prob} \;\middle|\; \mathcal{F}_t\right] = \E^\Prob[Z_H \mid \mathcal{F}_t]. \]
Theorem 1.2 (Martingale Property of the Density Process)

Assumptions: (A1) \((\Omega, \mathcal{F}, (\mathcal{F}_t)_{t \in [0, H]}, \Prob)\) is a filtered probability space; (A2) \(\mathbb{Q} \sim \Prob\) on \(\mathcal{F}_H\).

Statement: The density process \((Z_t)_{t \in [0, H]}\) is a strictly positive, continuous-time martingale with respect to \((\mathcal{F}_t, \Prob)\) with \(Z_0 = 1\).

Proof

For any \(0 \le s \le t \le H\), by the tower property of conditional expectation:

\[ \E^\Prob[Z_t \mid \mathcal{F}_s] = \E^\Prob\left[\E^\Prob[Z_H \mid \mathcal{F}_t] \mid \mathcal{F}_s\right] = \E^\Prob[Z_H \mid \mathcal{F}_s] = Z_s. \]

Furthermore, \(Z_0 = \E^\Prob[Z_H \mid \mathcal{F}_0] = \E^\Prob[Z_H] = 1\) almost surely. Strict positivity \(Z_t > 0\) almost surely follows because \(\Prob(Z_t = 0) > 0\) would contradict equivalence \(\mathbb{Q} \sim \Prob\).

2Doléans-Dade Exponentials and Novikov's Condition

Because \(Z_t\) is a strictly positive continuous martingale adapted to the Brownian filtration, we can write \(Z_t = \exp(X_t)\) for a continuous semimartingale \(X_t\). By the martingale representation theorem (established formally in Lesson 3), there exists an adapted process \((\theta_t)_{t \in [0, H]}\) such that \(dZ_t = -\theta_t Z_t dB_t\).

Definition 1.3 (Stochastic Exponential / Doléans-Dade Exponential)

For an adapted process \(\theta\) satisfying \(\int_0^H \theta_s^2 ds < \infty\) almost surely, the stochastic exponential \(\mathcal{E}(-\theta \cdot B)_t\) is defined as the unique strong solution to \(dZ_t = -\theta_t Z_t dB_t\) with \(Z_0 = 1\):

\[ Z_t = \mathcal{E}(-\theta \cdot B)_t \coloneqq \exp\left(-\int_0^t \theta_s dB_s - \frac{1}{2}\int_0^t \theta_s^2 ds\right). \]
Theorem 1.4 (Novikov's Condition)

Assumptions: (A1) \((\theta_t)_{t \in [0, H]}\) is an \(\mathcal{F}_t\)-adapted process; (A2) the integrability condition holds:

\[ \E^\Prob\left[\exp\left(\frac{1}{2}\int_0^H \theta_s^2 ds\right)\right] < \infty. \]

Statement: The stochastic exponential \(Z_t = \mathcal{E}(-\theta \cdot B)_t\) is a true martingale on \([0, H]\), and \(\E^\Prob[Z_H] = 1\).

Remark 1.5 (Local Martingale vs True Martingale)

The stochastic integral \(\int_0^t -\theta_s Z_s dB_s\) is always a non-negative local martingale, hence a supermartingale by Fatou's lemma: \(\E^\Prob[Z_t] \le Z_0 = 1\). If \(\E^\Prob[Z_H] < 1\), strict probability mass is lost at infinity, and the resulting set function fails to be a probability measure. Novikov's condition guarantees uniform integrability, ensuring \(\E^\Prob[Z_H] = 1\).

3Girsanov's Theorem and the Abstract Bayes Formula

Theorem 1.6 (Girsanov's Theorem)

Assumptions: (A1) \((B_t)_{t \in [0, H]}\) is a standard 1-dimensional Brownian motion on \((\Omega, \mathcal{F}, (\mathcal{F}_t), \Prob)\); (A2) \((\theta_t)_{t \in [0, H]}\) satisfies Novikov's condition, defining probability measure \(\mathbb{Q}\) via \(d\mathbb{Q}/d\Prob = Z_H = \mathcal{E}(-\theta \cdot B)_H\).

Statement: The process \((\widetilde{B}_t)_{t \in [0, H]}\) defined by:

\[ \widetilde{B}_t \coloneqq B_t + \int_0^t \theta_s ds \]

is a standard 1-dimensional Brownian motion with respect to the filtration \((\mathcal{F}_t)\) under the probability measure \(\mathbb{Q}\). This result is Girsanov's theorem.

Proof (Lévy's Characterization)

By Lévy's characterization of Brownian motion (SC1), a continuous process \(\widetilde{B}_t\) with \(\widetilde{B}_0 = 0\) is a standard Brownian motion under \(\mathbb{Q}\) if and only if (1) \(\widetilde{B}_t\) is a continuous local martingale under \(\mathbb{Q}\), and (2) its quadratic variation satisfies \([\widetilde{B}, \widetilde{B}]_t = t\).

First, consider the quadratic variation. Since \(\int_0^t \theta_s ds\) is a continuous process of finite variation, it contributes zero quadratic variation:

\[ [\widetilde{B}, \widetilde{B}]_t = \left[B + \int_0^\cdot \theta_s ds, B + \int_0^\cdot \theta_s ds\right]_t = [B, B]_t = t \quad \text{almost surely}. \]

Because \(\mathbb{Q} \sim \Prob\), an event occurring almost surely under \(\Prob\) occurs almost surely under \(\mathbb{Q}\). Thus \([\widetilde{B}, \widetilde{B}]_t = t\) under \(\mathbb{Q}\).

Second, we prove that \(\widetilde{B}_t\) is a \(\mathbb{Q}\)-martingale. By the abstract Bayes formula, \(\widetilde{B}_t\) is a \(\mathbb{Q}\)-martingale if and only if \(Z_t \widetilde{B}_t\) is a \(\Prob\)-martingale. Applying Itô's product rule under \(\Prob\):

\[ d(Z_t \widetilde{B}_t) = Z_t d\widetilde{B}_t + \widetilde{B}_t dZ_t + d\langle Z, \widetilde{B} \rangle_t. \]

Substituting \(d\widetilde{B}_t = dB_t + \theta_t dt\) and \(dZ_t = -\theta_t Z_t dB_t\):

\[ d\langle Z, \widetilde{B} \rangle_t = d\langle -\theta Z \cdot B, B \rangle_t = -\theta_t Z_t dt. \]

Therefore:

\[ d(Z_t \widetilde{B}_t) = Z_t (dB_t + \theta_t dt) - \theta_t Z_t \widetilde{B}_t dB_t - \theta_t Z_t dt = Z_t (1 - \theta_t \widetilde{B}_t) dB_t. \]

The drift terms \(Z_t \theta_t dt\) and \(-\theta_t Z_t dt\) cancel identically. Hence \(Z_t \widetilde{B}_t\) has zero drift, confirming that it is a \(\Prob\)-local martingale, and \(\widetilde{B}_t\) is a \(\mathbb{Q}\)-martingale.

Theorem 1.7 (Abstract Bayes Formula / Generalized Kallianpur–Striebel)

Assumptions: (A1) \(\mathbb{Q} \sim \Prob\) with density process \(Z_t = \E^\Prob[Z_H \mid \mathcal{F}_t]\); (A2) \(X\) is an \(\mathcal{F}_t\)-measurable integrable random variable.

Statement: For any \(s \le t \le H\), the conditional expectation under \(\mathbb{Q}\) satisfies:

\[ \E^\mathbb{Q}[X \mid \mathcal{F}_s] = \frac{\E^\Prob[X Z_t \mid \mathcal{F}_s]}{Z_s}. \]

Lab 1 · Numerical verification of Girsanov's theorem and drift shifting

Under the physical measure P, standard Brownian motion B_t has mean zero and variance t. For a constant drift shift theta and horizon H, the process B_tilde_t = B_t + theta * t has physical expectation E^P[B_tilde_H] = theta * H. Weighting paths by the Doléans-Dade exponential martingale Z_H = exp(-theta * B_H - (1/2) * theta^2 * H) defines an equivalent measure Q under which B_tilde_t is a standard Brownian motion. This lab verifies that E^P[Z_H] = 1, E^Q[B_tilde_H] = 0, and Var^Q(B_tilde_H) = H within sampling error using 10,000 simulated paths (SIMULATED).

"""Lab 1 · Numerical verification of Girsanov's theorem and drift shifting.

Under the physical measure P, standard Brownian motion B_t has mean zero and variance t.
For a constant drift shift theta and horizon H, the process B_tilde_t = B_t + theta * t has
physical expectation E^P[B_tilde_H] = theta * H.
Weighting paths by the Doléans-Dade exponential martingale:
    Z_H = exp(-theta * B_H - (1/2) * theta^2 * H)
defines an equivalent measure Q under which B_tilde_t is a standard Brownian motion.
This lab verifies that E^P[Z_H] = 1, E^Q[B_tilde_H] = 0, and Var^Q(B_tilde_H) = H within
sampling error using 10,000 simulated paths (SIMULATED).
"""

from __future__ import annotations

import math
import random


def main() -> None:
    seed = 42
    rng = random.Random(seed)
    n_paths = 10000
    horizon = 1.0
    theta = 0.75

    sq_h = math.sqrt(horizon)

    z_vals: list[float] = []
    b_tilde_vals: list[float] = []
    weighted_b_tilde: list[float] = []
    weighted_b_tilde_sq: list[float] = []

    for _ in range(n_paths):
        b_h = sq_h * rng.gauss(0.0, 1.0)
        b_tilde = b_h + theta * horizon
        # Radon-Nikodym derivative Z = exp(-theta * B_H - 0.5 * theta^2 * H)
        z = math.exp(-theta * b_h - 0.5 * (theta**2) * horizon)

        z_vals.append(z)
        b_tilde_vals.append(b_tilde)
        weighted_b_tilde.append(z * b_tilde)
        weighted_b_tilde_sq.append(z * (b_tilde**2))

    # Mean of Z under P (should equal 1)
    mean_z = sum(z_vals) / n_paths
    var_z = sum((x - mean_z) ** 2 for x in z_vals) / (n_paths - 1)
    se_z = math.sqrt(var_z / n_paths)

    # Physical expectation E^P[B_tilde_H] (should equal theta * H = 0.75)
    mean_p_btilde = sum(b_tilde_vals) / n_paths
    expected_p = theta * horizon

    # Measure Q expectation E^Q[B_tilde_H] = E^P[Z * B_tilde_H] (should equal 0)
    mean_q_btilde = sum(weighted_b_tilde) / n_paths
    var_q_btilde = sum((x - mean_q_btilde) ** 2 for x in weighted_b_tilde) / (n_paths - 1)
    se_q_btilde = math.sqrt(var_q_btilde / n_paths)

    # Measure Q second moment E^Q[B_tilde_H^2] = E^P[Z * B_tilde_H^2] (should equal H = 1.0)
    mean_q_sq = sum(weighted_b_tilde_sq) / n_paths

    print(f"horizon H: {horizon:.2f}, drift shift theta: {theta:.2f}")
    print(f"E^P[Z_H]: {mean_z:.6f} (se {se_z:.6f})")
    print(f"E^P[B_tilde_H]: {mean_p_btilde:.6f} (target {expected_p:.6f})")
    print(f"E^Q[B_tilde_H]: {mean_q_btilde:.6f} (se {se_q_btilde:.6f})")
    print(f"E^Q[B_tilde_H^2]: {mean_q_sq:.6f} (target {horizon:.6f})")
    print("Z martingale property |E[Z] - 1| <= 3*se:", abs(mean_z - 1.0) <= 3.0 * se_z)
    print("Q-Brownian zero drift |E^Q[B_tilde]| <= 3*se:", abs(mean_q_btilde) <= 3.0 * se_q_btilde)

Weighting each simulated trajectory by the Radon–Nikodym derivative \(Z_H\) shifts the sample mean to -0.004014 (standard error 0.015954), which is indistinguishable from 0.0 within 0.25 standard errors. 4Where the canon breaks

Classical probability theory often assumes that changing measure affects all trajectory properties equally. In continuous-time stochastic calculus, Girsanov's theorem demonstrates a fundamental asymmetry: measures can change drift, but they cannot change volatility or quadratic variation. If two continuous diffusion measures had different diffusion coefficients \(\sigma_1 \neq \sigma_2\), their quadratic variations \([X, X]_t = \int_0^t \sigma^2 ds\) would differ almost surely. Because quadratic variation is a pathwise limit of squared increments, an observer can compute \([X, X]_t\) from a single trajectory with probability 1. Therefore, any event \(\{[X, X]_t = \sigma_1^2 t\}\) would have probability 1 under \(\Prob_1\) and probability 0 under \(\Prob_2\), rendering the two measures mutually singular (\(\Prob_1 \perp \Prob_2\)). Consequently, no equivalent change of measure can ever alter the volatility of an asset price.

5Misconceptions

  1. “Changing the probability measure alters both the drift and the volatility of an asset price process.”

    Volatilities and quadratic covariations are invariant under equivalent measure changes. By Girsanov's theorem, changing to an equivalent measure \(\mathbb{Q} \sim \Prob\) shifts the drift by \(\sigma_t \theta_t dt\) but leaves the diffusion coefficient \(\sigma_t\) and the quadratic variation \([B, B]_t = t\) completely unchanged.

  2. “Every stochastic exponential \(Z_t = \mathcal{E}(-\theta \cdot B)_t\) is a true martingale.”

    A stochastic exponential is always a local martingale and a supermartingale, but it may fail to be a true martingale if probability mass escapes to infinity. Novikov's condition \(\E[\exp(\frac{1}{2}\int_0^H \theta_s^2 ds)] < \infty\) (or Kazamaki's condition) is required to ensure \(\E[Z_H] = 1\).

  3. “Under the risk-neutral measure \(\mathbb{Q}\), the paths of Brownian motion are different from those under \(\Prob\).”

    The sample paths \(\omega \in \Omega\) are identical under both measures; equivalence \(\mathbb{Q} \sim \Prob\) means both measures share the exact same sets of possible trajectories. What changes is the probability weight assigned to each path: trajectories with positive slope receive higher likelihood under measures that shift the drift upward.

6Problem set

Mechanics

M1 · Constant drift shift

Let \((B_t)_{t \ge 0}\) be a standard \(\Prob\)-Brownian motion. Define \(\theta = 2.0\) and horizon \(H = 3.0\). Write the explicit expression for the density process \(Z_H\), and compute \(\E^\Prob[Z_H]\) and \(\Var^\Prob(Z_H)\).

Solution

The stochastic exponential is \(Z_H = \exp(-\theta B_H - \tfrac{1}{2}\theta^2 H) = \exp(-2 B_3 - 6)\). Since \(\theta\) is constant, Novikov's condition holds trivially: \(\E[\exp(\tfrac{1}{2} \theta^2 H)] = \exp(6) < \infty\). Thus \(Z_t\) is a martingale and \(\E^\Prob[Z_H] = 1\). For the variance, \(Z_H^2 = \exp(-4 B_3 - 12)\). Since \(B_3 \sim \Normal(0, 3)\), \(\E[e^{-4 B_3}] = \exp(\tfrac{1}{2}(-4)^2 \cdot 3) = \exp(24)\). Therefore \(\E[Z_H^2] = e^{-12} e^{24} = e^{12}\), giving \(\Var(Z_H) = e^{12} - 1 \approx 162{,}754\).

M2 · Verification of Novikov's condition for bounded processes

Prove that if an adapted drift process \(\theta_t\) is uniformly bounded, \(|\theta_t| \le M < \infty\) for all \(t \in [0, H]\), then Novikov's condition is satisfied.

Solution

Because \(|\theta_t| \le M\) almost surely, \(\int_0^H \theta_s^2 ds \le \int_0^H M^2 ds = M^2 H\). Taking the exponential: \(\exp(\tfrac{1}{2}\int_0^H \theta_s^2 ds) \le \exp(\tfrac{1}{2} M^2 H)\). The expectation is bounded by the deterministic constant: \(\E^\Prob[\exp(\tfrac{1}{2}\int_0^H \theta_s^2 ds)] \le \exp(\tfrac{1}{2} M^2 H) < \infty\). Hence Novikov's condition holds, and \(Z_t\) is a true martingale.

M3 · Abstract Bayes formula calculation

Let \(Z_H = \exp(-\theta B_H - \tfrac{1}{2}\theta^2 H)\) with constant \(\theta\). Using the abstract Bayes formula, evaluate \(\E^\mathbb{Q}[B_H]\) directly by computing \(\E^\Prob[B_H Z_H]\).

Solution

By the abstract Bayes formula with \(s = 0\), \(\E^\mathbb{Q}[B_H] = \E^\Prob[B_H Z_H] / Z_0 = \E^\Prob[B_H Z_H]\). Since \(B_H \sim \Normal(0, H)\), let \(Z = B_H / \sqrt{H} \sim \Normal(0, 1)\). Then \(B_H Z_H = \sqrt{H} Z \exp(-\theta \sqrt{H} Z - \tfrac{1}{2}\theta^2 H)\). Completing the square in the Gaussian integral: \(\int_{-\infty}^\infty \sqrt{H} z e^{-\theta \sqrt{H} z - \frac{1}{2}\theta^2 H} \frac{e^{-z^2/2}}{\sqrt{2\pi}} dz = \sqrt{H} \int_{-\infty}^\infty z \frac{e^{-(z + \theta \sqrt{H})^2/2}}{\sqrt{2\pi}} dz\). Substituting \(u = z + \theta \sqrt{H}\), the integral becomes \(\sqrt{H} \int_{-\infty}^\infty (u - \theta \sqrt{H}) \frac{e^{-u^2/2}}{\sqrt{2\pi}} du = \sqrt{H}(0 - \theta \sqrt{H}) = -\theta H\). Since \(\widetilde{B}_H = B_H + \theta H\), this confirms \(\E^\mathbb{Q}[\widetilde{B}_H] = -\theta H + \theta H = 0\).

P1 · Product rule for Radon–Nikodym process

Let \(dZ_t = -\theta_t Z_t dB_t\) and let \(X_t\) be an Itô diffusion \(dX_t = \mu_t dt + \sigma_t dB_t\). Prove that \(Z_t X_t\) is a \(\Prob\)-local martingale if and only if \(\mu_t = \theta_t \sigma_t\).

Solution

Applying the Itô product rule: \(d(Z_t X_t) = Z_t dX_t + X_t dZ_t + d\langle Z, X \rangle_t\). Substituting the differentials: \(d\langle Z, X \rangle_t = (-\theta_t Z_t)(\sigma_t) dt = -\theta_t \sigma_t Z_t dt\). Thus \(d(Z_t X_t) = Z_t (\mu_t dt + \sigma_t dB_t) - X_t \theta_t Z_t dB_t - \theta_t \sigma_t Z_t dt = Z_t (\mu_t - \theta_t \sigma_t) dt + Z_t (\sigma_t - \theta_t X_t) dB_t\). The drift term vanishes for all \(t\) if and only if \(\mu_t - \theta_t \sigma_t = 0 \iff \mu_t = \theta_t \sigma_t\). When this holds, \(Z_t X_t\) is driftless, hence a \(\Prob\)-local martingale.

P2 · Invariance of quadratic variation under equivalent measure change

Prove that for any continuous semimartingale \(X_t\), its quadratic variation \([X, X]_t\) is identical under \(\Prob\) and under any equivalent measure \(\mathbb{Q} \sim \Prob\).

Solution

The quadratic variation \([X, X]_t\) is defined as the limit in probability of the sum of squared increments \(\sum_{k=0}^{n-1} (X_{t_{k+1}} - X_{t_k})^2\) as the partition mesh goes to zero. Convergence in probability under \(\Prob\) means that for every \(\epsilon > 0\), \(\lim_{n \to \infty} \Prob(|\sum (\Delta X_k)^2 - [X, X]_t| > \epsilon) = 0\). Because \(\mathbb{Q}\) is absolutely continuous with respect to \(\Prob\) (\(\mathbb{Q} \ll \Prob\)), for any sequence of events \(A_n\), \(\lim_{n \to \infty} \Prob(A_n) = 0 \implies \lim_{n \to \infty} \mathbb{Q}(A_n) = 0\). Therefore, the sum of squared increments converges in \(\mathbb{Q}\)-probability to the exact same limit \([X, X]_t\).

P3 · Inverse measure change

Let \(\mathbb{Q} \sim \Prob\) with density \(Z_H = d\mathbb{Q}/d\Prob\). Prove that the Radon–Nikodym derivative of \(\Prob\) with respect to \(\mathbb{Q}\) is \(d\Prob/d\mathbb{Q} = 1 / Z_H\), and determine the drift shift to return to \(\Prob\).

Solution

For any bounded measurable indicator \(\indic_A\), \(\E^\mathbb{Q}[\indic_A \cdot (1 / Z_H)] = \E^\Prob[\indic_A \cdot (1 / Z_H) \cdot Z_H] = \E^\Prob[\indic_A] = \Prob(A)\). Thus \(d\Prob/d\mathbb{Q} = 1 / Z_H\). By Itô's lemma on \(Y_t = 1 / Z_t\), \(dY_t = -Z_t^{-2} dZ_t + Z_t^{-3}(dZ_t)^2 = -Z_t^{-2}(-\theta_t Z_t dB_t) + Z_t^{-3}(\theta_t^2 Z_t^2 dt) = \theta_t Y_t dB_t + \theta_t^2 Y_t dt\). Expressing this in terms of the \(\mathbb{Q}\)-Brownian motion \(\widetilde{B}_t = B_t + \int_0^t \theta_s ds\), we have \(dB_t = d\widetilde{B}_t - \theta_t dt\), so \(dY_t = \theta_t Y_t (d\widetilde{B}_t - \theta_t dt) + \theta_t^2 Y_t dt = \theta_t Y_t d\widetilde{B}_t\). The drift shift to return from \(\mathbb{Q}\) to \(\Prob\) is \(-\theta_t\).

Empirical

E1 · Likelihood ratio variance explosion

Compute the coefficient of variation \(\sqrt{\Var(Z_H)} / \E[Z_H]\) of the density \(Z_H = \exp(-\theta B_H - \tfrac{1}{2}\theta^2 H)\) for \(\theta = 1.5\) and \(H = 4.0\). What does this imply for Monte Carlo importance sampling?

Solution

Here \(\E[Z_H] = 1\). From Problem M1, \(\Var(Z_H) = \exp(\theta^2 H) - 1\). With \(\theta = 1.5\) and \(H = 4.0\), \(\theta^2 H = (2.25)(4.0) = 9.0\). The variance is \(e^9 - 1 \approx 8{,}103 - 1 = 8{,}102\). The coefficient of variation is \(\sqrt{8102} \approx 90.01\). When \(\theta^2 H\) is large, the Radon–Nikodym weight has massive variance, meaning a naive change of measure across long horizons degrades Monte Carlo convergence unless guided by targeted importance sampling.

E2 · Shifted distribution skewness

Under \(\Prob\), \(B_H \sim \Normal(0, H)\) has skewness 0. What is the skewness of \(\widetilde{B}_H\) under \(\mathbb{Q}\)?

Solution

By Girsanov's theorem, \(\widetilde{B}_t\) is a standard Brownian motion under \(\mathbb{Q}\). At time \(H\), \(\widetilde{B}_H \sim \Normal(0, H)\) under \(\mathbb{Q}\). The normal distribution is symmetric about its mean, so all odd centered moments vanish: \(\E^\mathbb{Q}[(\widetilde{B}_H)^3] = 0\). The skewness is identically zero.

E3 · Discrete approximation of Girsanov weights

On a partition with \(N = 100\) steps and \(H = 1\), an analyst computes discrete weights \(Z_N = \prod_{k=0}^{N-1} \exp(-\theta \Delta B_k - \tfrac{1}{2}\theta^2 \Delta t)\). Compare \(Z_N\) with the continuous exponential \(\exp(-\theta B_H - \tfrac{1}{2}\theta^2 H)\).

Solution

Taking the product of exponentials: \(\prod_{k=0}^{N-1} \exp(-\theta \Delta B_k - \tfrac{1}{2}\theta^2 \Delta t) = \exp(-\theta \sum_k \Delta B_k - \tfrac{1}{2}\theta^2 \sum_k \Delta t) = \exp(-\theta B_H - \tfrac{1}{2}\theta^2 H)\). Because the sum of Brownian increments telescopes identically to \(B_H\) and \(\sum \Delta t = H\), the discrete product equals the continuous stochastic exponential exactly on every path with zero discretization error.

Research

R1 · Kazamaki's criterion

State Kazamaki's criterion for the martingality of stochastic exponentials and explain why it is strictly weaker than Novikov's condition.

Solution

Kazamaki's criterion states that \(Z_t = \mathcal{E}(M)_t\) is a uniformly integrable martingale if \(\sup_{t \in [0, H]} \E[\exp(\tfrac{1}{2} M_t)] < \infty\), where \(M_t = -\int_0^t \theta_s dB_s\). By Jensen's inequality and the supermartingale property of \(\exp(\tfrac{1}{2} M_t - \tfrac{1}{8}\langle M \rangle_t)\), \(\E[\exp(\tfrac{1}{2} M_t)] \le (\E[\exp(\tfrac{1}{2}\langle M \rangle_H)])^{1/2}\). Thus Novikov's condition implies Kazamaki's condition, but there exist processes (such as certain stopped diffusions) where Kazamaki's condition holds while Novikov's expectation is infinite.

R2 · Cameron–Martin theorem as deterministic Girsanov

Show that when \(\theta_t = h'(t)\) is a deterministic square-integrable function, Girsanov's theorem reduces to the classical Cameron–Martin theorem on Wiener space.

Solution

For deterministic \(h \in H^1([0, H])\) with \(h(0) = 0\), the shift is \(\widetilde{B}_t = B_t + h(t)\). The Radon–Nikodym derivative is \(\exp(-\int_0^H h'(s) dB_s - \tfrac{1}{2}\int_0^H |h'(s)|^2 ds)\). The Cameron–Martin theorem establishes that Wiener measure is quasi-invariant under translation by paths in the Cameron–Martin reproducing kernel Hilbert space \(H^1\), and the Radon–Nikodym derivative matches the Girsanov formula identically.

R3 · Multidimensional Girsanov theorem

Formulate Girsanov's theorem for a \(d\)-dimensional standard Brownian motion \(\mathbf{B}_t \in \R^d\) under an adapted drift shift vector \(\boldsymbol{\theta}_t \in \R^d\).

Solution

Let \(\mathbf{B}_t = (B_{1, t}, \dots, B_{d, t})^\top\) be a standard \(d\)-dimensional Brownian motion with independent components. Define \(Z_t = \exp(-\int_0^t \boldsymbol{\theta}_s^\top d\mathbf{B}_s - \tfrac{1}{2}\int_0^t \|\boldsymbol{\theta}_s\|^2 ds)\). If \(\E^\Prob[\exp(\tfrac{1}{2}\int_0^H \|\boldsymbol{\theta}_s\|^2 ds)] < \infty\), then \(\widetilde{\mathbf{B}}_t = \mathbf{B}_t + \int_0^t \boldsymbol{\theta}_s ds\) is a standard \(d\)-dimensional Brownian motion under \(\mathbb{Q}\), having independent components each with quadratic variation \(t\).

8Retrieval quiz

  1. What does Girsanov's theorem alter when transforming to an equivalent probability measure?

    Options

  2. What is the expectation \(\E^\Prob[Z_H]\) of the Radon–Nikodym density process under Novikov's condition?

  3. Which mathematical condition guarantees that the stochastic exponential \(\mathcal{E}(-\theta \cdot B)_t\) is a true martingale?

    Options

  4. If \(\widetilde{B}_t = B_t + \int_0^t \theta_s ds\) is a Brownian motion under \(\mathbb{Q}\), what is \(\E^\mathbb{Q}[\widetilde{B}_H]\)?

    Standard Brownian motion under \(\mathbb{Q}\) starts at zero and has zero expectation.

  5. Why can an equivalent change of measure never change the volatility of an asset price process?

    Options

    Different quadratic variations distinguish measures pathwise with probability 1, making them singular rather than equivalent.

  6. In the abstract Bayes formula \(\E^\mathbb{Q}[X \mid \mathcal{F}_s] = \E^\Prob[X Z_t \mid \mathcal{F}_s] / Z_s\), what role does \(Z_s\) play?

    Options

  7. What is the initial value \(Z_0\) of the Radon–Nikodym density process \((Z_t)_{t \ge 0}\)?

    \(Z_0 = \E^\Prob[Z_H \mid \mathcal{F}_0] = \E^\Prob[Z_H] = 1\).

  8. If an adapted process \(\theta_t\) is uniformly bounded by \(M\), is Novikov's condition satisfied on any finite horizon \([0, H]\)?
