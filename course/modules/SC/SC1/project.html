Reflection principle verified

A Brownian path that reaches a level and then returns has a mirror image after its first visit, and the mirror turns a question about the running maximum (the largest value the path has reached so far) into a question about the endpoint. You will prove the reflection principle, the closed form of the running-maximum law and the first-passage identity of Lesson 8. You will then write bm_checks.py, which checks each result on generated instances, and you will study how a grid maximum, the largest value a path takes on a finite set of times, differs from the continuous one. The proofs are graded by rubric. The engine is graded by an autograder on your own seeded instance.

Lab 1 · Worked example: the reflection tail for one instance, checked three ways (SIMULATED)

The instance is the seed-0 instance, with horizon \(H\) and level \(a\) as printed. The closed form is \(\operatorname{erfc}(a/\sqrt{2H})\), which equals \(\Prob(M_H \ge a)\) by the reflection principle and P2 of the statements section. Expected, stated before running: the closed form and a Simpson's rule value of \(2\,\Prob(B_H \ge a)\) agree to within \(10^{-8}\); and the one-step estimate of \(\Prob(B_H \ge a)\), taken on the instance's \(N\) seeded draws (\(N\) is the path count), lies within five standard errors plus one path of \(\tfrac12\) the closed form. With one grid step the grid maximum is \(B_H\) itself, so the target is half the tail.

"""Rung 1 worked example: the reflection tail for the seed-0 instance, checked three ways. SIMULATED.

The instance is the one the project's generator gives seed 0. This file draws the same four numbers in the same order,
so the two agree. The reflection principle gives P(M_t >= a) = 2 P(B_t >= a) for a standard Brownian motion M, so the
tail at level a and horizon H equals erfc(a / sqrt(2 H)). The lab prints that closed form, a Simpson's rule value of
2 P(B_H >= a) from the normal density with mean 0 and variance H, and a seeded simulation estimate of P(B_H >= a) on
N paths. With one grid step the grid maximum is B_H itself, so the estimate tests the half of the tail that needs no
grid. Every computed number is rounded to six decimal places by Python's own formatting, from the unrounded value,
except the Simpson difference, which is printed in exponent form to three significant digits. The horizon H and the
level a are printed as generated, to three decimals, and N is an integer. Standard library only.
"""

from __future__ import annotations

import math
import random
from dataclasses import dataclass


@dataclass(frozen=True)
class Instance:
    """One generated instance: the seed, the horizon H in time units, the level a, the grid size and the path count."""

    seed: int
    horizon: float
    level: float
    n_steps: int
    n_paths: int


def make_instance(seed: int) -> Instance:
    """The project's instance for a seed, drawn in the fixed order: horizon, level, grid size, path count."""
    rng = random.Random(1_000_003 * seed + 54_321)
    horizon = round(rng.uniform(0.25, 4.0), 3)
    level = round(rng.uniform(0.25, 2.5), 3)
    n_steps = rng.randint(4, 256)
    n_paths = rng.randint(400, min(800, 200_000 // n_steps))
    return Instance(seed, horizon, level, n_steps, n_paths)


def reflection_tail(level: float, horizon: float) -> float:
    """P(M_H >= level) = erfc(level / sqrt(2 H)), for level > 0 and horizon > 0."""
    return math.erfc(level / math.sqrt(2.0 * horizon))


def gaussian_tail_simpson(level: float, horizon: float, intervals: int = 4000) -> float:
    """2 P(B_H >= level) by Simpson's rule on the N(0, H) density over [level, level + 12 sqrt(H)]."""
    top = level + 12.0 * math.sqrt(horizon)
    step = (top - level) / intervals

    def density(x: float) -> float:
        return math.exp(-x * x / (2.0 * horizon)) / math.sqrt(2.0 * math.pi * horizon)

    total = density(level) + density(top)
    for k in range(1, intervals):
        weight = 4.0 if k % 2 else 2.0
        total += weight * density(level + k * step)
    return 2.0 * total * step / 3.0


def one_step_estimate(inst: Instance) -> tuple[float, float]:
    """The fraction of the N seeded draws of B_H that reach the level, and its standard error with divisor N - 1."""
    rng = random.Random(inst.seed)
    sd = math.sqrt(inst.horizon)
    indicators: list[float] = []
    for _ in range(inst.n_paths):
        value = rng.gauss(0.0, sd)
        indicators.append(1.0 if value >= inst.level else 0.0)
    count = len(indicators)
    mean = sum(indicators) / count
    variance = sum((x - mean) ** 2 for x in indicators) / (count - 1)
    return mean, math.sqrt(variance) / math.sqrt(count)


def main() -> None:
    """Print the instance, the closed form, the quadrature, and the one-step estimate with its band."""
    inst = make_instance(0)
    tail = reflection_tail(inst.level, inst.horizon)
    quad = gaussian_tail_simpson(inst.level, inst.horizon)
    estimate, se = one_step_estimate(inst)
    target = tail / 2.0
    band = 5.0 * se + 1.0 / inst.n_paths
    print(f"seed {inst.seed} instance: label SIMULATED, H = {inst.horizon}, a = {inst.level}, N = {inst.n_paths}")
    print(f"closed form erfc(a / sqrt(2 H)) = {tail:.6f}")
    print(f"quadrature 2 P(B_H >= a) = {quad:.6f}, absolute difference from the closed form {abs(quad - tail):.2e}")
    print(f"one step: estimate of P(B_H >= a) = {estimate:.6f}, standard error {se:.6f}")
    print(f"target tail / 2 = {target:.6f}, band 5 se + 1/N = {band:.6f}, difference {abs(estimate - target):.6f}")
    print(f"inside the band: {abs(estimate - target) <= band}")

Lab 2 · Completion problem: the reflection identity for the simple random walk

A walk takes \(n\) steps of \(+1\) or \(-1\), and the \(2^n\) walks are equally likely. For \(a \ge 1\), the number of walks whose maximum reaches \(a\) equals the number ending at \(a\) or above, plus the number ending at \(a+1\) or above. Replace each ___ with the expression the identity requires: the first blank is the sum of the two endpoint counts, and the second is the identity, so that the comparison tests the maximum count against it. Expected, once both lines are right: for \(n = 6\) and \(a = 2\), 29 walks reach 2, 22 end at 2 or above, 7 end at 3 or above, and the identity holds.

"""Rung 2 completion problem: the reflection identity for the simple random walk, by exact enumeration.

A walk takes n steps of +1 or -1, each with probability 1/2 and each of the 2**n walks equally likely. For a >= 1, the
number of walks whose maximum reaches a equals the number of walks ending at a or above, plus the number ending at a + 1
or above. Reflecting each walk after its first visit to a gives this identity. The lab counts all three quantities over
every walk and prints exact integers. It draws no random numbers, so every run prints the same lines.
"""

from __future__ import annotations

import itertools


def count_by_enumeration(n: int, a: int) -> tuple[int, int]:
    """Over all 2**n walks of n steps: (the number whose maximum is at least a, the number ending at least a)."""
    max_hits = 0
    end_hits = 0
    for steps in itertools.product((1, -1), repeat=n):
        sums = list(itertools.accumulate(steps))
        if max(sums) >= a:
            max_hits += 1
        if sums[-1] >= a:
            end_hits += 1
    return max_hits, end_hits


def main() -> None:
    """Count the walks for n = 6 and a = 2, and compare the maximum count with the identity."""
    n = 6
    a = 2

    end_above = count_by_enumeration(n, a + 1)[1]
    identity = ___
    print(f"n = {n}, a = {a}: walks with maximum >= a: {max_hits}")
    print(f"walks ending at >= a: {end_hits}, walks ending at >= a + 1: {end_above}")
    print("reflection identity holds:", max_hits == ___)

The first blank completes the identity: the walks whose maximum reaches \(a\) are the walks ending at \(a\) or above, together with the walks ending at \(a+1\) or above, so the identity line is end_hits + end_above. Rung 3 · Specification

Context
A quant research engineer must show that the running maximum of a Brownian path and its first-passage time follow the reflection principle, and that a simulated grid maximum understates the continuous one by an amount you can measure. You prove the three results, and you write the engine that checks each one on generated instances, so that a claim about a model can be tested against exact numbers and a stated tolerance.
Inputs
No data file. Each instance comes from grader/instance.py, seeded from your workspace ID as the autograder panel shows, and carries the horizon H, the level a, the grid size n_steps, the path count n_paths, the seed and the label SIMULATED. Every instance is generated, not measured, and no value is a price or an observed series. The report uses the instance of seed 0. Lab 3 prints the reference values of that instance.
Required outputs
In a repository of your own: bm_checks.py at its root, with the five functions below. Start from the starter file, whose signatures are complete. The functions are reflection_tail(a: float, t: float) -> float, discrete_max_exceedance(instance: dict, n_steps: int) -> tuple[float, float], nested_grid_counts(instance: dict, n_fine: int, n_coarse: int) -> tuple[int, int], srw_max_count(n: int, a: int) -> int and srw_terminal_count(n: int, a: int) -> int. Also commit proofs.html, a typeset file of your three proofs in the form of the statements below; report/run_report.py, which prints the report's numbers for seed 0 in the same lines as Lab 3; and report/self_assessment.md, the summary that the form in the self-assessment section produces.
Constraints
Standard library only (math, fractions, itertools, random). No function prints or warns. Every simulated probability in the report is a float with its standard error; every closed-form probability is a float; every count is an exact integer. Each printed decimal is computed from the unrounded value and rounded once, to six decimal places, by Python's own formatting, except two kinds of printed value: the horizon and the level, which are printed as generated (three decimals), and a difference between two computed values, which may be given in exponent form to three significant digits. Listing the \(2^n\) walks takes time that doubles with each step, so for n = 41 the counts must come from the reflection identity or from a recurrence over the walk's position and running maximum. The conditions that raise ValueError are the ones in the conventions. Any other invalid input may raise any exception or return a value, and the tests do not check which.
Grading mode
Both the autograder and the rubric apply. The engine is autograded by grader/test_project.py, which runs 128 tests with warnings as errors on your own instance. The same file runs in your browser and on your machine, and it is not secret: its integrity comes from the seeded instance and from a second instance, which a fixed answer for the first would also have to match. The proofs and the report are graded by the rubric, against the five criteria of the rubric, each with four observable levels. You score your own work with the form in the self-assessment section and calibrate on two annotated exemplars.

Conventions

  • \(B\) is a standard Brownian motion, \(M_t = \max_{0 \le s \le t} B_s\) is its running maximum, and \(\tau_a = \inf\{t \ge 0 : B_t = a\}\) is the first-passage time of the level \(a > 0\). The horizon is \(H\), because the symbol \(T\) has another meaning in this course. \(\Phi\) is the standard normal distribution function, and \(\operatorname{erfc}\) is the complementary error function.
  • The grid for \(n\) steps is \(t_k = kH/n\) for \(k = 1, \ldots, n\). The grid maximum is \(\max_{k \le n} B_{t_k}\). Because every grid point lies in \([0,H]\), the grid maximum never exceeds \(M_H\) on the same path, so the grid maximum is a lower bound for the continuous one, pathwise.
  • discrete_max_exceedance(instance, n_steps) draws its increments with random.Random(instance["seed"]) and gauss(0.0, sqrt(H / n_steps)), path by path and step by step, for instance["n_paths"] paths. It returns the fraction of paths whose grid maximum is at least a, and its standard error: the sample standard deviation of the \(N\) indicators, with divisor \(N-1\), divided by \(\sqrt{N}\). For 0/1 indicators with mean \(\hat p\), this equals \(\sqrt{\hat p(1-\hat p)/(N-1)}\). This draw order is the one Lab 3 uses. An implementation that draws in another order is correct if it passes the tests, but its numbers will not match Lab 3's.
  • nested_grid_counts(instance, n_fine, n_coarse) draws the \(n_{\text{fine}}\)-step paths in the same order, and returns the number of paths whose fine grid maximum is at least a and the number whose coarse maximum is. The coarse grid is every \(n_{\text{fine}}/n_{\text{coarse}}\)-th point of the fine grid, on the same paths. The coarse count is never larger than the fine count.
  • reflection_tail(a, t) is \(\Prob(M_t \ge a) = \operatorname{erfc}(a/\sqrt{2t})\), for \(a > 0\) and \(t > 0\). It equals \(2\,\Prob(B_t \ge a)\), by P1 and P2. Its value must agree with \(\operatorname{erfc}(a/\sqrt{2t})\) to within \(10^{-10}\) in absolute value.
  • The discretization bias at level \(a\), horizon \(H\) and a grid of \(n\) steps is \(\Prob(M_H \ge a) - \Prob(\max_{k \le n} B_{t_k} \ge a)\), the continuous tail minus the probability that the grid maximum reaches the level. The probability is never negative, because the grid maximum never exceeds \(M_H\) on the same path. Its estimate, the continuous tail minus the grid estimate from discrete_max_exceedance, can be negative through sampling noise, as Lab 3 shows at 64 steps.
  • srw_max_count(n, a) is the number of the \(2^n\) walks of \(n\) steps whose maximum is at least \(a\). srw_terminal_count(n, a) is the number whose final value is at least \(a\). Both are exact integers, for \(a \ge 1\) and \(n \ge 1\).
  • Each of the following raises ValueError, and no other invalid input is specified: a level \(a \le 0\) or a time \(t \le 0\) in reflection_tail; n_steps < 1 or instance["n_paths"] < 2 in discrete_max_exceedance; n_fine < 1, n_coarse < 1 or n_coarse not dividing n_fine in nested_grid_counts; n < 1 or a < 1 in both count functions.
  • Every instance is SIMULATED. Seeded simulation estimates are compared with a tolerance of five standard errors plus one path, 5 se + 1/N. The extra \(1/N\) keeps a target near zero from failing on a sample with no hits.

The three results to prove

Each proof states its numbered assumptions, which are the lemma and the facts used. Assumption A0 is the definition of standard Brownian motion (Definition 1.1 of Lesson 1), with continuous paths as in Lesson 2. A3 and A4 are Assumptions 3 and 4 of Lesson 5. A3 is the strong Markov property for a bounded stopping time, and A4 gives the standard facts, including that the first hitting time of a closed set is a stopping time.

P1 · Reflection principle.

  1. A0: \(B\) is a standard Brownian motion with \(B_0 = 0\) and continuous paths.
  2. A3 and A4 of Lesson 5, for the bounded stopping time \(\rho = \tau_a \wedge t\) and for the first hitting time \(\tau_a\).
  3. \(a > 0\) and \(t > 0\) are fixed.

Then \(\Prob(M_t \ge a) = 2\,\Prob(B_t > a) = 2\,\Prob(B_t \ge a)\).

P2 · Closed form of the running-maximum law.

  1. The assumptions of P1.
  2. \(B_t\) has the normal distribution \(\Normal(0,t)\), by the definition of Brownian motion in Lesson 1.

Then \(\Prob(M_t \ge a) = \operatorname{erfc}(a/\sqrt{2t})\), and this equals \(2\,(1 - \Phi(a/\sqrt{t}))\).

P3 · First passage.

  1. A0 with continuous paths, so that a path which is above \(B_0 = 0\) at some time has reached every level between them before that time.
  2. The assumptions of P2, for the second part.

Then, for every \(t \ge 0\), \(\Prob(\tau_a \le t) = \Prob(M_t \ge a)\), and \(\Prob(\tau_a < \infty) = 1\).

The proofs are in your own words in proofs.html. The proofs in Lessons 5 to 8 are the reference for the steps. A proof that names a lemma must say which assumption it uses, and a step that uses an assumption not listed above must name it.

"""Rung 3 reference numbers: the values the report quotes for the seed-0 instance. SIMULATED.

The instance is the one the project's generator gives seed 0, drawn in the same fixed order. For a grid of n steps
the lab draws N paths, each a sum of n Gaussian increments with mean 0 and variance H / n, taken path by path and
step by step from random.Random(seed). The estimate is the fraction of paths whose grid maximum reaches the level a,
and its standard error is the sample standard deviation of the 0/1 indicators (divisor N - 1) divided by sqrt(N). The
coarse grids in the nested check are every (256 / n)-th point of the same 256-step paths, so each coarse maximum is at
most the fine one. The continuous tail erfc(a / sqrt(2 H)) is the reflection principle's value for the continuous
maximum on [0, H]. Every computed decimal is rounded to six decimal places by Python's own formatting, from the
unrounded value. The horizon H and the level a are printed as generated, to three decimals, and N and the hit counts
are integers. The walk line is an exact count. Standard library only.
"""

from __future__ import annotations

import itertools
import math
import random
from dataclasses import dataclass


@dataclass(frozen=True)
class Instance:
    """One generated instance: the seed, the horizon H in time units, the level a, the grid size and the path count."""

    seed: int
    horizon: float
    level: float
    n_steps: int
    n_paths: int


def make_instance(seed: int) -> Instance:
    """The project's instance for a seed, drawn in the fixed order: horizon, level, grid size, path count."""
    rng = random.Random(1_000_003 * seed + 54_321)
    horizon = round(rng.uniform(0.25, 4.0), 3)
    level = round(rng.uniform(0.25, 2.5), 3)
    n_steps = rng.randint(4, 256)
    n_paths = rng.randint(400, min(800, 200_000 // n_steps))
    return Instance(seed, horizon, level, n_steps, n_paths)


def reflection_tail(level: float, horizon: float) -> float:
    """P(M_H >= level) = erfc(level / sqrt(2 H)), for level > 0 and horizon > 0."""
    return math.erfc(level / math.sqrt(2.0 * horizon))


def path_maxima(inst: Instance, n_fine: int, strides: tuple[int, ...]) -> dict[int, list[float]]:
    """For each stride s, the maximum over the grid points at every s-th step, one value per path.

    The paths are drawn with n_fine steps, so stride 1 is the fine grid. A stride s gives the grid with n_fine / s steps
    on the same paths.
    """
    rng = random.Random(inst.seed)
    sd = math.sqrt(inst.horizon / n_fine)
    maxima: dict[int, list[float]] = {s: [] for s in strides}
    for _ in range(inst.n_paths):
        position = 0.0
        best = dict.fromkeys(strides, -math.inf)
        for k in range(1, n_fine + 1):
            position += rng.gauss(0.0, sd)
            for s in strides:
                if k % s == 0 and position > best[s]:
                    best[s] = position
        for s in strides:
            maxima[s].append(best[s])
    return maxima


def estimate_and_se(hits: int, n: int) -> tuple[float, float]:
    """The fraction hits / n, and its standard error: the sample standard deviation of the indicators over sqrt(n)."""
    mean = hits / n
    variance = n * mean * (1.0 - mean) / (n - 1)
    return mean, math.sqrt(variance) / math.sqrt(n)


def walk_counts(n: int, a: int) -> tuple[int, int]:
    """Over all 2**n walks: (the number whose maximum is at least a, the number ending at least a)."""
    max_hits = 0
    end_hits = 0
    for steps in itertools.product((1, -1), repeat=n):
        sums = list(itertools.accumulate(steps))
        if max(sums) >= a:
            max_hits += 1
        if sums[-1] >= a:
            end_hits += 1
    return max_hits, end_hits


def main() -> None:
    """Print the continuous tail, the estimate and standard error for each grid, the nested counts and a walk count."""
    inst = make_instance(0)
    tail = reflection_tail(inst.level, inst.horizon)
    print(f"seed 0: H = {inst.horizon}, a = {inst.level}, N = {inst.n_paths}, continuous tail = {tail:.6f}")
    for n in (1, 4, 16, 64, 256):
        hits = sum(1 for m in path_maxima(inst, n, (1,))[1] if m >= inst.level)
        p, se = estimate_and_se(hits, inst.n_paths)
        print(
            f"grid n = {n}: hits {hits}, estimate {p:.6f}, standard error {se:.6f}, tail minus estimate {tail - p:.6f}"
        )
    strides = (1, 4, 16, 64, 256)

P1. Let \(\tau = \tau_a\), and let \(\rho\) be \(\tau\) cut off at \(t\). The paths are continuous, so \(\{\tau \le t\}\) is the event that the path has reached \(a\) by time \(t\). By symmetry, the restarted path is as likely to be above \(a\) as below, so \(\Prob(\tau \le t, B_t > a) = \tfrac12 \Prob(\tau \le t)\). Adding the paths that end at or above \(a\) gives \(\Prob(M_t \ge a) = 2\,\Prob(B_t \ge a)\).

Appendix · Proofs

Assumptions for P1.

  1. A0: \(B\) is a standard Brownian motion with \(B_0 = 0\) and continuous paths.
  2. A3 and A4 of Lesson 5, for the bounded stopping time \(\rho = \tau \wedge t\) and the first hitting time \(\tau\).
  3. \(a > 0\) and \(t > 0\) are fixed.

P1. Let \(\tau = \tau_a\), and let \(\rho = \tau \wedge t\). By A4(c), \(\tau\) is a stopping time, so \(\rho\) is a bounded stopping time with \(\rho \le t\). Let \(A = \{\tau \le t\}\). If \(\tau \le t\), then \(B_\tau = a\) by continuity, so \(M_t \ge a\). If \(M_t \ge a\), the maximum is attained at some \(s \le t\), and the intermediate value theorem gives a time in \([0,s]\) at which \(B = a\), so \(\tau \le t\). Hence \(A = \{M_t \ge a\}\). Also \(\Prob(\tau = t) \le \Prob(B_t = a) = 0\), because \(B_t\) is normal with variance \(t > 0\). Let \(\tilde B_r = B_{\rho + r} - B_\rho\). By A3, \(\tilde B\) is a standard Brownian motion independent of \(\mathcal F_\rho\). On \(A\), \(B_\rho = a\), so \(B_t - a = \tilde B_{t - \rho}\). Here \(A\) and \(t - \rho\) are \(\mathcal F_\rho\)-measurable. Applying A4(b) to the indicator functions of \(\{y > 0\}\) and of \(\{y < 0\}\), evaluated at \(y = \tilde B_{t-\rho}\), with \(t - \rho\) and \(A\) in the role of \(Z\), and using \(\Prob(\tilde B_u > 0) = \Prob(\tilde B_u < 0) = \tfrac12\) for \(u > 0\), gives \(\Prob(A, B_t < a) = \tfrac12\,\Prob(A, \rho < t) = \tfrac12\,\Prob(A)\). Also \(\{B_t \ge a\} \subseteq A\), so \(\Prob(A) = \Prob(B_t \ge a) + \Prob(A, B_t < a) = \Prob(B_t \ge a) + \tfrac12\,\Prob(A)\). Therefore \(\Prob(M_t \ge a) = \Prob(A) = 2\,\Prob(B_t \ge a)\). Since \(\Prob(B_t = a) = 0\), this equals \(2\,\Prob(B_t > a)\).

Assumptions for P2.

  1. The assumptions of P1.
  2. \(B_t \sim \Normal(0,t)\), by the definition of Brownian motion in Lesson 1 (Definition 1.1: \(B_0 = 0\), and each increment is normal with variance equal to its length).

P2. By P1 and \(B_t \sim \Normal(0,t)\), \(\Prob(B_t \ge a) = 1 - \Phi(a/\sqrt{t})\), so \(\Prob(M_t \ge a) = 2(1 - \Phi(a/\sqrt{t}))\). For the erfc form, substitute \(w = z/\sqrt{2}\) in \(\operatorname{erfc}(x) = \tfrac{2}{\sqrt\pi}\int_x^\infty e^{-w^2}\,dw\): this gives \(\operatorname{erfc}(x) = \tfrac{2}{\sqrt{2\pi}}\int_{x\sqrt2}^\infty e^{-z^2/2}\,dz = 2(1 - \Phi(x\sqrt{2}))\). With \(x = a/\sqrt{2t}\), \(x\sqrt{2} = a/\sqrt{t}\), so \(\operatorname{erfc}(a/\sqrt{2t}) = 2(1 - \Phi(a/\sqrt{t}))\).

Assumptions for P3.

  1. A0 with continuous paths, for the equality of the events.
  2. The assumptions of P2, for the second part.

P3. The equality \(\{\tau_a \le t\} = \{M_t \ge a\}\) for every \(t \ge 0\) is the first part of the P1 argument, and it uses only continuity. For the second part, \(\{\tau_a < \infty\} = \bigcup_{n} \{\tau_a \le n\}\), an increasing union. By continuity of probability from below and P2, \(\Prob(\tau_a < \infty) = \lim_n \Prob(M_n \ge a) = \lim_n \operatorname{erfc}(a/\sqrt{2n}) = \operatorname{erfc}(0) = 1\).

  • Meets C1 level 4: lists A0, A3 and A4 before each result, and ties A3 to the bounded time \(\rho \le t\) and the step that uses it.
  • Meets C2 level 4: names A4(b) for the freezing step, A4(c) for the stopping-time property, and continuity for the identity of the events; the restart uses A3 and no step is skipped.
