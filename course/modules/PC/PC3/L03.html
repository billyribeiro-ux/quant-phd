Expected-Value Games

  • Uses: the expectation of a random variable and its linearity (M4), and the conditional probability of Lesson 2 (Section 3 uses the fact that each turn's conditional payoff is defined given the earlier payoffs)
  • Introduces: expected-value game, defined in Section 2
  • Ttheorem, proved on the page
  • Areplicated
  • Bpublished, not settled
  • Csingle study or lab result
  • Dlore
  • Xrefuted

A game whose payoff depends on chance has an average payoff, weighted by the probability of each outcome. This lesson measures what a player gains by choosing when to stop. It proves that the average of a sum of payoffs is the sum of their averages. It then proves, over a finite number of turns, that no rule for stopping that sees only the results so far (this lesson, Definition 3.7) changes the average total of a game whose average payoff is zero on every turn, given the results before it (Definition 3.5). A reroll game, solved backwards from the last choice, shows the same tools give a precise answer where that zero condition fails. All payoffs are integer cents.

1Expected payoffs and linearity

Assumption A1 (finite space, integer cents)

The outcome set \(\Omega\) is a finite probability space, as defined in M4 Lesson 1, with weights \(p(\omega) > 0\) that sum to 1. Every payoff is an integer number of cents. No result below covers an infinite outcome set.

Definition 3.1 (expected payoff)

For a payoff \(X\) on \(\Omega\), with integer values in cents, the expected payoff is \(\E[X] = \sum_{\omega \in \Omega} X(\omega)\,p(\omega)\). It is the expectation of M4 on a finite space.

Proposition 3.2 (linearity over finite sums)
  1. (H1) Assuming A1, \(X_1, \dots, X_m\) are payoffs on the same \(\Omega\).

Conclusion: \(\E[X_1 + \cdots + X_m] = \E[X_1] + \cdots + \E[X_m]\).

Proof

Fix \(\omega\). Then \((X_1 + \cdots + X_m)(\omega)\,p(\omega) = \sum_{i} X_i(\omega)\,p(\omega)\), by the distributive law of the reals. Summing over the finite set \(\Omega\) and exchanging the two finite sums gives \(\E[X_1 + \cdots + X_m] = \sum_i \sum_\omega X_i(\omega)\,p(\omega) = \sum_i \E[X_i]\). \(\blacksquare\)

Example 3.3 (a die and two dice)

For one fair die with faces \(1\) to \(6\), \(\E[\text{face}] = (1 + 2 + \cdots + 6)/6 = 21/6 = 7/2\). A game that pays \(100\) cents times the face has expected payoff \(100 \cdot 7/2 = 350\) cents. For two independent dice \(X\) and \(Y\), Proposition 3.2 gives \(\E[X + Y] = \E[X] + \E[Y] = 7\). Lab 1, Part 1 computes \(\E[X + Y]\) by enumerating all 36 outcomes and prints 7, and the same value for \(\E[X] + \E[Y]\).

2Expected-value games and fairness

Definition 3.4 (expected-value game)

An expected-value game is a finite game with integer payoffs in cents, a finite outcome set with weights, and a stated rule for when play stops. Its value under a rule is the expected payoff of Definition 3.1 when the rule is followed.

Definition 3.5 (fair game)

A one-turn game is fair when its expected payoff is zero. A multi-turn game is fair when, for every history (the list of earlier payoffs) of fewer than the game's number of turns that has positive probability, the expected payoff of the next turn given that history is zero. Each turn's expected payoff is taken in the conditional sense of Lesson 2, Definition 2.2.

Assumption A2 (the game in Section 3)

The fair game of Section 3 pays \(+100\) or \(-100\) cents on each turn, each with probability \(1/2\), and the turns are independent. Given any history of positive probability, the next turn's expected payoff is therefore \(100 \cdot \tfrac12 - 100 \cdot \tfrac12 = 0\), so the game is fair in the sense of Definition 3.5.

Example 3.6 (a reroll game, by backward induction)

Roll a fair die. Then choose one of two options. Stop pays \(100\) cents times the face. Reroll costs \(100\) cents, and it rolls the die once more and pays \(100\) cents times that face, with no further choice. The reroll option, whose value is called the continuation value, is worth \(\E[100 g] - 100 = 350 - 100 = 250\) cents, where \(g\) is the second face. Backward induction compares the two options at the first roll. For face \(f\), stopping pays \(100f\) cents, and rerolling is worth 250 cents, so the better option is to stop on faces 3 to 6 and to reroll on faces 1 and 2. The value of the game is

\[ \frac{250 + 250 + 300 + 400 + 500 + 600}{6} = \frac{2300}{6} = \frac{1150}{3} \text{ cents}, \]

which is 383.33 cents to two places. Stopping on every face gives 350 cents, so the choice adds \(1150/3 - 350 = 100/3\) cents, which is 33.33 cents to two places. Lab 1, Part 2 checks the value by enumerating all 64 policies, one stop-or-reroll choice for each of the six first faces, and the best of them is \(1150/3\).

Definition 3.7 (stopping rule on a finite horizon)

Let the game have a horizon \(N \ge 1\) turns. For every history \(h = (x_1, \dots, x_t)\) of payoffs after turn \(t \le N\), let \(W(h) = x_1 + \cdots + x_t\) be its total. A stopping rule assigns to each history either stop or continue, using only \(h\), and it stops at every history of length \(N\). The total paid under the rule is \(W(h)\) at the history \(h\) at which the rule stops.

Lab 1 · Linearity, the reroll game and rules for when to stop, in integer cents

The lab computes every expectation by enumeration with fractions. Part 1 prints \(\E[X + Y] = 7\) for two dice and checks it against \(\E[X] + \E[Y]\). Part 2 prints the continuation value 250 cents, the best action on each face, the backward-induction value \(1150/3\) cents, the best of all 64 policies, and the stop-on-every-face value 350 cents. Part 3 applies five rules for when to stop to a fair game over six turns, by two methods: recursion on the history, and listing all 64 sequences. It prints the expectation of each rule under both methods, and checks that they agree and that all five are zero. Part 3b applies the same five rules to a biased game that pays \(+150\) or \(-100\) cents with probability \(1/2\) each.

"""PC3 lab L03: expectation by enumeration, a stopping rule on a fair game, and a reroll game in integer cents.

Standard library only. No randomness and no network. Every expectation is a fractions.Fraction computed by
enumerating the finite outcome set, so each printed value is exact. Money is integer cents throughout; a
Fraction of cents is printed as a fraction and, once, as a decimal to two places for display.

Part 1 checks linearity of expectation for two dice. Part 2 solves a one-roll game with a paid reroll in two
ways: by backward induction over the two options, and by enumerating every stopping policy. Part 3 applies
stopping rules to a fair game over a finite horizon, by two methods that must agree. Part 3b applies the same
rules to a biased game, by the recursion alone.
"""

from __future__ import annotations

from collections.abc import Callable
from fractions import Fraction
from itertools import product

HORIZON = 6
FAIR_GAME: tuple[tuple[int, Fraction], ...] = ((100, Fraction(1, 2)), (-100, Fraction(1, 2)))
BIASED_GAME: tuple[tuple[int, Fraction], ...] = ((150, Fraction(1, 2)), (-100, Fraction(1, 2)))
REROLL_FEE = 100
FACE_VALUE_CENTS = 100

Rule = Callable[[tuple[int, ...]], bool]


def part_one() -> None:
    print("Part 1 · linearity of expectation for two fair dice")
    faces = range(1, 7)
    pairs = [(x, y) for x, y in product(faces, faces)]
    e_sum = Fraction(sum(x + y for x, y in pairs), len(pairs))
    e_x = Fraction(sum(x for x, _ in pairs), len(pairs))
    e_y = Fraction(sum(y for _, y in pairs), len(pairs))
    print(f"E[X + Y] by enumeration over 36 outcomes = {e_sum}")
    print(f"E[X] + E[Y] = {e_x + e_y}")
    print(f"the two agree: {e_sum == e_x + e_y}")


def reroll_continuation() -> Fraction:
    """Value in cents of paying the fee and rolling once more, then stopping: E[100 g] - 100."""
    expected_second = Fraction(sum(FACE_VALUE_CENTS * g for g in range(1, 7)), 6)
    return expected_second - REROLL_FEE


def backward_induction() -> tuple[Fraction, dict[int, str]]:
    """The first-roll value, and the best action for each face, from the two options at that node."""
    continuation = reroll_continuation()
    actions: dict[int, str] = {}
    total = Fraction(0)
    for face in range(1, 7):
        stop = Fraction(FACE_VALUE_CENTS * face)
        best = max(stop, continuation)
        actions[face] = "stop" if stop >= continuation else "reroll"
        total += best
    return total / 6, actions


def policy_value(stop_on_face: dict[int, bool]) -> Fraction:
    """Expected payoff in cents of a policy that stops or rerolls as a function of the first face."""
    continuation = reroll_continuation()
    total = Fraction(0)
    for face in range(1, 7):
        total += Fraction(FACE_VALUE_CENTS * face) if stop_on_face[face] else continuation
    return total / 6


def part_two() -> None:
    print("Part 2 · one roll, a paid reroll of 100 cents, payoff 100 cents per face")
    print(f"continuation value after paying the fee: {reroll_continuation()} cents")
    value, actions = backward_induction()
    for face in range(1, 7):
        stop = FACE_VALUE_CENTS * face
        print(f"face {face}: stop pays {stop} cents, best action {actions[face]}")
    print(f"value of the game by backward induction = {value} cents ({float(value):.2f} to two places)")
    best = max(policy_value({face: bits[face - 1] == 1 for face in range(1, 7)}) for bits in product((0, 1), repeat=6))
    print(f"best of all 64 stopping policies by enumeration = {best} cents")
    print(f"backward induction equals the best policy: {value == best}")
    print(f"stop on every face (no reroll) = {policy_value({f: True for f in range(1, 7)})} cents")


def stopping_expectation(outcomes: tuple[tuple[int, Fraction], ...], rule: Rule) -> Fraction:
    """Expected total payoff over HORIZON turns, by recursion on the history: the backward induction method."""

    def value(history: tuple[int, ...]) -> Fraction:
        if len(history) == HORIZON or rule(history):
            return Fraction(sum(history))
        return sum((p * value((*history, x)) for x, p in outcomes), Fraction(0))

    return value(())


def stopping_by_sequences(outcomes: tuple[tuple[int, Fraction], ...], rule: Rule) -> Fraction:
    """The same expectation, by listing every sequence of HORIZON turns and stopping each one at its first hit."""
    total = Fraction(0)
    for seq in product(outcomes, repeat=HORIZON):
        weight = Fraction(1)
        for _, p in seq:
            weight *= p
        history: tuple[int, ...] = ()
        for x, _ in seq:
            history = (*history, x)
            if rule(history):
                break
        total += weight * sum(history)
    return total


RULES: tuple[tuple[str, Rule], ...] = (
    ("play all turns", lambda h: False),
    ("stop after the first win", lambda h: bool(h) and h[-1] > 0),
    ("stop after the first loss", lambda h: bool(h) and h[-1] < 0),
    ("stop when the total reaches 100 cents", lambda h: sum(h) >= 100),
    ("stop at 200 cents of gain or loss", lambda h: sum(h) >= 200 or sum(h) <= -200),
)


def part_three() -> None:
    print(f"Part 3 · stopping rules over {HORIZON} turns, fair game (+100 or -100, probability 1/2 each)")
    all_agree = True
    all_zero = True
    for name, rule in RULES:
        by_recursion = stopping_expectation(FAIR_GAME, rule)
        by_sequences = stopping_by_sequences(FAIR_GAME, rule)
        all_agree = all_agree and by_recursion == by_sequences
        all_zero = all_zero and by_recursion == 0
        print(f"{name}: expectation {by_recursion} (sequences: {by_sequences})")
    print(f"the two methods agree for every rule: {all_agree}")
    print(f"the expectation is 0 for every rule: {all_zero}")
    print("Part 3b · the same rules on a biased game (+150 or -100, probability 1/2 each)")
    for name, rule in RULES:
        print(f"{name}: expectation {stopping_expectation(BIASED_GAME, rule)}")


def main() -> None:
    part_one()
    part_two()
    part_three()


main()

3Stopping rules on a fair game

Assumption A3 (finite horizon, fairness at every history)

The horizon \(N\) is finite. For every history \(h\) of fewer than \(N\) turns with \(\Prob(h) > 0\), the next payoff \(x\) satisfies \(\sum_x x\,\Prob(\text{next payoff} = x \mid h) = 0\). This is the fairness condition of Definition 3.5. Conditional probabilities are defined only given a positive-probability event (Lesson 2, Definition 2.2), so the condition is stated for those histories alone.

Theorem 3.8 (a stopping rule does not change the expected total of a finite fair game)
  1. (H1) Assuming A1 and A3, the horizon \(N\) is finite.
  2. (H2) Assuming A3, the game is fair at every history of fewer than \(N\) turns that has positive probability.
  3. (H3) The stopping rule of Definition 3.7 depends only on the history \(h\).

Conclusion: the expected total paid under the rule is zero, \(\E[W] = 0\).

Proof

For a history \(h\) of length \(t \le N\) with \(\Prob(h) > 0\), let \(V(h)\) be the expected total paid under the rule, starting from \(h\). We show by backward induction on \(t\) that \(V(h) = W(h)\) for every history of length \(t\) with positive probability. Histories of probability zero add nothing to an expectation, so they are not needed.

Base, \(t = N\). By (H3) and Definition 3.7 the rule stops at \(h\), so \(V(h) = W(h)\).

Step. Suppose the claim holds for every history of length \(t + 1\) with positive probability, and let \(h\) of length \(t\) have \(\Prob(h) > 0\). If the rule stops at \(h\), then \(V(h) = W(h)\). If it continues, then \(V(h) = \sum_x \Prob(x \mid h)\,V(h, x)\), where the sum runs over the \(x\) with \(\Prob(h, x) > 0\), and by the hypothesis \(V(h, x) = W(h) + x\) for each of them. Hence \(V(h) = W(h)\sum_x \Prob(x \mid h) + \sum_x x\,\Prob(x \mid h)\). The first sum is 1 and the second is 0 by (H2), so \(V(h) = W(h)\).

At the empty history, \(W = 0\), so \(\E[W] = V(\varnothing) = 0\). \(\blacksquare\)

Remark 3.9

Theorem 3.8 uses the horizon \(N\) in the induction, which has a finite number of steps. It does not apply to a rule that may continue without bound. The lesson states no result for that case, and Section 4 names it as the place where the canon breaks. The theorem also needs (H3). A rule that looks at later payoffs is not a stopping rule, and Research problem R1 shows that its expectation can be nonzero.

Example 3.10 (five rules on the fair game, and the same rules on a biased game)

Assume A2 over \(N = 6\) turns, which gives the fairness condition of A3 with \(N = 6\). The rules are: play all six turns; stop after the first win; stop after the first loss; stop when the total reaches 100 cents; and stop when the total reaches 200 cents of gain or loss. Each is a stopping rule in the sense of Definition 3.7. By Theorem 3.8 each has expected total zero, and Lab 1, Part 3 prints zero for each of the five, computed by two methods.

The biased game pays \(+150\) or \(-100\) cents, each with probability \(1/2\). Its expected payoff per turn is \(25\) cents, and playing all six turns gives \(6 \cdot 25 = 150\) cents, which Lab 1, Part 3b prints. Its fairness condition fails, and each of the four rules other than play-all gives a value other than 150 cents. Stopping after the first loss gives \(1575/32\) cents, stopping when the total reaches 100 cents gives \(575/8\) cents, and stopping at 200 cents of gain or loss gives \(625/8\) cents. Theorem 3.8 does not apply to this game, because (H2) fails.

Example 3.11 (a fair one-turn game, for scale)

A single fair turn pays \(+100\) cents with probability \(1/2\) and \(-100\) cents with probability \(1/2\). Its expected payoff is zero. The turn pays a gain of \(+100\) cents with probability \(1/2\). A zero expectation does not mean that the game never pays a gain. It says that gains and losses balance in the average.

4Where the canon breaks

The results above hold for finite games and for the stated rules. Each limit below is a place where a naive extension fails.

  • Unbounded stopping. Theorem 3.8 needs a finite horizon \(N\). A rule that waits for the total to reach a target, with no cap on the number of turns, is outside it. This lesson states no value for such a rule, and the finite truncations of Lab 1 do not establish one.
  • Fairness is a hypothesis that cannot be dropped. Example 3.10 shows the same five rules giving zero for the fair game and nonzero values for the biased game. A claim that a rule cannot help must name the fairness condition it uses.
  • Choice has value in a game that is not fair. The reroll game of Example 3.6 has a choice worth \(100/3\) cents over stopping at once. Its stop payoff has mean 350 cents, so the game is not fair, and the choice is not a stopping rule on a fair game.

5Misconceptions

  1. “A clever stopping rule, chosen after seeing the outcomes, makes a fair game favourable.”

    Theorem 3.8 states that, over a finite horizon, every stopping rule that depends only on the history has expected total zero in a fair game. Lab 1, Part 3 prints zero for five rules, computed two ways. The rule must depend only on the past. A rule that looks ahead, as in Research problem R1, is not a stopping rule.

  2. “Choosing when to stop can never help a player.”

    In Example 3.6 the optimal choice raises the value from 350 cents to \(1150/3\) cents, a gain of \(100/3\) cents. The game is not fair, because its stop payoff has mean 350 cents, not zero. Theorem 3.8 does not apply, and in this game the choice does help. Lab 1, Part 2 prints both values.

  3. “A fair game with expected payoff zero never pays a gain.”

    Example 3.11 gives a fair turn that ends at \(+100\) cents with probability \(1/2\). Zero expectation balances the gains against the losses, and it does not say that gains are absent. The claim confuses a zero average with the absence of gains.

6Problem set

Every problem has a full worked solution. Attempt each problem before opening its solution. Problems marked E use the printed output of Lab 1.

Mechanics

M1 · A paid die game

A player pays 50 cents to roll a fair die, and receives 100 cents times the face. Find the expected net payoff in cents.

Solution

Hypotheses used: A1, a fair die, and integer cents. The expected payoff before the fee is \(100 \cdot \E[\text{face}] = 100 \cdot 7/2 = 350\) cents, by Example 3.3. Net of the fee, the expected payoff is \(350 - 50 = 300\) cents.

M2 · A fair win-or-lose game

A game pays 200 cents with probability \(p\) and costs 100 cents with probability \(1 - p\). Find \(p\) that makes the game fair in the sense of Definition 3.5.

Solution

Hypotheses used: a one-turn game, so Definition 3.5 requires expected payoff zero. The expected payoff is \(200p - 100(1 - p) = 300p - 100\). Setting it to zero gives \(p = 1/3\).

M3 · A two-stage game

A fair coin is tossed. On heads the game pays 100 cents and ends. On tails the player pays 50 cents and rolls a fair die, receiving 100 cents times the face. Find the expected payoff in cents.

Solution

Hypotheses used: A1, a fair coin, and a fair die. The heads branch has expected payoff 100 cents. The tails branch has expected payoff \(-50 + 100 \cdot 7/2 = 300\) cents. Weighting each branch by \(1/2\) gives \(\tfrac12 \cdot 100 + \tfrac12 \cdot 300 = 200\) cents.

Proof

P1 · Linearity for two payoffs

Prove Proposition 3.2 for \(m = 2\) directly from Definition 3.1, listing each hypothesis used.

Solution

Hypotheses used: A1, so \(\Omega\) is finite and the weights sum to 1. Then \(\E[X_1 + X_2] = \sum_\omega (X_1(\omega) + X_2(\omega))\,p(\omega) = \sum_\omega X_1(\omega)\,p(\omega) + \sum_\omega X_2(\omega)\,p(\omega) = \E[X_1] + \E[X_2]\). The two sums are finite, so the rearrangement is valid.

P2 · The play-all rule, by induction

Assume A3. Prove that the rule that plays all \(N\) turns has \(\E[W] = 0\), by induction on \(N\), using only the fairness condition at each history.

Solution

Hypotheses used: A3 and a finite horizon. For \(N = 1\), the expected total is the expected payoff of one fair turn, which is zero by (H2) at the empty history. Suppose the claim holds for \(t\) turns. For \(t + 1\) turns, the total is the total of the first \(t\) turns plus the payoff of turn \(t + 1\). The expectation of the first part is zero by hypothesis, and the expectation of the last is \(\sum_h \Prob(h)\sum_x x\,\Prob(x \mid h) = 0\), summed over the histories \(h\) of length \(t\) with \(\Prob(h) > 0\), by (H2) at each of them. Linearity (Proposition 3.2) gives \(\E[W] = 0\).

P3 · The optimal first action in the reroll game

In the reroll game of Example 3.6, prove that rerolling is optimal exactly on the faces \(f\) with \(100f < 250\), and state the threshold face.

Solution

Hypotheses used: the continuation value is 250 cents, from the derivation in Example 3.6. Stopping on face \(f\) pays \(100f\) cents, and rerolling is worth 250 cents, so rerolling is strictly better exactly when \(100f < 250\), that is, \(f < 2.5\). Stopping is at least as good when \(f \ge 2.5\). The integer faces with \(f < 2.5\) are 1 and 2, so the threshold face is 3, the lowest face at which stopping is preferred.

Empirical

E1 · The biased game by hand

From Lab 1, Part 3b, the rule "play all turns" on the biased game gives 150 cents. Confirm this value from the per-turn expectation.

Solution

Hypotheses used: six independent turns, each paying 150 or \(-100\) cents with probability \(1/2\). The per-turn expectation is \(\tfrac12 \cdot 150 + \tfrac12 \cdot (-100) = 25\) cents. Under the play-all rule the total is the sum of six turns, so its expectation is \(6 \cdot 25 = 150\) cents, matching the printed value.

E2 · The effect of a rule on the biased game

From Lab 1, Part 3b, the rule "stop at 200 cents of gain or loss" gives \(625/8\) cents. Find the change from the play-all value of 150 cents, as an exact fraction and as a decimal.

Solution

Hypotheses used: the printed values of Lab 1, Part 3b. The change is \(625/8 - 150 = 625/8 - 1200/8 = -575/8\) cents, which is \(-71.875\) cents exactly. On this biased game the rule gives a lower expected total than play-all. Theorem 3.8 does not apply, because (H2) fails.

E3 · The value of the reroll choice

From Lab 1, Part 2, the reroll game is worth \(1150/3\) cents and stopping on every face is worth 350 cents. Find the value of the choice in cents, as an exact fraction and as a decimal to two places.

Solution

Hypotheses used: the printed values. The value of the choice is \(1150/3 - 350 = 1150/3 - 1050/3 = 100/3\) cents, which is 33.33 cents to two places. The choice is worth the difference between the optimal policy and the stop-on-every-face policy.

Research

R1 · A rule that looks ahead

Open question with a stated criterion. Consider the fair two-turn game of Assumption A2. Let a rule look at both payoffs before it acts, and stop at the turn whose cumulative total is larger. Criterion: give the exact expected total of this rule, and state which hypothesis of Theorem 3.8 it violates.

Solution

Write \(W_1\) and \(W_2\) for the cumulative totals after turns 1 and 2. The rule stops at the turn with the larger \(W_t\), so its total is \(\max(W_1, W_2)\). The four equally likely paths give: \((+100, +100)\) with \(W_1 = 100\) and \(W_2 = 200\), total 200; \((+100, -100)\) with \(W_2 = 0\), total 100; \((-100, +100)\) with \(W_2 = 0\), total 0; and \((-100, -100)\) with \(W_1 = -100\) and \(W_2 = -200\), total \(-100\). The expected total is \((200 + 100 + 0 - 100)/4 = 50\) cents. The rule decides at turn 1 using the payoff of turn 2, so it is not a stopping rule of Definition 3.7, and (H3) fails.

R2 · A reroll game with a gain above ten cents

Open design question. Find an expected-value game, with integer cents and a stated stopping rule, whose optimal value exceeds the stop-at-once value by at least 10 cents. Criterion: both values are exact, and the game is not fair.

Solution

The reroll game of Example 3.6 meets the criterion. Its optimal value is \(1150/3\) cents and its stop-at-once value is 350 cents, so the gain is \(100/3\) cents, which is more than 10 cents. Both values are exact fractions. The game is not fair, because its first roll has mean payoff 350 cents, so (H2) of Theorem 3.8 fails at the first turn. Changing the fee changes the gain: for a fee \(c\) the gain is \((\sum_f \max(100f,\, 350 - c))/6 - 350\) cents, which is \(100/3\) cents at \(c = 100\) and \(74.5\) cents at \(c = 1\). The answer must state its own fee and values.

R3 · The unbounded rule, what the table does and does not show

Open question. For the fair game of Assumption A2, consider the rule that stops when the total reaches 100 cents, with a horizon of \(N\) turns. Compute its expected total for \(N = 1\) to \(6\) from Theorem 3.8, and state what these values say about the rule with no horizon. Criterion: the answer must separate what the finite values establish from what they do not.

Solution

For each finite \(N\), the rule is a stopping rule over a finite horizon that is forced to stop at \(N\), and Theorem 3.8 gives expected total zero for every \(N\) from 1 to 6. These values establish zero for each finite horizon. They do not establish the value of the rule with no horizon, because Theorem 3.8 needs a finite \(N\), and the lesson proves no limit. A run of zeros for \(N = 1\) to \(6\) cannot show that the limit of the expected totals equals the expected total of the unbounded rule, since that rule is outside the theorem.

8Retrieval quiz

Answer from memory, then check. Finishing the quiz adds this lesson's cards to your review deck.

  1. Under Definition 3.1, what is \(\E[X]\) on a finite space?

    Options

    Definition 3.1 weights each payoff by the probability of its outcome and sums over the finite outcome set.

  2. A game pays 100 cents times the face of a fair die. What is its expected payoff in cents?

    \(100 \cdot 7/2 = 350\) cents, because the expected face is \(21/6 = 7/2\) (Example 3.3).

  3. Under Definition 3.5, what makes a one-turn game fair?

    Options

    A one-turn game is fair when its expected payoff is zero, and the other options are not part of the definition.

  4. A game pays 200 cents with probability \(p\) and costs 100 cents otherwise. For what \(p\) is it fair? Give six decimal places.

    The expected payoff is \(200p - 100(1 - p) = 300p - 100\), which is zero at \(p = 1/3 = 0.333333\) (Problem M2).

  5. Which hypothesis of Theorem 3.8 is the one a rule that looks at later payoffs violates?

    Options

    Hypothesis (H3) requires the rule to depend only on the history. A rule that uses later payoffs fails (H3), as Research problem R1 shows.

  6. In the reroll game of Example 3.6, what is the value in cents, to six decimal places?

    The value is \(1150/3 = 383.333333\) cents to six decimal places (Lab 1, Part 2).

  7. In the reroll game, what is the continuation value in cents of paying the fee and rolling once more?

    The continuation value is \(\E[100 g] - 100 = 350 - 100 = 250\) cents.

  8. In the reroll game, on which first faces is rerolling the better option?

    Options

    Stopping on face \(f\) pays \(100f\) cents, which is below the continuation value 250 cents only for \(f = 1\) and \(f = 2\) (Problem P3).

  9. A fair two-turn game pays \(\pm 100\) cents per turn. A rule looks at both turns and stops at the turn with the larger cumulative total. What is its expected total in cents?

    Over the four equally likely paths the totals are 200, 100, 0 and \(-100\), with mean \(200/4 = 50\) cents (Research problem R1). The rule looks ahead, so Theorem 3.8 does not apply.

  10. A biased turn pays +150 or -100 cents, each with probability 1/2. What is the expected total over six turns, with every turn played?

    The per-turn expectation is \(25\) cents, and \(6 \cdot 25 = 150\) cents (Example 3.10, Lab 1, Part 3b).

  11. Does a stopping rule change the expected total of a biased game?

    Options

    The biased game fails fairness (H2), so Theorem 3.8 does not apply, and Example 3.10 shows the values differ by rule.

  12. Two fair dice, \(X\) and \(Y\). What is \(\E[X + Y]\)?

    By Proposition 3.2, \(\E[X + Y] = \E[X] + \E[Y] = 7/2 + 7/2 = 7\). Lab 1, Part 1 prints 7 by enumeration.
