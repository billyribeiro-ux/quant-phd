Representative SIMULATED instance of the Geanakoplos Collateral Equilibrium Solver.

def solve_geanakoplos_equilibrium(
    v_u: float,
    v_d: float,
    risk_free_rate: float = 1.0,
    max_loan_ratio: float = 1.0,
) -> dict[str, float]:
    """Calculate the collateral equilibrium for a two-state asset."""
    if v_d <= 0.0:
        raise ValueError(f"v_d must be strictly positive, got {v_d}")
    if v_u <= v_d:
        raise ValueError(f"v_u must be strictly greater than v_d, got v_u={v_u}, v_d={v_d}")
    if risk_free_rate < 1.0:
        raise ValueError(f"risk_free_rate must be >= 1.0, got {risk_free_rate}")
    if not (0.0 < max_loan_ratio <= 1.0):
        raise ValueError(f"max_loan_ratio must lie in (0.0, 1.0], got {max_loan_ratio}")

    loan = (max_loan_ratio * v_d) / risk_free_rate
    num = risk_free_rate - (1.0 - max_loan_ratio) * v_d
    den = risk_free_rate + (v_u - v_d)
    h_star = min(1.0, max(0.0, num / den))

    price = loan + (1.0 - h_star)
    margin = price - loan
    leverage = price / margin if margin > 0.0 else 1.0
    haircut = margin / price if price > 0.0 else 0.0

    return {
        "price": price,
        "marginal_buyer": h_star,
        "loan": loan,
        "margin": margin,
        "leverage": leverage,
        "haircut": haircut,
    }


def simulate_margin_shock(
    v_u: float,
    v_d: float,
    initial_loan_ratio: float,
    shocked_loan_ratio: float,
    risk_free_rate: float = 1.0,
) -> dict[str, float]:
    """Simulate asset price and leverage response to an exogenous margin shock."""
    if shocked_loan_ratio > initial_loan_ratio:
        raise ValueError("shocked_loan_ratio must be <= initial_loan_ratio")

    eq0 = solve_geanakoplos_equilibrium(v_u, v_d, risk_free_rate, initial_loan_ratio)
    eq1 = solve_geanakoplos_equilibrium(v_u, v_d, risk_free_rate, shocked_loan_ratio)

    p0 = eq0["price"]
    p1 = eq1["price"]
    price_drop = p0 - p1
    price_drop_pct = (price_drop / p0) * 100.0 if p0 > 0.0 else 0.0
    buyer_shift = eq1["marginal_buyer"] - eq0["marginal_buyer"]

    return {
        "initial_price": p0,
        "shocked_price": p1,
        "price_drop": price_drop,
        "price_drop_pct": price_drop_pct,
        "initial_leverage": eq0["leverage"],
        "shocked_leverage": eq1["leverage"],
        "initial_haircut": eq0["haircut"],
        "shocked_haircut": eq1["haircut"],
        "marginal_buyer_shift": buyer_shift,
    }

1. Mathematical Specification and Collateral Equilibrium Derivation

Consider a two-date economy \(t \in \{0, 1\}\) with a single risky asset in supply \(Q = 1\) yielding terminal payoffs \(V_U > V_D > 0\) at date 1. Agents are risk-neutral and indexed by optimism \(h \in [0, 1]\) with subjective probability \(p^h = h\) of state \(U\), with uniform wealth density \(\int_0^1 1 \, dh = 1\). Borrowing is non-recourse and secured by the physical asset.

Under non-default collateralized debt, the maximum safe loan per unit of collateral is \(L = \theta V_D / R_f\), where \(\theta \in (0, 1]\) is the loan ratio. The required equity down payment per unit is \(m = P - L\). For marginal buyer \(h^*\), expected return on equity equals the gross risk-free rate \(R_f\):

\[ \frac{(1 - \theta) V_D + h^*(V_U - V_D)}{P - L} = R_f \implies P - L = \frac{(1 - \theta) V_D + h^*(V_U - V_D)}{R_f} \]

Equating this to asset market clearing \(\frac{1 - h^*}{P - L} = 1 \implies P - L = 1 - h^*\) yields the unique closed-form marginal buyer cutoff:

\[ h^* = \frac{R_f - (1 - \theta) V_D}{R_f + V_U - V_D} \]

And equilibrium asset price: \(P = \frac{\theta V_D}{R_f} + (1 - h^*)\).

3. Exogenous Margin Shocks and Deleveraging

When lenders execute an exogenous margin shock by compressing \(\theta\) from 1.00 to 0.50, safe loan capacity collapses from $0.4000 to $0.2000. Price drops to \(P_1 = \$0.800000\) (-11.11%), haircuts widen from 55.56% to 75.00%, and leverage drops from 1.80x to 1.33x. This non-linear deleveraging illustrates the liquidity spiral of Brunnermeier and Pedersen (2008) .

4. Multi-Period Leverage Cycle and the Double Crash

In a three-period tree with terminal payoffs \(V_{UU} = 2.40, V_{UD} = 1.60, V_{DU} = 1.20, V_{DD} = 0.30\), date 0 price reaches \(P_0 = \$1.3333\) with leverage 2.38x. When bad news hits at date 1 (state \(D\)), price collapses to \(P_D = \$0.7737\) (-41.97%). Debt owed is \(L_0 = P_D = \$0.7737\), leaving optimists with exactly \(\$0.00\) equity. The price drop is a double crash: fundamental revisions lower the asset value, but the collapse of optimist purchasing power forces the marginal buyer down to \(h^*_D = 0.5263\), exacerbating fire-sale discounts .

5. Macroprudential Policy and Central Bank Facilities

During the 2008 financial crisis, private repo haircuts on securitized debt surged from ~0% to over 45% . Because borrowing constraints were bound by collateral haircuts rather than interest rates, lowering the federal funds rate to 0% failed to revive credit markets. The Federal Reserve's Term Asset-Backed Securities Loan Facility (TALF) restored market liquidity by providing non-recourse loans at fixed low haircuts (10%–15%), directly bypassing impaired private intermediary haircuts .

Model Overview

In the Geanakoplos model, people have different beliefs \(h\) from 0 to 1. The optimists borrow money backed by the asset to buy it. The safe loan is \(L = V_D\). The price formula is \(P = L + (1 - h^*)\). When margin shocks happen, lenders ask for more cash down payment, and prices drop.

Policy Discussion

During the 2008 crisis, repo haircuts went up a lot, which caused a run on repo as explained by Gorton and Metrick. The Fed cut interest rates, but banks still had high haircuts. The Fed had to create facilities like TALF to give loans to investors so they could buy bonds.
