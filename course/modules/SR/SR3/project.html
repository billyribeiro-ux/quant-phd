Specification

Context
A macroprudential financial stability authority monitors a network of interconnected financial intermediaries. Standalone Value-at-Risk fails to signal outward fire-sale spillovers, equity capital depletion during market crashes, or contractual cascade failures across bilateral interbank liabilities. The authority requires an automated systemic risk engine to calculate CoVaR, MES, SRISK, and Eisenberg-Noe network clearing in real time, triggering calibrated alert warnings when systemic thresholds are breached.
Inputs
  • r_system: 1D NumPy array of aggregate financial sector returns of length \(T\).
  • r_institutions: 2D NumPy array of shape \((N, T)\) or list of 1D arrays of institutional returns.
  • state_vars: Optional 2D NumPy array of shape \((T, K)\) containing lagged macroeconomic conditioning variables (VIX, liquidity spread, term slope, credit spread).
  • equities: 1D NumPy array of length \(N\) containing market capitalizations \(W_i > 0\).
  • debts: 1D NumPy array of length \(N\) containing book debt liabilities \(D_i \ge 0\).
  • nominal_liabilities: 2D NumPy array \(L \in \R^{N \times N}\) with \(L_{ij} \ge 0\) and \(L_{ii} = 0\).
  • external_assets: 1D NumPy array \(z \in \R_+^N\) of outside liquid asset endowments.
  • senior_liabilities: Optional 1D NumPy array \(b \in \R_+^N\) of outside senior debt obligations.
Required outputs
A pure Python module atlas/systemic.py implementing the public API specified in atlas/A19.contract.md:
  • fit_linear_quantile_regression(y, x, q=0.05) -> np.ndarray
  • compute_covar(r_system, r_institution, state_vars=None, alpha=0.05) -> dict[str, float]
  • compute_mes(r_system, r_institution, alpha=0.05) -> float
  • compute_lrmes(r_system, r_institution, alpha=0.05, crisis_drop=0.40) -> float
  • compute_srisk(equity_value, debt_value, lrmes, prudential_ratio=0.08) -> float
  • compute_systemic_srisk_panel(equities, debts, lrmes_values, prudential_ratio=0.08) -> dict[str, Any]
  • compute_network_clearing(nominal_liabilities, external_assets, senior_liabilities=None, max_iter=1000, tol=1e-10) -> dict[str, Any]
  • class SystemicRiskMonitor(thresholds=None) with evaluate(metrics) -> dict[str, Any]
Constraints
Strictly pure Python, NumPy 2.4, SciPy 1.18. Deterministic execution; no random seeds without fixed initialization; no network calls; no filesystem access outside input reading; complete suite executes in under 60 seconds across all 50 seeds; full compliance with mypy strict type checking.

Rung 1 · Worked example: End-to-end systemic risk pipeline

The worked example below simulates a 4-bank financial network, computes static and state-conditioned CoVaR, estimates non-parametric MES and multi-month LRMES, constructs the dollar SRISK panel, clears interbank contractual liabilities via Eisenberg-Noe, and evaluates the multi-tier prudential alert monitor.

Executing the reference systemic risk monitor pipeline evaluates CoVaR, MES, SRISK ($28.05B total shortfall), and network default clearing (1 default, $12.0B shortfall), triggering a CRITICAL alert status across 4 breached indicators.

"""Lab SR3-project-1 (Rung 1 Worked Example): Full Systemic Risk Monitor Pipeline.

SIMULATED: fully solved instance of the Atlas A19 Systemic Risk Monitor (`atlas.systemic`),
incorporating CoVaR, Marginal Expected Shortfall, SRISK capital shortfall index,
Eisenberg-Noe network clearing, and prudential alert monitoring.
"""

from __future__ import annotations

import numpy as np
from scipy.optimize import linprog


def fit_quantile_reg(y: np.ndarray, x: np.ndarray, q: float) -> np.ndarray:
    t_obs, k_vars = x.shape
    c = np.concatenate([np.zeros(k_vars), q * np.ones(t_obs), (1.0 - q) * np.ones(t_obs)])
    eye_t = np.eye(t_obs)
    res = linprog(
        c,
        A_eq=np.hstack([x, eye_t, -eye_t]),
        b_eq=y,
        bounds=[(None, None)] * k_vars + [(0.0, None)] * (2 * t_obs),
        method="highs",
    )
    return np.asarray(res.x[:k_vars], dtype=np.float64)


def main() -> None:
    rng = np.random.default_rng(303)
    t_obs = 500

    # Macro volatility state M_t
    vol_state = np.zeros(t_obs)
    for t in range(1, t_obs):
        vol_state[t] = 0.60 * vol_state[t - 1] + rng.normal(0.0, 0.01)

    # Market returns R_sys
    scale = np.sqrt(rng.chisquare(df=4, size=t_obs) / 4.0)
    r_sys = 0.0003 - 0.20 * vol_state + rng.normal(0.0, 0.011, size=t_obs) / np.maximum(scale, 1e-4)

    # 4 Institutions: returns, equities, debts
    names = ["Bank 1", "Bank 2", "Bank 3", "Bank 4"]
    betas = [1.50, 1.20, 0.90, 0.70]
    equities = np.array([120.0, 85.0, 210.0, 55.0])
    debts = np.array([850.0, 620.0, 1600.0, 440.0])

    r_insts: list[np.ndarray] = []
    for b in betas:
        noise = rng.normal(0.0, 0.012, size=t_obs)
        r_insts.append(b * r_sys + 0.05 * vol_state + noise)

    # 1. CoVaR and Delta-CoVaR
    ones = np.ones((t_obs, 1))
    delta_covars: list[float] = []
    for r_i in r_insts:
        # Static institution VaR
        var_i_05 = float(np.quantile(r_i, 0.05))
        var_i_50 = float(np.quantile(r_i, 0.50))
        x_sys = np.column_stack([ones, r_i])
        b_sys = fit_quantile_reg(r_sys, x_sys, q=0.05)
        d_cov = float(b_sys[1] * (var_i_05 - var_i_50))
        delta_covars.append(d_cov)

    # 2. MES and LRMES
    var_sys_05 = float(np.quantile(r_sys, 0.05))
    crisis_mask = r_sys <= var_sys_05
    mes_values = [float(-np.mean(r_i[crisis_mask])) for r_i in r_insts]
    var_s = float(np.var(r_sys, ddof=1))
    lrmes_values = [float(1.0 - (1.0 - 0.40) ** (np.cov(r_i, r_sys, ddof=1)[0, 1] / var_s)) for r_i in r_insts]

    # 3. SRISK Panel
    k = 0.08
    cs = k * debts - (1.0 - k) * (1.0 - np.array(lrmes_values)) * equities
    srisks = np.maximum(0.0, cs)
    total_srisk = float(np.sum(srisks))
    srisk_pcts = (srisks / total_srisk * 100.0) if total_srisk > 0 else np.zeros_like(srisks)

    # 4. Network Clearing under targeted shock
    l_mat = np.array(
        [
            [0.0, 20.0, 15.0, 10.0],
            [15.0, 0.0, 20.0, 15.0],
            [20.0, 15.0, 0.0, 15.0],
            [10.0, 20.0, 15.0, 0.0],
        ]
    )
    p_bar = np.sum(l_mat, axis=1)
    z_external = np.array([0.0, 25.0, 35.0, 20.0])  # Bank 1 wiped out
    b_senior = np.array([12.0, 10.0, 15.0, 8.0])

    pi = l_mat / p_bar[:, None]
    p = p_bar.copy()
    for _ in range(500):
        p_next = np.minimum(p_bar, np.maximum(0.0, z_external + pi.T @ p - b_senior))
        if np.max(np.abs(p_next - p)) < 1e-10:
            break
        p = p_next
    defaults = (p < p_bar - 1e-7).astype(int)

    # 5. Alert Monitor
    monitor_thresholds = {"delta_covar": -0.015, "mes": 0.035, "srisk_pct": 30.0, "network_defaults": 1}
    breaches = {
        "delta_covar": any(dc < monitor_thresholds["delta_covar"] for dc in delta_covars),
        "mes": any(m > monitor_thresholds["mes"] for m in mes_values),
        "srisk_pct": any(sp > monitor_thresholds["srisk_pct"] for sp in srisk_pcts),
        "network_defaults": int(np.sum(defaults)) >= monitor_thresholds["network_defaults"],
    }
    severity = "CRITICAL" if sum(breaches.values()) >= 3 else "WARNING"

    print("=== Atlas A19 Systemic-Risk Monitor (Full Pipeline) ===")
    print(f"Systemic SRISK (Total): ${total_srisk:.2f}B")
    print("-" * 75)
    print(f"{'Bank':<10} {'Delta-CoVaR':<15} {'MES (5%)':<12} {'LRMES':<10} {'SRISK ($B)':<12} {'Share (%)':<10}")
    print("-" * 75)
    for i, name in enumerate(names):
        mes_str = f"{mes_values[i] * 100:<11.2f}%"
        lrmes_str = f"{lrmes_values[i] * 100:<9.1f}%"
        srisk_str = f"${srisks[i]:<11.2f}"
        pct_str = f"{srisk_pcts[i]:<9.1f}%"
        print(f"{name:<10} {delta_covars[i]:<15.4f} {mes_str} {lrmes_str} {srisk_str} {pct_str}")
    print("-" * 75)
    print(f"Network Cascade: {int(np.sum(defaults))}/4 defaults. Clearing shortfall: ${np.sum(p_bar - p):.1f}B")
    print(f"Alert Monitor Status: {severity} ({sum(breaches.values())}/4 indicators breached)")


main()

Rung 4 · Stretch: Dynamic multi-horizon stress cascade engine

In actual financial crises, interbank contractual defaults do not occur in a vacuum; defaulting banks liquidate illiquid asset holdings, driving down asset market prices and triggering secondary fire-sale spirals on surviving balance sheets. The stretch lab below implements a coupled multi-horizon stress cascade engine combining Eisenberg–Noe network clearing with endogenous price impacts.

Coupling interbank contractual defaults with endogenous fire-sale price impact over a 3-horizon stress simulation demonstrates that initial asset price drops trigger forced liquidations, propagating secondary defaults and expanding cumulative systemic payment shortfalls from $19.00B to $29.93B.

"""Lab SR3-project-3 (Rung 4 Stretch Extension): Dynamic Multi-Horizon Stress Cascade Engine.

SIMULATED: couples interbank default clearing with endogenous fire-sale price impact
over multiple stress horizons, evaluating systemic liquidation spirals.
"""

from __future__ import annotations

import numpy as np


def clear_network(l_mat: np.ndarray, z_vec: np.ndarray, b_vec: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
    p_bar = np.sum(l_mat, axis=1)
    pi_mat = np.zeros_like(l_mat)
    has_liab = p_bar > 1e-12
    pi_mat[has_liab] = l_mat[has_liab] / p_bar[has_liab, None]

    p = p_bar.copy()
    for _ in range(300):
        p_next = np.minimum(p_bar, np.maximum(0.0, z_vec + pi_mat.T @ p - b_vec))
        if np.max(np.abs(p_next - p)) < 1e-9:
            p = p_next
            break
        p = p_next
    defaults = (p < p_bar - 1e-7).astype(int)
    return p, defaults


def main() -> None:
    n_banks = 4
    n_periods = 3
    fire_sale_alpha = 0.015  # Linear price impact parameter (1.5% drop per $1B liquidated)

    # Base interbank network
    l_mat = np.array(
        [
            [0.0, 30.0, 20.0, 10.0],
            [20.0, 0.0, 25.0, 15.0],
            [15.0, 25.0, 0.0, 20.0],
            [10.0, 15.0, 25.0, 0.0],
        ]
    )
    p_bar = np.sum(l_mat, axis=1)

    # Holdings of illiquid common asset (units): [20, 35, 45, 30]
    asset_holdings = np.array([20.0, 35.0, 45.0, 30.0])
    price_t = 1.0  # Initial asset price

    # Liquid cash reserves z_cash and senior outside liabilities b
    z_cash = np.array([2.0, 4.0, 6.0, 3.0])
    b_senior = np.array([20.0, 15.0, 18.0, 14.0])

    print("=== Dynamic Multi-Horizon Stress Cascade Engine (Stretch) ===")
    print(f"Network Size: N={n_banks} banks | Stress Horizons: T={n_periods}")
    print("-" * 75)

    cumulative_defaults = np.zeros(n_banks, dtype=int)

    for t in range(1, n_periods + 1):
        # Exogenous macro shock in period 1: 30% fundamental asset price decline
        if t == 1:
            price_t = 0.70

        # Outside asset valuation: cash + mark-to-market illiquid assets
        z_total = z_cash + asset_holdings * price_t

        # Solve interbank clearing
        p_star, period_defaults = clear_network(l_mat, z_total, b_senior)
        new_defaults = (period_defaults == 1) & (cumulative_defaults == 0)
        cumulative_defaults = np.maximum(cumulative_defaults, period_defaults)

        # Forced fire sales: newly defaulting banks liquidate 70% of illiquid assets
        liquidated_units = float(np.sum(asset_holdings[new_defaults] * 0.70))
        liquidation_dollar = liquidated_units * price_t

        # Endogenous price impact: Delta P / P = - alpha * liquidation_dollar
        price_drop_pct = fire_sale_alpha * liquidation_dollar
        next_price = price_t * max(0.20, 1.0 - price_drop_pct)

        print(f"Horizon t={t}:")
        print(f"  Asset Price: ${price_t:.4f} (Fire-Sale Impact: -{price_drop_pct * 100:.2f}%)")
        n_new = int(np.sum(new_defaults))
        n_cum = int(np.sum(cumulative_defaults))
        print(f"  New Defaults: {n_new} | Cumulative Defaults: {n_cum}/{n_banks}")
        print(f"  Forced Fire Sales: ${liquidation_dollar:.2f}B | Systemic Shortfall: ${np.sum(p_bar - p_star):.2f}B")

        price_t = next_price

    print("-" * 75)
    print("Coupled Contagion Outcome: Feedback between interbank contractual insolvencies")
    print("and fire-sale asset devaluations amplifies cumulative defaults across horizons.")


main()
