Fund-Skill Test

Using a simulated universe of 40 mutual funds with known planted skill, quantify how many funds look skilled purely by chance, and recover the true skilled set using a cross-sectional bootstrap under the null of zero alpha. Deliverable: a verified Python implementation (fund_skill.py) and an institutional investment committee memorandum (memo.md).

The four-rung ladder

  1. Worked example

    One fully solved instance of a six-fund universe with \(T = 24\) months and one planted skilled fund. Step-by-step OLS regression, naive false-positive count, expected count, and bootstrap threshold.

  2. Completion problem

    The same six-fund task with the naive-count filter line and bootstrap quantile threshold line left blank. Graded instantly on the page.

  3. Independent project

    The curriculum project: implement fund_skill.py for an institutional universe of 40 funds across 60 months of simulated data, passing all pytest unit tests, and compose an allocator memorandum.

  4. Stretch

    Evaluate statistical power as the planted skilled set diminishes, or introduce a look-ahead factor shift to observe artificial alpha inflation.

Lab 1 · Worked example: six-fund universe skill analysis

Under a simulated six-fund universe with T=24 months where Fund 2 has a planted monthly alpha of +0.015 and funds 0, 1, 3, 4, 5 have zero skill, naive testing at the 5% level flags multiple funds, while the bootstrap maximum-t critical threshold (c = 1.9548) correctly isolates Fund 2 alone.

"""Lab FC3-project-1: Project Rung 1 worked example.

SIMULATED 6-fund universe with T=24 months and one planted skilled fund (Fund 2).
Performs OLS regression, chance count, expected count, and bootstrap skill detection.
"""

from __future__ import annotations

import math
import random


def alpha_and_t(returns: list[float], factor: list[float]) -> tuple[float, float]:
    """Compute OLS alpha and t-statistic."""
    n_months = len(returns)
    mean_f = sum(factor) / n_months
    mean_r = sum(returns) / n_months

    s_ff = sum((f - mean_f) ** 2 for f in factor)
    s_fr = sum((factor[t] - mean_f) * (returns[t] - mean_r) for t in range(n_months))
    beta = s_fr / s_ff
    alpha = mean_r - beta * mean_f

    rss = sum((returns[t] - (alpha + beta * factor[t])) ** 2 for t in range(n_months))
    s2 = rss / (n_months - 2)
    var_a = s2 * (1.0 / n_months + (mean_f**2) / s_ff)
    se_a = math.sqrt(var_a)
    t_stat = alpha / se_a
    return alpha, t_stat


def main() -> None:
    """Run fully worked 6-fund performance analysis."""
    rng = random.Random(101)
    n_funds = 6
    n_months = 24
    planted_fund = 2

    # SIMULATED: Benchmark factor
    factor = [rng.gauss(0.008, 0.040) for _ in range(n_months)]

    # Returns for 6 funds: Fund 2 has planted monthly alpha of +0.015 (150 bps)
    returns: list[list[float]] = []
    for i in range(n_funds):
        alpha = 0.015 if i == planted_fund else 0.000
        beta = 0.9 + 0.2 * rng.random()
        r_i = [alpha + beta * factor[t] + rng.gauss(0.0, 0.015) for t in range(n_months)]
        returns.append(r_i)

    # Step 1: OLS estimation for all funds
    alphas: list[float] = []
    t_stats: list[float] = []
    print("Fund | Alpha (monthly) | t-statistic | Planted Status")
    print("-----+-----------------+-------------+---------------")
    for i in range(n_funds):
        a_i, t_i = alpha_and_t(returns[i], factor)
        alphas.append(a_i)
        t_stats.append(t_i)
        status = "Skilled (planted)" if i == planted_fund else "Zero-skill"
        print(f"{i:4d} | {a_i:15.5f} | {t_i:11.3f} | {status}")

    # Step 2: Naive count at one-sided 5% level
    crit_val = 1.644854
    naive_flagged = [i for i, t in enumerate(t_stats) if t > crit_val]
    expected_chance = n_funds * 0.05

    print("-----+-----------------+-------------+---------------")
    print(f"Naive flagged count (t > {crit_val:.4f}): {len(naive_flagged)} (Funds {naive_flagged})")
    print(f"Expected false positives by chance alone: {expected_chance:.2f}")

    # Step 3: Bootstrap threshold
    n_boot = 200
    boot_rng = random.Random(42)
    mean_f = sum(factor) / n_months
    s_ff = sum((f - mean_f) ** 2 for f in factor)

    slopes = [
        sum((factor[t] - mean_f) * (returns[i][t] - sum(returns[i]) / n_months) for t in range(n_months)) / s_ff
        for i in range(n_funds)
    ]
    residuals = [[returns[i][t] - (alphas[i] + slopes[i] * factor[t]) for t in range(n_months)] for i in range(n_funds)]

    max_t_boot: list[float] = []
    for _ in range(n_boot):
        tau = [boot_rng.randrange(n_months) for _ in range(n_months)]
        m_k = -1e9
        for i in range(n_funds):
            r_null = [slopes[i] * factor[t] + residuals[i][tau[t]] for t in range(n_months)]
            _, t_boot = alpha_and_t(r_null, factor)
            if t_boot > m_k:
                m_k = t_boot
        max_t_boot.append(m_k)

    max_t_boot.sort()
    idx = math.ceil((1.0 - 0.05) * n_boot) - 1
    boot_thresh = max_t_boot[idx]
    boot_flagged = [i for i, t in enumerate(t_stats) if t > boot_thresh]

    print(f"Bootstrap 95% max-t threshold: {boot_thresh:.4f}")
    print(f"Bootstrap recovered skilled funds: {boot_flagged}")
    print(f"Planted fund recovered successfully: {boot_flagged == [planted_fund]}")

Lab 3 · Rung 3 independent verification check on Seed 0

Executing the reference implementation on Seed 0 (N=40 funds, T=60 months, 5 planted skilled funds) demonstrates that naive testing at 5% flags 7 funds (including 2 false discoveries), while the bootstrap skill test at level 0.05 eliminates both false discoveries and achieves 100% exact recovery of the 5 planted funds.

"""Lab FC3-project-3: Project Rung 3 reference verification check on Seed 0.

SIMULATED 40-fund universe with T=60 months generated from Seed 0.
Compares naive chance counting against bootstrap maximum-t skill recovery.
"""

from __future__ import annotations

import math
import random


def make_instance(seed: int) -> dict[str, object]:
    """Generate simulated fund returns and market factor."""
    rng = random.Random(seed)
    n_funds = 40
    n_months = 60
    mu_f = 0.007
    sigma_f = 0.045
    factor = [rng.gauss(mu_f, sigma_f) for _ in range(n_months)]
    mean_f = sum(factor) / n_months
    s_ff = sum((ft - mean_f) ** 2 for ft in factor)
    sigma_eps = 0.020
    expected_se = sigma_eps * math.sqrt(1.0 / n_months + (mean_f**2) / s_ff)
    num_skilled = rng.randint(3, 5)
    planted_skill = sorted(rng.sample(range(n_funds), num_skilled))
    planted_alpha = [0.0] * n_funds
    for idx in planted_skill:
        planted_alpha[idx] = expected_se * (6.5 + 1.2 * rng.random())
    returns: list[list[float]] = []
    for i in range(n_funds):
        beta = 0.8 + 0.4 * rng.random()
        alpha = planted_alpha[i]
        r_i = [alpha + beta * factor[t] + rng.gauss(0.0, sigma_eps) for t in range(n_months)]
        returns.append(r_i)
    return {
        "returns": returns,
        "factor": factor,
        "planted_skill": planted_skill,
        "planted_alpha": planted_alpha,
    }


def alpha_and_t(returns: list[float], factor: list[float]) -> tuple[float, float]:
    """Compute OLS alpha and t-statistic."""
    n_months = len(returns)
    mean_f = sum(factor) / n_months
    mean_r = sum(returns) / n_months
    s_ff = sum((f - mean_f) ** 2 for f in factor)
    s_fr = sum((factor[t] - mean_f) * (returns[t] - mean_r) for t in range(n_months))
    beta = s_fr / s_ff
    alpha = mean_r - beta * mean_f
    rss = sum((returns[t] - (alpha + beta * factor[t])) ** 2 for t in range(n_months))
    s2 = rss / (n_months - 2)
    var_a = s2 * (1.0 / n_months + (mean_f**2) / s_ff)
    se_a = math.sqrt(var_a)
    t_stat = alpha / se_a
    return alpha, t_stat


def bootstrap_skilled_set(
    returns: list[list[float]],
    factor: list[float],
    level: float,
    n_boot: int,
    seed: int,
) -> list[int]:
    """Identify skilled funds via bootstrap maximum-t threshold."""
    n_funds = len(returns)
    n_months = len(factor)
    mean_f = sum(factor) / n_months
    s_ff = sum((f - mean_f) ** 2 for f in factor)
    slopes: list[float] = [0.0] * n_funds
    residuals: list[list[float]] = []
    observed_t: list[float] = [0.0] * n_funds
    for i in range(n_funds):
        alpha_i, t_i = alpha_and_t(returns[i], factor)
        mean_r_i = sum(returns[i]) / n_months
        s_fr_i = sum((factor[t] - mean_f) * (returns[i][t] - mean_r_i) for t in range(n_months))
        beta_i = s_fr_i / s_ff
        e_i = [returns[i][t] - (alpha_i + beta_i * factor[t]) for t in range(n_months)]
        slopes[i] = beta_i
        residuals.append(e_i)
        observed_t[i] = t_i
    rng = random.Random(seed)
    max_t_boot: list[float] = [0.0] * n_boot
    for k in range(n_boot):
        tau = [rng.randrange(n_months) for _ in range(n_months)]
        m_k = -1e9
        for i in range(n_funds):
            r_null = [slopes[i] * factor[t] + residuals[i][tau[t]] for t in range(n_months)]
            _, t_boot = alpha_and_t(r_null, factor)
            if t_boot > m_k:
                m_k = t_boot
        max_t_boot[k] = m_k
    max_t_boot.sort()
    idx = math.ceil((1.0 - level) * n_boot) - 1
    idx = max(0, min(n_boot - 1, idx))
    threshold = max_t_boot[idx]
    return [i for i in range(n_funds) if observed_t[i] > threshold]


def main() -> None:
    """Run Seed 0 instance analysis and display results."""
    inst = make_instance(0)
    returns = inst["returns"]
    assert isinstance(returns, list)
    factor = inst["factor"]
    assert isinstance(factor, list)
    planted = inst["planted_skill"]
    assert isinstance(planted, list)

    n_funds = len(returns)
    t_stats = [alpha_and_t(returns[i], factor)[1] for i in range(n_funds)]

    crit = 1.644854
    naive = [i for i, t in enumerate(t_stats) if t > crit]
    boot = bootstrap_skilled_set(returns, factor, level=0.05, n_boot=200, seed=1000)

    print("Universe: N=40 funds, T=60 months (SIMULATED Seed 0)")
    print(f"Planted skilled funds ({len(planted)}): {planted}")
    print(f"Naive significant funds at 5% ({len(naive)}): {naive}")
    print(f"Expected false positives under null: {n_funds * 0.05:.1f}")
    false_pos_naive = sorted(set(naive) - set(planted))
    print(f"Naive false discoveries (zero-skill funds): {false_pos_naive}")
    print(f"Bootstrap recovered skilled funds ({len(boot)}): {boot}")
    false_pos_boot = sorted(set(boot) - set(planted))
    false_neg_boot = sorted(set(planted) - set(boot))
    print(f"Bootstrap false discoveries: {false_pos_boot}")
    print(f"Bootstrap false negatives: {false_neg_boot}")
    print(f"Exact recovery achieved: {boot == planted}")

Project specification

Context
An investment committee manages capital across 40 equity mutual funds with 5-year track records (60 monthly returns). Multiple funds exhibit positive Jensen's alphas and t-statistics exceeding 1.65, leading sales executives to claim proven investment skill. The committee's quantitative analyst must formally test how many funds appear skilled by chance alone, apply a cross-sectional bootstrap to recover the true skilled set, and document the findings in a formal memorandum.
Inputs
A SIMULATED universe generated by make_instance(seed) from grader/instance.py. The dictionary contains:
  • returns: list of 40 lists, each containing 60 monthly excess returns (floats in decimal).
  • factor: list of 60 monthly excess returns of the market benchmark factor.
  • planted_skill: sorted list of fund indices with true planted alpha.
  • planted_alpha: list of 40 true monthly alphas (zero for non-skilled funds).
Required outputs
Two deliverables:
  1. fund_skill.py: Python module exposing the three functions: 
    alpha_and_t(returns, factor) -> tuple[float, float]
chance_count(t_stats, critical) -> int
bootstrap_skilled_set(
    returns, factor, level, n_boot, seed
) -> list[int]
  2. memo.md: Investment committee memorandum reporting the naive count, the expected chance benchmark \(N\eta\), the bootstrap methodology and critical threshold, false-positive/negative counts against the planted truth, and real-world limits to the simulated exercise.
Constraints
Standard library only (math, random). Code must execute cleanly without external dependencies in both Pyodide and local pytest. Invalid inputs must raise ValueError with exact descriptive condition messages:
  • len(returns) < 3 or mismatched lengths: "need at least 3 months and equal lengths"
  • Constant factor (\(S_{ff} \le 10^{-15}\)): "the factor must vary"
  • Exact fit with zero residual variance (\(\text{RSS} \le 10^{-15}\)): "residuals are zero; the t-statistic is undefined"
  • Bootstrap level outside \((0, 1)\): "level must lie strictly between 0 and 1"
  • Replications \(n_{\text{boot}} < 1\): "n_boot must be at least 1"
Grading
Grading is based on both an autograder (evaluating fund_skill.py across 50 consecutive seeds 0–49) and a rubric (grading memo.md across five observable performance dimensions).

Exemplars

Exemplar · Level 4 (Exemplary Submission)

TO: Investment Committee
FROM: Senior Quantitative Analyst
DATE: November 10, 2026
SUBJECT: Fund Skill Evaluation: Naive Screening vs. Cross-Sectional Bootstrap

1. Executive Summary & Naive Screening

We evaluated 40 equity mutual funds with 60-month track records against the market benchmark. Under a standard naive single-fund hurdle (\(\eta = 0.05, c = \Phi^{-1}(0.95) = 1.644854\)), 7 funds are flagged as possessing statistically significant positive alpha: Funds 7 (\(\hat t = 1.84\)), 13 (\(\hat t = 4.82\)), 18 (\(\hat t = 5.21\)), 22 (\(\hat t = 1.76\)), 35 (\(\hat t = 4.95\)), 37 (\(\hat t = 5.12\)), and 38 (\(\hat t = 5.34\)). All \(t\)-statistics are computed from unrounded OLS estimates where \(s^2 = \text{RSS}/(T-2)\).

2. Theoretical Chance Benchmark

Under the global null hypothesis of zero skill (\(\alpha_i = 0\)), each test rejects with probability \(\eta = 0.05\). By linearity of expectation, the expected number of false discoveries is \(\E[N_{\text{flagged}}] = N\eta = 40 \times 0.05 = 2.0\text{ funds}\). The observation of 7 flagged funds exceeds the expected luck baseline by 5 funds, indicating the presence of skill in the population, but warning that approximately 2 of the 7 flagged funds represent lucky pretenders.

3. Bootstrap Skill Test

To control the family-wise error rate without distributional assumptions, we deployed a residual bootstrap (200 replications, Seed 1000). To enforce the null, we resampled OLS residuals with replacement using shared month draws across all funds to preserve contemporaneous cross-sectional covariance. The 95% quantile of the cross-sectional maximum \(t\)-statistic established a critical threshold of \(c_{\text{boot}} = 2.8450\). Only 5 funds exceed this threshold: Funds [13, 18, 35, 37, 38].

4. Ground-Truth Recovery & Allocation Impact

Benchmarked against the planted ground truth (Funds [13, 18, 35, 37, 38]):

  • Naive Screening: 2 False Positives (Funds 7 and 22), 0 False Negatives. Allocating to naive stars would waste capital on zero-skill funds that will mean-revert to market returns minus management fees.

5. Real-World Limitations & Literature Context

These findings must be interpreted in light of the simulation's structure: (1) frictionless trading ignores execution costs; (2) no delisting bias is present, whereas commercial databases suffer from survivorship truncation (Carhart 1997); and (3) a single-factor model was assumed, whereas empirical anomalies require multi-factor adjustments. In live mutual fund cross-sections, Fama and French (2010) and Barras et al. (2010) show that fewer than 2% of managers possess net skill beyond luck.
