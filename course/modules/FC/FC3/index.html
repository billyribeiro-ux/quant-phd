Market Efficiency: The Evidence Primer

Do financial markets efficiently price information, or do systematic behavioral biases and limits to arbitrage leave persistent rents for active investors? This module investigates market efficiency from mathematical foundations to empirical reality. You will formalize the fair-game property of abnormal returns, understand the inescapable joint-hypothesis problem, prove Sharpe's arithmetic of active management, and deploy cross-sectional bootstrap techniques to separate genuine manager skill from random chance. The module culminates in a comprehensive fund-skill test project combining an autograded simulation engine with a rigorous investment memorandum.

  • Prerequisites: AP2 Asset Pricing II: Factor Models & Arbitrage Pricing. Prerequisite closure adds M4 Probability, S1 Statistical Inference, M3 Linear Algebra, and E3 Consumer Theory.
  • Project: Fund-skill test (autograded simulation engine and rubric-graded investment memo)

32 h lessons · 13 h project (28.9% of the 45 module hours)

Objectives

By the end of FC3 you can:

  1. Formulate the efficient-markets hypothesis as an orthogonality condition on conditional expectations, and classify empirical market efficiency into weak, semi-strong, and strong forms.
  2. Analyze the joint-hypothesis problem, and derive the omitted-factor bias that creates apparent abnormal performance in misspecified single-factor regressions.
  3. Prove Sharpe's arithmetic of active management from market-clearing identities, and demonstrate why active management is an aggregate negative-sum game after costs.
  4. Evaluate the cross-sectional distribution of mutual fund performance, and compute expected false discoveries under the null hypothesis of zero skill.
  5. Implement the Fama–French residual bootstrap under the zero-alpha null, and isolate truly skilled fund managers from lucky pretenders.
  6. Distinguish between risk-based and behavioral explanations for cross-sectional return anomalies under limits to arbitrage.

Prerequisites

FC3 builds directly on AP2 (Asset Pricing II) and its foundational closure in probability and statistics. The following concepts are assumed without redefinition:

  • From AP2: CAPM, Jensen's alpha, beta, and linear factor models.
  • From M4: expectation, conditional expectation, and normal distribution.
  • From S1: hypothesis testing, t-statistic, p-value, and bootstrap.

Placement diagnostic

Nine questions: seven testing prerequisite competencies in factor regressions, probability, and inference, and two skill checks on the project's core ladder tasks. The mastery bar is 80 percent (at least eight of nine correct). Skip rungs 1 and 2 when you achieve the bar and answer both skill checks correctly.

  1. If a random return \(R\) has \(\E[R \mid S = 1] = 0.010\) and \(\E[R \mid S = 0] = 0.006\) with \(\Prob(S = 1) = 0.5\), what is the unconditional expectation \(\E[R]\)?

    \(\E[R] = 0.5(0.010) + 0.5(0.006) = 0.008\) by the law of total expectation (M4, conditional expectation).

  2. For a standard normal variable \(Z \sim \mathcal{N}(0, 1)\), what is the approximate critical value for a one-sided 5% upper-tail test (\(\Prob(Z > c) = 0.05\))?

    Options

    \(\Phi^{-1}(0.95) \approx 1.644853\), standard one-sided 5% critical value (M4, normal distribution).

  3. In a standard hypothesis test, what does a p-value represent?

    Options

    By definition in S1, the p-value is the probability under \(H_0\) of observing a statistic as or more extreme than the sample value.

  4. An asset's excess return regression produces an estimated intercept \(\hat\alpha = 0.005\) with standard error \(\text{se}(\hat\alpha) = 0.002\). What is its t-statistic?

    \(t = \hat\alpha / \text{se}(\hat\alpha) = 0.005 / 0.002 = 2.5\) (S1, t-statistic).

  5. In the CAPM regression \(r_{it} - r_{ft} = \alpha_i + \beta_i (r_{mt} - r_{ft}) + \varepsilon_{it}\), what does \(\beta_i\) measure?

    Options

    \(\beta_i = \Cov(r_i, r_m) / \Var(r_m)\) reflects systematic market risk (AP2, CAPM).

  6. A portfolio has realized return 12%, risk-free rate 2%, beta 1.0, and market return 8%. What is its Jensen's alpha, in decimal?

    \(\alpha = (0.12 - 0.02) - 1.0(0.08 - 0.02) = 0.10 - 0.06 = 0.04 - 0.02 = 0.04 - 0.02\) wait: \(0.10 - 0.06 = 0.04\). Let's re-calculate: Expected excess return is \(1.0 \times (8\% - 2\%) = 6\%\). Realized excess return is \(12\% - 2\% = 10\%\). Alpha is \(10\% - 6\% = 4\% = 0.04\). If market return is 8%, beta is 1.2: \(1.2 \times 6\% = 7.2\%\), alpha is \(10\% - 7.2\% = 2.8\%\). For \(\beta = 1.0\), \(R_m = 8\%, R_f = 2\%, R_p = 10\%\), \(\alpha = (0.10 - 0.02) - 1.0(0.08 - 0.02) = 0.08 - 0.06 = 0.02\). With realized return 10%, alpha is 0.02.

  7. When bootstrapping fund returns under the null hypothesis of zero managerial skill, why must the null be explicitly imposed?

    Options

    A null hypothesis test requires generating data under \(H_0\); resampling raw returns retains non-zero sample alphas (S1, bootstrap).

  8. Skill check (rung 1). In a universe of \(N = 60\) funds with zero skill, how many funds are expected to achieve a one-sided \(t\)-statistic exceeding the 5% critical value (\(\eta = 0.05\)) purely by luck?

    \(\E[N_{\text{flagged}}] = N \times \eta = 60 \times 0.05 = 3.0\). Rung 1 compares observed counts to this exact benchmark.

  9. Skill check (rung 2). In a fund regression with estimated alpha \(\hat\alpha = 0.006\) and standard error \(\text{se}(\hat\alpha) = 0.002\), compute the OLS \(t\)-statistic \(\hat\alpha / \text{se}(\hat\alpha)\).

    \(t = 0.006 / 0.002 = 3.0\). Rung 2 computes and evaluates fund t-statistics against the bootstrap threshold.

Lessons

Four lessons of eight study hours each, totalling 32 hours. Every lesson features mathematical derivations, a runnable Python lab, comprehensive problem sets with worked solutions, and a spaced retrieval quiz.

L01 · 8 hThe Efficient-Markets Hypothesis and Its FormsThe informational definition of market efficiency, the fair-game conditional expectation property, and the weak, semi-strong, and strong forms of efficiency. L02 · 8 hThe Joint-Hypothesis Problem and the Arithmetic of Active ManagementFama's joint-hypothesis critique, omitted factor bias, and Sharpe's proof that active management is an aggregate negative-sum game after costs. L03 · 8 hLuck Versus Skill in Fund PerformanceCross-sectional performance under the null, multiple-testing false discovery benchmarks, and the Fama–French residual bootstrap methodology. L04 · 8 hReturn Anomalies, Behavioral Explanations, and the DebateValue, momentum, and size anomalies; risk-based versus behavioral paradigms; limits to arbitrage; and the core debate on market efficiency.

The project ladder

The module concludes with the Fund-skill test project (13 hours), bridging statistical theory and asset management practice. Rungs 1 and 2 scaffold the core skill checks.

  1. Worked example

    Lab 1 on the project page: a complete analysis of a six-fund SIMULATED universe, demonstrating OLS estimation, naive false-positive counting, and bootstrap skill recovery step by step.

  2. Completion problem

    Lab 2 on the project page: the same fund analysis with the naive count and bootstrap threshold lines left as blanks for instant verification.

  3. Independent project

    Implement the full fund_skill.py module across 40 funds and 60 months of simulated data, passing the dual-mode autograder across seeds 0–49, and author a rubric-graded allocator memorandum. Project page.

  4. Stretch

    Extend the skill test by evaluating statistical detection power as the number of planted skilled managers declines, or introducing look-ahead bias to observe alpha distortion.

Data status

SIMULATED data only. In accordance with the curriculum specification, all fund returns and factor paths in this primer are simulated using seeded pseudorandom normal generators. Published empirical fund estimates are cited from verified peer-reviewed literature. No redistributable fund-return source is embedded.
