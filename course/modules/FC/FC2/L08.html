Implied volatility

  • Uses: Black–Scholes formula, model-free option bounds, call payoff, limit, derivative
  • Introduces: implied volatility (defined in §1)
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study or lab

A quoted option price is often read as a volatility. Under the Black–Scholes formula of Lesson 7, each volatility gives one price, so a price can be read back as a volatility. This lesson shows when that reading exists and is unique, and gives a bisection (defined in Section 3) that finds it to a stated tolerance. A price outside the model-free bounds of Lesson 5 has no volatility under the formula, and the lesson names that condition. The lab checks the inversion on prices the formula itself produces, so it tests the code and the formula, not any quote.

1Definition and setting

Fix the spot \(S > 0\), the strike \(K > 0\), the rate \(r\) and the maturity \(\tau > 0\). Assumptions A1 to A5 and A7 of Lesson 7 are in force. Write \(C(\sigma)\) for the Black–Scholes call value of Lesson 7, Definition 1.3, as a function of the volatility \(\sigma > 0\), with the other inputs held fixed. The lower bound of Lesson 5 for a European call, with the same inputs, is

\[ L = \max\big(S - Ke^{-r\tau},\ 0\big). \]
Definition 1.1 (Implied volatility)

Let \(C^\ast\) be an observed price of the call. The implied volatility is the number \(\sigma^\ast > 0\), if one exists, with \(C(\sigma^\ast) = C^\ast\). It is defined from the price, the inputs \(S\), \(K\), \(r\), \(\tau\) and the model. It does not use the stock's history.

2Monotonicity and the range of prices

Lemma 2.1 (Vega)

For \(\sigma > 0\), the derivative \(dC/d\sigma\), called the vega, equals \(S\,\varphi(d_1)\sqrt{\tau}\), which is positive. Here \(\varphi\) is the standard normal density of Lesson 7.

Proof

Let \(a = \ln(S/K) + r\tau\) and \(s = \sigma\sqrt{\tau}\). Then \(d_1 = a/s + s/2\) and \(d_2 = a/s - s/2\). Since \(\partial s/\partial\sigma = \sqrt{\tau}\),

\[ \frac{\partial d_1}{\partial\sigma} - \frac{\partial d_2}{\partial\sigma} = \Big(-\frac{a\sqrt{\tau}}{s^2} + \frac{\sqrt{\tau}}{2}\Big) - \Big(-\frac{a\sqrt{\tau}}{s^2} - \frac{\sqrt{\tau}}{2}\Big) = \sqrt{\tau}. \]

Next, \(S\varphi(d_1) = Ke^{-r\tau}\varphi(d_2)\). Take logarithms of both sides, using \(\varphi(x) = e^{-x^2/2}/\sqrt{2\pi}\): the difference is \(\ln(S/K) + r\tau - (d_1^2 - d_2^2)/2\). Since \(d_1 - d_2 = s\) and \(d_1 + d_2 = 2a/s\), \((d_1^2 - d_2^2)/2 = a\), so the difference is zero.

Now, using \(\Phi' = \varphi\),

\[ \frac{dC}{d\sigma} = S\varphi(d_1)\frac{\partial d_1}{\partial\sigma} - Ke^{-r\tau}\varphi(d_2)\frac{\partial d_2}{\partial\sigma} = S\varphi(d_1)\Big(\frac{\partial d_1}{\partial\sigma} - \frac{\partial d_2}{\partial\sigma}\Big) = S\varphi(d_1)\sqrt{\tau}. \]

This is positive because \(S > 0\), \(\tau > 0\) and \(\varphi > 0\). \(\blacksquare\)

Lemma 2.2 (Limits in volatility)

\(\displaystyle\lim_{\sigma \to \infty} C(\sigma) = S\) and \(\displaystyle\lim_{\sigma \to 0^+} C(\sigma) = L\).

Proof

As \(\sigma \to \infty\), \(a/s \to 0\), so \(d_1 \to +\infty\) and \(d_2 \to -\infty\). Then \(\Phi(d_1) \to 1\) and \(\Phi(d_2) \to 0\), and \(C(\sigma) \to S\).

As \(\sigma \to 0^+\), \(s \to 0\), and there are three cases. If \(a > 0\), then \(a/s \to +\infty\), so \(d_1, d_2 \to +\infty\), \(C \to S - Ke^{-r\tau}\), which equals \(L\) because \(a > 0\) means \(S > Ke^{-r\tau}\). If \(a < 0\), then \(d_1, d_2 \to -\infty\), \(C \to 0 = L\). If \(a = 0\), then \(d_1 = s/2 \to 0\) and \(d_2 = -s/2 \to 0\), so \(\Phi(d_1), \Phi(d_2) \to 1/2\), and \(C \to S/2 - Ke^{-r\tau}/2 = 0 = L\), because \(a = 0\) gives \(S = Ke^{-r\tau}\). \(\blacksquare\)

Theorem 2.3 (Existence and uniqueness of the implied volatility)

For \(C^\ast\) given, there is exactly one \(\sigma^\ast > 0\) with \(C(\sigma^\ast) = C^\ast\) if \(L < C^\ast < S\), and there is none if \(C^\ast \le L\) or \(C^\ast \ge S\).

Proof

Let \(\sigma > 0\). Strict monotonicity gives \(C(\sigma/2) < C(\sigma)\), and \(C(\sigma/2^k)\) decreases to \(L\) by Lemma 2.2, so \(L \le C(\sigma/2) < C(\sigma)\). Likewise \(C(\sigma) < C(2\sigma) \le S\), because \(C(2^k\sigma)\) increases to \(S\). So \(L < C(\sigma) < S\), and no \(\sigma > 0\) solves \(C(\sigma) = C^\ast\) when \(C^\ast \le L\) or \(C^\ast \ge S\).

Let \(L < C^\ast < S\). By Lemma 2.2 there are \(\sigma_1\) with \(C(\sigma_1) < C^\ast\) and \(\sigma_2\) with \(C(\sigma_2) > C^\ast\). The intermediate value theorem gives a root in \([\sigma_1, \sigma_2]\). Strict monotonicity makes it the only root. \(\blacksquare\)

Theorem 2.3 is the answer to the question this lesson asks. A price strictly between the lower bound and the spot has one volatility. A price on or outside those bounds has none, so the implied volatility is not defined for it.

3Bisection to a stated tolerance

Definition 3.1 (Bisection bracket and step)

Let \(\sigma_{\text{lo}} < \sigma_{\text{hi}}\) be a bracket with \(C(\sigma_{\text{lo}}) < C^\ast\) and \(C(\sigma_{\text{hi}}) \ge C^\ast\), and let \(\tau_{\text{tol}} > 0\) be a tolerance. While \(\sigma_{\text{hi}} - \sigma_{\text{lo}} > \tau_{\text{tol}}\), repeat: set \(m = (\sigma_{\text{lo}} + \sigma_{\text{hi}})/2\); if \(C(m) < C^\ast\), set \(\sigma_{\text{lo}} = m\), and otherwise set \(\sigma_{\text{hi}} = m\). When the loop ends, report \(\hat\sigma = (\sigma_{\text{lo}} + \sigma_{\text{hi}})/2\). The test is made before each step, so a bracket already within \(\tau_{\text{tol}}\) takes no step. The tolerance is written \(\tau_{\text{tol}}\) to keep \(\tau\) for maturity.

Proposition 3.2 (Bisection error and step count)

Let \(\sigma_{\text{lo},0} < \sigma_{\text{hi},0}\) satisfy the bracket condition of Definition 3.1 with \(C^\ast\) in \((L, S)\), and let \(W = \sigma_{\text{hi},0} - \sigma_{\text{lo},0}\). Then the procedure stops after the smallest \(k\) with \(W/2^k \le \tau_{\text{tol}}\), which is \(\lceil \log_2(W/\tau_{\text{tol}}) \rceil\) when \(W > \tau_{\text{tol}}\), and \(|\hat\sigma - \sigma^\ast| \le \tau_{\text{tol}}/2\).

Proof

By Theorem 2.3, \(\sigma^\ast\) is unique. Because \(C\) is strictly increasing, \(C(\sigma) < C^\ast\) for \(\sigma < \sigma^\ast\) and \(C(\sigma) \ge C^\ast\) for \(\sigma \ge \sigma^\ast\). The invariant \(\sigma_{\text{lo}} < \sigma^\ast \le \sigma_{\text{hi}}\) holds at the start, and each step keeps it: if \(C(m) < C^\ast\) then \(m < \sigma^\ast\), and if \(C(m) \ge C^\ast\) then \(m \ge \sigma^\ast\). Each step halves the width, so after \(k\) steps the width is \(W/2^k\), and the procedure stops at the first \(k\) with \(W/2^k \le \tau_{\text{tol}}\). Then \(\sigma^\ast\) lies in the final bracket, whose width is at most \(\tau_{\text{tol}}\), and the midpoint is within half the width of \(\sigma^\ast\). \(\blacksquare\)

Lab 1 uses the bracket \([10^{-6}, 10]\) and the tolerance \(10^{-10}\) for the volatility. Its code checks the bracket and raises a named error when the bracket \([10^{-6}, 10]\) does not contain the root, which happens when the price is too close to the lower bound or to the spot. A price that is strictly between the bounds but too close to the spot is rejected by this check even though it has a volatility (Theorem 2.3). The bracket condition of Definition 3.1 holds in every case the lab accepts.

Lab 1 · Implied volatility by bisection, with the outside-the-bounds check

Stated before running: for spot 100, \(r = 0.05\), \(\tau = 1\), and strikes 80, 100 and 120 with volatilities 0.10, 0.20 and 0.40, the bisection with tolerance \(10^{-10}\) recovers each input volatility to within the tolerance, using 37 halvings in every case. A price of 0, 4.00, 100.00 or 120.00 at strike 100 is rejected, because the lower bound is 4.8771 and the spot is 100. Expected result: each row's recovery error is below \(10^{-10}\), each row uses 37 halvings, and the four prices are rejected with the bounds message. The inputs are model values; no data are read.

"""Lab FC2-L08-1: implied volatility by bisection on the Black-Scholes call price.

For a European call with spot 100.00, strike K, r = 0.05 continuously compounded and
tau = 1 year, the Black-Scholes price C(sigma) is strictly increasing in sigma (Lesson 8,
Lemma 2.1), so the volatility that reproduces a quoted price is found by bisection.
The inputs are stated model parameters, not market data. Nothing is random and no file
is read.

Prices are model values in currency units. The table prints each price in integer
cents, rounded half up for display only: the inversion runs on the unrounded price, so
the recovered volatility is compared with the volatility that produced the price.
A price outside the no-arbitrage bounds max(S - K e^(-r tau), 0) < price < S has no
volatility, and is rejected with a ValueError that names the condition. The lab uses
the standard library only.
"""

from __future__ import annotations

import math

SPOT = 100.0
RATE = 0.05
TAU = 1.0
LOW_SIGMA = 1e-6  # bracket endpoints for the bisection, in volatility units
HIGH_SIGMA = 10.0
TOL = 1e-10  # stop when the bracket is at most TOL wide
CASES = (
    (80.0, 0.10),
    (80.0, 0.20),
    (80.0, 0.40),
    (100.0, 0.10),
    (100.0, 0.20),
    (100.0, 0.40),
    (120.0, 0.10),
    (120.0, 0.20),
    (120.0, 0.40),
)


def cents(amount: float) -> int:
    """Integer cents of a currency amount, rounded half up (away from zero for negatives)."""
    sign = -1 if amount < 0 else 1
    return sign * math.floor(abs(amount) * 100 + 0.5)


def norm_cdf(x: float) -> float:
    """Standard normal distribution function, (1 + erf(x / sqrt 2)) / 2."""
    return 0.5 * (1.0 + math.erf(x / math.sqrt(2.0)))


def bs_call(spot: float, strike: float, rate: float, tau: float, sigma: float) -> float:
    """Black-Scholes European call value, in currency units: S Phi(d1) - K exp(-r tau) Phi(d2)."""
    root = sigma * math.sqrt(tau)
    d1 = (math.log(spot / strike) + (rate + sigma * sigma / 2.0) * tau) / root
    d2 = d1 - root
    return spot * norm_cdf(d1) - strike * math.exp(-rate * tau) * norm_cdf(d2)


def lower_bound(spot: float, strike: float, rate: float, tau: float) -> float:
    """The model-free lower bound on a European call, max(S - K exp(-r tau), 0)."""
    return max(spot - strike * math.exp(-rate * tau), 0.0)


def implied_volatility(price: float, strike: float) -> tuple[float, int]:
    """Volatility sigma with bs_call(sigma) = price, by bisection, and the number of halvings used.

    Raises ValueError when the price is not strictly between the lower bound and the spot price.
    """
    bound = lower_bound(SPOT, strike, RATE, TAU)
    if not bound < price < SPOT:
        raise ValueError(
            "price outside the no-arbitrage bounds: a European call needs max(S - K e^(-r tau), 0) < price < S"
        )

    def gap(sigma: float) -> float:
        return bs_call(SPOT, strike, RATE, TAU, sigma) - price

    if not gap(LOW_SIGMA) < 0 <= gap(HIGH_SIGMA):
        raise ValueError(
            f"the volatility bracket [{LOW_SIGMA}, {HIGH_SIGMA}] does not contain the root: "
            "the price is too close to the lower bound or to the spot"
        )
    low, high = LOW_SIGMA, HIGH_SIGMA
    halvings = 0
    while high - low > TOL:
        middle = (low + high) / 2
        if gap(middle) < 0:
            low = middle
        else:
            high = middle
        halvings += 1
    return (low + high) / 2, halvings


def main() -> None:
    """Invert the price of each case, check the recovered volatility, and reject prices outside the bounds."""
    print(f"spot={SPOT} r={RATE} tau={TAU} tolerance={TOL} bracket=[{LOW_SIGMA}, {HIGH_SIGMA}]")
    print(f"lower bound for strike 100 = {lower_bound(SPOT, 100.0, RATE, TAU):.4f} currency units")
    print("strike  sigma_true  price_cents  sigma_recovered  halvings  abs_error")
    worst = 0.0
    for strike, sigma_true in CASES:
        price = bs_call(SPOT, strike, RATE, TAU, sigma_true)
        sigma_hat, halvings = implied_volatility(price, strike)
        error = abs(sigma_hat - sigma_true)
        worst = max(worst, error)
        print(
            f"{strike:>6.0f}  {sigma_true:>10.2f}  {cents(price):>11}  {sigma_hat:>15.8f}  {halvings:>8}  {error:>9.2e}"
        )
    print(f"largest absolute error over {len(CASES)} cases: {worst:.2e}; within the tolerance: {worst <= TOL}")

    print("prices with no volatility (strike 100)")
    for price in (0.0, 4.0, 100.0, 120.0):
        try:
            implied_volatility(price, 100.0)
        except ValueError as exc:
            print(f"  price {price:.2f}: rejected: {exc}")
        else:
            print(f"  price {price:.2f}: accepted")

    assert worst <= TOL
    assert len(CASES) == 9


main()

4Where the canon breaks

In this lesson the implied volatility is defined relative to the A7 formula \(C(\sigma)\), which fixes one volatility for every strike. Suppose two quotes with the same spot, rate and maturity, at strikes \(K_1\) and \(K_2\), give implied volatilities \(\sigma_1 \ne \sigma_2\) by Definition 1.1. Each implied volatility is unique by Theorem 2.3. If both quotes were prices of the A7 formula at one common volatility, each would invert to that volatility. So the two quotes are not both values of the formula at one common volatility. The lesson does not say which assumption fails, because the failure can be in A7, in A1 (income on the stock), in A2 (costs), in A4 (the rate), or in the quote itself.

The bisection is a numerical procedure. Proposition 3.2 gives its error and step count, and the lesson does not teach the general theory of root-finding methods. Lab 1 uses only the bisection, and its guarantee holds for the model's price function, not for any other.

A price on a model's bounds has no implied volatility, and Theorem 2.3 says so for the A7 formula only. An American call, or a call on a stock that pays income, needs a different price function, and the proof of Lemma 2.1 is a proof for the formula of this lesson.

5Misconceptions

  1. “Implied volatility is the stock's historical volatility.”

    Definition 1.1 uses the observed price \(C^\ast\), the spot, the strike, the rate, the maturity and the model. The stock's past prices do not enter, so the implied volatility can differ from a historical volatility estimate computed from the same stock.

  2. “Every option price has an implied volatility.”

    Theorem 2.3 gives an implied volatility only for a price strictly between \(L\) and \(S\). Lab 1 rejects the prices 0.00, 4.00, 100.00 and 120.00 at strike 100. The price 4.00 is below the lower bound of 4.8771, and 100.00 is the spot, so neither has a volatility.

  3. “A successful inversion check shows that a quoted price is right.”

    The inversion check in Lab 1 starts from the formula's own price and returns the volatility that produced it. It checks the inversion code and the formula. It does not test any quote, because no quote enters the lab.

6Problem set

Mechanics

M1 · The lower bound

For \(S = K = 100\), \(r = 0.05\) and \(\tau = 1\), find \(L\).

Solution

\(Ke^{-r\tau} = 100e^{-0.05} = 95.1229\), so \(L = 100 - 95.1229 = 4.8771\), and the unrounded value is 4.877058.

M2 · Which prices have a volatility

For the inputs of M1, which of the prices 4.00, 4.90 and 100.00 has an implied volatility?

Solution

By Theorem 2.3 the prices must lie strictly between \(L = 4.8771\) and \(S = 100\). The price 4.00 is below \(L\), and 100.00 equals \(S\), so neither has an implied volatility. The price 4.90 lies strictly between the two bounds, so it has exactly one.

M3 · Halvings for a tolerance

For the bracket \([10^{-6}, 10]\) and tolerance \(10^{-10}\), how many halvings does the procedure of Proposition 3.2 use?

Solution

The width is \(W = 10 - 10^{-6}\), so \(W/\tau_{\text{tol}} \approx 10^{11}\), and \(\log_2(10^{11}) = 36.54\). The procedure stops at the first \(k\) with \(W/2^k \le 10^{-10}\), which is \(k = 37\). At \(k = 36\) the width is \(10/2^{36} = 1.46 \times 10^{-10}\), which is still above the tolerance. Lab 1 prints 37 halvings in every row.

Proof

P1 · The identity behind vega

Show \(S\varphi(d_1) = Ke^{-r\tau}\varphi(d_2)\) without the logarithm step, by writing \(d_1^2 - d_2^2\) in terms of \(a\) and \(s\).

Solution

\(d_1^2 - d_2^2 = (d_1 - d_2)(d_1 + d_2) = s \cdot 2a/s = 2a\). Then \(\varphi(d_1)/\varphi(d_2) = e^{-(d_1^2 - d_2^2)/2} = e^{-a}\), and \(e^{-a} = e^{-\ln(S/K) - r\tau} = K e^{-r\tau}/S\). Hence \(\varphi(d_1)/\varphi(d_2) = Ke^{-r\tau}/S\), which is the identity.

P2 · The upper limit

Show that \(C(\sigma) \to S\) as \(\sigma \to \infty\), using only that \(\Phi\) is increasing with limits 0 and 1.

Solution

As \(\sigma \to \infty\), \(a/s \to 0\), so \(d_1 = a/s + s/2 \to \infty\), and \(d_2 = a/s - s/2 \to -\infty\). Since \(\Phi\) has limits 1 at \(+\infty\) and 0 at \(-\infty\), \(\Phi(d_1) \to 1\) and \(\Phi(d_2) \to 0\). Then \(C = S\Phi(d_1) - Ke^{-r\tau}\Phi(d_2) \to S\).

P3 · The bracket invariant

Show that the bisection of Definition 3.1 keeps \(\sigma_{\text{lo}} < \sigma^\ast \le \sigma_{\text{hi}}\) after each step.

Solution

If \(C(m) < C^\ast\), then \(m < \sigma^\ast\), because \(C\) is increasing and \(C(\sigma) \ge C^\ast\) for \(\sigma \ge \sigma^\ast\). Setting \(\sigma_{\text{lo}} = m\) keeps \(\sigma_{\text{lo}} < \sigma^\ast\), and \(\sigma_{\text{hi}}\) is unchanged. If \(C(m) \ge C^\ast\), then \(m \ge \sigma^\ast\), and setting \(\sigma_{\text{hi}} = m\) keeps \(\sigma^\ast \le \sigma_{\text{hi}}\). Either way the invariant holds.

Empirical

E1 · The largest recovery error

From Lab 1's table, what is the largest recovery error, and is it within the stated tolerance?

Solution

The largest absolute error printed is \(1.74 \times 10^{-11}\), in the rows with volatility 0.40, and the rows with volatility 0.10 print \(1.73 \times 10^{-11}\). The tolerance is \(10^{-10}\), so every row is within it. The largest error is 0.174 of the tolerance, that is \(1.74 \times 10^{-11}\) divided by \(10^{-10}\), using the printed error.

E2 · Why the lower bound is zero at strike 120

Explain why the table's row for strike 120 gives a price of 46 cents at volatility 0.10, and why the bound \(L\) for that strike is zero.

Solution

\(120e^{-0.05} = 114.15\), which exceeds the spot of 100, so \(S - Ke^{-r\tau} < 0\) and \(L = \max(\cdot, 0) = 0\). The call is then worth something positive for every positive volatility: \(C(\sigma)\) is strictly increasing (Lemma 2.1) and tends to \(L = 0\) as \(\sigma \to 0^+\) (Lemma 2.2). At volatility 0.10 the printed price is 46 cents, from the unrounded value 46.2497 cents.

E3 · Predict the rejection

Predict whether a price of 0.50 at strike 120 is accepted or rejected, and say which condition decides.

Solution

At strike 120 the lower bound is \(L = 0\), so 0.50 is strictly above it and strictly below the spot of 100. The bounds check passes, and the bracket test decides the rest. The bracket has a sign change, because \(C\) is near 0 at the lower end and above 0.50 at the upper end. The price is accepted. Running the lab's inversion on this price gives a volatility of 0.102077 after 37 halvings, although Lab 1 does not print this case. The bounds message appears only for a price at or below 0 or at or above 100 at this strike.

Research

R1 · What monotonicity needs

State the property of a price function that Theorem 2.3 needs, and say which of the lessons of FC2 provides it for the formula of this lesson.

Solution

The argument needs a price function of volatility that is continuous and strictly increasing, with the limits of Lemma 2.2. Lemma 2.1 proves the derivative is positive for the formula of Lesson 7, and that is the only price function this lesson covers. A different pricing model needs its own proof of the same property.

R2 · A one-cent error

At spot 100, strike 100, \(r = 0.05\), \(\tau = 1\), and volatility 0.20, the vega is 37.52 currency units per unit of volatility, to two decimals (Lemma 2.1: \(100\varphi(0.35) = 37.5240\)). Use the first-order approximation \(\Delta C \approx \text{vega} \cdot \Delta\sigma\) to estimate the change in implied volatility from a one-cent change in the quoted price.

Solution

The change in price is \(0.01\) currency units. Using the displayed vega 37.52, \(\Delta\sigma \approx 0.01/37.52 = 0.000267\), or 0.0267 volatility points, which is 0.027 to three decimals. (The unrounded vega 37.5240 gives 0.000266.) This is a first-order estimate of a local change, not a theorem. It shows why a one-cent quote error moves the implied volatility by a small amount near the money at these inputs.

R3 · The evidence a fit needs

State what evidence would show whether a single volatility under A7 fits the quoted prices of one expiry across several strikes. Name one input it would need. Make no claim about any market.

Solution

The test needs quoted call prices at several strikes for one expiry, the spot and the rate on each quote date, and the dividends over the life of the option, because A1 excludes income. From these the implied volatility of each quote follows by Definition 1.1, and the test asks whether they agree. The lesson cites no source for the inputs and makes no claim about any quote.
