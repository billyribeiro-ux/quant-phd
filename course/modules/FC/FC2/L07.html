The Black–Scholes formula and the binomial limit

  • Introduces: Black–Scholes formula (defined in §1)
  • Ttheorem

  • Bpublished, not settled
  • Csingle study or lab
  • Dlore

The tree of Lesson 6 prices a claim by arithmetic at its nodes. Under assumptions A7 and A8 (Section 1), a call has the closed-form price of Definition 1.3, for a model in which the stock's volatility \(\sigma\) (the standard deviation of its log return per square root of a year) is constant and the riskless rate \(r\) is continuously compounded. This lesson states the formula as assumption A8, under A7, and does not derive it. It then compares tree prices, whose parameters depend on the step count, with the closed form. The comparison is numerical: Section 3 says what Lab 1 shows and what it does not. Lesson 8 inverts the formula for volatility.

1The closed form under assumption A7

The lesson uses the standing assumptions A1 to A5 of Lesson 4, as they are used here: A1 (no income on the stock over the life of the option), A2 (no transaction costs, and lending and borrowing at the riskless rate), A3 (no arbitrage), A4 (the riskless rate \(r\) is constant over the life \(\tau\) and continuously compounded, so the discount factor to expiry is \(e^{-r\tau}\)), A5 (European exercise, at expiry only), and A7 and A8 (Section 1). The maturity is written \(\tau\), in years, and not \(T\).

Assumption A7 (Constant-volatility lognormal model)

The terminal stock price is lognormal: its logarithm is normally distributed, with a volatility \(\sigma > 0\) that is constant over the life of the option, and the same \(\sigma\) applies to every strike. The rate \(r\) is constant as in A4. A7 is a model assumption. The closed form is stated as A8 below and used; the lesson does not derive it from A7.

Lemma 1.1 (The normal distribution function by the error function)

The standard normal distribution function \(\Phi(x) = \int_{-\infty}^{x} \varphi(t)\,dt\), where \(\varphi(t) = e^{-t^2/2}/\sqrt{2\pi}\), satisfies \(\Phi(x) = \tfrac12\big(1 + \operatorname{erf}(x/\sqrt{2})\big)\), with \(\operatorname{erf}(y) = \tfrac{2}{\sqrt{\pi}}\int_0^{y} e^{-s^2}\,ds\).

Proof

Substitute \(t = \sqrt{2}\,s\), so \(dt = \sqrt{2}\,ds\): \(\Phi(x) = \frac{1}{\sqrt{\pi}}\int_{-\infty}^{x/\sqrt{2}} e^{-s^2}\,ds\). Since \(\int_{-\infty}^{0} e^{-s^2}\,ds = \int_0^{\infty} e^{-s^2}\,ds = \tfrac{\sqrt{\pi}}{2}\), the integral over \((-\infty, y]\) equals \(\tfrac{\sqrt{\pi}}{2}\big(1 + \operatorname{erf}(y)\big)\) with \(y = x/\sqrt{2}\). Dividing by \(\sqrt{\pi}\) gives the claim. \(\blacksquare\)

Lemma 1.2 (Symmetry of the normal distribution function)

For every real \(x\), \(\Phi(-x) = 1 - \Phi(x)\).

Proof

Since \(\varphi(-t) = \varphi(t)\), the substitution \(t \mapsto -t\) gives \(\Phi(-x) = \int_{-\infty}^{-x}\varphi(t)\,dt = \int_{x}^{\infty}\varphi(t)\,dt\). The total integral of \(\varphi\) is 1, so the last integral equals \(1 - \Phi(x)\). \(\blacksquare\)

Definition 1.3 (Black–Scholes call value)

The Black–Scholes formula gives the value of a European call with spot \(S\), strike \(K\), rate \(r\), maturity \(\tau\) and volatility \(\sigma\) as

\[ C = S\,\Phi(d_1) - K e^{-r\tau}\,\Phi(d_2), \qquad d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)\,\tau}{\sigma\sqrt{\tau}}, \qquad d_2 = d_1 - \sigma\sqrt{\tau}. \]

Black and Scholes (1973) is the source of this formula, and this lesson does not check that paper. Assumption A8 below takes this formula to be the call value of the model under A7. The lesson uses the formula, and it does not derive it (Section 4).

Assumption A8 (Closed form)

Under A7, the value of the European call is the value \(C\) of Definition 1.3, for every spot \(S > 0\), strike \(K > 0\), rate \(r\), maturity \(\tau > 0\) and volatility \(\sigma > 0\). A8 is a premise of this lesson and is not proved here. Each result that uses it states it.

Proposition 1.4 (The put from parity)

Under A1 to A5, A7 and A8, the European put with the same spot, strike and maturity has value

\[ P = C - S + K e^{-r\tau} = K e^{-r\tau}\,\Phi(-d_2) - S\,\Phi(-d_1), \]

where \(C\) is the value of Definition 1.3.

Proof

Put-call parity, from Lesson 5, states \(C - P = S - Ke^{-r\tau}\) under A1 to A5, which gives the first equality. For the second, use Definition 1.3 and Lemma 1.2:

\[ C - S + Ke^{-r\tau} = -S\big(1 - \Phi(d_1)\big) + Ke^{-r\tau}\big(1 - \Phi(d_2)\big) = Ke^{-r\tau}\Phi(-d_2) - S\Phi(-d_1). \quad \blacksquare \]
Proposition 1.5 (What the formula depends on)

Under Definition 1.3, \(C\) depends on \(S\), \(K\), \(r\tau\) and \(\sigma\sqrt{\tau}\) only. In particular it does not depend on the expected return of the stock.

Proof

Split the numerator of \(d_1\), using \((r + \sigma^2/2)\tau = r\tau + \sigma^2\tau/2\), and note that \(\dfrac{\sigma^2\tau/2}{\sigma\sqrt{\tau}} = \dfrac{\sigma\sqrt{\tau}}{2}\). So \(d_1 = \dfrac{\ln(S/K) + r\tau}{\sigma\sqrt{\tau}} + \dfrac{\sigma\sqrt{\tau}}{2}\). This uses only \(\ln(S/K)\), \(r\tau\) and \(\sigma\sqrt{\tau}\). Then \(d_2 = d_1 - \sigma\sqrt{\tau}\), and \(Ke^{-r\tau}\) depends on \(r\tau\). The formula contains no drift term. \(\blacksquare\)

2The binomial tree with fixed parameters

Definition 2.1 (Tree parameters for n steps)

For a number of steps \(n \ge 1\), let \(h = \tau/n\), and let \(u^{(n)} = e^{\sigma\sqrt{h}}\), \(d^{(n)} = 1/u^{(n)} = e^{-\sigma\sqrt{h}}\), \(R^{(n)} = e^{rh}\), and \(q^{(n)} = (R^{(n)} - d^{(n)})/(u^{(n)} - d^{(n)})\). The parameters are the same at every node, which is assumption A6′ of Lesson 6, and A6 holds at each node whenever \(r > 0\) and \(h < \sigma^2/r^2\) (Lemma 2.2).

Lemma 2.2 (The binomial condition for these parameters)

Let \(r > 0\) and \(\sigma > 0\). Then \(0 < d^{(n)} < R^{(n)} < u^{(n)}\) holds if and only if \(h < \sigma^2/r^2\).

Proof

The inequality \(0 < d^{(n)}\) holds because it is an exponential. Since \(\exp\) is strictly increasing, \(d^{(n)} < R^{(n)}\) is \(-\sigma\sqrt{h} < rh\), which holds because \(rh > 0 > -\sigma\sqrt{h}\). Also \(R^{(n)} < u^{(n)}\) is \(rh < \sigma\sqrt{h}\). Dividing by \(\sqrt{h} > 0\) gives \(r\sqrt{h} < \sigma\), that is \(h < \sigma^2/r^2\). \(\blacksquare\)

Theorem 2.3 (The n-step binomial call)

Under A1, A2, A3, A4, A5 and A7, with \(r > 0\) and \(h < \sigma^2/r^2\), the tree of Definition 2.1 prices the call at

\[ V_n = e^{-r\tau} \sum_{k=0}^{n} \binom{n}{k} \big(q^{(n)}\big)^{k} (1 - q^{(n)})^{n - k}\, \max\!\big(S \big(u^{(n)}\big)^{k} \big(d^{(n)}\big)^{n-k} - K,\ 0\big). \]
Proof

By Lemma 2.2, A6 holds at each node, and the parameters are the same at every node, which is A6′. Theorem 3.3 of Lesson 6 with \(N = n\) and gross return \(R^{(n)}\) gives the sum with the discount factor \(\big(R^{(n)}\big)^{-n} = e^{-rnh} = e^{-r\tau}\), since \(nh = \tau\). The payoff is that of Lesson 4 at expiry. \(\blacksquare\)

Assumption A7 concerns the terminal distribution of the stock, and A8 links the closed form to the model. Theorem 2.3 is an exact statement about a finite tree, and it does not use the closed form of Definition 1.3 or A8. A link from Theorem 2.3 to the formula is a limit, which Section 3 takes numerically and does not prove. The theorem needs \(r > 0\): at \(r = 0\) the condition \(h < \sigma^2/r^2\) is undefined, and this lesson does not state the theorem for \(r = 0\).

3Comparing the tree with the closed form

Definition 3.1 (Pricing error)

For \(n\) steps, the pricing error is \(e_n = V_n - C\), where \(V_n\) is the tree price of Theorem 2.3 and \(C\) is the value of Definition 1.3, both in currency units.

Lab 1 prices the call at nine step counts and prints each price in integer cents. The prices are positive and are rounded half up for display only. The error column is the unrounded difference, rounded half away from zero, because the error can be negative. In general the error column can differ by one cent from the difference of the two printed price columns, because the error is rounded from the unrounded difference. In the nine printed rows it does not differ. The lab prints the closed form, the nine tree prices and the errors. It does not extend the list, and it does not prove a limit.

Lab 1 · Binomial prices against the Black–Scholes value

Stated before running: with spot 100, strike 100, \(r = 0.05\), \(\sigma = 0.20\) and \(\tau = 1\), the closed form is 1045 cents and the tree prices at the stated step counts are printed beside it. The lab checks that \(\Phi(x) + \Phi(-x) = 1\) at four points and that the put from parity agrees with the separate put formula. Expected result: the error column is positive at 1, 5 and 25 steps, negative at 2, 10, 50, 100 and 200 steps, and 0 cents at 400 steps. All inputs are model values; no data are read.

"""Lab FC2-L07-1: binomial call prices against the Black-Scholes closed form.

The curriculum lab for FC2: a recombining binomial tree (up factor exp(sigma sqrt h),
down factor its reciprocal, gross return exp(r h) per period, h = tau / n) is priced for
each step count in STEPS, and each price is compared with the closed-form Black-Scholes
call under assumption A7. The inputs are model parameters (spot 100.00, strike 100.00,
r = 0.05 continuously compounded, sigma = 0.20, tau = 1 year), not market data and not
a forecast. Nothing is random and no file is read.

Money is printed in integer cents. Each price is the unrounded model value rounded half
up to the cent for display (the prices are positive). The error column is the unrounded
difference, rounded half away from zero, so it can differ by one cent from the difference
of the two printed columns. The
standard normal distribution function is computed from math.erf (standard library only).
The lab shows numbers; it does not prove that the binomial price converges to the
closed form.
"""

from __future__ import annotations

import math

SPOT_CENTS = 10_000
STRIKE_CENTS = 10_000
RATE = 0.05  # continuously compounded riskless rate r (A4)
SIGMA = 0.20  # volatility sigma (A7)
TAU = 1.0  # time to expiry in years
STEPS = (1, 2, 5, 10, 25, 50, 100, 200, 400)


def cents(amount: float) -> int:
    """Integer cents of a currency amount, rounded half away from zero."""
    sign = -1 if amount < 0 else 1
    return sign * math.floor(abs(amount) * 100 + 0.5)


def norm_cdf(x: float) -> float:
    """Standard normal distribution function, (1 + erf(x / sqrt 2)) / 2."""
    return 0.5 * (1.0 + math.erf(x / math.sqrt(2.0)))


def d_terms(spot: float, strike: float, rate: float, tau: float, sigma: float) -> tuple[float, float]:
    """The Black-Scholes d1 and d2 for the given inputs (sigma and tau positive)."""
    root = sigma * math.sqrt(tau)
    d1 = (math.log(spot / strike) + (rate + sigma * sigma / 2.0) * tau) / root
    return d1, d1 - root


def bs_call(spot: float, strike: float, rate: float, tau: float, sigma: float) -> float:
    """Black-Scholes European call value, in currency units: S Phi(d1) - K exp(-r tau) Phi(d2)."""
    d1, d2 = d_terms(spot, strike, rate, tau, sigma)
    return spot * norm_cdf(d1) - strike * math.exp(-rate * tau) * norm_cdf(d2)


def bs_put(spot: float, strike: float, rate: float, tau: float, sigma: float) -> float:
    """Black-Scholes European put value, from its own formula: K exp(-r tau) Phi(-d2) - S Phi(-d1)."""
    d1, d2 = d_terms(spot, strike, rate, tau, sigma)
    return strike * math.exp(-rate * tau) * norm_cdf(-d2) - spot * norm_cdf(-d1)


def binomial_call(spot: float, strike: float, rate: float, tau: float, sigma: float, steps: int) -> float:
    """Price of the European call on a recombining tree with steps periods, by backward induction."""
    h = tau / steps
    up = math.exp(sigma * math.sqrt(h))
    down = 1.0 / up
    gross = math.exp(rate * h)
    q = (gross - down) / (up - down)
    values = [max(spot * up**j * down ** (steps - j) - strike, 0.0) for j in range(steps + 1)]
    for _ in range(steps):
        values = [(q * values[j + 1] + (1.0 - q) * values[j]) / gross for j in range(len(values) - 1)]
    return values[0]


def main() -> None:
    """Price the call on each tree, compare with the closed form, and check the identities used."""
    spot, strike = SPOT_CENTS / 100, STRIKE_CENTS / 100
    d1, d2 = d_terms(spot, strike, RATE, TAU, SIGMA)
    print(
        f"parameters: spot={SPOT_CENTS} cents strike={STRIKE_CENTS} cents r={RATE} sigma={SIGMA} tau={TAU} years "
        "(model inputs, not market data)"
    )
    print(f"Black-Scholes d1={d1:.6f} d2={d2:.6f} Phi(d1)={norm_cdf(d1):.6f} Phi(d2)={norm_cdf(d2):.6f}")
    closed = bs_call(spot, strike, RATE, TAU, SIGMA)
    print(f"Black-Scholes call = {closed:.6f} currency units = {cents(closed)} cents")
    print("   n  binomial_cents  black_scholes_cents  error_cents")
    errors: dict[int, float] = {}
    for n in STEPS:
        tree = binomial_call(spot, strike, RATE, TAU, SIGMA, n)
        errors[n] = tree - closed
        print(f"{n:>4}  {cents(tree):>14}  {cents(closed):>19}  {cents(errors[n]):>11}")

    symmetric = all(abs(norm_cdf(x) + norm_cdf(-x) - 1.0) < 1e-15 for x in (0.0, 0.35, 1.7, 3.0))
    parity = abs((closed - spot + strike * math.exp(-RATE * TAU)) - bs_put(spot, strike, RATE, TAU, SIGMA)) < 1e-9
    print(f"Phi(x) + Phi(-x) = 1 at the test points: {symmetric}")
    print(f"put-call parity holds for the closed-form put to 1e-9: {parity}")
    assert norm_cdf(0.0) == 0.5
    assert symmetric
    assert parity
    assert abs(d1 - 0.35) < 1e-12 and abs(d2 - 0.15) < 1e-12

The closed form and the tree prices are computed from the same inputs, so the error column measures the tree's distance from the formula at these step counts. The sign of the error changes five times across the printed step counts, and the absolute error decreases along the list. These are facts about the nine values printed. The lab does not show that the error tends to zero as the number of steps grows without bound, and it does not show what the error is for a step count outside the list. The Black–Scholes value is the formula of Definition 1.3 under A7 and A8, and the lab's agreement with it is not evidence about any market.

4Where the canon breaks

The formula is stated as A8 and used, not derived. This lesson gives no derivation from a continuous-time model of the stock price and takes no limit of the tree. The concepts that such a derivation uses are not taught in FC2, so no step of Definition 1.3 is proved here. A reader who wants the derivation has to look outside this unit; no source for it is cited here.

Assumption A7 takes one volatility \(\sigma\) for every strike, constant over the life of each option. The formula inverts to one volatility per quoted price, and Lesson 8 shows that the inversion is unique when it exists. Whether quoted prices for different strikes imply the same volatility is therefore a test of A7, and this lesson makes no claim about any data set.

Assumption A5 limits the claim to exercise at expiry. A European call's value is given by the formula. An American call can be exercised before expiry. Its tree value needs the exercise payment of Lesson 4 (Definition 2.1) at each node, with the backward induction of Lesson 6 (Definition 3.2). This lesson does not apply that recursion to American exercise.

5Misconceptions

  1. “The binomial price approaches the closed form from one side.”

    Lab 1's error column changes sign. The tree price is above the closed form at 1, 5 and 25 steps, and below it at 2, 10, 50, 100, 200 and 400 steps. At 1 step the printed error is 171 cents, at 2 steps it is \(-91\) cents, at 5 steps it is 36 cents, and at 400 steps the unrounded error is \(-0.4998\) cents, which prints as 0. The sign at 400 steps is visible only in the unrounded value, not in the printed table. The sign pattern of the nine printed values is a fact about those values, and it is not a theorem of this lesson.

  2. “The Black–Scholes call value rises with the stock's expected return.”

    Definition 1.3 contains the rate \(r\), not the expected return of the stock. Proposition 1.5 shows that \(C\) depends on \(S\), \(K\), \(r\tau\) and \(\sigma\sqrt{\tau}\) only. Two inputs with the same \(S\), \(K\), \(r\tau\) and \(\sigma\sqrt{\tau}\) give the same price, whatever the expected return.

  3. “The put needs its own formula, and it is a separate result from the call.”

    Proposition 1.4 gives the put from the call and from parity. The two forms of the put in that proposition agree, and Lab 1 checks them against each other. Problem M2 computes the put for the lab's inputs from the call value and parity.

6Problem set

Mechanics

M1 · The arguments \(d_1\) and \(d_2\)

Find \(d_1\) and \(d_2\) for \(S = K = 100\), \(r = 0.05\), \(\sigma = 0.2\) and \(\tau = 1\).

Solution

\(\ln(S/K) = 0\), so \(d_1 = (0 + (0.05 + 0.02) \cdot 1)/(0.2 \cdot 1) = 0.07/0.2 = 0.35\). Then \(d_2 = 0.35 - 0.2 = 0.15\). Lab 1 prints the same values, \(d_1 = 0.350000\) and \(d_2 = 0.150000\).

M2 · The put for the same inputs

Using the call value of Lab 1 and Proposition 1.4, find the put value for the inputs of M1, in currency units and in cents.

Solution

The call is \(C = 10.450584\) currency units (Lab 1, unrounded value \(10.4505836\)). Also \(Ke^{-r\tau} = 100e^{-0.05} = 95.122942\). Then \(P = C - S + Ke^{-r\tau} = 10.450584 - 100 + 95.122942 = 5.573526\) currency units, which is 557 cents.

M3 · Tree parameters for four steps

For \(\tau = 1\), \(\sigma = 0.2\) and \(r = 0.05\), give \(u^{(4)}\), \(d^{(4)}\), \(R^{(4)}\) and \(q^{(4)}\) (Definition 2.1). Check Lemma 2.2's condition.

Solution

\(h = 1/4\), so \(\sigma\sqrt{h} = 0.1\) and \(u^{(4)} = e^{0.1} = 1.105171\), \(d^{(4)} = 1/u^{(4)} = 0.904837\), \(R^{(4)} = e^{0.0125} = 1.012578\). Then \(q^{(4)} = (R^{(4)} - d^{(4)})/(u^{(4)} - d^{(4)})\). With the unrounded inputs \(u^{(4)} = 1.10517092\), \(d^{(4)} = 0.90483742\) and \(R^{(4)} = 1.01257845\), this gives \(q^{(4)} = 0.5378084\), which rounds to 0.537808. From the six-place inputs as printed, the same quotient is \(0.107741/0.200334 = 0.537807\), so the sixth digit depends on which inputs are used. The condition \(h = 0.25 < \sigma^2/r^2 = 16\) holds, so \(0 < d^{(4)} < R^{(4)} < u^{(4)}\).

Proof

P1 · Symmetry

Prove Lemma 1.2 without the substitution in its proof, using only that \(\varphi\) is even and integrates to 1.

Solution

Let \(g(x) = \Phi(x) + \Phi(-x)\). Its derivative is \(\varphi(x) - \varphi(-x) = 0\), because \(\Phi'(x) = \varphi(x)\) by the fundamental theorem of calculus and \(\frac{d}{dx}\Phi(-x) = -\varphi(-x)\). So \(g\) is constant. As \(x \to -\infty\), \(\Phi(x) \to 0\) and \(\Phi(-x) \to 1\), so \(g = 1\). Hence \(\Phi(-x) = 1 - \Phi(x)\).

P2 · The parity algebra

Verify the second equality in Proposition 1.4 term by term.

Solution

Start from \(C - S + Ke^{-r\tau} = S\Phi(d_1) - Ke^{-r\tau}\Phi(d_2) - S + Ke^{-r\tau}\). Group the \(S\) terms and the \(Ke^{-r\tau}\) terms: \(-S(1 - \Phi(d_1)) + Ke^{-r\tau}(1 - \Phi(d_2))\). Lemma 1.2 turns \(1 - \Phi(d_1)\) into \(\Phi(-d_1)\) and \(1 - \Phi(d_2)\) into \(\Phi(-d_2)\), giving \(Ke^{-r\tau}\Phi(-d_2) - S\Phi(-d_1)\).

P3 · Where the condition comes from

Show that \(R^{(n)} < u^{(n)}\) holds exactly when \(h < \sigma^2/r^2\), for \(r > 0\).

Solution

\(R^{(n)} < u^{(n)}\) is \(e^{rh} < e^{\sigma\sqrt{h}}\), which is \(rh < \sigma\sqrt{h}\) because \(\exp\) is strictly increasing. Dividing by \(\sqrt{h} > 0\) gives \(r\sqrt{h} < \sigma\). Both sides are positive, so squaring is an equivalence and gives \(r^2 h < \sigma^2\), that is \(h < \sigma^2/r^2\).

Empirical

E1 · The step count with the smallest error

From Lab 1's table, which step count has the smallest absolute error, and what is that error in cents?

Solution

The table prints an error of 0 cents at 400 steps, and every other row has a nonzero error. The unrounded error at 400 steps is \(-0.0049977\) currency units, which is \(-0.4998\) cents, shown as 0. So 400 steps has the smallest absolute error in the table, at 0.4998 cents (the next smallest, 200 steps, is \(-0.9992\) cents unrounded).

E2 · Count the signs

Count the step counts in Lab 1 whose error is positive, and the ones whose error is negative.

Solution

Positive at 1, 5 and 25 steps (unrounded 171.17, 35.54 and 7.04 cents). Negative at 2, 10, 50, 100, 200 and 400 steps (unrounded \(-91.01\), \(-19.72\), \(-3.99\), \(-2.00\), \(-1.00\) and \(-0.50\) cents). Counted from the unrounded errors, that is three positive and six negative errors. Counted from the printed values, 400 steps shows 0, so there are three positive, five negative and one zero.

E3 · Check the one-step price by hand

Compute \(V_1\) for \(S = K = 100\), \(\tau = 1\), \(\sigma = 0.2\) and \(r = 0.05\), using Definition 2.1 and Theorem 2.3, and compare with Lab 1's first row.

Solution

\(u^{(1)} = e^{0.2} = 1.221403\), \(d^{(1)} = 0.818731\), \(R^{(1)} = e^{0.05} = 1.051271\), and \(q^{(1)} = 0.577493\). The up payoff is \(100 \cdot 1.221403 - 100 = 22.1403\), and the down payoff is 0. So \(V_1 = e^{-0.05} \cdot 0.577493 \cdot 22.1403 = 12.1623\) currency units, which is 1216 cents. That matches Lab 1's first row.

Research

R1 · What the table would need to show

State a test of whether the tree price converges to the closed form. Name the sequence of step counts, the error measure, and the outcome that would count against convergence. Make no claim about the outcome.

Solution

Use a sequence of step counts that increases without bound, and the error \(|V_n - C|\) in currency units. A result that counts against convergence is a sequence of errors that stays above a fixed positive number at large step counts, or that grows. A result that agrees with convergence is an error that falls below every fixed positive number after some step count. Lab 1 covers only nine step counts, so it can support neither outcome, and this lesson draws no conclusion from it.

R2 · Two inputs with one price

Find a second set of inputs \((\sigma, \tau, r)\) with \(\tau\) different from 1 that gives the call value of Lab 1, with \(S = K = 100\) unchanged, using Proposition 1.5.

Solution

Take \(\tau = 4\), \(\sigma = 0.1\) and \(r = 0.0125\). Then \(\sigma\sqrt{\tau} = 0.2\) and \(r\tau = 0.05\), the same as in Lab 1. By Proposition 1.5, with \(S = K = 100\) unchanged, the call value is 10.450584, which is 1045 cents, the same value as Lab 1's closed form. The price depends on the inputs only through \(r\tau\) and \(\sigma\sqrt{\tau}\), so changing \(\tau\) while both products stay fixed leaves it unchanged.

R3 · The evidence a comparison needs

State what evidence would show whether the Black–Scholes formula matches the prices of traded options, and name one input it would need that this lesson does not have. Make no claim about any market.

Solution

The test needs quoted option prices for several strikes and maturities, the spot price and the riskless rate on each quote date, and the dividends paid over the option lives. The formula assumes no dividends (A1), so the dividend record is needed to judge that assumption. This lesson cites no source for any of these inputs, and it makes no claim about any market.
