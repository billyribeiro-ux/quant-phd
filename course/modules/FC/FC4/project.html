Initiation-of-Coverage Report

Write a professional sell-side format initiation-of-coverage report on a listed public equity: industry and competitive five-forces structure, rigorous financial valuation (Gordon growth perpetuity, multistage DDM, free cash flow to equity, and clean-surplus residual income), a scenario-weighted price target in integer cents, key operational risks, and explicit call-revision triggers. Your implementation valuation.py is autograded across randomized seeds, and your initiation memo is evaluated against an observable rubric with annotated exemplars.

The ladder

The project follows the four-rung learning ladder. Rungs 1 and 2 provide fully annotated and completion practice on a SIMULATED firm. Rung 3 is the graded deliverable (autograded code plus rubric-scored report). Rung 4 offers advanced stretch research.

  1. Rung 1 · Worked example

    Lab 1: a fully solved equity valuation model on a SIMULATED firm, walking through Gordon growth, multistage DDM, FCFE per share, residual income, and scenario target rounding.

  2. Rung 2 · Completion problem

    Lab 2: the core valuation routines with three critical formulas left as blanks, verified instantly against deterministic outputs.

  3. Rung 3 · Independent project

    The full dual deliverable: autograded valuation.py containing five exact functions, and the 1,500–2,500 word initiation memo initiation.md scored on a 6-criterion rubric.

  4. Rung 4 · Stretch

    Two-way sensitivity surfaces over discount rate \(r\) and terminal growth \(g\), and an extension comparing historical consensus analyst earnings surprises to fundamental intrinsic values.

Lab 1 · Worked example: complete valuation model

Calculates all five valuation metrics on a 5-year SIMULATED financial stream: Gordon growth value, multistage DDM equity value, FCFE per share, residual-income equity value, and a 3-scenario price target in whole cents rounded half-up.

"""Lab FC4-project-1: Rung 1 worked example: fully solved equity valuation (SIMULATED)."""

from fractions import Fraction


def gordon_value(d1: Fraction, r: Fraction, g: Fraction) -> Fraction:
    """Gordon growth perpetuity value D_1 / (r - g)."""
    assert r > g, "Discount rate must exceed perpetual growth rate"
    return d1 / (r - g)


def ddm_value(dividends: list[Fraction], r: Fraction, g: Fraction) -> Fraction:
    """Multistage dividend discount model value with terminal Gordon perpetuity."""
    factor = Fraction(1) + r
    pv_explicit = Fraction(0)
    disc = Fraction(1)
    for d in dividends:
        disc *= factor
        pv_explicit += d / disc

    n = len(dividends)
    terminal_d = dividends[-1] * (Fraction(1) + g)
    tv = gordon_value(terminal_d, r, g)
    pv_tv = tv / (factor**n)
    return pv_explicit + pv_tv


def fcfe_value_per_share(fcfe: list[Fraction], shares: Fraction, r: Fraction, g: Fraction) -> Fraction:
    """FCFE equity value per share with terminal Gordon perpetuity."""
    factor = Fraction(1) + r
    pv_explicit = Fraction(0)
    disc = Fraction(1)
    for f in fcfe:
        disc *= factor
        pv_explicit += f / disc

    n = len(fcfe)
    terminal_f = fcfe[-1] * (Fraction(1) + g)
    tv = gordon_value(terminal_f, r, g)
    pv_tv = tv / (factor**n)
    return (pv_explicit + pv_tv) / shares


def residual_income_value(
    book_value_0: Fraction, earnings: list[Fraction], dividends: list[Fraction], r: Fraction
) -> Fraction:
    """Residual income valuation under clean surplus: V_0 = B_0 + sum(RI_t / (1+r)^t)."""
    factor = Fraction(1) + r
    pv_ri = Fraction(0)
    b_prev = book_value_0
    disc = Fraction(1)

    for ni, d in zip(earnings, dividends, strict=True):
        ri = ni - r * b_prev
        disc *= factor
        pv_ri += ri / disc
        b_prev = b_prev + ni - d

    return book_value_0 + pv_ri


def scenario_price_target_cents(scenarios: list[tuple[Fraction, int]]) -> int:
    """Scenario-weighted target in integer cents rounded half-up: floor(E[V] + 1/2)."""
    tot_p = sum(p for p, _ in scenarios)
    assert tot_p == Fraction(1), "Probabilities must sum to 1"
    ev = sum(p * v for p, v in scenarios)
    num = 2 * ev.numerator + ev.denominator
    den = 2 * ev.denominator
    return num // den


def main() -> None:
    # Illustrative SIMULATED company fundamentals
    # 5-year explicit horizon
    r = Fraction(10, 100)  # Cost of equity r = 10%
    g = Fraction(3, 100)  # Perpetual growth g = 3%
    b0 = Fraction(2500, 100)  # Initial book value B_0 = $25.00 per share
    shares = Fraction(5000)  # 5,000 shares (or scaling factor)

    dividends = [Fraction(120, 100), Fraction(135, 100), Fraction(150, 100), Fraction(165, 100), Fraction(180, 100)]
    earnings = [Fraction(250, 100), Fraction(280, 100), Fraction(310, 100), Fraction(340, 100), Fraction(375, 100)]
    fcfe = [Fraction(140, 100), Fraction(160, 100), Fraction(180, 100), Fraction(205, 100), Fraction(230, 100)]
    # Scale FCFE to total equity for shares count
    fcfe_total = [f * shares for f in fcfe]

    # Scenarios for price target (Prob, Price in Cents)
    scenarios = [
        (Fraction(25, 100), 2200),  # Bear: 25% @ $22.00
        (Fraction(50, 100), 3100),  # Base: 50% @ $31.00
        (Fraction(25, 100), 4400),  # Bull: 25% @ $44.00
    ]

    # Execute valuation models
    val_gordon = gordon_value(dividends[0], r, g)
    val_ddm = ddm_value(dividends, r, g)
    val_fcfe_share = fcfe_value_per_share(fcfe_total, shares, r, g)
    val_ri = residual_income_value(b0, earnings, dividends, r)
    target_cents = scenario_price_target_cents(scenarios)

    print("SIMULATED Initiation-of-Coverage Valuation Model Output (Rung 1 Worked Example)")
    print(f"Cost of Equity r = {float(r):.2%}, Terminal Growth g = {float(g):.2%}")
    print("-" * 75)

    print("-" * 75)
    print(f"{'1. Pure Gordon Growth (D1/(r-g))':<36} ${float(val_gordon):15.2f} {val_gordon!s:>20}")
    print(f"{'2. Multistage DDM (5-yr + TV)':<36} ${float(val_ddm):15.2f} {val_ddm!s:>20}")
    print(f"{'3. FCFE Model (5-yr + TV)':<36} ${float(val_fcfe_share):15.2f} {val_fcfe_share!s:>20}")

    print("-" * 75)

Rung 3 · Specification

Context
You are an equity research associate initiating coverage on a publicly traded company. You must provide institutional clients with a complete investment thesis: an assessment of industry structure and competitive moats, a multi-model financial valuation (Gordon growth perpetuity, multistage DDM, FCFE, and residual income), a scenario-weighted 12-month price target in whole cents, key downside risks, and explicit call-revision triggers.
Inputs

SIMULATED Data for Autograder: The autograder provides a deterministic instance via instance.make_instance(seed) generating financial statement lines, cost of equity \(r\), terminal growth rate \(g\), share counts, and three scenario outcomes.

Real Company Fundamentals (Honest-Pending Note): The brief asks for an initiation on a real public company. This program embeds no company financial statements: no redistributable source for them is in the program's data registry yet. The autograder uses generated companies labelled SIMULATED. You supply your company's statements from its own filings as a bring-your-own-data CSV (columns: fiscal_year, net_income, dividends, book_equity, depreciation, capex, delta_nwc, net_borrowing, shares_outstanding). The file is processed locally in your browser and never leaves your device.

Required outputs

1. valuation.py: Python module implementing five functions adhering exactly to the API specified in the autograder panel:

gordon_value(d1: Fraction, r: Fraction, g: Fraction) -> Fraction
ddm_value(dividends: Sequence[Fraction], r: Fraction, g: Fraction) -> Fraction
fcfe_value_per_share(fcfe: Sequence[Fraction], shares: Fraction, r: Fraction, g: Fraction) -> Fraction
residual_income_value(book_value_0: Fraction, earnings: Sequence[Fraction], dividends: Sequence[Fraction], r: Fraction) -> Fraction
scenario_price_target_cents(scenarios: Sequence[tuple[Fraction, int]]) -> int

2. initiation.md: Sell-side initiation report (1,500–2,500 words) structured into Industry Analysis (Five Forces), Financial Modeling & Clean Surplus Integrity, Valuation & Reconciliation, Price Target & Scenarios, Key Investment Risks, and Call-Revision Triggers.

Constraints

All calculations in valuation.py must use exact rational arithmetic (fractions.Fraction) with no floating-point arithmetic in intermediate calculations. Price targets must be integers representing whole cents, rounded once using half-up rounding (\(\lfloor x + 1/2 \rfloor\)). Inputs violating mathematical validity (such as \(r \le g\), \(r \le -1\), \(d_1 < 0\), empty sequences, negative dividends, or probabilities not summing to 1) must raise ValueError.

Grading

Grading mode is both autograder and rubric. The autograder suite test_project.py runs deterministic property and invariant tests across 50 consecutive seeds (0–49). The written report initiation.md is evaluated by rubric across six observable criteria (C1–C6) using 4 performance levels.

Rubric & self-assessment

Scenarios & Price Target (C4): We assign probabilities: Bear 20% (\$18.50), Base 60% (\$28.00), Bull 20% (\$38.00). Sum of probabilities is exactly 1.0. Expected value is \$28.10 (2810 cents). The 12-month target is 2810 cents.
