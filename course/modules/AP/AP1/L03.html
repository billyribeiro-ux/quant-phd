Lesson 2 proved that an arbitrage exists exactly when no strictly positive state-price vector does. Both sides of that statement are systems of linear equations and inequalities, so a computer can decide which side holds, and hand you the portfolio or the state prices as proof. This lesson writes the decision as a linear program, shows why its answer is a certificate you can check without trusting the solver, and turns the same idea into the tightest price bounds that no arbitrage puts on a new payoff. A desk that quotes an option outside these bounds is offering money for nothing.

1Arbitrage conditions are linear

Keep the market \((X, p)\): \(S\) states, \(N\) assets, \(X \in \R^{S \times N}\), \(p \in \R^N\). An arbitrage is a portfolio \(\theta\) with \(X\theta \ge 0\), \(p^\top\theta \le 0\) and a nonzero cash-flow vector \((-p^\top\theta, X\theta)\) (Lesson 2, Definition 1.1). The first two conditions are linear inequalities. The third is not convex, because the set of nonzero vectors is not convex, and it is homogeneous: if \(\theta\) is an arbitrage, so is \(\lambda\theta\) for every \(\lambda > 0\). Both problems disappear if we ask instead for the cash flows to be as large as possible inside a box.

2The detection program

Definition 2.1 (arbitrage detection program)

The arbitrage detection program of the market \((X, p)\) is the linear program \[ V = \sup_{\theta \in \R^N} \; \mathbf 1^\top X\theta - p^\top\theta \quad\text{subject to}\quad 0 \le X\theta \le \mathbf 1, \qquad 0 \le -p^\top\theta \le 1. \] Its objective is the sum of the portfolio's cash flows, today's and every state's; its constraints say that each cash flow is nonnegative and at most one.

Proposition 2.2 (the program detects arbitrage)

The detection program is feasible and \(0 \le V \le S + 1\). The market has an arbitrage if and only if \(V > 0\), and then every feasible \(\theta\) with a positive objective is an arbitrage.

Proof

\(\theta = 0\) is feasible with objective 0, so \(V \ge 0\). Each of the \(S + 1\) cash flows is at most 1, so the objective is at most \(S + 1\). If a feasible \(\theta\) has a positive objective, its cash-flow vector is nonnegative (by the constraints) and has a positive sum, so it is nonzero: \(\theta\) is an arbitrage. Conversely, let \(\theta\) be an arbitrage, with cash-flow vector \(c \ge 0\), \(c \ne 0\), and let \(\lambda = 1/\max_j c_j > 0\). Then \(\lambda\theta\) has cash-flow vector \(\lambda c\), with entries in \([0, 1]\), so it is feasible, and its objective \(\lambda \sum_j c_j\) is positive. Hence \(V > 0\).

The box does two jobs. It makes the program bounded, so a solver returns a number instead of reporting an unbounded problem, and it picks one representative from each ray of arbitrage portfolios. Any other bounded normalization would do; this one keeps every constraint of the form "cash flow between 0 and 1".

Example 2.3 (the mispriced fund again)

Lesson 1's market: a bond \((1, 1, 1)\) at 0.96, a stock \((1.4, 1.1, 0.6)\) at 0.976, and a fund paying the sum of the two at 1.95. A solver returns \(\theta = (141, 140, -140)\) with \(V = 4 = S + 1\), the largest value possible. Check it by hand. The portfolio is 140 copies of the law-of-one-price violation \((1, 1, -1)\), each paying \(0.014\) today and nothing later, plus one bond. Its cost is \(140 \times (-0.014) + 0.96 = -1.96 + 0.96 = -1\), and its payoff is \(140 \times 0 + (1, 1, 1) = (1, 1, 1)\). Every cash flow is exactly 1. The program uses the violation to buy the bond for free, because the objective rewards every unit of every cash flow.

3Certificates in both directions

The fundamental theorem says that exactly one of two things exists: an arbitrage, or a strictly positive state-price vector. Each one is a certificate that the other does not exist, and each can be checked by matrix multiplication alone.

Theorem 3.1 (the alternative, as two checkable certificates)

For a market \((X, p)\), exactly one of the following holds:

  1. some \(\theta\) satisfies \(X\theta \ge 0\), \(p^\top\theta \le 0\), and \(\mathbf 1^\top X\theta - p^\top\theta > 0\);
  2. some \(\psi\) satisfies \(\psi \gg 0\) and \(X^\top\psi = p\).
Proof

A vector as in (a) has a nonnegative cash-flow vector with a positive sum, so it is an arbitrage; and every arbitrage satisfies (a), since a nonnegative nonzero vector has a positive sum. So (a) is the existence of an arbitrage, and the theorem is Lesson 2's Theorem 3.1.

A certificate of type (a) is verified by computing \(X\theta\) and \(p^\top\theta\); one of type (b) by computing \(X^\top\psi\) and checking signs. Neither check needs the solver that found the certificate, which matters, because solvers work in floating point with tolerances. The test for (b) is itself a linear program.

Proposition 3.2 (the state-price margin)

Let \(t^\ast = \sup \{ t \le 1 : X^\top\psi = p,\ \psi \ge t\mathbf 1 \}\), the state-price margin, with \(t^\ast = -\infty\) if no \(\psi\) solves \(X^\top\psi = p\). The market has no arbitrage if and only if \(t^\ast > 0\).

Proof

If \(t^\ast > 0\), some feasible \((\psi, t)\) has \(t > 0\), so \(\psi \ge t\mathbf 1 \gg 0\) solves (b) of Theorem 3.1, and there is no arbitrage. Conversely, if \(\psi \gg 0\) solves \(X^\top\psi = p\), then \((\psi, \min(1, \min_s \psi_s))\) is feasible with a positive \(t\), so \(t^\ast > 0\).

Lab 1 · Detecting a shaded price

A SIMULATED market of 12 states and 6 assets is priced by a strictly positive state-price vector, so it starts free of arbitrage. Asset 4 is then quoted below that value by increasing amounts. The lab first computes the lowest arbitrage-free price of asset 4 given the other five prices, \(\min\{\psi^\top x_4 : \psi \ge 0,\ \psi^\top x_n = p_n,\ n \ne 4\}\). Shading less than the gap between the fair price and that minimum should leave the detection value at 0 and the margin positive; shading more should make the detection value positive and the margin negative.

import numpy as np
from numpy.typing import NDArray
from scipy.optimize import linprog  # type: ignore[import-untyped]


def detect_arbitrage(payoffs: NDArray[np.float64], prices: NDArray[np.float64]) -> tuple[float, NDArray[np.float64]]:
    """Definition 2.1's linear program: max 1'X theta - p'theta s.t. X theta >= 0, p'theta <= 0,
    X theta <= 1, -p'theta <= 1. Returns (optimal value, optimal theta); the value is positive iff arbitrage."""
    n_states, n_assets = payoffs.shape
    a_ub = np.vstack([-payoffs, prices[None, :], payoffs, -prices[None, :]])
    b_ub = np.concatenate([np.zeros(n_states), [0.0], np.ones(n_states), [1.0]])
    c = -(payoffs.sum(axis=0) - prices)  # linprog minimizes
    res = linprog(c, A_ub=a_ub, b_ub=b_ub, bounds=[(None, None)] * n_assets, method="highs")
    return float(-res.fun), np.asarray(res.x)


def state_price_margin(payoffs: NDArray[np.float64], prices: NDArray[np.float64]) -> float:
    """Largest t <= 1 such that some psi >= t solves X'psi = p; positive iff strictly positive state prices exist."""
    n_states = payoffs.shape[0]
    c = np.zeros(n_states + 1)
    c[-1] = -1.0
    a_eq = np.hstack([payoffs.T, np.zeros((payoffs.shape[1], 1))])
    a_ub = np.hstack([-np.eye(n_states), np.ones((n_states, 1))])
    bounds = [(None, None)] * n_states + [(None, 1.0)]
    res = linprog(c, A_ub=a_ub, b_ub=np.zeros(n_states), A_eq=a_eq, b_eq=prices, bounds=bounds, method="highs")
    return float(res.x[-1]) if res.status == 0 else float("-inf")


# SIMULATED market: 12 states, 6 assets, priced by strictly positive state prices; then one price is shaded.
rng = np.random.default_rng(303)
X = 1.0 + 0.3 * rng.standard_normal((12, 6))
psi = rng.uniform(0.02, 0.14, 12)
fair = X.T @ psi
print("asset prices from psi >> 0:", np.round(fair, 4))

# The lowest arbitrage-free price of asset 4 given the other five: min psi'x_4 over psi >= 0 pricing the others.
others = [0, 1, 2, 4, 5]
res = linprog(X[:, 3], A_eq=X[:, others].T, b_eq=fair[others], bounds=[(0, None)] * 12, method="highs")
print(f"lowest arbitrage-free price of asset 4: {res.fun:.4f}, i.e. a shade of {fair[3] - res.fun:.4f}")

for shade in (0.0, 0.10, 0.20, 0.30):
    p = fair.copy()
    p[3] -= shade  # asset 4 quoted below its state-price value
    value, theta = detect_arbitrage(X, p)
    margin = state_price_margin(X, p)
    verdict = "arbitrage" if value > 1e-9 else "no arbitrage"
    print(f"shade {shade:.2f}: LP value {round(value, 6) + 0.0:.6f}, state-price margin {margin:+.6f} -> {verdict}")
asset prices from psi >> 0: [0.9743 1.097  0.9411 0.9862 0.9378 0.9754]
lowest arbitrage-free price of asset 4: 0.7783, i.e. a shade of 0.2078
shade 0.00: LP value 0.000000, state-price margin +0.061755 -> no arbitrage
shade 0.10: LP value 0.000000, state-price margin +0.042734 -> no arbitrage
shade 0.20: LP value 0.000000, state-price margin +0.003105 -> no arbitrage
shade 0.30: LP value 6.201973, state-price margin -0.036524 -> arbitrage

The two programs agree on every shade, as Theorem 3.1 requires: the detection value is positive exactly when the margin is negative. The lowest arbitrage-free price of asset 4 is 0.7783, a shade of 0.2078 below its fair value, which is why a shade of 0.20 is still arbitrage-free with a margin of only 0.003105, and 0.30 is not. A shade equal to the exact gap (0.2078358; the lab prints it rounded to 0.2078) would sit at the boundary, where the margin is zero and the classification depends on the solver's tolerance (Problem E2). The lab shows that no arbitrage tolerates a wide range of mispricing relative to one particular state-price vector: in a market with fewer assets than states, many state-price vectors exist, and the prices need to be consistent with only one of them.

4Arbitrage bounds on a new payoff

Lesson 2 showed that a new payoff \(z\) can be added at price \(c\) without creating an arbitrage exactly when \(c = \psi^\top z\) for some strictly positive state-price vector \(\psi\) (Lesson 2, Proposition 4.1). Two linear programs compute the range of such prices from the trader's side: the cheapest portfolio that pays at least \(z\) in every state, and the dearest that pays at most \(z\).

Theorem 4.1 (super-replication duality)

Let \((X, p)\) have no arbitrage, and suppose its payoff space \(M\) contains a strictly positive payoff \(u \gg 0\) (for instance a riskless bond). Let \(\Psi = \{\psi \in \R^S : \psi \ge 0,\ X^\top\psi = p\}\). Then for every \(z \in \R^S\), \[ \overline{c}(z) := \min_{\theta}\{p^\top\theta : X\theta \ge z\} = \max_{\psi \in \Psi} \psi^\top z, \qquad \underline{c}(z) := \max_{\theta}\{p^\top\theta : X\theta \le z\} = \min_{\psi \in \Psi} \psi^\top z, \] and all four optima are attained.

Proof

Step 1: \(\Psi\) is compact and nonempty, and the dual optima are attained. By Lesson 2's Theorem 3.1, \(\Psi\) contains a strictly positive vector. It is closed, as the intersection of closed sets. It is bounded: write \(u = X\theta_u\); every \(\psi \in \Psi\) has \(\psi^\top u = \psi^\top X\theta_u = p^\top\theta_u\), so \(\psi_s \le p^\top\theta_u / u_s\) for every \(s\), because the other terms of \(\psi^\top u\) are nonnegative. A continuous function on a nonempty compact set attains its maximum and minimum.

Step 2: weak duality. If \(X\theta \ge z\) and \(\psi \in \Psi\), then \(p^\top\theta = \psi^\top X\theta \ge \psi^\top z\), since \(\psi \ge 0\). So every super-replicating cost is at least \(\max_\Psi \psi^\top z\).

Step 3: the primal minimum is attained. Super-replication is feasible: \(t\theta_u\) pays \(tu \ge z\) for \(t \ge \max_s z_s/u_s\). Under the law of one price the cost of \(\theta\) depends only on its payoff \(y = X\theta\), through \(q(y) = \psi_0^\top y\) for any \(\psi_0 \in \Psi\) with \(\psi_0 \gg 0\). So the problem is to minimize \(\psi_0^\top y\) over \(y \in M\) with \(y \ge z\). For a feasible cost level \(c\), the set \(\{y \in M : y \ge z,\ \psi_0^\top y \le c\}\) is closed and bounded, because \(y_s \ge z_s\) and \(\psi_{0,s} y_s \le c - \sum_{r \ne s}\psi_{0,r} z_r\) for every \(s\). By compactness the minimum over it is attained.

Step 4: no gap. Let \(c > \max_\Psi \psi^\top z\). No strictly positive state-price vector gives \(z\) the price \(c\), so by Lesson 2's Proposition 4.1 the market enlarged by \(z\) at price \(c\) has an arbitrage \((\theta, a)\): \(X\theta + az \ge 0\), \(p^\top\theta + ac \le 0\), with nonzero cash flows. If \(a = 0\), \(\theta\) is an arbitrage in \((X, p)\), which has none. If \(a > 0\), take \(\psi \gg 0\) in \(\Psi\): \(0 \le \psi^\top(X\theta + az) = p^\top\theta + a\psi^\top z \le -ac + a\psi^\top z\), so \(\psi^\top z \ge c\), contradicting the choice of \(c\). So \(a < 0\), and \(\theta/|a|\) satisfies \(X\theta/|a| \ge z\) at cost \(p^\top\theta/|a| \le c\). Hence \(\overline{c}(z) \le c\) for every \(c\) above the dual maximum, and with Step 2, \(\overline{c}(z) = \max_\Psi \psi^\top z\).

Step 5: the lower bound. Apply Steps 2–4 to \(-z\): \(\max\{p^\top\theta : X\theta \le z\} = -\min\{p^\top\theta' : X\theta' \ge -z\} = -\max_\Psi \psi^\top(-z) = \min_\Psi \psi^\top z\).

For a textbook treatment of the link between no arbitrage and strictly positive pricing, Cochrane's Section 4.2 is titled "No Arbitrage and Positive Discount Factors"; this lesson's linear-programming form of the result is self-contained.

Theorem 4.1 is a strong duality theorem for a pair of linear programs: the trader's problem over portfolios and the pricing problem over state prices. Its proof used no general linear-programming duality, only the fundamental theorem and compactness, which is the sense in which the fundamental theorem is a duality theorem: the state prices are the multipliers on the payoff constraints of the super-replication problem.

Corollary 4.2 (the arbitrage-free interval)

Under the assumptions of Theorem 4.1, the set of prices at which \(z\) can be added without arbitrage is the single point \(q(z)\) if \(z \in M\), and the open interval \((\underline{c}(z), \overline{c}(z))\), with \(\underline{c}(z) < \overline{c}(z)\), if \(z \notin M\).

Proof

By Lesson 2's Proposition 4.1 the set is \(I = \{\psi^\top z : \psi \in \Psi_{++}\}\) with \(\Psi_{++} = \{\psi \gg 0 : X^\top\psi = p\}\). If \(z \in M\), \(\psi^\top z = q(z)\) for every state-price vector (Lesson 1, Problem P2). If \(z \notin M = (\ker X^\top)^\perp\), some \(v \in \ker X^\top\) has \(v^\top z \ne 0\). Given \(\psi \in \Psi_{++}\), the points \(\psi \pm \varepsilon v\) stay in \(\Psi_{++}\) for small \(\varepsilon > 0\) and give the prices \(\psi^\top z \pm \varepsilon v^\top z\) on both sides of \(\psi^\top z\): no point of \(I\) is an end point, so the convex set \(I\) is an open interval. Its closure is \([\underline{c}(z), \overline{c}(z)]\): every \(\psi \in \Psi\) is a limit of \((1 - t)\psi + t\psi_0 \in \Psi_{++}\) as \(t \downarrow 0\), for a fixed \(\psi_0 \in \Psi_{++}\), so \(I\) is dense in the image of \(\Psi\), which is \([\underline{c}(z), \overline{c}(z)]\) by Theorem 4.1. An open interval with that closure is \((\underline{c}(z), \overline{c}(z))\), and it is nonempty, so \(\underline{c}(z) < \overline{c}(z)\).

Example 4.3 (bounds on a call)

In the bond-and-stock market with the stock at 0.976, a call struck at 1, an option payoff \(\max(x_{\text{stock}} - 1, 0)\), pays \(z = (0.4, 0.1, 0)\). The state-price vectors form the segment between \(\psi^{(1)} = (0.5, 0, 0.46)\) and \(\psi^{(2)} = (0, 0.8, 0.16)\): both satisfy \(\sum\psi_s = 0.96\) and \(1.4\psi_1 + 1.1\psi_2 + 0.6\psi_3 = 0.976\), and each has a zero entry, so they are the ends of the line \(\psi_0 + tv\), \(v = (-0.5, 0.8, -0.3)\), inside the orthant. The call's value is linear along the segment, so its extremes are at the ends: \(\psi^{(1)\top}z = 0.2\) and \(\psi^{(2)\top}z = 0.08\). The call can be quoted anywhere in \((0.08, 0.20)\). The upper bound is the cost of buying 0.5 stock and selling 0.3 bonds, \(0.488 - 0.288 = 0.2\), which pays \((0.4, 0.25, 0)\ge z\); the lower bound is the value of 0.2 stock less 0.12 bonds, \(0.1952 - 0.1152 = 0.08\), which pays \((0.16, 0.1, 0) \le z\).

Lab 2 · Super-replication and its dual

For the call of Example 4.3, the four linear programs of Theorem 4.1 should return 0.20 and 0.08 from both sides, with the portfolios and the extreme state-price vectors of the example. Quoting the call at a price strictly inside the interval should leave a positive state-price margin; quoting it at either end should drive the margin to zero.

import numpy as np
from scipy.optimize import linprog  # type: ignore[import-untyped]

# Arbitrage bounds on a new payoff z: the primal (cheapest super-replication, dearest sub-replication) and the
# dual (extreme state-price values psi'z over psi >= 0 with X'psi = p) give the same numbers (Theorem 4.1).
X = np.array([[1.0, 1.4], [1.0, 1.1], [1.0, 0.6]])  # bond and stock, Lesson 1's three states
p = np.array([0.96, 0.976])
z = np.maximum(X[:, 1] - 1.0, 0.0)  # a call on the stock struck at 1
print("call payoff by state:", z)

free = [(None, None)] * 2
upper = linprog(p, A_ub=-X, b_ub=-z, bounds=free, method="highs")  # min p'theta s.t. X theta >= z
lower = linprog(-p, A_ub=X, b_ub=z, bounds=free, method="highs")  # max p'theta s.t. X theta <= z
print(f"super-replication: cost {upper.fun:.4f}, portfolio {np.round(upper.x, 4)}")
print(f"sub-replication:   value {-lower.fun:.4f}, portfolio {np.round(lower.x, 4)}")

nonneg = [(0, None)] * 3
dual_hi = linprog(-z, A_eq=X.T, b_eq=p, bounds=nonneg, method="highs")
dual_lo = linprog(z, A_eq=X.T, b_eq=p, bounds=nonneg, method="highs")
print(f"max psi'z over psi >= 0 pricing X: {-dual_hi.fun:.4f} at psi = {np.round(dual_hi.x, 4)}")
print(f"min psi'z over psi >= 0 pricing X: {dual_lo.fun:.4f} at psi = {np.round(dual_lo.x, 4)}")

# Any price strictly inside the interval admits strictly positive state prices; a price at an end does not.
for quote in (0.08, 0.14, 0.20):
    a_eq = np.vstack([X.T, z])
    b_eq = np.append(p, quote)
    c = np.zeros(4)
    c[-1] = -1.0

    res = linprog(
        c,
        A_ub=a_ub,
        b_ub=np.zeros(3),
        A_eq=np.hstack([a_eq, np.zeros((3, 1))]),
        b_eq=b_eq,
        bounds=[(None, None)] * 3 + [(None, 1.0)],
        method="highs",
    )
    print(f"call quoted at {quote:.2f}: largest smallest-state-price {round(float(res.x[-1]), 6) + 0.0:+.6f}")

The primal and dual values coincide, as Theorem 4.1 says, and the optimal state-price vectors are the two ends of the segment. Inside the interval the margin is positive (0.25 at 0.14); at either end it is zero, so the call cannot be quoted at exactly 0.08 or 0.20 without an arbitrage, as Corollary 4.2 says. The width of the interval, 0.12 on a payoff whose expected value under no particular measure is fixed, is the price of incompleteness: three states and two assets leave the call unspanned. The lab does not say where in the interval a market will quote the call; that needs preferences or a model, which no-arbitrage arguments do not supply.

5Where the canon breaks

  • Floating point. A solver, working in floating-point arithmetic, declares a constraint satisfied within a tolerance. At a price on the boundary of the arbitrage-free interval (Lab 1 near a shade of 0.20784) the certificate the solver returns can be an artefact of that tolerance (Problem E2). Verify any certificate independently, in exact or higher-precision arithmetic if the decision is close, and report how far from the boundary it is.
  • Bid and ask. With a bid–ask spread, that is, separate bid and ask prices, split \(\theta = \theta^+ - \theta^-\) with both parts nonnegative and charge \(p^{a\top}\theta^+ - p^{b\top}\theta^-\). The program stays linear and detects arbitrage net of the spread (Problem R1). The bounds of Theorem 4.1 then widen by the cost of trading the replicating portfolio.
  • Lots and capital. Real positions come in whole contracts and need margin. Example 2.3's arbitrage holds 141 bonds and 140 units of the stock and fund to collect one unit of cash; rounding to lots or capping gross exposure turns the problem into a mixed-integer or constrained program, and a small fractional arbitrage can vanish (Problem R2).
  • The states are a model. The program is exact for the payoff matrix it is given. For contractual payoffs on one underlying at one date, such as options at several strikes, the states can be the possible values of the underlying and the payoffs are not in doubt. For anything else, the matrix is an assumption, and a detected arbitrage may be an error in the matrix.

6Misconceptions

  1. “If the detection program returns 0, every price in the market is fair.”

    A value of 0 says that some strictly positive state-price vector prices every asset (Theorem 3.1). With fewer assets than states there are many such vectors, so the prices are consistent, not uniquely determined; Lab 1 shades one price by 0.20 without creating an arbitrage.

  2. “The arbitrage bounds are the range of a payoff's discounted expected value.”

    They are the extreme values of \(\psi^\top z\) over nonnegative state-price vectors (Theorem 4.1), which do not involve the probabilities at all. A state that is possible but unlikely can move a bound as much as a likely one (Lesson 2, Problem E2).

  3. “A payoff can be quoted at its upper arbitrage bound, since the bound is attained.”

    The bound is the cost of a portfolio that pays at least \(z\) in every state and strictly more in some state when \(z \notin M\). Quoting \(z\) at that cost lets anyone sell \(z\), buy the portfolio, pay nothing today and receive a nonnegative, sometimes positive, surplus: an arbitrage. The arbitrage-free prices form an open interval (Corollary 4.2), and Lab 2 shows the margin is zero at both ends.

  4. “The box in the detection program limits the size of the arbitrage you can find.”

    Arbitrages form a cone: any positive multiple of one is another (Section 1). The box picks one representative from each ray; it decides only whether an arbitrage exists, not how much can be made, which depends on constraints the program does not contain.

Mechanics

M1 · Verify a solver's certificate

For Lesson 2's Problem M1 (bond \((1, 1)\) at 0.95, stock \((1.2, 0.9)\) at 1.16), a solver returns \(\theta = (4, -10/3)\) for the detection program. Verify that it is feasible, compute its objective, and say what kind of arbitrage it is.

Solution

Payoff: \(4(1, 1) - \tfrac{10}{3}(1.2, 0.9) = (4 - 4, 4 - 3) = (0, 1)\), within \([0, 1]\) in both states. Cost: \(4 \times 0.95 - \tfrac{10}{3} \times 1.16 = 3.8 - 3.8667 = -0.0667\), so today's cash flow is \(0.0667 \in [0, 1]\). The objective is \(0 + 1 + 0.0667 = 1.0667\). It pays you \(1/15\) today and 1 in state 2: an arbitrage of both kinds at once. It is the short-stock, long-bond trade of Lesson 2's Problem M1, scaled so that the largest cash flow is 1.

M2 · Bounds on a put

In the market of Example 4.3, find the arbitrage bounds on a put struck at 1, paying \((0, 0, 0.4)\), in two ways: from the ends of the state-price segment, and from the call's bounds and put–call parity.

Solution

Segment ends: \(\psi^{(1)\top}z = 0.46 \times 0.4 = 0.184\) and \(\psi^{(2)\top}z = 0.16 \times 0.4 = 0.064\). So the put lies in \((0.064, 0.184)\). Parity: call minus put pays \(\max(x - 1, 0) - \max(1 - x, 0) = x - 1\), the stock minus one bond, which is in \(M\) with price \(0.976 - 0.96 = 0.016\). By Problem P3, the put's bounds are the call's shifted by \(-0.016\): \((0.08 - 0.016, 0.20 - 0.016) = (0.064, 0.184)\).

M3 · Digital options don't add up

In the same market, find the arbitrage bounds on each of the three digital payoffs \(e_1, e_2, e_3\), and compare the sum of the upper bounds with the price of the bond.

Solution

\(\psi^\top e_s = \psi_s\), so the bounds are the extremes of each coordinate along the segment: \(e_1 \in (0, 0.5)\), \(e_2 \in (0, 0.8)\), \(e_3 \in (0.16, 0.46)\). The upper bounds sum to \(1.76\), far above the bond's price of 0.96, although \(e_1 + e_2 + e_3 = \mathbf 1\) is the bond's payoff. Upper bounds are subadditive, not additive: \(\overline{c}(z + z') \le \overline{c}(z) + \overline{c}(z')\), since the sum of two super-replicating portfolios super-replicates the sum. They are attained by different state-price vectors, so they cannot all be quoted at once.

Proof

P1 · When the detection value is \(S + 1\)

Prove that \(V = S + 1\) if and only if some portfolio \(\theta\) has \(-p^\top\theta = 1\) and \(X\theta = \mathbf 1\): it pays 1 today and 1 in every state. Interpret the condition.

Solution

If such \(\theta\) exists, it is feasible and its objective is \(S + 1\), the upper bound, so \(V = S + 1\). Conversely, \(V = S + 1\) means the supremum of a sum of \(S + 1\) numbers each at most 1 equals \(S + 1\). The feasible set of portfolios may be unbounded, but the set of feasible cash-flow vectors is the intersection of the subspace \(L\) with the box \([0,1]^{1+S}\), which is compact, and the objective is continuous on it, so the supremum is attained at a cash-flow vector whose entries sum to \(S + 1\), all equal to 1. A portfolio producing it pays 1 today and 1 in every state. Such a portfolio exists if and only if the riskless payoff \(\mathbf 1\) is in \(M\) and some portfolio producing it has price \(-1\); under the law of one price that is \(q(\mathbf 1) = -1\), a negative bond price. Example 2.3 attains it differently, because the law of one price fails there: a violation can be scaled to give the bond away and pay 1 on top.

P2 · Why Theorem 4.1 assumes a positive payoff

Give a market with no arbitrage and no strictly positive payoff in \(M\) for which super-replication of some \(z\) is infeasible and \(\sup_{\psi \in \Psi}\psi^\top z = +\infty\).

Solution

Two states, one asset paying \((1, 0)\) at price 0.5. No arbitrage: \(\psi = (0.5, 1)\) is strictly positive and prices it. \(M = \{(a, 0)\}\) contains no strictly positive payoff. Let \(z = (0, 1)\). Every portfolio pays 0 in state 2, so none pays at least 1 there: super-replication is infeasible, and \(\overline{c}(z) = \min \emptyset = +\infty\) by convention. On the dual side, \(\Psi = \{(0.5, \psi_2) : \psi_2 \ge 0\}\) is unbounded, and \(\psi^\top z = \psi_2\) is unbounded above. Both sides are \(+\infty\), so duality survives as an identity in the extended reals, but nothing is attained. The assumption \(u \in M\), \(u \gg 0\) makes \(\Psi\) bounded (Step 1) and super-replication feasible (Step 3).

P3 · Bounds shift by spanned payoffs

Under the assumptions of Theorem 4.1, show that \(\overline{c}(z + y) = \overline{c}(z) + q(y)\) and \(\underline{c}(z + y) = \underline{c}(z) + q(y)\) for every \(y \in M\).

Solution

For every \(\psi \in \Psi\), \(\psi^\top y = q(y)\), because \(\psi\) is a state-price vector and \(y \in M\) (Lesson 1, Problem P2). Hence \(\psi^\top(z + y) = \psi^\top z + q(y)\) for all \(\psi \in \Psi\), and taking the maximum and the minimum over \(\Psi\) shifts both by the same constant. By Theorem 4.1 the maximum and minimum are \(\overline{c}\) and \(\underline{c}\). This is put–call parity in general form: two payoffs that differ by a spanned payoff have arbitrage intervals that differ by its price.

Empirical

E1 · Which asset is most constrained?

For each of the six assets of Lab 1's market, compute the lowest and highest arbitrage-free price given the other five prices. Predict, before running, which asset's interval is narrowest.

Solution

For asset \(n\), minimize and maximize \(\psi^\top x_n\) over \(\psi \ge 0\) with \(\psi^\top x_k = p_k\) for \(k \ne n\). An asset whose payoff is close to a linear combination of the others is nearly spanned, and if it were exactly spanned its interval would be a point (Corollary 4.2). So the prediction is: the narrowest interval belongs to the asset best fitted by the others, the one with the smallest least-squares residual.

import numpy as np
from scipy.optimize import linprog  # type: ignore[import-untyped]

# Problem E1: Lab 1's SIMULATED market; for each asset, its arbitrage-free price range given the other five.
rng = np.random.default_rng(303)
X = 1.0 + 0.3 * rng.standard_normal((12, 6))
psi = rng.uniform(0.02, 0.14, 12)
fair = X.T @ psi
print("asset  fair     lowest   highest  width   residual s.d. on the others")
for n in range(6):
    others = [k for k in range(6) if k != n]
    a_eq, b_eq = X[:, others].T, fair[others]
    lo = linprog(X[:, n], A_eq=a_eq, b_eq=b_eq, bounds=[(0, None)] * 12, method="highs").fun
    hi = -linprog(-X[:, n], A_eq=a_eq, b_eq=b_eq, bounds=[(0, None)] * 12, method="highs").fun
    coef, *_ = np.linalg.lstsq(X[:, others], X[:, n], rcond=None)
    resid = X[:, n] - X[:, others] @ coef
    print(f"{n + 1:5d}  {fair[n]:.4f}  {lo:.4f}   {hi:.4f}   {hi - lo:.4f}  {resid.std():.4f}")

E2 · Tolerance at the boundary

Run Lab 1's two programs with asset 4 shaded by 0.2078, by the exact gap, and by the exact gap less \(10^{-9}\) and less \(10^{-12}\). What do they report, and how should the result be stated?

Solution 
import numpy as np
from numpy.typing import NDArray
from scipy.optimize import linprog  # type: ignore[import-untyped]

# Problem E2: Lab 1's SIMULATED market at shades near the exact boundary of asset 4's arbitrage-free prices.
rng = np.random.default_rng(303)
X = 1.0 + 0.3 * rng.standard_normal((12, 6))
psi = rng.uniform(0.02, 0.14, 12)
fair = X.T @ psi


def detect(prices: NDArray[np.float64]) -> tuple[float, NDArray[np.float64]]:
    """Lesson 3's detection program: (optimal value, optimal theta)."""
    a_ub = np.vstack([-X, prices[None, :], X, -prices[None, :]])
    b_ub = np.concatenate([np.zeros(12), [0.0], np.ones(12), [1.0]])
    res = linprog(
        -(X.sum(axis=0) - prices),
        A_ub=a_ub,
        b_ub=b_ub,
        bounds=[(None, None)] * 6,
        method="highs",
        options={"primal_feasibility_tolerance": 1e-7},  # HiGHS accepts constraint violations up to this size
    )
    return float(-res.fun), np.asarray(res.x)


def margin(prices: NDArray[np.float64]) -> float:
    """Lesson 3's state-price margin t*."""
    c = np.zeros(13)
    c[-1] = -1.0
    a_ub = np.hstack([-np.eye(12), np.ones((12, 1))])
    a_eq = np.hstack([X.T, np.zeros((6, 1))])
    bounds = [(None, None)] * 12 + [(None, 1.0)]
    res = linprog(c, A_ub=a_ub, b_ub=np.zeros(12), A_eq=a_eq, b_eq=prices, bounds=bounds, method="highs")
    return float(res.x[-1])


others = [0, 1, 2, 4, 5]
lowest = linprog(X[:, 3], A_eq=X[:, others].T, b_eq=fair[others], bounds=[(0, None)] * 12, method="highs").fun
gap = float(fair[3] - lowest)
print(f"exact gap: {gap:.7f}")
for label, shade in (("0.2078", 0.2078), ("gap - 1e-9", gap - 1e-9), ("gap - 1e-12", gap - 1e-12), ("exact gap", gap)):
    p = fair.copy()
    p[3] -= shade
    value, theta = detect(p)
    flows = np.concatenate([[-p @ theta], X @ theta])
    print(
        f"shade {label}: margin {margin(p) + 0.0:+.3e}, detection value {round(value, 6) + 0.0:.6f}, "
        f"cash flows of the returned theta from {flows.min() + 0.0:+.1e} to {flows.max() + 0.0:.1e}"
    )

At 0.2078, the lab's rounded figure, the shade is below the gap: the margin is \(+1.419 \times 10^{-5}\), the detection value 0, no arbitrage. At the exact gap the margin is 0 to machine precision, while the detection program returns 3.987137, not a small number: its box normalization makes the optimum jump from 0 to a full-size certificate at the boundary. At shades \(10^{-9}\) and \(10^{-12}\) below the gap, where by Corollary 4.2 no arbitrage exists, the detection program still returns 3.987137, and the returned portfolio's smallest cash flow is \(-3.7 \times 10^{-8}\) and \(-3.7 \times 10^{-11}\): a certificate that fails by an amount within the primal feasibility tolerance the snippet passes to HiGHS, \(10^{-7}\) (also its default). It is not rounding error, which would be of order \(10^{-16}\) on cash flows of order 1; the violation grows with the distance from the boundary. So a large detection value is not evidence of distance from the boundary. Report the margin, which measures that distance, recompute the returned portfolio's cash flows independently, and state the result as "at the boundary within solver tolerance".

E3 · Bounds narrow as assets are added

In Example 4.3's market, add the call itself at a price of 0.14. What are the new bounds on the put, and why?

Solution

With the bond, the stock and the call, the payoff matrix has rank 3 = S (the call's payoff \((0.4, 0.1, 0)\) is not a combination of the bond's and the stock's), so the market is complete and the state prices are unique: solve \(\psi_1 + \psi_2 + \psi_3 = 0.96\), \(1.4\psi_1 + 1.1\psi_2 + 0.6\psi_3 = 0.976\), \(0.4\psi_1 + 0.1\psi_2 = 0.14\). From the first two, \(\psi = (0.5 - 0.5t, 0.8t, 0.46 - 0.3t)\); the third gives \(0.2 - 0.2t + 0.08t = 0.14\), so \(t = 0.5\) and \(\psi = (0.25, 0.4, 0.31)\). The put's price is forced to \(0.4 \times 0.31 = 0.124\), which is also the call's 0.14 minus the parity term 0.016. Each traded payoff removes one dimension of freedom from the state prices, and the interval shrinks to a point once \(M = \R^S\).

Research

R1 · Detection with a bid–ask spread

Each asset can be bought at \(p^a_n\) and sold at \(p^b_n \le p^a_n\). Write the detection program as a linear program and prove that it detects exactly the portfolios that make money net of the spread.

Solution

Variables \(\theta^+, \theta^- \ge 0\) (units bought and sold). Program: maximize \(\mathbf 1^\top X(\theta^+ - \theta^-) + p^{b\top}\theta^- - p^{a\top}\theta^+\) subject to \(0 \le X(\theta^+ - \theta^-) \le \mathbf 1\) and \(0 \le p^{b\top}\theta^- - p^{a\top}\theta^+ \le 1\). It is linear, feasible at zero and bounded by \(S + 1\). A feasible point with positive objective has nonnegative, nonzero net cash flows, so trading \(\theta^+\) at the ask and \(\theta^-\) at the bid is an arbitrage net of the spread. Conversely, for any trade with nonnegative nonzero net cash flows, write its net position \(\theta = \theta^+ - \theta^-\) with \(\theta^+ = \max(\theta, 0)\), \(\theta^- = \max(-\theta, 0)\), scale into the box, and the objective is positive. The optimum may buy and sell the same asset. The round trip burns cash at the spread, which lets the program keep today's cash flow inside its box while it scales the state payoffs up. This changes only the normalization, not detection: the netted position \(\theta^+ - \theta^-\) has cash flows at least as large, so it is an arbitrage net of the spread whenever the objective is positive. To report a trade, net the two legs.

R2 · Whole contracts

Example 2.3's arbitrage needs 141 bonds, 140 stocks and 140 funds to make one unit of cash. Suppose each trade must be in whole lots of 100 units and each lot costs 0.05 in fees. Is the arbitrage still there?

Solution

The underlying violation is \((1, 1, -1)\), paying 0.014 per unit and nothing later. In lots of 100, one lot of each leg pays \(100 \times 0.014 = 1.4\) today and costs \(3 \times 0.05 = 0.15\) in fees: still an arbitrage, worth 1.25 per set of lots. The bond in Example 2.3 was there only to fill the objective's box and is not needed. With fees of 0.5 per lot the set of three lots costs 1.5 and the arbitrage disappears. In general, fixed costs make the set of profitable portfolios non-convex, and detection becomes a mixed-integer program; the linear program's answer is then only an upper bound on what can be made.

R3 · A daily monitor for an options chain

Design a daily check that a chain of European calls on one underlying, at one expiry, admits a strictly positive state-price vector. Say what the states are, what the payoff matrix is, and what you report.

Solution
  • States. A grid of terminal prices that includes zero and every strike, plus one extra state for prices beyond the top node, whose payoffs are the slopes there (bond 0, underlying 1, each call 1). Between nodes every call is linear in the terminal price, so this grid with the extra state represents every terminal-price distribution the calls can distinguish; without the extra state, quotes generated by prices above the top node can look like an arbitrage. For a new payoff that is continuous and piecewise linear with kinks only at the nodes, and linear beyond the top node, the grid's bounds contain the true ones. A payoff with an extra kink needs the kink added as a node. A payoff with a jump at \(k\) (a digital) can have a bound that is approached but not attained: add nodes at \(k\) and on both sides of it, \(k - \delta\) and \(k + \delta\), and the bounds converge as \(\delta \to 0\) for either convention, \(\mathbf 1\{S \ge k\}\) or \(\mathbf 1\{S > k\}\); with only \(k\) added, or with one side only, the grid's interval can be far too narrow. A payoff that is curved between nodes, or grows faster than linearly beyond the top node (a power payoff such as the square of the terminal price), is not represented by any finite grid; its upper bound is infinite when it grows faster than linearly.
  • Assets. The calls, the underlying (paying its terminal price, adjusted for dividends to expiry) and a zero-coupon bond to expiry, each with bid and ask.
  • Programs. The bid–ask detection program of R1, and the margin program of Proposition 3.2 with prices between bid and ask.
  • Report. The detection value and margin, any certificate with its cash flows recomputed independently, the quote times, and the distance of the worst quote from its arbitrage bounds. A violation is reported as an alert only if it exceeds the spread and survives the recomputation.
