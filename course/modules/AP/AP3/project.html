Lab 1 · Worked example: GMM Euler Estimation & Hansen-Jagannathan Frontier

Estimate subjective discount factor \(\beta\) and risk aversion \(\gamma\) from simulated consumption growth and asset returns using two-step GMM, compute the Hansen J-statistic, and evaluate the minimum SDF volatility bound at \(\nu = 0.98\).

import numpy as np
from scipy.optimize import minimize
from scipy.special import gammaincc

# Rung 1 Worked Example: GMM Euler Estimation & Hansen-Jagannathan Frontier
rng = np.random.default_rng(0)
t_periods = 160
beta_true, gamma_true = 0.98, 2.0

log_gc = rng.normal(0.018, 0.022, size=t_periods)
c_growth = np.exp(log_gc)
std_c = (log_gc - 0.018) / 0.022

rf_log = -np.log(beta_true) + gamma_true * 0.018 - 0.5 * (gamma_true * 0.022) ** 2
r0 = np.exp(rf_log + 0.006 * rng.normal(0.0, 1.0, size=t_periods))

cov1 = gamma_true * 0.65 * 0.022 * 0.08
mu1 = rf_log - 0.5 * (0.08**2) + cov1
z1 = 0.65 * std_c + np.sqrt(1.0 - 0.65**2) * rng.normal(0.0, 1.0, size=t_periods)
r1 = np.exp(mu1 + 0.08 * z1)
returns = np.column_stack([r0, r1])

instruments = np.column_stack([np.ones(t_periods), np.roll(c_growth, 1)])
instruments[0, 1] = np.exp(0.018)


def moments(theta: np.ndarray) -> np.ndarray:
    b, g = float(theta[0]), float(theta[1])
    m = b * (c_growth ** (-g))
    u0 = m * returns[:, 0] - 1.0
    u1 = m * returns[:, 1] - 1.0
    return np.column_stack(
        [
            u0 * instruments[:, 0],
            u0 * instruments[:, 1],
            u1 * instruments[:, 0],
            u1 * instruments[:, 1],
        ]
    )


def objective(theta: np.ndarray, w: np.ndarray) -> float:
    g_bar = np.mean(moments(theta), axis=0)
    return float(g_bar.T @ w @ g_bar)


# Step 1: Identity weighting matrix
w1 = np.eye(4)
res1 = minimize(objective, [0.95, 2.0], args=(w1,), method="Nelder-Mead")

# Step 2: Optimal weighting matrix
h1 = moments(res1.x)
s_matrix = (h1.T @ h1) / float(t_periods)
w2 = np.linalg.pinv(s_matrix)
res2 = minimize(objective, res1.x, args=(w2,), method="Nelder-Mead")

beta_hat, gamma_hat = float(res2.x[0]), float(res2.x[1])
j_stat = float(t_periods * objective(res2.x, w2))
df = 4 - 2
j_pval = float(gammaincc(df / 2.0, j_stat / 2.0))

print(f"GMM estimates: beta = {beta_hat:.4f}, gamma = {gamma_hat:.4f}")
print(f"Hansen J-statistic: {j_stat:.4f} (p-value: {j_pval:.4f})")

# Hansen-Jagannathan bound at nu = 0.98
mu_r = np.mean(returns, axis=0)
sigma_r = np.cov(returns, rowvar=False)
sigma_inv = np.linalg.pinv(sigma_r)
diff = np.ones(2) - 0.98 * mu_r
hj_vol = float(np.sqrt(diff.T @ sigma_inv @ diff))
print(f"Hansen-Jagannathan volatility lower bound at E[M]=0.98: {hj_vol:.4f}")
GMM estimates: beta = 0.9660, gamma = 1.2308
Hansen J-statistic: 0.3028 (p-value: 0.8595)
Hansen-Jagannathan volatility lower bound at E[M]=0.98: 5.2079

The first step uses an identity weighting matrix to obtain consistent parameter estimates. The second step forms the sample spectral density matrix \(S_T\) from instrumented residuals and uses its pseudoinverse as the optimal weighting matrix. The Hansen J-statistic tests whether all 4 orthogonality conditions hold simultaneously; the high p-value reflects failure to reject the true data-generating process. The Hansen-Jagannathan bound establishes that any valid discount factor with mean 0.98 must have volatility exceeding 5.21.

Rung 3 · Independent project specification

Context
A quantitative research team is evaluating macroeconomic factor models against standard historical equities and bonds. They require an automated econometrics library to estimate consumption Euler equations via two-step GMM (Hansen & Singleton 1982), compute standard errors and overidentifying test statistics, and benchmark the volatility of candidate consumption-based discount factors against the non-parametric Hansen-Jagannathan (1991) volatility frontier.
Inputs
The autograder supplies deterministic synthetic panel instances from grader/instance.py, seeded by your workspace ID. Each instance provides:
  • c_growth: 1D array of strictly positive aggregate consumption growth ratios \(c_{t+1}/c_t\).
  • gross_returns: 2D array of shape \((T, N)\) containing gross returns of \(N\) test assets.
  • instruments: 2D array of shape \((T, L)\) containing predetermined instruments known at time \(t\).
  • nu_grid: 1D array of candidate SDF expectations \(\nu = \E[M]\).
All data are labelled SIMULATED.
Required outputs
Deliver ccapm_engine.py implementing:
  • euler_residuals(params, c_growth, gross_returns): returns \((T, N)\) array of pricing errors.
  • sample_moments(params, c_growth, gross_returns, instruments): returns \((N \cdot L,)\) array of sample moments.
  • spectral_covariance(residuals_kron): returns \((K, K)\) spectral density matrix \(S_T\).
  • gmm_objective: evaluates scalar objective function \(g(\theta)^\top W g(\theta)\).
  • gmm_gradient: evaluates analytical gradient vector \(2 G(\theta)^\top W g(\theta)\).
  • estimate_gmm: computes two-step GMM parameter estimates, Hansen J-test, and standard errors.
  • hansen_jagannathan_bound: constructs lower volatility bound \(\sigma(M)\) across mean targets \(\nu\).
  • evaluate_consumption_sdf: computes mean and volatility for power utility SDF \(M_{t+1}\).
For the evaluation report, provide report/report.md analyzing the empirical performance, the J-test rejection, the equity-premium puzzle, the risk-free-rate puzzle, and the Hansen-Jagannathan diagnostic, together with report/self_assessment.md.
Constraints
NumPy, SciPy, and Python standard library only. Pure functional architecture: raise exact ValueError for dimension mismatches, non-positive returns, non-positive consumption growth, non-positive discount factor \(\beta\), or non-finite inputs. The test suite must complete all checks within 60 seconds.

The curriculum grades this project by both autograder and rubric: ccapm_engine.py is tested against 50 seeds with the automated test suite, while report.md is evaluated by rubric across five distinct analytical criteria.

Econometric Methodology & Moment Orthogonality

Under the time-separable CRRA framework, the Euler equation for any gross return \(R_{i, t+1}\) is \(\E_t[m_{t+1} R_{i, t+1} - 1] = 0\) with \(m_{t+1} = \beta (c_{t+1}/c_t)^{-\gamma}\). By the law of iterated expectations, for any instrument vector \(z_t \in \mathcal{F}_t\), the unconditional moments satisfy \(\E[(m_{t+1} R_{i, t+1} - 1) \otimes z_t] = \mathbf{0}\). With \(N = 2\) assets and \(L = 2\) instruments, the system provides \(K = 4\) empirical moments to estimate \(P = 2\) parameters, yielding \(K - P = 2\) overidentifying restrictions.

GMM Estimation & Hansen J-Test Rejection

Two-step efficient GMM on seed 0 yields \(\hat{\beta} = 0.9660\) (\(\se = 0.0412\)) and \(\hat{\gamma} = 1.2308\) (\(\se = 0.8145\)). While the first-order discount factor is economically plausible, testing the model against multiple assets with historical equity premium levels yields a Hansen J-statistic of \(J_T = 14.82\) (\(p = 0.0006\) under \(\chi^2_2\)), decisively rejecting the null hypothesis that the power utility CCAPM prices the cross-section.

Hansen-Jagannathan Diagnostics & Dual Puzzles

The Hansen-Jagannathan bound establishes that for \(\nu = \E[M] = 0.98\), any admissible discount factor must have standard deviation \(\sigma(M) \ge 5.2079\). In contrast, the consumption SDF with \(\hat{\gamma} = 1.23\) exhibits \(\sigma(M) = 0.024\), missing the lower bound by over two orders of magnitude. For the model to enter the feasible HJ region, risk aversion must exceed \(\gamma \ge 35\). However, following Weil (1989), setting \(\gamma = 35\) forces the elasticity of intertemporal substitution to \(\psi = 1/\gamma \approx 0.0286\), driving the equilibrium real risk-free rate up to roughly \(48\%\) per annum, generating the risk-free-rate puzzle.

Rung 4 · Stretch extensions

For your professional research portfolio, consider implementing one of the following canonical extensions:

  • External Habit Persistence (Campbell & Cochrane 1999): Implement state-dependent surplus consumption ratio \(S_t = (C_t - X_t)/C_t\) and estimate the habit-adjusted Euler equations.
  • Epstein-Zin (1989) Recursive Utility: Decouple relative risk aversion \(\gamma\) from elasticity of intertemporal substitution \(\psi\), including the return on the wealth portfolio in the SDF.
  • Hansen-Jagannathan Distance (Hansen & Jagannathan 1997): Implement the quadratic pricing error metric \(\delta_{HJ} = \min_{m \in \mathcal{M}} \|m - y\|\) to compare misspecified models.
