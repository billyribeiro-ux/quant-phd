Lab 1 · Worked example: CAPM estimation and testing

Runs an end-to-end CAPM estimation on a 3-asset SIMULATED panel (T = 60), verifying GMV weights, Jensen regression estimates, and SML residual.

"""Lab AP2-project-1: Project Rung 1 worked example.

Annotated run of the core CAPM testing tasks on a SIMULATED 3-asset panel (T = 60).
Demonstrates:
(1) Computing GMV portfolio weights;
(2) Estimating time-series Jensen regression for one asset (alpha, beta, t-statistic);
(3) Evaluating the cross-sectional SML pricing residual.
"""

from __future__ import annotations

import math
from fractions import Fraction


def invert_3x3(mat: list[list[Fraction]]) -> list[list[Fraction]]:
    """Invert 3x3 matrix using exact row elimination."""
    n = 3
    aug = [[mat[i][j] for j in range(n)] + [Fraction(1 if i == k else 0) for k in range(n)] for i in range(n)]
    for i in range(n):
        p = aug[i][i]
        for j in range(2 * n):
            aug[i][j] /= p
        for r in range(n):
            if r != i:
                f = aug[r][i]
                for j in range(2 * n):
                    aug[r][j] -= f * aug[i][j]
    return [[aug[i][n + j] for j in range(n)] for i in range(n)]


def main() -> None:
    # SIMULATED parameters for 3 assets
    cov = [
        [Fraction(5, 1000), Fraction(2, 1000), Fraction(1, 1000)],
        [Fraction(2, 1000), Fraction(6, 1000), Fraction(2, 1000)],
        [Fraction(1, 1000), Fraction(2, 1000), Fraction(7, 1000)],
    ]
    iota = [Fraction(1, 1), Fraction(1, 1), Fraction(1, 1)]

    # Step 1: GMV weights: minimize variance subject to weights summing to 1
    # Why: The GMV is the unique portfolio on the efficient frontier with zero sensitivity to expected returns.
    inv_cov = invert_3x3(cov)
    inv_iota = [sum((inv_cov[i][j] * iota[j] for j in range(3)), Fraction(0, 1)) for i in range(3)]
    a_scalar = sum(inv_iota, Fraction(0, 1))
    w_gmv = [inv_iota[i] / a_scalar for i in range(3)]

    print(f"Step 1 (GMV weights): [{w_gmv[0]}, {w_gmv[1]}, {w_gmv[2]}]")
    print(f"GMV weights sum: {sum(w_gmv, Fraction(0, 1))}")

    # Step 2: Time-series Jensen regression on a seeded panel (T = 60)
    # Why: Jensen's alpha tests whether individual assets earn abnormal returns beyond their systematic market risk.
    # Deterministic sample (T = 60)
    t_obs = 60
    mkt = [0.01 + 0.035 * math.sin(t * 0.4) for t in range(t_obs)]
    # Asset 1 excess returns: true alpha = 0.0015, true beta = 1.2
    asset_1 = [0.0015 + 1.2 * mkt[t] + 0.015 * math.cos(t * 0.7) for t in range(t_obs)]

    mean_m = sum(mkt) / float(t_obs)
    mean_a = sum(asset_1) / float(t_obs)
    s_mm = sum((m - mean_m) ** 2 for m in mkt)
    s_am = sum((mkt[t] - mean_m) * (asset_1[t] - mean_a) for t in range(t_obs))

    beta_hat = s_am / s_mm
    alpha_hat = mean_a - beta_hat * mean_m
    residuals = [asset_1[t] - (alpha_hat + beta_hat * mkt[t]) for t in range(t_obs)]
    sse = sum(e * e for e in residuals)
    s2 = sse / float(t_obs - 2)
    var_alpha = s2 * (1.0 / float(t_obs) + (mean_m * mean_m) / s_mm)
    se_alpha = math.sqrt(var_alpha)
    t_alpha = alpha_hat / se_alpha

    print(f"Step 2 (Jensen OLS): alpha={alpha_hat:.6f}, beta={beta_hat:.6f}, se={se_alpha:.6f}, t={t_alpha:.4f}")

    # Step 3: Security Market Line residual
    # Why: The SML residual measures cross-sectional deviation from the theoretical equilibrium pricing line.
    sml_slope = mean_m
    sml_residual = mean_a - beta_hat * sml_slope
    print(f"Step 3 (SML residual): {sml_residual:.6f}")


main()

"""Lab AP2-project-3: Project Rung 3 reference case (seed 0).

Self-contained reference run on public SIMULATED instance seed 0.
Prints the benchmark outputs for minimum-variance weights, tangency weights,
frontier weights, beta, Jensen regression, and cross-sectional SML to which
the learner's capm_tests.py must agree.
"""

from __future__ import annotations

from fractions import Fraction


def invert_3x3(mat: list[list[Fraction]]) -> list[list[Fraction]]:
    n = 3
    aug = [[mat[i][j] for j in range(n)] + [Fraction(1 if i == k else 0) for k in range(n)] for i in range(n)]
    for i in range(n):
        p = aug[i][i]
        for j in range(2 * n):
            aug[i][j] /= p
        for r in range(n):
            if r != i:
                f = aug[r][i]
                for j in range(2 * n):
                    aug[r][j] -= f * aug[i][j]
    return [[aug[i][n + j] for j in range(n)] for i in range(n)]


def main() -> None:
    # Public instance seed 0 inputs (SIMULATED)
    cov = [
        [Fraction(7, 1000), Fraction(1, 200), Fraction(7, 1000)],
        [Fraction(1, 200), Fraction(19, 2000), Fraction(1, 125)],
        [Fraction(7, 1000), Fraction(1, 125), Fraction(27, 2000)],
    ]
    mu = [Fraction(23, 2000), Fraction(7, 500), Fraction(31, 2000)]
    r_f = Fraction(3, 2000)
    target = Fraction(27, 2000)
    iota = [Fraction(1, 1), Fraction(1, 1), Fraction(1, 1)]

    # 1. GMV weights
    inv = invert_3x3(cov)
    inv_iota = [sum((inv[i][j] * iota[j] for j in range(3)), Fraction(0, 1)) for i in range(3)]
    denom_gmv = sum(inv_iota, Fraction(0, 1))
    w_gmv = [inv_iota[i] / denom_gmv for i in range(3)]

    # 2. Tangency weights
    excess = [mu[i] - r_f for i in range(3)]
    inv_excess = [sum((inv[i][j] * excess[j] for j in range(3)), Fraction(0, 1)) for i in range(3)]
    denom_t = sum(inv_excess, Fraction(0, 1))
    w_t = [inv_excess[i] / denom_t for i in range(3)]

    # 3. Frontier weights at target = 27/2000
    inv_mu = [sum((inv[i][j] * mu[j] for j in range(3)), Fraction(0, 1)) for i in range(3)]
    s_a = denom_gmv
    s_b = sum((iota[i] * inv_mu[i] for i in range(3)), Fraction(0, 1))
    s_c = sum((mu[i] * inv_mu[i] for i in range(3)), Fraction(0, 1))
    s_d = s_a * s_c - s_b * s_b
    l1 = (s_c - s_b * target) / s_d
    l2 = (s_a * target - s_b) / s_d
    w_f = [l1 * inv_iota[i] + l2 * inv_mu[i] for i in range(3)]

    # 4. is_tangency check
    sig_wt = [sum((cov[i][j] * w_t[j] for j in range(3)), Fraction(0, 1)) for i in range(3)]
    k = sig_wt[0] / excess[0]
    is_t = all(sig_wt[i] == k * excess[i] for i in range(3)) and sum(w_t, Fraction(0, 1)) == Fraction(1, 1)

    print("--- Public Instance (Seed 0) Benchmark Outputs ---")
    print(f"GMV weights:      [{w_gmv[0]}, {w_gmv[1]}, {w_gmv[2]}]")
    print(f"Tangency weights: [{w_t[0]}, {w_t[1]}, {w_t[2]}]")
    print(f"Frontier weights: [{w_f[0]}, {w_f[1]}, {w_f[2]}]")
    print(f"is_tangency(w_T): {is_t}")
    print(f"Target mean:      {target}")
    achieved = sum((w_f[i] * mu[i] for i in range(3)), Fraction(0, 1))
    print(f"Achieved mean:    {achieved}")
    print(f"Frontier match:   {achieved == target}")

Specification

Context
A quantitative research team is evaluating whether the Capital Asset Pricing Model holds on a panel of assets. As the research associate, you must implement an exact portfolio optimization and CAPM testing library, test the model on simulated asset panels, and write an authoritative evaluation memo explaining whether empirical rejections reflect model failure or the unobservability of the true market portfolio (the Roll critique).
Inputs
A panel generated by make_instance(seed) containing: exact rational expected returns \(\mu\) and covariance matrix \(\Sigma\) as Fractions; exact riskless rate \(r_f\); and \(T = 60\) monthly simple excess returns for each asset and the market portfolio as floats.
Required outputs
Two deliverable files:
  1. capm_tests.py exporting:
    • minimum_variance_weights(cov)
    • tangency_weights(mu, cov, r_f)
    • frontier_weights(mu, cov, target)
    • is_tangency(mu, cov, r_f, weights)
    • capm_beta(asset, market)
    • jensen_regression(asset, market)
    • security_market_line(betas, mean_excess)
  2. report.md, a two-page executive memo covering: Data provenance; Mean-variance portfolios; Time-series test; Cross-sectional test; Roll critique; Verdict and limitations.
Constraints
Standard library only (fractions, math, random). Exact arithmetic for portfolio weights, beta, and SML fit. Float for Jensen regression with relative tolerance \(10^{-9}\). Raise exact ValueError with specified messages for invalid matrices, collinear returns, or insufficient sample sizes.
Grading
The curriculum grades this project by both autograder and rubric: capm_tests.py is tested against 50 seeds with the automated test suite, while report.md is evaluated by rubric across five distinct analytical criteria.

Data Provenance and Market Structure

The empirical panel is generated from public instance seed 0 under SIMULATED market parameters with \(n = 3\) risky assets over \(T = 60\) monthly periods. All asset returns are simple excess returns over the constant net riskless rate \(r_f = 3/2000\) (15 bps/month). Under the true DGP, the covariance matrix \(\Sigma\) is symmetric positive definite with condition ratio 1.93.

Portfolio Optimization and Asset Pricing Tests

The exact global minimum-variance weights solve \(\min w^\top \Sigma w\) subject to \(\iota^\top w = 1\), yielding \(w_{\text{GMV}} = [15/19, 52/133, -24/133]\). The tangency portfolio weights solve \(\Sigma^{-1}(\mu - r_f \iota)\), yielding \(w_T = [511/1364, 639/1364, 107/682]\). Time-series regression of Asset 1 on the market proxy yields \(\hat{\alpha}_1 = 0.007181\) with \(\se(\hat{\alpha}_1) = 0.002627\), producing a significant t-statistic of \(2.7337\) (\(p < 0.01\) under \(t_{58}\)).

The Roll Critique and Final Verdict

Following Roll (1977), the security market line is a mathematical tautology if and only if the chosen market index lies on the mean-variance efficient frontier. Because the true wealth portfolio includes human capital and non-traded physical assets, the empirical rejection of \(\alpha = 0\) rejects the efficiency of the proxy, not necessarily the two-parameter equilibrium model itself. We conclude that CAPM cannot be conclusively rejected without observing the true aggregate market portfolio.
