Lab 1 · Worked Example: Index Inclusion Event-Study Flow Impact

Under the Gabaix-Koijen framework, regressing cumulative abnormal returns from 50 index addition events on tracking flow fractions recovers the price impact slope mu = 4.64, yielding an implied stock-level demand elasticity zeta_stock = 0.22 and predicting a macro multiplier M = 3.76.

"""Lab AP6-project-1 (Rung 1, Worked Example): Index Inclusion Flow Impact.

SIMULATED: Complete worked example estimating stock-level price impact from index
rebalancing flows and translating cross-sectional estimates into the aggregate macro multiplier.
"""

from __future__ import annotations

import numpy as np


def main() -> None:
    rng = np.random.default_rng(101)
    n_events = 50  # 50 index addition events

    # Pre-event price and shares outstanding
    pre_prices = 40.0 + 30.0 * rng.uniform(0.0, 1.0, size=n_events)

    # Exogenous tracking inflow: fraction of shares demanded by passive index funds
    # Typically 3% to 12% of shares outstanding
    flow_fractions = rng.uniform(0.03, 0.12, size=n_events)

    # True stock-level demand elasticity zeta_stock = 0.22 => multiplier mu = 1 / 0.22 approx 4.55
    true_mu = 4.60
    true_intercept = 0.015  # average market drift over event window

    # Realized post-event price: Delta ln(P) = intercept + mu * flow + noise
    log_pre = np.log(pre_prices)
    noise = 0.02 * rng.standard_normal(n_events)
    delta_log_p = true_intercept + true_mu * flow_fractions + noise
    post_prices = np.exp(log_pre + delta_log_p)

    # Step 1: Compute cumulative abnormal returns (CAR)
    car_returns = np.log(post_prices) - np.log(pre_prices)
    mean_car = float(np.mean(car_returns))

    # Step 2: OLS regression of CAR on flow fraction: CAR_k = c + mu * flow_k + e_k
    x_design = np.column_stack([np.ones(n_events), flow_fractions])
    coefs = np.linalg.lstsq(x_design, car_returns, rcond=None)[0]
    c_hat = float(coefs[0])
    mu_hat = float(coefs[1])

    # Step 3: Compute implied stock demand elasticity and R-squared
    implied_zeta = float(1.0 / mu_hat)
    residuals = car_returns - x_design @ coefs
    tss = float(np.sum((car_returns - mean_car) ** 2))
    r2 = float(1.0 - np.sum(residuals**2) / tss)

    # Step 4: Macro translation (Gabaix & Koijen 2021)
    # If the micro elasticity is zeta_micro, aggregate market elasticity is dampened by general equilibrium
    # Macro multiplier M_agg approx 1 / (zeta_micro + alpha_macro)
    m_macro_predicted = float(1.0 / (implied_zeta + 0.05))

    print("Project Rung 1: Flow-Impact Worked Example Reference Output")
    print(f"Number of index addition events: {n_events}")
    print(f"Mean event CAR:                  {mean_car * 100:.2f}%")
    print(f"Estimated price impact slope mu: {mu_hat:.4f}")
    print(f"Estimated intercept c:           {c_hat:.4f}")
    print(f"Implied stock elasticity zeta:   {implied_zeta:.4f}")
    print(f"Event regression R^2:            {r2 * 100:.2f}%")
    print(f"Predicted macro multiplier M:    {m_macro_predicted:.2f}")


main()

"""Lab AP6-project-3 (Rung 3, Baseline): Full Inelastic Markets Engine Verification.

SIMULATED: Runs the complete reference engine on seed 42, exercising the HKM dealer SDF,
Koijen-Yogo demand system, fixed-point market clearing, and Gabaix-Koijen flow multiplier.
"""

from __future__ import annotations

import numpy as np


def main() -> None:
    # Build deterministic test instance for seed 42
    rng = np.random.default_rng(42)

    # 1. Intermediary SDF
    t_len = 100
    n_assets = 6
    eta = np.zeros(t_len)
    eta[0] = 0.08
    for t in range(1, t_len):
        eta[t] = 0.08 * 0.12 + 0.88 * eta[t - 1] + 0.012 * rng.standard_normal()

    x_ar = np.column_stack([np.ones(t_len - 1), eta[:-1]])
    ar_coefs = np.linalg.lstsq(x_ar, eta[1:], rcond=None)[0]
    phi_est = float(ar_coefs[1])
    u_shocks = eta[1:] - x_ar @ ar_coefs
    var_u = float(np.var(u_shocks, ddof=1))

    betas_true = np.array([2.4, 1.8, 1.2, 0.8, 0.5, 0.2])
    lambda_true = 0.02
    returns_excess = np.zeros((t_len - 1, n_assets))
    for j in range(n_assets):
        returns_excess[:, j] = (
            betas_true[j] * lambda_true + betas_true[j] * u_shocks + 0.03 * rng.standard_normal(t_len - 1)
        )

    betas_hat = np.zeros(n_assets)
    for j in range(n_assets):
        betas_hat[j] = float(np.cov(returns_excess[:, j], u_shocks)[0, 1]) / var_u
    mean_ret = np.mean(returns_excess, axis=0)
    lambda_hat = float((betas_hat @ mean_ret) / (betas_hat @ betas_hat))
    b_eta = lambda_hat / var_u

    # 2. Demand System & Flow Multiplier
    aum_shares = np.array([0.30, 0.25, 0.15, 0.30])
    elasticities = np.array([0.35, 0.08, 0.12, 0.40])
    zeta_m = float(np.sum(aum_shares * elasticities))
    m_multiplier = float(1.0 / zeta_m)

Project Specification

Context
Institutional investors and primary dealers dominate modern secondary asset markets. When passive index funds receive automated 401(k) inflows or when primary dealer balance sheets contract during panics, asset prices deviate sharply from textbook fundamentals. You are tasked by a quantitative asset manager to build an institutional asset pricing engine that estimates structural demand elasticities, inverts market clearing conditions, and evaluates the price impact of index rebalancing flows under the inelastic-markets hypothesis.
Inputs
Deterministic problem instances generated per workspace seed via grader/instance.py, containing: time series of multi-asset excess returns returns_excess (T x N), aggregate primary dealer equity capital ratio dealer_capital_ratio (T+1), institutional portfolio weights holdings_weights (I x N), asset characteristics characteristics (N x K), exogenous investment universe instruments instruments (N x L), institutional assets under management aum (I), shares outstanding shares_out (N), and index inclusion event prices and flows.
Required outputs
A Python module reference.py exposing five core functions:
  • estimate_intermediary_sdf(returns_excess, capital_ratio) -> dict[str, Any]
  • estimate_koijen_yogo_demand(holdings_weights, log_prices, characteristics, instruments) -> dict[str, Any]
  • solve_market_clearing_prices(aum, shares_out, alpha_i, beta_i, char_effects, tol, max_iter) -> np.ndarray
  • compute_flow_multiplier(aum_shares, elasticities) -> dict[str, float]
  • estimate_index_event_impact(pre_prices, post_prices, flow_fractions) -> dict[str, Any]
along with an accompanying empirical research note (1,500–2,500 words) assessing institutional inelasticity and market fragility.
Constraints
All code must be deterministic, written in Python 3.14+, strictly typed (mypy --strict), free of external runtime network dependencies, and finish execution across 50 seeds in under 10 seconds. All display math must respect the 45-character line length ceiling.
Grading mode
This project is assessed under both autograder and rubric modes. The automated test suite evaluates numerical precision, orthogonality invariants, and edge case robustness across 50 seeds, while the rubric evaluates econometric rigor, institutional analysis, and empirical defense in the research note.

Annotated Exemplars

Exemplar Level 4 (Exemplary): Structural Identification of Aggregate Inelasticity

“To identify the structural price elasticity of demand across institutional sectors, we estimate the Koijen-Yogo (2019) multinomial logit portfolio choice model using Two-Stage Least Squares. Naive ordinary least squares yields an estimated elasticity of \(\hat\beta^{\text{OLS}} = 0.56\), which is severely attenuated toward zero due to positive endogeneity bias: unobserved latent stock quality \(\epsilon_{i,n}\) simultaneously raises institutional desired holdings and bids up equilibrium market prices \(\operatorname{Cov}(p_n, \epsilon_{i,n}) > 0\). Using the counterfactual investment universe instrument \(Z_{i,n}\) based on other institutions' historical mandates, our first-stage F-statistic is 79.40, easily exceeding the Stock-Yogo weak-instrument critical threshold of 10. The resulting 2SLS structural price elasticity is \(\hat\beta^{\text{2SLS}} = 1.69\). Weighting across institutional sectors using US Flow of Funds equity holdings—where defined-benefit pensions (\(\zeta \approx 0.05\)) and life insurers (\(\zeta \approx 0.08\)) maintain rigid asset allocations—the aggregate market demand elasticity is \(\zeta_m = 0.272\). Inverting this aggregate elasticity yields a macroeconomic flow multiplier of \(M = 1 / \zeta_m = 3.67\). Every $1 of exogenous institutional cash inflow into the equity market increases aggregate stock market capitalization by $3.67. This structural inelasticity explains why automatic 401(k) retirement contributions exert steady upward pressure on market valuation multiples and demonstrates that financial markets are fundamentally quantity-driven rather than frictionless information processors.”

Annotation (Level 4): Meets all Level 4 descriptors: formally articulates the endogeneity mechanism, reports the first-stage F-statistic (79.40) against the Stock-Yogo benchmark, reports both OLS and 2SLS estimates, aggregates sectoral elasticities, derives the macro multiplier \(M = 3.67\), and provides deep institutional synthesis.
