Stablecoin Reserve Stress Test

Fiat-backed stablecoins promise continuous, par-value redeemability at $1.00 on demand while investing client collateral in yield-bearing assets. This structural maturity and liquidity transformation exposes the issuer to self-fulfilling depositor runs, as formalized by Diamond & Dybvig (1983) and demonstrated in modern wholesale banking runs by Gorton & Metrick (2012). When central banks rapidly raise benchmark rates, mark-to-market duration losses deplete reserve buffers (Jiang et al. 2024). In this project, you will build an institutional balance-sheet stress test engine (stablecoin_stress.py) evaluated across 50 seeded instances by autograder, and author an executive risk memo (memo.md) evaluated by rubric.

24 h lessons · 16 h project (40%)

Rung 1 · Worked example

In this worked example (seed 42), we model a $20,000M fiat-backed stablecoin with $20,200M in initial reserve assets (a 1.0% equity capital buffer). We apply a 125 bps interest rate shock and trace a multi-tier liquidation waterfall across cash, overnight reverse repo, 3-month T-bills, intermediate Treasury notes, and commercial bank deposits.

Lab 1 · Reserve portfolio stress waterfall worked example

Under a 125 bps rate shock and 40% redemption run ($8,000M), cash and overnight repo will be fully exhausted, forcing liquidations in 3-month T-bills. Despite $22.11M in haircut losses, the 1.0% initial capital buffer maintains remaining NAV above $1.00. Binary search locates the exact critical run size R* = $15,969.71M (79.85% of supply) where secondary NAV drops below the $0.995 peg threshold.

"""Lab X4-project-1: Rung 1 worked example for Stablecoin Reserve Stress Test.

SIMULATED reserve portfolio on seed 42. Traces rate shock duration adjustment,
liquidation waterfall accounting, and binary search for critical peg-break run size R*.
"""

from __future__ import annotations

from typing import Any

ORDERED_TIERS = ("cash", "overnight_repo", "tbills_short", "treasury_notes", "bank_deposits")


def make_sample_instance() -> dict[str, Any]:
    """Generate fixed worked example instance (seed 42)."""
    liabilities = 20000.0  # $20 Billion
    assets = {
        "cash": {"par": 3600.0, "duration": 0.0, "haircut": 0.0},
        "overnight_repo": {"par": 5400.0, "duration": 0.0, "haircut": 0.005},
        "tbills_short": {"par": 6800.0, "duration": 0.25, "haircut": 0.010},
        "treasury_notes": {"par": 3000.0, "duration": 2.50, "haircut": 0.035},
        "bank_deposits": {"par": 1400.0, "duration": 0.0, "haircut": 0.080},
    }
    return {
        "liabilities": liabilities,
        "assets": assets,
        "rate_shock_bps": 125.0,  # 125 bps
        "peg_threshold": 0.995,
    }


def apply_rate_shock(assets: dict[str, dict[str, float]], rate_shock_bps: float) -> dict[str, dict[str, float]]:
    dy = rate_shock_bps / 10000.0
    shocked = {}
    for tier, data in assets.items():
        par = data["par"]
        dur = data["duration"]
        h = data["haircut"]
        mv = par * max(0.0, 1.0 - dur * dy)
        shocked[tier] = {"par": par, "duration": dur, "haircut": h, "market_value": mv}
    return shocked


def simulate_waterfall(liabilities: float, shocked: dict[str, dict[str, float]], redemptions: float) -> dict[str, Any]:
    rem_r = redemptions
    current_mv = {t: shocked[t]["market_value"] for t in ORDERED_TIERS}
    haircut_losses = {t: 0.0 for t in ORDERED_TIERS}

    for t in ORDERED_TIERS:
        if rem_r <= 0:
            break
        mv = current_mv[t]
        h = shocked[t]["haircut"]
        avail_cash = mv * (1.0 - h)

        if rem_r <= avail_cash:
            mv_used = rem_r / (1.0 - h)
            loss = mv_used - rem_r
            current_mv[t] -= mv_used
            haircut_losses[t] = loss
            rem_r = 0.0
        else:
            current_mv[t] = 0.0
            haircut_losses[t] = mv * h
            rem_r -= avail_cash

    rem_tokens = max(0.0, liabilities - redemptions)
    rem_mv = sum(current_mv.values())
    total_loss = sum(haircut_losses.values())

    nav = rem_mv / rem_tokens if rem_tokens > 1e-9 else 1.0
    return {
        "nav": nav,
        "remaining_tokens": rem_tokens,
        "remaining_mv": rem_mv,
        "haircut_losses": haircut_losses,
        "total_haircut_loss": total_loss,
        "unfulfilled": rem_r,
    }


def main() -> None:
    print("Lab X4-project-1 | Rung 1 Worked Example: Reserve Stress Waterfall")
    print("-------------------------------------------------------------------")

    inst = make_sample_instance()
    liab = inst["liabilities"]
    shocked = apply_rate_shock(inst["assets"], inst["rate_shock_bps"])

    total_par = sum(v["par"] for v in inst["assets"].values())
    total_shocked_mv = sum(v["market_value"] for v in shocked.values())

    print(f"Total Liabilities:             ${liab:,.1f}M")
    print(f"Initial Reserve Par Value:     ${total_par:,.1f}M")
    print(f"Rate Shock:                    +{inst['rate_shock_bps']:.1f} bps")
    print(f"Post-Shock Market Value:       ${total_shocked_mv:,.2f}M")
    print(f"Duration Mark-to-Market Loss:  ${total_par - total_shocked_mv:,.2f}M")
    print(f"Initial Backing Ratio:         ${total_shocked_mv / liab:.5f}")

    # Stress test under a 40% redemption run ($8,000M)
    run_amount = 8000.0
    res_run = simulate_waterfall(liab, shocked, run_amount)
    print(f"\nStress Scenario: 40% Run (${run_amount:,.1f}M Redemptions):")
    print(f"  Remaining Tokens:            ${res_run['remaining_tokens']:,.1f}M")
    print(f"  Remaining Asset Market Val:  ${res_run['remaining_mv']:,.2f}M")
    print(f"  Total Liquidation Haircuts:  ${res_run['total_haircut_loss']:,.2f}M")
    print(f"  Post-Run Secondary NAV:      ${res_run['nav']:.5f}")

    # Binary search for R*
    peg_threshold = inst["peg_threshold"]
    low = 0.0
    high = liab
    for _ in range(50):
        mid = (low + high) / 2.0
        nav_mid = simulate_waterfall(liab, shocked, mid)["nav"]
        if nav_mid < peg_threshold:
            high = mid
        else:
            low = mid

    r_star = (low + high) / 2.0
    res_star = simulate_waterfall(liab, shocked, r_star)
    print(f"\nCritical Peg-Break Run Analysis (NAV < ${peg_threshold:.3f}):")
    print(f"  Critical Run Size R*:        ${r_star:,.2f}M")
    print(f"  Run Percentage of Supply:    {r_star / liab * 100.0:.2f}%")
    print(f"  NAV at Critical Point:       ${res_star['nav']:.5f}")


main()

Rung 3 · Independent project specification

Context
A global financial regulator is reviewing the risk model of a $10B–$50B fiat-backed stablecoin issuer. The issuer claims its reserve portfolio is 100% liquid and immune to bank runs. You are tasked with developing a deterministic stress-testing engine that simulates monetary tightening rate shocks, executes multi-tier liquidation waterfalls under redemption runs, calculates the Liquidity Coverage Ratio (LCR), and finds the critical redemption threshold \(R^*\) that triggers a break of the secondary market peg.
Inputs
A problem instance generated by instance.make_instance(seed) specifying:
  • total_liabilities: Total stablecoin tokens outstanding in millions of USD (\(D_0 \in [10000, 50000]\)).
  • reserve_assets: Dictionary mapping asset tier names (cash, overnight_repo, tbills_short, treasury_notes, bank_deposits) to their respective par value, modified duration, and liquidation haircut.
  • rate_shock_bps: Benchmark monetary tightening yield increase in basis points.
  • peg_threshold: Critical NAV threshold (typically 0.995 or 0.990) below which the peg is defined as broken.
  • stressed_outflow_30d: 30-day stressed redemption outflow for LCR calculation.
  • grid_shocks_bps and grid_redemption_fractions: Dimensions for 2D scenario matrix.
Required outputs
Two deliverables:
  1. stablecoin_stress.py: Python module implementing:
    • validate_inputs(total_liabilities, reserve_assets, rate_shock_bps, peg_threshold)
    • apply_rate_shock(reserve_assets, rate_shock_bps)
    • simulate_redemption_waterfall(total_liabilities, shocked_assets, redemptions)
    • find_peg_break_run_size(total_liabilities, shocked_assets, peg_threshold, tol=1e-5)
    • compute_liquidity_coverage_ratio(reserve_assets, stressed_outflow_30d)
    • run_stress_grid(total_liabilities, base_assets, rate_shocks_bps, redemption_fractions, peg_threshold=0.995)
  2. memo.md: A 1,500-word executive risk memo detailing balance-sheet vulnerabilities, Diamond–Dybvig first-mover dynamics, duration risks under monetary tightening, and regulatory policy recommendations.
Constraints
  • Pure Python standard library (math, typing, collections). No external dependencies.
  • Execution must complete in under 5 seconds in the browser (Pyodide) across all test seeds.
  • Deterministic execution: given the same seed, output values must be byte-for-byte reproducible.
  • All functions must pass strict type-checking (mypy --strict).
Grading
This project is evaluated by both autograder (100 points, 50 seeds in test_project.py) and rubric (5 criteria across 4 performance levels for memo.md).

Lab 3 · Multi-seed reference validation check

Running the reference implementation across seeds 0 through 4 demonstrates deterministic execution and verifies that critical peg-break run sizes R* and LCRs vary realistically across balance-sheet configurations.

"""Lab X4-project-3: Rung 3 reference verification across multiple seeds.

Validates the full reserve portfolio stress testing engine across seeds 0 through 4,
checking modified duration pricing, liquidation waterfall accounting, and critical run sizes.
"""

from __future__ import annotations

import random
from typing import Any

TIER_NAMES: list[str] = ["cash", "overnight_repo", "tbills_short", "treasury_notes", "bank_deposits"]


def make_instance(seed: int) -> dict[str, Any]:
    """Generate deterministic problem instance for seed."""
    rng = random.Random(seed)
    total_liabilities = round(10000.0 + (seed * 431) % 40000 + rng.uniform(0.0, 100.0), 2)
    surplus_pct = 0.002 + ((seed * 17) % 10) * 0.001
    total_assets = total_liabilities * (1.0 + surplus_pct)

    w_cash = 0.15 + (seed % 7) * 0.01
    w_repo = 0.25 + ((seed * 3) % 8) * 0.01
    w_tbills = 0.30 + ((seed * 5) % 6) * 0.01
    w_bank = 0.08 + (seed % 5) * 0.01
    w_notes = 1.0 - (w_cash + w_repo + w_tbills + w_bank)

    d_tbills = round(0.20 + (seed % 5) * 0.03, 3)
    d_notes = round(2.00 + ((seed * 7) % 7) * 0.20, 2)

    h_repo = round(0.005 + (seed % 4) * 0.001, 4)
    h_tbills = round(0.010 + ((seed * 2) % 5) * 0.002, 4)
    h_notes = round(0.025 + ((seed * 3) % 4) * 0.005, 4)
    h_bank = round(0.060 + (seed % 5) * 0.010, 4)

    tier_pars = [
        round(total_assets * w_cash, 2),
        round(total_assets * w_repo, 2),
        round(total_assets * w_tbills, 2),
        round(total_assets * w_notes, 2),
        round(total_assets * w_bank, 2),
    ]
    tier_durations = [0.0, 0.0, d_tbills, d_notes, 0.0]
    tier_haircuts = [0.0, h_repo, h_tbills, h_notes, h_bank]

    rate_shock_bps = round(75.0 + (seed * 23) % 175, 1)
    peg_threshold = 0.995 if seed % 2 == 0 else 0.990
    stressed_outflow_30d = round(total_liabilities * 0.30, 2)

    return {
        "seed": seed,
        "total_liabilities": total_liabilities,
        "tier_names": list(TIER_NAMES),
        "tier_pars": tier_pars,
        "tier_durations": tier_durations,
        "tier_haircuts": tier_haircuts,
        "rate_shock_bps": rate_shock_bps,
        "peg_threshold": peg_threshold,
        "stressed_outflow_30d": stressed_outflow_30d,
    }


def get_reserve_assets(inst: dict[str, Any]) -> dict[str, dict[str, float]]:
    """Reconstruct tiered reserve assets dictionary from instance arrays."""
    names: list[str] = inst["tier_names"]
    pars: list[float] = inst["tier_pars"]
    durations: list[float] = inst["tier_durations"]
    haircuts: list[float] = inst["tier_haircuts"]

    return {
        name: {"par": p, "duration": d, "haircut": h}
        for name, p, d, h in zip(names, pars, durations, haircuts, strict=True)
    }


def apply_rate_shock(
    reserve_assets: dict[str, dict[str, float]],
    rate_shock_bps: float,
) -> dict[str, dict[str, float]]:
    """Apply interest rate shock using modified duration pricing."""
    dy = rate_shock_bps / 10000.0
    shocked: dict[str, dict[str, float]] = {}
    for tier, data in reserve_assets.items():
        par = float(data["par"])
        duration = float(data["duration"])
        haircut = float(data["haircut"])
        price_factor = max(0.0, 1.0 - duration * dy)
        shocked[tier] = {
            "par": par,
            "duration": duration,
            "haircut": haircut,
            "market_value": par * price_factor,
        }
    return shocked


def simulate_waterfall(
    total_liabilities: float,
    shocked_assets: dict[str, dict[str, float]],
    redemptions: float,
) -> float:
    """Execute redemption waterfall and return post-run NAV."""
    order = ("cash", "overnight_repo", "tbills_short", "treasury_notes", "bank_deposits")
    current_mv = {t: shocked_assets[t]["market_value"] for t in order}
    haircuts = {t: shocked_assets[t]["haircut"] for t in order}

    rem_r = redemptions
    for t in order:
        if rem_r <= 0.0:
            break
        mv = current_mv[t]
        h = haircuts[t]
        avail_cash = mv * (1.0 - h)
        if rem_r <= avail_cash:
            current_mv[t] -= rem_r / (1.0 - h)
            rem_r = 0.0
        else:
            current_mv[t] = 0.0
            rem_r -= avail_cash

    rem_tokens = max(0.0, total_liabilities - redemptions)
    rem_mv = sum(current_mv.values())

    if rem_r > 1e-9:
        return 0.0
    if rem_tokens <= 1e-9:
        return 1.0
    return rem_mv / rem_tokens


def find_peg_break(
    total_liabilities: float,
    shocked_assets: dict[str, dict[str, float]],
    peg_threshold: float,
) -> tuple[float, float, bool]:
    """Find critical run size R* that causes NAV < peg_threshold."""
    if simulate_waterfall(total_liabilities, shocked_assets, 0.0) < peg_threshold:
        return 0.0, 0.0, True

    if simulate_waterfall(total_liabilities, shocked_assets, total_liabilities - 0.01) >= peg_threshold:
        return total_liabilities, 1.0, False

    low = 0.0
    high = total_liabilities
    for _ in range(60):
        mid = (low + high) / 2.0
        if simulate_waterfall(total_liabilities, shocked_assets, mid) < peg_threshold:
            high = mid
        else:
            low = mid

    r_star = (low + high) / 2.0
    return round(r_star, 4), round(r_star / total_liabilities, 6), True


def compute_lcr(reserve_assets: dict[str, dict[str, float]], outflow_30d: float) -> float:
    """Compute Liquidity Coverage Ratio."""
    cash = reserve_assets.get("cash", {}).get("par", 0.0)
    repo = reserve_assets.get("overnight_repo", {}).get("par", 0.0)
    return (cash + repo) / outflow_30d


def main() -> None:
    print("Lab X4-project-3 | Multi-Seed Stress Testing Suite Verification")
    print("----------------------------------------------------------------")

    seeds_to_check = [0, 1, 2, 3, 4]
    hdr = f"{'Seed':<5} | {'Liabilities':<12} | {'Rate Shock':<10} | {'LCR':<8} | {'R* ($M)':<12} | {'Run %':<8} | Peg"
    print(hdr)
    print("-" * len(hdr))

    for seed in seeds_to_check:
        inst = make_instance(seed)
        liab = float(inst["total_liabilities"])
        shock_bps = float(inst["rate_shock_bps"])
        peg_thresh = float(inst["peg_threshold"])
        outflow_30d = float(inst["stressed_outflow_30d"])

        assets = get_reserve_assets(inst)
        shocked = apply_rate_shock(assets, shock_bps)
        lcr = compute_lcr(assets, outflow_30d)

        r_star, r_pct, broken = find_peg_break(liab, shocked, peg_thresh)
        run_pct_str = f"{r_pct * 100.0:.2f}%"

        line = (
            f"{seed:<5} | ${liab:<11.1f} | +{shock_bps:<8.1f} | {lcr:<8.2f} | "
            f"${r_star:<11.1f} | {run_pct_str:<8} | {broken}"
        )
        print(line)

        assert lcr > 0.0
        assert 0.0 <= r_star <= liab

    print("\nAll seed instances validated successfully under reference stress test engine.")


main()

Exemplar Extracts

Level 4 Exemplar extract (Exemplary)

"Our empirical stress test establishes that Stablecoin Alpha's nominal $20,000M reserve portfolio possesses an effective critical run threshold of \(R^* = \$15,969.71\text{M}\) (79.85% of total liabilities) under a baseline +125 bps monetary tightening shock. The issuer's solvency vulnerability stems not from liquidity exhaustion per se, but from the interaction between duration mark-to-market losses and fire-sale liquidation haircuts. Consistent with Jiang et al. (2024), the 2.5-year duration intermediate Treasury tranche incurs an immediate $93.75M unrealized mark-to-market loss. While early redeemers withdraw at par ($1.0000), liquidating T-bills and notes at haircuts of 1.0% and 3.5% consumes $\$1.0101$ and $\$1.0363$ of asset market value per dollar of redemption paid. This generates a classic Diamond & Dybvig (1983) first-mover advantage: late redeemers face a depleted capital buffer, driving secondary market NAV below the $0.9950 peg break threshold. We recommend mandating a minimum 35% allocation to overnight reverse repo and unencumbered central bank cash to ensure an LCR strictly exceeding 1.20 under 30-day stressed runs."

Level 2 Exemplar extract (Developing)

"The stablecoin has $20,000M in liabilities and $20,200M in reserves. When interest rates rise by 125 bps, the bonds lose some value because of their duration. When people start running to redeem their tokens, the issuer first uses cash, then sells repo and Treasuries. Because there are haircuts when selling these assets, the total assets decrease faster than liabilities. The peg eventually breaks when redemptions reach around 75% to 80% because the NAV drops below $0.995. Stablecoins are like banks and people panic when they see the reserves dropping, so the government should require them to hold more cash."

Rung 4 · Stretch

In actual market crises (e.g. the March 2023 USDC de-peg following the Silicon Valley Bank failure), redemptions are not exogenous: when the secondary market price on decentralized exchanges (DEXs like Curve 3pool) falls to $0.980, arbitrageurs buy discounted tokens on-chain and submit them to the issuer for $1.00 par redemption. Implement an endogenous redemption feedback loop where daily redemption volume is an increasing function of the secondary market peg discount \(\max(0, 1.0 - \text{NAV}_t)\), generating self-reinforcing run spirals (Brunnermeier & Pedersen 2009).
