Oil-Shock Decomposition

In his landmark macroeconomic investigation, Kilian (2009) overturned decades of traditional modeling by proving that not all oil price shocks are alike. While conventional accounts attributed oil price spikes to physical crude supply disruptions, structural vector autoregression demonstrates that global aggregate demand shocks and oil-market-specific precautionary demand shocks drive the overwhelming majority of real oil price fluctuations. In this capstone project, you will build a structural VAR engine (oil_var.py) implementing OLS parameter estimation, recursive Cholesky identification, structural impulse response functions (IRFs), forecast error variance decompositions (FEVD), and historical shock decompositions across 50 seeded instances. In addition, you will author an analytical research memo (report.md) evaluated by rubric that applies the structural decomposition to an oil shock episode.

"""Lab X3-project-1: Rung 1 worked example for Kilian Structural VAR Oil-Shock Decomposition.

Executes the complete VAR estimation, Cholesky identification, IRF computation,
and FEVD calculation on seed 42.
"""

from __future__ import annotations

import math
from typing import Any


def cholesky(a_mat: list[list[float]]) -> list[list[float]]:
    """Compute lower-triangular Cholesky factorization L such that L L^T = A."""
    n = len(a_mat)
    l_mat = [[0.0] * n for _ in range(n)]
    for i in range(n):
        for j in range(i + 1):
            s = sum(l_mat[i][k] * l_mat[j][k] for k in range(j))
            if i == j:
                val = a_mat[i][i] - s
                if val <= 1e-14:
                    raise ValueError("Matrix is not positive definite")
                l_mat[i][j] = math.sqrt(val)
            else:
                l_mat[i][j] = (a_mat[i][j] - s) / l_mat[j][j]
    return l_mat


def invert_matrix(a_mat: list[list[float]]) -> list[list[float]]:
    """Invert square matrix via Gauss-Jordan elimination."""
    n = len(a_mat)
    m = [row[:] + [1.0 if i == j else 0.0 for j in range(n)] for i, row in enumerate(a_mat)]
    for i in range(n):
        max_row = max(range(i, n), key=lambda r: abs(m[r][i]))
        if abs(m[max_row][i]) < 1e-12:
            raise ValueError("Matrix is singular")
        m[i], m[max_row] = m[max_row], m[i]
        pivot = m[i][i]
        for c in range(2 * n):
            m[i][c] /= pivot
        for r in range(n):
            if r != i:
                factor = m[r][i]
                for c in range(2 * n):
                    m[r][c] -= factor * m[i][c]
    return [[m[r][c + n] for c in range(n)] for r in range(n)]


def matmul(a_mat: list[list[float]], b_mat: list[list[float]]) -> list[list[float]]:
    """Multiply two 2D matrices."""
    n = len(a_mat)
    m = len(b_mat[0])
    p = len(b_mat)
    return [[sum(a_mat[i][k] * b_mat[k][j] for k in range(p)) for j in range(m)] for i in range(n)]


def transpose(a_mat: list[list[float]]) -> list[list[float]]:
    """Transpose a 2D matrix."""
    return [[a_mat[i][j] for i in range(len(a_mat))] for j in range(len(a_mat[0]))]


def estimate_var(data: list[list[float]], lags: int) -> dict[str, Any]:
    """Estimate VAR(p) via OLS."""
    t_obs = len(data)
    k_vars = len(data[0])
    n_eff = t_obs - lags
    num_params = 1 + k_vars * lags

    x_mat = []
    y_mat = []
    for t in range(lags, t_obs):
        row_x = [1.0]
        for lag_idx in range(1, lags + 1):
            row_x.extend(data[t - lag_idx])
        x_mat.append(row_x)
        y_mat.append(data[t][:])

    xt = transpose(x_mat)
    xtx_inv = invert_matrix(matmul(xt, x_mat))
    b_hat = matmul(xtx_inv, matmul(xt, y_mat))

    xb = matmul(x_mat, b_hat)
    e_mat = [[y_mat[t][k] - xb[t][k] for k in range(k_vars)] for t in range(n_eff)]
    et = transpose(e_mat)
    ete = matmul(et, e_mat)
    dof = float(n_eff - num_params)
    sigma_u = [[round(ete[i][j] / dof, 8) for j in range(k_vars)] for i in range(k_vars)]

    intercepts = [round(b_hat[0][k], 6) for k in range(k_vars)]
    coefficients: list[list[list[float]]] = []
    for lag_idx in range(lags):
        bl: list[list[float]] = []
        for i in range(k_vars):
            row: list[float] = []
            for j in range(k_vars):
                idx = 1 + lag_idx * k_vars + j
                row.append(round(b_hat[idx][i], 6))
            bl.append(row)
        coefficients.append(bl)

    residuals = [[round(val, 6) for val in row] for row in e_mat]
    return {
        "intercepts": intercepts,
        "coefficients": coefficients,
        "residuals": residuals,
        "sigma_u": sigma_u,
    }


def compute_irf(
    coefficients: list[list[list[float]]], p_matrix: list[list[float]], horizon: int
) -> list[list[list[float]]]:
    """Compute structural impulse response functions Theta_h = Phi_h * P."""
    k_vars = len(p_matrix)
    p_lags = len(coefficients)

    phi: list[list[list[float]]] = [[[1.0 if i == j else 0.0 for j in range(k_vars)] for i in range(k_vars)]]
    for h in range(1, horizon + 1):
        phi_h = [[0.0] * k_vars for _ in range(k_vars)]
        for j in range(1, min(h, p_lags) + 1):
            b_phi = matmul(coefficients[j - 1], phi[h - j])
            for r in range(k_vars):
                for c in range(k_vars):
                    phi_h[r][c] += b_phi[r][c]
        phi.append(phi_h)

    irfs: list[list[list[float]]] = []
    for h in range(horizon + 1):
        theta_h = matmul(phi[h], p_matrix)
        irfs.append([[round(theta_h[i][j], 6) for j in range(k_vars)] for i in range(k_vars)])
    return irfs


def compute_fevd(irf: list[list[list[float]]]) -> list[list[list[float]]]:
    """Compute forecast error variance decomposition shares."""
    h_max = len(irf) - 1
    k_vars = len(irf[0])
    fevd: list[list[list[float]]] = []
    cum_mse = [[0.0] * k_vars for _ in range(k_vars)]
    for h in range(h_max + 1):
        fevd_h = [[0.0] * k_vars for _ in range(k_vars)]
        for i in range(k_vars):
            for j in range(k_vars):
                cum_mse[i][j] += irf[h][i][j] ** 2
            total_var_i = sum(cum_mse[i])
            for j in range(k_vars):
                fevd_h[i][j] = round(cum_mse[i][j] / total_var_i, 6) if total_var_i > 1e-12 else 0.0
        fevd.append(fevd_h)
    return fevd

The theoretical model and econometric framework

The structural vector autoregression framework formalizes the identification of macroeconomic oil market shocks established by Kilian (2009) and reviewed in time series foundations by Hamilton (1994).

Assumptions

  1. A1 · Structural VAR representation. Let \(y_t = [\Delta \text{prod}_t, \text{rea}_t, \text{rpo}_t]'\) denote the \(3 \times 1\) vector of endogenous variables, where \(\Delta \text{prod}_t\) is the percentage change in world crude oil production, \(\text{rea}_t\) is an index of global real economic activity, and \(\text{rpo}_t\) is the real price of crude oil. The structural data-generating process satisfies \(A_0 y_t = c_0 + \sum_{l=1}^p A_l y_{t-l} + \varepsilon_t\), where \(\varepsilon_t\) is a vector of serially and mutually uncorrelated structural innovations with \(\E[\varepsilon_t \varepsilon_t'] = I_3\).
  2. A2 · Reduced-form VAR representation. Pre-multiplying by \(A_0^{-1}\) yields the reduced-form VAR(p): \(y_t = c + \sum_{l=1}^p B_l y_{t-l} + e_t\), where \(c = A_0^{-1} c_0\), \(B_l = A_0^{-1} A_l\), and reduced-form residuals satisfy \(e_t = A_0^{-1} \varepsilon_t\) with \(\E[e_t e_t'] = \Sigma_e = A_0^{-1} (A_0^{-1})'\).
  3. A3 · Recursive Cholesky timing restrictions. The structural impact matrix \(P = A_0^{-1}\) is strictly lower triangular: \[\begin{pmatrix} e_t^{\Delta \text{prod}} \\ e_t^{\text{rea}} \\ e_t^{\text{rpo}} \end{pmatrix} = \begin{pmatrix} p_{11} & 0 & 0 \\ p_{21} & p_{22} & 0 \\ p_{31} & p_{32} & p_{33} \end{pmatrix} \begin{pmatrix} \varepsilon_t^{\text{oil supply shock}} \\ \varepsilon_t^{\text{aggregate demand shock}} \\ \varepsilon_t^{\text{oil-specific demand shock}} \end{pmatrix}\] Crude oil supply does not respond contemporaneously to global aggregate demand shocks or oil-market-specific demand shocks within the same month (\(p_{12} = 0, p_{13} = 0\)). Global real economic activity does not respond contemporaneously to oil-specific demand shocks within the month (\(p_{23} = 0\)). The real oil price responds contemporaneously to all three structural shocks.
  4. A4 · Moving average representation and impulse responses. The reduced-form moving average representation is \(y_t = \mu + \sum_{s=0}^\infty \Phi_s e_{t-s}\), where \(\Phi_0 = I_3\) and \(\Phi_s = \sum_{j=1}^{\min(s, p)} B_j \Phi_{s-j}\). The structural impulse response matrix at horizon \(h\) is \(\Theta_h = \Phi_h P = \Phi_h A_0^{-1}\).
  5. A5 · Forecast error variance decomposition (FEVD). The \(h\)-step-ahead forecast error variance of variable \(i\) explained by structural shock \(j\) is \(\text{MSE}_{i, j}(h) = \sum_{s=0}^h \Theta_{i, j, s}^2\). The proportion of forecast error variance is \(\text{FEVD}_{i, j}(h) = \frac{\text{MSE}_{i, j}(h)}{\sum_{k=1}^3 \text{MSE}_{i, k}(h)}\), satisfying \(\sum_{j=1}^3 \text{FEVD}_{i, j}(h) = 1.0\).

Theoretical propositions

Proposition 1 · Exact identification under recursive triangularity. Under Assumptions A1–A3, the lower-triangular Cholesky factor \(P\) of the positive-definite reduced-form covariance matrix \(\Sigma_e\) uniquely satisfies \(P P' = \Sigma_e\) with positive diagonal elements \(p_{ii} > 0\). The structural innovations are uniquely identified as \(\varepsilon_t = P^{-1} e_t\) and have identity covariance \(\E[\varepsilon_t \varepsilon_t'] = I_3\).

Proposition 2 · Orthogonal variance decomposition. Under Assumptions A1–A5, because structural shocks are mutually orthogonal, the total mean-squared forecast error of variable \(i\) at horizon \(h\) exactly equals the sum of the individual shock contributions: \(\Var(y_{i, t+h} - \E_t[y_{i, t+h}]) = \sum_{j=1}^3 \sum_{s=0}^h \Theta_{i, j, s}^2\). Normalization ensures \(\sum_{j=1}^3 \text{FEVD}_{i, j}(h) = 1.0\) for all \(i\) and \(h\ge 0\).

Exemplar 1 · Level 4 (Exemplary Memo Excerpt)

Decomposing the 2007–2008 Crude Oil Price Surge: Demand Expansion vs Precautionary Hoarding

Applying the 3-variable structural vector autoregression model of Kilian (2009) to monthly global crude oil production growth (\(\Delta \text{prod}_t\)), real economic activity (\(\text{rea}_t\)), and real crude oil prices (\(\text{rpo}_t\)) identifies the primary structural drivers of the mid-2008 oil price peak of $140/bbl. The recursive identification imposes the economic hypothesis that crude oil production does not respond contemporaneously to innovations in global demand within the same month, reflecting physical extraction constraints and multi-month tanker charter commitments. Contemporaneously, \(\Sigma_e = P P'\) yields lower-triangular impact matrix \(P\) with positive diagonal entries, ensuring that positive shocks expand supply, raise global activity, and increase real prices respectively.

The historical decomposition demonstrates that physical crude oil supply disruptions accounted for less than 11% of the cumulative price surge between January 2006 and June 2008. Instead, broad global aggregate demand expansion—driven by rapid industrialization in emerging East Asian economies—contributed 62% of the cumulative price appreciation. Precautionary inventory demand shocks, reflecting heightened anxiety concerning future Middle Eastern supply security and spare OPEC capacity depletion, contributed the remaining 27%. At 12-month and 24-month forecast horizons, the forecast error variance decomposition confirms that aggregate demand shocks account for 68.8% and 72.1% of real price variance respectively, whereas physical supply shocks account for only 8.8% and 8.7%.

We critically evaluate the contemporaneous zero restriction \(p_{12} = 0\) against the Bayesian sign-restriction critique of Baumeister & Hamilton (2019). If oil producers exhibit a non-zero short-run supply elasticity \(\epsilon_s > 0\), the Cholesky identification overstates the role of demand shocks. However, instrumental variable estimates using unexpected OPEC quota revisions demonstrate that short-run global supply elasticity does not statistically differ from zero (\(\hat{\epsilon}_s \approx 0.02, \text{se}=0.03\)), confirming the structural validity of Kilian's recursive baseline.

Analysis of Oil Price Shocks

We estimated a VAR on oil production, real activity, and oil prices. We used a Cholesky decomposition because it is the standard method in time series analysis. Oil production is ordered first because supply comes before demand in economics.

Looking at the 2008 oil price spike, our model shows that demand was more important than supply. Oil prices went up because of China's economic growth. When we ran the historical decomposition, aggregate demand had a big positive effect on oil prices. Supply shocks did not do very much during 2008. The impulse response functions show that oil prices go up after a positive demand shock.
