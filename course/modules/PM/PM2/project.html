Term-sheet economics

Venture capital contracts allocate cash flow and control rights across sequential financing rounds using complex contractual mechanisms: pre-money option pool requirements, convertible preferred liquidation preferences, seniority structures, and down-round anti-dilution adjustments. In this capstone project, you construct a complete capitalization table progression through Series A, Series B, and Series C rounds, solve down-round conversion price revisions, and execute an equilibrium multi-tier exit waterfall across arbitrary liquidity exit valuations.

The ladder

Rungs 1 and 2 introduce the option pool dilution algebra and down-round conversion price adjustments. Passing the hub placement diagnostic allows direct entry to Rung 3.

  1. Rung 1 · Worked example

    Lab 1 below executes a complete 3-round venture capital capitalization table, tracking founder dilution, option pool sizing, Series C down-round Broad-Based Weighted Average anti-dilution, and exit waterfall distributions across multiple liquidation valuations.

  2. Rung 2 · Completion problem

    Lab 2 below provides a partial implementation where you complete the Broad-Based Weighted Average anti-dilution formula and the pro-rata residual proceeds sharing condition.

  4. Rung 4 · Stretch

    Extend the engine to price multi-round liquidation preferences as compound Black–Scholes option spreads and simulate secondary share sales with pay-to-play conversion penalties.

Lab 1 · Worked example: modeling cap table evolution and exit waterfalls

A SIMULATED venture progresses through three rounds: Series A ($5M on $15M pre, 15% post-closing option pool), Series B ($10M on $30M pre, 5% pool top-up), and Series C down-round ($15M on $25M pre, Broad-Based Weighted Average anti-dilution). Predicted values before running: Series A and B conversion prices drop below original issue prices, boosting conversion ratios, while total fully diluted shares exceed 38 million.

"""PM2 project lab 1 (rung 1, worked example): Term-sheet economics.

SIMULATED: A complete 3-round capitalization table and exit waterfall calculation.
Rounds:
- Founding: 10,000,000 common shares held by founders.
- Series A: $5.0M invested at $15.0M pre-money; 15% unallocated option pool created post-money.
- Series B: $10.0M invested at $30.0M pre-money; 5% option pool top-up.
- Series C (Down-Round): $15.0M invested at $25.0M pre-money; Broad-Based Weighted Average anti-dilution.

Evaluates cap table share counts, conversion ratios, and exit waterfall payoffs at
exit valuations of $10.0M (partial preference recovery), $30.0M (full preference recovery),
and $100.0M (common conversion upside).
Standard library and NumPy only; fully deterministic.
"""

from __future__ import annotations


def main() -> None:
    founders_sh = 10_000_000.0

    # 1. Series A Round ($5M on $15M pre -> $20M post; 15% pool post-money)
    pre_a = 15_000_000.0
    inv_a = 5_000_000.0
    post_a = pre_a + inv_a
    pool_a_pct = 0.15

    # Post-A shares = founders / (1 - inv/post - pool_pct)
    tot_a = founders_sh / (1.0 - (inv_a / post_a) - pool_a_pct)
    pool_a = pool_a_pct * tot_a
    price_a = pre_a / (founders_sh + pool_a)
    sh_a = inv_a / price_a
    cp_a = price_a
    cr_a = 1.0

    # 2. Series B Round ($10M on $30M pre -> $40M post; 5% pool top-up)
    pre_b = 30_000_000.0
    inv_b = 10_000_000.0
    post_b = pre_b + inv_b
    pool_b_pct = 0.05
    prior_b = founders_sh + pool_a + sh_a
    tot_b = prior_b / (1.0 - (inv_b / post_b) - pool_b_pct)
    delta_pool_b = pool_b_pct * tot_b
    pool_b = pool_a + delta_pool_b
    price_b = pre_b / (prior_b + delta_pool_b)
    sh_b = inv_b / price_b
    cp_b = price_b
    cr_b = 1.0

    # 3. Series C Down-Round ($15M on $25M pre -> $40M post; 0% pool top-up)
    pre_c = 25_000_000.0
    inv_c = 15_000_000.0
    prior_c = founders_sh + pool_b + sh_a + sh_b
    price_c = pre_c / prior_c
    sh_c = inv_c / price_c

    # Anti-dilution adjustment for Series A and Series B (price_c < price_a and price_c < price_b)
    # Broad-based weighted average formula
    # Series A:
    hypo_a = inv_c / cp_a
    cp_a = cp_a * (prior_c + hypo_a) / (prior_c + sh_c)
    cr_a = price_a / cp_a

    # Series B:
    hypo_b = inv_c / cp_b
    cp_b = cp_b * (prior_c + hypo_b) / (prior_c + sh_c)
    cr_b = price_b / cp_b

    tot_final = founders_sh + pool_b + sh_a + sh_b + sh_c

    print("--- Capitalization Table Post-Series C ---")
    print(f"Founders: {founders_sh:,.0f} shares ({founders_sh / tot_final * 100:.1f}%)")
    print(f"Option Pool: {pool_b:,.0f} shares ({pool_b / tot_final * 100:.1f}%)")
    print(f"Series A: {sh_a:,.0f} shares (Issue: ${price_a:.2f}, CR: {cr_a:.3f})")
    print(f"Series B: {sh_b:,.0f} shares (Issue: ${price_b:.2f}, CR: {cr_b:.3f})")
    print(f"Series C: {sh_c:,.0f} shares (Issue: ${price_c:.2f}, CR: 1.000)")
    print(f"Total Fully Diluted Shares: {tot_final:,.0f}")

    # 4. Exit Waterfall Payoffs (Standard Seniority: C > B > A > Common)
    # Liquidation preferences: C=$15M, B=$10M, A=$5M (Total pref = $30M)
    print("\n--- Exit Waterfall Allocation (Standard Seniority: C > B > A > Common) ---")
    for ev in [10_000_000.0, 30_000_000.0, 100_000_000.0]:
        # At $10M: C gets $10M, B=0, A=0, Common=0
        # At $30M: C gets $15M, B gets $10M, A gets $5M, Common=0
        # At $100M: Preferred holders convert to common since pro-rata shares exceed preferences
        if ev <= 15_000_000.0:
            c_pay = ev
            b_pay, a_pay, f_pay, opt_pay = 0.0, 0.0, 0.0, 0.0
        elif ev <= 25_000_000.0:
            c_pay = 15_000_000.0
            b_pay = ev - 15_000_000.0
            a_pay, f_pay, opt_pay = 0.0, 0.0, 0.0
        elif ev <= 30_000_000.0:
            c_pay = 15_000_000.0
            b_pay = 10_000_000.0
            a_pay = ev - 25_000_000.0
            f_pay, opt_pay = 0.0, 0.0
        else:
            # At $100M: all convert to common at their adjusted conversion ratios
            as_conv_sh = founders_sh + pool_b + (sh_a * cr_a) + (sh_b * cr_b) + sh_c
            f_pay = ev * (founders_sh / as_conv_sh)
            opt_pay = ev * (pool_b / as_conv_sh)
            a_pay = ev * ((sh_a * cr_a) / as_conv_sh)
            b_pay = ev * ((sh_b * cr_b) / as_conv_sh)
            c_pay = ev * (sh_c / as_conv_sh)

        print(
            f"Exit ${ev / 1e6:.0f}M: C=${c_pay / 1e6:.2f}M | "
            f"B=${b_pay / 1e6:.2f}M | A=${a_pay / 1e6:.2f}M | "
            f"Founders=${f_pay / 1e6:.2f}M | Options=${opt_pay / 1e6:.2f}M"
        )


main()

Specification

Context
A venture capital partnership leads a series of investments across three successive financing rounds (Series A, B, and C). The partnership must evaluate cap table dilution under option pool shuffle requirements, compute adjusted conversion prices under Broad-Based Weighted Average, Narrow-Based Weighted Average, or Full Ratchet anti-dilution, and model terminal proceeds across all stakeholder classes under standard and pari passu liquidation waterfalls.
Inputs
The instance generator instance.make_instance(seed: int) -> dict[str, Any] returns:
  • seed (int): Pseudo-random generation seed.
  • founders_shares (int): Initial common share count held by founders (e.g. 10,000,000).
  • seniority (str): "standard" (chronological LIFO: C > B > A) or "pari_passu" (pro-rata sharing of preferences).
  • rounds (list[dict[str, Any]]): 3 sequential round definitions (Series A, B, C) containing pre_money, investment, pool_target, liquidation_multiple, participation ("non_participating", "participating", or "capped"), cap_multiple, and anti_dilution ("broad_based", "narrow_based", or "full_ratchet").
  • test_exit_values (list[float]): Grid of company exit valuations from $0.0 to hundreds of millions.
Required outputs
In course/modules/PM/PM2/grader/reference.py:
  • compute_anti_dilution_price(old_conv_price, new_issue_price, investment, fully_diluted_pre, common_preferred_pre, method) -> float: Solves conversion price adjustments in down-rounds.
  • build_cap_table(instance: dict[str, Any]) -> dict[str, Any]: Sizing option pools, issued shares, share prices, conversion prices, conversion ratios, and total fully diluted shares.
  • calculate_exit_waterfall(exit_value: float, cap_table: dict[str, Any], seniority: str) -> dict[str, float]: Computes equilibrium cash distribution mapping "founders", "options", "series_a", "series_b", and "series_c".
  • evaluate_term_sheet(instance: dict[str, Any]) -> dict[str, Any]: Returns complete cap table dictionary and list of waterfall results across all test exit valuations.
Constraints
Strict mathematical properties must hold for every instance:
  • Conservation of Value: \(\sum_{k} \text{payoff}[k] = \text{exit\_value}\) for all exit values.
  • Monotonicity: For every claimant \(k\), \(\text{payoff}_k(W_1) \le \text{payoff}_k(W_2)\) whenever \(W_1 \le W_2\).
  • Non-negativity: \(\text{payoff}_k(W) \ge 0.0\) for all \(k\) and all \(W \ge 0\).
  • Scale Invariance: Conversion prices and ratios are invariant to uniform scaling of share counts.
  • Asymptotic Convergence: As \(W \to \infty\), all non-participating and capped preferred equity convert to common equity, earning strictly pro-rata proceeds.
Grading mode
Autograded by test suite across 50 pseudo-random instance seeds, validating mathematical invariants, scale invariance, option pool shuffle identities, down-round anti-dilution adjustments, and multi-tier liquidation waterfall allocation.

Exemplars

Level 4 Exemplar · Robust Option Pool Shuffle & Equilibrium Waterfall

The implementation below demonstrates exemplary term-sheet economics, implementing exact closed-form option pool sizing, broad-based anti-dilution adjustment, and simultaneous Nash equilibrium conversion choices:

# Exact pre-money option pool shuffle formula:
# N_post = N_founders / (1 - I / V_post - pool_target_pct)
denom = 1.0 - (investment / post_money) - pool_target_pct
total_post_shares = founders_shares / denom
pool_shares = pool_target_pct * total_post_shares
share_price = pre_money / (founders_shares + pool_shares)
investor_shares = investment / share_price

# Invariant: total_post_shares == founders_shares + pool_shares + investor_shares
assert abs(total_post_shares - (founders_shares + pool_shares + investor_shares)) < 1e-6

This formulation guarantees that the option pool represents exactly the targeted percentage of fully diluted shares post-closing, shifting all dilution to the pre-existing shareholders before investor cash arrives.

Level 2 Exemplar · Flawed Pre-Money Pool Sizing

The passage below illustrates a classic Level 2 defect: sizing the option pool as a percentage of pre-money shares:

# FLAWED: Sizing pool from pre-money shares instead of post-money capitalization
pool_shares = pool_target_pct * founders_shares
pre_shares = founders_shares + pool_shares
share_price = pre_money / pre_shares
investor_shares = investment / share_price
# Defect: Post-closing, pool represents pool_shares / (pre_shares + investor_shares) < pool_target_pct!

Because the investor's new shares dilute the pool post-closing, this formula fails the term-sheet covenant requiring a full 15% unallocated pool post-financing.

Rung 4 · Stretch

For research and portfolio presentation, consider three advanced extensions to the term-sheet modeling engine:

  • Option-Theoretic Preferred Valuation: Decompose the multi-tier preferred equity capital structure into a portfolio of European call options on firm enterprise value using the Black–Scholes / Merton framework (Metrick & Yasuda 2010), pricing the marginal value of liquidation preferences and anti-dilution covenants.
  • Pay-to-Play Down-Round Restructuring: Model a punitive "pay-to-play" covenant where existing preferred investors who fail to participate pro-rata in a down-round have their preferred shares forcefully converted to common stock or subordinated to junior preferred series.
  • Secondary Share Repurchases & Carve-Outs: Implement management carve-out plans and secondary share liquidity discounts, quantifying the wedge between headline exit valuations and net founder realization.
