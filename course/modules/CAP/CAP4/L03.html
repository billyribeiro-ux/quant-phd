Study Pre-Registration & Methodological Protocol

Post-hoc specification searching and the garden of forking paths undermine empirical credibility in financial economics. When researchers choose data cleaning filters, sample dates, and control variables after observing initial test statistics, nominal p-values become meaningless. Formal pre-registration creates a binding methodological commitment that separates confirmatory hypothesis testing from exploratory discovery. This lesson formalizes pre-registration protocols, specification curve diagnostics, and cryptographic protocol hashing.

1. The Pre-Registration Commitment

In quantitative empirical finance, researcher degrees of freedom represent an insidious source of false discovery.

Definition 3.1 (Pre-registration) Pre-registration is the formal doctoral practice of specifying and time-stamping the primary and secondary empirical hypotheses, data ingestion boundaries, exclusion filters, statistical estimators, and robustness batteries before analyzing the primary evaluation dataset.

By fixing the analysis pipeline in advance, pre-registration eliminates the "garden of forking paths" identified by Gelman & Loken (2014), wherein researchers make context-dependent data decisions that inevitably steer results toward statistical significance.

Theorem 3.1 (Type I Error Inflation under Forking Paths) Let \(T_k\) be test statistics computed across \(K\) data-dependent specification paths under the null hypothesis \(H_0: \theta = 0\), where each marginal test has nominal size \(\alpha = \Prob(|T_k| \ge c_\alpha) = 0.05\). If the researcher selects the path yielding the maximum test statistic \(T_{\max} = \max_{1 \le k \le K} |T_k|\), the true Type I error rate \(\alpha_{\text{true}}\) satisfies: \[ \alpha_{\text{true}} = \Prob(T_{\max} \ge c_\alpha) = 1 - \Prob(|T_1| < c_\alpha, \dots, |T_K| < c_\alpha) \ge \alpha \] Under equicorrelated test statistics with correlation \(\rho \in [0, 1)\), as \(K \to \infty\), \(\alpha_{\text{true}} \to 1.0\).

Proof The event \(\{T_{\max} \ge c_\alpha\}\) is equivalent to \(\bigcup_{k=1}^K \{|T_k| \ge c_\alpha\}\). The complement is \(\bigcap_{k=1}^K \{|T_k| < c_\alpha\}\). For any non-degenerate multivariate distribution with correlation \(\rho < 1\), the joint probability \(\Prob(|T_1| < c_\alpha, \dots, |T_K| < c_\alpha) < \Prob(|T_1| < c_\alpha) = 1 - \alpha\). Therefore: \[ \alpha_{\text{true}} = 1 - \Prob\left(\bigcap_{k=1}^K \{|T_k| < c_\alpha\}\right) > \alpha \] As \(K \to \infty\), extreme value theory guarantees that the maximum of non-identical Gaussians \(\max_{1 \le k \le K} |T_k| \pto \infty\), so \(\alpha_{\text{true}} \to 1.0\). Pre-registration binds \(K = 1\), enforcing \(\alpha_{\text{true}} = \alpha\). This proof is complete.

Remark 3.1 (Separation of Confirmatory and Exploratory Inquiry) Pre-registration does not prohibit exploratory empirical discovery. Rather, it requires the candidate to partition the manuscript into two strictly distinct sections: confirmatory results (evaluating pre-registered hypotheses without deviation) and exploratory results (disclosing post-hoc findings labelled explicitly as hypotheses for future out-of-sample replication) per Harvey (2017).

2. Specification Curve Analysis & Cryptographic Hashing

To audit robustness against unconstrained researcher choices, modern doctoral dissertations accompany pre-registered specifications with complete specification curves.

Definition 3.2 (Specification Curve) A specification curve is an exhaustive empirical mapping that estimates and displays effect sizes and standard errors across every plausible combination of data transformations, exclusion thresholds, control variables, and standard error clustering choices.

In addition to tabular reporting, the research protocol is cryptographically hashed using SHA-256 before accessing the testing data sample, ensuring an immutable record of pre-analysis commitments.

Lab 1 · Pre-Registration Protocol Hash & Forking Path Diagnostic

Pre-registering an empirical specification freezes the primary estimate, whereas unconstrained specification searches across 24 candidate paths inflate the cherry-picked t-statistic by more than a factor of five.

"""Lab CAP4-L03-1: Pre-Registration Protocol Hash & Forking Path Diagnostic.

Evaluates methodological pre-registration by generating a cryptographic SHA-256 specification hash,
executing a multi-path specification curve across researcher degrees of freedom, and contrasting
pre-registered effect sizes against post-hoc cherry-picked extremes.
"""

from __future__ import annotations

import hashlib
import json
import math
from typing import Any

import numpy as np


def main() -> None:
    np.random.seed(42)

    # 1. Define pre-registered study specification parameters
    preregistration_spec: dict[str, Any] = {
        "hypothesis": "Cross-sectional momentum premium conditioned on intermediary leverage",
        "sample_start": "1972-01-01",
        "sample_end": "2024-12-31",
        "asset_universe": "CRSP common equities excluding microcaps (< 20th NYSE percentile)",
        "rebalancing": "Monthly value-weighted decile spreads",
        "controls": ["size", "book_to_market", "operating_profitability", "investment"],
        "clustering": "Two-way firm and calendar quarter",
        "primary_loss": "Mean cross-sectional pricing error under Shanken correction",
        "significance_threshold": 0.005,  # Stricter pre-registered hurdle
    }

    # Generate immutable cryptographic SHA-256 hash of the protocol
    spec_json = json.dumps(preregistration_spec, sort_keys=True)
    spec_hash = hashlib.sha256(spec_json.encode("utf-8")).hexdigest()

    # 2. Simulate a garden of forking paths (24 specification variations)
    # Varying: microcap filter (3 options), weighting (2 options), control lags (4 options)
    # Underlying true effect is 0.25% monthly (t ~ 2.1)
    true_alpha = 0.0025
    t_obs = 300
    noise = np.random.normal(0.0, 0.012, size=(24, t_obs))

    estimates: list[float] = []
    t_stats: list[float] = []
    p_values: list[float] = []

    for i in range(24):
        # Specific choice variations add small sample selection perturbations
        bias_shift = (i - 12) * 0.00015
        monthly_series = true_alpha + bias_shift + noise[i]
        est_mean = float(np.mean(monthly_series))
        se = float(np.std(monthly_series, ddof=1) / np.sqrt(t_obs))
        t_val = float(est_mean / se)
        # Two-tailed p-value normal approximation
        p_val = float(2.0 * (1.0 - 0.5 * (1.0 + math.erf(abs(t_val) / np.sqrt(2.0)))))
        estimates.append(est_mean)
        t_stats.append(t_val)
        p_values.append(p_val)

    # Pre-registered path is path 0 (baseline)
    prereg_est = estimates[0]
    prereg_t = t_stats[0]
    prereg_p = p_values[0]

    # Post-hoc cherry-picked max t-statistic across forking paths
    cherry_picked_idx = int(np.argmax(t_stats))
    cherry_est = estimates[cherry_picked_idx]
    cherry_t = t_stats[cherry_picked_idx]
    cherry_p = p_values[cherry_picked_idx]

    median_est = float(np.median(estimates))
    median_t = float(np.median(t_stats))

    print(f"Pre-Registration Protocol Hash: {spec_hash[:16]}...")
    print(f"Total Forking Paths Evaluated: {len(estimates)}")
    print(f"Pre-Registered Estimate: {prereg_est * 100:.3f}% (t={prereg_t:.2f}, p={prereg_p:.4f})")
    print(f"Median Specification Estimate: {median_est * 100:.3f}% (t={median_t:.2f})")
    print(f"Post-Hoc Cherry-Picked: {cherry_est * 100:.3f}% (t={cherry_t:.2f}, p={cherry_p:.4f})")
    print(f"Inflation Factor (Cherry / Pre-Reg t): {cherry_t / prereg_t:.2f}")


main()
Pre-Registration Protocol Hash: c53ec324db483f8f...
Total Forking Paths Evaluated: 24
Pre-Registered Estimate: 0.063% (t=0.93, p=0.3529)
Median Specification Estimate: 0.231% (t=3.27)
Post-Hoc Cherry-Picked: 0.396% (t=5.88, p=0.0000)
Inflation Factor (Cherry / Pre-Reg t): 6.33

The pre-registered protocol hash immutably pins the baseline estimate (0.063%, t = 0.93), whereas unprincipled cherry-picking across the 24 forking paths yields an inflated t-statistic of 5.88 (a 6.33-fold inflation), illustrating how p-hacking manufactures artificial anomalies from noise.

Where the canon breaks

Pre-registration encounters practical difficulties in non-experimental financial economics:

  • Historical Data Familiarity: Because macro-finance researchers already know historical market returns (e.g. the 2008 crisis or the 2000 dot-com collapse), pre-registering an analysis on past data cannot fully eliminate subconscious conditioning.
  • Structural Regime Breaks: Unforeseen market shocks (e.g., unexpected regulatory overhauls or exchange halts) can render pre-registered data filters invalid, necessitating transparent protocol deviations.
  • Survivorship Adjustments in Historical Panels: When commercial data vendors silently revise historical data (such as Compustat restatements), pre-registered queries may execute on shifting underlying records.

Misconceptions

  1. Pre-registration prevents a doctoral student from conducting exploratory data analysis.

    Pre-registration does not restrict exploration; it merely requires researchers to label exploratory analyses as hypothesis-generating exercises rather than confirmatory proofs, preserving statistical integrity.

  2. Pre-registration is only necessary for laboratory psychology experiments and has no place in quantitative finance.

    Because finance datasets are observational and extensively reused, multiple testing and data snooping are far more severe in financial economics than in experimental sciences, making pre-registration essential.

  3. If a pre-registered hypothesis yields a statistically insignificant result, the dissertation has failed.

    A rigorous, well-powered null result that overturns a published spurious anomaly is a major scientific contribution. Doctoral faculty evaluate methodological rigor, identification strength, and execution, not nominal p-values.

Problem set

Mechanics problems

If a researcher tests \(K = 20\) independent specification paths at nominal significance level \(\alpha = 0.05\), calculate the true probability of falsely rejecting the null hypothesis under Theorem 3.1.

Solution

Under independence across the \(K = 20\) specifications: \(\alpha_{\text{true}} = 1 - (1 - \alpha)^K = 1 - (1 - 0.05)^{20} = 1 - (0.95)^{20} \approx 1 - 0.35849 = 0.64151\). The true Type I error rate inflates from 5% to 64.15%. Without pre-registration, there is a greater than 64% probability of falsely reporting a significant finding under the null.

A pre-registered research protocol generates a SHA-256 digest on its JSON specification string. If the original JSON string is 2,450 bytes long, state the length in hexadecimal characters of the resulting hash and explain its uniqueness property.

Solution

SHA-256 produces a 256-bit cryptographic message digest. When represented as a hexadecimal string, each byte corresponds to 2 hex characters, producing exactly \(256 / 8 \times 2 = 64\) hexadecimal characters. By the cryptographic collision resistance property of SHA-256, finding two distinct specification strings that produce the identical 64-character hash requires approximately \(2^{128}\) operations, making it impossible to alter pre-registered hypotheses after observing data.

A researcher constructs a specification curve with 48 combinations of controls and sample cutoffs. If 12 specifications yield \(p < 0.05\), 24 yield \(p \in [0.05, 0.10]\), and 12 yield \(p > 0.10\), calculate the median p-value and evaluate whether the empirical effect is robust.

Solution

Sorting the 48 p-values in ascending order: the 24th and 25th values lie in the \([0.05, 0.10]\) interval. The median p-value is approximately 0.075. Because only 25% (12 of 48) of specifications achieve statistical significance at the conventional 5% level, and the median p-value exceeds 0.05, the finding is fragile and highly sensitive to discretionary researcher choices.

Proof problems

Prove that for two positively correlated test statistics \((T_1, T_2) \sim \Normal\left(\begin{bmatrix} 0 \\ 0 \end{bmatrix}, \begin{bmatrix} 1 & \rho \\ \rho & 1 \end{bmatrix}\right)\) with \(\rho > 0\), the probability of at least one false rejection \(\Prob(\max(|T_1|, |T_2|) \ge c_\alpha)\) is strictly less than the independent bound \(1 - (1 - \alpha)^2\).

Solution

By Slepian's lemma for Gaussian processes, the joint probability that all components remain below a threshold is a strictly increasing function of the off-diagonal correlation elements \(\rho\). Specifically, \(\Prob(|T_1| < c_\alpha, |T_2| < c_\alpha)\) is strictly greater when \(\rho > 0\) than when \(\rho = 0\): \[ \Prob(|T_1| < c_\alpha, |T_2| < c_\alpha \mid \rho > 0) > \Prob(|T_1| < c_\alpha \mid \rho = 0) \Prob(|T_2| < c_\alpha \mid \rho = 0) = (1 - \alpha)^2 \] Taking complements: \[ \Prob(\max(|T_1|, |T_2|) \ge c_\alpha) = 1 - \Prob(|T_1| < c_\alpha, |T_2| < c_\alpha \mid \rho > 0) < 1 - (1 - \alpha)^2 \] This confirms that positive correlation between specifications dampens Type I error inflation relative to the independent case, though it remains strictly higher than \(\alpha\).

Prove that pre-registering an empirical loss function \(L(\theta) = \E[(Y - X \theta)^2]\) eliminates the optimistic bias in estimated in-sample mean squared error.

Solution

In-sample mean squared error is \(\widehat{\operatorname{MSE}} = \frac{1}{N} \sum_{i=1}^N (Y_i - X_i \hat{\theta})^2\). By the properties of OLS projection, \(\hat{\theta} = \argmin_\theta \sum (Y_i - X_i \theta)^2\). Therefore: \[ \E[\widehat{\operatorname{MSE}}] = \sigma^2 \left(1 - \frac{K}{N}\right) < \sigma^2 = \operatorname{MSE}_{\text{true}} \] The optimistic in-sample bias is \(\frac{K}{N} \sigma^2\). When a researcher searches over \(M\) model specifications to minimize in-sample error, \(\min_{1 \le m \le M} \widehat{\operatorname{MSE}}_m\) compounds this bias by selecting models that overfit sample noise. Pre-registering a single fixed model specification restricts \(M = 1\) and pre-commits the parameter space, bounding the optimism to the known finite-sample correction \(\frac{K}{N} \sigma^2\) without discretionary search exaggeration.

Prove that under the Holm-Bonferroni step-down procedure, the Family-Wise Error Rate (\(\FWER\)) is controlled at level \(\alpha\) under arbitrary dependency structures.

Solution

Let \(H_{(1)}, \dots, H_{(M)}\) be sorted by p-values \(P_{(1)} \le \dots \le P_{(M)}\). The Holm procedure rejects \(H_{(i)}\) if \(P_{(j)} \le \frac{\alpha}{M - j + 1}\) for all \(j \le i\). Let \(I_0\) be the index set of true null hypotheses, with cardinality \(M_0 \le M\). Let \(k\) be the first index in the ordered sequence that belongs to \(I_0\). For a false rejection to occur, the procedure must reject at least one true null, which implies rejecting \(H_{(k)}\). Thus, \(P_{(k)} \le \frac{\alpha}{M - k + 1}\). Since \(k\) is the first true null rejected, there are at most \(k - 1\) false rejections before it, meaning \(M - k + 1 \ge M_0\). Therefore, \(\frac{\alpha}{M - k + 1} \le \frac{\alpha}{M_0}\). The probability of at least one false rejection is: \[ \Prob(\text{false rejection}) \le \Prob\left(P_{(k)} \le \frac{\alpha}{M_0}\right) \le \Prob\left(\min_{i \in I_0} P_i \le \frac{\alpha}{M_0}\right) \le \sum_{i \in I_0} \Prob\left(P_i \le \frac{\alpha}{M_0}\right) = M_0 \left(\frac{\alpha}{M_0}\right) = \alpha \] This holds under any dependence structure, completing the proof.

Empirical problems

A researcher pre-registers an analysis testing whether corporate carbon emissions reduce credit spreads. In the pre-registered specification, the estimated coefficient is \(\hat{\beta} = -0.012\) (\(t = -1.45\)). In an exploratory post-hoc check adding industry-by-year fixed effects and dropping utilities, the coefficient becomes \(\hat{\beta} = -0.028\) (\(t = -2.85\)). How must the researcher report these findings in a doctoral dissertation?

Solution

The candidate must report the pre-registered finding (\(\hat{\beta} = -0.012, t = -1.45\)) as the primary, confirmatory result in the main empirical table, concluding that the baseline hypothesis is not supported. The second specification (\(\hat{\beta} = -0.028, t = -2.85\)) must be explicitly labeled as an exploratory, post-hoc discovery in a separate section, disclosing that it was identified after observing the initial null result. The candidate must state that the post-hoc finding represents a new hypothesis requiring validation on fresh out-of-sample data.

An empirical study constructs a specification curve varying five dimensions: return windows (3 choices), outlier winsorization (3 choices), control variables (4 subsets), and clustering (2 choices). Calculate the total number of specification paths and the required Bonferroni threshold for family-wise error control at \(\alpha = 0.05\).

Solution

The total number of specification combinations is \(K = 3 \times 3 \times 4 \times 2 = 72\) paths. The Bonferroni-adjusted significance threshold is \(\alpha_{72} = \frac{0.05}{72} \approx 0.000694\). For two-tailed Gaussian inference, the critical value is \(z_{72}^* = \Phi^{-1}(1 - 0.000694 / 2) = \Phi^{-1}(0.999653) \approx 3.39\). Specifications in the curve must exceed \(t = 3.39\) to achieve family-wise significance.

In Chen & Zimmermann's (2020) replication of 400 equity anomalies, the average post-publication attenuation of long-short returns is approximately 50%. If a candidate discovers a pre-registered anomaly with a sample return of 80 bps/month, what is the expected out-of-sample return accounting for post-publication decay?

Solution

Accounting for the empirical 50% post-publication decay documented by Chen & Zimmermann (2020) and McLean & Pontiff (2016), the expected out-of-sample economic return is \(80 \times (1 - 0.50) = 40\) basis points per month. The doctoral thesis must evaluate whether this 40 bps return remains profitable after institutional execution costs, turnover drag, and borrowing fees.

Research problems

Critique the argument that pre-registration is impossible in empirical finance because all historical CRSP/Compustat data has already been observed by researchers.

Solution

While researchers have general awareness of historical equity trends, no individual possesses memory of the multidimensional joint distribution of thousands of micro-level accounting characteristics across 50 years of monthly data. Pre-registration on historical observational data remains highly effective because it prevents the researcher from iteratively tweaking filtering thresholds, lead-lag relationships, and control sets to fit noise. Furthermore, true out-of-sample pre-registration can be achieved by freezing protocols on past data and testing exclusively on future incoming market returns or unreleased international datasets.

Design a doctoral pre-registration template for an asset pricing study, specifying the required disclosure modules and boundary freeze points.

Solution

A rigorous doctoral pre-registration template consists of six modular sections: 1. Hypothesis Specification: Null and alternative hypotheses, signed directional predictions, and primary vs secondary designations. 2. Data Architecture: Exact vendor series IDs, point-in-time filing lag rules, and start/end dates. 3. Sample Hygiene Filters: Explicit microcap exclusion cutoffs (e.g. NYSE 20th percentile), share code filters (10 and 11 only), and Shumway delisting replacements. 4. Estimator Protocol: Exact functional form (OLS, WLS, Fama-MacBeth, 2SLS), control variables, and clustering dimensions. 5. Multiple-Testing Strategy: Pre-specified false discovery rate control algorithm (Benjamini-Hochberg or Holm). 6. Cryptographic Hashing: A SHA-256 hash generated on the immutable protocol JSON file, committed to a public registry prior to data execution.

Evaluate how the Registered Reports publishing model in academic finance alters the incentive structure for doctoral researchers compared to traditional peer review.

Solution

Under traditional peer review, journals evaluate completed manuscripts, creating intense pressure to produce statistically significant results (\(p < 0.05\)) and incentivizing p-hacking and HARKing (hypothesizing after the results are known). Under Registered Reports, peer review occurs at Stage 1 before data collection and analysis. Referees evaluate the importance of the economic question, the rigor of the theoretical framing, and the power of the pre-registered identification strategy. If accepted in-principle, the paper is published regardless of whether the final empirical results confirm or reject the null hypothesis, eliminating publication bias and aligning doctoral incentives with scientific truth.

Retrieval quiz

  1. What is the central scientific function of study pre-registration?

    Options

    Pre-registration creates an immutable pre-analysis commitment that separates confirmatory testing from exploratory data dredging.

  2. What does Gelman & Loken's (2014) "garden of forking paths" describe?

    Options

    The garden of forking paths refers to researchers making unconscious, data-dependent choices (filters, controls, sample periods) that steer outcomes toward statistical significance.

  3. How many hexadecimal characters are produced by a standard SHA-256 cryptographic digest of a pre-registration protocol?

    A 256-bit hash equals 32 bytes; each byte is represented by two hexadecimal characters, yielding exactly 64 characters.

  4. What does a specification curve analysis display?

    Options

    A specification curve comprehensively evaluates parameter sensitivity across the entire multidimensional grid of reasonable modeling choices.

  5. How should unexpected empirical discoveries made outside the pre-registered protocol be presented in a doctoral thesis?

    Options

    Doctoral integrity requires separating confirmatory tests from exploratory post-hoc findings, treating exploratory results as hypotheses for future inquiry.

  6. Why does positive correlation among candidate regression specifications attenuate Type I error inflation compared to independent tests?

    Options

    By Slepian's inequality, positive correlation clusters rejections together, reducing the probability of observing at least one false rejection relative to independent tests.

  7. Under the Registered Reports publication format, when does in-principle journal acceptance occur?

    Options

    Stage 1 review evaluates question novelty and pre-registered methodological rigor before data analysis, ensuring publication independent of the final p-value.

  8. Why is an empirical finding that overturns a published anomaly with a rigorously documented null result a valid doctoral contribution?

    Options

    Demonstrating that a published anomaly was a statistical artifact of survivorship bias or p-hacking advances scientific knowledge and curates the literature.
