The Atlas Research Pipeline & End-to-End Reproducibility

Modern empirical finance confronts a systemic reproducibility crisis: published findings frequently fail independent replication due to undocumented transformations, unpinned environments, and manual data copy-pasting. A doctoral thesis cannot rely on ephemeral notebook state or unversioned scripts. Constructing an end-to-end Atlas Directed Acyclic Graph pipeline with cryptographic artifact hashing, hermetic containerization, and automated publication tables guarantees bit-level reproducibility across independent platforms. This architecture transforms academic assertions into verifiable engineering artifacts, defending empirical claims against data tampering or fragility.

1. Atlas Directed Acyclic Graph Architecture

Large-scale asset pricing replication initiatives—such as Hou, Xue & Zhang (2020) and Chen & Zimmermann (2022)—demonstrate that empirical credibility requires complete provenance tracking from raw feeds to published figures.

Definition 7.1 (Research Pipeline DAG) An empirical research pipeline is a Directed Acyclic Graph \(G = (V, E)\) where each node \(v \in V\) represents an idempotent computational task (e.g. data ingestion, hygiene screening, econometric estimation), and each directed edge \((u, v) \in E\) denotes an immutable data dependency indicating that task \(v\) requires artifact output \(\mathcal{Y}_u\) produced by task \(u\).

The pipeline enforces a strict four-stage topological execution order: ingestion (\(v_1\)), hygiene filtering and delisting adjustment (\(v_2\)), cross-sectional econometric estimation (\(v_3\)), and publication table rendering (\(v_4\)).

Theorem 7.1 (Cryptographic Manifest Invariance) Let each computational node \(v_k \in V\) compute an output artifact \(\mathcal{Y}_k = f_k(\mathcal{X}_k; \boldsymbol{\theta}_k)\) from inputs \(\mathcal{X}_k\) and parameters \(\boldsymbol{\theta}_k\). Let \(H(\mathcal{Y}_k) = \operatorname{SHA-256}(\operatorname{CanonicalJSON}(\mathcal{Y}_k))\) be the cryptographic digest of the node output under lexicographical key ordering. Then the cumulative pipeline manifest hash: \[ \mathcal{H}_{\text{manifest}} = \operatorname{SHA-256}\Big( H(\mathcal{Y}_1) \parallel H(\mathcal{Y}_2) \parallel \dots \parallel H(\mathcal{Y}_K) \Big) \] is invariant under identical execution conditions, and any bit-level modification to raw data, filter thresholds, or numerical solver parameters produces a divergent manifest hash with probability \(1 - 2^{-256}\).

Proof By the collision resistance property of the SHA-256 cryptographic hash function, finding two distinct inputs \(m_1 \neq m_2\) such that \(\operatorname{SHA-256}(m_1) = \operatorname{SHA-256}(m_2)\) requires \(\mathcal{O}(2^{128})\) operations under the birthday attack bound. Because \(\operatorname{CanonicalJSON}\) maps mathematical structures to unique deterministic byte strings by sorting dictionary keys and fixing IEEE 754 representations, any perturbation \(\Delta \mathcal{Y}_k \neq 0\) alters the serialized byte sequence. By the avalanche effect of SHA-256, changing a single bit in \(\mathcal{Y}_k\) changes approximately 50% of the bits in \(H(\mathcal{Y}_k)\). Concatenating the stage hashes into \(\mathcal{H}_{\text{manifest}}\) propagates any stage divergence to the root checksum, completing the proof.

Remark 7.1 (Content-Addressable Storage Caching) In production econometric pipelines, intermediate outputs are stored in content-addressable storage (CAS). When task \(v_k\) is scheduled, the workflow engine computes the expected cache key \(K_k = \operatorname{SHA-256}(H(\mathcal{X}_k) \parallel H(f_k) \parallel H(\boldsymbol{\theta}_k))\). If an artifact with key \(K_k\) exists in the CAS repository, execution is skipped and results are loaded instantly, reducing multi-hour simulation runtimes to seconds.

2. Hermetic Isolation & Environment Freezing

Even mathematically sound pipelines produce divergent numerical results if executed across differing system libraries or unpinned environments.

Example 7.1 (BLAS/LAPACK Matrix Inversion Divergence) When solving for factor risk premia \(\hat{\boldsymbol{\lambda}} = (X^\top X)^{-1} X^\top \bar{R}\) on a poorly conditioned matrix with condition number \(\kappa(X^\top X) = 10^8\), different BLAS backends (Intel MKL vs. OpenBLAS vs. Apple Accelerate) execute inner products in differing summation orderings. Due to non-associativity of floating-point arithmetic, relative errors on the order of \(\kappa \cdot \varepsilon_{\text{mach}} \approx 10^8 \times 2.22 \times 10^{-16} \approx 2.2 \times 10^{-8}\) propagate through the matrix inverse, altering \(t\)-statistics at the fourth decimal place. Hermetic containers lock both the linear algebra binaries and instruction set architectures.

To eliminate environmental drift, the doctoral replication standard mandates three strict isolation layers:

  • Locked Dependencies: Dependency lockfiles (e.g. uv.lock) pin exact cryptographic wheel hashes for all Python libraries.
  • Hermetic Containers: Container images (Docker/OCI) encapsulate user-space libraries, system compilers, and BLAS runtimes.
  • Content-Addressable Raw Storage: Raw vendor snapshots (CRSP, Compustat, TRACE) are archived with immutable SHA-256 manifests to protect against retroactive database restatements.

Lab 1 · Atlas End-to-End Pipeline DAG & Cryptographic Manifest Verification

Executing an end-to-end 4-stage pipeline with cryptographic SHA-256 artifact hashing yields a deterministic cumulative manifest checksum and zero bit-level re-execution error.

"""Lab CAP4-L07-1: Atlas End-to-End Pipeline DAG & Reproducibility Diagnostic.

Evaluates doctoral reproducibility by executing an end-to-end Atlas DAG workflow
(Ingestion -> Hygiene -> Estimation -> Tables -> Figures) with cryptographic hash verification
of all intermediate artifacts and bit-level invariant matching.
"""

from __future__ import annotations

import hashlib
import json
from typing import Any

import numpy as np


def main() -> None:
    np.random.seed(42)

    # 1. Pipeline Stage Execution & Artifact Hash Function
    pipeline_state: dict[str, Any] = {}
    stage_hashes: dict[str, str] = {}

    def normalize(val: Any) -> Any:
        if isinstance(val, float):
            return round(val, 6)
        if isinstance(val, dict):
            return {k: normalize(v) for k, v in val.items()}
        if isinstance(val, list):
            return [normalize(v) for v in val]
        return val

    def hash_artifact(data: Any) -> str:
        serialized = json.dumps(normalize(data), sort_keys=True, default=str)
        return hashlib.sha256(serialized.encode("utf-8")).hexdigest()

    # Stage 1: Data Ingestion
    raw_panel = np.random.normal(0.01, 0.05, size=(60, 10))
    pipeline_state["stage_1_ingest"] = {
        "rows": 60,
        "cols": 10,
        "first_val": round(float(raw_panel[0, 0]), 6),
        "mean_val": round(float(np.mean(raw_panel)), 6),
    }
    stage_hashes["stage_1_ingest"] = hash_artifact(pipeline_state["stage_1_ingest"])

    # Stage 2: Sample Hygiene & Delisting Adjustment
    clean_panel = raw_panel.copy()
    clean_panel[clean_panel < -0.10] = -0.35  # Shumway adjustment
    pipeline_state["stage_2_hygiene"] = {
        "adjusted_cells": int(np.sum(raw_panel < -0.10)),
        "clean_mean": round(float(np.mean(clean_panel)), 6),
    }
    stage_hashes["stage_2_hygiene"] = hash_artifact(pipeline_state["stage_2_hygiene"])

    # Stage 3: Cross-Sectional Estimation
    f_ret = np.random.normal(0.008, 0.04, size=60)
    betas = np.zeros(10)
    for j in range(10):
        cov_jf = float(np.cov(clean_panel[:, j], f_ret)[0, 1])
        var_f = float(np.var(f_ret))
        betas[j] = cov_jf / var_f
    pipeline_state["stage_3_estimation"] = {
        "mean_beta": round(float(np.mean(betas)), 6),
        "min_beta": round(float(np.min(betas)), 6),
        "max_beta": round(float(np.max(betas)), 6),
    }
    stage_hashes["stage_3_estimation"] = hash_artifact(pipeline_state["stage_3_estimation"])

    # Stage 4: Publication Tables & Diagnostics
    t_stat = float(np.mean(betas) / (np.std(betas, ddof=1) / np.sqrt(10)))
    pipeline_state["stage_4_tables"] = {
        "table_t_stat": round(t_stat, 6),
        "table_rows": 10,
    }
    stage_hashes["stage_4_tables"] = hash_artifact(pipeline_state["stage_4_tables"])

    # 2. Cumulative Pipeline Manifest Hash
    cumulative_manifest = hash_artifact(stage_hashes)

    # 3. Deterministic Re-Execution Diff Check
    re_clean_mean = round(float(np.mean(clean_panel)), 6)
    byte_diff_error = abs(pipeline_state["stage_2_hygiene"]["clean_mean"] - re_clean_mean)

    print(f"Total Pipeline Stages: {len(stage_hashes)}")
    print(f"Stage 1 Ingest Hash: {stage_hashes['stage_1_ingest'][:12]}...")
    print(f"Stage 2 Hygiene Hash: {stage_hashes['stage_2_hygiene'][:12]}...")
    print(f"Stage 3 Estimation Hash: {stage_hashes['stage_3_estimation'][:12]}...")
    print(f"Stage 4 Tables Hash: {stage_hashes['stage_4_tables'][:12]}...")
    print(f"Cumulative Pipeline Checksum: {cumulative_manifest[:16]}...")
    print(f"Re-Execution Invariant Error: {byte_diff_error:.2e}")

Where the canon breaks

Standard empirical finance workflows fail reproducibility in three primary operational modes:

  • Interactive Notebook State Corruption: Jupyter notebooks allow out-of-order execution, retaining stale kernel variables that produce results impossible to recreate from a clean linear script execution.
  • Manual Post-Processing & Transcription Errors: Manually copying regression output from terminal screens or spreadsheets into LaTeX manuscripts causes transposed coefficients, inverted signs, and obsolete statistical counts.
  • Retroactive Vendor Database Drift: Querying live database endpoints without freezing point-in-time snapshots exposes research findings to Compustat accounting restatements and CRSP historical identifier adjustments.

Misconceptions

  1. Setting a single random seed at the top of a script guarantees reproducibility across all machines.

    Pseudo-random number generators depend on underlying C libraries and compiler vectorization. In multi-threaded or multi-core environments, race conditions in thread scheduling consume random variates out of order, producing divergent sequences unless explicit independent seed sequences (e.g. SeedSequence.spawn) are allocated to each worker.

  2. A research paper is fully reproducible if the author provides a zip file containing the cleaned final dataset and regression script.

    Providing only cleaned data bypasses the most consequential methodological choices in asset pricing: sample hygiene, microcap truncation, outlier winsorization, and delisting assumptions. A doctoral replication package must run autonomously from raw vendor files to final camera-ready figures.

  3. Docker containers automatically eliminate the need to version raw financial datasets.

    Containers encapsulate the operating system and user-space binaries, but they do not version external network databases or vendor license data. If the script queries a live database whose historical records undergo restatement, the container will produce divergent results.

Problem set

Mechanics problems

A research pipeline produces an intermediate artifact dictionary {"beta": 0.85, "alpha": 0.02}. Calculate the number of distinct JSON string serializations possible if dictionary keys are not sorted lexicographically, and explain why SHA-256 digests diverge.

Solution

For a dictionary with \(K = 2\) keys, there are \(2! = 2\) possible key orderings: {"beta": 0.85, "alpha": 0.02} and {"alpha": 0.02, "beta": 0.85}. Because SHA-256 evaluates byte sequences strictly, different key orderings yield completely different 256-bit hashes. Canonical serialization enforces sorted keys (sort_keys=True) and normalized float formatting, guaranteeing a unique byte sequence.

In a pipeline DAG with 4 sequential tasks, task execution times are: Ingest = 15s, Hygiene = 45s, Estimation = 120s, Tables = 10s. If an author modifies only the table generation script, calculate the speedup factor achieved by content-addressable storage caching versus re-running the full pipeline.

Solution

Full pipeline runtime = \(15 + 45 + 120 + 10 = 190\) seconds. With content-addressable caching, the first three stages are skipped because their inputs, code, and parameters are unchanged. Only the Table stage executes (10s), plus negligible cache lookup overhead (<0.1s). Speedup factor = \(\frac{190}{10} = 19.0\times\).

A cross-sectional asset pricing matrix \(X \in \mathbb{R}^{5000 \times 5}\) has condition number \(\kappa = 10^7\). Given double-precision machine epsilon \(\varepsilon_{\text{mach}} = 2.22 \times 10^{-16}\), calculate the upper bound on the relative error in the computed regression coefficients caused by numerical rounding.

Solution

The standard numerical linear algebra error bound states that relative solution error satisfies: \[ \frac{\|\Delta \hat{\boldsymbol{\beta}}\|}{\|\hat{\boldsymbol{\beta}}\|} \le \kappa(X) \cdot \varepsilon_{\text{mach}} = 10^7 \times 2.22 \times 10^{-16} = 2.22 \times 10^{-9} \] Rounding errors can affect the solution up to approximately 9 orders of magnitude above machine precision (around the 8th decimal place).

Proof problems

Prove that any valid computational pipeline with finite tasks and without recursive cyclical dependencies can be ordered as a topological sort, and that such an ordering is executable without deadlock.

Solution

Let \(G = (V, E)\) be a finite directed graph without directed cycles (a DAG). We proceed by induction on \(|V|\).
1. Base case: If \(|V| = 1\), the single vertex has no cycles and is trivially topologically sorted.
2. Inductive step: Assume every DAG with \(k\) vertices has a valid topological sort. Consider a DAG \(G\) with \(k + 1\) vertices. Since \(G\) is finite and contains no directed cycles, it must contain at least one vertex \(v_0\) with in-degree 0 (otherwise, tracing backward along incoming edges from any vertex would eventually repeat a vertex, creating a cycle).
3. Remove \(v_0\) and its outgoing edges from \(G\). The remaining graph \(G' = G \setminus \{v_0\}\) has \(k\) vertices and remains acyclic. By the induction hypothesis, \(G'\) has a valid topological sort \((v_1, v_2, \dots, v_k)\).
4. Placing \(v_0\) first yields the valid topological sort \((v_0, v_1, \dots, v_k)\). Because every task is executed only after all its dependencies are satisfied, no task ever waits on an uncomputed output, preventing computational deadlock.

Prove that floating-point addition under IEEE 754 is commutative but not associative: \((a \oplus b) \oplus c \neq a \oplus (b \oplus c)\), and construct an explicit numerical counterexample.

Solution

Under IEEE 754 arithmetic, the floating-point sum \(\operatorname{fl}(a + b)\) is the exact real sum rounded to the nearest representable floating-point number.
Commutativity: Real addition is commutative (\(a + b = b + a\)), so \(\operatorname{fl}(a + b) = \operatorname{fl}(b + a)\).
Non-associativity: Consider numbers where scale differences exceed the precision significand (53 bits). Let \(a = 1.0\), \(b = 2^{-53} \approx 1.11 \times 10^{-16}\), and \(c = -1.0\).
Left grouping: \((a \oplus b) \oplus c\). Since \(1.0 + 2^{-53}\) requires 54 bits of precision, under round-to-nearest-even, \(\operatorname{fl}(1.0 + 2^{-53}) = 1.0\). Then \(1.0 \oplus (-1.0) = 0.0\).
Right grouping: \(a \oplus (b \oplus c) = 1.0 \oplus (2^{-53} - 1.0)\). By real arithmetic, \(1.0 + (-1.0 + 2^{-53}) = 2^{-53}\).
Thus \((a \oplus b) \oplus c = 0.0 \neq 2^{-53} = a \oplus (b \oplus c)\). This completes the proof.

Prove that the probability of a cryptographic SHA-256 hash collision between two distinct empirical dataset artifacts is bounded by the birthday paradox to less than \(10^{-18}\) for any practical quantitative finance repository containing up to \(10^9\) artifacts.

Solution

Under the assumption of a uniform random oracle, the SHA-256 hash function maps inputs to an output space of size \(N = 2^{256}\).
By the birthday problem approximation, for \(m\) distinct artifacts, the probability of at least one hash collision is: \[ p(m) \approx 1 - \exp\left( -\frac{m^2}{2N} \right) \approx \frac{m^2}{2^{257}} \] For \(m = 10^9 \approx 2^{30}\): \[ p(10^9) \approx \frac{(2^{30})^2}{2^{257}} = \frac{2^{60}}{2^{257}} = 2^{-197} \approx 3.09 \times 10^{-60} \ll 10^{-18} \] The collision probability is astronomically small, guaranteeing that dataset digests uniquely identify empirical artifacts.

Explain how Chen & Zimmermann (2022) address the challenge of code modularity and cross-sectional anomaly re-estimation across 200+ signals in the Open Source Cross-Sectional Asset Pricing project.

Solution

Chen & Zimmermann (2022) establish an open-source architecture with three foundational pillars:
1. Standardized Predictor Signatures: Every anomaly signal is encapsulated in an isolated script that takes raw CRSP/Compustat inputs and returns a standardized pandas DataFrame with columns [permno, yyyymm, signal_value].
2. Decoupled Portfolio Engine: A shared portfolio formation engine ingests predictor signals, applies uniform NYSE market capitalization breakpoints, assigns value weights, and calculates spread portfolio returns.
3. Automated Metadata Verification: An automated test harness executes all signal scripts, compares summary statistics against original published benchmarks, and logs deviation metrics to detect data anomalies.

In a multi-process Python simulation running across 32 cores, formulate the code architecture using numpy.random.SeedSequence to guarantee independent, reproducible pseudo-random variates for each worker.

Solution

Formulation using SeedSequence spawning:

from numpy.random import SeedSequence, default_rng
from concurrent.futures import ProcessPoolExecutor

def worker_task(child_seed, worker_id):
    # Initialize independent Generator from spawned seed
    rng = default_rng(child_seed)
    # Generate Monte Carlo draws
    samples = rng.normal(loc=0.0, scale=1.0, size=10000)
    return float(samples.mean())

def run_parallel_simulation(master_seed=42, n_workers=32):
    ss = SeedSequence(master_seed)
    child_seeds = ss.spawn(n_workers)
    with ProcessPoolExecutor(max_workers=n_workers) as executor:
        futures = [executor.submit(worker_task, seed, idx) for idx, seed in enumerate(child_seeds)]
        results = [f.result() for f in futures]
    return results

Research & defense problems

A thesis examiner asks: "Your paper finds an annualized Sharpe ratio of 0.82 for your factor, but if you change the Python minor version from 3.12 to 3.14, does your result still hold?" Provide the exact architectural defense based on your Atlas pipeline manifest.

Solution

Defense: "Our empirical findings are not conditioned on unpinned Python interpreter quirks. The entire empirical DAG is packaged within an OCI-compliant container with pinned BLAS binaries and locked dependencies via uv.lock. Furthermore, all intermediate artifacts—from clean returns to covariance matrices—are checked against cryptographic SHA-256 manifests. Across Python 3.12 and 3.14, the closed-form OLS estimation produces identical coefficient vectors within double-precision machine epsilon (\(\pm 10^{-15}\)), and the factor annualized Sharpe ratio remains 0.8241 to four decimal places. The complete replication container executes autonomously via make reproduction, verifying bit-level invariant matching on any host architecture."

How does Hou, Xue & Zhang (2020) demonstrate that the replication failure of over 60% of published anomalies is driven by methodological choices in portfolio weighting rather than programming bugs?

Solution

Hou, Xue & Zhang (2020) evaluate 452 anomalies across the finance literature. They demonstrate that when anomalies are tested using equal-weighted portfolios and all-stock breakpoints, a high fraction appear statistically significant because microcaps (which account for only ~3% of aggregate market capitalization but ~60% of stock count) dominate the signal. When evaluated under institutional standards—using NYSE market capitalization breakpoints and value-weighted returns with proper Shumway delisting adjustments—the vast majority of anomalies fail to achieve statistical significance at \(t \ge 1.96\). Thus, replication divergence stems from economic hygiene choices rather than simple arithmetic code errors.

Construct an architectural policy for doctoral candidates governing the boundary between automated pipeline code and manuscript prose generation, explaining why manual editing of numbers in Overleaf should be strictly prohibited.

Solution

Policy Specification:
1. Separation of Concerns: Econometric code outputs structured data artifacts (JSON, Parquet) and serialized LaTeX tabular snippets. The manuscript contains only structural prose and formatting commands.
2. Prohibition of Hardcoded Statistics: All numerical quantities appearing in manuscript prose (e.g. sample size \(N\), time-series length \(T\), annualized Sharpe ratio, \(t\)-statistic, \(p\)-value) must be defined as LaTeX macros in an auto-generated stats_summary.tex file generated by the pipeline (e.g. \newcommand{\FactorSharpe}{0.82}) and referenced in the text via \FactorSharpe.
3. Auditability: When reviewers request a robustness check that alters sample dates, re-running the pipeline updates all macros and tables simultaneously, eliminating manual search-and-replace errors across a 50-page manuscript.

Retrieval quiz

  1. What is the primary architectural purpose of a Directed Acyclic Graph (DAG) in an empirical finance research pipeline?

    Options

    A DAG models computational tasks as nodes and data dependencies as edges, guaranteeing topological execution order and avoiding race conditions.

  2. Why must dictionary keys be sorted lexicographically before calculating SHA-256 artifact hashes?

    Options

    Cryptographic hash functions operate on byte sequences; canonical serialization ensures identical semantic data produces identical byte sequences.

  3. According to Hou, Xue & Zhang (2020), what is the primary procedural reason why many published asset pricing anomalies fail replication?

    Options

    Hou, Xue & Zhang (2020) prove that microcaps dominate equal-weighted portfolios, and majority of anomalies fail under value-weighted portfolios with NYSE breakpoints.

  4. How many output bits are produced by the standard SHA-256 cryptographic digest function?

    The SHA-256 algorithm produces a fixed 256-bit (32-byte) cryptographic digest.

  5. What risk arises when researchers execute empirical analyses inside interactive Jupyter notebooks without automated execution testing?

    Options

    Interactive notebook kernels maintain state across non-linear cell executions, masking hidden variables and missing dependencies.

  6. Why does setting np.random.seed(42 + core_id) fail to ensure statistical independence across parallel cores?

    Options

    Linear congruential and Mersenne Twister PRNGs do not guarantee independent sequences for adjacent seeds; modern libraries use SeedSequence.spawn.

  7. How should LaTeX tables in a doctoral thesis manuscript be linked to empirical code output?

    Options

    Automated export into dedicated .tex files ensures that re-running the pipeline updates all manuscript tables without transcription error.

  8. What does a dependency lockfile (such as uv.lock) guarantee in an academic replication repository?

    Options

    Lockfiles pin transitive dependencies and cryptographic hashes, preventing upstream package changes from breaking the replication environment.
