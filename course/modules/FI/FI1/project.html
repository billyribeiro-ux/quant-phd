Lab 1 · Worked example: bond pricing and risk sensitivity

A 10-year Treasury note paying 5.0% annual coupon semiannually is evaluated at a 4.5% annual yield with 45 accrued days under 30/360. Predict that dirty price exceeds par ($1,000) and that modified duration is slightly below maturity (around 7.86 years).

"""Lab FI1-project-1 (Rung 1, Worked Example): Fully solved bond analytics workflow.

SIMULATED: 10-year Treasury note with 5.0% annual coupon paid semiannually.
Computes dirty price, yield to maturity, duration, convexity, and DV01,
with explicit rationale annotated for each computational step.
Money is in integer cents; standard library only; no network.
"""

from __future__ import annotations

import math
from fractions import Fraction


def compute_dirty_price(face_cents: int, coupon_rate: Fraction, periods: int, y: Fraction) -> int:
    """Step 1: Compute dirty price on a coupon date using exact rational discounting."""
    v = Fraction(1, 1) / (1 + y)
    vn = v**periods
    annuity = (1 - vn) / y if y != 0 else Fraction(periods)
    unrounded = Fraction(face_cents) * (coupon_rate * annuity + vn)
    # Apply standard half-up integer cent rounding once to exact rational value
    return math.floor(unrounded + Fraction(1, 2))


def main() -> None:
    # Problem specification:
    # A $1,000.00 face value note paying 5.0% annual coupon semiannually (20 coupon periods)
    # Market yield is 4.5% annual (2.25% per period).
    # 45 days of interest have accrued under the 30/360 day-count convention.
    face_cents = 100_000  # $1,000.00
    annual_coupon = Fraction(5, 100)
    coupon_rate = annual_coupon / 2  # 2.5% per period = Fraction(25, 1000)
    periods = 20  # 10 years * 2
    annual_yield = Fraction(45, 1000)  # 4.5% annual yield
    yield_per_period = annual_yield / 2  # 2.25% per period

    print("Step 1 · Pricing on Coupon Date:")
    # Why: The dirty price on a coupon date discounts all 20 coupons and principal at periodic yield.
    dirty_on_coupon = compute_dirty_price(face_cents, coupon_rate, periods, yield_per_period)
    print(f"  Dirty price on coupon date = ${dirty_on_coupon / 100:.2f} ({dirty_on_coupon} cents)")

    print("\nStep 2 · Accrued Interest & Clean Price:")
    # Why: In trading, accrued interest compensates the seller for the holding period since last coupon.
    # 30/360 assumption: 45 accrued days out of 180-day semiannual period.
    semiannual_coupon_cents = math.floor(Fraction(face_cents) * coupon_rate + Fraction(1, 2))
    accrual_fraction = Fraction(45, 180)
    accrued_interest_cents = math.floor(Fraction(semiannual_coupon_cents) * accrual_fraction + Fraction(1, 2))
    # Clean price = Dirty price - Accrued interest
    clean_price_cents = dirty_on_coupon - accrued_interest_cents
    print(f"  Semiannual coupon = ${semiannual_coupon_cents / 100:.2f} ({semiannual_coupon_cents} cents)")
    print(f"  Accrued interest  = ${accrued_interest_cents / 100:.2f} ({accrued_interest_cents} cents)")
    print(f"  Clean price quote = ${clean_price_cents / 100:.2f} ({clean_price_cents} cents)")

    print("\nStep 3 · Macaulay & Modified Duration:")
    # Why: Macaulay duration is the weighted average maturity of cash flows; modified duration
    # scales it by (1 + y) to represent the percentage price sensitivity per unit yield change.
    y_float = float(yield_per_period)
    p_float = dirty_on_coupon / 100.0
    c_float = float(coupon_rate * face_cents) / 100.0
    f_float = face_cents / 100.0

    sum_t_cf = sum(k * c_float / ((1.0 + y_float) ** k) for k in range(1, periods + 1))
    sum_t_cf += periods * f_float / ((1.0 + y_float) ** periods)
    d_mac_periods = sum_t_cf / p_float
    d_mac_years = d_mac_periods / 2.0
    d_mod_annual = (d_mac_periods / (1.0 + y_float)) / 2.0
    print(f"  Macaulay Duration = {d_mac_years:.4f} years")
    print(f"  Modified Duration = {d_mod_annual:.4f} years")

    print("\nStep 4 · Convexity & DV01:")
    # Why: DV01 measures dollar exposure per 1 basis point (0.0001) shift in yield,
    # and convexity captures the second-order curvature of the price-yield function.
    sum_t_t1_cf = sum(k * (k + 1) * c_float / ((1.0 + y_float) ** k) for k in range(1, periods + 1))
    sum_t_t1_cf += periods * (periods + 1) * f_float / ((1.0 + y_float) ** periods)
    convexity_periods = sum_t_t1_cf / (p_float * ((1.0 + y_float) ** 2))
    convexity_annual = convexity_periods / 4.0

    dv01 = p_float * d_mod_annual * 0.0001
    print(f"  Annual Convexity  = {convexity_annual:.4f} years^2")
    print(f"  DV01              = ${dv01:.4f} per $1,000 face")

Lab 3 · Reference values for independent validation

Runs the core numerical routines on benchmark inputs. Compare your engine's output against these reference values before running the full autograder suite.

"""Lab FI1-project-3 (Rung 3, Sanity Run): Reference outputs for the Atlas A5 curve engine.

SIMULATED: reference bond portfolio and yield curve parameters for independent validation.
Every student implementation must reproduce these numerical values within stated tolerances.
NumPy and standard library only; no network.
"""

from __future__ import annotations

import datetime
import math
from fractions import Fraction


def day_count(start: datetime.date, end: datetime.date, conv: str) -> Fraction:
    if conv == "ACT/360":
        return Fraction((end - start).days, 360)
    if conv == "ACT/365":
        return Fraction((end - start).days, 365)
    if conv == "30/360":
        d1 = min(start.day, 30)
        d2 = min(end.day, 30)
        days = 360 * (end.year - start.year) + 30 * (end.month - start.month) + (d2 - d1)
        return Fraction(days, 360)
    raise ValueError(f"Unknown convention {conv}")


def price_bond(face: int, coupon: Fraction, periods: int, y: Fraction) -> int:
    v = Fraction(1, 1) / (1 + y)
    vn = v**periods
    annuity = (1 - vn) / y if y != 0 else Fraction(periods)
    unrounded = Fraction(face) * (coupon * annuity + vn)
    return math.floor(unrounded + Fraction(1, 2))


def ns_eval(tau: float, b0: float, b1: float, b2: float, lam: float) -> float:
    x = tau / lam
    g = (1.0 - math.exp(-x)) / x
    return float(b0 + b1 * g + b2 * (g - math.exp(-x)))


def sv_eval(tau: float, b0: float, b1: float, b2: float, b3: float, l1: float, l2: float) -> float:
    ns_part = ns_eval(tau, b0, b1, b2, l1)
    x2 = tau / l2
    g2 = (1.0 - math.exp(-x2)) / x2
    return float(ns_part + b3 * (g2 - math.exp(-x2)))


def main() -> None:
    # 1. Day count reference
    d_start = datetime.date(2024, 1, 15)
    d_end = datetime.date(2024, 7, 15)
    print("Reference Day Count Fractions (2024-01-15 to 2024-07-15):")
    for conv in ("ACT/360", "ACT/365", "30/360"):
        frac = day_count(d_start, d_end, conv)
        print(f"  {conv:7s} = {frac} ({float(frac):.6f})")

    # 2. Bond pricing reference
    face = 100_000
    coupon = Fraction(25, 1000)
    periods = 20
    yield_period = Fraction(225, 10000)
    p_cents = price_bond(face, coupon, periods, yield_period)
    print("\nReference Dirty Price (Face = $1000, 20 periods, c = 2.5%, y = 2.25%):")
    print(f"  Price = ${p_cents / 100:.2f} ({p_cents} cents)")

    # 3. Bootstrapping reference on 4 par bonds (1, 2, 3, 4 periods)
    # Par coupons per period: 1.5%, 1.8%, 2.0%, 2.2%
    par_coupons = [Fraction(15, 1000), Fraction(18, 1000), Fraction(20, 1000), Fraction(22, 1000)]
    dfs: list[Fraction] = [Fraction(1, 1)]
    zero_rates: list[float] = []
    print("\nReference Bootstrapping on 4 Par Bonds:")
    for n, c in enumerate(par_coupons, start=1):
        # Par bond: price_ratio = 1
        df_n = (Fraction(1, 1) - c * sum(dfs[1:n])) / (1 + c)
        dfs.append(df_n)
        zn = float(df_n) ** (-1.0 / n) - 1.0
        zero_rates.append(zn)
        print(f"  Period {n}: DF = {float(df_n):.6f}, Zero Rate = {zn:.6%}")

    # 4. Nelson-Siegel and Svensson reference yields
    b0, b1, b2, b3 = 0.05, -0.02, 0.02, -0.01
    l1, l2 = 2.0, 5.0
    print("\nReference Curve Yields (tau = 1, 2, 5, 10, 30 years):")
    for tau in (1.0, 2.0, 5.0, 10.0, 30.0):
        y_ns = ns_eval(tau, b0, b1, b2, l1)
        y_sv = sv_eval(tau, b0, b1, b2, b3, l1, l2)
        print(f"  tau = {tau:4.1f} yr: NS = {y_ns:.6%}, Svensson = {y_sv:.6%}")

Rung 3 · Specification

Context
A quantitative trading desk requires a deterministic, robust fixed-income analytics engine. The engine must compute exact day-count fractions, price coupon bonds to the integer cent, solve for yields by bisection, extract zero rates via bootstrapping, and calibrate Nelson-Siegel and Svensson parametric models.
Inputs
Synthetic bond portfolios, cash flow parameters, and yield curves generated deterministically from integer seeds via make_instance(seed). Labelled SIMULATED per BLUEPRINT §5.3.
Required outputs
A Python module implementing atlas.curves at atlas/curves.py exporting:
  • DAY_COUNT_CONVENTIONS: tuple[str, ...]
  • day_count_fraction(start: datetime.date, end: datetime.date, convention: str) -> Fraction
  • price_from_yield(face_cents: int, coupon_rate: Fraction, periods: int, yield_per_period: Fraction) -> int
  • yield_to_maturity(dirty_cents: int, face_cents: int, coupon_rate: Fraction, periods: int) -> Fraction
  • bootstrap_zero_rates(par_bonds: list[dict[str, Any]]) -> dict[int, float]
  • ns_yield(tau: float, beta0: float, beta1: float, beta2: float, lam: float) -> float
  • svensson_yield(tau: float, beta0: float, beta1: float, beta2: float, beta3: float, lam1: float, lam2: float) -> float
  • fit_nelson_siegel(maturities: list[Fraction], yields: list[Fraction]) -> dict[str, float]
  • fit_svensson(maturities: list[Fraction], yields: list[Fraction]) -> dict[str, float]
Constraints
Standard library and NumPy only (no SciPy). All money outputs must be exact integer cents rounded half up via math.floor(P + Fraction(1, 2)). No global mutable state, no network calls, and all functions must execute within stated Pyodide runtime limits.
Grading mode
Autograder: graded automatically against pytest suite test_project.py over 50 consecutive seeds (0 through 49).
