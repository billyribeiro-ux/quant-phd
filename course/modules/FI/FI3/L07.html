Carry & Roll-Down Strategies

In relative-value rates trading, portfolio managers frequently evaluate bond investments under the static benchmark assumption that the yield curve remains unchanged over the holding period. Under this assumption, the expected return decomposes into coupon income accrual (carry) and capital appreciation from the bond rolling down an upward-sloping yield curve toward maturity. Understanding carry and roll-down provides traders with a deterministic baseline against which to evaluate interest rate risks, duration bets, and relative-value cross-market positioning.

1Static Curve Horizon Return Decomposition

Consider an \(n\)-period zero-coupon bond held over a holding horizon \(h \le n\). Let the spot yield curve at inception be denoted \(y_t(\tau)\) for maturity \(\tau\).

Definition 7.1 (Carry and Roll-Down)

Assuming the yield curve remains static over horizon \(h\) (so that \(y_{t+h}(\tau) = y_t(\tau)\) for all \(\tau\)), the carry and roll-down return \(H_{t, t+h}^{(n)}\) is defined as the holding-period return generated entirely by the passage of time:

\[ H_{t, t+h}^{(n)} \equiv \mathrm{Carry}_{t, t+h}^{(n)} + \mathrm{RollDown}_{t, t+h}^{(n)} \]

where:

  • \(\mathrm{Carry}_{t, t+h}^{(n)} \equiv h \cdot y_t^{(n)}\) represents the pure yield accrual over duration \(h\).
  • \(\mathrm{RollDown}_{t, t+h}^{(n)} \equiv (n - h)\left(y_t^{(n)} - y_t^{(n-h)}\right)\) represents the capital gain achieved as the bond ages into a lower-yielding tenor on an upward-sloping curve.
Theorem 7.1 (Horizon Return Identity on Static Curves)

The total discrete holding-period return \(R_{t, t+h}^{(n)} \equiv p_{t+h}^{(n-h)} - p_t^{(n)}\) on a static yield curve identically satisfies:

\[ R_{t, t+h}^{(n)} = h y_t^{(n)} + (n - h) \left(y_t^{(n)} - y_t^{(n-h)}\right) \]

Annualizing the horizon return by dividing by \(h\) gives:

\[ \frac{1}{h} R_{t, t+h}^{(n)} = y_t^{(n)} + \frac{n - h}{h}\left(y_t^{(n)} - y_t^{(n-h)}\right) \]
Proof

By definition of zero-coupon bond log prices, \(p_t^{(n)} = -n y_t^{(n)}\). At time \(t+h\), the remaining maturity is \(n - h\). Under a static yield curve, \(y_{t+h}^{(n-h)} = y_t^{(n-h)}\), so \(p_{t+h}^{(n-h)} = -(n - h) y_t^{(n-h)}\). Therefore:

\[ \begin{aligned} R_{t, t+h}^{(n)} &= p_{t+h}^{(n-h)} - p_t^{(n)} = -(n - h) y_t^{(n-h)} - \left(-n y_t^{(n)}\right) \\ &= n y_t^{(n)} - (n - h) y_t^{(n-h)} = h y_t^{(n)} + (n - h)\left(y_t^{(n)} - y_t^{(n-h)}\right) \quad \blacksquare \end{aligned} \]

2The Roll-Down "Sweet Spot"

Because roll-down is the product of remaining modified duration \((n - h)\) and curve slope \((y_t^{(n)} - y_t^{(n-h)})\), the roll-down return is not maximized at the longest maturity:

  • At very short maturities (e.g., 6 months to 1 year), the curve is steep, but duration is tiny, so the product is small.
  • At very long maturities (e.g., 20 to 30 years), duration is large, but the yield curve is virtually flat, so the yield difference is near zero.
  • The peak roll-down return occurs at the intermediate "belly" of the yield curve (typically between 5 and 7 years), where the product of duration and curve steepness is maximized.

3Net Carry vs. Term Premium

Traders frequently evaluate the excess carry over financing costs: \(\mathrm{Carry} - h \cdot r_t = h (y_t^{(n)} - r_t)\). As shown by Adrian, Crump, and Moench (2013), carry and roll-down strategies systematically capture the term premium when yield curve slope reflects risk compensation rather than imminent rate hikes.

Lab 1 · Carry and roll-down analytics on upward-sloping yield curves

On an upward-sloping yield curve, roll-down return is strictly positive for all bonds with maturity exceeding the holding period, and total horizon return decomposes identically into yield accrual (carry) plus roll-down capital appreciation, with maximum roll-down concentrated in the intermediate 5- to 7-year tenors.

"""Lab FI3-L07-1: Carry and roll-down analytics on upward-sloping yield curves.

SIMULATED: evaluates carry, roll-down, and total horizon return across maturities
on a stylized upward-sloping parametric yield curve.
Standard library and NumPy only; no network.
"""

from __future__ import annotations

import numpy as np


def analyze_carry_roll(yield_curve: np.ndarray, maturities: np.ndarray, horizon: float = 1.0) -> dict[str, np.ndarray]:
    """Decompose horizon return into carry and roll-down on a static curve:

    Carry = horizon * y(tau)
    Roll-down = (tau - horizon) * [y(tau) - y(tau - horizon)] for tau > horizon
    Total Carry-Roll = Carry + Roll-down.
    """
    k_mat = len(maturities)
    carry = horizon * yield_curve
    roll_down = np.zeros(k_mat, dtype=np.float64)

    for i in range(k_mat):
        tau = maturities[i]
        if tau > horizon:
            tau_rem = tau - horizon
            y_rem = float(np.interp(tau_rem, maturities, yield_curve))
            roll_down[i] = tau_rem * (yield_curve[i] - y_rem)

    total_carry_roll = carry + roll_down
    annualized = total_carry_roll / horizon

    return {
        "carry": carry,
        "roll_down": roll_down,
        "total_carry_roll": total_carry_roll,
        "annualized": annualized,
    }


def main() -> None:
    # Stylized Nelson-Siegel upward-sloping curve:
    # y(tau) = beta_0 + beta_1 * ((1 - exp(-tau/2)) / (tau/2))
    maturities = np.array([0.5, 1.0, 2.0, 3.0, 5.0, 7.0, 10.0, 20.0, 30.0], dtype=np.float64)
    beta0 = 0.050
    beta1 = -0.025
    lam = 2.5
    x = maturities / lam
    curve = beta0 + beta1 * ((1.0 - np.exp(-x)) / x)

    horizon = 1.0  # 1-year horizon
    res = analyze_carry_roll(curve, maturities, horizon=horizon)

    carry = res["carry"]
    roll = res["roll_down"]
    total = res["total_carry_roll"]

    print("Carry and Roll-Down Breakdown (1-Year Horizon, Static Curve):")
    print("  Maturity | Spot Yield |   Carry   | Roll-down | Total Return | Roll/Total")
    print("  ---------+------------+-----------+-----------+--------------+-----------")
    for i, m in enumerate(maturities):
        pct_roll = (roll[i] / total[i]) * 100.0 if total[i] != 0 else 0.0
        line_str = (
            f"   {m:4.1f}y   |  {curve[i]:7.4%}  |  {carry[i]:6.4%}  |  "
            f"{roll[i]:7.4%}  |   {total[i]:7.4%}    |  {pct_roll:5.1f}%"
        )
        print(line_str)

    # Invariant: Total == Carry + Roll
    assert np.allclose(total, carry + roll, atol=1e-14)
    # Roll-down strictly positive for all maturities > 1.0y
    idx_gt_h = np.where(maturities > horizon)[0]
    assert np.all(roll[idx_gt_h] > 0.0)

    # Find peak roll-down maturity
    peak_idx = int(np.argmax(roll))
    print(f"\nPeak roll-down occurs at {maturities[peak_idx]:.1f}y: {roll[peak_idx]:.4%} per year.")
    print("Mathematical identity (Total == Carry + Roll) verified to machine precision.")


main()

Where the canon breaks

Static carry-roll analysis is the industry standard heuristic for evaluating curve trades, but its assumptions frequently break down in volatile rate environments:

  • The Static Curve Fallacy: Yield curves are dynamic, not static. If the curve shifts upward by more than \(\mathrm{Carry} + \mathrm{RollDown}\) divided by duration, all carry gains are wiped out by capital losses.
  • Convexity Distortion: For long-duration bonds, discrete price changes diverge from first-order linear duration approximations due to positive convexity \(\frac{1}{2} D_{\text{mod}}^2 (\Delta y)^2\), requiring second-order Taylor expansion terms in trade analysis.

Misconceptions

  1. Roll-down return is highest at the 30-year bond because 30-year bonds have the highest duration.

    Roll-down is the product of duration and curve slope \((y_t^{(n)} - y_t^{(n-h)})\). Because the yield curve is very flat between 20 and 30 years, the slope is near zero, making 30-year roll-down far smaller than 5-year roll-down.

  2. Carry and roll-down are risk-free profits guaranteed to the investor.

    Carry and roll-down represent horizon return conditional on an unchanged yield curve. A parallel shift of just 15 basis points on a 10-year bond erases over 100 basis points of annual carry and roll-down.

  3. When the yield curve is inverted, roll-down is zero.

    When the yield curve is inverted (\(y_t^{(n)} < y_t^{(n-h)}\)), roll-down is strictly negative (roll-up), acting as a drag against carry.

Problem set

Mechanics

A 5-year zero-coupon bond currently yields 4.20%, and the 4-year zero-coupon yield is 3.90%. Calculate the 1-year carry, roll-down, and total expected static return in basis points.

Solution

Carry over 1 year is \(h \cdot y_t^{(5)} = 1 \times 4.20\% = 420\text{ bps}\). Roll-down is \((n - h)(y_t^{(5)} - y_t^{(4)}) = (5 - 1)(4.20\% - 3.90\%) = 4 \times 0.30\% = 1.20\% = 120\text{ bps}\). Total expected static return is \(420 + 120 = 540\text{ bps}\). This demonstrates the significant contribution of roll-down.

Suppose an investor purchases a 10-year zero-coupon bond at yield 4.50%. The 9-year yield is 4.42%. How much can the 9-year yield rise over the next year before the investor's total return drops below the 1-year risk-free rate of 3.50%?

Solution

The static 1-year return is \(\mathrm{Carry} + \mathrm{Roll} = 4.50\% + 9(4.50\% - 4.42\%) = 4.50\% + 0.72\% = 5.22\%\). The return cushion over the risk-free rate is \(5.22\% - 3.50\% = 1.72\%\). With remaining duration 9 years, the breakeven yield rise is \(\Delta y = 1.72\% / 9 \approx 0.191\%\) or 19.1 basis points. If yields rise more than 19.1 bps, the trade underperforms cash.

On an inverted yield curve, the 3-year yield is 4.80% and the 2-year yield is 5.20%. Compute the 1-year roll-down return for holding a 3-year bond.

Solution

Roll-down is \((n - h)(y_t^{(3)} - y_t^{(2)}) = (3 - 1)(4.80\% - 5.20\%) = 2 \times (-0.40\%) = -0.80\%\) or -80 basis points. In an inverted regime, roll-down is negative and subtracts from yield accrual.

Proof

Prove that for a continuous-time yield curve \(y(\tau)\), the instantaneous roll-down return per unit time is given by \(\tau \frac{\partial y(\tau)}{\partial \tau}\).

Solution

Log bond price is \(p(t, \tau) = -\tau y(t, \tau)\). Taking the total derivative with respect to time as maturity rolls down (\(d\tau = -dt\)) on a time-invariant curve (\(\frac{\partial y}{\partial t} = 0\)): \(\frac{dp}{dt} = -\frac{d}{dt}[\tau y(\tau)] = -[(-1) y(\tau) + \tau \frac{dy}{d\tau}(-1)] = y(\tau) + \tau \frac{dy}{d\tau}\). The first term \(y(\tau)\) is the instantaneous carry, and the second term \(\tau \frac{dy(\tau)}{d\tau}\) is the instantaneous roll-down. \(\blacksquare\)

Under a Nelson-Siegel curve \(y(\tau) = \beta_0 + \beta_1 \frac{1 - e^{-\tau/\lambda}}{\tau/\lambda}\), prove that if \(\beta_1 < 0\), the roll-down is strictly positive for all \(\tau > 0\).

Solution

Compute the derivative \(\frac{dy}{d\tau} = \beta_1 \frac{d}{d\tau}[\frac{1 - e^{-x}}{x}]\) where \(x = \tau/\lambda\). Let \(g(x) = \frac{1 - e^{-x}}{x}\). Its derivative is \(g'(x) = \frac{x e^{-x} - (1 - e^{-x})}{x^2} = \frac{-(1 - (1+x)e^{-x})}{x^2}\). For all \(x > 0\), \(e^x > 1 + x\), so \(1 > (1+x)e^{-x}\), making \(g'(x) < 0\). Since \(\beta_1 < 0\), \(\frac{dy}{d\tau} = \frac{\beta_1}{\lambda} g'(x) > 0\). Because \(\tau > 0\) and \(\frac{dy}{d\tau} > 0\), instantaneous roll-down \(\tau \frac{dy}{d\tau} > 0\) strictly. \(\blacksquare\)

Prove that under a flat yield curve \(y(\tau) = y_0\) for all \(\tau\), the annualized horizon return over any horizon \(h\) is independent of bond maturity \(n\).

Solution

Under a flat curve, \(y_t^{(n)} = y_0\) and \(y_t^{(n-h)} = y_0\). By Theorem 7.1, \(\frac{1}{h} R_{t, t+h}^{(n)} = y_t^{(n)} + \frac{n-h}{h}(y_t^{(n)} - y_t^{(n-h)}) = y_0 + \frac{n-h}{h}(y_0 - y_0) = y_0\). This equals \(y_0\) identically for all \(n \ge h\), proving maturity invariance. \(\blacksquare\)

Empirical

Why do multi-asset systematic carry strategies consistently allocate higher weights to 5-year Treasuries than to 30-year Treasuries?

Solution

5-year Treasuries provide the highest roll-down per unit of duration risk (the sweet spot). While 30-year Treasuries have greater absolute duration, their curve slope is minimal, resulting in inferior risk-adjusted carry-to-volatility ratios compared to 5-year and 7-year notes.

In upward-sloping yield curve regimes, what fraction of total holding-period return on a 5-year Treasury note is typically provided by roll-down versus carry?

Solution

Empirical analyses on US Treasury data indicate that roll-down accounts for approximately 15% to 25% of total 1-year holding return on a 5-year Treasury note, adding between 60 and 90 basis points of capital appreciation on top of coupon carry.

How does the performance of a carry-roll bond strategy behave during monetary tightening cycles?

Solution

During central bank rate hiking cycles, the short end rises rapidly and the yield curve inverts. The strategy suffers from both negative capital losses due to rising yields and the collapse of roll-down into negative roll-up, resulting in severe performance drawdowns.

Research

Formulate an analytical optimization model to select the portfolio maturity weights that maximize carry-and-roll-down subject to zero net duration and tracking error constraints.

Solution

Maximize \(w^\top (\mathrm{Carry} + \mathrm{Roll})\) subject to \(\sum w_i D_i = 0\) (duration neutrality), \(\sum w_i = 0\) (dollar neutrality), and \(w^\top \Sigma w \le \sigma_{\text{target}}^2\) where \(\Sigma\) is the yield curve factor covariance matrix. This quadratic program extracts pure curve-shape carry isolated from level shifts.

Explain how cross-country carry trades between US Treasuries and German Bunds isolate currency-hedged term premia differentials.

Solution

By purchasing high-carry Treasuries and shorting low-carry Bunds while hedging FX risk via 3-month forward contracts, Covered Interest Parity (CIP) forces the short-rate carry differential to wash out against the FX forward points. The remaining net profit isolates the difference between US and German term premia and roll-down slopes.

How does incorporating term premium model forecasts (such as ACM) prevent "carry traps" in rates markets?

Solution

A "carry trap" occurs when an apparently high yield reflects impending central bank hikes or sovereign distress rather than true risk premia. Decomposing yield into expected path \(\bar{r}\) and term premium \(\mathrm{TP}\) allows managers to penalize trades where high carry is driven by rate hikes, avoiding positions with imminent capital loss.

Retrieval quiz

  1. Under the assumption of a static yield curve, what are the two components of horizon return?

    Options

    Total return on a static curve decomposes into carry \(h y_t^{(n)}\) and roll-down \((n-h)(y_t^{(n)} - y_t^{(n-h)})\).

  2. If a 5-year bond yields 4.20% and the 4-year bond yields 3.90%, what is the 1-year roll-down return in basis points?

    \((5 - 1)(4.20\% - 3.90\%) = 4 \times 0.30\% = 1.20\% = 120\text{ bps}\).

  3. Why does the 30-year Treasury bond typically have lower roll-down return than a 5-year Treasury note?

    Options

    Roll-down requires both duration and curve slope. The slope between 29y and 30y is virtually zero.

  4. What happens to roll-down return when the yield curve is inverted (\(y_t^{(n)} < y_t^{(n-h)}\))?

    Options

    On an inverted curve, a bond ages into higher yields, producing negative roll-down (capital loss).

  5. If the 5-year bond has 420 bps of carry and 120 bps of roll-down over 1 year, what is the total expected static return in basis points?

    \(420 + 120 = 540\text{ bps}\).

  6. In continuous time, what is the formula for the instantaneous roll-down return of a zero-coupon bond?

    Options

    Differentiating \(p = -\tau y(\tau)\) with \(d\tau = -dt\) gives \(\tau \frac{\partial y}{\partial \tau}\).

  7. What is a primary danger of relying solely on static carry and roll-down for portfolio positioning?

    Options

    Yield curves are dynamic; an adverse parallel shift of 15-20 bps completely eliminates typical carry-roll returns.

  8. At which segment of an upward-sloping yield curve is roll-down return typically maximized?

    Options

    The product of duration and slope peaks in the belly (5y to 7y).
