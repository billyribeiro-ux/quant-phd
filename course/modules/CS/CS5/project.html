Lab 1 · Worked example: step-by-step path generation

The script executes a two-path Monte Carlo pricing calculation on SIMULATED market parameters, printing intermediate 64-bit generator words, uniforms, normal deviates, terminal asset values, and discounted payoffs.

"""CS5 Project Rung 1: Worked example tracing Monte Carlo path generation.

Standard library only. SIMULATED data. Traces exact SplitMix64 state transitions,
uniform extraction, Box-Muller normal generation, and discounted payoffs.
"""

from __future__ import annotations

import math

SPLITMIX_GAMMA: int = 0x9E3779B97F4A7C15
SPLITMIX_MUL1: int = 0xBF58476D1CE4E5B9
SPLITMIX_MUL2: int = 0x94D049BB133111EB
MASK64: int = 0xFFFFFFFFFFFFFFFF
TWO_POW_53: float = 9007199254740992.0


def step_splitmix64(state: int) -> tuple[int, int]:
    """Advance 64-bit state by one step and return (new_state, output_64bit)."""
    state = (state + SPLITMIX_GAMMA) & MASK64
    z = state
    z = ((z ^ (z >> 30)) * SPLITMIX_MUL1) & MASK64
    z = ((z ^ (z >> 27)) * SPLITMIX_MUL2) & MASK64
    out = (z ^ (z >> 31)) & MASK64
    return state, out


def trace_two_paths() -> None:
    """Trace a 2-path Monte Carlo option pricing calculation step by step."""
    s0 = 100.0
    strike = 100.0
    rate = 0.05
    vol = 0.20
    maturity = 1.0
    seed = 42

    drift = (rate - 0.5 * vol * vol) * maturity
    vol_sqrt_t = vol * math.sqrt(maturity)
    df = math.exp(-rate * maturity)

    state = seed & MASK64
    discounted_calls: list[float] = []
    discounted_puts: list[float] = []

    print(f"Parameters: S0={s0:.1f}, K={strike:.1f}, r={rate:.2f}, sigma={vol:.2f}, tau={maturity:.1f}, seed={seed}")
    print(f"Drift term: (r - 0.5*sigma^2)*tau = {drift:.6f}")
    print(f"Diffusion multiplier: sigma*sqrt(tau) = {vol_sqrt_t:.6f}")
    print(f"Discount factor: exp(-r*tau) = {df:.6f}")

    for path_idx in range(2):
        state, x1 = step_splitmix64(state)
        state, x2 = step_splitmix64(state)
        u1 = ((x1 >> 11) + 0.5) / TWO_POW_53
        u2 = ((x2 >> 11) + 0.5) / TWO_POW_53

        z = math.sqrt(-2.0 * math.log(u1)) * math.cos(2.0 * math.pi * u2)
        st = s0 * math.exp(drift + vol_sqrt_t * z)
        c_payoff = max(st - strike, 0.0)
        p_payoff = max(strike - st, 0.0)
        dc = df * c_payoff
        dp = df * p_payoff
        discounted_calls.append(dc)
        discounted_puts.append(dp)

        print(
            f"Path {path_idx + 1}: x1=0x{x1:016x} x2=0x{x2:016x} u1={u1:.6f} u2={u2:.6f} "
            f"z={z:+.6f} ST={st:.4f} CallPayoff={c_payoff:.4f} PutPayoff={p_payoff:.4f}"
        )

    call_mean = sum(discounted_calls) / 2.0
    put_mean = sum(discounted_puts) / 2.0
    # Sample variance with ddof = 1
    call_var = sum((x - call_mean) ** 2 for x in discounted_calls) / 1.0
    put_var = sum((x - put_mean) ** 2 for x in discounted_puts) / 1.0
    call_se = math.sqrt(call_var / 2.0)
    put_se = math.sqrt(put_var / 2.0)

    print(f"Estimated Call Price: {call_mean:.6f} (SE: {call_se:.6f})")
    print(f"Estimated Put Price:  {put_mean:.6f} (SE: {put_se:.6f})")


def main() -> None:
    trace_two_paths()

Specification

Context
A quantitative trading team requires an ultra-low latency European option pricer capable of simulating millions of geometric Brownian motion trajectories per second. The simulation must provide identical seeded output between a high-level Python prototyping layer and an optimized C++ production engine, enabling automated regression testing across languages.
Inputs
Option pricing calculations accept seven parameters:
  • s0 (float > 0): Spot asset price at \(t=0\).
  • strike (float > 0): Option strike price \(K\).
  • rate (float): Continuously compounded risk-free rate \(r\).
  • vol (float > 0): Annualized asset price volatility \(\sigma\).
  • maturity (float > 0): Time to expiration \(\tau\) in years.
  • n_paths (int \(\ge\) 2): Number of simulated terminal price paths.
  • seed (int in \([0, 2^{64}-1]\)): 64-bit unsigned integer initialization seed.
All float parameters must be finite real numbers.
Required outputs
  • rng_stream(seed: int, count: int) -> list[int]: Returns the first count 64-bit unsigned integers generated by SplitMix64.
  • price_call_and_put(s0: float, strike: float, rate: float, vol: float, maturity: float, n_paths: int, seed: int) -> tuple[float, float, float, float]: Returns (call_price, call_se, put_price, put_se).
  • kernel/mc_pricer.hpp & kernel/mc_pricer.cpp: Native C++20 implementation of the generator and pricing kernel.
  • bindings/streamkernel.py: Python binding wrapping the compiled shared library via ctypes.
  • BENCHMARK.md: Empirical comparison documenting execution timing, hardware specifications, compiler flags, and speedup ratios.
  • REPORT.md: Technical architectural report analyzing where execution speedups originate (cache locality, register allocation, compiler vectorization).
Constraints
Modern C++ (C++20) compiled with -O2 or -O3. No external third-party libraries (standard library only). The Python layer must use ctypes and standard library modules. The following conditions must raise ValueError: (1) Non-finite floating-point parameters (NaN, \(+\infty\), \(-\infty\)); (2) s0 <= 0.0; (3) strike <= 0.0; (4) vol <= 0.0; (5) maturity <= 0.0; (6) n_paths < 2; (7) seed < 0 or seed >= 2^64; (8) count < 0 in rng_stream. Prices must match the Python reference solution within relative tolerance \(10^{-9}\) plus absolute tolerance \(10^{-12}\). The random number stream must match bit-for-bit.
Grading
Grading: autograder. The project is evaluated by an automated acceptance test suite in grader/test_project.py over seeds 0 through 49. The autograder validates bit-for-bit stream equality, pricing tolerance bounds, standard error degrees of freedom (\(n - 1\)), spot monotonicity, and boundary condition error handling.

Lab 3 · Baseline verification and put-call parity check

Runs the Monte Carlo pricing engine over 10,000 SIMULATED paths, printing the first four 64-bit generator outputs, European call and put estimates, and verifying numerical put-call parity.

"""CS5 Project Rung 3: Independent verification driver and performance baseline.

Standard library only. SIMULATED data. Runs the reference pricing kernel over
10,000 paths, validating stream integrity, option values, and put-call parity.
"""

from __future__ import annotations

import math

SPLITMIX_GAMMA: int = 0x9E3779B97F4A7C15
SPLITMIX_MUL1: int = 0xBF58476D1CE4E5B9
SPLITMIX_MUL2: int = 0x94D049BB133111EB
MASK64: int = 0xFFFFFFFFFFFFFFFF
TWO_POW_53: float = 9007199254740992.0


def step_splitmix64(state: int) -> tuple[int, int]:
    state = (state + SPLITMIX_GAMMA) & MASK64
    z = state
    z = ((z ^ (z >> 30)) * SPLITMIX_MUL1) & MASK64
    z = ((z ^ (z >> 27)) * SPLITMIX_MUL2) & MASK64
    out = (z ^ (z >> 31)) & MASK64
    return state, out


def run_benchmark(n_paths: int = 10000, seed: int = 20261110) -> None:
    s0 = 100.0
    strike = 100.0
    rate = 0.05
    vol = 0.20
    maturity = 1.0

    state = seed & MASK64
    first_four: list[str] = []
    for _ in range(4):
        state, val = step_splitmix64(state)
        first_four.append(f"0x{val:016x}")

    # Reset state for path pricing
    state = seed & MASK64
    drift = (rate - 0.5 * vol * vol) * maturity
    vol_sqrt_t = vol * math.sqrt(maturity)
    df = math.exp(-rate * maturity)

    calls: list[float] = [0.0] * n_paths
    puts: list[float] = [0.0] * n_paths
    st_sum = 0.0

    for i in range(n_paths):
        state, x1 = step_splitmix64(state)
        state, x2 = step_splitmix64(state)
        u1 = ((x1 >> 11) + 0.5) / TWO_POW_53
        u2 = ((x2 >> 11) + 0.5) / TWO_POW_53

        z = math.sqrt(-2.0 * math.log(u1)) * math.cos(2.0 * math.pi * u2)
        st = s0 * math.exp(drift + vol_sqrt_t * z)
        st_sum += st

        calls[i] = df * max(st - strike, 0.0)
        puts[i] = df * max(strike - st, 0.0)

    call_price = sum(calls) / n_paths
    put_price = sum(puts) / n_paths
    mean_st = st_sum / n_paths

    call_var = sum((c - call_price) ** 2 for c in calls) / (n_paths - 1)
    put_var = sum((p - put_price) ** 2 for p in puts) / (n_paths - 1)
    call_se = math.sqrt(call_var / n_paths)
    put_se = math.sqrt(put_var / n_paths)

    parity_lhs = call_price - put_price
    parity_rhs = df * (mean_st - strike)

    print(f"Rung 3 Benchmark Results (Paths: {n_paths}, Seed: {seed}):")
    print(f"Generator first 4 outputs: {', '.join(first_four)}")
    print(f"Call Price: {call_price:.6f} (SE: {call_se:.6f})")
    print(f"Put Price:  {put_price:.6f} (SE: {put_se:.6f})")
    print(f"Put-Call Parity: LHS={parity_lhs:.6f}, RHS={parity_rhs:.6f}, Diff={abs(parity_lhs - parity_rhs):.2e}")


def main() -> None:
    run_benchmark()
