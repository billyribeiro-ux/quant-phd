C++ & Systems for Finance

Master high-performance systems programming in modern C++ (C++20) for algorithmic trading, low-latency market gateways, and derivative pricing engines. Learn value semantics, RAII, compile-time template metaprogramming, CPU cache hierarchy optimization, memory layout vectorization, and cross-language boundaries.

Course objectives

  1. Analyze translation unit compilation, linker symbol tables, and One Definition Rule (ODR) constraints across multi-module builds (Lesson 1).
  2. Implement move constructors, value semantics, and the Rule of Five to eliminate heap allocations along latency paths (Lesson 2).
  3. Formulate exception-safe resource management policies using RAII and smart pointers across market feed lifecycles (Lesson 3).
  4. Construct generic, compile-time polymorphic pricing algorithms constrained by C++20 concepts and requires clauses (Lesson 4).
  5. Evaluate algorithmic complexity and cache efficiency across STL containers and PMR arena memory allocators (Lesson 5).
  6. Model hardware cache line access patterns, L1/L2 miss latencies, and multi-core false sharing on multi-threaded execution (Lesson 6).
  7. Transform financial quote structures into Struct-of-Arrays (SoA) memory layouts to double cache line utilization and enable SIMD (Lesson 7).
  8. Build high-performance foreign function boundaries via C ABI ctypes wrappers and compile freestanding C++ kernels to WebAssembly (Lesson 8).

Prerequisites

CS5 assumes mastery of CS2 (Algorithms & Data Structures) and CS4 (Software Engineering & Reproducibility). It builds upon concepts introduced across the curriculum closure:

  • From CS2: big-O complexity, hash map, binary heap, and order book data structures.
  • From CS4: deterministic computation and bit-for-bit reproducibility.
  • From M1: direct proof, exponential and logarithm, and continuous compounding.
  • From CS1: type hints, Python exceptions, and unit tests.

Placement diagnostic

Ten questions evaluate your readiness for CS5: eight on prerequisite fundamentals, and two skill checks covering the core competencies taught in rungs 1 and 2 of the Monte Carlo project. Achieving the 80% mastery threshold (at least 8 correct including both skill checks) allows proceeding directly to the independent project.

  1. What is the average-case lookup complexity in an ideal hash map?

    Options

    Under simple uniform hashing, lookup complexity is \(\mathcal{O}(1)\) average-case (CS2, hash-map).

  2. What is the height of a complete binary tree with 1,023 nodes?

    A complete binary tree with \(N = 2^{10} - 1 = 1023\) nodes has height \(\lfloor \log_2 1023 \rfloor + 1 = 10\) (CS2, binary-heap).

  3. What does bit-for-bit reproducibility require when running floating-point computations across environments?

    Options

    Bit-for-bit reproducibility requires deterministic integer seeds and identical mathematical evaluation order (CS4, bit-for-bit-reproducibility).

  4. How many bytes comprise a standard hardware cache line on modern x86-64 CPUs?

    Modern x86 and ARM processors standardize on 64-byte cache lines.

  5. Which discount factor discounts cash flow \(C\) received at \(\tau\) under continuous compounding at rate \(r\)?

    Options

    Continuous compounding uses \(\exp(-r \tau)\) (M1, continuous-compounding).

  6. What does an extern "C" linkage specification tell the C++ compiler?

    Options

    extern "C" prevents C++ name mangling, allowing dynamic libraries to export stable C ABI symbols.

  7. How many 8-byte double values fit in a single 64-byte cache line?

    \(64 / 8 = 8\) doubles fit in one cache line.

  8. What is the result of dereferencing a nullptr in standard C++?

    Options

    Dereferencing a null pointer is undefined behavior in C++.

  9. Skill check (rung 1): In Box-Muller transformation \(z = \sqrt{-2 \ln u_1} \cos(2\pi u_2)\), what is \(z\) when \(u_2 = 0.25\)?

    \(\cos(2\pi \times 0.25) = \cos(\pi / 2) = 0\), yielding \(z = 0\) regardless of \(u_1\).

  10. Skill check (rung 2): In sample variance estimation \(\sum (x_i - \bar{x})^2 / \text{denom}\), what is the unbiased denominator for \(n\) paths?

    Options

    Bessel's correction requires dividing by \(n - 1\) to provide an unbiased sample variance estimator.

The project ladder

The 52-hour capstone project challenges you to develop a production-ready C++ Monte Carlo option pricer with identical seeded output to Python, exposed via C ABI bindings with comprehensive benchmarks.

  1. Worked example

    Step-by-step trace of SplitMix64 generator advances, Box-Muller normal deviates, and terminal payoff discounting.

  2. Completion problem

    Complete polar coordinate normal transformation and unbiased sample variance calculation in an executable pricer.

  3. Independent project

    Develop the native C++20 Monte Carlo pricer, expose it through C ABI bindings to Python, and pass the 50-seed autograder suite. Project specification.

  4. Stretch

    Extend the pricer with C++20 concept-constrained payoff functors and evaluate Struct-of-Arrays SIMD vectorization.
