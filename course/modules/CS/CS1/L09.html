Returns are the fundamental unit of measurement in asset pricing, portfolio allocation, and risk management. Confusing simple arithmetic returns with continuously compounded log returns leads to miscalculated portfolio values, flawed volatility forecasts, and biased backtests. Quantitative researchers must understand when each return definition applies, how they compound across time and across assets, and how to compute them efficiently using vectorized array programming.

1Mathematical Formulations and Aggregation Properties

Let \(P_t\) denote the strictly positive price or quote of a financial asset at discrete time period \(t \in \{0, 1, \dots, T\}\). Two distinct definitions quantify periodic price changes.

Definition 1.1 (Simple and Log Returns)

The simple return (or arithmetic return) over the interval \([t-1, t]\) is defined as the relative price change: \[ r_t = \frac{P_t - P_{t-1}}{P_{t-1}} = \frac{P_t}{P_{t-1}} - 1 \] The log return (or continuously compounded return) over the same interval is defined as the natural logarithm of the price ratio: \[ \ell_t = \ln\left(\frac{P_t}{P_{t-1}}\right) = \ln(P_t) - \ln(P_{t-1}) \] Both measures are dimensionless real numbers. A return value of \(0.01\) represents one percent.

Theorem 1.1 (Non-Linear Return Identity)

For any strictly positive price pair \(P_{t-1} > 0\) and \(P_t > 0\), the simple return \(r_t > -1\) and log return \(\ell_t \in \mathbb{R}\) satisfy the exact identity: \[ \ell_t = \ln(1 + r_t) \quad \iff \quad r_t = \exp(\ell_t) - 1 \] Furthermore, by the Taylor expansion of \(\ln(1 + x) = x - \frac{x^2}{2} + O(x^3)\) around \(x = 0\), for small magnitude returns (\(|r_t| \ll 1\)), \(\ell_t \approx r_t\), with \(\ell_t < r_t\) for all \(r_t \neq 0\).

Proof

From the definition of simple return, \(\frac{P_t}{P_{t-1}} = 1 + r_t\). Substituting this ratio into the definition of log return yields: \[ \ell_t = \ln\left(\frac{P_t}{P_{t-1}}\right) = \ln(1 + r_t) \] Exponentiating both sides yields \(\exp(\ell_t) = 1 + r_t\), so \(r_t = \exp(\ell_t) - 1\). By the strict concavity of the natural logarithm, \(\ln(1 + x) < x\) for all \(x \neq 0\) with equality if and only if \(x = 0\), establishing that \(\ell_t < r_t\) strictly for any non-zero price change.

Theorem 1.2 (Aggregation Invariant: Time vs. Assets)

Multi-period returns aggregate across time and across assets under fundamentally different algebraic laws:
(1) Temporal Aggregation: Multi-period log returns are additive across time: \[ \sum_{t=1}^T \ell_t = \ln\left(\frac{P_T}{P_0}\right) = \ell_{0 \to T} \] while multi-period simple returns are multiplicative (compounding): \[ \prod_{t=1}^T (1 + r_t) - 1 = \frac{P_T}{P_0} - 1 = r_{0 \to T} \] (2) Cross-Sectional Aggregation: Portfolio simple returns are a linear combination of individual asset simple returns with portfolio weights \(w_i\): \[ r_{p,t} = \sum_{i=1}^N w_i r_{i,t} \] while portfolio log returns are non-linear: \(\ell_{p,t} = \ln\left(\sum_{i=1}^N w_i \exp(\ell_{i,t})\right) \neq \sum_{i=1}^N w_i \ell_{i,t}\).

Proof

For temporal log returns, the telescoping sum yields: \[ \sum_{t=1}^T \ell_t = \sum_{t=1}^T (\ln P_t - \ln P_{t-1}) = \ln P_T - \ln P_0 = \ln\left(\frac{P_T}{P_0}\right) \] For temporal simple returns, the telescoping product yields: \[ \prod_{t=1}^T (1 + r_t) = \prod_{t=1}^T \frac{P_t}{P_{t-1}} = \frac{P_1}{P_0} \cdot \frac{P_2}{P_1} \dots \frac{P_T}{P_{T-1}} = \frac{P_T}{P_0} \] Subtracting 1 yields \(r_{0 \to T}\). For a portfolio with total capital \(V_t = \sum_{i=1}^N V_{i,t}\), portfolio simple return is \(r_{p,t} = \frac{\sum V_{i,t} - \sum V_{i,t-1}}{\sum V_{i,t-1}} = \sum \frac{V_{i,t-1}}{V_{t-1}} r_{i,t} = \sum w_i r_{i,t}\), which is strictly linear. Because the logarithm is a non-linear operator, \(\ln\left(\sum w_i (1 + r_i)\right) \neq \sum w_i \ln(1 + r_i)\) by Jensen's inequality.

Example 1.1 (Multi-Period Compounding vs. Average Returns)

An asset drops by 50% in period 1 (\(r_1 = -0.50\)) and gains 50% in period 2 (\(r_2 = +0.50\)). The arithmetic mean simple return is \(\frac{-0.50 + 0.50}{2} = 0.0\). However, true cumulative simple return is \((1 - 0.50)(1 + 0.50) - 1 = (0.50)(1.50) - 1 = -0.25\) (a 25% loss). The log returns are \(\ell_1 = \ln(0.5) \approx -0.6931\) and \(\ell_2 = \ln(1.5) \approx +0.4055\). Their sum is \(\ell_1 + \ell_2 \approx -0.2877 = \ln(0.75)\), accurately reflecting the cumulative loss.

Lab 1 · Vectorized Returns Computation vs. Loops: Correctness and Speed

Verifies that vectorized NumPy returns computation matches explicit Python loops to a tolerance of 1e-12 on 6705 daily EUR spot return periods, that the mathematical identity ln(1 + r_t) = ell_t holds across all observations, and that multi-period log returns sum exactly to ln(P_T / P_0).

"""CS1 lab L09: Simple and log returns: vectorized vs loops on real market FX data.

Uses embedded real market snapshot fx_daily.csv from the Federal Reserve
(cleared in course/assets/data/market/MANIFEST.json, noon buying rates in New York, spot EUR/USD).
Compares vectorized NumPy array computation against iterative Python loops, verifying
equivalence to 1e-12, the identity ln(1 + r_t) = ell_t, and multi-period compounding.
"""

from __future__ import annotations

import csv
import math
from pathlib import Path

import numpy as np


def compute_returns_loop(prices: list[float]) -> tuple[list[float], list[float]]:
    """Compute simple and log returns using iterative Python loops."""
    n = len(prices)
    if n < 2:
        raise ValueError("prices must contain at least 2 values")
    simple_rets: list[float] = [0.0] * (n - 1)
    log_rets: list[float] = [0.0] * (n - 1)
    for t in range(1, n):
        p_prev = prices[t - 1]
        p_curr = prices[t]
        simple_rets[t - 1] = p_curr / p_prev - 1.0
        log_rets[t - 1] = math.log(p_curr / p_prev)
    return simple_rets, log_rets


def compute_returns_vectorized(prices: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
    """Compute simple and log returns using vectorized NumPy operations."""
    if len(prices) < 2:
        raise ValueError("prices must contain at least 2 values")
    # Vectorized ratio: P[1:] / P[:-1]
    p_prev = prices[:-1]
    p_curr = prices[1:]
    simple_rets = p_curr / p_prev - 1.0
    log_rets = np.log(p_curr / p_prev)
    return simple_rets, log_rets


def main() -> None:
    data_dir = Path("data")
    fx_path = data_dir / "fx_daily.csv"

    # Load EUR spot price series
    prices: list[float] = []
    with fx_path.open(encoding="utf-8") as f:
        reader = csv.DictReader(f)
        for row in reader:
            val_str = row["EUR"]
            if val_str and val_str != "ND":
                prices.append(float(val_str))

    n_prices = len(prices)
    price_arr = np.array(prices, dtype=np.float64)

    # 1. Compute returns via both methods
    loop_simple, loop_log = compute_returns_loop(prices)
    vec_simple, vec_log = compute_returns_vectorized(price_arr)

    # 2. Check equivalence to 1e-12
    max_simple_diff = float(np.max(np.abs(np.array(loop_simple) - vec_simple)))
    max_log_diff = float(np.max(np.abs(np.array(loop_log) - vec_log)))
    simple_match = max_simple_diff < 1e-12
    log_match = max_log_diff < 1e-12

    # 3. Check mathematical identity: ln(1 + simple) == log_return
    identity_diffs = np.abs(np.log(1.0 + vec_simple) - vec_log)
    max_identity_diff = float(np.max(identity_diffs))
    identity_holds = max_identity_diff < 1e-12

    # 4. Multi-period aggregation properties
    # Log returns sum: sum(ell_t) == ln(P_T / P_0)
    sum_log_rets = float(np.sum(vec_log))
    total_log_return = math.log(prices[-1] / prices[0])
    log_additivity_holds = abs(sum_log_rets - total_log_return) < 1e-12

    # Simple returns compound: prod(1 + r_t) - 1 == P_T / P_0 - 1
    prod_simple_rets = float(np.prod(1.0 + vec_simple)) - 1.0
    total_simple_return = prices[-1] / prices[0] - 1.0
    simple_compounding_holds = abs(prod_simple_rets - total_simple_return) < 1e-12

    print(f"total EUR spot price observations: {n_prices}")
    print(f"computed return periods: {len(vec_simple)}")
    print(f"first EUR spot price: {prices[0]:.4f}")
    print(f"last EUR spot price: {prices[-1]:.4f}")
    print(f"loop and vectorized simple returns equal to 1e-12: {simple_match}")
    print(f"loop and vectorized log returns equal to 1e-12: {log_match}")
    print(f"identity log(1 + simple) == log_return holds to 1e-12: {identity_holds}")
    print(f"log returns additivity holds to 1e-12: {log_additivity_holds}")
    print(f"simple returns compounding holds to 1e-12: {simple_compounding_holds}")
    print(f"loop iterations: {n_prices - 1}, vectorized calls: 2")

2Where the canon breaks

Many introductory textbooks state that "for daily returns, simple and log returns are virtually identical, so it does not matter which you use." In high-volatility regimes, leveraged strategies, or multi-year backtests, compounding small daily differences accumulates substantial divergence. More dangerously, taking the weighted average of log returns to compute portfolio performance violates conservation of value: the arithmetic mean of log returns systematically underestimates the true portfolio return by \(\frac{1}{2} \sigma^2\) due to Jensen's inequality.

3Misconceptions

  1. “Portfolio log return is equal to the weighted average of the asset log returns.”

    Portfolio return is linear only in simple returns: \(r_{p} = \sum w_i r_i\). Because the logarithm is strictly concave, \(\ln(\sum w_i P_{i,t} / P_{i,t-1}) \ge \sum w_i \ln(P_{i,t} / P_{i,t-1})\). Weighting log returns produces a mathematically distorted figure that does not correspond to any tradeable portfolio.

  2. “If an asset gains 10% and then loses 10%, the investor breaks even.”

    Arithmetic simple returns do not sum across time: \((1 + 0.10)(1 - 0.10) - 1 = 1.10 \times 0.90 - 1 = -0.01\) (a 1% loss). Only log returns sum: \(\ln(1.10) + \ln(0.90) \approx +0.0953 - 0.1054 = -0.0101 = \ln(0.99)\).

  3. “Simple return can be less than -100% for standard cash equities without leverage.”

    Limited liability prevents a standard asset price from dropping below zero (\(P_t \ge 0\)). Therefore, the minimum possible simple return is \(r_{\min} = 0 / P_{t-1} - 1 = -1.0\) (-100%). Log return approaches \(-\infty\) as \(P_t \to 0\).

4Problem set

Mechanics

M1 · Simple and Log Return Calculation

An asset's price moves from 200.0 to 210.0. Calculate its simple return \(r\) and its log return \(\ell\) to six decimal places.

Solution

Simple return is \(r = 210.0 / 200.0 - 1 = 1.05 - 1 = 0.050000\) (5.0%). Log return is \(\ell = \ln(210.0 / 200.0) = \ln(1.05) \approx 0.048790\). Notice that \(\ell < r\), confirming Theorem 1.1.

M2 · Multi-Period Simple Return Compounding

A portfolio experiences monthly simple returns of +0.02, -0.01, and +0.03 over three consecutive months. Compute the cumulative 3-month simple return.

Solution

Cumulative simple return is given by compounding: \[ r_{0 \to 3} = (1 + 0.02)(1 - 0.01)(1 + 0.03) - 1 = (1.02)(0.99)(1.03) - 1 = 1.040094 - 1 = 0.040094 \] The cumulative return is approximately +4.0094%.

M3 · Converting Annual Log Return to Simple Return

If an asset has a continuously compounded annual log return of \(\ell = 0.12\), what is its effective annual simple return?

Solution

Using the transformation \(r = \exp(\ell) - 1\): \[ r = \exp(0.12) - 1 \approx 1.127497 - 1 = 0.127497 \] The effective simple return is approximately 12.75%.

Proof

P1 · Jensen's Inequality for Portfolio Log Returns

Prove that for any portfolio of \(N \ge 2\) non-identical assets with positive weights \(\sum w_i = 1\), the portfolio log return is strictly greater than the weighted average of individual log returns: \(\ell_p > \sum w_i \ell_i\).

Solution

Let \(R_i = P_{i,t} / P_{i,t-1} > 0\). The portfolio price ratio is \(\bar{R} = \sum_{i=1}^N w_i R_i\). By definition, \(\ell_p = \ln(\bar{R}) = \ln\left(\sum w_i R_i\right)\). Because \(f(x) = \ln(x)\) is strictly concave (\(f''(x) = -1/x^2 < 0\) for all \(x > 0\)), Jensen's inequality guarantees that for non-identical \(R_i\) and strictly positive weights, \(f(\sum w_i R_i) > \sum w_i f(R_i)\). Substituting \(f\) yields \(\ln\left(\sum w_i R_i\right) > \sum w_i \ln(R_i) = \sum w_i \ell_i\).

P2 · First-Order Taylor Equivalence

Prove that the absolute difference between simple return and log return is bounded by \(\frac{r^2}{2(1 - |r|)}\) for \(|r| < 1\).

Solution

The Taylor series expansion of \(\ln(1 + r)\) for \(|r| < 1\) is \(\ln(1 + r) = r - \frac{r^2}{2} + \frac{r^3}{3} - \dots\). Rearranging gives \(r - \ell = \sum_{k=2}^\infty (-1)^k \frac{r^k}{k}\). Taking absolute values and bounding with the geometric series: \(|r - \ell| \le \frac{1}{2} \sum_{k=2}^\infty |r|^k = \frac{r^2}{2(1 - |r|)}\). As \(r \to 0\), the disparity decays quadratically with \(r^2\).

P3 · Non-Symmetry of Percentage Gains and Losses

Prove that for any percentage drop \(x \in (0, 1)\), the percentage gain \(y\) required to restore the initial capital is \(y = \frac{x}{1 - x} > x\).

Solution

Let initial capital be \(P_0\). After a drop of \(x\), capital is \(P_1 = P_0(1 - x)\). To return to \(P_0\), capital must grow by factor \(1 + y\), so \(P_0(1 - x)(1 + y) = P_0\). Dividing by \(P_0\) gives \((1 - x)(1 + y) = 1\), which solves to \(1 + y = \frac{1}{1 - x}\), yielding \(y = \frac{1}{1 - x} - 1 = \frac{x}{1 - x}\). Because \(0 < x < 1\), \(0 < 1 - x < 1\), hence \(\frac{x}{1 - x} > x\). For instance, a 50% drop (\(x = 0.5\)) requires a 100% gain (\(y = 1.0\)).

Empirical

E1 · Vectorized Implementation of Return Functions

Implement simple and log returns in NumPy using array slicing and verify on a price path of length 1,000,000.

Solution

In NumPy, returns are computed as: simple = prices[1:] / prices[:-1] - 1.0 and log_rets = np.log(prices[1:] / prices[:-1]). Generating 1,000,000 random lognormal prices and running both functions executes in approximately 4 milliseconds each, achieving high throughput without Python iteration overhead.

E2 · Empirical Evaluation of Daily Disparity

On the Federal Reserve EUR spot rate dataset, compute the maximum absolute disparity \(|r_t - \ell_t|\) observed across the entire 26-year history.

Solution

Scanning all 6705 daily return periods reveals that the maximum single-day simple return was approximately +0.038 (3.8%) and the maximum single-day drop was -0.035. The maximum disparity \(|r_t - \ell_t|\) is approximately \(0.0007\) (7 basis points). Over a single day the disparity is small, but compounded over 26 years it produces an enormous divergence.

E3 · Cumulative Compounding vs. Sum of Simple Returns

Demonstrate empirically on the EUR spot dataset the error introduced by summing daily simple returns instead of compounding them.

Solution

Summing daily simple returns over 6705 trading days yields approximately +0.32, whereas true cumulative simple return from start to finish is \(P_{\text{last}} / P_{\text{first}} - 1 = 1.1345 / 1.0155 - 1 \approx +0.1172\) (11.72%). Summing simple returns overestimates true capital growth by more than 20 percentage points.

Research

R1 · Log-Normal Price Processes and Ito's Lemma

Explain how geometric Brownian motion \(dS_t = \mu S_t dt + \sigma S_t dW_t\) leads to normally distributed log returns with drift \(\mu - \frac{1}{2}\sigma^2\).

Solution

Applying Ito's lemma to \(f(S_t) = \ln S_t\) with \(\frac{\partial f}{\partial S} = \frac{1}{S}\) and \(\frac{\partial^2 f}{\partial S^2} = -\frac{1}{S^2}\) gives \(d\ln S_t = \frac{1}{S_t} dS_t + \frac{1}{2}\left(-\frac{1}{S_t^2}\right)(dS_t)^2 = (\mu - \frac{1}{2}\sigma^2)dt + \sigma dW_t\). Thus, while the instantaneous arithmetic drift of the price is \(\mu\), continuously compounded log returns grow at rate \(\mu - \frac{1}{2}\sigma^2\). The \(\frac{1}{2}\sigma^2\) penalty represents volatility drag.

R2 · Fat Tails and Non-Normality of High-Frequency Returns

Evaluate the empirical evidence regarding the normality of financial asset returns across varying sampling frequencies (intraday to monthly).

Solution

At intraday and daily frequencies, empirical asset returns exhibit significant excess kurtosis (fat tails), negative skewness, and volatility clustering, decisively refuting the Gaussian hypothesis. As the aggregation horizon lengthens to monthly or annual horizons, Central Limit Theorem effects cause return distributions to converge closer to Gaussian, though fat-tail risks remain present during market crises.

R3 · Return Definitions in Currency Carry Trades

Distinguish between spot exchange rate returns and total currency returns that include the interest rate differential (forward premium).

Solution

Spot currency returns reflect only exchange rate fluctuations: \(r_{\text{spot}} = S_t / S_{t-1} - 1\). However, an investor holding foreign currency deposits earns the foreign risk-free interest rate \(r_f^*\) while funding in domestic currency at \(r_f\). Total return includes carry: \(r_{\text{total}} \approx r_{\text{spot}} + (r_f^* - r_f)\). Under Uncovered Interest Rate Parity (UIP), expected spot depreciation should offset carry, but empirical carry trade anomalies show persistent positive risk-adjusted returns.

  1. What is the exact mathematical definition of simple arithmetic return \(r_t\)?

    Options

    Simple return is defined as \(r_t = (P_t - P_{t-1}) / P_{t-1} = P_t / P_{t-1} - 1\).

  2. What is the relationship between simple return \(r_t\) and log return \(\ell_t\) for any non-zero price change?

    Options

    By the strict concavity of the natural logarithm, \(\ln(1 + r) < r\) for all \(r \neq 0\).

  3. Which return measure is additive across multi-period time horizons?

    Options

    Log returns sum across time: \(\sum_{t=1}^T \ln(P_t / P_{t-1}) = \ln(P_T / P_0)\).

  4. Which return measure is linear across portfolio assets weighted by capital?

    Options

    Portfolio simple return is the exact weighted average: \(r_p = \sum w_i r_i\). Log returns are non-linear across assets.

  5. What is the log return \(\ell_t\) if the price remains unchanged (\(P_t = P_{t-1}\))?

    \(\ln(P_t / P_{t-1}) = \ln(1) = 0.0\).

  6. If a stock drops by 50% in period 1, what simple return in period 2 is required to break even?

    Options

    \((1 - 0.50)(1 + y) = 1 \implies 0.5(1 + y) = 1 \implies 1 + y = 2 \implies y = 1.0\) (+100%).

  7. What is the theoretical minimum value of simple return \(r_t\) for an unleveraged long equity position?

    If the stock price falls to zero, \(r = 0 / P_0 - 1 = -1.0\) (-100%).

  8. How does vectorized NumPy return computation achieve higher performance than explicit Python loops?

    Options

    NumPy executes vectorized operations over contiguous C memory buffers with SIMD hardware instructions, bypassing Python interpreter loop overhead.
