Lab 1 · Worked Example: Return Calculations and Invariant Checks

Walks through the complete implementation of simple_return and log_return, verifying non-negative domain validation, length checks, and tolerance-bounded invariant equations. The prices are SIMULATED.

"""CS1 project lab 1: Worked example of Atlas A1 returns computation and invariant checks.

Demonstrates simple and log return calculation, input validation, and tolerance-checked invariants.
SIMULATED synthetic equity price trajectory.
"""

from __future__ import annotations

import math
from collections.abc import Sequence


def simple_return(prices: Sequence[float]) -> list[float]:
    """Compute simple returns: r_t = P_t / P_{t-1} - 1."""
    if len(prices) < 2:
        raise ValueError("At least 2 prices are required")
    out: list[float] = []
    p_prev = float(prices[0])
    if not math.isfinite(p_prev) or p_prev <= 0.0:
        raise ValueError(f"Price must be finite and positive, got {p_prev}")
    for p in prices[1:]:
        p_curr = float(p)
        if not math.isfinite(p_curr) or p_curr <= 0.0:
            raise ValueError(f"Price must be finite and positive, got {p_curr}")
        out.append(p_curr / p_prev - 1.0)
        p_prev = p_curr
    return out


def log_return(prices: Sequence[float]) -> list[float]:
    """Compute log returns: ell_t = ln(P_t / P_{t-1})."""
    if len(prices) < 2:
        raise ValueError("At least 2 prices are required")
    out: list[float] = []
    p_prev = float(prices[0])
    if not math.isfinite(p_prev) or p_prev <= 0.0:
        raise ValueError(f"Price must be finite and positive, got {p_prev}")
    for p in prices[1:]:
        p_curr = float(p)
        if not math.isfinite(p_curr) or p_curr <= 0.0:
            raise ValueError(f"Price must be finite and positive, got {p_curr}")
        out.append(math.log(p_curr / p_prev))
        p_prev = p_curr
    return out


def main() -> None:
    # SIMULATED prices for 5 trading days
    simulated_prices = [100.0, 102.5, 101.0, 104.0, 106.6]
    r = simple_return(simulated_prices)
    ell = log_return(simulated_prices)

    print(f"input price count: {len(simulated_prices)}")
    print(f"return count: {len(r)}")
    print(f"first simple return: {r[0]:.6f}")
    print(f"first log return: {ell[0]:.6f}")

    # Check invariant: ell[t] == ln(1 + r[t])
    invariant_diffs = [abs(ell[t] - math.log(1.0 + r[t])) for t in range(len(r))]
    max_diff = max(invariant_diffs)
    print(f"invariant holds within 1e-12: {max_diff < 1e-12}")

    # Check compounding
    cum_simple = 1.0
    for ret in r:
        cum_simple *= 1.0 + ret
    cum_simple -= 1.0
    expected_simple = simulated_prices[-1] / simulated_prices[0] - 1.0
    print(f"cumulative simple return matches price ratio: {abs(cum_simple - expected_simple) < 1e-12}")

    # Check log sum
    sum_log = sum(ell)
    expected_log = math.log(simulated_prices[-1] / simulated_prices[0])
    print(f"cumulative log return matches log price ratio: {abs(sum_log - expected_log) < 1e-12}")

Rung 3 · Specification

Context
Every quantitative research workflow starts with price level series and requires consistent, robust return calculations. In milestone A1 of the Atlas research platform, you will build the foundational repository skeleton, implementing the typed core returns module, an entry point CLI, strict static typing, and automated unit tests that all future milestones rely upon.
Inputs
Sequences of positive real price levels (\(P_t > 0\)) provided as Python sequences (lists, tuples, or NumPy arrays). During grading, deterministic price paths are generated from your unique workspace seed by grader/instance.py (all generated prices are SIMULATED).
Required outputs
A fully functional Python package adhering to atlas/A1.contract.md containing: src/atlas/__init__.py, src/atlas/returns.py exporting simple_return(prices: Sequence[float]) -> list[float] and log_return(prices: Sequence[float]) -> list[float], src/atlas/cli.py exporting main(argv: Sequence[str] | None = None) -> int, tests/test_returns.py with pytest tests, pyproject.toml with package metadata and strict mypy/ruff settings, .pre-commit-config.yaml, .github/workflows/ci.yml, and repository hygiene documentation (README.md, LICENSE, .gitignore).
Constraints
The core module must depend strictly on Python 3.14+ and the Python standard library (no third-party dependencies in production code). All prices must be finite real numbers greater than zero. Fewer than two prices, non-finite values (NaN, infinity), or non-positive prices must raise ValueError. Inputs must never be mutated in place. All functions must pass mypy --strict with zero warnings.
Grading mode
The curriculum grades this project by autograder. The reference solution is tested against 50 consecutive random seeds (0 through 49) checking numerical accuracy, invariant identities, and input validation.
