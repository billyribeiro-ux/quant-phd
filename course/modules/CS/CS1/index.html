Programming in Python from Zero

Quantitative finance requires software engineering: writing unambiguous, verified, typed, and vectorized code that executes numerical models without silent failure. CS1 builds complete programming proficiency from zero knowledge. It covers lexical scoping and closures, built-in containers (list, dict, set, tuple), object-oriented programming and structural protocols, modular packaging and exception propagation, static type annotations, pytest test harnesses, NumPy array vectorization, pandas index alignment on calendar mismatches, and the exact mathematical definitions of simple and log returns. The module culminates in Atlas Milestone A1: building the core returns calculation library with a command-line interface, strict static types, and continuous integration.

  • Prerequisites: P0.1 Foundations of Quantitative Research.
  • Project: Atlas A1: repository skeleton and typed returns module, graded by autograder
  • Data: Embedded Federal Reserve daily foreign exchange rates (fx_daily.csv) and constant-maturity Treasury yields (ust_daily.csv).

84 h lessons · 36 h project (30%)

Objectives

By the end of CS1 you can:

  1. Trace variable resolution through the LEGB (Local, Enclosing, Global, Built-in) scope hierarchy and construct state-preserving closures without global variables (Lesson 1).
  2. Select appropriate built-in data structures (list, tuple, dict, set) based on mutability constraints, key hashability requirements, and containment search complexity (Lesson 2).
  3. Define classes with encapsulated state and implement runtime-checkable structural protocols using duck typing without nominal subclassing (Lesson 3).
  4. Organize code into importable packages and handle operational failures using structured exception hierarchies with clean resource finalization (Lesson 4).
  5. Annotate Python functions with strict static type hints and verify type correctness using static analysis tools ahead of execution (Lesson 5).
  6. Construct automated unit test suites using pytest that assert mathematical invariants and catch expected runtime exceptions (Lesson 6).
  7. Vectorize array computations in NumPy using broadcasting and multidimensional reductions to eliminate Python-level interpretation overhead (Lesson 7).
  8. Align asynchronous market time series by calendar date keys to prevent lookahead and holiday misalignment bugs (Lesson 8).

Placement diagnostic

Ten questions: eight on P0.1 foundational prerequisites and mathematical literacy, and two skill checks on what rungs 1 and 2 of the project teach. The mastery threshold is 80 percent (at least eight of ten correct). To place out of rungs 1 and 2, you must achieve the mastery threshold and answer both skill checks correctly.

  1. Given consecutive asset prices \(P_{t-1} = 100.0\) and \(P_t = 105.0\), what is the simple arithmetic return \(r_t\)?

    Options

    Simple return is defined as \(r_t = P_t / P_{t-1} - 1 = 105.0 / 100.0 - 1 = 0.05\). Rung 1 worked example skill check.

  2. If a returns calculation function receives a price sequence of length 1, which exception must it raise under the Atlas A1 contract?

    Options

    The Atlas A1 contract specifies that a price sequence with fewer than two observations must raise ValueError. Rung 2 completion skill check.

  3. Which evidence grade designates a mathematical theorem whose proof holds unconditionally under its stated hypotheses?

    Options

    Grade T denotes pure mathematical or deductive truth (P0.1, evidence grades).

  4. What is \(\log_2(1024)\)?

    \(2^{10} = 1024\), so the base-2 logarithm is 10.

  5. What is the purpose of the Atlas research platform throughout this doctoral program?

    Options

    Atlas is the program-long software repository where each milestone delivers typed libraries consumed by subsequent modules (P0.1).

  6. What is \(\ln(1.0)\)?

    The natural logarithm of 1 is exactly 0.

  7. In a directed acyclic graph (DAG) curriculum, what restriction applies to concept usage?

    Options

    DAG integrity requires that every concept is introduced before consumption, preventing circular dependencies (P0.1).

  8. Which evidence grade represents published empirical findings that remain debated or contested across multiple studies?

    Options

    Grade B represents published results subject to active debate or unresolved methodological division (P0.1).

  9. If an initial investment of 100 dollars grows by simple return \(r_1 = 0.10\) in period 1 and \(r_2 = -0.10\) in period 2, what is the dollar loss from the initial 100 dollars?

    \(100 \times (1 + 0.10) \times (1 - 0.10) = 100 \times 1.10 \times 0.90 = 99.0\). The dollar loss is \(100 - 99 = 1.0\).

  10. What does the project ladder require for Rung 3?

    Options

    Rung 3 is the mandatory independent project deliverable (P0.1, project ladder).

Lessons

L01 · 10 h Functions, Control Flow, and Scope The LEGB scope lookup order, function calls, local namespace creation, shadowing, and state-preserving closures. L02 · 10 h Built-In Data Structures Lists, tuples, dictionaries, and sets: mutability vs. immutability, key hashability requirements, and containment search complexity. L03 · 10 h Classes and Structural Protocols Object encapsulation, instance methods, dunder methods, and structural typing using typing.Protocol without nominal inheritance. L04 · 9 h Modules, Packages, and Exceptions Hierarchical package architecture, module namespace boundaries, exception propagation hierarchies, and try-except-else-finally control flow. L05 · 9 h Type Hints and Static Checking Function and variable annotations, typing primitives, runtime non-enforcement semantics, and ahead-of-time static analysis with mypy. L06 · 9 h Unit Testing with pytest Automated test discovery, pure assertions, parameterized testing, invariant checking, and testing expected exceptions with pytest.raises. L07 · 9 h NumPy Arrays and Vectorization Contiguous memory buffers, ndarray data types, broadcasting rules across dimensions, and vectorized operations versus iterative Python loops. L08 · 9 h pandas DataFrames and Index Alignment Tabular data structures, Series and DataFrame labels, and the critical mechanics of index alignment on mismatched calendar dates. L09 · 9 h Simple and Log Returns Exact mathematical definitions of arithmetic and log returns, multi-period compounding properties, and performance benchmarking on real market FX data.
