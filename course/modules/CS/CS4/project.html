Reproducibility Audit

Take a deliberately broken quantitative research repository (unpinned dependencies, missing cryptographic hashes, non-deterministic wall-clock timestamps, order-dependent statistics, missing build configuration, missing tests, and absent continuous integration) and remediate it to achieve bit-for-bit reproducibility across 50 seeds, documenting every fix in an audit log.

  • Deliverable: Remediated repository plus an audit log (AUDIT.md), evaluated via repro_audit.py.
  • Grading: Autograder (verified by pytest suite across 50 seeds).
  • Hours: 16 study hours.
  • Prerequisites: Git branching workflow, regression test, property-based testing, Python packaging, dependency pinning, deterministic computation, bit-for-bit reproducibility, continuous integration.

The four-rung project ladder

  1. 1 · Worked example Walk through the triage and remediation of non-deterministic wall-clock metadata (Defect D3), annotated step-by-step.
  2. 2 · Completion Complete the missing linear congruential generator formula and exact rational sample variance calculation with instant feedback.
  3. 3 · Independent Execute the complete reproducibility audit: fix all eight defects, establish pyproject.toml and requirements.lock, write the test suite, create the CI workflow, and verify bit-for-bit reproducibility.
  4. 4 · Stretch Validate containerized bit-for-bit execution across distinct Python interpreter minor versions or host operating system kernels.

Lab 1 · Worked Example: Remediation of Defect D3

Compares consecutive executions of the broken engine against the repaired deterministic engine on SIMULATED seed 42. Demonstrates that broken runs diverge while repaired runs produce bit-for-bit identical JSON text.

"""CS4 Capstone Project Lab 1: Rung 1 worked example - Repairing wall-clock time leak.

Demonstrates the triage and repair of Defect D3 (wall-clock timestamp injected into output).
Shows that broken execution produces divergent outputs between consecutive runs with the same seed.
Shows that the repaired deterministic engine produces bit-for-bit identical outputs.

Data: SIMULATED study execution on fixed seed 42.
"""

from __future__ import annotations

import json
from collections.abc import Sequence
from fractions import Fraction


def generate_sequence(seed: int, n: int = 200) -> list[int]:
    """Generate deterministic sequence using the exact LCG formula from spec."""
    if seed < 0:
        raise ValueError("seed must be non-negative")
    seq: list[int] = []
    for i in range(1, n + 1):
        val = (1103515245 * seed + 12345 * i * i + 7 * i) % 1000003
        seq.append(val)
    return seq


def summarize(values: Sequence[int]) -> dict[str, object]:
    """Compute exact summary statistics using Fraction."""
    n = len(values)
    if n < 2:
        raise ValueError("len(values) must be at least 2")
    s = sum(values)
    s2 = sum(v * v for v in values)
    mean_frac = Fraction(s, n)
    var_frac = Fraction(n * s2 - s * s, n * (n - 1))
    return {
        "count": n,
        "max": max(values),
        "mean": str(mean_frac),
        "min": min(values),
        "variance": str(var_frac),
    }


def run_broken_with_timestamp(seed: int, fake_time: str) -> str:
    """Broken implementation injecting variable timestamp."""
    seq = generate_sequence(seed)
    stats = summarize(seq)
    payload = dict(stats)
    payload["timestamp"] = fake_time
    return json.dumps(payload, sort_keys=True, indent=2) + "\n"


def run_repaired(seed: int) -> str:
    """Repaired implementation without timestamp."""
    seq = generate_sequence(seed)
    stats = summarize(seq)
    return json.dumps(stats, sort_keys=True, indent=2) + "\n"


def main() -> None:
    print("SIMULATED reproducibility audit - Defect D3 repair (worked example):")
    seed = 42

    # Broken engine with timestamp
    broken_run1 = run_broken_with_timestamp(seed, "2026-11-10T09:00:00.123456Z")
    broken_run2 = run_broken_with_timestamp(seed, "2026-11-10T09:00:00.654321Z")

    print("Broken engine (with timestamp) comparison:")
    print(f"Run 1 matches Run 2: {broken_run1 == broken_run2}")

    # Repaired engine without timestamp
    repaired_run1 = run_repaired(seed)
    repaired_run2 = run_repaired(seed)

    print("\nRepaired engine (deterministic) comparison:")
    print(f"Run 1 matches Run 2: {repaired_run1 == repaired_run2}")
    print("\nRepaired output preview (seed 42):")
    for line in repaired_run1.splitlines()[:7]:
        print(f"  {line}")


main()

Specification

Context
A quantitative research team has inherited a flawed study repository (starter.py) whose simulation results fail to replicate across machines: dependencies are unpinned, lockfiles lack cryptographic hashes, execution outputs vary between runs due to wall-clock timestamps, summary statistics depend on input ordering, packaging metadata lacks build backends, automated tests are absent, and no continuous integration workflow exists. As quantitative research lead, you must perform a comprehensive reproducibility audit, fix every defect, and produce an auditable, bit-for-bit reproducible repository.
Inputs
The broken repository starter (grader/starter.py). No external network data feeds are permitted. Simulation inputs are generated deterministically from seed \(s\) using the exact linear congruential recurrence: \[ x_i = (1103515245 \cdot s + 12345 \cdot i^2 + 7 \cdot i) \pmod{1000003} \quad \text{for } i = 1, \dots, 200 \] All generated values carry the label SIMULATED.
Required outputs
Your solution module (repro_audit.py) must implement and export:
  • generate_sequence(seed: int, n: int = 200) -> list[int]: Generates the deterministic sequence; raises ValueError if seed < 0.
  • summarize(values: Sequence[int]) -> dict[str, object]: Computes exact summary statistics (count, min, max, mean, variance); raises ValueError if len(values) < 2. Mean and variance must be exact irreducible fraction strings (or integers) computed via fractions.Fraction with sample divisor \(n - 1\).
  • run(seed: int) -> str: Generates the sequence for seed, summarizes metrics, and returns canonical JSON formatted as: json.dumps(stats, sort_keys=True, indent=2) + "\n".
  • materialize_repo(target_dir: Path | str) -> Path: Writes the complete remediated repository files into target_dir, containing:
    • requirements.lock: Pinned dependencies matching name==version --hash=sha256:<64 hex>.
    • pyproject.toml: Standard packaging configuration with valid [build-system] and [project] tables.
    • study/core.py: Clean implementation exporting generate_sequence, summarize, and run.
    • tests/test_study.py: Automated pytest suite with at least 3 test functions (test_*).
    • .github/workflows/ci.yml: Automated CI workflow containing a run: step executing pytest.
    • AUDIT.md: Markdown audit log documenting all eight defects (D1 through D8) and referencing valid repository paths.
Constraints
  • Runtime: Python 3.14 standard library and vendored pytest only. No external packages, no hypothesis library, no network calls.
  • Determinism: Bit-for-bit identical string outputs across all runs under identical seeds.
  • Validation: Explicit ValueError on negative seeds or fewer than two return observations.
  • Repository integrity: All defect rows in AUDIT.md must reference actual files created under target_dir.
Grading
Autograder: Evaluated by the automated pytest suite in grader/test_project.py across 50 seeds (seeds 0 through 49). All tests must pass with zero failures.
