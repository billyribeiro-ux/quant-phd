Welford's Online Mean and Variance

  • Uses: proof by induction (M1), big-O complexity (Lesson 1)
  • Introduces: Welford's online mean and variance
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study
  • Dlore
  • Xrefuted

A monitoring system sees returns one at a time and cannot keep every past value. It still needs the mean and the variance of the stream so far, updated in constant work for each new value. Definition 1.1 needs the mean before the squared deviations, so computing it from the definition takes two passes over the data. The one-pass version that sums squares loses digits when the values share a large offset. This lesson states the one-pass update, proves it correct by induction on the number of values, and tests it on a stream where the naive formula fails.

1The mean, the sum of squared deviations and the update

A stream is a sequence of real numbers \(x_1, x_2, \ldots\) that arrives one value at a time. A statistic is online when each new value is absorbed into a fixed, small state (a count, a mean, a sum) and the earlier values are not read again. The two-pass method, by contrast, reads all the values to compute the mean, then reads them again for the squared deviations, so it needs every value to be stored.

Definition 1.1 (mean, sum of squared deviations, sample variance)

For an integer \(n \ge 1\) and real numbers \(x_1, \ldots, x_n\), the mean is \(\bar x_n = \frac{1}{n}\sum_{i=1}^{n} x_i\), and the sum of squared deviations is \(S_n = \sum_{i=1}^{n} (x_i - \bar x_n)^2\). For \(n \ge 2\), the sample variance is \(s_n^2 = S_n/(n-1)\), and the population variance is \(\sigma_n^2 = S_n/n\). The population form divides by the number of values; the sample form divides by one fewer, which is the correction for estimating the mean from the same values.

Definition 1.2 (Welford's update)

The Welford's online mean and variance is the recursion \[ M_1 = x_1, \qquad S_1 = 0, \] and, for \(n \ge 2\), \[ M_n = M_{n-1} + \frac{x_n - M_{n-1}}{n}, \qquad S_n = S_{n-1} + (x_n - M_{n-1})(x_n - M_n). \] The state after \(n\) values is the triple \((n, M_n, S_n)\). The sample variance is read off as \(S_n/(n-1)\) and the population variance as \(S_n/n\).

Lemma 1.3 (sum of squares identity)

Hypotheses. (1) \(n \ge 1\) is an integer. (2) \(x_1, \ldots, x_n\) are real numbers. (3) Arithmetic is exact, as in the real numbers. The lemma: \(\sum_{i=1}^{n}(x_i - \bar x_n)^2 = \sum_{i=1}^{n} x_i^2 - n\,\bar x_n^2\).

Proof

For any real \(m\), expanding the square gives \(\sum_i (x_i - m)^2 = \sum_i x_i^2 - 2m\sum_i x_i + n m^2\). By definition \(\sum_i x_i = n\bar x_n\). Put \(m = \bar x_n\): the middle term is \(-2\bar x_n \cdot n\bar x_n\) and the last is \(n\bar x_n^2\), so their sum is \(-n\bar x_n^2\). This gives the identity.

2Proof that the update is correct

Theorem 2.1 (one step of the update)

Hypotheses. (1) \(n \ge 2\) is an integer. (2) \(x_1, \ldots, x_n\) are real numbers. (3) Arithmetic is exact. (4) \(M_{n-1} = \bar x_{n-1}\) and \(S_{n-1} = \sum_{i=1}^{n-1}(x_i - \bar x_{n-1})^2\), which is the claim for \(n-1\) values. Under (1) to (4), the recursion of Definition 1.2 gives \(M_n = \bar x_n\) and \(S_n = \sum_{i=1}^{n}(x_i - \bar x_n)^2\).

Proof

The mean. Multiplying the update of \(M\) by \(n\) gives \(nM_n = nM_{n-1} + x_n - M_{n-1} = (n-1)M_{n-1} + x_n\). By hypothesis (4), \((n-1)M_{n-1} = \sum_{i=1}^{n-1} x_i\), so \(nM_n = \sum_{i=1}^{n} x_i\) and \(M_n = \bar x_n\).

The sum of squares. Write \(d = x_n - M_{n-1}\). Then \(M_n = M_{n-1} + d/n\), so \(x_n - M_n = d - d/n = d(n-1)/n\). The update adds \(d(x_n - M_n) = d^2(n-1)/n\) to \(S_{n-1}\). It remains to show that the true sums of squares differ by this amount. Lemma 1.3 applies to the first \(n\) values and to the first \(n-1\) values (with mean \(M_{n-1}\), by hypothesis (4)), so \[ S_n^{\text{true}} - S_{n-1}^{\text{true}} = \Bigl(\sum_{i=1}^{n} x_i^2 - n\,M_n^2\Bigr) - \Bigl(\sum_{i=1}^{n-1} x_i^2 - (n-1)M_{n-1}^2\Bigr) = x_n^2 - nM_n^2 + (n-1)M_{n-1}^2. \] Expand \(nM_n^2 = n\bigl(M_{n-1} + d/n\bigr)^2 = nM_{n-1}^2 + 2dM_{n-1} + d^2/n\). The difference becomes \(x_n^2 - M_{n-1}^2 - 2dM_{n-1} - d^2/n\). Since \(x_n = M_{n-1} + d\), we have \(x_n^2 - M_{n-1}^2 - 2dM_{n-1} = (M_{n-1} + d)^2 - M_{n-1}^2 - 2dM_{n-1} = d^2\). So the difference is \(d^2 - d^2/n = d^2(n-1)/n\), which is the amount the update adds. Hypothesis (4) says \(S_{n-1}\) is the true value, so \(S_n\) from the recursion is the true \(\sum_{i=1}^{n}(x_i - \bar x_n)^2\).

Theorem 2.2 (Welford's update is correct)

Hypotheses. (1) \(n \ge 1\) is an integer. (2) \(x_1, x_2, \ldots\) are real numbers. (3) Arithmetic is exact. The lemma: for every \(n \ge 1\), the recursion of Definition 1.2 gives \(M_n = \bar x_n\) and \(S_n = \sum_{i=1}^{n}(x_i - \bar x_n)^2\).

Proof

Induction on \(n\), in the form of Theorem 1.2 of M1 Lesson 6 (proof by induction). Base case, \(n = 1\). \(M_1 = x_1 = \bar x_1\) by definition, and \(S_1 = 0 = (x_1 - x_1)^2 = \sum_{i=1}^{1}(x_i - \bar x_1)^2\). Inductive step. Let \(n \ge 2\) and assume the claim for \(n-1\). That is hypothesis (4) of Theorem 2.1, and Theorem 2.1 gives the claim for \(n\). By induction the claim holds for every \(n \ge 1\).

Corollary 2.3 (variance estimates and operation count)

Hypotheses. (1) The stream is as in Theorem 2.2. (2) Arithmetic is exact. Under these, for \(n \ge 2\) the sample variance is \(s_n^2 = S_n/(n-1)\) and the population variance is \(\sigma_n^2 = S_n/n\). Each update of the pair \((M, S)\) uses six arithmetic operations and does not depend on \(n\). The state is the three numbers \(n\), \(M_n\), \(S_n\), and no earlier value is kept.

Proof

The two variance formulas are Definition 1.1 with \(S_n\) from Theorem 2.2. For the count, one update computes \(d = x_n - M_{n-1}\) (one subtraction), \(d/n\) (one division), \(M_{n-1} + d/n\) (one addition), \(x_n - M_n\) (one subtraction), \(d \cdot (x_n - M_n)\) (one multiplication) and \(S_{n-1} + \cdot\) (one addition). That is six operations, with no loop over earlier values. The constant \(c = 6\) satisfies the bound \(\text{operations} \le c\) for every \(n\), so the update is \(O(1)\) in \(n\) in the sense of Lesson 1. The count is a count of operations, not a measure of time. The space is the three stored numbers, and the update reads only \(x_n\) and that state.

Theorem 2.2 is an identity between real numbers. The proof uses only the algebra above, and the six-operation count is what makes the update constant in \(n\). Neither result says how close a floating-point computation stays to the real value, which is the subject of Section 3 and of Lab 1.

Lab 1 · Welford against the two-pass and naive variance, at three offsets

Stated before running: the three methods agree closely at offset 0, and the two-pass formula is the most accurate at every offset. As the offset grows, the naive formula's relative error rises from about \(7 \times 10^{-15}\) to \(1\), and the naive estimate is exactly zero at offset \(10^9\). Welford's relative error also rises with the offset, but stays far below the naive error. The reference is an exact \(\texttt{Fraction}\) variance of the same float values, and each relative error is printed to 3 significant digits.

"""CS2 L09 lab 1: Welford's one-pass update against two-pass and naive variance, on streams with a large offset.

Claim checked: for the same stream of n = 2000 values, the sample variance from Welford's update, from the
two-pass formula and from the naive sum-of-squares formula is compared with an exact Fraction reference.
The stream is offset + u, where u is uniform on [0, 1) from random.Random(SEED). The offset is the
variable under test: 0, 1e6 and 1e9. SIMULATED data, not market data.
Relative error is |estimate - exact| / exact, printed to 3 significant digits. Standard library only.
No randomness outside the seeded generator and no network access.
"""

from __future__ import annotations

import random
from fractions import Fraction

N = 2000
SEED = 90
OFFSETS = (0.0, 1e6, 1e9)


def stream(offset: float) -> list[float]:
    """Return N values offset + u, with u drawn uniformly from [0, 1) by a generator seeded with SEED."""
    rng = random.Random(SEED)
    return [offset + rng.random() for _ in range(N)]


def welford_variance(xs: list[float]) -> float:
    """One pass: keep the count, the running mean and the running sum of squared deviations."""
    count = 0
    mean = 0.0
    sum_sq_dev = 0.0
    for x in xs:
        count += 1
        delta = x - mean
        mean += delta / count
        sum_sq_dev += delta * (x - mean)
    return sum_sq_dev / (count - 1)


def two_pass_variance(xs: list[float]) -> float:
    """Two passes: the mean first, then the sum of squared deviations from that mean."""
    mean = sum(xs) / len(xs)
    return sum((x - mean) ** 2 for x in xs) / (len(xs) - 1)


def naive_variance(xs: list[float]) -> float:
    """One pass with running sums: (sum of x squared minus (sum of x)^2 / n) / (n - 1)."""
    total = 0.0
    total_sq = 0.0
    for x in xs:
        total += x
        total_sq += x * x
    n = len(xs)
    return (total_sq - total * total / n) / (n - 1)


def exact_variance(xs: list[float]) -> Fraction:
    """The sample variance of the float values in exact Fraction arithmetic (each float converts exactly)."""
    values = [Fraction(x) for x in xs]
    n = len(values)
    mean = sum(values, Fraction(0)) / n
    return sum(((x - mean) ** 2 for x in values), Fraction(0)) / (n - 1)


def relative_error(estimate: float, exact: Fraction) -> float:
    """Return |estimate - exact| / exact, computed in exact arithmetic and returned as a float."""
    return float(abs(Fraction(estimate) - exact) / exact)


def main() -> None:
    methods = (("Welford", welford_variance), ("two-pass", two_pass_variance), ("naive", naive_variance))
    for offset in OFFSETS:
        xs = stream(offset)
        exact = exact_variance(xs)
        print(f"offset {offset!r}: exact sample variance {float(exact):.6f}")
        for name, method in methods:
            print(f"  {name:<9} relative error {relative_error(method(xs), exact):.3e}")

Every line is one method at one offset on the same 2000 values, which are the offset plus a seeded uniform draw. SIMULATED data, not market data. The exact variance is 0.087281 to six digits at all three offsets, so the spread is the same and only the offset changes. The naive formula is correct in exact arithmetic (Lemma 1.3), and it fails here because its running sum of squares is about \(2 \times 10^{21}\) at offset \(10^9\), while the true sum of squared deviations is about 174. Doubles near \(2 \times 10^{21}\) are spaced \(2^{18} = 262144\) apart, while the sum of squared deviations is \((n-1)s^2 = 1999 \times 0.0872811 \approx 174.5\). The rounding error of the sums is therefore larger than the quantity being estimated. Welford's error rises from \(9.26 \times 10^{-16}\) at offset 0 to \(7.45 \times 10^{-8}\) at offset \(10^9\), so this update is not exact in floating point either. The lab shows the three offsets of one stream and one seed. It does not show that the rise continues beyond \(10^9\), that the ordering holds on other streams, or that any method is stable in general.

3Where the canon breaks

  • The proofs assume exact arithmetic. Theorem 2.2 holds for real numbers. In double precision each subtraction, division and multiplication rounds. Lab 1 measures the effect on one stream: Welford's relative error is \(7.45 \times 10^{-8}\) at offset \(10^9\), against \(1.27 \times 10^{-14}\) for the two-pass formula at the same offset. A claim that the update is "stable" needs such a measurement, and this proof does not supply one.
  • The naive formula is an exact identity that fails in floating point. Lemma 1.3 makes \(\sum x_i^2 - n\bar x_n^2\) equal to \(S_n\) for real numbers. The two terms are of size about \(n\) times the square of the offset, while \(S_n\) is of size about \(n\) times the spread. At offset \(10^9\) the difference cancels almost every digit, and on this stream the computed value is exactly \(0.0\).
  • The variance needs at least two values. The sample form \(S_n/(n-1)\) divides by zero at \(n = 1\). Welford's \(S_1 = 0\) is well defined, but the variance is not, so any query of \(s^2\) before the second value is an error and must not return \(0\).

4Misconceptions

  1. “The sum-of-squares formula is a correct algorithm at any scale, because it is an exact identity.”

    Lemma 1.3 is an identity for real numbers, and the algorithm computes it in floating point. Lab 1 at offset \(10^9\) returns exactly \(0.0\) for a stream whose true sample variance is \(0.0872811\), a relative error of \(1.000\).

  2. “Welford's update gives the exact variance in floating point, because its proof is exact.”

    Theorem 2.2 assumes exact arithmetic (hypothesis 3). On the lab stream its relative error rises from \(9.26 \times 10^{-16}\) at offset 0 to \(7.45 \times 10^{-8}\) at offset \(10^9\). It is far more accurate than the naive formula at every offset printed, and it is not exact.

  3. “Dividing \(S_n\) by \(n\) gives the sample variance.”

    Definition 1.1 divides by \(n-1\) for the sample variance and by \(n\) for the population variance. For the values 1, 2, 3 the sum of squared deviations is \(S_3 = 2\), so the sample variance is \(2/2 = 1\) and the population variance is \(2/3\). Using \(n\) in place of \(n-1\) underestimates the sample variance by the factor \((n-1)/n\).

5Problem set

Every problem has a full worked solution. Attempt each one before opening it.

Mechanics

M1 · Mean and sample variance by hand

For the values 2, 4, 4, 4, 5, 5, 7, 9, find the mean, \(S_8\), the sample variance and the population variance.

Solution

The sum is 40, so \(\bar x_8 = 40/8 = 5\). The deviations are \(-3, -1, -1, -1, 0, 0, 2, 4\), with squares \(9, 1, 1, 1, 0, 0, 4, 16\) that add to \(S_8 = 32\). The sample variance is \(32/7 \approx 4.5714\) and the population variance is \(32/8 = 4\).

M2 · Run the recursion on 1, 2, 3

Apply Definition 1.2 to \(x_1 = 1\), \(x_2 = 2\), \(x_3 = 3\). Give \(M_3\) and \(S_3\), and check \(S_3\) against Definition 1.1.

Solution

Start with \(M_1 = 1\), \(S_1 = 0\). For \(n = 2\): \(M_2 = 1 + (2-1)/2 = 1.5\), and \(S_2 = 0 + (2-1)(2-1.5) = 0.5\). For \(n = 3\): \(M_3 = 1.5 + (3-1.5)/3 = 2\), and \(S_3 = 0.5 + (3-1.5)(3-2) = 2\). Directly, \((1-2)^2 + (2-2)^2 + (3-2)^2 = 2\), which agrees.

M3 · A zero-one stream

Run the recursion on the values 0, 1, 0, 1. Give \(S_4\) and the population variance, and check the population variance against \(p(1-p)\), where \(p\) is the fraction of ones.

Solution

\(M_1 = 0\), \(S_1 = 0\). Value 1: \(M_2 = 0 + 1/2 = 0.5\), \(S_2 = 0 + 1 \cdot 0.5 = 0.5\). Value 0: \(d = -0.5\), \(M_3 = 0.5 - 0.5/3 = 1/3\), \(S_3 = 0.5 + (-0.5)(0 - 1/3) = 2/3\). Value 1: \(d = 2/3\), \(M_4 = 1/3 + (2/3)/4 = 1/2\), \(S_4 = 2/3 + (2/3)(1 - 1/2) = 1\). The population variance is \(S_4/4 = 1/4\). With \(p = 1/2\), \(p(1-p) = 1/4\), which agrees.

Proof

P1 · The two-value case

Show that for \(n = 2\) and any real \(x_1, x_2\), the recursion gives \(S_2 = (x_1 - x_2)^2/2\), and check this against Definition 1.1.

Solution

Let \(d = x_2 - x_1\). Then \(M_2 = x_1 + d/2 = (x_1 + x_2)/2\), and \(x_2 - M_2 = d/2\). The update gives \(S_2 = 0 + d \cdot d/2 = d^2/2 = (x_1 - x_2)^2/2\). Directly, the mean is \((x_1 + x_2)/2\), and the two squared deviations are each \((x_1 - x_2)^2/4\), which add to \((x_1 - x_2)^2/2\). The two agree.

P2 · A constant stream

Show that if \(x_i = c\) for every \(i\), then \(M_n = c\) and \(S_n = 0\) for every \(n \ge 1\), using the recursion and Theorem 2.2.

Solution

\(M_1 = c\) and \(S_1 = 0\). For \(n \ge 2\), \(d = x_n - M_{n-1} = c - c = 0\), so \(M_n = M_{n-1} = c\) and \(S_n = S_{n-1} + 0 \cdot (c - c) = S_{n-1}\). By induction \(S_n = 0\) for all \(n\). Theorem 2.2 then says \(S_n = \sum (x_i - \bar x_n)^2 = \sum (c - c)^2 = 0\), which agrees.

P3 · Merging two blocks

Let block A have \(a\) values with mean \(m_A\) and sum of squared deviations \(S_A\), and block B have \(b\) values with mean \(m_B\) and sum of squared deviations \(S_B\). Show that the combined sum of squared deviations is \(S = S_A + S_B + (m_B - m_A)^2 \, ab/(a+b)\). State every hypothesis used.

Solution

Hypotheses. \(a, b \ge 1\), the values are real, and arithmetic is exact. Let \(m = (a m_A + b m_B)/(a+b)\) be the combined mean and \(\Delta = m_B - m_A\). For block A, \(\sum_A (x - m)^2 = \sum_A (x - m_A)^2 + a(m_A - m)^2\), because the cross term \(2(m_A - m)\sum_A (x - m_A)\) is zero. The same holds for B. Now \(m_A - m = -b\Delta/(a+b)\) and \(m_B - m = a\Delta/(a+b)\). So \(a(m_A - m)^2 + b(m_B - m)^2 = (a b^2 + b a^2)\Delta^2/(a+b)^2 = ab\Delta^2/(a+b)\). Adding \(S_A + S_B\) gives the formula.

Empirical

E1 · Which estimate is zero, and why

In Lab 1 at offset \(10^9\), the naive estimate is exactly zero. Explain the mechanism using the magnitudes of the two running sums, and say why the lab's exact reference is not affected.

Solution

The running sums are \(\sum x_i\) and \(\sum x_i^2\). For 2000 values near \(10^9\), the second sum is about \(2 \times 10^{21}\), and doubles in that range are spaced \(2^{18} = 262144\) apart. The true sum of squared deviations is about \(174.5\), far below that spacing, so the difference of the two sums is dominated by rounding. The computed difference happens to be exactly zero on this stream. The reference uses \(\texttt{Fraction}\) arithmetic on the same float values, so it is not affected by rounding and gives \(0.0872811\).

E2 · The absolute error at offset zero

The lab prints Welford's relative error at offset 0 as \(9.26 \times 10^{-16}\), and the exact sample variance as 0.087281. Compute Welford's absolute error at offset 0, to two significant digits.

Solution

The unrounded exact variance is 0.08728110122738864, and the unrounded relative error is \(9.25811790803366 \times 10^{-16}\). Their product is \(8.08 \times 10^{-17}\), so the absolute error is about \(8.1 \times 10^{-17}\). The product is taken from the unrounded values, and the relative error printed as \(9.26 \times 10^{-16}\) gives the same result to two significant digits.

E3 · Why the two-pass error is smallest at offset zero

From the lab output, the two-pass relative error at offset 0 is \(2.82 \times 10^{-17}\), and the Welford error is \(9.26 \times 10^{-16}\). Name one reason the two-pass formula can be more accurate than Welford's update on the same stream, and say what the lab does not show.

Solution

One candidate mechanism: the two-pass formula computes the mean once and then squares deviations from that fixed mean, so it has no running mean that is updated with a rounded division at each value. Welford's update does update a running mean at each of the 2000 steps, and those rounding errors can enter the later deviations. This is a hypothesis about the mechanism. Lab 1 shows the ordering on one stream and does not test the mechanism, and it does not show that the ordering holds on other streams or at other sizes.

Research

R1 · Weighted updates

Let each value \(x_i\) carry a positive weight \(w_i\), and let the weighted mean be \(\sum w_i x_i / \sum w_i\). Derive the analogue of Definition 1.2 that keeps the running weight \(W_n = \sum_{i \le n} w_i\), and state its hypotheses.

Solution

Hypotheses. \(w_i > 0\), the values are real, and arithmetic is exact. Put \(W_1 = w_1\), \(M_1 = x_1\), \(S_1 = 0\). For \(n \ge 2\): \(W_n = W_{n-1} + w_n\), \(M_n = M_{n-1} + (w_n/W_n)(x_n - M_{n-1})\), and \(S_n = S_{n-1} + w_n (x_n - M_{n-1})(x_n - M_n)\). This is a sketch, not a proof: the induction follows Theorem 2.2 with \(w_n/W_n\) in place of \(1/n\). The mean step needs \(W_n M_n = W_{n-1}M_{n-1} + w_n x_n\), and the sum-of-squares step needs the increment \(w_n d^2 W_{n-1}/W_n\) with \(d = x_n - M_{n-1}\). Only the second step is checked here, on one example: \(x = (1, 2)\) with weights \((1, 3)\) gives \(M_2 = 1.75\) and \(S_2 = 3 \cdot 1 \cdot 0.25 = 0.75\), which equals \(\sum w_i(x_i - M_2)^2 = 1 \cdot 0.5625 + 3 \cdot 0.0625 = 0.75\). The algebra that completes the induction is left to the reader and is not verified on the page.

R2 · Why the proof is not a bound on error

Theorem 2.2 is an identity, and Lab 1 shows errors that grow with the offset. Explain in two or three sentences why no identity of this kind can bound the floating-point error of the update.

Solution

An identity holds for exact real numbers, and it says nothing about the value of a rounded computation unless the rounding is modelled. A bound on floating-point error needs an explicit model of each rounding step (for example, that each operation returns the exact result times one factor within \(1 \pm u\)) and a propagation argument through the recursion. Theorem 2.2 supplies neither, so it can establish correctness but not accuracy.

R3 · Population variance of a zero-one stream

For a stream of \(n\) values, each 0 or 1, with \(k\) ones, find the population variance \(\sigma_n^2\) in terms of \(p = k/n\), and compute it for \(n = 10\), \(k = 4\).

Solution

The mean is \(\bar x_n = p\). Each value contributes \((1 - p)^2\) if it is 1 and \(p^2\) if it is 0, so \(S_n = k(1-p)^2 + (n-k)p^2\). With \(k = np\), this is \(np(1-p)^2 + n(1-p)p^2 = np(1-p)\,[(1-p) + p] = np(1-p)\). Dividing by \(n\) gives \(\sigma_n^2 = p(1-p)\). For \(n = 10\), \(k = 4\), \(p = 0.4\) and \(\sigma_n^2 = 0.4 \times 0.6 = 0.24\). Direct check: \(S_{10} = 4(0.6)^2 + 6(0.4)^2 = 1.44 + 0.96 = 2.4\), and \(2.4/10 = 0.24\).

  2. Find the sample variance of 2, 4, 4, 4, 5, 5, 7, 9 (four decimals).

    The sum of squared deviations is 32 and \(n - 1 = 7\), so \(32/7 \approx 4.5714\) (M1).

  3. Run Welford's recursion on 1, 2, 3. What is \(S_3\)?

    \(S_3 = 0.5 + 1.5 \cdot 1 = 2\), with \(M_3 = 2\) (M2).

  4. The induction in Theorem 2.2 needs which two parts?

    Options

    The base case is \(M_1 = x_1\), \(S_1 = 0\). The step is Theorem 2.1.

  5. How many arithmetic operations does one Welford update perform, independent of \(n\)?

    Subtraction, division, addition for the mean; subtraction, multiplication, addition for the sum of squares (Corollary 2.3).

  6. Why does Lab 1 add a large offset to every value?

    Options

    The exact variance is 0.087281 to six digits at all three offsets. Only the offset changes, so any change in the estimates comes from the arithmetic.

  7. Find the population variance of 0, 1, 0, 1.

    \(S_4 = 1\), so \(\sigma_4^2 = 1/4\). This equals \(p(1-p)\) with \(p = 1/2\) (M3).

  8. Which hypothesis of Theorem 2.2 does floating-point arithmetic fail to satisfy?

    Options

    Hypothesis (3) of Theorem 2.2. Floating-point arithmetic rounds at each step, so the theorem does not cover the computed values, and Lab 1 measures that gap.

  9. In Lab 1 at offset \(10^9\), what does the naive estimate return?

    Options

    The lab's output for offset 1e9 shows a naive relative error of 1.000e+00, which means the estimate is zero (Section 3 and E1).
