Atlas A2: Data Layer

Build the Atlas research platform data layer (atlas.dataset): an immutable, point-in-time store backed by SQLite with ingestion adapters for the five foundational financial data sources (FRED, French, Shiller, Treasury, EDGAR), deterministic ASOF temporal querying, and cryptographic SHA-256 manifest verification.

  • Milestone: Atlas A2 (research data layer store).
  • Deliverable: atlas/dataset.py passing test suite on seeds 0–49.
  • Grading: Autograded by pytest suite (autograder).
  • Prerequisites: relational model, SQL joins, ASOF join, point-in-time data, data manifest.

Specification

Context
Quantitative trading strategies depend critically on point-in-time data integrity. Training models on historical restatements or future-dated revisions introduces catastrophic look-ahead bias that guarantees live operational failure. Atlas Milestone A2 delivers the foundational research store that ingests external data sources, maintains strict bitemporal point-in-time query isolation, and guarantees tamper resistance through cryptographic SHA-256 payload hashing.
Inputs
Simulated raw CSV tables and JSON byte payloads corresponding to the five core financial data sources: fred, french, shiller, treasury, and edgar. Each ingestion call provides the source identifier, raw payload bytes, ISO 8601 UTC retrieval timestamp, licence string, and source URL.
Required outputs
An importable module atlas.dataset exposing the frozen dataclass ManifestRow, the store factory open_store(path: str, *, engine: str = "sqlite") -> Store, and the Store class implementing methods: ingest, ingest_raw, asof, manifest, verify, and close.
Constraints
Standard library only on the grader path (sqlite3, hashlib, csv, datetime, decimal). No floating-point conversion of cell strings (exact text preserved). Strict ISO 8601 UTC timestamps with trailing Z (YYYY-MM-DDTHH:MM:SSZ). Atomic transaction rollback on malformed input. Clean execution under python -I -W error without unclosed database handles.
Grading
Autograded by automated pytest suite (autograder) verifying 50 independent per-learner workspace seeds (0–49) within 60 seconds.
