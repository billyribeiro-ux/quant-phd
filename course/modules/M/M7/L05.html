A quadratic program minimises a quadratic objective under linear constraints. This lesson defines that problem and proves the results named here under stated hypotheses. An equality-constrained problem has a unique minimiser when its Hessian is positive definite and its constraint rows are independent (Theorem 2.3). For a convex QP, with Q positive semidefinite, the KKT conditions with nonnegative inequality multipliers are sufficient for optimality (Theorem 3.1). A positive-definite Hessian gives at most one minimiser over a feasible set that contains the midpoint of any two of its points (Proposition 3.4). Lab 1 solves a three-variable equality problem in exact arithmetic and enumerates the sets fixed at zero in a two-variable problem. Lesson 6 applies the problem to mean-variance portfolio choice.

1The problem and its gradient

Vectors are columns, \(x^{\top}\) is the transpose of \(x\), and \(\mathbf{1}\) is the vector of ones. A quadratic form \(x^{\top}Qx\) is a real number for each \(x\).

Definition 1.1 (quadratic program)

Let \(Q\) be a real symmetric \(n \times n\) matrix, \(c \in \mathbb{R}^{n}\), \(A\) a real \(m \times n\) matrix with \(b \in \mathbb{R}^{m}\), and \(G\) a real \(p \times n\) matrix with \(h \in \mathbb{R}^{p}\). The quadratic program with these data is

\[\min_{x \in \mathbb{R}^{n}} \; f(x) = \tfrac{1}{2}\,x^{\top}Qx + c^{\top}x \quad \text{subject to} \quad Ax = b, \; Gx \le h.\]

Its feasible set is \(F = \{x \in \mathbb{R}^{n} : Ax = b,\; Gx \le h\}\), the set of points that satisfy every constraint. With \(p = 0\) the problem is an equality-constrained QP. With \(m = 0\) it has inequalities only.

Remark 1.2 (only the symmetric part of Q matters)

For any real \(n \times n\) matrix \(Q\), \(x^{\top}Qx = x^{\top}Q^{\top}x\), because a \(1 \times 1\) matrix equals its transpose. Averaging gives \(x^{\top}Qx = x^{\top}\tfrac{1}{2}(Q + Q^{\top})x\). So the definition loses no generality when \(Q\) is symmetric.

Lemma 1.3 (exact quadratic expansion)

Let \(Q\) be symmetric and \(f\) as in Definition 1.1. For all \(x, d \in \mathbb{R}^{n}\),

\[f(x + d) = f(x) + (Qx + c)^{\top}d + \tfrac{1}{2}\,d^{\top}Qd.\]

So the gradient of \(f\) at \(x\) is \(\nabla f(x) = Qx + c\), and the Hessian of \(f\) is the constant matrix \(Q\).

Proof

Expand \((x + d)^{\top}Q(x + d) = x^{\top}Qx + x^{\top}Qd + d^{\top}Qx + d^{\top}Qd\). The two middle terms are equal, because \(d^{\top}Qx\) is a real number equal to its transpose \(x^{\top}Q^{\top}d = x^{\top}Qd\). Hence \(\tfrac{1}{2}(x + d)^{\top}Q(x + d) = \tfrac{1}{2}x^{\top}Qx + x^{\top}Qd + \tfrac{1}{2}d^{\top}Qd\). Adding \(c^{\top}(x + d) = c^{\top}x + c^{\top}d\) gives \(f(x + d) = f(x) + (Qx)^{\top}d + c^{\top}d + \tfrac{1}{2}d^{\top}Qd\), which is the claim.

Lemma 1.4 (the tangent plane lies below the quadratic)

Let \(Q\) be symmetric and positive semidefinite, meaning \(d^{\top}Qd \ge 0\) for every \(d\). Then for all \(x, y\), \(f(y) \ge f(x) + (Qx + c)^{\top}(y - x)\). The function \(f\) is convex, in the sense defined in L01.

Proof

Apply Lemma 1.3 with the base point \(x\) and \(d = y - x\). It gives \(f(y) - f(x) - (Qx + c)^{\top}(y - x) = \tfrac{1}{2}(y - x)^{\top}Q(y - x) \ge 0\). For the convexity clause, let \(z = \theta x + (1 - \theta) y\) with \(\theta \in [0, 1]\). The linear terms of \(f\) cancel in the combination below, and the quadratic terms give \(\theta f(x) + (1 - \theta) f(y) - f(z) = \tfrac{1}{2}\theta(1 - \theta)(x - y)^{\top}Q(x - y) \ge 0\), because \(\theta - \theta^{2} = \theta(1 - \theta)\), \((1 - \theta) - (1 - \theta)^{2} = \theta(1 - \theta)\), and \(Q\) is positive semidefinite. This is the chord inequality \(f(z) \le \theta f(x) + (1 - \theta) f(y)\).

2Equality constraints and the KKT linear system

Let \(p = 0\), so \(F = \{x : Ax = b\}\). The Lagrangian of this section is \(\mathcal{L}(x, \lambda) = f(x) + \lambda^{\top}(Ax - b)\), with one multiplier \(\lambda_{k}\) for each row of \(A\). Its stationarity condition \(\nabla_{x}\mathcal{L} = 0\) reads \(Qx + c + A^{\top}\lambda = 0\). Together with \(Ax = b\), this is a linear system in \((x, \lambda)\):

\[K \begin{pmatrix} x \\ \lambda \end{pmatrix} = \begin{pmatrix} -c \\ b \end{pmatrix}, \qquad K = \begin{pmatrix} Q & A^{\top} \\ A & 0 \end{pmatrix}.\]

Proposition 2.1 (the KKT matrix is nonsingular)

Assume \(Q\) is symmetric positive definite and \(A\) has full row rank \(m \le n\). Then \(K\) is a nonsingular \((n + m) \times (n + m)\) matrix.

Proof

It suffices to show that \(K v = 0\) forces \(v = 0\). Write \(v = (x, \lambda)\). The first block row gives \(Qx + A^{\top}\lambda = 0\), and the second gives \(Ax = 0\). Multiply the first by \(x^{\top}\): \(x^{\top}Qx + x^{\top}A^{\top}\lambda = 0\). Since \(x^{\top}A^{\top}\lambda = (Ax)^{\top}\lambda = 0\), we get \(x^{\top}Qx = 0\). Positive definiteness gives \(x = 0\). Then \(A^{\top}\lambda = -Qx = 0\). Full row rank means the columns of \(A^{\top}\) are independent, so \(\lambda = 0\). Hence \(K\) has trivial kernel, and a square matrix with trivial kernel is nonsingular.

Remark 2.2 (dependent constraint rows make K singular)

Take \(n = 2\), \(Q = I\), and \(A\) with both rows equal to \((1, 0)\). Then \(A\) has rank one, not two. The matrix \(K\) has rows \((1, 0, 1, 1)\), \((0, 1, 0, 0)\), \((1, 0, 0, 0)\) and \((1, 0, 0, 0)\). Rows three and four are equal, so \(\det K = 0\). The rank condition in Proposition 2.1 cannot be dropped.

Theorem 2.3 (the equality-constrained QP has a unique minimiser)

Assume \(Q\) is symmetric positive definite and \(A\) has full row rank. Let \((\hat{x}, \lambda^{*})\) be the solution of \(K(x, \lambda)^{\top} = (-c, b)^{\top}\), which exists and is unique by Proposition 2.1. Then \(\hat{x}\) is the unique minimiser of \(f\) over \(F = \{x : Ax = b\}\).

Proof

Let \(x \in F\) and put \(d = x - \hat{x}\). Then \(Ad = Ax - A\hat{x} = b - b = 0\). By Lemma 1.3, \(f(x) = f(\hat{x}) + (Q\hat{x} + c)^{\top}d + \tfrac{1}{2}d^{\top}Qd\). The first block row gives \(Q\hat{x} + c = -A^{\top}\lambda^{*}\), so \((Q\hat{x} + c)^{\top}d = -\lambda^{*\top}Ad = 0\). Therefore \(f(x) = f(\hat{x}) + \tfrac{1}{2}d^{\top}Qd\). If \(d \ne 0\), the last term is positive, so \(f(x) > f(\hat{x})\). If \(d = 0\), then \(x = \hat{x}\). So \(\hat{x}\) is the only minimiser.

Remark 2.4 (the constraint line of a one-dimensional example)

Take \(n = 3\), \(A\) with rows \((1, 1, 1)\) and \((0, 1, -1)\), \(b = (1, 0)\), and \(Q\) and \(c\) as in Lab 1. The rows are not proportional, so \(A\) has full row rank. The matrix \(Q\) is positive definite, because \(x^{\top}Qx = 4x_{1}^{2} + 3x_{2}^{2} + 2x_{3}^{2} + 2x_{1}x_{2} + 2x_{2}x_{3}\) equals \((2x_{1} + \tfrac{1}{2}x_{2})^{2} + \tfrac{11}{4}(x_{2} + \tfrac{4}{11}x_{3})^{2} + \tfrac{18}{11}x_{3}^{2}\), which is positive unless \(x = 0\). The vector \(v = (-2, 1, 1)\) satisfies \(Av = 0\), so \(F\) is the line \(\hat{x} + tv\) for real \(t\). Along it, \(f(\hat{x} + tv) = f(\hat{x}) + \tfrac{1}{2}t^{2}\,v^{\top}Qv\), by Lemma 1.3 with \(d = tv\), because the linear term vanishes: \(Q\hat{x} + c = -A^{\top}\lambda^{*}\) and \(Av = 0\), as in the proof of Theorem 2.3.

3Inequality constraints and sufficiency of KKT

Now let \(G\) and \(h\) be present. An active set of a point \(x \in F\) is the set of inequality rows that hold with equality at \(x\). In this lesson the Lagrangian is \(\mathcal{L}(x, \lambda, \mu) = f(x) + \lambda^{\top}(Ax - b) + \mu^{\top}(Gx - h)\). The KKT conditions for the QP are the conditions of the definition in L03 written for this \(f\):

  • Stationarity. \(Qx + c + A^{\top}\lambda + G^{\top}\mu = 0\).
  • Primal feasibility. \(Ax = b\) and \(Gx \le h\).
  • Dual feasibility. \(\mu \ge 0\), componentwise.
  • Complementary slackness. \(\mu_{i}(Gx - h)_{i} = 0\) for every \(i\).

These are the conditions of the L03 definition for the constraints \(g_{i}(x) = (Gx - h)_{i} \le 0\) and \(h_{j}(x) = (Ax - b)_{j} = 0\), with the same Lagrangian sign, so the multipliers \(\mu_{i}\) of \(Gx \le h\) are the L03 multipliers that must be nonnegative. Theorem 3.1 needs that sign.

Theorem 3.1 (KKT conditions are sufficient for a convex QP)

Assume \(Q\) is symmetric positive semidefinite. Let \(\bar{x} \in F\), and suppose there are \(\bar{\lambda}\) and \(\bar{\mu} \ge 0\) with \(Q\bar{x} + c + A^{\top}\bar{\lambda} + G^{\top}\bar{\mu} = 0\) and \(\bar{\mu}_{i}(G\bar{x} - h)_{i} = 0\) for every \(i\). Then \(\bar{x}\) minimises \(f\) over \(F\).

Proof

Let \(x \in F\). By Lemma 1.4, \(f(x) \ge f(\bar{x}) + (Q\bar{x} + c)^{\top}(x - \bar{x})\). Stationarity gives \(Q\bar{x} + c = -A^{\top}\bar{\lambda} - G^{\top}\bar{\mu}\), so \((Q\bar{x} + c)^{\top}(x - \bar{x}) = -\bar{\lambda}^{\top}A(x - \bar{x}) - \bar{\mu}^{\top}G(x - \bar{x})\). The first term is zero, because \(A(x - \bar{x}) = (Ax - b) - (A\bar{x} - b) = 0\). For the second, \(G(x - \bar{x}) = (Gx - h) - (G\bar{x} - h)\), and complementary slackness gives \(\bar{\mu}^{\top}(G\bar{x} - h) = 0\). So \(-\bar{\mu}^{\top}G(x - \bar{x}) = \sum_{i}\bar{\mu}_{i}(h - Gx)_{i}\). Each term is nonnegative, since \(\bar{\mu}_{i} \ge 0\) and \(x\) is feasible. Hence \(f(x) \ge f(\bar{x})\).

Remark 3.2 (a stationary point with a negative multiplier need not be optimal)

Let \(n = 1\), \(Q = 1\), \(c = -1\), \(G = -1\), \(h = 0\), so the only constraint is \(x \ge 0\). The point \(\bar{x} = 0\) is feasible. Stationarity \(\bar{x} - 1 - \bar{\mu} = 0\) gives \(\bar{\mu} = -1\), which is negative. The point is not optimal: \(f(0) = 0\), while \(f(1) = \tfrac{1}{2} - 1 = -\tfrac{1}{2}\) and \(x = 1\) is feasible. Dual feasibility cannot be dropped from Theorem 3.1.

Definition 3.3 (the S-candidate)

For a set \(S\) of indices of rows of \(G\), the \(S\)-candidate is the solution \(x_{S}\), with multipliers, of the equality-constrained QP that keeps the constraints \(Ax = b\) and \(G_{i}x = h_{i}\) for \(i \in S\) and drops the other inequality constraints. When it exists, Theorem 2.3 identifies it when \(Q\) is symmetric positive definite and the rows of \(A\) and of \(G_{i}\) for \(i \in S\) are linearly independent. The method of Lab 1 Part B enumerates all \(2^{p}\) sets \(S\), keeps each candidate that passes the primal and dual tests of Section 3, and reports the kept ones.

Proposition 3.4 (at most one minimiser when Q is positive definite)

Assume \(Q\) is symmetric positive definite and \(F\) is midpoint convex: for \(x, y \in F\) the midpoint \(\tfrac{1}{2}(x + y)\) is in \(F\). Then \(f\) has at most one minimiser over \(F\). The proof uses only this midpoint property.

Proof

Let \(x \ne y\) both minimise \(f\) over \(F\), with common minimum value \(m\), and let \(z = \tfrac{1}{2}(x + y) \in F\). Put \(u = \tfrac{1}{2}(x - y)\) and \(g = Qz + c\). Since \(x = z + u\) and \(y = z - u\), Lemma 1.3 at the base point \(z\) gives \(f(x) = f(z) + g^{\top}u + \tfrac{1}{2}u^{\top}Qu\) and \(f(y) = f(z) - g^{\top}u + \tfrac{1}{2}u^{\top}Qu\). Adding the two lines cancels the linear terms: \(f(x) + f(y) = 2f(z) + u^{\top}Qu\). Since \(u^{\top}Qu = \tfrac{1}{4}(x - y)^{\top}Q(x - y)\), this is \(f(z) = \tfrac{1}{2}\big(f(x) + f(y)\big) - \tfrac{1}{8}(x - y)^{\top}Q(x - y)\). The last term is strictly negative, because \(Q\) is positive definite and \(x \ne y\). So \(f(z) < m\), which contradicts \(m\) being the minimum of \(f\) over \(F\), since \(z \in F\).

Remark 3.5 (the feasible set of Lab 1 is convex)

In Part B the constraints are \(x \ge 0\), which are linear, and \(Q = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}\) is positive definite, since \(x^{\top}Qx = (x_{1} + x_{2})^{2} + x_{1}^{2} + x_{2}^{2}\). If \(x\) and \(y\) satisfy them, so does \(\tfrac{1}{2}(x + y)\), because each coordinate of the midpoint is an average of two nonnegative numbers. So Proposition 3.4 applies to Lab 1 Part B.

Example 3.6 (the minimiser in Lab 1, Part B, by hand)

Let \(Q\) and \(c\) be as in Lab 1, Part B, with \(G = -I\) and \(h = 0\). Take \(\bar{x} = (3/2, 0)\). It is feasible. Here \(Q\bar{x} = (3, 3/2)\), so \(Q\bar{x} + c = (0, 5/2)\). Put \(\bar{\mu} = (0, 5/2)\). Then \(Q\bar{x} + c - \bar{\mu} = 0\), which is stationarity with \(G^{\top}\bar{\mu} = -\bar{\mu}\). Both multipliers are nonnegative, and \(\bar{\mu}_{i}\bar{x}_{i} = 0\) for each \(i\). By Theorem 3.1, \(\bar{x}\) minimises \(f\) over \(x \ge 0\), and \(f(\bar{x}) = \tfrac{1}{2}\cdot\tfrac{9}{2} - \tfrac{9}{2} = -\tfrac{9}{4}\).

Lab 1 applies Theorem 2.3 in Part A to the data of Remark 2.4, and enumerates candidates in Part B by Definition 3.3. The printed output is then checked against the hand derivations above.

Lab 1 · An equality QP from its KKT system, and an enumeration of active sets

The inputs are small integers chosen for this lab, not data, and the run uses no random draws. Stated before running. Part A solves the KKT system of Remark 2.4 in exact fractions. It predicts a nonzero KKT determinant, exact zero residuals in both block rows of the stationarity and constraint equations, and an exact match between \(f(\hat{x} + tv)\) and \(f(\hat{x}) + \tfrac{1}{2}t^{2}v^{\top}Qv\) at each of 17 values of \(t\) from \(-2\) to \(2\) in steps of \(1/4\). Part B lists the four sets of components fixed at zero for \(x \ge 0\) in two variables. It predicts that exactly one set passes both the primal test \(x \ge 0\) and the dual test on its fixed components, and that no point of a \(33 \times 33\) grid on \([0, 2]^{2}\) lies below that candidate's value.

"""M7 L05 lab 1: a quadratic program solved from its KKT system in exact arithmetic, and checked by enumeration.

Inputs are small hand-chosen integers, not data. No random draws are used, so every run prints the same lines.
Every number is a fractions.Fraction, so each residual is exactly zero or exactly a stated value.

Part A: equality-constrained QP, minimise f(x) = (1/2) x'Qx + c'x subject to Ax = b, with Q symmetric positive
definite (3 by 3) and A of full row rank (2 by 3). The KKT system [[Q, A'], [A, 0]] [x; lambda] = [-c; b] is solved
by Gaussian elimination. The printed checks are the exact residual of both block rows, and the increase of f along
the null direction v of A, which must equal (1/2) t^2 v'Qv for every t on a grid.

Part B: inequality QP, minimise (1/2) x'Qx + c'x subject to x >= 0 in two variables. The four active sets S (the
components fixed at zero) are enumerated. For each S the free components solve Q_FF x_F = -c_F, the multipliers on
S are mu_i = (Qx + c)_i, and the candidate is kept only if x >= 0 and mu_i >= 0 on S. The printed brute-force check
evaluates f on the grid {k/16 : 0 <= k <= 32}^2 and counts grid points below the candidate's value.

CU is the currency unit. This lab has no money amounts.
"""

from __future__ import annotations

from fractions import Fraction
from itertools import product

Q_A: list[list[Fraction]] = [
    [Fraction(4), Fraction(1), Fraction(0)],
    [Fraction(1), Fraction(3), Fraction(1)],
    [Fraction(0), Fraction(1), Fraction(2)],
]
C_A: list[Fraction] = [Fraction(-1), Fraction(0), Fraction(2)]
EQ_A: list[list[Fraction]] = [
    [Fraction(1), Fraction(1), Fraction(1)],
    [Fraction(0), Fraction(1), Fraction(-1)],
]
B_A: list[Fraction] = [Fraction(1), Fraction(0)]
NULL_A: list[Fraction] = [Fraction(-2), Fraction(1), Fraction(1)]

Q_B: list[list[Fraction]] = [[Fraction(2), Fraction(1)], [Fraction(1), Fraction(2)]]
C_B: list[Fraction] = [Fraction(-3), Fraction(1)]
GRID_STEPS = 16
GRID_MAX = 2


def solve(matrix: list[list[Fraction]], rhs: list[Fraction]) -> list[Fraction]:
    """Solve matrix x = rhs exactly by Gaussian elimination with row pivoting; raise ValueError if singular."""
    n = len(rhs)
    rows = [[*row, rhs[i]] for i, row in enumerate(matrix)]
    for col in range(n):
        pivot = next((r for r in range(col, n) if rows[r][col] != 0), None)
        if pivot is None:
            raise ValueError("the matrix is singular")
        rows[col], rows[pivot] = rows[pivot], rows[col]
        for r in range(n):
            if r != col and rows[r][col] != 0:
                factor = rows[r][col] / rows[col][col]
                rows[r] = [a - factor * b for a, b in zip(rows[r], rows[col], strict=True)]
    return [rows[i][n] / rows[i][i] for i in range(n)]


def quad(q: list[list[Fraction]], c: list[Fraction], x: list[Fraction]) -> Fraction:
    """f(x) = (1/2) x'Qx + c'x, exact."""
    qx = [sum((q[i][j] * x[j] for j in range(len(x))), Fraction(0)) for i in range(len(x))]
    return Fraction(1, 2) * sum((x[i] * qx[i] for i in range(len(x))), Fraction(0)) + sum(
        (c[i] * x[i] for i in range(len(x))), Fraction(0)
    )


def gradient(q: list[list[Fraction]], c: list[Fraction], x: list[Fraction]) -> list[Fraction]:
    """The gradient Qx + c of f, exact."""
    return [sum((q[i][j] * x[j] for j in range(len(x))), Fraction(0)) + c[i] for i in range(len(x))]


def leading_minors_positive(q: list[list[Fraction]]) -> bool:
    """Leading principal minors test: every leading principal minor is positive.

    An exact test for this Q. Remark 2.4 proves positive definiteness by completing the square.
    """
    for k in range(1, len(q) + 1):
        sub = [row[:k] for row in q[:k]]
        if det(sub) <= 0:
            return False
    return True


def det(m: list[list[Fraction]]) -> Fraction:
    """Determinant by cofactor expansion; the matrices here are at most 3 by 3."""
    n = len(m)
    if n == 1:
        return m[0][0]
    if n == 2:
        return m[0][0] * m[1][1] - m[0][1] * m[1][0]
    total = Fraction(0)
    for j in range(n):
        minor = [row[:j] + row[j + 1 :] for row in m[1:]]
        total += (-1) ** j * m[0][j] * det(minor)
    return total


def part_a() -> None:
    """Solve the equality-constrained QP from its KKT system and check it."""
    n, m = len(C_A), len(B_A)
    print(f"part_a_dimensions variables {n} constraints {m} kkt_size {n + m}")
    print(f"q_positive_definite {leading_minors_positive(Q_A)}")
    kkt = [Q_A[i] + [EQ_A[k][i] for k in range(m)] for i in range(n)]
    kkt += [EQ_A[k] + [Fraction(0)] * m for k in range(m)]
    print(f"kkt_determinant {det(kkt)}")
    rhs = [-c for c in C_A] + B_A
    sol = solve(kkt, rhs)
    x, lam = sol[:n], sol[n:]
    print("x " + " ".join(str(v) for v in x))
    print("lambda " + " ".join(str(v) for v in lam))

    grad = gradient(Q_A, C_A, x)
    stationarity = [grad[i] + sum((EQ_A[k][i] * lam[k] for k in range(m)), Fraction(0)) for i in range(n)]
    primal = [sum((EQ_A[k][i] * x[i] for i in range(n)), Fraction(0)) - B_A[k] for k in range(m)]
    print(f"max_abs_stationarity_residual {float(max(abs(v) for v in stationarity)):.1e}")
    print(f"max_abs_constraint_residual {float(max(abs(v) for v in primal)):.1e}")
    print(f"objective {float(quad(Q_A, C_A, x)):.10f}")

    base = quad(Q_A, C_A, x)
    null_ok = True
    worst = Fraction(0)
    for k in range(-8, 9):
        t = Fraction(k, 4)
        point = [x[i] + t * NULL_A[i] for i in range(n)]
        feasible = all(sum((EQ_A[r][i] * point[i] for i in range(n)), Fraction(0)) == B_A[r] for r in range(m))
        predicted = Fraction(1, 2) * t * t * quad_form(Q_A, NULL_A)
        gap = quad(Q_A, C_A, point) - base - predicted
        worst = max(worst, abs(gap))
        null_ok = null_ok and feasible and gap == 0
    print(f"null_line_increase_is_half_t_squared_form {null_ok}")
    print(f"null_line_worst_gap {float(worst):.1e}")


def quad_form(q: list[list[Fraction]], v: list[Fraction]) -> Fraction:
    """The quadratic form v'Qv, exact."""
    return sum((v[i] * q[i][j] * v[j] for i in range(len(v)) for j in range(len(v))), Fraction(0))


def part_b() -> None:
    """Enumerate the four active sets for x >= 0, keep the candidates that pass, and check on a grid."""
    n = len(C_B)
    candidates: list[tuple[tuple[int, ...], list[Fraction]]] = []
    print("part_b_candidates active_set primal_ok dual_ok")
    for mask in product((0, 1), repeat=n):
        fixed = tuple(i for i in range(n) if mask[i])
        free = [i for i in range(n) if not mask[i]]
        x = [Fraction(0)] * n
        if free:
            sub_q = [[Q_B[i][j] for j in free] for i in free]
            sub_c = [-C_B[i] for i in free]
            for pos, value in zip(free, solve(sub_q, sub_c), strict=True):
                x[pos] = value
        grad = gradient(Q_B, C_B, x)
        primal_ok = all(v >= 0 for v in x)
        dual_ok = all(grad[i] >= 0 for i in fixed)
        label = "{" + ",".join(str(i + 1) for i in fixed) + "}"
        print(f"candidate {label} primal {primal_ok} dual {dual_ok}")
        if primal_ok and dual_ok:
            candidates.append((fixed, x))
    print(f"passing_candidates {len(candidates)}")
    fixed, x_hat = candidates[0]
    value = quad(Q_B, C_B, x_hat)
    print("x_hat " + " ".join(str(v) for v in x_hat))
    print(f"objective_hat {value}")
    print("mu_hat " + " ".join(str(v) for v in gradient(Q_B, C_B, x_hat)))
    grid = [Fraction(k, GRID_STEPS) for k in range(GRID_STEPS * GRID_MAX + 1)]
    below = 0
    least = None
    for a in grid:
        for b in grid:
            fv = quad(Q_B, C_B, [a, b])
            below += fv < value
            least = fv if least is None or fv < least else least
    print(f"grid_points {len(grid) ** 2}")
    print(f"grid_points_below_candidate {below}")
    print(f"grid_minimum_equals_candidate {least == value}")

4Where the canon breaks

  • An indefinite Hessian can leave a QP with no minimiser. The theorems above need \(Q\) positive definite (Theorem 2.3, Proposition 3.4) or positive semidefinite (Theorem 3.1). Without one of these, a QP can have no minimiser at all, as Misconception 1 shows.
  • Semidefinite Hessians can have many minimisers. For \(Q = 0\), \(c = 0\) and no constraints, every point is a minimiser. Theorem 3.1 still holds for such a \(Q\), but it does not give uniqueness.
  • Enumeration grows exponentially. The method of Definition 3.3 examines \(2^{p}\) candidate sets. Lab 1 uses \(p = 2\), so four candidates. This lesson does not describe a method that examines fewer.
  • Exact arithmetic is limited to small problems. Lab 1 solves Part A in fractions for three variables. Its results are exact for these inputs, and they say nothing about floating-point solvers on larger problems.
  • The sign convention is part of the statement. With the opposite sign for \(\mu\), the dual test in Theorem 3.1 would read \(\mu \le 0\). The results here use the convention fixed in Section 3.

5Misconceptions

  1. “A quadratic objective always has a minimum, whatever the signs of its eigenvalues.”

    Take \(Q = \mathrm{diag}(1, -1)\), \(c = 0\), and no constraints. Along \(x = (0, t)\), \(f = -\tfrac{1}{2}t^{2}\), which tends to minus infinity as \(|t| \to \infty\). So \(f\) has no minimiser. Theorem 2.3 needs positive definiteness, and this \(Q\) is indefinite.

  2. “If a point satisfies the stationarity equation, it is optimal, whatever the multipliers are.”

    Remark 3.2 gives a feasible point that satisfies stationarity with a multiplier \(\bar{\mu} = -1\), and it is not optimal, because \(f(1) = -\tfrac{1}{2} < 0 = f(0)\). Theorem 3.1 requires \(\bar{\mu} \ge 0\), and that condition is what rules this out.

  3. “The minimiser of an equality-constrained QP is where the gradient of \(f\) is zero.”

    With \(Ax = b\), the gradient at the minimiser is \(-A^{\top}\lambda^{*}\), a combination of the constraint rows. It is zero exactly when \(\lambda^{*} = 0\), because \(A\) has full row rank. In Remark 2.4 the multipliers are \(\lambda^{*} = (-36/19, 11/19)\), which Lab 1 prints, so the gradient \(Q\hat{x} + c = -A^{\top}\lambda^{*}\) is not zero at \(\hat{x}\).

6Problem set

Every problem has a full worked solution. Attempt each one before opening it.

Mechanics

M1 · Minimise the squared norm on a line

Minimise \(x_{1}^{2} + x_{2}^{2}\) subject to \(x_{1} + x_{2} = 1\). Find the minimiser and the multiplier \(\lambda\) of the constraint.

Solution

Here \(Q = 2I\), \(c = 0\), \(A = (1, 1)\), \(b = 1\). The first block row \(Qx + A^{\top}\lambda = 0\) gives \(2x_{1} + \lambda = 0\) and \(2x_{2} + \lambda = 0\), so \(x_{1} = x_{2} = -\lambda/2\). The constraint gives \(-\lambda = 1\), so \(\lambda = -1\) and \(x = (1/2, 1/2)\). The objective there is \(1/4 + 1/4 = 1/2\). Theorem 2.3 says this is the only minimiser.

M2 · Positive definiteness by completing a square

Show that \(Q = \begin{pmatrix} 1 & 2 \\ 2 & 5 \end{pmatrix}\) is positive definite.

Solution

Expand \(x^{\top}Qx = x_{1}^{2} + 4x_{1}x_{2} + 5x_{2}^{2}\). Since \((x_{1} + 2x_{2})^{2} = x_{1}^{2} + 4x_{1}x_{2} + 4x_{2}^{2}\), we get \(x^{\top}Qx = (x_{1} + 2x_{2})^{2} + x_{2}^{2}\). This is zero only when \(x_{2} = 0\) and then \(x_{1} = 0\). So \(x^{\top}Qx > 0\) for every \(x \ne 0\).

M3 · The unconstrained minimiser

For \(Q = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}\) and \(c = (-3, 1)\), find the minimiser of \(f\) with no constraints.

Solution

With no constraints the stationarity condition is \(Qx = -c = (3, -1)\). The system \(2x_{1} + x_{2} = 3\), \(x_{1} + 2x_{2} = -1\) has solution \(x_{1} = 7/3\) and \(x_{2} = -5/3\). Check: \(2(7/3) - 5/3 = 3\) and \(7/3 - 10/3 = -1\). The matrix is positive definite, so this is the unique minimiser. Its second coordinate is negative, which is why Lab 1 finds that the empty active set fails the primal test.

Proof

P1 · The gap between f and its tangent

Let \(Q\) be symmetric. Prove that \(f(x) - f(y) - (Qy + c)^{\top}(x - y) = \tfrac{1}{2}(x - y)^{\top}Q(x - y)\) for all \(x\) and \(y\).

Solution

Apply Lemma 1.3 with base point \(y\) and \(d = x - y\). Lemma 1.3 gives \(f(x) = f(y) + (Qy + c)^{\top}(x - y) + \tfrac{1}{2}(x - y)^{\top}Q(x - y)\). Rearranging gives the claim. No other fact is used.

P2 · Dependent rows make the KKT matrix singular

Let \(Q\) be any symmetric matrix, and let the two rows of \(A\) be equal. Show that \(K\) is singular.

Solution

Let \(a^{\top}\) be the common row of \(A\). Then the last two rows of \(K\) are both \((a^{\top}, 0, 0)\), which are equal. Two equal rows make the determinant zero, so \(K\) is singular. This is the general form of Remark 2.2.

P3 · The equal-weight minimiser

Let \(Q = I\) on \(\mathbb{R}^{n}\), \(c = 0\), \(A = \mathbf{1}^{\top}\), and \(b = 1\). Show that the unique minimiser of \(\tfrac{1}{2}\|x\|^{2}\) subject to \(\mathbf{1}^{\top}x = 1\) is \(x_{i} = 1/n\) for each \(i\).

Solution

The first block row gives \(x + \lambda\mathbf{1} = 0\), so \(x = -\lambda\mathbf{1}\). The constraint gives \(\mathbf{1}^{\top}x = -n\lambda = 1\), so \(\lambda = -1/n\) and \(x = (1/n)\mathbf{1}\). Here \(Q = I\) is positive definite and \(A\) has full row rank, so Theorem 2.3 says this point is the unique minimiser.

E3 · What the determinant does and does not show

A nonzero determinant shows that the KKT matrix for this one instance is nonsingular, so the system of Part A has exactly one solution. Research

R1 · One variable with a nonnegativity constraint

Minimise \(\tfrac{1}{2}qx^{2} + cx\) subject to \(x \ge 0\), where \(q > 0\). Show that the minimiser is \(\max(0, -c/q)\).

Solution

Write the constraint as \(-x \le 0\), so \(G = -1\), \(h = 0\). Stationarity is \(qx + c - \mu = 0\). If \(-c/q \ge 0\), take \(x = -c/q\) and \(\mu = 0\): the point is feasible, stationarity holds, and complementary slackness holds. If \(-c/q < 0\), then \(c > 0\); take \(x = 0\) and \(\mu = c > 0\): stationarity holds, the point is feasible, and \(x\mu = 0\). In both cases Theorem 3.1 applies, since \(q > 0\) gives a convex objective.

R2 · Separable nonnegative minimisation

Let \(n = 3\), \(Q = I\), \(c = (1, -1, -2)\), and impose \(x \ge 0\) componentwise. Find the minimiser.

Solution

The objective is \(\sum_{i}\big(\tfrac{1}{2}x_{i}^{2} + c_{i}x_{i}\big)\), and the constraints act on one coordinate each. So the minimum splits into three one-variable problems. By R1 with \(q = 1\), the minimiser of coordinate \(i\) is \(\max(0, -c_{i})\). This gives \(\hat{x} = (0, 1, 2)\).

R3 · Two assets on the simplex

Let \(Q = I\) and \(c = -r\) with \(r = (0.1, 0.02)\), and impose \(w \ge 0\) and \(w_{1} + w_{2} = 1\). Find the minimiser.

Solution

Try the point with both components positive and the constraint active, \(w = r + t\mathbf{1}\). The sum is \(0.12 + 2t = 1\), so \(t = 0.44\) and \(w = (0.54, 0.46)\). Both components are positive, so the nonnegativity constraints are inactive and the multipliers on them are zero. Stationarity is \(w - r + \lambda\mathbf{1} = 0\) with \(\lambda = -0.44\), which the point satisfies, since \(w - r = (0.44, 0.44)\). By Theorem 3.1 it is the minimiser.
