Convex Sets and Convex Functions

A portfolio problem asks for the weights with the smallest variance that meet a budget and a set of limits. A central tool of this module is a structure called convexity. A convex set contains the segment between any two of its points, and a convex function never rises above the chord, the segment joining two points of its graph. This lesson defines both, proves its results apart from the spectral theorem (Assumption 1 below), takes the triangle inequality as known, and shows that a quadratic form \(x^{\top} Q x\), the form a portfolio variance takes, is convex exactly when its matrix is positive semidefinite. Lab 1 checks the identity behind that result on a finite grid.

1Convex sets

Definition 1.1 (convex set)

Let \(S\) be a subset of \(\R^n\). The set \(S\) is a convex set when, for every \(x, y \in S\) and every \(\lambda \in [0, 1]\), the point \(\lambda x + (1 - \lambda) y\) belongs to \(S\). The point \(\lambda x + (1 - \lambda) y\) is a convex combination of \(x\) and \(y\), and the set of such points for fixed \(x\) and \(y\) is the segment between them.

Example 1.2 (a disk is convex and a circle is not)

Let \(D = \{x \in \R^2 : \|x\| \le 1\}\) be the closed unit disk. For \(x, y \in D\) and \(\lambda \in [0, 1]\), the triangle inequality and \(\|\lambda x\| = \lambda \|x\|\) for \(\lambda \ge 0\) give \(\|\lambda x + (1 - \lambda) y\| \le \lambda \|x\| + (1 - \lambda)\|y\| \le \lambda + (1 - \lambda) = 1\). So \(D\) is convex.

The circle \(C = \{x : \|x\| = 1\}\) is not convex. The points \(x = (1, 0)\) and \(y = (0, 1)\) lie on \(C\), and their midpoint \((\tfrac12, \tfrac12)\) has squared norm \(\tfrac14 + \tfrac14 = \tfrac12 \ne 1\), so it is not on \(C\).

Proposition 1.3 (intersections)

Let \(\{S_i\}_{i \in I}\) be a nonempty family of convex subsets of \(\R^n\). Then \(\bigcap_{i \in I} S_i\) is convex. The hypothesis is that each \(S_i\) is convex; no assumption about the index set is needed beyond being nonempty.

Proof

Let \(x, y\) lie in the intersection and let \(\lambda \in [0, 1]\). For each \(i\), both \(x\) and \(y\) belong to \(S_i\), so \(\lambda x + (1 - \lambda) y \in S_i\) by Definition 1.1. This holds for every \(i\), so the point lies in the intersection. \(\blacksquare\)

Proposition 1.3 is the reason a set defined by several convex constraints is convex: each constraint set is convex, and the feasible set, the set of points that satisfy every constraint, is their intersection.

2Convex functions

Definition 2.1 (convex function)

Let \(S \subseteq \R^n\) be a convex set and \(f : S \to \R\). The function \(f\) is a convex function on \(S\) when, for every \(x, y \in S\) and every \(\lambda \in [0, 1]\),

\[f(\lambda x + (1 - \lambda) y) \le \lambda f(x) + (1 - \lambda) f(y).\]

The right side is the height of the chord between \((x, f(x))\) and \((y, f(y))\) above the point \(\lambda x + (1 - \lambda) y\). The definition says that the graph never rises above its chords. A function is convex or not only relative to a stated set \(S\), which is why the definition names \(S\).

Example 2.2 (the absolute value)

Let \(f(x) = |x|\) on \(\R\). For \(\lambda \in [0, 1]\), the triangle inequality gives \(|\lambda x + (1 - \lambda) y| \le \lambda |x| + (1 - \lambda)|y|\), which is the defining inequality. So \(f\) is convex on \(\R\). The function is not differentiable at \(0\), so convexity does not require smoothness.

Proposition 2.3 (sublevel sets)

Let \(S\) be a convex set, \(f : S \to \R\) a convex function on \(S\), and \(c \in \R\). Then the set \(L_c = \{x \in S : f(x) \le c\}\), the sublevel set of \(f\) at level \(c\), is convex. The hypotheses are that \(S\) is convex, \(f\) is convex on \(S\), and \(c\) is a real number.

Proof

Let \(x, y \in L_c\) and \(\lambda \in [0, 1]\). The point \(z = \lambda x + (1 - \lambda) y\) lies in \(S\) because \(S\) is convex. By Definition 2.1, \(f(z) \le \lambda f(x) + (1 - \lambda) f(y)\). Since \(f(x) \le c\) and \(f(y) \le c\) and the weights \(\lambda\) and \(1 - \lambda\) are non-negative, the right side is at most \(\lambda c + (1 - \lambda) c = c\). So \(f(z) \le c\), and \(z \in L_c\). \(\blacksquare\)

Proposition 2.3 is the set-level form of a convex inequality constraint: if \(f\) is convex on a convex set \(S\), then \(\{x \in S : f(x) \le c\}\) is convex. Lesson 3 uses the convexity of each constraint function \(g_i\) directly, in Theorem 2.1, and does not use this set-level result.

3Quadratic forms, the Hessian and the convexity test

Let \(Q\) be a real symmetric \(n \times n\) matrix, so \(Q^{\top} = Q\), and let \(q(x) = x^{\top} Q x\) for \(x \in \R^n\). The quadratic forms in this lesson and in Lesson 2 have this form, with a symmetric matrix. A matrix that is not symmetric gives the same quadratic form as its symmetric part \(\tfrac12(Q + Q^{\top})\). The reason is that \(x^{\top} Q x\) is a scalar, so it equals its transpose \(x^{\top} Q^{\top} x\), and the average of the two expressions is \(x^{\top} \tfrac12(Q + Q^{\top}) x\). Problem R1 is an instance of this argument.

Lemma 3.1 (the gap identity for a quadratic form)

Let \(Q\) be real and symmetric, and let \(q(x) = x^{\top} Q x\). For all \(x, y \in \R^n\) and every real \(\lambda\), the left side below is called the chord gap at \((x, y, \lambda)\), and it equals the right side:

\[\lambda q(x) + (1 - \lambda) q(y) - q\bigl(\lambda x + (1 - \lambda) y\bigr) = \lambda (1 - \lambda)\,(x - y)^{\top} Q (x - y).\]

Proof

Write \(z = \lambda x + (1 - \lambda) y\). Expanding the product,

\[q(z) = \lambda^2 x^{\top} Q x + (1 - \lambda)^2 y^{\top} Q y + \lambda(1 - \lambda)\bigl(x^{\top} Q y + y^{\top} Q x\bigr).\]

Symmetry of \(Q\) gives \(y^{\top} Q x = x^{\top} Q y\), so the last term is \(2\lambda(1 - \lambda) x^{\top} Q y\). Next, \(\lambda q(x) - \lambda^2 q(x) = \lambda(1 - \lambda) q(x)\) and \((1 - \lambda) q(y) - (1 - \lambda)^2 q(y) = \lambda(1 - \lambda) q(y)\). Therefore

\[\lambda q(x) + (1 - \lambda) q(y) - q(z) = \lambda (1 - \lambda)\bigl(q(x) + q(y) - 2 x^{\top} Q y\bigr).\]

Expanding \((x - y)^{\top} Q (x - y) = x^{\top} Q x - x^{\top} Q y - y^{\top} Q x + y^{\top} Q y\) and using symmetry once more gives \(q(x) + q(y) - 2 x^{\top} Q y\), which completes the proof. The identity uses no restriction on \(\lambda\). \(\blacksquare\)

Example 3.2a (the Hessian of a quadratic form)

Write \(q(x) = \sum_{i}\sum_{j} Q_{ij} x_i x_j\). Differentiating in \(x_k\) and using \(Q_{ij} = Q_{ji}\) gives \(\partial q / \partial x_k = 2 \sum_j Q_{kj} x_j = 2 (Qx)_k\), so the gradient is \(\nabla q(x) = 2Qx\). Differentiating again in \(x_l\) gives \(\partial^2 q / \partial x_l \partial x_k = 2 Q_{kl}\). The Hessian of \(q\) is therefore the constant matrix \(H = 2Q\), the same at every point.

Assumption 1 (spectral theorem, from M3)

Every real symmetric matrix \(Q\) can be written \(Q = V \Lambda V^{\top}\), where \(V\) is an orthogonal matrix and \(\Lambda = \operatorname{diag}(\mu_1, \dots, \mu_n)\) is diagonal, and \(\mu_1, \dots, \mu_n\) are the eigenvalues of \(Q\), listed with multiplicity. This is the spectral theorem for real symmetric matrices, which M3 states. It is assumed here and not proved on this page.

Proposition 3.2 (when a quadratic form is convex)

Let \(Q\) be real and symmetric, and let \(q(x) = x^{\top} Q x\) on \(\R^n\). The statements (i) and (ii) below are equivalent. Assuming Assumption 1, they are also equivalent to (iii).

(i) \(q\) is a convex function on \(\R^n\).

(ii) \(x^{\top} Q x \ge 0\) for every \(x \in \R^n\), that is, \(Q\) is positive semidefinite.

(iii) Every eigenvalue of \(Q\) is non-negative.

The hypotheses are that \(Q\) is real, symmetric and \(n \times n\), and that \(\R^n\) is the domain. The steps to and from (iii) use Assumption 1.

Proof

(i) implies (ii). Take \(y = 0\) and \(\lambda = \tfrac12\) in Lemma 3.1. Since \(q(0) = 0\), the gap \(\tfrac12 q(x) + \tfrac12 q(0) - q(\tfrac12 x)\) equals \(\tfrac12 \cdot \tfrac12 \cdot x^{\top} Q x = \tfrac14 q(x)\). The gap is the right side of Definition 2.1 minus the left side, so convexity of \(q\) makes it non-negative. Hence \(\tfrac14 q(x) \ge 0\), and \(q(x) \ge 0\).

(ii) implies (i). Take \(x, y \in \R^n\) and \(\lambda \in [0, 1]\). By Lemma 3.1, the gap \(\lambda q(x) + (1 - \lambda) q(y) - q(\lambda x + (1 - \lambda) y)\) equals \(\lambda(1 - \lambda)(x - y)^{\top} Q (x - y)\). The factor \(\lambda(1 - \lambda)\) is non-negative, and \((x - y)^{\top} Q (x - y) \ge 0\) by (ii) applied to the vector \(x - y\). So the gap is non-negative, which is the defining inequality of Definition 2.1.

(ii) implies (iii). Under Assumption 1, there is an orthogonal matrix \(V\) and a diagonal matrix \(\Lambda = \operatorname{diag}(\mu_1, \dots, \mu_n)\) with \(Q = V \Lambda V^{\top}\). For \(x \in \R^n\) put \(z = V^{\top} x\); the map \(x \mapsto z\) is a bijection of \(\R^n\) because \(V\) is invertible. Then \(x^{\top} Q x = z^{\top} \Lambda z = \sum_i \mu_i z_i^2\). Taking \(x = V e_i\), which gives \(z = e_i\), yields \(\mu_i \ge 0\) by (ii).

(iii) implies (ii). Under Assumption 1, if every \(\mu_i \ge 0\), then \(x^{\top} Q x = \sum_i \mu_i z_i^2 \ge 0\) for every \(x\), since \(z\) ranges over \(\R^n\) as \(x\) does. \(\blacksquare\)

Proposition 3.2 is the test used in Lab 1. The Hessian of \(q\) is \(H = 2Q\) by Example 3.2a. Its eigenvalues are twice those of \(Q\). Assuming Assumption 1, a quadratic form is convex exactly when the eigenvalues of its Hessian are all non-negative. The Hessian is the same at every point, so, under the same assumption, one eigenvalue test decides convexity on the whole space.

Example 3.3 (two 2 by 2 matrices)

Let \(Q_1 = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}\) and \(Q_2 = \begin{pmatrix} 1 & 2 \\ 2 & 1 \end{pmatrix}\). The vector \((1, 1)\) satisfies \(Q_1 (1, 1)^{\top} = 3 (1, 1)^{\top}\), and \((1, -1)\) satisfies \(Q_1 (1, -1)^{\top} = 1 \cdot (1, -1)^{\top}\), so the eigenvalues of \(Q_1\) are \(3\) and \(1\). For \(Q_2\), the same two vectors give \(Q_2 (1, 1)^{\top} = 3 (1, 1)^{\top}\) and \(Q_2 (1, -1)^{\top} = -1 \cdot (1, -1)^{\top}\), so its eigenvalues are \(3\) and \(-1\). Assuming Assumption 1, Proposition 3.2 and \(H = 2Q\) give that the form \(x^{\top} Q_1 x\) is convex, with Hessian eigenvalues \(6\) and \(2\). The form \(x^{\top} Q_2 x\) is not convex, with Hessian eigenvalues \(6\) and \(-2\), and Problem P3 shows this without the assumption. Lab 1 computes these eigenvalues and tests both forms on a grid.

Lab 1 · Convexity of two quadratic forms on a grid

Predicted from Lemma 3.1 and Proposition 3.2 before running. The lemma predicts that the gap identity holds in every case, so both identity lines read 3125 of 3125. Q1 has eigenvalues 3 and 1, so the chord inequality should hold in every case for Q1. Q2 has eigenvalues 3 and \(-1\), so the chord inequality should fail for Q2 in some cases. The gap for Q2 at a weight of 0 or 1 is zero. At a weight of \(\tfrac14\), \(\tfrac12\) or \(\tfrac34\) it has the sign of \((x - y)^{\top} Q_2 (x - y)\), so the number of failing Q2 cases should be three times the number of ordered pairs of grid points with \((x - y)^{\top} Q_2 (x - y) < 0\). The lab counts both numbers and does not assume the second.

"""M7 lab L01: convexity of two quadratic functions, checked exactly on a grid.

Standard library only. No randomness and no network. Every number is a fractions.Fraction or an integer,
so nothing is rounded and the output is the same on every run.

SIMULATED: the two quadratic forms Q1 and Q2 are illustrative inputs written on this page, not data.

The lab checks four things on the grid {-2, -1, 0, 1, 2} in each coordinate (25 points):
1. the identity f(l x + (1 - l) y) = l f(x) + (1 - l) f(y) - l (1 - l) (x - y)' Q (x - y), for f(x) = x' Q x,
   on every ordered pair (x, y) of grid points and every weight l in {0, 1/4, 1/2, 3/4, 1};
2. the chord inequality f(l x + (1 - l) y) <= l f(x) + (1 - l) f(y) on the same cases, for Q1 and for Q2;
3. the eigenvalues of the Hessian H = 2 Q, in closed form for each 2 x 2 symmetric matrix;
4. the explicit example x = (1, 0), y = (0, 1), l = 1/2 for Q2.

A check over a finite grid is evidence about the grid only. It does not prove convexity on the plane. The
plane-wide claim rests on the eigenvalue test, which is Proposition 3.2 of the lesson, proved on the page
under Assumption 1 (the spectral theorem, from M3).
"""

from __future__ import annotations

from fractions import Fraction
from itertools import product
from math import isqrt

GRID = (-2, -1, 0, 1, 2)
WEIGHTS = (Fraction(0), Fraction(1, 4), Fraction(1, 2), Fraction(3, 4), Fraction(1))
Q1 = ((2, 1), (1, 2))
Q2 = ((1, 2), (2, 1))
Point = tuple[int, int]
Matrix = tuple[tuple[int, int], tuple[int, int]]


def quad(q: Matrix, x: tuple[Fraction, Fraction]) -> Fraction:
    """The value x' Q x of the quadratic form with symmetric 2 x 2 matrix Q, at the point x."""
    return sum((Fraction(q[i][j]) * x[i] * x[j] for i in range(2) for j in range(2)), Fraction(0))


def combine(weight: Fraction, x: Point, y: Point) -> tuple[Fraction, Fraction]:
    """The point weight * x + (1 - weight) * y, with exact coordinates."""
    return (
        weight * x[0] + (1 - weight) * y[0],
        weight * x[1] + (1 - weight) * y[1],
    )


def identity_holds(q: Matrix, x: Point, y: Point, weight: Fraction) -> bool:
    """Exact check of f(z) = w f(x) + (1 - w) f(y) - w (1 - w) (x - y)' Q (x - y), with z = w x + (1 - w) y."""
    z = combine(weight, x, y)
    d = (Fraction(x[0] - y[0]), Fraction(x[1] - y[1]))
    lhs = quad(q, z)
    rhs = weight * quad(q, (Fraction(x[0]), Fraction(x[1]))) + (1 - weight) * quad(q, (Fraction(y[0]), Fraction(y[1])))
    rhs -= weight * (1 - weight) * quad(q, d)
    return lhs == rhs


def chord_holds(q: Matrix, x: Point, y: Point, weight: Fraction) -> bool:
    """True when f at the weighted point does not exceed the weighted chord of f at x and y."""
    z = combine(weight, x, y)
    chord = weight * quad(q, (Fraction(x[0]), Fraction(x[1]))) + (1 - weight) * quad(
        q, (Fraction(y[0]), Fraction(y[1]))
    )
    return quad(q, z) <= chord


def cases() -> list[tuple[Point, Point, Fraction]]:
    """Every ordered pair of grid points, with every weight. Pairs with x equal to y are included."""
    points = list(product(GRID, GRID))
    return [(x, y, w) for x in points for y in points for w in WEIGHTS]


def hessian_eigenvalues(q: Matrix) -> tuple[Fraction, Fraction]:
    """The two eigenvalues of H = 2 Q, larger first, from the closed form for a 2 x 2 symmetric matrix.

    For [[a, b], [b, c]] the eigenvalues are ((a + c) +/- sqrt((a - c)^2 + 4 b^2)) / 2. The square root must be an
    integer here, and the function raises ValueError if it is not.
    """
    a, b, c = 2 * q[0][0], 2 * q[0][1], 2 * q[1][1]
    disc = (a - c) ** 2 + 4 * b * b
    root = isqrt(disc)
    if root * root != disc:
        raise ValueError(f"discriminant {disc} is not a perfect square, so the eigenvalues are not integers")
    return Fraction(a + c + root, 2), Fraction(a + c - root, 2)


def is_psd_by_eigenvalues(q: Matrix) -> bool:
    """True when both eigenvalues of the Hessian 2 Q are non-negative."""
    return all(e >= 0 for e in hessian_eigenvalues(q))


def main() -> None:
    all_cases = cases()
    total = len(all_cases)
    points = len(GRID) ** 2
    print(f"grid {{-2, ..., 2}}^2: {points} points, {points * points} ordered pairs, {len(WEIGHTS)} weights,")
    print(f"{total} cases per function")

    for name, q in (("Q1", Q1), ("Q2", Q2)):
        ok = sum(identity_holds(q, x, y, w) for x, y, w in all_cases)
        print(f"{name} identity holds in {ok} of {total} cases")

    chord_q1 = sum(chord_holds(Q1, x, y, w) for x, y, w in all_cases)
    chord_q2 = sum(chord_holds(Q2, x, y, w) for x, y, w in all_cases)
    print(f"Q1 chord inequality holds in {chord_q1} of {total} cases")
    print(f"Q2 chord inequality holds in {chord_q2} of {total} cases")

    negative_pairs = sum(
        1
        for x, y in product(product(GRID, GRID), repeat=2)
        if quad(Q2, (Fraction(x[0] - y[0]), Fraction(x[1] - y[1]))) < 0
    )
    failures_q2 = total - chord_q2
    print(f"Q2 ordered pairs with (x - y)' Q2 (x - y) < 0: {negative_pairs}")
    print(f"Q2 failures equal 3 times that count: {failures_q2 == 3 * negative_pairs}")

    x, y, w = (1, 0), (0, 1), Fraction(1, 2)
    z = combine(w, x, y)
    midpoint = quad(Q2, z)
    chord = w * quad(Q2, (Fraction(1), Fraction(0))) + (1 - w) * quad(Q2, (Fraction(0), Fraction(1)))
    d = (Fraction(1), Fraction(-1))
    term = w * (1 - w) * quad(Q2, d)
    print(
        f"Q2 at x = (1, 0), y = (0, 1), weight 1/2: midpoint value {midpoint}, chord {chord}, "
        f"chord minus midpoint {chord - midpoint}"
    )
    print(f"identity term (1/4) (x - y)' Q2 (x - y) = {term}")

    for name, q in (("Q1", Q1), ("Q2", Q2)):
        high, low = hessian_eigenvalues(q)
        print(f"Hessian eigenvalues of {name} (H = 2 Q): {high} and {low}")
    print(f"Q1 eigenvalue test (both eigenvalues >= 0): {is_psd_by_eigenvalues(Q1)}")
    print(f"Q2 eigenvalue test (both eigenvalues >= 0): {is_psd_by_eigenvalues(Q2)}")

Each line that reads "holds in N of M cases" is an exact count over the 25 points of the grid \(\{-2, \dots, 2\}^2\), with the 5 weights, so 3125 cases per function. The identity lines check Lemma 3.1 on those cases. They are instances of Lemma 3.1, which is proved on the page for all \(x\), \(y\) and \(\lambda\). The chord lines show that the grid check agrees with Proposition 3.2 on this grid: Q1 passes every case, and Q2 fails 552 of them, which is \(3125 - 2573\). The count of 184 negative pairs is a count of ordered pairs of grid points, and the line that equals 3 times 184 uses the fact that the weights 0 and 1 give zero gap. None of these lines establishes convexity on the whole plane. That claim is Proposition 3.2 under Assumption 1, not the grid. The Q2 example line prints a midpoint value of 3/2 against a chord of 1, so the chord minus the midpoint value is \(-\tfrac12\), which equals the identity term \(\tfrac14 (x - y)^{\top} Q_2 (x - y) = -\tfrac12\). The eigenvalue lines apply the eigenvalue test of Proposition 3.2, under Assumption 1, to \(H = 2Q\), and they agree with Example 3.3.

4Where the canon breaks

The definitions above are the ones this module uses, and the results are proved on the page or are computations shown on it. Four points need care when they are used.

  • Convexity is relative to a set. Definition 2.1 names the set \(S\) on which the chord inequality must hold. A function that satisfies the inequality on one set is not thereby convex on a larger set, because the definition requires the points \(x\) and \(y\) to lie in the set where the function is defined.
  • Convexity of the feasible set and of the objective are separate conditions. Proposition 1.3 and Proposition 2.3 treat them separately. A problem can have a convex objective and a non-convex feasible set, as Example 1.2 shows for the circle, and the results of this lesson say nothing about that combination.
  • Convex is not the same as strictly convex. A constant function on \(\R\) satisfies Definition 2.1, with equality in every case, so it is convex. Its minimizer is then every point of \(\R\). Uniqueness of a minimizer needs a further property, which this lesson does not state.
  • A grid is a finite check. Lab 1 checks 3125 cases. That count refutes Q2, and it is consistent with Q1, but it is evidence about the grid and no more. Proposition 3.2, under Assumption 1, is the argument that covers all of \(\R^2\).

5Misconceptions

  1. “A set whose boundary is curved cannot be convex, and a set whose points all lie on a curve is convex.”

    Both halves are wrong in a way that Example 1.2 settles. The closed disk has a curved boundary and is convex, because it contains every segment between its points. The circle is a curve, and it is not convex, because the midpoint of two of its points lies strictly inside it. The test is whether the segment between two points stays in the set, not whether the set is curved.

  2. “A quadratic form is convex when its diagonal entries are positive.”

    The matrix \(Q_2\) of Example 3.3 has positive diagonal entries \(1\) and \(1\), and \(x^{\top} Q_2 x\) is not convex. Its eigenvalues are \(3\) and \(-1\), and the eigenvalue \(-1\) is the reason. A negative eigenvalue refutes convexity whatever the diagonal, as Problem P3 shows, and the eigenvalue \(-1\) of \(Q_2\) is such a case. Lab 1 prints the eigenvalue \(-2\) of the Hessian \(2Q_2\), and at the midpoint of \((1, 0)\) and \((0, 1)\) it prints the value \(3/2\) of \(x^{\top} Q_2 x\) above the chord value \(1\), for the same matrix.

  3. “If the chord inequality holds for many pairs of points, the function is convex.”

    A convex function satisfies the chord inequality for every pair of points and every weight, so many passing cases prove nothing. For Q2, Lab 1 prints 2573 passing cases out of 3125, so 552 cases fail. A single failing case refutes convexity, which is what the example at \(x = (1, 0)\) and \(y = (0, 1)\) does.

Mechanics

M1 · The half-space of a budget inequality

Show that the set \(\{w \in \R^3 : \mathbf{1}^{\top} w \le 1\}\) is convex, where \(\mathbf{1} = (1, 1, 1)^{\top}\).

Solution

Let \(x, y\) satisfy \(\mathbf{1}^{\top} x \le 1\) and \(\mathbf{1}^{\top} y \le 1\), and let \(\lambda \in [0, 1]\). Then \(\mathbf{1}^{\top}(\lambda x + (1 - \lambda) y) = \lambda \mathbf{1}^{\top} x + (1 - \lambda) \mathbf{1}^{\top} y \le \lambda + (1 - \lambda) = 1\). The inequality uses \(\lambda \ge 0\) and \(1 - \lambda \ge 0\). So the combination lies in the set, and the set is convex by Definition 1.1.

M2 · The chord of the square

For \(f(x) = x^2\) on \(\R\), take \(x = 1\), \(y = -1\) and \(\lambda = \tfrac12\). Compute the two sides of Definition 2.1 and their difference.

Solution

The midpoint is \(0\), so \(f(0) = 0\). The chord value is \(\tfrac12 f(1) + \tfrac12 f(-1) = \tfrac12 + \tfrac12 = 1\). The difference is \(1 - 0 = 1\). Lemma 3.1 with \(Q = (1)\) gives \(\lambda(1 - \lambda)(x - y)^2 = \tfrac14 \cdot 4 = 1\), which agrees with the direct computation.

M3 · The gap for a 2 by 2 form

Let \(Q_1\) be the matrix of Example 3.3. Compute \(q(x)\) at \(x = (1, 1)\) and at \(y = (-1, -1)\), and compute the gap of Lemma 3.1 at \(\lambda = \tfrac12\).

Solution

For \(x = (1, 1)\), \(q(x) = 2 \cdot 1 + 2 \cdot 1 \cdot 1 + 2 \cdot 1 = 6\), using \(x^{\top} Q_1 x = Q_{11} x_1^2 + 2 Q_{12} x_1 x_2 + Q_{22} x_2^2\). Since \(q\) is even, \(q(y) = 6\). The midpoint is \(0\), so the gap is \(\tfrac12 \cdot 6 + \tfrac12 \cdot 6 - 0 = 6\). Lemma 3.1 gives \(\tfrac14 (x - y)^{\top} Q_1 (x - y)\) with \(x - y = (2, 2)\), and \((2, 2)^{\top} Q_1 (2, 2) = 24\), so the gap is \(\tfrac14 \cdot 24 = 6\), as the direct computation gives.

Proof

P1 · A set above a level need not be convex (a contrast with Proposition 2.3)

Let \(f(x) = x^2\), which is convex on \(S = \R\) by Proposition 3.2, (ii) implies (i), with \(Q = (1)\), since \(x^2 = x \cdot 1 \cdot x \ge 0\) for every \(x\). Show that the set \(\{x \in \R : f(x) \ge 1\}\) of points where \(f\) is at least 1 is not convex.

Solution

Take \(c = 1\). The points \(x = 2\) and \(y = -2\) satisfy \(f \ge 1\), and their midpoint \(0\) has \(f(0) = 0 < 1\). So the midpoint is not in the set \(\{x : x^2 \ge 1\}\), which is therefore not convex. This does not contradict Proposition 2.3, which concerns the sublevel set \(\{f \le c\}\), not the superlevel set \(\{f \ge c\}\).

P2 · Intersections (Proposition 1.3 applied to two constraints)

Let \(S_1 = \{w \in \R^2 : w_1 \ge 0\}\) and \(S_2 = \{w \in \R^2 : w_1 + w_2 \le 1\}\). Show that \(S_1 \cap S_2\) is convex, citing Proposition 1.3 for the step that needs it.

Solution

Each set is a half-plane, and a half-plane is convex by the argument of Problem M1. Proposition 1.3 then says that the intersection of the two convex sets is convex. Explicitly, if \(x\) and \(y\) satisfy both constraints, then \(\lambda x_1 + (1 - \lambda) y_1 \ge 0\) and \(\lambda (x_1 + x_2) + (1 - \lambda)(y_1 + y_2) \le 1\), so the combination satisfies both constraints.

P3 · A negative eigenvalue refutes convexity

Let \(Q\) be real and symmetric, and suppose \(Q v = \mu v\) with \(v \ne 0\) and \(\mu < 0\). Show that \(q(x) = x^{\top} Q x\) is not convex on \(\R^n\).

Solution

We have \(q(v) = v^{\top} Q v = \mu\, v^{\top} v = \mu \|v\|^2 < 0\). Take \(x = v\) and \(y = 0\) in Lemma 3.1 with \(\lambda = \tfrac12\). Since \(q(0) = 0\), the gap \(\tfrac12 q(v) + \tfrac12 q(0) - q(\tfrac12 v)\) equals \(\tfrac12 q(v) - \tfrac14 q(v) = \tfrac14 q(v) < 0\). A negative gap violates Definition 2.1, so \(q\) is not convex. This is the contrapositive of (i) implies (ii) in Proposition 3.2.

Empirical

E1 · Why the failing count is a multiple of 3 (Lab 1)

Lab 1 prints 2573 passing Q2 cases of 3125, so 552 cases fail. It also counts 184 ordered pairs with \((x - y)^{\top} Q_2 (x - y) < 0\), and the line "Q2 failures equal 3 times that count" prints True. Explain why the failures come in groups of three for each negative pair, and check the arithmetic.

Solution

For a fixed ordered pair \((x, y)\), the gap of Lemma 3.1 is \(\lambda(1 - \lambda)(x - y)^{\top} Q_2 (x - y)\). At weights \(0\) and \(1\) the factor \(\lambda(1 - \lambda)\) is zero, so the gap is zero and the chord holds. At weights \(\tfrac14\), \(\tfrac12\) and \(\tfrac34\) the factor is positive, so the gap is negative exactly when \((x - y)^{\top} Q_2 (x - y) < 0\). That gives three failing weights for each negative pair. Since \(3 \times 184 = 552\) and \(3125 - 2573 = 552\), the printed numbers agree.

E2 · What the grid check for Q1 does and does not show (Lab 1)

Lab 1 prints that the chord inequality holds in 3125 of 3125 cases for Q1. State what this establishes about Q1 and what it does not.

Solution

It establishes that the chord inequality holds for every pair of points of the 25-point grid and every listed weight, because the count is exact. It does not establish convexity on the plane, since the plane has points off the grid and weights off the list. The claim for the whole plane follows from Proposition 3.2 (iii), under Assumption 1, and the eigenvalues 3 and 1 of \(Q_1\), not from the count. The count is consistent with that proposition and is not the proof of it.

E3 · Reading the eigenvalues (Lab 1)

Lab 1 prints the Hessian eigenvalues of Q1 as 6 and 2. Recover the eigenvalues of Q1 itself, and state which statement of Proposition 3.2 this output checks.

Solution

The Hessian is \(H = 2Q_1\), so the eigenvalues of \(Q_1\) are half the printed values, namely \(3\) and \(1\). This agrees with Example 3.3. Both are non-negative, so statement (iii) of Proposition 3.2 holds, and under Assumption 1 the proposition gives statement (i), that the form is convex. The lab checks the eigenvalues and the grid, and Proposition 3.2 under Assumption 1 supplies the implication from eigenvalues to convexity.

Research

R1 · Why the matrix is taken to be symmetric

Let \(Q = \begin{pmatrix} 1 & 1 \\ -1 & 1 \end{pmatrix}\), which is not symmetric. Show that \(x^{\top} Q x = x_1^2 + x_2^2\) for every \(x\), and identify the symmetric matrix that Lemma 3.1 must use in its place.

Solution

Expanding, \(x^{\top} Q x = x_1 (x_1 + x_2) + x_2 (-x_1 + x_2) = x_1^2 + x_1 x_2 - x_1 x_2 + x_2^2 = x_1^2 + x_2^2\), so the cross terms cancel. This is an instance of the general argument on the page: \(x^{\top} Q x\) is a scalar, so it equals \(x^{\top} Q^{\top} x\), and averaging gives \(x^{\top} \tfrac12 (Q + Q^{\top}) x\). Here the symmetric part is \(\tfrac12 (Q + Q^{\top}) = I\), the identity, and \(x^{\top} I x = \|x\|^2\) gives the same form. Lemma 3.1 is stated for symmetric matrices because the expansion uses \(y^{\top} Q x = x^{\top} Q y\). For a non-symmetric \(Q\) the same argument works with the symmetric part in place of \(Q\), and the Hessian of the form is then \(Q + Q^{\top}\), not \(2Q\).

R2 · Can a finite grid ever prove convexity on the plane?

Without a theorem, can any finite set of grid points and weights establish that a function is convex on \(\R^2\)? Explain using Definition 2.1 and the discussion of Lab 1.

Solution

No finite check establishes convexity on \(\R^2\) by itself. Definition 2.1 quantifies over every pair of points of the domain and every weight in \([0, 1]\), and a finite grid tests only finitely many of them. A finite check can refute convexity, since one failing triple is enough. To establish convexity, the argument must cover every pair and weight, which for a quadratic form Proposition 3.2 does through the eigenvalues, under Assumption 1. Lab 1 is therefore a refutation test for Q2 and a consistency test for Q1, and Proposition 3.2 under Assumption 1 is what settles Q1.

R3 · When are both eigenvalues of a 2 by 2 symmetric matrix non-negative?

Let \(Q = \begin{pmatrix} a & b \\ b & c \end{pmatrix}\) be real and symmetric. Show that both eigenvalues are non-negative if and only if \(a + c \ge 0\) and \(ac - b^2 \ge 0\), and that \(a \ge 0\) and \(c \ge 0\) follow from the same condition.

Solution

The eigenvalues \(\mu_1\) and \(\mu_2\) of \(Q\) are real, because the discriminant \((a - c)^2 + 4b^2\) is non-negative, and they satisfy \(\mu_1 + \mu_2 = a + c\) and \(\mu_1 \mu_2 = ac - b^2\). If both are non-negative, both sums are non-negative. Conversely, if \(\mu_1 \mu_2 \ge 0\) the two eigenvalues have the same sign or one is zero, and if also \(\mu_1 + \mu_2 \ge 0\) they cannot both be negative, so both are non-negative. Finally, the two conditions give \(a \ge 0\) and \(c \ge 0\): since \(ac \ge b^2 \ge 0\), the numbers \(a\) and \(c\) have the same sign or one is zero, and \(a + c \ge 0\) rules out two negative values. For Q1 of Example 3.3 the conditions read \(4 \ge 0\) and \(4 - 1 = 3 \ge 0\).
