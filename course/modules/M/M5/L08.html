The Discounted Bellman Operator Is a Contraction

  • Uses: completeness of the real numbers, metric space, contraction mapping, Banach fixed-point theorem, discount factor
  • Introduces: contraction property of the discounted Bellman operator
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study
  • Dlore
  • Xrefuted

A planner who chooses how much to save today must compare the utility now with the discounted value of the next state. Writing that comparison as an operator on value functions (defined in Section 1) turns the planning problem into a fixed-point problem. This lesson defines the operator for a small savings model on a finite grid, and it proves that the operator is a contraction in the sup norm (Section 1) with modulus equal to the discount factor. Lesson 7 then gives the fixed point, its uniqueness, and the convergence of the iterates. The contraction proof uses three facts: each feasible set is finite and nonempty, it does not depend on the function, and the discount factor is nonnegative.

1A savings model on a finite grid

Fix a finite set of states \(G = (g_1, \ldots, g_K)\) with \(0 < g_1 < \cdots < g_K\), called the grid. A value function on \(G\) is a real function \(V\) on \(G\) that gives the discounted utility of the best plan from each state. A policy chooses, for each state, one next state. The model has four parts:

  • Output from capital \(k\) is \(k^{\alpha}\), where \(\alpha \in (0, 1)\).
  • The feasible next states from \(k\) are \(F(k) = \{k' \in G : k' \le k^{\alpha}\}\). Choosing \(k'\) leaves consumption \(c = k^{\alpha} - k'\), which is nonnegative on \(F(k)\).
  • Utility of consumption is \(u(c) = \sqrt{c}\) for \(c \ge 0\).
  • The discount factor \(\beta\) lies in \((0, 1)\). The discount factor is the Module M1 concept discount factor, and it weights next-period value.

The grid space \(\mathbb{R}^{G}\) is the set of real functions on \(G\). With \(K\) states it is the same as \(\mathbb{R}^{K}\). Its sup norm is \(\lVert V \rVert_\infty = \max_{k \in G} |V(k)|\). The distance between \(V\) and \(W\) is \(\lVert V - W \rVert_\infty\).

Definition 1.1 (the discounted Bellman operator)

For a value function \(V\) on \(G\), the discounted Bellman operator \(\mathcal{B}\) is \[ (\mathcal{B}V)(k) = \max_{k' \in F(k)} \Big\{ \sqrt{k^{\alpha} - k'} + \beta\, V(k') \Big\}, \qquad k \in G. \] The maximum is over a finite set, so it is attained. The operator is defined by this formula. It uses only the grid, the feasible sets and \(\beta\).

Example 1.2 (one step on a two-point grid)

Let \(G = (0.25, 1.0)\), \(\alpha = 1/2\), and \(V = 0\). At \(k = 0.25\), the output is \(0.5\), so \(F(0.25) = \{0.25\}\) and \((\mathcal{B}V)(0.25) = \sqrt{0.5 - 0.25} = 0.5\). At \(k = 1.0\), the output is \(1\), so \(F(1.0) = \{0.25, 1.0\}\). The two candidates are \(\sqrt{0.75} = 0.866025\) and \(\sqrt{0} = 0\), so \((\mathcal{B}V)(1.0) = 0.866025\).

Proposition 1.3 (the grid space is complete)

Hypotheses: (1) \(G\) is a finite set of \(K \ge 1\) points; (2) the distance on \(\mathbb{R}^{G}\) is \(d(V, W) = \lVert V - W \rVert_\infty\). Conclusion: \((\mathbb{R}^{G}, d)\) is a complete metric space.

Proof

The sup norm is a metric, because \(\lVert V - W \rVert_\infty\) is a maximum of finitely many nonnegative numbers, is zero only when \(V = W\), and satisfies the triangle inequality. Let \((V_n)\) be Cauchy. For each \(k \in G\), \(|V_n(k) - V_m(k)| \le \lVert V_n - V_m \rVert_\infty\), so \((V_n(k))_n\) is a Cauchy sequence of reals. By completeness of \(\mathbb{R}\) (Lesson 1) it converges to some \(V(k)\). Let \(V\) be the function so defined. Since \(G\) has finitely many points, the maximum of the finitely many errors \(|V_n(k) - V(k)|\) tends to zero, so \(\lVert V_n - V \rVert_\infty \to 0\).

Remark on well-definedness

If \(F(k)\) is nonempty for every \(k \in G\), then each maximum in Definition 1.1 is a maximum of a finite nonempty set of real numbers. So \(\mathcal{B}\) maps \(\mathbb{R}^{G}\) into \(\mathbb{R}^{G}\). The lesson's hypotheses include this nonemptiness. Problem R3 shows that it holds for every grid contained in \((0, 1]\), and gives a grid where it fails.

2The contraction property and the fixed point

Definition 2.1 (contraction property of the operator)

Let \(0 < \beta < 1\). The operator \(\mathcal{B}\) has the contraction property of the discounted Bellman operator with modulus \(\beta\) when \[ \lVert \mathcal{B}V - \mathcal{B}W \rVert_\infty \le \beta\, \lVert V - W \rVert_\infty \qquad \text{for all } V, W \in \mathbb{R}^{G}. \]

Theorem 2.2 (the operator is a contraction)

Hypotheses:

  1. \(G = (g_1, \ldots, g_K)\) is a finite grid of positive numbers, and \(F(k)\) is nonempty for every \(k \in G\).
  2. \(\alpha \in (0, 1)\), so that \(k^{\alpha}\) is the output.
  3. \(u(c) = \sqrt{c}\) is the utility for \(c \ge 0\), and \(c = k^{\alpha} - k' \ge 0\) on \(F(k)\).
  4. \(0 < \beta < 1\) is the discount factor.

Conclusion:

  1. \(\mathcal{B}\) has the contraction property of Definition 2.1 with modulus \(\beta\).
  2. \(\mathcal{B}\) has exactly one fixed point \(V^\ast\) in \(\mathbb{R}^{G}\), that is, exactly one function with \(\mathcal{B}V^\ast = V^\ast\). Hence \(V^\ast(k) = \max_{k' \in F(k)}\{\sqrt{k^{\alpha} - k'} + \beta V^\ast(k')\}\) for each \(k \in G\).
  3. For every starting function \(V_0\), the iterates \(V_{n+1} = \mathcal{B}V_n\) satisfy \(\lVert V_n - V^\ast \rVert_\infty \le \beta^{n}\, \lVert V_1 - V_0 \rVert_\infty / (1 - \beta)\), and they converge to \(V^\ast\).
Proof of (a)

Let \(V, W \in \mathbb{R}^{G}\) and fix \(k \in G\). The set \(F(k)\) is finite and nonempty, and it does not depend on \(V\) or \(W\). Choose \(a\) in \(F(k)\) that maximises \(\sqrt{k^{\alpha} - a'} + \beta V(a')\) over \(a' \in F(k)\), and choose \(b\) in \(F(k)\) that maximises the same expression with \(W\) in place of \(V\). Then \[ (\mathcal{B}V)(k) - (\mathcal{B}W)(k) = \big[\sqrt{k^{\alpha} - a} + \beta V(a)\big] - \big[\sqrt{k^{\alpha} - b} + \beta W(b)\big]. \] Since \(b\) maximises the \(W\)-expression, the second bracket is at least \(\sqrt{k^{\alpha} - a} + \beta W(a)\). Therefore \[ (\mathcal{B}V)(k) - (\mathcal{B}W)(k) \le \beta\,\big(V(a) - W(a)\big) \le \beta\, \lVert V - W \rVert_\infty. \] Exchanging \(V\) and \(W\) gives \((\mathcal{B}W)(k) - (\mathcal{B}V)(k) \le \beta\, \lVert V - W \rVert_\infty\). The two inequalities give \(|(\mathcal{B}V)(k) - (\mathcal{B}W)(k)| \le \beta\,\lVert V - W \rVert_\infty\). Since \(k\) was arbitrary, the maximum over \(k\) gives (a). The step uses \(\beta \ge 0\) to multiply the inequality \(V(a) - W(a) \le \lVert V - W \rVert_\infty\).

Proof of (b) and (c)

By Proposition 1.3, \((\mathbb{R}^{G}, \lVert \cdot \rVert_\infty)\) is a complete metric space. It is nonempty. By part (a), \(\mathcal{B}\) is a contraction mapping with modulus \(\beta \in (0, 1)\). Theorem 2.1 of Lesson 7 applies with \(X = \mathbb{R}^{G}\) and the map \(\mathcal{B}\), and it gives the unique fixed point \(V^\ast\), the convergence of the iterates from any \(V_0\), and the bound with \(d(V_0, V_1) = \lVert V_0 - V_1 \rVert_\infty\).

Example 2.3 (one state)

Let \(G = (1/4)\), one point, with \(\alpha = 1/2\). Then \(k^{\alpha} = 1/2\), \(F(1/4) = \{1/4\}\), and the consumption is \(c = 1/4\), so \(u = \sqrt{1/4} = 1/2\). The operator is \((\mathcal{B}V) = 1/2 + \beta V\), a map of \(\mathbb{R}\). Its fixed point solves \(V = 1/2 + \beta V\), so \(V^\ast = (1/2)/(1 - \beta)\). At \(\beta = 0.9\), \(V^\ast = 5\). Here \(|\mathcal{B}V - \mathcal{B}W| = \beta\,|V - W|\) exactly, so the modulus \(\beta\) of Theorem 2.2(a) is attained.

Lab 1 · The fixed point of the discounted Bellman operator on a four-state grid

Stated before running: on the grid \((0.25, 0.5, 0.75, 1.0)\) with \(\alpha = 1/2\) and \(\beta = 0.9\), iterating \(\mathcal{B}\) from \(V_0 = 0\) reaches a fixed point, where the residual \(\lVert \mathcal{B}V^\ast - V^\ast \rVert_\infty\) is at most \(10^{-9}\). For seeded random pairs \((V, W)\), the ratio \(\lVert \mathcal{B}V - \mathcal{B}W \rVert_\infty / \lVert V - W \rVert_\infty\) does not exceed \(\beta\) by more than \(10^{-12}\). On the one-point grid of Example 2.3, the fixed point is \(5\) at \(\beta = 0.9\), and at \(\beta = 1\) the iterates equal \(n/2\) after \(n\) steps, so they have no finite limit. The stopping gap and the ratio and iterate checks use \(10^{-12}\), and the residual and one-point fixed-point checks use \(10^{-9}\).

"""M5 L08 lab 1: fixed point of the discounted Bellman operator on a finite grid.

Generated model parameters; not data. The state k is capital on the grid GRID. Output is k ** ALPHA. The planner
chooses next-period capital k' in GRID with k' <= k ** ALPHA, so consumption c = k ** ALPHA - k' is nonnegative,
and utility is u(c) = sqrt(c). The operator is (B V)(k) = max over feasible k' of [u(c) + BETA * V(k')], with ties
broken by the smallest feasible index. Part A iterates B from V_0 = 0 to a fixed point and prints the residual of
the fixed point. Part B draws seeded pairs (V, W) with the standard random module and checks that the sup-norm
ratio ||BV - BW|| / ||V - W|| does not exceed BETA by more than TOL. Part C applies B to a one-point grid, where
the fixed point is u / (1 - BETA) = 5 at BETA = 0.9, and then iterates it at BETA = 1, where the iterates grow
without bound.
Standard library only; no network access. TOL = 1e-12 bounds the stopping gap, the ratio check of Part B and the
iterate checks of Part C. The residual check of Part A and the one-point fixed-point check of Part C use 1e-9.
"""

from __future__ import annotations

import math
import random

ALPHA = 0.5
BETA = 0.9
GRID: tuple[float, ...] = (0.25, 0.5, 0.75, 1.0)
SEED = 20261028
PAIRS = 2000
TOL = 1e-12


def bellman(values: list[float], grid: tuple[float, ...], beta: float) -> tuple[list[float], list[int]]:
    """Apply the operator to values on grid. Return the new values and, for each state, the chosen index."""
    if len(values) != len(grid):
        raise ValueError("values and grid must have equal length")
    new_values: list[float] = []
    policy: list[int] = []
    for k in grid:
        output = k**ALPHA
        feasible = [j for j, kp in enumerate(grid) if kp <= output]
        if not feasible:
            raise AssertionError(f"no feasible successor for state {k}")
        best_value = -math.inf
        best_index = -1
        for j in feasible:
            consumption = output - grid[j]
            candidate = math.sqrt(consumption) + beta * values[j]
            if candidate > best_value:
                best_value, best_index = candidate, j
        new_values.append(best_value)
        policy.append(best_index)
    return new_values, policy


def solve(grid: tuple[float, ...], beta: float) -> tuple[list[float], list[int], int]:
    """Iterate the operator from zero until successive values differ by at most TOL. Return values, policy, count."""
    values = [0.0] * len(grid)
    count = 0
    while True:
        new_values, policy = bellman(values, grid, beta)
        count += 1
        gap = max(abs(a - b) for a, b in zip(new_values, values, strict=True))
        values = new_values
        if gap <= TOL:
            return values, policy, count
        if count > 10000:
            raise AssertionError("no convergence within 10000 iterations")


def part_a() -> None:
    """Solve on GRID and check the residual of the fixed point."""
    values, policy, count = solve(GRID, BETA)
    image, _ = bellman(values, GRID, BETA)
    residual = max(abs(a - b) for a, b in zip(image, values, strict=True))
    if residual > 1e-9:
        raise AssertionError("the computed values are not a fixed point")
    print(f"part A: beta = {BETA}, alpha = {ALPHA}, grid = {GRID}")
    print(f"part A: iterations until the successive gap is at most {TOL:g} = {count}")
    for k, v, j in zip(GRID, values, policy, strict=True):
        print(f"part A: state k = {k:.2f}  V*(k) = {v:.6f}  chosen next capital = {GRID[j]:.2f}")
    print(f"part A: residual max |BV* - V*| = {residual:.3e} (at most 1e-9)")


def part_b() -> None:
    """Check the sup-norm contraction ratio on seeded random pairs."""
    rng = random.Random(SEED)
    worst = 0.0
    for _ in range(PAIRS):
        v = [rng.uniform(-10.0, 10.0) for _ in GRID]
        w = [rng.uniform(-10.0, 10.0) for _ in GRID]
        bv, _ = bellman(v, GRID, BETA)
        bw, _ = bellman(w, GRID, BETA)
        num = max(abs(a - b) for a, b in zip(bv, bw, strict=True))
        den = max(abs(a - b) for a, b in zip(v, w, strict=True))
        worst = max(worst, num / den)
    if worst > BETA + TOL:
        raise AssertionError("a sampled contraction ratio exceeds beta")
    print(f"part B: seed = {SEED}, pairs = {PAIRS}, largest sampled ratio = {worst:.6f}, beta = {BETA}")
    print("part B: no sampled pair has ratio above beta by more than 1e-12")


def part_c() -> None:
    """Check the one-point grid: fixed point 5 at beta = 0.9, and unbounded iterates at beta = 1."""
    one = (0.25,)
    values, _, count = solve(one, 0.9)
    print(f"part C: one-point grid, beta = 0.9: V* = {values[0]:.6f} after {count} iterations")
    if abs(values[0] - 5.0) > 1e-9:
        raise AssertionError("one-point fixed point differs from u / (1 - beta) = 5")
    v = [0.0]
    for n in range(1, 1001):
        v, _ = bellman(v, one, 1.0)
        if abs(v[0] - 0.5 * n) > TOL:
            raise AssertionError("iterates at beta = 1 are not n times u")
    print(f"part C: one-point grid, beta = 1: after 1000 iterations V = {v[0]:.6f}, which is 0.5 times 1000")
    print("part C: at beta = 1 the iterates grow linearly, so no finite fixed point is reached")


def main() -> None:
    part_a()
    part_b()
    part_c()


main()

Part A confirms that the iteration from zero reaches a fixed point. The residual is the sup-norm distance \(\lVert \mathcal{B}V^\ast - V^\ast \rVert_\infty\), and the printed value is \(8.695 \times 10^{-13}\). The printed values are the fixed point, and the printed chosen capital is the policy. At \(\beta = 0.9\) the policy chooses the smallest grid point in every state, so this grid shows the operator at work and not a pattern of saving. Part B prints the largest sampled ratio, which agrees with \(\beta = 0.9\) to six decimal places. The lab checks that no sampled ratio exceeds \(\beta\) by more than \(10^{-12}\). Recomputed outside the lab with the same seed and draw order, the unrounded largest ratio is \(0.9 + 5.6 \times 10^{-16}\), about five units in the last place above \(\beta\), so "never exceeds" would be false at float level. The lab does not print this value. The sampled check does not prove the contraction, which Theorem 2.2(a) proves; it tests the inequality on 2000 pairs. Part C checks Example 2.3 and the \(\beta = 1\) case, where the lab prints the value \(500\) after \(1000\) iterations and does not converge.

3Where the canon breaks

  • The discount factor must be strictly below one. Take the one-point grid of Example 2.3 with \(\beta = 1\). Then \(\mathcal{B}V = 1/2 + V\), so the iterates from \(V_0 = 0\) are \(V_n = n/2\). They are unbounded, so there is no fixed point in \(\mathbb{R}\). The proof of Theorem 2.1 uses \(\beta^{n} \to 0\) in Step 1, which fails at \(\beta = 1\). The same pattern appears on the four-state grid: if \(k \in F(k)\) and \(u(k^{\alpha} - k) > 0\), then at \(\beta = 1\) the value at \(k\) grows by at least \(u(k^{\alpha} - k)\) per step, by the argument of Problem R2.
  • Every feasible set must be nonempty. Take \(G = (2, 3)\) and \(\alpha = 1/2\). At \(k = 2\), the output is \(\sqrt{2} \approx 1.414\), which is below both grid points, so \(F(2) = \varnothing\). The maximum in Definition 1.1 is then over an empty set, and \(\mathcal{B}\) is undefined. Hypothesis (1) of Theorem 2.2 fails. Problem R3 shows that the condition holds for every grid contained in \((0, 1]\).
  • The proof uses finiteness. The maxima exist because each \(F(k)\) is finite. For a continuum of feasible next states, a maximum may fail to exist. This page does not treat that case, and it makes no claim about the continuity of the operator or of its fixed point.
  • The grid fixed point is not the continuous model's value. Theorem 2.2 is a theorem about \(\mathcal{B}\) on \(\mathbb{R}^{G}\), a space with four coordinates in Lab 1. Its fixed point is an object of the grid model. Lesson 9 states its error bound with respect to this grid fixed point, and it names the discretisation error as a limitation that the bound does not cover.

4Misconceptions

  1. “The maximum over feasible choices can break the contraction property, because a maximum is not linear.”

    The proof in Theorem 2.2(a) compares each maximiser with the other operator's value at the same point, and it needs no linearity. The proof uses three facts: each feasible set \(F(k)\) is finite and nonempty, \(F(k)\) is the same set for \(V\) and \(W\), and \(\beta \ge 0\). That is why the feasible set must not depend on the value function.

  2. “A larger discount factor gives a stronger contraction.”

    The modulus is \(\beta\). A larger \(\beta\) gives a weaker contraction, because the bound \(\beta\,\lVert V - W \rVert_\infty\) is larger. The iteration count shows the same direction. In a copy of the lab code with the constant BETA set to \(0.5\), the solver prints 40 iterations. With BETA set to \(0.9\), as printed, it prints 257. With BETA set to \(0.95\), it prints 527.

  3. “The fixed point on the grid is the value of the continuous savings problem.”

    The fixed point is an object of the grid model. Lab 1 computes it on four states, and its values are numbers such as \(V^\ast(0.25) = 5.000000\). A finer or continuous state space has a different operator. Lesson 9 names the difference as discretisation error, and it bounds only the distance to the grid fixed point.

Mechanics

M1 · One step on a two-point grid

Let \(G = (0.25, 1.0)\), \(\alpha = 1/2\), \(\beta = 0.9\), and \(V = 0\). Compute \(\mathcal{B}V\) at each grid point.

Solution

At \(k = 0.25\), the output is \(0.5\), and \(F(0.25) = \{0.25\}\) because \(1.0 > 0.5\). The consumption is \(0.25\), so \((\mathcal{B}V)(0.25) = \sqrt{0.25} = 0.5\). At \(k = 1.0\), the output is \(1\), and \(F(1.0) = \{0.25, 1.0\}\). The candidates are \(\sqrt{0.75} = 0.866025\) for \(k' = 0.25\) and \(\sqrt{0} = 0\) for \(k' = 1.0\). Since \(V = 0\), the discounted terms vanish, and the maximum is \(0.866025\).

M2 · The fixed point on one state

On the one-point grid of Example 2.3, with utility \(u = 1/2\) and \(\beta = 0.95\), find the fixed point \(V^\ast\).

Solution

The fixed point solves \(V = u + \beta V\), so \(V(1 - \beta) = u\) and \(V^\ast = u/(1 - \beta) = 0.5/0.05 = 10\). Since the operator is \(V \mapsto 1/2 + 0.95\,V\), substituting \(V = 10\) gives \(0.5 + 9.5 = 10\), which confirms it.

M3 · Feasible sets on the four-point grid

Let \(G = (0.25, 0.5, 0.75, 1.0)\) and \(\alpha = 1/2\). List \(F(k)\) for each \(k \in G\).

Solution

The output is \(k^{1/2}\). For \(k = 0.25\), the output is \(0.5\), so \(F = \{0.25, 0.5\}\). For \(k = 0.5\), the output is \(0.707107\), so \(F = \{0.25, 0.5\}\), since \(0.75 > 0.707107\). For \(k = 0.75\), the output is \(0.866025\), so \(F = \{0.25, 0.5, 0.75\}\). For \(k = 1.0\), the output is \(1\), so \(F = G\). Every set is nonempty, so Theorem 2.2's hypothesis (1) holds.

Proof

P1 · Monotonicity of the operator

Let \(V \le W\) pointwise on \(G\). Prove that \(\mathcal{B}V \le \mathcal{B}W\) pointwise.

Solution

Fix \(k\). Let \(a \in F(k)\) maximise \(\sqrt{k^{\alpha} - a'} + \beta V(a')\) over \(F(k)\), and let \(b \in F(k)\) maximise \(\sqrt{k^{\alpha} - b'} + \beta W(b')\). Then \((\mathcal{B}V)(k) = \sqrt{k^{\alpha} - a} + \beta V(a)\). Since \(V(a) \le W(a)\) and \(\beta \ge 0\), this is at most \(\sqrt{k^{\alpha} - a} + \beta W(a)\). That expression is one of the candidates for \(W\), so it is at most its maximum \((\mathcal{B}W)(k) = \sqrt{k^{\alpha} - b} + \beta W(b)\). So \((\mathcal{B}V)(k) \le (\mathcal{B}W)(k)\) for every \(k\). This proves the claim.

P2 · The value at one state with a finite feasible set

Suppose \(F(k) = \{g\}\) is a single point for every \(k\), and let \(0 < \beta < 1\). Prove that \(\mathcal{B}\) is a contraction with modulus \(\beta\) directly from Definition 2.1, without using Theorem 2.2.

Solution

When \(F(k) = \{g(k)\}\), the operator is \((\mathcal{B}V)(k) = \sqrt{k^{\alpha} - g(k)} + \beta V(g(k))\). The utility term does not depend on \(V\), so \((\mathcal{B}V)(k) - (\mathcal{B}W)(k) = \beta\,(V(g(k)) - W(g(k)))\). Its absolute value is at most \(\beta\,\lVert V - W \rVert_\infty\). Taking the maximum over \(k\) gives \(\lVert \mathcal{B}V - \mathcal{B}W \rVert_\infty \le \beta \lVert V - W \rVert_\infty\), which is Definition 2.1.

P3 · The one-point iterates in closed form

On the one-point grid, with utility \(u\) and \(0 < \beta < 1\), start from \(V_0 = 0\) and let \(V_{n+1} = u + \beta V_n\). Prove that \(V_n = u(1 - \beta^{n})/(1 - \beta)\), and that \(|V_n - V^\ast| = u\beta^{n}/(1 - \beta)\), where \(V^\ast = u/(1 - \beta)\).

Solution

For \(n = 0\), the formula gives \(0\), which equals \(V_0\). If \(V_n = u(1 - \beta^n)/(1 - \beta)\), then \(V_{n+1} = u + \beta u (1 - \beta^n)/(1 - \beta) = u\,[(1 - \beta) + \beta - \beta^{n+1}]/(1 - \beta) = u(1 - \beta^{n+1})/(1 - \beta)\). For the error, \(V^\ast - V_n = u\beta^n/(1 - \beta)\), because \(u/(1-\beta) - u(1 - \beta^n)/(1 - \beta) = u\beta^n/(1 - \beta)\). This is the bound of Theorem 2.2(c) with \(\lVert V_1 - V_0 \rVert = u\), attained with equality.

Empirical

E1 · Iterations against the discount factor

Lab 1 prints 257 iterations at \(\beta = 0.9\). Change the BETA constant in a copy of the lab code to \(0.5\) and to \(0.95\), and run it. Report the two counts, and state the direction in which the count moves as \(\beta\) rises.

Solution

In a copy with BETA set to \(0.5\), the solver stops after 40 iterations. With BETA set to \(0.95\), it stops after 527 iterations. The count rises with \(\beta\). The solver stops on the gap between successive values, not on the bound, so these counts are not the a priori count. The a priori count, from Theorem 2.2(c), is the least \(n\) with \(\beta^{n} d/(1 - \beta) \le \tau\), where \(d = \lVert V_1 - V_0 \rVert_\infty\) and \(\tau\) is the tolerance. That is \(n \ge \ln\bigl(d/(\tau(1-\beta))\bigr)/\ln(1/\beta)\), so it scales with \(1/\ln(1/\beta)\). That quantity is \(1/\ln 2 \approx 1.443\) at \(\beta = 0.5\), \(1/\ln(1/0.9) \approx 9.49\) at \(\beta = 0.9\), and \(1/\ln(1/0.95) \approx 19.5\) at \(\beta = 0.95\). The solver counts rise in the same direction.

E2 · Checking the printed fixed point by hand

Lab 1 prints \(V^\ast(0.25) = 5.000000\) and \(V^\ast(0.50) = 5.176097\). Use the fixed-point relation at \(k = 0.50\) to check the second value, given that the policy chooses \(k' = 0.25\).

Solution

At \(k = 0.5\), the output is \(0.707107\), so the consumption from \(k' = 0.25\) is \(0.707107 - 0.25 = 0.457107\), with utility \(\sqrt{0.457107} = 0.676097\). The discounted value of the next state is \(0.9 \times 5.000000 = 4.5\). The sum is \(0.676097 + 4.5 = 5.176097\), which matches the printed value to six decimal places.

E3 · When the one-point iterates pass a threshold

On the one-point grid with \(\beta = 1\), the iterates are \(V_n = n/2\), as Lab 1, part C checks at \(n = 1000\). Find the first \(n\) with \(V_n > 1000\).

Solution

The condition \(n/2 > 1000\) holds exactly when \(n > 2000\). So the first such integer is \(n = 2001\), where \(V_{2001} = 1000.5\). The iterates never settle, because each step adds \(1/2\) and nothing offsets it.

R1 · Dependence on the discount factor

For \(\beta, \gamma \in (0, 1)\), let \(\mathcal{B}_\beta\) and \(\mathcal{B}_\gamma\) denote the operator with those discount factors on the same grid. Prove that \(\lVert \mathcal{B}_\beta V - \mathcal{B}_\gamma V \rVert_\infty \le |\beta - \gamma|\,\lVert V \rVert_\infty\) for every \(V\).

Solution

Fix \(k\), and write \(f_a = \sqrt{k^{\alpha} - a} + \beta V(a)\) and \(g_a = \sqrt{k^{\alpha} - a} + \gamma V(a)\) for \(a \in F(k)\). For finitely many numbers, \(|\max_a f_a - \max_a g_a| \le \max_a |f_a - g_a|\). To see this, let \(a^\ast\) maximise \(f\); then \(\max f - \max g \le f_{a^\ast} - g_{a^\ast} \le \max_a |f_a - g_a|\), and the same bound holds with the roles exchanged. Here \(f_a - g_a = (\beta - \gamma)V(a)\), so \(|f_a - g_a| \le |\beta - \gamma|\,\lVert V \rVert_\infty\). Taking the maximum over \(k\) gives the claim. So for each fixed \(V\), \(\mathcal{B}V\) depends Lipschitz-continuously on \(\beta\), with constant \(\lVert V \rVert_\infty\).

R2 · Divergence at \(\beta = 1\) on the four-point grid

On the grid \((0.25, 0.5, 0.75, 1.0)\) with \(\alpha = 1/2\) and \(\beta = 1\), start from \(V_0 = 0\). Prove that \(V_n(0.25) \ge n/2\) for every \(n\), so the iterates are unbounded.

Solution

The state \(0.25\) is in its own feasible set, since \(0.25 \le 0.5\). Choosing \(k' = 0.25\) gives consumption \(0.5 - 0.25 = 0.25\) and utility \(0.5\). So \(V_{n+1}(0.25) \ge 0.5 + V_n(0.25)\), because \(\beta = 1\) and the maximum is at least the value of this choice. By induction from \(V_0(0.25) = 0\), \(V_n(0.25) \ge n/2\). Now suppose a fixed point \(V^{\ast}\) exists in \(\mathbb{R}^{G}\) at \(\beta = 1\). The proof of Theorem 2.2(a) with \(\beta = 1\) gives \(\lVert \mathcal{B}V - \mathcal{B}W \rVert_\infty \le \lVert V - W \rVert_\infty\) for all \(V, W\), so \(\lVert V_n - V^{\ast} \rVert_\infty \le \lVert V_0 - V^{\ast} \rVert_\infty\) for every \(n\). Then \(V_n(0.25) \le V^{\ast}(0.25) + \lVert V_0 - V^{\ast} \rVert_\infty\) for every \(n\), which contradicts \(V_n(0.25) \ge n/2\). So no fixed point exists in \(\mathbb{R}^{G}\) at \(\beta = 1\). Lab 1 part C shows the linear growth on the one-point grid.

R3 · When every feasible set is nonempty

Prove that if \(G \subseteq (0, 1]\), then \(\min G \in F(k)\) for every \(k \in G\). Then show that the grid \(G = (2, 3)\) with \(\alpha = 1/2\) has \(F(2) = \varnothing\).

Solution

Let \(g_1 = \min G\) and \(k \in G\), so \(0 < g_1 \le k \le 1\). Because \(\alpha \in (0, 1)\), \(k^{\alpha} \ge k\) for \(k \in (0, 1]\), since \(k^{\alpha - 1} \ge 1\) when \(k \le 1\) and \(\alpha - 1 < 0\). So \(g_1 \le k \le k^{\alpha}\), which means \(g_1 \in F(k)\). For \(G = (2, 3)\), the output at \(k = 2\) is \(\sqrt{2} \approx 1.414\), which is below \(2\), so no grid point lies in \(F(2)\). The first grid point is too large to be reached from \(2\).
