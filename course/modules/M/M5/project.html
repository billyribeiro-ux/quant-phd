Contraction-mapping solver

A planner chooses how much of a finite grid of capital values to save, and the value function of the grid is the fixed point of the discounted Bellman operator. You will prove that the operator is a contraction in the sup norm (the conventions below define the operator, the norm and the certified error), derive a certified error bound for value-function iteration, write the solver that reports that bound, and show that it reproduces the reference numbers of one illustrative instance.

Rungs 1 and 2

Both labs use one illustrative grid: the three capital values 0.5, 0.9 and 1.4, a discount factor \(\beta = 0.9\), and a production exponent \(\alpha = 0.5\). The output from capital \(k\), which the labs call its resources, is \(k^{\alpha}\), and saving \(k'\) leaves the consumption \(k^{\alpha}-k'\). A saving \(k'\) is feasible from \(k\) when that consumption is nonnegative. The utility of consumption \(c\ge 0\) is \(\sqrt{c}\). The inputs are illustrative. They are not data, and no file is read. A sweep is one application of the operator, defined in the conventions below, to the whole vector of values. The change of a sweep is the largest absolute difference between its output and the vector before it, and the labs use \(\beta/(1-\beta)\) times that change as the certified error after a sweep; the conventions below define the certified error and give this as the bound they use.

Lab 1 · Worked example: one sweep and its certified error

Stated before running. The resources are \(0.5^{0.5}=0.707107\), \(0.9^{0.5}=0.948683\) and \(1.4^{0.5}=1.183216\). The feasible savings are \(\{0.5\}\) from 0.5, and \(\{0.5, 0.9\}\) from 0.9 and from 1.4. One sweep from the zero vector gives \(V_1 = (0.455090,\ 0.669838,\ 0.826569)\). The contraction inequality, \(\sup|\mathcal{B}V-\mathcal{B}W| \le \beta\sup|V-W|\) (result A1 in the brief below states it for all vectors), holds for \(V = V_0\) and \(W = V_1\): \(0.409581 \le 0.743912\). The first sweep has a change of 0.826569 and a certified error of 7.439119. The iteration stops after sweep 146, with a certified error below \(10^{-6}\), and its actual error, measured against a reference fixed point iterated to \(10^{-12}\), agrees with the certified error to nine decimals.

"""Rung 1 worked example: one discounted Bellman sweep and its certified error on a three-point grid.

Standard library only; the example uses no random numbers. The model: output from capital k is k**alpha, so saving
kp leaves consumption k**alpha - kp; utility is sqrt(consumption); the operator takes the best feasible saving plus
beta times the value of that saving. Step 1 prints the resources, step 2 the feasible savings, step 3 one sweep from
zero, step 4 a contraction check, step 5 the iteration to a certified error of 1e-6, and step 6 the actual error
against a reference fixed point iterated to 1e-12.
"""

import math

BETA = 0.9
ALPHA = 0.5
GRID = [0.5, 0.9, 1.4]


def resources(k: float) -> float:
    """Output available from capital k: k to the power alpha."""
    return float(k**ALPHA)


def feasible(k: float) -> list[int]:
    """Indices of the successors kp with kp <= k**alpha, that is, consumption k**alpha - kp >= 0."""
    return [j for j, kp in enumerate(GRID) if kp <= resources(k)]


def bellman(values: list[float]) -> list[float]:
    """One application of the discounted Bellman operator: max over feasible kp of sqrt(k**alpha - kp) + beta V(kp)."""
    out = []
    for k in GRID:
        out.append(max(math.sqrt(resources(k) - GRID[j]) + BETA * values[j] for j in feasible(k)))
    return out


def sup_distance(a: list[float], b: list[float]) -> float:
    """The sup norm of a difference: the largest absolute entry."""
    return max(abs(x - y) for x, y in zip(a, b, strict=False))


def main() -> None:
    # Step 1. The resources k**alpha at each grid point.
    for k in GRID:
        print(f"resources at k={k}: {resources(k):.6f}")
    # Step 2. The feasible successors: kp is feasible from k when kp <= k**alpha.
    for k in GRID:
        print(f"feasible successors from k={k}: {[GRID[j] for j in feasible(k)]}")
    # Step 3. One sweep from the zero vector: the continuation term beta V(kp) is zero, so V1 is the best consumption.
    v0 = [0.0, 0.0, 0.0]
    v1 = bellman(v0)
    print("V1:", [f"{x:.6f}" for x in v1])
    # Step 4. Contraction check with V = V0 and W = V1: sup|BV - BW| is at most beta times sup|V - W|.
    bv, bw = bellman(v0), bellman(v1)
    lhs = sup_distance(bv, bw)
    rhs = BETA * sup_distance(v0, v1)
    print(f"sup|BV - BW| = {lhs:.6f} | beta * sup|V - W| = {rhs:.6f} | holds: {lhs <= rhs}")
    # Step 5. Iterate from V0. After each sweep: the change sup|V_n - V_{n-1}| and the certified error
    # beta/(1-beta) times that change. Print the first three sweeps, then stop at the first certified error <= 1e-6.
    values = v0
    n = 0
    certified = math.inf
    while certified > 1e-6:
        n += 1
        new = bellman(values)
        change = sup_distance(new, values)
        certified = BETA / (1 - BETA) * change
        values = new
        if n <= 3:
            print(f"sweep {n}: change {change:.6f} | certified error {certified:.6f}")
    print(f"stopped after sweep {n}: change {change:.9f} | certified error {certified:.9f}")
    # Step 6. Compare with a reference fixed point, iterated until its certified error is at most 1e-12.
    reference = v0
    for _ in range(100_000):
        nxt = bellman(reference)
        small = BETA / (1 - BETA) * sup_distance(nxt, reference) <= 1e-12
        reference = nxt
        if small:
            break
    print("value after the last sweep:", [f"{x:.6f}" for x in values])
    actual = sup_distance(values, reference)
    relation = "<=" if actual <= certified else ">"
    print(f"actual error {actual:.9f} {relation} certified error {certified:.9f}")


main()

Step 3 is the operator applied once to the zero vector, so the continuation term is zero. Step 4 is the contraction inequality with \(\beta = 0.9\) on one pair. Rung 3 · Specification

Context
A planner chooses how much of the output at each capital level on a finite grid to save. The value function of the grid is the fixed point \(V\) of the discounted Bellman operator \(\mathcal{B}\), defined in the conventions below. You write the operator, prove that it is a contraction in the sup norm, prove the fixed-point facts the solver relies on, and write a value-function iteration that reports a certified error. The solver must reproduce the reference numbers of one illustrative instance.
Inputs
No data file. The autograder's instance comes from grader/instance.py, seeded by your workspace ID. It holds a discount factor beta, a production exponent alpha, a strictly increasing grid grid and a tolerance tol. All of it is SIMULATED: generated parameters, not data. The report uses the illustrative instance of Lab 3 (\(\beta = 0.9\), \(\alpha = 0.3\), ten grid points from 0.45 to 2.70, and a tolerance of \(10^{-10}\)), which is an input and not data.
Required outputs
In a repository of your own: contraction_solver.py at its root, and a report/ folder beside it. The module defines bellman_operator(params, grid, values), which returns the list \(\mathcal{B}V\), and solve(params, grid, tol, max_iter), which returns a dictionary with the keys value, iterations, certified_error and converged. The parameters are passed as params = {"beta": beta, "alpha": alpha}, where beta and alpha are the two numbers. Start from the starter file, whose signatures are complete. For the report, commit three more files: report/run_report.py, which is Lab 3 with its bellman function and sweep loop replaced by calls to your module, and which prints the same lines (solve does not return the last change, which is the certified error times \((1-\beta)/\beta\)); report/report.md, the proof write-up described in the brief; and report/self_assessment.md, the summary that the form in the self-assessment section produces.
Constraints
Standard library only. Each input named in the conventions below raises ValueError when it is invalid. No function prints or warns. A run in your browser stops after 120 seconds. The conventions are in the next subsection, and they are binding.
Grading mode
Both modes apply. The code is autograded by grader/test_project.py, which runs 101 checks with warnings as errors: the operator against its definition, the contraction and monotonicity properties on seeded pairs, the feasibility rule, the certified error against the fixed point and against its formula, the iteration budget, and the named invalid inputs. The same file runs in your browser and on your machine. It is not secret: its integrity comes from your seeded instance and from a second instance, which a fixed answer for the first would also have to match. The proof write-up is graded by rubric, against the six criteria of the report rubric, each with four observable levels. You score it yourself with the form in the self-assessment section and calibrate that scoring on two annotated exemplars. The report meets the bar at level 3 or above on every criterion.

Conventions

  • The state space. A state is a capital value on a grid \(k_1 < k_2 < \cdots < k_m\) of positive real numbers, with \(k_1 \le 1\). The grid is a finite subset of \(\R\) with the sup norm \(\lVert V\rVert_\infty = \max_i |V(k_i)|\), so a value vector is a point of \(\R^m\).
  • Feasibility. Output from capital \(k\) is \(k^{\alpha}\). Saving \(k'\) leaves consumption \(c = k^{\alpha}-k'\), and \(k'\) is feasible from \(k\) when \(c \ge 0\), that is, when \(k' \le k^{\alpha}\). Every state has a feasible saving: \(k_1\) is feasible from every state. For \(k \le 1\), \(k^{\alpha} \ge k \ge k_1\), because \(\alpha < 1\); for \(k > 1\), \(k^{\alpha} > 1 \ge k_1\).
  • Utility. The utility of consumption \(c \ge 0\) is \(u(c) = \sqrt{c}\).
  • The operator. For a vector \(V\) on the grid, \((\mathcal{B}V)(k) = \max\{\sqrt{k^{\alpha}-k'} + \beta V(k') : k' \text{ feasible from } k\}\), with \(\beta\in(0,1)\). The maximum is over the grid points \(k'\) of the feasible set. bellman_operator returns \(\mathcal{B}V\) as a list, one entry per grid point, computed from the vector it is given.
  • Iteration. solve starts from the zero vector, \(V_0 = 0\). A sweep is one application of the operator to the current vector, and \(V_n\) is the vector after \(n\) sweeps. Each sweep is synchronous: every state is updated from the previous vector as a whole. An in-place sweep, which updates the states one at a time so that later states read the values already updated in the same sweep, is compared with the synchronous sweep in Rung 4.
  • Certified error. certified_error is an upper bound on the sup-norm distance \(\lVert V_{\mathrm{out}} - V^{\ast}\rVert_\infty\), where \(V^{\ast}\) is the fixed point of \(\mathcal{B}\) on the grid. It is not a bound on the distance to a continuous problem. The certified error is this bound: \(\frac{\beta}{1-\beta}\lVert V_n - V_{n-1}\rVert_\infty\), where \(V_n\) is the vector after the last sweep. The suite checks validity against a reference fixed point and checks the formula on the first three sweeps.
  • Stopping. The solver stops at the first sweep at which certified_error is at most tol, or after max_iter sweeps. iterations is the number of sweeps made, at least 1. converged is True exactly when certified_error is at most tol. value is the vector the certified error refers to.
  • Iteration budget. A correct solver stops within the a priori count plus one, where the a priori count is the least \(n \ge 0\) with \(\beta^{n}\sqrt{k_m^{\alpha}}/(1-\beta) \le \mathrm{tol}\).
  • Named invalid inputs. Each of these raises ValueError: beta or alpha that is not a real number in the open interval \((0,1)\), including a boolean or a non-finite number; tol that is not a finite real number greater than zero; max_iter that is not a whole number of sweeps, one or more, including a boolean or a float; a grid that is empty, has a point that is not a positive real number, is not strictly increasing, or whose first point exceeds 1; and, in bellman_operator, a values list whose length is not the grid's length.

"""Rung 3 reference numbers: the solver's output on the report's illustrative instance, and the report's checks.

Standard library only. The inputs are illustrative, not data: beta = 0.9, alpha = 0.3, the ten grid points
0.45, 0.70, 0.95 and so on up to 2.70, and the tolerance 1e-10. The model is the one in the specification: output
k**alpha, feasible savings kp <= k**alpha, utility sqrt of consumption, and value iteration from the zero vector.
The random pairs use the seed 7.

Copy this file into report/run_report.py, replace the operator and solver calls with calls to your
contraction_solver module, and print the same lines. The numbers are the ones the report quotes.
"""

import math
import random

BETA = 0.9
ALPHA = 0.3
GRID = [0.45 + 0.25 * j for j in range(10)]
TOL = 1e-10


def resources(k: float) -> float:
    """Output available from capital k: k to the power alpha."""
    return float(k**ALPHA)


def bellman(values: list[float]) -> list[float]:
    """One application of the discounted Bellman operator: max over feasible kp of sqrt(k**alpha - kp) + beta V(kp)."""
    out = []
    for k in GRID:
        best = max(math.sqrt(resources(k) - kp) + BETA * values[j] for j, kp in enumerate(GRID) if kp <= resources(k))
        out.append(best)
    return out


def sup_distance(a: list[float], b: list[float]) -> float:
    """The sup norm of a difference: the largest absolute entry."""
    return max(abs(x - y) for x, y in zip(a, b, strict=False))


def main() -> None:
    # The smallest gap between a grid point and a resource level k**alpha: a gap near zero would make the
    # feasibility test a near-tie.
    gap = min(abs(kp - resources(k)) for k in GRID for kp in GRID)
    print(f"instance: beta {BETA}, alpha {ALPHA}, {len(GRID)} grid points from {GRID[0]} to {GRID[-1]}")
    print(f"smallest gap between a grid point and a resource level: {gap:.6f} | clear of a tie: {gap > 1e-6}")
    # Value iteration from zero, stopped at the first certified error at most TOL.
    values = [0.0] * len(GRID)
    sweeps = 0
    certified = math.inf
    change = math.inf
    while certified > TOL:
        new = bellman(values)
        change = sup_distance(new, values)
        certified = BETA / (1 - BETA) * change
        values = new
        sweeps += 1
    print(f"sweeps: {sweeps} | last change: {change:.3e} | certified error: {certified:.3e}")
    # The a priori count: the least n with beta**n * U / (1 - beta) at most TOL, where U = sqrt(max grid**alpha).
    bound_u = math.sqrt(max(GRID) ** ALPHA)
    n_apriori = 0
    while BETA**n_apriori * bound_u / (1 - BETA) > TOL:
        n_apriori += 1
    print(f"a priori count: {n_apriori} | sweeps within the count plus one: {sweeps <= n_apriori + 1}")
    # The residual of the output: |BV - V| is at most (1 + beta) times the certified error.
    residual = sup_distance(bellman(values), values)
    print(
        f"residual: {residual:.3e} | at most (1 + beta) times the certified error: {residual <= (1 + BETA) * certified}"
    )
    # The contraction ratio on seeded random pairs: the largest sup|BV - BW| / sup|V - W| seen is at most beta.
    rng = random.Random(7)
    worst = 0.0
    for _ in range(200):
        v = [rng.uniform(0.0, 4.0) for _ in GRID]
        w = [rng.uniform(0.0, 4.0) for _ in GRID]
        worst = max(worst, sup_distance(bellman(v), bellman(w)) / sup_distance(v, w))
    print(f"largest observed contraction ratio over 200 pairs: {worst:.6f} | at most beta: {worst <= BETA + 1e-12}")
    # The value at each grid point.
    for k, value in zip(GRID, values, strict=False):
        print(f"V({k}) = {value:.6f}")

The brief

Write the proof write-up in report/report.md, with these sections in this order: Setting, Contraction, Fixed point, Certified bound, Numerical check and Limitations. Then an appendix, A, with four proofs. Each proof states its hypotheses in a numbered list before its conclusion, and each uses only those hypotheses.

  1. A1, the contraction. Hypotheses: a grid of positive points whose first point is at most 1, so that every feasible set is nonempty; \(\alpha\in(0,1)\), which is what makes \(k^{\alpha}\ge k_1\) for every state; \(\beta\in(0,1)\); and the feasibility and utility rules above. Conclusion: \(\lVert\mathcal{B}V-\mathcal{B}W\rVert_\infty \le \beta\lVert V-W\rVert_\infty\) for all vectors \(V\), \(W\) on the grid.
  2. A2, the space. Hypothesis: a finite grid of \(m\) points. Conclusion: the vectors on the grid form a complete metric space under the sup norm, with a reason that does not assume the conclusion.
  3. A3, the fixed point. Hypotheses: A1 and A2, and the zero vector as the start. Conclusion: \(\mathcal{B}\) has exactly one fixed point \(V^{\ast}\) on the grid, and the sweeps from zero converge to it. Lesson 7 states the general argument; check its hypotheses for this operator and prove the step your solver relies on.
  4. A4, the certified bound. Hypotheses: A1, A3 (the sweeps converge to \(V^{\ast}\)), and the sweep \(V_n = \mathcal{B}V_{n-1}\). Conclusion: \(\lVert V_n - V^{\ast}\rVert_\infty \le \frac{\beta}{1-\beta}\lVert V_n-V_{n-1}\rVert_\infty\). Derive it from A1 by summing a geometric series; do not assert it.

Exemplar B

Official scoring: C1 4 · C2 4 · C3 4 · C4 4 · C5 4 · C6 3. Every criterion is met at level 4 except the limitations, where the direction of the discretization error is not stated.

Setting

The state space is a grid \(k_1 < \cdots < k_{10}\) of positive points, with \(k_1 = 0.45 \le 1\), under the sup norm. A saving \(k'\) is feasible from \(k\) when \(k' \le k^{0.3}\), and utility is \(\sqrt{k^{0.3}-k'}\) on consumption \(k^{0.3}-k' \ge 0\). The discount factor is \(\beta = 0.9\), with \(\beta\in(0,1)\), and the production exponent is \(\alpha = 0.3\), with \(\alpha\in(0,1)\). The iteration starts at \(V_0 = 0\), stops at a tolerance of \(10^{-10}\), and the fixed point \(V^{\ast}\) is the one of the grid operator.

Contraction (A1)

For a state \(k\), let \(a\) and \(b\) be the maxima of \(\sqrt{k^{0.3}-k'}+\beta V(k')\) and \(\sqrt{k^{0.3}-k'}+\beta W(k')\) over the same feasible set. Each of the two maxima is taken over the same family of summands, which differ only by \(\beta(V(k')-W(k'))\). The maximum of a family of numbers moves by at most the largest move of its members, so \(|a-b| \le \beta\max_{k'}|V(k')-W(k')| = \beta\lVert V-W\rVert_\infty\). Taking the maximum over \(k\) gives \(\lVert\mathcal{B}V-\mathcal{B}W\rVert_\infty \le \beta\lVert V-W\rVert_\infty\).

Fixed point (A2, A3)

A2: a vector on the grid is a point of \(\R^{10}\), and \(|V(k_i)-W(k_i)|\le\lVert V-W\rVert_\infty\) for each \(i\). A Cauchy sequence in the sup norm is therefore Cauchy in each of the ten coordinates, each coordinate converges because \(\R\) is complete, and the ten limits form a vector on the grid that is the sup-norm limit, since there are only ten indices. A3: by A1, \(d_{n+1}\le\beta d_n\) for \(d_n = \lVert V_n-V_{n-1}\rVert_\infty\), so \(\sum_n d_n\) is a geometric series and the sweeps are Cauchy. Their limit \(V^{\ast}\) satisfies \(V^{\ast}=\mathcal{B}V^{\ast}\), because \(\mathcal{B}\) is continuous by A1. If \(W\) is another fixed point, \(\lVert V^{\ast}-W\rVert_\infty = \lVert\mathcal{B}V^{\ast}-\mathcal{B}W\rVert_\infty \le \beta\lVert V^{\ast}-W\rVert_\infty\), which with \(\beta<1\) forces \(W=V^{\ast}\).

Certified bound (A4)

Let \(d_n\) be as above. By A1 with \(V = V_k\) and \(W = V_{k-1}\), \(d_{k+1} \le \beta d_k\), so by induction on \(j\), \(d_{n+j} \le \beta^{j} d_n\). By A3 the sweeps converge to \(V^{\ast}\), so the triangle inequality and the limit give \(\lVert V_n-V^{\ast}\rVert_\infty \le \sum_{j\ge 1} d_{n+j} \le d_n\sum_{j\ge 1}\beta^{j} = d_n\beta/(1-\beta)\). At the stop, the last change is printed as \(1.025\times 10^{-11}\), and the certified error as \(9.226\times 10^{-11}\).

Numerical check

For the instance of Lab 3, with a tolerance of \(10^{-10}\), the printed line sweeps: 236 | last change: 1.025e-11 | certified error: 9.226e-11 gives 236 sweeps, a last change of \(1.025\times 10^{-11}\) and a certified error of \(9.226\times 10^{-11}\). The printed line a priori count: 242 gives the a priori count of 242, and the printed line residual: 9.226e-12 gives a residual of \(9.226\times 10^{-12}\). The residual is at most \((1+\beta)\) times the certified error, as the printed line ending at most (1 + beta) times the certified error: True confirms. The printed line largest observed contraction ratio over 200 pairs: 0.900000 reports a largest ratio of 0.900000, at most \(\beta\) within the stated rounding margin.

Limitations

The bound is for the fixed point of the grid operator. It does not bound the error of a continuous model, and the grid's own spacing is part of the error the bound leaves out. The bound does not measure that part, and this implementation costs about \(m^2\) operations per sweep, so the cost grows with the square of the number of points.

  • Meets C1 level 4: names the grid and the sup norm, the feasibility rule, the utility on \(c \ge 0\), the parameters, and the start, with the fixed point taken on the grid.
  • Meets C2 level 4: each step names its property, and the constant appears at the end of the inequality.
  • Meets C3 level 4: proves A2 with the coordinatewise step, and the sup-norm limit is identified on the grid.
  • Meets C4 level 4: sums the geometric series, shows the constant, and gives the certified error at the stop, which is the sweep the solver uses.
  • Meets C5 level 4: every number is named as printed by Lab 3, with its instance and tolerance.
  • Meets C6 level 3: states the grid limitation and the scope of the bound, but does not give the direction in which the discretization error moves with the grid spacing.
  • Misses C6 level 4: the direction of the discretization error is not stated, and the passage says the grid's spacing is part of the error the bound leaves out, and gives no direction for it.
