The limits of L02 and the continuity of L03 are defined through a distance. On the real line the distance is \(\lvert x-y\rvert\). A metric space is a set with a distance that obeys three axioms, and the proofs in this lesson use the metric axioms and the facts that Section 1 names and lists. This lesson states the axioms, proves that two standard distances satisfy them, and shows that completeness (defined in Section 3) depends on the space as well as on the sequence.

1Metrics and the metric axioms

Throughout, \(\R\) is the set of real numbers. The proofs in this lesson use the metric axioms and the following facts, which are taken as given. From L01: the supremum property (Definition 1.1 there). From L02: every Cauchy sequence of real numbers converges to a real number (Theorem 2.5 there), and \(1/n\to 0\) (Problem M1 there). Order and arithmetic, taken as prose facts: (F1) the square of a real number is nonnegative, and if \(s\ge 0\), \(t\ge 0\) and \(s^{2}\le t^{2}\), then \(s\le t\); (F2) a sum of two nonnegative reals is zero only if both are zero; (F3) a nonnegative real number that is at most 0 is 0; (F4) the triangle inequality \(\lvert a+b\rvert\le\lvert a\rvert+\lvert b\rvert\) holds for real \(a\) and \(b\); (F5) if \(a_n\to 0\) and \(b_n\to 0\), then \(a_n+b_n\to 0\) (L02, Problem P2); (F6) if \(c\ge 0\) and \(c\le t_n\) for every \(n\), where \(t_n\to 0\), then \(c=0\): for each \(\varepsilon>0\) some \(t_n<\varepsilon\), so \(c<\varepsilon\) for every \(\varepsilon>0\). If \(c>0\), taking \(\varepsilon=c\) gives \(csupremum of a nonempty set of real numbers is its least upper bound. A set of real numbers is bounded when some real number \(M \ge 0\) satisfies \(\lvert v\rvert \le M\) for every member \(v\) of the set. A function \(f\) from a set \(S\) to \(\R\) is bounded when the set of its values is bounded.

Definition 1.1 (metric space)

Let \(X\) be a nonempty set and \(d\colon X\times X\to\R\) a function. The pair \((X,d)\) is a metric space, and \(d\) is a metric on \(X\), when for all \(x,y,z\in X\):

  • (M1) \(d(x,y)\ge 0\), and \(d(x,y)=0\) if and only if \(x=y\);
  • (M2) \(d(x,y)=d(y,x)\) (symmetry);
  • (M3) \(d(x,z)\le d(x,y)+d(y,z)\) (triangle inequality).
Remark 1.2 (what the axioms exclude)

M1 makes \(d\) a measure of separation that vanishes only on the diagonal. M2 says that the distance from \(x\) to \(y\) is the distance from \(y\) to \(x\). M3 says that a detour through a third point is never shorter than the direct path. Section 5 gives one example in which M3 fails and one in which the "only if" half of M1 fails.

Example 1.3 (the Euclidean plane)

On \(\R^{2}\), write \(\lvert u\rvert=\sqrt{u_{1}^{2}+u_{2}^{2}}\) for the length of \(u=(u_{1},u_{2})\), and set \(d_{2}(x,y)=\lvert x-y\rvert\). This is the Euclidean distance.

Proposition 1.4 (the Euclidean distance is a metric)

Hypotheses: (1) \(x=(x_{1},x_{2})\), \(y=(y_{1},y_{2})\) and \(z=(z_{1},z_{2})\) are points of \(\R^{2}\); (2) \(d_{2}\) is as in Example 1.3. Conclusion: \((\R^{2},d_{2})\) is a metric space.

Proof

M1. The quantity \(d_{2}(x,y)^{2}=(x_{1}-y_{1})^{2}+(x_{2}-y_{2})^{2}\) is a sum of two squares, so it is nonnegative and \(d_{2}(x,y)\ge 0\). It is zero if and only if both differences vanish, that is, if and only if \(x=y\).

M2. Each square \((x_{i}-y_{i})^{2}\) equals \((y_{i}-x_{i})^{2}\), so \(d_{2}(x,y)=d_{2}(y,x)\).

M3. Put \(u=x-y\) and \(v=y-z\), so \(x-z=u+v\). Write \(u\cdot v=u_{1}v_{1}+u_{2}v_{2}\). The Lagrange identity in two dimensions, \[ (u_{1}^{2}+u_{2}^{2})(v_{1}^{2}+v_{2}^{2})-(u_{1}v_{1}+u_{2}v_{2})^{2}=(u_{1}v_{2}-u_{2}v_{1})^{2}, \] holds, because expanding the left side leaves \(u_{1}^{2}v_{2}^{2}+u_{2}^{2}v_{1}^{2}-2u_{1}v_{1}u_{2}v_{2}\), which is the right side. The right side is at least zero, so \((u\cdot v)^{2}\le \lvert u\rvert^{2}\lvert v\rvert^{2}\), and taking square roots of nonnegative numbers gives \(\lvert u\cdot v\rvert\le \lvert u\rvert\lvert v\rvert\). Then \[ \lvert u+v\rvert^{2}=\lvert u\rvert^{2}+2\,u\cdot v+\lvert v\rvert^{2}\le \lvert u\rvert^{2}+2\lvert u\rvert\lvert v\rvert+\lvert v\rvert^{2}=(\lvert u\rvert+\lvert v\rvert)^{2}. \] Taking square roots gives \(\lvert u+v\rvert\le \lvert u\rvert+\lvert v\rvert\), that is, \(d_{2}(x,z)\le d_{2}(x,y)+d_{2}(y,z)\). \(\square\)

Example 1.5 (the discrete metric)

On any nonempty set \(X\), set \(d(x,y)=0\) when \(x=y\) and \(d(x,y)=1\) when \(x\ne y\). Axioms M1 and M2 are immediate. For M3, if \(x=z\), then \(d(x,z)=0\), and the inequality holds because both terms on the right are nonnegative. Now let \(x\ne z\). If \(y=x\), then \(d(x,y)=0\) and \(d(y,z)=d(x,z)=1\), so the inequality reads \(1\le 0+1\). If \(y=z\), the same argument applies. If \(y\) equals neither, then \(d(x,y)+d(y,z)=2\ge 1\). So the discrete distance is a metric.

Lab 1 · The metric axioms on finite samples

Before running: nonnegativity, identity and symmetry are tested on every pair of a finite sample, and the triangle inequality on every triple. Expected: zero failures for the Euclidean distance on the 25 grid points of \(\R^{2}\) (Part A), zero failures for the sup distance on the 27 vectors of length 3 (Part B), and exactly two triangle-inequality failures for the squared distance \((x-y)^{2}\) on the points 0, 1, 2 (Part C). Standard library only. No random draws are used, because every sample is enumerated. The check tests the sample, not the whole space.

"""M5 L04 lab 1: the metric axioms, checked exhaustively on finite samples.

Standard library only. No randomness and no network: every sample is enumerated, so every run prints the same lines.
A check on a finite sample tests that sample only. The output is evidence about the sample and says nothing about the
whole space.

Part A: the Euclidean distance on the 25 points (i/2, j/2) with i, j in {-2, -1, 0, 1, 2}, in R^2. Floats are used,
and the triangle inequality is tested with a slack of 1e-12 for floating-point
error. Nonnegativity, identity and symmetry are tested on all pairs; the triangle inequality is tested on all triples.
Part B: the sup distance max_k |f_k - g_k| on the 27 vectors of length 3 with entries in {0, 1, 2}. Entries are exact
Fractions, so the slack is zero.
Part C: the squared Euclidean distance on the three points 0, 1, 2 of R. It is symmetric and zero only at equal points,
and it fails the triangle inequality. The printed numbers are the exact values at the failing triple.
"""

from __future__ import annotations

from collections.abc import Callable, Sequence
from fractions import Fraction
from itertools import product
from math import sqrt

Number = float | Fraction
Point = tuple[float, float]
Vector = tuple[Fraction, ...]

SLACK = 1e-12
AXIOMS = ("nonnegative", "identity", "symmetry", "triangle")


def euclidean(x: Point, y: Point) -> float:
    """The Euclidean distance in R^2, in the units of the coordinates."""
    return sqrt((x[0] - y[0]) ** 2 + (x[1] - y[1]) ** 2)


def sup_distance(f: Vector, g: Vector) -> Fraction:
    """The maximum over k of |f_k - g_k|, exact. Both vectors have the same length."""
    return max(abs(a - b) for a, b in zip(f, g, strict=True))


def squared_distance(x: int, y: int) -> int:
    """The squared difference (x - y)^2 on the integers. It is a candidate distance, and it is not a metric."""
    return (x - y) ** 2


def axiom_failures[P](points: Sequence[P], dist: Callable[[P, P], Number], slack: Number) -> dict[str, int]:
    """Count, for each metric axiom, the sample tuples on which it fails.

    Nonnegativity and identity use pairs, symmetry uses pairs, and the triangle inequality uses triples
    (x, y, z) with d(x, z) <= d(x, y) + d(y, z) + slack. The count for each axiom is returned in AXIOMS order.
    """
    failures = dict.fromkeys(AXIOMS, 0)
    for x, y in product(points, repeat=2):
        d = dist(x, y)
        if d < 0:
            failures["nonnegative"] += 1
        if (d == 0) != (x == y):
            failures["identity"] += 1
        if d != dist(y, x):
            failures["symmetry"] += 1
    for x, y, z in product(points, repeat=3):
        if dist(x, z) > dist(x, y) + dist(y, z) + slack:
            failures["triangle"] += 1
    return failures


def report[P](label: str, points: Sequence[P], dist: Callable[[P, P], Number], slack: Number) -> dict[str, int]:
    """Print the number of pairs and triples checked, then the failure count for each axiom."""
    failures = axiom_failures(points, dist, slack)
    print(f"{label} points {len(points)} pairs {len(points) ** 2} triples {len(points) ** 3}")
    print("failures " + " ".join(f"{name} {failures[name]}" for name in AXIOMS))
    return failures


def main() -> None:
    """Run Parts A, B and C. Every line is a count, a flag or an exact value, so the output is reproducible."""
    grid = [(i / 2, j / 2) for i in (-2, -1, 0, 1, 2) for j in (-2, -1, 0, 1, 2)]
    print("Part A: Euclidean distance on a 5 by 5 grid of R^2, slack 1e-12")
    report("euclidean", grid, euclidean, SLACK)

    vectors = [tuple(Fraction(v) for v in combo) for combo in product((0, 1, 2), repeat=3)]
    print("Part B: sup distance max_k |f_k - g_k| on vectors of length 3 with entries in {0, 1, 2}, exact")
    report("sup", vectors, sup_distance, Fraction(0))

    integers = [0, 1, 2]
    print("Part C: squared distance (x - y)^2 on the points 0, 1, 2, exact")
    failures = report("squared", integers, squared_distance, 0)
    print(f"squared_triangle_failures {failures['triangle']}")
    print(f"d(0,2) {squared_distance(0, 2)} d(0,1)+d(1,2) {squared_distance(0, 1) + squared_distance(1, 2)}")

Example 1.6 (the sup distance on bounded functions)

Let \(S\) be a nonempty set and let \(B(S)\) be the set of bounded real functions on \(S\). For \(f,g\in B(S)\), set \[ d_{\infty}(f,g)=\sup_{x\in S}\lvert f(x)-g(x)\rvert. \] When \(S=\{1,\dots,N\}\) is finite, the supremum is a maximum, and \(d_{\infty}\) is the max distance used in Part B of Lab 1.

Proposition 1.7 (the sup distance is a metric on B(S))

Hypotheses: (1) \(S\) is a nonempty set; (2) \(f\), \(g\) and \(h\) are bounded real functions on \(S\); (3) \(d_{\infty}\) is as in Example 1.6. Conclusion: \((B(S),d_{\infty})\) is a metric space, and every value \(d_{\infty}(f,g)\) is a real number.

Proof

Finiteness. Choose \(M\) with \(\lvert f(x)\rvert\le M\) and \(\lvert g(x)\rvert\le M\) for all \(x\in S\), which exists by hypothesis (2). Then \(\lvert f(x)-g(x)\rvert\le 2M\). The set \(\{\lvert f(x)-g(x)\rvert : x\in S\}\) is nonempty and bounded above by \(2M\), so its supremum exists by the supremum property of L01, and it is a real number.

M1. Each term \(\lvert f(x)-g(x)\rvert\) is nonnegative, and the supremum of a set of nonnegative numbers is nonnegative. If \(f=g\), every term is zero, so \(d_{\infty}(f,g)=0\). If \(d_{\infty}(f,g)=0\), then each term is at most zero, so \(f(x)=g(x)\) for every \(x\).

M2. \(\lvert f(x)-g(x)\rvert=\lvert g(x)-f(x)\rvert\) for each \(x\), so the two suprema are equal.

M3. Fix \(x\in S\). By the ordinary triangle inequality on \(\R\), \[ \lvert f(x)-h(x)\rvert\le \lvert f(x)-g(x)\rvert+\lvert g(x)-h(x)\rvert\le d_{\infty}(f,g)+d_{\infty}(g,h), \] where the second inequality holds because each term is at most its supremum. The number \(d_{\infty}(f,g)+d_{\infty}(g,h)\) therefore bounds every \(\lvert f(x)-h(x)\rvert\), so it bounds their supremum: \(d_{\infty}(f,h)\le d_{\infty}(f,g)+d_{\infty}(g,h)\). \(\square\)

2Open balls and open sets

Let \((X,d)\) be a metric space, \(x\in X\) and \(r>0\). The open ball of radius \(r\) about \(x\) is \(B(x,r)=\{y\in X : d(x,y)open when for each \(x\in U\) there is \(r>0\) with \(B(x,r)\subseteq U\). A set \(F\subseteq X\) is closed when its complement \(X\setminus F\) is open.

Proposition 2.1 (open balls are open)

Hypotheses: (1) \((X,d)\) is a metric space; (2) \(x\in X\) and \(r>0\). Conclusion: \(B(x,r)\) is an open set.

Proof

Let \(y\in B(x,r)\), and put \(s=r-d(x,y)\). Then \(s>0\). Let \(z\in B(y,s)\). By M3, \(d(x,z)\le d(x,y)+d(y,z)

Remark 2.2 (openness depends on the metric)

Let \(U=(0,1]\) with the Euclidean distance on \(\R\). The set \(U\) is not open. Take \(x=1\) and any \(r>0\). The point \(1+r/2\) lies in \(B(1,r)\) but not in \(U\), so no ball about \(1\) fits inside \(U\). A set can be open for one metric and not for another, so the metric must be named. For example, on \(\R\) with the discrete metric of Example 1.5, every ball \(B(x,1/2)\) is \(\{x\}\), because a point at distance \(0\) is the only point within \(1/2\) of \(x\). So every subset of \(\R\), including \(U=(0,1]\), is open for that metric.

3Convergence, Cauchy sequences and completeness

Definition 3.1 (convergence in a metric space)

A sequence \((x_{n})\) in \((X,d)\) converges to \(x\in X\) when \(d(x_{n},x)\to 0\) as \(n\to\infty\). Written out: for every \(\varepsilon>0\) there is \(N\) such that \(d(x_{n},x)<\varepsilon\) for all \(n\ge N\). The limit of the real sequence \(d(x_{n},x)\) is the sequence limit of Lesson 2, Definition 1.1.

Definition 3.2 (Cauchy sequence and complete space)

A sequence \((x_{n})\) in \((X,d)\) is a Cauchy sequence when for every \(\varepsilon>0\) there is \(N\) such that \(d(x_{m},x_{n})<\varepsilon\) for all \(m,n\ge N\). This is the definition of Cauchy sequence of L02, with \(d(x_{m},x_{n})\) in place of \(\lvert x_{m}-x_{n}\rvert\). The space \((X,d)\) is complete when every Cauchy sequence in \(X\) converges to a point of \(X\).

Proposition 3.3 (convergent sequences are Cauchy)

Hypotheses: (1) \((X,d)\) is a metric space; (2) \((x_{n})\) converges to \(x\in X\). Conclusion: \((x_{n})\) is a Cauchy sequence.

Proof

Let \(\varepsilon>0\). By hypothesis (2) there is \(N\) with \(d(x_{n},x)<\varepsilon/2\) for all \(n\ge N\). For \(m,n\ge N\), M3 and M2 give \(d(x_{m},x_{n})\le d(x_{m},x)+d(x,x_{n})=d(x_{m},x)+d(x_{n},x)<\varepsilon\). \(\square\)

Proposition 3.4 (the plane is complete)

Hypotheses: (1) \((x^{(n)})\) is a Cauchy sequence in \((\R^{2},d_{2})\), with \(x^{(n)}=(x^{(n)}_{1},x^{(n)}_{2})\); (2) the completeness of the real numbers, in the form proved in L02: every Cauchy sequence of real numbers converges to a real number. Conclusion: \((x^{(n)})\) converges in \(\R^{2}\), so \((\R^{2},d_{2})\) is complete.

Proof

For each \(i\in\{1,2\}\), \(\lvert x^{(m)}_{i}-x^{(n)}_{i}\rvert\le d_{2}(x^{(m)},x^{(n)})\), because the square of that coordinate difference is one of the two summands of \(d_{2}^{2}\). So each coordinate sequence is Cauchy in \(\R\), and by hypothesis (2) it converges to a real number \(a_{i}\). Put \(a=(a_{1},a_{2})\). Let \(\varepsilon>0\). Choose \(N\) so that \(\lvert x^{(n)}_{i}-a_{i}\rvert<\varepsilon/2\) for \(i=1,2\) and all \(n\ge N\). Then \(d_{2}(x^{(n)},a)^{2}<\varepsilon^{2}/4+\varepsilon^{2}/4<\varepsilon^{2}\), so \(d_{2}(x^{(n)},a)<\varepsilon\). \(\square\)

Remark 3.5 (the same sequence can converge in one space and not in another)

Let \(x_{n}=1/n\) for \(n\ge 1\). In \(\R\), the sequence converges to \(0\) (Definition 3.1, with the real sequence \(1/n\to 0\)). By Proposition 3.3 it is Cauchy in \(\R\). The next example shows that the same sequence is Cauchy in \((0,1]\) and has no limit there.

Example 3.6 ((0,1] is not complete)

Let \(X=(0,1]\) with the Euclidean distance on \(\R\). The sequence \(x_{n}=1/n\) lies in \(X\). It converges to \(0\) in \(\R\), so it is Cauchy in \(\R\) by Proposition 3.3, and the metric of \(X\) is the restriction of that of \(\R\), so it is Cauchy in \(X\). Suppose it converged in \(X\) to some \(x\in X\). Then \(\lvert x-1/n\rvert\to 0\) and \(1/n\to 0\). By F4, \(\lvert x\rvert\le \lvert x-1/n\rvert+\lvert 1/n\rvert\) for every \(n\). The two terms on the right tend to \(0\) (Definition 3.1, and \(1/n\to 0\)), so their sum does by F5, and F6 with \(c=\lvert x\rvert\) gives \(\lvert x\rvert=0\). That gives \(x=0\), which is not in \(X\). So \(X\) is not complete.

4Continuity between metric spaces

Definition 4.1 (continuity of a map between metric spaces)

Let \((X,d_{X})\) and \((Y,d_{Y})\) be metric spaces, \(f\colon X\to Y\) a function and \(x\in X\). The map \(f\) is continuous at \(x\) when for every \(\varepsilon>0\) there is \(\delta>0\) such that \(d_{X}(x,z)<\delta\) implies \(d_{Y}(f(x),f(z))<\varepsilon\). The map \(f\) is continuous when it is continuous at every point of \(X\). For \(X=Y=\R\) with the absolute value, this is the epsilon–delta continuity of L03.

Proposition 4.2 (continuity by sequences)

Hypotheses: (1) \((X,d_{X})\) and \((Y,d_{Y})\) are metric spaces; (2) \(f\colon X\to Y\) is a function and \(x\in X\). Conclusion: \(f\) is continuous at \(x\) if and only if \(f(x_{n})\to f(x)\) for every sequence \((x_{n})\) in \(X\) with \(x_{n}\to x\).

Proof

(Only if.) Let \(f\) be continuous at \(x\), let \(x_{n}\to x\), and let \(\varepsilon>0\). Take \(\delta\) from Definition 4.1. There is \(N\) with \(d_{X}(x_{n},x)<\delta\) for \(n\ge N\), and for those \(n\), \(d_{Y}(f(x_{n}),f(x))<\varepsilon\). So \(f(x_{n})\to f(x)\).

(If.) Suppose \(f\) is not continuous at \(x\). Then there is \(\varepsilon>0\) such that for every \(n\) no \(\delta=1/n\) works. So for each \(n\) there is \(z_{n}\in X\) with \(d_{X}(x,z_{n})<1/n\) and \(d_{Y}(f(x),f(z_{n}))\ge\varepsilon\). Then \(z_{n}\to x\), but \(f(z_{n})\) does not converge to \(f(x)\), since its distances from \(f(x)\) stay at least \(\varepsilon\). This contradicts the hypothesis, so \(f\) is continuous at \(x\). \(\square\)

Example 4.3 (distance to a fixed point is continuous)

Let \((X,d)\) be a metric space, \(a\in X\), and \(\phi(x)=d(x,a)\), a map from \(X\) to \(\R\). For all \(x,z\), M3 gives \(d(x,a)\le d(x,z)+d(z,a)\), and by M2 the same argument with \(x\) and \(z\) exchanged gives \(d(z,a)\le d(z,x)+d(x,a)\). So \(\lvert\phi(x)-\phi(z)\rvert\le d(x,z)\). Given \(\varepsilon>0\), take \(\delta=\varepsilon\): then \(d(x,z)<\delta\) forces \(\lvert\phi(x)-\phi(z)\rvert<\varepsilon\). Hence \(\phi\) is continuous at every point.

5Where the canon breaks

The axioms are not decoration. The first three failures below show what goes wrong when one part of the definition is dropped or a function is not bounded; the fourth shows that completeness depends on the space.

Without M3. Let \(q(x,y)=(x-y)^{2}\) on \(\R\). It satisfies M1 and M2, and it vanishes only on the diagonal. It fails M3: \(q(0,2)=4\), while \(q(0,1)+q(1,2)=2\). Lab 1, Part C, prints this failure.

Without the "only if" half of M1. The function \(d(x,y)=\lvert x^{2}-y^{2}\rvert\) on \(\R\) satisfies M2 and M3, but \(d(1,-1)=0\) with \(1\ne -1\). A function that is nonnegative, has \(d(x,x)=0\), satisfies M2 and M3, and vanishes at some pair \(x\ne y\) is a pseudometric. This \(d\) is a pseudometric, not a metric, because M1 is needed for \(d\) to separate points.

Without boundedness. The formula of Example 1.6 is a real number when \(f\) and \(g\) are bounded (Proposition 1.7), and not for every pair of functions. For \(S=\R\), \(f(x)=x\) is not bounded, and with \(g=0\) the supremum of \(\lvert f(x)-g(x)\rvert=\lvert x\rvert\) over \(\R\) is \(+\infty\), which is not a real number. So \(f\) is excluded from \(B(\R)\), and Proposition 1.7 is stated on \(B(S)\).

Completeness depends on the space. The sequence \(1/n\) converges in \(\R\) and not in \((0,1]\) (Example 3.6). Completeness is a property of a metric space, not of a sequence.

6Misconceptions

  1. “Any symmetric function that is zero only on the diagonal is a distance.”

    The triangle inequality is an extra requirement. The squared distance \((x-y)^{2}\) is symmetric and vanishes only at equal points, yet Lab 1, Part C, prints two triangle failures on \(\{0,1,2\}\), and the printed values \(d(0,2)=4\) and \(d(0,1)+d(1,2)=2\) show the failure at \((0,1,2)\).

  2. “Every Cauchy sequence converges.”

    This holds in \(\R\) (L02) and in \(\R^{2}\) (Proposition 3.4), but not in every metric space. In \((0,1]\), the sequence \(1/n\) is Cauchy, because its distances are those of \(\R\), where Proposition 3.3 applies (Example 3.6), and it has no limit in the space (Example 3.6).

  3. “A set is open exactly when it is not closed.”

    The set \((0,1]\subseteq\R\) is neither open nor closed. It is not open by Remark 2.2. It is not closed. Its complement contains \(0\), but every open ball about \(0\), of radius \(r\), contains the point \(\min(r/2,1)\), which lies in \((0,1]\). So no ball about \(0\) fits inside the complement, and the complement is not open.

7Problem set

Mechanics

L04 · Mechanics 1 · Euclidean distance

Compute \(d_{2}\) between \(x=(1,2)\) and \(y=(4,-2)\) in \(\R^{2}\).

Solution

The coordinate differences are \(x_{1}-y_{1}=1-4=-3\) and \(x_{2}-y_{2}=2-(-2)=4\). The sum of squares is \(9+16=25\), and \(d_{2}(x,y)=\sqrt{25}=5\). The same value comes from \(d_{2}(y,x)\), by M2.

L04 · Mechanics 2 · Checking a finite metric

Let \(X=\{a,b,c\}\) with \(d(a,b)=2\), \(d(b,c)=2\), \(d(a,c)=3\), \(d(x,x)=0\) for each \(x\), and \(d\) symmetric. Show that \(d\) is a metric.

Solution

M1 holds: the three off-diagonal values are positive and the diagonal values are zero. M2 holds by construction. For M3, take an ordered triple \((x,y,z)\). If \(x=z\), then \(d(x,z)=0\), and the inequality holds because both terms on the right are nonnegative. If \(y=x\) or \(y=z\), one of the two terms on the right is zero and the other equals \(d(x,z)\), so the inequality holds with equality. When \(x,y,z\) are distinct, the six ordered cases are: \(d(a,c)=3\le 2+2\); \(d(c,a)=3\le 2+2\); \(d(a,b)=2\le 3+2\); \(d(b,a)=2\le 2+3\); \(d(b,c)=2\le 2+3\); \(d(c,b)=2\le 3+2\). All hold, so \(d\) is a metric.

L04 · Mechanics 3 · Sup distance of two functions

On \(S=[0,1]\), let \(f(x)=x\) and \(g(x)=x^{2}\). Compute \(d_{\infty}(f,g)\).

Solution

On \([0,1]\), \(\lvert f(x)-g(x)\rvert=x-x^{2}=x(1-x)\ge 0\). Completing the square, \(x-x^{2}=\tfrac14-(x-\tfrac12)^{2}\). The square \((x-\tfrac12)^{2}\) is nonnegative, so \(\lvert f(x)-g(x)\rvert\le\tfrac14\) for every \(x\in[0,1]\), with equality at \(x=\tfrac12\), where \(\lvert f(\tfrac12)-g(\tfrac12)\rvert=\tfrac12-\tfrac14=\tfrac14\). So the supremum is a maximum, \(d_{\infty}(f,g)=1/4\), attained at \(x=1/2\). No limiting argument is needed.

Proof

L04 · Proof 1 · A pseudometric is not a metric

Show that \(d(x,y)=\lvert x^{2}-y^{2}\rvert\) on \(\R\) satisfies M2 and M3 but not M1. Which part of M1 fails?

Solution

M2 holds because \(\lvert x^{2}-y^{2}\rvert=\lvert y^{2}-x^{2}\rvert\). For M3, put \(a=x^{2}\), \(b=y^{2}\), \(c=z^{2}\); the ordinary triangle inequality for absolute values gives \(\lvert a-c\rvert\le\lvert a-b\rvert+\lvert b-c\rvert\), that is, M3. Nonnegativity holds. The "only if" half of M1 fails: \(d(1,-1)=\lvert 1-1\rvert=0\) while \(1\ne -1\).

L04 · Proof 2 · A truncated metric on the line

Prove that \(\rho(x,y)=\min(\lvert x-y\rvert,1)\) is a metric on \(\R\).

Solution

M1 and M2 hold, because \(\min(t,1)\ge 0\) for \(t\ge 0\), \(\min(t,1)=0\) only at \(t=0\), and \(\lvert x-y\rvert=\lvert y-x\rvert\). For M3, put \(a=\lvert x-y\rvert\) and \(b=\lvert y-z\rvert\), so \(\lvert x-z\rvert\le a+b\). If \(a\ge 1\) or \(b\ge 1\), then \(\rho(x,y)+\rho(y,z)\ge 1\ge \rho(x,z)\). Otherwise \(\rho(x,y)+\rho(y,z)=a+b\ge\lvert x-z\rvert\ge\rho(x,z)\). In both cases M3 holds.

L04 · Proof 3 · Uniform closeness implies pointwise closeness

Let \(f_{n},f\in B(S)\). Prove that if \(d_{\infty}(f_{n},f)\to 0\), then \(f_{n}(x)\to f(x)\) for every \(x\in S\).

Solution

Fix \(x\in S\). Each \(\lvert f_{n}(x)-f(x)\rvert\) is one of the terms whose supremum is \(d_{\infty}(f_{n},f)\), so \(\lvert f_{n}(x)-f(x)\rvert\le d_{\infty}(f_{n},f)\). Let \(\varepsilon>0\). By hypothesis there is \(N\) with \(d_\infty(f_{n},f)<\varepsilon\) for all \(n\ge N\), and for those \(n\), \(\lvert f_{n}(x)-f(x)\rvert\le d_\infty(f_{n},f)<\varepsilon\). So \(f_{n}(x)\to f(x)\) in \(\R\), as Definition 3.1 requires.

L04 · Empirical 1 · Reading the Euclidean check

Read Part A of Lab 1. How many triples does the check cover, and how many triangle-inequality failures does the output report? Give the count of triples as \(25^{3}\), and say what the failure count shows.

Solution

There are 25 grid points, so the check covers \(25^{3}=15625\) ordered triples, and the output line reads "triangle 0" with 15625 triples. The zero is a count on the grid of 25 points. It is evidence that the grid has no failure, and Proposition 1.4 is the proof for every point of \(\R^{2}\).

L04 · Empirical 2 · Locating the squared-distance failures

Part C reports two triangle failures for the squared distance on \(\{0,1,2\}\). Identify both triples, and show that no other triple fails.

Solution

A triple \((x,y,z)\) fails when \((x-z)^{2}>(x-y)^{2}+(y-z)^{2}\). If \(x=z\), the left side is zero and nothing fails. For the pair \(\{x,z\}=\{0,2\}\): with \(y=1\), the left side is \(4\) and the right side is \(1+1=2\), so the triples \((0,1,2)\) and \((2,1,0)\) fail. With \(y=0\) or \(y=2\), the right side is \(4\), and the strict inequality fails. For the pair \(\{0,1\}\), the triples are \((0,y,1)\) and \((1,y,0)\), with left side \(1\) and right side \(y^{2}+(y-1)^{2}\), which is \(1\), \(1\), \(5\) for \(y=0,1,2\); the strict inequality never holds. For the pair \(\{1,2\}\), the right side \((1-y)^{2}+(y-2)^{2}\) is \(5\), \(1\), \(1\) for \(y=0,1,2\), again with left side \(1\), so nothing fails. Exactly two triples fail, as the output reports.

L04 · Empirical 3 · Sup distance in Part B

Part B works with vectors of length 3 whose entries lie in \(\{0,1,2\}\). State the number of such vectors, the number of triples the check covers, and the sup distance from \((0,0,0)\) to \((2,1,0)\).

Solution

Each of the 3 entries takes one of 3 values, so there are \(3^{3}=27\) vectors, and the check covers \(27^{3}=19683\) triples. The sup distance is \(\max(\lvert 0-2\rvert,\lvert 0-1\rvert,\lvert 0-0\rvert)=\max(2,1,0)=2\). The output line for Part B reads "triples 19683", which matches \(27^{3}\).

Research

L04 · Research 1 · A bounded metric from a metric

Prove that \(d(x,y)=\dfrac{\lvert x-y\rvert}{1+\lvert x-y\rvert}\) is a metric on \(\R\).

Solution

Let \(\varphi(t)=t/(1+t)\) for \(t\ge 0\). For \(0\le s\le t\), \(\varphi(t)-\varphi(s)=\dfrac{t-s}{(1+t)(1+s)}\ge 0\), so \(\varphi\) is nondecreasing. For \(a,b\ge 0\), \(\varphi(a+b)=\dfrac{a}{1+a+b}+\dfrac{b}{1+a+b}\le \dfrac{a}{1+a}+\dfrac{b}{1+b}=\varphi(a)+\varphi(b)\), because \(1+a+b\ge 1+a\) and \(1+a+b\ge 1+b\). M1 and M2 hold, since \(\varphi(t)\ge 0\) with equality only at \(t=0\). For M3, put \(a=\lvert x-y\rvert\) and \(b=\lvert y-z\rvert\). Then \(\lvert x-z\rvert\le a+b\), so \(d(x,z)=\varphi(\lvert x-z\rvert)\le\varphi(a+b)\le\varphi(a)+\varphi(b)=d(x,y)+d(y,z)\).

L04 · Research 2 · Closed subsets of complete spaces

Let \((X,d)\) be complete and let \(F\subseteq X\) be closed. Prove that \(F\), with the restricted metric, is complete.

Solution

Let \((x_{n})\) be a Cauchy sequence in \(F\). It is Cauchy in \(X\), so it converges to some \(x\in X\). It remains to show \(x\in F\). Suppose \(x\notin F\). Then \(x\) lies in the open set \(X\setminus F\), so some ball \(B(x,r)\) lies in \(X\setminus F\). Since \(x_{n}\to x\), some \(x_{n}\) lies in \(B(x,r)\), but \(x_{n}\in F\). That contradicts \(B(x,r)\subseteq X\setminus F\). So \(x\in F\), and \(x_{n}\to x\) in \(F\), because the distances are the same.

L04 · Research 3 · Constant functions form a complete subspace

Let \(C\subseteq B([0,1])\) be the set of constant functions. Let \(\kappa\colon\R\to C\) send \(c\) to the constant function with value \(c\). Show that \(\kappa\) preserves distances, and deduce that \(C\) is complete.

Solution

For constants \(c,c'\), the difference \(\kappa(c)-\kappa(c')\) is the constant \(c-c'\), so \(d_{\infty}(\kappa(c),\kappa(c'))=\sup_{x}\lvert c-c'\rvert=\lvert c-c'\rvert\). The map \(\kappa\) is therefore distance preserving and onto \(C\). Let \((\kappa(c_{n}))\) be a Cauchy sequence in \(C\). Then \((c_{n})\) is Cauchy in \(\R\), since distances are preserved, so by L02 it converges to some real \(c\). Then \(d_{\infty}(\kappa(c_{n}),\kappa(c))=\lvert c_{n}-c\rvert\to 0\), so \(\kappa(c_{n})\to\kappa(c)\in C\). Hence \(C\) is complete.

9Retrieval quiz

  1. Which three properties make \(d\) a metric?

    Options

    M1 to M3 of Definition 1.1 are nonnegativity with the identity property, symmetry and the triangle inequality. Boundedness is not an axiom of a metric; it is a condition on functions in Example 1.6.

  2. What is \(d_{2}((0,0),(3,4))\) in \(\R^{2}\)?

    The coordinate differences are 3 and 4, and \(\sqrt{9+16}=5\).

  3. Which sequence is Cauchy in \((0,1]\) and has no limit in \((0,1]\)?

    Options

    The sequence \(1/n\) converges to \(0\) in \(\R\), so it is Cauchy by Proposition 3.3. Its only candidate limit is \(0\), which is not in \((0,1]\) (Example 3.6). The constant sequence converges in \((0,1]\), and \((-1)^{n}\) does not lie in \((0,1]\).

  4. Let \(f(x)=x\) and \(g=0\) on \([0,1]\). What is \(d_{\infty}(f,g)\)?

    The supremum of \(\lvert x-0\rvert=x\) over \([0,1]\) is attained at \(x=1\) and equals \(1\).

  5. Which triple of points shows that \((x-y)^{2}\) violates the triangle inequality on \(\R\)?

    Options

    At the triple \((0,1,2)\), the direct squared distance is 4, while the detour through 1 costs \(1+1=2\). Equal points give no violation, since M3 is then an equality.

  6. Is \((0,1]\) an open subset of \(\R\)?

    Options

    Remark 2.2 uses the point \(1\): for each \(r>0\), the point \(1+r/2\) lies in \(B(1,r)\) and outside the set.

  7. How many ordered triples \((x,y,z)\) does Part B of Lab 1 check?

    There are 27 vectors, so \(27^{3}=19683\) ordered triples.

  8. Proposition 3.3 says that a convergent sequence is Cauchy. Which hypothesis does its proof need?

    Options

    The proof bounds \(d(x_{m},x_{n})\) by \(d(x_{m},x)+d(x,x_{n})\) using M3 and M2. Completeness is the conclusion of other results, not an input here.

  9. A set \(F\) is closed when:

    Options

    That is the definition of a closed set in §2. The first option describes an open set, not a closed one, and boundedness is not part of the definition.
