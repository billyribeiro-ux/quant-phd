Continuity in Epsilon–Delta Form

  • Uses: sequences and their convergence (Lesson 2, Definition 1.1), the Archimedean property (Lesson 1, Theorem 1.2), and the M2 limit, which this lesson names but does not use in its definitions
  • Introduces: continuity in epsilon–delta form (defined in §1)
  • Ttheorem, proved on the page
  • Areplicated
  • Bpublished, not settled
  • Csingle study or lab result
  • Dlore
  • Xrefuted

Informally, continuity means that a small change in the input produces a small change in the output. This lesson gives the epsilon–delta definition of continuity, proves it for \(x^2\) at \(x_0 = 2\) with an explicit \(\delta\), and proves that continuity at a point is equivalent to the behaviour of every sequence that converges to that point. Lab 1 checks the explicit \(\delta\) on an exact grid, and Section 3 shows that for \(x^2\) and \(\varepsilon = 1\) no single \(\delta\) serves every point, so the \(\delta\) depends on the point as well as on the tolerance.

1Continuity at a point and on a set

Let \(D\) be a subset of \(\R\), let \(f \colon D \to \R\) be a function, and let \(x_0 \in D\).

Definition 1.1 (continuity, epsilon–delta form)

The function \(f\) is continuous at \(x_0\) when for every \(\varepsilon > 0\) there is \(\delta > 0\) such that every \(x \in D\) with \(|x - x_0| < \delta\) satisfies \(|f(x) - f(x_0)| < \varepsilon\). The function \(f\) is continuous on \(D\) when it is continuous at every point of \(D\).

The number \(\delta\) depends on \(\varepsilon\) and on \(x_0\). The definition asks for one \(\delta\) for each pair of \(\varepsilon\) and \(x_0\). Proposition 3.1 (§3) shows that for \(x^2\) on \(\R\) and \(\varepsilon = 1\), no single \(\delta\) serves every point.

Proposition 1.4 shows that \(x \mapsto x^2\) is continuous at \(2\). The proof uses Lemma 1.3, a bound on \(|x^2 - 4|\) near \(2\), which is proved first.

Lemma 1.3 (a bound for \(x^2 - 4\) near 2)
  1. (H1) \(x\) is a real number with \(|x - 2| \le 1\).

Conclusion: \(|x^2 - 4| \le 5\,|x - 2|\).

Proof

Write \(x^2 - 4 = (x - 2)(x + 2)\), so \(|x^2 - 4| = |x - 2|\,|x + 2|\). Also \(x + 2 = (x - 2) + 4\), so the triangle inequality and (H1) give \(|x + 2| \le |x - 2| + 4 \le 1 + 4 = 5\). Therefore \(|x^2 - 4| = |x - 2|\,|x + 2| \le 5\,|x - 2|\). \(\blacksquare\)

Proposition 1.4 (\(x^2\) is continuous at 2)
  1. (H1) \(D = \R\) and \(f(x) = x^2\), with \(x_0 = 2\).

Conclusion: \(f\) is continuous at 2, with \(\delta = \min\{1, \varepsilon/5\}\) working for each \(\varepsilon > 0\).

Proof

Let \(\varepsilon > 0\) and put \(\delta = \min\{1, \varepsilon/5\}\), which is positive. Let \(x\) satisfy \(|x - 2| < \delta\). Then \(|x - 2| < \delta \le 1\), so Lemma 1.3 applies: \(|x^2 - 4| \le 5|x - 2|\). Since \(|x - 2| < \delta\) and \(5\delta \le \varepsilon\), we get \(5|x - 2| < 5\delta \le \varepsilon\). So \(|f(x) - f(2)| = |x^2 - 4| < \varepsilon\). \(\blacksquare\)

Proposition 1.5 (sums of continuous functions)
  1. (H1) \(f\) and \(g\) are functions from \(D\) to \(\R\), and \(x_0 \in D\).
  2. (H2) \(f\) is continuous at \(x_0\), and \(g\) is continuous at \(x_0\).

Conclusion: \(f + g\) is continuous at \(x_0\).

Proof

Let \(\varepsilon > 0\). By (H2), with \(\varepsilon/2\) in place of \(\varepsilon\), there are \(\delta_f\) and \(\delta_g\) such that \(|x - x_0| < \delta_f\) gives \(|f(x) - f(x_0)| < \varepsilon/2\), and \(|x - x_0| < \delta_g\) gives \(|g(x) - g(x_0)| < \varepsilon/2\). Put \(\delta = \min\{\delta_f, \delta_g\}\). If \(|x - x_0| < \delta\), then \(|(f + g)(x) - (f + g)(x_0)| \le |f(x) - f(x_0)| + |g(x) - g(x_0)| < \varepsilon\). \(\blacksquare\)

Lab 1 · An epsilon–delta check for \(x^2\) at 2 on an exact grid

Predicted before running. The grid consists of the 401 points \(2 + k/200\) for integers \(k\) from \(-200\) to \(200\), so every grid point satisfies \(|x - 2| \le 1\). The bound of Lemma 1.3 should hold at all 401 points. For \(\varepsilon = 1/10\), the choice \(\delta = \min\{1, \varepsilon/5\} = 1/50\) should admit exactly 7 grid points, namely \(k\) from \(-3\) to \(3\), and all 7 should satisfy \(|x^2 - 4| < 1/10\). For \(\delta = 1/10\), the first failing grid point should be \(381/200\), and 29 grid points with \(|x - 2| < 1/10\) should have \(|x^2 - 4| \ge 1/10\).

"""M5 lab L03: an epsilon-delta check for f(x) = x * x at x0 = 2, on an exact grid.

Standard library only. No randomness and no network. The grid is x = 2 + k/200 for integers k with
|k| <= 200, so every grid point satisfies |x - 2| <= 1, the range in which the page proves the bound
|x * x - 4| <= 5 |x - 2|. All comparisons use fractions.Fraction, so each printed count is exact.
The lab checks the bound and the choice delta = min(1, eps / 5) on this grid only. A grid check is
evidence about the grid. The page's proof covers every x with |x - 2| <= 1.
"""

from __future__ import annotations

from fractions import Fraction

X0 = Fraction(2)
K_MAX = 200
EPS = Fraction(1, 10)


def f(x: Fraction) -> Fraction:
    """The function f(x) = x * x."""
    return x * x


def grid() -> list[Fraction]:
    """The points x = 2 + k/200 for integers k with -200 <= k <= 200, in increasing order."""
    return [X0 + Fraction(k, K_MAX) for k in range(-K_MAX, K_MAX + 1)]


def delta_for(eps: Fraction) -> Fraction:
    """The delta the page proves works for eps: min(1, eps / 5)."""
    return min(Fraction(1), eps / 5)


def main() -> None:
    points = grid()
    bound_holds = sum(abs(f(x) - 4) <= 5 * abs(x - X0) for x in points)
    print(f"bound |x*x - 4| <= 5|x - 2| on the grid: holds at {bound_holds} of {len(points)} points")

    delta = delta_for(EPS)
    inside = [x for x in points if abs(x - X0) < delta]
    good = sum(abs(f(x) - 4) < EPS for x in inside)
    print(f"delta = {delta}: points with |x - 2| < delta: {len(inside)}")
    print(f"of those, points with |x*x - 4| < 1/10: {good} of {len(inside)}")

    too_large = Fraction(1, 10)
    failing = [x for x in points if abs(x - X0) < too_large and abs(f(x) - 4) >= EPS]
    first = failing[0]
    print(f"delta = {too_large} fails: first failing grid point x = {first}, with |x*x - 4| = {abs(f(first) - 4)}")
    print(f"grid points with |x - 2| < {too_large} and |x*x - 4| >= 1/10: {len(failing)}")


main()

The middle lines show that the choice \(\delta = 1/50\) is valid on the grid, and that it admits 7 points, which are the \(x\) values with \(|k| \le 3\). The last lines show that \(\delta = 1/10\) is not a valid choice for \(\varepsilon = 1/10\): the first grid point it fails at is \(381/200\), where \(|x^2 - 4| = 14839/40000\), which is \(0.370975\). 2The sequential characterization

Proposition 2.1 (sequential characterization)
  1. (H1) \(D \subseteq \R\), \(f \colon D \to \R\), and \(x_0 \in D\).

Conclusion: \(f\) is continuous at \(x_0\) if and only if for every sequence \((x_n)\) with every \(x_n \in D\) and \(x_n \to x_0\) (Lesson 2, Definition 1.1), the sequence \(f(x_n)\) converges to \(f(x_0)\).

Proof

Continuity implies the sequential property. Let \((x_n)\) be a sequence in \(D\) with \(x_n \to x_0\), and let \(\varepsilon > 0\). Choose \(\delta\) as in Definition 1.1. Since \(x_n \to x_0\), there is \(N\) with \(|x_n - x_0| < \delta\) for \(n \ge N\). For these \(n\), \(|f(x_n) - f(x_0)| < \varepsilon\). So \(f(x_n) \to f(x_0)\).

The sequential property implies continuity. Suppose \(f\) is not continuous at \(x_0\). Then there is \(\varepsilon_0 > 0\) such that for every \(\delta > 0\) some \(x \in D\) satisfies \(|x - x_0| < \delta\) and \(|f(x) - f(x_0)| \ge \varepsilon_0\). For each \(n \in \N\), take \(\delta = 1/n\) and choose such an \(x_n \in D\). Then \(|x_n - x_0| < 1/n\). The sequence \((x_n)\) converges to \(x_0\): given \(\varepsilon > 0\), Lesson 1, Theorem 1.2 gives \(N\) with \(N > 1/\varepsilon\), and for \(n \ge N\), \(|x_n - x_0| < 1/n \le 1/N < \varepsilon\). But \(|f(x_n) - f(x_0)| \ge \varepsilon_0\) for every \(n\), so \(f(x_n)\) does not converge to \(f(x_0)\). \(\blacksquare\)

Proposition 2.2 (sequential check of \(x^2\) at 2)
  1. (H1) \(f(x) = x^2\) on \(\R\), and \((x_n)\) is a real sequence with \(x_n \to 2\).

Conclusion: \(x_n^2 \to 4\).

Proof

Let \(\varepsilon > 0\). Since \(x_n \to 2\) (Lesson 2, Definition 1.1), there is \(N\) with \(|x_n - 2| < \min\{1, \varepsilon/5\}\) for \(n \ge N\). For those \(n\), \(|x_n - 2| \le 1\), so Lemma 1.3 gives \(|x_n^2 - 4| \le 5|x_n - 2| < 5 \cdot \varepsilon/5 = \varepsilon\). Hence \(x_n^2 \to 4\). \(\blacksquare\)

3Uniform continuity: one \(\delta\) for all points

Say that \(f\) is uniformly continuous on \(D\) when for every \(\varepsilon > 0\) there is one \(\delta > 0\) with \(|f(x) - f(y)| < \varepsilon\) whenever \(x, y \in D\) and \(|x - y| < \delta\). Uniform continuity asks for one \(\delta\) for all points at once. Proposition 3.1 shows that \(x^2\) on \(\R\) does not have this property.

Proposition 3.1 (\(x^2\) is not uniformly continuous on \(\R\))
  1. (H1) \(f(x) = x^2\) on \(\R\), and \(\varepsilon = 1\).

Conclusion: for every \(\delta > 0\) there are \(x, y \in \R\) with \(|x - y| < \delta\) and \(|f(x) - f(y)| \ge 1\).

Proof

Let \(\delta > 0\). Put \(x = 1/\delta\) and \(y = x + \delta/2\), so \(|x - y| = \delta/2 < \delta\). Then \(f(y) - f(x) = (x + \delta/2)^2 - x^2 = x\delta + \delta^2/4 \ge x\delta = 1\), since \(x\delta = 1\) and \(\delta^2/4 \ge 0\). \(\blacksquare\)

4Where the canon breaks

Continuity at a point is local, and its \(\delta\) depends on the point. Two examples show what goes wrong when a part of the definition is dropped or moved.

  • A single \(\delta\) for all points fails for \(x^2\). Proposition 3.1 shows that \(x^2\) on \(\R\) is not uniformly continuous, the property defined in §3. Proposition 1.4 gave \(\delta\) that depends on the point \(2\); for \(\varepsilon = 1\), no single \(\delta\) can serve every point.
  • A value at the point is not enough. Let \(f(x) = x\) for \(x \ne 1\) and \(f(1) = 5\). For \(\varepsilon = 1\) and any \(\delta > 0\), the point \(x = 1 + \min\{\delta, 1\}/2\) satisfies \(0 < x - 1 < \delta\) and \(|f(x) - f(1)| = |x - 5| = 5 - x \ge 3.5\). So \(f\) is not continuous at 1, although \(f(1)\) is defined.

5Misconceptions

  1. “One \(\delta\) serves every \(\varepsilon\) and every point.”

    The \(\delta\) in Definition 1.1 depends on \(\varepsilon\) and on \(x_0\). Proposition 1.4 gives \(\delta = \min\{1, \varepsilon/5\}\) at the point 2. The same choice fails at the point 10 when \(\varepsilon = 1\): then \(\delta = 1/5\), and the point \(x = 10.1\) satisfies \(|x - 10| = 0.1 < 1/5\) while \(|x^2 - 100| = 2.01 \ge 1\). Proposition 3.1 shows that, for \(\varepsilon = 1\), no single \(\delta\) works for all points of \(\R\) at once.

  2. “A function that is defined at \(x_0\) is continuous there.”

    The example \(f(x) = x\) for \(x \ne 1\), with \(f(1) = 5\), is defined at 1 and is not continuous there (canon break, second item). Continuity compares \(f(x)\) with \(f(x_0)\) for \(x\) near \(x_0\), and the value \(f(x_0)\) must agree with those nearby values.

  3. “One sequence converging to \(x_0\) with \(f(x_n) \to f(x_0)\) shows continuity.”

    Let \(f(x) = 0\) when \(x = 0\) or \(x = 1/k\) for some \(k \in \N\), and \(f(x) = 1\) otherwise, with \(x_0 = 0\). The sequence \(x_n = 1/n\) gives \(f(x_n) = 0 = f(0)\). But \(y_n = 2/(2n + 1)\) tends to 0, because \(0 < y_n \le 1/n\), so \(|y_n| < \varepsilon\) once \(n > 1/\varepsilon\) (Lesson 1, Theorem 1.2), and \(y_n\) is not of the form \(1/k\), so \(f(y_n) = 1\) for every \(n\), which does not converge to \(f(0) = 0\). By Proposition 2.1, \(f\) is not continuous at 0. Proposition 2.1 needs every sequence, not one.

6Problem set

Every problem has a full worked solution. Attempt each one before opening it. Problems marked E use the output of Lab 1.

Mechanics

M1 · A delta for \(3x + 1\)

For \(f(x) = 3x + 1\) at \(x_0 = 2\), show that \(\delta = \varepsilon/3\) works for each \(\varepsilon > 0\).

Solution

Here \(f(2) = 7\), and \(|f(x) - f(2)| = |3x - 6| = 3|x - 2|\). If \(|x - 2| < \varepsilon/3\), then \(3|x - 2| < \varepsilon\). So \(\delta = \varepsilon/3\) works.

M2 · The delta of Proposition 1.4 for \(\varepsilon = 1/10\)

Compute the \(\delta\) that Proposition 1.4 gives for \(x^2\) at 2 with \(\varepsilon = 1/10\), and check that every \(x\) with \(|x - 2| < \delta\) satisfies \(|x^2 - 4| < 1/10\).

Solution

\(\delta = \min\{1, (1/10)/5\} = \min\{1, 1/50\} = 1/50\). If \(|x - 2| < 1/50\), then \(|x - 2| \le 1\), so Lemma 1.3 gives \(|x^2 - 4| \le 5|x - 2| < 5/50 = 1/10\).

M3 · A delta for \(1/x\) at 1

Show that \(\delta = 1/20\) works for \(f(x) = 1/x\) at \(x_0 = 1\) with \(\varepsilon = 1/10\), on the domain \((0, \infty)\).

Solution

Let \(|x - 1| < 1/20\). Then \(x > 19/20\), and \(|1/x - 1| = |x - 1|/x < (1/20)/(19/20) = 1/19\). Since \(1/19 < 1/10\), we get \(|1/x - 1| < 1/10\).

Proof

P1 · The absolute value is continuous

Prove that \(f(x) = |x|\) is continuous at every \(x_0 \in \R\).

Solution

For all real \(x\) and \(x_0\), the triangle inequality gives \(\bigl||x| - |x_0|\bigr| \le |x - x_0|\). Given \(\varepsilon > 0\), put \(\delta = \varepsilon\). If \(|x - x_0| < \delta\), then \(\bigl||x| - |x_0|\bigr| \le |x - x_0| < \varepsilon\).

P2 · The absolute value of a continuous function

Let \(f \colon D \to \R\) be continuous at \(x_0 \in D\). Prove that \(|f|\) is continuous at \(x_0\).

Solution

For every \(x \in D\), \(\bigl||f(x)| - |f(x_0)|\bigr| \le |f(x) - f(x_0)|\). Given \(\varepsilon > 0\), take \(\delta\) from the continuity of \(f\) at \(x_0\). For \(|x - x_0| < \delta\), the inequality gives \(\bigl||f(x)| - |f(x_0)|\bigr| < \varepsilon\).

P3 · \(x^2\) is continuous at every point

Prove that \(f(x) = x^2\) is continuous at every \(x_0 \in \R\), with \(\delta = \min\{1, \varepsilon/(1 + 2|x_0|)\}\).

Solution

Let \(|x - x_0| < \delta \le 1\). Then \(|x + x_0| = |(x - x_0) + 2x_0| \le |x - x_0| + 2|x_0| \le 1 + 2|x_0|\). So \(|x^2 - x_0^2| = |x - x_0|\,|x + x_0| \le (1 + 2|x_0|)|x - x_0| < (1 + 2|x_0|)\delta \le \varepsilon\). The bound on \(\delta\) is what makes the last step hold.

Empirical

E1 · The bound at the failing point

Lab 1 checks Lemma 1.3 at every grid point. Check it by hand at \(x = 381/200\), and state both sides as exact fractions.

Solution

\(x - 2 = -19/200\), so \(5|x - 2| = 95/200 = 0.475\). Also \(x^2 = 145161/40000\), so \(|x^2 - 4| = 14839/40000 = 0.370975\). Since \(0.370975 \le 0.475\), the bound holds at this point, as the lab's count of 401 of 401 predicts.

E2 · The seven points admitted by \(\delta = 1/50\)

Lab 1 says that \(\delta = 1/50\) admits 7 grid points. List them, and explain the count from the grid spacing.

Solution

The grid points are \(2 + k/200\). The condition \(|x - 2| < 1/50\) becomes \(|k|/200 < 1/50\), that is, \(|k| < 4\), so \(k\) runs over \(-3, \dots, 3\). The points are \(397/200, 199/100, 399/200, 2, 401/200, 201/100, 403/200\), which is 7 points. For each, \(|x^2 - 4| < 1/10\), which the lab confirms.

E3 · The count of 29 for \(\delta = 1/10\)

Lab 1 says that 29 grid points have \(|x - 2| < 1/10\) and \(|x^2 - 4| \ge 1/10\). Explain the count.

Solution

Write \(x = 2 + k/200\). Then \(|x - 2| < 1/10\) means \(|k| \le 19\), and \(x^2 - 4 = (k/200)(4 + k/200)\). For \(k > 0\) the condition \(|x^2 - 4| \ge 1/10\) is \(k(4 + k/200) \ge 20\). At \(k = 4\) the left side is \(16.08\), and at \(k = 5\) it is \(20.125\), so \(k\) runs from 5 to 19: 15 values. For \(k < 0\), with \(j = -k\), the condition is \(j(4 - j/200) \ge 20\). At \(j = 5\) the left side is \(19.875\), and at \(j = 6\) it is \(23.82\), so \(j\) runs from 6 to 19: 14 values. Total 29, which the lab prints.

Research

R1 · The sharp constant in Lemma 1.3

Show that 5 is the least constant \(c\) such that \(|x^2 - 4| \le c|x - 2|\) for every real \(x\) with \(|x - 2| \le 1\).

Solution

The constant \(c = 5\) works by Lemma 1.3. Suppose \(c < 5\). Take \(x = 3\), which satisfies \(|x - 2| = 1 \le 1\). Then \(|x^2 - 4| = 5\), but \(c|x - 2| = c < 5\). So the inequality fails for every \(c < 5\), and 5 is the least constant.

R2 · A grid check cannot prove continuity

Let \(g(x) = x^2\) for \(x\) on the grid of Lab 1, and \(g(x) = x^2 + 1\) for every other real \(x\). Show that \(g\) passes the grid check of Lab 1 at \(\varepsilon = 1/10\) with \(\delta = 1/50\), and that \(g\) is not continuous at 2.

Solution

The grid check uses only grid points, and at grid points \(g(x) = x^2\). So the 7 points with \(|x - 2| < 1/50\) satisfy \(|g(x) - g(2)| = |x^2 - 4| < 1/10\), and the check passes. But take \(\varepsilon_0 = 1\). For any \(\delta > 0\), let \(x = 2 + h\) with \(0 < h < \min\{\delta, 1/200\}\). Then \(x\) is not a grid point, because the grid points differ by multiples of \(1/200\) from 2 and \(0 < h < 1/200\). So \(g(x) = x^2 + 1\), and \(|g(x) - g(2)| = |x^2 - 3| \ge 1\), since \(x^2 \ge 4\). So \(g\) is not continuous at 2.

R3 · The maximum of two continuous functions

Let \(f\) and \(g\) be continuous at \(x_0\). Prove that \(\max\{f, g\}\) is continuous at \(x_0\), using the inequality \(|\max\{a, b\} - \max\{c, d\}| \le \max\{|a - c|, |b - d|\}\), which you must also prove.

Solution

Let \(M = \max\{a, b\}\) and \(N = \max\{c, d\}\). By symmetry assume \(M = a\). Then \(M - N \le a - c \le |a - c|\), because \(N \ge c\). If \(N = c\), then \(N - M = c - a \le |a - c|\). If \(N = d\), then \(N - M = d - a \le d - b \le |b - d|\), because \(a \ge b\). In each case \(|M - N| \le \max\{|a - c|, |b - d|\}\). For the continuity, let \(h(x) = \max\{f(x), g(x)\}\). Given \(\varepsilon > 0\), take \(\delta\) that works for both \(f\) and \(g\) at \(\varepsilon\), which is the minimum of the two deltas. For \(|x - x_0| < \delta\), the inequality gives \(|h(x) - h(x_0)| \le \max\{|f(x) - f(x_0)|, |g(x) - g(x_0)|\} < \varepsilon\).
