Contraction Mappings and the Banach Fixed-Point Theorem

  • Uses: completeness of the real numbers, Cauchy sequence, continuity on \(\R\) (epsilon–delta), continuity between metric spaces (L04, Definition 4.1), uniform convergence, metric space, limit, derivative, definite integral
  • Introduces: contraction mapping, Banach fixed-point theorem
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study
  • Dlore
  • Xrefuted

An iteration \(x_{n+1} = f(x_n)\) finds a solution of \(x = f(x)\) when its iterates converge to one, and not every map makes them converge: \(x\mapsto -x\) sends \(1\) to \(-1\) and back. A contraction (Definition 1.1) pulls every pair of distinct points strictly closer together by a fixed factor \(\beta<1\). On a nonempty complete space (Definition 1.2), such a map has exactly one fixed point, the iterates reach it from any start, and the distance from each iterate to it is bounded by a geometric term computed from the first two iterates and \(\beta\). The lesson proves this and shows which hypothesis each step uses. Lesson 8 applies Theorem 2.1 to an operator that it defines by formula.

1Contractions and the completeness they need

Let \((X, d)\) be a metric space, as defined in Lesson 4. Its distance \(d(x, y)\) is a nonnegative real number, with \(d(x, y) = 0\) only when \(x = y\), and it satisfies the triangle inequality. A map \(\varphi \colon X \to X\) sends each point of \(X\) to a point of \(X\). A fixed point of \(\varphi\) is a point \(\bar x\) with \(\varphi \bar x = \bar x\).

Definition 1.1 (contraction mapping)

Let \(\beta\) be a real number with \(0 < \beta < 1\). A map \(\varphi \colon X \to X\) is a contraction mapping with modulus \(\beta\) if \[ d(\varphi x, \varphi y) \le \beta\, d(x, y) \qquad \text{for all } x, y \in X. \] The number \(\beta\) is the modulus. The inequality is required for every pair of points, with the same \(\beta\) for all pairs.

Definition 1.2 (complete metric space)

A metric space \((X, d)\) is complete when every Cauchy sequence in \(X\) converges to a point of \(X\). Lesson 2 defines a Cauchy sequence. Lesson 2, Theorem 2.5 gives the completeness of \(\mathbb{R}\), with \(d(x, y) = |x - y|\), in the form that every Cauchy sequence of real numbers converges; that theorem is proved in Lesson 2 from the completeness axiom (Lesson 1, Definition 1.1). A closed interval \([a, b]\) with the distance \(|x - y|\) is complete too: a Cauchy sequence in \([a, b]\) converges in \(\mathbb{R}\) to some \(x\), and \(a \le x \le b\) because \(a \le x_n \le b\) for every term.

Example 1.3 (a linear contraction)

Let \(X = \mathbb{R}\) and \(\varphi x = x/3 + 2\). For all \(x, y\), \(|\varphi x - \varphi y| = |x - y|/3\), so \(\varphi \) is a contraction with modulus \(1/3\). The point \(3\) is fixed, because \(3/3 + 2 = 3\).

Proposition 1.4 (a contraction is continuous)

Hypotheses: (1) \((X, d)\) is a metric space; (2) \(\varphi \colon X \to X\) satisfies \(d(\varphi x, \varphi y) \le \beta\, d(x, y)\) for all \(x, y\), where \(0 < \beta < 1\). Conclusion: \(\varphi \) is continuous at every point of \(X\).

Proof

Fix \(x_0 \in X\) and \(\varepsilon > 0\). Let \(d(x, x_0) < \varepsilon\). By hypothesis (2), \(d(\varphi x, \varphi x_0) \le \beta\, d(x, x_0)\). Since \(0 < \beta < 1\) and \(d(x, x_0) \ge 0\), we have \(\beta\, d(x, x_0) \le d(x, x_0) < \varepsilon\). So \(d(\varphi x, \varphi x_0) < \varepsilon\), which is the continuity condition at \(x_0\) with \(\delta = \varepsilon\).

2The Banach fixed-point theorem

Theorem 2.1 (Banach fixed-point theorem)

Hypotheses:

  1. \((X, d)\) is a complete metric space, and \(X\) is nonempty.
  2. \(\varphi \colon X \to X\) is a contraction mapping with modulus \(\beta\), where \(0 < \beta < 1\).
  3. \(x_0\) is a point of \(X\), and \(x_{n+1} = \varphi x_n\) for \(n = 0, 1, 2, \ldots\).

Conclusion:

  1. \(\varphi \) has exactly one fixed point \(\bar x\), that is, exactly one point with \(\varphi \bar x = \bar x\).
  2. \(x_n \to \bar x\), for every starting point \(x_0\).
  3. For every \(n \ge 0\), \[ d(x_n, \bar x) \le \frac{\beta^{n}}{1 - \beta}\, d(x_0, x_1). \] This is the a priori bound. It uses only \(x_0\), \(x_1\) and the modulus \(\beta\), so it is known once \(x_1\) is computed, before the later iterates.
Lemma 2.2 (the step estimate)

Hypotheses: (1)–(3) of Theorem 2.1, with \(c = d(x_0, x_1)\). Conclusion: for every \(k \ge 0\), \(d(x_{k+1}, x_k) \le \beta^{k} c\). For all integers \(m > n \ge 0\), \[ d(x_n, x_m) \le \frac{\beta^{n}}{1 - \beta}\, c. \]

Proof of Lemma 2.2

The first claim holds for \(k = 0\) by the definition of \(c\). If \(d(x_{k+1}, x_k) \le \beta^{k} c\), then \(d(x_{k+2}, x_{k+1}) = d(\varphi x_{k+1}, \varphi x_k) \le \beta\, d(x_{k+1}, x_k) \le \beta^{k+1} c\), which completes the induction.

Let \(m > n\). The triangle inequality, applied \(m - n\) times, and the first claim give \[ d(x_n, x_m) \le \sum_{k=n}^{m-1} d(x_k, x_{k+1}) \le c \sum_{k=n}^{m-1} \beta^{k} = c\,\beta^{n}\,\frac{1 - \beta^{m-n}}{1 - \beta} \le \frac{c\,\beta^{n}}{1 - \beta}. \] The last step uses \(0 < \beta^{m-n} \le 1\). The geometric sum is valid because \(\beta \ne 1\).

Proof of Theorem 2.1

Step 1: the iterates form a Cauchy sequence. Let \(c = d(x_0, x_1)\) and \(\varepsilon > 0\). Since \(\beta^{n} \to 0\) (because \(0 < \beta < 1\)), there is an \(N\) with \(\beta^{N} c / (1 - \beta) < \varepsilon\). For \(m > n \ge N\), Lemma 2.2 gives \(d(x_n, x_m) \le \beta^{n} c/(1 - \beta) \le \beta^{N} c/(1 - \beta) < \varepsilon\). So \((x_n)\) is Cauchy.

Step 2: the limit exists. By hypothesis (1), the Cauchy sequence converges to some \(\bar x \in X\).

Step 3: the limit is fixed. By Proposition 1.4, \(\varphi \) is continuous, so \(\varphi x_n \to \varphi \bar x\). But \(\varphi x_n = x_{n+1}\), and \(x_{n+1} \to \bar x\). A sequence has at most one limit: if \(p\) and \(q\) were both limits of \(a_n\), then \(d(p, q) \le d(p, a_n) + d(a_n, q) \to 0\). Hence \(\varphi \bar x = \bar x\). This proves existence in (a) and the convergence in (b), since \(x_n \to \bar x\) for every starting point.

Step 4: uniqueness. Let \(y\) and \(z\) be fixed points. Then \(d(y, z) = d(\varphi y, \varphi z) \le \beta\, d(y, z)\), so \((1 - \beta)\, d(y, z) \le 0\). Since \(1 - \beta > 0\) and \(d(y, z) \ge 0\), we get \(d(y, z) = 0\), so \(y = z\).

Step 5: the bound. Fix \(n\). For \(m > n\), the triangle inequality gives \(|d(x_n, x_m) - d(x_n, \bar x)| \le d(x_m, \bar x) \to 0\). Letting \(m \to \infty\) in Lemma 2.2 yields \(d(x_n, \bar x) \le \beta^{n} c / (1 - \beta)\), which is (c).

Example 2.3 (the bound is exact for \(\varphi x = x/3 + 2\))

Take \(\varphi x = x/3 + 2\) on \(\mathbb{R}\) from \(x_0 = 0\). Then \(x_1 = 2\), so \(c = 2\), and \(x_n = 3 - 3\cdot 3^{-n}\). The error is \(|x_n - 3| = 3 \cdot 3^{-n}\). The bound of Theorem 2.1(c) is \((1/3)^{n} \cdot 2/(2/3) = 3 \cdot 3^{-n}\). The two agree at every \(n\), so for this map from this start the bound cannot be improved.

Proposition 2.4 (bounded continuous functions form a complete space)

Hypotheses: (1) \(S\) is a metric space; (2) \(C_b(S)\) is the set of bounded continuous functions \(f\colon S \to \mathbb{R}\); (3) \(d_\infty(f, g) = \sup_{s \in S} |f(s) - g(s)|\), which is finite for \(f, g \in C_b(S)\); (4) every Cauchy sequence of real numbers converges (Lesson 2, Theorem 2.5). Conclusion: \((C_b(S), d_\infty)\) is a complete metric space.

Proof

Distance. \(d_\infty\) is finite, nonnegative, symmetric and satisfies the triangle inequality, because it is a supremum of the corresponding inequalities for \(|f(s) - g(s)|\). It is zero only when \(f = g\).

Pointwise limit. Let \((f_n)\) be Cauchy for \(d_\infty\). For each \(s\), \(|f_n(s) - f_m(s)| \le d_\infty(f_n, f_m)\), so \((f_n(s))_n\) is Cauchy in \(\mathbb{R}\). By hypothesis (4) it converges to a number \(f(s)\).

Uniform convergence. Let \(\varepsilon > 0\), and choose \(N\) with \(d_\infty(f_n, f_m) \le \varepsilon\) for \(n, m \ge N\). Fix \(n \ge N\) and \(s\), and let \(m \to \infty\) in \(|f_n(s) - f_m(s)| \le \varepsilon\). This gives \(|f_n(s) - f(s)| \le \varepsilon\) for every \(s\), so \(\sup_s |f_n(s) - f(s)| \le \varepsilon\) for \(n \ge N\).

The limit lies in \(C_b(S)\). Boundedness: \(|f(s)| \le |f_N(s)| + \varepsilon \le \sup_t |f_N(t)| + \varepsilon\) for every \(s\). Continuity: fix \(s_0\) and \(\varepsilon > 0\). Choose \(n\) with \(\sup_s |f_n(s) - f(s)| \le \varepsilon/3\). Since \(f_n\) is continuous, there is \(\delta > 0\) with \(|f_n(s) - f_n(s_0)| < \varepsilon/3\) when the distance from \(s\) to \(s_0\) is below \(\delta\). For such \(s\), \(|f(s) - f(s_0)| \le |f(s) - f_n(s)| + |f_n(s) - f_n(s_0)| + |f_n(s_0) - f(s_0)| < \varepsilon\). So \(f\) is continuous at \(s_0\).

Hence \(f \in C_b(S)\), and \(d_\infty(f_n, f) \to 0\). Every Cauchy sequence converges, so the space is complete.

3From a derivative bound to a contraction

Two calculus facts are assumed in this section without proof. They are numbered Assumption 1 and Assumption 2, and each result that uses them says so. Each is a standard result of the calculus that Lesson 1 and Lesson 2 do not cover, and it is listed here so that every hypothesis is visible.

Assumption 1 (fundamental theorem of calculus)

If \(f\) is continuously differentiable on \([a, b]\) and \(a \le x \le y \le b\), then \(f(y) - f(x) = \int_x^y f'(t)\,dt\), where the integral is a definite integral. If \(|g(t)| \le L\) for every \(t\) in \([x, y]\), then \(\left| \int_x^y g(t)\,dt \right| \le L\,(y - x)\).

Assumption 2 (sine and cosine on \([0, 1]\))

(a) The function \(\sin\) is strictly increasing on \([0, 1]\), and \(\sin 0 = 0\). (b) For every \(t\) in \([0, 1]\), \(0 < \cos t \le 1\). (c) The derivative of \(\cos\) is \(-\sin\), and the derivative of \(\sin\) is \(\cos\). (d) \(\sin 1<1\). Assumption 2(a) gives \(0 \le \sin t \le \sin 1\) on \([0, 1]\), and \(\sin t < \sin 1\) for \(t < 1\).

Proposition 3.1 (a derivative bound controls differences)

Assuming Assumption 1. Hypotheses: (1) \(I = [a, b]\) with \(a < b\); (2) \(f\colon I \to \mathbb{R}\) is continuously differentiable; (3) \(L = \sup_{t \in I} |f'(t)|\) is finite. Conclusion: for all \(x, y \in I\), \[ |f(x) - f(y)| \le L\,|x - y|. \] An inequality of this form, with one constant \(L\) for all pairs of points, is a Lipschitz bound with constant \(L\).

Proof

By symmetry, take \(x \le y\); the case \(x > y\) follows by exchanging the two points. By Assumption 1 with \(g = f'\), and because \(|f'(t)| \le L\) for every \(t\) in \(I\), we have \(|f(y) - f(x)| = \left| \int_x^y f'(t)\,dt \right| \le L\,(y - x)\).

Corollary 3.2 (a contraction on an interval)

Assuming Assumption 1. Hypotheses: (1)–(3) of Proposition 3.1; (4) \(f(I) \subseteq I\); (5) \(0 < L < 1\). Conclusion: \(f\) is a contraction mapping of the complete metric space \((I, |\cdot|)\) with modulus \(L\). The space is complete because \(I\) is a closed interval (Definition 1.2).

Example 3.3 (cosine on \([0, 1]\))

Assuming Assumptions 1 and 2. Let \(I = [0, 1]\) and \(f(t) = \cos t\). Hypotheses (1) and (2) of Proposition 3.1 hold, and \(f'(t) = -\sin t\) by Assumption 2(c). By Assumption 2(a), \(\sin t \ge 0\) on \([0, 1]\), so \(|f'(t)| = \sin t\) there, and the supremum is attained at \(t = 1\): \(L = \sup_{t \in [0,1]} |f'(t)| = \sin 1 \approx 0.841471\), which lies in \((0,1)\): \(\sin 1>0\) by Assumption 2(a), and \(\sin 1<1\) by Assumption 2(d). By Assumption 2(b), \(\cos t\) lies in \((0, 1]\) for \(t\) in \(I\), so \(f(I) \subseteq I\). Corollary 3.2 applies with modulus \(\beta = \sin 1\), and Theorem 2.1 gives one fixed point \(\bar x\) of \(\cos\) on \([0, 1]\), which the iteration from \(x_0 = 0\) reaches.

Lab 1 · Banach iteration for cosine, the sampled contraction ratio, and a map without a fixed point

Stated before running: for \(f(t) = \cos t\) on \([0, 1]\), the iteration \(x_{n+1} = \cos x_n\) from \(x_0 = 0\) has an error at most the bound of Theorem 2.1(c) with \(\beta = \sin 1\) and \(d(x_0, x_1) = 1\), for \(n = 0\) to \(30\). For every pair of distinct sampled points \(x\neq y\) on a grid of \(201\) points on \([0, 1]\), the ratio \(\lvert\cos x-\cos y\rvert/\lvert x-y\rvert\) is at most \(\sin 1\). For \(f(x) = \sqrt{x^2 + 1}\) on \([-W, W]\), the sampled ratio is larger on \([-50, 50]\) than on \([-5, 5]\), and \(f(x) - x\) is positive at every grid point. The grid check does not prove that \(f\) has no fixed point; Section 4 (Where the canon breaks) proves that. Parts A and B use the tolerance \(10^{-12}\), and Part C tests the sign of \(f(x) - x\) in floating point with no tolerance.

"""M5 L07 lab 1: Banach iteration for cos on [0, 1], the sampled contraction ratio, and a map with no fixed point.

Part A iterates x_{n+1} = cos(x_n) from x_0 = 0 and checks the error |x_n - xbar| against the a priori bound of
Theorem 2.1, beta**n * d(x_0, x_1) / (1 - beta), with beta = sin(1) and d(x_0, x_1) = 1. Part B samples the
difference quotient |cos x - cos y| / |x - y| over all pairs of a grid on [0, 1] and checks that no pair exceeds
sin(1), which is sup |f'| on [0, 1] by Example 3.3. Part C applies this sampling to f(x) = sqrt(x*x + 1) on
[-W, W] for two windows, and checks that f(x) - x is positive at every grid point. A grid check does not prove that
f has no fixed point; the page proves that analytically.
Standard library only; no randomness and no network access. The float tolerance is TOL = 1e-12 in Parts A and B;
Part C tests the sign of f(x) - x in floating point with no tolerance.
"""

from __future__ import annotations

import math

BETA = math.sin(1.0)
GRID_N = 200
ITER_STEPS = 300
TOL = 1e-12
WINDOWS = (5.0, 50.0)


def cos_fixed_point() -> float:
    """Return cos iterated ITER_STEPS times from 0; the iterates converge to the fixed point of cos on [0, 1]."""
    x = 0.0
    for _ in range(ITER_STEPS):
        x = math.cos(x)
    return x


def part_a() -> None:
    """Check the a priori error bound for the Banach iteration of cos from x_0 = 0."""
    xstar = cos_fixed_point()
    d01 = abs(0.0 - math.cos(0.0))  # d(x_0, x_1) = |0 - 1| = 1
    print(f"part A: modulus beta = sin(1) = {BETA:.6f}; fixed point xbar = {xstar:.6f}")
    x = 0.0
    for n in range(31):
        err = abs(x - xstar)
        bound = BETA**n * d01 / (1.0 - BETA)
        if err > bound + TOL:
            raise AssertionError(f"a priori bound fails at n = {n}")
        if n in (0, 1, 2, 5, 10, 20, 30):
            print(f"part A: n = {n:2d}  x_n = {x:.6f}  error = {err:.6e}  bound = {bound:.6e}")
        x = math.cos(x)
    print("part A: the error is at most the a priori bound for n = 0 to 30")


def part_b() -> None:
    """Sample the difference quotient of cos over all grid pairs on [0, 1] and compare it with sin(1)."""
    xs = [i / GRID_N for i in range(GRID_N + 1)]
    if not all(0.0 <= math.cos(x) <= 1.0 for x in xs):
        raise AssertionError("cos does not map the grid into [0, 1]")
    best = 0.0
    for i, x in enumerate(xs):
        for y in xs[i + 1 :]:
            best = max(best, abs(math.cos(x) - math.cos(y)) / (y - x))
    if best > BETA + TOL:
        raise AssertionError("a sampled difference quotient exceeds sin(1)")
    print(f"part B: grid of {GRID_N + 1} points on [0, 1]; largest sampled ratio = {best:.6f}; sin(1) = {BETA:.6f}")
    print("part B: cos maps the grid into [0, 1], and no sampled pair has ratio above sin(1)")


def window_ratio(half: float) -> tuple[float, float]:
    """Return the largest sampled ratio of f(x) = sqrt(x*x + 1) on [-half, half], and the minimum of f(x) - x."""
    xs = [-half + 2.0 * half * i / GRID_N for i in range(GRID_N + 1)]

    def f(x: float) -> float:
        return math.sqrt(x * x + 1.0)

    best = 0.0
    for i, x in enumerate(xs):
        for y in xs[i + 1 :]:
            best = max(best, abs(f(x) - f(y)) / (y - x))
    gap = min(f(x) - x for x in xs)
    return best, gap


def part_c() -> None:
    """Print the sampled ratio of f on each window, and check that f(x) - x is positive at every grid point."""
    for half in WINDOWS:
        best, gap = window_ratio(half)
        if gap <= 0.0:
            raise AssertionError("f(x) - x vanishes on the grid")
        print(f"part C: window [-{half:g}, {half:g}]: largest sampled ratio = {best:.6f}; min of f(x) - x = {gap:.6f}")
    print("part C: f(x) - x is positive at every grid point on either window")


def main() -> None:
    part_a()
    part_b()
    part_c()

Part A confirms the bound at the thirty-one values of \(n\) tested, with the stated tolerance. The fixed point printed, labelled xbar, is \(\bar x \approx 0.739085\), which the bound does not determine: the bound limits the error and gives no value. Part B prints the largest sampled quotient, \(0.840117\), which is below \(\sin 1 = 0.841471\). Each grid quotient is the average of \(\sin\) over the interval between its two points (Assumptions 1 and 2(c)), and that average is below \(\sin 1\) because \(\sin\) is strictly increasing on \([0, 1]\) (Assumption 2(a)). Part C prints the largest sampled ratio for \(f(x) = \sqrt{x^2 + 1}\) as \(0.980390\) on \([-5, 5]\) and \(0.999798\) on \([-50, 50]\); both are below \(1\), and the wider window gives the larger value. The lab does not show that no modulus below \(1\) exists on \(\mathbb{R}\), and its sign check does not show that \(f\) has no fixed point; the proofs in Section 4 (Where the canon breaks) do.

4Where the canon breaks

  • Completeness is needed. Let \(X = (0, 1]\) with \(d(x, y) = |x - y|\), and let \(\varphi x = x/2\). Then \(\varphi \) maps \(X\) into \(X\) and has modulus \(1/2\). Its only candidate fixed point is \(x = 0\), and \(0 \notin X\), so \(\varphi \) has no fixed point in \(X\). The iterates \(x_n = x_0 / 2^{n}\) converge to \(0\), which is outside \(X\). The sequence is Cauchy in \(X\) but has no limit in \(X\), so hypothesis (1) of Theorem 2.1 fails.
  • The modulus must be strictly below one, uniformly. Let \(X = \mathbb{R}\) and \(\varphi x = \sqrt{x^2 + 1}\). For \(x \ne y\), \(|\varphi x - \varphi y| = |x + y|\,|x - y|/(\varphi x + \varphi y)\). Since \(\varphi x > |x|\) and \(\varphi y > |y|\), we have \(\varphi x + \varphi y > |x| + |y| \ge |x + y|\), so \(|\varphi x - \varphi y| < |x - y|\). Yet \(\varphi \) has no fixed point, because \(\sqrt{x^2 + 1} > |x| \ge x\). Also \(|\varphi x - \varphi y|/|x - y| = |x + y|/(\varphi x + \varphi y)\) tends to \(1\) for each fixed \(h \ne 0\) as \(x = y + h\) and \(y \to \infty\), so no modulus \(\beta < 1\) works on all of \(\mathbb{R}\).
  • The self-map condition matters. Corollary 3.2 requires \(f(I) \subseteq I\). For \(f(t) = \cos t\) this holds on \([0, 1]\) by Assumption 2(b). Without it, the iterates may leave \(I\), where the derivative bound says nothing about \(f\). Theorem 2.1 needs \(\varphi \) defined on all of \(X\).

5Misconceptions

  1. “If \(d(\varphi x, \varphi y) < d(x, y)\) for every pair of distinct points, then \(\varphi \) is a contraction.”

    A contraction needs one \(\beta < 1\) that works for all pairs. The map \(\varphi x = \sqrt{x^2 + 1}\) on \(\mathbb{R}\) shrinks every distinct pair, but its ratio tends to \(1\) for pairs of fixed separation far from the origin, and it has no fixed point (canon-breaks, second item).

  2. “A contraction must be differentiable.”

    Let \(\varphi x = |x|/2\) on \(\mathbb{R}\). The reverse triangle inequality gives \(\big||x| - |y|\big| \le |x - y|\), so \(|\varphi x - \varphi y| \le |x - y|/2\). The map is a contraction with modulus \(1/2\) and is not differentiable at \(0\). Proposition 3.1 is a sufficient condition, not a necessary one.

  3. “The bound \(\beta^{n} d(x_0, x_1)/(1 - \beta)\) is an estimate of the error that uses the current iterate.”

    The bound uses only \(x_0\), \(x_1\) and \(\beta\), and never the iterate \(x_n\) that it bounds. In Lab 1, part A, \(\cos\) from \(0\) at \(n = 5\) has an error of \(5.439523 \times 10^{-2}\) and a bound of \(2.661258\). The bound is about \(48.9\) times the error at this step (\(2.661258 / 0.05439523 = 48.92\), from the printed values), so at \(n = 5\) it is a valid upper bound and a loose one.

Mechanics

M1 · A halving map

Let \(\varphi x = x/2 + 1\) on \(\mathbb{R}\). Find the modulus, the fixed point, \(x_1\) and \(x_2\) from \(x_0 = 0\), and the bound of Theorem 2.1(c) at \(n = 2\). Compare the bound with the actual error.

Solution

The modulus is \(\beta = 1/2\), since \(|\varphi x - \varphi y| = |x - y|/2\). The fixed point solves \(x = x/2 + 1\), so \(\bar x = 2\). From \(x_0 = 0\), \(x_1 = 1\) and \(x_2 = 1.5\). Here \(d(x_0, x_1) = 1\), so the bound at \(n = 2\) is \((1/2)^{2} \cdot 1/(1/2) = 0.5\). The actual error is \(|x_2 - 2| = 0.5\), so the bound is exact at this step. Example 2.3 shows the same equality for \(\varphi x = x/3+2\) from \(0\), and Problem R1 for \(\varphi x = \beta x\) from \(1\); no general linear map is treated here.

M2 · How many iterations to reach a tolerance

For \(\varphi x = x/3 + 2\) from \(x_0 = 0\), find the smallest \(n\) for which the bound of Theorem 2.1(c) is at most \(10^{-6}\).

Solution

Example 2.3 gives the bound \(3 \cdot 3^{-n}\). At \(n = 13\) it equals \(3/1594323 \approx 1.8817 \times 10^{-6}\), which is too large. At \(n = 14\) it equals \(3/4782969 \approx 6.2723 \times 10^{-7}\), which is at most \(10^{-6}\). The smallest such \(n\) is \(14\).

M3 · A quadratic map on the unit interval

Let \(f(x) = x^2/4\) on \(I = [0, 1]\). Show that \(f\) is a contraction on \(I\), and find its unique fixed point in \(I\).

Solution

The derivative is \(f'(x) = x/2\), which satisfies \(0 \le f'(x) \le 1/2\) on \(I\). So \(L = 1/2\), and under Assumption 1 Proposition 3.1 applies. Also \(f(I) = [0, 1/4] \subseteq I\), so under Assumption 1 Corollary 3.2 makes \(f\) a contraction with modulus \(1/2\). The fixed points of \(f\) solve \(x^2/4 = x\), so \(x = 0\) or \(x = 4\). Only \(x = 0\) lies in \(I\), so \(0\) is the unique fixed point in \(I\).

Proof

P1 · Uniqueness without completeness

Let \((X, d)\) be any metric space, not necessarily complete, and let \(\varphi \) be a contraction with modulus \(\beta\). Prove that \(\varphi \) has at most one fixed point.

Solution

Let \(y\) and \(z\) satisfy \(\varphi y = y\) and \(\varphi z = z\). The contraction inequality gives \(d(y, z) = d(\varphi y, \varphi z) \le \beta\, d(y, z)\). So \((1 - \beta)\, d(y, z) \le 0\). Because \(\beta < 1\), the factor \(1 - \beta\) is positive, and since \(d(y, z) \ge 0\), it follows that \(d(y, z) = 0\). The metric axioms then give \(y = z\). Completeness was not used.

P2 · The step estimate by induction

Let \(x_{n+1} = \varphi x_n\) with \(\varphi \) a contraction of modulus \(\beta\). Prove by induction that \(d(x_{k+1}, x_k) \le \beta^{k}\, d(x_1, x_0)\) for every \(k \ge 0\).

Solution

For \(k = 0\) the claim reads \(d(x_1, x_0) \le d(x_1, x_0)\), which holds. Assume the claim for \(k\). Then \(d(x_{k+2}, x_{k+1}) = d(\varphi x_{k+1}, \varphi x_k) \le \beta\, d(x_{k+1}, x_k)\), by the contraction inequality applied to \(x_{k+1}\) and \(x_k\). Using the hypothesis, this is at most \(\beta \cdot \beta^{k} d(x_1, x_0) = \beta^{k+1} d(x_1, x_0)\). This completes the induction.

P3 · Contractions preserve Cauchy sequences

Let \(\varphi \) be a contraction with modulus \(\beta\) on a metric space \((X, d)\), and let \((a_n)\) be a Cauchy sequence in \(X\). Prove that \((\varphi a_n)\) is Cauchy.

Solution

Let \(\varepsilon > 0\). Choose \(N\) with \(d(a_n, a_m) < \varepsilon\) for \(n, m \ge N\). Then \(d(\varphi a_n, \varphi a_m) \le \beta\, d(a_n, a_m) \le d(a_n, a_m) < \varepsilon\) for \(n, m \ge N\), because \(0 < \beta < 1\) and distances are nonnegative. So \((\varphi a_n)\) is Cauchy. Note that the argument uses only the contraction inequality, not completeness.

Empirical

E1 · The bound against the error for cosine

Run Lab 1. At \(n = 5\), the printed error and bound for the cosine iteration are \(5.439523 \times 10^{-2}\) and \(2.661258\). Compute their ratio, and explain in one sentence why the ratio is not close to one.

Solution

The ratio is \(2.661258 / 0.05439523 \approx 48.92\). The bound is \(\sin(1)^{5}/(1 - \sin 1) \cdot 1\), and it depends only on \(x_0\), \(x_1\) and \(\beta\). The error depends on how close the iterate already is to \(\bar x\), which the bound does not use. So the bound overstates the error by a factor of about \(49\) at this step.

E2 · Is there a uniform modulus for the square-root map?

Lab 1, part C prints the largest sampled ratio of \(f(x) = \sqrt{x^2 + 1}\) on \([-5, 5]\) and on \([-50, 50]\). Read those two values, compute \(f'(5)\) and \(f'(50)\), and state whether the samples support a modulus below one on \(\mathbb{R}\).

Solution

The printed values are \(0.980390\) on \([-5, 5]\) and \(0.999798\) on \([-50, 50]\). The derivative is \(f'(x) = x/\sqrt{x^2 + 1}\). For \(x\ne y\) in a window, the sampled quotient \(\lvert f(x)-f(y)\rvert/\lvert x-y\rvert\) is the absolute value of an average of \(f'\) over \([\min(x,y),\max(x,y)]\) (Assumption 1). Since \(\lvert f'(t)\rvert=\lvert t\rvert/\sqrt{t^2+1}\) increases in \(\lvert t\rvert\) (its derivative in \(s=\lvert t\rvert\) is \((s^2+1)^{-3/2}>0\)), every sampled quotient is at most \(f'(5)=5/\sqrt{26}\approx 0.980581\) on \([-5,5]\) and at most \(f'(50)=50/\sqrt{2501}\approx 0.999800\) on \([-50,50]\). The printed maxima lie below these bounds, and the wider window gives the larger printed value, consistent with its larger bound. Each window's bound is \(f'\) at its end point, and \(f'(L)=L/\sqrt{L^2+1}\to 1\) as \(L\to\infty\). Canon-breaks item 2 shows that no modulus below one works on all of \(\mathbb{R}\), so the samples do not support a modulus below one on \(\mathbb{R}\).

E3 · Where the largest sampled quotient comes from

Lab 1, part B prints \(0.840117\) as the largest sampled ratio of \(\cos\) on \([0, 1]\), while \(\sin 1 = 0.841471\). Compute the quotient for the pair \((0.995, 1)\), and explain why the sampled maximum sits below \(\sin 1\).

Solution

The quotient for the pair is \((\cos 0.995 - \cos 1)/(1 - 0.995) = 0.8401167\ldots\), which matches the printed maximum to six decimal places. The quotient is an average of \(\sin t\) over \([0.995, 1]\) (Assumptions 1 and 2(c)). By Assumption 2(a), \(\sin t < \sin 1\) for every \(t < 1\), so this average is strictly less than \(\sin 1\), because the interval has width \(0.005 > 0\) and ends at \(1\). The printed maximum is below \(\sin 1\) by \(\sin 1-0.8401167257\ldots=0.0013542591\ldots\), computed from unrounded values. The quotients for the pairs \((1-h,1)\) tend to \(\sin 1\) as \(h \to 0\), as Problem R3 shows.

Research

R1 · When the bound is exact

Let \(\varphi x = \beta x\) on \(\mathbb{R}\), with \(0 < \beta < 1\), and let \(x_0 = 1\). Show that the bound of Theorem 2.1(c) equals the error at every \(n\).

Solution

The fixed point is \(\bar x = 0\), and \(x_n = \beta^{n}\), so the error is \(\beta^{n}\). Here \(d(x_0, x_1) = |1 - \beta| = 1 - \beta\), so the bound is \(\beta^{n}(1 - \beta)/(1 - \beta) = \beta^{n}\). The two agree at every \(n\). This page does not state a general condition for the bound to be attained; the two computed cases are this one and Example 2.3.

R2 · Iterations needed for a tolerance

Let \(\beta = \sin 1\) and \(d(x_0, x_1) = 1\), as for cosine from \(0\). Find the smallest integer \(n\) for which the bound of Theorem 2.1(c) is at most \(\varepsilon = 10^{-6}\), in terms of \(\beta\) and \(\varepsilon\). Give its value numerically.

Solution

The condition \(\beta^{n}/(1 - \beta) \le \varepsilon\) is equivalent to \(n\ln(1/\beta) \ge \ln\big(1/(\varepsilon(1 - \beta))\big)\), so \(n \ge \ln\big(1/(\varepsilon(1-\beta))\big)/\ln(1/\beta)\). With \(\beta = \sin 1 = 0.8414710\) and \(\varepsilon = 10^{-6}\), the right side is \(\ln(1/(10^{-6} \cdot 0.1585290))/\ln(1/0.8414710) \approx 90.71\). The smallest integer is \(n = 91\). The bound is conservative: Lab 1, Part A, prints an error of \(2.834693 \times 10^{-6}\) at \(n = 30\), against a bound of \(3.556850 \times 10^{-2}\) at the same \(n\).

R3 · The modulus of cosine is sharp

Show that no number \(\beta' < \sin 1\) satisfies \(|\cos x - \cos y| \le \beta'|x - y|\) for all \(x, y\) in \([0, 1]\). Use the definition of the derivative.

Solution

Take \(y = 1\) and \(x = 1 - h\) with \(0 < h < 1\). Then \(|\cos x - \cos 1|/|x - 1| = |\cos(1 - h) - \cos 1|/h\). As \(h \to 0\), this quotient tends to \(|\cos'(1)| = |-\sin 1| = \sin 1\), by the definition of the derivative and Assumption 2(c). If \(\beta' < \sin 1\), the inequality would fail for all sufficiently small \(h\). So the modulus \(\sin 1\) cannot be lowered.
