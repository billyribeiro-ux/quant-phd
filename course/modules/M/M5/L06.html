A continuous function on a closed bounded interval attains its maximum. The property that gives this is compactness, which this lesson defines by sequences. The lesson proves the Bolzano–Weierstrass theorem by bisection, derives the extreme value theorem, and shows that compact metric spaces are complete. It also shows that a bounded set need not be compact: unit vectors in the sup distance give a counterexample, and the continuous function \(x\) on the open interval \((0,1)\) is bounded but has no maximum.

1Sequential compactness and the bisection theorem

Let \((X,d)\) be a metric space. A subsequence of \((x_{n})\) is a sequence \((x_{n_{k}})_{k\ge 1}\) with \(n_{1}<n_{2}<\cdots\). A subset of \(\R\) is bounded when some real number bounds its members in absolute value. The supremum property of L01 is used in Lemma 1.2.

Definition 1.1 (sequential compactness)

A subset \(K\) of a metric space \((X,d)\) is compact when every sequence in \(K\) has a subsequence that converges to a point of \(K\). This is sequential compactness. The lesson uses this definition only; the open-cover definition is not used here.

Lemma 1.2 (nested closed intervals)

Hypotheses: (1) \(I_{k}=[a_{k},b_{k}]\) for \(k\ge 1\), with \(I_{1}\supseteq I_{2}\supseteq\cdots\); (2) \(b_{k}-a_{k}\to 0\). Conclusion: there is exactly one real number \(s\) with \(s\in I_{k}\) for every \(k\).

Proof

The sequence \((a_{k})\) is nondecreasing, because the intervals are nested, and it is bounded above by \(b_{1}\). Let \(s=\sup_{k}a_{k}\), which exists by the supremum property of L01. For each \(k\), \(a_{k}\le s\). Also \(s\le b_{k}\): for \(j\ge k\), \(a_{j}\le b_{j}\le b_{k}\), and for \(j<k\), \(a_{j}\le a_{k}\le b_{k}\). So \(b_{k}\) is an upper bound of \(\{a_{j}\}\), and \(s\le b_{k}\). Hence \(s\in I_{k}\) for every \(k\). If \(t\) is another point in every \(I_{k}\), then \(\lvert t-s\rvert\le b_{k}-a_{k}\) for every \(k\), so \(\lvert t-s\rvert\le 0\) by hypothesis (2), and \(t=s\). \(\square\)

Proposition 1.3 (Bolzano–Weierstrass)

Hypotheses: (1) \((x_{n})\) is a sequence of real numbers; (2) there are real numbers \(a\le b\) with \(a\le x_{n}\le b\) for all \(n\). Conclusion: \((x_{n})\) has a subsequence that converges to a real number.

Proof

Set \(I_{0}=[a,b]\). Suppose \(I_{k-1}=[a_{k-1},b_{k-1}]\) has been chosen, and that \(x_{n}\in I_{k-1}\) for infinitely many indices \(n\). Let \(m=(a_{k-1}+b_{k-1})/2\). The two halves \([a_{k-1},m]\) and \([m,b_{k-1}]\) cover \(I_{k-1}\), so the indices \(n\) with \(x_{n}\in I_{k-1}\) are split between them. An infinite set cannot be split into two finite sets, so one half, call it \(I_{k}\), contains \(x_{n}\) for infinitely many \(n\). Having chosen \(n_{k-1}\), pick \(n_{k}>n_{k-1}\) with \(x_{n_{k}}\in I_{k}\), which is possible because infinitely many indices give such terms. (For \(k=1\), take \(n_{0}=0\).)

The intervals \(I_{k}\) are nested, and each has length \((b-a)/2^{k}\), which tends to zero. By Lemma 1.2 there is a real \(s\) in every \(I_{k}\). Both \(x_{n_{k}}\) and \(s\) lie in \(I_{k}\), so \(\lvert x_{n_{k}}-s\rvert\le (b-a)/2^{k}\to 0\). The subsequence \((x_{n_{k}})\) converges to \(s\). \(\square\)

Proposition 1.4 (closed bounded intervals are compact)

Hypotheses: (1) \(a\le b\) are real numbers; (2) \([a,b]\) carries the Euclidean distance of \(\R\). Conclusion: \([a,b]\) is a compact metric space.

Proof

Let \((x_{n})\) be a sequence in \([a,b]\). It is bounded by \(a\) and \(b\), so Proposition 1.3 gives a subsequence converging to some real \(s\). Each term of the subsequence satisfies \(a\le x_{n_{k}}\le b\), and these inequalities pass to the limit, so \(a\le s\le b\). The limit lies in \([a,b]\). \(\square\)

Example 1.5 (the open interval is not compact)

Let \(K=(0,1)\) with the Euclidean distance. The sequence \(x_{n}=1/n\) lies in \(K\). Every subsequence converges in \(\R\) to \(0\): for a subsequence with \(n_{1}<n_{2}<\cdots\), each \(n_{k}\ge k\), so \(0<\lvert 1/n_{k}\rvert\le 1/k\to 0\). If a subsequence converged to a point of \(K\), that point would equal \(0\) by uniqueness of limits in \(\R\), and \(0\notin K\). So no subsequence converges to a point of \(K\), and \(K\) is not compact.

Lab 1 · Bisection, grid maxima and unit vectors

Before running: Part A halves \([0,1]\) eight times on a finite prefix of 4096 terms of \((n^{2}\bmod 1000)/1000\), keeping the half with more prefix indices, and checks that every chosen value from step \(j\) on lies in the interval of step \(j\). Part B takes the maximum of \(x(1-x)\) on the grid \(k/10\), which contains the maximiser \(1/2\), and on the grid \(k/7\), which does not. Part C computes the sup distance between the unit vectors \(e_{0},\dots,e_{9}\), truncated to length 20. The expected results are: the nested check is True; the grid maximum on tenths is \(1/4\); the grid maximum on sevenths is below \(1/4\); and all 45 pairwise distances equal \(1\). The program is exact.

"""M5 L06 lab 1: bisection for a convergent subsequence, grid maxima, and unit vectors in the sup distance.

Standard library only. No randomness and no network: the sequence is a fixed formula, every grid is enumerated, and
all arithmetic is exact with Fraction, so every run prints the same lines.

Part A: the bisection construction of Bolzano-Weierstrass, run on a finite prefix. The prefix is the first 4096 terms
of x_n = (n^2 mod 1000)/1000 in [0, 1). At each of 8 steps the current interval is halved, and the half that contains
more of the remaining prefix indices inside the current interval is kept. The output gives each interval, the chosen
index, and whether every chosen value from step j on lies in the interval of step j. A finite prefix is not
an infinite sequence, so this illustrates the construction and proves nothing about the infinite sequence.
Part B: f(x) = x(1 - x) on two grids of [0, 1]: k/10 (which contains the maximiser 1/2) and k/7 (which does not). The
grid maxima are exact, and the printed values show that a grid maximum is a lower bound for the true maximum 1/4.
Part C: the unit vectors e_0, ..., e_9 truncated to length 20 in the sup distance. Every pair of distinct vectors
has distance exactly 1. The output reports the minimum and maximum pairwise distance over all 45 pairs.
"""

from __future__ import annotations

from fractions import Fraction
from itertools import combinations

PREFIX = 4096
STEPS = 8
TRUNCATION = 20
VECTORS = 10


def term(n: int) -> Fraction:
    """The n-th term of the prefix, (n^2 mod 1000)/1000, an exact fraction in [0, 1)."""
    return Fraction(n * n % 1000, 1000)


def unit_vector(index: int, length: int) -> tuple[Fraction, ...]:
    """The vector with a 1 in position index and zeros elsewhere, of the given length."""
    return tuple(Fraction(1) if k == index else Fraction(0) for k in range(length))


def sup_distance(f: tuple[Fraction, ...], g: tuple[Fraction, ...]) -> Fraction:
    """The maximum over positions of |f_k - g_k|, exact. Both vectors have the same length."""
    return max(abs(a - b) for a, b in zip(f, g, strict=True))


def bisect_prefix() -> None:
    """Halve [0, 1] for STEPS steps and print each step.

    At each step the pool is the set of prefix indices after the last chosen index whose terms lie in the current
    interval. The half of the interval that holds more pool indices is kept, and the first pool index in it is chosen.
    """
    values = [term(n) for n in range(1, PREFIX + 1)]
    left, right = Fraction(0), Fraction(1)
    last_index = 0
    chosen: list[tuple[int, Fraction]] = []
    intervals: list[tuple[Fraction, Fraction]] = []
    for step in range(1, STEPS + 1):
        mid = (left + right) / 2
        pool = [n for n in range(last_index + 1, PREFIX + 1) if left <= values[n - 1] <= right]
        in_left = [n for n in pool if values[n - 1] < mid]
        in_right = [n for n in pool if values[n - 1] >= mid]
        if len(in_left) >= len(in_right):
            right = mid
            half = in_left
        else:
            left = mid
            half = in_right
        index = half[0]
        last_index = index
        chosen.append((index, values[index - 1]))
        intervals.append((left, right))
        print(f"step {step} interval [{left}, {right}] width {right - left} chosen_index {index}")
    nested = all(intervals[j][0] <= value <= intervals[j][1] for j in range(STEPS) for _, value in chosen[j:])
    print(f"tail_values_in_their_interval {nested}")
    print(f"subsequence_indices {' '.join(str(index) for index, _ in chosen)}")


def grid_maximum(grid: list[Fraction]) -> tuple[Fraction, Fraction]:
    """The maximum of f(x) = x(1 - x) over the grid, and the first grid point that attains it."""
    best = max(x * (1 - x) for x in grid)
    point = next(x for x in grid if x * (1 - x) == best)
    return point, best


def main() -> None:
    """Print Parts A, B and C. Every value is an exact fraction, an integer, or a boolean."""
    print("Part A: bisection on a prefix of 4096 terms of (n^2 mod 1000)/1000, on [0, 1]")
    bisect_prefix()

    print("Part B: maximum of x(1 - x) on grids of [0, 1]; the true maximum is 1/4 at x = 1/2")
    fine = [Fraction(k, 10) for k in range(11)]
    point, value = grid_maximum(fine)
    print(f"grid_tenths argmax {point} maximum {value} true_maximum {Fraction(1, 4)}")
    coarse = [Fraction(k, 7) for k in range(8)]
    point, value = grid_maximum(coarse)
    print(f"grid_sevenths argmax {point} maximum {value} lower_bound_for_true {value <= Fraction(1, 4)}")

    print("Part C: unit vectors e_0 to e_9 of length 20, sup distance between distinct vectors")
    vectors = [unit_vector(i, TRUNCATION) for i in range(VECTORS)]
    distances = [sup_distance(f, g) for f, g in combinations(vectors, 2)]
    print(f"pairs {len(distances)} min_distance {min(distances)} max_distance {max(distances)}")
    print(f"self_distance {sup_distance(vectors[0], vectors[0])}")


main()

Part A runs the construction of Proposition 1.3 on a finite prefix. The output shows nested intervals of widths \(1/2,\dots,1/256\), and the chosen indices increase. A finite prefix is not an infinite sequence, so the output illustrates the construction and does not prove the theorem. 2Continuous functions on compact sets

Proposition 2.1 (continuous functions attain their extremes on compact sets)

Hypotheses: (1) \((X,d)\) is a metric space; (2) \(K\subseteq X\) is nonempty and compact; (3) \(f\colon X\to\R\) is continuous. Conclusion: there are points \(p,q\in K\) with \(f(q)\le f(x)\le f(p)\) for every \(x\in K\).

Proof

Step 1, bounded above. Suppose \(f\) is unbounded above on \(K\). Then for each \(n\) there is \(x_{n}\in K\) with \(f(x_{n})>n\). By compactness, some subsequence \((x_{n_{k}})\) converges to a point \(x\in K\). By continuity and L04, Proposition 4.2, \(f(x_{n_{k}})\to f(x)\), a real number. But \(f(x_{n_{k}})>n_{k}\ge k\), which tends to infinity. This is a contradiction, so \(f\) is bounded above on \(K\).

Step 2, the maximum is attained. Let \(M=\sup_{x\in K}f(x)\), which is a real number by Step 1 and the supremum property of L01. For each \(n\), choose \(x_{n}\in K\) with \(f(x_{n})>M-1/n\). A subsequence \((x_{n_{k}})\) converges to some \(p\in K\). Then \(f(x_{n_{k}})\to f(p)\) by continuity. Also \(M-1/n_{k}<f(x_{n_{k}})\le M\), so \(f(x_{n_{k}})\to M\). Limits are unique, so \(f(p)=M\), and \(f(x)\le f(p)\) for all \(x\in K\).

Step 3, the minimum. Apply Steps 1 and 2 to \(-f\), which is continuous. \(\square\)

Corollary 2.2 (extreme value theorem on a closed interval)

Hypotheses: (1) \(a\le b\) are real numbers; (2) \(f\colon[a,b]\to\R\) is continuous. Conclusion: \(f\) attains a maximum and a minimum on \([a,b]\).

Proof

By Proposition 1.4, \([a,b]\) is compact and nonempty. Apply Proposition 2.1 with \(X=K=[a,b]\). \(\square\)

3Compact metric spaces are complete, and bounded does not mean compact

Proposition 3.1 (a Cauchy sequence with a convergent subsequence converges)

Hypotheses: (1) \((X,d)\) is a metric space; (2) \((x_{n})\) is a Cauchy sequence in \(X\); (3) some subsequence \((x_{n_{k}})\) converges to \(x\in X\). Conclusion: \(x_{n}\to x\).

Proof

Let \(\varepsilon>0\). Choose \(N\) with \(d(x_{m},x_{n})<\varepsilon/2\) for \(m,n\ge N\). Choose \(k\) with \(n_{k}\ge N\) and \(d(x_{n_{k}},x)<\varepsilon/2\). For \(n\ge N\), \(d(x_{n},x)\le d(x_{n},x_{n_{k}})+d(x_{n_{k}},x)<\varepsilon/2+\varepsilon/2=\varepsilon\). \(\square\)

Corollary 3.2 (compact metric spaces are complete)

Hypotheses: (1) \((X,d)\) is a metric space; (2) \(K\subseteq X\) is compact, with the restricted metric. Conclusion: every Cauchy sequence in \(K\) converges to a point of \(K\), so \(K\) is complete in the sense of L04, Definition 3.2.

Proof

Let \((x_{n})\) be Cauchy in \(K\). By compactness it has a subsequence converging to some \(x\in K\). By Proposition 3.1 the whole sequence converges to \(x\), which lies in \(K\). \(\square\)

Example 3.3 (the sup distance on bounded sequences)

Let \(\mathbb{N}=\{1,2,\dots\}\), and let \(B(\mathbb{N})\) be the bounded real sequences, which is \(B(S)\) of L04, Example 1.6 with \(S=\mathbb{N}\). For \(k\ge 1\), let \(e_{n}\) be the sequence with \(e_{n}(k)=1\) if \(k=n\) and \(e_{n}(k)=0\) otherwise. Each \(e_{n}\) is bounded by \(1\).

Proposition 3.4 (the unit vectors have no convergent subsequence)

Hypotheses: (1) \(B(\mathbb{N})\) carries the sup distance \(d_{\infty}\) of L04, Example 1.6; (2) \(e_{n}\) is as in Example 3.3. Conclusion: \(d_{\infty}(e_{m},e_{n})=1\) for all \(m\ne n\). Hence no subsequence of \((e_{n})\) converges, and the closed unit ball \(\{f\in B(\mathbb{N}) : d_{\infty}(f,0)\le 1\}\) is bounded but not compact.

Proof

Let \(m\ne n\). For each \(k\), \(\lvert e_{m}(k)-e_{n}(k)\rvert\le 1\), because both values lie in \([0,1]\). At \(k=m\), \(\lvert e_{m}(m)-e_{n}(m)\rvert=\lvert 1-0\rvert=1\). So the supremum is \(1\). Now let \((e_{n_{k}})\) be a subsequence with \(n_{1}<n_{2}<\cdots\). Any two of its terms are at distance \(1\), so it is not Cauchy. A convergent sequence is Cauchy (L04, Proposition 3.3), so no subsequence converges. Every \(e_{n}\) lies in the closed unit ball, so the ball contains a sequence with no convergent subsequence and is not compact. The ball is bounded, because two of its points are at distance at most \(2\) by the triangle inequality of L04, Proposition 1.7. \(\square\)

4Where the canon breaks

Proposition 2.1 and Corollary 3.2 use compactness, and the examples below show what fails for sets that are not compact.

Boundedness is not enough. Proposition 3.4 gives a closed unit ball in \(B(\mathbb{N})\) with no convergent subsequence. The bounded set \((0,1)\) of Example 1.5 is another example. Proposition 1.3 is a statement about real sequences; Proposition 3.4 shows that a bounded set in \(B(\mathbb{N})\) need not be compact.

The maximum is not attained. Let \(f(x)=x\) on \((0,1)\). It is continuous and bounded, with supremum \(1\). It has no maximum. If \(p\in(0,1)\), then \((p+1)/2\in(p,1)\) and \(f((p+1)/2)>f(p)\), so no point of \((0,1)\) is a maximiser. Proposition 2.1 does not apply here, because \((0,1)\) is not compact (Example 1.5).

5Misconceptions

  1. “Every bounded sequence converges.”

    The sequence \((-1)^{n}\) is bounded and has no limit. Proposition 1.3 gives a convergent subsequence, here the odd terms, which converge to \(-1\). Boundedness gives a convergent subsequence, not convergence.

  2. “A bounded set is compact.”

    The open interval \((0,1)\) is bounded, and Example 1.5 shows it is not compact. The closed unit ball in \(B(\mathbb{N})\) is bounded and not compact by Proposition 3.4.

  3. “A continuous function on a bounded set attains its maximum.”

    The function \(f(x)=x\) on \((0,1)\) is continuous, bounded and has no maximum (Section 4). Corollary 2.2 needs a closed bounded interval, which is compact by Proposition 1.4.

6Problem set

Mechanics

L06 · Mechanics 1 · A convergent subsequence

Let \(x_{n}=(-1)^{n}+1/n\). Give a convergent subsequence and its limit.

Solution

The even indices \(n=2k\) give \(x_{2k}=1+1/(2k)\), which tends to \(1\) as \(k\to\infty\). So the subsequence \((x_{2k})_{k\ge 1}\) converges to \(1\). The odd terms converge to \(-1\) along their own subsequence, so the sequence has two subsequential limits and no limit.

L06 · Mechanics 2 · Extremes of a cubic

Find the maximum and minimum of \(f(x)=x^{3}-3x\) on \([-2,2]\), and the points where they occur.

Solution

The derivative is \(3x^{2}-3\), which vanishes at \(x=\pm 1\). The values are \(f(-2)=-2\), \(f(-1)=2\), \(f(1)=-2\) and \(f(2)=2\). By Corollary 2.2 the maximum and the minimum exist. Let \(p\) be a maximiser. If \(p\in(-2,2)\), then \(f'(p)=0\): for small \(h>0\) the quotient \((f(p+h)-f(p))/h\) is at most \(0\), for small \(h<0\) it is at least \(0\), and both one-sided limits equal \(f'(p)\). So \(p\in\{-2,-1,1,2\}\), and the same holds for a minimiser. Comparing the four values, the maximum is \(2\), attained at \(x=-1\) and \(x=2\), and the minimum is \(-2\), attained at \(x=-2\) and \(x=1\).

L06 · Mechanics 3 · No maximum on an open interval

Let \(f(x)=x\) on \((0,1)\). Show that \(f\) has no maximum on \((0,1)\), and state the supremum.

Solution

Let \(p\in(0,1)\). Then \((p+1)/2\) lies in \((p,1)\), which is contained in \((0,1)\), and \(f((p+1)/2)=(p+1)/2>p=f(p)\). So no point of \((0,1)\) is a maximiser. The supremum is \(1\), which is not attained, because \(1\notin(0,1)\).

Proof

L06 · Proof 1 · Unions of compact sets

Let \(K\) and \(L\) be compact subsets of a metric space. Prove that \(K\cup L\) is compact.

Solution

Let \((x_{n})\) be a sequence in \(K\cup L\). Infinitely many terms lie in \(K\) or infinitely many lie in \(L\), since the index set is the union of two sets, one of which is infinite. Take the subsequence of those terms, which lies in \(K\) (or in \(L\)). By compactness of \(K\) (or \(L\)), a further subsequence converges to a point of \(K\) (or \(L\)), which lies in \(K\cup L\). So \(K\cup L\) is compact.

L06 · Proof 2 · Closed subsets of compact sets

Let \(K\) be compact and let \(F\subseteq K\) be such that every convergent sequence in \(F\) has its limit in \(F\). Prove that \(F\) is compact.

Solution

Let \((x_{n})\) be a sequence in \(F\). It is a sequence in \(K\), so a subsequence converges to some \(x\in K\). That subsequence is a convergent sequence in \(F\), so by hypothesis \(x\in F\). Hence every sequence in \(F\) has a subsequence converging to a point of \(F\), and \(F\) is compact.

L06 · Proof 3 · A positive continuous function has a positive lower bound

Let \(K\) be a nonempty compact subset of a metric space and let \(f\colon K\to\R\) be continuous with \(f(x)>0\) for every \(x\in K\). Prove that there is \(c>0\) with \(f(x)\ge c\) for all \(x\in K\).

Solution

By Proposition 2.1 applied to \(K\) and \(f\), there is \(q\in K\) with \(f(q)\le f(x)\) for all \(x\in K\). Take \(c=f(q)\). Then \(c>0\), because \(q\in K\) and \(f\) is positive on \(K\). So \(f(x)\ge c\) for all \(x\in K\).

L06 · Empirical 1 · Widths of the bisection

Read Part A of Lab 1. What is the width of the interval after step 8, and what does the output show about the chosen values?

Solution

Each step halves the interval, so after step 8 the width is \(1/2^{8}=1/256\). The output prints "width 1/256" for step 8, and "tail_values_in_their_interval True". The prefix is finite, so the check says nothing about the infinite sequence.

L06 · Empirical 2 · A grid maximum below the true maximum

Part B reports the maximum of \(x(1-x)\) on the grid \(k/7\) as \(12/49\) at \(x=3/7\). Compute the gap to the true maximum \(1/4\) exactly.

Solution

Write \(1/4=49/196\) and \(12/49=48/196\). The gap is \(1/196\), which is about \(0.0051\). The grid maximum is therefore a lower bound that misses the true maximum by \(1/196\), because the maximiser \(1/2\) is not on the grid of sevenths.

L06 · Empirical 3 · Pairwise distances of unit vectors

Part C reports 45 pairs with minimum and maximum distance both equal to \(1\). Check the number of pairs, and state why every distance is \(1\).

Solution

Ten vectors give \(\binom{10}{2}=45\) unordered pairs, matching the printed count. Two distinct unit vectors \(e_{m}\ne e_{n}\) differ in exactly two positions, \(m\) and \(n\), by \(1\) each. So the maximum entry difference is \(1\), as in Proposition 3.4.

Research

L06 · Research 1 · Compact sets are bounded

Let \((X,d)\) be a metric space and \(K\subseteq X\) compact and nonempty. Prove that \(K\) is bounded, meaning there is \(x_{0}\in X\) and \(R\) with \(d(x_{0},x)\le R\) for all \(x\in K\).

Solution

Fix \(x_{0}\in K\). Suppose \(K\) is unbounded from \(x_{0}\): for each \(n\) there is \(x_{n}\in K\) with \(d(x_{0},x_{n})>n\). By compactness a subsequence \((x_{n_{k}})\) converges to some \(x\in K\). For large \(k\), \(d(x_{n_{k}},x)<1\), so \(d(x_{0},x_{n_{k}})\le d(x_{0},x)+1\). Since \(d(x_{0},x)\) is a fixed real number, this bounds \(d(x_{0},x_{n_{k}})\) for all large \(k\), which contradicts \(d(x_{0},x_{n_{k}})>n_{k}\ge k\). So \(K\) is bounded.

L06 · Research 2 · Uniform continuity on a compact set

Let \(K\) be a compact metric space and \(f\colon K\to\R\) continuous. Prove that \(f\) is uniformly continuous: for every \(\varepsilon>0\) there is \(\delta>0\) such that \(d(x,y)<\delta\) implies \(\lvert f(x)-f(y)\rvert<\varepsilon\), for all \(x,y\in K\).

Solution

Suppose not. Then for some \(\varepsilon>0\) and every \(n\) there are \(x_{n},y_{n}\in K\) with \(d(x_{n},y_{n})<1/n\) and \(\lvert f(x_{n})-f(y_{n})\rvert\ge\varepsilon\). By compactness a subsequence \((x_{n_{k}})\) converges to some \(x\in K\). Then \(d(y_{n_{k}},x)\le d(y_{n_{k}},x_{n_{k}})+d(x_{n_{k}},x)\), and both terms tend to zero, so \(y_{n_{k}}\to x\). By L04, Proposition 4.2 and continuity at \(x\), both \(f(x_{n_{k}})\) and \(f(y_{n_{k}})\) tend to \(f(x)\). Then \(\lvert f(x_{n_{k}})-f(y_{n_{k}})\rvert\to 0\), which contradicts \(\lvert f(x_{n_{k}})-f(y_{n_{k}})\rvert\ge\varepsilon\).

L06 · Research 3 · A convergent sequence with its limit

Let \(K=\{0\}\cup\{1/n : n\ge 1\}\) with the Euclidean distance on \(\R\). Prove that \(K\) is compact.

Solution

Let \((x_{n})\) be a sequence in \(K\). Case A: some value of \(K\) occurs infinitely often. The terms with that value form a constant subsequence, which converges to a point of \(K\). Case B: every value occurs only finitely often. Fix \(M\ge 1\). Only finitely many values \(1,1/2,\dots,1/M\) occur, and each occurs finitely often, so only finitely many indices \(n\) have \(x_{n}\in\{1,1/2,\dots,1/M\}\). For every other index, \(x_{n}=0\) or \(x_{n}=1/m\) with \(m>M\), so \(\lvert x_{n}\rvert\le 1/M\). Hence \(x_{n}\to 0\in K\) along all but finitely many indices, and the whole sequence has a subsequence converging to \(0\). In both cases a convergent subsequence has its limit in \(K\), so \(K\) is compact.
