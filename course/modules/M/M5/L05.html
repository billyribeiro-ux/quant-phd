Uniform convergence

  • Introduces: uniform convergence
  • Ttheorem
  • Areplicated
  • Bpublished, not settled

A sequence of functions can converge at every point while its graphs stay far apart. The distinction matters for continuity: uniform convergence in the sense of Definition 1.2 guarantees that a limit is continuous (Proposition 2.1), and pointwise convergence in the sense of Definition 1.1 does not (Example 2.3). Lesson L08 proves that a space of functions on a finite grid is complete under the sup norm (its Proposition 1.3). This lesson defines uniform convergence, proves that a uniform limit of continuous functions is continuous, shows that the pointwise version fails, and proves that the bounded functions, and the bounded continuous functions, are complete under the sup distance.

1Pointwise and uniform convergence

Let \(S\) be a nonempty set and let \(f_{n}\colon S\to\R\) and \(f\colon S\to\R\) be functions. Recall from L04 that a function is bounded when its values form a bounded set, and that \(\sup\) denotes the least upper bound.

Definition 1.1 (pointwise convergence)

The sequence \((f_{n})\) converges pointwise to \(f\) on \(S\) when, for each \(x\in S\), \(f_{n}(x)\to f(x)\) as \(n\to\infty\). Written out: for each \(x\) and each \(\varepsilon>0\) there is \(N\), which may depend on \(x\) and \(\varepsilon\), with \(\lvert f_{n}(x)-f(x)\rvert<\varepsilon\) for all \(n\ge N\).

Definition 1.2 (uniform convergence)

The sequence \((f_{n})\) converges uniformly to \(f\) on \(S\) when for each \(\varepsilon>0\) there is one \(N\), not depending on \(x\), with \(\lvert f_{n}(x)-f(x)\rvert<\varepsilon\) for all \(x\in S\) and all \(n\ge N\). The difference from Definition 1.1 is the position of the quantifier over \(x\): in the uniform case the threshold \(N\) is chosen before \(x\).

Proposition 1.3 (uniform convergence as a sup distance)

Hypotheses: (1) \(S\) is a nonempty set; (2) \(f_{n}\) and \(f\) are bounded real functions on \(S\), so that \(d_{\infty}(f_{n},f)=\sup_{x\in S}\lvert f_{n}(x)-f(x)\rvert\) is a real number as in L04, Example 1.6. Conclusion: (a) \((f_{n})\) converges uniformly to \(f\) on \(S\) if and only if \(d_{\infty}(f_{n},f)\to 0\); (b) uniform convergence implies pointwise convergence.

Proof

(a) Suppose \(d_{\infty}(f_{n},f)\to 0\). Given \(\varepsilon>0\), choose \(N\) with \(d_{\infty}(f_{n},f)<\varepsilon\) for \(n\ge N\). Each \(\lvert f_{n}(x)-f(x)\rvert\) is at most this supremum, so it is below \(\varepsilon\) for every \(x\) and every \(n\ge N\). Conversely, suppose uniform convergence. Given \(\varepsilon>0\), choose \(N\) as in Definition 1.2. For \(n\ge N\), every \(\lvert f_{n}(x)-f(x)\rvert\) is less than \(\varepsilon\), so their supremum is at most \(\varepsilon\). Hence \(d_{\infty}(f_{n},f)\le \varepsilon\) for \(n\ge N\), which is \(d_{\infty}(f_{n},f)\to 0\).

(b) Given \(x\in S\) and \(\varepsilon>0\), take \(N\) from Definition 1.2. Then \(\lvert f_{n}(x)-f(x)\rvert<\varepsilon\) for \(n\ge N\), which is Definition 1.1 at \(x\). \(\square\)

Example 1.4 (powers on the unit interval)

Let \(f_{n}(x)=x^{n}\) on \(S=[0,1]\). Each \(f_{n}\) is bounded by \(1\). For \(x\in[0,1)\), \(x^{n}\to 0\), and \(f_{n}(1)=1\) for every \(n\). So \((f_{n})\) converges pointwise to the function \(f\) with \(f(x)=0\) for \(x<1\) and \(f(1)=1\). The proof that this convergence is not uniform is Proposition 2.4 below; Lab 1 prints the sup distance from these powers to \(0\) on a grid, which is the distance to \(0\), not to \(f\).

Lab 1 · Sup distances of powers on exact grids

Before running: on the grid \(k/100\) of \([0,1]\), the sup distance from \(x^{n}\) to \(0\) is \(1\) for every printed order \(n\), because the grid contains \(1\). On the grid of \([0,1/2]\), the sup distance is \((1/2)^{n}\), and the least order with \((1/2)^{n}<1/1000\) is \(10\). The values of \(x^{n}\) at \(x=0.99\) decay as \(n\) grows. The program is exact (fractions) except for the printed floats in Part C.

"""M5 L05 lab 1: the functions x^n on [0, 1] and on [0, a], checked on exact rational grids.

Standard library only. No randomness and no network: every grid is enumerated with Fraction arithmetic, so every run
prints the same lines. A supremum over a grid is a maximum over finitely many points. A grid that contains the
endpoint of an interval gives the supremum of a monotone function exactly, because the monotone maximum sits at that
endpoint. The output is therefore exact for these functions, and it says nothing about grids that omit the endpoint.

Part A: f_n(x) = x^n on the grid k/100 for k = 0, ..., 100 (which contains 1). The sup distance from f_n to the
function 0 on [0, 1] is printed for n in (1, 2, 5, 10, 50), with the value at x = 1/2 beside it.
Part B: the same functions on [0, 1/2], on the grid k/200 for k = 0, ..., 100 (which contains 1/2). The sup distance
is printed for the same n, with a check that it equals (1/2)^n, and the least n with (1/2)^n below 1/1000.
Part C: the values of f_n at x = 0.99 are printed for n = 10, 100, 1000 as floats, and a check prints True
when f_n(1) = 1 for n = 1, 10, 100 and 1000. The pointwise limit is not computed by the program; the page states it.
"""

from __future__ import annotations

from fractions import Fraction

ORDERS = (1, 2, 5, 10, 50)
HALF = Fraction(1, 2)


def grid(right: Fraction, steps: int) -> list[Fraction]:
    """The points k * right / steps for k = 0, ..., steps, all exact. The last point is right."""
    return [right * Fraction(k, steps) for k in range(steps + 1)]


def power(x: Fraction, n: int) -> Fraction:
    """The exact value x^n for a whole number n >= 1."""
    return x**n


def sup_on_grid(values: list[Fraction]) -> Fraction:
    """The largest of the sampled values, exact. The list is nonempty."""
    return max(values)


def least_order_below(bound: Fraction, base: Fraction) -> int:
    """The least n >= 1 with base^n < bound, for 0 < base < 1 and bound > 0."""
    n = 1
    while base**n >= bound:
        n += 1
    return n


def main() -> None:
    """Print Parts A, B and C. Every value is an exact fraction or a float with ten decimals."""
    print("Part A: sup distance from x^n to 0 on [0, 1], grid k/100")
    unit = grid(Fraction(1), 100)
    for n in ORDERS:
        sup = sup_on_grid([power(x, n) for x in unit])
        print(f"order {n} sup_distance {sup} value_at_half {power(HALF, n)}")

    print("Part B: sup distance from x^n to 0 on [0, 1/2], grid k/200, with the check (1/2)^n")
    half_grid = grid(HALF, 100)
    for n in ORDERS:
        sup = sup_on_grid([power(x, n) for x in half_grid])
        print(f"order {n} sup_distance {sup} equals_half_power {sup == power(HALF, n)}")
    threshold = Fraction(1, 1000)
    print(f"least_order_with_half_power_below_1_over_1000 {least_order_below(threshold, HALF)}")

    print("Part C: pointwise limit of x^n on [0, 1] is 0 on [0, 1) and 1 at 1")
    for n in (10, 100, 1000):
        print(f"order {n} value_at_0_99 {float(power(Fraction(99, 100), n)):.10f}")
    print(f"value_at_one_for_every_order {all(power(Fraction(1), n) == 1 for n in (1, 10, 100, 1000))}")

On \([0,1]\) the printed sup distance from \(x^{n}\) to the function \(0\) stays at \(1\) for every printed order, while the value at \(x=1/2\) shrinks as the order grows. The grid on \([0,1]\) contains \(1\), where \(x^{n}\) is largest, so each printed sup is the exact supremum of \(x^{n}\) on \([0,1]\). The program does not compute the distance to the pointwise limit \(f\) of Example 1.4, which is \(0\) on \([0,1)\) and \(1\) at \(1\). The value \(d_{\infty}(f_{n},f)=1\) for every \(n\ge 1\) is proved in Proposition 2.4, and that proof, not the printed value, shows that the convergence is not uniform on \([0,1]\). On the grid of \([0,1/2]\), which contains \(1/2\), the sup distance equals \((1/2)^{n}\), which tends to zero. There \(f=0\), so this printed value is the distance to \(f\), and Proposition 2.5 with \(a=1/2\) shows that the convergence is uniform on \([0,1/2]\).

2A uniform limit of continuous functions is continuous

Proposition 2.1 (uniform limits preserve continuity)

Hypotheses: (1) \((X,d)\) is a metric space (L04, Definition 1.1); (2) each \(f_{n}\colon X\to\R\) is continuous at each point of \(X\) in the sense of L04, Definition 4.1; (3) \(f\colon X\to\R\) and \((f_{n})\) converges uniformly to \(f\) on \(X\). Conclusion: \(f\) is continuous at every point of \(X\).

Proof

Fix \(x_{0}\in X\) and \(\varepsilon>0\). By hypothesis (3), choose \(N\) with \(\lvert f_{N}(z)-f(z)\rvert<\varepsilon/3\) for every \(z\in X\). By hypothesis (2), \(f_{N}\) is continuous at \(x_{0}\), so there is \(\delta>0\) with \(\lvert f_{N}(z)-f_{N}(x_{0})\rvert<\varepsilon/3\) whenever \(d(x_{0},z)<\delta\). For such \(z\), the triangle inequality on \(\R\) gives \[ \lvert f(z)-f(x_{0})\rvert\le \lvert f(z)-f_{N}(z)\rvert+\lvert f_{N}(z)-f_{N}(x_{0})\rvert+\lvert f_{N}(x_{0})-f(x_{0})\rvert<\frac{\varepsilon}{3}+\frac{\varepsilon}{3}+\frac{\varepsilon}{3}=\varepsilon. \] So \(f\) is continuous at \(x_{0}\). Since \(x_{0}\) was arbitrary, \(f\) is continuous. \(\square\)

Remark 2.2 (the choice of N is the whole point)

In the proof, \(N\) depends on \(\varepsilon\) alone, not on \(x_{0}\). Hypothesis (3) gives one \(N\) for all points at once, which is what makes \(\lvert f_{N}(x_{0})-f(x_{0})\rvert\) small at the same time as \(\lvert f(z)-f_{N}(z)\rvert\) is small for every \(z\). With pointwise convergence the threshold may depend on the point, and Example 2.3 shows what then fails.

Example 2.3 (a pointwise limit of continuous functions need not be continuous)

Let \(f_{n}(x)=x^{n}\) on \([0,1]\). Each \(f_{n}\) is continuous at every point of \([0,1]\): for \(x,y\in[0,1]\), \(x^{n}-y^{n}=(x-y)\sum_{k=0}^{n-1}x^{k}y^{n-1-k}\), every term of the sum lies in \([0,1]\), and so \(\lvert x^{n}-y^{n}\rvert\le n\lvert x-y\rvert\). Given \(\varepsilon>0\), the choice \(\delta=\varepsilon/n\) satisfies L04, Definition 4.1 at every point. The pointwise limit \(f\) of Example 1.4 is discontinuous at \(1\). Proof: let \(x_{k}=1-1/k\) for \(k\ge 2\). Then \(x_{k}\to 1\) and \(f(x_{k})=0\) for each \(k\), because \(x_{k}<1\). But \(f(1)=1\). By L04, Proposition 4.2, a map that is continuous at \(1\) must send \(x_{k}\to 1\) to \(f(x_{k})\to f(1)\). Here \(0\not\to 1\), so \(f\) is not continuous at \(1\).

Proposition 2.4 (the powers do not converge uniformly on [0, 1])

Hypotheses: (1) \(f_{n}(x)=x^{n}\) on \(S=[0,1]\); (2) \(f\) is the pointwise limit of Example 1.4. Conclusion: \(d_{\infty}(f_{n},f)=1\) for every \(n\ge 1\). So \((f_{n})\) does not converge uniformly to \(f\) on \([0,1]\).

Proof

Let \(n\ge 1\). At \(x=1\), \(\lvert f_{n}(1)-f(1)\rvert=\lvert 1-1\rvert=0\), so this point does not contribute. Consider \(x\in[0,1)\). Here \(\lvert f_{n}(x)-f(x)\rvert=x^{n}\), and \(x^{n}\le 1\). So \(d_{\infty}(f_{n},f)\le 1\). For the reverse inequality, let \(t\in[0,1)\). Put \(x=t^{1/n}\), which lies in \([0,1)\) and satisfies \(x^{n}=t\). Then \(d_{\infty}(f_{n},f)\ge t\). Since \(t<1\) was arbitrary, \(d_{\infty}(f_{n},f)\ge 1\). Hence \(d_{\infty}(f_{n},f)=1\) for every \(n\). By Proposition 1.3(a), the convergence is not uniform. \(\square\)

Proposition 2.5 (uniform convergence on [0, a] for a < 1)

Hypotheses: (1) \(f_{n}(x)=x^{n}\) and \(0<a<1\); (2) \(S=[0,a]\). Conclusion: \(d_{\infty}(f_{n},0)=a^{n}\) for every \(n\ge 1\), and \(a^{n}\to 0\). So \(f_{n}\to 0\) uniformly on \([0,a]\).

Proof

For \(x\in[0,a]\), \(0\le x^{n}\le a^{n}\), since \(0\le x\le a\) and the power \(t\mapsto t^{n}\) is nondecreasing on \([0,\infty)\). The value at \(x=a\) equals \(a^{n}\), so the supremum is \(a^{n}\). To show \(a^{n}\to 0\), write \(a=1/(1+h)\) with \(h>0\). By induction on \(n\), \((1+h)^{n}\ge 1+nh\): the case \(n=1\) is equality, and if \((1+h)^{n}\ge 1+nh\), then \((1+h)^{n+1}\ge (1+nh)(1+h)\ge 1+(n+1)h\). Hence \(0<a^{n}=(1+h)^{-n}\le 1/(1+nh)\). Given \(\varepsilon>0\), choose \(n\) with \(nh>1/\varepsilon\); then \(a^{n}<\varepsilon\), and \(a^{m}\le a^{n}\) for \(m\ge n\). So \(a^{n}\to 0\). By Proposition 1.3(a), the convergence on \([0,a]\) is uniform. \(\square\)

3Completeness of the bounded and of the bounded continuous functions

Proposition 3.1 (the bounded functions are complete under the sup distance)

Hypotheses: (1) \(S\) is a nonempty set; (2) \(B(S)\) is the set of bounded real functions on \(S\) with the metric \(d_{\infty}\) of L04, Example 1.6 (a metric space by L04, Proposition 1.7); (3) \((f_{n})\) is a Cauchy sequence in \((B(S),d_{\infty})\); (4) every Cauchy sequence of real numbers converges (L02, Theorem 2.5, proved there from L01, Definition 1.1). Conclusion: there is \(f\in B(S)\) with \(d_{\infty}(f_{n},f)\to 0\).

Proof

Step 1, a pointwise limit. For each \(x\in S\), \(\lvert f_{m}(x)-f_{n}(x)\rvert\le d_{\infty}(f_{m},f_{n})\), so \((f_{n}(x))_{n}\) is a Cauchy sequence of real numbers. By hypothesis (4), it converges; call its limit \(f(x)\). This defines a function \(f\colon S\to\R\).

Step 2, uniform closeness. Let \(\varepsilon>0\) and choose \(N\) with \(d_{\infty}(f_{m},f_{n})<\varepsilon\) for \(m,n\ge N\). Fix \(n\ge N\) and \(x\in S\). For every \(m\ge N\), \(\lvert f_{n}(x)-f_{m}(x)\rvert<\varepsilon\). Letting \(m\to\infty\) and using the continuity of the absolute value on \(\R\) gives \(\lvert f_{n}(x)-f(x)\rvert\le\varepsilon\). Since \(x\) was arbitrary, \(d_{\infty}(f_{n},f)\le\varepsilon\) for every \(n\ge N\).

Step 3, boundedness. Take \(n=N\). Let \(M\) bound \(\lvert f_{N}\rvert\). Then \(\lvert f(x)\rvert\le \lvert f_{N}(x)\rvert+\varepsilon\le M+\varepsilon\) for every \(x\in S\), so \(f\in B(S)\). Step 2 then says \(d_{\infty}(f_{n},f)\to 0\). \(\square\)

Proposition 3.2 (the bounded continuous functions are complete)

Hypotheses: (1) \((X,d)\) is a metric space; (2) \(C_{b}(X)\) is the set of bounded functions \(f\colon X\to\R\) that are continuous at every point of \(X\), with the metric \(d_{\infty}\) of Example 1.6 applied on \(X\) (so \(C_{b}(X)\subseteq B(X)\)); (3) \((f_{n})\) is a Cauchy sequence in \(C_{b}(X)\). Conclusion: there is \(f\in C_{b}(X)\) with \(d_{\infty}(f_{n},f)\to 0\).

Proof

By Proposition 3.1 with \(S=X\), there is a bounded function \(f\) with \(d_{\infty}(f_{n},f)\to 0\), so \((f_{n})\) converges uniformly to \(f\). Each \(f_{n}\) is continuous by hypothesis (3), so Proposition 2.1 gives that \(f\) is continuous. Thus \(f\in C_{b}(X)\), and \(d_{\infty}(f_{n},f)\to 0\) in \(C_{b}(X)\). \(\square\)

Remark 3.3 (what the two propositions do not give)

Propositions 3.1 and 3.2 give a limit in the same space as the Cauchy sequence. They do not say that every bounded function is a limit of continuous functions; that question is not treated in this lesson.

4Where the canon breaks

The following examples show where the hypotheses of Propositions 2.1, 3.1 and 3.2 are needed or fail.

Pointwise convergence. Example 2.3 shows that the pointwise limit of continuous functions can be discontinuous. The uniform hypothesis in Proposition 2.1 cannot be dropped.

Non-uniform convergence on the closed interval. Proposition 2.5 gives uniform convergence on \([0,a]\) for every \(a<1\), and Proposition 2.4 shows that the convergence fails on \([0,1]\). On \([0,a]\) with \(a<1\), the sup distance \(a^{n}\) is at most \(a<1\) for every \(n\ge 1\). On \([0,1]\), the points near \(1\) bring the sup distance back to \(1\) for every \(n\).

Unbounded functions. Let \(f_{n}(x)=x/n\) on \(\R\). For each \(n\), \(\sup_{x\in\R}\lvert x/n\rvert=\infty\), so \(d_{\infty}\) is not a real number for these functions. The pointwise limit \(0\) exists, but no single \(N\) works for \(\varepsilon=1\): for any \(N\), the function \(f_{N}\) takes the value \(2\) at \(x=2N\), and \(\lvert f_{N}(2N)\rvert=2>1\). Propositions 3.1 and 3.2 are therefore stated for bounded functions, where \(d_{\infty}\) is a real number (L04, Proposition 1.7).

5Misconceptions

  1. “Pointwise convergence preserves continuity.”

    It does not. Example 2.3 gives continuous \(x^{n}\) on \([0,1]\) whose pointwise limit jumps at \(1\). Proposition 2.1 needs uniform convergence, and Proposition 2.4 shows that \(x^{n}\) does not converge uniformly on \([0,1]\).

  2. “Uniform convergence on \([0,a]\) for every \(a<1\) gives uniform convergence on \([0,1]\).”

    The first is true (Proposition 2.5) and the second is false (Proposition 2.4). The sup distance to \(f\) on \([0,1]\) stays at \(1\), while on each \([0,a]\) it is \(a^{n}\). Lab 1, Part A, prints the sup distance from \(x^{n}\) to \(0\) on the grid of \([0,1]\) as \(1\). That is the distance to \(0\), not to \(f\), so the lab does not compute the value that Proposition 2.4 proves.

  3. “If each \(x\) has its own \(N_x\), the convergence is uniform.”

    Each \(x\) having its own threshold is pointwise convergence. Uniform convergence needs a single \(N\) for all \(x\) at once. For \(x^{n}\) on \([0,1]\), no single \(N\) serves every \(x\), as Proposition 2.4 shows.

6Problem set

Mechanics

L05 · Mechanics 1 · Sup distances of powers

On \([0,1]\), compute \(d_{\infty}(x^{n},0)\) for \(n=3\) and \(n=10\), and compute \(d_{\infty}(x^{3},0)\) on \([0,1/2]\).

Solution

On \([0,1]\), \(x^{n}\) is nondecreasing and equals \(1\) at \(x=1\), so the supremum is \(1\) for both \(n=3\) and \(n=10\). On \([0,1/2]\), the supremum is attained at \(x=1/2\), and equals \((1/2)^{3}=1/8\), by the argument of Proposition 2.5.

L05 · Mechanics 2 · A sup distance that shrinks

Let \(f_{n}(x)=x/n\) on \([0,1]\) and \(f=0\). Compute \(d_{\infty}(f_{n},f)\) and state whether \(f_{n}\to f\) uniformly.

Solution

On \([0,1]\), \(\lvert x/n-0\rvert=x/n\) is largest at \(x=1\), so \(d_{\infty}(f_{n},f)=1/n\). Since \(1/n\to 0\), Proposition 1.3(a) gives uniform convergence.

L05 · Mechanics 3 · Shifted functions

Let \(f_{n}(x)=x+1/n\) on \([0,1]\) and \(f(x)=x\). Compute \(d_{\infty}(f_{n},f)\) and say whether the convergence is uniform.

Solution

For every \(x\), \(\lvert f_{n}(x)-f(x)\rvert=1/n\), a constant in \(x\). So \(d_{\infty}(f_{n},f)=1/n\), which tends to zero, and the convergence is uniform on \([0,1]\).

Proof

L05 · Proof 1 · Sums of uniformly convergent sequences

Let \(f_{n}\to f\) and \(g_{n}\to g\) uniformly on a set \(S\). Prove that \(f_{n}+g_{n}\to f+g\) uniformly on \(S\).

Solution

Let \(\varepsilon>0\). Choose \(N_{1}\) with \(\lvert f_{n}(x)-f(x)\rvert<\varepsilon/2\) for all \(x\in S\) and \(n\ge N_{1}\), and \(N_{2}\) with the same bound for \(g\). For \(n\ge\max(N_{1},N_{2})\) and every \(x\), the triangle inequality gives \(\lvert (f_{n}+g_{n})(x)-(f+g)(x)\rvert\le \lvert f_{n}(x)-f(x)\rvert+\lvert g_{n}(x)-g(x)\rvert<\varepsilon\). The threshold does not depend on \(x\), so the convergence is uniform.

L05 · Proof 2 · A uniform limit of bounded functions is bounded

Let each \(f_{n}\) be bounded on \(S\), and let \(f_{n}\to f\) uniformly on \(S\). Prove that \(f\) is bounded.

Solution

Choose \(N\) with \(\lvert f_{N}(x)-f(x)\rvert<1\) for all \(x\in S\). Let \(M\) bound \(\lvert f_{N}\rvert\). Then \(\lvert f(x)\rvert\le \lvert f_{N}(x)\rvert+1\le M+1\) for every \(x\), so \(f\) is bounded. The proof uses a single \(N\), which is the uniformity.

L05 · Proof 3 · The triangle inequality for sup distances

Let \(f,g\in B(S)\) with \(d_{\infty}(f,g)\le \delta\), and let \(h\in B(S)\). Prove that \(\lvert d_{\infty}(f,h)-d_{\infty}(g,h)\rvert\le\delta\).

Solution

By the triangle inequality, axiom (M3) of L04, Definition 1.1, applied to \(d_{\infty}\) (a metric by L04, Proposition 1.7), \(d_{\infty}(f,h)\le d_{\infty}(f,g)+d_{\infty}(g,h)\le \delta+d_{\infty}(g,h)\). Exchanging the roles of \(f\) and \(g\), symmetry (axiom (M2) of L04, Definition 1.1) and the triangle inequality (axiom (M3)) give \(d_{\infty}(g,h)\le d_{\infty}(g,f)+d_{\infty}(f,h)\le \delta+d_{\infty}(f,h)\). Together these say the difference of the two distances is at most \(\delta\) in absolute value.

Empirical

L05 · Empirical 1 · The sup distance on the full interval

Read Part A of Lab 1. For each printed order \(n\), what is the sup distance from \(x^{n}\) to \(0\) on the grid of \([0,1]\), and what is the value at \(x=1/2\)? State how the two numbers differ as \(n\) grows.

Solution

The output reads "sup_distance 1" for every printed order, and the value at \(1/2\) is \(1/2\), \(1/4\), \(1/32\), \(1/1024\), and \(1/2^{50}\) for orders 1, 2, 5, 10, 50. The sup stays at \(1\) while the value at \(1/2\) shrinks. The sup is computed on the finite grid, and it equals the true supremum because the grid contains \(1\), where the maximum is attained.

L05 · Empirical 2 · The least order below a threshold

Part B reports the least \(n\) with \((1/2)^{n}<1/1000\). Confirm the printed value by computing \((1/2)^{9}\) and \((1/2)^{10}\).

Solution

\((1/2)^{9}=1/512>1/1000\), and \((1/2)^{10}=1/1024<1/1000\). So the least order is \(10\), which matches the printed "least_order_with_half_power_below_1_over_1000 10".

L05 · Empirical 3 · A value at 0.99

Part C prints the value of \(x^{n}\) at \(x=0.99\) for \(n=100\). Compute \(0.99^{100}\) to three decimal places, and state which printed line it matches.

Solution

Since \(\ln 0.99\approx -0.0100503\), \(0.99^{100}=e^{100\ln 0.99}\approx e^{-1.00503}\approx 0.36603\). To three decimals that is \(0.366\). The printed line "order 100 value_at_0_99 0.3660323413" matches.

Research

L05 · Research 1 · Non-uniform convergence on the half-open interval

Let \(f_{n}(x)=x^{n}\) and \(f\) as in Example 1.4, now on \(S=[0,1)\). Prove that \(d_{\infty}(f_{n},f)=1\) for every \(n\), so the convergence is not uniform on \([0,1)\).

Solution

On \([0,1)\), \(f(x)=0\), so \(\lvert f_{n}(x)-f(x)\rvert=x^{n}\le 1\), and \(d_{\infty}(f_{n},f)\le 1\). For \(t\in[0,1)\), the point \(x=t^{1/n}\) lies in \([0,1)\) and gives \(x^{n}=t\). So the supremum is at least \(t\) for each \(t<1\), which forces it to be at least \(1\). Thus \(d_{\infty}(f_{n},f)=1\) for each \(n\), and by Proposition 1.3(a) the convergence is not uniform.

L05 · Research 2 · Continuous functions that converge to an indicator

Let \(f_{n}(x)=\max(0,\,1-n\lvert x-1/2\rvert)\) on \([0,1]\). Show that each \(f_{n}\) is continuous with values in \([0,1]\), that \(f_{n}\) converges pointwise to the indicator \(\mathbf{1}_{\{1/2\}}\), and that this limit is discontinuous at \(1/2\).

Solution

Each \(f_{n}\) is continuous. Put \(g(x)=1-n\lvert x-1/2\rvert\). Then \(\lvert g(x)-g(y)\rvert\le n\lvert x-y\rvert\), because \(\lvert\,\lvert u\rvert-\lvert v\rvert\,\rvert\le\lvert u-v\rvert\). The map \(t\mapsto\max(0,t)\) also satisfies \(\lvert\max(0,s)-\max(0,t)\rvert\le\lvert s-t\rvert\), checked on the three cases \(s,t\ge 0\), \(s,t<0\), and \(s<0\le t\) (or the reverse). So \(\lvert f_{n}(x)-f_{n}(y)\rvert\le n\lvert x-y\rvert\), and \(\delta=\varepsilon/n\) gives continuity at every point. The values of \(f_{n}\) lie in \([0,1]\) because \(\max(0,\cdot)\ge 0\) and \(g\le 1\). At \(x=1/2\), \(f_{n}(1/2)=1\) for every \(n\). If \(x\ne 1/2\), then \(n\lvert x-1/2\rvert\ge 1\) once \(n\ge 1/\lvert x-1/2\rvert\), so \(f_{n}(x)=0\) from then on. The limit is \(1\) at \(1/2\) and \(0\) elsewhere. For discontinuity at \(1/2\), take \(x_{k}=1/2+1/k\) for \(k\ge 2\), so that \(x_{k}\in[0,1]\). Then \(x_{k}\to 1/2\) but the limit equals \(0\) at each \(x_{k}\), while its value at \(1/2\) is \(1\). By L04, Proposition 4.2 the limit is not continuous at \(1/2\). The convergence cannot be uniform, because a uniform limit of continuous functions is continuous (Proposition 2.1).

L05 · Research 3 · A summable sequence of steps

Let \((f_{n})\) lie in \(B(S)\) and suppose \(\sum_{k=1}^{\infty} d_{\infty}(f_{k},f_{k+1})<\infty\). Prove that \((f_{n})\) converges in \(B(S)\).

Solution

For \(m>n\), the triangle inequality for \(d_{\infty}\) (L04, Proposition 1.7) and repeated use of it give \(d_{\infty}(f_{n},f_{m})\le \sum_{k=n}^{m-1} d_{\infty}(f_{k},f_{k+1})\). The tail \(\sum_{k\ge n}d_{\infty}(f_{k},f_{k+1})\) of a convergent series tends to zero, so \((f_{n})\) is Cauchy in \(B(S)\). By Proposition 3.1 it converges to some \(f\in B(S)\).

8Retrieval quiz

  1. What distinguishes uniform from pointwise convergence?

    Options

    Definition 1.2 places the choice of \(N\) before \(x\). The other two options are properties of particular examples, not the definition.

  2. On \([0,1]\), what is \(d_{\infty}(x^{10},0)\)?

    \(x^{10}\) is largest at \(x=1\), where it equals \(1\).

  3. On \([0,1/2]\), what is \(d_{\infty}(x^{3},0)\)?

    On \([0,a]\) the sup distance is \(a^{n}\), so here it is \((1/2)^{3}=1/8=0.125\).

  4. Does \(x^{n}\) converge uniformly on \([0,1]\)?

    Options

    Proposition 2.4 gives \(d_{\infty}(f_{n},f)=1\) for every \(n\). The pointwise limit is not \(0\) at \(x=1\), and the continuity of each \(f_{n}\) does not transfer to the limit without uniformity.

  5. If \(f_{n}\to f\) uniformly and each \(f_{n}\) is continuous, which is true?

    Options

    Proposition 2.1 is exactly this statement, with the \(\varepsilon/3\) proof.

  6. To three decimals, what is \(0.99^{100}\)?

    \(0.99^{100}\approx 0.36603\), so to three decimals it is \(0.366\), matching Part C of Lab 1.

  7. Which statement about the sup distance on \(\R\) for \(f_{n}(x)=x/n\) is correct?

    Options

    On \(\R\), \(\lvert x/n\rvert\) has no upper bound, so the supremum is infinite and the sup-distance description does not apply. The value \(1/n\) is the sup on \([0,1]\), not on \(\R\).

  8. Proposition 2.1 has a hypothesis that pointwise convergence does not supply. Which one is it?

    Options

    Hypothesis (3) of Proposition 2.1 is uniform convergence. Example 2.3 shows that pointwise convergence of continuous functions does not give continuity.

  9. What is the least \(n\) with \((1/2)^{n}<1/1000\)?

    \((1/2)^{9}=1/512\) is above \(1/1000\), and \((1/2)^{10}=1/1024\) is below it.
