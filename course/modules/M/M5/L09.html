Value-function iteration with a certified error bound

  • Uses: contraction mapping, Banach fixed-point theorem, contraction property of the discounted Bellman operator, Cauchy sequence, completeness of the real numbers
  • Introduces: value-function iteration with a certified error bound
  • Ttheorem

  • Bpublished, not settled

A solver for a dynamic savings problem repeats one operator until the values stop moving. Stopping when the last change is small is not enough, because the error can be larger than the change. This lesson proves a bound that uses only the computed iterates and the discount factor \(\beta\) of Section 1, and that is valid for the fixed point of the grid operator defined in Section 1. The bound rests on the contraction property of Lesson 8 and the Banach fixed-point theorem of Lesson 7. Lab 1 runs the iteration on the four-point grid of Lesson 8 and compares the bound with the error measured against a tight reference solve.

1The grid model and its operator

This lesson restates the model of Lesson 8 so that it can be read alone. The state space is a finite grid \(G = (0.25, 0.5, 0.75, 1.0)\) of capital values. Output from capital \(k\) is \(k^{\alpha}\), with \(\alpha = 1/2\). The feasible next states from \(k\) are \(F(k) = \{k' \in G : k' \le k^{\alpha}\}\). Saving \(k'\) leaves consumption \(c = k^{\alpha} - k' \ge 0\), which earns the utility \(\sqrt{c}\). The discount factor \(\beta\) lies in \((0, 1)\), and Lab 1 uses \(\beta = 0.9\). A rule that gives the next state \(k' \in F(k)\) for each \(k\) is a policy.

Write \(\R^{G}\) for the real functions \(V\) on \(G\), with sup norm \(\lVert V \rVert_\infty = \max_{k \in G} |V(k)|\). The norm is defined here. The discounted Bellman operator \(\mathcal{B}\) sends \(V\) to the function

\[ (\mathcal{B}V)(k) = \max_{k' \in F(k)} \bigl\{ \sqrt{k^{\alpha} - k'} + \beta\, V(k') \bigr\}, \qquad k \in G. \]

Each \(F(k)\) contains \(0.25\), because \(0.25 \le k^{\alpha}\) for every \(k \in G\): the smallest case is \(0.25^{1/2} = 0.5\). So each \(F(k)\) is finite and nonempty, and each maximum is over a finite nonempty set. The maximum is therefore attained, and \(\mathcal{B}V\) is a function on \(G\).

Lemma 1.1 (the grid space is complete)

Hypotheses: (1) \(G\) is finite; (2) the distance is \(d(V, W) = \lVert V - W \rVert_\infty\). Conclusion: every Cauchy sequence in \((\R^{G}, d)\) converges to a function on \(G\). A metric space in which every Cauchy sequence converges is complete, so \((\R^{G}, d)\) is complete.

Proof

Let \((V_m)\) be a Cauchy sequence in \(\R^{G}\), and fix \(k \in G\). For all \(m, l\), \(|V_m(k) - V_l(k)| \le \lVert V_m - V_l \rVert_\infty\), so the real sequence \((V_m(k))_m\) is Cauchy. By completeness of the reals (Lesson 1) and the fact that a Cauchy sequence of reals converges (Lesson 2), it has a limit \(a(k) \in \R\). Put \(a = (a(k))_{k \in G}\). Let \(\varepsilon > 0\), and choose \(M\) so that \(\lVert V_m - V_l \rVert_\infty \le \varepsilon\) for \(m, l \ge M\). For a fixed \(k\) and \(m \ge M\), letting \(l \to \infty\) gives \(|V_m(k) - a(k)| \le \varepsilon\). Since this holds for each of the finitely many \(k\), \(\lVert V_m - a \rVert_\infty \le \varepsilon\) for \(m \ge M\). So \(V_m \to a\).

Lemma 1.2 (the operator is a contraction)

Hypotheses: (1) \(0 < \beta < 1\); (2) \(V, W \in \R^{G}\). Conclusion: \(\lVert \mathcal{B}V - \mathcal{B}W \rVert_\infty \le \beta \lVert V - W \rVert_\infty\). This is part (a) of Theorem 2.2 of Lesson 8, and its proof is repeated so that this chain of results is complete on this page.

Proof

Put \(\delta = \lVert V - W \rVert_\infty\), and fix \(k \in G\). The set \(F(k)\) does not depend on the function, so a maximizer \(k'_{W}\) for \((\mathcal{B}W)(k)\) is also feasible for \((\mathcal{B}V)(k)\). Hence \((\mathcal{B}V)(k) \ge \sqrt{k^{\alpha} - k'_{W}} + \beta V(k'_{W}) \ge \sqrt{k^{\alpha} - k'_{W}} + \beta W(k'_{W}) - \beta \delta = (\mathcal{B}W)(k) - \beta\delta\), because \(|V(k') - W(k')| \le \delta\) for every \(k'\). Exchanging \(V\) and \(W\) gives \((\mathcal{B}W)(k) \ge (\mathcal{B}V)(k) - \beta\delta\). So \(|(\mathcal{B}V)(k) - (\mathcal{B}W)(k)| \le \beta\delta\) for every \(k\), which is the claim.

Theorem 1.3 (the grid fixed point; Banach)

Hypotheses, as in the Banach fixed-point theorem of Lesson 7: (1) \((X, d)\) is a complete metric space; (2) \(\Psi \colon X \to X\) is a contraction with modulus \(\beta \in (0, 1)\); (3) \(X\) is nonempty. Conclusion: \(\Psi\) has exactly one fixed point \(\xi^{\ast}\), and for every starting point \(x_0\) the iterates \(x_{n+1} = \Psi x_n\) converge to \(\xi^{\ast}\). Apply this with \(X = \R^{G}\), the sup norm, and \(\Psi = \mathcal{B}\). Hypothesis (1) holds by Lemma 1.1, and hypothesis (2) holds with modulus \(\beta \in (0, 1)\) by Lemma 1.2. Hypothesis (3) holds because the zero function lies in \(\R^{G}\). So \(\mathcal{B}\) has exactly one fixed point \(V^{\ast} \in \R^{G}\), and \(V_n \to V^{\ast}\) for every starting function \(V_0\).

2The iteration and its certified error

Start from a function \(V_0\) on \(G\) (Lab 1 uses \(V_0 = 0\)). The iteration replaces the current function by its image under \(\mathcal{B}\).

Definition 2.1 (value-function iteration)

The value-function iteration from \(V_0 \in \R^{G}\) is the sequence \(V_{n+1} = \mathcal{B}V_n\) for \(n \ge 0\). The function \(V_n\) is the iterate after \(n\) steps.

Definition 2.2 (certified error)

For \(n \ge 1\), the certified error after \(n\) steps is \(\operatorname{cert}_n = \dfrac{\beta}{1 - \beta}\,\lVert V_n - V_{n-1} \rVert_\infty\). It is computed from two iterates, without knowing \(V^{\ast}\). It is called a posteriori because it uses the computed iterates, not a formula for the error in terms of the starting function.

Lemma 2.3 (three inequalities for the iteration)

Hypotheses: (1) \(0 < \beta < 1\); (2) \(V_0 \in \R^{G}\) and \(V_{n+1} = \mathcal{B}V_n\); (3) \(V^{\ast}\) is the fixed point of Theorem 1.3. Conclusion, with \(\lVert \cdot \rVert = \lVert \cdot \rVert_\infty\): (a) \(\lVert V_{n+1} - V_n \rVert \le \beta \lVert V_n - V_{n-1} \rVert\) for \(n \ge 1\); (b) \((1 - \beta)\lVert V_n - V^{\ast} \rVert \le \lVert V_{n+1} - V_n \rVert\) for \(n \ge 0\); (c) \(\lVert V_n - V^{\ast} \rVert \le \dfrac{\beta}{1 - \beta}\lVert V_n - V_{n-1} \rVert\) for \(n \ge 1\).

Proof

(a) Apply Lemma 1.2 with \(V = V_n\) and \(W = V_{n-1}\). It gives \(\lVert V_{n+1} - V_n \rVert = \lVert \mathcal{B}V_n - \mathcal{B}V_{n-1} \rVert \le \beta \lVert V_n - V_{n-1} \rVert\).

(b) By the triangle inequality, \(\lVert V_n - V^{\ast} \rVert \le \lVert V_n - V_{n+1} \rVert + \lVert V_{n+1} - V^{\ast} \rVert\). Since \(V_{n+1} = \mathcal{B}V_n\) and \(V^{\ast} = \mathcal{B}V^{\ast}\), Lemma 1.2 gives \(\lVert V_{n+1} - V^{\ast} \rVert \le \beta \lVert V_n - V^{\ast} \rVert\). Substituting, \(\lVert V_n - V^{\ast} \rVert \le \lVert V_n - V_{n+1} \rVert + \beta \lVert V_n - V^{\ast} \rVert\), and subtracting \(\beta \lVert V_n - V^{\ast} \rVert\) from both sides gives (b).

(c) Divide (b) by \(1 - \beta > 0\), and use (a) to bound \(\lVert V_{n+1} - V_n \rVert\) by \(\beta \lVert V_n - V_{n-1} \rVert\). This gives \(\lVert V_n - V^{\ast} \rVert \le \dfrac{\beta}{1 - \beta}\lVert V_n - V_{n-1} \rVert\).

Theorem 2.4 (certified stopping rule)

Hypotheses: (1) \(0 < \beta < 1\); (2) \(V_0 \in \R^{G}\) and \(V_{n+1} = \mathcal{B}V_n\); (3) a tolerance \(\tau > 0\). Let \(N\) be the first \(n \ge 1\) with \(\operatorname{cert}_n \le \tau\). Conclusion: \(N\) is finite, and \(\lVert V_N - V^{\ast} \rVert_\infty \le \operatorname{cert}_N \le \tau\).

Proof

By Lemma 2.3(a) and induction on \(n\), \(\lVert V_n - V_{n-1} \rVert \le \beta^{\,n-1} \lVert V_1 - V_0 \rVert\) for \(n \ge 1\). Hence \(\operatorname{cert}_n \le \dfrac{\beta^{n}}{1 - \beta}\lVert V_1 - V_0 \rVert\). Since \(0 < \beta < 1\), the sequence \(\beta^{n}\) tends to zero: write \(\beta = 1/(1 + h)\) with \(h = (1 - \beta)/\beta > 0\). Induction gives \((1 + h)^{n} \ge 1 + nh\), so \(0 < \beta^{n} \le 1/(1 + nh)\), and \(1/(1 + nh)\) tends to zero because for each \(\varepsilon > 0\) the Archimedean property (Lesson 1, Theorem 1.2) gives an \(n\) with \(nh > 1/\varepsilon\). So \(\operatorname{cert}_n\) falls below \(\tau\) for some \(n\), and \(N\) is finite. The second inequality is Lemma 2.3(c) at \(n = N\), and the third is the definition of \(N\).

Remark 2.5 (what the certificate covers)

Theorem 2.4 bounds the distance to \(V^{\ast}\), the fixed point of the grid operator on \(G\). It does not bound the distance to the value of the continuous problem, which the grid only approximates. The discretization error is not covered by the certificate, and Misconception 2 in Section 4 states this limitation.

Lab 1 · Iteration stopped by the certified bound

SIMULATED The inputs are generated model parameters, not data: the grid \(G = (0.25, 0.5, 0.75, 1.0)\), \(\alpha = 1/2\), \(\beta = 0.9\), and the starting function \(V_0 = 0\). These are the parameters of Lesson 8's Lab 1. Stated before running. The lab prints the reference solution at certified error at most \(10^{-12}\), its policy, and three certified stops at tolerances \(10^{-2}\), \(10^{-4}\) and \(10^{-6}\). Each stop prints its iteration count, its certified error, and the actual error against the reference. Theorem 2.4 and Lemma 2.3(c) predict that the actual error is at most the certified error at every stop (the bound_holds field adds \(10^{-12}\) for the reference's own error), and that each certified error is at most its tolerance. The lab also prints a fixed count of 10 steps, and a naive stop on the size of the last step at \(10^{-6}\). The code uses no random draws.

"""M5 L09 lab 1: value-function iteration on a finite grid, stopped by an a posteriori bound.

Generated model parameters, not data. The state k is capital on the grid GRID = (0.25, 0.5, 0.75, 1.0). Output is
k ** ALPHA with ALPHA = 0.5. The planner chooses next-period capital k' in GRID with k' <= k ** ALPHA, so the
consumption c = k ** ALPHA - k' is nonnegative, and the utility is u(c) = sqrt(c). The discount factor is
BETA = 0.9. The discounted Bellman operator is

    (B V)(k) = max over k' in F(k) of [ sqrt(k ** ALPHA - k') + BETA * V(k') ],
    where F(k) = {k' in GRID : k' <= k ** ALPHA} is the feasible set from k.

Each F(k) contains 0.25, because 0.25 <= k ** ALPHA for every k in GRID, so each maximum is over a nonempty finite set.
This is the operator of Lesson 8 of this unit, with the same grid and parameters as its Lab 1.

The iteration starts from V_0 = 0 and sets V_{n+1} = B V_n. For n >= 1 the certified error is
cert_n = BETA/(1 - BETA) * max_k |V_n(k) - V_{n-1}(k)|. The reference V_ref is the iterate at which cert_n <= 1e-12.
By Lemma 2.3(c), its distance to the fixed point V* of B on GRID is at most 1e-12. For each certified stop the lab
prints whether the actual error max_k |V_n(k) - V_ref(k)| is at most cert_n + 1e-12 (field bound_holds), and whether
cert_n <= tol (field cert_within_tol). The added 1e-12 allows for the reference error.

Floats are used throughout, so a printed value is correct only as far as double-precision arithmetic allows.
No random draws. Standard library only.
"""

from __future__ import annotations

import math
from collections.abc import Callable

ALPHA = 0.5
BETA = 0.9
GRID = (0.25, 0.5, 0.75, 1.0)
TOLERANCES = (1e-2, 1e-4, 1e-6)
NAIVE_TOL = 1e-6
FIXED_COUNT = 10
REFERENCE_TOL = 1e-12
SLACK = 1e-12


def feasible(k: float) -> list[int]:
    """Indices j of the grid points k' with k' <= k ** ALPHA, the feasible next states from k."""
    output = k**ALPHA
    return [j for j, kp in enumerate(GRID) if kp <= output]


def bellman(values: list[float]) -> list[float]:
    """Apply the discounted Bellman operator to a value vector indexed like GRID."""
    out: list[float] = []
    for k in GRID:
        output = k**ALPHA
        best = max(math.sqrt(output - GRID[j]) + BETA * values[j] for j in feasible(k))
        out.append(best)
    return out


def sup_distance(a: list[float], b: list[float]) -> float:
    """The sup norm of the difference of two vectors on GRID."""
    return max(abs(x - y) for x, y in zip(a, b, strict=True))


def certified(prev: list[float], cur: list[float]) -> float:
    """The a posteriori bound beta/(1 - beta) times the last step, from V_{n-1} and V_n."""
    return BETA / (1 - BETA) * sup_distance(prev, cur)


def iterate_until(stop: Callable[[list[float], list[float]], bool]) -> tuple[int, list[float], list[float]]:
    """Iterate V_{n+1} = B V_n from V_0 = 0. Return (n, V_n, V_{n-1}) at the first n >= 1 where stop holds."""
    prev = [0.0] * len(GRID)
    cur = bellman(prev)
    n = 1
    while not stop(prev, cur):
        prev, cur = cur, bellman(cur)
        n += 1
    return n, cur, prev


def iterate_count(count: int) -> tuple[list[float], list[float]]:
    """Return (V_count, V_{count-1}) from V_0 = 0 after a fixed number of steps, for count >= 1."""
    prev = [0.0] * len(GRID)
    cur = bellman(prev)
    for _ in range(count - 1):
        prev, cur = cur, bellman(cur)
    return cur, prev


def certified_stop(tol: float) -> Callable[[list[float], list[float]], bool]:
    """The stopping rule: stop when the certified error is at most tol."""

    def stop(prev: list[float], cur: list[float]) -> bool:
        return certified(prev, cur) <= tol

    return stop


def main() -> None:
    """Print the reference solve, the policy, the certified stops, a fixed count, and the naive step rule."""
    ref_n, v_ref, ref_prev = iterate_until(lambda p, c: certified(p, c) <= REFERENCE_TOL)
    print(f"factor beta/(1-beta) {BETA / (1 - BETA):.6f}")
    print(f"reference_iterations {ref_n} reference_certified {certified(ref_prev, v_ref):.3e}")
    print("reference_values " + " ".join(f"k{k}:{v:.10f}" for k, v in zip(GRID, v_ref, strict=True)))
    policy: list[float] = []
    for k in GRID:
        options = [(math.sqrt(k**ALPHA - GRID[j]) + BETA * v_ref[j], GRID[j]) for j in feasible(k)]
        policy.append(max(options, key=lambda pair: (pair[0], -pair[1]))[1])
    print("reference_policy_saved " + " ".join(f"k{k}:{kp}" for k, kp in zip(GRID, policy, strict=True)))
    for tol in TOLERANCES:
        n, v, prev = iterate_until(certified_stop(tol))
        cert = certified(prev, v)
        err = sup_distance(v, v_ref)
        steps = [c - p for c, p in zip(v, prev, strict=True)]
        spread = max(steps) - min(steps)
        print(
            f"certified_stop tol {tol:g} n {n} cert {cert:.10f} actual_error {err:.10f} "
            f"bound_holds {err <= cert + SLACK} cert_within_tol {cert <= tol} step_spread {spread:.3e}"
        )
    v10, prev10 = iterate_count(FIXED_COUNT)
    cert10 = certified(prev10, v10)
    err10 = sup_distance(v10, v_ref)
    print(
        f"fixed_count_stop n {FIXED_COUNT} cert {cert10:.10f} actual_error {err10:.10f} "
        f"bound_holds {err10 <= cert10 + SLACK}"
    )
    n, v, prev = iterate_until(lambda p, c: sup_distance(p, c) <= NAIVE_TOL)
    step = sup_distance(prev, v)
    err = sup_distance(v, v_ref)
    print(
        f"naive_step_stop tol {NAIVE_TOL:g} n {n} step {step:.10f} actual_error {err:.10f} "
        f"error_exceeds_step {err > step} naive_factor_times_step {BETA / (1 - BETA) * step:.10f}"
    )


main()

3Where the canon breaks

  • The space must be complete. Let \(X = (0, 1]\) with the usual distance, and let \(\Psi(x) = x/2\). Then \(\Psi\) maps \(X\) into \((0, 1/2] \subseteq X\), and it is a contraction with modulus \(1/2\). Its iterates \(x_n = 2^{-n}x_0\) are Cauchy, but they converge to \(0 \notin X\). So \(\Psi\) has no fixed point in \(X\), and the conclusion of Theorem 1.3 fails. Completeness of the space is the hypothesis that fails here.
  • The factor needs \(\beta < 1\). On \(\R\), let \(\Psi(x) = x + 1\). The space is complete, but \(\Psi\) has no fixed point, and \(\lvert \Psi(x) - x \rvert = 1\) for every \(x\), so the step never shrinks. The factor \(\beta/(1 - \beta)\) is undefined at \(\beta = 1\), and Lemma 2.3(b) would read \(0 \cdot \lVert V_n - V^{\ast} \rVert \le \lVert V_{n+1} - V_n \rVert\), which says nothing.
  • The factor is sharp for one family. On \(\R\), let \(\Psi(x) = \beta x + 1\) with \(0 < \beta < 1\), and let \(V_0 = 0\). The fixed point is \(\xi^{\ast} = 1/(1 - \beta)\), and \(V_1 - V_0 = 1\). Then \(\lvert V_1 - \xi^{\ast} \rvert = \beta/(1 - \beta)\), which equals \(\beta/(1 - \beta)\) times \(\lvert V_1 - V_0 \rvert\). So for this family of maps at \(n = 1\), no constant smaller than \(\beta/(1 - \beta)\) can serve in Lemma 2.3(c), for the \(\beta\) of that map and the starting point \(V_0 = 0\). Problem R3 checks this.

4Misconceptions

  1. “A small step between two iterates bounds the error.”

    Lemma 2.3(c) bounds the error by \(\beta/(1 - \beta)\) times the step, which is 9 times the step at \(\beta = 0.9\). Lab 1's naive rule stops when the step is at most \(10^{-6}\), at 126 steps. Its last step is 0.0000009534, and the actual error is 0.0000085808, which is more than eight times the tolerance. The printed values give the quotient \(0.0000085808/0.0000009534 = 9.0002\), which is 9 to the precision of the printed step, so in this run the step alone understates the error by a factor of about nine.

  2. “The certified bound applies to the savings problem in continuous time.”

    Theorem 2.4 bounds \(\lVert V_N - V^{\ast} \rVert_\infty\), where \(V^{\ast}\) is the fixed point of the operator on the four-point grid \(G\) (Remark 2.5). The lab measures the error against that grid fixed point only. It does not measure the discretization error, and no printed number in Lab 1 refers to a finer grid.

  3. “Running a fixed number of iterations gives a certified answer.”

    A certificate guarantees that the error is at most \(\operatorname{cert}_N\). To certify a tolerance \(\tau\), the certificate must be compared with \(\tau\), as in Theorem 2.4. Lab 1's fixed count of 10 steps leaves an actual error of 1.7433922005, which is far above the tolerance of \(10^{-6}\). The printed certificate for that count is the same number, and it is valid (bound_holds True), but it is large. A fixed count has no tolerance attached, so it cannot certify \(10^{-6}\).

5Problem set

Every problem has a full worked solution. Attempt each one before opening it.

Mechanics

M1 · The factor at three discount factors

Compute \(\beta/(1 - \beta)\) for \(\beta = 0.5\), \(\beta = 0.9\) and \(\beta = 0.99\).

Solution

For \(\beta = 0.5\), \(\beta/(1 - \beta) = 0.5/0.5 = 1\). For \(\beta = 0.9\), \(0.9/0.1 = 9\). For \(\beta = 0.99\), \(0.99/0.01 = 99\). The factor grows without bound as \(\beta\) approaches one, which is why Section 3 excludes \(\beta = 1\).

M2 · A certificate from one step

With \(\beta = 0.8\), the last step is \(\lVert V_2 - V_1 \rVert_\infty = 0.016\). What is the certified error after two steps?

Solution

The certified error is \(\operatorname{cert}_2 = \dfrac{\beta}{1 - \beta}\lVert V_2 - V_1 \rVert_\infty\). Here \(\beta/(1 - \beta) = 0.8/0.2 = 4\), so \(\operatorname{cert}_2 = 4 \times 0.016 = 0.064\). By Lemma 2.3(c), the actual error \(\lVert V_2 - V^{\ast} \rVert_\infty\) is at most 0.064.

M3 · The step needed for a tolerance

With \(\beta = 0.9\), what is the largest last step \(\lVert V_n - V_{n-1} \rVert_\infty\) that certifies an error of at most \(10^{-3}\)?

Solution

We need \(\dfrac{\beta}{1 - \beta}\lVert V_n - V_{n-1} \rVert_\infty \le 10^{-3}\). With \(\beta/(1 - \beta) = 9\), the condition is \(\lVert V_n - V_{n-1} \rVert_\infty \le 10^{-3}/9 = 1/9000\). So the largest step is \(10^{-3}(1 - \beta)/\beta = 1/9000\), which is about \(1.11 \times 10^{-4}\).

Proof

P1 · The step shrinks by the factor beta

Using only Lemma 1.2, prove that \(\lVert V_{n+1} - V_n \rVert_\infty \le \beta \lVert V_n - V_{n-1} \rVert_\infty\) for \(n \ge 1\).

Solution

Apply Lemma 1.2 to \(V = V_n\) and \(W = V_{n-1}\). Since \(V_{n+1} = \mathcal{B}V_n\) and \(V_n = \mathcal{B}V_{n-1}\), the left side is \(\lVert \mathcal{B}V_n - \mathcal{B}V_{n-1} \rVert_\infty\). Lemma 1.2 bounds it by \(\beta \lVert V_n - V_{n-1} \rVert_\infty\). The proof is one application of Lemma 1.2, whose hypothesis \(0 < \beta < 1\) is assumed here.

P2 · The error is at most the distance to the next iterate

Prove \((1 - \beta)\lVert V_n - V^{\ast} \rVert_\infty \le \lVert V_{n+1} - V_n \rVert_\infty\) for \(n \ge 0\), using the triangle inequality and Lemma 1.2.

Solution

The triangle inequality gives \(\lVert V_n - V^{\ast} \rVert \le \lVert V_n - V_{n+1} \rVert + \lVert V_{n+1} - V^{\ast} \rVert\). Since \(V_{n+1} - V^{\ast} = \mathcal{B}V_n - \mathcal{B}V^{\ast}\), Lemma 1.2 gives \(\lVert V_{n+1} - V^{\ast} \rVert \le \beta \lVert V_n - V^{\ast} \rVert\). Substituting, \((1 - \beta)\lVert V_n - V^{\ast} \rVert \le \lVert V_n - V_{n+1} \rVert\), and the norm is symmetric in its two arguments.

P3 · The geometric decay of the certified error

Prove by induction that \(\operatorname{cert}_n \le \dfrac{\beta^{n}}{1 - \beta}\lVert V_1 - V_0 \rVert_\infty\) for \(n \ge 1\), and state why this shows that the stopping rule of Theorem 2.4 ends.

Solution

For \(n = 1\), \(\operatorname{cert}_1 = \dfrac{\beta}{1 - \beta}\lVert V_1 - V_0 \rVert_\infty\), which is the claim. Suppose \(\lVert V_n - V_{n-1} \rVert_\infty \le \beta^{\,n-1}\lVert V_1 - V_0 \rVert_\infty\). By P1, \(\lVert V_{n+1} - V_n \rVert_\infty \le \beta \lVert V_n - V_{n-1} \rVert_\infty \le \beta^{\,n}\lVert V_1 - V_0 \rVert_\infty\), so the bound holds for the next step. Multiplying the step bound by \(\beta/(1 - \beta)\) gives the claim for \(n\). Since \(\beta^{n} \to 0\), the right side falls below any \(\tau > 0\), so the first \(N\) with \(\operatorname{cert}_N \le \tau\) exists.

Research

R1 · No contraction with beta equal to one

Let \(\Psi(x) = x + 1\) on \(\R\). Show that \(\Psi\) has no fixed point and that \(\lvert \Psi(x) - x \rvert = 1\) for every \(x\). Explain which step of Lemma 2.3 fails.

Solution

A fixed point would satisfy \(x = x + 1\), which is impossible, so there is no fixed point. For every \(x\), \(\Psi(x) - x = 1\), so the step is 1 at every point and does not shrink. Lemma 2.3 requires \(0 < \beta < 1\) in hypothesis (1) and a fixed point \(V^{\ast}\) in hypothesis (3). Here \(\beta = 1\), which hypothesis (1) excludes, and no fixed point exists, which hypothesis (3) excludes. In (b) the factor \(1 - \beta\) is zero, so the inequality reads \(0 \le \lVert V_{n+1} - V_n \rVert\) and says nothing.

R2 · An a priori count against the certified stop

Prove that \(\lVert V_n - V^{\ast} \rVert_\infty \le \dfrac{\beta^{n}}{1 - \beta}\lVert V_1 - V_0 \rVert_\infty\), using the telescoping sum \(V^{\ast} - V_n = \sum_{j \ge n} (V_{j+1} - V_j)\) and P1. For the grid of Lab 1, \(\lVert V_1 - V_0 \rVert_\infty = \sqrt{3}/2\). Find the smallest \(n\) for which this a priori bound is at most \(10^{-6}\), and compare it with the 147 steps of the certified stop.

Solution

Since \(V_n \to V^{\ast}\) (Theorem 1.3), \(V^{\ast} - V_n = \sum_{j \ge n}(V_{j+1} - V_j)\) as a limit of partial sums. By P1 repeated, \(\lVert V_{j+1} - V_j \rVert_\infty \le \beta^{j}\lVert V_1 - V_0 \rVert_\infty\). The triangle inequality then gives \(\lVert V_n - V^{\ast} \rVert_\infty \le \sum_{j \ge n}\beta^{j}\lVert V_1 - V_0 \rVert_\infty = \dfrac{\beta^{n}}{1-\beta}\lVert V_1 - V_0 \rVert_\infty\). For Lab 1, \(V_1(k) = \max_{k' \in F(k)}\sqrt{k^{\alpha} - k'}\) with \(V_0 = 0\), and the largest value is at \(k = 1.0\), where \(F(1.0) = G\) gives \(\sqrt{1 - 0.25} = \sqrt{3}/2 = 0.8660254\). The bound is at most \(10^{-6}\) when \(0.9^{n} \le 1.1547 \times 10^{-7}\). At \(n = 151\) the bound is \(1.067 \times 10^{-6}\), and at \(n = 152\) it is \(9.60 \times 10^{-7}\). So the a priori count is 152, and the certified stop at 147 steps is earlier, because it uses the computed step rather than the worst case.

R3 · The constant cannot be lowered in general

Using the example of the canon-breaks section, check that the equality \(\lvert V_1 - \xi^{\ast} \rvert = \dfrac{\beta}{1 - \beta}\lvert V_1 - V_0 \rvert\) holds for every \(\beta \in (0, 1)\), and explain why, for each fixed \(\beta \in (0, 1)\), no constant smaller than \(\beta/(1 - \beta)\) bounds the \(n = 1\) error of this map.

Solution

Here \(\Psi(x) = \beta x + 1\) and \(V_0 = 0\), so \(V_1 = 1\). The fixed point satisfies \(\xi^{\ast} = \beta \xi^{\ast} + 1\), so \(\xi^{\ast} = 1/(1 - \beta)\). Then \(\lvert V_1 - \xi^{\ast} \rvert = \lvert 1 - 1/(1-\beta) \rvert = \beta/(1 - \beta)\), and \(\lvert V_1 - V_0 \rvert = 1\), so the equality holds for every \(\beta\). If a smaller constant \(c(\beta) < \beta/(1-\beta)\) worked at \(n = 1\) for this map, the inequality \(\lvert V_1 - \xi^{\ast} \rvert \le c(\beta)\lvert V_1 - V_0 \rvert\) would fail. So, for each \(\beta\), no smaller constant works for this map at \(n = 1\).
