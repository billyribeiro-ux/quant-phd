  • Bpublished, not settled

  • Dlore

The real numbers have a property that the rational numbers lack: a nonempty set of real numbers that is bounded above (terms defined in §1) has a least upper bound, called a supremum (defined in §1). Lesson 2 uses it to show that sequences whose terms settle close together converge. Bisection, defined in §3, produces brackets, intervals \([a_n, b_n]\) with rational endpoints, that close in on a point that no rational number equals (a rational supremum would have square 2 by Proposition 1.7, which M1, Lesson 2, Corollary 2.6 rules out). This lesson states the property as the completeness axiom, derives the Archimedean property and the nested-interval principle from it, and proves the bisection theorem that the lab runs.

1Upper bounds and the completeness axiom

Let \(A\) be a set of real numbers. The set \(A\) is bounded above when some real number \(u\) satisfies \(a \le u\) for every \(a \in A\). Such a \(u\) is an upper bound of \(A\). A maximum of \(A\) is an element of \(A\) that is also an upper bound of \(A\). A supremum of \(A\) is an upper bound \(s\) of \(A\) with \(s \le u\) for every upper bound \(u\) of \(A\), that is, a least upper bound. Two suprema of the same set are equal, because each is at most the other. The supremum of \(A\) is written \(\sup A\) when it exists.

Definition 1.1 (completeness of the real numbers)

The completeness of \(\R\) is the following statement, taken as the defining property of the real numbers: every nonempty subset of \(\R\) that is bounded above has a supremum in \(\R\).

This unit takes Definition 1.1 as given and does not construct \(\R\) from the rational numbers. The results below are proved from it, from earlier results of this lesson, and from the elementary rules of order and arithmetic, which are used as prose facts and are stated where they appear. A property is derived here when it is proved from Definition 1.1 on the page.

2The Archimedean property and nested intervals

Theorem 1.2 (Archimedean property)
  1. (H1) \(x\) is a real number.
  2. (H2) Every nonempty subset of \(\R\) that is bounded above has a supremum in \(\R\) (Definition 1.1).
  3. (H3) The set \(\N = \{1, 2, 3, \dots\}\) has the property that \(n \in \N\) implies \(n + 1 \in \N\).

Conclusion: there is \(n \in \N\) with \(n > x\).

Proof

Suppose, for contradiction, that \(n \le x\) for every \(n \in \N\). Then \(\N\) is nonempty and bounded above by \(x\), so by (H2) it has a supremum \(s\). Since \(s - 1 < s\), the number \(s - 1\) is not an upper bound of \(\N\), so some \(n \in \N\) satisfies \(n > s - 1\). By (H3), \(n + 1 \in \N\), and \(n + 1 > s\). This contradicts the fact that \(s\) is an upper bound of \(\N\). So some \(n \in \N\) satisfies \(n > x\). \(\blacksquare\)

Theorem 1.3 (nested intervals)
  1. (H1) For each \(n \in \N\), \(a_n \le b_n\) are real numbers, and the interval \(I_n = [a_n, b_n]\) is nonempty.
  2. (H2) The intervals are nested: \(I_{n+1} \subseteq I_n\) for every \(n \in \N\).
  3. (H3) Every nonempty subset of \(\R\) that is bounded above has a supremum in \(\R\) (Definition 1.1).

Conclusion: there is a real number \(s\) with \(s \in I_n\) for every \(n \in \N\).

Proof

Let \(A = \{a_n : n \in \N\}\), which is nonempty. We show that \(a_n \le b_m\) for all \(n, m \in \N\). If \(n \le m\), then \(I_m \subseteq I_n\) by (H2) and repeated use of it, so \(a_n \le a_m \le b_m\). If \(m < n\), then \(I_n \subseteq I_m\), so \(a_n \le b_n \le b_m\). Hence each \(b_m\) is an upper bound of \(A\), and \(A\) is bounded above. By (H3), \(s = \sup A\) exists. For each \(n\), \(a_n \le s\) because \(a_n \in A\). For each \(m\), \(s \le b_m\) because \(b_m\) is an upper bound of \(A\) and \(s\) is the least one. So \(a_n \le s \le b_n\) for every \(n\), which is \(s \in I_n\). \(\blacksquare\)

Corollary 1.4 (a single point)
  1. (H1) to (H3) as in Theorem 1.3.
  2. (H4) The lengths \(b_n - a_n\) tend to 0 as \(n\) grows, in the sense that for every \(\eta > 0\) some \(N\) gives \(b_n - a_n < \eta\) for all \(n \ge N\).

Conclusion: the intersection \(\bigcap_{n} I_n\) contains exactly one real number.

Proof

Theorem 1.3 gives a point \(s\) in every \(I_n\), so the intersection is nonempty. Let \(t\) also lie in every \(I_n\). For each \(n\), both \(s\) and \(t\) lie in \(I_n\), so \(|s - t| \le b_n - a_n\). Given \(\eta > 0\), choose \(N\) as in (H4). Then \(|s - t| < \eta\), and since \(\eta\) was arbitrary, \(s = t\). \(\blacksquare\)

3Bisection and the supremum

Let \(S = \{x \in \R : x \ge 0 \text{ and } x^2 < 2\}\). This is the set whose supremum the lab brackets. The letter \(S\) is local to this lesson. The set is nonempty, since \(0 \in S\). Lemma 1.5 gives a test that decides, for each midpoint, which of two cases holds.

Lemma 1.5 (a two-case test for \(S\))
  1. (H1) \(m\) is a real number with \(m \ge 0\).

Conclusion: either \(m \in S\), when \(m^2 < 2\), or \(m\) is an upper bound of \(S\), when \(m^2 \ge 2\). In particular, 2 is an upper bound of \(S\).

Proof

If \(m^2 < 2\), then \(m \ge 0\) and \(m^2 < 2\) give \(m \in S\) by the definition of \(S\). If \(m^2 \ge 2\), take any \(x \in S\). Then \(x \ge 0\) and \(x^2 < 2 \le m^2\). If \(x \ge m\), then \(x^2 \ge m^2\), since both are nonnegative; so \(x < m\). Hence \(m\) is an upper bound of \(S\). The number 2 satisfies \(2^2 = 4 \ge 2\), so 2 is an upper bound of \(S\). \(\blacksquare\)

Theorem 1.6 (bisection brackets the supremum)
  1. (H1) \(S_0\) is a nonempty subset of \(\R\) that is bounded above.
  2. (H2) \(a_0 \in S_0\), and \(b_0\) is an upper bound of \(S_0\), with \(a_0 \le b_0\).
  3. (H3) For every real \(m\) with \(a_0 \le m \le b_0\), either \(m \in S_0\) or \(m\) is an upper bound of \(S_0\).

Conclusion: define \(m_n = (a_n + b_n)/2\), set \((a_{n+1}, b_{n+1}) = (m_n, b_n)\) if \(m_n \in S_0\), and \((a_{n+1}, b_{n+1}) = (a_n, m_n)\) otherwise. Then for every \(n\), \(a_n \le \sup S_0 \le b_n\), and \(b_n - a_n = (b_0 - a_0)/2^n\).

Proof

Write \(s = \sup S_0\), which exists by (H1) and Definition 1.1. We prove by induction on \(n\) that \(a_n \in S_0\), that \(b_n\) is an upper bound of \(S_0\), that \(a_0 \le a_n \le b_n \le b_0\), and that \(b_n - a_n = (b_0 - a_0)/2^n\). For \(n = 0\) this is (H2), and \(b_0 - a_0 = (b_0 - a_0)/2^0\). Suppose it holds for \(n\). Then \(a_0 \le a_n \le m_n \le b_n \le b_0\), so (H3) applies to \(m_n\). If \(m_n \in S_0\), the new left endpoint \(a_{n+1} = m_n\) lies in \(S_0\), the right endpoint \(b_n\) is still an upper bound, and \(b_{n+1} - a_{n+1} = (b_n - a_n)/2\). Otherwise \(m_n\) is an upper bound, so \(b_{n+1} = m_n\) is an upper bound, \(a_{n+1} = a_n \in S_0\), and again \(b_{n+1} - a_{n+1} = (b_n - a_n)/2\). This completes the induction, and the width formula follows. Now \(a_n \in S_0\) gives \(a_n \le s\), and \(b_n\) is an upper bound of \(S_0\), so \(s \le b_n\). \(\blacksquare\)

Applied to \(S\), the test of Lemma 1.5 supplies (H3) on \([0, 2]\). The start \(a_0 = 0\) lies in \(S\), and \(b_0 = 2\) is an upper bound of \(S\) by Lemma 1.5, so Theorem 1.6 gives the brackets that Lab 1 prints. The lab uses exact rational arithmetic, so each printed inequality is exact.

Lab 1 · Bisection brackets the supremum of \(S\) with exact widths

The first step whose width is below \(1/1000\) is step 11, because \(2/2^{11} = 1/1024\) and \(2/2^{10} = 1/512\) is not below \(1/1000\).

"""M5 lab L01: bisection brackets the supremum of S = {x >= 0 : x * x < 2}, with exact brackets.

Standard library only. No randomness and no network. Every bracket is a rational number held as a
fractions.Fraction, so each printed inequality and each printed width is exact. The lab uses two
tests on the midpoint m >= 0: m is in S when m * m < 2, and m is an upper bound of S when m * m >= 2
(Lemma 1.5 of the page proves that these two cases cover every m >= 0). The lab brackets the
supremum by exact rational numbers. It does not compute the supremum as a decimal, and a finite
run of bisection is evidence about where the supremum lies, not a proof of its value.
"""

from __future__ import annotations

from fractions import Fraction

STEPS = 12


def in_set(x: Fraction) -> bool:
    """Membership in S = {x >= 0 : x * x < 2}."""
    return x >= 0 and x * x < 2


def bisect(steps: int) -> list[tuple[Fraction, Fraction]]:
    """Brackets [a, b] after 0, 1, ..., steps bisection steps, starting from a = 0 and b = 2.

    Invariant kept at every step: a is in S and b is an upper bound of S, so a <= sup S <= b.
    At the midpoint m = (a + b) / 2 (which is at least 0), either m is in S and a becomes m, or
    m * m >= 2 and m is an upper bound of S, so b becomes m. Each step halves the width.
    """
    a, b = Fraction(0), Fraction(2)
    brackets = [(a, b)]
    for _ in range(steps):
        m = (a + b) / 2
        if in_set(m):
            a = m
        else:
            b = m
        brackets.append((a, b))
    return brackets


def first_step_below(brackets: list[tuple[Fraction, Fraction]], tol: Fraction) -> int:
    """The least step index n with width b - a < tol, or -1 if no bracket in the list is that narrow."""
    for n, (a, b) in enumerate(brackets):
        if b - a < tol:
            return n
    return -1


def main() -> None:
    brackets = bisect(STEPS)
    for n, (a, b) in enumerate(brackets):
        print(f"step {n:2d}: a = {a}, b = {b}, width = {b - a}")
    sandwich = sum(a * a < 2 <= b * b for a, b in brackets)
    print(f"brackets with a*a < 2 <= b*b: {sandwich} of {len(brackets)}")
    halving = sum((b - a) == Fraction(2, 2**n) for n, (a, b) in enumerate(brackets))
    print(f"width equals 2 / 2^n after n steps: {halving} of {len(brackets)} brackets")
    nested = all(
        brackets[n + 1][0] >= brackets[n][0] and brackets[n + 1][1] <= brackets[n][1] for n in range(len(brackets) - 1)
    )
    print(f"each bracket lies inside the one before it: {nested}")
    step = first_step_below(brackets, Fraction(1, 1000))
    print(f"first step with width below 1/1000: {step}")

Each printed line is an exact rational bracket, and the checks compare fractions, so no tolerance is involved. The width column shows the halving of Theorem 1.6. The lab shows the bracket on every step, not the supremum itself: the supremum is the number the brackets close in on, and the page identifies it in Proposition 1.7. A finite run of bisection locates the supremum to within the printed width, and it does not prove any value for it. The lab's checks cover a finite run of 12 steps.

Proposition 1.7 (the supremum squared is 2)
  1. (H1) \(S\) is as defined above, and \(s = \sup S\), which exists by Definition 1.1, since \(0 \in S\) and 2 is an upper bound of \(S\) (Lemma 1.5).

Conclusion: \(s^2 = 2\).

Proof

Since \(0 \in S\), we have \(s \ge 0\). We rule out \(s^2 < 2\) and \(s^2 > 2\), which leaves \(s^2 = 2\).

Case \(s^2 < 2\). Put \(\varepsilon = \min\{1, (2 - s^2)/(2s + 2)\}\), which is positive. Since \(\varepsilon \le 1\), we have \(\varepsilon^2 \le \varepsilon\), so \((s + \varepsilon)^2 = s^2 + 2s\varepsilon + \varepsilon^2 \le s^2 + \varepsilon(2s + 1)\). Also \(\varepsilon(2s + 1) < \varepsilon(2s + 2) \le 2 - s^2\). Hence \((s + \varepsilon)^2 < 2\), so \(s + \varepsilon \in S\). But \(s + \varepsilon > s\), which contradicts the fact that \(s\) is an upper bound of \(S\).

Case \(s^2 > 2\). Then \(s > 0\). Put \(\delta = (s^2 - 2)/(4s)\), which is positive, and \(t = s - \delta\). Since \(s^2 - 2 < 4s^2\), we have \(\delta < s\), so \(t > 0\). Also \(t^2 = s^2 - 2s\delta + \delta^2 \ge s^2 - 2s\delta = s^2 - (s^2 - 2)/2 = (s^2 + 2)/2 > 2\). Let \(x \in S\). Then \(0 \le x\) and \(x^2 < 2 < t^2\), so \(x < t\), since \(x \ge t\) would give \(x^2 \ge t^2\). Thus \(t\) is an upper bound of \(S\) with \(t < s\), which contradicts the fact that \(s\) is the least upper bound. \(\blacksquare\)

The proof of Proposition 1.7 shows that \(\sup S\) is the number whose square is 2. The lab's brackets sandwich it: the lower endpoints satisfy \(a^2 < 2\), and the upper endpoints satisfy \(b^2 \ge 2\), Theorem 1.6 places \(\sup S\) between them, since \(a \le \sup S \le b\), and Proposition 1.7 gives \((\sup S)^2 = 2\).

4Where the canon breaks

The property of Definition 1.1 is strong. The three failures below show what it does not give on its own: a supremum among the rationals, membership of the supremum in the set, and the need for the bounded-above hypothesis.

  • The rational numbers are not complete. Let \(S_{\text{rat}}\) be the set of rational numbers \(x \ge 0\) with \(x^2 < 2\). The set is nonempty and bounded above in the rational numbers. It has no least upper bound among the rational numbers. Run the proof of Proposition 1.7 with the rational numbers in place of \(\R\). If \(q\) is a rational least upper bound of \(S_{\text{rat}}\), then the number \(\varepsilon\) in the first case and the numbers \(\delta\) and \(t\) in the second are rational, because each is built from \(q\) by rational operations. Each of the two cases leads to a contradiction, so \(q^2 = 2\). No rational number has square 2 (M1, Lesson 2, Corollary 2.6, which this lesson cites and does not reprove), so no rational least upper bound exists.
  • A supremum need not belong to the set. The supremum of \(S\) is \(s\) with \(s^2 = 2\) (Proposition 1.7), so \(s \notin S\), because \(s^2 < 2\) fails. The set has no maximum. A set with a supremum can have no maximum, and an element of the set can fail to be the supremum.
  • The boundedness hypothesis is not idle. The set \(\N\) is nonempty and has no upper bound, by Theorem 1.2. Without the bounded-above hypothesis, Definition 1.1 says nothing about \(\N\), and the completeness axiom does not apply to it.

5Misconceptions

  1. “A bounded set has a largest element.”

    A bounded set need not have a maximum. The set \(S\) is bounded above by 2 (Lemma 1.5), and it has supremum \(s\) with \(s^2 = 2\) (Proposition 1.7). Since \(s^2 = 2\), the number \(s\) does not satisfy \(s^2 < 2\), so \(s \notin S\), and \(S\) has no largest element. The supremum is the least upper bound, which need not be in the set.

  2. “Every bounded-above set of rational numbers has a supremum among the rational numbers.”

    This fails for \(S_{\text{rat}}\), the rational numbers \(x \ge 0\) with \(x^2 < 2\), as the first canon break shows. The completeness axiom is a property of \(\R\), not of the rational numbers. Theorem 1.6 applies to \(S\) because \(S\) is a nonempty subset of \(\R\) bounded above, and Definition 1.1 supplies its supremum.

  3. “Bisection with enough steps lands exactly on the supremum.”

    Each bracket of Lab 1 has rational endpoints, because every midpoint of two rational numbers is rational, and its width is \(2^{1 - n}\), which is positive for each \(n\). If the supremum equalled some endpoint \(a_n\) or \(b_n\), it would be a rational number whose square is 2 (by Proposition 1.7), which is impossible (M1, Lesson 2, Corollary 2.6). So no finite number of steps reaches the supremum, and the lab shows brackets, not the supremum.

Mechanics

M1 · The supremum of the open interval

Let \(A = \{x \in \R : 0 < x < 1\}\). Show that \(\sup A = 1\).

Solution

The number 1 is an upper bound of \(A\), since every \(x \in A\) has \(x < 1\). Let \(y\) be any real number with \(y < 1\). Put \(x = (1 + \max\{y, 0\})/2\). Then \(x < 1\), and \(x > \max\{y, 0\} \ge 0\), so \(x \in A\). Also \(x > y\), so \(y\) is not an upper bound of \(A\). Therefore 1 is the least upper bound, and \(\sup A = 1\).

M2 · A maximum is the supremum

Show that if a set \(A\) has a maximum \(m\), then \(m = \sup A\). Then find \(\sup\{1 - 1/n : n \in \N\}\) and decide whether the set has a maximum.

Solution

The maximum \(m\) is an element of \(A\) and an upper bound of \(A\). Any upper bound \(u\) of \(A\) satisfies \(u \ge m\), because \(m \in A\). So \(m\) is the least upper bound, and \(m = \sup A\). For the second set, each element \(1 - 1/n\) is less than 1, so 1 is an upper bound. For \(y < 1\), the Archimedean property (Theorem 1.2) gives \(n\) with \(n > 1/(1 - y)\), so \(1/n < 1 - y\) and \(1 - 1/n > y\). So 1 is the least upper bound, and \(\sup = 1\). The set has no maximum, because \(1 - 1/n < 1\) for every \(n\), so no element equals the supremum.

M3 · The first two bisection steps by hand

For the set \(S\) of this lesson, start from \(a_0 = 0\) and \(b_0 = 2\). Carry out two steps of Theorem 1.6 by hand, and state the bracket after each step.

Solution

Step 1: \(m_0 = (0 + 2)/2 = 1\). Since \(1^2 = 1 < 2\), \(1 \in S\), so \(a_1 = 1\) and \(b_1 = 2\). The bracket is \([1, 2]\), of width 1. Step 2: \(m_1 = (1 + 2)/2 = 3/2\). Since \((3/2)^2 = 9/4 \ge 2\), the number \(3/2\) is an upper bound of \(S\) by Lemma 1.5, so \(b_2 = 3/2\) and \(a_2 = 1\). The bracket is \([1, 3/2]\), of width \(1/2\). These match the lab's steps 1 and 2.

P1 · The intersection of nested intervals with lengths tending to zero

Let \(I_n = [a_n, b_n]\) be nested intervals with \(b_n - a_n \to 0\). Prove that the intersection contains exactly one point, using Theorem 1.3 and listing the hypotheses you use.

Solution

Hypotheses used: the intervals are nested (H2 of Theorem 1.3), each is nonempty (H1), the supremum axiom holds (H3), and the lengths tend to zero. Theorem 1.3 gives a point in every \(I_n\), so the intersection is nonempty. If \(s\) and \(t\) both lie in every \(I_n\), then \(|s - t| \le b_n - a_n\) for every \(n\). Since the lengths tend to zero, \(|s - t|\) is less than every positive number, so \(s = t\). This is Corollary 1.4.

P2 · Approximation by elements of the set

Let \(A\) be a nonempty set bounded above with supremum \(s\), and let \(\eta > 0\). Prove that some \(a \in A\) satisfies \(a > s - \eta\).

Solution

Since \(\eta > 0\), the number \(s - \eta\) is less than \(s\). Because \(s\) is the least upper bound of \(A\), the number \(s - \eta\) is not an upper bound of \(A\). So some \(a \in A\) satisfies \(a > s - \eta\). This uses only that \(s\) is the least of the upper bounds.

P3 · When the bisection hypothesis holds for a set with a maximum

Let \(A\) be a nonempty set with a maximum \(m\), and let \(a_0\) be an element of \(A\) with \(a_0 \le m\). Prove that hypothesis (H3) of Theorem 1.6 holds for \(S_0 = A\) on \([a_0, m]\) if and only if every real \(x\) with \(a_0 \le x < m\) belongs to \(A\).

Solution

Suppose (H3) holds and let \(a_0 \le x < m\) with \(x \notin A\). By (H3), \(x\) is an upper bound of \(A\). But \(m \in A\) and \(x < m\), so \(x\) is not an upper bound, a contradiction. So every such \(x\) lies in \(A\). Conversely, suppose every \(x\) with \(a_0 \le x < m\) lies in \(A\), and let \(a_0 \le x \le m\). If \(x = m\), then \(x \in A\). If \(x < m\), then \(x \in A\) by the supposition. So (H3) holds in both cases. The condition on \([a_0, m)\) is therefore exactly what (H3) needs.

Empirical

E1 · Checking the step-12 bracket by hand

Lab 1 prints the bracket \([181/128, 2897/2048]\) after 12 steps. Check by integer arithmetic that the left endpoint squared is below 2 and the right endpoint squared is at least 2, and confirm the width.

Solution

For the left endpoint, \(181^2 = 32761\) and \(2 \cdot 128^2 = 32768\). Since \(32761 < 32768\), we have \((181/128)^2 < 2\). For the right endpoint, \(2897^2 = 8392609\) and \(2 \cdot 2048^2 = 8388608\). Since \(8392609 \ge 8388608\), we have \((2897/2048)^2 \ge 2\). The width is \(2897/2048 - 181/128 = (2897 - 16 \cdot 181)/2048 = (2897 - 2896)/2048 = 1/2048\), which is \(2/2^{12}\), as Theorem 1.6 predicts. The lab prints the same values.

E2 · The first step with width below 1/1000

Lab 1 prints 11 as the first step whose width is below \(1/1000\). Explain the number from the width formula and confirm it against the output.

Solution

The width after \(n\) steps is \(2/2^n = 2^{1-n}\). The condition \(2^{1-n} < 1/1000\) is equivalent to \(2^{n-1} > 1000\). Since \(2^9 = 512\) and \(2^{10} = 1024\), the least \(n\) with \(2^{n-1} > 1000\) is \(n - 1 = 10\), so \(n = 11\). The lab's output agrees, and the width at step 11 is \(1/1024\), which is below \(1/1000\).

E3 · The nesting check

Lab 1 prints True for "each bracket lies inside the one before it". Verify the nesting at steps 4 and 5 by hand, using the printed endpoints.

Solution

At step 4 the bracket is \([11/8, 3/2]\). At step 5 it is \([11/8, 23/16]\). The left endpoint is the same, \(11/8\), and the right endpoint decreases from \(3/2 = 24/16\) to \(23/16\), so \([11/8, 23/16] \subseteq [11/8, 3/2]\). The nesting holds at this pair of steps, and the lab checks it at every consecutive pair of brackets.

Research

R1 · The same method for a cubic set

Let \(S_3 = \{x \in \R : x \ge 0 \text{ and } x^3 < 2\}\). State a two-case test for \(S_3\) analogous to Lemma 1.5, and show that bisection from \([0, 2]\) satisfies the hypotheses of Theorem 1.6.

Solution

For \(m \ge 0\): if \(m^3 < 2\), then \(m \in S_3\). If \(m^3 \ge 2\), take \(x \in S_3\), so \(0 \le x\) and \(x^3 < 2 \le m^3\). Since the cube is increasing on the nonnegative numbers, \(x < m\), so \(m\) is an upper bound. For (H2), \(0 \in S_3\) and \(2^3 = 8 \ge 2\), so 2 is an upper bound, because any \(x \in S_3\) has \(x^3 < 2 < 8\), so \(x < 2\). Thus Theorem 1.6 applies, and the brackets shrink to width 0 around \(\sup S_3\).

R2 · No bracket endpoint is the supremum

Show that the supremum \(s\) of \(S\) is not an endpoint of any bracket of Lab 1.

Solution

Each endpoint is a rational number, since bisection of rational numbers produces rational midpoints. If \(s\) equalled an endpoint, \(s\) would be a rational number with \(s^2 = 2\) by Proposition 1.7. That is impossible, by the irrationality of the square root of 2 proved in M1, Lesson 2, Corollary 2.6. So \(s\) is not an endpoint, and it is not equal to any bracket endpoint.

R3 · Infima exist

Let \(B\) be a nonempty set of real numbers that is bounded below. Prove that \(B\) has a greatest lower bound in \(\R\), using Definition 1.1.

Solution

Let \(C = \{-b : b \in B\}\). This set is nonempty. If \(m\) is a lower bound of \(B\), then \(-m\) is an upper bound of \(C\), so \(C\) is bounded above. By Definition 1.1, \(t = \sup C\) exists. For each \(b \in B\), \(-b \le t\), so \(-t \le b\), and \(-t\) is a lower bound of \(B\). If \(u\) is any lower bound of \(B\), then \(-u\) is an upper bound of \(C\), so \(t \le -u\), which gives \(u \le -t\). So \(-t\) is the greatest lower bound of \(B\).

  1. Which statement is the completeness of \(\R\) in this lesson?

  2. Does \(S = \{x \ge 0 : x^2 < 2\}\) have a largest element?

    Options

  3. In Lab 1, what is the width of the bracket after 3 steps?

    The width after \(n\) steps is \(2/2^n\). For \(n = 3\) it is \(2/8 = 1/4\), which is step 3 of the printed output.

  4. What is the first bisection step whose width is below \(1/1000\)?

    The width after \(n\) steps is \(2^{1-n}\). The first \(n\) with \(2^{1-n} < 1/1000\) is 11 (Problem E2).

  5. Which number is an upper bound of \(S = \{x \ge 0 : x^2 < 2\}\)?

    Options

    \((3/2)^2 = 9/4 \ge 2\), so \(3/2\) is an upper bound by Lemma 1.5. The number \(7/5\) lies in \(S\), since \((7/5)^2 = 49/25 < 2\), and \(7/5 > 1\), so 1 is not an upper bound. Also \(141/100\) lies in \(S\), since \((141/100)^2 = 19881/10000 < 2\), and \(141/100 > 7/5\), so \(7/5\) is not an upper bound.

  6. What is the least natural number \(n\) with \(n > 1000.5\)?

    Theorem 1.2 guarantees such an \(n\) exists. Here \(n = 1001\) is the least natural number above \(1000.5\).

  7. Does the set of rational numbers \(x \ge 0\) with \(x^2 < 2\) have a least upper bound among the rational numbers?

    Options

    The first canon break shows that a rational least upper bound \(q\) would satisfy \(q^2 = 2\), which no rational number does.

  8. If \(s = \sup S\) for \(S = \{x \ge 0 : x^2 < 2\}\), what is \(s^2\)?

    Proposition 1.7 proves \(s^2 = 2\).

  9. Why is the set \(\N\) not bounded above?

    Options

    Infinite sets can be bounded: the set \(\{1 - 1/n\}\) is bounded above by 1. The unboundedness of \(\N\) is the Archimedean property.

  10. After bisection of Theorem 1.6, what is the relation between a bracket's width and the supremum?
