Vector Spaces, Spans, Bases and Dimension

  • Uses: quantifiers (M1 Lesson 1) and direct proof (M1 Lesson 2), as used in the proofs below; secondary-school algebra as prose
  • Introduces: vector space
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study or lab result
  • Dlore

Over one period, the return of a portfolio is a weighted sum of the returns of its assets, with weights equal to each asset's share of the starting value, so a weight vector and a vector of returns are combined linearly. The structure that makes those combinations precise is defined in Section 1. This lesson defines a real vector space, proves the subspace test, and defines span, linear independence, basis and dimension. It proves that the dimension of a space with a finite basis does not depend on the basis. Lab 1 counts independent lists in exact rational arithmetic.

1Vector spaces and subspaces

Definition 1.1 (real vector space)

A vector space over \(\R\) is a set \(V\) with an addition \(u + v\) and a scalar multiplication \(a v\), where \(a \in \R\), such that for all \(u, v, w \in V\) and all \(a, b \in \R\):

(i) \(u + v = v + u\) and \((u + v) + w = u + (v + w)\);

(ii) there is a vector \(\mathbf{0}\) with \(v + \mathbf{0} = v\), and for each \(v\) there is a vector \(-v\) with \(v + (-v) = \mathbf{0}\);

(iii) \(a(bv) = (ab)v\) and \(1v = v\);

(iv) \(a(u + v) = au + av\) and \((a + b)v = av + bv\).

Example 1.2 (the spaces used in this unit)

The set \(\R^n\) of ordered lists of \(n\) real numbers, with entrywise addition and scalar multiplication, is a vector space; so is the set of \(m \times n\) real matrices with the same operations. Lesson 2 uses both. The axioms of Definition 1.1 are the ones each example must satisfy, and for \(\R^n\) each one is an identity of real numbers applied entrywise.

Lemma 1.3 (zero and negative)

Let \(V\) be a real vector space. Then \(0v = \mathbf{0}\) for every \(v \in V\), and \((-1)v = -v\).

Proof

By axiom (iv), \(0v = (0 + 0)v = 0v + 0v\). Add \(-(0v)\), which exists by axiom (ii), to both sides. The left side gives \(\mathbf{0}\) and the right side gives \(0v\), so \(0v = \mathbf{0}\). Next, \(v + (-1)v = 1v + (-1)v = (1 + (-1))v = 0v = \mathbf{0}\) by axioms (iii), (iv) and what was just shown. So \((-1)v\) is an additive inverse of \(v\). The additive inverse is unique: if \(v + x = \mathbf{0}\), then adding \(-v\) to both sides and using axioms (i) and (ii) gives \(x = -v\). Hence \((-1)v = -v\). \(\blacksquare\)

Proposition 1.4 (the subspace test)

Let \(V\) be a real vector space and \(W\) a subset of \(V\). Then \(W\) is a vector space under the operations of \(V\) if and only if (a) \(W\) is non-empty, (b) \(u, v \in W\) implies \(u + v \in W\), and (c) \(a \in \R\) and \(v \in W\) imply \(av \in W\). A subset with these properties is a subspace of \(V\).

Proof

If \(W\) is a vector space under the operations of \(V\), then it is non-empty, because it contains a zero vector, and conditions (b) and (c) hold because addition and scalar multiplication map \(W\) into \(W\). Conversely, assume (a), (b) and (c). Axioms (i), (iii) and (iv) hold in \(W\) because they hold in \(V\) for all vectors. Take \(w \in W\). By (c) with \(a = 0\), \(0w \in W\), and \(0w = \mathbf{0}\) by Lemma 1.3, so \(\mathbf{0} \in W\), which gives axiom (ii)'s zero vector. By (c) with \(a = -1\), \((-1)w = -w \in W\), which gives the additive inverse in \(W\). Every remaining requirement is an identity of \(V\). \(\blacksquare\)

2Span

Definition 2.1 (linear combination and span)

Let \(v_1, \dots, v_k\) be vectors in a real vector space \(V\). A linear combination of them is a vector \(c_1 v_1 + \dots + c_k v_k\) with real coefficients \(c_1, \dots, c_k\). The span of the list, written \(\operatorname{span}(v_1, \dots, v_k)\), is the set of all linear combinations of \(v_1, \dots, v_k\). By convention, the span of the empty list is \(\{\mathbf{0}\}\).

Proposition 2.2 (the span is the smallest subspace containing the list)

Let \(V\) be a real vector space and \(v_1, \dots, v_k \in V\). Then \(\operatorname{span}(v_1, \dots, v_k)\) is a subspace of \(V\) that contains each \(v_i\). If \(W\) is a subspace of \(V\) that contains each \(v_i\), then \(\operatorname{span}(v_1, \dots, v_k) \subseteq W\).

Proof

Let \(S\) be the span. For \(k = 0\), \(S = \{\mathbf{0}\}\), a subspace contained in every subspace. Let \(k \ge 1\). The vector \(\mathbf{0} = 0v_1 + \dots + 0v_k\) lies in \(S\), so (a) of Proposition 1.4 holds. If \(x = \sum_i c_i v_i\) and \(y = \sum_i d_i v_i\), then \(x + y = \sum_i (c_i + d_i) v_i\) by axioms (i) and (iv), so (b) holds. For \(a \in \R\), \(a x = \sum_i (a c_i) v_i\) by axioms (iii) and (iv), so (c) holds. Hence \(S\) is a subspace. Each \(v_j\) is in \(S\) with coefficients \(c_j = 1\) and \(c_i = 0\) for \(i \ne j\). Now let \(W\) be a subspace containing the \(v_i\). By (c), each \(c_i v_i \in W\), and by (b) repeated, the sum of these \(k\) vectors lies in \(W\). Every element of \(S\) has this form, so \(S \subseteq W\). \(\blacksquare\)

Example 2.3 (a coordinate plane)

In \(\R^3\), let \(e_1 = (1, 0, 0)\) and \(e_2 = (0, 1, 0)\). Then \(\operatorname{span}(e_1, e_2)\) is the set of vectors \((a, b, 0)\). Every such vector equals \(a e_1 + b e_2\), and every combination \(c_1 e_1 + c_2 e_2\) has third coordinate \(0\). So a vector \(x = (x_1, x_2, x_3)\) lies in the span exactly when \(x_3 = 0\). Lab 1 tests this on seeded vectors.

3Independence, bases and dimension

Definition 3.1 (linear independence)

A list \(v_1, \dots, v_k\) in \(V\) is linearly independent when \(c_1 v_1 + \dots + c_k v_k = \mathbf{0}\) forces \(c_1 = \dots = c_k = 0\). A list that is not linearly independent is dependent. The empty list is independent.

Definition 3.2 (basis)

A basis of \(V\) is a linearly independent list of vectors that spans \(V\). A space with a basis of finitely many vectors is finite-dimensional, and its dimension is the number of vectors in such a basis. Theorem 3.8 shows that this number does not depend on the basis.

Independence is a property of the whole list. A list can contain no vector that is a multiple of another and still be dependent. Misconception 3 below gives such a list.

Definition 3.3 (echelon form and rank)

Gaussian elimination reduces a real \(m \times k\) matrix \(A\) by elementary row operations (swapping two rows, multiplying a row by a non-zero number, and adding a multiple of one row to another) to an echelon form: the non-zero rows come first, and each row's first non-zero entry, its pivot, lies strictly to the right of the pivot of the row above it. Each row operation replaces the system \(Ac = \mathbf{0}\) by an equivalent one: the old equations are combinations of the new ones, and the operation can be undone by another row operation. So the echelon form has the same solutions \(c\). The rank of \(A\) is the number of pivots in its echelon form. Proposition 3.12 below shows that every echelon form of \(A\) has the same number of pivots, so the rank is well defined.

Lemma 3.4 (more columns than pivots gives a non-zero solution)

Let \(A\) be a real \(m \times k\) matrix. If the echelon form of \(A\) has fewer than \(k\) pivots, then \(Ac = \mathbf{0}\) has a solution \(c \ne 0\) in \(\R^k\). In particular, if \(k > m\), such a solution exists.

Proof

Let \(U\) be the echelon form, which has the same solutions as \(Ac = \mathbf{0}\). Since fewer than \(k\) columns carry a pivot, some column \(j\) has no pivot. The unknown \(c_j\) is free: set \(c_j = 1\) and set every other free unknown to \(0\). Now solve for the pivot unknowns from the last pivot row upward. A pivot row is an equation whose pivot unknown has a non-zero coefficient and whose other non-zero coefficients belong to unknowns to the right of the pivot. Those unknowns are already determined, so the pivot unknown is determined. Every pivot unknown is determined this way, and the result is a solution with \(c_j = 1\), so \(c \ne 0\). For the second statement, \(U\) has at most \(m\) pivots, one per row, and \(m < k\). \(\blacksquare\)

Proposition 3.5 (independence as a pivot count)

Let \(v_1, \dots, v_k\) be vectors in \(\R^n\), and let \(A\) be the \(n \times k\) matrix whose columns are these vectors. Then the list is linearly independent if and only if the echelon form of \(A\) has \(k\) pivots, that is, if and only if \(\operatorname{rank}(A) = k\).

Proof

A combination \(\sum_i c_i v_i\) equals \(A c\), so the list is independent exactly when \(Ac = \mathbf{0}\) has only the solution \(c = \mathbf{0}\). If the echelon form has fewer than \(k\) pivots, Lemma 3.4 gives a solution \(c \ne \mathbf{0}\), so the list is dependent. Suppose the echelon form has \(k\) pivots. Its pivot columns are distinct columns among \(1, \dots, k\), and the pivot of a lower row lies to the right of the pivot of the row above it. So the pivot of row \(i\) is in column \(j_i\) with \(j_1 < j_2 < \dots < j_k \le k\). Then \(j_k = k\), \(j_{k-1} = k - 1\), and so on down to \(j_1 = 1\), which means \(j_i = i\). Row \(i\) therefore reads \(u_{ii} c_i + \sum_{l > i} u_{il} c_l = 0\) with \(u_{ii} \ne 0\). Starting from row \(k\), which gives \(c_k = 0\), each row in turn gives \(c_i = 0\). So the only solution is \(c = \mathbf{0}\), and the list is independent. \(\blacksquare\)

Corollary 3.6 (no independence beyond the dimension of \(\R^n\))

In \(\R^n\), every list of more than \(n\) vectors is linearly dependent. So four vectors in \(\R^3\) are dependent, and five vectors in \(\R^4\) are dependent.

Proof

Let the list have \(k > n\) vectors, and let \(A\) be the \(n \times k\) matrix with these columns. By Lemma 3.4 with \(m = n\), \(Ac = \mathbf{0}\) has a solution \(c \ne \mathbf{0}\). Then \(\sum_i c_i v_i = A c = \mathbf{0}\), so the list is dependent by Definition 3.1. \(\blacksquare\)

Theorem 3.7 (a vector space that is spanned by a list has no longer independent list)

Let \(V\) be a real vector space, let \(v_1, \dots, v_m\) span \(V\), and let \(w_1, \dots, w_k\) be vectors in \(V\) with \(k > m\). Then \(w_1, \dots, w_k\) is linearly dependent.

Proof

Each \(w_j\) lies in \(\operatorname{span}(v_1, \dots, v_m)\), so there are real numbers \(a_{ij}\) with \(w_j = \sum_{i=1}^m a_{ij} v_i\). Let \(A\) be the \(m \times k\) matrix with entries \(a_{ij}\). Since \(k > m\), Lemma 3.4 gives \(c \ne \mathbf{0}\) in \(\R^k\) with \(Ac = \mathbf{0}\), that is, \(\sum_j a_{ij} c_j = 0\) for each \(i\). Then, by axioms (i) to (iv) and Lemma 1.3,

\[\sum_{j=1}^k c_j w_j = \sum_{j=1}^k c_j \sum_{i=1}^m a_{ij} v_i = \sum_{i=1}^m \Bigl(\sum_{j=1}^k a_{ij} c_j\Bigr) v_i = \sum_{i=1}^m 0\, v_i = \mathbf{0}.\]

The coefficients \(c_j\) are not all zero, so the list is dependent. \(\blacksquare\)

Theorem 3.8 (invariance of dimension)

Let \(V\) be a real vector space with a basis \(h_1, \dots, h_m\) and a basis \(g_1, \dots, g_k\), both lists finite. Then \(m = k\).

Proof

The list \(h_1, \dots, h_m\) spans \(V\), so Theorem 3.7 applies to any \(k\) vectors of \(V\). If \(k > m\), then \(g_1, \dots, g_k\) would be dependent, contradicting that it is a basis. So \(k \le m\). The same argument with the roles of the two bases exchanged gives \(m \le k\). Hence \(m = k\). \(\blacksquare\)

Example 3.9 (the standard basis of \(\R^n\))

Let \(e_i\) be the vector in \(\R^n\) with \(1\) in position \(i\) and \(0\) elsewhere. The list \(e_1, \dots, e_n\) spans \(\R^n\), because \((x_1, \dots, x_n) = \sum_i x_i e_i\). It is independent, because \(\sum_i c_i e_i\) has entries \(c_1, \dots, c_n\), so it equals \(\mathbf{0}\) only when every \(c_i = 0\). So it is a basis, and by Theorem 3.8 the dimension of \(\R^n\) is \(n\).

Example 3.10 (a dependent list with a plane for its span)

Let \(v_1 = (1, 0, 1)\), \(v_2 = (0, 1, 1)\) and \(v_3 = (1, 1, 2)\). Since \(v_1 + v_2 = (1, 1, 2) = v_3\), the list is dependent by Definition 3.1, with coefficients \(1, 1, -1\). The span of \(v_1, v_2\) is the set of \((a, b, a + b)\), and \(v_3\) belongs to it. So the span of all three is the plane \(z = x + y\), and \(v_1, v_2\) is a basis of that plane. Its dimension is \(2\). Lab 1 tests dependence of seeded lists by elimination. It also uses lists of the form \(v_1, v_2, v_3, v_4\) with \(v_4 = 2v_1 - v_2 + v_3\), which are dependent for the same reason as this example.

Lab 1 · Rank, independence and span of seeded integer vectors

Predicted from the theorems before running. Corollary 3.6 predicts 0 for the count of independent 4-vector lists in \(\R^3\) and 0 for the count of independent 5-vector lists in \(\R^4\), out of 200 seeded lists each. Proposition 3.5 with the planted relation \(v_4 = 2v_1 - v_2 + v_3\) predicts that the four vectors are dependent in every one of 100 draws, and that the count of four-vector lists with rank 3 equals the count of independent triples \(v_1, v_2, v_3\). Example 2.3 predicts that membership in \(\operatorname{span}(e_1, e_2)\) agrees with the test \(x_3 = 0\) in every one of 100 draws. The counts of independent 3-vector lists in \(\R^3\) and of independent 4-vector lists in \(\R^4\) are not predicted; the lab prints them. All entries are integers from \(-3\) to \(3\), drawn by a fixed generator.

"""M3 L01 lab 1: rank, independence and span of integer vectors, in exact rational arithmetic.

Claims checked, on seeded integer vectors with entries from -3 to 3:
  (a) a list of k vectors is linearly independent exactly when the matrix having them as columns has
      rank k, where rank is the number of pivots that Gauss-Jordan elimination finds (Proposition 3.5
      of Lesson 1); the lab uses this rank test as its independence test;
  (b) on the seeded lists, the 4-vector lists in R^3 and the 5-vector lists in R^4 are all dependent
      (Corollary 3.6 of Lesson 1 proves this for every list of more than n vectors in R^n);
  (c) for v4 = 2 v1 - v2 + v3 in R^4, the number of four-vector lists with rank 3 equals the number of
      independent triples v1, v2, v3 over the seeded draws (the lab compares the two counts);
  (d) x lies in the span of e1 and e2 in R^3 exactly when its third coordinate is 0 (Example 2.3
      of Lesson 1);
  (e) the standard basis e1, ..., e4 of R^4 is independent and has rank 4.
Every rank is computed with fractions.Fraction, so no rounding enters. The draws come from a linear
congruential generator with fixed constants, so the output is the same on every run. The lab checks
these claims on the listed seeded inputs only and says nothing about other inputs. Standard library only.
"""

from __future__ import annotations

from fractions import Fraction

LCG_MULTIPLIER = 1103515245
LCG_INCREMENT = 12345
LCG_MODULUS = 2**31
SEED = 20261028
DRAWS = 200
PLANTED_DRAWS = 100


class Lcg:
    """A linear congruential generator with fixed constants, so every run draws the same integers."""

    def __init__(self, seed: int) -> None:
        self.state = seed % LCG_MODULUS

    def below(self, n: int) -> int:
        """Return an integer from 0 to n - 1. Each call advances the state once."""
        self.state = (LCG_MULTIPLIER * self.state + LCG_INCREMENT) % LCG_MODULUS
        return (self.state >> 16) % n

    def entry(self, bound: int) -> int:
        """Return an integer from -bound to bound, inclusive."""
        return self.below(2 * bound + 1) - bound


def vector(gen: Lcg, n: int, bound: int = 3) -> list[Fraction]:
    """A vector in R^n with integer entries from -bound to bound, as exact fractions."""
    return [Fraction(gen.entry(bound)) for _ in range(n)]


def rank(columns: list[list[Fraction]]) -> int:
    """The rank of the matrix whose columns are the given vectors: the number of pivots found by elimination.

    Gauss-Jordan elimination is run on the matrix with those columns. Every column has the same length n.
    An empty list has rank 0.
    """
    if not columns:
        return 0
    n = len(columns[0])
    k = len(columns)
    m = [[columns[j][i] for j in range(k)] for i in range(n)]
    pivots = 0
    for c in range(k):
        p = next((i for i in range(pivots, n) if m[i][c] != 0), None)
        if p is None:
            continue
        m[pivots], m[p] = m[p], m[pivots]
        for i in range(n):
            if i != pivots and m[i][c] != 0:
                factor = m[i][c] / m[pivots][c]
                m[i] = [a - factor * b for a, b in zip(m[i], m[pivots], strict=True)]
        pivots += 1
        if pivots == n:
            break
    return pivots


def independent(columns: list[list[Fraction]]) -> bool:
    """True when the list is linearly independent: its rank equals the number of vectors."""
    return rank(columns) == len(columns)


def in_span(spanning: list[list[Fraction]], x: list[Fraction]) -> bool:
    """True when x lies in the span of the list: adding x does not raise the rank."""
    return rank([*spanning, x]) == rank(spanning)


def count_independent(gen: Lcg, n: int, k: int, draws: int) -> int:
    """How many of the draws are lists of k vectors in R^n that are linearly independent."""
    hits = 0
    for _ in range(draws):
        cols = [vector(gen, n) for _ in range(k)]
        hits += independent(cols)
    return hits


def planted(gen: Lcg) -> tuple[int, int, int]:
    """For PLANTED_DRAWS draws of v1, v2, v3 in Z^4, with v4 = 2 v1 - v2 + v3.

    Returns (the count of dependent four-vector lists, the count of independent triples, the count of
    four-vector lists with rank exactly 3).
    """
    dependent = triples = rank_three = 0
    for _ in range(PLANTED_DRAWS):
        v1 = vector(gen, 4)
        v2 = vector(gen, 4)
        v3 = vector(gen, 4)
        v4 = [2 * a - b + c for a, b, c in zip(v1, v2, v3, strict=True)]
        four = [v1, v2, v3, v4]
        dependent += not independent(four)
        triples += independent([v1, v2, v3])
        rank_three += rank(four) == 3
    return dependent, triples, rank_three


def main() -> None:
    gen = Lcg(SEED)
    a = count_independent(gen, 3, 3, DRAWS)
    b = count_independent(gen, 3, 4, DRAWS)
    c = count_independent(gen, 4, 4, DRAWS)
    d = count_independent(gen, 4, 5, DRAWS)
    print(f"R^3, 3 vectors: independent in {a} of {DRAWS} seeded lists")
    print(f"R^3, 4 vectors: independent in {b} of {DRAWS} seeded lists")
    print(f"R^4, 4 vectors: independent in {c} of {DRAWS} seeded lists")
    print(f"R^4, 5 vectors: independent in {d} of {DRAWS} seeded lists")

    dependent, triples, rank_three = planted(gen)
    print(f"planted v4 = 2 v1 - v2 + v3 in R^4: dependent in {dependent} of {PLANTED_DRAWS} seeded triples")
    print(f"v1, v2, v3 independent in {triples} of {PLANTED_DRAWS} seeded triples")
    print(f"planted list has rank 3 in {rank_three} of {PLANTED_DRAWS} seeded triples")
    print(f"rank 3 count equals the independent-triple count: {rank_three == triples}")

    e1 = [Fraction(1), Fraction(0), Fraction(0)]
    e2 = [Fraction(0), Fraction(1), Fraction(0)]
    print(f"(1, 2, 0) in span(e1, e2): {in_span([e1, e2], [Fraction(1), Fraction(2), Fraction(0)])}")
    print(f"(0, 0, 1) in span(e1, e2): {in_span([e1, e2], [Fraction(0), Fraction(0), Fraction(1)])}")
    agree = 0
    for _ in range(PLANTED_DRAWS):
        x = vector(gen, 3)
        agree += in_span([e1, e2], x) == (x[2] == 0)
    print(f"span membership agrees with the test x3 = 0 in {agree} of {PLANTED_DRAWS} seeded vectors")

    basis = [[Fraction(int(i == j)) for i in range(4)] for j in range(4)]
    print(f"standard basis e1, ..., e4 of R^4 is independent with rank 4: {independent(basis) and rank(basis) == 4}")

Remark 3.11 (what a finite check establishes)

Lab 1 checks each claim on the listed draws. The proofs above hold for every list, and Lab 1 does not replace them. A counterexample would refute a claim, but a list of passed draws proves nothing about the draws it does not make.

Proposition 3.12 (the rank is well defined and gives the solution dimension)

Let \(A\) be a real \(m \times k\) matrix, and let \(N(A) = \{c \in \R^k : Ac = \mathbf{0}\}\). Then every echelon form of \(A\), obtained by the row operations of Definition 3.3, has the same number \(r\) of pivots. Also \(N(A)\) is a subspace of \(\R^k\) with \(\dim N(A) = k - r\), so \(\dim N(A) = k - \operatorname{rank}(A)\). The hypotheses are: real entries, the dimensions \(m\) and \(k\), and the row operations of Definition 3.3.

Proof

Let \(U\) be an echelon form of \(A\) with \(r\) pivots, in columns \(j_1 < \dots < j_r\), and let \(F\) be the set of the \(k - r\) other columns. By Definition 3.3, \(U\) and \(A\) have the same solutions, so \(N(A) = \{c : Uc = \mathbf{0}\}\). Since the pivot columns of \(U\) are \(j_1 < \dots < j_r\), the unknown \(c_l\) with \(l > j_i\) is either a pivot unknown of a lower row or a free unknown. Let \(\varphi : N(A) \to \R^F\) send \(c\) to its entries \((c_f)_{f \in F}\). It is linear. It is injective: each non-zero row \(i\) of \(U\) reads \(u_{i j_i} c_{j_i} + \sum_{l > j_i} u_{i l} c_l = 0\) with \(u_{i j_i} \ne 0\), so solving the pivot rows from the last upward determines every pivot unknown from the free unknowns. It is surjective: for any choice of the free unknowns, the same back substitution defines the pivot unknowns, and the resulting \(c\) satisfies every row, since zero rows impose no condition. So \(\varphi\) is a bijection. The preimages under \(\varphi\) of the standard unit vectors of \(\R^F\) form a basis of \(N(A)\) with \(k - r\) vectors, once \(N(A)\) is known to be a subspace. It is one, because if \(Ac = Ac' = \mathbf{0}\) then \(A(ac + bc') = \mathbf{0}\). By Theorem 3.8, \(\dim N(A) = k - r\). Since \(k\) and \(N(A)\) do not depend on \(U\), neither does \(r = k - \dim N(A)\). \(\blacksquare\)

4Where the canon breaks

This lesson uses the real numbers throughout. Each named limitation below is a boundary of the results above, not a gap in the proofs.

  • The field is the reals. Lemma 3.4 uses division by a pivot, and Definition 1.1 uses the real numbers as scalars. The proofs use only the properties of the reals that these steps need. They are not claimed for other scalar fields in this unit.
  • Infinite bases are outside Theorem 3.8. The theorem compares two finite bases. A space with no finite basis is not covered by this lesson, and its dimension is not defined here.
  • Exact rank is not floating-point rank. The pivot test asks whether an entry is exactly zero. In floating-point arithmetic a tiny non-zero entry can stand for zero, and the rank of a computed matrix can differ from the exact rank. Lab 1 uses exact fractions for that reason.
  • A spanning list need not be a basis. Example 3.10 has three vectors spanning a plane. Only a list that is both spanning and independent is a basis.

5Misconceptions

  1. “Three distinct non-zero vectors in \(\R^3\) form a basis.”

    Example 3.10 gives three distinct non-zero vectors, \((1, 0, 1)\), \((0, 1, 1)\) and \((1, 1, 2)\), with \(v_3 = v_1 + v_2\). The list is dependent, its span is a plane, and it is not a basis of \(\R^3\). Distinctness and non-zero length do not imply independence, as Example 3.10 shows.

  2. “Four vectors in \(\R^3\) can be independent, because there is room for them.”

    Corollary 3.6 shows that every list of more than \(n\) vectors in \(\R^n\) is dependent. Lab 1 prints 0 independent 4-vector lists in \(\R^3\) out of 200 seeded lists, which is the count the corollary predicts. A fourth vector cannot add a new independent direction in \(\R^3\).

  3. “A list is independent when no vector is a multiple of another.”

    The list \((1, 0)\), \((0, 1)\), \((1, 1)\) in \(\R^2\) has no vector that is a multiple of another. Yet \((1, 1) = (1, 0) + (0, 1)\), so the list is dependent by Definition 3.1. Pairwise non-proportionality is necessary for a pair to be independent (if \(v = cw\), then \(v - cw = \mathbf{0}\) is a non-zero relation), but it does not decide the independence of a longer list.

Mechanics

M1 · Is a list a basis of the plane?

Let \(u = (1, 2, 0)\), \(v = (0, 1, 1)\) and \(w = (1, 3, 1)\) in \(\R^3\). Decide whether \(u, v, w\) is a basis of \(\R^3\), and find the dimension of \(\operatorname{span}(u, v, w)\).

Solution

The list is not a basis of \(\R^3\), because it is dependent, and Definition 3.2 requires a basis to be independent. Indeed \(u + v = (1, 3, 1) = w\), so the coefficients \(1, 1, -1\) give \(u + v - w = \mathbf{0}\), which is a non-zero combination equal to zero. The span of \(u, v\) is the set \((a, 2a + b, b)\), and \(w\) lies in it with \(a = 1\), \(b = 1\). So \(\operatorname{span}(u, v, w) = \operatorname{span}(u, v)\), which has dimension \(2\), since \(u, v\) are independent: \(au + bv = \mathbf{0}\) gives \(a = 0\) from the first coordinate and then \(b = 0\) from the third.

M2 · Does the subspace test hold for a set defined by a product?

Let \(W = \{(x, y) \in \R^2 : xy = 0\}\), the union of the two coordinate axes. Decide whether \(W\) is a subspace of \(\R^2\), using Proposition 1.4.

Solution

\(W\) contains \(\mathbf{0}\), so it is non-empty. It is closed under scalar multiplication: \(a(x, y) = (ax, ay)\) has product \(a^2 xy = a^2 \cdot 0 = 0\) when \(xy = 0\). Closure under addition fails. The vectors \((1, 0)\) and \((0, 1)\) are in \(W\), since each has a zero coordinate, but their sum \((1, 1)\) has product \(1 \ne 0\). By Proposition 1.4 (b), \(W\) is not a subspace.

M3 · A basis of a plane through the origin

Let \(W = \{(x, y, z) \in \R^3 : x + y + z = 0\}\). Show that \(W\) is a subspace, and find a basis of \(W\) and its dimension.

Solution

\(W\) contains \(\mathbf{0}\), so it is non-empty. If \(x + y + z = 0\) and \(x' + y' + z' = 0\), the sum has coordinate total \(0 + 0 = 0\), and \(a(x, y, z)\) has coordinate total \(a \cdot 0 = 0\). By Proposition 1.4, \(W\) is a subspace. The vectors \(p = (1, -1, 0)\) and \(q = (1, 0, -1)\) lie in \(W\). They span \(W\): any \((x, y, z)\) in \(W\) equals \(-y\, p - z\, q\), since \(-y p - z q = (-y - z, y, z)\) and \(-y - z = x\) because \(x + y + z = 0\). They are independent: \(a p + b q = \mathbf{0}\) gives \(a + b = 0\), \(-a = 0\) and \(-b = 0\), so \(a = b = 0\). So \(p, q\) is a basis and \(\dim W = 2\).

Proof

P1 · The intersection of two subspaces

Let \(X\) and \(W\) be subspaces of a real vector space \(V\). Prove that \(X \cap W\) is a subspace of \(V\).

Solution

Apply Proposition 1.4. Both \(X\) and \(W\) contain \(\mathbf{0}\), so \(\mathbf{0} \in X \cap W\), and the intersection is non-empty. If \(u, v \in X \cap W\), then \(u + v\) lies in \(X\) because \(X\) is a subspace, and in \(W\) because \(W\) is a subspace, so \(u + v \in X \cap W\). If \(a \in \R\) and \(v \in X \cap W\), then \(av\) lies in \(X\) and in \(W\) by the same argument for scalar multiplication. Conditions (a), (b) and (c) hold, so \(X \cap W\) is a subspace.

P2 · Adding a vector outside the span keeps independence

Let \(v_1, \dots, v_k\) be linearly independent in \(V\), and let \(x \notin \operatorname{span}(v_1, \dots, v_k)\). Prove that \(v_1, \dots, v_k, x\) is linearly independent.

Solution

Suppose \(\sum_i c_i v_i + c x = \mathbf{0}\). If \(c \ne 0\), then \(x = -c^{-1} \sum_i c_i v_i\), which is a linear combination of the \(v_i\) by axioms (iii) and (iv), so \(x\) would lie in the span, contrary to hypothesis. Hence \(c = 0\). The equation becomes \(\sum_i c_i v_i = \mathbf{0}\), and independence of \(v_1, \dots, v_k\) gives \(c_i = 0\) for every \(i\). So every coefficient is zero, and the extended list is independent.

P3 · A dependence removes a redundant vector

Let \(v_1, \dots, v_k\) be dependent, with \(\sum_i c_i v_i = \mathbf{0}\) and \(c_j \ne 0\) for some \(j\). Prove that \(\operatorname{span}(v_1, \dots, v_k) = \operatorname{span}(v_i : i \ne j)\).

Solution

From the dependence, \(v_j = -c_j^{-1} \sum_{i \ne j} c_i v_i\), so \(v_j\) lies in the span of the other vectors. Let \(S\) be the span of all \(k\) vectors and \(Y\) the span of the others. Each \(v_i\) with \(i \ne j\) lies in \(Y\), and \(v_j\) lies in \(Y\) by the displayed formula, so \(S \subseteq Y\) by Proposition 2.2 (the span is the smallest subspace containing the list). The reverse inclusion \(Y \subseteq S\) holds because every combination of the \(k - 1\) vectors is a combination of all \(k\) vectors with coefficient zero on \(v_j\).

Empirical

E1 · Reading the 4-vector count (Lab 1)

Lab 1 prints the number of independent 4-vector lists in \(\R^3\) among 200 seeded lists. State the printed value and the reason it must be that value, and say what the printout does not show about lists in \(\R^3\) with more than four vectors.

Solution

The printed value is 0 of 200. By Corollary 3.6 every 4-vector list in \(\R^3\) is dependent, so no draw can be independent, whatever the seeded values are. The printout shows the count for these 200 draws, which the theorem already determines. It does not show anything about lists with more than four vectors, which the lab does not draw. The corollary covers them, but the lab does not check them.

E2 · A rank by hand

Find the rank of the \(3 \times 3\) matrix with columns \((1, 2, 3)\), \((2, 4, 6)\) and \((0, 1, 1)\), and say which columns form an independent list.

Solution

The second column is twice the first, so the first two columns are dependent. Write the matrix by rows: \((1, 2, 0)\), \((2, 4, 1)\), \((3, 6, 1)\). Subtracting twice the first row from the second, and three times the first row from the third, gives \((1, 2, 0)\), \((0, 0, 1)\), \((0, 0, 1)\). Subtracting the second row from the third gives \((0, 0, 0)\). The pivots are in column 1 and column 3, so the rank is \(2\). The independent sub-list is the first and third columns: if \(a(1, 2, 3) + b(0, 1, 1) = \mathbf{0}\), the first coordinate gives \(a = 0\), and then the second gives \(b = 0\).

E3 · The rank-3 count in the planted draws (Lab 1)

Lab 1 prints the count of planted 4-vector lists with rank 3, and the count of independent triples \(v_1, v_2, v_3\), and then the line that says whether those two counts are equal. Explain why they must be equal, and state what the lab computes to check it.

Solution

The fourth vector \(v_4 = 2v_1 - v_2 + v_3\) lies in \(\operatorname{span}(v_1, v_2, v_3)\), so adding it does not change the span and does not change the rank. The rank of the four vectors therefore equals the rank of the triple. If the triple is independent, its rank is 3 and so is the rank of the four vectors. If the triple is dependent, its rank is at most 2, and so is the rank of the four vectors, which is therefore not 3. The two counts are equal for every set of draws. The lab computes both counts by elimination and prints the comparison.

Research

R1 · Which properties of the reals do the proofs use?

List the properties of \(\R\) that the proofs of Lemma 3.4 and Theorem 3.8 use, and say which of them the rationals also have. Lab 1 uses the rationals. State what that lets the lab claim.

Solution

Lemma 3.4 uses the arithmetic of the scalars: commutativity and associativity of addition and multiplication, distributivity, the existence of additive inverses, and the existence of a multiplicative inverse for each non-zero pivot. Theorem 3.8 uses Theorem 3.7, and so the same properties. The rationals have all of these, so each step of those two proofs is valid with the rational numbers as scalars. Section 4 does not claim the theorems for other fields. Lab 1 computes with fractions, which are the rationals, so its elimination uses the same steps. The lab's counts concern lists of integer vectors. They say nothing about lists of real vectors with non-integer entries, and the lab does not claim that they do.

R2 · The space of polynomials has no finite basis

Let \(\mathcal{P}\) be the set of formal polynomials \(p = a_0 + a_1 x + \dots + a_M x^M\), for some integer \(M \ge 0\), with real coefficients, where two polynomials are equal when their coefficient lists agree, with zero coefficients added as needed. Show that \(\mathcal{P}\) has no finite spanning list.

Solution

Take any finite list \(p_1, \dots, p_m\) in \(\mathcal{P}\), with degrees \(\deg p_1, \dots, \deg p_m\), and let \(D = \max_i \deg p_i\). Every linear combination \(\sum_i c_i p_i\) has degree at most \(D\), because the coefficient of \(x^n\) for \(n > D\) is the sum of zero contributions. So \(x^{D+1}\) is not a linear combination of the list: its coefficient of \(x^{D+1}\) is \(1\), while every combination has coefficient \(0\) there. The list does not span \(\mathcal{P}\). The monomials \(1, x, x^2, \dots\) are independent by coefficient comparison, so \(\mathcal{P}\) has an infinite basis and the finite-dimensional results of this lesson do not apply to it.

R3 · Finite-precision rank

A colleague computes the rank of a matrix with floating-point elimination and treats any pivot smaller than \(10^{-9}\) in absolute value as zero. Give a matrix for which this rule can change the rank relative to exact arithmetic, and explain which of Lab 1's choices avoids the problem.

Solution

Take the \(2 \times 2\) matrix with columns \((1, 1)\) and \((1, 1 + 10^{-12})\). Exactly, the columns are independent: \(a(1, 1) + b(1, 1 + 10^{-12}) = \mathbf{0}\) gives \(a + b = 0\) and \(a + (1 + 10^{-12}) b = 0\); subtracting the first from the second gives \(10^{-12} b = 0\), so \(b = 0\) and then \(a = 0\). The second pivot is \(10^{-12}\) in exact arithmetic, and about \(1.00009 \times 10^{-12}\) in double-precision arithmetic, where \(1 + 10^{-12}\) is rounded before the subtraction. Either value is below \(10^{-9}\), so the rule treats it as zero and the computed rank is 1. The exact rank is 2. Lab 1 uses exact arithmetic on fractions with integer entries, so no pivot is ever rounded, and the rank it reports is the exact rank of the integer input.

8Retrieval quiz

Answer from memory, then check. Finishing the quiz adds this lesson's cards to your review deck.

  1. Which list of vectors in \(\R^3\) is dependent?

    Options

    \(e_1 + e_2\) is the sum of the first two vectors, so the coefficients \(1, 1, -1\) give a non-zero combination equal to zero (Definition 3.1).

  2. What is the dimension of the span of \((1, 0, 1)\), \((0, 1, 1)\) and \((1, 1, 2)\)?

    The third vector is the sum of the first two (Example 3.10), so the span is the plane \(z = x + y\), spanned by two independent vectors. The dimension is 2.

  3. Can four vectors in \(\R^3\) be linearly independent?

    Options

    Corollary 3.6: a list of more than \(n\) vectors in \(\R^n\) is dependent, so four vectors in \(\R^3\) are dependent.

  4. Is \((1, 0), (0, 1), (1, 1)\) linearly independent?

    Options

    The sum \((1, 0) + (0, 1)\) equals \((1, 1)\), so the coefficients \(1, 1, -1\) give a non-zero combination equal to zero (Misconception 3).

  5. How many pivots does the \(3 \times 4\) matrix with columns \(e_1, e_2, e_3, (1, 1, 1)\) have?

    The first three columns already give pivots in rows 1, 2 and 3. The fourth column has no further pivot, since three rows give at most three pivots (the proof of Lemma 3.4).

  6. Which set is a subspace of \(\R^2\)?

    Options

    The first-coordinate-zero set contains \(\mathbf{0}\) and is closed under addition and scalar multiplication (Proposition 1.4). The set with first coordinate 1 does not contain \(\mathbf{0}\), and the set of vectors with both coordinates non-negative is not closed under multiplication by \(-1\).

  7. In a real vector space, what is \(0v\) for a vector \(v\)?

    Options

    Lemma 1.3: \(0v = \mathbf{0}\), the zero vector of the space, not the real number 0.

  8. Which pair is a basis of the plane \(z = 0\) in \(\R^3\)?

    Options

    The first pair is independent and spans the plane. The second and third pairs are dependent, since one vector is a multiple of the other.

  9. What is the dimension of \(\R^5\)?

    The standard basis \(e_1, \dots, e_5\) has five vectors (Example 3.9), and dimension is well defined (Theorem 3.8).

  10. What does Lab 1's count of 100 of 100 for the planted lists establish?

    Options

    The count is exact for the seeded draws. The statement for all draws is Proposition 3.5 with the relation \(v_4 = 2v_1 - v_2 + v_3\), which is proved, not counted (Remark 3.11).
