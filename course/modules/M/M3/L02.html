Linear Maps and Their Matrices

  • Uses: vector space, span, linear independence and basis (Lesson 1)
  • Introduces: linear map and its matrix
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study or lab result
  • Dlore
  • Xrefuted

Later lessons compute quantities from the matrix of a map, and that matrix depends on the basis chosen. So a statement about a matrix must say which basis it refers to. This lesson defines a linear map, its kernel and image, and the matrix of a map with respect to a chosen basis of the input space and a chosen basis of the output space. It proves that composition of maps is multiplication of their matrices, and that a change of basis turns a matrix \(A\) into \(P^{-1} A P\). Lab 1 checks that formula on seeded matrices, exactly in its matrix products and in floating point in a separate tolerance check.

1Linear maps

Definition 1.1 (linear map)

Let \(V\) and \(W\) be real vector spaces. A function \(\mathcal{L} : V \to W\) is a linear map when \(\mathcal{L}(u + v) = \mathcal{L}u + \mathcal{L}v\) and \(\mathcal{L}(av) = a\,\mathcal{L}v\) for all \(u, v \in V\) and all \(a \in \R\).

Lemma 1.2 (zero and combinations)

Let \(\mathcal{L} : V \to W\) be linear. Then \(\mathcal{L}\mathbf{0} = \mathbf{0}\), and \(\mathcal{L}(av + bw) = a\,\mathcal{L}v + b\,\mathcal{L}w\) for all \(v, w \in V\) and \(a, b \in \R\).

Proof

By Lemma 1.3 of Lesson 1, \(\mathbf{0}_V = 0\,\mathbf{0}_V\), so \(\mathcal{L}\mathbf{0}_V = \mathcal{L}(0\,\mathbf{0}_V) = 0\,\mathcal{L}\mathbf{0}_V = \mathbf{0}_W\), using the scalar rule and Lemma 1.3 in \(W\). The second identity follows from the two defining rules: \(\mathcal{L}(av + bw) = \mathcal{L}(av) + \mathcal{L}(bw) = a\,\mathcal{L}v + b\,\mathcal{L}w\). \(\blacksquare\)

Definition 1.3 (kernel and image)

For a linear map \(\mathcal{L} : V \to W\), the kernel is \(\ker \mathcal{L} = \{v \in V : \mathcal{L}v = \mathbf{0}\}\), and the image is \(\operatorname{Im} \mathcal{L} = \{\mathcal{L}v : v \in V\}\).

Proposition 1.4 (kernel and image are subspaces)

Let \(\mathcal{L} : V \to W\) be linear. Then \(\ker \mathcal{L}\) is a subspace of \(V\), and \(\operatorname{Im} \mathcal{L}\) is a subspace of \(W\).

Proof

Both sets are non-empty: \(\mathcal{L}\mathbf{0} = \mathbf{0}\) by Lemma 1.2, so \(\mathbf{0} \in \ker \mathcal{L}\) and \(\mathbf{0} \in \operatorname{Im} \mathcal{L}\). If \(u, v \in \ker \mathcal{L}\) and \(a \in \R\), then \(\mathcal{L}(u + v) = \mathcal{L}u + \mathcal{L}v = \mathbf{0}\) and \(\mathcal{L}(av) = a\,\mathcal{L}v = \mathbf{0}\), so \(\ker \mathcal{L}\) satisfies conditions (b) and (c) of Proposition 1.4 of Lesson 1. If \(\mathcal{L}u, \mathcal{L}v \in \operatorname{Im} \mathcal{L}\) and \(a \in \R\), then \(\mathcal{L}u + \mathcal{L}v = \mathcal{L}(u + v)\) and \(a\,\mathcal{L}u = \mathcal{L}(au)\) lie in \(\operatorname{Im} \mathcal{L}\). \(\blacksquare\)

Example 1.5 (a map with trivial kernel and full image)

Let \(\mathcal{L}(x, y) = (x + y, x - y)\) from \(\R^2\) to \(\R^2\). It is linear, because each coordinate is a linear function of \((x, y)\). If \(\mathcal{L}(x, y) = \mathbf{0}\), then \(x + y = 0\) and \(x - y = 0\), so \(x = y = 0\) and \(\ker \mathcal{L} = \{\mathbf{0}\}\). For any \((p, q)\), the point \(x = (p + q)/2\), \(y = (p - q)/2\) gives \(\mathcal{L}(x, y) = (p, q)\), so \(\operatorname{Im} \mathcal{L} = \R^2\).

2Coordinates and the matrix of a map

A real \(m \times n\) matrix is a rectangular array of real numbers with \(m\) rows and \(n\) columns. For an \(m \times n\) matrix \(A\) and a vector \(x \in \R^n\), \(Ax\) is the vector in \(\R^m\) whose \(i\)-th entry is \(\sum_j A_{ij} x_j\). For an \(m \times n\) matrix \(A\) and an \(n \times p\) matrix \(B\), the product \(AB\) has entries \((AB)_{ij} = \sum_k A_{ik} B_{kj}\). A square matrix \(P\) is invertible when it has an inverse \(P^{-1}\) with \(PP^{-1} = P^{-1}P = I\), where \(I\) is the identity matrix. The standard unit vectors are \(e_1, \dots, e_n\) in \(\R^n\).

Definition 2.1 (coordinates)

Let \(B = (b_1, \dots, b_n)\) be a basis of \(V\), in this order. For \(v \in V\), the coordinate vector \([v]_B\) is the vector \(x \in \R^n\) with \(v = \sum_j x_j b_j\). Such an \(x\) exists because \(B\) spans \(V\), and it is unique because \(B\) is independent: if \(\sum_j x_j b_j = \sum_j y_j b_j\), then \(\sum_j (x_j - y_j) b_j = \mathbf{0}\), so \(x = y\).

Proposition 2.2 (coordinates are linear)

Let \(B\) be a basis of \(V\). For \(v, w \in V\) and \(a, b \in \R\), \([av + bw]_B = a[v]_B + b[w]_B\).

Proof

Let \(x = [v]_B\) and \(y = [w]_B\). By axioms (iii) and (iv) of Definition 1.1 of Lesson 1, \(av + bw = \sum_j (a x_j + b y_j) b_j\). The vector \(a x + b y\) is therefore a coordinate vector of \(av + bw\), and by the uniqueness in Definition 2.1 it is the coordinate vector. \(\blacksquare\)

Definition 2.3 (matrix of a map)

Let \(B = (b_1, \dots, b_n)\) be a basis of \(V\), let \(C\) be a basis of \(W\), and let \(\mathcal{L} : V \to W\) be linear. The matrix of \(\mathcal{L}\) with respect to \(B\) and \(C\), written \([\mathcal{L}]_{C \leftarrow B}\), is the matrix whose \(j\)-th column is \([\mathcal{L} b_j]_C\). The matrix depends on both bases, which is why the notation names them.

Theorem 2.4 (the matrix represents the map)

Let \(\mathcal{L} : V \to W\) be linear, let \(B = (b_1, \dots, b_n)\) be a basis of \(V\), and let \(C\) be a basis of \(W\). Then for every \(v \in V\), \([\mathcal{L}v]_C = [\mathcal{L}]_{C \leftarrow B}\, [v]_B\).

Proof

Let \(x = [v]_B\), so \(v = \sum_j x_j b_j\). By Lemma 1.2 and induction on the number of terms, \(\mathcal{L}v = \sum_j x_j\, \mathcal{L} b_j\). By Proposition 2.2 applied in \(W\), \([\mathcal{L}v]_C = \sum_j x_j [\mathcal{L} b_j]_C\). The vector \(\sum_j x_j [\mathcal{L} b_j]_C\) is the product of the matrix with columns \([\mathcal{L} b_j]_C\) and the vector \(x\), which is \([\mathcal{L}]_{C \leftarrow B}\, x\). \(\blacksquare\)

Remark 2.5 (a matrix is determined by its action)

If \(M\) and \(N\) are \(m \times n\) matrices with \(Mx = Nx\) for every \(x \in \R^n\), then \(M = N\). Taking \(x = e_j\) gives \(Me_j = Ne_j\), and \(Me_j\) is the \(j\)-th column of \(M\). So the two matrices have the same columns. The same column argument closes the proof of Theorem 4.1.

Example 2.6 (the map of Example 1.5 in a non-standard basis)

Let \(\mathcal{L}(x, y) = (x + y, x - y)\) as in Example 1.5, and let \(B = C = (b_1, b_2)\) with \(b_1 = (1, 0)\) and \(b_2 = (1, 1)\). Then \(\mathcal{L}b_1 = (1, 1) = b_2\), so \([\mathcal{L}b_1]_C = (0, 1)\). And \(\mathcal{L}b_2 = (2, 0) = 2b_1\), so \([\mathcal{L}b_2]_C = (2, 0)\). The matrix is \([\mathcal{L}]_{C \leftarrow B} = \begin{pmatrix} 0 & 2 \\ 1 & 0 \end{pmatrix}\). For \(v = (1, 1) = b_2\), \([v]_B = (0, 1)\), and the matrix times \((0, 1)\) gives \((2, 0)\), which is \([\mathcal{L}v]_C\), as Theorem 2.4 requires.

3Composition is matrix multiplication

Proposition 3.1 (the matrix of a composition is the product)

Let \(\mathcal{L} : V \to W\) and \(S : W \to Z\) be linear, with bases \(B\) of \(V\), \(C\) of \(W\) and \(D\) of \(Z\). Then \([S \circ \mathcal{L}]_{D \leftarrow B} = [S]_{D \leftarrow C}\, [\mathcal{L}]_{C \leftarrow B}\).

Proof

Both sides are matrices with \(n\) columns, where \(n\) is the number of vectors in \(B\). Fix \(j\) and let \(w = \mathcal{L} b_j\). The \(j\)-th column of the left side is \([S w]_D\). By Theorem 2.4 applied to \(S\), \([S w]_D = [S]_{D \leftarrow C} [w]_C\). The vector \([w]_C = [\mathcal{L} b_j]_C\) is the \(j\)-th column of \([\mathcal{L}]_{C \leftarrow B}\), which is \([\mathcal{L}]_{C \leftarrow B} e_j\). So the \(j\)-th column of the left side is \([S]_{D \leftarrow C}[\mathcal{L}]_{C \leftarrow B} e_j\), the \(j\)-th column of the right side. Equal columns give equal matrices. \(\blacksquare\)

Remark 3.2 (the order is fixed)

Proposition 3.1 gives the matrix of \(S \circ \mathcal{L}\), which applies \(\mathcal{L}\) first. The product is written with the matrix of \(S\) on the left. Misconception 2 below shows that reversing the factors gives a different matrix in general.

4Change of basis

Let \(A\) be an \(n \times n\) matrix and let \(\mathcal{L} : \R^n \to \R^n\) be \(x \mapsto Ax\). Let \(P\) be an invertible \(n \times n\) matrix whose columns \(p_1, \dots, p_n\) form a basis \(B\) of \(\R^n\). The two hypotheses are used below: invertibility gives \(P^{-1}\), and the basis property gives the coordinates \([x]_B\).

Theorem 4.1 (change of basis)

Let \(A\) be an \(n \times n\) real matrix, and let \(P\) be an invertible \(n \times n\) real matrix whose columns form a basis \(B\) of \(\R^n\). Then the matrix of \(x \mapsto Ax\) with respect to \(B\) and \(B\) is \([\mathcal{L}]_{B \leftarrow B} = P^{-1} A P\).

Proof

Let \(x \in \R^n\) and let \(y = [x]_B\). By Definition 2.1, \(x = \sum_j y_j p_j = P y\). Then \(Ax = A P y\). Put \(z = P^{-1} A P y\). Then \(P z = P P^{-1} A P y = A P y = Ax\). Since \(Pz = Ax\) exhibits \(Ax\) as a combination of the columns of \(P\) with coefficients \(z\), the uniqueness in Definition 2.1 gives \([Ax]_B = z\). So for every \(x\), \([Ax]_B = (P^{-1}AP)\,[x]_B\). Now take \(x = b_j\). Then \([b_j]_B = e_j\), and the identity gives \([A b_j]_B = P^{-1}AP\, e_j\), which is the \(j\)-th column of \(P^{-1}AP\). But the \(j\)-th column of \([\mathcal{L}]_{B \leftarrow B}\) is \([\mathcal{L} b_j]_B = [A b_j]_B\) by Definition 2.3. So the two matrices have the same columns, and they are equal. \(\blacksquare\)

Corollary 4.2 (the inverse direction)

Let \(A\) and \(P\) be \(n \times n\) matrices with \(P\) invertible, and put \(\widetilde{A} = P^{-1} A P\). Then \(A = P \widetilde{A} P^{-1}\).

Proof

\(P \widetilde{A} P^{-1} = P (P^{-1} A P) P^{-1} = (P P^{-1}) A (P P^{-1}) = I A I = A\), using associativity of matrix multiplication. \(\blacksquare\)

Example 4.3 (the change of basis of Example 2.6)

Take \(A = \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}\), the matrix of \(x \mapsto Ax\), which is the map of Example 1.5. Let \(P\) have columns \((1, 0)\) and \((1, 1)\), so \(P = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}\), with inverse \(P^{-1} = \begin{pmatrix} 1 & -1 \\ 0 & 1 \end{pmatrix}\). Then \(AP = \begin{pmatrix} 1 & 2 \\ 1 & 0 \end{pmatrix}\), and \(P^{-1}(AP) = \begin{pmatrix} 0 & 2 \\ 1 & 0 \end{pmatrix}\). This is the matrix of Example 2.6, as Theorem 4.1 predicts for the basis \(B\) of Example 2.6.

Lab 1 · The matrix of a map in a seeded basis, checked exactly

Predicted from the theorems before running. Theorem 4.1 predicts that the matrix built column by column from coordinates equals \(P^{-1}AP\) for every pair of an integer matrix \(A\) and an invertible integer matrix \(P\), so the count printed for that check should be 50 of 50. Proposition 3.1 with the same basis on all three spaces predicts that, for the second integer matrix \(M\) of each pair, the matrix of the composition \(x \mapsto M(Ax)\) equals the product of the two matrices in that basis, again 50 of 50. The float evaluation is predicted to agree with the exact matrix within \(10^{-12}\), relative to \(\max(1, |\text{entry}|)\). Singular draws of \(P\) (matrices with no inverse) are not predicted; the lab rejects them and prints how many it rejected.

"""M3 L02 lab 1: the matrix of a linear map in a new basis, and the change-of-basis identity.

For 50 seeded pairs (A, M) of 3 by 3 integer matrices and a seeded invertible 3 by 3 integer matrix P
whose columns form a basis of R^3, the lab checks:
  (a) the matrix of x -> A x in the basis of the columns of P, built column by column from coordinates
      (the coordinates y_j solve P y_j = A p_j, where p_j is column j of P, by elimination), equals
      P^-1 A P exactly (Theorem 4.1 of Lesson 2);
  (b) the matrix of the composition x -> M (A x) in that basis equals the product of the matrix of
      x -> M x and the matrix of x -> A x, both taken in that basis (Proposition 3.1 of Lesson 2);
  (c) a floating-point evaluation of P^-1 A P agrees with the exact matrix to within 1e-12, measured
      relative to max(1, |entry|) for each entry.
Checks (a) and (b) use fractions.Fraction, so they involve no rounding. Check (c) uses floats only.
Candidate matrices P that are singular (they have no inverse) are rejected and redrawn; the count of
rejections is printed.
Draws come from a linear congruential generator with fixed constants, so the output is the same on
every run. The lab checks the listed pairs only. Standard library only.
"""

from __future__ import annotations

from fractions import Fraction

LCG_MULTIPLIER = 1103515245
LCG_INCREMENT = 12345
LCG_MODULUS = 2**31
SEED = 7
PAIRS = 50
SIZE = 3
MATRIX_BOUND = 4
BASIS_BOUND = 3
FLOAT_TOLERANCE = 1e-12


class Lcg:
    """A linear congruential generator with fixed constants, so every run draws the same integers."""

    def __init__(self, seed: int) -> None:
        self.state = seed % LCG_MODULUS

    def entry(self, bound: int) -> int:
        """Return an integer from -bound to bound, inclusive. Each call advances the state once."""
        self.state = (LCG_MULTIPLIER * self.state + LCG_INCREMENT) % LCG_MODULUS
        return (self.state >> 16) % (2 * bound + 1) - bound


Matrix = list[list[Fraction]]


def draw_matrix(gen: Lcg, bound: int) -> Matrix:
    """A SIZE by SIZE matrix of exact fractions with integer entries from -bound to bound."""
    return [[Fraction(gen.entry(bound)) for _ in range(SIZE)] for _ in range(SIZE)]


def mul(a: Matrix, b: Matrix) -> Matrix:
    """The matrix product a b of exact fraction matrices."""
    return [
        [sum((a[i][k] * b[k][j] for k in range(len(b))), Fraction(0)) for j in range(len(b[0]))] for i in range(len(a))
    ]


def solve(m: Matrix, rhs: list[Fraction]) -> list[Fraction]:
    """The solution y of m y = rhs, by Gauss-Jordan elimination with partial pivoting on the largest entry.

    Raises ValueError when m has no pivot in some column, which means m is singular.
    """
    n = len(m)
    aug = [[*m[i], rhs[i]] for i in range(n)]
    for c in range(n):
        p = max(range(c, n), key=lambda i: abs(aug[i][c]))
        if aug[p][c] == 0:
            raise ValueError("singular matrix")
        aug[c], aug[p] = aug[p], aug[c]
        for i in range(n):
            if i != c:
                f = aug[i][c] / aug[c][c]
                aug[i] = [x - f * y for x, y in zip(aug[i], aug[c], strict=True)]
    return [aug[i][n] / aug[i][i] for i in range(n)]


def inverse(m: Matrix) -> Matrix:
    """The inverse of m, solving m x_j = e_j for each standard unit vector e_j."""
    n = len(m)
    columns = [solve(m, [Fraction(int(i == j)) for i in range(n)]) for j in range(n)]
    return [[columns[j][i] for j in range(n)] for i in range(n)]


def solve_float(m: list[list[float]], rhs: list[float]) -> list[float]:
    """The floating-point counterpart of solve, with the same pivoting rule (used only in the float check)."""
    n = len(m)
    aug = [[*m[i], rhs[i]] for i in range(n)]
    for c in range(n):
        p = max(range(c, n), key=lambda i: abs(aug[i][c]))
        if aug[p][c] == 0.0:
            raise ValueError("singular matrix")
        aug[c], aug[p] = aug[p], aug[c]
        for i in range(n):
            if i != c:
                f = aug[i][c] / aug[c][c]
                aug[i] = [x - f * y for x, y in zip(aug[i], aug[c], strict=True)]
    return [aug[i][n] / aug[i][i] for i in range(n)]


def inverse_float(m: list[list[float]]) -> list[list[float]]:
    """The floating-point inverse of m, solving m x_j = e_j for each unit vector."""
    n = len(m)
    columns = [solve_float(m, [float(i == j) for i in range(n)]) for j in range(n)]
    return [[columns[j][i] for j in range(n)] for i in range(n)]


def mul_float(a: list[list[float]], b: list[list[float]]) -> list[list[float]]:
    """The matrix product a b of float matrices."""
    return [[sum(a[i][k] * b[k][j] for k in range(len(b))) for j in range(len(b[0]))] for i in range(len(a))]


def main() -> None:
    gen = Lcg(SEED)
    rejected = 0
    coordinates_ok = 0
    composition_ok = 0
    float_ok = 0
    first_basis_matrix: Matrix = []
    for pair in range(PAIRS):
        a = draw_matrix(gen, MATRIX_BOUND)
        c = draw_matrix(gen, MATRIX_BOUND)
        while True:
            s = draw_matrix(gen, BASIS_BOUND)
            try:
                s_inv = inverse(s)
                break
            except ValueError:
                rejected += 1

        formula = mul(mul(s_inv, a), s)
        coordinates = [
            solve(s, [sum((a[i][k] * s[k][j] for k in range(SIZE)), Fraction(0)) for i in range(SIZE)])
            for j in range(SIZE)
        ]
        built = [list(row) for row in zip(*coordinates, strict=True)]
        coordinates_ok += built == formula

        in_basis_a = formula
        in_basis_c = mul(mul(s_inv, c), s)
        composed = mul(mul(s_inv, c), mul(a, s))
        composition_ok += composed == mul(in_basis_c, in_basis_a)

        float_s = [[float(x) for x in row] for row in s]
        float_a = [[float(x) for x in row] for row in a]
        float_formula = mul_float(mul_float(inverse_float(float_s), float_a), float_s)
        within = all(
            abs(float_formula[i][j] - float(formula[i][j])) <= FLOAT_TOLERANCE * max(1.0, abs(float(formula[i][j])))
            for i in range(SIZE)
            for j in range(SIZE)
        )
        float_ok += within
        if pair == 0:
            first_basis_matrix = formula
    print(f"pairs (A, M) and invertible P tested: {PAIRS}")
    print(f"singular draws of P rejected before an invertible P was found: {rejected}")
    print(f"coordinates of A p_j equal P^-1 A P in {coordinates_ok} of {PAIRS} pairs")
    print(f"composition matrix equals the product of matrices in {composition_ok} of {PAIRS} pairs")
    print(f"float evaluation of P^-1 A P within 1e-12 of the exact matrix in {float_ok} of {PAIRS} pairs")
    print("first pair, matrix of A in the basis of P, row by row:")
    for row in first_basis_matrix:
        print(" ".join(str(x) for x in row))

5Where the canon breaks

The formulas above depend on conventions that texts state in different ways. Each point below names one of them.

  • Columns, not rows, hold the images of the basis vectors. Definition 2.3 puts the coordinate vectors \([\mathcal{L} b_j]_C\) in columns. An alternative convention arranges the same data in rows. The formulas of Sections 2 to 4 are stated for the column convention, and a reader who mixes the two conventions gets wrong matrices.
  • The basis order matters. Reordering the input basis permutes the columns of the matrix and the entries of every input coordinate vector. The map has not changed, but its matrix has.
  • The change-of-basis formula needs an invertible matrix. Theorem 4.1 uses \(P^{-1}\). For a matrix \(P\) without an inverse, \(P^{-1}AP\) is undefined.
  • Exact and floating-point inverses differ. Computing \(P^{-1}\) in floating point introduces rounding errors in general. Lab 1 uses exact fractions for the identity and uses floats only for the separate tolerance check.

6Misconceptions

  1. “A matrix is the map itself, so changing the basis changes the map.”

    Changing the basis changes the matrix, not the map. Example 4.3 gives the matrix \(\begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}\) of \(\mathcal{L}(x, y) = (x + y, x - y)\) in the standard basis, and Example 2.6 gives \(\begin{pmatrix} 0 & 2 \\ 1 & 0 \end{pmatrix}\) for the same \(\mathcal{L}\) in the basis \((1, 0), (1, 1)\). Theorem 4.1 shows these are related by \(P^{-1}AP\).

  2. “The matrix of a composition is the product in either order.”

    Proposition 3.1 gives \([S \circ \mathcal{L}] = [S][\mathcal{L}]\), with \(\mathcal{L}\) applied first. Take \(A = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}\) and \(N = \begin{pmatrix} 1 & 0 \\ 1 & 1 \end{pmatrix}\). The product \(AN = \begin{pmatrix} 2 & 1 \\ 1 & 1 \end{pmatrix}\) differs from \(NA = \begin{pmatrix} 1 & 1 \\ 1 & 2 \end{pmatrix}\), so the order of the factors changes the matrix.

  3. “A vector has the same coordinates in every basis.”

    In the basis \((1, 0), (1, 1)\), the vector \((1, 1)\) is the second basis vector, so its coordinate vector is \((0, 1)\), not \((1, 1)\). Coordinates are defined only relative to a named basis (Definition 2.1).

Mechanics

M1 · The standard matrix of a map

Let \(\mathcal{L}(x, y) = (2x - y, x)\). Find the matrix of \(\mathcal{L}\) in the standard basis of \(\R^2\), using Definition 2.3 with \(B = C = (e_1, e_2)\).

Solution

The first column is \([\mathcal{L} e_1]\). Since \(\mathcal{L}(1, 0) = (2, 1)\), the first column is \((2, 1)\). Since \(\mathcal{L}(0, 1) = (-1, 0)\), the second column is \((-1, 0)\). The matrix is \(\begin{pmatrix} 2 & -1 \\ 1 & 0 \end{pmatrix}\). Its product with \((x, y)\) gives \((2x - y, x)\), which confirms it.

M2 · A coordinate vector

Let \(B = ((1, 0), (1, 1))\) in \(\R^2\). Find \([(3, 1)]_B\).

Solution

Solve \(a(1, 0) + b(1, 1) = (3, 1)\). The second coordinate gives \(b = 1\), and the first gives \(a + b = 3\), so \(a = 2\). The coordinate vector is \((2, 1)\). Check: \(2(1, 0) + 1(1, 1) = (3, 1)\).

M3 · Kernel and image of a projection

Let \(\mathcal{L}(x, y) = (x, 0)\) from \(\R^2\) to \(\R^2\). Find \(\ker \mathcal{L}\) and \(\operatorname{Im} \mathcal{L}\), and check that each is a subspace by Proposition 1.4.

Solution

\(\mathcal{L}(x, y) = \mathbf{0}\) exactly when \(x = 0\), so \(\ker \mathcal{L} = \{(0, y) : y \in \R\}\), the second coordinate axis. The image is \(\{(x, 0) : x \in \R\}\), the first coordinate axis. Each is a subspace: each is the span of one vector, and Proposition 2.2 of Lesson 1 gives that a span is a subspace. Each has dimension 1, since each is spanned by one non-zero vector, and a single non-zero vector is independent: \(a v = \mathbf{0}\) with \(v \ne \mathbf{0}\) forces \(a = 0\).

Proof

P1 · Injective maps keep independence

Let \(\mathcal{L} : V \to W\) be linear with \(\ker \mathcal{L} = \{\mathbf{0}\}\), and let \(v_1, \dots, v_k\) be linearly independent in \(V\). Prove that \(\mathcal{L}v_1, \dots, \mathcal{L}v_k\) is linearly independent in \(W\).

Solution

Suppose \(\sum_j c_j\, \mathcal{L}v_j = \mathbf{0}\). By Lemma 1.2 and induction on the number of terms, \(\sum_j c_j\, \mathcal{L}v_j = \mathcal{L}(\sum_j c_j v_j)\), so \(\sum_j c_j v_j \in \ker \mathcal{L} = \{\mathbf{0}\}\). Thus \(\sum_j c_j v_j = \mathbf{0}\), and independence of the \(v_j\) gives \(c_j = 0\) for every \(j\). So the images are independent.

P2 · Recovering the matrix from the change of basis

Let \(A\) be \(n \times n\), let \(P\) be invertible, and let \(\widetilde{A} = P^{-1} A P\). Prove that \(A = P \widetilde{A} P^{-1}\), using only the definition of the inverse and associativity of the product.

Solution

Compute \(P \widetilde{A} P^{-1} = P(P^{-1} A P)P^{-1}\). By associativity this is \((P P^{-1}) A (P P^{-1})\). Since \(P P^{-1} = I\), the expression is \(I A I = A\), because \(I\) is the identity for the product. This is Corollary 4.2.

P3 · Two matrices with the same action are equal

Prove Remark 2.5: if \(M\) and \(N\) are \(m \times n\) matrices with \(Mx = Nx\) for every \(x \in \R^n\), then \(M = N\).

Solution

Let \(j\) be a column index. Taking \(x = e_j\), the product \(Me_j\) is the \(j\)-th column of \(M\), because the \(i\)-th entry of \(Me_j\) is \(\sum_k M_{ik} (e_j)_k = M_{ij}\). Likewise \(Ne_j\) is the \(j\)-th column of \(N\). The hypothesis gives \(Me_j = Ne_j\), so the two matrices have equal \(j\)-th columns for every \(j\), and therefore \(M = N\).

Empirical

E1 · What the 50 of 50 counts establish (Lab 1)

A reader says that the printed line "coordinates of A p_j equal P^-1 A P in 50 of 50 pairs" proves the change-of-basis formula for every \(3 \times 3\) matrix. Say what is correct in that claim, what is not, and which result proves the general statement.

Solution

The printed line shows that the computation agrees with \(P^{-1}AP\) on the 50 pairs the seeded generator produces. That is an observation about those pairs. It does not prove the formula for every matrix, because 50 pairs are a finite set of the matrices of that size. The general statement is Theorem 4.1, whose proof covers every invertible \(P\) and every \(A\). The lab is a check that the implemented computation matches the theorem on the listed inputs.

E2 · Example 4.3 by hand

Verify the computation of Example 4.3 without using the lab: multiply \(A\) by \(P\), then multiply \(P^{-1}\) by the result, and compare with the matrix of Example 2.6.

Solution

\(AP\) has first row \((1 \cdot 1 + 1 \cdot 0,\ 1 \cdot 1 + 1 \cdot 1) = (1, 2)\) and second row \((1 \cdot 1 + (-1) \cdot 0,\ 1 \cdot 1 + (-1) \cdot 1) = (1, 0)\). Then \(P^{-1}(AP)\) has first row \((1 \cdot 1 + (-1) \cdot 1,\ 1 \cdot 2 + (-1) \cdot 0) = (0, 2)\) and second row \((0 \cdot 1 + 1 \cdot 1,\ 0 \cdot 2 + 1 \cdot 0) = (1, 0)\). The result is \(\begin{pmatrix} 0 & 2 \\ 1 & 0 \end{pmatrix}\), which is the matrix of Example 2.6.

E3 · The rejected draws (Lab 1)

Lab 1 prints the number of singular draws of \(P\) that were rejected. Explain why that number does not change the 50 of 50 counts.

Solution

A singular \(P\) has no inverse, so the formula \(P^{-1}AP\) is undefined for it. The lab rejects each singular draw and draws again until it has an invertible \(P\), and every counted pair uses an invertible \(P\). The rejections change which matrices the generator produces, but every counted pair satisfies the checks. The count of rejections is a fact about the run, and the lab prints it so that the reader can see the number.

Research

R1 · Composition when the middle bases differ

Proposition 3.1 uses the same basis \(C\) of \(W\) as the output of \(\mathcal{L}\) and the input of \(S\). Suppose instead that \(S\) is written in a basis \(C'\) of \(W\). Explain what extra matrix is needed to express \([S \circ \mathcal{L}]\), and why.

Solution

The output of \(\mathcal{L}\) is expressed in the basis \(C\), but the matrix of \(S\) takes inputs in the basis \(C'\). The coordinates \([\mathcal{L}b_j]_C\) must be converted to coordinates in \(C'\) before \([S]_{D \leftarrow C'}\) is applied. The conversion is the matrix \([\mathrm{id}]_{C' \leftarrow C}\), the matrix of the identity map from \(W\) with basis \(C\) to \(W\) with basis \(C'\), which exists by Definition 2.3. Then \([S \circ \mathcal{L}]_{D \leftarrow B} = [S]_{D \leftarrow C'}\, [\mathrm{id}]_{C' \leftarrow C}\, [\mathcal{L}]_{C \leftarrow B}\). The proof of Proposition 3.1 goes through unchanged with this conversion inserted.

R2 · Which matrices represent the same map?

Let \(\mathcal{L} : \R^n \to \R^n\) be \(x \mapsto Ax\). Describe the set of matrices that represent \(\mathcal{L}\) in some basis of \(\R^n\), using Theorem 4.1, and say which half of your description this lesson proves.

Solution

Theorem 4.1 shows that for every invertible \(P\) whose columns form a basis, \(P^{-1}AP\) is the matrix of \(\mathcal{L}\) in that basis. So every matrix of the form \(P^{-1}AP\) with \(P\) invertible whose columns form a basis occurs. The converse, that every basis of \(\R^n\) gives such a \(P\) with \(P\) invertible, is not proved in this lesson, and neither is the statement that every invertible \(P\) has columns forming a basis. The claim "the set is exactly \(\{P^{-1}AP\}\)" therefore depends on these unproved facts, and this lesson does not establish it.

R3 · Differentiation as a matrix

Let \(V\) be the set of real polynomials of degree at most 3, identified with coordinate vectors \((c_0, c_1, c_2, c_3)\) in the basis \(1, x, x^2, x^3\). Assuming the sum and scalar rules and the power rule for derivatives, which this lesson takes as given and does not prove, show that differentiation \(D\) is linear, write its matrix in this basis, and state what \(D\) does to a coordinate vector.

Solution

Assuming the sum and scalar rule \((ap + bq)' = a p' + b q'\), \(D\) is linear. Assuming the power rule \((x^k)' = k x^{k-1}\), its values on the basis are \(D(1) = 0\), \(D(x) = 1\), \(D(x^2) = 2x\) and \(D(x^3) = 3x^2\). Their coordinate vectors are \((0, 0, 0, 0)\), \((1, 0, 0, 0)\), \((0, 2, 0, 0)\) and \((0, 0, 3, 0)\). So the matrix is \(\begin{pmatrix} 0 & 1 & 0 & 0 \\ 0 & 0 & 2 & 0 \\ 0 & 0 & 0 & 3 \\ 0 & 0 & 0 & 0 \end{pmatrix}\). Applied to \((c_0, c_1, c_2, c_3)\), it returns \((c_1, 2c_2, 3c_3, 0)\), the coordinates of \(c_1 + 2c_2 x + 3c_3 x^2\).

  1. Which map \(\R^2 \to \R^2\) is linear?

    Options

  2. For \(\mathcal{L}(x, y) = (2x - y, x)\), what is the entry in row 2, column 1 of its standard matrix?

    The first column is \(\mathcal{L}(1, 0) = (2, 1)\), so its second entry is 1 (Problem M1).

  3. Which matrix represents \(S \circ \mathcal{L}\), where \(\mathcal{L}\) is applied first?

    Options

    Proposition 3.1: the matrix of the composition is the product, with the matrix of the outer map on the left.

  4. If \(\widetilde{A} = P^{-1} A P\) with \(P\) invertible, which expression equals \(A\)?

    Options

    Corollary 4.2: multiply \(\widetilde{A} = P^{-1}AP\) on the left by \(P\) and on the right by \(P^{-1}\).

  5. For the basis \(B = ((1, 0), (1, 1))\), what is the first coordinate of \([(3, 1)]_B\)?

    Solving \(a(1, 0) + b(1, 1) = (3, 1)\) gives \(b = 1\) and \(a = 2\) (Problem M2).

  6. What is the kernel of \(\mathcal{L}(x, y) = (x, 0)\)?

    Options

    \(\mathcal{L}(x, y) = \mathbf{0}\) exactly when \(x = 0\), so the kernel is the set of vectors \((0, y)\) (Problem M3).

  7. What does the matrix of a linear map depend on?

    Options

    Definition 2.3: the matrix is built from coordinates in the chosen bases, so changing a basis changes the matrix (Misconception 1).

  8. For \(\mathcal{L}(x, y) = (x + y, x - y)\), what is the entry in row 1, column 2 of its standard matrix?

    The second column is \(\mathcal{L}(0, 1) = (1, -1)\), so its first entry is 1.

  9. What does the printed line "50 of 50 pairs" in Lab 1 establish?

    Options

    The lab checks the listed pairs (Problem E1). The general statement is proved in Theorem 4.1.

  10. If \(\mathcal{L}\) and \(S\) are linear, is \(S \circ \mathcal{L}\) linear?

    Options

    \(S(\mathcal{L}(au + bv)) = S(a\,\mathcal{L}u + b\,\mathcal{L}v) = a\,S(\mathcal{L}u) + b\,S(\mathcal{L}v)\), using linearity of \(\mathcal{L}\) and then of \(S\) (Lemma 1.2).
