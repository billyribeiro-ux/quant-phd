Covariance-matrix doctor

A risk team estimates the pairwise relations of several assets one pair at a time. The resulting matrix has ones on its diagonal (a unit diagonal, defined in the conventions), but it need not be positive semidefinite, and a covariance matrix must be. You will write the module that diagnoses such a matrix and repairs it two ways, prove the properties the repairs rest on, and report which repair is nearer the input and where the weight formula applies to each repaired matrix.

Rungs 1 and 2

Both labs repair one matrix of pairwise estimates with unit diagonal. The entries are SIMULATED: they are set by hand for these examples, and no file is read. The repair uses the eigendecomposition of a symmetric matrix, which is defined in Lesson 3 and used through the spectral theorem of Lesson 4. An eigenvalue is a number λ for which Av = λv has a nonzero solution v; the eigenvalues of a symmetric matrix are real. Clipping, which both labs use, sets each eigenvalue below zero to zero, rebuilds the matrix from its eigenvectors and rescales it to a unit diagonal; the conventions define it in full.

Lab 1 · Worked example: one matrix, repaired step by step

The off-diagonal entries are 0.8, −0.5 and 0.6, and the diagonal is 1. Stated before running: the smallest eigenvalue is negative, so the matrix is not positive semidefinite, and the verdict printed for it is False. After clipping the negative eigenvalue to 0 and rescaling, the diagonal is 1 to six decimals and the repaired matrix passes the check at tolerance 1e-9.

"""Rung 1 worked example: repair one pairwise-estimated matrix by eigenvalue clipping, step by step.

SIMULATED: the three off-diagonal entries are set by hand for this example. They are not estimated from data.
Standard library only. Every number printed is computed from unrounded values; printing rounds it for display.
"""

import math

Matrix = list[list[float]]


def jacobi_eigen(a: Matrix) -> tuple[list[float], Matrix]:
    """Eigenvalues and eigenvectors (as columns) of a symmetric matrix, by cyclic Jacobi rotations."""
    n = len(a)
    m = [row[:] for row in a]
    v = [[1.0 if i == j else 0.0 for j in range(n)] for i in range(n)]
    for _ in range(100):
        off = math.sqrt(sum(m[i][j] ** 2 for i in range(n) for j in range(n) if i != j))
        scale = math.sqrt(sum(m[i][j] ** 2 for i in range(n) for j in range(n)))
        if off <= 1e-15 * max(scale, 1e-300):
            break
        for p in range(n - 1):
            for q in range(p + 1, n):
                if m[p][q] == 0.0:
                    continue
                theta = (m[q][q] - m[p][p]) / (2.0 * m[p][q])
                t = (1.0 if theta >= 0 else -1.0) / (abs(theta) + math.sqrt(theta * theta + 1.0))
                c = 1.0 / math.sqrt(t * t + 1.0)
                s = t * c
                for k in range(n):
                    mkp, mkq = m[k][p], m[k][q]
                    m[k][p] = c * mkp - s * mkq
                    m[k][q] = s * mkp + c * mkq
                for k in range(n):
                    mpk, mqk = m[p][k], m[q][k]
                    m[p][k] = c * mpk - s * mqk
                    m[q][k] = s * mpk + c * mqk
                for k in range(n):
                    vkp, vkq = v[k][p], v[k][q]
                    v[k][p] = c * vkp - s * vkq
                    v[k][q] = s * vkp + c * vkq
    return [m[i][i] for i in range(n)], v


def main() -> None:
    # Step 1. The pairwise estimates form a symmetric matrix with unit diagonal. The entries are SIMULATED.
    corr = [[1.0, 0.8, -0.5], [0.8, 1.0, 0.6], [-0.5, 0.6, 1.0]]
    n = len(corr)
    # Step 2. Eigenvalues and orthonormal eigenvectors. The eigenvalues of a symmetric matrix are real.
    values, vectors = jacobi_eigen(corr)
    print("eigenvalues, sorted:", " ".join(f"{x:.6f}" for x in sorted(values)))
    # Step 3. The PSD check: every eigenvalue must be at least -tol. Here tol = 1e-10.
    smallest = min(values)
    print("smallest eigenvalue:", f"{smallest:.6f}", "| positive semidefinite at tol 1e-10:", smallest >= -1e-10)
    # Step 4. Clipping: each eigenvalue below the floor 0 becomes 0; the matrix is rebuilt from the same eigenvectors.
    clipped = [max(x, 0.0) for x in values]
    rebuilt = [[sum(vectors[i][k] * clipped[k] * vectors[j][k] for k in range(n)) for j in range(n)] for i in range(n)]
    print("rebuilt diagonal:", " ".join(f"{rebuilt[i][i]:.6f}" for i in range(n)))
    # Step 5. Rescaling: entry (i, j) is divided by sqrt(d_i d_j), where d is the diagonal of the rebuilt matrix.
    # The diagonal becomes 1, and D^(-1/2) X D^(-1/2) stays positive semidefinite.
    d = [rebuilt[i][i] for i in range(n)]
    repaired = [[rebuilt[i][j] / math.sqrt(d[i] * d[j]) for j in range(n)] for i in range(n)]
    for row in repaired:
        print("repaired row:", " ".join(f"{x:.6f}" for x in row))
    # Step 6. Checks on the repaired matrix: the largest deviation of its diagonal from 1, and its own PSD check.
    deviation = max(abs(repaired[i][i] - 1.0) for i in range(n))
    new_values, _ = jacobi_eigen(repaired)
    print("largest deviation of the diagonal from 1:", f"{deviation:.6f}")
    print("positive semidefinite at tol 1e-9 after repair:", min(new_values) >= -1e-9)

Rung 3 · Specification

Context
A risk team forms a matrix of pairwise estimates for its assets. The matrix has a unit diagonal and may fail to be positive semidefinite; Lab 1 shows one such matrix. A matrix that fails the test cannot be the covariance matrix of any set of returns. You write the module that tests the matrix, repairs it by two methods, measures how far each repair moves the input, and computes the weights that the closed form gives to the assets, saying where that form does not apply. The module must match the reference numbers of one illustrative matrix in Lab 3, and must pass the autograder on your own seeded instances.
Inputs
No data file. The autograder's instance comes from grader/instance.py, seeded by your workspace ID. For each seed it holds the number of assets k (3, 4 or 5), k volatilities, a pairwise matrix that is not positive semidefinite by a margin of 0.02, a positive definite matrix with unit diagonal, two sets of planted eigenvalues, and the orthonormal eigenvectors they are built on. All of it is SIMULATED. The report uses the four-by-four matrix and the volatilities of Lab 3, which are set by hand for that run and are not estimated from data.
Required outputs
In a repository of your own: covariance_doctor.py at its root, and a report/ folder beside it. The module has these functions: min_eigenvalue(matrix), the smallest eigenvalue of a symmetric matrix; is_psd(matrix, tol=1e-10), which is True when every eigenvalue is at least -tol; clip_repair(matrix, floor=0.0), which sets every eigenvalue below floor to floor, rebuilds the matrix from its eigenvectors and rescales it to unit diagonal; projection_repair(matrix, tol=1e-10, max_iter=500), an approximation of the matrix nearest to the input in the Frobenius distance (defined in the conventions below) that is symmetric, positive semidefinite and has unit diagonal; and comparison_weights(corr, vols), the weights of the closed form in the conventions. Start from the starter file, whose signatures are complete. For the report, commit three more files: report/run_report.py, which is Lab 3 with its repair and weight calls replaced by calls to your module and which prints the same lines; report/report.md, the report described in the brief with its appendix; and report/self_assessment.md, the summary that the form in the self-assessment section produces.
Constraints
Standard library only. The functions raise ValueError for the four conditions the conventions below name, in each function where that condition applies, and no test asserts an exception for any other input. No function prints or warns. A run in your browser stops after 120 seconds. The conventions are binding.
Grading mode
Both modes apply. The code is autograded by grader/test_project.py, which runs 138 tests with warnings as errors: the eigenvalues of planted matrices, the sign and tolerance of the positive semidefinite test, the unit diagonal and symmetry of both repairs, the nearness of the projection, the printed numbers of Lab 3's matrix, the closed-form weights, the named refusals, and the purity of the module. The same file runs in your browser and on your machine. It is not secret: its integrity comes from your seeded instances and from a second instance, which a fixed answer for the first would also have to match. The report and its proof appendix are graded by rubric, against the five criteria of the report rubric, each with four observable levels. You score it yourself with the form in the self-assessment section and calibrate that scoring on two annotated exemplars. The report meets the bar at level 3 or above on every criterion.

Conventions

  • Unit-diagonal matrix. A symmetric matrix whose diagonal entries are all 1. The repairs are specified for any symmetric matrix with a positive diagonal. Every instance of the autograder is unit-diagonal, by construction in grader/instance.py. The tests also use planted spectra and small hand-made matrices, some of which are not unit-diagonal, such as diag(3, −2, 5) for min_eigenvalue.
  • Positive semidefinite. A symmetric matrix is positive semidefinite (PSD) when every eigenvalue is at least zero; Lesson 5 gives the definition and its equivalent forms. The PSD verdict of this specification is the test of is_psd: the smallest eigenvalue is at least -tol. The autograder accepts a repaired matrix as PSD when its smallest eigenvalue is at least -1e-9 for clipping and at least -1e-8 for the projection.
  • Frobenius distance. For matrices A and B of the same size, the square root of the sum of the squared differences of their entries, written \(\lVert A-B\rVert_F\). A repair is nearer the input when this distance is smaller. The Frobenius-nearest repair is the PSD unit-diagonal matrix with the smallest distance from the input.
  • Clipping. Write the eigendecomposition of the input as \(A = V\Lambda V^{\top}\), with V orthogonal. Clipping sets \(\Lambda_{ii}\) to \(\max(\Lambda_{ii}, f)\) for the floor \(f\), gives \(X = V\Lambda_f V^{\top}\), and then rescales to \(Y = D^{-1/2} X D^{-1/2}\) with \(D\) the diagonal of \(X\). Clipping followed by rescaling is a valid repair; Lab 3 shows that it is not the nearest one on its input. For an input with a negative eigenvalue and floor 0, the clipped matrix is singular, so the weights formula does not apply to it (A4, under its stated hypothesis).
  • Weights. With \(D = \diag(v_1,\dots,v_k)\) for the volatilities \(v_i > 0\) and a symmetric unit-diagonal matrix \(C\), let \(\Sigma = DCD\). Where \(\Sigma\) is invertible and \(\mathbf{1}^{\top}\Sigma^{-1}\mathbf{1} \ne 0\), the weights are \(w = \Sigma^{-1}\mathbf{1} / (\mathbf{1}^{\top}\Sigma^{-1}\mathbf{1})\). They sum to 1, and a weight may be negative. The formula does not require \(C\) to be positive semidefinite. Where \(\Sigma\) is singular the formula gives no weights, and the function's behaviour there is not specified: no test asserts a value or an exception for that case.
  • The four named ValueError conditions. (1) A matrix that is not square: a row has a number of entries other than the number of rows. (2) A matrix that is not symmetric beyond 1e-9: some pair of entries \(m_{ij}\) and \(m_{ji}\) differ by more than 1e-9. (3) A volatility that is not strictly greater than zero, in comparison_weights. (4) A volatility list whose length differs from the number of rows of the correlation matrix. No other input is named, and no test asserts an exception for one.
  • Precision. Results are floats. The tests compare them with the tolerances the conventions and the test file state, and a result that is correct to the tolerance passes.

"""Rung 3 reference numbers: the repairs, their distances from the input, and the determinant and weights of the input.

SIMULATED: the four-by-four matrix and the volatilities are set by hand for this run. They are not estimated from data.
Standard library only. Copy this file into report/run_report.py, delete the six functions jacobi_eigen, psd_projection,
min_eigenvalue, clip_repair, projection_repair and comparison_weights, and import the four names min_eigenvalue,
clip_repair, projection_repair and comparison_weights from your covariance_doctor module. frobenius and determinant
stay. Your module must print the same lines.
"""

import math

Matrix = list[list[float]]


def jacobi_eigen(a: Matrix) -> tuple[list[float], Matrix]:
    """Eigenvalues and eigenvectors (as columns) of a symmetric matrix, by cyclic Jacobi rotations."""
    n = len(a)
    m = [row[:] for row in a]
    v = [[1.0 if i == j else 0.0 for j in range(n)] for i in range(n)]
    for _ in range(100):
        off = math.sqrt(sum(m[i][j] ** 2 for i in range(n) for j in range(n) if i != j))
        scale = math.sqrt(sum(m[i][j] ** 2 for i in range(n) for j in range(n)))
        if off <= 1e-15 * max(scale, 1e-300):
            break
        for p in range(n - 1):
            for q in range(p + 1, n):
                if m[p][q] == 0.0:
                    continue
                theta = (m[q][q] - m[p][p]) / (2.0 * m[p][q])
                t = (1.0 if theta >= 0 else -1.0) / (abs(theta) + math.sqrt(theta * theta + 1.0))
                c = 1.0 / math.sqrt(t * t + 1.0)
                s = t * c
                for k in range(n):
                    mkp, mkq = m[k][p], m[k][q]
                    m[k][p] = c * mkp - s * mkq
                    m[k][q] = s * mkp + c * mkq
                for k in range(n):
                    mpk, mqk = m[p][k], m[q][k]
                    m[p][k] = c * mpk - s * mqk
                    m[q][k] = s * mpk + c * mqk
                for k in range(n):
                    vkp, vkq = v[k][p], v[k][q]
                    v[k][p] = c * vkp - s * vkq
                    v[k][q] = s * vkp + c * vkq
    return [m[i][i] for i in range(n)], v


def psd_projection(a: Matrix) -> Matrix:
    """The nearest positive semidefinite matrix in the Frobenius norm: negative eigenvalues set to 0, then rebuilt."""
    n = len(a)
    values, vectors = jacobi_eigen(a)
    clipped = [max(x, 0.0) for x in values]
    return [[sum(vectors[i][k] * clipped[k] * vectors[j][k] for k in range(n)) for j in range(n)] for i in range(n)]


def min_eigenvalue(a: Matrix) -> float:
    """The smallest eigenvalue of a symmetric matrix."""
    values, _ = jacobi_eigen(a)
    return min(values)


def clip_repair(a: Matrix) -> Matrix:
    """Eigenvalue clipping at 0, then rescaling to unit diagonal: D^(-1/2) X D^(-1/2) with D the diagonal of X."""
    n = len(a)
    values, vectors = jacobi_eigen(a)
    clipped = [max(x, 0.0) for x in values]
    x_matrix = [[sum(vectors[i][k] * clipped[k] * vectors[j][k] for k in range(n)) for j in range(n)] for i in range(n)]
    d = [x_matrix[i][i] for i in range(n)]
    return [[x_matrix[i][j] / math.sqrt(d[i] * d[j]) for j in range(n)] for i in range(n)]


def projection_repair(a: Matrix, tol: float = 1e-10, max_iter: int = 500) -> Matrix:
    """Dykstra's alternating projections between the positive semidefinite and the unit-diagonal matrices."""
    n = len(a)
    x = [row[:] for row in a]
    corr_s = [[0.0] * n for _ in range(n)]
    corr_u = [[0.0] * n for _ in range(n)]
    for _ in range(max_iter):
        y = psd_projection([[x[i][j] + corr_s[i][j] for j in range(n)] for i in range(n)])
        corr_s = [[x[i][j] + corr_s[i][j] - y[i][j] for j in range(n)] for i in range(n)]
        new_x = [[y[i][j] + corr_u[i][j] for j in range(n)] for i in range(n)]
        for i in range(n):
            new_x[i][i] = 1.0
        corr_u = [[y[i][j] + corr_u[i][j] - new_x[i][j] for j in range(n)] for i in range(n)]
        gap = math.sqrt(sum((new_x[i][j] - y[i][j]) ** 2 for i in range(n) for j in range(n)))
        step = math.sqrt(sum((new_x[i][j] - x[i][j]) ** 2 for i in range(n) for j in range(n)))
        x = new_x
        if gap <= tol and step <= tol:
            break
    return x


def comparison_weights(corr: Matrix, vols: list[float]) -> list[float]:
    """Weights proportional to Sigma^(-1) 1, with Sigma = D C D and D = diag(vols), normalised to sum to 1."""
    n = len(corr)
    sigma = [[vols[i] * corr[i][j] * vols[j] for j in range(n)] for i in range(n)]
    aug = [[*sigma[i], 1.0] for i in range(n)]
    for col in range(n):
        pivot = max(range(col, n), key=lambda r: abs(aug[r][col]))
        aug[col], aug[pivot] = aug[pivot], aug[col]
        for r in range(n):
            if r != col:
                factor = aug[r][col] / aug[col][col]
                aug[r] = [p - factor * q for p, q in zip(aug[r], aug[col], strict=True)]
    solution = [aug[i][n] / aug[i][i] for i in range(n)]
    total = sum(solution)
    return [x / total for x in solution]


def determinant(a: Matrix) -> float:
    """The determinant by Gaussian elimination with partial pivoting: the pivots' product, sign-flipped per swap."""
    n = len(a)
    m = [row[:] for row in a]
    det = 1.0
    for col in range(n):
        pivot = max(range(col, n), key=lambda r: abs(m[r][col]))
        if m[pivot][col] == 0.0:
            return 0.0
        if pivot != col:
            m[col], m[pivot] = m[pivot], m[col]
            det = -det
        det *= m[col][col]
        for r in range(col + 1, n):
            factor = m[r][col] / m[col][col]
            m[r] = [p - factor * q for p, q in zip(m[r], m[col], strict=True)]
    return det


def frobenius(a: Matrix, b: Matrix) -> float:
    """The Frobenius distance: the square root of the sum of squared entry differences."""
    n = len(a)
    return math.sqrt(sum((a[i][j] - b[i][j]) ** 2 for i in range(n) for j in range(n)))

Appendix A · Proofs

A1. Let \(A\) be a real symmetric matrix and \(f \ge 0\). The spectral theorem gives \(A = V\Lambda V^{\top}\) with V orthogonal and \(\Lambda\) diagonal and real. Let \(\Lambda_f = \diag(\max(\Lambda_{ii}, f))\) and \(X = V\Lambda_f V^{\top}\). X is symmetric. For any vector z, \(z^{\top}Xz = \sum_i \max(\Lambda_{ii}, f)\,(V^{\top}z)_i^2 \ge 0\), since each \(\max(\Lambda_{ii}, f) \ge f \ge 0\). So X is PSD.

A2. Let X be symmetric and PSD, with \(d_i = X_{ii} > 0\) for every i, D = diag(d), and \(Y = D^{-1/2}XD^{-1/2}\). Then \(Y_{ii} = X_{ii}/(\sqrt{d_i})^2 = 1\). For any z, \(z^{\top}Yz = w^{\top}Xw \ge 0\) with \(w = D^{-1/2}z\), so Y is PSD. The positivity of \(d_i\) is needed for the division; it fails only when row i of X is zero.

A3. Let C have unit diagonal and off-diagonal entries \(\rho\), with \(|\rho| < 1\), and let the volatilities be \(a, b > 0\). Then \(\Sigma\) has diagonal entries \(a^2\) and \(b^2\) and off-diagonal entries \(\rho ab\), and \(\det\Sigma = a^2b^2(1-\rho^2) > 0\), so \(\Sigma\) is invertible. Its inverse has diagonal entries \(b^2/\det\Sigma\) and \(a^2/\det\Sigma\) and off-diagonal entries \(-\rho ab/\det\Sigma\), so \(\Sigma^{-1}\mathbf{1} = (\det\Sigma)^{-1}(b(b-\rho a),\, a(a-\rho b))\). Normalising, the \(\det\Sigma\) cancels, and the sum of the two components is \(a^2+b^2-2\rho ab\), which is positive because \(a^2+b^2-2\rho ab = (a-b)^2 + 2ab(1-\rho) > 0\). For \(c > 0\), replacing \((a, b)\) by \((ca, cb)\) multiplies every component and the sum by \(c^2\), so the normalised weights do not change. A4 Let \(C\) be symmetric with a negative eigenvalue \(\lambda_i\), with unit eigenvector \(v_i\), and let \(X = V\Lambda_0V^{\top}\) be the clipped matrix at floor 0, where \(\Lambda_0 = \diag(\max(\Lambda_{jj}, 0))\). Assume every diagonal entry of \(X\) is positive, which the rescaling needs. Then \(Xv_i = V\Lambda_0e_i = 0\), so \(X\) is singular. With \(D_X = \diag(X)\) and \(Y = D_X^{-1/2}XD_X^{-1/2}\), the vector \(z = D_X^{1/2}v_i\) satisfies \(Yz = D_X^{-1/2}Xv_i = 0\), so \(Y\) is singular. For \(v > 0\), \(D_v = \diag(v)\) and \(\Sigma = D_vYD_v\), the vector \(D_v^{-1}z\) satisfies \(\Sigma D_v^{-1}z = D_vYz = 0\), so \(\Sigma\) is singular and the weights formula gives no weights.

  • Meets C1 level 4: A1 and A2 are complete, and each hypothesis is named at the step that uses it.
  • Meets C2 level 4: A3 states \(|\rho| < 1\) and \(a, b > 0\), and proves the scaling statement.
