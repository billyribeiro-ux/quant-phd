A proof is a finite chain of statements, each justified by a definition or an earlier result. Some of the unit's formulas are conditional, for example the growing-perpetuity formula, which needs \(r > g\) (Lesson 7): if the inputs satisfy a condition, the output has a property. Two techniques prove such conditional claims. One starts from the hypothesis and reaches the conclusion. The other assumes the conclusion is false and reaches a false statement. This lesson defines both, proves the parity facts they need, and proves that no rational number has square 2. The lab runs finite checks and reads each one as evidence about its range.

1Implications and the direct proof

Definition 1.1 (implication)

For statements \(P\) and \(Q\), the implication \(P \Rightarrow Q\) is false exactly when \(P\) is true and \(Q\) is false. In every other case it is true, including when \(P\) is false.

Definition 1.2 (direct proof)

To prove a universal claim \(\forall x\, (P(x) \Rightarrow Q(x))\), take an arbitrary \(x\) for which \(P(x)\) holds, and derive \(Q(x)\) through a chain of statements, each one a definition, an earlier result, or a logical rule. A direct proof is such an argument. The variable \(x\) must be arbitrary: the argument uses \(P(x)\), the definitions and earlier results, and it never fixes a particular value of \(x\).

Definition 1.3 (even, odd, divisibility)

An integer \(n\) is even when \(n = 2k\) for some integer \(k\), and odd when \(n = 2k + 1\) for some integer \(k\). For integers \(d\) and \(n\), \(d\) divides \(n\) when \(n = dk\) for some integer \(k\). Then \(n\) is divisible by 4 when 4 divides \(n\).

Fact 1.4 (every integer is even or odd)

For every integer \(n\), there is an integer \(k\) with \(n = 2k\) or \(n = 2k + 1\). This is a basic property of the integers, and the unit takes it as given. It is not proved here.

Theorem 1.5 (a direct proof about even integers)

Let \(a\) and \(b\) be integers. If \(a\) and \(b\) are both even, then \(a + b\) is even and \(a b\) is divisible by 4.

Proof

Take \(a\) and \(b\) both even. By Definition 1.3 there are integers \(m\) and \(n\) with \(a = 2m\) and \(b = 2n\). Then \(a + b = 2m + 2n = 2(m + n)\), and \(m + n\) is an integer, so \(a + b\) is even. Also \(a b = (2m)(2n) = 4mn\), and \(mn\) is an integer, so 4 divides \(ab\). The hypothesis is used to write \(a\) and \(b\) in the form \(2m\) and \(2n\), and no particular values are used, so the argument is a direct proof in the sense of Definition 1.2. \(\blacksquare\)

Theorem 1.5 is a universal claim over pairs of integers. The proof names its witnesses, \(m\) and \(n\), from the hypothesis and then checks the conclusion. Lab 1 repeats that construction on a finite range. The lab also enumerates the parity lemma of §2 over \(-2000\) to \(2000\) and searches for solutions of \(p^2 = 4q^2\) and \(p^2 = 2q^2\) over a bounded range. Each of these is a finite check, and none of them is a proof.

2Proof by contradiction

This unit reasons in classical logic, in which every statement is true or false and a statement that is not false is true. The proofs on this page are valid under the classical rules stated here, and the unit does not use other logics.

Definition 2.1 (contradiction)

To prove a statement \(S\) by contradiction, assume \(\neg S\) and derive a statement \(T\) together with its negation \(\neg T\), or any other statement known to be false. The assumption \(\neg S\) is then false, and \(S\) holds.

Lemma 2.2 (no integer is both even and odd)

There is no integer \(t\) with \(2t = 1\). Consequently no integer is both even and odd.

Proof

Suppose an integer \(t\) satisfies \(2t = 1\), and argue by contradiction. If \(t \ge 1\), then \(2t \ge 2 > 1\). If \(t \le 0\), then \(2t \le 0 < 1\). Either way \(2t \ne 1\), which contradicts the assumption. So no such \(t\) exists. For the consequence, suppose \(n = 2k = 2j + 1\) with integers \(k\) and \(j\). Then \(2(k - j) = 1\), with \(k - j\) an integer, which is impossible. \(\blacksquare\)

Lemma 2.3 (the parity of a square)

Let \(p\) be an integer. If \(p^2\) is even, then \(p\) is even.

Proof

Assume \(p^2\) is even, and suppose for contradiction that \(p\) is not even. By Fact 1.4 there is an integer \(k\) with \(p = 2k + 1\). Then \(p^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1\), so \(p^2 = 2j + 1\) for the integer \(j = 2k^2 + 2k\). But \(p^2\) is even, so \(p^2 = 2i\) for some integer \(i\). Then \(2i = 2j + 1\), so \(2(i - j) = 1\) with \(i - j\) an integer. Lemma 2.2 says this is impossible. The assumption that \(p\) is not even is therefore false, and \(p\) is even. \(\blacksquare\)

Definition 2.4 (lowest terms)

Integers \(p\) and \(q\) are coprime when the only positive integer that divides both is 1. Writing a fraction \(r = p/q\) with \(q \ge 1\) in lowest terms means choosing \(p\) and \(q\) coprime. Every rational number has such a representation, by dividing out a common factor. This is a basic fact of integer arithmetic, and the unit takes it as given.

Theorem 2.5 (no coprime solution of \(p^2 = 2q^2\))

There are no integers \(p\) and \(q\) with \(q \ge 1\), \(p\) and \(q\) coprime, and \(p^2 = 2q^2\).

Proof

Suppose such integers exist, and argue by contradiction. Since \(p^2 = 2q^2\) is even, Lemma 2.3 gives \(p = 2m\) for an integer \(m\). Substituting, \(4m^2 = 2q^2\), so \(q^2 = 2m^2\). Now \(q^2\) is even, so Lemma 2.3 gives \(q = 2n\) for an integer \(n\). Then 2 divides both \(p = 2m\) and \(q = 2n\). Since 2 is a positive integer other than 1, this contradicts the coprimality of \(p\) and \(q\). So no such integers exist. \(\blacksquare\)

Corollary 2.6 (no rational number has square 2)

There is no rational number \(r\) with \(r^2 = 2\).

Proof

Suppose \(r\) is rational with \(r^2 = 2\). By Definition 2.4 write \(r = p/q\) with \(q \ge 1\) and \(p\), \(q\) coprime. Then \(p^2 / q^2 = 2\), so \(p^2 = 2q^2\). This contradicts Theorem 2.5. \(\blacksquare\)

Remark 2.7 (what the contradiction uses)

The proof of Theorem 2.5 uses the number 2 in an essential way: the same argument needs \(p^2 = 2q^2\) to force \(p\) and \(q\) to be even. Lab 1 shows that the coprimality condition by itself does not produce a contradiction for \(p^2 = 4q^2\), where coprime solutions exist.

Lab 1 · A direct-proof claim on a finite range, and a search for counterexamples

Predicted before running. The even integers from \(-60\) to \(60\) are 61 in number, \(-60, -58, \dots, 60\), so there are \(61^2 = 3721\) ordered pairs of even integers. Theorem 1.5 says the conclusion holds for every one, and the witnesses \(m = a/2\) and \(n = b/2\) satisfy \(a + b = 2(m + n)\) and \(ab = 4mn\) for every one. The claim "if \(a\) is even then \(a^2 + 1\) is even" is false: at \(a = 0\), \(a^2 + 1 = 1\) is odd, so \(a = 0\) is a counterexample, and the search over 0 to 60 returns 0. For the parity lemma, the integers from \(-2000\) to \(2000\) include 2001 even values, and the values with \(p^2\) even are exactly the even values: by Lemma 2.3 every \(p\) with \(p^2\) even is even, and by Problem P3 every even \(p\) has \(p^2\) even. For the squares, \(p^2 = 2q^2\) has no coprime solution with \(q \ge 1\) by Theorem 2.5. Dividing any solution by \(\gcd(p, q)\) gives a coprime one, so there is no solution with \(q \ge 1\) at all. Also \(p^2 = 4q^2\) has solutions \(p = \pm 2q\), of which only \(q = 1\) gives coprime pairs.

"""M1 lab L02: a direct proof checked on a finite range, and a contradiction proof with a search.

Standard library only. No randomness and no network. Each claim is tested on a finite range,
which is evidence about that range. The proofs on the page are what establish the claims for
all integers. The searches below report counterexamples or solutions inside their range. They cannot
establish a claim over all integers, and the page reads the output that way.
"""

from __future__ import annotations

from math import gcd


def is_even(n: int) -> bool:
    """True when n = 2k for some integer k."""
    return n % 2 == 0


def direct_proof_cases(bound: int) -> tuple[int, int, int, int]:
    """Test the direct-proof claim for even a, b in -bound..bound.

    Claim: if a and b are even, then a + b is even and a * b is divisible by 4.
    The proof writes a = 2m and b = 2n, so a + b = 2(m + n) and a * b = 4mn. The code uses
    exactly those witnesses m = a // 2 and n = b // 2, and checks both identities for each pair.

    Returns (pairs tested, conclusion holds, identities hold, pairs where the conclusion fails).
    """
    evens = [n for n in range(-bound, bound + 1) if is_even(n)]
    tested = conclusion = identities = 0
    for a in evens:
        for b in evens:
            m, n = a // 2, b // 2
            tested += 1
            if is_even(a + b) and (a * b) % 4 == 0:
                conclusion += 1
            if a + b == 2 * (m + n) and a * b == 4 * m * n:
                identities += 1
    return tested, conclusion, identities, tested - conclusion


def refute_by_search(bound: int) -> int:
    """The least even a in 0..bound for which a * a + 1 is even, or -1 if none exists in range.

    The claim 'if a is even, then a * a + 1 is even' is false. A search finds a counterexample;
    it cannot show a claim is true.
    """
    for a in range(0, bound + 1, 2):
        if not is_even(a * a + 1):
            return a
    return -1


def parity_lemma(bound: int) -> tuple[int, int, bool]:
    """Lemma used in the contradiction proof: for integers p, if p * p is even then p is even.

    Returns (count of p in -bound..bound with p * p even, count with p even, the two sets are equal).
    """
    values = range(-bound, bound + 1)
    square_even = [p for p in values if is_even(p * p)]
    even = [p for p in values if is_even(p)]
    return len(square_even), len(even), square_even == even


def search_square_equation(c: int, q_max: int, p_max: int) -> tuple[int, int, int]:
    """Count integer solutions of p * p == c * q * q with 1 <= q <= q_max and |p| <= p_max.

    Returns (tested pairs, solutions, solutions with gcd(p, q) = 1).
    """
    tested = solutions = coprime = 0
    for q in range(1, q_max + 1):
        for p in range(-p_max, p_max + 1):
            tested += 1
            if p * p == c * q * q:
                solutions += 1
                if gcd(abs(p), q) == 1:
                    coprime += 1
    return tested, solutions, coprime


def main() -> None:
    tested, conclusion, identities, failed = direct_proof_cases(60)
    print(f"direct proof, a and b even in -60 to 60: pairs tested {tested}")
    print(f"a + b even and a * b divisible by 4: {conclusion} of {tested} pairs")
    print(f"witness identities a + b = 2(m + n) and a * b = 4mn: {identities} of {tested} pairs")
    print(f"pairs where the conclusion fails: {failed}")
    counterexample = refute_by_search(60)
    print(f"refutation of 'a even implies a*a + 1 even' over even a in 0 to 60: least counterexample {counterexample}")

    square_even, even, same = parity_lemma(2000)
    print(f"parity lemma, p in -2000 to 2000: p*p even for {square_even} values, p even for {even} values")
    print(f"the two sets of values are equal: {same}")

    tested, solutions, coprime = search_square_equation(2, 300, 500)
    print(f"search p*p == 2*q*q, 1 <= q <= 300, |p| <= 500: pairs tested {tested}")
    print(f"solutions found: {solutions}")
    tested, solutions, coprime = search_square_equation(4, 300, 500)
    print(f"search p*p == 4*q*q over the same range: solutions {solutions}, with gcd(p, q) = 1: {coprime}")

The direct-proof lines check the claim and the witness identities on every pair in the finite range. They agree with Theorem 1.5, which proves the claim for all integers, and they add no proof. The refutation line finds a counterexample, which is enough to refute a universal claim (Lesson 1, Remark 5.1). The square search finds no solution of \(p^2 = 2q^2\) in its range. That agrees with Theorem 2.5, but the search covers only \(q \le 300\) and \(|p| \le 500\), so it does not prove the theorem. The search for \(p^2 = 4q^2\) finds 500 solutions and 2 coprime ones. The lab prints the count only; the pairs \((\pm 2, 1)\) follow by hand from \(p = \pm 2q\) (Problem E3), which is the point of Remark 2.7. C Every count is a finite enumeration on the stated range.

3Where the canon breaks

These two techniques are not a complete toolkit. Four limits matter for what follows.

  • Contradiction gives no object. Theorem 2.5 proves that no coprime pair satisfies \(p^2 = 2q^2\). It does not say how close a rational number can come to \(\sqrt{2}\) in a given form, and it does not construct anything. A reader who needs an approximation must compute one separately.
  • Classical logic is a convention. Proof by contradiction relies on the rule that a statement that is not false is true. This unit adopts classical logic, as stated at the head of §2, and the proofs here depend on that choice.
  • A finite check is not a proof. Lab 1 checks Theorem 1.5 on 3721 pairs and finds no solution of \(p^2 = 2q^2\) in a bounded search. Each check is exact for its range and says nothing outside it. The proof, not the check, covers all integers.
  • A proof can use a hypothesis the reader does not see. Fact 1.4 is used in Lemma 2.3 without proof. A proof is complete relative to the facts it cites, and the unit states each such fact where it is used.

4Misconceptions

  1. “A proof by example proves a universal claim.”

    An example satisfies the claim at one point, and a universal claim needs every point. Theorem 1.5 begins with arbitrary integers \(a\) and \(b\), and no particular pair such as \(a = 2\), \(b = 4\) appears in its argument. A single counterexample refutes a universal claim, but an example that works does not prove one. Lab 1 finds 3721 satisfying pairs and proves nothing about pairs outside \(-60\) to \(60\).

  2. “To prove \(P \Rightarrow Q\), it is enough to prove \(Q \Rightarrow P\).”

    The converse of an implication is a different statement. Take \(P\) to be "\(a\) and \(b\) are both even" and \(Q\) to be "\(a + b\) is even". Theorem 1.5 proves \(P \Rightarrow Q\). The converse \(Q \Rightarrow P\) is false: \(a = 1\) and \(b = 1\) give \(a + b = 2\), which is even, while neither \(a\) nor \(b\) is even. Proving the converse would have settled nothing about the original claim.

  3. “A search that finds no counterexample proves the claim.”

    Lab 1 searches \(p^2 = 2q^2\) over \(q \le 300\) and \(|p| \le 500\), and finds no solution. Theorem 2.5 covers every coprime pair \((p, q)\) with \(q \ge 1\) that satisfies \(p^2 = 2q^2\), with no bound on its size, and its proof covers them all, whereas the search covers the listed range. A search with no hits has tested a finite list, and the number of untested cases is infinite. The search is consistent with the theorem and is not a substitute for it.

5Problem set

Every problem has a full worked solution. Attempt each one before opening it. Problems marked E use the output of Lab 1.

Mechanics

M1 · The sum of two odd integers

Give a direct proof that the sum of two odd integers is even.

Solution

Let \(a\) and \(b\) be odd. By Definition 1.3 write \(a = 2k + 1\) and \(b = 2m + 1\) with integers \(k\) and \(m\). Then \(a + b = 2k + 2m + 2 = 2(k + m + 1)\), and \(k + m + 1\) is an integer, so \(a + b\) is even. The argument starts from the hypothesis and uses no particular values, so it is a direct proof.

M2 · Refuting a claim by a single integer

Show that the claim "for every integer \(n\), \(n^2 \ge 2n\)" is false, by giving a counterexample.

Solution

Take \(n = 1\). Then \(n^2 = 1\) and \(2n = 2\), and \(1 \ge 2\) is false. By Lesson 1, Remark 5.1, a single member that fails a universal claim refutes it. The claim is therefore false on the integers. The smallest positive counterexample is 1, which is the answer to the numeric quiz item.

M3 · Parity of a square, by Lemma 2.3

Decide whether \(1001^2\) is even, using Lemma 2.3 and Fact 1.4.

Solution

By Fact 1.4, \(1001 = 2 \cdot 500 + 1\) is odd, so it is not even. If \(1001^2\) were even, Lemma 2.3 would make 1001 even, which it is not. So \(1001^2\) is odd. The arithmetic agrees: \(1001^2 = 1002001\), which is odd.

Proof

P1 · Odd plus even is odd

Give a direct proof that the sum of an odd integer and an even integer is odd.

Solution

Let \(a\) be odd and \(b\) be even. Write \(a = 2k + 1\) and \(b = 2m\). Then \(a + b = 2(k + m) + 1\), and \(k + m\) is an integer, so \(a + b\) has the form \(2j + 1\) and is odd by Definition 1.3.

P2 · No integer solves \(2k = 1\)

Prove by contradiction that there is no integer \(k\) with \(2k = 1\). Name the statement you derive as false.

Solution

Assume an integer \(k\) with \(2k = 1\). If \(k \ge 1\) then \(2k \ge 2\), which is greater than 1. If \(k \le 0\) then \(2k \le 0\), which is less than 1. So \(2k = 1\) is false in both cases, which contradicts the assumption. The statement derived as false is "\(2k = 1\)" itself, together with its negation "\(2k \ne 1\)". This is Lemma 2.2.

P3 · The forward direction of the parity of a square

Show that if \(p = 2k\) for an integer \(k\), then \(p^2\) is even. Then state which direction of Lemma 2.3 this is, and say what the other direction needs.

Solution

If \(p = 2k\) then \(p^2 = 4k^2 = 2(2k^2)\), and \(2k^2\) is an integer, so \(p^2\) is even. This is the easy direction, and it is a direct proof. The other direction, that an even square comes from an even integer, is Lemma 2.3, and it needs the contradiction argument with Lemma 2.2, because the hypothesis is about a square and the conclusion is about its root.

Empirical

E1 · Counting the pairs in Lab 1 (finite range)

Lab 1 prints 3721 pairs for the direct-proof claim. Explain the number from the range \(-60\) to \(60\) and confirm it against the output.

Solution

The even integers from \(-60\) to \(60\) step by 2 number \((60 - (-60))/2 + 1 = 61\). Ordered pairs of them number \(61 \times 61 = 3721\). The lab prints 3721 pairs, and it also prints 3721 of 3721 for the conclusion and for the witness identities. Both counts agree with Theorem 1.5 on this range, and that agreement is what the check tests.

E2 · Why 0 is the least counterexample (finite range)

Lab 1 prints 0 as the least counterexample to "if \(a\) is even then \(a^2 + 1\) is even". Verify this by hand, and say why the search starts at 0.

Solution

At \(a = 0\), which is even, \(a^2 + 1 = 1\), which is odd. So the claim fails at 0, and 0 is the least even integer in the search range, so it is the least counterexample. The search starts at 0 because 0 is the smallest non-negative even integer. A search that started at a larger even number would not find this counterexample.

E3 · The coprime solutions of \(p^2 = 4q^2\) (finite range)

Lab 1 prints 500 solutions of \(p^2 = 4q^2\) with \(1 \le q \le 300\) and \(|p| \le 500\), and 2 with \(\gcd(p, q) = 1\). List the 2 coprime pairs and explain why there are 500 solutions.

Solution

A solution satisfies \(p^2 = 4q^2\), so \(p = \pm 2q\). The bound \(|p| \le 500\) allows \(2q \le 500\), that is \(q \le 250\), and each such \(q\) gives two values of \(p\). That is \(250 \times 2 = 500\) solutions. For the coprime ones, \(\gcd(2q, q) = q\), so coprimality needs \(q = 1\), giving \((p, q) = (2, 1)\) and \((-2, 1)\). These are the 2 coprime pairs that the lab counts.

Research

R1 · Why a bounded search cannot prove Theorem 2.5

A colleague extends the search for \(p^2 = 2q^2\) to \(q \le 10^9\) and finds no solution. Explain why this still does not prove Theorem 2.5, and state what a proof must do that a search cannot.

Solution

The extended search covers \(q \le 10^9\), a finite set of pairs. Theorem 2.5 concerns every coprime pair with \(q \ge 1\), and infinitely many values of \(q\) lie beyond the bound, so the search leaves infinitely many cases untested. A proof must cover every candidate by an argument that works for an arbitrary one. Theorem 2.5 does this by showing that any coprime solution forces \(p\) and \(q\) to be even, which contradicts coprimality, for every candidate at once.

R2 · Odd plus even, proved two ways

Prove that the sum of an even integer and an odd integer is odd, once by a direct proof and once by contradiction. In the contradiction, name the false statement you derive.

Solution

Direct: let \(a = 2m\) be even and \(b = 2k + 1\) be odd. Then \(a + b = 2(m + k) + 1\), which is odd. Contradiction: assume \(a + b\) is even, say \(a + b = 2j\). Then \(b = 2j - a = 2(j - m)\), which is even. So \(b\) is both odd and even. By Lemma 2.2 that is impossible, and the false statement derived is "\(b\) is both odd and even". So \(a + b\) is not even, which is odd by Fact 1.4.

R3 · What is special about the number 2

The coprimality argument of Theorem 2.5 works for \(c = 2\). Explain why the same argument, with \(c = 4\) in place of 2, does not yield a contradiction, using Lab 1's output.

Solution

For \(c = 4\) the equation \(p^2 = 4q^2\) has coprime solutions, \((\pm 2, 1)\), and Lab 1 counts 2 of them. So coprimality alone cannot be contradicted for \(c = 4\). The argument for \(c = 2\) works because the parity step, Lemma 2.3, forces \(p\) to be even and then \(q\) to be even, and 2 divides both. For \(c = 4\), the equation holds with \(p = 2\) and \(q = 1\), where \(q\) is odd, so the second parity step fails.

7Retrieval quiz

Answer from memory, then check. Finishing the quiz adds this lesson's cards to your review deck.

  1. In a direct proof of \(\forall x\, (P(x) \Rightarrow Q(x))\), what do you assume at the start?

    Options

    Definition 1.2: the hypothesis is \(P(x)\), and \(x\) must stay arbitrary.

  2. When is \(P \Rightarrow Q\) false?

    Options

    Definition 1.1: the implication is false only when the hypothesis holds and the conclusion fails.

  3. What is the smallest positive integer \(n\) for which the claim \(n^2 \ge 2n\) fails?

    For \(n = 1\), \(n^2 = 1\) and \(2n = 2\), and \(1 \ge 2\) is false, so the claim fails at 1 (Problem M2).

  4. Is "if \(a + b\) is even then \(a\) and \(b\) are both even" true for all integers?

    Options

    The converse of an implication is a different statement. With \(a = b = 1\) the sum is 2, which is even, and neither number is even.

  5. How many even integers lie between \(-60\) and \(60\), inclusive?

    The evens are \(-60, -58, \dots, 60\), which is \((60 + 60)/2 + 1 = 61\) values.

  6. In a proof by contradiction of \(S\), what is assumed at the start?

    Options

    Definition 2.1: assume \(\neg S\), derive a contradiction, and conclude \(S\).

  7. Which fact does Lemma 2.3 use in its contradiction step?

    Options

    The proof assumes \(p\) is odd and \(p^2\) is even, and Lemma 2.2 rules out the resulting \(2(i - j) = 1\).

  8. Lab 1 finds no integer solution of \(p^2 = 2q^2\) with \(q\) up to 300 and \(|p| \le 500\). What does this establish?

    Options

    A search covers a finite list of cases. Theorem 2.5 covers every coprime pair \((p, q)\) with \(q \ge 1\) that satisfies \(p^2 = 2q^2\), with no bound on its size, so the proof is what establishes it.

  9. How many coprime pairs \((p, q)\) with \(1 \le q \le 300\) and \(|p| \le 500\) satisfy \(p^2 = 4q^2\)?

    Coprimality needs \(\gcd(2q, q) = q = 1\), so the pairs are \((2, 1)\) and \((-2, 1)\), two in all. Lab 1 prints 2.

  10. Why does the proof of Theorem 2.5 fail for \(p^2 = 4q^2\)?

    Options

    Remark 2.7: for \(c = 4\) the pair \((p, q) = (2, 1)\) is coprime and satisfies the equation, so there is no contradiction.
