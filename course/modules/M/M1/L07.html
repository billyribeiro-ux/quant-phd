Annuities, Perpetuities and Growing Perpetuities

  • Uses: present value, the discount factor, geometric series, proof by induction
  • Introduces: annuity, perpetuity, growing perpetuity
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study
  • Dlore
  • Xrefuted

A promise of level payments, or of payments that grow at a fixed rate, is worth a sum of discounted payments. Each of these sums is a geometric series, so each has a closed form that follows from Lesson 6. The closed forms are only valid under conditions: the rate must not be zero in one formula, and the growth rate must be below the discount rate in another. This lesson proves each formula, states its condition, and shows what happens outside it.

1Conventions and the annuity

Payments occur at the ends of periods \(t = 1, 2, 3, \ldots\). The rate \(r\) is the rate per period, and it is positive unless a result says otherwise. The discount factor is \(v = 1/(1 + r)\), so a payment \(C\) at time \(t\) has present value \(C v^t\) (Lesson 5). Every value in this lesson is in currency units (CU), valued at time 0, and the period is the unit that \(r\) is quoted for. A monthly payment needs a monthly rate.

Definition 1.1 (annuity)

An annuity of length \(n\) pays a fixed amount \(C\) at each of the times \(1, 2, \ldots, n\). Its present value is \[ \mathrm{PV}_n = \sum_{t=1}^{n} C v^{t}. \] An annuity due pays the same amount at times \(0, 1, \ldots, n-1\), so its present value is \(\sum_{t=0}^{n-1} C v^{t}\).

Theorem 1.2 (annuity closed form)

For \(r > 0\) and every integer \(n \ge 1\), \[ \mathrm{PV}_n = C\,\frac{1 - v^{n}}{r} = C\,\frac{1 - (1 + r)^{-n}}{r}. \] For \(r = 0\), \(\mathrm{PV}_n = nC\).

Proof

Let \(r = 0\). Then \(v = 1\), and each of the \(n\) terms equals \(C\), so \(\mathrm{PV}_n = nC\).

Let \(r > 0\). Then \(0 < v < 1\), so \(v \ne 1\). Factor \(v\) out of the sum and apply Theorem 2.2 of Lesson 6 with \(q = v\): \[ \mathrm{PV}_n = C\sum_{t=1}^{n} v^{t} = C v \sum_{k=0}^{n-1} v^{k} = C v\,\frac{1 - v^{n}}{1 - v}. \] Now \(1 - v = 1 - \frac{1}{1 + r} = \frac{r}{1 + r}\), and \(v / (1 - v) = \frac{1}{1 + r} \cdot \frac{1 + r}{r} = \frac{1}{r}\). Substituting gives \(\mathrm{PV}_n = C(1 - v^n)/r\).

Example 1.3 (three payments at ten per cent)

Take \(C = 100\), \(r = 1/10\) and \(n = 3\). Then \(v = 1/1.1\), and the closed form gives \(100(1 - 1/1.331)/0.1 = 248.6852\) to four decimals. Adding the three discounted payments directly gives \(100/1.1 + 100/1.21 + 100/1.331 = 248.6852\) to four decimals, which agrees.

Proposition 1.4 (annuity due)

For \(r > 0\) and every \(n \ge 1\), the annuity due of length \(n\) has present value \((1 + r)\,\mathrm{PV}_n\), which is \(C(1 - v^n)(1 + r)/r\).

Proof

The due annuity's terms are \(C v^{t}\) for \(t = 0, \ldots, n-1\). Reindex with \(s = t + 1\), so that \(v^{t} = v^{s-1} = (1 + r) v^{s}\), because \(v^{-1} = 1 + r\). The sum becomes \(\sum_{s=1}^{n} (1 + r) C v^{s} = (1 + r)\,\mathrm{PV}_n\). The closed form follows from Theorem 1.2.

Example 1.5 (the same payments, paid at the start)

With \(C = 100\), \(r = 1/10\) and \(n = 3\) as in Example 1.3, the due annuity is worth \(1.1 \times 248.6852 = 273.5537\) to four decimals. The difference of \(24.8685\) is the interest on the ordinary annuity's value for one period.

2The perpetuity

Consider a stream of payments with no last payment. Its value cannot be a finite sum, so this section defines the value through the present values of the first \(m\) payments (Definition 2.1), and proves that a constant stream of \(C\) at each period has the unique value \(C/r\).

Definition 2.1 (payment stream and its value)

Let a payment stream pay \(x_t\) at each time \(t \ge 1\), and let \(\mathrm{PV}_m = \sum_{t=1}^{m} x_t v^{t}\) be the present value of its first \(m\) payments. A number \(V\) is the value of the stream if, for every \(\varepsilon > 0\), there is an integer \(M\) such that \(|\mathrm{PV}_m - V| \le \varepsilon\) for every \(m \ge M\). A perpetuity is the stream with \(x_t = C\) for every \(t \ge 1\); for \(x_t = C\) the partial values are those of Definition 1.1.

Lemma 2.2 (Bernoulli's inequality for nonnegative rates)

For every real \(x \ge 0\) and every integer \(m \ge 0\), \((1 + x)^m \ge 1 + mx\).

Proof

Induction on \(m\), with \(n_0 = 0\) in Theorem 1.2 of Lesson 6 and \(P(m)\) the statement \((1 + x)^m \ge 1 + mx\). For \(m = 0\) both sides equal \(1\). Assume \((1 + x)^k \ge 1 + kx\) for some \(k \ge 0\). Multiply both sides by \(1 + x > 0\), which keeps the inequality: \[ (1 + x)^{k+1} \ge (1 + kx)(1 + x) = 1 + (k+1)x + kx^2 \ge 1 + (k+1)x. \] The last step uses \(kx^2 \ge 0\).

Proposition 2.3 (the remainder of the perpetuity)

For \(r > 0\) and every integer \(m \ge 0\), the perpetuity's first \(m\) payments are worth \(\mathrm{PV}_m = C(1 - v^m)/r\), and the gap to \(C/r\) is \[ \frac{C}{r} - \mathrm{PV}_m = \frac{C v^{m}}{r} \ge 0. \]

Proof

For \(m = 0\) the sum is empty and both sides are zero. For \(m \ge 1\), the formula for \(\mathrm{PV}_m\) is Theorem 1.2. Subtract it from \(C/r = C \cdot 1/r\): \(C/r - C(1 - v^m)/r = C v^m / r\). The gap is nonnegative because \(C > 0\) and \(v^m > 0\).

Theorem 2.4 (value of the perpetuity)

For \(C > 0\) and \(r > 0\), the number \(V = C/r\) is the value of the perpetuity in the sense of Definition 2.1, and it is the only such number.

Proof

\(C/r\) is a value. Let \(\varepsilon > 0\). By Proposition 2.3 and Lemma 2.2 (with \(x = r\)), \(v^m = 1/(1 + r)^m \le 1/(1 + mr)\). So the gap satisfies \(0 \le C/r - \mathrm{PV}_m \le C/(r(1 + mr))\). Choose an integer \(M \ge 0\) with \(1 + Mr \ge C/(r\varepsilon)\), which exists because \(r > 0\). For \(m \ge M\), \(1 + mr \ge 1 + Mr \ge C/(r\varepsilon)\), so the gap is at most \(\varepsilon\).

Uniqueness. Suppose \(V\) and \(V'\) both satisfy Definition 2.1. Fix \(\varepsilon > 0\) and take \(m\) at least both integers the definition gives for \(\varepsilon/2\). Then \(|V - V'| \le |V - \mathrm{PV}_m| + |\mathrm{PV}_m - V'| \le \varepsilon\). Since \(\varepsilon\) is arbitrary, \(V = V'\).

Example 2.5 (a remainder at five per cent)

Take \(C = 100\) and \(r = 0.05\), so \(C/r = 2000\). The first ten payments are worth \(100(1 - 1.05^{-10})/0.05 = 772.1735\). The gap is \(2000 \times 1.05^{-10} = 1227.8265\), which is \(C v^{10}/r\), as Proposition 2.3 says.

3The growing perpetuity

Definition 3.1 (growing perpetuity)

A growing perpetuity with first payment \(C > 0\) and growth rate \(g > -1\) pays \(C(1 + g)^{t-1}\) at each time \(t \ge 1\). Its partial values are \(\mathrm{PV}_n = \sum_{t=1}^{n} C(1 + g)^{t-1} v^{t}\), with \(v = 1/(1 + r)\) and \(r > 0\). Its value, when one exists, is the value of this payment stream in the sense of Definition 2.1.

Write \(q = (1 + g)/(1 + r)\). Because \(g > -1\), \(1 + g > 0\), so \(q > 0\). Because \(r > 0\), \(1 + r > 0\).

Proposition 3.2 (partial values of the growing perpetuity)

If \(g \ne r\), then for every integer \(n \ge 1\), \[ \mathrm{PV}_n = \frac{C}{r - g}\,\bigl(1 - q^{n}\bigr). \]

Proof

Each term satisfies \((1 + g)^{t-1} v^{t} = v \cdot (1 + g)^{t-1} v^{t-1} = v\, q^{t-1}\). So \(\mathrm{PV}_n = C v \sum_{k=0}^{n-1} q^{k}\). Since \(g \ne r\), \(q \ne 1\), and Theorem 2.2 of Lesson 6 gives \(\mathrm{PV}_n = C v (1 - q^n)/(1 - q)\). Next, \(1 - q = \frac{(1 + r) - (1 + g)}{1 + r} = \frac{r - g}{1 + r}\), so \(v/(1 - q) = \frac{1}{1 + r} \cdot \frac{1 + r}{r - g} = \frac{1}{r - g}\). Substituting gives the claim.

Theorem 3.3 (value of the growing perpetuity when r > g)

Let \(C > 0\), \(r > 0\) and \(-1 < g < r\). Then \(q \in (0, 1)\), and the growing perpetuity has value \(C/(r - g)\) in the sense of Definition 2.1, and no other.

Proof

Since \(g < r\), \(1 + g < 1 + r\), so \(q < 1\). Since \(g > -1\), \(q > 0\). Put \(d = 1/q - 1 = (r - g)/(1 + g) > 0\). Then \(q^m = (1 + d)^{-m} \le 1/(1 + md)\) by Lemma 2.2 with \(x = d\). By Proposition 3.2, the gap to \(C/(r - g)\) is \[ \frac{C}{r - g} - \mathrm{PV}_m = \frac{C}{r - g}\, q^{m} \le \frac{C}{(r - g)(1 + md)}. \] Given \(\varepsilon > 0\), choose \(M\) with \(1 + Md \ge C/((r - g)\varepsilon)\). For \(m \ge M\) the gap is at most \(\varepsilon\), so \(C/(r - g)\) is a value. Uniqueness follows exactly as in Theorem 2.4.

Theorem 3.4 (no finite value when g is at least r)

Let \(C > 0\), \(r > 0\) and \(g \ge r\). Then \(\mathrm{PV}_n \ge nC/(1 + r)\) for every \(n \ge 1\), so no number \(V\) satisfies Definition 2.1. The closed form \(C/(r - g)\) does not describe the growing perpetuity in this case.

Proof

Each term of the growing perpetuity is \(C(1 + g)^{t-1}/(1 + r)^{t} = \frac{C}{1 + r} q^{t-1}\), with \(q = (1 + g)/(1 + r) \ge 1\), because \(g \ge r\) gives \(1 + g \ge 1 + r\). Hence \(q^{t-1} \ge 1\) and each term is at least \(C/(1 + r)\). Summing \(n\) terms gives \(\mathrm{PV}_n \ge nC/(1 + r)\). Suppose a number \(V\) satisfied Definition 2.1. Take \(\varepsilon = 1\) and an integer \(m\) larger than \(\max\{M, (V + 1)(1 + r)/C\}\), where \(M\) is the integer the definition gives for \(\varepsilon = 1\). Then \(\mathrm{PV}_m \ge mC/(1 + r) > V + 1\), contradicting \(|\mathrm{PV}_m - V| \le 1\).

Example 3.5 (a growing perpetuity at 8 per cent and 3 per cent growth)

Take \(C = 100\), \(r = 0.08\) and \(g = 0.03\). Then \(r > g\), \(q = 1.03/1.08 = 0.953704\), and the value is \(100/0.05 = 2000\). The first payment is worth \(92.5926\), and the first ten payments are worth \(755.0134\). Proposition 3.2 gives the remainder after ten payments as \(2000 \times q^{10} = 1244.9866\), and the lab below checks this remainder at several horizons.

Lab 1 · The annuity formula, and the growing perpetuity at and above the boundary

Stated before running: for four rational rates and every length from 1 to 40, the annuity closed form of Theorem 1.2 equals the direct sum of discounted payments exactly, and the annuity due equals \((1 + r)\) times the ordinary annuity. For the growing perpetuity with \(C = 100\), \(r = 0.08\) and \(g = 0.03\), the gap between the partial values and \(2000\) should equal \((C/(r - g))\, q^N\) at every horizon \(N\) printed. For \(g = r\), the partial values should grow linearly in \(N\), and the code should refuse the closed form.

"""M1 L07 lab 1: annuity closed form against direct summation, and the growing-perpetuity limit case.

Amounts are in currency units (CU). Payments fall at the end of each period, r is the rate per period,
and v = 1 / (1 + r) is the discount factor. Part A uses exact rational arithmetic (fractions.Fraction).
Part B uses floats and prints partial sums for several horizons N, next to the closed form and the
remainder formula of Proposition 3.2. Part C shows the case g = r, where the partial sums are unbounded and
the closed form must be refused. Standard library only; no randomness and no network access.
"""

from __future__ import annotations

import math
from fractions import Fraction

RATES: tuple[Fraction, ...] = (Fraction(1, 20), Fraction(3, 100), Fraction(1, 10), Fraction(1, 3))
N_MAX = 40
PAYMENT = Fraction(100)


def annuity_closed(c: Fraction, r: Fraction, n: int) -> Fraction:
    """PV of n payments of c at ends of periods 1..n. Requires r > 0; the r = 0 case is n * c."""
    if r <= 0:
        raise ValueError("this closed form needs r > 0; at r = 0 the value is n * c")
    v = 1 / (1 + r)
    return c * (1 - v**n) / r


def annuity_direct(c: Fraction, r: Fraction, n: int) -> Fraction:
    """PV of n payments of c at ends of periods 1..n, by adding the discounted payments."""
    total = Fraction(0)
    for t in range(1, n + 1):
        total += c / (1 + r) ** t
    return total


def annuity_due_direct(c: Fraction, r: Fraction, n: int) -> Fraction:
    """PV of n payments of c at the start of periods 1..n, that is at times 0..n-1."""
    total = Fraction(0)
    for t in range(0, n):
        total += c / (1 + r) ** t
    return total


def growing_pv_partial(c: float, r: float, g: float, n: int) -> float:
    """PV of the first n payments of c * (1 + g)**(t - 1) at times t = 1..n."""
    return sum(c * (1 + g) ** (t - 1) / (1 + r) ** t for t in range(1, n + 1))


def growing_perpetuity_value(c: float, r: float, g: float) -> float:
    """Value C / (r - g) of a growing perpetuity. Refuses inputs outside the domain -1 < g < r, r > 0."""
    if r <= 0:
        raise ValueError("a perpetuity needs a positive discount rate r")
    if g <= -1:
        raise ValueError("a growing perpetuity needs g > -1 so that its payments stay positive")
    if not r > g:
        raise ValueError("a growing perpetuity needs r > g; when g >= r its partial values grow without bound")
    return c / (r - g)


def part_a() -> None:
    checks = 0
    for r in RATES:
        for n in range(1, N_MAX + 1):
            direct = annuity_direct(PAYMENT, r, n)
            if direct != annuity_closed(PAYMENT, r, n):
                raise AssertionError(f"annuity closed form fails at r = {r}, n = {n}")
            due = annuity_due_direct(PAYMENT, r, n)
            if due != (1 + r) * direct:
                raise AssertionError(f"annuity-due relation fails at r = {r}, n = {n}")
            checks += 2
    print(f"part A: exact checks passed: {checks} (r takes {len(RATES)} values, n = 1 to {N_MAX})")
    r, n = Fraction(1, 10), 3
    ordinary = annuity_direct(PAYMENT, r, n)
    due = annuity_due_direct(PAYMENT, r, n)
    print(f"part A example, c = 100, r = 1/10, n = 3: ordinary PV = {float(ordinary):.4f}, due PV = {float(due):.4f}")
    print(f"part A example, due / ordinary = {float(due / ordinary):.1f} (equals 1 + r = {float(1 + r):.1f})")


def part_b() -> None:
    c, r, g = 100.0, 0.08, 0.03
    closed = growing_perpetuity_value(c, r, g)
    q = (1 + g) / (1 + r)
    print(f"part B: c = {c:g}, r = {r:g}, g = {g:g}, q = (1 + g)/(1 + r) = {q:.6f}")
    print(f"part B: closed form C/(r - g) = {closed:.1f}")
    for n in (1, 5, 10, 50, 100, 200, 400):  # float sums: abs_tol covers the last digits at N = 400
        partial = growing_pv_partial(c, r, g, n)
        remainder = closed - partial
        predicted = closed * q**n
        if not math.isclose(remainder, predicted, rel_tol=1e-9, abs_tol=1e-9):
            raise AssertionError(f"remainder formula fails at n = {n}")
        print(f"part B: N = {n:3d}  PV of first N = {partial:10.4f}  remainder to closed form = {remainder:10.4f}")
    print("part B: the remainder equals (C / (r - g)) * q**N at every horizon listed")


def part_c() -> None:
    c, r = 100.0, 0.08
    g = r
    for n in (10, 100):
        partial = growing_pv_partial(c, r, g, n)
        if not math.isclose(partial, n * c / (1 + r), rel_tol=1e-12):
            raise AssertionError(f"g = r partial sums differ from N * C / (1 + r) at N = {n}")
        print(f"part C: g = r = {g:g}, N = {n:3d}  PV of first N = {partial:10.4f} (equals N * C / (1 + r))")
    try:
        growing_perpetuity_value(c, r, g)
    except ValueError as exc:
        print(f"part C: the closed form is refused: {exc}")


def main() -> None:
    part_a()
    part_b()
    part_c()


main()

The exact checks passed, so Theorem 1.2 and Proposition 1.4 hold for these 160 rate-and-length pairs, where each pair contributes two checks. The growing-perpetuity part is floating point: the remainder printed at each horizon matches \((C/(r - g))\, q^N\) to a relative tolerance of \(10^{-9}\), with an absolute tolerance of \(10^{-9}\) so that the tiniest remainder at \(N = 400\) is not tested at a relative scale. 4Where the canon breaks

  • The rate and the period must match. Theorem 1.2 uses \(r\) for one period and \(n\) for the number of periods. A monthly payment on an annual rate of 6 per cent uses \(r = 0.06/12\), not \(0.06\). Lesson 8 states this convention for loans.
  • The value is sensitive to the spread. Proposition 3.2 gives a value that depends on \(r - g\), not on \(r\) and \(g\) separately. With \(C = 100\), the value is \(2500\) at \(r - g = 0.04\) and \(2000\) at \(r - g = 0.05\), so a rise of one percentage point in the spread lowers the value by 20 per cent, from \(2500\) to \(2000\). A small error in \(g\) is a large error in the value when \(r - g\) is small.
  • The closed forms are defined by conditions. Theorem 1.2 needs \(r > 0\), and Theorem 3.3 needs \(-1 < g < r\). Outside these conditions, the code must refuse the formula or use a different branch, as Lab 1 shows. A formula without its condition returns a number that is not a value.

5Misconceptions

  1. “An annuity due and an ordinary annuity of the same length differ by a fixed amount of CU.”

    They differ by the factor \(1 + r\) (Proposition 1.4). With \(C = 100\), \(r = 0.1\) and \(n = 3\), the difference is \(24.8685\) CU, which is \(10\%\) of the ordinary value.

  2. “A growing perpetuity with \(g > r\) has a negative value, \(C/(r - g) < 0\), so it is worth less than nothing.”

    The formula is not the value in this case. Theorem 3.4 shows that the partial values are at least \(nC/(1 + r)\), which grows without bound. The sign of \(C/(r - g)\) is an artifact of applying a formula outside its condition.

  3. “The value of a perpetuity with its first payment at time 0 is \(C/r\), the same as one starting at time 1.”

    Shifting every payment one period earlier multiplies each present value by \(1 + r\), so the value is \((1 + r)C/r\). For \(C = 100\) and \(r = 0.05\), that is \(2100\) rather than \(2000\). Shifting each payment one period earlier multiplies every partial value by \(1 + r\), as in Proposition 1.4, so the limit in Definition 2.1 carries that factor to the value.

6Problem set

Every problem has a full worked solution. Attempt each one before opening it.

Mechanics

M1 · Five annual payments

Find the present value of five annual payments of 200 CU at \(r = 0.06\), at the ends of the years.

Solution

Theorem 1.2 with \(C = 200\), \(r = 0.06\), \(n = 5\) gives \(200(1 - 1.06^{-5})/0.06\). Here \(1.06^{5} = 1.3382256\), so \(1.06^{-5} = 0.7472582\) and \(1 - 0.7472582 = 0.2527418\). Dividing by \(0.06\) gives \(4.2123638\), and multiplying by 200 gives \(842.4728\) CU to four decimals (842.47276 before rounding).

M2 · A perpetuity's value

A perpetuity pays 50 CU at each year end, with \(r = 0.04\). What is its value?

Solution

The payments are \(C = 50\) CU at each year end, and \(r = 0.04\) is the rate per year. By Theorem 2.4 the value is \(C/r\), which is \(50/0.04 = 1250\) CU. Each year's payment is worth less than its face value, and the perpetuity as a whole is worth 1250 CU today.

M3 · A growing perpetuity

A growing perpetuity has \(C = 100\), \(r = 0.10\) and \(g = 0.04\). Find its value, and find its value if the first payment is at time 0.

Solution

Since \(r > g > -1\), Theorem 3.3 gives the value \(C/(r - g) = 100/0.06 = 1666.6667\) CU. With the first payment at time 0, the shift argument of Misconception 3 multiplies this by \(1 + r = 1.1\), giving \(1833.3333\) CU.

Proof

P1 · The annuity grows with its length

Prove that for \(r > 0\), \(\mathrm{PV}_{n+1} > \mathrm{PV}_n\) for every \(n \ge 1\), using Theorem 1.2 and no other fact.

Solution

Theorem 1.2 gives \(\mathrm{PV}_{n+1} - \mathrm{PV}_n = \frac{C}{r}\bigl[(1 - v^{n+1}) - (1 - v^{n})\bigr] = \frac{C}{r}\bigl(v^n - v^{n+1}\bigr) = \frac{C}{r} v^n (1 - v)\). Since \(1 - v = r/(1 + r) = r v\), the difference is \(C v^n \cdot v = C v^{n+1}\). This is positive because \(C > 0\) and \(v > 0\).

P2 · Induction for the growing annuity

Prove by induction on \(n \ge 1\) that \(\mathrm{PV}_n = \frac{C}{r - g}(1 - q^n)\) for \(g \ne r\), using only the definition of \(\mathrm{PV}_n\) and the identity \(1 - q = (r - g)/(1 + r)\).

Solution

Base case. \(\mathrm{PV}_1 = Cv = C/(1 + r)\). The formula gives \(\frac{C}{r - g}(1 - q) = \frac{C}{r - g} \cdot \frac{r - g}{1 + r} = \frac{C}{1 + r}\). Inductive step. Assume the formula for \(n\). Then \(\mathrm{PV}_{n+1} = \mathrm{PV}_n + C(1 + g)^{n} v^{n+1} = \mathrm{PV}_n + C v\, q^{n}\), because \((1 + g)^n v^n = q^n\). By the hypothesis, \(\mathrm{PV}_{n+1} = \frac{C}{r - g}(1 - q^n) + C v q^n\). Since \(C v = \frac{C}{r - g}\cdot\frac{r - g}{1 + r} = \frac{C}{r - g}(1 - q)\), this equals \(\frac{C}{r - g}\bigl(1 - q^n + q^n - q^{n+1}\bigr) = \frac{C}{r - g}(1 - q^{n+1})\), which is the formula for \(n + 1\).

P3 · The remainder shrinks

For a perpetuity with \(r > 0\), show that the gap \(C/r - \mathrm{PV}_m\) is at most \(\varepsilon = 1\) CU once \(m\) is large enough. Give an explicit sufficient \(m\) for \(C = 100\) and \(r = 0.05\).

Solution

By Proposition 2.3 and Lemma 2.2, the gap is at most \(C/(r(1 + mr))\). With \(C = 100\) and \(r = 0.05\) this is \(2000/(1 + 0.05m)\), which is at most 1 once \(1 + 0.05m \ge 2000\), that is \(m \ge 39{,}980\). The bound is loose: the exact gap is \(2000 \times 1.05^{-m}\), which is at most 1 once \(m \ge \ln 2000/\ln 1.05 \approx 155.8\), so \(m = 156\) suffices for the exact gap.

Empirical

E1 · How many payments for one CU

In Lab 1's growing perpetuity, how many payments are needed for the gap to the value 2000 to be at most 1 CU? Solve the inequality by hand before checking the lab's column.

Solution

The gap is \(2000\, q^N\) with \(q = 1.03/1.08\). The condition \(2000\, q^N \le 1\) is \(N \ge \ln 2000 / \ln(1/q)\). Here \(\ln(1/q) = 0.047402\), so the bound is \(N \ge 160.35\), and the smallest integer is \(N = 161\). The lab's column at \(N = 200\) shows a gap of 0.1527, which is below 1, and the bound says \(N = 161\) is the first horizon that works.

E2 · Sensitivity of the annuity to the rate

Before running anything, predict whether the present value of a 30-year annuity of 100 CU per year is larger at \(r = 0.05\) or at \(r = 0.10\), and compute both values.

Solution

A lower rate discounts less, so the present value is larger at \(r = 0.05\). By Theorem 1.2, \(\mathrm{PV}_{30}(0.05) = 100(1 - 1.05^{-30})/0.05 = 1537.2451\) and \(\mathrm{PV}_{30}(0.10) = 100(1 - 1.1^{-30})/0.10 = 942.6914\), so the lower rate gives the larger value.

E3 · The closed form at zero rate

Lab 1 refuses the closed form of Theorem 1.2 when \(r = 0\). Explain what the closed form would compute at \(r = 0\), and give the correct value of a five-period annuity of 100 CU at \(r = 0\).

Solution

At \(r = 0\), both \(1 - v^n\) and \(r\) are zero, so the formula is \(0/0\) and has no value. Every discount factor is \(1\), so the correct value is the sum of five payments of 100, which is \(500\). The code should branch on \(r = 0\) and return \(nC\).

Research

R1 · Why the growth rate must exceed minus one

Theorem 3.3 requires \(g > -1\). Explain which step of its proof uses this condition, and what goes wrong for \(g < -1\) when payments are required to be positive.

Solution

The condition gives \(q > 0\), so that \(d = 1/q - 1\) is a real number. The sign \(d > 0\) comes from \(q < 1\), that is from \(g < r\) (the proof of Theorem 3.3), and then the Bernoulli bound of Lemma 2.2 applies to \(q^m = (1 + d)^{-m}\). Also, the payments \(C(1 + g)^{t-1}\) are positive only when \(1 + g > 0\). For \(g < -1\) the payments alternate in sign, so the sum is no longer a perpetuity of positive payments, and Definition 3.1 does not apply. The algebra of Proposition 3.2 still holds for \(q < 0\), but the bound of Theorem 3.3 does not.

R2 · The implied discount rate

A growing perpetuity with \(C = 1\) and \(g = 0.02\) is quoted at a value of 25. What discount rate \(r\) is implied, if the quote is a value in the sense of Definition 2.1?

Solution

Theorem 3.3 gives the value as \(C/(r - g)\), so \(1/(r - 0.02) = 25\), giving \(r - 0.02 = 0.04\) and \(r = 0.06\). The condition \(r > g\) holds, so the quote is consistent with the formula.

R3 · A perpetuity starting at time zero

Compute the value of a growing perpetuity whose payments are \(C(1 + g)^t\) at times \(t = 0, 1, 2, \ldots\), with \(C = 100\), \(r = 0.08\) and \(g = 0.03\).

Solution

Reindex with \(s = t + 1\). The payment at time \(s - 1\) is \(C(1 + g)^{s-1}\) and is discounted by \((1 + r)^{-(s-1)} = (1 + r)\,(1 + r)^{-s}\). So the value is \((1 + r)\) times the value of the time-1 stream of Example 3.5, which is \(1.08 \times 2000 = 2160\).
