Proof portfolio: martingales

A fair game looks safe, and a stopping rule looks like a way to beat it. You will prove the three results that decide the question for martingales: optional stopping for a bounded stopping time, Doob's maximal inequality, and convergence for martingales bounded in second moment. Then you will write the engine that checks each result exactly on generated cases, including the doubling strategy, with a capital limit and without one, which shows why the boundedness hypothesis is needed.

Rungs 1 and 2

Lab 1 · Worked example: one bounded stopping time, step by step

Take \(N = 3\) and the stopping time \(\tau = \min(\text{the first time } S_k = +1,\ 3)\). Since \(\tau \le 3\), optional stopping for a bounded stopping time gives \(\E[S_\tau] = S_0 = 0\). Expected: \(\E[S_\tau] = 0\), and \(\E[S_{\tau\wedge k}] = 0\) for \(k = 0, 1, 2, 3\), on the 8 equally likely paths of length 3.

"""Rung 1 worked example: E[S_tau] for a bounded stopping time of the fair walk, by exact enumeration.

The fair walk S starts at S_0 = 0 and takes steps of +1 or -1, each with probability 1/2. The stopping time tau is the
first time the walk reaches +1, or the cap N = 3, whichever comes first, so tau is bounded by 3. Optional stopping for a
bounded stopping time says E[S_tau] = S_0 = 0. The lab lists the 8 equally likely paths of length 3, prints the value of
S at tau on each path, and prints E[S_(tau and k)] for k = 0, 1, 2, 3. Each printed expectation should be 0.
Everything is an exact fractions.Fraction on a finite space, so every run prints the same lines. No random draws.
"""

from __future__ import annotations

import itertools
from fractions import Fraction

HORIZON = 3
LEVEL = 1


def stopping_time(steps: tuple[int, ...]) -> int:
    """tau for one path: the first k with S_k = LEVEL, and HORIZON if the walk does not reach LEVEL by then."""
    position = 0
    for k, step in enumerate(steps, start=1):
        position += step
        if position == LEVEL:
            return k
    return HORIZON


def main() -> None:
    """Enumerate the paths, print tau and S_tau on each, then the expectation of the stopped walk at each time."""
    paths = list(itertools.product((1, -1), repeat=HORIZON))
    weight = Fraction(1, len(paths))
    total = Fraction(0)
    print("path tau S_tau weight")
    for steps in paths:
        tau = stopping_time(steps)
        value = sum(steps[:tau])
        total += weight * value
        label = "".join("+" if step == 1 else "-" for step in steps)
        print(f"{label} {tau} {value:+d} {weight}")
    print("E[S_tau] =", total)
    for k in range(HORIZON + 1):
        expectation = sum(
            (weight * sum(steps[: min(k, stopping_time(steps))]) for steps in paths),
            Fraction(0),
        )
        print(f"E[S_(tau and {k})] =", expectation)

Each row is one path, with its stopping time and the walk's value there. Step 1: a path whose first step is \(+1\) reaches \(+1\) at time 1, so \(\tau = 1\) and the value is \(+1\). These four paths have total weight \(1/2\) and contribute \(+1/2\) to the expectation. Step 2: a path whose first step is \(-1\) reaches \(+1\) only at time 3, on the path that steps \(-1, +1, +1\), where \(\tau = 3\) and the value is \(+1\). The other three paths that start with \(-1\) do not reach \(+1\) by time 3, so \(\tau = 3\) by the cap, with values \(-1\), \(-1\) and \(-3\). Together the four paths that start with \(-1\) contribute \((1 - 1 - 1 - 3)/8 = -1/2\). Step 3: the two halves cancel, so \(\E[S_\tau] = 0 = S_0\). Step 4: the same cancellation holds at each time \(k\), since \(\E[S_{\tau\wedge k}] = 0\) for \(k = 0, 1, 2, 3\). The printed expectations are exact, so the equality is exact and not a close value. The lab checks this one stopping time on one finite space. The theorem for every bounded stopping time is part P1 of this page.

Lab 2 · Completion problem: the doubling recursion with a capital limit

Bet number \(k\) stakes \(\text{base} \cdot 2^{k-1}\) cents, and it is placed only if its stake does not exceed the wealth on hand. Every placed bet loses in this lab. Replace each ___ with the expression that the rule requires: the first blank is the wealth on hand, and the second is the wealth after the stake is lost. Expected, once both lines are right: for capital 100 cents and base 1 cent, 6 bets are placed and 37 cents remain; for capital 1 cent, 1 bet is placed and 0 cents remain; for capital 1000 cents with at most 6 bets, 6 bets are placed and 937 cents remain.

"""Rung 2 completed solution: the doubling strategy with finite capital, when every placed bet loses.

Bet k (k = 1, 2, ...) stakes base * 2**(k-1) cents. A bet is placed only if its stake does not exceed the
wealth on hand, and a placed bet that loses takes its stake from the wealth. The loop stops when the next
stake does not fit the wealth (ruin) or when the cap on the number of bets is reached. The function returns
the number of bets placed and the wealth left after those losses. All money is an integer number of cents,
and the lab is an exact integer computation.
"""

from __future__ import annotations


def lost_bets(capital: int, base: int, cap: int) -> tuple[int, int]:
    """The bets placed when every placed bet loses, at most cap of them, and the wealth in cents after those losses."""
    wealth = capital
    placed = 0
    while placed < cap:
        stake = base * 2**placed
        if stake > ___:
            break
        wealth = ___
        placed += 1
    return placed, wealth


def main() -> None:
    """Print the bets placed and the wealth left for three capitals, base stake 1 cent."""
    for capital, base, cap in ((100, 1, 10), (1, 1, 10), (1000, 1, 6)):
        placed, wealth = lost_bets(capital, base, cap)
        print(f"capital {capital} base {base} cap {cap}: bets placed {placed}, wealth after losses {wealth}")

Rung 3 · Specification

Context
The curriculum names the later modules AP1 and SC1 as users of the three martingale results of this unit. Each result has hypotheses, and a result applied without them can fail, as the doubling strategy shows. You prove the three results, and you write the engine that checks each one exactly on generated cases, so that a claim about a model can be tested against exact numbers rather than against a plot.
Inputs
No data file. The autograder's instances come from grader/instance.py, seeded by your workspace. Each instance holds a horizon \(N\) between 4 and 10 steps, a stopping rule of level 1 or 2 with a cap between 1 and \(N\), a base stake and a capital in integer cents, a dyadic level and a barrier. Every instance is SIMULATED: it is a generated case and not a market, a price or a real stake. The report uses the instance of seed 0. Lab 3 prints the reference numbers of one illustrative case, which is an input and not data.
Required outputs
In a repository of your own: martingale_checks.py at its root, with the five functions of the table below. Start from the starter file, whose signatures are complete. The module has these names: stopped_value_expectation(instance) -> Fraction, doob_max_probability(instance, lam: int) -> tuple[Fraction, Fraction], doubling_outcome(instance) -> dict[str, int | Fraction], dyadic_martingale_error(instance, n: int) -> Fraction, and dyadic_martingale_value(instance, n: int, x: Fraction) -> Fraction, the last one giving the value of the dyadic martingale at a point. Also commit proofs.html, a typeset file of your three proofs in the form of the statements below; report/run_report.py, which prints the report's numbers for seed 0 and the same lines as Lab 3 for the illustrative case; and report/self_assessment.md, the summary that the form in the self-assessment section produces.

Conventions

  • The walk \(S\) starts at \(S_0 = 0\). Each step is \(+1\) with probability \(p\) and \(-1\) with probability \(1-p\), and the instance's win_probability is \(p\), an exact Fraction. The instances use \(p = 1/2\), so \(S\) is a martingale; the control walk uses \(p = 1/3\).
  • A stopping rule in an instance is \(\tau = \min(\text{the first time } S_k = \text{stop\_level},\ \text{stop\_cap})\). Its cap is bounded by the horizon \(N\), and stopped_value_expectation returns \(\E[S_\tau]\), exact.
  • doob_max_probability(instance, lam) uses the fair walk \(X_k = |S_k|\) for \(0 \le k \le N\), and returns the pair \((\Prob(\max_{k \le N} X_k \ge \lambda),\ \E[X_N]/\lambda)\), both exact. The level \(\lambda\) is a whole number of steps.
  • The doubling strategy has base stake \(s\) and capital \(K\), both in integer cents, with \(s \le K\). Bet \(k\) stakes \(s\,2^{k-1}\) cents. A bet is placed only if its stake does not exceed the wealth on hand. A win pays the stake, and the strategy stops at the first win or at the first bet that is not placed. The function returns the number \(J\) of bets placed when every placed bet loses, with the win and ruin probabilities, the wealths on each branch, the largest stake placed, and \(\E[\text{final wealth}]\) rounded once, half up, to the nearest cent.
  • dyadic_martingale_error(instance, n) is \(\E[(M_n - Y)^2]\), where \(Y(x) = x\) on \([0,1]\) under the measure that gives each interval its length and \(M_n\) is the average of \(Y\) over each level-\(n\) cell \([j/2^n, (j+1)/2^n)\), the last cell closed at 1. dyadic_martingale_value(instance, n, x) is the value \(M_n(x)\) on the cell that contains \(x\), which is the cell's midpoint.
  • Each of the following raises ValueError, and no other invalid input is specified: a horizon \(N\) below 1 in stopped_value_expectation or doob_max_probability; a stopping cap above \(N\) in stopped_value_expectation; a level \(\lambda \le 0\) in doob_max_probability; a capital of zero or less in doubling_outcome; a base stake larger than the capital in doubling_outcome.
  • The three results that the proofs establish are stated here with their assumptions, and the statements are the ones the tests check. They are proved in your own words in proofs.html.

The three results to prove

P1 · Optional stopping, bounded case.

  1. \((\Omega, \mathcal F, \Prob)\) is a probability space, and \((\mathcal F_k)_{k \ge 0}\) is a filtration on it.
  2. \(M = (M_k)_{k \ge 0}\) is a martingale on \((\mathcal F_k)\): each \(M_k\) is integrable and adapted, and \(\E[M_{k+1} \mid \mathcal F_k] = M_k\).
  3. \(\tau\) is a stopping time on \((\mathcal F_k)\), so \(\{\tau \le k\} \in \mathcal F_k\) for every \(k\), and there is a fixed whole number \(N \ge 0\) with \(\tau \le N\) everywhere.

Then \(M_\tau\) is integrable and \(\E[M_\tau] = \E[M_0]\).

P2 · Doob's maximal inequality.

  1. \((\Omega, \mathcal F, \Prob)\) is a probability space, and \((\mathcal F_k)_{k \ge 0}\) is a filtration on it.
  2. \(X = (X_k)_{k \ge 0}\) is adapted, integrable and nonnegative, and it is a submartingale: \(\E[X_{k+1}\indic_B] \ge \E[X_k\indic_B]\) for every \(k\) and every \(B \in \mathcal F_k\).
  3. \(N \ge 0\) is a fixed whole number, and \(\lambda > 0\) is a real number.

Then \(\lambda\,\Prob(\max_{k \le N} X_k \ge \lambda) \le \E[X_N]\), and so \(\Prob(\max_{k \le N} X_k \ge \lambda) \le \E[X_N]/\lambda\).

P3 · Convergence for martingales bounded in second moment.

  1. \((\Omega, \mathcal F, \Prob)\) is a probability space, and \((\mathcal F_n)_{n \ge 0}\) is a filtration on it.
  2. \(M = (M_n)_{n \ge 0}\) is a martingale on \((\mathcal F_n)\), and each \(M_n\) is square-integrable.
  3. There is a real number \(L\) with \(\E[M_n^2] \le L\) for every \(n \ge 0\).

Then there is an event \(\Omega_0\) with \(\Prob(\Omega_0) = 1\) such that \(M_n(\omega)\) converges to a finite limit for every \(\omega \in \Omega_0\).

The proofs in Lessons 10, 11 and 12 are the reference for the steps. Each of your proofs must name the lemma or definition that justifies each step, and must say which assumption each step uses. A proof of a different statement does not count for these three.

The stopping rule that fails

The doubling strategy of Lesson 10 shows what happens when a stopping time is not bounded. Without a capital limit, the net gain of the doubling bets, stopped at its first win, has \(\Prob(\tau > n) = 2^{-n}\) for every \(n\), so no fixed \(N\) bounds \(\tau\) almost surely. The stopped gain equals 1 with probability 1 while its start is 0, so the identity of P1 fails for this \(\tau\) (Lesson 10, Proposition 10.9). Your engine reproduces the bounded case through its outputs for a finite capital, where \(\tau\) is bounded by \(J\), and your P1 proof must show which assumption this example breaks.

"""Rung 3 reference numbers: the values the report quotes for one illustrative case of each martingale check.

Standard library only. Everything is exact: each probability and expectation is a fractions.Fraction computed by
enumeration or by a closed sum, and each money amount is an integer number of cents, rounded once, half up, from the
exact value. The case is illustrative and is not a generated instance: a walk of horizon N = 6, a stopping rule
tau = min(first time S = +1, 4), Doob's level 3, doubling with capital 100 cents and base stake 1 cent, the dyadic
martingale for levels 0 to 10, and a biased control with win probability 1/3. Copy this file into report/run_report.py,
then replace the enumerations with calls to your martingale_checks module. It must print the same lines.
"""

from __future__ import annotations

import itertools
import math
from fractions import Fraction

HALF = Fraction(1, 2)
HORIZON = 6
LEVEL = 1
CAP = 4
LAM = 3
CAPITAL = 100
BASE = 1
CONTROL = Fraction(1, 3)


def half_up(amount: Fraction) -> int:
    """An exact amount in cents, rounded once, half up: floor(x + 1/2)."""
    return math.floor(amount + HALF)


def stopped_expectation(p: Fraction) -> Fraction:
    """E[S_tau] for tau = min(first time S = LEVEL, CAP), by enumerating the 2**HORIZON paths."""
    total = Fraction(0)
    for steps in itertools.product((1, -1), repeat=HORIZON):
        weight = Fraction(1)
        for step in steps:
            weight *= p if step == 1 else 1 - p
        position = 0
        value = None
        for step in steps[:CAP]:
            position += step
            if position == LEVEL:
                value = position
                break
        if value is None:
            value = sum(steps[:CAP])
        total += weight * value
    return total


def doob(lam: int) -> tuple[Fraction, Fraction]:
    """P(max over k <= HORIZON of |S_k| >= lam) and E|S_HORIZON| / lam for the fair walk, by enumeration."""
    hits = Fraction(0)
    expected_abs = Fraction(0)
    weight = Fraction(1, 2**HORIZON)
    for steps in itertools.product((1, -1), repeat=HORIZON):
        position = 0
        peak = 0
        for step in steps:
            position += step
            peak = max(peak, abs(position))
        if peak >= lam:
            hits += weight
        expected_abs += weight * abs(position)
    return hits, expected_abs / lam


def doubling(p: Fraction) -> dict[str, Fraction | int]:
    """Doubling with CAPITAL cents and base stake BASE: bets placed, probabilities, wealths and E[final], exact.

    A bet is placed while its stake does not exceed the wealth on hand. The strategy stops at the first win, which
    leaves CAPITAL + BASE, or at ruin, after the placed bets have all lost.
    """
    branches: list[tuple[Fraction, int, str, int]] = []

    def play(wealth: int, bet: int, weight: Fraction) -> None:
        stake = BASE * 2 ** (bet - 1)
        if stake > wealth:
            branches.append((weight, wealth, "ruin", bet - 1))
            return
        branches.append((weight * p, wealth + stake, "win", bet))
        play(wealth - stake, bet + 1, weight * (1 - p))

    play(CAPITAL, 1, Fraction(1))
    win = sum((w for w, _, kind, _ in branches if kind == "win"), Fraction(0))
    ruin = sum((w for w, _, kind, _ in branches if kind == "ruin"), Fraction(0))
    expected = sum((w * wealth for w, wealth, _, _ in branches), Fraction(0))
    placed = next(bets for _, _, kind, bets in branches if kind == "ruin")
    return {
        "bets": placed,
        "win": win,
        "ruin": ruin,
        "wealth_on_win": CAPITAL + BASE,
        "wealth_on_ruin": CAPITAL - BASE * (2**placed - 1),
        "expected": expected,
        "expected_cents": half_up(expected),
    }


def dyadic_error(n: int) -> Fraction:
    """E[(M_n - Y)^2] for Y(x) = x on [0, 1]: the sum over the 2**n cells of the exact integral of (x - midpoint)^2."""
    cells = 2**n
    width = Fraction(1, cells)
    total = Fraction(0)
    for j in range(cells):
        a = Fraction(j, cells)
        b = a + width
        c = (a + b) / 2
        total += ((b - c) ** 3 - (a - c) ** 3) / 3
    return total


def dyadic_value(n: int, x: Fraction) -> Fraction:
    """M_n(x): the midpoint of the level-n cell that contains x, for x in [0, 1]."""
    cells = 2**n
    index = min(int(x * cells), cells - 1)  # x is in [0, 1], so truncation is the floor
    return Fraction(2 * index + 1, 2 * cells)


def main() -> None:
    """Print the reference values for the four checks, the control and the dyadic martingale."""
    fair = stopped_expectation(HALF)
    control = stopped_expectation(CONTROL)
    print("stopped walk, fair coin: E[S_tau] =", fair)
    print("stopped walk, control p = 1/3: E[S_tau] =", control, "| decimal", f"{float(control):.6f}")
    prob, bound = doob(LAM)
    print(f"Doob, N = {HORIZON}, level {LAM}: P(max |S_k| >= {LAM}) =", prob, "| bound E|S_N|/level =", bound)
    print("Doob bound decimal", f"{float(bound):.6f}", "| probability decimal", f"{float(prob):.6f}")
    print("Doob holds:", prob <= bound)
    fair_out = doubling(HALF)
    print(
        f"doubling, capital {CAPITAL}, base {BASE}, fair coin: bets {fair_out['bets']}, "
        f"P(win) = {fair_out['win']}, P(ruin) = {fair_out['ruin']}, "
        f"wealth on win {fair_out['wealth_on_win']}, wealth on ruin {fair_out['wealth_on_ruin']}"
    )
    print("doubling, fair coin: E[final wealth] =", fair_out["expected"], "| cents", fair_out["expected_cents"])
    control_out = doubling(CONTROL)
    print(
        "doubling, control p = 1/3: E[final wealth] =",
        control_out["expected"],
        "| decimal",
        f"{float(control_out['expected']):.6f}",
        "| cents",
        control_out["expected_cents"],
    )
    for n in (0, 1, 2, 3, 10):
        print(
            f"dyadic level {n}: E[(M_n - Y)^2] =",
            dyadic_error(n),
            "| closed form equal:",
            dyadic_error(n) == Fraction(1, 12 * 4**n),
        )
    x = Fraction(1, 3)
    print(
        "dyadic level 10 at x = 1/3: M_10(x) =",
        dyadic_value(10, x),
        "| |M_10(x) - x| <= 2**-11:",
        abs(dyadic_value(10, x) - x) <= Fraction(1, 2**11),
    )

The brief

Write for a reader who knows Lessons 8 to 12, not for a referee of this case. Use these five sections, in this order and under these headings, followed by the appendix.

  1. Summary: the case, the three checks and the one number that shows each of them holds, in at most 80 words.
  2. Setup and conventions: the walk, the stopping rule, the coin, the cent rule, and which module function computes each number.
  3. The checks: the stopped expectation, Doob's probability and bound, and the doubling outcome, each with its printed value and its exact check.
  4. The dyadic martingale: the error at each level and the value at a point, with the convergence bound.
  5. Limitations: what a finite horizon does not show, what the seeded instance does and does not cover, and what the cent rule does.

Summary

For the illustrative case of Lab 3, the stopped fair walk has expectation exactly 0, Doob's probability of 7/16 lies below its bound of 5/8, and the fair doubling strategy has expected final wealth of exactly 100 cents. The biased control gives 95 cents, rounded half up from 69533/729. The dyadic error at level \(n\) is \(1/(12 \cdot 4^n)\).

Setup and conventions

The walk \(S\) starts at 0 and steps by \(\pm 1\) with probability \(1/2\) each, so \(S\) is a martingale on its natural filtration. The stopping rule is \(\tau = \min(\text{first } S = +1,\ 4)\), and \(N = 6\). Money is integer cents. stopped_value_expectation computes \(\E[S_\tau]\), doob_max_probability computes the Doob pair, doubling_outcome computes the doubling values, and dyadic_martingale_error and dyadic_martingale_value compute the dyadic values. The control walk has win probability \(1/3\). Every number below is printed by Lab 3 as it prints it.

  • Meets C3 level 3: the section names the module function behind each number and states the terms of the case where the numbers first appear.
The checks

The fair stopped expectation is \(0 = S_0\). For the control, \(\E[S_\tau] = -79/81\), which is not 0, so the control breaks the identity as it should. Doob at level \(\lambda = 3\) gives \(\Prob(\max_{k \le 6}|S_k| \ge 3) = 7/16\), and the bound \(\E|S_6|/3 = 5/8\), so \(7/16 \le 5/8\). For the doubling strategy with capital 100 cents and base 1 cent, \(J = 6\) bets are placed, the win probability is \(63/64\), the ruin probability is \(1/64\), the wealth on a win is 101 cents and on ruin 37 cents. The fair expectation is 100 cents, the capital, by P1 applied to the net gain of the bets, which is a martingale stopped at a time bounded by \(J\). The control's expectation is \(69533/729 \approx 95.381344\), which rounds half up to 95 cents; the six-place decimal is rounded from the exact fraction for display only.

  • Meets C3 level 4: each value is marked as an exact fraction, an integer of cents, or a decimal rounded from an exact value, and the rounding is stated.
  • Meets C1 level 3: the bounded strategy is named as the case in which P1 applies, with its assumption \(\tau \le J\) stated.
  • Meets C5 level 3: the bound uses the first power of \(\E|S_6|\) and the constant 1, and the probability is compared with it.
Limitations

The check uses one horizon, one stopping rule and one coin, so it shows the identities for this case only. The three theorems are proved for every case in the appendix, and the lab does not extend them. The cent rule leaves each printed cent amount within half a cent of its exact value. Lowering the win probability lowers the control's expectation, since \(\E = K + s - s\,(2(1-p))^J\) and the subtracted term grows as \(p\) falls. The model has no fees, no interest and no limit on bets beyond the capital. A finite horizon cannot show almost-sure convergence, and the dyadic check at level 10 shows the mean-square error and one point only.

  • Meets C4 level 3: states that one horizon is a finite check and that the theorems hold for every case in the appendix, and names the cent rule.
  • Misses C4 level 4: does not say which way a change of the horizon or of the stopping cap would move the expectations, which level 4 requires.
Appendix · Proofs

P1. Assume the probability space, the filtration, the martingale \(M\) with integrable \(M_k\), and the stopping time \(\tau \le N\) everywhere. Since \(\tau \le N\), \(M_\tau = M_{\tau \wedge N}\), and \(|M_{\tau \wedge N}| \le \sum_{k \le N}|M_k|\), so \(M_\tau\) is integrable. For \(0 \le k < N\), \(M_{\tau \wedge (k+1)} - M_{\tau \wedge k} = \indic_{\{\tau > k\}}(M_{k+1} - M_k)\), because on \(\{\tau \le k\}\) both stopped values equal \(M_\tau\). The event \(\{\tau > k\}\) lies in \(\mathcal F_k\), since \(\{\tau \le k\} \in \mathcal F_k\) by the definition of a stopping time. The martingale property with \(A = \{\tau > k\}\) gives \(\E[\indic_A(M_{k+1} - M_k)] = 0\). Summing over \(k = 0, \ldots, N-1\) telescopes to \(\E[M_\tau] = \E[M_{\tau\wedge N}] = \E[M_0]\).

P2. Assume \(X\) is a nonnegative submartingale on \((\mathcal F_k)\), \(N\) is fixed and \(\lambda > 0\). Let \(A = \{\max_{k \le N} X_k \ge \lambda\}\), and let \(A_k = \{X_k \ge \lambda\} \cap \bigcap_{j < k}\{X_j < \lambda\}\), for \(0 \le k \le N\). The sets \(A_k\) are disjoint, have union \(A\), and \(A_k \in \mathcal F_k\). For \(B \in \mathcal F_k\) and \(k \le N\), chaining the submartingale inequality from \(i = k\) to \(N - 1\), with \(B \in \mathcal F_k \subseteq \mathcal F_i\), gives \(\E[X_N\indic_B] \ge \E[X_k\indic_B]\). Take \(B = A_k\): then \(\E[X_N\indic_{A_k}] \ge \E[X_k\indic_{A_k}] \ge \lambda\,\Prob(A_k)\), since \(X_k \ge \lambda\) on \(A_k\). Summing over \(k\) gives \(\E[X_N\indic_A] \ge \lambda\,\Prob(A)\). Since \(X_N \ge 0\), \(\E[X_N\indic_A] \le \E[X_N]\). Dividing by \(\lambda\) gives the bound. The bound is attained in one case: for \(|S|\) with \(N = 1\) and \(\lambda = 1\), the probability is 1 and \(\E|S_1|/1 = 1\), so the bound cannot be sharpened there. It bounds a probability, not \(\E[\max_k X_k]\).

P3. Assume the probability space, the filtration, the martingale \(M\) with square-integrable \(M_n\), and \(\E[M_n^2] \le L\) for all \(n\). Let \(v_n = \E[M_n^2]\). For \(m \le n\), \(M_m\) is square-integrable and \(\mathcal F_m\)-measurable, so \(\E[M_m(M_n - M_m)] = 0\) by the orthogonality of martingale increments (Lemma 12.1 of Lesson 12). Expanding \(M_n = M_m + (M_n - M_m)\) gives \(\E[(M_n - M_m)^2] = v_n - v_m\), so \(v_n\) is nondecreasing and bounded by \(L\). Let \(L^\ast = \lim_n v_n \le L\), which exists. Fix \(m\) and \(\varepsilon > 0\). The process \(Y_k = (M_k - M_m)^2\) for \(k \ge m\) is a nonnegative submartingale (Lemma 12.3 of Lesson 12). Doob's inequality (P2) with level \(\varepsilon^2\), applied to \(Y\) on \(m \le k \le N\), gives \(\Prob(\max_{m \le k \le N}|M_k - M_m| \ge \varepsilon) \le \E[Y_N]/\varepsilon^2 = (v_N - v_m)/\varepsilon^2 \le (L^\ast - v_m)/\varepsilon^2\). Let \(D_m(\varepsilon) = \{\exists k \ge m: |M_k - M_m| \ge \varepsilon\}\). The events in the maximum increase with \(N\), so by continuity of probability from below, \(\Prob(D_m(\varepsilon)) \le (L^\ast - v_m)/\varepsilon^2\). Let \(G\) be the set where \((M_n)\) is not Cauchy. If \(\omega \in G\), there is \(j\) with \(|M_k - M_l| \ge 1/j\) for some \(k, l \ge m\), for every \(m\); then one of \(|M_k - M_m|\) and \(|M_l - M_m|\) is at least \(1/(2j)\), so \(\omega \in D_m(1/(2j))\) for every \(m\). Hence \(G \subseteq \bigcup_j \bigcap_m D_m(1/(2j))\). For each \(j\), \(\Prob(\bigcap_m D_m(1/(2j))) \le \inf_m 4j^2(L^\ast - v_m) = 0\), because \(v_m \to L^\ast\). A countable union of null sets is null, so \(\Prob(G) = 0\). Off \(G\), the real sequence is Cauchy and converges, by the completeness of the reals. Take \(\Omega_0 = G^c\).

  • Meets C1 level 4: lists the assumptions of P1, P2 and P3, and ties the bound \(\tau \le N\) and the nonnegativity of \(X\) to the steps that use them.
  • Meets C2 level 4: names the lemma behind each step, the orthogonality of P3, the continuity from below, and Doob's inequality for the squared increments.
  • Meets C5 level 4: the bound of P2 has the first power of \(\E[X_N]\), and the Lesson 11 case with \(N = 1\), \(\lambda = 1\) for \(|S|\) attains it.
