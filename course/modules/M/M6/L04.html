Monotone and Dominated Convergence

The limit of the integrals of a sequence of functions is not, in general, the integral of their limit. Two sufficient hypotheses license the interchange. Monotone convergence applies to non-decreasing sequences of non-negative functions. Dominated convergence applies to sequences bounded by a single function with finite integral. This lesson proves the first, states the second with its assumptions, and computes an example in which both fail and the two integrals disagree.

1Pointwise convergence

Definition 1.1 (pointwise convergence, monotone sequences)

Let \(f_1, f_2, \dots\) be functions from \(\Omega\) to \([0, \infty]\). The sequence converges pointwise to \(f\) when \(f_n(\omega) \to f(\omega)\) for every \(\omega\), as a limit of numbers in \([0, \infty]\). The sequence is non-decreasing when \(f_n \le f_{n+1}\) everywhere for every \(n\).

For a non-decreasing sequence the pointwise limit always exists in \([0, \infty]\), because the values never decrease, and it equals the supremum \(\sup_n f_n(\omega)\). This fact is used in the proof below.

2Monotone convergence

Theorem 2.1 (monotone convergence theorem)

Assumptions.

  1. \((\Omega, \mathcal F, \mu)\) is a measure space.
  2. Each \(f_n\) is a measurable function from \(\Omega\) to \([0, \infty]\), and the sequence is non-decreasing.
  3. \(f = \lim_n f_n\) pointwise, so \(f(\omega) = \sup_n f_n(\omega)\).

Statement. \(f\) is measurable, and \(\int f_n \, d\mu \to \int f \, d\mu\) in \([0, \infty]\).

Proof

Measurability. For real \(t\), \(f(\omega) > t\) holds exactly when \(f_n(\omega) > t\) for some \(n\), because \(f(\omega)\) is the supremum of the \(f_n(\omega)\). So \(\{f > t\} = \bigcup_n \{f_n > t\}\), a countable union of events, and \(f\) is measurable.

Upper bound. Since \(f_n \le f_{n+1} \le f\), Proposition 3.2(b) of Lesson 3 gives \(\int f_n \le \int f_{n+1} \le \int f\). So \(L = \lim_n \int f_n\) exists in \([0, \infty]\) and \(L \le \int f\).

Lower bound. Let \(s\) be simple with \(0 \le s \le f\), with canonical values \(a_1, \dots, a_m\) on the events \(A_1, \dots, A_m\), and fix \(c\) with \(0 < c < 1\). Put \(E_n = \{f_n \ge c s\}\). On \(A_i\), the condition \(f_n \ge c s\) is \(f_n \ge c a_i\), so \(E_n = \bigcup_i \bigl(A_i \cap \{f_n \ge c a_i\}\bigr)\). Each \(\{f_n \ge c a_i\} = \bigcap_m \{f_n > c a_i - 1/m\}\) is an event, so \(E_n\) is an event. The sets increase, \(E_n \subseteq E_{n+1}\), because the \(f_n\) do.

The sets cover \(\Omega\). If \(s(\omega) = 0\), then \(\omega \in E_1\), since \(f_1 \ge 0 = cs(\omega)\). If \(s(\omega) = a > 0\), then \(f(\omega) \ge a > ca\), and since \(f(\omega)\) is the supremum of the \(f_n(\omega)\), some \(f_n(\omega) > ca\), so \(\omega \in E_n\) for that \(n\) and all later \(n\). Hence \(E_n \uparrow \Omega\).

The function \(t_n = c\,s\,\indic\{E_n\}\) is simple, with \(t_n \le f_n\): on \(E_n\), \(f_n \ge cs = t_n\), and off \(E_n\), \(t_n = 0\). So \(\int f_n \ge \int t_n\) by Definition 3.1. The integral of \(t_n\) is \(\sum_i c\,a_i\,\mu(A_i \cap E_n)\), because the value zero contributes nothing. The sets \(A_i \cap E_n\) increase to \(A_i\), so by continuity from below (Lesson 2, Proposition 1.3(d)), \(\mu(A_i \cap E_n) \to \mu(A_i)\) for each \(i\). Therefore \(L \ge c \sum_i a_i \mu(A_i) = c \int s \, d\mu\).

Letting \(c\) increase to \(1\) gives \(L \ge \int s \, d\mu\) for every simple \(s\) with \(0 \le s \le f\). Taking the supremum over such \(s\) gives \(L \ge \int f \, d\mu\). With the upper bound, \(L = \int f \, d\mu\). \(\blacksquare\)

Example 2.2 (a sequence that is not non-decreasing)

On \([0, 1]\) with the length measure, let \(f_n = n \indic\{(0, 1/n]\}\). Then \(f_1 = \indic\{(0, 1]\}\) takes the value 1 on \((1/2, 1]\), while \(f_2\) takes the value 0 there, so \(f_1 \le f_2\) fails. Theorem 2.1 does not apply to this sequence, and Section 4 shows what happens.

3Dominated convergence

Theorem 3.1 (dominated convergence theorem, stated, not proved here)

Assumptions.

  1. \((\Omega, \mathcal F, \mu)\) is a measure space.
  2. Each \(f_n\) and \(f\) is a real-valued measurable function on \(\Omega\), and \(f_n(\omega) \to f(\omega)\) for every \(\omega\).
  3. There is a measurable \(g : \Omega \to [0, \infty]\) with \(\int g \, d\mu < \infty\) and \(|f_n| \le g\) everywhere, for every \(n\).

Statement. \(f\) is integrable, meaning \(\int |f| \, d\mu < \infty\), and \(\int f_n \, d\mu \to \int f \, d\mu\).

The statement is given here without a proof. No locator for it is cited in this lesson, and the references below say what has and has not been read.

Example 3.2 (an unbounded dominating function; the Lebesgue identity is assumed)

On \((0, 1]\) with the length measure, let \(f_n(x) = \min(n, x^{-1/2})\) and \(f(x) = x^{-1/2}\). The sequence converges pointwise to \(f\), since \(x^{-1/2}\) is finite for \(x > 0\). Take \(g = x^{-1/2}\), which dominates every \(f_n\). Its calculus integral is \(\int_0^1 x^{-1/2} \, dx = 2\), by the antiderivative \(2\sqrt{x}\). This example assumes that this calculus value is the Lebesgue integral, which the page does not prove (compare Lesson 3, Remark 4.2). Under that assumption the domination hypothesis holds.

Proof of the integral. The function \(f_n\) equals \(n\) on \((0, 1/n^2]\) and \(x^{-1/2}\) on \((1/n^2, 1]\). So \(\int f_n = n \cdot (1/n^2) + \int_{1/n^2}^{1} x^{-1/2} \, dx = 1/n + (2 - 2/n) = 2 - 1/n\), using the same calculus values. This tends to \(2\), which is the calculus value of \(\int f\) and agrees with Theorem 3.1 under the same assumption. The dominating function is unbounded, and the example shows that a dominating function need not be bounded.

4A sequence with no integrable bound

Proposition 4.1 (the sequence \(n \indic\{(0, 1/n]\}\) has no integrable bound)

Assumptions.

  1. \([0, 1]\) carries the length measure \(\lambda\), as in Lesson 3, Assumption L.
  2. \(f_n = n \indic\{(0, 1/n]\}\) for \(n \ge 1\), and \(g : (0, 1] \to [0, \infty]\) is measurable with \(g \ge f_n\) on \((0, 1]\) for every \(n\).

Statement. Assuming Assumption L, \(\int_{(0,1]} g \, d\lambda = \infty\). So no function with a finite integral dominates every \(f_n\).

Proof

For \(n \ge 1\), let \(I_n = (1/(n+1), 1/n]\). These intervals are pairwise disjoint and have length \(1/n - 1/(n+1) = 1/(n(n+1))\). For \(x\) in \(I_n\), \(x \le 1/n\), so \(f_n(x) = n\); hence \(g(x) \ge n\) on \(I_n\).

Fix \(N\) and let \(h_N = \sum_{n=1}^{N} n \, \indic\{I_n\}\). This is a simple function, and \(h_N \le g\): on \(I_n\) it equals \(n \le g\), and it is zero elsewhere. By Definition 3.1 and Definition 2.1,

\[\int g \, d\lambda \ge \int h_N \, d\lambda = \sum_{n=1}^{N} n \cdot \frac{1}{n(n+1)} = \sum_{n=1}^{N} \frac{1}{n+1}.\]

Now \(\sum_{n=1}^{N} 1/(n+1)\) is unbounded. For \(m \ge 1\), split the integers \(2, 3, \dots, 2^m\) into the blocks \(\{2^{j-1}+1, \dots, 2^j\}\) for \(j = 1, \dots, m\). Each block has \(2^{j-1}\) terms, each at least \(1/2^j\), so each block sums to at least \(1/2\). Hence \(\sum_{k=2}^{2^m} 1/k \ge m/2\). Taking \(N = 2^m - 1\), so that \(N + 1 = 2^m\), gives \(\int g \, d\lambda \ge m/2\) for every \(m\). Therefore \(\int g \, d\lambda = \infty\). \(\blacksquare\)

Proposition 4.2 (the integrals stay at 1 while the limit is zero)

Assumptions. \([0, 1]\) carries \(\lambda\), the length measure of Lesson 3, Assumption L, and \(f_n = n \indic\{(0, 1/n]\}\).

Statement. Assuming Assumption L, (a) \(\int f_n \, d\lambda = 1\) for every \(n\). (b) \(f_n(x) \to 0\) for every \(x\) in \([0, 1]\). (c) \(\lim_n \int f_n \, d\lambda = 1 \ne 0 = \int \bigl(\lim_n f_n\bigr) \, d\lambda\).

Proof

(a) The function \(f_n\) is simple, with value \(n\) on the interval \((0, 1/n]\) and value 0 elsewhere. The interval \((0, 1/n]\) is the increasing union of the closed intervals \([1/m, 1/n]\) for \(m \ge n\), so by continuity from below (Lesson 2, Proposition 1.3(d)) and Assumption L, \(\lambda((0, 1/n]) = \lim_m (1/n - 1/m) = 1/n\). So \(\int f_n \, d\lambda = n \cdot (1/n) = 1\).

(b) For \(x = 0\), every \(f_n(0) = 0\). For \(x > 0\), \(f_n(x) = n\) when \(x \le 1/n\) and \(0\) otherwise. If \(n > 1/x\), then \(1/n < x\), so \(f_n(x) = 0\). Hence \(f_n(x) = 0\) for all large \(n\), and \(f_n(x) \to 0\).

(c) By (a), the integrals are all 1, so their limit is 1. By (b), the pointwise limit is the zero function, whose integral is 0. \(\blacksquare\)

Remark 4.3 (both theorems are silent here)

Theorem 2.1 does not apply, because \(f_1 \le f_2\) fails (Example 2.2). Theorem 3.1 does not apply, because by Proposition 4.1 no measurable \(g\) with a finite integral dominates the sequence. Proposition 4.2 shows that the interchange of limit and integral fails in this case. Because both hypotheses fail here, the example lies outside both theorems and does not show that either hypothesis is needed on its own.

Lab 4 · The sequence n times the indicator of (0, 1/n]

Predicted before running. Proposition 4.2(a) gives an integral of 1 for each \(n\), so the first check should print True. At \(x = 1/5\), \(f_n(x) = n\) for \(n \le 5\) and \(0\) for \(n \ge 6\), so the printed row should be 1, 2, 3, 4, 5, 0, 0, 0, and the first zero is at \(n = 6 = \lfloor 1/x \rfloor + 1\). The same holds at \(x = 1/50\), with first zero \(51\). The contributions \(n\) times the length of \((1/(n+1), 1/n]\) equal \(1/(n+1)\), so the printed contributions should be \(1/2, 1/3, 1/4, 1/5, 1/6\). The partial sums of \(1/(n+1)\) for \(n\) up to 10 and up to 100 are about 2.019877 and 4.197279. The grouping bound should hold for \(m\) from 1 to 10.

"""M6 lab L04: f_n = n times the indicator of (0, 1/n] on [0, 1], with exact Fraction arithmetic.

Part A: each f_n has integral exactly 1 under length measure, while at a fixed point x > 0 the values f_n(x) are 0
for every n beyond 1/x, so f_n(x) tends to 0 on (0, 1]. Part B: the contributions of the intervals (1/(n+1), 1/n]
to the lower bound that any dominating function must satisfy, and the partial sums of those contributions.
Part C: the grouping bound sum of 1/k for k from 2 to 2^m is at least m/2, checked exactly for m from 1 to 10.

Every value is an exact Fraction, except the one line that is labelled rounded. Standard library only. Nothing is
random, and nothing is read from a file. The lab checks finitely many n and x only; the page states the general
argument, which covers all n and all x.
"""

from __future__ import annotations

from fractions import Fraction


def f_value(n: int, x: Fraction) -> Fraction:
    """f_n(x) = n when 0 < x <= 1/n, and 0 otherwise. Raises ValueError when n < 1."""
    if n < 1:
        raise ValueError("n must be at least 1")
    return Fraction(n) if 0 < x <= Fraction(1, n) else Fraction(0)


def integral_f(n: int) -> Fraction:
    """The integral of f_n over [0, 1] under length measure: n times the length 1/n of the interval (0, 1/n]."""
    if n < 1:
        raise ValueError("n must be at least 1")
    return n * Fraction(1, n)


def first_zero_index(x: Fraction, limit: int) -> int:
    """The least n in 1..limit with f_n(x) = 0, or 0 when there is none. Raises ValueError for x <= 0."""
    if x <= 0:
        raise ValueError("x must be positive")
    for n in range(1, limit + 1):
        if f_value(n, x) == 0:
            return n
    return 0


def lower_bound_contribution(n: int) -> Fraction:
    """n times the length of (1/(n+1), 1/n], the part of a dominating integral forced by f_n on that interval."""
    if n < 1:
        raise ValueError("n must be at least 1")
    return n * (Fraction(1, n) - Fraction(1, n + 1))


def partial_sum(big_n: int) -> Fraction:
    """The sum of the contributions for n from 1 to N, which equals the sum of 1/(n+1) for n from 1 to N."""
    if big_n < 1:
        raise ValueError("N must be at least 1")
    return sum((lower_bound_contribution(n) for n in range(1, big_n + 1)), Fraction(0))


def grouping_holds(m: int) -> bool:
    """True when the sum of 1/k for k from 2 to 2^m is at least m/2, checked exactly."""
    total = sum((Fraction(1, k) for k in range(2, 2**m + 1)), Fraction(0))
    return total >= Fraction(m, 2)


def main() -> None:
    print("Part A (exact): integral of f_n over [0, 1]")
    integrals = [integral_f(n) for n in range(1, 21)]
    print(f"integral of f_n for n from 1 to 20 equals 1 in every case: {all(v == 1 for v in integrals)}")
    x = Fraction(1, 5)
    values = [f_value(n, x) for n in range(1, 9)]
    print("f_n(1/5) for n from 1 to 8: " + ", ".join(str(v) for v in values))
    for point in (Fraction(1, 5), Fraction(1, 50)):
        zero = first_zero_index(point, 200)
        expected = (point.denominator // point.numerator) + 1
        print(
            f"x = {point}: first n with f_n(x) = 0 is {zero}; floor(1/x) + 1 is {expected}; equal: {zero == expected}"
        )

    print("Part B (exact): contributions n times the length of (1/(n+1), 1/n]")
    contributions = [str(lower_bound_contribution(n)) for n in range(1, 6)]
    print("n from 1 to 5: " + ", ".join(contributions))
    for big_n in (10, 100):
        total = partial_sum(big_n)
        print(f"partial sum to N = {big_n}: {float(total):.6f} (rounded to 6 decimals from the exact value)")

    print("Part C (exact): sum of 1/k for k from 2 to 2^m, against m/2")
    checks = [grouping_holds(m) for m in range(1, 11)]
    print(f"sum of 1/k for k from 2 to 2^m is at least m/2 for m from 1 to 10: {all(checks)}")

5Where the canon breaks

Theorem 2.1 and Theorem 3.1 each have hypotheses that the page states. The sequence of Example 2.2 and Proposition 4.2 fails both monotonicity and an integrable bound, so neither theorem applies to it, but it does not show that either hypothesis is needed on its own. The other hypotheses are stated and are not tested here.

  • Monotonicity is a hypothesis of Theorem 2.1. Example 2.2 gives a sequence that is not non-decreasing, and Proposition 4.2 shows that its integrals and limit disagree. That sequence also fails domination (Proposition 4.1), so the example does not isolate monotonicity.
  • Domination must hold for every \(n\), with an integrable bound. Proposition 4.1 shows that no integrable bound exists for \(n \indic\{(0, 1/n]\}\). A bound that holds only for large \(n\), or one with infinite integral, is not enough for Theorem 3.1.
  • The stated hypotheses are pointwise and everywhere. The page uses convergence at every point. A version with convergence almost everywhere, meaning convergence except on a set of measure zero, is not stated or used here.
  • The dominated convergence theorem is not proved here. Theorem 3.1 is stated with its assumptions. The page uses its conclusion only as a consistency check in Example 3.2, where the value 2 is also computed from the antiderivative, under the assumption stated there.

6Misconceptions

  1. “If \(f_n \to f\) pointwise, then \(\int f_n \to \int f\).”

    Proposition 4.2 gives \(f_n = n \indic\{(0, 1/n]\}\), whose pointwise limit is zero and whose integrals are all 1. The interchange fails. Lab 4 prints the integrals and the zero pattern.

  2. “Monotone convergence applies to every convergent sequence of functions.”

    Theorem 2.1 needs the sequence to be non-decreasing. Example 2.2 shows that \(f_1 \le f_2\) fails for the sequence of Proposition 4.2, so the theorem does not apply to it.

  3. “A dominating function must be bounded.”

    Example 3.2 uses \(g = x^{-1/2}\), which is unbounded on \((0, 1]\) but has integral 2. It dominates \(\min(n, x^{-1/2})\) for every \(n\), and Theorem 3.1 applies under the assumption of Example 3.2. The integrals are \(2 - 1/n\) by the calculus antiderivative, under the assumption of Example 3.2, and they tend to 2.

Mechanics

M1 · Values of \(f_5\)

For \(f_5 = 5 \indic\{(0, 1/5]\}\), find \(\int f_5 \, d\lambda\), \(f_5(1/3)\) and \(f_5(1/7)\).

Solution

The integral is \(5 \cdot (1/5) = 1\). The point \(1/3\) is not in \((0, 1/5]\), since \(1/3 > 1/5\), so \(f_5(1/3) = 0\). The point \(1/7\) is in \((0, 1/5]\), since \(1/7 < 1/5\), so \(f_5(1/7) = 5\).

M2 · A non-decreasing sequence

Let \(g_n = 1 - x^n\) on \([0, 1]\). Show that the sequence is non-decreasing, compute \(\int g_n \, d\lambda\), and find the limit of the integrals.

Solution

For \(x\) in \([0, 1]\), \(x^n\) is non-increasing in \(n\), so \(1 - x^n\) is non-decreasing. The integral is \(\int_0^1 (1 - x^n) \, dx = 1 - 1/(n+1) = n/(n+1)\), which tends to 1. The pointwise limit is 1 on \([0, 1)\) and 0 at \(x = 1\), a simple function whose integral is \(1 \cdot \lambda([0, 1)) = 1\). Theorem 2.1 gives the same limit.

M3 · A capped power

Compute \(\int_0^1 \min(2, x^{-1/2}) \, dx\).

Solution

The minimum equals 2 when \(x^{-1/2} \ge 2\), that is, when \(x \le 1/4\). The calculus antiderivative is used for the second piece only, under the same assumption as Example 3.2. So the integral is \(2 \cdot (1/4) + \int_{1/4}^{1} x^{-1/2} \, dx = 1/2 + (2 - 1) = 3/2\), using the antiderivative \(2\sqrt{x}\), which gives \(2 - 2 \cdot (1/2) = 1\) on \([1/4, 1]\).

Proof

P1 · The limit is measurable

Under the assumptions of Theorem 2.1, prove that \(f = \sup_n f_n\) is measurable, using only the definition of measurability.

Solution

For real \(t\), \(f(\omega) > t\) if and only if \(f_n(\omega) > t\) for some \(n\), since a supremum exceeds \(t\) exactly when some term does. So \(\{f > t\} = \bigcup_n \{f_n > t\}\), a countable union of events. Axiom (S3) of Lesson 1, Definition 1.1, shows that this union is an event.

P2 · The sets \(E_n\) increase to \(\Omega\)

In the proof of Theorem 2.1, show that for a simple \(s\) with \(0 \le s \le f\) and \(0 < c < 1\), every \(\omega\) lies in \(E_n = \{f_n \ge cs\}\) for all large \(n\).

Solution

If \(s(\omega) = 0\), then \(f_n(\omega) \ge 0 = c s(\omega)\) for every \(n\). If \(s(\omega) = a > 0\), then \(f(\omega) \ge a > ca\). Since \(f(\omega) = \sup_n f_n(\omega) > ca\), some \(f_N(\omega) > ca\). The sets \(E_n\) increase, so \(\omega \in E_n\) for every \(n \ge N\).

P3 · The grouping bound

For \(m \ge 1\), prove \(\sum_{k=2}^{2^m} 1/k \ge m/2\).

Solution

Split \(\{2, \dots, 2^m\}\) into the blocks \(\{2^{j-1}+1, \dots, 2^j\}\) for \(j = 1, \dots, m\). These blocks partition the set. Block \(j\) has \(2^{j-1}\) terms, and each term is at least \(1/2^j\), so the block sum is at least \(2^{j-1}/2^j = 1/2\). Adding the \(m\) blocks gives at least \(m/2\).

Empirical

E1 · The integrals of \(f_n\)

Lab 4 Part A prints True for the claim that every integral from \(n = 1\) to \(20\) equals 1. Derive the value for each \(n\) by hand, and say what the printed line does not establish.

Solution

Each \(f_n\) has value \(n\) on an interval of length \(1/n\), so its integral is \(n \cdot (1/n) = 1\) for every \(n\). The printed line checks only \(n\) up to 20. The general claim for every \(n\) is Proposition 4.2(a), which the proof above gives for all \(n\).

E2 · The zero pattern at \(x = 1/5\)

Lab 4 prints the values \(1, 2, 3, 4, 5, 0, 0, 0\) for \(f_n(1/5)\), \(n\) from 1 to 8. Explain why the value is \(n\) up to \(n = 5\) and zero from \(n = 6\).

Solution

The value \(f_n(1/5)\) is \(n\) exactly when \(1/5 \le 1/n\), that is, when \(n \le 5\). For \(n = 6\), \(1/5 > 1/6\), so \(1/5\) lies outside \((0, 1/6]\) and the value is zero. The first zero is \(6 = \lfloor 5 \rfloor + 1\), which is the pattern the lab checks.

E3 · The partial sum for \(N = 10\)

Before running Lab 4, compute \(\sum_{n=1}^{10} 1/(n+1)\) to six decimals.

Solution

The sum is \(1/2 + 1/3 + 1/4 + \cdots + 1/11\). Adding the terms gives \(2.019877\) to six decimals. Lab 4 prints the same value, and it prints the value for \(N = 100\) as 4.197279.

Research

R1 · An inference that fails

A reader argues: each \(\int f_n\) equals 1, so \(\int \lim f_n\) must equal 1. Identify the error and state which hypothesis of Theorem 2.1 or Theorem 3.1 the sequence fails.

Solution

The argument assumes that the limit of the integrals equals the integral of the limit, which is the interchange that fails here. The limit of the integrals is 1, but the pointwise limit is zero, with integral zero. The sequence is not non-decreasing (Example 2.2), so Theorem 2.1 does not apply, and no integrable bound exists (Proposition 4.1), so Theorem 3.1 does not apply.

R2 · A sequence where domination holds

Let \(f_n = n \indic\{(0, 1/n^2]\}\) on \((0, 1]\). Show that \(\int f_n \, d\lambda = 1/n \to 0\), that \(f_n \to 0\) pointwise, and that the function \(g(x) = \lfloor x^{-1/2} \rfloor\) dominates every \(f_n\) with finite integral. State what Theorem 3.1 then gives.

Solution

The integral is \(n \cdot (1/n^2) = 1/n\). For fixed \(x > 0\), \(f_n(x) = 0\) once \(n^2 > 1/x\), so the limit is zero. If \(f_n(x) = n\), then \(x \le 1/n^2\), so \(x^{-1/2} \ge n\) and \(g(x) \ge n\). Hence \(g \ge f_n\). The value \(g(x) = n\) holds on \((1/(n+1)^2, 1/n^2]\), which has length \((2n+1)/(n^2(n+1)^2)\), so \(\int g = \sum_n (2n+1)/(n(n+1)^2)\). Each term is at most \(3/n^2\), so the sum is finite. Theorem 3.1, as stated and not proved in this lesson, then gives \(\int f_n \to 0\), which agrees with \(1/n \to 0\).

R3 · Why Proposition 4.1 covers every \(g\)

Explain why proving that no dominating function has finite integral needs an argument that applies to every \(g\), and identify the only property of \(g\) that the proof uses.

Solution

A claim that no \(g\) exists must rule out every candidate, so the argument cannot test one particular \(g\). The proof uses the inequality \(g \ge n\) on the interval \((1/(n+1), 1/n]\), which follows from \(g \ge f_n\), and the measurability of \(g\) that makes \(\int g\) defined. Every dominating \(g\) must satisfy that inequality, so its integral is at least the divergent sum.
