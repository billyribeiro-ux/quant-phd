A trader who stops after a loss, or an algorithm that stops when a signal first appears, chooses a time that depends on what has already happened. Lesson L10 asks whether a martingale keeps its expected value under such a choice. The answer depends on which choices are allowed, so this lesson first fixes the class of allowed times. A stopping time is a random time that can be recognised as having occurred from the information available at that time. The lesson proves that this class is closed under the operations that later proofs need, and it shows with a lab that a rule which reads one step ahead is excluded.

1Random times and what is known at each time

Let \((\Omega,\mathcal F,\Prob)\) be a probability space (L02), and let \((\mathcal F_k)_{k\ge 0}\) be a filtration (L08; L08 defines filtrations over a finite horizon, and here the index runs over all \(k\ge 0\) with the same definition), so that \(\mathcal F_0\subseteq \mathcal F_1\subseteq\cdots\subseteq\mathcal F\). The event \(A\in\mathcal F_k\) is the set of outcomes for which the information available at time \(k\) settles whether \(A\) has occurred. A random time is a function \(\tau:\Omega\to\{0,1,2,\ldots\}\cup\{\infty\}\), so \(\tau(\omega)\) is the time at which the path \(\omega\) reaches the event of interest, with \(\infty\) meaning never.

Definition 9.1 (stopping time)

A random time \(\tau\) is a stopping time if \(\{\tau\le k\}\in\mathcal F_k\) for every whole number \(k\ge 0\). In words, by time \(k\) the information in \(\mathcal F_k\) settles whether \(\tau\) has already happened.

Remark 9.2 (the event that the time is exactly k)

The definition may equivalently require \(\{\tau=k\}\in\mathcal F_k\) for every \(k\). Given that, \(\{\tau\le k\}=\bigcup_{j\le k}\{\tau=j\}\) is a finite union of sets in \(\mathcal F_j\subseteq\mathcal F_k\), so it lies in \(\mathcal F_k\). Conversely, Lemma 9.7 shows that a stopping time has \(\{\tau=k\}\in\mathcal F_k\). The two forms are therefore equivalent, and the proofs below use both.

Example 9.3 (a fixed time)

For a whole number \(n\ge 0\), the constant random time \(\tau\equiv n\) is a stopping time. For \(k\ge n\), \(\{\tau\le k\}=\Omega\in\mathcal F_k\). For \(k<n\), \(\{\tau\le k\}=\emptyset\in\mathcal F_k\). Both sets lie in every \(\sigma\)-algebra, so the definition holds at every \(k\).

2Hitting times of an adapted process

The most common stopping time is the first time a process enters a set. Here a process \(X=(X_k)_{k\ge 0}\) is a sequence of random variables, and it is adapted to the filtration when each \(X_k\) is known at time \(k\): for every whole number \(b\), the event \(\{X_k=b\}\) lies in \(\mathcal F_k\). This is the event form of the adaptedness in L08, Definition 1.1, written for integer values.

Example 9.4 (the fair walk and its natural filtration)

Let \(X_1,X_2,\ldots\) be independent steps, each equal to \(+1\) or \(-1\) with probability \(1/2\). Let \(S_0=0\) and \(S_k=X_1+\cdots+X_k\). The natural filtration \(\mathcal F_k=\sigma(X_1,\ldots,X_k)\) is the one L08 uses for the fair walk. The process \(S\) is adapted to it, because \(S_k\) is a function of \(X_1,\ldots,X_k\). Let \(\tau\) be the first time the walk equals \(+1\), with \(\tau=\infty\) if it never does. Proposition 9.5 shows that \(\tau\) is a stopping time.

Proposition 9.5 (hitting times are stopping times)
  1. \((\Omega,\mathcal F,\Prob)\) is a probability space, and \((\mathcal F_k)_{k\ge 0}\) is a filtration.
  2. \(Y=(Y_k)_{k\ge 0}\) is an integer-valued process adapted to \((\mathcal F_k)\), so \(\{Y_k=b\}\in\mathcal F_k\) for every whole number \(k\ge 0\) and every integer \(b\).
  3. \(B\) is a set of integers, and \(\tau_B=\inf\{k\ge 0: Y_k\in B\}\), with \(\inf\emptyset=\infty\).

Then \(\tau_B\) is a stopping time.

Proof

Fix \(k\ge 0\). The process reaches \(B\) by time \(k\) exactly when \(Y_j\in B\) for some \(j\le k\), so \(\{\tau_B\le k\}=\bigcup_{j=0}^{k}\{Y_j\in B\}\). Each set \(\{Y_j\in B\}\) is the countable union \(\bigcup_{b\in B}\{Y_j=b\}\) (hypothesis 2 and the fact that \(B\) is a set of integers). Each \(\{Y_j=b\}\) lies in \(\mathcal F_j\), and \(\mathcal F_j\subseteq\mathcal F_k\) because \(j\le k\) and the filtration increases. So each \(\{Y_j\in B\}\) lies in \(\mathcal F_k\), and so does the finite union \(\{\tau_B\le k\}\). Since \(k\) was arbitrary, \(\tau_B\) is a stopping time.

For the fair walk, Proposition 9.5 with \(B=\{1\}\), applied with \(Y=S\), shows that the first time \(S\) equals \(+1\) is a stopping time for the natural filtration. Lab 1 checks the definition on every path of an 8-step walk, and it also tests a rule that the definition excludes.

Lab 1 · Stopping times for the fair walk, checked on all 256 paths

The lab enumerates the \(2^8=256\) step sequences of an 8-step fair walk, each with probability \(1/256\), and computes every probability as an exact fraction. Part A prints, for each \(k\) from 0 to 8, the number of paths on which the walk has reached \(+1\) by time \(k\), and checks that this event depends only on the first \(k\) steps. Part B runs the same check on a rule that reads step \(k+1\) at time \(k\). Proposition 9.5 predicts that Part A passes at every \(k\), and the definition predicts that Part B fails. Part C checks that the first-hit probabilities add up to the probability of reaching \(+1\) by time 8.

"""M6 L09 lab 1: stopping times for a fair walk on a finite horizon.

The sample space is the set of all 2**N sequences of +1 and -1 steps, N = 8, each sequence with probability
1/256. Every probability is an exact fractions.Fraction. Steps are X_1, ..., X_N and S_k = X_1 + ... + X_k.

Part A: the hitting time tau of level +1, the first k with S_k = +1, or None when S_k never equals +1 by N.
For each k from 0 to N it prints the number of paths with tau <= k and the probability, and it checks that the
event {tau <= k} depends only on the first k steps. On a finite space an event is determined by the first k steps
exactly when its indicator is the same for every two paths that agree on those steps.

Part B: a rule that reads one step ahead, tau_ahead = the first k from 0 to N-1 with step k+1 equal to +1. The
same test is run on {tau_ahead <= k}, and it fails at k = 0, because that event depends on step 1.

Part C: the exact identity P(tau = 1) + ... + P(tau = N) = P(tau <= N), checked with Fractions.
"""

from __future__ import annotations

import itertools
from collections.abc import Callable
from fractions import Fraction

N = 8
PATHS: tuple[tuple[int, ...], ...] = tuple(itertools.product((-1, 1), repeat=N))
WEIGHT = Fraction(1, len(PATHS))


def hitting_time(path: tuple[int, ...]) -> int | None:
    """The first k from 1 to N with S_k equal to +1, or None when S_k never equals +1 up to N."""
    level = 0
    for k, step in enumerate(path, start=1):
        level += step
        if level == 1:
            return k
    return None


def lookahead_time(path: tuple[int, ...]) -> int | None:
    """The first k from 0 to N-1 with step k+1 equal to +1. It reads the future, so it is not a stopping time."""
    for k, step in enumerate(path):
        if step == 1:
            return k
    return None


def hit_by(rule: Callable[[tuple[int, ...]], int | None], k: int) -> Callable[[tuple[int, ...]], bool]:
    """The event {rule <= k} as a function of the path, false when the rule never fires."""

    def event(path: tuple[int, ...]) -> bool:
        value = rule(path)
        return value is not None and value <= k

    return event


def depends_on_first(event: Callable[[tuple[int, ...]], bool], k: int) -> bool:
    """True when the event's indicator is the same for every two paths that agree on their first k steps."""
    seen: dict[tuple[int, ...], bool] = {}
    for path in PATHS:
        value = event(path)
        if seen.setdefault(path[:k], value) != value:
            return False
    return True


def _first_hit_at(k: int) -> Callable[[tuple[int, ...]], bool]:
    """The event that the first hitting time of +1 is exactly k."""

    def event(path: tuple[int, ...]) -> bool:
        return hitting_time(path) == k

    return event


def probability(event: Callable[[tuple[int, ...]], bool]) -> Fraction:
    """The exact probability of the event under the uniform weight on the 2**N paths."""
    return WEIGHT * sum(1 for path in PATHS if event(path))


def main() -> None:
    """Print Parts A, B and C. Every line is an exact count, a float printed to ten places (exact here, because every
    probability is a dyadic fraction), or a boolean."""
    print("Part A: hitting time of level +1 by the fair walk, N = 8")
    all_known = True
    for k in range(N + 1):
        event = hit_by(hitting_time, k)
        known = depends_on_first(event, k)
        all_known = all_known and known
        count = sum(1 for path in PATHS if event(path))
        print(f"k {k} paths_hit_by_k {count} probability {float(probability(event)):.10f} known_by_first_k {known}")
    print(f"hitting_time_is_stopping_time {all_known}")

    print("Part B: a rule that reads the next step")
    failing = [k for k in range(N + 1) if not depends_on_first(hit_by(lookahead_time, k), k)]
    print(f"lookahead_failing_k {failing}")
    print(f"lookahead_is_stopping_time {not failing}")

    print("Part C: the hitting-time probabilities add up to P(tau <= N)")
    total = sum((probability(_first_hit_at(k)) for k in range(1, N + 1)), Fraction(0))
    print(f"sum_of_first_hit_probabilities {float(total):.10f}")
    print(f"sum_equals_P_tau_at_most_N {total == probability(hit_by(hitting_time, N))}")


main()

Part A passes the test at every \(k\) from 0 to 8, which is what Proposition 9.5 predicts for this walk. The counts are exact: 128 of 256 paths have reached \(+1\) by time 1, and 186 by time 8, a probability of 0.7265625. Part B's look-ahead rule fails at every \(k\) from 0 to 7. At \(k=8\) its event depends on all 8 steps, so the test can pass there, and that pass says nothing about the rule's behaviour at earlier times. Part C shows that the first-hit probabilities add to the same 0.7265625. The lab uses a finite space, so it confirms the definition on these paths and proves nothing about the infinite walk; the proof is Proposition 9.5.

3Closure under minimum, maximum and shift

Proposition 9.6 (closure properties)
  1. \(\tau\) and \(\sigma\) are stopping times for the same filtration \((\mathcal F_k)\) on the probability space \((\Omega,\mathcal F,\Prob)\).
  2. Time is measured in whole numbers, and \(\infty+1=\infty\), \(\min(\tau,\infty)=\tau\).

Then \(\tau\wedge\sigma=\min(\tau,\sigma)\), \(\tau\vee\sigma=\max(\tau,\sigma)\) and \(\tau+1\) are stopping times.

Proof

Fix \(k\ge 0\). An outcome has \(\min(\tau,\sigma)\le k\) exactly when \(\tau\le k\) or \(\sigma\le k\), so \(\{\min(\tau,\sigma)\le k\}=\{\tau\le k\}\cup\{\sigma\le k\}\). Each set on the right lies in \(\mathcal F_k\), and \(\mathcal F_k\) is closed under finite unions, so the left side lies in \(\mathcal F_k\). Next, \(\max(\tau,\sigma)\le k\) exactly when both \(\tau\le k\) and \(\sigma\le k\), so \(\{\max(\tau,\sigma)\le k\}=\{\tau\le k\}\cap\{\sigma\le k\}\in\mathcal F_k\), because \(\mathcal F_k\) is closed under finite intersections. For the shift, \(\{\tau+1\le 0\}=\emptyset\in\mathcal F_0\). For \(k\ge 1\), \(\tau+1\le k\) exactly when \(\tau\le k-1\), so \(\{\tau+1\le k\}=\{\tau\le k-1\}\in\mathcal F_{k-1}\subseteq\mathcal F_k\). In each case the event lies in \(\mathcal F_k\), and \(k\) was arbitrary.

Proposition 9.6 with \(\sigma\equiv N\), a constant time, which is a stopping time by Example 9.3, shows that \(\tau\wedge N\) is a stopping time for every whole number \(N\ge 0\).

Lemma 9.7 (events about the time itself)
  1. \((\Omega,\mathcal F,\Prob)\) is a probability space, and \((\mathcal F_k)_{k\ge 0}\) is a filtration on it.
  2. \(\tau\) is a stopping time for \((\mathcal F_k)\), and \(k\ge 0\) is a whole number.

Then \(\{\tau>k\}\in\mathcal F_k\) and \(\{\tau=k\}\in\mathcal F_k\).

Proof

The complement of \(\{\tau\le k\}\) is \(\{\tau>k\}\). Since \(\{\tau\le k\}\in\mathcal F_k\) and \(\mathcal F_k\) is closed under complements, \(\{\tau>k\}\in\mathcal F_k\). For the second claim, \(\{\tau=k\}=\{\tau\le k\}\setminus\{\tau\le k-1\}\) when \(k\ge 1\), and \(\{\tau=0\}=\{\tau\le 0\}\) when \(k=0\). The set \(\{\tau\le k-1\}\) lies in \(\mathcal F_{k-1}\subseteq\mathcal F_k\), so both sets in the difference lie in \(\mathcal F_k\), and so does the difference.

4Where the canon breaks

  • A rule that reads the future is not a stopping time. Part B of Lab 1 tests the rule "stop at the step before the first \(+1\)". At time \(k\) it needs step \(k+1\), which is not known at time \(k\). The check fails at every \(k\) from 0 to 7.
  • A stopping time depends on the filtration. Take the first time \(\tau\) that the fair walk equals \(+1\), and the trivial filtration \(\mathcal F_k=\{\emptyset,\Omega\}\) for every \(k\). Then \(\{\tau\le 1\}=\{X_1=1\}\) is neither \(\emptyset\) nor \(\Omega\), so \(\tau\) is not a stopping time for that filtration, though it is one for the natural filtration of Example 9.4.
  • A stopping time need not be bounded. The rule "stop at the first \(+1\)" has \(\tau=\infty\) on the path that never reaches \(+1\). No single \(N\) satisfies \(\tau\le N\) on every path. L10 needs this boundedness, and the closure in Proposition 9.6 does not supply it.

5Misconceptions

  1. “Any time that depends on the whole path is a stopping time, because it is a function of the outcome.”

    Being a function of the outcome is not enough. Definition 9.1 asks that \(\{\tau\le k\}\in\mathcal F_k\) at each \(k\), which fixes what may be used at time \(k\). Part B of Lab 1 gives a rule that is a perfectly good function of the path and fails the test at each \(k\) from 0 to 7, because it uses step \(k+1\) at time \(k\).

  2. “The first hitting time of a level is a stopping time whatever the filtration.”

    Proposition 9.5 needs the process to be adapted to the filtration. Example 9.4 uses the natural filtration. With the trivial filtration, the first time the walk equals \(+1\) fails the definition at \(k=1\), because \(\{\tau\le 1\}=\{X_1=1\}\) is not in \(\{\emptyset,\Omega\}\).

  3. “A stopping time that is finite on each path is bounded, so it can be used wherever a bounded time can.”

    Finiteness on each path gives no common bound. For the first time the walk equals \(+1\), the paths with \(m\) steps of \(-1\) followed by \(m+1\) steps of \(+1\) give \(\tau=2m+1\), which is finite on each such path. These values have no upper bound as \(m\) grows. L10 requires \(\tau\le N\) for one fixed \(N\), which is a stronger condition than finiteness.

Mechanics

M1 · The hitting time of +1 for a 3-step walk

For a fair walk with steps \(X_1,X_2,X_3\), let \(\tau\) be the first \(k\le 3\) with \(S_k=+1\), and \(\tau=\infty\) otherwise. Find \(\Prob(\tau=1)\), \(\Prob(\tau=3)\), and \(\Prob(\tau\le 2)\).

Solution

Four of the eight paths have \(X_1=+1\), so \(S_1=+1\) and \(\tau=1\). Thus \(\Prob(\tau=1)=1/2\). If \(X_1=-1\), then \(S_2\in\{-2,0\}\), and \(S_2=+1\) is impossible, so \(\tau\ne 2\). Hence \(\Prob(\tau\le 2)=1/2\). The only path with \(\tau=3\) is \((-1,+1,+1)\), which gives \(S_1=-1\), \(S_2=0\), \(S_3=+1\). So \(\Prob(\tau=3)=1/8\). Check: \(\Prob(\tau\le 3)=5/8=0.625\), which matches the \(k=3\) row of Part A of Lab 1, where 160 of 256 paths have reached \(+1\) by time 3. The same value holds for horizon 4, because \(S_4\) is even, so no path first reaches \(+1\) at time 4 and \(\Prob(\tau\le 4)=\Prob(\tau\le 3)\).

M2 · A constant time is a stopping time

Show that the constant random time \(\tau\equiv 5\) is a stopping time for any filtration \((\mathcal F_k)\).

Solution

Example 9.3 applies with \(n=5\). For \(k\ge 5\), \(\{\tau\le k\}=\Omega\) and \(\Omega\in\mathcal F_k\). For \(k\le 4\), \(\{\tau\le k\}=\emptyset\) and \(\emptyset\in\mathcal F_k\). The two cases cover every \(k\ge 0\), so \(\tau\) satisfies Definition 9.1.

M3 · The minimum of a stopping time and a constant

Let \(\tau\) be a stopping time and \(N=3\). Show that \(\tau\wedge 3\) is a stopping time, and find \(\{\tau\wedge 3\le 1\}\) in terms of \(\tau\).

Solution

The constant \(3\) is a stopping time by Example 9.3, so Proposition 9.6 with \(\sigma\equiv 3\) gives that \(\tau\wedge 3\) is a stopping time. For the event, \(\tau\wedge 3\le 1\) holds exactly when \(\tau\le 1\) or \(3\le 1\). The second is false, so \(\{\tau\wedge 3\le 1\}=\{\tau\le 1\}\), which lies in \(\mathcal F_1\) by Definition 9.1.

P1 · The shift in Proposition 9.6

Prove that \(\tau+1\) is a stopping time when \(\tau\) is one, including the case \(\tau=\infty\).

Solution

Fix \(k\ge 0\). If \(k=0\), \(\{\tau+1\le 0\}\) is empty, since \(\tau+1\ge 1\), so the event is in \(\mathcal F_0\). If \(k\ge 1\), an outcome has \(\tau+1\le k\) exactly when \(\tau\le k-1\), so \(\{\tau+1\le k\}=\{\tau\le k-1\}\). The set \(\{\tau\le k-1\}\) lies in \(\mathcal F_{k-1}\), which is contained in \(\mathcal F_k\) because the filtration increases. For \(\tau=\infty\), both \(\tau+1\le k\) and \(\tau\le k-1\) are false, so the identity covers that case too.

P2 · The first-passage event of a hitting time

Let \(\tau\) be the hitting time of Proposition 9.5 with \(B=\{1\}\), applied with \(Y=S\). Show that \(\{\tau=k\}=\{S_k=1\}\cap\bigcap_{j<k}\{S_j\ne 1\}\), and deduce that \(\{\tau=k\}\in\mathcal F_k\).

Solution

The first time the walk equals \(1\) is \(k\) exactly when \(S_k=1\) and no earlier \(S_j\) equals \(1\), which is the displayed intersection. Each \(\{S_j\ne 1\}\) is the complement of \(\{S_j=1\}\), which lies in \(\mathcal F_j\subseteq\mathcal F_k\) for \(j\le k\), and \(\{S_k=1\}\in\mathcal F_k\) by adaptedness. A finite intersection of events in \(\mathcal F_k\) lies in \(\mathcal F_k\), so \(\{\tau=k\}\in\mathcal F_k\). This is also Lemma 9.7.

P3 · The step of Proposition 9.6 that uses the filtration's growth

Identify the single inclusion in the proof of Proposition 9.6 that uses the fact that the filtration increases, and state which events it moves from one \(\sigma\)-algebra into another.

Solution

It is the step for the shift. For \(k\ge 1\), \(\{\tau+1\le k\}=\{\tau\le k-1\}\), which lies in \(\mathcal F_{k-1}\) by Definition 9.1 applied at time \(k-1\). The inclusion \(\mathcal F_{k-1}\subseteq\mathcal F_k\) moves that event into \(\mathcal F_k\). The minimum and maximum use only that each \(\mathcal F_k\) is a \(\sigma\)-algebra, so they do not need monotonicity.

Empirical

E1 · Paths that have reached +1 by time 4

Read Part A of Lab 1. How many of the 256 paths have reached \(+1\) by time 4, and what is the probability? Why does the count equal the count at time 3?

Solution

Part A prints 160 paths at \(k=4\), so the probability is \(160/256=0.625\). The count at \(k=3\) is also 160. No path is added at time 4 because the walk has the parity of its time: \(S_k\) is a sum of \(k\) steps of \(\pm 1\), so \(S_4\) is even and cannot equal \(+1\). A path can therefore first reach \(+1\) only at an odd time.

E2 · Paths that never reach +1 by time 8

Using Part A of Lab 1, how many of the 256 paths never reach \(+1\) by time 8, and what is their probability?

Solution

Part A prints 186 paths that have reached \(+1\) by time 8. The rest number \(256-186=70\), so their probability is \(70/256=0.2734375\). The printed probability 0.7265625000 and this value are both exact, since 186/256 and 70/256 are dyadic fractions with finite decimal expansions.

E3 · The first-hit identity in Part C

Part C of Lab 1 prints that the first-hit probabilities add to \(\Prob(\tau\le N)\). Explain why this identity holds for every horizon \(N\), and state what the printed check verifies.

Solution

The events \(\{\tau=k\}\) for \(k=1,\ldots,N\) are disjoint and their union is \(\{\tau\le N\}\), because \(\tau\) takes one value on each path. So the probabilities add to \(\Prob(\tau\le N)\). The printed line sum_equals_P_tau_at_most_N True checks this identity exactly with Fractions for \(N=8\). The check confirms the bookkeeping of the lab's counts. It does not test the stopping-time property, which Part A and Proposition 9.5 address.

Research

R1 · The look-ahead rule and the definition

Let \(\rho\) be the rule "stop at the step before the first \(+1\)", so \(\rho=k\) when step \(k+1\) is the first \(+1\) step. Show that \(\{\rho\le 0\}\) is not in \(\mathcal F_0\) for the natural filtration, and so \(\rho\) is not a stopping time.

Solution

Under the rule, \(\rho\le 0\) means \(\rho=0\), which happens exactly when step 1 is \(+1\). So \(\{\rho\le 0\}=\{X_1=+1\}\). The natural filtration has \(\mathcal F_0=\{\emptyset,\Omega\}\), since \(\sigma(\,)\) is trivial. The event \(\{X_1=+1\}\) is neither empty nor all of \(\Omega\), so it is not in \(\mathcal F_0\), and Definition 9.1 fails at \(k=0\). This matches Part B of Lab 1, which fails at \(k=0\).

R2 · Stopping times for the trivial filtration are constant

Suppose \(\mathcal F_k=\{\emptyset,\Omega\}\) for every \(k\ge 0\). Show that every stopping time is a constant random time, meaning that \(\tau\) takes one value \(c\in\{0,1,\ldots\}\cup\{\infty\}\) on every outcome.

Solution

For each \(k\), \(\{\tau\le k\}\) is \(\emptyset\) or \(\Omega\). The sets \(\{\tau\le k\}\) increase with \(k\). Let \(c\) be the least \(k\) with \(\{\tau\le k\}=\Omega\), or \(c=\infty\) if there is none. For \(k<c\), \(\{\tau\le k\}\) is not \(\Omega\), so it is \(\emptyset\). If \(c=\infty\), every \(\{\tau\le k\}\) is empty, so \(\tau=\infty\) on every outcome. If \(c<\infty\), take an outcome \(\omega\). If \(\tau(\omega)<c\), then \(\omega\in\{\tau\le\tau(\omega)\}\), which is empty, a contradiction; so \(\tau(\omega)\ge c\). Also \(\omega\in\{\tau\le c\}=\Omega\), so \(\tau(\omega)\le c\). Hence \(\tau=c\) on every outcome, and \(\tau\) is constant.

R3 · The minimum of two stopping times is bounded by each

Let \(\tau\) and \(\sigma\) be stopping times. Show that \(\{\tau\wedge\sigma>k\}=\{\tau>k\}\cap\{\sigma>k\}\), and deduce from Lemma 9.7 that this event lies in \(\mathcal F_k\).

Solution

The minimum exceeds \(k\) exactly when both times exceed \(k\), which gives the identity. By Lemma 9.7, \(\{\tau>k\}\in\mathcal F_k\) and \(\{\sigma>k\}\in\mathcal F_k\). A finite intersection of events in \(\mathcal F_k\) lies in \(\mathcal F_k\), so \(\{\tau\wedge\sigma>k\}\in\mathcal F_k\). This is the complement form of the closure in Proposition 9.6.

  1. Which condition makes a random time \(\tau\) a stopping time for the filtration \((\mathcal F_k)\)?

    Options

    Definition 9.1. A bound on \(\tau\) is a different property (§4), and a function of the path is not enough without measurability at each time (misconception 1).

  2. In Part A of Lab 1, 160 of 256 paths have reached \(+1\) by time 4. What is the probability, as a decimal?

    \(160/256=0.625\), the \(k=4\) row of Part A (Problem E1).

  3. Is the constant random time \(\tau\equiv 5\) a stopping time?

    Options

    Example 9.3 and Problem M2. Constant times satisfy the definition for any filtration.

  4. A rule stops at the step before the first \(+1\), so at time \(k\) it uses step \(k+1\). Is it a stopping time?

    Options

    Part B of Lab 1 fails the test at every \(k\) from 0 to 7 (Problem R1).

  5. In Part A of Lab 1, how many of the 256 paths have never reached \(+1\) by time 8?

    \(256-186=70\), using the \(k=8\) row (Problem E2).

  6. If \(\tau\) and \(\sigma\) are stopping times, which of these is also a stopping time?

    Options

    Proposition 9.6 gives the minimum, the maximum and the shift \(\tau+1\). The shift \(\tau-1\) is not in the list.

  7. Under the trivial filtration \(\mathcal F_k=\{\emptyset,\Omega\}\) for all \(k\), which random times are stopping times?

    Options

    Problem R2 shows that a stopping time is constant for this filtration, and Example 9.3 shows constants qualify.

  8. For the fair walk, what is the probability that the first time the walk equals \(+1\) is exactly time 3?

    Only the path \((-1,+1,+1)\) gives \(\tau=3\), so the probability is \(1/8=0.125\) (Problem M1).

  9. Which event is in \(\mathcal F_k\) for every stopping time \(\tau\) and every \(k\ge 0\)?

    Options

    Lemma 9.7. The events \(\{\tau=k\}\) and \(\{\tau>k\}\) lie in \(\mathcal F_k\), and \(\{\tau>k\}=\{\tau\ge k+1\}\). The event \(\{\tau=k+1\}\) need not lie in \(\mathcal F_k\), even when \(\tau\) is bounded.
