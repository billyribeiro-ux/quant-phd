Robust Implied-Volatility Solver

A quantitative volatility desk requires an implied-volatility solver for European call and put options that never fails on any valid market quote, including deep in-the-money, deep out-of-the-money, and ultra-short expiry contracts. Fixed-bracket bisection solvers fail when extreme quotes require volatilities exceeding their arbitrary upper boundaries, while naive Newton-Raphson iterations diverge or encounter zero-division when vega underflows. In this project you author solver.py to implement dynamic bracket expansion coupled with safeguarded Newton-Raphson acceleration, verify it against an automated test suite across 50 independent seeds on a grid of \(N = 2{,}000\) options per seed, and generate a failure-region report classifying conditioning regimes. All market inputs are generated (SIMULATED); no live quotes are used.

Lab 1 · Worked example: step-by-step robust implied-volatility inversion

A valid European call quote with \(S = 120\), \(K = 115\), \(\tau = 0.5\), \(r = 0.03\), and true \(\sigma^* = 0.28\) generates a market price \(C \approx 12.938942\). The solver validates that \(C\) lies strictly within \((S - K e^{-r\tau}, S)\), verifies root bracketing, and achieves convergence within 4 safeguarded Newton iterations with price residual \(|C(\hat{\sigma}) - C| \le 10^{-12} S\) and forward error \(|\hat{\sigma} - \sigma^*| \le 10^{-7}\).

"""Rung 1 worked example: step-by-step robust implied-volatility inversion (SIMULATED).

Standard library only. Inverts one European call option quote from the seeded test suite,
showing the no-arbitrage boundary check, dynamic bracket expansion, and safeguarded Newton steps.
"""

from __future__ import annotations

import math


def bs_price(spot: float, strike: float, tau: float, rate: float, vol: float, kind: str) -> float:
    sqrt_t = math.sqrt(tau)
    v_sqrt_t = vol * sqrt_t
    d1 = (math.log(spot / strike) + (rate + 0.5 * vol * vol) * tau) / v_sqrt_t
    d2 = d1 - v_sqrt_t
    disc = math.exp(-rate * tau)
    c1 = 0.5 * (1.0 + math.erf(d1 / math.sqrt(2.0)))
    c2 = 0.5 * (1.0 + math.erf(d2 / math.sqrt(2.0)))
    if kind == "call":
        return spot * c1 - strike * disc * c2
    else:
        return strike * disc * (1.0 - c2) - spot * (1.0 - c1)


def vega(spot: float, strike: float, tau: float, rate: float, vol: float) -> float:
    sqrt_t = math.sqrt(tau)
    d1 = (math.log(spot / strike) + (rate + 0.5 * vol * vol) * tau) / (vol * sqrt_t)
    return spot * sqrt_t * math.exp(-0.5 * d1 * d1) / math.sqrt(2.0 * math.pi)


def main() -> None:
    # Representative instance from make_instance(0)
    spot = 120.0
    strike = 115.0
    tau = 0.5
    rate = 0.03
    kind = "call"
    true_vol = 0.28
    price = bs_price(spot, strike, tau, rate, true_vol, kind)

    print("=== Rung 1: Step-by-Step Robust Implied Volatility Inversion ===")
    print(f"Option quote: S={spot}, K={strike}, tau={tau}, r={rate}, kind={kind}")
    print(f"Target market price: {price:.10f}")

    # Step 1: Strict no-arbitrage bounds check
    disc = math.exp(-rate * tau)
    lo = max(spot - strike * disc, 0.0)
    hi = spot
    print(f"\nStep 1: Bounds check. Lower={lo:.6f}, Upper={hi:.6f}")
    assert lo < price < hi, "Price violates strict no-arbitrage bounds"
    print("  Result: Valid interior quote strictly between theoretical bounds.")

    # Step 2: Dynamic bracket expansion
    a, b = 1e-4, 1.0
    fa = bs_price(spot, strike, tau, rate, a, kind) - price
    fb = bs_price(spot, strike, tau, rate, b, kind) - price
    print(f"\nStep 2: Initial bracket [{a:.4f}, {b:.4f}], f(a)={fa:.6f}, f(b)={fb:.6f}")

    while fa > 0.0 and a > 1e-15:
        b = a
        fb = fa
        a /= 4.0
        fa = bs_price(spot, strike, tau, rate, a, kind) - price

    while fb < 0.0 and b < 1e6:
        a = b
        fa = fb
        b *= 2.0
        fb = bs_price(spot, strike, tau, rate, b, kind) - price

    print(f"  Guaranteed root bracket: [{a:.6f}, {b:.6f}] with f(a)*f(b) <= 0")

    # Step 3: Safeguarded Newton-Raphson iteration
    print("\nStep 3: Safeguarded Newton iteration")
    sigma = 0.5 * (a + b)
    tol = 1e-12 * spot

    for step in range(1, 15):
        f = bs_price(spot, strike, tau, rate, sigma, kind) - price
        v = vega(spot, strike, tau, rate, sigma)
        print(f"  Iter {step:2d}: sigma={sigma:.10f}, f(sigma)={f:.2e}, vega={v:.4f}")

        if abs(f) <= tol:
            print(f"  Converged: residual |f| <= {tol:.2e}")
            break

        if f < 0.0:
            a = sigma
        else:
            b = sigma

        # Proposed Newton step
        sigma = sigma - f / v if v > 1e-14 and a < sigma - f / v < b else 0.5 * (a + b)

    v_final = vega(spot, strike, tau, rate, sigma)
    reg = "solved" if v_final >= 0.01 else "ill_conditioned"
    print("\nFinal Result:")
    print(f"  Solved volatility sigma_hat: {sigma:.12f}")
    print(f"  Generating true volatility:  {true_vol:.12f}")
    print(f"  Forward error |sigma - true|: {abs(sigma - true_vol):.2e}")
    print(f"  Final vega: {v_final:.4f} -> Region: {reg}")


main()

Lab 3 · Reference verification on the seeded grid

Running the reference solver across the seed 0 grid of \(N = 2{,}000\) options confirms that every valid quote satisfies the residual bound \(|C(\hat{\sigma}) - P| \le 10^{-12} \cdot S\) and partitions inputs into well-conditioned solved cases (\(\text{vega} \ge 0.01\)) and ill-conditioned cases (\(\text{vega} < 0.01\)).

"""Rung 3 independent project verification on seeded grid (SIMULATED).

Standard library only. Runs the reference solver on the seed 0 generated grid (N = 2,000)
and verifies accuracy bounds and prints failure-region report counts.
"""

from __future__ import annotations

import math
import random


def bs_price(spot: float, strike: float, tau: float, rate: float, vol: float, kind: str) -> float:
    sqrt_t = math.sqrt(tau)
    v_sqrt_t = vol * sqrt_t
    d1 = (math.log(spot / strike) + (rate + 0.5 * vol * vol) * tau) / v_sqrt_t
    d2 = d1 - v_sqrt_t
    disc = math.exp(-rate * tau)
    c1 = 0.5 * (1.0 + math.erf(d1 / math.sqrt(2.0)))
    c2 = 0.5 * (1.0 + math.erf(d2 / math.sqrt(2.0)))
    if kind == "call":
        return spot * c1 - strike * disc * c2
    else:
        return strike * disc * (1.0 - c2) - spot * (1.0 - c1)


def vega(spot: float, strike: float, tau: float, rate: float, vol: float) -> float:
    sqrt_t = math.sqrt(tau)
    d1 = (math.log(spot / strike) + (rate + 0.5 * vol * vol) * tau) / (vol * sqrt_t)
    return spot * sqrt_t * math.exp(-0.5 * d1 * d1) / math.sqrt(2.0 * math.pi)


def solve_implied_vol(price: float, spot: float, strike: float, tau: float, rate: float, kind: str) -> float:
    a, b = 1e-4, 2.0
    fa = bs_price(spot, strike, tau, rate, a, kind) - price
    fb = bs_price(spot, strike, tau, rate, b, kind) - price

    while fa > 0.0 and a > 1e-15:
        b = a
        fb = fa
        a /= 4.0
        fa = bs_price(spot, strike, tau, rate, a, kind) - price

    while fb < 0.0 and b < 1e6:
        a = b
        fa = fb
        b *= 2.0
        fb = bs_price(spot, strike, tau, rate, b, kind) - price

    sigma = 0.5 * (a + b)
    tol = 1e-13 * spot

    for _ in range(100):
        f = bs_price(spot, strike, tau, rate, sigma, kind) - price
        if abs(f) <= tol or (b - a) <= 1e-13 * max(1.0, sigma):
            break

        if f < 0.0:
            a = sigma
        else:
            b = sigma

        v = vega(spot, strike, tau, rate, sigma)
        sigma = sigma - f / v if v > 1e-14 and a < (sigma - f / v) < b else 0.5 * (a + b)

    return sigma


def bounds(spot: float, strike: float, tau: float, rate: float, kind: str) -> tuple[float, float]:
    disc = math.exp(-rate * tau)
    if kind == "call":
        lower = max(spot - strike * disc, 0.0)
        upper = spot
    else:
        lower = max(strike * disc - spot, 0.0)
        upper = strike * disc
    return lower, upper


def main() -> None:
    # Seed 0 grid generator
    rng = random.Random(1_000_003 * 0 + 42)
    n_target = 2000

    spots: list[float] = []
    strikes: list[float] = []
    taus: list[float] = []
    rates: list[float] = []
    kinds: list[str] = []
    prices: list[float] = []
    vols: list[float] = []
    vegas_list: list[float] = []
    while len(spots) < n_target:
        s = rng.uniform(40.0, 300.0)
        scenario = rng.choice(["near_expiry", "deep_itm", "deep_otm", "standard", "standard"])
        if scenario == "near_expiry":
            tau = rng.choice([1.0 / 365.0, 2.0 / 365.0, 7.0 / 365.0, 1.0 / 52.0])
            log_m = rng.uniform(-0.5, 0.5)
            vol = rng.uniform(0.05, 1.5)
        elif scenario == "deep_itm":
            tau = rng.uniform(0.1, 2.0)
            log_m = rng.uniform(1.0, 2.2)
            vol = rng.uniform(0.1, 2.5)
        elif scenario == "deep_otm":
            tau = rng.uniform(0.05, 1.5)
            log_m = rng.uniform(-2.2, -1.0)
            vol = rng.uniform(0.1, 2.0)
        else:
            tau = rng.uniform(0.1, 2.0)
            log_m = rng.uniform(-0.8, 0.8)
            vol = rng.uniform(0.05, 3.5)

        kind = rng.choice(["call", "put"])
        k = s * math.exp(-log_m)
        r = rng.uniform(0.01, 0.08)
        lo, hi = bounds(s, k, tau, r, kind)
        p = bs_price(s, k, tau, r, vol, kind)

        if p <= lo + 1e-8 * s or p >= hi - 1e-8 * s:
            continue

        v = vega(s, k, tau, r, vol)
        spots.append(s)
        strikes.append(k)
        taus.append(tau)
        rates.append(r)
        kinds.append(kind)
        prices.append(p)
        vols.append(vol)
        vegas_list.append(v)

    n_solved = 0
    n_ill = 0
    max_res = 0.0
    max_fwd_well_conditioned = 0.0

    for i in range(n_target):
        v_hat = solve_implied_vol(prices[i], spots[i], strikes[i], taus[i], rates[i], kinds[i])
        recalc = bs_price(spots[i], strikes[i], taus[i], rates[i], v_hat, kinds[i])
        res = abs(recalc - prices[i]) / spots[i]
        if res > max_res:
            max_res = res

        v_calc = vega(spots[i], strikes[i], taus[i], rates[i], v_hat)
        if v_calc >= 0.01:
            n_solved += 1
            fwd = abs(v_hat - vols[i])
            if fwd > max_fwd_well_conditioned:
                max_fwd_well_conditioned = fwd
        else:
            n_ill += 1

    print("=== Rung 3 Verification on Seed 0 Grid (N = 2,000) ===")
    print(f"Total processed instances: {n_target}")
    print(f"Solved (well-conditioned, vega >= 0.01): {n_solved}")
    print(f"Ill-conditioned (vega < 0.01):           {n_ill}")
    print(f"Max relative price residual:             {max_res:.2e} (bound: 1.00e-12)")
    print(f"Max forward error on solved instances:   {max_fwd_well_conditioned:.2e} (bound: 1.00e-07)")
    print(f"All residual bounds satisfied:           {max_res <= 1.0e-12}")

Specification

Context
A production volatility surface calibration pipeline requires an implied-volatility engine that evaluates millions of option quotes across multiple expiries and strikes. The solver must be unconditionally robust: it must never crash or enter an infinite loop on any input that satisfies theoretical no-arbitrage bounds, and it must detect and report ill-conditioned contracts where extreme moneyness or near-expiry conditions render vega too small for forward volatility accuracy.
Inputs
Each option inversion takes scalar inputs: price (float in currency units), spot \(S\) (positive finite float), strike \(K\) (positive finite float), tau \(\tau\) (positive finite float in years), rate \(r\) (finite float annualized continuously compounded risk-free rate), and kind (string "call" or "put"). All test cases are generated (SIMULATED) deterministically by make_instance(seed).
Required outputs
Deliver a single Python module solver.py exposing:
  • implied_vol(price: float, spot: float, strike: float, tau: float, rate: float, kind: str) -> float: returns the annualized implied volatility \(\hat{\sigma} > 0\).
  • region(price: float, spot: float, strike: float, tau: float, rate: float, kind: str) -> str: returns "solved" if the input is valid and \(\text{vega}(\hat{\sigma}) \ge 0.01\); returns "ill_conditioned" if the input is valid and \(\text{vega}(\hat{\sigma}) < 0.01\); raises ValueError on invalid inputs.
  • last_evaluations() -> int: returns the integer count of Black–Scholes pricing calls performed during the most recent invocation of implied_vol.
Constraints
  1. Input validation: ValueError must be raised if: kind is not "call" or "put"; spot, strike, or tau is not finite or \(\le 0\); rate is not finite; price is not finite; or price lies on or outside the strict theoretical no-arbitrage bounds: \[ \begin{aligned} \text{Call:}&\quad \max(S - K e^{-r\tau}, 0) < \text{price} < S \\ \text{Put:}&\quad \max(K e^{-r\tau} - S, 0) < \text{price} < K e^{-r\tau} \end{aligned} \]
  2. Residual accuracy bound: For every valid input, the returned volatility \(\hat{\sigma}\) must satisfy the residual pricing error bound: \[ |C_{\text{kind}}(\hat{\sigma}) - \text{price}| \le 10^{-12} \cdot S \]
  3. Forward accuracy bound: On well-conditioned inputs where \(\text{vega}(\sigma^*) \ge 0.01\), the forward error must satisfy: \[ |\hat{\sigma} - \sigma^*| \le 10^{-7} \]
  4. Dynamic bracket expansion: The solver must dynamically expand its search interval when high-volatility quotes exceed fixed thresholds (e.g. \(\sigma^* > 10\)).
  5. Evaluation budget: Inverting any quote on the seeded test grid must require at most \(B = 35\) Black–Scholes pricing calls.
  6. Determinism: Consecutive calls with identical arguments must yield bit-identical IEEE 754 floats. Standard library only; no external package dependencies.
