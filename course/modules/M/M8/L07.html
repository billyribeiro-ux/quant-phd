Variance Reduction: Antithetic and Control Variates

  • Uses: variance (M4), covariance and correlation (M4), Black–Scholes formula (FC2), Monte Carlo integration (L06)
  • Introduces: antithetic variates, control variates
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study or convention
  • Dlore
  • Xrefuted

Standard Monte Carlo simulation suffers from an agonizingly slow \(O(1/\sqrt{n})\) convergence rate: gaining a single decimal digit of pricing accuracy demands a hundredfold increase in computational paths. When pricing complex derivative portfolios under real-time risk constraints, raw brute-force simulation is computationally prohibitive. Variance reduction techniques exploit mathematical structure to shrink the underlying variance \(\sigma^2\) without biasing the expectation. Antithetic variates generate negatively correlated sample pairs by reflecting driving Gaussian shocks through the origin. Control variates leverage analytically tractable companion assets to soak up simulation noise. Together, these methods slash computational costs by orders of magnitude while preserving exact unbiasedness.

1The mathematics of variance reduction

Recall from Lesson 6 that the Monte Carlo estimator \(\hat{\theta}_n = \frac{1}{n} \sum_{i=1}^n Y_i\) has mean squared error \(\E[(\hat{\theta}_n - \theta)^2] = \Var(\hat{\theta}_n) = \frac{\sigma^2}{n}\). There are only two ways to reduce this error: increase the computational budget \(n\), or construct an alternative unbiased estimator with smaller intrinsic variance \(\sigma^2\).

Variance reduction methods modify the sampling scheme or payoff representation such that the simulated random variable has identical expectation \(\theta\) but substantially smaller variance \(\sigma_{\text{new}}^2 \ll \sigma^2\) (Glasserman 2003, Chapter 4).

2Antithetic variates

The method of antithetic variates introduces negative dependence between pairs of simulated paths while preserving identical marginal distributions.

Definition 2.1 (antithetic variates)

Let \(Y^{(1)} = g(U_1, \dots, U_d)\) be an evaluation of a payoff driven by independent uniform variates \(U_j \sim \text{Uniform}(0, 1)\). The antithetic variates estimator pairs \(Y^{(1)}\) with the reflection \(Y^{(2)} = g(1 - U_1, \dots, 1 - U_d)\). For standard Gaussian drivers \(Z \sim \mathcal{N}(0, I_d)\), the antithetic pair is \(Y^{(1)} = h(Z)\) and \(Y^{(2)} = h(-Z)\). The paired estimator from \(m = n/2\) independent pairs is:

\[ \hat{\theta}_{\text{anti}} = \frac{1}{m} \sum_{j=1}^m \frac{Y_j^{(1)} + Y_j^{(2)}}{2} \]

Theorem 2.2 (variance of antithetic estimator)

Assume \(Y^{(1)}\) and \(Y^{(2)}\) are identically distributed with mean \(\theta\) and finite variance \(\sigma^2\), having correlation \(\rho = \text{Corr}(Y^{(1)}, Y^{(2)})\). Then:

  1. \(\hat{\theta}_{\text{anti}}\) is strictly unbiased: \(\E[\hat{\theta}_{\text{anti}}] = \theta\).
  2. For an equal computational budget of \(n\) function evaluations (\(m = n/2\) pairs): \[ \Var(\hat{\theta}_{\text{anti}}) = \frac{\sigma^2}{n} (1 + \rho) \]
  3. The antithetic estimator achieves strictly smaller variance than crude Monte Carlo (\(\Var(\hat{\theta}_{\text{anti}}) < \Var(\hat{\theta}_{\text{crude}})\)) if and only if \(\rho < 0\).
Proof

Since \(Y^{(1)}\) and \(Y^{(2)}\) have identical marginal distributions, \(\E[\frac{1}{2}(Y^{(1)} + Y^{(2)})] = \frac{1}{2}(\theta + \theta) = \theta\), so \(\hat{\theta}_{\text{anti}}\) is unbiased. For a single pair \(\bar{Y} = \frac{1}{2}(Y^{(1)} + Y^{(2)})\):

\[ \Var(\bar{Y}) = \frac{1}{4} [2 \sigma^2 + 2 \rho \sigma^2] = \frac{\sigma^2}{2} (1 + \rho) \]

Averaging over \(m = n/2\) independent pairs gives \(\Var(\hat{\theta}_{\text{anti}}) = \frac{\Var(\bar{Y})}{m} = \frac{\frac{\sigma^2}{2}(1 + \rho)}{n/2} = \frac{\sigma^2}{n} (1 + \rho)\). Comparing with crude Monte Carlo variance \(\frac{\sigma^2}{n}\), the ratio is \(1 + \rho < 1 \iff \rho < 0\). \(\blacksquare\)

Proposition 2.3 (monotonicity guarantees negative correlation)

If \(h: \R^d \to \R\) is a coordinate-wise monotonic function (either non-decreasing or non-increasing in each argument), then for \(Z \sim \mathcal{N}(0, I_d)\), the antithetic pair \(h(Z)\) and \(h(-Z)\) satisfies \(\text{Cov}(h(Z), h(-Z)) \le 0\), guaranteeing that \(\Var(\hat{\theta}_{\text{anti}}) \le \frac{\sigma^2}{n}\).

Proof

Follows directly from the FKG inequality / Chebyshev's association inequality for monotonic functions of independent random variables: if \(f\) and \(g\) are non-decreasing, \(\text{Cov}(f(Z), g(Z)) \ge 0\). Setting \(g(z) = -h(-z)\) makes \(g\) non-decreasing whenever \(h\) is non-decreasing, implying \(\text{Cov}(h(Z), -h(-Z)) \ge 0\), or \(\text{Cov}(h(Z), h(-Z)) \le 0\). \(\blacksquare\)

3Control variates

The method of control variates exploits analytical knowledge of an auxiliary random variable that is strongly correlated with the target simulation payoff.

Definition 3.1 (control variate)

Let \(X\) be the target payoff whose expectation \(\theta = \E[X]\) is unknown. A control variates setup introduces an auxiliary random variable \(Y\) whose expectation \(\E[Y] = \mu_Y\) is known analytically. For any real coefficient \(b \in \R\), the controlled variate is:

\[ X(b) = X - b (Y - \mu_Y) \]

The control variate estimator based on \(n\) i.i.d. draws \((X_i, Y_i)\) is:

\[ \hat{\theta}_{\text{cv}}(b) = \bar{X} - b (\bar{Y} - \mu_Y) \]

Theorem 3.2 (optimal control variate coefficient and variance reduction)

Assume \(\Var(Y) = \sigma_Y^2 > 0\). For any fixed \(b \in \R\):

  1. \(\hat{\theta}_{\text{cv}}(b)\) is strictly unbiased: \(\E[\hat{\theta}_{\text{cv}}(b)] = \theta\).
  2. The variance of \(X(b)\) as a function of \(b\) is quadratic: \[ \Var(X(b)) = \sigma_X^2 - 2 b \text{Cov}(X, Y) + b^2 \sigma_Y^2 \]
  3. The unique variance-minimizing optimal coefficient \(b^*\) is the population regression slope: \[ b^* = \frac{\text{Cov}(X, Y)}{\Var(Y)} \]
  4. At the optimum \(b^*\), the minimum variance is: \[ \Var(X(b^*)) = \sigma_X^2 (1 - \rho_{XY}^2) \] where \(\rho_{XY} = \text{Corr}(X, Y)\). The variance is reduced by a factor of \(1 - \rho_{XY}^2\).
Proof

Unbiasedness follows from \(\E[X(b)] = \E[X] - b(\E[Y] - \mu_Y) = \theta - b(0) = \theta\). The variance is \(\Var(X - b(Y - \mu_Y)) = \Var(X) - 2b \text{Cov}(X, Y) + b^2 \Var(Y) = \sigma_X^2 - 2 b \sigma_{XY} + b^2 \sigma_Y^2\). Differentiating with respect to \(b\) and setting to zero: \(\frac{d}{db}\Var(X(b)) = -2 \sigma_{XY} + 2 b \sigma_Y^2 = 0 \implies b^* = \frac{\sigma_{XY}}{\sigma_Y^2}\). The second derivative is \(2 \sigma_Y^2 > 0\), confirming a global minimum. Substituting \(b^*\) back into the variance formula: \(\Var(X(b^*)) = \sigma_X^2 - 2 \frac{\sigma_{XY}^2}{\sigma_Y^2} + \frac{\sigma_{XY}^2}{\sigma_Y^4} \sigma_Y^2 = \sigma_X^2 - \frac{\sigma_{XY}^2}{\sigma_Y^2} = \sigma_X^2 \left(1 - \frac{\sigma_{XY}^2}{\sigma_X^2 \sigma_Y^2}\right) = \sigma_X^2 (1 - \rho_{XY}^2)\). \(\blacksquare\)

Remark 3.3 (estimated control coefficient \(\hat{b}^*\))

In practice, \(\text{Cov}(X, Y)\) and \(\Var(Y)\) are estimated from the simulation sample using sample covariance and sample variance: \(\hat{b}^* = \frac{s_{XY}}{s_Y^2}\). Although substituting \(\hat{b}^*\) introduces a mild finite-sample correlation between the coefficient and the sample, the resulting estimator remains consistent and asymptotically normal, with negligible bias of order \(O(1/n)\) (Glasserman 2003, §4.2).

4Financial engineering applications: European call options

Under the Black–Scholes risk-neutral measure, the terminal asset price is log-normal: \(S_\tau = S_0 \exp\left((r - \frac{1}{2}\sigma^2)\tau + \sigma\sqrt{\tau} Z\right)\). When pricing an option \(C = \E[e^{-r\tau} (S_\tau - K)^+]\):

  • Antithetic variates: For each draw \(Z \sim \mathcal{N}(0, 1)\), simulate paths driven by \(+Z\) and \(-Z\). Because the European call payoff \((S_\tau - K)^+\) is a monotonically increasing function of \(Z\), Proposition 2.3 guarantees strictly negative correlation between the pair, shrinking variance by a factor of \(1 + \rho < 1\).
  • Underlying asset as control variate: The discounted stock price \(Y = e^{-r\tau} S_\tau\) has exact known expectation \(\E[Y] = S_0\) under the no-arbitrage martingale condition. For at-the-money options, \(S_\tau\) is strongly correlated with \((S_\tau - K)^+\) (\(\rho \approx 0.90\) to \(0.95\)), slashing variance by \(1 - \rho^2 \approx 80\% \) to \(90\%\).

5Inline laboratory: antithetic and control variate efficiency

Lab 1 · Variance reduction efficiency for European call option (SIMULATED)

Under the Black–Scholes model with parameters \(S_0 = 100, K = 100, \tau = 1.0, r = 0.05, \sigma = 0.20\), the exact analytical call price is \(10.4505835722\). Simulating \(N = 50,000\) evaluations will demonstrate: (i) antithetic variates reduce estimator variance by approximately 75% (\(\Var_{\text{pair}} / \Var_{\text{crude}} \approx 0.2444\)); and (ii) using the discounted stock price as a control variate achieves correlation \(\rho \approx 0.9242\), reducing variance by \(1 - \rho^2 \approx 0.1458\) (an 85.4% variance reduction), cutting standard error from \(6.58 \times 10^{-2}\) to \(2.51 \times 10^{-2}\).

"""Lab M8-L07-1: Variance reduction efficiency: antithetic and control variates.

Standard library only. Compares variance and standard error of crude Monte Carlo,
antithetic variates, and underlying asset control variates for a European call (SIMULATED).
"""

from __future__ import annotations

import math
import random


def bs_call_price(s: float, k: float, tau: float, r: float, sigma: float) -> float:
    """Exact Black-Scholes call price via math.erf."""
    v_sqrt_t = sigma * math.sqrt(tau)
    d1 = (math.log(s / k) + (r + 0.5 * sigma * sigma) * tau) / v_sqrt_t
    d2 = d1 - v_sqrt_t
    disc = math.exp(-r * tau)
    phi_d1 = 0.5 * (1.0 + math.erf(d1 / math.sqrt(2.0)))
    phi_d2 = 0.5 * (1.0 + math.erf(d2 / math.sqrt(2.0)))
    return s * phi_d1 - k * disc * phi_d2


def main() -> None:
    s0 = 100.0
    k = 100.0
    tau = 1.0
    r = 0.05
    sigma = 0.20
    n = 50_000
    disc = math.exp(-r * tau)
    drift = (r - 0.5 * sigma * sigma) * tau
    vol_sqrt = sigma * math.sqrt(tau)

    exact_price = bs_call_price(s0, k, tau, r, sigma)
    print("=== Variance Reduction for European Call Option (SIMULATED) ===")
    print(f"Parameters: S0={s0}, K={k}, tau={tau}, r={r}, sigma={sigma}")
    print(f"Exact Black-Scholes price: {exact_price:.10f}")

    rng = random.Random(42)

    # 1. Crude Monte Carlo
    z_crude = [rng.gauss(0.0, 1.0) for _ in range(n)]
    payoffs_crude = [disc * max(s0 * math.exp(drift + vol_sqrt * z) - k, 0.0) for z in z_crude]
    mc_est = sum(payoffs_crude) / n
    mc_var = sum((x - mc_est) ** 2 for x in payoffs_crude) / (n - 1)
    mc_se = math.sqrt(mc_var / n)

    # 2. Antithetic Variates (n/2 pairs = n evaluations)
    rng_anti = random.Random(42)
    n_pairs = n // 2
    anti_estimates: list[float] = []
    for _ in range(n_pairs):
        z = rng_anti.gauss(0.0, 1.0)
        s_pos = s0 * math.exp(drift + vol_sqrt * z)
        s_neg = s0 * math.exp(drift - vol_sqrt * z)
        c_pos = disc * max(s_pos - k, 0.0)
        c_neg = disc * max(s_neg - k, 0.0)
        anti_estimates.append(0.5 * (c_pos + c_neg))

    anti_est = sum(anti_estimates) / n_pairs
    anti_var = sum((x - anti_est) ** 2 for x in anti_estimates) / (n_pairs - 1)
    anti_se = math.sqrt(anti_var / n_pairs)

    # 3. Control Variates: using terminal stock price S_tau as control
    # Known expectation: E[S_tau] = S0 * exp(r * tau)
    # Discounted terminal price: E[e^{-r*tau} S_tau] = S0
    y_vals = [disc * s0 * math.exp(drift + vol_sqrt * z) for z in z_crude]
    e_y = s0  # exact expectation of discounted stock price

    y_mean = sum(y_vals) / n
    cov_xy = sum((payoffs_crude[i] - mc_est) * (y_vals[i] - y_mean) for i in range(n)) / (n - 1)
    var_y = sum((y - y_mean) ** 2 for y in y_vals) / (n - 1)
    b_star = cov_xy / var_y

    cv_payoffs = [payoffs_crude[i] - b_star * (y_vals[i] - e_y) for i in range(n)]
    cv_est = sum(cv_payoffs) / n
    cv_var = sum((x - cv_est) ** 2 for x in cv_payoffs) / (n - 1)
    cv_se = math.sqrt(cv_var / n)

    corr_xy = cov_xy / math.sqrt(mc_var * var_y)
    theoretical_reduction = 1.0 - corr_xy**2

    print("\nEstimator Performance (N = 50,000 evaluations):")
    print(f"Crude MC:     Estimate = {mc_est:.6f}, Std Err = {mc_se:.4e}, Variance = {mc_var:.4f}")
    print(
        f"Antithetic:   Estimate = {anti_est:.6f}, Std Err = {anti_se:.4e}, "
        f"Variance ratio to MC = {anti_var / mc_var:.4f}"
    )
    print(f"Control Var:  Estimate = {cv_est:.6f}, Std Err = {cv_se:.4e}, Variance = {cv_var:.4f}")
    print(f"Correlation corr(Payoff, S_tau): {corr_xy:.4f}")
    print(f"Empirical variance ratio Var(CV) / Var(MC): {cv_var / mc_var:.4f}")
    print(f"Theoretical variance ratio (1 - rho^2):     {theoretical_reduction:.4f}")

6Where the canon breaks

  • Non-monotonic payoffs destroying antithetic efficiency. Antithetic variance reduction depends fundamentally on monotonicity. If the payoff function is symmetric or non-monotonic—such as a straddle \(|S_\tau - K|\), a butterfly spread, or a deep out-of-the-money digital—the correlation \(\text{Corr}(h(Z), h(-Z))\) can be zero or strictly positive (\(\rho > 0\)). In the worst case, antithetic sampling doubles computational work while increasing estimator variance.
  • Overfitting multi-control regressions. When introducing multiple control variates \(Y = (Y_1, \dots, Y_k)^\top\), estimating the optimal vector \(b^* = \Sigma_{YY}^{-1} \Sigma_{XY}\) requires inverting an empirical covariance matrix. If the sample size \(n\) is small relative to \(k\), or if controls are collinear (e.g. adjacent forward swap rates), the sample covariance matrix is ill-conditioned, introducing substantial finite-sample estimation noise that inflates overall mean squared error.

7Misconceptions

  1. “Antithetic variates always reduce simulation variance for any financial payoff.”

    Antithetic sampling reduces variance if and only if the correlation between reflected paths is strictly negative (\(\rho < 0\)). For symmetric payoffs (such as an at-the-money straddle \(|S - K|\)), reflecting \(+Z\) to \(-Z\) produces positively correlated payoffs, which increases the estimator variance per evaluation.

  2. “Using an estimated control variate coefficient \(\hat{b}^*\) introduces severe bias into the price estimate.”

    While using the sample-estimated coefficient \(\hat{b}^*\) introduces minor finite-sample dependence between \(\hat{b}^*\) and the sample observations, the resulting bias scales as \(O(1/n)\), which is negligible compared to the \(O(1/\sqrt{n})\) standard error. Moreover, if \((X, Y)\) are jointly normal, the estimator is exactly unbiased even with estimated \(\hat{b}^*\).

  3. “A control variate with correlation \(\rho = 0.5\) reduces simulation variance by half.”

    Variance reduction scales as \(1 - \rho^2\), not \(1 - \rho\). For \(\rho = 0.5\), the variance reduction is only \(1 - (0.5)^2 = 0.75\) (a 25% reduction, not 50%). To cut variance in half (50% reduction), one needs correlation \(\rho \ge \sqrt{0.5} \approx 0.7071\).

8Problem set

Mechanics

M1 · Variance reduction from correlation

If a proposed control variate \(Y\) has correlation \(\rho = 0.95\) with target derivative payoff \(X\), by what percentage does the optimal control variate reduce the estimator variance?

Solution

The variance of the optimal control variate estimator is \(\Var(X(b^*)) = \sigma_X^2(1 - \rho^2)\). For \(\rho = 0.95\), \(\rho^2 = 0.95^2 = 0.9025\). The remaining variance is \(1 - 0.9025 = 0.0975\) of the original variance, representing an exact \(90.25\%\) variance reduction.

M2 · Antithetic pair variance formula

Suppose an individual simulation path has variance \(\sigma^2 = 16.0\). When paired antithetically, the correlation between paired paths is \(\rho = -0.60\). What is the variance of the average of a single antithetic pair \(\frac{1}{2}(Y_1 + Y_2)\)?

Solution

By Theorem 2.2, the variance of the pair average is \(\Var(\frac{Y_1 + Y_2}{2}) = \frac{\sigma^2}{2}(1 + \rho) = \frac{16.0}{2}(1 - 0.60) = 8.0 \times 0.40 = 3.20\). This represents a 60% reduction compared to the variance of an independent two-path average (\(16.0 / 2 = 8.0\)).

M3 · Optimal control coefficient calculation

A Monte Carlo run yields sample covariance \(s_{XY} = 45.0\) and sample variance \(s_Y^2 = 50.0\). What is the estimated optimal control variate coefficient \(\hat{b}^*\)?

Solution

By Theorem 3.2, the optimal coefficient is given by the regression slope \(\hat{b}^* = \frac{s_{XY}}{s_Y^2} = \frac{45.0}{50.0} = 0.90\).

P1 · Unbiasedness of sample-estimated control variate

Prove that if \((X, Y)\) are bivariate normal, the control variate estimator \(\hat{\theta}_{\text{cv}}(\hat{b}^*) = \bar{X} - \hat{b}^* (\bar{Y} - \mu_Y)\) is strictly unbiased: \(\E[\hat{\theta}_{\text{cv}}(\hat{b}^*)] = \theta\).

Solution

Under bivariate normality, the sample regression slope \(\hat{b}^*\) is statistically independent of the sample mean vector \((\bar{X}, \bar{Y})\) by Basu's theorem / Fisher's lemma. Therefore, \(\E[\hat{b}^* (\bar{Y} - \mu_Y)] = \E[\hat{b}^*] \cdot \E[\bar{Y} - \mu_Y]\). Since \(\bar{Y}\) is an unbiased estimator of \(\mu_Y\), \(\E[\bar{Y} - \mu_Y] = 0\). Thus \(\E[\hat{\theta}_{\text{cv}}(\hat{b}^*)] = \E[\bar{X}] - \E[\hat{b}^*] \cdot 0 = \theta\), establishing strict unbiasedness.

P2 · Straddle failure under antithetic sampling

Let \(Z \sim \mathcal{N}(0, 1)\) and consider the symmetric payoff \(g(Z) = |Z|\). Prove that the antithetic correlation \(\text{Corr}(g(Z), g(-Z)) = +1\), and explain why antithetic sampling fails to reduce variance.

Solution

Since \(|-Z| = |Z|\), \(g(-Z) = g(Z)\) identically for all \(Z\). The paired variates are identical: \(Y^{(1)} = Y^{(2)} = |Z|\). Their correlation is \(\text{Corr}(|Z|, |Z|) = 1.0\). By Theorem 2.2, the variance of the pair average is \(\frac{\sigma^2}{2}(1 + 1) = \sigma^2\). For \(n\) evaluations (\(n/2\) pairs), the variance is \(\frac{\sigma^2}{n/2} = 2 \frac{\sigma^2}{n}\), which is double the variance of crude Monte Carlo with \(n\) independent draws.

P3 · Multivariate control variates variance formula

Let \(Y = (Y_1, \dots, Y_k)^\top\) be a vector of \(k\) control variates with covariance matrix \(\Sigma_{YY}\) and cross-covariance vector \(\Sigma_{XY}\). Derive the optimal vector \(b^* = \Sigma_{YY}^{-1} \Sigma_{XY}\) and the resulting minimal variance.

Solution

The controlled payoff is \(X(b) = X - b^\top (Y - \mu_Y)\). Its variance is \(\Var(X(b)) = \sigma_X^2 - 2 b^\top \Sigma_{XY} + b^\top \Sigma_{YY} b\). Taking the gradient with respect to \(b\) and setting to zero: \(\nabla_b \Var(X(b)) = -2 \Sigma_{XY} + 2 \Sigma_{YY} b = 0\), which yields \(b^* = \Sigma_{YY}^{-1} \Sigma_{XY}\). The Hessian is \(2 \Sigma_{YY}\), which is positive-definite when controls are non-redundant. Substituting \(b^*\) back gives \(\Var(X(b^*)) = \sigma_X^2 - 2 \Sigma_{XY}^\top \Sigma_{YY}^{-1} \Sigma_{XY} + \Sigma_{XY}^\top \Sigma_{YY}^{-1} \Sigma_{YY} \Sigma_{YY}^{-1} \Sigma_{XY} = \sigma_X^2 - \Sigma_{XY}^\top \Sigma_{YY}^{-1} \Sigma_{XY} = \sigma_X^2 (1 - R_{X|Y}^2)\), where \(R_{X|Y}\) is the multiple correlation coefficient.

E2 · Effective sample size speedup

In Lab 1, compute the equivalent number of crude Monte Carlo paths needed to match the precision of the control variate estimator at \(N = 50,000\).

Solution

Crude MC standard error is \(\se_{\text{crude}} = 6.5783 \times 10^{-2}\), while control variate standard error is \(\se_{\text{cv}} = 2.5119 \times 10^{-2}\). Because standard error scales as \(1/\sqrt{n}\), the required sample size ratio is \((\se_{\text{crude}} / \se_{\text{cv}})^2 = (6.5783 / 2.5119)^2 = (2.6189)^2 \approx 6.8585\). Multiplying by 50,000 evaluations yields \(50,000 \times 6.8585 \approx 342,925\) paths. The control variate achieves a nearly 7-fold computational speedup.

E3 · Antithetic variance ratio in Lab 1

In Lab 1, explain why the printed antithetic variance ratio to crude MC is 0.2444, and calculate the implied path-level correlation \(\rho\).

Solution

The lab reports the variance of the pair average \(\Var(\bar{Y}_{\text{pair}}) = 52.87\), compared to crude path variance \(\Var(Y) = 216.37\). The ratio is \(52.87 / 216.37 \approx 0.2444\). By Theorem 2.2, \(\Var(\bar{Y}_{\text{pair}}) / \Var(Y) = \frac{1}{2}(1 + \rho)\). Setting \(\frac{1}{2}(1 + \rho) = 0.2444\) yields \(1 + \rho = 0.4888\), so \(\rho = -0.5112\). The negative correlation between European call payoffs driven by \(+Z\) and \(-Z\) is approximately \(-0.5112\).

Research

R1 · Geometric average Asian option as control variate

Explain how Kemna and Vorst (1990) used the closed-form Black–Scholes price of a geometric average Asian option as a control variate to price arithmetic average Asian options.

Solution

An arithmetic Asian option pays \((\frac{1}{m}\sum S_{t_i} - K)^+\), which has no closed-form distribution because sums of log-normals are not log-normal. In contrast, the geometric average \((\prod S_{t_i})^{1/m} = \exp(\frac{1}{m}\sum \ln S_{t_i})\) is the exponential of a Gaussian sum, hence strictly log-normal, possessing an exact Black–Scholes closed-form formula. Because geometric and arithmetic averages move almost identically along every sample path, their correlation typically exceeds \(\rho > 0.995\). Using the geometric option as a control variate eliminates over 99% of simulation variance, reducing computational requirements by a factor of 100 or more.

R2 · Combining antithetic and control variates

When combining antithetic variates with control variates in the same simulation engine, what symmetry properties must hold for the estimators to operate orthogonally without interfering with one another?

Solution

If the control variate \(Y(Z)\) is an odd function of the driving Gaussian shocks (\(Y(-Z) = -Y(Z)\)), its antithetic pair average \(\frac{1}{2}(Y(Z) + Y(-Z)) = 0\) vanishes identically, completely neutralizing its effectiveness when combined naively with antithetic averaging. To preserve orthogonality, the control variate must be evaluated on the antithetic pair averages directly: \(\bar{X}_i = \frac{1}{2}(X(Z_i) + X(-Z_i))\) and \(\bar{Y}_i = \frac{1}{2}(Y(Z_i) + Y(-Z_i))\). If \(Y\) is an odd function, \(Y\) should control the anti-symmetric component, while an even function controls the symmetric component (Glasserman 2003, §4.4).

R3 · Martingale control variates in path-dependent simulations

In simulating Heston stochastic volatility or multi-factor term structure models, explain how discretized martingale properties (such as \(\E[M_{t_{k+1}} | M_{t_k}] = M_{t_k}\)) can generate an entire family of zero-mean control variates.

Solution

For any discrete martingale \(M_t\) adapted to the simulation filtration, the martingale increments \(\Delta M_k = M_{t_{k+1}} - M_{t_k}\) satisfy \(\E[\Delta M_k] = 0\) exactly. Any linear combination \(\sum_{k=0}^{m-1} H_k \Delta M_k\) where \(H_k\) is predictable has expectation zero. In financial engineering, this corresponds to delta-hedging the derivative payoff along the simulated path: \(X - \sum \Delta_k \Delta S_k\). By the Clark–Ocone theorem, if the hedging strategy \(\Delta_k\) matches the true financial delta, the simulation variance vanishes asymptotically as the time grid refines, demonstrating the deep mathematical connection between financial risk hedging and numerical variance reduction.
