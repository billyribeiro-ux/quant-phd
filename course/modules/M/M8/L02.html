Numerical errors in scientific computing arise from two fundamentally distinct sources: the sensitivity of the underlying mathematical problem (conditioning) and the propagation of roundoff errors by the algorithm (stability). An ill-conditioned problem amplifies tiny input changes into massive solution errors regardless of the algorithm used. Conversely, an unstable algorithm can produce catastrophic errors even on well-conditioned problems. In quantitative finance, portfolio covariance matrix inversion and option Greek calculations are frequently ill-conditioned. Disentangling problem conditioning from algorithmic stability is necessary to design robust risk models and linear solvers.

1Problem conditioning and condition numbers

A computational problem can be formalized as evaluating a map \(f: X \to Y\) from input normed space \(X\) to output space \(Y\). Conditioning measures how sensitive the exact output \(f(x)\) is to perturbations in the input \(x\).

Definition 1.1 (relative condition number of a function)

Let \(f: \R \to \R\) be a differentiable scalar function. The relative condition number \(\kappa(x)\) of \(f\) at \(x \ne 0\) with \(f(x) \ne 0\) is the limit of the relative output change divided by the relative input change:

\[ \kappa(x) = \lim_{\delta x \to 0} \left| \frac{\frac{f(x + \delta x) - f(x)}{f(x)}}{\frac{\delta x}{x}} \right| = \left| \frac{x f'(x)}{f(x)} \right| \]

A problem is well-conditioned if \(\kappa(x)\) is small (e.g. \(O(1)\)), and ill-conditioned if \(\kappa(x) \gg 1\).

Example 1.2 (conditioning of elementary operations)

For \(f(x) = \sqrt{x}\), \(\kappa(x) = |x \frac{1}{2\sqrt{x}} / \sqrt{x}| = \frac{1}{2}\). Square root evaluation is unconditionally well-conditioned: a 1% error in \(x\) produces only a 0.5% error in \(\sqrt{x}\). For \(f(x) = \frac{1}{1 - x}\) near \(x \approx 1\), \(f'(x) = \frac{1}{(1-x)^2}\), so \(\kappa(x) = |\frac{x}{(1-x)^2} (1 - x)| = \frac{|x|}{|1 - x|}\). As \(x \to 1\), \(\kappa(x) \to \infty\), illustrating severe ill-conditioning.

2Conditioning of linear systems

Consider solving a linear system of equations \(A x = b\) where \(A \in \R^{n \times n}\) is non-singular and \(b \in \R^n\) is non-zero.

Definition 2.1 (matrix condition number)

For a non-singular matrix \(A \in \R^{n \times n}\) and subordinate matrix norm \(\|\cdot\|\), the condition number of \(A\) is:

\[ \kappa(A) = \|A\| \, \|A^{-1}\| \]

Since \(I = A A^{-1}\), \(\|I\| \le \|A\| \|A^{-1}\|\). In any induced norm where \(\|I\| = 1\), \(\kappa(A) \ge 1\). If \(A\) is singular, \(\kappa(A) = \infty\).

Proposition 2.2 (relative perturbation error bound)

Let \(A x = b\) and \(A (x + \delta x) = b + \delta b\), where \(b \ne 0\). The relative change in the solution satisfies:

\[ \frac{\|\delta x\|}{\|x\|} \le \kappa(A) \frac{\|\delta b\|}{\|b\|} \]

Furthermore, this bound is sharp: there exist non-zero vectors \(b\) and \(\delta b\) for which equality holds.

Proof

From \(A (x + \delta x) = b + \delta b\) and \(A x = b\), linearity implies \(A \delta x = \delta b\), so \(\delta x = A^{-1} \delta b\). Taking norms and using submultiplicativity: \(\|\delta x\| \le \|A^{-1}\| \|\delta b\|\). From \(b = A x\), we have \(\|b\| \le \|A\| \|x\|\), which implies \(\frac{1}{\|x\|} \le \frac{\|A\|}{\|b\|}\). Multiplying the two inequalities gives \(\frac{\|\delta x\|}{\|x\|} \le \|A\| \|A^{-1}\| \frac{\|\delta b\|}{\|b\|} = \kappa(A) \frac{\|\delta b\|}{\|b\|}\). To show sharpness, choose \(x\) such that \(\|A x\| = \min_{z \ne 0} \frac{\|A z\|}{\|z\|} \|x\| = \frac{1}{\|A^{-1}\|} \|x\|\), and choose \(\delta b\) such that \(\|A^{-1} \delta b\| = \|A^{-1}\| \|\delta b\|\). Then equality is attained. \(\blacksquare\)

3Forward error, backward error, and numerical stability

When solving \(f(x) = y\) with a numerical algorithm, finite-precision computation produces an approximate output \(\hat{y} = \text{alg}(x)\). We distinguish between forward and backward error.

Definition 3.1 (forward and backward error)

The forward error of an computed solution \(\hat{y}\) is the distance to the true output \(\|\hat{y} - y\|\), or relative forward error \(\frac{\|\hat{y} - y\|}{\|y\|}\). The backward error is the smallest perturbation \(\Delta x\) to the input such that the computed result is exact for the perturbed input: \(f(x + \Delta x) = \hat{y}\). The relative backward error is \(\frac{\|\Delta x\|}{\|x\|}\).

Definition 3.2 (numerical stability and backward stability)

An algorithm is numerically stable if its forward error is commensurate with problem conditioning: \(\text{forward error} \lesssim \kappa(x) \times u\). An algorithm is backward stable if for every input \(x\), it produces the exact output for a slightly perturbed input \(x + \Delta x\) with relative backward error bounded by the unit roundoff: \(\frac{\|\Delta x\|}{\|x\|} \le C u\), where \(C\) is a moderate constant.

Proposition 3.3 (backward stability implies forward error bound)

If an algorithm for evaluating \(f\) is backward stable with \(\frac{\|\Delta x\|}{\|x\|} \le C u\), then its relative forward error satisfies:

\[ \frac{\|\hat{y} - y\|}{\|y\|} \le \kappa(x) \cdot C u + O(u^2) \]

Proof

By definition of backward stability, \(\hat{y} = f(x + \Delta x)\). By first-order Taylor expansion for normed spaces, \(f(x + \Delta x) - f(x) = f'(x) \Delta x + O(\|\Delta x\|^2)\). Taking norms and dividing by \(\|y\| = \|f(x)\|\): \(\frac{\|f(x + \Delta x) - f(x)\|}{\|f(x)\|} = \frac{\|f'(x) \Delta x\|}{\|f(x)\|} + O(\|\Delta x\|^2) \le \frac{\|f'(x)\| \|x\|}{\|f(x)\|} \frac{\|\Delta x\|}{\|x\|} + O(u^2) = \kappa(x) \frac{\|\Delta x\|}{\|x\|} + O(u^2) \le \kappa(x) C u + O(u^2)\). \(\blacksquare\)

Remark 3.4 (fundamental rule of numerical analysis)

The forward error is at most the condition number times the backward error:

\[ \text{Forward Error} \le \text{Condition Number} \times \text{Backward Error} \]

A backward stable algorithm guarantees that any large forward error observed in practice is entirely attributable to the mathematical ill-conditioning of the problem itself, not the algorithmic implementation.

4Inline laboratory: exact conditioning of a 2x2 system

Lab 1 · Conditioning and stability of a linear system

For an ill-conditioned 2x2 matrix \(A\) with \(\kappa_\infty(A) = 40{,}000\), an input perturbation \(\|\delta b\|_\infty / \|b\|_\infty = 5 \times 10^{-6}\) produces an observed relative solution change \(\|\delta x\|_\infty / \|x\|_\infty = 10\%\). The exact theoretical bound \(\kappa_\infty(A) \|\delta b\|_\infty / \|b\|_\infty = 20\%\) holds strictly in exact rational arithmetic.

"""Lab M8-L02-1: Conditioning and stability of a linear system.

Exact arithmetic using fractions.Fraction. Computes the exact condition number
and compares the theoretical error bound to the observed solution error under perturbation.
"""

from __future__ import annotations

from fractions import Fraction


def inf_norm_matrix(a11: Fraction, a12: Fraction, a21: Fraction, a22: Fraction) -> Fraction:
    """Maximum row sum norm."""
    r1 = abs(a11) + abs(a12)
    r2 = abs(a21) + abs(a22)
    return max(r1, r2)


def inf_norm_vector(v1: Fraction, v2: Fraction) -> Fraction:
    """Maximum absolute entry norm."""
    return max(abs(v1), abs(v2))


def solve_2x2(
    a11: Fraction, a12: Fraction, a21: Fraction, a22: Fraction, b1: Fraction, b2: Fraction
) -> tuple[Fraction, Fraction]:
    """Solve 2x2 linear system via Cramer's rule in exact arithmetic."""
    det = a11 * a22 - a12 * a21
    if det == 0:
        raise ValueError("Matrix is singular")
    x1 = (b1 * a22 - a12 * b2) / det
    x2 = (a11 * b2 - b1 * a21) / det
    return x1, x2


def invert_2x2(
    a11: Fraction, a12: Fraction, a21: Fraction, a22: Fraction
) -> tuple[Fraction, Fraction, Fraction, Fraction]:
    """Inverse of 2x2 matrix."""
    det = a11 * a22 - a12 * a21
    if det == 0:
        raise ValueError("Matrix is singular")
    return a22 / det, -a12 / det, -a21 / det, a11 / det


def main() -> None:
    # A = [[1, 1], [1, 1 - eps]] with eps = 1/10000
    eps = Fraction(1, 10_000)
    a11, a12 = Fraction(1, 1), Fraction(1, 1)
    a21, a22 = Fraction(1, 1), Fraction(1, 1) - eps

    # b = [2, 2 - eps], exact solution x = [1, 1]
    b1, b2 = Fraction(2, 1), Fraction(2, 1) - eps
    x1, x2 = solve_2x2(a11, a12, a21, a22, b1, b2)

    # Invert A
    inv11, inv12, inv21, inv22 = invert_2x2(a11, a12, a21, a22)

    norm_a = inf_norm_matrix(a11, a12, a21, a22)
    norm_inv = inf_norm_matrix(inv11, inv12, inv21, inv22)
    kappa_inf = norm_a * norm_inv

    print(f"Matrix A: [[{a11}, {a12}], [{a21}, {a22}]]")
    print(f"Right-hand side b: [{b1}, {b2}]")
    print(f"Exact unperturbed solution x: [{x1}, {x2}]")
    print(f"||A||_inf: {norm_a}")
    print(f"||A^-1||_inf: {norm_inv}")
    print(f"Exact condition number kappa_inf(A): {kappa_inf} (decimal: {float(kappa_inf):.1f})")

    # Perturb b by delta_b = [0, 1/100000]
    delta_b1, delta_b2 = Fraction(0, 1), Fraction(1, 100_000)
    b1_pert = b1 + delta_b1
    b2_pert = b2 + delta_b2

    x1_pert, x2_pert = solve_2x2(a11, a12, a21, a22, b1_pert, b2_pert)
    delta_x1 = x1_pert - x1
    delta_x2 = x2_pert - x2

    norm_b = inf_norm_vector(b1, b2)
    norm_delta_b = inf_norm_vector(delta_b1, delta_b2)
    norm_x = inf_norm_vector(x1, x2)
    norm_delta_x = inf_norm_vector(delta_x1, delta_x2)

    rel_b = norm_delta_b / norm_b
    rel_x = norm_delta_x / norm_x
    bound = kappa_inf * rel_b

    print(f"\nPerturbation delta_b: [{delta_b1}, {delta_b2}]")
    print(f"Perturbed solution x_pert: [{x1_pert}, {x2_pert}]")
    print(f"Solution error delta_x: [{delta_x1}, {delta_x2}]")
    print(f"Relative rhs change ||delta_b|| / ||b||: {rel_b} (decimal: {float(rel_b):.2e})")
    print(f"Relative solution change ||delta_x|| / ||x||: {rel_x} (decimal: {float(rel_x):.2e})")
    print(f"Condition bound kappa_inf * (||delta_b|| / ||b||): {bound} (decimal: {float(bound):.2e})")
    print(f"Theoretical bound holds: {rel_x <= bound}")

5Where the canon breaks

  • Condition bounds are worst-case upper bounds. A condition number \(\kappa(A) = 10^8\) does not imply every perturbation will be amplified by \(10^8\). If \(\delta b\) lies along the principal direction associated with the largest singular value of \(A\), the amplification is minimal (\(\sim 1\)). The bound guarantees what cannot happen, not what always happens.
  • Inverting ill-conditioned matrices cannot be fixed by software. If a financial covariance matrix has condition number \(\kappa = 10^{16}\), all double-precision significance is lost. No stable algorithm can recover meaningful portfolio weights without regularizing the underlying matrix (e.g. Ridge shrinkage or eigenvalue clipping).

6Misconceptions

  1. “A small matrix determinant implies an ill-conditioned matrix.”

    Determinants are not scale-invariant. Consider the diagonal matrix \(A = 10^{-2} I_{100 \times 100}\). Its determinant is \(\det(A) = 10^{-200}\), which underflows to 0 in double precision. However, \(\|A\|_2 = 10^{-2}\) and \(\|A^{-1}\|_2 = 10^2\), so \(\kappa_2(A) = 10^{-2} \times 10^2 = 1.0\). The system is perfectly well-conditioned despite having an infinitesimal determinant.

  2. “If an algorithm produces large forward error, the algorithm must be unstable.”

    If the underlying problem is ill-conditioned (\(\kappa \gg 1\)), even an ideally backward stable algorithm will exhibit large forward error (\(\approx \kappa u\)). Instability occurs only when the forward error is vastly larger than \(\kappa u\).

  3. “A small residual \(\|A \hat{x} - b\|\) guarantees an accurate solution \(\hat{x}\).”

    The relative error is bounded by \(\frac{\|\hat{x} - x\|}{\|x\|} \le \kappa(A) \frac{\|A \hat{x} - b\|}{\|b\|}\). When \(\kappa(A)\) is large, a computed solution can achieve a tiny residual near machine precision (\(\|A \hat{x} - b\| \approx 10^{-16}\)) while the error \(\|\hat{x} - x\|\) remains 100%.

7Problem set

Mechanics

M1 · Condition number of 2x2 matrix

Calculate \(\|A\|_\infty\), \(\|A^{-1}\|_\infty\), and \(\kappa_\infty(A)\) for \(A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}\).

Solution

The row sums of \(A\) are \(1 + 2 = 3\) and \(3 + 4 = 7\), so \(\|A\|_\infty = 7\). The determinant is \(1(4) - 2(3) = -2\). The inverse is \(A^{-1} = -\frac{1}{2} \begin{pmatrix} 4 & -2 \\ -3 & 1 \end{pmatrix} = \begin{pmatrix} -2 & 1 \\ 1.5 & -0.5 \end{pmatrix}\). The row sums of \(A^{-1}\) are \(|-2| + |1| = 3\) and \(|1.5| + |-0.5| = 2\), so \(\|A^{-1}\|_\infty = 3\). Thus, \(\kappa_\infty(A) = \|A\|_\infty \|A^{-1}\|_\infty = 7 \times 3 = 21\).

M2 · Condition number of power function

Compute the relative condition number \(\kappa(x)\) of \(f(x) = x^n\) for constant non-zero integer \(n\).

Solution

The derivative is \(f'(x) = n x^{n-1}\). By Definition 1.1, \(\kappa(x) = \left|\frac{x f'(x)}{f(x)}\right| = \left|\frac{x \cdot n x^{n-1}}{x^n}\right| = |n|\). The condition number is constant and equals \(|n|\) for all \(x \ne 0\). For example, squaring has \(\kappa = 2\), while \(x^{100}\) has \(\kappa = 100\).

M3 · Residual versus error

Let \(A = \begin{pmatrix} 1 & 1 \\ 1 & 1.0001 \end{pmatrix}\) and \(b = \begin{pmatrix} 2 \\ 2.0001 \end{pmatrix}\) with exact solution \(x = \begin{pmatrix} 1 \\ 1 \end{pmatrix}\). Suppose an algorithm yields \(\hat{x} = \begin{pmatrix} 2 \\ 0 \end{pmatrix}\). Compute the residual vector \(r = b - A \hat{x}\) and the relative error \(\|\hat{x} - x\|_\infty / \|x\|_\infty\).

Solution

Compute \(A \hat{x} = \begin{pmatrix} 1(2) + 1(0) \\ 1(2) + 1.0001(0) \end{pmatrix} = \begin{pmatrix} 2 \\ 2 \end{pmatrix}\). The residual is \(r = b - A \hat{x} = \begin{pmatrix} 2 - 2 \\ 2.0001 - 2 \end{pmatrix} = \begin{pmatrix} 0 \\ 0.0001 \end{pmatrix}\). The residual norm is \(\|r\|_\infty = 10^{-4}\), which appears small. However, \(\hat{x} - x = \begin{pmatrix} 2 - 1 \\ 0 - 1 \end{pmatrix} = \begin{pmatrix} 1 \\ -1 \end{pmatrix}\), so \(\|\hat{x} - x\|_\infty / \|x\|_\infty = 1 / 1 = 100\%\). The solution is completely wrong despite a small residual.

Proof

P1 · Condition number of orthogonal matrix

Prove that for any orthogonal matrix \(Q \in \R^{n \times n}\) (\(Q^\top Q = I\)), \(\kappa_2(Q) = 1\).

Solution

The 2-norm of a matrix is \(\|A\|_2 = \sqrt{\lambda_{\max}(A^\top A)}\). Since \(Q^\top Q = I\), \(Q^\top Q\) has all eigenvalues equal to 1, so \(\|Q\|_2 = 1\). Furthermore, \(Q^{-1} = Q^\top\), and \((Q^\top)^\top Q^\top = Q Q^\top = I\) (since square orthogonal matrices have orthonormal rows as well as columns). Therefore, \(\|Q^{-1}\|_2 = \|Q^\top\|_2 = 1\). Hence \(\kappa_2(Q) = \|Q\|_2 \|Q^{-1}\|_2 = 1 \times 1 = 1\). Orthogonal transformations are perfectly conditioned.

P2 · Perturbation in the coefficient matrix

Let \(A x = b\) and \((A + \delta A)(x + \delta x) = b\). Assuming \(\|\delta A\| \|A^{-1}\| < 1\), prove that \(\frac{\|\delta x\|}{\|x\|} \le \frac{\kappa(A) \frac{\|\delta A\|}{\|A\|}}{1 - \kappa(A) \frac{\|\delta A\|}{\|A\|}}\).

Solution

Expanding gives \(A x + A \delta x + \delta A (x + \delta x) = b\). Since \(A x = b\), we have \(A \delta x = -\delta A (x + \delta x)\), so \(\delta x = -A^{-1} \delta A (x + \delta x)\). Taking norms: \(\|\delta x\| \le \|A^{-1}\| \|\delta A\| (\|x\| + \|\delta x\|)\). Rearranging: \((1 - \|A^{-1}\| \|\delta A\|) \|\delta x\| \le \|A^{-1}\| \|\delta A\| \|x\|\). Dividing by \(\|x\|\) and using \(\|A^{-1}\| \|\delta A\| = \|A\| \|A^{-1}\| \frac{\|\delta A\|}{\|A\|} = \kappa(A) \frac{\|\delta A\|}{\|A\|}\) yields the stated inequality.

P3 · Singular values and condition number

Prove that for any non-singular matrix \(A \in \R^{n \times n}\), \(\kappa_2(A) = \frac{\sigma_{\max}(A)}{\sigma_{\min}(A)}\) where \(\sigma_{\max}, \sigma_{\min}\) are the largest and smallest singular values.

Solution

From the singular value decomposition \(A = U \Sigma V^\top\), the matrix 2-norm is the largest singular value: \(\|A\|_2 = \sigma_{\max}(A) = \sigma_1\). The inverse is \(A^{-1} = V \Sigma^{-1} U^\top\). The diagonal entries of \(\Sigma^{-1}\) are \(1/\sigma_n \ge 1/\sigma_{n-1} \ge \dots \ge 1/\sigma_1\). Therefore, \(\|A^{-1}\|_2 = \frac{1}{\sigma_{\min}(A)}\). Multiplying the two norms gives \(\kappa_2(A) = \|A\|_2 \|A^{-1}\|_2 = \frac{\sigma_{\max}(A)}{\sigma_{\min}(A)}\).

In Lab 1, what are the exact fraction values of \(\|A\|_\infty\), \(\|A^{-1}\|_\infty\), and \(\kappa_\infty(A)\)?

Solution

As computed in Lab 1: \(\|A\|_\infty = \max(1 + 1, 1 + 9999/10000) = 2\). The inverse matrix has row sums \(\max(|-9999| + |10000|, |10000| + |-10000|) = 20000\), so \(\|A^{-1}\|_\infty = 20000\). The exact condition number is \(\kappa_\infty(A) = 2 \times 20000 = 40000\).

E2 · Perturbation amplification in Lab 1

Using the values printed in Lab 1, compare the observed relative solution change with the theoretical condition bound.

Solution

Lab 1 prints relative right-hand side change \(\|\delta b\|_\infty / \|b\|_\infty = 1/200000 = 5.00 \times 10^{-6}\). The observed relative solution error is \(\|\delta x\|_\infty / \|x\|_\infty = 1/10 = 0.10\) (10%). The theoretical upper bound is \(\kappa_\infty(A) \times \frac{\|\delta b\|_\infty}{\|b\|_\infty} = 40000 \times 5.00 \times 10^{-6} = 0.20\) (20%). The bound strictly holds: \(0.10 \le 0.20\).

E3 · Conditioning of Hilbert matrices

The \(n \times n\) Hilbert matrix has entries \(H_{ij} = \frac{1}{i + j - 1}\). Explain why solving \(H x = b\) becomes impossible in binary64 for \(n \ge 12\).

Solution

Hilbert matrices are notoriously ill-conditioned. For \(n = 12\), \(\kappa_2(H_{12}) \approx 1.7 \times 10^{16}\). Since the unit roundoff in binary64 is \(u \approx 1.11 \times 10^{-16}\), the product \(\kappa(H) u \approx 1.9 > 1\). According to Remark 3.4, the expected forward error is \(O(\kappa u) \ge 100\%\), completely destroying all 16 decimal digits of precision.

Research

R1 · Covariance matrix conditioning in Markowitz allocation

Why are empirical covariance matrices of equity returns with \(N \approx 500\) assets and \(T \approx 250\) daily observations severely ill-conditioned, and how does this affect optimal weights?

Solution

When \(N > T\), the sample covariance matrix \(\hat{\Sigma} = \frac{1}{T} X X^\top\) is singular with rank at most \(T < N\), so \(\kappa(\hat{\Sigma}) = \infty\). Even when \(T > N\) with \(T \approx 2N\), the Marchenko-Pastur distribution from random matrix theory shows that sample eigenvalues spread widely: \(\lambda_{\min} \approx (1 - \sqrt{N/T})^2\). For \(N/T = 0.5\), \(\lambda_{\min} \approx 0.086\) and \(\lambda_{\max} \approx 2.91\). Inverting \(\hat{\Sigma}\) in the Markowitz formula \(w^* \propto \hat{\Sigma}^{-1} \mu\) severely amplifies noise in the smallest eigenvectors, resulting in extreme, unstable portfolio positions.

R2 · Conditioning of Black–Scholes vega inversion

Explain why inverting the Black–Scholes formula for implied volatility \(\sigma\) becomes ill-conditioned when \(\text{vega} \to 0\).

Solution

Let \(C(\sigma)\) be the option price as a function of volatility. The inverse problem seeks \(\sigma(C)\). By the inverse function theorem, \(\frac{d\sigma}{dC} = \frac{1}{\text{vega}}\). The condition number of inversion is \(\kappa_C = |\frac{C \sigma'(C)}{\sigma}| = \frac{C}{\sigma \cdot \text{vega}}\). As an option moves deep out-of-the-money or approaches expiry (\(\tau \to 0\)), vega decays exponentially to zero. Consequently, \(\kappa_C \to \infty\), meaning a roundoff error of \(10^{-16}\) in price can translate into an error of order 1 in implied volatility.

R3 · Preconditioning in iterative solvers

How does left-preconditioning by matrix \(M^{-1}\) transform an ill-conditioned system \(A x = b\), and what properties must the preconditioner \(M\) satisfy?

Solution

Left-preconditioning solves the equivalent system \(M^{-1} A x = M^{-1} b\). The goal is to choose \(M\) such that \(M^{-1} A \approx I\), resulting in \(\kappa(M^{-1} A) \approx 1 \ll \kappa(A)\). A valid preconditioner must balance two competing objectives: \(M\) must be a sufficiently accurate approximation of \(A\) to cluster the eigenvalues of \(M^{-1} A\) near 1, while systems of the form \(M z = r\) must be computationally inexpensive to solve (e.g. Incomplete Cholesky or diagonal Jacobi).

    By Proposition 3.3, forward error is bounded by condition number times backward error.

  8. What is the 2-norm condition number \(\kappa_2(Q)\) of any real orthogonal matrix \(Q\)?

    Orthogonal matrices preserve 2-norms: \(\|Q\|_2 = \|Q^{-1}\|_2 = 1\), so \(\kappa_2(Q) = 1\).
