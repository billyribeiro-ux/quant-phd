The implicit-function theorem

A relation between economic quantities can be stated as an equation rather than as a formula for one of them, for example an equation that fixes a price and a yield together. When the equation can be solved locally for one variable, its slope follows from the equation without solving it. This lesson states the local result, derives the slope formula from the chain rule, and shows where the solvability condition fails, using one example solved in closed form (the circle) and one solved numerically (a cubic relation in the lab).

1A relation that defines a function locally

Let \(F\) be a real function of two variables on an open set \(U \subseteq \mathbb{R}^2\). The set \(\{(x, y) \in U : F(x, y) = 0\}\) is a curve in the plane, and a point on it is a pair \((x, y)\) that satisfies the relation. A curve of this kind need not be the graph of a function \(y = g(x)\) over any interval.

Definition 1.1 (locally implicit function)

Let \((x_0, y_0)\) satisfy \(F(x_0, y_0) = 0\). A function \(g\) on an open interval \(I\) containing \(x_0\) is a locally implicit function of \(F\) at \((x_0, y_0)\) if \(g(x_0) = y_0\) and \(F(x, g(x)) = 0\) for every \(x \in I\). The implicit-function theorem is the statement that gives conditions under which such a \(g\) exists, is unique among functions with values in an open interval \(J\) around \(y_0\), and is differentiable.

Assumption 1.3 (intermediate value theorem, assumed here and not proved)

If \(\varphi\) is continuous on a closed interval \([p, q]\) with \(p < q\), and \(\varphi(p) < 0 < \varphi(q)\), then \(\varphi(c) = 0\) for some \(c\) with \(p < c < q\). This is a stated assumption of this lesson. No proof is given here, and no grade is given to it. Every result below that uses it begins its statement with "Assuming Assumption 1.3".

Theorem 1.2 (the implicit-function theorem, one dependent variable)

Assuming Assumption 1.3 and Assumption 2.1 of Lesson L06, let \(F\) be continuously differentiable on an open set \(U\) containing \((x_0, y_0)\), with \(F(x_0, y_0) = 0\) and \(F_y(x_0, y_0) \ne 0\). Then there are open intervals \(I \ni x_0\) and \(J \ni y_0\), with \(I \times J \subseteq U\) and \(F_y \ne 0\) on \(I \times J\), and a unique function \(g: I \to J\) such that \(F(x, g(x)) = 0\) for all \(x \in I\). Moreover \(g\) is continuously differentiable on \(I\).

Proof

Replacing \(F\) by \(-F\) if necessary, assume \(F_y(x_0, y_0) > 0\). Since \(F_y\) is continuous, there are \(a > 0\) and \(c > 0\) such that the rectangle \(R = [x_0 - a, x_0 + a] \times [y_0 - c, y_0 + c]\) lies in \(U\) and \(F_y > 0\) on \(R\). Put \(J = (y_0 - c, y_0 + c)\). The function \(y \mapsto F(x_0, y)\) is strictly increasing on \([y_0 - c, y_0 + c]\) and vanishes at \(y_0\), so \(F(x_0, y_0 - c) < 0 < F(x_0, y_0 + c)\). By continuity of \(F\) there is \(0 < a_1 \le a\) with \(F(x, y_0 - c) < 0 < F(x, y_0 + c)\) for \(|x - x_0| < a_1\). Put \(I = (x_0 - a_1, x_0 + a_1)\), so that \(I \times J \subseteq R \subseteq U\), and \(F_y > 0\) on \(I \times J\) because \(F_y > 0\) on \(R\).

(Existence and uniqueness.) For each \(x \in I\), the function \(y \mapsto F(x, y)\) is strictly increasing on \([y_0 - c, y_0 + c]\) and changes sign there, so by Assumption 1.3 it has exactly one zero \(g(x)\) in \(J\). This defines \(g: I \to J\) with \(g(x_0) = y_0\) and \(F(x, g(x)) = 0\). Any \(J\)-valued function with the same property must take the zero \(g(x)\), so \(g\) is unique.

(Continuity.) Let \(x_1 \in I\) and let \(\varepsilon > 0\) be small enough that \([g(x_1) - \varepsilon, g(x_1) + \varepsilon] \subseteq J\). Then \(F(x_1, g(x_1) - \varepsilon) < 0 < F(x_1, g(x_1) + \varepsilon)\), so by continuity of \(F\) the same two inequalities hold for all \(x\) near \(x_1\). For such \(x\), strict monotonicity in \(y\) places the zero \(g(x)\) between \(g(x_1) - \varepsilon\) and \(g(x_1) + \varepsilon\). Hence \(g\) is continuous at \(x_1\).

(Differentiability.) Fix \(x_1 \in I\), put \(y_1 = g(x_1)\), and let \(h \ne 0\) be small enough that \(x_1 + h \in I\). Put \(y_2 = g(x_1 + h)\). The mean value theorem in \(x\), applied to \(s \mapsto F(s, y_2)\), and then in \(y\), applied to \(s \mapsto F(x_1, s)\), gives \(\xi_h\) between \(x_1\) and \(x_1 + h\), and \(\eta_h\) between \(y_1\) and \(y_2\), with

\[0 = F(x_1 + h, y_2) - F(x_1, y_1) = h\,F_x(\xi_h, y_2) + (y_2 - y_1)\,F_y(x_1, \eta_h).\]

If \(y_2 = y_1\), the second step is trivial and the identity still holds. The point \((x_1, \eta_h)\) lies in \(R\), so \(F_y(x_1, \eta_h) > 0\), and therefore \(\dfrac{y_2 - y_1}{h} = -\dfrac{F_x(\xi_h, y_2)}{F_y(x_1, \eta_h)}\). As \(h \to 0\), \(y_2 \to y_1\) by continuity of \(g\), so \(\xi_h \to x_1\) and \(\eta_h \to y_1\). Continuity of \(F_x\) and \(F_y\) gives \(\lim_{h \to 0} (y_2 - y_1)/h = -F_x(x_1, y_1)/F_y(x_1, y_1)\). So \(g\) is differentiable at \(x_1\).

Finally \(g'(x) = -F_x(x, g(x))/F_y(x, g(x))\) is continuous on \(I\), because \(g\) is continuous, \(F_x\) and \(F_y\) are continuous, and \(F_y > 0\) on \(R\). So \(g\) is continuously differentiable on \(I\). \(\blacksquare\)

2The slope of the implicit function

Theorem 2.1 (the slope formula)

Assuming Assumption 1.3 and Assumption 2.1 of Lesson L06, under the hypotheses of Theorem 1.2, and with \(g\) the function it provides, \(g'(x) = -F_x(x, g(x)) / F_y(x, g(x))\) for every \(x \in I\), where \(F_x\) and \(F_y\) are the partial derivatives of \(F\).

Proof

By Theorem 1.2, \(F_y \ne 0\) on \(I \times J\), so the division below is allowed at every \(x \in I\). Since \(F\) is continuously differentiable and \(g\) is differentiable, the chain rule applies to \(x \mapsto F(x, g(x))\), which is identically zero on \(I\). Its derivative is \(F_x(x, g(x)) + F_y(x, g(x))\,g'(x)\), so this sum is zero. Dividing by \(F_y(x, g(x)) \ne 0\) gives the formula. \(\blacksquare\)

Example 2.2 (the circle, solved in closed form)

Let \(F(x, y) = x^2 + y^2 - 1\) and \((x_0, y_0) = (0.6, 0.8)\). Here \(F_y = 2y = 1.6 \ne 0\). The function \(g(x) = \sqrt{1 - x^2}\) on \(I = (-1, 1)\) satisfies \(F(x, g(x)) = 0\) and \(g(0.6) = 0.8\). Its derivative is \(g'(x) = -x/\sqrt{1 - x^2}\), which at \(x_0\) is \(-0.6/0.8 = -0.75\). Assuming Assumption 1.3 and Assumption 2.1 of Lesson L06, the formula of Theorem 2.1 gives \(-F_x/F_y = -2x/2y = -0.6/0.8 = -0.75\), so the two agree.

Remark 2.3 (the formula does not need the closed form)

Assuming Assumption 1.3 and Assumption 2.1 of Lesson L06, Theorem 2.1 gives \(g'(x)\) from the values of \(F_x\) and \(F_y\) at the point \((x, g(x))\), with no formula for \(g\). So a derivative can be computed when \(g\) is only known through a numerical root. Lab 1 uses this.

Lab 1 · The slope of a root found numerically, against the formula

The relation is \(F(x, y) = y^3 + xy - 1 = 0\), a SIMULATED test relation chosen for this lab and not market data. The lab does not use the cubic formula; it finds \(y(x) > 0\) by Newton's method. Here \(F_x = y\) and \(F_y = 3y^2 + x\). For \(x > 0\) and \(y > 0\), \(F_y > 0\), so the hypothesis of Theorem 1.2 holds at every point the lab uses. Predicted before running: the formula \(dy/dx = -y/(3y^2 + x)\) at each root should agree with a central difference of the computed roots at step \(10^{-5}\) to about \(10^{-11}\) or better, and each residual should be at the rounding level.

"""M2 lab L21: the derivative of an implicitly defined function, against finite differences of its root.

SIMULATED: the relation F(x, y) = y**3 + x * y - 1 = 0 is a test equation chosen for this lab. It is not market data.
For each x in a fixed list the lab finds the root y(x) > 0 by Newton's method, not the cubic formula. It then
compares the implicit derivative dy/dx = -F_x / F_y, evaluated at the root, with a central difference of the computed
roots at step h = 1e-5. On this relation F_y = 3 y**2 + x is positive at every x > 0 used, so the hypothesis of the
implicit-function theorem (F_y not zero at the point) holds at each listed point.
Standard library only; no randomness and no network access.
"""

from __future__ import annotations

X_VALUES: tuple[float, ...] = (0.25, 0.5, 1.0, 2.0)
STEP = 1e-5
TOLERANCE = 1e-15
MAX_ITERATIONS = 100


def relation(x: float, y: float) -> float:
    """F(x, y) = y**3 + x * y - 1."""
    return y * y * y + x * y - 1.0


def relation_y(x: float, y: float) -> float:
    """The partial derivative F_y(x, y) = 3 y**2 + x."""
    return 3.0 * y * y + x


def root(x: float) -> float:
    """The root y > 0 of F(x, y) = 0 for a given x > 0, by Newton's method from y = 1.

    Starting at y = 1 is to the right of the root for every x > 0, because F(x, 1) = x > 0 and F is increasing
    in y there, so the iterates decrease to the root. A non-convergent run raises RuntimeError.
    """
    if x <= 0.0:
        raise ValueError(f"this lab takes x > 0, got {x}")
    y = 1.0
    for _ in range(MAX_ITERATIONS):
        step = relation(x, y) / relation_y(x, y)
        y -= step
        if abs(step) < TOLERANCE:
            return y
    raise RuntimeError(f"Newton's method did not converge at x = {x}")


def implicit_derivative(x: float, y: float) -> float:
    """dy/dx = -F_x / F_y at (x, y), with F_x = y for this relation and F_y = 3 y**2 + x."""
    return -y / relation_y(x, y)


def central_difference_of_root(x: float, h: float) -> float:
    """The central difference (y(x + h) - y(x - h)) / (2 h) of the computed root. The step h must be positive."""
    if h <= 0.0:
        raise ValueError(f"the step must be positive, got {h}")
    return (root(x + h) - root(x - h)) / (2.0 * h)


def main() -> None:
    print("relation F(x, y) = y^3 + x*y - 1, root y > 0, step h = 1e-5")
    for x in X_VALUES:
        y = root(x)
        residual = relation(x, y)
        formula = implicit_derivative(x, y)
        fd = central_difference_of_root(x, STEP)
        print(
            f"x = {x:<5} y = {y:.10f} residual {residual: .1e} F_y = {relation_y(x, y):.6f} "
            f"dy/dx formula {formula:.10f} central difference {fd:.10f} difference {abs(formula - fd):.1e}"
        )

3Where the canon breaks

Assuming Assumption 1.3 and Assumption 2.1 of Lesson L06, Theorem 1.2 is local. It produces a function on an interval around \(x_0\), and it says nothing about the whole solution curve. The condition \(F_y(x_0, y_0) \ne 0\) is the hypothesis under which Theorem 1.2 gives a graph over \(x\). It is sufficient, not necessary: for \(F = y^3 - x\) at the origin, \(F_y = 0\), yet the zero set is the graph \(y = x^{1/3}\) over all of \(\mathbb{R}\).

Example 3.1 (the circle at its two kinds of points)

Take \(F(x, y) = x^2 + y^2 - 1\). At \((0.6, 0.8)\) the condition \(F_y \ne 0\) holds and the curve is a graph \(y = \sqrt{1-x^2}\) near that point. At \((1, 0)\) we have \(F_y = 0\) and \(F_x = 2 \ne 0\). Near \((1, 0)\) the curve is the graph \(x = \sqrt{1 - y^2}\) over \(y\), and its slope \(dx/dy = -y/\sqrt{1-y^2}\) is zero at \(y = 0\). The same relation can be a function of \(y\) near one point and of \(x\) near another, and the condition on the partial that is non-zero decides which.

Example 3.2 (no implicit function at all)

Take \(F(x, y) = x^2 + y^2\) at \((0, 0)\), where \(F = 0\) and both partials vanish. For \(x \ne 0\), \(F(x, y) = 0\) requires \(y^2 = -x^2 < 0\), which has no real solution. So no function \(g\) on an open interval containing \(0\) satisfies \(F(x, g(x)) = 0\) with \(g(0) = 0\), because \(F(x, g(x)) = x^2 + g(x)^2\) is positive for \(x \ne 0\).

  • The theorem is local. The circle has two branches \(y = \pm\sqrt{1-x^2}\) that a single function on \((-1, 1)\) cannot both be. Theorem 1.2 gives one branch near each point with \(F_y \ne 0\).
  • The condition is not implied by the relation. Example 3.2 satisfies \(F = 0\) at the origin and has no implicit function there, so the relation alone does not determine a function.
  • The slope formula needs \(F_y\), not \(F_x\). At the point of Example 3.1 where \(F_y = 0\), the slope \(-F_x/F_y\) is undefined. There the curve is a graph over \(y\), There the curve is a graph over \(y\), and the theorem with the roles of the variables exchanged, assuming Assumption 1.3 and Assumption 2.1 of Lesson L06, gives \(dx/dy = -F_y/F_x\).

4Misconceptions

  1. “Every equation \(F(x,y) = 0\) defines \(y\) as a function of \(x\).”

    Example 3.2 has a zero set with no function near the origin. The circle of Example 3.1 has two branches over \(x\), so no single function of \(x\) on \((-1, 1)\) describes it. Theorem 1.2 needs \(F_y \ne 0\) at the point.

  2. “The slope is \(dy/dx = F_y/F_x\).”

    The chain rule in Theorem 2.1 gives \(F_x + F_y\,g' = 0\), so \(g' = -F_x/F_y\). For the circle at \((0.6, 0.8)\), the wrong formula gives \(F_y/F_x = 1.6/1.2 = 4/3\), while Example 2.2 gives \(-0.75\).

  3. “When \(F_y = 0\) the formula still gives a slope, so the theorem is not needed.”

    At a point where \(F_y = 0\) the formula divides by zero, and Example 3.1 shows that the zero set may not be a graph over \(x\) near that point. Where \(F_y = 0\) and \(F_x \ne 0\), the theorem with the roles exchanged gives \(dx/dy = -F_y/F_x\) instead, under Assumption 1.3 and Assumption 2.1 of Lesson L06.

Mechanics

M1 · A slope at a point on a conic

Assuming Assumption 1.3 and Assumption 2.1 of Lesson L06, for \(F(x, y) = x^2 + xy + y^2 - 3\) and the point \((1, 1)\), check that \(F = 0\), and find \(dy/dx\) there by Theorem 2.1.

Solution

\(F(1,1) = 1 + 1 + 1 - 3 = 0\). Then \(F_x = 2x + y = 3\) and \(F_y = x + 2y = 3\), both non-zero at the point, so \(dy/dx = -F_x/F_y = -3/3 = -1\).

M2 · A hyperbola checked against its explicit form

Assuming Assumption 1.3 and Assumption 2.1 of Lesson L06, for \(F(x, y) = xy - 1\) and the point \((1, 1)\), compute \(dy/dx\) by Theorem 2.1, then check it against \(y = 1/x\).

Solution

\(F_x = y = 1\) and \(F_y = x = 1\) at the point, so \(dy/dx = -1\). From \(y = 1/x\), \(dy/dx = -1/x^2 = -1\) at \(x = 1\), which agrees.

M3 · An exponential relation

Assuming Assumption 1.3 and Assumption 2.1 of Lesson L06, for \(F(x, y) = e^x + y - 2\) at \((0, 1)\), find \(dy/dx\) by Theorem 2.1 and by solving for \(y\).

Solution

\(F(0,1) = 1 + 1 - 2 = 0\). \(F_x = e^x = 1\) and \(F_y = 1\), so \(dy/dx = -1\). Solving gives \(y = 2 - e^x\), whose derivative is \(-e^x = -1\) at \(x = 0\).

P1 · A linear relation

Let \(F(x, y) = ax + by - c\) with \(b \ne 0\). Show from first principles that the unique \(y = g(x)\) has \(g'(x) = -F_x/F_y\).

Solution

Solving \(ax + by - c = 0\) gives \(g(x) = (c - ax)/b\) on all of \(\mathbb{R}\), which is unique because \(b \ne 0\). Its derivative is \(-a/b\). Since \(F_x = a\) and \(F_y = b\), \(-F_x/F_y = -a/b\), which is the same.

P2 · The circle's branch

Show that \(g(x) = \sqrt{1 - x^2}\) on \((-1, 1)\) is differentiable with \(g'(x) = -x/\sqrt{1-x^2}\), and that this equals \(-F_x/F_y\) for \(F = x^2 + y^2 - 1\) wherever \(y = g(x) > 0\).

Solution

The function \(1 - x^2\) is positive on \((-1, 1)\), and the square root is differentiable where its argument is positive, with derivative \(\tfrac{1}{2}(1-x^2)^{-1/2}\cdot(-2x) = -x/\sqrt{1-x^2}\). With \(y = \sqrt{1-x^2} > 0\), \(-F_x/F_y = -2x/(2y) = -x/\sqrt{1-x^2}\), which is the same expression.

P3 · No function through the origin

For \(F(x, y) = x^2 + y^2\), show that there is no function \(g\) on an open interval \(I\) containing \(0\) with \(g(0) = 0\) and \(F(x, g(x)) = 0\) on \(I\).

Solution

For \(x \in I\) with \(x \ne 0\), which exists because \(I\) is open and contains \(0\), \(F(x, g(x)) = x^2 + g(x)^2 \ge x^2 > 0\), so \(F(x, g(x)) \ne 0\). That contradicts the requirement, so no such \(g\) exists.

Empirical

E1 · The sign of the slope (Lab 1)

Lab 1 prints a negative slope at every \(x\) it uses. Using \(F_x = y > 0\) and \(F_y > 0\) at those points, explain the sign from Theorem 2.1 without the printed numbers.

Solution

Assuming Assumption 1.3 and Assumption 2.1 of Lesson L06, Theorem 2.1 gives \(dy/dx = -F_x/F_y = -y/(3y^2 + x)\). With \(y > 0\) and \(x > 0\), both the numerator \(y\) and the denominator \(3y^2 + x\) are positive, so the quotient is positive and its negative is negative. The printed slopes are negative, as this predicts.

E2 · Agreement at the four points (Lab 1)

Lab 1's largest difference between the formula and the central difference is 3.9e-12. Explain why a central difference at step \(10^{-5}\) can agree to about this size, and why the agreement is not a proof of the theorem.

Solution

A central difference has truncation error of order \(h^2\), about \(10^{-10}\) times a third derivative, and rounding error of order \(\varepsilon/h\), about \(2 \times 10^{-11}\) at this step. The truncation term is of order \(h^2\) times a third derivative of the root, and the rounding term sets a scale of about \(2 \times 10^{-11}\) at this step; the printed \(3.9 \times 10^{-12}\) lies below that scale. The agreement checks the formula at four points only. The theorem is the statement that the slope equals the formula for every \(x\) in \(I\), which four points cannot establish.

E3 · The residuals (Lab 1)

Lab 1 prints residuals at the rounding level for each root. Explain why small residuals show that the computed \(y\) is close to a solution, and why they do not show that the root is the one that Theorem 1.2 provides.

Solution

A residual \(|F(x, y)|\) at the rounding level means \((x, y)\) is nearly on the curve. Assuming Assumption 1.3 and Assumption 2.1 of Lesson L06, Theorem 1.2 gives a unique solution \(g(x)\) in the interval \(J\) around \(y_0\). The lab takes the root from Newton's method started at \(y = 1\). Its docstring says the iterates converge to the root from that start, but the printed output does not show that the root is unique, and the lab does not check uniqueness.

Research

R1 · The price of a bond as an implicit function of its yield

Let \(P\) be continuously differentiable on \((-1, \infty)\), with \(P'(y) < 0\) for all \(y > -1\). This inequality is a hypothesis of the problem and is not derived here. Let \(P_0\) be a fixed price, and consider \(F(P_0, y) = P(y) - P_0\). Assuming Assumption 1.3 and Assumption 2.1 of Lesson L06, find \(dy/dP_0\) by Theorem 2.1, and state its sign.

Solution

Assuming Assumption 1.3 and Assumption 2.1 of Lesson L06, take \(P_0\) in the role of \(x\) and \(y\) in the role of the dependent variable. Then \(F\) is continuously differentiable, \(F_{P_0} = -1\) and \(F_y = P'(y) \ne 0\), so Theorem 2.1 gives \(dy/dP_0 = -F_{P_0}/F_y = 1/P'(y)\). This is negative because \(P'(y) < 0\) is assumed. A higher price goes with a lower yield. The sign rests on the stated hypothesis \(P'(y) < 0\) and on Assumption 1.3 for the existence of \(y(P_0)\).

R2 · A system of two relations

State the analogue of Theorem 1.2 for two relations \(F_1(x_1, x_2, y_1, y_2) = 0\) and \(F_2 = 0\), using the determinant of the Jacobian with respect to \((y_1, y_2)\) as the non-degeneracy condition, and name the Jacobian object of Lesson L18 that it uses.

Solution

Assume \(F = (F_1, F_2)\) is continuously differentiable near a point where \(F = 0\), and that the Jacobian matrix of \(F\) with respect to \((y_1, y_2)\) is invertible there, which is the condition that its determinant is non-zero. Assuming the system analogue of Assumption 1.3 (not proved here), the relations define \(y\) as a continuously differentiable function of \(x\) near the point. The condition uses the Jacobian of Lesson L18 with respect to the dependent variables. The proof is not given here.

R3 · When is the local statement enough?

An analyst uses the slope of \(g\) at one point to approximate a change over a wide range of \(x\). Explain what Theorem 1.2 licenses and what it does not, and name the quantity that controls how far the approximation holds.

Solution

Assuming Assumption 1.3 and Assumption 2.1 of Lesson L06, Theorem 1.2 licenses a differentiable \(g\) on an interval \(I\) that depends on the point, and the slope formula holds on \(I\). It does not give the size of \(I\), and the slope may change quickly across it. If \(g\) is twice differentiable on the interval, then, assuming Assumption 1.1 of Lesson L08 (the extreme value theorem), Taylor's theorem (Lesson L08, Theorem 2.1) gives the error of the first-order approximation over a change \(\Delta x\) is at most \(\tfrac12 \sup |g''| \, \Delta x^2\) over the interval; Theorem 1.2 does not supply a bound on \(g''\), and does not state that \(g\) is twice differentiable; Lesson L19 treats second-order expansions.

  1. Which condition does Theorem 1.2 require at \((x_0, y_0)\), besides \(F(x_0, y_0) = 0\)?

    Options

    The theorem assumes \(F\) is continuously differentiable with \(F_y\) non-zero at the point.

  2. What is \(dy/dx\) for \(F(x,y) = y^3 + xy - 1\) in general?

    Options

    \(F_x = y\) and \(F_y = 3y^2 + x\), so \(-F_x/F_y = -y/(3y^2 + x)\).

  3. For \(F(x, y) = x^2 + y^2 - 1\) at \((0.6, 0.8)\), what is \(dy/dx\)?

    \(-F_x/F_y = -2x/(2y) = -1.2/1.6 = -0.75\).

  4. For \(F(x, y) = x^2 + xy + y^2 - 3\) at \((1, 1)\), what is \(dy/dx\)?

    \(F_x = 2x + y = 3\) and \(F_y = x + 2y = 3\), so \(dy/dx = -1\).

  5. For the circle \(x^2 + y^2 = 1\) at \((1, 0)\), what does the condition \(F_y \ne 0\) give?

    Options

    Example 3.1: \(F_y = 2y = 0\) at \((1, 0)\), while \(F_x = 2\), so the curve is locally a graph over \(y\) instead.

  6. Does \(x^2 + y^2 = 0\) define a function \(y = g(x)\) with \(g(0) = 0\) on an open interval around \(0\)?

    Options

    Problem P3: for \(x \ne 0\), \(x^2 + g(x)^2 \ge x^2 > 0\).

  7. What does Theorem 2.1 give for \(dy/dx\) when \(F_x\) and \(F_y\) are both non-zero?

    Options

    Differentiating \(F(x, g(x)) = 0\) gives \(F_x + F_y g' = 0\).

  8. For \(F(x,y) = e^x + y - 2\) at \((0, 1)\), what is \(|dy/dx|\)?

    \(F_x = e^0 = 1\) and \(F_y = 1\), so \(dy/dx = -1\) and \(|dy/dx| = 1\).

  9. Why is the implicit-function theorem a local statement?

    Options

    Example 3.1: the circle has two branches over \(x\), and the theorem gives one of them near each point with \(F_y \ne 0\).
