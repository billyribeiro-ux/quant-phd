Taylor's Theorem with Remainder

A Taylor polynomial is an approximation, and the approximation is controlled when its error can be bounded (Corollary 2.2). Taylor's theorem gives the error as a single term that depends on one derivative of order one higher than the degree, evaluated at an unknown point between the centre and the argument. That form lets one bound the error of a polynomial approximation to a function. This lesson states the theorem, proves it with Rolle's theorem applied repeatedly, and checks the remainder for the geometric function, where the unknown point can be solved for exactly.

1Setting and the tool

Let \(I\) be an open interval, and let \(x_0\) be a point of \(I\). The Taylor polynomial of degree \(n\) at \(x_0\) generalizes Definition 2.1 of Lesson 7, which fixed \(x_0 = 0\). For a function whose derivatives up to order \(n\) exist at \(x_0\), it is \[ T_n(x) = \sum_{k=0}^{n} \frac{f^{(k)}(x_0)}{k!}\,(x - x_0)^{k}, \] and the remainder is \(R_n(x) = f(x) - T_n(x)\). Lesson 7, Problem L07-P3, showed that \(T_n\) has the same derivatives as \(f\) up to order \(n\) at 0. The same argument, with \(x_0\) in place of 0, gives the next lemma, which the proof uses.

Assumption 1.1 (Fact 2.1 of Lesson 6, the extreme value theorem, assumed there and not proved here)

Let \(h\) be continuous on a closed interval \([p, q]\) with \(p < q\). Then \(h\) attains a maximum value and a minimum value on \([p, q]\). This is assumed, not proved, in this lesson, as it is in Lesson 6. No grade is given to it here.

Lemma 1.1 (derivatives of \(T_n\) at the centre)

For \(0 \le j \le n\), \(T_n^{(j)}(x_0) = f^{(j)}(x_0)\). Also \(\bigl((x - x_0)^{n+1}\bigr)^{(j)}\) equals 0 at \(x_0\) for \(0 \le j \le n\), and equals \((n+1)!\) for \(j = n+1\).

Proof

Write \(T_n(x) = \sum_{i=0}^{n} c_i (x - x_0)^i\) with \(c_i = f^{(i)}(x_0)/i!\). The \(j\)-th derivative of \((x - x_0)^i\) is \(\frac{i!}{(i-j)!}(x - x_0)^{i-j}\) for \(i \ge j\), and 0 for \(i < j\). At \(x_0\), the term is nonzero only when \(i = j\), giving \(j!\). So \(T_n^{(j)}(x_0) = c_j\,j! = f^{(j)}(x_0)\). The power \((x - x_0)^{n+1}\) has its \(j\)-th derivative \(\frac{(n+1)!}{(n+1-j)!}(x - x_0)^{n+1-j}\), which vanishes at \(x_0\) when \(j \le n\) and equals \((n+1)!\) when \(j = n+1\).

Theorem 1.2 (Rolle's theorem, from Lesson 6)

Assuming Assumption 1.1, let \(p < q\). If \(h\) is continuous on \([p, q]\), differentiable on \((p, q)\), and \(h(p) = h(q)\), then \(h'(c) = 0\) for some \(c\) with \(p < c < q\).

Remark 1.3

Theorem 1.2 is the special case of the mean value theorem of Lesson 6 with equal endpoint values. This lesson uses it in no other form. Its proof is in Lesson 6, which derives the mean value theorem from the extreme value theorem. That theorem is Assumption 1.1 here, so Theorem 1.2 holds under Assumption 1.1 and is not proved on this page.

2Taylor's theorem with the Lagrange remainder

The statement below, with its remainder term, is Taylor's theorem with remainder.

Theorem 2.1 (Taylor's theorem with the Lagrange remainder)

Assuming Assumption 1.1, let \(n \ge 0\) be an integer, and let \(x_0\) lie in an open interval \(I\) on which \(f\) has derivatives up to order \(n+1\). Then for every \(x \in I\) with \(x \ne x_0\) there is a point \(\xi\) strictly between \(x_0\) and \(x\) such that \[ f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(x_0)}{k!}(x - x_0)^{k} + \frac{f^{(n+1)}(\xi)}{(n+1)!}(x - x_0)^{n+1}. \] The last term is the Lagrange form of the remainder. Hypotheses: \(f\) is \((n+1)\) times differentiable on the open interval \(I\), and the centre \(x_0\) and the argument \(x\) both lie in \(I\).

Proof

Fix \(x \ne x_0\) in \(I\), and let \(J\) be the closed interval with endpoints \(x_0\) and \(x\), so \(J \subset I\). Define the constant \(K\) by \(K (x - x_0)^{n+1} = R_n(x)\), and set \[ g(t) = f(t) - T_n(t) - K(t - x_0)^{n+1}, \qquad t \in I. \] Then \(g(x) = 0\) by the choice of \(K\), and \(g(x_0) = f(x_0) - T_n(x_0) = 0\). For \(0 \le j \le n\), Lemma 1.1 gives \(g^{(j)}(x_0) = f^{(j)}(x_0) - f^{(j)}(x_0) - 0 = 0\). Each \(g^{(j)}\) with \(j \le n+1\) exists on \(I\), since \(f\) has derivatives to order \(n+1\) there. Construct a sequence of points \(y_0, y_1, \ldots, y_{n+1}\) in \(J\) as follows, starting from \(y_0 = x\). Suppose \(0 \le j \le n\) and that \(y_j\) is a point of \(J\) with \(y_j \ne x_0\) and \(g^{(j)}(y_j) = 0\). Since \(g^{(j)}(x_0) = 0\) and \(g^{(j)}\) is differentiable on \(I\), it is continuous on the closed interval between \(x_0\) and \(y_j\), and Rolle's theorem (Theorem 1.2) gives a point \(y_{j+1}\) strictly between \(x_0\) and \(y_j\) with \(g^{(j+1)}(y_{j+1}) = 0\). The point \(y_{j+1}\) lies in \(J\) and differs from \(x_0\), so the step can be repeated. The starting point satisfies \(g^{(0)}(y_0) = g(x) = 0\) and \(x \ne x_0\), so the induction runs for \(j = 0, 1, \ldots, n\). Set \(\xi = y_{n+1}\). It lies strictly between \(x_0\) and \(x\), because each \(y_{j+1}\) lies strictly between \(x_0\) and \(y_j\), and every \(y_j\) lies strictly between \(x_0\) and \(x\) for \(j \ge 1\). Now \(g^{(n+1)}(t) = f^{(n+1)}(t) - K(n+1)!\), by Lemma 1.1, since \(T_n\) has degree \(n\). Since \(g^{(n+1)}(\xi) = 0\), we get \(K = f^{(n+1)}(\xi)/(n+1)!\). Substituting into \(R_n(x) = K(x - x_0)^{n+1}\) gives the displayed identity.

Corollary 2.2 (a bound on an interval)

Under the hypotheses of Theorem 2.1 and Assumption 1.1, suppose \(|f^{(n+1)}(t)| \le M\) for every \(t\) in the closed interval \(J\) with endpoints \(x_0\) and \(x\). Then \(|R_n(x)| \le M\,|x - x_0|^{n+1}/(n+1)!\).

Proof

The point \(\xi\) of Theorem 2.1 lies in \(J\), so \(|f^{(n+1)}(\xi)| \le M\). Taking absolute values in the Lagrange form gives the bound.

Example 2.3 (\(1/(1-x)\) at 0, with \(\xi\) in closed form)

Let \(f(x) = 1/(1-x)\), \(x_0 = 0\), and \(0 < x < 1\). By Lesson 7, Proposition 2.3, \(R_n(x) = x^{n+1}/(1-x)\). The Lagrange form needs \(f^{(n+1)}(\xi) = (n+1)!/(1-\xi)^{n+2}\), so the theorem asks for \(\xi\) with \((1 - \xi)^{n+2} = 1 - x\). Put \(\xi = 1 - (1-x)^{1/(n+2)}\). Since \(0 < 1 - x < 1\), the power \((1-x)^{1/(n+2)}\) lies strictly between \(1 - x\) and 1, so \(0 < \xi < x\), and the point satisfies the equation. Therefore the Lagrange form at this \(\xi\) equals \(x^{n+1}/(1-x)\), as required.

Example 2.4 (a bound on \([0, 1/2]\))

On \([0, 1/2]\), \(|f^{(n+1)}(t)| = (n+1)!/(1-t)^{n+2} \le (n+1)!\,2^{n+2}\). Under Assumption 1.1, Corollary 2.2 with \(M = (n+1)!\,2^{n+2}\) gives \(|R_n(x)| \le 2^{n+2}x^{n+1}\) for \(0 \le x \le 1/2\). For \(0 < x \le 1/2\), the exact ratio is \(R_n(x)/x^{n+1} = 1/(1-x) \in (1, 2]\), so the bound divided by the exact remainder is \(2^{n+2}(1-x)\), which lies in \([2^{n+1}, 2^{n+2})\).

Lab 1 · The Lagrange remainder of \(1/(1-x)\), checked at sampled points

Stated before running: for each of the 133 points \(x = k/20\) (\(k = 1, \ldots, 19\)) and each degree \(n = 0, \ldots, 6\), the point \(\xi = 1 - (1-x)^{1/(n+2)}\) lies strictly between 0 and \(x\), and the Lagrange form at \(\xi\) equals the exact remainder \(x^{n+1}/(1-x)\) (part A). On \([0, 1/2]\) the bound of Example 2.4 holds at every sampled point (part B). A table of sample rows follows (part C).

"""M2 L08 lab 1: the Lagrange remainder of 1/(1 - x) at 0, checked at sampled points.

For f(x) = 1/(1 - x) and x0 = 0, the Taylor polynomial of degree n is T_n(x) = sum of x^k for k = 0..n, and the
remainder is R_n(x) = f(x) - T_n(x) = x^(n+1)/(1 - x) (Lesson 7, Proposition 2.3). Taylor's theorem with the
Lagrange form (Theorem 2.1 of this lesson) says R_n(x) = f^(n+1)(xi) x^(n+1) / (n+1)!
for some xi strictly between 0 and x.
Here f^(n+1)(t) = (n+1)! / (1 - t)^(n+2), so the theorem asks for xi with (1 - xi)^(n+2) = 1 - x. The program
computes that xi in closed form, xi = 1 - (1 - x)^(1/(n+2)), and checks two things at 19 x 7 = 133 sampled points
(x = k/20 for k = 1..19; n = 0..6): that 0 < xi < x, and that the Lagrange form evaluated at xi equals the exact
remainder. Part B checks the bound of Corollary 2.2 of this lesson on [0, 1/2]: |R_n(x)| <= 2^(n+2) x^(n+1), at every
sampled x in that interval. Part C prints a few rows of the table. Standard library only; no randomness and no
network access.
"""

from __future__ import annotations

import math
from math import factorial

N_VALUES = range(0, 7)
X_GRID = [k / 20 for k in range(1, 20)]


def derivative(k: int, t: float) -> float:
    """k-th derivative of 1/(1 - t): k! / (1 - t)^(k+1), for t < 1."""
    return factorial(k) / (1 - t) ** (k + 1)


def remainder_exact(x: float, n: int) -> float:
    """R_n(x) = x^(n+1) / (1 - x), the closed form of the remainder for 1/(1 - x) at 0."""
    return x ** (n + 1) / (1 - x)


def xi_for(x: float, n: int) -> float:
    """The point xi that Taylor's theorem asks for: the solution of (1 - xi)^(n+2) = 1 - x in (0, x)."""
    return float(1 - (1 - x) ** (1 / (n + 2)))


def lagrange_form(x: float, n: int, xi: float) -> float:
    """f^(n+1)(xi) x^(n+1) / (n+1)!, the Lagrange form of the remainder evaluated at xi."""
    return derivative(n + 1, xi) * x ** (n + 1) / factorial(n + 1)


def part_a() -> None:
    checks = 0
    for x in X_GRID:
        for n in N_VALUES:
            xi = xi_for(x, n)
            if not 0 < xi < x:
                raise AssertionError(f"xi is not strictly between 0 and x at x = {x}, n = {n}")
            if not math.isclose(lagrange_form(x, n, xi), remainder_exact(x, n), rel_tol=1e-9):
                raise AssertionError(f"Lagrange form differs from the exact remainder at x = {x}, n = {n}")
            checks += 1
    print(f"part A: {checks} points (x = k/20, k = 1 to 19; n = 0 to 6): 0 < xi < x at every point")
    print("part A: the Lagrange form at xi equals the exact remainder to relative error 1e-9 at every point")


def part_b() -> None:
    checks = 0
    for x in X_GRID:
        if x > 0.5:
            continue
        for n in N_VALUES:
            bound = 2 ** (n + 2) * x ** (n + 1)
            if not remainder_exact(x, n) <= bound:
                raise AssertionError(f"Corollary bound fails at x = {x}, n = {n}")
            checks += 1
    print(f"part B: the bound |R_n(x)| <= 2^(n+2) x^(n+1) holds at all {checks} points with 0 < x <= 1/2")


def part_c() -> None:
    print("part C: a sample of rows, with xi from the closed form")
    print("part C:     x     n        xi        R_n(x) exact    Lagrange form at xi")
    for x in (0.1, 0.3, 0.5, 0.9):
        for n in (1, 3, 5):
            xi = xi_for(x, n)
            print(
                f"part C: {x:5.2f} {n:4d}  {xi:10.6f}  {remainder_exact(x, n):14.8f}  {lagrange_form(x, n, xi):14.8f}"
            )


def main() -> None:
    part_a()
    part_b()
    part_c()

3Where the canon breaks

Remark 3.1 (the interval must avoid singularities)

Theorem 2.1 requires an open interval \(I\) that contains \(x_0\) and \(x\) and on which \(f\) has the derivatives. For \(f(x) = 1/(1-x)\), the point \(x = 1\) is a singularity, so no such interval contains both 0 and 2. At \(x = 2\), the theorem does not apply, and Lesson 7, Lab 1 part C shows the remainder growing, which is consistent with that.

Remark 3.2 (the point \(\xi\) is not computed in general)

The theorem asserts that \(\xi\) exists. For \(1/(1-x)\), Example 2.3 solves for it, but Theorem 2.1 gives no formula for \(\xi\) in general, and the bound of Corollary 2.2 replaces \(f^{(n+1)}(\xi)\) by a supremum over \(J\). The supremum can be large: the bound of Example 2.4 has the factor \(2^{n+2}\), which grows with \(n\).

Remark 3.3 (a bound can grow while the error shrinks)

On \([0, x]\) with \(0 < x < 1\), the supremum of \(|f^{(n+1)}|\) is \((n+1)!/(1-x)^{n+2}\), so Corollary 2.2 (under Assumption 1.1) gives the bound \(x^{n+1}/(1-x)^{n+2}\). Take \(x = 0.6\). The bound is \(0.36/0.064 = 5.625\) at \(n = 1\) and \(0.216/0.0256 = 8.4375\) at \(n = 2\), so it grows. The exact remainder is \(0.36/0.4 = 0.9\) at \(n = 1\) and \(0.216/0.4 = 0.54\) at \(n = 2\), so it shrinks. A bound that grows with \(n\) is not evidence that the approximation worsens.

4Misconceptions

  1. “The derivative of order \(n+1\) at the centre \(x_0\) alone is enough for the expansion.”

    The proof applies Rolle's theorem to \(g^{(j)}\) on the interval between \(x_0\) and \(y_j\), so \(g^{(j)}\) must be differentiable on an interval, not at one point. Theorem 2.1 therefore assumes the derivatives on the open interval \(I\), which contains \(x_0\) and \(x\), and the proof uses that assumption in each Rolle step.

  2. “The Lagrange remainder gives the exact error without further work.”

    The Lagrange form is exact only at the unknown point \(\xi\). Lab 1, part C prints the exact remainder and the Lagrange form at \(\xi\) side by side, and they agree because the closed-form \(\xi\) of Example 2.3 solves \((1-\xi)^{n+2} = 1-x\), the equation that the theorem requires. For a general function, the theorem gives the existence of \(\xi\) and nothing about its value, so the error is bounded, not computed.

  3. “A larger degree always gives a smaller bound.”

    Remark 3.3 gives the bound \(x^{n+1}/(1-x)^{n+2}\) on \([0, x]\). At \(x = 0.6\) it grows from \(5.625\) at \(n = 1\) to \(8.4375\) at \(n = 2\), while the exact remainder shrinks from \(0.9\) to \(0.54\). The bound is a bound and not the error, so its monotonicity in \(n\) says nothing about the error.

Mechanics

M2-L08 · The quartic at 1

For \(f(x) = x^4\) with \(x_0 = 1\) and \(n = 3\), write \(T_3\) and the Lagrange remainder, and check the identity.

Solution

The derivatives at 1 are \(f(1) = 1\), \(f'(1) = 4\), \(f''(1) = 12\), and \(f'''(1) = 24\). So \(T_3(x) = 1 + 4(x-1) + 6(x-1)^2 + 4(x-1)^3\). Since \(f^{(4)}(\xi) = 24\) for every \(\xi\), the Lagrange remainder is \(24(x-1)^4/4! = (x-1)^4\). Expanding gives \(x^4 = T_3(x) + (x-1)^4\), which is the binomial theorem and confirms the identity.

M2-L08 · The point \(\xi\) at \(x = 1/4\)

For \(f(x) = 1/(1-x)\), \(x_0 = 0\), \(x = 1/4\) and \(n = 2\), compute \(T_2(1/4)\), the exact remainder, and the point \(\xi\) of Example 2.3.

Solution

Proposition 2.3 of Lesson 7 gives \(T_2(1/4) = 1 + 1/4 + 1/16 = 21/16 = 1.3125\). The exact remainder is \(f(1/4) - T_2(1/4) = 4/3 - 21/16 = 1/48\), which agrees with \(x^3/(1-x) = (1/64)/(3/4) = 1/48\). The point is \(\xi = 1 - (3/4)^{1/4} \approx 0.0693951\), computed from the unrounded power. It lies in \((0, 1/4)\).

M2-L08 · A bound on \([0, 1/4]\)

For \(f(x) = 1/(1-x)\) and \(n = 1\), find the supremum \(M\) of \(|f''|\) on \([0, 1/4]\), apply Corollary 2.2 at \(x = 1/4\), and compare with the exact remainder.

Solution

Here \(f''(t) = 2/(1-t)^3\), which increases in \(t\), so the supremum on \([0, 1/4]\) is at \(t = 1/4\): \(M = 2/(3/4)^3 = 128/27\). Corollary 2.2 gives \(|R_1(1/4)| \le (128/27)(1/16)/2 = 4/27 \approx 0.148148\). The exact remainder is \((1/16)/(3/4) = 1/12 \approx 0.083333\), which is below the bound.

M2-L08 · Taylor coefficients about a general centre

Prove Lemma 1.1 for the \(j\)-th derivative of \(T_n\) at \(x_0\), by a direct computation that does not cite the lemma.

Solution

Write \(T_n(x) = \sum_{i=0}^{n} c_i(x - x_0)^i\) with \(c_i = f^{(i)}(x_0)/i!\). Differentiating \(j\) times term by term, the \(i\)-th term becomes \(c_i\,i!/(i-j)!\,(x-x_0)^{i-j}\) when \(i \ge j\), and 0 when \(i < j\). At \(x = x_0\), only \(i = j\) survives, giving \(c_j\,j! = f^{(j)}(x_0)\). The term \((x - x_0)^{n+1}\) has the same form with \(c = 1\) and \(i = n+1\), and its \(j\)-th derivative vanishes at \(x_0\) when \(j \le n\).

M2-L08 · The point of Example 2.3 lies inside the interval

For \(0 < x < 1\) and \(n \ge 0\), prove that \(\xi = 1 - (1-x)^{1/(n+2)}\) satisfies \(0 < \xi < x\).

Solution

Let \(c = 1 - x\), so \(0 < c < 1\), and let \(m = n + 2 \ge 2\). Since \(0 < c < 1\) and \(1/m \in (0, 1)\), we have \(c < c^{1/m} < 1\): the first inequality holds because raising \(c\) to a power in \((0,1)\) increases it, and the second because a power of a number below 1 is below 1. So \(0 < 1 - c^{1/m} < 1 - c = x\), which is \(0 < \xi < x\).

M2-L08 · The bound from the interval's supremum

State precisely why Corollary 2.2 needs the bound \(M\) on the closed interval \(J\), not only at the endpoint \(x\), and give the proof of the corollary from Theorem 2.1.

Solution

The point \(\xi\) of Theorem 2.1 depends on \(x\) and on \(n\), and it is not known in advance. Its location can be anywhere strictly between \(x_0\) and \(x\), so the bound must hold on all of \(J\) to cover \(f^{(n+1)}(\xi)\). Once \(|f^{(n+1)}(t)| \le M\) on \(J\), we have \(|f^{(n+1)}(\xi)| \le M\), and multiplying the Lagrange form by absolute values gives \(|R_n(x)| \le M|x-x_0|^{n+1}/(n+1)!\).

Empirical

M2-L08 · Checking a printed row

Lab 1, part C prints \(\xi = 0.129449\) at \(x = 0.5\) and \(n = 3\). Recompute \(\xi\) from the closed form and check the printed exact remainder.

Solution

The closed form gives \(\xi = 1 - (1/2)^{1/5}\), and \((1/2)^{1/5} = 0.8705506\) to seven digits, so \(\xi = 0.1294494\), which agrees with the printed \(0.129449\) in six decimals. The exact remainder is \((1/2)^4/(1/2) = 1/8 = 0.125\), which the lab prints as \(0.12500000\).

M2-L08 · Reproducing the \(x = 0.3\) point

Lab 1, part C prints \(\xi = 0.049677\) at \(x = 0.3\) and \(n = 5\). Recompute it from the closed form.

Solution

The closed form is \(\xi = 1 - (0.7)^{1/7}\). Computing \((0.7)^{1/7}\) from its unrounded value gives \(0.9503228\) to seven digits, so \(\xi = 0.0496772\), which agrees with the printed \(0.049677\). Example 2.3 proves that \(0 < \xi < 0.3\).

M2-L08 · The growing bound at \(x = 0.6\)

Using Remark 3.3, tabulate the bound and the exact remainder at \(x = 0.6\) for \(n = 1, 2, 3, 4\), and state where the two sequences move in different directions.

Solution

The bound \(0.6^{n+1}/0.4^{n+2}\) gives \(5.625\), \(8.4375\), \(12.65625\), and \(18.984375\) for \(n = 1\) to 4. The exact remainder \(0.6^{n+1}/0.4\) gives \(0.9\), \(0.54\), \(0.324\), and \(0.1944\). The bound increases at each step and the remainder decreases at each step, because the bound's ratio between consecutive degrees is \(0.6/0.4 = 1.5\), while the remainder's is \(0.6\).

Research

M2-L08 · The point \(\xi\) tends to the centre

For \(0 < x < 1\) fixed, prove that \(\xi_n = 1 - (1-x)^{1/(n+2)}\) tends to 0 as \(n\) grows.

Solution

Let \(c = 1 - x \in (0, 1)\) and \(a_m = c^{1/m} = 1/(1 + h_m)\) with \(h_m = c^{-1/m} - 1 \ge 0\). Then \((1+h_m)^m = 1/c\). By the Bernoulli inequality \((1 + h)^m \ge 1 + mh\) for \(h \ge 0\) (proved in the proof of Lesson 7, Lemma 3.1), \(1/c \ge 1 + m h_m\), so \(0 \le h_m \le (1/c - 1)/m\). The right side tends to 0 as \(m\) grows, so \(h_m \to 0\) and \(a_m \to 1\). Hence \(\xi_n = 1 - a_{n+2} \to 0\).

M2-L08 · Where the bound on \([0, x]\) tends to 0

For \(0 < x < 1\), the bound of Remark 3.3 is \(B_n(x) = x^{n+1}/(1-x)^{n+2}\). Prove that \(B_n(x) \to 0\) as \(n\) grows if and only if \(x < 1/2\).

Solution

Write \(B_n(x) = r^{n+1}/(1-x)\) with \(r = x/(1-x) \ge 0\). If \(x < 1/2\), then \(r < 1\), so \(r^{n+1} \to 0\) by Lesson 7, Lemma 3.1, and \(B_n \to 0\). If \(x = 1/2\), then \(r = 1\) and \(B_n(1/2) = 2\) for every \(n\), which does not tend to 0. If \(x > 1/2\), then \(r > 1\), and \(r^{n+1} \to \infty\), so \(B_n\) grows without bound. So the bound tends to 0 exactly when \(x < 1/2\).

M2-L08 · A degree for the bound at one half

Using the bound of Example 2.4 on \([0, 1/2]\), find the bound on \(|R_n(1/2)|\) for each \(n\), and explain why it cannot certify any tolerance smaller than 2.

Solution

Example 2.4 gives \(|R_n(x)| \le 2^{n+2}x^{n+1}\), which at \(x = 1/2\) equals \(2^{n+2}/2^{n+1} = 2\) for every \(n\). The bound is 2 at every degree. The exact remainder at \(1/2\) is \((1/2)^n\), which tends to 0. So the bound certifies no tolerance below 2, while the true error becomes arbitrarily small. This is the cost of replacing \(f^{(n+1)}(\xi)\) by a supremum over \([0, 1/2]\) that is attained at the endpoint.
