Limits of Functions and One-Sided Limits

  • Uses: the limit of a sequence (Lesson 1, Definition 2.1); the sequential form of continuity (Lesson 2, §2)
  • Introduces: no new concept. The word limit keeps the meaning of Lesson 1, and this lesson states it for functions.
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study or lab result
  • Dlore
  • Xrefuted

A payoff function can be defined by one formula on one side of a point and by another formula on the other side. A pricing rule can change at a threshold, and a limit is the tool that says what the rule does as the price approaches that threshold. This lesson states the limit of a function at a point, with \(\varepsilon\) and \(\delta\), links it to sequences, and treats one-sided limits. It shows that when the limits from the left and from the right at a point differ, the function has no two-sided limit there.

1Limits of a function at a point

An open interval \((c, d)\), with \(c < d\), is the set of real \(x\) with \(c < x < d\). Let \(f\) be a function defined on an open interval \(I\) that contains a point \(a\), except that \(f\) need not be defined at \(a\) itself. The value \(f(a)\), if it exists, plays no role in the limit at \(a\).

Definition 1.1 (limit of a function at a point)

Let \(f\) and \(I\) be as above, and let \(L\) be a real number. We write \(\lim_{x \to a} f(x) = L\) when the following holds: for every \(\varepsilon > 0\) there is \(\delta > 0\) such that \(|f(x) - L| < \varepsilon\) for every \(x\) in \(I\) with \(0 < |x - a| < \delta\). This uses the meaning of "limit" from Lesson 1, carried over from sequences to functions. It defines no new concept.

Example 1.2 (a linear function)

Let \(f(x) = 3x + 1\) on \(\R\). Then \(\lim_{x \to 2} f(x) = 7\). Proof: let \(\varepsilon > 0\) and put \(\delta = \varepsilon/3\). If \(0 < |x - 2| < \delta\), then \(|f(x) - 7| = |3x - 6| = 3|x - 2| < 3\delta = \varepsilon\). So the condition of Definition 1.1 holds with this \(\delta\).

Proposition 1.3 (sequences and the limit of a function)

Let \(f\) and \(I\) be as in Definition 1.1, and suppose \(\lim_{x \to a} f(x) = L\). Let \((x_n)\) be a sequence with each \(x_n\) in \(I\), each \(x_n \ne a\), and \(x_n \to a\). Then \(f(x_n) \to L\). Hypotheses: the limit of \(f\) at \(a\) is \(L\) in the sense of Definition 1.1, and the sequence avoids \(a\).

Proof

Let \(\varepsilon > 0\). Choose \(\delta > 0\) from Definition 1.1. Since \(x_n \to a\), there is \(N\) with \(|x_n - a| < \delta\) for every \(n \ge N\). For such \(n\), \(x_n \in I\) and \(0 < |x_n - a| < \delta\), because \(x_n \ne a\). Definition 1.1 gives \(|f(x_n) - L| < \varepsilon\). Since \(\varepsilon\) was arbitrary, \(f(x_n) \to L\). \(\blacksquare\)

Corollary 1.4 (a limit equal to the value is continuity)

Let \(f\) be defined on \(I\), let \(a \in I\), and suppose that \(\lim_{x \to a} f(x) = f(a)\). Hypotheses: the limit exists in the sense of Definition 1.1 and equals the value of \(f\) at \(a\). Then \(f\) is continuous at \(a\) in the sequential sense of Lesson 2, §2.

Proof

Let \((x_n)\) be a sequence in \(I\) with \(x_n \to a\). Let \(\varepsilon > 0\), with \(\delta\) from Definition 1.1 for \(L = f(a)\). Choose \(N\) with \(|x_n - a| < \delta\) for \(n \ge N\). For such \(n\), either \(x_n = a\), and then \(|f(x_n) - f(a)| = 0 < \varepsilon\), or \(0 < |x_n - a| < \delta\), and then \(|f(x_n) - f(a)| < \varepsilon\) by Definition 1.1. So \(f(x_n) \to f(a)\). \(\blacksquare\)

2One-sided limits

Definition 2.1 (one-sided limits)

Let \(f\) be defined on an open interval \(I\) containing \(a\), except possibly at \(a\). Let \(L\) be a real number. We write \(\lim_{x \to a^+} f(x) = L\), the right-hand limit, when for every \(\varepsilon > 0\) there is \(\delta > 0\) with \(|f(x) - L| < \varepsilon\) for every \(x\) in \(I\) with \(a < x < a + \delta\). We write \(\lim_{x \to a^-} f(x) = L\), the left-hand limit, when the same holds with \(a - \delta < x < a\) in place of \(a < x < a + \delta\).

Proposition 2.2 (the two-sided limit needs both one-sided limits)

Let \(f\) be defined on an open interval \(I\) containing \(a\), except possibly at \(a\), and let \(L\) be real. Then \(\lim_{x \to a} f(x) = L\) if and only if \(\lim_{x \to a^+} f(x) = L\) and \(\lim_{x \to a^-} f(x) = L\). Hypotheses: \(f\) is defined on \(I\) minus possibly \(a\), and \(I\) contains \(a\) in its interior.

Proof

(Only if.) Let \(\varepsilon > 0\) and take \(\delta\) from Definition 1.1. Every \(x\) with \(a < x < a + \delta\) satisfies \(0 < |x - a| < \delta\), so \(|f(x) - L| < \varepsilon\). The right-hand limit is \(L\). The same argument on the left gives the left-hand limit.

(If.) Let \(\varepsilon > 0\), and take \(\delta_+\) and \(\delta_-\) from Definition 2.1 for the two sides. Put \(\delta = \min(\delta_+, \delta_-)\). Let \(x\) satisfy \(0 < |x - a| < \delta\). If \(x > a\), then \(a < x < a + \delta_+\), so \(|f(x) - L| < \varepsilon\). If \(x < a\), then \(a - \delta_- < x < a\), so \(|f(x) - L| < \varepsilon\). Hence \(\lim_{x \to a} f(x) = L\). \(\blacksquare\)

Example 2.3 (a piecewise function with no two-sided limit at its break)

Let \(f(x) = x^2\) for \(x < 1\) and \(f(x) = 2x\) for \(x \ge 1\). Its left-hand limit at 1 is 1: for \(0 < 1 - x < \delta \le 1\), we have \(|x^2 - 1| = |x - 1|\,|x + 1| < 2\delta\), because \(|x + 1| < 2\) there, and \(\delta = \min(1, \varepsilon/2)\) works. Its right-hand limit at 1 is 2: for \(0 < x - 1 < \delta\), \(|2x - 2| = 2|x - 1| < 2\delta\), and \(\delta = \varepsilon/2\) works. The two one-sided limits differ, so by Proposition 2.2 the two-sided limit at 1 does not exist.

Example 2.3 uses Proposition 2.2 in the form that the two-sided limit, if it exists, equals each one-sided limit. The lab below computes the one-sided values at 1 and checks the choice \(\delta = \varepsilon/3\) of Example 1.2 on a grid for three tolerances.

Lab 1 · One-sided values at a break and an epsilon-delta grid

Predicted before running, from Example 2.3. At \(h = 0.1\), \(f(1 - h) = 0.81\) and \(f(1 + h) = 2.2\), so the gap is \(1.39\). In general \(f(1 - h) = (1 - h)^2\) and \(f(1 + h) = 2 + 2h\), so the gap is \(1 + 4h - h^2\), which tends to 1 as \(h\) falls, and the left and right values tend to 1 and 2. For Example 1.2, \(\delta = \varepsilon/3\) should work at each of the tolerances \(0.1\), \(0.01\) and \(0.001\), and the grid check should print True in all three cases.

"""M2 lab L03: one-sided limits of a piecewise function at its break, and an epsilon-delta check.

Standard library only. No randomness and no network. The piecewise function is f(x) = x^2 for x < 1 and
f(x) = 2x for x >= 1. Its left-hand values tend to 1 and its right-hand values tend to 2 as x tends to 1, so the
two-sided limit at 1 does not exist. Each value is an exact rational number (fractions.Fraction). The second part
checks, on a finite grid of points x with 0 < |x - 2| < delta, that delta = epsilon/3 gives |g(x) - 7| < epsilon
for g(x) = 3x + 1 (limit 7 at x = 2), for three values of epsilon. The grid is a finite check of one choice
of delta. The epsilon-delta proof on the page covers every x.
"""

from __future__ import annotations

from fractions import Fraction

BREAK = Fraction(1)


def f(x: Fraction) -> Fraction:
    """The piecewise function: x^2 when x < 1, and 2x when x >= 1. Exact for a rational x."""
    return x * x if x < BREAK else 2 * x


def g(x: Fraction) -> Fraction:
    """The linear function 3x + 1, whose limit at 2 is 7."""
    return 3 * x + 1


def grid_points(centre: Fraction, radius: Fraction) -> list[Fraction]:
    """Points centre + (k/20) * radius for k from -19 to 19, k != 0. Each satisfies 0 < |x - centre| < radius."""
    return [centre + Fraction(k, 20) * radius for k in range(-19, 20) if k != 0]


def delta_works(epsilon: Fraction) -> bool:
    """True when every grid point with 0 < |x - 2| < epsilon/3 has |g(x) - 7| < epsilon."""
    delta = epsilon / 3
    return all(abs(g(x) - 7) < epsilon for x in grid_points(Fraction(2), delta))


def main() -> None:
    print("h, f(1 - h), f(1 + h), gap f(1 + h) - f(1 - h)")
    for k in range(1, 5):
        h = Fraction(1, 10**k)
        left, right = f(BREAK - h), f(BREAK + h)
        print(f"{float(h):g}, {float(left):.6f}, {float(right):.6f}, {float(right - left):.6f}")
    for epsilon in (Fraction(1, 10), Fraction(1, 100), Fraction(1, 1000)):
        print(f"epsilon {float(epsilon):g}: delta = epsilon/3 works on the grid: {delta_works(epsilon)}")

The left-hand values in the table approach 1 and the right-hand values approach 2, and the gap approaches 1, so no single number is the two-sided limit at 1. The grid check tests \(\delta = \varepsilon/3\) at 38 points with \(0 < |x - 2| < \delta\), for each of the three tolerances. It is a finite check of one choice of \(\delta\), and the proof in Example 1.2 covers every \(x\). C Basis: Lab 1.

Example 2.4 (a limit at a point where the function is undefined)

Let \(g(x) = (x^2 - 1)/(x - 1)\) for \(x \ne 1\), and leave \(g(1)\) undefined. For \(x \ne 1\), \(g(x) = x + 1\). So \(|g(x) - 2| = |x - 1|\), and given \(\varepsilon > 0\), \(\delta = \varepsilon\) gives \(|g(x) - 2| < \varepsilon\) for \(0 < |x - 1| < \delta\). Hence \(\lim_{x \to 1} g(x) = 2\), even though \(g(1)\) is not defined.

3Where the canon breaks

The definition is exact. Three points of practice need care.

  • The limit ignores the value at the point. Example 2.4 has a limit at 1 with no value there. Corollary 1.4 applies when the value exists and equals the limit, and then the function is continuous at the point in the sequential sense.
  • Boundedness does not give a limit. A function can be bounded near a point and have no limit there. Misconception 2 gives the example.
  • This lesson defines no infinite limits. Statements such as \(f(x) \to \infty\) need a separate definition, which this lesson does not give. The claims here concern finite limits.

4Misconceptions

  1. “The limit at \(a\) depends on the value \(f(a)\).”

    Definition 1.1 excludes \(x = a\) by the condition \(0 < |x - a|\). Example 2.4 has no value at 1 and still has the limit 2. If \(g(1)\) were set to 5, the limit would still be 2, because no value at 1 enters the definition.

  2. “A bounded function must have a limit at every point.”

    Let \(w(x) = 1\) for \(x \ge 0\) and \(w(x) = -1\) for \(x < 0\). Then \(|w(x)| = 1\) for every \(x\), so \(w\) is bounded. Its left-hand limit at 0 is \(-1\) and its right-hand limit is 1. By Proposition 2.2, the two-sided limit at 0 does not exist.

  3. “The right-hand limit equals \(f(a)\) whenever \(f\) is defined at \(a\).”

    Let \(f(x) = x\) for \(x > 0\) and \(f(0) = 5\). The right-hand limit at 0 is 0, by Definition 2.1, while \(f(0) = 5\). The right-hand limit is a property of the values near 0, and the value at 0 is a separate fact.

Mechanics

M1 · A threshold for a linear function

For \(f(x) = 2x - 1\) and \(a = 3\), find a \(\delta\) that works for \(\varepsilon = 0.02\) in Definition 1.1.

Solution

We have \(|f(x) - 5| = |2x - 6| = 2|x - 3|\). This is less than \(0.02\) when \(|x - 3| < 0.01\). So \(\delta = 0.01\) works. Any smaller positive \(\delta\) also works, so one \(\delta\) is enough.

M2 · The sign function

Let \(s(x) = |x|/x\) for \(x \ne 0\). Find the left-hand and right-hand limits at 0, and say whether the two-sided limit exists.

Solution

For \(x > 0\), \(|x|/x = 1\), so the right-hand limit is 1. For \(x < 0\), \(|x|/x = -1\), so the left-hand limit is \(-1\). These differ, so by Proposition 2.2 the two-sided limit at 0 does not exist. The function is not defined at 0, and that fact is not what makes the limit fail.

M3 · A factor that cancels

Let \(q(x) = (x^2 - 4)/(x - 2)\) for \(x \ne 2\). Find \(\lim_{x \to 2} q(x)\).

Solution

For \(x \ne 2\), \(x^2 - 4 = (x - 2)(x + 2)\), so \(q(x) = x + 2\). Then \(|q(x) - 4| = |x - 2|\), and \(\delta = \varepsilon\) works, as in Example 2.4. The limit is 4.

Proof

P1 · A constant function

Let \(f(x) = c\) for every \(x\) in an open interval containing \(a\). Prove from Definition 1.1 that \(\lim_{x \to a} f(x) = c\).

Solution

Let \(\varepsilon > 0\), and take \(\delta = 1\), for example. For every \(x\) with \(0 < |x - a| < 1\), \(|f(x) - c| = |c - c| = 0 < \varepsilon\). So the condition of Definition 1.1 holds, and the limit is \(c\).

P2 · The square at a point

Prove from Definition 1.1 that \(\lim_{x \to a} x^2 = a^2\) for every real \(a\).

Solution

Let \(\varepsilon > 0\), and put \(\delta = \min\bigl(1, \varepsilon/(1 + 2|a|)\bigr)\). If \(0 < |x - a| < \delta\), then \(|x + a| \le |x - a| + 2|a| < 1 + 2|a|\). So \(|x^2 - a^2| = |x - a|\,|x + a| < \delta(1 + 2|a|) \le \varepsilon\). Hence the limit is \(a^2\).

P3 · Uniqueness of the limit of a function

Suppose \(\lim_{x \to a} f(x) = L\) and \(\lim_{x \to a} f(x) = M\). Prove that \(L = M\).

Solution

Let \(\varepsilon > 0\). Take \(\delta_1\) for \(L\) and \(\delta_2\) for \(M\), with \(\varepsilon/2\) in place of \(\varepsilon\) in each. Put \(\delta = \min(\delta_1, \delta_2)\). For \(0 < |x - a| < \delta\), \(|L - M| \le |f(x) - L| + |f(x) - M| < \varepsilon\). Since \(\varepsilon\) was arbitrary, \(|L - M| = 0\), so \(L = M\).

Empirical

E1 · Checking the left-hand value (from Lab 1)

Lab 1 prints \(f(1 - h)\) at \(h = 0.001\) as 0.998001. Check it from the closed form \((1 - h)^2\), and say which side of 1 this value is on.

Solution

We have \((1 - 0.001)^2 = 0.999^2 = 0.998001\), which is the printed value. Since \(1 - h < 1\), the point lies left of the break, and \(f\) uses the formula \(x^2\) there, so the printed value is the left-hand value at that point.

E2 · The gap column (from Lab 1)

The gap column prints 1.039900 at \(h = 0.01\). Check it from the closed form \(1 + 4h - h^2\).

Solution

At \(h = 0.01\), \(1 + 4(0.01) - (0.01)^2 = 1 + 0.04 - 0.0001 = 1.0399\), which is the printed 1.039900. The gap tends to 1 because \(4h - h^2 \to 0\) as \(h \to 0\). The one-sided values tend to 1 and 2 for the same reason, since \((1 - h)^2 \to 1\) and \(2 + 2h \to 2\).

E3 · A prediction the lab does not test

Without running the lab, predict whether the grid check would print True for the choice \(\delta = \varepsilon\), instead of \(\delta = \varepsilon/3\), at \(\varepsilon = 0.1\). Say what the prediction rests on.

Solution

Take \(x = 2 + (19/20)\cdot 0.1\), which is a grid point with \(0 < |x - 2| < 0.1\). Then \(|3x + 1 - 7| = 3 \cdot 0.095 = 0.285\), which is larger than \(0.1\), so the check would print False. The prediction rests on the formula \(|f(x) - 7| = 3|x - 2|\) and not on any run of the lab, which does not test \(\delta = \varepsilon\).

Research

R1 · A function that is zero except on the rationals

Let \(f(x) = x^2\) if \(x\) is rational and \(f(x) = 0\) otherwise. Prove that \(\lim_{x \to 0} f(x) = 0\), and state why the proof does not need to know which \(x\) are rational.

Solution

In either case \(|f(x)| \le x^2\). Given \(\varepsilon > 0\), put \(\delta = \sqrt{\varepsilon}\). For \(0 < |x| < \delta\), \(|f(x) - 0| \le x^2 < \delta^2 = \varepsilon\). The bound \(|f(x)| \le x^2\) holds for every \(x\), whether or not \(x\) is rational, so the proof uses only that bound.

R2 · A bounded factor and a zero limit

Let \(|f(x)| \le M\) for every \(x\) in an interval containing \(a\), with \(M\) a constant, and let \(\lim_{x \to a} g(x) = 0\). Prove that \(\lim_{x \to a} f(x) g(x) = 0\).

Solution

Let \(\varepsilon > 0\). Choose \(\delta\) with \(|g(x)| < \varepsilon/(M + 1)\) for \(0 < |x - a| < \delta\). Then \(|f(x)g(x)| \le M|g(x)| \le M\varepsilon/(M+1) < \varepsilon\). The hypothesis that \(M\) bounds \(f\) is used once, and no property of \(f\) beyond it is needed.

R3 · The absolute value of a limit

Suppose \(\lim_{x \to a} f(x) = L\). Prove that \(\lim_{x \to a} |f(x)| = |L|\).

Solution

For every \(x\), \(\bigl||f(x)| - |L|\bigr| \le |f(x) - L|\). Given \(\varepsilon > 0\), take \(\delta\) from Definition 1.1. For \(0 < |x - a| < \delta\), the inequality gives \(\bigl||f(x)| - |L|\bigr| < \varepsilon\). So \(|f|\) has limit \(|L|\) at \(a\), by Definition 1.1 applied to \(|f|\).
