The Derivative as a Limit

A sensitivity measures how a value moves when an input moves a little. The slope of a price against a yield is the simplest case. That slope is a limit of a ratio of changes, and this lesson defines it exactly. It proves that a function with a derivative at a point is continuous there, and it shows with a kink that a continuous function can fail to have a derivative.

1The derivative as a limit

Definition 1.1 (derivative at a point)

Let \(f\) be defined on an open interval \(I\), and let \(a \in I\). For each \(h \ne 0\) with \(a + h \in I\), put \(Q(h) = \dfrac{f(a + h) - f(a)}{h}\), the difference quotient at \(a\). If \(\lim_{h \to 0} Q(h)\) exists, in the sense of Lesson 3, Definition 1.1 with \(h\) in place of \(x\) and \(0\) in place of \(a\), then \(f\) is differentiable at \(a\). Its derivative at \(a\) is that limit, written \(f'(a)\).

The derivative is a limit of ratios of changes. The numerator \(f(a+h) - f(a)\) is the change in the value, the denominator \(h\) is the change in the input, and \(f'(a)\) is what the ratio approaches as the input change shrinks. This is the meaning of derivative used in this lesson.

Example 1.2 (the square)

Let \(f(x) = x^2\) on \(\mathbb{R}\). For \(h \ne 0\), \(Q(h) = \dfrac{(a + h)^2 - a^2}{h} = \dfrac{2ah + h^2}{h} = 2a + h\). Then \(|Q(h) - 2a| = |h|\), so for \(\varepsilon > 0\) the choice \(\delta = \varepsilon\) gives \(|Q(h) - 2a| < \varepsilon\) whenever \(0 < |h| < \delta\). Hence \(f\) is differentiable at every \(a\) with \(f'(a) = 2a\).

At \(h = 0.1\) the quotient is 3.31 and the error is 0.31. """M2 lab L04: the difference quotient of f(x) = x^3 at a = 1 converges to f'(1) = 3, with an exact error column.

Standard library only. No randomness and no network. The difference quotient is
Q(h) = (f(1 + h) - f(1)) / h, which expands exactly to 3 + 3h + h^2 for f(x) = x^3, so its error from 3 is exactly
3h + h^2. The script computes Q(h) as an exact rational number (fractions.Fraction) for h = 10^-1 to 10^-6, and
checks the expansion at each step. The derivative 3 is the limit of Q(h) as h tends to 0. The limit is established
on the page from the expansion, and the table only displays the values of Q at the listed steps.
"""

from __future__ import annotations

from fractions import Fraction


def f(x: Fraction) -> Fraction:
    """The cube x^3 for a rational x."""
    return x * x * x


def quotient(h: Fraction) -> Fraction:
    """The difference quotient (f(1 + h) - f(1)) / h at a = 1, for a non-zero rational h."""
    if h == 0:
        raise ValueError("the difference quotient needs h != 0")
    return (f(Fraction(1) + h) - f(Fraction(1))) / h


def expansion_holds(h: Fraction) -> bool:
    """True when quotient(h) equals 3 + 3h + h^2 exactly."""
    return quotient(h) == 3 + 3 * h + h * h


def main() -> None:
    print("h, difference quotient, error from 3")
    for k in range(1, 7):
        h = Fraction(1, 10**k)
        q = quotient(h)
        print(f"{float(h):g}, {float(q):.6f}, {float(abs(q - 3)):.6e}")
    steps = [Fraction(1, 10**k) for k in range(1, 7)]
    print(f"expansion 3 + 3h + h^2 holds at every listed h: {all(expansion_holds(h) for h in steps)}")
    print(f"error divided by h at h = 1e-6: {float(abs(quotient(steps[-1]) - 3) / steps[-1]):.6f}")

The quotients are exact rational numbers, rounded for display. The expansion \(3 + 3h + h^2\) holds at each of the six steps. The error at each step is \(3h + h^2\), so the ratio of successive errors tends to 10 as \(h\) falls. The table shows the approach to 3 at six steps. The limit itself is the statement that \(Q(h)\) is within any tolerance of 3 for all small enough \(h\ne 0\), which follows from the expansion on the page. C Basis: Lab 1.

2Differentiable implies continuous

Proposition 2.1 (differentiability implies continuity)

Let \(f\) be defined on an open interval \(I\), let \(a \in I\), and suppose \(f\) is differentiable at \(a\). Hypotheses: the derivative \(f'(a)\) exists in the sense of Definition 1.1. Then \(f\) is continuous at \(a\) in the sequential sense of Lesson 2, §2.

Proof

Let \(\varepsilon > 0\). Apply Definition 1.1 with tolerance 1 in place of \(\varepsilon\): there is \(\delta_1 > 0\) such that \(|Q(h) - f'(a)| < 1\) for \(0 < |h| < \delta_1\), with \(a + h \in I\). For such \(h\), \(|Q(h)| < |f'(a)| + 1\). Put \(\delta = \min\bigl(\delta_1, \varepsilon/(|f'(a)| + 1)\bigr)\). For \(x \in I\) with \(0 < |x - a| < \delta\), \(f(x) - f(a) = (x - a)\,Q(x - a)\), so

\[|f(x) - f(a)| = |x - a|\,|Q(x - a)| < \delta\bigl(|f'(a)| + 1\bigr) \le \varepsilon.\]

For \(x = a\) the difference is 0. So \(|f(x) - f(a)| < \varepsilon\) for every \(x \in I\) with \(|x - a| < \delta\). Now let \((x_n)\) be a sequence in \(I\) with \(x_n \to a\). Choose \(N\) with \(|x_n - a| < \delta\) for \(n \ge N\); then \(|f(x_n) - f(a)| < \varepsilon\) for these \(n\). Since \(\varepsilon\) was arbitrary, \(f(x_n) \to f(a)\). \(\blacksquare\)

Proposition 2.1 gives one direction only. A continuous function need not be differentiable, and Example 3.1 gives the case.

3Where the derivative fails

Example 3.1 (the absolute value at its kink)

Let \(f(x) = |x|\) on \(\mathbb{R}\). At \(a = 0\), \(Q(h) = |h|/h\), which is 1 for \(h > 0\) and \(-1\) for \(h < 0\). The right-hand limit of \(Q\) at 0 is 1 and the left-hand limit is \(-1\). By Lesson 3, Proposition 2.2, the two-sided limit \(\lim_{h \to 0} Q(h)\) does not exist. So \(f\) is not differentiable at 0. The function is continuous at 0, because \(|x_n - 0| = |x_n| \to 0\) whenever \(x_n \to 0\), by Definition 2.1 of Lesson 1.

Example 3.1 is the converse failure promised after Proposition 2.1: a function can be continuous at a point and have no derivative there. The derivative needs the difference quotient to settle from both sides, not only from the sides that the continuity test can see.

4Where the canon breaks

The definition is a statement about one point, and it depends on the limit being the same from both sides. Three points of practice need care.

  • A formula is not a derivative. A function given by a formula can have no derivative at a point where the formula changes, as Example 3.1 shows for \(|x|\). The derivative is checked at each point, not inferred from the formula elsewhere.
  • The quotient is an approximation, not the derivative. Lab 1 gives \(Q(0.001) = 3.003001\), which differs from \(f'(1) = 3\). The derivative is the limit, and the quotient at a single step is only an approximation to it.
  • Floating-point arithmetic is a further source of error. The lab works in exact rational arithmetic, so it shows no rounding. Lesson 13 treats the effect of rounding on the quotient when it is computed in floating-point arithmetic.

5Misconceptions

  1. “Every function given by a formula has a derivative at every point.”

    Example 3.1 gives \(f(x) = |x|\), a formula, with no derivative at 0. The one-sided quotients differ, so the limit in Definition 1.1 does not exist.

  2. “A continuous function is differentiable.”

    Example 3.1 is continuous at 0 and not differentiable there. Proposition 2.1 proves only the direction from differentiable to continuous.

  3. “The quotient at \(h = 0.001\) is the derivative.”

    For \(x^3\) at \(a = 1\), Lab 1 gives \(Q(0.001) = 3.003001\), while \(f'(1) = 3\). The quotient differs from the derivative by \(3h + h^2 = 0.003001\) at that step. The derivative is the limit, which the quotient approaches but does not equal.

6Problem set

Every problem has a full worked solution. Attempt each one before opening it. Problems marked E use the output of Lab 1.

Mechanics

M1 · A linear function

Let \(f(x) = 5x - 2\). Find \(f'(3)\) from Definition 1.1.

Solution

The difference quotient is \(Q(h) = (5(3 + h) - 2 - (5 \cdot 3 - 2))/h = 5h/h = 5\) for \(h \ne 0\). The constant sequence has limit 5, so \(f'(3) = 5\).

M2 · The square at a negative point

Let \(f(x) = x^2\). Find \(f'(-1)\) from Example 1.2, and check it with the quotient at \(h = 0.01\).

Solution

Example 1.2 gives \(f'(a) = 2a\), so \(f'(-1) = -2\). At \(h = 0.01\), \(Q(h) = 2(-1) + 0.01 = -1.99\), which is \(-2\) plus the step, so the check agrees with the derivative to within the step.

M3 · The reciprocal

Let \(f(x) = 1/x\) for \(x \ne 0\). Find \(f'(2)\) from Definition 1.1.

Solution

For \(h \ne 0\) with \(2 + h \ne 0\), \(Q(h) = \dfrac{1/(2+h) - 1/2}{h} = \dfrac{2 - (2 + h)}{2(2+h)h} = \dfrac{-1}{2(2+h)}\). As \(h \to 0\) this tends to \(-1/4\), by the quotient law of Lesson 2, Proposition 1.1 (iii), applied to sequences \(h_n \to 0\), since the denominator \(2(2+h_n)\) tends to \(4 \ne 0\). So \(f'(2) = -1/4\).

Proof

P1 · The cube at any point

Let \(f(x) = x^3\). Prove from Definition 1.1 that \(f'(a) = 3a^2\) for every real \(a\).

Solution

We have \(Q(h) = ((a+h)^3 - a^3)/h = 3a^2 + 3ah + h^2\). So \(|Q(h) - 3a^2| = |h|\,|3a + h| \le |h|(3|a| + |h|)\). Let \(\varepsilon > 0\) and put \(\delta = \min\bigl(1, \varepsilon/(3|a| + 1)\bigr)\). For \(0 < |h| < \delta\), \(|h| < 1\), so \(|Q(h) - 3a^2| < \delta(3|a| + 1) \le \varepsilon\). Hence \(f'(a) = 3a^2\).

P2 · The sum rule

Let \(f\) and \(g\) be differentiable at \(a\). Prove that \(f + g\) is differentiable at \(a\) with \((f+g)'(a) = f'(a) + g'(a)\).

Solution

For \(h \ne 0\), the difference quotient of \(f + g\) is \(Q_f(h) + Q_g(h)\). Given \(\varepsilon > 0\), choose \(\delta_1\) with \(|Q_f(h) - f'(a)| < \varepsilon/2\) and \(\delta_2\) with \(|Q_g(h) - g'(a)| < \varepsilon/2\) for \(0 < |h| < \min(\delta_1, \delta_2)\), with \(\delta = \min(\delta_1,\delta_2)\). Then \(|(Q_f + Q_g)(h) - (f'(a) + g'(a))| < \varepsilon\). So the sum is differentiable at \(a\) with the stated derivative.

P3 · A constant multiple

Let \(f\) be differentiable at \(a\) and let \(c\) be a real constant. Prove that \(cf\) is differentiable at \(a\) with \((cf)'(a) = c\,f'(a)\).

Solution

The difference quotient of \(cf\) is \(cQ(h)\). Let \(\varepsilon > 0\), and choose \(\delta\) with \(|Q(h) - f'(a)| < \varepsilon/(|c| + 1)\) for \(0 < |h| < \delta\). Then \(|cQ(h) - cf'(a)| = |c|\,|Q(h) - f'(a)| < |c|\varepsilon/(|c| + 1) < \varepsilon\). So \((cf)'(a) = c f'(a)\).

Empirical

E1 · The quotient at h = 0.1 (from Lab 1)

Lab 1 prints the quotient and its error at \(h = 0.1\). Check both from the expansion \(3 + 3h + h^2\).

Solution

At \(h = 0.1\), \(3 + 0.3 + 0.01 = 3.31\), and the error is \(0.31\), which the lab prints as 3.310000 and 3.100000e-01 at that step. The expansion matches the printed values.

E2 · The error at h = 10^-5 (from Lab 1)

Lab 1 prints the error at \(h = 10^{-5}\) as \(3.000010 \times 10^{-5}\). Compute the exact error and check the printed value.

Solution

The exact error is \(3h + h^2 = 3 \times 10^{-5} + 10^{-10} = 3.00001 \times 10^{-5}\), since \(10^{-10} = 10^{-5} \cdot 10^{-5}\). The printed value \(3.000010 \times 10^{-5}\) is this number with a trailing zero, so it agrees with the output.

E3 · The ratio of error to step (from Lab 1)

Lab 1 prints the error divided by \(h\) at \(h = 10^{-6}\) as 3.000001. Explain from the expansion why this ratio is \(3 + h\), and why it does not depend on the printed rounding.

Solution

The error is \(3h + h^2\), so dividing by \(h\) gives \(3 + h\) exactly for \(h > 0\). At \(h = 10^{-6}\) this is \(3.000001\) exactly, and the printed value is the same number. The ratio is the coefficient 3 plus the step, which is why it approaches 3 as \(h\) falls.

Research

R1 · A derivative at one point only

Let \(f(x) = x|x|\). Show that \(f\) is differentiable at 0 with \(f'(0) = 0\), and say what this shows about how a derivative can exist at one point of a kink.

Solution

At \(a = 0\), \(Q(h) = h|h|/h = |h|\) for \(h \ne 0\). Since \(|Q(h) - 0| = |h|\), the choice \(\delta = \varepsilon\) gives \(|Q(h)| < \varepsilon\) for \(0 < |h| < \delta\). So \(f'(0) = 0\). Unlike \(|x|\) in Example 3.1, the quotient here has a single limit from both sides, because the sign of \(h\) cancels.

R2 · The quotient along a sequence of steps

Let \(f\) be differentiable at \(a\). Show that \(Q(1/n) \to f'(a)\), where \(Q\) is the difference quotient at \(a\), for the sequence of steps \(h_n = 1/n\).

Solution

The function \(Q\) has limit \(f'(a)\) at 0, by Definition 1.1. The sequence \(h_n = 1/n\) avoids 0 and tends to 0. By Lesson 3, Proposition 1.3, applied to \(Q\) at the point 0, \(Q(h_n) \to f'(a)\). The argument uses only the limit of \(Q\) and no property of \(f\) beyond differentiability.

R3 · The derivative of a constant

Let \(f(x) = c\) for every \(x\), with \(c\) constant. Find \(f'(a)\) for every \(a\), and say which step of Definition 1.1 uses that \(f\) is constant.

Solution

For \(h \ne 0\), \(Q(h) = (c - c)/h = 0\). The quotient is the constant sequence 0, so its limit is 0, and \(f'(a) = 0\) at every \(a\). The step that uses constancy is the equality \(f(a + h) = f(a)\), which makes the numerator zero for every \(h\).
