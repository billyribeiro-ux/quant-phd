Automatic Differentiation: Forward and Reverse Mode

  • Uses: the derivative (Lesson L04), the product, quotient and chain rules (Lesson L05, stated there in prose), and the finite-difference approximation (Lesson L13), which this lesson compares with
  • Introduces: automatic differentiation
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study or lab result
  • Dlore

A program that computes a price, a yield or a risk measure is a sequence of arithmetic steps and standard functions. Its derivative can be found by applying the chain rule to each step. Lesson L13 showed that a difference quotient has truncation and rounding errors that depend on a step size. This lesson shows a different method. Automatic differentiation carries a derivative alongside each value, so it has no step size and no truncation error. It has its own limits, which are set by the program's branches and by the memory that the reverse mode needs.

1A program as a sequence of operations

Take a formula such as \(f(x) = x\,e^{x} + \sin(x)/x\). A program that evaluates it at a number \(x\) does so in steps: it forms \(x\,e^{x}\), forms \(\sin(x)/x\), and adds the two. Each step is one of a few primitive operations. This lesson uses the operations addition, subtraction, multiplication, division, \(\exp\) and \(\sin\), with constants.

Definition 1.1 (automatic differentiation)

Let \(f\) be a function given by a program built from the primitive operations above, with each operation differentiable at the point where it is used. Automatic differentiation is a method that computes \(f'(a)\) by applying the chain rule, the product rule or the quotient rule to each primitive operation in the order the program runs, rather than by a difference quotient or by a symbolic formula for \(f'\).

Two properties of Definition 1.1 separate the method from Lesson L13. It uses no step \(h\), so there is no truncation error of the kind Theorem 2.1 of that lesson bounds. It also does not form a difference of two stored values divided by a step, so the rounding model of Proposition 3.2 in that lesson does not describe its error directly. The method still uses floating-point arithmetic, so it has rounding error of a different kind, which Section 6 discusses.

2Dual numbers

The forward mode attaches to each value a second number, its tangent. The two numbers are carried together as a dual number, which is a pair written with a symbol \(\varepsilon\) that satisfies \(\varepsilon^2 = 0\).

Definition 2.1 (dual numbers and their operations)

A dual number is an expression \(a + b\varepsilon\) with real \(a\) and \(b\), with \(\varepsilon^2 = 0\). Its value is \(a\) and its tangent is \(b\). The operations are:

\[(a + b\varepsilon) + (c + d\varepsilon) = (a + c) + (b + d)\varepsilon, \qquad (a + b\varepsilon)(c + d\varepsilon) = ac + (ad + bc)\varepsilon,\]

\[\frac{a + b\varepsilon}{c + d\varepsilon} = \frac{a}{c} + \frac{bc - ad}{c^2}\,\varepsilon \quad (c \ne 0), \qquad \exp(a + b\varepsilon) = e^{a} + b\,e^{a}\,\varepsilon, \qquad \sin(a + b\varepsilon) = \sin a + b\cos a\,\varepsilon.\]

A real number \(c\) is the dual number \(c + 0\varepsilon\). The variable \(x\) at the point \(a\) is the dual number \(a + 1\varepsilon\).

Definition 2.1 is a rule for computing with pairs. The tangent rules are the product, quotient and chain rules written for the pair. Proposition 3.1 shows that they compute derivatives.

Assumption 1. The derivative of \(\exp\) is \(\exp\), and the derivative of \(\sin\) is \(\cos\). This page assumes both facts and does not prove them. The exponential and sine rules of Definition 2.1 and the closed forms in Example 4.1, Lab 1 and Proposition 5.2 use them, and each such statement says so.

3Forward mode computes the derivative

An expression is a formula built from the variable, constants, and the operations of Definition 2.1. The next result says that evaluating an expression on \(a + \varepsilon\) returns its value at \(a\) and its derivative at \(a\) as the tangent.

Proposition 3.1 (forward mode returns the derivative)

Assume Assumption 1. Let \(F\) be an expression built from the variable \(x\), real constants, the operations \(+\), \(-\), \(\times\), \(\div\), \(\exp\) and \(\sin\). Let \(a\) be a real number such that every division in \(F\) has a non-zero denominator at \(a\). Let \(F\) define the function \(f\), and assume each sub-expression of \(F\) defines a function differentiable at \(a\). Then evaluating \(F\) on \(a + 1\varepsilon\) gives a dual number \(f(a) + f'(a)\,\varepsilon\).

Proof

The proof is by induction on the structure of \(F\). The sub-expressions of \(F\) are smaller expressions, and the claim is that each one returns its value and its derivative at \(a\).

Base cases. The variable \(x\) gives \(a + 1\varepsilon\), with value \(a\) and tangent \(1 = \frac{d}{dx}x\). A constant \(c\) gives \(c + 0\varepsilon\), with value \(c\) and tangent \(0 = \frac{d}{dx}c\).

Sums. If \(F = G + H\) and \(G\) returns \(g(a) + g'(a)\varepsilon\), \(H\) returns \(h(a) + h'(a)\varepsilon\), then by Definition 2.1 the sum returns \((g(a) + h(a)) + (g'(a) + h'(a))\varepsilon\), and \((g + h)'(a) = g'(a) + h'(a)\) by the sum rule. Differences are the same argument with a minus sign.

Products. If \(F = GH\), the operation returns \(g(a)h(a) + \bigl(g(a)h'(a) + g'(a)h(a)\bigr)\varepsilon\), and the product rule from Lesson L05 gives \((gh)'(a) = g(a)h'(a) + g'(a)h(a)\).

Quotients. If \(F = G/H\) and \(h(a) \ne 0\), the operation returns \(\frac{g(a)}{h(a)} + \frac{g'(a)h(a) - g(a)h'(a)}{h(a)^2}\varepsilon\), and the quotient rule of Lesson L05 gives the same tangent for \((g/h)'(a)\).

Exponentials and sines. If \(F = \exp(G)\), the operation returns \(e^{g(a)} + g'(a)e^{g(a)}\varepsilon\). The chain rule, together with the derivative of \(\exp\) being \(\exp\) (Assumption 1, not proved on this page), gives \(\frac{d}{dx}\exp(g(x)) = \exp(g(x))\,g'(x)\), so the tangent is the derivative. The sine case is the same with \(\cos\) in place of \(e^{\cdot}\).

Each step uses the induction hypothesis for the sub-expressions, and each sub-expression is differentiable at \(a\) by hypothesis. The induction therefore covers the whole of \(F\). \(\blacksquare\)

The hypotheses of Proposition 3.1 are the denominators being non-zero at \(a\) and the sub-expressions being differentiable at \(a\). The second one is not automatic: a sub-expression built from \(\exp\) and \(\sin\) is differentiable at every point (Assumption 1 gives the derivatives), but a sub-expression built from a branch, as in Section 6, may not be. The proof does not use the step size, because the tangent is an exact rule and not a limit.

4A worked forward-mode example

Example 4.1 (the formula of Section 1 at \(x = 2\))

Let \(f(x) = x\,e^{x} + \sin(x)/x\). Under Assumption 1, evaluate \(f\) on \(2 + 1\varepsilon\) step by step, and read the tangent at each step.

The variable gives \(2 + 1\varepsilon\). Then \(\exp(2 + 1\varepsilon) = e^2 + e^2\varepsilon\), with \(e^2 = 7.389056099\). The product with \(x\) is \((2 + 1\varepsilon)(e^2 + e^2\varepsilon) = 2e^2 + (2e^2 + e^2)\varepsilon = 14.778112198 + 22.167168297\,\varepsilon\). Next, \(\sin(2 + 1\varepsilon) = \sin 2 + \cos 2\,\varepsilon = 0.909297427 - 0.416146837\,\varepsilon\). The quotient by \(x = 2 + 1\varepsilon\) is \(\frac{0.909297427}{2} + \frac{(-0.416146837)(2) - 0.909297427 \cdot 1}{4}\varepsilon = 0.454648713 - 0.435397775\,\varepsilon\). Adding the two parts gives \(f(2) + f'(2)\varepsilon\) with \(f(2) = 14.778112198 + 0.454648713 = 15.232760911\) and \(f'(2) = 22.167168297 - 0.435397775 = 21.731770522\).

Check against the closed form. Under Assumption 1, differentiating by hand gives \(f'(x) = e^{x} + x e^{x} + \frac{x\cos x - \sin x}{x^2}\). At \(x = 2\) the three terms are \(7.389056099\), \(14.778112198\) and \(-0.435397775\), with sum \(21.731770522\). The tangent from the dual computation agrees with this sum.

Example 4.1 has the structure that the lab below repeats. The dual evaluation applies each operation to pairs, and the tangent at each step is the derivative of the sub-expression. Lab 1 runs this on a grid and compares the tangent with the closed form at 251 points.

Lab 1 · Dual numbers against closed-form derivatives

Predicted before running. The lab implements Definition 2.1 for addition, subtraction, multiplication, division, integer powers, \(\exp\) and \(\sin\). It evaluates two functions on the grid \(0.5 + i/100\) for \(i = 0, \dots, 250\), which is 251 points from 0.5 to 3.0. The first is \(f_1(x) = x e^{x} + \sin(x)/x\) from Example 4.1, and the second is \(f_2(x) = \exp(\sin(x^2))\). The tangent of each dual evaluation is compared with its closed-form derivative (Assumption 1) at every grid point. Proposition 3.1 says the tangent is the exact derivative, so the errors should be at the level of rounding in double precision, below \(10^{-12}\) at every grid point, with no step size anywhere in the computation.

"""M2 lab L14: forward-mode automatic differentiation with dual numbers, checked against analytic derivatives.

Standard library only. A dual number a + b*eps (with eps*eps = 0) carries a value and a tangent.
Each primitive operation updates both, so evaluating a function on a dual number a + 1*eps returns
f(a) in the value part and f'(a) in the tangent part. No step size h appears anywhere. The test
functions are evaluated on a grid of 251 points from 0.5 to 3.0 and compared with closed-form
derivatives. Nothing is random and nothing is fetched, so the output is the same on every run.
"""

from __future__ import annotations

import math
from collections.abc import Callable

Number = int | float


class Dual:
    """A dual number val + dot*eps with eps*eps = 0. val is the value; dot is the tangent (the derivative)."""

    __slots__ = ("dot", "val")

    def __init__(self, val: float, dot: float = 0.0) -> None:
        self.val = float(val)
        self.dot = float(dot)

    def __add__(self, other: Number | Dual) -> Dual:
        o = lift(other)
        return Dual(self.val + o.val, self.dot + o.dot)

    __radd__ = __add__

    def __neg__(self) -> Dual:
        return Dual(-self.val, -self.dot)

    def __sub__(self, other: Number | Dual) -> Dual:
        return self + (-lift(other))

    def __rsub__(self, other: Number | Dual) -> Dual:
        return lift(other) + (-self)

    def __mul__(self, other: Number | Dual) -> Dual:
        o = lift(other)
        return Dual(self.val * o.val, self.val * o.dot + self.dot * o.val)

    __rmul__ = __mul__

    def __truediv__(self, other: Number | Dual) -> Dual:
        o = lift(other)
        if o.val == 0.0:
            raise ZeroDivisionError("dual division by a zero value")
        return Dual(self.val / o.val, (self.dot * o.val - self.val * o.dot) / (o.val * o.val))

    def __rtruediv__(self, other: Number | Dual) -> Dual:
        return lift(other) / self

    def __pow__(self, n: int) -> Dual:
        """Integer power n >= 0 by repeated multiplication. Other exponents are not needed here."""
        if not isinstance(n, int) or n < 0:
            raise ValueError(f"Dual power needs an integer n >= 0, got {n!r}")
        result = Dual(1.0)
        for _ in range(n):
            result = result * self
        return result


def lift(x: Number | Dual) -> Dual:
    """A plain number becomes a dual number with zero tangent. A dual number is returned unchanged."""
    return x if isinstance(x, Dual) else Dual(float(x), 0.0)


def dexp(x: Dual) -> Dual:
    """exp with its chain-rule tangent: d/dt exp(v) = exp(v) * dv."""
    e = math.exp(x.val)
    return Dual(e, e * x.dot)


def dsin(x: Dual) -> Dual:
    """sin with its chain-rule tangent: d/dt sin(v) = cos(v) * dv."""
    return Dual(math.sin(x.val), math.cos(x.val) * x.dot)


def f1(x: Dual) -> Dual:
    """f1(x) = x exp(x) + sin(x) / x, defined for x != 0."""
    return x * dexp(x) + dsin(x) / x


def f1_exact(x: float) -> float:
    """The closed-form derivative of f1: exp(x) + x exp(x) + (x cos x - sin x) / x^2."""
    return math.exp(x) + x * math.exp(x) + (x * math.cos(x) - math.sin(x)) / (x * x)


def f2(x: Dual) -> Dual:
    """f2(x) = exp(sin(x^2)), a composition of three primitives."""
    return dexp(dsin(x**2))


def f2_exact(x: float) -> float:
    """The closed-form derivative of f2: exp(sin(x^2)) cos(x^2) 2x."""
    return math.exp(math.sin(x * x)) * math.cos(x * x) * 2.0 * x


def grid() -> list[float]:
    """The 251 points 0.5 + i/100 for integer i from 0 to 250, so the last point is 3.0."""
    return [0.5 + i / 100 for i in range(251)]


def max_error(ad: Callable[[Dual], Dual], exact: Callable[[float], float]) -> float:
    """The largest absolute difference between the dual-number tangent and the closed form on the grid."""
    worst = 0.0
    for x in grid():
        worst = max(worst, abs(ad(Dual(x, 1.0)).dot - exact(x)))
    return worst


def main() -> None:
    print(f"grid points: {len(grid())}")
    e1 = max_error(f1, f1_exact)
    e2 = max_error(f2, f2_exact)
    print(f"max error, f1: below 1e-12: {e1 < 1e-12}")
    print(f"max error, f2: below 1e-12: {e2 < 1e-12}")
    x = 2.0
    print(f"f1 at x = 2: value {f1(Dual(x)).val:.10f}")
    print(f"f1'(2) by dual numbers: {f1(Dual(x, 1.0)).dot:.10f}")
    print(f"f1'(2) closed form: {f1_exact(x):.10f}")
    print(f"f2'(1) by dual numbers: {f2(Dual(1.0, 1.0)).dot:.10f}")
    print(f"f2'(1) closed form: {f2_exact(1.0):.10f}")


main()

max error, f1: below 1e-12: True
max error, f2: below 1e-12: True
f1 at x = 2: value 15.2327609113
f1'(2) by dual numbers: 21.7317705218

The printed values are one double-precision run of the lab and are not claimed to hold on every Python installation beyond the stated tolerance.

5Reverse mode: one backward pass for both partial derivatives of Example 5.1

Forward mode, as defined in this lesson, carries one tangent direction, so each forward pass gives the derivative in one input direction. Reverse mode works with the adjoint of each intermediate value, which is the sensitivity of the output to that value. In Example 5.1 one backward pass gives the derivative of the output with respect to each input, and Proposition 5.2 proves this for that graph.

Example 5.1 (two inputs, one output, the adjoints by hand)

Let \(f(x_1, x_2) = x_1 x_2 + \sin x_1\), evaluated at \((x_1, x_2) = (1, 2)\). The forward pass stores the intermediate values in a sequence: \(v_1 = x_1 = 1\), \(v_2 = x_2 = 2\), \(v_3 = v_1 v_2 = 2\), \(v_4 = \sin v_1 = 0.841470985\), and \(f = v_3 + v_4 = 2.841470985\). The stored values are needed in the backward pass, because the adjoints use them.

The backward pass starts with the adjoint of the output, \(\bar f = 1\), and visits each operation in reverse order. The output is \(f = v_3 + v_4\), so \(\bar v_3 = 1\) and \(\bar v_4 = 1\). The operation \(v_4 = \sin v_1\) contributes \(\bar v_1 \mathrel{+}= \cos(v_1)\,\bar v_4 = \cos 1\). The operation \(v_3 = v_1 v_2\) contributes \(\bar v_1 \mathrel{+}= v_2\,\bar v_3 = 2\) and \(\bar v_2 \mathrel{+}= v_1\,\bar v_3 = 1\). The adjoints of the inputs are therefore \(\bar x_1 = \bar v_1 = 2 + \cos 1 = 2.540302306\) and \(\bar x_2 = \bar v_2 = 1\).

Under Assumption 1 these are the partial derivatives of \(f\): \(\partial f/\partial x_1 = x_2 + \cos x_1\) and \(\partial f/\partial x_2 = x_1\), which at \((1, 2)\) are \(2 + \cos 1\) and \(1\).

Example 5.1 shows the count. Forward mode needs two passes, one for each input direction. Reverse mode needs one backward pass, after one forward evaluation that stores the values, and that pass produces both partial derivatives. This lesson does not prove a general count for programs with many inputs. The example shows the mechanism that gives the count.

Proposition 5.2 (the reverse pass gives the partial derivatives of Example 5.1)

Assume Assumption 1. Let \(f = v_3 + v_4\), \(v_3 = v_1 v_2\), \(v_4 = \sin v_1\), \(v_1 = x_1\) and \(v_2 = x_2\), with \(x_1\) and \(x_2\) real. Let \(\bar v_k\) be the sum, over the operations that use \(v_k\), of the partial derivative of the operation's output with respect to \(v_k\), multiplied by the adjoint of that output, with \(\bar f = 1\). Then \(\bar x_1 = \partial f/\partial x_1\) and \(\bar x_2 = \partial f/\partial x_2\).

Proof

Each adjoint is a sum over the paths from the variable to the output in the graph of operations, and each path contributes a product of the local partial derivatives along it. For \(x_1 = v_1\), there are two paths. The first is \(v_1 \to v_3 \to f\), with local derivatives \(\partial v_3/\partial v_1 = v_2\) and \(\partial f/\partial v_3 = 1\), contributing \(v_2\). The second is \(v_1 \to v_4 \to f\), with local derivatives \(\cos v_1\) and \(1\), contributing \(\cos v_1\). Their sum is \(v_2 + \cos v_1 = \partial f/\partial x_1\), which is what \(\bar v_1\) computes. For \(x_2 = v_2\), the only path is \(v_2 \to v_3 \to f\), with contribution \(v_1 = \partial f/\partial x_2\). The backward pass computes these sums by adding the contributions as it visits each operation, so it returns the same sums. \(\blacksquare\)

The proof uses the path sum of the chain rule for the graph of Example 5.1, and it is written for that graph. It is not a general theorem for every program. Section 6 notes what the backward pass needs in storage.

6Where the canon breaks

In exact arithmetic, automatic differentiation returns the derivative of the program it runs. That is not necessarily the derivative of the function the program was meant to compute. Four points show where the program and the intended function come apart.

  • A branch changes the program. Take \(g(x) = x\) for \(x > 0\) and \(g(x) = -x\) for \(x \le 0\), which is \(|x|\). At \(a = 0\), the program written as x if x > 0 else -x sees the dual number \(0 + 1\varepsilon\), takes the else branch and returns \(0 - 1\varepsilon\), so the tangent is \(-1\). The same function written as x if x >= 0 else -x takes the first branch and returns tangent \(+1\). The function \(|x|\) has no derivative at \(0\), and the two programs return different tangents for the same function.
  • A discrete operation has zero tangent. Suppose a rounding operation returns the nearest integer to its value and sets the tangent to \(0\). Between two half-integers the operation is constant, so its tangent is \(0\) there, and the jumps at the half-integers are invisible to the method. Automatic differentiation then reports a zero derivative for a function that jumps.
  • Reverse mode stores the forward values. In Example 5.1 the backward step for \(\sin\) needs \(v_1\), and the step for the product needs \(v_1\) and \(v_2\). A program with many steps must keep those values until the backward pass reads them. The number of stored values grows with the number of operations in the program. Forward mode, as defined in Section 2, stores no list of intermediate values for a later backward pass.
  • Floating-point arithmetic still rounds. The tangent rules are exact on paper, but each stored value and each tangent is a double-precision number. A tangent can lose digits when two large tangents cancel. Lab 1 measures this on a grid and finds the errors below \(10^{-12}\), which is not a bound for every expression or every point.

7Misconceptions

  1. “Automatic differentiation is a finite difference with a very small step.”

    Definition 2.1 has no step, and Proposition 3.1 shows that the tangent is the derivative exactly, with no truncation error of order \(h\) or \(h^2\). Lesson L13 shows that a shorter step in a difference quotient brings rounding error, which the dual computation does not have in the same form. The two methods have different error sources.

  2. “Reverse mode is always the cheaper choice.”

    Example 5.1 has two inputs, and forward mode needs two passes while reverse mode needs one. Reverse mode also stores the forward values, as Section 6 states. This lesson does not prove a general comparison of the two modes, so Example 5.1 is the one count it establishes.

  3. “The tangent of a program is the derivative of the function it was meant to compute.”

    The tangent is the derivative of the program. The branch example in Section 6 gives \(-1\) and \(+1\) for the same function \(|x|\) at \(0\), and \(|x|\) has no derivative there. So the tangent is a property of the program as written, and it can differ from the derivative of the function the program was meant to compute.

Mechanics

M1 · Dual evaluation of a quadratic

Evaluate \(g(x) = x^2 + 3x\) on \(2 + 1\varepsilon\), and state the value and the tangent.

Solution

The product \((2 + \varepsilon)(2 + \varepsilon) = 4 + (2 + 2)\varepsilon = 4 + 4\varepsilon\), since \(\varepsilon^2 = 0\). Then \(3(2 + \varepsilon) = 6 + 3\varepsilon\). The sum is \(10 + 7\varepsilon\). The value is \(g(2) = 10\) and the tangent is \(7\), which equals \(g'(2) = 2 \cdot 2 + 3 = 7\).

M2 · The reciprocal on a dual number

Use the quotient rule of Definition 2.1 to evaluate \(1/(a + b\varepsilon)\), and check the tangent at \(a = 2\), \(b = 1\) against \(-1/x^2\).

Solution

Take \(c = a\) and \(d = b\) in the quotient formula with numerator \(1 + 0\varepsilon\). Then \(\frac{1}{a + b\varepsilon} = \frac{1}{a} + \frac{0 \cdot a - 1 \cdot b}{a^2}\varepsilon = \frac{1}{a} - \frac{b}{a^2}\varepsilon\). At \(a = 2\), \(b = 1\), the tangent is \(-1/4\). The derivative of \(1/x\) is \(-1/x^2 = -1/4\) at \(2\), which agrees.

M3 · Partial derivatives of a product by reverse mode

For \(f(x_1, x_2) = x_1 x_2\) at \((3, 4)\), run the reverse pass with \(\bar f = 1\) and state the two adjoints.

Solution

The operation \(f = x_1 x_2\) gives \(\bar x_1 = x_2 \bar f = 4\) and \(\bar x_2 = x_1 \bar f = 3\). These agree with \(\partial f/\partial x_1 = x_2 = 4\) and \(\partial f/\partial x_2 = x_1 = 3\).

Proof

P1 · The product rule in dual form

Starting from the product of Definition 2.1, show that the tangent of \((a + b\varepsilon)(c + d\varepsilon)\) equals \(f'(x)g(x) + f(x)g'(x)\) when \(f\) and \(g\) are the functions whose dual values are \(a + b\varepsilon\) and \(c + d\varepsilon\), with \(b = f'\) and \(d = g'\) at the point.

Solution

The tangent of the product is \(ad + bc\) by Definition 2.1. Here \(a = f(x)\), \(b = f'(x)\), \(c = g(x)\) and \(d = g'(x)\). So the tangent is \(f(x)g'(x) + f'(x)g(x)\), which is the product rule. This is exactly the calculation in the product case of Proposition 3.1.

P2 · The chain rule for \(\exp(x^2)\)

Evaluate \(\exp(x^2)\) on \(a + 1\varepsilon\) with the rules of Definition 2.1 and show that the tangent is \(2a\,e^{a^2}\).

Solution

First \((a + \varepsilon)^2 = a^2 + 2a\varepsilon\). Then \(\exp(a^2 + 2a\varepsilon) = e^{a^2} + 2a\,e^{a^2}\varepsilon\), by the exponential rule of Definition 2.1 with \(b = 2a\) (Assumption 1). The tangent is \(2a\,e^{a^2}\), which is the derivative \(\frac{d}{dx} e^{x^2} = 2x\,e^{x^2}\) at \(a\).

P3 · The quotient rule in dual form

Show that the quotient formula of Definition 2.1 gives the tangent of \(f/g\) at \(a\) when \(g(a) \ne 0\), by stating the tangent of \((a + b\varepsilon)/(c + d\varepsilon)\) and comparing it with the quotient rule.

Solution

The tangent of the quotient is \((bc - ad)/c^2\) by Definition 2.1. With \(a = f(x)\), \(b = f'(x)\), \(c = g(x)\) and \(d = g'(x)\), this is \(\frac{f'(x)g(x) - f(x)g'(x)}{g(x)^2}\), which is the quotient rule for \((f/g)'\). The condition \(g(a) \ne 0\) is the non-zero denominator of Proposition 3.1.

Empirical

E1 · The derivative of \(f_2\) at 1 (Lab 1)

Lab 1 prints \(f_2'(1) = 2.5067615350\). Derive this value from the chain rule by hand, using Assumption 1 for the derivatives of \(\exp\) and \(\sin\), and check the printed digits.

Solution

\(f_2(x) = \exp(\sin(x^2))\) has derivative \(\exp(\sin(x^2))\cos(x^2)\cdot 2x\). At \(x = 1\) this is \(\exp(\sin 1)\cos 1 \cdot 2\). With \(\sin 1 = 0.8414709848\), \(\exp(\sin 1) = 2.3197768247\), and \(\cos 1 = 0.5403023059\), the product of these rounded factors is \(2.3197768247 \times 0.5403023059 \times 2 = 2.5067615351\), where the last digit comes from rounding the three factors. The unrounded product \(2\exp(\sin 1)\cos 1 = 2.506761534986\ldots\) rounds at ten decimals to the printed \(2.5067615350\). So the printed value agrees with the chain-rule computation to nine decimals, and the tenth decimal depends on the rounding of the factors.

E2 · What the grid does not test (Lab 1)

Lab 1 tests 251 points from 0.5 to 3.0. Name one point type that the grid does not contain, and say what the lab's result does not establish about it.

Solution

The grid does not contain points below \(0.5\), negative points, or points where \(\sin(x)/x\) would need \(x = 0\). The lab's result does not establish the tangent at those points, because it checks the 251 grid values. At \(x = 0\), \(f_1\) is undefined because of the division by \(x\), so the lab's grid avoids the one point where the formula fails. The lab does not check negative \(x\) or \(x\) near \(0\). Proposition 3.1 covers those points by proof, if its hypotheses hold there, and the lab's printed values say nothing about them.

E3 · Comparing with Lesson L13

Lesson L13 shows that a forward difference at \(h = 10^{-8}\) has an error of about \(6.6 \times 10^{-9}\) for \(\exp\) at \(1\). Explain why the dual-number computation for \(\exp\) at \(1\) has no step to choose, and state which part of the L13 error analysis does not apply.

Solution

The dual computation uses the rule \(\exp(1 + \varepsilon) = e + e\varepsilon\), which is Assumption 1 and has no step: the tangent is \(e\), not a difference of values at nearby points. So there is no \(h\) to choose and no truncation term of Theorem 2.1 in L13. The rounding model of Proposition 3.2 in L13 used a difference of two stored values divided by \(h\). The dual computation does not form that difference, so that part of the L13 analysis does not apply in the same form. The tangent still carries floating-point rounding, as Section 6 says.

R1 · Second derivatives by nesting

Suppose each dual number carries a tangent that is itself a dual number. Describe what the nested evaluation of \(x^3\) at \(a\) returns, and identify which coefficient is \(f''(a)\).

Solution

Write the inner dual number as \(a + \varepsilon_1\) and the outer tangent as \(\varepsilon_2\), with \(\varepsilon_2^2 = 0\) and \(\varepsilon_1^2 = 0\). Then \((a + \varepsilon_1 + \varepsilon_2)^3\) expands to \(a^3 + 3a^2(\varepsilon_1 + \varepsilon_2) + 6a\,\varepsilon_1\varepsilon_2\), since \(\varepsilon_1^2 = \varepsilon_2^2 = 0\). The coefficient of \(\varepsilon_1\varepsilon_2\) is \(6a = f''(a)\), because \(f''(x) = 6x\). The problem does not extend the argument to a general expression, and the nested form is a design choice that this lesson does not analyse for cost.

R2 · The storage of a long program

A program runs a loop of 1000 steps, and each step stores 3 intermediate values for the reverse pass. Count the values stored, and say what the reverse pass must read in the order of the backward sweep.

Solution

The forward pass stores \(1000 \times 3 = 3000\) values. The backward pass visits the steps from the last to the first and reads, at each step, the values that step stored, so it reads the stored list in reverse order. The count is \(1000 \times 3 = 3000\) from the stated numbers, and this lesson does not analyse memory-saving schemes for long loops.

R3 · Two programs for \(\max(x, 0)\) at zero

Write the two implementations x if x > 0 else 0 and x if x >= 0 else 0. State the tangent each returns at \(a = 0\) for the input \(0 + 1\varepsilon\), and say whether either matches the derivative of \(\max(x, 0)\) at zero.

Solution

For x if x > 0 else 0 the condition \(0 > 0\) is false, so the program returns the constant \(0\), with tangent \(0\). For x if x >= 0 else 0 the condition holds, so the program returns \(x\), with tangent \(1\). The two programs compute the same function \(\max(x, 0)\) at every point, but they return tangents \(0\) and \(1\) at zero. The derivative of \(\max(x, 0)\) does not exist at zero, since the one-sided slopes are \(0\) and \(1\). Neither tangent is the derivative, and the answer depends on the branch the program takes.
