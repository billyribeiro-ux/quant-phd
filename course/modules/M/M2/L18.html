Differentiability and the Jacobian Matrix

  • Uses: the partial derivatives and their examples (Lesson L16), the gradient and the directional derivative (Lesson L17), the mean value theorem (Lesson L06), and the continuity and sequence results of Lesson L15
  • Introduces: Jacobian matrix
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study or lab result
  • Dlore
  • Xrefuted

A model that maps several inputs to several outputs, such as a set of prices or yields computed from a set of parameters, needs a linear approximation of every output at once. The Jacobian matrix, defined in Section 2, collects the partial derivatives of every output with respect to every input into one rectangular array. This lesson defines differentiability, which says that the array gives a linear approximation whose error is small compared with the step, and proves the two results that connect it to the partial derivatives: the Jacobian is the only array that works, and continuous partial derivatives are enough for the approximation to hold.

1Maps from one Euclidean space to another

A map \(F : U \to \R^m\) on an open set \(U\) in \(\R^n\) is a list of \(m\) real functions, \(F = (F_1, \dots, F_m)\), with \(F_i : U \to \R\). Each component \(F_i\) is an ordinary real function of \(n\) variables, and each partial derivative of \(F_i\) is defined as in Lesson L16.

2The Jacobian array

Definition 2.1 (Jacobian matrix)

Let \(F = (F_1, \dots, F_m) : U \to \R^m\), and let \(a \in U\) be a point where every partial derivative \(\partial F_i/\partial x_j(a)\) exists. The Jacobian matrix of \(F\) at \(a\) is the array \(J_F(a)\) with \(m\) rows and \(n\) columns whose entry in row \(i\) and column \(j\) is

\[\bigl(J_F(a)\bigr)_{ij} = \frac{\partial F_i}{\partial x_j}(a).\]

Here "matrix" means a rectangular array of real numbers. For such an array \(A\) and a vector \(h \in \R^n\), the product \(Ah\) is the vector in \(\R^m\) whose \(i\)th entry is \(\sum_{j=1}^{n} A_{ij} h_j\). No other algebra of arrays is used in this lesson.

When \(m = 1\), the Jacobian has one row, and it is the gradient of Lesson L17 written as a row. When \(n = 1\), it has one column, the vector of derivatives of the components.

3Differentiability

Definition 3.1 (differentiable at a point)

The map \(F\) is differentiable at \(a \in U\) when there is an array \(A\) with \(m\) rows and \(n\) columns such that

\[\lim_{h \to 0} \frac{|F(a + h) - F(a) - Ah|}{|h|} = 0.\]

The limit is over vectors \(h \ne 0\) with \(a + h \in U\), and \(|\cdot|\) is the Euclidean norm of Lesson L15 in each space.

Definition 3.1 says that \(F(a + h)\) is approximated by \(F(a) + Ah\) with an error whose ratio to \(|h|\) tends to \(0\), in every direction. The next result says that the array \(A\) is unique and is the Jacobian, so the Jacobian is the only candidate for the linear approximation.

Proposition 3.2 (the array is the Jacobian)

Let \(F\) be differentiable at \(a\) with array \(A\). Then every partial derivative \(\partial F_i/\partial x_j(a)\) exists and equals \(A_{ij}\). So \(A = J_F(a)\), and no other array satisfies Definition 3.1.

Proof

Take \(h = t e_j\) with \(t \ne 0\). Definition 3.1 gives \(\bigl|F(a + te_j) - F(a) - tAe_j\bigr|/|t| \to 0\). Here \(Ae_j\) is the \(j\)th column of \(A\). Taking the \(i\)th component, \(\bigl|\,\bigl(F_i(a + te_j) - F_i(a)\bigr)/t - A_{ij}\,\bigr| \le \bigl|F(a + te_j) - F(a) - tAe_j\bigr|/|t| \to 0\). So the difference quotient of \(F_i\) in \(x_j\) at \(a\) converges to \(A_{ij}\), which is the partial derivative, and it equals \(A_{ij}\). For uniqueness, let \(A\) and \(B\) both satisfy Definition 3.1. For a unit vector \(v\) and \(t > 0\), the triangle inequality gives \(|(A - B)tv| \le |F(a + tv) - F(a) - Atv| + |F(a + tv) - F(a) - Btv|\). Dividing by \(t\) and letting \(t \to 0\) gives \(|(A - B)v| = 0\). Since this holds for every unit \(v\), \(A = B\). \(\blacksquare\)

Proposition 3.3 (differentiable implies continuous)

If \(F\) is differentiable at \(a\), then \(F\) is continuous at \(a\).

Proof

Each entry of \(Ah\) satisfies \(|(Ah)_i| \le \sum_j |A_{ij}|\,|h_j| \le \bigl(\sum_j |A_{ij}|\bigr)|h|\), so \(|Ah| \le \bigl(\sum_{i,j} |A_{ij}|\bigr)|h|\), using \(|v| \le \sum_i |v_i|\) for a vector \(v\). Write \(K = \sum_{i,j}|A_{ij}|\). Then

\[|F(a + h) - F(a)| \le |Ah| + |F(a + h) - F(a) - Ah| \le K|h| + |h| \cdot \frac{|F(a + h) - F(a) - Ah|}{|h|}.\]

The right side tends to \(0\) as \(h \to 0\), by Definition 3.1. So \(F(a + h) \to F(a)\), which is continuity at \(a\). \(\blacksquare\)

4Continuous partial derivatives give differentiability

Theorem 4.1 (continuous partials imply differentiability)

Let \(F : U \to \R^m\) on an open set \(U\) in \(\R^n\), and let \(a \in U\). Assume that every partial derivative \(\partial F_i/\partial x_j\) exists at every point of an open ball \(B \subseteq U\) about \(a\), and that each \(\partial F_i/\partial x_j\) is continuous at \(a\). Then \(F\) is differentiable at \(a\), with array \(J_F(a)\).

Proof

Fix \(i\). Let \(B = B(a, r)\) and let \(0 < |h| < r\). Write \(p_0 = a\) and \(p_k = a + (h_1, \dots, h_k, 0, \dots, 0)\), so that \(p_k - p_{k-1} = h_k e_k\) and \(p_n = a + h\). Each \(p_k\) lies in \(B\), because its distance from \(a\) is at most \(|h|\). The telescoping sum is \(F_i(a + h) - F_i(a) = \sum_{k=1}^{n}\bigl(F_i(p_k) - F_i(p_{k-1})\bigr)\). For each \(k\), the function \(s \mapsto F_i(p_{k-1} + s e_k)\) has derivative \(\partial F_i/\partial x_k\) at each point of its domain in \(B\), so the mean value theorem of Lesson L06 gives \(\theta_k \in (0, 1)\) with \(F_i(p_k) - F_i(p_{k-1}) = h_k \partial F_i/\partial x_k(q_k)\), where \(q_k = p_{k-1} + \theta_k h_k e_k\). (If \(h_k = 0\), the term is zero and \(q_k = p_{k-1}\) works.) Each \(q_k\) is within \(|h|\) of \(a\). Therefore

\[F_i(a + h) - F_i(a) - \sum_{k=1}^{n} h_k \frac{\partial F_i}{\partial x_k}(a) = \sum_{k=1}^{n} h_k\Bigl(\frac{\partial F_i}{\partial x_k}(q_k) - \frac{\partial F_i}{\partial x_k}(a)\Bigr).\]

Let \(\omega(\rho)\) be the largest, over \(i\), \(k\), and points \(x\) with \(|x - a| \le \rho\), of \(|\partial F_i/\partial x_k(x) - \partial F_i/\partial x_k(a)|\). Continuity at \(a\) of the finitely many partials gives \(\omega(\rho) \to 0\) as \(\rho \to 0\). Since \(|h_k| \le |h|\) and \(|q_k - a| \le |h|\), the absolute value of the right side above is at most \(n\,\omega(|h|)\,|h|\) for each \(i\). Stacking the \(m\) components, \(|F(a + h) - F(a) - J_F(a)h| \le \sqrt{m}\,n\,\omega(|h|)\,|h|\), and the ratio in Definition 3.1 is at most \(\sqrt{m}\,n\,\omega(|h|) \to 0\). \(\blacksquare\)

Example 4.2 (a quadratic map)

Let \(F(x, y) = (x^2 - y^2,\; 2xy)\), the square of the complex number \(x + iy\) written in coordinates. Its partial derivatives are polynomials, so they are continuous everywhere, and Theorem 4.1 applies at every point. The Jacobian at \(a = (1, 2)\) is \(\begin{pmatrix} 2 & -4 \\ 4 & 2 \end{pmatrix}\), since \(\partial F_1/\partial x = 2x\), \(\partial F_1/\partial y = -2y\), \(\partial F_2/\partial x = 2y\) and \(\partial F_2/\partial y = 2x\). Expanding with \(a = (1, 2)\) and \(h = (s_1, s_2)\) gives \(F(a + h) = (-3, 4) + (2s_1 - 4s_2 + s_1^2 - s_2^2,\; 4s_1 + 2s_2 + 2s_1 s_2)\). Using \(F(a) = (-3, 4)\), this gives \(F(a + h) - F(a) = (2s_1 - 4s_2 + s_1^2 - s_2^2,\; 4s_1 + 2s_2 + 2s_1 s_2)\). So the remainder is \(F(a + h) - F(a) - J_F(a)h = (s_1^2 - s_2^2,\; 2s_1 s_2)\), whose length is \(|h|^2\), because \((s_1^2 - s_2^2)^2 + (2s_1s_2)^2 = (s_1^2 + s_2^2)^2\). The ratio in Definition 3.1 is therefore \(|h|\), which tends to \(0\).

Example 4.2 is the case that Lab 1 checks numerically: the central differences fill the array, and the remainder ratio is computed along a fixed direction.

Lab 1 · The Jacobian of a map from R² to R² by central differences

Predicted before running, from Example 4.2. For \(F(x, y) = (x^2 - y^2, 2xy)\) the Jacobian array is \(\begin{pmatrix} 2x & -2y \\ 2y & 2x \end{pmatrix}\), and at \((1, 2)\) it is \(\begin{pmatrix} 2 & -4 \\ 4 & 2 \end{pmatrix}\). Each entry of the central-difference array, with step \(h = 10^{-5}\), should agree with the closed form to better than \(10^{-6}\) at the 25 grid points. The map is quadratic, so its third partial derivatives are zero and the central difference has no truncation error (Problem P1 of Lesson L16); the rounding part is at most about \(10^{-10}\). For the remainder, Example 4.2 predicts that the ratio of the remainder to the step length equals \(|k|\) exactly, so the four printed ratios should be \(10^{-1}\), \(10^{-2}\), \(10^{-3}\) and \(10^{-4}\).

"""M2 lab L18: the Jacobian of a map from R^2 to R^2 by central differences, against its closed form.

Standard library only. The map is F(x, y) = (x^2 - y^2, 2 x y). Its Jacobian array of partial
derivatives is [[2x, -2y], [2y, 2x]]. The lab fills the array by a central difference in each
variable, at 25 grid points (x and y in {-1, -0.5, 0, 0.5, 1}), with step h = 10^-5, and reports whether
the largest absolute entry error is below 1e-6. It also checks the remainder F(a + k u) - F(a) - J(a) (k u)
at a = (1, 2) for the unit vector u = (0.6, 0.8) and k = 10^-1 to 10^-4, dividing the remainder by the length
|k u| of the step.
Nothing is random.
"""

from __future__ import annotations

import math

H = 1e-5
A = (1.0, 2.0)


def big_f(x: float, y: float) -> tuple[float, float]:
    """F(x, y) = (x^2 - y^2, 2 x y), the map that sends the complex number x + i y to its square."""
    return (x * x - y * y, 2.0 * x * y)


def jacobian_closed(x: float, y: float) -> list[list[float]]:
    """The closed-form Jacobian array of F: row i holds the partial derivatives of component i."""
    return [[2.0 * x, -2.0 * y], [2.0 * y, 2.0 * x]]


def jacobian_fd(x: float, y: float, h: float) -> list[list[float]]:
    """The Jacobian array filled by central differences: entry (i, j) is the central difference of F_i in x_j."""
    up_x, down_x = big_f(x + h, y), big_f(x - h, y)
    up_y, down_y = big_f(x, y + h), big_f(x, y - h)
    columns = [
        [(up_x[i] - down_x[i]) / (2.0 * h) for i in range(2)],
        [(up_y[i] - down_y[i]) / (2.0 * h) for i in range(2)],
    ]
    return [[columns[0][0], columns[1][0]], [columns[0][1], columns[1][1]]]


def apply(matrix: list[list[float]], v: tuple[float, float]) -> tuple[float, float]:
    """The product of a 2 by 2 array with a vector in R^2."""
    return (matrix[0][0] * v[0] + matrix[0][1] * v[1], matrix[1][0] * v[0] + matrix[1][1] * v[1])


def remainder_ratio(k: float) -> float:
    """|F(a + k u) - F(a) - J(a) k u| divided by |k u|, for the unit direction u = (0.6, 0.8)."""
    ax, ay = A
    u = (0.6, 0.8)
    step = (k * u[0], k * u[1])
    fa = big_f(ax, ay)
    fk = big_f(ax + step[0], ay + step[1])
    lin = apply(jacobian_closed(ax, ay), step)
    diff = (fk[0] - fa[0] - lin[0], fk[1] - fa[1] - lin[1])
    return math.hypot(*diff) / math.hypot(*step)


def main() -> None:
    grid = [-1.0, -0.5, 0.0, 0.5, 1.0]
    worst = 0.0
    points = 0
    for x in grid:
        for y in grid:
            points += 1
            fd = jacobian_fd(x, y, H)
            cf = jacobian_closed(x, y)
            for i in range(2):
                for j in range(2):
                    worst = max(worst, abs(fd[i][j] - cf[i][j]))
    print(f"grid points: {points}")
    print(f"max entry error of the central-difference Jacobian below 1e-6: {worst < 1e-6}")
    fd_a = jacobian_fd(A[0], A[1], H)
    print("Jacobian at (1, 2) by central difference:")
    print(f"row 1: {fd_a[0][0]:.6f} {fd_a[0][1]:.6f}")
    print(f"row 2: {fd_a[1][0]:.6f} {fd_a[1][1]:.6f}")
    for k in (1e-1, 1e-2, 1e-3, 1e-4):
        print(f"remainder over step length, k = {k:.0e}: {remainder_ratio(k):.4e}")


main()

The lab reports 25 grid points, and that the largest central-difference entry error is below \(10^{-6}\), which is True. The array at \((1, 2)\) prints as \(\begin{pmatrix} 2.000000 & -4.000000 \\ 4.000000 & 2.000000 \end{pmatrix}\), which is the closed form of Example 4.2 to six decimals. The remainder ratios print \(1.0000 \times 10^{-1}\), \(10^{-2}\), \(10^{-3}\) and \(10^{-4}\) for \(k = 10^{-1}\) to \(10^{-4}\), so the ratio equals \(|k|\), as Example 4.2 predicts and as the algebra requires: the remainder is exactly \((s_1^2 - s_2^2, 2 s_1 s_2)\), of length \(|h|^2\). The ratio tends to \(0\), which is the limit of Definition 3.1 along this one direction. The lab checks one direction at one point, and it does not check the limit in every direction. The 25 grid points and the one direction are finite checks, so they are evidence about those points and that direction.

5Where the canon breaks

Differentiability is a strong condition, and the partial derivatives alone do not give it.

  • Existence of partials does not give differentiability. The function \(g\) of Lesson L15 has both partials \(0\) at the origin by Proposition 3.1 of Lesson L16, but \(g\) is not continuous there. By Proposition 3.3, \(g\) is not differentiable at the origin. The partial \(\partial g/\partial x = y(y^2 - x^2)/(x^2 + y^2)^2\) is not continuous at the origin: on the \(y\)-axis it equals \(1/y\) for \(y \ne 0\), which is unbounded as \(y \to 0\). So the hypothesis of Theorem 4.1 is not met, and differentiability does not follow from the partials alone.
  • Directional derivatives expose the failure. If \(F\) is differentiable at \(a\) with array \(A\), then \(D_u F(a) = Au\) for every unit \(u\), because the remainder \(F(a + tu) - F(a) - tAu\), divided by \(t\), tends to \(0\). Take the function \(f(x, y) = x^2 y/(x^2 + y^4)\) of Problem R2 in Lesson L17, with \(f(0, 0) = 0\). Its partials at the origin are \(0\), so a differentiable \(f\) would have array \(A = 0\). But for \(\cos\theta \sin\theta \ne 0\) the directional derivative is \(D_u f(0) = \sin\theta \ne 0 = Au\). So \(f\) is not differentiable at the origin.
  • Theorem 4.1 is sufficient, and not necessary. Problem R1 gives a function that is differentiable at a point where its partials are not continuous. So the continuity hypothesis is a sufficient condition for differentiability, and this lesson does not claim that it is necessary.
  • Numerical Jacobians inherit the step analysis. The lab fills the array by central differences with step \(10^{-5}\). Its entries are approximations, with the error of Lesson L13 for each entry, and the printed digits are not the exact Jacobian.

6Misconceptions

  1. “A function that has all its partial derivatives is differentiable.”

    The function \(g\) of Proposition 3.1 in Lesson L16 has both partials at the origin, and it is not differentiable there, by Proposition 3.3 and its discontinuity. Definition 3.1 asks for the approximation in every direction, and the partials use the \(n\) coordinate directions.

  2. “The Jacobian needs the values of the map only along a line.”

    The Jacobian is computed from partial derivatives, which use the coordinate lines, but differentiability in Definition 3.1 requires the approximation for every \(h\). The directional derivatives of Section 5 show that a map can have every partial and still fail the approximation in other directions.

  3. “The Jacobian of a map from \(\R^2\) to \(\R^2\) is a single number.”

    Definition 2.1 gives an array with \(m\) rows and \(n\) columns, here \(2\) by \(2\), with four entries. Example 4.2 writes out all four.

7Problem set

Every problem has a full worked solution. Attempt each one before opening it. Problems marked E use the output of Lab 1.

Assumption 1. The derivative of \(\sin\) is \(\cos\), and the derivative of \(\cos\) is \(-\sin\). This page assumes both and does not prove them. Problems M2 and R1 use them, and each says so.

Mechanics

M1 · The Jacobian of a sum and a product

For \(F(x, y) = (x + y,\; xy)\), find \(J_F(2, 3)\).

Solution

\(\partial F_1/\partial x = 1\), \(\partial F_1/\partial y = 1\), \(\partial F_2/\partial x = y = 3\), \(\partial F_2/\partial y = x = 2\). So \(J_F(2, 3) = \begin{pmatrix} 1 & 1 \\ 3 & 2 \end{pmatrix}\).

M2 · The Jacobian of polar coordinates

For \(F(r, \theta) = (r\cos\theta, r\sin\theta)\), find \(J_F(r, \theta)\), and evaluate it at \((1, 0)\).

Solution

Under Assumption 1, the derivative of \(\cos\) is \(-\sin\) and the derivative of \(\sin\) is \(\cos\). So \(\partial F_1/\partial r = \cos\theta\), \(\partial F_1/\partial\theta = -r\sin\theta\), \(\partial F_2/\partial r = \sin\theta\), \(\partial F_2/\partial\theta = r\cos\theta\). So \(J_F = \begin{pmatrix} \cos\theta & -r\sin\theta \\ \sin\theta & r\cos\theta \end{pmatrix}\), and at \((1, 0)\) it is the identity \(\begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}\).

M3 · Applying the Jacobian to a vector

With \(J = \begin{pmatrix} 1 & 1 \\ 3 & 2 \end{pmatrix}\) from Problem M1 and \(h = (1, -1)\), compute \(Jh\).

Solution

The first entry is \(1 \cdot 1 + 1 \cdot (-1) = 0\), and the second is \(3 \cdot 1 + 2 \cdot (-1) = 1\). So \(Jh = (0, 1)\).

Proof

P1 · The Jacobian from one direction

Show that if \(F\) is differentiable at \(a\) with array \(A\), then the directional derivative \(D_u F(a)\) equals \(Au\) for each unit vector \(u\), where \(D_u F\) is taken componentwise as in Definition 2.1 of Lesson L17.

Solution

Put \(h = tu\) in Definition 3.1. Then \(|F(a + tu) - F(a) - tAu|/|t| = |F(a+tu) - F(a) - Atu|/|tu| \to 0\), since \(|tu| = |t|\). So \((F(a + tu) - F(a))/t \to Au\), and this is the directional derivative of each component, which is \(Au\) componentwise.

P2 · The bound used in Proposition 3.3

For \(A\) with entries \(A_{ij}\) and any \(h\), show that \(|Ah| \le (\sum_{i,j}|A_{ij}|)\,|h|\).

Solution

For each \(i\), \(|(Ah)_i| = |\sum_j A_{ij}h_j| \le \sum_j |A_{ij}|\,|h_j| \le \bigl(\sum_j |A_{ij}|\bigr)|h|\), since \(|h_j| \le |h|\). Then \(|Ah| \le \sum_i |(Ah)_i| \le \sum_i \sum_j |A_{ij}|\,|h| = (\sum_{i,j}|A_{ij}|)|h|\). The first inequality uses \(|v| \le \sum_i |v_i|\), which holds because \(|v|^2 = \sum_i v_i^2 \le (\sum_i |v_i|)^2\).

P3 · The remainder of Example 4.2

Verify the expansion \(F(a + h) - F(a) = (-3, 4) + (2s_1 - 4s_2 + s_1^2 - s_2^2,\; 4s_1 + 2s_2 + 2s_1 s_2)\) for \(a = (1, 2)\) and \(h = (s_1, s_2)\), and check that its length of remainder is \(|h|^2\).

Solution

\(F_1(a + h) = (1 + s_1)^2 - (2 + s_2)^2 = 1 + 2s_1 + s_1^2 - 4 - 4s_2 - s_2^2 = -3 + (2s_1 - 4s_2) + (s_1^2 - s_2^2)\). \(F_2(a + h) = 2(1 + s_1)(2 + s_2) = 4 + 2s_2 + 4s_1 + 2s_1 s_2\). With \(F(a) = (-3, 4)\), the increments are as stated. The linear part \((2s_1 - 4s_2,\; 4s_1 + 2s_2)\) is \(J_F(a)h\). So the remainder is \((s_1^2 - s_2^2,\; 2s_1 s_2)\), and \((s_1^2 - s_2^2)^2 + (2s_1 s_2)^2 = (s_1^2 + s_2^2)^2 = |h|^4\), so its length is \(|h|^2\).

Empirical

E1 · The printed Jacobian (Lab 1)

Lab 1 prints the Jacobian at \((1, 2)\) as \(\begin{pmatrix} 2.000000 & -4.000000 \\ 4.000000 & 2.000000 \end{pmatrix}\). Derive the four entries from Example 4.2, and state the step and the size of the expected error for each entry.

Solution

The closed-form entries are \(2x = 2\), \(-2y = -4\), \(2y = 4\), and \(2x = 2\) at \((1, 2)\). The lab uses central differences with \(h = 10^{-5}\). The map is quadratic, so its third partial derivatives are zero and the truncation part of each entry is zero (Problem P1 of Lesson L16). The rounding part is about \(\delta/h\) with \(\delta\) the half spacing of doubles near \(4\), about \(4.4 \times 10^{-16}\), so it is about \(4.4 \times 10^{-11}\). That is far below the printed precision of six decimals.

E2 · The printed remainder ratios (Lab 1)

Lab 1 prints a remainder ratio equal to \(10^{-1}\) at \(k = 10^{-1}\), and similarly at each step down to \(10^{-4}\). Explain why the ratio equals \(|k|\) exactly, and what this says about Definition 3.1 along this direction.

Solution

The remainder is \((s_1^2 - s_2^2, 2s_1 s_2)\) with \(s = k u\), and its length is \(|s|^2\) by Problem P3. The step length is \(|s| = |k|\). So the ratio is \(|s|^2/|s| = |s| = |k|\). Along this direction, the ratio tends to \(0\) as \(k \to 0\), which is the limit in Definition 3.1 restricted to the one direction \(u = (0.6, 0.8)\). The lab does not show the limit in other directions. Example 4.2 shows it for all directions, because the bound \(|h|^2\) holds for every \(h\).

E3 · The grid error (Lab 1)

Lab 1 reports that the largest central-difference entry error over the 25 grid points is below \(10^{-6}\). Explain what the grid covers and what it does not, and say why the step \(10^{-5}\) does not change the conclusion.

Solution

The grid covers the 25 points with coordinates in \(\{-1, -0.5, 0, 0.5, 1\}\), all within the closed square \([-1, 1]^2\). It does not cover other points, and it cannot show the entry error bound elsewhere. For these entries the truncation part is zero and the rounding part is at most about \(4.4 \times 10^{-11}\), as E1 shows. Both are below \(10^{-6}\), so the printed conclusion holds with a large margin on these points.

Research

R1 · Differentiable without continuous partials

Let \(f(x, y) = (x^2 + y^2)\sin\!\bigl(1/\sqrt{x^2 + y^2}\bigr)\) for \((x, y) \ne (0, 0)\), and \(f(0, 0) = 0\). Show that \(f\) is differentiable at the origin with array \(0\), and that its partial derivative \(\partial f/\partial x\) is not continuous at the origin. What does this say about the sufficiency and necessity of the hypothesis in Theorem 4.1?

Solution

Let \(r = |h|\). Then \(|f(h) - f(0) - 0|/|h| = r^2|\sin(1/r)|/r \le r \to 0\), so \(f\) is differentiable at the origin with array \(0\). Under Assumption 1, the partial in \(x\) at a point with \(x \ne 0\) or \(y \ne 0\) is \(\partial f/\partial x = (2\rho\sin(1/\rho) - \cos(1/\rho))\cdot x/\rho\) with \(\rho = \sqrt{x^2 + y^2}\). Along the points \((\rho, 0)\), this is \(2\rho\sin(1/\rho) - \cos(1/\rho)\). At \(\rho_k = 1/(2\pi k)\), \(\cos(1/\rho_k) = 1\), so the value tends to \(-1\), not to \(\partial f/\partial x(0) = 0\), which is the value at the origin since \(f(t, 0) = t^2\sin(1/|t|)\) gives \(\partial f/\partial x(0) = \lim t\sin(1/|t|) = 0\). So \(\partial f/\partial x\) is not continuous at the origin. The function is differentiable there without continuous partials, so the continuity hypothesis of Theorem 4.1 is sufficient and not necessary.

R2 · A chain of derivatives

Suppose \(F\) is differentiable at \(a\) and \(G\) is differentiable at \(F(a)\). State the array that the composition \(G \circ F\) should have at \(a\), and say which result this lesson would need to prove it. Do not prove it here.

Solution

The natural candidate is the product \(J_G(F(a))\,J_F(a)\), where the product is the row-by-column matrix product, with the inner dimensions matching. Definition 2.1 defines only the product \(Ah\) with a vector, so this product is not defined in the lesson and is used here only as a candidate. The proof needs the approximation of Definition 3.1 for \(G\) at \(F(a)\) applied to \(F(a + h) - F(a)\), which is itself a vector of size at most \(K|h|\) plus a remainder of size \(o(|h|)\), by Definition 3.1 and the bound of Problem P2, with \(K\) the sum of the absolute entries of \(J_F(a)\). This lesson does not prove it, and the claim is stated here as a candidate, with the argument left open for a later result.

R3 · A finite-difference Jacobian in a program

A program fills a \(2 \times 2\) Jacobian by central differences with step \(h\), and stores its values with evaluation error at most \(\delta\). Write the total error bound for each entry using Lesson L13, and state the step that minimizes it when the third derivatives are bounded by \(M\), with \(\delta > 0\) and \(M > 0\).

Solution

For each entry, the truncation part is at most \(\tfrac{M}{6}h^2\) and the rounding part is at most \(\delta/h\), by Theorem 2.2 and Proposition 3.2 of Lesson L13. The total bound is \(B(h) = \tfrac{M}{6}h^2 + \tfrac{\delta}{h}\). By Problem P3 of Lesson L13, the minimizer is \(h^* = (3\delta/M)^{1/3}\), and the value there is \(B(h^*) = \tfrac{3\delta}{2h^*}\), provided \(h^* \le h_0\), where \(M\) bounds the third derivatives of every component on the neighborhood of radius \(h_0\) about \(a\). Otherwise the smallest value of \(B\) on \((0, h_0]\) is at \(h_0\). The same step applies to each entry, since the bound is the same for each.
