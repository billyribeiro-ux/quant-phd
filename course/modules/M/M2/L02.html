Continuity and the Limit Laws

A sum, a product or a ratio of two sequences can be studied one part at a time. If each part settles down, does the combination settle down, and to what value? The limit laws answer this for sequences. Each law has a hypothesis that must hold before it applies, and the quotient law has a hypothesis beyond convergence: when the limit of the denominator is zero, the quotient can diverge (Remark 3.1). This lesson proves the laws and applies them to continuity.

1The limit laws for sequences

Proposition 1.1 (limit laws)

Let \((a_n)\) and \((b_n)\) be sequences of real numbers with \(a_n \to a\) and \(b_n \to b\), where \(a\) and \(b\) are real numbers. Hypotheses: both limits exist in the sense of Definition 2.1 of Lesson 1. Then:

(i) \(a_n + b_n \to a + b\);

(ii) \(a_n b_n \to ab\);

(iii) if \(b \ne 0\) and \(b_n \ne 0\) for every \(n\), then \(a_n / b_n \to a / b\).

Proof

(i) Let \(\varepsilon > 0\). Choose \(N_1\) with \(|a_n - a| < \varepsilon/2\) for \(n \ge N_1\), and \(N_2\) with \(|b_n - b| < \varepsilon/2\) for \(n \ge N_2\). For \(n \ge \max(N_1, N_2)\), the triangle inequality gives \(|(a_n + b_n) - (a + b)| \le |a_n - a| + |b_n - b| < \varepsilon\).

(ii) Write \(a_n b_n - ab = a_n(b_n - b) + b(a_n - a)\). Choose \(N_0\) with \(|a_n - a| < 1\) for \(n \ge N_0\); then \(|a_n| < |a| + 1\) for these \(n\), by the triangle inequality. Let \(\varepsilon > 0\). Choose \(N\ge N_0\) so that for \(n \ge N\), \(|b_n - b| < \dfrac{\varepsilon}{2(|a| + 1)}\) and \(|a_n - a| < \dfrac{\varepsilon}{2(|b| + 1)}\). Then

\[|a_n b_n - ab| \le |a_n|\,|b_n - b| + |b|\,|a_n - a| < (|a| + 1)\frac{\varepsilon}{2(|a| + 1)} + |b|\frac{\varepsilon}{2(|b| + 1)} < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon,\]

using \(|b|/(|b| + 1) < 1\) in the last step.

(iii) Since \(b \ne 0\), put \(\delta = |b|/2 > 0\). Choose \(N_1\) with \(|b_n - b| < \delta\) for \(n \ge N_1\). Then \(|b_n| \ge |b| - |b_n - b| > |b|/2\), so \(1/|b_n| < 2/|b|\) for these \(n\). Now \[\frac{a_n}{b_n} - \frac{a}{b} = \frac{b(a_n - a) - a(b_n - b)}{b\, b_n}, \qquad \left|\frac{a_n}{b_n} - \frac{a}{b}\right| < \frac{2}{|b|^2}\bigl(|b|\,|a_n - a| + |a|\,|b_n - b|\bigr).\] Let \(\varepsilon > 0\). Choose \(N \ge N_1\) with \(|a_n - a| < \varepsilon|b|/4\) and \(|b_n - b| < \varepsilon |b|^2 / (4(|a| + 1))\) for \(n \ge N\). Then the bracket is less than \(\varepsilon|b|^2/4 + \varepsilon|b|^2/4 = \varepsilon|b|^2/2\), and the whole expression is less than \(\varepsilon\). \(\blacksquare\)

The hypothesis \(b_n \ne 0\) in (iii) is needed for the quotient to be defined at every index. The hypothesis \(b \ne 0\) is needed for the proof: it is what keeps \(|b_n|\) bounded away from zero for large \(n\).

"""M2 lab L02: the limit laws for sums, products and quotients, checked term by term on a grid of n.

Standard library only. No randomness and no network. Two sequences are used: a_n = (2n + 1)/(n + 1), with limit 2,
and b_n = (n + 2)/n, with limit 1. Every term and every error is an exact rational number (fractions.Fraction).
The script checks the closed forms of the exact errors against the terms, and the triangle inequality for the sum,
at n = 1, 10, 100, 1000 and 10000 only. The limit laws themselves are proved on the page for every n. The grid
is a finite check of the closed forms, and it says nothing about other n.
"""

from __future__ import annotations

from fractions import Fraction

GRID = (1, 10, 100, 1000, 10000)


def a(n: int) -> Fraction:
    """The term a_n = (2n + 1)/(n + 1), with limit 2, for an integer n >= 1."""
    if n < 1:
        raise ValueError(f"a needs n >= 1, got {n}")
    return Fraction(2 * n + 1, n + 1)


def b(n: int) -> Fraction:
    """The term b_n = (n + 2)/n, with limit 1, for an integer n >= 1. Never zero."""
    if n < 1:
        raise ValueError(f"b needs n >= 1, got {n}")
    return Fraction(n + 2, n)


def sum_error(n: int) -> Fraction:
    """The exact distance |(a_n + b_n) - 3| from the sum to its limit 3."""
    return abs(a(n) + b(n) - 3)


def product_error(n: int) -> Fraction:
    """The exact distance |a_n b_n - 2| from the product to its limit 2 (the product of limits 2 and 1)."""
    return abs(a(n) * b(n) - 2)


def quotient_error(n: int) -> Fraction:
    """The exact distance |a_n / b_n - 2| from the quotient to its limit 2 (the quotient of limits 2 and 1)."""
    return abs(a(n) / b(n) - 2)


def closed_forms_hold(n: int) -> bool:
    """True when the three errors equal the closed forms (n+2)/(n(n+1)), (3n+2)/(n(n+1)) and (5n+4)/((n+1)(n+2))."""
    return (
        sum_error(n) == Fraction(n + 2, n * (n + 1))
        and product_error(n) == Fraction(3 * n + 2, n * (n + 1))
        and quotient_error(n) == Fraction(5 * n + 4, (n + 1) * (n + 2))
    )


def main() -> None:
    print("n, sum error, product error, quotient error")
    for n in GRID:
        print(f"{n}, {float(sum_error(n)):.6e}, {float(product_error(n)):.6e}, {float(quotient_error(n)):.6e}")
    print(f"closed forms match the exact errors at every grid n: {all(closed_forms_hold(n) for n in GRID)}")
    triangle = all(sum_error(n) <= abs(a(n) - 2) + abs(b(n) - 1) for n in GRID)
    print(f"sum error at most |a_n - 2| + |b_n - 1| at every grid n: {triangle}")

2Continuity, through sequences

Let \(f\) be a function defined on a set \(D\) of real numbers, and let \(a\) be a point of \(D\). We say that \(f\) is continuous at \(a\) when \(f(x_n) \to f(a)\) for every sequence \((x_n)\) with each \(x_n\) in \(D\) and \(x_n \to a\). This sentence is the definition used in this lesson. It is stated in words, with no numbered definition and no concept entry. The function is continuous on \(D\) when it is continuous at every point of \(D\).

Example 2.1 (the identity and the square)

Let \(f(x) = x\) on \(\mathbb{R}\). If \(x_n \to a\), then \(f(x_n) = x_n \to a = f(a)\) by the definition of the limit, so \(f\) is continuous at every \(a\). The next result shows that the square is continuous at every \(a\) too.

Corollary 2.2 (sums and products of continuous functions)

Let \(f\) and \(g\) be functions on \(D\), both continuous at a point \(a\) of \(D\). Hypotheses: the continuity is in the sequential sense of §2. Then \(f + g\) and \(fg\) are continuous at \(a\).

Proof

Let \((x_n)\) be a sequence in \(D\) with \(x_n \to a\). By continuity, \(f(x_n) \to f(a)\) and \(g(x_n) \to g(a)\). Proposition 1.1 (i) and (ii) give \((f + g)(x_n) = f(x_n) + g(x_n) \to f(a) + g(a) = (f+g)(a)\) and \((fg)(x_n) \to f(a)g(a) = (fg)(a)\). Since \((x_n)\) was arbitrary, \(f + g\) and \(fg\) are continuous at \(a\). \(\blacksquare\)

Example 2.3 (a polynomial)

Let \(f(x) = x^2\). By Example 2.1 the identity is continuous at each point, and by Corollary 2.2 applied with \(f = g = \mathrm{id}\), the product \(x \mapsto x \cdot x\) is continuous at each point. So \(x^2\) is continuous at every \(a\), with \(\lim x_n^2 = a^2\) for every sequence \(x_n \to a\).

3Quotients and the nonzero hypothesis

Remark 3.1 (the quotient needs a limit away from zero)

Proposition 1.1 (iii) needs \(b \ne 0\). Without it, the law fails. Take \(a_n = 1\) and \(b_n = 1/n\). Then \(b_n \to 0\), but \(a_n / b_n = n\), which does not converge. The law says nothing when its hypothesis fails.

Remark 3.1 shows an error that is easy to make with the quotient law. The quotient of two convergent sequences can diverge when the limit of the denominator is zero (Problem R1). Two divergent sequences can also have a convergent sum or product: Misconception 2 gives the sum, and the product of \((-1)^n\) with itself is 1 for every \(n\).

4Where the canon breaks

The limit laws are exact, and the sequential definition of continuity is exact too. Three limits of practice make them look broader than they are.

  • The converse of the sum law is false. Proposition 1.1 gives a limit for the sum when both terms converge. It says nothing about a sum whose terms diverge. Misconception 2 gives the counterexample.
  • Continuity needs a value at the point. The sequential definition requires \(f(a)\) to exist. A function that has a limit at \(a\) but no value there, or a different value there, is not continuous at \(a\), as Misconception 3 shows.
  • The laws say nothing about speed. The proof of Proposition 1.1 gives thresholds, but the lab prints errors at five indices. The rate at which an error falls is a separate question, and this lesson does not answer it.

5Misconceptions

  1. “The limit of a quotient is the quotient of the limits, whatever the denominator does.”

    Remark 3.1 gives \(a_n = 1\) and \(b_n = 1/n\). The denominator converges to 0, and the quotient \(n\) diverges. Proposition 1.1 (iii) excludes this case by its hypothesis \(b \ne 0\), and the example shows that the hypothesis matters.

  2. “A sum converges only when each of its terms converges.”

    Take \(a_n = (-1)^n\) and \(b_n = -(-1)^n\). The sequence \(a_n\) diverges by Example 4.1 of Lesson 1. The sequence \(b_n\) also diverges: if \(b_n \to L\), then \(a_n = (-1) b_n \to -L\) by Proposition 1.1 (ii) with the constant sequence \(-1\), which contradicts Example 4.1. The sum \(a_n + b_n\) equals 0 for every \(n\), so it converges to 0. Proposition 1.1 (i) runs in one direction: it gives the limit of a sum from the limits of its terms.

  3. “A function is continuous at \(a\) whenever its formula has a limit at \(a\).”

    Let \(f(x) = x + 1\) for \(x \ne 1\) and \(f(1) = 0\). Take \(x_n = 1 + 1/n\). Then \(x_n \to 1\) and \(x_n \ne 1\), so \(f(x_n) = x_n + 1 \to 2\) by Proposition 1.1 (i) and \(1/n \to 0\). But \(f(1) = 0 \ne 2\). So \(f\) is not continuous at 1, although the formula has the limit 2 there.

6Problem set

Every problem has a full worked solution. Attempt each one before opening it. Problems marked E use the output of Lab 1.

Mechanics

M1 · A rational sequence with equal degrees

Find the limit of \(a_n = \dfrac{3n^2 + 1}{n^2 + 2}\), using Proposition 1.1 and the fact \(1/n \to 0\) from Lesson 1, Problem M3.

Solution

Divide the numerator and the denominator by \(n^2\): \(a_n = (3 + 1/n^2)/(1 + 2/n^2)\). From \(1/n \to 0\) and Proposition 1.1 (ii), \(1/n^2 = (1/n)(1/n) \to 0\), and then \(2/n^2 \to 0\) by (ii) with the constant sequence 2. The numerator tends to 3 and the denominator to 1 by (i). The denominator is never zero and its limit is 1, so (iii) gives \(a_n \to 3\).

M2 · A sequence of half-quotients

Let \(c_n = (n + 1)/(2n)\). Find its limit and state which law of Proposition 1.1 you use, and which hypothesis it needs.

Solution

We have \(c_n = (1 + 1/n)/2\). The sequence \(1 + 1/n\) tends to 1 by (i), since \(1/n \to 0\). Multiplying by the constant \(1/2\) is the product law (ii) with the constant sequence \(1/2\), so \(c_n \to 1/2\). The quotient law (iii) is not needed here, because the denominator \(2\) is constant and not zero.

M3 · A product with a sequence tending to zero

Let \(d_n = 5 \cdot (-1)^n / n\). Find the limit of \(d_n\), using Proposition 1.1 (ii).

Solution

The sequence \((-1)^n/n\) tends to 0, by Lesson 1, Problem M3. The constant sequence 5 tends to 5. By (ii), the product \(d_n\) tends to \(5 \cdot 0 = 0\). The hypothesis of (ii) holds for any convergent pair, and no nonzero denominator is involved.

Proof

P1 · The absolute value of a convergent sequence

Let \(a_n \to a\). Prove that \(|a_n| \to |a|\), using the inequality \(\bigl||x| - |y|\bigr| \le |x - y|\).

Solution

Let \(\varepsilon > 0\), and choose \(N\) with \(|a_n - a| < \varepsilon\) for \(n \ge N\). For such \(n\), \(\bigl||a_n| - |a|\bigr| \le |a_n - a| < \varepsilon\), by the stated inequality. So \(|a_n| \to |a|\) by Definition 2.1 of Lesson 1.

P2 · Squares of a convergent sequence

Let \(a_n \to a\). Prove that \(a_n^2 \to a^2\) by applying Proposition 1.1 (ii) to the pair \((a_n, a_n)\), and state the hypotheses used.

Solution

The pair \(a_n\) and \(a_n\) both tend to \(a\), by hypothesis. Proposition 1.1 (ii) applies with \(a_n\) and \(b_n = a_n\), and gives \(a_n \cdot a_n \to a \cdot a = a^2\). The hypothesis used is that the two sequences converge to real numbers, which is given. No quotient law is used.

P3 · The product law without a bound

Let \(a_n = n\) and \(b_n = 0\) for every \(n\). Show that \(a_n b_n \to 0\), and that \(a_n\) diverges. What does this show about the converse of Proposition 1.1 (ii)?

Solution

The product \(a_n b_n = 0\) for every \(n\), so it converges to 0. The sequence \(a_n = n\) is unbounded, and a convergent sequence is bounded from some index on, by the estimate \(|a_n| < |a| + 1\) used in the proof of (ii), while \(n\) exceeds every bound. So \(a_n\) diverges, and the converse, that a product converges only when each factor converges, is false.

Empirical

E1 · The sum error at n = 10 (from Lab 1)

Lab 1 prints the sum error at \(n = 10\). Derive its exact value from the closed form, and check it against the printed decimal.

Solution

The sum is \(a_n + b_n = (2n+1)/(n+1) + (n+2)/n\), and \(a_n - 2 = -1/(n+1)\), \(b_n - 1 = 2/n\). So \(|a_n + b_n - 3| = |2/n - 1/(n+1)| = (n+2)/(n(n+1))\). At \(n = 10\) this is \(12/110 = 6/55 \approx 0.109091\). Lab 1 prints \(1.090909 \times 10^{-1}\), which agrees.

E2 · The product error at n = 100 (from Lab 1)

Lab 1 prints the product error at \(n = 100\) as \(2.990099 \times 10^{-2}\). Compute the exact fraction and show that the printed value is its rounding.

Solution

The product is \(a_n b_n = (2n+1)(n+2)/(n(n+1))\), and \(a_n b_n - 2 = (3n+2)/(n(n+1))\). At \(n = 100\) this is \(302/10100 = 0.0299009900\ldots\). Lab 1 prints \(2.990099 \times 10^{-2}\), which is that value rounded to six decimal places of the mantissa.

E3 · The quotient error at n = 1 (from Lab 1)

Lab 1 prints the quotient error at \(n = 1\) as \(1.500000 \times 10^{0}\). Check it from the closed form, using \(a_1 = 3/2\) and \(b_1 = 3\).

Solution

At \(n = 1\), \(a_1 / b_1 = (3/2)/3 = 1/2\), so the error is \(|1/2 - 2| = 3/2 = 1.5\). The closed form \((5n+4)/((n+1)(n+2))\) gives \(9/6 = 3/2\) at \(n = 1\), which agrees with the printed value.

Research

R1 · When the quotient diverges

Let \(a_n \to a \ne 0\) and \(b_n \to 0\), with \(b_n \ne 0\) for every \(n\). Prove that \(|a_n/b_n| \to \infty\), meaning that for every \(M > 0\) there is \(N\) with \(|a_n/b_n| > M\) for \(n \ge N\).

Solution

Since \(a_n \to a \ne 0\), there is \(N_1\) with \(|a_n| > |a|/2\) for \(n \ge N_1\), as in the proof of (iii). Given \(M > 0\), since \(b_n \to 0\), there is \(N\ge N_1\) with \(|b_n| < |a|/(2M)\) for \(n \ge N\). For such \(n\), \(|a_n / b_n| > (|a|/2)/|b_n| > (|a|/2)\cdot(2M/|a|) = M\). So the quotient diverges to infinity, which is the Remark 3.1 phenomenon in general.

R2 · The absolute value and continuity

Let \(f(x) = |x|\) on \(\mathbb{R}\). Show that \(f\) is continuous at 0 in the sequential sense, and identify the definition the argument uses.

Solution

Let \(x_n \to 0\). Then \(f(x_n) = |x_n| = |x_n - 0|\), and by Definition 2.1 applied to \(x_n\) with limit 0, \(|x_n - 0| \to 0\). So \(f(x_n) \to 0 = f(0)\). The argument uses the definition of convergence and no law from Proposition 1.1.

R3 · Which hypothesis does the sum converse need

Suppose \(a_n + b_n\) converges and \(a_n\) converges. Prove that \(b_n\) converges, and state the limit law used.

Solution

Let \(s_n = a_n + b_n\), which converges to some \(s\). Then \(b_n = s_n - a_n\). By Proposition 1.1 (i) applied to \(s_n\) and \(-a_n\), and the fact that \(-a_n \to -a\) (the product law with the constant \(-1\)), \(b_n \to s - a\). So if the sum and one summand converge, the other summand converges. The example in Misconception 2 has both summands divergent, which is the case this argument does not cover.

8Retrieval quiz

Answer from memory, then check. Finishing the quiz adds this lesson's cards to your review deck.

  1. Which hypothesis does the quotient law (Proposition 1.1 (iii)) need?

    Options

    The proof bounds \(1/|b_n|\), which needs \(b \ne 0\), and the definition of the quotient needs \(b_n \ne 0\).

  2. With \(a_n = 1\) and \(b_n = 1/n\), what happens to \(a_n/b_n\)?

    Options

    \(a_n/b_n = n\), which is unbounded (Remark 3.1).

  3. What is the limit of \((3n^2 + 1)/(n^2 + 2)\)?

    Divide by \(n^2\): the numerator tends to 3 and the denominator to 1 (Problem M1).

  4. Do \(a_n = (-1)^n\) and \(b_n = -(-1)^n\) both converge?

    Options

    Lesson 1, Example 4.1 shows \((-1)^n\) diverges. If \(b_n\) converged, then \(a_n = -b_n\) would converge by Proposition 1.1 (ii), so \(b_n\) diverges too. Their sum is identically 0 (Misconception 2).

  5. For \(a_n = (2n+1)/(n+1)\) and \(b_n = (n+2)/n\), what is the product error \(|a_n b_n - 2|\) at \(n = 100\), to eight decimal places?

    The error is \((3n+2)/(n(n+1)) = 302/10100 = 0.02990099\ldots\) (Problem E2).

  6. Under the sequential definition in §2, what is needed for \(f\) to be continuous at \(a\)?

    Options

    §2 requires \(f(a)\) to exist and the convergence \(f(x_n) \to f(a)\) for every sequence in \(D\) that converges to \(a\).

  7. Why is the identity \(f(x) = x\) continuous at every point?

    Options

    Example 2.1: with \(f(x) = x\), the convergence \(f(x_n) \to f(a)\) is the hypothesis \(x_n \to a\) itself.

  8. For the same sequences, what is the sum error \(|(a_n + b_n) - 3|\) at \(n = 10\), to seven decimal places?

    The error is \((n+2)/(n(n+1)) = 12/110 = 0.1090909\ldots\) (Problem E1).

  9. Is the converse of the product law true: if \(a_n b_n\) converges, must both \(a_n\) and \(b_n\) converge?

    Options

    With \(b_n = 0\), the product is 0 and converges, while \(a_n = n\) diverges (Problem P3).
