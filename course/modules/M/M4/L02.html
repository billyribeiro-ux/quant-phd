Expectation and Variance

The expected loss of a position and the spread of its losses are two numbers computed from the distribution of the loss. Both have exact formulas for a finite law, and later lessons of M4 use both. This lesson defines expectation as a probability-weighted sum, states the integral form that M2's definite integral gives for a continuous law, and defines variance and standard deviation. It proves the shortcut \(\operatorname{Var}(X) = E[X^2] - (EX)^2\) and the scale rule for variance, and it checks both with exact arithmetic on a die and on a two-point loss in integer cents.

1Expectation of a finite law

Throughout this lesson \(X\) is a random variable on a finite probability space \(\Omega\) with positive weights, as in Lesson 1. Its distinct values are \(x_1, \dots, x_m\), and \(p_k = P(X = x_k)\).

Definition 1.1 (expectation of a finite law)

The expectation of \(X\) is \(E[X] = \sum_{k=1}^m x_k\, p_k\). It is the average of the values of \(X\), weighted by their probabilities. The expectation is a real number, and it need not be one of the values of \(X\).

Proposition 1.2 (expectation over outcomes)

For \(X\) as above, \(\sum_{\omega \in \Omega} X(\omega)\, p(\omega) = \sum_{k=1}^m x_k\, p_k\).

Proof

The events \(\{X = x_1\}, \dots, \{X = x_m\}\) partition \(\Omega\), since every outcome has exactly one value. Grouping the outcomes by value gives \(\sum_{\omega} X(\omega) p(\omega) = \sum_{k} \sum_{\omega : X(\omega) = x_k} x_k\, p(\omega) = \sum_{k} x_k \sum_{\omega : X(\omega) = x_k} p(\omega) = \sum_{k} x_k\, p_k\). The last step uses the definition \(p_k = P(X = x_k)\). \(\blacksquare\)

Proposition 1.3 (linearity on a finite space)

Let \(U\) and \(V\) be random variables on the same finite probability space, and let \(\alpha, \beta, \gamma\) be real constants. Then \(E[\alpha U + \beta V + \gamma] = \alpha E[U] + \beta E[V] + \gamma\).

Proof

By Proposition 1.2, \(E[W] = \sum_{\omega} W(\omega)\, p(\omega)\) for any random variable \(W\) on the space. With \(W = \alpha U + \beta V + \gamma\), we get \(E[W] = \alpha \sum_\omega U(\omega) p(\omega) + \beta \sum_\omega V(\omega) p(\omega) + \gamma \sum_\omega p(\omega)\). The three sums are \(E[U]\), \(E[V]\) and \(P(\Omega) = 1\). \(\blacksquare\)

Example 1.4 (a fair die)

Let \(X\) be the number shown by a fair six-sided die, so \(X\) takes the values 1 to 6 with probability \(\tfrac16\) each. Then \(E[X] = \tfrac16(1 + 2 + 3 + 4 + 5 + 6) = \tfrac{21}{6} = \tfrac72\). The expectation 3.5 is not a face of the die.

Example 1.5 (a two-point loss in cents)

Let \(L\) be a loss in integer cents: \(L = 250000\) with probability \(\tfrac1{20}\), and \(L = 0\) with probability \(\tfrac{19}{20}\). Then \(E[L] = 250000 \cdot \tfrac1{20} + 0 \cdot \tfrac{19}{20} = 12500\) cents. The expected loss is an integer number of cents here because the probabilities have denominator 20, which divides 250000.

Remark 1.6 (the continuous case, in M2's integral)

A random variable with a continuous density \(f\), so that \(P(a \le X \le b) = \int_a^b f(x)\, dx\), has expectation \(E[X] = \int_{-\infty}^{\infty} x\, f(x)\, dx\) whenever \(\int_{-\infty}^{\infty} |x|\, f(x)\, dx\) is finite. The integral over the whole line is the limit of definite integrals as the endpoints go to \(\pm\infty\). When the law is discrete, the integral is the sum of Definition 1.1. This remark gives a definition for continuous laws. No result of this lesson depends on it, and it is not proved here.

2Variance and standard deviation

Definition 2.1 (variance and standard deviation)

Let \(\mu = E[X]\). The variance of \(X\) is \(\operatorname{Var}(X) = E[(X - \mu)^2]\), and the standard deviation is \(\sigma = \sqrt{\operatorname{Var}(X)}\). The variance is in squared units of \(X\), and the standard deviation is in the units of \(X\). A variance is never negative, because it is the expectation of a square.

Proposition 2.2 (shortcut formula)

For \(X\) on a finite probability space with positive weights, \(\operatorname{Var}(X) = E[X^2] - (E[X])^2\).

Proof

Expand the square: \((X - \mu)^2 = X^2 - 2\mu X + \mu^2\), where \(\mu\) is a constant. Proposition 1.3, with \(U = X^2\), \(V = X\), \(\alpha = 1\), \(\beta = -2\mu\) and \(\gamma = \mu^2\), gives \(E[(X - \mu)^2] = E[X^2] - 2\mu E[X] + \mu^2\). Since \(E[X] = \mu\), this is \(E[X^2] - 2\mu^2 + \mu^2 = E[X^2] - \mu^2\). \(\blacksquare\)

Proposition 2.3 (scale and shift)

For constants \(a, b\), \(\operatorname{Var}(aX + b) = a^2 \operatorname{Var}(X)\). In particular \(\operatorname{Var}(X + b) = \operatorname{Var}(X)\), and \(\operatorname{Var}(aX)\) is \(a^2\) times the variance of \(X\).

Proof

By Proposition 1.3, \(E[aX + b] = a\mu + b\). So \((aX + b) - E[aX + b] = a(X - \mu)\), and its square is \(a^2 (X - \mu)^2\). Taking expectations and using Proposition 1.3 once more, \(\operatorname{Var}(aX + b) = a^2 E[(X - \mu)^2] = a^2 \operatorname{Var}(X)\). \(\blacksquare\)

Proposition 2.4 (zero variance means a single value)

For \(X\) on a finite probability space with positive weights, \(\operatorname{Var}(X) = 0\) if and only if \(X\) takes exactly one value.

Proof

Write \(\operatorname{Var}(X) = \sum_k (x_k - \mu)^2 p_k\), which is a sum of nonnegative terms, each with \(p_k > 0\). The sum is zero exactly when every term is zero, that is, when \(x_k = \mu\) for every \(k\). That happens exactly when \(m = 1\), since the \(x_k\) are distinct. Conversely, if \(X\) takes one value, that value is \(\mu\), and the variance is 0. \(\blacksquare\)

Example 2.5 (the fair die)

For the die of Example 1.4, \(E[X^2] = \tfrac16(1 + 4 + 9 + 16 + 25 + 36) = \tfrac{91}{6}\). By Proposition 2.2, \(\operatorname{Var}(X) = \tfrac{91}{6} - \left(\tfrac72\right)^2 = \tfrac{182}{12} - \tfrac{147}{12} = \tfrac{35}{12}\). The standard deviation is \(\sqrt{35/12}\), which is about 1.708 when rounded from the exact value \(35/12\).

Example 2.6 (the two-point loss in cents)

For \(L\) of Example 1.5, \(E[L^2] = 250000^2 \cdot \tfrac1{20} = 3\,125\,000\,000\) cents squared, and \(E[L] = 12500\). By Proposition 2.2, \(\operatorname{Var}(L) = 3\,125\,000\,000 - 12500^2 = 3\,125\,000\,000 - 156\,250\,000 = 2\,968\,750\,000\) cents squared. The standard deviation is \(\sqrt{2\,968\,750\,000}\), which is about 54486.24 cents. Lab 2 prints the same two values.

Lab 2 · Exact moments of two finite laws, and a seeded sample check

Predicted before running from Examples 1.4, 1.5, 2.5 and 2.6. The die has \(E[X] = \tfrac72\), \(E[X^2] = \tfrac{91}{6}\) and \(\operatorname{Var}(X) = \tfrac{35}{12}\). The definition and the shortcut should agree, and \(\operatorname{Var}(2X) = \tfrac{35}{3}\), which is 4 times \(\operatorname{Var}(X)\). The loss has \(E[L] = 12500\) cents, \(E[L^2] = 3\,125\,000\,000\) and \(\operatorname{Var}(L) = 2\,968\,750\,000\). The seeded samples are estimates, not the exact values. Their printed means should be compared with \(\tfrac72\) and with 12500 cents, and the printed differences show how far each run is from its exact value. The lab does not report how far a sample must be from the exact value to count as close.

"""M4 lab L02: expectation and variance of two finite laws, computed exactly, then a seeded sample check.

Standard library only (fractions, random). The two laws are stated tables, not data: a fair six-sided
die (values 1 to 6, each with probability 1/6) and a two-point loss in integer cents (a loss of 250000
cents with probability 1/20, and no loss otherwise). Expectations and variances are exact rationals or
integers. Each variance is computed two ways, from the definition E[(X - mu)^2] and from the shortcut
E[X^2] - mu^2, and the program checks that the two agree. It also checks the scale rule
Var(2X) = 4 Var(X) on the die. Last, it draws seeded samples (seed 2026 for the die, seed 2027 for the
loss) and prints their sample means and variances, and for the loss the number of losses and their total.
A sample is one random run, so its printed values are estimates that a different seed would move; the exact
values above them are not.
"""

from __future__ import annotations

import math
import random
from collections.abc import Sequence
from fractions import Fraction

Law = Sequence[tuple[int, Fraction]]

DIE: tuple[tuple[int, Fraction], ...] = tuple((k, Fraction(1, 6)) for k in range(1, 7))
LOSS: tuple[tuple[int, Fraction], ...] = ((0, Fraction(19, 20)), (250000, Fraction(1, 20)))
SEED_DIE = 2026
SEED_LOSS = 2027
N_DRAWS = 10000


def check_law(law: Law) -> None:
    """Raise ValueError unless every probability lies in [0, 1] and the probabilities sum to exactly 1."""
    if any(p < 0 or p > 1 for _, p in law):
        raise ValueError("each probability must lie in [0, 1]")
    if sum((p for _, p in law), Fraction(0)) != 1:
        raise ValueError("probabilities must sum to exactly 1")


def expectation(law: Law) -> Fraction:
    """E[X] = sum of x times P(X = x), over the finite support."""
    return sum((v * p for v, p in law), Fraction(0))


def second_moment(law: Law) -> Fraction:
    """E[X^2] = sum of x^2 times P(X = x)."""
    return sum((v * v * p for v, p in law), Fraction(0))


def variance_by_definition(law: Law) -> Fraction:
    """Var(X) = E[(X - mu)^2], with mu = E[X]."""
    mu = expectation(law)
    return sum(((v - mu) ** 2 * p for v, p in law), Fraction(0))


def variance_shortcut(law: Law) -> Fraction:
    """Var(X) = E[X^2] - mu^2."""
    mu = expectation(law)
    return second_moment(law) - mu * mu


def scaled(law: Law, a: int) -> Law:
    """The law of aX for an integer a: each value multiplied by a, with its probability unchanged."""
    return tuple((a * v, p) for v, p in law)


def sample_mean_and_variance(xs: Sequence[int]) -> tuple[float, float]:
    """Sample mean and sample variance with divisor n (the population form of the variance, as in Var above)."""
    n = len(xs)
    mean = sum(xs) / n
    variance = sum((x - mean) ** 2 for x in xs) / n
    return mean, variance


def main() -> None:
    check_law(DIE)
    check_law(LOSS)

    mu_die = expectation(DIE)
    var_die = variance_by_definition(DIE)
    print(f"fair die: E[X] = {mu_die}, E[X^2] = {second_moment(DIE)}, Var(X) = {var_die}")
    print(f"definition and shortcut agree for the die: {var_die == variance_shortcut(DIE)}")
    print(
        f"Var(2X) = {variance_by_definition(scaled(DIE, 2))}, which equals 4 Var(X): "
        f"{variance_by_definition(scaled(DIE, 2)) == 4 * var_die}"
    )

    mu_loss = expectation(LOSS)
    var_loss = variance_by_definition(LOSS)
    print(f"two-point loss in cents: E[X] = {mu_loss}, E[X^2] = {second_moment(LOSS)}, Var(X) = {var_loss}")
    print(f"definition and shortcut agree for the loss: {var_loss == variance_shortcut(LOSS)}")
    print(f"standard deviation of the loss in cents: {math.sqrt(var_loss):.2f}")

    rng_die = random.Random(SEED_DIE)
    rolls = [rng_die.randint(1, 6) for _ in range(N_DRAWS)]
    mean_die, var_sample_die = sample_mean_and_variance(rolls)
    print(f"die sample, seed {SEED_DIE}, n = {N_DRAWS}: mean {mean_die:.3f}, variance {var_sample_die:.3f}")
    print(f"sample mean minus 7/2: {mean_die - 3.5:+.3f}")

    rng_loss = random.Random(SEED_LOSS)
    losses = [250000 if rng_loss.random() < 0.05 else 0 for _ in range(N_DRAWS)]
    mean_loss, var_sample_loss = sample_mean_and_variance(losses)
    count = sum(1 for x in losses if x > 0)
    print(f"loss sample, seed {SEED_LOSS}, n = {N_DRAWS}: losses {count}, total {sum(losses)} cents")
    print(f"sample mean loss {mean_loss:.1f} cents, sample variance {var_sample_loss:.1f} cents squared")


main()

Var(2X) = 35/3, which equals 4 Var(X): True

The first block is exact: the fractions and integers are printed as computed, and the two "True" lines confirm the shortcut of Proposition 2.2 and the scale rule of Proposition 2.3 for this die. The loss is in integer cents, so its variance is in cents squared and its standard deviation is in cents. The seeded lines are one run each: seed 2026 gives a die sample mean of 3.469, which is 0.031 below \(\tfrac72\), and seed 2027 gives 489 losses in 10000 draws, with a sample mean of 12225.0 cents. Another seed gives other numbers, and the printed lines say nothing about how far a sample of this size is from the exact value in general.

3Where the canon breaks

The formulas above need hypotheses, and the mean is not a typical value.

  • The expectation can fail to exist. Remark 1.6 requires \(\int |x| f(x)\, dx\) to be finite. For a continuous law where that integral is infinite, Remark 1.6 gives no value, and a statement about the mean is then undefined. Every computation in this lesson uses a finite law, so that case does not arise here.
  • The variance needs a second moment. Proposition 2.2 needs \(E[X^2]\) to be finite. On a finite law this holds, so every variance here is defined. Lesson 6 gives a Student-t law with \(\nu \le 2\), which has no finite variance, and Lesson 10 treats heavy tails.
  • The mean is not the median. For the table of L01 Example 3.6, \(E[X] = \tfrac{3}{10}\), since \((-2 - 2 + 0 + 2 + 2 + 3)/10 = 3/10\). Its quantile at \(\tfrac12\) is \(Q(\tfrac12) = 0\), as L01 Example 3.6 shows. The two numbers answer different questions, and a report must say which one it gives.
  • The variance has squared units. A variance of 2968750000 cents squared is not a loss of that size. The standard deviation, in cents, is the figure with the units of the loss.

4Misconceptions

  1. “The expectation is always one of the values the variable takes.”

    Example 1.4 gives \(E[X] = \tfrac72\) for a die whose faces are 1 to 6. Definition 1.1 is a weighted average, and an average of integers can be a non-integer. The value 3.5 is not a face, and Lab 2 prints \(\tfrac72\) as the exact expectation.

  2. “Scaling a variable by \(a\) multiplies its variance by \(a\).”

    Proposition 2.3 gives \(\operatorname{Var}(aX) = a^2 \operatorname{Var}(X)\). For the die with \(a = 2\), the variance is \(\tfrac{35}{3}\), which is 4 times \(\tfrac{35}{12}\), not twice. Lab 2 prints this check as True.

  3. “The variance is the expectation of \(X^2\).”

    Proposition 2.2 subtracts \((EX)^2\). For the die, \(E[X^2] = \tfrac{91}{6}\) is about 15.17, while \(\operatorname{Var}(X) = \tfrac{35}{12}\) is about 2.92. The subtraction removes the squared mean, and omitting it gives a number of the wrong size.

  4. “A sample mean from a seeded run equals the expectation.”

    Lab 2 prints a die sample mean of 3.469 for seed 2026, and the expectation is \(\tfrac72\). The sample mean is an estimate computed from one run, and a different seed prints a different mean. The lab states the difference as a printed value, not as a theorem about samples.

5Problem set

Every problem has a full worked solution. Attempt each one before opening it. Problems marked E use the output of Lab 2.

Mechanics

M1 · The variance of an indicator

Let \(X\) take the value 1 with probability \(\tfrac{3}{10}\) and 0 otherwise. Find \(E[X]\), \(E[X^2]\) and \(\operatorname{Var}(X)\).

Solution

\(E[X] = 1 \cdot \tfrac{3}{10} + 0 \cdot \tfrac{7}{10} = \tfrac{3}{10}\). Since \(X^2 = X\) when \(X\) is 0 or 1, \(E[X^2] = E[X] = \tfrac{3}{10}\). By Proposition 2.2, \(\operatorname{Var}(X) = \tfrac{3}{10} - \tfrac{9}{100} = \tfrac{21}{100}\), which is \(\tfrac{3}{10} \cdot \tfrac{7}{10}\).

M2 · A loss in cents whose standard deviation is a whole number of cents

A loss \(L\) is 0 cents with probability \(\tfrac{9}{10}\) and 50000 cents with probability \(\tfrac{1}{10}\). Find \(E[L]\), \(\operatorname{Var}(L)\) and the standard deviation in cents.

Solution

\(E[L] = 50000 \cdot \tfrac{1}{10} = 5000\) cents. \(E[L^2] = 50000^2 \cdot \tfrac{1}{10} = 2.5 \times 10^{8}\), so by Proposition 2.2, \(\operatorname{Var}(L) = 2.5 \times 10^{8} - 5000^2 = 2.5 \times 10^{8} - 2.5 \times 10^{7} = 2.25 \times 10^{8}\) cents squared. Its square root is \(15000\) cents exactly, since \(15000^2 = 2.25 \times 10^{8}\).

M3 · Scaling and shifting

A random variable \(X\) has \(\operatorname{Var}(X) = 4\). Find \(\operatorname{Var}(3X - 2)\) and \(\operatorname{Var}(X + 10)\).

Solution

By Proposition 2.3 with \(a = 3\) and \(b = -2\), \(\operatorname{Var}(3X - 2) = 9 \cdot 4 = 36\). The shift by 10 does not change the variance, so \(\operatorname{Var}(X + 10) = 4\). The answers are 36 and 4.

Proof

P1 · Expectation of a sum of two variables

Let \(U\) and \(V\) be random variables on one finite probability space with positive weights. Prove that \(E[U + V] = E[U] + E[V]\), starting from Definition 1.1 and Proposition 1.2.

Solution

By Proposition 1.2 applied to \(W = U + V\), \(E[U + V] = \sum_\omega (U(\omega) + V(\omega)) p(\omega)\). Split the sum into two sums, which is allowed because each is a finite sum: \(\sum_\omega U(\omega) p(\omega) + \sum_\omega V(\omega) p(\omega)\). By Proposition 1.2 again, these are \(E[U]\) and \(E[V]\). This is the case \(\alpha = \beta = 1\), \(\gamma = 0\) of Proposition 1.3.

P2 · The mean minimizes squared error

Let \(\mu = E[X]\) and let \(c\) be any real number. Prove that \(E[(X - c)^2] = \operatorname{Var}(X) + (\mu - c)^2\), and deduce that \(E[(X - c)^2]\) is smallest when \(c = \mu\).

Solution

Write \(X - c = (X - \mu) + (\mu - c)\), so \((X - c)^2 = (X - \mu)^2 + 2(\mu - c)(X - \mu) + (\mu - c)^2\). Take expectations with Proposition 1.3, with \(\mu - c\) a constant. The middle term has expectation \(2(\mu - c) E[X - \mu] = 2(\mu - c)(\mu - \mu) = 0\). So \(E[(X - c)^2] = \operatorname{Var}(X) + (\mu - c)^2\). The second term is nonnegative and is zero exactly when \(c = \mu\), so the expression is smallest at \(c = \mu\).

P3 · A counterexample to additivity of variance

Show by a counterexample on a finite space that \(\operatorname{Var}(U + V) = \operatorname{Var}(U) + \operatorname{Var}(V)\) can fail, and compute both sides.

Solution

Let \(V = -U\) with \(U\) taking the values \(-1\) and 1 with probability \(\tfrac12\) each. Then \(E[U] = 0\), \(E[U^2] = 1\), so \(\operatorname{Var}(U) = 1\). Also \(V = -U\) takes the same two values with the same probabilities, so \(\operatorname{Var}(V) = 1\). But \(U + V = 0\) is constant, so \(\operatorname{Var}(U + V) = 0\) by Proposition 2.4. The two sides are 0 and 2, so the additivity identity fails. The example uses dependence, since \(V\) is a function of \(U\). Lesson 5 treats covariance, which gives the general formula for \(\operatorname{Var}(U + V)\).

Empirical

E1 · The die sample mean for seed 2026 (Lab 2)

Lab 2 prints "mean 3.469" and "sample mean minus 7/2: -0.031" for seed 2026. Say what the printed mean is an average of, and what it estimates. Do not infer a bound on its error.

Solution

The printed mean is the average of 10000 rolls generated by Python's random generator from seed 2026. It is a sample average, and it estimates \(E[X] = \tfrac72\). The printed difference is \(3.469 - 3.5 = -0.031\), which is the difference for this run only. A different seed gives a different average, and the lab does not compute how large such differences typically are, so no bound on the error is stated here.

E2 · Losses in one seeded run (Lab 2)

Lab 2 prints 489 losses in 10000 draws for seed 2027. Each draw is a loss with probability \(\tfrac{1}{20}\), so 500 losses is the expected count. Explain what the printed count does and does not show.

Solution

The expected count is \(10000 \cdot \tfrac{1}{20} = 500\). The printed count, 489, is the number of losses in one run with seed 2027. The run is 11 below the expected count, and the lab does not compute the spread of the count over repeated runs, so the printed count alone does not show whether 11 is unusual. The count is a single realization, and it shows what seed 2027 produced.

E3 · The scale check (Lab 2)

Lab 2 prints "Var(2X) = 35/3, which equals 4 Var(X): True" for the die. Verify the printed value from \(\operatorname{Var}(X) = \tfrac{35}{12}\), and state which proposition the printed True line checks.

Solution

By Proposition 2.3 with \(a = 2\), \(\operatorname{Var}(2X) = 4 \cdot \tfrac{35}{12} = \tfrac{140}{12} = \tfrac{35}{3}\). The printed value is \(\tfrac{35}{3}\), and the True line checks the equality of the two sides for this die, which is the scale rule of Proposition 2.3 with \(b = 0\).

Research

R1 · The sample variance as a variance of the empirical law

Lab 2 computes the sample variance with divisor \(n\). Show that this equals \(\operatorname{Var}(Y)\), where \(Y\) takes each value in a list \(z_1, \dots, z_n\) with probability \(\tfrac{1}{n}\) and repeated values are counted with their multiplicity.

Solution

Let \(\bar z = \tfrac1n \sum_i z_i\). The mean of \(Y\) is \(E[Y] = \tfrac1n \sum_i z_i = \bar z\) by Definition 1.1 with each entry weighted \(\tfrac1n\). By Definition 2.1, \(\operatorname{Var}(Y) = E[(Y - \bar z)^2] = \tfrac1n \sum_i (z_i - \bar z)^2\), which is the divisor-\(n\) sample variance. Repeated values contribute once for each entry, so the multiplicity is respected. The identity holds for any list, with no distinctness assumption.

R2 · Converting the loss to currency units

The loss \(L\) of Example 2.6 is in cents. Let \(D = L/100\) be the same loss in currency units. Find \(\operatorname{Var}(D)\) and \(\sigma_D\) from the exact variance, and explain why the variance and the standard deviation change by different factors.

Solution

By Proposition 2.3 with \(a = \tfrac{1}{100}\), \(\operatorname{Var}(D) = \tfrac{1}{10\,000} \cdot 2\,968\,750\,000 = 296\,875\). So \(\operatorname{Var}(D) = 296\,875\) currency units squared. The standard deviation is \(\sqrt{296\,875}\), which equals \(544.8624\) currency units when computed from \(\sqrt{2\,968\,750\,000} \approx 54486.24\) cents divided by 100. The variance changes by \(a^2 = 10^{-4}\), and the standard deviation by \(|a| = 10^{-2}\), because the variance is a squared quantity.

R3 · Which summary answers which question

For the table of L01 Example 3.6, state the expectation and the quantile at \(\tfrac12\), and say which summary answers "half the outcomes are at or below this value".

Solution

The expectation is \(\tfrac{3}{10}\), computed as the probability-weighted sum of the six values. The quantile at \(\tfrac12\) is \(Q(\tfrac12) = 0\), which is the least value whose distribution function reaches \(\tfrac12\). The statement "half the outcomes are at or below this value" describes the quantile, since \(F(0) = \tfrac35 \ge \tfrac12\) and \(F(-1) = \tfrac{3}{10} < \tfrac12\). The expectation answers a different question, namely the probability-weighted average.

  1. What is the expectation of a fair six-sided die, as a decimal?

    \(\tfrac16(1 + \dots + 6) = \tfrac{21}{6} = \tfrac72 = 3.5\) (Example 1.4).

  2. A variable has \(E[X] = 2\) and \(E[X^2] = 5\). What is \(\operatorname{Var}(X)\)?

    Proposition 2.2: \(\operatorname{Var}(X) = 5 - 2^2 = 1\).

  3. A variable has \(\operatorname{Var}(X) = 3\). What is \(\operatorname{Var}(2X)\)?

    Options

    Proposition 2.3: \(\operatorname{Var}(2X) = 2^2 \cdot 3 = 12\).

  4. Which expression is the variance of \(X\)?

    Options

    Definition 2.1. The other two expressions are the second moment and the squared mean.

  5. A loss is 0 cents with probability \(\tfrac{9}{10}\) and 50000 cents with probability \(\tfrac{1}{10}\). What is its expectation, in cents?

    \(50000 \cdot \tfrac{1}{10} = 5000\) cents (Problem M2).

  6. For the loss in the previous question, what is the variance, in cents squared?

    \(50000^2 \cdot \tfrac{1}{10} - 5000^2 = 2.5 \times 10^8 - 2.5 \times 10^7 = 2.25 \times 10^8\) (Problem M2).

  7. A variable \(X\) takes the values 0 and 1 with probability \(\tfrac{3}{10}\) on the value 1. What is \(\operatorname{Var}(X)\)?

    Options

    Problem M1: \(E[X^2] = E[X] = \tfrac{3}{10}\), so \(\operatorname{Var}(X) = \tfrac{3}{10} - \tfrac{9}{100} = \tfrac{21}{100}\).

  8. Which constant \(c\) minimizes \(E[(X - c)^2]\)?

    Options

    Problem P2: \(E[(X - c)^2] = \operatorname{Var}(X) + (EX - c)^2\), which is smallest at \(c = E[X]\).

  9. For the loss with variance 225000000 cents squared, what is the standard deviation, in cents?

    \(\sqrt{2.25 \times 10^8} = 15000\) cents, since \(15000^2 = 2.25 \times 10^8\) (Problem M2).

  10. If \(E[X] = 2\), what is \(E[3X - 1]\)?

    Proposition 1.3: \(E[3X - 1] = 3 \cdot 2 - 1 = 5\).
