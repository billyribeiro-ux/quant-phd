Tail-Risk Simulator

A risk team estimates the 99% loss of a portfolio from simulated returns, and it must know how the answer depends on the choice of distribution. You will write the module that simulates the losses under a Gaussian and under a Student-t return model matched to the same covariance (the matched factor is defined under Conventions below), computes the 99% loss, and prove the moment facts that make the Student-t comparison fair. Every input is SIMULATED: the positions and covariances are generated numbers, not market data.

Lab 1 · Worked example: one seeded run, step by step

Stated before running. Assuming Assumption 1 (Conventions item 6), the variance of the portfolio loss is \(w^{\top}\Sigma w = 8.4 \times 10^{9}\) cents squared, and the matched factor \((\nu-2)/\nu\), with \(\nu\) the Student-t degrees of freedom (defined under Conventions), is \(0.6\) for \(\nu = 5\). The 99% loss of 20000 losses is the 19800th smallest, because \(\lceil 0.99 \cdot 20000 \rceil = 19800\). Both sample variances should lie within 5 % of the target. The run prints the two 99% losses in cents, the sample variances as ratios to the target, and the factor by which an unmatched Student-t would inflate the variance.

"""Rung 1 worked example: the 99% loss of a two-asset portfolio, Gaussian and matched Student-t, for one seeded run.

Standard library only. Every input is SIMULATED: the positions and the covariance are illustrative numbers, not market
data. Losses are whole cents, rounded once with round(). The 99% loss is the loss of 1-based rank ceil(0.99 n) in
ascending order, computed in exact integers. The Student-t draws are scaled by sqrt((NU - 2) / W), the square root of
the matched factor (NU - 2) / NU times sqrt(NU / W), where W is the chi-square draw.
"""

import math
import random

POSITIONS = [3_000_000, 2_000_000]  # cents: $30,000.00 and $20,000.00, illustrative
COV = [[0.0004, 0.0001], [0.0001, 0.0009]]  # per-period return covariance: volatilities 2% and 3%, SIMULATED
N_DRAWS = 20_000
SEED = 20261028
NU = 5  # Student-t degrees of freedom


def cholesky_2x2(cov: list[list[float]]) -> list[list[float]]:
    """The lower-triangular L with L L^T = cov, for a 2 x 2 positive definite matrix."""
    l11 = math.sqrt(cov[0][0])
    l21 = cov[1][0] / l11
    l22 = math.sqrt(cov[1][1] - l21 * l21)
    return [[l11, 0.0], [l21, l22]]


def simulate(family: str) -> list[int]:
    """One loss per draw in whole cents, for the gaussian or the student_t family, from the same seed."""
    rng = random.Random(SEED)
    chol = cholesky_2x2(COV)
    losses: list[int] = []
    for _ in range(N_DRAWS):
        # Step 1. Two independent standard normals per draw.
        z1 = rng.gauss(0.0, 1.0)
        z2 = rng.gauss(0.0, 1.0)
        scale = 1.0
        if family == "student_t":
            # Step 2. A chi-square with NU degrees of freedom is a gamma with shape NU / 2 and scale 2. The t draw
            # divides the normal by sqrt(W / NU), so its returns carry the factor sqrt(NU / W), times the square
            # root of the matched factor, sqrt((NU - 2) / NU), which equals sqrt((NU - 2) / W).
            chi_square = rng.gammavariate(NU / 2, 2.0)
            scale = math.sqrt((NU - 2) / chi_square)
        # Step 3. Correlate the normals with the factor L, then scale them to the returns.
        r1 = scale * chol[0][0] * z1
        r2 = scale * (chol[1][0] * z1 + chol[1][1] * z2)
        # Step 4. The loss is minus the position-weighted return, in cents, rounded once.
        losses.append(round(-(POSITIONS[0] * r1 + POSITIONS[1] * r2)))
    return losses


def quantile_99(losses: list[int]) -> int:
    """The ceil(0.99 n)-th smallest loss (1-based rank), computed in exact integers."""
    index = (99 * len(losses) + 99) // 100
    return sorted(losses)[index - 1]


def sample_variance(xs: list[int]) -> float:
    """The unbiased sample variance."""
    mean = sum(xs) / len(xs)
    return sum((x - mean) ** 2 for x in xs) / (len(xs) - 1)


def main() -> None:
    # Step 5. The target: the variance of the portfolio loss is w' Sigma w, in cents squared.
    target = sum(POSITIONS[i] * POSITIONS[j] * COV[i][j] for i in range(2) for j in range(2))
    print("portfolio variance w'Sigma w (cents^2):", f"{target:.1f}")
    print("matched factor (NU - 2) / NU:", f"{(NU - 2) / NU:.6f}")
    print("index of the 99% loss, ceil(0.99 n) with n =", N_DRAWS, ":", (99 * N_DRAWS + 99) // 100)
    gaussian = simulate("gaussian")
    print("gaussian 99% loss (cents):", quantile_99(gaussian))
    print("gaussian sample variance / w'Sigma w:", f"{sample_variance(gaussian) / target:.4f}")
    student = simulate("student_t")
    print("student_t 99% loss (cents):", quantile_99(student))
    print("student_t sample variance / w'Sigma w:", f"{sample_variance(student) / target:.4f}")
    print("unmatched t would inflate the variance by NU / (NU - 2):", f"{NU / (NU - 2):.4f}")


main()

The printed target, 8400000000.0, is the variance of the loss in cents squared. Both sample variances are within 5 % of it, as the hypothesis said. The two 99% losses differ: the matched Student-t gives 243004 cents against 210946 cents for the Gaussian, a ratio of 1.152 (Student-t over Gaussian) in this one seeded run. Rung 3 · Specification

Context
A risk team reports a 99% loss for a portfolio each day. Its model draws losses from a distribution and reads the 99% loss from the sorted draws. Two return models are in use: a Gaussian model and a Student-t model with the same covariance matrix. The team needs to know how much the 99% loss depends on the choice, and it needs every run to be reproducible from its seed. You write the module that does this, prove the moment facts that make the matched Student-t comparable with the Gaussian, and test the module against the properties this page states.
Inputs
No data file. The autograder's instance comes from grader/instance.py, seeded by your workspace ID. It holds 2 or 3 positions in whole cents (every position is long in every instance; a short position is valid input, see the conditions), a covariance matrix, a Student-t degrees of freedom \(\nu\) from 3 to 8, and a number of draws. Every value is SIMULATED, and none of it is a real position or a market return. The report uses the illustrative portfolio of Lab 1 and Lab 3.
Required outputs
In a repository of your own: tail_risk.py at its root, and a report/ folder beside it. The module has these three functions, with these signatures: matched_scale(nu: int) -> float, simulate_losses(position_cents: list[int], cov: list[list[float]], n_draws: int, seed: int, family: str, nu: int | None) -> list[int] and quantile_99(losses_cents: list[int]) -> int. Start from the starter file, whose signatures are complete. For the report, commit three more files: report/run_report.py, which calls your module with the seed the report states and prints the sampled numbers the report quotes; report/report.md, the report described in the brief, with its proof appendix; and report/self_assessment.md, the summary that the form in the self-assessment section produces.
Constraints
Standard library only. Each function validates its inputs and raises ValueError for the conditions listed in the conditions subsection. No function prints or warns. The conventions in the conventions subsection are binding, except the items the suite does not grade (the suite is defined under Grading mode below): the Student-t variance at \(\nu\) of 3 and 4 (item 1), the sign of the Student-t loss (item 2), the round() call of item 2 and the integer formula of item 4, of which the suite checks only the values they produce, and the source and the order of the Student-t family's draws (item 5; the Gaussian order is graded). See what the suite does not test.
Grading mode
Both modes apply. The code is autograded by grader/test_project.py (the suite on this page), which runs 156 checks with warnings as errors (the Student-t variance check is skipped at \(\nu\) of 3 or 4, so on such an instance the run shows 155 passed and one skipped): the matched scale, the loss variance against the instance's covariance (the Student-t family for \(\nu\) of 5 or more), the Student-t cross term at \(\nu\) of 5 (defined under what the suite does not test), the covariance of two asset returns (see what the suite does not test), the mean absolute Student-t loss at \(\nu\) of 3 to 8, the share of pairs of Student-t draws one, two and three apart with both absolute losses above the median, which pairwise independence (every two of the draws independent of each other) makes 1/4 (see what the suite does not test), the frozen Gaussian stream (Conventions item 5, below) with the sign of the loss, the short positions, the family and degrees-of-freedom rules, the draw count, the positions, the covariance, the quantile convention and its types, and the rounding of each portfolio loss to a whole cent, once and not per position, and the absence of printed output. The same file runs in your browser and on your machine. It is not secret: its integrity comes from your seeded instance. The proof appendix is graded by rubric, against the five criteria of the report rubric, each with four observable levels. You score the report yourself with the form in the self-assessment section, and calibrate that scoring on two annotated exemplars.

Conventions

  1. The model. Let \(Z\) be a standard normal vector with the identity covariance, and let \(L\) be a lower-triangular matrix with \(LL^{\top} = \Sigma\), the covariance of the returns. A symmetric \(\Sigma\) is positive definite when \(w^{\top}\Sigma w > 0\) for every nonzero \(w\). The Gaussian return is \(R = LZ\). The Student-t return is \(R = \sqrt{(\nu-2)/W}\; LZ\), where \(W\) is a chi-square variable with \(\nu\) degrees of freedom (the sum of \(\nu\) squared independent standard normals, Lesson 6, Definition 2.1), with the density of Assumption 1 (item 6 below), and \(W\) is independent of \(Z\). The factor \(\sqrt{(\nu-2)/W}\) is \(\sqrt{s}\sqrt{\nu/W}\) with the matched factor, or matched scale, \(s = (\nu-2)/\nu\). Lesson 6 gives the Student-t as \(Z/\sqrt{W/\nu}\), and this return is that variable times \(\sqrt{s}\).
  2. The loss is \(\ell = -\sum_i w_i R_i\), in cents, where \(w_i\) is the position of asset \(i\) in cents. The loss is positive when the portfolio falls. A negative \(w_i\) is a short position, and the same formula applies to it. Each draw gives one loss, and simulate_losses returns the list of losses rounded once to the nearest integer with round(). This rounding is the cent rule.
  3. matched_scale(nu) is \((\nu-2)/\nu\). It is defined for \(\nu > 2\) only.
  4. quantile_99(losses) is the \(\lceil 0.99\,n \rceil\)-th smallest of the \(n\) losses, the order statistic of 1-based index \(\lceil 0.99\,n \rceil\), computed in exact integer arithmetic as \((99n+99)//100\). Appendix A4 shows that this is the 99% point of the empirical distribution of the losses, \(\inf\{x : F_n(x) \ge 0.99\}\), where \(F_n(x)\) is the share of the \(n\) losses at most \(x\), with the quantile function of Lesson 1.
  5. Stream order. The Gaussian family takes, for each draw in turn, the \(m\) standard normals of \(Z\), one per position, where \(m\) is the number of positions, in position order, from random.Random(seed).gauss(0.0, 1.0), and takes no degrees of freedom. The Student-t family takes \(Z\) for each draw and one chi-square variable per draw, independent of the chi-square variables of the other draws. Two draws that use one chi-square variable form a sharing. The source of the Student-t family's normals and the order of its draws are not fixed here. The suite fixes the Gaussian order. For the Student-t family at \(\nu = 3\) only, it checks, at lags one to three (a pair at lag \(d\) is draws \(i\) and \(i + d\)), the share of pairs with both absolute losses above the median, which pairwise independence makes 1/4. A sharing of one pair of draws at a lag of four or more is not read by that check. A chain of sharings at lag four, in which draws 4j and 4j + 4 reuse one variable for every j \(\ge 0\), so that all draws at multiples of 4 share one variable, fails it on 38 of the 50 seeds tested. See what the suite does not test.
  6. Assumption 1 (used by Appendix A1 to A3; not proved on this page). (a) For \(x > 0\), the Gamma function \(\Gamma(x) = \int_0^{\infty} t^{x-1}e^{-t}\,dt\), and \(\Gamma(x) = (x-1)\Gamma(x-1)\) for \(x > 1\). (b) For a positive integer \(\nu\), a chi-square variable \(W\) with \(\nu\) degrees of freedom has the density \(u^{\nu/2-1}e^{-u/2}/(2^{\nu/2}\Gamma(\nu/2))\) for \(u > 0\).

Conditions the functions must check

These are the conditions that raise ValueError, and the suite checks each one. A valid input outside them must return a value of the stated type.

  • matched_scale raises when \(\nu \le 2\), and when \(\nu\) is not an int, including a float, a boolean and a string. It accepts \(\nu = 3\).
  • simulate_losses raises when family is neither "gaussian" nor "student_t"; when family is "gaussian" and nu is not None; when family is "student_t" and nu is None; when nu is 2 or less, through matched_scale; when n_draws is 0 or less, or is not an int, including a float and a boolean; when position_cents is empty or holds a value that is not an int, including a float and a boolean; and when cov is not a square matrix with one row and one column per position, is not symmetric, or is not positive definite. It accepts n_draws = 1, nu = None for the Gaussian family, \(\nu = 3\), a one-position portfolio with a positive variance, and a negative position. A negative position is a short position and is valid: the loss is linear in the positions, so a short position of a given size enters the loss with the opposite sign to a long one of that size. For a two-position example at 300 draws in both families, the suite checks that negating every position negates every loss.
  • quantile_99 raises when the list is empty, and when an element is not an int, including a float and a boolean. It accepts a list of one loss, which is that loss.

What the suite does not test

The suite does not check the Student-t variance for \(\nu\) of 3 or 4. The fourth moment is infinite at \(\nu = 3\) and at \(\nu = 4\) (Appendix A3), so a sample variance there can miss its target by a wide margin, and the test is skipped for those values. At those values the suite checks the matched factor through the mean absolute loss, which needs no fourth moment. The suite does not test the sign of the Student-t losses. The sign of the Gaussian losses is checked against the frozen stream of item 5, within half a cent. The reason for the difference is that a sign error alone leaves the law of the losses unchanged, because both returns have symmetric laws (\(-R\) has the same law as \(R\)). A check on the law cannot see it. A check on the draws would need a fixed order of the Student-t draws, and item 5 leaves that order open. Your sign follows the convention above, and you should check it by hand: a long position that gains produces a negative loss. The suite checks the cross term, the covariance of two asset returns, which is the dependence that a shared chi-square variable creates across the assets of a draw, and it does so only at \(\nu = 5\): two assets with correlation 0.8, 100,000 draws, and a relative tolerance of 0.05. Over seeds 0 to 49, a cross-term error of +3 % fails the check on none of the 50 seeds, a cross-term error of −3 % on one (seed 38), a cross-term error of +5 % on 19 of them, and a cross-term error of −5 % on 30 of them. At \(\nu = 3\) only, the suite checks over 40,000 draws that, for pairs of draws one, two and three apart, the share with both absolute losses above the median is within five standard errors of 1/4, the value that pairwise independence gives. That is one necessary consequence of independence, not a test of it, so a dependence that leaves these shares at 1/4 is not detected. A family that shares one chi-square variable between draws \(2k\) and \(2k + 1\) fails this check on all 50 seeds tested (seeds 0 to 49). A family that shares one between draws \(4j\) and \(4j + 2\) fails it on all 50 seeds tested. A family that shares one between draws \(6j\) and \(6j + 3\) fails it on 39 of the 50 seeds tested (seeds 0 to 49). A family that shares one variable across all the even-indexed draws fails it on 44 of the 50 seeds tested (seeds 0 to 49). A sharing of one pair of draws at a lag of four or more is not read by this check: disjoint pairs of that kind pass on all 50 seeds tested (seeds 0 to 49). The chain of sharings at lag four defined under Conventions item 5, in which all draws at multiples of 4 share one variable, fails this check on 38 of the 50 seeds tested.

Lab 3 · The report's closed-form numbers

Stated before running. The loss variance is \(w^{\top}\Sigma w = 8.4 \times 10^{9}\) cents squared, so its standard deviation is about 91651.5 cents. The standard normal 99% point is \(z = 2.3263\) to four decimals, and the parametric Gaussian 99% loss is \(z\) times that standard deviation, a whole number of cents. The matched factor for each \(\nu\) and the variance inflation an unmatched draw would carry are printed for \(\nu\) of 3, 4, 5 and 8. The index rows show that the ceiling and the floor of \(0.99\,n\) differ at \(n = 101\), which is why the convention matters. The lab uses no random draws.

"""Rung 3 reference numbers: the closed-form values the report quotes, with no random draws.

Standard library only. The inputs are the illustrative two-asset portfolio of Lab 1, a SIMULATED example and not market
data. Every number here is a formula evaluated on unrounded values. The one value rounded in the code is the parametric
99% loss, rounded once to whole cents with round(); every other number is rounded for display only. The sampled
numbers of your own module depend on its random stream, so the report quotes these closed forms, and its sampled
numbers with the seed it used.
"""

import math
import statistics
from fractions import Fraction

POSITIONS = [3_000_000, 2_000_000]  # cents, illustrative
COV = [[0.0004, 0.0001], [0.0001, 0.0009]]  # per-period covariance, SIMULATED


def main() -> None:
    target = sum(POSITIONS[i] * POSITIONS[j] * COV[i][j] for i in range(2) for j in range(2))
    sd = math.sqrt(target)
    z99 = statistics.NormalDist().inv_cdf(0.99)
    print("portfolio variance w'Sigma w (cents^2):", f"{target:.1f}")
    print("standard deviation of the loss (cents):", f"{sd:.3f}")
    print("standard normal 99% point z:", f"{z99:.6f}")
    print("parametric Gaussian 99% loss (cents, rounded once):", round(z99 * sd))
    for nu in (3, 4, 5, 8):
        print(f"nu = {nu}: matched factor {(nu - 2) / nu:.6f}, unmatched variance inflation {nu / (nu - 2):.6f}")
    for n in (100, 101, 19_987):
        exact = Fraction(99, 100) * n
        print(f"n = {n}: 0.99 n = {float(exact):.2f}, ceil index {math.ceil(exact)}, floor index {math.floor(exact)}")

Appendix A · Proofs. Four results, each stated with its assumptions and proved in your own words: A1, assuming Assumption 1, the Gamma integrals \(\E[W^{-1}] = 1/(\nu-2)\) for \(\nu > 2\), and the divergence at \(\nu \le 2\); A2, assuming Assumption 1 and \(\nu > 2\), with \(W\) independent of \(Z\), the covariance of the matched Student-t return, \(\E[RR^{\top}] = \Sigma\); A3, assuming Assumption 1 and that the chi-square variable \(W\) is independent of the standard normal \(Z\), the variance \(\nu/(\nu-2)\) of a Student-t variable for \(\nu > 2\), its infinity at \(\nu \le 2\), and the infinite fourth moment for \(\nu \le 4\), so at \(\nu = 3\) and \(\nu = 4\); A4 the 99% loss as the order statistic with index \(\lceil 0.99\,n \rceil\). A proof may use an earlier result of the appendix.

Length. The body (the five sections) runs 300 to 700 words. The appendix has no limit. A word is a run of characters between spaces.

Numbers. Every number the report quotes is printed by report/run_report.py or by Lab 3, with its unit (cents, cents squared, or a factor). A factor is quoted to no more than four significant digits. A cent amount is quoted as the integer the run prints.

Scoring. Each criterion scores the highest level whose every element the report shows. Each level contains the one below it: level 4 is level 3 plus the elements its cell names; level 2 is any attempt that misses an element of level 3 or makes an error its cell names; level 1 is the absence its cell names. The report meets the bar at level 3 or above on every criterion.

Summary

The portfolio has positions of 3000000 and 2000000 cents and a loss variance of 8400000000.0 cents squared. Its Gaussian 99% loss is 213213 cents, the parametric value that Lab 3 prints. One seeded run of the matched Student-t model, with seed 20261028 as in Lab 1, gives a 99% loss of 243004 cents.   • Meets C5 level 3: a Summary of 80 words or fewer.
Setup and conventions

The loss is minus the position-weighted return, in whole cents, with each position \(w_i\) in cents. The Gaussian return is \(R = LZ\), where \(Z\) is a standard normal vector and \(L\) is lower-triangular with \(LL^{\top} = \Sigma\). The Student-t return is \(R = \sqrt{(\nu-2)/W}\,LZ\), where \(W\) is chi-square with \(\nu\) degrees of freedom and independent of \(Z\). simulate_losses computes the losses and rounds each one once with round(). matched_scale(nu) returns \((\nu-2)/\nu\). quantile_99 returns the 99% loss as the order statistic with index \(\lceil 0.99\,n\rceil\), computed as \((99n+99)//100\).

  • Meets C5 level 3: the second section is under its brief heading and names the function that computes each number.
Moments and the matched scale (A1 to A3)

Assume \(\nu > 2\) and Assumption 1, and let \(W\) have the chi-square density \(u^{\nu/2-1}e^{-u/2}/(2^{\nu/2}\Gamma(\nu/2))\) for \(u > 0\). Then \(\E[W^{-1}] = \Gamma(\nu/2-1)/(2\Gamma(\nu/2)) = 1/(\nu-2)\), and \(\E[W^{-2}] = 1/((\nu-2)(\nu-4))\) for \(\nu > 4\). For \(\nu \le 2\) the integrand of \(\E[W^{-1}]\) behaves like \(u^{\nu/2-2}\), which is not integrable at 0, so \(\E[W^{-1}]\) is infinite. The variance of the Student-t is \(\nu\,\E[W^{-1}]\), so it equals \(\nu/(\nu-2)\) for \(\nu > 2\) and is infinite for \(\nu \le 2\). For \(\nu \le 4\) the integrand of \(\E[W^{-2}]\) behaves like \(u^{\nu/2-3}\), which is not integrable at 0, so the fourth moment is infinite at \(\nu = 3\). With \(Z\) and \(W\) independent, \(\E[RR^{\top}] = \E[(\nu-2)/W]\,L\,\E[ZZ^{\top}]\,L^{\top} = (\nu-2)\cdot\frac{1}{\nu-2}\,LL^{\top} = \Sigma\). Lab 1 prints 1.0447 for the matched Student-t sample variance divided by \(w^{\top}\Sigma w\), so the run's ratio of 1.0447 differs from the identity's value of 1 by about 4.5 % of 1. It prints the unmatched inflation at \(\nu = 5\) as 1.6667, which is \(5/3\) (about 1.667 to four significant digits).

  • Meets C1 level 4: states \(\nu > 2\) as the hypothesis, derives both Gamma integrals, shows the divergence at \(\nu \le 2\) and for \(\E[W^{-2}]\) at \(\nu \le 4\), and gives the infinite fourth moment at \(\nu = 3\).
  • Meets C2 level 4: states the independence of \(Z\) and \(W\) as a hypothesis, reaches \(\Sigma\), and checks the identity against the run's variance ratio, 1.0447, stating the difference as about 4.5 % of 1.
The 99% loss (A4)

Let \(F_n(x)\) be the share of the \(n\) losses at most \(x\). Lesson 1 defines the quantile as \(Q(p) = \inf\{x : F(x) \ge p\}\) with the left-endpoint convention, so the 99% loss is \(\inf\{x : F_n(x) \ge 0.99\}\). Since the count is whole, \(F_n(x) \ge 0.99\) holds exactly when at least \(\lceil 0.99\,n\rceil\) losses are at most \(x\). The 99% loss is therefore the \(\lceil 0.99\,n\rceil\)-th smallest loss. Lab 3 prints index 100 for \(n = 101\), where the floor would give 99. Ties do not change this: tied losses fill consecutive sorted positions with one value, so position \(\lceil 0.99\,n\rceil\) holds the same value whichever tied loss is counted there. The types are these. 213213 is an integer of cents from a formula, the parametric value of Lab 3, and not a sample. 210946 and 243004 are integers of cents, each from one sample with seed 20261028 (Lab 1). 8400000000.0 is a float in cents squared. 1.0447 is a float ratio from the same seed. The sampled Gaussian loss is 2267 cents below the parametric value. The matched Student-t loss is 32058 cents, or 15.2 %, above the sampled Gaussian loss. One run does not show how large the sampling error is, and the ratio 1.152 comes from this seed.

  • Meets C3 level 4: derives the index from the distribution function, states the tie rule, and checks the index rows of Lab 3.
  • Meets C4 level 4: states each number's type (integer of cents, float, or seeded sample) and what each difference means for the comparison: 2267 cents, 32058 cents, and 15.2 %.
Limitations

Three limits apply. First, the suite checks the Student-t variance for \(\nu\) of 5 or more. At \(\nu = 3\) and \(\nu = 4\) the fourth moment is infinite, so a sample variance there can miss its target by a wide margin, which is why the check is skipped at those values and one run at \(\nu = 3\) is not evidence. Second, the relative variance tolerance is 0.30 of the target, so the check cannot be relied on to separate a modest unmatched inflation from the correct value. Third, the loss has the same law as minus the loss, because \(R\) has a symmetric law, so a sign error leaves the distribution of the losses unchanged. The sign is checked by hand: a long position that gains must give a negative loss. The model has no fees and holds the covariance fixed.

  • Meets C5 level 3: names three limitations, one of them the variance check at \(\nu = 3\).
  • Misses C5 level 4: does not state the smallest inflation the variance check cannot detect.
