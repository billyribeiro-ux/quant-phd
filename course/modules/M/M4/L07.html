Moment-generating and characteristic functions

  • Uses: random variable, expectation, independence, normal distribution, exponential function, definite integral
  • Introduces: moment-generating function, characteristic function
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study
  • Dlore
  • Xrefuted

Two functions summarize a distribution: the moment-generating function \(M_X(t) = E[e^{tX}]\), which may not exist for every t, and the characteristic function \(\varphi_X(t) = E[e^{itX}]\), which always exists. This lesson gives the domain of each, derives the normal moment-generating function by completing the square, and shows that the characteristic function of any variable has modulus at most one. It also shows that the moment-generating function of a sum of independent variables is the product of the two functions. Lab 1 checks the normal formula by numerical integration and a two-point characteristic function by a seeded sample.

1The moment-generating function

Definition 1.1 (moment-generating function and its domain)

For a real random variable X and a real t, let \(M_X(t) = E[e^{tX}]\) whenever this expectation is finite. The moment-generating function is \(M_X\), and its domain is the set of real t at which \(E[e^{tX}] < \infty\). The domain always contains \(t = 0\), where \(M_X(0) = E[1] = 1\).

Proposition 1.2 (finitely many values)

If X takes finitely many values, then the domain of \(M_X\) is the whole real line.

Proof

For each value x, \(e^{tx}\) is a finite real number for every real t. So \(E[e^{tX}] = \sum_x e^{tx}P(X = x)\) is a finite sum of finite numbers for every t.

Proposition 1.3 (the normal moment-generating function)

If \(X \sim N(\mu, \sigma^{2})\) with \(\sigma > 0\), then the domain of \(M_X\) is the whole real line, and \(M_X(t) = \exp(\mu t + \sigma^{2}t^{2}/2)\) for every real t.

Proof

By Proposition 1.4 of L06, \(X = \mu + \sigma Z\) with Z standard normal. So \(E[e^{tX}] = e^{\mu t}E[e^{s Z}]\) with \(s = \sigma t\). For real s, the integrand \(e^{sz - z^{2}/2}\) is at most \(e^{s^{2} - z^{2}/4}\), because \(sz \le z^{2}/4 + s^{2}\). That bound is integrable, so the integral converges absolutely and \[ E[e^{sZ}] = (2\pi)^{-1/2}\int e^{sz - z^{2}/2}\,dz. \] Complete the square: \[ sz - \frac{z^{2}}{2} = -\frac{(z - s)^{2}}{2} + \frac{s^{2}}{2}. \] So the integral is \(e^{s^{2}/2}\int e^{-(z-s)^{2}/2}\,dz\). Substituting \(u = z - s\) leaves the integral over the whole line unchanged, and by Proposition 1.2 of L06 it equals \(\sqrt{2\pi}\). Hence \(E[e^{sZ}] = e^{s^{2}/2}\), and \[ M_X(t) = e^{\mu t}\,e^{\sigma^{2}t^{2}/2} = \exp\big(\mu t + \sigma^{2}t^{2}/2\big). \]

Proposition 1.4 (the square of a standard normal has no moment-generating function for large t)

Let Z be standard normal and \(W = Z^{2}\). Then \(E[e^{tW}] = (1 - 2t)^{-1/2}\) for \(t < 1/2\), and \(E[e^{tW}] = \infty\) for \(t \ge 1/2\). So the domain of \(M_W\) is \((-\infty, 1/2)\).

Proof

The expectation is \[\begin{aligned} E[e^{tZ^{2}}] &= (2\pi)^{-1/2}\int e^{tz^{2}} e^{-z^{2}/2}\,dz \\ &= (2\pi)^{-1/2}\int e^{-(1 - 2t)z^{2}/2}\,dz \end{aligned}\]. For \(t \ge 1/2\), the exponent \(-(1 - 2t)z^{2}/2\) is nonnegative, so the integrand is at least \(1/\sqrt{2\pi}\) at every z, and the integral over the line is infinite. For \(t < 1/2\), substitute \(u = \sqrt{1 - 2t}\,z\), exactly as in Lemma 2.3 of L06, to get \((1 - 2t)^{-1/2}\).

Remark 1.5 (what the domain means)

A moment-generating function is defined on its domain only. Proposition 1.2 covers finitely many values, and Proposition 1.3 covers the normal. Proposition 1.4 gives a variable whose domain is bounded above by \(1/2\). This page does not compute the domain of the Student-t moment-generating function, and no result below depends on it.

2The characteristic function

Definition 2.1 (complex exponential)

For a real a, the complex exponential is \(e^{ia} = \cos a + i\sin a\), where \(i^{2} = -1\). Its modulus is \(|e^{ia}| = \sqrt{\cos^{2}a + \sin^{2}a} = 1\). The expectation of a complex-valued variable is the expectation of its real part plus \(i\) times the expectation of its imaginary part.

Definition 2.2 (characteristic function)

For a real random variable X and a real t, the characteristic function is \(\varphi_X(t) = E[e^{itX}]\).

Proposition 2.3 (the characteristic function always exists)

For every real random variable X with finitely many values, or with a density, and every real t, \(\varphi_X(t)\) is defined. Moreover \(|\varphi_X(t)| \le 1\) and \(\varphi_X(0) = 1\).

Proof

The variable \(e^{itX}\) has modulus 1 for every outcome (Definition 2.1), so its real and imaginary parts are bounded by 1 and integrable. Its expectation is therefore finite. The triangle inequality for finite sums (or for integrals, in the density case) gives \(|E[Y]| \le E[|Y|]\) for a complex variable Y. With \(Y = e^{itX}\), \(|\varphi_X(t)| \le E[1] = 1\). At \(t = 0\), \(e^{0} = 1\), so \(\varphi_X(0) = 1\).

Proposition 2.4 (affine maps)

For real a and b, \(\varphi_{aX + b}(t) = e^{itb}\,\varphi_X(at)\) for every real t.

Proof

Since \(e^{it(aX + b)} = e^{itb}e^{i(at)X}\) and \(e^{itb}\) is a constant, linearity of expectation gives \(E[e^{it(aX+b)}] = e^{itb}E[e^{i(at)X}] = e^{itb}\varphi_X(at)\).

Proposition 2.5 (a two-point law)

Let X take the value a with probability p and the value b with probability \(1 - p\), where \(0 < p < 1\). Then for every real t, \[ \varphi_X(t) = p\,e^{ita} + (1 - p)\,e^{itb}, \] and \(|\varphi_X(t)|^{2} = p^{2} + (1 - p)^{2} + 2p(1 - p)\cos\big(t(a - b)\big)\).

Proof

The first formula is the definition of the expectation over two values. For the modulus, write \(\alpha = p\), \(\beta = 1 - p\), \(\theta_1 = ta\) and \(\theta_2 = tb\). Then \[\begin{aligned} |\alpha e^{i\theta_1} + \beta e^{i\theta_2}|^{2} &= (\alpha\cos\theta_1 + \beta\cos\theta_2)^{2} \\ &\quad + (\alpha\sin\theta_1 + \beta\sin\theta_2)^{2} \end{aligned}\]. Expanding and using \(\cos^{2} + \sin^{2} = 1\) for each angle, the cross terms give \[\begin{aligned} &= \alpha^{2} + \beta^{2} \\ &\quad + 2\alpha\beta(\cos\theta_1\cos\theta_2 + \sin\theta_1\sin\theta_2) \\ &= \alpha^{2} + \beta^{2} + 2\alpha\beta\cos(\theta_1 - \theta_2) \end{aligned}\], by the cosine of a difference. So the modulus squared is \(\alpha^{2} + \beta^{2} + 2\alpha\beta\cos(t(a - b))\).

Lab 1 · The normal MGF and a two-point characteristic function

The inputs are illustrative, not data, and Part C is a SIMULATED sample from a seeded generator. Stated before running. Part A takes \(X \sim N(0.5, 1.5^{2})\) and predicts that Simpson's rule for \(E[e^{tX}]\) agrees with the closed form of Proposition 1.3 to within \(10^{-9}\) in each row, at \(t\) in \(\{-1, 0, 0.5, 1, 2\}\). Part B takes the two-point law with values 0 and 2 and \(P = 0.25\) at 0, and predicts the characteristic function of Proposition 2.5 at \(t\) in \(\{0, 1, \pi\}\). It predicts modulus 1 at \(t = 0\) and \(t = \pi\), since \(\cos(-2\pi) = 1\) and \(\cos(0) = 1\). Part C predicts that the sample means of \(\cos(X)\) and \(\sin(X)\) from 100000 seeded draws are close to the real and imaginary parts of \(\varphi(1)\).

"""M4 L07 lab 1: the normal MGF by numerical integration against its closed form, and a two-point characteristic
function.

Inputs are illustrative, not data. Part A uses X ~ N(mu, sigma^2) with mu = 0.5 and sigma = 1.5. Part B and Part C use
a two-point law that takes the value A = 0 with probability P_A = 0.25 and the value B = 2 otherwise. Part C draws
100000 observations of that law from random.Random(20260701), and each observation uses one uniform draw.

Part A: M(t) = E[exp(tX)] at t in {-1, 0, 0.5, 1, 2}. Each value is a Simpson's rule sum of exp(t x) times the normal
density over [mu - 12 sigma, mu + 12 sigma] with 20000 intervals. The closed form is exp(mu t + sigma^2 t^2 / 2). The
line prints both values and their absolute difference.
Part B: phi(t) = P_A exp(i t A) + (1 - P_A) exp(i t B) at t in {0, 1, pi}, printed as real and imaginary parts, with
the modulus |phi(t)|.
Part C: the sample mean of cos(tX) and of sin(tX) at t = 1 over the 100000 draws, beside the real and imaginary
parts of phi(1) from Part B.
"""

from __future__ import annotations

import cmath
import math
import random

MU = 0.5
SIGMA = 1.5
P_A = 0.25
VALUE_A = 0.0
VALUE_B = 2.0
SEED = 20260701
N_DRAWS = 100000
INTERVALS = 20000


def normal_density(x: float, mu: float, sigma: float) -> float:
    """The normal density exp(-(x - mu)^2 / (2 sigma^2)) / (sigma sqrt(2 pi)) at x, for sigma > 0."""
    return math.exp(-((x - mu) ** 2) / (2.0 * sigma * sigma)) / (sigma * math.sqrt(2.0 * math.pi))


def mgf_numerical(t: float, mu: float, sigma: float) -> float:
    """E[exp(tX)] for X ~ N(mu, sigma^2), by Simpson's rule over mu +/- 12 sigma with INTERVALS (even) intervals."""
    lo = mu - 12.0 * sigma
    hi = mu + 12.0 * sigma
    h = (hi - lo) / INTERVALS
    total = 0.0
    for k in range(INTERVALS + 1):
        x = lo + k * h
        weight = 1.0 if k in (0, INTERVALS) else (4.0 if k % 2 == 1 else 2.0)
        total += weight * math.exp(t * x) * normal_density(x, mu, sigma)
    return total * h / 3.0


def mgf_closed(t: float, mu: float, sigma: float) -> float:
    """The closed form exp(mu t + sigma^2 t^2 / 2) of the normal MGF."""
    return math.exp(mu * t + sigma * sigma * t * t / 2.0)


def phi_two_point(t: float) -> complex:
    """The characteristic function P_A exp(i t A) + (1 - P_A) exp(i t B) of the two-point law."""
    return P_A * cmath.exp(1j * t * VALUE_A) + (1.0 - P_A) * cmath.exp(1j * t * VALUE_B)


def main() -> None:
    """Print Parts A, B and C. The seed is fixed, so every run prints the same lines."""
    print("Part A: normal MGF, Simpson's rule against the closed form")
    for t in (-1.0, 0.0, 0.5, 1.0, 2.0):
        numerical = mgf_numerical(t, MU, SIGMA)
        closed = mgf_closed(t, MU, SIGMA)
        print(
            f"t {t:.1f} numerical {numerical:.8f} closed {closed:.8f} absolute_difference {abs(numerical - closed):.2e}"
        )

    print("Part B: characteristic function of the two-point law")
    for t in (0.0, 1.0, math.pi):
        phi = phi_two_point(t)
        print(f"t {t:.6f} real {phi.real:.8f} imag {phi.imag:.8f} modulus {abs(phi):.8f}")

    print("Part C: seeded sample means of cos(tX) and sin(tX) at t = 1, against phi(1)")
    rng = random.Random(SEED)
    cos_sum = 0.0
    sin_sum = 0.0
    for _ in range(N_DRAWS):
        x = VALUE_A if rng.random() < P_A else VALUE_B
        cos_sum += math.cos(x)
        sin_sum += math.sin(x)
    phi1 = phi_two_point(1.0)
    print(f"sample_mean_cos {cos_sum / N_DRAWS:.6f} real_part_phi {phi1.real:.6f}")
    print(f"sample_mean_sin {sin_sum / N_DRAWS:.6f} imag_part_phi {phi1.imag:.6f}")

Part A matches the prediction in every row. The largest absolute difference is \(7.11 \times 10^{-13}\), at \(t = 2\), where the value is 244.69193226. Part B prints \(\varphi(0) = 1\) with modulus 1. At \(t = 1\) it prints real part \(-0.06211013\), imaginary part 0.68197307 and modulus 0.68479554. The modulus agrees with Proposition 2.5, since \(0.625 + 0.375\cos(-2) = 0.4689449\) and its square root is 0.6847955. At \(t = \pi\) it prints modulus 1, because \(e^{2\pi i} = 1\). Part C prints a sample mean of \(\cos X\) of \(-0.062124\) against the real part \(-0.062110\), and a sample mean of \(\sin X\) of 0.681982 against 0.681973. These are one seed, so they show agreement at this sample size and do not show a rate. The lab checks two laws. It does not show that the characteristic function determines a law.

3Where the canon breaks

  • The moment-generating function may not exist. Proposition 1.4 gives \(E[e^{tZ^{2}}] = \infty\) for \(t \ge 1/2\), so the domain is bounded above. Proposition 2.3 has no such restriction for the characteristic function.
  • A characteristic function does not need a density. Proposition 2.5 gives the function for a two-point law, which has no density. The same definition applies to any variable with finitely many values.
  • Whether either function determines the law is not shown here. This lesson does not prove that \(M_X\) or \(\varphi_X\) determines the distribution, and no result below uses that uniqueness.
  • The normal characteristic function is not derived here. Proposition 1.3 covers only the moment-generating function of the normal. The lab uses only the two-point characteristic function.

4Misconceptions

  1. “Every random variable has a moment-generating function that is finite everywhere.”

    Proposition 1.4 shows that \(W = Z^{2}\), with Z standard normal, has \(E[e^{tW}] = \infty\) for every \(t \ge 1/2\). Proposition 1.2 gives an everywhere-finite domain for every variable with finitely many values, and Proposition 1.3 gives one for the normal.

  2. “The moment-generating function of a sum is the sum of the two functions.”

    Take X and Y both equal to the same variable. Then \(M_{X+Y}(t) = E[e^{2tX}] = M_X(2t)\). At \(t = 0\) this is \(1\), while \(M_X(0) + M_Y(0) = 2\). For independent variables with finitely many values the correct rule is the product, \(M_{X+Y}(t) = M_X(t)M_Y(t)\), as the proof in §5 shows.

  3. “The characteristic function exists only for a variable with a density.”

    Proposition 2.3 gives \(\varphi_X(t)\) for every variable with finitely many values, and Proposition 2.5 gives it explicitly for a two-point law. That law has no density, so the requirement is false.

5Problem set

Every problem has a full worked solution. Attempt each one before opening it.

Mechanics

M1 · The MGF and characteristic function of a fair two-point law

Let X take the values 0 and 2 with probability 1/2 each. Find \(M_X(t)\) and \(\varphi_X(t)\).

Solution

\(M_X(t) = \tfrac12 e^{0} + \tfrac12 e^{2t} = (1 + e^{2t})/2\), defined for every real t by Proposition 1.2. \(\varphi_X(t) = \tfrac12 + \tfrac12 e^{2it} = (1 + e^{2it})/2\) by Proposition 2.5 with \(p = 1/2\), \(a = 0\), \(b = 2\).

M2 · A normal MGF at one point

Let X be \(N(1, 4)\). Find \(M_X(1)\), exactly and to four decimal places.

Solution

Here \(\mu = 1\) and \(\sigma^{2} = 4\). By Proposition 1.3, \(M_X(1) = \exp(\mu \cdot 1 + \sigma^{2}\cdot 1^{2}/2) = \exp(1 + 2) = e^{3}\). Numerically \(e^{3} = 20.0855\) to four decimal places.

M3 · A zero characteristic function

Let X take the values 0 and 2 with probability 1/2 each. Find \(\varphi_X(\pi/2)\).

Solution

\(\varphi_X(\pi/2) = \tfrac12 e^{0} + \tfrac12 e^{i\pi} = \tfrac12 - \tfrac12 = 0\). Proposition 2.5 gives the same value: \[|\varphi|^{2} = \tfrac14 + \tfrac14 + 2\cdot\tfrac14\cos(-\pi) = \tfrac12 - \tfrac12 = 0\].

Proof

P1 · The affine rule for characteristic functions

Prove Proposition 2.4, stating each use of linearity.

Solution

\(e^{it(aX + b)} = e^{itb}\,e^{i(at)X}\) by the exponential law \(e^{u+v} = e^{u}e^{v}\), applied with \(u = itb\) and \(v = i(at)X\). The factor \(e^{itb}\) is a constant, so linearity of expectation takes it outside: \(E[e^{itb}e^{i(at)X}] = e^{itb}E[e^{i(at)X}]\). The last expectation is \(\varphi_X(at)\) by definition.

P2 · The normal MGF by completing the square

Prove Proposition 1.3 for a standard normal variable (\(\mu = 0\), \(\sigma = 1\)), showing where the Gaussian integral enters.

Solution

\(E[e^{tZ}] = \frac{1}{\sqrt{2\pi}}\int e^{tz - z^{2}/2}\,dz\). Since \(tz - z^{2}/2 = -(z - t)^{2}/2 + t^{2}/2\), the integral is \(e^{t^{2}/2}\int e^{-(z-t)^{2}/2}\,dz\). The substitution \(u = z - t\) leaves the integral over the line unchanged, and Proposition 1.2 of L06 gives \(\sqrt{2\pi}\). So \(E[e^{tZ}] = e^{t^{2}/2}\), which is the formula with \(\mu = 0\) and \(\sigma = 1\).

P3 · The product rule for independent variables

Let X and Y be independent with finitely many values. Show that \(M_{X+Y}(t) = M_X(t)\,M_Y(t)\) for every real t.

Solution

\(M_{X+Y}(t) = E[e^{tX}e^{tY}]\). Write \(E[g(X)h(Y)] = \sum_{x,y} g(x)h(y)P(X = x)P(Y = y)\), which holds by independence. Here \(g(x) = e^{tx}\) and \(h(y) = e^{ty}\), so the double sum factors as \(\big(\sum_x e^{tx}P(X = x)\big)\big(\sum_y e^{ty}P(Y = y)\big) = M_X(t)M_Y(t)\). This is the same factorization as Proposition 1.5 of L04.

Empirical

E1 · The sample mean of cos at t = 1

Read Part C of Lab 1. What is the difference between the sample mean of \(\cos(tX)\) at \(t = 1\) and the real part of \(\varphi(1)\)?

Solution

The printed sample mean is \(-0.062124\) and the real part is \(-0.062110\). The difference is \(-0.062124 - (-0.062110) = -0.000014\), that is, \(-1.4 \times 10^{-5}\). The sample size is 100000, and the two values are printed at six places, so the difference is the sum of sampling error and the printing rule.

E2 · The relative error of the normal MGF check

Read Part A of Lab 1. At \(t = 2\), the absolute difference is \(7.11 \times 10^{-13}\), and the closed-form value is 244.69193226. What is the relative error?

Solution

The relative error is \(7.11 \times 10^{-13}/244.69193226 = 2.9 \times 10^{-15}\), which is at the level of double-precision floating-point error. It is the size expected from floating-point arithmetic, not from the quadrature step size.

E3 · The modulus at t = 1 from Proposition 2.5

Read Part B of Lab 1. Verify the printed modulus 0.68479554 at \(t = 1\) with the formula of Proposition 2.5.

Solution

Here \(p = 0.25\), \(a = 0\), \(b = 2\), so \(p(1 - p) = 0.1875\) and \(2p(1 - p) = 0.375\). Then \[\begin{aligned} |\varphi(1)|^{2} &= 0.25^{2} + 0.75^{2} + 0.375\cos(-2) \\ &= 0.625 + 0.375 \cdot (-0.4161468) \\ &= 0.4689449 \end{aligned}\]. The square root is 0.6847955, which agrees with the printed 0.68479554 to the six places shown.

Research

R1 · When a two-point characteristic function has modulus one

Let X take the values 0 and 1 with probabilities \(1 - p\) and \(p\), where \(0 < p < 1\). Show that \(|\varphi_X(t)| = 1\) if and only if \(t\) is a multiple of \(2\pi\).

Solution

By Proposition 2.5 with \(a = 0\) and \(b = 1\), \(|\varphi(t)|^{2} = p^{2} + (1 - p)^{2} + 2p(1 - p)\cos t\). Since \(p^{2} + (1 - p)^{2} + 2p(1 - p) = (p + (1 - p))^{2} = 1\), the condition \(|\varphi|^{2} = 1\) becomes \(2p(1 - p)(\cos t - 1) = 0\). With \(0 < p < 1\) the factor \(2p(1-p)\) is positive, so \(\cos t = 1\). That holds exactly when \(t\) is a multiple of \(2\pi\).

R2 · The MGF of a two-point law is strictly increasing

Let X take the values 0 and 1 with probabilities \(1 - p\) and \(p\), where \(0 < p < 1\). Show that \(M_X\) is strictly increasing on the whole real line.

Solution

\(M_X(t) = (1 - p) + p e^{t}\). Its derivative is \(M_X'(t) = p e^{t}\), which is positive for every real t because \(p > 0\). A function with positive derivative everywhere is strictly increasing.

R3 · A symmetric sign has a real characteristic function

Let X take the values \(-1\) and \(1\) with probability 1/2 each. Show that \(\varphi_X(t) = \cos t\).

Solution

\[\begin{aligned} \varphi_X(t) &= \tfrac12 e^{-it} + \tfrac12 e^{it} \\ &= \tfrac12(\cos t - i\sin t) \\ &\quad + \tfrac12(\cos t + i\sin t) = \cos t \end{aligned}\]. The imaginary parts cancel, because the law is symmetric about 0.
