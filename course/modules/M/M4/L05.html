Covariance, correlation and the covariance matrix

  • Uses: expectation, variance, independence, and the covariance formula of L04 §1
  • Introduces: covariance and correlation, covariance matrix
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study
  • Dlore

The covariance of two quantities measures how they move together, in the product of their units. Dividing it by the two standard deviations (Definition 1.3) gives the correlation, a unit-free number that lies between minus one and one, as this lesson proves. Stacking the variances and covariances of several quantities gives the covariance matrix. Its quadratic form \(w^{\top}\Sigma w\), defined in §2, is the variance of a weighted sum, so it is never negative (Proposition 2.3). Lab 1 estimates a generating matrix from a seeded sample and reports the error at two sample sizes. Lesson L08 uses this matrix to define the multivariate normal distribution.

1Covariance and correlation

In §1 and §2, as in L04, the random variables take finitely many values, except \(Z_1\), \(Z_2\) and the \(X_1\), \(X_2\) built from them in Example 2.5, which states its own assumption about them. The support is the set of values with positive probability. The covariance \(\operatorname{Cov}(X,Y) = E[(X - E[X])(Y - E[Y])]\) and its shortcut \(E[XY] - E[X]\,E[Y]\) are Definition 1.6 and Proposition 1.7 of L04.

Proposition 1.1 (bilinearity and symmetry of covariance)

For random variables X, Y and Z with finitely many values, and real numbers a and b: (i) \(\operatorname{Cov}(X,Y) = \operatorname{Cov}(Y,X)\); (ii) \(\operatorname{Cov}(aX + b, Y) = a\,\operatorname{Cov}(X,Y)\); (iii) \(\operatorname{Cov}(X + Z, Y) = \operatorname{Cov}(X,Y) + \operatorname{Cov}(Z,Y)\); (iv) \(\operatorname{Cov}(X,X) = \operatorname{Var}(X) \ge 0\).

Proof

(i) The product \((X - E[X])(Y - E[Y])\) is the same as \((Y - E[Y])(X - E[X])\). (ii) Since \(E[aX + b] = aE[X] + b\), the centred variable is \(aX + b - E[aX + b] = a(X - E[X])\). So \(\operatorname{Cov}(aX + b, Y) = E[a(X - E[X])(Y - E[Y])] = a\,\operatorname{Cov}(X,Y)\), by linearity of finite expectations. (iii) Expand the product and use linearity of expectation, the same way as in the proof of Proposition 1.7 of L04. (iv) Setting \(Y = X\) in Proposition 1.7 of L04 gives \(\operatorname{Cov}(X,X) = E[X^{2}] - (E[X])^{2}\), which is \(\operatorname{Var}(X)\) by the formula of L02. The value is a finite sum of squares times probabilities, so it is nonnegative.

Proposition 1.2 (covariance under scaling)

For real a, b, c and d, \(\operatorname{Cov}(aX + b,\ cY + d) = ac\,\operatorname{Cov}(X,Y)\). In particular \(\operatorname{Var}(aX + b) = a^{2}\operatorname{Var}(X)\).

Proof

By Proposition 1.1(ii), \(\operatorname{Cov}(aX + b, Y) = a\,\operatorname{Cov}(X,Y)\). By symmetry (i) and (ii) again, \(\operatorname{Cov}(aX + b,\ cY + d) = c\,\operatorname{Cov}(aX + b, Y) = ac\,\operatorname{Cov}(X,Y)\). Setting \(Y = X\), \(c = a\) and \(d = b\) gives \(\operatorname{Var}(aX + b) = a^{2}\operatorname{Cov}(X,X) = a^{2}\operatorname{Var}(X)\).

Definition 1.3 (standard deviation)

The standard deviation of X is \(\sigma_X = \sqrt{\operatorname{Var}(X)}\), the nonnegative square root of the variance.

Definition 1.4 (correlation)

For X and Y with \(\sigma_X > 0\) and \(\sigma_Y > 0\), the correlation is \(\rho(X,Y) = \operatorname{Cov}(X,Y)/(\sigma_X \sigma_Y)\). The condition \(\sigma_X > 0\) excludes a constant X, whose correlation is not defined.

Proposition 1.5 (Cauchy–Schwarz for covariance)

For random variables X and Y with finitely many values, \(\operatorname{Cov}(X,Y)^{2} \le \operatorname{Var}(X)\operatorname{Var}(Y)\). Consequently, if \(\sigma_X > 0\) and \(\sigma_Y > 0\), then \(-1 \le \rho(X,Y) \le 1\).

Proof

Let \(U = X - E[X]\) and \(V = Y - E[Y]\). For every real t, the variable \((U + tV)^{2}\) is nonnegative, so its expectation is nonnegative: \[ 0 \le E[(U + tV)^{2}] = E[V^{2}]\,t^{2} + 2\,E[UV]\,t + E[U^{2}] =: At^{2} + Bt + C. \] Here \(A = \operatorname{Var}(Y)\), \(B = 2\operatorname{Cov}(X,Y)\) and \(C = \operatorname{Var}(X)\). First suppose \(A = 0\). Then \(V^{2}\) has zero expectation, and since every support point has positive probability, \(V = 0\) at every support point. So \(E[UV] = 0\), which gives \(\operatorname{Cov}(X,Y) = 0\), and the inequality holds with \(0 \le 0\). Now suppose \(A > 0\). Completing the square, \(At^{2} + Bt + C = A(t + B/(2A))^{2} + (C - B^{2}/(4A))\). Taking \(t = -B/(2A)\) gives \(C - B^{2}/(4A) \ge 0\), so \(B^{2} \le 4AC\). Substituting, \(4\operatorname{Cov}(X,Y)^{2} \le 4\operatorname{Var}(X)\operatorname{Var}(Y)\). The bound on \(\rho\) follows by dividing by \(\sigma_X^{2}\sigma_Y^{2} > 0\) and taking square roots.

Proposition 1.6 (correlation is unchanged by positive affine maps)

Let \(\sigma_X > 0\) and \(\sigma_Y > 0\). For real \(a, c > 0\) and any real b and d, \(\rho(aX + b,\ cY + d) = \rho(X,Y)\).

Proof

By Proposition 1.2, \(\operatorname{Cov}(aX + b, cY + d) = ac\,\operatorname{Cov}(X,Y)\) and \(\operatorname{Var}(aX + b) = a^{2}\operatorname{Var}(X)\). Since \(a > 0\), the standard deviation of \(aX + b\) is \(a\sigma_X\), and similarly for \(cY + d\) it is \(c\sigma_Y\). So \(\rho(aX + b,\ cY + d) = ac\,\operatorname{Cov}(X,Y)/(ac\,\sigma_X\sigma_Y) = \rho(X,Y)\).

Example 1.7 (correlation one for an increasing affine map)

Let \(\sigma_X > 0\), let \(a > 0\), and let \(Y = aX + b\). By Proposition 1.2, \(\operatorname{Cov}(X,Y) = a\operatorname{Var}(X)\). Also \(\sigma_Y = a\sigma_X\). So \(\rho(X,Y) = a\operatorname{Var}(X)/(\sigma_X \cdot a\sigma_X) = 1\), because \(\operatorname{Var}(X) = \sigma_X^{2}\).

Remark 1.8 (correlation measures linear association)

Let X be uniform on \(\{-1, 0, 1\}\) and \(Y = X^{2}\), the pair of Example 1.9 in L04. Then \(\operatorname{Cov}(X,Y) = 0\). Also \(\operatorname{Var}(X) = E[X^{2}] = 2/3 > 0\) and \(\operatorname{Var}(Y) = E[X^{4}] - (E[Y])^{2} = 2/3 - 4/9 = 2/9 > 0\). So \(\rho(X,Y) = 0\), although Y is a function of X. Here the covariance is computed to be 0, so the correlation is 0. That zero reflects the absence of a linear trend, and it does not show that the two are unrelated. Lab 1 of L04 checks the covariance of this pair.

2The covariance matrix

Definition 2.1 (covariance matrix)

For a vector \(X = (X_1, \dots, X_n)\) of random variables with finitely many values, the covariance matrix is the \(n \times n\) matrix \(\Sigma\) with entries \(\Sigma_{ij} = \operatorname{Cov}(X_i, X_j)\). Its diagonal entries are the variances \(\Sigma_{ii} = \operatorname{Var}(X_i)\).

Definition 2.2 (positive semidefinite, defined here)

A real symmetric \(n \times n\) matrix \(M\) is positive semidefinite when \(w^{\top}Mw \ge 0\) for every vector \(w \in \mathbb{R}^{n}\), where \(w^{\top}Mw = \sum_{i}\sum_{j} w_i M_{ij} w_j\) is the quadratic form.

Proposition 2.3 (a covariance matrix is positive semidefinite)

Let \(\Sigma\) be the covariance matrix of \(X = (X_1, \dots, X_n)\), a vector of random variables with finitely many values. Then \(\Sigma\) is symmetric, and for every \(w \in \mathbb{R}^{n}\), \(w^{\top}\Sigma w = \operatorname{Var}\big(\sum_{i} w_i X_i\big) \ge 0\).

Proof

Symmetry is Proposition 1.1(i). Expanding the quadratic form, \[ w^{\top}\Sigma w = \sum_{i}\sum_{j} w_i w_j \operatorname{Cov}(X_i, X_j). \] Proposition 1.1(ii) and (iii) extend by induction to finite sums, so \(\operatorname{Cov}\big(\sum_i w_i X_i, \sum_j w_j X_j\big) = \sum_i \sum_j w_i w_j \operatorname{Cov}(X_i, X_j)\). Setting \(Y = \sum_j w_j X_j\) and using Proposition 1.1(iv) gives \(\operatorname{Cov}(Y,Y) = \operatorname{Var}(Y)\). The variance is a nonnegative sum of squares times probabilities, so \(w^{\top}\Sigma w \ge 0\).

Proposition 2.4 (diagonal and off-diagonal bounds)

For a covariance matrix \(\Sigma\) of X with finitely many values, every diagonal entry is nonnegative, and \(\Sigma_{ij}^{2} \le \Sigma_{ii}\Sigma_{jj}\) for all i and j.

Proof

The diagonal entry \(\Sigma_{ii} = \operatorname{Var}(X_i)\) is nonnegative, by Proposition 1.1(iv). The bound is Proposition 1.5 applied to the pair \(X_i\) and \(X_j\), since \(\Sigma_{ij} = \operatorname{Cov}(X_i, X_j)\), \(\Sigma_{ii} = \operatorname{Var}(X_i)\) and \(\Sigma_{jj} = \operatorname{Var}(X_j)\).

Example 2.5 (a two-asset matrix from a construction)

Let \(S_1, S_2 > 0\), \(|\rho| < 1\), and let \(Z_1\) and \(Z_2\) be independent random variables with mean 0 and variance 1. Put \(X_1 = S_1 Z_1\) and \(X_2 = S_2(\rho Z_1 + \sqrt{1 - \rho^{2}}\,Z_2)\). The variables \(Z_1\) and \(Z_2\) are not finitely valued, so this example uses the rules of Proposition 1.1 for them without proving them here. It assumes that those rules hold, with \(\operatorname{Var}(Z_i) = 1\) and \(\operatorname{Cov}(Z_1, Z_2) = 0\). Under that assumption, \(\operatorname{Var}(X_1) = S_1^{2}\), \(\operatorname{Var}(X_2) = S_2^{2}(\rho^{2} + 1 - \rho^{2}) = S_2^{2}\), and \(\operatorname{Cov}(X_1, X_2) = S_1 S_2 \rho\). So the covariance matrix is \(\Sigma = \begin{pmatrix} S_1^{2} & \rho S_1 S_2 \\ \rho S_1 S_2 & S_2^{2} \end{pmatrix}\). Lab 1 draws from this construction and compares the sample matrix with \(\Sigma\).

Lab 1 · Sample covariance matrix against the generating matrix

The inputs are SIMULATED, not data. Stated before running. One seeded stream, random.Random(20260501).gauss, supplies \(Z_1\) and \(Z_2\) in turn for each observation, and the construction of Example 2.5 gives two assets with \(S_1 = 0.02\), \(S_2 = 0.03\) and \(\rho = 0.6\). The generating matrix \(\Sigma\) is \([[0.0004, 0.00036], [0.00036, 0.0009]]\). Part A predicts that the sample covariance matrix with divisor \(n - 1\), whose entries are \(\frac{1}{n-1}\sum_{k=1}^{n}(X_{ik} - \bar X_i)(X_{jk} - \bar X_j)\) with \(\bar X_i\) the sample mean of the i-th variable, moves toward \(\Sigma\) as n grows from 100 to 20000, so its largest entry error is smaller at 20000. Part B predicts a sample correlation near 0.6. Part C predicts that the quadratic form of the sample matrix is nonnegative in every one of nine directions. Proposition 2.3 requires this of a covariance matrix, and the sample matrix is one: it is a positive multiple of the covariance matrix of the n observations taken with equal probabilities. Each \(Z_i\) is a draw from random.gauss(0.0, 1.0), with mean 0 and variance 1.

"""M4 L05 lab 1: the sample covariance matrix of a seeded two-asset Gaussian draw, against the generating matrix.

Inputs are simulated, not data. One seeded stream, random.Random(20260501).gauss, supplies Z1 and Z2 in turn for
each observation. Asset 1 has standard deviation S1 = 0.02 and asset 2 has
S2 = 0.03 (returns as decimals), and the correlation is RHO = 0.6. The construction is
X1 = S1 Z1 and X2 = S2 (RHO Z1 + sqrt(1 - RHO^2) Z2), which gives the generating covariance matrix
Sigma = [[S1^2, RHO S1 S2], [RHO S1 S2, S2^2]]. The first 100 observations are a prefix of the 20000-observation run.

Part A: the generating matrix, then the sample covariance matrix with divisor n - 1 for n = 100 and n = 20000, and the
largest absolute entry error |S_ij - Sigma_ij| for each n.
Part B: the sample correlation for n = 20000, against RHO.
Part C: the quadratic form w^T S w for the sample matrix S of n = 20000 and nine directions w = (cos a, sin a), with
a = k pi / 8 for k = 0 to 8. The printed flag says whether every value is nonnegative.
"""

from __future__ import annotations

import math
import random

S1 = 0.02
S2 = 0.03
RHO = 0.6
SEED = 20260501
DIRECTIONS = 9


def draws(n: int, seed: int) -> list[tuple[float, float]]:
    """n observations (X1, X2) of the two-asset Gaussian construction, from a generator seeded with seed."""
    rng = random.Random(seed)
    out: list[tuple[float, float]] = []
    for _ in range(n):
        z1 = rng.gauss(0.0, 1.0)
        z2 = rng.gauss(0.0, 1.0)
        out.append((S1 * z1, S2 * (RHO * z1 + math.sqrt(1.0 - RHO * RHO) * z2)))
    return out


def sample_cov(xs: list[tuple[float, float]]) -> list[list[float]]:
    """The 2 by 2 sample covariance matrix with divisor n - 1, computed from the means."""
    n = len(xs)
    m1 = sum(x for x, _ in xs) / n
    m2 = sum(y for _, y in xs) / n
    s11 = sum((x - m1) ** 2 for x, _ in xs) / (n - 1)
    s22 = sum((y - m2) ** 2 for _, y in xs) / (n - 1)
    s12 = sum((x - m1) * (y - m2) for x, y in xs) / (n - 1)
    return [[s11, s12], [s12, s22]]


def quadratic_form(matrix: list[list[float]], w: tuple[float, float]) -> float:
    """w^T M w for a 2 by 2 matrix M and a vector w."""
    return sum(w[i] * matrix[i][j] * w[j] for i in range(2) for j in range(2))


def max_entry_error(a: list[list[float]], b: list[list[float]]) -> float:
    """The largest absolute difference between corresponding entries of two 2 by 2 matrices."""
    return max(abs(a[i][j] - b[i][j]) for i in range(2) for j in range(2))


def main() -> None:
    """Print Parts A, B and C. The seed is fixed, so every run prints the same lines."""
    sigma = [[S1 * S1, RHO * S1 * S2], [RHO * S1 * S2, S2 * S2]]
    print("Part A: generating matrix and sample covariance matrices")
    print(f"sigma_11 {sigma[0][0]:.8f} sigma_12 {sigma[0][1]:.8f} sigma_22 {sigma[1][1]:.8f}")
    sample_20000: list[tuple[float, float]] = []
    for n in (100, 20000):
        xs = draws(n, SEED)
        if n == 20000:
            sample_20000 = xs
        s = sample_cov(xs)
        print(f"n {n} s_11 {s[0][0]:.8f} s_12 {s[0][1]:.8f} s_22 {s[1][1]:.8f}")
        print(f"n {n} max_entry_error {max_entry_error(s, sigma):.8f}")

    print("Part B: sample correlation at n = 20000 against RHO")
    s = sample_cov(sample_20000)
    corr = s[0][1] / math.sqrt(s[0][0] * s[1][1])
    print(f"n 20000 sample_correlation {corr:.6f} rho {RHO:.6f} error {corr - RHO:.6f}")

    print("Part C: quadratic form w^T S w for nine directions, n = 20000")
    values: list[float] = []
    for k in range(DIRECTIONS):
        angle = k * math.pi / 8
        w = (math.cos(angle), math.sin(angle))
        value = quadratic_form(s, w)
        values.append(value)
        print(f"k {k} w1 {w[0]:.6f} w2 {w[1]:.6f} quadratic_form {value:.10f}")
    print(f"all_nonnegative {all(v >= 0 for v in values)}")

3Where the canon breaks

  • A zero correlation does not mean independence. Remark 1.8 gives a dependent pair with \(\rho = 0\). Remark 1.8 shows that a zero correlation can belong to a pair with a nonlinear relation.
  • A sample matrix is an estimate. The matrix in Part A of Lab 1 is computed from a seeded sample, so it differs from \(\Sigma\) at both sample sizes. The lab's errors are the differences between the sample and generating entries, computed from unrounded values, and Lab 1 Part B shows that the sample correlation also differs from \(\rho\).
  • Covariance depends on units. Proposition 1.2 gives \(\operatorname{Cov}(100X, 100Y) = 10^{4}\operatorname{Cov}(X,Y)\). A covariance in decimal returns and the same covariance in percentage points differ by that factor, while the correlation is the same.
  • The covariance matrix is not an arbitrary symmetric matrix. Proposition 2.4 is a restriction. Misconception 3 in §4 shows a symmetric matrix with positive diagonal that cannot be a covariance matrix.

4Misconceptions

  1. “Zero correlation means the two variables are unrelated.”

    Remark 1.8 gives \(Y = X^{2}\) with X uniform on \(\{-1, 0, 1\}\). The correlation is 0, while Y is a function of X. Independence is the stronger property, and zero correlation does not imply it.

  2. “Covariance is unit-free, like correlation.”

    Proposition 1.2 gives \(\operatorname{Cov}(100X, 100Y) = 10^{4}\operatorname{Cov}(X,Y)\). For the generating matrix of Lab 1, \(\Sigma_{11} = 0.0004\). In percentage points the variance is \((100 \times 0.02)^{2} = 4\), which is \(10^{4}\) times larger. The correlation of Proposition 1.6 is unchanged by the same scaling.

  3. “Any symmetric matrix with positive diagonal entries is a covariance matrix.”

    The matrix \(\begin{pmatrix}1 & 2 \\ 2 & 1\end{pmatrix}\) is symmetric with positive diagonal. Proposition 2.4 requires \(\Sigma_{12}^{2} \le \Sigma_{11}\Sigma_{22}\), which here reads \(4 \le 1\). No pair of variables with finitely many values has this covariance matrix, because it would violate Proposition 1.5.

Mechanics

M1 · The correlation of a relabelled coin

Let X take the values 0 and 1 with probability 1/2 each, and let \(Y = 2X + 1\). Compute \(\operatorname{Cov}(X,Y)\) and \(\rho(X,Y)\).

Solution

\(\operatorname{Var}(X) = E[X^{2}] - (E[X])^{2} = 1/2 - 1/4 = 1/4\), so \(\sigma_X = 1/2\). By Proposition 1.2, \(\operatorname{Cov}(X, 2X + 1) = 2\operatorname{Var}(X) = 1/2\). Also \(\sigma_Y = 2\sigma_X = 1\). So \(\rho = (1/2)/((1/2)(1)) = 1\), as Example 1.7 predicts for an increasing affine map.

M2 · The quadratic form of a two-variable matrix

Let \(\Sigma = \begin{pmatrix} 4 & 3 \\ 3 & 9 \end{pmatrix}\) be a covariance matrix. Compute \(w^{\top}\Sigma w\) for \(w = (1, -1)\), and compute the correlation of the two variables.

Solution

\(w^{\top}\Sigma w = 4 \cdot 1 + 2 \cdot 3 \cdot (1)(-1) + 9 \cdot 1 = 4 - 6 + 9 = 7\). This is nonnegative, as Proposition 2.3 requires. The correlation is \(3/(\sqrt{4}\sqrt{9}) = 3/6 = 1/2\).

M3 · The variance of a sum

Let \(\operatorname{Var}(X) = \operatorname{Var}(Y) = 1\) and \(\operatorname{Cov}(X,Y) = -0.4\). Compute \(\operatorname{Var}(X + Y)\).

Solution

By Proposition 1.1, \(\operatorname{Cov}(X + Y, X + Y) = \operatorname{Cov}(X,X) + \operatorname{Cov}(X,Y) + \operatorname{Cov}(Y,X) + \operatorname{Cov}(Y,Y) = 1 - 0.4 - 0.4 + 1 = 1.2\). So \(\operatorname{Var}(X + Y) = 1.2\), smaller than the 2 that independence would give.

Proof

P1 · The linearity step

Prove Proposition 1.1(ii) from the definition of covariance, stating each use of linearity.

Solution

Write \(\operatorname{Cov}(aX + b, Y) = E[(aX + b - E[aX + b])(Y - E[Y])]\). Linearity gives \(E[aX + b] = aE[X] + b\), so the first factor is \(a(X - E[X])\). Pulling the constant a out of the expectation, which is linearity again, gives \(a\,E[(X - E[X])(Y - E[Y])] = a\,\operatorname{Cov}(X,Y)\). The constant b cancels in the first factor.

P2 · The quadratic form for n = 2

For a two-variable vector \((X_1, X_2)\) and \(w = (w_1, w_2)\), expand \(w^{\top}\Sigma w\) and show that it equals \(\operatorname{Var}(w_1X_1 + w_2X_2)\).

Solution

Expanding, \(w^{\top}\Sigma w = w_1^{2}\Sigma_{11} + 2w_1w_2\Sigma_{12} + w_2^{2}\Sigma_{22}\), using \(\Sigma_{12} = \Sigma_{21}\). The variance of \(w_1X_1 + w_2X_2\) is \(\operatorname{Cov}(w_1X_1 + w_2X_2, w_1X_1 + w_2X_2)\). By Proposition 1.1, this expands to \(w_1^{2}\operatorname{Cov}(X_1,X_1) + 2w_1w_2\operatorname{Cov}(X_1,X_2) + w_2^{2}\operatorname{Cov}(X_2,X_2)\), which is the same expression.

P3 · Correlation under a negative scale

Show that \(\rho(-X, Y) = -\rho(X,Y)\). Note that Proposition 1.6 requires \(a > 0\), so this case is outside it.

Solution

By Proposition 1.2 with \(a = -1\) and \(c = 1\), \(\operatorname{Cov}(-X, Y) = -\operatorname{Cov}(X,Y)\). The standard deviation \(\sigma_{-X} = \sqrt{\operatorname{Var}(-X)} = \sqrt{\operatorname{Var}(X)} = \sigma_X\), because \(\operatorname{Var}(-X) = (-1)^{2}\operatorname{Var}(X)\). So \(\rho(-X,Y) = -\operatorname{Cov}(X,Y)/(\sigma_X\sigma_Y) = -\rho(X,Y)\). A negative scale reverses the sign and leaves the size unchanged.

E1 · The asset-1 variance at n = 20000

Read Part A of Lab 1. What is the relative error of the sample variance of \(X_1\) at \(n = 20000\), against the generating value \(\Sigma_{11} = 0.0004\)?

Solution

Part A prints \(s_{11} = 0.00039491\) at \(n = 20000\), which rounds the unrounded sample variance. The relative error \((s_{11} - \Sigma_{11})/\Sigma_{11}\), computed from the unrounded sample variance against \(\Sigma_{11} = 0.0004\), is \(-0.012715\), or \(-1.27\%\) to two places. Computed from the printed value instead, \((0.00039491 - 0.0004)/0.0004 = -0.012725\), which also rounds to \(-1.27\%\).

E2 · Which entry carries the largest error at n = 100

Read Part A of Lab 1. Which entry of the sample matrix at \(n = 100\) has the largest absolute error, and how large is it?

Solution

The sample entries at \(n = 100\) are \(s_{11} = 0.00038490\), \(s_{12} = 0.00033176\) and \(s_{22} = 0.00073743\). Against the generating entries 0.0004, 0.00036 and 0.0009, the errors are 0.0000151, 0.00002824 and 0.00016257. The largest is the (2,2) entry, with error 0.00016257, which matches the printed max_entry_error.

E3 · The ratio of quadratic forms in Part C

Read Part C of Lab 1. What is the ratio of the largest to the smallest quadratic form among the nine directions?

The largest printed value is 0.0010539032 at \(k = 3\), and the smallest is 0.0002187758 at \(k = 7\). Their ratio, computed from the printed values, is \(4.8173\), or 4.82 to two places. The ratio describes these nine directions. It does not bound the matrix.

R1 · Zero correlation with a variable that is not constant

Let X be uniform on \(\{-1, 0, 1\}\) and \(Y = |X|\). Show that \(\rho(X,Y) = 0\), and show that \(\sigma_Y > 0\).

Solution

\(E[X] = 0\). The product \(XY = X\,|X|\) takes the values \(-1\), 0 and 1 with probability 1/3 each, so \(E[XY] = 0\). So \(\operatorname{Cov}(X,Y) = 0\) by Proposition 1.1 and the shortcut of L04. For \(\sigma_Y\), \(E[Y] = 2/3\) and \(E[Y^{2}] = E[X^{2}] = 2/3\), so \(\operatorname{Var}(Y) = 2/3 - 4/9 = 2/9 > 0\). The correlation is \(0/(\sigma_X\sigma_Y) = 0\).

R2 · The matrix in Misconception 3

Show that no pair of random variables with finitely many values has covariance matrix \(\begin{pmatrix}1 & 2 \\ 2 & 1\end{pmatrix}\).

Solution

Suppose \(X_1\) and \(X_2\) had this covariance matrix. Then \(\operatorname{Var}(X_1) = \operatorname{Var}(X_2) = 1\) and \(\operatorname{Cov}(X_1,X_2) = 2\). Proposition 1.5 requires \(\operatorname{Cov}^{2} \le \operatorname{Var}\operatorname{Var}\), which here reads \(4 \le 1\). That is false, so no such pair exists.

R3 · A zero diagonal entry forces a zero row

Let \(\Sigma\) be the covariance matrix of X with finitely many values, and suppose \(\Sigma_{ii} = 0\) for some i. Show that \(\Sigma_{ij} = 0\) for every j.

Solution

By Proposition 2.4, \(\Sigma_{ij}^{2} \le \Sigma_{ii}\Sigma_{jj} = 0 \cdot \Sigma_{jj} = 0\). A square of a real number that is at most zero is zero, so \(\Sigma_{ij} = 0\). The variable \(X_i\) has zero variance, so it is constant on its support, and it has zero covariance with every other variable.

  1. What is \(\operatorname{Cov}(2X, 3Y)\)?

    Options

    Proposition 1.2 gives \(ac\operatorname{Cov}(X,Y)\) with \(a = 2\) and \(c = 3\).

  2. What is the correlation of X and \(Y = 2X + 1\), when \(\sigma_X > 0\)?

    Example 1.7: an increasing affine map has correlation 1 (Problem M1).

  3. When both standard deviations are positive, which bound holds for the correlation?

    Options

    Proposition 1.5, the Cauchy–Schwarz bound for covariance.

  4. A covariance matrix has \(\Sigma_{11} = 4\), \(\Sigma_{12} = 3\) and \(\Sigma_{22} = 9\). What is \(w^{\top}\Sigma w\) for \(w = (1,-1)\)?

    \(4 - 6 + 9 = 7\) (Problem M2). The value is nonnegative, as Proposition 2.3 requires.

  5. Can a diagonal entry of a covariance matrix be negative?

    Options

    Proposition 2.4: \(\Sigma_{ii} = \operatorname{Var}(X_i) \ge 0\).

  6. A covariance is 3, and the standard deviations are 2 and 3. What is the correlation?

    \(3/(2 \cdot 3) = 0.5\) (Definition 1.4).

  7. Does zero correlation imply that two variables are independent?

    Options

    Remark 1.8. A zero correlation can belong to a pair with a nonlinear relation.

  8. Is the matrix \(\begin{pmatrix}1 & 2 \\ 2 & 1\end{pmatrix}\) the covariance matrix of some pair of random variables?

    Options

    Problem R2. Proposition 2.4 requires \(\Sigma_{12}^{2} \le \Sigma_{11}\Sigma_{22}\), which fails here.

  9. If \(\operatorname{Var}(X) = \operatorname{Var}(Y) = 1\) and \(\operatorname{Cov}(X,Y) = -0.4\), what is \(\operatorname{Var}(X + Y)\)?

    \(1 + 1 + 2(-0.4) = 1.2\) (Problem M3).

  10. If \(\operatorname{Cov}(X,Y) = 0.0004\), what is \(\operatorname{Cov}(100X, 100Y)\)?

    Proposition 1.2 gives \(100^{2} \times 0.0004 = 4\). The same scaling leaves the correlation unchanged (Proposition 1.6).
