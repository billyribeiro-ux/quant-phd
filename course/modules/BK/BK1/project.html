Asset-Liability Management (ALM) Engine

Bank treasury and asset-liability management (ALM) committees require quantitative models to manage the dual risks of maturity transformation: short-term Net Interest Income (NII) volatility and long-term Economic Value of Equity (EVE) impairment. In this capstone project, you will build an enterprise ALM simulation engine (alm.py) that computes multi-bucket repricing gaps, evaluates 12-month NII sensitivity, and values equity under parallel shifts and non-parallel yield curve twists, with retail deposit betas modeled explicitly. You will then author an executive Asset-Liability Committee (ALCO) risk memo (memo.md) analyzing your balance sheet's vulnerability under monetary tightening.

  • Deliverables: alm.py (evaluated by autograder across 50 seeds) and memo.md (evaluated by 5-criterion rubric)
  • Grading: Both (autograder and rubric)
  • Allocation: 26 study hours (28.9% of module hours)

The Four-Rung Ladder

  1. Rung 1 · Worked example

    A fully solved instance of the ALM engine on a 5-position SIMULATED banking book, calculating repricing gaps, 12-month NII sensitivity under +100 bp, and EVE change under parallel and twist shocks in exact integer cents.

  2. Rung 2 · Completion problem

    Complete the core NII tenor weighting arithmetic and deposit pass-through calculations in an interactive lab graded instantly in the browser.

  3. Rung 3 · Independent project

    Implement the full specification in alm.py, passing all invariants across 50 random seeds, and draft the executive ALCO risk memo memo.md.

  4. Rung 4 · Stretch extensions

    Optionally extend your model to value non-maturity core deposits dynamically as interest rate swaptions, incorporating interest rate path simulation and non-linear deposit run-off models.

Rung 1 · Worked Example

Consider a SIMULATED commercial bank with $270,000 in assets funded by $200,000 in liabilities and $70,000 in equity. The book comprises cash (non-rate-sensitive), floating loans repricing in 2 months, 5-year fixed loans, 6-month term CDs, 3-year term notes, and $100,000 in non-maturity core deposits with a deposit beta of 0.40 (4000 bp). All amounts are computed in integer cents without float rounding.

Lab Project-1 · Solved ALM Engine Instance

Computing the 5-bucket repricing gaps, 12-month NII sensitivity under a +100 bp parallel shock, and EVE impacts under parallel (+100 bp) and twist (+150/+50 bp) shocks on the 5-position SIMULATED book using exact fraction arithmetic.

"""Lab BK1-project-1: Rung 1 worked example — Asset-Liability Management (ALM) Engine.

Demonstrates a fully solved, annotated evaluation of:
1. Repricing gap analysis across 5 time buckets.
2. 12-month Net Interest Income (NII) sensitivity to a +100 bp parallel shock.
3. Economic Value of Equity (EVE) and Delta EVE under parallel (+100 bp) and twist (+150/+50 bp) shocks.

Conventions:
- All money amounts are integer cents.
- Calculations use exact fractions and round half away from zero once at the end.
- Positions with months=None are non-rate-sensitive, omitted from gap analysis and carried at face in EVE.
- Core deposits are carried at face value in EVE and reprice with pass-through beta in NII.
"""

from __future__ import annotations

from dataclasses import dataclass
from fractions import Fraction


@dataclass(frozen=True)
class Position:
    cents: int
    months: int | None
    side: str


@dataclass(frozen=True)
class DepositBook:
    cents: int
    beta_bp: int


@dataclass(frozen=True)
class ParallelShift:
    bp: int


@dataclass(frozen=True)
class TwistShift:
    short_bp: int
    long_bp: int


def round_cents(f: Fraction) -> int:
    if f >= 0:
        return (f.numerator * 2 + f.denominator) // (f.denominator * 2)
    else:
        return -((-f.numerator * 2 + f.denominator) // (f.denominator * 2))


def bucket_index(months: int) -> int:
    if months <= 0:
        raise ValueError("months must be positive")
    if months <= 3:
        return 0
    elif months <= 6:
        return 1
    elif months <= 12:
        return 2
    elif months <= 60:
        return 3
    else:
        return 4


def repricing_gap(positions: list[Position]) -> list[int]:
    gaps_frac = [Fraction(0, 1) for _ in range(5)]
    for p in positions:
        if p.months is None:
            continue
        b = bucket_index(p.months)
        if p.side == "asset":
            gaps_frac[b] += Fraction(p.cents, 1)
        else:
            gaps_frac[b] -= Fraction(p.cents, 1)
    return [round_cents(g) for g in gaps_frac]


def nii_change_cents(positions: list[Position], deposits: DepositBook, shock_bp: int) -> int:
    delta_nii_frac = Fraction(0, 1)
    shock_frac = Fraction(shock_bp, 10_000)

    for p in positions:
        if p.months is not None and 1 <= p.months <= 12:
            weight = Fraction(12 - p.months, 12)
            term = Fraction(p.cents, 1) * shock_frac * weight
            if p.side == "asset":
                delta_nii_frac += term
            else:
                delta_nii_frac -= term

    beta_frac = Fraction(deposits.beta_bp, 10_000)
    dep_expense = Fraction(deposits.cents, 1) * beta_frac * shock_frac
    delta_nii_frac -= dep_expense
    return round_cents(delta_nii_frac)


def shift_at_month(m: int, shift: ParallelShift | TwistShift | None) -> Fraction:
    if shift is None:
        return Fraction(0, 1)
    if isinstance(shift, ParallelShift):
        return Fraction(shift.bp, 1)
    if isinstance(shift, TwistShift):
        if m <= 3:
            return Fraction(shift.short_bp, 1)
        if m >= 120:
            return Fraction(shift.long_bp, 1)
        return Fraction(shift.short_bp, 1) + Fraction((shift.long_bp - shift.short_bp) * (m - 3), 117)
    raise TypeError(f"Unknown shift: {shift}")


def eve_cents(
    positions: list[Position],
    deposits: DepositBook,
    base_rate_bp: int,
    shift: ParallelShift | TwistShift | None = None,
) -> int:
    eve_frac = Fraction(0, 1)
    for p in positions:
        if p.months is None:
            pv = Fraction(p.cents, 1)
        else:
            s_bp = shift_at_month(p.months, shift)
            effective_bp = Fraction(base_rate_bp, 1) + s_bp
            denom = Fraction(120_000, 1) + effective_bp
            df = (Fraction(120_000, 1) / denom) ** p.months
            pv = Fraction(p.cents, 1) * df

        if p.side == "asset":
            eve_frac += pv
        else:
            eve_frac -= pv

    eve_frac -= Fraction(deposits.cents, 1)
    return round_cents(eve_frac)


def delta_eve_cents(
    positions: list[Position],
    deposits: DepositBook,
    base_rate_bp: int,
    shift: ParallelShift | TwistShift,
) -> int:
    return eve_cents(positions, deposits, base_rate_bp, shift) - eve_cents(
        positions, deposits, base_rate_bp, ParallelShift(0)
    )


def main() -> None:
    # 5-position SIMULATED banking book (cents)
    positions = [
        Position(2_000_000, None, "asset"),  # $20,000 cash (face)
        Position(5_000_000, 2, "asset"),  # $50,000 loan (2m, bucket 0)
        Position(15_000_000, 60, "asset"),  # $150,000 loan (60m, bucket 3)
        Position(4_000_000, 6, "liability"),  # $40,000 CD (6m, bucket 1)
        Position(6_000_000, 36, "liability"),  # $60,000 note (36m, bucket 3)
    ]
    deposits = DepositBook(cents=10_000_000, beta_bp=4000)  # $100,000 deposits, beta=0.40
    base_rate_bp = 300  # 3.00%
    shock_bp = 100  # +100 bp parallel shock
    twist = TwistShift(short_bp=150, long_bp=50)

    print("A. Repricing Gap by Bucket (SIMULATED, in cents)")
    gaps = repricing_gap(positions)
    labels = ["0-3m", "3-6m", "6-12m", "1-5y", ">5y"]
    for idx, (label, g) in enumerate(zip(labels, gaps, strict=False)):
        print(f"Bucket {idx} ({label:5s}): {g:+10d} cents")

    print()
    print("B. 12-Month Net Interest Income Sensitivity")
    nii_delta = nii_change_cents(positions, deposits, shock_bp)
    print(f"12-Month NII Change for +{shock_bp} bp shock: {nii_delta:+8d} cents")

    print()
    print("C. Economic Value of Equity (EVE)")
    base_eve = eve_cents(positions, deposits, base_rate_bp, None)
    par_delta = delta_eve_cents(positions, deposits, base_rate_bp, ParallelShift(shock_bp))
    twist_delta = delta_eve_cents(positions, deposits, base_rate_bp, twist)

    print(f"Base EVE (300 bp rate):             {base_eve:10d} cents")
    print(f"Delta EVE Parallel (+100 bp):       {par_delta:+10d} cents")
    print(f"Delta EVE Twist (+150/+50 bp):      {twist_delta:+10d} cents")

Rung 2 · Completion Problem

In this exercise, implement the core NII sensitivity formula. For each rate-sensitive position repricing at month \(m \le 12\), the interest rate change applies for the fraction of the year remaining: \(\frac{12 - m}{12}\). Non-maturity deposits reprice immediately according to their deposit beta: \(\Delta \mathrm{IE}_{\text{dep}} = \text{deposits} \times \beta \times \Delta r\). Rung 3 · Independent Project Specification

Context
The Asset-Liability Committee (ALCO) of a commercial bank requires an institutional-grade risk engine to model the balance sheet's vulnerability to rate shifts. Your deliverable informs executive decisions on liquidity buffers, wholesale debt issuance, and interest rate hedging.
Inputs
A deterministic SIMULATED balance sheet generated by grader/instance.py::make_instance(seed), containing:
  • positions: list of dicts with keys cents (int ≥ 0), months (int ≥ 1 or None), and side ("asset" or "liability").
  • deposits_cents: integer cents ≥ 0 of core non-maturity deposits.
  • beta_bp: deposit pass-through beta in basis points [0, 10000].
  • base_rate_bp: base market interest rate in basis points ≥ 0.
  • shock_bp: parallel shock size in basis points.
  • twist_short_bp and twist_long_bp: short (m ≤ 3) and long (m ≥ 120) rate shifts in basis points.
Required outputs
Two deliverables:
  1. alm.py: Fully tested Python module exposing frozen dataclasses Position, DepositBook, ParallelShift, TwistShift, and functions bucket_index(months), repricing_gap(positions), nii_change_cents(positions, deposits, shock_bp), eve_cents(positions, deposits, base_rate_bp, shift), and delta_eve_cents(positions, deposits, base_rate_bp, shift).
  2. memo.md: Executive ALCO risk memo covering (1) Repricing Gap Diagnosis, (2) NII Sensitivity Analysis, (3) EVE Valuation under Stress, (4) Deposit Beta Sensitivity, and (5) Model Limitations & Hedging Recommendations.
Constraints
  • All money calculations must be exact in fractions.Fraction and rounded once half away from zero to integer cents.
  • Time buckets are strictly bounded: 0: 0 < m ≤ 3; 1: 3 < m ≤ 6; 2: 6 < m ≤ 12; 3: 12 < m ≤ 60; 4: m > 60.
  • Discount factor convention: monthly compounding \(DF(m) = (1 + r(m)/12)^{-m}\) where \(r(m) = \frac{\text{base\_rate\_bp} + \text{shift}(m)}{10000}\).
  • Standard library only: no external packages (NumPy, pandas) permitted.
Grading
This project is graded by both an autograder (evaluating alm.py against algebraic invariants across 50 random seeds) and a rubric (evaluating memo.md across 5 observable criteria at 4 performance levels).
Reading list
  1. Diamond (1984), "Financial Intermediation and Delegated Monitoring", Review of Economic Studies.
  2. Drechsler, Savov & Schnabl (2017), "The Deposits Channel of Monetary Policy", Quarterly Journal of Economics.
  3. Drechsler, Savov & Schnabl (2021), "Banking on Deposits: Maturity Transformation without Interest Rate Risk", Journal of Finance.
  4. Jiang, Matvos, Piskorski & Seru (2024), "Monetary Tightening and U.S. Bank Fragility in 2023: Mark-to-Market Losses and Uninsured Depositor Runs?", Journal of Financial Economics.
  5. Basel Committee on Banking Supervision, "Basel III: International Regulatory Framework for Banks", Bank for International Settlements.

SUBJECT: Comprehensive Asset-Liability Risk Diagnosis: Seed 0 Balance Sheet

1. Repricing Gap Schedule & Structural Mismatch

Analysis of our bank balance sheet (Seed 0, total assets of $128,162,961 cents) reveals a classic maturity transformation structure. Rate-sensitive assets and liabilities are distributed across the five standard regulatory repricing buckets:

  • Bucket 0 (0 < m ≤ 3 months): RSA = 16,390,521 cents; RSL = 0 cents; Periodic Gap \(G_0 = +16,390,521\) cents.
  • Bucket 1 (3 < m ≤ 6 months): RSA = 0 cents; RSL = 16,326,909 cents; Periodic Gap \(G_1 = -16,326,909\) cents.
  • Bucket 2 (6 < m ≤ 12 months): RSA = 30,117,888 cents; RSL = 0 cents; Periodic Gap \(G_2 = +30,117,888\) cents.
  • Bucket 3 (12 < m ≤ 60 months): RSA = 75,968,631 cents; RSL = 11,017,530 cents; Periodic Gap \(G_3 = +64,951,101\) cents.
  • Bucket 4 (m > 60 months): RSA = 0 cents; RSL = 0 cents; Periodic Gap \(G_4 = 0\) cents.

Summing periodic gaps across all buckets yields \(\sum_{b=0}^4 G_b = +95,132,601\) cents, which identically equals total RSA (122,477,040 cents) minus total RSL (27,344,439 cents), satisfying the repricing summation invariant. Cash (5,685,921 cents) carries months=None and is appropriately excluded from repricing gaps. The 1-year cumulative gap is \(CG_2 = G_0 + G_1 + G_2 = +30,181,500\) cents, indicating asset sensitivity over a 12-month horizon prior to deposit expense.

2. Net Interest Income Sensitivity & Deposit Beta Pass-Through

Over a 12-month horizon, a parallel shock of +150 bp (+0.015) impacts asset income, liability expense, and deposit expense. Non-maturity core deposits total 80,347,599 cents. We stress-test 12-month NII sensitivity across deposit pass-through assumptions:

  • \(\beta = 0.00\) (0 bp): \(\Delta \mathrm{NII} = +192,202\) cents
  • \(\beta = 0.35\) (3500 bp, Base Case): \(\Delta \mathrm{NII} = -229,623\) cents
  • \(\beta = 0.50\) (5000 bp): \(\Delta \mathrm{NII} = -410,405\) cents
  • \(\beta = 1.00\) (10000 bp): \(\Delta \mathrm{NII} = -1,013,012\) cents

This confirms exact mathematical linearity: higher deposit beta increases interest expense proportionally. When deposit beta exceeds the break-even threshold of approximately 0.16, net interest income sensitivity turns negative because deposit repricing outstrips net earning asset repricing.

3. Economic Value of Equity (EVE) Valuation under Rate Shocks

Base EVE under monthly compounding at 5.17% (517 bp) is \(3,138,774\) cents. Subjecting the balance sheet to parallel and twist shocks reveals significant economic capital sensitivity:

  • Parallel +150 bp Shock: EVE = -1,105,446 cents (\(\Delta \mathrm{EVE} = -4,244,220\) cents)
  • Twist Shock (+227 bp short / +52 bp long): EVE = -913,738 cents (\(\Delta \mathrm{EVE} = -4,052,512\) cents)

Because the bank holds 75,968,631 cents of 5-year fixed loans with substantial duration, long-term asset value falls much more than short-term liabilities. Notice that TwistShift(150, 150) generates \(\Delta \mathrm{EVE} = -4,244,220\) cents, identical to ParallelShift(150).

4. Modeling Conventions & Calculation Standards

All values are evaluated in exact arithmetic using Python's fractions.Fraction. Intermediate figures are unrounded; final values are rounded once half away from zero to integer cents. Discount factors follow monthly compounding: \(DF(m) = (120,000 / (120,000 + r_m))^m\). Non-maturity deposits are carried at face value in EVE and reprice immediately in NII.

5. Limitations, Literature Evidence & Hedging Recommendations

Our model assumes a static balance sheet without new originations or borrower prepayments. Drechsler, Savov & Schnabl (2017, 2021) document that retail deposit market power typically limits beta to 0.30–0.50, partially insulating bank earnings. However, Jiang, Matvos, Piskorski & Seru (2024) demonstrate that during severe tightening, uninsured depositors run when mark-to-market EVE losses threaten solvency, driving effective beta to 1.0. We recommend hedging 50% of the 5-year asset exposure using receive-floating interest rate swaps to stabilize EVE.
