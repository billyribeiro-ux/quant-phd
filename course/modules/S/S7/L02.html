Family-Wise Error: Bonferroni and Holm

  • Uses: hypothesis tests, p-values, type I error, power, data-snooping bias
  • Introduces: the family-wise error rate, the Bonferroni correction, Holm's step-down procedure
  • Ttheorem
  • Areplicated
  • Bpublished, not settled
  • Csingle study
  • Dlore
  • Xrefuted

Lesson 1 measured how far the best of many null statistics drifts above zero. This lesson turns that measurement into a decision rule. If you will act on any discovery, such as a factor added to a production model or a strategy given capital, the error that matters is the chance that even one of your discoveries is false. Two procedures control it without any knowledge of how your tests depend on each other. Bonferroni is the blunt one, and Holm's step-down procedure is never less powerful. Both pay for that robustness in power, and you will measure exactly how much.

1The multiple-testing table

A researcher tests \(m\) null hypotheses \(H_1, \dots, H_m\), for instance “factor \(i\) earns no premium”. An unknown subset \(I_0 \subseteq \{1, \dots, m\}\) of them is true, with \(m_0 = |I_0|\). Each test produces a p-value \(p_i\), and a procedure maps the vector \((p_1, \dots, p_m)\) to a set of rejections. Every outcome falls in one cell of a two-by-two table.

Outcomes of one multiple-testing procedure. Only \(m\) and \(R\) are observed.
Not rejectedRejectedTotal
True null (\(i \in I_0\))\(U\)\(V\)\(m_0\)
False null\(W\)\(S\)\(m - m_0\)
Total\(m - R\)\(R\)\(m\)

\(V\) counts false discoveries: type I errors. \(W\) counts missed effects. Bonferroni and Holm assume only that each null p-value is valid: if \(H_i\) is true, then \(\Prob(p_i \le u) \le u\) for every \(u \in [0, 1]\). A continuous test statistic with an exactly known null distribution gives a uniform p-value, which satisfies this with equality. A test whose standard errors are wrong does not, and no multiple-testing correction repairs that (Section 5).

Definition 1.1 (family-wise error rate)

The family-wise error rate of a procedure is the probability that it makes at least one false rejection, \[ \FWER = \Prob(V \ge 1). \] A procedure controls the FWER strongly at level \(\alpha\) if \(\FWER \le \alpha\) for every configuration \(I_0\) of true and false nulls. It controls it weakly if \(\FWER \le \alpha\) only when all \(m\) nulls are true.

Weak control is not enough for research: a procedure could reject a true null with high probability whenever some other hypothesis happens to be false. Every procedure in this lesson controls the FWER strongly. Harvey, Liu and Zhu describe the family-wise error rate and the false discovery rate as the two error rates most widely used in the statistics literature.

Testing each hypothesis at level \(\alpha\) ignores the family. If the \(m_0\) null p-values are independent and uniform, the probability that none falls below \(\alpha\) is \((1-\alpha)^{m_0}\), so \[ \FWER_{\text{naive}} = 1 - (1 - \alpha)^{m_0}. \] With twenty true nulls at \(\alpha = 0.05\) this is \(1 - 0.95^{20} = 0.642\). That is the testing counterpart of data-snooping bias. In Lesson 1 the best of many null Sharpe ratios looked like skill; here some null p-value almost surely looks significant.

2Bonferroni: the union bound

Definition 2.1 (Bonferroni correction)

The Bonferroni correction at level \(\alpha\) rejects \(H_i\) if and only if \(p_i \le \alpha/m\). Equivalently, it rejects when the Bonferroni-adjusted p-value \(\tilde p^{\,\mathrm{Bonf}}_i = \min(m\, p_i, 1)\) is at most \(\alpha\).

Theorem 2.2 (Bonferroni controls the FWER under any dependence)

If every true-null p-value is valid, then for any joint distribution of \((p_1, \dots, p_m)\) the Bonferroni correction satisfies \[ \FWER \le \frac{m_0}{m}\,\alpha \le \alpha. \tag{1}\]

Proof

A false rejection occurs exactly when some true null has \(p_i \le \alpha/m\), so \(\{V \ge 1\} = \bigcup_{i \in I_0} \{p_i \le \alpha/m\}\). The probability of a union is at most the sum of the probabilities (Boole's inequality), and each term is at most \(\alpha/m\) by validity: \[ \Prob(V \ge 1) \le \sum_{i \in I_0} \Prob\big(p_i \le \tfrac{\alpha}{m}\big) \le m_0\, \frac{\alpha}{m}. \] Boole's inequality holds for any events whatever their dependence, so no assumption about the joint distribution entered. The second inequality in (1) uses \(m_0 \le m\).

Independence buys a slightly larger per-test level.

Proposition 2.3 (Šidák level under independence)

If the \(m_0\) true-null p-values are independent and uniform, rejecting \(H_i\) when \(p_i \le \alpha_S = 1 - (1-\alpha)^{1/m}\) gives \(\FWER = 1 - (1-\alpha)^{m_0/m} \le \alpha\), with equality when \(m_0 = m\). Moreover \(\alpha_S \ge \alpha/m\).

Proof

By independence, \(\Prob(V = 0) = \prod_{i \in I_0} \Prob(p_i > \alpha_S) = (1-\alpha_S)^{m_0} = (1-\alpha)^{m_0/m}\). This is at least \(1 - \alpha\) because \(m_0/m \le 1\) and \(1-\alpha \in [0,1]\). For the comparison, Bernoulli's inequality \((1 - x)^m \ge 1 - m x\) for \(x \in [0,1]\), applied with \(x = \alpha/m\), gives \((1 - \alpha/m)^m \ge 1 - \alpha\). Taking \(m\)-th roots, \(1 - \alpha/m \ge (1-\alpha)^{1/m}\), that is, \(\alpha/m \le \alpha_S\).

Example 2.4 (how little independence buys)

With \(m = 20\) and \(\alpha = 0.05\), Bonferroni tests each hypothesis at \(0.05/20 = 0.0025\) and Šidák at \(1 - 0.95^{1/20} = 0.002561\), a relative gain of 2.5%. In the other direction, Bonferroni's own FWER under independence with all nulls true is \(1 - (1 - 0.0025)^{20} = 0.0488\), barely below the nominal 5%. When tests are independent the union bound is nearly tight, and assuming independence gains almost nothing.

The bound in (1) becomes loose when tests are positively dependent. In the extreme where all null p-values are equal, the union of \(m_0\) identical events is one event, and Bonferroni's FWER is \(\alpha/m\), not \(\alpha\). The next lab measures what happens in between.

Lab 1 · Family-wise error under correlation

With 50 true nulls tested one-sided at 5%, the naive FWER should be near \(1 - 0.95^{50} = 0.923\) under independence, and Bonferroni's near 0.049. As the pairwise correlation \(\rho\) of the test statistics rises, both should fall, Bonferroni's far below 5%. Under the global null Holm's FWER should equal Bonferroni's exactly.

from statistics import NormalDist

import numpy as np

# SIMULATED global null: m one-sided z-tests, all hypotheses true, pairwise correlation rho.
rng = np.random.default_rng(2002)
m, alpha, n_reps = 50, 0.05, 20000
quantile = NormalDist().inv_cdf
naive_cut = quantile(1 - alpha)  # reject when z exceeds this (p <= alpha)
bonferroni_cut = quantile(1 - alpha / m)  # p <= alpha / m
holm_cuts = np.array([quantile(1 - alpha / (m + 1 - b)) for b in range(1, m + 1)])

print("rho  naive_fwer  bonferroni_fwer  holm_fwer")
for rho in (0.0, 0.5, 0.9):
    w = rng.standard_normal((n_reps, 1))
    e = rng.standard_normal((n_reps, m))
    z = np.sqrt(rho) * w + np.sqrt(1 - rho) * e
    z_max = z.max(axis=1)
    naive = np.mean(z_max > naive_cut)
    bonferroni = np.mean(z_max > bonferroni_cut)
    # Holm's step-down, run in full: sort the statistics (smallest p first), stop at the first
    # failure. Every rejection is false under the global null.
    ordered = -np.sort(-z, axis=1)
    passes = ordered > holm_cuts
    n_rejected = np.where(passes.all(axis=1), m, np.argmin(passes, axis=1))
    holm = np.mean(n_rejected > 0)
    print(f"{rho:.1f} {naive:.4f} {bonferroni:.4f} {holm:.4f}")
rho  naive_fwer  bonferroni_fwer  holm_fwer
0.0 0.9226 0.0491 0.0491
0.5 0.4713 0.0287 0.0287
0.9 0.1656 0.0056 0.0056

The guarantee holds at every correlation, but at \(\rho = 0.9\) Bonferroni spends roughly a tenth of its error budget: the fifty tests behave like a handful of independent ones. Holm cannot recover this slack, because under the global null its first step is Bonferroni's test of the smallest p-value: the lab runs Holm's full step-down, and its family-wise error rate equals Bonferroni's in every row. The lab shows how conservative dependence-free control becomes. It does not show that a correlation-aware procedure is valid; that requires the bootstrap arguments of Lessons 4 and 5.

3Holm's step-down procedure

Bonferroni charges every hypothesis the full price of \(m\) tests, even after the strongest ones have been rejected. Once \(H_{(1)}\) is rejected, at most \(m - 1\) true nulls can remain among the others, so the second test can be run against \(\alpha/(m-1)\), and so on. The procedure below turns this observation into a rule.

Definition 3.1 (Holm's step-down procedure)

Order the p-values \(p_{(1)} \le p_{(2)} \le \dots \le p_{(m)}\), with hypotheses \(H_{(1)}, \dots, H_{(m)}\); ties may be ordered arbitrarily. Holm's step-down procedure at level \(\alpha\) finds the first index \(k\) with \[ p_{(k)} > \frac{\alpha}{m + 1 - k} \] and rejects \(H_{(1)}, \dots, H_{(k-1)}\). If no such \(k\) exists, it rejects all \(m\) hypotheses.

The thresholds \(\alpha/m, \alpha/(m-1), \dots, \alpha/1\) rise along the ordering, and the procedure stops at the first failure. That is what “step-down” means: it starts from the most significant statistic and moves toward the least.

Theorem 3.2 (Holm controls the FWER strongly under any dependence)

If every true-null p-value is valid, then for any joint distribution of \((p_1, \dots, p_m)\) and any configuration \(I_0\), Holm's procedure at level \(\alpha\) has \(\FWER \le \alpha\).

Proof

If \(m_0 = 0\) there is nothing to prove, so let \(m_0 \ge 1\). Among the true nulls, let \(j\) be the position in the ordering of the first one, the true null with the smallest p-value. At most \(m - m_0\) hypotheses precede it, all of them false nulls, so \(j \le m - m_0 + 1\), equivalently \(m + 1 - j \ge m_0\).

Holm rejects an initial segment \(H_{(1)}, \dots, H_{(k-1)}\) of the ordering. If it rejects any true null, it therefore rejects the one at position \(j\). It can do that only if it does not stop at step \(j\), which requires \[ p_{(j)} \le \frac{\alpha}{m + 1 - j} \le \frac{\alpha}{m_0}. \] Since \(p_{(j)} = \min_{i \in I_0} p_i\), we have shown \(\{V \ge 1\} \subseteq \{\min_{i \in I_0} p_i \le \alpha/m_0\} = \bigcup_{i \in I_0}\{p_i \le \alpha/m_0\}\). Boole's inequality and validity then give \[ \Prob(V \ge 1) \le \sum_{i \in I_0} \Prob\big(p_i \le \tfrac{\alpha}{m_0}\big) \le m_0 \cdot \frac{\alpha}{m_0} = \alpha. \] As in Theorem 2.2, nothing assumed independence. The proof works because the false nulls, however many, can only push the first true null later in the ordering, where its threshold is looser by at most the factor \(m/m_0\).

Proposition 3.3 (Holm rejects everything Bonferroni rejects)

For any p-values, every hypothesis rejected by the Bonferroni correction at level \(\alpha\) is rejected by Holm's procedure at level \(\alpha\).

Proof

Suppose Bonferroni rejects \(H_{(b)}\), so \(p_{(b)} \le \alpha/m\). For every \(b' \le b\), \(p_{(b')} \le p_{(b)} \le \alpha/m \le \alpha/(m + 1 - b')\), because \(m + 1 - b' \le m\). So Holm passes steps \(1, \dots, b\), and its first failure, if any, comes after \(b\). Hence Holm rejects \(H_{(b)}\).

Holm is therefore uniformly at least as powerful as Bonferroni at the same level, under the same dependence-free guarantee. Its decisions can also be reported as adjusted p-values, so a reader can apply any level \(\alpha\).

Proposition 3.4 (Holm-adjusted p-values)

Define \(\tilde p^{\,\mathrm{Holm}}_{(b)} = \min\!\big(1, \max_{j \le b}\, (m - j + 1)\, p_{(j)}\big)\). Then \(\tilde p^{\,\mathrm{Holm}}_{(1)} \le \dots \le \tilde p^{\,\mathrm{Holm}}_{(m)}\), and Holm's procedure at level \(\alpha \in (0, 1)\) rejects \(H_{(b)}\) if and only if \(\tilde p^{\,\mathrm{Holm}}_{(b)} \le \alpha\).

Proof

The running maximum is non-decreasing in \(b\), and so is its minimum with 1, which proves the ordering. For \(\alpha \lt 1\), \(\tilde p^{\,\mathrm{Holm}}_{(b)} \le \alpha\) holds if and only if \((m - j + 1)\, p_{(j)} \le \alpha\) for every \(j \le b\), that is, \(p_{(j)} \le \alpha/(m + 1 - j)\) for \(j = 1, \dots, b\). That is exactly the condition that Holm passes steps \(1, \dots, b\), which is the condition for rejecting \(H_{(b)}\).

Harvey, Liu and Zhu illustrate both procedures on ten hypothetical factor tests at \(\alpha = 5\%\): Bonferroni rejects three hypotheses and Holm four. Their example is worth re-running, because it also shows how fragile decisions near a threshold are.

Lab 2 · Re-running a published Holm example

Applied to the published p-values, Bonferroni should reject tests 4, 7 and 8 and Holm should add test 9, as the paper reports. Recomputing two-sided normal p-values from the published t-statistics should change at most the last reported digit of some p-values; whether that changes any decision depends on how close they sit to Holm's thresholds.

from statistics import NormalDist

import numpy as np
from numpy.typing import NDArray

# Harvey, Liu and Zhu's hypothetical ten-test example (their Table 4, panel A, p. 18):
# the reported t-statistics and the reported two-sided p-values in percent.
t_stats = np.array([1.99, 2.63, 2.21, 3.43, 2.17, 2.64, 4.56, 5.34, 2.75, 2.49])
reported_p = np.array([4.66, 0.85, 2.71, 0.05, 3.00, 0.84, 0.00, 0.00, 0.60, 1.28]) / 100
alpha = 0.05
m = t_stats.size


def holm_adjusted(p: NDArray[np.float64]) -> NDArray[np.float64]:
    """Holm-adjusted p-values: running maximum of (m - j + 1) * p_(j), capped at 1."""
    order = np.argsort(p, kind="stable")
    scaled = (m - np.arange(m)) * p[order]
    adjusted = np.empty(m)
    adjusted[order] = np.minimum(np.maximum.accumulate(scaled), 1.0)
    return adjusted


phi = NormalDist()
recomputed_p = np.array([2 * (1 - phi.cdf(float(t))) for t in t_stats])
print("reported p (%):  ", " ".join(f"{100 * p:.2f}" for p in reported_p))
print("recomputed p (%):", " ".join(f"{100 * p:.2f}" for p in recomputed_p))
for label, p in (("reported", reported_p), ("recomputed", recomputed_p)):
    bonferroni = np.flatnonzero(p <= alpha / m) + 1
    holm = np.flatnonzero(holm_adjusted(p) <= alpha) + 1
    print(f"{label} p-values: Bonferroni rejects tests {bonferroni.tolist()}, Holm rejects tests {holm.tolist()}")
print("test 6: reported p = 0.84%, recomputed p = " + f"{100 * recomputed_p[5]:.4f}%")
print("Holm threshold at the fifth step = " + f"{100 * alpha / (m + 1 - 5):.4f}%")
reported p (%):   4.66 0.85 2.71 0.05 3.00 0.84 0.00 0.00 0.60 1.28
recomputed p (%): 4.66 0.85 2.71 0.06 3.00 0.83 0.00 0.00 0.60 1.28
reported p-values: Bonferroni rejects tests [4, 7, 8], Holm rejects tests [4, 7, 8, 9]
recomputed p-values: Bonferroni rejects tests [4, 7, 8], Holm rejects tests [2, 4, 6, 7, 8, 9]
test 6: reported p = 0.84%, recomputed p = 0.8291%

The first two lines show that recomputing changes only tests 4 and 6, each in its last reported digit. With the published two-decimal p-values the lab reproduces the paper's decisions. Recomputed as two-sided normal p-values from the published t-statistics, test 6's p-value is 0.8291%, just below Holm's fifth threshold of 0.8333%; the two-decimal value 0.84% sits just above it. Passing step five lets the step-down continue, and test 2 (p = 0.85%) then clears the sixth threshold of 1%. So the count moves from four to six on the third significant digit of one p-value. Nothing in Harvey, Liu and Zhu's argument rests on this hypothetical example; the lesson is about reporting. A step-down decision depends on every p-value before it, so report p-values to enough digits for the reader to rerun it.

Remark 3.5 (what Holm leaves on the table)

Holm uses only the marginal validity of each p-value, which is why its guarantee survives any dependence, and also why it inherits Bonferroni's conservatism under positive correlation (Lab 1). Raising its constants would reduce that conservatism under positive correlation, but not safely: Problem P4 shows that raising any one of them lets some joint distribution of valid p-values push the family-wise error rate above \(\alpha\), so the guarantee under any dependence is lost. Using the joint distribution of the test statistics requires knowing or estimating it. Romano and Wolf propose a stepwise procedure that asymptotically controls the familywise error rate, implicitly captures the joint dependence of the test statistics, and is more powerful than related single-step methods, often rejecting more false hypotheses. Lesson 5 builds it on the bootstrap of Lesson 4.

4The price: power as the family grows

Strong FWER control at a fixed \(\alpha\) forces the per-test threshold down as \(m\) grows, and power falls with it. Proposition 4.1 bounds the threshold with the same \(\sqrt{2\ln(\cdot)}\) form as Lesson 1's bound on the maximum, and Problem M3 shows that the rate is attained.

Proposition 4.1 (Bonferroni critical values grow no faster than \(\sqrt{2\ln(m/(2\alpha))}\))

For a standard normal \(Z\) and \(x \ge 0\), \(\Prob(Z > x) \le \tfrac12 e^{-x^2/2}\). Consequently, for \(m \ge 2\alpha\), the one-sided Bonferroni critical value satisfies \[ \Phi^{-1}\!\big(1 - \tfrac{\alpha}{m}\big) \le \sqrt{2 \ln\!\big(\tfrac{m}{2\alpha}\big)}. \]

Proof

Substitute \(t = x + u\) in \(\Prob(Z > x) = \int_x^\infty \varphi(t)\,dt\), where \(\varphi\) is the standard normal density: \[ \Prob(Z > x) = \int_0^\infty \varphi(x + u)\, du = \varphi(x) \int_0^\infty e^{-xu - u^2/2}\, du \le \varphi(x) \int_0^\infty e^{-u^2/2}\, du = \frac{e^{-x^2/2}}{\sqrt{2\pi}} \sqrt{\frac{\pi}{2}} = \frac{e^{-x^2/2}}{2}, \] using \(e^{-xu} \le 1\) for \(x, u \ge 0\). At \(x^\ast = \sqrt{2\ln(m/(2\alpha))}\), which is real because \(m \ge 2\alpha\), the bound equals \(\alpha/m\). So \(\Prob(Z > x^\ast) \le \alpha/m\), which means \(\Phi(x^\ast) \ge 1 - \alpha/m\). Since \(\Phi^{-1}\) is increasing, \(\Phi^{-1}(1 - \alpha/m) \le x^\ast\).

Example 4.2 (the same effect, a larger family)

Consider a two-sided z-test whose statistic is centred at 3.5 under the alternative. With Bonferroni at \(\alpha = 5\%\), the critical value \(\Phi^{-1}(1 - \alpha/(2m))\) is 1.960, 2.807, 3.481 and 4.056 for \(m = 1, 10, 100, 1000\). The power, \(\Phi(3.5 - \text{critical value})\) (the opposite tail contributes less than \(10^{-7}\)), falls from 0.938 to 0.756, 0.508 and 0.289. The same evidence that is decisive alone is a coin flip in a family of one hundred.

Lab 3 · Bonferroni against Holm when some effects are real

Among 100 independent one-sided tests with \(m_1\) false nulls centred at 3.5, both procedures should keep the FWER below 5%. Holm's power advantage should be small when false nulls are rare (\(m_1 = 10\)) and larger when they are common (\(m_1 = 50\)), because each early rejection loosens every later threshold.

from statistics import NormalDist

import numpy as np

# SIMULATED: m independent one-sided z-tests; the first m1 hypotheses are false,
# with z-statistics centred at delta; the rest are true nulls.
rng = np.random.default_rng(3003)
m, delta, alpha, n_reps = 100, 3.5, 0.05, 4000
quantile = NormalDist().inv_cdf
holm_cuts = np.array([quantile(1 - alpha / (m + 1 - b)) for b in range(1, m + 1)])
bonferroni_cut = holm_cuts[0]

print("m1  method      power   fwer")
for m1 in (10, 50):
    is_false_null = np.arange(m) < m1
    z = rng.standard_normal((n_reps, m)) + np.where(is_false_null, delta, 0.0)
    bonferroni_reject = z > bonferroni_cut
    order = np.argsort(-z, axis=1)  # largest z first, i.e. smallest p first
    passes = np.take_along_axis(z, order, axis=1) > holm_cuts
    k = np.where(passes.all(axis=1), m, np.argmin(passes, axis=1))  # step-down stops at the first failure
    holm_reject = np.zeros_like(bonferroni_reject)
    for rep in range(n_reps):
        holm_reject[rep, order[rep, : k[rep]]] = True
    for name, rejected in (("bonferroni", bonferroni_reject), ("holm", holm_reject)):
        power = rejected[:, is_false_null].mean()
        fwer = rejected[:, ~is_false_null].any(axis=1).mean()
        print(f"{m1} {name:<11} {power:.4f} {fwer:.4f}")
m1  method      power   fwer
10 bonferroni  0.5837 0.0423
10 holm        0.5901 0.0440
50 bonferroni  0.5803 0.0250
50 holm        0.6212 0.0355

With ten real effects Holm adds under one percentage point of power. With fifty it adds about four, and it spends more of the error budget in doing so (an FWER of 0.036 against 0.025). Bonferroni charges for all 100 tests although only 50 nulls are true, so its FWER sits near \(1 - (1 - 0.0005)^{50} = 0.025\); Holm's thresholds loosen with each rejection, so its error rate moves toward \(\alpha\). Neither procedure detects much more than half of the effects at this strength. FWER control is expensive by design: it protects every single decision. When a research process can tolerate a known fraction of false discoveries, Lesson 3's false discovery rate is the better criterion.

5Where the canon breaks

  • The family is undefined in practice. Every guarantee above conditions on \(m\), the number of hypotheses in the family. A researcher who reports 20 tests after running 200 and corrects for 20 has the FWER of a 20-test correction applied to a 200-test search. Lesson 1 showed why the true count is usually unobservable. Which tests form one family (one paper, one research programme, one fund) is a decision about which errors you are accountable for, and no theorem makes it for you.
  • FWER is the wrong target when discoveries are many. Harvey, Liu and Zhu note that when the total number of discoveries is large, one or even a few false ones may be tolerable, and that a false discovery proportion may then be more desirable. A factor researcher who finds forty genuine premia does not need a guarantee that all forty are real; Lesson 3 controls the expected proportion instead.
  • Garbage p-values in, garbage control out. Bonferroni and Holm assume only valid p-values, but they do assume them. If the per-test standard errors ignore heteroskedasticity, autocorrelation or clustering (S2), the null p-values are too small, and the corrected procedure inherits the bias. The fix belongs in each test, not in the correction.
  • Dependence is wasted, not exploited. Lab 1 shows Bonferroni's actual FWER at a tenth of its nominal level when tests are highly correlated, which is the usual case for variants of one strategy. Recovering that power requires the joint distribution of the statistics, which the bootstrap procedures of Lessons 4–5 estimate.

6Misconceptions

  1. “Bonferroni assumes the tests are independent.”

    It assumes nothing about dependence. The proof of Theorem 2.2 uses only Boole's inequality, which holds for any events. Independence is what Šidák's level needs (Proposition 2.3), and Example 2.4 shows it buys a relative gain of about 2% at \(m = 20\).

  2. “Holm controls a weaker error rate than Bonferroni, which is why it rejects more.”

    Both control the same quantity, the FWER, strongly and at the same level, under the same assumptions (Theorems 2.2 and 3.2). Holm rejects more because it stops charging for hypotheses already rejected, and Proposition 3.3 shows it never rejects less.

  3. “Correcting for multiple testing means dividing \(\alpha\) by the number of tests I report.”

    The correction must divide by the number of tests in the family, including those run and not reported. Correcting for the reported subset leaves the search itself uncorrected.

  4. “Controlling the FWER at 5% means that 5% of my discoveries are false.”

    The FWER is the probability that any discovery is false, not a proportion. A procedure with FWER 5% is wrong at least once in about one study in twenty. The proportion of false discoveries is a different, random quantity whose expectation Lesson 3 controls.

7Problem set

Every problem has a full worked solution. Attempt each one before opening it.

Mechanics

M1 · Thirty signals

A desk tests 30 signals, all in fact useless, with independent uniform p-values. (a) What is the FWER if each is tested at 5%? (b) What is the expected number of false rejections? (c) What per-test levels do Bonferroni and Šidák use for FWER 5%?

Solution

(a) \(1 - 0.95^{30} = 1 - 0.2146 = 0.785\).

(b) Each signal is rejected with probability 0.05, so by linearity of expectation \(\E[V] = 30 \times 0.05 = 1.5\). This holds even without independence.

(c) Bonferroni: \(0.05/30 = 0.001667\). Šidák: \(1 - 0.95^{1/30} = 0.001708\). The difference is 2.5% in relative terms.

M2 · By hand

Eight ordered p-values are 0.001, 0.004, 0.008, 0.012, 0.03, 0.04, 0.2 and 0.6. At \(\alpha = 0.05\), (a) which hypotheses does Bonferroni reject, (b) which does Holm reject, and (c) what are the Holm-adjusted p-values?

Solution

(a) The Bonferroni cutoff is \(0.05/8 = 0.00625\). It rejects the hypotheses with p-values 0.001 and 0.004.

(b) Holm's thresholds \(0.05/(9 - b)\) for \(b = 1, 2, 3, 4\) are 0.00625, 0.007143, 0.008333 and 0.01. The first three p-values pass (0.001, 0.004, 0.008), and the fourth fails (\(0.012 > 0.01\)), so Holm rejects three hypotheses.

(c) The products \((m - j + 1)\,p_{(j)}\) are 0.008, 0.028, 0.048, 0.06, 0.12, 0.12, 0.4 and 0.6. Their running maxima, capped at 1, are the Holm-adjusted p-values: 0.008, 0.028, 0.048, 0.06, 0.12, 0.12, 0.4 and 0.6. The first three are at most 0.05, matching (b), as Proposition 3.4 requires.

M3 · One-sided critical values and their bound

For one-sided Bonferroni tests at \(\alpha = 0.05\), compute the critical value \(\Phi^{-1}(1 - \alpha/m)\) and the bound \(\sqrt{2\ln(m/(2\alpha))}\) of Proposition 4.1 for \(m = 10, 100, 1000\).

Solution

For \(m = 10\): \(\Phi^{-1}(0.995) = 2.576\), and the bound is \(\sqrt{2\ln 100} = 3.035\). For \(m = 100\): \(\Phi^{-1}(0.9995) = 3.291\), and the bound is \(\sqrt{2\ln 1000} = 3.717\). For \(m = 1000\): \(\Phi^{-1}(0.99995) = 3.891\), and the bound is \(\sqrt{2\ln 10000} = 4.292\). The bound overstates the critical value by about 0.4–0.5 throughout, and a matching lower bound shows it has the right growth rate. For \(x > 0\), \(h(x) = \Prob(Z > x) - \tfrac{x}{1+x^2}\varphi(x)\) has \(h'(x) = -2\varphi(x)/(1+x^2)^2 \lt 0\) and \(h(x) \to 0\) as \(x \to \infty\), so \(h(x) > 0\). At the critical value \(x_m\) this gives \(\alpha/m > \tfrac{x_m}{1+x_m^2}\varphi(x_m)\), which rearranges to \(x_m^2 > 2\ln(m/\alpha) - 2\ln\!\big(\sqrt{2\pi}\,(x_m + 1/x_m)\big)\). With Proposition 4.1, \(x_m/\sqrt{2\ln m} \to 1\). Over this range, each tenfold increase in the family costs 0.6–0.7 more standard deviations of evidence (\(3.291 - 2.576 = 0.715\), then \(3.891 - 3.291 = 0.600\)), and each decade costs less than the last.

Proof

P1 · Perfect dependence

Suppose all \(m\) hypotheses are true and all \(m\) p-values are equal to one uniform random variable \(U\). Compute the FWER of the Bonferroni correction and of Holm's procedure at level \(\alpha\). Then compute Bonferroni's FWER when the \(m\) p-values are instead independent uniforms, and evaluate both at \(m = 50\), \(\alpha = 0.05\).

Solution

With equal p-values, Bonferroni rejects all or none, so its FWER is \(\Prob(U \le \alpha/m) = \alpha/m\). Holm's first step tests \(U \le \alpha/m\). If it passes, every later step passes too, because \(p_{(b)} = U \le \alpha/m \le \alpha/(m + 1 - b)\); if it fails, Holm stops. So Holm's FWER is also \(\alpha/m\).

With independent uniforms, Bonferroni's FWER is \(1 - (1 - \alpha/m)^m\). At \(m = 50\) and \(\alpha = 0.05\), perfect dependence gives \(0.05/50 = 0.001\) and independence gives \(1 - 0.999^{50} = 0.0488\). The guarantee \(\FWER \le \alpha\) holds in both cases; the actual error spent differs by a factor of almost 50.

P2 · Bonferroni's exact error for disjoint rejection regions

Show that the inequality \(\FWER \le m_0\alpha/m\) of Theorem 2.2 holds with equality when the true-null p-values are uniform and the events \(\{p_i \le \alpha/m\}\), \(i \in I_0\), are pairwise disjoint. Then construct such a joint distribution for \(m_0 = m = 2\) and \(\alpha \lt 1\).

Solution

For pairwise disjoint events, the probability of the union equals the sum of the probabilities, so \(\Prob(V \ge 1) = \sum_{i \in I_0} \Prob(p_i \le \alpha/m) = m_0\alpha/m\) when each \(p_i\) is uniform.

A construction: let \(U\) be uniform on \([0,1]\), and set \(p_1 = U\) and \(p_2 = (U + \tfrac12) \bmod 1\). Each is uniform, because a rotation of the circle preserves the uniform distribution. The event \(\{p_1 \le \alpha/2\}\) is \(\{U \le \alpha/2\}\), and \(\{p_2 \le \alpha/2\}\) is \(\{\tfrac12 \le U \le \tfrac12 + \alpha/2\}\). For \(\alpha \lt 1\) these intervals are disjoint, so the FWER is exactly \(\alpha\). Negative dependence of this kind is the one case in which the union bound is attained.

P3 · Holm via closed testing

The closed testing principle rejects \(H_i\) if every intersection hypothesis \(H_J = \bigcap_{j \in J} H_j\) with \(i \in J\) is rejected by a level-\(\alpha\) test of \(H_J\). Show that if each \(H_J\) is tested by Bonferroni within \(J\) (reject \(H_J\) when \(\min_{j \in J} p_j \le \alpha/|J|\)), the resulting procedure rejects \(H_{(b)}\) if and only if Holm does.

Solution

(⇐) Suppose Holm rejects \(H_{(b)}\), so \(p_{(c)} \le \alpha/(m + 1 - c)\) for every \(c \le b\). Take any \(J\) containing \((b)\). Let \(c\) be the smallest ordered index in \(J\). Then \(c \le b\), and \(J\) contains only indices from \(c\) to \(m\), so \(|J| \le m + 1 - c\). Hence \(\min_{j \in J} p_j = p_{(c)} \le \alpha/(m + 1 - c) \le \alpha/|J|\), and \(H_J\) is rejected. Every intersection containing \(H_{(b)}\) is rejected, so closed testing rejects \(H_{(b)}\).

(⇒) Suppose Holm does not reject \(H_{(b)}\). Then Holm stops at some \(k \le b\), with \(p_{(k)} > \alpha/(m + 1 - k)\). Let \(J = \{(k), (k+1), \dots, (m)\}\), which contains \((b)\) and has \(|J| = m + 1 - k\). Its minimum p-value is \(p_{(k)} > \alpha/|J|\), so \(H_J\) is not rejected, and closed testing does not reject \(H_{(b)}\).

Closed testing controls the FWER strongly whenever each intersection test has level \(\alpha\). The true intersection \(H_{I_0}\) is rejected with probability at most \(\alpha\), and any false rejection requires rejecting it. This gives a second proof of Theorem 3.2.

P4 · Holm's constants cannot be raised

Let \(\alpha \in (0,1)\) and let \(c_1, \dots, c_m\) be positive constants. A step-down procedure with these constants finds the first index \(k\) with \(p_{(k)} > c_k\), rejects \(H_{(1)}, \dots, H_{(k-1)}\), and rejects all \(m\) hypotheses if there is no such \(k\). Holm's procedure has \(c_k = \alpha/(m + 1 - k)\) (Definition 3.1). Suppose that for one index \(i\) the constant satisfies \(c_i > \alpha/(m - i + 1)\), whatever the other constants are. Show that some joint distribution of valid p-values, with \(i - 1\) false nulls and \(m - i + 1\) true nulls, gives this procedure a family-wise error rate above \(\alpha\). Then (a) show that the same distribution gives Holm's procedure a family-wise error rate of exactly \(\alpha\), and (b) evaluate the construction for \(m = 3\), \(\alpha = 0.05\), \(i = 2\) and \(c_2 = 0.03\).

Solution

Set-up. Write \(m' = m - i + 1\) for the number of true nulls and \(c = \min(c_i,\, 1/m')\). Since \(\alpha \lt 1\) and \(c_i > \alpha/m'\), we have \(c > \alpha/m'\), that is, \(m'c > \alpha\).

Construction. Let \(U\) be uniform on \([0,1)\). Give each of the \(i - 1\) false nulls the p-value 0, a value that a false null is free to take. Give the \(m'\) true nulls the p-values \[ q_j = \big(U + (j-1)/m'\big) \bmod 1, \qquad j = 1, \dots, m'. \] Each \(q_j\) is uniform on \([0,1)\), because adding a constant modulo 1 rotates the circle and preserves its uniform distribution (the device of Problem P2). So every true-null p-value is valid.

The rejection events are disjoint. The event \(\{q_j \le c\}\) is the event that \(U\) falls in the arc of length \(c\) that starts at \(\big(-(j-1)/m'\big) \bmod 1\). These \(m'\) starting points are \(0, 1/m', \dots, (m'-1)/m'\), spaced \(1/m'\) apart, and \(c \le 1/m'\), so the arcs meet at most at their ends. The events are therefore disjoint up to a null set, and \[ \Prob\big(\min_j q_j \le c\big) = \sum_{j=1}^{m'} \Prob(q_j \le c) = m'c. \]

A false rejection. With probability one every \(q_j\) is positive, so the \(i - 1\) zeros are the smallest p-values, \(p_{(1)} = \dots = p_{(i-1)} = 0\), and \(p_{(i)} = \min_j q_j\) belongs to a true null. The zeros pass steps \(1, \dots, i-1\), because the constants are positive. If \(\min_j q_j \le c\), then \(p_{(i)} \le c \le c_i\), step \(i\) passes as well, and the procedure rejects \(H_{(i)}\), a true null. Hence \[ \FWER \ge \Prob\big(\min_j q_j \le c\big) = m'c = \min(m'c_i,\, 1) > \alpha, \] where the last inequality uses \(m'c_i > \alpha\) and \(\alpha \lt 1\).

(a) With \(c_i = \alpha/m'\) we have \(c = \alpha/m'\). If \(p_{(i)} > c_i\), step \(i\) fails and the procedure stops with only the \(i - 1\) false nulls rejected, so \(V = 0\). Hence \(V \ge 1\) exactly when \(\min_j q_j \le \alpha/m'\), and \(\FWER = m' \cdot \alpha/m' = \alpha\). This holds for every \(i = 1, \dots, m\), that is, for every number \(m' = m, \dots, 1\) of true nulls. Every inequality in the proof of Theorem 3.2 holds with equality here: the zeros put the first true null at position \(m - m' + 1\), the latest the proof allows; the disjoint events turn Boole's inequality into an equality; and uniform p-values turn validity into an equality.

(b) For \(m = 3\) and \(\alpha = 0.05\), Holm's constants are \(0.05/3 = 0.0167\) (rounded), \(0.025\) and \(0.05\). Raising \(c_2\) to 0.03 gives \(m' = 2\) and \(c = \min(0.03,\, 1/2) = 0.03\). The construction is \(p_1 = 0\), \(p_2 = U\), \(p_3 = (U + \tfrac12) \bmod 1\). The events \(\{p_2 \le 0.03\} = \{U \le 0.03\}\) and \(\{p_3 \le 0.03\} = \{0.5 \le U \le 0.53\}\) are disjoint, so a true null is rejected with probability \(0.03 + 0.03 = 0.06 > 0.05\). At Holm's own \(c_2 = 0.025\), the same distribution gives \(0.025 + 0.025 = 0.05\). A raise to \(c_2 = 0.6\) gives \(c = 1/2\); the events \(\{p_2 \le \tfrac12\} = \{U \le \tfrac12\}\) and \(\{p_3 \le \tfrac12\} = \{U \ge \tfrac12\}\) cover every value of \(U\), so the FWER is 1.

Zeros are a convenience. Let the \(i - 1\) false-null p-values be any numbers in \((0, \delta]\) instead, with \(\delta\) at most every \(c_j\) for \(j \lt i\). On the event \(\{\delta \lt \min_j q_j \le c\}\) the \(i - 1\) smallest p-values are the false nulls', each at most its constant, so the argument above again ends in a false rejection. For \(\delta \le c\) the event has probability \(\Prob(\min_j q_j \le c) - \Prob(\min_j q_j \le \delta) = m'(c - \delta)\), which exceeds \(\alpha\) once \(\delta \lt c - \alpha/m'\). False nulls whose p-values are only near 0 therefore do as well.

What it shows. A step-down procedure with fixed constants that controls the FWER at level \(\alpha\) under every joint distribution of valid p-values must have \(c_k \le \alpha/(m + 1 - k)\) for every \(k\). Raising constants only adds rejections, because the first failure moves later, so Holm's procedure rejects everything such a procedure rejects, for every vector of p-values. A gain beyond Holm's needs the dependence between the tests (Lessons 4 and 5). Lehmann and Romano prove the analogue for the k-FWER step-down of Lesson 5, whose constants for \(k = 1\) are Holm's: for every \(i \ge k\), no constant \(\alpha_i\) can be increased without violating control of the k-FWER.

Empirical

E1 · The FWER curve

Extend Lab 1 to \(\rho \in \{0, 0.25, 0.5, 0.75, 0.9, 0.99\}\). Before running, predict Bonferroni's FWER at the two ends using P1, then compare.

Solution

At \(\rho = 0\) the tests are independent, so the FWER is \(1 - (1 - 0.05/50)^{50} = 0.0488\). As \(\rho \to 1\) the statistics coincide, and by P1 the FWER tends to \(0.05/50 = 0.001\). Between the ends it falls steadily. Lab 1 already shows 0.029 at \(\rho = 0.5\) and 0.006 at \(\rho = 0.9\). At \(\rho = 0.99\) expect about 0.002: close to 0.001 but above it, because the idiosyncratic parts with standard deviation \(\sqrt{0.01} = 0.1\) still spread the maximum. With 20,000 replications the Monte Carlo standard error there is about \(\sqrt{0.002 \times 0.998/20000} = 0.0003\), so the ordering of the curve is reliable. E2 · How fragile was the published example?

In Lab 2, find the smallest two-sided t-statistic for test 6 at which Holm passes its fifth step, given the other nine tests. Then explain why test 2's decision changes together with test 6's.

Solution

At the fifth step the threshold is \(0.05/(10 + 1 - 5) = 0.008333\). A two-sided normal p-value of 0.008333 corresponds to \(|t| = \Phi^{-1}(1 - 0.008333/2) = 2.6383\). The published statistic, 2.64, exceeds it by 0.0017, so the exact p-value passes, while the rounded value of 0.84% does not. Test 2 has \(p = 0.85\%\), which would pass the sixth threshold of \(0.05/5 = 1\%\). But a step-down procedure never reaches step six if step five fails. The two decisions are linked: one p-value's third significant digit decides two rejections.

E3 · A simulated factor zoo

Simulate 200 one-sided factor tests (SIMULATED), 20 of them real with statistics centred at 3.5 and the rest null, all independent. Over 2,000 replications, record the number of false discoveries under naive 5% testing, Bonferroni and Holm. Predict the averages first.

Solution

Predictions. Naive testing rejects each of the 180 nulls with probability 0.05, so it averages \(180 \times 0.05 = 9\) false discoveries per study, almost one for every two real effects. Bonferroni at \(0.05/200\) averages \(180 \times 0.00025 = 0.045\) false discoveries, and its FWER is \(1 - (1 - 0.00025)^{180} = 0.044\). Holm's FWER is at most 0.05 and, with only 10% false nulls, close to Bonferroni's, as in Lab 3 with \(m_1 = 10\).

Code sketch. Reuse Lab 3 with m, n_reps = 200, 2000 and m1 = 20. For naive testing add naive = z > NormalDist().inv_cdf(0.95), then report rejected[:, ~is_false_null].sum(axis=1).mean() for each method. Your averages should match the predictions within Monte Carlo error. The standard error of the naive average is about \(\sqrt{180 \times 0.05 \times 0.95/2000} = 0.065\).

Research

R1 · Choosing the error rate

A fund's research committee approves signals for a production model. Argue when it should control the FWER and when a false-discovery criterion is acceptable. Use the economics of a false signal, not only statistics.

Solution

Control the FWER when a single false discovery is costly and not diluted. Examples are a standalone strategy receiving its own capital allocation, a regulatory capital model, or a published claim that others will build on. In these cases one error is one failure, and the committee is accountable for each decision.

A proportion criterion is acceptable when signals enter a diversified combination. Adding \(k\) weak signals to a model with many others, with position sizes shrunk by estimated strength, means a few false signals add noise and turnover cost rather than a directional bet. The expected cost of a false discovery is then small relative to the opportunity cost of rejecting real ones.

The quantitative test compares the expected loss from false inclusions (turnover, crowding, capacity used) with the expected gain from true inclusions missed under FWER control. Lab 3 shows that FWER control discards nearly half of real effects of moderate strength. A committee should also fix its family in advance (all signals reviewed in a year, say), because the choice of family changes \(m\).

R2 · Defining the family

A team of five researchers each tests 20 signals per year, and each researcher publishes internally the best two. What is \(m\) for (a) a researcher deciding which of their own signals to promote, (b) the head of research approving the year's promotions, and (c) an outside allocator reading one researcher's memo? Justify each answer.

Solution
  • (a) \(m = 20\). The researcher's decisions range over their own 20 tests.
  • (b) \(m = 100\). The head approves from the union of all tests run that year. Approving the top two of each researcher without accounting for the 18 unreported tests each would understate \(m\) by a factor of 10.
  • (c) Also at least \(m = 100\). The allocator sees two results but must correct for the search that produced them, which includes every researcher's tests that could have produced a memo. If the allocator would equally have read any of the five researchers' memos, the effective search is all 100 tests.

The principle: the family is every test whose outcome could have changed what you are now looking at. In practice that requires the trial log of Lesson 1's Problem R1.

R3 · Exploiting dependence safely

Lab 1 shows Bonferroni and Holm wasting most of their error budget when tests are highly correlated. Propose two ways to recover power while keeping strong FWER control, and state what each needs to be true.

Solution
  1. Estimate the joint null distribution of the maximum statistic and step down. Use the \((1-\alpha)\)-quantile of \(\max_{i \in J} Z_i\) over the remaining hypotheses \(J\) in place of \(\Phi^{-1}(1 - \alpha/|J|)\). This is Romano and Wolf's construction (Lesson 5). It needs a resampling scheme that reproduces the dependence across tests and over time, such as the stationary bootstrap of Lesson 4, and its guarantee is asymptotic rather than exact.
  2. Use closed testing with intersection tests that exploit the correlation, for instance a test of \(H_J\) based on the exact distribution of \(\max_{j \in J} Z_j\) under a known correlation matrix. Strong control then follows from P3's argument, but only if the correlation is known or estimated precisely enough that each intersection test keeps its level.

Both trade Bonferroni's assumption-free exactness for power. The trade is worth making when the dependence is strong and well estimated, as for overlapping variants of one strategy, and dangerous when the dependence is unstable over time.
