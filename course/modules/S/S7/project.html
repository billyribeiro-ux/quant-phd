Rungs 1 and 2

Lab 1 · Worked example: Benjamini–Hochberg, line by line

BH is a step-up procedure. Here the third-smallest p-value sits above its own line \(3q/m\), yet it is rejected because the fourth-smallest passes its line (L03).

import numpy as np
from numpy.typing import NDArray


def benjamini_hochberg(pvalues: NDArray[np.float64], q: float) -> NDArray[np.bool_]:
    """Benjamini-Hochberg step-up at FDR level q; returns a mask in the input order."""
    if not 0.0 < q < 1.0:
        raise ValueError("q must lie strictly between 0 and 1")  # a level of 0 or 1 is not a test
    p = np.asarray(pvalues, dtype=np.float64)
    if p.ndim != 1 or np.any(~np.isfinite(p)) or np.any((p < 0.0) | (p > 1.0)):
        raise ValueError("pvalues must be a 1-D array in [0, 1]")
    m = p.size
    if m == 0:
        return np.zeros(0, dtype=bool)  # no hypotheses, no rejections
    order = np.argsort(p)  # any sort order gives the same mask: ties never straddle k*
    lines = q * np.arange(1, m + 1) / m  # the BH line k*q/m for k = 1..m
    below = np.nonzero(p[order] <= lines)[0]  # every k whose ordered p-value is under its line
    reject = np.zeros(m, dtype=bool)
    if below.size:
        k_star = below[-1] + 1  # step-UP: the LARGEST passing k, not the first failure
        reject[order[:k_star]] = True  # reject the k* smallest p-values, including any above their own line
    return reject


# Eight p-values from a hypothetical strategy grid (illustrative inputs, not data).
p = np.array([0.041, 0.001, 0.300, 0.012, 0.024, 0.700, 0.020, 0.049])
mask = benjamini_hochberg(p, 0.05)
print("rejected (input order):", "".join("R" if r else "." for r in mask))
print("number rejected:", int(mask.sum()))
print("largest rejected p-value:", f"{p[mask].max():.3f}")
third = float(np.sort(p)[2])
print(
    "third-smallest p-value:",
    f"{third:.3f}",
    "| its own line:",
    f"{3 * 0.05 / p.size:.4f}",
    "| rejected:",
    bool(third <= p[mask].max()),
)
rejected (input order): .R.RR.R.
number rejected: 4
largest rejected p-value: 0.024
third-smallest p-value: 0.020 | its own line: 0.0188 | rejected: True

The comments carry the reasons. Ties cannot straddle \(k^\ast\): if \(p_{(k)} = p_{(k+1)}\) and \(k\) passes its line, so does \(k + 1\), so the mask is the same for any sort order. The mask is returned in input order because callers index trials, not ranks. The procedure looks for the largest passing \(k\). An implementation that stops at the first p-value above its line is step-down. It would reject only two hypotheses here, and the autograder's test test_bh_steps_up_not_down rejects it.

Rung 3 · Specification

Context
A research desk evaluates hundreds of strategy configurations a week and proposes a few for capital. The investment committee will no longer accept a Sharpe ratio without the number of trials behind it, the probability that the selection overfit, and multiple-testing-adjusted decisions. Atlas A9, the backtester, will call your module on every result it returns.
Inputs
Your instance comes from grader/instance.py, seeded by your workspace ID. It holds a set of p-values with a planted share of true effects, a skewed return series for the proposed strategy, the Sharpe ratios of the trials behind it, a trial-by-period backtest matrix, and performance differentials with a common factor and serial correlation. All data are SIMULATED, so no market data are needed.
Required outputs
One file, atlas/integrity.py, implementing exactly the interface in the A8 contract: sharpe_ratio, sample_skewness, sample_kurtosis, sharpe_ratio_std, probabilistic_sharpe_ratio, expected_max_sharpe, deflated_sharpe_ratio, benjamini_hochberg, stationary_bootstrap_indices, stepdown_rejections, romano_wolf, probability_of_backtest_overfitting with PBOResult, TrialSet with from_backtest, and integrity_report with IntegrityReport. Start from the starter file, whose dataclasses are complete.
Constraints
Use NumPy and the Python standard library only. Functions are pure: they validate inputs, raise ValueError naming the violated condition, and never print, warn or mutate their arguments. Follow the contract's conventions exactly: ddof, moment estimators, \(T-1\) in the standard error, step-up BH, the order-statistic critical value, the CSCV row-dropping rule, average ranks and the combination order. Series and p-value inputs are one-dimensional; a CSCV half-sample needs at least 2 periods, so integrity_report needs \(T \ge 4\); a series or column whose values are all equal has zero variance (test equality, not std == 0), and a constant resampled column in romano_wolf is studentized by its sample standard deviation. Every statistic is unchanged when the returns are multiplied by a power of two that keeps them exact (the contract's Scale row), and no function may warn at any magnitude or for NumPy scalar arguments, so rescale each series, column, bootstrap resample and CSCV subsample by its own power of two before squaring, and convert scalars with float(), and accept NumPy integers and integral floats below 2**1000 wherever an integer is expected. A bootstrap statistic too large for a float is \(\pm\infty\) and ranks as its true value would. The whole suite must finish within 60 seconds in your browser.
Grading mode
Autograded by grader/test_project.py: 130 checks of definitions, numbers to stated tolerances, invariants (step-up behaviour, nesting in \(\alpha\), joint resampling, studentization of every bootstrap draw, average ranks for ties) and failure behaviour, run with warnings as errors, plus a check that the module imports only NumPy and the standard library. The same file runs in your browser and on your machine. It is not secret. Its integrity comes from your seeded instance, and the credential is the module you can show and defend.

The A8 contract, in brief

The binding text is atlas/A8.contract.md in the program repository, and later milestones depend on it, so it is frozen once released. Its key conventions are these:

  • Sharpe ratios are per period, \(\bar r / s\) with \(s\) using ddof = 1. Skewness and kurtosis are the moment estimators \(m_3/m_2^{3/2}\) and \(m_4/m_2^2\), and kurtosis is not excess.
  • \(\operatorname{se}(\hSR) = \sqrt{(1 - \gamma_3\hSR + \tfrac{\gamma_4 - 1}{4}\hSR^2)/(T-1)}\). PSR is \(\Phi((\hSR - \SR^\ast)/\operatorname{se})\), and DSR is the PSR at \(\SR_0\) given by L01's expected-maximum formula, with the trial variance taken at ddof = 1.
  • BH rejects the \(k^\ast\) smallest p-values, \(k^\ast = \max\{k : p_{(k)} \le kq/m\}\), with the mask in input order.
  • The stationary bootstrap starts a new block with probability \(1/b\) at each step and wraps around. Romano–Wolf draws its \(B\) index vectors in order, each by stationary_bootstrap_indices(T, mean_block, rng) from the single rng = np.random.default_rng(seed); it uses studentized statistics, resamples whole periods jointly, and takes as critical value the \(\lceil (1-\alpha)B\rceil\)-th smallest bootstrap maximum over the active set.
  • CSCV uses an even \(S\), drops the oldest \(T \bmod S\) rows, and takes all \(\binom{S}{S/2}\) splits in itertools order. Ranks are average ranks, \(\omega = \text{rank}/(N+1)\), and PBO is the share of logits at or below zero.

Paste or load your atlas/integrity.py and run the suite on your own instance. Your code is saved in this browser as you type.

Running the suite locally

Atlas lives in your own git repository (BLUEPRINT §5.1). Copy test_project.py and instance.py next to your repository's atlas package, then run, with the seed shown in the autograder panel:

QF_SEED=<your seed> pytest -q -p no:cacheprovider --assert=plain -W error test_project.py

--assert=plain keeps the failure messages to the property that failed, and -W error turns warnings into failures, both as in the browser. Use Python 3.12 or later with NumPy 2.2 and pytest 8.3.
