Rungs 1 and 2

Lab 1 · Worked example: Benjamini–Hochberg, line by line

BH is a step-up procedure. Here the third-smallest p-value sits above its own line \(3q/m\), yet it is rejected because the fourth-smallest passes its line (L03).

import numpy as np
from numpy.typing import NDArray


def benjamini_hochberg(pvalues: NDArray[np.float64], q: float) -> NDArray[np.bool_]:
    """Benjamini-Hochberg step-up at FDR level q; returns a mask in the input order."""
    if not 0.0 < q < 1.0:
        raise ValueError("q must lie strictly between 0 and 1")  # a level of 0 or 1 is not a test
    p = np.asarray(pvalues, dtype=np.float64)
    if p.ndim != 1 or np.any(~np.isfinite(p)) or np.any((p < 0.0) | (p > 1.0)):
        raise ValueError("pvalues must be a 1-D array in [0, 1]")
    m = p.size
    if m == 0:
        return np.zeros(0, dtype=bool)  # no hypotheses, no rejections
    order = np.argsort(p)  # any sort order gives the same mask: ties never straddle k*
    lines = q * np.arange(1, m + 1) / m  # the BH line k*q/m for k = 1..m
    below = np.nonzero(p[order] <= lines)[0]  # every k whose ordered p-value is under its line
    reject = np.zeros(m, dtype=bool)
    if below.size:
        k_star = below[-1] + 1  # step-UP: the LARGEST passing k, not the first failure
        reject[order[:k_star]] = True  # reject the k* smallest p-values, including any above their own line
    return reject


# Eight p-values from a hypothetical strategy grid (illustrative inputs, not data).
p = np.array([0.041, 0.001, 0.300, 0.012, 0.024, 0.700, 0.020, 0.049])
mask = benjamini_hochberg(p, 0.05)
print("rejected (input order):", "".join("R" if r else "." for r in mask))
print("number rejected:", int(mask.sum()))
print("largest rejected p-value:", f"{p[mask].max():.3f}")
third = float(np.sort(p)[2])
print(
    "third-smallest p-value:",
    f"{third:.3f}",
    "| its own line:",
    f"{3 * 0.05 / p.size:.4f}",
    "| rejected:",
    bool(third <= p[mask].max()),
)
rejected (input order): .R.RR.R.
number rejected: 4
largest rejected p-value: 0.024
third-smallest p-value: 0.020 | its own line: 0.0188 | rejected: True

The comments carry the reasons. Ties cannot straddle \(k^\ast\): if \(p_{(k)} = p_{(k+1)}\) and \(k\) passes its line, so does \(k + 1\), so the mask is the same for any sort order. The mask is returned in input order because callers index trials, not ranks. The procedure looks for the largest passing \(k\). An implementation that stops at the first p-value above its line is step-down. It would reject only two hypotheses here, and the autograder's test test_bh_steps_up_not_down rejects it.

Constraints
Use NumPy and the Python standard library only. Functions are pure: they validate inputs, raise ValueError naming the violated condition, and never print, warn or mutate their arguments. A bootstrap statistic too large for a float is \(\pm\infty\) and ranks as its true value would. The whole suite must finish within 60 seconds in your browser. The memo reviews the grid as it was run: no new trials or data, and checks that vary only a tool's setting. The brief sets its rules for length and for numbers. Your module's DSR and 16-block PBO must equal those that Lesson 8's Lab 4 prints, which come from the same matrix; if they differ, fix the module before writing.

The A8 contract, in brief

The binding text is atlas/A8.contract.md in the program repository, and later milestones depend on it, so it is frozen once released. Its key conventions are these:

  • Sharpe ratios are per period, \(\bar r / s\) with \(s\) using ddof = 1. Skewness and kurtosis are the moment estimators \(m_3/m_2^{3/2}\) and \(m_4/m_2^2\), and kurtosis is not excess.
  • \(\operatorname{se}(\hSR) = \sqrt{(1 - \gamma_3\hSR + \tfrac{\gamma_4 - 1}{4}\hSR^2)/(T-1)}\). PSR is \(\Phi((\hSR - \SR^\ast)/\operatorname{se})\), and DSR is the PSR at \(\SR_0\) given by L01's expected-maximum formula, with the trial variance taken at ddof = 1.
  • BH rejects the \(k^\ast\) smallest p-values, \(k^\ast = \max\{k : p_{(k)} \le kq/m\}\), with the mask in input order.
  • The stationary bootstrap starts a new block with probability \(1/b\) at each step and wraps around. Romano–Wolf draws its \(B\) index vectors in order, each by stationary_bootstrap_indices(T, mean_block, rng) from the single rng = np.random.default_rng(int(seed)); it uses studentized statistics, resamples whole periods jointly, and takes as critical value the \(\lceil (1-\alpha)B\rceil\)-th smallest bootstrap maximum over the active set.
  • CSCV uses an even \(S\), drops the oldest \(T \bmod S\) rows, and takes all \(\binom{S}{S/2}\) splits in itertools order. Ranks are average ranks, \(\omega = \text{rank}/(N+1)\), and PBO is the share of logits at or below zero.

import csv
import itertools
import math

import numpy as np
from numpy.typing import NDArray

# The memo's trial set: Lesson 8, Lab 4's grid, rebuilt from the same file with the same code.
# Month-end spot rates, USD per unit of foreign currency (Federal Reserve H.10 noon buying rates in New York).
with (Path("data") / "fx_monthly.csv").open(newline="", encoding="utf-8") as handle:
    rows = list(csv.reader(handle))
currencies, months = rows[0][1:], [row[0] for row in rows[1:]]
prices = np.array([[float(v) if v else math.nan for v in row[1:]] for row in rows[1:]])
start = int(np.argmax(~np.isnan(prices).any(axis=1)))  # the first month in which every currency has a rate
print(f"fx_monthly.csv: {len(months)} months from {months[0]} to {months[-1]}")

months, log_p = months[start:], np.log(prices[start:])
spot = np.exp(np.diff(log_p, axis=0)) - 1.0  # spot[t - 1]: simple spot return over month t, long the currency
grid = list(itertools.product((1, 3, 6, 9, 12), (1, 3, 6, 12), (0, 1)))  # lookback, holding, skip, in months
first = max(h for _, h, _ in grid) + max(s for _, _, s in grid) + max(lb for lb, _, _ in grid)


def sign_rule(lookback: int, hold: int, skip: int) -> NDArray[np.float64]:
    """Monthly spot return, months first..last, of one sign rule: each currency is held long (short) when its
    lookback-month log change, ending `skip` months before formation, is positive (negative); positions formed at
    each of the last `hold` month-ends are averaged, and currencies are equally weighted."""
    t = np.arange(first, len(months))
    weight = np.zeros((t.size, len(currencies)))
    for h in range(1, hold + 1):
        end = t - h - skip  # the signal formed at the end of month t - h uses prices up to month t - h - skip
        weight += np.sign(log_p[end] - log_p[end - lookback])
    return np.asarray((weight / hold * spot[t - 1]).mean(axis=1))


trials = np.column_stack([sign_rule(*spec) for spec in grid])  # (T, N): the TrialSet's returns, column n = grid[n]
n_obs, n_trials = trials.shape
labels = [f"L{lb}-H{h}-skip{s}" for lb, h, s in grid]
sharpe = trials.mean(axis=0) / trials.std(axis=0, ddof=1)
pick = int(np.argmax(sharpe))  # the TrialSet's `selected`: the highest full-sample Sharpe ratio
print(f"prices from {months[0]}; returns from {months[first]} to {months[-1]}")
print(f"trial matrix: {n_obs} months x {n_trials} trials, columns in grid order (lookback, holding, skip)")
print(f"checksums: sum {trials.sum():.10f} sum of squares {(trials**2).sum():.10f}")
print("annualized Sharpe ratio by lookback (rows) and holding period, skip 0 then skip 1 (columns)")
print("lookback " + " ".join(f"H{h}s{s}" for s in (0, 1) for h in (1, 3, 6, 12)))
for lookback in (1, 3, 6, 9, 12):

The brief

Write to the committee, not to a statistician: define each statistic once, in a sentence, with its unit. Use these five sections, in this order and under these headings.

  1. Recommendation: fund, do not fund, or fund on stated conditions; the decision rule, with a threshold for each statistic it uses, fixed before you read the report; and the statistics that decide it.
  2. The proposal and the search: the selected rule in words; the grid; the number of trials and how they were logged; the window and the number of months; and the choices the trial count does not include.
  3. Evidence: the evidence table below, then one paragraph each on the deflated Sharpe ratio, the PBO, and StepM with Benjamini–Hochberg. Each paragraph says what the tool asks, what its number says, and what it does not say.
  4. Limitations: what spot returns leave out (Lesson 5, Section 8, equation (4)), trading costs, and the limits of the sample. The strongest memos also name the assumption of each tool that these data put most at risk (rubric C6, level 4).
  5. What would change the decision: at least two pieces of further evidence, each with the result that would change or confirm the recommendation, fixed before the evidence is seen. Specify them here; running one is a stretch (§8).

Length. The body text runs 1,200 to 1,800 words, and the Recommendation at most 100 of them. Body text is every word in the five sections' paragraphs and lists; headings, a To/From header block and the evidence table do not count. A word is a run of characters between spaces, so 2001-02 and 0.489 count as one word each.

Numbers. Every number the memo takes from the review, statistics, counts and dates alike, is printed by memo/run_memo.py. A measured statistic carries at most four significant digits and its unit (per month, or annualized by \(\sqrt{12}\)); counts, dates and the tools' settings are exact, so the number of splits is written in full. Two kinds of number need not come from the script: your decision thresholds, which the Recommendation states as your choice, and figures quoted from the lessons, which name their lesson and lab.

What may vary. No new trials and no new data. The evidence uses the contract's defaults; a check may vary only a tool's setting (the number of blocks, the mean block length, or the effective number of trials paired with the single-trial variance), and is labelled as a check.

Scoring. Each criterion of the rubric below scores the highest level whose every element the memo shows. Each level contains the one below it: level 4 is level 3 plus the elements its cell names; level 2 is any attempt that misses an element of level 3 or makes a misreading its cell names; level 1 is the absence its cell names. The memo meets the bar when it scores level 3 or above on every criterion, brief compliance (C7) included, so a memo without the evidence table, with a section missing, or with a body outside 1,200 to 1,800 words does not meet it.

Two exemplars

Two memos written to this brief, at different levels. Their statistics are what a correct A8 module prints for this trial set, so they double as a check on yours; the effective-number figures and the grid's own null (the 100 resampled grids, their mean PBO and the share at or above the observed PBO) come from Lesson 8's Lab 4, and the mean and volatility from the trial matrix itself. A repository test pins each number to the code that computes it. Each passage carries an annotation naming the descriptors it meets or misses. With JavaScript on, the annotations stay hidden until you reveal the official scoring with the form below, so score both exemplars first.

Exemplar A

Official scoring: level 2 overall (C1 2 · C2 2 · C3 2 · C4 2 · C5 3 · C6 2 · C7 1). The memo reaches a recommendation the evidence it reports does not support, reads three statistics as probabilities they are not, misses the spot-only limitation, and ignores the brief's form: it has no evidence table, its headings are not the brief's, and its body text runs to 322 words.

Recommendation

We recommend a small pilot allocation to the selected rule, L1-H3-skip0, with a review after one year. The rule has a positive Sharpe ratio, and its probabilistic Sharpe ratio of 77% says it is more likely than not to be a real strategy. The risks are manageable at pilot size.

  • Meets C1 level 2: a recommendation with a stated reason.
  • Misses C1 level 3: the reason is the PSR against zero, which ignores the search, so the recommendation contradicts the DSR, PBO and test results the memo itself reports below.
The search

The research team tested 40 combinations of lookback (1, 3, 6, 9 and 12 months) and holding period (1, 3, 6 and 12 months), with and without a skip month, on 10 currencies from 2001-02 to 2026-09, 308 months in all. All 40 combinations were run on the same months, and all of them are included here. The best combination uses a one-month lookback and a three-month holding period. Other choices, such as the sample period, were also made, but the grid covers the main parameters.

  • Meets C5 level 3: states N, says which trials were kept (all of them) and on which months they were evaluated (the same ones), and names one choice N does not count, the sample period.
  • Misses C5 level 4: does not say whether the record shows when the grid was fixed, so it never reads N as a lower bound on the search; names only one uncounted choice; calls the grid "the main parameters", and gives no effective number of trials.
Performance

The selected rule has an annualized Sharpe ratio of 0.14, positive over more than two decades of data. Its PSR of 77% means there is a 77% probability that the strategy is profitable. After adjusting for the number of combinations tested, the deflated Sharpe ratio is 0.49, which is close to a coin flip: about a 49% chance that the rule has real skill. This is lower than we would like, but it is not zero.

  • Meets C2 level 2: reports the DSR, but leads with the raw Sharpe ratio and the PSR against zero.
  • Misses C2 level 3: no hurdle and no trials' dispersion next to the DSR, and both the PSR and the DSR are read as probabilities that the rule is good. Each is one minus a p-value.
Overfitting

The probability of backtest overfitting is 73%. This means there is a 73% chance that the strategy will lose money out of sample, which is a real risk and one reason we recommend starting small.

  • Meets C3 level 2: reports the PBO.
  • Misses C3 level 3: reads the PBO as a loss probability (Lesson 8, Misconception 1) and compares it with nothing; the reference value of one half and the number of blocks are missing.
Statistical tests

Neither StepM nor Benjamini–Hochberg found any significant rules. These tests are designed to be very conservative when many strategies are tested, so it is not surprising that nothing passed, and we do not think this should count against the rule.

  • Meets C4 level 2: reports the outcome of both tests.
  • Misses C4 level 3: no counts, levels or bootstrap parameters, and the non-rejections are dismissed as conservatism without argument. Benjamini–Hochberg controls the false discovery rate, the less demanding target of Lesson 3, and it also rejects nothing.
Limitations

The backtest does not include transaction costs, so real returns would be somewhat lower. The data also stop in 2026-09. Before full deployment we would monitor the pilot for a year to confirm the results.

  • Meets C6 level 2: names two limitations, trading costs and the end of the data, but not the omitted interest differential.
  • Misses C6 level 3: never says the returns are spot returns that omit each position's interest differential, which can bias them either way, and implies the omissions can only lower returns. "Monitor the pilot" is one piece of further evidence, with no result that would change the decision; level 3 needs two, each with that result.
  • Meets C7 at level 1 only: the memo has no evidence table; of its six headings only Recommendation and Limitations are the brief's ("The search" is not "The proposal and the search", and Performance, Overfitting and Statistical tests replace Evidence); there is no "What would change the decision" section; and the body text runs to 322 words against the 1,200 the brief requires.
  • Misses C7 level 2: it has neither the evidence table nor three of the five sections.

Exemplar B

Official scoring: level 4 overall (C1 4 · C2 4 · C3 4 · C4 3 · C5 4 · C6 4 · C7 4). The memo states its decision rule before its evidence, reads every statistic for the question it answers, and specifies further evidence with the results that would change its mind. It falls short of level 4 once: it never says how large an edge the sample could have detected.

To: Investment Committee. From: Research integrity review. Re: the currency sign-rule proposal L1-H3-skip0. Data: Federal Reserve H.10 month-end noon buying rates, retrieved 2026-10-17. Statistics: our A8 integrity module, run with the contract's defaults.

Recommendation

Do not fund. Before the review we chose the bar a strategy must clear: a DSR of at least 0.95, a PBO below 0.5 with 8, 10 and 16 blocks, and at least one StepM rejection against cash. The proposal clears none of the three. Its DSR is 0.489: its Sharpe ratio is about what the luckiest of 40 skill-free rules would show. Its PBO of 0.733 is consistent with a selection that carries no information on these data. Neither StepM nor Benjamini–Hochberg finds any of the 40 rules better than cash.

  • Meets C1 level 4: the decision comes first; the reason cites all three results; the decision rule was fixed before the evidence, with a numeric threshold for each statistic it uses; nothing later contradicts it.
The proposal and the search

The proposal is a sign rule on 10 currencies against the dollar. At each month-end it goes long every currency whose spot rate rose over the past month and short every currency whose rate fell, holds each month's positions for three months, and weights the currencies equally. It is the best, by full-sample Sharpe ratio, of a grid of 40 rules: lookbacks of 1, 3, 6, 9 and 12 months and holding periods of 1, 3, 6 and 12 months, each with and without a one-month skip. Its lookbacks and holding periods lie within the horizons of the published evidence on such rules (Lesson 8, Section 6). Every rule was kept, and all 40 were evaluated on the same 308 months, 2001-02 to 2026-09, so the trial matrix holds every trial the record shows. Lab 3 rebuilds it from the published file and prints two checksums, so anyone on the committee's staff can confirm that they are reviewing the same trials. What the record cannot show is when the grid was chosen. Its code and its output were published together, so nothing in it shows that the grid was fixed before the data were seen, or that no other grid was tried first.

Nor does the record count the choices made before the grid: the window, which opens in 1999-01, the first month in which all 10 currencies have a rate; the currency set; equal weighting; the sign of the past change as the signal; and the full-sample Sharpe ratio as the selection metric. The count of 40 is therefore a floor on the search, not its size (Lesson 1, Section 7), and a larger search could only raise the hurdle below. The rules are also closely related. Their mean pairwise correlation is 0.567. Their correlation matrix has a participation ratio of 2.37, and treating them as equicorrelated at that mean gives a matching effective number of 7.74 independent trials (Lesson 7, Section 4). The A8 contract pairs the raw count with the cross-sectional variance of the trials' Sharpe ratios, which already reflects their correlation (Lesson 7, Proposition 4.2). The effective count appears below as a check, paired with the single-trial variance as Lesson 7 prescribes.

  • Meets C5 level 4: states N and what the record shows (every trial kept, common months); says the record cannot show that the grid was fixed before it was run, and reads N as a floor on the search; names five choices N does not count; and reports an effective number with its estimator while explaining why A8 pairs the raw count with the cross-sectional variance.

Deflated Sharpe ratio. The annualized Sharpe ratio of 0.141 means little by itself, because it is the largest of 40. The DSR asks whether it beats the Sharpe ratio the best of 40 skill-free rules would show, 0.0424 per month, which Lesson 7's formula builds from the cross-sectional standard deviation of the 40 Sharpe ratios, 0.0193. The rule's 0.0408 falls just short of that hurdle. Its skewness of 1.57 and kurtosis of 15.2 enter the standard error, and the DSR is 0.489: one minus a one-sided p-value of 0.51 against the hurdle. It is not a probability that the rule has skill. Before the search is counted at all, the PSR against zero is 0.770, one minus a p-value of 0.23. Pairing the effective number of trials, 7.74, with the single-trial variance raises the hurdle to 0.0821 per month and lowers the DSR to 0.228. Under either pairing the DSR is far below our bar of 0.95.

  • Meets C2 level 4: the DSR comes with N, the trials' dispersion, the hurdle, the higher moments and the PSR against zero; it is read as one minus a p-value, not a probability of skill; and the raw Sharpe ratio appears only against its hurdle.

Probability of backtest overfitting. PBO asks a different question: does picking the in-sample best carry information out of sample? The months were cut into 16 blocks of 19 months, after dropping the oldest 4, and each of the 12,870 ways of choosing half the blocks served as the in-sample half. The in-sample best ranked at or below the out-of-sample median in 73.3% of those splits. One half is a reference value here, not this grid's null expectation: Lesson 8's Theorem 4.1 gives it for exchangeable trials on independent months, and these rules differ in design and hold overlapping positions. Lesson 8's Lab 4 computes the grid's own null instead, rebuilding all forty rules on 100 histories of resampled months, on which no rule can time the currencies. There the PBO averages 0.527, and 21% of the null grids reach 0.733 or more, so this estimate is consistent with an uninformative selection. With 8 and 10 blocks the estimate is 0.743 and 0.714. A PBO of 0.733 is not a 73% chance of losing money, which PBO does not measure, and it is not evidence that the rules have negative skill.

  • Meets C3 level 4: says what PBO measures, compares it with one half as a reference value and says why it is no more than that, shows how noisy one estimate is with the grid's own null and two more block counts, and rules out the loss-probability and negative-skill readings.

Multiple testing against cash. Each rule's null hypothesis is a mean spot return at or below zero. StepM, which controls the family-wise error rate at 0.05, rejects 0 of the 40, and Benjamini–Hochberg, which controls the false discovery rate at 0.05, rejects 0. StepM used 1,000 joint stationary-bootstrap draws with mean block length 10 and seed 0, and gives the same answer with block lengths 5 and 20. The smallest one-sided p-value, the selected rule's, is 0.237, and 0 rules have a p-value at or below 0.05 before any correction. Failing to reject is not proof that the rules have no edge. It says that 308 months of spot returns do not establish one.

  • Meets C4 level 3: both counts with their levels and the bootstrap's parameters, the FWER and FDR targets told apart, and non-rejection read as an absence of evidence.
  • Misses C4 level 4: it never says how large an edge the sample could have detected, for example the Sharpe ratio a rule would need to clear StepM's first critical value, so the committee cannot tell a weak test from a weak rule.
Limitations

The returns are spot returns of a dollar investor, not the returns a desk would earn. A long currency position also earns the interest differential between the currency and the dollar, and a short one pays it (Lesson 5, Section 8, equation (4)). The H.10 files contain no interest rates, so every trial return omits that carry, and none is charged trading costs. Carry can raise or lower each rule's mean, depending on whether the rule tends to be long the higher-yielding currencies, so it could reorder the 40 rules and change every statistic above. It matters here because the selected rule's mean spot return is only 0.55% a year, on a volatility of 3.91%. Costs lower every rule, most for the rules that trade most. The sample is one window, 308 months of ten currencies from 2001-02, so nothing here tests the rules before the euro or in other currencies. Each tool also rests on an assumption these data strain: the DSR on an approximately normal Sharpe-ratio estimate, against a kurtosis of 15.2; PBO on blocks that are comparable across the window; StepM on stationarity, for the bootstrap.

  • Meets C6 level 4, in part: the returns are named as spot returns, not tradable excess returns; the omitted carry is explained with Lesson 5's identity, with a bias of either sign, and sized against the rule's own mean; costs, the limits of the sample and each tool's assumption at risk are added.
What would change the decision

Three pieces of evidence could change it. Each is specified here, before it is seen.

  • Carry-inclusive returns. Rebuild the 40 trials with each position's interest differential, from one-month deposit or forward rates for the same currencies and months, and rerun this review unchanged. We would reconsider only if the rule then selected clears the same bar: a DSR of at least 0.95, a PBO below 0.5 with 8, 10 and 16 blocks, and at least one StepM rejection against cash.
  • A holdout. The file holds 1971-01 to 1998-12 for 9 of the 10 currencies, and no part of this review used those years. Run L1-H3-skip0 on them unchanged, on the currencies available there. A one-sided t-test of its mean spot return that fails to reject at 5% would count against this rule on spot rates; a rejection would justify the carry-inclusive review, not funding.
  • Costs. Estimate the rule's turnover and charge a cost per unit traded. If its mean spot return net of costs is negative, a carry-inclusive result would have to clear the bar on its own.

None of the three can make the rule fundable by itself. Each can only reopen the review, which would then be run again in full, with the new trials added to the log.

  • Meets C6 level 4: three pieces of further evidence, each with the result that would change or confirm the decision, fixed before the evidence is seen.
  • Meets C7 level 4: the five sections under the brief's headings and in its order; every required row of the evidence table, the window included; 1,352 words of body text and a Recommendation of 92 words; every number taken from the review, with the thresholds stated as the review's own choice and Lab 4's null figures named with their lesson.

Rung 4 · Stretch

  • Holm, Benjamini–Yekutieli and SPA. Add them to A8 with the same validation discipline, and add tests in the style of the suite that kill the plausible wrong versions you can think of.
  • An effective number of trials. Estimate it from the trials' correlation matrix (L07), report the DSR under each estimate, and show how sensitive the decision is.
  • HAC-studentized StepM. Replace the iid studentization with a Newey–West standard error inside each bootstrap draw. Measure the size of both versions under a serially correlated null.
  • An audit. Take a published strategy grid you can reconstruct from data you may use (the French data library, for example, in bring-your-own-data mode, since its files carry no redistribution grant) and write the integrity report an investment committee should have seen.
  • The memo's further evidence. Run what your memo's fifth section specified, with the decision rule it fixed: the selected rule on the months the review did not use, or carry-inclusive returns. The embedded files contain no foreign interest rates, so carry needs deposit or forward rates you supply in bring-your-own-data mode. Report the result whatever it shows.
