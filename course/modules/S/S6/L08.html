Placebo Tests & Permutation Inference

Falsification Designs, Exclusion Buffers, and Multi-Date False Discovery

Why It Matters

In quantitative research, finding a statistically significant abnormal return or treatment effect is never sufficient to establish causality. Apparent significance can arise from underlying time trends, unmodeled volatility clusters, or researcher specification searching. A placebo test serves as an empirical falsification diagnostic: by executing the exact econometric pipeline on artificial dates or untreated securities where no causal effect could possibly exist, researchers verify that their test statistics achieve nominal size control. If a pipeline detects spurious abnormal returns on fake dates, any causal claim on true announcement dates is immediately invalidated.

1. Falsification Strategies: In-Time and In-Space Placebos

A rigorous causal design must withstand falsification tests where the true treatment effect is known a priori to be zero.

Definition 1.1 · Placebo Test

A placebo test (or falsification test) is an empirical diagnostic procedure that applies an estimation pipeline to an artificial intervention known to have no genuine economic effect, verifying whether the empirical rejection rate adheres to the nominal significance level \(\alpha\).

Placebo tests are categorized along two fundamental dimensions:

  • In-Time Placebo (Temporal Falsification): The true treated units are assigned artificial event dates \(\tau_{\text{fake}}\) outside the true event window. If the pipeline detects significant abnormal returns on non-event days, the normal-return model is misspecified or contaminated by pre-event trends.
  • In-Space Placebo (Cross-Sectional Falsification): The true event date is assigned to untreated control units. If untreated securities exhibit significant pseudo-reactions, the estimated effect is driven by market-wide shocks rather than the specific policy intervention.

Angrist and Pischke (2009) highlight placebo checks as the premier diagnostic against omitted variable bias and spurious trends in quasi-experimental policy evaluations.

Definition 1.2 · Placebo Exclusion Buffer

To prevent contaminating the null distribution with true event dynamics, artificial placebo dates \(\tau_{\text{fake}}\) must satisfy a strict exclusion buffer:

\[ |\tau_{\text{fake}} - \tau_{\text{true}}| > h_{\text{buffer}}, \]

where \(h_{\text{buffer}}\) covers the event window and the parameter estimation window. Any placebo date falling within the buffer of an actual event is discarded.

2. Multi-Date Testing and Family-Wise False Discovery

When an empirical analyst runs \(m\) separate placebo date tests to stress-test an event study model, the probability of encountering false positive rejections accumulates rapidly.

Theorem 1.1 · Multi-Date False Discovery Probability Under Independence

Assumptions:

  1. Valid Null Model (A1): The true abnormal return on every placebo date is zero (\(H_0: AR_{\tau} = 0\)).
  2. Nominal Size Control (A2): Each individual test statistic has an exact false rejection probability \(\Prob(|T_j| > c_{\alpha}) = \alpha\) for all \(j \in \{1, \dots, m\}\).
  3. Mutual Independence (A3): The test statistics \(\{T_1, \dots, T_m\}\) across the \(m\) selected placebo dates are mutually statistically independent.

Conclusion: The probability of observing at least one false positive rejection across the family of \(m\) independent placebo tests is:

\[ \Prob(\text{At least one false rejection}) = 1 - (1 - \alpha)^m. \]
Proof

Let \(E_j\) denote the event that test \(j\) falsely rejects the null hypothesis, with \(\Prob(E_j) = \alpha\). The complement event \(E_j^c\) that test \(j\) correctly retains the null occurs with probability \(\Prob(E_j^c) = 1 - \alpha\).

The event that zero false rejections occur across all \(m\) tests is the joint intersection \(\bigcap_{j=1}^m E_j^c\). By mutual independence (assumption A3), the joint probability factors as the product of marginal probabilities:

\[ \Prob\left(\bigcap_{j=1}^m E_j^c\right) = \prod_{j=1}^m \Prob(E_j^c) = (1 - \alpha)^m. \]

The probability of observing at least one false rejection is the complement of zero rejections:

\[ \Prob\left(\bigcup_{j=1}^m E_j\right) = 1 - \Prob\left(\bigcap_{j=1}^m E_j^c\right) = 1 - (1 - \alpha)^m. \]

This completes the derivation.

Remark 1.1 · The Burden of Multiple Placebo Dates

For a standard nominal level \(\alpha = 0.05\):

  • For \(m = 1\) placebo date: \(\Prob(\text{False Reject}) = 0.0500\) (5.0%).
  • For \(m = 5\) independent dates: \(1 - (0.95)^5 = 1 - 0.7738 = 0.2262\) (22.6%).
  • For \(m = 10\) independent dates: \(1 - (0.95)^{10} = 1 - 0.5987 = 0.4013\) (40.1%).
  • For \(m = 20\) independent dates: \(1 - (0.95)^{20} = 1 - 0.3585 = 0.6415\) (64.2%).

An analyst who evaluates 10 independent placebo dates has a 40.1% baseline probability of seeing at least one date falsely reject at the 5% level entirely by chance.

3. Empirical Demonstration: Multi-Date Falsification Benchmark

We execute a Monte Carlo simulation of 2,500 trials under the true null hypothesis. In each trial, an analyst tests \(m = 10\) independent placebo dates at nominal significance level \(\alpha = 0.05\) using critical value \(\pm 1.96\).

Lab 1 · Multi-Date Placebo False Discovery (SIMULATED)

Across 2,500 trials with m = 10 independent dates at nominal alpha = 0.05, individual dates reject at 0.0517 while the multi-date family rejection rate reaches 0.4196, aligning with the theoretical probability 1 - (1 - 0.05)^10 = 0.4013 within 0.02.

"""Lab S6-L08-1: Placebo event tests and multiple testing false rejection rates.

SIMULATED: evaluates false positive rates for placebo event dates under the null hypothesis,
verifying that individual placebo tests reject at nominal alpha while the family-wise
false discovery probability across m independent placebo dates scales as 1 - (1 - alpha)^m.
"""

from __future__ import annotations

import random


def main() -> None:
    rng = random.Random(2026)
    trials = 2500
    m_dates = 10
    alpha = 0.05
    crit_val = 1.96  # Two-sided standard normal critical threshold

    # Theoretical probability of at least one false rejection across m independent dates
    theoretical_family_rate = 1.0 - (1.0 - alpha) ** m_dates

    total_single_tests = 0
    total_single_rejections = 0
    trials_with_any_rejection = 0

    for _ in range(trials):
        trial_rejections = 0
        for _ in range(m_dates):
            # Draw standard normal test statistic under the null of zero abnormal return
            z_stat = rng.gauss(0.0, 1.0)
            total_single_tests += 1
            if abs(z_stat) > crit_val:
                total_single_rejections += 1
                trial_rejections += 1

        if trial_rejections > 0:
            trials_with_any_rejection += 1

    emp_single_rate = total_single_rejections / total_single_tests
    emp_family_rate = trials_with_any_rejection / trials

    print("Placebo Date Multiple Testing Falsification Analysis (SIMULATED):")
    print(f"  Simulation Trials:             {trials}")
    print(f"  Placebo Dates Per Trial (m):   {m_dates}")
    print(f"  Nominal Single Date Size (alpha): {alpha:.4f} ({alpha * 100:.1f}%)")
    print(f"  Standard Normal Threshold:     +/-{crit_val:.2f}\n")
    print("Rejection Rate Results Under The Null:")
    print(f"  Empirical Single Date Rate:    {emp_single_rate:.4f} ({emp_single_rate * 100:.2f}%)")
    print(f"  Single Date Error vs Alpha:    {abs(emp_single_rate - alpha):.4f}")
    print(f"  Theoretical Multi-Date Rate:   {theoretical_family_rate:.4f} ({theoretical_family_rate * 100:.2f}%)")
    print(f"  Empirical Multi-Date Rate:     {emp_family_rate:.4f} ({emp_family_rate * 100:.2f}%)")
    print(f"  Multi-Date Discrepancy:        {abs(emp_family_rate - theoretical_family_rate):.4f}")

The numerical simulation confirms Theorem 1.1. Across 25,000 individual date evaluations, the empirical single-date false positive rate is 5.17% (matching the nominal 5.0% target within Monte Carlo sampling variation of 0.0017). Across the 2,500 multi-date trials, 41.96% of trials contained at least one false rejection, closely matching the theoretical prediction of 40.13% (discrepancy 0.0183). This illustrates why researchers must account for multiple comparisons when running battery placebo diagnostics.

Where the Canon Breaks

The standard assumptions underlying placebo tests fail in practical financial panels:

  • Temporal Dependence & Volatility Clustering: Theorem 1.1 assumes test statistics across placebo dates are mutually independent. In equity and fixed-income markets, return volatility exhibits persistent autoregressive conditional heteroskedasticity (volatility clustering). A quiet market period suppresses rejections across multiple adjacent dates, while a turbulent market period triggers multiple simultaneous false rejections.
  • Unobserved News Contamination: Randomly selected placebo dates in historical financial data may inadvertently land on major unscheduled corporate disclosures (e.g., unexpected CEO resignations or patent rulings). These genuine idiosyncratic shocks generate real abnormal returns, causing the placebo test to reject the null even though the econometric model is perfectly valid.
  • Researcher Selection Cherry-Picking: If researchers selectively choose or report only the placebo dates that fail to reject the null, the placebo test ceases to be an objective falsification diagnostic and degenerates into confirmation bias.

Misconceptions

  • Passing a placebo test proves that the empirical model is correctly specified and the causal finding is true.

    A placebo test is a necessary falsification check, not a sufficient proof of causality. A model can pass a placebo test while still suffering from severe omitted variable bias or selection bias on the actual event day.

  • If a researcher runs 20 placebo dates and finds 1 significant result at the 5% level, the model has failed.

    Under the null hypothesis, testing 20 independent dates has a 64.2% theoretical probability of producing at least one rejection at the 5% level. Observing 1 rejection out of 20 (\(5\%\)) exactly matches the nominal expectation of the null.

  • Placebo dates can be chosen immediately before or after the true event date without an exclusion buffer.

    Event effects often leak into prior trading days through informed trading, or persist into subsequent trading days through delayed price discovery. Testing dates without an exclusion buffer contaminates the placebo test with the true causal shock.

Problem Set

Mechanics

Problem 8.1 · Multi-Date False Discovery Probability Calculation

An equity analyst runs a battery of \(m = 8\) independent in-time placebo tests on an event study pipeline at nominal significance level \(\alpha = 0.05\). Compute the exact theoretical probability that the analyst observes at least one false rejection under the null.

Solution

Under mutual independence, the probability that all \(m = 8\) tests fail to reject is:

\[ (1 - \alpha)^m = (1 - 0.05)^8 = (0.95)^8 \approx 0.66342. \]

The probability of at least one false rejection is the complement:

\[ 1 - (1 - \alpha)^m = 1 - 0.66342 = 0.33658 \quad (33.66\%). \]

There is approximately a one-in-three chance of observing at least one false positive rejection purely by random variation.

Problem 8.2 · Minimum Placebo Count for 50% False Alarm Rate

At nominal level \(\alpha = 0.05\), what is the minimum number of independent placebo dates \(m\) such that the probability of at least one false rejection exceeds 50%?

Solution

We solve the inequality \(1 - (1 - \alpha)^m \ge 0.50\), which simplifies to \((0.95)^m \le 0.50\). Taking natural logarithms on both sides:

\[ m \ln(0.95) \le \ln(0.50). \]

Since \(\ln(0.95) < 0\), dividing reverses the inequality:

\[ m \ge \frac{\ln(0.50)}{\ln(0.95)} \approx \frac{-0.69315}{-0.05129} \approx 13.51. \]

Since \(m\) must be an integer, the minimum number of independent placebo dates is \(m = 14\). For \(m = 13\), \(1 - (0.95)^{13} \approx 0.4867\); for \(m = 14\), \(1 - (0.95)^{14} \approx 0.5123\).

Problem 8.3 · Placebo Date Exclusion Filtering

A trading calendar has 252 days indexed \(0\) to \(251\). True corporate events occur on days \(\{40, 120, 190\}\). An analyst specifies an exclusion half-window of \(h_{\text{buffer}} = 10\) days (excluding \([\tau - 10, \tau + 10]\)). If candidate placebo dates generated by an algorithm are \(\{25, 35, 80, 115, 150, 198, 240\}\), determine which candidate dates are valid and which are rejected.

Solution

The exclusion buffers are \([30, 50]\), \([110, 130]\), and \([180, 200]\). We test each candidate:

  • Day 25: Valid (outside all buffers).
  • Day 35: Rejected (falls in \([30, 50]\) of event 40).
  • Day 80: Valid (outside all buffers).
  • Day 115: Rejected (falls in \([110, 130]\) of event 120).
  • Day 150: Valid (outside all buffers).
  • Day 198: Rejected (falls in \([180, 200]\) of event 190).
  • Day 240: Valid (outside all buffers).

Four dates are valid: \(\{25, 80, 150, 240\}\); three are rejected by the exclusion rule.

Proof

Problem 8.4 · Rejection Rate Under Perfectly Correlated Placebo Dates

Prove that if \(m\) placebo tests have identical, perfectly correlated test statistics (\(T_1 = T_2 = \dots = T_m\)), the probability of observing at least one false rejection is \(\alpha\), rather than \(1 - (1 - \alpha)^m\).

Solution

When test statistics are perfectly collinear, the event that test \(j\) rejects is identical to the event that test 1 rejects: \(E_j = E_1\) for all \(j \in \{1, \dots, m\}\).

The event that at least one test rejects is the union:

\[ \bigcup_{j=1}^m E_j = \bigcup_{j=1}^m E_1 = E_1. \]

Taking probabilities:

\[ \Prob\left(\bigcup_{j=1}^m E_j\right) = \Prob(E_1) = \alpha. \]

When tests are perfectly dependent, multiple testing does not increase the family-wise false rejection rate above \(\alpha\). Mutual independence represents the upper bound on independent discovery.

Problem 8.5 · Bonferroni Bound on Multi-Date Rejection

Use Boole's inequality to prove that the family-wise false rejection probability \(\Prob(\bigcup_{j=1}^m E_j)\) is strictly bounded above by \(m \alpha\), regardless of the correlation structure among tests.

Solution

By Boole's inequality (the union bound) for any arbitrary collection of events \(\{E_1, \dots, E_m\}\):

\[ \Prob\left(\bigcup_{j=1}^m E_j\right) \le \sum_{j=1}^m \Prob(E_j). \]

Under the null hypothesis, each individual test has size \(\Prob(E_j) = \alpha\). Therefore:

\[ \sum_{j=1}^m \Prob(E_j) = \sum_{j=1}^m \alpha = m \alpha. \]

This bound holds universally for any degree of positive, negative, or nonlinear dependence across tests, providing the foundation for Bonferroni size adjustments.

Problem 8.6 · Derivation of Asymptotic Equivalence of Union Bound

Prove that as \(\alpha \to 0\) with fixed \(m\), the independent multi-date false discovery rate \(1 - (1 - \alpha)^m\) converges to the linear Bonferroni bound \(m \alpha\).

Solution

Consider the binomial expansion of \((1 - \alpha)^m\):

\[ (1 - \alpha)^m = 1 - m \alpha + \binom{m}{2} \alpha^2 - \dots + (-1)^m \alpha^m. \]

Substituting into the multi-date false rejection formula:

\[ 1 - (1 - \alpha)^m = m \alpha - \binom{m}{2} \alpha^2 + O(\alpha^3). \]

Dividing by \(m \alpha\) and taking the limit as \(\alpha \to 0\):

\[ \lim_{\alpha \to 0} \frac{1 - (1 - \alpha)^m}{m \alpha} = \lim_{\alpha \to 0} \left[ 1 - \frac{m - 1}{2} \alpha + O(\alpha^2) \right] = 1. \]

For small significance thresholds (e.g., \(\alpha \le 0.01\)), the independent probability and the linear union bound are virtually indistinguishable.

Empirical

Problem 8.7 · Placebo Date Simulation vs Macro Announcements

A quantitative analyst runs an event study on 10 scheduled Consumer Price Index (CPI) release dates, finding an average abnormal return of \(\overline{AR} = +0.018\) (\(t = 2.45\)). To validate the finding, the analyst selects 100 randomly sampled non-CPI trading days and re-runs the pipeline. What distribution of t-statistics should the analyst observe on the 100 placebo dates if the CPI result is valid?

Solution

If the model is well-specified and the CPI reaction is genuinely causal, the 100 placebo dates represent draws from the true null distribution. The analyst should observe:

  1. A mean t-statistic across the 100 placebo dates centered at approximately zero (\(\bar{t}_{\text{placebo}} \approx 0.0\)).
  2. A sample standard deviation of t-statistics close to 1.0.
  3. Approximately 5 out of 100 placebo dates (5%) rejecting at the two-sided 5% level (\(|t| > 1.96\)), with 2 or 3 in each tail.

The true CPI t-statistic of 2.45 should lie in the extreme tail (top 1% or 2%) of the empirical placebo distribution.

Problem 8.8 · Diagnosing In-Space Placebo Failures in Sovereign Debt

A researcher studies the causal yield reaction of Italian government bonds following an Italian budget deficit announcement. An in-space placebo assigns the announcement date to German Bunds and Spanish Bonos. German Bund yields fall by 15 basis points, while Spanish yields jump by 35 basis points. How does this in-space placebo challenge a causal interpretation of the Italian yield change?

Solution

The non-zero reactions in untreated sovereign bonds indicate that the announcement was not an isolated, country-specific shock, but rather triggered a systemic Eurozone-wide portfolio rebalancing: a "flight to safety" into German Bunds and risk-premium contagion into peripheral Spanish debt.

Because control units reacted strongly, the Italian yield movement cannot be cleanly attributed solely to domestic debt mechanics; part of the movement reflects broad macro-financial repricing that contaminated the entire European sovereign curve.

Problem 8.9 · Evaluating Lab 1 Null Discrepancy

In Lab 1, the empirical multi-date false discovery rate across 2,500 trials is 0.4196, while the theoretical rate is 0.4013. Compute the standard error of the Monte Carlo simulation proportion and assess whether the discrepancy of 0.0183 is statistically significant at the 5% level.

Solution

The sampling variance of a sample proportion \(\hat{p}\) across \(N = 2{,}500\) independent trials with true probability \(p = 0.4013\) is:

\[ \text{SE}(\hat{p}) = \sqrt{\frac{p(1 - p)}{N}} = \sqrt{\frac{0.4013 \times 0.5987}{2500}} = \sqrt{\frac{0.24026}{2500}} \approx \sqrt{0.0000961} \approx 0.00980. \]

The difference between observed and theoretical proportion is \(0.4196 - 0.4013 = 0.0183\). The z-statistic for the simulation discrepancy is:

\[ z = \frac{0.0183}{0.00980} \approx 1.867. \]

Because \(|1.867| < 1.96\), the discrepancy is not statistically significant at the two-sided 5% level, confirming that the Monte Carlo output is consistent with the theoretical model.

Tier 4 · Research

Problem 8.10 · Randomization Inference vs Parametric Placebo Testing

Compare parametric placebo testing based on the Student-t distribution with Fisherian randomization inference (permutation tests) in event study methodology.

Solution

Parametric testing assumes that abnormal return residuals follow a specific distributional law (e.g. Gaussian disturbances) and relies on asymptotic standard error derivations.

Fisherian randomization inference makes zero parametric distributional assumptions. It computes the test statistic across all possible permutations (or a large Monte Carlo sample of permutations) of event dates or treatment assignments. The exact p-value is the empirical proportion of permuted test statistics that exceed the observed statistic:

\[ p_{\text{exact}} = \frac{1}{B} \sum_{b=1}^B \indic\{|T_b^{\text{perm}}| \ge |T^{\text{observed}}|\}. \]

Randomization inference is exact in finite samples, robust to extreme non-normality, and immune to asymptotic standard error underestimation.

Problem 8.11 · In-Time Placebo Test as an Empirical Pre-Trends Diagnostic

How does executing in-time placebo tests over the pre-treatment period \([-T, -1]\) serve as an empirical test of the parallel counterfactual trends assumption in difference-in-differences?

Solution

In difference-in-differences, the identification assumption is that treated and control units would have followed parallel outcome trajectories in the absence of treatment. While the counterfactual is unobservable post-treatment, its validity can be falsified pre-treatment.

Running in-time placebo tests on historical pre-treatment dates tests whether treated and control units diverged prior to the true policy date. If pre-period placebo tests reject the null of zero difference, parallel trends is empirically refuted, proving that pre-existing differential trends account for the post-treatment divergence.

Problem 8.12 · Synthetic Controls and In-Space Permutation P-Values

Foreshadowing synthetic control methods (Lesson 9), explain how Abadie, Diamond, and Hainmueller (2010) use in-space placebo tests across every donor unit to construct exact non-parametric p-values for a single treated unit.

Solution

When only one aggregate unit is treated (e.g., California's Proposition 99 tobacco law), classical large-sample inference is impossible because the sample size of treated units is \(N_1 = 1\).

Abadie, Diamond, and Hainmueller solve this by applying the synthetic control algorithm iteratively to every control state in the donor pool (in-space placebos). By comparing California's post-intervention Mean Squared Prediction Error (MSPE) ratio to the empirical distribution of placebo MSPE ratios across all 38 donor states, they obtain an exact permutation p-value: if California has the largest ratio, \(p = 1 / (38 + 1) = 1/39 \approx 0.0256\).

Retrieval Quiz

  1. What is the core objective of a placebo test in causal inference?

    A placebo test checks that an estimation procedure does not manufacture spurious significant results when run on fake dates or untreated units.

  2. What is the distinction between an in-time placebo and an in-space placebo?

    In-time placebos test temporal falsification on treated units; in-space placebos test cross-sectional falsification on control units.

  3. Under mutual independence, what is the probability of observing at least one false positive rejection across \(m\) independent placebo tests at significance level \(\alpha\)?

    By independence, the probability that all \(m\) tests correctly fail to reject is \((1 - \alpha)^m\); the complement is \(1 - (1 - \alpha)^m\).

  4. Compute the theoretical probability of observing at least one false rejection across \(m = 10\) independent placebo tests evaluated at nominal level \(\alpha = 0.05\).

    \(1 - (1 - 0.05)^{10} = 1 - (0.95)^{10} \approx 1 - 0.598737 = 0.401263\).

  5. Why must placebo dates adhere to a strict exclusion buffer around actual event dates?

    If a placebo date lands inside an active event window, real causal price movements leak into the placebo, biasing the null benchmark.

  6. If an analyst tests 20 independent placebo dates at \(\alpha = 0.05\) and observes exactly 1 rejection, what is the proper conclusion?

    An empirical rejection rate of 1/20 = 5% exactly matches the 5% nominal size of the test under the null hypothesis.

  7. What happens to the family-wise false rejection rate if placebo dates are perfectly positively correlated rather than independent?

    When tests are perfectly correlated, all \(m\) tests replicate test 1, so the probability of at least one rejection is simply \(\Prob(E_1) = \alpha\).

  8. How does a Fisherian permutation test construct exact p-values for an event study?

    A permutation test compares the actual observed statistic to the empirical distribution generated by shuffling dates or treatment indicators.
