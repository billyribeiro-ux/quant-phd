Event Studies & Abnormal Returns

Market Benchmarks, Exact Finite-Sample Variance, and Clustered Policy Testing

Why It Matters

Financial asset prices incorporate new economic information within milliseconds. Evaluating whether an unexpected central bank interest rate decision, regulatory reform, or corporate earnings release created economic value requires measuring price changes relative to an explicit counterfactual benchmark. The event study methodology isolates this value impact by calculating abnormal returns relative to a market model. However, naive implementations that neglect parameter estimation uncertainty in market model betas suffer from severe finite-sample size distortions, over-rejecting the null hypothesis and manufacturing spurious statistical significance on macro announcement days.

1. The Classical Event Study Framework

MacKinlay (1997) establishes the classical econometric structure for event studies in financial economics. An event study partitions chronological trading time into distinct windows around an economic announcement.

Definition 1.1 · Event Study

An event study is an empirical methodology designed to measure the causal impact of a specific economic event or policy disclosure on the valuation of a security or portfolio by comparing observed returns to counterfactual normal returns over an event window.

Let \(t = 0\) index the event date. Chronological trading time is partitioned into:

  • Estimation Window: \(t \in [-L - \tau_1, -\tau_1 - 1]\) of length \(L\), used exclusively to estimate normal-return benchmark parameters without contamination from the event.
  • Event Window: \(t \in [-\tau_1, \tau_2]\), typically \([-1, +1]\), spanning the announcement and potential pre-announcement leakage or post-announcement price discovery.
  • Post-Event Window: Subsequent periods used to examine longer-term underreaction or drift.
Definition 1.2 · Abnormal Return

The abnormal return \(AR_{it}\) for asset \(i\) at trading date \(t\) is the difference between the observed ex-post return \(R_{it}\) and the expected normal return predicted by a reference model conditional on market covariates \(R_{mt}\):

\[ AR_{it} \equiv R_{it} - \E[R_{it} \mid R_{mt}, \mathcal{F}_{\text{pre}}]. \]

Under the linear single-factor market model, normal returns follow:

\[ R_{it} = \alpha_i + \beta_i R_{mt} + \varepsilon_{it}, \]

with \(\E[\varepsilon_{it}] = 0\), \(\Var(\varepsilon_{it}) = \sigma_i^2\), and \(\Cov(R_{mt}, \varepsilon_{it}) = 0\). The empirical abnormal return using ordinary least squares estimates \((\hat{\alpha}_i, \hat{\beta}_i)\) from the estimation window is:

\[ AR_{it} = R_{it} - (\hat{\alpha}_i + \hat{\beta}_i R_{mt}). \]

Angrist and Pischke (2009) emphasize that causal attribution in regression models requires orthogonal regression residuals; in event studies, this orthogonality is ensured by conditioning strictly on pre-event estimation windows.

2. Exact Finite-Sample Abnormal Return Variance

A widespread error in quantitative research is treating estimated coefficients \((\hat{\alpha}_i, \hat{\beta}_i)\) as fixed, deterministic constants, setting \(\Var(AR_{it}) = s^2\). This ignores the sampling variance of the estimated parameters.

Theorem 1.1 · Exact Analytical Variance of Abnormal Returns

Assumptions:

  1. Market Model (A1): \(R_{it} = \alpha_i + \beta_i R_{mt} + \varepsilon_{it}\) for all \(t\).
  2. Spherical Disturbances (A2): Disturbances \(\varepsilon_{it}\) are independent across time, homoskedastic with variance \(\sigma_i^2\), and independent of market returns \(R_{ms}\) for all \(s, t\).
  3. Window Independence (A3): Event-window disturbance \(\varepsilon_{i0}\) is statistically independent of estimation-window disturbances \(\{\varepsilon_{i\tau}\}_{\tau \in \text{est}}\).
  4. Degrees of Freedom (A4): Unbiased residual variance estimator \(s_i^2 = \frac{1}{L - 2} \sum_{\tau \in \text{est}} e_{i\tau}^2\).

Conclusion: Conditional on market returns, the exact finite-sample variance of the event-day abnormal return \(AR_{i0}\) is:

\[ \Var(AR_{i0} \mid R_{m0}, \boldsymbol{R}_m) = \sigma_i^2 \left[ 1 + \frac{1}{L} + \frac{(R_{m0} - \bar{R}_m)^2}{\sum_{\tau \in \text{est}} (R_{m\tau} - \bar{R}_m)^2} \right], \]

where \(\bar{R}_m = \frac{1}{L} \sum_{\tau \in \text{est}} R_{m\tau}\).

Proof

Substitute the true market model \(R_{i0} = \alpha_i + \beta_i R_{m0} + \varepsilon_{i0}\) into the abnormal return expression:

\[ \begin{aligned} AR_{i0} &= R_{i0} - (\hat{\alpha}_i + \hat{\beta}_i R_{m0}) \\ &= (\alpha_i - \hat{\alpha}_i) \\ &\quad + (\beta_i - \hat{\beta}_i) R_{m0} + \varepsilon_{i0}. \end{aligned} \]

Recall from standard OLS that \(\hat{\alpha}_i = \bar{R}_i - \hat{\beta}_i \bar{R}_m\). Expressing the intercept in centered form:

\[ \hat{\alpha}_i + \hat{\beta}_i R_{m0} = \bar{R}_i + \hat{\beta}_i (R_{m0} - \bar{R}_m). \]

Subtracting this from \(R_{i0} = \bar{R}_i + \beta_i (R_{m0} - \bar{R}_m) + (\varepsilon_{i0} - \bar{\varepsilon}_i)\) yields:

\[ AR_{i0} = \varepsilon_{i0} - \left[ \bar{\varepsilon}_i + (\hat{\beta}_i - \beta_i)(R_{m0} - \bar{R}_m) \right]. \]

By assumption A3, event disturbance \(\varepsilon_{i0}\) is independent of estimation disturbance sample mean \(\bar{\varepsilon}_i\) and slope error \((\hat{\beta}_i - \beta_i)\). Furthermore, under OLS, \(\bar{\varepsilon}_i\) and \((\hat{\beta}_i - \beta_i)\) are mutually uncorrelated. Therefore:

\[ \begin{aligned} \Var(AR_{i0}) &= \Var(\varepsilon_{i0}) + \Var(\bar{\varepsilon}_i) \\ &\quad + (R_{m0} - \bar{R}_m)^2 \Var(\hat{\beta}_i). \end{aligned} \]

Substituting \(\Var(\varepsilon_{i0}) = \sigma_i^2\), \(\Var(\bar{\varepsilon}_i) = \frac{\sigma_i^2}{L}\), and \(\Var(\hat{\beta}_i) = \frac{\sigma_i^2}{\sum_{\tau} (R_{m\tau} - \bar{R}_m)^2}\) proves the result.

Remark 1.1 · The Constant-Mean Return Model

When no market index benchmark is specified (setting \(\beta_i \equiv 0\)), normal returns follow the constant-mean model \(R_{it} = \mu_i + \varepsilon_{it}\). In this case, \(\hat{\mu}_i = \bar{R}_i\), \(s_i^2 = \frac{1}{L - 1} \sum_{\tau} (R_{i\tau} - \bar{R}_i)^2\), and the abnormal return variance reduces to:

\[ \Var(AR_{i0}) = \sigma_i^2 \left( 1 + \frac{1}{L} \right). \]

3. Cumulative Abnormal Returns & Clustered Testing

To capture multi-day price reactions, abnormal returns are aggregated across the event window \([-\tau_1, \tau_2]\).

Definition 1.3 · Cumulative Abnormal Return (CAR)

The Cumulative Abnormal Return \(CAR_i(-\tau_1, \tau_2)\) is the sum of daily abnormal returns across the event window:

\[ CAR_i(-\tau_1, \tau_2) \equiv \sum_{t = -\tau_1}^{\tau_2} AR_{it}. \]

Under assumption A2 (no intertemporal serial correlation in \(\varepsilon_{it}\)), the variance of CAR is the sum of daily AR variances:

\[ \Var(CAR_i) = \sum_{t = -\tau_1}^{\tau_2} \Var(AR_{it}). \]
Definition 1.4 · Cross-Sectional and Clustered Test Statistics

Across a sample of \(K\) independent corporate events, the sample average CAR is \(\overline{CAR} = \frac{1}{K} \sum_{i=1}^K CAR_i\). The cross-sectional test statistic is:

\[ t_{\text{cross}} = \frac{\overline{CAR}}{s_{\text{CAR}} / \sqrt{K}}, \]

where \(s_{\text{CAR}} = \sqrt{\frac{1}{K - 1} \sum_{i=1}^K (CAR_i - \overline{CAR})^2}\).

When events share calendar dates (e.g., scheduled Federal Open Market Committee announcements), asset returns covary across firms due to common macro shocks. We apply cluster-robust inference (CR1) grouping observations into \(G\) calendar clusters:

\[ V_{\text{CR1}} = \frac{G}{G - 1} \frac{\sum_{g=1}^G \left( \sum_{i \in g} (CAR_i - \overline{CAR}) \right)^2}{K^2}, \]

yielding clustered test statistic \(t_{\text{cluster}} = \overline{CAR} / \sqrt{V_{\text{CR1}}}\).

4. Empirical Demonstration: Abnormal Return Variance Null Rejection

We execute a Monte Carlo experiment with 3,000 replications under the true null hypothesis \(H_0: AR = 0.0\). We evaluate the empirical false rejection rate at nominal size \(\alpha = 0.05\) using estimation window \(L = 30\). We compare the naive variance formula \(s^2\) against the correct analytical variance formula.

Lab 1 · Finite-Sample AR Variance Test Size (SIMULATED)

Under H_0 with L = 30 and nominal size 0.05, the naive variance estimator s^2 produces inflated false rejection rates above 0.055, whereas the correct analytical formula achieves exact nominal control at 0.0500.

"""Lab S6-L07-1: Event study with correct abnormal-return variance vs naive variance.

SIMULATED: curriculum benchmark comparing empirical rejection rates under the null
hypothesis of no event response when using the naive residual variance versus
the correct analytical abnormal-return variance that includes parameter estimation error.
"""

from __future__ import annotations

import math
import random


def main() -> None:
    rng = random.Random(1997)
    reps = 3000
    est_len = 30  # Relatively short estimation window to highlight estimation uncertainty

    # Critical value for two-sided 5% test with df = L - 2 = 28
    # Student t critical value for df=28 at alpha=0.05 is 2.0484
    crit_val = 2.0484

    rejections_naive = 0
    rejections_correct = 0

    true_alpha = 0.0003
    true_beta = 1.15
    true_sigma = 0.015

    for _ in range(reps):
        # 1. Estimation window (L days)
        mkt_est = [rng.gauss(0.0004, 0.014) for _ in range(est_len)]
        stk_est = [true_alpha + true_beta * m + rng.gauss(0.0, true_sigma) for m in mkt_est]

        # Market model OLS
        m_bar = sum(mkt_est) / est_len
        s_bar = sum(stk_est) / est_len
        ss_m = sum((m - m_bar) ** 2 for m in mkt_est)
        sp_ms = sum((m - m_bar) * (s - s_bar) for m, s in zip(mkt_est, stk_est, strict=True))

        beta_hat = sp_ms / ss_m
        alpha_hat = s_bar - beta_hat * m_bar
        ss_res = sum((s - (alpha_hat + beta_hat * m)) ** 2 for s, m in zip(stk_est, mkt_est, strict=True))
        sig2_hat = ss_res / (est_len - 2)

        # 2. Event day (Null hypothesis: true abnormal return is exactly 0.0)
        mkt_ev = rng.gauss(0.0004, 0.014)
        stk_ev = true_alpha + true_beta * mkt_ev + rng.gauss(0.0, true_sigma)  # shock = 0

        # Abnormal return
        ar = stk_ev - (alpha_hat + beta_hat * mkt_ev)

        # Naive variance: s^2 alone (omits sampling error of alpha and beta)
        var_naive = sig2_hat
        t_naive = ar / math.sqrt(var_naive)
        if abs(t_naive) > crit_val:
            rejections_naive += 1

        # Correct analytical variance: s^2 * (1 + 1/L + (R_m0 - mean)^2 / SS_m)
        dev_m = (mkt_ev - m_bar) ** 2
        var_correct = sig2_hat * (1.0 + 1.0 / est_len + dev_m / ss_m)
        t_correct = ar / math.sqrt(var_correct)
        if abs(t_correct) > crit_val:
            rejections_correct += 1

    rate_naive = rejections_naive / reps
    rate_correct = rejections_correct / reps

    print("Event Study Abnormal Return Variance Null Rejection Benchmark (SIMULATED):")
    print(f"  Monte Carlo Replications:      {reps}")
    print(f"  Estimation Window Length (L):  {est_len}")
    print("  Nominal Test Size (alpha):     0.0500 (5.00%)")
    print(f"  Two-sided Critical Value:      {crit_val:.4f}\n")
    print("Empirical False Rejection Rates Under H_0:")
    print(f"  Naive Residual Variance (s^2):      {rate_naive:6.4f} ({rate_naive * 100:4.2f}%)  <-- Size distortion!")
    print(
        f"  Correct Analytical Variance:        {rate_correct:6.4f} ({rate_correct * 100:4.2f}%)  <-- Nominal control"
    )
    print(f"  Excess False Rejections (Naive):    +{rate_naive - 0.0500:6.4f} ({(rate_naive - 0.0500) * 100:4.2f} pp)")
    print(f"  Absolute Size Error (Correct):       {abs(rate_correct - 0.0500):6.4f}")


main()

Where the Canon Breaks

Standard event study assumptions frequently collapse in real financial markets:

  • Event-Induced Volatility: Major announcements frequently cause asset return volatility to spike on event days, violating the homoskedasticity assumption \(\Var(\varepsilon_{i0}) = \sigma_i^2\). When event variance exceeds historical estimation variance, standard t-tests over-reject null hypotheses even with the exact analytical formula. Robust procedures (such as Boehmer-Musumeci-Poulsen standardized cross-sectional tests) adjust for event-day variance inflation.
  • Cross-Sectional Clustering: When an event occurs on the same calendar day for all firms (e.g., regulatory tax changes or central bank rate decisions), abnormal returns share unmodeled industry or market shocks. Standard cross-sectional standard errors assume zero covariance across firms, dramatically understating true standard errors. Date clustering or portfolio aggregation is mandatory.
  • Information Leakage & Pre-Event Drift: Insiders or informed institutional traders frequently trade ahead of public announcements. Restricting the event window to day 0 misses pre-announcement price discovery, while widening the window inflates noise.

Misconceptions

  • The variance of an abnormal return is simply the sample variance of the regression residuals \(s^2\).

    The regression residuals \(e_{it}\) measure in-sample fit, while \(AR_{i0}\) is an out-of-sample forecast error. The true variance includes estimation uncertainty in the intercept (\(1/L\)) and slope (\((R_{m0} - \bar{R}_m)^2 / SS_m\)), inflating out-of-sample variance above \(s^2\).

  • A statistically significant abnormal return proves that financial markets are inefficient.

    An abnormal return tests a joint hypothesis: market efficiency and the validity of the normal return model. A significant abnormal return could reflect true mispricing, model misspecification (omitted risk factors), or event-induced risk premiums.

  • Cumulative Abnormal Returns over a multi-day window can be computed by compounding daily abnormal returns: \(\prod (1 + AR_t) - 1\).

    Compounding introduces non-linear cross-product terms and statistical asymmetry. In linear event study econometrics, CAR is defined as the arithmetic sum of abnormal returns, which preserves unbiasedness and linear expectation properties.

Problem 7.1 · Calculating Exact Abnormal Return Variance

An equity analyst fits a market model on \(L = 60\) trading days. The estimated residual variance is \(s^2 = 0.00025\), the market sum of squares is \(\sum_{\tau} (R_{m\tau} - \bar{R}_m)^2 = 0.0036\), and on the event day, the market deviates from its estimation mean by \(R_{m0} - \bar{R}_m = +0.012\). Compute the exact analytical variance \(\Var(AR_{i0})\) and the percentage increase over naive \(s^2\).

Solution

The squared market deviation is \((0.012)^2 = 0.000144\). The variance inflation factor is:

\[ 1 + \frac{1}{L} + \frac{(R_{m0} - \bar{R}_m)^2}{SS_m} = 1 + \frac{1}{60} + \frac{0.000144}{0.0036} = 1 + 0.01667 + 0.04000 = 1.05667. \]

Multiplying by \(s^2 = 0.00025\):

\[ \Var(AR_{i0}) = 0.00025 \times 1.05667 = 0.00026417. \]

The exact variance is 5.67% higher than the naive residual variance \(s^2\).

Problem 7.2 · Cumulative Abnormal Return and Variance Aggregation

Over a 3-day event window \([-1, +1]\), estimated daily abnormal returns and analytical standard errors are: Day -1: \(AR = +0.008\), \(\text{SE} = 0.010\); Day 0: \(AR = +0.035\), \(\text{SE} = 0.012\); Day +1: \(AR = -0.005\), \(\text{SE} = 0.010\). Assuming zero serial correlation across days, calculate the Cumulative Abnormal Return \(CAR(-1, +1)\), its standard error, and the resulting t-statistic.

Solution

The CAR is the arithmetic sum:

\[ CAR = 0.008 + 0.035 - 0.005 = +0.0380 \quad (3.80\%). \]

The CAR variance is the sum of daily variances:

\[ \Var(CAR) = (0.010)^2 + (0.012)^2 + (0.010)^2 = 0.000100 + 0.000144 + 0.000100 = 0.000344. \]

The standard error is \(\sqrt{0.000344} \approx 0.01855\). The t-statistic is \(t = \frac{0.0380}{0.01855} \approx +2.049\), significant at the 5% level.

Problem 7.3 · Cross-Sectional Mean CAR Test

A portfolio manager studies 25 corporate merger announcements. The sample mean CAR is \(\overline{CAR} = +0.042\) with sample standard deviation \(s = 0.080\). Compute the standard error of the mean, the cross-sectional t-statistic, and evaluate significance at the two-sided 5% level (critical value 2.064 for 24 degrees of freedom).

Solution

The standard error of the sample mean is \(\text{SE} = \frac{s}{\sqrt{K}} = \frac{0.080}{\sqrt{25}} = \frac{0.080}{5} = 0.0160\).

The t-statistic is:

\[ t = \frac{\overline{CAR}}{\text{SE}} = \frac{0.042}{0.0160} = 2.625. \]

Because \(|2.625| > 2.064\), the merger announcements generate a statistically significant positive abnormal return at the 5% level.

Problem 7.4 · Unbiasedness of Abnormal Return Forecast Errors

Prove that under assumptions A1–A3, the abnormal return is an unbiased estimator of zero under the null hypothesis: \(\E[AR_{i0} \mid R_{m0}, \boldsymbol{R}_m] = 0\).

Solution

Take the conditional expectation of \(AR_{i0} = (\alpha_i - \hat{\alpha}_i) + (\beta_i - \hat{\beta}_i) R_{m0} + \varepsilon_{i0}\):

\[ \E[AR_{i0} \mid R_{m0}, \boldsymbol{R}_m] = \E[\alpha_i - \hat{\alpha}_i \mid \boldsymbol{R}_m] + \E[\beta_i - \hat{\beta}_i \mid \boldsymbol{R}_m] R_{m0} + \E[\varepsilon_{i0} \mid R_{m0}]. \]

By the Gauss-Markov theorem for OLS, \(\E[\hat{\alpha}_i \mid \boldsymbol{R}_m] = \alpha_i\) and \(\E[\hat{\beta}_i \mid \boldsymbol{R}_m] = \beta_i\). By assumption A2, \(\E[\varepsilon_{i0} \mid R_{m0}] = 0\). Substituting these expectations:

\[ \E[AR_{i0} \mid R_{m0}, \boldsymbol{R}_m] = 0 + 0 \cdot R_{m0} + 0 = 0. \]

The expected abnormal return under the null is identically zero.

Problem 7.5 · Multi-Day CAR Covariance Under Estimation Error

Show that even when disturbances \(\varepsilon_{it}\) are serially independent, abnormal returns \(AR_{it}\) and \(AR_{is}\) on two different event days \(t \ne s\) share a positive covariance due to common parameter estimation error \(\hat{\alpha}_i\) and \(\hat{\beta}_i\).

Solution

Write \(AR_{it} = \varepsilon_{it} - [\bar{\varepsilon}_i + (\hat{\beta}_i - \beta_i)(R_{mt} - \bar{R}_m)]\). For two distinct event days \(t \ne s\):

\[ \begin{aligned} \Cov(AR_{it}, AR_{is}) &= \Cov\Big(\varepsilon_{it} - [\bar{\varepsilon}_i + (\hat{\beta}_i - \beta_i)(R_{mt} - \bar{R}_m)], \\ &\quad\quad \varepsilon_{is} - [\bar{\varepsilon}_i + (\hat{\beta}_i - \beta_i)(R_{ms} - \bar{R}_m)]\Big). \end{aligned} \]

Since \(\varepsilon_{it}\) and \(\varepsilon_{is}\) are independent of each other and of the estimation window, the cross-terms with disturbances vanish. The remaining covariance is:

\[ \Cov(AR_{it}, AR_{is}) = \Var(\bar{\varepsilon}_i) + (R_{mt} - \bar{R}_m)(R_{ms} - \bar{R}_m) \Var(\hat{\beta}_i) = \sigma_i^2 \left[ \frac{1}{L} + \frac{(R_{mt} - \bar{R}_m)(R_{ms} - \bar{R}_m)}{SS_m} \right]. \]

This covariance is non-zero, proving that estimation uncertainty induces positive intertemporal correlation across event-window abnormal returns.

Problem 7.6 · Proof of Small-Sample Inflation in Naive t-Statistics

Prove that the naive t-statistic \(t_{\text{naive}} = AR_{i0} / s_i\) has a variance strictly greater than 1 under the null hypothesis when \(L\) is finite.

Solution

Let \(\omega^2 \equiv 1 + \frac{1}{L} + \frac{(R_{m0} - \bar{R}_m)^2}{SS_m} > 1\). The exact standardized test statistic is \(t_{\text{correct}} = \frac{AR_{i0}}{s_i \omega}\), which follows a Student-t distribution with \(L - 2\) degrees of freedom. Therefore, the naive test statistic satisfies:

\[ t_{\text{naive}} = \frac{AR_{i0}}{s_i} = \omega \cdot t_{\text{correct}}. \]

The variance of \(t_{\text{naive}}\) is:

\[ \Var(t_{\text{naive}}) = \omega^2 \Var(t_{\text{correct}}) = \omega^2 \left( \frac{L - 2}{L - 4} \right) > 1. \]

Because \(\omega > 1\) and \(\frac{L - 2}{L - 4} > 1\) for any finite \(L > 4\), the naive statistic has inflated dispersion, inevitably causing excess false rejections at any critical threshold.

Empirical

Problem 7.7 · Federal Reserve FOMC Rate Decision Clustering

An empirical researcher studies stock market reactions across 100 S&P 500 equities on an unexpected FOMC interest rate hike date. Why does computing a cross-sectional t-statistic assuming 100 independent events produce severely inflated t-statistics? How does date clustering fix this?

Solution

All 100 firms experience the interest rate announcement on the exact same calendar day. The cross-sectional test assumes that the 100 abnormal returns are independent observations (\(N=100\)). In reality, the common macroeconomic shock creates strong positive correlation across equity returns, meaning the true effective degrees of freedom is closer to 1 (a single macro date) rather than 100.

By clustering observations at the announcement date level (CR1), the clustered variance estimator aggregates firm residuals within the date before squaring, correctly accounting for cross-firm correlation and preventing massive over-rejection.

Problem 7.8 · Market Model versus Constant-Mean Model Selection

Under what circumstances does a constant-mean model outperform a market model in event study applications? Discuss the empirical trade-off between variance reduction and model specification error.

Solution

The market model reduces abnormal return variance by \(1 - R^2\) where \(R^2\) is the regression explanatory power. For high-beta equities with \(R^2 \ge 0.30\), the market model significantly sharpens test power.

However, when studying broad market events (such as central bank policy shifts or exchange rate shocks) or fixed income yields where a clean, uncontaminated market benchmark index is unavailable, fitting an OLS market model introduces regressor estimation error and potential endogeneity. In fixed income event studies (e.g., 10-year Treasury yield changes), the constant-mean model is frequently preferred because yields already represent market-clearing equilibrium rates.

Problem 7.9 · Event Window Selection and Pre-Announcement Leakage

A corporate event study compares a 1-day event window \([0, 0]\) against a 3-day window \([-1, +1]\). If merger rumors leaked on day -1, what happens to the estimated abnormal return in both windows? What is the penalty for using an unnecessarily wide window \([-5, +5]\)?

Solution

If information leaks on day -1, a single-day window \([0, 0]\) misses the initial price reaction, underestimating the total economic impact of the merger. A 3-day window \([-1, +1]\) successfully captures both the pre-announcement leakage on day -1 and subsequent price discovery.

However, expanding the window to \([-5, +5]\) introduces 11 days of unrelated firm-specific noise. Since the variance of CAR scales linearly with window length \(T_{\text{win}}\), widening the window from 3 to 11 days increases variance by nearly 4-fold (\(11/3 \approx 3.67\)), severely diluting statistical power.

Tier 4 · Research

Problem 7.10 · The Patell and Boehmer-Musumeci-Poulsen Standardized Tests

Explain how the Patell (1976) standardized residual test and the Boehmer, Musumeci, and Poulsen (BMP, 1991) standardized cross-sectional test handle event-induced variance changes.

Solution

The Patell test standardizes each firm's abnormal return by its analytical standard error prior to cross-sectional aggregation: \(SAR_{it} = AR_{it} / s_i \omega_t\), weighting precise estimates more heavily. However, Patell assumes that event-day variance equals estimation-window variance.

BMP (1991) resolve event-induced variance inflation by calculating the cross-sectional sample variance of the standardized abnormal returns \(SAR_{i0}\) on the event day itself. If event announcements double return volatility, BMP's cross-sectional standard error scales up proportionally, restoring correct test size.

Problem 7.11 · Event Studies with High-Frequency Intraday Data

How does the shift from daily return data to intraday 1-minute or 5-minute intervals alter the econometric properties of event studies around macroeconomic announcements?

Solution

High-frequency intraday data offers two massive econometric advantages: (1) it narrows the event window from 24 hours to a 5-minute or 15-minute interval around the exact announcement timestamp, effectively eliminating unrelated background noise; (2) market-model normal returns over 5 minutes are virtually zero, rendering benchmark model specification error negligible.

However, high-frequency studies introduce new econometric challenges: microstructure noise, bid-ask bounce, asynchronous trading, and non-Gaussian fat-tailed jump distributions, requiring robust high-frequency volatility estimators.

Problem 7.12 · Factor Model Benchmark Misspecification and Spurious CARs

Explain why using the CAPM single-factor market model can generate spurious long-horizon abnormal returns when the true data-generating process follows a multi-factor pricing model (e.g., Fama-French factors).

Solution

If treated firms load heavily on an omitted risk factor (such as size, value, or momentum), the single-factor market model error term \(\varepsilon_{it}\) contains the omitted factor realization \(s_t F_t\). If the factor experiences positive returns during the post-event window, the residuals will be systematically positive.

The event study will interpret this common factor risk compensation as a spurious causal policy abnormal return. Over short 1-day windows, factor returns are negligible, but over long horizons (months or years), factor benchmark misspecification completely dominates test outcomes.

Retrieval Quiz

  1. Why must the estimation window be strictly separated from the event window in an event study?

    If the event window were included in estimation, the abnormal return would be absorbed into \(\hat{\alpha}\) and \(\hat{\beta}\), biasing normal return expectations.

  2. In the exact finite-sample variance formula \(\Var(AR) = \sigma^2 [1 + 1/L + (R_{m0} - \bar{R}_m)^2 / SS_m]\), what does the term \(1/L\) represent?

    The term \(1/L\) represents the uncertainty in estimating the baseline mean return \(\bar{R}_i\), which has sampling variance \(\sigma^2 / L\).

  3. What statistical consequence occurs if a researcher uses the naive residual variance \(s^2\) instead of the exact analytical variance?

    Omitting parameter estimation uncertainty systematically underestimates standard errors, producing spuriously large t-statistics and excess false rejections.

  4. Under the constant-mean return model without a market benchmark, what is the exact abnormal return variance formula?

    With no slope parameter, the prediction variance equals the error variance plus the mean estimation variance: \(\sigma^2 (1 + 1/L)\).

  5. How is the Cumulative Abnormal Return \(CAR(-\tau_1, \tau_2)\) defined in linear event study methodology?

    In standard linear event study econometrics, CAR is the arithmetic sum of abnormal returns, which preserves linear expectations and tractability.

  6. When multiple sample events occur on the exact same calendar date, why is standard cross-sectional inference invalid?

    Common calendar dates expose all sample firms to shared macroeconomic shocks, violating cross-sectional independence and inflating standard t-statistics.

  7. Given daily abnormal returns of \(AR_{-1} = +0.012\), \(AR_0 = +0.025\), and \(AR_{+1} = -0.005\), compute the cumulative abnormal return \(CAR(-1, +1)\).

    \(CAR = 0.012 + 0.025 - 0.005 = 0.032\).

  8. What adjustment does the cluster-robust CR1 variance estimator include to correct for a small number of clusters \(G\)?

    The standard CR1 small-sample cluster correction factor is \(\frac{G}{G - 1}\).
