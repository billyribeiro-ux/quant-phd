The Autoregressive Conditional Heteroskedasticity (ARCH) Model

Engle's Paradigm Shift: Explicit Parameterization of Dynamic Variance and Fourth-Moment Breakdown

Why It Matters

Before 1982, econometricians treated heteroskedasticity as a nuisance to be corrected using robust standard errors rather than a structure to be modeled. Robert Engle demonstrated that conditional variance is an autoregressive state variable that carries vital economic information. The ARCH model provided the first mathematically coherent framework linking today's variance to past squared return shocks. This revolutionized option pricing, risk budgeting, and macro-financial forecasting by turning changing uncertainty from an econometric defect into an explicitly forecastable quantity, earning Engle the 2003 Nobel Memorial Prize in Economic Sciences.

1. Mathematical Formulation of the ARCH(q) Process

In his seminal paper, Engle (1982) decomposed discrete-time return innovations into a stationary standardized white noise shock scaled by a time-varying conditional standard deviation.

Definition 2.1 · ARCH(q) Model

Let \(\{\varepsilon_t\}\) be a real-valued discrete-time stochastic process adapted to filtration \(\mathcal{F}_{t-1}\). The process is an ARCH model of order \(q\), denoted ARCH(\(q\)), if:

\[ \begin{aligned} \varepsilon_t &= \sigma_t z_t, \\ z_t &\iid \Normal(0, 1), \\ \sigma_t^2 &= \omega + \sum_{i=1}^q \alpha_i \varepsilon_{t-i}^2, \end{aligned} \]

where \(z_t\) is independent of \(\mathcal{F}_{t-1}\). To guarantee that the conditional variance \(\sigma_t^2 > 0\) almost surely for all \(t\), the parameter constraints are \(\omega > 0\) and \(\alpha_i \ge 0\) for all \(i \in \{1, \dots, q\}\).

Remark 2.1 · Mechanism for Volatility Clustering

The ARCH specification directly generates volatility clustering. If a large shock occurs at \(t-1\), \(\varepsilon_{t-1}^2\) is large. Through the conditional variance equation, this elevates \(\sigma_t^2\), making a large realization of \(|\varepsilon_t| = \sigma_t |z_t|\) highly probable today. Conversely, a quiet period with small \(\varepsilon_{t-1}^2\) depresses \(\sigma_t^2\), inducing persistent tranquility.

Theorem 2.1 · Stationarity, Unconditional Variance, and Kurtosis of ARCH(1)

Assumptions:

  1. Let \(\varepsilon_t = \sigma_t z_t\) with \(\sigma_t^2 = \omega + \alpha \varepsilon_{t-1}^2\).
  2. The standardized innovations satisfy \(z_t \iid \Normal(0, 1)\).
  3. Parameter constraints: \(\omega > 0\) and \(\alpha \ge 0\).

Conclusions:

  1. The process is weakly stationary if and only if \(\alpha < 1\). The unconditional variance is: \[ \Var(\varepsilon_t) = \sigma^2 = \frac{\omega}{1 - \alpha}. \]
  2. The fourth moment \(\E[\varepsilon_t^4]\) is finite if and only if \(3\alpha^2 < 1\) (\(\alpha < 1/\sqrt{3} \approx 0.5773\)). When finite, the unconditional kurtosis is: \[ \kappa = \frac{\E[\varepsilon_t^4]}{(\E[\varepsilon_t^2])^2} = 3 \frac{1 - \alpha^2}{1 - 3\alpha^2} > 3. \]
Proof

Step 1: Unconditional Variance. Taking the unconditional expectation of \(\varepsilon_t^2 = \sigma_t^2 z_t^2\) and using the law of iterated expectations:

\[ \E[\varepsilon_t^2] = \E[\E[\sigma_t^2 z_t^2 \mid \mathcal{F}_{t-1}]] = \E[\sigma_t^2 \E[z_t^2 \mid \mathcal{F}_{t-1}]] = \E[\sigma_t^2]. \]

Substituting \(\sigma_t^2 = \omega + \alpha \varepsilon_{t-1}^2\):

\[ \E[\varepsilon_t^2] = \omega + \alpha \E[\varepsilon_{t-1}^2]. \]

Under weak stationarity, \(\E[\varepsilon_t^2] = \E[\varepsilon_{t-1}^2] = \sigma^2\). Solving yields \(\sigma^2 (1 - \alpha) = \omega\), which requires \(\alpha < 1\) to ensure \(\sigma^2 = \omega / (1 - \alpha) > 0\).

Step 2: Fourth Moment and Kurtosis. Since \(z_t \iid \Normal(0,1)\), \(\E[z_t^4 \mid \mathcal{F}_{t-1}] = 3\). Thus:

\[ \E[\varepsilon_t^4] = \E[\sigma_t^4 z_t^4] = 3 \E[\sigma_t^4] = 3 \E[(\omega + \alpha \varepsilon_{t-1}^2)^2]. \]

Expanding the square:

\[ \E[\sigma_t^4] = \omega^2 + 2\omega\alpha \E[\varepsilon_{t-1}^2] + \alpha^2 \E[\varepsilon_{t-1}^4]. \]

Substituting \(\E[\varepsilon_{t-1}^2] = \omega / (1 - \alpha)\) and imposing fourth-moment stationarity \(\E[\varepsilon_t^4] = \E[\varepsilon_{t-1}^4]\):

\[ \E[\varepsilon_t^4] = 3\left(\omega^2 + \frac{2\omega^2 \alpha}{1 - \alpha}\right) + 3\alpha^2 \E[\varepsilon_t^4] = \frac{3\omega^2(1 + \alpha)}{1 - \alpha} + 3\alpha^2 \E[\varepsilon_t^4]. \]

Rearranging terms gives:

\[ \E[\varepsilon_t^4](1 - 3\alpha^2) = \frac{3\omega^2(1 + \alpha)}{1 - \alpha}. \]

For \(\E[\varepsilon_t^4] < \infty\), we must have \(1 - 3\alpha^2 > 0 \iff \alpha < 1/\sqrt{3}\). When this holds:

\[ \E[\varepsilon_t^4] = \frac{3\omega^2(1 + \alpha)}{(1 - \alpha)(1 - 3\alpha^2)}. \]

Dividing by \((\E[\varepsilon_t^2])^2 = \omega^2 / (1 - \alpha)^2\):

\[ \kappa = \frac{3\omega^2(1 + \alpha)}{(1 - \alpha)(1 - 3\alpha^2)} \cdot \frac{(1 - \alpha)^2}{\omega^2} = 3 \frac{(1 + \alpha)(1 - \alpha)}{1 - 3\alpha^2} = 3 \frac{1 - \alpha^2}{1 - 3\alpha^2}. \]

Since \(1 - 3\alpha^2 < 1 - \alpha^2\), the fraction is strictly greater than 1 for \(\alpha > 0\), proving \(\kappa > 3\).

Example 2.1 · Kurtosis for Selected Alpha Values

Consider an ARCH(1) process with \(\omega = 0.20\):

  • If \(\alpha = 0.30\): \(3\alpha^2 = 3(0.09) = 0.27 < 1\). Unconditional variance is \(\sigma^2 = 0.20 / 0.70 \approx 0.2857\). Kurtosis is \(\kappa = 3(1 - 0.09) / (1 - 0.27) = 3(0.91) / 0.73 \approx 3.7397\) (excess kurtosis \(\approx 0.74\)).
  • If \(\alpha = 0.50\): \(3\alpha^2 = 3(0.25) = 0.75 < 1\). Unconditional variance is \(\sigma^2 = 0.20 / 0.50 = 0.4000\). Kurtosis is \(\kappa = 3(1 - 0.25) / (1 - 0.75) = 3(0.75) / 0.25 = 9.0000\) (excess kurtosis \(= 6.00\)).
  • If \(\alpha = 0.60\): \(3\alpha^2 = 3(0.36) = 1.08 > 1\). Even though the process is covariance stationary (\(\alpha < 1\)), the fourth moment diverges to infinity, resulting in undefined population kurtosis.

2. Empirical Simulation of the ARCH(1) Process

To verify the moment recursion and investigate the finite-sample distribution of sample kurtosis, we simulate an ARCH(1) process with \(\omega = 0.20\) and \(\alpha = 0.50\).

Lab 1 · ARCH(1) Simulation and Moment Verification

Simulating an ARCH(1) path with omega=0.20 and alpha=0.50 reproduces the theoretical unconditional variance 0.40 within sampling variation and confirms pronounced excess kurtosis (sample kurtosis > 3.0).

"""Lab S4-L02-1: ARCH(1) simulation, moment recursion, and fat tails.

SIMULATED: generates stationary ARCH(1) path and compares empirical variance
and kurtosis against theoretical closed-form population moments.
"""

from __future__ import annotations

import math
import random


def simulate_arch1(omega: float, alpha: float, n: int, seed: int = 42) -> tuple[list[float], list[float]]:
    """Simulate ARCH(1) process with burn-in."""
    rng = random.Random(seed)
    burn = 500
    uncond_var = omega / (1.0 - alpha)
    h = uncond_var
    for _ in range(burn):
        z = rng.gauss(0.0, 1.0)
        eps = math.sqrt(h) * z
        h = omega + alpha * (eps**2)

    epsilons: list[float] = []
    variances: list[float] = []
    for _ in range(n):
        z = rng.gauss(0.0, 1.0)
        eps = math.sqrt(h) * z
        epsilons.append(eps)
        variances.append(h)
        h = omega + alpha * (eps**2)
    return epsilons, variances


def main() -> None:
    omega = 0.20
    alpha = 0.50
    n = 10000
    eps, _ = simulate_arch1(omega, alpha, n, seed=42)

    var_emp = sum(e * e for e in eps) / n
    m4_emp = sum(e**4 for e in eps) / n
    kurt_emp = m4_emp / (var_emp**2)

    theo_var = omega / (1.0 - alpha)
    theo_kurt = 3.0 * (1.0 - alpha**2) / (1.0 - 3.0 * alpha**2)

    print(f"ARCH(1) Simulation (omega={omega:.2f}, alpha={alpha:.2f}, n={n})")
    print(f"Theoretical unconditional variance: {theo_var:.4f}")
    print(f"Empirical sample variance:          {var_emp:.4f}")
    print(f"Theoretical kurtosis:               {theo_kurt:.4f} (excess kurtosis: {theo_kurt - 3.0:.4f})")
    print(f"Empirical sample kurtosis:          {kurt_emp:.4f} (excess kurtosis: {kurt_emp - 3.0:.4f})")
    print(f"Leptokurtic fat tails confirmed:    {kurt_emp > 3.0}")


main()
ARCH(1) Simulation (omega=0.20, alpha=0.50, n=10000)
Theoretical unconditional variance: 0.4000
Empirical sample variance:          0.3952
Theoretical kurtosis:               9.0000 (excess kurtosis: 6.0000)
Empirical sample kurtosis:          5.8690 (excess kurtosis: 2.8690)
Leptokurtic fat tails confirmed:    True

The simulation confirms that ARCH dynamics naturally generate leptokurtic asset returns. Note that empirical kurtosis in heavy-tailed samples exhibits Kendall-Hurwicz downward finite-sample bias, but still comfortably exceeds 3.0, proving that conditional heteroskedasticity accounts for fat tails.

Where the Canon Breaks

While the ARCH model represented a breakthrough in financial econometrics, its empirical limitations quickly became apparent in practice:

  • Excessive lag length requirement: To capture the long-lasting persistence of volatility shocks in financial markets, an ARCH(\(q\)) model requires large lag orders (\(q = 8\) to \(20\)). Estimating so many unconstrained parameters frequently violates non-negativity constraints (\(\alpha_i \ge 0\)) and inflates parameter estimation error.
  • Restrictive fourth-moment existence: In empirical asset pricing, typical estimated persistence parameters exceed \(0.60\). Under ARCH(1), \(\alpha > 1/\sqrt{3} \approx 0.577\) implies that the theoretical fourth moment is infinite, creating severe instability in volatility forecasts.
  • Symmetric response to asymmetric shocks: In ARCH(\(q\)), \(\varepsilon_{t-i}^2\) depends only on the magnitude of past shocks and ignores their sign. This contradicts the well-documented market phenomenon where negative return shocks trigger much higher volatility than positive shocks of equal magnitude.

Misconceptions

  • Wrong belief: An ARCH(1) process with \(\alpha = 0.65\) is non-stationary because its fourth moment is infinite.

    Why it is wrong: Weak (covariance) stationarity requires only that first and second moments are constant and finite over time, which holds whenever \(\alpha < 1\). Divergence of the fourth moment does not violate covariance stationarity.

  • Wrong belief: The ARCH model assumes that returns are unconditionally normally distributed.

    Why it is wrong: The ARCH model assumes conditional normality (\(\varepsilon_t \mid \mathcal{F}_{t-1} \sim \Normal(0, \sigma_t^2)\)). The unconditional distribution is a continuous mixture of normals with distinct variances, which is strictly non-Gaussian and leptokurtic.

  • Wrong belief: Ordinary least squares (OLS) can be applied directly to \(\varepsilon_t^2 = \omega + \alpha \varepsilon_{t-1}^2 + u_t\) to obtain efficient estimates.

    Why it is wrong: While OLS is consistent under fourth-moment stationarity, the innovation \(u_t = \varepsilon_t^2 - \sigma_t^2\) is itself severely heteroskedastic (\(\Var(u_t \mid \mathcal{F}_{t-1}) = 2\sigma_t^4\)), rendering OLS highly inefficient compared to Maximum Likelihood Estimation.

Practice Problems

Mechanics Tier

An ARCH(1) model has parameters \(\omega = 0.15\) and \(\alpha = 0.40\). Compute its unconditional variance \(\sigma^2\), check the condition for finite fourth moments, and calculate its population kurtosis \(\kappa\).

Worked Solution

The unconditional variance is \(\sigma^2 = \omega / (1 - \alpha) = 0.15 / (1 - 0.40) = 0.15 / 0.60 = 0.2500\). The fourth-moment existence condition requires \(3\alpha^2 < 1\). Here, \(3(0.40^2) = 3(0.16) = 0.48 < 1\), so the fourth moment exists. Population kurtosis is: \[ \kappa = 3 \frac{1 - \alpha^2}{1 - 3\alpha^2} = 3 \frac{1 - 0.16}{1 - 0.48} = 3 \frac{0.84}{0.52} = 3 \times 1.6154 \approx 4.8462. \] The process exhibits excess kurtosis of \(1.8462\).

Given an ARCH(1) process with \(\omega = 0.05\) and current conditional variance \(\sigma_t^2 = 0.20\), calculate the expected conditional variance \(\E[\sigma_{t+1}^2 \mid \mathcal{F}_{t-1}]\) if \(\alpha = 0.35\).

Worked Solution

By definition, \(\sigma_{t+1}^2 = \omega + \alpha \varepsilon_t^2\). Taking expectations conditional on \(\mathcal{F}_{t-1}\): \[ \E[\sigma_{t+1}^2 \mid \mathcal{F}_{t-1}] = \omega + \alpha \E[\varepsilon_t^2 \mid \mathcal{F}_{t-1}] = \omega + \alpha \sigma_t^2. \] Substituting the given values: \(\E[\sigma_{t+1}^2 \mid \mathcal{F}_{t-1}] = 0.05 + 0.35 \times 0.20 = 0.05 + 0.07 = 0.1200\).

Determine the maximum permissible value of \(\alpha\) in an ARCH(1) process such that the unconditional excess kurtosis does not exceed 1.00.

Worked Solution

Excess kurtosis is \(\kappa - 3 = 3(1 - \alpha^2)/(1 - 3\alpha^2) - 3 = 6\alpha^2 / (1 - 3\alpha^2)\). Setting this equal to 1.00: \[ \frac{6\alpha^2}{1 - 3\alpha^2} = 1.00 \implies 6\alpha^2 = 1 - 3\alpha^2 \implies 9\alpha^2 = 1 \implies \alpha^2 = \frac{1}{9}. \] Since \(\alpha \ge 0\), \(\alpha = 1/3 \approx 0.3333\). Thus, \(\alpha \le 1/3\).

Proof Tier

Prove that in an ARCH(1) model with \(\alpha < 1\), the squared innovations \(\varepsilon_t^2\) follow an AR(1) representation with white noise innovations.

Worked Solution

Define \(u_t = \varepsilon_t^2 - \sigma_t^2\). Notice that \(\E[u_t \mid \mathcal{F}_{t-1}] = \E[\varepsilon_t^2 \mid \mathcal{F}_{t-1}] - \sigma_t^2 = 0\), so \(u_t\) is a martingale difference sequence (white noise). Rearranging gives \(\sigma_t^2 = \varepsilon_t^2 - u_t\). Substituting this into the ARCH(1) equation \(\sigma_t^2 = \omega + \alpha \varepsilon_{t-1}^2\): \[ \varepsilon_t^2 - u_t = \omega + \alpha \varepsilon_{t-1}^2 \implies \varepsilon_t^2 = \omega + \alpha \varepsilon_{t-1}^2 + u_t. \] This is an explicit AR(1) process for squared returns with autoregressive coefficient \(\alpha\) and zero-mean innovation \(u_t\).

Prove that the conditional variance of the innovation \(u_t = \varepsilon_t^2 - \sigma_t^2\) is given by \(\Var(u_t \mid \mathcal{F}_{t-1}) = 2\sigma_t^4\) under Gaussian standardized shocks \(z_t \iid \Normal(0,1)\).

Worked Solution

Since \(\varepsilon_t = \sigma_t z_t\), we write \(u_t = \sigma_t^2 z_t^2 - \sigma_t^2 = \sigma_t^2 (z_t^2 - 1)\). The conditional variance is: \[ \Var(u_t \mid \mathcal{F}_{t-1}) = \E[u_t^2 \mid \mathcal{F}_{t-1}] = \E[\sigma_t^4 (z_t^2 - 1)^2 \mid \mathcal{F}_{t-1}] = \sigma_t^4 \E[(z_t^2 - 1)^2 \mid \mathcal{F}_{t-1}]. \] Since \(z_t \iid \Normal(0,1)\), \(\E[z_t^2] = 1\) and \(\E[z_t^4] = 3\). Thus, \(\E[(z_t^2 - 1)^2] = \E[z_t^4] - 2\E[z_t^2] + 1 = 3 - 2 + 1 = 2\). Multiplying gives \(\Var(u_t \mid \mathcal{F}_{t-1}) = 2\sigma_t^4\).

Prove that if \(\alpha \ge 1/\sqrt{3}\) in an ARCH(1) process, the fourth moment \(\E[\varepsilon_t^4]\) does not converge to a finite positive number.

Worked Solution

Consider the backward recursion for the fourth moment \(\E[\varepsilon_t^4] = 3 \omega^2 (1 + \alpha)/(1 - \alpha) + 3\alpha^2 \E[\varepsilon_{t-1}^4]\). Iterating backward \(k\) periods: \[ \E[\varepsilon_t^4] = \frac{3\omega^2(1+\alpha)}{1-\alpha} \sum_{j=0}^{k-1} (3\alpha^2)^j + (3\alpha^2)^k \E[\varepsilon_{t-k}^4]. \] This series converges as \(k \to \infty\) if and only if the ratio of the geometric series \(3\alpha^2 < 1\). If \(3\alpha^2 \ge 1\), the partial sums diverge to infinity because \(\omega > 0\), establishing that \(\E[\varepsilon_t^4] = \infty\).

Empirical Tier

In an empirical estimation of an ARCH(1) model on equity indices, an analyst obtains \(\hat{\omega} = 0.08\) and \(\hat{\alpha} = 0.62\). Evaluate the econometric validity of this model.

Worked Solution

Since \(\hat{\alpha} = 0.62 < 1.0\), the estimated process is covariance stationary with estimated unconditional variance \(\hat{\sigma}^2 = 0.08 / (1 - 0.62) \approx 0.2105\). However, \(3\hat{\alpha}^2 = 3(0.62^2) = 3(0.3844) = 1.1532 > 1.0\). This implies that the model's theoretical fourth moment is infinite. Standard errors based on fourth-moment regularity conditions are invalid, and simulated paths will exhibit explosive kurtosis spikes.

Explain why Engle's ARCH LM test for conditional heteroskedasticity is asymptotically equivalent to the Breusch-Pagan test on squared residuals.

Worked Solution

Engle (1982) showed that testing \(H_0: \alpha_1 = \dots = \alpha_q = 0\) via Lagrange Multiplier principles corresponds to regressing squared residuals \(\hat{e}_t^2\) on an intercept and \(q\) lagged squared residuals \(\hat{e}_{t-1}^2, \dots, \hat{e}_{t-q}^2\). The test statistic is \(T R^2 \xrightarrow{d} \chi^2(q)\). Under the null of constant variance, this is mathematically identical to a Breusch-Pagan test where the candidate explanatory variables for variance are the lagged squared residuals.

How does an ARCH(1) model behave during an acute market crisis (such as October 1987 or March 2020), and why does it revert too rapidly to baseline?

Worked Solution

In an ARCH(1) model, conditional variance depends on only a single lag \(\varepsilon_{t-1}^2\). Following an extreme crash shock, \(\sigma_t^2\) surges immediately on day \(t\). However, if day \(t\) experiences a modest return, \(\varepsilon_t^2\) is small, causing \(\sigma_{t+1}^2 = \omega + \alpha \varepsilon_t^2\) to collapse back to near-normal levels on day \(t+1\). In real markets, heightened volatility persists for months following a crisis shock, exposing the single-lag ARCH specification as far too memoryless.

Research Tier

Analyze the asymptotic distribution of Quasi-Maximum Likelihood Estimators (QMLE) for ARCH models when true innovations are non-Gaussian (e.g., Student-t).

Worked Solution

Weiss (1986) and Bollerslev & Wooldridge (1992) established that if conditional variance is correctly specified, Gaussian QMLE parameter estimates \(\hat{\theta}\) remain consistent and asymptotically normal: \(\sqrt{T}(\hat{\theta} - \theta_0) \xrightarrow{d} \Normal(0, A^{-1} B A^{-1})\), where \(A\) is the expected Hessian and \(B\) is the outer product of the score. When innovations are non-Gaussian with kurtosis \(\kappa_z \ne 3\), the information matrix equality \(A = B\) fails, requiring robust Huber-White sandwich covariance corrections.

Contrast the parameter constraints required in ARCH(\(q\)) models under linear inequality restrictions versus Nelson and Cao's (1992) necessary and sufficient conditions.

Worked Solution

Standard textbook ARCH requires \(\omega > 0\) and all \(\alpha_i \ge 0\) for \(i=1,\dots,q\) (sufficient conditions). Nelson and Cao (1992) showed that these non-negativity constraints are overly restrictive for higher-order lag polynomials. A negative coefficient \(\alpha_i < 0\) is permissible provided that the moving-average representation \(\sigma_t^2 = \psi_0 + \sum_{j=1}^\infty \psi_j \varepsilon_{t-j}^2\) has strictly non-negative weights \(\psi_j \ge 0\) for all \(j\). However, enforcing these weaker conditions during optimization is numerically challenging.

Formulate the ARCH-in-Mean (ARCH-M) model of Engle, Lilien, and Robins (1987) and explain its asset-pricing justification.

Worked Solution

In standard asset pricing theory (e.g., CAPM or Merton's ICAPM), risk-averse investors demand higher expected returns to hold an asset during periods of elevated volatility. The ARCH-in-Mean model introduces the conditional variance into the mean equation: \(r_t = \mu + \delta \sigma_t^2 + \varepsilon_t\) (or \(\delta \sigma_t\)), where \(\varepsilon_t \mid \mathcal{F}_{t-1} \sim \Normal(0, \sigma_t^2)\). The parameter \(\delta\) represents the coefficient of relative risk aversion. It links the time-varying risk premium directly to the econometric conditional volatility process.

Retrieval Quiz

  1. In an ARCH(1) process \(\sigma_t^2 = \omega + \alpha \varepsilon_{t-1}^2\), what condition is necessary and sufficient for weak (covariance) stationarity?

    Weak stationarity requires the autoregressive root in squared shocks to lie outside the unit circle, which requires \(\alpha < 1\).

  2. What condition governs the existence of a finite fourth moment in an ARCH(1) process with Gaussian innovations?

    Because \(\E[z_t^4] = 3\) for standard normal shocks, the fourth moment recursion has ratio \(3\alpha^2\), which must be strictly less than 1.

  3. What is the population kurtosis of an ARCH(1) process with \(\alpha = 0.40\)?

    Using \(\kappa = 3(1 - \alpha^2)/(1 - 3\alpha^2) = 3(0.84)/0.52 \approx 4.8462\).

  4. How does an ARCH model generate fat-tailed unconditional distributions from conditionally Gaussian shocks?

    Mixtures of zero-mean Gaussians with fluctuating variance always have kurtosis \(\kappa \ge 3\), with strict inequality if variance is non-degenerate.

  5. What major empirical drawback of the pure ARCH(\(q\)) model motivated the development of GARCH?

    High-order ARCH models require estimating many parameters \(\alpha_1, \dots, \alpha_q\), which is statistically inefficient and prone to boundary violations.

  6. In an ARCH(1) process with \(\omega = 0.10\) and \(\alpha = 0.50\), what is the unconditional variance \(\sigma^2\)?

    \(\sigma^2 = \omega / (1 - \alpha) = 0.10 / 0.50 = 0.2000\).

  7. Why is the standard ARCH model unable to capture the leverage effect observed in equity markets?

    Squaring the past return shock eliminates its sign, making the news-impact curve completely symmetric around zero.

  8. If \(\alpha = 0.70\) in an ARCH(1) process with \(\omega = 0.05\), what can be said about the process?

    \(\alpha = 0.70 < 1\) satisfies second-moment stationarity, but \(3\alpha^2 = 1.47 > 1\) causes the fourth moment to diverge.
