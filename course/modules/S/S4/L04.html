Asymmetric Volatility & The EGARCH Model

The Leverage Effect, Unconstrained Log-Variance Dynamics, and Nelson's News-Impact Curve

Why It Matters

Standard GARCH models assume that volatility responds symmetrically to market shocks: a 5% market surge and a 5% market crash generate identical conditional variance forecasts tomorrow. In equity markets, this symmetry is flatly contradicted by data. Market selloffs trigger violent spikes in implied and realized volatility, whereas rallies tend to calm markets. Daniel Nelson revolutionized volatility modeling with the Exponential GARCH (EGARCH) model. By parameterizing the logarithm of conditional variance, EGARCH captures this asymmetric leverage effect while guaranteeing strictly positive variances without artificial parameter restrictions, providing the mathematical backbone for options skew modeling.

1. The Leverage Effect and Asymmetric Volatility

The asymmetric relationship between equity returns and volatility changes is among the most robust stylized facts in empirical finance.

Definition 4.1 · The Leverage Effect

The leverage effect is the empirical negative correlation between current asset returns and future volatility innovations:

\[ \operatorname{Corr}(r_t, \sigma_{t+1}^2) < 0. \]

A negative return shock (\(r_t < 0\)) produces a substantially larger increase in next-period conditional variance \(\sigma_{t+1}^2\) than a positive return shock (\(r_t > 0\)) of identical absolute magnitude.

Remark 4.1 · Financial Leverage vs. Volatility Feedback

Two primary economic mechanisms explain the leverage effect:

  1. Financial Leverage Hypothesis (Black 1976, Christie 1982): When a firm's stock price falls, the market value of its equity declines while its debt obligations remain fixed. This mechanically increases the firm's financial debt-to-equity ratio (leverage), making future equity cash flows fundamentally riskier.
  2. Volatility Feedback Hypothesis (French, Schwert & Stambaugh 1987, Campbell & Hentschel 1992): If volatility is priced, an anticipated rise in future risk requires higher future expected returns. To generate higher expected returns, the current asset price must immediately drop, creating contemporaneous negative returns whenever volatility rises.

2. Nelson's Exponential GARCH (EGARCH) Model

To overcome the symmetry and parameter boundary traps of standard GARCH models, Nelson (1991) formulated the Exponential GARCH model.

Definition 4.2 · The EGARCH(1,1) Model

Let \(\varepsilon_t = \sigma_t z_t\) with \(z_t \iid \Normal(0,1)\). The EGARCH model specifies the evolution of the natural logarithm of conditional variance:

\[ \ln \sigma_t^2 = \omega + \beta \ln \sigma_{t-1}^2 + g(z_{t-1}), \]

where the news-impact function \(g(z)\) is defined as:

\[ g(z) = \alpha (|z| - \E[|z|]) + \gamma z. \]

Under standard Gaussian innovations \(z \sim \Normal(0,1)\), the expected absolute value evaluates to \(\E[|z|] = \sqrt{2/\pi} \approx 0.79788\).

Theorem 4.1 · Mathematical Properties of the EGARCH(1,1) Model

Assumptions:

  1. Let \(\ln \sigma_t^2 = \omega + \beta \ln \sigma_{t-1}^2 + \alpha (|z_{t-1}| - \sqrt{2/\pi}) + \gamma z_{t-1}\).
  2. Innovations satisfy \(z_t \iid \Normal(0,1)\) independent of \(\mathcal{F}_{t-1}\).
  3. Parameters \(\omega, \beta, \alpha, \gamma \in \R\).

Conclusions:

  1. Automatic Positivity: Conditional variance is strictly positive almost surely (\(\sigma_t^2 = \exp(\ln \sigma_t^2) > 0\)) for any parameter values without requiring non-negativity inequality constraints.
  2. Covariance Stationarity of Log-Variance: The log-variance process \(\ln \sigma_t^2\) is weakly stationary if and only if \(|\beta| < 1\). The unconditional mean of log-variance is: \[ \E[\ln \sigma_t^2] = \frac{\omega}{1 - \beta}. \]
  3. Asymmetric Slopes: The derivative of the news-impact function with respect to standardized shock \(z\) is piecewise linear: \[ g'(z) = \begin{cases} \alpha + \gamma, & \text{if } z > 0, \\ -\alpha + \gamma, & \text{if } z < 0. \end{cases} \] When \(\gamma < 0\), a negative shock (\(z < 0\)) has slope magnitude \(|\alpha - \gamma| = \alpha + |\gamma|\), while a positive shock has slope magnitude \(\alpha - |\gamma|\).
Proof

Part 1: Positivity. The exponential map \(\exp: \R \to (0, \infty)\) is strictly positive on the entire real line. Because \(\ln \sigma_t^2 \in \R\), \(\sigma_t^2 = \exp(\ln \sigma_t^2) > 0\) for all \(t\), regardless of the signs of \(\omega, \beta, \alpha, \gamma\).

Part 2: Stationarity of Log-Variance. By construction, \(\E[g(z_{t-1})] = \alpha(\E[|z_{t-1}|] - \sqrt{2/\pi}) + \gamma \E[z_{t-1}] = 0\). Thus, \(\ln \sigma_t^2\) is an AR(1) process with zero-mean innovation \(g(z_{t-1})\) and autoregressive parameter \(\beta\). An AR(1) is weakly stationary if and only if its autoregressive root lies outside the unit circle, which requires \(|\beta| < 1\). Taking unconditional expectations yields \(\E[\ln \sigma_t^2] = \omega + \beta \E[\ln \sigma_{t-1}^2] \implies \E[\ln \sigma_t^2] = \omega / (1 - \beta)\).

Part 3: Piecewise Slopes. For \(z > 0\), \(|z| = z\), so \(g(z) = \alpha z - \alpha\sqrt{2/\pi} + \gamma z = (\alpha + \gamma)z - \alpha\sqrt{2/\pi}\), with derivative \(\alpha + \gamma\). For \(z < 0\), \(|z| = -z\), so \(g(z) = -\alpha z - \alpha\sqrt{2/\pi} + \gamma z = (-\alpha + \gamma)z - \alpha\sqrt{2/\pi}\), with derivative \(-\alpha + \gamma\). If \(\gamma < 0\), \(-\alpha + \gamma = -(\alpha + |\gamma|)\), demonstrating a steeper response to negative shocks.

Example 4.1 · Quantifying Asymmetry

Let \(\alpha = 0.20\) and \(\gamma = -0.15\). For positive shocks (\(z > 0\)), the slope is \(\alpha + \gamma = 0.20 - 0.15 = +0.05\). For negative shocks (\(z < 0\)), the slope is \(-\alpha + \gamma = -0.20 - 0.15 = -0.35\). The magnitude of the response to a negative shock is \(|-0.35| / 0.05 = 7.0\) times greater than to an equivalent positive shock!

3. Empirical Evaluation of the News-Impact Curve

We evaluate Nelson's news-impact function \(g(z)\) across a range of standardized shocks from \(-3.0\) to \(+3.0\) standard deviations.

Lab 1 · The EGARCH News-Impact Curve and Leverage Asymmetry

Evaluating the EGARCH news-impact curve with alpha=0.20 and gamma=-0.15 reveals pronounced asymmetry: negative shocks produce a response slope seven times steeper than positive shocks, confirming the leverage effect.

"""Lab S4-L04-1: The EGARCH news-impact curve and asymmetric leverage effect.

Evaluates Nelson (1991) news-impact curve across standardized shocks,
quantifying the asymmetric volatility response to negative versus positive returns.
"""

from __future__ import annotations

import math


def egarch_news_impact(z: float, alpha: float, gamma: float) -> float:
    """Compute EGARCH news impact function g(z) = alpha * (|z| - E[|z|]) + gamma * z."""
    expected_abs_z = math.sqrt(2.0 / math.pi)
    return float(alpha * (abs(z) - expected_abs_z) + gamma * z)


def main() -> None:
    alpha = 0.20
    gamma = -0.15
    expected_abs_z = math.sqrt(2.0 / math.pi)

    shocks = [-3.0, -2.0, -1.0, 0.0, 1.0, 2.0, 3.0]

    print(f"EGARCH(1,1) News Impact: alpha={alpha:.2f}, gamma={gamma:.2f}, E[|z|]={expected_abs_z:.4f}")
    print("Shock z | News Impact g(z) | Negative Slope | Positive Slope | Asymmetry Ratio")
    print("-" * 75)

    neg_slope = alpha - gamma  # 0.20 - (-0.15) = 0.35
    pos_slope = alpha + gamma  # 0.20 + (-0.15) = 0.05
    asym_ratio = neg_slope / pos_slope

    for z in shocks:
        val = egarch_news_impact(z, alpha, gamma)
        print(
            f"  {z:+4.1f}  |       {val:+8.4f}   |"
            f"          {neg_slope:.2f}  |          {pos_slope:.2f}  |          {asym_ratio:.1f}x"
        )


main()

The lab confirms the severe asymmetry of the news-impact curve. A 3-standard-deviation market selloff increases log-variance by +0.8904, whereas a 3-standard-deviation rally slightly contracts log-variance (-0.0096). This explains why equity index option smiles exhibit downward-sloping skews.

Where the Canon Breaks

Although EGARCH solves the positivity constraint and captures the leverage effect, several econometric challenges remain:

  • Outlier over-sensitivity: Because conditional variance depends on \(\exp(g(z))\), extreme return shocks (such as a 10-standard-deviation market crash) enter exponentially into future variance. This can cause explosive, unrealistic variance forecasts following isolated data spikes.
  • Inverting conditional variance for forecasts: Because \(\E[\exp(X)] \ne \exp(\E[X])\), multi-step forecasts of the level of conditional variance \(\E[\sigma_{t+k}^2 \mid \mathcal{F}_t]\) cannot be computed simply by exponentiating the forecast of \(\ln \sigma_{t+k}^2\). Researchers must evaluate the moment-generating function of the innovation sum, which depends heavily on the distributional assumption of \(z_t\).
  • Non-invertibility under non-Gaussian innovations: Wintenberger (2013) demonstrated that checking the strict invertibility of EGARCH models under heavy-tailed innovations is mathematically intricate and can fail if parameters do not satisfy contraction conditions.

Misconceptions

  • Wrong belief: The leverage effect is exclusively caused by corporate debt obligations.

    Why it is wrong: Christie (1982) and Bekaert & Wu (2000) showed that financial debt leverage accounts for only a fraction of the observed empirical asymmetry. Unlevered firms and macroeconomic market-wide portfolios display strong leverage effects, which are driven by volatility feedback risk premiums.

  • Wrong belief: EGARCH requires non-negativity constraints on \(\omega, \alpha\), and \(\beta\) to guarantee positive variance.

    Why it is wrong: EGARCH models \(\ln \sigma_t^2\). Exponentiating any real number yields a strictly positive variance (\(\sigma_t^2 = \exp(\ln \sigma_t^2) > 0\)), eliminating the need for boundary constraints during optimization.

  • Wrong belief: Multi-step volatility forecasts in EGARCH are computed as \(\hat{\sigma}_{t+k}^2 = \exp(\widehat{\ln \sigma_{t+k}^2})\).

    Why it is wrong: By Jensen's inequality, \(\E[\exp(X)] > \exp(\E[X])\) for any non-degenerate random variable. Exponentiating the expected log-variance severely underestimates the true expected future variance by omitting the Jensen inequality convexity adjustment.

Practice Problems

Mechanics Tier

An EGARCH(1,1) model has parameters \(\alpha = 0.25\) and \(\gamma = -0.10\). Compute the slope of the news-impact function for positive standardized shocks (\(z > 0\)) and for negative standardized shocks (\(z < 0\)), and determine the asymmetry ratio.

Worked Solution

For positive shocks (\(z > 0\)), the slope is \(s_+ = \alpha + \gamma = 0.25 + (-0.10) = +0.15\). For negative shocks (\(z < 0\)), the slope is \(s_- = -\alpha + \gamma = -0.25 - 0.10 = -0.35\). The magnitude of the response to negative shocks is \(|-0.35| = 0.35\). The asymmetry ratio is \(|s_-| / s_+ = 0.35 / 0.15 \approx 2.3333\).

Given an EGARCH(1,1) model with \(\omega = -0.10\) and \(\beta = 0.90\), calculate the unconditional mean of log-variance \(\E[\ln \sigma_t^2]\), and evaluate \(\exp(\E[\ln \sigma_t^2])\).

Worked Solution

Under \(|\beta| < 1\), the unconditional mean of log-variance is \(\mu_{\ln} = \omega / (1 - \beta) = -0.10 / (1 - 0.90) = -0.10 / 0.10 = -1.0000\). Exponentiating this value gives \(\exp(-1.0) \approx 0.3679\). Note that by Jensen's inequality, the true unconditional variance \(\E[\sigma_t^2]\) is strictly greater than \(0.3679\).

In an EGARCH(1,1) model with \(\alpha = 0.18\) and \(\gamma = -0.12\), evaluate the news impact \(g(z)\) for a standardized return shock of \(z = -2.50\), assuming \(z \sim \Normal(0,1)\).

Worked Solution

For standard normal innovations, \(\E[|z|] = \sqrt{2/\pi} \approx 0.79788\). For \(z = -2.50\), \(|z| = 2.50\). Evaluating \(g(z)\): \[ g(-2.50) = 0.18 \times (2.50 - 0.79788) + (-0.12) \times (-2.50) = 0.18 \times 1.70212 + 0.3000 = 0.30638 + 0.3000 = 0.6064. \]

Proof Tier

Prove that \(\E[g(z_t)] = 0\) for any standardized innovation \(z_t \iid \Normal(0,1)\), where \(g(z) = \alpha(|z| - \E[|z|]) + \gamma z\).

Worked Solution

By linearity of expectation: \[ \E[g(z_t)] = \alpha \E[|z_t| - \E[|z_t|]] + \gamma \E[z_t] = \alpha(\E[|z_t|] - \E[|z_t|]) + \gamma \E[z_t]. \] Since \(z_t \iid \Normal(0,1)\), \(\E[z_t] = 0\), and \(\E[|z_t|] - \E[|z_t|] = 0\). Thus, \(\E[g(z_t)] = \alpha(0) + \gamma(0) = 0\). This confirms that \(g(z_t)\) is a zero-mean innovation sequence for the log-variance AR(1) process.

Prove that if \(z \sim \Normal(0,1)\), then \(\E[|z|] = \sqrt{2/\pi}\).

Worked Solution

By definition of expectation for a continuous random variable with standard normal density \(\phi(z) = \frac{1}{\sqrt{2\pi}} e^{-z^2/2}\): \[ \E[|z|] = \int_{-\infty}^\infty |z| \frac{1}{\sqrt{2\pi}} e^{-z^2/2} dz = 2 \int_0^\infty z \frac{1}{\sqrt{2\pi}} e^{-z^2/2} dz = \sqrt{\frac{2}{\pi}} \int_0^\infty z e^{-z^2/2} dz. \] Let \(u = z^2/2 \implies du = z dz\). When \(z=0\), \(u=0\); as \(z \to \infty\), \(u \to \infty\). The integral evaluates to: \[ \int_0^\infty e^{-u} du = \left[-e^{-u}\right]_0^\infty = 0 - (-1) = 1. \] Therefore, \(\E[|z|] = \sqrt{2/\pi} \times 1 = \sqrt{2/\pi}\).

Derive the variance of the news-impact innovation \(\Var(g(z))\) under \(z \sim \Normal(0,1)\).

Worked Solution

Since \(\E[g(z)] = 0\), \(\Var(g(z)) = \E[g(z)^2]\). Expanding \(g(z) = \alpha(|z| - c) + \gamma z\) where \(c = \sqrt{2/\pi}\): \[ g(z)^2 = \alpha^2(|z| - c)^2 + 2\alpha\gamma(|z| - c)z + \gamma^2 z^2. \] Taking expectations: \(\E[(|z| - c)^2] = \Var(|z|) = \E[z^2] - (\E[|z|])^2 = 1 - 2/\pi\). For the cross term: \(\E[(|z| - c)z] = \E[|z|z] - c\E[z]\). Because \(|z|z\) is an odd function of \(z\) (\(|(-z)|(-z) = -|z|z\)) and the normal density is symmetric, \(\E[|z|z] = 0\). Also \(\E[z] = 0\), so the cross-term vanishes. For the last term: \(\E[z^2] = 1\). Combining terms yields: \[ \Var(g(z)) = \alpha^2\left(1 - \frac{2}{\pi}\right) + \gamma^2. \]

Empirical Tier

In an empirical study of daily equity index returns, an EGARCH(1,1) model produces \(\hat{\alpha} = 0.14\) and \(\hat{\gamma} = -0.11\), while in foreign exchange returns it yields \(\hat{\alpha} = 0.12\) and \(\hat{\gamma} = -0.01\). Interpret the economic difference between these markets.

Worked Solution

In equity indices, \(\hat{\gamma} = -0.11\) is strongly negative and statistically significant, confirming an intense leverage effect: market drops create massive volatility surges compared to rallies. In foreign exchange, \(\hat{\gamma} = -0.01\) is economically and statistically indistinguishable from zero. In FX, an exchange rate is a relative price between two currencies; an appreciation of Currency A is simultaneously a depreciation of Currency B. There is no corporate debt structure or directional asymmetry, so FX volatility responds symmetrically to shocks of either sign.

Contrast the Glosten, Jagannathan, and Runkle (1993) GJR-GARCH model with Nelson's EGARCH model in capturing asymmetric volatility.

Worked Solution

GJR-GARCH models variance in levels: \(\sigma_t^2 = \omega + \alpha \varepsilon_{t-1}^2 + \gamma \varepsilon_{t-1}^2 I_{\{\varepsilon_{t-1} < 0\}} + \beta \sigma_{t-1}^2\). It incorporates asymmetry via an indicator variable \(I_{\{\varepsilon_{t-1} < 0\}}\) that increases the ARCH coefficient by \(\gamma\) for negative returns. However, GJR-GARCH still requires parameter non-negativity constraints (\(\omega > 0, \alpha \ge 0, \alpha + \gamma \ge 0, \beta \ge 0\)) to guarantee positive variance, whereas EGARCH models log-variance and is inherently unconstrained.

Explain why options market makers quote an implied volatility "skew" or "smirk" in equity index options, and connect this to EGARCH's \(\gamma < 0\).

Worked Solution

In Black-Scholes-Merton, volatility is constant, implying a flat implied volatility curve across strikes. In actual equity index option markets, out-of-the-money puts trade at substantially higher implied volatilities than out-of-the-money calls (the volatility skew). This skew prices in the empirical reality that if the market crashes, volatility will surge (\(\gamma < 0\)), making deep out-of-the-money puts far more likely to finish in the money than predicted by a geometric Brownian motion.

Research Tier

Derive the exact one-step-ahead conditional expectation \(\E[\sigma_{t+1}^2 \mid \mathcal{F}_t]\) for an EGARCH(1,1) model under Gaussian innovations.

Worked Solution

By definition, \(\sigma_{t+1}^2 = \exp(\omega + \beta \ln \sigma_t^2 + g(z_t))\). Conditioning on \(\mathcal{F}_t\), \(\sigma_t^2\) is known. Thus: \[ \E[\sigma_{t+1}^2 \mid \mathcal{F}_t] = \exp(\omega + \beta \ln \sigma_t^2) \E[\exp(g(z_t))]. \] We evaluate \(\E[\exp(g(z))] = \E[\exp(\alpha|z| - \alpha\sqrt{2/\pi} + \gamma z)] = \exp(-\alpha\sqrt{2/\pi}) \E[\exp(\alpha|z| + \gamma z)]\). Splitting the integral over \(z \ge 0\) and \(z < 0\): \[ \E[\exp(\alpha|z| + \gamma z)] = \int_0^\infty e^{(\alpha+\gamma)z} \frac{e^{-z^2/2}}{\sqrt{2\pi}} dz + \int_{-\infty}^0 e^{(-\alpha+\gamma)z} \frac{e^{-z^2/2}}{\sqrt{2\pi}} dz. \] Completing the square yields \(\exp((\alpha+\gamma)^2/2)\Phi(\alpha+\gamma) + \exp((\alpha-\gamma)^2/2)\Phi(\alpha-\gamma)\). Multiplying by \(\exp(-\alpha\sqrt{2/\pi})\) provides the exact analytic Jensen convexity correction.

Evaluate how non-Gaussian standardized innovation distributions (such as Student-t or Generalized Error Distributions) affect the baseline offset \(\E[|z|]\) in EGARCH.

Worked Solution

In Nelson (1991), innovations are frequently modeled using the Generalized Error Distribution (GED) with tail parameter \(\nu\), where \(\nu = 2\) corresponds to the normal distribution. For a standardized GED random variable with parameter \(\nu\), \(\E[|z|] = 2^{1/\nu} \Gamma(2/\nu) / \sqrt{\Gamma(1/\nu)\Gamma(3/\nu)}\). When \(\nu < 2\) (fat tails), \(\E[|z|]\) shrinks below \(\sqrt{2/\pi}\). If an analyst assumes Gaussianity when the true distribution is fat-tailed, \(\E[g(z)] \ne 0\), which induces severe bias in the estimated intercept \(\hat{\omega}\).

Discuss the concept of "volatility of volatility" (vol-of-vol) in EGARCH and how the parameter \(\alpha\) relates to VIX option pricing.

Worked Solution

In continuous stochastic volatility models, volatility of volatility is governed by parameter \(\xi\) in \(d\sigma_t^2 = \kappa(\theta - \sigma_t^2)dt + \xi \sigma_t^2 dW_{2,t}\). In EGARCH, the variance of the log-variance innovation is \(\Var(g(z)) = \alpha^2(1 - 2/\pi) + \gamma^2\). The magnitude of \(\alpha\) directly controls how violently log-volatility fluctuates in response to return shocks. In VIX options trading, pricing out-of-the-money calls on the VIX requires a large \(\alpha\) to reproduce the high implied vol-of-vol observed in derivatives markets.

Retrieval Quiz

  1. What is the defining characteristic of the leverage effect in equity markets?

    The leverage effect refers to the asymmetric volatility response where market drops trigger higher volatility than market gains.

  2. How does Nelson's EGARCH model guarantee that conditional variance \(\sigma_t^2\) remains strictly positive?

    The exponential function maps any real number to a strictly positive number, eliminating the need for boundary constraints.

  3. In an EGARCH(1,1) model with \(g(z) = \alpha(|z| - \E[|z|]) + \gamma z\), what parameter value of \(\gamma\) corresponds to the standard symmetric response?

    When \(\gamma = 0\), \(g(z) = \alpha(|z| - \E[|z|])\), which depends only on \(|z|\) and treats positive and negative shocks identically.

  4. Under standard normal innovations \(z \sim \Normal(0,1)\), what is the exact value of \(\E[|z|]\)?

    Integrating \(z \phi(z)\) over \([0, \infty)\) yields \(\sqrt{2/\pi} \approx 0.79788\).

  5. What condition guarantees weak stationarity of the log-variance process \(\ln \sigma_t^2\) in EGARCH(1,1)?

    Because \(\ln \sigma_t^2\) is an AR(1) process with persistence parameter \(\beta\), stationarity requires \(|\beta| < 1\).

  6. If \(\alpha = 0.20\) and \(\gamma = -0.10\) in an EGARCH model, what is the slope of the news-impact function for negative shocks?

    For \(z < 0\), the derivative is \(-\alpha + \gamma = -0.20 - 0.10 = -0.30\).

  7. Why is computing multi-step level variance forecasts \(\E[\sigma_{t+k}^2 \mid \mathcal{F}_t]\) in EGARCH more complex than in standard GARCH?

    Jensen's inequality requires evaluating the moment-generating function of \(\sum \beta^j g(z)\) to compute expected variance in levels.

  8. Why do foreign exchange markets generally display negligible leverage asymmetry (\(\gamma \approx 0\)) compared to equity index markets?

    Currency returns represent symmetric relative price ratios; currency depreciation for one economy is appreciation for the other, removing directional asymmetry.
