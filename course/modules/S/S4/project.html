Lab 1 · Solved Time-Series Pipeline Instance

Simulating 100 observations under stationary GARCH(1,1) parameters verifies that recursive variance updates maintain strict positivity and produce well-behaved QLIKE forecast evaluations.

"""Lab S4-project-1: Rung 1 worked example for Atlas A4 time-series toolkit.

SIMULATED: fully solved instance of GARCH(1,1) variance recursion, HAR design,
and QLIKE loss evaluation.
"""

from __future__ import annotations

import math
import random


def run_worked_example() -> None:
    rng = random.Random(42)
    # 1. GARCH(1,1) path
    omega, alpha, beta = 0.04, 0.10, 0.82
    h = omega / (1.0 - alpha - beta)
    returns: list[float] = []
    for _ in range(100):
        z = rng.gauss(0.0, 1.0)
        eps = math.sqrt(h) * z
        returns.append(eps)
        h = omega + alpha * (eps**2) + beta * h

    # GARCH variance recursion
    mean_r = sum(returns) / len(returns)
    h0 = sum((r - mean_r) ** 2 for r in returns) / len(returns)
    var_seq = [h0]
    for t in range(1, len(returns)):
        ht = omega + alpha * (returns[t - 1] ** 2) + beta * var_seq[-1]
        var_seq.append(ht)

    # 2. QLIKE calculation
    realized_val = 0.85
    forecast_val = var_seq[-1]
    ratio = realized_val / forecast_val
    qlike_val = ratio - math.log(ratio) - 1.0

    print("Rung 1 Worked Example Pipeline:")
    print(f"  Returns length: {len(returns)}")
    print(f"  Initial variance h_0: {h0:.4f}")
    print(f"  Terminal variance h_T: {var_seq[-1]:.4f}")
    print(f"  Realized target: {realized_val:.4f}")
    print(f"  QLIKE loss: {qlike_val:.4f}")


def main() -> None:
    run_worked_example()


main()

"""Lab S4-project-3: Rung 3 independent verification check for Atlas A4.

SIMULATED: runs the reference timeseries estimators across GARCH, HAR,
Kalman filtering, and ARMA on synthetic benchmark data.
"""

from __future__ import annotations

import math
import random


def simulate_garch(n: int = 200, seed: int = 42) -> list[float]:
    rng = random.Random(seed)
    omega, alpha, beta = 0.05, 0.10, 0.82
    h = omega / (1.0 - alpha - beta)
    rets: list[float] = []
    for _ in range(n):
        z = rng.gauss(0.0, 1.0)
        eps = math.sqrt(h) * z
        rets.append(eps)
        h = omega + alpha * (eps**2) + beta * h
    return rets


def garch11_variance(returns: list[float], omega: float, alpha: float, beta: float) -> list[float]:
    n = len(returns)
    mean_r = sum(returns) / n
    h0 = sum((r - mean_r) ** 2 for r in returns) / n
    h = [h0]
    for t in range(1, n):
        h.append(omega + alpha * (returns[t - 1] ** 2) + beta * h[-1])
    return h


def qlike(realized: float, forecast: float) -> float:
    ratio = realized / forecast
    return float(ratio - math.log(ratio) - 1.0)


def main() -> None:
    returns = simulate_garch(n=200, seed=42)
    omega, alpha, beta = 0.05, 0.10, 0.82
    h_seq = garch11_variance(returns, omega, alpha, beta)

    # Invariant checks
    assert len(h_seq) == len(returns), "length mismatch"
    assert all(h > 0.0 for h in h_seq), "variance must be strictly positive"

    loss = qlike(1.0, h_seq[-1])
    assert loss >= 0.0, "QLIKE loss must be non-negative"

    print("Atlas A4 Independent Verification Check:")
    print(f"  Processed returns: {len(returns)} observations")
    print("  All variance estimates positive: True")
    print(f"  Final conditional variance: {h_seq[-1]:.4f}")
    print(f"  Out-of-sample QLIKE: {loss:.4f}")
    print("  Status: All mathematical invariants satisfied.")


main()

Exemplar A (Level 4: Exemplary)

Atlas A4 Architecture Report: Production Time-Series Econometric Engine

To: Atlas Systems Architecture Committee

Subject: High-Performance Pure-Python Time-Series and Volatility Infrastructure (Milestone A4)

1. Design Architecture and Standard Library Independence

Milestone A4 delivers a zero-dependency, pure-Python econometrics engine for Atlas. By eliminating external C-extensions, the module guarantees cross-platform reproducibility and instant startup times in serverless execution environments. All linear algebra operations—including \(4 \times 4\) Gauss-Jordan inversion for HAR-RV and Nelder-Mead simplex optimization for GARCH and ARMA estimation—are engineered in pure Python, executing comprehensive parameter calibration across 50 test instances in under 8 seconds.

2. Volatility Filtering and Invariant Preservation

The GARCH(1,1) filter strictly enforces covariance stationarity (\(\alpha + \beta < 1\)) and conditional variance positivity (\(h_t > 0\)). The initial variance \(h_0\) is explicitly anchored to the unconditional sample variance \(\frac{1}{T} \sum_{t=1}^T (r_t - \bar{r})^2\), preventing arbitrary burn-in distortion. The log-likelihood function incorporates the complete Gaussian normal density constants \(-\frac{1}{2} \ln(2\pi) - \frac{1}{2} \ln h_t - \frac{r_t^2}{2 h_t}\), ensuring exact equivalence with benchmark econometric packages.

3. Multi-Horizon HAR Design and Closed-Form OLS

The HAR module constructs the multi-horizon design matrix starting at index \(t = 22\), ensuring that all rolling windows (1-day, 5-day, and 22-day) are populated exclusively with valid historical realized variances. The system solves the OLS normal equations \((X^\top X)^{-1} X^\top y\) using partial-pivoting Gauss-Jordan elimination, providing numerical conditioning safeguards and computing coefficient of determination \(R^2\) and residual variance.

4. Robust Loss Functions and Model Evaluation

To eliminate proxy ranking distortion, the scoring suite implements Patton's (2011) complete family of robust loss functions. The Gaussian quasi-likelihood (QLIKE) loss \(L(y, h) = y/h - \ln(y/h) - 1\) is verified to be homogeneous of degree zero, penalizing under-forecasting volatility 2.26 times more heavily than over-forecasting at 50% relative error. Non-robust metrics (MAE, MAPE) are rigorously excluded from model selection pipelines.

5. State-Space Kalman Filtering

The local-level state-space filter executes the discrete-time Kalman recursion: prior prediction \(a_{t|t-1} = a_{t-1}\), prior variance \(P_{t|t-1} = P_{t-1} + \sigma_w^2\), Kalman gain \(K_t = P_{t|t-1} / (P_{t|t-1} + \sigma_v^2)\), and posterior update \(a_t = a_{t|t-1} + K_t (y_t - a_{t|t-1})\). Kalman gain is analytically bounded within \([0, 1]\), and filtered state paths are verified against pure random walk and white noise benchmark limits.

Exemplar B (Level 2: Developing)

Memo: Time Series Code Implementation

We wrote functions for GARCH, HAR, and Kalman filtering in Python without importing external packages. The GARCH function computes variance updates using a loop. Sometimes the variance can be very small or negative if the parameters are not constrained, so we had to set a floor.

For the HAR model, we calculated the 5-day and 22-day moving averages and ran a regression. The regression uses matrix multiplication to find the coefficients, but if the columns are collinear it crashes with a divide-by-zero error.

For loss evaluation, we wrote MSE and QLIKE. QLIKE works when the forecast is positive, but crashes if the forecast is zero because of the log function. The Kalman filter works on the simulated series, but we did not implement the full ARMA likelihood.
