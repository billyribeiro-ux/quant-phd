S4 · Volatility Econometrics

Conditional Heteroskedasticity, High-Frequency Realized Volatility, and Robust Forecast Evaluation (80 Hours · Tier M)

Course Overview

Asset returns in financial markets exhibit stationary first moments but highly persistent, time-varying second moments. Volatility clusters: large price changes of either sign tend to be followed by large price changes, and small changes tend to be followed by small changes. This conditional heteroskedasticity violates classical Gauss-Markov assumptions, rendering static risk models dangerously inaccurate during market turmoil.

This module provides rigorous doctoral-level training in discrete-time conditional volatility modeling and modern high-frequency econometrics. Beginning with Engle's ARCH and Bollerslev's GARCH representations, the curriculum advances through asymmetric leverage dynamics in Nelson's EGARCH, continuous-time quadratic variation foundations, high-frequency realized volatility under microstructure noise, Corsi's multi-component HAR framework, and Patton's theory of robust forecast evaluation under imperfect volatility proxies.

Learning Objectives

  1. Formulate conditional heteroskedasticity models and test for volatility clustering using sample autocorrelations of squared returns.
  2. Derive stationarity constraints, unconditional variance limits, and excess kurtosis formulas for ARCH and GARCH processes.
  3. Model asymmetric leverage effects using Exponential GARCH news-impact curves without non-negativity parameter constraints.
  4. Construct non-parametric realized volatility measures from high-frequency intraday prices and diagnose microstructure noise bias via signature plots.
  5. Estimate multi-horizon Heterogeneous Autoregressive (HAR) models using ordinary least squares to capture apparent long memory.
  6. Evaluate out-of-sample volatility forecasts using QLIKE and Patton-robust loss functions invariant to proxy noise.

Placement Diagnostic

Complete this diagnostic before starting the lessons. Scoring 80% or higher and demonstrating competence on all marked core skills allows fast-tracking of introductory material.

  1. In a GARCH(1,1) model \(h_t = \omega + \alpha \varepsilon_{t-1}^2 + \beta h_{t-1}\) with \(\omega = 0.04\), \(\alpha = 0.10\), and \(\beta = 0.80\), if yesterday's conditional variance was \(h_{t-1} = 1.00\) and yesterday's return shock was \(\varepsilon_{t-1} = 2.00\), what is today's conditional variance \(h_t\)?

    Evaluating the recursion: \(h_t = 0.04 + 0.10 \times (2.0)^2 + 0.80 \times 1.00 = 0.04 + 0.40 + 0.80 = 1.24\).

  2. Given true realized variance \(y = 1.00\) and volatility forecast \(h = 0.50\), what is the value of the QLIKE loss \(L(y, h) = \frac{y}{h} - \ln\frac{y}{h} - 1\)?

    With \(y/h = 1.00 / 0.50 = 2.00\), \(L = 2.00 - \ln(2.00) - 1.00 \approx 2.00 - 0.693147 - 1.00 = 0.30685\).

  3. Under what condition on parameters \(\alpha\) and \(\beta\) is the standard GARCH(1,1) process weakly (covariance) stationary?

    Weak stationarity requires the root of the autoregressive polynomial in squared returns to lie outside the unit circle, which translates to \(\alpha + \beta < 1\) along with non-negativity.

  4. Why does ultra-high frequency sampling (e.g., 1-second ticks) distort realized volatility estimation in liquid equity and foreign exchange markets?

    Additive microstructure noise with variance \(\sigma_\eta^2\) adds an asymptotic bias term \(2 M \sigma_\eta^2\) to realized variance, which diverges to infinity as sampling frequency \(M \to \infty\).

  5. According to Patton (2011), what defining property characterizes a loss function as robust to an imperfect, conditionally unbiased volatility proxy?

    A loss function is robust if and only if the expected loss difference between two forecasters evaluated on the noisy proxy equals the expected loss difference evaluated on the true latent variance.

Lesson Map

The 56 classroom study hours are organized across eight modular lessons of 7 hours each:

  1. Lesson 1 · Volatility Clustering & Empirical Stylized Facts: Mandelbrot stylized facts, fat tails, absence of linear return autocorrelation, persistent squared return dependence, and Bartlett white noise bounds.
  2. Lesson 2 · The ARCH Model: Engle's formulation, conditional variance equations, fourth-moment derivations, excess kurtosis, and maximum likelihood estimation.
  3. Lesson 3 · The GARCH Model: Bollerslev's generalization, GARCH(1,1) specification, ARMA representation of squared shocks, covariance stationarity conditions, and volatility half-life.
  4. Lesson 4 · Asymmetric Volatility & The EGARCH Model: The leverage effect, Black's hypothesis vs volatility feedback, Nelson's exponential GARCH, and news-impact curves.
  5. Lesson 5 · Realized Volatility: Continuous-time jump diffusions, quadratic variation, high-frequency returns, microstructure noise, and volatility signature plots.
  6. Lesson 6 · The HAR Model of Realized Volatility: Corsi's heterogeneous autoregressive model, economic foundations across daily, weekly, and monthly horizons, OLS estimation, and forecasting.
  7. Lesson 7 · The QLIKE Loss Function: Latent target forecasting evaluation, Gaussian quasi-likelihood loss derivation, scale invariance, and severe penalty on volatility under-predictions.
  8. Lesson 8 · Robust Loss Functions for Volatility Comparison: Patton's characterization of robust loss families, proxy noise invariance, ranking consistency theorems, and comparison with non-robust metrics.
