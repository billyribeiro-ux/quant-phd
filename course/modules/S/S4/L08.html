Robust Loss Functions & Patton's Theorem

Proxy Invariance, Patton's Characterization Theorem, and the Perils of Non-Robust Scoring Rules

Why It Matters

When evaluating financial models, an econometrician assumes that the scoring rule accurately identifies the best forecasting algorithm. In volatility modeling, this assumption easily fails: using an intuitive loss metric like Mean Absolute Error (MAE) or Mean Absolute Percentage Error (MAPE) can cause an inferior model to consistently beat the true data-generating process simply because evaluation relies on an imperfect proxy. Andrew Patton established the exact mathematical boundary separating valid from invalid volatility loss functions. Understanding Patton's robust family prevents quantitative desks from deploying flawed trading models that appear superior under non-robust metrics.

1. The Patton (2011) Robustness Framework

Let \(\sigma_t^2 = \Var(r_t \mid \mathcal{F}_{t-1})\) be the unobservable true conditional variance, and let \(\hat{\sigma}_t^2\) be an observable proxy (such as daily squared returns \(r_t^2\) or high-frequency realized volatility \(RV_t\)). Assume that the proxy is conditionally unbiased:

\[ \begin{aligned} \E\big[\hat{\sigma}_t^2 \mid \mathcal{F}_{t-1}\big] &= \sigma_t^2. \end{aligned} \]

Consider two competing volatility forecasts, \(h_{1t}\) and \(h_{2t}\), generated with respect to information set \(\mathcal{F}_{t-1}\).

Definition 8.1 · Robust Volatility Loss Function

A loss function \(L(y, h)\) is a robust volatility loss function if and only if the ranking between any two forecasts \(h_1\) and \(h_2\) evaluated using the noisy proxy \(\hat{\sigma}^2\) is identical to their ranking under the unobserved true variance \(\sigma^2\):

\[ \begin{aligned} \E\big[L(\hat{\sigma}_t^2, h_{1t})\big] \le \E\big[L(\hat{\sigma}_t^2, h_{2t})\big] &\iff \E\big[L(\sigma_t^2, h_{1t})\big] \le \E\big[L(\sigma_t^2, h_{2t})\big] \end{aligned} \]

for all conditionally unbiased proxies \(\hat{\sigma}_t^2\).

Theorem 8.1 · Patton's Necessary and Sufficient Characterization

Assumptions:

  1. Let the proxy \(\hat{\sigma}^2\) satisfy \(\E[\hat{\sigma}^2 \mid \mathcal{F}] = \sigma^2\) almost surely.
  2. Let \(L(y, h)\) be twice continuously differentiable on \((0, \infty) \times (0, \infty)\).

Conclusion (Patton, 2011): The loss function \(L(y, h)\) is robust if and only if the cross-partial derivative does not depend on the proxy \(y\):

\[ \begin{aligned} \frac{\partial^2 L(y, h)}{\partial y \partial h} &= g(h), \end{aligned} \]

where \(g(h)\) is a strictly negative, continuous function of the forecast \(h\). Consequently, all robust loss functions take the general additive form:

\[ \begin{aligned} L(y, h) &= \tilde{C}(h) + C(h) y + f(y), \end{aligned} \]

where \(C'(h) = -g(h) < 0\) and \(\tilde{C}'(h) = -h C'(h)\), ensuring that the minimum expected loss strictly elicits \(h^* = \sigma^2\).

Proof Outline

Consider the expected loss difference between two forecasts \(h_1\) and \(h_2\) evaluated on proxy \(\hat{\sigma}^2\):

\[ \begin{aligned} \Delta L(\hat{\sigma}^2) &= L(\hat{\sigma}^2, h_1) - L(\hat{\sigma}^2, h_2). \end{aligned} \]

Taking conditional expectations and applying the law of iterated expectations:

\[ \begin{aligned} \E\big[\Delta L(\hat{\sigma}^2) \mid \mathcal{F}\big] &= \E\big[L(\hat{\sigma}^2, h_1) - L(\hat{\sigma}^2, h_2) \mid \mathcal{F}\big]. \end{aligned} \]

If \(L(y, h) = \tilde{C}(h) + C(h) y + f(y)\), then \(f(\hat{\sigma}^2)\) cancels out entirely in the difference:

\[ \begin{aligned} \Delta L(\hat{\sigma}^2) &= \big(\tilde{C}(h_1) - \tilde{C}(h_2)\big) + \big(C(h_1) - C(h_2)\big) \hat{\sigma}^2. \end{aligned} \]

Taking expectations conditional on \(\mathcal{F}\) and using \(\E[\hat{\sigma}^2 \mid \mathcal{F}] = \sigma^2\):

\[ \begin{aligned} \E\big[\Delta L(\hat{\sigma}^2) \mid \mathcal{F}\big] &= \big(\tilde{C}(h_1) - \tilde{C}(h_2)\big) + \big(C(h_1) - C(h_2)\big) \sigma^2 = \Delta L(\sigma^2). \end{aligned} \]

Because \(\E[\Delta L(\hat{\sigma}^2) \mid \mathcal{F}] \equiv \Delta L(\sigma^2)\), the expected ranking under the proxy is identically equal to the ranking under the true latent variance for every sample realization.

2. The Homogeneous Family of Robust Losses

In empirical finance, practitioners prefer loss functions that are homogeneous of degree \(b\), meaning \(L(c y, c h) = c^b L(y, h)\). Patton showed that imposing homogeneity on the robust family generates a single-parameter continuum indexed by \(b \in \R\):

\[ \begin{aligned} L_b(y, h) &= \begin{cases} \frac{1}{b(b-1)}\big(y^b - h^b\big) - \frac{1}{b-1} h^{b-1}(y - h), & b \notin \{0, 1\}, \\ \frac{y}{h} - \ln\left(\frac{y}{h}\right) - 1, & b = 0 \quad (\text{QLIKE}), \\ y \ln\left(\frac{y}{h}\right) - (y - h), & b = 1. \end{cases} \end{aligned} \]

Notice that for \(b = 2\), the expression simplifies to half of Mean Squared Error: \(L_2(y, h) = \frac{1}{2}(y - h)^2\). For \(b = 0\), it yields QLIKE loss.

Table 8.1: Comparison of Common Loss Functions in Volatility Econometrics
Loss Function Formula \(L(y, h)\) Robust to Proxy Noise? Homogeneity Degree Practical Suitability
QLIKE (\(b=0\)) \(y/h - \ln(y/h) - 1\) YES (Robust) 0 (Scale-invariant) Gold standard; penalizes under-forecasting
MSE (\(b=2\)) \((y - h)^2\) YES (Robust) 2 (Quadratic scale) Valid, but dominated by crisis outliers
MAE \(|y - h|\) NO (Distorted) 1 Elicits median; rankings systematically flip

3. Empirical Lab: Patton (2011) Ranking Consistency

The following standalone Python lab simulates a true conditional variance series and a noisy proxy \(y_t = \sigma_t^2 z_t^2\). It compares Model 1 (a superior forecaster) against Model 2 (an inferior, biased forecaster) under QLIKE, MSE, and non-robust MAE loss to empirically verify ranking preservation.

Lab 1 · Patton Ranking Consistency on True Variance vs Noisy Proxy

Under robust losses (QLIKE and MSE), the ranking of forecasting models evaluated on the noisy proxy is identical to the ranking on the unobserved true variance, whereas non-robust metrics can distort rankings.

"""Lab S4-L08-1: Patton (2011) ranking consistency under imperfect volatility proxies.

SIMULATED: generates true latent conditional variance and a conditionally unbiased
noisy proxy y_t = sigma_t^2 * z_t^2. Compares Model 1 (superior) vs Model 2 (inferior)
under QLIKE, MSE, and non-robust MAE loss to verify ranking robustness.
"""

from __future__ import annotations

import math
import random


def run_patton_experiment(n: int = 5000, seed: int = 42) -> None:
    """Evaluate model rankings on true variance versus proxy."""
    rng = random.Random(seed)

    sigma2 = [1.0]
    for _ in range(n):
        s = 0.20 + 0.80 * sigma2[-1] + rng.gauss(0.0, 0.05)
        sigma2.append(max(0.2, s))
    sigma2 = sigma2[1:]

    # Model 1 (Superior): small zero-mean error
    h1 = [s + rng.gauss(0.0, 0.05) for s in sigma2]
    # Model 2 (Inferior): biased + noisier
    h2 = [s + rng.gauss(0.10, 0.15) for s in sigma2]

    # Unbiased noisy proxy: y_t = sigma_t^2 * z_t^2
    y_proxy = [s * (rng.gauss(0.0, 1.0) ** 2) for s in sigma2]

    def avg_losses(target: list[float], h: list[float]) -> tuple[float, float, float]:
        mse = sum((target[i] - h[i]) ** 2 for i in range(n)) / n
        qlike = sum((target[i] / h[i]) - math.log(target[i] / h[i]) - 1.0 for i in range(n)) / n
        mae = sum(abs(target[i] - h[i]) for i in range(n)) / n
        return mse, qlike, mae

    mse1_true, q1_true, mae1_true = avg_losses(sigma2, h1)
    mse2_true, q2_true, mae2_true = avg_losses(sigma2, h2)

    mse1_prx, q1_prx, mae1_prx = avg_losses(y_proxy, h1)
    mse2_prx, q2_prx, mae2_prx = avg_losses(y_proxy, h2)

    print("Patton (2011) Loss Robustness Verification:")
    print("Loss Metric | True Var Loss (M1 vs M2) | Noisy Proxy Loss (M1 vs M2) | Ranking Preserved?")
    print("-" * 80)

    # MSE
    win_t_mse = "M1 < M2" if mse1_true < mse2_true else "M2 < M1"
    win_p_mse = "M1 < M2" if mse1_prx < mse2_prx else "M2 < M1"
    ok_mse = "YES (Robust)" if win_t_mse == win_p_mse else "NO (Distorted)"
    print(
        f"MSE         |   {mse1_true:.4f} vs {mse2_true:.4f} ({win_t_mse})  |"
        f"   {mse1_prx:.4f} vs {mse2_prx:.4f} ({win_p_mse})   | {ok_mse}"
    )

    # QLIKE
    win_t_q = "M1 < M2" if q1_true < q2_true else "M2 < M1"
    win_p_q = "M1 < M2" if q1_prx < q2_prx else "M2 < M1"
    ok_q = "YES (Robust)" if win_t_q == win_p_q else "NO (Distorted)"
    print(
        f"QLIKE       |   {q1_true:.4f} vs {q2_true:.4f} ({win_t_q})  |"
        f"   {q1_prx:.4f} vs {q2_prx:.4f} ({win_p_q})   | {ok_q}"
    )

    # MAE
    win_t_mae = "M1 < M2" if mae1_true < mae2_true else "M2 < M1"
    win_p_mae = "M1 < M2" if mae1_prx < mae2_prx else "M2 < M1"
    ok_mae = "YES" if win_t_mae == win_p_mae else "NO (Distorted)"
    print(
        f"MAE         |   {mae1_true:.4f} vs {mae2_true:.4f} ({win_t_mae})  |"
        f"   {mae1_prx:.4f} vs {mae2_prx:.4f} ({win_p_mae})   | {ok_mae}"
    )


def main() -> None:
    run_patton_experiment(n=5000, seed=42)


main()

Where the Canon Breaks

While Patton's theorem completely characterizes proxy-robust scoring rules, its real-world implementation depends on critical boundary conditions:

  • Proxy conditional unbiasedness is mandatory: If the proxy is contaminated by microstructure noise or rounding bias (\(\E[\hat{\sigma}_t^2 \mid \mathcal{F}_{t-1}] \ne \sigma_t^2\)), even QLIKE and MSE lose their robustness guarantee and can rank models incorrectly.
  • Discrepancy with economic utility: A quantitative trading desk may care about portfolio drawdown or option replication hedging error rather than statistical loss. Patton's robust family guarantees consistency for statistical conditional variance, but not necessarily for arbitrary non-linear utility functions.
  • Low finite-sample discrimination power: When candidate models produce similar forecasts, the loss differential \(\Delta L_t\) can have high variance, requiring large test samples (\(T > 1,000\) days) for the Diebold-Mariano test to achieve sufficient statistical power.

Misconceptions

  • Wrong belief: Any convex loss function is robust for evaluating volatility forecasts.

    Why it is wrong: Convexity alone is insufficient. For instance, \(L(y, h) = (\ln y - \ln h)^2\) is strictly convex, yet it is non-robust because \(\frac{\partial^2 L}{\partial y \partial h} = \frac{2}{y h}\) depends on the noisy proxy \(y\), causing Jensen's inequality distortions that flip model rankings.

  • Wrong belief: Evaluating volatility in standard deviation units \(\sigma\) using MSE \((\hat{\sigma} - h_\sigma)^2\) is robust if variance MSE is robust.

    Why it is wrong: By Jensen's inequality, an unbiased estimator of variance is a biased estimator of standard deviation: \(\E[\sqrt{\hat{\sigma}^2}] < \sqrt{\E[\hat{\sigma}^2]} = \sigma\). Evaluating in standard deviation units with standard MSE introduces systematic downward bias unless using Patton's specifically adapted standard-deviation loss family.

  • Wrong belief: The ranking between two models under MSE must always match their ranking under QLIKE.

    Why it is wrong: MSE and QLIKE are both robust to proxy noise, meaning each will preserve its own true ranking when evaluated on an unbiased proxy. However, MSE and QLIKE place different relative penalties on errors (MSE is quadratic in levels, QLIKE is scale-invariant and asymmetric). Hence, two candidate models may legitimately have different rankings under MSE versus QLIKE.

Practice Problems

Mechanics Tier

Evaluate Patton's family of robust loss functions for \(b = 2\). Show that \(L_2(y, h) = \frac{1}{2}(y - h)^2\), confirming that MSE is a member of the robust family.

Worked Solution

Substitute \(b = 2\) into Patton's general homogeneous formula: \[ L_b(y, h) = \frac{1}{b(b-1)}\big(y^b - h^b\big) - \frac{1}{b-1} h^{b-1}(y - h). \] For \(b = 2\), the prefactors become \(\frac{1}{2(1)} = \frac{1}{2}\) and \(\frac{1}{1} = 1\): \[ \begin{aligned} L_2(y, h) &= \frac{1}{2}(y^2 - h^2) - h(y - h) \\ &= \frac{1}{2} y^2 - \frac{1}{2} h^2 - h y + h^2 \\ &= \frac{1}{2} y^2 - h y + \frac{1}{2} h^2 = \frac{1}{2}(y - h)^2. \end{aligned} \] This equals exactly half the standard Mean Squared Error loss, confirming that MSE belongs to Patton's robust family.

Check whether the Mean Absolute Error loss \(L(y, h) = |y - h|\) satisfies Patton's condition \(\frac{\partial^2 L}{\partial y \partial h} = g(h)\).

Worked Solution

For \(y \ne h\), write \(L(y, h) = (y - h) \operatorname{sgn}(y - h)\). Differentiating with respect to \(h\): \[ \frac{\partial L}{\partial h} = -\operatorname{sgn}(y - h). \] Differentiating with respect to \(y\): \[ \frac{\partial^2 L}{\partial y \partial h} = -2 \delta(y - h), \] where \(\delta(\cdot)\) is the Dirac delta distribution. This cross-partial derivative depends directly on whether the proxy \(y\) is greater than or less than \(h\), which varies from observation to observation depending on proxy noise. Because the cross-derivative depends on \(y\), MAE violates Patton's theorem and is strictly non-robust.

Calculate the limit of Patton's robust loss family \(L_b(y, h)\) as parameter \(b \to 0\) using L'Hôpital's rule, and verify that it yields QLIKE loss.

Worked Solution

As \(b \to 0\), write \(L_b(y, h) = \frac{y^b - h^b - b h^{b-1}(y - h)}{b(b-1)}\). The denominator \(b(b-1) \to 0\), and the numerator \(1 - 1 - 0 = 0\), yielding a \(0/0\) indeterminate form. Differentiating numerator and denominator with respect to \(b\): The derivative of the denominator is \(\frac{d}{db}[b^2 - b] = 2b - 1 \to -1\) as \(b \to 0\). The derivative of the numerator with respect to \(b\): \[ \frac{d}{db}\big[y^b - h^b - b h^{b-1}(y - h)\big] = y^b \ln y - h^b \ln h - h^{b-1}(y - h) - b \frac{d}{db}[h^{b-1}(y - h)]. \] Evaluating at \(b = 0\): \[ \ln y - \ln h - h^{-1}(y - h) - 0 = \ln\left(\frac{y}{h}\right) - \left(\frac{y}{h} - 1\right) = \ln\left(\frac{y}{h}\right) - \frac{y}{h} + 1. \] Dividing by the denominator derivative \(-1\): \[ \lim_{b \to 0} L_b(y, h) = \frac{\ln(y/h) - y/h + 1}{-1} = \frac{y}{h} - \ln\left(\frac{y}{h}\right) - 1. \] This recovers QLIKE loss identically.

Proof Tier

Prove that for any robust loss function \(L(y, h) = \tilde{C}(h) + C(h) y + f(y)\), the ranking difference \(\Delta L_t = L(\hat{\sigma}_t^2, h_{1t}) - L(\hat{\sigma}_t^2, h_{2t})\) has expectation equal to the true variance ranking difference \(\Delta L(\sigma_t^2)\) whenever \(\E[\hat{\sigma}_t^2 \mid \mathcal{F}_{t-1}] = \sigma_t^2\).

Worked Solution

Write out the loss difference for an arbitrary observation: \[ \begin{aligned} \Delta L(\hat{\sigma}_t^2) &= L(\hat{\sigma}_t^2, h_{1t}) - L(\hat{\sigma}_t^2, h_{2t}) \\ &= \big(\tilde{C}(h_{1t}) + C(h_{1t}) \hat{\sigma}_t^2 + f(\hat{\sigma}_t^2)\big) - \big(\tilde{C}(h_{2t}) + C(h_{2t}) \hat{\sigma}_t^2 + f(\hat{\sigma}_t^2)\big) \\ &= \big(\tilde{C}(h_{1t}) - \tilde{C}(h_{2t})\big) + \big(C(h_{1t}) - C(h_{2t})\big) \hat{\sigma}_t^2. \end{aligned} \] Taking conditional expectation with respect to \(\mathcal{F}_{t-1}\), noting that \(h_{1t}, h_{2t} \in \mathcal{F}_{t-1}\): \[ \begin{aligned} \E\big[\Delta L(\hat{\sigma}_t^2) \mid \mathcal{F}_{t-1}\big] &= \big(\tilde{C}(h_{1t}) - \tilde{C}(h_{2t})\big) + \big(C(h_{1t}) - C(h_{2t})\big) \E\big[\hat{\sigma}_t^2 \mid \mathcal{F}_{t-1}\big] \\ &= \big(\tilde{C}(h_{1t}) - \tilde{C}(h_{2t})\big) + \big(C(h_{1t}) - C(h_{2t})\big) \sigma_t^2 \\ &= L(\sigma_t^2, h_{1t}) - L(\sigma_t^2, h_{2t}) = \Delta L(\sigma_t^2). \end{aligned} \] Taking unconditional expectations completes the proof: \(\E[\Delta L(\hat{\sigma}_t^2)] = \E[\Delta L(\sigma_t^2)]\). The proxy ranking is unconditionally identical to the true variance ranking.

Prove that if \(\frac{\partial^2 L}{\partial y \partial h}\) depends on \(y\), there exist two forecasts \(h_1 \ne h_2\) and two conditionally unbiased distributions of \(\hat{\sigma}^2\) such that the model ranking flips.

Worked Solution

Suppose \(\frac{\partial^2 L}{\partial y \partial h} = g(y, h)\) depends non-trivially on \(y\). Then the expected loss difference \(\E[L(\hat{\sigma}^2, h_1) - L(\hat{\sigma}^2, h_2) \mid \mathcal{F}]\) depends on higher-order moments of \(\hat{\sigma}^2\) (such as its variance \(\Var(\hat{\sigma}^2 \mid \mathcal{F})\) or skewness) via Taylor series expansion: \[ \E[L(\hat{\sigma}^2, h) \mid \mathcal{F}] = L(\sigma^2, h) + \frac{1}{2} \frac{\partial^2 L(\sigma^2, h)}{\partial y^2} \Var(\hat{\sigma}^2 \mid \mathcal{F}) + \dots \] Taking the difference between \(h_1\) and \(h_2\): \[ \E[\Delta L(\hat{\sigma}^2)] = \Delta L(\sigma^2) + \frac{1}{2} \left(\frac{\partial^2 L(\sigma^2, h_1)}{\partial y^2} - \frac{\partial^2 L(\sigma^2, h_2)}{\partial y^2}\right) \Var(\hat{\sigma}^2 \mid \mathcal{F}) + \dots \] Because \(\frac{\partial^2 L}{\partial y^2}\) depends on \(h\), the term in parentheses is non-zero. By selecting a proxy distribution with sufficiently large variance \(\Var(\hat{\sigma}^2 \mid \mathcal{F})\), the second-order term can be made larger in magnitude than \(\Delta L(\sigma^2)\) and of opposite sign, reversing the sign of the expected loss difference and flipping the ranking.

Prove that the log-squared error loss \(L(y, h) = (\ln y - \ln h)^2\) is non-robust by showing that the proxy noise variance introduces an intractable distortion term in the expected loss.

Worked Solution

Expand \(L(y, h)\): \[ L(y, h) = (\ln y - \ln h)^2 = (\ln y)^2 - 2 \ln y \ln h + (\ln h)^2. \] Compute the cross-partial derivative: \[ \frac{\partial L}{\partial h} = -\frac{2 \ln y}{h} + \frac{2 \ln h}{h}. \] \[ \frac{\partial^2 L}{\partial y \partial h} = -\frac{2}{y h}. \] Because this depends explicitly on the proxy \(y\) via \(1/y\), Patton's condition is violated. Furthermore, taking expectations with proxy \(\hat{\sigma}^2 = \sigma^2 \eta\) where \(\E[\eta] = 1\): \[ \E[\ln \hat{\sigma}^2 \mid \mathcal{F}] = \ln \sigma^2 + \E[\ln \eta]. \] By Jensen's inequality, \(\E[\ln \eta] < \ln \E[\eta] = 0\). The distortion term \(\E[\ln \eta]\) depends on the shape of the proxy noise distribution, which alters the optimal forecast away from \(\sigma^2\) and corrupts model rankings.

Empirical Tier

A quantitative research team runs a Diebold-Mariano test comparing a deep neural network volatility forecaster against a standard GARCH(1,1) model using MAE loss, obtaining a \(p\)-value of 0.01 in favor of the neural network. Should the portfolio manager approve the model for production trading? Explain.

Worked Solution

No, the portfolio manager should reject or suspend approval until re-evaluated under a robust loss function. Because MAE is strictly non-robust to proxy noise, minimizing MAE trains and selects models that track the conditional median of the proxy rather than the conditional mean (variance). Because squared return proxies are right-skewed, the neural network may simply be generating systematically depressed variance forecasts that score well under MAE while grossly underestimating risk in actual trading. The evaluation must be re-conducted using QLIKE and Patton's robust family.

In an academic paper, the author evaluates volatility models using Mean Absolute Percentage Error: \(\text{MAPE} = \frac{1}{T} \sum_{t=1}^T \frac{|\hat{\sigma}_t^2 - h_t|}{\hat{\sigma}_t^2}\). Identify the econometric error and discuss its consequence.

Worked Solution

MAPE is flawed on two counts. First, like MAE, it is non-robust: its cross-derivative depends on \(\operatorname{sgn}(\hat{\sigma}^2 - h)\), violating Patton's condition. Second, placing the noisy proxy \(\hat{\sigma}_t^2\) in the denominator creates severe numerical and statistical distortion: whenever market returns are near zero, \(\hat{\sigma}_t^2 \approx 0\), causing individual loss terms to explode toward infinity. This makes the MAPE statistic dominated by random near-zero price noise rather than forecast accuracy.

How does increasing proxy precision (e.g. switching from daily squared returns to 5-minute realized variance) impact empirical model comparison even when using a robust loss function?

Worked Solution

While Patton's theorem guarantees that expected model rankings are identical under any conditionally unbiased proxy, in a finite sample of size \(T\), sampling noise in the proxy inflates the variance of the loss differential \(\Var(\bar{d}_T)\). Switching from squared daily returns to 5-minute realized variance reduces proxy variance \(\Var(\hat{\sigma}_t^2 \mid \sigma_t^2)\) by over 90%. This dramatically shrinks the standard error of the Diebold-Mariano test, transforming inconclusive tests into statistically significant distinctions and drastically reducing the sample size required to validate superior models.

Research Tier

Derive the robust loss family when the target of interest is conditional standard deviation \(\sigma_t\) rather than conditional variance \(\sigma_t^2\).

Worked Solution

Patton (2011) showed that if the object of interest is \(\sigma_t\), an unbiased proxy for standard deviation \(\hat{\sigma}\) is generally unavailable without distributional assumptions. However, if one specifies a loss function \(L(\hat{\sigma}^2, h_\sigma)\) comparing a variance proxy \(\hat{\sigma}^2\) directly to a standard deviation forecast \(h_\sigma\), the first-order condition must elicit \(h_\sigma^* = \sigma = \sqrt{\E[\hat{\sigma}^2 \mid \mathcal{F}]}\). The robust family of homogeneous loss functions for standard deviation forecasts takes the form: \[ L(y, h_\sigma) = \frac{1}{b(b-2)}\left(y^{b/2} - h_\sigma^b\right) - \frac{1}{b-2} h_\sigma^{b-2}(y - h_\sigma^2), \] which guarantees that the standard deviation forecast is consistent without requiring an unbiased standard deviation proxy.

Analyze the robustness of out-of-sample forecast comparison when the volatility proxy is contaminated by additive market microstructure noise: \(\tilde{y}_t = \sigma_t^2 + \text{bias}_t + \eta_t\).

Worked Solution

Patton's theorem assumes \(\E[\hat{\sigma}_t^2 \mid \mathcal{F}_{t-1}] = \sigma_t^2\). If additive microstructure noise induces a non-zero bias \(b_t = 2 M \sigma_\varepsilon^2\), then \(\E[\tilde{y}_t \mid \mathcal{F}_{t-1}] = \sigma_t^2 + b_t\). Under MSE, \(\E[( \tilde{y}_t - h_t)^2] = \E[(\sigma_t^2 + b_t - h_t)^2] + \Var(\eta_t)\). The optimal forecast shifts to \(h^* = \sigma_t^2 + b_t\). If competing models have differing abilities to absorb this artificial constant bias, the ranking evaluated on \(\tilde{y}_t\) will select the model that best matches the noise bias rather than the true variance, proving that proxy unbiasedness is a non-negotiable prerequisite for robust evaluation.

Discuss how the Giacomini-White (2006) test for conditional predictive ability generalizes the Diebold-Mariano test within Patton's robust scoring framework.

Worked Solution

The standard Diebold-Mariano test evaluates unconditional predictive ability: \(H_0: \E[L(\hat{\sigma}_{t+1}^2, h_{1, t+1}) - L(\hat{\sigma}_{t+1}^2, h_{2, t+1})] = 0\). Giacomini and White extend this to conditional predictive ability: \(H_0: \E[\Delta L_{t+1} \mid \mathcal{G}_t] = 0\), testing whether the forecast superiority of Model 1 over Model 2 is predictable using instruments \(q_t \in \mathcal{G}_t\) (e.g. current market regime or VIX levels). By using a Patton-robust loss function like QLIKE as the scoring rule, the Giacomini-White test enables econometricians to establish dynamic model switching rules that are completely immune to proxy noise distortion.

Diagnostic Quiz

  1. What is the defining condition of a "robust" volatility loss function according to Patton (2011)?

    Robustness guarantees that noise in the empirical proxy cannot distort or invert the relative ranking of competing forecasting models.

  2. What mathematical property characterizes all robust loss functions \(L(y, h)\)?

    Patton proved that \(\partial^2 L / (\partial y \partial h) = g(h)\) is the necessary and sufficient condition for ranking invariance under conditionally unbiased proxies.

  3. Which of the following loss functions is NOT robust to proxy noise?

    MAE's cross-derivative involves \(\operatorname{sgn}(y - h)\), which depends on the realized proxy \(y\), causing ranking distortions.

  4. In Patton's homogeneous family of robust losses \(L_b(y, h)\), what value of parameter \(b\) corresponds to QLIKE?

    Taking the limit of \(L_b(y, h)\) as \(b \to 0\) via L'Hôpital's rule recovers QLIKE loss.

  5. Why does Mean Absolute Percentage Error (MAPE) fail as a volatility forecast evaluation metric?

    MAPE divides by the noisy proxy \(\hat{\sigma}_t^2\), which diverges whenever price returns are close to zero, rendering the metric statistically unstable and non-robust.

  6. What assumption regarding the volatility proxy is essential for Patton's robustness theorem to hold?

    Patton's theorem relies directly on the law of iterated expectations \(\E[\Delta L(\hat{\sigma}^2) \mid \mathcal{F}] = \Delta L(\sigma^2)\), which requires conditional unbiasedness.

  7. If an analyst evaluates volatility models using Log-MSE loss \((\ln y - \ln h)^2\), what econometric problem occurs?

    Because \(\ln(\cdot)\) is concave, Jensen's inequality introduces a negative distortion term \(\E[\ln \eta] < 0\), violating robustness and distorting rankings.

  8. How does the Model Confidence Set (MCS) procedure of Hansen et al. (2011) utilize robust loss functions in practice?

    MCS uses robust loss differentials to test equal predictive ability, pruning inferior forecasters to construct a statistically valid confidence set.
