The Generalized ARCH (GARCH) Model

Parsimonious Infinite-Memory Volatility Modeling, ARMA Analogies, and Persistence Dynamics

Why It Matters

Fitting financial market volatility using Engle's pure ARCH model often requires twenty or more lagged squared return shocks, creating unwieldy parameter vectors that frequently violate non-negativity constraints. Tim Bollerslev solved this parameter profligacy by adding lagged conditional variances to the recursion. The resulting GARCH(1,1) specification requires just three parameters to capture an infinite exponentially decaying cascade of past shocks. For four decades, GARCH(1,1) has served as the indispensable workhorse benchmark of industrial quantitative finance, foundational to risk budgeting, Value-at-Risk calculations, margin modeling at clearinghouses, and dynamic volatility trading strategies across global financial institutions.

1. The GARCH(p, q) Specification

In his landmark dissertation work, Bollerslev (1986) extended the ARCH model by permitting lagged conditional variances to enter the conditional variance equation directly.

Definition 3.1 · GARCH(p, q) Model

Let \(\{\varepsilon_t\}\) be a discrete-time stochastic process adapted to filtration \(\mathcal{F}_{t-1}\). The process is a GARCH model of orders \(p\) and \(q\), denoted GARCH(\(p, q\)), if:

\[ \begin{aligned} \varepsilon_t &= \sigma_t z_t, \\ z_t &\iid \Normal(0, 1), \\ \sigma_t^2 &= \omega + \sum_{i=1}^q \alpha_i \varepsilon_{t-i}^2 + \sum_{j=1}^p \beta_j \sigma_{t-j}^2, \end{aligned} \]

where \(\omega > 0\), \(\alpha_i \ge 0\) for \(i=1,\dots,q\), and \(\beta_j \ge 0\) for \(j=1,\dots,p\). The standard workhorse is the GARCH(1,1) specification:

\[ \sigma_t^2 = \omega + \alpha \varepsilon_{t-1}^2 + \beta \sigma_{t-1}^2. \]
Theorem 3.1 · GARCH(1,1) Covariance Stationarity and Unconditional Variance

Assumptions:

  1. Let \(\varepsilon_t = \sigma_t z_t\) with \(\sigma_t^2 = \omega + \alpha \varepsilon_{t-1}^2 + \beta \sigma_{t-1}^2\).
  2. Standardized shocks satisfy \(z_t \iid \Normal(0, 1)\) independent of \(\mathcal{F}_{t-1}\).
  3. Parameters satisfy \(\omega > 0\), \(\alpha \ge 0\), and \(\beta \ge 0\).

Conclusions:

  1. The process is weakly stationary if and only if: \[ \alpha + \beta < 1. \]
  2. Under weak stationarity, the unconditional variance is: \[ \Var(\varepsilon_t) = \sigma^2 = \frac{\omega}{1 - \alpha - \beta}. \]
  3. The persistence parameter is \(\rho = \alpha + \beta\). The half-life of a volatility shock in discrete periods is: \[ h_{1/2} = \frac{\ln(0.5)}{\ln(\alpha + \beta)}. \]
Proof

Taking the unconditional expectation of both sides of \(\sigma_t^2 = \omega + \alpha \varepsilon_{t-1}^2 + \beta \sigma_{t-1}^2\) and applying the law of iterated expectations:

\[ \E[\sigma_t^2] = \omega + \alpha \E[\varepsilon_{t-1}^2] + \beta \E[\sigma_{t-1}^2]. \]

Since \(\E[\varepsilon_{t-1}^2] = \E[\sigma_{t-1}^2 \E[z_{t-1}^2 \mid \mathcal{F}_{t-2}]] = \E[\sigma_{t-1}^2]\), we have:

\[ \E[\sigma_t^2] = \omega + (\alpha + \beta) \E[\sigma_{t-1}^2]. \]

Under weak stationarity, \(\E[\sigma_t^2] = \E[\sigma_{t-1}^2] = \sigma^2\). Imposing this condition yields:

\[ \sigma^2 = \omega + (\alpha + \beta) \sigma^2 \implies \sigma^2(1 - \alpha - \beta) = \omega. \]

Because \(\omega > 0\) and variance must be positive, this requires \(1 - \alpha - \beta > 0 \iff \alpha + \beta < 1\), giving \(\sigma^2 = \omega / (1 - \alpha - \beta)\).

To determine shock decay, consider the forecast \(k\) steps ahead: \(\E[\sigma_{t+k}^2 \mid \mathcal{F}_t] - \sigma^2 = (\alpha + \beta)^k (\sigma_t^2 - \sigma^2)\). The deviation decays by half when \((\alpha + \beta)^{h_{1/2}} = 0.5 \iff h_{1/2} \ln(\alpha + \beta) = \ln(0.5) \iff h_{1/2} = \ln(0.5)/\ln(\alpha + \beta)\).

Remark 3.1 · ARMA Representation of Squared Residuals

Define the zero-mean martingale difference innovation \(v_t = \varepsilon_t^2 - \sigma_t^2\). Substituting \(\sigma_t^2 = \varepsilon_t^2 - v_t\) into the GARCH(1,1) equation yields:

\[ \varepsilon_t^2 - v_t = \omega + \alpha \varepsilon_{t-1}^2 + \beta (\varepsilon_{t-1}^2 - v_{t-1}), \] \[ \varepsilon_t^2 = \omega + (\alpha + \beta) \varepsilon_{t-1}^2 + v_t - \beta v_{t-1}. \]

This is an ARMA(1,1) process for \(\varepsilon_t^2\) with autoregressive parameter \(\alpha + \beta\) and moving-average parameter \(-\beta\). This equivalence explains why GARCH captures long memory with so few parameters: an ARMA(1,1) corresponds to an infinite-order ARCH(\(\infty\)) with geometrically decaying weights \(\alpha_j = \alpha \beta^{j-1}\).

Example 3.1 · Persistence and Half-Life Calculation

In daily equity returns, typical estimates are \(\alpha = 0.08\) and \(\beta = 0.90\). The persistence is \(\alpha + \beta = 0.98\). The half-life of a volatility shock is:

\[ h_{1/2} = \frac{\ln(0.5)}{\ln(0.98)} = \frac{-0.69315}{-0.02020} \approx 34.31 \text{ trading days}. \]

A shock to volatility requires nearly seven full trading weeks to decay by half, illustrating the substantial memory of financial risk.

2. Empirical Simulation of GARCH(1,1)

We execute an in-line simulation of a GARCH(1,1) process with parameters \(\omega = 0.05\), \(\alpha = 0.10\), and \(\beta = 0.85\) (\(\alpha + \beta = 0.95\)) over 10,000 steps.

Lab 1 · GARCH(1,1) Variance Recursion and Persistence

Simulating GARCH(1,1) with omega=0.05, alpha=0.10, and beta=0.85 verifies unconditional variance 1.0000 within sampling tolerance and confirms shock half-life of approximately 13.5 periods.

"""Lab S4-L03-1: GARCH(1,1) variance recursion, stationarity, and persistence.

SIMULATED: simulates a stationary GARCH(1,1) process, computes conditional variance
recursion, and verifies empirical sample moments against theoretical unconditional limits.
"""

from __future__ import annotations

import math
import random


def simulate_garch11(
    omega: float, alpha: float, beta: float, n: int, seed: int = 123
) -> tuple[list[float], list[float]]:
    """Simulate GARCH(1,1) process with burn-in."""
    rng = random.Random(seed)
    burn = 500
    uncond_var = omega / (1.0 - alpha - beta)
    h = uncond_var
    for _ in range(burn):
        z = rng.gauss(0.0, 1.0)
        eps = math.sqrt(h) * z
        h = omega + alpha * (eps**2) + beta * h

    epsilons: list[float] = []
    variances: list[float] = []
    for _ in range(n):
        z = rng.gauss(0.0, 1.0)
        eps = math.sqrt(h) * z
        epsilons.append(eps)
        variances.append(h)
        h = omega + alpha * (eps**2) + beta * h
    return epsilons, variances


def main() -> None:
    omega = 0.05
    alpha = 0.10
    beta = 0.85
    n = 10000
    eps, h = simulate_garch11(omega, alpha, beta, n, seed=123)

    var_emp = sum(e * e for e in eps) / n
    mean_h = sum(h) / n
    theo_var = omega / (1.0 - alpha - beta)
    persistence = alpha + beta
    half_life = math.log(0.5) / math.log(persistence)

    print(f"GARCH(1,1) Simulation (omega={omega:.2f}, alpha={alpha:.2f}, beta={beta:.2f}, n={n})")
    print(f"Theoretical unconditional variance: {theo_var:.4f}")
    print(f"Sample mean conditional variance:   {mean_h:.4f}")
    print(f"Sample variance of returns:         {var_emp:.4f}")
    print(f"Persistence (alpha + beta):         {persistence:.4f}")
    print(f"Shock half-life (periods):          {half_life:.2f}")


main()
GARCH(1,1) Simulation (omega=0.05, alpha=0.10, beta=0.85, n=10000)
Theoretical unconditional variance: 1.0000
Sample mean conditional variance:   1.0152
Sample variance of returns:         1.0228
Persistence (alpha + beta):         0.9500
Shock half-life (periods):          13.51

The sample mean of the conditional variance sequence and the sample return variance both match the theoretical unconditional variance 1.0000. The persistence parameter 0.95 produces the predicted 13.51-period half-life, verifying the stationarity theorem.

Where the Canon Breaks

Although GARCH(1,1) is the standard baseline across financial econometrics, its fundamental structure imposes several critical restrictions:

  • Integrated GARCH (IGARCH) artifact: In long historical series, estimated persistence \(\hat{\alpha} + \hat{\beta}\) often approaches or equals 1.00. While labeled "Integrated GARCH", Mikosch and Starica demonstrated that this apparent unit root is frequently an artifact of unmodeled structural breaks in unconditional variance rather than true permanent memory.
  • Symmetry constraint: Like ARCH, GARCH specifies \(\sigma_t^2\) as a function of \(\varepsilon_{t-1}^2\). It cannot account for the empirical reality that negative equity shocks trigger significantly larger volatility spikes than positive shocks of identical size.
  • Non-negativity boundary traps: Maximizing the Gaussian likelihood under the hard inequality constraints \(\omega > 0, \alpha \ge 0, \beta \ge 0\) frequently traps numerical solvers on boundary edges, especially in multi-asset or high-frequency contexts.

Misconceptions

  • Wrong belief: An Integrated GARCH (IGARCH) model with \(\alpha + \beta = 1\) is non-stationary and has explosive variance paths.

    Why it is wrong: Nelson (1990) proved that IGARCH(1,1) processes are strictly stationary and ergodic with probability 1, even though their second moments do not exist and they are not covariance stationary. Sample paths do not explode to infinity.

  • Wrong belief: High persistence (\(\alpha + \beta \approx 0.99\)) implies that conditional variance forecasts are unpredictable.

    Why it is wrong: High persistence means that current volatility shocks decay very slowly, making multi-day and multi-week volatility forecasts highly informative and predictable rather than random.

  • Wrong belief: The GARCH(1,1) parameter \(\alpha\) measures long-run volatility persistence.

    Why it is wrong: The parameter \(\alpha\) measures the immediate reaction to new return shocks (the ARCH effect). Long-run persistence is determined by the sum \(\alpha + \beta\). An asset with low \(\alpha\) (e.g. 0.03) and high \(\beta\) (e.g. 0.95) has high persistence but low immediate reactivity.

Practice Problems

Mechanics Tier

A GARCH(1,1) model has parameters \(\omega = 0.02\), \(\alpha = 0.08\), and \(\beta = 0.87\). Calculate the unconditional variance \(\sigma^2\), the persistence \(\rho\), and the shock half-life \(h_{1/2}\) in trading days.

Worked Solution

Persistence: \(\rho = \alpha + \beta = 0.08 + 0.87 = 0.95\). Since \(\rho < 1\), the process is covariance stationary. Unconditional variance: \(\sigma^2 = \omega / (1 - \rho) = 0.02 / (1 - 0.95) = 0.02 / 0.05 = 0.4000\). Half-life: \(h_{1/2} = \ln(0.5) / \ln(0.95) \approx -0.69315 / -0.05129 \approx 13.51\) trading days.

Given the GARCH(1,1) model above, suppose yesterday's conditional variance was \(\sigma_{t-1}^2 = 0.50\) and yesterday's return shock was \(\varepsilon_{t-1} = -1.20\). Compute today's conditional variance \(\sigma_t^2\).

Worked Solution

Apply the recursion: \(\sigma_t^2 = \omega + \alpha \varepsilon_{t-1}^2 + \beta \sigma_{t-1}^2\). Here, \(\varepsilon_{t-1}^2 = (-1.20)^2 = 1.44\). Thus: \[ \sigma_t^2 = 0.02 + 0.08 \times 1.44 + 0.87 \times 0.50 = 0.02 + 0.1152 + 0.4350 = 0.5702. \]

If today's conditional variance is \(\sigma_t^2 = 0.80\) in a GARCH(1,1) process with \(\sigma^2 = 0.40\) and \(\alpha + \beta = 0.95\), calculate the multi-step volatility forecast 10 days ahead, \(\E[\sigma_{t+10}^2 \mid \mathcal{F}_t]\).

Worked Solution

The multi-step forecast formula is \(\E[\sigma_{t+k}^2 \mid \mathcal{F}_t] = \sigma^2 + (\alpha + \beta)^k (\sigma_t^2 - \sigma^2)\). For \(k = 10\): \[ \E[\sigma_{t+10}^2 \mid \mathcal{F}_t] = 0.40 + 0.95^{10} (0.80 - 0.40) = 0.40 + 0.5987 \times 0.40 = 0.40 + 0.2395 = 0.6395. \]

Proof Tier

Prove that the multi-step forecast of a GARCH(1,1) model satisfies \(\E[\sigma_{t+k}^2 \mid \mathcal{F}_t] = \sigma^2 + (\alpha + \beta)^k (\sigma_t^2 - \sigma^2)\) for all integers \(k \ge 1\).

Worked Solution

For \(k = 1\), \(\E[\sigma_{t+1}^2 \mid \mathcal{F}_t] = \omega + \alpha \E[\varepsilon_t^2 \mid \mathcal{F}_t] + \beta \sigma_t^2 = \omega + (\alpha + \beta)\sigma_t^2\). Using \(\omega = \sigma^2(1 - \alpha - \beta)\): \[ \E[\sigma_{t+1}^2 \mid \mathcal{F}_t] = \sigma^2(1 - \alpha - \beta) + (\alpha + \beta)\sigma_t^2 = \sigma^2 + (\alpha + \beta)(\sigma_t^2 - \sigma^2). \] Assume by induction that the formula holds for horizon \(k-1\). By the law of iterated expectations: \[ \E[\sigma_{t+k}^2 \mid \mathcal{F}_t] = \sigma^2 + (\alpha + \beta)\left(\E[\sigma_{t+k-1}^2 \mid \mathcal{F}_t] - \sigma^2\right) = \sigma^2 + (\alpha + \beta)\left((\alpha + \beta)^{k-1}(\sigma_t^2 - \sigma^2)\right) = \sigma^2 + (\alpha + \beta)^k(\sigma_t^2 - \sigma^2). \] This completes the mathematical induction for all \(k \ge 1\).

Prove that an ARCH(\(\infty\)) process \(\sigma_t^2 = \psi_0 + \sum_{j=1}^\infty \psi_j \varepsilon_{t-j}^2\) with \(\psi_j = \alpha \beta^{j-1}\) is mathematically identical to a GARCH(1,1) process.

Worked Solution

In GARCH(1,1), \(\sigma_t^2 = \omega + \alpha \varepsilon_{t-1}^2 + \beta \sigma_{t-1}^2\). Iterating backward repeatedly: \[ \begin{aligned} \sigma_t^2 &= \omega + \alpha \varepsilon_{t-1}^2 + \beta (\omega + \alpha \varepsilon_{t-2}^2 + \beta \sigma_{t-2}^2) \\ &= \omega(1 + \beta) + \alpha \varepsilon_{t-1}^2 + \alpha\beta \varepsilon_{t-2}^2 + \beta^2 \sigma_{t-2}^2 \\ &= \omega \sum_{k=0}^{m-1} \beta^k + \sum_{j=1}^m \alpha \beta^{j-1} \varepsilon_{t-j}^2 + \beta^m \sigma_{t-m}^2. \end{aligned} \] Since \(0 \le \beta < 1\), as \(m \to \infty\), \(\beta^m \sigma_{t-m}^2 \to 0\) almost surely, and \(\omega \sum_{k=0}^\infty \beta^k = \omega / (1 - \beta) = \psi_0\). Thus, \(\sigma_t^2 = \psi_0 + \sum_{j=1}^\infty (\alpha \beta^{j-1}) \varepsilon_{t-j}^2\), matching the ARCH(\(\infty\)) representation.

Show that the fourth moment of a GARCH(1,1) process exists if and only if \((\alpha + \beta)^2 + 2\alpha^2 < 1\) under Gaussian innovations.

Worked Solution

Bollerslev (1986) derived \(\E[\sigma_t^4]\) by squaring the variance equation: \(\sigma_t^4 = \omega^2 + \alpha^2 \varepsilon_{t-1}^4 + \beta^2 \sigma_{t-1}^4 + 2\omega\alpha \varepsilon_{t-1}^2 + 2\omega\beta \sigma_{t-1}^2 + 2\alpha\beta \varepsilon_{t-1}^2 \sigma_{t-1}^2\). Under \(z_t \iid \Normal(0,1)\), \(\E[\varepsilon_{t-1}^4 \mid \mathcal{F}_{t-2}] = 3\sigma_{t-1}^4\) and \(\E[\varepsilon_{t-1}^2 \sigma_{t-1}^2 \mid \mathcal{F}_{t-2}] = \sigma_{t-1}^4\). Taking expectations: \[ \E[\sigma_t^4] = \text{const} + (3\alpha^2 + \beta^2 + 2\alpha\beta) \E[\sigma_{t-1}^4] = \text{const} + ((\alpha + \beta)^2 + 2\alpha^2) \E[\sigma_{t-1}^4]. \] A finite stationary solution requires the coefficient on \(\E[\sigma_{t-1}^4]\) to be strictly less than 1, yielding \((\alpha + \beta)^2 + 2\alpha^2 < 1\).

Empirical Tier

In daily S&P 500 returns, an estimated GARCH(1,1) model produces \(\hat{\omega} = 1.5 \times 10^{-6}\), \(\hat{\alpha} = 0.085\), and \(\hat{\beta} = 0.905\). Annualize the unconditional volatility assuming 252 trading days per year.

Worked Solution

Daily unconditional variance is \(\sigma^2 = \omega / (1 - \alpha - \beta) = (1.5 \times 10^{-6}) / (1 - 0.085 - 0.905) = (1.5 \times 10^{-6}) / 0.010 = 1.5 \times 10^{-4}\). The daily standard deviation is \(\sigma = \sqrt{1.5 \times 10^{-4}} \approx 0.012247\) (1.225% per day). Annualizing by multiplying by \(\sqrt{252}\): \(\sigma_{\text{ann}} = 0.012247 \times 15.8745 \approx 0.1944\) or 19.44% per annum.

Why does estimating GARCH(1,1) on 5-minute intraday returns over a multi-month period often fail or produce \(\alpha + \beta \ge 1\)?

Worked Solution

Intraday returns display strong deterministic diurnal U-shaped volatility patterns (high volatility at the market open and close, low at midday). Standard GARCH assumes covariance stationarity without diurnal seasonality. Confounding intraday cyclical swings with stochastic volatility persistence artificially inflates \(\alpha + \beta\) toward 1.0. Intraday returns must be filtered to remove deterministic diurnal patterns before GARCH estimation.

Explain how a variance targeting constraint in GARCH(1,1) estimation improves numerical optimization stability.

Worked Solution

Variance targeting re-parameterizes the intercept as \(\omega = \bar{s}^2 (1 - \alpha - \beta)\), where \(\bar{s}^2 = \frac{1}{T} \sum r_t^2\) is the sample variance of returns. This eliminates \(\omega\) from the numerical optimization search, reducing a 3-dimensional optimization problem over \((\omega, \alpha, \beta)\) to a 2-dimensional search over \((\alpha, \beta)\). This ensures the unconditional variance matches the sample variance by construction and prevents solvers from getting stuck in degenerate zero-intercept regions.

Research Tier

Formulate the Nelson (1990) continuous-time diffusion limit of a GARCH(1,1) process as sampling interval \(\Delta t \to 0\).

Worked Solution

Nelson (1990) proved that as the time step \(\Delta t \to 0\), under suitable parameter scaling, the discrete GARCH(1,1) bivariate process \((r_t, \sigma_t^2)\) converges weakly to a continuous stochastic volatility diffusion: \[ \begin{aligned} dp_t &= \sigma_t dW_{1,t}, \\ d\sigma_t^2 &= \kappa(\theta - \sigma_t^2) dt + \xi \sigma_t^2 dW_{2,t}, \end{aligned} \] where \(W_{1,t}\) and \(W_{2,t}\) are independent Brownian motions. Unlike discrete GARCH where volatility and returns share the same shock \(z_t\), the continuous limit is a two-factor diffusion where volatility Innovations are asymptotically uncorrelated with price innovations.

Examine the stationarity of Nelson's (1990) IGARCH(1,1) model using the Lyapunov exponent condition.

Worked Solution

For \(\sigma_t^2 = \omega + (\alpha z_{t-1}^2 + \beta)\sigma_{t-1}^2\), write \(A_t = \alpha z_t^2 + \beta\). The top Lyapunov exponent is \(\gamma_L = \E[\ln(\alpha z_t^2 + \beta)]\). By Jensen's inequality, \(\E[\ln A_t] < \ln \E[A_t] = \ln(\alpha + \beta)\). In an IGARCH(1,1) model where \(\alpha + \beta = 1\), \(\E[\ln(\alpha z_t^2 + \beta)] < \ln(1) = 0\). Because the Lyapunov exponent is strictly negative, the process is strictly stationary and ergodic despite possessing an infinite second moment.

Contrast the term structure of volatility implied by a GARCH(1,1) process against the empirical term structure observed in VIX option markets.

Worked Solution

In GARCH(1,1), the term structure of expected cumulative variance \(\frac{1}{K}\sum_{k=1}^K \E[\sigma_{t+k}^2 \mid \mathcal{F}_t]\) is strictly monotonic in horizon \(K\): it slopes monotonically upward when current volatility is below unconditional mean \(\sigma_t^2 < \sigma^2\) and monotonically downward when \(\sigma_t^2 > \sigma^2\). Real-world implied volatility term structures from options markets frequently exhibit humped or non-monotonic shapes, reflecting multiple volatility components acting over distinct trading horizons.

Retrieval Quiz

  1. What condition ensures weak (covariance) stationarity in the standard GARCH(1,1) model?

    Covariance stationarity requires the autoregressive root \(1 - (\alpha + \beta)L = 0\) to lie outside the unit circle, requiring \(\alpha + \beta < 1\).

  2. What is the formula for the unconditional variance of a stationary GARCH(1,1) process?

    Taking expectations yields \(\E[\sigma_t^2] = \omega + (\alpha + \beta)\E[\sigma_t^2]\), which rearranges to \(\omega / (1 - \alpha - \beta)\).

  3. For a GARCH(1,1) model with persistence \(\alpha + \beta = 0.90\), what is the half-life of a volatility shock in discrete periods?

    \(h_{1/2} = \ln(0.5) / \ln(0.90) \approx -0.69315 / -0.10536 \approx 6.5788\) periods.

  4. What ARMA process representation governs the squared residuals \(\varepsilon_t^2\) in a GARCH(1,1) model?

    Substituting \(v_t = \varepsilon_t^2 - \sigma_t^2\) gives \(\varepsilon_t^2 = \omega + (\alpha + \beta)\varepsilon_{t-1}^2 + v_t - \beta v_{t-1}\).

  5. In an Integrated GARCH (IGARCH) model where \(\alpha + \beta = 1\), what did Nelson (1990) prove about the process?

    Nelson proved that the top Lyapunov exponent \(\E[\ln(\alpha z_t^2 + \beta)] < 0\) remains strictly negative, guaranteeing strict stationarity and ergodicity.

  6. In a GARCH(1,1) process with \(\omega = 0.04\), \(\alpha = 0.10\), and \(\beta = 0.85\), what is the unconditional variance?

    \(\sigma^2 = \omega / (1 - \alpha - \beta) = 0.04 / 0.05 = 0.8000\).

  7. Why is variance targeting widely employed in professional quantitative GARCH implementations?

    Variance targeting sets \(\omega = \bar{s}^2(1 - \alpha - \beta)\), anchoring unconditional variance to historical sample variance and improving optimization convergence.

  8. What major empirical phenomenon in equity returns does the symmetric GARCH(1,1) model fail to capture?

    Because \(\varepsilon_{t-1}^2\) treats positive and negative return innovations identically, GARCH(1,1) cannot capture asymmetric leverage effects.
