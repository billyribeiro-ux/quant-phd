Omitted-variable bias

In empirical financial economics, omitted variables are the primary source of parameter inconsistency. Omitting a relevant pricing factor—such as market momentum, liquidity risk, or credit exposure—when evaluating portfolio alpha or corporate investment policy attributes the omitted factor's return premium to the included regressor. Understanding the exact algebraic structure of omitted-variable bias allows researchers to sign the direction of bias and distinguish valid identification strategies from spurious regressions.

Short versus long regressions

Suppose the true data-generating process governing asset returns or firm outcomes is the "long" linear model:

\[ y = X_1\beta_1 + X_2\beta_2 + \varepsilon \]

where \(X_1 \in \R^{n \times k_1}\) represents the included regressors of primary interest and \(X_2 \in \R^{n \times k_2}\) represents relevant explanatory variables omitted from the estimated model.

Assumption 5.1 (Long Model Exogeneity)

The disturbance term \(\varepsilon \in \R^n\) in the long specification satisfies strict conditional exogeneity with respect to all regressors:

\[ \E[\varepsilon | X_1, X_2] = 0 \]

Furthermore, the joint design matrix \([X_1 \;\; X_2]\) has full column rank \(k_1 + k_2 < n\).

Instead of estimating the long model, a researcher estimates the "short" regression of \(y\) on \(X_1\) alone:

\[ y = X_1\beta_1 + u \]

The short-regression ordinary least squares estimator is \(\hat\beta_1^{\mathrm{short}} = (X_1'X_1)^{-1}X_1'y\).

The omitted-variable bias formula

Theorem 5.1 (Omitted-variable bias Formula)

Under Assumption 5.1, the conditional expectation of the short-regression estimator \(\hat\beta_1^{\mathrm{short}}\) equals the true parameter vector \(\beta_1\) plus a systematic bias term:

\[ \begin{aligned} \E[\hat\beta_1^{\mathrm{short}} | X_1, X_2] &= \beta_1 + (X_1'X_1)^{-1}X_1'X_2\beta_2 \\ &= \beta_1 + \hat\Gamma_{21}\beta_2 \end{aligned} \]

where \(\hat\Gamma_{21} = (X_1'X_1)^{-1}X_1'X_2 \in \R^{k_1 \times k_2}\) is the matrix of OLS coefficients obtained from regressing each omitted variable in \(X_2\) on the included regressors \(X_1\). The omitted-variable bias is:

\[ \begin{aligned} \mathrm{Bias}(\hat\beta_1^{\mathrm{short}}) &= \E[\hat\beta_1^{\mathrm{short}} | X_1, X_2] - \beta_1 \\ &= \hat\Gamma_{21}\beta_2 \end{aligned} \]

Proof of Theorem 5.1

Substitute the true long data-generating process \(y = X_1\beta_1 + X_2\beta_2 + \varepsilon\) into the short-regression estimator formula:

\[ \begin{aligned} \hat\beta_1^{\mathrm{short}} &= (X_1'X_1)^{-1}X_1' (X_1\beta_1 + X_2\beta_2 + \varepsilon) \\ &= \beta_1 + (X_1'X_1)^{-1}X_1'X_2\beta_2 \\ &\quad + (X_1'X_1)^{-1}X_1'\varepsilon \end{aligned} \]

Taking conditional expectations with respect to \([X_1 \;\; X_2]\):

\[ \begin{aligned} \E[\hat\beta_1^{\mathrm{short}} | X_1, X_2] &= \beta_1 + (X_1'X_1)^{-1}X_1'X_2\beta_2 \\ &\quad + (X_1'X_1)^{-1}X_1' \E[\varepsilon | X_1, X_2] \end{aligned} \]

By Assumption 5.1, \(\E[\varepsilon | X_1, X_2] = 0\), so the disturbance term vanishes. Defining \(\hat\Gamma_{21} = (X_1'X_1)^{-1}X_1'X_2\), we obtain \(\E[\hat\beta_1^{\mathrm{short}} | X_1, X_2] = \beta_1 + \hat\Gamma_{21}\beta_2\). Because this bias does not vanish as sample size \(n \to \infty\), \(\hat\beta_1^{\mathrm{short}}\) is not a consistent estimator of \(\beta_1\) whenever \(\hat\Gamma_{21}\beta_2 \ne 0\).

Remark 5.1 (Bivariate Signed Bias Table)

In the scalar case with one included regressor \(x_1\) and one omitted regressor \(x_2\), the auxiliary regression of \(x_2\) on \(x_1\) yields slope \(\delta = \Cov(x_1, x_2)/\Var(x_1)\). The omitted-variable bias formula simplifies to:

\[ \mathrm{Bias}(\hat\beta_1^{\mathrm{short}}) = \beta_2 \cdot \delta \]

The direction of bias is governed by the signs of \(\beta_2\) (the impact of the omitted variable on \(y\)) and \(\delta\) (the correlation between the included and omitted variables):

  • Positive bias (\(\beta_2 \delta > 0\)): When \(\beta_2 > 0\) and \(\delta > 0\), or \(\beta_2 < 0\) and \(\delta < 0\). The short regression overstates the true coefficient \(\beta_1\).
  • Negative bias (\(\beta_2 \delta < 0\)): When \(\beta_2 > 0\) and \(\delta < 0\), or \(\beta_2 < 0\) and \(\delta > 0\). The short regression understates \(\beta_1\).
  • Zero bias (\(\beta_2 \delta = 0\)): If the omitted variable is economically irrelevant (\(\beta_2 = 0\)) or uncorrelated with the included regressor (\(\delta = 0\)).

Lab 1 · Omitted-variable bias exact formula and Monte Carlo validation

Hypothesis: For a linear model with true parameters \(\beta_1 = 1.50\), \(\beta_2 = 2.00\), and auxiliary correlation slope \(\delta = 0.60\), the short-regression slope of \(y\) on \(x_1\) across 2,000 Monte Carlo replications converges to \(\beta_1 + \beta_2 \delta = 1.50 + 2.00 \times 0.60 = 2.70\), matching theoretical omitted-variable bias within sampling error.

"""Lab S2-L05-1: Omitted-variable bias exact formula and Monte Carlo validation.

Evaluates the short-regression slope against beta_1 + beta_2 * delta
on a seeded design under Monte Carlo sampling. Standard library only.
"""

from __future__ import annotations

import random


def main() -> None:
    rng = random.Random(42)
    n = 100
    replications = 2000

    # True population parameters:
    # y = alpha + beta_1 * x1 + beta_2 * x2 + eps
    alpha = 1.00
    beta1 = 1.50
    beta2 = 2.00

    # Auxiliary relationship: x2 = gamma_0 + delta * x1 + eta
    delta = 0.60
    gamma0 = 0.50

    # Theoretical omitted-variable bias for short regression of y on x1:
    # plim b1_short = beta1 + beta2 * delta = 1.50 + 2.00 * 0.60 = 2.70
    expected_short_b1 = beta1 + beta2 * delta
    theoretical_bias = beta2 * delta

    b1_short_draws: list[float] = []
    b1_long_draws: list[float] = []
    b2_long_draws: list[float] = []
    delta_draws: list[float] = []

    for _ in range(replications):
        # Draw x1
        x1 = [rng.gauss(2.0, 1.5) for _ in range(n)]
        # Draw x2 correlated with x1
        x2 = [gamma0 + delta * xi + rng.gauss(0.0, 1.0) for xi in x1]
        # Draw response y
        eps = [rng.gauss(0.0, 1.2) for _ in range(n)]
        y = [alpha + beta1 * xi1 + beta2 * xi2 + ei for xi1, xi2, ei in zip(x1, x2, eps, strict=True)]

        # 1. Short regression: y on x1
        x1_bar = sum(x1) / n
        y_bar = sum(y) / n
        s_x1x1 = sum((xi - x1_bar) ** 2 for xi in x1)
        s_x1y = sum((xi - x1_bar) * (yi - y_bar) for xi, yi in zip(x1, y, strict=True))
        b1_short = s_x1y / s_x1x1
        b1_short_draws.append(b1_short)

        # 2. Auxiliary regression: x2 on x1
        x2_bar = sum(x2) / n
        s_x1x2 = sum((xi1 - x1_bar) * (xi2 - x2_bar) for xi1, xi2 in zip(x1, x2, strict=True))
        delta_hat = s_x1x2 / s_x1x1
        delta_draws.append(delta_hat)

        # 3. Long regression: y on [x1, x2]
        s_x2x2 = sum((xi - x2_bar) ** 2 for xi in x2)
        s_x2y = sum((xi - x2_bar) * (yi - y_bar) for xi, yi in zip(x2, y, strict=True))

        det = s_x1x1 * s_x2x2 - s_x1x2 * s_x1x2
        b1_long = (s_x2x2 * s_x1y - s_x1x2 * s_x2y) / det
        b2_long = (s_x1x1 * s_x2y - s_x1x2 * s_x1y) / det
        b1_long_draws.append(b1_long)
        b2_long_draws.append(b2_long)

    mean_short = sum(b1_short_draws) / replications
    mean_long1 = sum(b1_long_draws) / replications
    mean_long2 = sum(b2_long_draws) / replications
    mean_delta = sum(delta_draws) / replications

    empirical_bias = mean_short - beta1

    print(f"True beta_1: {beta1:.4f}, True beta_2: {beta2:.4f}, True delta: {delta:.4f}")
    print(f"Theoretical short-regression slope: {expected_short_b1:.4f}")
    print(f"Theoretical omitted-variable bias: {theoretical_bias:.4f}")
    print(f"Empirical mean short slope b1: {mean_short:.4f}")
    print(f"Empirical mean long slope b1: {mean_long1:.4f}")
    print(f"Empirical mean long slope b2: {mean_long2:.4f}")
    print(f"Empirical mean delta: {mean_delta:.4f}")
    print(f"Empirical omitted-variable bias: {empirical_bias:.4f}")


main()

Where the canon breaks: the peril of bad controls

A widespread misconception in quantitative finance asserts that adding more control variables always reduces omitted-variable bias. This rule fails catastrophically when controls are mediators (variables lying on the causal chain between \(X_1\) and \(y\)) or colliders (variables causally influenced by both \(X_1\) and an unobserved confounder). Controlling for a mediator purges the true indirect causal effect of \(X_1\). Controlling for a collider induces collider stratification bias (Berkson's fallacy), artificially creating spurious correlations between previously independent variables. Valid identification demands selecting controls based on structural exogeneity, not maximizing statistical fit.

Misconceptions

  1. Adding every available control variable to a regression always reduces parameter bias.

    Controlling for variables that are consequences of the treatment (mediators) or colliders between the treatment and unobserved errors introduces severe collider bias, worsening identification compared to the short model.

  2. Omitted-variable bias vanishes when the sample size \(n\) grows to infinity.

    Omitted-variable bias is a structural identification failure, not a finite-sample sampling artifact. As \(n \to \infty\), \(\hat\beta_1^{\mathrm{short}} \pto \beta_1 + \Gamma_{21}\beta_2 \ne \beta_1\). The estimator remains asymptotically inconsistent.

  3. If an omitted variable is uncorrelated with the outcome \(y\), it cannot cause bias.

    If \(\beta_2 = 0\), the omitted variable does not enter the true data-generating process and cannot cause bias. However, if \(x_2\) has zero raw correlation with \(y\) due to offsetting indirect channels, omitting it can still bias other coefficients in a multivariate system.

Practice problems

Mechanics

In a study of corporate executive compensation \(y\), firm performance \(x_1\) has true coefficient \(\beta_1 = 0.80\). Firm size \(x_2\) is omitted. The true effect of size is \(\beta_2 = 1.20\), and regressing size on performance yields slope \(\delta = 0.50\). Calculate the expected short-regression slope \(\E[\hat\beta_1^{\mathrm{short}}]\) and the omitted-variable bias.

Solution

The omitted-variable bias is \(\mathrm{Bias} = \beta_2 \delta = 1.20 \times 0.50 = 0.60\). The expected short-regression slope is \(\E[\hat\beta_1^{\mathrm{short}}] = \beta_1 + \mathrm{Bias} = 0.80 + 0.60 = 1.40\). The short regression overstates the true sensitivity of pay to performance by 75% because larger firms simultaneously deliver higher returns and pay larger executive salaries.

Suppose \(\beta_1 = 2.0\), \(\beta_2 = -1.5\), and the sample covariance between \(x_1\) and \(x_2\) is negative, \(\delta = -0.40\). Determine the sign and magnitude of the omitted-variable bias.

Solution

The bias is \(\mathrm{Bias} = \beta_2 \delta = (-1.5) \times (-0.40) = +0.60\). Even though both \(\beta_2\) and \(\delta\) are individually negative, their product is strictly positive. The short-regression slope will systematically overestimate \(\beta_1\) by 0.60, converging to \(\E[\hat\beta_1^{\mathrm{short}}] = 2.60\).

In a two-factor asset pricing model, excess return \(r\) is regressed on market excess return \(r_m\). The true model includes value factor \(r_{\mathrm{hml}}\) with loading \(\beta_{\mathrm{hml}} = 0.40\). If the sample regression of \(r_{\mathrm{hml}}\) on \(r_m\) yields slope \(0.15\), how much is the estimated market beta \(\hat\beta_m\) distorted?

Solution

The distortion in estimated market beta is \(\mathrm{Bias} = \beta_{\mathrm{hml}} \times \delta = 0.40 \times 0.15 = 0.06\). The single-index market model overestimates the true market exposure by 0.06 because the asset's positive value loading is partially picked up by the market factor's positive correlation with value.

Proof

Prove that \(\hat\beta_1^{\mathrm{short}}\) is an unbiased estimator of \(\beta_1\) if and only if \(X_1'X_2\beta_2 = 0\).

Solution

From Theorem 5.1, \(\E[\hat\beta_1^{\mathrm{short}} | X_1, X_2] = \beta_1 + (X_1'X_1)^{-1}X_1'X_2\beta_2\). For unbiasedness, the bias term must equal the zero vector: \((X_1'X_1)^{-1}X_1'X_2\beta_2 = 0\). Premultiplying by the non-singular matrix \(X_1'X_1\) yields \(X_1'X_2\beta_2 = 0\). Conversely, if \(X_1'X_2\beta_2 = 0\), multiplying by \((X_1'X_1)^{-1}\) gives a bias of zero. Thus \(X_1'X_2\beta_2 = 0\) is both necessary and sufficient.

Show that the variance of the short estimator is weakly smaller than the variance of the long estimator: \(\Var(\hat\beta_1^{\mathrm{short}} | X) \le \Var(\hat\beta_1^{\mathrm{long}} | X)\).

Solution

Under homoskedasticity, \(\Var(\hat\beta_1^{\mathrm{short}} | X) = \sigma^2 (X_1'X_1)^{-1}\). By the Frisch–Waugh–Lovell theorem, the long estimator has variance \(\Var(\hat\beta_1^{\mathrm{long}} | X) = \sigma^2 (X_1' M_2 X_1)^{-1}\), where \(M_2 = I - X_2(X_2'X_2)^{-1}X_2'\). Note that \(X_1'X_1 - X_1' M_2 X_1 = X_1' H_2 X_1 \ge 0\) is positive semidefinite. By the Loewner ordering for matrix inverses, \(A \ge B > 0 \implies B^{-1} \ge A^{-1}\). Therefore, \((X_1' M_2 X_1)^{-1} \ge (X_1'X_1)^{-1}\), proving that the short estimator has weakly smaller variance.

Evaluate the mean squared error trade-off between the short and long estimators: when does \(\mathrm{MSE}(\hat\beta_1^{\mathrm{short}}) < \mathrm{MSE}(\hat\beta_1^{\mathrm{long}})\)?

Solution

Mean squared error decomposes into \(\mathrm{MSE} = \mathrm{Bias}^2 + \Var\). The long estimator is unbiased, so \(\mathrm{MSE}(\hat\beta_1^{\mathrm{long}}) = \Var(\hat\beta_1^{\mathrm{long}})\). The short estimator has \(\mathrm{MSE}(\hat\beta_1^{\mathrm{short}}) = (\hat\Gamma_{21}\beta_2)^2 + \Var(\hat\beta_1^{\mathrm{short}})\). The short estimator achieves lower MSE if and only if \((\hat\Gamma_{21}\beta_2)^2 < \Var(\hat\beta_1^{\mathrm{long}}) - \Var(\hat\beta_1^{\mathrm{short}})\). This occurs when the omitted variable has a small true effect (\(\beta_2 \approx 0\)) and is highly correlated with \(X_1\), so that omitting it eliminates substantial variance inflation without incurring large bias.

Empirical

In estimating mutual fund alpha against the CAPM, omitted momentum (Carhart 1997) causes an analyst to find positive, statistically significant alpha for high-turnover growth funds. How does the OVB formula explain this finding?

Solution

High-turnover growth funds systematically hold recent winning stocks, giving them large positive momentum exposures (\(\delta > 0\)). The momentum factor has a well-documented positive risk premium (\(\beta_{\mathrm{umd}} > 0\)). Omitting the momentum factor from the CAPM regression produces positive omitted-variable bias \(\beta_{\mathrm{umd}} \times \delta > 0\), which falsely manifests as abnormal managerial alpha rather than mechanical factor exposure.

In corporate finance, regressing firm investment on Tobin's q yields a small coefficient that researchers suspect is biased by omitted unobservable managerial quality. In what direction does this bias operate?

Solution

High managerial quality increases firm investment opportunities (\(\beta_{\mathrm{qual}} > 0\)) and is simultaneously capitalized into higher market equity valuations, raising Tobin's q (\(\delta > 0\)). The omitted-variable bias is \(\beta_{\mathrm{qual}} \times \delta > 0\), causing simple OLS regressions to overestimate the true sensitivity of physical investment to market valuation signals.

Why does controlling for firm leverage when testing the effect of governance on firm value create potential collider bias if governance affects both profitability and capital structure choices?

Solution

If firm governance and unobserved operational shocks both causally influence leverage, leverage acts as a collider variable. Conditioning on leverage in a multivariate regression opens a spurious non-causal path between governance and the unobserved shocks, creating collider stratification bias that corrupts the estimated governance coefficient even if governance was originally randomly assigned.

Research

Oster (2019) develops sensitivity analysis for unobservable selection based on proportional selection \(\delta_{\mathrm{oster}}\) and maximum \(R_{\mathrm{max}}^2\). Summarize how Oster's method bounds omitted-variable bias relative to observable controls.

Solution

Oster formalizes the intuition of Altonji et al. by linking movement in the coefficient of interest \(\hat\beta\) to changes in \(R^2\) as controls are added. Under the assumption that selection on unobservables is proportional to selection on observables by a factor \(\delta_{\mathrm{oster}}\), Oster derives an identified set for \(\beta\) bounded by the hypothetical maximum \(R_{\mathrm{max}}^2\) achieved if all unobservables were observed, establishing whether an estimated effect is robust to plausible omitted confounders.

Cinelli and Hazlett (2020) introduce omitted variable bias benchmarks using partial \(R^2\) values. Explain how partial \(R^2\) of the omitted confounder with treatment and outcome bounds coefficient bias.

Solution

Cinelli and Hazlett prove that the absolute omitted variable bias can be expressed exactly as \(\mathrm{Bias} = \se(\hat\beta_1) \sqrt{\frac{R_{Y \sim Z | X}^2 R_{D \sim Z | X}^2}{1 - R_{D \sim Z | X}^2} (n - k)}\), where \(R_{Y \sim Z | X}^2\) and \(R_{D \sim Z | X}^2\) are the partial coefficients of determination of the omitted confounder \(Z\) with the outcome and treatment. This allows researchers to bound the strength an unobserved confounder must possess to overturn an empirical finance finding.

In return forecasting, Welch and Goyal (2008) show that many predictive variables fail out-of-sample. How does time-varying omitted risk premia explain this in-sample versus out-of-sample breakdown?

Solution

In-sample regressions of returns on valuation ratios omit structural regime shifts in macroeconomic risk premia and central bank policy. If the correlation between the predictor and unobserved macroeconomic shocks varies across business cycles, the omitted-variable bias term \(\hat\Gamma_{21}\beta_2\) shifts sign and magnitude over time. An in-sample OLS fit captures sample-specific omitted factor alignments that reverse out of sample, generating severe out-of-sample forecast deterioration.

Retrieval quiz

  1. What is the algebraic expression for omitted-variable bias when \(X_2\) is omitted from the regression of \(y\) on \(X_1\)?

    Options

    Theorem 5.1 derives \(\mathrm{Bias} = (X_1'X_1)^{-1}X_1'X_2\beta_2 = \hat\Gamma_{21}\beta_2\).

  2. Under what conditions is the short regression estimator \(\hat\beta_1^{\mathrm{short}}\) strictly unbiased for \(\beta_1\)?

    Options

    Bias vanishes if and only if \(X_1'X_2\beta_2 = 0\), requiring zero omitted impact (\(\beta_2 = 0\)) or zero correlation (\(X_1'X_2 = 0\)) (Problem P1).

  3. If \(\beta_1 = 1.50\), \(\beta_2 = 2.00\), and \(\delta = 0.60\), what is the expected value of the short-regression slope \(\E[\hat\beta_1^{\mathrm{short}}]\)?

    \(\E[\hat\beta_1^{\mathrm{short}}] = \beta_1 + \beta_2\delta = 1.50 + 2.00 \times 0.60 = 1.50 + 1.20 = 2.70\) (Lab 1).

  4. What is the numerical omitted-variable bias for the previous problem (\(\beta_1=1.50, \beta_2=2.00, \delta=0.60\))?

    \(\mathrm{Bias} = \beta_2\delta = 2.00 \times 0.60 = 1.20\) (Theorem 5.1).

  5. If the true effect of an omitted variable is negative (\(\beta_2 < 0\)) and its correlation with the included regressor is negative (\(\delta < 0\)), what is the direction of bias?

    Options

    The product of two negative values is positive: \(\mathrm{Bias} = \beta_2 \delta > 0\) (Remark 5.1).

  6. Does omitted-variable bias diminish to zero as sample size \(n \to \infty\)?

    Options

    OVB reflects a structural identification failure; \(\hat\beta_1^{\mathrm{short}} \pto \beta_1 + \Gamma_{21}\beta_2 \ne \beta_1\) (Theorem 5.1).

  7. How does the variance of the short estimator compare to the variance of the long estimator?

    Options

    \(\Var(\hat\beta_1^{\mathrm{short}}|X) \le \Var(\hat\beta_1^{\mathrm{long}}|X)\) because omitting correlated variables eliminates multicollinearity variance inflation (Problem P2).

  8. What is a "bad control" that should NOT be added to an econometric regression?

    Options

    Controlling for mediators or colliders opens spurious confounding channels or blocks true causal effects (Section Canon breaks).
