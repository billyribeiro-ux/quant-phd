Ordinary least squares as orthogonal projection

Linear regression decomposes an observed financial response into a systematic component spanned by explanatory factors and an orthogonal residual vector. Understanding ordinary least squares through projection geometry clarifies that the algebraic properties of OLS—fitted values, residual orthogonality, and the normal equations—depend purely on linear algebra and require zero distributional assumptions on the underlying disturbances.

The linear model and least squares criterion

Let \(y \in \R^n\) denote an \(n \times 1\) vector of observed responses, such as excess asset returns across \(n\) periods or \(n\) cross-sectional entities. Let \(X \in \R^{n \times k}\) be an \(n \times k\) design matrix whose columns represent explanatory variables (factors, signals, or characteristic controls). We assume the primary rank condition:

Assumption 1.1 (Full Column Rank Design)

The design matrix \(X \in \R^{n \times k}\) has full column rank, \(\mathrm{rank}(X) = k\), with sample size strictly exceeding the parameter dimension, \(n > k\). Consequently, the Gram matrix \(X'X\) is a symmetric, strictly positive definite \(k \times k\) matrix, invertible in \(\R^{k \times k}\).

The linear model expresses \(y\) as:

\[ y = X\beta + \varepsilon \]

where \(\beta \in \R^k\) is the unknown parameter vector and \(\varepsilon \in \R^n\) is a vector of unobserved disturbances. For any candidate coefficient vector \(b \in \R^k\), the residual vector is \(e(b) = y - Xb\). The least squares projection objective minimizes the Euclidean norm of the residual vector:

\[ S(b) = \|y - Xb\|^2 = (y - Xb)'(y - Xb) = y'y - 2b'X'y + b'X'Xb \]

Definition 1.1 (Ordinary least squares (OLS) estimator)

Under Assumption 1.1, the ordinary least squares (OLS) estimator \(\hat\beta \in \R^k\) is the unique global minimizer of the sum of squared residuals:

\[ \hat\beta = \argmin_{b \in \R^k} \|y - Xb\|^2 = (X'X)^{-1}X'y \]

Derivation 1.1 (The Normal Equations)

Because \(S(b)\) is a smooth quadratic function of \(b\), its first-order gradient condition with respect to \(b\) is:

\[ \nabla_b S(b) = -2X'y + 2X'Xb = 0 \]

Dividing by 2 yields the celebrated normal equations:

\[ X'X\hat\beta = X'y \]

The Hessian matrix is \(\nabla^2_b S(b) = 2X'X\). By Assumption 1.1, \(X\) has full column rank, ensuring \(X'X\) is a positive semidefinite matrix with strictly positive eigenvalues, hence strictly positive definite. The first-order condition therefore uniquely characterizes the global minimum.

The hat matrix and projection geometry

The fitted value vector \(\hat y \in \R^n\) is obtained by evaluating the linear predictor at \(\hat\beta\):

\[ \hat y = X\hat\beta = X(X'X)^{-1}X'y = Hy \]

where \(H = X(X'X)^{-1}X'\) is the hat matrix (so called because it puts the "hat" on \(y\)).

Theorem 1.1 (Orthogonal Projection Properties of H)

The hat matrix \(H = X(X'X)^{-1}X'\) represents the unique orthogonal projection operator mapping \(\R^n\) onto the column space \(\mathrm{col}(X)\). Specifically:

  1. Symmetry: \(H' = (X(X'X)^{-1}X')' = X((X'X)^{-1})'X' = X(X'X)^{-1}X' = H\).
  2. Idempotence: \(H^2 = (X(X'X)^{-1}X')(X(X'X)^{-1}X') = X(X'X)^{-1}(X'X)(X'X)^{-1}X' = H\).
  3. Rank and trace: \(\mathrm{rank}(H) = \tr(H) = \tr(X(X'X)^{-1}X') = \tr((X'X)^{-1}X'X) = \tr(I_k) = k\).

Theorem 1.2 (Residual Orthogonality and Annihilator Matrix)

The OLS residual vector \(e = y - \hat y = (I_n - H)y = My\), where \(M = I_n - H\) is the annihilator matrix. The residual vector satisfies:

  1. Orthogonality to regressors: \(X'e = X'(I_n - H)y = (X' - X'X(X'X)^{-1}X')y = (X' - X')y = 0\).
  2. Orthogonality to fitted values: \(\hat y'e = (Hy)'(My) = y'H'My = y'H(I_n - H)y = y'(H - H^2)y = 0\).
  3. Pythagorean decomposition: \(\|y\|^2 = \|\hat y + e\|^2 = \|\hat y\|^2 + \|e\|^2\).

Remark 1.1 (Implications of an Intercept)

When the first column of \(X\) is the constant vector \(\mathbf{1} = (1, 1, \dots, 1)'\), residual orthogonality \(X'e = 0\) immediately implies that the sum of the OLS residuals is identically zero:

\[ \mathbf{1}'e = \sum_{i=1}^n e_i = 0 \implies \bar e = 0 \]

Consequently, the sample mean of the fitted values equals the sample mean of the actual observations: \(\bar{\hat y} = \bar y\). If a regression is estimated without an intercept, \(\sum e_i \ne 0\) in general.

Lab 1 · Exact OLS normal equations and residual orthogonality

Hypothesis: For a bivariate regression design with integer values, the OLS normal equations and residual inner products \(X'e\) evaluated via exact rational arithmetic (fractions.Fraction) equal zero identically without floating-point error, and the trace of the hat matrix equals the column rank \(k = 2\).

"""Lab S2-L01-1: Exact OLS normal equations and residual orthogonality.

Evaluates OLS projection, normal equations, and residual orthogonality
using exact rational arithmetic (fractions.Fraction). Standard library only.
"""

from __future__ import annotations

from fractions import Fraction


def solve_2x2(
    a: Fraction, b: Fraction, c: Fraction, d: Fraction, y1: Fraction, y2: Fraction
) -> tuple[Fraction, Fraction]:
    """Solve 2x2 linear system [[a, b], [c, d]] [b0, b1]' = [y1, y2]' in exact rational arithmetic."""
    det = a * d - b * c
    if det == 0:
        raise ValueError("Singular matrix")
    x1 = (d * y1 - b * y2) / det
    x2 = (-c * y1 + a * y2) / det
    return x1, x2


def main() -> None:
    # Seeded integer design: n = 5 observations, k = 2 (constant intercept and regressor x)
    x = [Fraction(1), Fraction(2), Fraction(3), Fraction(4), Fraction(5)]
    y = [Fraction(2), Fraction(3), Fraction(5), Fraction(4), Fraction(6)]
    n = Fraction(len(x))

    # Compute inner products for normal equations
    s_x = sum(x, Fraction(0))
    s_y = sum(y, Fraction(0))
    s_xx = sum((xi * xi for xi in x), Fraction(0))
    s_xy = sum((xi * yi for xi, yi in zip(x, y, strict=True)), Fraction(0))

    # Normal equations:
    # [[n, s_x], [s_x, s_xx]] [b0, b1]' = [s_y, s_xy]'
    b0, b1 = solve_2x2(n, s_x, s_x, s_xx, s_y, s_xy)

    # Fitted values and residuals
    y_hat = [b0 + b1 * xi for xi in x]
    e = [yi - yhat_i for yi, yhat_i in zip(y, y_hat, strict=True)]

    # Orthogonality checks: X'e must be identically zero
    orthog_const = sum(e, Fraction(0))
    orthog_x = sum((xi * ei for xi, ei in zip(x, e, strict=True)), Fraction(0))

    # Hat matrix diagonal elements: h_ii = x_i' (X'X)^{-1} x_i
    det = n * s_xx - s_x * s_x
    inv_00 = s_xx / det
    inv_01 = -s_x / det
    inv_11 = n / det

    h_diag = [inv_00 + Fraction(2) * inv_01 * xi + inv_11 * xi * xi for xi in x]
    trace_h = sum(h_diag, Fraction(0))

    print(f"OLS intercept b0: {b0} ({float(b0):.4f})")
    print(f"OLS slope b1: {b1} ({float(b1):.4f})")
    print(f"Residual orthogonality to 1 (sum e): {orthog_const}")
    print(f"Residual orthogonality to x (sum x*e): {orthog_x}")
    print(f"Trace of hat matrix H: {trace_h} (k = 2)")
    print(f"Residuals: {[str(ei) for ei in e]}")


main()

OLS slope b1: 9/10 (0.9000)
Residual orthogonality to 1 (sum e): 0
Residual orthogonality to x (sum x*e): 0
Trace of hat matrix H: 2 (k = 2)
Residuals: ['-1/5', '-1/10', '1', '-9/10', '1/5']

Interpretation: The exact zero sum of residuals and zero inner product with the regressor confirm that residual orthogonality is an algebraic identity produced by the normal equations, independent of sample size or error distributions.

Where the canon breaks

The geometric elegance of OLS requires Assumption 1.1 (\(\mathrm{rank}(X) = k\)). When regressors are exactly collinear—such as including both individual asset weights and a cash weight that sum to 1 alongside an intercept—\(X'X\) is singular and the normal equations admit infinitely many solutions. In such cases, the projection \(\hat y = Hy\) remains unique, but individual parameter coefficients \(\beta_j\) are non-identified. Furthermore, residual orthogonality \(X'e = 0\) does not imply statistical independence between \(X\) and \(\varepsilon\): sample orthogonality is enforced by construction even when the true data-generating process suffers from non-linearities, endogeneity, or omitted variables.

Misconceptions

  1. OLS estimation requires normally distributed disturbance terms to be valid.

    Ordinary least squares is an algebraic projection method minimizing the squared Euclidean distance in \(\R^n\). The normal equations \(X'X\hat\beta = X'y\), residual orthogonality \(X'e = 0\), and the hat matrix \(H\) hold identically for any vector \(y\) and matrix \(X\), regardless of whether disturbances are Gaussian, heavy-tailed, or deterministic.

  2. The sum of OLS residuals always equals zero in any linear regression.

    The residuals sum to zero if and only if the constant vector \(\mathbf{1}\) lies in the column space of \(X\). In regressions without an explicit intercept, or regressions where regressors do not span the constant vector, the residuals generally do not sum to zero.

  3. The hat matrix diagonal entries \(h_{ii}\) can take arbitrary positive values.

    Because \(H\) is an orthogonal projection matrix, its eigenvalues are either 0 or 1. For each diagonal element, \(h_{ii} = \sum_{j=1}^n H_{ij}^2 = h_{ii}^2 + \sum_{j \ne i} H_{ij}^2 \ge h_{ii}^2\), which restricts \(0 \le h_{ii} \le 1\). In a regression with an intercept, \(h_{ii} \ge 1/n\), reflecting the leverage of each observation.

Practice problems

Mechanics

Consider the univariate regression without intercept \(y_i = \beta x_i + \varepsilon_i\). For data vectors \(x = (1, 2, 3)'\) and \(y = (2, 3, 5)'\), compute the OLS slope \(\hat\beta\) and the residual vector \(e\). Verify that \(x'e = 0\).

Solution

The normal equation is \(x'x \hat\beta = x'y\). Here \(x'x = 1^2 + 2^2 + 3^2 = 14\). The cross-product is \(x'y = 1(2) + 2(3) + 3(5) = 2 + 6 + 15 = 23\). Thus, \(\hat\beta = 23/14 \approx 1.6429\). The fitted values are \(\hat y = (23/14, 46/14, 69/14)'\). The residuals are \(e = y - \hat y = (28/14 - 23/14, 42/14 - 46/14, 70/14 - 69/14)' = (5/14, -4/14, 1/14)'\). Evaluating the inner product: \(x'e = 1(5/14) + 2(-4/14) + 3(1/14) = (5 - 8 + 3)/14 = 0/14 = 0\). Orthogonality holds exactly.

Calculate the trace of the annihilator matrix \(M = I_n - X(X'X)^{-1}X'\) for a sample of \(n = 100\) observations and \(k = 5\) linearly independent regressors.

Solution

By linearity of the trace operator, \(\tr(M) = \tr(I_n - H) = \tr(I_n) - \tr(H)\). The trace of the \(n \times n\) identity matrix is \(\tr(I_n) = n = 100\). The trace of the hat matrix is \(\tr(X(X'X)^{-1}X') = \tr((X'X)^{-1}X'X) = \tr(I_k) = k = 5\) by the cyclic property of the trace. Therefore, \(\tr(M) = 100 - 5 = 95\). The trace corresponds to the dimension of the orthogonal subspace onto which \(M\) projects.

Show that if an observation \(i\) has leverage \(h_{ii} = 1\), the corresponding OLS residual \(e_i\) must be zero.

Solution

The annihilator matrix \(M = I - H\) has diagonal elements \(m_{ii} = 1 - h_{ii}\). If \(h_{ii} = 1\), then \(m_{ii} = 0\). Because \(M\) is symmetric and idempotent, \(m_{ii} = \sum_{j=1}^n M_{ij}^2 = M_{ii}^2 + \sum_{j \ne i} M_{ij}^2 = 0\). Since each squared term is non-negative, \(M_{ij} = 0\) for all \(j = 1, \dots, n\). The \(i\)-th residual is \(e_i = \sum_{j=1}^n M_{ij} y_j = 0\). The regression line fits observation \(i\) perfectly.

Proof

Prove that the hat matrix \(H = X(X'X)^{-1}X'\) is idempotent, \(H^2 = H\), and symmetric, \(H' = H\).

Solution

To prove symmetry, take the transpose: \(H' = (X(X'X)^{-1}X')' = (X')' ((X'X)^{-1})' X' = X ((X'X)')^{-1} X'\). Because \(X'X\) is symmetric, \((X'X)' = X'X\), which implies \(((X'X)')^{-1} = (X'X)^{-1}\). Hence \(H' = H\). To prove idempotence, multiply \(H\) by itself: \(H^2 = (X(X'X)^{-1}X')(X(X'X)^{-1}X') = X(X'X)^{-1}(X'X)(X'X)^{-1}X'\). Since \((X'X)^{-1}(X'X) = I_k\), this reduces directly to \(X I_k (X'X)^{-1}X' = X(X'X)^{-1}X' = H\). Thus \(H\) is an orthogonal projection matrix.

Prove the Pythagorean decomposition \(\|y\|^2 = \|\hat y\|^2 + \|e\|^2\) for OLS regression.

Solution

Express \(y\) as the sum of its orthogonal components: \(y = \hat y + e\). Compute the squared Euclidean norm: \(\|y\|^2 = (\hat y + e)'(\hat y + e) = \hat y'\hat y + 2\hat y'e + e'e = \|\hat y\|^2 + 2\hat y'e + \|e\|^2\). From Theorem 1.2, \(\hat y'e = (Hy)'(My) = y'H(I - H)y = y'(H - H^2)y\). Because \(H\) is idempotent (\(H^2 = H\)), \(H - H^2 = 0\), establishing \(\hat y'e = 0\). Substituting this into the expansion yields \(\|y\|^2 = \|\hat y\|^2 + \|e\|^2\).

Prove that the eigenvalues of any symmetric idempotent matrix \(P\) are strictly in \(\{0, 1\}\).

Solution

Let \(\lambda\) be an eigenvalue of \(P\) with corresponding non-zero eigenvector \(v \ne 0\), so \(Pv = \lambda v\). Premultiplying by \(P\) gives \(P^2 v = P(\lambda v) = \lambda Pv = \lambda^2 v\). Since \(P\) is idempotent, \(P^2 = P\), which implies \(P^2 v = Pv = \lambda v\). Equating the expressions yields \(\lambda^2 v = \lambda v \implies (\lambda^2 - \lambda)v = 0\). Because \(v \ne 0\), we must have \(\lambda^2 - \lambda = 0\), whose only real roots are \(\lambda = 0\) and \(\lambda = 1\).

Empirical

In a factor regression of equity returns on market and size factors with \(n = 60\) monthly observations and an intercept, an analyst finds that the residuals sum to \(0.0042\). Explain what this indicates about the estimation.

Solution

Mathematically, when an intercept is included, \(\mathbf{1}'e = 0\) holds identically. A non-zero residual sum of \(0.0042\) indicates either that the intercept was omitted from the regression specification, that observation weights were applied without adjusting the constant, or that numerical optimization was terminated prematurely without solving the normal equations to convergence.

A risk model estimates single-index market betas for \(n = 252\) trading days. The maximum hat matrix diagonal entry is \(\max_i h_{ii} = 0.42\). What does this imply about the influence of that specific trading day?

Solution

The average leverage across all observations is \(\bar h = k/n = 2/252 \approx 0.0079\). A leverage value of \(h_{ii} = 0.42\) exceeds the average by more than a factor of 50. This indicates an extreme outlier in market return (such as a major market crash or volatility shock) that exerts disproportionate influence on the estimated beta coefficient.

Explain why regressing asset returns on two collinear macroeconomic factors results in standard OLS software reporting an error or dropping a variable.

Solution

When two factors are perfectly collinear, \(\mathrm{rank}(X) < k\), causing the Gram matrix \(X'X\) to have a determinant of zero. Inversion of \(X'X\) is mathematically impossible because the normal equations have infinitely many solutions. OLS software must either apply a generalized pseudoinverse or drop the redundant column to restore full column rank.

Research

In cross-sectional asset pricing regressions (Fama–MacBeth first pass), why is it critical that individual stock returns are regressed on a constant alongside factor betas?

Solution

Including the constant ensures that pricing errors (alphas) have zero sample mean across time for each asset when tested under unconditional expectations. Omitting the intercept forces the regression line through the origin, which biases the estimated factor loadings whenever the true pricing alpha is non-zero, distorting subsequent cross-sectional risk premia tests.

Discuss how high-leverage observations in financial time series affect the robustness of OLS relative to least absolute deviations (LAD) regression.

Solution

OLS minimizes the sum of squared residuals, which causes observations with large regressor values (high leverage \(h_{ii}\)) to pull the regression plane toward themselves quadratically. In contrast, LAD minimizes the \(\ell_1\) norm of residuals, providing robustness against vertical outliers in \(y\), although it remains sensitive to bad leverage points in regressor space unless robust weighting is incorporated.

Evaluate the geometric interpretation of regularized regression (ridge regression) in terms of modifying the hat matrix projection.

Solution

Ridge regression solves \(\min \|y - Xb\|^2 + \lambda \|b\|^2\), yielding \(\hat\beta_{\mathrm{ridge}} = (X'X + \lambda I_k)^{-1}X'y\). The corresponding hat matrix \(H_\lambda = X(X'X + \lambda I_k)^{-1}X'\) is symmetric but no longer idempotent for \(\lambda > 0\) because \(H_\lambda^2 \ne H_\lambda\). Rather than an orthogonal projection onto \(\mathrm{col}(X)\), ridge performs a shrinkage operation that contracts the projection along the singular vectors corresponding to small singular values of \(X\).

Retrieval quiz

  1. What algebraic condition guarantees the unique existence of the OLS estimator \(\hat\beta = (X'X)^{-1}X'y\)?

    Options

    When \(X\) has full column rank, \(X'X\) is strictly positive definite and invertible (Assumption 1.1).

  2. What is the trace of the hat matrix \(H = X(X'X)^{-1}X'\) when \(X\) is \(n \times k\) of rank \(k\)?

    Options

    \(\tr(H) = \tr(X(X'X)^{-1}X') = \tr((X'X)^{-1}X'X) = \tr(I_k) = k\) (Theorem 1.1).

  3. If a regression model contains a constant intercept term, what is the value of the residual sample mean \(\bar e\)?

    Options

    Orthogonality with the intercept column requires \(\mathbf{1}'e = \sum e_i = 0\), so \(\bar e = 0\) exactly (Remark 1.1).

  4. What are the possible eigenvalues of any orthogonal projection matrix such as \(H\)?

    Options

    Idempotence \(H^2 = H\) implies \(\lambda^2 = \lambda\), which has roots \(\lambda \in \{0, 1\}\) (Problem P3).

  5. In a regression with \(n = 50\) and \(k = 10\), what is the rank of the annihilator matrix \(M = I_n - H\)? Enter the trace of \(H\) instead: what is \(\tr(H)\)?

    \(\tr(H) = k = 10\) (Theorem 1.1).

  6. For the same regression with \(n = 50\) and \(k = 10\), what is the rank and trace of the annihilator matrix \(M = I_n - H\)?

    \(\tr(M) = n - k = 50 - 10 = 40\) (Problem M2).

  7. Which matrix operator projects an arbitrary vector \(y \in \R^n\) onto the orthogonal complement of the column space of \(X\)?

    Options

    \(M = I - H\) projects \(y\) onto \(\mathrm{col}(X)^\perp\), producing the residual vector \(e = My\) (Theorem 1.2).

  8. Does OLS residual orthogonality \(X'e = 0\) guarantee that the regressor \(X\) is uncorrelated with the true disturbance \(\varepsilon\)?

    Options

    \(X'e = 0\) is an algebraic necessity from the normal equations regardless of endogeneity in \(\varepsilon\) (Section Canon breaks).
