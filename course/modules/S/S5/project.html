Rung 1 · Worked Example

In this solved example, we simulate a monthly panel of \(N = 15\) test assets over \(T = 140\) months with \(K = 1\) factor. The first \(T_1 = 80\) months serve as the in-sample training window for estimating factor loadings \(\hat{\beta}_i\). The remaining \(T_2 = 60\) months serve as the out-of-sample test window for running monthly cross-sectional regressions.

Lab 1 · Solved Two-Pass Pipeline Execution

Executing the two-pass regression yields monthly slope estimates whose time-series average equals the estimated risk premium, and the Shanken multiplier c is strictly greater than 1.

"""Lab S5-project-1: Rung 1 worked example of two-pass asset pricing with Shanken correction.

SIMULATED: runs a fully solved, annotated execution of the two-pass Fama-MacBeth pipeline
on a seeded synthetic panel, printing factor loadings, monthly premia slopes, naive standard errors,
the Shanken errors-in-variables multiplier, and corrected inference.
"""

from __future__ import annotations

import numpy as np


def main() -> None:
    seed = 42
    rng = np.random.default_rng(seed)
    t_months = 140
    n_assets = 15
    k_factors = 1
    train = 80
    t2 = t_months - train

    # Generate synthetic factors and returns
    f_mean = 0.008
    f_sd = 0.040
    factors = rng.normal(f_mean, f_sd, size=(t_months, k_factors))
    betas_true = rng.uniform(0.6, 1.4, size=(n_assets, k_factors))
    resid_sd = rng.uniform(0.02, 0.05, size=n_assets)

    excess = np.empty((t_months, n_assets))
    for t in range(t_months):
        e_t = rng.normal(0.0, resid_sd, size=n_assets)
        excess[t] = (betas_true @ factors[t]).ravel() + e_t

    # Step 1: First-pass time-series regression on first train months
    x_ts = np.column_stack([np.ones(train), factors[:train]])
    betas_est = np.empty((n_assets, k_factors + 1))
    for i in range(n_assets):
        betas_est[i] = np.linalg.solve(x_ts.T @ x_ts, x_ts.T @ excess[:train, i])

    # Step 2: Second-pass cross-sectional regressions on test months
    z_cs = np.column_stack([np.ones(n_assets), betas_est[:, 1:]])
    slopes = np.empty((t2, k_factors + 1))
    for i in range(t2):
        month = train + i
        slopes[i] = np.linalg.solve(z_cs.T @ z_cs, z_cs.T @ excess[month])

    premia = np.mean(slopes, axis=0)
    naive_se = np.std(slopes, axis=0, ddof=1) / np.sqrt(t2)

    # Step 3: Shanken errors-in-variables correction
    factor_cov = np.cov(factors[train:], rowvar=False, ddof=1).reshape((k_factors, k_factors))
    lambda_f = premia[1:].reshape((k_factors, 1))
    q = float((lambda_f.T @ np.linalg.solve(factor_cov, lambda_f)).item())
    c = 1.0 + q
    shanken_se = naive_se * np.sqrt(c)

    t_naive = premia[1] / naive_se[1]
    t_shanken = premia[1] / shanken_se[1]

    print("Rung 1 Worked Example: Two-Pass Asset Pricing")
    print(f"  Sample size T: {t_months}, Assets N: {n_assets}, Training T1: {train}, Test T2: {t2} (seed {seed})")
    print(f"  First-pass mean factor loading beta: {np.mean(betas_est[:, 1]):.4f}")
    print(f"  Estimated factor risk premium: {premia[1]:.6f}")
    print(f"  Shanken correction factor c: {c:.4f} (Multiplier sqrt(c): {np.sqrt(c):.4f})")
    print(f"  Naive Fama-MacBeth SE: {naive_se[1]:.6f} (t-statistic: {t_naive:.3f})")
    print(f"  Shanken-corrected SE:  {shanken_se[1]:.6f} (t-statistic: {t_shanken:.3f})")
    print(f"  Standard error inflation: {((np.sqrt(c) - 1.0) * 100.0):.2f}%")


main()

"""Lab S5-project-3: Rung 3 independent verification check.

SIMULATED: runs the two-pass Fama-MacBeth pipeline with Shanken correction
on the public demonstration instance (seed 0), printing the replication table
and verifying mathematical invariants.
"""

from __future__ import annotations

import numpy as np


def main() -> None:
    # Public demonstration parameters (seed 0)
    seed = 0
    rng = np.random.default_rng(seed)
    t_months = 130
    n_assets = 14
    k_factors = 1
    train = int(t_months * 0.60)  # 78
    t2 = t_months - train  # 52

    # Factor dynamics
    sigma_f = np.array([[0.0025]])
    mu_f = np.array([0.008])
    factors = rng.multivariate_normal(mu_f, sigma_f, size=t_months)

    true_loadings = rng.uniform(0.5, 1.5, size=(n_assets, k_factors))
    true_alphas = rng.normal(0.0, 0.001, size=n_assets)
    resid_sd = rng.uniform(0.02, 0.05, size=n_assets)

    excess = np.empty((t_months, n_assets), dtype=np.float64)
    for t in range(t_months):
        e_t = rng.normal(0.0, resid_sd, size=n_assets)
        excess[t] = true_alphas + true_loadings @ factors[t] + e_t

    # Step 1: First-pass OLS
    x_ts = np.column_stack([np.ones(train), factors[:train]])
    x_inv = np.linalg.inv(x_ts.T @ x_ts)
    betas = np.empty((n_assets, k_factors + 1))
    for i in range(n_assets):
        betas[i] = x_inv @ (x_ts.T @ excess[:train, i])

    # Step 2: Second-pass cross-sectional OLS
    z_cs = np.column_stack([np.ones(n_assets), betas[:, 1:]])
    z_inv = np.linalg.inv(z_cs.T @ z_cs)
    slopes = np.empty((t2, k_factors + 1))
    for i in range(t2):
        slopes[i] = z_inv @ (z_cs.T @ excess[train + i])

    premia = np.mean(slopes, axis=0)
    naive_se = np.std(slopes, axis=0, ddof=1) / np.sqrt(t2)

    # Shanken correction
    factor_cov = np.cov(factors[train:], rowvar=False, ddof=1).reshape((k_factors, k_factors))
    lambda_f = premia[1:].reshape((k_factors, 1))
    q = float((lambda_f.T @ np.linalg.solve(factor_cov, lambda_f)).item())
    c = 1.0 + q
    shanken_se = naive_se * np.sqrt(c)

    # Invariant checks
    assert premia.shape == (k_factors + 1,), "premia dimension mismatch"
    assert np.all(shanken_se >= naive_se), "Shanken SE must be >= naive SE"
    assert c >= 1.0, "Shanken correction multiplier c must be >= 1.0"

    print("Rung 3 Independent Verification Table (Seed 0)")
    print(f"  Configuration: T={t_months}, N={n_assets}, K={k_factors}, T1={train}, T2={t2}")
    print("  Parameter | Estimated Premium | Naive SE    | Shanken SE  | Ratio Shanken/Naive")
    print("  " + "-" * 75)
    names = ["Zero-Beta Intercept", "Factor 1 Premium"]
    for idx, name in enumerate(names):
        ratio = shanken_se[idx] / naive_se[idx]
        p_str = f"{premia[idx]:+.6f}"
        nse_str = f"{naive_se[idx]:.6f}"
        sse_str = f"{shanken_se[idx]:.6f}"
        print(f"  {name:<20} | {p_str}        | {nse_str}   | {sse_str}   | {ratio:.4f}")
    print(f"  Shanken multiplier c: {c:.6f}")
    print("  Status: All mathematical invariants satisfied.")

Exemplar A (Level 4: Exemplary)

Replication Note: Errors-in-Variables Corrections in Two-Pass Cross-Sectional Pricing

Author: Doctoral Quantitative Researcher
Date: October 2026
Status: SIMULATED Research Calibration (Seed 143)

1. Econometric Framework and Two-Pass Methodology

In two-pass cross-sectional asset pricing tests (Fama & MacBeth 1973), asset excess returns \(R_{it}\) for \(i = 1, \dots, N\) are regressed on candidate factors \(f_t\) over an initial training window \(t = 1, \dots, T_1\) to estimate factor loadings \(\hat{\beta}_i\). In the second pass, for each out-of-sample month \(t = T_1 + 1, \dots, T\), a cross-sectional ordinary least squares regression of asset returns on estimated loadings yields monthly premia slopes \(\hat{\lambda}_t = (\hat{Z}^\top \hat{Z})^{-1} \hat{Z}^\top R_t\), where \(\hat{Z} = [\mathbf{1}_N, \hat{\beta}]\).

2. Measurement Error and the Shanken Inflation Factor

Because \(\hat{\beta}_i = \beta_i + v_i\), the second-pass regressor matrix contains measurement error. Under classical assumptions (A6: i.i.d. factor returns with covariance \(\Sigma_f\), homoskedastic idiosyncratic errors uncorrelated with factors, and constant loadings), Shanken (1992) proved that the asymptotic variance of the sample mean premium \(\bar{\lambda}\) is scaled by \(c = 1 + \lambda_f^\top \Sigma_f^{-1} \lambda_f\). When stacked into a Generalized Method of Moments system (Hansen 1982), the sandwich asymptotic covariance matrix identically reproduces this correction factor.

3. Empirical Replication Results (Seed 143)

We evaluate a simulated panel of \(N = 20\) assets over \(T = 140\) monthly periods (\(T_1 = 80, T_2 = 60\)) with \(K = 1\) factor. The factor sample mean is \(\bar{f} = 0.0080\) with variance \(\hat{\Sigma}_f = 0.001964\). Unrounded calculations display the following results:

4. Structural Inference Reversal and Theoretical Caveats

Under naive Fama–MacBeth standard errors, Factor 1 is judged statistically significant at the 5% level (\(t = 1.973 > 1.960\)). However, because the factor carries a positive Sharpe ratio (\(\SR_f^2 = 0.0568\)), the Shanken multiplier is \(c = 1.0568\) (standard error inflation of 2.80%). Adjusting for loading estimation uncertainty deflates the test statistic to \(t = 1.919 \le 1.960\), overturning the finding of priced factor risk. This reversal demonstrates the critical necessity of errors-in-variables corrections in empirical finance. We note that Shanken's asymptotic derivation assumes stationary loadings and homoskedastic errors; under conditional heteroskedasticity, full two-step GMM weighting or Newey–West corrections are required.

Exemplar B (Level 2: Developing)

Project Memo: Fama–MacBeth and Shanken Analysis

We estimated the Fama–MacBeth regression on the generated asset returns. In the first pass we ran regressions of returns on factors to get betas. In the second pass we regressed each month on the betas to get the risk premia. The naive standard error is the standard deviation divided by the square root of time.

Then we calculated Shanken's formula using the factor covariance matrix. Shanken's standard error is bigger than the naive standard error because the betas are estimated with noise. For our seed, the factor premium had a t-stat of about 1.97 with naive standard errors, but when we applied Shanken it dropped to 1.92, so it became not significant.

The code matches the tests, but the data is simulated and in real life returns might have fat tails or time-varying betas that make the formula different.
