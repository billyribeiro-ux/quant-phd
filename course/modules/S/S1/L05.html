Type I and Type II Errors, and Power

  • Uses: hypothesis test (L04), and p-value (L04).
  • Introduces: type I error, type II error, and statistical power.

  • DMarket lore

Every trading decision hinges on two asymmetric risks: backing an unviable strategy due to random luck, or discarding a genuine money-maker due to finite-sample noise. Classical hypothesis testing quantifies these mistakes through Type I error and Type II error. The probability of successfully detecting an authentic edge is statistical power. Without rigorous power analysis, quantitative researchers routinely conduct underpowered experiments that waste years on noise or misattribute true edge to unluckiness.

1Decision errors in statistical testing

Consider a hypothesis testing problem with parameter space \(\Theta\) partitioned into null hypothesis \(H_0: \theta \in \Theta_0\) and alternative hypothesis \(H_1: \theta \in \Theta_1 = \Theta \setminus \Theta_0\). Given an observed sample \(X = (X_1, \dots, X_n) \in \mathcal{X}\), a test decides between two terminal actions: reject \(H_0\) (conclude \(\theta \in \Theta_1\)) or fail to reject \(H_0\) (withhold judgment or retain \(\theta \in \Theta_0\)).

Because the sample is random, any fixed decision rule partitions the state space into four distinct outcomes, two of which represent correct inferences and two of which represent costly inferential errors.

Definition 1.1 (type I error and type II error)

Let a test have critical rejection region \(R \subset \mathcal{X}\):

  • A type I error (false positive) occurs when the test rejects \(H_0\) when \(H_0\) is true. For a specific parameter value \(\theta \in \Theta_0\), the probability of committing a Type I error is: \[ \alpha(\theta) = \Prob_\theta(X \in R) \] The size (or significance level) of the test is the worst-case Type I error probability: \(\alpha = \sup_{\theta \in \Theta_0} \alpha(\theta)\).
  • A type II error (false negative) occurs when the test fails to reject \(H_0\) when \(H_1\) is true (the null is false). For a specific parameter value \(\theta \in \Theta_1\), the probability of committing a Type II error is: \[ \beta(\theta) = \Prob_\theta(X \notin R) = 1 - \Prob_\theta(X \in R) \]
Table 1.1: Decision matrix in quantitative hypothesis testing
Truth \ Decision Fail to reject \(H_0\) (\(X \notin R\)) Reject \(H_0\) (\(X \in R\))
\(H_0\) is true (\(\theta \in \Theta_0\)) Correct retention (Probability: \(1 - \alpha(\theta)\)) Type I error (Probability: \(\alpha(\theta)\))
\(H_1\) is true (\(\theta \in \Theta_1\)) Type II error (Probability: \(\beta(\theta)\)) Correct rejection / Power (Probability: \(1 - \beta(\theta)\))

2The power function

Definition 2.1 (statistical power and power function)

The power function \(\pi: \Theta \to [0, 1]\) of a test with critical region \(R\) is the probability of rejecting the null hypothesis as a function of the parameter \(\theta\): \[ \pi(\theta) = \Prob_\theta(X \in R) \] When evaluated at an alternative parameter value \(\theta_1 \in \Theta_1\), the quantity \(\pi(\theta_1) = 1 - \beta(\theta_1)\) is the statistical power of the test against that alternative.

Notice the unification provided by the power function \(\pi(\theta)\):

  • For any null state \(\theta \in \Theta_0\), \(\pi(\theta) = \alpha(\theta)\) measures the Type I error probability.
  • For any alternative state \(\theta_1 \in \Theta_1\), \(\pi(\theta_1) = 1 - \beta(\theta_1)\) measures the statistical power, while \(1 - \pi(\theta_1) = \beta(\theta_1)\) is the Type II error probability.
Proposition 2.2 (power monotonicity in exponential families)

Assumptions:
(A1) The sample \(X\) has distribution in a one-parameter exponential family with monotone likelihood ratio in test statistic \(T(X)\).
(A2) The critical region has the form \(R = \{x : T(x) \ge c\}\) for a fixed critical threshold \(c\).
Statement:
The power function \(\pi(\theta) = \Prob_\theta(T(X) \ge c)\) is strictly increasing in \(\theta\).

Proof

By the monotone likelihood ratio property, for any \(\theta' < \theta''\), the likelihood ratio \(f(x; \theta'')/f(x; \theta')\) is a non-decreasing function of \(T(x)\). By Karlin–Rubin stochastic ordering (see Casella & Berger ), the family of distributions is stochastically increasing in \(\theta\). Consequently, the tail probability \(\Prob_\theta(T(X) \ge c)\) is strictly increasing in \(\theta\).

3The fundamental error trade-off

In any statistical experiment with a fixed sample size \(n\), there is an inescapable tension between Type I and Type II errors. If a quant attempts to drive the Type I error \(\alpha\) toward zero by demanding an extreme critical threshold \(c\), the acceptance region expands. Consequently, the test fails to reject under mild alternatives, driving the Type II error probability \(\beta(\theta_1)\) toward 1 and reducing power \(\pi(\theta_1)\) toward 0.

Proposition 3.1 (error trade-off for continuous test statistics)

Assumptions:
(A1) Let \(T(X)\) have continuous and strictly increasing CDF \(F_0\) under simple null \(H_0\) and CDF \(F_1\) under simple alternative \(H_1\).
(A2) The rejection region is \(R(c) = \{x : T(x) \ge c\}\).
Statement:
As the critical threshold \(c\) increases: \[ \frac{d\alpha}{dc} = -f_0(c) < 0 \quad \text{and} \quad \frac{d\beta}{dc} = f_1(c) > 0 \] At fixed sample size \(n\), reducing Type I error strictly increases Type II error.

Proof

By definition, \(\alpha(c) = \Prob_{H_0}(T \ge c) = 1 - F_0(c)\), and \(\beta(c) = \Prob_{H_1}(T < c) = F_1(c)\). Differentiating both with respect to \(c\) yields: \[ \frac{d\alpha}{dc} = -F_0'(c) = -f_0(c) < 0 \] \[ \frac{d\beta}{dc} = F_1'(c) = f_1(c) > 0 \] Since \(f_0(c) > 0\) and \(f_1(c) > 0\) everywhere on the support, any choice of \(c\) that decreases \(\alpha\) simultaneously increases \(\beta\).

The only mechanism to simultaneously reduce both Type I error \(\alpha\) and Type II error \(\beta\) is to increase the sample size \(n\). As \(n\) grows, the variance of the test statistic shrinks at rate \(\mathcal{O}(1/n)\), separating the distributions of \(T(X)\) under \(H_0\) and \(H_1\).

4Exact power analysis: the binomial case

Example 4.1 (exact power calculation for hit rate)

Continuing the trade signal problem from Lesson 4, we evaluate \(n = 20\) independent binary trading outcomes. We test \(H_0: p \le 1/2\) against \(H_1: p > 1/2\). Using the critical rejection rule \(R = \{k : k \ge 15\}\) found in Example 1.3 of Lesson 4:

  • Under \(H_0\) at boundary \(p = 0.50\), the Type I error is: \[ \alpha = \sum_{k=15}^{20} \binom{20}{k}\left(\frac{1}{2}\right)^{20} = \frac{5425}{262144} \approx 0.020695 \] and the probability of retaining \(H_0\) is \(\beta(0.50) = 1 - 0.020695 = 0.979305\).
  • Under alternative \(p = 0.60\), the power is: \[ \pi(0.60) = \sum_{k=15}^{20} \binom{20}{k}(0.60)^k (0.40)^{20-k} = \frac{11978051445297}{95367431640625} \approx 0.125599 \] The Type II error is \(\beta(0.60) = 1 - \pi(0.60) \approx 0.874401\). In \(87.4\%\) of samples of 20 trades, a genuine \(60\%\) hit-rate strategy will fail to reach statistical significance.
  • Under alternative \(p = 0.70\), the power rises to: \[ \pi(0.70) = \frac{10409270736187034593}{25000000000000000000} \approx 0.416371 \] The Type II error is \(\beta(0.70) \approx 0.583629\).
  • Under alternative \(p = 0.80\), the power reaches: \[ \pi(0.80) = \frac{76695231004672}{95367431640625} \approx 0.804208 \] with Type II error \(\beta(0.80) \approx 0.195792\).
  • Under alternative \(p = 0.90\), the power reaches: \[ \pi(0.90) = \frac{24718671645887274993}{25000000000000000000} \approx 0.988747 \] with Type II error \(\beta(0.90) \approx 0.011253\).

This illustrates the danger of underpowered tests: a sample of size \(n = 20\) has only \(12.6\%\) power against a realistic \(60\%\) win-rate edge, meaning nearly 7 out of 8 profitable strategies would be mistakenly discarded as noise.

Lab 1 · Exact binomial statistical power curve and Type I / Type II error trade-off

Hypothesis: For \(n = 20\) trials with cutoff \(K \ge 15\), exact power \(\pi(p)\) evaluated in rational arithmetic is \(5425/262144 \approx 0.020695\) at \(p = 0.50\), \(11978051445297/95367431640625 \approx 0.125599\) at \(p = 0.60\), \(\approx 0.416371\) at \(p = 0.70\), \(\approx 0.804208\) at \(p = 0.80\), and \(\approx 0.988747\) at \(p = 0.90\). The Type II error satisfies \(\beta(p) = 1 - \pi(p)\) exactly.

"""Lab S1-L05-1: Exact binomial statistical power curve and Type I / Type II error trade-off.

Evaluates exact power pi(p1) = P(K >= 15 | p1) and Type II error beta(p1) = 1 - pi(p1) for n = 20.
All values computed in exact rational arithmetic using fractions.Fraction.
Standard library only. No external imports.
"""

from __future__ import annotations

import math
from fractions import Fraction


def binom_prob(n: int, k: int, p: Fraction) -> Fraction:
    """Exact binomial PMF P(K = k) = comb(n, k) * p^k * (1 - p)^(n - k)."""
    comb = math.comb(n, k)
    return Fraction(comb, 1) * (p**k) * ((1 - p) ** (n - k))


def main() -> None:
    n = 20
    cutoff = 15  # Decision rule from L04: reject H0 when K >= 15

    # Grid of alternative values for true parameter p
    p_values = [
        Fraction(5, 10),
        Fraction(6, 10),
        Fraction(7, 10),
        Fraction(8, 10),
        Fraction(9, 10),
    ]

    print(f"sample size n: {n}, rejection region: K >= {cutoff}")
    print("exact power and Type II error across parameter values:")

    for p in p_values:
        # Power is probability of rejection under p: sum_{k=cutoff}^n P(K = k | p)
        power = sum(binom_prob(n, k, p) for k in range(cutoff, n + 1))
        beta = Fraction(1, 1) - power  # Type II error probability

        is_null = p == Fraction(1, 2)
        label = "H0 (Type I error)" if is_null else "H1"
        print(
            f"p = {p} ({float(p):.2f}) [{label}]: "
            f"power = {power} ({float(power):.6f}), "
            f"beta = {beta} ({float(beta):.6f})"
        )

    # Check relation at null: power under p0 equals achieved Type I error rate
    type_i_rate = sum(binom_prob(n, k, Fraction(1, 2)) for k in range(cutoff, n + 1))
    print(f"achieved Type I error at p = 1/2: {type_i_rate} ({float(type_i_rate):.6f})")

Interpretation: The exact rational computation verifies that power increases monotonically with effect size \(p\), and \(\beta(p) = 1 - \pi(p)\) holds exactly. It reveals that small samples have severe Type II error rates against moderate edges.

5Where the canon breaks

Classical Neyman–Pearson power analysis operates under several mathematical idealizations that fail in empirical market environments:

  • Non-stationarity and alpha decay: The assumption that alternative parameter \(\theta_1\) remains constant as sample size \(n\) increases is false in financial markets. Alpha decays as arbitrage capital enters the trade. Demanding excessive sample size \(n\) to achieve \(90\%\) power may mean the edge vanishes before the required track record is collected.
  • Selection bias and post-selection power distortion: In backtesting, dozens or thousands of strategies are screened simultaneously. Conditioning on a strategy passing an initial hurdle inflates the apparent power and distorts the sampling distribution. The true out-of-sample power of a selected strategy is drastically lower than the in-sample calculation suggests.
  • Serial dependence: Market returns exhibit volatility clustering and autocorrelation. When return observations are serially correlated, the effective sample size \(n_{\mathrm{eff}}\) is strictly smaller than the calendar count \(n\), sharply depressing real power below nominal formulas.

Misconceptions

  • Failing to reject the null hypothesis proves that no edge exists.

    Correction: Failing to reject \(H_0\) does not imply that \(H_0\) is true. If a test has low statistical power (for example, \(12.6\%\) power against \(p = 0.60\) with \(n = 20\)), failing to reject occurs \(87.4\%\) of the time even when the alternative is true. Absence of evidence is not evidence of absence.

  • The Type II error probability is simply 1 minus the Type I error.

    Correction: Type I error \(\alpha\) and Type II error \(\beta\) are computed under completely different probability measures: \(\alpha = \Prob_{H_0}(X \in R)\) is evaluated under the null distribution, whereas \(\beta = \Prob_{H_1}(X \notin R)\) is evaluated under the alternative distribution. There is no simple identity \(\alpha + \beta = 1\). Instead, \(\beta(\theta_1) = 1 - \pi(\theta_1)\), where \(\pi(\theta_1)\) is the power against alternative \(\theta_1\).

  • A high significance level (small alpha) guarantees high decision quality.

    Correction: Choosing an ultra-conservative significance level such as \(\alpha = 0.001\) controls false positives, but for a fixed track record length \(n\), it drives statistical power toward zero. The researcher avoids false discoveries only by ensuring they will never detect true alpha.

Problem set

Mechanics

M1 · Normal power function

Suppose a test statistic \(Z \sim \Normal(\mu, 1)\) tests \(H_0: \mu = 0\) versus \(H_1: \mu > 0\) at level \(\alpha = 0.05\) using critical value \(c = 1.645\). Derive the power function \(\pi(\mu)\) as a function of \(\mu\).

Solution

Under parameter \(\mu\), \(Z - \mu \sim \Normal(0, 1)\). Therefore: \[ \pi(\mu) = \Prob_\mu(Z \ge 1.645) = \Prob_\mu(Z - \mu \ge 1.645 - \mu) = 1 - \Phi(1.645 - \mu) = \Phi(\mu - 1.645) \]

M2 · Power evaluation at a specific alternative

In the setting of Problem M1, calculate the exact power \(\pi(\mu)\) against alternative \(\mu_1 = 2.50\).

Solution

Evaluating \(\pi(2.50) = \Phi(2.50 - 1.645) = \Phi(0.855)\). Using standard normal tables or software, \(\Phi(0.855) \approx 0.8037\), or approximately \(80.4\%\) power.

M3 · Exact Type II error for binomial test

For the binomial test in Example 4.1 with \(n = 20\) and cutoff \(c = 15\), compute the exact Type II error probability \(\beta(0.80)\) as a reduced fraction.

Solution

From Example 4.1, \(\pi(0.80) = \frac{76695231004672}{95367431640625}\). Hence: \[ \beta(0.80) = 1 - \pi(0.80) = \frac{95367431640625 - 76695231004672}{95367431640625} = \frac{18672200635953}{95367431640625} \approx 0.195792 \]

Proof

P1 · Error trade-off under threshold shift

Prove that for any continuous test statistic \(T\) with densities \(f_0(t) > 0\) under \(H_0\) and \(f_1(t) > 0\) under \(H_1\), shifting the critical threshold \(c\) satisfies \(\frac{d\alpha}{dc} < 0\) and \(\frac{d\beta}{dc} > 0\).

Solution

By definition, \(\alpha(c) = \int_c^\infty f_0(t) \, dt = 1 - F_0(c)\) and \(\beta(c) = \int_{-\infty}^c f_1(t) \, dt = F_1(c)\). By Leibniz's rule, \(\frac{d\alpha}{dc} = -f_0(c) < 0\) and \(\frac{d\beta}{dc} = f_1(c) > 0\). Thus any change in threshold that lowers \(\alpha\) strictly raises \(\beta\).

P2 · Sample size derivation for normal mean

Show that for testing \(H_0: \mu \le 0\) versus \(H_1: \mu > 0\) with sample mean \(\bar X \sim \Normal(\mu, \sigma^2/n)\), the sample size required to achieve significance level \(\alpha\) and power \(1 - \beta\) against alternative \(\mu_1 > 0\) is: \[ n = \frac{\sigma^2 \left(\Phi^{-1}(1 - \alpha) + \Phi^{-1}(1 - \beta)\right)^2}{\mu_1^2} \]

Solution

The test rejects when \(\sqrt{n}\bar X / \sigma \ge \Phi^{-1}(1 - \alpha)\), or \(\bar X \ge \frac{\sigma}{\sqrt{n}}\Phi^{-1}(1 - \alpha)\). Under \(\mu = \mu_1\), \(Z = \frac{\bar X - \mu_1}{\sigma/\sqrt{n}} \sim \Normal(0, 1)\). Power is \(\Prob_{\mu_1}\left(\bar X \ge \frac{\sigma}{\sqrt{n}}\Phi^{-1}(1 - \alpha)\right) = \Phi\left(\frac{\sqrt{n}\mu_1}{\sigma} - \Phi^{-1}(1 - \alpha)\right)\). Setting this equal to \(1 - \beta\) requires \(\frac{\sqrt{n}\mu_1}{\sigma} - \Phi^{-1}(1 - \alpha) = \Phi^{-1}(1 - \beta)\). Solving for \(\sqrt{n}\) gives \(\sqrt{n} = \frac{\sigma}{\mu_1}\left(\Phi^{-1}(1 - \alpha) + \Phi^{-1}(1 - \beta)\right)\). Squaring yields the result.

P3 · Power limit under consistency

Prove that for any consistent test of \(H_0: \theta = \theta_0\) versus \(H_1: \theta = \theta_1\) with fixed level \(\alpha\), the power \(\pi_n(\theta_1) \to 1\) as \(n \to \infty\).

Solution

A test sequence is consistent against alternative \(\theta_1\) if the rejection probability under \(\theta_1\) converges to 1 as sample size grows: \(\lim_{n \to \infty} \Prob_{\theta_1}(X \in R_n) = 1\). By Definition 2.1, power is \(\pi_n(\theta_1) = \Prob_{\theta_1}(X \in R_n)\). Hence \(\lim_{n \to \infty} \pi_n(\theta_1) = 1\), and the Type II error probability \(\beta_n(\theta_1) = 1 - \pi_n(\theta_1) \to 0\).

Empirical

E1 · Minimum detectable effect size

An equity analyst tests whether a daily mean return \(\mu\) is positive using \(n = 100\) observations with known \(\sigma = 1.0\). For \(\alpha = 0.05\), how large must \(\mu_1\) be to achieve \(90\%\) power (\(1 - \beta = 0.90\))?

Solution

The test statistic is \(10 \bar X\), rejecting when \(10 \bar X \ge \Phi^{-1}(0.95) \approx 1.6449\). Power is \(\Phi(10\mu_1 - 1.6449)\). Setting this equal to \(0.90\) gives \(10\mu_1 - 1.6449 = \Phi^{-1}(0.90) \approx 1.2816\). Thus \(10\mu_1 = 1.6449 + 1.2816 = 2.9265\), so \(\mu_1 = 0.29265\).

E2 · Effect of halving signal on sample size

In Problem E1, determine the effect on required sample size \(n\) if the true effect size \(\mu_1/\sigma\) is halved.

Solution

Because \(n \propto 1/(\mu_1/\sigma)^2\), halving the effect size quadruples the required sample size (\(2^2 = 4\)).

E3 · Power deficit of small sample

In Lab 1, evaluate the probability that a strategy with a strong \(60\%\) win rate fails to reach statistical significance across 20 trades.

Solution

From Lab 1, the power at \(p = 0.60\) is \(\pi(0.60) \approx 0.125599\). The failure probability is the Type II error \(\beta(0.60) = 1 - 0.125599 = 0.874401\), or \(87.4\%\).

Research

R1 · Multiple testing and power dilution

When multiple hypothesis tests are conducted and a Bonferroni threshold \(\alpha/m\) is applied, explain why the statistical power of detecting an individual true alternative is severely diluted.

Solution

Dividing the per-test significance level by \(m\) drives the individual critical threshold far into the distribution tails (e.g. from \(1.645\) to \(3.09\) or beyond). For a fixed track record length \(n\), the alternative distribution has minimal density above this elevated cutoff, causing individual test power \(\pi(\theta_1)\) to collapse toward zero.

R2 · Winner's curse in backtested alpha

Explain how selecting only backtests that cross a high power hurdle creates an upward bias in estimated Sharpe ratio ("winner's curse").

Solution

Conditioning on rejecting the null \(T(X) \ge c\) implies the expected value of the estimator given selection is \(\E[T(X) \mid T(X) \ge c] > \E[T(X)]\). In finite samples, only strategies that enjoyed large positive sampling noise clear the significance threshold, leading to severe performance degradation out-of-sample.

R3 · Link to Sharpe ratio required track record

How does the sample size formula derived in Problem P2 directly motivate the capstone project's required track record formula for the Sharpe ratio?

Solution

The sample Sharpe ratio estimator has asymptotic variance under the alternative equal to \((1 + \SR^2/2)/T\). Substituting this inflated variance into the normal power equation directly produces the project's closed-form required years formula: \(y = \frac{(\Phi^{-1}(1 - \alpha) + \Phi^{-1}(1 - \beta)\sqrt{1 + \SR_{\mathrm{ann}}^2/(2k)})^2}{\SR_{\mathrm{ann}}^2}\).
