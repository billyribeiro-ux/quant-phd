How should a quantitative model choose parameters when fitting stochastic volatility models, credit transition matrices, or multi-factor asset return distributions? Rather than choosing ad hoc moments, maximum likelihood estimation selects the parameter values that maximize the joint probability of observing the historical data. Fisher information quantifies the curvature of this likelihood surface, measuring the precise amount of information data carries about the unknown parameters. This lesson develops the score function, the information equality, and the properties of maximum likelihood estimators.

1The likelihood function and the score

Let \(X = (X_1, \dots, X_n)\) be a sample drawn from a parametric family with joint probability density or probability mass function \(f(x; \theta)\), where \(\theta \in \Theta \subseteq \R^k\) is the parameter vector. Once the sample \(x\) is realized, \(f(x; \theta)\) is viewed as a function of the parameter \(\theta\).

Definition 1.1 (likelihood, log-likelihood, and score)

The likelihood function \(L(\theta; x): \Theta \to [0, \infty)\) is defined as \(L(\theta; x) = f(x; \theta)\). For an i.i.d. sample with marginal densities \(f(x_i; \theta)\): \[ L(\theta; x) = \prod_{i=1}^n f(x_i; \theta) \] The log-likelihood function is the natural logarithm: \[ \ell(\theta; x) = \ln L(\theta; x) = \sum_{i=1}^n \ln f(x_i; \theta) \] Assuming \(\ell(\theta; x)\) is differentiable on an open parameter space \(\Theta\), the score function \(S(\theta; x)\) is the gradient with respect to \(\theta\): \[ S(\theta; x) = \nabla_\theta \ell(\theta; x) = \sum_{i=1}^n \nabla_\theta \ln f(x_i; \theta) \]

Definition 1.2 (maximum likelihood estimator)

A maximum likelihood estimation procedure selects an estimator \(\hat\theta_{\mathrm{MLE}} = \hat\theta(X)\) satisfying: \[ \hat\theta_{\mathrm{MLE}} \in \argmax_{\theta \in \Theta} L(\theta; X) = \argmax_{\theta \in \Theta} \ell(\theta; X) \] If \(\ell(\theta; X)\) is strictly concave and continuously differentiable on an open set \(\Theta\), the MLE is the unique solution to the score equation: \[ S(\hat\theta_{\mathrm{MLE}}; X) = \mathbf{0} \]

Example 1.3 (Bernoulli MLE)

Let \(X_1, \dots, X_n\) be i.i.d. \(\operatorname{Bernoulli}(p)\) with \(p \in (0, 1)\). The likelihood is: \[ L(p; X) = \prod_{i=1}^n p^{X_i}(1 - p)^{1 - X_i} = p^{\sum X_i}(1 - p)^{n - \sum X_i} \] Letting \(k = \sum_{i=1}^n X_i\), the log-likelihood is: \[ \ell(p; X) = k \ln p + (n - k) \ln(1 - p) \] Differentiating with respect to \(p\): \[ S(p; X) = \frac{\partial \ell}{\partial p} = \frac{k}{p} - \frac{n - k}{1 - p} \] Setting \(S(\hat p; X) = 0\) yields \(\frac{k}{\hat p} = \frac{n - k}{1 - \hat p} \implies k(1 - \hat p) = \hat p(n - k) \implies k = n\hat p\). Thus \(\hat p_{\mathrm{MLE}} = \frac{k}{n} = \bar X\). The second derivative is \(\frac{\partial^2 \ell}{\partial p^2} = -\frac{k}{p^2} - \frac{n - k}{(1 - p)^2} < 0\) for all \(p \in (0, 1)\), confirming that \(\bar X\) is the unique global maximizer.

2Fisher information and the information equality

Definition 2.1 (Fisher information)

Let \(X\) have density \(f(x; \theta)\) satisfying regularity assumptions (support does not depend on \(\theta\), and \(\ln f(x; \theta)\) is twice continuously differentiable). The Fisher information matrix \(I_n(\theta) \in \R^{k \times k}\) contained in the sample \(X\) is defined as: \[ I_n(\theta) = \E_\theta\left[ S(\theta; X) S(\theta; X)^\top \right] \] For a scalar parameter \(\theta \in \R\): \[ I_n(\theta) = \E_\theta\left[ \left(\frac{\partial \ln f(X; \theta)}{\partial \theta}\right)^2 \right] \]

Proposition 2.2 (mean of the score is zero)

Under the regularity condition that differentiation with respect to \(\theta\) and integration over the sample space can be interchanged: \[ \E_\theta[S(\theta; X)] = \mathbf{0} \]

Proof

For a continuous distribution (the discrete proof replaces integrals with sums): \[ \int f(x; \theta) \, dx = 1 \] Differentiating both sides with respect to \(\theta\): \[ \nabla_\theta \int f(x; \theta) \, dx = \mathbf{0} \] Interchanging differentiation and integration: \[ \int \nabla_\theta f(x; \theta) \, dx = \int \frac{\nabla_\theta f(x; \theta)}{f(x; \theta)} f(x; \theta) \, dx = \int \nabla_\theta \ln f(x; \theta) f(x; \theta) \, dx = \E_\theta[S(\theta; X)] = \mathbf{0} \] \(\blacksquare\)

Theorem 2.3 (information equality)

Under the regularity condition that the second derivative can be passed under the integral sign: \[ I_n(\theta) = -\E_\theta\left[ \nabla_\theta^2 \ell(\theta; X) \right] \] For scalar \(\theta\): \[ I_n(\theta) = \E_\theta\left[\left(\frac{\partial \ell}{\partial \theta}\right)^2\right] = -\E_\theta\left[\frac{\partial^2 \ell}{\partial \theta^2}\right] \]

Proof

Differentiating the identity \(\int \nabla_\theta \ln f(x; \theta) f(x; \theta) \, dx = \mathbf{0}\) with respect to \(\theta^\top\): \[ \int \left( \nabla_\theta^2 \ln f(x; \theta) f(x; \theta) + \nabla_\theta \ln f(x; \theta) [\nabla_\theta f(x; \theta)]^\top \right) \, dx = \mathbf{0} \] Substituting \(\nabla_\theta f(x; \theta) = \nabla_\theta \ln f(x; \theta) f(x; \theta)\): \[ \int \nabla_\theta^2 \ln f(x; \theta) f(x; \theta) \, dx + \int \left[\nabla_\theta \ln f(x; \theta)\right] \left[\nabla_\theta \ln f(x; \theta)\right]^\top f(x; \theta) \, dx = \mathbf{0} \] The first integral is \(\E_\theta[\nabla_\theta^2 \ln f(X; \theta)]\), and the second is \(I_n(\theta)\). Therefore, \(I_n(\theta) = -\E_\theta[\nabla_\theta^2 \ln f(X; \theta)]\). \(\blacksquare\)

Proposition 2.4 (additivity of Fisher information under i.i.d. sampling)

If \(X_1, \dots, X_n\) are i.i.d. draws with unit Fisher information \(I_1(\theta)\), then: \[ I_n(\theta) = n I_1(\theta) \]

Proof

By additivity of log-likelihood: \(\ell(\theta; X) = \sum_{i=1}^n \ln f(X_i; \theta)\). Taking the second derivative: \[ \nabla_\theta^2 \ell(\theta; X) = \sum_{i=1}^n \nabla_\theta^2 \ln f(X_i; \theta) \] Taking expectations on both sides under \(\Prob_\theta\): \[ -\E_\theta[\nabla_\theta^2 \ell(\theta; X)] = -\sum_{i=1}^n \E_\theta[\nabla_\theta^2 \ln f(X_i; \theta)] = \sum_{i=1}^n I_1(\theta) = n I_1(\theta) \] By the information equality (Theorem 2.3), \(I_n(\theta) = n I_1(\theta)\). \(\blacksquare\)

Example 2.5 (Fisher information for Bernoulli and normal distributions)

(a) Bernoulli distribution: For a single observation \(X_1 \in \{0, 1\}\) with parameter \(p \in (0, 1)\), the second derivative of the log-likelihood is: \[ \frac{\partial^2 \ln f(X_1; p)}{\partial p^2} = -\frac{X_1}{p^2} - \frac{1 - X_1}{(1 - p)^2} \] Taking expectations with \(\E[X_1] = p\): \[ I_1(p) = -\E\left[-\frac{X_1}{p^2} - \frac{1 - X_1}{(1 - p)^2}\right] = \frac{p}{p^2} + \frac{1 - p}{(1 - p)^2} = \frac{1}{p} + \frac{1}{1 - p} = \frac{1}{p(1 - p)} \] For a sample of size \(n\), \(I_n(p) = \frac{n}{p(1 - p)}\).

(b) Normal mean: For \(X_i \sim \mathcal{N}(\mu, \sigma^2)\) with known \(\sigma^2\): \[ \ln f(X_1; \mu) = -\frac{1}{2}\ln(2\pi\sigma^2) - \frac{(X_1 - \mu)^2}{2\sigma^2} \] The score is \(\frac{\partial \ln f}{\partial \mu} = \frac{X_1 - \mu}{\sigma^2}\), and \(\frac{\partial^2 \ln f}{\partial \mu^2} = -\frac{1}{\sigma^2}\). Thus \(I_1(\mu) = \frac{1}{\sigma^2}\), and for a sample of size \(n\), \(I_n(\mu) = \frac{n}{\sigma^2}\).

Lab 1 · Bernoulli MLE grid search, score check, and Fisher information

Hypothesis: For a sample of \(n = 20\) Bernoulli observations with \(k = 8\) successes, evaluating the likelihood over a rational grid of \(p \in (0, 1)\) will identify the exact maximizer at \(p^* = 8/20 = 2/5\), at which the score function evaluates to exactly zero. The sample Fisher information evaluates to \(I_n(2/5) = 250/3\), yielding a Cramér–Rao bound of \(3/250 = 0.012\), which exactly equals the variance of the sample proportion.

"""Lab S1-L02-1: Bernoulli MLE by exact rational likelihood evaluation, score check, and Fisher information.

Standard library only. Exact rational arithmetic using fractions.Fraction.
"""

from __future__ import annotations

from fractions import Fraction


def main() -> None:
    n = 20
    k = 8  # 8 successes, 12 failures
    n_minus_k = n - k

    # Search over grid of p = j / 100 for j in 1..99
    best_p = Fraction(1, 100)
    best_lik = Fraction(0)

    for j in range(1, 100):
        p = Fraction(j, 100)
        # Likelihood proportional to p^k * (1 - p)^(n - k)
        lik = (p**k) * ((1 - p) ** n_minus_k)
        if lik > best_lik:
            best_lik = lik
            best_p = p

    mle_analytic = Fraction(k, n)

    print(f"sample size n: {n}, successes k: {k}")
    print(f"grid search maximizer: {best_p} ({float(best_p):.4f})")
    print(f"analytic MLE k / n: {mle_analytic} ({float(mle_analytic):.4f})")
    print(f"grid matches analytic MLE: {best_p == mle_analytic}")

    # Check score equation: S(p) = k / p - (n - k) / (1 - p)
    score_at_mle = Fraction(k, 1) / mle_analytic - Fraction(n_minus_k, 1) / (1 - mle_analytic)
    print(f"score S(p_hat): {score_at_mle}")

    # Fisher information per observation: I_1(p) = 1 / (p * (1 - p))
    i_1 = Fraction(1, 1) / (mle_analytic * (1 - mle_analytic))
    # Sample Fisher information: I_n(p) = n * I_1(p)
    i_n = n * i_1
    cr_bound = Fraction(1, 1) / i_n

    print(f"unit Fisher information I_1(p_hat): {i_1} ({float(i_1):.6f})")
    print(f"sample Fisher information I_n(p_hat): {i_n} ({float(i_n):.6f})")
    print(f"Cramer-Rao lower bound 1 / I_n(p_hat): {cr_bound} ({float(cr_bound):.6f})")

    # Variance of sample proportion: Var(p_hat) = p * (1 - p) / n
    var_mle = (mle_analytic * (1 - mle_analytic)) / n
    print(f"variance of sample mean Var(p_hat): {var_mle} ({float(var_mle):.6f})")
    print(f"sample mean attains Cramer-Rao bound: {var_mle == cr_bound}")

Interpretation: The exact rational calculation confirms that the score function vanishes at the likelihood maximizer. The Cramér–Rao bound \(1/I_n(p)\) equals the sampling variance of \(\hat p = \bar X\), demonstrating that the sample mean is an efficient estimator.

3Where the canon breaks

Maximum likelihood theory relies heavily on regularity conditions: (1) the parameter space \(\Theta\) is an open subset of \(\R^k\); (2) the support \(\{x : f(x; \theta) > 0\}\) does not depend on \(\theta\); (3) the true parameter lies in the interior of \(\Theta\). When the support depends on \(\theta\) (such as Uniform\((0, \theta)\)), the score function is not defined at the boundary, differentiation under the integral sign fails, the information equality does not hold, and the MLE converges at the accelerated rate \(O(1/n)\) rather than \(O(1/\sqrt{n})\). Furthermore, if the log-likelihood is multimodal (common in Gaussian mixture models and GARCH processes), gradient-based score solvers can trap the estimator in poor local optima.

Misconceptions

  • The MLE is always unbiased in finite samples.

    Correction: The MLE is generally biased in finite samples. In normal samples with unknown variance, the MLE for \(\sigma^2\) is the divisor \(n\) estimator \(S_n^2 = \frac{1}{n}\sum (X_i - \bar X)^2\), which has bias \(-\sigma^2/n\). MLE guarantees asymptotic unbiasedness, not finite-sample unbiasedness.

  • Fisher information depends on the observed data values.

    Correction: Fisher information is an expectation over all possible sample values under the probability measure \(\Prob_\theta\): \(I_n(\theta) = \E_\theta[- \nabla^2 \ell(\theta; X)]\). It is a deterministic function of \(\theta\), not a random variable. The un-expected negative Hessian \(J_n(\theta) = -\nabla^2 \ell(\theta; x)\) is the observed information.

  • A larger Fisher information means higher estimator variance.

    Correction: Fisher information measures curvature and signal strength. Higher Fisher information corresponds to a sharper likelihood peak, narrower uncertainty, and lower achievable estimator variance (the Cramér–Rao bound is \(1/I_n(\theta)\)).

Problem set

Mechanics

M1 · Poisson distribution MLE and Fisher information

Let \(X_1, \dots, X_n\) be i.i.d. \(\operatorname{Poisson}(\lambda)\) with PMF \(f(x; \lambda) = \frac{\lambda^x e^{-\lambda}}{x!}\). Derive the score function, the MLE \(\hat\lambda\), and the sample Fisher information \(I_n(\lambda)\).

Solution

The log-likelihood is \(\ell(\lambda) = \sum_{i=1}^n [X_i \ln\lambda - \lambda - \ln(X_i!)] = \ln\lambda \sum X_i - n\lambda - \sum \ln(X_i!)\). The score is \(S(\lambda) = \frac{d\ell}{d\lambda} = \frac{\sum X_i}{\lambda} - n\). Setting \(S(\hat\lambda) = 0\) yields \(\hat\lambda = \frac{1}{n}\sum_{i=1}^n X_i = \bar X\). The second derivative is \(\frac{d^2\ell}{d\lambda^2} = -\frac{\sum X_i}{\lambda^2}\). By the information equality, \(I_n(\lambda) = -\E\left[-\frac{\sum X_i}{\lambda^2}\right] = \frac{n\lambda}{\lambda^2} = \frac{n}{\lambda}\).

M2 · Exponential distribution MLE and Fisher information

Let \(X_1, \dots, X_n\) be i.i.d. draws from an Exponential distribution with rate \(\beta > 0\) and density \(f(x; \beta) = \beta e^{-\beta x}\) for \(x > 0\). Determine the score function, the MLE \(\hat\beta\), and \(I_n(\beta)\).

Solution

\(\ell(\beta) = \sum_{i=1}^n [\ln\beta - \beta X_i] = n\ln\beta - \beta \sum_{i=1}^n X_i\). The score is \(S(\beta) = \frac{n}{\beta} - \sum X_i\). Setting \(S(\hat\beta) = 0\) gives \(\hat\beta = \frac{n}{\sum X_i} = \frac{1}{\bar X}\). The second derivative is \(\frac{d^2\ell}{d\beta^2} = -\frac{n}{\beta^2}\), which is constant with respect to \(X\). Thus \(I_n(\beta) = -\E[-n/\beta^2] = \frac{n}{\beta^2}\).

M3 · Fisher information for normal variance

Let \(X_1, \dots, X_n \sim \mathcal{N}(0, \sigma^2)\) with known mean zero. Compute the Fisher information \(I_n(\sigma^2)\) for parameter \(\theta = \sigma^2\).

Solution

\(\ell(\theta) = -\frac{n}{2}\ln(2\pi) - \frac{n}{2}\ln\theta - \frac{1}{2\theta}\sum X_i^2\). The score is \(\frac{d\ell}{d\theta} = -\frac{n}{2\theta} + \frac{1}{2\theta^2}\sum X_i^2\). Differentiating again: \(\frac{d^2\ell}{d\theta^2} = \frac{n}{2\theta^2} - \frac{1}{\theta^3}\sum X_i^2\). Taking expectation with \(\E[\sum X_i^2] = n\theta\): \(I_n(\theta) = -\E\left[\frac{n}{2\theta^2} - \frac{n\theta}{\theta^3}\right] = -\left[\frac{n}{2\theta^2} - \frac{n}{\theta^2}\right] = \frac{n}{2\theta^2} = \frac{n}{2\sigma^4}\).

P1 · Invariance property of maximum likelihood estimators

Let \(\hat\theta_{\mathrm{MLE}}\) be the MLE of \(\theta \in \Theta\). Prove that for any bijective transformation \(g: \Theta \to \Omega\), the MLE of \(\tau = g(\theta)\) is \(\hat\tau_{\mathrm{MLE}} = g(\hat\theta_{\mathrm{MLE}})\).

Solution

Define the induced likelihood for \(\tau \in \Omega\) by \(L^*(\tau) = \sup_{\theta \in g^{-1}(\{\tau\})} L(\theta)\). Since \(g\) is a bijection, \(g^{-1}(\{\tau\})\) contains the unique element \(\theta = g^{-1}(\tau)\), so \(L^*(\tau) = L(g^{-1}(\tau))\). Then \(\sup_{\tau \in \Omega} L^*(\tau) = \sup_{\tau \in \Omega} L(g^{-1}(\tau)) = \sup_{\theta \in \Theta} L(\theta) = L(\hat\theta_{\mathrm{MLE}})\). The supremum of \(L^*(\tau)\) is attained at the point \(\tau^*\) where \(g^{-1}(\tau^*) = \hat\theta_{\mathrm{MLE}}\), which means \(\tau^* = g(\hat\theta_{\mathrm{MLE}})\). Hence \(\hat\tau_{\mathrm{MLE}} = g(\hat\theta_{\mathrm{MLE}})\).

P2 · Fisher information under reparameterization

Let \(\theta = g(\psi)\) be a one-to-one differentiable reparameterization of a scalar parameter. Prove that the Fisher information with respect to \(\psi\) is \(I_\psi(\psi) = I_\theta(g(\psi)) \cdot [g'(\psi)]^2\).

Solution

Let \(\ell^*(\psi) = \ell(g(\psi))\). By the chain rule: \(\frac{\partial \ell^*}{\partial \psi} = \frac{\partial \ell}{\partial \theta} \cdot \frac{d\theta}{d\psi} = \frac{\partial \ell}{\partial \theta} \cdot g'(\psi)\). Squaring both sides: \(\left(\frac{\partial \ell^*}{\partial \psi}\right)^2 = \left(\frac{\partial \ell}{\partial \theta}\right)^2 \cdot [g'(\psi)]^2\). Taking expectations under \(\Prob_\theta\) with \(\theta = g(\psi)\): \(I_\psi(\psi) = \E\left[\left(\frac{\partial \ell^*}{\partial \psi}\right)^2\right] = \E\left[\left(\frac{\partial \ell}{\partial \theta}\right)^2\right] \cdot [g'(\psi)]^2 = I_\theta(g(\psi)) \cdot [g'(\psi)]^2\).

P3 · Non-negativity of Fisher information

Prove that for any regular parametric family, the Fisher information matrix \(I_n(\theta)\) is positive semidefinite, and strictly positive definite if the score components are linearly independent.

Solution

By Definition 2.1, \(I_n(\theta) = \E_\theta[S(\theta; X) S(\theta; X)^\top]\). For any non-zero vector \(v \in \R^k\), the quadratic form is \(v^\top I_n(\theta) v = v^\top \E_\theta[S S^\top] v = \E_\theta[v^\top S S^\top v] = \E_\theta[(v^\top S)^2]\). Since \((v^\top S)^2 \ge 0\) almost surely, its expectation is non-negative: \(v^\top I_n(\theta) v \ge 0\), establishing positive semidefiniteness. Furthermore, \(v^\top I_n(\theta) v = 0\) if and only if \(v^\top S(\theta; X) = 0\) almost surely. If the score components are linearly independent, no non-trivial linear combination can vanish almost surely, so \(v^\top I_n(\theta) v > 0\) for all \(v \ne \mathbf{0}\), proving strict positive definiteness.

Empirical

E1 · Rational score evaluation at grid points (Lab 1)

In Lab 1, compute the value of the score function \(S(p) = \frac{k}{p} - \frac{n-k}{1-p}\) for \(n = 20, k = 8\) at \(p = 1/2\), and explain why the sign shows the MLE lies below 1/2.

Solution

At \(p = 1/2\), \(S(1/2) = \frac{8}{1/2} - \frac{12}{1/2} = 16 - 24 = -8\). Since the log-likelihood is strictly concave (\(S'(p) < 0\)), a negative score at \(p = 1/2\) implies that the slope of the log-likelihood is downward, so the maximum must lie to the left of 1/2. Indeed, the true MLE is \(8/20 = 0.40 < 0.50\).

E2 · Fisher information magnitude (Lab 1)

In Lab 1, \(I_n(p) = \frac{n}{p(1-p)}\). Compute the sample Fisher information for \(n = 20\) at \(p = 0.10\) and compare it with the value at \(p = 0.40\).

Solution

At \(p = 0.40\), \(I_{20}(0.40) = \frac{20}{0.40 \times 0.60} = \frac{20}{0.24} = \frac{250}{3} \approx 83.3333\). At \(p = 0.10\), \(I_{20}(0.10) = \frac{20}{0.10 \times 0.90} = \frac{20}{0.09} = \frac{2000}{9} \approx 222.2222\). The information is much higher near the boundary \(p = 0.10\) because variance \(p(1-p)\) is smaller, so each observation carries more precision about \(p\).

E3 · Likelihood ratio comparison (Lab 1)

Compute the exact likelihood ratio \(L(2/5) / L(1/2)\) for the data of Lab 1 (\(n = 20, k = 8\)) in exact fractions.

Solution

\(L(2/5) = (2/5)^8 (3/5)^{12} = \frac{2^8 3^{12}}{5^{20}} = \frac{256 \times 531441}{5^{20}} = \frac{136048896}{5^{20}}\). At \(p = 1/2\), \(L(1/2) = (1/2)^{20} = \frac{1}{2^{20}}\). The ratio is \(\frac{L(2/5)}{L(1/2)} = \frac{2^{28} 3^{12}}{5^{20}} = \frac{268435456 \times 531441}{95367431640625} = \frac{142657618993152}{95367431640625} \approx 1.49587\). The data is roughly 1.5 times more likely under the MLE than under the null \(p = 1/2\).

Research

R1 · MLE failure under Uniform(0, theta)

Let \(X_1, \dots, X_n\) be i.i.d. \(\operatorname{Uniform}(0, \theta)\). Show that the score equation cannot be solved by differentiation, identify the MLE \(\hat\theta\), and explain why the information equality fails.

Solution

The joint density is \(f(x; \theta) = \theta^{-n} \prod_{i=1}^n \indic(0 \le X_i \le \theta) = \theta^{-n} \indic(\max_i X_i \le \theta)\). For \(\theta \ge X_{(n)} = \max_i X_i\), the log-likelihood is \(\ell(\theta) = -n\ln\theta\), which is strictly decreasing in \(\theta\). For \(\theta < X_{(n)}\), \(L(\theta) = 0\) and \(\ell(\theta) = -\infty\). Thus the likelihood is maximized at the boundary: \(\hat\theta_{\mathrm{MLE}} = X_{(n)}\). The derivative \(\ell'(\theta) = -n/\theta \ne 0\) is never zero. The support depends on \(\theta\), violating the regularity condition for differentiation under the integral, so the score does not have mean zero and the information equality fails.

R2 · Observed vs expected Fisher information

In finite samples, Efron and Hinkley (1978) advocate using the observed information \(J_n(\hat\theta) = -\ell''(\hat\theta)\) rather than the expected information \(I_n(\hat\theta)\) for conditioning inferences. Compare \(J_n(p)\) and \(I_n(p)\) for the Bernoulli model and state when they coincide.

Solution

From Section 1, the negative second derivative of the log-likelihood is \(J_n(p) = \frac{k}{p^2} + \frac{n - k}{(1 - p)^2}\). The expected information is \(I_n(p) = \E[J_n(p)] = \frac{n}{p(1 - p)}\). At the MLE \(\hat p = k/n\), substituting \(k = n\hat p\) gives \(J_n(\hat p) = \frac{n\hat p}{\hat p^2} + \frac{n(1 - \hat p)}{(1 - \hat p)^2} = \frac{n}{\hat p} + \frac{n}{1 - \hat p} = \frac{n}{\hat p(1 - \hat p)} = I_n(\hat p)\). In canonical exponential families with linear sufficient statistics, the observed information at the MLE coincides identically with the expected information. In non-linear models (such as Cauchy regression or ARMA models), they diverge, and observed information reflects the realized sample precision.

R3 · Unbounded likelihood in Gaussian mixture models

Consider a two-component Gaussian mixture model with density \(f(x; \theta) = \pi \phi(x; \mu_1, \sigma_1^2) + (1 - \pi) \phi(x; \mu_2, \sigma_2^2)\). Prove that the likelihood function is unbounded on the parameter space.

Solution

Set \(\mu_1 = X_1\) (centering the first component on the first data point). Then the contribution of \(X_1\) to the mixture density is \(\pi \frac{1}{\sqrt{2\pi}\sigma_1} e^0 + (1 - \pi)\phi(X_1; \mu_2, \sigma_2^2) = \frac{\pi}{\sqrt{2\pi}\sigma_1} + (1 - \pi)\phi(X_1; \mu_2, \sigma_2^2)\). For any other observation \(X_j\) (\(j \ge 2\)), its density contribution is at least \((1 - \pi)\phi(X_j; \mu_2, \sigma_2^2) > 0\). As \(\sigma_1 \to 0\), the term \(\frac{\pi}{\sqrt{2\pi}\sigma_1} \to \infty\), while all other terms stay bounded away from zero. Hence \(L(\theta; X) \to \infty\) as \(\sigma_1 \to 0\). The global maximum is \(+\infty\) on the boundary, so the MLE does not exist as an interior point without variance constraints.

8Retrieval quiz

Answer the retrieval items below to test your recall of maximum likelihood and Fisher information.

  1. What is the score function \(S(\theta; X)\)?

    Options

    Definition 1.1: the score is defined as the first derivative (gradient) of the log-likelihood function with respect to the parameters.

  2. Under standard regularity conditions, what is the expected value of the score function \(\E_\theta[S(\theta; X)]\)?

    Proposition 2.2 proves that the expectation of the score is identically zero: \(\E_\theta[S(\theta; X)] = 0\).

  3. What does the information equality state for regular parametric families?

    Options

    Theorem 2.3 establishes the information equality: \(I_n(\theta) = \E[(\nabla\ell)(\nabla\ell)^\top] = -\E[\nabla^2\ell]\).

  4. For an i.i.d. sample of size \(n = 25\) from a normal distribution with known variance \(\sigma^2 = 0.25\), what is the sample Fisher information \(I_n(\mu)\) for the mean?

    From Example 2.5, \(I_n(\mu) = n / \sigma^2 = 25 / 0.25 = 100\).

  5. For an i.i.d. Bernoulli sample of size \(n = 100\) with true parameter \(p = 0.50\), what is the sample Fisher information \(I_n(p) = \frac{n}{p(1-p)}\)?

    \(I_{100}(0.5) = 100 / (0.5 \times 0.5) = 100 / 0.25 = 400\) (Example 2.5).

  6. If \(\hat\theta_{\mathrm{MLE}}\) is the maximum likelihood estimator for \(\theta\), what is the maximum likelihood estimator for \(\tau = g(\theta)\) where \(g\) is a one-to-one function?

    Options

    Proof problem P1: maximum likelihood estimators are functionally invariant under transformations: \(\hat\tau_{\mathrm{MLE}} = g(\hat\theta_{\mathrm{MLE}})\).

  7. How does sample Fisher information \(I_n(\theta)\) scale with sample size \(n\) under i.i.d. sampling?

    Options

    Proposition 2.4: by additivity of independent log-likelihoods, Fisher information grows strictly linearly in sample size.

  8. What does a sharper, more curved log-likelihood peak at the MLE imply about the parameter estimate?

    Options

    Higher curvature means \(-\ell''(\theta)\) is large, implying high Fisher information and narrow uncertainty bands.
