The Bootstrap

Complex financial metrics such as hedge fund Sharpe ratios, drawdown durations, and value-at-risk rarely follow neat analytical distributions. When mathematical derivations of standard errors are intractable or invalid due to skewness, the bootstrap substitutes computer simulation for analytical formulas. Introduced by Efron in 1979, the bootstrap resamples the observed data with replacement to approximate the sampling distribution of virtually any plug-in estimator without imposing Gaussian assumptions.

1The empirical distribution and plug-in principle

Let \(X_1, \dots, X_n\) be independent and identically distributed random variables from an unknown distribution \(F\). In classical parametric inference, we assume \(F\) belongs to a known parametric family \(\{F_\theta : \theta \in \Theta\}\). In nonparametric inference, the distribution \(F\) itself is completely unknown.

The fundamental nonparametric estimator of \(F\) is the empirical cumulative distribution function: \[ F_n(x) = \frac{1}{n} \sum_{i=1}^n \indic(X_i \le x) \]

By the Glivenko–Cantelli theorem, \(F_n\) converges uniformly to \(F\) almost surely: \(\sup_{x \in \R} |F_n(x) - F(x)| \xrightarrow{\text{a.s.}} 0\). The empirical distribution places discrete mass \(1/n\) on each observed sample point.

Definition 1.1 (plug-in estimator)

Any population parameter that can be expressed as a functional of the cumulative distribution function \(\theta = T(F)\) is estimated by its plug-in estimator: \[ \hat\theta = T(F_n) \] For example, the population mean \(\mu = \int x \, dF(x)\) has plug-in estimator \(\bar X = \int x \, dF_n(x) = \frac{1}{n}\sum_{i=1}^n X_i\).

2The bootstrap resampling algorithm

Definition 2.1 (bootstrap)

The bootstrap is a computational resampling method that approximates the unknown sampling distribution of an estimator \(\hat\theta = T(F_n)\) under distribution \(F\) by the distribution of the bootstrap estimator \(\hat\theta^* = T(F_n^*)\) under the empirical distribution \(F_n\).

The conceptual logic of the bootstrap operates via an exact analogy:

Table 2.1: The bootstrap analogy
Concept Real World (Unknown) Bootstrap World (Known & Computable)
Population Unknown distribution \(F\) Empirical distribution \(F_n\)
Sample \(X = (X_1, \dots, X_n) \iid F\) \(X^* = (X_1^*, \dots, X_n^*) \iid F_n\)
Parameter \(\theta = T(F)\) \(\hat\theta = T(F_n)\)
Estimator \(\hat\theta = T(F_n)\) \(\hat\theta^* = T(F_n^*)\)
Sampling Error Distribution of \(\hat\theta - \theta\) Distribution of \(\hat\theta^* - \hat\theta\)

Drawing an observation from \(F_n\) corresponds exactly to selecting one observation uniformly at random from the original sample \(\{X_1, \dots, X_n\}\) with replacement.

The Nonparametric Bootstrap Algorithm:

  1. Given original sample \(X = (X_1, \dots, X_n)\), compute point estimate \(\hat\theta = T(X)\).
  2. For each replication \(b = 1, \dots, B\):
    • Draw a bootstrap sample \(X^{*(b)} = (X_1^{*(b)}, \dots, X_n^{*(b)})\) of size \(n\) by sampling from \(X\) with replacement.
    • Compute the bootstrap replicate \(\hat\theta^{*(b)} = T(X^{*(b)})\).
  3. Estimate the standard error of \(\hat\theta\) by the sample standard deviation of the \(B\) replicates: \[ \widehat{\se}_B(\hat\theta) = \sqrt{\frac{1}{B-1}\sum_{b=1}^B \left(\hat\theta^{*(b)} - \bar{\hat\theta}^*\right)^2}, \quad \text{where } \bar{\hat\theta}^* = \frac{1}{B}\sum_{b=1}^B \hat\theta^{*(b)} \]

Theorem 2.2 (bootstrap consistency for the sample mean)

Assumptions:
(A1) The sample \(X_1, \dots, X_n\) are \(\iid\) from distribution \(F\).
(A2) The population variance \(\sigma^2 = \Var_F(X_1)\) is finite and strictly positive (\(0 < \sigma^2 < \infty\)).
Statement:
As \(n \to \infty\), conditional on the data \(X_1, X_2, \dots\), the bootstrap distribution of \(\sqrt{n}(\bar X^* - \bar X)\) converges weakly to \(\Normal(0, \sigma^2)\) almost surely: \[ \sup_{t \in \R} \left| \Prob_*\left(\sqrt{n}(\bar X^* - \bar X) \le t\right) - \Prob\left(\sqrt{n}(\bar X - \mu) \le t\right) \right| \xrightarrow{\text{a.s.}} 0 \]

Proof sketch

Conditional on the sample \(X\), the bootstrap draws \(X_i^*\) are \(\iid\) with mean \(\E_*[X_i^*] = \bar X\) and variance \(\Var_*[X_i^*] = \frac{1}{n}\sum_{i=1}^n (X_i - \bar X)^2 = \frac{n-1}{n}s^2\). By the strong law of large numbers, \(\frac{n-1}{n}s^2 \to \sigma^2\) almost surely. Applying the Lindeberg–Feller central limit theorem to the triangular array of bootstrap draws conditional on the data establishes that \(\sqrt{n}(\bar X^* - \bar X) / s \dto \Normal(0, 1)\) almost surely. See Efron . \(\blacksquare\)

3Percentile bootstrap confidence intervals

Definition 3.1 (percentile bootstrap interval)

Let \(\hat\theta^{*(1)} \le \hat\theta^{*(2)} \le \dots \le \hat\theta^{*(B)}\) be the ordered bootstrap replicates. The percentile bootstrap confidence interval of nominal level \(1 - \alpha\) is defined by the empirical quantiles of the bootstrap distribution: \[ \operatorname{CI}_{\mathrm{percentile}} = \left[ \hat\theta^*_{(\lfloor B \cdot \alpha/2 \rfloor)}, \, \hat\theta^*_{(\lceil B(1 - \alpha/2) \rceil)} \right] \]

The percentile interval is transformation-invariant: if \(g\) is a monotonic transformation, the percentile interval for \(g(\theta)\) is simply \([g(L), g(U)]\). Moreover, for asymmetric sampling distributions (common in financial data), the percentile interval naturally accommodates skewness without forcing symmetric error bars.

Lab 1 · Percentile bootstrap confidence interval for a mean (SIMULATED)

Hypothesis: For a sample of \(n = 30\) draws from a skewed lognormal distribution generated with seed 801, the sample mean is \(1.2847\) with standard error \(0.1441\). Resampling with \(B = 2000\) bootstrap iterations yields bootstrap standard error \(0.1431\). The percentile bootstrap \(95\%\) confidence interval is \([1.0079, 1.5869]\) (width \(0.5790\)), shifted rightward relative to the symmetric asymptotic normal interval \([1.0023, 1.5671]\) (width \(0.5648\)).

"""Lab S1-L08-1: Percentile bootstrap confidence interval for a mean.

Generates a seeded skewed sample and compares normal asymptotic and bootstrap percentile 95% intervals.
SIMULATED: sample and resamples generated with random.Random(801).
Standard library only. No external imports.
"""

from __future__ import annotations

import math
import random
import statistics


def main() -> None:
    seed = 801
    rng = random.Random(seed)
    n = 30

    # Draw n observations from a lognormal distribution exp(Normal(0, 0.6^2))
    sample = [math.exp(rng.gauss(0.0, 0.6)) for _ in range(n)]

    sample_mean = math.fsum(sample) / n
    sample_var = math.fsum((x - sample_mean) ** 2 for x in sample) / (n - 1)
    se_mean = math.sqrt(sample_var / n)

    # 1. Asymptotic normal 95% confidence interval
    z95 = statistics.NormalDist().inv_cdf(0.975)
    ci_norm_lo = sample_mean - z95 * se_mean
    ci_norm_hi = sample_mean + z95 * se_mean

    # 2. Percentile bootstrap interval with B = 2000 resamples
    b = 2000
    boot_means: list[float] = []
    for _ in range(b):
        # Sample with replacement
        resample = [sample[rng.randrange(n)] for _ in range(n)]
        boot_means.append(math.fsum(resample) / n)

    boot_means.sort()
    # 2.5% and 97.5% quantiles of the bootstrap distribution
    idx_lo = int(0.025 * b)
    idx_hi = int(0.975 * b)
    ci_boot_lo = boot_means[idx_lo]
    ci_boot_hi = boot_means[idx_hi]

    boot_se = math.sqrt(math.fsum((x - sample_mean) ** 2 for x in boot_means) / (b - 1))

    print(f"sample size n: {n}, bootstrap resamples B: {b}, seed: {seed}")
    print(f"sample mean: {sample_mean:.4f}, sample standard error: {se_mean:.4f}")
    print(f"bootstrap standard error: {boot_se:.4f}")
    print(f"asymptotic normal 95% CI: [{ci_norm_lo:.4f}, {ci_norm_hi:.4f}] (width: {ci_norm_hi - ci_norm_lo:.4f})")
    print(f"percentile bootstrap 95% CI: [{ci_boot_lo:.4f}, {ci_boot_hi:.4f}] (width: {ci_boot_hi - ci_boot_lo:.4f})")


main()

sample mean: 1.2847, sample standard error: 0.1441
bootstrap standard error: 0.1431
asymptotic normal 95% CI: [1.0023, 1.5671] (width: 0.5648)
percentile bootstrap 95% CI: [1.0079, 1.5869] (width: 0.5790)

Interpretation: The simulation demonstrates that the bootstrap standard error closely tracks the asymptotic estimate while adapting the confidence bounds to the underlying distribution's positive skewness.

4Where the canon breaks

The naive i.i.d. bootstrap fails under several common conditions in quantitative asset management:

  • Serial dependence and time series: When asset returns exhibit autocorrelation or autoregressive conditional heteroskedasticity (volatility clustering), sampling individual observations with replacement completely destroys the time-series structure. The bootstrap replicates behave as if returns are serially independent, underestimating estimation variance. Addressing serial dependence requires block resampling techniques (such as moving block bootstrap), which operate outside the elementary i.i.d. framework.
  • Extreme order statistics and boundaries: The bootstrap fails for non-smooth parameters such as the maximum return \(\max(X_1, \dots, X_n)\) or support boundaries. The probability that the bootstrap sample contains the sample maximum is \(1 - (1 - 1/n)^n \approx 1 - 1/e \approx 0.632\), meaning \(\hat\theta^* = \hat\theta\) with probability \(63.2\%\). The bootstrap distribution is discrete and fails to converge to the true continuous extreme value distribution.
  • Heavy tails and infinite variance: If asset returns follow a Pareto or Lévy stable distribution with tail index \(\alpha \le 2\) (infinite variance), the standard bootstrap is inconsistent (Bickel and Freedman, 1981). Subsampling or \(m\)-out-of-\(n\) bootstrap is required.

Misconceptions

  • "The bootstrap creates new data out of thin air."

    Correction: The bootstrap does not add new information; it merely explores the variation of the empirical distribution \(F_n\) already collected. If the initial sample size \(n\) is small or unrepresentative, the bootstrap inherits all finite-sample biases and distortions without correction.

  • "Increasing the number of bootstrap resamples B eliminates estimation error."

    Correction: Increasing \(B\) drives Monte Carlo simulation noise toward zero, perfectly revealing the sampling properties under \(F_n\). However, it does not reduce the fundamental sampling error between \(F_n\) and the true distribution \(F\), which remains governed by the original sample size \(n\) at rate \(\mathcal{O}(1/\sqrt{n})\).

  • "The bootstrap works for any estimator without assumptions."

    Correction: Bootstrap validity requires that the parameter functional \(T(F)\) is sufficiently smooth (Hadamard differentiable) and that the observations are independent draws from a law with finite variance. As noted in Section 4, it fails completely for extrema, support boundaries, and dependent time series.

Problem set

Mechanics

M1 · Probability of omitting an observation

In a bootstrap sample of size \(n\) drawn with replacement from \(n\) distinct observations, calculate the exact probability that a specific observation \(X_1\) is not selected, and find its limit as \(n \to \infty\).

Solution

In each draw, the probability of not selecting \(X_1\) is \(1 - 1/n\). Because draws are independent, the probability of omitting \(X_1\) across all \(n\) draws is \((1 - 1/n)^n\). As \(n \to \infty\), \(\lim_{n \to \infty} (1 - 1/n)^n = e^{-1} \approx 0.367879\). Thus approximately \(36.8\%\) of original observations are omitted from any single bootstrap sample.

M2 · Bootstrap standard error formula

Given \(B = 5\) bootstrap replicates of a strategy's annualized return: \(0.12, 0.15, 0.10, 0.14, 0.09\), compute the bootstrap estimate of the standard error \(\widehat{\se}_B\).

Solution

The sample mean of the replicates is \(\bar{\hat\theta}^* = (0.12 + 0.15 + 0.10 + 0.14 + 0.09) / 5 = 0.60 / 5 = 0.120\). The squared deviations are \((0.12-0.12)^2 = 0\), \((0.15-0.12)^2 = 0.0009\), \((0.10-0.12)^2 = 0.0004\), \((0.14-0.12)^2 = 0.0004\), \((0.09-0.12)^2 = 0.0009\). The sum of squared deviations is \(0.0026\). The variance is \(0.0026 / (5 - 1) = 0.0026 / 4 = 0.00065\). The standard error is \(\sqrt{0.00065} \approx 0.0255\).

M3 · Percentile interval index selection

For \(B = 1000\) sorted bootstrap replications, determine the indices of the replicates that form the nominal \(90\%\) percentile bootstrap confidence interval.

Solution

For nominal \(90\%\) confidence, \(\alpha = 0.10\). The lower quantile is \(\alpha/2 = 0.05\), corresponding to index \(\lfloor 1000 \times 0.05 \rfloor = 50\). The upper quantile is \(1 - \alpha/2 = 0.95\), corresponding to index \(\lceil 1000 \times 0.95 \rceil = 950\). The interval is \([\hat\theta^*_{(50)}, \hat\theta^*_{(950)}]\).

Proof

P1 · Transformation invariance of percentile interval

Prove that if \(g: \R \to \R\) is a strictly increasing monotonic function, the percentile bootstrap confidence interval is transformation-invariant.

Solution

Let \(\hat\theta^{*(1)} \le \dots \le \hat\theta^{*(B)}\) be the sorted bootstrap replicates of \(\hat\theta\). Because \(g\) is strictly increasing, the sorted replicates of \(g(\hat\theta)\) are \(g(\hat\theta^{*(1)}) \le \dots \le g(\hat\theta^{*(B)})\). The \(\alpha/2\) empirical quantile of the transformed replicates is \(g(\hat\theta^*_{(\lfloor B \alpha/2 \rfloor)})\), and the \(1 - \alpha/2\) quantile is \(g(\hat\theta^*_{(\lceil B(1 - \alpha/2) \rceil)})\). Thus the percentile interval for \(g(\theta)\) is identically \([g(L), g(U)]\), where \([L, U]\) is the percentile interval for \(\theta\).

P2 · Number of distinct bootstrap samples

Show that from a sample of \(n\) distinct observations, the total number of distinct possible bootstrap samples (ignoring order) is \(\binom{2n-1}{n}\).

Solution

Selecting \(n\) items from \(n\) distinct categories with replacement is equivalent to placing \(n\) indistinguishable balls into \(n\) distinguishable bins. By the classic stars-and-bars combinatorial formula, the number of ways is \(\binom{n + k - 1}{k}\) with \(k = n\), giving \(\binom{n + n - 1}{n} = \binom{2n - 1}{n}\).

P3 · Failure of bootstrap for sample maximum

Prove that for \(\iid\) draws \(X_1, \dots, X_n \sim \operatorname{Uniform}(0, \theta)\), the bootstrap distribution of \(n(\theta - \max X_i^*)\) does not converge to the true sampling distribution of \(n(\theta - \max X_i)\).

Solution

Under the true distribution, \(\Prob(n(\theta - \max X_i) = 0) = 0\) because the distribution is continuous. However, in the bootstrap world, \(\max X_i^* = \max X_i\) whenever the sample maximum is selected at least once among the \(n\) bootstrap draws. The probability of this event is \(1 - (1 - 1/n)^n \to 1 - e^{-1} \approx 0.632\). Thus the bootstrap distribution places positive probability mass \(\approx 0.632\) at zero, whereas the true distribution has zero atom at zero. Thus the bootstrap fails.

Empirical

E1 · Bootstrap standard error comparison (Lab 1)

In Lab 1, compare the sample standard error \(0.1441\) with the bootstrap standard error across \(B = 2000\) resamples.

Solution

Lab 1 reports bootstrap standard error \(0.1431\), which matches the sample standard error \(0.1441\) to within \(0.0010\), confirming that the bootstrap accurately estimates the dispersion of the sample mean.

E2 · Percentile interval skewness (Lab 1)

In Lab 1, explain why the percentile bootstrap interval \([1.0079, 1.5869]\) is shifted to the right relative to the normal asymptotic interval \([1.0023, 1.5671]\).

Solution

The underlying data is drawn from a lognormal distribution, which is positively skewed. The bootstrap replicates capture this right-tail asymmetry, resulting in a higher upper bound (\(1.5869\) vs \(1.5671\)) and higher lower bound (\(1.0079\) vs \(1.0023\)).

E3 · Monte Carlo error of bootstrap

If \(B = 2000\) resamples are used to estimate a tail probability \(p = 0.025\), compute the Monte Carlo standard error of the estimated quantile probability.

Solution

The Monte Carlo standard error is \(\sqrt{p(1 - p) / B} = \sqrt{0.025 \times 0.975 / 2000} = \sqrt{0.024375 / 2000} \approx \sqrt{0.0000121875} \approx 0.00349\), or approximately \(0.35\%\).

Research

R1 · Studentized bootstrap (bootstrap-t)

Describe the Studentized bootstrap (bootstrap-t) method and explain why it achieves second-order accuracy \(\mathcal{O}(1/n)\) compared to the \(\mathcal{O}(1/\sqrt{n})\) accuracy of the percentile bootstrap.

Solution

The bootstrap-t resamples the asymptotically pivotal statistic \(t = (\hat\theta - \theta)/\widehat{\se}\), computing \(t^* = (\hat\theta^* - \hat\theta)/\widehat{\se}^*\). By approximating the distribution of a pivotal statistic, Hall (1988) proved that the bootstrap implicitly corrects for the leading Edgeworth expansion skewness term, improving coverage error from \(\mathcal{O}(1/\sqrt{n})\) to \(\mathcal{O}(1/n)\).

R2 · Moving block bootstrap for dependent returns

In quantitative trading, explain how the moving block bootstrap preserves short-term autocorrelation and volatility clustering that the standard i.i.d. bootstrap destroys.

Solution

Rather than resampling individual return observations, the moving block bootstrap resamples contiguous blocks of length \(\ell\) with replacement. Because observations within each block remain in their original temporal sequence, any autocorrelation or volatility persistence within time lag \(\ell\) is preserved.
