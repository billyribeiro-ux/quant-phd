Is a strategy's observed alpha genuine skill or mere luck? A hypothesis test formalizes decision-making under uncertainty by pitting a skeptical null hypothesis of zero edge against an alternative of positive outperformance. A p-value measures the exact probability of observing data at least as extreme as the realized sample if the null were true. Understanding exact versus asymptotic p-values and critical regions prevents disastrous over-allocation to spurious backtests.

1The statistical hypothesis testing framework

Let sample \(X = (X_1, \dots, X_n)\) have joint distribution indexed by parameter \(\theta \in \Theta\). The parameter space is partitioned into two disjoint subsets: the null hypothesis \(H_0: \theta \in \Theta_0\) and the alternative hypothesis \(H_1: \theta \in \Theta_1 = \Theta \setminus \Theta_0\). A hypothesis is simple if it specifies a single parameter value (\(\Theta_0 = \{\theta_0\}\)); otherwise it is composite.

Definition 1.1 (hypothesis test, test statistic, and critical region)

A hypothesis test is a decision rule that partitions the sample space \(\mathcal{X}\) into a rejection region (or critical region) \(R \subset \mathcal{X}\) and an acceptance region \(R^c\). If the observed sample \(X \in R\), the test rejects \(H_0\) in favor of \(H_1\); if \(X \notin R\), the test fails to reject \(H_0\). A non-randomized test is commonly defined by a real-valued test statistic \(T(X)\) and a threshold (critical value) \(c\): \[ R = \{x \in \mathcal{X} : T(x) \ge c\} \]

Definition 1.2 (size and significance level)

The rejection probability function (or power function) of a test with critical region \(R\) is: \[ \beta(\theta) = \Prob_\theta(X \in R) \] The size of the test is the supremum of the rejection probability over the null hypothesis: \[ \alpha = \sup_{\theta \in \Theta_0} \beta(\theta) = \sup_{\theta \in \Theta_0} \Prob_\theta(X \in R) \] A test is of significance level \(\alpha_0\) if its size satisfies \(\alpha \le \alpha_0\).

Example 1.3 (exact one-sided binomial test)

Consider evaluating an algorithmic trade signal over \(n = 20\) independent trades. Let \(K \sim \operatorname{Binomial}(n, p)\) be the number of profitable trades. We test \(H_0: p \le 1/2\) (no predictive skill) versus \(H_1: p > 1/2\) at nominal level \(\alpha = 0.05\). The test statistic is \(T(X) = K\), and the rejection region is \(R = \{k : k \ge c\}\). Under \(H_0\), the maximum rejection probability occurs at the boundary \(p = 1/2\). Because the binomial distribution is discrete, the rejection probabilities jump at integers: \[ \Prob_{1/2}(K \ge 14) = \sum_{k=14}^{20} \binom{20}{k}\left(\frac{1}{2}\right)^{20} = \frac{60460}{1048576} \approx 0.05766 > 0.05 \] \[ \Prob_{1/2}(K \ge 15) = \sum_{k=15}^{20} \binom{20}{k}\left(\frac{1}{2}\right)^{20} = \frac{21700}{1048576} = \frac{5425}{262144} \approx 0.020695 \le 0.05 \] To ensure the size does not exceed \(0.05\), the critical cutoff is \(c^* = 15\). The exact achieved size is \(\alpha^* = 5425/262144 \approx 0.0207\), strictly below nominal \(0.05\).

2The p-value

Definition 2.1 (p-value)

For an observed sample \(x\) and a family of tests with critical regions of the form \(\{y : T(y) \ge c\}\), the p-value \(p(x)\) is the smallest significance level \(\alpha\) at which the null hypothesis would be rejected given the data. Equivalently, it is the probability under \(H_0\) of obtaining a test statistic at least as extreme as the observed value \(T(x)\): \[ p(x) = \sup_{\theta \in \Theta_0} \Prob_\theta(T(X) \ge T(x)) \]

Proposition 2.2 (uniform distribution of continuous p-values under the null)

Let \(T(X)\) be a continuous test statistic with strictly increasing continuous cumulative distribution function \(F_0(t) = \Prob_{H_0}(T(X) \le t)\) under a simple null hypothesis. Then the p-value \(P = 1 - F_0(T(X))\) is distributed as \(\operatorname{Uniform}(0, 1)\) under \(H_0\): \[ \Prob_{H_0}(P \le u) = u \quad \text{for all } u \in [0, 1] \]

Proof

Since \(F_0\) is strictly increasing and continuous, the probability integral transform guarantees that \(U = F_0(T(X)) \sim \operatorname{Uniform}(0, 1)\). The p-value is \(P = 1 - F_0(T(X)) = 1 - U\). Since \(U\) is uniform on \([0, 1]\), \(1 - U\) is also uniformly distributed on \([0, 1]\): \[ \Prob_{H_0}(P \le u) = \Prob_{H_0}(1 - U \le u) = \Prob_{H_0}(U \ge 1 - u) = 1 - (1 - u) = u \] \(\blacksquare\)

Remark 2.3 (sub-uniformity in discrete models)

When the test statistic \(T(X)\) is discrete (as in the binomial test of Example 1.3), \(P\) takes only countably many values. The distribution function of \(P\) is a step function satisfying \(\Prob_{H_0}(P \le u) \le u\) for all \(u \in [0, 1]\). The test that rejects when \(P \le \alpha\) is conservative (its true size is strictly less than or equal to \(\alpha\)).

3The Neyman–Pearson lemma

How should a researcher construct the optimal test statistic? The fundamental Neyman–Pearson lemma establishes that the likelihood ratio maximizes statistical power for simple hypotheses.

Theorem 3.1 (Neyman–Pearson lemma)

Let \(H_0: \theta = \theta_0\) and \(H_1: \theta = \theta_1\) be simple hypotheses with densities \(f(x; \theta_0)\) and \(f(x; \theta_1)\). Consider a test with critical region \(R^*\) defined by the likelihood ratio: \[ R^* = \left\{x \in \mathcal{X} : \frac{f(x; \theta_1)}{f(x; \theta_0)} > k\right\} \] for constant \(k \ge 0\), with boundary randomization if necessary so that \(\Prob_{\theta_0}(X \in R^*) = \alpha\). Then for any other test with critical region \(R\) having size \(\Prob_{\theta_0}(X \in R) \le \alpha\), the power of \(R^*\) is at least that of \(R\): \[ \Prob_{\theta_1}(X \in R^*) \ge \Prob_{\theta_1}(X \in R) \]

Proof

Let \(\phi^*(x) = \indic(x \in R^*)\) and \(\phi(x) = \indic(x \in R)\). By construction of \(R^*\), for all \(x\): \[ (\phi^*(x) - \phi(x))(f(x; \theta_1) - k f(x; \theta_0)) \ge 0 \] To see this: if \(x \in R^*\), \(\phi^*(x) = 1 \ge \phi(x)\) and \(f(x; \theta_1) - k f(x; \theta_0) \ge 0\), so the product is \(\ge 0\). If \(x \notin R^*\), \(\phi^*(x) = 0 \le \phi(x)\) and \(f(x; \theta_1) - k f(x; \theta_0) \le 0\), so the product is \((-)(-) \ge 0\). Integrating over \(\mathcal{X}\): \[ \int (\phi^*(x) - \phi(x)) f(x; \theta_1) \, dx - k \int (\phi^*(x) - \phi(x)) f(x; \theta_0) \, dx \ge 0 \] Notice that \(\int \phi^*(x) f(x; \theta_1) \, dx = \Prob_{\theta_1}(X \in R^*)\) and \(\int \phi(x) f(x; \theta_1) \, dx = \Prob_{\theta_1}(X \in R)\). Likewise, \(\int (\phi^*(x) - \phi(x)) f(x; \theta_0) \, dx = \alpha - \Prob_{\theta_0}(X \in R) \ge 0\) because \(\Prob_{\theta_0}(X \in R) \le \alpha\). Since \(k \ge 0\): \[ \Prob_{\theta_1}(X \in R^*) - \Prob_{\theta_1}(X \in R) \ge k\left(\alpha - \Prob_{\theta_0}(X \in R)\right) \ge 0 \] Hence \(\Prob_{\theta_1}(X \in R^*) \ge \Prob_{\theta_1}(X \in R)\). \(\blacksquare\)

Lab 1 · Exact binomial test and p-value calculation

Hypothesis: For an exact binomial test of \(H_0: p = 1/2\) vs \(H_1: p > 1/2\) with \(n = 20\) at nominal level \(\alpha = 0.05\), the exact rejection threshold is \(c^* = 15\). The achieved test size is \(5425/262144 \approx 0.020695 \le 0.05\). For observed \(k = 15\), the exact p-value is \(0.020695\) (reject \(H_0\)); for \(k = 13\), the p-value is \(0.131588\) (fail to reject).

"""Lab S1-L04-1: Exact binomial hypothesis test and p-value calculation.

Evaluates an exact one-sided binomial test of H0: p = 1/2 vs H1: p > 1/2 for n = 20.
All probabilities and tail sums are computed in exact rational arithmetic using fractions.Fraction.
Standard library only. No external imports.
"""

from __future__ import annotations

import math
from fractions import Fraction


def binom_prob(n: int, k: int, p: Fraction) -> Fraction:
    """Exact binomial PMF P(K = k) = comb(n, k) * p^k * (1 - p)^(n - k)."""
    comb = math.comb(n, k)
    return Fraction(comb, 1) * (p**k) * ((1 - p) ** (n - k))


def main() -> None:
    n = 20
    p0 = Fraction(1, 2)
    alpha_nominal = Fraction(5, 100)

    # Compute PMF and upper tail probabilities P(K >= c) under H0
    pmf = [binom_prob(n, k, p0) for k in range(n + 1)]
    tail = [sum(pmf[k:]) for k in range(n + 1)]

    # Find rejection cutoff: smallest integer c such that P(K >= c) <= alpha_nominal
    c_star = next(c for c in range(n + 1) if tail[c] <= alpha_nominal)
    achieved_size = tail[c_star]

    print(f"sample size n: {n}, null parameter p0: {p0}")
    print(f"nominal significance level alpha: {alpha_nominal} ({float(alpha_nominal):.4f})")
    print(f"critical cutoff c*: {c_star}")
    print(f"achieved test size alpha*: {achieved_size} ({float(achieved_size):.6f})")
    print(f"achieved size <= nominal alpha: {achieved_size <= alpha_nominal}")
    print(f"tail prob at c* - 1 ({c_star - 1}): {tail[c_star - 1]} ({float(tail[c_star - 1]):.6f}) > nominal")

    # p-value calculations for observed data
    k_obs1 = 15  # Rejects at c* = 15
    pval_1 = tail[k_obs1]
    k_obs2 = 13  # Fails to reject
    pval_2 = tail[k_obs2]

    print(f"observed k = {k_obs1}: p-value = {pval_1} ({float(pval_1):.6f}), reject H0: {pval_1 <= alpha_nominal}")
    print(f"observed k = {k_obs2}: p-value = {pval_2} ({float(pval_2):.6f}), reject H0: {pval_2 <= alpha_nominal}")


main()
sample size n: 20, null parameter p0: 1/2
nominal significance level alpha: 1/20 (0.0500)
critical cutoff c*: 15
achieved test size alpha*: 5425/262144 (0.020695)
achieved size <= nominal alpha: True
tail prob at c* - 1 (14): 15115/262144 (0.057659) > nominal
observed k = 15: p-value = 5425/262144 (0.020695), reject H0: True
observed k = 13: p-value = 34495/262144 (0.131588), reject H0: False

Interpretation: The exact computation in rational arithmetic demonstrates the discrete nature of significance testing. The p-value precisely matches the achieved size at the boundary \(k = 15\), confirming that the p-value is the smallest level at which \(H_0\) is rejected.

4Where the canon breaks

The classical p-value interpretation assumes that exactly one pre-specified hypothesis is evaluated on an independent sample. In quantitative finance, backtesting routinely searches over hundreds or thousands of parameter combinations, feature sets, and trading rules (data snooping). When 1,000 independent useless strategies are tested at \(\alpha = 0.05\), the probability of observing at least one false positive ("significant" p-value \(< 0.05\)) is \(1 - (1 - 0.05)^{1000} \approx 1.0\). A naive p-value without multiple testing adjustment is meaningless in a search environment.

Misconceptions

  • A p-value is the probability that the null hypothesis is true.

    Correction: The p-value is \(\Prob(\text{data at least as extreme} \mid H_0)\), not \(\Prob(H_0 \mid \text{data})\). In classical frequentist inference, parameters are fixed constants, not random variables, so \(\Prob(H_0)\) is undefined without a Bayesian prior.

  • Failing to reject the null hypothesis proves that the null is true.

    Correction: "Absence of evidence is not evidence of absence." Failing to reject simply means the observed data is not inconsistent with the null; the test may merely lack statistical power due to small sample size.

  • A small p-value implies a large economic effect.

    Correction: Statistical significance is distinct from economic significance. With large sample sizes (e.g. high-frequency tick data), an economically negligible Sharpe ratio of \(0.01\) can produce an astronomically small p-value (\(p < 10^{-10}\)) despite being completely un-tradable after transaction costs.

Problem set

Mechanics

M1 · One-sided z-test p-value

A sample of \(n = 100\) i.i.d. daily returns with known volatility \(\sigma = 0.02\) yields sample mean \(\bar X = 0.004\). Test \(H_0: \mu \le 0\) vs \(H_1: \mu > 0\). Compute the z-statistic and the exact p-value.

Solution

The standard error of the sample mean is \(\sigma / \sqrt{n} = 0.02 / 10 = 0.002\). The test statistic is \(z = \frac{\bar X - 0}{\sigma / \sqrt{n}} = \frac{0.004}{0.002} = 2.00\). The one-sided p-value is \(1 - \Phi(2.00) \approx 1 - 0.97725 = 0.02275\). At significance level \(\alpha = 0.05\), we reject \(H_0\) since \(p = 0.02275 < 0.05\).

M2 · Two-sided z-test critical value

For a two-sided test \(H_0: \mu = \mu_0\) vs \(H_1: \mu \ne \mu_0\) at significance level \(\alpha = 0.01\) under normality, state the critical value and rejection region in terms of \(\Phi^{-1}\).

Solution

The two-sided test divides the rejection probability equally between both tails (\(\alpha/2 = 0.005\)). The upper critical value is \(c = \Phi^{-1}(1 - \alpha/2) = \Phi^{-1}(0.995) \approx 2.5758\). The rejection region is \(|Z| \ge \Phi^{-1}(0.995)\), or equivalently \(Z \le -2.5758\) or \(Z \ge 2.5758\).

M3 · Exact binomial upper tail calculation

Let \(K \sim \operatorname{Binomial}(10, 1/2)\). Compute the exact probability \(\Prob(K \ge 8)\) in rational arithmetic.

Solution

\(\Prob(K \ge 8) = \Prob(K = 8) + \Prob(K = 9) + \Prob(K = 10)\). The total number of outcomes is \(2^{10} = 1024\). \(\binom{10}{8} = 45\), \(\binom{10}{9} = 10\), \(\binom{10}{10} = 1\). Sum is \(45 + 10 + 1 = 56\). Probability is \(\frac{56}{1024} = \frac{7}{128} \approx 0.0546875\).

P1 · Monotonicity of the binomial power function

Let \(K \sim \operatorname{Binomial}(n, p)\). For fixed integer cutoff \(c \in \{1, \dots, n\}\), prove that the rejection probability \(\beta(p) = \Prob_p(K \ge c)\) is strictly increasing in \(p\) on \((0, 1)\).

Solution

Express the binomial tail using the incomplete beta integral identity: \(\Prob_p(K \ge c) = \frac{n!}{(c-1)!(n-c)!}\int_0^p u^{c-1}(1 - u)^{n-c} \, du\). Differentiating with respect to \(p\) via the fundamental theorem of calculus: \(\frac{d\beta(p)}{dp} = \frac{n!}{(c-1)!(n-c)!} p^{c-1}(1 - p)^{n-c}\). Since \(p \in (0, 1)\), the integrand is strictly positive for all \(u \in (0, 1)\), so \(\frac{d\beta(p)}{dp} > 0\). Thus \(\beta(p)\) is strictly increasing in \(p\).

P2 · Uniformly most powerful test for normal mean

Let \(X_1, \dots, X_n\) be i.i.d. \(\mathcal{N}(\mu, \sigma^2)\) with known \(\sigma^2\). Use the Neyman–Pearson lemma to prove that the test rejecting when \(\bar X \ge \mu_0 + z_{1-\alpha}\frac{\sigma}{\sqrt{n}}\) is Uniformly Most Powerful (UMP) for \(H_0: \mu \le \mu_0\) vs \(H_1: \mu > \mu_0\).

Solution

For any fixed alternative \(\mu_1 > \mu_0\), consider testing the simple hypotheses \(\mu = \mu_0\) vs \(\mu = \mu_1\). The likelihood ratio is \(\frac{L(\mu_1)}{L(\mu_0)} = \exp\left(-\frac{1}{2\sigma^2}\sum(X_i - \mu_1)^2 + \frac{1}{2\sigma^2}\sum(X_i - \mu_0)^2\right) = \exp\left(\frac{\mu_1 - \mu_0}{\sigma^2}\sum X_i - \frac{n(\mu_1^2 - \mu_0^2)}{2\sigma^2}\right)\). Since \(\mu_1 > \mu_0\), this ratio is a strictly increasing function of \(\sum X_i\) (or \(\bar X\)). By the Neyman–Pearson lemma (Theorem 3.1), the most powerful test rejects when \(\bar X \ge c\). To achieve size \(\alpha\) under \(\mu_0\), \(c = \mu_0 + \Phi^{-1}(1 - \alpha)\frac{\sigma}{\sqrt{n}}\). Since this critical region depends only on \(\mu_0\) and \(\alpha\), and not on the specific value of \(\mu_1 > \mu_0\), it is Uniformly Most Powerful against all \(\mu > \mu_0\).

P3 · Conservatism of discrete p-values

Let \(T\) be a discrete random variable under \(H_0\) taking values \(t_1 < t_2 < \dots < t_m\) with probabilities \(p_j = \Prob(T = t_j) > 0\). Prove that the p-value \(P = \Prob_{H_0}(T \ge T_{\mathrm{obs}})\) satisfies \(\Prob_{H_0}(P \le \alpha) \le \alpha\) for all \(\alpha \in [0, 1]\).

Solution

Let \(q_k = \Prob_{H_0}(T \ge t_k) = \sum_{j=k}^m p_j\). The possible values of \(P\) are \(q_1 = 1 > q_2 > \dots > q_m = p_m > 0\). For any \(\alpha \in [0, 1]\), if \(\alpha < q_m\), then \(\{P \le \alpha\} = \emptyset\), so \(\Prob(P \le \alpha) = 0 \le \alpha\). Otherwise, let \(k^*\) be the smallest index such that \(q_k \le \alpha\). Then \(P \le \alpha\) if and only if \(T \ge t_{k^*}\). Thus \(\Prob_{H_0}(P \le \alpha) = \Prob_{H_0}(T \ge t_{k^*}) = q_{k^*}\). By definition of \(k^*\), \(q_{k^*} \le \alpha\). Therefore, \(\Prob_{H_0}(P \le \alpha) \le \alpha\) for all \(\alpha\).

Empirical

E1 · Achieved size comparison (Lab 1)

In Lab 1, the achieved size of the binomial test at \(c^* = 15\) is \(\alpha^* = 5425/262144 \approx 0.020695\). What would the achieved size be if the cutoff were lowered to \(c = 14\)?

Solution

At \(c = 14\), we add \(\binom{20}{14}(1/2)^{20} = 38760 / 1048576\) to \(\alpha^*\). Total is \(21700 + 38760 = 60460 / 1048576 \approx 0.05766\). Since \(0.05766 > 0.05\), setting \(c = 14\) would violate the nominal \(5\%\) significance level guarantee.

E2 · p-value for k = 14 (Lab 1)

Compute the exact p-value if an experiment in Lab 1 observed \(k = 14\) successes in 20 trials.

Solution

The p-value is the upper tail probability \(\Prob_{1/2}(K \ge 14) = 60460 / 1048576 = 15115 / 262144 \approx 0.05766\). Since \(0.05766 > 0.05\), we fail to reject \(H_0\) at level 0.05.

E3 · Ratio of p-values (Lab 1)

Compute the ratio of the p-value for \(k = 15\) to the p-value for \(k = 16\) in Lab 1.

Solution

For \(k = 15\), tail is \(21700 / 1048576\). For \(k = 16\), tail drops \(\binom{20}{15} = 15504\), leaving \(21700 - 15504 = 6196 / 1048576\). The ratio is \(21700 / 6196 \approx 3.502\). Each additional success substantially shrinks the p-value by more than a factor of 3 in the extreme tail.

Research

R1 · Multiple testing and the Bonferroni inequality

Suppose an investment firm evaluates \(m\) independent strategy backtests, testing each at level \(\alpha_{\mathrm{ind}}\). Prove that setting \(\alpha_{\mathrm{ind}} = \alpha / m\) guarantees that the family-wise error rate (probability of at least one false discovery) is at most \(\alpha\).

Solution

Let \(E_i\) be the event that test \(i\) rejects under \(H_{0,i}\), so \(\Prob(E_i) \le \alpha / m\). The family-wise error rate is \(\Prob(\bigcup_{i=1}^m E_i)\). By Boole's inequality (union bound): \(\Prob(\bigcup_{i=1}^m E_i) \le \sum_{i=1}^m \Prob(E_i) \le \sum_{i=1}^m \frac{\alpha}{m} = m \left(\frac{\alpha}{m}\right) = \alpha\). Thus the Bonferroni correction controls FWER at level \(\alpha\).

R2 · Randomized tests for discrete distributions

Explain how a randomized test achieves exact size \(\alpha = 0.05\) in the binomial setting of Example 1.3, and state why practitioners avoid randomized decisions.

Solution

To hit \(\alpha = 0.05\) exactly: reject if \(K \ge 15\), accept if \(K \le 13\), and if \(K = 14\), reject with probability \(\gamma = \frac{\alpha - \Prob(K \ge 15)}{\Prob(K = 14)} = \frac{0.05 - 0.020695}{0.036965} \approx 0.7928\). Then \(\Prob(\text{reject}) = \Prob(K \ge 15) + \gamma \Prob(K = 14) = 0.05\) exactly. Practitioners avoid randomized tests because capital allocation decisions should not hinge on the toss of an extraneous coin unrelated to the underlying market.

R3 · p-hacking and publication bias

Describe how "data snooping" distorts the distribution of reported p-values in empirical asset pricing literature.

Solution

Under a true null hypothesis, Proposition 2.2 proves that valid p-values follow \(\operatorname{Uniform}(0, 1)\). If researchers run \(m\) variations and report only \(\min_{1 \le j \le m} P_j\), the reported statistic is an order statistic with distribution \(\Prob(\min P_j \le u) = 1 - (1 - u)^m \approx m u\) for small \(u\). The reported p-values exhibit extreme concentration just below the \(0.05\) threshold, producing the classic "p-hacking" cliff documented by Harvey, Liu, and Zhu (2016).
