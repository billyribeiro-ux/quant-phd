Rung 1 · Worked Example

The pairs-trading audit evaluates whether two candidate assets share a genuine stationary equilibrium relationship or merely exhibit spurious correlation. We estimate the formation hedge ratio \(\hat{\beta}\), evaluate the Engle-Granger residual test statistic against the 5% Monte Carlo critical value \(-3.3378\), compute the out-of-sample trading spread, and evaluate the mean-reversion half-life.

A planted cointegrated pair on 400 observations rejects the null of no cointegration (t < -3.3378) on the formation window and demonstrates a finite mean-reversion half-life on the trading window.

"""Lab S3-project-1: Rung 1 worked example for pairs-trading audit.

SIMULATED: complete worked audit of a seeded cointegration candidate pair.
"""

from __future__ import annotations

import math
import random


def ols_1d(y: list[float], x: list[float]) -> tuple[float, float]:
    m = len(y)
    mx = sum(x) / m
    my = sum(y) / m
    cov = sum((x[i] - mx) * (y[i] - my) for i in range(m))
    var_x = sum((x[i] - mx) ** 2 for i in range(m))
    beta = cov / var_x
    alpha = my - beta * mx
    return alpha, beta


def eg_statistic(y: list[float], x: list[float], split: int) -> float:
    a, b = ols_1d(y[:split], x[:split])
    u = [y[t] - a - b * x[t] for t in range(split)]
    m = len(u)
    du = [u[i] - u[i - 1] for i in range(1, m)]
    y_dep = du[1:]
    x0 = [u[t - 1] for t in range(2, m)]
    x1 = [du[t - 2] for t in range(2, m)]
    n_obs = len(y_dep)

    s00 = sum(x0[r] * x0[r] for r in range(n_obs))
    s01 = sum(x0[r] * x1[r] for r in range(n_obs))
    s11 = sum(x1[r] * x1[r] for r in range(n_obs))
    det = s00 * s11 - s01 * s01
    inv00 = s11 / det
    inv01 = -s01 / det
    sy0 = sum(x0[r] * y_dep[r] for r in range(n_obs))
    sy1 = sum(x1[r] * y_dep[r] for r in range(n_obs))
    gamma = inv00 * sy0 + inv01 * sy1
    delta = inv01 * sy0 + (s00 / det) * sy1

    res = [y_dep[r] - gamma * x0[r] - delta * x1[r] for r in range(n_obs)]
    rss = sum(r * r for r in res)
    sigma2 = rss / (n_obs - 2)
    se_gamma = math.sqrt(sigma2 * inv00)
    return gamma / se_gamma


def half_life(spread: list[float]) -> float:
    y = spread[1:]
    x = spread[:-1]
    _, phi = ols_1d(y, x)
    if phi <= 0.0:
        raise ValueError("phi <= 0")
    if phi >= 1.0:
        return math.inf
    return math.log(2.0) / (-math.log(phi))


def main() -> None:
    rng = random.Random(42)
    n = 400
    split = 240
    eg_crit_5pct = -3.3378

    # Generate synthetic cointegrated pair
    rw = [0.0]
    for _ in range(n - 1):
        rw.append(rw[-1] + rng.gauss(0.0, 1.0))
    x = [50.0 + rw[t] for t in range(n)]
    s = [0.0]
    for _ in range(n - 1):
        s.append(0.75 * s[-1] + rng.gauss(0.0, 0.5))
    y = [2.0 + 1.2 * x[t] + s[t] for t in range(n)]

    # Step 1: Formation hedge ratio
    alpha, beta = ols_1d(y[:split], x[:split])

    # Step 2: Engle-Granger test on formation window
    eg_stat = eg_statistic(y, x, split)
    eg_pass = eg_stat < eg_crit_5pct

    # Step 3: Out-of-sample trading spread and half-life
    trading_spread = [y[t] - alpha - beta * x[t] for t in range(split, n)]
    hl = half_life(trading_spread)
    hl_finite = math.isfinite(hl)

    # Step 4: Final survival verdict
    pair_survives = eg_pass and hl_finite

    print("Pairs-Trading Audit: Worked Example (SIMULATED):")
    print(f"  Sample size: n={n} (Formation split={split}, Trading={n - split})")
    print(f"  Step 1 Formation OLS: alpha = {alpha:.4f}, beta = {beta:.4f}")
    print(f"  Step 2 EG residual t-statistic: {eg_stat:.4f} (5% critical value: {eg_crit_5pct:.4f})")
    print(f"         EG null rejected (cointegrated): {eg_pass}")
    print(f"  Step 3 Trading spread half-life: {hl:.2f} business days (finite: {hl_finite})")
    print(f"  Step 4 Audit verdict: Pair survives = {pair_survives}")

Context
Quantitative trading desks routinely construct pairs-trading strategies based on co-movement of asset prices. However, simple correlation in levels is notoriously vulnerable to spurious regression. To prevent disastrous capital allocation to non-stationary drifting spreads, an econometric auditor must verify cointegration using exact residual critical values and ensure mean-reversion stability out of sample.

1. fx_daily.csv (Federal Reserve H.10 / G.5 noon buying rates): 6,706 daily observations from 2000-01-03 to 2026-09-30 for six major currencies (AUD, CAD, CHF, EUR, GBP, JPY), expressed as USD per unit of foreign currency. Log exchange rates are used throughout.

    u = [y[t] - alpha - beta * x[t] for t in range(split)]
    m = len(u)
    du = [u[i] - u[i - 1] for i in range(1, m)]
    y_dep = du[1:]
    x0 = [u[t - 1] for t in range(2, m)]
    x1 = [du[t - 2] for t in range(2, m)]
    n_obs = len(y_dep)

    s00 = sum(x0[r] * x0[r] for r in range(n_obs))
    s01 = sum(x0[r] * x1[r] for r in range(n_obs))
    s11 = sum(x1[r] * x1[r] for r in range(n_obs))
    det = s00 * s11 - s01 * s01
    inv00 = s11 / det
    inv01 = -s01 / det
    sy0 = sum(x0[r] * y_dep[r] for r in range(n_obs))
    sy1 = sum(x1[r] * y_dep[r] for r in range(n_obs))
    gamma = inv00 * sy0 + inv01 * sy1
    delta = inv01 * sy0 + (s00 / det) * sy1

    res = [y_dep[r] - gamma * x0[r] - delta * x1[r] for r in range(n_obs)]
    rss = sum(r * r for r in res)
    sigma2 = rss / (n_obs - 2)
    se_gamma = math.sqrt(sigma2 * inv00)
    return gamma / se_gamma


def half_life(spread: list[float]) -> float:
    y = spread[1:]
    x = spread[:-1]
    _, phi = ols_1d(y, x)
    if phi <= 0.0:
        raise ValueError("phi <= 0")
    if phi >= 1.0:
        return math.inf
    return math.log(2.0) / (-math.log(phi))


def main() -> None:
    data_path = Path("data") / "fx_daily.csv"
    with data_path.open(encoding="utf-8") as f:
        reader = csv.DictReader(f)
        rows = list(reader)

    currencies = ["AUD", "CAD", "CHF", "EUR", "GBP", "JPY"]
    n = len(rows)
    split = math.floor(0.6 * n)  # 4023

    log_rates = {c: [math.log(float(r[c])) for r in rows] for c in currencies}

    for i in range(len(currencies)):

                f"{c1}/{c2:3s} |     {alpha:7.4f}     |    {beta:7.4f}   |"
                f"   {stat:6.4f}  |     {hl_str}      |  {survives}"
            )

    print("-" * 75)
    print(f"Total surviving pairs: {survivor_count} / 15")

Exemplar A (Level 4: Exemplary)

Memorandum: Econometric Audit of Foreign Exchange Pairs Trading

To: Quantitative Investment Committee
From: Senior Econometric Auditor
Date: October 2026
Subject: Coin-tegration and Out-of-Sample Persistence Audit of Federal Reserve H.10 FX Rates

1. Data and Sample Partition

We audit daily noon buying rates in New York from the Federal Reserve Board H.10 release (fx_daily.csv) spanning 6,706 trading days from January 3, 2000 to September 30, 2026. The universe consists of six major currencies quoted as USD per unit of foreign currency: Australian Dollar (AUD), Canadian Dollar (CAD), Swiss Franc (CHF), Euro (EUR), British Pound (GBP), and Japanese Yen (JPY). All rates are analyzed in natural logarithms. The sample is strictly partitioned chronologically: the first 60% of observations (\(T_{\text{form}} = 4,023\) trading days, ending March 2016) serves as the formation window for cointegrating vector estimation; the remaining 40% (\(T_{\text{trade}} = 2,683\) trading days) serves as the un-snooped out-of-sample trading window.

2. Econometric Methodology and Precomputed Critical Values

For each of the \(\binom{6}{2} = 15\) unique currency pairs \((y_t, x_t)\), we estimate the formation cointegrating regression \(y_t = \alpha + \beta x_t + u_t\) via ordinary least squares. We test for cointegration by evaluating the Augmented Dickey-Fuller statistic on the formation residuals \(\hat{u}_t\) with no intercept and fixed lag augmentation \(p = 1\): \[ \Delta \hat{u}_t = \gamma \hat{u}_{t-1} + \delta_1 \Delta \hat{u}_{t-1} + \varepsilon_t. \] Because OLS selects \(\hat{\alpha}\) and \(\hat{\beta}\) to minimize residual sum of squares, the residuals \(\hat{u}_t\) are spuriously more stationary than a generic random walk. Consequently, standard Dickey-Fuller critical values (\(-2.8611\) at 5%) severely over-reject the null of no cointegration. We employ the precomputed Engle-Granger 5% critical value of \(-3.3287\), established via 20,000 Monte Carlo replications for \(T = 4,023\).

3. Out-of-Sample Spread Dynamics and Half-Life

Using the locked formation parameters \((\hat{\alpha}, \hat{\beta})\), we construct the out-of-sample trading spread \(s_t = y_t - \hat{\alpha} - \hat{\beta} x_t\) for \(t \ge 4,023\). Spread persistence is estimated via AR(1) regression \(s_t = c + \phi s_{t-1} + e_t\), yielding the continuous mean-reversion half-life \(h^* = \ln 2 / (-\ln \hat{\phi})\) in business days. Any pair exhibiting \(\hat{\phi} \ge 1\) is assigned \(h^* = \infty\).

4. Empirical Findings and Multiplicity Analysis

Across the entire 15-pair universe, exactly zero pairs survive the econometric audit. The most negative formation Engle-Granger statistic was observed for AUD/CAD at \(-3.1670\), which fails to breach the \(-3.3287\) barrier. All other pairs exhibited statistics ranging between \(-0.5546\) (CHF/EUR) and \(-2.7097\) (CAD/EUR). Furthermore, on the out-of-sample trading window, the CHF/JPY spread experienced a regime drift yielding \(\hat{\phi} \ge 1\) (\(h^* = \infty\)).

In a multiplicity context, conducting 15 independent tests at a 5% significance level would yield an expected false positive rate of \(15 \times 0.05 = 0.75\) spurious cointegrated pairs. Given that the 15 pairs share underlying currencies and are strongly cross-correlated, the effective independent test count is lower, further affirming that the complete absence of rejections reflects genuine economic non-stationarity.

5. Economic Constraints and Risk Verdict

We advise the investment committee that pairs-trading models fitted to spot exchange rate levels without accounting for interest rate differentials (uncovered interest parity dynamics) are economically misspecified. Spot FX rates represent non-stationary drift processes; without holding yield differentials, any apparent mean-reversion is transient. Capital deployment into spot currency pairs trading is strongly rejected.

Exemplar B (Level 2: Developing)

Memo: FX Pairs Trading Review

We ran regressions on FX data to find cointegrated pairs for our strategy. We looked at daily currencies like AUD, CAD, EUR, GBP, JPY, and CHF from 2000 to 2026. We split the data into a training window and a testing window.

We regressed the currencies on each other and tested the residuals with an ADF test. Some pairs like AUD/CAD had t-stats around -3.16, which is pretty negative. If you use a normal t-distribution critical value of -1.96, almost all pairs look cointegrated! But if we use a tougher cutoff like -3.3, none of the pairs make it.

The half-lives of the spreads varied widely. Some had half-lives of 100 days, while CHF/JPY kept trending away. Because none of the pairs passed the -3.3 cutoff, we don't recommend trading these currency pairs right now.

Caveats: trading currencies has transaction costs and slippage, and markets change over time.
