The Engle-Granger Test and the Half-Life of Mean Reversion

Two-Step Residual Testing, Non-Standard Critical Thresholds, and Statistical Arbitrage Persistence

Why It Matters

Testing whether two asset prices are cointegrated requires evaluating whether their estimated residual spread is stationary. However, testing estimated residuals is fundamentally different from testing raw data: first-stage OLS deliberately minimizes residual variance, artificially shifting the test statistic negative. Understanding the Engle-Granger two-step procedure and measuring the half-life of mean reversion allows quantitative researchers to filter out transient noise and identify tradable stationary spreads.

1. The Engle-Granger Two-Step Cointegration Test

Definition 6.1 · Engle–Granger Two-Step Test

The Engle–Granger two-step test assesses the null hypothesis of no cointegration between two \(I(1)\) time series \(y_t\) and \(x_t\) using a sequential procedure:

  1. Step 1 (Cointegrating Regression): Estimate the long-run relation by OLS with an intercept: \[ y_t = \alpha + \beta x_t + u_t, \] yielding estimated residuals \(\hat{u}_t = y_t - \hat{\alpha} - \hat{\beta} x_t\).
  2. Step 2 (Residual Unit Root Test): Run an Augmented Dickey–Fuller test on the residuals with no intercept: \[ \Delta \hat{u}_t = \gamma \hat{u}_{t-1} + \sum_{j=1}^p \delta_j \Delta \hat{u}_{t-j} + \varepsilon_t. \] The test statistic is \(t_\gamma = \hat{\gamma} / \operatorname{SE}(\hat{\gamma})\). The null hypothesis \(H_0: \gamma = 0\) (residuals are \(I(1)\), no cointegration) is rejected in favor of cointegration if \(t_\gamma < t_{\text{crit}}\).
Remark 6.1 · Why Residual Critical Values Differ from Dickey-Fuller Values

Engle and Granger (1987) demonstrated that the t-statistic on OLS residuals does not follow the standard Dickey-Fuller distribution. Because OLS selects \((\hat{\alpha}, \hat{\beta})\) to minimize \(\sum \hat{u}_t^2\), the residuals \(\hat{u}_t\) are biased toward appearing stationary even under the null of independent random walks. Consequently, the limiting distribution is pushed further into the negative tail:

  • Standard Dickey-Fuller 5% critical value (with constant): \(\approx -2.86\).
  • Engle-Granger 5% critical value (2 variables, constant): \(\approx -3.34\).

Using standard Dickey-Fuller critical values for residual cointegration testing produces massive false positive discovery rates.

2. The Half-Life of Mean Reversion

Definition 6.2 · Half-Life of Mean Reversion

For a continuous or discrete-time stationary spread process, the half-life of mean reversion \(h^*\) is the expected time required for a unit deviation from equilibrium to decay by 50%:

\[ \frac{\mathbb{E}[s_{t+h^*} - \mu \mid s_t]}{\mathbb{E}[s_t - \mu]} = \frac{1}{2}. \]
Theorem 6.1 · Half-Life Formula for Discrete AR(1) Dynamics

Assumptions:

  1. The spread follows an AR(1) process \(s_t = c + \phi s_{t-1} + e_t\).
  2. The persistence coefficient satisfies \(0 < \phi < 1\).

Conclusion: The mean-reversion half-life is uniquely given in periods by:

\[ h^* = \frac{\ln(2)}{-\ln(\phi)}. \]

Boundary Cases:

  • If \(\phi \ge 1\), the spread is non-stationary and \(h^* = \infty\).
  • If \(\phi \le 0\), the process exhibits negative persistence (alternating sign oscillations) and the continuous half-life is undefined (raises ValueError).
Proof

By recursive expectation, the conditional deviation at horizon \(h\) satisfies \(\mathbb{E}[s_{t+h} - \mu \mid s_t] = \phi^h (s_t - \mu)\). Setting the ratio of expected deviation to initial deviation equal to \(1/2\) yields:

\[ \phi^{h^*} = \frac{1}{2}. \]

Taking natural logarithms on both sides gives \(h^* \ln(\phi) = \ln(1/2) = -\ln(2)\). Since \(0 < \phi < 1\), \(\ln(\phi) < 0\). Dividing by \(\ln(\phi)\) yields \(h^* = -\ln(2) / \ln(\phi) = \ln(2) / (-\ln \phi) > 0\).

Example 6.1 · Half-Life Evaluation in Trading Days

Consider an equity pairs spread estimated on daily closing prices with \(\hat{\phi} = 0.95\). The half-life in trading days is:

\[ h^* = \frac{\ln 2}{-\ln(0.95)} \approx \frac{0.69315}{0.05129} \approx 13.51 \text{ business days}. \]

If \(\hat{\phi} = 0.99\), \(h^* = \ln 2 / (-\ln 0.99) \approx 68.97\) business days (~3.3 calendar months). High persistence drastically prolongs trade holding duration.

3. Numerical Verification

We execute Lab 1 to verify the half-life formula on an exact noiseless exponential decay path and on a seeded AR(1) spread process.

Lab 1 · Noiseless Half-Life and Engle-Granger Two-Step Verification

Verifies that the OLS half-life estimator on a noiseless path s_t = 0.9^t equals ln(2)/(-ln(0.9)) ~ 6.5788 to 1e-6, estimates half-life on a seeded AR(1) spread, and demonstrates that a cointegrated pair rejects the EG test while independent random walks fail.

"""Lab S3-L06-1: Engle-Granger test and mean-reversion half-life.

Exact for noiseless exponential decay; SIMULATED for seeded AR(1) spread
and Engle-Granger two-step cointegration test.
"""

from __future__ import annotations

import math
import random


def ols_slope(y: list[float], x: list[float]) -> tuple[float, float]:
    m = len(y)
    mx = sum(x) / m
    my = sum(y) / m
    cov = sum((x[i] - mx) * (y[i] - my) for i in range(m))
    var_x = sum((x[i] - mx) ** 2 for i in range(m))
    beta = cov / var_x
    alpha = my - beta * mx
    return alpha, beta


def half_life(spread: list[float]) -> float:
    y = spread[1:]
    x = spread[:-1]
    _, phi = ols_slope(y, x)
    if phi <= 0.0:
        raise ValueError("phi <= 0")
    if phi >= 1.0:
        return math.inf
    return math.log(2.0) / (-math.log(phi))


def eg_residual_t(y: list[float], x: list[float]) -> float:
    alpha, beta = ols_slope(y, x)
    u = [y[t] - alpha - beta * x[t] for t in range(len(y))]
    # ADF without intercept, lags = 1
    m = len(u)
    du = [u[i] - u[i - 1] for i in range(1, m)]
    y_dep = du[1:]
    x0 = [u[t - 1] for t in range(2, m)]
    x1 = [du[t - 2] for t in range(2, m)]
    n_obs = len(y_dep)

    s00 = sum(x0[r] * x0[r] for r in range(n_obs))
    s01 = sum(x0[r] * x1[r] for r in range(n_obs))
    s11 = sum(x1[r] * x1[r] for r in range(n_obs))
    det = s00 * s11 - s01 * s01
    inv00 = s11 / det
    inv01 = -s01 / det
    sy0 = sum(x0[r] * y_dep[r] for r in range(n_obs))
    sy1 = sum(x1[r] * y_dep[r] for r in range(n_obs))
    gamma = inv00 * sy0 + inv01 * sy1
    delta = inv01 * sy0 + (s00 / det) * sy1

    res = [y_dep[r] - gamma * x0[r] - delta * x1[r] for r in range(n_obs)]
    rss = sum(r * r for r in res)
    sigma2 = rss / (n_obs - 2)
    se_gamma = math.sqrt(sigma2 * inv00)
    return gamma / se_gamma


def main() -> None:
    # 1. Noiseless exponential decay
    noiseless_path = [0.90**t for t in range(50)]
    hl_noiseless = half_life(noiseless_path)
    hl_exact = math.log(2.0) / (-math.log(0.90))

    print("Part 1: Exact Noiseless Half-Life Verification:")
    print(f"  Theoretical half-life for phi=0.90: {hl_exact:.6f} periods")
    print(f"  Estimated half-life from path:      {hl_noiseless:.6f} periods")
    print(f"  Absolute discrepancy:               {abs(hl_noiseless - hl_exact):.2e}")

    # 2. Seeded AR(1) spread
    rng = random.Random(42)
    n = 600
    phi_true = 0.85
    s = [0.0]
    for _ in range(n - 1):
        s.append(phi_true * s[-1] + rng.gauss(0.0, 1.0))

    _, phi_hat = ols_slope(s[1:], s[:-1])
    hl_hat = half_life(s)
    hl_true = math.log(2.0) / (-math.log(phi_true))

    print("\nPart 2: Seeded AR(1) Spread (T=600, true phi=0.85, seed=42):")
    print(f"  True half-life:      {hl_true:.4f} periods")
    print(f"  Estimated phi:       {phi_hat:.4f}")
    print(f"  Estimated half-life: {hl_hat:.4f} periods")

    # 3. Engle-Granger test comparison
    rw = [0.0]
    for _ in range(n - 1):
        rw.append(rw[-1] + rng.gauss(0.0, 1.0))
    x_coint = [rw[t] + rng.gauss(0.0, 0.5) for t in range(n)]
    y_coint = [1.5 * x_coint[t] + s[t] for t in range(n)]

    rw_indep = [0.0]
    for _ in range(n - 1):
        rw_indep.append(rw_indep[-1] + rng.gauss(0.0, 1.0))

    eg_coint = eg_residual_t(y_coint, x_coint)
    eg_indep = eg_residual_t(rw, rw_indep)

    print("\nPart 3: Engle-Granger 2-Step Test (5% critical value ~ -3.34):")
    print(f"  Cointegrated pair EG t-statistic: {eg_coint:.4f} (rejects null of no cointegration)")
    print(f"  Independent pair EG t-statistic:  {eg_indep:.4f} (fails to reject)")


main()

Where the Canon Breaks

Applying the Engle-Granger procedure and half-life formulas in quantitative finance reveals severe structural limitations:

  • Normalization direction dependence: Regressing \(y_t\) on \(x_t\) does not produce the inverse slope of regressing \(x_t\) on \(y_t\) (\(\hat{\beta}_{y|x} \ne 1/\hat{\beta}_{x|y}\)). In finite samples, the Engle-Granger test can reject cointegration when \(y\) is the dependent variable but fail to reject when \(x\) is the dependent variable! Multivariate Johansen testing (Lesson 7) solves this asymmetry.
  • Out-of-sample half-life instability: A spread with a tight in-sample half-life of 5 days frequently experiences parameter drift out of sample, extending to \(h^* = \infty\) (unit root breakdown). Static hedge ratios guarantee eventual strategy drawdown.
  • Asymmetric mean reversion: Real market spreads mean-revert faster when widening (panic liquidation) than when narrowing (gradual capital redeployment), violating linear AR(1) symmetry.

Misconceptions

  • Wrong belief: The half-life of mean reversion is identical to the lag-1 autocorrelation.

    Why it is wrong: The lag-1 autocorrelation \(\phi\) is a dimensionless correlation coefficient in \([-1, 1]\). The half-life \(h^* = \ln 2 / (-\ln \phi)\) is a temporal duration expressed in physical time units (business days, hours, or months).

  • Wrong belief: A statistically significant Engle-Granger test implies that pairs trading will be profitable.

    Why it is wrong: Statistical rejection of a unit root only guarantees that the spread is covariance-stationary. If transaction costs, borrow fees, and execution slippage exceed the equilibrium spread amplitude, expected trading P&L is strictly negative.

  • Wrong belief: The residual ADF regression in step 2 should include an intercept.

    Why it is wrong: The first-stage cointegrating regression already includes an intercept \(\alpha\), ensuring the OLS residuals have exact sample mean zero: \(\sum \hat{u}_t = 0\). Adding an intercept in step 2 distorts degrees of freedom and shifts critical values.

Practice Problems

Mechanics Tier

An estimated pairs-trading spread has daily AR(1) persistence coefficient \(\hat{\phi} = 0.88\). Calculate its mean-reversion half-life in business days.

Worked Solution

Applying Theorem 6.1: \(h^* = \frac{\ln 2}{-\ln \hat{\phi}} = \frac{0.693147}{-\ln(0.88)} = \frac{0.693147}{0.127833} \approx 5.42\) business days. On average, any disequilibrium deviation decays by 50% in approximately 5.4 trading days.

Suppose a pairs-trading spread fitted on hourly bars yields \(\hat{\phi} = 0.96\). Given 6.5 trading hours per day, calculate the half-life in trading days.

Worked Solution

In hourly periods, the half-life is \(h^*_{\text{hours}} = \frac{\ln 2}{-\ln(0.96)} \approx \frac{0.693147}{0.040822} \approx 16.98\) hours. Converting to trading days: \(h^*_{\text{days}} = 16.98 / 6.5 \approx 2.61\) business days.

In an Engle-Granger test on \(T = 500\) daily observations, the residual ADF t-statistic is \(t_\gamma = -3.15\). Evaluate whether cointegration is detected at the 5% level using the correct critical value \(-3.34\).

Worked Solution

The rejection rule requires \(t_\gamma < t_{\text{crit}}\). Because \(-3.15 > -3.34\), the test fails to reject the null hypothesis of no cointegration. Note that if an analyst had mistakenly used the standard Dickey-Fuller critical value (\(-2.86\)), they would have spuriously concluded cointegration occurred!

Proof Tier

Prove that the continuous-time Ornstein-Uhlenbeck process \(ds_t = -\theta(s_t - \mu)dt + \sigma dW_t\) sampled at discrete intervals \(\Delta t\) yields an exact AR(1) model, and derive the relationship between \(\theta\) and \(\phi\).

Worked Solution

Integrating the SDE from \(t\) to \(t + \Delta t\) using the integrating factor \(e^{\theta t}\) yields \(s_{t+\Delta t} - \mu = e^{-\theta \Delta t}(s_t - \mu) + \sigma \int_t^{t+\Delta t} e^{-\theta(t+\Delta t - u)} dW_u\). Defining \(\phi = e^{-\theta \Delta t}\) and \(c = \mu(1 - e^{-\theta \Delta t})\), the discrete process is \(s_{t+\Delta t} = c + \phi s_t + e_{t+\Delta t}\), where \(e_{t+\Delta t} \sim \mathcal{N}(0, \frac{\sigma^2}{2\theta}(1 - e^{-2\theta \Delta t}))\). Therefore, \(\theta = -\ln(\phi)/\Delta t\), and the continuous half-life \(h^* = \ln 2 / \theta\) matches the discrete formula.

Show why regressing \(y_t\) on \(x_t\) produces an inconsistent slope estimate for the cointegrating vector when \(T\) is small and \(\operatorname{Corr}(e_{xt}, e_{yt}) \ne 0\).

Worked Solution

In finite samples, \(T(\hat{\beta} - \beta) = \frac{T^{-1}\sum x_t u_t}{T^{-2}\sum x_t^2}\). Expanding the numerator reveals a contemporaneous innovation bias: \(\mathbb{E}[x_t u_t] = \sum_{j=1}^t \mathbb{E}[\Delta x_j u_t] = t \sigma_{xu} + \sum_{k=1}^\infty \gamma_{xu}(k)\). While the denominator grows as \(O_p(T^2)\), for small \(T\) the bias term \(\sigma_{xu}\) shifts the expectation of \(\hat{\beta}\) toward the correlation between the error processes, causing finite-sample endogeneity bias.

Prove that if \(\phi \le 0\), the sequence \(\mathbb{E}[s_{t+h} - \mu \mid s_t] = \phi^h (s_t - \mu)\) cannot achieve half-life decay in continuous time.

Worked Solution

For \(\phi \in (-1, 0)\), \(\phi^h = (-1)^h |\phi|^h\). For odd \(h\), \(\phi^h < 0\), so the ratio of expected deviation to initial deviation is negative (\(< 0\)). For even \(h\), \(\phi^h > 0\). The equation \(\phi^h = 0.5\) has no real solution for continuous \(h\), because \(\ln(\phi)\) is complex when \(\phi < 0\). Hence half-life is mathematically undefined.

Empirical Tier

An algorithmic execution desk trades an ETF pair with estimated half-life \(h^* = 8\) days. Explain how the optimal rebalancing frequency and entry threshold should be calibrated to this half-life.

Worked Solution

To avoid over-trading and incurring excessive round-trip transaction costs, position holding horizons should be calibrated to \(1\) to \(2\) half-lives (8 to 16 days). Entry thresholds should be set at \(\pm 2\) standard deviations of the stationary spread, while profit-taking exits are placed near the equilibrium mean (\(\pm 0.5\) standard deviations) to capture the bulk of mean-reverting velocity before reversion momentum slows.

In testing 100 potential stock pairs for cointegration at the nominal 5% level, an analyst identifies 6 "cointegrated" pairs. Evaluate whether this finding represents real statistical arbitrage opportunities.

Worked Solution

Under the null hypothesis that all 100 pairs are independent non-cointegrated random walks, conducting 100 tests at the \(\alpha = 0.05\) level expects \(100 \times 0.05 = 5.0\) false discoveries purely due to multiple testing multiplicity. Observing 6 rejections is entirely consistent with pure chance (\(p \approx 0.38\) under a Binomial distribution). Without Bonferroni or Benjamini-Hochberg FDR adjustments, the 6 pairs are likely spurious.

Explain how borrow fees (repo costs for shorting stock) distort the effective half-life and profitability of an equity pairs trade.

Worked Solution

Borrowing hard-to-borrow equities incurs continuous annualized financing fees (e.g. 15% per year \(\approx 6\) bps per day). This linear cost creates a negative drift in the net spread P&L: \(\Delta \Pi_t = \Delta s_t - c_{\text{borrow}} \Delta t\). If the half-life is long (e.g. 60 days), cumulative borrow fees exceed the mean-reversion profit, converting an econometrically stationary spread into a financially losing investment.

Research Tier

Analyze how MacKinnon (1991, 2010) response surface regressions compute finite-sample critical values for cointegration tests across arbitrary sample sizes and variable counts.

Worked Solution

MacKinnon simulated millions of replications for varying sample sizes \(T\) and fitted response surface polynomials: \(C(p, T) = \beta_\infty + \beta_1/T + \beta_2/T^2 + \beta_3/T^3\). The intercept \(\beta_\infty\) provides the exact asymptotic Brownian motion functional quantile, while the negative inverse power terms \(\beta_k/T^k\) capture finite-sample boundary corrections, providing highly accurate critical values for any empirical sample length.

Evaluate the impact of structural change in the cointegrating vector: how does the Gregory-Hansen (1996) residual test accommodate regime shifts?

Worked Solution

Gregory and Hansen extend Engle-Granger testing to allow for an unknown structural break in the cointegrating relationship: \(y_t = \alpha_1 + \alpha_2 \mathbf{1}_{\{t > \tau\}} + \beta_1 x_t + \beta_2 x_t \mathbf{1}_{\{t > \tau\}} + u_t\). The test minimizes the residual ADF t-statistic over all possible break fractions \(\tau \in (0.15, 0.85)\). This test maintains power against regime-shifting cointegrated systems that standard Engle-Granger tests fail to detect.

In cryptocurrency decentralized exchanges (DEXs), automated market makers (AMMs) maintain constant product invariants \(x \cdot y = k\). Contrast the microeconomic cointegration of AMM pool tokens against centralized order book pairs.

Worked Solution

In constant product AMMs, arbitrageurs continually trade against the liquidity pool to align DEX spot prices with centralized exchanges (CEXs). The invariant \(x \cdot y = k\) implies \(\ln(y_t) = \ln(k) - \ln(x_t)\). This mechanical deterministic constraint enforces exact cointegration with \(\beta = -1\) in log prices. Deviations from CEX parity represent impermanent loss and arbitrage transaction gas costs, creating structural threshold cointegration driven by Ethereum block validation times.

Retrieval Quiz

  1. In step 2 of the Engle-Granger test, why is the ADF regression fitted with no intercept?

    Step 1 fits \(y_t = \alpha + \beta x_t + u_t\). First-order conditions of OLS force \(\sum \hat{u}_t = 0\), so the residuals have exact sample mean zero, eliminating the need for an intercept in step 2.

  2. Why is the 5% critical value for the Engle-Granger residual test (\(\approx -3.34\)) more negative than the standard Dickey-Fuller critical value (\(\approx -2.86\))?

    Minimizing residual variance biases the residuals toward stationarity under the null, shifting the distribution to the left and requiring a more stringent negative threshold.

  3. What is the mean-reversion half-life \(h^*\) of an AR(1) spread process with persistence \(\phi = 0.50\)?

    \(h^* = \ln(2) / (-\ln(0.50)) = \ln(2) / \ln(2) = 1.00\) period. Deviations decay by exactly half in one period.

  4. What value should the half-life function return if the estimated persistence is \(\hat{\phi} = 1.02\)?

    When \(\phi \ge 1\), the spread is non-stationary and explosive. It never mean-reverts to equilibrium, which corresponds to infinite half-life \(\infty\).

  5. What exception should an econometric half-life estimator raise if \(\hat{\phi} = -0.40\)?

    For \(\phi \le 0\), the spread exhibits sign oscillations, rendering the logarithm \(\ln(\phi)\) complex and the continuous half-life undefined. The specification mandates raising a ValueError.

  6. What is a major limitation of the Engle-Granger two-step cointegration test compared to the Johansen test?

    Because OLS minimizes vertical errors along the chosen dependent variable, the test statistic depends arbitrarily on which variable is placed on the left-hand side.

  7. In pairs trading, if a candidate pair has \(t_\gamma = -3.80\) (critical \(-3.34\)) but trading-window spread has \(\hat{\phi} = 1.05\), what is the correct audit verdict?

    Survival requires both statistical cointegration in formation (\(t < t_{\text{crit}}\)) and finite mean-reversion half-life out of sample. An explosive out-of-sample spread breaks the strategy.

  8. How does a continuous-time Ornstein-Uhlenbeck mean-reversion parameter \(\theta\) relate to the discrete AR(1) persistence \(\phi\)?

    Discretizing an Ornstein-Uhlenbeck process over sampling interval \(\Delta t\) yields the exact autoregressive coefficient \(\phi = e^{-\theta \Delta t}\).
