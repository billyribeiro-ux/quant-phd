Unit Roots and the Dickey-Fuller Test

Integrated Processes, Stochastic Trends, Non-Standard Asymptotics, and Lag-Augmented Testing

Why It Matters

Testing for unit roots is the critical gateway of time series econometrics. Applying stationary regression techniques to unit-root processes destroys classical inference: standard errors collapse, t-ratios diverge, and independent random walks produce spuriously high regression fits. Distinguishing difference-stationary processes from trend-stationary processes determines whether shocks have permanent structural impacts or transient cyclical effects on asset valuations.

1. The Unit-Root Process and Stochastic Trends

Definition 3.1 · Unit Root and Integration of Order One

An autoregressive process \(\phi(L) y_t = c + \varepsilon_t\) is said to possess a unit root if the characteristic polynomial \(\phi(z) = 0\) has a root exactly on the complex unit circle at \(z = 1\). If \(\phi(L) = (1 - L) \phi^*(L) = \Delta \phi^*(L)\) where all roots of \(\phi^*(z) = 0\) lie strictly outside the unit circle, then \(y_t\) is said to be integrated of order one, denoted \(y_t \sim I(1)\).

Theorem 3.1 · Properties of the Random Walk with Drift

Assumptions: Let \(y_t = \mu + y_{t-1} + \varepsilon_t\) with initial condition \(y_0\), where \(\varepsilon_t \sim \operatorname{iid}(0, \sigma^2)\).

Properties: By recursive substitution, \(y_t = y_0 + \mu t + \sum_{j=1}^t \varepsilon_j\):

  1. Deterministic linear drift: \(\mathbb{E}[y_t] = y_0 + \mu t\).
  2. Linearly expanding variance: \(\operatorname{Var}(y_t) = t \sigma^2\).
  3. Permanent shock persistence: \(\frac{\partial y_{t+h}}{\partial \varepsilon_t} = 1\) for all future horizons \(h \ge 0\).
  4. Unit autocorrelation asymptote: \(\operatorname{Corr}(y_t, y_{t-h}) = \sqrt{\frac{t-h}{t}} \to 1\) as \(t \to \infty\) for fixed lag \(h\).
Proof

Expanding the recursion gives \(y_t = y_0 + \mu t + \sum_{j=1}^t \varepsilon_j\). The expectation follows by linearity: \(\mathbb{E}[y_t] = y_0 + \mu t + \sum \mathbb{E}[\varepsilon_j] = y_0 + \mu t\). Variance is \(\operatorname{Var}(y_t) = \sum_{j=1}^t \operatorname{Var}(\varepsilon_j) = t \sigma^2\) because innovations are iid. For any shock \(\varepsilon_t\), \(\partial y_{t+h}/\partial \varepsilon_t = \partial(\sum_{j=1}^{t+h} \varepsilon_j)/\partial \varepsilon_t = 1\), establishing infinite memory. Finally, \(\operatorname{Cov}(y_t, y_{t-h}) = (t-h)\sigma^2\), yielding \(\operatorname{Corr}(y_t, y_{t-h}) = \frac{(t-h)\sigma^2}{\sqrt{t\sigma^2 (t-h)\sigma^2}} = \sqrt{\frac{t-h}{t}}\), which approaches 1 as \(t \to \infty\).

2. The Dickey-Fuller Test and Non-Standard Asymptotics

Definition 3.2 · Dickey–Fuller Test

The Dickey–Fuller test tests the null hypothesis of a unit root \(H_0: \phi = 1\) against the one-sided stationary alternative \(H_1: \phi < 1\) in the re-parameterized regression:

\[ \Delta y_t = \alpha + \gamma y_{t-1} + \varepsilon_t, \]

where \(\gamma = \phi - 1\). The null hypothesis corresponds to \(H_0: \gamma = 0\) versus \(H_1: \gamma < 0\). The test statistic is the standard OLS t-statistic:

\[ t_\gamma = \frac{\hat{\gamma}}{\operatorname{SE}(\hat{\gamma})} = \frac{\sum_{t=1}^T (y_{t-1} - \bar{y}_{-1})\Delta y_t}{\hat{\sigma}_\varepsilon \sqrt{\sum_{t=1}^T (y_{t-1} - \bar{y}_{-1})^2}}. \]
Remark 3.1 · Dickey-Fuller Non-Standard Distribution

Dickey and Fuller (1979) established that under the unit-root null \(\gamma = 0\), \(t_\gamma\) does not follow Student's t or standard normal distributions. Instead, \(t_\gamma\) converges to a functional of standard Brownian motion \(W(r)\) on \(r \in [0, 1]\):

\[ t_\gamma \xrightarrow{d} \frac{\int_0^1 W^*(r) \, dW(r)}{\left(\int_0^1 [W^*(r)]^2 \, dr\right)^{1/2}}, \]

where \(W^*(r) = W(r) - \int_0^1 W(s) \, ds\) is demeaned Brownian motion. This distribution is skewed heavily to the left with a negative median (\(\approx -1.53\)) and a 5% critical value of \(-2.86\) (rather than \(-1.645\) for a standard normal one-tailed test).

Definition 3.3 · Augmented Dickey-Fuller (ADF) Regression

When innovations exhibit serial correlation, the Augmented Dickey-Fuller test augments the regression with \(p\) lagged differences:

\[ \Delta y_t = \alpha + \gamma y_{t-1} + \sum_{j=1}^p \delta_j \Delta y_{t-j} + \varepsilon_t. \]

The augmentation whitens the residuals, ensuring that the t-statistic on \(\gamma\) shares the identical asymptotic Dickey-Fuller limiting distribution under \(H_0: \gamma = 0\).

3. Numerical Verification

We simulate the empirical distribution of the Dickey-Fuller t-statistic under the null of a random walk with \(T = 250\) observations across 2,500 replications.

Lab 1 · Dickey-Fuller Null Distribution vs. Standard Normal

Simulating 2500 pure random walks of length T=250 produces an empirical t_gamma distribution with mean ~ -1.52 and 5% critical quantile near -2.86, substantially shifted left of the normal critical value -1.645.

"""Lab S3-L03-1: Dickey-Fuller test distribution under the null.

SIMULATED: generates empirical distribution of the Dickey-Fuller t-statistic
under the null hypothesis of a unit root, demonstrating its leftward shift
relative to the standard normal distribution.
"""

from __future__ import annotations

import math
import random


def df_t_statistic(y: list[float]) -> float:
    """Compute DF t-statistic for regression with intercept: Delta y_t = alpha + gamma * y_{t-1} + e_t."""
    m = len(y)
    dy = [y[t] - y[t - 1] for t in range(1, m)]
    x = [y[t - 1] for t in range(1, m)]
    n_obs = len(dy)
    mean_x = sum(x) / n_obs
    mean_y = sum(dy) / n_obs
    cov = sum((x[i] - mean_x) * (dy[i] - mean_y) for i in range(n_obs))
    var_x = sum((x[i] - mean_x) ** 2 for i in range(n_obs))
    gamma = cov / var_x
    alpha = mean_y - gamma * mean_x
    res = [dy[i] - alpha - gamma * x[i] for i in range(n_obs)]
    s2 = sum(r * r for r in res) / (n_obs - 2)
    se_gamma = math.sqrt(s2 / var_x)
    return gamma / se_gamma


def main() -> None:
    reps = 2500
    n = 250
    rng = random.Random(42)

    t_stats: list[float] = []
    for _ in range(reps):
        y = [0.0]
        for _ in range(n - 1):
            y.append(y[-1] + rng.gauss(0.0, 1.0))
        t_stats.append(df_t_statistic(y))

    t_stats.sort()
    q01 = t_stats[int(0.01 * reps)]
    q05 = t_stats[int(0.05 * reps)]
    q10 = t_stats[int(0.10 * reps)]
    mean_t = sum(t_stats) / reps

    print(f"Dickey-Fuller Simulation (R={reps}, T={n}, seed=42)")
    print(f"Empirical mean of t_gamma: {mean_t:.4f} (Standard Normal: 0.0000)")
    print("\nQuantile Comparison:")
    print("Level | Empirical DF | Standard Normal | Shift")
    print("-" * 47)
    print(f"   1% |     {q01:.4f}   |     -2.3263     | {q01 - (-2.3263):+.4f}")
    print(f"   5% |     {q05:.4f}   |     -1.6449     | {q05 - (-1.6449):+.4f}")
    print(f"  10% |     {q10:.4f}   |     -1.2816     | {q10 - (-1.2816):+.4f}")

Where the Canon Breaks

The classical Dickey-Fuller unit-root testing paradigm exhibits well-documented econometric vulnerabilities in real market data:

  • Structural breaks destroy power: As Perron (1989) demonstrated, if a stationary process experiences an unmodeled shift in its mean or trend, standard Dickey-Fuller tests fail to reject the unit root null with probability approaching 1 as \(T \to \infty\). Stationary series with structural breaks mimic unit roots.
  • Lag length selection sensitivity: Selecting too few lags \(p\) in the ADF regression induces severe size distortion (inflated false rejections due to residual autocorrelation); selecting too many lags inflates estimator variance and crushes test power.
  • Near-unit-root boundary discontinuity: When \(\phi = 1 - c/T\) for a local-to-unity parameter \(c > 0\), the distribution of \(t_\gamma\) is a continuous deformation between Dickey-Fuller and standard normal. In finite samples, no statistical test can uniformly distinguish a unit root from a root at \(\phi = 0.999\).

Misconceptions

  • Wrong belief: Failing to reject the Dickey-Fuller null hypothesis proves that the series is a unit root.

    Why it is wrong: Failure to reject is not proof of the null. In finite samples, the Dickey-Fuller test has notorious low power against persistent stationary alternatives (\(\phi \in [0.90, 0.98]\)), frequently failing to reject even when the true process is stationary.

  • Wrong belief: One can use standard Student-t critical values (\(\pm 1.96\)) for the Dickey-Fuller regression.

    Why it is wrong: The regressor \(y_{t-1}\) is non-stationary under the null, violating classical central limit theorems. The t-statistic converges to a non-standard functional of Brownian motion with a 5% critical value near \(-2.86\).

  • Wrong belief: First-differencing is always the best solution to handle time series persistence.

    Why it is wrong: Differencing a stationary or trend-stationary series introduces an artificial moving-average unit root into the error term (\(\Delta y_t = (1 - L) u_t\)), causing over-differencing, non-invertibility, and destroying low-frequency equilibrium information.

Practice Problems

Mechanics Tier

In an ADF regression \(\Delta y_t = 0.12 - 0.08 y_{t-1} + 0.25 \Delta y_{t-1} + e_t\) fitted to \(T = 250\) observations, the estimated standard error of the \(y_{t-1}\) coefficient is \(\operatorname{SE}(\hat{\gamma}) = 0.025\). Compute the Dickey-Fuller test statistic and evaluate the test at the 5% level against critical value \(-2.86\).

Worked Solution

The t-statistic on \(\gamma\) is \(t_\gamma = \hat{\gamma} / \operatorname{SE}(\hat{\gamma}) = -0.08 / 0.025 = -3.2000\). Since \(-3.2000 < -2.8600\), the test statistic falls into the rejection region. We reject the unit root null hypothesis at the 5% significance level in favor of covariance stationarity.

An AR(2) process is specified as \(y_t = 1.3 y_{t-1} - 0.3 y_{t-2} + \varepsilon_t\). Formulate the lag polynomial \(\phi(L)\), find its roots, and determine whether the process has a unit root.

Worked Solution

The lag polynomial is \(\phi(z) = 1 - 1.3 z + 0.3 z^2 = (1 - z)(1 - 0.3 z)\). The roots of \(\phi(z) = 0\) are \(z_1 = 1.0\) and \(z_2 = 1 / 0.3 \approx 3.333\). Because root \(z_1 = 1.0\) lies exactly on the unit circle and \(|z_2| > 1\), the process possesses exactly one unit root and is integrated of order one: \(y_t \sim I(1)\).

Consider an asset price modeled as a geometric Brownian motion discretely observed: \(\ln S_t = \mu + \ln S_{t-1} + \sigma \varepsilon_t\). Calculate the variance of the log price at horizons \(t = 30\) and \(t = 252\) days if \(\sigma = 0.015\).

Worked Solution

Because \(\ln S_t\) is a random walk with drift, \(\operatorname{Var}(\ln S_t) = t \sigma^2\). For \(t = 30\), \(\operatorname{Var}(\ln S_{30}) = 30 \times (0.015)^2 = 30 \times 0.000225 = 0.00675\) (standard deviation \(\approx 8.22\%\)). For \(t = 252\), \(\operatorname{Var}(\ln S_{252}) = 252 \times 0.000225 = 0.0567\) (standard deviation \(\approx 23.81\%\)).

Proof Tier

Prove that if \(y_t = y_{t-1} + \varepsilon_t\) with \(\varepsilon_t \sim \operatorname{iid}(0, \sigma^2)\), the OLS estimator \(\hat{\phi}\) in \(y_t = \phi y_{t-1} + u_t\) converges at rate \(T\) (super-consistency), rather than \(\sqrt{T}\).

Worked Solution

The OLS estimator satisfies \(T(\hat{\phi} - 1) = \frac{T^{-1}\sum_{t=1}^T y_{t-1}\varepsilon_t}{T^{-2}\sum_{t=1}^T y_{t-1}^2}\). Under the functional central limit theorem, \(T^{-1/2} y_{\lfloor rT \rfloor} \Rightarrow \sigma W(r)\). By continuous mapping, the denominator converges to \(T^{-2}\sum y_{t-1}^2 \Rightarrow \sigma^2 \int_0^1 [W(r)]^2 dr\), while the numerator converges to \(T^{-1}\sum y_{t-1}\varepsilon_t \Rightarrow \frac{1}{2}\sigma^2 (W(1)^2 - 1)\). Because the ratio of these limits is \(O_p(1)\), \(\hat{\phi} - 1 = O_p(1/T)\), establishing super-consistency at rate \(T\).

Show that first-differencing a trend-stationary process \(y_t = \alpha + \beta t + u_t\) where \(u_t \sim \operatorname{iid}(0, \sigma^2)\) induces an artificial unit root in the moving-average component.

Worked Solution

Taking differences gives \(\Delta y_t = y_t - y_{t-1} = \beta + u_t - u_{t-1} = \beta + (1 - L) u_t\). The error process \(\eta_t = (1 - L) u_t\) is an MA(1) with polynomial \(\theta(L) = 1 - L\). The root of \(\theta(z) = 1 - z = 0\) is \(z = 1.0\), which lies exactly on the unit circle. Differencing a trend-stationary series creates a non-invertible moving-average unit root, precluding autoregressive inversion.

Prove that in the ADF regression \(\Delta y_t = \alpha + \gamma y_{t-1} + \sum_{j=1}^p \delta_j \Delta y_{t-j} + \varepsilon_t\), the lag augmentation terms \(\Delta y_{t-j}\) are asymptotically orthogonal to the non-stationary level regressor \(y_{t-1}\).

Worked Solution

Under the null hypothesis, \(y_{t-1} \sim I(1)\) scales at rate \(O_p(\sqrt{T})\), so \(\sum y_{t-1}^2 = O_p(T^2)\). In contrast, the differenced terms \(\Delta y_{t-j} \sim I(0)\) are stationary and scale at standard rates: \(\sum (\Delta y_{t-j})^2 = O_p(T)\) and \(\sum y_{t-1}\Delta y_{t-j} = O_p(T)\). When normalized by \(T^{-3/2}\), the cross-product \(T^{-3/2} \sum y_{t-1}\Delta y_{t-j} \xrightarrow{p} 0\), establishing asymptotic block-diagonality of the covariance matrix between levels and differences.

Empirical Tier

A financial econometrician runs three specifications of the Dickey-Fuller test: (1) no constant, (2) constant only, and (3) constant and linear time trend. Explain how the 5% critical values change across these specifications and why.

Worked Solution

The 5% critical values become increasingly negative: \(-1.95\) (no constant), \(-2.86\) (constant only), and \(-3.41\) (constant and trend). Adding deterministic regressors removes additional low-frequency variance from the random walk regressor, shifting the projection residual closer to zero and pushing the Brownian motion functional further into the negative tail.

Describe how the Phillips-Perron test handles serial correlation in unit-root testing compared to the Augmented Dickey-Fuller test.

Worked Solution

While the ADF test uses parametric lag augmentation (\(\sum \delta_j \Delta y_{t-j}\)) to whiten regression residuals, the Phillips-Perron (PP) test fits an unaugmented DF regression and applies non-parametric Newey-West HAC adjustments directly to the t-statistic. PP avoids choosing lag orders for autoregressive differences but exhibits severe finite-sample size distortions in the presence of negative moving-average errors.

In analyzing 10-year Treasury yields, an ADF test yields \(t_\gamma = -2.45\) (p-value \(\approx 0.13\)), failing to reject a unit root. A KPSS test for stationarity yields a test statistic of 0.65 (5% critical value 0.463), rejecting stationarity. Synthesize these conflicting findings.

Worked Solution

The ADF test has null hypothesis of a unit root (fail to reject \(\implies\) unit root plausible). The KPSS test has null hypothesis of stationarity (reject \(\implies\) non-stationary). The joint conclusion is robust: both tests agree that 10-year Treasury yields behave as a non-stationary \(I(1)\) process over the sample window, ruling out simple mean-reversion without structural adjustment.

Research Tier

Analyze Perron's (1989) structural break critique of unit root tests, and explain how an unmodeled shift in the mean of a stationary series biases the ADF t-statistic toward non-rejection.

Worked Solution

Perron proved that if a true data-generating process is stationary around a broken trend or broken mean (\(y_t = \mu_1 \mathbf{1}_{\{t \le T_b\}} + \mu_2 \mathbf{1}_{\{t > T_b\}} + u_t\)), fitting a standard ADF regression forces the residual cross-products to absorb the persistent step function. The sample autocorrelations decay like a unit root, pushing \(\hat{\gamma} \to 0\) and rendering the ADF test asymptotically powerless against broken stationary alternatives.

Explain the Elliott-Rothenberg-Stock (DF-GLS) efficient unit root test: how does local quasi-differencing optimize asymptotic power envelopes?

Worked Solution

Elliott, Rothenberg, and Stock (1996) showed that OLS de-trending in standard ADF tests is inefficient. DF-GLS de-trends the data under a local alternative \(\bar{\alpha} = 1 - 7/T\) using quasi-differencing \(y_t^{\bar{\alpha}} = y_t - \bar{\alpha} y_{t-1}\). Running the ADF regression on the GLS-detrended series attains the Gaussian power envelope, substantially boosting power against persistent alternatives with roots \(\phi \in [0.90, 0.98]\).

In commodity futures markets, spot commodity prices are often modeled as mean-reverting Schwartz two-factor processes. Why do standard unit-root tests on raw commodity price levels frequently fail to reject the unit root null?

Worked Solution

Schwartz models feature a slow-moving, non-stationary convenience yield / long-term equilibrium factor coupled with a fast-reverting short-term shock factor. Over 10-to-20 year horizons, the persistence of the equilibrium factor dominates the sample variance, preventing the ADF test from rejecting the unit root even when substantial mean-reversion operates at 3-to-6 month trading horizons.

Retrieval Quiz

  1. In the Dickey-Fuller regression \(\Delta y_t = \alpha + \gamma y_{t-1} + \varepsilon_t\), how is the parameter \(\gamma\) related to the autoregressive persistence \(\phi\)?

    Subtracting \(y_{t-1}\) from both sides of \(y_t = \alpha + \phi y_{t-1} + \varepsilon_t\) yields \(\Delta y_t = \alpha + (\phi - 1) y_{t-1} + \varepsilon_t\), so \(\gamma = \phi - 1\).

  2. Why is the standard Student's t distribution invalid for testing \(\gamma = 0\) in the Dickey-Fuller regression?

    Non-stationarity causes the denominator sum of squares to explode at rate \(O(T^2)\) instead of \(O(T)\), yielding a non-standard Brownian motion ratio distribution.

  3. What is the approximate 5% critical value for the Augmented Dickey-Fuller test in a model with an intercept?

    For a specification with an intercept (and no linear trend), the 5% Dickey-Fuller critical value is approximately \(-2.86\). Values below \(-2.86\) reject the unit root null.

  4. What is the primary function of the lagged difference terms \(\sum_{j=1}^p \delta_j \Delta y_{t-j}\) in the ADF test?

    Lagged differences parameterize any AR(p) dynamics, whitening the residuals so that the asymptotic Dickey-Fuller limiting distribution applies without nuisance correlation parameters.

  5. What does Perron's (1989) structural break analysis demonstrate regarding standard Dickey-Fuller unit root tests?

    Perron proved that an ignored shift in the trend or mean mimics the low-frequency persistence of a unit root, destroying the statistical power of standard ADF tests.

  6. How does a unit-root process respond to a one-time historical innovation shock \(\varepsilon_t = 1.0\)?

    In a unit root process \(\partial y_{t+h}/\partial \varepsilon_t = 1\) for all \(h\), meaning every historical innovation enters the permanent stochastic trend.

  7. What rate of convergence does the OLS estimator \(\hat{\phi}\) achieve when the true process is a pure unit root (super-consistency)?

    Unlike stationary regressors that converge at rate \(\sqrt{T}\), the unit root estimator converges at rate \(T\) because the regressor variance grows at rate \(T^2\).

  8. Why is it dangerous to difference a trend-stationary series \(y_t = \alpha + \beta t + u_t\)?

    Differencing a stationary error creates an MA(1) with \(\theta = -1\), which lies on the unit circle and cannot be inverted into a valid autoregression.
