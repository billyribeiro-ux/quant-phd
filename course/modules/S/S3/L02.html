ARMA Models and the Wold Decomposition

Lag Operator Polynomials, Causality, Invertibility, and Fundamental Moving-Average Representations

Why It Matters

High-order autoregressions require estimating dozens of parameters, depleting degrees of freedom and inflating sampling variance. By parsimoniously combining autoregressive and moving-average components, ARMA models approximate complex stationary dynamics with minimal parameter footprints. Furthermore, the Wold decomposition proves that every purely non-deterministic stationary process possesses an exact infinite moving-average representation driven by white noise forecast errors.

1. The ARMA(p, q) Specification and Operator Algebra

Definition 2.1 · Autoregressive Moving-Average (ARMA) Model

An autoregressive moving-average (ARMA) process of orders \(p\) and \(q\), denoted \(\operatorname{ARMA}(p, q)\), satisfies the linear difference equation:

\[ y_t = c + \sum_{i=1}^p \phi_i y_{t-i} + \varepsilon_t + \sum_{j=1}^q \theta_j \varepsilon_{t-j}, \]

where \(\varepsilon_t \sim \operatorname{iid}(0, \sigma^2)\) with \(\sigma^2 > 0\). Using the lag operator \(L\) where \(L^k x_t = x_{t-k}\), the specification is written compactly as:

\[ \phi(L) y_t = c + \theta(L) \varepsilon_t, \]

with lag polynomials \(\phi(L) = 1 - \sum_{i=1}^p \phi_i L^i\) and \(\theta(L) = 1 + \sum_{j=1}^q \theta_j L^j\).

Definition 2.2 · Causality and Invertibility

Let \(\phi(z) = 1 - \sum_{i=1}^p \phi_i z^i\) and \(\theta(z) = 1 + \sum_{j=1}^q \theta_j z^j\) for complex \(z \in \mathbb{C}\), sharing no common roots:

  1. Causality: The process is causal (with respect to \(\varepsilon_t\)) if there exists an absolutely summable sequence \(\{\psi_j\}\) such that \(y_t = \mu + \sum_{j=0}^\infty \psi_j \varepsilon_{t-j}\). This holds if and only if all roots of \(\phi(z) = 0\) lie strictly outside the unit circle (\(|z| > 1\)).
  2. Invertibility: The process is invertible if the white noise can be recovered as an infinite autoregression \(\varepsilon_t = \sum_{j=0}^\infty \pi_j (y_{t-j} - \mu)\) with \(\sum_{j=0}^\infty |\pi_j| < \infty\). This holds if and only if all roots of \(\theta(z) = 0\) lie strictly outside the unit circle (\(|z| > 1\)).

2. ARMA(1, 1) Moments and Autocovariances

Theorem 2.1 · Closed-Form Autocovariances of ARMA(1, 1)

Assumptions:

  1. The process follows \(y_t = \phi y_{t-1} + \varepsilon_t + \theta \varepsilon_{t-1}\) with \(\mathbb{E}[y_t] = 0\).
  2. The innovation sequence satisfies \(\varepsilon_t \sim \operatorname{iid}(0, \sigma^2)\) with \(\sigma^2 > 0\).
  3. Causality holds: \(|\phi| < 1\) (root \(z_{\text{AR}} = 1/\phi\) satisfies \(|z| > 1\)).
  4. Invertibility holds: \(|\theta| < 1\) (root \(z_{\text{MA}} = -1/\theta\) satisfies \(|z| > 1\)).

Conclusion: The autocovariances \(\gamma(h) = \mathbb{E}[y_t y_{t-h}]\) satisfy:

\[ \begin{aligned} \gamma(0) &= \sigma^2 \frac{1 + \theta^2 + 2\phi\theta}{1 - \phi^2}, \\ \gamma(1) &= \phi \gamma(0) + \theta \sigma^2 = \sigma^2 \frac{(\phi + \theta)(1 + \phi\theta)}{1 - \phi^2}, \\ \gamma(h) &= \phi^{h-1} \gamma(1), \quad \forall h \ge 1. \end{aligned} \]
Proof

Multiplying \(y_t = \phi y_{t-1} + \varepsilon_t + \theta \varepsilon_{t-1}\) by \(y_t\) and taking expectations yields:

\[ \gamma(0) = \phi \mathbb{E}[y_{t-1} y_t] + \mathbb{E}[\varepsilon_t y_t] + \theta \mathbb{E}[\varepsilon_{t-1} y_t] = \phi \gamma(1) + \sigma^2 + \theta(\phi \sigma^2 + \theta \sigma^2), \]

since \(\mathbb{E}[\varepsilon_t y_t] = \sigma^2\) and \(y_t = \varepsilon_t + (\phi + \theta)\varepsilon_{t-1} + \dots \implies \mathbb{E}[\varepsilon_{t-1} y_t] = (\phi + \theta)\sigma^2\). For lag 1, multiplying by \(y_{t-1}\) gives:

\[ \gamma(1) = \phi \gamma(0) + \mathbb{E}[\varepsilon_t y_{t-1}] + \theta \mathbb{E}[\varepsilon_{t-1} y_{t-1}] = \phi \gamma(0) + \theta \sigma^2. \]

Substituting \(\gamma(1)\) into the expression for \(\gamma(0)\) produces \(\gamma(0) = \phi^2 \gamma(0) + \phi \theta \sigma^2 + \sigma^2 + \phi \theta \sigma^2 + \theta^2 \sigma^2\). Grouping terms yields \((1 - \phi^2)\gamma(0) = \sigma^2(1 + \theta^2 + 2\phi\theta)\), proving \(\gamma(0)\). For any \(h \ge 2\), multiplying by \(y_{t-h}\) yields \(\gamma(h) = \phi \gamma(h-1)\) because \(\mathbb{E}[\varepsilon_t y_{t-h}] = \mathbb{E}[\varepsilon_{t-1} y_{t-h}] = 0\), establishing geometric decay \(\gamma(h) = \phi^{h-1} \gamma(1)\).

3. The Wold Decomposition Theorem

Theorem 2.2 · Wold Decomposition Theorem

The Wold decomposition provides the foundational representation theorem for all discrete-time covariance-stationary processes.

Assumptions: Let \(\{y_t\}\) be any zero-mean weakly stationary discrete-time stochastic process.

Statement: Then \(y_t\) can be uniquely represented as the orthogonal sum of two mutually uncorrelated processes:

\[ y_t = \sum_{j=0}^\infty \psi_j \varepsilon_{t-j} + d_t, \]

where:

  1. \(\psi_0 = 1\) and the moving-average coefficients are square-summable: \(\sum_{j=0}^\infty \psi_j^2 < \infty\).
  2. \(\{\varepsilon_t\}\) is white noise with \(\varepsilon_t = y_t - \hat{P}_{t-1} y_t\), representing the one-step ahead linear forecast innovation of \(y_t\) given its infinite past.
  3. \(\operatorname{Cov}(\varepsilon_t, d_s) = 0\) for all \(t, s \in \mathbb{Z}\).
  4. \(d_t\) is linearly deterministic: it can be predicted without error from an affine projection on the infinite history \(\{y_{t-1}, y_{t-2}, \dots\}\).

The Wold decomposition theorem establishes that every covariance-stationary process has an MA(\(\infty\)) representation in terms of its own linear innovations. (General Hilbert-space proof given in Hamilton 1994, Chapter 4; unproved here).

4. Numerical Verification

We verify the root criteria and evaluate sample autocovariances against closed-form expressions for an ARMA(1, 1) process with \(\phi = 0.60, \theta = 0.40, \sigma^2 = 1.0\).

Lab 1 · ARMA(1, 1) Root Verification and Autocovariance Matching

Sample autocovariances for lags 0 to 3 from a simulated ARMA(1,1) with phi=0.60, theta=0.40 (T=3000) match closed-form formulas within Monte Carlo tolerance |diff| < 0.15, with roots strictly outside the unit circle.

"""Lab S3-L02-1: ARMA(1,1) autocovariances and causality-invertibility roots.

SIMULATED for the empirical simulation path; exact for root calculations and
closed-form autocovariances.
"""

from __future__ import annotations

import random


def simulate_arma11(phi: float, theta: float, sigma: float, n: int, seed: int = 42) -> list[float]:
    """Generate ARMA(1,1) path: y_t = phi * y_{t-1} + e_t + theta * e_{t-1}."""
    rng = random.Random(seed)
    burn = 150
    y = 0.0
    prev_e = 0.0
    for _ in range(burn):
        e = rng.gauss(0.0, sigma)
        y = phi * y + e + theta * prev_e
        prev_e = e
    series: list[float] = []
    for _ in range(n):
        e = rng.gauss(0.0, sigma)
        y = phi * y + e + theta * prev_e
        prev_e = e
        series.append(y)
    return series


def sample_autocovariances(series: list[float], max_lag: int) -> list[float]:
    """Compute sample autocovariances for lags 0 through max_lag."""
    n = len(series)
    mean_y = sum(series) / n
    demeaned = [val - mean_y for val in series]
    gamma: list[float] = []
    for h in range(max_lag + 1):
        gamma_h = sum(demeaned[t] * demeaned[t + h] for t in range(n - h)) / n
        gamma.append(gamma_h)
    return gamma


def main() -> None:
    phi = 0.60
    theta = 0.40
    sigma = 1.0
    n = 3000

    # Root conditions
    root_ar = 1.0 / phi
    root_ma = -1.0 / theta
    is_causal = abs(root_ar) > 1.0
    is_invertible = abs(root_ma) > 1.0

    print("ARMA(1,1) Root Analysis:")
    print(f"  AR root z = 1/phi = {root_ar:.4f} (|z| > 1: {is_causal}, causal)")
    print(f"  MA root z = -1/theta = {root_ma:.4f} (|z| > 1: {is_invertible}, invertible)")

    # Closed-form autocovariances
    gamma0_theo = (sigma**2) * (1.0 + theta**2 + 2.0 * phi * theta) / (1.0 - phi**2)
    gamma1_theo = phi * gamma0_theo + theta * (sigma**2)
    gamma2_theo = phi * gamma1_theo
    gamma3_theo = phi * gamma2_theo
    theo_gammas = [gamma0_theo, gamma1_theo, gamma2_theo, gamma3_theo]

    series = simulate_arma11(phi, theta, sigma, n, seed=42)
    emp_gammas = sample_autocovariances(series, 3)

    print("\nAutocovariances (T=3000, seed=42):")
    print("Lag | Sample gamma(h) | Closed Form | Diff")
    print("-" * 43)
    for h in range(4):
        diff = emp_gammas[h] - theo_gammas[h]
        print(f"  {h} |     {emp_gammas[h]:.4f}      |   {theo_gammas[h]:.4f}    | {diff:+.4f}")


main()

Where the Canon Breaks

The classical ARMA and Wold representation framework embodies foundational mathematical idealizations that fail in financial applications:

  • Linear projection vs. conditional expectation: Wold innovations \(\varepsilon_t\) are uncorrelated white noise, not independent white noise. For non-linear processes (e.g. GARCH), \(\mathbb{E}[\varepsilon_t \mid \mathcal{F}_{t-1}] = 0\) holds but \(\operatorname{Var}(\varepsilon_t \mid \mathcal{F}_{t-1})\) is time-varying. The Wold decomposition captures the best linear projection, which can be severely suboptimal compared to non-linear filters.
  • Common root cancellation: If \(\phi(L)\) and \(\theta(L)\) share a root \(z_0\), the transfer function \(\theta(L)/\phi(L)\) contains redundant dynamics. Near-cancellation creates severe numerical instability in maximum likelihood estimation (flat likelihood surfaces).
  • Non-invertibility in asset prices: If an econometrician models asset returns with a non-invertible MA polynomial (roots inside the unit circle), the true structural economic shocks cannot be recovered from the observable history of prices alone (informationally non-fundamental).

Misconceptions

  • Wrong belief: An ARMA model can capture sudden regime switches in volatility or mean return.

    Why it is wrong: ARMA specifications are intrinsically linear filters of white noise innovations with time-invariant coefficients. Structural shifts require non-linear models such as Hamilton Markov-switching architectures (Lesson 10).

  • Wrong belief: Wold decomposition proves that all stationary economic processes are linear moving averages of independent structural shocks.

    Why it is wrong: Wold innovations are orthogonal (uncorrelated), not independent. Strongly non-linear or chaotic deterministic systems can have identical linear Wold representations to Gaussian linear ARMA processes.

  • Wrong belief: Invertibility is required for a process to be covariance-stationary.

    Why it is wrong: Stationarity depends entirely on the autoregressive polynomial \(\phi(L)\). Invertibility depends on the moving-average polynomial \(\theta(L)\) and governs whether innovations can be reconstructed from historical observables.

Practice Problems

Mechanics Tier

For an ARMA(1, 1) process \(y_t = 0.5 y_{t-1} + \varepsilon_t + 0.3 \varepsilon_{t-1}\) with \(\sigma^2 = 1.0\), compute \(\gamma(0)\), \(\gamma(1)\), and the lag-1 autocorrelation \(\rho(1)\).

Worked Solution

Unconditional variance: \(\gamma(0) = \sigma^2 \frac{1 + \theta^2 + 2\phi\theta}{1 - \phi^2} = 1.0 \times \frac{1 + 0.09 + 2(0.5)(0.3)}{1 - 0.25} = \frac{1.39}{0.75} \approx 1.8533\). Lag-1 autocovariance: \(\gamma(1) = \phi \gamma(0) + \theta \sigma^2 = 0.5(1.8533) + 0.3(1.0) = 0.9267 + 0.3000 = 1.2267\). Lag-1 autocorrelation: \(\rho(1) = 1.2267 / 1.8533 \approx 0.6619\).

Determine whether the MA(2) process \(y_t = \varepsilon_t - 1.3 \varepsilon_{t-1} + 0.4 \varepsilon_{t-2}\) is invertible by finding the roots of \(\theta(z) = 0\).

Worked Solution

The MA polynomial is \(\theta(z) = 1 - 1.3 z + 0.4 z^2 = 0\). Factoring yields \((1 - 0.8 z)(1 - 0.5 z) = 0\). The roots are \(z_1 = 1 / 0.8 = 1.25\) and \(z_2 = 1 / 0.5 = 2.00\). Since \(|z_1| = 1.25 > 1\) and \(|z_2| = 2.00 > 1\), all roots lie strictly outside the complex unit circle, confirming that the process is invertible.

For the causal AR(1) process \((1 - 0.8 L) y_t = \varepsilon_t\), write out the first four coefficients \(\psi_0, \psi_1, \psi_2, \psi_3\) of its infinite moving-average representation \(\psi(L) = \sum_{j=0}^\infty \psi_j L^j\).

Worked Solution

Inverting the lag polynomial yields \(\psi(L) = (1 - 0.8 L)^{-1} = \sum_{j=0}^\infty (0.8)^j L^j\). Therefore, the coefficients evaluate to \(\psi_0 = 1.0000\), \(\psi_1 = 0.8000\), \(\psi_2 = 0.6400\), and \(\psi_3 = 0.5120\).

Proof Tier

Prove that if \(y_t = \varepsilon_t + \theta \varepsilon_{t-1}\) is an MA(1) process with \(|\theta| > 1\), there exists an observationally equivalent invertible MA(1) representation with the identical autocorrelation function.

Worked Solution

For \(y_t = \varepsilon_t + \theta \varepsilon_{t-1}\) with \(\varepsilon_t \sim \operatorname{iid}(0, \sigma^2)\), \(\gamma(0) = (1 + \theta^2)\sigma^2\) and \(\gamma(1) = \theta \sigma^2\), giving \(\rho(1) = \theta / (1 + \theta^2)\). Define \(\tilde{\theta} = 1/\theta\) and \(\tilde{\sigma}^2 = \theta^2 \sigma^2\). Then \(|\tilde{\theta}| = |1/\theta| < 1\) (invertible). For this representation: \(\tilde{\gamma}(0) = (1 + \tilde{\theta}^2)\tilde{\sigma}^2 = (1 + 1/\theta^2)\theta^2 \sigma^2 = (\theta^2 + 1)\sigma^2 = \gamma(0)\), and \(\tilde{\gamma}(1) = \tilde{\theta}\tilde{\sigma}^2 = (1/\theta)(\theta^2 \sigma^2) = \theta \sigma^2 = \gamma(1)\). Thus both processes share identical first and second moments.

Prove that the autocorrelation function of an MA(q) process cuts off strictly after lag \(q\): \(\rho(h) = 0\) for all \(|h| > q\).

Worked Solution

An MA(q) is defined by \(y_t = \sum_{j=0}^q \theta_j \varepsilon_{t-j}\) with \(\theta_0 = 1\). The autocovariance at lag \(h > 0\) is \(\gamma(h) = \mathbb{E}\left[\left(\sum_{j=0}^q \theta_j \varepsilon_{t-j}\right)\left(\sum_{k=0}^q \theta_k \varepsilon_{t-h-k}\right)\right]\). Because \(\mathbb{E}[\varepsilon_r \varepsilon_s] = \sigma^2 \mathbf{1}_{\{r = s\}}\), terms are non-zero only when \(t - j = t - h - k \implies j = h + k\). Since \(j \le q\) and \(k \ge 0\), a non-empty intersection requires \(h \le q\). For \(h > q\), no indices match and \(\gamma(h) = 0\), establishing \(\rho(h) = 0\) for all \(|h| > q\).

Show that in the Wold decomposition \(y_t = \sum_{j=0}^\infty \psi_j \varepsilon_{t-j} + d_t\), the deterministic component \(d_t\) has zero prediction error variance across all future forecast horizons.

Worked Solution

By definition, \(d_t\) lies in the closed linear subspace \(\mathcal{M}_{-\infty} = \bigcap_{s=-\infty}^\infty \overline{\operatorname{sp}}\{y_s, y_{s-1}, \dots\}\). Because \(d_t \in \mathcal{M}_{t-k}\) for all \(k \ge 1\), the orthogonal projection of \(d_t\) onto \(\overline{\operatorname{sp}}\{y_{t-1}, y_{t-2}, \dots\}\) is \(d_t\) itself. Consequently, the linear forecast error \(d_t - \hat{P}_{t-1} d_t = d_t - d_t = 0\) almost surely, yielding identically zero forecast error variance.

Empirical Tier

Explain how an empirical analyst uses the sample autocorrelation function (ACF) and sample partial autocorrelation function (PACF) to identify candidate orders \(p\) and \(q\) in the Box-Jenkins framework.

Worked Solution

For a pure AR(p) process, the theoretical ACF decays exponentially or via damped sinusoids, while the PACF cuts off sharply to zero after lag \(p\). For a pure MA(q) process, the theoretical ACF cuts off sharply after lag \(q\), while the PACF decays geometrically. For a mixed ARMA(p, q) process, both the ACF and PACF exhibit tail decay without cutting off, requiring information criteria (AIC, BIC) for model selection.

Suppose an estimated ARMA(1, 1) model for equity returns yields \(\hat{\phi} = 0.92\) and \(\hat{\theta} = -0.90\). Diagnose the potential econometric pathology in this estimation result.

Worked Solution

This result exhibits near-cancellation of roots: the autoregressive polynomial has root \(z_{\text{AR}} \approx 1/0.92 = 1.087\), while the moving-average polynomial has root \(z_{\text{MA}} \approx 1/0.90 = 1.111\). Because \(\phi(L) \approx \theta(L)\), the transfer function \((1 - 0.90 L)/(1 - 0.92 L) \approx 1.0\), indicating that the true underlying data-generating process is approximately white noise, and the ARMA(1, 1) model is over-parameterized.

In modeling high-frequency order book flow, why do empirical autocorrelations remain positive across hundreds of lags, violating standard low-order ARMA exponential decay?

Worked Solution

Order book trade sign sequences exhibit long memory and order splitting by algorithmic execution algorithms (e.g. TWAP/VWAP child orders). Meta-orders generate power-law autocorrelation decay \(\rho(h) \sim c h^{-\gamma}\) with \(0 < \gamma < 1\). Fitting low-order ARMA(p, q) fails because exponential decay drops to zero far too rapidly, necessitating fractionally integrated ARFIMA models.

Research Tier

Analyze the non-fundamentalness problem in macro-econometrics: why might a structural DSGE model generate an equilibrium time series with non-invertible moving-average representations?

Worked Solution

Following Hansen and Sargent (1991) and Lippi and Reichlin (1994), when economic agents observe forward-looking news or anticipated policy shocks that the econometrician cannot observe directly in current and past prices, the mapping from observable economic variables to structural shocks has moving-average roots inside the unit circle. Inverting the MA polynomial would require future prices, rendering structural shocks unrecoverable from standard causal VAR/ARMA filters.

Evaluate how the Akaike Information Criterion (AIC) and Bayesian Information Criterion (BIC) penalize ARMA model complexity, and contrast their asymptotic properties.

Worked Solution

AIC penalizes model order by \(2k/T\), where \(k = p + q\) is the parameter count. BIC penalizes by \(k \ln(T) / T\). For \(T > e^2 \approx 7.39\), \(\ln(T) > 2\), so BIC penalizes complexity much more aggressively. Asymptotically, BIC is order-consistent (the probability of selecting the true finite orders \(p_0, q_0\) approaches 1 as \(T \to \infty\)), whereas AIC is minimax-rate optimal for out-of-sample prediction but over-selects model lag orders with positive asymptotic probability.

Discuss how the spectral density function \(f(\omega) = \frac{\sigma^2}{2\pi} \frac{|\theta(e^{-i\omega})|^2}{|\phi(e^{-i\omega})|^2}\) characterizes the frequency distribution of variance in an ARMA process.

Worked Solution

By the Wiener-Khinchin theorem, the spectral density is the Fourier transform of the autocovariance function \(\gamma(h)\). For an ARMA process, the ratio of polynomial squared moduli filters white noise variance across frequencies \(\omega \in [-\pi, \pi]\). Autoregressive roots near the unit circle generate sharp spectral peaks (business cycles or seasonal periodicity), while moving-average roots near the unit circle create spectral zeroes (complete cancellation of specific frequency cycles).

Retrieval Quiz

  1. What is the condition on the polynomial \(\phi(z) = 1 - \phi_1 z - \dots - \phi_p z^p\) for an AR(p) process to be causal?

    Writing \(\phi(z) = \prod (1 - \lambda_i z)\), the eigenvalues \(\lambda_i = 1/z_i\) must lie inside the unit circle (\(|\lambda_i| < 1\)), which implies all roots \(z_i\) lie outside the unit circle (\(|z_i| > 1\)).

  2. What is the root of the MA(1) polynomial \(\theta(z) = 1 + 0.5 z = 0\), and is the process invertible?

    Solving \(1 + 0.5 z = 0\) yields \(z = -1 / 0.5 = -2.0\). The modulus is \(|-2.0| = 2.0 > 1\), which satisfies the invertibility criterion.

  3. For a causal and invertible ARMA(1, 1) process, how do the autocovariances \(\gamma(h)\) behave for lags \(h \ge 2\)?

    Because \(\mathbb{E}[\varepsilon_t y_{t-h}] = \mathbb{E}[\varepsilon_{t-1} y_{t-h}] = 0\) for \(h \ge 2\), the Yule-Walker equation reduces to \(\gamma(h) = \phi \gamma(h-1)\).

  4. What does the Wold decomposition theorem prove about any zero-mean weakly stationary process?

    The Wold decomposition proves that every weakly stationary process can be represented as an infinite square-summable moving average of its one-step ahead linear prediction innovations plus an orthogonal linearly deterministic term.

  5. What empirical symptom indicates root cancellation in an estimated ARMA(1, 1) model?

    When \(\phi(L) = 1 - \phi L\) and \(\theta(L) = 1 + \theta L\) share a common root, \(\phi \approx -\theta\). The factors cancel, leaving the likelihood surface flat and standard errors inflated.

  6. What is the relationship between the Wold innovations \(\varepsilon_t\) and the information set \(\mathcal{F}_{t-1}\) in non-linear time series?

    Wold decomposition relies on linear projection. Hence \(\varepsilon_t\) is orthogonal to past values in a linear sense (\(\mathbb{E}[\varepsilon_t y_{t-k}] = 0\)), but higher-order dependencies like \(\mathbb{E}[\varepsilon_t^2 \mid y_{t-1}]\) can be non-constant.

  7. How does an MA(2) autocorrelation function behave compared to an AR(2) autocorrelation function?

    A moving-average process of order \(q\) has zero autocovariance for all lags \(h > q\). Autoregressive processes have infinite memory with decaying autocovariances.

  8. Why does the Bayesian Information Criterion (BIC) select more parsimonious models than the Akaike Information Criterion (AIC) in large samples?

    BIC's penalty \(\ln(T)\) per parameter increases with sample size, preventing the positive asymptotic overfitting probability present in AIC.
