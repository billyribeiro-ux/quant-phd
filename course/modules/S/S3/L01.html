Stationarity and the Autocorrelation Function

Foundations of Discrete-Time Stochastic Processes, Autocovariance Invariance, and AR(1) Dynamics

Why It Matters

Financial time series exhibit temporal dependence that destroys cross-sectional econometric guarantees. Without stationarity, sample moments fail to converge to population constants, sample means drift with history, and regression t-statistics produce spurious discoveries. Weak stationarity establishes time-invariance of first and second moments, enabling consistent estimation from a single observed historical realization.

1. Weak Stationarity & Autocovariance Functions

Definition 1.1 · Weak Stationarity

A discrete-time real-valued stochastic process \(\{y_t\}_{t \in \mathbb{Z}}\) is said to possess weak stationarity (or covariance stationarity) if and only if it satisfies three conditions for all \(t, h \in \mathbb{Z}\):

  1. Constant mean: \(\mathbb{E}[y_t] = \mu < \infty\).
  2. Finite constant variance: \(\operatorname{Var}(y_t) = \mathbb{E}[(y_t - \mu)^2] = \gamma(0) < \infty\).
  3. Lag-dependent autocovariance: \(\operatorname{Cov}(y_t, y_{t-h}) = \mathbb{E}[(y_t - \mu)(y_{t-h} - \mu)] = \gamma(h)\), depending only on the temporal separation \(h\) and not on observation index \(t\).
Remark 1.1 · Strict vs. Weak Stationarity

Strict stationarity requires the joint distribution of \((y_{t_1}, \dots, y_{t_k})\) to be identical to \((y_{t_1+h}, \dots, y_{t_k+h})\) for all shift horizons \(h\) and tuples \((t_1, \dots, t_k)\). If a process is strictly stationary with finite second moments, it is weakly stationary. Conversely, weak stationarity does not imply strict stationarity unless the joint distribution is Gaussian.

Definition 1.2 · Autocorrelation Function (ACF)

For a weakly stationary process with autocovariance function \(\gamma(h)\), the autocorrelation function \(\rho(h)\) at lag \(h \in \mathbb{Z}\) is the scale-invariant ratio:

\[ \rho(h) = \frac{\gamma(h)}{\gamma(0)} = \frac{\operatorname{Cov}(y_t, y_{t-h})}{\sqrt{\operatorname{Var}(y_t)\operatorname{Var}(y_{t-h})}}. \]

By Cauchy-Schwarz, \(|\rho(h)| \le 1\) with \(\rho(0) = 1\) and symmetry \(\rho(h) = \rho(-h)\).

2. First-Order Autoregressive Dynamics

Theorem 1.1 · AR(1) Moments and Geometric Autocorrelation

Assumptions:

  1. Let \(y_t = c + \phi y_{t-1} + \varepsilon_t\) for all \(t \in \mathbb{Z}\).
  2. The innovations satisfy \(\varepsilon_t \sim \operatorname{iid}(0, \sigma^2)\) with \(\sigma^2 > 0\).
  3. The persistence coefficient satisfies \(|\phi| < 1\).

Conclusion: There exists a unique weakly stationary causal solution with:

\[ \begin{aligned} \mu &= \frac{c}{1 - \phi}, \\ \gamma(0) &= \frac{\sigma^2}{1 - \phi^2}, \\ \rho(h) &= \phi^{|h|}, \quad \forall h \in \mathbb{Z}. \end{aligned} \]
Proof

Iterating backward \(k\) periods yields:

\[ y_t = c \sum_{j=0}^{k-1} \phi^j + \phi^k y_{t-k} + \sum_{j=0}^{k-1} \phi^j \varepsilon_{t-j}. \]

Since \(|\phi| < 1\), as \(k \to \infty\), \(\phi^k y_{t-k} \to 0\) in mean-square, and by the geometric series formula, \(c \sum_{j=0}^{\infty} \phi^j = c / (1 - \phi) = \mu\). Subtracting \(\mu\) gives the demeaned representation \(\tilde{y}_t = \sum_{j=0}^\infty \phi^j \varepsilon_{t-j}\). The unconditional variance is:

\[ \gamma(0) = \mathbb{E}\left[\left(\sum_{j=0}^\infty \phi^j \varepsilon_{t-j}\right)^2\right] = \sigma^2 \sum_{j=0}^\infty \phi^{2j} = \frac{\sigma^2}{1 - \phi^2}. \]

For \(h \ge 1\), multiplying \(\tilde{y}_t = \phi \tilde{y}_{t-1} + \varepsilon_t\) by \(\tilde{y}_{t-h}\) and taking expectations yields \(\gamma(h) = \phi \gamma(h-1)\). By induction, \(\gamma(h) = \phi^h \gamma(0)\), hence \(\rho(h) = \gamma(h) / \gamma(0) = \phi^h\).

Example 1.1 · Autocorrelation Decay Profile

Let \(\phi = 0.70\) and \(\sigma = 1.0\). Then unconditional variance is \(\gamma(0) = 1.0 / (1 - 0.49) = 1.9608\). The theoretical autocorrelations evaluate to:

\[ \rho(1) = 0.7000, \quad \rho(2) = 0.4900, \quad \rho(3) = 0.3430, \quad \rho(4) = 0.2401, \quad \rho(5) = 0.1681. \]

Notice the monotonic geometric decay toward zero without sign oscillation because \(\phi > 0\).

3. Empirical Verification

In finite samples of length \(T\), the sample autocorrelation is computed via plug-in estimators:

\[ \hat{\gamma}(h) = \frac{1}{T} \sum_{t=1}^{T-h} (y_t - \bar{y})(y_{t+h} - \bar{y}), \quad \hat{\rho}(h) = \frac{\hat{\gamma}(h)}{\hat{\gamma}(0)}. \]

Lab 1 · AR(1) Sample Autocorrelations vs. Geometric Powers

A simulated AR(1) process with phi=0.70 and T=500 produces sample autocorrelations that track theoretical powers phi^h within Monte Carlo sampling variation |diff| < 0.08.

"""Lab S3-L01-1: Sample autocorrelation function of an AR(1) process.

SIMULATED: generates a stationary AR(1) series and compares the empirical
sample autocorrelation function against the theoretical closed-form powers phi^h.
"""

from __future__ import annotations

import random


def simulate_ar1(phi: float, sigma: float, n: int, seed: int = 42) -> list[float]:
    """Generate stationary AR(1) path with burn-in."""
    rng = random.Random(seed)
    burn = 100
    y = 0.0
    for _ in range(burn):
        y = phi * y + rng.gauss(0.0, sigma)
    series: list[float] = []
    for _ in range(n):
        y = phi * y + rng.gauss(0.0, sigma)
        series.append(y)
    return series


def sample_acf(series: list[float], max_lag: int) -> list[float]:
    """Compute sample autocorrelations for lags 0 through max_lag."""
    n = len(series)
    mean_y = sum(series) / n
    demeaned = [val - mean_y for val in series]
    gamma0 = sum(d * d for d in demeaned) / n
    acf: list[float] = [1.0]
    for h in range(1, max_lag + 1):
        gamma_h = sum(demeaned[t] * demeaned[t + h] for t in range(n - h)) / n
        acf.append(gamma_h / gamma0)
    return acf


def main() -> None:
    phi = 0.70
    sigma = 1.0
    n = 500
    series = simulate_ar1(phi, sigma, n, seed=42)

    max_lag = 5
    emp_acf = sample_acf(series, max_lag)

    print(f"AR(1) Simulation (phi={phi:.2f}, n={n})")
    print(f"Sample mean: {sum(series) / n:+.4f} (theoretical: 0.0000)")
    mean_y = sum(series) / n
    var_emp = sum((v - mean_y) ** 2 for v in series) / n
    var_theo = (sigma**2) / (1.0 - phi**2)
    print(f"Sample variance: {var_emp:.4f} (theoretical: {var_theo:.4f})")
    print("Lag | Sample ACF | Theoretical | Diff")
    print("-" * 37)
    for h in range(1, max_lag + 1):
        theo = phi**h
        diff = emp_acf[h] - theo
        print(f"  {h} |    {emp_acf[h]:.4f}  |     {theo:.4f}  | {diff:+.4f}")

Where the Canon Breaks

Textbook time series analysis frequently presumes that stationarity is an intrinsic property of an economic series. In market practice, covariance stationarity is an operational assumption that regularly breaks:

  • Structural breaks in regime: Unconditional mean and volatility shift abruptly across monetary policy regimes or crisis periods, creating spurious persistence in sample ACFs.
  • Sample ACF downward bias: The plug-in estimator \(\hat{\rho}(h)\) suffers from Hurwicz-Kendall downward bias of order \(O(1/T)\), causing analysts to systematically underestimate long-horizon persistence.
  • Heavy tails and infinite variance: If innovations \(\varepsilon_t\) exhibit tail index \(\alpha \le 2\) (common in unconditioned high-frequency returns), \(\gamma(0)\) is undefined, rendering sample ACFs inconsistent.

Misconceptions

  • Wrong belief: A visually flat or oscillating historical chart proves that a series is stationary.

    Why it is wrong: A single sample path of an integrated random walk over small sample horizons can exhibit prolonged mean-reverting excursions. Visual inspection cannot distinguish slow unit-root drift from stationary persistence.

  • Wrong belief: A large lag-1 autocorrelation (\(\hat{\rho}(1) \approx 0.95\)) indicates the presence of a unit root.

    Why it is wrong: A stationary AR(1) with \(\phi = 0.95\) is strictly covariance-stationary with finite variance \(\sigma^2/(1 - 0.95^2) \approx 10.25 \sigma^2\). High persistence is not equivalent to a unit root.

  • Wrong belief: The sample autocorrelation estimator \(\hat{\rho}(h)\) is unbiased in finite samples.

    Why it is wrong: Because the sample mean \(\bar{y}\) is estimated from the same sample, deviations are negatively correlated across the sample period, creating an inherent negative bias of order \(-(1 + 4h)/T\).

Practice Problems

Mechanics Tier

An AR(1) process has specification \(y_t = 0.5 + 0.6 y_{t-1} + \varepsilon_t\) with innovation variance \(\sigma^2 = 2.0\). Calculate the unconditional mean \(\mu\), unconditional variance \(\gamma(0)\), and lag-2 autocovariance \(\gamma(2)\).

Worked Solution

Unconditional mean: \(\mu = c / (1 - \phi) = 0.5 / (1 - 0.6) = 1.25\). Unconditional variance: \(\gamma(0) = \sigma^2 / (1 - \phi^2) = 2.0 / (1 - 0.36) = 2.0 / 0.64 = 3.125\). Lag-2 autocovariance: \(\gamma(2) = \phi^2 \gamma(0) = 0.36 \times 3.125 = 1.125\).

Given an AR(1) process with \(\phi = -0.50\), compute the first four autocorrelations \(\rho(1), \rho(2), \rho(3), \rho(4)\).

Worked Solution

Autocorrelations follow \(\rho(h) = \phi^h\). Therefore: \(\rho(1) = -0.5000\), \(\rho(2) = (-0.5)^2 = +0.2500\), \(\rho(3) = (-0.5)^3 = -0.1250\), and \(\rho(4) = (-0.5)^4 = +0.0625\). The sequence exhibits damped oscillations about zero.

Suppose a process has \(\gamma(0) = 4.0\) and \(\gamma(1) = 2.8\). Calculate \(\rho(1)\) and evaluate whether the process can be an AR(1) with positive innovations.

Worked Solution

The lag-1 autocorrelation is \(\rho(1) = \gamma(1) / \gamma(0) = 2.8 / 4.0 = 0.70\). If modeled as an AR(1), \(\phi = 0.70 < 1\), giving required innovation variance \(\sigma^2 = \gamma(0)(1 - \phi^2) = 4.0(1 - 0.49) = 2.04 > 0\), which is valid.

Proof Tier

Prove that a pure random walk \(y_t = y_{t-1} + \varepsilon_t\) with \(y_0 = 0\) and \(\varepsilon_t \sim \operatorname{iid}(0, \sigma^2)\) violates weak stationarity.

Worked Solution

Expanding the recursion yields \(y_t = \sum_{j=1}^t \varepsilon_j\). The unconditional variance is \(\operatorname{Var}(y_t) = \operatorname{Var}\left(\sum_{j=1}^t \varepsilon_j\right) = t \sigma^2\). Because \(\operatorname{Var}(y_t)\) depends directly on the time index \(t\) and grows without bound as \(t \to \infty\), condition 2 of weak stationarity is violated.

Prove that the autocovariance function of any weakly stationary process is positive semi-definite.

Worked Solution

Consider any linear combination \(Z = \sum_{j=1}^k a_j y_{t_j}\) for arbitrary real weights \(a_j\) and times \(t_j\). By the non-negativity of variance, \(0 \le \operatorname{Var}(Z) = \sum_{i=1}^k \sum_{j=1}^k a_i a_j \operatorname{Cov}(y_{t_i}, y_{t_j}) = \sum_{i=1}^k \sum_{j=1}^k a_i a_j \gamma(t_i - t_j) = a^\top \Gamma_k a\). Since this quadratic form is non-negative for all non-zero \(a \in \mathbb{R}^k\), the Toeplitz autocovariance matrix \(\Gamma_k\) is positive semi-definite.

Prove that if \(y_t\) is weakly stationary with autocorrelation function \(\rho(h)\), then \(\rho(h) \to 0\) as \(h \to \infty\) is necessary for the sample mean \(\bar{y} = \frac{1}{T} \sum_{t=1}^T y_t\) to be mean-square consistent.

Worked Solution

The variance of the sample mean is \(\operatorname{Var}(\bar{y}) = \frac{\gamma(0)}{T} \sum_{h=-(T-1)}^{T-1} \left(1 - \frac{|h|}{T}\right) \rho(h)\). For \(\operatorname{Var}(\bar{y}) \to 0\) as \(T \to \infty\), Cesàro summability requires that the average autocorrelation vanishes, which holds if \(\rho(h) \to 0\) sufficiently fast such that \(\sum_{h=0}^\infty |\rho(h)| < \infty\).

Empirical Tier

In a sample of \(T = 200\) daily stock return observations, the sample autocorrelations are \(\hat{\rho}(1) = 0.04\) and \(\hat{\rho}(2) = -0.06\). Using Bartlett's formula \(\operatorname{Var}(\hat{\rho}(h)) \approx 1/T\) under the null of white noise, construct the 95% confidence intervals and test for predictability.

Worked Solution

Under the white noise null, the standard error is \(\operatorname{SE} = 1 / \sqrt{T} = 1 / \sqrt{200} \approx 0.0707\). The 95% critical bounds are \(\pm 1.96 \times 0.0707 = \pm 0.1386\). Since both \(\hat{\rho}(1) = 0.04\) and \(\hat{\rho}(2) = -0.06\) lie strictly inside \([-0.1386, +0.1386]\), neither is statistically significant, consistent with market efficiency.

Explain how an unmodeled deterministic linear trend \(y_t = \alpha + \beta t + u_t\) with stationary \(u_t\) distorts the sample autocorrelation function if calculated on levels.

Worked Solution

Because \(\bar{y}\) averages the deterministic upward ramp, early observations lie systematically below \(\bar{y}\) and late observations lie systematically above \(\bar{y}\). Consequently, cross-products \((y_t - \bar{y})(y_{t+h} - \bar{y})\) are overwhelmingly positive for all finite lags \(h\), causing \(\hat{\rho}(h)\) to decay very slowly toward zero, falsely mimicking an integrated unit-root process.

Describe the Kendall bias formula for the sample autocorrelation of an AR(1) process of length \(T\), and compute the expected bias for \(\phi = 0.80\) with \(T = 100\).

Worked Solution

Kendall's formula approximates the expected sample autocorrelation as \(\mathbb{E}[\hat{\rho}(1)] \approx \phi - \frac{1 + 4\phi}{T}\). For \(\phi = 0.80\) and \(T = 100\), the bias is \(-(1 + 4 \times 0.80)/100 = -4.2 / 100 = -0.042\). The expected sample estimate is approximately \(0.80 - 0.042 = 0.758\), showing substantial underestimation of persistence in moderate samples.

Research Tier

Contrast the autocovariance behavior of a short-memory AR(1) process with a long-memory fractionally integrated \(I(d)\) process where \(0 < d < 0.5\).

Worked Solution

A short-memory AR(1) process exhibits exponential autocovariance decay \(\rho(h) \sim \phi^h\), which is absolutely summable \(\sum_{h=0}^\infty |\rho(h)| < \infty\). In contrast, a fractionally integrated \(I(d)\) process exhibits hyperbolic decay \(\rho(h) \sim c h^{2d-1}\). For \(0 < d < 0.5\), the autocovariance sequence is non-summable \(\sum_{h=0}^\infty \rho(h) = \infty\), generating persistent long-range dependence observed in volatility time series.

Explain why estimating volatility dynamics using squared daily returns \(r_t^2\) yields low sample autocorrelations even when true latent volatility is highly persistent.

Worked Solution

Under stochastic volatility models \(r_t = \sigma_t z_t\) with \(\operatorname{iid}\) standard normal \(z_t\), the squared return is \(r_t^2 = \sigma_t^2 z_t^2 = \sigma_t^2 + \sigma_t^2(z_t^2 - 1)\). The term \(\sigma_t^2(z_t^2 - 1)\) acts as massive observational measurement noise. By errors-in-variables, the autocorrelation of \(r_t^2\) is attenuated by the factor \(\operatorname{Var}(\sigma_t^2) / \operatorname{Var}(r_t^2)\), which is typically less than 0.20 in financial equities.

How does cross-sectional aggregation of heterogeneous stationary AR(1) micro-series generate aggregate long memory in macro-financial time series?

Worked Solution

Following the Granger (1980) aggregation theorem, if individual economic agents or assets have persistence parameters \(\phi_i\) drawn from a Beta distribution over \([0, 1)\), the aggregate series \(Y_t = \sum_{i=1}^N y_{i,t}\) exhibits autocovariance decay that matches a fractionally integrated process \(I(d)\) as \(N \to \infty\). Heterogeneity in micro-dynamics naturally aggregates into macroeconomic power-law persistence.

Retrieval Quiz

  1. Which set of conditions defines weak (covariance) stationarity for a discrete process \(y_t\)?

    Weak stationarity requires a constant unconditional mean, a finite constant unconditional variance, and an autocovariance function that depends only on the lag separation \(h\).

  2. For an AR(1) model \(y_t = c + \phi y_{t-1} + \varepsilon_t\) with \(\varepsilon_t \sim \operatorname{iid}(0, \sigma^2)\), what is the necessary and sufficient condition for causality and weak stationarity?

    The condition \(|\phi| < 1\) places the root of \(1 - \phi z = 0\) strictly outside the complex unit circle (\(|z| = |1/\phi| > 1\)), which is necessary and sufficient for causality and covariance stationarity.

  3. What is the theoretical lag-3 autocorrelation \(\rho(3)\) of an AR(1) process with persistence parameter \(\phi = 0.60\)?

    For an AR(1), \(\rho(h) = \phi^h\). At lag 3, \(\rho(3) = 0.60^3 = 0.2160\).

  4. Why is a pure random walk with iid innovations \(y_t = y_{t-1} + \varepsilon_t\) non-stationary?

    A random walk accumulating \(t\) innovations has unconditional variance \(\operatorname{Var}(y_t) = t \sigma^2\), which is a function of time and violates the constant variance requirement.

  5. What mathematical property ensures that any valid autocovariance matrix \(\Gamma_k\) is positive semi-definite?

    For any vector \(a\), the variance of \(a^\top Y\) is \(a^\top \Gamma_k a \ge 0\). Variance is strictly non-negative, which defines positive semi-definiteness.

  6. Under the null hypothesis that a time series is Gaussian white noise, what is the asymptotic variance of the sample autocorrelation estimator \(\hat{\rho}(h)\)?

    By Bartlett's formula, for an iid process the sample autocorrelations are asymptotically independent with mean 0 and variance \(1/T\).

  7. What pattern does the autocorrelation function of an AR(1) process with negative persistence \(\phi \in (-1, 0)\) display?

    Because \(\rho(h) = \phi^h\) and \(\phi < 0\), \(\phi^h\) is negative for odd lags and positive for even lags, producing damped oscillation.

  8. In finite samples of size \(T\), how does the sample autocorrelation estimator \(\hat{\rho}(1)\) behave relative to the true parameter \(\phi\)?

    Kendall showed that estimating the sample mean induces a negative finite-sample bias of order \(-(1 + 4\phi)/T\) on the lag-1 autocorrelation.
