Cost-of-Capital Estimation Under Uncertainty

A corporate acquisition committee requires an rigorous estimation of a target company’s cost of capital and enterprise valuation range. You write wacc_engine.py, the estimation engine that computes OLS beta, Hamada unlevering and relevering, CAPM cost of equity, after-tax cost of debt, weighted average cost of capital (WACC), first-order delta-method variance (WACC estimation error), and growing perpetuity enterprise valuation ranges. Then you draft an executive memo (memo.md) presenting your valuation intervals and evaluating capital structure dynamics. The project uses dual grading: the autograder tests your engine across 50 pseudo-random seeds, while the rubric evaluates your memo.

The ladder

Follow the four rungs in order. If you demonstrated competency on the module hub placement quiz and answered both skill checks, you may proceed directly to rung 3.

  1. Rung 1 · Worked example

    Lab 1 below: end-to-end cost-of-capital estimation and delta-method valuation range on a SIMULATED firm.

  2. Rung 2 · Completion

    Lab 2 below: complete the missing unlevering, WACC, delta variance, and valuation bounds.

  3. Rung 3 · Independent

    Write wacc_engine.py and memo.md following the formal specification. Verified against the automated test suite and Lab 3 benchmark.

  4. Rung 4 · Stretch

    Bootstrap estimation of equity beta standard errors and empirical comparison against delta-method analytical variance.

Rungs 1 and 2

Lab 1 · Worked example: Full cost of capital pipeline

Evaluates a simulated corporate issuer with 40M debt and 60M equity (tau_c = 25%). Unlevers equity beta (1.30) to asset beta (0.9467), computes WACC (8.4875%), evaluates analytical delta-method standard error (114.7 bps), and establishes base valuation of $77.07M with an uncertainty span of $28.05M ($65.55M to $93.60M at k = 1.0 SE).

"""CF2 project lab 1 (rung 1, worked example): Full cost of capital pipeline under uncertainty.

SIMULATED: Firm data and market assumptions are generated for a simulated corporate issuer.
Money is in integer cents; component rates are floats; valuations are rounded half-up in cents.
Standard library only; no external network access.
Demonstrates the full end-to-end valuation pipeline with delta-method error propagation.
"""

from __future__ import annotations

import math
from decimal import ROUND_HALF_UP, Decimal


def main() -> None:
    print("CF2 Project Rung 1: Cost-of-Capital Estimation Pipeline (Worked Example)")
    print("======================================================================")

    # 1. Stated Inputs
    debt_cents = 4_000_000_000  # $40,000,000.00
    equity_cents = 6_000_000_000  # $60,000,000.00
    total_cents = debt_cents + equity_cents  # $100,000,000.00
    tau_c = 0.25

    rf = 0.0425  # 4.25% 10-year Treasury constant-maturity rate
    erp = 0.0550  # 5.50% Equity risk premium
    spread = 0.0175  # 1.75% (175 bps) debt credit spread

    beta_l = 1.30  # Estimated levered equity beta
    var_beta = 0.0225  # se(beta) = 0.150
    var_erp = 0.000100  # se(ERP) = 0.010 (100 bps)
    cov_beta_erp = 0.000300  # Positive estimation covariance
    var_spread = 0.000016  # se(spread) = 0.004 (40 bps)

    cash_flow_cents = 500_000_000  # $5,000,000.00 next-period operating cash flow
    growth = 0.0200  # 2.00% terminal growth

    # 2. Capital Structure Weights and Unlevering
    w_e = equity_cents / total_cents
    w_d = debt_cents / total_cents
    de_ratio = debt_cents / equity_cents
    beta_u = beta_l / (1.0 + (1.0 - tau_c) * de_ratio)

    # 3. Cost of Capital Components
    re = rf + beta_l * erp
    rd = rf + spread
    after_tax_rd = rd * (1.0 - tau_c)
    r_wacc = w_e * re + w_d * after_tax_rd

    # 4. Delta-Method Variance of WACC
    # Gradient: [w_E * ERP, w_E * beta, w_D * (1 - tau_c)]
    term_equity = (w_e**2) * (erp**2 * var_beta + beta_l**2 * var_erp + 2.0 * beta_l * erp * cov_beta_erp)
    term_debt = (w_d * (1.0 - tau_c)) ** 2 * var_spread
    wacc_var = term_equity + term_debt
    wacc_se = math.sqrt(wacc_var)

    # 5. Valuation Range using Decimal half-up rounding
    k = 1.0
    d_mid = Decimal(str(r_wacc))
    d_se = Decimal(str(wacc_se))
    d_g = Decimal(str(growth))
    d_cf = Decimal(cash_flow_cents)

    r_low = d_mid - Decimal(str(k)) * d_se
    r_high = d_mid + Decimal(str(k)) * d_se

    val_low = (d_cf / (r_high - d_g)).quantize(Decimal("1"), rounding=ROUND_HALF_UP)
    val_base = (d_cf / (d_mid - d_g)).quantize(Decimal("1"), rounding=ROUND_HALF_UP)
    val_high = (d_cf / (r_low - d_g)).quantize(Decimal("1"), rounding=ROUND_HALF_UP)

    cap_str = (
        f"Capital: Debt = ${debt_cents / 100:,.2f} | Equity = ${equity_cents / 100:,.2f} | "
        f"Total = ${total_cents / 100:,.2f}"
    )
    print(cap_str)
    print(f"Weights: w_E = {w_e:.4f}, w_D = {w_d:.4f}, D/E = {de_ratio:.4f}")
    print(f"Asset beta (beta_U):        {beta_u:.4f} (from equity beta {beta_l:.4f})")
    print(f"Cost of equity (r_E):       {re:.4%}")
    print(f"Pre-tax cost of debt (r_D): {rd:.4%}")
    print(f"After-tax cost of debt:     {after_tax_rd:.4%}")
    print(f"WACC point estimate:        {r_wacc:.4%}")
    print(f"Delta-method variance:      {wacc_var:.8f}")
    print(f"Delta-method standard error:{wacc_se:.4%} ({wacc_se * 10000:.1f} bps)")
    print(f"\nTerminal growth rate (g):   {growth:.2%}")
    print(f"Base Enterprise Valuation:  ${int(val_base) / 100:,.2f}")
    print("Valuation Band (k = 1.0 SE):")
    print(f"  Low valuation (at {float(r_high):.4%}):  ${int(val_low) / 100:,.2f}")
    print(f"  High valuation (at {float(r_low):.4%}): ${int(val_high) / 100:,.2f}")
    print(f"  Valuation Uncertainty Span:   ${(int(val_high) - int(val_low)) / 100:,.2f}")


main()

Rung 3 · Specification

Context
A corporate acquisition committee requires an independent valuation of an acquisition target. The committee requires both an algorithmic estimation engine (wacc_engine.py) implementing beta estimation, capital structure adjustment, WACC calculation, and delta-method uncertainty propagation, and a rigorous executive memorandum (memo.md) documenting data provenance, parameter uncertainty, and capital structure trade-offs.
Inputs
The estimation engine and memo ingest five distinct inputs:
  1. Risk-free benchmark rate (\(r_f\)): 10-year Treasury constant-maturity yield (cmt_10y) from the embedded market dataset ust_daily.csv, taking the latest valid observation on or before the valuation date (real data from Federal Reserve Board H.15).
  2. Historical return series: Periodic stock and market returns (at least 36 periods) for OLS beta regression.
  3. Equity risk premium (\(\mathrm{ERP}\)): Forward-looking annual equity risk premium with variance \(\mathrm{Var}(\mathrm{ERP})\) and estimation covariance \(\mathrm{Cov}(\beta, \mathrm{ERP})\).
  4. Corporate debt credit spread (\(s\)): Spread over the risk-free rate with variance \(\mathrm{Var}(s)\).
  5. Capital structure and cash flows: Market value of debt and equity in integer cents, statutory corporate tax rate \(\tau_c \in [0, 1)\), next-period operating cash flow \(C_1\) in integer cents, and terminal growth rate \(g\).
Required outputs
Two core deliverables:
  • wacc_engine.py: Standard-library Python module containing the eight required functions (beta_ols, unlever_beta, relever_beta, cost_of_equity, cost_of_debt, wacc, wacc_delta_variance, valuation_range).
  • memo.md: Executive case memo (1–2 pages) presenting point estimates, standard errors, valuation bounds in integer cents, and policy implications.
Constraints
  • Money quantities must be formatted and computed in integer cents; component rates and weights are decimals.
  • Standard library only: no external dependencies (numpy, pandas, scipy). Use math and decimal.
  • Valuation bounds must use Decimal.quantize(Decimal("1"), rounding=ROUND_HALF_UP).
  • All invalid inputs (e.g. \(D < 0\), \(E \le 0\), \(\tau_c \notin [0, 1)\), \(r \le g\), non-positive integer cash flows, \(k < 0\)) must raise ValueError.
Grading
Grading: both. The autograder runs the engine's test suite; the rubric grades the memo. The autograder runs 24 property and numerical tests across seeds 0–49 to verify exact mathematical correctness, boundary validation, and error propagation. The rubric grades the executive memo across five analytical criteria.

"""CF2 project lab 3 (rung 3 check): Reference numbers for independent memo evaluation.

from __future__ import annotations

import csv
import math
from decimal import ROUND_HALF_UP, Decimal
from pathlib import Path

VALUATION_DATE = "2026-09-30"


def read_risk_free_rate(csv_path: Path, target_date: str) -> float:
    """Read 10-year Treasury constant-maturity yield on or before target date from ust_daily.csv."""
    latest_yield = None
    with csv_path.open(encoding="utf-8") as f:
        reader = csv.DictReader(f)
        for row in reader:
            if row["date"] <= target_date and row["cmt_10y"]:
                latest_yield = float(row["cmt_10y"])
    if latest_yield is None:
        raise ValueError(f"No Treasury yield found on or before {target_date}")
    # Published by H.15 in percent per year; convert to decimal
    return latest_yield / 100.0

    # Pipeline calculations

Exemplar A (Level 4 · Exemplary)

Official scoring: C1 4 · C2 4 · C3 4 · C4 4 · C5 4.

1 Data and Provenance

Valuation date: 2026-09-30. Benchmark risk-free rate \(r_f = 4.1500\%\), obtained from the Federal Reserve Board H.15 constant-maturity 10-year Treasury yield (cmt_10y) in ust_daily.csv. Forward equity risk premium \(\mathrm{ERP} = 5.0000\%\) with estimation variance \(\mathrm{Var}(\mathrm{ERP}) = 0.000100\) (BYOD/SIMULATED). Corporate credit spread \(s = 1.8000\%\) (180 bps) with variance \(\mathrm{Var}(s) = 0.000016\) (BYOD/SIMULATED). Market equity is 5,500,000,000 cents ($55.0M) and market debt is 4,500,000,000 cents ($45.0M). Statutory tax rate \(\tau_c = 0.25\). Next-period operating cash flow \(C_1 = 600,000,000\) cents ($6.0M) with terminal growth \(g = 2.0000\%\).

C1, Level 4: All five inputs named with explicit provenance, exact dates, SIMULATED/real classifications, and units.

2 Beta and Capital Weights

Market capital weights: \(w_E = 0.5500\), \(w_D = 0.4500\), yielding market debt-equity ratio \(D/E = 45/55 \approx 0.8182\). Under Assumption A7 (perpetual debt, constant leverage ratio, and risk-free debt beta \(\beta_D = 0\)), the Hamada relation unlevers the observed equity beta \(\beta_L = 1.1500\) to an asset beta of \(\beta_U = 1.1500 / [1 + (1 - 0.25)(0.8182)] = 0.8168\).

C2, Level 4: States exact unlevering assumptions, debt beta zero convention, market debt-equity ratio, and computed asset beta.

3 WACC and Estimation Error

Cost of equity: \(r_E = 4.1500\% + 1.1500(5.0000\%) = 9.9000\%\). Pre-tax cost of debt: \(r_D = 4.1500\% + 1.8000\% = 5.9500\%\); after-tax cost of debt: \(r_D(1 - \tau_c) = 5.9500\% \times 0.75 = 4.4625\%\). The weighted average cost of capital is \(r_{\mathrm{WACC}} = 0.55(9.9000\%) + 0.45(4.4625\%) = 7.4531\%\). Propagating parameter variances (\(\mathrm{Var}(\beta) = 0.0196\), \(\mathrm{Var}(\mathrm{ERP}) = 0.000100\), \(\mathrm{Cov}(\beta, \mathrm{ERP}) = 0.000200\), \(\mathrm{Var}(s) = 0.000016\)) via the first-order delta method yields variance \(\mathrm{Var}(r_{\mathrm{WACC}}) = 0.00011800\) and standard error \(\mathrm{se}(r_{\mathrm{WACC}}) = 1.0863\%\) (108.6 bps). Note that the first-order delta expansion omits the positive second-order term \(w_E^2 [\mathrm{Var}(\beta)\mathrm{Var}(\mathrm{ERP}) + \mathrm{Cov}^2] = 6.2 \times 10^{-7}\), which negligibly affects the standard error.

C3, Level 4: Fully reports WACC components, analytical delta-method standard error, covariance term, and quantifies the omitted second-order Taylor term.

5 Limits and Evidence
