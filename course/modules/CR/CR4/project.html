Lab 1 · Project Worked Example: Capital Structure Recovery Waterfall

A multi-tranche capital structure recovery waterfall preserves total enterprise value across liquidation and reorganization scenarios, identifying the fulcrum security and evaluating distressed investor expected returns.

"""Lab CR4-project-1: Project Rung 1 Worked Example — Capital Structure Recovery Waterfall.

Fully solved instance of the capital structure recovery waterfall, fulcrum security detection,
consensual plan carve-out reallocation, and distressed investor expected return analysis.
"""

from __future__ import annotations

from typing import NamedTuple


class Tranche(NamedTuple):
    name: str
    claim: float
    seniority: int


class Scenario(NamedTuple):
    name: str
    ev: float
    prob: float


def main() -> None:
    # Stylized Capital Structure
    tranches = [
        Tranche("DIP Facility", 20.0, 1),
        Tranche("First Lien Term Loan", 100.0, 2),
        Tranche("Second Lien Notes", 60.0, 3),
        Tranche("Senior Unsecured Notes", 80.0, 4),
        Tranche("Subordinated Debentures", 40.0, 5),
        Tranche("Common Equity", 0.0, 6),
    ]
    total_debt = sum(t.claim for t in tranches if t.claim > 0)  # 300.0

    scenarios = [
        Scenario("Liquidation", 70.0, 0.20),
        Scenario("Low Reorganization", 140.0, 0.30),
        Scenario("Base Reorganization", 220.0, 0.35),
        Scenario("High Reorganization", 340.0, 0.15),
    ]

    purchase_prices = {
        "First Lien Term Loan": 0.85,
        "Second Lien Notes": 0.55,
        "Senior Unsecured Notes": 0.28,
        "Subordinated Debentures": 0.08,
    }
    holding_period = 1.5  # years

    print("Project Rung 1: Capital Structure Recovery Waterfall & Fulcrum Analysis")
    print(f"Company: Horizon Industrial Systems · Total Contractual Debt Claims = {total_debt:.1f}")
    print("=" * 80)

    # 1. Strict Waterfall Across Scenarios
    print("\n1. Strict Absolute Priority Waterfall Schedule Across Scenarios:")
    print("Tranche Name            | Claim | Liq ($70M) | Low ($140M) | Base ($220M) | High ($340M)")
    print("-" * 79)

    scenario_allocations: list[list[float]] = []
    fulcrum_names: list[str] = []

    for s in scenarios:
        ev = s.ev
        rem = ev
        s_allocs: list[float] = []
        fulcrum_found = False
        fulcrum_str = "None (Solvent)"

        for t in tranches:
            c = t.claim
            if c > 0:
                alloc = min(rem, c)
                rem -= alloc
            else:
                alloc = rem if rem > 0 else 0.0
                rem = 0.0
            s_allocs.append(alloc)

            if not fulcrum_found and ev < total_debt and c > 0:
                is_part = 0.0 < alloc < c
                is_bound = abs(alloc - c) < 1e-6 and abs(ev - sum(s_allocs)) < 1e-6 and rem == 0.0
                if is_part or is_bound:
                    fulcrum_str = t.name
                    fulcrum_found = True

        scenario_allocations.append(s_allocs)
        fulcrum_names.append(fulcrum_str)

    for i, t in enumerate(tranches):
        c = t.claim
        c_str = f"{c:5.1f}" if c > 0 else "  N/A"
        row_str = f"{t.name:23} | {c_str} |"
        for s_idx in range(len(scenarios)):
            alloc = scenario_allocations[s_idx][i]
            pct = (alloc / c * 100.0) if c > 0 else (100.0 if alloc > 0 else 0.0)
            row_str += f" {alloc:5.1f} ({pct:3.0f}%) |"
        print(row_str)

    print("-" * 79)
    fn0 = fulcrum_names[0][:10]
    fn1 = fulcrum_names[1][:11]
    fn2 = fulcrum_names[2][:12]
    fn3 = fulcrum_names[3][:11]
    print(f"Identified Fulcrum      |  N/A  | {fn0:10} | {fn1:11} | {fn2:12} | {fn3:11}")

    # 2. Carveout in Base Reorganization
    # Senior Unsecured transfers 6% of its allocation to Common Equity
    base_allocs = scenario_allocations[2]
    unsec_idx = 3
    equity_idx = 5
    carveout_pct = 0.06
    carveout_amt = base_allocs[unsec_idx] * carveout_pct

    adj_unsec = base_allocs[unsec_idx] - carveout_amt
    adj_equity = base_allocs[equity_idx] + carveout_amt

    print("\n2. Consensual Plan Carve-Out (Base Scenario: EV = $220M):")
    b_u = base_allocs[unsec_idx]
    print(f"Senior Unsecured: {b_u:.2f} -> minus 6% carve-out ({carveout_amt:.2f}) = {adj_unsec:.2f}")
    print(f"Common Equity initial: {base_allocs[equity_idx]:.2f} -> plus carve-out gift = {adj_equity:.2f}")
    print(f"Total value distributed conserved: {sum(base_allocs):.2f} == {sum(base_allocs):.2f}")

    # 3. Expected Returns
    print("\n3. Distressed Investor Return Evaluation (Holding Period = 1.5 Years):")
    print("Tranche Name            | Purchase Price | Invested ($M) | Expected Rec ($M) |   MOIC   | Annualized IRR")
    print("-" * 96)

    tot_inv = 0.0
    tot_rec = 0.0

    for i, t in enumerate(tranches):
        name = t.name
        c = t.claim
        if name in purchase_prices and c > 0:
            price = purchase_prices[name]
            inv = price * c
            exp_rec = sum(scenarios[s_idx].prob * scenario_allocations[s_idx][i] for s_idx in range(len(scenarios)))
            tot_inv += inv
            tot_rec += exp_rec
            moic = exp_rec / inv if inv > 0 else 0.0
            irr = (moic ** (1.0 / holding_period) - 1.0) * 100.0 if moic > 0 else -100.0
            p_s = f"{price:4.2f}"
            i_s = f"{inv:5.1f}"
            r_s = f"{exp_rec:5.1f}"
            m_s = f"{moic:5.2f}x"
            ir_s = f"{irr:5.1f}%"
            print(f"{name:23} |      {p_s}      |     {i_s}     |       {r_s}       |  {m_s}  |     {ir_s}")

    port_moic = tot_rec / tot_inv if tot_inv > 0 else 0.0
    port_irr = (port_moic ** (1.0 / holding_period) - 1.0) * 100.0 if port_moic > 0 else -100.0
    print("-" * 96)
    ti_s = f"{tot_inv:5.1f}"
    tr_s = f"{tot_rec:5.1f}"
    pm_s = f"{port_moic:5.2f}x"
    pi_s = f"{port_irr:5.1f}%"
    print(f"Total Distressed Debt   |      N/A       |     {ti_s}     |       {tr_s}       |  {pm_s}  |     {pi_s}")

    # Invariant assertions
    assert abs(sum(base_allocs) - 220.0) < 1e-9
    assert fulcrum_names[2] == "Senior Unsecured Notes"
    assert port_moic > 1.0
    print("\nAll project rung 1 calculations verified.")


main()

    fulcrum_name = "None"

    total_debt = sum(t.claim for t in tranches)

        is_bound = abs(alloc - claim) < 1e-6 and abs(rem) < 1e-6
        if not fulcrum_found and ev < total_debt and claim > 0 and (___ or is_bound):

Specification

In this project, you construct a production Python engine waterfall.py that executes a multi-tranche capital structure recovery waterfall, determines fulcrum securities across probabilistic enterprise value scenarios, models consensual plan carve-outs, articulates Plan of Reorganization consideration, and evaluates secondary distressed debt investment returns.

Context
A middle-market industrial manufacturer has defaulted on its debt and is negotiating a Chapter 11 Plan of Reorganization. The capital structure consists of multiple prioritized debt tranches: Debtor-in-Possession (DIP) facility, First Lien Term Loan, Second Lien Notes, Senior Unsecured Notes, and Subordinated Debentures. Financial advisors have established four probabilistic enterprise value scenarios: Liquidation, Low Reorganization, Base Reorganization, and High Reorganization. Distressed debt hedge funds hold positions across secondary tranches and seek to determine expected recoveries, fulcrum equitization economics, and investment yields.
Inputs
The instance generator grader/instance.py provides a randomized debtor instance:
  • company_name (str): Corporate debtor name.
  • tranches (list of dict): Debt tranches sorted by seniority (1 = highest priority), each with name, claim, and seniority. Common equity is represented with claim 0.0.
  • scenarios (list of dict): Valuation outcomes, each with name, ev, and prob (probabilities summing to 1.0).
  • holding_period_years (float): Time horizon to restructuring exit (typically 1.0 to 2.5 years).
  • purchase_prices (dict): Secondary market purchase price (in cents on the dollar, e.g., 0.35) for each debt tranche.
  • consensual_carveout_pct (float): Fraction of fulcrum tranche recovery gifted to old equity in consensual negotiations (typically 0.04 to 0.08).
Required outputs
Your module waterfall.py must expose the following pure functions:
  1. calculate_waterfall_strict(tranches: list[dict], ev: float) -> list[dict]: Allocates available enterprise value down the capital structure under strict Absolute Priority. Returns a list of dicts with name, claim, allocated, recovery_pct, and is_fulcrum.
  2. calculate_waterfall_with_carveout(tranches: list[dict], ev: float, carveout_pct: float) -> list[dict]: Applies a negotiated consensual carve-out from the fulcrum tranche to equity. Strictly conserves total distributed enterprise value.
  3. reorganization_equity_distribution(tranches: list[dict], ev: float, cash_retained: float, takeback_debt_face: float) -> dict: Determines post-emergence Plan of Reorganization distributions. Allocates cash and reinstated/take-back debt to senior fully covered tranches, and distributes reorganized common equity value (\(\text{EV} - \text{takeback debt}\)) to the fulcrum class.
  4. evaluate_expected_returns(tranches: list[dict], scenarios: list[dict], purchase_prices: dict, holding_period: float) -> dict: Calculates scenario-weighted expected recovery, Multiple on Invested Capital (MOIC), and annualized Internal Rate of Return (IRR) for each individual tranche and the aggregate distressed portfolio.
  5. run_waterfall_engine(instance: dict) -> dict: Orchestrates the entire valuation workflow, returning structured execution outputs across all scenarios and investment analytics.
Constraints
The module must use only the Python standard library. Functions must be pure: no mutations of input dictionaries or lists, no print statements, and no global state. Calculations must maintain floating-point precision with value conservation holding to within \(10^{-6}\). Seniority monotonicity must be strictly maintained in all scenarios. If enterprise value is less than total debt, exactly one fulcrum tranche must be identified.
Grading
Grading: both autograder and rubric. The autograder tests waterfall.py against 50 randomized seeds in grader/test_project.py, testing value conservation, strict APR allocation, fulcrum uniqueness, consensual carve-out mechanics, POR equity distribution, and investor MOIC/IRR metrics. The rubric grades the restructuring investment memo against criteria C1–C5.

Two exemplars

Two sample memos written to this brief on the Horizon Industrial Systems instance (Lab 1), demonstrating performance at Level 2 (Developing) versus Level 4 (Exemplary).

Exemplar A · Developing (Score: 2 / 2 / 2 / 2 / 2)

Official scoring: C1 2 · C2 2 · C3 2 · C4 2 · C5 2.

1 Executive Summary & Waterfall Recovery

Horizon Industrial Systems has total debt of $300M. If enterprise value is $220M in the reorganization, senior debt gets paid in full and the senior unsecured notes recover $40M, which is a 50% recovery. We recommend buying the senior unsecured notes at 28 cents because 50% is higher than 28%.

C1, level 2: Reports numbers for only one scenario; fails to demonstrate mathematical value conservation across the full scenario distribution.

2 Fulcrum Analysis

The senior unsecured notes are the fulcrum security because they do not get paid in full. They get some money and the subordinated notes get zero.

C2, level 2: States the fulcrum definition intuitively but fails to analyze fulcrum migration across the other three valuation scenarios ($70M, $140M, $340M).

3 Plan Carve-Out

The company agrees to give 6% to common equity so they don't fight. This leaves less money for the creditors, but it is necessary.

C3, level 2: Describes the carve-out qualitatively but does not compute the exact dollar reduction ($2.40M) from the fulcrum tranche or show that total estate value is conserved.

4 Investment Returns

We invest $22.4M in senior unsecured notes. In the base case we get back $40M, which is a profit of $17.6M. The simple return is 78.6%, or about 52% per year over 1.5 years.

C4, level 2: Computes simple non-compounded annual return instead of compound annualized IRR, and ignores the probability of liquidation failure.

5 Evidence

Bankruptcy practice shows that equity often gets a recovery even when debt is not paid in full. Industry lore asserts that workouts are cheaper than Chapter 11.

C5, level 2: Uses vague assertions without support; provides zero citations to verified registry keys or statutory sections.

Exemplar B · Exemplary (Score: 4 / 4 / 4 / 4 / 4)

Official scoring: C1 4 · C2 4 · C3 4 · C4 4 · C5 4.

1 Executive Summary & Capital Structure Waterfall

Horizon Industrial Systems presents total contractual debt claims of $300.0M: DIP Facility ($20.0M), First Lien Term Loan ($100.0M), Second Lien Notes ($60.0M), Senior Unsecured Notes ($80.0M), and Subordinated Debentures ($40.0M). Under the four evaluated enterprise value scenarios (Lab 1), strict Absolute Priority Rule allocation conserves total enterprise value identically (\(\sum V_k = \text{EV}\)):

  • Liquidation (\(\text{EV} = \$70.0\text{M}\), prob \(0.20\)): DIP receives $20.0M (100.0%); First Lien receives $50.0M (50.0%); Second Lien, Unsecured, Subordinated, and Equity receive $0.0M (0.0%). Fulcrum: First Lien Term Loan.
  • Low Reorganization (\(\text{EV} = \$140.0\text{M}\), prob \(0.30\)): DIP receives $20.0M (100.0%); First Lien receives $100.0M (100.0%); Second Lien receives $20.0M (33.33%); Junior tranches receive $0.0M. Fulcrum: Second Lien Notes.
  • Base Reorganization (\(\text{EV} = \$220.0\text{M}\), prob \(0.35\)): DIP receives $20.0M (100.0%); First Lien receives $100.0M (100.0%); Second Lien receives $60.0M (100.0%); Senior Unsecured receives $40.0M (50.0%); Subordinated and Equity receive $0.0M. Fulcrum: Senior Unsecured Notes.
  • High Reorganization (\(\text{EV} = \$340.0\text{M}\), prob \(0.15\)): All debt tranches receive 100.0% par recovery ($300.0M total); residual $40.0M flows to Common Equity. Fulcrum: None (Fully Solvent).

C1, level 4: Complete articulation of all four scenarios, verifying exact value conservation and strict priority monotonicity across all tranches.

2 Fulcrum Security & Control Shift Dynamics

The fulcrum security migrates down the capital structure as a monotonic step function of EV (Theorem 1.1 in L05): First Lien at $70M, Second Lien at $140M, Senior Unsecured at $220M, and solvent equity at $340M. In the most probable Base Reorganization scenario ($220M EV), the Senior Unsecured Notes represent the fulcrum security. Under the Plan of Reorganization, Senior Unsecured claims will be equitized, receiving 100% of the reorganized common equity (worth $40.0M), while First and Second Lien claims are refinanced or reinstated as take-back debt. Acquiring Senior Unsecured debt at 28 cents provides an entry multiple of 4.4x EV/EBITDA into the post-emergence operating entity.

C2, level 4: Thoroughly analyzes fulcrum migration, connects fulcrum equitization to post-reorganization equity ownership, and calculates implied entry multiples.

3 Consensual Plan Carve-Out Economics

Under Bankruptcy Code § 1121, debtor management holds exclusive rights to file a plan. Threatening a contested cramdown under § 1129(b) would impose 6 to 9 months of delay, destroying an estimated $8.0M to $12.0M in administrative professional fees and operational attrition (L03). To secure consensual plan acceptance under § 1126(c), the fulcrum Senior Unsecured class rationally grants a 6.0% carve-out ($2.40M) to existing common equity. This carve-out reduces Senior Unsecured recovery from $40.0M to $37.60M (a net recovery of 47.0%), while old equity receives $2.40M in new out-of-the-money warrants. Total distributed value remains strictly conserved at $220.00M ($20M DIP + $100M 1st Lien + $60M 2nd Lien + $37.60M Unsecured + $2.40M Equity), confirming the strategic bargaining equilibrium of Theorem 1.1.

C3, level 4: Rigorously details the delay-avoidance rationale under § 1121 and § 1126(c), proves exact dollar value conservation, and explains the warrant carve-out structure.

4 Distressed Debt Investment Return Evaluation

Evaluating an investment across secondary purchase prices (First Lien at 0.85, Second Lien at 0.55, Senior Unsecured at 0.28, and Subordinated at 0.08) over a 1.5-year holding horizon (Lab 1):

  • Senior Unsecured Notes: Purchase cost is $22.40M ($80M par @ 0.28). Expected dollar recovery across the four scenarios is \(\mathbb{E}[V] = 0.20(0) + 0.30(0) + 0.35(40.0) + 0.15(80.0) = \$26.0\text{M}\). The expected Multiple on Invested Capital is \(\text{MOIC} = 26.0 / 22.4 = 1.161\text{x}\), yielding an annualized compound \(\text{IRR} = (1.161)^{1/1.5} - 1 = 10.4\%\). Conditional on the Base scenario, MOIC is \(40.0 / 22.4 = 1.786\text{x}\) (\(46.2\%\) annualized IRR).
  • Subordinated Debentures: Purchase cost is $3.20M ($40M par @ 0.08). Subordinated debt recovers only in the High scenario ($40M), yielding expected recovery \(\mathbb{E}[V] = 0.15 \times 40.0 = \$6.0\text{M}\). Expected MOIC is \(6.0 / 3.2 = 1.875\text{x}\) (\(52.1\%\) annualized IRR).
  • Portfolio Aggregation: Total distressed portfolio cost is $143.60M, generating expected recovery of $158.00M, a portfolio MOIC of 1.100x and portfolio IRR of 6.6%. We recommend overweighting Senior Unsecured Notes due to favorable risk-adjusted loan-to-own optionality.

C4, level 4: Scenario-weighted expected recovery, exact MOIC, and compounded annualized IRR computed across all tranches and the aggregate portfolio.

5 Statutory and Empirical Grounding

Our recommendation is grounded in statutory bankruptcy jurisprudence and empirical literature. Under Section 316(b) of the Trust Indenture Act, out-of-court restructuring would fail due to the public bondholder holdout dilemma (Gilson, John & Lang 1990, p. 315). The high concentration of dispersed public unsecured bonds (representing 40% of total debt) necessitates Chapter 11 filing to bind dissenting holdouts via § 1126(c) class voting. Furthermore, historical default studies (Altman 1968, p. 589) confirm that distressed manufacturing firms suffer severe operating cash-flow contraction during extended restructuring disputes, validating our recommendation to execute the 6% consensual carve-out and avoid protracted cramdown litigation under § 1129(b).

C5, level 4: Integrates verified citations to Gilson et al. (1990) and Altman (1968) with exact locators and evidence grades, synthesizing financial and legal analysis.
