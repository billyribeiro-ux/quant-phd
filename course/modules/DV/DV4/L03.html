Longstaff–Schwartz Least-Squares Monte Carlo (LSMC)

Lattices and finite difference schemes scale exponentially with state space dimension, rendering multi-asset American options computationally intractable. Monte Carlo simulation easily circumvents the curse of dimensionality for European options, but traditionally struggled with early exercise because forward simulation cannot evaluate backwards-in-time conditional continuation expectations. The Longstaff–Schwartz least-squares Monte Carlo (LSMC) algorithm reconciles forward path simulation with backward dynamic programming by projecting discounted cash flows onto orthogonal basis functions on in-the-money paths.

  • Introduces: Longstaff–Schwartz least-squares Monte Carlo
  • Prerequisites: early-exercise boundary, Monte Carlo integration, optional stopping theorem

1. Backward Induction Along Simulated Trajectories

Consider an American option exercisable at discrete monitoring dates \(0 = t_0 < t_1 < \dots < t_K = T\) with time increments \(\Delta t = T / K\). Let \(S_{k, i}\) denote the simulated asset price on path \(i \in \{1, \dots, M\}\) at date \(t_k\). The intrinsic exercise payoff is \(g(S) = (K - S)^+\) for a put. At terminal maturity \(t_K\), the cash flow on path \(i\) is trivially \(C_{K, i} = g(S_{K, i})\).

At any interior date \(t_k\) (\(k = K-1, \dots, 1\)), the option holder compares the immediate exercise payoff \(g(S_{k, i})\) against the conditional continuation value:

\[ F(S_{k, i}) = \mathbb{E}^\mathbb{Q} \left[ e^{-r \Delta t} C_{k+1, i} \mid S_{k, i} \right] \]

If \(g(S_{k, i}) > F(S_{k, i})\), early exercise is optimal, so the path exercises at \(t_k\), setting \(C_{k, i} = g(S_{k, i})\). Otherwise, the option is held, and cash flows are discounted: \(C_{k, i} = e^{-r \Delta t} C_{k+1, i}\).

Definition 3.1 · Longstaff–Schwartz LSMC

Longstaff–Schwartz least-squares Monte Carlo (LSMC) is an algorithm that approximates the unknown conditional continuation value function \(F(S)\) at each backward induction date \(t_k\) by performing ordinary least-squares regression of discounted realized future cash flows onto a finite set of \(P\) linearly independent orthogonal basis functions \(\{\psi_p(S)\}_{p=1}^P\) exclusively across in-the-money paths.

2. In-the-Money Path Regression and Orthogonal Bases

Following Longstaff & Schwartz (2001), regression is restricted strictly to paths where immediate exercise is in the money (\(g(S_{k, i}) > 0\)). Paths currently out of the money cannot be exercised at \(t_k\); including them dilutes the regression fit near the early-exercise boundary.

Let \(\mathcal{I}_k = \{i \in \{1, \dots, M\} : g(S_{k, i}) > 0\}\) be the in-the-money path index set with size \(M_k = |\mathcal{I}_k|\). The design matrix \(\mathbf{\Psi}_k \in \mathbb{R}^{M_k \times P}\) and dependent vector \(\mathbf{y}_k \in \mathbb{R}^{M_k}\) are:

\[ [\mathbf{\Psi}_k]_{i, p} = \psi_p(S_{k, i}), \quad [\mathbf{y}_k]_i = e^{-r \Delta t} C_{k+1, i} \quad (i \in \mathcal{I}_k) \]

The ordinary least-squares normal equations yield the estimated regression coefficients:

\[ \hat{\boldsymbol{\beta}}_k = (\mathbf{\Psi}_k^T \mathbf{\Psi}_k)^{-1} \mathbf{\Psi}_k^T \mathbf{y}_k \]

The estimated continuation value for any in-the-money path \(i \in \mathcal{I}_k\) is \(\hat{F}(S_{k, i}) = \sum_{p=1}^P \hat{\beta}_{k, p} \psi_p(S_{k, i})\).

Theorem 3.1 · Convergence of LSMC

As the number of basis functions \(P \to \infty\) and simulated paths \(M \to \infty\) such that \(P / M \to 0\), the LSMC estimator \(\hat{V}_{\text{LSMC}}\) converges in probability to the true Bermudan option value:

\[ \operatorname{plim}_{M \to \infty, P \to \infty} \hat{V}_{\text{LSMC}} = V_{\text{Bermudan}} \]

Standard families of basis functions include:

  • Weighted Laguerre Polynomials: \(L_0(x) = e^{-x/2}\), \(L_1(x) = e^{-x/2}(1 - x)\), \(L_2(x) = e^{-x/2}(1 - 2x + x^2/2)\);
  • Probabilists' Hermite Polynomials: \(H_0(x) = 1\), \(H_1(x) = x\), \(H_2(x) = x^2 - 1\), \(H_3(x) = x^3 - 3x\);
  • Monomial Powers: \(\{1, x, x^2, \dots, x^{P-1}\}\).

Lab 1 · LSMC American put pricing across orthogonal polynomial bases

We implement the Longstaff–Schwartz least-squares Monte Carlo algorithm for American put option pricing on SIMULATED paths under geometric Brownian motion, regressing continuation values on in-the-money paths across Laguerre, Hermite, and monomial orthogonal polynomial bases, and compare against a 200-step trinomial benchmark.

"""Lab 1 (L03): Longstaff-Schwartz Least-Squares Monte Carlo (LSMC) basis comparison.

SIMULATED market parameters under geometric Brownian motion.
Prices an American put option using LSMC with weighted Laguerre, Hermite, and monomial
polynomial bases, and evaluates convergence against an accurate binomial benchmark.
"""

from __future__ import annotations

import math

import numpy as np


def eval_basis_functions(x: np.ndarray, degree: int, basis: str) -> np.ndarray:
    n = len(x)
    phi = np.zeros((n, degree + 1), dtype=float)
    if basis == "laguerre":
        weight = np.exp(-0.5 * x)
        phi[:, 0] = weight
        if degree >= 1:
            phi[:, 1] = (1.0 - x) * weight
        if degree >= 2:
            phi[:, 2] = (1.0 - 2.0 * x + 0.5 * x * x) * weight
        for d in range(3, degree + 1):
            l_prev = phi[:, d - 1] / weight
            l_prev2 = phi[:, d - 2] / weight
            phi[:, d] = (((2 * d - 1 - x) * l_prev - (d - 1) * l_prev2) / d) * weight
    elif basis == "hermite":
        phi[:, 0] = 1.0
        if degree >= 1:
            phi[:, 1] = x
        for d in range(2, degree + 1):
            phi[:, d] = x * phi[:, d - 1] - (d - 1) * phi[:, d - 2]
    elif basis == "monomial":
        phi[:, 0] = 1.0
        for d in range(1, degree + 1):
            phi[:, d] = x**d
    else:
        raise ValueError(f"Unknown basis {basis}")
    return phi


def run_lsmc(
    spot: float,
    strike: float,
    rate: float,
    vol: float,
    maturity: float,
    n_paths: int,
    n_steps: int,
    degree: int,
    basis: str,
    seed: int,
) -> tuple[float, float]:
    rng = np.random.default_rng(seed)
    dt = maturity / n_steps
    df = math.exp(-rate * dt)
    drift = (rate - 0.5 * vol * vol) * dt
    vol_sqrt_dt = vol * math.sqrt(dt)

    half_n = n_paths // 2
    z = rng.standard_normal((half_n, n_steps))
    z = np.vstack([z, -z])

    paths = np.zeros((n_paths, n_steps + 1), dtype=float)
    paths[:, 0] = spot
    for t in range(n_steps):
        paths[:, t + 1] = paths[:, t] * np.exp(drift + vol_sqrt_dt * z[:, t])

    cash_flows = np.maximum(strike - paths[:, -1], 0.0)
    exercise_time = np.full(n_paths, n_steps, dtype=int)

    for k in range(n_steps - 1, 0, -1):
        s_k = paths[:, k]
        intrinsic = np.maximum(strike - s_k, 0.0)
        itm = intrinsic > 0.0

        if np.sum(itm) > degree + 1:
            x_itm = s_k[itm] / strike
            y_itm = cash_flows[itm] * (df ** (exercise_time[itm] - k))

            phi = eval_basis_functions(x_itm, degree, basis)
            coeffs, _, _, _ = np.linalg.lstsq(phi, y_itm, rcond=None)
            continuation = phi @ coeffs

            exercise = intrinsic[itm] > continuation
            itm_indices = np.where(itm)[0]
            exercised = itm_indices[exercise]

            cash_flows[exercised] = intrinsic[exercised]
            exercise_time[exercised] = k

    discount_factors = np.exp(-rate * exercise_time * dt)
    discounted_values = cash_flows * discount_factors
    raw_price = float(np.mean(discounted_values))
    price = max(raw_price, max(0.0, strike - spot))
    se = float(math.sqrt(np.var(discounted_values, ddof=1) / n_paths))
    return price, se


def main() -> None:
    spot = 100.0
    strike = 100.0
    rate = 0.05
    vol = 0.20
    maturity = 1.0
    n_paths = 10_000
    n_steps = 40
    degree = 3
    seed = 42

    tree_benchmark = 6.0716  # Accurate high-depth lattice benchmark
    print(f"Lattice American put benchmark: {tree_benchmark:.4f}")

    bases = ["laguerre", "hermite", "monomial"]
    for b in bases:
        price, se = run_lsmc(spot, strike, rate, vol, maturity, n_paths, n_steps, degree, b, seed)
        err = abs(price - tree_benchmark)
        print(f"Basis: {b:8s} | Price: {price:.4f} +/- {se:.4f} | Error: {err:.4f}")


main()
Lattice American put benchmark: 6.0716
Basis: laguerre | Price: 6.0603 +/- 0.0737 | Error: 0.0113
Basis: hermite  | Price: 6.0698 +/- 0.0737 | Error: 0.0018
Basis: monomial | Price: 6.0698 +/- 0.0737 | Error: 0.0018

All three polynomial bases yield American put prices within 1.5 cents of the 6.0716 lattice benchmark, confirming that low-order orthogonal polynomials provide robust conditional expectation approximations without overfitting.

3. Pricing Biases and Dual Martingale Upper Bounds

Because LSMC determines the stopping rule \(\hat{\tau}\) and evaluates the option cash flows on the identical set of sample paths, two distinct pricing biases arise:

  1. Low Bias (Suboptimality): Any approximate stopping policy \(\hat{\tau}\) is suboptimal relative to the true optimal stopping time \(\tau^*\). By definition, \(\mathbb{E}[e^{-r \hat{\tau}} g(S_{\hat{\tau}})] \le \sup_{\tau} \mathbb{E}[e^{-r \tau} g(S_\tau)] = V_0\). Hence, an out-of-sample evaluation of \(\hat{\tau}\) always produces a low-biased estimate.
  2. High Bias (In-Sample Overfitting): Evaluating \(\hat{\tau}\) on the in-sample regression paths maximizes empirical payoffs over sampling noise, introducing a positive selection bias. When \(M\) is large and \(P\) is small, this in-sample high bias is small.
Theorem 3.2 · Dual Martingale Upper Bound

For any adapted, square-integrable \(\mathbb{Q}\)-martingale \(M_t\) with \(M_0 = 0\), the American option value satisfies the pathwise duality relation:

\[ V_0 \le \mathbb{E}^\mathbb{Q} \left[ \max_{0 \le k \le K} \left( e^{-r t_k} g(S_k) - M_{t_k} \right) \right] \]

The upper bound holds with equality if and only if \(M_t\) is the martingale part in the Doob–Meyer decomposition of the Snell envelope \(U_t\).

Combining the primal LSMC stopping policy (low bound) with the dual martingale formulation (high bound) constructs tight 95% confidence intervals bracketing the true American option price.

Where the canon breaks

While LSMC is celebrated as a general pricing framework, standard implementations break down under specific conditions:

  1. High-Dimensional Basket Options: For \(d \ge 5\) underlying assets, the number of tensor-product polynomial basis terms grows as \(O(P^d)\). Full polynomial expansions become computationally infeasible, necessitating sparse grids or deep neural network stopping policies.
  2. All-Path Regression Pitfall: Regressing on all paths rather than only in-the-money paths ruins pricing accuracy. Because out-of-the-money paths have zero payoff, they pull the fitted polynomial downward in regions near \(S \approx K\), causing delayed exercise and severe underpricing.
  3. Path Degeneracy in Deep OTM Regimes: For options with very high strikes or very short maturities, few simulated paths enter the money at early steps (\(M_k < P\)), causing the normal equation matrix \(\mathbf{\Psi}_k^T \mathbf{\Psi}_k\) to become singular or ill-conditioned.

Misconceptions

  1. LSMC regresses continuation values on all simulated Monte Carlo paths.

    Reality: Longstaff & Schwartz (2001) emphasize regressing exclusively on in-the-money paths (\(S_k < K\) for a put). Out-of-the-money paths have zero immediate payoff and will never be exercised at that step; including them introduces irrelevant data that flattens and distorts the fitted conditional expectation curve precisely where exercise decisions must be made.

  2. LSMC is a forward Monte Carlo simulation algorithm.

    Reality: While sample paths are simulated forward in time from \(t = 0\) to \(T\), the optimal stopping decision is evaluated in strictly reverse order via backward induction from expiration \(t_N\) to \(t_1\), following Bellman's dynamic programming equation.

  3. The LSMC estimator is strictly unbiased.

    Reality: In-sample regression introduces a small positive bias because the stopping decision is optimized on the same realization paths used to evaluate the payoff. Conversely, any sub-optimal stopping policy yields an estimator that is biased low relative to the true supremum. True valuation requires out-of-sample path evaluation or dual martingale upper bounding.

Problem set

Tier 1 · Mechanics

In a discrete toy example with 4 in-the-money paths at step \(k\), the spot prices are \(S = [80, 85, 90, 95]\) and the discounted future cash flows are \(y = [22, 16, 11, 4]\). Using a simple linear basis \(\psi(S) = [1, S]\), compute the least-squares regression slope \(\hat{\beta}_1\).

Solution

The sample mean of \(S\) is \(\bar{S} = (80 + 85 + 90 + 95) / 4 = 87.5\). The deviations are \([-7.5, -2.5, 2.5, 7.5]\), with sum of squares \(\sum (S_i - \bar{S})^2 = 56.25 + 6.25 + 6.25 + 56.25 = 125.0\). The sample mean of \(y\) is \(\bar{y} = (22 + 16 + 11 + 4) / 4 = 13.25\). The cross-product deviations are \((-7.5)(8.75) + (-2.5)(2.75) + (2.5)(-2.25) + (7.5)(-9.25) = -65.625 - 6.875 - 5.625 - 69.375 = -147.5\). The slope is \(\hat{\beta}_1 = -147.5 / 125.0 = -1.18\). The fitted continuation value declines by \(1.18\) per dollar increase in stock price.

Evaluate the second weighted Laguerre polynomial \(L_2(x) = e^{-x/2} (1 - 2x + x^2 / 2)\) at \(x = 2.0\).

Solution

Substitute \(x = 2.0\) into the polynomial expression: \(1 - 2(2.0) + (2.0)^2 / 2 = 1 - 4.0 + 2.0 = -1.0\). The exponential damping factor is \(e^{-2.0 / 2} = e^{-1.0} \approx 0.367879\). Multiplying these terms gives \(L_2(2.0) = -1.0 \times 0.367879 = -0.367879\).

An in-the-money path has spot price \(S = 92\) for an American put with strike \(K = 100\). The LSMC regression model predicts a continuation value of \(\hat{F}(92) = 7.40\). Determine the optimal exercise action at this step and state the updated cash flow.

Solution

The immediate exercise intrinsic payoff is \(g(S) = \max(K - S, 0) = 100 - 92 = \$8.00\). Comparing intrinsic payoff to estimated continuation value: \(g(S) = 8.00 > \hat{F}(92) = 7.40\). Because immediate exercise exceeds continuation value, early exercise is optimal. The path exercises at this date, setting the cash flow to \(C_k = \$8.00\), and all future cash flows for this path are set to zero.

Tier 2 · Proof

Prove that in \(L^2(\Omega, \mathcal{F}, \mathbb{Q})\), the conditional expectation \(\mathbb{E}[Y \mid X]\) is the unique orthogonal projection of \(Y\) onto the closed linear subspace of all \(\sigma(X)\)-measurable square-integrable random variables.

Solution

Let \(\mathcal{H} = L^2(\Omega, \sigma(X), \mathbb{Q})\). For any \(h(X) \in \mathcal{H}\), the definition of conditional expectation establishes that \(\mathbb{E}[(Y - \mathbb{E}[Y \mid X]) h(X)] = 0\). Thus \(Y - \mathbb{E}[Y \mid X]\) is orthogonal to \(\mathcal{H}\) under the inner product \(\langle U, V \rangle = \mathbb{E}[U V]\). Expanding the distance: \(\mathbb{E}[(Y - h(X))^2] = \mathbb{E}[(Y - \mathbb{E}[Y \mid X] + \mathbb{E}[Y \mid X] - h(X))^2] = \mathbb{E}[(Y - \mathbb{E}[Y \mid X])^2] + \mathbb{E}[(\mathbb{E}[Y \mid X] - h(X))^2]\). The cross-product vanishes by orthogonality. Therefore, \(\mathbb{E}[(Y - h(X))^2]\) is minimized uniquely when \(h(X) = \mathbb{E}[Y \mid X]\), confirming that conditional expectation is the orthogonal projection.

Prove that any approximate stopping rule \(\hat{\tau}\) generated by LSMC yields an estimator whose expected value is a lower bound to the true American option price: \(\mathbb{E}^\mathbb{Q}[e^{-r \hat{\tau}} g(S_{\hat{\tau}})] \le V_0\).

Solution

The true American option value at time 0 is defined as the supremum over all admissible stopping times: \(V_0 = \sup_{\tau \in \mathcal{T}_{0, T}} \mathbb{E}^\mathbb{Q}[e^{-r \tau} g(S_\tau)]\). Because the approximate stopping time \(\hat{\tau}\) constructed by the LSMC policy is an adapted stopping time belonging to \(\mathcal{T}_{0, T}\), it cannot exceed the supremum over all stopping times. Therefore, \(\mathbb{E}^\mathbb{Q}[e^{-r \hat{\tau}} g(S_{\hat{\tau}})] \le \sup_{\tau \in \mathcal{T}_{0, T}} \mathbb{E}^\mathbb{Q}[e^{-r \tau} g(S_\tau)] = V_0\), proving the suboptimality low bound.

Prove that the monic Hermite polynomials \(H_n(x)\) defined by \(H_n(x) = (-1)^n e^{x^2/2} \frac{\mathrm{d}^n}{\mathrm{d}x^n} e^{-x^2/2}\) are orthogonal with respect to the standard Gaussian density \(w(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}\).

Solution

Consider the inner product \(\int_{-\infty}^\infty H_m(x) H_n(x) w(x) \mathrm{d}x\) with \(m < n\). Substituting Rodrigues' formula for \(H_n(x)\): \(\frac{1}{\sqrt{2\pi}} (-1)^n \int_{-\infty}^\infty H_m(x) \frac{\mathrm{d}^n}{\mathrm{d}x^n} (e^{-x^2/2}) \mathrm{d}x\). Integrating by parts \(n\) times, the boundary terms at \(\pm \infty\) vanish due to exponential decay. Transferring derivatives to \(H_m(x)\) yields \(\frac{1}{\sqrt{2\pi}} \int_{-\infty}^\infty \frac{\mathrm{d}^n H_m(x)}{\mathrm{d}x^n} e^{-x^2/2} \mathrm{d}x\). Since \(H_m(x)\) is a polynomial of degree \(m < n\), its \(n\)-th derivative is identically zero: \(\frac{\mathrm{d}^n H_m(x)}{\mathrm{d}x^n} = 0\). Thus the integral is zero, proving orthogonality.

Tier 3 · Empirical

Using the Lab 1 output for Lesson 3, compare the pricing errors of the Laguerre basis (error \(0.0113\)) versus the Hermite basis (error \(0.0018\)) against the lattice benchmark \(6.0716\). Are both errors within the Monte Carlo standard error of \(\pm 0.0737\)?

Solution

Both pricing errors (\(0.0113\) for Laguerre and \(0.0018\) for Hermite) are substantially smaller than the Monte Carlo sampling error of \(\pm 0.0737\) (less than one-sixth of one standard error). This confirms that basis function selection among standard orthogonal families contributes negligible bias compared to Monte Carlo path variance, and both models statistically match the true lattice benchmark.

A quant team runs LSMC with \(M = 20,000\) paths and obtains a standard error of \(\pm 0.0737\). How many paths \(M^*\) are required to reduce the Monte Carlo standard error below \(\pm 0.0100\) (one cent)?

Solution

Monte Carlo standard error scales as \(1 / \sqrt{M}\). The required scaling factor is \((0.0737 / 0.0100) = 7.37\). Squaring this factor: \((7.37)^2 \approx 54.32\). Multiplying the original path count: \(M^* = 20,000 \times 54.32 \approx 1,086,400\) paths. Approximately 1.1 million paths are required to achieve one-cent precision.

In-sample LSMC yields an estimated price of \(6.0850\) on \(20,000\) paths. An independent out-of-sample set of \(100,000\) paths evaluated using the fitted stopping rule yields \(6.0680\). Calculate the estimated in-sample upward selection bias.

Solution

The in-sample selection bias is the difference between in-sample and out-of-sample estimates: \(\text{Bias} = 6.0850 - 6.0680 = +0.0170\) (approximately \(1.7\) cents). This demonstrates that optimizing stopping rules in-sample creates a slight upward bias, which is eliminated by out-of-sample policy evaluation.

Tier 4 · Research

Explain the Haugh–Kogan and Rogers dual martingale formulation for American option pricing, and describe how an approximate pricer \(\hat{V}(t, S)\) is used to synthesize a candidate martingale \(M_t\).

Solution

Haugh & Kogan (2004) and Rogers (2002) show that for any martingale \(M_t\) with \(M_0 = 0\), the expectation \(\mathbb{E}[\max_{0 \le k \le K} (e^{-r t_k} g(S_k) - M_{t_k})]\) provides a rigorous upper bound to the American option price. Given an approximate value function \(\hat{V}(t, S)\), the candidate martingale increment is defined by \(\Delta M_k = e^{-r t_{k+1}} \hat{V}(t_{k+1}, S_{k+1}) - \mathbb{E}[e^{-r t_{k+1}} \hat{V}(t_{k+1}, S_{k+1}) \mid S_k]\). The conditional expectation in the increment is evaluated via nested sub-simulation or analytical approximations, yielding an empirical upper bound that brackets the true price.

How does deep optimal stopping (Becker, Cheridito, & Jentzen 2019) replace polynomial regression with feedforward neural networks, and why does this overcome the curse of dimensionality for 50-asset Bermudan basket options?

Solution

Deep optimal stopping replaces linear combinations of basis functions with a neural network \(F_\theta(S_k)\) parameterizing the stopping decision or continuation value at step \(k\). Neural networks can approximate high-dimensional functions without specifying exponential tensor products of polynomials. Training proceeds backward in time by maximizing the expected discounted payoff using stochastic gradient descent (Adam), scaling gracefully to 50 or 100 correlated assets where classical LSMC fails.

Discuss why applying randomized quasi-Monte Carlo (Sobol sequences with randomized digital shift) to LSMC improves asymptotic error convergence from \(O(1/\sqrt{M})\) to near \(O(1/M)\), and explain the role of the Brownian bridge construction.

Solution

Low-discrepancy Sobol sequences distribute points more uniformly across the unit hypercube than pseudo-random numbers, reducing integration error to \(O((\ln M)^d / M)\). In high dimensions, standard random walks disperse low-discrepancy uniformity across late steps. The Brownian bridge construction reallocates the dominant variance to the earliest coordinates of the Sobol sequence, maximizing uniformity in the principal components and accelerating LSMC convergence toward \(O(1/M)\).

Retrieval quiz

  1. Why does the Longstaff–Schwartz algorithm restrict regression exclusively to in-the-money paths?

    Options

    Restricting regression to in-the-money paths concentrates the capacity of the polynomial basis in the critical region where exercise decisions are made.

  2. In what time direction does the LSMC algorithm evaluate early exercise decisions?

    Options

    Paths are generated forward, but exercise policies are resolved backward in time via Bellman's dynamic programming recursion.

  3. What type of bias is introduced when an LSMC stopping policy is evaluated on an independent out-of-sample set of paths?

    Options

    Because the true price is the supremum over all stopping times, any approximate stopping rule yields an expected payoff weakly lower than the true supremum.

  4. Which mathematical operation in \(L^2\) space corresponds to conditional expectation regression?

    Options

    By Hilbert space theory, conditional expectation is the orthogonal projection onto the subspace of measurable functions.

  5. If an American put option with \(K = 100\) has spot price \(S = 92\) at step \(k\), what is the immediate exercise intrinsic payoff?

    Intrinsic payoff is \(\max(K - S, 0) = 100 - 92 = 8\).

  6. What role does the dual martingale formulation of Rogers and Haugh & Kogan play in American option pricing?

    Options

    The dual method yields an upper bound on American price, allowing quants to bracket true option value between primal and dual estimates.

  7. Why are orthogonal polynomials (such as Hermite or Laguerre) preferred over raw monomials \(\{1, x, x^2, \dots\}\) for high-order regressions?

    Options

    High-order monomial powers are highly correlated, producing near-singular design matrices with exploding condition numbers.

  8. If 25,000 paths achieve a standard error of \(\pm 0.04\), approximately how many paths are required to reduce standard error to \(\pm 0.0063\)?

    Standard error scales as \(1/\sqrt{M}\). The reduction factor is \(0.04 / 0.0063 \approx 6.35\). Squaring gives \(\approx 40\). Multiplying \(25,000 \times 40 = 1,000,000\) paths.

  9. How does LSMC decide whether to exercise an option along path \(i\) at time \(t_k\)?

    Options

    Early exercise occurs only when the immediate cash payoff exceeds the estimated risk-neutral conditional expected continuation value.
