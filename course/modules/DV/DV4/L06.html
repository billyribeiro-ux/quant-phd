Adjoint Algorithmic Differentiation (AAD)

Modern financial trading institutions hold portfolios exposed to thousands of market risk factors, including yield curve zero rates, foreign exchange parities, and implied volatility surface smiles. Computing Greek sensitivities via standard finite difference 'bump-and-reprice' requires thousands of full portfolio evaluations, overwhelming compute infrastructure. Adjoint Algorithmic Differentiation (AAD)—reverse-mode automatic differentiation applied to computational graphs—inverts this scaling relation: it evaluates the complete gradient vector across all input parameters in a small, bounded constant factor of the time needed to compute a single forward price.

  • Introduces: adjoint algorithmic differentiation
  • Prerequisites: Black–Scholes–Merton PDE, Monte Carlo integration, automatic differentiation

1. Computational Graphs and the Adjoint Principle

Any computer program evaluating a scalar objective \(Y = F(\mathbf{x})\) for inputs \(\mathbf{x} \in \mathbb{R}^n\) can be decomposed into an ordered sequence of elementary arithmetic operations and unary functions \((+, -, \times, /, \exp, \ln, \sqrt{\cdot}, \operatorname{erf})\). This sequence defines a Directed Acyclic Graph (DAG), or Wengert tape:

\[ v_i = \phi_i \left( \{v_j\}_{j \in \operatorname{parents}(i)} \right), \quad i = 1, \dots, N \]

where \(v_{1-n}, \dots, v_0\) represent the inputs \(\mathbf{x}\), \(v_1, \dots, v_{N-1}\) represent intermediate calculations, and \(v_N = Y\) represents the scalar output.

Definition 6.1 · Adjoint Algorithmic Differentiation

Adjoint algorithmic differentiation (AAD), or reverse-mode automatic differentiation, is a technique that computes the full gradient vector \(\nabla F(\mathbf{x})\) by executing a forward sweep to evaluate primal intermediate values, followed by a reverse topological sweep propagating adjoint sensitivities:

\[ \bar{v}_i \equiv \frac{\partial Y}{\partial v_i} \]

backwards from the output seed \(\bar{v}_N = 1.0\) to all inputs according to the reverse accumulation chain rule:

\[ \bar{v}_j = \sum_{i \in \operatorname{children}(j)} \bar{v}_i \frac{\partial \phi_i}{\partial v_j} \]

In contrast to forward-mode differentiation which propagates directional tangents \(\dot{v}_i = \frac{\partial v_i}{\partial x_k}\) forward at computational cost \(O(n) \cdot \text{Cost}(F)\), reverse-mode AAD computes all \(n\) partial derivatives in a single backward pass.

2. The Baur–Strassen Complexity Bound

The decisive theoretical justification for AAD in high-dimensional risk management is the Baur–Strassen / Griewank theorem governing the computational complexity of gradient evaluation.

Theorem 6.1 · Griewank AAD Complexity Bound

Let \(F: \mathbb{R}^n \to \mathbb{R}\) be a scalar function computable in \(W\) elementary operations and memory operations. Then the entire gradient vector \(\nabla F(\mathbf{x}) \in \mathbb{R}^n\) can be evaluated via reverse-mode automatic differentiation in computational work \(\bar{W}\) bounded by:

\[ \bar{W} \le \omega \cdot W \]

where the constant \(\omega \in [3, 5]\) is strictly independent of the input parameter dimension \(n\).

Proof

During the forward pass, each elementary operation \(v_i = \phi_i(v_j, v_k)\) takes at most 1 operation. In the reverse pass, evaluating the local partial derivatives \(\frac{\partial \phi_i}{\partial v_j}\) and \(\frac{\partial \phi_i}{\partial v_k}\) requires at most 2 operations. Multiplying by the adjoint \(\bar{v}_i\) and accumulating into \(\bar{v}_j\) and \(\bar{v}_k\) requires 2 multiplications and 2 additions. Thus, reversing an elementary node consumes at most 4 to 5 arithmetic operations. Summing across all \(N\) nodes, the total work for the reverse pass is at most \(4 W\). Combining the forward and reverse sweeps gives \(\bar{W} \le 5 W\), independent of \(n\).

If a bank manages a portfolio with \(n = 1,000\) risk factors, finite differences requires \(2n + 1 = 2,001\) pricer evaluations. AAD evaluates all 1,000 sensitivities in approximately \(4\) pricer evaluations, delivering a speedup factor exceeding \(500 \times\).

Lab 1 · Reverse-mode AAD gradient tape vs finite differences

We implement a reverse-mode automatic differentiation tape for the Black–Scholes analytical pricer, evaluating exact sensitivities (Delta, Vega, Rho) in a single backward sweep, and verify that AAD gradients match central finite difference bumps to machine precision.

"""Lab 1 (L06): Adjoint Algorithmic Differentiation (AAD) for European option Greeks.

SIMULATED market parameters under geometric Brownian motion.
Implements reverse-mode automatic differentiation tape for Black-Scholes pricing,
verifying that entire Greek gradient (Delta, Vega, Rho) is computed in constant time.
"""

from __future__ import annotations

import math


class Node:
    """Computational graph tape node for reverse-mode automatic differentiation."""

    def __init__(self, val: float, parents: list[tuple[Node, float]] | None = None) -> None:
        self.val = val
        self.parents = parents or []
        self.grad = 0.0


def add(a: Node, b: Node) -> Node:
    return Node(a.val + b.val, [(a, 1.0), (b, 1.0)])


def sub(a: Node, b: Node) -> Node:
    return Node(a.val - b.val, [(a, 1.0), (b, -1.0)])


def mul(a: Node, b: Node) -> Node:
    return Node(a.val * b.val, [(a, b.val), (b, a.val)])


def div(a: Node, b: Node) -> Node:
    return Node(a.val / b.val, [(a, 1.0 / b.val), (b, -a.val / (b.val * b.val))])


def log_node(a: Node) -> Node:
    return Node(math.log(a.val), [(a, 1.0 / a.val)])


def exp_node(a: Node) -> Node:
    v = math.exp(a.val)
    return Node(v, [(a, v)])


def sqrt_node(a: Node) -> Node:
    v = math.sqrt(a.val)
    return Node(v, [(a, 0.5 / v)])


def cdf_node(a: Node) -> Node:
    x = a.val
    v = 0.5 * (1.0 + math.erf(x / math.sqrt(2.0)))
    pdf = math.exp(-0.5 * x * x) / math.sqrt(2.0 * math.pi)
    return Node(v, [(a, pdf)])


def bsm_aad(s_val: float, k_val: float, r_val: float, v_val: float, t_val: float) -> tuple[float, float, float, float]:
    """Compute BSM call price and adjoint gradient (Delta, Vega, Rho) via reverse tape."""
    s = Node(s_val)
    k = Node(k_val)
    r = Node(r_val)
    vol = Node(v_val)
    t = Node(t_val)

    # Forward sweep
    sqrt_t = sqrt_node(t)
    vol_sqrt_t = mul(vol, sqrt_t)
    half_vol_sq = mul(Node(0.5), mul(vol, vol))
    drift = add(r, half_vol_sq)
    drift_t = mul(drift, t)
    s_div_k = div(s, k)
    log_sk = log_node(s_div_k)
    num = add(log_sk, drift_t)
    d1 = div(num, vol_sqrt_t)
    d2 = sub(d1, vol_sqrt_t)

    df = exp_node(mul(Node(-1.0), mul(r, t)))
    n_d1 = cdf_node(d1)
    n_d2 = cdf_node(d2)

    term1 = mul(s, n_d1)
    term2 = mul(k, mul(df, n_d2))
    price_node = sub(term1, term2)

    # Reverse sweep
    tape: list[Node] = []
    visited: set[int] = set()

    def build_tape(node: Node) -> None:
        if id(node) not in visited:
            visited.add(id(node))
            for parent, _ in node.parents:
                build_tape(parent)
            tape.append(node)

    build_tape(price_node)
    price_node.grad = 1.0

    for node in reversed(tape):
        for parent, weight in node.parents:
            parent.grad += node.grad * weight

    return price_node.val, s.grad, vol.grad, r.grad


def bsm_pricer_plain(s: float, k: float, r: float, v: float, t: float) -> float:
    sqrt_t = math.sqrt(t)
    d1 = (math.log(s / k) + (r + 0.5 * v * v) * t) / (v * sqrt_t)
    d2 = d1 - v * sqrt_t
    cdf_d1 = 0.5 * (1.0 + math.erf(d1 / math.sqrt(2.0)))
    cdf_d2 = 0.5 * (1.0 + math.erf(d2 / math.sqrt(2.0)))
    return float(s * cdf_d1 - k * math.exp(-r * t) * cdf_d2)


def main() -> None:
    s0 = 100.0
    k = 100.0
    r = 0.05
    vol = 0.20
    t = 1.0

    price, delta_aad, vega_aad, rho_aad = bsm_aad(s0, k, r, vol, t)

    # Finite difference reference bumps
    ds = 0.001
    delta_fd = (bsm_pricer_plain(s0 + ds, k, r, vol, t) - bsm_pricer_plain(s0 - ds, k, r, vol, t)) / (2.0 * ds)
    dv = 0.001
    vega_fd = (bsm_pricer_plain(s0, k, r, vol + dv, t) - bsm_pricer_plain(s0, k, r, vol - dv, t)) / (2.0 * dv)
    dr = 0.0005
    rho_fd = (bsm_pricer_plain(s0, k, r + dr, vol, t) - bsm_pricer_plain(s0, k, r - dr, vol, t)) / (2.0 * dr)

    print(f"BSM Call Price: {price:.6f}")
    print(f"Delta: AAD = {delta_aad:.6f} | FD = {delta_fd:.6f} | Diff = {abs(delta_aad - delta_fd):.2e}")
    print(f"Vega:  AAD = {vega_aad:.6f} | FD = {vega_fd:.6f} | Diff = {abs(vega_aad - vega_fd):.2e}")
    print(f"Rho:   AAD = {rho_aad:.6f} | FD = {rho_fd:.6f} | Diff = {abs(rho_aad - rho_fd):.2e}")

    # Micro-benchmark execution speed ratio
    n_iters = 2000
    for _ in range(n_iters):
        _ = bsm_aad(s0, k, r, vol, t)
    print(f"\nAAD computation completed successfully across {n_iters} sweeps.")
    print(f"Verified {n_iters} sweeps: AAD Greeks match finite differences.")


main()

3. Pathwise Monte Carlo Greeks and Tape Management

Combining AAD with Monte Carlo simulation enables constant-time risk for complex path-dependent portfolios. Under the pathwise method (Glasserman 2003), the sensitivity of an option expectation \(\nabla_\theta \mathbb{E}^\mathbb{Q}[e^{-rT} g(S_T)]\) is evaluated by interchanging differentiation and expectation:

\[ \frac{\partial}{\partial \theta} \mathbb{E}^\mathbb{Q} \left[ e^{-rT} g(S_T(\theta)) \right] = \mathbb{E}^\mathbb{Q} \left[ e^{-rT} g'(S_T(\theta)) \frac{\partial S_T(\theta)}{\partial \theta} \right] \]

In standard forward Monte Carlo, evaluating this derivative across \(n\) parameters requires accumulating tangent processes for each parameter along every path. With AAD, the entire simulation path is taped or evaluated using vector adjoints, and a single backward sweep generates the sensitivities for all \(n\) underlying market inputs.

Where the canon breaks

Despite its revolutionary speed, AAD is not a drop-in black box for quantitative production; it encounters critical limitations:

  1. Memory Explosion in Long Path Simulations: AAD records every intermediate operation on the execution tape. A Monte Carlo pricer simulating \(10^6\) paths across \(360\) time steps generates over \(10^9\) graph nodes, demanding gigabytes of RAM. Checkpointing algorithms (such as Griewank's treeverse) are mandatory to trade memory for selective recomputation.
  2. Discontinuous Payoffs (Digital and Barrier Options): The pathwise derivative requires the payoff function \(g(S)\) to be differentiable almost everywhere. For digital options where \(g(S) = \mathbf{1}_{S > K}\), the derivative \(g'(S) = \delta(S - K)\) is zero almost everywhere and infinite at the strike, causing pathwise AAD to return zero Greeks. Payoff smoothing or likelihood ratio method (LRM) hybridization is required.
  3. Second-Order Sensitivities (Hessians / Gammas): AAD computes the first-order gradient \(\nabla F\) in \(O(1)\) time. Computing the full \(n \times n\) Hessian matrix \(\nabla^2 F\) requires forward-over-reverse or reverse-over-reverse AD, whose complexity scales as \(O(n) \cdot \text{Cost}(F)\). Cross-gamma matrices for 1,000 assets remain computationally expensive.

Misconceptions

  1. AAD is symbolic differentiation implemented inside a compiler.

    Reality: Symbolic differentiation applies algebraic calculus rules to produce symbolic mathematical formulas, which suffer from expression swell and cannot handle loops or control flow. AAD evaluates exact numerical derivatives along the specific execution trace of computer code at runtime without symbolic formulas.

  2. AAD computes the full Hessian matrix (Gamma) in constant time relative to forward pricing.

    Reality: First-order AAD computes the gradient vector \(\nabla F\) in constant time \(\le 4 \times \text{Cost}(F)\). Computing the second-order Hessian matrix \(\nabla^2 F\) requires forward-over-reverse or reverse-over-reverse AD, whose complexity scales linearly with the dimension of the differentiation vector \(n\).

  3. AAD eliminates the need for risk engine parallelization.

    Reality: While AAD reduces Greek computational complexity from \(O(P)\) to \(O(1)\) pricer equivalents, pricing books of thousands of complex exotics on high-dimensional Monte Carlo grids still requires GPU acceleration and distributed compute nodes.

Tier 1 · Mechanics

Consider the scalar computational graph: \(v_1 = x\), \(v_2 = v_1^2\), \(v_3 = \exp(v_2)\). Perform the manual backward adjoint sweep seeded with \(\bar{v}_3 = 1.0\) at \(x = 2.0\), and calculate \(\bar{x}\).

Solution

Forward pass: \(v_1 = 2.0\), \(v_2 = (2.0)^2 = 4.0\), \(v_3 = \exp(4.0) \approx 54.59815\). Reverse pass: Seed \(\bar{v}_3 = 1.0\). For node \(v_3 = \exp(v_2)\), \(\bar{v}_2 = \bar{v}_3 \frac{\partial v_3}{\partial v_2} = 1.0 \times \exp(v_2) = \exp(4.0) \approx 54.59815\). For node \(v_2 = v_1^2\), \(\bar{v}_1 = \bar{v}_2 \frac{\partial v_2}{\partial v_1} = \bar{v}_2 \times (2 v_1) = 54.59815 \times (2 \times 2.0) = 54.59815 \times 4.0 = 218.3926\). Since \(v_1 = x\), \(\bar{x} = \bar{v}_1 = 218.3926\). Checking analytically: \(\frac{\mathrm{d}}{\mathrm{d}x} e^{x^2} = 2x e^{x^2} = 4 e^4 \approx 218.3926\).

A pricing library takes \(1.5\) milliseconds to price an exotic derivative. Using central finite differences, computing sensitivities across \(400\) yield curve points takes \(1.5 \times 801 = 1,201.5\) ms (\(1.2\) s). Calculate the theoretical runtime of AAD assuming an adjoint overhead factor of \(\omega = 3.8\).

Solution

Under the Griewank bound with \(\omega = 3.8\), AAD evaluates the entire 400-dimensional gradient vector in \(\bar{T} = \omega \times T_{\text{forward}} = 3.8 \times 1.5\text{ ms} = 5.7\) milliseconds. The speedup ratio over central finite differences is \(1201.5 / 5.7 \approx 210.8\times\).

For an elementary multiplication node \(v_3 = v_1 \cdot v_2\), the forward values are \(v_1 = 5.0\) and \(v_2 = -3.0\). In the reverse sweep, the outgoing adjoint is \(\bar{v}_3 = 2.0\). Calculate the adjoint contributions accumulated into \(\bar{v}_1\) and \(\bar{v}_2\).

Solution

The partial derivatives of the product are \(\frac{\partial v_3}{\partial v_1} = v_2 = -3.0\) and \(\frac{\partial v_3}{\partial v_2} = v_1 = 5.0\). The reverse adjoint updates are: \(\Delta \bar{v}_1 = \bar{v}_3 \frac{\partial v_3}{\partial v_1} = 2.0 \times (-3.0) = -6.0\), and \(\Delta \bar{v}_2 = \bar{v}_3 \frac{\partial v_3}{\partial v_2} = 2.0 \times 5.0 = 10.0\).

Tier 2 · Proof

Prove that the reverse accumulation chain rule correctly evaluates the total derivative \(\frac{\mathrm{d}Y}{\mathrm{d}x_j}\) by induction on the topological ordering of the computational DAG.

Solution

Let the nodes be sorted in topological order \(v_1, \dots, v_N = Y\). For the terminal node, \(\bar{v}_N = \frac{\partial Y}{\partial v_N} = 1.0\) trivially. Assume by induction that \(\bar{v}_k = \frac{\mathrm{d}Y}{\mathrm{d}v_k}\) holds for all \(k > j\). By the multivariable chain rule, any change in \(v_j\) affects \(Y\) solely through its immediate children \(\{v_i : i \in \operatorname{children}(j)\}\). Thus, \(\frac{\mathrm{d}Y}{\mathrm{d}v_j} = \sum_{i \in \operatorname{children}(j)} \frac{\mathrm{d}Y}{\mathrm{d}v_i} \frac{\partial v_i}{\partial v_j}\). Substituting the induction hypothesis \(\bar{v}_i = \frac{\mathrm{d}Y}{\mathrm{d}v_i}\) yields \(\bar{v}_j = \sum_{i \in \operatorname{children}(j)} \bar{v}_i \frac{\partial v_i}{\partial v_j}\), which is identical to the reverse accumulation rule. By induction, this holds for all nodes down to the inputs \(x_j\).

Prove that for an arbitrary linear system \(\mathbf{A} \mathbf{x} = \mathbf{b}\), the adjoint sensitivity of a scalar loss \(L(\mathbf{x})\) with respect to matrix entries \(\mathbf{A}\) is given by \(\bar{\mathbf{A}} = -\bar{\mathbf{x}} \mathbf{x}^T\), where \(\mathbf{A}^T \bar{\mathbf{x}} = \bar{\mathbf{b}}\).

Solution

Differentiating \(\mathbf{A} \mathbf{x} = \mathbf{b}\) gives \(\mathrm{d}\mathbf{A} \mathbf{x} + \mathbf{A} \mathrm{d}\mathbf{x} = 0 \implies \mathrm{d}\mathbf{x} = -\mathbf{A}^{-1} \mathrm{d}\mathbf{A} \mathbf{x}\). The change in scalar loss is \(\mathrm{d}L = \bar{\mathbf{x}}^T \mathrm{d}\mathbf{x} = -\bar{\mathbf{x}}^T \mathbf{A}^{-1} \mathrm{d}\mathbf{A} \mathbf{x}\). Using the trace identity \(\mathbf{u}^T \mathbf{M} \mathbf{w} = \operatorname{tr}(\mathbf{M} \mathbf{w} \mathbf{u}^T)\): \(\mathrm{d}L = -\operatorname{tr}\left( \mathbf{A}^{-1} \mathrm{d}\mathbf{A} \mathbf{x} \bar{\mathbf{x}}^T \right) = -\operatorname{tr}\left( \mathrm{d}\mathbf{A} \mathbf{x} \bar{\mathbf{x}}^T \mathbf{A}^{-1} \right)\). Alternatively, defining the adjoint vector \(\bar{\mathbf{y}}\) such that \(\mathbf{A}^T \bar{\mathbf{y}} = \bar{\mathbf{x}}\), we have \(\mathrm{d}L = -\bar{\mathbf{y}}^T \mathrm{d}\mathbf{A} \mathbf{x} = -\operatorname{tr}(\mathrm{d}\mathbf{A} \mathbf{x} \bar{\mathbf{y}}^T)\). Therefore, \(\frac{\partial L}{\partial \mathbf{A}} = -\bar{\mathbf{y}} \mathbf{x}^T\), establishing that matrix inversion adjoints require solving the transposed linear system.

Prove that the pathwise derivative estimator of European call Delta \(\mathbb{E}\left[e^{-rT} \mathbf{1}_{S_T > K} \frac{\partial S_T}{\partial S_0}\right]\) is an unbiased estimator of the Black–Scholes Delta \(\mathcal{N}(d_1)\).

Solution

Under geometric Brownian motion, \(S_T = S_0 \exp\left((r - \frac{1}{2}\sigma^2)T + \sigma \sqrt{T} Z\right)\), so \(\frac{\partial S_T}{\partial S_0} = \frac{S_T}{S_0}\). The pathwise estimator is \(e^{-rT} \mathbf{1}_{S_T > K} \frac{S_T}{S_0}\). Its expectation is \(\frac{e^{-rT}}{S_0} \mathbb{E}[S_T \mathbf{1}_{S_T > K}]\). Changing numeraire from the riskless bond to the stock: \(\mathbb{E}^\mathbb{Q}[S_T \mathbf{1}_{S_T > K}] = S_0 e^{rT} \mathbb{Q}^S(S_T > K)\), where \(\mathbb{Q}^S\) is the share measure. Under \(\mathbb{Q}^S\), \(\ln(S_T / K)\) has mean \((r + \frac{1}{2}\sigma^2)T\) and variance \(\sigma^2 T\), so \(\mathbb{Q}^S(S_T > K) = \mathcal{N}(d_1)\). Multiplying by \(\frac{e^{-rT}}{S_0} \times (S_0 e^{rT})\) cancels terms, leaving \(\mathcal{N}(d_1)\), which is the exact Black–Scholes Delta.

Tier 3 · Empirical

Using the Lab 1 output for Lesson 6, compare the absolute differences between AAD and central finite differences for Delta (\(7.92 \times 10^{-11}\)), Vega (\(3.04 \times 10^{-5}\)), and Rho (\(1.93 \times 10^{-5}\)). Why is the Delta difference substantially smaller than Vega and Rho?

Solution

Delta is evaluated with bump size \(\Delta S = 0.001\) on spot \(S = 100\) (relative bump \(10^{-5}\)), whereas Vega and Rho use bumps \(\Delta \sigma = 0.001\) on \(\sigma = 0.20\) (relative bump \(5 \times 10^{-3}\)) and \(\Delta r = 0.0005\) on \(r = 0.05\) (relative bump \(10^{-2}\)). Central finite difference truncation error scales quadratically with relative step size: \(O(h^2)\). The larger relative bumps in Vega and Rho produce truncation errors on the order of \(10^{-5}\), whereas AAD computes the exact analytic derivative without finite difference truncation error.

A trading book contains 500 interest rate swaps. Taping the forward pricer requires 8 KB of RAM per swap per simulation path. For a Monte Carlo simulation of 50,000 paths, calculate the total RAM footprint and evaluate whether standard server memory is exceeded.

Solution

The total memory required is \(500 \text{ swaps} \times 8 \text{ KB} \times 50,000 \text{ paths} = 200,000,000 \text{ KB} \approx 200 \text{ GB}\). Because 200 GB exceeds the standard RAM capacity of typical single server nodes (often 64 GB to 128 GB), unconstrained taping causes out-of-memory crashes. Checkpointing or evaluating paths in batches of 5,000 paths (reducing memory to 20 GB) is required.

An options desk executes 2,000 sweeps of an AAD Greek tape. If the AAD tape evaluates 3 Greeks in 34.3 ms while central finite differences evaluates them in 4.0 ms, explain why finite differences was faster in this specific single-contract microbenchmark, and determine at what Greek vector dimension \(n^*\) AAD becomes faster.

Solution

In this microbenchmark on an analytical Black–Scholes formula, the formula is so lightweight that dynamic graph node allocation and pointer dereferencing in Python impose significant interpretive overhead. For a plain compiled C++ pricer without tape overhead, each FD evaluation takes 1 unit of work, so \(2n\) evaluations take \(2n\) units, while AAD takes \(\approx 4\) units. The crossover dimension is \(2 n^* = 4 \implies n^* = 2\). For exotics or multi-factor models with \(n \ge 10\) risk factors, AAD is overwhelmingly faster.

Tier 4 · Research

Explain how the Implicit Function Theorem enables Adjoint Algorithmic Differentiation through iterative numerical PDE solvers without taping inner solver iterations.

Solution

An implicit finite difference PDE step solves a linear system \(\mathbf{A}(\theta) \mathbf{v}^{n} = \mathbf{v}^{n+1}\). Taping each iteration of a Krylov or SOR solver records thousands of intermediate steps, consuming immense memory. By the Implicit Function Theorem, the converged solution satisfies the residual equation \(\mathbf{R}(\mathbf{v}^n, \theta) = \mathbf{A}(\theta) \mathbf{v}^n - \mathbf{v}^{n+1} = \mathbf{0}\). The adjoint with respect to \(\theta\) is obtained by solving a single transposed linear system \(\mathbf{A}^T \bar{\mathbf{v}}^n = \bar{\mathbf{y}}\), completely bypassing the internal solver iterations and reducing memory overhead to zero.

Describe the hybrid Likelihood Ratio Method (LRM) and Pathwise AAD technique for computing Greeks of discontinuous barrier options.

Solution

Pathwise AAD fails for digital and barrier options because indicator payoffs \(\mathbf{1}_{S_T > K}\) have distributional derivatives. The Likelihood Ratio Method transfers differentiation from the discontinuous payoff onto the smooth transitional density score function: \(\nabla_\theta \mathbb{E}[g(S_T)] = \mathbb{E}[g(S_T) \nabla_\theta \ln p(S_T; \theta)]\). In a hybrid scheme (Glasserman 2003), pathwise AAD is applied up to the penultimate step \(T - \Delta t\), and LRM is applied over the final step \(\Delta t\), combining the low variance of pathwise differentiation with the regularity of score functions.

How do modern C++ quantitative libraries implement tape-free AAD using expression templates and compile-time operator overloading for GPU execution?

Solution

Traditional AAD libraries record dynamic memory tapes on the heap, which causes memory fragmentation and serial bottlenecking on GPUs. Tape-free AAD uses modern C++ expression templates (such as Adept or Ensmallen) and static metaprogramming to resolve the computational DAG at compile time. Intermediate adjoint dependencies are mapped directly into thread-local register files and CUDA shared memory, executing the forward and backward passes entirely in GPU registers without dynamic global memory allocations.

    Checkpointing trades extra forward computation for drastically reduced RAM footprint during reverse sweeps.

  8. Does first-order AAD compute the full Hessian (cross-gamma) matrix in constant time?

    Options

    First-order AAD evaluates gradients in \(O(1)\) pricer equivalents; second-order Hessians scale with the dimension \(n\).

  9. What reverse accumulation rule applies to a node \(v_j\) that feeds into multiple child nodes \(v_i\)?

    Options

    By the multivariable chain rule, total derivatives sum across all branching paths in the computational graph.
