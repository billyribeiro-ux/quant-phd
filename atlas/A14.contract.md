## 1. Mathematical Specifications

### 1.1 Merton (1974) Structural Model

In Merton's model, the firm's total asset value $V_t$ follows geometric Brownian motion under the risk-neutral measure $\mathbb{Q}$:
$$dV_t = (r - \delta) V_t dt + \sigma_V V_t dW_t^\mathbb{Q}$$
The capital structure consists of equity $E$ and a single zero-coupon debt issue maturing at $T$ with face value $D$. Payout rate $\delta = 0$.

At maturity $T$, equityholders receive the residual claim $\max(V_T - D, 0)$, so equity is an isomorphic European call option on firm assets:
$$E = V \Phi(d_1) - D e^{-r T} \Phi(d_2)$$
where
$$d_1 = \frac{\ln(V / D) + (r + \frac{1}{2}\sigma_V^2)T}{\sigma_V \sqrt{T}}, \quad d_2 = d_1 - \sigma_V \sqrt{T}$$
By balance-sheet accounting, defaultable zero-coupon debt value is:
$$B = V - E = D e^{-r T} \Phi(d_2) + V (1 - \Phi(d_1))$$
The continuously compounded debt yield $y$ and credit spread $s$ are:
$$y = -\frac{1}{T} \ln\left(\frac{B}{D}\right), \quad s = y - r = -\frac{1}{T} \ln\left(\frac{B}{D e^{-r T}}\right)$$
The risk-neutral default probability is:
$$\mathrm{PD}^\mathbb{Q} = \Phi(-d_2)$$

### 1.2 Black–Cox (1976) First-Passage Model

In Black & Cox (1976), default occurs at the first-passage time $\tau$ when asset value $V_t$ drops to an exogenous safety covenant barrier $C(t) = K \le D$ before maturity $T$:
$$\tau = \inf\{t > 0 : V_t \le K\}$$
For a constant default barrier $K < V$, the risk-neutral cumulative distribution function of default before horizon $T$ is:
$$\Prob^\mathbb{Q}(\tau \le T) = \Phi\left( \frac{\ln(K / V) - (r - \frac{1}{2}\sigma_V^2)T}{\sigma_V \sqrt{T}} \right) + \left(\frac{K}{V}\right)^{2r/\sigma_V^2 - 1} \Phi\left( \frac{\ln(K / V) + (r - \frac{1}{2}\sigma_V^2)T}{\sigma_V \sqrt{T}} \right)$$
Survival probability to maturity is $q(T) = 1 - \Prob^\mathbb{Q}(\tau \le T)$.
If default occurs at $\tau \le T$, debt holders receive recovery fraction $R \in [0, 1]$ of debt face value $D$, discounted at the risk-free rate to present value $R D e^{-r \tau}$. When default does not occur ($\tau > T$), debt holders receive the promised face value $D$ at $T$.
Under flat barrier $K$, the debt value is:
$$B = D e^{-r T} q(T) + R D \int_0^T e^{-r t} f_\tau(t) dt$$
where $f_\tau(t)$ is the first-passage density of Brownian motion with drift:
$$f_\tau(t) = \frac{|\ln(K/V)|}{\sigma_V \sqrt{2\pi t^3}} \exp\left( -\frac{(\ln(K/V) - (r - \frac{1}{2}\sigma_V^2)t)^2}{2\sigma_V^2 t} \right)$$
The equity value is $E = V - B$. Credit spread is $s = -\frac{1}{T}\ln(B / (D e^{-r T}))$.

### 1.3 Reduced-Form (Intensity-Based) Model

In Jarrow & Turnbull (1995) and Duffie & Singleton (1999), default is driven by an exogenous jump process with hazard rate $\lambda \ge 0$.
Under constant intensity $\lambda$ and constant risk-free rate $r$:
- **Recovery of Market Value (RMV, Duffie–Singleton):**
  At default, bondholders receive fraction $R$ of the pre-default market value of the bond. The zero-coupon bond price is:
  $$P(0, T) = \exp\left(-(r + \lambda (1 - R)) T\right)$$
  The credit spread is $s = \lambda (1 - R)$.
- **Recovery of Face Value (RFV / Recovery of Par):**
  At default time $\tau \le T$, bondholders receive recovery payment $R \cdot D$ (where $D=1$ per unit face value).
  $$P(0, T) = e^{-(r + \lambda)T} + \int_0^T R \lambda e^{-\lambda t} e^{-r t} dt = e^{-(r + \lambda)T} + \frac{R \lambda}{r + \lambda} \left(1 - e^{-(r + \lambda)T}\right)$$
  The credit spread is $s = -\frac{1}{T} \ln(P(0, T)) - r$.
The survival probability is $\Prob(\tau > T) = \exp(-\lambda T)$.

### 1.4 Merton Distance to Default (KMV System)

Observed market equity $E$ and equity volatility $\sigma_E$ are inverted to recover unobservable asset value $V$ and asset volatility $\sigma_V$ through the simultaneous system:
$$E = V \Phi(d_1) - D e^{-r T} \Phi(d_2)$$
$$\sigma_E = \frac{V \Phi(d_1)}{E} \sigma_V$$
Given an expected physical asset drift $\mu$ (defaulting to risk-free rate $r$ if unspecified), the physical Distance to Default ($\mathrm{DD}$) is:
$$\mathrm{DD} = \frac{\ln(V / D) + (\mu - \frac{1}{2}\sigma_V^2)T}{\sigma_V \sqrt{T}}$$
The implied expected default frequency is $\mathrm{EDF} = \Phi(-\mathrm{DD})$.

### 1.5 Bharath & Shumway (2008) Naive Predictor

Bharath & Shumway (2008) approximate the structural parameters without iterative solving:
$$V_{\mathrm{naive}} = E + D$$
$$\sigma_{V, \mathrm{naive}} = \frac{E}{E + D} \sigma_E + \frac{D}{E + D} (0.05 + 0.25 \sigma_E)$$
$$\mathrm{DD}_{\mathrm{naive}} = \frac{\ln(V_{\mathrm{naive}} / D) + (\mu - \frac{1}{2}\sigma_{V, \mathrm{naive}}^2)T}{\sigma_{V, \mathrm{naive}} \sqrt{T}}$$
The naive default probability is $\pi_{\mathrm{naive}} = \Phi(-\mathrm{DD}_{\mathrm{naive}})$.

### 1.6 Credit Spread Decomposition (Huang & Huang 2012)

Observed corporate credit spread $s$ is decomposed into:
1. **Expected Loss Spread ($s_{\mathrm{EL}}$):**
   $$s_{\mathrm{EL}} = -\frac{1}{T} \ln\left(1 - \mathrm{PD} \times (1 - R)\right)$$
2. **Credit Risk Premium Spread ($s_{\mathrm{CRP}}$):**
   $$s_{\mathrm{CRP}} = s_{\mathrm{EL}} \times \rho_{\mathrm{premium}}$$
   where $\rho_{\mathrm{premium}} \ge 0$ is the risk premium multiplier (ratio of risk-neutral to physical loss rate minus 1).
3. **Total Credit Component:**
   $$s_{\mathrm{credit}} = s_{\mathrm{EL}} + s_{\mathrm{CRP}}$$
4. **Non-Credit Residual Spread:**
   $$s_{\mathrm{residual}} = \max(0.0, s - s_{\mathrm{credit}})$$
5. **Credit Fraction:**
   $$f_{\mathrm{credit}} = \frac{\min(s, s_{\mathrm{credit}})}{s}$$

## 3. Function Details and Validation

- `merton_price`:
  - `asset_value > 0`, `debt_face > 0`, `maturity > 0`, `asset_volatility > 0`.
  - Returns dict with keys `["equity", "debt", "yield", "spread", "default_prob"]`.
  - Invariant: `abs(equity + debt - asset_value) < 1e-7`.

- `black_cox_price`:
  - `asset_value >= barrier > 0`, `debt_face > 0`, `maturity > 0`, `asset_volatility > 0`, `0.0 <= recovery_rate <= 1.0`.
  - Returns dict with keys `["debt", "equity", "spread", "survival_prob", "default_prob"]`.
  - Invariant: `abs(debt + equity - asset_value) < 1e-7`.

- `reduced_form_price`:
  - `maturity > 0`, `hazard_rate >= 0`, `0.0 <= recovery_rate <= 1.0`.
  - `convention` in `("rmv", "rfv")`.
  - Returns dict with keys `["price", "yield", "spread", "survival_prob"]`.

- `merton_distance_to_default`:
  - `equity_value > 0`, `debt_face > 0`, `maturity > 0`, `equity_volatility > 0`.
  - Solves for $(V, \sigma_V)$ using bisection / Newton root search.
  - Returns dict with keys `["asset_value", "asset_volatility", "distance_to_default", "default_prob"]`.

- `bharath_shumway_naive_dd`:
  - `equity_value > 0`, `debt_face > 0`, `maturity > 0`, `equity_volatility > 0`.
  - Returns dict with keys `["asset_value", "asset_volatility", "distance_to_default", "default_prob"]`.

- `credit_spread_decomposition`:
  - `market_spread >= 0`, `0.0 <= default_prob <= 1.0`, `0.0 <= recovery_rate <= 1.0`, `maturity > 0`, `risk_premium_ratio >= 0`.
  - Returns dict with keys `["spread_el", "spread_crp", "spread_credit", "spread_residual", "credit_fraction"]`.
