## Overview

Milestone A6 delivers the foundational numerical derivative pricing library for Atlas:
1. **Black–Scholes–Merton analytical pricer (`bsm_price`):** closed-form European option pricing and full analytical Greek vectors (\(\Delta, \Gamma, \Theta, \mathcal{V}, \rho\)).
2. **Cox–Ross–Rubinstein binomial tree (`binomial_tree_price`):** recombining lattice supporting European and American early exercise with lattice Greek extraction.
3. **Trinomial tree (`trinomial_tree_price`):** Boyle (1977) 3-branch discrete recombining lattice matching drift and variance with stability conditions and Greek extraction.
4. **Finite difference PDE solver (`pde_price`):** log-spot parabolic PDE solver supporting Explicit, Implicit, and Crank–Nicolson schemes, Thomas tridiagonal elimination, and Brennan–Schwartz early-exercise constraint handling.
5. **Monte Carlo simulation (`monte_carlo_price`):** European path simulation with antithetic variates, standard error estimation, and finite-difference/score Greeks.
6. **Longstaff–Schwartz least-squares Monte Carlo (`lsmc_price`):** American option pricing via backward induction regression on orthogonal basis functions (weighted Laguerre, Hermite, monomial) over in-the-money paths.
7. **Cross-method pricing consistency (`cross_method_consistency_check`):** automated reconciliation verifying that discrete lattices, PDE schemes, and Monte Carlo estimators converge to analytical benchmarks within proven error tolerances.

Every function validates its inputs and raises `ValueError` with an informative message when invariants are violated. No function prints, warns, writes files, or mutates its inputs.

## Conventions

| Concept | Definition & Convention |
|---|---|
| Spot price \(S\) | `float`, \(S > 0\), spot asset level. |
| Strike price \(K\) | `float`, \(K > 0\), option strike price. |
| Risk-free rate \(r\) | `float`, annualized continuously compounded risk-free rate. |
| Volatility \(\sigma\) | `float`, \(\sigma > 0\), annualized asset return volatility. |
| Time to maturity \(T\) | `float`, \(T > 0\), annualized time to expiration in years. |
| Dividend yield \(q\) | `float`, annualized continuous dividend yield (\(q \ge 0\), default 0.0). |
| Call / Put indicator | `is_call: bool = True`. When `True`, prices call; when `False`, prices put. |
| American indicator | `is_american: bool = False`. When `True`, evaluates early exercise. |
| Tolerance | `float`, \(\epsilon > 0\), allowable pricing discrepancy. |

## Error specifications

| Function | Condition | Exception |
|---|---|---|
| All functions | `spot <= 0` | `ValueError` |
| All functions | `strike <= 0` | `ValueError` |
| All functions | `vol <= 0` | `ValueError` |
| All functions | `maturity <= 0` | `ValueError` |
| All functions | `dividend_yield < 0` | `ValueError` |
| `binomial_tree_price`, `trinomial_tree_price` | `n_steps <= 0` | `ValueError` |
| `pde_price` | `n_time_steps <= 0` or `n_spot_steps < 3` | `ValueError` |
| `pde_price` | `scheme not in ("explicit", "implicit", "crank_nicolson")` | `ValueError` |
| `monte_carlo_price`, `lsmc_price` | `n_paths <= 0` | `ValueError` |
| `monte_carlo_price`, `lsmc_price` | `n_steps <= 0` | `ValueError` |
| `lsmc_price` | `degree < 1` | `ValueError` |
| `lsmc_price` | `basis not in ("laguerre", "hermite", "monomial")` | `ValueError` |
| `cross_method_consistency_check` | `tolerance <= 0` | `ValueError` |
