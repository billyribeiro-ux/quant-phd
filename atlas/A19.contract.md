## 1. Units and Conventions

| Quantity | Unit and definition |
|---|---|
| Returns \(R\) | `np.ndarray` of 1D floating point values. Simple or log periodic returns. |
| Quantile / Confidence level \(\alpha\) | `float` in \((0, 1)\), typically \(\alpha = 0.05\) (left tail) or \(0.01\). |
| Losses \(L\) | Expressed as negative returns \(L = -R\), or left-tail returns \(R \le \text{VaR}_\alpha\). |
| Equity value \(W\) | Market capitalization, scalar or 1D array in millions of dollars (\(W > 0\)). |
| Debt value \(D\) | Book value of total liabilities, scalar or 1D array in millions of dollars (\(D \ge 0\)). |
| Prudential capital ratio \(k\) | Regulatory benchmark fraction \(k \in (0, 1)\), typically \(0.08\) (8% for US Fed stress tests) or \(0.055\) (5.5% for European banks). |
| Crisis market decline \(d\) | Macroeconomic systemic crisis drawdown \(d \in (0, 1)\), standard value \(d = 0.40\) (40% 6-month market crash). |
| Interbank liabilities \(L_{ij}\) | Nominal matrix \(L \in \R^{N \times N}\) with \(L_{ij} \ge 0, L_{ii} = 0\), where \(L_{ij}\) is the obligation of institution \(i\) to institution \(j\). |
| External operating assets \(z\) | Vector \(z \in \R_+^N\) representing outside liquid and fundamental assets available for debt service. |

## 2. Mathematical Specifications

### 2.1 CoVaR and \(\Delta\text{CoVaR}\) (Adrian & Brunnermeier 2016)
Given institution returns \(R_{i,t}\), system returns \(R_{s,t}\), and optional lagged macro state variables \(M_{t-1} \in \R^{T \times K}\):
The \(\alpha\)-quantile regression problem minimizes the check function (pinball loss) \(\rho_\alpha(u) = u(\alpha - \indic_{\{u < 0\}})\):
$$\min_{\beta_\alpha} \sum_{t=1}^T \rho_\alpha(R_{s,t} - \tilde{X}_t \beta_\alpha)$$
where \(\tilde{X}_t = [1, R_{i,t}, M_{t-1}]\).

1. **Institution VaR:**
   $$\text{VaR}_{\alpha,t}^i = \hat{\alpha}_\alpha^i + \hat{\gamma}_\alpha^i M_{t-1}$$
   where parameters are estimated by regressing \(R_{i,t}\) on \([1, M_{t-1}]\). At the sample median: \(\text{VaR}_{0.5,t}^i\).
2. **Conditional System VaR (\(\text{CoVaR}\)):**
   $$\text{CoVaR}_{\alpha,t}^{s|i} = \hat{\alpha}_\alpha^{s|i} + \hat{\beta}_\alpha^{s|i} \text{VaR}_{\alpha,t}^i + \hat{\gamma}_\alpha^{s|i} M_{t-1}$$
3. **Marginal Systemic Contribution (\(\Delta\text{CoVaR}\)):**
   $$\Delta\text{CoVaR}_{\alpha,t}^i = \text{CoVaR}_{\alpha,t}^{s|i} - \text{CoVaR}_{\alpha,t}^{s|\text{median}} = \hat{\beta}_\alpha^{s|i} \left(\text{VaR}_{\alpha,t}^i - \text{VaR}_{0.5,t}^i\right)$$
   For static estimation without macro state variables, \(\text{VaR}_\alpha^i\) is the empirical sample quantile of \(R_i\), and \(\Delta\text{CoVaR}_\alpha^i = \hat{\beta}_\alpha^{s|i} (\text{VaR}_\alpha^i - \text{Median}(R_i))\).

### 2.2 Marginal Expected Shortfall (MES) and Long-Run MES (LRMES) (Acharya et al. 2017)
1. **Non-parametric MES:**
   Given system return series \(R_{s,t}\) and institution return series \(R_{i,t}\) over \(T\) periods, let \(\mathcal{T}_\alpha = \{t : R_{s,t} \le \text{VaR}_\alpha^s\}\) be the set of market crisis days:
   $$\text{MES}_\alpha^i = -\frac{1}{|\mathcal{T}_\alpha|} \sum_{t \in \mathcal{T}_\alpha} R_{i,t}$$
   where \(\text{VaR}_\alpha^s\) is the empirical \(\alpha\)-quantile of \(R_s\).
2. **Long-Run Marginal Expected Shortfall (LRMES):**
   Projected equity loss over a 6-month crisis with aggregate market drop \(d = 0.40\):
   $$\text{LRMES}_i = 1 - \exp(\ln(1 - d) \cdot \beta_i)$$
   where \(\beta_i = \Cov(R_i, R_s) / \Var(R_s)\) is the systematic equity beta, or by the daily approximation \(\text{LRMES}_i \approx 1 - \exp(-18 \times \text{MES}_i)\).

### 2.3 SRISK: Conditional Capital Shortfall Index (Brownlees & Engle 2017)
For institution \(i\) with market value of equity \(W_i\), book debt \(D_i\), prudential capital fraction \(k\), and long-run tail loss \(\text{LRMES}_i\):
1. **Capital Shortfall (\(\text{CS}_i\)):**
   $$\text{CS}_i = k D_i - (1 - k)(1 - \text{LRMES}_i) W_i$$
2. **Individual SRISK:**
   $$\text{SRISK}_i = \max(0, \text{CS}_i)$$
3. **Aggregate Systemic SRISK:**
   $$\text{SRISK}_{\text{sys}} = \sum_{i=1}^N \text{SRISK}_i$$
4. **Systemic Percentage Contribution:**
   $$\text{SRISK}\%_i = \begin{cases} \frac{\text{SRISK}_i}{\text{SRISK}_{\text{sys}}} & \text{if } \text{SRISK}_{\text{sys}} > 0 \\ 0 & \text{otherwise} \end{cases}$$

### 2.4 Interbank Network Contagion and Clearing (Acemoglu et al. 2015; Eisenberg & Noe 2001)
Given an interbank liability matrix \(L \in \R^{N \times N}\) with \(L_{ii} = 0, L_{ij} \ge 0\), total nominal interbank obligations \(\bar{p}_i = \sum_{j=1}^N L_{ij}\), external asset vector \(z \in \R_+^N\), and senior outside liabilities \(b \in \R_+^N\):
1. **Relative Liability Matrix:**
   $$\Pi_{ij} = \begin{cases} \frac{L_{ij}}{\bar{p}_i} & \text{if } \bar{p}_i > 0 \\ 0 & \text{otherwise} \end{cases}$$
2. **Eisenberg–Noe Clearing Vector \(p^* \in [0, \bar{p}]\):**
   Fixed point satisfying:
   $$p_i^* = \min\left(\bar{p}_i, \; \max\left(0, \; z_i + \sum_{j=1}^N \Pi_{ji} p_j^* - b_i\right)\right)$$
   Computed via Picard iteration: \(p^{(k+1)} = \Phi(p^{(k)})\) starting from \(p^{(0)} = \bar{p}\), terminating when \(\|p^{(k+1)} - p^{(k)}\|_\infty < \text{tol}\).
3. **Default Indicators and Equity Values:**
   $$d_i = \indic_{\{p_i^* < \bar{p}_i\}}$$
   $$e_i^* = \max\left(0, \; z_i + \sum_{j=1}^N \Pi_{ji} p_j^* - b_i - \bar{p}_i\right)$$

### 2.5 Systemic Risk Monitor and Alert Thresholds
Monitors systemic risk indicators against calibrated prudential alert levels:
- \(\Delta\text{CoVaR}\) threshold: warning if \(\Delta\text{CoVaR}_i < \theta_{\Delta\text{CoVaR}}\) (e.g. \(<-0.025\) or exceeding 250 bps spillover).
- \(\text{MES}\) threshold: warning if \(\text{MES}_i > \theta_{\text{MES}}\) (e.g. \(> 0.04\) or 4% daily drop in crisis).
- \(\text{SRISK}\) threshold: warning if \(\text{SRISK}_i > \theta_{\text{SRISK}}\) or aggregate \(\text{SRISK}_{\text{sys}} > \Theta_{\text{total}}\).
- Network contagion: warning if defaults \(\sum d_i > 0\) or cascade depth \(> 1\).
Alert statuses: `"NORMAL"`, `"WATCH"`, `"WARNING"`, `"CRITICAL"`.
