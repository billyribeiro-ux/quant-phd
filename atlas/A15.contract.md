# Atlas A15 — fundamentals engine (`atlas.fundamentals`)

**Delivered in:** AC2 · Financial Statement Analysis & Earnings Quality
**Status:** frozen once AC2 is released. A breaking change goes through
`CONTRACT_CHANGE_REQUESTS` (BUILDER_RULES §5.5).
**Depends on:** NumPy 2.4 and the Python standard library only. A15 consumes no
earlier milestone API: it takes the SEC "company facts" JSON as a parsed
mapping, so it can be built and graded before A2 (the data layer) exists. A2
will supply the loader that downloads and stores that JSON.
**Consumed by:** A16 (CF4, valuation engine), whose scenario and sensitivity
grids are driven by the standardized statements and ratios defined here.

Every function validates its inputs and raises `ValueError` with a message that
names the violated condition (the grader checks the exception type, not the
wording). No function prints, warns, or mutates its inputs. Numbers are
`float` unless a function says otherwise; money is in the unit the filing
reports (the engine never converts currency or scale).

## Input: the company-facts mapping

```python
Facts = Mapping[str, Any]
# facts["facts"][taxonomy][tag]["units"][unit] is a list of observations; each observation is a mapping with
#   "end": ISO date "YYYY-MM-DD"  (period end, or the instant)
#   "val": number
#   "filed": ISO date             (when the filing was made)
#   "form": str                   (e.g. "10-K", "10-K/A", "10-Q")
#   "fp": str                     (e.g. "FY", "Q1")
#   "start": ISO date             (present for flow items, absent for instant items)
#   "accn": str                   (optional filing identifier; used only as a tie-break)
# Extra keys are ignored. Only taxonomy "us-gaap" is read; unit "USD" for money, "shares" for share counts.
```

A mapping that lacks `"facts"`, whose observations lack `end`, `val`, `filed` or `form`, or
whose `val` is not a finite number, raises `ValueError`. Dates are parsed with
`datetime.date.fromisoformat`; anything else raises `ValueError`.

## Standardization

An observation is **annual** when `form` starts with `"10-K"`, `fp == "FY"`, and either
(flow item) `start` is present and `350 <= (end - start).days <= 380`, or
(instant item) `start` is absent. Other observations are ignored.

For one tag and one period end, several annual observations can exist (each 10-K repeats its comparatives, and a
10-K/A restates). Selection is the **as-of rule**: among the annual observations for that `end` whose
`filed <= as_of`, take the one with the greatest `(filed, accn or "")`. With `as_of=None` there is no filing-date
cut-off. A period end with no observation at or before `as_of` does not exist for that tag.

For one standardized item the **tag priority** below applies per period end: the first tag in the list that has an
annual observation (after the as-of rule) for that `end` supplies the value. A period end with no tag in the list
has no value for that item (the key is absent; nothing is imputed, interpolated or defaulted).

| Item | us-gaap tags, in priority order | Kind |
|---|---|---|
| `revenue` | `Revenues`, `RevenueFromContractWithCustomerExcludingAssessedTax`, `SalesRevenueNet` | flow |
| `cogs` | `CostOfRevenue`, `CostOfGoodsAndServicesSold` | flow |
| `sga` | `SellingGeneralAndAdministrativeExpense` | flow |
| `depreciation` | `DepreciationDepletionAndAmortization`, `DepreciationAndAmortization`, `Depreciation` | flow |
| `operating_income` | `OperatingIncomeLoss` | flow |
| `net_income` | `NetIncomeLoss` | flow |
| `cfo` | `NetCashProvidedByUsedInOperatingActivities` | flow |
| `total_assets` | `Assets` | instant |
| `current_assets` | `AssetsCurrent` | instant |
| `cash` | `CashAndCashEquivalentsAtCarryingValue` | instant |
| `receivables` | `AccountsReceivableNetCurrent` | instant |
| `ppe` | `PropertyPlantAndEquipmentNet` | instant |
| `total_liabilities` | `Liabilities` | instant |
| `current_liabilities` | `LiabilitiesCurrent` | instant |
| `long_term_debt` | `LongTermDebtNoncurrent` | instant |
| `equity` | `StockholdersEquity` | instant |
| `shares_outstanding` | `CommonStockSharesOutstanding` (unit `shares`) | instant |

## Ratios (Penman conventions)

"Previous year" and "average" are defined in Conventions below: the previous year is the latest period end 350 to 380 days earlier, and an average is the mean of the two year-end balances. A function that needs an item
or a previous year that the statements do not contain raises `ValueError` naming the item or period.

```python
def dupont(statements, period_end: str) -> dict[str, float]
    # net_margin = net_income / revenue; asset_turnover = revenue / average total_assets;
    # leverage = average total_assets / average equity; roe = net_income / average equity;
    # roa = net_income / average total_assets. Keys: net_margin, asset_turnover, leverage, roe, roa.
    # Identity: roe == net_margin * asset_turnover * leverage (to relative 1e-12). Zero revenue, assets or equity
    # in a denominator raises ValueError.

def roic(statements, period_end: str, tax_rate: float) -> float
    # NOPAT / average invested capital; NOPAT = operating_income * (1 - tax_rate), 0 <= tax_rate < 1;
    # invested capital = equity + long_term_debt - cash (year-end), averaged. A non-positive average invested
    # capital raises ValueError.

def current_ratio(statements, period_end: str) -> float      # current_assets / current_liabilities
def gross_margin(statements, period_end: str) -> float       # (revenue - cogs) / revenue
def debt_to_assets(statements, period_end: str) -> float     # long_term_debt / total_assets (year-end)
def days_sales_outstanding(statements, period_end: str) -> float  # receivables / revenue * 365
```

## Earnings quality

```python
def accruals_cash_flow(statements, period_end: str) -> float
    # (net_income - cfo) / average total_assets            (Hribar-Collins cash-flow accruals)

def accruals_balance_sheet(statements, period_end: str) -> float
    # Sloan (1996) operating accruals, balance-sheet approach, scaled by average total assets:
    # [ (d current_assets - d cash) - (d current_liabilities) - depreciation ] / average total_assets
    # where d x = x(period_end) - x(previous year end). Short-term debt and taxes payable are not separate items
    # in this contract: the engine uses current_liabilities as published; the lesson states that simplification.

def modified_jones(sample: Sequence[Mapping[str, float]]) -> dict[str, Any]
    # Dechow, Sloan & Sweeney (1995). `sample` is a cross-section of firm-years; each element has the keys
    # total_accruals, lag_assets, d_revenue, d_receivables, ppe (all in currency units, lag_assets > 0).
    # Estimation: regress total_accruals/lag_assets on [1/lag_assets, (d_revenue - d_receivables)/lag_assets,
    # ppe/lag_assets] WITHOUT an intercept, by ordinary least squares (numpy.linalg.lstsq, rcond=None).
    # Returns {"coefficients": (a1, a2, a3), "nondiscretionary": [...], "discretionary": [...]} with
    # nondiscretionary_i = fitted_i and discretionary_i = total_accruals_i/lag_assets_i - fitted_i, in sample order.
    # Fewer than 4 firm-years, a non-positive lag_assets, non-finite values or a rank-deficient design raise ValueError.
```

## Scores

```python
def piotroski_f_score(statements, period_end: str) -> dict[str, Any]
    # Piotroski (2000), nine binary signals, each 1 if true else 0. With ROA_t = net_income_t / total_assets_{t-1}
    # (beginning-of-year assets), CFO_t = cfo_t / total_assets_{t-1}, LEV_t = long_term_debt_t / average total_assets_t,
    # CR_t = current_ratio_t, GM_t = gross_margin_t, ATO_t = revenue_t / total_assets_{t-1}:
    #   1 ROA_t > 0                      2 CFO_t > 0                 3 ROA_t > ROA_{t-1}
    #   4 CFO_t > ROA_t (cash > accruals)  5 LEV_t < LEV_{t-1}         6 CR_t > CR_{t-1}
    #   7 shares_outstanding_t <= shares_outstanding_{t-1} (no equity issuance)
    #   8 GM_t > GM_{t-1}                9 ATO_t > ATO_{t-1}
    # Needs the period end and its two preceding year ends. Returns {"signals": (s1..s9), "score": sum}.

def beneish_m_score(statements, period_end: str) -> dict[str, float]
    # Beneish (1999), eight-variable model, on t and t-1:
    #   DSRI = (receivables_t / revenue_t) / (receivables_{t-1} / revenue_{t-1})
    #   GMI  = gross_margin_{t-1} / gross_margin_t
    #   AQI  = (1 - (current_assets_t + ppe_t) / total_assets_t) / (1 - (current_assets_{t-1} + ppe_{t-1}) / total_assets_{t-1})
    #   SGI  = revenue_t / revenue_{t-1}
    #   DEPI = (depr_{t-1} / (depr_{t-1} + ppe_{t-1})) / (depr_t / (depr_t + ppe_t)),  depr = depreciation
    #   SGAI = (sga_t / revenue_t) / (sga_{t-1} / revenue_{t-1})
    #   LVGI = ((current_liabilities_t + long_term_debt_t) / total_assets_t) / (same at t-1)
    #   TATA = (net_income_t - cfo_t) / total_assets_t
    #   M = BENEISH_INTERCEPT + sum(BENEISH_COEFFICIENTS[name] * value[name])
    # Returns the eight variables and "m_score". A zero denominator or a missing item raises ValueError.

BENEISH_INTERCEPT: float
BENEISH_COEFFICIENTS: Mapping[str, float]   # keys DSRI, GMI, AQI, SGI, DEPI, SGAI, LVGI, TATA
```

**Departures from the published definitions (deliberate proxies, stated in the lessons).**
The engine works from the standardized items only, so three Piotroski (2000) inputs are proxies:
`net_income` is the `NetIncomeLoss` tag (the paper uses income before extraordinary items);
the equity-issuance signal (7) uses the change in `shares_outstanding` (the paper tests whether the firm issued
common equity in the year); `long_term_debt` is the `LongTermDebtNoncurrent` tag (the paper's total long-term debt).
Documentation only: signatures and behaviour are as written above.

**The Beneish constants are published numbers, not derived.** The module that delivers A15 states the intercept and
the eight coefficients with a `data-locator` into Beneish (1999) and grades the claim at the grade the evidence
supports; a coefficient the builder cannot confirm against the paper (or a source that reproduces its table)
is reported as unconfirmed and the module's text says so. The reference solution and the grader import them from one
place, so changing a confirmed value changes both.

## Conventions

| Quantity | Definition |
|---|---|
| Period end | An ISO date string; a statement mapping is keyed by it. |
| Previous year | The latest period end in the mapping that is 350 to 380 days earlier than the period end asked for; none raises `ValueError`. |
| Average | `(x_t + x_{t-1}) / 2` of year-end balances. |
| Missing item | Absent key; any function that needs it raises `ValueError`. Nothing is imputed. |
| Division | A zero denominator raises `ValueError`; so does a non-finite result. |
| Tolerance | Scale: ratios, accrual ratios and scores are invariant to multiplying every money item by a positive constant; the grader tests this. |

## Data for the module (not part of the code contract)

The lab and the reader's own runs use real company-facts files; the autograder uses generated filers (labelled
SIMULATED) so that every instance is valid and the answers differ across seeds. Real files come from the SEC's
`data.sec.gov/api/xbrl/companyfacts/CIK##########.json`. Embedding any of it needs a `DATA_REQUESTS` entry that
quotes the issuer's statement on reuse (BUILDER_RULES §6.6, `tools/data_sources.yaml`); until that statement has been
read from an issuer page the build can reach, the lab uses an explicit honest-pending state, never invented figures.
