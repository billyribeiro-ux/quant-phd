## 1. Mathematical Specifications

### 1.1 Point-in-Time Feature Store & Lookahead Prevention

A production quantitative machine learning pipeline requires deterministic point-in-time state reconstruction. Let an entity $e \in \mathcal{E}$ possess time-stamped feature observations $(t_{\text{obs}}, f, v)$, where $t_{\text{obs}}$ is the availability timestamp, $f$ is the feature name, and $v \in \R$ is the observed scalar value.

For an evaluation query at decision timestamp $t_{\text{query}}$:
$$\mathcal{F}_{t_{\text{query}}} = \{ (t_{\text{obs}}, f, v) : t_{\text{obs}} \le t_{\text{query}} \}$$

The feature store enforces strict temporal causality:
1. Any record with $t_{\text{obs}} > t_{\text{query}}$ is inaccessible at $t_{\text{query}}$. If a query attempts to retrieve future data or if no observation exists prior to $t_{\text{query}}$, the store returns `np.nan` or raises `ValueError` in strict mode.
2. The as-of value for feature $f$ at query time $t_{\text{query}}$ is the most recent observation:
   $$v^*(e, f, t_{\text{query}}) = v(e, f, t^*), \quad t^* = \max \{ t_{\text{obs}} \le t_{\text{query}} \}$$

```python
class FeatureStore:
    def __init__(self) -> None: ...
    def register_entity(self, entity_id: str) -> None: ...
    def add_feature_record(self, entity_id: str, timestamp: int | float, feature_name: str, value: float) -> None: ...
    def get_point_in_time(self, entity_id: str, query_timestamp: int | float, feature_names: list[str] | None = None) -> dict[str, float]: ...
    def as_of_join(self, query_keys: list[tuple[str, int | float]], feature_names: list[str]) -> np.ndarray: ...
```

### 1.2 Purged and Embargoed Cross-Validation (PurgedKFold & CombinatorialPurgedCV)

Standard $K$-fold cross-validation violates independence when labels are computed over overlapping forward return horizons $[i, i + h - 1]$ where $h \ge 1$ bars.

Let $T$ denote the total sample size. For each split into test fold indices $J_{\text{test}} = [j_{\text{start}}, j_{\text{end}}]$ and candidate training indices $J_{\text{cand}} = \{0, \dots, T-1\} \setminus J_{\text{test}}$:

1. **Left-Purging:** A training observation $i \in J_{\text{cand}}$ with label window $[i, i + h - 1]$ overlaps with the test evaluation period if:
   $$i \le j_{\text{end}} \quad \text{and} \quad i + h - 1 \ge j_{\text{start}}$$
   Every such index $i$ is purged from the training set.
2. **Post-Test Embargo:** To prevent autoregressive feature leakage following the test fold, an embargo of duration $h_{\text{embargo}} = \lceil \text{embargo\_pct} \times T \rceil$ bars is applied immediately following $j_{\text{end}}$:
   $$\text{Embargo index } i \quad \text{if } \quad j_{\text{end}} < i \le j_{\text{end}} + h_{\text{embargo}}$$

For **Combinatorial Purged Cross-Validation (CPCV)**, the sample of size $T$ is divided into $N$ contiguous blocks ($N \ge 2$). In each split, a combination of $k$ blocks ($1 \le k < N$) forms the test set, while the remaining $N-k$ blocks form the candidate training set, subject to pairwise purging and post-test embargoing against each test block.

```python
class PurgedKFold:
    def __init__(self, n_splits: int = 5, label_lookahead: int = 1, embargo_pct: float = 0.01) -> None: ...
    def split(self, n_samples: int) -> list[tuple[np.ndarray, np.ndarray]]: ...

class CombinatorialPurgedCV:
    def __init__(self, n_groups: int = 6, k_test_groups: int = 2, label_lookahead: int = 1, embargo_pct: float = 0.01) -> None: ...
    def split(self, n_samples: int) -> list[tuple[np.ndarray, np.ndarray]]: ...
```

### 1.3 Statistical Learning Estimators

All estimators implement standard `.fit(X: np.ndarray, y: np.ndarray)` and `.predict(X: np.ndarray) -> np.ndarray` methods with full type annotations.

#### 1.3.1 Ridge Regressor ($L_2$ Regularization)
Minimizes penalized residual sum of squares:
$$\min_{\beta_0, \beta} \frac{1}{2N} \|y - \beta_0 \mathbf{1} - X\beta\|_2^2 + \frac{\alpha}{2} \|\beta\|_2^2$$
Closed-form solution for centered $X$ and $y$:
$$\hat{\beta} = (X^\top X + N \alpha I)^{-1} X^\top y$$

#### 1.3.2 LASSO Regressor ($L_1$ Regularization)
Minimizes:
$$\min_{\beta_0, \beta} \frac{1}{2N} \|y - \beta_0 \mathbf{1} - X\beta\|_2^2 + \alpha \|\beta\|_1$$
Solved via cyclical coordinate descent with soft-thresholding operator:
$$\mathcal{S}(z, \gamma) = \operatorname{sign}(z) \max(|z| - \gamma, 0)$$
Coordinate update for standardized feature $j$:
$$\beta_j \leftarrow \frac{\mathcal{S}\left(\frac{1}{N} X_{:,j}^\top (y - \hat{y}^{(-j)}), \alpha\right)}{\frac{1}{N} X_{:,j}^\top X_{:,j}}$$

#### 1.3.3 Decision Tree Regressor
Greedy recursive binary partitioning using mean squared error (MSE) impurity reduction.
At each node with sample subset $\mathcal{I}_m$:
$$\operatorname{MSE}(m) = \frac{1}{|\mathcal{I}_m|} \sum_{i \in \mathcal{I}_m} (y_i - \bar{y}_m)^2$$
Split criterion chooses feature $j^*$ and split threshold $s^*$ maximizing:
$$\Delta \operatorname{MSE} = \operatorname{MSE}(m) - \left( \frac{|\mathcal{I}_L|}{|\mathcal{I}_m|} \operatorname{MSE}(L) + \frac{|\mathcal{I}_R|}{|\mathcal{I}_m|} \operatorname{MSE}(R) \right)$$
subject to tree depth $d \le d_{\max}$ and leaf sample count $|\mathcal{I}_m| \ge n_{\min\_leaf}$.

#### 1.3.4 Random Forest Regressor
Bagging ensemble of $B$ randomized decision trees:
$$\hat{f}_{\text{RF}}(x) = \frac{1}{B} \sum_{b=1}^B T_b(x; \Theta_b)$$
where each tree $T_b$ is trained on a bootstrap sample of the training data, and each split considers a random feature subset of size $m_{\text{try}} = \lfloor \sqrt{P} \rfloor$ or $\lfloor P/3 \rfloor$.

#### 1.3.5 Gradient Boosted Decision Trees (GBDT)
Stage-wise additive model fitting negative gradients (pseudo-residuals):
$$r_{i}^{(m)} = - \left[ \frac{\partial L(y_i, f(x_i))}{\partial f(x_i)} \right]_{f = f_{m-1}} = y_i - f_{m-1}(x_i) \quad (\text{for squared loss})$$
Update:
$$f_m(x) = f_{m-1}(x) + \eta \cdot h_m(x)$$
where $\eta \in (0, 1]$ is the shrinkage learning rate and $h_m(x)$ is a shallow regression tree fit to $r^{(m)}$.

#### 1.3.6 Feedforward Neural Network Regressor
Multi-layer perceptron (MLP) with analytical backpropagation:
$$\mathbf{z}^{[l]} = W^{[l]} \mathbf{a}^{[l-1]} + \mathbf{b}^{[l]}, \quad \mathbf{a}^{[l]} = g(\mathbf{z}^{[l]})$$
Trained via mini-batch stochastic gradient descent or Adam with $L_2$ weight decay regularization and early stopping on a purged validation set.


### 1.4 Interpretability via TreeSHAP

For a trained `DecisionTreeRegressor` and query vector $x \in \R^P$, exact Shapley values $\phi_0, \phi_1, \dots, \phi_P$ satisfy the local accuracy (additivity) axiom:
$$f(x) = \phi_0 + \sum_{j=1}^P \phi_j(x)$$
where $\phi_0 = \E[f(X)]$ is the expected model prediction over training leaves, and $\phi_j(x)$ represents the marginal attribution of feature $j$.

```python
class TreeSHAPExplainer:
    def __init__(self, model: DecisionTreeRegressor) -> None: ...
    @property
    def expected_value(self) -> float: ...
    def explain(self, x: np.ndarray) -> np.ndarray: ...
```

### 1.5 Model Registry & Lifecycle Management

Models transition through a finite state machine:
$$\text{DRAFT} \longrightarrow \text{VALIDATED} \longrightarrow \text{DEPLOYED} \longrightarrow \text{RETIRED}$$
- Direct transition from `DRAFT` to `DEPLOYED` without passing `VALIDATED` raises `ValueError`.
- A registered model stores serialized hyperparameters, training date range, training fold metrics, out-of-sample $R^2_{\text{OOS}}$, and Sharpe ratio.

```python
class ModelLifecycleState(str, Enum):
    DRAFT = "DRAFT"
    VALIDATED = "VALIDATED"
    DEPLOYED = "DEPLOYED"
    RETIRED = "RETIRED"

class ModelRegistry:
    def __init__(self) -> None: ...
    def register_model(self, model_id: str, model: Any, metadata: dict[str, Any]) -> None: ...
    def transition_state(self, model_id: str, new_state: ModelLifecycleState) -> None: ...
    def get_model(self, model_id: str) -> tuple[Any, dict[str, Any], ModelLifecycleState]: ...
```
