## 1. Units and Conventions

| Quantity | Unit and definition |
|---|---|
| Losses \(L\) | `np.ndarray` of 1D floating point values. Positive numbers represent portfolio losses: \(L = -R\) where \(R\) is the portfolio return. |
| Confidence level \(\alpha\) | `float` in \((0, 1)\), typically \(0.95\), \(0.975\), or \(0.99\). |
| Value-at-Risk (\(\mathrm{VaR}_\alpha\)) | \(\mathrm{VaR}_\alpha(L) = q_\alpha(L) = \inf\{l \in \mathbb{R} : F_L(l) \ge \alpha\}\). Expressed in positive loss units. |
| Expected Shortfall (\(\mathrm{ES}_\alpha\)) | \(\mathrm{ES}_\alpha(L) = \frac{1}{1-\alpha}\int_\alpha^1 \mathrm{VaR}_u(L) \, du\). Average loss conditional on exceeding \(\mathrm{VaR}_\alpha\). |
| Exceptions / Hits \(I_t\) | Binary indicator sequence \(I_t = \mathbf{1}_{\{L_t > \mathrm{VaR}_{\alpha, t}\}} \in \{0, 1\}\). |
| Degrees of freedom \(\nu\) | Integer \(\nu \ge 3\) for Student-\(t\) distributions (guaranteeing finite variance). |
| GPD Shape parameter \(\xi\) | Tail index (\(\xi > 0\) for heavy-tailed Fréchet domain). |
| GPD Scale parameter \(\beta\) | Scale parameter \(\beta > 0\). |
| Shocks \(\Delta S / S\) | Fractional price change vector \([-1, \infty)\). |

## 2. Mathematical Specifications

### 2.1 Historical Simulation VaR and Expected Shortfall
Given a sample of historical losses \(L \in \mathbb{R}^T\) with \(T \ge 10\):
- **Historical VaR:**
  $$\mathrm{VaR}_\alpha^{\text{hist}}(L) = \text{quantile}(L, \alpha)$$
  computed using linear interpolation (standard sample quantile).
- **Historical ES:**
  $$\mathrm{ES}_\alpha^{\text{hist}}(L) = \frac{1}{\sum_{t=1}^T \mathbf{1}_{\{L_t > \mathrm{VaR}_\alpha\}}} \sum_{t=1}^T L_t \cdot \mathbf{1}_{\{L_t > \mathrm{VaR}_\alpha\}}$$
  If no sample observation strictly exceeds \(\mathrm{VaR}_\alpha\) (e.g. in very small samples), \(\mathrm{ES}_\alpha(L) = \mathrm{VaR}_\alpha(L)\).

### 2.2 Parametric Normal VaR and Expected Shortfall
For losses modeled as Gaussian \(L \sim \mathcal{N}(\mu, \sigma^2)\):
$$\mathrm{VaR}_\alpha^{\text{norm}} = \mu + \sigma \Phi^{-1}(\alpha)$$
$$\mathrm{ES}_\alpha^{\text{norm}} = \mu + \sigma \frac{\phi(\Phi^{-1}(\alpha))}{1 - \alpha}$$
where \(\Phi(\cdot)\) is the standard normal cumulative distribution function and \(\phi(\cdot)\) is the standard normal probability density function.

### 2.3 Parametric Student-\(t\) VaR and Expected Shortfall
For standardized Student-\(t\) losses with \(\nu > 2\) degrees of freedom, sample mean \(\mu\), and sample standard deviation \(\sigma\):
The scale parameter is \(s = \sigma \sqrt{\frac{\nu - 2}{\nu}}\) such that \(\mathrm{Var}(L) = s^2 \frac{\nu}{\nu - 2} = \sigma^2\).
$$\mathrm{VaR}_\alpha^{\text{stud}} = \mu + s \cdot t_\nu^{-1}(\alpha)$$
$$\mathrm{ES}_\alpha^{\text{stud}} = \mu + s \cdot \left( \frac{g_\nu(t_\nu^{-1}(\alpha))}{1 - \alpha} \cdot \frac{\nu + (t_\nu^{-1}(\alpha))^2}{\nu - 1} \right)$$
where \(t_\nu^{-1}\) is the Student-\(t\) quantile function and \(g_\nu\) is the standard Student-\(t\) density with \(\nu\) degrees of freedom:
$$g_\nu(x) = \frac{\Gamma((\nu+1)/2)}{\sqrt{\pi \nu} \Gamma(\nu/2)} \left(1 + \frac{x^2}{\nu}\right)^{-(\nu+1)/2}$$

### 2.4 Extreme Value Theory: Peaks Over Threshold (POT) and GPD
Given threshold \(u\) and exceedances \(Y_i = L_i - u\) for \(L_i > u\) (\(N_u\) exceedances out of \(T\) total observations):
Under the Pickands-Balkema-de Haan theorem, excess losses follow the Generalized Pareto Distribution (GPD):
$$G_{\xi, \beta}(y) = 1 - \left(1 + \xi \frac{y}{\beta}\right)^{-1/\xi}, \quad \xi \ne 0$$
Parameters \((\xi, \beta)\) are estimated via probability-weighted moments or method of moments.
For \(\alpha > 1 - N_u / T\):
$$\mathrm{VaR}_\alpha^{\text{EVT}} = u + \frac{\beta}{\xi} \left( \left(\frac{T}{N_u}(1 - \alpha)\right)^{-\xi} - 1 \right)$$
$$\mathrm{ES}_\alpha^{\text{EVT}} = \frac{\mathrm{VaR}_\alpha^{\text{EVT}} + \beta - \xi u}{1 - \xi}, \quad \xi < 1$$

### 2.5 Kupiec Proportion of Failures (POF) Likelihood Ratio Test
Given \(x\) exceptions observed over \(T\) out-of-sample periods and nominal failure probability \(p = 1 - \alpha\):
Under the null hypothesis \(H_0: \hat{p} = x / T = p\):
$$LR_{\text{POF}} = -2 \ln \left( \frac{(1 - p)^{T - x} p^x}{(1 - \hat{p})^{T - x} \hat{p}^x} \right)$$
where for \(x = 0\), \((1 - \hat{p})^{T - x} \hat{p}^x \to 1\), giving \(LR_{\text{POF}} = -2 T \ln(1 - p)\).
Under \(H_0\), \(LR_{\text{POF}} \xrightarrow{d} \chi^2(1)\).
The \(p\)-value is \(p_{\text{val}} = \mathrm{erfc}\left(\sqrt{LR_{\text{POF}} / 2}\right)\).
The null hypothesis is rejected at significance level \(0.05\) if \(p_{\text{val}} < 0.05\).

### 2.6 Christoffersen Independence and Conditional Coverage Test
Given binary exception sequence \(I \in \{0, 1\}^T\):
Let \(n_{ij}\) be the number of times state \(i\) is followed by state \(j\) for \(i, j \in \{0, 1\}\).
Transition probabilities under first-order Markov chain:
$$\pi_{01} = \frac{n_{01}}{n_{00} + n_{01}}, \quad \pi_{11} = \frac{n_{11}}{n_{10} + n_{11}}$$
Unconditional exception rate across transitions:
$$\pi = \frac{n_{01} + n_{11}}{n_{00} + n_{01} + n_{10} + n_{11}}$$
The independence likelihood ratio statistic is:
$$LR_{\text{ind}} = -2 \ln \left( \frac{(1 - \pi)^{n_{00} + n_{10}} \pi^{n_{01} + n_{11}}}{(1 - \pi_{01})^{n_{00}} \pi_{01}^{n_{01}} (1 - \pi_{11})^{n_{10}} \pi_{11}^{n_{11}}} \right)$$
Under \(H_0\) (independence), \(LR_{\text{ind}} \xrightarrow{d} \chi^2(1)\).
The joint conditional coverage statistic is:
$$LR_{\text{cc}} = LR_{\text{POF}} + LR_{\text{ind}} \xrightarrow{d} \chi^2(2)$$
with \(p\)-value \(p_{\text{cc}} = \exp(-LR_{\text{cc}} / 2)\).

### 2.7 Stress Scenario Engine
Given asset capital weights \(w \in \mathbb{R}^N\) with \(\sum_{i=1}^N w_i = 1\), initial portfolio dollar value \(V_0 > 0\), and fractional asset price shocks \(\mathbf{s} \in \mathbb{R}^N\):
The portfolio dollar P&L is:
$$\Delta V = V_0 \sum_{i=1}^N w_i s_i$$
and the post-stress portfolio value is \(V_{\text{stress}} = V_0 + \Delta V\).

### 2.8 Copula Simulation and Tail Dependence Metrics
Given a correlation matrix \(\Sigma \in \mathbb{R}^{2 \times 2}\), generate \(M\) draws from a bivariate Gaussian copula:
$$U_1 = \Phi(Z_1), \quad U_2 = \Phi(Z_2), \quad (Z_1, Z_2)^\top \sim \mathcal{N}(0, \Sigma)$$
Compute:
1. Joint exceedance probability at quantile \(q \in (0, 1)\):
   $$\hat{P}_{\text{joint}} = \frac{1}{M} \sum_{m=1}^M \mathbf{1}_{\{U_{1, m} > q \text{ and } U_{2, m} > q\}}$$
2. Empirical upper tail dependence proxy:
   $$\hat{\lambda}_q = \frac{\hat{P}_{\text{joint}}}{1 - q}$$
