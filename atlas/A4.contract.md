**Depends on:** Python 3.14 and the standard library only (`math`, `statistics`). Consumes in-memory sequences of floats.
**Consumed by:** subsequent time-series and volatility evaluation pipelines across Part S and Part PR.

## Overview

Milestone A4 delivers pure-Python estimators and loss functions for univariate volatility and time-series econometrics:
1. GARCH(1,1) conditional variance recursion, Gaussian log-likelihood, and quasi-maximum likelihood estimator.
2. Heterogeneous Autoregressive (HAR) design matrix generation, OLS estimation, and one-step rolling forecasts.
3. Robust and standardized loss evaluations: QLIKE and MSE.
4. ARMA(1,1) conditional sum-of-squares fitting and Kalman local-level filtering.

Every function validates its inputs and raises `ValueError` with a message that names the violated condition (the grader checks the exception type). No function prints, warns, writes files, or mutates its inputs.

## Error specifications

| Function | Condition | Exception |
|---|---|---|
| `garch11_variance`, `garch11_loglik` | `len(returns) < 2` | `ValueError` |
| `garch11_variance`, `garch11_loglik` | `omega <= 0` | `ValueError` |
| `garch11_variance`, `garch11_loglik` | `alpha < 0` | `ValueError` |
| `garch11_variance`, `garch11_loglik` | `beta < 0` | `ValueError` |
| `garch11_fit` | `len(returns) < 50` | `ValueError` |
| `garch11_fit` | any non-finite value in `returns` | `ValueError` |
| `har_design`, `har_fit` | `len(rv) < 23` | `ValueError` |
| `har_design`, `har_fit` | any `rv[t] <= 0` | `ValueError` |
| `har_fit` | singular design matrix (e.g. constant series) | `ValueError` |
| `har_forecast` | `t < 22` or `t > len(rv)` | `ValueError` |
| `qlike` | `realized <= 0` or `forecast <= 0` | `ValueError` |
| `kalman_local_level_filter` | `len(y) == 0` | `ValueError` |
| `kalman_local_level_filter` | `sigma_w2 < 0` or `sigma_v2 <= 0` | `ValueError` |
| `arma11_fit` | `len(x) < 30` | `ValueError` |
