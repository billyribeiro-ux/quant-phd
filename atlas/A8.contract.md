# Atlas A8 — research-integrity module (`atlas.integrity`)

**Delivered in:** S7 · Research Integrity & Multiple Testing
**Status:** frozen once S7 is released. A breaking change goes through
`CONTRACT_CHANGE_REQUESTS` (BUILDER_RULES §5.5).
**Depends on:** NumPy 2.2 and the Python standard library only. A8 consumes
no earlier milestone API, so it can be built and graded before A1–A7 exist.
**Consumed by:** A9 (QR2, backtester), which must call `integrity_report` on
every backtest result it returns; A17 (QR3, ML pipeline).

Every function validates its inputs and raises `ValueError` with a message that
names the violated condition. No function prints, warns, or mutates its inputs.
"Per period" means the sampling frequency of the input; nothing is annualized
unless a function says so.

## Conventions

| Quantity | Definition |
|---|---|
| Series input | One-dimensional and finite, with at least 2 observations; anything else raises `ValueError`. |
| Zero variance | A series or column has zero variance when all its values are equal (`x.max() == x.min()`, the test `np.ptp(x) == 0` without its overflow). Test that, not `std(x) == 0`: a constant non-dyadic series such as 250 copies of `1e-4` has a tiny nonzero floating-point standard deviation. |
| Scale | Every statistic is invariant to multiplying a series, or a column of a matrix, by a positive constant. Multiplying every return (or every return of one column) by a power of two `2**k` leaves every output unchanged, as long as the scaled values are exact (none overflows or falls below `2**-1022`), and no function warns, overflows or underflows at any magnitude: compute moments on the series rescaled by the power of two that brings its largest absolute value into `[0.5, 1)` (`np.frexp`, `np.ldexp`). This applies to every series whose moments are computed: each series, each column, each bootstrap resample `d*_k` and each CSCV subsample, each rescaled by its own power of two (rescaling a column once does not protect a resample of its tiny values). |
| Scalars | Scalar arguments may be Python or NumPy numbers; convert them with `float()` before arithmetic, so a NumPy scalar cannot raise an overflow warning. An integer argument (`n_obs`, `n_trials`, `n_boot`, `n_blocks`, `selected`, `periods_per_year`, `seed`) is a Python or NumPy integer, or a Python or NumPy float with an integral value, of magnitude below `2**1000` (`seed` also non-negative); anything else, including `inf`, `nan` and larger values, raises `ValueError`. `TrialSet.from_backtest` applies the same rule to `result.selected` and `result.periods_per_year`. |
| Sharpe ratio of a series `r` (length `T ≥ 2`) | `mean(r) / std(r, ddof=1)`, per period. Zero variance raises `ValueError`. |
| Skewness `γ3` | `m3 / m2**1.5`, with `m_k = mean((r - mean(r))**k)` (moment estimators, no small-sample correction). Zero variance raises `ValueError`. |
| Kurtosis `γ4` | `m4 / m2**2` (not excess: 3 for a normal). Zero variance raises `ValueError`. |
| `Φ`, `Φ⁻¹` | standard normal CDF and quantile (`statistics.NormalDist()`) |
| Euler–Mascheroni constant | `EULER_MASCHERONI = 0.5772156649015329` |

## Functions

```python
EULER_MASCHERONI: float

def sharpe_ratio(returns: ArrayLike) -> float
def sample_skewness(returns: ArrayLike) -> float
def sample_kurtosis(returns: ArrayLike) -> float

def sharpe_ratio_std(sharpe: float, n_obs: int, skewness: float, kurtosis: float) -> float
    # sqrt((1 - skewness*sharpe + (kurtosis - 1)/4 * sharpe**2) / (n_obs - 1))
    # n_obs >= 2 and finite arguments; raises ValueError if the bracket is not positive or overflows.

def probabilistic_sharpe_ratio(returns: ArrayLike, sr_benchmark: float = 0.0) -> float
    # Φ((SR - sr_benchmark) / sharpe_ratio_std(SR, T, γ3, γ4)), all estimated from `returns`; sr_benchmark finite.

def expected_max_sharpe(n_trials: int, sr_variance: float, sr_mean: float = 0.0) -> float
    # sr_mean + sqrt(sr_variance) * ((1-γ) Φ⁻¹(1 - 1/N) + γ Φ⁻¹(1 - 1/(N e))) for N >= 2;
    # N == 1 returns sr_mean. sr_variance finite and >= 0; sr_mean finite. N may be any positive integer below 2**1000:
    # evaluate Φ⁻¹(1 - p) as -Φ⁻¹(p), since 1 - 1/N rounds to 1 once N exceeds 2**53.

def deflated_sharpe_ratio(returns: ArrayLike, trial_sharpes: ArrayLike, n_trials: int | None = None) -> float
    # PSR(returns, SR0) with SR0 = expected_max_sharpe(N, var(trial_sharpes, ddof=1), 0.0),
    # N = n_trials if given, else len(trial_sharpes). Needs finite trial_sharpes, len(trial_sharpes) >= 2 and N >= 1;
    # a variance beyond the largest float raises ValueError.

def benjamini_hochberg(pvalues: ArrayLike, q: float) -> NDArray[np.bool_]
    # Step-up: reject the k* smallest p-values, k* = max{k : p_(k) <= k q / m} (0 if none).
    # Returns a boolean mask aligned with the input order. Ties are handled by the definition.
    # Empty input returns an empty mask. pvalues must be one-dimensional with values in [0, 1]; 0 < q < 1.

def stationary_bootstrap_indices(n_obs: int, mean_block: float, rng: np.random.Generator) -> NDArray[np.intp]
    # One stationary-bootstrap resample of time indices 0..n_obs-1 (Politis–Romano):
    # start at a uniform index; at each later step, with probability 1/mean_block start a new block
    # at a uniform index, otherwise move to (previous + 1) mod n_obs. n_obs is a positive integer and
    # mean_block a finite number >= 1.

def stepdown_rejections(t_obs: ArrayLike, t_boot: ArrayLike, alpha: float) -> NDArray[np.bool_]
    # Romano–Wolf step-down given observed statistics t_obs (K,) and centred bootstrap statistics
    # t_boot (B, K). Active set A = all hypotheses. Repeat: c = the ceil((1-alpha) B)-th smallest of
    # max_{k in A} t_boot[b, k] over b; reject every k in A with t_obs[k] > c; remove them from A;
    # stop when a step rejects nothing or A is empty. Needs 0 < alpha < 1, B >= 1 and finite statistics.

def romano_wolf(differentials: ArrayLike, alpha: float = 0.05, n_boot: int = 1000,
                mean_block: float = 10.0, seed: int = 0) -> NDArray[np.bool_]
    # differentials: (T, K) per-period performance of K strategies relative to a benchmark.
    # H0_k: E[d_k] <= 0. Studentized statistics t_k = mean(d_k) / (std(d_k, ddof=1) / sqrt(T)).
    # Draw b = 1, ..., n_boot in order: idx_b = stationary_bootstrap_indices(T, mean_block, rng), all from the
    # single rng = np.random.default_rng(seed). Resample whole rows (time periods) jointly across the K columns,
    # d* = d[idx_b]; t*_bk = (mean(d*_k) - mean(d_k)) / (std(d*_k, ddof=1) / sqrt(T)); in a draw where the
    # resampled column d*_k is constant (all values equal), use std(d_k, ddof=1) instead. A constant column of
    # d raises ValueError; so do n_boot < 1 and alpha outside (0, 1). A t*_bk too large for a float is ±inf, which
    # ranks above (below) every finite statistic exactly as its true value would; apply the step-down loop of
    # stepdown_rejections to (t, t*, alpha) without its finiteness check, which guards only direct callers.

@dataclass(frozen=True)
class PBOResult:
    pbo: float                 # share of combinations with logit <= 0
    logits: NDArray[np.float64]  # one per combination, in itertools.combinations(range(S), S // 2) order
    n_combinations: int

def probability_of_backtest_overfitting(performance: ArrayLike, n_blocks: int = 16) -> PBOResult
    # CSCV (Bailey, Borwein, López de Prado & Zhu). performance: (T, N) per-period returns of N
    # trials, N >= 2. n_blocks S is even, 2 <= S <= T. If T is not divisible by S, the first T mod S
    # rows (oldest) are dropped. Each half-sample needs at least 2 periods, (T - T mod S) / 2 >= 2. Blocks are consecutive. For each combination c of S/2 blocks (IS),
    # the complement is OOS; both keep time order. Metric = per-column Sharpe ratio on the subsample
    # (on a constant subsample, all values equal: 0.0 if its value is 0, ±inf by its sign otherwise). n* = argmax IS metric (lowest index on
    # ties). OOS rank of n* = 1 + #{strategies with lower OOS metric} + 0.5 * #{others with equal OOS
    # metric}. ω = rank / (N + 1); logit = ln(ω / (1 - ω)).

@dataclass(frozen=True)
class TrialSet:
    returns: NDArray[np.float64]   # (T, N) per-period excess returns of every trial run
    selected: int                  # column of the strategy being proposed
    periods_per_year: int

    @classmethod
    def from_backtest(cls, result: BacktestLike) -> TrialSet
    # BacktestLike: any object with attributes trial_returns (T, N), selected (int), periods_per_year (int).

@dataclass(frozen=True)
class IntegrityReport:
    n_trials: int
    selected_sharpe: float                # per period
    selected_sharpe_annualized: float     # selected_sharpe * sqrt(periods_per_year)
    psr: float                            # probabilistic_sharpe_ratio(selected, 0.0)
    expected_max_sharpe: float            # SR0 used by the DSR (per period)
    dsr: float                            # deflated_sharpe_ratio(selected, all trial Sharpe ratios)
    pbo: float                            # probability_of_backtest_overfitting(returns, n_blocks).pbo
    bh_rejections: NDArray[np.bool_]      # benjamini_hochberg(one-sided p-values, q)
    romano_wolf_rejections: NDArray[np.bool_]  # romano_wolf(returns, alpha, n_boot, mean_block, seed)

def integrity_report(trials: TrialSet, *, alpha: float = 0.05, q: float = 0.05, n_blocks: int = 16,
                     n_boot: int = 1000, mean_block: float = 10.0, seed: int = 0) -> IntegrityReport
    # One-sided p-value of trial n: 1 - Φ(mean / (std(ddof=1) / sqrt(T))) for H0: mean <= 0.
    # n_blocks is reduced to the largest even number <= min(n_blocks, T). Needs T >= 4, so that each CSCV
    # half-sample has at least 2 periods; a shorter trial set raises ValueError. A constant trial raises
    # ValueError (its Sharpe ratio is undefined).
```

## Acceptance

The S7 autograder (`course/modules/S/S7/grader/test_project.py`) is the
acceptance suite for A8. It runs identically in the browser (Pyodide) and
locally (`QF_SEED=<seed> pytest -q -p no:cacheprovider --assert=plain -W error test_project.py`, with

reference implementation passes it on seeds 0–49, and every wrong solution in `ledgers/S7/mutants/`
