## Input: the dataset mapping

```python
Dataset = Mapping[str, Any]
# dataset["name"]:       str                        label used in the report only
# dataset["date"]:       Sequence[str]              one ISO calendar date "YYYY-MM-DD" per row, strictly increasing
# dataset["price"]:      Sequence[float | None]     one value per row; None or NaN is a gap
# dataset["split_ratio"]: Sequence[float]           optional; the share-count ratio of a corporate action at that
#                                                   row (2.0 for a 2-for-1 split, 1.0 for none). Default: all 1.0.
# Extra keys are ignored.
```

A mapping without `"name"`, `"date"` or `"price"`, whose sequences differ in length, whose dates do not parse with
`datetime.date.fromisoformat` or are not strictly increasing, whose present price is not a finite number greater than
zero, or whose `split_ratio` (when given) is not a finite number greater than zero, raises `ValueError`. A dataset with
no rows raises `ValueError`. Infinities raise `ValueError`.

## The profiler

```python
def profile(
    dataset: Dataset,
    *,
    stale_run: int = 5,
    outlier_k: float = 5.0,
    break_log: float = 0.25,
) -> dict[str, Any]
```

Parameters (proposed by the architect's assistant, architect to confirm; the defaults are design choices of this
contract, not published thresholds, and no source is cited for them):

| Parameter | Constraint | Meaning |
|---|---|---|
| `stale_run` | integer >= 2 | minimum number of consecutive rows with the same present price to flag a stale run |
| `outlier_k` | float > 0 | outlier if the return differs from the median of the non-break returns by more than `outlier_k` times their MAD |
| `break_log` | float > 0 | a corporate-action break if the split-adjusted absolute log return exceeds this value |

Rules the report applies (all proposed by the architect's assistant, architect to confirm):

1. **Gap.** A row whose price is None or NaN.
2. **Return.** For consecutive rows t-1 and t that both have a price, the raw log return is `ln(price_t / price_{t-1})`
   and the split-adjusted log return is `r_t = ln(price_t / price_{t-1}) + ln(split_ratio_t)`. No return is computed
   across a gap.
3. **Corporate-action break.** Row t is a break when `|r_t| > break_log`. A split that the source reports in
   `split_ratio` explains the price step and is not a break. A split with no ratio, or any other unexplained step, is a
   break. A break is never also reported as an outlier.
4. **Outlier.** Among the returns that are not breaks, let `m` be their median and `d` their MAD (median of
   `|r - m|`). Row t is an outlier when `|r_t - m| > outlier_k * d`. If `d` is zero while an outlier test is needed,
   `profile` raises `ValueError` naming the zero scale; it does not guess a scale.
5. **Stale run.** A maximal run of consecutive rows with the same present price, of length at least `stale_run`. A gap
   row ends a run.

## Output

```python
# {
#   "name": str,
#   "rows": int,                                 number of rows in the dataset
#   "gaps": list[int],                           row indices, ascending
#   "stale_runs": list[tuple[int, int]],         (first_row, last_row) inclusive, ascending
#   "corporate_action_breaks": list[int],        row t: a break between t-1 and t, ascending
#   "outliers": list[int],                       row t: an outlier return into t, ascending
# }
```

Row indices are zero-based positions in the input sequences. Every list is sorted ascending and contains no duplicates.
Keys are always present, with an empty list when nothing is flagged. Keys not listed here are not part of the contract.

A dataset in which no return exists (fewer than two rows with a price, or every consecutive pair has a gap) raises
`ValueError`, because there is nothing to profile for breaks or outliers.

## Units and conventions

| Quantity | Unit or definition |
|---|---|
| `price` | float, in the dataset's own currency or index unit. Never converted, never rescaled (A15 does the same for currency). |
| `split_ratio` | dimensionless multiplier |
| returns and `break_log` | natural logarithm, dimensionless |
| `outlier_k` | dimensionless multiple of the MAD |
| `date` | ISO calendar date in the dataset's own calendar; no time zone |
| money | The report carries no money amount. If a later field carries a money amount it is an integer number of cents (i64 rule in the user's global instructions). |

**The calendar is the dataset's rows.** A calendar date that a dataset does not contain (for example a market holiday
absent from `fx_daily`, `tools/data_sources.yaml` lines 28-30) is not a row and therefore not a gap. The profiler can
only see missing prices that appear as rows. This limit is stated on the S0 pages.

**Corporate actions.** The curriculum's milestone text says "splits" and the project brief says "corporate-action
breaks" (`atlas/A3`: `curriculum/meta.yaml` line 210 and `curriculum/01-foundations.yaml` line 614). This contract
flags both through one rule: a split reported in `split_ratio` is explained, and any other large step is a break. A
dividend or other action with no ratio is reported as a break.

## Data for the module (not part of the code contract)

The labs and the autograder use generated datasets labelled **SIMULATED**, so that every instance is valid and instances
differ across seeds. No cleared equity price series exists in the repository (`tools/data_sources.yaml` lists only
`fx_daily`, `fx_monthly` and `ust_daily`; the two `rejected` entries are the French library and Open Source Asset Pricing).
Therefore the split-adjustment labs are SIMULATED, with an honest-pending note for real equity data.

The stretch rung may run the profiler on the cleared `fx_daily.csv` and `ust_daily.csv` snapshots. Those carry no
`split_ratio`, so the profiler applies to them only through the `price` column and their own rows.
