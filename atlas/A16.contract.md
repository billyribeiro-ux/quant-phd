## 1. Free Cash Flow to the Firm (FCFF)

Free cash flow to the firm represents cash generated by operating activities available to all capital providers (equity and debt) after paying operating expenses, corporate taxes, and meeting necessary investments in working capital and fixed capital:

$$\text{NOPAT} = \text{EBIT} \cdot (1 - \tau_c)$$
$$\text{FCFF} = \text{NOPAT} + \text{D\&A} - \text{CapEx} - \Delta\text{NWC}$$

```python
def calculate_fcff(
    ebit: float | np.ndarray,
    tax_rate: float,
    depreciation: float | np.ndarray,
    capex: float | np.ndarray,
    delta_nwc: float | np.ndarray,
) -> float | np.ndarray:
    """Calculate Free Cash Flow to the Firm (FCFF).

    Parameters:
        ebit: Earnings before interest and taxes (operating income).
        tax_rate: Marginal corporate income tax rate, 0 <= tax_rate < 1.
        depreciation: Depreciation and amortization expense (>= 0).
        capex: Capital expenditures (>= 0).
        delta_nwc: Change in net operating working capital (NWC_t - NWC_{t-1}).

    Returns:
        FCFF = EBIT * (1 - tax_rate) + depreciation - capex - delta_nwc.
    """
```

Validation:
- `tax_rate < 0` or `tax_rate >= 1` raises `ValueError`.
- Negative `depreciation` or negative `capex` raises `ValueError`.
- Mismatched array lengths raise `ValueError`.

## 2. Discounted Cash Flow (DCF) Enterprise Value

The operating enterprise value ($EV$) is the sum of the present value of explicit forecast FCFF and the present value of the terminal value ($TV_H$):

$$EV = \sum_{t=1}^H \frac{\text{FCFF}_t}{(1 + WACC)^t} + \frac{TV_H}{(1 + WACC)^H}$$

When `mid_year=True`, cash flows are assumed to arrive evenly throughout the period, discounting by $(1 + WACC)^{t - 0.5}$:

$$PV(\text{FCFF}_t) = \frac{\text{FCFF}_t}{(1 + WACC)^{t - 0.5}}$$

### Terminal value methods:
1. **Gordon growth model (`terminal_method="gordon"`)**:
   $$TV_H = \frac{\text{FCFF}_H \cdot (1 + g)}{WACC - g}$$
   Or value-driver formulation when `terminal_roic` is supplied:
   $$TV_H = \frac{\text{NOPAT}_{H+1} \cdot (1 - g / \text{RONIC})}{WACC - g}$$
   where $g < WACC$. If $g \ge WACC$, raises `ValueError`.
2. **Exit multiple method (`terminal_method="exit_multiple"`)**:
   $$TV_H = \text{EBITDA}_H \cdot M_{\text{exit}}$$
   where $M_{\text{exit}} > 0$.

```python
def dcf_enterprise_value(
    fcff_forecast: Sequence[float] | np.ndarray,
    wacc: float,
    terminal_method: str = "gordon",
    terminal_growth: float | None = None,
    exit_multiple: float | None = None,
    terminal_metric: float | None = None,
    mid_year: bool = False,
) -> dict[str, Any]:
    """Discount explicit FCFF forecast and terminal value to determine Enterprise Value.

    Returns dict with keys:
        - "pv_explicit": float (sum of discounted explicit cash flows)
        - "terminal_value": float (nominal TV at horizon H)
        - "pv_terminal": float (discounted TV)
        - "enterprise_value": float (pv_explicit + pv_terminal)
        - "tv_share": float (pv_terminal / enterprise_value)
    """
```

## 3. Enterprise-to-Equity Bridge

Reconciles operating enterprise value ($EV$) to common equity value ($E$) and diluted equity value per share:

$$E = EV - \text{Total Debt} + \text{Cash} - \text{Minority Interest} - \text{Preferred Stock} + \text{Non-Operating Assets}$$
$$P = \frac{E}{N_{\text{diluted}}}$$

```python
def enterprise_to_equity_bridge(
    enterprise_value: float,
    total_debt: float,
    cash: float,
    minority_interest: float = 0.0,
    preferred_stock: float = 0.0,
    non_operating_assets: float = 0.0,
    shares_outstanding: float = 1.0,
) -> dict[str, float]:
    """Reconcile enterprise value to common equity value and per-share price.

    Returns dict with keys:
        - "net_debt": float (total_debt - cash)
        - "equity_value": float
        - "per_share_value": float (equity_value / shares_outstanding)
    """
```

Validation:
- Negative `total_debt`, `cash`, `minority_interest`, `preferred_stock`, `non_operating_assets` raises `ValueError`.
- `shares_outstanding <= 0` raises `ValueError`.

## 4. Ohlson (1995) Residual Income Model

Under clean surplus accounting ($B_t = B_{t-1} + NI_t - D_t$), equity value equals initial book value plus discounted abnormal earnings:

$$RI_t = NI_t - r_e \cdot B_{t-1}$$
$$V_0 = B_0 + \sum_{t=1}^H \frac{RI_t}{(1 + r_e)^t} + \frac{TV_{RI, H}}{(1 + r_e)^H}$$

With Ohlson linear information dynamics $RI_{t+1} = \omega \cdot RI_t$, the terminal residual income value is:

$$TV_{RI, H} = \frac{\omega \cdot RI_H}{1 + r_e - \omega}$$

```python
def residual_income_valuation(
    initial_book_equity: float,
    net_income_forecast: Sequence[float] | np.ndarray,
    dividends_forecast: Sequence[float] | np.ndarray,
    cost_of_equity: float,
    omega: float = 0.0,
) -> dict[str, Any]:
    """Compute equity value via Ohlson residual income model with clean surplus dynamics.

    Parameters:
        initial_book_equity: Book equity at t=0 (B_0 > 0).
        net_income_forecast: Sequence of projected net income values for t=1..H.
        dividends_forecast: Sequence of projected net dividends for t=1..H.
        cost_of_equity: Cost of equity r_e > 0.
        omega: Residual income persistence parameter, 0 <= omega < 1.

    Returns dict with keys:
        - "book_values": list[float] (B_0, B_1, ..., B_H)
        - "residual_income": list[float] (RI_1, ..., RI_H)
        - "pv_residual_income": float
        - "terminal_residual_income": float
        - "pv_terminal_residual_income": float
        - "equity_value": float (B_0 + pv_residual_income + pv_terminal_residual_income)
    """
```
