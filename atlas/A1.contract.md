## Core module: `atlas.returns`

Prices are positive real numbers in any single currency or index unit. Only ratios of prices are used, so the unit
cancels. Returns are dimensionless: `0.01` means one per cent.

```python
def simple_return(prices: Sequence[float]) -> list[float]
    # r_t = P_t / P_{t-1} - 1 for t = 1 .. n-1. Output length is len(prices) - 1, in input order.

def log_return(prices: Sequence[float]) -> list[float]
    # l_t = ln(P_t / P_{t-1}) (natural logarithm). Output length is len(prices) - 1, in input order.
```

Invariant (stated on the page and tested by the grader): for every t, `log_return(prices)[t] == math.log(1 + simple_return(prices)[t])`
to a relative tolerance of 1e-12.

**Error behaviour** (all `ValueError`):

| Condition | Raised by |
|---|---|
| fewer than two prices | `simple_return`, `log_return` |
| a price that is not finite (NaN or infinity) | `simple_return`, `log_return` |
| a price that is zero or negative | `simple_return`, `log_return` |

A value that is not a real number (for example a string) raises `TypeError` from Python itself; the contract does not
wrap it. Inputs are never mutated; the returned list is new.

## Console entry point: `atlas.cli`

```python
def main(argv: Sequence[str] | None = None) -> int
```

Declared in `pyproject.toml` as `[project.scripts] atlas = "atlas.cli:main"`.

Usage:

```
atlas returns [--log] PRICE PRICE [PRICE ...]
```

- Prints one return per line, formatted with `format(value, ".15g")`. Without `--log` the values are simple returns;
  with `--log` they are log returns.
- Exit codes:

| Code | Meaning |
|---|---|
| 0 | success, and `--help` |
| 1 | a `ValueError` from `atlas.returns`; the message goes to stderr as `atlas: error: <message>` |
| 2 | usage error (argparse default: missing or non-numeric argument, unknown option) |

A bad argument never exits 0.
