## Overview

Milestone A7 delivers the foundational cross-sectional asset pricing engine for Atlas:
1. **Delisting return adjustment (`apply_shumway_delisting`):** compounds valid delisting returns and replaces missing performance-related delisting returns with empirical replacement penalties following Shumway (1997) (-30% for NYSE/AMEX) and Shumway & Sloan (1999) (-55% for NASDAQ).
2. **NYSE breakpoint derivation (`compute_breakpoints`):** computes empirical percentile thresholds on eligible NYSE common stocks (exchange code 1) to eliminate microcap distortion before allocating all exchange-listed securities.
3. **Univariate and bivariate portfolio sorting (`univariate_sort`, `bivariate_sort`):** sorts assets by cross-sectional characteristic signals into quantiles or intersection grids under value-weighting or equal-weighting.
4. **Two-pass Fama–MacBeth cross-sectional regression (`fama_macbeth`):** estimates cross-sectional risk premia with both naive and Shanken (1992) errors-in-variables corrected standard errors.
5. **Gibbons–Ross–Shanken test (`grs_test`):** calculates the exact finite-sample GRS (1989) $F$-statistic and asymptotic $p$-value for the joint hypothesis that all pricing errors (alphas) are zero.

Every function validates its inputs and raises `ValueError` with an informative message when invariants are violated. No function prints, warns, writes files, or mutates its inputs.

## Conventions

| Concept | Definition & Convention |
|---|---|
| Exchange codes | `1 = NYSE`, `2 = AMEX`, `3 = NASDAQ`. Stocks with exchange code 1 define NYSE breakpoints. |
| Performance delisting codes | CRSP delisting codes $500$ or between $520$ and $584$ inclusive signify liquidation, bankruptcy, or failure to meet exchange listing standards. |
| Delisting replacement returns | $-0.30$ ($-30\%$) for NYSE/AMEX (exchange codes 1, 2); $-0.55$ ($-55\%$) for NASDAQ (exchange code 3). Missing non-performance delistings default to $0.0$. |
| Return compounding with delisting | $R_{\text{total}} = (1 + R_{\text{CRSP}}) \times (1 + R_{\text{delist}}) - 1$. |
| Portfolio weighting | Value-weighted: $w_i = \text{ME}_i / \sum_j \text{ME}_j$; Equal-weighted: $w_i = 1 / N_p$. |
| Shanken multiplier | $c = 1 + \bar{\lambda}_f' \Sigma_f^{-1} \bar{\lambda}_f$; $\se_{\text{Shanken}}(\lambda) = \sqrt{c \cdot \se_{\text{naive}}^2(\lambda) + \frac{1}{T} \Sigma_f}$. |
| GRS $F$-statistic | $\text{GRS} = \frac{T - N - K}{N} \left(1 + \bar{f}' \hat{\Sigma}_f^{-1} \bar{f}\right)^{-1} \hat{\alpha}' \hat{\Sigma}_\epsilon^{-1} \hat{\alpha} \sim F(N, T - N - K)$. |

## Error Specifications

| Function | Condition | Exception |
|---|---|---|
| All functions | Non-finite values (`NaN`, `Inf`) in required non-delisting inputs | `ValueError` |
| All functions | Mismatched array lengths or dimensions | `ValueError` |
| `compute_breakpoints` | `n_quantiles < 2` or no valid NYSE stocks when `use_nyse_only=True` | `ValueError` |
| `univariate_sort` | `weighting not in ("value", "equal")` | `ValueError` |
| `bivariate_sort` | `method not in ("independent", "conditional")` or invalid `weighting` | `ValueError` |
| `fama_macbeth` | Insufficient cross-sectional assets ($N \le K + 1$) or periods ($T < 3$) | `ValueError` |
| `grs_test` | Degrees of freedom non-positive ($T - N - K \le 0$) or singular covariance | `ValueError` |
