51: In this model, when a member of a central counterparty defaults, its loss is paid from a fixed sequence of resources, and the sequence decides who bears the loss first. This lesson defines that sequence as the CCP default waterfall and proves that its layers pay the loss exactly, with any part no layer covers named. It then defines the margin cover level, the share of scenario losses that the defaulter's margin pays in full, and proves that the smallest margin reaching a target cover is the k-th smallest scenario loss, for a k that the target fixes. Lab 1 computes both cases in integer cents and checks each sizing answer by brute force.
53: 1The waterfall for one default
55: Three resources pay a loss in this lesson, and the default funds of the surviving members pay what remains after them. The initial margin of a member is the collateral it posts to the CCP against its positions. The default fund of a member is its contribution to a pool held for defaults. The CCP capital is the clearing house's own equity committed to losses. The defaulter is the member that defaults, and a surviving member is any other member. Each loss is one input: the lesson takes the loss \(L\) as given and does not model how it arises from closing out the defaulter's positions or from netting. Section 3 names the close-out part of that limit.
58: Assumptions A1 and A2 (the layer order and the inputs)
60: A1 (layer order). A loss is paid from the layers of Definition 1.1, in that order. The order is a rule of this model. The lesson does not claim that any clearing house uses it.
61: A2 (inputs). One member \(\delta\) defaults. The loss \(L\), the initial margin \(\mathrm{IM}_i\) and the default fund \(\mathrm{DF}_i\) of each member \(i\), and the CCP capital \(K\) are non-negative integers in cents.
66: Definition 1.1 (CCP default waterfall)
67: Under A1 and A2, let \(\mathcal{V}\) be the set of surviving members, and let \(D = \sum_{i \in \mathcal{V}} \mathrm{DF}_i\) be their total default fund. The CCP default waterfall pays the loss \(L\) through three layers, in this order:
69: the defaulter's initial margin pays \(a_1 = \min(L, \mathrm{IM}_\delta)\);
70: the defaulter's default fund pays \(a_2 = \min(L - a_1, \mathrm{DF}_\delta)\);
71: the CCP capital pays \(a_3 = \min(L - a_1 - a_2, K)\).
73: The residual is \(Z = L - a_1 - a_2 - a_3\). If \(Z \ge D\), each surviving member \(i\) pays \(\mathrm{DF}_i\) and the uncovered loss is \(u = Z - D\). If \(Z < D\), each surviving member pays \(x_i = \lfloor Z\,\mathrm{DF}_i / D \rfloor\), and the leftover \(\ell = Z - \sum_{i \in \mathcal{V}} x_i\) goes one cent each to the first \(\ell\) surviving members, in ascending member id, that have \(\mathrm{DF}_i > 0\). Then \(u = 0\). A member with \(\mathrm{DF}_i = 0\) pays nothing.
77: Proposition 1.2 (conservation)
78: Assuming A1 and A2, for every loss \(L \ge 0\), the layers and the survivor payments add to the loss:
79: \[ a_1 + a_2 + a_3 + \sum_{i \in \mathcal{V}} x_i + u = L, \]
80: where \(x_i\) and \(u\) are the survivor payments and the uncovered loss of Definition 1.1, and \(x_i\) is taken to be \(\mathrm{DF}_i\) in the case \(Z \ge D\).
84: Proof
85: Each minimum is at most its own remaining argument. So \(a_1 \le L\), \(a_2 \le L - a_1\) and \(a_3 \le L - a_1 - a_2\), and \(Z \ge 0\). Case \(Z \ge D\): the survivors pay \(D\) in total, so the sum is \(a_1 + a_2 + a_3 + D + (Z - D) = a_1 + a_2 + a_3 + Z = L\). Case \(Z < D\): the survivors pay \(\sum_i x_i + \ell\), and \(\sum_i x_i + \ell = Z\) by the definition of \(\ell\), with \(u = 0\). So the sum is \(a_1 + a_2 + a_3 + Z = L\). The second case needs \(\ell\) to be a non-negative integer that the surviving members with a positive default fund can absorb, which Proposition 1.3 establishes. \(\blacksquare\)
89: Proposition 1.3 (the survivor rule is well defined)
90: Assuming A1 and A2, suppose \(0 \le Z < D\). Let \(n^{+}\) be the number of surviving members with \(\mathrm{DF}_i > 0\). Then \(D > 0\), \(0 \le \ell \le n^{+} - 1\), and every survivor's payment satisfies \(x_i \le \mathrm{DF}_i\), and \(x_i + 1 \le \mathrm{DF}_i\) for every survivor with \(\mathrm{DF}_i > 0\) that receives a leftover cent.
94: Proof
95: Since \(Z \ge 0\) and \(Z < D\), we have \(D > 0\). Write \(p_i = Z\,\mathrm{DF}_i / D\), so \(\sum_i p_i = Z\) and \(x_i = \lfloor p_i \rfloor\). Then \(\ell = \sum_i (p_i - \lfloor p_i \rfloor)\), a sum of fractional parts. Each fractional part is non-negative, so \(\ell \ge 0\). A survivor with \(\mathrm{DF}_i = 0\) has \(p_i = 0\) and fractional part 0. Each other fractional part is strictly less than 1, so \(\ell < n^{+}\), and \(\ell\) is an integer, so \(\ell \le n^{+} - 1\). Hence the first \(\ell\) survivors with a positive default fund exist. Next, \(Z < D\) gives \(p_i < \mathrm{DF}_i\). Since \(\mathrm{DF}_i\) is an integer and \(x_i \le p_i\), we get \(x_i \le \mathrm{DF}_i - 1\) whenever \(\mathrm{DF}_i > 0\), so \(x_i + 1 \le \mathrm{DF}_i\). \(\blacksquare\)
99: Remark 1.4 (each layer waits for the one before it)
100: Under Definition 1.1, a layer pays only after the layer before it is used in full. Precisely: \(a_2 > 0\) implies \(a_1 = \mathrm{IM}_\delta\); \(a_3 > 0\) implies \(a_2 = \mathrm{DF}_\delta\); and \(Z > 0\) implies \(a_3 = K\). Proof: \(a_2 > 0\) gives \(L - a_1 > 0\), so \(a_1 < L\), and \(a_1 = \min(L, \mathrm{IM}_\delta) < L\) forces \(a_1 = \mathrm{IM}_\delta\). The other two follow the same way, using \(L - a_1 - a_2 > 0\) and \(L - a_1 - a_2 - a_3 > 0\).
104: Example 1.5 (the fixture of Lab 1, Part A1)
105: Let the defaulter be member 3, with \(\mathrm{IM}_3 = 100\), \(\mathrm{DF}_3 = 50\) and \(K = 30\). The survivors are members 1 and 2, with \(\mathrm{DF}_1 = 40\) and \(\mathrm{DF}_2 = 60\), so \(D = 100\). For \(L = 200\): \(a_1 = 100\), \(a_2 = \min(100, 50) = 50\), \(a_3 = \min(50, 30) = 30\), and \(Z = 200 - 180 = 20 < 100\). 125: Let the defaulter be member 4 with no margin and no default fund, the CCP capital be 0, and the survivors be members 1, 2 and 3, each with \(\mathrm{DF} = 1\). Then \(D = 3\). 128: 2Margin cover and the sizing rule
130: The next definition takes the defaulter's initial margin as a single number \(M\) and asks how many scenario losses it pays in full. By Remark 2.2, that is the case where the margin alone pays the loss in the waterfall of Section 1.
133: Definition 2.1 (margin cover level)
134: Let a scenario set consist of \(S\) losses \(L_1, \dots, L_S\), each a non-negative integer in cents, with \(S \ge 1\). For an integer margin \(M\) in cents, let \(c(M) = \#\{s : L_s \le M\}\) be the number of scenarios whose loss the margin covers in full. The margin cover level in basis points is \(\mathrm{cover}(M) = \lfloor 10000\,c(M) / S \rfloor\). Its basis is the count of scenarios in the set, floored to a whole basis point. It is not a dollar-weighted share and not an expected value.
138: Remark 2.2 (the margin alone pays the loss)
139: Let a loss \(L\) and the defaulter's initial margin \(\mathrm{IM}_\delta = M\) enter Definition 1.1. Then \(a_1 = \min(L, M)\) equals \(L\) if and only if \(L \le M\). So a loss is covered in full by the margin alone exactly when it is counted in \(c(M)\) of Definition 2.1. A loss equal to the margin is counted, because \(L = M\) satisfies \(L \le M\).
143: Assumptions A3 and A4 (the target and the scenario set)
145: A3 (target). The target cover \(t\) is an integer in basis points with \(1 \le t \le 10000\).
146: A4 (scenario set). The scenario set is non-empty, with \(S \ge 1\) losses that are non-negative integers in cents.
151: Proposition 2.3 (the sized margin is an order statistic)
152: Assuming A3 and A4, sort the losses as \(L_{(1)} \le L_{(2)} \le \dots \le L_{(S)}\), with repetitions kept, and let \(k = \lceil t\,S / 10000 \rceil\). Then:
154: \(1 \le k \le S\);
155: for every integer margin \(M\), \(\mathrm{cover}(M) \ge t\) if and only if \(M \ge L_{(k)}\);
156: the smallest integer margin with cover at least \(t\) is \(L_{(k)}\).
161: Proof
162: Part 1. Since \(t \ge 1\), \(tS / 10000 > 0\), so \(k \ge 1\). Since \(t \le 10000\), \(tS / 10000 \le S\), and \(S\) is an integer, so \(k \le S\).
163: Part 2. For an integer \(t\) and a real number \(y\), \(\lfloor y \rfloor \ge t\) if and only if \(y \ge t\). Applying this with \(y = 10000\,c(M) / S\): \(\mathrm{cover}(M) \ge t\) if and only if \(10000\,c(M) \ge tS\), that is \(c(M) \ge tS / 10000\). Since \(c(M)\) is an integer, \(c(M) \ge tS / 10000\) holds if and only if \(c(M) \ge k\). It remains to show that \(c(M) \ge k\) if and only if \(M \ge L_{(k)}\). If \(M \ge L_{(k)}\), then \(L_{(1)}, \dots, L_{(k)}\) are all at most \(M\), so \(c(M) \ge k\). If \(M < L_{(k)}\), then \(L_{(j)} > M\) for every \(j \ge k\), so at most the \(k - 1\) losses \(L_{(1)}, \dots, L_{(k-1)}\) are at most \(M\), and \(c(M) \le k - 1\).
164: Part 3. By Part 2, the integer margin \(L_{(k)}\) has cover at least \(t\), and every integer margin with cover at least \(t\) is at least \(L_{(k)}\). \(L_{(k)}\) is a non-negative integer, so it is the smallest. \(\blacksquare\)
168: Corollary 2.4 (the sized margin rises with the target)
169: Assuming A3 and A4, let \(t \le t'\) be two targets, with sized margins \(M(t)\) and \(M(t')\) given by Proposition 2.3. Then \(M(t) \le M(t')\).
173: Proof
174: Since \(t \le t'\), \(tS/10000 \le t'S/10000\). The ceiling function does not decrease, so \(k \le k'\). The sorted losses do not decrease with the index, so \(L_{(k)} \le L_{(k')}\). Proposition 2.3 gives \(M(t) = L_{(k)}\) and \(M(t') = L_{(k')}\). \(\blacksquare\)
178: Example 2.5 (two targets with 200 scenarios)
179: Let \(S = 200\). For \(t = 9900\), \(tS / 10000 = 198\) exactly, so \(k = 198\). For \(t = 9975\), \(tS / 10000 = 199.5\), so \(k = 200\), and the sized margin is the largest loss. Lab 1, Part B draws 200 seeded scenario losses and prints both sized margins, 2961 cents and 2992 cents, and the brute-force minimum agrees with each.
183: Remark 2.6 (what the cover does not count)
184: The cover of Definition 2.1 counts scenarios that the margin pays in full. It does not count scenarios that the default fund or the CCP capital pays. A scenario with loss above the margin is uncovered in this sense even when the waterfall pays all of it.

198: """
200: from __future__ import annotations
202: import random
203: from dataclasses import dataclass
205: SEED = 2026
206: MEMBERS = (1, 2, 3, 4)
207: DEFAULTER = 3

209: SCENARIOS = 200

213: @dataclass(frozen=True)
214: class Waterfall:
215: """The payments for one loss, in cents, by layer.
217: margin_cents, default_fund_cents and ccp_capital_cents are the three layers a1, a2 and a3 of Definition 1.1.
218: survivor_cents maps each surviving member id to its payment from its default fund. uncovered_cents is the
219: part of the loss that no layer pays.
220: """
222: margin_cents: int
223: default_fund_cents: int
224: ccp_capital_cents: int
225: survivor_cents: dict[int, int]
226: uncovered_cents: int
228: def total_cents(self) -> int:
229: """All payments for the loss, in cents. Proposition 1.2 says this equals the loss."""
230: return (
231: self.margin_cents
232: + self.default_fund_cents
233: + self.ccp_capital_cents
234: + sum(self.survivor_cents.values())
235: + self.uncovered_cents
236: )
239: def survivor_payments(
240: residual_cents: int, df_cents: dict[int, int], survivors: list[int]
241: ) -> tuple[dict[int, int], int]:
242: """Split the residual loss over the surviving default funds, in cents.
244: If the residual is at least the total of the survivors' default funds, each survivor pays its whole default
245: fund and the excess is uncovered. Otherwise each survivor pays its floor share of the residual in proportion
246: to its default fund, and the leftover cents go one each to the first survivors, in ascending id order, that
247: have a positive default fund. Returns the payments and the uncovered loss.
248: """
249: total = sum(df_cents[i] for i in survivors)
250: if residual_cents >= total:
251: return {i: df_cents[i] for i in survivors}, residual_cents - total
252: pay = {i: residual_cents * df_cents[i] // total for i in survivors}
253: leftover = residual_cents - sum(pay.values())
254: for i in survivors:
255: if leftover == 0:
256: break
257: if df_cents[i] > 0:
258: pay[i] += 1
259: leftover -= 1
260: if leftover != 0:
261: raise RuntimeError("the leftover cents were not all assigned")
262: return pay, 0
265: def waterfall(
266: loss_cents: int,
267: defaulter: int,
268: im_cents: dict[int, int],
269: df_cents: dict[int, int],
270: capital_cents: int,
271: ) -> Waterfall:
272: """Pay one loss in the layer order of Definition 1.1.
274: The layers are the defaulter's initial margin, then the defaulter's default fund, then the CCP capital, then
275: the surviving default funds. Each layer pays the smaller of the loss left and its own size. Inputs are
276: non-negative integers in cents.
277: """
278: if loss_cents < 0:
279: raise ValueError("loss cannot be negative")
280: margin = min(loss_cents, im_cents[defaulter])
281: fund = min(loss_cents - margin, df_cents[defaulter])
282: capital = min(loss_cents - margin - fund, capital_cents)
283: residual = loss_cents - margin - fund - capital
284: survivors = sorted(i for i in df_cents if i != defaulter)
285: pay, uncovered = survivor_payments(residual, df_cents, survivors)
286: return Waterfall(margin, fund, capital, pay, uncovered)
289: def cover_count(losses_cents: list[int], margin_cents: int) -> int:
290: """Number of scenarios whose loss the margin covers in full, that is the losses with loss <= margin."""
291: return sum(1 for loss in losses_cents if loss <= margin_cents)
294: def cover_bps(losses_cents: list[int], margin_cents: int) -> int:
295: """Margin cover in basis points, floored: 10000 times the covered count, divided by the scenario count."""
296: return 10000 * cover_count(losses_cents, margin_cents) // len(losses_cents)
299: def sized_margin(losses_cents: list[int], target_bps: int) -> tuple[int, int]:
300: """The smallest margin with cover at least target_bps, by the order statistic of Proposition 2.3.
302: Returns the margin in cents and the index k = ceil(target_bps * S / 10000), computed in integers as
303: -((-target_bps * S) // 10000), where S is the scenario count. The margin is the k-th smallest loss.
304: """
305: k = -((-target_bps * len(losses_cents)) // 10000)
306: return sorted(losses_cents)[k - 1], k
309: def brute_force_margin(losses_cents: list[int], target_bps: int) -> int:
310: """The smallest integer margin with cover at least target_bps, found by testing 0, 1, 2 in turn.
312: The search uses no sorting and no formula. The largest loss covers every scenario, so the search always ends
313: at or before the largest loss.
314: """
315: for margin in range(max(losses_cents) + 1):
316: if cover_bps(losses_cents, margin) >= target_bps:
317: return margin
318: raise RuntimeError("no integer margin reaches the target")

327: f"layers sum to the loss: {w.total_cents() == loss}"

414: 3Where the canon breaks
416: The layer order is a model rule. A1 fixes the order of Definition 1.1. This lesson reads no clearing house's rulebook, and the registry holds no source on CCP waterfalls. So the order is a stated assumption, and no statement here says which order any real CCP uses.
417: The scenario set is an input. The cover of Definition 2.1 is a count over the \(S\) losses supplied to the model. It is not a probability, not an estimate from data, and not a forecast. At 9900 basis points with \(S = 200\), Lab 1 prints a cover of exactly 9900 basis points at the sized margin, which means 2 of the 200 scenarios lie above the margin.
418: No close-out period is modelled. The loss \(L\) enters as one number. The model does not show how it changes while the defaulter's positions are closed out, so Proposition 1.2 is an identity about the waterfall and says nothing about the path of the loss.
419: One default at a time. The model pays one defaulter's loss from one set of layers. It does not model a second default, or the same layers reused after the first.
420: Variation margin is outside the model. A variation margin is a payment that moves with changes in a position's value between margin calls. The model has initial margin only, so every statement here about the margin concerns initial margin.
421: A low target leaves a tail. At 9900 basis points and \(S = 200\), the two largest scenarios are above the sized margin. For those two, the margin pays its full amount, and the rest goes to the layers after it in Definition 1.1: the default fund, the CCP capital, then the surviving members and any uncovered loss. While each of these two losses stays at or above the sized margin, changing it does not change the sized margin, because the 198 smallest losses stay the same.
426: 4Misconceptions
429: “A loss equal to the margin is not covered.”
430: Definition 2.1 counts a scenario when \(L_s \le M\), and Remark 2.2 shows that \(a_1 = \min(L, M) = L\) when \(L = M\). The margin pays that loss in full, so the scenario is counted.
433: “A target of 9900 basis points means losses average 99 percent of the margin.”
434: The cover is a count share of the scenarios, floored, as Definition 2.1 states. It says nothing about the size of the losses. Example 2.5 turns the target into a count: with \(S = 200\), 9900 basis points requires \(k = 198\) of the 200 scenarios. The cover depends only on how many losses sit at or below the margin.
437: “The default fund pays alongside the margin, so both are used on every loss.”
438: Remark 1.4 shows that \(a_2 > 0\) requires \(a_1 = \mathrm{IM}_\delta\). A loss inside the margin uses the margin alone, and Lab 1, Part A3 prints a scenario in which the default fund and the CCP capital pay nothing.
441: “Surviving members pay in proportion to their initial margins.”
442: Definition 1.1 shares the residual by default fund, \(\mathrm{DF}_i\). The survivors' initial margins do not appear in the waterfall at all, so they cannot change a survivor's payment.

452: Mechanics
454: M1 · The waterfall at a loss of 200
455: Use Example 1.5. The defaulter has \(\mathrm{IM}_3 = 100\), \(\mathrm{DF}_3 = 50\), and \(K = 30\). The survivors have \(\mathrm{DF}_1 = 40\) and \(\mathrm{DF}_2 = 60\). Find each layer, the residual, and each survivor's payment for a loss of 200 cents.
456: Solution
457: \(a_1 = \min(200, 100) = 100\). \(a_2 = \min(100, 50) = 50\). \(a_3 = \min(50, 30) = 30\). The residual is \(Z = 200 - 180 = 20\). Since \(D = 100 > 20\), member 1 pays \(\lfloor 20 \cdot 40 / 100 \rfloor = 8\) cents and member 2 pays \(\lfloor 20 \cdot 60 / 100 \rfloor = 12\) cents. The leftover is \(20 - 20 = 0\), and the uncovered loss is 0. The total is \(100 + 50 + 30 + 8 + 12 = 200\).
461: M2 · The cover of one margin, and the margin for one target
462: Four scenarios have losses 1000, 2000, 3000 and 5000 cents. Find \(\mathrm{cover}(4000)\) in basis points, and the smallest integer margin with cover at least 7500 basis points.
463: Solution
464: Three losses are at most 4000, so \(c(4000) = 3\) and \(\mathrm{cover}(4000) = \lfloor 10000 \cdot 3 / 4 \rfloor = 7500\). For the target \(t = 7500\), \(k = \lceil 7500 \cdot 4 / 10000 \rceil = \lceil 3 \rceil = 3\), so the margin is \(L_{(3)} = 3000\) cents. Check: \(\mathrm{cover}(3000) = \lfloor 10000 \cdot 3 / 4 \rfloor = 7500\), and \(\mathrm{cover}(2999) = \lfloor 10000 \cdot 2 / 4 \rfloor = 5000\).
468: M3 · Three targets on five losses
469: The scenario losses are 10, 20, 30, 40 and 50 cents. Find the sized margin for the targets 8000, 8001 and 10000 basis points.
470: Solution
471: For \(t = 8000\), \(tS/10000 = 8000 \cdot 5 / 10000 = 4\), so \(k = 4\) and the margin is \(L_{(4)} = 40\). For \(t = 8001\), \(tS/10000 = 4.0005\), so \(k = 5\) and the margin is \(L_{(5)} = 50\). For \(t = 10000\), \(k = 5\) and the margin is 50. The three answers are 40, 50 and 50 cents.
477: Proof
479: P1 · A layer needs the one before it
480: Under Definition 1.1, prove that \(a_3 > 0\) implies \(a_2 = \mathrm{DF}_\delta\) and \(a_1 = \mathrm{IM}_\delta\).
481: Solution
482: \(a_3 = \min(L - a_1 - a_2, K) > 0\) gives \(L - a_1 - a_2 > 0\), so \(a_2 < L - a_1\). Then \(a_2 = \min(L - a_1, \mathrm{DF}_\delta)\) is less than \(L - a_1\), which forces the minimum to be \(\mathrm{DF}_\delta\): \(a_2 = \mathrm{DF}_\delta\). Next, \(a_2 \ge 0\) and \(a_2 < L - a_1\) give \(L - a_1 > 0\), so \(a_1 < L\). The minimum \(a_1 = \min(L, \mathrm{IM}_\delta)\) is then \(\mathrm{IM}_\delta\), because a minimum below \(L\) must be its second argument.
486: P2 · The index k is in range
487: Let \(t\) be an integer with \(1 \le t \le 10000\) and let \(S \ge 1\) be an integer. Show that \(\lceil tS / 10000 \rceil\) is an integer from 1 to \(S\).
488: Solution
489: Because \(t \ge 1\) and \(S \ge 1\), \(tS/10000 > 0\), so its ceiling is at least 1. Because \(t \le 10000\), \(tS/10000 \le S\). The ceiling of a number \(x \le S\) is at most \(S\), since \(S\) is an integer and \(S \ge x\). So the ceiling is an integer with \(1 \le \lceil tS/10000 \rceil \le S\).
493: P3 · The brute-force search always stops
494: Under A4, show that \(c(M)\) does not decrease as \(M\) increases, and that \(\mathrm{cover}(M) = 10000\) for every \(M \ge \max_s L_s\). Use this to explain why the search of Lab 1, Part B tests only margins up to the largest loss.
495: Solution
496: If \(M \le M'\), then every scenario with \(L_s \le M\) also has \(L_s \le M'\), so \(c(M) \le c(M')\). If \(M \ge \max_s L_s\), then every scenario is counted, so \(c(M) = S\) and \(\mathrm{cover}(M) = \lfloor 10000 \cdot S / S \rfloor = 10000\). So a margin at the largest loss meets every target in A3, and the search over 0, 1, 2, and so on, ends at or before the largest loss.

504: E1 · The scenario that reaches the default fund
505: Lab 1, Part A3 prints a scenario with loss 3160 cents for defaulter 3, whose margin is 3058 cents. Which layers pay, and by how much?
506: Solution

511: E2 · The surviving-members scenario
512: Lab 1, Part A3 prints a scenario with loss 5850 cents, layers of 3058, 205 and 1730 cents, and survivor payments of 312, 381 and 164 cents for members 1, 2 and 4. Show that the payments add to the residual, and state why they are exactly half of each survivor's default fund.
513: Solution
514: The residual is \(Z = 5850 - 3058 - 205 - 1730 = 857\), and \(312 + 381 + 164 = 857\), so the payments add to the residual. The survivors' default funds are 624, 762 and 328 cents, with total \(D = 1714\). Since \(Z = 857 = D/2\), each share is \(\lfloor \mathrm{DF}_i / 2 \rfloor\). The three default funds 624, 762 and 328 are even, so each share is exactly \(\mathrm{DF}_i / 2\): \(624/2 = 312\), \(762/2 = 381\) and \(328/2 = 164\). No leftover arises, consistent with the printed payments.
518: E3 · What the 9900 cover counts
519: Lab 1, Part B prints a cover of 9900 basis points at the sized margin for target 9900, with 200 scenarios. How many scenarios lie above that margin, and how do you know?
520: Solution
521: Cover is \(\lfloor 10000 \cdot c / 200 \rfloor = \lfloor 50c \rfloor = 9900\), which holds only for \(c = 198\), because \(50 \cdot 198 = 9900\) and \(50 \cdot 199 = 9950\). So 198 scenarios are at or below the margin, and \(200 - 198 = 2\) lie above it. The lab does not print the losses, so this count comes from the printed cover alone.
527: Research
529: R1 · Real margins give the same answer
530: Suppose the margin may be any non-negative real number of cents, not only an integer. Show that the smallest margin with cover at least \(t\) is still \(L_{(k)}\), with \(k\) as in Proposition 2.3.
531: Solution
532: The proof of Proposition 2.3, Part 2, uses only that \(M\) is a real number. For real \(M\), \(c(M) \ge k\) if and only if \(M \ge L_{(k)}\), and the cover condition is \(c(M) \ge tS/10000\), which is \(c(M) \ge k\). So the set of margins with cover at least \(t\) is the interval \([L_{(k)}, \infty)\). Its smallest element is \(L_{(k)}\), which is attained. Definition 2.1 gives c(M) and the cover by the same formula for real M, so moving from integer to real margins leaves the answer unchanged.
536: R2 · One large loss with 100 scenarios
537: Take \(S = 100\) and compare the targets 9900 and 10000 basis points. Find \(k\) for each. Show that the margin for 9900 leaves at most one scenario above it, and state when it leaves exactly one.
538: Solution
539: For \(t = 9900\), \(tS/10000 = 99\) exactly, so \(k = 99\) and the margin is \(L_{(99)}\). For \(t = 10000\), \(k = 100\) and the margin is \(L_{(100)}\), the largest loss. Since \(c(L_{(99)}) \ge 99\), at most \(100 - 99 = 1\) scenario lies above \(L_{(99)}\). The count is exactly 1 when \(c(L_{(99)}) = 99\), which holds if and only if \(L_{(99)} < L_{(100)}\). If the two largest losses are equal, no scenario lies above the margin for 9900.
543: R3 · When a 9975 target covers every scenario
544: For which scenario counts \(S\) does the target 9975 basis points require every scenario to be covered, so that \(k = S\)? Prove your answer.
545: Solution
546: \(k = S\) holds if and only if \(\lceil 0.9975 S \rceil = S\), that is \(0.9975 S > S - 1\). This gives \(0.0025 S < 1\), so \(S < 400\). So for \(1 \le S \le 399\), \(k = S\) and the margin is the largest loss. For \(S \ge 400\), \(k \le S - 1\), so one scenario may lie above the margin. At \(S = 400\), \(0.9975 \cdot 400 = 399\) and \(k = 399\), which is consistent with the boundary.
