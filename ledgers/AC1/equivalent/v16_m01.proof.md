# v16_m01 is equivalent to the reference

The mutant replaces `_iso_date(entry["date"])` by `_manual_iso_date(entry["date"])`, and `_manual_iso_date` calls
`_iso_date` first. `_iso_date` runs `date.fromisoformat`, which already raises ValueError for 2100-02-29 (not a leap year).
The added manual leap rule (`year % 4 == 0`) only runs after that call returns, so it never sees an input that the
reference accepts and the mutant rejects or the reverse. Direct run on 2100-02-29: reference and mutant both raise
ValueError. A non-equivalent mutant covering the same behaviour is `ledgers/AC1/mutants/fx16_m01_post_manual_leap_rule_accepts_2100_02_29.py`.
