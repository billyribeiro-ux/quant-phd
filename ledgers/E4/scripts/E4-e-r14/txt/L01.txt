0015| A price is attached to a payment due only in some future state of the world. A market can value such a payment only after the model says what the states are, what a payment in each state is, and how payments are priced. This lesson fixes those objects on a finite state space. It defines the Arrow–Debreu security (Definition 1.3), which pays in a single state, and proves that every claim (Definition 1.2) is a weighted sum of these securities (Proposition 1.4, under A1). Under the linear valuation of Assumption A2 (§3), a claim's value is the sum of security prices (Definition 1.6) times payoffs. Lesson L02 uses these prices to define equilibrium.
0016| 1States, claims and probabilities
0017| Definition 1.1 (state space)
0018| A state space is a finite set \(\Omega = \{1, \ldots, S\}\) of states, one of which is realized. Each state \(s\) has a probability \(\pi_s\). Probabilities are numbers with \(\pi_s > 0\) and \(\sum_{s=1}^{S} \pi_s = 1\).
0019| Assumption A1 (finite, strictly positive states)
0020| The state space \(\Omega\) of Definition 1.1 has \(S < \infty\) states, and \(\pi_s > 0\) for every \(s\). Every result of this lesson that writes a sum over states uses A1. No result here allows infinitely many states.
0021| Definition 1.2 (claim)
0022| A claim is a vector \(x = (x_1, \ldots, x_S) \in \R^{S}\). Its entry \(x_s\) is the payoff in cents that the claim delivers in state \(s\). A claim is the random variable \(X\) on \(\Omega\) with \(X(s) = x_s\), so \(X\) takes the value \(x_s\) in state \(s\). \(\Prob(X = x_s)\) equals \(\pi_s\) exactly when no other state has the same payoff. Payoffs may be negative, which is a promise to pay.
0023| 2Arrow–Debreu securities and decomposition
0024| Definition 1.3 (Arrow–Debreu security)
0025| For a state \(s\), the Arrow–Debreu security of state \(s\) is the claim \(e_s\) with entries \((e_s)_t = 1\) when \(t = s\) and \((e_s)_t = 0\) when \(t \ne s\). It pays one cent in state \(s\) and nothing in any other state.
0026| Proposition 1.4 (decomposition into securities)
0027| Assume A1. Every claim \(x \in \R^{S}\) satisfies \[ x = \sum_{s=1}^{S} x_s\, e_s . \] The coefficient of the security of state \(s\) is the payoff \(x_s\) of the claim in that state.
0028| Proof
0029| Fix a state \(t\). The entry of the right-hand side in state \(t\) is \(\sum_{s=1}^{S} x_s (e_s)_t\). By Definition 1.3, \((e_s)_t\) equals 1 when \(s = t\) and 0 otherwise, so the sum has the single nonzero term \(x_t\). The entry of the left-hand side in state \(t\) is \(x_t\). The two vectors agree in every state. The sum is finite because A1 gives \(S < \infty\). The proof uses no probability, so it holds for any positive \(\pi\).
0030| Example 1.5 (a claim on four states)
0031| Let \(S = 4\), with \(\pi = (\tfrac18, \tfrac38, \tfrac38, \tfrac18)\), and let the claim be \(x = (100, 40, 0, 250)\) cents. Proposition 1.4 gives \(x = 100\, e_1 + 40\, e_2 + 0\, e_3 + 250\, e_4\). The coefficient on \(e_3\) is zero because the claim pays nothing in state 3. Lab 1 uses these four states, numbered 0 to 3 in its code, and prints the same decomposition.
0032| 3Valuation and the prices of the securities
0033| Assumption A2 (linear valuation)
0034| A valuation is a map \(V\) from claims to cents, and it is linear: for all claims \(x\) and \(y\) and all real numbers \(a\) and \(b\), \[ V(a x + b y) = a\, V(x) + b\, V(y). \] A2 excludes quantity discounts, bid-ask spreads and price impact. Each of them makes \(V\) depend on the size or the direction of a trade, so \(V\) need not be linear. A2 is an assumption about the market, and this lesson does not derive it.
0035| Definition 1.6 (security price vector)
0036| Under A2, the security price of state \(s\) is \(q_s = V(e_s)\), in cents of value per cent of payoff, and it is a dimensionless number. The price vector is \(q = (q_1, \ldots, q_S)\). The vector \(q\) is called the Arrow–Debreu security price vector.
0037| Proposition 1.7 (value formula)
0038| Assume A1 and A2. For every claim \(x\), \[ V(x) = \sum_{s=1}^{S} q_s\, x_s . \] Assuming A2 for the valuation \(V\), the value of a claim is determined by the security prices and the payoffs alone.
0039| Proof
0040| By Proposition 1.4, \(x = \sum_{s} x_s e_s\). A2 with two terms gives \(V(a x + b y) = a V(x) + b V(y)\). Applying it repeatedly, by induction on the number of summands, gives \(V\bigl(\sum_{s} x_s e_s\bigr) = \sum_{s} x_s V(e_s)\), which is finite because A1 gives \(S < \infty\). Substituting \(q_s = V(e_s)\) from Definition 1.6 gives the formula.
0041| Proposition 1.8 (the prices are unique)
0042| Assume A1 and A2. Suppose a vector \(r \in \R^{S}\) satisfies \(V(x) = \sum_{s} r_s x_s\) for every claim \(x\). Then \(r_s = q_s\) for every state \(s\), where \(q\) is the price vector of Definition 1.6 under A2.
0043| Proof
0044| Take \(x = e_s\) in the hypothesis. Then \(V(e_s) = \sum_t r_t (e_s)_t = r_s\), by Definition 1.3. Also \(V(e_s) = q_s\) by Definition 1.6. Hence \(r_s = q_s\).
0045| Definition 1.9 (expected payoff)
0046| The expected payoff of a claim is \(\E x = \sum_{s} \pi_s x_s\), the average payoff weighted by the probabilities of Definition 1.1. It is the expectation of the random variable of Definition 1.2.
0047| Proposition 1.10 (value equals expected payoff exactly when prices are probabilities)
0048| Assume A1 and A2. The following two statements are equivalent. (a) \(V(x) = \E x\) for every claim \(x\). (b) \(q_s = \pi_s\) for every state \(s\).
0049| Proof
0050| Assume (b). Proposition 1.7 gives \(V(x) = \sum_s \pi_s x_s = \E x\) for every \(x\), which is (a). Now assume (a). For the security \(e_s\), Definition 1.9 gives \(\E e_s = \sum_t \pi_t (e_s)_t = \pi_s\). Taking \(x = e_s\) in (a) gives \(q_s = V(e_s) = \E e_s = \pi_s\), which is (b).
0051| Remark 1.11 (a price is not a probability)
0052| Proposition 1.10 says that prices and probabilities coincide only in the special case (b). Nothing in A1 or A2 forces (b). A security price \(q_s\) depends on how the market values state \(s\), and the probability \(\pi_s\) is an input to the model. Lab 1 Part D shows that the value under the prices differs from the expected payoff for the claim of Example 1.5, so by Proposition 1.10 the prices differ from the probabilities.
0053| Lab 1 · Decomposition and valuation of a four-state claim
0054| The lab uses no data. It computes exactly, with Fraction values, on the four states of Example 1.5, numbered 0 to 3 in the code. Before running it, the hypothesis is this. The printed decomposition gives coefficients 100, 40, 0 and 250 on the four securities, and it rebuilds the claim exactly (Proposition 1.4). Under the prices \((\tfrac12, \tfrac13, \tfrac14, \tfrac15)\), the claim has value \(340/3\) cents, and the second claim has value 56 cents (Proposition 1.7). Linearity holds exactly on a combination with weights 2 and \(-\tfrac12\) (A2). The expected payoff of the claim is \(235/4\) cents, and it differs from the value under these prices (Proposition 1.10). A probability vector with a negative entry, and one whose entries sum to \(9/8\), are each rejected with a ValueError. No random draws are used, so every run prints the same lines.

0058| 4Where the canon breaks
0059| Finitely many states. Proposition 1.4 is a finite sum, and Proposition 1.7 applies A2 finitely many times (A1). With countably many states, the decomposition still holds coordinate by coordinate, but the step from finite to infinite sums in Proposition 1.7 is not justified by this lesson, and the formula for infinite \(S\) is not derived here. Research problem R1 identifies that step.
0060| Linearity is an assumption. A2 says that a combination of claims is worth the same combination of values, with no discount for size. Under a quantity discount or a size premium, \(V(2x)\) can differ from \(2V(x)\). In that case A2 fails and Proposition 1.7 does not apply (Problem R2).
0061| Every security must be priced. Definition 1.6 needs \(V(e_s)\) for each state. If the market cannot deliver the security of some state, \(q_s\) is not defined by this lesson. Lesson L04 treats this case through the rank of the payoff matrix.
0062| Probabilities are given. The lesson takes \(\pi\) as an input and does not derive it from beliefs or data. Proposition 1.7 makes the value of a claim depend on \(q\), and Proposition 1.10 shows that \(q\) need not equal \(\pi\).
0063| 5Misconceptions
0064| “The price of the security for a state is that state's probability.”
0065| Proposition 1.10 says the two coincide only under condition (b), and Remark 1.11 says nothing in A1 or A2 forces it. Lab 1 uses prices \((\tfrac12, \tfrac13, \tfrac14, \tfrac15)\) and probabilities \((\tfrac18, \tfrac38, \tfrac38, \tfrac18)\), which differ in every state. Part D prints the line that reads False.
0066| “A claim that pays in several states needs its own price, so a market with \(S\) states must price every combination of states.”
0067| Proposition 1.7 gives the value of every claim from the \(S\) security prices. Lab 1 Part B values two different claims, 340/3 and 56 cents, from the same four prices, with no further price needed.
0068| “The decomposition works only when the states are equally likely.”
0069| Proposition 1.4 uses no probability, so it holds for every positive \(\pi\). Lab 1 checks its unequal probabilities \((\tfrac18, \tfrac38, \tfrac38, \tfrac18)\) once, at the start of main(), before Part A. Part A's decomposition uses only the claim, so the rebuilt payoff equals the claim exactly.

0072| Mechanics
0073| M1 · Decompose and value a three-state claim
0074| Let \(S = 3\), \(\pi = (\tfrac12, \tfrac14, \tfrac14)\), and the claim \(x = (10, 0, 30)\) cents. Write \(x\) as a combination of securities. Under the prices \(q = (\tfrac13, \tfrac15, \tfrac12)\), find \(V(x)\) and \(\E x\), and compare them.
0075| Solution
0076| By Proposition 1.4, \(x = 10\, e_1 + 0\, e_2 + 30\, e_3\). By Proposition 1.7, \(V(x) = 10 \cdot \tfrac13 + 0 \cdot \tfrac15 + 30 \cdot \tfrac12 = \tfrac{10}{3} + 15 = \tfrac{55}{3}\) cents, which is about 18.33 cents to two decimal places. The expected payoff is \(\E x = 10 \cdot \tfrac12 + 0 \cdot \tfrac14 + 30 \cdot \tfrac14 = 5 + 7.5 = 12.5\) cents. The value exceeds the expected payoff by \(\tfrac{55}{3} - \tfrac{25}{2} = \tfrac{35}{6}\) cents. By Proposition 1.10, this difference shows that \(q \ne \pi\).
0077| M2 · Value of a claim that pays in one state
0078| A two-state claim pays 0 cents in state 1 and 50 cents in state 2. The security prices are \(q_1 = 0.4\) and \(q_2 = 0.5\). Find the value of the claim, and state which proposition gives it.
0079| Solution
0080| The claim is \(x = (0, 50) = 50\, e_2\), by Proposition 1.4. Proposition 1.7 gives \(V(x) = 0.4 \cdot 0 + 0.5 \cdot 50 = 25\) cents. The price of state 1 does not enter, because the claim pays nothing in state 1, which is the reason the value depends only on \(q_2\) here.
0081| M3 · A combination of two claims
0082| Let \(x = (1, 2, 3)\), \(y = (4, 0, 1)\) and \(q = (\tfrac12, \tfrac14, \tfrac18)\). Compute \(V(3x - 2y)\) directly from its payoffs, and again from \(V(x)\) and \(V(y)\) using A2, and check that the two answers agree.
0083| Solution
0084| The combination is \(3x - 2y = (3 - 8, 6 - 0, 9 - 2) = (-5, 6, 7)\). By Proposition 1.7, \(V = -5 \cdot \tfrac12 + 6 \cdot \tfrac14 + 7 \cdot \tfrac18 = -\tfrac{20}{8} + \tfrac{12}{8} + \tfrac{7}{8} = -\tfrac18\). Separately, \(V(x) = \tfrac12 + \tfrac12 + \tfrac38 = \tfrac{11}{8}\) and \(V(y) = 2 + 0 + \tfrac18 = \tfrac{17}{8}\). Then A2 gives \(3 \cdot \tfrac{11}{8} - 2 \cdot \tfrac{17}{8} = \tfrac{33 - 34}{8} = -\tfrac18\). The two answers agree.

0086| P1 · The riskless one-cent claim
0087| Let \(\iota\) be the vector of ones, \(\iota = (1, \ldots, 1)\), which is the claim that pays one cent in every state. Show that \(\iota = \sum_{s} e_s\), and that \(V(\iota) = \sum_{s} q_s\) under A1 and A2.
0088| Solution
0089| For each state \(t\), the entry of \(\sum_{s} e_s\) in state \(t\) is \(\sum_{s} (e_s)_t\). By Definition 1.3 exactly one term, the one with \(s = t\), equals 1, so the entry is 1 in every state, and \(\sum_{s} e_s = \iota\). Proposition 1.7 applied to \(x = \iota\) gives \(V(\iota) = \sum_{s} q_s \cdot 1 = \sum_{s} q_s\). The value of a sure cent is the sum of the security prices.
0090| P2 · Value of the zero claim and of a reversed claim
0091| Under A2, show that \(V(0) = 0\) for the zero claim, and that \(V(-x) = -V(x)\) for every claim \(x\).
0092| Solution
0093| Take \(a = 0\) and \(b = 0\) in A2 with any claim \(x\) and \(y = x\): \(V(0 \cdot x + 0 \cdot x) = 0 \cdot V(x) + 0 \cdot V(x) = 0\), so \(V(0) = 0\). Take \(a = -1\) and \(b = 0\): \(V(-x) = -1 \cdot V(x) + 0 \cdot V(x) = -V(x)\). Both follow from A2 alone.
0094| P3 · Prices that differ from probabilities, two states
0095| Let \(S = 2\), \(\pi = (\tfrac13, \tfrac23)\) and \(q = (\tfrac14, \tfrac12)\), with \(V\) linear and defined by Proposition 1.7. Show that \(V(x) \ne \E x\) for some claim \(x\), and identify the claim.
0096| Solution
0097| Take \(x = e_1\), which pays one cent in state 1. Then \(V(e_1) = q_1 = \tfrac14\), while \(\E e_1 = \pi_1 = \tfrac13\). Since \(\tfrac14 \ne \tfrac13\), the equality of Proposition 1.10 fails for \(x = e_1\), and so statement (a) fails. This is the contrapositive of Proposition 1.10, which says that (a) forces \(q = \pi\). It is not a counterexample to a converse, because Proposition 1.10 proves both directions.

0111| Research
0112| R1 · Infinitely many states
0113| Let the state space be countable, with \(\pi_s > 0\) and \(\sum_s \pi_s = 1\). Identify the step of the proof of Proposition 1.7 that is not justified when \(S\) is infinite.
0114| Solution
0115| The decomposition still holds coordinate by coordinate, because in each state only one term of \(\sum_s x_s e_s\) is nonzero. The step that is not justified is the application of A2 to an infinite sum, since A2 is stated for two terms and induction on the number of summands gives finite sums only. This lesson therefore derives the formula \(V(x) = \sum_s q_s x_s\) for finite \(S\) only, and it does not derive that formula for infinite \(S\).
0116| R2 · A size effect breaks linearity
0117| Let \(V(x) = \bigl(\sum_s q_s x_s\bigr)^2\), which applies a size effect to the value. With \(q_1 = \tfrac12\), compute \(V(e_1)\) and \(V(2 e_1)\), and state which assumption fails.
0118| Solution
0119| We have \(V(e_1) = (\tfrac12)^2 = \tfrac14\) and \(V(2e_1) = (2 \cdot \tfrac12)^2 = 1\). Linearity would require \(V(2e_1) = 2V(e_1) = \tfrac12\), which fails. So A2 fails, and Proposition 1.7 does not apply to this \(V\). The formula \(\sum_s q_s x_s\) is then not the value of the claim.
0120| R3 · When nonnegative claims have nonnegative value
0121| Under A1 and A2, show that \(V(x) \ge 0\) for every claim with \(x_s \ge 0\) for all \(s\) if and only if \(q_s \ge 0\) for all \(s\).
0122| Solution
0123| If every \(q_s \ge 0\) and every \(x_s \ge 0\), then \(V(x) = \sum_s q_s x_s \ge 0\) by Proposition 1.7. Conversely, if \(V(x) \ge 0\) for every nonnegative claim, take \(x = e_s\), which is nonnegative. Then \(q_s = V(e_s) \ge 0\) by Definition 1.6. Both directions use only Proposition 1.7 and the definition of the prices.

0141| A2 with \(a = 2\) and \(b = 0\) gives \(V(2x) = 2V(x)\). Problem R2 shows what happens when A2 fails.
0142| A claim pays 0 in state 1 and 4 in state 2, with probabilities \(\pi_1 = \tfrac14\) and \(\pi_2 = \tfrac34\). What is its expected payoff, in cents?
0143| Answer
0144| \(\E x = 0 \cdot \tfrac14 + 4 \cdot \tfrac34 = 3\) cents (Definition 1.9).
0145| Which property holds for an Arrow–Debreu security?
0146| Options It pays one cent in its own state and nothing in any other state It pays the expected payoff in every state It pays the same amount in every state
0147| Definition 1.3 gives the payoff vector \(e_s\), with a 1 in state \(s\) and 0 elsewhere.
0148| Which assumption does the decomposition \(x = \sum_s x_s e_s\) of Proposition 1.4 require?
0149| Options A finite state space (A1) Equal state probabilities A linear utility function
0150| Proposition 1.4 is an identity about payoff vectors. It uses A1 for the finiteness of the sum, and it uses no probability and no utility.
0151| A claim pays one cent in each of three states. The security prices are \(0.2\), \(0.3\) and \(0.1\). What is its value, in cents?
0152| Answer
0153| \(V(\iota) = \sum_s q_s = 0.2 + 0.3 + 0.1 = 0.6\) cents (Problem P1).
0154| Two vectors \(r\) and \(q\) both satisfy \(V(x) = \sum_s r_s x_s\) and \(V(x) = \sum_s q_s x_s\) for every claim \(x\). What follows?
0155| Options \(r = q\) \(r = \pi\) Nothing, because \(r\) and \(q\) may differ
0156| Proposition 1.8: taking \(x = e_s\) gives \(r_s = V(e_s) = q_s\) for every state.
0157| Which feature of a market would make the value of a claim nonlinear in its payoff?
0158| Options Two states instead of three A discount that depends on the size of the order Unequal state probabilities
0159| A size discount violates A2, which is the linearity that Proposition 1.7 uses (Problem R2). Neither the number of states nor the probabilities alone affects linearity.
