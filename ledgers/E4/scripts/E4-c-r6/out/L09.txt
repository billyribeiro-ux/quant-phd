  65| Two traders with the same prior (Assumption B1) and different information sometimes seem to have reasons to bet against each other. The no-trade theorem (Definition 2.2 below) asks when those reasons can be mutual. This lesson sets up a finite model with a common prior and two information partitions, and it proves that a bet (Assumption B3) which both traders accept (Definition 1.1), with the acceptance common knowledge (Definition 1.2), has zero conditional expected receipt for each of them (Definition 1.1). The proof is a short sum over cells. The lesson then shows which hypothesis carries the result: a different prior, or acceptance that is not common knowledge, allows bets that both traders strictly accept.
  68| 1A finite model of bets between two traders
  72| Assumption B1 (finite common prior)
  74| The state space \(\Omega\) is finite. A prior \(\pi\) assigns \(\pi(\omega) > 0\) to every state \(\omega\), with \(\sum_{\omega \in \Omega} \pi(\omega) = 1\). Both traders hold this prior. For a set \(D\) with \(\pi(D) = \sum_{\omega \in D} \pi(\omega) > 0\), the conditional probability of an event \(E\) given \(D\) is \(\pi(E \cap D)/\pi(D)\). Traders update by this rule.
  79| Assumption B2 (information partitions)
  81| Trader 1 observes a partition \(\mathcal{P}_1\) of \(\Omega\), and trader 2 observes a partition \(\mathcal{P}_2\). The sets of a partition are its cells. In state \(\omega\), trader \(i\) learns the cell \(\mathcal{P}_i(\omega)\) that contains \(\omega\). Both partitions are common knowledge: each trader knows both partitions. This is an assumption of the model, and Definition 1.2 gives common knowledge for events.
  86| Assumption B3 (zero-sum bets)
  88| A bet is a function \(x : \Omega \to \R\). Trader 1 receives \(x(\omega)\) in state \(\omega\), and trader 2 receives \(-x(\omega)\). The bet is a transfer between the traders and creates no other payoff.
  93| Definition 1.1 (posterior value of a bet)
  95| For a bet \(x\) and a cell \(D\) with \(\pi(D) > 0\), the posterior expected receipt is \(\E[x \mid D] = \sum_{\omega \in D}\pi(\omega)x(\omega)/\pi(D)\). The posterior values of the bet for the two traders are
  96| \[ g_1(\omega) = \E\bigl[x \mid \mathcal{P}_1(\omega)\bigr], \qquad g_2(\omega) = \E\bigl[-x \mid \mathcal{P}_2(\omega)\bigr]. \]
  97| Trader \(i\) accepts the bet at \(\omega\) when \(g_i(\omega) \ge 0\), and accepts it strictly when \(g_i(\omega) > 0\).
 102| Definition 1.2 (meet and common knowledge)
 104| The meet \(M(\omega)\) is the smallest set that contains \(\omega\) and is a union of cells of \(\mathcal{P}_1\) and also a union of cells of \(\mathcal{P}_2\). An event \(E\) is common knowledge at \(\omega\) when \(M(\omega) \subseteq E\). Equivalently, \(M(\omega)\) is the set of states reachable from \(\omega\) by moves within a \(\mathcal{P}_1\) cell or within a \(\mathcal{P}_2\) cell.
 108| The function \(g_i\) is constant on the cells of trader \(i\). So the event \(\{\omega : g_i(\omega) \ge 0\}\) is a union of cells of trader \(i\), and trader \(i\) knows it at every state where it holds. Definition 1.2 then says when this acceptance is common knowledge.
 111| 2The theorem and its hypothesis
 115| Theorem 2.1 (the no-trade theorem, finite version)
 117| Assumptions: B1, B2 and B3. Let \(\omega^\ast \in \Omega\) and \(M = M(\omega^\ast)\). If
 118| \[ g_1(\omega) \ge 0 \quad\text{and}\quad g_2(\omega) \ge 0 \qquad\text{for every } \omega \in M, \]
 119| then \(g_1(\omega) = 0\) and \(g_2(\omega) = 0\) for every \(\omega \in M\).
 124| Proof
 126| Since \(M\) is a union of cells of \(\mathcal{P}_1\), it is the disjoint union of those cells \(D\) of \(\mathcal{P}_1\) with \(D \subseteq M\). For each such cell, \(\sum_{\omega \in D}\pi(\omega)x(\omega) = \pi(D)\,\E[x \mid D]\), and \(\E[x \mid D] = g_1(\omega)\) for every \(\omega \in D\). Summing over the cells,
 127| \[ S_1 := \sum_{\omega \in M}\pi(\omega)x(\omega) = \sum_{D \in \mathcal{P}_1,\ D \subseteq M}\pi(D)\,g_1(D). \]
 128| The same argument with \(\mathcal{P}_2\) and the bet \(-x\), which is zero-sum with \(x\), gives
 129| \[ S_2 := \sum_{\omega \in M}\pi(\omega)(-x(\omega)) = \sum_{D \in \mathcal{P}_2,\ D \subseteq M}\pi(D)\,g_2(D). \]
 130| Here \(g_2(D)\) is the common value of \(g_2\) on \(D\). The hypothesis says every term on the right of each sum is nonnegative, because \(\pi(D) > 0\) by B1. So \(S_1 \ge 0\) and \(S_2 \ge 0\). But \(S_2 = -S_1\), so \(S_1 \ge 0\) and \(-S_1 \ge 0\), which gives \(S_1 = 0\). Then the nonnegative terms in the first sum add to zero, so each term is zero: \(\pi(D)g_1(D) = 0\), and \(g_1(D) = 0\) for every cell \(D \subseteq M\) of \(\mathcal{P}_1\). Every \(\omega \in M\) lies in such a cell, so \(g_1(\omega) = 0\) on \(M\). The same argument with \(S_2 = 0\) gives \(g_2 = 0\) on \(M\).
 135| Definition 2.2 (no-trade)
 137| The no-trade theorem is the statement of Theorem 2.1 read as a restriction on bets. It says that under B1 to B3, a bet whose acceptance by both traders is common knowledge on the meet of \(\omega^\ast\) has zero posterior value for both traders on that meet. Theorem 2.1 is a result about bets and posteriors. It says nothing about prices, and this page does not connect it to an equilibrium price.
 142| Corollary 2.3 (no common strict acceptance)
 144| Assumptions: B1 to B3. Let \(\omega^\ast \in \Omega\), \(M = M(\omega^\ast)\), and let \(x\) be a bet with \(g_1(\omega^\ast) > 0\) and \(g_2(\omega^\ast) > 0\). Then there is a state \(\omega \in M\) with \(g_1(\omega) < 0\) or \(g_2(\omega) < 0\).
 149| Proof
 151| If the hypothesis of Theorem 2.1 held, then \(g_1(\omega^\ast) = 0\), which contradicts \(g_1(\omega^\ast) > 0\). So the hypothesis fails, and some \(\omega \in M\) violates \(g_1(\omega) \ge 0\) or \(g_2(\omega) \ge 0\).
 156| Example 2.4 (a bet that is strict at one state but not on the meet)
 158| Let \(\Omega = \{1, 2, 3, 4, 5, 6\}\) with the uniform prior \(\pi(\omega) = 1/6\). Let \(\mathcal{P}_1 = \{\{1, 2\}, \{3\}, \{4, 5, 6\}\}\) and \(\mathcal{P}_2 = \{\{1, 2, 3\}, \{4, 5\}, \{6\}\}\). The meet of state 1 is \(M(1) = \{1, 2, 3\}\), because \(\{1, 2\}\) and \(\{1, 2, 3\}\) link 1 to 2 and 3, and the cells of 3 are \(\{3\}\) and \(\{1, 2, 3\}\). Take \(x = (-1, 2, -2, -2, -2, -2)\). Then \(g_1(1) = (x(1) + x(2))/2 = 1/2\), and trader 2's receipts \(-x\) on \(\{1, 2, 3\}\) are \((1, -2, 2)\), so \(g_2(1) = 1/3\). Both are strictly positive at state 1. But \(g_1(3) = x(3) = -2 < 0\), so the hypothesis of Theorem 2.1 fails, as Corollary 2.3 requires. Lab 1, part B checks this bet and every other bet with values from \(-2\) to \(2\) on the same six states.
 162| 3Lab 1: every bet with values from \(-2\) to \(2\) on the six-state space
 165| Lab 1 enumerates all \(5^6 = 15625\) bets with values in \(\{-2, -1, 0, 1, 2\}\) on the space of Example 2.4. It computes every posterior in exact rational arithmetic, so the equalities of the proof are checked without rounding. Part A checks the identity \(S_1 = \sum_{D} \pi(D)g_1(D)\) on the meet of state 1 for every bet. Parts B and C apply the theorem to states 1 and 4, and print the counts.
 170| Lab 1 · Every bet with values from \(-2\) to \(2\) on a six-state space, checked against both posteriors
 172| Stated before running: the enumeration has \(15625\) bets. The identity of the proof holds exactly for every bet. At state 1, with meet \(\{1, 2, 3\}\), some bets are strictly positive for both traders, but none of them satisfies the nonnegativity condition on the meet, and every bet that satisfies that condition has zero posteriors on the meet. The same holds at state 4, with meet \(\{4, 5, 6\}\). The lab uses exact fractions and no random draws, so no SIMULATED label applies.
 174| """E4 L09 lab 1: every bet on a six-state space, checked against the posteriors of two agents.
 176| The states are 1 to 6 with the common prior 1/6 on each state. Agent 1 knows the cell of P1 = {1,2}, {3}, {4,5,6}.
 177| Agent 2 knows the cell of P2 = {1,2,3}, {4,5}, {6}. A bet is a function x from the states to {-2, -1, 0, 1, 2}: agent 1
 178| receives x(w) in state w and agent 2 receives -x(w). There are 5**6 = 15625 bets. Each agent's posterior expected
 179| receipt, given the cell of the agent's own information, is computed in exact rational arithmetic (fractions.Fraction).
 180| The common-knowledge meet of a state is the set of states reachable from it by moves within a P1 cell or within a
 181| P2 cell. Part B checks the finite no-trade statement on the meet of state 1 and prints a bet that both agents
 182| accept strictly at state 1 when the acceptance is not common knowledge. Part C does the same at state 4.
 183| There are no random draws and no data. Standard library only; no network access.
 184| """
 186| from __future__ import annotations
 188| from fractions import Fraction
 189| from itertools import product
 191| STATES = (1, 2, 3, 4, 5, 6)
 192| PRIOR = Fraction(1, 6)
 193| P1 = (frozenset({1, 2}), frozenset({3}), frozenset({4, 5, 6}))
 194| P2 = (frozenset({1, 2, 3}), frozenset({4, 5}), frozenset({6}))
 195| VALUES = (-2, -1, 0, 1, 2)
 198| def cell_of(partition: tuple[frozenset[int], ...], state: int) -> frozenset[int]:
 199| """The cell of the partition that contains the state."""
 200| for cell in partition:
 201| if state in cell:
 202| return cell
 203| raise ValueError(f"state {state} is in no cell")
 206| def posterior(partition: tuple[frozenset[int], ...], state: int, receipt: dict[int, int]) -> Fraction:
 207| """Expected receipt given the cell of the state, under the common prior."""
 208| cell = cell_of(partition, state)
 209| total = PRIOR * len(cell)
 210| return sum((PRIOR * receipt[k] for k in cell), Fraction(0)) / total
 213| def meet(state: int) -> frozenset[int]:
 214| """States reachable from state by moves within a P1 cell or within a P2 cell."""
 215| reached = {state}
 216| frontier = [state]
 217| while frontier:
 218| current = frontier.pop()
 219| for partition in (P1, P2):
 220| for other in cell_of(partition, current):
 221| if other not in reached:
 222| reached.add(other)
 223| frontier.append(other)
 224| return frozenset(reached)
 227| def bets() -> list[dict[int, int]]:
 228| """Every bet, as a map from state to agent 1's receipt."""
 229| return [dict(zip(STATES, values, strict=True)) for values in product(VALUES, repeat=len(STATES))]
 232| def posteriors(bet: dict[int, int]) -> tuple[dict[int, Fraction], dict[int, Fraction]]:
 233| """Agent 1's and agent 2's posterior expected receipts at every state."""
 234| negated = {k: -v for k, v in bet.items()}
 235| g1 = {w: posterior(P1, w, bet) for w in STATES}
 236| g2 = {w: posterior(P2, w, negated) for w in STATES}
 237| return g1, g2
 240| def part_a() -> None:
 241| """The enumeration and the identity used in the proof, checked on the meet of state 1."""
 242| everything = bets()
 243| print(f"part A: states = {len(STATES)}, prior = {PRIOR} each, bets = {len(everything)} (exact arithmetic)")
 244| meet_1 = meet(1)
 245| for bet in everything:
 246| g1, g2 = posteriors(bet)
 247| left = sum((PRIOR * bet[w] for w in meet_1), Fraction(0))
 248| right = sum(
 249| (PRIOR * len(cell) * g1[next(iter(cell))] for cell in P1 if cell <= meet_1),
 250| Fraction(0),
 251| )
 252| if left != right:
 253| raise AssertionError("the proof identity sum over the meet fails")
 254| neg_left = -left
 255| right2 = sum(
 256| (PRIOR * len(cell) * g2[next(iter(cell))] for cell in P2 if cell <= meet_1),
 257| Fraction(0),
 258| )
 259| if neg_left != right2:
 260| raise AssertionError("the agent 2 identity sum over the meet fails")
 261| print("part A: identity sum of prior times receipt over the meet equals the sum over own cells: True")
 264| def examine(state: int, label: str) -> None:
 265| """Count the mutually strict bets at a state, then check the no-trade statement on its meet."""
 266| everything = bets()
 267| meet_s = meet(state)
 268| print(f"{label}: state {state}, common-knowledge meet = {sorted(meet_s)}")
 269| strict_at_state = []
 270| accepted = []
 271| for bet in everything:
 272| g1, g2 = posteriors(bet)
 273| if g1[state] > 0 and g2[state] > 0:
 274| strict_at_state.append(bet)
 275| if all(g1[w] >= 0 and g2[w] >= 0 for w in meet_s):
 276| accepted.append((bet, g1, g2))
 277| print(f"{label}: bets with both posteriors strictly positive at state {state}: {len(strict_at_state)}")
 278| strict_and_common = [
 279| b for b in strict_at_state if all(posteriors(b)[0][w] >= 0 and posteriors(b)[1][w] >= 0 for w in meet_s)
 280| ]
 281| print(
 282| f"{label}: of those, bets with both posteriors nonnegative on the meet: {len(strict_and_common)} (theorem: 0)"
 283| )
 284| violations = 0
 285| for _, g1, g2 in accepted:
 286| if any(g1[w] != 0 or g2[w] != 0 for w in meet_s):
 287| violations += 1
 288| print(f"{label}: bets with both posteriors nonnegative on the meet: {len(accepted)}")
 289| print(f"{label}: of those, bets with a nonzero posterior on the meet: {violations} (theorem: 0)")
 290| if strict_and_common or violations:
 291| raise AssertionError("the no-trade statement fails on the meet")
 292| if strict_at_state:
 293| witness = strict_at_state[0]
 294| g1, g2 = posteriors(witness)
 295| shown = tuple(witness[w] for w in STATES)
 296| print(f"{label}: first bet with both posteriors strictly positive at state {state}: x = {shown}")
 297| order = sorted(meet_s)
 298| print(f"{label}: that bet's agent 1 posteriors on the meet {order} = {[str(g1[w]) for w in order]}")
 299| print(f"{label}: that bet's agent 2 posteriors on the meet {order} = {[str(g2[w]) for w in order]}")

 334| Remark 2.5 (the posterior standard)
 336| The posterior values \(g_1\) and \(g_2\) play the role that utilities play in the Pareto efficiency standard: a bet that both traders value strictly positively is an improvement for both, in posterior terms. Theorem 2.1 excludes such a bet on the meet when acceptance is common knowledge. The trades of the Arrow–Debreu equilibrium of Lesson L02 come from state-contingent endowments and prices. This lesson has neither, and asks whether differences in information alone can make bets mutually acceptable. In an adverse-selection setting, a counterpart's willingness to trade is itself informative. Theorem 2.1 does not cover that setting unless acceptance is common knowledge.
 340| Example 2.4 shows the role of common knowledge. Each trader, knowing only their own cell, accepts the bet at state 1. Acceptance of the bet is not common knowledge at state 1, because on the meet trader 1 rejects it at state 3. A bet that both traders accept only on their private information is not ruled out by the theorem, and the example is a bet of this kind.
 345| 4Where the canon breaks
 348| The prior must be common. Take two states \(H\) and \(L\) with trivial partitions, so neither trader learns anything. Let trader 1 have the prior \(q_1(H) = 0.7\), and trader 2 have \(q_2(H) = 0.4\). Let \(x(H) = 1\) and \(x(L) = -1\). Trader 1's expected receipt is \(0.7 - 0.3 = 0.4\), and trader 2's expected receipt of \(-x\) is \(-(0.4 - 0.6) = 0.2\). Both are strictly positive, with common knowledge of the partitions. The proof uses one prior \(\pi\) in both posterior sums and in \(S_2 = -S_1\). With two priors the two sums are taken under different measures, and \(S_2 = -S_1\) no longer holds.
 350| Acceptance must be common knowledge. Example 2.4 shows a bet that both traders accept strictly at state 1. The hypothesis of Theorem 2.1 is the common knowledge of acceptance on the meet, and it is the hypothesis that fails in the example.
 352| The statement is for finite models. The proof sums over finitely many cells. For infinite state spaces the sums become integrals, and the statement needs conditions this page does not state. The page makes no claim for infinite \(\Omega\).
 354| The meet is the set of common knowledge, not the set of agreement. Theorem 2.1 uses the meet, the smallest set that contains the state and is a union of cells of both partitions, on which acceptance must hold. An event that both traders know at a state need not be common knowledge there. The next section gives an example.
 361| 5Misconceptions
 366| “Traders with different information must trade with each other.”
 368| Corollary 2.3 says that a bet both traders accept strictly at \(\omega^\ast\) has a state on the meet where one of them has a negative posterior, so the acceptance cannot be common knowledge on the meet. Lab 1, part B, finds 500 bets that both traders accept strictly at state 1, and none of them satisfies the common-knowledge condition. With a common prior and common knowledge of acceptance on the meet, Theorem 2.1 rules out a bet that both traders accept strictly. Acceptance on private information is not ruled out (Example 2.4).
 373| “If both traders know an event at a state, the event is common knowledge there.”
 375| Let \(\Omega = \{\omega_1, \omega_2, \omega_3\}\) with \(\mathcal{P}_1 = \{\{\omega_1, \omega_2\}, \{\omega_3\}\}\) and \(\mathcal{P}_2 = \{\{\omega_1\}, \{\omega_2, \omega_3\}\}\), and let \(E = \{\omega_1, \omega_2\}\). At state \(\omega_1\), trader 1's cell \(\{\omega_1, \omega_2\}\) lies in \(E\), and trader 2's cell \(\{\omega_1\}\) lies in \(E\), so both know \(E\). But \(M(\omega_1) = \{\omega_1, \omega_2, \omega_3\}\), since \(\omega_2\) and \(\omega_3\) share a cell of \(\mathcal{P}_2\), and \(M(\omega_1) \not\subseteq E\). So \(E\) is not common knowledge at \(\omega_1\). Definition 1.2 requires the whole meet, not the two cells.
 380| “The trader with more information wins every bet.”
 382| The posterior \(g_i(\omega)\) is an expected receipt given a cell, not a realised payoff. In Example 2.4 trader 1 has posterior \(1/2\) at state 1, but receives \(-2\) at state 3, where the bet pays against trader 1 in that state. A posterior that is positive at one state does not guarantee a gain in every state of the meet.

 397| Mechanics
 400| Mech 1 · Posteriors on two cells
 402| Let \(\Omega = \{1, 2, 3, 4\}\) with the uniform prior, and \(\mathcal{P}_1 = \{\{1, 2\}, \{3, 4\}\}\). Let \(x = (2, 0, -1, 4)\). Compute \(g_1\) at every state.
 404| Solution
 406| On the cell \(\{1, 2\}\), \(\E[x \mid \{1, 2\}] = (2 + 0)/2 = 1\), so \(g_1(1) = g_1(2) = 1\). On the cell \(\{3, 4\}\), \(\E[x \mid \{3, 4\}] = (-1 + 4)/2 = 3/2\), so \(g_1(3) = g_1(4) = 3/2\). The prior cancels in the average, because each cell has two states with the same prior.
 411| Mech 2 · The meet of a state
 413| On the four states of Mech 1, let \(\mathcal{P}_1 = \{\{1, 2\}, \{3, 4\}\}\) and \(\mathcal{P}_2 = \{\{1\}, \{2, 3\}, \{4\}\}\). Find the meet \(M(1)\).
 415| Solution
 417| Start from state 1. Its \(\mathcal{P}_1\) cell is \(\{1, 2\}\), so state 2 is reachable. The \(\mathcal{P}_2\) cell of 2 is \(\{2, 3\}\), so state 3 is reachable. The \(\mathcal{P}_1\) cell of 3 is \(\{3, 4\}\), so state 4 is reachable. No further states appear, so \(M(1) = \{1, 2, 3, 4\} = \Omega\). Common knowledge of an event at state 1 then requires the event to be all of \(\Omega\).
 422| Mech 3 · Two priors
 424| Two states \(H\) and \(L\) have trivial partitions. Trader 1 has the prior \(q_1(H) = 0.7\) and trader 2 has \(q_2(H) = 0.4\). Let \(x(H) = 1\) and \(x(L) = -1\). Find each trader's expected receipt.
 426| Solution
 428| Trader 1 expects \(0.7 \cdot 1 + 0.3 \cdot (-1) = 0.4\). Trader 2 expects \(-x\), which is \(-1\) at \(H\) and \(+1\) at \(L\), so the expected receipt is \(-0.4 + 0.6 = 0.2\). Both values are strictly positive, which is the failure of the common-prior hypothesis in Section 4.
 436| Proof
 439| Proof 1 · The identity over the meet
 441| Let \(M\) be a union of cells of \(\mathcal{P}_1\). Prove that \(\sum_{\omega \in M}\pi(\omega)x(\omega) = \sum_{D \in \mathcal{P}_1, D \subseteq M}\pi(D)\E[x \mid D]\).
 443| Solution
 445| A union of cells is the disjoint union of the cells it contains, so the states of \(M\) are partitioned into the cells \(D \subseteq M\) of \(\mathcal{P}_1\). For each cell, \(\sum_{\omega \in D}\pi(\omega)x(\omega) = \pi(D)\E[x \mid D]\) by Definition 1.1. Summing over the disjoint cells gives the stated identity. The step uses only that the cells are disjoint and that \(\pi(D) > 0\).
 450| Proof 2 · Common knowledge of an event
 452| Let \(E\) be an event with \(M(\omega) \subseteq E\). Show that for every state \(\omega' \in M(\omega)\), the meet of \(\omega'\) is contained in \(E\).
 454| Solution
 456| Let \(\omega' \in M(\omega)\). The meet \(M(\omega')\) is the smallest set containing \(\omega'\) that is a union of cells of both partitions. Because \(\omega' \in M(\omega)\) and \(M(\omega)\) is a union of cells of both partitions, the cell of \(\omega'\) in each partition lies in \(M(\omega)\), and so does the whole meet of \(\omega'\). Then \(M(\omega') \subseteq M(\omega) \subseteq E\).
 461| Proof 3 · Two traders, one cell each
 463| Suppose \(\mathcal{P}_1\) and \(\mathcal{P}_2\) are both the trivial partition \(\{\Omega\}\). Prove that the hypothesis of Theorem 2.1 implies \(g_1 = \E[x]\) and \(g_2 = -\E[x]\) on \(\Omega\), and that \(\E[x] = 0\) under the hypothesis.
 465| Solution
 467| With the trivial partitions, every state has the same cell \(\Omega\), so \(g_1(\omega) = \E[x]\) and \(g_2(\omega) = \E[-x] = -\E[x]\) for every \(\omega\). The hypothesis gives \(\E[x] \ge 0\) and \(-\E[x] \ge 0\), so \(\E[x] = 0\). Then \(g_1 = g_2 = 0\), as Theorem 2.1 states. This is the case of a single common cell, where no information differs.
 475| Empirical
 478| Emp 1 · The counts in Lab 1, part B
 480| Lab 1, part B, prints 500 bets strictly positive for both traders at state 1, and 625 bets nonnegative on the meet. Explain, from the printed counts, why none of the 500 bets is among the 625.
 482| Solution
 484| The 625 bets are nonnegative for both traders on the meet \(\{1, 2, 3\}\), while each of the 500 is strictly positive at state 1 but has a negative posterior somewhere on the meet. By Theorem 2.1 a bet nonnegative on the meet has zero posterior there, so it cannot be strictly positive at state 1. The printed count of the intersection is 0, which agrees with this argument.
 489| Emp 2 · The witness bet
 491| Lab 1, part B, prints the first bet that is strictly positive for both traders at state 1, with agent 1's posteriors on the meet equal to \(1/2\), \(1/2\), \(-2\). Verify these three values from the bet and the partition.
 493| Solution
 495| The printed bet is \(x = (-1, 2, -2, -2, -2, -2)\). The cell \(\{1, 2\}\) gives \((-1 + 2)/2 = 1/2\) for states 1 and 2. The cell \(\{3\}\) gives \(x(3) = -2\) for state 3. These match the printed values. The printed trader 2 posteriors \(1/3\) on \(\{1, 2, 3\}\) come from the cell \(\{1, 2, 3\}\) and the receipts \(-x = (1, -2, 2)\), whose mean is \(1/3\).
 500| Emp 3 · The zero-posterior bets
 502| Show that a bet has \(g_1 = g_2 = 0\) on \(\{1, 2, 3\}\) if and only if \(x(3) = 0\) and \(x(2) = -x(1)\). Check the count of 625 against this description.
 504| Solution
 506| Trader 1's posterior is zero on the cell \(\{1, 2\}\) when \(x(1) + x(2) = 0\), and on the cell \(\{3\}\) when \(x(3) = 0\). Trader 2's posterior on the cell \(\{1, 2, 3\}\) is zero when \(x(1) + x(2) + x(3) = 0\), which holds given the first two conditions. So the condition is \(x(3) = 0\) and \(x(2) = -x(1)\). Then \(x(1)\) takes 5 values, \(x(4)\), \(x(5)\) and \(x(6)\) are free with 5 values each, and the count is \(5 \cdot 5^3 = 625\), which matches the printed count.

 517| Res 1 · A transaction cost removes every candidate
 519| Suppose trader 2 pays a fixed cost \(k > 0\) in addition to receiving \(-x\). Show that no bet \(x\) can have \(g_1 \ge 0\) and \(g_2 \ge 0\) on the meet of a state, with trader 2's receipts \(-x - k\).
 521| Solution
 523| Let \(M\) be the meet. The first condition gives \(S_1 = \sum_{M}\pi x \ge 0\), by the identity of Proof 1. The second condition gives \(\sum_{M}\pi(-x - k) \ge 0\), that is \(-S_1 - k\,\pi(M) \ge 0\). Adding the two gives \(-k\,\pi(M) \ge 0\), which contradicts \(k > 0\) and \(\pi(M) > 0\). So no bet satisfies both conditions.
 528| Res 2 · Strict acceptance with two priors
 530| Two states \(H\) and \(L\) have trivial partitions, and the traders have priors \(q_1(H) = \nu_1\) and \(q_2(H) = \nu_2\), with \(\nu_1 \ne \nu_2\) and \(0 < \nu_1, \nu_2 < 1\), as B1 requires for state probabilities. Show that there is a bet with strictly positive expected receipts for both traders.
 532| Solution
 534| Take a bet with \(x(H) = 1\) and \(x(L) = -t\) for \(t > 0\). Trader 1's expected receipt is \(\nu_1 - (1 - \nu_1)t\). Trader 2's expected receipt of \(-x\) is \(-(\nu_2 - (1 - \nu_2)t) = (1 - \nu_2)t - \nu_2\). Set \(\theta = t/(1+t)\), so that \(1 - \theta = 1/(1+t)\). Trader 1's receipt is \((\nu_1 - \theta)/(1 - \theta) = (1 + t)(\nu_1 - \theta)\), and trader 2's is \((\theta - \nu_2)/(1 - \theta) = (1 + t)(\theta - \nu_2)\). Both are positive when \(\nu_2 < \theta < \nu_1\). Let \(\nu_2 < \nu_1\) and take \(\theta = (\nu_1 + \nu_2)/2\), which lies strictly between \(\nu_2\) and \(\nu_1\), and in \((0, 1)\) because \(0 < \nu_2 < \nu_1 < 1\). Then \(t = \theta/(1 - \theta) > 0\) gives the bet. If \(\nu_1 < \nu_2\), exchange the labels \(H\) and \(L\). The priors of \(H\) become \(1 - \nu_1\) and \(1 - \nu_2\), with \(1 - \nu_2 < 1 - \nu_1\), so the first case applies.
 539| Res 3 · The statement on any shared meet
 541| Let \(E\) be any set that is a union of cells of both \(\mathcal{P}_1\) and \(\mathcal{P}_2\). Show that if \(g_1 \ge 0\) and \(g_2 \ge 0\) on \(E\), then \(g_1 = g_2 = 0\) on \(E\).
 543| Solution
 545| The proof of Theorem 2.1 uses that \(M\) is a union of cells of both partitions and that every cell has positive prior probability (Assumption B1). Replace \(M\) by \(E\), which is also a union of cells of both partitions, so the same B1 reasoning applies. The sums \(S_1 = \sum_E\pi x\) and \(S_2 = -S_1\) are computed in the same way, the argument gives \(S_1 = 0\), and then each cell of \(\mathcal{P}_1\) in \(E\) and each cell of \(\mathcal{P}_2\) in \(E\) has zero posterior. The result therefore holds for every such \(E\), not only for the meet.
