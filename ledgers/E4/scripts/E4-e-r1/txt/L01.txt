00020 A price is attached to a payment due only in some future state of the world. A market can value such a payment only after the model says what the states are, what a payment in each state is, and how payments are priced. This lesson fixes those objects on a finite state space. It defines the Arrow–Debreu security (Definition 1.3), which pays in a single state, and proves that every claim (Definition 1.2) is a weighted sum of these securities (Proposition 1.4, under A1). Under the linear valuation of Assumption A2 (§3), a claim's value is the sum of security prices (Definition 1.6) times payoffs. Lesson L02 uses these prices to define equilibrium.
00021 1States, claims and probabilities
00022 Definition 1.1 (state space)
00023 A
00024 state space
00025 is a finite set \(\Omega = \{1, \ldots, S\}\) of states, one of which is realized. Each state \(s\) has a probability \(\pi_s\). Probabilities are numbers with \(\pi_s > 0\) and \(\sum_{s=1}^{S} \pi_s = 1\).
00026 Assumption A1 (finite, strictly positive states)
00027 The state space \(\Omega\) of Definition 1.1 has \(S < \infty\) states, and \(\pi_s > 0\) for every \(s\). Every result of this lesson that writes a sum over states uses A1. No result here allows infinitely many states.
00028 Definition 1.2 (claim)
00029 A
00030 claim
00031 is a vector \(x = (x_1, \ldots, x_S) \in \R^{S}\). Its entry \(x_s\) is the payoff in cents that the claim delivers in state \(s\). A claim is the random variable \(X\) on \(\Omega\) with \(X(s) = x_s\), so \(X\) takes the value \(x_s\) in state \(s\). \(\Prob(X = x_s)\) equals \(\pi_s\) exactly when no other state has the same payoff. Payoffs may be negative, which is a promise to pay.
00032 2Arrow–Debreu securities and decomposition
00033 Definition 1.3 (Arrow–Debreu security)
00034 For a state \(s\), the
00035 Arrow–Debreu security
00036 of state \(s\) is the claim \(e_s\) with entries \((e_s)_t = 1\) when \(t = s\) and \((e_s)_t = 0\) when \(t \ne s\). It pays one cent in state \(s\) and nothing in any other state.
00037 Proposition 1.4 (decomposition into securities)
00038 Assume A1. Every claim \(x \in \R^{S}\) satisfies
00039 \[
00040 x = \sum_{s=1}^{S} x_s\, e_s .
00041 \]
00042 The coefficient of the security of state \(s\) is the payoff \(x_s\) of the claim in that state.
00043 Proof
00044 Fix a state \(t\). The entry of the right-hand side in state \(t\) is \(\sum_{s=1}^{S} x_s (e_s)_t\). By Definition 1.3, \((e_s)_t\) equals 1 when \(s = t\) and 0 otherwise, so the sum has the single nonzero term \(x_t\). The entry of the left-hand side in state \(t\) is \(x_t\). The two vectors agree in every state. The sum is finite because A1 gives \(S < \infty\). The proof uses no probability, so it holds for any positive \(\pi\).
00045 Example 1.5 (a claim on four states)
00046 Let \(S = 4\), with \(\pi = (\tfrac18, \tfrac38, \tfrac38, \tfrac18)\), and let the claim be \(x = (100, 40, 0, 250)\) cents. Proposition 1.4 gives \(x = 100\, e_1 + 40\, e_2 + 0\, e_3 + 250\, e_4\). The coefficient on \(e_3\) is zero because the claim pays nothing in state 3. Lab 1 uses these four states, numbered 0 to 3 in its code, and prints the same decomposition.
00047 3Valuation and the prices of the securities
00048 Assumption A2 (linear valuation)
00049 A valuation is a map \(V\) from claims to cents, and it is linear: for all claims \(x\) and \(y\) and all real numbers \(a\) and \(b\),
00050 \[
00051 V(a x + b y) = a\, V(x) + b\, V(y).
00052 \]
00053 A2 excludes quantity discounts, bid-ask spreads and price impact. Each of them makes \(V\) depend on the size or the direction of a trade, so \(V\) need not be linear. A2 is an assumption about the market, and this lesson does not derive it.
00054 Definition 1.6 (security price vector)
00055 Under A2, the
00056 security price
00057 of state \(s\) is \(q_s = V(e_s)\), in cents of value per cent of payoff, and it is a dimensionless number. The
00058 price vector
00059 is \(q = (q_1, \ldots, q_S)\). The vector \(q\) is called the Arrow–Debreu security price vector.
00060 Proposition 1.7 (value formula)
00061 Assume A1 and A2. For every claim \(x\),
00062 \[
00063 V(x) = \sum_{s=1}^{S} q_s\, x_s .
00064 \]
00065 Assuming A2 for the valuation \(V\), the value of a claim is determined by the security prices and the payoffs alone.
00066 Proof
00067 By Proposition 1.4, \(x = \sum_{s} x_s e_s\). A2 with two terms gives \(V(a x + b y) = a V(x) + b V(y)\). Applying it repeatedly, by induction on the number of summands, gives \(V\bigl(\sum_{s} x_s e_s\bigr) = \sum_{s} x_s V(e_s)\), which is finite because A1 gives \(S < \infty\). Substituting \(q_s = V(e_s)\) from Definition 1.6 gives the formula.
00068 Proposition 1.8 (the prices are unique)
00069 Assume A1 and A2. Suppose a vector \(r \in \R^{S}\) satisfies \(V(x) = \sum_{s} r_s x_s\) for every claim \(x\). Then \(r_s = q_s\) for every state \(s\), where \(q\) is the price vector of Definition 1.6 under A2.
00070 Proof
00071 Take \(x = e_s\) in the hypothesis. Then \(V(e_s) = \sum_t r_t (e_s)_t = r_s\), by Definition 1.3. Also \(V(e_s) = q_s\) by Definition 1.6. Hence \(r_s = q_s\).
00072 Definition 1.9 (expected payoff)
00073 The
00074 expected payoff
00075 of a claim is \(\E x = \sum_{s} \pi_s x_s\), the average payoff weighted by the probabilities of Definition 1.1. It is the expectation of the random variable of Definition 1.2.
00076 Proposition 1.10 (value equals expected payoff exactly when prices are probabilities)
00077 Assume A1 and A2. The following two statements are equivalent.
00078 (a) \(V(x) = \E x\) for every claim \(x\).
00079 (b) \(q_s = \pi_s\) for every state \(s\).
00080 Proof
00081 Assume (b). Proposition 1.7 gives \(V(x) = \sum_s \pi_s x_s = \E x\) for every \(x\), which is (a). Now assume (a). For the security \(e_s\), Definition 1.9 gives \(\E e_s = \sum_t \pi_t (e_s)_t = \pi_s\). Taking \(x = e_s\) in (a) gives \(q_s = V(e_s) = \E e_s = \pi_s\), which is (b).
00082 Remark 1.11 (a price is not a probability)
00083 Proposition 1.10 says that prices and probabilities coincide only in the special case (b). Nothing in A1 or A2 forces (b). A security price \(q_s\) depends on how the market values state \(s\), and the probability \(\pi_s\) is an input to the model. Lab 1 Part D shows that the value under the prices differs from the expected payoff for the claim of Example 1.5, so by Proposition 1.10 the prices differ from the probabilities.
00084 Lab 1 · Decomposition and valuation of a four-state claim
00085 The lab uses no data. It computes exactly, with Fraction values, on the four states of Example 1.5, numbered 0 to 3 in the code. Before running it, the hypothesis is this. The printed decomposition gives coefficients 100, 40, 0 and 250 on the four securities, and it rebuilds the claim exactly (Proposition 1.4). Under the prices \((\tfrac12, \tfrac13, \tfrac14, \tfrac15)\), the claim has value \(340/3\) cents, and the second claim has value 56 cents (Proposition 1.7). Linearity holds exactly on a combination with weights 2 and \(-\tfrac12\) (A2). The expected payoff of the claim is \(235/4\) cents, and it differs from the value under these prices (Proposition 1.10). A probability vector with a negative entry, and one whose entries sum to \(9/8\), are each rejected with a ValueError. No random draws are used, so every run prints the same lines.
00086 """E4 L01 lab 1: Arrow-Debreu decomposition and valuation of a claim on four states, computed exactly.
00087 Inputs are illustrative numbers, not data. The state space has four states. State s has the probability
00088 STATE_PROBABILITIES[s], a positive exact Fraction, and the probabilities sum to exactly 1. A claim is a payoff vector
00089 in whole cents, one entry per state. An Arrow-Debreu security s pays 1 in state s and 0 in every other state. Its
00090 price PRICES[s] is a dimensionless exact Fraction, so a claim's value in cents is the sum of price times payoff.
00091 Part A: the decomposition of the claim into Arrow-Debreu securities, checked state by state.
00092 Part B: the value of the claim under the prices, and of a second claim.
00093 Part C: linearity of the value map in the payoff, checked exactly on a combination with a negative weight.
00094 Part D: the expected payoff under the probabilities, and the value when the prices are the probabilities.
00095 Part E: a probability vector with a negative entry, and one whose entries do not sum to 1, are rejected.
00096 No random draws are used, so every run prints the same lines.
00097 """
00098 from __future__ import annotations
00099 from fractions import Fraction
00100 Payoff = tuple[Fraction, ...]
00101 STATE_PROBABILITIES: Payoff = (Fraction(1, 8), Fraction(3, 8), Fraction(3, 8), Fraction(1, 8))
00102 PRICES: Payoff = (Fraction(1, 2), Fraction(1, 3), Fraction(1, 4), Fraction(1, 5))
00103 CLAIM: Payoff = (Fraction(100), Fraction(40), Fraction(0), Fraction(250))
00104 OTHER: Payoff = (Fraction(0), Fraction(60), Fraction(120), Fraction(30))
00105 def check_probabilities(probabilities: Payoff) -> None:
00106 """Raise ValueError unless every probability is positive and the probabilities sum to exactly 1."""
00107 if any(p <= 0 for p in probabilities):
00108 raise ValueError("state probabilities must be positive")
00109 if sum(probabilities, Fraction(0)) != 1:
00110 raise ValueError("state probabilities must sum to 1")
00111 def security(state: int, n_states: int) -> Payoff:
00112 """The payoff vector of the Arrow-Debreu security for one state: 1 in that state and 0 in every other state."""
00113 return tuple(Fraction(1 if t == state else 0) for t in range(n_states))
00114 def value(payoff: Payoff, prices: Payoff) -> Fraction:
00115 """The value of a claim, the sum over states of price times payoff, in cents, as an exact Fraction."""
00116 if len(payoff) != len(prices):
00117 raise ValueError("payoff and prices must have one entry per state")
00118 return sum((q * x for q, x in zip(prices, payoff, strict=True)), Fraction(0))
00119 def expected_payoff(payoff: Payoff, probabilities: Payoff) -> Fraction:
00120 """The probability-weighted average payoff in cents, the sum over states of probability times payoff."""
00121 return sum((p * x for p, x in zip(probabilities, payoff, strict=True)), Fraction(0))
00122 def combine(a: Fraction, x: Payoff, b: Fraction, y: Payoff) -> Payoff:
00123 """The payoff a times x plus b times y, state by state, with exact Fractions."""
00124 return tuple(a * xi + b * yi for xi, yi in zip(x, y, strict=True))
00125 def main() -> None:
00126 """Print Parts A to E. Every value is an exact Fraction, so the output is reproducible."""
00127 n_states = len(STATE_PROBABILITIES)
00128 check_probabilities(STATE_PROBABILITIES)
00129 print("Part A: decomposition of the claim into Arrow-Debreu securities")
00130 rebuilt = [Fraction(0)] * n_states
00131 for state in range(n_states):
00132 payoff_of_security = security(state, n_states)
00133 coefficient = CLAIM[state]
00134 print(f"security {state} coefficient {coefficient} pays {tuple(str(z) for z in payoff_of_security)}")
00135 for t in range(n_states):
00136 rebuilt[t] += coefficient * payoff_of_security[t]
00137 print(f"rebuilt payoff {tuple(str(z) for z in rebuilt)} claim {tuple(str(z) for z in CLAIM)}")
00138 print(f"decomposition_exact {tuple(rebuilt) == CLAIM}")
00139 print("Part B: value under the prices, in cents")
00140 print(f"value_of_claim {value(CLAIM, PRICES)} value_of_other {value(OTHER, PRICES)}")
00141 print("Part C: linearity of the value in the payoff")
00142 combined = combine(Fraction(2), CLAIM, Fraction(-1, 2), OTHER)
00143 lhs = value(combined, PRICES)
00144 rhs = 2 * value(CLAIM, PRICES) - Fraction(1, 2) * value(OTHER, PRICES)
00145 print(f"combined_payoff {tuple(str(z) for z in combined)}")
00146 print(f"value_of_combination {lhs} linear_combination_of_values {rhs} equal {lhs == rhs}")
00147 print("Part D: expected payoff and value at the probabilities")
00148 expected = expected_payoff(CLAIM, STATE_PROBABILITIES)
00149 print(f"expected_payoff_claim {expected}")
00150 print(f"value_at_probability_prices {value(CLAIM, STATE_PROBABILITIES)}")
00151 print(f"value_at_prices {value(CLAIM, PRICES)} equal_to_expected_payoff {value(CLAIM, PRICES) == expected}")
00152 print("Part E: invalid probability vectors are rejected")
00153 negative = (Fraction(1, 2), Fraction(1, 2), Fraction(1, 2), Fraction(-1, 2))
00154 overweight = (Fraction(1, 8), Fraction(3, 8), Fraction(3, 8), Fraction(1, 4))
00155 for label, bad in (("negative", negative), ("overweight", overweight)):
00156 try:
00157 check_probabilities(bad)
00158 except ValueError as exc:
00159 print(f"rejected {label} message {exc}")
00160 main()

00181 4Where the canon breaks
00182 Finitely many states. Proposition 1.4 is a finite sum, and Proposition 1.7 applies A2 finitely many times (A1). With countably many states, the decomposition still holds coordinate by coordinate, but the step from finite to infinite sums in Proposition 1.7 is not justified by this lesson, and the formula for infinite \(S\) is not derived here. Research problem R1 identifies that step.
00183 Linearity is an assumption. A2 says that a combination of claims is worth the same combination of values, with no discount for size. Under a quantity discount or a size premium, \(V(2x)\) can differ from \(2V(x)\). In that case A2 fails and Proposition 1.7 does not apply (Problem R2).
00184 Every security must be priced. Definition 1.6 needs \(V(e_s)\) for each state. If the market cannot deliver the security of some state, \(q_s\) is not defined by this lesson. Lesson L04 treats this case through the rank of the payoff matrix.
00185 Probabilities are given. The lesson takes \(\pi\) as an input and does not derive it from beliefs or data. Proposition 1.7 makes the value of a claim depend on \(q\), and Proposition 1.10 shows that \(q\) need not equal \(\pi\).
00186 5Misconceptions
00187 “The price of the security for a state is that state's probability.”
00188 Proposition 1.10 says the two coincide only under condition (b), and Remark 1.11 says nothing in A1 or A2 forces it. Lab 1 uses prices \((\tfrac12, \tfrac13, \tfrac14, \tfrac15)\) and probabilities \((\tfrac18, \tfrac38, \tfrac38, \tfrac18)\), which differ in every state. Part D prints the line that reads False.
00189 “A claim that pays in several states needs its own price, so a market with \(S\) states must price every combination of states.”
00190 Proposition 1.7 gives the value of every claim from the \(S\) security prices. Lab 1 Part B values two different claims, 340/3 and 56 cents, from the same four prices, with no further price needed.
00191 “The decomposition works only when the states are equally likely.”
00192 Proposition 1.4 uses no probability, so it holds for every positive \(\pi\). Lab 1 checks its unequal probabilities \((\tfrac18, \tfrac38, \tfrac38, \tfrac18)\) once, at the start of main(), before Part A. Part A's decomposition uses only the claim, so the rebuilt payoff equals the claim exactly.

00195 Mechanics
00196 M1 · Decompose and value a three-state claim
00197 Let \(S = 3\), \(\pi = (\tfrac12, \tfrac14, \tfrac14)\), and the claim \(x = (10, 0, 30)\) cents. Write \(x\) as a combination of securities. Under the prices \(q = (\tfrac13, \tfrac15, \tfrac12)\), find \(V(x)\) and \(\E x\), and compare them.
00198 Solution
00199 By Proposition 1.4, \(x = 10\, e_1 + 0\, e_2 + 30\, e_3\). By Proposition 1.7, \(V(x) = 10 \cdot \tfrac13 + 0 \cdot \tfrac15 + 30 \cdot \tfrac12 = \tfrac{10}{3} + 15 = \tfrac{55}{3}\) cents, which is about 18.33 cents to two decimal places. The expected payoff is \(\E x = 10 \cdot \tfrac12 + 0 \cdot \tfrac14 + 30 \cdot \tfrac14 = 5 + 7.5 = 12.5\) cents. The value exceeds the expected payoff by \(\tfrac{55}{3} - \tfrac{25}{2} = \tfrac{35}{6}\) cents. By Proposition 1.10, this difference shows that \(q \ne \pi\).
00200 M2 · Value of a claim that pays in one state
00201 A two-state claim pays 0 cents in state 1 and 50 cents in state 2. The security prices are \(q_1 = 0.4\) and \(q_2 = 0.5\). Find the value of the claim, and state which proposition gives it.
00202 Solution
00203 The claim is \(x = (0, 50) = 50\, e_2\), by Proposition 1.4. Proposition 1.7 gives \(V(x) = 0.4 \cdot 0 + 0.5 \cdot 50 = 25\) cents. The price of state 1 does not enter, because the claim pays nothing in state 1, which is the reason the value depends only on \(q_2\) here.
00204 M3 · A combination of two claims
00205 Let \(x = (1, 2, 3)\), \(y = (4, 0, 1)\) and \(q = (\tfrac12, \tfrac14, \tfrac18)\). Compute \(V(3x - 2y)\) directly from its payoffs, and again from \(V(x)\) and \(V(y)\) using A2, and check that the two answers agree.
00206 Solution
00207 The combination is \(3x - 2y = (3 - 8, 6 - 0, 9 - 2) = (-5, 6, 7)\). By Proposition 1.7, \(V = -5 \cdot \tfrac12 + 6 \cdot \tfrac14 + 7 \cdot \tfrac18 = -\tfrac{20}{8} + \tfrac{12}{8} + \tfrac{7}{8} = -\tfrac18\). Separately, \(V(x) = \tfrac12 + \tfrac12 + \tfrac38 = \tfrac{11}{8}\) and \(V(y) = 2 + 0 + \tfrac18 = \tfrac{17}{8}\). Then A2 gives \(3 \cdot \tfrac{11}{8} - 2 \cdot \tfrac{17}{8} = \tfrac{33 - 34}{8} = -\tfrac18\). The two answers agree.

00209 P1 · The riskless one-cent claim
00210 Let \(\iota\) be the vector of ones, \(\iota = (1, \ldots, 1)\), which is the claim that pays one cent in every state. Show that \(\iota = \sum_{s} e_s\), and that \(V(\iota) = \sum_{s} q_s\) under A1 and A2.
00211 Solution
00212 For each state \(t\), the entry of \(\sum_{s} e_s\) in state \(t\) is \(\sum_{s} (e_s)_t\). By Definition 1.3 exactly one term, the one with \(s = t\), equals 1, so the entry is 1 in every state, and \(\sum_{s} e_s = \iota\). Proposition 1.7 applied to \(x = \iota\) gives \(V(\iota) = \sum_{s} q_s \cdot 1 = \sum_{s} q_s\). The value of a sure cent is the sum of the security prices.
00213 P2 · Value of the zero claim and of a reversed claim
00214 Under A2, show that \(V(0) = 0\) for the zero claim, and that \(V(-x) = -V(x)\) for every claim \(x\).
00215 Solution
00216 Take \(a = 0\) and \(b = 0\) in A2 with any claim \(x\) and \(y = x\): \(V(0 \cdot x + 0 \cdot x) = 0 \cdot V(x) + 0 \cdot V(x) = 0\), so \(V(0) = 0\). Take \(a = -1\) and \(b = 0\): \(V(-x) = -1 \cdot V(x) + 0 \cdot V(x) = -V(x)\). Both follow from A2 alone.
00217 P3 · Prices that differ from probabilities, two states
00218 Let \(S = 2\), \(\pi = (\tfrac13, \tfrac23)\) and \(q = (\tfrac14, \tfrac12)\), with \(V\) linear and defined by Proposition 1.7. Show that \(V(x) \ne \E x\) for some claim \(x\), and identify the claim.
00219 Solution
00220 Take \(x = e_1\), which pays one cent in state 1. Then \(V(e_1) = q_1 = \tfrac14\), while \(\E e_1 = \pi_1 = \tfrac13\). Since \(\tfrac14 \ne \tfrac13\), the equality of Proposition 1.10 fails for \(x = e_1\), and so statement (a) fails. This is the contrapositive of Proposition 1.10, which says that (a) forces \(q = \pi\). It is not a counterexample to a converse, because Proposition 1.10 proves both directions.

00230 E3 · What Part D shows about prices and probabilities
00231 Part D of Lab 1 prints an expected payoff, a value at the probabilities, and a value at the prices with a flag. What do the three printed numbers equal, and what does the flag say?
00232 Solution

The value at the prices is \(340/3 \approx 113.33\) cents, rounded to two decimal places from \(340/3\), and the flag reads False. So the prices are not the probabilities, and the value under the prices differs from the expected payoff.
00234 Research
00235 R1 · Infinitely many states
00236 Let the state space be countable, with \(\pi_s > 0\) and \(\sum_s \pi_s = 1\). Identify the step of the proof of Proposition 1.7 that is not justified when \(S\) is infinite.
00237 Solution
00238 The decomposition still holds coordinate by coordinate, because in each state only one term of \(\sum_s x_s e_s\) is nonzero. The step that is not justified is the application of A2 to an infinite sum, since A2 is stated for two terms and induction on the number of summands gives finite sums only. This lesson therefore derives the formula \(V(x) = \sum_s q_s x_s\) for finite \(S\) only, and it does not derive that formula for infinite \(S\).
00239 R2 · A size effect breaks linearity
00240 Let \(V(x) = \bigl(\sum_s q_s x_s\bigr)^2\), which applies a size effect to the value. With \(q_1 = \tfrac12\), compute \(V(e_1)\) and \(V(2 e_1)\), and state which assumption fails.
00241 Solution
00242 We have \(V(e_1) = (\tfrac12)^2 = \tfrac14\) and \(V(2e_1) = (2 \cdot \tfrac12)^2 = 1\). Linearity would require \(V(2e_1) = 2V(e_1) = \tfrac12\), which fails. So A2 fails, and Proposition 1.7 does not apply to this \(V\). The formula \(\sum_s q_s x_s\) is then not the value of the claim.
00243 R3 · When nonnegative claims have nonnegative value
00244 Under A1 and A2, show that \(V(x) \ge 0\) for every claim with \(x_s \ge 0\) for all \(s\) if and only if \(q_s \ge 0\) for all \(s\).
00245 Solution
00246 If every \(q_s \ge 0\) and every \(x_s \ge 0\), then \(V(x) = \sum_s q_s x_s \ge 0\) by Proposition 1.7. Conversely, if \(V(x) \ge 0\) for every nonnegative claim, take \(x = e_s\), which is nonnegative. Then \(q_s = V(e_s) \ge 0\) by Definition 1.6. Both directions use only Proposition 1.7 and the definition of the prices.
