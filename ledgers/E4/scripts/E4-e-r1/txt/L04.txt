00020 In the finite model of this lesson, whether a payoff can be bought depends on the rank of the matrix of security payoffs. This lesson gives the exact test for completeness in that model: the rank of the payoff matrix. The test is a computation, and the exact arithmetic of the lab leaves no tolerance in the verdict. The last section shows that the finite test does not carry over to infinitely many states. Section 1 defines the terms used here (the payoff matrix, portfolios, attainable payoffs, rank and complete markets, in Definitions 1.1 and 1.3).
00021 1Attainable payoffs and complete markets
00022 Assumptions
00023 A1 (finite states). The state space has \(S\) elements, with \(1 \le S < \infty\). A payoff is a vector in \(\R^S\), with one real entry per state.
00024 A2 (finitely many securities). There are \(J\) securities, with \(1 \le J < \infty\). Security \(j\) pays the real amount \(A_{jk}\) in state \(k\).
00025 A3 (unrestricted holdings). A portfolio is any \(\zeta \in \R^J\). Each entry may be positive or negative, so short positions are allowed.
00026 Definition 1.1 (payoff matrix, portfolio, attainable payoff)
00027 Under A1 and A2, the
00028 payoff matrix
00029 is the \(J \times S\) real matrix \(A\) with entries \(A_{jk}\). A
00030 portfolio
00031 is a vector \(\zeta \in \R^J\), and its payoff is the row vector \(\zeta^\top A \in \R^S\), whose entry in state \(k\) is \(\sum_{j=1}^{J} \zeta_j A_{jk}\). A payoff \(\xi \in \R^S\) is
00032 attainable
00033 when \(\xi = \zeta^\top A\) for some portfolio \(\zeta\).
00034 Lemma 1.2 (the attainable payoffs form the row space)
00035 Let \(M(A) = \{\zeta^\top A : \zeta \in \R^J\}\) be the set of attainable payoffs. Under A1 to A3, \(M(A)\) is a linear subspace of \(\R^S\), and it equals the
00036 row space
00037 of \(A\), the set of all linear combinations of the \(J\) rows of \(A\).
00038 Proof. The map \(\zeta \mapsto \zeta^\top A\) from \(\R^J\) to \(\R^S\) is linear, because \((a\zeta + b\phi)^\top A = a\,\zeta^\top A + b\,\phi^\top A\). The image of a linear map is a subspace, so \(M(A)\) is a subspace. Writing \(\zeta = \sum_j \zeta_j e_j\) with the standard basis \(e_j\) of \(\R^J\) gives \(\zeta^\top A = \sum_j \zeta_j\,(\text{row } j \text{ of } A)\). So \(M(A)\) is exactly the set of linear combinations of the rows. \(\square\)
00039 Definition 1.3 (rank; complete and incomplete markets)
00040 The
00041 rank
00042 of \(A\) is \(\operatorname{rank}(A) = \dim \operatorname{row}(A)\), the dimension of its row space. The market is
00043 complete
00044 when \(M(A) = \R^S\), so that every payoff in \(\R^S\) is attainable. It is
00045 incomplete
00046 otherwise.
00047 Theorem 1.4 (completeness criterion)
00048 Under A1 to A3, the market is complete if and only if \(\operatorname{rank}(A) = S\).
00049 Proof. By Lemma 1.2 and Definition 1.3, \(M(A) = \operatorname{row}(A)\) and \(\dim M(A) = \operatorname{rank}(A)\). The row space is a subspace of \(\R^S\), so its dimension is at most \(S\). If \(\operatorname{rank}(A) = S\), then \(M(A)\) is a subspace of \(\R^S\) with the full dimension \(S\). In a finite-dimensional vector space a subspace of full dimension is the whole space (a basis of the subspace is \(S\) linearly independent vectors in \(\R^S\), and \(S\) such vectors span \(\R^S\)). So \(M(A) = \R^S\). Conversely, if \(M(A) = \R^S\), then \(\operatorname{rank}(A) = \dim \R^S = S\). \(\square\)
00050 Proposition 1.5 (the attainability test)
00051 Under A1 to A3, a payoff \(\xi \in \R^S\) is attainable if and only if \(\operatorname{rank}\bigl([A;\,\xi]\bigr) = \operatorname{rank}(A)\), where \([A;\,\xi]\) is the matrix \(A\) with \(\xi\) appended as one more row. Its rank is the
00052 augmented rank
00053 of \(\xi\).
00054 Proof. The row space of \([A;\,\xi]\) is \(\operatorname{row}(A) + \operatorname{span}(\xi)\), which contains \(\operatorname{row}(A)\). The payoff \(\xi\) is attainable if and only if \(\xi \in \operatorname{row}(A)\), that is, if and only if \(\operatorname{row}([A;\,\xi]) = \operatorname{row}(A)\). A subspace that contains \(\operatorname{row}(A)\) equals it exactly when the two have the same dimension. So \(\xi\) is attainable if and only if the two ranks agree. \(\square\)
00055 Corollary 1.6 (a complete market needs at least S securities)
00056 Under A1 to A3, if the market is complete then \(J \ge S\).
00057 Proof. The row space is spanned by \(J\) vectors, so its dimension is at most \(J\). A complete market has \(\operatorname{rank}(A) = S\) by Theorem 1.4, so \(S \le J\). \(\square\)
00058 2Rank by elimination, with two examples
00059 Assumption A0 (real entries)
00060 \(A\) is a real \(J \times S\) matrix, with real entries, so that the multiples used in elimination (an entry divided by a nonzero pivot) are defined.
00061 Lemma 2.1 (elimination counts the rank)
00062 Apply to \(A\) the row operations of two kinds: swap two rows, and add a multiple of one row to another. Each operation leaves the row space unchanged. After the operations, the matrix is in
00063 echelon form
00064 : each nonzero row has a
00065 pivot
00066 , its first nonzero entry, and the pivots lie in strictly increasing columns, with the rows below the pivot row having zeros in its column. The number of pivots equals \(\operatorname{rank}(A)\).
00067 Proof. Under A0 every entry is real, so the division by a pivot is defined. A swap changes only the order of the rows. Adding a multiple of row \(i\) to row \(l\), with \(i \ne l\), gives a row that is a combination of old rows, and the old row \(l\) is recovered by subtracting the same multiple, so the two row sets span the same space. The echelon form is reached in finitely many steps: take the first column with a nonzero entry, swap a row with a nonzero entry there to the top, and subtract multiples of that row from the rows below to clear the column. Repeat on the rows below the top row and the columns to the right of that column. For the count, let the nonzero rows be \(r_1, \dots, r_m\), with pivots in columns \(q_1 < \dots < q_m\). Suppose \(\sum_i c_i r_i = 0\) with some \(c_i \ne 0\), and let \(i\) be the smallest such index. Rows \(r_l\) with \(l > i\) have zeros in column \(q_i\), because \(q_l > q_i\). Rows \(r_l\) with \(l < i\) have \(c_l = 0\). So the column-\(q_i\) entry of the sum is \(c_i\) times the pivot of \(r_i\), which is nonzero, and the sum cannot be zero. Hence the rows are linearly independent, and they span the row space, so \(m = \dim \operatorname{row}(A) = \operatorname{rank}(A)\). \(\square\)
00068 Example 2.2 (an incomplete market with two securities in three states)
00069 Let \(A\) have rows \(r_1 = (1, 1, 1)\) and \(r_2 = (0, 1, 2)\). The rows are independent: if \(a r_1 + b r_2 = 0\), the first coordinate gives \(a = 0\), and then the second gives \(b = 0\). So \(\operatorname{rank}(A) = 2\), and \(2 < S = 3\). By Theorem 1.4 the market is incomplete.
00070 Test two payoffs with Proposition 1.5. For \(\xi = (1,2,3)\), \(\xi = r_1 + r_2\), so \(\xi\) is attainable with \(\zeta = (1,1)\). For \(\xi = (0,0,1)\), suppose \(a r_1 + b r_2 + c\,\xi = 0\). The first coordinate gives \(a = 0\), the second gives \(a + b = 0\), so \(b = 0\), and the third gives \(a + 2b + c = 0\), so \(c = 0\). The three rows \(r_1, r_2, \xi\) are independent, so \(\operatorname{rank}([A;\,\xi]) = 3 \ne 2\), and \((0,0,1)\) is not attainable.
00071 Example 2.3 (a complete market with a redundant security)
00072 Let \(A\) have four rows: \(e_1 = (1,0,0)\), \(e_2 = (0,1,0)\), \(e_3 = (0,0,1)\), and \(r_4 = (1,2,3)\). The first three rows are independent, so the rank is at least 3, and it is at most \(S = 3\). So \(\operatorname{rank}(A) = 3\), and the market is complete by Theorem 1.4. The fourth security is redundant, because \(r_4 = 1\cdot e_1 + 2\cdot e_2 + 3\cdot e_3\). The row space is unchanged by adding \(r_4\), since it is already spanned by \(e_1, e_2, e_3\).
00073 Lab 1 · Rank by exact elimination and the completeness test
00074 The two payoff matrices of Examples 2.2 and 2.3 are tested in exact Fractions. The expected result: the two-security matrix has rank 2, below its three states, so it is incomplete; the four-security matrix has rank 3 and is complete. In the incomplete market \((1,2,3)\) is attainable, and \((0,0,1)\) and \((5,0,0)\) are not. In the complete market all three payoffs are attainable, and the fourth security equals the combination of the first three with weights 1, 2 and 3.
00075 """E4 L04 lab 1: rank of a payoff matrix by exact Gaussian elimination, and the completeness test.
00076 Inputs are illustrative numbers, not data. A payoff matrix has one row per traded security and one column per state.
00077 Entry (j, k) is the payoff of security j in state k, in whole units of one common payoff unit. Two matrices are used: an
00078 incomplete market with two securities in three states, and a complete market with four securities in three states,
00079 one of which is a redundant combination of the other three.
00080 The rank of a matrix is the number of pivots that exact Gaussian elimination produces. The market is complete when the
00081 rank equals the number of states S. A payoff vector xi in the states is attainable when some portfolio zeta reproduces
00082 it, that is, when xi lies in the row space of the matrix. That holds exactly when the rank of the matrix with xi
00083 appended as one more row equals the rank of the matrix.
00084 Part A: the rank of each matrix, computed in exact Fractions.
00085 Part B: the completeness test, rank equal to the number of states, for each matrix.
00086 Part C: attainability of three payoff vectors in the incomplete market, tested by the augmented rank.
00087 Part D: attainability of the same three payoff vectors in the complete market.
00088 Part E: a redundant security leaves the rank unchanged.
00089 No random draws are used, so every run prints the same lines.
00090 """
00091 from __future__ import annotations
00092 from fractions import Fraction
00093 Row = list[Fraction]
00094 Matrix = list[Row]
00095 def vec(*values: int) -> Row:
00096 """A row of exact Fractions from integers, one entry per state."""
00097 return [Fraction(v) for v in values]
00098 INCOMPLETE: Matrix = [vec(1, 1, 1), vec(0, 1, 2)]
00099 COMPLETE: Matrix = [vec(1, 0, 0), vec(0, 1, 0), vec(0, 0, 1), vec(1, 2, 3)]
00100 CLAIMS: tuple[tuple[str, Row], ...] = (
00101 ("(1,2,3)", vec(1, 2, 3)),
00102 ("(0,0,1)", vec(0, 0, 1)),
00103 ("(5,0,0)", vec(5, 0, 0)),
00104 )
00105 def check_matrix(matrix: Matrix) -> int:
00106 """Return the number of states (the number of columns), or raise ValueError if the matrix is not rectangular."""
00107 if not matrix or not matrix[0]:
00108 raise ValueError("payoff matrix must have at least one security and one state")
00109 width = len(matrix[0])
00110 if any(len(row) != width for row in matrix):
00111 raise ValueError("every security must pay in the same states")
00112 return width
00113 def rank(matrix: Matrix) -> int:
00114 """The rank of a rectangular matrix of exact Fractions, the number of pivots found by Gaussian elimination.
00115 Each pivot is the first nonzero entry in its column among the rows not yet used. Rows are eliminated below and
00116 above each pivot, so the arithmetic stays exact and the rank is an integer, with no tolerance.
00117 """
00118 rows = [list(row) for row in matrix]
00119 n_rows = len(rows)
00120 n_cols = len(rows[0]) if rows else 0
00121 used = 0
00122 for col in range(n_cols):
00123 pivot = next((i for i in range(used, n_rows) if rows[i][col] != 0), None)
00124 if pivot is None:
00125 continue
00126 rows[used], rows[pivot] = rows[pivot], rows[used]
00127 for i in range(n_rows):
00128 if i != used and rows[i][col] != 0:
00129 factor = rows[i][col] / rows[used][col]
00130 rows[i] = [a - factor * b for a, b in zip(rows[i], rows[used], strict=True)]
00131 used += 1
00132 if used == n_rows:
00133 break
00134 return used
00135 def attainable(payoff: Row, matrix: Matrix) -> bool:
00136 """True when the payoff lies in the row space of the matrix, tested by rank(matrix with payoff appended) == rank."""
00137 if len(payoff) != check_matrix(matrix):
00138 raise ValueError("a payoff must have one entry per state")
00139 return rank([*matrix, payoff]) == rank(matrix)
00140 def tup(row: Row) -> str:
00141 """The row as a printable tuple of exact Fractions."""
00142 return "(" + ",".join(str(z) for z in row) + ")"
00143 def main() -> None:
00144 """Print Parts A to E. Every value is an exact integer or Fraction, so the output is reproducible."""
00145 states = check_matrix(INCOMPLETE)
00146 check_matrix(COMPLETE)
00147 print("Part A: rank of each payoff matrix by exact Gaussian elimination")
00148 print(f"incomplete securities {len(INCOMPLETE)} states {states} rank {rank(INCOMPLETE)}")
00149 print(f"complete securities {len(COMPLETE)} states {check_matrix(COMPLETE)} rank {rank(COMPLETE)}")
00150 print("Part B: complete if and only if rank equals the number of states")
00151 for name, matrix in (("incomplete", INCOMPLETE), ("complete", COMPLETE)):
00152 n_states = check_matrix(matrix)
00153 r = rank(matrix)
00154 print(f"{name} rank {r} states {n_states} complete {r == n_states} rank_minus_states {r - n_states}")
00155 print("Part C: attainability in the incomplete market, tested by rank of the matrix with the payoff appended")
00156 for label, claim in CLAIMS:
00157 augmented = rank([*INCOMPLETE, claim])
00158 print(f"claim {label} attainable {attainable(claim, INCOMPLETE)} augmented_rank {augmented}")
00159 print("Part D: the same three payoffs in the complete market")
00160 for label, claim in CLAIMS:
00161 print(f"claim {label} attainable {attainable(claim, COMPLETE)} augmented_rank {rank([*COMPLETE, claim])}")
00162 print("Part E: the redundant fourth security leaves the rank unchanged")
00163 print(f"first_three_rows_rank {rank(COMPLETE[:3])} all_four_rows_rank {rank(COMPLETE)}")
00164 weights = (Fraction(1), Fraction(2), Fraction(3))
00165 combo = [sum((w * COMPLETE[j][k] for j, w in enumerate(weights)), Fraction(0)) for k in range(states)]
00166 print(f"weighted_sum_of_first_three_rows {tup(combo)} equals_fourth_row {combo == COMPLETE[3]}")

00186 3The Arrow–Debreu case and what a redundant security adds
00187 Remark 3.1 (one security per state)
00188 Let \(A = I_S\), with one security per state, so that security \(k\) is the Arrow–Debreu security of Lesson L01 (the payoff \(e_k\)). Then \(\operatorname{rank}(I_S) = S\), and the market is complete by Theorem 1.4. For any payoff \(\xi\), the portfolio \(\zeta = \xi\) satisfies \(\zeta^\top I_S = \xi\), so the attainable portfolio holds \(\xi_k\) units of the security for state \(k\). Each state is then covered by its own security, and the rank test needs no elimination.
00189 Remark 3.2 (redundancy)
00190 If a new security's payoff is a combination of the existing rows, the row space does not change, so the attainable set and the rank are unchanged. Example 2.3 shows the effect on portfolios: the payoff \((1,2,3)\) is attainable by \(\zeta = (1,2,3,0)\) and by \(\zeta = (0,0,0,1)\). Two portfolios give the same payoff, so a payoff does not determine its portfolio in this example. In general, the linear map \(\zeta \mapsto \zeta^\top A\) from \(\R^J\) to \(\R^S\) has rank \(\operatorname{rank}(A)\), so by rank-nullity its kernel \(\{\zeta \in \R^J : \zeta^\top A = 0\}\) has dimension \(J - \operatorname{rank}(A)\). If \(\operatorname{rank}(A) < J\), the kernel is nonzero, and every attainable payoff \(\xi\) is replicated by a whole translate of that kernel, so a payoff does not determine its portfolio.
00191 4Where the canon breaks
00192 Assumption A4 (infinitely many states)
00193 The state space \(\Omega\) is an infinite set, and a payoff is any real function on \(\Omega\). The set of all such functions is written \(\R^{\Omega}\), and it is a vector space under pointwise operations. The \(J\) securities are as in A2.
00194 Proposition 4.1 (no finite market is complete with infinitely many states)
00195 Under A2 to A4, the attainable set \(M(A)\) is a proper subspace of \(\R^{\Omega}\).
00196 Proof. The set \(M(A)\) is spanned by the \(J\) rows of \(A\), so its dimension is at most \(J\), by the argument of Corollary 1.6. Pick \(J + 1\) distinct states \(\omega_0, \dots, \omega_J\), which exist because \(\Omega\) is infinite. Let \(\indic\{\omega\}\) be the function that equals 1 at \(\omega\) and 0 elsewhere. If \(\sum_{i=0}^{J} c_i \indic\{\omega_i\} = 0\), evaluating at \(\omega_k\) gives \(c_k = 0\) for each \(k\). So these \(J + 1\) functions are linearly independent in \(\R^{\Omega}\). Hence \(M(A)\), of dimension at most \(J\), cannot contain all of them and cannot equal \(\R^{\Omega}\). \(\square\)
00197 The rank test of Theorem 1.4 uses the finiteness of A1: a finite set of rows spans a finite-dimensional subspace of \(\R^S\). With infinitely many states, Proposition 4.1 shows that no finite set of securities completes the market, so the finite-state conclusion cannot be carried over. The lesson does not state whether equilibrium allocations are efficient in an incomplete market, and no such claim is made here.
00198 Proposition 4.2 (nonnegative holdings give a cone, not a subspace)
00199 Under A1 and A2, replace A3 by the restriction \(\zeta \ge 0\) entrywise. The set \(C(A) = \{\zeta^\top A : \zeta \ge 0\}\) is a
00200 convex cone
00201 : if \(\xi\) and \(\eta\) are two elements of \(C(A)\) and \(a, b \ge 0\), then \(a\xi + b\eta \in C(A)\). It need not equal \(\R^S\). For \(A = I_2\), \(C(A)\) is the nonnegative quadrant of \(\R^2\), and \((-1, 0) \notin C(A)\), whereas \((-1,0)\) is attainable under A3.
00202 Proof. Let \(\zeta, \phi \ge 0\) with \(\xi = \zeta^\top A\) and \(\eta = \phi^\top A\), and let \(a, b \ge 0\). Then \(a\zeta + b\phi \ge 0\), and linearity gives \(a\xi + b\eta = a\,\zeta^\top A + b\,\phi^\top A = (a\zeta + b\phi)^\top A \in C(A)\), so \(C(A)\) is closed under nonnegative combinations. For \(A = I_2\), \(\zeta^\top I_2 = \zeta\), so \(C(I_2)\) is the set of \(\zeta \ge 0\), and \((-1,0)\) has a negative entry, so it is not in \(C(I_2)\). Under A3 the portfolio \(\zeta = (-1,0)\) gives \((-1,0)\). \(\square\)
00203 5Misconceptions
00204 “A market is complete only when it has exactly one security for each state.”
00205 Theorem 1.4 states the condition as a rank, not a count. Example 2.3 has four securities in three states, and the rank is 3, so the market is complete. Lab 1 prints complete for that matrix.
00206 “Having at least as many securities as states makes the market complete.”
00207 Corollary 1.6 gives only a necessary condition. The rows \((1,1,1)\), \((1,1,1)\) and \((0,1,2)\) are three securities in three states, but the second row repeats the first and the third is independent of the first, so the rank is 2 and the market is incomplete. Corollary 1.6 is not the converse of Theorem 1.4.
00208 “An attainable payoff is replicated by exactly one portfolio.”
00209 Remark 3.2 gives two portfolios, \((1,2,3,0)\) and \((0,0,0,1)\), for the payoff \((1,2,3)\) in Example 2.3. Lab 1 Part E prints that the weighted sum of the first three rows equals the fourth row. A unique portfolio requires the rows to be independent, which Example 2.3 is not.
00210 “Completeness depends on the prices of the securities.”
00211 Definition 1.3 and Theorem 1.4 use only the payoff matrix \(A\). No price enters the rank, the row space or the attainable set. A price can be attached to an attainable payoff in a later step, but it does not change whether the payoff is attainable.

00214 Mechanics
00215 M1 · The rank of a dependent pair
00216 Two securities pay \((1,2,0)\) and \((2,4,0)\) in three states. Find the rank and decide whether the market is complete.
00217 Solution
00218 The second row is twice the first, so the two rows are dependent. The row space is \(\operatorname{span}\{(1,2,0)\}\), of dimension 1. So \(\operatorname{rank} = 1 < 3\), and the market is incomplete by Theorem 1.4.
00219 M2 · Attainability by solving the equations
00220 Two securities pay \((1,0,1)\) and \((0,1,1)\) in three states. Decide whether the payoffs \((1,1,2)\) and \((0,0,1)\) are attainable, and give the portfolio for each attainable one.
00221 Solution
00222 For \((1,1,2)\), take \(\zeta = (1,1)\): \(1\cdot(1,0,1) + 1\cdot(0,1,1) = (1,1,2)\), so it is attainable. For \((0,0,1)\), a portfolio \(\zeta\) must satisfy \(\zeta_1 = 0\) in state 1, \(\zeta_2 = 0\) in state 2, and \(\zeta_1 + \zeta_2 = 1\) in state 3. The first two equations force \(\zeta_1 + \zeta_2 = 0 \ne 1\), so no portfolio works and \((0,0,1)\) is not attainable.
00223 M3 · A four-security matrix with two redundant rows
00224 Four securities pay \(r_1 = (1,2,0)\), \(r_2 = (0,1,1)\), \(r_3 = (1,3,1)\) and \(r_4 = (2,5,1)\) in three states. Find the rank and decide whether the market is complete.
00225 Solution
00226 Here \(r_3 = r_1 + r_2\) and \(r_4 = 2r_1 + r_2\), since \(2(1,2,0) + (0,1,1) = (2,5,1)\). So the row space is spanned by \(r_1\) and \(r_2\). These two are independent: if \(a r_1 + b r_2 = 0\), the first coordinate gives \(a = 0\), and then \(b = 0\). So \(\operatorname{rank} = 2 < 3\), and the market is incomplete.
00227 Proof
00228 P1 · The forward direction of Proposition 1.5
00229 Show that if \(\xi\) is attainable then \(\operatorname{rank}([A;\,\xi]) = \operatorname{rank}(A)\), using only Lemma 1.2 and Definition 1.3.
00230 Solution
00231 If \(\xi\) is attainable, then \(\xi = \zeta^\top A\) for some \(\zeta\), so \(\xi \in \operatorname{row}(A)\) by Lemma 1.2. The row space of \([A;\,\xi]\) is \(\operatorname{row}(A) + \operatorname{span}(\xi)\), and since \(\xi\) lies in \(\operatorname{row}(A)\), this sum equals \(\operatorname{row}(A)\). Equal row spaces have equal dimension, so the ranks agree.
00232 P2 · The rank is at most the number of rows
00233 Show that \(\operatorname{rank}(A) \le J\) for every \(J \times S\) matrix \(A\), using only the definition of rank.
00234 Solution
00235 By definition \(\operatorname{rank}(A) = \dim \operatorname{row}(A)\). The row space is spanned by the \(J\) rows of \(A\). A spanning set of a finite-dimensional space contains a basis of that space, so the dimension is at most the number of spanning vectors, which is \(J\).
00236 P3 · Complete markets from the identity
00237 Let \(A = I_S\). Show that every payoff \(\xi \in \R^S\) is attainable and that the portfolio is \(\zeta = \xi\).
00238 Solution
00239 For any \(\zeta\), \(\zeta^\top I_S = \zeta^\top\), so the attainable payoff of \(\zeta\) is \(\zeta\) itself. Given \(\xi\), the choice \(\zeta = \xi\) gives \(\zeta^\top I_S = \xi\), so \(\xi\) is attainable. Since \(\xi\) was arbitrary, \(M(I_S) = \R^S\), and the market is complete by Definition 1.3.

00241 E1 · Reading the lab's augmented rank
00242 In Lab 1 Part C the payoff \((5,0,0)\) has augmented rank 3 in the two-security market. Explain in words why this means the payoff is not attainable, and state the portfolio equations that the augmented rank summarises.
00243 Solution
00244 Proposition 1.5 says \(\xi\) is attainable exactly when the augmented rank equals \(\operatorname{rank}(A) = 2\). The printed value 3 is not 2, so the payoff is not attainable. The equations for a portfolio \(\zeta\) are \(\zeta_1 = 5\) in state 1, \(\zeta_1 + \zeta_2 = 0\) in state 2, and \(\zeta_1 + 2\zeta_2 = 0\) in state 3. The first two give \(\zeta_2 = -5\), and then the third gives \(5 - 10 = -5 \ne 0\), which is the inconsistency the augmented rank detects.
00245 E2 · What the fourth security adds
00246 Lab 1 Part E prints that the weighted sum of the first three rows equals the fourth row. Using only this output, state which portfolios replicate \((1,2,3)\) in the four-security market, and whether the fourth security changes the set of attainable payoffs.
00247 Solution
00248 The printed equality says \(1\cdot e_1 + 2\cdot e_2 + 3\cdot e_3 = (1,2,3)\), so \(\zeta = (1,2,3,0)\) replicates \((1,2,3)\). The fourth row equals the same payoff, so \(\zeta = (0,0,0,1)\) also replicates it. In general, \(\zeta = (1-t, 2-2t, 3-3t, t)\) replicates it for every real \(t\), because \(\zeta^\top A = (1-t)e_1 + (2-2t)e_2 + (3-3t)e_3 + t(1,2,3) = (1,2,3)\). The fourth security does not change the attainable set, because its row lies in the span of the first three. It adds a second portfolio for the same payoff.
00249 E3 · A three-security market
00250 Three securities pay \((1,1,0)\), \((0,1,1)\) and \((1,2,1)\) in three states. Find the rank and decide whether the market is complete.
00251 Solution
00252 The third row is the sum of the first two, since \((1,1,0) + (0,1,1) = (1,2,1)\). The first two rows are independent: if \(a(1,1,0) + b(0,1,1) = 0\), the first coordinate gives \(a = 0\), and then \(b = 0\). So \(\operatorname{rank} = 2 < 3\), and the market is incomplete.

00254 R1 · Fewer securities than states
00255 Let \(J < S\). Show that the market is incomplete for every \(J \times S\) payoff matrix \(A\).
00256 Solution
00257 By Corollary 1.6, a complete market needs \(J \ge S\). Since \(J < S\), the row space has dimension at most \(J < S\), so it cannot equal \(\R^S\), whatever the entries of \(A\). The argument uses the count of rows and the finiteness of the states in A1.
00258 R2 · The minimum number of securities
00259 For a finite state space with \(S\) states, find the least number of securities \(J\) that makes some market complete, and show that the bound is attained.
00260 Solution
00261 Corollary 1.6 shows that a complete market has \(J \ge S\). The identity matrix \(I_S\), with \(J = S\) securities, is complete by Problem P3. So the least number is \(J = S\), and the bound is attained.
00262 R3 · Nonnegative holdings can span the plane
00263 Take \(S = 2\) and the three securities \((1,0)\), \((0,1)\) and \((-1,-1)\). Under the restriction \(\zeta \ge 0\) of Proposition 4.2, show that every payoff \(\xi \in \R^2\) is attainable.
00264 Solution
00265 The payoff of \(\zeta = (\zeta_1, \zeta_2, \zeta_3)\) is \((\zeta_1 - \zeta_3,\ \zeta_2 - \zeta_3)\). Given \(\xi = (\xi_1, \xi_2)\), let \(t = \max(0, -\xi_1, -\xi_2)\), which is nonnegative. Set \(\zeta_3 = t\), \(\zeta_1 = \xi_1 + t\) and \(\zeta_2 = \xi_2 + t\). Then \(\zeta_1 \ge 0\) because \(t \ge -\xi_1\), and \(\zeta_2 \ge 0\) because \(t \ge -\xi_2\). The payoff is \((\xi_1 + t - t,\ \xi_2 + t - t) = \xi\), so each \(\xi\) is attainable with nonnegative holdings.
