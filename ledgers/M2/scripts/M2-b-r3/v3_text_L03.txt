   51 A payoff function can be defined by one formula on one side of a point and by another formula on the other side. A pricing rule can change at a threshold, and a limit is the tool that says what the rule does as the price approaches that threshold. This lesson states the limit of a function at a point, with \(\varepsilon\) and \(\delta\), links it to sequences, and treats one-sided limits. It shows that when the limits from the left and from the right at a point differ, the function has no two-sided limit there.
   53 1
   53 Limits of a function at a point
   55 An open interval \((c, d)\), with \(c < d\), is the set of real \(x\) with \(c < x < d\). Let \(f\) be a function defined on an open interval \(I\) that contains a point \(a\), except that \(f\) need not be defined at \(a\) itself. The value \(f(a)\), if it exists, plays no role in the limit at \(a\).
   58 Definition 1.1
   58 (limit of a function at a point)
   59 Let \(f\) and \(I\) be as above, and let \(L\) be a real number. We write \(\lim_{x \to a} f(x) = L\) when the following holds: for every \(\varepsilon > 0\) there is \(\delta > 0\) such that \(|f(x) - L| < \varepsilon\) for every \(x\) in \(I\) with \(0 < |x - a| < \delta\). This uses the meaning of "limit" from Lesson 1, carried over from sequences to functions. It defines no new concept.
   63 Example 1.2
   63 (a linear function)
   64 Let \(f(x) = 3x + 1\) on \(\R\). Then \(\lim_{x \to 2} f(x) = 7\). Proof: let \(\varepsilon > 0\) and put \(\delta = \varepsilon/3\). If \(0 < |x - 2| < \delta\), then \(|f(x) - 7| = |3x - 6| = 3|x - 2| < 3\delta = \varepsilon\). So the condition of Definition 1.1 holds with this \(\delta\).
   68 Proposition 1.3
   68 (sequences and the limit of a function)
   69 Let \(f\) and \(I\) be as in Definition 1.1, and suppose \(\lim_{x \to a} f(x) = L\). Let \((x_n)\) be a sequence with each \(x_n\) in \(I\), each \(x_n \ne a\), and \(x_n \to a\). Then \(f(x_n) \to L\). Hypotheses: the limit of \(f\) at \(a\) is \(L\) in the sense of Definition 1.1, and the sequence avoids \(a\).
   73 Proof
   74 Let \(\varepsilon > 0\). Choose \(\delta > 0\) from Definition 1.1. Since \(x_n \to a\), there is \(N\) with \(|x_n - a| < \delta\) for every \(n \ge N\). For such \(n\), \(x_n \in I\) and \(0 < |x_n - a| < \delta\), because \(x_n \ne a\). Definition 1.1 gives \(|f(x_n) - L| < \varepsilon\). Since \(\varepsilon\) was arbitrary, \(f(x_n) \to L\). \(\blacksquare\)
   78 Corollary 1.4
   78 (a limit equal to the value is continuity)
   79 Let \(f\) be defined on \(I\), let \(a \in I\), and suppose that \(\lim_{x \to a} f(x) = f(a)\). Hypotheses: the limit exists in the sense of Definition 1.1 and equals the value of \(f\) at \(a\). Then \(f\) is continuous at \(a\) in the sequential sense of Lesson 2, §2.
   83 Proof
   84 Let \((x_n)\) be a sequence in \(I\) with \(x_n \to a\). Let \(\varepsilon > 0\), with \(\delta\) from Definition 1.1 for \(L = f(a)\). Choose \(N\) with \(|x_n - a| < \delta\) for \(n \ge N\). For such \(n\), either \(x_n = a\), and then \(|f(x_n) - f(a)| = 0 < \varepsilon\), or \(0 < |x_n - a| < \delta\), and then \(|f(x_n) - f(a)| < \varepsilon\) by Definition 1.1. So \(f(x_n) \to f(a)\). \(\blacksquare\)
   87 2
   87 One-sided limits
   90 Definition 2.1
   90 (one-sided limits)
   91 Let \(f\) be defined on an open interval \(I\) containing \(a\), except possibly at \(a\). Let \(L\) be a real number. We write \(\lim_{x \to a^+} f(x) = L\), the right-hand limit, when for every \(\varepsilon > 0\) there is \(\delta > 0\) with \(|f(x) - L| < \varepsilon\) for every \(x\) in \(I\) with \(a < x < a + \delta\). We write \(\lim_{x \to a^-} f(x) = L\), the left-hand limit, when the same holds with \(a - \delta < x < a\) in place of \(a < x < a + \delta\).
   95 Proposition 2.2
   95 (the two-sided limit needs both one-sided limits)
   96 Let \(f\) be defined on an open interval \(I\) containing \(a\), except possibly at \(a\), and let \(L\) be real. Then \(\lim_{x \to a} f(x) = L\) if and only if \(\lim_{x \to a^+} f(x) = L\) and \(\lim_{x \to a^-} f(x) = L\). Hypotheses: \(f\) is defined on \(I\) minus possibly \(a\), and \(I\) contains \(a\) in its interior.
  100 Proof
  101 (Only if.) Let \(\varepsilon > 0\) and take \(\delta\) from Definition 1.1. Every \(x\) with \(a < x < a + \delta\) satisfies \(0 < |x - a| < \delta\), so \(|f(x) - L| < \varepsilon\). The right-hand limit is \(L\). The same argument on the left gives the left-hand limit.
  102 (If.) Let \(\varepsilon > 0\), and take \(\delta_+\) and \(\delta_-\) from Definition 2.1 for the two sides. Put \(\delta = \min(\delta_+, \delta_-)\). Let \(x\) satisfy \(0 < |x - a| < \delta\). If \(x > a\), then \(a < x < a + \delta_+\), so \(|f(x) - L| < \varepsilon\). If \(x < a\), then \(a - \delta_- < x < a\), so \(|f(x) - L| < \varepsilon\). Hence \(\lim_{x \to a} f(x) = L\). \(\blacksquare\)
  106 Example 2.3
  106 (a piecewise function with no two-sided limit at its break)
  107 Let \(f(x) = x^2\) for \(x < 1\) and \(f(x) = 2x\) for \(x \ge 1\). Its left-hand limit at 1 is 1: for \(0 < 1 - x < \delta \le 1\), we have \(|x^2 - 1| = |x - 1|\,|x + 1| < 2\delta\), because \(|x + 1| < 2\) there, and \(\delta = \min(1, \varepsilon/2)\) works. Its right-hand limit at 1 is 2: for \(0 < x - 1 < \delta\), \(|2x - 2| = 2|x - 1| < 2\delta\), and \(\delta = \varepsilon/2\) works. The two one-sided limits differ, so by Proposition 2.2 the two-sided limit at 1 does not exist.
  110 Example 2.3 uses Proposition 2.2 in the form that the two-sided limit, if it exists, equals each one-sided limit. The lab below computes the one-sided values at 1 and checks the choice \(\delta = \varepsilon/3\) of Example 1.2 on a grid for three tolerances.

  176 Example 2.4
  176 (a limit at a point where the function is undefined)
  177 Let \(g(x) = (x^2 - 1)/(x - 1)\) for \(x \ne 1\), and leave \(g(1)\) undefined. For \(x \ne 1\), \(g(x) = x + 1\). So \(|g(x) - 2| = |x - 1|\), and given \(\varepsilon > 0\), \(\delta = \varepsilon\) gives \(|g(x) - 2| < \varepsilon\) for \(0 < |x - 1| < \delta\). Hence \(\lim_{x \to 1} g(x) = 2\), even though \(g(1)\) is not defined.
  181 3
  181 Where the canon breaks
  182 The definition is exact. Three points of practice need care.
  184 - The limit ignores the value at the point. Example 2.4 has a limit at 1 with no value there. Corollary 1.4 applies when the value exists and equals the limit, and then the function is continuous at the point in the sequential sense.
  185 - Boundedness does not give a limit. A function can be bounded near a point and have no limit there. Misconception 2 gives the example.
  186 - This lesson defines no infinite limits. Statements such as \(f(x) \to \infty\) need a separate definition, which this lesson does not give. The claims here concern finite limits.
  191 4
  191 Misconceptions
  193 -
  194 “The limit at \(a\) depends on the value \(f(a)\).”
  195 Definition 1.1 excludes \(x = a\) by the condition \(0 < |x - a|\). Example 2.4 has no value at 1 and still has the limit 2. If \(g(1)\) were set to 5, the limit would still be 2, because no value at 1 enters the definition.
  197 -
  198 “A bounded function must have a limit at every point.”
  199 Let \(w(x) = 1\) for \(x \ge 0\) and \(w(x) = -1\) for \(x < 0\). Then \(|w(x)| = 1\) for every \(x\), so \(w\) is bounded. Its left-hand limit at 0 is \(-1\) and its right-hand limit is 1. By Proposition 2.2, the two-sided limit at 0 does not exist.
  201 -
  202 “The right-hand limit equals \(f(a)\) whenever \(f\) is defined at \(a\).”
  203 Let \(f(x) = x\) for \(x > 0\) and \(f(0) = 5\). The right-hand limit at 0 is 0, by Definition 2.1, while \(f(0) = 5\). The right-hand limit is a property of the values near 0, and the value at 0 is a separate fact.

  213 Mechanics
  215 M1 · A threshold for a linear function
  216 For \(f(x) = 2x - 1\) and \(a = 3\), find a \(\delta\) that works for \(\varepsilon = 0.02\) in Definition 1.1.
  217 Solution
  218 We have \(|f(x) - 5| = |2x - 6| = 2|x - 3|\). This is less than \(0.02\) when \(|x - 3| < 0.01\). So \(\delta = 0.01\) works. Any smaller positive \(\delta\) also works, so one \(\delta\) is enough.
  222 M2 · The sign function
  223 Let \(s(x) = |x|/x\) for \(x \ne 0\). Find the left-hand and right-hand limits at 0, and say whether the two-sided limit exists.
  224 Solution
  225 For \(x > 0\), \(|x|/x = 1\), so the right-hand limit is 1. For \(x < 0\), \(|x|/x = -1\), so the left-hand limit is \(-1\). These differ, so by Proposition 2.2 the two-sided limit at 0 does not exist. The function is not defined at 0, and that fact is not what makes the limit fail.
  229 M3 · A factor that cancels
  230 Let \(q(x) = (x^2 - 4)/(x - 2)\) for \(x \ne 2\). Find \(\lim_{x \to 2} q(x)\).
  231 Solution
  232 For \(x \ne 2\), \(x^2 - 4 = (x - 2)(x + 2)\), so \(q(x) = x + 2\). Then \(|q(x) - 4| = |x - 2|\), and \(\delta = \varepsilon\) works, as in Example 2.4. The limit is 4.
  238 Proof
  240 P1 · A constant function
  241 Let \(f(x) = c\) for every \(x\) in an open interval containing \(a\). Prove from Definition 1.1 that \(\lim_{x \to a} f(x) = c\).
  242 Solution
  243 Let \(\varepsilon > 0\), and take \(\delta = 1\), for example. For every \(x\) with \(0 < |x - a| < 1\), \(|f(x) - c| = |c - c| = 0 < \varepsilon\). So the condition of Definition 1.1 holds, and the limit is \(c\).
  247 P2 · The square at a point
  248 Prove from Definition 1.1 that \(\lim_{x \to a} x^2 = a^2\) for every real \(a\).
  249 Solution
  250 Let \(\varepsilon > 0\), and put \(\delta = \min\bigl(1, \varepsilon/(1 + 2|a|)\bigr)\). If \(0 < |x - a| < \delta\), then \(|x + a| \le |x - a| + 2|a| < 1 + 2|a|\). So \(|x^2 - a^2| = |x - a|\,|x + a| < \delta(1 + 2|a|) \le \varepsilon\). Hence the limit is \(a^2\).
  254 P3 · Uniqueness of the limit of a function
  255 Suppose \(\lim_{x \to a} f(x) = L\) and \(\lim_{x \to a} f(x) = M\). Prove that \(L = M\).
  256 Solution
  257 Let \(\varepsilon > 0\). Take \(\delta_1\) for \(L\) and \(\delta_2\) for \(M\), with \(\varepsilon/2\) in place of \(\varepsilon\) in each. Put \(\delta = \min(\delta_1, \delta_2)\). For \(0 < |x - a| < \delta\), \(|L - M| \le |f(x) - L| + |f(x) - M| < \varepsilon\). Since \(\varepsilon\) was arbitrary, \(|L - M| = 0\), so \(L = M\).
  263 Empirical
  265 E1 · Checking the left-hand value (from Lab 1)
  266 Lab 1 prints \(f(1 - h)\) at \(h = 0.001\) as 0.998001. Check it from the closed form \((1 - h)^2\), and say which side of 1 this value is on.
  267 Solution
  268 We have \((1 - 0.001)^2 = 0.999^2 = 0.998001\), which is the printed value. Since \(1 - h < 1\), the point lies left of the break, and \(f\) uses the formula \(x^2\) there, so the printed value is the left-hand value at that point.
  272 E2 · The gap column (from Lab 1)
  273 The gap column prints 1.039900 at \(h = 0.01\). Check it from the closed form \(1 + 4h - h^2\).
  274 Solution
  275 At \(h = 0.01\), \(1 + 4(0.01) - (0.01)^2 = 1 + 0.04 - 0.0001 = 1.0399\), which is the printed 1.039900. The gap tends to 1 because \(4h - h^2 \to 0\) as \(h \to 0\). The one-sided values tend to 1 and 2 for the same reason, since \((1 - h)^2 \to 1\) and \(2 + 2h \to 2\).
  279 E3 · A prediction the lab does not test
  280 Without running the lab, predict whether the grid check would print True for the choice \(\delta = \varepsilon\), instead of \(\delta = \varepsilon/3\), at \(\varepsilon = 0.1\). Say what the prediction rests on.
  281 Solution
  282 Take \(x = 2 + (19/20)\cdot 0.1\), which is a grid point with \(0 < |x - 2| < 0.1\). Then \(|3x + 1 - 7| = 3 \cdot 0.095 = 0.285\), which is larger than \(0.1\), so the check would print False. The prediction rests on the formula \(|f(x) - 7| = 3|x - 2|\) and not on any run of the lab, which does not test \(\delta = \varepsilon\).
  288 Research
  290 R1 · A function that is zero except on the rationals
  291 Let \(f(x) = x^2\) if \(x\) is rational and \(f(x) = 0\) otherwise. Prove that \(\lim_{x \to 0} f(x) = 0\), and state why the proof does not need to know which \(x\) are rational.
  292 Solution
  293 In either case \(|f(x)| \le x^2\). Given \(\varepsilon > 0\), put \(\delta = \sqrt{\varepsilon}\). For \(0 < |x| < \delta\), \(|f(x) - 0| \le x^2 < \delta^2 = \varepsilon\). The bound \(|f(x)| \le x^2\) holds for every \(x\), whether or not \(x\) is rational, so the proof uses only that bound.
  297 R2 · A bounded factor and a zero limit
  298 Let \(|f(x)| \le M\) for every \(x\) in an interval containing \(a\), with \(M\) a constant, and let \(\lim_{x \to a} g(x) = 0\). Prove that \(\lim_{x \to a} f(x) g(x) = 0\).
  299 Solution
  300 Let \(\varepsilon > 0\). Choose \(\delta\) with \(|g(x)| < \varepsilon/(M + 1)\) for \(0 < |x - a| < \delta\). Then \(|f(x)g(x)| \le M|g(x)| \le M\varepsilon/(M+1) < \varepsilon\). The hypothesis that \(M\) bounds \(f\) is used once, and no property of \(f\) beyond it is needed.
  304 R3 · The absolute value of a limit
  305 Suppose \(\lim_{x \to a} f(x) = L\). Prove that \(\lim_{x \to a} |f(x)| = |L|\).
  306 Solution
  307 For every \(x\), \(\bigl||f(x)| - |L|\bigr| \le |f(x) - L|\). Given \(\varepsilon > 0\), take \(\delta\) from Definition 1.1. For \(0 < |x - a| < \delta\), the inequality gives \(\bigl||f(x)| - |L|\bigr| < \varepsilon\). So \(|f|\) has limit \(|L|\) at \(a\), by Definition 1.1 applied to \(|f|\).
