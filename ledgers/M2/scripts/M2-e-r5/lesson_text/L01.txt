Several quantities in the later lessons are defined as limits of an expression that depends on a parameter. Each such definition says that the expression settles down as the parameter goes to its end point. This lesson makes "settles down" exact for a sequence: the epsilon-N definition of the limit. It proves that a limit is unique, that the first terms of a sequence do not decide its limit, and that a sequence whose terms stay between two fixed numbers can still fail to converge.
1Sequences
A sequence is a list \((a_1, a_2, a_3, \dots)\) with one real number \(a_n\) for each positive integer \(n\). The sequence is written \((a_n)\). Its terms are the numbers \(a_n\), and the index \(n\) runs over the positive integers. The lesson uses this definition, stated in prose rather than as a numbered definition.
2The limit of a sequence
Definition 2.1 (limit of a sequence)
Let \((a_n)\) be a sequence of real numbers and let \(L\) be a real number. We say that \(L\) is the limit of \((a_n)\), and write \(a_n \to L\), when the following holds: for every \(\varepsilon > 0\) there is a positive integer \(N\) such that \(|a_n - L| < \varepsilon\) for every integer \(n \ge N\). A sequence with a limit is convergent. A sequence with no limit is divergent.
Read the definition in order. The tolerance \(\varepsilon\) is chosen first, and it may be any positive number. The index \(N\) is then chosen to depend on \(\varepsilon\). The condition must hold from \(N\) onward, not only at \(N\). A fixed \(\varepsilon\) tests the sequence at one tolerance. The definition asks for a threshold at every tolerance.
Proposition 2.2 (uniqueness of the limit)
Let \((a_n)\) be a sequence of real numbers. If \(a_n \to L\) and \(a_n \to M\), then \(L = M\). Hypotheses: \((a_n)\) is a sequence of real numbers, and both \(L\) and \(M\) satisfy Definition 2.1 for it.
Proof
Let \(\varepsilon > 0\). By Definition 2.1 applied to \(L\), there is \(N_1\) with \(|a_n - L| < \varepsilon/2\) for every \(n \ge N_1\). By Definition 2.1 applied to \(M\), there is \(N_2\) with \(|a_n - M| < \varepsilon/2\) for every \(n \ge N_2\). Let \(n = \max(N_1, N_2)\). Then both inequalities hold at this \(n\), and the triangle inequality gives
\[|L - M| = |(L - a_n) + (a_n - M)| \le |a_n - L| + |a_n - M| < \tfrac{\varepsilon}{2} + \tfrac{\varepsilon}{2} = \varepsilon.\]
Since \(\varepsilon > 0\) was arbitrary, \(|L - M|\) is smaller than every positive number. A non-negative number smaller than every positive number is zero. So \(|L - M| = 0\), and \(L = M\). \(\blacksquare\)
Proposition 2.2 justifies the phrase "the limit", because it makes the notation \(\lim a_n\) well defined.
Example 2.3 (a sequence with a limit and an explicit threshold)
Let \(a_n = \dfrac{2n + 1}{n + 1}\). Then \(a_n - 2 = \dfrac{2n + 1 - 2(n + 1)}{n + 1} = -\dfrac{1}{n + 1}\), so \(|a_n - 2| = \dfrac{1}{n+1}\). Given \(\varepsilon > 0\), choose a positive integer \(N > 1/\varepsilon\). For every \(n \ge N\), we have \(n + 1 > N > 1/\varepsilon\), so \(\dfrac{1}{n+1} < \varepsilon\). Hence \(a_n \to 2\), with the threshold \(N\) chosen from \(\varepsilon\) as above.
Example 2.3 chooses \(N\) from \(\varepsilon\) by a formula. Lab 1 computes the terms and the exact distances, and then searches for the least threshold at one tolerance. The search finds the same kind of threshold, but it checks finitely many values of \(n\).
Lab 1 · A sequence with limit 2 and an exact threshold
Predicted before running, from Example 2.3. The terms are \(a_n = (2n+1)/(n+1)\), so \(a_1 = 3/2\) and the error at \(n = 1\) is \(1/2\). At \(n = 10\) the error is \(1/11 \approx 0.0909\), and at \(n = 100\) it is \(1/101\). The inequality \(1/(n+1) < 1/1000\) holds exactly when \(n + 1 > 1000\), that is, \(n \ge 1000\). At \(n = 999\) the error equals \(1/1000\) and the strict inequality fails, so the least threshold is \(N = 1000\), and the printed error at \(n = 999\) should be \(1.000000 \times 10^{-3}\). """M2 lab L01: the limit of a sequence, tabulated against its known limit, and an exact threshold.
Standard library only. No randomness and no network. The sequence is a_n = (2n + 1)/(n + 1), whose limit is 2
and whose exact distance from the limit is |a_n - 2| = 1/(n + 1). The terms are exact rational numbers
(fractions.Fraction), and the printed decimals are rounded only for display. The threshold search checks the
inequality |a_n - 2| < 1/1000 for each n from N to 5000 only. The fact that it holds for every n >= N is proved on
the page, not by the search.
"""
from __future__ import annotations
from fractions import Fraction
LIMIT = Fraction(2)
def a(n: int) -> Fraction:
"""The n-th term (2n + 1)/(n + 1) as an exact fraction, for an integer n >= 1."""
if n < 1:
raise ValueError(f"a needs n >= 1, got {n}")
return Fraction(2 * n + 1, n + 1)
def error(n: int) -> Fraction:
"""The exact distance |a_n - 2| from the n-th term to the limit 2."""
return abs(a(n) - LIMIT)
def least_threshold(epsilon: Fraction, search_limit: int) -> int:
"""The least N in 1..search_limit with |a_n - 2| < epsilon for every n from N to search_limit.
Returns 0 when no N in that range works.
"""
for big_n in range(1, search_limit + 1):
if all(error(n) < epsilon for n in range(big_n, search_limit + 1)):
return big_n
return 0
def main() -> None:
print("n, a_n, |a_n - 2|")
for n in (1, 10, 100, 1000, 10000):
print(f"{n}, {float(a(n)):.6f}, {float(error(n)):.6e}")
big_n = least_threshold(Fraction(1, 1000), 5000)
print(f"least N with |a_n - 2| < 0.001 for every n from N to 5000: {big_n}")
print(f"error at n = 999: {float(error(999)):.6e}; error at n = 1000: {float(error(1000)):.6e}")
print(f"the strict inequality fails at n = 999: {not error(999) < Fraction(1, 1000)}")
main()

Every term and every error is an exact rational number, and the printed decimals are rounding of those values. The threshold line shows that the strict inequality fails at \(n = 999\) and holds from \(n = 1000\) up to the search limit. That is a finite check of one tolerance. The claim that the inequality holds for every \(n \ge 1000\) follows from the identity \(|a_n - 2| = 1/(n+1)\) in Example 2.3 and not from the search. 3The tail of a sequence
The tail of \((a_n)\) from index \(M\) is the sequence \(a_M, a_{M+1}, a_{M+2}, \dots\).
Proposition 3.1 (the tail decides the limit)
Let \((a_n)\) and \((c_n)\) be sequences of real numbers, and let \(M\) be a positive integer such that \(c_n = a_n\) for every \(n \ge M\). If \(a_n \to L\), then \(c_n \to L\). Hypotheses: \(a_n \to L\) in the sense of Definition 2.1, and the two sequences agree from index \(M\) onward. The first \(M - 1\) terms of \((c_n)\) are unrestricted.
Proof
Let \(\varepsilon > 0\). Since \(a_n \to L\), there is \(N\) with \(|a_n - L| < \varepsilon\) for every \(n \ge N\). Put \(N' = \max(N, M)\). For every \(n \ge N'\), we have \(n \ge N\) and \(n \ge M\), so \(c_n = a_n\) and \(|c_n - L| = |a_n - L| < \varepsilon\). Since \(\varepsilon\) was arbitrary, \(c_n \to L\). \(\blacksquare\)
Proposition 3.1 says that the early terms cannot change a limit. The limit of \((a_n)\) is fixed by its tail, and the first terms are free.
4Divergence
A sequence \((a_n)\) is bounded when there is a real number \(B\) with \(|a_n| \le B\) for every \(n\).
Example 4.1 (a bounded sequence that does not converge)
Let \(a_n = (-1)^n\), so the terms alternate \(-1, 1, -1, 1, \dots\). Every term satisfies \(|a_n| \le 1\), so the sequence is bounded. We show it does not converge. Suppose, for a contradiction, that \(a_n \to L\) for some real \(L\). Apply Definition 2.1 with \(\varepsilon = 1\): there is \(N\) with \(|a_n - L| < 1\) for every \(n \ge N\). Choose an even \(n \ge N\) and an odd \(m \ge N\). Then \(a_n = 1\) and \(a_m = -1\), so \(|1 - L| < 1\) and \(|-1 - L| < 1\). By the triangle inequality, \(2 = |1 - (-1)| \le |1 - L| + |L - (-1)| < 2\), which is false. So no real \(L\) is the limit, and \((a_n)\) is divergent.
Proposition 4.2 (a convergent sequence is bounded)
Let \((a_n)\) be a sequence of real numbers with \(a_n \to L\) in the sense of Definition 2.1. Then there is a real number \(B\) with \(|a_n| \le B\) for every positive integer \(n\). Hypotheses: \((a_n)\) is a sequence of real numbers, and \(L\) satisfies Definition 2.1 for it.
Proof
Apply Definition 2.1 with \(\varepsilon = 1\): there is \(N\) with \(|a_n - L| < 1\) for every \(n \ge N\). For such \(n\), the triangle inequality gives \(|a_n| \le |L| + |a_n - L| < |L| + 1\). Put
\[B = \max\bigl(|a_1|, |a_2|, \dots, |a_{N-1}|, |L| + 1\bigr).\]
This is the maximum of finitely many real numbers, so \(B\) is a real number. For \(n < N\), \(|a_n| \le B\) by the choice of \(B\). For \(n \ge N\), \(|a_n| < |L| + 1 \le B\). Hence \(|a_n| \le B\) for every \(n\). \(\blacksquare\)
Example 4.1 uses proof by contradiction, from M1 Lesson 2: the assumption that a limit exists leads to the false inequality \(2 < 2\). The example also shows that boundedness is not enough for convergence.
5Where the canon breaks
The definition handles sequences cleanly. Three limits of practice break the picture that a limit is a value the sequence reaches.
A limit need not be attained. The terms of \((2n+1)/(n+1)\) never equal 2, because \(2n + 1 = 2n + 2\) has no solution. The limit is a value the terms approach, and the definition does not require any term to equal it.
The definition checks a limit and does not find one. Definition 2.1 tests a proposed \(L\). It does not produce \(L\). One method is to compute a candidate and then prove it, as Example 2.3 does with the candidate 2.
A finite search is not a proof. Lab 1 finds \(N = 1000\) for one tolerance by checking 5000 terms. The limit claim for all tolerances and all \(n\) is proved by Example 2.3, and no search over finitely many \(n\) can replace that proof.
6Misconceptions
“A sequence with limit \(L\) must reach \(L\) at some finite step.”
Definition 2.1 asks that the terms eventually lie within \(\varepsilon\) of \(L\), for each \(\varepsilon\). The sequence \(a_n = 1/n\) has limit 0, by the argument of Problem M3 with the sign factor removed, and no term equals 0. Its terms are \(1, \tfrac12, \tfrac13, \dots\), and \(1/n > 0\) for each \(n\), so no term is 0.
“The first terms of a sequence help determine its limit.”
Proposition 3.1 shows that changing finitely many terms leaves the limit unchanged. Replace the first term of \((2n+1)/(n+1)\) by \(10^6\). The new sequence still has limit 2, because it agrees with the old one from index 2 onward, which is the hypothesis of Proposition 3.1.
“A bounded sequence must converge.”
Example 4.1 gives the bounded sequence \((-1)^n\), with \(|a_n| \le 1\) for every \(n\), which does not converge. Proposition 4.2 shows that boundedness is necessary for a limit. Example 4.1 shows that it is not sufficient.
7Problem set
Every problem has a full worked solution. Attempt each one before opening it. Problems marked E use the output of Lab 1.
Mechanics
M1 · The distance to the limit
Let \(a_n = \dfrac{3n - 1}{n + 4}\). Show that \(a_n\) has a limit by computing \(|a_n - 3|\) and giving a threshold \(N\) for \(\varepsilon = 0.01\).
Solution
We have \(a_n - 3 = \dfrac{3n - 1 - 3(n + 4)}{n + 4} = \dfrac{-13}{n + 4}\), so \(|a_n - 3| = \dfrac{13}{n + 4}\). This is less than \(0.01\) exactly when \(n + 4 > 1300\), that is, \(n > 1296\). So \(N = 1297\) works for \(\varepsilon = 0.01\), and the same argument with \(N > 13/\varepsilon - 4\) works for any \(\varepsilon > 0\). Hence \(a_n \to 3\).
M2 · The least threshold
Let \(b_n = 1/n^2\). Find the least integer \(N\) such that \(|b_n - 0| < 0.01\) for every \(n \ge N\).
Solution
The inequality \(1/n^2 < 0.01\) is equivalent to \(n^2 > 100\), and for positive \(n\) that is \(n > 10\). At \(n = 10\) the value is \(1/100 = 0.01\), which fails the strict inequality. So the inequality holds for every \(n \ge 11\) and fails at \(n = 10\). The least threshold is \(N = 11\).
M3 · A sequence with alternating sign
Let \(c_n = (-1)^n / n\). Show that \(c_n \to 0\).
Solution
We have \(|c_n - 0| = |(-1)^n| / n = 1/n\), because \(|(-1)^n| = 1\). Given \(\varepsilon > 0\), choose a positive integer \(N > 1/\varepsilon\). For every \(n \ge N\) we have \(n > 1/\varepsilon\), so \(1/n < \varepsilon\). Hence \(|c_n - 0| < \varepsilon\) for every \(n \ge N\), and \(c_n \to 0\).
Proof
P1 · A constant sequence
Let \(a_n = C\) for every \(n\), with \(C\) a fixed real number. Prove from Definition 2.1 that \(a_n \to C\).
Solution
Let \(\varepsilon > 0\). Take \(N = 1\), for example. For every \(n \ge 1\), \(|a_n - C| = |C - C| = 0 < \varepsilon\). The condition of Definition 2.1 holds at every tolerance, so \(a_n \to C\). Any positive integer would serve as \(N\), since the inequality holds at every index.
P2 · A limit cannot be negative when the terms are not
Let \((a_n)\) satisfy \(a_n \ge 0\) for every \(n\), and suppose \(a_n \to L\). Prove that \(L \ge 0\).
Solution
Suppose, for a contradiction, that \(L < 0\). Apply Definition 2.1 with \(\varepsilon = -L > 0\). There is \(N\) with \(|a_n - L| < -L\) for every \(n \ge N\). For such an \(n\), \(a_n - L < -L\), so \(a_n < 0\). This contradicts \(a_n \ge 0\). Hence \(L \ge 0\).
P3 · Shifting the index
Let \(a_n \to L\) and let \(d_n = a_{n+5}\) for every \(n \ge 1\). Prove that \(d_n \to L\).
Solution
Let \(\varepsilon > 0\). Since \(a_n \to L\), there is \(N\) with \(|a_m - L| < \varepsilon\) for every \(m \ge N\). Put \(N' = \max(1, N - 5)\). For \(n \ge N'\), the index \(m = n + 5\) satisfies \(m \ge N\), so \(|d_n - L| = |a_{n+5} - L| < \varepsilon\). Hence \(d_n \to L\).
Empirical
E1 · Reading the error column (from Lab 1)
Lab 1 prints the error \(|a_n - 2|\) at \(n = 1000\). Give the exact fraction, and check the printed decimal.
Solution
By Example 2.3, \(|a_{1000} - 2| = 1/1001\). Lab 1 prints \(9.990010 \times 10^{-4}\), and \(1/1001 = 0.000999000999\ldots\) rounds to \(9.990010 \times 10^{-4}\) at six digits after the point of the mantissa. The exact value is \(1/1001\), and the printed decimal is that fraction rounded for display.
E2 · Why the threshold is 1000 and not 999 (from Lab 1)
Lab 1 prints the least threshold 1000 for the tolerance 0.001. Explain why \(N = 999\) is not a valid threshold, using the printed error at \(n = 999\).
Solution
Lab 1 prints the error at \(n = 999\) as \(1.000000 \times 10^{-3}\), which is exactly the tolerance \(0.001\). Definition 2.1 uses the strict inequality, so the error must be less than \(0.001\) for every \(n \ge N\). At \(n = 999\) it is not, and so \(N = 999\) fails. The first index at which the strict inequality holds for all later terms is \(1000\).
E3 · A prediction for a smaller tolerance
Without running the lab, predict the least threshold for the tolerance \(0.0001\), using Example 2.3. Then state the error \(|a_n - 2|\) at \(n = 9999\), the index one below that threshold.
Solution
The inequality \(1/(n+1) < 10^{-4}\) holds exactly when \(n + 1 > 10000\), that is, \(n \ge 10000\). At \(n = 9999\) the error is \(1/10000 = 10^{-4}\), which fails the strict inequality. So the least threshold is 10000. Evaluating the same formula at \(n = 9999\) gives \(1.000000 \times 10^{-4}\). Lab 1 does not print this value, because its search uses the tolerance \(0.001\). This is a prediction from the formula, and no lab run in this lesson checks it.
Research
R1 · What one tolerance can establish
A study reports that a numerical sequence is within \(0.001\) of its limit for every term from index \(10^6\) onward. Explain what this establishes about convergence, and what a second claim, that the sequence converges, would additionally require.
Solution
The report establishes the inequality of Definition 2.1 at the single tolerance \(0.001\), with threshold \(N = 10^6\). It does not establish convergence, because Definition 2.1 requires a threshold for every positive tolerance. The second claim requires, for every \(\varepsilon > 0\), a threshold \(N(\varepsilon)\). A finite report cannot supply that for all \(\varepsilon\) unless a formula or a proof gives the thresholds.
R2 · Truncations of a real number
Let \(x\) be a real number, and let \(t_n = \lfloor 10^n x \rfloor / 10^n\) be its truncation to \(n\) decimal places. Prove that \(t_n \to x\).
Solution
By the definition of the floor, \(\lfloor y \rfloor \le y < \lfloor y \rfloor + 1\) for every real \(y\). With \(y = 10^n x\) this gives \(0 \le x - t_n < 10^{-n}\). Given \(\varepsilon > 0\), choose \(N\) with \(10^{-N} < \varepsilon\). For \(n \ge N\), \(|t_n - x| < 10^{-n} \le 10^{-N} < \varepsilon\). Hence \(t_n \to x\).
R3 · A limit that depends on the index set
Let \(a_n = 1\) for \(n\) a perfect square and \(a_n = 0\) otherwise. Decide whether \((a_n)\) converges, and explain which property of Definition 2.1 settles the question.
Solution
The sequence does not converge. Suppose \(a_n \to L\). Take \(\varepsilon = 1/2\). Then for \(n \ge N\), \(|a_n - L| < 1/2\). There are both perfect squares and non-squares beyond \(N\), with values 1 and 0. Then \(1 - 0 = |a_m - a_n| \le |a_m - L| + |L - a_n| < 1\), which is false for \(m\) a square and \(n\) a non-square beyond \(N\). The contradiction shows that no \(L\) is the limit.
