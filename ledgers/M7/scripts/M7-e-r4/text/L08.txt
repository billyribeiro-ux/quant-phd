0019 Xrefuted
0020 The recursion of Theorem 2.1 in L07, once future rewards are discounted, is the Bellman equation defined in §1 of this lesson: the value at a state is the best immediate reward plus the discounted value of the next state. For \(\beta \ge 0\), this lesson proves that the value function is the unique solution of the Bellman equation with its terminal condition. It then defines the Bellman operator and value iteration. For \(\beta \ge 0\), Proposition 2.3 identifies each iterate with the exact value of a finite-horizon problem. Lab 1 checks the recursion against brute force on a fixed toy problem, with exact fractions, and reports the change between successive iterates. The infinite-horizon case is not treated here.
0021 1Discounted finite-horizon problems and the Bellman equation
0022 Take the problem of Definition 1.1 in L07, with its data \(S\), \(A(s)\), \(f\), \(r\), \(B\) and horizon \(H\), and add a discount factor \(\beta \ge 0\), a real number. The discount factor multiplies the reward of each later period by one more power of \(\beta\). Lesson L07 is the case \(\beta = 1\). Section 3 gives an example in which Theorem 1.3 fails for \(\beta < 0\). In this lesson \(\beta\) has this meaning.
0023 Definition 1.1 (discounted total and value)
0024 Let \(0 \le t \le H\) and \(s \in S\). For a plan \(p = (a_t, \ldots, a_{H-1})\) from \((t,s)\) with states \(s_k\) along it, the discounted total reward is
0025 \[
0026 J_t(p) = \sum_{k=t}^{H-1} \beta^{\,k-t}\, r(s_k, a_k) + \beta^{\,H-t}\, B(s_H).
0027 \]
0028 The discounted value function is \(V_t(s) = \max_p J_t(p)\), the maximum over the plans from \((t,s)\). The maximum exists because the set of plans is finite and nonempty, as in L07 Definition 1.2.
0029 Definition 1.2 (the Bellman equation)
0030 The Bellman equation for the problem of Definition 1.1 is the system of equations
0031 \[
0032 U_H(s) = B(s), \qquad U_t(s) = \max_{a \in A(s)} \bigl\{ r(s,a) + \beta\, U_{t+1}\bigl(f(s,a)\bigr) \bigr\} \quad (0 \le t \le H-1),
0033 \]
0034 in unknown functions \(U_0, \ldots, U_H\) on \(S\). A solution is a family \((U_0, \ldots, U_H)\) that satisfies all of these equations.
0035 Theorem 1.3 (the value function solves the Bellman equation)
0036 Under the hypotheses of Definition 1.1, with \(\beta \ge 0\), the discounted value function \((V_0, \ldots, V_H)\) is a solution of the Bellman equation of Definition 1.2.
0037 Proof
0038 The terminal equation holds because the only plan from \((H,s)\) is the empty plan, with total \(B(s)\), so \(V_H(s) = B(s)\). Fix \(t\) with \(0 \le t \le H-1\) and \(s \in S\). A plan from \((t,s)\) is a pair \((a, q)\), with \(a \in A(s)\) and \(q\) a plan from \((t+1, f(s,a))\), and every such pair is a plan from \((t,s)\). Split off the first period in the sum of Definition 1.1. The remaining terms are \(\beta\) times the discounted total of \(q\):
0039 \[
0040 \sum_{k=t+1}^{H-1} \beta^{\,k-t}\, r(s_k,a_k) + \beta^{\,H-t}\, B(s_H) = \beta \Bigl( \sum_{k=t+1}^{H-1} \beta^{\,k-(t+1)}\, r(s_k,a_k) + \beta^{\,H-(t+1)}\, B(s_H) \Bigr).
0041 \]
0042 So \(J_t(a,q) = r(s,a) + \beta\, J_{t+1}(q)\). Since \(\beta \ge 0\), the maximum over \(q\) of \(\beta J_{t+1}(q)\) is \(\beta\) times the maximum of \(J_{t+1}(q)\); this is the only step that uses the sign of \(\beta\). Taking the maximum over \(q\) and then over \(a\), exactly as in the proof of L07 Theorem 2.1, gives \(V_t(s) = \max_{a \in A(s)} \{ r(s,a) + \beta V_{t+1}(f(s,a)) \}\).
0043 Theorem 1.4 (uniqueness given the terminal condition)
0044 Under the hypotheses of Definition 1.1, with \(\beta \ge 0\), let \((U_0, \ldots, U_H)\) be a solution of the Bellman equation of Definition 1.2. Then \(U_t = V_t\) for every \(t\) with \(0 \le t \le H\).
0045 Proof
0046 The proof is by downward induction on \(t\). At \(t = H\), \(U_H = B = V_H\) by the terminal equation and Theorem 1.3. Suppose \(U_{t+1} = V_{t+1}\), and let \(s \in S\). The equation for \(U_t\) and Theorem 1.3 give
0047 \[
0048 U_t(s) = \max_{a \in A(s)} \bigl\{ r(s,a) + \beta\, U_{t+1}(f(s,a)) \bigr\} = \max_{a \in A(s)} \bigl\{ r(s,a) + \beta\, V_{t+1}(f(s,a)) \bigr\} = V_t(s).
0049 \]
0050 The second equality uses the induction hypothesis at each state \(f(s,a)\).
0051 Remark 1.5 (the equations alone do not fix the value)
0052 The terminal equation \(U_H = B\) is part of the system, and Theorem 1.4 needs it. The equations for \(t < H\) alone do not determine the family. Take \(H = 1\), one state \(s\), \(A(s) = \{a\}\), \(r(s,a) = 1\), \(f(s,a) = s\) and \(\beta = 1\). For every real \(c\), the pair \((U_0, U_1) = (1 + c, c)\) satisfies \(U_0(s) = 1 + U_1(s)\), so there are infinitely many solutions of the equation for \(t = 0\). Only \(c = B(s)\) is the solution of Theorem 1.4.
0053 2The Bellman operator and value iteration
0054 A cleaner statement of the recursion uses a map on functions. The map is defined for every function \(U\) from \(S\) to \(\R\), with \(\beta\) as in §1.
0055 Definition 2.1 (the Bellman operator and value iteration)
0056 The Bellman operator \(\mathcal{G}\) sends a function \(U\) on \(S\) to the function
0057 \[
0058 (\mathcal{G}U)(s) = \max_{a \in A(s)} \bigl\{ r(s,a) + \beta\, U(f(s,a)) \bigr\}.
0059 \]
0060 Value iteration starts from a function \(U^{0}\) on \(S\) and sets \(U^{n+1} = \mathcal{G} U^{n}\) for \(n \ge 0\).
0061 Lemma 2.2 (time shift)
0062 Under the hypotheses of Definition 1.1, fix a function \(C\) on \(S\) to use as terminal reward. Let \(V^{(H)}_t\) be the discounted value function at time \(t\) of the problem with the data of Definition 1.1, horizon \(H\) and terminal reward \(C\). For \(0 \le t \le H\), \(V^{(H)}_t = V^{(H-t)}_0\) as functions on \(S\), where \(V^{(H-t)}_0\) is the value at time 0 of the problem with horizon \(H-t\), the same data and the same terminal reward \(C\).
0063 Proof
0064 The constraints \(a_k \in A(s_k)\) and \(s_{k+1} = f(s_k, a_k)\) do not mention the time, and the terminal reward \(C\) is the same function in both problems. Shifting every index by \(t\) maps a plan \((a_t, \ldots, a_{H-1})\) from \((t,s)\) to a plan \((a_0', \ldots, a_{H-t-1}')\) from \((0,s)\) with the same actions and states, and it maps the discounted total of Definition 1.1 to the same number. The exponent \(k-t\) in the sum is the shifted index, and the terminal reward \(B(s_H)\) gets the exponent \(\beta^{H-t}\), which is the shifted horizon. The shift is a bijection between the two sets of plans, so the two maxima agree.
0065 Proposition 2.3 (iterates are finite-horizon values)
0066 Under the hypotheses of Definition 1.1, with \(\beta \ge 0\), let \(U^{0}\) be any function on \(S\), and let \(W^{(n)}_0\) be the value at time 0 of the \(n\)-period problem with the same data and terminal reward \(U^{0}\), so that \(W^{(0)}_0 = U^{0}\). Then \(U^{n} = W^{(n)}_0\) for every whole number \(n \ge 0\).
0067 Proof
0068 The proof is by induction on \(n\). For \(n = 0\), the only plan is the empty plan, whose total is \(U^{0}(s)\), so \(W^{(0)}_0 = U^{0}\). Suppose \(U^{n} = W^{(n)}_0\). The proof of Theorem 1.3 uses no property of the terminal reward, so it applies to the \((n+1)\)-period problem with terminal reward \(U^{0}\) at \(t = 0\). Hence \(W^{(n+1)}_0(s) = \max_{a \in A(s)} \{ r(s,a) + \beta\, W^{(n+1)}_1(f(s,a)) \}\). By Lemma 2.2, applied with terminal reward \(U^{0}\), the value at time 1 of the \((n+1)\)-period problem is the value at time 0 of the \(n\)-period problem, \(W^{(n+1)}_1 = W^{(n)}_0 = U^{n}\). Hence \(W^{(n+1)}_0 = \mathcal{G} U^{n} = U^{n+1}\).
0069 Remark 2.4 (what value iteration does not show)
0070 Proposition 2.3 says that after \(n\) steps the iterate is the exact value of an \(n\)-period problem. It does not say that \(U^{n}\) approximates the value of a problem with no fixed horizon, and this lesson does not treat that case. The changes between successive iterates that Lab 1 prints describe the sequence. They are not a bound on the error of the iterates: the lesson states no limit, and Problem R3 shows that changes alone do not bound the distance to a limit.
0071 Lab 1 · The Bellman recursion, brute force and value iteration
0072 SIMULATED: a fixed toy maintenance problem with integer inputs, not market data. A machine is in condition 0 (good), 1 (worn) or 2 (worn out). Each period it runs, earning 6, 4 or 1 utils in conditions 0, 1 or 2, and it moves one step toward condition 2; or it is repaired, paying 4 utils and returning to condition 0 in the next period. The horizon is 6 periods, the terminal reward is 0, and the discount factor is 9/10. Stated before running: Part A should print the value table for t = 0 to 6 and an optimal action at each state for t = 0 to 5, with no tie at any (t, s) pair for t = 0 to 5; its entry for t = 0, state 0 should be 13.948890 utils. Part B should print recursion_matches_brute_force True, over 378 enumerated action sequences. Part C should print the change between iterates for n = 0 to 5, and iterate_equals_n_period_recursion True.
0073 """M7 L08 lab 1: the Bellman equation for a finite-horizon, discounted, finite-state problem, and value iteration.
0074 SIMULATED: a fixed toy maintenance problem. It is not market data and it uses no random draws. A machine is in one of
0075 three condition states, 0 (good), 1 (worn) or 2 (worn out). Each period it either runs or is repaired. Running earns
0076 the profit PROFIT[s] in utils and moves the condition one step toward 2 (2 stays 2). Repair costs 4 utils, and the
0077 condition is 0 in the next period. The discount factor is 9/10, the horizon is H = 6 periods, and the terminal reward
0078 is 0. All arithmetic is exact in fractions.Fraction, so the printed decimals are display only.
0079 Part A: the backward Bellman recursion from the terminal reward 0. It prints V_t(s) for t = 0 to 6, and the optimal
0080 action at each (t, s) for t = 0 to 5. It also counts the (t, s) pairs with a tie between the two actions, t = 0 to 5.
0081 Part B: brute force. For each t and s it takes the best discounted total over every action sequence of length H - t, and
0082 compares it exactly with the recursion.
0083 Part C: value iteration. Start from U^0 = 0 and apply the Bellman operator n times. It prints the largest change
0084 max_s |U^(n+1)(s) - U^n(s)| for n = 0 to 5, and checks that U^n equals V_(H-n) from Part A. It does not show that the
0085 iteration converges as n grows.
0086 """
0087 from __future__ import annotations
0088 from fractions import Fraction
0089 from itertools import product
0090 HORIZON = 6
0091 DISCOUNT = Fraction(9, 10)
0092 STATES = (0, 1, 2)
0093 ACTIONS = ("run", "repair")
0094 PROFIT = {0: 6, 1: 4, 2: 1}
0095 REPAIR_COST = 4
0096 def reward(state: int, action: str) -> Fraction:
0097 """Period reward in utils: the profit when running, minus the repair cost when repairing."""
0098 if action == "run":
0099 return Fraction(PROFIT[state])
0100 return Fraction(-REPAIR_COST)
0101 def next_state(state: int, action: str) -> int:
0102 """Condition in the next period: running moves one step toward 2, repair resets it to 0."""
0103 if action == "run":
0104 return min(state + 1, 2)
0105 return 0
0106 def bellman_step(u: dict[int, Fraction]) -> tuple[dict[int, Fraction], dict[int, str], int]:
0107 """Apply the Bellman operator to u: at each state, the largest of reward + DISCOUNT * u(next state).
0108 Returns the new function, the first action that attains the maximum at each state, and the number of states
0109 where both actions attain it. Values are exact fractions in utils.
0110 """
0111 new: dict[int, Fraction] = {}
0112 best: dict[int, str] = {}
0113 ties = 0
0114 for s in STATES:
0115 candidates = {a: reward(s, a) + DISCOUNT * u[next_state(s, a)] for a in ACTIONS}
0116 top = max(candidates.values())
0117 winners = [a for a in ACTIONS if candidates[a] == top]
0118 if len(winners) > 1:
0119 ties += 1
0120 new[s] = top
0121 best[s] = winners[0]
0122 return new, best, ties
0123 def backward_recursion(horizon: int, terminal: dict[int, Fraction]) -> list[dict[int, Fraction]]:
0124 """values[t][s] is V_t(s). V_horizon is the terminal reward; each earlier value applies the Bellman step."""
0125 values: list[dict[int, Fraction]] = [{} for _ in range(horizon + 1)]
0126 values[horizon] = dict(terminal)
0127 for t in range(horizon - 1, -1, -1):
0128 values[t], _, _ = bellman_step(values[t + 1])
0129 return values
0130 def brute_force(t: int, s: int, horizon: int) -> tuple[Fraction, int]:
0131 """Best discounted total from (t, s) over every action sequence of length horizon - t, and the count enumerated."""
0132 best: Fraction | None = None
0133 checked = 0
0134 for plan in product(ACTIONS, repeat=horizon - t):
0135 checked += 1
0136 state = s
0137 total = Fraction(0)
0138 weight = Fraction(1)
0139 for action in plan:
0140 total += weight * reward(state, action)
0141 weight *= DISCOUNT
0142 state = next_state(state, action)
0143 total += weight * Fraction(0)
0144 if best is None or total > best:
0145 best = total
0146 if best is None:
0147 raise RuntimeError("no action sequence")
0148 return best, checked
0149 def main() -> None:
0150 """Print Parts A, B and C. Each value is an exact fraction; the printed decimals are display only."""
0151 terminal = {s: Fraction(0) for s in STATES}
0152 values = backward_recursion(HORIZON, terminal)
0153 print("Part A: Bellman recursion, discount 9/10, horizon 6, terminal reward 0")
0154 for t in range(HORIZON + 1):
0155 cells = " ".join(f"V{s}={float(values[t][s]):.6f}" for s in STATES)
0156 print(f"t {t} {cells}")
0157 total_ties = 0
0158 for t in range(HORIZON):
0159 _, best, ties = bellman_step(values[t + 1])
0160 total_ties += ties
0161 actions = " ".join(f"s{s}={best[s]}" for s in STATES)
0162 print(f"policy t {t} {actions}")
0163 print(f"tied_pairs_t0_to_5 {total_ties}")
0164 print("Part B: brute force over every action sequence")
0165 all_match = True
0166 plans = 0
0167 for t in range(HORIZON):
0168 for s in STATES:
0169 brute_best, checked = brute_force(t, s, HORIZON)
0170 all_match = all_match and brute_best == values[t][s]
0171 plans += checked
0172 print(f"plans_enumerated {plans}")
0173 print(f"recursion_matches_brute_force {all_match}")
0174 print("Part C: value iteration from U^0 = 0")
0175 iterates = [dict(terminal)]
0176 for _ in range(6):
0177 new, _, _ = bellman_step(iterates[-1])
0178 iterates.append(new)
0179 for n in range(6):
0180 change = max(abs(iterates[n + 1][s] - iterates[n][s]) for s in STATES)
0181 print(f"n {n} change {float(change):.10f}")
0182 matches = all(iterates[n][s] == values[HORIZON - n][s] for n in range(7) for s in STATES)
0183 print(f"iterate_equals_n_period_recursion {matches}")

0212 3Where the canon breaks
0213 No fixed horizon. Each result in §1 and §2 fixes a finite number of periods, \(H\) in §1 and \(n\) in Proposition 2.3. Proposition 2.3 identifies each iterate with a finite-horizon value, and Remark 2.4 explains why that identification says nothing about an infinite horizon. This lesson states no infinite-horizon result.
0214 Deterministic transitions. The operator \(\mathcal{G}\) reads \(U\) at the single next state \(f(s,a)\). A random next state would replace that value with a weighted average over the next states, which this lesson does not define.
0215 Equations without the terminal condition. Remark 1.5 shows that the equations for \(t < H\) have infinitely many solutions in a one-state example. The terminal condition in Definition 1.2 is what makes the solution unique.
0216 Negative discount. Theorems 1.3 and 1.4 are stated for \(\beta \ge 0\), and the example below shows that Theorem 1.3 fails for \(\beta = -1\). Take \(H = 2\), one state \(s\), \(A(s) = \{x, y\}\), \(f(s,a) = s\), \(r(s,x) = 0\), \(r(s,y) = 1\), \(B(s) = 0\) and \(\beta = -1\). The four plans from \((0,s)\) have totals \(0\), \(-1\), \(1\) and \(0\), so \(V_0(s) = 1\), and \(V_1(s) = 1\). The Bellman equation gives \(U_1(s) = \max\{0, 1\} = 1\) and \(U_0(s) = \max\{0 + (-1) \cdot 1,\; 1 + (-1) \cdot 1\} = 0\). So \((V_0, V_1, V_2)\) is not a solution when \(\beta = -1\).
0217 Ties. Where two actions tie, the choice of optimal action at that state and time is not unique, so the policy (the optimal action at each state and time) is not determined. Corollary 2.4 of L07 says that any maximizing choice, followed forward, gives an optimal plan, but it is stated for \(\beta = 1\). This lesson does not write out that statement for \(\beta \ge 0\). Lab 1 prints no tie, so it does not illustrate this case.
0218 4Misconceptions
0219 “The iterate \(U^{n}\) does not depend on the starting function \(U^{0}\).”
0220 Definition 2.1 gives \((\mathcal{G}U)(s) = \max_{a \in A(s)} \{ r(s,a) + \beta\, U(f(s,a)) \}\), which reads \(U\) at the next states, so the output depends on the input. Take one state, one action with \(r = 1\), \(f(s,a) = s\) and \(\beta = 1\). Then \(U^{1} = 1 + U^{0}\): \(U^{0} = 0\) gives \(U^{1} = 1\), and \(U^{0} = 5\) gives \(U^{1} = 6\). Proposition 2.3 gives the general form: \(U^{n}\) is the exact value of an \(n\)-period problem whose terminal reward is \(U^{0}\), so it depends on \(U^{0}\). Lab 1 starts only from \(U^{0} = 0\), so its check does not test this dependence.
0221 “The Bellman equation by itself determines the value function.”
0222 Remark 1.5 gives a one-state, one-action problem in which the equation for \(t = 0\) has a solution for every real \(c\), with \(U_1 = c\). For \(\beta \ge 0\), Theorem 1.4 shows that the terminal condition \(U_H = B\) makes the solution unique, and the value function is that solution.
0223 “The best action in a state does not depend on how many periods remain.”
0224 Part A of Lab 1 prints the policy for state 2 as repair at t = 0 to 3 and run at t = 4 and 5. The recursion uses \(V_{t+1}\), and \(V_{t+1}\) depends on the remaining periods (Lemma 2.2). The same state can call for different actions at different times.

0226 Every problem has a full worked solution. Attempt each one before opening it. Problems M2 and M3 use the following problem. States \(x\) and \(y\), with \(A(x) = \{a, b\}\), \(A(y) = \{c\}\), \(f(x,a) = y\), \(f(x,b) = x\), \(f(y,c) = y\), \(r(x,a) = 2\), \(r(x,b) = 1\), \(r(y,c) = 3\), \(B(x) = B(y) = 0\), \(H = 2\) and \(\beta = 1/2\).
0227 Mechanics
0228 M1 · Two steps of the maintenance recursion
0229 In the maintenance problem of Lab 1, compute \(V_5(s)\) for each state, and then compute \(V_4(0)\), and check your answer against Part A.
0230 Solution
0231 With one period left (\(t = 5\), \(H = 6\)), \(V_5(s) = \max_a \{ r(s,a) + \tfrac{9}{10} B(f(s,a)) \} = \max_a \{ r(s,a) \}\), because \(B = 0\). In state 0 the profit 6 beats the repair cost \(-4\), so \(V_5(0) = 6\). In state 1 the profit is 4, and in state 2 it is 1, so \(V_5(1) = 4\) and \(V_5(2) = 1\). For \(V_4(0)\), running gives \(6 + \tfrac{9}{10} \cdot V_5(1) = 6 + 3.6 = 9.6\), and repairing gives \(-4 + \tfrac{9}{10} \cdot V_5(0) = -4 + 5.4 = 1.4\). So \(V_4(0) = 9.6\), which matches the t = 4 row of Part A.
0232 M2 · The value function of the two-state example
0233 Compute \(V_1(x)\), \(V_1(y)\), \(V_0(x)\) and \(V_0(y)\) for the problem above.
0234 Solution
0235 At time 1 there is one period left, and \(B = 0\). From \(x\), action \(a\) gives \(2 + 0 = 2\) and action \(b\) gives \(1 + 0 = 1\), so \(V_1(x) = 2\). From \(y\), action \(c\) gives \(3\), so \(V_1(y) = 3\). At time 0, from \(x\), action \(a\) gives \(2 + \tfrac12 V_1(y) = 2 + 1.5 = 3.5\) and action \(b\) gives \(1 + \tfrac12 V_1(x) = 1 + 1 = 2\), so \(V_0(x) = 3.5\), attained by \(a\). From \(y\), \(V_0(y) = 3 + \tfrac12 V_1(y) = 3 + 1.5 = 4.5\).
0236 M3 · A discounted total checked against the value
0237 For the problem above, compute the discounted total of the plan \((a, c)\) from \((0,x)\) and confirm that it equals \(V_0(x)\).
0238 Solution
0239 The plan takes \(a\) at \(x\), which moves to \(y\), and then \(c\) at \(y\), which stays at \(y\). Its discounted total is \(r(x,a) + \tfrac12 r(y,c) + \tfrac14 B(y) = 2 + 1.5 + 0 = 3.5\). This equals \(V_0(x) = 3.5\) from M2, so the plan is optimal.
0240 Proof
0241 P1 · The Bellman equation at horizon one
0242 Let \(H = 1\). Show that the Bellman equation of Definition 1.2 has exactly one solution, and identify it.
0243 Solution
0244 The terminal equation forces \(U_1 = B\). The only equation for \(t = 0\) is \(U_0(s) = \max_{a \in A(s)} \{ r(s,a) + \beta\, B(f(s,a)) \}\), which determines \(U_0\) uniquely from \(B\). So the solution is \((U_0, U_1)\) with \(U_1 = B\) and \(U_0\) given by that maximum. This is the value function of Definition 1.1 at \(H = 1\). The only plan from \((0,s)\) is one action \(a\), with total \(r(s,a) + \beta B(f(s,a))\), so \(V_0(s)\) is the maximum in the equation for \(U_0\). No sign condition on \(\beta\) is used, because a plan from \((0,s)\) has one term.
0245 P2 · The time shift for one period
0246 Let \(H = 2\). Show directly that \(V^{(2)}_1(s) = V^{(1)}_0(s)\) for every \(s\), where \(V^{(1)}_0\) is the value of the one-period problem with the same data. This is Lemma 2.2 for one shift.
0247 Solution
0248 A plan from \((1,s)\) in the two-period problem is a single action \(a \in A(s)\), with discounted total \(\beta^{0} r(s,a) + \beta^{1} B(f(s,a)) = r(s,a) + \beta B(f(s,a))\). A plan from \((0,s)\) in the one-period problem is also a single action, with discounted total \(\beta^{0} r(s,a) + \beta^{1} B(f(s,a))\). The two sets of totals are identical, so their maxima agree, and \(V^{(2)}_1(s) = V^{(1)}_0(s)\).
0249 P3 · Why the terminal condition is needed
0250 Take \(\beta = 1\) as in Remark 1.5. Verify the claim that for every real \(c\), the pair \((1 + c, c)\) solves the equation for \(t = 0\), and state which member of this family is the value function when \(B(s) = 0\).
0251 Solution
0252 With one action \(a\), \(f(s,a) = s\) and \(\beta = 1\), the equation for \(t = 0\) reads \(U_0(s) = r(s,a) + \beta U_1(s) = 1 + U_1(s)\). Setting \(U_0(s) = 1 + c\) and \(U_1(s) = c\) satisfies it for every \(c\). The terminal equation \(U_1 = B\) fixes \(c = B(s) = 0\), which gives \(U_0(s) = 1\). That is the value function, because the only plan has total \(1 + B(s) = 1\).

0266 Research
0267 R1 · Where the sign of the discount factor enters
0268 Theorems 1.3 and 1.4 are stated for \(\beta \ge 0\). Identify every step of their proofs that uses \(\beta\), say which step uses its sign, and say what fails for \(\beta < 0\).
0269 Solution
0270 In the proof of Theorem 1.3, the identity \(J_t(a,q) = r(s,a) + \beta J_{t+1}(q)\) is algebraic and holds for every real \(\beta\). The step that uses the sign is \(\max_q \beta J_{t+1}(q) = \beta \max_q J_{t+1}(q)\), which holds when \(\beta \ge 0\). For \(\beta < 0\) the maximum over \(q\) of \(\beta J_{t+1}(q)\) is \(\beta\) times a minimum, and the example in §3 with \(\beta = -1\) shows that Theorem 1.3 then fails. In the proof of Theorem 1.4, \(\beta\) appears only in the equations that both families satisfy, so the induction inherits the same restriction through Theorem 1.3. The maxima are over finite sets, so each maximum exists by finiteness alone.
0271 R2 · The iterate written as a sum over plans
0272 Using Proposition 2.3 and Definition 1.1, write \(U^{2}(s)\) as a maximum over action sequences of length 2, for an arbitrary starting function \(U^{0}\).
0273 Solution
0274 Proposition 2.3 with \(n = 2\) says that \(U^{2}(s)\) is the value at time 0 of the two-period problem with terminal reward \(U^{0}\). By Definition 1.1 with \(B\) replaced by \(U^{0}\), this value is the maximum, over action sequences \((a_0, a_1)\) that are feasible from \(s\), of \(r(s,a_0) + \beta\, r(s_1,a_1) + \beta^{2} U^{0}(s_2)\), where \(s_1 = f(s,a_0)\) and \(s_2 = f(s_1,a_1)\). The terminal function \(U^{0}\) enters only through \(\beta^{2} U^{0}(s_2)\).
0275 R3 · What a shrinking change would need to show
0276 Suppose the changes between successive iterates shrink, as in Part C. Explain what additional result would be needed before the change could bound the distance from \(U^{n}\) to a limit, and why this lesson does not supply it.
0277 Solution
0278 A change between successive iterates does not by itself bound the distance to a limit. For example, \(u_n = 1/n\) has limit 0 and changes \(|u_{n+1} - u_n| = 1/(n(n+1))\), which tend to 0. Its distance \(|u_n - 0| = 1/n\) is \(n+1\) times the change at step \(n\), so no constant bound of the form distance \(\le C\) times change holds. A bound needs an extra fact, such as a rate that connects the change at step \(n\) to the remaining distance. Proposition 2.3 identifies each iterate with a finite-horizon value and says nothing about a limit. So a shrinking sequence of changes, such as the one in Part C, is an observation about this instance and does not by itself bound the error of any iterate.
