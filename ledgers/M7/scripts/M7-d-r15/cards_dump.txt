M7-c001 L01 [T]
 F: What is a convex set?
 B: A set S in R^n such that for every x and y in S and every λ in [0, 1], the point λx + (1 − λ)y lies in S (Definition 1.1). Equivalently, S contains the segment between any two of its points.
M7-c002 L01 [T]
 F: What is a convex function on a convex set S?
 B: A function f: S → R such that f(λx + (1 − λ)y) ≤ λf(x) + (1 − λ)f(y) for every x and y in S and every λ in [0, 1] (Definition 2.1). The definition names S, so convexity is always relative to a stated set.
M7-c003 L01 [T]
 F: Is the closed unit disk convex, and why?
 B: Yes. For x, y in the disk and λ in [0, 1], the triangle inequality gives ||λx + (1 − λ)y|| ≤ λ||x|| + (1 − λ)||y|| ≤ 1 (Example 1.2).
M7-c004 L01 [T]
 F: Is an intersection of convex sets convex?
 B: Yes. The intersection of any nonempty family of convex subsets of R^n is convex. The hypothesis is that each set in the family is convex (Proposition 1.3).
M7-c005 L01 [T]
 F: Is the sublevel set {x in S : f(x) ≤ c} of a convex function convex?
 B: Yes. For a convex set S, a convex function f on S, and a real c, the sublevel set is convex (Proposition 2.3). The hypotheses are that S is convex, f is convex on S, and c is real.
M7-c006 L01 [T]
 F: What is the gap identity for a quadratic form q(x) = x'Qx?
 B: For real symmetric Q, every real λ, and all x and y: λq(x) + (1 − λ)q(y) − q(λx + (1 − λ)y) = λ(1 − λ)(x − y)'Q(x − y) (Lemma 3.1). The identity uses symmetry of Q and no restriction on λ.
M7-c007 L01 [T]
 F: What is the Hessian of q(x) = x'Qx for a real symmetric Q?
 B: The constant matrix 2Q, the same at every point. The gradient is 2Qx (Example 3.2a).
M7-c008 L01 [T]
 F: When is a quadratic form x'Qx convex on R^n?
 B: For real symmetric n × n Q, the statements (i) the form is convex on R^n and (ii) x'Qx ≥ 0 for every x, that is, Q is positive semidefinite, are equivalent (Proposition 3.2). Assuming Assumption 1 (the spectral theorem), both are also equivalent to (iii): every eigenvalue of Q is non-negative. The step from (ii) to (iii) uses the spectral theorem.
M7-c009 L01 [T]
 F: What are the eigenvalues of Q1 = [[2, 1], [1, 2]]?
 B: 3 and 1. The eigenvectors (1, 1) and (1, −1) give these values directly (Example 3.3).
M7-c010 L01 [T]
 F: For Q2 = [[1, 2], [2, 1]], x = (1, 0), y = (0, 1) and λ = 1/2, what is the gap λq(x) + (1 − λ)q(y) − q(λx + (1 − λ)y)?
 B: −1/2. Lemma 3.1 gives (1/4)(x − y)'Q2(x − y) with x − y = (1, −1) and (1, −1)Q2(1, −1)' = −2, so the gap is −1/2. The midpoint value is 3/2 and the chord value is 1.
M7-c011 L01 [T]
 F: Why is a symmetric matrix assumed in the quadratic-form lemma?
 B: The expansion in Lemma 3.1 uses y'Qx = x'Qy, which needs symmetry. A non-symmetric Q gives the same quadratic form as its symmetric part (Q + Q')/2 (Section 3). Problem R1 is an instance of that argument.

M7-c013 L01 [T]
 F: Can one failing case in a finite grid check refute convexity?
 B: Yes. Definition 2.1 quantifies over every pair of points and every weight, so one failing triple refutes convexity on the set where it occurs. In Lab 1, Q2 fails at x = (1, 0), y = (0, 1) and weight 1/2: the midpoint value is 3/2 and the chord value is 1.
M7-c014 L01 [T]
 F: Misconception: a set whose boundary is curved cannot be convex. True or false?
 B: False. The closed disk has a curved boundary and is convex, because it contains the segment between any two of its points (Example 1.2). The test is whether the segment between two points stays in the set, not whether the boundary is curved.
M7-c015 L01 [T]
 F: Misconception: a quadratic form is convex when its diagonal entries are positive. True or false?
 B: False. Q2 = [[1, 2], [2, 1]] has positive diagonal entries, yet x'Q2x is not convex because its eigenvalue −1 is negative. A negative eigenvalue refutes convexity whatever the diagonal (Problem P3). Under Assumption 1, Proposition 3.2 (iii) requires every eigenvalue to be non-negative, not only the diagonal.
M7-c016 L01 [C basis=Lab 1 (exact count on the 25-point grid)]
 F: Misconception: if the chord inequality holds for many pairs of points, the function is convex. True or false?
 B: False. A convex function must satisfy the chord inequality for every pair of points and every weight. In Lab 1, 2573 of 3125 Q2 cases pass and 552 fail, so the passing count is not a proof of convexity.
M7-c017 L02 [T]
 F: What is a Lagrange multiplier of f at a feasible point x* for the constraint h(x) = 0?
 B: A real number λ with ∇f(x*) = λ∇h(x*) (Definition 2.1). The sign convention is ∇f = λ∇h, not ∇f + λ∇h = 0.
M7-c018 L02 [T]
 F: State the necessity theorem for the Lagrange condition on an equality constraint.
 B: Under Assumption 1 (the implicit function theorem, from M2): let U in R^n be open, f and h continuously differentiable on U, x* in U with h(x*) = 0 and ∇h(x*) ≠ 0, and x* a local minimizer of f on {x in U : h(x) = 0}. Then there is a real λ with ∇f(x*) = λ∇h(x*) (Theorem 2.2). The hypotheses are openness, continuous differentiability, feasibility, the regularity condition ∇h(x*) ≠ 0, and minimality on the feasible set.
M7-c019 L02 [T]
 F: For h(x, y) = y² − x³ and f(x, y) = x, why is the origin a minimizer on the feasible set?
 B: The feasible set y² = x³ forces x = (y²)^{1/3} ≥ 0, so f = x ≥ 0 = f(0, 0) at every feasible point (Example 2.5).
M7-c020 L02 [T]
 F: In Example 2.6, which feasible points show that the origin is not a local minimizer of f(x, y) = y³ on h(x, y) = x = 0, and what are their values?
 B: The points (0, −y) with y > 0 are feasible and lie arbitrarily close to the origin, with f(0, −y) = −y³ < 0 = f(0, 0). The witness (0, −1) alone already refutes global minimality (Example 2.6).
M7-c021 L02 [T]
 F: Is the Lagrange multiplier unique when ∇h(x*) ≠ 0?
 B: If ∇h(x*) ≠ 0 and λ and μ are both Lagrange multipliers of f at x* for h = 0, then λ = μ (Proposition 2.4). The hypothesis ∇h(x*) ≠ 0 is what cancels λ − μ from (λ − μ)∇h(x*) = 0.
M7-c022 L02 [T]
 F: What is the closed-form minimum-variance solution under the budget 1'w = 1 for a positive definite Σ?
 B: Put u = Σ⁻¹1, s = 1'u and λ = 1/s. Then w* = λu is the unique minimizer of (1/2)w'Σw over {w : 1'w = 1}, and Σw* = λ1 (Proposition 3.2). The hypotheses are that Σ is symmetric and positive definite, and that the constraint is the budget. No sign condition on w is imposed.
M7-c023 L02 [T]
 F: For a positive definite Σ and the budget 1'w = 1, what is the increase f(w* + d) − f(w*) when 1'd = 0?
 B: It equals (1/2)d'Σd, which is non-negative and zero only at d = 0 (Proposition 3.2 (d)). The linear term vanishes because w*'Σd = λ1'd = 0.
M7-c024 L02 [T]
 F: Is A'A + I symmetric and positive definite for every real square matrix A?
 B: Yes. It is symmetric, and x'(A'A + I)x = ||Ax||² + ||x||² > 0 for x ≠ 0 (Proposition 3.3).
M7-c025 L02 [T]
 F: What is the minimum value of (1/2)w'Σw under the budget 1'w = 1 with Σ positive definite?
 B: λ/2 = 1/(2s), where s = 1'Σ⁻¹1 (Problem P3). This follows from w*'Σw* = λ1'w* = λ.
M7-c026 L02 [T]
 F: For Σ = diag(1, 2) and the budget w1 + w2 = 1, what are λ, w* and the minimum value?
 B: λ = 2/3, w* = (2/3, 1/3) and the minimum value is 1/3 (Problem M2). The gradient Σw* = (2/3, 2/3) = (2/3)1.

M7-c031 L02 [T]
 F: Misconception: at a constrained minimum the gradient of the objective is zero. True or false?
 B: False. At a minimizer on a regular equality constraint, the gradient is a multiple of the constraint gradient, not zero in general. For f = x² + y² on x + y = 1, the minimizer is (1/2, 1/2), and ∇f = (1, 1) = 1·∇h (Theorem 2.2, under Assumption 1).
M7-c032 L02 [T]
 F: Misconception: a point that satisfies the Lagrange condition is a minimizer. True or false?
 B: False. The condition is necessary, not sufficient. The origin of f = y³ with h = x satisfies it with λ = 0 and is not a minimizer (Example 2.6). Sufficiency for the budget problem comes from positive definiteness in Proposition 3.2.
M7-c033 L02 [T]
 F: Misconception: the Lagrange condition holds at every minimizer whatever the constraint. True or false?
 B: False. Theorem 2.2 requires ∇h(x*) ≠ 0. In Example 2.5 the minimizer at the origin has ∇h = 0 and no multiplier, so the regularity hypothesis is needed for the conclusion.
M7-c036 L03 [T]
 F: What is the feasible set F of problem (P)?
 B: The set of points x in R^n that satisfy every constraint g_i(x) ≤ 0 and h_j(x) = 0 (Definition 1.1).
M7-c037 L03 [T]
 F: When is a constraint g_i(x) ≤ 0 active, and when is it slack?
 B: It is active at x when g_i(x) = 0 and slack when g_i(x) < 0 (Definition 1.1).
M7-c038 L03 [T]
 F: What is a KKT point of problem (P)?
 B: A pair (x*, (λ, ν)) that satisfies four conditions (Definition 1.2): (K1) stationarity, ∇f(x*) + Σ λ_i∇g_i(x*) + Σ ν_j∇h_j(x*) = 0; (K2) primal feasibility, x* in F; (K3) dual feasibility, λ_i ≥ 0 for every i; (K4) complementary slackness, λ_i g_i(x*) = 0 for every i.
M7-c039 L03 [T]
 F: What does complementary slackness (K4) say, and what does it not say?
 B: For each i, at least one of λ_i and g_i(x*) is zero. It does not say which one. An active constraint can have a zero multiplier, and a slack constraint must have a zero multiplier (Remark 1.3).
M7-c040 L03 [T]
 F: What is the gradient inequality for a convex differentiable function, and what does it give at a zero gradient?
 B: For convex differentiable φ on R^n and all x, y: φ(x) ≥ φ(y) + ∇φ(y)'(x − y) (Lemma 1.4). If ∇φ(y) = 0, then y minimizes φ over R^n.
M7-c041 L03 [T]
 F: When is q(w) = (1/2)w'Σw − c'w convex, and what is its gradient?
 B: When Σ is symmetric with x'Σx ≥ 0 for all x, q is convex on R^n for every c (Lemma 1.5). Its gradient is Σw − c.
M7-c042 L03 [T]
 F: State the sufficiency theorem for KKT conditions.
 B: Assume f and each g_i are convex and differentiable on R^n, and each h_j is affine. If (x*, (λ, ν)) is a KKT point of (P), then x* is optimal and f(x*) = p* (Theorem 2.1). No hypothesis beyond these is used (Remark 2.2).
M7-c043 L03 [T]
 F: Is x* = 0 a KKT point of f(x) = x³ with no constraints, and is it a minimizer?
 B: It satisfies (K1) to (K4) trivially, since f'(0) = 0 (Example 2.3). It is not a minimizer: f(−1) = −1 < 0 = f(0). The function is not convex, since the midpoint value f(−1/2) = −1/8 exceeds the average −1/2 of f(−1) and f(0).
M7-c044 L03 [T]
 F: In Example 3.1, why does no KKT point exist at the optimum of minimizing x subject to x² ≤ 0?
 B: The feasible set is {0}, so x* = 0 is optimal. The gradient of g_1 = x² at 0 is 0, so (K1) reads 1 = 0 and fails for every multiplier. Slater's condition fails, since no point satisfies x² < 0 (Example 3.1).

M7-c056 L04 [T]
 F: What is the dual function g(λ, ν), and when is a pair (λ, ν) dual feasible?
 B: g(λ, ν) = inf over x in R^n of L(x, λ, ν), a number or −∞. A pair (λ, ν) is dual feasible when λ_i ≥ 0 for every i and g(λ, ν) is finite (Definition 1.1).
M7-c057 L04 [T]
 F: Is the dual function concave, and does this need convexity of the problem?
 B: Yes, on the set where it is finite. For a given x the Lagrangian is affine in (λ, ν), and the infimum of a sum is at least the sum of the infima (Proposition 1.2). The proof uses no convexity of f or the g_i.
M7-c058 L04 [T]
 F: State weak duality.
 B: For every dual feasible (λ, ν), g(λ, ν) ≤ p*. Hence d* ≤ p*. The statement needs no convexity assumption (Proposition 1.3). The proof uses λ_i ≥ 0, g_i(x) ≤ 0 and h_j(x) = 0 for feasible x.
M7-c059 L04 [T]
 F: What bound do finite grids of primal and dual points give on the duality gap?
 B: For finite non-empty F̃ in F and dual feasible D̃, min over F̃ of f minus max over D̃ of g is at least p* − d*, which is at least 0 (Proposition 1.4). Finiteness makes the minimum and maximum exist.
M7-c060 L04 [T]
 F: Can a dual grid show a positive gap when the true duality gap is zero?
 B: Yes. Restricting the dual grid of Lab 1 to λ = (0, 0) and ν in steps of 1/10 on [−1, 0] gives a grid gap of 7/300, while the true gap is zero (Problem R3). A grid gap bounds the true gap only from above (Remark 1.5).
M7-c061 L04 [T]
 F: Hypotheses and conclusion of the KKT zero-gap proposition.
 B: Assume f and each g_i are convex and differentiable on R^n, and each h_j is affine. If (x̂, (λ*, ν*)) is a KKT point, then g(λ*, ν*) = f(x̂), and p* = d* = f(x̂). The dual optimum is attained at (λ*, ν*) and the primal optimum at x̂ (Proposition 2.1).

 B: A Slater point x̄ satisfies g_i(x̄) < 0 for every inequality and h_j(x̄) = 0 for every equality. Slater's condition is the statement that a Slater point exists (Definition 3.1).

 B: False. Each dual value is a lower bound on p*, so the best bound is the largest value, and the dual problem maximizes g (Proposition 1.3 and Definition 1.1).

M7-c073 L05 [T]
 F: What is a quadratic program with data Q, c, A, b, G, h?
 B: min over x in R^n of f(x) = (1/2)x'Qx + c'x subject to Ax = b and Gx ≤ h, with Q real symmetric. Its feasible set is {x : Ax = b, Gx ≤ h} (Definition 1.1). With no inequality rows it is an equality-constrained QP.
M7-c074 L05 [T]
 F: Does a non-symmetric Q lose generality in a quadratic program?
 B: No. x'Qx = x'((Q + Q')/2)x for every x, so only the symmetric part of Q matters (Remark 1.2).
M7-c075 L05 [T]
 F: What is the exact quadratic expansion of f(x) = (1/2)x'Qx + c'x?
 B: For symmetric Q and all x, d: f(x + d) = f(x) + (Qx + c)'d + (1/2)d'Qd (Lemma 1.3). So ∇f(x) = Qx + c and the Hessian is the constant matrix Q.
M7-c076 L05 [T]
 F: When does the tangent plane of a QP objective lie below it everywhere?
 B: When Q is symmetric positive semidefinite: f(y) ≥ f(x) + (Qx + c)'(y − x) for all x and y (Lemma 1.4). The proof applies Lemma 1.3 with d = y − x.
M7-c077 L05 [T]
 F: When is the KKT matrix K = [[Q, A'], [A, 0]] nonsingular?
 B: When Q is symmetric positive definite and A has full row rank (Proposition 2.1). The proof shows that Kv = 0 forces v = 0.
M7-c078 L05 [T]
 F: What happens to K when two rows of A are equal?
 B: K is singular. For n = 2, Q = I and both rows of A equal (1, 0), rows three and four of K coincide, so det K = 0 (Remark 2.2). The full row rank hypothesis cannot be dropped.
M7-c079 L05 [T]
 F: State the unique-minimizer theorem for an equality-constrained QP.
 B: Assume Q is symmetric positive definite and A has full row rank. Let (x̂, λ*) solve the KKT system K(x, λ) = (−c, b). Then x̂ is the unique minimizer of f over {x : Ax = b} (Theorem 2.3). The proof uses Lemma 1.3 and the first block row.
M7-c080 L05 [T]

 B: xᵀQx = (2x1 + (1/2)x2)² + (11/4)(x2 + (4/11)x3)² + (18/11)x3², which is positive unless x = 0 (Remark 2.4).
M7-c081 L05 [T]
 F: State the sufficiency theorem for KKT points of a convex QP.
 B: Assume Q is symmetric positive semidefinite. Let x̄ be feasible, and suppose there are λ̄ and μ̄ ≥ 0 with Qx̄ + c + A'λ̄ + G'μ̄ = 0 and μ̄_i(Gx̄ − h)_i = 0 for every i. Then x̄ minimizes f over the feasible set (Theorem 3.1). The proof uses Lemma 1.4 and the sign μ̄ ≥ 0.

M7-c083 L05 [T]

M7-c121 L07 [T]
 F: What data define a finite-horizon decision problem?
 B: A finite set S of states; for each s a nonempty finite set A(s) of actions; a deterministic transition map f(s, a) in S; a period reward r(s, a) in R; and a terminal reward B(s) in R paid at time H (Definition 1.1).
M7-c122 L07 [T]
 F: What is a plan from (t, s), its total reward J_t(p), and the value V_t(s)?
 B: A plan from (t, s) is a sequence of actions (a_t, ..., a_{H−1}) that are feasible along the states it visits, starting from s_t = s. Its total reward is J_t(p) = Σ_{k=t}^{H−1} r(s_k, a_k) + B(s_H). The value V_t(s) is the maximum of J_t(p) over plans from (t, s), and a plan is optimal when J_t(p) = V_t(s) (Definition 1.2).

 F: Is f(x) = |x| convex on R, and is differentiability needed?
 B: Yes. For λ in [0, 1], the triangle inequality gives |λx + (1 − λ)y| ≤ λ|x| + (1 − λ)|y|, which is the defining inequality (Example 2.2). The function is not differentiable at 0, so convexity does not require smoothness.
M7-c185 L02 [T]
 F: When is a symmetric matrix Σ positive definite?
 B: When x′Σx > 0 for every x ≠ 0. This is stronger than non-negativity, because it excludes a zero value at a non-zero x (Section 3).
