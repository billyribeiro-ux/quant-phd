0014 A quadratic program minimises a quadratic objective under linear constraints. This lesson defines that problem and proves the results named here under stated hypotheses. An equality-constrained problem has a unique minimiser when its Hessian is positive definite and its constraint rows are independent (Theorem 2.3). For a convex QP, with Q positive semidefinite, the KKT conditions with nonnegative inequality multipliers are sufficient for optimality (Theorem 3.1). A positive-definite Hessian gives at most one minimiser over a feasible set that contains the midpoint of any two of its points (Proposition 3.4). Lab 1 solves a three-variable equality problem in exact arithmetic and enumerates the sets fixed at zero in a two-variable problem. Lesson 6 applies the problem to mean-variance portfolio choice.
0015 1The problem and its gradient
0016 Vectors are columns, \(x^{\top}\) is the transpose of \(x\), and \(\mathbf{1}\) is the vector of ones. A quadratic form \(x^{\top}Qx\) is a real number for each \(x\).
0017 Definition 1.1 (quadratic program)
0018 Let \(Q\) be a real symmetric \(n \times n\) matrix, \(c \in \R^{n}\), \(A\) a real \(m \times n\) matrix with \(b \in \R^{m}\), and \(G\) a real \(p \times n\) matrix with \(h \in \R^{p}\). The quadratic program with these data is
0019 \[\min_{x \in \R^{n}} \; f(x) = \tfrac{1}{2}\,x^{\top}Qx + c^{\top}x \quad \text{subject to} \quad Ax = b, \; Gx \le h.\]
0020 Its feasible set is \(F = \{x \in \R^{n} : Ax = b,\; Gx \le h\}\), the set of points that satisfy every constraint. With \(p = 0\) the problem is an equality-constrained QP. With \(m = 0\) it has inequalities only.
0021 Remark 1.2 (only the symmetric part of Q matters)
0022 For any real \(n \times n\) matrix \(Q\), \(x^{\top}Qx = x^{\top}Q^{\top}x\), because a \(1 \times 1\) matrix equals its transpose. Averaging gives \(x^{\top}Qx = x^{\top}\tfrac{1}{2}(Q + Q^{\top})x\). So the definition loses no generality when \(Q\) is symmetric.
0023 Lemma 1.3 (exact quadratic expansion)
0024 Let \(Q\) be symmetric and \(f\) as in Definition 1.1. For all \(x, d \in \R^{n}\),
0025 \[f(x + d) = f(x) + (Qx + c)^{\top}d + \tfrac{1}{2}\,d^{\top}Qd.\]
0026 So the gradient of \(f\) at \(x\) is \(\nabla f(x) = Qx + c\), and the Hessian of \(f\) is the constant matrix \(Q\).
0027 Proof
0028 Expand \((x + d)^{\top}Q(x + d) = x^{\top}Qx + x^{\top}Qd + d^{\top}Qx + d^{\top}Qd\). The two middle terms are equal, because \(d^{\top}Qx\) is a real number equal to its transpose \(x^{\top}Q^{\top}d = x^{\top}Qd\). Hence \(\tfrac{1}{2}(x + d)^{\top}Q(x + d) = \tfrac{1}{2}x^{\top}Qx + x^{\top}Qd + \tfrac{1}{2}d^{\top}Qd\). Adding \(c^{\top}(x + d) = c^{\top}x + c^{\top}d\) gives \(f(x + d) = f(x) + (Qx)^{\top}d + c^{\top}d + \tfrac{1}{2}d^{\top}Qd\), which is the claim.
0029 Lemma 1.4 (the tangent plane lies below the quadratic)
0030 Let \(Q\) be symmetric and positive semidefinite, meaning \(d^{\top}Qd \ge 0\) for every \(d\). Then for all \(x, y\), \(f(y) \ge f(x) + (Qx + c)^{\top}(y - x)\). The function \(f\) is convex, in the sense defined in L01.
0031 Proof
0032 Apply Lemma 1.3 with the base point \(x\) and \(d = y - x\). It gives \(f(y) - f(x) - (Qx + c)^{\top}(y - x) = \tfrac{1}{2}(y - x)^{\top}Q(y - x) \ge 0\). For the convexity clause, let \(z = \theta x + (1 - \theta) y\) with \(\theta \in [0, 1]\). The linear terms of \(f\) cancel in the combination below, and the quadratic terms give \(\theta f(x) + (1 - \theta) f(y) - f(z) = \tfrac{1}{2}\theta(1 - \theta)(x - y)^{\top}Q(x - y) \ge 0\), because \(\theta - \theta^{2} = \theta(1 - \theta)\), \((1 - \theta) - (1 - \theta)^{2} = \theta(1 - \theta)\), and \(Q\) is positive semidefinite. This is the chord inequality \(f(z) \le \theta f(x) + (1 - \theta) f(y)\).
0033 2Equality constraints and the KKT linear system
0034 Let \(p = 0\), so \(F = \{x : Ax = b\}\). The Lagrangian of this section is \(\mathcal{L}(x, \lambda) = f(x) + \lambda^{\top}(Ax - b)\), with one multiplier \(\lambda_{k}\) for each row of \(A\). Its stationarity condition \(\nabla_{x}\mathcal{L} = 0\) reads \(Qx + c + A^{\top}\lambda = 0\). Together with \(Ax = b\), this is a linear system in \((x, \lambda)\):
0035 \[K \begin{pmatrix} x \\ \lambda \end{pmatrix} = \begin{pmatrix} -c \\ b \end{pmatrix}, \qquad K = \begin{pmatrix} Q & A^{\top} \\ A & 0 \end{pmatrix}.\]
0036 Proposition 2.1 (the KKT matrix is nonsingular)
0037 Assume \(Q\) is symmetric positive definite and \(A\) has full row rank \(m \le n\). Then \(K\) is a nonsingular \((n + m) \times (n + m)\) matrix.
0038 Proof
0039 It suffices to show that \(K v = 0\) forces \(v = 0\). Write \(v = (x, \lambda)\). The first block row gives \(Qx + A^{\top}\lambda = 0\), and the second gives \(Ax = 0\). Multiply the first by \(x^{\top}\): \(x^{\top}Qx + x^{\top}A^{\top}\lambda = 0\). Since \(x^{\top}A^{\top}\lambda = (Ax)^{\top}\lambda = 0\), we get \(x^{\top}Qx = 0\). Positive definiteness gives \(x = 0\). Then \(A^{\top}\lambda = -Qx = 0\). Full row rank means the columns of \(A^{\top}\) are independent, so \(\lambda = 0\). Hence \(K\) has trivial kernel, and a square matrix with trivial kernel is nonsingular.
0040 Remark 2.2 (dependent constraint rows make K singular)
0041 Take \(n = 2\), \(Q = I\), and \(A\) with both rows equal to \((1, 0)\). Then \(A\) has rank one, not two. The matrix \(K\) has rows \((1, 0, 1, 1)\), \((0, 1, 0, 0)\), \((1, 0, 0, 0)\) and \((1, 0, 0, 0)\). Rows three and four are equal, so \(\det K = 0\). The rank condition in Proposition 2.1 cannot be dropped.
0042 Theorem 2.3 (the equality-constrained QP has a unique minimiser)
0043 Assume \(Q\) is symmetric positive definite and \(A\) has full row rank. Let \((\hat{x}, \lambda^{*})\) be the solution of \(K(x, \lambda)^{\top} = (-c, b)^{\top}\), which exists and is unique by Proposition 2.1. Then \(\hat{x}\) is the unique minimiser of \(f\) over \(F = \{x : Ax = b\}\).
0044 Proof
0045 Let \(x \in F\) and put \(d = x - \hat{x}\). Then \(Ad = Ax - A\hat{x} = b - b = 0\). By Lemma 1.3, \(f(x) = f(\hat{x}) + (Q\hat{x} + c)^{\top}d + \tfrac{1}{2}d^{\top}Qd\). The first block row gives \(Q\hat{x} + c = -A^{\top}\lambda^{*}\), so \((Q\hat{x} + c)^{\top}d = -\lambda^{*\top}Ad = 0\). Therefore \(f(x) = f(\hat{x}) + \tfrac{1}{2}d^{\top}Qd\). If \(d \ne 0\), the last term is positive, so \(f(x) > f(\hat{x})\). If \(d = 0\), then \(x = \hat{x}\). So \(\hat{x}\) is the only minimiser.
0046 Remark 2.4 (the constraint line of a one-dimensional example)
0047 Take \(n = 3\), \(A\) with rows \((1, 1, 1)\) and \((0, 1, -1)\), \(b = (1, 0)\), and \(Q\) and \(c\) as in Lab 1. The rows are not proportional, so \(A\) has full row rank. The matrix \(Q\) is positive definite, because \(x^{\top}Qx = 4x_{1}^{2} + 3x_{2}^{2} + 2x_{3}^{2} + 2x_{1}x_{2} + 2x_{2}x_{3}\) equals \((2x_{1} + \tfrac{1}{2}x_{2})^{2} + \tfrac{11}{4}(x_{2} + \tfrac{4}{11}x_{3})^{2} + \tfrac{18}{11}x_{3}^{2}\), which is positive unless \(x = 0\). The vector \(v = (-2, 1, 1)\) satisfies \(Av = 0\), so \(F\) is the line \(\hat{x} + tv\) for real \(t\). Along it, \(f(\hat{x} + tv) = f(\hat{x}) + \tfrac{1}{2}t^{2}\,v^{\top}Qv\), by Lemma 1.3 with \(d = tv\), because the linear term vanishes: \(Q\hat{x} + c = -A^{\top}\lambda^{*}\) and \(Av = 0\), as in the proof of Theorem 2.3.
0048 3Inequality constraints and sufficiency of KKT
0049 Now let \(G\) and \(h\) be present. An active set of a point \(x \in F\) is the set of inequality rows that hold with equality at \(x\). In this lesson the Lagrangian is \(\mathcal{L}(x, \lambda, \mu) = f(x) + \lambda^{\top}(Ax - b) + \mu^{\top}(Gx - h)\). The KKT conditions for the QP are the conditions of the definition in L03 written for this \(f\):
0050 Stationarity. \(Qx + c + A^{\top}\lambda + G^{\top}\mu = 0\).
0051 Primal feasibility. \(Ax = b\) and \(Gx \le h\).
0052 Dual feasibility. \(\mu \ge 0\), componentwise.
0053 Complementary slackness. \(\mu_{i}(Gx - h)_{i} = 0\) for every \(i\).
0054 These are the conditions of the L03 definition for the constraints \(g_{i}(x) = (Gx - h)_{i} \le 0\) and \(h_{j}(x) = (Ax - b)_{j} = 0\), with the same Lagrangian sign, so the multipliers \(\mu_{i}\) of \(Gx \le h\) play the role of the L03 inequality multipliers \(\lambda_{i}\), which must be nonnegative. Theorem 3.1 needs that sign.
0055 Theorem 3.1 (KKT conditions are sufficient for a convex QP)
0056 Assume \(Q\) is symmetric positive semidefinite. Let \(\bar{x} \in F\), and suppose there are \(\bar{\lambda}\) and \(\bar{\mu} \ge 0\) with \(Q\bar{x} + c + A^{\top}\bar{\lambda} + G^{\top}\bar{\mu} = 0\) and \(\bar{\mu}_{i}(G\bar{x} - h)_{i} = 0\) for every \(i\). Then \(\bar{x}\) minimises \(f\) over \(F\).
0057 Proof
0058 Let \(x \in F\). By Lemma 1.4, \(f(x) \ge f(\bar{x}) + (Q\bar{x} + c)^{\top}(x - \bar{x})\). Stationarity gives \(Q\bar{x} + c = -A^{\top}\bar{\lambda} - G^{\top}\bar{\mu}\), so \((Q\bar{x} + c)^{\top}(x - \bar{x}) = -\bar{\lambda}^{\top}A(x - \bar{x}) - \bar{\mu}^{\top}G(x - \bar{x})\). The first term is zero, because \(A(x - \bar{x}) = (Ax - b) - (A\bar{x} - b) = 0\). For the second, \(G(x - \bar{x}) = (Gx - h) - (G\bar{x} - h)\), and complementary slackness gives \(\bar{\mu}^{\top}(G\bar{x} - h) = 0\). So \(-\bar{\mu}^{\top}G(x - \bar{x}) = \sum_{i}\bar{\mu}_{i}(h - Gx)_{i}\). Each term is nonnegative, since \(\bar{\mu}_{i} \ge 0\) and \(x\) is feasible. Hence \(f(x) \ge f(\bar{x})\).
0059 Remark 3.2 (a stationary point with a negative multiplier need not be optimal)
0060 Let \(n = 1\), \(Q = 1\), \(c = -1\), \(G = -1\), \(h = 0\), so the only constraint is \(x \ge 0\). The point \(\bar{x} = 0\) is feasible. Stationarity \(\bar{x} - 1 - \bar{\mu} = 0\) gives \(\bar{\mu} = -1\), which is negative. The point is not optimal: \(f(0) = 0\), while \(f(1) = \tfrac{1}{2} - 1 = -\tfrac{1}{2}\) and \(x = 1\) is feasible. Dual feasibility cannot be dropped from Theorem 3.1.
0061 Definition 3.3 (the S-candidate)
0062 For a set \(S\) of indices of rows of \(G\), the \(S\)-candidate is the solution \(x_{S}\), with multipliers, of the equality-constrained QP that keeps the constraints \(Ax = b\) and \(G_{i}x = h_{i}\) for \(i \in S\) and drops the other inequality constraints. When it exists, Theorem 2.3 identifies it when \(Q\) is symmetric positive definite and the rows of \(A\) and of \(G_{i}\) for \(i \in S\) are linearly independent. The method of Lab 1 Part B enumerates all \(2^{p}\) sets \(S\), keeps each candidate that passes the primal and dual tests of Section 3, and reports the kept ones.
0063 Proposition 3.4 (at most one minimiser when Q is positive definite)
0064 Assume \(Q\) is symmetric positive definite and \(F\) is midpoint convex: for \(x, y \in F\) the midpoint \(\tfrac{1}{2}(x + y)\) is in \(F\). Then \(f\) has at most one minimiser over \(F\). The proof uses only this midpoint property.
0065 Proof
0066 Let \(x \ne y\) both minimise \(f\) over \(F\), with common minimum value \(m\), and let \(z = \tfrac{1}{2}(x + y) \in F\). Put \(u = \tfrac{1}{2}(x - y)\) and \(g = Qz + c\). Since \(x = z + u\) and \(y = z - u\), Lemma 1.3 at the base point \(z\) gives \(f(x) = f(z) + g^{\top}u + \tfrac{1}{2}u^{\top}Qu\) and \(f(y) = f(z) - g^{\top}u + \tfrac{1}{2}u^{\top}Qu\). Adding the two lines cancels the linear terms: \(f(x) + f(y) = 2f(z) + u^{\top}Qu\). Since \(u^{\top}Qu = \tfrac{1}{4}(x - y)^{\top}Q(x - y)\), this is \(f(z) = \tfrac{1}{2}\big(f(x) + f(y)\big) - \tfrac{1}{8}(x - y)^{\top}Q(x - y)\). The last term is strictly negative, because \(Q\) is positive definite and \(x \ne y\). So \(f(z) < m\), which contradicts \(m\) being the minimum of \(f\) over \(F\), since \(z \in F\).
0067 Remark 3.5 (the feasible set of Lab 1 is convex)
0068 In Part B the constraints are \(x \ge 0\), which are linear, and \(Q = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}\) is positive definite, since \(x^{\top}Qx = (x_{1} + x_{2})^{2} + x_{1}^{2} + x_{2}^{2}\). If \(x\) and \(y\) satisfy them, so does \(\tfrac{1}{2}(x + y)\), because each coordinate of the midpoint is an average of two nonnegative numbers. So Proposition 3.4 applies to Lab 1 Part B.
0069 Example 3.6 (the minimiser in Lab 1, Part B, by hand)
0070 Let \(Q\) and \(c\) be as in Lab 1, Part B, with \(G = -I\) and \(h = 0\). Take \(\bar{x} = (3/2, 0)\). It is feasible. Here \(Q\bar{x} = (3, 3/2)\), so \(Q\bar{x} + c = (0, 5/2)\). Put \(\bar{\mu} = (0, 5/2)\). Then \(Q\bar{x} + c - \bar{\mu} = 0\), which is stationarity with \(G^{\top}\bar{\mu} = -\bar{\mu}\). Both multipliers are nonnegative, and \(\bar{\mu}_{i}\bar{x}_{i} = 0\) for each \(i\). By Theorem 3.1, \(\bar{x}\) minimises \(f\) over \(x \ge 0\), and \(f(\bar{x}) = \tfrac{1}{2}\cdot\tfrac{9}{2} - \tfrac{9}{2} = -\tfrac{9}{4}\).

0072 Lab 1 · An equality QP from its KKT system, and an enumeration of active sets
0073 The inputs are small integers chosen for this lab, not data, and the run uses no random draws. Stated before running. Part A solves the KKT system of Remark 2.4 in exact fractions. It predicts a nonzero KKT determinant, exact zero residuals in both block rows of the stationarity and constraint equations, and an exact match between \(f(\hat{x} + tv)\) and \(f(\hat{x}) + \tfrac{1}{2}t^{2}v^{\top}Qv\) at each of 17 values of \(t\) from \(-2\) to \(2\) in steps of \(1/4\). Part B lists the four sets of components fixed at zero for \(x \ge 0\) in two variables. It predicts that exactly one set passes both the primal test \(x \ge 0\) and the dual test on its fixed components, and that no point of a \(33 \times 33\) grid on \([0, 2]^{2}\) lies below that candidate's value.

0077 4Where the canon breaks
0078 An indefinite Hessian can leave a QP with no minimiser. The theorems above need \(Q\) positive definite (Theorem 2.3, Proposition 3.4) or positive semidefinite (Theorem 3.1). Without one of these, a QP can have no minimiser at all, as Misconception 1 shows.
0079 Semidefinite Hessians can have many minimisers. For \(Q = 0\), \(c = 0\) and no constraints, every point is a minimiser. Theorem 3.1 still holds for such a \(Q\), but it does not give uniqueness.
0080 Enumeration grows exponentially. The method of Definition 3.3 examines \(2^{p}\) candidate sets. Lab 1 uses \(p = 2\), so four candidates. This lesson does not describe a method that examines fewer.
0081 Exact arithmetic is limited to small problems. Lab 1 solves Part A in fractions for three variables. Its results are exact for these inputs, and they say nothing about floating-point solvers on larger problems.
0082 The sign convention is part of the statement. With the opposite sign for \(\mu\), the dual test in Theorem 3.1 would read \(\mu \le 0\). The results here use the convention fixed in Section 3.
0083 5Misconceptions
0084 “A quadratic objective always has a minimum, whatever the signs of its eigenvalues.”
0085 Take \(Q = \mathrm{diag}(1, -1)\), \(c = 0\), and no constraints. Along \(x = (0, t)\), \(f = -\tfrac{1}{2}t^{2}\), which tends to minus infinity as \(|t| \to \infty\). So \(f\) has no minimiser. Theorem 2.3 needs positive definiteness, and this \(Q\) is indefinite.
0086 “If a point satisfies the stationarity equation, it is optimal, whatever the multipliers are.”
0087 Remark 3.2 gives a feasible point that satisfies stationarity with a multiplier \(\bar{\mu} = -1\), and it is not optimal, because \(f(1) = -\tfrac{1}{2} < 0 = f(0)\). Theorem 3.1 requires \(\bar{\mu} \ge 0\), and that condition is what rules this out.
0088 “The minimiser of an equality-constrained QP is where the gradient of \(f\) is zero.”
0089 With \(Ax = b\), the gradient at the minimiser is \(-A^{\top}\lambda^{*}\), a combination of the constraint rows. It is zero exactly when \(\lambda^{*} = 0\), because \(A\) has full row rank. In Remark 2.4 the multipliers are \(\lambda^{*} = (-36/19, 11/19)\), which Lab 1 prints, so the gradient \(Q\hat{x} + c = -A^{\top}\lambda^{*}\) is not zero at \(\hat{x}\).

0092 Mechanics
0093 M1 · Minimise the squared norm on a line
0094 Minimise \(x_{1}^{2} + x_{2}^{2}\) subject to \(x_{1} + x_{2} = 1\). Find the minimiser and the multiplier \(\lambda\) of the constraint.
0095 Solution
0096 Here \(Q = 2I\), \(c = 0\), \(A = (1, 1)\), \(b = 1\). The first block row \(Qx + A^{\top}\lambda = 0\) gives \(2x_{1} + \lambda = 0\) and \(2x_{2} + \lambda = 0\), so \(x_{1} = x_{2} = -\lambda/2\). The constraint gives \(-\lambda = 1\), so \(\lambda = -1\) and \(x = (1/2, 1/2)\). The objective there is \(1/4 + 1/4 = 1/2\). Theorem 2.3 says this is the only minimiser.
0097 M2 · Positive definiteness by completing a square
0098 Show that \(Q = \begin{pmatrix} 1 & 2 \\ 2 & 5 \end{pmatrix}\) is positive definite.
0099 Solution
0100 Expand \(x^{\top}Qx = x_{1}^{2} + 4x_{1}x_{2} + 5x_{2}^{2}\). Since \((x_{1} + 2x_{2})^{2} = x_{1}^{2} + 4x_{1}x_{2} + 4x_{2}^{2}\), we get \(x^{\top}Qx = (x_{1} + 2x_{2})^{2} + x_{2}^{2}\). This is zero only when \(x_{2} = 0\) and then \(x_{1} = 0\). So \(x^{\top}Qx > 0\) for every \(x \ne 0\).
0101 M3 · The unconstrained minimiser
0102 For \(Q = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}\) and \(c = (-3, 1)\), find the minimiser of \(f\) with no constraints.
0103 Solution
0104 With no constraints the stationarity condition is \(Qx = -c = (3, -1)\). The system \(2x_{1} + x_{2} = 3\), \(x_{1} + 2x_{2} = -1\) has solution \(x_{1} = 7/3\) and \(x_{2} = -5/3\). Check: \(2(7/3) - 5/3 = 3\) and \(7/3 - 10/3 = -1\). The matrix is positive definite, so this is the unique minimiser. Its second coordinate is negative, which is why Lab 1 finds that the empty active set fails the primal test.
0105 Proof
0106 P1 · The gap between f and its tangent
0107 Let \(Q\) be symmetric. Prove that \(f(x) - f(y) - (Qy + c)^{\top}(x - y) = \tfrac{1}{2}(x - y)^{\top}Q(x - y)\) for all \(x\) and \(y\).
0108 Solution
0109 Apply Lemma 1.3 with base point \(y\) and \(d = x - y\). Lemma 1.3 gives \(f(x) = f(y) + (Qy + c)^{\top}(x - y) + \tfrac{1}{2}(x - y)^{\top}Q(x - y)\). Rearranging gives the claim. No other fact is used.
0110 P2 · Dependent rows make the KKT matrix singular
0111 Let \(Q\) be any symmetric matrix, and let the two rows of \(A\) be equal. Show that \(K\) is singular.
0112 Solution
0113 Let \(a^{\top}\) be the common row of \(A\). Then the last two rows of \(K\) are both \((a^{\top}, 0, 0)\), which are equal. Two equal rows make the determinant zero, so \(K\) is singular. This is the general form of Remark 2.2.
0114 P3 · The equal-weight minimiser
0115 Let \(Q = I\) on \(\R^{n}\), \(c = 0\), \(A = \mathbf{1}^{\top}\), and \(b = 1\). Show that the unique minimiser of \(\tfrac{1}{2}\|x\|^{2}\) subject to \(\mathbf{1}^{\top}x = 1\) is \(x_{i} = 1/n\) for each \(i\).
0116 Solution
0117 The first block row gives \(x + \lambda\mathbf{1} = 0\), so \(x = -\lambda\mathbf{1}\). The constraint gives \(\mathbf{1}^{\top}x = -n\lambda = 1\), so \(\lambda = -1/n\) and \(x = (1/n)\mathbf{1}\). Here \(Q = I\) is positive definite and \(A\) has full row rank, so Theorem 2.3 says this point is the unique minimiser.

0131 Research
0132 R1 · One variable with a nonnegativity constraint
0133 Minimise \(\tfrac{1}{2}qx^{2} + cx\) subject to \(x \ge 0\), where \(q > 0\). Show that the minimiser is \(\max(0, -c/q)\).
0134 Solution
0135 Write the constraint as \(-x \le 0\), so \(G = -1\), \(h = 0\). Stationarity is \(qx + c - \mu = 0\). If \(-c/q \ge 0\), take \(x = -c/q\) and \(\mu = 0\): the point is feasible, stationarity holds, and complementary slackness holds. If \(-c/q < 0\), then \(c > 0\); take \(x = 0\) and \(\mu = c > 0\): stationarity holds, the point is feasible, and \(x\mu = 0\). In both cases Theorem 3.1 applies, since \(q > 0\) gives a convex objective.
0136 R2 · Separable nonnegative minimisation
0137 Let \(n = 3\), \(Q = I\), \(c = (1, -1, -2)\), and impose \(x \ge 0\) componentwise. Find the minimiser.
0138 Solution
0139 The objective is \(\sum_{i}\big(\tfrac{1}{2}x_{i}^{2} + c_{i}x_{i}\big)\), and the constraints act on one coordinate each. So the minimum splits into three one-variable problems. By R1 with \(q = 1\), the minimiser of coordinate \(i\) is \(\max(0, -c_{i})\). This gives \(\hat{x} = (0, 1, 2)\).
0140 R3 · Two assets on the simplex
0141 Let \(Q = I\) and \(c = -r\) with \(r = (0.1, 0.02)\), and impose \(w \ge 0\) and \(w_{1} + w_{2} = 1\). Find the minimiser.
0142 Solution
0143 Try the point with both components positive and the constraint active, \(w = r + t\mathbf{1}\). The sum is \(0.12 + 2t = 1\), so \(t = 0.44\) and \(w = (0.54, 0.46)\). Both components are positive, so the nonnegativity constraints are inactive and the multipliers on them are zero. Stationarity is \(w - r + \lambda\mathbf{1} = 0\) with \(\lambda = -0.44\), which the point satisfies, since \(w - r = (0.44, 0.44)\). By Theorem 3.1 it is the minimiser.
