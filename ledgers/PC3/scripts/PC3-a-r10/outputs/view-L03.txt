51: A game whose payoff depends on chance has an average payoff, weighted by the probability of each outcome. This lesson measures what a player gains by choosing when to stop. It proves that the average of a sum of payoffs is the sum of their averages. It then proves, over a finite number of turns, that no rule for stopping that sees only the results so far (this lesson, Definition 3.7) changes the average total of a game whose average payoff is zero on every turn, given the results before it (Definition 3.5). A reroll game, solved backwards from the last choice, shows the same tools give a precise answer where that zero condition fails. All payoffs are integer cents.
53: 1 Expected payoffs and linearity
56: Assumption A1 (finite space, integer cents)
57: The outcome set \(\Omega\) is a finite probability space, as defined in M4 Lesson 1 , with weights \(p(\omega) > 0\) that sum to 1. Every payoff is an integer number of cents. No result below covers an infinite outcome set.
61: Definition 3.1 (expected payoff)
62: For a payoff \(X\) on \(\Omega\), with integer values in cents, the expected payoff is \(\E[X] = \sum_{\omega \in \Omega} X(\omega)\,p(\omega)\). It is the expectation of M4 on a finite space.
66: Proposition 3.2 (linearity over finite sums)
68: (H1) Assuming A1, \(X_1, \dots, X_m\) are payoffs on the same \(\Omega\).
70: Conclusion: \(\E[X_1 + \cdots + X_m] = \E[X_1] + \cdots + \E[X_m]\).
74: Proof
75: Fix \(\omega\). Then \((X_1 + \cdots + X_m)(\omega)\,p(\omega) = \sum_{i} X_i(\omega)\,p(\omega)\), by the distributive law of the reals. Summing over the finite set \(\Omega\) and exchanging the two finite sums gives \(\E[X_1 + \cdots + X_m] = \sum_i \sum_\omega X_i(\omega)\,p(\omega) = \sum_i \E[X_i]\). \(\blacksquare\)
79: Example 3.3 (a die and two dice)
80: For one fair die with faces \(1\) to \(6\), \(\E[\text{face}] = (1 + 2 + \cdots + 6)/6 = 21/6 = 7/2\). A game that pays \(100\) cents times the face has expected payoff \(100 \cdot 7/2 = 350\) cents. For two independent dice \(X\) and \(Y\), Proposition 3.2 gives \(\E[X + Y] = \E[X] + \E[Y] = 7\). Lab 1, Part 1 computes \(\E[X + Y]\) by enumerating all 36 outcomes and prints 7, and the same value for \(\E[X] + \E[Y]\).
83: 2 Expected-value games and fairness
86: Definition 3.4 (expected-value game)
87: An expected-value game is a finite game with integer payoffs in cents, a finite outcome set with weights, and a stated rule for when play stops. Its value under a rule is the expected payoff of Definition 3.1 when the rule is followed.
91: Definition 3.5 (fair game)
92: A one-turn game is fair when its expected payoff is zero. A multi-turn game is fair when, for every history (the list of earlier payoffs) of fewer than the game's number of turns that has positive probability, the expected payoff of the next turn given that history is zero. Each turn's expected payoff is taken in the conditional sense of Lesson 2, Definition 2.2.
96: Assumption A2 (the game in Section 3)
97: The fair game of Section 3 pays \(+100\) or \(-100\) cents on each turn, each with probability \(1/2\), and the turns are independent. Given any history of positive probability, the next turn's expected payoff is therefore \(100 \cdot \tfrac12 - 100 \cdot \tfrac12 = 0\), so the game is fair in the sense of Definition 3.5.
101: Example 3.6 (a reroll game, by backward induction)
102: Roll a fair die. Then choose one of two options. Stop pays \(100\) cents times the face. Reroll costs \(100\) cents, and it rolls the die once more and pays \(100\) cents times that face, with no further choice. The reroll option, whose value is called the continuation value, is worth \(\E[100 g] - 100 = 350 - 100 = 250\) cents, where \(g\) is the second face. Backward induction compares the two options at the first roll. For face \(f\), stopping pays \(100f\) cents, and rerolling is worth 250 cents, so the better option is to stop on faces 3 to 6 and to reroll on faces 1 and 2. The value of the game is
103: \[ \frac{250 + 250 + 300 + 400 + 500 + 600}{6} = \frac{2300}{6} = \frac{1150}{3} \text{ cents}, \]
104: which is 383.33 cents to two places. Stopping on every face gives 350 cents, so the choice adds \(1150/3 - 350 = 100/3\) cents, which is 33.33 cents to two places. Lab 1, Part 2 checks the value by enumerating all 64 policies, one stop-or-reroll choice for each of the six first faces, and the best of them is \(1150/3\).
108: Definition 3.7 (stopping rule on a finite horizon)
109: Let the game have a horizon \(N \ge 1\) turns. For every history \(h = (x_1, \dots, x_t)\) of payoffs after turn \(t \le N\), let \(W(h) = x_1 + \cdots + x_t\) be its total. A stopping rule assigns to each history either stop or continue , using only \(h\), and it stops at every history of length \(N\). The total paid under the rule is \(W(h)\) at the history \(h\) at which the rule stops.
113: Lab 1 · Linearity, the reroll game and rules for when to stop, in integer cents
114: The lab computes every expectation by enumeration with fractions. Part 1 prints \(\E[X + Y] = 7\) for two dice and checks it against \(\E[X] + \E[Y]\). Part 2 prints the continuation value 250 cents, the best action on each face, the backward-induction value \(1150/3\) cents, the best of all 64 policies, and the stop-on-every-face value 350 cents. Part 3 applies five rules for when to stop to a fair game over six turns, by two methods: recursion on the history, and listing all 64 sequences. It prints the expectation of each rule under both methods, and checks that they agree and that all five are zero. Part 3b applies the same five rules to a biased game that pays \(+150\) or \(-100\) cents with probability \(1/2\) each.

199: def value(history: tuple[int, ...]) -> Fraction:

289: 3 Stopping rules on a fair game
292: Assumption A3 (finite horizon, fairness at every history)
293: The horizon \(N\) is finite. For every history \(h\) of fewer than \(N\) turns with \(\Prob(h) > 0\), the next payoff \(x\) satisfies \(\sum_x x\,\Prob(\text{next payoff} = x \mid h) = 0\). This is the fairness condition of Definition 3.5. Conditional probabilities are defined only given a positive-probability event (Lesson 2, Definition 2.2), so the condition is stated for those histories alone.
297: Theorem 3.8 (a stopping rule does not change the expected total of a finite fair game)
299: (H1) Assuming A1 and A3, the horizon \(N\) is finite.
300: (H2) Assuming A3, the game is fair at every history of fewer than \(N\) turns that has positive probability.
301: (H3) The stopping rule of Definition 3.7 depends only on the history \(h\).
303: Conclusion: the expected total paid under the rule is zero, \(\E[W] = 0\).
307: Proof
308: For a history \(h\) of length \(t \le N\) with \(\Prob(h) > 0\), let \(V(h)\) be the expected total paid under the rule, starting from \(h\). We show by backward induction on \(t\) that \(V(h) = W(h)\) for every history of length \(t\) with positive probability. Histories of probability zero add nothing to an expectation, so they are not needed.
309: Base, \(t = N\). By (H3) and Definition 3.7 the rule stops at \(h\), so \(V(h) = W(h)\).
310: Step. Suppose the claim holds for every history of length \(t + 1\) with positive probability, and let \(h\) of length \(t\) have \(\Prob(h) > 0\). If the rule stops at \(h\), then \(V(h) = W(h)\). If it continues, then \(V(h) = \sum_x \Prob(x \mid h)\,V(h, x)\), where the sum runs over the \(x\) with \(\Prob(h, x) > 0\), and by the hypothesis \(V(h, x) = W(h) + x\) for each of them. Hence \(V(h) = W(h)\sum_x \Prob(x \mid h) + \sum_x x\,\Prob(x \mid h)\). The first sum is 1 and the second is 0 by (H2), so \(V(h) = W(h)\).
311: At the empty history, \(W = 0\), so \(\E[W] = V(\varnothing) = 0\). \(\blacksquare\)
315: Remark 3.9
316: Theorem 3.8 uses the horizon \(N\) in the induction, which has a finite number of steps. It does not apply to a rule that may continue without bound. The lesson states no result for that case, and Section 4 names it as the place where the canon breaks. The theorem also needs (H3). A rule that looks at later payoffs is not a stopping rule, and Research problem R1 shows that its expectation can be nonzero.
320: Example 3.10 (five rules on the fair game, and the same rules on a biased game)
321: Assume A2 over \(N = 6\) turns, which gives the fairness condition of A3 with \(N = 6\). The rules are: play all six turns; stop after the first win; stop after the first loss; stop when the total reaches 100 cents; and stop when the total reaches 200 cents of gain or loss. Each is a stopping rule in the sense of Definition 3.7. By Theorem 3.8 each has expected total zero, and Lab 1, Part 3 prints zero for each of the five, computed by two methods.
322: The biased game pays \(+150\) or \(-100\) cents, each with probability \(1/2\). Its expected payoff per turn is \(25\) cents, and playing all six turns gives \(6 \cdot 25 = 150\) cents, which Lab 1, Part 3b prints. Its fairness condition fails, and each of the four rules other than play-all gives a value other than 150 cents. Stopping after the first loss gives \(1575/32\) cents, stopping when the total reaches 100 cents gives \(575/8\) cents, and stopping at 200 cents of gain or loss gives \(625/8\) cents. Theorem 3.8 does not apply to this game, because (H2) fails.
326: Example 3.11 (a fair one-turn game, for scale)
327: A single fair turn pays \(+100\) cents with probability \(1/2\) and \(-100\) cents with probability \(1/2\). Its expected payoff is zero. The turn pays a gain of \(+100\) cents with probability \(1/2\). A zero expectation does not mean that the game never pays a gain. It says that gains and losses balance in the average.
331: 4 Where the canon breaks
332: The results above hold for finite games and for the stated rules. Each limit below is a place where a naive extension fails.
334: Unbounded stopping. Theorem 3.8 needs a finite horizon \(N\). A rule that waits for the total to reach a target, with no cap on the number of turns, is outside it. This lesson states no value for such a rule, and the finite truncations of Lab 1 do not establish one.
335: Fairness is a hypothesis that cannot be dropped. Example 3.10 shows the same five rules giving zero for the fair game and nonzero values for the biased game. A claim that a rule cannot help must name the fairness condition it uses.
336: Choice has value in a game that is not fair. The reroll game of Example 3.6 has a choice worth \(100/3\) cents over stopping at once. Its stop payoff has mean 350 cents, so the game is not fair, and the choice is not a stopping rule on a fair game.
341: 5 Misconceptions
344: “A clever stopping rule, chosen after seeing the outcomes, makes a fair game favourable.”
345: Theorem 3.8 states that, over a finite horizon, every stopping rule that depends only on the history has expected total zero in a fair game. Lab 1, Part 3 prints zero for five rules, computed two ways. The rule must depend only on the past. A rule that looks ahead, as in Research problem R1, is not a stopping rule.
348: “Choosing when to stop can never help a player.”
349: In Example 3.6 the optimal choice raises the value from 350 cents to \(1150/3\) cents, a gain of \(100/3\) cents. The game is not fair, because its stop payoff has mean 350 cents, not zero. Theorem 3.8 does not apply, and in this game the choice does help. Lab 1, Part 2 prints both values.
352: “A fair game with expected payoff zero never pays a gain.”
353: Example 3.11 gives a fair turn that ends at \(+100\) cents with probability \(1/2\). Zero expectation balances the gains against the losses, and it does not say that gains are absent. The claim confuses a zero average with the absence of gains.

363: Mechanics
365: M1 · A paid die game
366: A player pays 50 cents to roll a fair die, and receives 100 cents times the face. Find the expected net payoff in cents.
367: Solution
368: Hypotheses used: A1, a fair die, and integer cents. The expected payoff before the fee is \(100 \cdot \E[\text{face}] = 100 \cdot 7/2 = 350\) cents, by Example 3.3. Net of the fee, the expected payoff is \(350 - 50 = 300\) cents.
372: M2 · A fair win-or-lose game
373: A game pays 200 cents with probability \(p\) and costs 100 cents with probability \(1 - p\). Find \(p\) that makes the game fair in the sense of Definition 3.5.
374: Solution
375: Hypotheses used: a one-turn game, so Definition 3.5 requires expected payoff zero. The expected payoff is \(200p - 100(1 - p) = 300p - 100\). Setting it to zero gives \(p = 1/3\).
379: M3 · A two-stage game
380: A fair coin is tossed. On heads the game pays 100 cents and ends. On tails the player pays 50 cents and rolls a fair die, receiving 100 cents times the face. Find the expected payoff in cents.
381: Solution
382: Hypotheses used: A1, a fair coin, and a fair die. The heads branch has expected payoff 100 cents. The tails branch has expected payoff \(-50 + 100 \cdot 7/2 = 300\) cents. Weighting each branch by \(1/2\) gives \(\tfrac12 \cdot 100 + \tfrac12 \cdot 300 = 200\) cents.
388: Proof
390: P1 · Linearity for two payoffs
391: Prove Proposition 3.2 for \(m = 2\) directly from Definition 3.1, listing each hypothesis used.
392: Solution
393: Hypotheses used: A1, so \(\Omega\) is finite and the weights sum to 1. Then \(\E[X_1 + X_2] = \sum_\omega (X_1(\omega) + X_2(\omega))\,p(\omega) = \sum_\omega X_1(\omega)\,p(\omega) + \sum_\omega X_2(\omega)\,p(\omega) = \E[X_1] + \E[X_2]\). The two sums are finite, so the rearrangement is valid.
397: P2 · The play-all rule, by induction
398: Assume A3. Prove that the rule that plays all \(N\) turns has \(\E[W] = 0\), by induction on \(N\), using only the fairness condition at each history.
399: Solution
400: Hypotheses used: A3 and a finite horizon. For \(N = 1\), the expected total is the expected payoff of one fair turn, which is zero by (H2) at the empty history. Suppose the claim holds for \(t\) turns. For \(t + 1\) turns, the total is the total of the first \(t\) turns plus the payoff of turn \(t + 1\). The expectation of the first part is zero by hypothesis, and the expectation of the last is \(\sum_h \Prob(h)\sum_x x\,\Prob(x \mid h) = 0\), summed over the histories \(h\) of length \(t\) with \(\Prob(h) > 0\), by (H2) at each of them. Linearity (Proposition 3.2) gives \(\E[W] = 0\).
404: P3 · The optimal first action in the reroll game
405: In the reroll game of Example 3.6, prove that rerolling is optimal exactly on the faces \(f\) with \(100f < 250\), and state the threshold face.
406: Solution
407: Hypotheses used: the continuation value is 250 cents, from the derivation in Example 3.6. Stopping on face \(f\) pays \(100f\) cents, and rerolling is worth 250 cents, so rerolling is strictly better exactly when \(100f < 250\), that is, \(f < 2.5\). Stopping is at least as good when \(f \ge 2.5\). The integer faces with \(f < 2.5\) are 1 and 2, so the threshold face is 3, the lowest face at which stopping is preferred.
413: Empirical
415: E1 · The biased game by hand
416: From Lab 1, Part 3b, the rule "play all turns" on the biased game gives 150 cents. Confirm this value from the per-turn expectation.
417: Solution
418: Hypotheses used: six independent turns, each paying 150 or \(-100\) cents with probability \(1/2\). The per-turn expectation is \(\tfrac12 \cdot 150 + \tfrac12 \cdot (-100) = 25\) cents. Under the play-all rule the total is the sum of six turns, so its expectation is \(6 \cdot 25 = 150\) cents, matching the printed value.
422: E2 · The effect of a rule on the biased game
423: From Lab 1, Part 3b, the rule "stop at 200 cents of gain or loss" gives \(625/8\) cents. Find the change from the play-all value of 150 cents, as an exact fraction and as a decimal.
424: Solution
425: Hypotheses used: the printed values of Lab 1, Part 3b. The change is \(625/8 - 150 = 625/8 - 1200/8 = -575/8\) cents, which is \(-71.875\) cents exactly. On this biased game the rule gives a lower expected total than play-all. Theorem 3.8 does not apply, because (H2) fails.
429: E3 · The value of the reroll choice
430: From Lab 1, Part 2, the reroll game is worth \(1150/3\) cents and stopping on every face is worth 350 cents. Find the value of the choice in cents, as an exact fraction and as a decimal to two places.
431: Solution
432: Hypotheses used: the printed values. The value of the choice is \(1150/3 - 350 = 1150/3 - 1050/3 = 100/3\) cents, which is 33.33 cents to two places. The choice is worth the difference between the optimal policy and the stop-on-every-face policy.
438: Research
440: R1 · A rule that looks ahead
441: Open question with a stated criterion. Consider the fair two-turn game of Assumption A2. Let a rule look at both payoffs before it acts, and stop at the turn whose cumulative total is larger. Criterion: give the exact expected total of this rule, and state which hypothesis of Theorem 3.8 it violates.
442: Solution
443: Write \(W_1\) and \(W_2\) for the cumulative totals after turns 1 and 2. The rule stops at the turn with the larger \(W_t\), so its total is \(\max(W_1, W_2)\). The four equally likely paths give: \((+100, +100)\) with \(W_1 = 100\) and \(W_2 = 200\), total 200; \((+100, -100)\) with \(W_2 = 0\), total 100; \((-100, +100)\) with \(W_2 = 0\), total 0; and \((-100, -100)\) with \(W_1 = -100\) and \(W_2 = -200\), total \(-100\). The expected total is \((200 + 100 + 0 - 100)/4 = 50\) cents. The rule decides at turn 1 using the payoff of turn 2, so it is not a stopping rule of Definition 3.7, and (H3) fails.
447: R2 · A reroll game with a gain above ten cents
448: Open design question. Find an expected-value game, with integer cents and a stated stopping rule, whose optimal value exceeds the stop-at-once value by at least 10 cents. Criterion: both values are exact, and the game is not fair.
449: Solution
450: The reroll game of Example 3.6 meets the criterion. Its optimal value is \(1150/3\) cents and its stop-at-once value is 350 cents, so the gain is \(100/3\) cents, which is more than 10 cents. Both values are exact fractions. The game is not fair, because its first roll has mean payoff 350 cents, so (H2) of Theorem 3.8 fails at the first turn. Changing the fee changes the gain: for a fee \(c\) the gain is \((\sum_f \max(100f,\, 350 - c))/6 - 350\) cents, which is \(100/3\) cents at \(c = 100\) and \(74.5\) cents at \(c = 1\). The answer must state its own fee and values.
454: R3 · The unbounded rule, what the table does and does not show
455: Open question. For the fair game of Assumption A2, consider the rule that stops when the total reaches 100 cents, with a horizon of \(N\) turns. Compute its expected total for \(N = 1\) to \(6\) from Theorem 3.8, and state what these values say about the rule with no horizon. Criterion: the answer must separate what the finite values establish from what they do not.
456: Solution
457: For each finite \(N\), the rule is a stopping rule over a finite horizon that is forced to stop at \(N\), and Theorem 3.8 gives expected total zero for every \(N\) from 1 to 6. These values establish zero for each finite horizon. They do not establish the value of the rule with no horizon, because Theorem 3.8 needs a finite \(N\), and the lesson proves no limit. A run of zeros for \(N = 1\) to \(6\) cannot show that the limit of the expected totals equals the expected total of the unbounded rule, since that rule is outside the theorem.
