36: Market-making game
37: You write the quoting rule of a market maker for one asset over 20 turns, and the replay of the game log that the rule produces. Some counterparties trade on information the maker does not see. The engine plays the market-making game for your seed, and your replay (specified under Rung 3 ) turns the log into a decomposition of the P&L into cash flow and inventory mark, in integer cents; the terms are defined under Conventions . The analysis then says where the result came from and what would change it. Play is by code, not by clicking. Every instance is SIMULATED.

52: Rungs 1 and 2
53: Both labs play the same game: seed 0, the fair path and arrivals that grader/instance.py generates for seed 0, and one fixed quoting rule. The rule takes the mid (the price its quote is centred on) to be the last filled price, or 10000 cents before any fill, and quotes a half-spread of 10 cents (the distance of each quote from the mid), for one unit: a bid 10 cents below the mid and an ask 10 cents above it. A fill is a trade of one unit at the bid or at the ask. The game is SIMULATED: its fair path (the fair value v 0 to v 20 , which the maker does not see) and its arrivals (one per turn: an uninformed buy, an uninformed sell or an informed trader) are generated, and no data file is read. The turn-by-turn rules are those of Lesson 4 , and they are restated in the conventions below, where the cash flow, the settlement value, the inventory mark, the P&L and the identity that links them are defined. The labs show the replay that your replay function must reproduce.
56: Lab 1 · Worked example: one seeded game and its replay
57: Stated before running. On seed 0 the game has 9 fills in 20 turns. The fills sum to a cash flow of \(-9950\) cents, the maker ends with an inventory of 1 unit, the settlement value is 9980 cents, so the inventory mark is 9980 cents and the P&L is \(30\) cents. The identity P&L = cash flow + inventory \(\times\) settlement holds, and no inventory passes the limit of 10 units.
58: """PC3 project, rung 1: a worked example. One seeded game, one fixed quoting rule, and the replay of its log.
60: SIMULATED. The fair path and the arrivals are generated from random.Random(0), in the order of the project's instance
61: generator, which is the order of Lesson 4. No data file is read and there is no network access. Standard library only.
62: Money is an integer number of cents, and every accounting value is an int.
64: The quoting rule is fixed: bid and ask sit 10 cents either side of the last filled price, or of 10000 cents before any
65: fill, and each side is for one unit. The log has the fields the project specifies. The replay below computes the cash
66: flow, the ending inventory, the mark at the settlement value and the P&L from the fills of the log. Then main checks the
67: identity P&L = cash flow + inventory x settlement, in integer cents. The numbers describe this one seed and this one
68: rule.
69: """
71: from __future__ import annotations
73: import random
74: from typing import Any
76: HORIZON = 20 # turns
77: START_CENTS = 10_000 # v_0, in cents
78: MOVE_CENTS = 5 # the fair value moves by +5 or -5 cents each turn
79: HALF_SPREAD = 10 # cents either side of the mid
80: SIZE = 1 # units quoted on each side
81: LIMIT = 10 # inventory limit: a fill is refused when |inventory| would exceed it
82: SEED = 0
85: def draw_game(seed: int) -> tuple[list[int], list[str]]:
86: """The fair path v_0 .. v_20 in cents and the 20 arrivals. Turn t draws its move first, then its arrival."""
87: rng = random.Random(seed)
88: path = [START_CENTS]
89: arrivals: list[str] = []
90: for _ in range(HORIZON):
91: # Step 1a. The fair value moves by +5 cents when the draw is below 0.5, otherwise by -5 cents.
92: move = MOVE_CENTS if rng.random() < 0.5 else -MOVE_CENTS
93: path.append(path[-1] + move)
94: # Step 1b. The arrival: an uninformed buy below 0.25, an uninformed sell below 0.5, else an informed trader.
95: draw = rng.random()
96: if draw < 0.25:
97: arrivals.append("uninformed-buy")
98: elif draw < 0.5:
99: arrivals.append("uninformed-sell")
100: else:
101: arrivals.append("informed")
102: return path, arrivals
105: def quote(last_fill: int | None) -> tuple[int, int, int]:
106: """The fixed rule: the mid is the last filled price, or 10000 cents before any fill. Returns (bid, ask, size)."""
107: # Step 2. Quote HALF_SPREAD cents either side of the mid: the last filled price, or 10000 before any fill.
108: mid = START_CENTS if last_fill is None else last_fill
109: return mid - HALF_SPREAD, mid + HALF_SPREAD, SIZE
112: def maker_side(arrival: str, fair: int, bid: int, ask: int) -> int:
113: """+1 when the maker buys one unit at the bid, -1 when it sells one at the ask, 0 when there is no trade."""
114: if arrival == "uninformed-buy":
115: return -1 # the customer buys, so the maker sells at the ask
116: if arrival == "uninformed-sell":
117: return 1 # the customer sells, so the maker buys at the bid
118: if fair > ask:
119: return -1 # an informed trader buys when the fair value is strictly above the ask
120: if fair < bid:
121: return 1 # and sells when the fair value is strictly below the bid
122: return 0
125: def play(seed: int) -> dict[str, Any]:
126: """Play the 20 turns and return the log: the seed, the settlement value and the turn records."""
127: path, arrivals = draw_game(seed)
128: inventory = 0
129: cash = 0
130: last_fill: int | None = None
131: turns: list[dict[str, Any]] = []
132: for turn in range(1, HORIZON + 1):
133: bid, ask, size = quote(last_fill)
134: arrival = arrivals[turn - 1]
135: side = maker_side(arrival, path[turn], bid, ask)
136: # Step 3. A fill needs a size of at least 1, a trade on the arrival, and |inventory| within the limit after it.
137: filled = side != 0 and size >= 1 and abs(inventory + side) <= LIMIT
138: price: int | None = None
139: if filled:
140: price = ask if side < 0 else bid
141: inventory += side
142: cash += -side * price
143: last_fill = price
144: turns.append(
145: {
146: "turn": turn,
147: "bid_cents": bid,
148: "ask_cents": ask,
149: "size": size,
150: "arrival": arrival,
151: "filled": filled,
152: "fill_price_cents": price,
153: "inventory_after": inventory,
154: "cash_after_cents": cash,
155: }
156: )
157: return {"seed": seed, "settlement_cents": path[HORIZON], "turns": turns}
160: def replay(log: dict[str, Any]) -> dict[str, int]:
161: """Replay the fills of a log: the cash flow, the ending inventory, the mark at settlement and the P&L, in cents."""
162: turns: list[dict[str, Any]] = log["turns"]
163: # Step 4. A log has exactly 20 turns. Every fill is one unit: a fill at the ask is a sale by the maker, a fill at
164: # the bid is a purchase by the maker. The cash flow of a sale is +price, and of a purchase is -price.
165: if len(turns) != HORIZON:
166: raise ValueError("a log has exactly 20 turns")
167: cash_flow = 0
168: inventory = 0
169: for record in turns:
170: if record["filled"] is not True:
171: continue
172: if record["fill_price_cents"] is None:
173: raise ValueError("a filled turn needs a fill price")
174: price = int(record["fill_price_cents"])
175: side = -1 if price == record["ask_cents"] else 1
176: cash_flow += -side * price
177: inventory += side
178: # Step 5. The inventory is marked at the settlement value, not at the last quote, because the game is settled there.
179: mark = inventory * int(log["settlement_cents"])
180: return {
181: "cash_flow_cents": cash_flow,
182: "inventory_end": inventory,
183: "inventory_mark_cents": mark,
184: "pnl_cents": cash_flow + mark,
185: }
188: def main() -> None:
189: print("Rung 1 worked example · seed 0 · SIMULATED · quote 10 cents either side of the last fill, size 1")
190: log = play(SEED)
191: settlement = log["settlement_cents"]
192: print(f"settlement v_{HORIZON} = {settlement} cents")
193: print("replay of the fills:")
194: for record in log["turns"]:
195: if record["filled"]:
196: price = int(record["fill_price_cents"])
197: side = -1 if price == record["ask_cents"] else 1
198: step = -side * price
199: print(
200: f" turn {record['turn']:>2}: maker {'sells at the ask' if side < 0 else 'buys at the bid'} "
201: f"{price} cents, cash flow {step:+d} cents, inventory {record['inventory_after']:+d}"
202: )
203: result = replay(log)
204: final = log["turns"][-1]
205: fills = sum(1 for record in log["turns"] if record["filled"])
206: print(f"fills = {fills} of {HORIZON} turns")
207: print(f"cash_flow_cents = {result['cash_flow_cents']}")
208: print(f"inventory_end = {result['inventory_end']}")
209: print(f"inventory_mark_cents = {result['inventory_mark_cents']}")
210: print(f"pnl_cents = {result['pnl_cents']}")
211: identity = result["pnl_cents"] == result["cash_flow_cents"] + result["inventory_end"] * settlement
212: print(f"identity P&L = cash flow + inventory x settlement holds: {identity}")
213: print(f"cash flow equals the cash after the last turn: {result['cash_flow_cents'] == final['cash_after_cents']}")
214: largest = max(abs(record["inventory_after"]) for record in log["turns"])
215: print(f"largest |inventory| over the run = {largest} (limit {LIMIT}): {largest <= LIMIT}")
218: main()

386: Rung 3 · Specification
388: Context
389: Play is by code, not by clicking. You write a quoting rule for a market maker who posts a bid and an ask for one asset over 20 turns, and a replay of the log that the engine writes. Some counterparties trade on information the maker does not see. From the log you must explain the result as its cash flow and its inventory mark (both defined under Conventions ), and say what would change the result. The log is the evidence: the numbers that describe your result are numbers of the log or of your replay, and the model's constants are taken from the conventions. The engine that writes the log is described under Inputs.
390: Inputs
391: No data file. The game for your workspace seed comes from grader/instance.py , which holds make_instance(seed) : a fair path of 21 integers in cents (v 0 to v 20 , starting at 10000) and 20 arrivals. Every instance is SIMULATED, and the seed is derived from your workspace ID. The rules are those of Lesson 4 , restated exactly in the conventions . The engine is grader/engine.py , which plays one game for a quoting rule and a seed, and returns the log.
392: Required outputs
393: In a folder of your own: market_maker.py at its root. It defines two functions. quote(state: dict[str, object]) -> tuple[int, int, int] returns (bid_cents, ask_cents, size) for the current turn; its state holds exactly the keys turn (1 to 20), inventory , cash_cents , max_size (5), limit (10) and history (the earlier turn records of the log). replay(log: dict[str, object]) -> dict[str, int] returns exactly the keys cash_flow_cents , inventory_end , inventory_mark_cents and pnl_cents , with pnl_cents = cash_flow_cents + inventory_mark_cents and inventory_mark_cents = inventory_end × settlement_cents . Start from the starter file , whose signatures are complete. Also analysis.md , the analysis described in the brief . For the analysis you need a log of your own rule. Run this in the folder that holds engine.py , instance.py and market_maker.py , and it writes game_log.json for the seed shown in the autograder panel: python3 -c "import json, engine, market_maker; print(json.dumps(engine.play(market_maker.quote, <your seed>)))" > game_log.json In the browser a log is not saved as a file. The autograder replays the logs of your rule inside its run. A log is the dict that engine.play(quote, seed) returns. Its keys are seed (an int), settlement_cents (an int, the value \(v_{20}\)) and turns , a list of 20 records. Each record has the keys turn (1 to 20), bid_cents , ask_cents , size , arrival (one of uninformed-buy , uninformed-sell or informed ), filled ( true or false ), fill_price_cents , inventory_after and cash_after_cents . When filled is false , fill_price_cents is None . A fill at the bid is a purchase by the maker, and a fill at the ask is a sale by the maker.
394: Constraints
395: Standard library only. Money is an integer number of cents everywhere, and inventory is an integer number of units. A quote must have its bid below its ask, and its size must lie in 0 to 5; the engine refuses a quote that breaks either rule with ValueError , as the named conditions below state. A fill is one unit. A fill needs a size of at least 1 and an inventory within the limit of 10 units after the fill: an order that would take the inventory past the limit is not filled, and its record says filled: false . Neither quote nor replay prints or warns. A quote depends only on the state it is given: it keeps nothing between turns or games outside that state. The analysis does not claim a result for real market makers: the model has one asset, and its arrival probabilities are the ones the rules set. Known limitation. The instance is in grader/instance.py , and a student who reads it can see the fair path. A log shows only the settlement value, at the end, and not the fair path; the autograder cannot check that a rule avoids the fair path. A static site cannot keep its tests secret. Integrity rests on the per-seed instances, on the checks that run on the fixed seeds 0 to 49 and on a second seed (see Grading mode), and on the analysis.
396: Grading mode
397: The grade has two parts. The autograder runs 484 checks, with warnings as errors, from grader/test_project.py : 484 for any seed from 0 to 49, and 493 for any other seed. Nine checks run on each distinct seed of the set, which holds the fixed seeds 0 to 49, your seed and your seed plus 7919: 51 seeds when your seed is one of 0 to 49, and 52 otherwise. The nine checks are: the legality of your quote on every turn, the replay against the fills of the log, the agreement of the replay with the engine's final cash and inventory, the P&L identity (defined under Conventions ) exact in cents, integer money, the cash change on each turn, the seed and settlement of a log, the instance, and that neither quote nor replay prints or warns, checked on the game and on a log with no fill. Twenty-four checks run on your seed only: the refusals and boundaries of the quote, the named refusals of the replay, the replay of hand-built logs (its sums, its stale totals, a log with no fill, a fill as one unit, a fill at price 0 and the mark at the settlement value), the fill rules of the engine (the size rule, the inventory limit and the informed-trader rule), and that a quote depends only on the state it is given, so a game played after another game gives the same log. One further check uses no seed of yours: it checks that the fixed seeds 0 to 49 give fifty different fair paths, so it is the same for every learner. The total is therefore 9 × 51 + 24 + 1 = 484 when your seed is one of 0 to 49, and 9 × 52 + 24 + 1 = 493 otherwise. The analysis is scored against the rubric, which has five criteria, each with four observable levels. This page does not collect analysis.md and names no reviewer: you score your analysis yourself with the form in the self-assessment section , calibrated on two annotated exemplars, and you keep the summary the form produces as self_assessment.md . The analysis meets the bar at level 3 or above on every criterion.
400: Conventions
402: The game. There are \(N = 20\) turns, indexed \(t = 1, \dots, 20\). The fair value starts at \(v_0 = 10000\) cents. Each turn it moves by \(+5\) or \(-5\) cents with probability \(1/2\) each, and the path \(v_0, \dots, v_{20}\) is hidden from the maker. These constants are the model's choices, not facts about any market.
403: The quote. Each turn the maker posts a bid \(b_t\) and an ask \(a_t\) in cents, with \(b_t < a_t\), and a size \(q_t\) in units, with \(0 \le q_t \le 5\). The quote sees the state listed under Required outputs. Its state holds no entry for \(v_t\).
404: The arrival. Each turn one arrival comes. With probability \(1/4\) it is an uninformed buy of one unit, with probability \(1/4\) an uninformed sell of one unit, and with probability \(1/2\) an informed trader. The arrival probabilities are assumptions of the model, not estimates.
405: Trades. An uninformed buy takes one unit from the maker at the ask, so the maker sells. An uninformed sell gives one unit to the maker at the bid, so the maker buys. An informed trader buys one unit at the ask when \(v_t \gt a_t\), sells one unit at the bid when \(v_t \lt b_t\), and otherwise does not trade. A trade fills only when \(q_t \ge 1\) and the inventory after the fill satisfies \(|I| \le 10\), where \(I\) is the inventory in units.
406: Cash and inventory. A maker purchase at the bid \(b\) changes cash by \(-b\) and inventory by \(+1\). A maker sale at the ask \(a\) changes cash by \(+a\) and inventory by \(-1\). Cash starts at zero.
407: The P&L. The settlement value is \(v_{20}\), and the inventory mark is \(I_{20} \times v_{20}\). The P&L of a log is \(\mathrm{pnl} = \mathrm{cash\ flow} + I_{20} \times v_{20}\), in cents, with the cash flow the sum of the fill cash flows. The identity is exact: the cash flow, the inventory and the settlement value are integers, so the product and the sum carry no rounding.

411: The engine raises ValueError for the first two conditions, and your replay for the last two, each with the message named here.

458: Lab 3 · The rung 3 check: the reference rule, its replay and one counterfactual
459: Stated before running. For the reference rule on seed 0, the replay gives the four numbers of Lab 1: a cash flow of \(-9950\) cents, an ending inventory of 1 unit, an inventory mark of 9980 cents and a P&L of \(30\) cents, with 9 fills. The counterfactual is the same seed and the same arrivals, with the half-spread widened from 10 cents to 15 cents. It has 9 fills too, and its P&L is 55 cents, which is 25 cents more. Your replay , run on the log of the reference rule for seed 0, must return the same four numbers.
460: """PC3 project, rung 3 check: the reference game on seed 0, its replay, and one counterfactual on the same seed.
462: SIMULATED. The fair path and the arrivals come from random.Random(0), in the order of Lesson 4 and of the project's
463: instance generator. No data file is read and there is no network access. Standard library only. Money is an integer
464: number of cents, and every accounting value is an int.
466: The reference rule quotes around the last filled price, or around 10000 cents before any fill, for one unit. Its
467: half-spread is 10 cents. The counterfactual is the same game with a half-spread of 15 cents, one change of the rule that
468: the lab uses to show the rerun. The numbers below describe this one seed. They are not an estimate for any market.
469: """
471: from __future__ import annotations
473: import random
474: from typing import Any
476: HORIZON = 20 # turns
477: START_CENTS = 10_000 # v_0, in cents
478: MOVE_CENTS = 5 # the fair value moves by +5 or -5 cents each turn
479: SIZE = 1 # units quoted on each side
480: LIMIT = 10 # inventory limit
481: REFERENCE_HALF_SPREAD = 10 # cents, the reference rule
482: COUNTERFACTUAL_HALF_SPREAD = 15 # cents, the counterfactual
483: SEED = 0
486: def draw_game(seed: int) -> tuple[list[int], list[str]]:
487: """The fair path v_0 .. v_20 in cents and the 20 arrivals, drawn in the order of Lesson 4."""
488: rng = random.Random(seed)
489: path = [START_CENTS]
490: arrivals: list[str] = []
491: for _ in range(HORIZON):
492: move = MOVE_CENTS if rng.random() < 0.5 else -MOVE_CENTS
493: path.append(path[-1] + move)
494: draw = rng.random()
495: if draw < 0.25:
496: arrivals.append("uninformed-buy")
497: elif draw < 0.5:
498: arrivals.append("uninformed-sell")
499: else:
500: arrivals.append("informed")
501: return path, arrivals
504: def maker_side(arrival: str, fair: int, bid: int, ask: int) -> int:
505: """+1 when the maker buys one unit at the bid, -1 when it sells one at the ask, 0 when there is no trade."""
506: if arrival == "uninformed-buy":
507: return -1
508: if arrival == "uninformed-sell":
509: return 1
510: if fair > ask:
511: return -1
512: if fair < bid:
513: return 1
514: return 0
517: def play(seed: int, half_spread: int) -> dict[str, Any]:
518: """Play the 20 turns; quote half_spread cents either side of the last filled price (10000 before any fill)."""
519: path, arrivals = draw_game(seed)
520: inventory = 0
521: cash = 0
522: last_fill: int | None = None
523: turns: list[dict[str, Any]] = []
524: for turn in range(1, HORIZON + 1):
525: mid = START_CENTS if last_fill is None else last_fill
526: bid, ask, size = mid - half_spread, mid + half_spread, SIZE
527: arrival = arrivals[turn - 1]
528: side = maker_side(arrival, path[turn], bid, ask)
529: filled = side != 0 and size >= 1 and abs(inventory + side) <= LIMIT
530: price: int | None = None
531: if filled:
532: price = ask if side < 0 else bid
533: inventory += side
534: cash += -side * price
535: last_fill = price
536: turns.append(
537: {
538: "turn": turn,
539: "bid_cents": bid,
540: "ask_cents": ask,
541: "size": size,
542: "arrival": arrival,
543: "filled": filled,
544: "fill_price_cents": price,
545: "inventory_after": inventory,
546: "cash_after_cents": cash,
547: }
548: )
549: return {"seed": seed, "settlement_cents": path[HORIZON], "turns": turns}
552: def replay(log: dict[str, Any]) -> dict[str, int]:
553: """Replay the fills of a log: the cash flow, the ending inventory, the mark at settlement and the P&L, in cents."""
554: turns: list[dict[str, Any]] = log["turns"]
555: if len(turns) != HORIZON:
556: raise ValueError("a log has exactly 20 turns")
557: fills: list[tuple[int, int]] = []
558: for record in turns:
559: if record["filled"] is True:
560: if record["fill_price_cents"] is None:
561: raise ValueError("a filled turn needs a fill price")
562: price = int(record["fill_price_cents"])
563: fills.append((1 if price == record["bid_cents"] else -1, price))
564: inventory = sum(side for side, _ in fills)
565: cash_flow = sum(-side * price for side, price in fills)
566: mark = inventory * int(log["settlement_cents"])
567: return {
568: "cash_flow_cents": cash_flow,
569: "inventory_end": inventory,
570: "inventory_mark_cents": mark,
571: "pnl_cents": cash_flow + mark,
572: }
575: def main() -> None:
576: print("Rung 3 check · seed 0 · SIMULATED · reference rule: 10 cents either side of the last fill, size 1")
577: log = play(SEED, REFERENCE_HALF_SPREAD)
578: result = replay(log)
579: fills = sum(1 for record in log["turns"] if record["filled"])
580: settlement = int(log["settlement_cents"])
581: print(f"settlement v_{HORIZON} = {settlement} cents, fills = {fills} of {HORIZON} turns")
582: print(f"cash_flow_cents = {result['cash_flow_cents']}")
583: print(f"inventory_end = {result['inventory_end']}")
584: print(f"inventory_mark_cents = {result['inventory_mark_cents']}")
585: print(f"pnl_cents = {result['pnl_cents']}")
586: identity = result["pnl_cents"] == result["cash_flow_cents"] + result["inventory_end"] * settlement
587: print(f"identity P&L = cash flow + inventory x settlement holds: {identity}")
588: last_cash = log["turns"][-1]["cash_after_cents"]
589: print(f"cash flow equals the cash after the last turn: {result['cash_flow_cents'] == last_cash}")
590: # The counterfactual: the same seed and arrivals, with the half-spread widened by 5 cents.
591: wider = play(SEED, COUNTERFACTUAL_HALF_SPREAD)
592: wider_result = replay(wider)
593: wider_fills = sum(1 for record in wider["turns"] if record["filled"])
594: print(f"counterfactual half-spread {COUNTERFACTUAL_HALF_SPREAD} cents: fills = {wider_fills} of {HORIZON} turns")
595: print(f"counterfactual pnl_cents = {wider_result['pnl_cents']}")
596: print(f"change in pnl_cents from the wider half-spread = {wider_result['pnl_cents'] - result['pnl_cents']} cents")
599: main()
600: Rung 3 check · seed 0 · SIMULATED · reference rule: 10 cents either side of the last fill, size 1
601: settlement v_20 = 9980 cents, fills = 9 of 20 turns
602: cash_flow_cents = -9950
603: inventory_end = 1
604: inventory_mark_cents = 9980
605: pnl_cents = 30
606: identity P&L = cash flow + inventory x settlement holds: True
607: cash flow equals the cash after the last turn: True
608: counterfactual half-spread 15 cents: fills = 9 of 20 turns
609: counterfactual pnl_cents = 55
610: change in pnl_cents from the wider half-spread = 25 cents
611: The first block of lines is the reference output: the settlement, the fills, the four numbers, the identity, and the agreement of the cash flow with the cash after the last turn. For the reference log, your replay must return the four numbers in that block. The last three lines are the counterfactual. It changes one number of the policy, the half-spread, and reruns the same game, so the change in the P&L of 25 cents is a difference on one seed. It is not an estimate of how a wider spread performs on other seeds, and the lab does not test any other seed.
