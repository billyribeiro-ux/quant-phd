65: Expected utility values a gamble only through the utility of the wealth levels it can produce, so it has no separate reference point for gains and losses. A reference-dependent model values outcomes as changes from a reference point (Definition 1.1), and it can weight losses more heavily than equal gains. Example 2.3 shows that a gamble with a positive expected value can have a negative value under such a model. This lesson defines the value function and the prospect value, proves the shape of the value function when the powers are below one, computes the threshold at which a gamble's value changes sign, and states what is not settled about the size of the asymmetry.
68: 1Reference dependence and the value function
72: Definition 1.1 (reference point, gains and losses)
73: Let \(r\) be a reference point. An outcome \(x\) is a gain if \(x > r\) and a loss if \(x < r\). This lesson takes \(r = 0\), so outcomes are changes in wealth from the start, in cents. A choice of reference point is a modelling assumption, and Section 4 names its consequences.
79: Definition 1.2 (the value function)
80: Let \(\alpha > 0\), \(\delta > 0\) and \(\lambda > 0\). The value function is
82: \[v(x) = x^{\alpha} \ \text{ for } x \ge 0, \qquad v(x) = -\lambda\,(-x)^{\delta} \ \text{ for } x < 0.\]
84: Here \(\alpha\) is the curvature parameter for gains, \(\delta\) the curvature parameter for losses, and \(\lambda\) the coefficient that multiplies the loss term. The function has \(v(0) = 0\).
90: Definition 1.3 (prospect value of a lottery)
91: Let a lottery have finitely many outcomes \(x_i\) with probabilities \(p_i > 0\), \(\sum_i p_i = 1\). The prospect value is \(\mathrm{PV} := \sum_i p_i\, v(x_i)\). It is the value part of prospect theory as this unit uses the term: outcomes are valued relative to the reference point, and the probabilities are used as they are. Lesson L07 adds probability weighting.
97: Proposition 1.4 (shape of the value function)
98: Assume \(0 < \alpha < 1\), \(0 < \delta < 1\) and \(\lambda > 0\). Then \(v\) is strictly increasing on \(\R\), \(v''(x) < 0\) for every \(x > 0\) (so \(v\) is strictly concave on \([0, \infty)\), in the sign convention of Assumption A2 in Lesson L02), and \(v''(x) \ge 0\) for every \(x < 0\).
104: Proof
105: Both pieces are continuous at 0, since \(x^{\alpha} \to 0\) as \(x \to 0^+\) and \(-\lambda(-x)^{\delta} \to 0\) as \(x \to 0^-\). For \(x > 0\), \(v'(x) = \alpha x^{\alpha - 1} > 0\) and \(v''(x) = \alpha(\alpha-1)x^{\alpha-2} < 0\), because \(\alpha < 1\). For \(x < 0\), write \(y = -x > 0\). Then \(v(x) = -\lambda y^{\delta}\), and by the chain rule \(v'(x) = \lambda\delta\,(-x)^{\delta-1} > 0\). Differentiating again, \(v''(x) = \lambda\delta(1-\delta)(-x)^{\delta-2} > 0\), because \(\delta < 1\). A function with a positive derivative on each open half-line that is continuous at 0 is strictly increasing on \(\R\). A continuous function with negative second derivative on \((0, \infty)\) is strictly concave on \([0, \infty)\), and \(v''\) is positive on \((-\infty, 0)\), so \(v''(x) \ge 0\) there, as the statement says. \(\blacksquare\)
111: Remark 1.5 (equal magnitudes when α = δ)
112: If \(\alpha = \delta\), then for every \(x > 0\), \(v(-x) = -\lambda x^{\alpha}\) and \(v(x) = x^{\alpha}\), so \(|v(-x)|/v(x) = \lambda\). The ratio is the same at every magnitude. This is why \(\lambda\) can be read as a weight on losses relative to gains of equal size, for this value function only.
118: Definition 1.6 (loss aversion)
119: Loss aversion is the property that, at equal magnitude, a loss has a larger absolute value than the gain. In the value function of Definition 1.2 with \(\alpha = \delta\), this is the property \(\lambda > 1\), by Remark 1.5.
124: 2The sign of a gamble's value
127: Consider a gamble \(G\) that pays a prize \(g > 0\) with probability \(p\) and a loss \(\ell > 0\) with probability \(1 - p\), where \(0 < p < 1\). Its expected value in cents is \(\mathrm{EV}(G) = p\,g - (1-p)\,\ell\). Its prospect value is \(\mathrm{PV} = p\, v(g) + (1-p)\, v(-\ell)\), by Definition 1.3. The loss size is written \(\ell\) to keep it apart from the coefficient \(\lambda\).
131: Proposition 2.1 (the sign threshold with linear pieces)
132: Assume \(\alpha = \delta = 1\), \(0 < p < 1\), \(g > 0\) and \(\ell > 0\). Let \(\lambda^{\ast} := \dfrac{p\,g}{(1-p)\,\ell}\). Then \(\mathrm{PV}(\lambda) = p\,g - (1-p)\,\lambda\,\ell\), which is strictly decreasing in \(\lambda\). Also \(\mathrm{PV}(1) = \mathrm{EV}(G)\), \(\mathrm{PV}(\lambda^{\ast}) = 0\), \(\mathrm{PV}(\lambda) > 0\) for \(\lambda < \lambda^{\ast}\), and \(\mathrm{PV}(\lambda) < 0\) for \(\lambda > \lambda^{\ast}\).
138: Proof
139: With \(\alpha = \delta = 1\), \(v(g) = g\) and \(v(-\ell) = -\lambda\,\ell\), so \(\mathrm{PV} = p\,g - (1-p)\,\lambda\,\ell\). Its slope in \(\lambda\) is \(-(1-p)\,\ell < 0\), so \(\mathrm{PV}\) is strictly decreasing. At \(\lambda = 1\) it equals \(p\,g - (1-p)\,\ell = \mathrm{EV}(G)\). Setting \(\mathrm{PV} = 0\) gives \(\lambda = pg/((1-p)\ell) = \lambda^{\ast}\), and strict monotonicity gives the signs on either side. \(\blacksquare\)
145: Proposition 2.2 (the sign threshold with powers)
146: Assume \(\alpha > 0\), \(\delta > 0\), \(\lambda > 0\), \(0 < p < 1\), \(g > 0\) and \(\ell > 0\). Then \(\mathrm{PV} = p\, g^{\alpha} - (1-p)\,\lambda\,\ell^{\delta}\). The value is zero at \(\lambda^{\ast} := \dfrac{p\, g^{\alpha}}{(1-p)\,\ell^{\delta}}\), positive below it, and negative above it.
152: Proof
153: By Definition 1.2 with \(g > 0\) and \(-\ell < 0\), \(v(g) = g^{\alpha}\) and \(v(-\ell) = -\lambda\,\ell^{\delta}\). Substituting into Definition 1.3 gives the formula for \(\mathrm{PV}\). It is strictly decreasing in \(\lambda\), with slope \(-(1-p)\,\ell^{\delta} < 0\), and it vanishes at \(\lambda^{\ast}\). The signs follow as in Proposition 2.1. \(\blacksquare\)
159: Example 2.3 (a positive expected value with a negative prospect value)
160: Take \(\alpha = \delta = 1\), \(p = 1/2\), \(g = 1000\) cents and \(\ell = 600\) cents. Then \(\mathrm{EV}(G) = 200\) cents and \(\lambda^{\ast} = 5/3\). At \(\lambda = 1\), \(\mathrm{PV} = 200\), which is the expected value. At \(\lambda = 3/2\), \(\mathrm{PV} = 50\), still positive. At \(\lambda = 2\), \(\mathrm{PV} = -100\), negative, although the expected value is 200. Lab 1 prints each of these values.
166: Remark 2.4 (the sign is the sign of the certainty equivalent)
167: Let \(\mathrm{CE}\) be the certainty equivalent of \(G\) under \(v\), defined as the sure amount \(c\) with \(v(c) = \mathrm{PV}\) (Lesson L02 defines the concept). For every \(\alpha, \delta, \lambda > 0\), \(v\) is continuous, strictly increasing, and \(v(0) = 0\). It maps \(\R\) onto \(\R\), because \(v(x) \to \infty\) as \(x \to \infty\) and \(v(x) \to -\infty\) as \(x \to -\infty\), so the sure amount exists and is unique. Monotonicity needs no bound on the powers: \(v'(x) = \alpha x^{\alpha-1} > 0\) for \(x > 0\), \(v'(x) = \lambda\delta(-x)^{\delta-1} > 0\) for \(x < 0\), and both pieces are continuous at 0, which is the argument of Proposition 1.4 without its bounds on \(\alpha\) and \(\delta\). Hence \(\mathrm{CE} > 0\) exactly when \(\mathrm{PV} > 0\), and \(\mathrm{CE} < 0\) exactly when \(\mathrm{PV} < 0\). In Example 2.3, the certainty equivalent at \(\lambda = 2\) is negative, so the gamble is worth less than the sure amount 0.
173: Remark 2.5 (a gamble alone and a gamble with its copy)
174: Let \(G_1\) and \(G_2\) be two independent copies of the gamble of Example 2.3, with \(\alpha = \delta = 1\). The combined lottery over the sum pays 2000 cents with probability \(1/4\), 400 cents with probability \(1/2\), and \(-1200\) cents with probability \(1/4\). Its value is \(\tfrac14\cdot 2000 + \tfrac12\cdot 400 - \tfrac14\cdot\lambda\cdot 1200\), which is \(700 - 300\lambda\). Evaluating each copy alone and adding gives \(2(500 - 300\lambda) = 1000 - 600\lambda\). At \(\lambda = 2\) the combined value is \(100\) and the sum of separate values is \(-200\). Evaluating each copy alone is called narrow framing here; evaluating the combined lottery is called integrated evaluation. The lesson does not claim that people evaluate either way.

335: 3Loss aversion as a parameter
339: Remark 3.1 (λ > 1 is a restriction, not a consequence)
340: Definition 1.2 allows any \(\lambda > 0\). The condition \(\lambda > 1\) that defines loss aversion in Definition 1.6 is a parameter restriction. The proofs in Sections 1 and 2 use only \(\lambda > 0\): Proposition 1.4 needs \(\lambda > 0\), and Propositions 2.1 and 2.2 hold for every \(\lambda > 0\). The threshold \(\lambda^{\ast}\) of Example 2.3 is 5/3, which is above 1, but that fact belongs to the example's numbers and not to the theory.
346: Remark 3.2 (the reference point and the sign of a gamble)
347: Suppose the reference point is the expected value \(\mathrm{EV}(G)\) instead of 0, with \(\alpha = \delta\). The gain relative to that point is \(g - \mathrm{EV}(G)\), and the loss has magnitude \(\ell + \mathrm{EV}(G)\). The value is \(p\,(g - \mathrm{EV})^{\alpha} - (1-p)\,\lambda\,(\ell + \mathrm{EV})^{\alpha}\), which is zero at \(\lambda_R := \dfrac{p\,(g-\mathrm{EV})^{\alpha}}{(1-p)\,(\ell+\mathrm{EV})^{\alpha}}\), not at \(\lambda^{\ast}\) in general. Two cases are computed. For \(\alpha = 1\), \(p(g-\mathrm{EV}) - (1-p)(\ell+\mathrm{EV}) = \mathrm{EV} - \mathrm{EV} = 0\), so \(\lambda_R = 1\). For the gamble of Example 2.3, \(g - \mathrm{EV} = \ell + \mathrm{EV} = 800\) cents and \(p = 1/2\), so \(\lambda_R = 1\) for every \(\alpha = \delta\), and the value is \(\tfrac12\cdot 800^{\alpha}(1-\lambda)\). For \(p = 1/3\), \(g = 1000\), \(\ell = 300\) and \(\alpha = \delta = 1/2\), \(\mathrm{EV} = 400/3\), \((g-\mathrm{EV})/(\ell+\mathrm{EV}) = 2\), and \(\lambda_R = \tfrac12\sqrt2 \approx 0.7071\), so the threshold is not 1. The lesson uses the reference point of this remark only here, in Section 4, in Problem R2 and in retrieval quiz item 7.
354: 4Where the canon breaks
356: The value function of Definition 1.2 is a model, and four of its choices are open. Each is named here with its consequence.
359: The size of loss aversion is not settled. Whether \(\lambda\) takes one value across people, stakes and settings is not settled by anything on this page. This lesson cites no source for any magnitude of \(\lambda\), so it states none. Any claim about a typical \(\lambda\) needs a source that this page does not give. Whether \(\lambda\) is stable across stakes and elicitation methods is left open: this page takes no position on it and cites no estimate.
361: The reference point is a choice. Remark 3.2 shows that a different reference point changes the sign threshold. For the gamble of Example 2.3 it moves the threshold from \(\lambda^{\ast} = 5/3\) to 1, and, with \(\alpha = \delta\), the threshold is the formula \(\lambda_R\) of Remark 3.2. The page takes 0 and does not argue that 0 is the right reference point.
363: Evaluation of bundles. Remark 2.5 shows that the sign of a bundle can differ from the sign of each copy. Whether people evaluate gambles alone or together is an empirical question. This lesson makes no claim about it.
365: Probability weighting is absent. Definition 1.3 uses the probabilities \(p_i\) directly. Lesson L07 adds a weighting of probabilities, and the results here do not carry over to that version without a new argument.
373: 5Misconceptions
377: “Loss aversion means that a gamble with a positive expected value is always rejected.”
379: Proposition 2.1 and Example 2.3 show that the prospect value is negative only above the threshold \(\lambda^{\ast}\). The gamble has expected value 200, and at \(\lambda = 3/2\) its prospect value is 50, which is still positive. Lab 1 prints both values.
384: “Loss aversion is a theorem, so every value function with the power form has \(\lambda > 1\).”
386: Remark 3.1 shows that the proofs of this lesson use only \(\lambda > 0\), and Definition 1.2 allows any \(\lambda > 0\). Lab 1 evaluates the prospect value at \(\lambda = 1\), \(3/2\) and \(2\) as parameter values, and the power block uses \(\lambda = 2\) as a stated choice.
391: “The sign of a gamble's prospect value is the same however the gamble is bundled with other gambles.”
393: Remark 2.5 gives a combined value of 100 and a sum of separate values of \(-200\) at \(\lambda = 2\). Lab 1 prints both numbers and the sign pattern.

412: M1 · The threshold for a different gamble
413: Let \(\alpha = \delta = 1\), \(p = 1/3\), \(g = 900\) cents and \(\ell = 300\) cents. Find \(\lambda^{\ast}\), and the sign of \(\mathrm{PV}\) at \(\lambda = 2\).
415: Solution
417: By Proposition 2.1, \(\lambda^{\ast} = \dfrac{(1/3)\cdot 900}{(2/3)\cdot 300} = \dfrac{300}{200} = \dfrac32\). At \(\lambda = 2\), \(\mathrm{PV} = \tfrac13\cdot 900 - \tfrac23\cdot 2\cdot 300 = 300 - 400 = -100\), which is negative, as the proposition requires for \(\lambda > \lambda^{\ast}\).
424: M2 · The value of an even gamble
425: Let \(\alpha = \delta = 1\), \(p = 1/2\), \(g = 100\) and \(\ell = 100\) cents, and \(\lambda = 2\). Find \(\mathrm{EV}(G)\) and \(\mathrm{PV}\).
427: Solution
429: The expected value is \(\tfrac12\cdot 100 - \tfrac12\cdot 100 = 0\). The prospect value is \(\tfrac12\cdot 100 - \tfrac12\cdot 2\cdot 100 = 50 - 100 = -50\). The gamble is fair in expectation and has a negative prospect value at \(\lambda = 2\), with \(\lambda^{\ast} = 1 < 2\).
436: M3 · Equal magnitudes with powers
437: Let \(\alpha = \delta = 1/2\) and \(\lambda = 2\). Compute \(v(16)\), \(v(-16)\) and the ratio \(|v(-16)|/v(16)\).
439: Solution
441: \(v(16) = 16^{1/2} = 4\) and \(v(-16) = -2\cdot 16^{1/2} = -8\). The ratio is \(8/4 = 2 = \lambda\), as Remark 1.5 gives for \(\alpha = \delta\).

454: P1 · Strict monotonicity of the value function
455: Under \(0 < \alpha, \delta \le 1\) and \(\lambda > 0\), show that \(v\) is strictly increasing on \(\R\).
457: Solution
459: For \(x > 0\), \(v'(x) = \alpha x^{\alpha-1} > 0\), so \(v\) is strictly increasing on \((0, \infty)\). For \(x < 0\), \(v'(x) = \lambda\delta(-x)^{\delta-1} > 0\), so \(v\) is strictly increasing on \((-\infty, 0)\). Both pieces are continuous at 0, with \(v(0) = 0\), so for \(x < 0 < y\) we have \(v(x) < 0 < v(y)\), and \(v\) is strictly increasing on \(\R\).
466: P2 · Monotonicity of the prospect value in λ
467: Show that \(\mathrm{PV}(\lambda) = p\,v(g) + (1-p)\,v(-\ell)\) is strictly decreasing in \(\lambda\) when \(p < 1\), \(g > 0\) and \(\ell > 0\), and that \(\alpha\) and \(\delta\) are fixed.
469: Solution
471: Only the second term depends on \(\lambda\), through \(v(-\ell) = -\lambda\,\ell^{\delta}\). So \(\mathrm{PV}(\lambda) = p\,v(g) - (1-p)\,\lambda\,\ell^{\delta}\), which has slope \(-(1-p)\,\ell^{\delta}\). This slope is negative because \(p < 1\) and \(\ell > 0\), so \(\mathrm{PV}\) is strictly decreasing in \(\lambda\).
478: P3 · Equal magnitudes when α = δ
479: Show that if \(\alpha = \delta\), then \(|v(-x)|/v(x) = \lambda\) for every \(x > 0\).
481: Solution
483: For \(x > 0\), \(v(x) = x^{\alpha}\) and \(v(-x) = -\lambda\,x^{\delta} = -\lambda\,x^{\alpha}\). Their ratio in absolute value is \(\lambda\,x^{\alpha}/x^{\alpha} = \lambda\), which does not depend on \(x\).

535: Research
538: R1 · Which choices would identify λ
539: Describe a choice design that would separate the loss-aversion coefficient λ from the curvature parameters \(\alpha\) and \(\delta\), and say what variation the design needs. Do not estimate anything.
541: Solution
543: Propositions 2.1 and 2.2 show that the sign threshold depends on \(p\), \(g\), \(\ell\), \(\alpha\) and \(\delta\). A design that varies the magnitudes \(g\) and \(\ell\) at fixed \(p\) moves the threshold through the powers, so the threshold carries information about \(\alpha\) and \(\delta\) as well as \(\lambda\). This is an argument about identification in the model; it does not show that the design identifies all three parameters. Remark 1.5 shows that with \(\alpha = \delta\) the ratio at equal magnitude is \(\lambda\), so equal-magnitude gambles isolate \(\lambda\) under that restriction. This is an argument about identification in the model.
550: R2 · A reference point at the expected value
551: Explain why the sign threshold of Remark 3.2 is 1 and not \(\lambda^{\ast}\) for the gamble of Example 2.3, and say which assumption of Proposition 2.1 that argument departs from.
553: Solution
555: Remark 3.2 measures outcomes from the expected value, so the two outcomes are \(\pm 800\) cents around that point and the value is \(\tfrac12\cdot 800^{\alpha}(1-\lambda)\) for \(\alpha = \delta\). For that gamble, \(p = 1/2\) and the two magnitudes are equal, so the sign changes at \(\lambda = 1\). Proposition 2.1 uses the reference point 0, so its threshold \(\lambda^{\ast}\) does not apply when the reference point changes. The departure is the reference point, which Definition 1.1 fixes at 0.
562: R3 · When the value of a sum is the sum of values
563: For the value function with \(\alpha = \delta = 1\), show that \(v(x + y) = v(x) + v(y)\) when \(x\) and \(y\) have the same sign. Then show by computation that this fails when \(x > 0 > y\), using \(x = 2\), \(y = -1\) and \(\lambda = 2\).
565: Solution
567: When \(x, y \ge 0\), \(v(x+y) = x + y = v(x) + v(y)\). When \(x, y < 0\), \(v(x+y) = \lambda(x+y) = v(x) + v(y)\). For \(x = 2\) and \(y = -1\) with \(\lambda = 2\), \(v(x+y) = v(1) = 1\), while \(v(x) + v(y) = 2 + 2\cdot(-1) = 0\). The two sides differ, which is the non-additivity behind Remark 2.5.
