66: Expected utility needs one probability for each outcome. When the probability of an outcome is itself unknown, a model can rank bets by a set of probabilities instead. This lesson defines maxmin expected utility over a prior set, defines ambiguity aversion as a certainty equivalent below the average-prior one, and compares four models on one gamble: expected utility, prospect value, two-date Epstein–Zin preferences and maxmin. The comparison shows where the models differ and where they agree. The Epstein–Zin row equals the expected-utility row, for a reason the lesson proves. The parameters are stated, and no estimate is quoted.
69: 1Prior sets and the maxmin rule
72: A gamble \(f\) pays a finite list of outcomes in cents, and each outcome has a probability. When the probability of an outcome is unknown, the decision maker holds a set of candidate probabilities. The candidates are not weighted here, so the set is the whole model of the uncertainty.
76: Definition 1.1 (prior set)
77: A prior set \(\mathcal{P}\) is a finite nonempty set of probability distributions over the outcomes of the gamble. For the two-outcome gambles of this lesson, a prior is a number \(p\) in \([0, 1]\), the probability of the first outcome.
83: Definition 1.2 (maxmin and alpha-MEU)
84: Let \(u\) be a utility function on final wealth, \(\mathcal{P}\) a prior set, and \(\tau \in [0, 1]\). The weight is written \(\tau\), not \(\alpha\), because \(\alpha\) is the gains exponent of Lesson 6. The alpha-MEU value of \(f\) is
85: \[ V_\tau(f) = \tau \min_{P \in \mathcal{P}} \E_P\, u(f) + (1 - \tau) \max_{P \in \mathcal{P}} \E_P\, u(f). \]
86: The maxmin expected utility value is \(V_\tau(f)\) at \(\tau = 1\), which equals \(\min_{P \in \mathcal{P}} \E_P\, u(f)\). The certainty equivalent of \(f\) is \(\mathrm{CE}(f) = u^{-1}(V_\tau(f))\), the sure wealth that has the same utility. The name maxmin expected utility appears in the title of the 1989 Gilboa and Schmeidler paper; this page has not read the paper and cites it for no result. This lesson uses the rule as defined here and states no axiom or result from that paper.
92: Proposition 1.3 (a one-element prior set gives expected utility)
93: Assume:
95: A1. \(\mathcal{P} = \{P\}\) is a single prior;
97: A2. \(\tau \in [0, 1]\).
99: Then \(V_\tau(f) = \E_P\, u(f)\), and the certainty equivalent is the expected-utility certainty equivalent under \(P\).
105: Proof
106: With one prior the minimum and the maximum over \(\mathcal{P}\) are both \(\E_P u(f)\), so \(V_\tau(f) = \tau \E_P u(f) + (1 - \tau)\E_P u(f) = \E_P u(f)\). Applying \(u^{-1}\) gives the certainty equivalent.
112: Example 1.4 (the ambiguous urn and its average prior)
113: An urn holds 90 balls, each red or black. The number \(k\) of red balls is unknown, and the prior set is \(\mathcal{P} = \{P_k : k = 30, 31, \ldots, 60\}\), with \(P_k(\text{red}) = k/90\). The uniform average of the set is \(\bar P\), with \(\bar P(\text{red}) = \frac{1}{31}\sum_{k=30}^{60} k/90 = \frac{45}{90} = \frac{1}{2}\). Each of the three models of Section 4 that takes one probability uses \(\bar P(\text{red}) = 1/2\).
118: 2Ambiguity aversion
121: The gamble of Section 4 is evaluated under the average prior and under the worst prior of Example 1.4. Ambiguity aversion compares these two evaluations.
125: Definition 2.1 (ambiguity aversion)
126: Let \(\bar P\) be the uniform average of a finite prior set \(\mathcal{P}\), and let \(\mathrm{CE}_{\bar P}(f) = u^{-1}(\E_{\bar P} u(f))\) be the certainty equivalent under \(\bar P\). A decision rule is ambiguity averse at \(f\) if \(\mathrm{CE}(f) \le \mathrm{CE}_{\bar P}(f)\). It is ambiguity neutral at \(f\) if equality holds.
132: Theorem 2.2 (maxmin is ambiguity averse)
133: Assume:
135: A1. \(\mathcal{P}\) is finite and nonempty, and \(\bar P\) is its uniform average;
137: A2. \(u\) is strictly increasing on the range of final wealth, so \(u^{-1}\) is defined and strictly increasing on the range of values;
139: A3. \(f\) has finitely many outcomes.
141: Then \(\mathrm{CE}_{\text{maxmin}}(f) \le \mathrm{CE}_{\bar P}(f)\) for every such \(f\).
147: Proof
148: Let \(P_1, \ldots, P_n\) be the priors and \(m = \min_i \E_{P_i} u(f)\). The average prior gives \(\E_{\bar P} u(f) = \frac{1}{n}\sum_i \E_{P_i} u(f)\), which is an average of \(n\) numbers each at least \(m\). So \(\E_{\bar P} u(f) \ge m\). Since \(u^{-1}\) is strictly increasing (A2), \(u^{-1}(m) \le u^{-1}(\E_{\bar P} u(f))\). The left side is \(\mathrm{CE}_{\text{maxmin}}(f)\) and the right side is \(\mathrm{CE}_{\bar P}(f)\). Strict case: if the numbers \(\E_{P_i} u(f)\) are not all equal, at least one of them exceeds \(m\), so their average \(\E_{\bar P} u(f)\) is strictly greater than \(m\), and the inequality is strict, because \(u^{-1}\) is strictly increasing.
154: Remark 2.3 (the inequality needs a prior set with spread)
155: By Proposition 1.3, a one-element prior set gives equality in Theorem 2.2, so it is ambiguity neutral. The inequality is strict when the priors give different expected utilities at \(f\), by the strict case of the proof of Theorem 2.2. In the gamble of Section 4, the priors \(1/3\) and \(2/3\) give different expected utilities, and the maxmin certainty equivalent \(99523.8095\) cents is below the average-prior certainty equivalent \(101951.2195\) cents.
161: Proposition 2.4 (the worst prior depends on the bet)
162: Let an urn hold 90 balls, each red or black, with \(k\) red balls unknown. Assume:
164: A1. the prior set is \(\{P_k : k = 0, 1, \ldots, 90\}\), where \(P_k(\text{red}) = k/90\);
166: A2. \(u\) is strictly increasing on the range of final wealth;
168: A3. a bet on red pays a prize: final wealth is \(w_{\text{red}}\) if the ball is red and \(w_{\text{no}}\) otherwise, with \(w_{\text{red}} > w_{\text{no}}\). A bet on black pays the same prize if the ball is black, so final wealth is \(w_{\text{red}}\) if the ball is black and \(w_{\text{no}}\) otherwise.
170: Then the worst prior for the bet on red is \(P_0\), with no red balls. For the bet on black it is \(P_{90}\), with no black balls. So one prior is not the worst for both bets.
176: Proof
177: For the bet on red, under a prior with \(P(\text{red}) = p\), the expected utility is \(\E_p u(f) = u(w_{\text{no}}) + p\,\bigl(u(w_{\text{red}}) - u(w_{\text{no}})\bigr)\). The bracket is positive by A2 and A3, so this is increasing in \(p\). Its minimum over the prior set is therefore at the smallest \(p\), which is \(p = 0\) under A1 (that is \(P_0\)). For the bet on black the probability of black is \(q = 1 - p\); the same argument applies to \(q\), and the minimum is at \(q = 0\), that is \(p = 1\), which is \(P_{90}\).
183: Example 2.5 (a known urn against the ambiguous urn)
184: A known urn holds 30 red and 60 black balls, so its red probability is \(1/3\) and its black probability is \(2/3\). The bet pays 10000 cents (100 CU) on the stated colour and 0 otherwise, so final wealth is 110000 cents or 100000 cents. Take \(u(w) = -1/w\) (CRRA with \(\gamma = 2\), as in Section 4). With it, the known urn's CE for red is \(103125\) cents, and its CE for black is \(106451.6129\) cents. Under maxmin over the full set \(\{0, \ldots, 90\}\) of red counts, the ambiguous urn's CE is \(100000\) cents for red and \(100000\) cents for black, because the worst prior gives no red and no black ball respectively (Proposition 2.4). The numbers depend on this choice of \(u\), but the preference for the known urn does not. For any strictly increasing \(u\), the worst prior for red, \(P_0\), and the worst prior for black, \(P_{90}\), each give final wealth 100000 cents surely, so the ambiguous CE is 100000 cents for both colours. The known urn's expected utility is \(\tfrac13 u(110000) + \tfrac23 u(100000)\) for red and \(\tfrac23 u(110000) + \tfrac13 u(100000)\) for black, and each exceeds \(u(100000)\), so the known urn's CE exceeds 100000 cents for both colours. So the model prefers the known urn for both colours.
186: The registry title of the 1961 paper by Ellsberg contains the word ambiguity; this page has not read the paper and cites it for no result, so its design and results are not attributed here. The numbers above are the lesson's own, and they describe the model only.
191: 3Epstein–Zin preferences with a stated two-date timing
194: Epstein–Zin preferences separate the elasticity of intertemporal substitution \(\psi\) (Lesson 5) from the risk-aversion coefficient \(\gamma\). A gamble has to be placed in time before its value can be compared. This lesson fixes one convention, stated here, and uses it for the one-shot gamble of Section 4.
198: Definition 3.1 (the two-date value and the timing convention)
199: Let \(\Omega = 1 - 1/\psi\), with \(\psi > 0\) and \(\psi \ne 1\), and let \(\gamma \ne 1\) and \(\beta \in (0, 1)\). Date 0 consumes a sure amount \(c_0 > 0\). Date 1 consumes \(c_1 > 0\), which may be random. The two-date Epstein–Zin value is
200: \[ V_0 = \Bigl[(1 - \beta)\, c_0^{\Omega} + \beta\,\bigl(\E\, c_1^{1 - \gamma}\bigr)^{\Omega/(1 - \gamma)}\Bigr]^{1/\Omega}. \]
201: Timing convention: the gamble pays at date 1 only. The certainty equivalent of a gamble is the sure date-1 amount \(c\) for which the sure plan \((c_0, c)\) has the same \(V_0\) as the gamble.
207: Proposition 3.2 (a gamble at the last date gives the CRRA certainty equivalent)
208: Under Definition 3.1, assume:
210: A1. \(\psi > 0\) and \(\psi \ne 1\), so that \(\Omega \ne 0\);
212: A2. \(\gamma \ne 1\);
214: A3. \(\beta \in (0, 1)\);
216: A4. \(c_0 > 0\);
218: A5. the date-1 gamble has finite support, and every outcome \(c_1\) is positive.
220: Then the Epstein–Zin certainty equivalent equals \((\E\, c_1^{1-\gamma})^{1/(1-\gamma)}\), the CRRA certainty equivalent with the same \(\gamma\). The formula contains neither \(\psi\), nor \(\beta\), nor \(c_0\).
226: Proof
227: Let \(c\) be the sure date-1 amount. The sure plan has \(V_0 = [(1 - \beta)c_0^{\Omega} + \beta c^{\Omega}]^{1/\Omega}\), because \(\E\, c^{1-\gamma} = c^{1-\gamma}\) and \((c^{1-\gamma})^{\Omega/(1-\gamma)} = c^{\Omega}\). The gamble has \(V_0 = [(1 - \beta)c_0^{\Omega} + \beta K]^{1/\Omega}\) with \(K = (\E\, c_1^{1-\gamma})^{\Omega/(1-\gamma)}\). Since \(\Omega \ne 0\) and both bases are positive, the map \(x \mapsto x^{1/\Omega}\) is injective on positive numbers. Equal values therefore require \(\beta c^{\Omega} = \beta K\), and \(\beta > 0\) gives \(c^{\Omega} = K\). Taking the \(\Omega\)-th root, which is injective on positive numbers because \(\Omega \ne 0\), gives \(c = (\E\, c_1^{1-\gamma})^{1/(1-\gamma)}\). This is the CRRA certainty equivalent, and it does not involve \(\psi\), \(\beta\) or \(c_0\).
233: Remark 3.3 (what the convention leaves out)
234: Proposition 3.2 covers a gamble that resolves at the last date. A gamble that resolves earlier, and changes a later consumption, has a random continuation value. Its certainty equivalent can then depend on \(\psi\) and \(\beta\), as a hypothesis the lesson does not test; Problem R1 names the step that fails, and the lesson does not compute the number. The convention is a choice, and the four-model comparison below uses it for the Epstein–Zin row.
240: Lab 1 · The four-model comparison, the identity check and the two-urn check
242: Stated before running: the expected-utility certainty equivalent of the gamble is \(4180000/41 = 101951.2195\) cents; the prospect value gives \(99892.7670\) cents; the Epstein–Zin value under the stated convention gives the same \(101951.2195\) cents as expected utility, for every \(\psi\) and \(\beta\) checked; maxmin gives \(99523.8095\) cents, at the worst prior \(P(\text{red}) = 1/3\); and in the two-urn check the known urn is preferred for both colours.
244: """E3 L08 lab 1: certainty equivalents of one gamble under four preference models, and a two-urn check.
246: Inputs are integer cents (100 cents = 1 CU). Initial wealth is w0 = 100000 cents (1000 CU). The gamble is a bet on
247: one ball drawn from an urn of 90 balls: final wealth is 110000 cents (a gain of 10000 cents) if the ball is red and
248: 95000 cents (a loss of 5000 cents) otherwise. A certainty equivalent (CE) is the sure final wealth, in cents, that
249: the model ranks equal to the gamble. Part A prints each of the four model CEs at four decimals and rounds it once, half
250: up, to a whole cent; Parts B and C print at fixed decimals and do not round to a whole cent.
252: The ambiguous urn holds k red balls, with k unknown and only known to lie in 30 to 60 (the prior set). Four models:
253: 1. Expected utility with CRRA utility u(w) = -1/w (gamma = 2), at P(red) = 1/2, the average of the prior set.
254: 2. Prospect value on changes from the reference point 0, with v(x) = x**(1/2) for gains and -2 * (-x)**(1/2) for
255: losses (alpha = delta = 1/2, lambda = 2), at P(red) = 1/2. The gamble's value is inverted in closed form.
256: 3. Epstein-Zin over two dates: date 0 consumes w0; date 1 consumes final wealth. psi = 1/2, beta = 0.95, gamma = 2,
257: at P(red) = 1/2. The CE is the sure date-1 amount that gives the same date-0 value, found by 200 halvings of
258: a bracket of 17000 cents, which reaches floating-point resolution.
259: 4. Maxmin expected utility over the prior set (tau = 1), and alpha-MEU with tau = 1/2, which weights the lowest
260: and highest expected utility over the prior set.
262: Part A prints the four CEs, the alpha-MEU value at tau = 1/2, the prospect closed form against bisection, and
263: the ambiguity-aversion check. Part B checks the Epstein-Zin CE against the CRRA CE for three values of psi and two of
264: beta. Part C is an Ellsberg-type two-urn check: a known urn (30 red of 90) against an ambiguous urn whose red count is
265: any of 0 to 90, under the CRRA utility u(w) = -1/w. Part D checks that a one-element prior set gives expected
266: utility. Standard library only; no randomness and no network access.
267: """
269: from __future__ import annotations
271: import math
272: from collections.abc import Sequence
273: from fractions import Fraction
275: W0_CENTS = 100_000
276: WIN_CENTS = 110_000
277: LOSS_CENTS = 95_000
278: URN_SIZE = 90
279: PRIOR_SET: tuple[Fraction, ...] = tuple(Fraction(k, URN_SIZE) for k in range(30, 61))
280: FULL_PRIOR_SET: tuple[Fraction, ...] = tuple(Fraction(k, URN_SIZE) for k in range(0, URN_SIZE + 1))
281: GAMMA = 2.0
282: PSI_VALUES: tuple[float, ...] = (0.5, 1.5, 3.0)
283: BETA_VALUES: tuple[float, ...] = (0.9, 0.95)
284: ALPHA_VALUE = 0.5
285: LAMBDA_VALUE = 2.0
286: GAIN_CU = 100.0
287: LOSS_CU = -50.0
290: def average(values: Sequence[Fraction]) -> Fraction:
291: """Arithmetic mean of exact fractions."""
292: return sum(values, Fraction(0)) / len(values)
295: def ce_single_prior(p: Fraction) -> Fraction:
296: """CE in cents of the gamble when red has probability p, under CRRA gamma = 2 (u(w) = -1/w), exactly.
298: The CE solves -1/CE = E u(w) = -(p/WIN + (1 - p)/LOSS), so CE = 1 / E[1/w]."""
299: return 1 / (p / WIN_CENTS + (1 - p) / LOSS_CENTS)
302: def alpha_meu_ce(priors: Sequence[Fraction], tau: Fraction) -> Fraction:
303: """CE in cents of alpha-MEU: V = tau * min_P E_P u + (1 - tau) * max_P E_P u, then CE = u^{-1}(V).
305: With u(w) = -1/w and inv(P) = E_P[1/w], V = -(tau * max inv + (1 - tau) * min inv), so CE = 1/(tau * max inv
306: + (1 - tau) * min inv). tau = 1 is maxmin expected utility."""
307: invs = [ce_inv(p) for p in priors]
308: return 1 / (tau * max(invs) + (1 - tau) * min(invs))
311: def ce_inv(p: Fraction) -> Fraction:
312: """E[1/w] of the gamble when red has probability p, in 1/cents."""
313: return p / WIN_CENTS + (1 - p) / LOSS_CENTS
316: def half_up(value: Fraction) -> int:
317: """Return an exact fraction as a whole number of cents, half up."""
318: return math.floor(value + Fraction(1, 2))
321: def half_up_float(value_cents: float) -> int:
322: """Return a float number of cents as a whole number, half up; refuse a value within 1e-6 cents of a half cent."""
323: floor_part = math.floor(value_cents)
324: if abs(value_cents - floor_part - 0.5) < 1e-6:
325: raise ValueError("the unrounded CE lies within 1e-6 cents of a half cent; the rounding rule is not applied")
326: return math.floor(value_cents + 0.5)
329: def prospect_value(x_cu: float) -> float:
330: """Prospect value of a change x in CU: x**(1/2) for gains, -LAMBDA * (-x)**(1/2) for losses."""
331: if x_cu >= 0:
332: return float(x_cu**ALPHA_VALUE)
333: return float(-LAMBDA_VALUE * (-x_cu) ** (1.0 / 2.0))
336: def prospect_inverse(v: float) -> float:
337: """Closed-form inverse of prospect_value: v**2 for v >= 0, and -(-v / LAMBDA)**2 for v < 0."""
338: if v >= 0:
339: return float(v ** (1.0 / ALPHA_VALUE))
340: return float(-((-v / LAMBDA_VALUE) ** 2))
343: def prospect_inverse_by_bisection(v: float) -> float:
344: """The same inverse by 200 halvings of prospect_value over [-1000, 1000] CU, which reaches
345: floating-point resolution."""
346: lo, hi = -1000.0, 1000.0
347: for _ in range(200):
348: mid = (lo + hi) / 2
349: if prospect_value(mid) < v:
350: lo = mid
351: else:
352: hi = mid
353: return (lo + hi) / 2
356: def ez_value(c0: float, date1: Sequence[tuple[float, float]], psi: float, beta: float) -> float:
357: """Two-date Epstein-Zin value V0 = [(1 - beta) c0**omega + beta * (E[c1**(1 - gamma)])**(omega / (1 - gamma))]
358: ** (1/omega), with omega = 1 - 1/psi, gamma = GAMMA and the terminal value V1 = c1. The sure amount is a
359: one-point distribution."""
360: omega = 1.0 - 1.0 / psi
361: expectation = sum(p * c1 ** (1.0 - GAMMA) for c1, p in date1)
362: inner = (1.0 - beta) * c0**omega + beta * expectation ** (omega / (1.0 - GAMMA))
363: return float(inner ** (1.0 / omega))
366: def ez_certainty_equivalent(c0: float, date1: Sequence[tuple[float, float]], psi: float, beta: float) -> float:
367: """The sure date-1 amount c with ez_value(c0, [(c, 1)]) equal to ez_value(c0, date1), by 200 halvings of
368: a bracket of 17000 cents, which reaches floating-point resolution."""
369: target = ez_value(c0, date1, psi, beta)
370: lo, hi = float(LOSS_CENTS - 1000), float(WIN_CENTS + 1000)
371: for _ in range(200):
372: mid = (lo + hi) / 2
373: if ez_value(c0, [(mid, 1.0)], psi, beta) < target:
374: lo = mid
375: else:
376: hi = mid
377: return (lo + hi) / 2
380: def gamble_outcomes(p: float) -> list[tuple[float, float]]:
381: """Final wealth in cents with probabilities: (WIN, p) and (LOSS, 1 - p)."""
382: return [(float(WIN_CENTS), p), (float(LOSS_CENTS), 1.0 - p)]
385: def part_a() -> None:
386: p_bar = average(PRIOR_SET)
387: print(
388: f"part A: wealth w0 = {W0_CENTS} cents; red pays +{WIN_CENTS - W0_CENTS} cents, otherwise "
389: f"{LOSS_CENTS - W0_CENTS} cents"
390: )
391: print(f"part A: prior set = red counts 30 to 60 out of {URN_SIZE}; average prior P(red) = {p_bar}")
392: eu = ce_single_prior(p_bar)
393: print(f"part A: EU, CRRA gamma = 2, P(red) = 1/2: CE = {float(eu):.4f} cents, whole cents = {half_up(eu)}")
394: prospect_cu = 0.5 * prospect_value(GAIN_CU) + 0.5 * prospect_value(LOSS_CU)
395: prospect_wealth = W0_CENTS + 100.0 * prospect_inverse(prospect_cu)
396: print(
397: f"part A: prospect value V_p = {prospect_cu:.6f} (CU to the 1/2 power), CE = {prospect_wealth:.4f} cents, "
398: f"whole cents = {half_up_float(prospect_wealth)}"
399: )
400: gap_inverse = prospect_inverse(prospect_cu) - prospect_inverse_by_bisection(prospect_cu)
401: print(f"part A: prospect inverse, closed form minus bisection = {gap_inverse:.2e} CU")
402: ez_cents = ez_certainty_equivalent(float(W0_CENTS), gamble_outcomes(0.5), psi=0.5, beta=0.95)
403: print(
404: f"part A: Epstein-Zin, psi = 0.5, beta = 0.95, P(red) = 1/2: CE = {ez_cents:.4f} cents, "
405: f"whole cents = {half_up_float(ez_cents)}"
406: )
407: worst = min(PRIOR_SET, key=ce_single_prior)
408: maxmin = alpha_meu_ce(PRIOR_SET, Fraction(1))
409: print(
410: f"part A: maxmin, tau = 1: worst prior is P(red) = {worst}; CE = {float(maxmin):.4f} cents, "
411: f"whole cents = {half_up(maxmin)}"
412: )
413: mix = alpha_meu_ce(PRIOR_SET, Fraction(1, 2))
414: print(f"part A: alpha-MEU, tau = 1/2: CE = {float(mix):.4f} cents, whole cents = {half_up(mix)}")
415: print(f"part A: alpha-MEU at tau = 1/2 equals the EU CE here = {mix == eu}")
416: print(f"part A: ambiguity aversion holds (maxmin CE <= CE at the average prior) = {maxmin <= eu}")
419: def part_b() -> None:
420: eu_exact = ce_single_prior(average(PRIOR_SET))
421: worst = 0.0

429: f"EZ minus CRRA CE = {ez - float(eu_exact):.2e}"
430: )

432: print(f"part B: all six gaps below 1e-6 cents = {worst < 1e-6}")

508: 4Four models on one gamble
511: The gamble \(f\) pays final wealth \(w_1 = 110000\) cents if the ball is red and \(w_L = 95000\) cents otherwise, from an initial wealth of \(w_0 = 100000\) cents (1000 CU). Its changes are \(+100\) CU and \(-50\) CU. Each model below gives a certainty equivalent in cents, and each is rounded once, half up, to a whole cent.
515: Model 1 (expected utility, CRRA with \(\gamma = 2\))
516: Let \(u(w) = -1/w\), which is CRRA with \(\gamma = 2\) (Lesson 3). The probability is \(\bar P(\text{red}) = 1/2\). Then \(\E\, u(f) = -(\tfrac{1}{2}/w_1 + \tfrac{1}{2}/w_L)\), and \(\mathrm{CE} = 1/(\tfrac{1}{2}/w_1 + \tfrac{1}{2}/w_L) = 4180000/41 = 101951.2195\) cents.
522: Model 2 (prospect value on changes, with \(\alpha = \delta = 1/2\) and \(\lambda = 2\))
523: The value of a change \(x\) in CU is \(v(x) = x^{1/2}\) for \(x \ge 0\) and \(v(x) = -2(-x)^{1/2}\) for \(x < 0\), with reference point 0 (Lesson 6). The gamble's prospect value is \(V_{\mathrm{p}} = \tfrac{1}{2} v(100) + \tfrac{1}{2} v(-50) = 5 - \sqrt{50} = -2.071068\). The inverse on losses is \(v^{-1}(V_{\mathrm{p}}) = -(-V_{\mathrm{p}}/2)^2\), so the certainty equivalent of the change is \(-1.072330\) CU, and the wealth equivalent is \(100000 - 107.2330 = 99892.7670\) cents. This model has no probability weighting; Lesson 7 is not used here.

530: Definition 3.1 with \(c_0 = w_0\) and \(c_1\) equal to final wealth, at \(\bar P(\text{red}) = 1/2\). Here \(\Omega = 1 - 1/\psi = -1\). The certainty equivalent is the sure date-1 amount found by bisection (200 halvings, which reaches floating-point resolution). Proposition 3.2 gives \(101951.2195\) cents, the same as Model 1.
536: Model 4 (maxmin over the prior set, and alpha-MEU with \(\tau = 1/2\))
537: The prior set is \(\{P_k : k = 30, \ldots, 60\}\) of Example 1.4. 565: Remark 4.2 (why the alpha-MEU row coincides with expected utility here)
566: Assuming \(u(w) = -1/w\) (the CRRA utility of Model 1, so that the certainty equivalent is \(1/\E[1/w]\)), and for a two-outcome gamble, \(\E_P[1/w] = p/w_1 + (1-p)/w_L\) is affine in \(p\). Let \(p_{\min}\) and \(p_{\max}\) be the smallest and largest priors. Since \(w_1 > w_L\), the coefficient of \(p\) is \(1/w_1 - 1/w_L < 0\), so \(\E_p[1/w]\) is decreasing in \(p\): its largest value over the set is at \(p_{\min}\) and its smallest is at \(p_{\max}\). Therefore \(\tfrac{1}{2}\E_{p_{\min}}[1/w] + \tfrac{1}{2}\E_{p_{\max}}[1/w] = \E_{(p_{\min} + p_{\max})/2}[1/w]\). So, under the same assumption, the alpha-MEU value at \(\tau = 1/2\) is the expected-utility value at the midpoint \((p_{\min} + p_{\max})/2\). It equals expected utility at the average prior \(\bar P\) when that midpoint equals \(\bar P(\text{red})\). Here the extreme priors \(1/3\) and \(2/3\) have midpoint \(1/2\), and the average prior has \(\bar P(\text{red}) = 45/90 = 1/2\), so both coincide.
571: Maxmin is ambiguity averse here, as Theorem 2.2 guarantees: \(99523.8095 \le 101951.2195\) cents. The risk premium, expected final wealth minus the expected-utility certainty equivalent (not relative to the initial wealth), is \(102500 - 101951.2195 = 548.7805\) cents, with \(102500\) cents the expected final wealth under \(\bar P\). The maxmin certainty equivalent is \(476.1905\) cents below the initial wealth, so the bet is worth less than nothing to that model.
575: 5Where the canon breaks
578: The prior set is a modelling choice. Maxmin depends on the endpoints of the set. With the full set of red counts from 0 to 90, the worst prior for this gamble gives \(P(\text{red}) = 0\), and the certainty equivalent is \(w_L = 95000\) cents. With the set from 30 to 60 it is \(99523.8095\) cents. The numbers of Section 4 are for the set of Example 1.4.
580: Epstein–Zin adds nothing for a gamble at the last date. Proposition 3.2 makes the Epstein–Zin row equal to the CRRA row for every \(\psi > 0\) with \(\psi \ne 1\) and every \(\beta \in (0, 1)\), under its assumptions A1 to A5, which also require \(\gamma \ne 1\), \(c_0 > 0\) and a finite gamble with positive outcomes. The certainty equivalent that Proposition 3.2 gives contains neither \(\psi\) nor \(\beta\). Remark 3.3 names the case, a gamble resolved before a later consumption date, where they can enter; this lesson does not compute it.
582: The magnitudes are parameters, not estimates. The prospect model uses \(\lambda = 2\) and exponents \(1/2\), and the CRRA model uses \(\gamma = 2\). Each is stated for the example. The lesson quotes no published estimate of loss aversion or of any risk-aversion coefficient. Its two named sources are used for their titles only, and this page has not read them.
584: The alpha-MEU row is one point of a family. The lesson computes \(\tau = 1\) and \(\tau = 1/2\). Its coincidence with expected utility at \(\tau = 1/2\) holds because \(g\) is affine and the midpoint of the extreme priors equals the average prior, both \(1/2\) here (Remark 4.2).
592: 6Misconceptions
596: “A maxmin agent applies one pessimistic prior to every gamble.”
598: The worst prior depends on the gamble. Over the full set of red counts 0 to 90, and for bets that pay their prize on their own colour with \(w_{\text{red}} > w_{\text{no}}\) (A3 of Proposition 2.4), the worst prior for a bet on red is the prior with no red balls, and for a bet on black it is the prior with no black balls (Proposition 2.4). The same decision maker evaluates two bets with two different worst priors, so no single prior summarises the rule.
603: “A prior set with one element is ambiguity averse, because maxmin is a worst-case rule.”
605: With one prior the worst case is the only case. Proposition 1.3 gives expected utility, and Remark 2.3 notes that the comparison is an equality, so the model is ambiguity neutral.
610: “Epstein–Zin preferences give a different certainty equivalent from CRRA for every gamble, because they separate risk aversion from the elasticity of substitution.”
612: For a gamble at the last date the two certainty equivalents are equal for every \(\psi > 0\) with \(\psi \ne 1\) and every \(\beta \in (0, 1)\), under assumptions A1 to A5 of Proposition 3.2 (which include \(\gamma \ne 1\)). Lab 1, part B, prints gaps from \(0.00\) to \(-2.91 \times 10^{-11}\) cents over the six pairs, all below \(10^{-6}\) cents. The gaps are of the size of floating-point rounding in the powers and in the bisection, which runs to floating-point resolution. The lesson's convention fixes the dates, and Remark 3.3 names the case where the convention leaves the answer open.

628: Mechanics
631: M1 · Expected utility at one quarter
632: For the gamble of Section 4, with final wealth \(110000\) cents if red and \(95000\) cents otherwise, compute the expected-utility certainty equivalent under \(P(\text{red}) = 1/4\), for \(\gamma = 2\).
634: Solution
636: The CE is \(1/(\tfrac{1}{4}/110000 + \tfrac{3}{4}/95000)\). The inner sum is \(1/440000 + 3/380000 = 85/8360000\), so the CE is \(8360000/85 = 1672000/17 = 98352.94117647\) cents, which is 98352.94 to two decimals. The expected final wealth is \(0.25 \times 110000 + 0.75 \times 95000 = 98750\) cents, and the CE lies below it, as risk aversion requires (Lesson 2).
643: M2 · Maxmin over two priors
644: For the prior set \(\{1/4, 3/4\}\) and the same gamble, find the maxmin certainty equivalent in cents.
646: Solution
648: Maxmin is the smallest certainty equivalent over the priors, because the CE is increasing in \(p\) (as in the proof of Proposition 2.4). The smaller prior \(1/4\) gives \(98352.94\) cents from Problem M1, and the larger prior \(3/4\) gives \(105822.78\) cents. So the maxmin CE is \(98352.94\) cents.
655: M3 · Optimistic weighting over the same two priors
656: For the prior set \(\{1/4, 3/4\}\), compute the alpha-MEU value with \(\tau = 0\), and say which prior it uses.
658: Solution
660: With \(\tau = 0\) the formula gives \(\mathrm{CE} = 1/(\min_P \E_P[1/w])\), which is the largest certainty equivalent. It is attained at the prior \(3/4\), and its value is \(105822.78\) cents, from \(1/(\tfrac{3}{4}/110000 + \tfrac{1}{4}/95000)\).
670: Proof
673: P1 · The one-element prior set
674: Prove Proposition 1.3 for every \(\tau \in [0, 1]\), using only Definition 1.2.
676: Solution
678: With \(\mathcal{P} = \{P\}\), the minimum and the maximum of \(\E_P u(f)\) over \(\mathcal{P}\) are both \(\E_P u(f)\). Substituting into Definition 1.2 gives \(V_\tau(f) = \tau \E_P u(f) + (1 - \tau)\E_P u(f) = \E_P u(f)\), because the two weights sum to one. The certainty equivalent is then \(u^{-1}(\E_P u(f))\), the expected-utility value.
685: P2 · Averages of priors do not raise the maxmin value
686: Prove Theorem 2.2 for the case of two priors \(P_1, P_2\) and a mixture \(\varpi P_1 + (1 - \varpi) P_2\), with \(\varpi \in [0, 1]\), in place of the uniform average.
688: Solution
690: The mixture gives \(\E_{\varpi P_1 + (1 - \varpi)P_2} u(f) = \varpi \E_{P_1} u(f) + (1 - \varpi)\E_{P_2} u(f)\), a weighted average of two numbers with nonnegative weights summing to one. A weighted average of two numbers with nonnegative weights summing to one is at least their minimum \(m\). So the mixture's expected utility is at least \(m\), and applying the strictly increasing \(u^{-1}\) gives \(\mathrm{CE}_{\text{maxmin}}(f) \le u^{-1}(\text{mixture value})\), as in the proof of Theorem 2.2.
697: P3 · Alpha-MEU at the midpoint
698: Let \(\mathcal{P} = \{p_{\min}, p_{\max}\}\) for a two-outcome gamble. Show that the alpha-MEU certainty equivalent at \(\tau = 1/2\) equals the expected-utility certainty equivalent at \((p_{\min} + p_{\max})/2\), for \(u(w) = -1/w\).
700: Solution
702: Write \(g(p) = \E_p[1/w] = p/w_1 + (1-p)/w_L\), which is affine in \(p\). With \(u(w) = -1/w\), the alpha-MEU certainty equivalent is \(1/(\tau \max_P g(P) + (1-\tau)\min_P g(P))\). At \(\tau = 1/2\) the denominator is \(\tfrac{1}{2}g(p_{\min}) + \tfrac{1}{2}g(p_{\max})\) (since \(w_1 > w_L\) makes \(g\) decreasing, \(\max_P g = g(p_{\min})\) and \(\min_P g = g(p_{\max})\)). Affinity gives \(\tfrac{1}{2}g(p_{\min}) + \tfrac{1}{2}g(p_{\max}) = g\bigl((p_{\min} + p_{\max})/2\bigr)\). So the CE equals \(1/g\) at the midpoint, which is the expected-utility CE there.

754: Research
757: R1 · The step that fails for an earlier-resolving gamble
758: Name the step in the proof of Proposition 3.2 that fails when the gamble resolves at date 1 and changes date-2 consumption, and say on what the certainty equivalent then depends.
760: Solution
762: The proof uses that the date-1 value is the consumption \(c_1\) itself, so the expectation is over \(c_1^{1-\gamma}\). That step fails when a later consumption \(c_2\) enters: the date-1 value becomes \(Z_1 = [(1-\beta)c_1^{\Omega} + \beta c_2^{\Omega}]^{1/\Omega}\), which is random when \(c_1\) is random, so the expectation must be taken over \(Z_1^{1-\gamma}\). Whether the certainty equivalent then depends on \(\psi\) and \(\beta\) is the untested hypothesis of Remark 3.3; this solution does not compute it.
769: R2 · A narrower prior set
770: Replace the full set of red counts 0 to 90 by the set 30 to 60 (Example 1.4) in the two-urn check. For each colour, say whether maxmin prefers the known urn, is indifferent, or prefers the ambiguous urn.
772: Solution
774: Under the set 30 to 60, the red probability lies in \([1/3, 2/3]\), so the worst prior for red is \(1/3\), and the ambiguous red CE is \(103125\) cents. The known red CE is also \(103125\) cents, so maxmin is indifferent. For black the probability lies in \([1/3, 2/3]\) as well, and the bet on black is worst at black probability \(1/3\) (red probability \(2/3\)), giving \(103125\) cents. The known black CE is \(106451.6129\) cents, which is higher, so maxmin prefers the known urn for black and is indifferent for red.
781: R3 · Whether the ranking survives a change of utility
782: Suppose the CRRA utility is replaced by \(u(w) = -e^{-\nu w}\) for some \(\nu > 0\), with the same prior set. Does Theorem 2.2 still hold? State the assumption it uses.
784: Solution
786: Yes. Theorem 2.2 uses \(u\) only through A2, that \(u\) is strictly increasing, so the inequality \(\mathrm{CE}_{\text{maxmin}}(f) \le \mathrm{CE}_{\bar P}(f)\) holds for \(u(w) = -e^{-\nu w}\) for any \(\nu > 0\), because \(u\) is strictly increasing there. The numbers of this lesson change, but the inequality does not. The proof does not depend on the form of \(u\), which is the point of stating the assumption.
