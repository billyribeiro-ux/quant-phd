0047: Two lotteries can be compared without a utility function. If one finite lottery puts no more probability at or below every level of wealth than the other, then every nondecreasing utility ranks it no lower. If the means are equal, a weaker test still ranks the pair for every concave utility. This lesson defines both tests for finite lotteries, proves that each is equivalent to a family of expected-utility comparisons, and checks the verdicts in Lab 1 on seeded pairs against expected utilities.
0049: 1
0050: Distribution functions and the integrated test
0052: Assumptions A1 and A2
0053: (finite support and equal means)
0055: A1 (finite support). The lotteries \(X\) and \(Y\) take values in one finite set \(S = \{s_{1} < s_{2} < \dots < s_{m}\}\) of wealth levels in cents. Each \(X\) and \(Y\) is a finite lottery in the sense of Lesson L01, Definition 1.1, with probabilities that sum to 1.
0057: A2 (equal means). \(\E X = \E Y\). A2 is assumed only where the second-order theorem below is stated.
0059: Definition 1.1
0060: (distribution function and integrated distribution function)
0062: The distribution function of \(X\) is \(F_{X}(t) = \Prob(X \le t)\) for real \(t\). Its integrated distribution function is \(I_{X}(t) = \int_{-\infty}^{t} F_{X}(s)\, ds\). Both are defined for every real \(t\), and the second is a finite integral because \(F_{X}(s) = 0\) for \(s < s_{1}\).
0064: Lemma 1.2
0065: (the integrated distribution is a shortfall)
0067: Under A1, for every real \(t\), \(I_{X}(t) = \E\big[(t - X)^{+}\big]\), where \(z^{+} = \max(z, 0)\).
0069: Proof
0071: For a real \(x\), \((t - x)^{+} = \int_{-\infty}^{t} \indic\{x \le s\}\, ds\), because the set of \(s \le t\) with \(x \le s\) is the interval \([x, t]\), which has length \((t - x)^{+}\), or is empty when \(x > t\). Taking expectations, \(\E(t - X)^{+} = \int_{-\infty}^{t} \Prob(X \le s)\, ds = I_{X}(t)\). The interchange of expectation and integral is elementary here, because \(X\) takes finitely many values, so the expectation is a finite sum of integrals of step functions. \(\blacksquare\)
0073: Definition 1.3
0074: (first-order dominance)
0076: Under A1, the lottery \(X\) dominates \(Y\) in the first order when \(F_{X}(t) \le F_{Y}(t)\) for every real \(t\). \(X\) is then at least as likely as \(Y\) to exceed every level \(t\).
0078: Definition 1.4
0079: (the test utilities on S)
0081: A function \(u : S \to \R\) is nondecreasing when \(u(s_{j}) \le u(s_{j+1})\) for every \(j\). It is concave on S when its chord slopes \(\sigma_{j} = \big(u(s_{j+1}) - u(s_{j})\big)/(s_{j+1} - s_{j})\), for \(j = 1, \dots, m-1\), never increase: \(\sigma_{1} \ge \sigma_{2} \ge \dots \ge \sigma_{m-1}\). Both notions use only the values of \(u\) on \(S\), and the expected utility of a lottery on \(S\) is \(\E u(X) = \sum_{j} \Prob(X = s_{j}) u(s_{j})\).
0083: Theorem 1.5
0084: (first-order dominance on a finite support)
0086: Assume A1. Then \(F_{X}(t) \le F_{Y}(t)\) for every real \(t\) if and only if \(\E u(X) \ge \E u(Y)\) for every nondecreasing \(u : S \to \R\).
0088: Proof
0090: Only if. Let \(u\) be nondecreasing on \(S\). Put \(d_{j} = u(s_{j}) - u(s_{j-1}) \ge 0\) for \(j = 2, \dots, m\). For each \(s_{k}\) in \(S\), \(u(s_{k}) = u(s_{1}) + \sum_{j=2}^{k} d_{j}\), so \(u(x) = u(s_{1}) + \sum_{j=2}^{m} d_{j} \indic\{x \ge s_{j}\}\) for every \(x \in S\). Taking expectations, \(\E u(X) = u(s_{1}) + \sum_{j=2}^{m} d_{j} \Prob(X \ge s_{j})\). Because \(X\) takes values in \(S\) and no point of \(S\) lies strictly between \(s_{j-1}\) and \(s_{j}\), \(\{X \ge s_{j}\} = \{X > s_{j-1}\}\), so \(\Prob(X \ge s_{j}) = 1 - F_{X}(s_{j-1})\). The same holds for \(Y\). Subtracting,
0092: \[ \E u(X) - \E u(Y) = \sum_{j=2}^{m} d_{j}\big(F_{Y}(s_{j-1}) - F_{X}(s_{j-1})\big). \]
0094: Each \(d_{j} \ge 0\), and each \(F_{Y}(s_{j-1}) - F_{X}(s_{j-1}) \ge 0\) by hypothesis, so \(\E u(X) \ge \E u(Y)\).
0096: If. Suppose \(F_{X}(t) > F_{Y}(t)\) for some real \(t\). Let \(u_{t}(s) = \indic\{s > t\}\), which is nondecreasing on \(S\). Then \(\E u_{t}(X) = 1 - F_{X}(t) < 1 - F_{Y}(t) = \E u_{t}(Y)\), which contradicts the hypothesis. So \(F_{X}(t) \le F_{Y}(t)\) for every real \(t\). \(\blacksquare\)
0098: Lemma 1.6
0099: (the test needs only the support points)
0101: Under A1, \(F_{X}(t) \le F_{Y}(t)\) for every real \(t\) if and only if \(F_{X}(s) \le F_{Y}(s)\) for every \(s \in S\).
0103: Proof
0105: The "only if" direction is immediate. For the other, let \(t\) be real. If \(t < s_{1}\), both distribution functions are \(0\) at \(t\). Otherwise let \(s_{j}\) be the largest point of \(S\) with \(s_{j} \le t\). Then \(X\) takes no value in \((s_{j}, t]\), so \(F_{X}(t) = \Prob(X \le s_{j}) = F_{X}(s_{j})\), and likewise \(F_{Y}(t) = F_{Y}(s_{j})\). So the inequality at \(t\) is the inequality at \(s_{j} \in S\). \(\blacksquare\)
0107: Example 1.7
0108: (a shift of probability upward)
0110: Let \(X\) put probability \(1/2\) on 2000 cents and \(1/2\) on 4000 cents, and let \(Y\) put probability \(1/2\) on 3000 cents and \(1/2\) on 4000 cents. On \(S = \{2000, 3000, 4000\}\), \(F_{X} = (1/2, 1/2, 1)\) and \(F_{Y} = (0, 1/2, 1)\). So \(F_{Y}(t) \le F_{X}(t)\) at every support point, and by Lemma 1.6, \(Y\) dominates \(X\) in the first order. The means are 3000 and 3500 cents. The example is an instance of Theorem 1.5, not a separate argument.
0112: Proposition 1.8
0113: (first-order dominance implies the integrated order)
0115: Under A1, if \(F_{X}(t) \le F_{Y}(t)\) for every real \(t\), then \(I_{X}(t) \le I_{Y}(t)\) for every real \(t\). This holds without A2.
0117: Proof
0119: For each real \(s\), \(F_{X}(s) \le F_{Y}(s)\) by hypothesis. Both integrals \(\int_{-\infty}^{t} F_{X}(s)\, ds\) and \(\int_{-\infty}^{t} F_{Y}(s)\, ds\) are finite, because each integrand is \(0\) for \(s < s_{1}\) and lies in \([0, 1]\) elsewhere. Integrating the pointwise inequality over \((-\infty, t]\) gives \(I_{X}(t) \le I_{Y}(t)\). \(\blacksquare\)
0121: 2
0122: Second-order dominance
0124: Definition 2.1
0125: (second-order dominance)
0127: Under A1 and A2, the lottery \(X\) dominates \(Y\) in the second order when \(I_{X}(t) \le I_{Y}(t)\) for every real \(t\). By Lemma 1.2 this says \(\E(t - X)^{+} \le \E(t - Y)^{+}\) for every \(t\), so \(X\) has the smaller expected shortfall below every level.
0129: Lemma 2.2
0130: (the integrated test needs only the support points)
0132: Under A1 and A2, \(I_{X}(t) \le I_{Y}(t)\) for every real \(t\) if and only if it holds for every \(s \in S\).
0134: Proof
0136: Let \(D(t) = I_{Y}(t) - I_{X}(t)\). By Lemma 1.2, \(D(t) = \E(t - Y)^{+} - \E(t - X)^{+}\). Between two consecutive points of \(S\), each \((t - x)^{+}\) is an affine function of \(t\), so \(D\) is affine on each interval \([s_{j}, s_{j+1}]\). For \(t \le s_{1}\), \(D(t) = 0\), and for \(t \ge s_{m}\), \((t - X)^{+} = t - X\) and \(D(t) = (t - \E Y) - (t - \E X) = 0\) by A2. So if \(D \ge 0\) on \(S\), then on each interval \(D\) is an affine function that is nonnegative at both ends, hence nonnegative throughout, and \(D \ge 0\) on \(\R\). \(\blacksquare\)
0138: Theorem 2.3
0139: (second-order dominance on a finite support)
0141: Assume A1 and A2. Then \(I_{X}(t) \le I_{Y}(t)\) for every real \(t\) if and only if \(\E u(X) \ge \E u(Y)\) for every nondecreasing concave \(u : S \to \R\) (Definition 1.4).
0143: Proof
0145: If. Fix \(t\) and let \(u_{t}(s) = \min(s - t, 0)\) on \(S\). It is nondecreasing, and its chord slopes are \(1\) on the intervals left of \(t\), \(0\) on the intervals right of \(t\), and a value in \([0, 1]\) on the interval that contains \(t\), so they never increase and \(u_{t}\) is concave on \(S\). Since \(\min(x - t, 0) = -(t - x)^{+}\), Lemma 1.2 gives \(\E u_{t}(X) = -I_{X}(t)\) and \(\E u_{t}(Y) = -I_{Y}(t)\). So \(\E u_{t}(X) \ge \E u_{t}(Y)\) says \(I_{X}(t) \le I_{Y}(t)\).
0147: Only if. Let \(u\) be concave on \(S\) with chord slopes \(\sigma_{1} \ge \dots \ge \sigma_{m-1}\). Let \(L\) be the piecewise linear function that equals \(u\) at each \(s_{j}\) and is affine on each \([s_{j}, s_{j+1}]\). Its slope on \((s_{k}, s_{k+1})\) is \(\sigma_{k}\), so for \(s \in [s_{1}, s_{m}]\),
0149: \[ L(s) = u(s_{1}) + \sigma_{1}(s - s_{1}) + \sum_{j=2}^{m-1} (\sigma_{j} - \sigma_{j-1})\,(s - s_{j})^{+}. \]
0151: Write \((s - s_{j})^{+} = (s - s_{j}) - \min(s - s_{j}, 0)\), and put \(c_{j} = \sigma_{j-1} - \sigma_{j} \ge 0\), which is nonnegative by concavity. Then \(L(s) = b_{0} + b_{1} s + \sum_{j=2}^{m-1} c_{j} \min(s - s_{j}, 0)\) for constants \(b_{0}\) and \(b_{1}\). Since \(X\) and \(Y\) take values in \(S\), \(\E u(X) = \E L(X)\) and \(\E u(Y) = \E L(Y)\). By the expression of \(\E \min(x - t, 0)\) in the "if" part,
0153: \[ \E u(X) - \E u(Y) = b_{1}(\E X - \E Y) +\sum_{j=2}^{m-1} c_{j}\big(I_{Y}(s_{j}) - I_{X}(s_{j})\big). \]
0155: The first term is \(0\) by A2, and each \(c_{j} \ge 0\) with \(I_{Y}(s_{j}) - I_{X}(s_{j}) \ge 0\) by hypothesis. So \(\E u(X) \ge \E u(Y)\). \(\blacksquare\)
0157: Remark 2.4
0158: (what the proof uses)
0160: The "only if" proof uses concavity through \(c_{j} \ge 0\) and A2 through the vanishing of the affine term. It does not use monotonicity. So the same conclusion holds for every concave \(u\) on \(S\). The statement keeps nondecreasing utilities because the "if" direction uses the nondecreasing witnesses \(u_{t}\). Research problem R3 shows where monotonicity enters when the means are not equal.
0162: Example 2.5
0163: (a mean-preserving spread)
0165: Let \(X\) put probability \(1/2\) on 2000 cents and \(1/2\) on 4000 cents, and let \(Y\) put probability \(1/4\) on 1000, \(1/2\) on 3000 and \(1/4\) on 5000 cents. Both means are 3000 cents, so A2 holds. On \(S = \{1000, 2000, 3000, 4000, 5000\}\), the integrated distribution functions are computed from Lemma 1.2 as sums of probability times shortfall.
0167: For \(X\): \(I_{X}(1000) = 0\), \(I_{X}(2000) = 0\), \(I_{X}(3000) = \tfrac12 \cdot 1000 = 500\), \(I_{X}(4000) = \tfrac12 \cdot 2000 = 1000\), and \(I_{X}(5000) = \tfrac12 \cdot 3000 + \tfrac12 \cdot 1000 = 2000\).
0169: For \(Y\): \(I_{Y}(1000) = 0\), \(I_{Y}(2000) = \tfrac14 \cdot 1000 = 250\), \(I_{Y}(3000) = \tfrac14 \cdot 2000 = 500\), \(I_{Y}(4000) = \tfrac14 \cdot 3000 + \tfrac12 \cdot 1000 = 1250\), and \(I_{Y}(5000) = \tfrac14 \cdot 4000 + \tfrac12 \cdot 2000 = 2000\).
0171: So \(I_{X} \le I_{Y}\) at every support point, and by Theorem 2.3 and Lemma 2.2, \(X\) dominates \(Y\) in the second order. The first-order test fails in both directions. At 2000 cents, \(F_{X} = 1/2 > 1/4 = F_{Y}\), so \(F_{X} \le F_{Y}\) fails. At 3000 cents, \(F_{Y} = 3/4 > 1/2 = F_{X}\), so \(F_{Y} \le F_{X}\) fails. The pair is ranked in the second order and not in the first.
0173: Example 2.6
0174: (equal means and no first-order ranking)
0176: Let \(X\) put probability \(1/2\) on 1000 cents and \(1/2\) on 5000 cents, and let \(Y\) put probability 1 on 3000 cents. Both means are 3000 cents. At 1000 cents, \(F_{X} = 1/2 > 0 = F_{Y}\), and at 3000 cents, \(F_{Y} = 1 > 1/2 = F_{X}\). So neither \(F_{X} \le F_{Y}\) nor \(F_{Y} \le F_{X}\) holds, and there is no first-order ranking. The integrated distribution functions give \(I_{Y}(t) = (t - 3000)^{+} \le I_{X}(t)\) at every support point, so \(Y\) dominates \(X\) in the second order. Here the lottery that is ranked is the one with no spread.

0184: SIMULATED: 24 pairs of lotteries on one support of five wealth levels, in cents, are drawn with random.Random(SEED).
0185: Each first lottery places 12 balls on the five levels uniformly at random, so its probabilities are multiples of 1/12.
0186: The second lottery is a shifted copy (one ball moved up, so still multiples of 1/12), a fresh draw, or a mean-matched
0187: lottery (match_mean), whose probabilities are multiples of 1/48.
0188: Three named pairs are fixed in the code and are not SIMULATED. Every integrated distribution function and every
0189: dominance verdict from the distribution functions is exact (fractions.Fraction). The expected utilities of the CRRA
0190: utilities are floating-point, and their differences are compared with a tolerance of 1e-12. Standard library only,
0191: no network.
0193: The check of the expected-utility side uses a finite set of test utilities, not all nondecreasing or all concave
0194: utilities. The set holds the indicator utilities 1{s > t} (first order) or the utilities min(s - t, 0) (second order)
0195: at each support point t, which are the witnesses for the verdicts, together with three CRRA utilities.
0196: """
0198: from __future__ import annotations
0200: import itertools
0201: import math
0202: import random

0204: from fractions import Fraction
0206: SUPPORT = (1000, 2000, 3000, 4000, 5000)
0207: SEED = 20261028
0208: N_BALLS = 12

0210: GAMMAS = (0.5, 1.0, 2.0)
0211: TOL = 1e-12
0213: PMF = tuple[Fraction, ...]
0215: def crra_utility(w: float, gamma: float) -> float:
0216: """CRRA utility of positive wealth w in cents: (w**(1 - gamma) - 1) / (1 - gamma) for gamma != 1, ln(w) at 1."""
0217: if w <= 0.0:
0218: raise ValueError(f"CRRA utility needs positive wealth, got {w}")
0219: if gamma == 1.0:
0220: return math.log(w)
0221: return float((w ** (1.0 - gamma) - 1.0) / (1.0 - gamma))
0223: def from_dict(masses: dict[int, Fraction]) -> PMF:
0224: """A pmf on SUPPORT from a dict of outcome -> probability; every key must lie on SUPPORT."""
0225: if not set(masses) <= set(SUPPORT):
0226: raise ValueError("every outcome must lie on SUPPORT")
0227: return tuple(masses.get(x, Fraction(0)) for x in SUPPORT)
0229: def mean(pmf: PMF) -> Fraction:
0230: """Expected value in cents, exact."""
0231: return sum((p * x for p, x in zip(pmf, SUPPORT, strict=True)), Fraction(0))
0233: def cdf(pmf: PMF, t: int) -> Fraction:
0234: """F(t) = P(X <= t), exact."""
0235: return sum((p for p, x in zip(pmf, SUPPORT, strict=True) if x <= t), Fraction(0))
0237: def integrated_cdf(pmf: PMF, t: int) -> Fraction:
0238: """I(t) = integral of F from minus infinity to t, which equals E[(t - X)^+] for a finite support. Exact."""
0239: return sum((p * max(t - x, 0) for p, x in zip(pmf, SUPPORT, strict=True)), Fraction(0))
0241: def verdict(x_first: bool, y_first: bool) -> str:
0242: """Name the ordering from the two one-way tests: X at least as good as Y, Y at least as good as X, or both."""
0243: if x_first and y_first:
0244: return "identical"
0245: if x_first:
0246: return "X dominates Y"
0247: if y_first:
0248: return "Y dominates X"

0251: def fosd_cdf_verdict(px: PMF, py: PMF) -> str:

0254: fy = [cdf(py, t) for t in SUPPORT]

0257: def sosd_cdf_verdict(px: PMF, py: PMF) -> str:
0258: """Second-order verdict from integrated distribution functions, for equal means. X dominates Y when I_X <= I_Y."""
0259: if mean(px) != mean(py):
0260: raise ValueError("the second-order test in this lab needs equal means")

0262: iy = [integrated_cdf(py, t) for t in SUPPORT]

0265: def eu_verdict(diffs: list[Fraction | float]) -> str:
0266: """Verdict from the expected-utility differences E u(X) - E u(Y) over a set of test utilities."""
0267: return verdict(all(d >= -TOL for d in diffs), all(d <= TOL for d in diffs))
0269: def exact_diffs(px: PMF, py: PMF, utilities: list[tuple[Fraction, ...]]) -> list[Fraction | float]:
0270: """E u(X) - E u(Y) for exact-valued utilities, computed as Fractions."""
0271: return [sum(((a - b) * v for a, b, v in zip(px, py, u, strict=True)), Fraction(0)) for u in utilities]
0273: def float_diffs(px: PMF, py: PMF, utilities: list[tuple[float, ...]]) -> list[Fraction | float]:
0274: """E u(X) - E u(Y) for floating-point utilities."""
0275: return [sum(float(a - b) * v for a, b, v in zip(px, py, u, strict=True)) for u in utilities]
0277: def indicator_utilities() -> list[tuple[Fraction, ...]]:
0278: """The first-order witnesses 1{s > t} at each support point t."""
0279: return [tuple(Fraction(1 if x > t else 0) for x in SUPPORT) for t in SUPPORT]
0281: def min_utilities() -> list[tuple[Fraction, ...]]:
0282: """The second-order witnesses min(s - t, 0) at each support point t: nondecreasing and concave in s."""
0283: return [tuple(Fraction(min(x - t, 0)) for x in SUPPORT) for t in SUPPORT]
0285: def crra_values() -> list[tuple[float, ...]]:
0286: """CRRA utilities at the support points, for the gamma values in GAMMAS."""
0287: return [tuple(crra_utility(float(x), g) for x in SUPPORT) for g in GAMMAS]
0289: def chord_slopes_nonincreasing(values: tuple[Fraction | float, ...]) -> bool:
0290: """True when the chord slopes of the function through (SUPPORT, values) never increase: concavity on the support."""
0291: slopes = [(values[j + 1] - values[j]) / (SUPPORT[j + 1] - SUPPORT[j]) for j in range(len(SUPPORT) - 1)]
0292: return all(a >= b for a, b in itertools.pairwise(slopes))
0294: def draw_pmf(rng: random.Random) -> PMF:

0302: """Move one ball's probability, 1/N_BALLS, from a lower support point to a higher one. None if no ball can move."""
0303: step = Fraction(1, N_BALLS)
0304: eligible = [i for i in range(len(SUPPORT) - 1) if px[i] >= step]
0305: if not eligible:
0306: return None
0307: i = rng.choice(eligible)
0308: j = rng.randrange(i + 1, len(SUPPORT))

0310: q[i] -= step
0311: q[j] += step
0312: return tuple(q)
0314: def match_mean(pmf: PMF, target: Fraction) -> PMF | None:
0315: """Move mass between the lowest and highest support points until the mean equals target. None if infeasible."""
0316: move = (target - mean(pmf)) / (SUPPORT[-1] - SUPPORT[0])
0317: q = list(pmf)
0318: if move >= 0:
0319: if q[0] < move:
0320: return None
0321: q[0] -= move

0323: else:
0324: m = -move

0329: return tuple(q)

0474: Where the canon breaks
0476: Dominance is a partial ranking, not a total one, and four limits apply to this lesson.
0478: The support is finite. Theorems 1.5 and 2.3 are proved here for lotteries with finite support, under A1. The statement for general distributions is not proved on this page, and this lesson cites no source for it.
0480: Second-order dominance needs equal means. Theorem 2.3 assumes A2. Research problem R3 gives the monotone case when the means differ, and the lesson does not state a general result beyond it.
0482: Some pairs are not ranked. In Lab 1, 10 of the 24 seeded pairs have no first-order ranking, and 2 of the 8 equal-mean pairs have no second-order ranking. A verdict of "no ranking" is a result, not an error: the test does not order that pair, and by the proof of Theorem 1.5, some nondecreasing utility prefers X to Y and some nondecreasing utility prefers Y to X.
0484: The test set is finite. Lab 1 checks verdicts against the witnesses of the proofs and three CRRA utilities. The theorems quantify over every nondecreasing or concave utility on \(S\), and the lab does not check that quantifier.

0487: Misconceptions
0489: “Equal means make one lottery dominate the other.”
0491: Equal means are a hypothesis of the second-order theorem, not a ranking. Example 2.6 has equal means of 3000 cents and no first-order ranking, and Example 2.5 has equal means and a second-order ranking in one direction only. The mean says nothing about the shape, so a ranking needs one of the two tests.
0493: “Second-order dominance is a weaker test, so it ranks every pair.”
0495: The second-order test applies only to pairs with equal means (A2), and it ranks a pair only when the integrated distribution functions are ordered at every support point. Lab 1 finds 2 equal-mean pairs with no second-order ranking, pairs 16 and 19 in its list. The lab does not apply the second-order test to its unequal-mean pairs.
0497: “The second-order test is the first-order test under another name.”
0499: The first-order test compares distribution functions, and the second-order test compares their integrals. Example 2.5 has a second-order ranking and no first-order ranking, so the two tests are different. Proposition 1.8 shows that a first-order ranking implies the integrated ordering, so the second-order test is the weaker of the two in that sense.

0506: Mechanics
0508: M1 · Distribution functions of two lotteries
0510: Let \(X\) put probability \(1/2\) on 1000 cents and \(1/2\) on 4000 cents, and let \(Y\) put probability 1 on 2000 cents. Find \(F_{X}\) and \(F_{Y}\) at 1000, 2000 and 4000 cents, and state the first-order verdict.
0512: Solution
0514: \(F_{X}(1000) = 1/2\), \(F_{X}(2000) = 1/2\), \(F_{X}(4000) = 1\). \(F_{Y}(1000) = 0\), \(F_{Y}(2000) = 1\), \(F_{Y}(4000) = 1\). Then \(F_{X}(1000) > F_{Y}(1000)\), so \(F_{X} \le F_{Y}\) fails. Also \(F_{Y}(2000) > F_{X}(2000)\), so \(F_{Y} \le F_{X}\) fails. There is no first-order ranking. The means are 2500 and 2000 cents, so the means alone would suggest an ordering that the first-order test does not give.
0516: M2 · An integrated distribution value
0518: For the pair of Example 2.5, compute \(I_{X}(3000)\) and \(I_{Y}(3000)\) from the definition \(I(t) = \E(t - X)^{+}\).
0520: Solution
0522: For \(X\), \((3000 - 2000)^{+} = 1000\) with probability \(1/2\) and \((3000 - 4000)^{+} = 0\) with probability \(1/2\), so \(I_{X}(3000) = 500\). For \(Y\), \((3000 - 1000)^{+} = 2000\) with probability \(1/4\), and the other two outcomes are at or above 3000, so \(I_{Y}(3000) = 500\). Both equal 500, which agrees with the table in Example 2.5.
0524: M3 · Two ways to compute an integrated value
0526: Let \(X\) put probability \(1/4\) on 1000 cents and \(3/4\) on 5000 cents. Compute \(I_{X}(3000)\) once as the integral of \(F_{X}\) and once as \(\E(3000 - X)^{+}\), and check that they agree.
0528: Solution
0530: \(F_{X}(s) = 0\) for \(s < 1000\), \(F_{X}(s) = 1/4\) for \(1000 \le s < 5000\). So \(\int_{-\infty}^{3000} F_{X}(s)\,ds = \tfrac14 (3000 - 1000) = 500\). The expectation is \(\tfrac14 (3000 - 1000)^{+} + \tfrac34 (3000 - 5000)^{+} = \tfrac14 \cdot 2000 + 0 = 500\). The two computations agree, as Lemma 1.2 requires.
0532: Proof
0534: P1 · The test needs only support points
0536: Prove Lemma 1.6 without citing it, for a point \(t\) between two consecutive points of \(S\).
0538: Solution
0540: Let \(s_{j} < t < s_{j+1}\). Neither \(X\) nor \(Y\) takes a value in \((s_{j}, t]\), because that interval contains no point of \(S\). So \(\Prob(X \le t) = \Prob(X \le s_{j})\) and \(\Prob(Y \le t) = \Prob(Y \le s_{j})\). The inequality \(F_{X}(t) \le F_{Y}(t)\) is therefore the inequality \(F_{X}(s_{j}) \le F_{Y}(s_{j})\) at a point of \(S\). If \(t > s_{m}\), no point of \(S\) lies in \((s_{m}, t]\), so \(F_{X}(t) = F_{X}(s_{m})\) and \(F_{Y}(t) = F_{Y}(s_{m})\), and both equal 1 because every outcome is at most \(s_{m}\). The argument is then complete for every \(t\) with \(s_{1} \le t\). For \(t < s_{1}\), both distribution functions are 0.
0542: P2 · First-order dominance implies the integrated order
0544: Prove Proposition 1.8 in one line of integration, and say which hypothesis is not needed.
0546: Solution
0548: If \(F_{X} \le F_{Y}\) everywhere, then \(\int_{-\infty}^{t} F_{X}(s)\,ds \le \int_{-\infty}^{t} F_{Y}(s)\,ds\), because the integral of a pointwise smaller function over the same interval is smaller. Both integrals are finite since each integrand is 0 below \(s_{1}\) and lies in \([0, 1]\). The equal-means hypothesis A2 is not needed, because the integrated order does not involve the means.
0550: P3 · The witness utility is nondecreasing and concave
0552: For a fixed \(t \in S\), show that \(u_{t}(s) = \min(s - t, 0)\) is nondecreasing and concave on \(S\) in the sense of Definition 1.4, and that \(\E u_{t}(X) = -I_{X}(t)\).
0554: Solution
0556: The values \(u_{t}(s)\) are \(s - t\) for \(s < t\) and 0 for \(s \ge t\), so they never decrease in \(s\). The chord slope between consecutive points left of \(t\) is 1, and between consecutive points at or to the right of \(t\) it is 0, and the slope across \(t\) lies between them, so the chord slopes are nonincreasing. Finally \(\min(x - t, 0) = -(t - x)^{+}\), so \(\E u_{t}(X) = -\E(t - X)^{+} = -I_{X}(t)\) by Lemma 1.2.

0584: Research
0586: R1 · The converse of first-order dominance
0588: Show that the integrated ordering of Proposition 1.8 does not imply the first-order ordering, using Example 2.5.
0590: Solution
0592: In Example 2.5, \(I_{X}(t) \le I_{Y}(t)\) at every support point, so the integrated ordering holds. But the first-order ordering fails, because \(F_{X}(2000) = 1/2 > 1/4 = F_{Y}(2000)\). So the integrated ordering is strictly weaker, and the first-order ordering does not follow from it.
0594: R2 · Where the equal-means hypothesis enters
0596: Explain in one paragraph why Theorem 2.3 needs A2 in its "only if" direction, and identify the term of the proof that A2 removes.
0598: Solution
0600: The proof writes \(\E u(X) - \E u(Y)\) as \(b_{1}(\E X - \E Y)\) plus a sum of nonnegative terms weighted by the integrated distributions. The coefficient \(b_{1}\) is the slope of the interpolant on the last interval, and the term \(b_{1}(\E X - \E Y)\) is nonzero in general when the means differ. A2 removes that term, so the sum of nonnegative terms alone decides the ordering.
0602: R3 · Unequal means under a nondecreasing concave utility
0604: Suppose \(I_{X}(t) \le I_{Y}(t)\) for every \(t\) but A2 fails, and \(u\) is nondecreasing and concave on \(S\). Show that \(\E u(X) \ge \E u(Y)\) still holds.
0606: Solution
0608: Use the representation of the "only if" proof. The slope of the interpolant on the last interval is \(b_{1} = \sigma_{m-1} \ge 0\), because \(u\) is nondecreasing. At \(t = s_{m}\), every outcome is at most \(t\), so \(I_{X}(s_{m}) = s_{m} - \E X\) and \(I_{Y}(s_{m}) = s_{m} - \E Y\). The hypothesis \(I_{X}(s_{m}) \le I_{Y}(s_{m})\) then gives \(\E X \ge \E Y\), so the affine term \(b_{1}(\E X - \E Y)\) is nonnegative. The sum of nonnegative terms is nonnegative as before, so \(\E u(X) \ge \E u(Y)\). This is where monotonicity enters.
