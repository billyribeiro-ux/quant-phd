0047: Expected utility needs one probability for each outcome. When the probability of an outcome is itself unknown, a model can rank bets by a set of probabilities instead. This lesson defines maxmin expected utility over a prior set, defines ambiguity aversion as a certainty equivalent below the average-prior one, and compares four models on one gamble: expected utility, prospect value, two-date Epstein–Zin preferences and maxmin. The comparison shows where the models differ and where they agree. The Epstein–Zin row equals the expected-utility row, for a reason the lesson proves. The parameters are stated, and no estimate is quoted.
0049: 1
0050: Prior sets and the maxmin rule
0052: A gamble \(f\) pays a finite list of outcomes in cents, and each outcome has a probability. When the probability of an outcome is unknown, the decision maker holds a set of candidate probabilities. The candidates are not weighted here, so the set is the whole model of the uncertainty.
0054: Definition 1.1
0055: (prior set)
0057: A prior set \(\mathcal{P}\) is a finite nonempty set of probability distributions over the outcomes of the gamble. For the two-outcome gambles of this lesson, a prior is a number \(p\) in \([0, 1]\), the probability of the first outcome.
0059: Definition 1.2
0060: (maxmin and alpha-MEU)
0062: Let \(u\) be a utility function on final wealth, \(\mathcal{P}\) a prior set, and \(\tau \in [0, 1]\). The weight is written \(\tau\), not \(\alpha\), because \(\alpha\) is the gains exponent of Lesson 6. The alpha-MEU value of \(f\) is
0063: \[ V_\tau(f) = \tau \min_{P \in \mathcal{P}} \E_P\, u(f) + (1 - \tau) \max_{P \in \mathcal{P}} \E_P\, u(f). \]
0064: The maxmin expected utility value is \(V_1(f) = \min_{P \in \mathcal{P}} \E_P\, u(f)\). The certainty equivalent of \(f\) is \(\mathrm{CE}(f) = u^{-1}(V_\tau(f))\), the sure wealth that has the same utility.
0065: The name maxmin expected utility appears in the title of the 1989 Gilboa and Schmeidler paper
0066: ; this lesson uses the rule as defined here and does not reproduce the paper's axioms or results.
0068: Proposition 1.3
0069: (a one-element prior set gives expected utility)
0071: Assume:
0073: A1. \(\mathcal{P} = \{P\}\) is a single prior;
0075: A2. \(\tau \in [0, 1]\).
0077: Then \(V_\tau(f) = \E_P\, u(f)\), and the certainty equivalent is the expected-utility certainty equivalent under \(P\).
0079: Proof
0081: With one prior the minimum and the maximum over \(\mathcal{P}\) are both \(\E_P u(f)\), so \(V_\tau(f) = \tau \E_P u(f) + (1 - \tau)\E_P u(f) = \E_P u(f)\). Applying \(u^{-1}\) gives the certainty equivalent.
0083: Example 1.4
0084: (the ambiguous urn and its average prior)
0086: An urn holds 90 balls, each red or black. The number \(k\) of red balls is unknown, and the prior set is \(\mathcal{P} = \{P_k : k = 30, 31, \ldots, 60\}\), with \(P_k(\text{red}) = k/90\). The uniform average of the set is \(\bar P\), with \(\bar P(\text{red}) = \frac{1}{31}\sum_{k=30}^{60} k/90 = \frac{45}{90} = \frac{1}{2}\). Each of the three models of Section 4 that takes one probability uses \(\bar P(\text{red}) = 1/2\).
0088: 2
0089: Ambiguity aversion
0091: The gamble of Section 4 is evaluated under the average prior and under the worst prior of Example 1.4. Ambiguity aversion compares these two evaluations.
0093: Definition 2.1
0094: (ambiguity aversion)
0096: Let \(\bar P\) be the uniform average of a finite prior set \(\mathcal{P}\), and let \(\mathrm{CE}_{\bar P}(f) = u^{-1}(\E_{\bar P} u(f))\) be the certainty equivalent under \(\bar P\). A decision rule is ambiguity averse at \(f\) if \(\mathrm{CE}(f) \le \mathrm{CE}_{\bar P}(f)\). It is ambiguity neutral at \(f\) if equality holds.
0098: Theorem 2.2
0099: (maxmin is ambiguity averse)
0101: Assume:
0103: A1. \(\mathcal{P}\) is finite and nonempty, and \(\bar P\) is its uniform average;
0105: A2. \(u\) is strictly increasing on the range of final wealth, so \(u^{-1}\) is defined and strictly increasing on the range of values;
0107: A3. \(f\) has finitely many outcomes.
0109: Then \(\mathrm{CE}_{\text{maxmin}}(f) \le \mathrm{CE}_{\bar P}(f)\) for every such \(f\).
0111: Proof
0113: Let \(P_1, \ldots, P_n\) be the priors and \(m = \min_i \E_{P_i} u(f)\). The average prior gives \(\E_{\bar P} u(f) = \frac{1}{n}\sum_i \E_{P_i} u(f)\), which is an average of \(n\) numbers each at least \(m\). So \(\E_{\bar P} u(f) \ge m\). Since \(u^{-1}\) is strictly increasing (A2), \(u^{-1}(m) \le u^{-1}(\E_{\bar P} u(f))\). The left side is \(\mathrm{CE}_{\text{maxmin}}(f)\) and the right side is \(\mathrm{CE}_{\bar P}(f)\). Strict case: if the numbers \(\E_{P_i} u(f)\) are not all equal, at least one of them exceeds \(m\), so their average \(\E_{\bar P} u(f)\) is strictly greater than \(m\), and the inequality is strict, because \(u^{-1}\) is strictly increasing.
0115: Remark 2.3
0116: (the inequality needs a prior set with spread)
0118: By Proposition 1.3, a one-element prior set gives equality in Theorem 2.2, so it is ambiguity neutral. The inequality is strict when the priors give different expected utilities at \(f\), by the strict case of the proof of Theorem 2.2. In the gamble of Section 4, the priors \(1/3\) and \(2/3\) give different expected utilities, and the maxmin certainty equivalent \(99523.8095\) cents is below the average-prior certainty equivalent \(101951.2195\) cents.
0120: Proposition 2.4
0121: (the worst prior depends on the bet)
0123: Let an urn hold 90 balls, each red or black, with \(k\) red balls unknown. Assume:
0125: A1. the prior set is \(\{P_k : k = 0, 1, \ldots, 90\}\), where \(P_k(\text{red}) = k/90\);
0127: A2. \(u\) is strictly increasing on the range of final wealth;
0129: A3. a bet on red pays a prize: final wealth is \(W_{\text{red}}\) if the ball is red and \(W_{\text{no}}\) otherwise, with \(W_{\text{red}} > W_{\text{no}}\). A bet on black pays the same prize if the ball is black, so final wealth is \(W_{\text{red}}\) if the ball is black and \(W_{\text{no}}\) otherwise.
0131: Then the worst prior for the bet on red is \(P_0\), with no red balls. For the bet on black it is \(P_{90}\), with no black balls. So one prior is not the worst for both bets.
0133: Proof
0135: For the bet on red, under a prior with \(P(\text{red}) = p\), the expected utility is \(\E_p u(f) = u(W_{\text{no}}) + p\,\bigl(u(W_{\text{red}}) - u(W_{\text{no}})\bigr)\). The bracket is positive by A2 and A3, so this is increasing in \(p\). Its minimum over the prior set is therefore at the smallest \(p\), which is \(p = 0\) under A1 (that is \(P_0\)). For the bet on black the probability of black is \(q = 1 - p\); the same argument applies to \(q\), and the minimum is at \(q = 0\), that is \(p = 1\), which is \(P_{90}\).
0137: Example 2.5
0138: (a known urn against the ambiguous urn)
0140: A known urn holds 30 red and 60 black balls, so its red probability is \(1/3\) and its black probability is \(2/3\). The bet pays 10000 cents (100 CU) on the stated colour and 0 otherwise, so final wealth is 110000 cents or 100000 cents. Take \(u(W) = -1/W\) (CRRA with \(\gamma = 2\), as in Section 4). With it, the known urn's CE for red is \(103125\) cents, and its CE for black is \(106451.6129\) cents. Under maxmin over the full set \(\{0, \ldots, 90\}\) of red counts, the ambiguous urn's CE is \(100000\) cents for red and \(100000\) cents for black, because the worst prior gives no red and no black ball respectively (Proposition 2.4). The numbers depend on this choice of \(u\), but the preference for the known urn does not. For any strictly increasing \(u\), the worst prior for red, \(P_0\), and the worst prior for black, \(P_{90}\), each give final wealth 100000 cents surely, so the ambiguous CE is 100000 cents for both colours. The known urn's expected utility is \(\tfrac13 u(110000) + \tfrac23 u(100000)\) for red and \(\tfrac23 u(110000) + \tfrac13 u(100000)\) for black, and each exceeds \(u(100000)\), so the known urn's CE exceeds 100000 cents for both colours. So the model prefers the known urn for both colours.
0142: The registry title of the 1961 paper by Ellsberg contains the word ambiguity
0143: . The lesson did not read the 1961 paper, so its design and results are not attributed here. The numbers above are the lesson's own, and they describe the model only.
0145: 3
0146: Epstein–Zin preferences with a stated two-date timing
0148: Epstein–Zin preferences separate the elasticity of intertemporal substitution \(\psi\) (Lesson 5) from the risk-aversion coefficient \(\gamma\). A gamble has to be placed in time before its value can be compared. This lesson fixes one convention, stated here, and uses it for the one-shot gamble of Section 4.
0150: Definition 3.1
0151: (the two-date value and the timing convention)
0153: Let \(a = 1 - 1/\psi\), with \(\psi > 0\) and \(\psi \ne 1\), and let \(\gamma \ne 1\) and \(\beta \in (0, 1)\). Date 0 consumes a sure amount \(c_0 > 0\). Date 1 consumes \(c_1 > 0\), which may be random. The two-date Epstein–Zin value is
0154: \[ V_0 = \Bigl[(1 - \beta)\, c_0^{a} + \beta\,\bigl(\E\, c_1^{1 - \gamma}\bigr)^{a/(1 - \gamma)}\Bigr]^{1/a}. \]
0155: Timing convention: the gamble pays at date 1 only. The certainty equivalent of a gamble is the sure date-1 amount \(c\) for which the sure plan \((c_0, c)\) has the same \(V_0\) as the gamble.
0157: Proposition 3.2
0158: (a gamble at the last date gives the CRRA certainty equivalent)
0160: Under Definition 3.1, assume:
0162: A1. \(\psi > 0\) and \(\psi \ne 1\), so that \(a \ne 0\);
0164: A2. \(\gamma \ne 1\);
0166: A3. \(\beta \in (0, 1)\);
0168: A4. \(c_0 > 0\);
0170: A5. the date-1 gamble has finite support, and every outcome \(c_1\) is positive.
0172: Then the Epstein–Zin certainty equivalent equals \((\E\, c_1^{1-\gamma})^{1/(1-\gamma)}\), the CRRA certainty equivalent with the same \(\gamma\). The formula contains neither \(\psi\), nor \(\beta\), nor \(c_0\).
0174: Proof
0176: Let \(c\) be the sure date-1 amount. The sure plan has \(V_0 = [(1 - \beta)c_0^{a} + \beta c^{a}]^{1/a}\), because \(\E\, c^{1-\gamma} = c^{1-\gamma}\) and \((c^{1-\gamma})^{a/(1-\gamma)} = c^{a}\). The gamble has \(V_0 = [(1 - \beta)c_0^{a} + \beta K]^{1/a}\) with \(K = (\E\, c_1^{1-\gamma})^{a/(1-\gamma)}\). Since \(a \ne 0\) and both bases are positive, the map \(x \mapsto x^{1/a}\) is injective on positive numbers. Equal values therefore require \(\beta c^{a} = \beta K\), and \(\beta > 0\) gives \(c^{a} = K\). Taking the \(a\)-th root, which is injective on positive numbers because \(a \ne 0\), gives \(c = (\E\, c_1^{1-\gamma})^{1/(1-\gamma)}\). This is the CRRA certainty equivalent, and it does not involve \(\psi\), \(\beta\) or \(c_0\).
0178: Remark 3.3
0179: (what the convention leaves out)
0181: Proposition 3.2 covers a gamble that resolves at the last date. A gamble that resolves earlier, and changes a later consumption, has a random continuation value. Its certainty equivalent can then depend on \(\psi\) and \(\beta\), as a hypothesis the lesson does not test; Problem R1 names the step that fails, and the lesson does not compute the number. The convention is a choice, and the four-model comparison below uses it for the Epstein–Zin row.
0183: Lab 1 · The four-model comparison, the identity check and the two-urn check
0185: Stated before running: the expected-utility certainty equivalent of the gamble is \(4180000/41 = 101951.2195\) cents; the prospect value gives \(99892.7670\) cents; the Epstein–Zin value under the stated convention gives the same \(101951.2195\) cents as expected utility, for every \(\psi\) and \(\beta\) checked; maxmin gives \(99523.8095\) cents, at the worst prior \(P(\text{red}) = 1/3\); and in the two-urn check the known urn is preferred for both colours.
0187: """E3 L08 lab 1: certainty equivalents of one gamble under four preference models, and a two-urn check.
0189: Inputs are integer cents (100 cents = 1 CU). Initial wealth is W0 = 100000 cents (1000 CU). The gamble is a bet on
0190: one ball drawn from an urn of 90 balls: final wealth is 110000 cents (a gain of 10000 cents) if the ball is red and
0191: 95000 cents (a loss of 5000 cents) otherwise. A certainty equivalent (CE) is the sure final wealth, in cents, that
0192: the model ranks equal to the gamble. Part A prints each of the four model CEs at four decimals and rounds it once, half
0193: up, to a whole cent; Parts B and C print at fixed decimals and round nothing to a whole cent.
0195: The ambiguous urn holds k red balls, with k unknown and only known to lie in 30 to 60 (the prior set). Four models:
0196: 1. Expected utility with CRRA utility u(W) = -1/W (gamma = 2), at P(red) = 1/2, the average of the prior set.
0197: 2. Prospect value on changes from the reference point 0, with v(x) = x**(1/2) for gains and -2 * (-x)**(1/2) for
0198: losses (alpha = delta = 1/2, lambda = 2), at P(red) = 1/2. The gamble's value is inverted in closed form.
0199: 3. Epstein-Zin over two dates: date 0 consumes W0; date 1 consumes final wealth. psi = 1/2, beta = 0.95, gamma = 2,
0200: at P(red) = 1/2. The CE is the sure date-1 amount that gives the same date-0 value, found by 200 halvings of
0201: a bracket of 17000 cents, which reaches floating-point resolution.
0202: 4. Maxmin expected utility over the prior set (tau = 1), and alpha-MEU with tau = 1/2, which weights the lowest
0203: and highest expected utility over the prior set.
0205: Part A prints the four CEs, the alpha-MEU value at tau = 1/2, the prospect closed form against bisection, and
0206: the ambiguity-aversion check. Part B checks the Epstein-Zin CE against the CRRA CE for three values of psi and two of
0207: beta. Part C is an Ellsberg-type two-urn check: a known urn (30 red of 90) against an ambiguous urn whose red count is
0208: any of 0 to 90, under the CRRA utility u(W) = -1/W. Part D checks that a one-element prior set gives expected
0209: utility. Standard library only; no randomness and no network access.
0210: """
0212: from __future__ import annotations
0214: import math
0215: from collections.abc import Sequence
0216: from fractions import Fraction
0218: W0_CENTS = 100_000
0219: WIN_CENTS = 110_000
0220: LOSS_CENTS = 95_000
0221: URN_SIZE = 90
0222: PRIOR_SET: tuple[Fraction, ...] = tuple(Fraction(k, URN_SIZE) for k in range(30, 61))
0223: FULL_PRIOR_SET: tuple[Fraction, ...] = tuple(Fraction(k, URN_SIZE) for k in range(0, URN_SIZE + 1))
0224: GAMMA = 2.0
0225: PSI_VALUES: tuple[float, ...] = (0.5, 1.5, 3.0)
0226: BETA_VALUES: tuple[float, ...] = (0.9, 0.95)
0227: ALPHA_VALUE = 0.5
0228: LAMBDA_VALUE = 2.0
0229: GAIN_CU = 100.0
0230: LOSS_CU = -50.0
0232: def average(values: Sequence[Fraction]) -> Fraction:
0233: """Arithmetic mean of exact fractions."""
0234: return sum(values, Fraction(0)) / len(values)
0236: def ce_single_prior(p: Fraction) -> Fraction:
0237: """CE in cents of the gamble when red has probability p, under CRRA gamma = 2 (u(W) = -1/W), exactly.
0239: The CE solves -1/CE = E u(W) = -(p/WIN + (1 - p)/LOSS), so CE = 1 / E[1/W]."""
0240: return 1 / (p / WIN_CENTS + (1 - p) / LOSS_CENTS)
0242: def alpha_meu_ce(priors: Sequence[Fraction], tau: Fraction) -> Fraction:
0243: """CE in cents of alpha-MEU: V = tau * min_P E_P u + (1 - tau) * max_P E_P u, then CE = u^{-1}(V).
0245: With u(W) = -1/W and inv(P) = E_P[1/W], V = -(tau * max inv + (1 - tau) * min inv), so CE = 1/(tau * max inv
0246: + (1 - tau) * min inv). tau = 1 is maxmin expected utility."""
0247: invs = [ce_inv(p) for p in priors]
0248: return 1 / (tau * max(invs) + (1 - tau) * min(invs))
0250: def ce_inv(p: Fraction) -> Fraction:
0251: """E[1/W] of the gamble when red has probability p, in 1/cents."""
0252: return p / WIN_CENTS + (1 - p) / LOSS_CENTS
0254: def half_up(value: Fraction) -> int:
0255: """Return an exact fraction as a whole number of cents, half up."""
0256: return math.floor(value + Fraction(1, 2))
0258: def half_up_float(value_cents: float) -> int:
0259: """Return a float number of cents as a whole number, half up; refuse a value within 1e-6 cents of a half cent."""
0260: floor_part = math.floor(value_cents)
0261: if abs(value_cents - floor_part - 0.5) < 1e-6:
0262: raise ValueError("the unrounded CE lies within 1e-6 cents of a half cent; the rounding rule is not applied")
0263: return math.floor(value_cents + 0.5)
0265: def prospect_value(x_cu: float) -> float:
0266: """Prospect value of a change x in CU: x**(1/2) for gains, -LAMBDA * (-x)**(1/2) for losses."""
0267: if x_cu >= 0:
0268: return float(x_cu**ALPHA_VALUE)
0269: return float(-LAMBDA_VALUE * (-x_cu) ** (1.0 / 2.0))
0271: def prospect_inverse(v: float) -> float:
0272: """Closed-form inverse of prospect_value: v**2 for v >= 0, and -(-v / LAMBDA)**2 for v < 0."""
0273: if v >= 0:
0274: return float(v ** (1.0 / ALPHA_VALUE))
0275: return float(-((-v / LAMBDA_VALUE) ** 2))
0277: def prospect_inverse_by_bisection(v: float) -> float:
0278: """The same inverse by 200 halvings of prospect_value over [-1000, 1000] CU, which reaches
0279: floating-point resolution."""
0280: lo, hi = -1000.0, 1000.0
0281: for _ in range(200):
0282: mid = (lo + hi) / 2
0283: if prospect_value(mid) < v:
0284: lo = mid
0285: else:
0286: hi = mid
0287: return (lo + hi) / 2
0289: def ez_value(c0: float, date1: Sequence[tuple[float, float]], psi: float, beta: float) -> float:
0290: """Two-date Epstein-Zin value V0 = [(1 - beta) c0**a + beta * (E[c1**(1 - gamma)])**(a / (1 - gamma))]**(1/a),
0291: with a = 1 - 1/psi, gamma = GAMMA and the terminal value V1 = c1. The sure amount is a one-point distribution."""
0292: a = 1.0 - 1.0 / psi
0293: expectation = sum(p * c1 ** (1.0 - GAMMA) for c1, p in date1)
0294: inner = (1.0 - beta) * c0**a + beta * expectation ** (a / (1.0 - GAMMA))
0295: return float(inner ** (1.0 / a))
0297: def ez_certainty_equivalent(c0: float, date1: Sequence[tuple[float, float]], psi: float, beta: float) -> float:
0298: """The sure date-1 amount c with ez_value(c0, [(c, 1)]) equal to ez_value(c0, date1), by 200 halvings of
0299: a bracket of 17000 cents, which reaches floating-point resolution."""
0300: target = ez_value(c0, date1, psi, beta)
0301: lo, hi = float(LOSS_CENTS - 1000), float(WIN_CENTS + 1000)
0302: for _ in range(200):
0303: mid = (lo + hi) / 2
0304: if ez_value(c0, [(mid, 1.0)], psi, beta) < target:
0305: lo = mid
0306: else:
0307: hi = mid
0308: return (lo + hi) / 2
0310: def gamble_outcomes(p: float) -> list[tuple[float, float]]:
0311: """Final wealth in cents with probabilities: (WIN, p) and (LOSS, 1 - p)."""
0312: return [(float(WIN_CENTS), p), (float(LOSS_CENTS), 1.0 - p)]
0314: def part_a() -> None:
0315: p_bar = average(PRIOR_SET)
0316: print(
0317: f"part A: wealth W0 = {W0_CENTS} cents; red pays +{WIN_CENTS - W0_CENTS} cents, otherwise "
0318: f"{LOSS_CENTS - W0_CENTS} cents"
0319: )
0320: print(f"part A: prior set = red counts 30 to 60 out of {URN_SIZE}; average prior P(red) = {p_bar}")
0321: eu = ce_single_prior(p_bar)
0322: print(f"part A: EU, CRRA gamma = 2, P(red) = 1/2: CE = {float(eu):.4f} cents, whole cents = {half_up(eu)}")
0323: prospect_cu = 0.5 * prospect_value(GAIN_CU) + 0.5 * prospect_value(LOSS_CU)
0324: prospect_wealth = W0_CENTS + 100.0 * prospect_inverse(prospect_cu)
0325: print(
0326: f"part A: prospect value V = {prospect_cu:.6f} (CU to the 1/2 power), CE = {prospect_wealth:.4f} cents, "
0327: f"whole cents = {half_up_float(prospect_wealth)}"
0328: )
0329: gap_inverse = prospect_inverse(prospect_cu) - prospect_inverse_by_bisection(prospect_cu)
0330: print(f"part A: prospect inverse, closed form minus bisection = {gap_inverse:.2e} CU")
0331: ez_cents = ez_certainty_equivalent(float(W0_CENTS), gamble_outcomes(0.5), psi=0.5, beta=0.95)
0332: print(
0333: f"part A: Epstein-Zin, psi = 0.5, beta = 0.95, P(red) = 1/2: CE = {ez_cents:.4f} cents, "
0334: f"whole cents = {half_up_float(ez_cents)}"
0335: )
0336: worst = min(PRIOR_SET, key=ce_single_prior)
0337: maxmin = alpha_meu_ce(PRIOR_SET, Fraction(1))
0338: print(
0339: f"part A: maxmin, tau = 1: worst prior is P(red) = {worst}; CE = {float(maxmin):.4f} cents, "
0340: f"whole cents = {half_up(maxmin)}"
0341: )
0342: mix = alpha_meu_ce(PRIOR_SET, Fraction(1, 2))
0343: print(f"part A: alpha-MEU, tau = 1/2: CE = {float(mix):.4f} cents, whole cents = {half_up(mix)}")
0344: print(f"part A: alpha-MEU at tau = 1/2 equals the EU CE here = {mix == eu}")
0345: print(f"part A: ambiguity aversion holds (maxmin CE <= CE at the average prior) = {maxmin <= eu}")
0347: def part_b() -> None:
0348: eu_exact = ce_single_prior(average(PRIOR_SET))
0349: worst = 0.0
0350: for psi in PSI_VALUES:
0351: for beta in BETA_VALUES:
0352: ez = ez_certainty_equivalent(float(W0_CENTS), gamble_outcomes(0.5), psi, beta)

0359: print(f"part B: largest absolute gap over the six (psi, beta) pairs = {worst:.2e} cents")
0360: print(f"part B: all six gaps below 1e-6 cents = {worst < 1e-6}")

0364: black_known = Fraction(60, URN_SIZE)

0368: return 1 / (p / prize_win + (1 - p) / prize_lose)

0468: Remark 4.2
0469: (why the alpha-MEU row coincides with expected utility here)
0471: For a two-outcome gamble, \(\E_P[1/W] = p/W_1 + (1-p)/W_L\) is affine in \(p\). Let \(p_{\min}\) and \(p_{\max}\) be the smallest and largest priors. Then \(\tfrac{1}{2}\E_{p_{\min}}[1/W] + \tfrac{1}{2}\E_{p_{\max}}[1/W] = \E_{(p_{\min} + p_{\max})/2}[1/W]\). So the alpha-MEU value at \(\tau = 1/2\) is the expected-utility value at the midpoint \((p_{\min} + p_{\max})/2\). It equals expected utility at the average prior \(\bar P\) when that midpoint equals \(\bar P(\text{red})\). Here the extreme priors \(1/3\) and \(2/3\) have midpoint \(1/2\), and the average prior has \(\bar P(\text{red}) = 45/90 = 1/2\), so both coincide.
0473: Maxmin is ambiguity averse here, as Theorem 2.2 guarantees: \(99523.8095 \le 101951.2195\) cents. The risk premium, expected final wealth minus the expected-utility certainty equivalent (not relative to the initial wealth), is \(102500 - 101951.2195 = 548.7805\) cents, with \(102500\) cents the expected final wealth under \(\bar P\). The maxmin certainty equivalent is \(476.1905\) cents below the initial wealth, so the bet is worth less than nothing to that model.

0476: Where the canon breaks
0478: The prior set is a modelling choice. Maxmin depends on the endpoints of the set. With the full set of red counts from 0 to 90, the worst prior for this gamble gives \(P(\text{red}) = 0\), and the certainty equivalent is \(W_L = 95000\) cents. With the set from 30 to 60 it is \(99523.8095\) cents. The numbers of Section 4 are for the set of Example 1.4.
0480: Epstein–Zin adds nothing for a gamble at the last date. Proposition 3.2 makes the Epstein–Zin row equal to the CRRA row for every \(\psi\) and \(\beta\). The certainty equivalent that Proposition 3.2 gives contains neither \(\psi\) nor \(\beta\). Remark 3.3 names the case, a gamble resolved before a later consumption date, where they can enter; this lesson does not compute it.
0482: The magnitudes are parameters, not estimates. The prospect model uses \(\lambda = 2\) and exponents \(1/2\), and the CRRA model uses \(\gamma = 2\). Each is stated for the example. The lesson quotes no published estimate of loss aversion or of any risk-aversion coefficient. Its two cited sources are used for their titles only, and the lesson did not read them.
0484: The alpha-MEU row is one point of a family. The lesson computes \(\tau = 1\) and \(\tau = 1/2\). Its coincidence with expected utility at \(\tau = 1/2\) holds because \(g\) is affine and the midpoint of the extreme priors equals the average prior, both \(1/2\) here (Remark 4.2).

0487: Misconceptions
0489: “A maxmin agent applies one pessimistic prior to every gamble.”
0491: The worst prior depends on the gamble. Over the full set of red counts 0 to 90, the worst prior for a bet on red is the prior with no red balls, and for a bet on black it is the prior with no black balls (Proposition 2.4). The same decision maker evaluates two bets with two different worst priors, so no single prior summarises the rule.
0493: “A prior set with one element is ambiguity averse, because maxmin is a worst-case rule.”
0495: With one prior the worst case is the only case. Proposition 1.3 gives expected utility, and Remark 2.3 notes that the comparison is an equality, so the model is ambiguity neutral.
0497: “Epstein–Zin preferences give a different certainty equivalent from CRRA for every gamble, because they separate risk aversion from the elasticity of substitution.”
0499: For a gamble at the last date the two certainty equivalents are equal for every \(\psi\) and \(\beta\) (Proposition 3.2). Lab 1, part B, prints gaps from \(0.00\) to \(-2.91 \times 10^{-11}\) cents over the six pairs, all below \(10^{-6}\) cents. The gaps are of the size of floating-point rounding in the powers and in the bisection, which runs to floating-point resolution. The lesson's convention fixes the dates, and Remark 3.3 names the case where the convention leaves the answer open.

0508: M1 · Expected utility at one quarter
0510: For the gamble of Section 4, with final wealth \(110000\) cents if red and \(95000\) cents otherwise, compute the expected-utility certainty equivalent under \(P(\text{red}) = 1/4\), for \(\gamma = 2\).
0512: Solution
0514: The CE is \(1/(\tfrac{1}{4}/110000 + \tfrac{3}{4}/95000)\). The inner sum is \(1/440000 + 3/380000 = 85/8360000\), so the CE is \(8360000/85 = 1672000/17 = 98352.94117647\) cents, which is 98352.94 to two decimals. The expected final wealth is \(0.25 \times 110000 + 0.75 \times 95000 = 98750\) cents, and the CE lies below it, as risk aversion requires (Lesson 2).
0516: M2 · Maxmin over two priors
0518: For the prior set \(\{1/4, 3/4\}\) and the same gamble, find the maxmin certainty equivalent in cents.
0520: Solution
0522: Maxmin is the smallest certainty equivalent over the priors, because the CE is increasing in \(p\) (as in the proof of Proposition 2.4). The smaller prior \(1/4\) gives \(98352.94\) cents from Problem M1, and the larger prior \(3/4\) gives \(105822.78\) cents. So the maxmin CE is \(98352.94\) cents.
0524: M3 · Optimistic weighting over the same two priors
0526: For the prior set \(\{1/4, 3/4\}\), compute the alpha-MEU value with \(\tau = 0\), and say which prior it uses.
0528: Solution
0530: With \(\tau = 0\) the formula gives \(\mathrm{CE} = 1/(\min_P \E_P[1/W])\), which is the largest certainty equivalent. It is attained at the prior \(3/4\), and its value is \(105822.78\) cents, from \(1/(\tfrac{3}{4}/110000 + \tfrac{1}{4}/95000)\).
0532: Proof
0534: P1 · The one-element prior set
0536: Prove Proposition 1.3 for every \(\tau \in [0, 1]\), using only Definition 1.2.
0538: Solution
0540: With \(\mathcal{P} = \{P\}\), the minimum and the maximum of \(\E_P u(f)\) over \(\mathcal{P}\) are both \(\E_P u(f)\). Substituting into Definition 1.2 gives \(V_\tau(f) = \tau \E_P u(f) + (1 - \tau)\E_P u(f) = \E_P u(f)\), because the two weights sum to one. The certainty equivalent is then \(u^{-1}(\E_P u(f))\), the expected-utility value.
0542: P2 · Averages of priors do not raise the maxmin value
0544: Prove Theorem 2.2 for the case of two priors \(P_1, P_2\) and a mixture \(\theta P_1 + (1 - \theta) P_2\), with \(\theta \in [0, 1]\), in place of the uniform average.
0546: Solution
0548: The mixture gives \(\E_{\theta P_1 + (1 - \theta)P_2} u(f) = \theta \E_{P_1} u(f) + (1 - \theta)\E_{P_2} u(f)\), a weighted average of two numbers with nonnegative weights summing to one. A weighted average of two numbers with nonnegative weights summing to one is at least their minimum \(m\). So the mixture's expected utility is at least \(m\), and applying the strictly increasing \(u^{-1}\) gives \(\mathrm{CE}_{\text{maxmin}}(f) \le u^{-1}(\text{mixture value})\), as in the proof of Theorem 2.2.
0550: P3 · Alpha-MEU at the midpoint
0552: Let \(\mathcal{P} = \{p_{\min}, p_{\max}\}\) for a two-outcome gamble. Show that the alpha-MEU certainty equivalent at \(\tau = 1/2\) equals the expected-utility certainty equivalent at \((p_{\min} + p_{\max})/2\), for \(u(W) = -1/W\).
0554: Solution
0556: Write \(g(p) = \E_p[1/W] = p/W_1 + (1-p)/W_L\), which is affine in \(p\). With \(u(W) = -1/W\), the alpha-MEU certainty equivalent is \(1/(\tau \max_P g(P) + (1-\tau)\min_P g(P))\). At \(\tau = 1/2\) the denominator is \(\tfrac{1}{2}g(p_{\min}) + \tfrac{1}{2}g(p_{\max})\) (since \(W_1 > W_L\) makes \(g\) decreasing, \(\max_P g = g(p_{\min})\) and \(\min_P g = g(p_{\max})\)). Affinity gives \(\tfrac{1}{2}g(p_{\min}) + \tfrac{1}{2}g(p_{\max}) = g\bigl((p_{\min} + p_{\max})/2\bigr)\). So the CE equals \(1/g\) at the midpoint, which is the expected-utility CE there.

0584: Research
0586: R1 · The step that fails for an earlier-resolving gamble
0588: Name the step in the proof of Proposition 3.2 that fails when the gamble resolves at date 1 and changes date-2 consumption, and say on what the certainty equivalent then depends.
0590: Solution
0592: The proof uses that the date-1 value is the consumption \(c_1\) itself, so the expectation is over \(c_1^{1-\gamma}\). That step fails when a later consumption \(c_2\) enters: the date-1 value becomes \(Z_1 = [(1-\beta)c_1^{a} + \beta c_2^{a}]^{1/a}\), which is random when \(c_1\) is random, so the expectation must be taken over \(Z_1^{1-\gamma}\). Whether the certainty equivalent then depends on \(\psi\) and \(\beta\) is the untested hypothesis of Remark 3.3; this solution does not compute it.
0594: R2 · A narrower prior set
0596: Replace the full set of red counts 0 to 90 by the set 30 to 60 (Example 1.4) in the two-urn check. For each colour, say whether maxmin prefers the known urn, is indifferent, or prefers the ambiguous urn.
0598: Solution
0600: Under the set 30 to 60, the red probability lies in \([1/3, 2/3]\), so the worst prior for red is \(1/3\), and the ambiguous red CE is \(103125\) cents. The known red CE is also \(103125\) cents, so maxmin is indifferent. For black the probability lies in \([1/3, 2/3]\) as well, so the worst prior for black is \(1/3\), giving \(103125\) cents. The known black CE is \(106451.6129\) cents, which is higher, so maxmin prefers the known urn for black and is indifferent for red.
0602: R3 · Whether the ranking survives a change of utility
0604: Suppose the CRRA utility is replaced by \(u(W) = -e^{-\kappa W}\) for some \(\kappa > 0\), with the same prior set. Does Theorem 2.2 still hold? State the assumption it uses.
0606: Solution
0608: Yes. Theorem 2.2 uses \(u\) only through A2, that \(u\) is strictly increasing, so the inequality \(\mathrm{CE}_{\text{maxmin}}(f) \le \mathrm{CE}_{\bar P}(f)\) holds for \(u(W) = -e^{-\kappa W}\) for any \(\kappa > 0\), because \(u\) is strictly increasing there. The numbers of this lesson change, but the inequality does not. The proof does not depend on the form of \(u\), which is the point of stating the assumption.
