Proof For a real \(x\), \((t - x)^{+} = \int_{-\infty}^{t} \indic\{x \le s\}\, ds\), because the set of \(s \le t\) with \(x \le s\) is the interval \([x, t]\), which has length \((t - x)^{+}\), or is empty when \(x > t\). Definition 1.4 (the test utilities on S) A function \(u : S \to \R\) is nondecreasing when \(u(s_{j}) \le u(s_{j+1})\) for every \(j\). It is concave on S when its chord slopes \(\sigma_{j} = \big(u(s_{j+1}) - u(s_{j})\big)/(s_{j+1} - s_{j})\), for \(j = 1, \dots, m-1\), never increase: \(\sigma_{1} \ge \sigma_{2} \ge \dots \ge \sigma_{m-1}\). Both notions use only the values of \(u\) on \(S\), and the expected utility of a lottery on \(S\) is \(\E u(X) = \sum_{j} \Prob(X = s_{j}) u(s_{j})\). Theorem 1.5 (first-order dominance on a finite support) Assume A1. Then \(F_{X}(t) \le F_{Y}(t)\) for every real \(t\) if and only if \(\E u(X) \ge \E u(Y)\) for every nondecreasing \(u : S \to \R\). Proof Only if. Let \(u\) be nondecreasing on \(S\). Put \(d_{j} = u(s_{j}) - u(s_{j-1}) \ge 0\) for \(j = 2, \dots, m\). Taking expectations, \(\E u(X) = u(s_{1}) + \sum_{j=2}^{m} d_{j} \Prob(X \ge s_{j})\). Because \(X\) takes values in \(S\) and no point of \(S\) lies strictly between \(s_{j-1}\) and \(s_{j}\), \(\{X \ge s_{j}\} = \{X > s_{j-1}\}\), so \(\Prob(X \ge s_{j}) = 1 - F_{X}(s_{j-1})\). By Lemma 1.2 this says \(\E(t - X)^{+} \le \E(t - Y)^{+}\) for every \(t\), so \(X\) has the smaller expected shortfall below every level. Lemma 2.2 (the integrated test needs only the support points) Under A1 and A2, \(I_{X}(t) \le I_{Y}(t)\) for every real \(t\) if and only if it holds for every \(s \in S\). Proof Let \(D(t) = I_{Y}(t) - I_{X}(t)\). By Lemma 1.2, \(D(t) = \E(t - Y)^{+} - \E(t - X)^{+}\). Between two consecutive points of \(S\), each \((t - x)^{+}\) is an affine function of \(t\), so \(D\) is affine on each interval \([s_{j}, s_{j+1}]\). For \(t \le s_{1}\), \(D(t) = 0\), and for \(t \ge s_{m}\), \((t - X)^{+} = t - X\) and \(D(t) = (t - \E Y) - (t - \E X) = 0\) by A2. So if \(D \ge 0\) on \(S\), then on each interval \(D\) is an affine function that is nonnegative at both ends, hence nonnegative throughout, and \(D \ge 0\) on \(\R\). \(\blacksquare\) Theorem 2.3 (second-order dominance on a finite support) Assume A1 and A2. Then \(I_{X}(t) \le I_{Y}(t)\) for every real \(t\) if and only if \(\E u(X) \ge \E u(Y)\) for every nondecreasing concave \(u : S \to \R\) (Definition 1.4). Proof If. Fix \(t\) and let \(u_{t}(s) = \min(s - t, 0)\) on \(S\). It is nondecreasing, and its chord slopes are \(1\) on the intervals left of \(t\), \(0\) on the intervals right of \(t\), and a value in \([0, 1]\) on the interval that contains \(t\), so they never increase and \(u_{t}\) is concave on \(S\). Since \(\min(x - t, 0) = -(t - x)^{+}\), Lemma 1.2 gives \(\E u_{t}(X) = -I_{X}(t)\) and \(\E u_{t}(Y) = -I_{Y}(t)\). So \(\E u_{t}(X) \ge \E u_{t}(Y)\) says \(I_{X}(t) \le I_{Y}(t)\). Only if. Let \(u\) be concave on \(S\) with chord slopes \(\sigma_{1} \ge \dots \ge \sigma_{m-1}\). Let \(L\) be the piecewise linear function that equals \(u\) at each \(s_{j}\) and is affine on each \([s_{j}, s_{j+1}]\). Its slope on \((s_{k}, s_{k+1})\) is \(\sigma_{k}\), so for \(s \in [s_{1}, s_{m}]\), \[ L(s) = u(s_{1}) + \sigma_{1}(s - s_{1}) + \sum_{j=2}^{m-1} (\sigma_{j} - \sigma_{j-1})\,(s - s_{j})^{+}. \] Write \((s - s_{j})^{+} = (s - s_{j}) - \min(s - s_{j}, 0)\), and put \(c_{j} = \sigma_{j-1} - \sigma_{j} \ge 0\), which is nonnegative by concavity. Then \(L(s) = b_{0} + b_{1} s + \sum_{j=2}^{m-1} c_{j} \min(s - s_{j}, 0)\) for constants \(b_{0}\) and \(b_{1}\). Since \(X\) and \(Y\) take values in \(S\), \(\E u(X) = \E L(X)\) and \(\E u(Y) = \E L(Y)\). By the expression of \(\E \min(x - t, 0)\) in the "if" part, \[ \E u(X) - \E u(Y) = b_{1}(\E X - \E Y) +\sum_{j=2}^{m-1} c_{j}\big(I_{Y}(s_{j}) - I_{X}(s_{j})\big). \] The first term is \(0\) by A2, and each \(c_{j} \ge 0\) with \(I_{Y}(s_{j}) - I_{X}(s_{j}) \ge 0\) by hypothesis. So \(\E u(X) \ge \E u(Y)\). \(\blacksquare\) Remark 2.4 (what the proof uses) The "only if" proof uses concavity through \(c_{j} \ge 0\) and A2 through the vanishing of the affine term. It does not use monotonicity. So the same conclusion holds for every concave \(u\) on \(S\). The statement keeps nondecreasing utilities because the "if" direction uses the nondecreasing witnesses \(u_{t}\). Research problem R3 shows where monotonicity enters when the means are not equal. Example 2.5 (a mean-preserving spread) Let \(X\) put probability \(1/2\) on 2000 cents and \(1/2\) on 4000 cents, and let \(Y\) put probability \(1/4\) on 1000, \(1/2\) on 3000 and \(1/4\) on 5000 cents. Both means are 3000 cents, so A2 holds. On \(S = \{1000, 2000, 3000, 4000, 5000\}\), the integrated distribution functions are computed from Lemma 1.2 as sums of probability times shortfall. For \(X\): \(I_{X}(1000) = 0\), \(I_{X}(2000) = 0\), \(I_{X}(3000) = \tfrac12 \cdot 1000 = 500\), \(I_{X}(4000) = \tfrac12 \cdot 2000 = 1000\), and \(I_{X}(5000) = \tfrac12 \cdot 3000 + \tfrac12 \cdot 1000 = 2000\). For \(Y\): \(I_{Y}(1000) = 0\), \(I_{Y}(2000) = \tfrac14 \cdot 1000 = 250\), \(I_{Y}(3000) = \tfrac14 \cdot 2000 = 500\), \(I_{Y}(4000) = \tfrac14 \cdot 3000 + \tfrac12 \cdot 1000 = 1250\), and \(I_{Y}(5000) = \tfrac14 \cdot 4000 + \tfrac12 \cdot 2000 = 2000\). So \(I_{X} \le I_{Y}\) at every support point, and by Theorem 2.3 and Lemma 2.2, \(X\) dominates \(Y\) in the second order. The first-order test fails in both directions. At 2000 cents, \(F_{X} = 1/2 > 1/4 = F_{Y}\), so \(F_{X} \le F_{Y}\) fails. At 3000 cents, \(F_{Y} = 3/4 > 1/2 = F_{X}\), so \(F_{Y} \le F_{X}\) fails. The pair is ranked in the second order and not in the first. Example 2.6 (equal means and no first-order ranking) Let \(X\) put probability \(1/2\) on 1000 cents and \(1/2\) on 5000 cents, and let \(Y\) put probability 1 on 3000 cents. Both means are 3000 cents. At 1000 cents, \(F_{X} = 1/2 > 0 = F_{Y}\), and at 3000 cents, \(F_{Y} = 1 > 1/2 = F_{X}\). So neither \(F_{X} \le F_{Y}\) nor \(F_{Y} \le F_{X}\) holds, and there is no first-order ranking. The integrated distribution functions give \(I_{Y}(t) = (t - 3000)^{+} \le I_{X}(t)\) at every support point, so \(Y\) dominates \(X\) in the second order. Research R1 · The converse of first-order dominance Show that the integrated ordering of Proposition 1.8 does not imply the first-order ordering, using Example 2.5. Solution In Example 2.5, \(I_{X}(t) \le I_{Y}(t)\) at every support point, so the integrated ordering holds. But the first-order ordering fails, because \(F_{X}(2000) = 1/2 > 1/4 = F_{Y}(2000)\). R2 · Where the equal-means hypothesis enters Explain in one paragraph why Theorem 2.3 needs A2 in its "only if" direction, and identify the term of the proof that A2 removes. Solution The proof writes \(\E u(X) - \E u(Y)\) as \(b_{1}(\E X - \E Y)\) plus a sum of nonnegative terms weighted by the integrated distributions. The coefficient \(b_{1}\) is the slope of the interpolant on the last interval, and the term \(b_{1}(\E X - \E Y)\) is nonzero in general when the means differ. A2 removes that term, so the sum of nonnegative terms alone decides the ordering. R3 · Unequal means under a nondecreasing concave utility Suppose \(I_{X}(t) \le I_{Y}(t)\) for every \(t\) but A2 fails, and \(u\) is nondecreasing and concave on \(S\). Show that \(\E u(X) \ge \E u(Y)\) still holds. Solution Use the representation of the "only if" proof. The slope of the interpolant on the last interval is \(b_{1} = \sigma_{m-1} \ge 0\), because \(u\) is nondecreasing. At \(t = s_{m}\), every outcome is at most \(t\), so \(I_{X}(s_{m}) = s_{m} - \E X\) and \(I_{Y}(s_{m}) = s_{m} - \E Y\). The hypothesis \(I_{X}(s_{m}) \le I_{Y}(s_{m})\) then gives \(\E X \ge \E Y\), so the affine term \(b_{1}(\E X - \E Y)\) is nonnegative. The sum of nonnegative terms is nonnegative as before, so \(\E u(X) \ge \E u(Y)\).
