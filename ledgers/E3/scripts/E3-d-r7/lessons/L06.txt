A reference-dependent model values outcomes as changes from a reference point (Definition 1.1), and it can weight losses more heavily than equal gains. Example 2.3 shows that a gamble with a positive expected value can have a negative value under such a model. This lesson defines the value function and the prospect value, proves the shape of the value function when the powers are below one, computes the threshold at which a gamble's value changes sign, and states what is not settled about the size of the asymmetry. 1 Reference dependence and the value function Definition 1.1 (reference point, gains and losses) Let \(r\) be a reference point . An outcome \(x\) is a gain if \(x > r\) and a loss if \(x Definition 1.2 (the value function) Let \(\alpha > 0\), \(\delta > 0\) and \(\lambda > 0\). The value function is \[v(x) = x^{\alpha} \ \text{ for } x \ge 0, \qquad v(x) = -\lambda\,(-x)^{\delta} \ \text{ for } x Here \(\alpha\) is the curvature parameter for gains, \(\delta\) the curvature parameter for losses, and \(\lambda\) the coefficient that multiplies the loss term. The function has \(v(0) = 0\). Definition 1.3 (prospect value of a lottery) Let a lottery have finitely many outcomes \(x_i\) with probabilities \(p_i > 0\), \(\sum_i p_i = 1\). The prospect value is \(W := \sum_i p_i\, v(x_i)\). It is the value part of prospect theory as this unit uses the term: outcomes are valued relative to the reference point, and the probabilities are used as they are. The condition \(\lambda > 1\) that defines loss aversion in Definition 1.6 is a parameter restriction. The proofs in Sections 1 and 2 use only \(\lambda > 0\): Proposition 1.4 needs \(\lambda > 0\), and Propositions 2.1 and 2.2 hold for every \(\lambda > 0\). The threshold \(\lambda^{\ast}\) of Example 2.3 is 5/3, which is above 1, but that fact belongs to the example's numbers and not to the theory. Remark 3.2 (the reference point and the sign of a gamble) Suppose the reference point is the expected value \(\mathrm{EV}(G)\) instead of 0, with \(\alpha = \delta\). The gain relative to that point is \(g - \mathrm{EV}(G)\), and the loss has magnitude \(\ell + \mathrm{EV}(G)\). The value is \(p\,(g - \mathrm{EV})^{\alpha} - (1-p)\,\lambda\,(\ell + \mathrm{EV})^{\alpha}\), which is zero at \(\lambda_R := \dfrac{p\,(g-\mathrm{EV})^{\alpha}}{(1-p)\,(\ell+\mathrm{EV})^{\alpha}}\), not at \(\lambda^{\ast}\) in general. Two cases are computed. For \(\alpha = 1\), \(p(g-\mathrm{EV}) - (1-p)(\ell+\mathrm{EV}) = \mathrm{EV} - \mathrm{EV} = 0\), so \(\lambda_R = 1\). For the gamble of Example 2.3, \(g - \mathrm{EV} = \ell + \mathrm{EV} = 800\) cents and \(p = 1/2\), so \(\lambda_R = 1\) for every \(\alpha = \delta\), and the value is \(\tfrac12\cdot 800^{\alpha}(1-\lambda)\). For \(p = 1/3\), \(g = 1000\), \(\ell = 300\) and \(\alpha = \delta = 1/2\), \(\mathrm{EV} = 400/3\), \((g-\mathrm{EV})/(\ell+\mathrm{EV}) = 2\), and \(\lambda_R = \tfrac12\sqrt2 \approx 0.7071\), so the threshold is not 1. The lesson uses the reference point of this remark only here, in Section 4, in Problem R2 and in retrieval quiz item 7. 4 Where the canon breaks The value function of Definition 1.2 is a model, and four of its choices are open. Each is named here with its consequence. The size of loss aversion is not settled. Whether \(\lambda\) takes one value across people, stakes and settings is not settled by anything on this page. This lesson cites no source for any magnitude of \(\lambda\), so it states none. Any claim about a typical \(\lambda\) needs a source that this page does not give. The reference point is a choice. Remark 3.2 shows that a different reference point changes the sign threshold. For the gamble of Example 2.3 it moves the threshold from \(\lambda^{\ast} = 5/3\) to 1, and in general the threshold is the formula \(\lambda_R\) of Remark 3.2. The page takes 0 and does not argue that 0 is the right reference point. Evaluation of bundles. Remark 2.5 shows that the sign of a bundle can differ from the sign of each copy. Whether people evaluate gambles alone or together is an empirical question. This lesson makes no claim about it. Probability weighting is absent. Definition 1.3 uses the probabilities \(p_i\) directly. Lesson L07 adds a weighting of probabilities, and the results here do not carry over to that version without a new argument. 5 Misconceptions “Loss aversion means that a gamble with a positive expected value is always rejected.” Proposition 2.1 and Example 2.3 show that the prospect value is negative only above the threshold \(\lambda^{\ast}\).
