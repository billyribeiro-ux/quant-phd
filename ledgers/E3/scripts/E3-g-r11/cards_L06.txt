### E3-c098 | L06 | grade=None | basis=None
F: What is a gain and a loss relative to the reference point?
B: An outcome x is a gain if x > r and a loss if x < r. Here r = 0, so outcomes are changes in wealth in cents (Definition 1.1).
### E3-c099 | L06 | grade=None | basis=None
F: What is the value function with powers alpha and delta and coefficient lambda?
B: v(x) = x^alpha for x >= 0 and v(x) = -lambda (-x)^delta for x < 0, with alpha, delta and lambda all positive, and v(0) = 0 (Definition 1.2).
### E3-c100 | L06 | grade=None | basis=None
F: What is the prospect value of a lottery?
B: W = sum of p_i v(x_i) over the outcomes, with p_i > 0 summing to 1. Probabilities enter unweighted; probability weighting comes in Lesson L07 (Definition 1.3).
### E3-c101 | L06 | grade=T | basis=None
F: What shape does the value function have when alpha and delta lie in (0, 1)?
B: It is strictly increasing on R, strictly concave on [0, infinity) and strictly convex on (-infinity, 0], for lambda > 0 (Proposition 1.4).
### E3-c102 | L06 | grade=T | basis=None
F: What is |v(-x)|/v(x) when alpha = delta?
B: lambda, for every x > 0 (Remark 1.5).
### E3-c103 | L06 | grade=None | basis=None
F: What is loss aversion (Definition 1.6)?
B: A loss has a larger absolute value than a gain of equal magnitude. In the value function with alpha = delta this is the condition lambda > 1 (Definition 1.6).
### E3-c104 | L06 | grade=T | basis=None
F: Where does the prospect value of the two-outcome gamble change sign when alpha = delta = 1?
B: Under alpha = delta = 1, 0 < p < 1, g > 0 and l > 0 (Proposition 2.1), with p the probability of the prize g and l the loss size: lambda* = p g/((1 - p) l). W(lambda) = p g - (1 - p) lambda l is strictly decreasing in lambda, equals the expected value at lambda = 1, is positive below lambda* and negative above it.
### E3-c105 | L06 | grade=T | basis=None
F: What is the sign threshold with powers?
B: For 0 < p < 1, g > 0, l > 0 and alpha, delta, lambda > 0, the sign threshold is lambda* = p g^alpha/((1 - p) l^delta). The value W = p g^alpha - (1 - p) lambda l^delta is zero at lambda*, positive below it and negative above it (Proposition 2.2).
### E3-c106 | L06 | grade=C | basis=Lab 1, exact fractions on one gamble; Example 2.3

### E3-c107 | L06 | grade=T | basis=None
F: How does the sign of the prospect value relate to the certainty equivalent?
B: They have the same sign, for every alpha, delta and lambda > 0. The certainty equivalent under v is positive exactly when W is positive, because v is continuous, strictly increasing and v(0) = 0 (Remark 2.4).
### E3-c108 | L06 | grade=T | basis=None

### E3-c109 | L06 | grade=None | basis=None

### E3-c110 | L06 | grade=T | basis=None
