52: A trader who stops after a loss, or an algorithm that stops when a signal first appears, chooses a time that depends on what has already happened. Lesson L10 asks whether a martingale keeps its expected value under such a choice. The answer depends on which choices are allowed, so this lesson first fixes the class of allowed times, the stopping times of Definition 9.1. The lesson proves that this class is closed under minimum, maximum and shift (§3), and it shows with a lab that a rule which reads one step ahead is excluded.
54: 1Random times and what is known at each time
56: Let \((\Omega,\mathcal F,\Prob)\) be a probability space (L02), and let \((\mathcal F_k)_{k\ge 0}\) be a filtration (L08; L08 defines filtrations over a finite horizon, and here the index runs over all \(k\ge 0\) with the same definition), so that \(\mathcal F_0\subseteq \mathcal F_1\subseteq\cdots\subseteq\mathcal F\). The event \(A\in\mathcal F_k\) is the set of outcomes for which the information available at time \(k\) settles whether \(A\) has occurred. A random time is a function \(\tau:\Omega\to\{0,1,2,\ldots\}\cup\{\infty\}\), so \(\tau(\omega)\) is the time at which the path \(\omega\) reaches the event of interest, with \(\infty\) meaning never.
59: Definition 9.1 (stopping time)
60: A random time \(\tau\) is a stopping time if \(\{\tau\le k\}\in\mathcal F_k\) for every whole number \(k\ge 0\). In words, by time \(k\) the information in \(\mathcal F_k\) settles whether \(\tau\) has already happened.
64: Remark 9.2 (the event that the time is exactly k)
65: The definition may equivalently require \(\{\tau=k\}\in\mathcal F_k\) for every \(k\). Given that, \(\{\tau\le k\}=\bigcup_{j\le k}\{\tau=j\}\) is a finite union of sets in \(\mathcal F_j\subseteq\mathcal F_k\), so it lies in \(\mathcal F_k\). Conversely, Lemma 9.7 shows that a stopping time has \(\{\tau=k\}\in\mathcal F_k\). The two forms are therefore equivalent, and the proofs below use both.
69: Example 9.3 (a fixed time)
70: For a whole number \(n\ge 0\), the constant random time \(\tau\equiv n\) is a stopping time. For \(k\ge n\), \(\{\tau\le k\}=\Omega\in\mathcal F_k\). For \(k<n\), \(\{\tau\le k\}=\emptyset\in\mathcal F_k\). Both sets lie in every \(\sigma\)-algebra, so the definition holds at every \(k\).
73: 2Hitting times of an adapted process
75: The most common stopping time is the first time a process enters a set. Here a process \(X=(X_k)_{k\ge 0}\) is a sequence of random variables, and it is adapted to the filtration when each \(X_k\) is known at time \(k\): for every whole number \(b\), the event \(\{X_k=b\}\) lies in \(\mathcal F_k\). This is the event form of the adaptedness in L08, Definition 1.1, written for integer values.
78: Example 9.4 (the fair walk and its natural filtration)
79: Let \(X_1,X_2,\ldots\) be independent steps, each equal to \(+1\) or \(-1\) with probability \(1/2\). Let \(S_0=0\) and \(S_k=X_1+\cdots+X_k\). The natural filtration \(\mathcal F_k=\sigma(X_1,\ldots,X_k)\) is the one L08 uses for the fair walk. The process \(S\) is adapted to it, because \(S_k\) is a function of \(X_1,\ldots,X_k\). Let \(\tau\) be the first time the walk equals \(+1\), with \(\tau=\infty\) if it never does. Proposition 9.5 shows that \(\tau\) is a stopping time.
83: Proposition 9.5 (hitting times are stopping times)
85: \((\Omega,\mathcal F,\Prob)\) is a probability space, and \((\mathcal F_k)_{k\ge 0}\) is a filtration.
86: \(Y=(Y_k)_{k\ge 0}\) is an integer-valued process adapted to \((\mathcal F_k)\), so \(\{Y_k=b\}\in\mathcal F_k\) for every whole number \(k\ge 0\) and every integer \(b\).
87: \(B\) is a set of integers, and \(\tau_B=\inf\{k\ge 0: Y_k\in B\}\), with \(\inf\emptyset=\infty\).
89: Then \(\tau_B\) is a stopping time.
93: Proof
94: Fix \(k\ge 0\). The process reaches \(B\) by time \(k\) exactly when \(Y_j\in B\) for some \(j\le k\), so \(\{\tau_B\le k\}=\bigcup_{j=0}^{k}\{Y_j\in B\}\). Each set \(\{Y_j\in B\}\) is the countable union \(\bigcup_{b\in B}\{Y_j=b\}\) (hypothesis 2 and the fact that \(B\) is a set of integers). Each \(\{Y_j=b\}\) lies in \(\mathcal F_j\), and \(\mathcal F_j\subseteq\mathcal F_k\) because \(j\le k\) and the filtration increases. So each \(\{Y_j\in B\}\) lies in \(\mathcal F_k\), and so does the finite union \(\{\tau_B\le k\}\). Since \(k\) was arbitrary, \(\tau_B\) is a stopping time.
97: For the fair walk, Proposition 9.5 with \(B=\{1\}\), applied with \(Y=S\), shows that the first time \(S\) equals \(+1\) is a stopping time for the natural filtration. Lab 1 checks the definition on every path of an 8-step walk, and it also tests a rule that the definition excludes.
100: Lab 1 · Stopping times for the fair walk, checked on all 256 paths
101: The lab enumerates the \(2^8=256\) step sequences of an 8-step fair walk, each with probability \(1/256\), and computes every probability as an exact fraction. Part A prints, for each \(k\) from 0 to 8, the number of paths on which the walk has reached \(+1\) by time \(k\), and checks that this event depends only on the first \(k\) steps. Part B runs the same check on a rule that reads step \(k+1\) at time \(k\). Proposition 9.5 predicts that Part A passes at every \(k\), and the definition predicts that Part B fails. Part C checks that the first-hit probabilities add up to the probability of reaching \(+1\) by time 8.

104: The sample space is the set of all 2**N sequences of +1 and -1 steps, N = 8, each sequence with probability
105: 1/256. Every probability is an exact fractions.Fraction. Steps are X_1, ..., X_N and S_k = X_1 + ... + X_k.

109: event {tau <= k} depends only on the first k steps. On a finite space an event is determined by the first k steps
110: exactly when its indicator is the same for every two paths that agree on those steps.
112: Part B: a rule that reads one step ahead, tau_ahead = the first k from 0 to N-1 with step k+1 equal to +1. The
113: same test is run on {tau_ahead <= k}, and it fails at k = 0, because that event depends on step 1.

226: 3Closure under minimum, maximum and shift
229: Proposition 9.6 (closure properties)
231: \(\tau\) and \(\sigma\) are stopping times for the same filtration \((\mathcal F_k)\) on the probability space \((\Omega,\mathcal F,\Prob)\).
232: Time is measured in whole numbers, and \(\infty+1=\infty\), \(\min(\tau,\infty)=\tau\).
234: Then \(\tau\wedge\sigma=\min(\tau,\sigma)\), \(\tau\vee\sigma=\max(\tau,\sigma)\) and \(\tau+1\) are stopping times.
238: Proof
239: Fix \(k\ge 0\). An outcome has \(\min(\tau,\sigma)\le k\) exactly when \(\tau\le k\) or \(\sigma\le k\), so \(\{\min(\tau,\sigma)\le k\}=\{\tau\le k\}\cup\{\sigma\le k\}\). Each set on the right lies in \(\mathcal F_k\), and \(\mathcal F_k\) is closed under finite unions, so the left side lies in \(\mathcal F_k\). Next, \(\max(\tau,\sigma)\le k\) exactly when both \(\tau\le k\) and \(\sigma\le k\), so \(\{\max(\tau,\sigma)\le k\}=\{\tau\le k\}\cap\{\sigma\le k\}\in\mathcal F_k\), because \(\mathcal F_k\) is closed under finite intersections. For the shift, \(\{\tau+1\le 0\}=\emptyset\in\mathcal F_0\). For \(k\ge 1\), \(\tau+1\le k\) exactly when \(\tau\le k-1\), so \(\{\tau+1\le k\}=\{\tau\le k-1\}\in\mathcal F_{k-1}\subseteq\mathcal F_k\). In each case the event lies in \(\mathcal F_k\), and \(k\) was arbitrary.
242: Proposition 9.6 with \(\sigma\equiv N\), a constant time, which is a stopping time by Example 9.3, shows that \(\tau\wedge N\) is a stopping time for every whole number \(N\ge 0\).
245: Lemma 9.7 (events about the time itself)
247: \((\Omega,\mathcal F,\Prob)\) is a probability space, and \((\mathcal F_k)_{k\ge 0}\) is a filtration on it.
248: \(\tau\) is a stopping time for \((\mathcal F_k)\), and \(k\ge 0\) is a whole number.
250: Then \(\{\tau>k\}\in\mathcal F_k\) and \(\{\tau=k\}\in\mathcal F_k\).
254: Proof
255: The complement of \(\{\tau\le k\}\) is \(\{\tau>k\}\). Since \(\{\tau\le k\}\in\mathcal F_k\) and \(\mathcal F_k\) is closed under complements, \(\{\tau>k\}\in\mathcal F_k\). For the second claim, \(\{\tau=k\}=\{\tau\le k\}\setminus\{\tau\le k-1\}\) when \(k\ge 1\), and \(\{\tau=0\}=\{\tau\le 0\}\) when \(k=0\). The set \(\{\tau\le k-1\}\) lies in \(\mathcal F_{k-1}\subseteq\mathcal F_k\), so both sets in the difference lie in \(\mathcal F_k\), and so does the difference.
259: 4Where the canon breaks
261: A rule that reads the future is not a stopping time. Part B of Lab 1 tests the rule "stop at the step before the first \(+1\)". At time \(k\) it needs step \(k+1\), which is not known at time \(k\). The check fails at every \(k\) from 0 to 7.
262: A stopping time depends on the filtration. Take the first time \(\tau\) that the fair walk equals \(+1\), and the trivial filtration \(\mathcal F_k=\{\emptyset,\Omega\}\) for every \(k\). Then \(\{\tau\le 1\}=\{X_1=1\}\) is neither \(\emptyset\) nor \(\Omega\), so \(\tau\) is not a stopping time for that filtration, though it is one for the natural filtration of Example 9.4.
263: A stopping time need not be bounded. The rule "stop at the first \(+1\)" has \(\tau=\infty\) on the path that never reaches \(+1\). No single \(N\) satisfies \(\tau\le N\) on every path. L10 needs this boundedness, and the closure in Proposition 9.6 does not supply it.
268: 5Misconceptions
271: “Any time that depends on the whole path is a stopping time, because it is a function of the outcome.”
272: Being a function of the outcome is not enough. Definition 9.1 asks that \(\{\tau\le k\}\in\mathcal F_k\) at each \(k\), which fixes what may be used at time \(k\). Part B of Lab 1 gives a rule that is a perfectly good function of the path and fails the test at each \(k\) from 0 to 7, because it uses step \(k+1\) at time \(k\).
275: “The first hitting time of a level is a stopping time whatever the filtration.”
276: Proposition 9.5 needs the process to be adapted to the filtration. Example 9.4 uses the natural filtration. With the trivial filtration, the first time the walk equals \(+1\) fails the definition at \(k=1\), because \(\{\tau\le 1\}=\{X_1=1\}\) is not in \(\{\emptyset,\Omega\}\).
279: “A stopping time that is finite on each path is bounded, so it can be used wherever a bounded time can.”
280: Finiteness on each path gives no common bound. For the first time the walk equals \(+1\), the paths with \(m\) steps of \(-1\) followed by \(m+1\) steps of \(+1\) give \(\tau=2m+1\), which is finite on each such path. These values have no upper bound as \(m\) grows. L10 requires \(\tau\le N\) for one fixed \(N\), which is a stronger condition than finiteness.

292: M1 · The hitting time of +1 for a 3-step walk
293: For a fair walk with steps \(X_1,X_2,X_3\), let \(\tau\) be the first \(k\le 3\) with \(S_k=+1\), and \(\tau=\infty\) otherwise. Find \(\Prob(\tau=1)\), \(\Prob(\tau=3)\), and \(\Prob(\tau\le 2)\).
294: Solution
295: Four of the eight paths have \(X_1=+1\), so \(S_1=+1\) and \(\tau=1\). Thus \(\Prob(\tau=1)=1/2\). If \(X_1=-1\), then \(S_2\in\{-2,0\}\), and \(S_2=+1\) is impossible, so \(\tau\ne 2\). Hence \(\Prob(\tau\le 2)=1/2\). The only path with \(\tau=3\) is \((-1,+1,+1)\), which gives \(S_1=-1\), \(S_2=0\), \(S_3=+1\). So \(\Prob(\tau=3)=1/8\). Check: \(\Prob(\tau\le 3)=5/8=0.625\), which matches the \(k=3\) row of Part A of Lab 1, where 160 of 256 paths have reached \(+1\) by time 3. The same value holds for horizon 4, because \(S_4\) is even, so no path first reaches \(+1\) at time 4 and \(\Prob(\tau\le 4)=\Prob(\tau\le 3)\).
299: M2 · A constant time is a stopping time
300: Show that the constant random time \(\tau\equiv 5\) is a stopping time for any filtration \((\mathcal F_k)\).
301: Solution
302: Example 9.3 applies with \(n=5\). For \(k\ge 5\), \(\{\tau\le k\}=\Omega\) and \(\Omega\in\mathcal F_k\). For \(k\le 4\), \(\{\tau\le k\}=\emptyset\) and \(\emptyset\in\mathcal F_k\). The two cases cover every \(k\ge 0\), so \(\tau\) satisfies Definition 9.1.

317: P1 · The shift in Proposition 9.6
318: Prove that \(\tau+1\) is a stopping time when \(\tau\) is one, including the case \(\tau=\infty\).
319: Solution
320: Fix \(k\ge 0\). If \(k=0\), \(\{\tau+1\le 0\}\) is empty, since \(\tau+1\ge 1\), so the event is in \(\mathcal F_0\). If \(k\ge 1\), an outcome has \(\tau+1\le k\) exactly when \(\tau\le k-1\), so \(\{\tau+1\le k\}=\{\tau\le k-1\}\). The set \(\{\tau\le k-1\}\) lies in \(\mathcal F_{k-1}\), which is contained in \(\mathcal F_k\) because the filtration increases. For \(\tau=\infty\), both \(\tau+1\le k\) and \(\tau\le k-1\) are false, so the identity covers that case too.
324: P2 · The first-passage event of a hitting time
325: Let \(\tau\) be the hitting time of Proposition 9.5 with \(B=\{1\}\), applied with \(Y=S\). Show that \(\{\tau=k\}=\{S_k=1\}\cap\bigcap_{j<k}\{S_j\ne 1\}\), and deduce that \(\{\tau=k\}\in\mathcal F_k\).
326: Solution
327: The first time the walk equals \(1\) is \(k\) exactly when \(S_k=1\) and no earlier \(S_j\) equals \(1\), which is the displayed intersection. Each \(\{S_j\ne 1\}\) is the complement of \(\{S_j=1\}\), which lies in \(\mathcal F_j\subseteq\mathcal F_k\) for \(j\le k\), and \(\{S_k=1\}\in\mathcal F_k\) by adaptedness. A finite intersection of events in \(\mathcal F_k\) lies in \(\mathcal F_k\), so \(\{\tau=k\}\in\mathcal F_k\). This is also Lemma 9.7.
331: P3 · The step of Proposition 9.6 that uses the filtration's growth
332: Identify the single inclusion in the proof of Proposition 9.6 that uses the fact that the filtration increases, and state which events it moves from one \(\sigma\)-algebra into another.
333: Solution
334: It is the step for the shift. For \(k\ge 1\), \(\{\tau+1\le k\}=\{\tau\le k-1\}\), which lies in \(\mathcal F_{k-1}\) by Definition 9.1 applied at time \(k-1\). The inclusion \(\mathcal F_{k-1}\subseteq\mathcal F_k\) moves that event into \(\mathcal F_k\). The minimum and maximum use only that each \(\mathcal F_k\) is a \(\sigma\)-algebra, so they do not need monotonicity.

342: E1 · Paths that have reached +1 by time 4
343: Read Part A of Lab 1. How many of the 256 paths have reached \(+1\) by time 4, and what is the probability? Why does the count equal the count at time 3?
344: Solution
345: Part A prints 160 paths at \(k=4\), so the probability is \(160/256=0.625\). The count at \(k=3\) is also 160. 356: E3 · The first-hit identity in Part C

358: Solution

367: R1 · The look-ahead rule and the definition
368: Let \(\rho\) be the rule "stop at the step before the first \(+1\)", so \(\rho=k\) when step \(k+1\) is the first \(+1\) step. Show that \(\{\rho\le 0\}\) is not in \(\mathcal F_0\) for the natural filtration, and so \(\rho\) is not a stopping time.

370: Under the rule, \(\rho\le 0\) means \(\rho=0\), which happens exactly when step 1 is \(+1\). So \(\{\rho\le 0\}=\{X_1=+1\}\). 383: Solution
384: The minimum exceeds \(k\) exactly when both times exceed \(k\), which gives the identity. By Lemma 9.7, \(\{\tau>k\}\in\mathcal F_k\) and \(\{\sigma>k\}\in\mathcal F_k\). A finite intersection of events in \(\mathcal F_k\) lies in \(\mathcal F_k\), so \(\{\tau\wedge\sigma>k\}\in\mathcal F_k\). This is the complement form of the closure in Proposition 9.6.
