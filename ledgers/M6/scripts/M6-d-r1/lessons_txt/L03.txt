The Lebesgue Integral

A random payoff is valued by an integral against a probability measure, and a theorem about that integral needs the integral to be defined first. This lesson defines it in two steps. For a simple function, which takes finitely many values on events, the integral is a finite sum of values times measures. For a non-negative function, the integral is the supremum of the integrals of the simple functions below it. The lesson proves that the integral is monotone, and it brackets the integral of \(x^2\) on \([0, 1]\) by simple functions, which the lab then checks.
1Measurable and simple functions
Let \((\Omega, \mathcal F, \mu)\) be a measure space: \(\mathcal F\) is a σ-algebra and \(\mu\) is a measure on it, as in Lesson 2. A function \(f\) from \(\Omega\) to \([0, \infty]\) is measurable when, for every real number \(t\), the set \(\{f > t\} = \{\omega : f(\omega) > t\}\) is an event. Each such set is then an event, and so is \(\{f \ge t\}\), because \(\{f \ge t\} = \bigcap_m \{f > t - 1/m\}\) is a countable intersection of events (Lesson 1, Proposition 1.3(c)).
Definition 1.1 (simple function)
A simple function is a measurable function \(s : \Omega \to [0, \infty)\) that takes finitely many values. The level set of \(s\) at a value \(a\) is \(\{s = a\}\), the set of points where \(s\) takes the value \(a\). Its canonical representation lists the distinct values \(a_1, \dots, a_m\) and the level sets \(A_i = \{s = a_i\}\), which are events that partition \(\Omega\). Then \(s = \sum_i a_i \indic\{A_i\}\).
Remark 1.2 (simple functions are measurable)
For a simple function \(s\) and real \(t\), the set \(\{s > t\}\) is the union of those \(A_i\) with \(a_i > t\). That is a finite union of events, which is an event by Lesson 1, Problem P1. So a simple function is measurable.
2The integral of a simple function
Definition 2.1 (integral of a simple function)
Let \(s\) be simple with canonical representation \(a_1, \dots, a_m\) and \(A_1, \dots, A_m\). Its integral against \(\mu\) is
\[\int s \, d\mu = \sum_{i=1}^{m} a_i \, \mu(A_i),\]
with the convention \(0 \cdot \infty = 0\).
Proposition 2.2 (monotonicity for simple functions)
Assumptions.
\((\Omega, \mathcal F, \mu)\) is a measure space.
\(s\) and \(t\) are simple functions with \(s \le t\) on \(\Omega\).
Statement. \(\int s \, d\mu \le \int t \, d\mu\).
Proof
Let \(a_1, \dots, a_m\) with sets \(A_i\) be the canonical representation of \(s\), and \(b_1, \dots, b_p\) with sets \(B_j\) that of \(t\). For each \(i\), the sets \(A_i \cap B_j\) for \(j = 1, \dots, p\) are events that partition \(A_i\), so by finite additivity (Lesson 2, Proposition 1.3(a)), \(\mu(A_i) = \sum_j \mu(A_i \cap B_j)\). Hence
\[\int s \, d\mu = \sum_{i,j} a_i \, \mu(A_i \cap B_j).\]
If \(A_i \cap B_j\) is non-empty, pick \(\omega\) in it. Then \(a_i = s(\omega) \le t(\omega) = b_j\), so \(a_i \, \mu(A_i \cap B_j) \le b_j \, \mu(A_i \cap B_j)\). If the intersection is empty, both terms are zero. Summing over the pairs gives
\[\int s \, d\mu \le \sum_{i,j} b_j \, \mu(A_i \cap B_j) = \sum_j b_j \, \mu(B_j) = \int t \, d\mu,\]
where the middle equality is the same finite additivity applied to each \(B_j\). \(\blacksquare\)
3The Lebesgue integral of a non-negative function
Definition 3.1 (Lebesgue integral)
Let \(f : \Omega \to [0, \infty]\) be measurable. Its Lebesgue integral against \(\mu\) is
\[\int f \, d\mu = \sup\Bigl\{ \int s \, d\mu : s \text{ simple}, \; 0 \le s \le f \Bigr\} \in [0, \infty].\]
The set over which the supremum is taken contains the zero function, so it is never empty.
Proposition 3.2 (consistency and monotonicity)
Assumptions.
\((\Omega, \mathcal F, \mu)\) is a measure space.
\(f\) and \(g\) are measurable functions from \(\Omega\) to \([0, \infty]\), and \(s\) is simple.
Statement. (a) If \(s\) is simple, Definition 3.1 gives the value \(\int s \, d\mu\) of Definition 2.1. (b) If \(f \le g\), then \(\int f \, d\mu \le \int g \, d\mu\).
Proof
(a) The function \(s\) is one of the simple functions in the supremum, so the supremum is at least \(\int s \, d\mu\). Every other simple \(t\) with \(0 \le t \le s\) satisfies \(\int t \, d\mu \le \int s \, d\mu\) by Proposition 2.2, so the supremum is at most \(\int s \, d\mu\).
(b) Every simple \(s\) with \(0 \le s \le f\) also satisfies \(0 \le s \le g\). So the set over which the supremum for \(f\) is taken is contained in the set for \(g\), and the supremum for \(f\) is at most the supremum for \(g\). \(\blacksquare\)
Proposition 3.3 (a value at one point does not matter for a simple function)
Assumptions.
\((\Omega, \mathcal F, \mu)\) is a measure space, and \(\{x_0\}\) is an event with \(\mu(\{x_0\}) = 0\).
\(s\) is simple, and \(s'\) equals \(s\) except at \(x_0\), where \(s'(x_0) = c\) for some \(c \in [0, \infty)\).
Statement. \(s'\) is simple and \(\int s' \, d\mu = \int s \, d\mu\).
Proof
For any event \(A\), \(\mu(A) = \mu(A \setminus \{x_0\}) + \mu(A \cap \{x_0\})\), and \(\mu(A \cap \{x_0\}) \le \mu(\{x_0\}) = 0\) by monotonicity. So \(\mu(A \setminus \{x_0\}) = \mu(A)\) for every event \(A\). The level sets of \(s'\) are the level sets of \(s\) with \(x_0\) removed from its own level and added to the level \(c\). Each level set of \(s'\) therefore differs from the corresponding one of \(s\) by at most the point \(x_0\), and has the same measure. So the two integrals are sums of the same values times the same measures, and they agree. Since the level sets are events and \(s'\) takes finitely many values, \(s'\) is simple. \(\blacksquare\)
4The length measure and the integral of \(x^2\)
The next results use the length of intervals on \([0, 1]\). The existence of the length measure is an assumption here, not a result proved on this page.
Assumption L (the length measure on [0, 1], stated, not proved here)
The events of \([0, 1]\) form a σ-algebra \(\mathcal L\) that contains every interval, and there is a measure \(\lambda\) on \(([0, 1], \mathcal L)\) with \(\lambda([a, b]) = b - a\) for \(0 \le a \le b \le 1\). The measure \(\lambda\) is the length measure. Its existence is assumed, and the page does not prove it.
Under Assumption L, a single point has length zero, because \(\{x_0\} = [x_0, x_0]\) has \(\lambda = x_0 - x_0 = 0\). Every interval is an event, and so is each half-open interval \([a, b)\), which is the countable union of the closed intervals \([a, b - 1/m]\) for large \(m\).
Proposition 4.1 (dyadic simple functions bracket \(x^2\))
Assumptions.
Assumption L holds, and \(\lambda\) is the length measure on \([0, 1]\).
For a positive integer \(n\), let \(s_n(x) = 2^{-n} \lfloor 2^n x^2 \rfloor\) for \(x \in [0, 1]\), where \(\lfloor \cdot \rfloor\) is the greatest integer at most the argument.
Statement. Assuming Assumption L, (a) \(s_n\) is simple, and \(0 \le s_n(x) \le x^2 \le s_n(x) + 2^{-n}\) for every \(x\) in \([0, 1]\). (b) Let \(I_n = \int s_n \, d\lambda = \sum_{k=0}^{2^n - 1} \frac{k}{2^n}\bigl(\sqrt{(k+1)/2^n} - \sqrt{k/2^n}\bigr)\). Then \(I_n \le \int x^2 \, d\lambda \le I_n + 2^{-n}\).
Proof
(a) The value \(2^n x^2\) lies in \([0, 2^n]\), so \(\lfloor 2^n x^2 \rfloor\) is an integer \(k\) from \(0\) to \(2^n\), and \(s_n\) takes the values \(k/2^n\). Since \(k \le 2^n x^2 < k + 1\) for \(k = \lfloor 2^n x^2 \rfloor\), we get \(s_n(x) \le x^2 < s_n(x) + 2^{-n}\). For \(0 \le k \le 2^n - 1\), the level set \(\{s_n = k/2^n\}\) is \(\{x \in [0, 1] : k/2^n \le x^2 < (k+1)/2^n\}\), which is the interval from \(\sqrt{k/2^n}\) up to \(\sqrt{(k+1)/2^n}\), intersected with \([0, 1]\). Since \((k+1)/2^n \le 1\), it is the half-open interval \([\sqrt{k/2^n}, \sqrt{(k+1)/2^n})\), an event with length \(\sqrt{(k+1)/2^n} - \sqrt{k/2^n}\). The level set for \(k = 2^n\) is the single point \(x = 1\), of length zero. So \(s_n\) is simple.
(b) By Definition 2.1 with the level sets of (a), \(\int s_n \, d\lambda\) is the displayed sum. Since \(s_n\) is simple and \(0 \le s_n \le x^2\), Definition 3.1 gives \(I_n \le \int x^2 \, d\lambda\). The function \(s_n + 2^{-n}\) is simple, with the same level sets as \(s_n\) and each value raised by \(2^{-n}\). Its integral is \(\sum_k (k/2^n + 2^{-n}) \lambda(\{s_n = k/2^n\}) = I_n + 2^{-n} \sum_k \lambda(\{s_n = k/2^n\}) = I_n + 2^{-n}\), because the level sets partition \([0, 1]\) and \(\lambda([0, 1]) = 1\). Since \(x^2 \le s_n + 2^{-n}\) by (a), Proposition 3.2(b) gives \(\int x^2 \, d\lambda \le I_n + 2^{-n}\). \(\blacksquare\)
Remark 4.2 (what the bracket does not give)
Proposition 4.1 gives \(\int x^2 \, d\lambda\) to within \(2^{-n}\) of the computable number \(I_n\). It does not compute the integral exactly. Calculus gives the value \(1/3\) through the antiderivative \(x^3/3\). The page does not prove that this calculus value is the Lebesgue integral. Lab 3 uses \(1/3\) for that purpose and reports the numerical check.
Lab 3 has two parts. Part A is an exact step function. Part B computes \(I_n\) for \(n\) from 1 to 10 and compares the error \(1/3 - I_n\) with the bound \(2^{-n}\) of Proposition 4.1.

"""M6 lab L03: the integral of simple functions with the length measure, and dyadic lower sums for x squared.
Part A is exact. A simple function is given as a list of pieces, each a Fraction length and a value on that piece;
its integral is the sum of value times length, computed in Fraction arithmetic.
Part B is numerical. It uses floating-point arithmetic and prints 10 decimals. It computes the integral of the
dyadic simple function floor(2^n x^2) / 2^n on [0, 1] in closed form for each level set, and compares 1/3 minus that
integral with the bound 2^(-n). The bound is proved on the page; the value 1/3 is the calculus value of the
integral of x^2, and this lab reads it off numerically. The output is therefore labelled numerical.
Standard library only. Nothing is random and nothing is read from a file.
"""
from __future__ import annotations
from fractions import Fraction
from itertools import pairwise
from math import sqrt
Piece = tuple[Fraction, Fraction]
def simple_integral(pieces: list[Piece]) -> Fraction:
"""The integral of a simple function given by (length, value) pieces: the sum of value times length.
A piece of length 0 is a single point and contributes nothing. Raises ValueError for a negative length.
"""
if any(length < 0 for length, _ in pieces):
raise ValueError("piece lengths must be non-negative")
return sum((length * value for length, value in pieces), Fraction(0))
def dyadic_integral(n: int) -> float:
"""The integral over [0, 1] of floor(2^n x^2) / 2^n, using the length of each level set.
For k from 0 to 2^n - 1, the level set where floor(2^n x^2) = k is the interval from sqrt(k / 2^n) up to
sqrt((k + 1) / 2^n), whose length is sqrt((k + 1) / 2^n) - sqrt(k / 2^n). The level 2^n is the single point
x = 1, of length 0. Raises ValueError when n is negative.
"""
if n < 0:
raise ValueError("n must be a non-negative integer")
scale = 2**n
total = 0.0
for k in range(scale):
total += (k / scale) * (sqrt((k + 1) / scale) - sqrt(k / scale))
return total
def main() -> None:
third_quarter = Fraction(3, 4)
print("Part A (exact): values 0 on [0, 1/2), 1 on [1/2, 3/4), 3 on [3/4, 1]")
base = [
(Fraction(1, 2), Fraction(0)),
(third_quarter - Fraction(1, 2), Fraction(1)),
(Fraction(1) - third_quarter, Fraction(3)),
]
print(f"integral = {simple_integral(base)}")
moved_point = [
(Fraction(1, 2), Fraction(0)),
(Fraction(0), Fraction(5)),
(third_quarter - Fraction(1, 2), Fraction(1)),
(Fraction(1) - third_quarter, Fraction(3)),
]
print(f"step function plus a point at 1/2 of value 5 (length 0): integral = {simple_integral(moved_point)}")
print("Part B (numerical, 10 decimals): dyadic lower sums of x^2 on [0, 1]")
values: list[float] = []

f"0 <= error <= 2^(-n): {0 <= error <= bound}"
)

print(f"I_n is nondecreasing for n from 1 to 10: {nondecreasing}")

The second function adds a piece of length 0, so its equal integral follows from the length rule in the code. 5Where the canon breaks
The definitions are simple to state and easy to misapply. Four points mark where the simple picture fails.
The sup definition is needed for functions that are not simple, such as \(x^2\) (Misconceptions, first item). The function \(x^2\) takes uncountably many values, so it is not simple, and Definition 2.1 does not apply to it directly. Definition 3.1 is the route.
Assumption L is a hypothesis. The existence of the length measure is not proved here. Every integral against \(\lambda\) in §4 depends on it.
The integral is an extended number. Definition 3.1 gives values in \([0, \infty]\). A function can have an infinite integral, and the page makes no claim that a given function is finite under a given measure.
The integral depends on the measure. The same function can have different integrals under different measures. This lesson fixes one measure at a time, and the statements apply to the measure named.
6Misconceptions
“\(x^2\) is a simple function, since it is a polynomial.”
A simple function takes finitely many values. The function \(x^2\) takes every value in \([0, 1]\), so it is not simple. Its integral is defined through the supremum of Definition 3.1, and, under Assumption L, Proposition 4.1 brackets that integral from below and above.
“A dyadic approximation at a finite level gives the integral exactly.”
At \(n = 1\), \(I_1 = \tfrac12(1 - \sqrt{1/2}) \approx 0.1464\), while the calculus value of \(\int x^2 \, d\lambda\), which Remark 4.2 does not prove equal to the Lebesgue integral, is \(1/3 \approx 0.3333\). The gap is \(1/3 - I_1 \approx 0.1869\), which is inside the bound \(2^{-1} = 0.5\) but far from zero. Lab 3 prints \(I_1 = 0.1464466094\) and \(1/3 - I_1 = 0.1868867239\), which agree with the figures above at the printed precision.
“Changing a function at one point changes its integral.”
Proposition 3.3 proves that for a simple function, moving the value at a point of measure zero leaves the integral unchanged. Lab 3 prints the integral 1 for the step function and again after a one-point piece of value 5 at \(1/2\) is added, because that piece has length 0.
7Problem set
Attempt each problem before opening its solution. Problems marked E use the output of Lab 3.
Mechanics
M1 · A three-piece simple function
Under the length measure, let \(s = 2\) on \([0, 1/3]\) and \(s = 5\) on \((1/3, 1]\). Compute \(\int s \, d\lambda\).
Solution
The canonical representation has values \(2\) and \(5\) on the events \([0, 1/3]\) and \((1/3, 1]\), with lengths \(1/3\) and \(2/3\). By Definition 2.1 the integral is \(2 \cdot 1/3 + 5 \cdot 2/3 = 2/3 + 10/3 = 4\).
M2 · The indicator of a union of intervals
Compute \(\int \indic\{[0, 1/2] \cup [3/4, 1]\} \, d\lambda\).
Solution
The indicator is simple with value 1 on the union and 0 elsewhere. The union is disjoint, with length \(1/2 + 1/4 = 3/4\). So the integral is \(1 \cdot 3/4 + 0 \cdot 1/4 = 3/4\), with the convention that the zero value contributes nothing.
M3 · The first dyadic sum in closed form
Write \(I_1\) from Proposition 4.1(b) as a closed form, and evaluate it to four decimals.
Solution
With \(n = 1\) the sum has the two terms \(k = 0\) and \(k = 1\). The \(k = 0\) term is zero, and the \(k = 1\) term is \(\tfrac12\bigl(\sqrt{2/2} - \sqrt{1/2}\bigr) = \tfrac12(1 - \sqrt{1/2})\). Numerically this is \(0.1464\), which is the lab's first row, \(0.1464466094\), to four places.
Proof
P1 · Monotonicity of the sup
Prove Proposition 3.2(b) from Definition 3.1, stating each inclusion used.
Solution
Let \(f \le g\). A simple \(s\) with \(0 \le s \le f\) also satisfies \(0 \le s \le g\), so it is among the simple functions in the supremum for \(g\). The supremum over a larger set is at least the supremum over a smaller set, so \(\int f \, d\mu \le \int g \, d\mu\).
P2 · The pointwise bracket
For \(x\) in \([0, 1]\) and a positive integer \(n\), prove \(s_n(x) \le x^2 < s_n(x) + 2^{-n}\).
Solution
Let \(k = \lfloor 2^n x^2 \rfloor\). By definition \(k \le 2^n x^2 < k + 1\). Dividing by \(2^n\) gives \(k/2^n \le x^2 < k/2^n + 2^{-n}\), and \(s_n(x) = k/2^n\), which is the bracket.
P3 · Measure of a point
Under Assumption L, prove \(\lambda(\{x_0\}) = 0\) for every \(x_0\) in \([0, 1]\), and state where Proposition 3.3 uses this.
Solution
The set \(\{x_0\}\) is the closed interval \([x_0, x_0]\), with \(a = b = x_0\) in the length rule. So \(\lambda(\{x_0\}) = x_0 - x_0 = 0\). Proposition 3.3 uses this for the point \(x_0\) at which the value of the simple function is changed.
Empirical
E1 · The exact step function
Lab 3 Part A prints the integral 1 for the step function with values 0, 1 and 3. Recompute the integral by hand from its pieces and check the value against the output.
Solution
The value 0 sits on a piece of length \(1/2\), contributing 0. The value 1 sits on a piece of length \(1/4\), contributing \(1/4\). The value 3 sits on a piece of length \(1/4\), contributing \(3/4\). The sum is \(1\), which the lab prints. Both lines of Part A are exact.
E2 · Reading the error column
At \(n = 10\), Lab 3 prints an error of 0.0004819768 and a bound of 0.0009765625. What do these two numbers establish, and what do they depend on?
Solution
They establish that the error is inside the bound at \(n = 10\), if the integral of \(x^2\) is \(1/3\). The inequality depends on that value, which is taken from calculus and not proved here. The numbers are floating-point, so they are numerical and carry the grade C. The check covers \(n\) from 1 to 10 only. The bound for every \(n\), given Assumption L and the value \(1/3\), is the proof in Proposition 4.1.
E3 · Predicting \(I_2\)
Write \(I_2\) as the sum in Proposition 4.1(b) with \(n = 2\), and evaluate it to four decimals before looking at the lab output.
Solution
The terms for \(k = 1, 2, 3\) are \(\tfrac14(\sqrt{1/2} - \sqrt{1/4})\), \(\tfrac12(\sqrt{3/4} - \sqrt{1/2})\) and \(\tfrac34(1 - \sqrt{3/4})\). Their values are about \(0.0518\), \(0.0795\) and \(0.1005\). The sum is \(0.231717\) from the unrounded terms; the three rounded values add to \(0.2318\). The lab prints \(0.2317169538\) for \(I_2\), which agrees with the unrounded sum \(0.231717\) to six places. Rounded to four places, that sum is \(0.2317\), not the \(0.2318\) from adding the rounded terms.
Research
R1 · Which statements are exact
Lab 3 mixes exact and numerical output. List the printed statements that are exact and the ones that are numerical, and say what would be needed to make each numerical one exact.
Solution
The Part A lines are exact fractions. The Part B lines are floating-point numbers. To make a Part B line exact, the integral of \(x^2\) would need an exact value, which needs either a proof of the calculus value for the Lebesgue integral or an exact evaluation of the sums \(I_n\). The page does neither, so Part B stays numerical.
R2 · Dropping the events of intervals
Assumption L requires every interval to be an event. Explain which step of Proposition 4.1 would fail if a model's events did not include the half-open intervals \([\sqrt{k/2^n}, \sqrt{(k+1)/2^n})\).
Solution
Part (a) of Proposition 4.1 identifies the level sets of \(s_n\) with those intervals. If they were not events, \(s_n\) would not be measurable and the simple-function integral in Definition 2.1 would not be defined for it. The bracket would then have no value to bound.
R3 · An infinite integral
Let \(\Omega\) be a non-empty set with \(\mathcal F\) the collection of all its subsets. Define \(\mu(A) = \infty\) for each non-empty \(A\) and \(\mu(\emptyset) = 0\). Show that \(\mu\) is a measure and compute \(\int 1 \, d\mu\).
Solution
For a sequence of pairwise disjoint events, the union is non-empty exactly when some term is non-empty, and then both sides of (M2) equal \(\infty\). If all are empty, both sides are \(0\). So \(\mu\) is a measure. The constant function \(1\) is simple with the single value \(1\) on \(\Omega\), so \(\int 1 \, d\mu = 1 \cdot \mu(\Omega) = \infty\), provided \(\Omega\) is non-empty.

For a simple function with value 2 on an event \(A\) and value 0 elsewhere, what is the integral?
Options
\(2\,\mu(A)\)
\(2 + \mu(A)\)
\(\mu(A)/2\)
Definition 2.1: the value 2 times \(\mu(A)\), plus 0 times the complement's measure.
Under the length measure, what is \(\int \indic\{[0, 1/2]\} \, d\lambda\)?
Answer
The indicator is simple with value 1 on an interval of length \(1/2\): the integral is \(1/2\).
Which condition makes a function measurable in this lesson?
Options
It is continuous
Every set \(\{f > t\}\) is an event
It takes only integer values
Measurability is defined through the sets \(\{f > t\}\), which must be events (§1).
What is \(I_1 = \int s_1 \, d\lambda\) for \(s_1(x) = \tfrac12\lfloor 2x^2 \rfloor\), to four decimals?
Answer
\(I_1 = \tfrac12(1 - \sqrt{1/2}) \approx 0.1464\). Lab 3 prints 0.1464466094.
Is \(x^2\) on \([0, 1]\) a simple function?
Options
Yes, because it is a polynomial
No, it takes uncountably many values
Yes, because its integral is finite
A simple function takes finitely many values. \(x^2\) takes every value in \([0, 1]\).
A simple function equals 2 on \([0, 1/3]\) and 5 on \((1/3, 1]\). What is its integral under the length measure?
Answer
\(2 \cdot 1/3 + 5 \cdot 2/3 = 4\), as in Problem M1.
Changing a simple function's value at a point of measure zero does what to its integral?
Options
It doubles it
It leaves it unchanged
It makes it infinite
Proposition 3.3. Lab 3 prints the integral 1 both for the step function and after a one-point piece of value 5 at \(1/2\) is added, since a point has length 0.
In the integral convention, what is \(0 \cdot \infty\)?
Options
Zero
Infinity
Undefined, so the integral does not exist
Definition 2.1 fixes \(0 \cdot \infty = 0\), so a zero value contributes nothing even on an infinite-measure event.
Under Assumption L, Proposition 4.1 gives which bracket for \(\int x^2 \, d\lambda\) at level \(n\)?
Options
\(I_n \le \int x^2 \, d\lambda \le I_n + 2^{-n}\)
\(I_n \ge \int x^2 \, d\lambda\)
\(\int x^2 \, d\lambda = I_n\) exactly
Proposition 4.1(b). The bracket has width \(2^{-n}\), so it tightens with \(n\).
