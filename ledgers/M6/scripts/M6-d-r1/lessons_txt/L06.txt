Some measures are reweightings of others. A density \(f\) (Definition 2.1) turns a measure \(\mu\) into a second measure \(\nu\) by \(\nu(A) = \int_A f\,d\mu\) for every event \(A\). Not every pair of measures admits such an \(f\). On a finite space the condition is absolute continuity, defined in §1, and the finite case below proves that it is also sufficient. This lesson proves the finite case. The general statement is listed as Assumption RN and is not proved here. Lab 1 computes the density on a four-point space, checks it on all 16 events, and exhibits a point where \(\mu = 0 < \nu\), where no density exists.
1Measures on a finite set, and absolute continuity
Let \(\Omega\) be a finite set. A weight is a function \(w \ge 0\) on \(\Omega\). A measure on \(\Omega\) is given by its weights \(\mu(\omega) \ge 0\), and the measure of an event \(A \subseteq \Omega\) is \(\mu(A) = \sum_{\omega \in A} \mu(\omega)\). Because the measure is a sum over points, it is additive over disjoint events: \(\mu(A \cup B) = \mu(A) + \mu(B)\) when \(A\) and \(B\) are disjoint. An event is any subset of \(\Omega\). Every event here is a finite set of points, so no further sets are needed.
Definition 1.1 (absolute continuity; plain words)
The measure \(\nu\) is absolutely continuous with respect to \(\mu\), written \(\nu \ll \mu\), when \(\mu(A) = 0\) implies \(\nu(A) = 0\) for every event \(A\). In words, \(\nu\) gives no weight to any event that \(\mu\) regards as having no weight.
Lemma 1.2 (absolute continuity on a finite set)
Assumptions.
\(\Omega\) is finite, and \(\mu\) and \(\nu\) are measures on \(\Omega\) given by nonnegative weights.
Statement. \(\nu \ll \mu\) holds if and only if \(\nu(\omega) = 0\) for every point \(\omega\) with \(\mu(\omega) = 0\).
Proof
If \(\nu \ll \mu\) and \(\mu(\omega) = 0\), then the event \(\{\omega\}\) has \(\mu(\{\omega\}) = 0\), so \(\nu(\{\omega\}) = 0\). Conversely, suppose the condition holds and \(\mu(A) = 0\). The weights are nonnegative and sum to zero over \(A\), so \(\mu(\omega) = 0\) for every \(\omega \in A\). The condition gives \(\nu(\omega) = 0\) for each such \(\omega\), so \(\nu(A) = \sum_{\omega \in A} \nu(\omega) = 0\). Hence \(\nu \ll \mu\).
2The density and the Radon–Nikodym theorem
Definition 2.1 (density)
A density of \(\nu\) with respect to \(\mu\) is a function \(f \ge 0\) on \(\Omega\) such that \(\nu(A) = \int_A f\,d\mu = \sum_{\omega \in A} f(\omega)\,\mu(\omega)\) for every event \(A\). The symbol \(\int_A f\,d\mu\) is the integral of \(f\) over \(A\) against \(\mu\), which on a finite set is this finite sum.
Assumption RN (the Radon–Nikodym theorem, general form; not proved here)
\(\mu\) and \(\nu\) are \(\sigma\)-finite measures on a measurable space, where \(\sigma\)-finite means the space is a countable union of sets of finite measure.
\(\nu \ll \mu\), as in Definition 1.1.
Conclusion. There exists a measurable density \(f \ge 0\) as in Definition 2.1, and it is unique up to a set of \(\mu\)-measure zero. Here "unique up to a set of \(\mu\)-measure zero" means that two densities agree at every point except on a set that \(\mu\) gives weight zero. The statement is not proved on this page, and no grade is given to it.
Theorem 2.2 (Radon–Nikodym, finite case)
Assumptions.
\(\Omega\) is finite, and \(\mu\) and \(\nu\) are measures given by nonnegative weights.
\(\nu \ll \mu\), as in Definition 1.1. Part (a) uses this assumption; parts (b) and (c) do not.
Statement. (a) If \(\nu \ll \mu\), then \(f(\omega) = \nu(\omega)/\mu(\omega)\) for \(\mu(\omega) > 0\), and \(f(\omega) = 0\) for \(\mu(\omega) = 0\), is a density of \(\nu\) with respect to \(\mu\). (b) Every density \(g\) of \(\nu\) with respect to \(\mu\) satisfies \(g(\omega) = f(\omega)\) at every point with \(\mu(\omega) > 0\). (c) If \(\nu\) has a density with respect to \(\mu\), then \(\nu \ll \mu\).
Proof
(c) Let \(g\) be a density and let \(\mu(A) = 0\). Every \(\omega \in A\) has \(\mu(\omega) = 0\), because \(\mu(A) = 0\) is a sum of nonnegative weights. So each term \(g(\omega)\mu(\omega)\) with \(\omega \in A\) is zero, and \(\nu(A) = \sum_{\omega \in A} g(\omega)\mu(\omega) = 0\). Hence \(\nu \ll \mu\).
(b) Take \(A = \{\omega\}\) in Definition 2.1. Then \(\nu(\omega) = g(\omega)\mu(\omega)\). If \(\mu(\omega) > 0\), divide by \(\mu(\omega)\) to get \(g(\omega) = \nu(\omega)/\mu(\omega) = f(\omega)\).
(a) Let \(\nu \ll \mu\), and let \(f\) be defined as in the statement. For an event \(A\), split \(A\) into the points with \(\mu(\omega) > 0\) and the points with \(\mu(\omega) = 0\). On the second set, \(\nu(\omega) = 0\) by Lemma 1.2, and \(f(\omega)\mu(\omega) = 0\). On the first set, \(f(\omega)\mu(\omega) = \nu(\omega)\). Adding the two parts, \(\sum_{\omega \in A} f(\omega)\mu(\omega) = \sum_{\omega \in A} \nu(\omega) = \nu(A)\). So \(f\) is a density.
Proposition 2.2 (integrals against a density)
Assumptions.
\(\Omega\) is finite, \(\mu\) and \(\nu\) are measures given by nonnegative weights, and \(\nu \ll \mu\).
\(f\) is a density of \(\nu\) with respect to \(\mu\), in the sense of Definition 2.1.
\(g\) is any real function on \(\Omega\).
Statement. \(\sum_{\omega} g(\omega)\,\nu(\omega) = \sum_{\omega} g(\omega)\,f(\omega)\,\mu(\omega)\).
Proof
Take \(A = \{\omega\}\) in Definition 2.1 at each point \(\omega\), which gives \(\nu(\omega) = f(\omega)\mu(\omega)\). Multiply this identity by \(g(\omega)\) and sum over the finite set \(\Omega\). The distributive law gives the claim.
Proposition 2.3 (no density when mu vanishes and nu does not)
Assumptions.
\(\Omega\) is finite, and \(\mu\) and \(\nu\) are given by nonnegative weights.
There is a point \(\omega_0\) with \(\mu(\omega_0) = 0\) and \(\nu(\omega_0) > 0\).
Statement. No function \(g \ge 0\) on \(\Omega\) is a density of \(\nu\) with respect to \(\mu\).
Proof
Take the event \(A = \{\omega_0\}\). Then \(\mu(A) = 0\), and for any function \(g\) the density integral is \(\sum_{\omega \in A} g(\omega)\mu(\omega) = g(\omega_0) \cdot 0 = 0\). But \(\nu(A) = \nu(\omega_0) > 0\). So the requirement \(\nu(A) = \int_A g\,d\mu\) fails for every \(g\).
Remark 2.4 (the density is a ratio, and it need not be a probability)
The density is the pointwise ratio \(\nu(\omega)/\mu(\omega)\) where \(\mu\) is positive, so its values need not lie between 0 and 1, and it need not be a probability. Equal total masses do not prevent this: \(\mu = (1, 1)\) and \(\nu = (2, 0)\) both have total mass 2, and the density at the first point is 2. Lab 1 Part A has total mass 1 for both measures, and its density values 2, 1/2, 2 and 1/3 include two values greater than 1.
Lab 1 · Densities on a finite space, checked exactly
The inputs are fixed measures, not data, and no random draws are used. Part A takes four points with \(\mu\) positive everywhere, and checks the density \(f = \nu/\mu\) against \(\nu\) on all 16 events, by exact rational arithmetic. Part B takes five points, with \(\mu = 0\) at point 5 (index 4 in the code) and \(\nu > 0\) there. Before running, the expected result is that the density in Part A reproduces \(\nu\) on every event, that Part B has exactly one event, \(\{\text{point }5\}\), that fails the absolute-continuity test, and that the candidate density of Part B misses some events, which the lab counts. Part C checks Proposition 2.2 for one function \(g\): the integral of \(g\) against \(\nu\) equals the integral of \(g\) against \(f\mu\).
"""M6 L06 lab 1: densities on a finite space, computed in exact rational arithmetic.
Inputs are two fixed finite measures, not data, and no random draws are used, so every run prints the same lines.
A measure on a finite set is given by its weights on the points; the measure of an event A is the sum of the weights
of its points. An event is a subset of the points, and it is written here as a bit mask. Points are numbered from 1
in the text, so point 5 is index 4 in the code.
Part A: the points carry mu and nu with mu > 0 everywhere. The density f = nu / mu reproduces nu on all 16 events.
Part B: the fifth point (point 5) carries mu = 0 and nu > 0. The event {point 5} then has nu > 0 and mu = 0, so no
density can reproduce nu on it. Exactly one of the 32 events fails the absolute-continuity test.
Part C: for a function g on the four points, the sum of g times nu equals the sum of g times the density times mu.
Every weight, measure and density is a Fraction, so each equality test is exact. Nothing is rounded.
"""
from fractions import Fraction
def measure(weights: tuple[Fraction, ...], event: int) -> Fraction:
"""The measure of the event with bit mask `event`: the sum of the weights of the points whose bit is set."""
return sum((w for i, w in enumerate(weights) if event >> i & 1), Fraction(0))
def integral(density: tuple[Fraction, ...], mu: tuple[Fraction, ...], event: int) -> Fraction:
"""The integral over the event of the density with respect to mu: the sum of density * mu over its points."""
return sum((d * w for i, (d, w) in enumerate(zip(density, mu, strict=True)) if event >> i & 1), Fraction(0))
def fmt(value: Fraction) -> str:
"""A rational number as a reduced fraction with no spaces, for printing."""
return str(value)
def part_a() -> None:
"""A four-point space with mu > 0 everywhere: the density nu/mu reproduces nu on every event."""
mu = (Fraction(1, 8), Fraction(1, 4), Fraction(1, 4), Fraction(3, 8))
nu = (Fraction(1, 4), Fraction(1, 8), Fraction(1, 2), Fraction(1, 8))
density = tuple(n / m for n, m in zip(nu, mu, strict=True))
print("Part A: density nu/mu on a four-point space with mu > 0")
print("density " + " ".join(fmt(d) for d in density))
events = range(2**4)
matches = all(integral(density, mu, a) == measure(nu, a) for a in events)
print(f"events_checked {len(events)}")
print(f"all_events_match {matches}")
print(f"total_mass_mu {fmt(measure(mu, 15))} total_mass_nu {fmt(measure(nu, 15))}")
def part_b() -> None:
"""A five-point space with mu = 0 at point 5 (index 4) and nu > 0 there: no density exists."""
mu = (Fraction(1, 4), Fraction(1, 4), Fraction(1, 4), Fraction(1, 4), Fraction(0))
nu = (Fraction(1, 4), Fraction(1, 4), Fraction(1, 4), Fraction(1, 8), Fraction(1, 8))
print("Part B: a point with mu = 0 and nu > 0")
failing = [a for a in range(2**5) if measure(mu, a) == 0 and measure(nu, a) > 0]
print(f"events_checked {2**5}")
print(f"absolute_continuity_failures {len(failing)}")
for a in failing:
print(f"failing_event_mask {a} mu {fmt(measure(mu, a))} nu {fmt(measure(nu, a))}")
candidate = tuple(n / m if m > 0 else Fraction(0) for n, m in zip(nu, mu, strict=True))
misses = [a for a in range(2**5) if integral(candidate, mu, a) != measure(nu, a)]
print(f"candidate_density_misses {len(misses)}")
print(f"candidate_reproduces_nu {len(misses) == 0}")
def part_c() -> None:
"""The integral of a function g against nu equals its integral against the density times mu (Proposition 2.2)."""
mu = (Fraction(1, 8), Fraction(1, 4), Fraction(1, 4), Fraction(3, 8))
nu = (Fraction(1, 4), Fraction(1, 8), Fraction(1, 2), Fraction(1, 8))
density = tuple(n / m for n, m in zip(nu, mu, strict=True))
g = (Fraction(3), Fraction(-1), Fraction(2), Fraction(5))
against_nu = sum((gi * ni for gi, ni in zip(g, nu, strict=True)), Fraction(0))
against_density = sum((gi * di * mi for gi, di, mi in zip(g, density, mu, strict=True)), Fraction(0))
print("Part C: integral of g against nu, and against the density times mu")
print(f"integral_against_nu {fmt(against_nu)}")
print(f"integral_against_density {fmt(against_density)}")
print(f"equal {against_nu == against_density}")
def main() -> None:
"""Print Parts A, B and C."""
part_a()
part_b()
part_c()
main()

Part A prints the density \(2, 1/2, 2, 1/3\) (as exact fractions), counts 16 events, and prints True for "all_events_match", so the density reproduces \(\nu\) on every event of the four-point space. Both total masses are 1. Part B counts 32 events and finds one absolute-continuity failure, the event with mask 16, which is \(\{\text{point }5\}\), with \(\mu = 0\) and \(\nu = 1/8\). The candidate density gives 16 misses, and the printed flag is False. The lab prints only this count. Problem E2 shows that the misses are the 16 events that contain point 5. Part C prints the same exact value, \(9/4\), for both integrals. The lab shows these results for the stated measures only. It does not show that the density is unique on other spaces, and it says nothing about any market or account.
3Where the canon breaks
A point with \(\mu = 0\) and \(\nu > 0\). Proposition 2.3 shows that no density exists. Absolute continuity is the hypothesis whose failure breaks the theorem, and Lab 1 Part B shows it failing.
Uniqueness only where \(\mu\) is positive. Theorem 2.2(b) fixes the density only at points with \(\mu(\omega) > 0\). At a point with \(\mu(\omega) = 0\), any nonnegative value is a density value. Theorem 2.2(a) sets it to 0, and changing it to any other nonnegative value leaves every sum \(\sum f\mu\) unchanged.
Infinite spaces. The finite proofs use only the arithmetic of real numbers (the distributive law, division by \(\mu(\omega) > 0\), and nonnegativity of the weights) and finite sums. Assumption RN is stated for general measures, under \(\sigma\)-finiteness, and it is not proved here. The page does not claim that a density is bounded, or that one exists on a space that is not \(\sigma\)-finite.
4Misconceptions
“Any two measures on a finite set are related by a density.”
Proposition 2.3 gives a counterexample. With \(\mu = 0\) at point 5 and \(\nu(5) = 1/8\), no density exists, and Lab 1 Part B prints one failing event. A density requires \(\nu \ll \mu\) (Theorem 2.2(c)).
“A density is a probability, so its values lie between 0 and 1.”
The density of Part A takes the values 2, 1/2, 2 and 1/3 (Lab 1 Part A), and two of them exceed 1. Its values are ratios of two measures, so they can exceed 1 (Remark 2.4).
“The density is unique at every point.”
Theorem 2.2(b) fixes the density only where \(\mu(\omega) > 0\). Where \(\mu(\omega) = 0\), the density value does not change any integral, so it can be any nonnegative number. The uniqueness statement in Assumption RN is also only up to a \(\mu\)-null set.
5Problem set
Every problem has a full worked solution. Attempt each one before opening it.
Mechanics
M1 · A density on two points
On \(\Omega = \{a, b\}\), let \(\mu(a) = 1/4\), \(\mu(b) = 3/4\), and \(\nu(a) = \nu(b) = 1/2\). Find the density \(f\) of \(\nu\) with respect to \(\mu\), and check it.
Solution
Both weights of \(\mu\) are positive, so Theorem 2.2(a) gives \(f(a) = \nu(a)/\mu(a) = (1/2)/(1/4) = 2\) and \(f(b) = (1/2)/(3/4) = 2/3\). Check: \(f(a)\mu(a) = 2 \cdot 1/4 = 1/2 = \nu(a)\), and \(f(b)\mu(b) = (2/3)(3/4) = 1/2 = \nu(b)\).
M2 · A density on four points
On four points let \(\mu\) be uniform, \(\mu(\omega) = 1/4\) for each point, and let \(\nu = (1/8, 1/8, 1/4, 1/2)\). Find the density \(f\).
Solution
Divide each weight of \(\nu\) by \(1/4\): \(f = (1/2, 1/2, 1, 2)\). Check: \(f(\omega)\cdot 1/4\) is \(1/8, 1/8, 1/4, 1/2\), which are the weights of \(\nu\). The weights of \(\nu\) sum to 1, the same as the total mass of \(\mu\), and the density has total \(\mu\)-integral 1.
M3 · Integrating a function two ways
For the measures of M2 and \(g = (0, 1, 2, 3)\), compute \(\sum_\omega g(\omega)\nu(\omega)\) and \(\sum_\omega g(\omega)f(\omega)\mu(\omega)\).
Solution
Against \(\nu\): \(0 \cdot \tfrac18 + 1 \cdot \tfrac18 + 2 \cdot \tfrac14 + 3 \cdot \tfrac12 = \tfrac18 + \tfrac12 + \tfrac32 = \tfrac{17}{8}\). Against \(f\mu\): \((0 \cdot \tfrac12 + 1 \cdot \tfrac12 + 2 \cdot 1 + 3 \cdot 2)/4 = (\tfrac12 + 2 + 6)/4 = \tfrac{17}{8}\). The two agree, as Proposition 2.2 states, which Part C of Lab 1 checks for a different \(g\).
Proof
P1 · The converse direction of Lemma 1.2
Suppose \(\nu(\omega) = 0\) whenever \(\mu(\omega) = 0\). Show that \(\nu \ll \mu\).
Solution
Let \(\mu(A) = 0\). Since \(\mu(A)\) is a sum of nonnegative weights, each weight \(\mu(\omega)\) with \(\omega \in A\) is zero. By the hypothesis, \(\nu(\omega) = 0\) for each such \(\omega\). So \(\nu(A) = \sum_{\omega \in A} \nu(\omega) = 0\). This is the definition of \(\nu \ll \mu\) for the event \(A\), and \(A\) was arbitrary.
P2 · Uniqueness on the positive part
Let \(g\) and \(h\) be densities of \(\nu\) with respect to \(\mu\). Show that \(g = h\) at every point with \(\mu(\omega) > 0\).
Solution
Take \(A = \{\omega\}\) in Definition 2.1 for each density. Then \(\nu(\omega) = g(\omega)\mu(\omega)\) and \(\nu(\omega) = h(\omega)\mu(\omega)\). Subtracting, \((g(\omega) - h(\omega))\mu(\omega) = 0\). If \(\mu(\omega) > 0\), dividing by \(\mu(\omega)\) gives \(g(\omega) = h(\omega)\).
P3 · The integral against the density
Show that if \(f\) is a density of \(\nu\) with respect to \(\mu\), then \(\sum_\omega g(\omega)\nu(\omega) = \sum_\omega g(\omega)f(\omega)\mu(\omega)\) for every function \(g\).
Solution
This is Proposition 2.2. Its proof takes \(A = \{\omega\}\) in Definition 2.1 at each point, so it needs no positivity of \(\mu\). Part C of Lab 1 checks the identity for one function \(g\).
Empirical
E1 · Reading the density at one point
Read Part A of Lab 1. Which point has \(\mu = 3/8\), what is its density, and what does \(\nu\) give that point?
Solution
The fourth point of Part A (index 3 in the code) has \(\mu = 3/8\). Part A prints the density 1/3 at that point. Then \(f \cdot \mu = (1/3)(3/8) = 1/8\), which is \(\nu\) at that point. Part A's check of all 16 events passes, so this product is the weight of \(\nu\) there.
E2 · Why the candidate misses 16 events
Part B prints 16 candidate misses. Explain why this number equals the number of events that contain point 5.
Solution
For an event \(A\) that does not contain point 5, every point of \(A\) has \(\mu > 0\), so \(f\mu = \nu\) at each point of \(A\), and the candidate's integral equals \(\nu(A)\). For an event \(A\) that contains point 5, the candidate contributes \(0\) at point 5 because \(\mu(5) = 0\). So the integral equals \(\nu(A) - \nu(5) = \nu(A) - 1/8\), which differs from \(\nu(A)\). The misses are exactly the events containing point 5. There are \(2^4 = 16\) such events in a five-point space.
E3 · The largest density in Part A
Which density values in Part A are largest, and what are they?
Solution
Part A prints the densities \(2, 1/2, 2, 1/3\). The largest value is 2, and it occurs at two points, the first and the third. These are the two points where \(\nu\) is twice \(\mu\): \(\nu = 1/4\) against \(\mu = 1/8\), and \(\nu = 1/2\) against \(\mu = 1/4\).
Research
R1 · An unbounded density
On \(\Omega = \{1, 2, 3, \ldots\}\), let \(\mu(n) = 3^{-n}\) and \(\nu(n) = 2^{-n}\). Show that \(f(n) = (3/2)^n\) is a density of \(\nu\) with respect to \(\mu\), and that \(f\) is unbounded.
Solution
For each point, \(f(n)\mu(n) = (3/2)^n \cdot 3^{-n} = 2^{-n} = \nu(n)\). For a general event \(A\), \(\sum_{n \in A} f(n)\mu(n) = \sum_{n \in A} \nu(n) = \nu(A)\), which uses the countable additivity of nonnegative series, a standard fact used without proof. So \(f\) is a density. It is unbounded, because \(f(n) = (3/2)^n\) increases without limit. The example shows that a density need not be bounded, which the finite case cannot show. The space here is infinite, so this is outside Theorem 2.2.
R2 · Probability measures and total mass
Suppose \(\mu\) and \(\nu\) are probability measures on a finite \(\Omega\), with \(\nu \ll \mu\), and let \(f\) be the density. Show that \(\sum_\omega f(\omega)\mu(\omega) = 1\).
Solution
Take \(A = \Omega\) in Definition 2.1. Then \(\sum_{\omega \in \Omega} f(\omega)\mu(\omega) = \nu(\Omega)\). The measure \(\nu\) is a probability, so \(\nu(\Omega) = 1\). Hence \(\sum_\omega f(\omega)\mu(\omega) = 1\), which is the total mass identity that Remark 2.4 discusses.
R3 · Pointwise uniqueness on a finite space, and why Assumption RN is stated up to null sets
Explain why, on a finite space, the density is unique at every point with \(\mu > 0\), and why Assumption RN states uniqueness only up to a set of \(\mu\)-measure zero on a general space.
Solution
On a finite space, each point is an event with a definite \(\mu\)-weight. Problem P2 shows that the density is determined at every point with positive weight, and Theorem 2.2(b) states this. Points with weight zero are exactly the points where the density is free (Misconception 3 in §4). On a general measure space the same freedom exists on any set \(N\) with \(\mu(N) = 0\). If \(f\) is a density and \(g = f\) outside \(N\), then \(\int_A g\,d\mu = \int_A f\,d\mu\) for every event \(A\), because the two integrands differ only on \(N\), and a set of measure zero contributes nothing to an integral (a standard fact, used here without proof). So \(g\) is also a density, and pointwise uniqueness cannot hold in general. Assumption RN states uniqueness up to such sets, and the page does not prove it.

Because \(\nu(\Omega) = \sum_\omega f(\omega)\mu(\omega)\) and \(\nu(\Omega) = 1\) (Problem R2)
