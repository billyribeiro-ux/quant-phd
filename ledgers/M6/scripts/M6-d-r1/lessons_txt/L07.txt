Conditional expectation is the best estimate of a random quantity from information that splits outcomes into cells. In mean squared error, it is the closest function that the information can produce, and its residual has zero average against every such function. This lesson defines it on a finite probability space, where information is a partition into cells (§1). It proves that the best estimate is the cell average, and that averaging in two steps over nested partitions gives the coarser answer. The general definition is Assumption CE (Remark 2.6), not proved here. The term \(\E[X \mid \mathcal G]\), with \(\mathcal G\) defined in §1, extends the elementary conditional expectation of M4 and does not redefine it. Lab 1 checks them.
1Information, partitions and the L2 setting
Let \(\Omega\) be finite, with weights \(p(\omega) > 0\) that sum to 1. The expectation of a function \(X\) on \(\Omega\) is \(\E[X] = \sum_\omega X(\omega)\,p(\omega)\). Every real function on \(\Omega\) is a random variable. For two random variables, \(\E[XY]\) is their average product. The pairing \((X, Y) \mapsto \E[XY]\) is an inner product in the plain sense, a symmetric, linear pairing that is positive on \(X\) with \(X \ne 0\). Two random variables are called orthogonal when \(\E[XY] = 0\). The mean squared error between \(X\) and \(Y\) is \(\E[(X - Y)^2]\), which is the squared distance under this pairing. Because \(\Omega\) is finite, every random variable has finite second moment, so every function here is square-integrable (its second moment is finite; the space of such functions is written L2).
A partition of \(\Omega\) is a family of disjoint nonempty cells \(B_1, \dots, B_m\) whose union is \(\Omega\). Each cell is assumed to have \(\Prob(B_j) = \sum_{\omega \in B_j} p(\omega) > 0\). The sub-\(\sigma\)-algebra \(\mathcal G\) generated by the partition consists of all unions of cells. An event in \(\mathcal G\) is one that the information reveals: knowing the information tells you which cell occurred. A function \(Z\) is \(\mathcal G\)-measurable when every level set \(\{Z = z\}\) is in \(\mathcal G\), which means that \(Z\) reveals no more than the cells do.
Proposition 1.1 (the measurable functions are the cell-constant functions)
Assumptions.
\(\Omega\) is finite and \(\mathcal G\) is generated by a partition of \(\Omega\) into cells, as above.
\(Z\) is a real function on \(\Omega\).
Statement. \(Z\) is \(\mathcal G\)-measurable if and only if \(Z\) is constant on each cell. In that case \(Z = \sum_j c_j \indic_{B_j}\), where \(c_j\) is the value of \(Z\) on \(B_j\).
Proof
Suppose \(Z\) is \(\mathcal G\)-measurable and \(\omega \in B_j\). The level set \(\{Z = Z(\omega)\}\) contains \(\omega\) and lies in \(\mathcal G\), so it is a union of cells. The cell that contains \(\omega\) is one of those cells, and so it lies inside the level set. Therefore \(Z\) equals \(Z(\omega)\) on all of \(B_j\). Conversely, if \(Z\) is constant on each cell, each level set \(\{Z = z\}\) is a union of cells, so it lies in \(\mathcal G\). The last sentence follows because the cells are disjoint and cover \(\Omega\).
2The conditional expectation as a projection
Definition 2.1 (conditional expectation in L2)
Let \(X\) be a random variable on \(\Omega\) and \(\mathcal G\) generated by a partition, as in §1. The conditional expectation of \(X\) given \(\mathcal G\) in L2, written \(\E[X \mid \mathcal G]\), is the \(\mathcal G\)-measurable random variable \(Y\) that minimizes \(\E[(X - Y)^2]\) over all \(\mathcal G\)-measurable \(Y\). Theorem 2.2 shows that such a \(Y\) exists, that it is unique, and that it is the orthogonal projection of \(X\) onto the \(\mathcal G\)-measurable functions. Here "orthogonal" means that the residual \(X - Y\) has \(\E[(X - Y)Z] = 0\) for every \(\mathcal G\)-measurable \(Z\).
Theorem 2.2 (cell-average formula and the projection property)
Assumptions.
\(\Omega\) is finite, with weights \(p(\omega) > 0\) that sum to 1.
\(\mathcal G\) is generated by a partition \(B_1, \dots, B_m\) of \(\Omega\) with \(\Prob(B_j) > 0\) for each \(j\).
\(X\) is a random variable on \(\Omega\).
Statement. Define \(Y(\omega) = \E[X\indic_{B_j}]/\Prob(B_j)\) for \(\omega \in B_j\). Then (a) \(Y\) is \(\mathcal G\)-measurable and minimizes \(\E[(X - Y')^2]\) over \(\mathcal G\)-measurable \(Y'\), with the minimizer unique; (b) \(Y\) is the only \(\mathcal G\)-measurable function with \(\E[(X - Y)Z] = 0\) for every \(\mathcal G\)-measurable \(Z\).
Proof
Orthogonality. \(Y\) is constant on each cell, so it is \(\mathcal G\)-measurable by Proposition 1.1. Let \(Z\) be \(\mathcal G\)-measurable, so \(Z = \sum_j c_j \indic_{B_j}\). Write \(Y_j\) for the value of \(Y\) on \(B_j\), so that \(Y_j \Prob(B_j) = \E[X\indic_{B_j}]\) by the definition of \(Y\). Then
\[
\E[(X - Y)Z] = \sum_j c_j\, \E[(X - Y)\indic_{B_j}] = \sum_j c_j \big(\E[X\indic_{B_j}] - Y_j \Prob(B_j)\big) = 0.
\]
Pythagoras. Let \(Y'\) be \(\mathcal G\)-measurable and put \(D = Y - Y'\), which is \(\mathcal G\)-measurable. Then \(X - Y' = (X - Y) + D\), and so \(\E[(X - Y')^2] = \E[(X - Y)^2] + 2\,\E[(X - Y)D] + \E[D^2]\). The middle term is zero by the orthogonality just shown, so \(\E[(X - Y')^2] = \E[(X - Y)^2] + \E[D^2]\). Hence \(\E[(X - Y')^2] \ge \E[(X - Y)^2]\), with equality only if \(\E[D^2] = \sum_\omega D(\omega)^2 p(\omega) = 0\). Since every \(p(\omega) > 0\), this forces \(D = 0\), so \(Y' = Y\). This proves (a).
Uniqueness of the orthogonal solution. Let \(Y'\) be \(\mathcal G\)-measurable with \(\E[(X - Y')Z] = 0\) for every \(\mathcal G\)-measurable \(Z\). Take \(Z = Y - Y'\), which is \(\mathcal G\)-measurable. Then \(\E[(X - Y')(Y - Y')] = 0\) and \(\E[(X - Y)(Y - Y')] = 0\). Subtracting, \(\E[(Y - Y')^2] = 0\), so \(Y = Y'\) because every \(p(\omega) > 0\). This proves (b).
Remark 2.3 (what the uniqueness step needs)
The theorem assumes \(p(\omega) > 0\) at every point, and the proof uses that assumption to pass from \(\E[D^2] = 0\) to \(D = 0\). The proof needs less. Every \(\mathcal G\)-measurable function is constant on each cell, so \(D\) takes one value \(d_j\) on each cell \(B_j\), and \(\E[D^2] = \sum_j d_j^2\,\Prob(B_j)\). When \(\Prob(B_j) > 0\) for every cell, \(\E[D^2] = 0\) forces every \(d_j = 0\), so \(D = 0\) at every point, including a point of zero weight (a case the theorem excludes by its assumption \(p(\omega) > 0\)). The cell-probability assumption \(\Prob(B_j) > 0\) is needed for the average \(\E[X\indic_{B_j}]/\Prob(B_j)\) to be defined.
Proposition 2.4 (the tower property for nested partitions)
Assumptions.
\(\Omega\) is finite, with weights \(p(\omega) > 0\) that sum to 1, and \(\Prob(B) > 0\) for each cell used.
\(\mathcal G\) is generated by a partition \(\{B_j\}\), and \(\mathcal H\) is generated by a coarser partition \(\{C_i\}\), so that each \(C_i\) is a union of cells \(B_j\).
\(X\) is a random variable on \(\Omega\).
Statement. \(\E\big[\E[X \mid \mathcal G] \mid \mathcal H\big] = \E[X \mid \mathcal H]\). Taking \(\mathcal H\) to be the trivial partition \(\{\Omega\}\), \(\E\big[\E[X \mid \mathcal G]\big] = \E[X]\).
Proof
Let \(Y = \E[X \mid \mathcal G]\), so \(Y_j \Prob(B_j) = \E[X\indic_{B_j}]\). Fix a cell \(C_i\) of \(\mathcal H\), and let \(J\) be the set of indices \(j\) with \(B_j \subseteq C_i\). Then \(C_i\) is the disjoint union of the \(B_j\) with \(j \in J\). By Theorem 2.2 applied to \(\mathcal H\), \(\E[Y \mid \mathcal H]\) on \(C_i\) equals \(\E[Y\indic_{C_i}]/\Prob(C_i)\), and
\[
\E[Y\indic_{C_i}] = \sum_{j \in J} Y_j\,\Prob(B_j) = \sum_{j \in J} \E[X\indic_{B_j}] = \E[X\indic_{C_i}].
\]
So \(\E[Y \mid \mathcal H]\) equals \(\E[X\indic_{C_i}]/\Prob(C_i)\) on \(C_i\), which is \(\E[X \mid \mathcal H]\) on \(C_i\). For the trivial partition, \(\E[Y]\) is \(\E[Y\indic_\Omega]/\Prob(\Omega) = \E[X\indic_\Omega] = \E[X]\), using \(\Prob(\Omega) = 1\).
Remark 2.5 (the order of the nested conditioning)
Proposition 2.4 conditions on the finer \(\mathcal G\) first and then on the coarser \(\mathcal H\). The result is the coarser conditional expectation, \(\E[X \mid \mathcal H]\), not \(\E[X \mid \mathcal G]\). Part D of Lab 1 checks this on the two cells of \(\mathcal H\).
Remark 2.6 (the general definition; not proved here)
On a general probability space, with \(\mathcal G\) a sub-\(\sigma\)-algebra and \(X\) integrable, the conditional expectation is a \(\mathcal G\)-measurable \(Y\) with \(\E[X\indic_A] = \E[Y\indic_A]\) for every \(A \in \mathcal G\). Assumption CE below states this, and it is not proved here. A route to the general case applies Assumption RN (L06), which is stated for \(\sigma\)-finite measures, to \(A \mapsto \E[X\indic_A]\) on \(\mathcal G\) when \(X \ge 0\); this page does not carry out that step or the extension to a general integrable \(X\). Under Assumption CE, the finite cell average of Theorem 2.2 is the special case in which \(\mathcal G\) is generated by a partition. The finite theorem in this lesson does not depend on Assumption CE.
Assumption CE (not proved here): for integrable \(X\) and a sub-\(\sigma\)-algebra \(\mathcal G\), there is a \(\mathcal G\)-measurable \(Y\) with \(\E[X\indic_A] = \E[Y\indic_A]\) for all \(A \in \mathcal G\), unique up to a set of probability zero.
Lab 1 · Cell averages, the L2 projection, and the tower property
The inputs are a fixed probability space with eight outcomes and integer values of \(X\), not data. No random draws are used. Part A prints the cell averages on the partition \(\{0,1,2\}\), \(\{3,4\}\), \(\{5,6,7\}\). Part B solves the normal equations for the projection onto the span of three functions that span the \(\mathcal G\)-measurable functions, and checks that the projection equals the cell averages and that the residual is orthogonal to each spanning function. Part C computes the mean squared error of the cell averages and of 125 cell-constant functions, and checks that no candidate has a smaller error. Part D checks the tower property and the total expectation. Before running, the expected result is that every flag prints True, and that no one of the 125 candidates has a smaller error than the cell average.
"""M6 L07 lab 1: conditional expectation on a finite space as the L2 projection onto partition-measurable functions.
Inputs are a fixed finite probability space with eight outcomes, not data, and no random draws are used.
The sigma-algebra G is generated by the partition {0,1,2}, {3,4}, {5,6,7} of the outcomes.
Part A: the cell-average formula E[X | G] = E[X 1_B] / P(B) on each cell B.
Part B: the L2 projection of X onto the span of three functions that span the G-measurable functions, found by
solving the normal equations exactly; it is compared with Part A, and the residual is checked to be orthogonal to
each spanning function.
Part C: the mean squared error E[(X - Y)^2] of the cell averages and of all 125 cell-constant functions whose cell
values lie in {-2, -1, 0, 1, 2}. No function among these 125 has a smaller error than the cell average.
Part D: the tower property for the coarser sigma-algebra H generated by {0,1,2,3,4}, {5,6,7}, and the identity
E[E[X | G]] = E[X].
Every probability, value and projection is a Fraction, so every equality test is exact.
"""
from fractions import Fraction
from itertools import product
P = tuple(Fraction(n, 16) for n in (1, 2, 1, 3, 2, 3, 2, 2))
X = tuple(Fraction(v) for v in (2, -1, 4, 0, 3, -2, 1, 5))
CELLS = ((0, 1, 2), (3, 4), (5, 6, 7))
COARSE = ((0, 1, 2, 3, 4), (5, 6, 7))
def expect(values: tuple[Fraction, ...], event: tuple[int, ...]) -> Fraction:
"""The expectation of `values` times the indicator of `event`, a set of outcome indices."""
return sum((P[w] * values[w] for w in event), Fraction(0))
def prob(event: tuple[int, ...]) -> Fraction:
"""The probability of an event, a set of outcome indices."""
return sum((P[w] for w in event), Fraction(0))
def cell_average(cells: tuple[tuple[int, ...], ...]) -> tuple[Fraction, ...]:
"""The function that equals E[X 1_B] / P(B) on each cell B and is constant on cells."""
out = [Fraction(0)] * len(P)
for cell in cells:
value = expect(X, cell) / prob(cell)
for w in cell:
out[w] = value
return tuple(out)
def solve(matrix: list[list[Fraction]], rhs: list[Fraction]) -> list[Fraction]:
"""Solve a small square linear system by Gaussian elimination in exact arithmetic."""
n = len(rhs)
rows = [[*row, rhs[i]] for i, row in enumerate(matrix)]
for col in range(n):
pivot = next(r for r in range(col, n) if rows[r][col] != 0)
rows[col], rows[pivot] = rows[pivot], rows[col]
for r in range(n):
if r != col and rows[r][col] != 0:
factor = rows[r][col] / rows[col][col]
rows[r] = [a - factor * b for a, b in zip(rows[r], rows[col], strict=True)]
return [rows[i][n] / rows[i][i] for i in range(n)]
def mse(y: tuple[Fraction, ...]) -> Fraction:
"""The mean squared error E[(X - Y)^2] of a function Y."""
return sum((P[w] * (X[w] - y[w]) ** 2 for w in range(len(P))), Fraction(0))
def part_a() -> tuple[Fraction, ...]:
"""Print the cell averages and return them."""
average = cell_average(CELLS)
print("Part A: cell averages E[X | G] = E[X 1_B] / P(B)")
for cell in CELLS:
print(f"cell {cell} prob {prob(cell)} average {expect(X, cell) / prob(cell)}")
return average
def part_b(average: tuple[Fraction, ...]) -> None:
"""Solve the normal equations for the projection onto span{1, 1_{B1}, 1_{B1 u B2}} and compare."""
basis = [
tuple(Fraction(1) for _ in P),
tuple(Fraction(1) if w in CELLS[0] else Fraction(0) for w in range(len(P))),
tuple(Fraction(1) if w in CELLS[0] + CELLS[1] else Fraction(0) for w in range(len(P))),
]
gram = [
[expect(tuple(a * b for a, b in zip(u, v, strict=True)), tuple(range(len(P)))) for v in basis] for u in basis
]
rhs = [expect(tuple(a * x for a, x in zip(u, X, strict=True)), tuple(range(len(P)))) for u in basis]
coef = solve(gram, rhs)
projection = tuple(sum((c * u[w] for c, u in zip(coef, basis, strict=True)), Fraction(0)) for w in range(len(P)))
print("Part B: L2 projection by normal equations")
print("coefficients " + " ".join(str(c) for c in coef))
print(f"projection_equals_cell_average {projection == average}")
residual = tuple(x - y for x, y in zip(X, projection, strict=True))
orthogonal = [expect(tuple(r * b for r, b in zip(residual, u, strict=True)), tuple(range(len(P)))) for u in basis]
print("residual_inner_products " + " ".join(str(v) for v in orthogonal))
print(f"residual_orthogonal {all(v == 0 for v in orthogonal)}")
def part_c(average: tuple[Fraction, ...]) -> None:
"""Enumerate the 125 cell-constant functions with values in {-2,...,2} and compare their errors."""
values = (-2, -1, 0, 1, 2)
errors = []
for triple in product(values, repeat=len(CELLS)):
y = [Fraction(0)] * len(P)
for cell, v in zip(CELLS, triple, strict=True):
for w in cell:
y[w] = Fraction(v)
errors.append(mse(tuple(y)))
best = mse(average)
print("Part C: mean squared error over cell-constant functions")
print(f"candidates_checked {len(errors)}")
print(f"average_mse {best} = {float(best):.10f}")
print(f"average_mse_is_minimum {all(best <= e for e in errors)}")
print(f"candidates_with_equal_mse {sum(1 for e in errors if e == best)}")
def part_d(average: tuple[Fraction, ...]) -> None:
"""Check E[E[X|G] | H] = E[X|H] on each H-cell, and E[E[X|G]] = E[X]."""
print("Part D: tower property and the total expectation")
for cell in COARSE:
lhs = expect(average, cell) / prob(cell)
rhs = expect(X, cell) / prob(cell)
print(f"coarse_cell {cell} lhs {lhs} rhs {rhs} equal {lhs == rhs}")
everything = tuple(range(len(P)))
print(f"total_expectation_equal {expect(average, everything) == expect(X, everything)}")
def main() -> None:
"""Print Parts A to D."""
average = part_a()
part_b(average)
part_c(average)
part_d(average)
main()

Part A prints the three cell averages \(1\), \(6/5\) and \(6/7\), which are exact fractions. Part B prints the coefficients \(6/7\), \(-1/5\) and \(12/35\) of the projection, with the flag projection_equals_cell_average True, and it prints residual inner products 0, 0 and 0. Part C prints the mean squared error \(767/140 = 5.4785714286\) of the cell averages and the flag average_mse_is_minimum True over the 125 candidates. The count of candidates with equal error is 0. A candidate with the same error as the average would be a second minimizer over all \(\mathcal G\)-measurable functions, which Theorem 2.2(a) excludes, so it would equal the average at every point. The second and third cell averages, \(6/5\) and \(6/7\), are not integers, so the average is not one of the 125 integer-valued functions. Part D prints True for both coarse cells and for the total expectation. The lab shows these identities for the stated space only. It does not test any infinite space. It checks 125 candidates, not all \(\mathcal G\)-measurable functions, so it does not show the minimum over the full set; Theorem 2.2(a) proves that the cell average is the unique minimizer over all \(\mathcal G\)-measurable functions.
3Where the canon breaks
A cell of zero probability. The cell average \(\E[X\indic_B]/\Prob(B)\) is undefined when \(\Prob(B) = 0\). Theorem 2.2 assumes every cell has positive probability.
Zero-weight points. The theorem assumes \(p(\omega) > 0\) at every point. Remark 2.3 shows that the uniqueness argument needs only \(\Prob(B_j) > 0\) for each cell, because a \(\mathcal G\)-measurable function is constant on each cell.
A different loss. Theorem 2.2 minimizes the squared error. This lesson does not treat other loss functions, and it makes no claim about them.
The general case. On a general space the sub-\(\sigma\)-algebra need not be generated by a partition, and the general definition is Assumption CE (Remark 2.6), which is not proved here. The finite proof does not cover that case.
4Misconceptions
“\(\E[X \mid \mathcal G]\) is a single number.”
It is a random variable, constant on each cell and generally different on different cells. Part A prints a separate average for each of the three cells, 1, 6/5 and 6/7.
“The conditional expectation is the value of \(X\) at the outcome that occurred.”
It is the average of \(X\) over the cell that contains the outcome. In cell \(\{0,1,2\}\), the values of \(X\) are 2, \(-1\) and 4, with probabilities 1/16, 2/16 and 1/16. The conditional expectation there is the weighted average \((2\cdot 1 - 1\cdot 2 + 4\cdot 1)/4 = 1\) (Part A). It is not any one of those values.
“Conditioning on the finer information and then on the coarser gives the finer answer: \(\E[\E[X \mid \mathcal G] \mid \mathcal H] = \E[X \mid \mathcal G]\).”
Proposition 2.4 gives \(\E[X \mid \mathcal H]\), the coarser answer. Part D of Lab 1 checks the two coarse cells, where the coarser answers are 10/9 and 6/7.

Mechanics
M1 · The cell average on four points
Let \(\Omega = \{1,2,3,4\}\) with \(p(\omega) = 1/4\), \(X = (1, 2, 3, 6)\), and the partition \(\{1,2\}, \{3,4\}\). Find \(\E[X \mid \mathcal G]\).
Solution
On \(\{1,2\}\), the average is \((1 + 2)/2 = 3/2\). On \(\{3,4\}\), it is \((3 + 6)/2 = 9/2\). So \(\E[X \mid \mathcal G] = (3/2, 3/2, 9/2, 9/2)\). Check: \(\E[(X - Y)\indic_{\{1,2\}}] = (1 - 3/2)/4 + (2 - 3/2)/4 = 0\), and the same holds on \(\{3,4\}\).
M2 · The total expectation
For the function of M1, compute \(\E[X]\) and \(\E[\E[X \mid \mathcal G]]\).
Solution
\(\E[X] = (1 + 2 + 3 + 6)/4 = 3\). The conditional expectation has values \(3/2, 3/2, 9/2, 9/2\), so its average is \((3/2 + 3/2 + 9/2 + 9/2)/4 = 12/4 = 3\). The two agree, as Proposition 2.4 states for the trivial partition.
M3 · The mean squared error of the projection
For M1, compute \(\E[(X - Y)^2]\) with \(Y = \E[X \mid \mathcal G]\), and compare it with \(\E[(X - 3)^2]\), where 3 is the constant \(\E[X]\).
Solution
The residuals \(X - Y\) are \((-1/2, 1/2, -3/2, 3/2)\), whose squares are \(1/4, 1/4, 9/4, 9/4\). Their average is \((1/4 + 1/4 + 9/4 + 9/4)/4 = 5/4\). For the constant, the residuals are \((-2, -1, 0, 3)\), with squares \(4, 1, 0, 9\), and the average is \(14/4 = 7/2\). The difference \(7/2 - 5/4 = 9/4\) equals \(\E[(Y-3)^2]\), which is the Pythagoras identity of Theorem 2.2 in this case.

P1 · Uniqueness of the orthogonal solution
Let \(Y'\) be \(\mathcal G\)-measurable with \(\E[(X - Y')Z] = 0\) for every \(\mathcal G\)-measurable \(Z\). Show that \(Y' = \E[X \mid \mathcal G]\).
Solution
Take \(Z = Y - Y'\), which is \(\mathcal G\)-measurable because both \(Y\) and \(Y'\) are. The hypothesis gives \(\E[(X - Y')(Y - Y')] = 0\). Theorem 2.2(b) gives \(\E[(X - Y)(Y - Y')] = 0\). Subtracting the second from the first, \(\E[(Y - Y')(Y - Y')] = 0\), that is \(\E[(Y - Y')^2] = 0\). Every weight is positive, so \(Y = Y'\) at every point.
P2 · The Pythagoras identity
Let \(D\) be \(\mathcal G\)-measurable and \(Y = \E[X \mid \mathcal G]\). Show that \(\E[(X - Y - D)^2] = \E[(X - Y)^2] + \E[D^2]\).
Solution
Expanding the square, \(\E[(X - Y - D)^2] = \E[(X - Y)^2] - 2\,\E[(X - Y)D] + \E[D^2]\). Since \(D\) is \(\mathcal G\)-measurable, Theorem 2.2 gives \(\E[(X - Y)D] = 0\). The identity follows.
P3 · The trivial partition
Show that \(\E[X \mid \{\Omega\}] = \E[X]\), the constant function, from the cell-average formula of Theorem 2.2.
Solution
The partition has one cell \(\Omega\), with \(\Prob(\Omega) = 1\). The formula gives \(Y(\omega) = \E[X\indic_\Omega]/\Prob(\Omega) = \E[X]\) for every \(\omega\), which is constant. So \(\E[X \mid \{\Omega\}]\) is the constant \(\E[X]\).
Empirical
E1 · One cell average from Part A
In Lab 1, the outcomes with code indices 3 and 4 (counted from 0) have probabilities 3/16 and 2/16, and values \(X(3) = 0\) and \(X(4) = 3\). Verify the printed average 6/5 on the cell \(\{3,4\}\).
Solution
The cell probability is \(3/16 + 2/16 = 5/16\), as Part A prints. The integral over the cell is \(0 \cdot 3/16 + 3 \cdot 2/16 = 6/16\). The ratio is \((6/16)/(5/16) = 6/5\), which is the printed average.
E2 · The projection value on the first cell
Part B prints the coefficients \(6/7\), \(-1/5\) and \(12/35\). Show that the projection equals 1 on the cell \(\{0,1,2\}\).
Solution
The spanning functions are \(1\), \(\indic_{\{0,1,2\}}\), and \(\indic_{\{0,1,2,3,4\}}\). On \(\{0,1,2\}\) each equals 1, 1 and 1, so the projection is \(6/7 - 1/5 + 12/35\). With denominator 35, this is \((30 - 7 + 12)/35 = 35/35 = 1\), which equals the cell average printed in Part A.
E3 · Why no candidate ties
Part C prints 0 candidates with the same error as the cell average. Explain why.
Solution
The candidates have integer values on the three cells. The cell averages are 1, 6/5 and 6/7. Only the first is an integer, and the second and third are not, so the average function is not among the 125 candidates. A candidate with the same error as the average would be a second minimizer over all \(\mathcal G\)-measurable functions. Theorem 2.2(a) excludes a second minimizer, so such a candidate would equal the average at every point. The average is not integer-valued, so no candidate qualifies, and the count of ties is 0. The printed minimality flag concerns the 125 candidates only.

R1 · The two extreme partitions
Show that if \(\mathcal G\) is the full power set of \(\Omega\) (each point is a cell), then \(\E[X \mid \mathcal G] = X\). Show also that for the trivial partition the answer is \(\E[X]\), as in P3.
Solution
With singleton cells, \(\Prob(\{\omega\}) = p(\omega) > 0\), and the cell average is \(\E[X\indic_{\{\omega\}}]/p(\omega) = X(\omega)p(\omega)/p(\omega) = X(\omega)\). So the conditional expectation is \(X\). The trivial case is P3. On a general partition, the conditional expectation is \(X\) averaged over each cell.
R2 · Linearity
Let \(X\) and \(X'\) be random variables and \(a, b\) real numbers. Show that \(\E[aX + bX' \mid \mathcal G] = a\,\E[X \mid \mathcal G] + b\,\E[X' \mid \mathcal G]\).
Solution
The cell average is linear in the function, because \(\E[(aX + bX')\indic_B] = a\,\E[X\indic_B] + b\,\E[X'\indic_B]\) and dividing by \(\Prob(B)\) preserves the sum. The right side is \(\mathcal G\)-measurable, and it has the cell averages of \(aX + bX'\) on each cell. By the uniqueness in Theorem 2.2, it is the conditional expectation.
R3 · Where a point of zero weight would matter
Suppose one point \(\omega_0\) has \(p(\omega_0) = 0\), but every cell still has positive probability. Does the uniqueness in Theorem 2.2(b) still hold at \(\omega_0\)? Explain, using that every \(\mathcal G\)-measurable function is constant on each cell.
Solution
Yes, by the argument of Remark 2.3, which needs only \(\Prob(B_j) > 0\) for each cell. Theorem 2.2 as stated assumes \(p(\omega) > 0\) at every point, so its uniqueness step does not apply here as written. Let \(\omega_0\) lie in the cell \(B\). Every \(\mathcal G\)-measurable function is constant on \(B\), so its value at \(\omega_0\) equals its value at any point of \(B\) with positive weight, and such a point exists because \(\Prob(B) > 0\). The uniqueness step gives \(\E[(Y - Y')^2] = 0\), which for \(D = Y - Y'\) means \(\sum_j d_j^2 \Prob(B_j) = 0\). Hence every \(d_j = 0\), and \(Y'(\omega_0) = Y(\omega_0)\). A zero-weight point would be undetermined only if it formed a cell by itself, and such a cell has probability zero, which the assumption excludes.
