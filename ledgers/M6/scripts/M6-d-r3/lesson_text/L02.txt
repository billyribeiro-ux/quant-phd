 Lesson 1 says which subsets are events. This lesson says how large they are. A measure assigns a non-negative size to each event, and a probability measure assigns sizes that total one. The axioms are short, but they fix the arithmetic that the unit uses for probabilities: a probability never falls when an event grows, disjoint events add, and the probability of an increasing union is the limit of the probabilities. The finite case shows the axioms in their simplest form. When every subset of a finite space is an event, every probability on that space is a sum of point weights.
 1Measures and probability spaces
 Let \(\mathcal F\) be a σ-algebra on \(\Omega\), as defined in Lesson 1. A measure is a rule that assigns a number to each event. Numbers here are non-negative and may be infinite, with \(a + \infty = \infty\) for every \(a\) in \([0, \infty]\).
 Definition 1.1 (measure)
 Let \(\mathcal F\) be a σ-algebra on \(\Omega\). A measure on \((\Omega, \mathcal F)\) is a function \(\mu : \mathcal F \to [0, \infty]\) such that
 (M1) \(\mu(\emptyset) = 0\);
 (M2) if \(A_1, A_2, \dots\) is a countable sequence of pairwise disjoint events, then \(\mu\bigl(\bigcup_n A_n\bigr) = \sum_n \mu(A_n)\). The sum of non-negative terms is taken in \([0, \infty]\).
 Property (M2) is countable additivity. Its finite case, finite additivity, is proved below as Proposition 1.3(a) from (M1) and (M2).
 Definition 1.2 (probability space)
 A probability space is a triple \((\Omega, \mathcal F, \Prob)\), where \(\mathcal F\) is a σ-algebra on \(\Omega\) and \(\Prob\) is a measure on \((\Omega, \mathcal F)\) with \(\Prob(\Omega) = 1\). The function \(\Prob\) is a probability measure, and \(\Prob(A)\) is the probability of the event \(A\).
 Proposition 1.3 (the basic properties of a measure)
 Assumptions.
 \((\Omega, \mathcal F)\) is a σ-algebra, and \(\mu\) is a measure on it (Definition 1.1).
 \(A, B, A_1, A_2, \dots\) are events.
 Statement.
 (a) (finite additivity) If \(A_1, \dots, A_m\) are pairwise disjoint events, then \(\mu\bigl(\bigcup_{i \le m} A_i\bigr) = \sum_{i \le m} \mu(A_i)\).
 (b) (monotonicity) If \(A \subseteq B\), then \(\mu(A) \le \mu(B)\).
 (c) (countable subadditivity) \(\mu\bigl(\bigcup_n A_n\bigr) \le \sum_n \mu(A_n)\).
 (d) (continuity from below) If \(A_1 \subseteq A_2 \subseteq \cdots\) and \(A = \bigcup_n A_n\), then \(\mu(A_n) \to \mu(A)\) as \(n \to \infty\).
 Proof
 (a) Put \(A_n = \emptyset\) for \(n > m\). These are pairwise disjoint events, and \(\emptyset\) is an event by Lesson 1, Proposition 1.3(a). By (M2) and (M1), \(\mu\bigl(\bigcup_{i \le m} A_i\bigr) = \sum_{i \le m} \mu(A_i) + \sum_{i > m} 0\), which is the claim.
 (b) Write \(B\) as the disjoint union of \(A\) and \(B \setminus A = B \cap A^c\). The set \(B \setminus A\) is an event, because an intersection of two events is an event (Lesson 1, Proposition 1.3(b)). By (a), \(\mu(B) = \mu(A) + \mu(B \setminus A) \ge \mu(A)\).
 (c) Put \(D_1 = A_1\) and \(D_n = A_n \cap \bigl(A_1 \cup \dots \cup A_{n-1}\bigr)^c\) for \(n \ge 2\). Each \(D_n\) is an event, the \(D_n\) are pairwise disjoint, and \(\bigcup_n D_n = \bigcup_n A_n\). Since \(D_n \subseteq A_n\), (b) gives \(\mu(D_n) \le \mu(A_n)\), and (M2) gives \(\mu\bigl(\bigcup_n A_n\bigr) = \sum_n \mu(D_n) \le \sum_n \mu(A_n)\).
 (d) Put \(D_1 = A_1\) and \(D_n = A_n \setminus A_{n-1}\) for \(n \ge 2\). These are events, pairwise disjoint, and \(\bigcup_{n \le N} D_n = A_N\) for each \(N\), because the sets are nested. By (M2) and (a), \(\mu(A) = \sum_n \mu(D_n)\), and \(\sum_{n \le N} \mu(D_n) = \mu(A_N)\). The sum of a series of non-negative terms is the limit of its partial sums, so \(\mu(A_N) \to \mu(A)\). \(\blacksquare\)
 Remark 1.4 (where countable additivity is used)
 Part (a) derives finite additivity from (M2) applied to a sequence padded with empty sets, and part (b) uses only (a). Parts (c) and (d) use (M2) for a genuinely infinite sequence, in the steps \(\mu\bigl(\bigcup_n A_n\bigr) = \sum_n \mu(D_n)\) and \(\mu(A) = \sum_n \mu(D_n)\). The page does not construct a measure that satisfies the finite case and fails (d); no such example is proved here.
 Proposition 1.5 (probabilities lie in [0, 1])
 Assumptions. \((\Omega, \mathcal F, \Prob)\) is a probability space (Definition 1.2), and \(A\) is an event.
 Statement. (a) \(\Prob(A^c) = 1 - \Prob(A)\). (b) \(0 \le \Prob(A) \le 1\).
 Proof
 (a) The sets \(A\) and \(A^c\) are disjoint events with union \(\Omega\). By Proposition 1.3(a), \(\Prob(A) + \Prob(A^c) = \Prob(\Omega) = 1\), which rearranges to the claim. (b) The lower bound holds because \(\Prob\) takes values in \([0, \infty]\). The upper bound holds because \(A \subseteq \Omega\), so \(\Prob(A) \le \Prob(\Omega) = 1\) by Proposition 1.3(b). \(\blacksquare\)
 Example 1.6 (a fair die)
 Let \(\Omega = \{1, 2, 3, 4, 5, 6\}\) with \(\mathcal F\) the collection of all subsets, and let \(\Prob(A) = |A|/6\), where \(|A|\) is the number of members of \(A\). Then \((\Omega, \mathcal F, \Prob)\) is a probability space: \(\Prob(\emptyset) = 0\), \(\Prob(\Omega) = 1\), and the count of members of a disjoint union is the sum of the counts. The event "the outcome is even" is \(\{2, 4, 6\}\), with probability \(3/6 = 1/2\).
 2Probability on a finite sample space
 When \(\Omega\) is finite and \(\mathcal F\) is the collection of all subsets, a probability measure is determined by the probability of each single outcome. That is the content of the next proposition.
 Proposition 2.1 (probability measures on a finite set)
 Assumptions.
 \(\Omega = \{\omega_1, \dots, \omega_n\}\) is finite, and \(\mathcal F\) is the collection of all subsets of \(\Omega\).
 Statement. (a) If \(p(\omega) \ge 0\) for each \(\omega\) and \(\sum_{\omega} p(\omega) = 1\), then \(\Prob(A) = \sum_{\omega \in A} p(\omega)\) defines a probability measure on \((\Omega, \mathcal F)\). (b) Every probability measure \(\Prob\) on \((\Omega, \mathcal F)\) is of this form, with \(p(\omega) = \Prob(\{\omega\})\).
 Proof
 (a) The empty sum is \(0\), which gives (M1). For (M2), let \(A_1, A_2, \dots\) be pairwise disjoint subsets of \(\Omega\). Each non-empty \(A_n\) contains a point of \(\Omega\), and the points are distinct, so only finitely many \(A_n\) are non-empty. The sum over the countable family therefore has finitely many non-zero terms, and it equals the sum of \(p\) over the union, because each point of the union lies in exactly one \(A_n\). The total is \(\Prob(\Omega) = \sum_{\omega} p(\omega) = 1\).
 (b) Each event \(A\) is a finite disjoint union of its single outcomes. By Proposition 1.3(a), \(\Prob(A) = \sum_{\omega \in A} \Prob(\{\omega\})\). Setting \(p(\omega) = \Prob(\{\omega\})\) gives \(p \ge 0\) and \(\sum_{\omega} p(\omega) = \Prob(\Omega) = 1\). \(\blacksquare\)
 Example 2.2 (a biased die and a point mass)
 Take the weights \(p(1) = 1/2\), \(p(2) = 1/4\), \(p(3) = 1/8\), \(p(4) = 1/16\), \(p(5) = p(6) = 1/32\). They are non-negative and sum to \(1\), so by Proposition 2.1(a) they define a probability measure. The event \(\{1, 2\}\) has probability \(3/4\). A second example puts all the weight on \(1\): then \(\Prob(\{2\}) = 0\), so the non-empty event \(\{2\}\) has probability zero.
 Example 2.3 (a function that is not a measure)
 On the six-point set, let \(\nu(A) = (|A|/6)^2\). Then \(\nu(\Omega) = 1\) and every value lies in \([0, 1]\), but \(\nu\) is not additive. For the disjoint events \(\{1\}\) and \(\{2\}\), \(\nu(\{1, 2\}) = 4/36\), while \(\nu(\{1\}) + \nu(\{2\}) = 2/36\). A probability measure must be additive, so \(\nu\) is not one.

A finite check establishes the finite case only; the general case is proved on the page, not checked here.

from __future__ import annotations
from collections.abc import Callable
from fractions import Fraction
from itertools import combinations
from typing import NamedTuple
Subset = frozenset[int]
SetFunction = Callable[[Subset], Fraction]
OMEGA: Subset = frozenset(range(1, 7))
def all_subsets(omega: Subset) -> list[Subset]:
 """Every subset of omega, the power set. A set with n members has 2 to the power n subsets."""
 items = sorted(omega)
 return [frozenset(c) for r in range(len(items) + 1) for c in combinations(items, r)]
def weighted(weights: dict[int, Fraction]) -> SetFunction:
 """The set function A -> sum of the weights of the members of A. Weights must be given for every point."""
 def measure(a: Subset) -> Fraction:
 return sum((weights[x] for x in a), Fraction(0))
 return measure
def squared_cardinality(a: Subset) -> Fraction:
 """The set function A -> (number of members of A divided by 6) squared, on the six-point space."""
 return Fraction(len(a), 6) ** 2
class AxiomReport(NamedTuple):
 """The result of the exhaustive axiom check of one set function on OMEGA."""
 nonnegative: bool
 total_mass_one: bool
 additive: bool
 monotone: bool
 failing_pairs: int
 disjoint_pairs: int
def check_axioms(omega: Subset, prob: SetFunction) -> AxiomReport:
 """Test the probability axioms of the finite case for prob, over every subset of omega.
 Nonnegative: prob(A) >= 0 for every subset A. Total mass one: prob(omega) equals 1. Additive: for every
 ordered pair of disjoint subsets, prob(A or B) equals prob(A) + prob(B); failing_pairs counts the pairs
 where it does not. Monotone: prob(A) <= prob(B) whenever A is contained in B. disjoint_pairs counts the
 ordered disjoint pairs tested.
 """
 subsets = all_subsets(omega)
 nonnegative = all(prob(a) >= 0 for a in subsets)
 total_mass_one = prob(omega) == 1
 monotone = True
 failing_pairs = 0
 disjoint_pairs = 0
 for a in subsets:
 for b in subsets:
 if not (a & b):
 disjoint_pairs += 1
 if prob(a | b) != prob(a) + prob(b):
 failing_pairs += 1
 if a <= b and prob(a) > prob(b):
 monotone = False
 return AxiomReport(nonnegative, total_mass_one, failing_pairs == 0, monotone, failing_pairs, disjoint_pairs)

 3Consequences for probability
 The next proposition gives two facts: the identity for two events that may overlap, and the union bound that follows from it. Each follows from Proposition 1.3.
 Proposition 3.1 (a union bound)
 Assumptions. \((\Omega, \mathcal F, \Prob)\) is a probability space, and \(A, B\) are events.
 Statement. \(\Prob(A \cup B) = \Prob(A) + \Prob(B) - \Prob(A \cap B)\). In particular, \(\Prob(A \cup B) \le \Prob(A) + \Prob(B)\).
 Proof
 The set \(A \cup B\) is the disjoint union of \(A\) and \(B \setminus A\), so \(\Prob(A \cup B) = \Prob(A) + \Prob(B \setminus A)\) by Proposition 1.3(a). The set \(B\) is the disjoint union of \(B \setminus A\) and \(A \cap B\), so \(\Prob(B \setminus A) = \Prob(B) - \Prob(A \cap B)\). Substituting gives the identity. The inequality follows because \(\Prob(A \cap B) \ge 0\). \(\blacksquare\)
 Proposition 3.1 is the arithmetic that replaces additivity for overlapping events. Misconception 2 below shows the error it prevents.
 4Where the canon breaks
 The finite picture is exact, and it is misleading in four places.
 Proposition 2.1 needs a finite space with every subset an event. Its hypotheses are that \(\Omega\) is finite and \(\mathcal F\) is the collection of all subsets. On an infinite \(\Omega\), Proposition 2.1 does not apply, and this page does not classify probability measures there.
 Continuity from below is proved from countable additivity. Proposition 1.3(d) uses (M2), and Remark 1.4 identifies where (M2) is used. The page does not give an example in which the finite part of (M2) holds and continuity fails, so none is claimed.
 A measure can take the value infinity. Definition 1.1 allows \([0, \infty]\). A probability measure cannot, because it is normalized to total mass one (Proposition 1.5).
 Probability is defined on events only. The function \(\Prob\) is defined on \(\mathcal F\). Asking for the probability of a set outside \(\mathcal F\) has no answer in this framework, as Lesson 1 showed for families that are not closed under countable unions (Example 3.1).
 5Misconceptions
 “A function from events to \([0, 1]\) that gives the whole space the value one is a probability measure.”
 The function \(\nu\) of Example 2.3 gives \(\Omega\) the value one and takes values in \([0, 1]\), yet it is not additive. Lab 2 finds 602 disjoint pairs that fail. The axioms need additivity as well as normalization.
 “The probability of \(A \cup B\) is always \(\Prob(A) + \Prob(B)\).”
 That holds for disjoint events, and for overlapping events only when the overlap has probability zero. For the fair die, \(\Prob(\{1, 2\}) + \Prob(\{2, 3\}) = 2/3\), but \(\Prob(\{1, 2\} \cup \{2, 3\}) = \Prob(\{1, 2, 3\}) = 1/2\). Proposition 3.1 gives the correction: subtract \(\Prob(\{2\}) = 1/6\). Lab 2 prints both values.
 “An event with probability zero is impossible.”
 Example 2.2 gives the non-empty event \(\{2\}\) probability zero under the point-mass measure. Probability zero says the event carries no weight in the model. It does not say the event is empty, and Lab 2 prints the value 0 for the non-empty set \(\{2\}\).

 Mechanics
 M1 · Fair-die probabilities
 For the fair die of Example 1.6, compute \(\Prob(\{1, 6\})\) and \(\Prob(\{2, 3, 5\})\).
 Solution
 The set \(\{1, 6\}\) has two members, so \(\Prob(\{1, 6\}) = 2/6 = 1/3\). The set \(\{2, 3, 5\}\) has three members, so \(\Prob(\{2, 3, 5\}) = 3/6 = 1/2\). Both values are exact fractions.
 M2 · Odd outcomes of the biased die
 For the biased die of Example 2.2, compute \(\Prob(\{1, 2\})\) and the probability that the outcome is odd.
 Solution
 By Proposition 2.1(a), \(\Prob(\{1, 2\}) = 1/2 + 1/4 = 3/4\). The odd outcomes are \(\{1, 3, 5\}\), with probability \(1/2 + 1/8 + 1/32 = 16/32 + 4/32 + 1/32 = 21/32\).
 M3 · Which axiom fails
 Let the six faces each receive weight \(3/20\). State which axioms of the finite case hold and which fails, and compute the total mass.
 Solution
 The weights are non-negative and additive, because they are point weights. The total mass is \(6 \cdot 3/20 = 18/20 = 9/10\), so normalization fails. Lab 2 prints this result for the same weights. The function is therefore not a probability measure, although it is a measure with total mass \(9/10\).
 Proof
 P1 · Monotonicity from additivity
 Prove Proposition 1.3(b) using only Proposition 1.3(a).
 Solution
 Let \(A \subseteq B\). Then \(B\) is the disjoint union of \(A\) and \(B \setminus A\), and \(B \setminus A\) is an event by Lesson 1. Finite additivity gives \(\mu(B) = \mu(A) + \mu(B \setminus A)\). Since \(\mu(B \setminus A) \ge 0\), the claim follows.
 P2 · Complements in a probability space
 Prove Proposition 1.5(a) from Proposition 1.3(a).
 Solution
 The events \(A\) and \(A^c\) are disjoint and their union is \(\Omega\). Finite additivity gives \(\Prob(A) + \Prob(A^c) = \Prob(\Omega) = 1\). Subtracting \(\Prob(A)\) from both sides gives \(\Prob(A^c) = 1 - \Prob(A)\).
 P3 · Countable subadditivity
 For any countable sequence of events \(A_n\), prove \(\Prob\bigl(\bigcup_n A_n\bigr) \le \sum_n \Prob(A_n)\), which is Proposition 1.3(c), using the sets \(D_n\) of its proof and monotonicity.
 Solution
 The sets \(D_n = A_n \cap (A_1 \cup \dots \cup A_{n-1})^c\) are events, pairwise disjoint, and have the same union as the \(A_n\). By (M2), \(\Prob(\bigcup_n A_n) = \sum_n \Prob(D_n)\). Each \(D_n\) is a subset of \(A_n\), so \(\Prob(D_n) \le \Prob(A_n)\) by monotonicity, and summing gives the bound.
 Empirical
 E1 · Where 602 comes from
 Lab 2 prints 602 of 729 failing pairs for \(\nu\). Derive the count by hand and check it against the output.
 Solution
 An ordered disjoint pair of subsets of a six-point set assigns each point to \(A\), to \(B\), or to neither, so there are \(3^6 = 729\) such pairs. Additivity fails for \(\nu\) exactly when \(|A|\) and \(|B|\) are both at least one, because the cross term \(2|A||B|/36\) is then non-zero. Pairs with an empty member are \(64 + 64 - 1 = 127\), and \(729 - 127 = 602\). The lab prints 602, which agrees with this count.
 E2 · What the finite check does not establish
 Lab 2 reports that the point-mass measure passes every check. State what that establishes and what it does not.
 Solution
 It establishes that the point-mass measure is a probability measure on the six-point space, since Proposition 2.1(a) also gives that. It does not establish any property of an infinite space, or any property that the six-point check does not test. The check is exhaustive for the six-point space and says nothing beyond it.
 E3 · Counting pairs on a four-point set
 Without running the lab, state how many ordered disjoint pairs a check on a four-point set would test.
 Solution
 Each of the four points goes to \(A\), to \(B\), or to neither, so there are \(3^4 = 81\) ordered disjoint pairs. The same argument gives \(3^6 = 729\) for the six-point set of Lab 2.
 Research
 R1 · Zero probability and impossibility
 A model states that an event of probability zero never occurs. Separate the part of this claim that follows from the axioms from the part that is a modelling convention.
 Solution
 The axioms give \(\Prob(A) = 0\) for the events that are empty, by (M1), so an empty event has probability zero. The converse is not an axiom. The claim that a non-empty event of probability zero never occurs is a modelling assumption, and Example 2.2 shows the converse fails in the model it describes.
 R2 · Where finiteness is used
 Identify the step in the proof of Proposition 2.1(a) that uses finiteness of \(\Omega\), and state what fails for an infinite \(\Omega\) without a further assumption.
 Solution
 Finiteness is used to say that only finitely many of the pairwise disjoint sets \(A_n\) are non-empty, so that the sum of \(p\) over the countable family has finitely many terms. For an infinite \(\Omega\), the family of point weights may have infinitely many non-zero terms, and the definition of \(\Prob\) by a sum over points needs a convergence statement that this lesson does not supply.
 R3 · The inclusion-exclusion identity
 Using only Proposition 1.3(a) and set operations, prove that for events \(A\), \(B\) and \(C\), \(\Prob(A \cup B) = \Prob(A) + \Prob(B) - \Prob(A \cap B)\), and state which axiom gives each step.
 Solution
 This is Proposition 3.1. The disjoint decomposition \(A \cup B = A \sqcup (B \setminus A)\) uses finite additivity, and so does \(B = (B \setminus A) \sqcup (A \cap B)\). Substituting the second into the first gives \(\Prob(A \cup B) = \Prob(A) + \Prob(B) - \Prob(A \cap B)\). The third event \(C\) is not needed for the identity, which concerns two events.
