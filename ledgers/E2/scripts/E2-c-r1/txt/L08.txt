52: When every bidder estimates the same unknown value with its own error, the bidder with the highest estimate is the one with the largest error. This lesson defines a common-value auction and proves that a winner who bids its own estimate loses money on average, which is the winner's curse. It computes the expected size of that loss exactly, and it derives the shading (Definition 1.3) that removes it. The seeded simulation in Lab 1 is SIMULATED. It checks the exact figures, and it makes no claim about real bidders.
54: 1Common values, signals and the highest signal
56: Money is in integer cents. An auction sells one unit. There are \(n\) bidders, with \(n \ge 2\), and the number \(n\) is fixed and known. The unit has one value \(V\), in cents, which is the same for every bidder. No bidder observes \(V\). Each bidder \(i\) observes a signal \(S_i\), which is an estimate of \(V\) with an error. The lesson uses the letter \(n\) for the count of bidders, and \(\varepsilon_i\) for the error in bidder \(i\)'s signal.
59: Assumption 1 (common value and signal errors)
60: The common value \(V\) is a whole number of cents, and it has any prior distribution. Each signal is \(S_i = V + \varepsilon_i\), where the errors \(\varepsilon_1, \dots, \varepsilon_n\) are independent of each other and of \(V\). Each error is uniform on the whole numbers \(-a, \dots, a\) for a fixed whole number \(a \ge 1\), in cents. The number \(a\) is called the half-width of the errors. Each error has mean 0, because the range is symmetric about 0.
64: Assumption 2 (the format and the payoff)
65: The auction is a first-price auction for one unit. The bidder with the highest bid wins, a tie goes to the lower bidder index, and the winner pays its own bid. A bidder's profit when it wins is \(V\) minus its price, in cents, and it is 0 when it loses. Bidders are risk neutral, so each one maximizes expected profit.
69: Definition 1.1 (common-value auction)
70: A common-value auction is an auction in which every bidder's payoff depends on the same unknown value \(V\), and each bidder has only a signal about it. This is the case of Assumption 1. A private-value auction, in which each bidder knows its own value, is a different model and is not analyzed here.
74: Definition 1.2 (the winner's curse)
75: The winner's curse is the fact that, in a common-value auction in which each bidder bids its own signal, the bidder who wins has a negative expected profit. The winner is the bidder whose signal is the largest. Its error is the largest of the errors, \(M\) (defined in §2), and \(\E[M] > 0\) (Proposition 2.1), so the winning signal is too high on average.
79: Definition 1.3 (bid shading)
80: Bid shading is a bid below the bidder's own signal. A shading rule has the form \(b = S - c\), where \(c\) is a whole number of cents that does not depend on the bidder's signal. The rule is a fixed offset, and this lesson does not claim that it is an equilibrium of the auction (see §4).
83: 2The winner loses money on average when it bids its signal
85: Let \(M = \max(\varepsilon_1, \dots, \varepsilon_n)\) be the largest error. The largest error is the one the winner has. Under the naive rule in which each bidder bids its signal, \(b_i = S_i\), the largest signal wins. Because every signal has the same \(V\), the largest signal is \(V + M\), and the winner is the bidder with the largest error.
88: Proposition 2.1 (the naive winner's expected profit is \(-\E[M]\))
89: Under Assumptions 1 and 2, let each bidder bid its signal. The winner's profit in cents is \(-M\), in every realization. Its expected profit is \(-\E[M]\). For \(n \ge 2\) and \(a \ge 1\), \(\E[M] > 0\), so the expected profit of the winner is strictly negative.
93: Proof
94: Each bid is \(b_i = V + \varepsilon_i\). The winner is the bidder with the largest bid, and a tie goes to the lower index. Every bid is \(V + \varepsilon_i\), so the largest bid is \(V + M\), and the winner's bid is \(V + M\) whichever bidder holds it. The winner pays \(V + M\), so its profit is \(V - (V + M) = -M\). This holds in every realization, including ties. Taking expectations gives \(-\E[M]\).
95: For the sign, \(M \ge \varepsilon_1\) in every realization, so \(\E[M] \ge \E[\varepsilon_1] = 0\). Also \(M - \varepsilon_1 \ge (\varepsilon_2 - \varepsilon_1)^{+}\), where \((x)^{+} = \max(x, 0)\), so \(\E[M] \ge \E[\varepsilon_1] + \E[(\varepsilon_2 - \varepsilon_1)^{+}] = \E[(\varepsilon_2 - \varepsilon_1)^{+}]\). The event \(\varepsilon_2 = a\) and \(\varepsilon_1 = -a\) has probability \((2a+1)^{-2} > 0\), and on it \(\varepsilon_2 - \varepsilon_1 = 2a > 0\). So \(\E[(\varepsilon_2 - \varepsilon_1)^{+}] > 0\), and \(\E[M] > 0\).
99: Proposition 2.2 (the expected largest error, in closed form)
100: Under Assumption 1, with \(F(x) = (x + a + 1)/(2a + 1)\) for whole \(x\) with \(-a \le x \le a\),
101: \[
102: \E[M] = -a + \sum_{x=-a}^{a-1} \bigl(1 - F(x)^{n}\bigr).
103: \]
107: Proof
108: Each error is at most \(a\) and at least \(-a\), so \(M\) takes whole values in \(-a, \dots, a\). Since each error is at most \(x\) with probability \(F(x)\), and the errors are independent, \(\Prob(M \le x) = F(x)^{n}\) for those \(x\). For a whole number \(m\) with \(-a \le m \le a\), the number of whole \(x\) with \(-a \le x \le a - 1\) and \(x  x\}\) in every realization. Taking expectations, \(\E[M] + a = \sum_{x=-a}^{a-1} \Prob(M > x) = \sum_{x=-a}^{a-1} (1 - F(x)^{n})\).
112: Remark 2.3 (the continuous analogue)
113: If each error were uniform on the whole interval \([-a, a]\), then \(M = -a + 2a\,U\), where \(U\) is the largest of \(n\) independent uniform draws on \([0, 1]\). The largest draw has \(\Prob(U > u) = 1 - u^{n}\), so \(\E[U] = \int_0^1 (1 - u^{n})\,du = n/(n+1)\), and \(\E[M] = -a + 2an/(n+1) = a(n-1)/(n+1)\). For \(n = 5\) and \(a = 2000\) cents this is \(4000/3 = 1333.33\) cents. The discrete model of Assumption 1 gives \(\E[M] = 85418692002000/64048012001 \approx 1333.66656253\) cents. This value is Proposition 2.2 evaluated exactly with fractions (grade T, basis: Proposition 2.2; Lab 1 Part B uses it). The two values differ by \(1333.66656253 - 1333.3333333 = 0.3332292\) cents, which rounds to 0.3332 cents; the rounded figures 1333.67 and 1333.33 differ by 0.34. This lesson does not analyze that difference beyond the two formulas.
117: Example 2.4 (two bidders, a half-width of one cent)
118: Take \(n = 2\) and \(a = 1\). Each error is \(-1\), 0 or 1 with probability 1/3 each. Then \(\Prob(M \le -1) = (1/3)^{2} = 1/9\) and \(\Prob(M \le 0) = (2/3)^{2} = 4/9\). So \(\Prob(M = -1) = 1/9\), \(\Prob(M = 0) = 3/9\) and \(\Prob(M = 1) = 5/9\), and \(\E[M] = -1/9 + 5/9 = 4/9\) cents. Part A of Lab 1 checks this by listing all nine pairs of errors.
121: 3Shading by the expected largest error removes the loss
124: Proposition 3.1 (the expected profit under a fixed shading)
125: Under Assumptions 1 and 2, let each bidder bid \(S_i - c\) for a fixed whole number \(c\) of cents. The winner's expected profit is \(c - \E[M]\). It is nonnegative exactly when \(c \ge \E[M]\).
129: Proof
130: Subtracting the same \(c\) from every signal does not change the order of the bids, so the winner is still the bidder with the largest signal, and its bid is \(V + M - c\). Its profit is \(V - (V + M - c) = c - M\). Taking expectations gives \(c - \E[M]\). This is nonnegative exactly when \(c \ge \E[M]\).
134: Remark 3.2 (the shading in whole cents)
135: The shading of Proposition 3.1 must be a whole number of cents, because a bid is a money amount. With \(\E[M] = 1333.66656253\) cents for \(n = 5\) and \(a = 2000\), the smallest whole-cent shading that makes the expected profit nonnegative is 1334. Lab 1 Part C uses 1334 cents, the rounded value, with a tie going up. Rounding down to 1333 would leave an expected profit of \(1333 - 1333.66656253 = -0.66656253\) cents per auction, which rounds to \(-0.67\) cents.

270: 4Where the canon breaks
272: The shading is not an equilibrium. Proposition 3.1 averages the winner's profit over all signal realizations. It does not condition on a bidder's own signal, and it does not condition on winning with that signal. A Bayesian–Nash equilibrium (L02) needs each bidder's best bid for each of its own signals, given the other bidders' bids. This lesson does not compute such an equilibrium.
273: Mechanism design. The auction of Assumption 2 is a mechanism in the sense of Definition 1.1 of L07, in which the messages are bids. The format is given by Assumption 2, so the lesson does not choose the rules, and it does not use the revelation principle of L07.
274: The model is narrow. The errors are independent and uniform with mean zero (Assumption 1), there is one unit, the format is first-price, and the bidders are risk neutral (Assumption 2). Proposition 2.1 needs the errors to be independent and identically distributed, and it needs \(a \ge 1\) for the strict inequality. The results of §2 and §3 are derived under these assumptions, and this lesson does not derive them for other models.
275: Real bidders. The lesson proves a result about the model. Whether bidders in real auctions overpay in this way is an empirical question. The registry does not hold a source for the empirical claim, so the lesson makes no such claim (see §9).
276: Private values. The winner's curse of Definition 1.2 needs a common value. When each bidder knows its own value, a winner's profit is not defined by the same identity, and this lesson does not analyze that case.
281: 5Misconceptions
284: “If every signal is an unbiased estimate of the value, bidding the signal is a fair bid.”
285: Each signal is unbiased for \(V\), since \(\E[S_i \mid V] = V\). But the winner is the bidder with the largest error, and its expected profit under naive bidding is \(-\E[M]
288: “Winning an auction is good news about the value.”
289: Under naive bidding, winning means that one's signal was the largest, so the winner's own signal is too high on average (\(\E[M] > 0\), Proposition 2.1), and that error is the cause of the loss. The price the winner pays equals \(V + M\), which is above \(V\) by the largest error. The winner's profit in one auction is \(-M\) cents, so its loss is \(M\) cents when \(M > 0\), and its expected loss is \(\E[M] > 0\) cents.
292: “Any positive shading removes the winner's curse.”
293: Proposition 3.1 gives an expected profit of \(c - \E[M]\). A shading below \(\E[M]\) leaves the expected profit negative. For \(n = 5\) and \(a = 2000\) cents, a shading of 1333 cents leaves \(-0.67\) cents per auction (Remark 3.2). The size of the shading matters, not only its sign.

313: Take \(n = 3\) and \(a = 1\). Find \(\E[M]\) from the closed form of Proposition 2.2.
314: Solution
315: Here \(F(-1) = 1/3\) and \(F(0) = 2/3\). Proposition 2.2 gives \(\E[M] = -1 + (1 - F(-1)^{3}) + (1 - F(0)^{3}) = -1 + (1 - 1/27) + (1 - 8/27) = -1 + 26/27 + 19/27 = -1 + 45/27 = 2/3\). 330: P1 · The winner's profit with ties
331: Show that the identity \(\text{profit} = -M\) of Proposition 2.1 holds when two bidders have the same largest signal.
332: Solution
333: If two bidders share the largest signal \(V + M\), the rule gives the win to the lower index, and the price is that common bid, \(V + M\). The winner's profit is \(V - (V + M) = -M\), the same as with no tie. The identity uses only the value of the largest bid, so it holds with or without ties.
337: P2 · The distribution of the largest error
338: Under Assumption 1, show that \(\Prob(M \le x) = F(x)^{n}\) for whole \(x\) with \(-a \le x \le a\).
339: Solution
340: The event \(M \le x\) is the event that every error is at most \(x\), that is \(\varepsilon_1 \le x, \dots, \varepsilon_n \le x\). The errors are independent, so the probability is the product \(\prod_i \Prob(\varepsilon_i \le x)\). Each factor is \(\Prob(\varepsilon_i \le x) = F(x)\), because the error is uniform on \(-a, \dots, a\) and \(F(x) = (x + a + 1)/(2a + 1)\) counts the whole numbers from \(-a\) to \(x\). So \(\Prob(M \le x) = F(x)^{n}\).
344: P3 · Strict positivity of the expected largest error
345: Using only Assumption 1, show that \(\E[M] > 0\) when \(n \ge 2\) and \(a \ge 1\), and explain why the argument needs \(a \ge 1\).
346: Solution
347: The proof of Proposition 2.1 gives \(M \ge \varepsilon_1\), so \(\E[M] \ge \E[\varepsilon_1] = 0\). The inequality is strict because \(M - \varepsilon_1 \ge (\varepsilon_2 - \varepsilon_1)^{+}\), and on the event \(\varepsilon_2 = a\), \(\varepsilon_1 = -a\), which has probability \((2a+1)^{-2}\), the right side equals \(2a\). This event needs \(a \ge 1\), because when \(a = 0\) every error is 0, and then \(M = 0\) and \(\E[M] = 0\). So \(\E[M] > 0\) requires \(a \ge 1\).

387: R2 · What an equilibrium check would need
388: Explain why the calculation in Proposition 3.1 does not show that bidding \(S - \E[M]\) is a Bayesian–Nash equilibrium, and name the quantity an equilibrium check must compute for a bidder with signal \(s\).
389: Solution
390: Proposition 3.1 averages the winner's profit over all realizations of the signals. A bidder choosing a bid makes that choice with its own signal \(s\) known. An equilibrium check therefore computes the expected profit of a bid conditional on the bidder's own signal \(s\) and on winning with that bid, given the other bidders' bids. That conditional expectation is not the unconditional average of Proposition 3.1, so the calculation does not establish an equilibrium.
394: R3 · The set of shadings with nonnegative expected profit
395: In the model of Proposition 3.1, find the set of whole-number shadings \(c \ge 0\) for which the winner's expected profit is nonnegative, when \(n = 5\) and \(a = 2000\).
396: Solution
397: By Proposition 3.1 the expected profit is \(c - \E[M]\), which is nonnegative exactly when \(c \ge \E[M] = 1333.6666\) cents. Among whole-number shadings, the set is \(\{1334, 1335, 1336, \dots\}\), so the smallest member is 1334. Larger shadings give a larger expected profit, which is a larger margin for the winner, but a larger shading also means a lower bid. This lesson does not model how the number of wins changes with the shading.
