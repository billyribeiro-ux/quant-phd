[problem M1] M1 · The correlation of a relabelled coin Let X take the values 0 and 1 with probability 1/2 each, and let \(Y = 2X + 1\). Compute \(\operatorname{Cov}(X,Y)\) and \(\rho(X,Y)\). Solution \(\operatorname{Var}(X) = E[X^{2}] - (E[X])^{2} = 1/2 - 1/4 = 1/4\), so \(\sigma_X = 1/2\). By Proposition 1.2, \(\operatorname{Cov}(X, 2X + 1) = 2\operatorname{Var}(X) = 1/2\). Also \(\sigma_Y = 2\sigma_X = 1\). So \(\rho = (1/2)/((1/2)(1)) = 1\), as Example 1.7 predicts for an increasing affine map.
[problem M2] M2 · The quadratic form of a two-variable matrix Let \(\Sigma = \begin{pmatrix} 4 & 3 \\ 3 & 9 \end{pmatrix}\) be a covariance matrix. Compute \(w^{\top}\Sigma w\) for \(w = (1, -1)\), and compute the correlation of the two variables. Solution \(w^{\top}\Sigma w = 4 \cdot 1 + 2 \cdot 3 \cdot (1)(-1) + 9 \cdot 1 = 4 - 6 + 9 = 7\). This is nonnegative, as Proposition 2.3 requires. The correlation is \(3/(\sqrt{4}\sqrt{9}) = 3/6 = 1/2\).
[problem M3] M3 · The variance of a sum Let \(\operatorname{Var}(X) = \operatorname{Var}(Y) = 1\) and \(\operatorname{Cov}(X,Y) = -0.4\). Compute \(\operatorname{Var}(X + Y)\). Solution By Proposition 1.1, \(\operatorname{Cov}(X + Y, X + Y) = \operatorname{Cov}(X,X) + \operatorname{Cov}(X,Y) + \operatorname{Cov}(Y,X) + \operatorname{Cov}(Y,Y) = 1 - 0.4 - 0.4 + 1 = 1.2\). So \(\operatorname{Var}(X + Y) = 1.2\), smaller than the 2 that independence would give. Proof
[problem P1] P1 · The linearity step Prove Proposition 1.1(ii) from the definition of covariance, stating each use of linearity. Solution Write \(\operatorname{Cov}(aX + b, Y) = E[(aX + b - E[aX + b])(Y - E[Y])]\). Linearity gives \(E[aX + b] = aE[X] + b\), so the first factor is \(a(X - E[X])\). Pulling the constant a out of the expectation, which is linearity again, gives \(a\,E[(X - E[X])(Y - E[Y])] = a\,\operatorname{Cov}(X,Y)\). The constant b cancels in the first factor.
[problem P2] P2 · The quadratic form for n = 2 For a two-variable vector \((X_1, X_2)\) and \(w = (w_1, w_2)\), expand \(w^{\top}\Sigma w\) and show that it equals \(\operatorname{Var}(w_1X_1 + w_2X_2)\). Solution Expanding, \(w^{\top}\Sigma w = w_1^{2}\Sigma_{11} + 2w_1w_2\Sigma_{12} + w_2^{2}\Sigma_{22}\), using \(\Sigma_{12} = \Sigma_{21}\). The variance of \(w_1X_1 + w_2X_2\) is \(\operatorname{Cov}(w_1X_1 + w_2X_2, w_1X_1 + w_2X_2)\). By Proposition 1.1, this expands to \(w_1^{2}\operatorname{Cov}(X_1,X_1) + 2w_1w_2\operatorname{Cov}(X_1,X_2) + w_2^{2}\operatorname{Cov}(X_2,X_2)\), which is the same expression.
[problem P3] P3 · Correlation under a negative scale Show that \(\rho(-X, Y) = -\rho(X,Y)\). Note that Proposition 1.6 requires \(a > 0\), so this case is outside it. Solution By Proposition 1.2 with \(a = -1\) and \(c = 1\), \(\operatorname{Cov}(-X, Y) = -\operatorname{Cov}(X,Y)\). The standard deviation \(\sigma_{-X} = \sqrt{\operatorname{Var}(-X)} = \sqrt{\operatorname{Var}(X)} = \sigma_X\), because \(\operatorname{Var}(-X) = (-1)^{2}\operatorname{Var}(X)\). So \(\rho(-X,Y) = -\operatorname{Cov}(X,Y)/(\sigma_X\sigma_Y) = -\rho(X,Y)\). A negative scale reverses the sign and leaves the size unchanged. Empirical

[problem R1] R1 · Zero correlation with a variable that is not constant Let X be uniform on \(\{-1, 0, 1\}\) and \(Y = |X|\). Show that \(\rho(X,Y) = 0\), and show that \(\sigma_Y > 0\). Solution \(E[X] = 0\). The product \(XY = X\,|X|\) takes the values \(-1\), 0 and 1 with probability 1/3 each, so \(E[XY] = 0\). So \(\operatorname{Cov}(X,Y) = 0\) by Proposition 1.1 and the shortcut of L04. For \(\sigma_Y\), \(E[Y] = 2/3\) and \(E[Y^{2}] = E[X^{2}] = 2/3\), so \(\operatorname{Var}(Y) = 2/3 - 4/9 = 2/9 > 0\). The correlation is \(0/(\sigma_X\sigma_Y) = 0\).
[problem R2] R2 · The matrix in Misconception 3 Show that no pair of random variables with finitely many values has covariance matrix \(\begin{pmatrix}1 & 2 \\ 2 & 1\end{pmatrix}\). Solution Suppose \(X_1\) and \(X_2\) had this covariance matrix. Then \(\operatorname{Var}(X_1) = \operatorname{Var}(X_2) = 1\) and \(\operatorname{Cov}(X_1,X_2) = 2\). Proposition 1.5 requires \(\operatorname{Cov}^{2} \le \operatorname{Var}\operatorname{Var}\), which here reads \(4 \le 1\). That is false, so no such pair exists.
[problem R3] R3 · A zero diagonal entry forces a zero row Let \(\Sigma\) be the covariance matrix of X with finitely many values, and suppose \(\Sigma_{ii} = 0\) for some i. Show that \(\Sigma_{ij} = 0\) for every j. Solution By Proposition 2.4, \(\Sigma_{ij}^{2} \le \Sigma_{ii}\Sigma_{jj} = 0 \cdot \Sigma_{jj} = 0\). A square of a real number that is at most zero is zero, so \(\Sigma_{ij} = 0\). The variable \(X_i\) has zero variance, so it is constant on its support, and it has zero covariance with every other variable.
