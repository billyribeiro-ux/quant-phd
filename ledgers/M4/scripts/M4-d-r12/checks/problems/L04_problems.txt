[problem M1] M1 · Test one table for independence A joint table has \(p(0,0) = 0.1\), \(p(0,1) = 0.2\), \(p(1,0) = 0.3\) and \(p(1,1) = 0.4\). Compute the marginals and decide whether X and Y are independent. Solution The marginals are \(P(X = 0) = 0.1 + 0.2 = 0.3\), \(P(X = 1) = 0.7\), \(P(Y = 0) = 0.1 + 0.3 = 0.4\) and \(P(Y = 1) = 0.6\). The cell \((0,0)\) needs \(P(X = 0)\,P(Y = 0) = 0.3 \times 0.4 = 0.12\), but \(p(0,0) = 0.1\). The cell fails, so the variables are dependent.
[problem M2] M2 · A conditional expectation from the table in M1 For the table in M1, compute \(E[X \mid Y = 1]\) exactly. Solution \(P(Y = 1) = 0.6\). The numerator is \(\sum_x x\,p(x,1) = 0 \cdot 0.2 + 1 \cdot 0.4 = 0.4\). So \(E[X \mid Y = 1] = 0.4/0.6 = 2/3\), which is 0.6667 to four places. This differs from \(E[X] = 0.7\), so in this table learning that Y = 1 changes the expected value of X, which is the dependence found in M1.

Write out the joint table, check that it sums to 1, and compute \(E[XY]\) by two methods. Solution The cells are \(p(1,1) = 1/8\), \(p(1,0) = 1/8\), \(p(0,1) = 3/8\) and \(p(0,0) = 3/8\). [problem P1] P1 · The covariance shortcut Prove Proposition 1.7 by expanding the product, and state which property of expectation you use. Solution Expand \((X - E[X])(Y - E[Y]) = XY - E[Y]X - E[X]Y + E[X]E[Y]\). Expectation is linear over finite sums, and \(E[Y]\), \(E[X]\) and \(E[X]E[Y]\) are constants whose expectations equal themselves. The sum is \(E[XY] - E[Y]E[X] - E[X]E[Y] + E[X]E[Y] = E[XY] - E[X]E[Y]\). The only property used is linearity.
[problem P2] P2 · Proposition 2.4 for a two-valued Y Suppose X and Y are independent and Y takes the value 1 with probability \(q\), where \(0 < q < 1\). Show that \(E[X \mid Y = 1] = E[X]\) and \(E[X \mid Y = 0] = E[X]\). Solution Both conditioning values have positive probability, because \(P(Y = 1) = q > 0\) and \(P(Y = 0) = 1 - q > 0\). Proposition 2.4 applies to each. Concretely, \(P(X = x \mid Y = y) = P(X = x)P(Y = y)/P(Y = y) = P(X = x)\) for \(y = 0\) and \(y = 1\). Summing \(x\,P(X = x)\) over x gives \(E[X]\) in both cases.

[problem R1] R1 · Zero covariance from a different function Let X be uniform on \(\{-1, 0, 1\}\) and let \(Y = |X|\). Show that \(\operatorname{Cov}(X,Y) = 0\), and show that X and Y are dependent. Solution \(E[X] = 0\), \(E[Y] = (1 + 0 + 1)/3 = 2/3\), and \(XY = X|X|\) takes the values \(-1\), 0 and 1 with probability 1/3 each, so \(E[XY] = 0\). By Proposition 1.7, \(\operatorname{Cov}(X,Y) = 0 - 0 \cdot 2/3 = 0\). For dependence, \(p(0,0) = P(X = 0, Y = 0) = 1/3\), while \(P(X = 0)P(Y = 0) = (1/3)(1/3) = 1/9\). The cell fails the product rule.
[problem R2] R2 · Covariance of a variable with itself For a random variable X with finitely many values, show that \(\operatorname{Cov}(X,X) = \operatorname{Var}(X)\), using the variance formula \(\operatorname{Var}(X) = E[X^{2}] - (E[X])^{2}\) from L02. Solution Set \(Y = X\) in Proposition 1.7. Then \(\operatorname{Cov}(X,X) = E[X \cdot X] - E[X]E[X] = E[X^{2}] - (E[X])^{2}\), which is \(\operatorname{Var}(X)\) by the formula of L02. The covariance of a variable with itself is its variance.
[problem R3] R3 · A constant conditional expectation does not imply independence Let X be uniform on \(\{-1, 0, 1\}\) and \(Y = X^{2}\), as in Example 1.9. Show that \(E[X \mid Y = 0] = E[X \mid Y = 1] = E[X]\), and show that X and Y are dependent. Solution Given \(Y = 0\), X must be 0, so \(E[X \mid Y = 0] = 0\). Given \(Y = 1\), X is \(-1\) or \(1\) with probability 1/2 each, so \(E[X \mid Y = 1] = (-1 + 1)/2 = 0\). Also \(E[X] = 0\). So all three agree. Dependence was shown in Example 1.9: \(p(0,0) = 1/3\) against \(1/9\). The conclusion is that equal conditional expectations do not imply independence.
