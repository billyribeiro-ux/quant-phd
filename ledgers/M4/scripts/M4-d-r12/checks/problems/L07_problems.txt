[problem M1] M1 · The MGF and characteristic function of a fair two-point law Let X take the values 0 and 2 with probability 1/2 each. Find \(M_X(t)\) and \(\varphi_X(t)\). Solution \(M_X(t) = \tfrac12 e^{0} + \tfrac12 e^{2t} = (1 + e^{2t})/2\), defined for every real t by Proposition 1.2. \(\varphi_X(t) = \tfrac12 + \tfrac12 e^{2it} = (1 + e^{2it})/2\) by Proposition 2.5 with \(p = 1/2\), \(a = 0\), \(b = 2\).
[problem M2] M2 · A normal MGF at one point Let X be \(N(1, 4)\). Find \(M_X(1)\), exactly and to four decimal places. Solution Here \(\mu = 1\) and \(\sigma^{2} = 4\). By Proposition 1.3, \(M_X(1) = \exp(\mu \cdot 1 + \sigma^{2}\cdot 1^{2}/2) = \exp(1 + 2) = e^{3}\). Numerically \(e^{3} = 20.0855\) to four decimal places.
[problem M3] M3 · A zero characteristic function Let X take the values 0 and 2 with probability 1/2 each. Find \(\varphi_X(\pi/2)\). Solution \(\varphi_X(\pi/2) = \tfrac12 e^{0} + \tfrac12 e^{i\pi} = \tfrac12 - \tfrac12 = 0\). [problem P1] P1 · The affine rule for characteristic functions Prove Proposition 2.4, stating each use of linearity. Solution \(e^{it(aX + b)} = e^{itb}\,e^{i(at)X}\) by the exponential law \(e^{u+v} = e^{u}e^{v}\), applied with \(u = itb\) and \(v = i(at)X\). The factor \(e^{itb}\) is a constant, so linearity of expectation takes it outside: \(E[e^{itb}e^{i(at)X}] = e^{itb}E[e^{i(at)X}]\). The last expectation is \(\varphi_X(at)\) by definition.
[problem P2] P2 · The normal MGF by completing the square Prove Proposition 1.3 for a standard normal variable (\(\mu = 0\), \(\sigma = 1\)), showing where the Gaussian integral enters. Solution \(E[e^{tZ}] = \frac{1}{\sqrt{2\pi}}\int e^{tz - z^{2}/2}\,dz\). Since \(tz - z^{2}/2 = -(z - t)^{2}/2 + t^{2}/2\), the integral is \(e^{t^{2}/2}\int e^{-(z-t)^{2}/2}\,dz\). The substitution \(u = z - t\) leaves the integral over the line unchanged, and Proposition 1.2 of L06 gives \(\sqrt{2\pi}\). So \(E[e^{tZ}] = e^{t^{2}/2}\), which is the formula with \(\mu = 0\) and \(\sigma = 1\).
[problem P3] P3 · The product rule for independent variables Let X and Y be independent with finitely many values. Show that \(M_{X+Y}(t) = M_X(t)\,M_Y(t)\) for every real t. Solution \(M_{X+Y}(t) = E[e^{tX}e^{tY}]\). Write \(E[g(X)h(Y)] = \sum_{x,y} g(x)h(y)P(X = x)P(Y = y)\), which holds by independence. Here \(g(x) = e^{tx}\) and \(h(y) = e^{ty}\), so the double sum factors as \(\big(\sum_x e^{tx}P(X = x)\big)\big(\sum_y e^{ty}P(Y = y)\big) = M_X(t)M_Y(t)\). This is the same factorization as Proposition 1.5 of L04. Empirical

[problem R1] R1 · When a two-point characteristic function has modulus one Let X take the values 0 and 1 with probabilities \(1 - p\) and \(p\), where \(0 < p < 1\). Show that \(|\varphi_X(t)| = 1\) if and only if \(t\) is a multiple of \(2\pi\). Solution By Proposition 2.5 with \(a = 0\) and \(b = 1\), \(|\varphi(t)|^{2} = p^{2} + (1 - p)^{2} + 2p(1 - p)\cos t\). Since \(p^{2} + (1 - p)^{2} + 2p(1 - p) = (p + (1 - p))^{2} = 1\), the condition \(|\varphi|^{2} = 1\) becomes \(2p(1 - p)(\cos t - 1) = 0\). With \(0 < p < 1\) the factor \(2p(1-p)\) is positive, so \(\cos t = 1\). That holds exactly when \(t\) is a multiple of \(2\pi\).
[problem R2] R2 · The MGF of a two-point law is strictly increasing Let X take the values 0 and 1 with probabilities \(1 - p\) and \(p\), where \(0 < p < 1\). Assuming Assumption 1(b), show that \(M_X\) is strictly increasing on the whole real line. Solution \(M_X(t) = (1 - p) + p e^{t}\). Its derivative is \(M_X'(t) = p e^{t}\), which is positive for every real t because \(p > 0\). A function with positive derivative everywhere is strictly increasing (Assumption 1(b)).
[problem R3] R3 · A symmetric sign has a real characteristic function Let X take the values \(-1\) and \(1\) with probability 1/2 each. Show that \(\varphi_X(t) = \cos t\). Solution \[\begin{aligned} \varphi_X(t) &= \tfrac12 e^{-it} + \tfrac12 e^{it} \\ &= \tfrac12(\cos t - i\sin t) \\ &\quad + \tfrac12(\cos t + i\sin t) = \cos t \end{aligned}\]. The imaginary parts cancel, because the law is symmetric about 0.
