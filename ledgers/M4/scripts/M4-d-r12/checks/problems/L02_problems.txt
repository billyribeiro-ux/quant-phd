[problem mech-1] M1 · The variance of an indicator Let \(X\) take the value 1 with probability \(\tfrac{3}{10}\) and 0 otherwise. Find \(E[X]\), \(E[X^2]\) and \(\operatorname{Var}(X)\). Solution \(E[X] = 1 \cdot \tfrac{3}{10} + 0 \cdot \tfrac{7}{10} = \tfrac{3}{10}\). Since \(X^2 = X\) when \(X\) is 0 or 1, \(E[X^2] = E[X] = \tfrac{3}{10}\). By Proposition 2.2, \(\operatorname{Var}(X) = \tfrac{3}{10} - \tfrac{9}{100} = \tfrac{21}{100}\), which is \(\tfrac{3}{10} \cdot \tfrac{7}{10}\).
[problem mech-2] M2 · A loss in cents whose standard deviation is a whole number of cents A loss \(L\) is 0 cents with probability \(\tfrac{9}{10}\) and 50000 cents with probability \(\tfrac{1}{10}\). Find \(E[L]\), \(\operatorname{Var}(L)\) and the standard deviation in cents. Solution \(E[L] = 50000 \cdot \tfrac{1}{10} = 5000\) cents. \(E[L^2] = 50000^2 \cdot \tfrac{1}{10} = 2.5 \times 10^{8}\), so by Proposition 2.2, \(\operatorname{Var}(L) = 2.5 \times 10^{8} - 5000^2 = 2.5 \times 10^{8} - 2.5 \times 10^{7} = 2.25 \times 10^{8}\) cents squared. Its square root is \(15000\) cents exactly, since \(15000^2 = 2.25 \times 10^{8}\).
[problem mech-3] M3 · Scaling and shifting A random variable \(X\) has \(\operatorname{Var}(X) = 4\). Find \(\operatorname{Var}(3X - 2)\) and \(\operatorname{Var}(X + 10)\). Solution By Proposition 2.3 with \(a = 3\) and \(b = -2\), \(\operatorname{Var}(3X - 2) = 9 \cdot 4 = 36\). The shift by 10 does not change the variance, so \(\operatorname{Var}(X + 10) = 4\). [problem proof-1] P1 · Expectation of a sum of two variables Let \(U\) and \(V\) be random variables on one finite probability space with positive weights. Prove that \(E[U + V] = E[U] + E[V]\), starting from Definition 1.1 and Proposition 1.2. Solution By Proposition 1.2 applied to \(W = U + V\), \(E[U + V] = \sum_\omega (U(\omega) + V(\omega)) p(\omega)\). Split the sum into two sums, which is allowed because each is a finite sum: \(\sum_\omega U(\omega) p(\omega) + \sum_\omega V(\omega) p(\omega)\). By Proposition 1.2 again, these are \(E[U]\) and \(E[V]\). This is the case \(\alpha = \beta = 1\), \(\delta = 0\) of Proposition 1.3.
[problem proof-2] P2 · The mean minimizes squared error Let \(\mu = E[X]\) and let \(c\) be any real number. Prove that \(E[(X - c)^2] = \operatorname{Var}(X) + (\mu - c)^2\), and deduce that \(E[(X - c)^2]\) is smallest when \(c = \mu\). Solution Write \(X - c = (X - \mu) + (\mu - c)\), so \((X - c)^2 = (X - \mu)^2 + 2(\mu - c)(X - \mu) + (\mu - c)^2\). Take expectations with Proposition 1.3, with \(\mu - c\) a constant. The middle term has expectation \(2(\mu - c) E[X - \mu] = 2(\mu - c)(\mu - \mu) = 0\). So \(E[(X - c)^2] = \operatorname{Var}(X) + (\mu - c)^2\). The second term is nonnegative and is zero exactly when \(c = \mu\), so the expression is smallest at \(c = \mu\).
[problem proof-3] P3 · A counterexample to additivity of variance Show by a counterexample on a finite space that \(\operatorname{Var}(U + V) = \operatorname{Var}(U) + \operatorname{Var}(V)\) can fail, and compute both sides. Solution Let \(V = -U\) with \(U\) taking the values \(-1\) and 1 with probability \(\tfrac12\) each. Then \(E[U] = 0\), \(E[U^2] = 1\), so \(\operatorname{Var}(U) = 1\). Also \(V = -U\) takes the same two values with the same probabilities, so \(\operatorname{Var}(V) = 1\). But \(U + V = 0\) is constant, so \(\operatorname{Var}(U + V) = 0\) by Proposition 2.4. The two sides are 0 and 2, so the additivity identity fails. The example uses dependence, since \(V\) is a function of \(U\). The example shows that additivity of variance can fail. [problem res-1] R1 · The sample variance as a variance of the empirical law Lab 1 computes the sample variance with divisor \(n\). Show that this equals \(\operatorname{Var}(Y)\), where \(\Omega = \{1, \dots, n\}\) carries probability \(\tfrac{1}{n}\) on each point and \(Y(i) = z_i\) for a list \(z_1, \dots, z_n\). Repeated values in the list need no special treatment. Solution Let \(\bar z = \tfrac1n \sum_i z_i\). By Proposition 1.2 with each outcome \(i\) weighted \(\tfrac1n\), \(E[Y] = \tfrac1n \sum_i z_i = \bar z\). By Definition 2.1, \(\operatorname{Var}(Y) = E[(Y - \bar z)^2] = \tfrac1n \sum_i (z_i - \bar z)^2\), which is the divisor-\(n\) sample variance. Each entry of the list is one outcome, so a repeated value is counted once for each time it occurs. The identity needs no distinctness assumption.
[problem res-2] R2 · Converting the loss to currency units The loss \(L\) of Example 2.6 is in cents. Let \(D = L/100\) be the same loss in currency units. Find \(\operatorname{Var}(D)\) and \(\sigma_D\) from the exact variance, and explain why the variance and the standard deviation change by different factors. Solution By Proposition 2.3 with \(a = \tfrac{1}{100}\), \(\operatorname{Var}(D) = \tfrac{1}{10\,000} \cdot 2\,968\,750\,000 = 296\,875\). So \(\operatorname{Var}(D) = 296\,875\) currency units squared. The standard deviation is \(\sqrt{296\,875}\), which is about \(544.8624\) currency units when computed from \(\sqrt{2\,968\,750\,000} \approx 54486.24\) cents divided by 100. The variance changes by \(a^2 = 10^{-4}\), and the standard deviation by \(|a| = 10^{-2}\), because the variance is a squared quantity.
