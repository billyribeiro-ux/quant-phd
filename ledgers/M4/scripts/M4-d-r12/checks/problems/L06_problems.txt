[problem M1] M1 · A normal probability and second moment Let X be \(N(3, 4)\). Find \(P(X \le 3)\) and \(E[X^{2}]\). Solution Here \(\sigma = 2\), so \(P(X \le 3) = P(Z \le (3 - 3)/2) = P(Z \le 0)\). Since \(\varphi\) is symmetric about 0 and integrates to 1, \(P(Z \le 0) = 1/2\). For the second moment, \(E[X^{2}] = \operatorname{Var}(X) + (E[X])^{2} = 4 + 9 = 13\), using Proposition 1.5.
[problem M2] M2 · Student-t variances for small degrees of freedom Find \(\operatorname{Var}(\mathrm{t}_{\nu})\) for \(\nu = 3, 4, 5\), and say which of these is the smallest. Solution By Proposition 2.6, \(\operatorname{Var}(\mathrm{t}_{\nu}) = \nu/(\nu - 2)\). For \(\nu = 3\) this is \(3/1 = 3\), for \(\nu = 4\) it is \(4/2 = 2\), and for \(\nu = 5\) it is \(5/3\). The smallest is \(5/3\), at \(\nu = 5\), so the three values fall as \(\nu\) grows.
[problem M3] M3 · Standardizing a normal Let X be \(N(-1, 9)\). Find the standard normal value z with \(P(X \le 2) = P(Z \le z)\). Solution \(\sigma = 3\), so \(z = (2 - (-1))/3 = 3/3 = 1\). By Proposition 1.4, \(P(X \le 2) = P(Z \le 1)\), which is the standard normal distribution function at 1. Proof
[problem P1] P1 · The Laplace transform of a squared normal Prove Lemma 2.3's first step: for \(s \ge 0\), \(E[e^{-sZ^{2}}] = (1 + 2s)^{-1/2}\). Solution Write the expectation as \(\frac{1}{\sqrt{2\pi}}\int e^{-(1 + 2s)z^{2}/2}\,dz\). Substitute \(u = \sqrt{1 + 2s}\,z\), so \(dz = du/\sqrt{1 + 2s}\). The integral becomes \((1 + 2s)^{-1/2}\,\frac{1}{\sqrt{2\pi}}\int e^{-u^{2}/2}\,du\). By Proposition 1.2 the last integral is \(\sqrt{2\pi}\), so the factor is 1, and the result is \((1 + 2s)^{-1/2}\).
[problem P2] P2 · The divergence at \(\nu = 2\) Show directly that \(\int_0^{\infty}(1 + 2s)^{-1}\,ds = \infty\), and deduce that \(E[1/W_2] = \infty\). Solution An antiderivative of \((1 + 2s)^{-1}\) is \(\tfrac12\ln(1 + 2s)\). As \(s \to \infty\) this tends to infinity, so the integral is infinite. For \(\nu = 2\), \(a = \nu/2 = 1\), and Lemma 2.3 gives \(E[1/W_2] = \int_0^{\infty}(1 + 2s)^{-1}\,ds = \infty\). This is the case \(a \le 1\) of Proposition 2.4.
[problem P3] P3 · The second moment of the standard normal Prove \(E[Z^{2}] = 1\) for a standard normal Z by integration by parts, stating the boundary term and why it vanishes. Solution With \(u = z\) and \(dv = z\varphi(z)\,dz\), \(v = -\varphi(z)\) since \(\varphi' = -z\varphi\). The integral is \([-z\varphi(z)]_{-\infty}^{\infty} + \int\varphi(z)\,dz\). The boundary term is zero because \(z\varphi(z) = z e^{-z^{2}/2}/\sqrt{2\pi} \to 0\) as \(|z| \to \infty\). The remaining integral is 1 by Proposition 1.3. So \(E[Z^{2}] = 1\). Empirical

[problem R1] R1 · The mean of the absolute normal Show that \(E[|Z|] = \sqrt{2/\pi}\) for a standard normal Z. Solution The integrand \(|z|\varphi(z)\) is even, so \(E[|Z|] = 2\int_0^{\infty} z\,e^{-z^{2}/2}\,dz/\sqrt{2\pi}\). The antiderivative of \(z e^{-z^{2}/2}\) is \(-e^{-z^{2}/2}\), so the integral from 0 to infinity is \(0 - (-1) = 1\). Hence \(E[|Z|] = 2/\sqrt{2\pi} = \sqrt{2/\pi}\), which is finite. This is the finiteness used in the mean step of Proposition 2.6.
[problem R2] R2 · Why the denominator is centred at one Show that \(E[W_{\nu}/\nu] = 1\), and explain why this makes \(\sqrt{W_{\nu}/\nu}\) a natural scale for the Student-t. Solution Each \(E[Z_i^{2}] = 1\) by Proposition 1.5, and expectation is linear over the \(\nu\) terms, so \(E[W_{\nu}] = \nu\). Then \(E[W_{\nu}/\nu] = 1\). So the denominator \(W_{\nu}/\nu\) has mean one. The page uses this to fix the scale of the construction. The variance formula of Proposition 2.6 comes from \(E[1/W_{\nu}]\), not from this mean.
[problem R3] R3 · A dependent denominator changes the answer Let \(W = Z^{2}\), which is not independent of Z, and let \(\mathrm{t}' = Z/\sqrt{W}\). Show that \(\operatorname{Var}(\mathrm{t}') = 1\), and say why this does not contradict Proposition 2.6. Solution Here \(\mathrm{t}' = Z/|Z| = \operatorname{sign}(Z)\), which is \(\pm 1\) with \(P(Z = 0) = 0\). So \(E[\mathrm{t}'^{2}] = 1\), and \(E[\mathrm{t}'] = 0\) by symmetry of Z. Hence \(\operatorname{Var}(\mathrm{t}') = 1\). Proposition 2.6 needs the denominator to be chi-square with \(\nu\) degrees of freedom and independent of Z. Here W is chi-square with \(\nu = 1\) in its law, but it is not independent of Z, and the independence step fails. So the two results do not conflict.
