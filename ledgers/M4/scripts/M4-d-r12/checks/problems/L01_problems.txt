[problem mech-1] M1 · The distribution of a parity variable Let \(\Omega = \{1, 2, 3, 4\}\) with \(p(\omega) = \tfrac14\) for each \(\omega\), and let \(X(\omega) = 1\) if \(\omega\) is odd and \(X(\omega) = 0\) if \(\omega\) is even. Find the distribution function and \(Q(\tfrac12)\). Solution The outcomes 1 and 3 give \(X = 1\), and the outcomes 2 and 4 give \(X = 0\). So \(P(X = 0) = \tfrac12\) and \(P(X = 1) = \tfrac12\). The distribution function is \(F(x) = 0\) for \(x < 0\), \(F(x) = \tfrac12\) for \(0 \le x < 1\), and \(F(x) = 1\) for \(x \ge 1\). Since \(F(0) = \tfrac12 \ge \tfrac12\), Proposition 3.2 gives \(Q(\tfrac12) = 0\), the least value whose distribution function reaches \(\tfrac12\).
[problem mech-2] M2 · A quantile on a three-value law Let \(X\) take the values 2, 5 and 7 with probabilities \(\tfrac15\), \(\tfrac12\) and \(\tfrac{3}{10}\). Find \(F(5)\), \(Q(\tfrac{7}{10})\) and \(Q(\tfrac{71}{100})\). Solution The distribution function at 5 is \(F(5) = P(X \le 5) = \tfrac15 + \tfrac12 = \tfrac{7}{10}\). So \(F(5) = \tfrac{7}{10} \ge \tfrac{7}{10}\), and \(F(2) = \tfrac15 < \tfrac{7}{10}\), so \(Q(\tfrac{7}{10}) = 5\) by Proposition 3.2. For \(p = \tfrac{71}{100}\), \(F(5) = \tfrac{70}{100} < \tfrac{71}{100}\) and \(F(7) = 1\), so \(Q(\tfrac{71}{100}) = 7\). Remark 3.3 predicts this, since \(\tfrac{7}{10} = F_2\) and \(Q(F_2) = x_2 = 5\).
[problem mech-3] M3 · The index on forty equally likely values Let \(X\) take forty distinct values \(y_1 < \dots < y_{40}\) with probability \(\tfrac{1}{40}\) each. Find the index of \(Q(0.9)\) and of \(Q(0.901)\). Solution By Proposition 3.4, the index is \(\lceil 40 p \rceil\). For \(p = 0.9\), \(40 p = 36\), an integer, so the index is 36. For \(p = 0.901\), \(40 p = 36.04\), and \(\lceil 36.04 \rceil = 37\). So \(Q(0.9) = y_{36}\) and \(Q(0.901) = y_{37}\). The index changes because \(40 \times 0.901 = 36.04\) is not an integer, and the ceiling of 36.04 is 37. Proof
[problem proof-1] P1 · The distribution function of any finite law is nondecreasing Let \(X\) take finitely many values with \(P(X = v)\) given for each. Prove from the definition \(F(x) = P(X \le x)\) that \(F\) is nondecreasing, without using the distinct-values hypothesis of Proposition 2.2. Solution Let \(x \le y\). The event \(\{X \le x\}\) is contained in \(\{X \le y\}\), because any outcome with \(X \le x\) also has \(X \le y\). Probability is monotone on events: \(P(B) = P(A) + P(B \setminus A) \ge P(A)\) when \(A \subseteq B\), since \(P(B \setminus A) \ge 0\) for nonnegative weights. Hence \(F(x) = P(X \le x) \le P(X \le y) = F(y)\).
[problem proof-2] P2 · Quantile at a point with no jump Let \(X\) be as in Proposition 2.2 and let \(k\) satisfy \(F_{k-1} < p < F_k\). Show that \(Q(p) = x_k\) and that \(Q(p')\) equals \(x_k\) for all \(p'\) in a neighbourhood of \(p\). Solution Remark 3.3 gives \(Q(p) = x_k\) for every \(p\) with \(F_{k-1} < p \le F_k\). Since \(F_{k-1} < p < F_k\), the interval \((F_{k-1}, F_k]\) contains a neighbourhood of \(p\): take \(\delta = \min(p - F_{k-1}, F_k - p) > 0\). Every \(p'\) with \(|p' - p| < \delta\) satisfies \(F_{k-1} < p' < F_k\), so \(Q(p') = x_k\). The quantile is locally constant at such \(p\).
[problem proof-3] P3 · The maximum is the quantile at one For \(X\) as in Proposition 2.2, prove that \(Q(1) = x_m\), the largest value. Solution By Proposition 2.2(c), \(F_m = 1\), and \(F_k < 1\) for \(k < m\), because \(F_k = p_1 + \dots + p_k\) and the weights \(p_{k+1}, \dots, p_m\) are positive. So the least index with \(F_k \ge 1\) is \(m\). Proposition 3.2 gives \(Q(1) = x_m\). Empirical
[problem emp-1] E1 · Checking the 99th quantile of the table (Lab 1) Lab 1 prints \(Q(\tfrac{99}{100}) = 3\) for the table of Example 3.6. Verify this by hand, and say which value of \(F\) decides it. Solution The distribution function at 2 is \(F(2) = \tfrac{9}{10} = 0.90\), which is below \(0.99\). At 3 it is \(F(3) = 1 \ge 0.99\). By Proposition 3.2 the least value whose distribution function reaches 0.99 is 3. So \(Q(\tfrac{99}{100}) = 3\), and the printed line agrees. The decision rests on \(F(2) = \tfrac{9}{10} < \tfrac{99}{100}\), since the jump at 3 carries the last tenth of the probability.
[problem emp-2] E2 · What the \(\varepsilon\) line shows (Lab 1) Lab 1 prints \(Q(F(0)) = 0\) and \(Q(F(0) + \varepsilon) = 1\) with \(\varepsilon = 10^{-9}\). Explain both values, and say what the lab does not establish about \(\varepsilon\). Solution \(F(0) = \tfrac35\), and \(Q(\tfrac35) = 0\) by Remark 3.3, which says \(Q(F_k) = x_k\). For \(p = \tfrac35 + \varepsilon\), the least value with \(F \ge p\) is the next value above the jump, since \(F(0) < p \le F(1) = \tfrac45\). So \(Q = 1\). The lab checks one value of \(\varepsilon\). It does not establish a limit as \(\varepsilon\) shrinks; that follows from the proof, which covers every \(p\) in \((\tfrac35, \tfrac45]\).
[problem emp-3] E3 · What a count below 100 would mean (Lab 1) Lab 1 prints "scan equals definition at 100 of 100 points". Suppose a run printed 99. State what the printed count would show, and why the grid check cannot by itself prove the agreement for all \(p\). Solution The scan and the definition of \(Q\) both give the value of \(Q\) that Definition 3.1 defines and Proposition 3.2 identifies, so a disagreement at any grid point would show an error in one of the two code paths for that point. The grid has 100 points, so a count below 100 would show that at least one grid point disagrees. The printed line does not say which point. The grid check cannot prove agreement for all \(p\), because \((0, 1]\) has infinitely many points and the grid covers only 100. The proof of Proposition 3.2 covers every \(p\), and the lab is a check of the code against that proof. Research
[problem res-1] R1 · The strict convention Suppose the quantile were defined with a strict inequality, \(Q^{s}(p) = \inf\{x : F(x) > p\}\). For the table of Example 3.6, compute \(Q^{s}(\tfrac35)\) and state the general rule that \(Q^{s}\) follows on a finite law. Solution The distribution function at 0 is \(F(0) = \tfrac35\), which is not strictly greater than \(\tfrac35\). The next value with \(F > \tfrac35\) is \(x = 1\), since \(F(1) = \tfrac45 > \tfrac35\). So \(Q^{s}(\tfrac35) = 1\), while \(Q(\tfrac35) = 0\). For a finite law and \(p < 1\), the strict rule returns \(x_{k+1}\) when \(p = F_k\), and it agrees with \(Q\) at every other \(p\). Proof: if \(p = F_k\) with \(k < m\), then \(F(x_k) = F_k \not> p\) and \(F(x_{k+1}) > p\), so the least such \(x\) is \(x_{k+1}\). If \(F_{k-1} < p < F_k\), then \(F(x_j) \le F_{k-1} < p\) for \(j < k\) and \(F(x_k) = F_k > p\), so the least \(x\) with \(F(x) > p\) is \(x_k = Q(p)\), by Remark 3.3. At \(p = 1\) the set \(\{x : F(x) > 1\}\) is empty, so the strict rule has no value there. A report that uses the strict form must say so at each such point.
[problem res-2] R2 · Why left-continuity matters for a stated convention Remark 3.3 says \(Q\) is left-continuous. Explain why a reader who expects right-continuity, as for \(F\), would misread the quantile at the jump points of Example 3.6. Solution The distribution function \(F\) is right-continuous (Proposition 2.2(d)), so its value at a jump is the value to the right. The quantile \(Q\) is left-continuous: at \(p = \tfrac35\), the value is 0, and the limit from the left, \(Q(p)\) for \(p\) just below \(\tfrac35\), is also 0. The limit from the right is 1. A reader who assumes right-continuity would expect \(Q(\tfrac35)\) to be the limit from the right, which is 1, and would read the table wrongly. The left-endpoint convention is what makes \(Q(\tfrac35) = 0\) match the limit from the left.
[problem res-3] R3 · What finite checks can and cannot establish A colleague says the grid check of Lab 1 proves Proposition 3.2 for this table because every grid point agrees. State precisely what the check establishes, and what proof would be needed for all \(p\). Solution The grid check establishes agreement at the 100 points \(j/100\), \(j = 1, \dots, 100\), for this one table. It does not establish agreement at any other \(p\), and it says nothing about other tables. A proof for all \(p\) is Proposition 3.2 itself: it takes an arbitrary \(p\) in \((0, 1]\), finds the least index with \(F_k \ge p\), and shows that every \(x\) with \(F(x) \ge p\) is at least \(x_{k^*}\). That argument uses only Proposition 2.2 and the definition of infimum, and it covers every table with positive weights.
