[assumption] Assumption 1 (calculus facts used without proof)< grade=- :: /span> The page uses the following facts without proof. (a) The integration rules of Assumption 1 of L06 for the integrals in Propositions 1.3, 1.4 and 2.3. (b) The derivative of \(e^{t}\) is \(e^{t}\), and a real function on the line with positive derivative everywhere is strictly increasing (used in Problem R2). (c) For a complex-valued integrand g, \(\left|\int g\right| \le \int |g|\) (used in the density case of Proposition 2.3).
[definition] Definition 1.1 (moment-generating function and its domain)< grade=- :: /span> For a real random variable X and a real t, let \(M_X(t) = E[e^{tX}]\) whenever this expectation is finite. The moment-generating function is \(M_X\), and its domain is the set of real t at which \(E[e^{tX}] < \infty\). The domain always contains \(t = 0\), where \(M_X(0) = E[1] = 1\).
[theorem] Proposition 1.2 (finitely many values)< grade=T :: /span> If X takes finitely many values, then the domain of \(M_X\) is the whole real line.
[proof]  grade=- :: /span> For each value x, \(e^{tx}\) is a finite real number for every real t. So \(E[e^{tX}] = \sum_x e^{tx}P(X = x)\) is a finite sum of finite numbers for every t.
[theorem] Proposition 1.3 (the normal moment-generating function)< grade=T :: /span> Assuming Assumption 1, if \(X \sim N(\mu, \sigma^{2})\) with \(\sigma > 0\), then the domain of \(M_X\) is the whole real line, and \(M_X(t) = \exp(\mu t + \sigma^{2}t^{2}/2)\) for every real t.
[proof]  grade=- :: /span> By Proposition 1.4 of L06, \(X = \mu + \sigma Z\) with Z standard normal. So \(E[e^{tX}] = e^{\mu t}E[e^{s Z}]\) with \(s = \sigma t\). For real s, the integrand \(e^{sz - z^{2}/2}\) is at most \(e^{s^{2} - z^{2}/4}\), because \(sz \le z^{2}/4 + s^{2}\). That bound is integrable, so the integral converges absolutely and \[ E[e^{sZ}] = (2\pi)^{-1/2}\int e^{sz - z^{2}/2}\,dz. \] Complete the square: \[ sz - \frac{z^{2}}{2} = -\frac{(z - s)^{2}}{2} + \frac{s^{2}}{2}. \] So the integral is \(e^{s^{2}/2}\int e^{-(z-s)^{2}/2}\,dz\). Substituting \(u = z - s\) leaves the integral over the whole line unchanged, and by Proposition 1.2 of L06 it equals \(\sqrt{2\pi}\). Hence \(E[e^{sZ}] = e^{s^{2}/2}\), and \[ M_X(t) = e^{\mu t}\,e^{\sigma^{2}t^{2}/2} = \exp\big(\mu t + \sigma^{2}t^{2}/2\big). \]
[theorem] Proposition 1.4 (the square of a standard normal has no moment-generating function for large t)< grade=T :: /span> Assuming Assumption 1, let Z be standard normal and \(W = Z^{2}\). Then \(E[e^{tW}] = (1 - 2t)^{-1/2}\) for \(t < 1/2\), and \(E[e^{tW}] = \infty\) for \(t \ge 1/2\). So the domain of \(M_W\) is \((-\infty, 1/2)\).
[proof]  grade=- :: /span> The expectation is \[\begin{aligned} E[e^{tZ^{2}}] &= (2\pi)^{-1/2}\int e^{tz^{2}} e^{-z^{2}/2}\,dz \\ &= (2\pi)^{-1/2}\int e^{-(1 - 2t)z^{2}/2}\,dz \end{aligned}\]. For \(t \ge 1/2\), the exponent \(-(1 - 2t)z^{2}/2\) is nonnegative, so the integrand is at least \(1/\sqrt{2\pi}\) at every z, and the integral over the line is infinite. For \(t < 1/2\), put \(c = 1 - 2t > 0\) and substitute \(u = \sqrt{c}\,z\), so \(dz = du/\sqrt{c}\). The integral becomes \(c^{-1/2}\) times \((2\pi)^{-1/2}\int e^{-u^{2}/2}\,du\), and this equals \((1 - 2t)^{-1/2}\) by Proposition 1.2 of L06, which gives \(\int e^{-u^{2}/2}\,du = \sqrt{2\pi}\).
[remark] Remark 1.5 (what the domain means)< grade=- :: /span> A moment-generating function is defined on its domain. Proposition 1.2 covers finitely many values, and Proposition 1.3 covers the normal. Proposition 1.4 gives a variable whose domain is bounded above by \(1/2\). This page does not compute the domain of the Student-t moment-generating function, and no result below depends on it. 2Expectations of complex exponentials
[definition] Definition 2.1 (complex exponential)< grade=- :: /span> For a real a, the complex exponential is \(e^{ia} = \cos a + i\sin a\), where \(i^{2} = -1\). Its modulus is \(|e^{ia}| = \sqrt{\cos^{2}a + \sin^{2}a} = 1\). The expectation of a complex-valued variable is the expectation of its real part plus \(i\) times the expectation of its imaginary part.
[definition] Definition 2.2 (characteristic function)< grade=- :: /span> For a real random variable X and a real t, the characteristic function is \(\varphi_X(t) = E[e^{itX}]\).
[theorem] Proposition 2.3 (existence and bound for finitely valued variables and densities)< grade=T :: /span> Assuming Assumption 1(c) in the density case, for every real random variable X with finitely many values, or with a density, and every real t, \(\varphi_X(t)\) is defined. Moreover \(|\varphi_X(t)| \le 1\) and \(\varphi_X(0) = 1\).
[proof]  grade=- :: /span> The variable \(e^{itX}\) has modulus 1 for every outcome (Definition 2.1), so its real and imaginary parts are bounded by 1 and integrable. Its expectation is therefore finite. The triangle inequality for finite sums (or, in the density case, for integrals by Assumption 1(c)) gives \(|E[Y]| \le E[|Y|]\) for a complex variable Y. With \(Y = e^{itX}\), \(|\varphi_X(t)| \le E[1] = 1\). At \(t = 0\), \(e^{0} = 1\), so \(\varphi_X(0) = 1\).
[theorem] Proposition 2.4 (affine maps)< grade=T :: /span> For real a and b, \(\varphi_{aX + b}(t) = e^{itb}\,\varphi_X(at)\) for every real t.
[proof]  grade=- :: /span> Since \(e^{it(aX + b)} = e^{itb}e^{i(at)X}\) and \(e^{itb}\) is a constant, linearity of expectation gives \(E[e^{it(aX+b)}] = e^{itb}E[e^{i(at)X}] = e^{itb}\varphi_X(at)\).
[theorem] Proposition 2.5 (a two-point law)< grade=T :: /span> Let X take the value a with probability p and the value b with probability \(1 - p\), where \(0 < p < 1\). Then for every real t, \[ \varphi_X(t) = p\,e^{ita} + (1 - p)\,e^{itb}, \] and \(|\varphi_X(t)|^{2} = p^{2} + (1 - p)^{2} + 2p(1 - p)\cos\big(t(a - b)\big)\).
[proof]  grade=- :: /span> The first formula is the definition of the expectation over two values. For the modulus, write \(\alpha = p\), \(\beta = 1 - p\), \(\theta_1 = ta\) and \(\theta_2 = tb\). Then \[\begin{aligned} |\alpha e^{i\theta_1} + \beta e^{i\theta_2}|^{2} &= (\alpha\cos\theta_1 + \beta\cos\theta_2)^{2} \\ &\quad + (\alpha\sin\theta_1 + \beta\sin\theta_2)^{2} \end{aligned}\]. Expanding and using \(\cos^{2} + \sin^{2} = 1\) for each angle, the cross terms give \[\begin{aligned} &= \alpha^{2} + \beta^{2} \\ &\quad + 2\alpha\beta(\cos\theta_1\cos\theta_2 + \sin\theta_1\sin\theta_2) \\ &= \alpha^{2} + \beta^{2} + 2\alpha\beta\cos(\theta_1 - \theta_2) \end{aligned}\], by the cosine of a difference. So the modulus squared is \(\alpha^{2} + \beta^{2} + 2\alpha\beta\cos(t(a - b))\).
