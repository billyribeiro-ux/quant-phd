[proposition] Proposition 1.1 (the first two central moments)< grade=T :: /span> For a random variable \(X\) on a finite probability space with positive weights, \(m_1 = 0\) and \(m_2 = \operatorname{Var}(X)\).
[proof]  grade=- :: /span> By linearity of expectation (Lesson 2, Proposition 1.3), \(m_1 = E[X] - \mu = \mu - \mu = 0\). The second claim is Definition 2.1 of Lesson 2 with \(k = 2\). \(\blacksquare\) 2Standardized moments: skewness and kurtosis
[definition] Definition 2.1 (standardized variable)< grade=- :: /span> Let \(X\) take at least two values on a finite probability space with positive weights, so that \(\sigma = \sqrt{\operatorname{Var}(X)} > 0\) by Lesson 2, Proposition 2.4. The standardized variable is \(Z = (X - \mu)/\sigma\). It has mean 0 and variance 1, which Proposition 2.3 checks.
[definition] Definition 2.2 (skewness and kurtosis)< grade=- :: /span> The skewness of \(X\) is \(\gamma_3 = E[Z^3]\), the third standardized moment. The kurtosis of \(X\) is \(\gamma_4 = E[Z^4]\), the fourth standardized moment. This lesson uses the kurtosis without subtracting 3. Excess kurtosis, the kurtosis minus 3, is a different quantity and is not used on this page. Every kurtosis computed on this page is \(E[Z^4]\) in this sense.
[proposition] Proposition 2.3 (standardized moments in central moments)< grade=T :: /span> Let \(X\) take at least two values on a finite probability space with positive weights. Then \(E[Z] = 0\), \(E[Z^2] = 1\), \(\gamma_3 = m_3 / \sigma^3\), and \(\gamma_4 = m_4 / \sigma^4 = m_4 / m_2^2\).
[proof]  grade=- :: /span> Write \(Z = (X - \mu)/\sigma\), where \(\sigma\) is a positive constant. By linearity (Lesson 2, Proposition 1.3), \(E[Z^j] = E[(X - \mu)^j]/\sigma^j\) for \(j = 1, 2, 3, 4\), because \((X - \mu)^j / \sigma^j\) is the \(j\)-th power of \(Z\) and dividing by the constant \(\sigma^j\) pulls out of the sum. So \(E[Z] = m_1/\sigma = 0\) and \(E[Z^2] = m_2/\sigma^2 = 1\). Also \(\gamma_3 = E[Z^3] = m_3/\sigma^3\) and \(\gamma_4 = E[Z^4] = m_4/\sigma^4\). Since \(\sigma^4 = m_2^2\), the last form follows. \(\blacksquare\)
[proposition] Proposition 2.4 (affine maps)< grade=T :: /span> Let \(X\) take at least two values on a finite probability space with positive weights, and let \(Y = aX + b\) with constants \(a \ne 0\) and \(b\). Then \(\gamma_{4,Y} = \gamma_{4,X}\), and \(\gamma_{3,Y} = \operatorname{sign}(a)\, \gamma_{3,X}\), where \(\operatorname{sign}(a)\) is 1 for \(a > 0\) and \(-1\) for \(a < 0\).
[proof]  grade=- :: /span> By Lesson 2, Proposition 2.3, \(\sigma_Y = |a| \sigma_X\), since \(\sigma_Y^2 = a^2 \sigma_X^2\). Also \(E[Y] = a\mu_X + b\), so \(Y - E[Y] = a(X - \mu_X)\). Therefore \(Z_Y = a(X - \mu_X) / (|a| \sigma_X) = \operatorname{sign}(a)\, Z_X\). Raising to the third power gives \(Z_Y^3 = \operatorname{sign}(a)^3 Z_X^3 = \operatorname{sign}(a)\, Z_X^3\), and to the fourth power gives \(Z_Y^4 = Z_X^4\), since \(\operatorname{sign}(a)^4 = 1\). Taking expectations gives the two claims. \(\blacksquare\)
[proposition] Proposition 2.5 (kurtosis is at least 1)< grade=T :: /span> Let \(X\) take at least two values on a finite probability space with positive weights. Then \(\gamma_4 \ge 1\), and \(\gamma_4 = 1\) if and only if \(X\) takes exactly two values, each with probability \(\tfrac12\).
[proof]  grade=- :: /span> Let \(W = Z^2\). By Proposition 2.3, \(E[W] = 1\) and \(E[W^2] = E[Z^4] = \gamma_4\). The shortcut formula of Lesson 2, Proposition 2.2, applied to \(W\), gives \(\operatorname{Var}(W) = E[W^2] - (E[W])^2 = \gamma_4 - 1\). A variance is nonnegative, so \(\gamma_4 \ge 1\). For the equality case, \(\gamma_4 = 1\) means \(\operatorname{Var}(W) = 0\), so by Lesson 2, Proposition 2.4, \(W = Z^2\) takes a single value, which is \(E[W] = 1\). Then \(Z\) takes the values \(\pm 1\). Since \(E[Z] = 0\), write \(P(Z = 1) = r\), so \(P(Z = -1) = 1 - r\), and \(E[Z] = r - (1 - r) = 2r - 1 = 0\), which gives \(r = \tfrac12\). Conversely, if \(X\) takes two values \(a < b\) with probability \(\tfrac12\) each, then \(\mu = (a + b)/2\) and \(\sigma = (b - a)/2\), so \(Z = \pm 1\) with probability \(\tfrac12\) each, and \(\gamma_4 = E[Z^4] = 1\). \(\blacksquare\)
[example] Example 2.6 (the two-point Bernoulli law)< grade=- :: /span> Let \(X\) take the value 1 with probability \(p\) and 0 with probability \(q = 1 - p\), where \(0 < p < 1\). Then \(\mu = p\) and \(\sigma^2 = \operatorname{Var}(X) = p - p^2 = pq\), by Lesson 2, Proposition 2.2. The centred values are \(X - p = q\) when \(X = 1\), and \(X - p = -p\) when \(X = 0\). So \(m_3 = p\,q^3 - q\,p^3 = pq(q^2 - p^2) = pq(q - p)\), and \(m_4 = p\,q^4 + q\,p^4 = pq(q^3 + p^3) = pq(1 - 3pq)\), using \(q^3 + p^3 = (q + p)(q^2 - pq + p^2)\), \(q + p = 1\), and \(q^2 - pq + p^2 = (q + p)^2 - 3pq = 1 - 3pq\). By Proposition 2.3, \[\gamma_3 = \frac{pq(q - p)}{(pq)^{3/2}} = \frac{1 - 2p}{\sqrt{pq}}, \qquad \gamma_4 = \frac{pq(1 - 3pq)}{(pq)^2} = \frac{1 - 3pq}{pq}.\] For \(p = \tfrac1{10}\), \(pq = \tfrac{9}{100}\) and \(\sqrt{pq} = \tfrac{3}{10}\), so \(\gamma_3 = \tfrac{4/5}{3/10} = \tfrac83\) and \(\gamma_4 = \tfrac{73/100}{9/100} = \tfrac{73}{9}\), which is about 8.11. Lab 1 checks the squared skewness \(\gamma_3^2 = \tfrac{64}{9}\) and the kurtosis \(\gamma_4 = \tfrac{73}{9}\) exactly.
