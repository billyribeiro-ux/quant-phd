[proposition] Proposition 1.1 (second moments of a standard normal vector)< grade=T :: /span> Assuming Lesson 6's Assumption 1, let \(Z\) be a standard normal vector of length \(k\). Then \(E[Z_i Z_j] = 1\) if \(i = j\) and \(E[Z_i Z_j] = 0\) if \(i \ne j\). In matrix form, \(E[ZZ^{\top}] = I_k\), the identity matrix.
[proof]  grade=- :: /span> If \(i = j\), then \[E[Z_i Z_j] = E[Z_i^2] = \operatorname{Var}(Z_i) + (E[Z_i])^2 = 1 + 0 = 1\]. If \(i \ne j\), the coordinates \(Z_i\) and \(Z_j\) are independent, so \[E[Z_i Z_j] = E[Z_i]\,E[Z_j] = 0\]. The product rule for independent variables is the factorization of Lesson 4, which Lesson 6, Remark 2.2 states for nonnegative functions. Write \(Z_i = Z_i^{+} - Z_i^{-}\) and \(Z_j = Z_j^{+} - Z_j^{-}\) with nonnegative parts. Each part has a finite expectation, because \(|z| \le (1 + z^2)/2\) and \(E[Z_i^2] = 1\). Applying the rule to each of the four products of parts gives \(E[Z_i Z_j] = E[Z_i]\,E[Z_j]\), which is 0. The matrix identity follows because entry \((i, j)\) of \(ZZ^{\top}\) is \(Z_i Z_j\). \(\blacksquare\)
[definition] Definition 1.2 (multivariate normal)< grade=- :: /span> Let \(\mu\) be a vector of length \(d\), let \(\Sigma\) be a symmetric \(d \times d\) matrix, and let \(Z\) be a standard normal vector of length \(k\). A random vector \(X\) of length \(d\) is multivariate normal with mean \(\mu\) and covariance matrix \(\Sigma\) when \(X\) has the same law as \(\mu + AZ\) for some \(d \times k\) matrix \(A\) with \[AA^{\top} = \Sigma\]. The matrix \(A\) is called a factor of \(\Sigma\). This lesson gives an explicit factor for one example, in Example 1.5. It does not prove that every symmetric nonnegative \(\Sigma\) has a factor, and no result below needs that fact.
[proposition] Proposition 1.3 (mean and covariance of a linear image)< grade=T :: /span> Assuming Lesson 6's Assumption 1, let \(X = \mu + AZ\), where \(Z\) is a standard normal vector of length \(k\), \(\mu\) is a constant vector of length \(d\), and \(A\) is a constant \(d \times k\) matrix. Then \(E[X] = \mu\), and the covariance matrix of \(X\), whose entry \((r, s)\) is \(\operatorname{Cov}(X_r, X_s)\) of Lesson 5, equals \(AA^{\top}\).
[proof]  grade=- :: /span> By linearity of expectation (Lesson 2) and \(E[Z] = 0\) from Lesson 6, \(E[X] = \mu + A\,E[Z] = \mu\). The covariance of \(X_r\) and \(X_s\) is \[E[(X_r - E[X_r])(X_s - E[X_s])]\], as in Lesson 5. Write \(\mu_r\) for the \(r\)-th entry of \(\mu\). Then \(X_r - \mu_r = \sum_{i=1}^{k} A_{ri} Z_i\), so \[ \operatorname{Cov}(X_r, X_s) = E\Bigl[\sum_{i=1}^{k} \sum_{j=1}^{k} A_{ri} A_{sj} Z_i Z_j\Bigr] = \sum_{i=1}^{k} \sum_{j=1}^{k} A_{ri} A_{sj}\, E[Z_i Z_j]. \] The second equality uses linearity of expectation for finite sums. By Proposition 1.1, \(E[Z_i Z_j]\) is \(1\) when \(i = j\) and \(0\) otherwise, so the double sum collapses to \(\sum_{i} A_{ri} A_{si}\). That sum is entry \((r, s)\) of \(AA^{\top}\). \(\blacksquare\)
[remark] Remark 1.4 (the factor is not unique)< grade=- :: /span> If \(Q\) is a \(k \times k\) matrix with \(QQ^{\top} = I\), then \(A\) and \(AQ\) are both factors of \(AA^{\top}\). Indeed \[(AQ)(AQ)^{\top} = A(QQ^{\top})A^{\top} = AA^{\top}\]. Assuming Lesson 6's Assumption 1, Proposition 1.3 then gives the same mean and covariance for \(\mu + AQZ\) as for \(\mu + AZ\). A covariance matrix does not determine its factor.
[example] Example 1.5 (a two-dimensional factor, with a second factor)< grade=- :: /span> Take \(\mu = (1, -2)\) and \(A = \begin{pmatrix} 2 & 0 \\ 1 & 1 \end{pmatrix}\). Then \[ \Sigma = AA^{\top} = \begin{pmatrix} 4 & 2 \\ 2 & 2 \end{pmatrix}. \] The rotation \(Q = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}\) satisfies \(QQ^{\top} = I\), since its rows are orthonormal. The second factor is \[B = AQ = \begin{pmatrix} 0 & -2 \\ 1 & -1 \end{pmatrix}\], and \(BB^{\top} = \Sigma\) by Remark 1.4. The matrix \(A^{\top}A = \begin{pmatrix} 5 & 1 \\ 1 & 1 \end{pmatrix}\) is a different matrix, and it is not a covariance matrix of \(X = \mu + AZ\). Assuming Lesson 6's Assumption 1, Proposition 1.3 gives \(E[X] = (1, -2)\) and covariance \(\Sigma\) for both \(X = \mu + AZ\) and \(Y = \mu + BZ\).
[proposition] Proposition 1.6 (covariance matrices are symmetric and nonnegative)< grade=T :: /span> Let \(\Sigma = AA^{\top}\) for a real matrix \(A\). Then \(\Sigma\) is symmetric, and \(w^{\top}\Sigma w \ge 0\) for every vector \(w\) of the matching length.
[proof]  grade=- :: /span> \((AA^{\top})^{\top} = (A^{\top})^{\top} A^{\top} = AA^{\top}\), so \(\Sigma\) is symmetric. For any \(w\), \[w^{\top}AA^{\top}w = (A^{\top}w)^{\top}(A^{\top}w)\], which is the sum of the squares of the entries of \(A^{\top}w\), and so is nonnegative. \(\blacksquare\) Proposition 1.6 is the statement of Lesson 5, Proposition 2.3 (a covariance matrix is positive semidefinite), proved here for the matrices that this lesson uses. A symmetric matrix \(\Sigma\) is positive definite when \(w^{\top}\Sigma w > 0\) for every nonzero vector \(w\). Example 1.5 is positive definite, because \(w^{\top}\Sigma w = (2w_1 + w_2)^2 + w_2^2\), which is zero only when \(w_2 = 0\) and \(2w_1 = 0\), that is, when \(w = 0\). 2Singular covariance matrices This section proves one fact about covariance matrices that are not positive definite. It states no density formula for a multivariate normal law with a general factor. Section 4 uses one density only, the product density of two independent standard normal variables. A square matrix is singular when it has no inverse. A matrix with a nonzero \(w\) such that \(\Sigma w = 0\) is not positive definite, because then \(w^{\top}\Sigma w = 0\); Proposition 2.1 gives the converse for \(\Sigma = AA^{\top}\).
[proposition] Proposition 2.1 (a singular covariance has no inverse)< grade=T :: /span> Let \(\Sigma = AA^{\top}\) for a real matrix \(A\), and suppose that \(\Sigma\) is not positive definite. Then there is a nonzero vector \(w\) with \(\Sigma w = 0\), and \(\Sigma\) has no inverse.
[proof]  grade=- :: /span> Since \(\Sigma\) is not positive definite, some nonzero \(w\) has \(w^{\top}\Sigma w \le 0\). By Proposition 1.6, \(w^{\top}\Sigma w \ge 0\), so \(w^{\top}\Sigma w = 0\). Write \(u = A^{\top}w\). The proof of Proposition 1.6 gives \(w^{\top}\Sigma w = u^{\top}u = \sum_j u_j^2\), so every \(u_j\) is 0 and \(u = 0\). Hence \(\Sigma w = A(A^{\top}w) = Au = 0\).
