[assumption] Assumption 1 (calculus and measure facts used without proof)< grade=- :: /span> The page uses the following standard facts without proof. (a) The substitution rule, integration by parts, the fundamental theorem of calculus for improper integrals of continuous functions over the real line, and the derivative of \(e^{u}\), which gives \(\varphi'(z) = -z\varphi(z)\). (b) Polar coordinates in the plane, with Jacobian \(r\). (c) Tonelli's theorem for nonnegative integrands, which lets a double integral equal an iterated integral. (d) For independent variables X and Y, the joint law of the pair is the product of their two laws. Functions of independent variables are independent: if X and Y are independent, then f(X) and g(Y) are independent for the functions f and g that the page applies, and a function of a finite family of independent variables is independent of any variable that is independent of the whole family. Each result that uses Assumption 1 says so in its statement.
[definition] Definition 1.1 (normal distribution)< grade=- :: /span> For a real \(\mu\) and \(\sigma > 0\), the normal distribution \(N(\mu, \sigma^{2})\) is the law with density \(f(x) = \dfrac{1}{\sigma\sqrt{2\pi}}\exp\!\Big(-\dfrac{(x - \mu)^{2}}{2\sigma^{2}}\Big)\) on the real line. The standard normal law is \(N(0,1)\), with density \(\varphi(z) = e^{-z^{2}/2}/\sqrt{2\pi}\). A variable Z with this law is a standard normal variable.
[theorem] Proposition 1.2 (the Gaussian integral)< grade=T :: /span> Assuming Assumption 1, the integral \(I = \int_{-\infty}^{\infty} e^{-x^{2}/2}\,dx\) converges and equals \(\sqrt{2\pi}\).
[proof]  grade=- :: /span> The integrand is positive and is at most \(e^{-|x|}\) for \(|x| \ge 2\), since \(x^{2}/2 \ge |x|\) there. So the integral converges. Let \(J = \int_{-\infty}^{\infty}\int_{-\infty}^{\infty} e^{-(x^{2} + y^{2})/2}\,dx\,dy\) over the plane. Since the integrand is nonnegative, Tonelli's theorem (Assumption 1(c)) lets the double integral equal \(I^{2}\), because \(e^{-(x^{2}+y^{2})/2} = e^{-x^{2}/2}e^{-y^{2}/2}\). Change to polar coordinates (Assumption 1(b)) \(x = r\cos\theta\), \(y = r\sin\theta\), with Jacobian r and \(r \ge 0\), \(\theta \in [0, 2\pi)\): \[ I^{2} = \int_{0}^{2\pi}\int_{0}^{\infty} e^{-r^{2}/2}\,r\,dr\,d\theta = 2\pi\Big[-e^{-r^{2}/2}\Big]_{0}^{\infty} = 2\pi. \] Since \(I > 0\), \(I = \sqrt{2\pi}\).
[theorem] Proposition 1.3 (the normal density integrates to one)< grade=T :: /span> Assuming Assumption 1, for \(\sigma > 0\) and real \(\mu\), the function f of Definition 1.1 is a probability density: it is nonnegative and \(\int f = 1\). In particular \(\varphi\) is a density.
[proof]  grade=- :: /span> Substitute \(x = \mu + \sigma u\), so \(dx = \sigma\,du\). Then \(\int_{-\infty}^{\infty} f(x)\,dx = \int_{-\infty}^{\infty} \frac{1}{\sigma\sqrt{2\pi}} e^{-u^{2}/2}\,\sigma\,du = \frac{I}{\sqrt{2\pi}} = 1\) by Proposition 1.2.
[theorem] Proposition 1.4 (standardization)< grade=T :: /span> Assuming Assumption 1, let \(X \sim N(\mu, \sigma^{2})\) with \(\sigma > 0\). Then \(Z = (X - \mu)/\sigma\) has the standard normal law \(N(0,1)\). Conversely, if Z is standard normal, then \(\mu + \sigma Z \sim N(\mu, \sigma^{2})\).
[proof]  grade=- :: /span> For real z, \(P(Z \le z) = P(X \le \mu + \sigma z) = \int_{-\infty}^{\mu + \sigma z} f(x)\,dx\). Substituting \(x = \mu + \sigma u\) as in Proposition 1.3 gives \(\int_{-\infty}^{z} \varphi(u)\,du\), which is the distribution function of N(0,1). The converse follows by reversing the substitution.
[theorem] Proposition 1.5 (moments of the standard normal)< grade=T :: /span> Assuming Assumption 1, if Z is standard normal, then \(E[Z] = 0\) and \(E[Z^{2}] = 1\), so \(\operatorname{Var}(Z) = 1\). Consequently, if \(X \sim N(\mu, \sigma^{2})\), then \(E[X] = \mu\) and \(\operatorname{Var}(X) = \sigma^{2}\).
[proof]  grade=- :: /span> The integrand \(z\varphi(z)\) is odd, and \(|z|\varphi(z)\) is integrable. Write \(|z|\varphi(z) = (|z|e^{-z^{2}/4})\,e^{-z^{2}/4}/\sqrt{2\pi}\). For \(z \ge 0\), the derivative of \(z e^{-z^{2}/4}\) is \((1 - z^{2}/2)e^{-z^{2}/4}\), which is positive on \([0, \sqrt{2})\) and negative after \(\sqrt{2}\), so the maximum of \(|z|e^{-z^{2}/4}\) is \(\sqrt{2}\,e^{-1/2} < 0.86\). Since \(1/\sqrt{2\pi} < 1\), \(|z|\varphi(z) \le 0.86\,e^{-z^{2}/4}\). The function \(e^{-z^{2}/4}\) is integrable on the line by the substitution \(z = \sqrt{2}\,x\) and Proposition 1.2. So \(\int z\varphi(z)\,dz = 0\), because the integral over \((-\infty, 0]\) is minus the integral over \([0, \infty)\). For the second moment, note \(\varphi'(z) = -z\varphi(z)\). Integrating by parts with \(u = z\) and \(dv = z\varphi(z)\,dz\), so \(v = -\varphi(z)\), \[ \int_{-\infty}^{\infty} z^{2}\varphi(z)\,dz = \Big[-z\varphi(z)\Big]_{-\infty}^{\infty} + \int_{-\infty}^{\infty}\varphi(z)\,dz = 0 + 1 = 1. \] The boundary term vanishes because \(z\varphi(z) \to 0\) at both ends, and the last integral is 1 by Proposition 1.3. So \(\operatorname{Var}(Z) = E[Z^{2}] - (E[Z])^{2} = 1\). For \(X = \mu + \sigma Z\), which has the law \(N(\mu, \sigma^{2})\) by Proposition 1.4, linearity gives \(E[X] = \mu + \sigma E[Z] = \mu\), and \(\operatorname{Var}(X) = E[(\sigma Z)^{2}] = \sigma^{2}E[Z^{2}] = \sigma^{2}\), because the constant \(\sigma^{2}\) comes out of the integral by linearity. 2Sums of squared normals and their ratio
[definition] Definition 2.1 (chi-square variable, defined by its sum)< grade=- :: /span> For a positive integer \(\nu\), a chi-square variable with \(\nu\) degrees of freedom is \(W_{\nu} = Z_{1}^{2} + \dots + Z_{\nu}^{2}\), where \(Z_{1}, \dots, Z_{\nu}\) are independent standard normal variables. Its law is fixed by this sum. The page uses the sum as the definition.
[remark] Remark 2.2 (independence for variables with densities)< grade=- :: /span> Variables X and Y are independent when \(P(X \in A,\ Y \in B) = P(X \in A)\,P(Y \in B)\) for all sets A and B. Assuming Assumption 1(d), two consequences are used below. For independent variables and functions g and h that are nonnegative, \(E[g(X)h(Y)] = E[g(X)]\,E[h(Y)]\). This is Tonelli's theorem (Assumption 1(c)) applied to the product of the two laws. Functions of independent variables are independent (Assumption 1(d)). The page uses both facts in the proofs below.
[theorem] Lemma 2.3 (a Laplace transform of a squared normal)< grade=T :: /span> Assuming Assumption 1, for \(s \ge 0\), \(E[e^{-sZ^{2}}] = (1 + 2s)^{-1/2}\) for a standard normal Z. For a chi-square variable W with \(\nu\) degrees of freedom, \(W > 0\) with probability one, and \(E[1/W] = \int_{0}^{\infty} (1 + 2s)^{-\nu/2}\,ds\), which is a value in \((0, \infty]\).
[proof]  grade=- :: /span> First, \(E[e^{-sZ^{2}}] = \frac{1}{\sqrt{2\pi}}\int e^{-sz^{2}} e^{-z^{2}/2}\,dz = \frac{1}{\sqrt{2\pi}}\int e^{-(1 + 2s)z^{2}/2}\,dz\). Substitute \(u = \sqrt{1 + 2s}\,z\), so \(dz = du/\sqrt{1 + 2s}\). The integral is \((1 + 2s)^{-1/2}\) times \(\frac{1}{\sqrt{2\pi}}\int e^{-u^{2}/2}\,du = 1\), by Proposition 1.2 and Proposition 1.3. Second, W is zero only if every \(Z_i\) is zero, and \(P(Z_1 = 0) = 0\) because a single point has zero length under a density. So \(W > 0\) with probability one. For \(w > 0\), \(1/w = \int_{0}^{\infty} e^{-sw}\,ds\). Substitute \(w = W\) and use Tonelli's theorem, since the integrand is nonnegative: \[ E[1/W] = \int_{0}^{\infty} E[e^{-sW}]\,ds. \] By independence (Remark 2.2), \(E[e^{-sW}] = \prod_{i=1}^{\nu} E[e^{-sZ_i^{2}}] = (1 + 2s)^{-\nu/2}\), using the first step for each \(Z_i\). This gives the formula.
[theorem] Proposition 2.4 (the mean of the reciprocal of a chi-square)< grade=T :: /span> Assuming Assumption 1 and Lemma 2.3, let W be chi-square with \(\nu\) degrees of freedom, a positive integer. If \(\nu > 2\), then \(E[1/W] = 1/(\nu - 2)\). If \(\nu \le 2\), then \(E[1/W] = \infty\).
[proof]  grade=- :: /span> Let \(a = \nu/2\). By Lemma 2.3, \(E[1/W] = \int_{0}^{\infty} (1 + 2s)^{-a}\,ds\). Suppose \(a > 1\). An antiderivative of \((1 + 2s)^{-a}\) is \((1 + 2s)^{1-a}/(2(1 - a))\), which tends to 0 as \(s \to \infty\), because \(1 - a < 0\). So the integral is \(0 - 1/(2(1 - a)) = 1/(2(a - 1)) = 1/(\nu - 2)\). Now suppose \(a \le 1\). For \(s \ge 0\), \(1 + 2s \ge 1\) and \(-a \ge -1\), so \((1 + 2s)^{-a} \ge (1 + 2s)^{-1}\). The integral of \((1 + 2s)^{-1}\) over \([0, \infty)\) is infinite, because its antiderivative \(\tfrac12\ln(1 + 2s)\) tends to infinity. By comparison the integral is infinite.
[definition] Definition 2.5 (Student-t variable)< grade=- :: /span> For a positive integer \(\nu\), the Student-t distribution with \(\nu\) degrees of freedom is the law of \(\mathrm{t}_{\nu} = Z / \sqrt{W_{\nu}/\nu}\), where Z is standard normal and \(W_{\nu}\) is a chi-square variable with \(\nu\) degrees of freedom, independent of Z. The page takes \(\nu\) to be a positive integer, as Lab 1 does. It does not define the Student-t for non-integer \(\nu\).
[theorem] Proposition 2.6 (mean and variance of the Student-t)< grade=T :: /span> Assuming Assumption 1, let \(\mathrm{t} = \mathrm{t}_{\nu}\) with \(\nu\) a positive integer. If \(\nu > 2\), then \(E[\mathrm{t}] = 0\) and \(\operatorname{Var}(\mathrm{t}) = \nu/(\nu - 2)\). If \(\nu \le 2\), then \(E[\mathrm{t}^{2}] = \infty\). In either case the law of \(\mathrm{t}\) is symmetric about 0.
[proof]  grade=- :: /span> Let \(V = (\nu/W)^{1/2}\), a function of W, so that \(\mathrm{t} = ZV\) and Z and V are independent (Remark 2.2). Since \(E[Z^{2}] = 1\) (Proposition 1.5) and the two factors are independent and nonnegative in \(Z^{2}V^{2}\), Remark 2.2 gives \[ E[\mathrm{t}^{2}] = E[Z^{2}]\,E[V^{2}] = \nu\,E[1/W]. \] If \(\nu > 2\), Proposition 2.4 gives \(E[\mathrm{t}^{2}] = \nu/(\nu - 2)\), which is finite. If \(\nu \le 2\), Proposition 2.4 gives \(E[\mathrm{t}^{2}] = \infty\). For the mean when \(\nu > 2\): \(E[V] \le (1 + E[V^{2}])/2 < \infty\), because \(v \le (1 + v^{2})/2\) for every real v, and \(E[V^{2}] = \nu E[1/W] < \infty\). So \(E[|Z|]\,E[V] < \infty\), where \(E[|Z|] = \sqrt{2/\pi}\) is finite (Problem R1). Write \(Z = Z^{+} - Z^{-}\) with both parts nonnegative. Remark 2.2 gives \(E[Z^{+}V] = E[Z^{+}]\,E[V]\) and \(E[Z^{-}V] = E[Z^{-}]\,E[V]\), both finite, so \(E[ZV] = E[Z]\,E[V] = 0\), since \(E[Z] = 0\) by Proposition 1.5. Therefore \(E[\mathrm{t}] = 0\), and \(\operatorname{Var}(\mathrm{t}) = E[\mathrm{t}^{2}] - (E[\mathrm{t}])^{2} = \nu/(\nu - 2)\). For symmetry, \(-Z\) has the standard normal law, because \(\varphi\) is even, and \(-Z\) is independent of V, a function of W (Remark 2.2). So \((-Z, V)\) has the same joint law as \((Z, V)\) (Assumption 1(d)), and \(-\mathrm{t} = (-Z)V\) has the same law as \(\mathrm{t}\).
[remark] Remark 2.7 (what the formula does and does not say)< grade=- :: /span> Proposition 2.6 gives the variance for \(\nu > 2\) and says that \(E[\mathrm{t}^{2}]\) is infinite for \(\nu \le 2\). It does not say what the sample variance does for \(\nu \le 2\). For \(\nu = 3\), the variance is 3, which is larger than the variance 1 of the standard normal \(N(0,1)\).
