[theorem] Proposition 1.1 (bilinearity and symmetry of covariance)< grade=T :: /span> For random variables X, Y and Z with finitely many values, and real numbers a and b: (i) \(\operatorname{Cov}(X,Y) = \operatorname{Cov}(Y,X)\); (ii) \(\operatorname{Cov}(aX + b, Y) = a\,\operatorname{Cov}(X,Y)\); (iii) \(\operatorname{Cov}(X + Z, Y) = \operatorname{Cov}(X,Y) + \operatorname{Cov}(Z,Y)\); (iv) \(\operatorname{Cov}(X,X) = \operatorname{Var}(X) \ge 0\).
[proof]  grade=- :: /span> (i) The product \((X - E[X])(Y - E[Y])\) is the same as \((Y - E[Y])(X - E[X])\). (ii) Since \(E[aX + b] = aE[X] + b\), the centred variable is \(aX + b - E[aX + b] = a(X - E[X])\). So \(\operatorname{Cov}(aX + b, Y) = E[a(X - E[X])(Y - E[Y])] = a\,\operatorname{Cov}(X,Y)\), by linearity of finite expectations. (iii) Expand the product and use linearity of expectation, the same way as in the proof of Proposition 1.7 of L04. (iv) Setting \(Y = X\) in Proposition 1.7 of L04 gives \(\operatorname{Cov}(X,X) = E[X^{2}] - (E[X])^{2}\), which is \(\operatorname{Var}(X)\) by the formula of L02. The value is a finite sum of squares times probabilities, so it is nonnegative.
[theorem] Proposition 1.2 (covariance under scaling)< grade=T :: /span> For real a, b, c and d, \(\operatorname{Cov}(aX + b,\ cY + d) = ac\,\operatorname{Cov}(X,Y)\). In particular \(\operatorname{Var}(aX + b) = a^{2}\operatorname{Var}(X)\).
[proof]  grade=- :: /span> By Proposition 1.1(ii), \(\operatorname{Cov}(aX + b, Y) = a\,\operatorname{Cov}(X,Y)\). By symmetry (i) and (ii) again, \(\operatorname{Cov}(aX + b,\ cY + d) = c\,\operatorname{Cov}(aX + b, Y) = ac\,\operatorname{Cov}(X,Y)\). Setting \(Y = X\), \(c = a\) and \(d = b\) gives \(\operatorname{Var}(aX + b) = a^{2}\operatorname{Cov}(X,X) = a^{2}\operatorname{Var}(X)\).
[remark] Remark 1.3 (notation for the standard deviation)< grade=- :: /span> The standard deviation of \(X\) is defined in Lesson L02, Definition 2.1. This lesson writes it \(\sigma_X = \sqrt{\operatorname{Var}(X)}\), the nonnegative square root of the variance.
[definition] Definition 1.4 (correlation)< grade=- :: /span> For X and Y with \(\sigma_X > 0\) and \(\sigma_Y > 0\), the correlation is \(\rho(X,Y) = \operatorname{Cov}(X,Y)/(\sigma_X \sigma_Y)\). The condition \(\sigma_X > 0\) excludes a constant X, whose correlation is not defined.
[theorem] Proposition 1.5 (Cauchy–Schwarz for covariance)< grade=T :: /span> For random variables X and Y with finitely many values, \(\operatorname{Cov}(X,Y)^{2} \le \operatorname{Var}(X)\operatorname{Var}(Y)\). Consequently, if \(\sigma_X > 0\) and \(\sigma_Y > 0\), then \(-1 \le \rho(X,Y) \le 1\).
[proof]  grade=- :: /span> Let \(U = X - E[X]\) and \(V = Y - E[Y]\). For every real t, the variable \((U + tV)^{2}\) is nonnegative, so its expectation is nonnegative: \[ 0 \le E[(U + tV)^{2}] = E[V^{2}]\,t^{2} + 2\,E[UV]\,t + E[U^{2}] =: At^{2} + Bt + C. \] Here \(A = \operatorname{Var}(Y)\), \(B = 2\operatorname{Cov}(X,Y)\) and \(C = \operatorname{Var}(X)\). First suppose \(A = 0\). Then \(V^{2}\) has zero expectation, and since every support point has positive probability, \(V = 0\) at every support point. So \(E[UV] = 0\), which gives \(\operatorname{Cov}(X,Y) = 0\), and the inequality holds with \(0 \le 0\). Now suppose \(A > 0\). Completing the square, \(At^{2} + Bt + C = A(t + B/(2A))^{2} + (C - B^{2}/(4A))\). Taking \(t = -B/(2A)\) gives \(C - B^{2}/(4A) \ge 0\), so \(B^{2} \le 4AC\). Substituting, \(4\operatorname{Cov}(X,Y)^{2} \le 4\operatorname{Var}(X)\operatorname{Var}(Y)\). The bound on \(\rho\) follows by dividing by \(\sigma_X^{2}\sigma_Y^{2} > 0\) and taking square roots.
[theorem] Proposition 1.6 (correlation is unchanged by positive affine maps)< grade=T :: /span> Let \(\sigma_X > 0\) and \(\sigma_Y > 0\). For real \(a, c > 0\) and any real b and d, \(\rho(aX + b,\ cY + d) = \rho(X,Y)\).
[proof]  grade=- :: /span> By Proposition 1.2, \(\operatorname{Cov}(aX + b, cY + d) = ac\,\operatorname{Cov}(X,Y)\) and \(\operatorname{Var}(aX + b) = a^{2}\operatorname{Var}(X)\). Since \(a > 0\), the standard deviation of \(aX + b\) is \(a\sigma_X\), and similarly for \(cY + d\) it is \(c\sigma_Y\). So \(\rho(aX + b,\ cY + d) = ac\,\operatorname{Cov}(X,Y)/(ac\,\sigma_X\sigma_Y) = \rho(X,Y)\).
[example] Example 1.7 (correlation one for an increasing affine map)< grade=- :: /span> Let \(\sigma_X > 0\), let \(a > 0\), and let \(Y = aX + b\). By Proposition 1.2, \(\operatorname{Cov}(X,Y) = a\operatorname{Var}(X)\). Also \(\sigma_Y = a\sigma_X\). So \(\rho(X,Y) = a\operatorname{Var}(X)/(\sigma_X \cdot a\sigma_X) = 1\), because \(\operatorname{Var}(X) = \sigma_X^{2}\).
[remark] Remark 1.8 (correlation measures linear association)< grade=- :: /span> Let X be uniform on \(\{-1, 0, 1\}\) and \(Y = X^{2}\), the pair of Example 1.9 in L04. Since \(E[X] = 0\) and \(XY = X^{3}\) takes the values \(-1, 0, 1\) with probability 1/3 each, \(E[XY] = 0\), so \(\operatorname{Cov}(X,Y) = E[XY] - E[X]E[Y] = 0\). Also \(\operatorname{Var}(X) = E[X^{2}] = 2/3 > 0\) and \(\operatorname{Var}(Y) = E[X^{4}] - (E[Y])^{2} = 2/3 - 4/9 = 2/9 > 0\), using \(E[X^{4}] = E[X^{2}] = 2/3\). So \(\rho(X,Y) = 0\), although Y is a function of X. Y is not independent of X either: \(P(X = 0, Y = 0) = 1/3\), while \(P(X = 0)P(Y = 0) = 1/9\). That zero reflects the absence of a linear trend, and it does not show that the two are unrelated. Lab 1 of L04 checks the covariance of this pair. 2Stacking covariances into a matrix
[definition] Definition 2.1 (covariance matrix)< grade=- :: /span> For a vector \(X = (X_1, \dots, X_n)\) of random variables with finitely many values, the covariance matrix is the \(n \times n\) matrix \(\Sigma\) with entries \(\Sigma_{ij} = \operatorname{Cov}(X_i, X_j)\). Its diagonal entries are the variances \(\Sigma_{ii} = \operatorname{Var}(X_i)\).
[definition] Definition 2.2 (positive semidefinite, defined here)< grade=- :: /span> A real symmetric \(n \times n\) matrix \(M\) is positive semidefinite when \(w^{\top}Mw \ge 0\) for every vector \(w \in \R^{n}\), where \(w^{\top}Mw = \sum_{i}\sum_{j} w_i M_{ij} w_j\) is the quadratic form.
[theorem] Proposition 2.3 (a covariance matrix is positive semidefinite)< grade=T :: /span> Let \(\Sigma\) be the covariance matrix of \(X = (X_1, \dots, X_n)\), a vector of random variables with finitely many values. Then \(\Sigma\) is symmetric, and for every \(w \in \R^{n}\), \(w^{\top}\Sigma w = \operatorname{Var}\big(\sum_{i} w_i X_i\big) \ge 0\).
[proof]  grade=- :: /span> Symmetry is Proposition 1.1(i). Expanding the quadratic form, \[ w^{\top}\Sigma w = \sum_{i}\sum_{j} w_i w_j \operatorname{Cov}(X_i, X_j). \] Proposition 1.1(ii) and (iii) extend by induction to finite sums, so \(\operatorname{Cov}\big(\sum_i w_i X_i, \sum_j w_j X_j\big) = \sum_i \sum_j w_i w_j \operatorname{Cov}(X_i, X_j)\). Setting \(Y = \sum_j w_j X_j\) and using Proposition 1.1(iv) gives \(\operatorname{Cov}(Y,Y) = \operatorname{Var}(Y)\). The variance is a nonnegative sum of squares times probabilities, so \(w^{\top}\Sigma w \ge 0\).
[theorem] Proposition 2.4 (diagonal and off-diagonal bounds)< grade=T :: /span> For a covariance matrix \(\Sigma\) of X with finitely many values, every diagonal entry is nonnegative, and \(\Sigma_{ij}^{2} \le \Sigma_{ii}\Sigma_{jj}\) for all i and j.
[proof]  grade=- :: /span> The diagonal entry \(\Sigma_{ii} = \operatorname{Var}(X_i)\) is nonnegative, by Proposition 1.1(iv). The bound is Proposition 1.5 applied to the pair \(X_i\) and \(X_j\), since \(\Sigma_{ij} = \operatorname{Cov}(X_i, X_j)\), \(\Sigma_{ii} = \operatorname{Var}(X_i)\) and \(\Sigma_{jj} = \operatorname{Var}(X_j)\).
[example] Example 2.5 (a two-asset matrix from a construction)< grade=- :: /span> Let \(S_1, S_2 > 0\), \(|\rho| < 1\), and let \(Z_1\) and \(Z_2\) be independent random variables with mean 0 and variance 1. Put \(X_1 = S_1 Z_1\) and \(X_2 = S_2(\rho Z_1 + \sqrt{1 - \rho^{2}}\,Z_2)\). The variables \(Z_1\) and \(Z_2\) are not finitely valued, so this example uses the rules of Proposition 1.1 for them without proving them here. That use is stated as Assumption 1 of this example, which is not proved on this page: the rules of Proposition 1.1 hold for \(Z_1\) and \(Z_2\), with \(\operatorname{Var}(Z_i) = 1\) and \(\operatorname{Cov}(Z_1, Z_2) = 0\). Assuming Assumption 1, \(\operatorname{Var}(X_1) = S_1^{2}\), \(\operatorname{Var}(X_2) = S_2^{2}(\rho^{2} + 1 - \rho^{2}) = S_2^{2}\), and \(\operatorname{Cov}(X_1, X_2) = S_1 S_2 \rho\). So the covariance matrix is \(\Sigma = \begin{pmatrix} S_1^{2} & \rho S_1 S_2 \\ \rho S_1 S_2 & S_2^{2} \end{pmatrix}\).
