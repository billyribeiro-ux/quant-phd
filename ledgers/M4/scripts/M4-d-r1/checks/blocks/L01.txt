[definition] Definition 1.1 (random variable)< grade=- :: /span> Let \(\Omega\) be a finite probability space. A random variable on \(\Omega\) is a function \(X : \Omega \to \R\). Its values are the real numbers \(X(\omega)\), one for each outcome.
[definition] Definition 1.2 (distribution and support)< grade=- :: /span> The distribution of \(X\) assigns to each real \(x\) the probability \(P(X = x) = \sum_{\omega \,:\, X(\omega) = x} p(\omega)\). The support of \(X\) is the set of values that \(X\) takes on \(\Omega\). A value \(x\) is in the support exactly when \(P(X = x) > 0\), because every outcome has positive weight.
[example] Example 1.3 (a three-outcome loss)< grade=- :: /span> Let \(\Omega = \{a, b, c\}\) with \(p(a) = \tfrac12\), \(p(b) = \tfrac13\) and \(p(c) = \tfrac16\). These weights are positive and sum to 1. Let \(X(a) = 0\), \(X(b) = 1\) and \(X(c) = 3\). The distribution of \(X\) is \(P(X = 0) = \tfrac12\), \(P(X = 1) = \tfrac13\) and \(P(X = 3) = \tfrac16\). Its support is \(\{0, 1, 3\}\). The probability that \(X\) is at most 1 is \(\tfrac12 + \tfrac13 = \tfrac56\). 2The distribution function
[definition] Definition 2.1 (distribution function)< grade=- :: /span> The distribution function of \(X\) is \(F(x) = P(X \le x)\) for \(x \in \R\). Writing \(x_1 < x_2 < \dots < x_m\) for the distinct values of \(X\), we set \(p_k = P(X = x_k)\) and \(F_k = F(x_k)\).
[proposition] Proposition 2.2 (shape of a finite distribution function)< grade=T :: /span> Let \(X\) be a random variable on a finite probability space whose weights are all positive, with distinct values \(x_1 < \dots < x_m\). Then: (a) \(F(x) = 0\) for \(x < x_1\), and \(F(x) = 1\) for \(x \ge x_m\); (b) \(F\) is nondecreasing, and for \(x_k \le x < x_{k+1}\) (with \(1 \le k < m\)) we have \(F(x) = F_k\); (c) \(F_k = p_1 + \dots + p_k\) for each \(k\), and \(F_m = 1\); (d) \(F\) is right-continuous at each \(x_k\), meaning that \(F(x) \to F(x_k)\) as \(x \downarrow x_k\), and it jumps at each value: \(F(x_k) - \lim_{x \uparrow x_k} F(x) = p_k > 0\).
[proof]  grade=- :: /span> Since \(X\) takes only the values \(x_1, \dots, x_m\), and these values partition \(\Omega\) into the events \(\{X = x_j\}\), we have \(P(X \le x) = \sum_{j \,:\, x_j \le x} p_j\). So \(F(x)\) is a sum of the weights \(p_j\) over the values \(x_j\) that do not exceed \(x\). For (a), if \(x < x_1\) there is no such \(j\), and the empty sum is 0. If \(x \ge x_m\), every index \(j\) qualifies, so \(F(x) = \sum_{j=1}^m p_j\). This sum equals \(P(\Omega) = 1\), which proves (c) for \(k = m\) and the second claim of (a). For (b), each \(p_j\) is positive, so adding more indices as \(x\) grows can only increase the sum. If \(x_k \le x < x_{k+1}\), the indices with \(x_j \le x\) are exactly \(1, \dots, k\), so \(F(x) = F_k = p_1 + \dots + p_k\), which proves (b) and (c). For (d), the formula in (b) shows \(F\) is constant on \([x_k, x_{k+1})\), so it is right-continuous at each \(x_k\), and its left limit at \(x_k\) is \(F_{k-1}\) (with \(F_0 = 0\)). The jump is \(F_k - F_{k-1} = p_k\), which is positive. \(\blacksquare\) 3The quantile function For a set \(A\) of real numbers that is bounded below, \(\inf A\) denotes its infimum, the greatest real number that is at most every member of \(A\). The quantifier logic of M1 applies to these definitions, and each claim below states its domain.
[definition] Definition 3.1 (quantile function)< grade=- :: /span> For \(X\) as above and \(0 < p \le 1\), the quantile function of \(X\) is \(Q(p) = \inf\{x \in \R : F(x) \ge p\}\). This is the left-endpoint convention used in this lesson: at a jump, \(Q(p)\) is the smallest value whose distribution function reaches \(p\). The convention is fixed by this definition. Other conventions exist, and they give different answers at the jump points.
[proposition] Proposition 3.2 (quantile of a finite law)< grade=T :: /span> Let \(X\) be as in Proposition 2.2, with distinct values \(x_1 < \dots < x_m\) and \(F_k = F(x_k)\). Let \(0 < p \le 1\), and let \(k^*\) be the least index \(k\) with \(F_k \ge p\). Then the set \(\{x : F(x) \ge p\}\) has the infimum \(x_{k^*}\), so \(Q(p) = x_{k^*}\).
[proof]  grade=- :: /span> The index \(k^*\) exists, because \(F_m = 1 \ge p\) by Proposition 2.2(c). Let \(A = \{x : F(x) \ge p\}\). The point \(x_{k^*}\) belongs to \(A\), since \(F_{k^*} \ge p\) by choice. To show that \(x_{k^*}\) is the infimum of \(A\), it remains to show that every \(x \in A\) satisfies \(x \ge x_{k^*}\). Take \(x \in A\). If \(x < x_1\), then \(F(x) = 0 < p\) by Proposition 2.2(a), which contradicts \(x \in A\). So \(x \ge x_1\), and there is an index \(j\) with \(x_j \le x < x_{j+1}\), or \(j = m\) if \(x \ge x_m\). By Proposition 2.2(b), \(F(x) = F_j\). Since \(x \in A\), we get \(F_j \ge p\), and minimality of \(k^*\) gives \(j \ge k^*\). Therefore \(x \ge x_j \ge x_{k^*}\). The point \(x_{k^*}\) is thus a lower bound of \(A\) that belongs to \(A\), so it is the infimum. \(\blacksquare\)
[remark] Remark 3.3 (the jumps of the quantile function)< grade=T :: /span> Let \(X\) be as in Proposition 2.2, and put \(F_0 = 0\). For \(1 \le k \le m\) and \(F_{k-1} < p \le F_k\), we have \(Q(p) = x_k\). In particular \(Q(F_k) = x_k\), and \(Q\) is left-continuous on \((0, 1]\): if \(u_n \uparrow p\), then \(Q(u_n) \to Q(p)\). For \(k < m\), just to the right of \(F_k\) the value jumps to \(x_{k+1}\). Proof. Since \(F\) is nondecreasing, \(F_j \le F_{k-1} < p\) for \(j \le k-1\), and \(F_k \ge p\). So the least index with \(F_j \ge p\) is \(k\), and Proposition 3.2 gives \(Q(p) = x_k\). For left-continuity, fix \(p \in (0, 1]\) and choose \(k\) with \(F_{k-1} < p \le F_k\), which exists because \(F_0 = 0 < p \le F_m = 1\). Then \(Q(p) = x_k\), as shown above. Take \(u_n \uparrow p\). Eventually \(u_n\) lies in \((F_{k-1}, p]\), a subset of \((F_{k-1}, F_k]\), so \(Q(u_n) = x_k = Q(p)\). \(\blacksquare\)
[proposition] Proposition 3.4 (quantile of n equally likely values)< grade=T :: /span> Let \(y_1 < \dots < y_n\) be \(n \ge 1\) distinct real numbers, and let \(X\) take each \(y_j\) with probability \(1/n\). Then for every \(p\) with \(0 < p \le 1\), \(Q(p) = y_{\lceil pn \rceil}\), where \(\lceil pn \rceil\) is the least integer that is at least \(pn\). Thus \(Q(p)\) is the \(\lceil pn \rceil\)-th smallest value.
[proof]  grade=- :: /span> Here \(p_j = 1/n\), so Proposition 2.2(c) gives \(F_j = j/n\). By Proposition 3.2, \(Q(p) = y_{k^*}\), where \(k^*\) is the least \(j\) with \(j/n \ge p\). Multiplying by \(n > 0\), this is the least integer \(j\) with \(j \ge pn\), which is \(\lceil pn \rceil\). Since \(0 < pn \le n\), the integer \(\lceil pn \rceil\) lies between 1 and \(n\), so it is a valid index. \(\blacksquare\)
[example] Example 3.5 (the index for 150 and 200 values)< grade=- :: /span> Take \(n = 200\) and \(p = 0.99\). Then \(pn = 198\), which is an integer, so \(\lceil pn \rceil = 198\), and the quantile is the 198th smallest value. Take \(n = 150\) and \(p = 0.99\). Then \(pn = 148.5\), so \(\lceil pn \rceil = 149\). The quantile is the 149th smallest value, not the 148th. The floor of 148.5 is 148, and using it would move the index down by one.
[example] Example 3.6 (the table of Lab 1)< grade=- :: /span> Let \(X\) take the values \(-2, -1, 0, 1, 2, 3\) with probabilities \(\tfrac1{10}, \tfrac2{10}, \tfrac3{10}, \tfrac2{10}, \tfrac1{10}, \tfrac1{10}\). These sum to 1 and are positive, so Proposition 2.2 applies. The distribution function values are \(F(-2) = \tfrac1{10}\), \(F(-1) = \tfrac3{10}\), \(F(0) = \tfrac35\), \(F(1) = \tfrac45\), \(F(2) = \tfrac9{10}\) and \(F(3) = 1\). By Proposition 3.2, \(Q(\tfrac12) = 0\), because \(F(-1) = \tfrac3{10} < \tfrac12\) and \(F(0) = \tfrac35 \ge \tfrac12\). Also \(Q(\tfrac35) = 0\), because \(F(0) = \tfrac35\) reaches \(\tfrac35\) exactly, and \(Q(\tfrac{61}{100}) = 1\), because \(F(0) = \tfrac35 < \tfrac{61}{100} \le \tfrac45 = F(1)\).
