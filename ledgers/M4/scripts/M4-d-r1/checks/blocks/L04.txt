[definition] Definition 1.1 (joint table and marginals)< grade=- :: /span> A joint table for X and Y is the list of values \(p(x,y)\) over the pairs of values, each \(p(x,y) \ge 0\), with \(\sum_{x,y} p(x,y) = 1\). Each pair \((x,y)\) of values is a cell of the table. Its marginal probabilities are \(P(X = x) = \sum_{y} p(x,y)\) and \(P(Y = y) = \sum_{x} p(x,y)\). The marginals are the distributions of X and Y alone, as defined in L01.
[definition] Definition 1.2 (independence)< grade=- :: /span> Independence of two events \(A\) and \(B\) means \(P(A \cap B) = P(A)\,P(B)\). Discrete random variables X and Y are independent when \(p(x,y) = P(X = x)\,P(Y = y)\) for every pair \((x,y)\) of values. In words, every cell of the joint table is the product of its two marginals.
[remark] Remark 1.3 (the test is cell by cell)< grade=- :: /span> Independence is a property of the whole joint table. One cell that fails the product rule makes the pair dependent. Lab 1 applies the test to every cell of three tables (Parts A and B) and prints the verdict for each table.
[theorem] Proposition 1.4 (disjoint events are dependent)< grade=T :: /span> Let \(A\) and \(B\) be events with \(A \cap B = \varnothing\), \(P(A) > 0\) and \(P(B) > 0\). Then \(A\) and \(B\) are not independent.
[proof]  grade=- :: /span> Since \(A \cap B = \varnothing\), \(P(A \cap B) = 0\). The hypotheses give \(P(A)\,P(B) > 0\), because a product of two positive numbers is positive. So \(P(A \cap B) \ne P(A)P(B)\).
[theorem] Proposition 1.5 (the expectation of a product under independence)< grade=T :: /span> Let X and Y be independent random variables with finitely many values. Then \(E[XY] = E[X]\,E[Y]\).
[proof]  grade=- :: /span> The cells \((x,y)\) partition the outcomes, since each outcome has exactly one pair of values. Grouping the outcomes by their cell, as in L02 Proposition 1.2, gives \(E[XY] = \sum_{x,y} xy\,p(x,y)\). Independence replaces each cell, giving \(\sum_{x,y} xy\,P(X = x)\,P(Y = y)\). The sum factors, because the summand is a product of a function of x and a function of y: \[ \sum_{x}\sum_{y} x\,P(X = x)\; y\,P(Y = y) = \Big(\sum_{x} x\,P(X = x)\Big)\Big(\sum_{y} y\,P(Y = y)\Big) = E[X]\,E[Y]. \]
[definition] Definition 1.6 (covariance, defined here and studied in L05)< grade=- :: /span> The covariance of X and Y is \(\operatorname{Cov}(X,Y) = E[(X - E[X])(Y - E[Y])]\). Only its formula is used in this lesson. The correlation, which is built from it, is developed in Lesson 5.
[theorem] Proposition 1.7 (the shortcut formula for covariance)< grade=T :: /span> For random variables X and Y with finitely many values, \(\operatorname{Cov}(X,Y) = E[XY] - E[X]\,E[Y]\).
[proof]  grade=- :: /span> Expand the product inside the expectation: \[ (X - E[X])(Y - E[Y]) = XY - E[Y]\,X - E[X]\,Y + E[X]\,E[Y]. \] Expectation is linear over finite sums, and the expectations of the constants \(E[Y]\) and \(E[X]\) are themselves. So \[ E[(X - E[X])(Y - E[Y])] = E[XY] - E[Y]\,E[X] - E[X]\,E[Y] + E[X]\,E[Y] = E[XY] - E[X]\,E[Y]. \]
[theorem] Proposition 1.8 (independence implies zero covariance)< grade=T :: /span> If X and Y are independent with finitely many values, then \(\operatorname{Cov}(X,Y) = 0\).
[proof]  grade=- :: /span> By Proposition 1.5, \(E[XY] = E[X]\,E[Y]\). By Proposition 1.7, the covariance is \(E[XY] - E[X]\,E[Y] = 0\).
[example] Example 1.9 (zero covariance without independence)< grade=- :: /span> Let X be uniform on \(\{-1, 0, 1\}\), so each value has probability \(1/3\), and let \(Y = X^{2}\). Then \(E[X] = 0\), \(E[Y] = 2/3\) and \(E[XY] = E[X^{3}] = 0\). By Proposition 1.7, \(\operatorname{Cov}(X,Y) = 0 - 0 \cdot 2/3 = 0\). The pair is not independent. The cell \((0,0)\) has \(p(0,0) = P(X = 0,\ Y = 0) = 1/3\), while \(P(X = 0)\,P(Y = 0) = (1/3)(1/3) = 1/9\). So the converse of Proposition 1.8 is false. [definition] Definition 2.1 (conditional distribution and conditional expectation, elementary form)< grade=- :: /span> For a value y with \(P(Y = y) > 0\), the conditional distribution of X given \(Y = y\) is \(P(X = x \mid Y = y) = p(x,y)/P(Y = y)\), a probability over the values x. Its expectation is the conditional expectation \(E[X \mid Y = y] = \sum_{x} x\,P(X = x \mid Y = y)\), which this lesson writes in the same way for every such y.
[remark] Remark 2.2 (the scope of this lesson)< grade=- :: /span> Definition 2.1 covers conditioning on one discrete variable with a finite table. It does not define conditioning on a variable with a continuous distribution, or on an event of probability zero. This lesson does not treat either case, and nothing later in this lesson needs them.
[theorem] Proposition 2.3 (total expectation)< grade=T :: /span> For random variables X and Y with finitely many values, \(E[X] = \sum_{y:\,P(Y=y) > 0} E[X \mid Y = y]\,P(Y = y)\).
[proof]  grade=- :: /span> For \(P(Y = y) > 0\), \(E[X \mid Y = y]\,P(Y = y) = \sum_{x} x\,p(x,y)\). Summing over these y, and noting that the values with \(P(Y = y) = 0\) contribute \(p(x,y) = 0\) to the joint table, gives \(\sum_{x}\sum_{y} x\,p(x,y)\). Regrouping the finite sum by x gives \(\sum_{x} x \sum_{y} p(x,y) = \sum_{x} x\,P(X = x) = E[X]\).
[theorem] Proposition 2.4 (independence fixes the conditional expectation)< grade=T :: /span> If X and Y are independent with finitely many values, then \(E[X \mid Y = y] = E[X]\) for every y with \(P(Y = y) > 0\).
[proof]  grade=- :: /span> Independence gives \(p(x,y) = P(X = x)\,P(Y = y)\), so \(P(X = x \mid Y = y) = P(X = x)\,P(Y = y)/P(Y = y) = P(X = x)\) for every x. Substituting into the definition, \(E[X \mid Y = y] = \sum_{x} x\,P(X = x) = E[X]\).
[example] Example 2.5 (the dependent table of Lab 1)< grade=- :: /span> Take X in \(\{0,1,2\}\) and Y in \(\{0,1\}\) with \(p(0,0) = 1/10\), \(p(0,1) = 3/10\), \(p(1,0) = 2/10\), \(p(1,1) = 2/10\), \(p(2,0) = 1/10\) and \(p(2,1) = 1/10\). The marginals are \(P(Y = 0) = 2/5\) and \(P(Y = 1) = 3/5\). Then \(E[X] = 0 \cdot 2/5 + 1 \cdot 2/5 + 2 \cdot 1/5 = 4/5\). The conditional expectations are \(E[X \mid Y = 0] = (0 \cdot 1/10 + 1 \cdot 2/10 + 2 \cdot 1/10)/(2/5) = 1\) and \(E[X \mid Y = 1] = (0 \cdot 3/10 + 1 \cdot 2/10 + 2 \cdot 1/10)/(3/5) = 2/3\). Check Proposition 2.3: \(1 \cdot 2/5 + (2/3)(3/5) = 4/5\), which equals \(E[X]\). The two conditional expectations differ. Proposition 2.4 says that independence forces each of them to equal \(E[X]\), so the table is dependent. Lab 1 Part C prints these values.
