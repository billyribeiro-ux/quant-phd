[definition] Definition 1.1 (random variable) grade=- :: Let \(\Omega\) be a finite probability space. A random variable on \(\Omega\) is a function \(X : \Omega \to \R\). Its values are the real numbers \(X(\omega)\), one for each outcome.
[definition] Definition 1.2 (distribution and support) grade=- :: The distribution of \(X\) assigns to each real \(x\) the probability \(P(X = x) = \sum_{\omega \,:\, X(\omega) = x} p(\omega)\). The support of \(X\) is the set of values that \(X\) takes on \(\Omega\). A value \(x\) is in the support exactly when \(P(X = x) > 0\), because every outcome has positive weight.
[example] Example 1.3 (a three-outcome loss) grade=- :: Let \(\Omega = \{a, b, c\}\) with \(p(a) = \tfrac12\), \(p(b) = \tfrac13\) and \(p(c) = \tfrac16\). These weights are positive and sum to 1. Let \(X(a) = 0\), \(X(b) = 1\) and \(X(c) = 3\). The distribution of \(X\) is \(P(X = 0) = \tfrac12\), \(P(X = 1) = \tfrac13\) and \(P(X = 3) = \tfrac16\). Its support is \(\{0, 1, 3\}\). The probability that \(X\) is at most 1 is \(\tfrac12 + \tfrac13 = \tfrac56\).
