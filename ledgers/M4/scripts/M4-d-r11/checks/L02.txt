[definition] Definition 1.1 (expectation of a finite law) grade=- :: The expectation of \(X\) is \(E[X] = \sum_{k=1}^m x_k\, p_k\). It is the average of the values of \(X\), weighted by their probabilities. The expectation is a real number, and it need not be one of the values of \(X\).
[proposition] Proposition 1.2 (expectation over outcomes) grade=T :: For \(X\) as above, \(\sum_{\omega \in \Omega} X(\omega)\, p(\omega) = \sum_{k=1}^m x_k\, p_k\).
[proof] Proof grade=- :: The events \(\{X = x_1\}, \dots, \{X = x_m\}\) partition \(\Omega\), since every outcome has exactly one value. Grouping the outcomes by value gives \(\sum_{\omega} X(\omega) p(\omega) = \sum_{k} \sum_{\omega : X(\omega) = x_k} x_k\, p(\omega) = \sum_{k} x_k \sum_{\omega : X(\omega) = x_k} p(\omega) = \sum_{k} x_k\, p_k\). The last step uses the definition \(p_k = P(X = x_k)\). \(\blacksquare\)
[proposition] Proposition 1.3 (linearity on a finite space) grade=T :: Let \(U\) and \(V\) be random variables on the same finite probability space, and let \(\alpha, \beta, \delta\) be real constants. Then \(E[\alpha U + \beta V + \delta] = \alpha E[U] + \beta E[V] + \delta\).
[proof] Proof grade=- :: By Proposition 1.2, \(E[W] = \sum_{\omega} W(\omega)\, p(\omega)\) for any random variable \(W\) on the space. With \(W = \alpha U + \beta V + \delta\), we get \(E[W] = \alpha \sum_\omega U(\omega) p(\omega) + \beta \sum_\omega V(\omega) p(\omega) + \delta \sum_\omega p(\omega)\). The three sums are \(E[U]\), \(E[V]\) and \(P(\Omega) = 1\). \(\blacksquare\)
[example] Example 1.4 (a fair die) grade=- :: Let \(X\) be the number shown by a fair six-sided die, so \(X\) takes the values 1 to 6 with probability \(\tfrac16\) each. Then \(E[X] = \tfrac16(1 + 2 + 3 + 4 + 5 + 6) = \tfrac{21}{6} = \tfrac72\). The expectation 3.5 is not a face of the die.
[example] Example 1.5 (a two-point loss in cents) grade=- :: Let \(L\) be a loss in integer cents: \(L = 250000\) with probability \(\tfrac1{20}\), and \(L = 0\) with probability \(\tfrac{19}{20}\). Then \(E[L] = 250000 \cdot \tfrac1{20} + 0 \cdot \tfrac{19}{20} = 12500\) cents. The expected loss is an integer number of cents here because the probabilities have denominator 20, which divides 250000.
[definition] Definition 1.6 (the continuous case, in M2's integral) grade=- :: Let \(X\) have a density \(f\), a nonnegative function with \(\int_{-\infty}^{\infty} f(x)\, dx = 1\), so that \(P(a \le X \le b) = \int_a^b f(x)\, dx\). When \(\int_{-\infty}^{\infty} |x|\, f(x)\, dx\) is finite, the expectation of \(X\) is \(E[X] = \int_{-\infty}^{\infty} x\, f(x)\, dx\). The integral over the whole line is the limit of definite integrals as the endpoints go to \(\pm\infty\). For a discrete law, Definition 1.1 applies instead. No result of this lesson uses this definition.
[definition] Definition 2.1 (variance and standard deviation) grade=- :: Let \(\mu = E[X]\). The variance of \(X\) is \(\operatorname{Var}(X) = E[(X - \mu)^2]\), and the standard deviation is \(\sigma = \sqrt{\operatorname{Var}(X)}\). The variance is in squared units of \(X\), and the standard deviation is in the units of \(X\). A variance is never negative, because it is the expectation of a square.
[proposition] Proposition 2.2 (shortcut formula) grade=T :: For \(X\) on a finite probability space with positive weights, \(\operatorname{Var}(X) = E[X^2] - (E[X])^2\).
[proof] Proof grade=- :: Expand the square: \((X - \mu)^2 = X^2 - 2\mu X + \mu^2\), where \(\mu\) is a constant. Proposition 1.3, with \(U = X^2\), \(V = X\), \(\alpha = 1\), \(\beta = -2\mu\) and \(\delta = \mu^2\), gives \(E[(X - \mu)^2] = E[X^2] - 2\mu E[X] + \mu^2\). Since \(E[X] = \mu\), this is \(E[X^2] - 2\mu^2 + \mu^2 = E[X^2] - \mu^2\). \(\blacksquare\)
[proposition] Proposition 2.3 (scale and shift) grade=T :: For constants \(a, b\), \(\operatorname{Var}(aX + b) = a^2 \operatorname{Var}(X)\). In particular \(\operatorname{Var}(X + b) = \operatorname{Var}(X)\), and \(\operatorname{Var}(aX)\) is \(a^2\) times the variance of \(X\).
[proof] Proof grade=- :: By Proposition 1.3, \(E[aX + b] = a\mu + b\). So \((aX + b) - E[aX + b] = a(X - \mu)\), and its square is \(a^2 (X - \mu)^2\). Taking expectations and using Proposition 1.3 once more, \(\operatorname{Var}(aX + b) = a^2 E[(X - \mu)^2] = a^2 \operatorname{Var}(X)\). \(\blacksquare\)
[proposition] Proposition 2.4 (zero variance means a single value) grade=T :: For \(X\) on a finite probability space with positive weights, \(\operatorname{Var}(X) = 0\) if and only if \(X\) takes exactly one value.
[proof] Proof grade=- :: Write \(\operatorname{Var}(X) = \sum_k (x_k - \mu)^2 p_k\), which is a sum of nonnegative terms, each with \(p_k > 0\). The sum is zero exactly when every term is zero, that is, when \(x_k = \mu\) for every \(k\). That happens exactly when \(m = 1\), since the \(x_k\) are distinct. Conversely, if \(X\) takes one value, that value is \(\mu\), and the variance is 0. \(\blacksquare\)
[example] Example 2.5 (the fair die) grade=- :: For the die of Example 1.4, \(E[X^2] = \tfrac16(1 + 4 + 9 + 16 + 25 + 36) = \tfrac{91}{6}\). By Proposition 2.2, \(\operatorname{Var}(X) = \tfrac{91}{6} - \left(\tfrac72\right)^2 = \tfrac{182}{12} - \tfrac{147}{12} = \tfrac{35}{12}\). The standard deviation is \(\sqrt{35/12}\), which is about 1.708 when rounded from the exact value \(35/12\).
[example] Example 2.6 (the two-point loss in cents) grade=- :: For \(L\) of Example 1.5, \(E[L^2] = 250000^2 \cdot \tfrac1{20} = 3\,125\,000\,000\) cents squared, and \(E[L] = 12500\). By Proposition 2.2, \(\operatorname{Var}(L) = 3\,125\,000\,000 - 12500^2 = 3\,125\,000\,000 - 156\,250\,000 = 2\,968\,750\,000\) cents squared. The standard deviation is \(\sqrt{2\,968\,750\,000}\), which is about 54486.24 cents. Lab 1 prints the same two values.
