[proposition] Proposition 1.1 (Chebyshev's inequality) grade=T :: Let \(Y\) be a random variable with finitely many values, with mean \(m\) and variance \(v\). For every \(a > 0\), \(P(|Y - m| \ge a) \le v/a^2\).
[proof] Proof grade=- :: Let \(W = (Y - m)^2\), which is nonnegative. On the event \(\{|Y - m| \ge a\}\), \(W \ge a^2\). Off that event, the indicator is 0 and \(0 \le W\). So pointwise \(a^2 \mathbf{1}\{|Y - m| \ge a\} \le W\). Taking expectations of both sides, which are finite sums, gives \[a^2 P(|Y - m| \ge a) \le E[W] = v\]. Divide by \(a^2\). \(\blacksquare\)
[proposition] Proposition 1.2 (mean and variance of the sample mean) grade=T :: Let \(X_1, X_2, \ldots\) be identically distributed with mean \(\mu\) and variance \(\sigma^2\), and suppose that \(X_i\) and \(X_j\) are independent whenever \(i \ne j\). Then \(E[\bar X_n] = \mu\) and \(\operatorname{Var}(\bar X_n) = \sigma^2/n\).
[proof] Proof grade=- :: By linearity of expectation, \(E[\bar X_n] = \frac1n \sum_i E[X_i] = \mu\). For the variance, \[\operatorname{Var}(S_n) = E[(S_n - n\mu)^2] = \sum_{i} \sum_{j} E[(X_i - \mu)(X_j - \mu)]\]. For \(i \ne j\), independence of \(X_i\) and \(X_j\) (Lesson 4) gives \[E[(X_i - \mu)(X_j - \mu)] = E[X_i - \mu]\,E[X_j - \mu] = 0\]. For \(i = j\) the term is \(\sigma^2\). So \(\operatorname{Var}(S_n) = n\sigma^2\), and \[\operatorname{Var}(\bar X_n) = \operatorname{Var}(S_n)/n^2 = \sigma^2/n\], because the variance of \(cY\) is \(c^2\operatorname{Var}(Y)\) (Lesson 2). \(\blacksquare\)
[definition] Definition 1.4 (law of large numbers) grade=- :: The law of large numbers holds for a sequence of identically distributed variables with mean \(\mu\) when \(P(|\bar X_n - \mu| \ge \varepsilon) \to 0\) as \(n \to \infty\), for every \(\varepsilon > 0\). Theorem 1.3 proves it under the hypotheses of Proposition 1.2, for finitely valued laws.
[theorem] Theorem 1.3 (weak law of large numbers) grade=T :: Under the hypotheses of Proposition 1.2, with every law taking finitely many values, for every \(\varepsilon > 0\) and every \(n \ge 1\), \[ P(|\bar X_n - \mu| \ge \varepsilon) \le \frac{\sigma^2}{n\varepsilon^2}, \] and therefore \(P(|\bar X_n - \mu| \ge \varepsilon) \to 0\) as \(n \to \infty\).
[proof] Proof grade=- :: Apply Proposition 1.1 to \(Y = \bar X_n\), with \(m = \mu\) by Proposition 1.2 and \(v = \sigma^2/n\), and with \(a = \varepsilon\). This gives the bound. The bound is a fixed number divided by \(n\), and \(\sigma^2/(n\varepsilon^2) \to 0\) as \(n \to \infty\) by the limit of \(1/n\) (M2), so the probability tends to 0 by the squeeze of the limit (M2). \(\blacksquare\)
[remark] Assumption 1 (two limits used without proof) grade=- :: The exponential function is continuous on the real line, and \(\ln(1 + u)/u \to 1\) as \(u \to 0\). The page uses both facts and does not prove either. Each result that uses them says so in its statement.
[proposition] Proposition 2.1 (product rule for independent variables) grade=T :: Let \(X_1, \ldots, X_n\) be finitely valued and independent in the sense above, and let each \(g_i\) be a complex-valued function on the values of \(X_i\). Then \[E[\prod_i g_i(X_i)] = \prod_i E[g_i(X_i)]\]. In particular, \(\varphi_{X_1 + \cdots + X_n}(t) = \prod_i \varphi_{X_i}(t)\) for real \(t\), and for i.i.d. variables this is \(\varphi_X(t)^n\).
[proof] Proof grade=- :: Write \(p_i(x) = P(X_i = x)\). By the factorization of the joint probabilities, \[ E\Bigl[\prod_i g_i(X_i)\Bigr] = \sum_{x_1, \ldots, x_n} \prod_i g_i(x_i)\,p_i(x_i) = \prod_{i=1}^{n} \Bigl(\sum_{x} g_i(x)\,p_i(x)\Bigr) = \prod_i E[g_i(X_i)]. \] The middle equality is the distributive law for a finite sum over a product of finite index sets. Taking \(g_i(x) = e^{it x}\) gives the characteristic function of the sum, since \(e^{it(X_1 + \cdots + X_n)} = \prod_i e^{itX_i}\). \(\blacksquare\)
[proposition] Proposition 2.2 (expansion of the characteristic function near zero) grade=T :: Let \(Y\) take finitely many values, with \(E[Y] = 0\), \(E[Y^2] = 1\), and \[M = \max|Y| > 0\]. For real \(s\) with \(|s| \le 1/M\), \[ \bigl| \varphi_Y(s) - (1 - s^2/2) \bigr| \le \frac{|s|^3\,E|Y|^3}{3}. \]
[proof] Proof grade=- :: Let \(f(x) = \cos x - 1 + x^2/2\) and \(g(x) = \sin x - x\). Then \(f(0) = g(0) = 0\), \(f'(x) = x - \sin x = -g(x)\), and \(g'(x) = \cos x - 1\), which lies in \([-x^2/2, 0]\) because \(0 \le 1 - \cos u \le u^2/2\) for every real \(u\), by the double-angle identity \(1 - \cos u = 2\sin^2(u/2)\) and \(|\sin v| = \bigl|\int_0^v \cos t\,dt\bigr| \le |v|\), since \(|\cos t| \le 1\). Hence \(|g(x)| \le \int_0^{|x|} u^2/2\,du = |x|^3/6\). Also \[|f(x)| = |\int_0^x (u - \sin u)\,du| \le \int_0^{|x|} u^3/6\,du = x^4/24\]. For \(|x| \le 1\), \(x^4/24 \le |x|^3/24\), so \(|f(x)| + |g(x)| \le |x|^3/3\). Since \[e^{ix} - 1 - ix + x^2/2 = f(x) + i\,g(x)\], its modulus is at most \(|x|^3/3\) for \(|x| \le 1\). Apply this with \(x = sY\), which satisfies \(|sY| \le |s| M \le 1\). Taking expectations and using \(E[Y] = 0\) and \(E[Y^2] = 1\), \[\varphi_Y(s) = 1 + is\,E[Y] - \frac{s^2}{2} E[Y^2] + E[R] = 1 - s^2/2 + E[R]\], where \[R = e^{isY} - 1 - isY + s^2Y^2/2\] satisfies \(|R| \le |s|^3|Y|^3/3\). Then \[|E[R]| \le E|R| \le |s|^3E|Y|^3/3\]. \(\blacksquare\)
[proposition] Proposition 2.3 (the standardized mean: second moment and characteristic functions) grade=T :: Under the i.i.d. hypotheses of this section, with the variables finitely valued and \(Z_n\) as defined above: (a) \(E[Z_n] = 0\) and \(E[Z_n^2] = 1\) for every \(n\); (b) assuming Assumption 1, for every real \(t\), \(\varphi_{Z_n}(t) \to e^{-t^2/2}\) as \(n \to \infty\).
[proof] Proof grade=- :: (a) Proposition 1.2 gives \(E[\bar X_n] = \mu\) and \(\operatorname{Var}(\bar X_n) = \sigma^2/n\). So \(E[Z_n] = 0\), and by the scale rule of Lesson 2, \(\operatorname{Var}(Z_n) = (\sigma^2/n)/(\sigma^2/n) = 1\). Since \(E[Z_n] = 0\), \(E[Z_n^2] = \operatorname{Var}(Z_n) = 1\). (b) Fix real \(t\). By Proposition 2.1 with \(g_i(y) = e^{ity/\sqrt n}\), \(\varphi_{Z_n}(t) = a_n^{\,n}\), where \(a_n = \varphi_Y(t/\sqrt n)\). Let \[b_n = 1 - t^2/(2n)\]. For \(n\) large enough that \(|t|/\sqrt n \le 1/M\) and \(t^2 \le 2n\), both \(|a_n| \le 1\) (since \(|E[W]| \le E|W|\) and \(|e^{i\theta}| = 1\)) and \(|b_n| \le 1\). Telescoping, \[a^n - b^n = (a - b)\sum_{k=0}^{n-1} a^k b^{n-1-k}\], so \(|a^n - b^n| \le n|a - b|\) when \(|a|, |b| \le 1\). By Proposition 2.2 with \(s = t/\sqrt n\), \[ n|a_n - b_n| \le n \cdot \frac{|t|^3\,E|Y|^3}{3\,n^{3/2}} = \frac{|t|^3\,E|Y|^3}{3\sqrt n} \to 0. \] Finally \(b_n^n = (1 - t^2/(2n))^n \to e^{-t^2/2}\). For \(t = 0\) this is trivial, so let \(t \ne 0\), and write \(b_n^n = \exp(n\ln(1 - x/n))\) with \(x = t^2/2\). By Assumption 1, \(\ln(1 + u)/u \to 1\) as \(u \to 0\), so we get \[n\ln(1 - x/n) = -x\cdot \frac{\ln(1 - x/n)}{-x/n} \to -x\]. Hence \(a_n^n - b_n^n \to 0\), and \(b_n^n \to e^{-t^2/2}\) by the continuity of exp (Assumption 1), so \(\varphi_{Z_n}(t) \to e^{-t^2/2}\). \(\blacksquare\)
[definition] Definition 2.4 (central limit theorem) grade=- :: The central limit theorem holds for \(X\) when \(P(Z_n \le z) \to \Phi(z)\) for every real \(z\), where \(\Phi\) is the distribution function of the standard normal law of Lesson 6.
