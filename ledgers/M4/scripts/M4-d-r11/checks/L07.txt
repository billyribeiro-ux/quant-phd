[theorem] Proposition 1.2 (finitely many values) grade=T :: If X takes finitely many values, then the domain of \(M_X\) is the whole real line.
[proof] Proof grade=- :: For each value x, \(e^{tx}\) is a finite real number for every real t. So \(E[e^{tX}] = \sum_x e^{tx}P(X = x)\) is a finite sum of finite numbers for every t.
[theorem] Proposition 1.3 (the normal moment-generating function) grade=T :: Assuming Assumption 1, if \(X \sim N(\mu, \sigma^{2})\) with \(\sigma > 0\), then the domain of \(M_X\) is the whole real line, and \(M_X(t) = \exp(\mu t + \sigma^{2}t^{2}/2)\) for every real t.
[proof] Proof grade=- :: By Proposition 1.4 of L06, \(X = \mu + \sigma Z\) with Z standard normal. So \(E[e^{tX}] = e^{\mu t}E[e^{s Z}]\) with \(s = \sigma t\). For real s, the integrand \(e^{sz - z^{2}/2}\) is at most \(e^{s^{2} - z^{2}/4}\), because \(sz \le z^{2}/4 + s^{2}\). That bound is integrable, so the integral converges absolutely and \[ E[e^{sZ}] = (2\pi)^{-1/2}\int e^{sz - z^{2}/2}\,dz. \] Complete the square: \[ sz - \frac{z^{2}}{2} = -\frac{(z - s)^{2}}{2} + \frac{s^{2}}{2}. \] So the integral is \(e^{s^{2}/2}\int e^{-(z-s)^{2}/2}\,dz\). Substituting \(u = z - s\) leaves the integral over the whole line unchanged, and by Proposition 1.2 of L06 it equals \(\sqrt{2\pi}\). Hence \(E[e^{sZ}] = e^{s^{2}/2}\), and \[ M_X(t) = e^{\mu t}\,e^{\sigma^{2}t^{2}/2} = \exp\big(\mu t + \sigma^{2}t^{2}/2\big). \]

[remark] Remark 1.5 (what the domain means) grade=- :: A moment-generating function is defined on its domain. Proposition 1.2 covers finitely many values, and Proposition 1.3 covers the normal. Proposition 1.4 gives a variable whose domain is bounded above by \(1/2\). This page does not compute the domain of the Student-t moment-generating function, and no result below depends on it.
[definition] Definition 2.1 (complex exponential) grade=- :: For a real a, the complex exponential is \(e^{ia} = \cos a + i\sin a\), where \(i^{2} = -1\). Its modulus is \(|e^{ia}| = \sqrt{\cos^{2}a + \sin^{2}a} = 1\). The expectation of a complex-valued variable is the expectation of its real part plus \(i\) times the expectation of its imaginary part.
[definition] Definition 2.2 (characteristic function) grade=- :: For a real random variable X and a real t, the characteristic function is \(\varphi_X(t) = E[e^{itX}]\).
[theorem] Proposition 2.3 (existence and bound for finitely valued variables and densities) grade=T :: Assuming Assumption 1(c) in the density case, for every real random variable X with finitely many values, or with a density, and every real t, \(\varphi_X(t)\) is defined. Moreover \(|\varphi_X(t)| \le 1\) and \(\varphi_X(0) = 1\).
[proof] Proof grade=- :: The variable \(e^{itX}\) has modulus 1 for every outcome (Definition 2.1), so its real and imaginary parts are bounded by 1 and integrable. Its expectation is therefore finite. The triangle inequality for finite sums (or, in the density case, for integrals by Assumption 1(c)) gives \(|E[Y]| \le E[|Y|]\) for a complex variable Y. With \(Y = e^{itX}\), \(|\varphi_X(t)| \le E[1] = 1\). At \(t = 0\), \(e^{0} = 1\), so \(\varphi_X(0) = 1\).
[theorem] Proposition 2.4 (affine maps) grade=T :: For real a and b, \(\varphi_{aX + b}(t) = e^{itb}\,\varphi_X(at)\) for every real t.
[proof] Proof grade=- :: Since \(e^{it(aX + b)} = e^{itb}e^{i(at)X}\) and \(e^{itb}\) is a constant, linearity of expectation gives \(E[e^{it(aX+b)}] = e^{itb}E[e^{i(at)X}] = e^{itb}\varphi_X(at)\).
