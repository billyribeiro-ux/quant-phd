A risk report that says the 99th percentile loss on a portfolio is a stated amount is making a claim about a quantile (defined in Definition 3.1 below): a value below which, by a stated probability, the loss falls. To say that exactly, you need a definition of the quantile that still makes sense when the distribution has jumps, which a formula written for a smooth distribution does not give. This lesson defines a random variable and its distribution on a finite probability space, the distribution function, and the quantile function with a stated convention. It proves the formula for the quantile of a finite law and checks that formula on an exact example.
1Probability spaces and random variables
A finite probability space is a finite set \(\Omega\) of outcomes together with weights \(p(\omega) > 0\) for \(\omega \in \Omega\), with \(\sum_{\omega \in \Omega} p(\omega) = 1\). For an event \(A \subseteq \Omega\), its probability is \(P(A) = \sum_{\omega \in A} p(\omega)\). Strictly positive weights mean that every outcome has positive probability, which keeps the statements below free of empty cases.
        Definition 1.1 (random variable)
Let \(\Omega\) be a finite probability space. A random variable on \(\Omega\) is a function \(X : \Omega \to \R\). Its values are the real numbers \(X(\omega)\), one for each outcome.
        Definition 1.2 (distribution and support)
The distribution of \(X\) assigns to each real \(x\) the probability \(P(X = x) = \sum_{\omega \,:\, X(\omega) = x} p(\omega)\). The support of \(X\) is the set of values that \(X\) takes on \(\Omega\). A value \(x\) is in the support exactly when \(P(X = x) > 0\), because every outcome has positive weight.
        Example 1.3 (a three-outcome loss)
Let \(\Omega = \{a, b, c\}\) with \(p(a) = \tfrac12\), \(p(b) = \tfrac13\) and \(p(c) = \tfrac16\). These weights are positive and sum to 1. Let \(X(a) = 0\), \(X(b) = 1\) and \(X(c) = 3\). The distribution of \(X\) is \(P(X = 0) = \tfrac12\), \(P(X = 1) = \tfrac13\) and \(P(X = 3) = \tfrac16\). Its support is \(\{0, 1, 3\}\). The probability that \(X\) is at most 1 is \(\tfrac12 + \tfrac13 = \tfrac56\).
2The distribution function
        Definition 2.1 (distribution function)
The distribution function of \(X\) is \(F(x) = P(X \le x)\) for \(x \in \R\). Writing \(x_1 < x_2 < \dots < x_m\) for the distinct values of \(X\), we set \(p_k = P(X = x_k)\) and \(F_k = F(x_k)\).
        Proposition 2.2 (shape of a finite distribution function)
Let \(X\) be a random variable on a finite probability space whose weights are all positive, with distinct values \(x_1 < \dots < x_m\). Then:
(a) \(F(x) = 0\) for \(x < x_1\), and \(F(x) = 1\) for \(x \ge x_m\);
(b) \(F\) is nondecreasing, and for \(x_k \le x < x_{k+1}\) (with \(1 \le k < m\)) we have \(F(x) = F_k\);
(c) \(F_k = p_1 + \dots + p_k\) for each \(k\), and \(F_m = 1\);
(d) \(F\) is right-continuous, and it jumps at each value: \(F(x_k) - \lim_{x \uparrow x_k} F(x) = p_k > 0\).
        Proof
Since \(X\) takes only the values \(x_1, \dots, x_m\), and these values partition \(\Omega\) into the events \(\{X = x_j\}\), we have \(P(X \le x) = \sum_{j \,:\, x_j \le x} p_j\). So \(F(x)\) is a sum of the weights \(p_j\) over the values \(x_j\) that do not exceed \(x\). For (a), if \(x < x_1\) there is no such \(j\), and the empty sum is 0. If \(x \ge x_m\), every index \(j\) qualifies, so \(F(x) = \sum_{j=1}^m p_j\). This sum equals \(P(\Omega) = 1\), which proves (c) for \(k = m\) and the second claim of (a). For (b), each \(p_j\) is positive, so adding more indices as \(x\) grows can only increase the sum. If \(x_k \le x < x_{k+1}\), the indices with \(x_j \le x\) are exactly \(1, \dots, k\), so \(F(x) = F_k = p_1 + \dots + p_k\), which proves (b) and (c). For (d), the formula in (b) shows \(F\) is constant on \([x_k, x_{k+1})\), so it is right-continuous at each \(x_k\), and its left limit at \(x_k\) is \(F_{k-1}\) (with \(F_0 = 0\)). The jump is \(F_k - F_{k-1} = p_k\), which is positive. \(\blacksquare\)
3The quantile function
For a set \(A\) of real numbers that is bounded below, \(\inf A\) denotes its infimum, the greatest real number that is at most every member of \(A\). The quantifier logic of M1 applies to these definitions, and each claim below states its domain.
        Definition 3.1 (quantile function)
For \(X\) as above and \(0 < p \le 1\), the quantile function of \(X\) is \(Q(p) = \inf\{x \in \R : F(x) \ge p\}\). This is the left-endpoint convention used in this lesson: at a jump, \(Q(p)\) is the smallest value whose distribution function reaches \(p\). The convention is fixed by this definition. Other conventions exist, and they give different answers at the jump points.
        Proposition 3.2 (quantile of a finite law)
Let \(X\) be as in Proposition 2.2, with distinct values \(x_1 < \dots < x_m\) and \(F_k = F(x_k)\). Let \(0 < p \le 1\), and let \(k^*\) be the least index \(k\) with \(F_k \ge p\). Then the set \(\{x : F(x) \ge p\}\) has the infimum \(x_{k^*}\), so \(Q(p) = x_{k^*}\).
        Proof
The index \(k^*\) exists, because \(F_m = 1 \ge p\) by Proposition 2.2(c). Let \(A = \{x : F(x) \ge p\}\). The point \(x_{k^*}\) belongs to \(A\), since \(F_{k^*} \ge p\) by choice. To show that \(x_{k^*}\) is the infimum of \(A\), it remains to show that every \(x \in A\) satisfies \(x \ge x_{k^*}\). Take \(x \in A\). If \(x < x_1\), then \(F(x) = 0 < p\) by Proposition 2.2(a), which contradicts \(x \in A\). So \(x \ge x_1\), and there is an index \(j\) with \(x_j \le x < x_{j+1}\), or \(j = m\) if \(x \ge x_m\). By Proposition 2.2(b), \(F(x) = F_j\). Since \(x \in A\), we get \(F_j \ge p\), and minimality of \(k^*\) gives \(j \ge k^*\). Therefore \(x \ge x_j \ge x_{k^*}\). The point \(x_{k^*}\) is thus a lower bound of \(A\) that belongs to \(A\), so it is the infimum. \(\blacksquare\)
        Remark 3.3 (the jumps of the quantile function)
Let \(X\) be as in Proposition 2.2, and put \(F_0 = 0\). For \(1 \le k \le m\) and \(F_{k-1} < p \le F_k\), we have \(Q(p) = x_k\). In particular \(Q(F_k) = x_k\), and \(Q\) is left-continuous on \((0, 1]\): if \(u_n \uparrow p\), then \(Q(u_n) \to Q(p)\). For \(k < m\), just to the right of \(F_k\) the value jumps to \(x_{k+1}\).
Proof. Since \(F\) is nondecreasing, \(F_j \le F_{k-1} < p\) for \(j \le k-1\), and \(F_k \ge p\). So the least index with \(F_j \ge p\) is \(k\), and Proposition 3.2 gives \(Q(p) = x_k\). For left-continuity, fix \(p \in (0, 1]\) and choose \(k\) with \(F_{k-1} < p \le F_k\), which exists because \(F_0 = 0 < p \le F_m = 1\). Then \(Q(p) = x_k\), as shown above. Take \(u_n \uparrow p\). Eventually \(u_n\) lies in \((F_{k-1}, p]\), a subset of \((F_{k-1}, F_k]\), so \(Q(u_n) = x_k = Q(p)\). \(\blacksquare\)
        Proposition 3.4 (quantile of n equally likely values)
Let \(y_1 < \dots < y_n\) be \(n \ge 1\) distinct real numbers, and let \(X\) take each \(y_j\) with probability \(1/n\). Then for every \(p\) with \(0 < p \le 1\), \(Q(p) = y_{\lceil pn \rceil}\), where \(\lceil pn \rceil\) is the least integer that is at least \(pn\). Thus \(Q(p)\) is the \(\lceil pn \rceil\)-th smallest value.
        Proof
Here \(p_j = 1/n\), so Proposition 2.2(c) gives \(F_j = j/n\). By Proposition 3.2, \(Q(p) = y_{k^*}\), where \(k^*\) is the least \(j\) with \(j/n \ge p\). Multiplying by \(n > 0\), this is the least integer \(j\) with \(j \ge pn\), which is \(\lceil pn \rceil\). Since \(0 < pn \le n\), the integer \(\lceil pn \rceil\) lies between 1 and \(n\), so it is a valid index. \(\blacksquare\)
        Example 3.5 (the index for 150 and 200 values)
Take \(n = 200\) and \(p = 0.99\). Then \(pn = 198\), which is an integer, so \(\lceil pn \rceil = 198\), and the quantile is the 198th smallest value. Take \(n = 150\) and \(p = 0.99\). Then \(pn = 148.5\), so \(\lceil pn \rceil = 149\). The quantile is the 149th smallest value, not the 148th. The floor of 148.5 is 148, and using it would move the index down by one.
        Example 3.6 (the table of Lab 1)
Let \(X\) take the values \(-2, -1, 0, 1, 2, 3\) with probabilities \(\tfrac1{10}, \tfrac2{10}, \tfrac3{10}, \tfrac2{10}, \tfrac1{10}, \tfrac1{10}\). These sum to 1 and are positive, so Proposition 2.2 applies. The distribution function values are \(F(-2) = \tfrac1{10}\), \(F(-1) = \tfrac3{10}\), \(F(0) = \tfrac35\), \(F(1) = \tfrac45\), \(F(2) = \tfrac9{10}\) and \(F(3) = 1\). By Proposition 3.2, \(Q(\tfrac12) = 0\), because \(F(-1) = \tfrac3{10} < \tfrac12\) and \(F(0) = \tfrac35 \ge \tfrac12\). Also \(Q(\tfrac35) = 0\), because \(F(0) = \tfrac35\) reaches \(\tfrac35\) exactly, and \(Q(\tfrac{61}{100}) = 1\), because \(F(0) = \tfrac35 < \tfrac{61}{100} \le \tfrac45 = F(1)\). Lab 1 prints these values and the rest of the table.
Lab 1 · The distribution function and quantile of a finite law
Predicted from Propositions 2.2 and 3.2 before running. The distribution function values are \(\tfrac1{10}\), \(\tfrac3{10}\), \(\tfrac35\), \(\tfrac45\), \(\tfrac9{10}\) and 1, printed as exact fractions. The quantile at \(p = \tfrac1{20}\) and at \(p = \tfrac1{10}\) is \(-2\), at \(p = \tfrac{11}{100}\) it is \(-1\), at \(p = \tfrac12\) and \(p = \tfrac35\) it is 0, at \(p = \tfrac{61}{100}\) it is 1, at \(p = \tfrac9{10}\) it is 2, and at \(p = \tfrac{91}{100}\), \(p = \tfrac{99}{100}\) and \(p = 1\) it is 3. The scan and the definition of \(Q\) should agree at all 100 grid points \(p = j/100\), and \(F(Q(p)) \ge p\) should hold at all 100. Just above \(F(x)\), the quantile should jump to the next value.
"""M4 lab L01: a finite discrete law, its CDF and its quantile function, computed exactly.
Standard library only (fractions, itertools, collections.abc). No randomness and no network: every probability and every
value of F and Q is an exact rational or an integer, so the output is the same on every run.
The law is a stated table, not data. The quantile function is Q(p) = inf{x : F(x) >= p} for
0 < p <= 1. On a finite law F changes only at support points, so Q(p) is the least support
point x with F(x) >= p. The program computes Q two ways (a scan of the support in increasing
order, and the minimum over the support points with F(x) >= p) and checks them against each
other on 100 grid points, p = j/100 for j = 1 to 100. It also checks F(Q(p)) >= p on the same
grid and checks Q(F(x)) = x at each support point. It prints Q at F(x) and just above F(x) to
show the jump. Each check covers only the finite list it runs on.
"""
from __future__ import annotations
import itertools
from collections.abc import Sequence
from fractions import Fraction
Law = Sequence[tuple[int, Fraction]]
# value -> probability, values strictly increasing, probabilities exact and summing to 1
LAW: tuple[tuple[int, Fraction], ...] = (
    (-2, Fraction(1, 10)),
    (-1, Fraction(2, 10)),
    (0, Fraction(3, 10)),
    (1, Fraction(2, 10)),
    (2, Fraction(1, 10)),
    (3, Fraction(1, 10)),
)
def check_law(law: Law) -> None:
    """Raise ValueError unless the values strictly increase and the probabilities are in [0, 1] and sum to 1."""
    values = [v for v, _ in law]
    if any(a >= b for a, b in itertools.pairwise(values)):
        raise ValueError("values must be strictly increasing")
    if any(p < 0 or p > 1 for _, p in law):
        raise ValueError("each probability must lie in [0, 1]")
    if sum((p for _, p in law), Fraction(0)) != 1:
        raise ValueError("probabilities must sum to exactly 1")
def cdf(law: Law, x: int) -> Fraction:
    """F(x) = P(X <= x): the sum of the probabilities of the values at most x."""
    return sum((p for v, p in law if v <= x), Fraction(0))
def quantile(law: Law, p: Fraction) -> int:
    """Q(p) by a scan: the first value, in increasing order, whose cumulative probability reaches p."""
    if not 0 < p <= 1:
        raise ValueError(f"quantile needs 0 < p <= 1, got {p}")
    total = Fraction(0)
    for value, prob in law:
        total += prob
        if total >= p:
            return value
    raise ValueError("the law does not reach p; check_law should have rejected it")
def quantile_by_definition(law: Law, p: Fraction) -> int:
    """Q(p) as the minimum of {x : F(x) >= p} over the support points.
    F is constant between support points and equal to F at the support point just below, so
    the infimum over all real x with F(x) >= p is attained at a support point.
    """
    if not 0 < p <= 1:
        raise ValueError(f"quantile needs 0 < p <= 1, got {p}")
    return min(v for v, _ in law if cdf(law, v) >= p)
def main() -> None:
    check_law(LAW)
    values = [v for v, _ in LAW]
    print(f"law: {len(LAW)} values, probabilities sum to {sum((p for _, p in LAW), Fraction(0))}")
    cdfs = [cdf(LAW, v) for v in values]
    print("CDF F(x) at " + ", ".join(str(v) for v in values) + ": " + ", ".join(str(f) for f in cdfs))
    probes = [
        Fraction(1, 20),
        Fraction(1, 10),
        Fraction(11, 100),
        Fraction(1, 2),
        Fraction(3, 5),
        Fraction(61, 100),
        Fraction(9, 10),
        Fraction(91, 100),
        Fraction(99, 100),
        Fraction(1),
    ]
    for p in probes:
        print(f"Q({p}) = {quantile(LAW, p)}")
    grid = [Fraction(j, 100) for j in range(1, 101)]
    same = sum(quantile(LAW, p) == quantile_by_definition(LAW, p) for p in grid)
    reaches = sum(cdf(LAW, quantile(LAW, p)) >= p for p in grid)
    print(f"grid p = j/100, j = 1 to 100: scan equals definition at {same} of 100 points")
    print(f"F(Q(p)) >= p at {reaches} of 100 grid points")
    back = all(quantile(LAW, cdf(LAW, v)) == v for v in values)
    print(f"Q(F(x)) = x at all {len(values)} support points: {back}")
    eps = Fraction(1, 10**9)
    for v, f in zip(values[:-1], cdfs[:-1], strict=True):
        print(f"at x = {v}: Q(F(x)) = {quantile(LAW, f)}, Q(F(x) + eps) = {quantile(LAW, f + eps)}, eps = 1/10**9")
main()

The program uses exact fractions, so every printed value is exact and the output is the same on every run. The check "scan equals definition at 100 of 100 points" is a finite check on the grid \(j/100\), and it confirms the two forms of Proposition 3.2 at those 100 points only. The proof, not the grid, covers all \(p\) in \((0, 1]\). The lines for \(x = -2\) to \(2\) show the left-endpoint convention and the jump: \(Q(F(x)) = x\), and \(Q\) moves to the next value of the support immediately above \(F(x)\). The printed value of \(F(x) + \varepsilon\) with \(\varepsilon = 10^{-9}\) is the value at a point just above the jump, not a limit taken over all \(p\).
4Where the canon breaks
The definitions above fix one convention and prove results for finite laws. Four caveats follow from that.
The convention decides the answer at a jump. Example 3.6 gives \(Q(\tfrac35) = 0\) under Definition 3.1. The strict rule \(\inf\{x : F(x) > p\}\) returns 1 at the same \(p\) (Problem R1). Each rule is a different definition, and a report must state which one it uses. Proposition 3.4 is Definition 3.1 applied to equally likely values, and it gives the ceiling index.
The off-by-one index is a convention error, not a rounding detail. Example 3.5 gives 149 for \(n = 150\) and \(p = 0.99\), and names 148, the floor of \(pn = 148.5\), as the wrong index; the two differ by one position in the sorted list. A rule with the floor of \(pn\) returns the lower index. Under Definition 3.1 the index is the ceiling, 149: the 148th value has distribution function \(148/150 = 74/75 \approx 0.987\), which is below 0.99, so it does not reach the level.
The results concern finite laws. Every proof here uses a finite list of values and weights. The general quantile function of a law with infinite support is a different object, and this lesson does not prove its properties.
A quantile of a sample describes the sample. Proposition 3.4 is an exact statement about \(n\) equally likely values. It says nothing about the distribution those values were drawn from, which is a question about estimation that this lesson does not address.
5Misconceptions
“The quantile at \(p\) is a value \(x\) with \(F(x) = p\), so \(F(Q(p)) = p\) always holds.”
Proposition 3.2 gives \(F(Q(p)) \ge p\), not equality. In Example 3.6, \(Q(\tfrac12) = 0\), but \(F(0) = \tfrac35 \ne \tfrac12\). The value 0 is where the distribution function jumps over \(\tfrac12\), so no value \(x\) has \(F(x) = \tfrac12\). Lab 1 checks \(F(Q(p)) \ge p\) at 100 grid points and prints 100 of 100.
“At \(p = F(x_k)\), the quantile moves up to the next value \(x_{k+1}\).”
Remark 3.3 says \(Q(F_k) = x_k\). The condition in Definition 3.1 is \(F(x) \ge p\), so the value whose distribution function equals \(p\) qualifies. In Example 3.6, \(Q(\tfrac35) = 0\), not 1. By Proposition 3.2 with \(F(0) = \tfrac35\) and \(F(1) = \tfrac45\), \(Q(p) = 1\) exactly for \(p\) in \((\tfrac35, \tfrac45]\), as the value \(Q(\tfrac{61}{100}) = 1\) shows.
“The 99th percentile of 150 values is the 148th smallest, because \(0.99 \times 150 = 148.5\) rounds down.”
Proposition 3.4 gives the index \(\lceil pn \rceil = \lceil 148.5 \rceil = 149\). The index is the least integer at least \(pn\), so the ceiling of 148.5 is 149, not the floor, 148. The 149th value is the one whose distribution function reaches 0.99 in the list of 150 equally likely values.

Mechanics
            M1 · The distribution of a parity variable
Let \(\Omega = \{1, 2, 3, 4\}\) with \(p(\omega) = \tfrac14\) for each \(\omega\), and let \(X(\omega) = 1\) if \(\omega\) is odd and \(X(\omega) = 0\) if \(\omega\) is even. Find the distribution function and \(Q(\tfrac12)\).
Solution
The outcomes 1 and 3 give \(X = 1\), and the outcomes 2 and 4 give \(X = 0\). So \(P(X = 0) = \tfrac12\) and \(P(X = 1) = \tfrac12\). The distribution function is \(F(x) = 0\) for \(x < 0\), \(F(x) = \tfrac12\) for \(0 \le x < 1\), and \(F(x) = 1\) for \(x \ge 1\). Since \(F(0) = \tfrac12 \ge \tfrac12\), Proposition 3.2 gives \(Q(\tfrac12) = 0\), the least value whose distribution function reaches \(\tfrac12\).
            M2 · A quantile on a three-value law
Let \(X\) take the values 2, 5 and 7 with probabilities \(\tfrac15\), \(\tfrac12\) and \(\tfrac{3}{10}\). Find \(F(5)\), \(Q(\tfrac{7}{10})\) and \(Q(\tfrac{71}{100})\).
Solution
The distribution function at 5 is \(F(5) = P(X \le 5) = \tfrac15 + \tfrac12 = \tfrac{7}{10}\). So \(F(5) = \tfrac{7}{10} \ge \tfrac{7}{10}\), and \(F(2) = \tfrac15 < \tfrac{7}{10}\), so \(Q(\tfrac{7}{10}) = 5\) by Proposition 3.2. For \(p = \tfrac{71}{100}\), \(F(5) = \tfrac{70}{100} < \tfrac{71}{100}\) and \(F(7) = 1\), so \(Q(\tfrac{71}{100}) = 7\). Remark 3.3 predicts this, since \(\tfrac{7}{10} = F_2\) and \(Q(F_2) = x_2 = 5\).
            M3 · The index on forty equally likely values
Let \(X\) take forty distinct values \(y_1 < \dots < y_{40}\) with probability \(\tfrac{1}{40}\) each. Find the index of \(Q(0.9)\) and of \(Q(0.901)\).
Solution
By Proposition 3.4, the index is \(\lceil 40 p \rceil\). For \(p = 0.9\), \(40 p = 36\), an integer, so the index is 36. For \(p = 0.901\), \(40 p = 36.04\), and \(\lceil 36.04 \rceil = 37\). So \(Q(0.9) = y_{36}\) and \(Q(0.901) = y_{37}\). The change of index happens because \(36.04\) exceeds 36 by any positive amount, which the ceiling rule detects.
Proof
            P1 · The distribution function of any finite law is nondecreasing
Let \(X\) take finitely many values with \(P(X = v)\) given for each. Prove from the definition \(F(x) = P(X \le x)\) that \(F\) is nondecreasing, without using the distinct-values hypothesis of Proposition 2.2.
Solution
Let \(x \le y\). The event \(\{X \le x\}\) is contained in \(\{X \le y\}\), because any outcome with \(X \le x\) also has \(X \le y\). Probability is monotone on events: \(P(B) = P(A) + P(B \setminus A) \ge P(A)\) when \(A \subseteq B\), since \(P(B \setminus A) \ge 0\) for nonnegative weights. Hence \(F(x) = P(X \le x) \le P(X \le y) = F(y)\).
            P2 · Quantile at a point with no jump
Let \(X\) be as in Proposition 2.2 and let \(k\) satisfy \(F_{k-1} < p < F_k\). Show that \(Q(p) = x_k\) and that \(Q(p')\) equals \(x_k\) for all \(p'\) in a neighbourhood of \(p\).
Solution
Remark 3.3 gives \(Q(p) = x_k\) for every \(p\) with \(F_{k-1} < p \le F_k\). Since \(F_{k-1} < p < F_k\), the interval \((F_{k-1}, F_k]\) contains a neighbourhood of \(p\): take \(\delta = \min(p - F_{k-1}, F_k - p) > 0\). Every \(p'\) with \(|p' - p| < \delta\) satisfies \(F_{k-1} < p' < F_k\), so \(Q(p') = x_k\). The quantile is locally constant at such \(p\).
            P3 · The maximum is the quantile at one
For \(X\) as in Proposition 2.2, prove that \(Q(1) = x_m\), the largest value.
Solution
By Proposition 2.2(c), \(F_m = 1\), and \(F_k < 1\) for \(k < m\), because \(F_k = p_1 + \dots + p_k\) and the weights \(p_{k+1}, \dots, p_m\) are positive. So the least index with \(F_k \ge 1\) is \(m\). Proposition 3.2 gives \(Q(1) = x_m\).
Empirical
            E1 · Checking the 99th quantile of the table (Lab 1)
Lab 1 prints \(Q(\tfrac{99}{100}) = 3\) for the table of Example 3.6. Verify this by hand, and say which value of \(F\) decides it.
Solution
The distribution function at 2 is \(F(2) = \tfrac{9}{10} = 0.90\), which is below \(0.99\). At 3 it is \(F(3) = 1 \ge 0.99\). By Proposition 3.2 the least value whose distribution function reaches 0.99 is 3. So \(Q(\tfrac{99}{100}) = 3\), and the printed line agrees. The decision rests on \(F(2) = \tfrac{9}{10} < \tfrac{99}{100}\), since the jump at 3 carries the last tenth of the probability.
            E2 · What the \(\varepsilon\) line shows (Lab 1)
Lab 1 prints \(Q(F(0)) = 0\) and \(Q(F(0) + \varepsilon) = 1\) with \(\varepsilon = 10^{-9}\). Explain both values, and say what the lab does not establish about \(\varepsilon\).
Solution
\(F(0) = \tfrac35\), and \(Q(\tfrac35) = 0\) by Remark 3.3, which says \(Q(F_k) = x_k\). For \(p = \tfrac35 + \varepsilon\), the least value with \(F \ge p\) is the next value above the jump, since \(F(0) < p \le F(1) = \tfrac45\). So \(Q = 1\). The lab checks one value of \(\varepsilon\). It does not establish a limit as \(\varepsilon\) shrinks; that follows from the proof, which covers every \(p\) in \((\tfrac35, \tfrac45]\).
            E3 · What a count below 100 would mean (Lab 1)
Lab 1 prints "scan equals definition at 100 of 100 points". Suppose a run printed 99. State what the printed count would show, and why the grid check cannot by itself prove the agreement for all \(p\).
Solution
The scan and the definition of \(Q\) both give the answer defined in Proposition 3.2, so a disagreement at any grid point would show an error in one of the two code paths for that point. The grid has 100 points, so a count below 100 would show that at least one grid point disagrees. The printed line does not say which point. The grid check cannot prove agreement for all \(p\), because \((0, 1]\) has infinitely many points and the grid covers only 100. The proof of Proposition 3.2 covers every \(p\), and the lab is a check of the code against that proof.

            R1 · The strict convention
Suppose the quantile were defined with a strict inequality, \(Q^{s}(p) = \inf\{x : F(x) > p\}\). For the table of Example 3.6, compute \(Q^{s}(\tfrac35)\) and state the general rule that \(Q^{s}\) follows on a finite law.
Solution
The distribution function at 0 is \(F(0) = \tfrac35\), which is not strictly greater than \(\tfrac35\). The next value with \(F > \tfrac35\) is \(x = 1\), since \(F(1) = \tfrac45 > \tfrac35\). So \(Q^{s}(\tfrac35) = 1\), while \(Q(\tfrac35) = 0\). For a finite law and \(p < 1\), the strict rule returns \(x_{k+1}\) when \(p = F_k\), and it agrees with \(Q\) at every other \(p\). Proof: if \(p = F_k\) with \(k < m\), then \(F(x_k) = F_k \not> p\) and \(F(x_{k+1}) > p\), so the least such \(x\) is \(x_{k+1}\). If \(F_{k-1} < p < F_k\), then \(F(x_j) \le F_{k-1} < p\) for \(j < k\) and \(F(x_k) = F_k > p\), so the least \(x\) with \(F(x) > p\) is \(x_k = Q(p)\), by Remark 3.3. At \(p = 1\) the set \(\{x : F(x) > 1\}\) is empty, so the strict rule has no value there. A report that uses the strict form must say so at each such point.
            R2 · Why left-continuity matters for a stated convention
Remark 3.3 says \(Q\) is left-continuous. Explain why a reader who expects right-continuity, as for \(F\), would misread the quantile at the jump points of Example 3.6.
Solution
The distribution function \(F\) is right-continuous (Proposition 2.2(d)), so its value at a jump is the value to the right. The quantile \(Q\) is left-continuous: at \(p = \tfrac35\), the value is 0, and the limit from the left, \(Q(p)\) for \(p\) just below \(\tfrac35\), is also 0. The limit from the right is 1. A reader who assumes right-continuity would expect \(Q(\tfrac35)\) to be the limit from the right, which is 1, and would read the table wrongly. The left-endpoint convention is what makes \(Q(\tfrac35) = 0\) match the limit from the left.
            R3 · What finite checks can and cannot establish
A colleague says the grid check of Lab 1 proves Proposition 3.2 for this table because every grid point agrees. State precisely what the check establishes, and what proof would be needed for all \(p\).
Solution
The grid check establishes agreement at the 100 points \(j/100\), \(j = 1, \dots, 100\), for this one table. It does not establish agreement at any other \(p\), and it says nothing about other tables. A proof for all \(p\) is Proposition 3.2 itself: it takes an arbitrary \(p\) in \((0, 1]\), finds the least index with \(F_k \ge p\), and shows that every \(x\) with \(F(x) \ge p\) is at least \(x_{k^*}\). That argument uses only Proposition 2.2 and the definition of infimum, and it covers every table with positive weights.
