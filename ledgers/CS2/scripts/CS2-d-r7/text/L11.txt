A median, a 99th percentile or a risk threshold needs the ranks of the values seen so far (Definition 1.1), and keeping every value makes memory grow with the stream. A streaming quantile sketch (Definition 2.1) keeps a bounded set of values instead. At \(n = 10^9\) and \(\varepsilon = 1/20\) the closed-form memory bound (Section 2, \(L = 29\)) is 198430, far below \(n\). At \(n = 5000\) the closed form is 18213 and the exact Corollary 2.6 sum is 18187 (Problem R3), both above \(n\). This lesson defines the allowed error, gives a deterministic sketch with a proved error guarantee, and checks it against exact ranks on a seeded stream of 5000 values.
1Ranks and approximate quantiles
Definition 1.1 (rank)
Let \(x_1, \ldots, x_n\) be real numbers, the values seen so far, in any order. For a real \(v\), the rank of \(v\) is \(R(v) = \#\{i : x_i \le v\}\), the number of values not above \(v\). The strict rank is \(R^-(v) = \#\{i : x_i < v\}\), the number of values below \(v\). Both are exact counts on the whole stream.
Definition 1.2 (approximate quantile)
Let \(q\) satisfy \(0 \le q \le 1\), and let \(\varepsilon\) satisfy \(0 < \varepsilon < 1\). A real number \(v\) is an \(\varepsilon\)-approximate \(q\)-quantile of \(x_1, \ldots, x_n\) if \[ R^-(v) \le qn + \varepsilon n \qquad\text{and}\qquad R(v) \ge qn - \varepsilon n. \] The condition is on counts, not on the distance between \(v\) and any exact value. The error is measured in ranks, as a fraction \(\varepsilon\) of \(n\). Setting \(\varepsilon = 0\) in the two inequalities gives an exact-count condition; Definition 1.2 requires \(\varepsilon > 0\), so this \(\varepsilon = 0\) case is an extension, used in Section 3, Misconception 2 and Problem P3.
A sketch is an object that reads the stream once, stores a set of items whose number is bounded by a cubic polynomial in \(\log_2 n\) (Corollary 2.6 and its proof), and answers quantile queries from those items alone. The sketch below is deterministic: it keeps no random choices, so the same stream gives the same answer.
2The sketch and its guarantee
Definition 2.1 (compactor sketch with level capacities)
Fix \(\varepsilon\) with \(0 < \varepsilon < 1\). For each level \(h = 0, 1, 2, \ldots\), the capacity is \[ k_h = 2\left\lceil \frac{(h+1)(h+2)}{2\varepsilon} \right\rceil. \] Each \(k_h\) is an even integer with \(k_h \ge (h+1)(h+2)/\varepsilon\). The streaming quantile sketch has buffers \(B_0, B_1, \ldots\), where each item in \(B_h\) has weight \(2^h\). It has three operations. (1) Add a value \(x\): push \(x\) into level 0 with weight 1. (2) Push a value \(y\) into level \(h\): append \(y\) to \(B_h\). If \(B_h\) now holds \(k_h\) items, compact it: sort \(B_h\) by comparisons, keep the items at the 2nd, 4th, \(\ldots\), \(k_h\)th positions (\(k_h/2\) items), empty \(B_h\), and push each kept item into level \(h+1\), in order. A kept item keeps its value and its weight doubles. (3) Quantile \(q\): list every stored item as a pair (value, weight), sort the pairs by value, and return the value of the first pair at which the running total of weights reaches \(qn\), where \(n\) is the number of values added.
Each compaction removes \(k_h\) items of weight \(2^h\) from level \(h\), and it adds \(k_h/2\) items of weight \(2^{h+1}\) to level \(h+1\). The next theorem shows that these two totals are equal, which is what keeps the total stored weight equal to \(n\).
Theorem 2.2 (weight is conserved, and compactions are bounded)
Hypotheses. (1) The values \(x_1, \ldots, x_n\) are added in order, one at a time. (2) \(\varepsilon\) is fixed with \(0 < \varepsilon < 1\), and the capacities \(k_h\) are as in Definition 2.1. (3) Arithmetic on weights and capacities is exact. Let \(C_h\) be the number of compactions at level \(h\) so far. The claim: (a) after every add, the total weight of the stored items is the number of values added; (b) for every \(h\), \(C_h \cdot k_h \cdot 2^h \le n\).
Proof
(a) An add increases the total weight by 1. A compaction at level \(h\) removes \(k_h\) items of weight \(2^h\), a total of \(k_h 2^h\), and adds \(k_h/2\) items of weight \(2^{h+1}\), again a total of \(k_h 2^h\). So a compaction leaves the total weight unchanged. Induction over the operations gives (a).
(b) Let \(P_h\) be the total weight of all items ever pushed into level \(h\). Every add pushes weight 1 into level 0, so \(P_0 = n\). A compaction at level \(h\) pushes \(k_h/2\) items of weight \(2^{h+1}\) into level \(h+1\), so \(P_{h+1} = C_h \cdot k_h 2^h\). A compaction at level \(h\) removes \(k_h\) items that were pushed into level \(h\), so \(C_h \cdot k_h 2^h \le P_h\). Combining the two, \(P_{h+1} \le P_h\) for every \(h\), so \(P_h \le P_0 = n\) for every \(h\). Then \(C_h k_h 2^h \le P_h \le n\), which is (b).
Lemma 2.3 (the capacity series sums to one)
For every integer \(H \ge 0\), \[ \sum_{h=0}^{H} \frac{1}{(h+1)(h+2)} = 1 - \frac{1}{H+2} < 1. \] Every partial sum of the series is below 1. No limit is taken.
Proof
Since \(\frac{1}{(h+1)(h+2)} = \frac{1}{h+1} - \frac{1}{h+2}\), the sum from \(h = 0\) to \(H\) telescopes to \(1 - \frac{1}{H+2}\). This is below 1 for every \(H\), because \(\frac{1}{H+2} > 0\).
Theorem 2.4 (rank error is at most \(\varepsilon n\))
Hypotheses. Those of Theorem 2.2, with \(n \ge 1\), and the capacities of Definition 2.1. Let \(E = \sum_h C_h 2^h\) be the total of the compaction errors. For a real \(v\), let \(\hat R(v)\) be the total weight of the stored items with value at most \(v\), and \(\hat R^-(v)\) the total weight of the stored items with value below \(v\). The claim: for every real \(v\), \(-E \le \hat R(v) - R(v) \le 0\) and \(-E \le \hat R^-(v) - R^-(v) \le 0\), and \(E \le \varepsilon n\).
Proof
The two sides. Every stored item is either an added value (weight 1) or an item pushed by a compaction. Each add changes \(\hat R(v)\) and \(R(v)\) by the same amount, \([x \le v]\), so the difference \(\hat R(v) - R(v)\) changes only at compactions. A compaction at level \(h\) is applied to a buffer whose sorted values are \(a_1 \le \cdots \le a_k\), with \(k = k_h\). Let \(c = \#\{j : a_j \le v\}\), so that \(a_1, \ldots, a_c\) are the values at most \(v\). The kept items are \(a_2, a_4, \ldots\), and the number of them at most \(v\) is \(\lfloor c/2 \rfloor\). The compaction changes \(\hat R(v)\) by \(2^{h+1}\lfloor c/2 \rfloor - 2^h c = 2^h(2\lfloor c/2 \rfloor - c)\). Since \(2\lfloor c/2 \rfloor - c\) is 0 when \(c\) is even and \(-1\) when \(c\) is odd, the change is 0 or \(-2^h\). Each stored item is created once, by an add or by a compaction, and removed at most once, by a compaction. So \(\hat R(v) - R(v)\) is the sum of the changes made by all the adds and compactions, and the adds contribute nothing to it. Each compaction changes it by a number in \([-2^h, 0]\), and summing over all compactions gives \(-E \le \hat R(v) - R(v) \le 0\). For \(\hat R^-\), take \(c = \#\{j : a_j < v\}\); the same computation applies, since the sorted values below \(v\) are again \(a_1, \ldots, a_c\).
The bound on \(E\). By Theorem 2.2(b), \(C_h 2^h \le n/k_h\) for every \(h\). Since \(k_h \ge (h+1)(h+2)/\varepsilon\), we have \(n/k_h \le \varepsilon n/((h+1)(h+2))\). Only finitely many \(C_h\) are nonzero: if \(C_h \ge 1\), then \(2^h \le n\), by Theorem 2.2(b) and \(k_h \ge 1\). Let \(H\) be the largest such \(h\), or let \(E = 0\) if no compaction happens. Summing over \(h \le H\) and using Lemma 2.3 gives \(E \le \varepsilon n \sum_{h \le H} 1/((h+1)(h+2)) \le \varepsilon n\).
Theorem 2.5 (the quantile answer satisfies Definition 1.2)
Hypotheses. Those of Theorem 2.4. For \(q\) with \(0 \le q \le 1\), the quantile query returns a stored value \(v\) with \(R(v) \ge qn\) and \(R^-(v) \le qn + E \le qn + \varepsilon n\). Hence \(v\) is an \(\varepsilon\)-approximate \(q\)-quantile in the sense of Definition 1.2.
Proof
Sort the stored pairs by value as \((v_1, w_1), \ldots, (v_s, w_s)\), and let \(W_j = w_1 + \cdots + w_j\). By Theorem 2.2(a), \(W_s = n\). The query returns \(v = v_{j^*}\), where \(j^*\) is the smallest index with \(W_{j^*} \ge qn\); such an index exists because \(W_s = n \ge qn\).
The upper count. Every item with index at most \(j^*\) has value at most \(v\), so \(\hat R(v) \ge W_{j^*} \ge qn\). By Theorem 2.4, \(R(v) \ge \hat R(v) \ge qn\), which gives \(R(v) \ge qn - \varepsilon n\).
The lower count. Let \(f\) be the first index with value \(v\), so \(f \le j^*\). The stored items with value below \(v\) have indices below \(f\), so \(\hat R^-(v) \le W_{f-1}\). If \(j^* \ge 2\), then \(f - 1 \le j^* - 1\) and \(W_{j^*-1} < qn\) by the minimality of \(j^*\), so \(\hat R^-(v) < qn\). If \(j^* = 1\), then \(f = 1\) and \(\hat R^-(v) = 0 \le qn\). In both cases \(\hat R^-(v) \le qn\). By Theorem 2.4, \(R^-(v) \le \hat R^-(v) + E \le qn + \varepsilon n\).
Corollary 2.6 (memory)
Hypotheses. Those of Theorem 2.2, with \(n \ge 1\). The number of stored items is at most \(\sum_{h=0}^{\lfloor \log_2 n \rfloor} (k_h - 1)\).
Proof
A stored item at level \(h\) has weight \(2^h\), so level \(h\) is nonempty only if \(2^h \le P_h \le n\), by the proof of Theorem 2.2(b). That gives \(h \le \log_2 n\). Each buffer holds at most \(k_h - 1\) items, because it is compacted when it reaches \(k_h\). Summing over the levels that can be nonempty gives the bound.
Growth of the bound. Let \(L = \lfloor \log_2 n \rfloor\). From \(k_h = 2\lceil (h+1)(h+2)/(2\varepsilon) \rceil \le (h+1)(h+2)/\varepsilon + 2\) we get \(k_h - 1 \le (h+1)(h+2)/\varepsilon + 1\). Since \(\sum_{h=0}^{L}(h+1)(h+2) = \sum_{m=1}^{L+1} m(m+1) = (L+1)(L+2)(L+3)/3\), the bound is at most \((L+1)(L+2)(L+3)/(3\varepsilon) + (L+1)\). This is \(O((\log_2 n)^3/\varepsilon)\) as \(n\) grows. For \(\varepsilon = 1/20\) and \(n = 5000\) (so \(L = 12\)) it gives \(2730/0.15 + 13 = 18213\), which is at least the exact sum 18187 of Problem R3.
Theorems 2.4 and 2.5 hold for every stream, in exact arithmetic on the weights. The lab below checks the guarantee on one seeded stream, and Section 3 says what that check does and does not show.
Lab 1 · The sketch's rank error against exact counts on a seeded stream

3Where the canon breaks
The guarantee is about ranks, not values. Take the values \(1, \ldots, 1000\), \(q = 1/2\) and \(\varepsilon = 1/20\). One exact answer is \(v = 500\), since \(R^-(500) = 499 \le 500\) and \(R(500) = 500 \ge 500\). With the two inequalities taken with \(\varepsilon n\) replaced by 0, the value \(v = 501\) is also accepted, since \(R^-(501) = 500 \le 500\) and \(R(501) = 501 \ge 500\), so the exact answer is not unique. The value \(v = 450\) is allowed with \(\varepsilon = 1/20\): \(R^-(450) = 449 \le 550\) and \(R(450) = 450 \ge 450\). The two answers 450 and 500 differ by 50 in value, and Definition 1.2 with \(\varepsilon = 1/20\) accepts both.
The bound is worst case, and it is not claimed to be optimal. Theorem 2.4 holds for every stream, so no stream's rank error exceeds \(\varepsilon n\). The memory bound of Corollary 2.6 is a sum of capacities over the levels up to \(\log_2 n\), and the proof of Corollary 2.6 bounds it by a quantity that is \(O((\log_2 n)^3/\varepsilon)\). No comparison with other sketch designs is made here, and this lesson does not claim the design is space-optimal.
Exact before the first compaction. If fewer than \(k_0\) values have been added, no compaction has happened, every weight is 1, and \(E = 0\). Theorem 2.5 then gives \(R(v) \ge qn\) and \(R^-(v) \le qn\), which are the two inequalities of Definition 1.2 with \(\varepsilon n\) replaced by 0 (the extension noted in Section 1). The bound \(E\) becomes positive at the first compaction.
4Misconceptions
“A quantile sketch must store every value before it can answer a quantile query.”
Corollary 2.6 bounds the stored items by a sum over the levels up to \(\log_2 n\), and the proof bounds that sum by \((L+1)(L+2)(L+3)/(3\varepsilon) + (L+1)\) with \(L = \lfloor \log_2 n \rfloor\). For \(n = 10^9\) (so \(L = 29\)) and \(\varepsilon = 1/20\), this is at most 198430, far below \(n\). At \(n = 5000\) the exact sum of Corollary 2.6 for \(\varepsilon = 1/20\) is 18187 (Problem R3), which is larger than \(n\), so the bound saves nothing at that size. Lab 1 stores 500 items out of 5000 values with \(\varepsilon = 1/20\).
“An \(\varepsilon\)-approximate quantile is within \(\varepsilon\) of the exact quantile in value.”
Definition 1.2 bounds counts. Take 500 values equal to 0 and 500 values equal to 1000. For \(q = 1/2\) and \(\varepsilon = 1/20\), the value 1000 satisfies \(R^-(1000) = 500 \le 550\) and \(R(1000) = 1000 \ge 450\), so it is an allowed answer, although it is 1000 away from 0 in value. Any value in \([0, 1000]\) satisfies both inequalities of Definition 1.2 with \(\varepsilon n\) replaced by 0 (the extension noted in Section 1), so the counts alone do not determine the value of a median.
“Every stored item counts once in the answer.”
An item at level \(h\) has weight \(2^h\) (Definition 2.1). The quantile query adds these weights, not the number of items, and Theorem 2.2(a) says the weights sum to \(n\).
5Problem set
Every problem has a full worked solution. Attempt each one before opening it.
Mechanics
M1 · Capacities for epsilon one tenth
For \(\varepsilon = 1/10\), compute \(k_0\), \(k_1\) and \(k_2\) from Definition 2.1.
Solution
Here \((h+1)(h+2)/(2\varepsilon) = 5(h+1)(h+2)\). So \(k_0 = 2\lceil 10 \rceil = 20\), \(k_1 = 2\lceil 30 \rceil = 60\), and \(k_2 = 2\lceil 60 \rceil = 120\). These match the lab's printed capacities 20, 60 and 120.
M2 · A quantile from stored pairs
The stored pairs are (1, weight 1), (2, weight 2) and (5, weight 4). What does the query return for \(q = 1/2\)?
Solution
The total weight is \(n = 7\), so \(qn = 3.5\). The running totals are 1, 3 and 7. The first total at least 3.5 is 7, at the pair with value 5. The query returns 5. If these pairs are the state of a run of the sketch, Theorem 2.4 gives \(R(5) \ge \hat R(5) = 7\), so \(R(5) \ge 3.5\) holds, and \(R(5) = 7\) because \(R(5) \le n = 7\).
M3 · Forty values at epsilon one tenth
Add 40 values with \(\varepsilon = 1/10\), so \(k_0 = 20\). Give the number of stored items at each level and the total weight.
Solution
The 20th add fills level 0, which compacts: 10 items of weight 2 go to level 1, and level 0 is empty. Adds 21 to 40 fill level 0 again at the 40th add, so there is a second compaction, and 10 more items of weight 2 go to level 1. Level 1 now holds 20 items, which is below \(k_1 = 60\), so it does not compact. Level 0 is empty. The total weight is \(20 \times 2 = 40\), which equals the number of values, as Theorem 2.2(a) requires.
Proof
P1 · The series in Lemma 2.3
Show that the partial sums of \(\sum_{h \ge 0} 1/((h+1)(h+2))\) equal \(1 - 1/(H+2)\), and deduce that every partial sum is below 1.
Solution
Each term is \(\frac{1}{h+1} - \frac{1}{h+2}\), so the terms telescope: the sum from \(h = 0\) to \(H\) keeps \(\frac{1}{1}\) and the last term \(-\frac{1}{H+2}\), which is \(1 - \frac{1}{H+2}\). Since \(1/(H+2) > 0\) for every \(H\), every partial sum is below 1. The argument takes no limit.
P2 · The parity step
Let \(a_1 \le \cdots \le a_k\) be sorted, and let \(c = \#\{j : a_j \le v\}\). Show that \(2\lfloor c/2 \rfloor - c\) is 0 or \(-1\), and state the consequence for the per-compaction error.
Solution
If \(c\) is even, \(\lfloor c/2 \rfloor = c/2\), so \(2\lfloor c/2 \rfloor - c = 0\). If \(c\) is odd, \(\lfloor c/2 \rfloor = (c-1)/2\), so the expression is \((c-1) - c = -1\). So the change in \(\hat R(v)\) from one compaction at level \(h\) is \(2^h\) times this, which is 0 or \(-2^h\). Each compaction therefore moves the weighted count by at most \(2^h\).
P3 · An exact run
Show that if \(n < k_0\), the answer to every quantile query is exact in the sense of Definition 1.2 with \(\varepsilon = 0\).
Solution
When \(n < k_0\), no buffer reaches its capacity, so no compaction occurs. Every stored item has weight 1, and the stored items are all \(n\) values, so \(E = 0\). Theorem 2.5 with \(E = 0\) gives \(R(v) \ge qn\) and \(R^-(v) \le qn\), which are the two inequalities of Definition 1.2 with \(\varepsilon n\) replaced by 0 (the extension noted in Section 1).
Empirical
E1 · Thirty-nine values at epsilon one tenth
Add 39 values with \(\varepsilon = 1/10\). Give the number of stored items, the total weight, and the rank-error bound \(E\).
Solution
The 20th add compacts level 0, which leaves 10 items of weight 2 at level 1. Adds 21 to 39 put 19 items into level 0, which has capacity 20 and so does not compact. The stored items number \(10 + 19 = 29\), and the total weight is \(20 + 19 = 39\). There is one compaction at level 0, so \(E = C_0 \cdot 2^0 = 1\). The bound \(\varepsilon n = 3.9\) is larger than \(E = 1\), as Theorem 2.4 gives.
E2 · The compaction count in Lab 1
Lab 1 prints 151 compactions for \(\varepsilon = 1/20\) and 5000 values. Compare this with the bound of Theorem 2.2(b), level by level.
Solution
The capacities are \(k_0 = 40\), \(k_1 = 120\), \(k_2 = 240\), \(k_3 = 400\) and \(k_4 = 600\). Theorem 2.2(b) gives \(C_h \le 5000/(k_h 2^h)\), so the integer upper bounds on the counts are \(\lfloor 5000/40 \rfloor = 125\), \(\lfloor 5000/240 \rfloor = 20\), \(\lfloor 5000/960 \rfloor = 5\), \(\lfloor 5000/3200 \rfloor = 1\), and \(0\) for \(h \ge 4\). These sum to 151, which equals the printed total. Lab 1 prints only the total, not the count at each level, so the comparison is made at the total: the printed 151 compactions are at most the sum of the level bounds, and here the two are equal. The bounds are the same for every stream, and the count 151 depends only on \(n\) and \(\varepsilon\), because a buffer is compacted when it reaches \(k_h\) items, and the number of items pushed into each level depends only on \(n\).
E3 · Changing epsilon
Lab 1 stores 500 items for \(\varepsilon = 1/20\) and 220 for \(\varepsilon = 1/10\). Explain the direction of this change from the capacities.
Solution
The capacity \(k_h = 2\lceil (h+1)(h+2)/(2\varepsilon) \rceil\) decreases as \(\varepsilon\) increases. At \(\varepsilon = 1/10\) the capacities are 20, 60 and 120, and at \(\varepsilon = 1/20\) they are 40, 120 and 240. Smaller capacities give a smaller memory bound \(\sum_h (k_h - 1)\) in Corollary 2.6. The stored counts 500 and 220 are the lab's values on one stream, and the lab does not measure this trend on other streams. The bound \(E \le \varepsilon n\) is looser when \(\varepsilon\) is larger, so the trade is between memory and error.
Research
R1 · Why the capacities must grow with the level
Suppose every level had the same capacity \(k\). Using Theorem 2.2(b), bound \(E/n\) in terms of \(k\) and \(n\), and explain why this bound does not give \(E \le \varepsilon n\) for all \(n\).
Solution
Levels that can be nonempty satisfy \(2^h \le n\), so there are at most \(\lfloor \log_2 n \rfloor + 1\) of them (Corollary 2.6). Each level contributes \(C_h 2^h \le n/k\), so \(E/n \le (\lfloor \log_2 n \rfloor + 1)/k\). For a fixed \(k\), this bound grows without limit as \(n\) grows, while \(E \le \varepsilon n\) needs \(E/n\) to stay at or below \(\varepsilon\). With level-dependent capacities, the contributions are at most \(\varepsilon n/((h+1)(h+2))\) for each level, and their sum over the levels that can be nonempty is at most \(\varepsilon n\) by Lemma 2.3, since every partial sum is below 1.
R2 · Keeping the odd positions
Suppose a compaction kept the 1st, 3rd, \(\ldots\) items instead of the 2nd, 4th, \(\ldots\). Show that each compaction still changes the weighted count by at most \(2^h\), and say what changes in the signs of Theorem 2.4.
Solution
With the odd positions kept, the number kept at most \(v\) is \(\lceil c/2 \rceil\). The change is \(2^h(2\lceil c/2 \rceil - c)\), and \(2\lceil c/2 \rceil - c\) is 0 when \(c\) is even and \(+1\) when \(c\) is odd. So the change lies in \(\{0, 2^h\}\), and each compaction still moves the count by at most \(2^h\). The sign reverses: \(0 \le \hat R(v) - R(v) \le E\) and \(0 \le \hat R^-(v) - R^-(v) \le E\). The guarantee still holds with the same bound \(\varepsilon n\), by the argument of Theorem 2.5 with the signs of the error changed. The upper count: \(R(v) \ge \hat R(v) - E \ge W_{j^*} - E \ge qn - E \ge qn - \varepsilon n\). The lower count: \(R^-(v) \le \hat R^-(v) \le qn\), where the second inequality is the lower-count step of Theorem 2.5's proof, which uses only the stored weights and not the sign of the error.
R3 · The memory bound in Lab 1
For \(\varepsilon = 1/20\) and \(n = 5000\), compute the bound of Corollary 2.6 exactly, and compare it with the 500 items Lab 1 stores.
Solution
Here \(\lfloor \log_2 5000 \rfloor = 12\), so the levels run from 0 to 12. With \(\varepsilon = 1/20\), \(k_h = 20(h+1)(h+2)\). The bound is \[ \sum_{h=0}^{12} \bigl(20(h+1)(h+2) - 1\bigr) = 20 \sum_{m=1}^{13} m(m+1) - 13 = 20 \cdot 910 - 13 = 18187. \] The lab stores 500, which is well below the bound. The stored count depends only on \(n\) and \(\varepsilon\) (see E2), so it is 500 for every stream of 5000 values at \(\varepsilon = 1/20\), and it is not the bound.
