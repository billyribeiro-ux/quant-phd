21: A monitoring system sees returns one at a time and cannot keep every past value. It still needs the mean and the variance of the stream so far, updated in constant work for each new value. Definition 1.1 needs the mean before the squared deviations, so computing it from the definition takes two passes over the data. The naive one-pass version, which takes the difference of two running sums, can lose digits when the values are a large constant plus a small spread. This lesson states the one-pass update, proves it correct by induction on the number of values, and tests it on a stream where the naive formula fails.
22: 1 The mean, the sum of squared deviations and the update
23: A stream is a sequence of real numbers \(x_1, x_2, \ldots\) that arrives one value at a time. A statistic is online when each new value is absorbed into a fixed, small state (a count, a mean, a sum) and the earlier values are not read again. The two-pass method, by contrast, reads all the values to compute the mean, then reads them again for the squared deviations, so it needs every value to be stored.
24: Definition 1.1 (mean, sum of squared deviations, sample variance)
25: For an integer \(n \ge 1\) and real numbers \(x_1, \ldots, x_n\), the mean is \(\bar x_n = \frac{1}{n}\sum_{i=1}^{n} x_i\), and the sum of squared deviations is \(S_n = \sum_{i=1}^{n} (x_i - \bar x_n)^2\). For \(n \ge 2\), the sample variance is \(s_n^2 = S_n/(n-1)\), and the population variance is \(\sigma_n^2 = S_n/n\). The population form divides by the number of values; the sample form divides by one fewer, which is the correction for estimating the mean from the same values.
26: Definition 1.2 (Welford's update)
27: Welford's online mean and variance is the recursion
28: \[ M_1 = x_1, \qquad S_1 = 0, \]
29: and, for \(n \ge 2\),
30: \[ M_n = M_{n-1} + \frac{x_n - M_{n-1}}{n}, \qquad S_n = S_{n-1} + (x_n - M_{n-1})(x_n - M_n). \]
31: The state after \(n\) values is the triple \((n, M_n, S_n)\). The sample variance is read off as \(S_n/(n-1)\) and the population variance as \(S_n/n\).
32: Lemma 1.3 (sum of squares identity)
33: Hypotheses. (1) \(n \ge 1\) is an integer. (2) \(x_1, \ldots, x_n\) are real numbers. (3) Arithmetic is exact, as in the real numbers. The lemma: \(\sum_{i=1}^{n}(x_i - \bar x_n)^2 = \sum_{i=1}^{n} x_i^2 - n\,\bar x_n^2\).
34: Proof
35: For any real \(m\), expanding the square gives \(\sum_i (x_i - m)^2 = \sum_i x_i^2 - 2m\sum_i x_i + n m^2\). By definition \(\sum_i x_i = n\bar x_n\). Put \(m = \bar x_n\): the middle term is \(-2\bar x_n \cdot n\bar x_n\) and the last is \(n\bar x_n^2\), so their sum is \(-n\bar x_n^2\). This gives the identity.
36: 2 Proof that the update is correct
37: Theorem 2.1 (one step of the update)
38: Hypotheses. (1) \(n \ge 2\) is an integer. (2) \(x_1, \ldots, x_n\) are real numbers. (3) Arithmetic is exact. (4) \(M_{n-1} = \bar x_{n-1}\) and \(S_{n-1} = \sum_{i=1}^{n-1}(x_i - \bar x_{n-1})^2\), which is the claim for \(n-1\) values. Under (1) to (4), the recursion of Definition 1.2 gives \(M_n = \bar x_n\) and \(S_n = \sum_{i=1}^{n}(x_i - \bar x_n)^2\).
39: Proof
40: The mean. Multiplying the update of \(M\) by \(n\) gives \(nM_n = nM_{n-1} + x_n - M_{n-1} = (n-1)M_{n-1} + x_n\). By hypothesis (4), \((n-1)M_{n-1} = \sum_{i=1}^{n-1} x_i\), so \(nM_n = \sum_{i=1}^{n} x_i\) and \(M_n = \bar x_n\).
41: The sum of squares. Write \(d = x_n - M_{n-1}\). Then \(M_n = M_{n-1} + d/n\), so \(x_n - M_n = d - d/n = d(n-1)/n\). The update adds \(d(x_n - M_n) = d^2(n-1)/n\) to \(S_{n-1}\). It remains to show that the true sums of squares differ by this amount. Lemma 1.3 applies to the first \(n\) values and to the first \(n-1\) values (with mean \(M_{n-1}\), by hypothesis (4)), so
42: \[ S_n^{\text{true}} - S_{n-1}^{\text{true}} = \Bigl(\sum_{i=1}^{n} x_i^2 - n\,M_n^2\Bigr) - \Bigl(\sum_{i=1}^{n-1} x_i^2 - (n-1)M_{n-1}^2\Bigr) = x_n^2 - nM_n^2 + (n-1)M_{n-1}^2. \]
43: Expand \(nM_n^2 = n\bigl(M_{n-1} + d/n\bigr)^2 = nM_{n-1}^2 + 2dM_{n-1} + d^2/n\). The difference becomes \(x_n^2 - M_{n-1}^2 - 2dM_{n-1} - d^2/n\). Since \(x_n = M_{n-1} + d\), we have \(x_n^2 - M_{n-1}^2 - 2dM_{n-1} = (M_{n-1} + d)^2 - M_{n-1}^2 - 2dM_{n-1} = d^2\). So the difference is \(d^2 - d^2/n = d^2(n-1)/n\), which is the amount the update adds. Hypothesis (4) says \(S_{n-1}\) is the true value, so \(S_n\) from the recursion is the true \(\sum_{i=1}^{n}(x_i - \bar x_n)^2\).
44: Theorem 2.2 (Welford's update is correct)
45: Hypotheses. (1) \(n \ge 1\) is an integer. (2) \(x_1, x_2, \ldots\) are real numbers. (3) Arithmetic is exact. The claim: for every \(n \ge 1\), the recursion of Definition 1.2 gives \(M_n = \bar x_n\) and \(S_n = \sum_{i=1}^{n}(x_i - \bar x_n)^2\).
46: Proof
47: Induction on \(n\), in the form of Theorem 1.2 of M1 Lesson 6 ( proof by induction ). Base case, \(n = 1\). \(M_1 = x_1 = \bar x_1\) by definition, and \(S_1 = 0 = (x_1 - x_1)^2 = \sum_{i=1}^{1}(x_i - \bar x_1)^2\). Inductive step. Let \(n \ge 2\) and assume the claim for \(n-1\). That is hypothesis (4) of Theorem 2.1, and Theorem 2.1 gives the claim for \(n\). By induction the claim holds for every \(n \ge 1\).
48: Corollary 2.3 (variance estimates and operation count)
49: Hypotheses. (1) The stream is as in Theorem 2.2. (2) Arithmetic is exact. Under these, for \(n \ge 2\) the sample variance is \(s_n^2 = S_n/(n-1)\) and the population variance is \(\sigma_n^2 = S_n/n\). Each update of the pair \((M, S)\) uses six arithmetic operations and does not depend on \(n\). The state is the three numbers \(n\), \(M_n\), \(S_n\), and no earlier value is kept.
50: Proof
51: The two variance formulas are Definition 1.1 with \(S_n\) from Theorem 2.2. For the count, one update computes \(d = x_n - M_{n-1}\) (one subtraction), \(d/n\) (one division), \(M_{n-1} + d/n\) (one addition), \(x_n - M_n\) (one subtraction), \(d \cdot (x_n - M_n)\) (one multiplication) and \(S_{n-1} + \cdot\) (one addition). That is six operations, with no loop over earlier values. The constant \(c = 6\) satisfies the bound \(\text{operations} \le c\) for every \(n\), so the update is \(O(1)\) in \(n\) in the sense of Lesson 1. The count is a count of operations, not a measure of time. The space is the three stored numbers, and the update reads only \(x_n\) and that state.
52: Theorem 2.2 is an identity between real numbers. The proof uses only the algebra above, and the six-operation count is what makes the update constant in \(n\). Floating-point arithmetic stores each number with a fixed number of binary digits and rounds each result to a number it can store. Python floats are double precision, with a 53-bit significand ( sys.float_info.mant_dig is 53 in CPython 3.14, the version the labs use). Neither result says how close a floating-point computation stays to the real value, which is the subject of Section 3 and of Lab 1.
53: Lab 1 · Welford against the two-pass and naive variance, at three offsets
54: The lab prints the values for the following claims, which are read off its output: at offset 0 each of the three relative errors is below \(10^{-14}\), and the two-pass formula is the most accurate at each of the three offsets printed. As the offset grows, the naive formula's relative error rises from about \(7 \times 10^{-15}\) to \(1\), and the naive estimate is exactly zero at offset \(10^9\). Welford's relative error also rises with the offset, but stays below the naive error at each of the three offsets. The reference is an exact \(\texttt{Fraction}\) variance of the same float values. Each estimate is printed in scientific notation with six digits after the decimal point, and each relative error, \(|\text{estimate} - \text{exact}|/\text{exact}\), with three digits.
55: """CS2 L09 lab 1: Welford's one-pass update against two-pass and naive variance, on streams with a large offset.
56: Claim checked: for the same stream of n = 2000 values, the sample variance from Welford's update, from the
57: two-pass formula and from the naive sum-of-squares formula is compared with an exact Fraction reference.
58: The stream is offset + u, where u is uniform on [0, 1) from random.Random(SEED). The offset is the
59: variable under test: 0, 1e6 and 1e9. SIMULATED data, not market data.
60: Each estimate is printed in scientific notation with six digits after the decimal point. Relative error is
61: |estimate - exact| / exact, printed in scientific notation with three digits after the decimal point.
62: Standard library only.
63: No randomness outside the seeded generator and no network access.
64: """
65: from __future__ import annotations
66: import random
67: from fractions import Fraction
68: N = 2000
69: SEED = 90
70: OFFSETS = (0.0, 1e6, 1e9)
71: def stream(offset: float) -> list[float]:
72: """Return N values offset + u, with u drawn uniformly from [0, 1) by a generator seeded with SEED."""
73: rng = random.Random(SEED)
74: return [offset + rng.random() for _ in range(N)]
75: def welford_variance(xs: list[float]) -> float:
76: """One pass: keep the count, the running mean and the running sum of squared deviations."""
77: count = 0
78: mean = 0.0
79: sum_sq_dev = 0.0
80: for x in xs:
81: count += 1
82: delta = x - mean
83: mean += delta / count
84: sum_sq_dev += delta * (x - mean)
85: return sum_sq_dev / (count - 1)
86: def two_pass_variance(xs: list[float]) -> float:
87: """Two passes: the mean first, then the sum of squared deviations from that mean."""
88: mean = sum(xs) / len(xs)
89: return sum((x - mean) ** 2 for x in xs) / (len(xs) - 1)
90: def naive_variance(xs: list[float]) -> float:
91: """One pass with running sums: (sum of x squared minus (sum of x)^2 / n) / (n - 1)."""
92: total = 0.0
93: total_sq = 0.0
94: for x in xs:
95: total += x
96: total_sq += x * x
97: n = len(xs)
98: return (total_sq - total * total / n) / (n - 1)
99: def exact_variance(xs: list[float]) -> Fraction:
100: """The sample variance of the float values in exact Fraction arithmetic (each float converts exactly)."""
101: values = [Fraction(x) for x in xs]
102: n = len(values)
103: mean = sum(values, Fraction(0)) / n
104: return sum(((x - mean) ** 2 for x in values), Fraction(0)) / (n - 1)
105: def relative_error(estimate: float, exact: Fraction) -> float:
106: """Return |estimate - exact| / exact, computed in exact arithmetic and returned as a float."""
107: return float(abs(Fraction(estimate) - exact) / exact)
108: def main() -> None:
109: methods = (("Welford", welford_variance), ("two-pass", two_pass_variance), ("naive", naive_variance))
110: for offset in OFFSETS:
111: xs = stream(offset)
112: exact = exact_variance(xs)
113: print(f"offset {offset!r}: exact sample variance {float(exact):.6f}")
114: for name, method in methods:
115: estimate = method(xs)
116: print(f" {name:<9} estimate {estimate:.6e} relative error {relative_error(estimate, exact):.3e}")
117: main()
118: offset 0.0: exact sample variance 0.087281
119: Welford estimate 8.728110e-02 relative error 9.258e-16
120: two-pass estimate 8.728110e-02 relative error 2.819e-17
121: naive estimate 8.728110e-02 relative error 7.286e-15
122: offset 1000000.0: exact sample variance 0.087281
123: Welford estimate 8.728110e-02 relative error 8.852e-11
124: two-pass estimate 8.728110e-02 relative error 4.357e-17
125: naive estimate 8.604302e-02 relative error 1.418e-02
126: offset 1000000000.0: exact sample variance 0.087281
127: Welford estimate 8.728109e-02 relative error 7.449e-08
128: two-pass estimate 8.728110e-02 relative error 1.269e-14
129: naive estimate 0.000000e+00 relative error 1.000e+00
130: Every line is one method at one offset on the same 2000 values, which are the offset plus a seeded uniform draw. SIMULATED data, not market data. The estimate column prints each method's variance. The naive estimate prints as 0.000000e+00 at offset \(10^9\) and as 8.604302e-02 at offset \(10^6\). The exact variance is 0.087281 to six digits at all three offsets, so the spread is the same to six digits and only the offset changes. The naive formula is correct in exact arithmetic (Lemma 1.3), and it fails here because its running sum of squares is about \(2 \times 10^{21}\) at offset \(10^9\) (unrounded, \(2.0000000020 \times 10^{21}\)), while the true sum of squared deviations is about 174.5 (unrounded, \((n-1)s^2 = 1999 \times 0.08728110093 = 174.4749\)). Doubles near \(2 \times 10^{21}\) are spaced \(2^{18} = 262144\) apart (Python's math.ulp(2e21) returns 262144.0), while the sum of squared deviations is about 174.5. The rounding error of the sums is therefore larger than the quantity being estimated. Welford's error rises from \(9.26 \times 10^{-16}\) at offset 0 to \(7.45 \times 10^{-8}\) at offset \(10^9\), so this update is not exact in floating point either. The lab shows the three offsets of one stream and one seed. It does not show that the rise continues beyond \(10^9\), that the ordering holds on other streams, or that any method is stable in general.
131: 3 Where the canon breaks
132: The proofs assume exact arithmetic. Theorem 2.2 holds for real numbers. In double precision each subtraction, division and multiplication rounds. Lab 1 measures the effect on one stream: Welford's relative error is \(7.45 \times 10^{-8}\) at offset \(10^9\), against \(1.27 \times 10^{-14}\) for the two-pass formula at the same offset. A claim that the update is "stable" needs such a measurement, and this proof does not supply one.
133: The naive formula is an exact identity that fails in floating point. Lemma 1.3 makes \(\sum x_i^2 - n\bar x_n^2\) equal to \(S_n\) for real numbers. At offset \(10^9\) the two terms are about \(2 \times 10^{21}\), where doubles are \(2^{18} = 262144\) apart, while \(S_n = (n-1)s^2 \approx 174.5\) on this stream. The rounding error of the terms is therefore far larger than \(S_n\), and on this stream the computed value is exactly \(0.0\).
134: The variance needs at least two values. The sample form \(S_n/(n-1)\) divides by zero at \(n = 1\). Welford's \(S_1 = 0\) is well defined, but the variance is not, so any query of \(s^2\) before the second value is an error and must not return \(0\).
135: 4 Misconceptions
136: “The sum-of-squares formula is a correct algorithm at any scale, because it is an exact identity.”
137: Lemma 1.3 is an identity for real numbers, and the algorithm computes it in floating point. Lab 1 at offset \(10^9\) prints a naive estimate of 0.000000e+00 for a stream whose true sample variance is \(0.0872811\), a relative error of \(1.000\).
138: “Welford's update gives the exact variance in floating point, because its proof is exact.”
139: Theorem 2.2 assumes exact arithmetic (hypothesis 3). On the lab stream its relative error rises from \(9.26 \times 10^{-16}\) at offset 0 to \(7.45 \times 10^{-8}\) at offset \(10^9\). Its relative error is smaller than the naive formula's by a factor of about 8 at offset 0, about \(1.6 \times 10^{8}\) at offset \(10^6\) and about \(1.3 \times 10^{7}\) at offset \(10^9\). These factors are ratios of the unrounded relative errors of the naive and Welford estimates (Lab 1 output, printed to three digits): \(7.87\), \(1.60 \times 10^{8}\) and \(1.34 \times 10^{7}\) at offsets 0, \(10^6\) and \(10^9\). The printed values reproduce them to two digits. The update is not exact.
140: “Dividing \(S_n\) by \(n\) gives the sample variance.”
141: Definition 1.1 divides by \(n-1\) for the sample variance and by \(n\) for the population variance. For the values 1, 2, 3 the sum of squared deviations is \(S_3 = 2\), so the sample variance is \(2/2 = 1\) and the population variance is \(2/3\). Using \(n\) in place of \(n-1\) underestimates the sample variance by the factor \((n-1)/n\).

143: Every problem has a full worked solution. Attempt each one before opening it.
144: Mechanics
145: M1 · Mean and sample variance by hand
146: For the values 2, 4, 4, 4, 5, 5, 7, 9, find the mean, \(S_8\), the sample variance and the population variance.
147: Solution
148: The sum is 40, so \(\bar x_8 = 40/8 = 5\). The deviations are \(-3, -1, -1, -1, 0, 0, 2, 4\), with squares \(9, 1, 1, 1, 0, 0, 4, 16\) that add to \(S_8 = 32\). The sample variance is \(32/7 \approx 4.5714\) and the population variance is \(32/8 = 4\).
149: M2 · Run the recursion on 1, 2, 3
150: Apply Definition 1.2 to \(x_1 = 1\), \(x_2 = 2\), \(x_3 = 3\). Give \(M_3\) and \(S_3\), and check \(S_3\) against Definition 1.1.
151: Solution
152: Start with \(M_1 = 1\), \(S_1 = 0\). For \(n = 2\): \(M_2 = 1 + (2-1)/2 = 1.5\), and \(S_2 = 0 + (2-1)(2-1.5) = 0.5\). For \(n = 3\): \(M_3 = 1.5 + (3-1.5)/3 = 2\), and \(S_3 = 0.5 + (3-1.5)(3-2) = 2\). Directly, \((1-2)^2 + (2-2)^2 + (3-2)^2 = 2\), which agrees.
153: M3 · A zero-one stream
154: Run the recursion on the values 0, 1, 0, 1. Give \(S_4\) and the population variance, and check the population variance against \(p(1-p)\), where \(p\) is the fraction of ones.
155: Solution
156: \(M_1 = 0\), \(S_1 = 0\). Value 1: \(M_2 = 0 + 1/2 = 0.5\), \(S_2 = 0 + 1 \cdot 0.5 = 0.5\). Value 0: \(d = -0.5\), \(M_3 = 0.5 - 0.5/3 = 1/3\), \(S_3 = 0.5 + (-0.5)(0 - 1/3) = 2/3\). Value 1: \(d = 2/3\), \(M_4 = 1/3 + (2/3)/4 = 1/2\), \(S_4 = 2/3 + (2/3)(1 - 1/2) = 1\). The population variance is \(S_4/4 = 1/4\). With \(p = 1/2\), \(p(1-p) = 1/4\), which agrees.
157: Proof
158: P1 · The two-value case
159: Show that for \(n = 2\) and any real \(x_1, x_2\), the recursion gives \(S_2 = (x_1 - x_2)^2/2\), and check this against Definition 1.1.
160: Solution
161: Let \(d = x_2 - x_1\). Then \(M_2 = x_1 + d/2 = (x_1 + x_2)/2\), and \(x_2 - M_2 = d/2\). The update gives \(S_2 = 0 + d \cdot d/2 = d^2/2 = (x_1 - x_2)^2/2\). Directly, the mean is \((x_1 + x_2)/2\), and the two squared deviations are each \((x_1 - x_2)^2/4\), which add to \((x_1 - x_2)^2/2\). The two agree.
162: P2 · A constant stream
163: Show that if \(x_i = c\) for every \(i\), then \(M_n = c\) and \(S_n = 0\) for every \(n \ge 1\), using the recursion and Theorem 2.2.
164: Solution
165: \(M_1 = c\) and \(S_1 = 0\). For \(n \ge 2\), \(d = x_n - M_{n-1} = c - c = 0\), so \(M_n = M_{n-1} = c\) and \(S_n = S_{n-1} + 0 \cdot (c - c) = S_{n-1}\). By induction \(S_n = 0\) for all \(n\). Theorem 2.2 then says \(S_n = \sum (x_i - \bar x_n)^2 = \sum (c - c)^2 = 0\), which agrees.
166: P3 · Merging two blocks
167: Let block A have \(a\) values with mean \(m_A\) and sum of squared deviations \(S_A\), and block B have \(b\) values with mean \(m_B\) and sum of squared deviations \(S_B\). Show that the combined sum of squared deviations is \(S = S_A + S_B + (m_B - m_A)^2 \, ab/(a+b)\). State every hypothesis used.
168: Solution
169: Hypotheses. \(a, b \ge 1\), the values are real, and arithmetic is exact. Let \(m = (a m_A + b m_B)/(a+b)\) be the combined mean and \(\Delta = m_B - m_A\). For block A, \(\sum_A (x - m)^2 = \sum_A (x - m_A)^2 + a(m_A - m)^2\), because the cross term \(2(m_A - m)\sum_A (x - m_A)\) is zero. The same holds for B. Now \(m_A - m = -b\Delta/(a+b)\) and \(m_B - m = a\Delta/(a+b)\). So \(a(m_A - m)^2 + b(m_B - m)^2 = (a b^2 + b a^2)\Delta^2/(a+b)^2 = ab\Delta^2/(a+b)\). Adding \(S_A + S_B\) gives the formula.
170: Empirical
171: E1 · Which estimate is zero, and why
172: In Lab 1 at offset \(10^9\), the naive estimate is exactly zero. Explain the mechanism using the magnitudes of the two running sums, and say why the lab's exact reference is not affected.
173: Solution
174: The running sums are \(\sum x_i\) and \(\sum x_i^2\). For 2000 values near \(10^9\), the second sum is about \(2 \times 10^{21}\), and doubles in that range are spaced \(2^{18} = 262144\) apart. The true sum of squared deviations is about \(174.5\), far below that spacing, so the difference of the two sums is dominated by rounding. The computed difference happens to be exactly zero on this stream, and the lab prints it as 0.000000e+00. The reference uses \(\texttt{Fraction}\) arithmetic on the same float values, so it is not affected by rounding and gives \(0.0872811\).
175: E2 · The absolute error at offset zero
176: The lab prints Welford's relative error at offset 0 as \(9.26 \times 10^{-16}\), and the exact sample variance as 0.087281. Compute Welford's absolute error at offset 0, to two significant digits.
177: Solution
178: The unrounded exact variance is 0.08728110122738864, and the unrounded relative error is \(9.25811790803366 \times 10^{-16}\). Their product is \(8.08 \times 10^{-17}\), so the absolute error is about \(8.1 \times 10^{-17}\). The product is taken from the unrounded values, and the relative error printed as \(9.26 \times 10^{-16}\) gives the same result to two significant digits.
179: E3 · Why the two-pass error is smallest at offset zero
180: From the lab output, the two-pass relative error at offset 0 is \(2.82 \times 10^{-17}\), and the Welford error is \(9.26 \times 10^{-16}\). Name one reason the two-pass formula can be more accurate than Welford's update on the same stream, and say what the lab does not show.
181: Solution
182: One candidate mechanism: the two-pass formula computes the mean once and then squares deviations from that fixed mean, so it has no running mean that is updated with a rounded division at each value. Welford's update does update a running mean at each of the 2000 steps, and those rounding errors can enter the later deviations. This is a hypothesis about the mechanism. Lab 1 shows the ordering on one stream and does not test the mechanism, and it does not show that the ordering holds on other streams or at other sizes.
183: Research
184: R1 · Weighted updates
185: Let each value \(x_i\) carry a positive weight \(w_i\), and let the weighted mean be \(\sum w_i x_i / \sum w_i\). Derive the analogue of Definition 1.2 that keeps the running weight \(W_n = \sum_{i \le n} w_i\), and state its hypotheses.
186: Solution
187: Hypotheses. (1) \(w_i > 0\). (2) The values are real. (3) Arithmetic is exact. Put \(W_1 = w_1\), \(M_1 = x_1\), \(S_1 = 0\). For \(n \ge 2\): \(W_n = W_{n-1} + w_n\), \(M_n = M_{n-1} + (w_n/W_n)(x_n - M_{n-1})\), and \(S_n = S_{n-1} + w_n (x_n - M_{n-1})(x_n - M_n)\). Let \(d = x_n - M_{n-1}\), so that \(M_n - M_{n-1} = w_n d/W_n\) and \(x_n - M_n = W_{n-1} d/W_n\).
188: The mean. Multiply the update of \(M\) by \(W_n\): \(W_n M_n = W_n M_{n-1} + w_n x_n - w_n M_{n-1} = W_{n-1} M_{n-1} + w_n x_n\). Induction gives \(W_{n-1} M_{n-1} = \sum_{i\lt n} w_i x_i\), so \(M_n = \sum_{i \le n} w_i x_i / W_n\).
189: The sum of squares. Let \(\mathrm{SS}_n = \sum_{i \le n} w_i (x_i - M_n)^2\). We show \(S_n = \mathrm{SS}_n\) by induction. The base case \(\mathrm{SS}_1 = 0 = S_1\) holds. Write \(\mathrm{SS}_n - \mathrm{SS}_{n-1} = w_n (x_n - M_n)^2 + \sum_{i\lt n} w_i \bigl[(x_i - M_n)^2 - (x_i - M_{n-1})^2\bigr]\). The bracket equals \((M_{n-1} - M_n)(2x_i - M_n - M_{n-1})\). Using \(\sum_{i\lt n} w_i = W_{n-1}\) and \(\sum_{i\lt n} w_i x_i = W_{n-1} M_{n-1}\), the sum over \(i < n\) is \((M_{n-1} - M_n)\,W_{n-1}(M_{n-1} - M_n) = W_{n-1}(M_n - M_{n-1})^2\). Therefore \(\mathrm{SS}_n - \mathrm{SS}_{n-1} = w_n W_{n-1}^2 d^2/W_n^2 + W_{n-1} w_n^2 d^2/W_n^2 = w_n W_{n-1} d^2 (W_{n-1} + w_n)/W_n^2 = w_n W_{n-1} d^2/W_n\). The update adds \(w_n d (x_n - M_n) = w_n W_{n-1} d^2/W_n\) to \(S_{n-1}\), which is the same amount. Since \(S_{n-1} = \mathrm{SS}_{n-1}\) by hypothesis of the induction, \(S_n = \mathrm{SS}_n\).
190: Check on one example: \(x = (1, 2)\) with weights \((1, 3)\) gives \(M_2 = 1 + (3/4)\cdot 1 = 1.75\) and \(S_2 = 0 + 3 \cdot 1 \cdot 0.25 = 0.75\), which equals \(\sum w_i(x_i - M_2)^2 = 1 \cdot 0.5625 + 3 \cdot 0.0625 = 0.75\).
191: R2 · Why the proof is not a bound on error
192: Theorem 2.2 is an identity, and Lab 1 shows errors that rise across its three offsets. Explain in two or three sentences why no identity of this kind can bound the floating-point error of the update.
193: Solution
194: Theorem 2.2 is an identity for exact real numbers, and it says nothing about the value of a rounded computation unless the rounding is modelled. A bound on floating-point error needs an explicit model of each rounding step (for example, that each operation returns the exact result times one factor within \(1 \pm u\)) and a propagation argument through the recursion. Theorem 2.2 supplies neither, so on this page it establishes correctness and does not establish accuracy.
195: R3 · Population variance of a zero-one stream
196: For a stream of \(n\) values, each 0 or 1, with \(k\) ones, find the population variance \(\sigma_n^2\) in terms of \(p = k/n\), and compute it for \(n = 10\), \(k = 4\).
197: Solution
198: The mean is \(\bar x_n = p\). Each value contributes \((1 - p)^2\) if it is 1 and \(p^2\) if it is 0, so \(S_n = k(1-p)^2 + (n-k)p^2\). With \(k = np\), this is \(np(1-p)^2 + n(1-p)p^2 = np(1-p)\,[(1-p) + p] = np(1-p)\). Dividing by \(n\) gives \(\sigma_n^2 = p(1-p)\). For \(n = 10\), \(k = 4\), \(p = 0.4\) and \(\sigma_n^2 = 0.4 \times 0.6 = 0.24\). Direct check: \(S_{10} = 4(0.6)^2 + 6(0.4)^2 = 1.44 + 0.96 = 2.4\), and \(2.4/10 = 0.24\).
