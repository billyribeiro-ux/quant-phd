21: The data structures in this unit are judged by how their operation counts grow with the number of items \(n\). This lesson fixes what such a bound means. It defines big-O notation by inequalities with witnesses, proves the bounds that the later lessons use, and counts the operations of a loop and of a nested loop in Lab 1. The lab measures no time, so its numbers do not depend on the machine it runs on.
22: 1 Operation counts and the big-O definition
23: A cost model states which operations are counted. In this unit one counted operation is one comparison of two values, one assignment of a value into a slot, or one inner step of a loop. An array is a sequence of slots numbered \(0, 1, \dots, n - 1\) and read or written by its index. The Python list used in the labs is an array in this sense. A count is a function of the input size \(n\), and the question of this lesson is how fast that function grows.
24: Definition 1.1 (big-O notation)
25: Let \(f\) and \(g\) be functions from the positive integers to the non-negative reals, with \(g(n) > 0\) for every \(n\). We write \(f \in O(g)\), read "\(f\) is big-O of \(g\)", when there exist a constant \(c > 0\) and an integer \(n_0 \ge 1\) such that \[f(n) \le c\, g(n)\] for every integer \(n \ge n_0\). The constant \(c\) is the witness of the constant factor and \(n_0\) is the threshold. The big-O notation above is this definition, and it uses no limit.
26: Proposition 1.2 (a linear count)
27: Assume \(a\) and \(b\) are non-negative reals, \(n\) is an integer with \(n \ge 1\), and the count is \(f(n) = a n + b\). Then \(f \in O(n)\), with witness \(c = a + b + 1\) and threshold \(n_0 = 1\).
28: Proof
29: Let \(n \ge 1\). Then \(b \le b n\), because \(b \ge 0\) and \(n \ge 1\). So \[a n + b \le a n + b n = (a + b) n\]. Since \(n > 0\), \[(a + b) n \le (a + b + 1) n\]. Hence \(f(n) \le c\, n\) for every \(n \ge 1\), with \(c = a + b + 1 > 0\). \(\blacksquare\)
30: Proposition 1.3 (a quadratic count is not linear)
31: Assume \(n\) ranges over the integers \(n \ge 1\). Then \(n^2 \notin O(n)\): there is no constant \(c > 0\) and no integer \(n_0 \ge 1\) with \(n^2 \le c\, n\) for every \(n \ge n_0\).
32: Proof (by contradiction )
33: Suppose \(c > 0\) and \(n_0 \ge 1\) satisfy \(n^2 \le c\, n\) for every \(n \ge n_0\). Let \[N = \max(n_0, \lfloor c \rfloor + 1)\]. Then \(N \ge n_0\), so \(N^2 \le c N\). But \(\lfloor c \rfloor + 1 > c\), so \(N > c\), and multiplying by \(N > 0\) gives \(N^2 > c N\). This contradicts \(N^2 \le c N\), so no such \(c\) and \(n_0\) exist. \(\blacksquare\)
34: Proposition 1.4 (the sum of the first integers)
35: For every integer \(n \ge 1\), \[\sum_{i=0}^{n-1} i = \dfrac{n(n-1)}{2}\].
36: Proof (by induction on \(n\))
37: Base case \(n = 1\): the sum has the single term \(i = 0\), which is \(0\), and \(1 \cdot 0 / 2 = 0\). Inductive step: assume the formula for some \(n \ge 1\). Then \[\sum_{i=0}^{n} i = \sum_{i=0}^{n-1} i + n = \dfrac{n(n-1)}{2} + n = \dfrac{n(n-1) + 2n}{2} = \dfrac{n(n+1)}{2}\], which is the formula for \(n + 1\). \(\blacksquare\)
38: Definition 1.5 (maximum scan)
39: The maximum scan of a list \(x_0, \dots, x_{n-1}\) with \(n \ge 1\) sets best to \(x_0\), then for each later element \(x\) makes one comparison \(x > \mathrm{best}\) and replaces best by \(x\) when the comparison holds. The scan returns best and the number of comparisons made.
40: Proposition 1.6 (the maximum scan)
41: Assume a list of \(n \ge 1\) values and the scan of Definition 1.5, where a comparison is the single test \(x > \mathrm{best}\). Then the scan returns the largest value of the list, and it makes exactly \(n - 1\) comparisons. Hence the count is in \(O(n)\), with witness \(c = 1\) and threshold \(n_0 = 1\).
42: Proof
43: Correctness, by induction on \(k\) for \(1 \le k \le n\): after the first \(k\) values have been read, best is their largest. For \(k = 1\), best is \(x_0\). If it holds for \(k\), then the comparison for \(x_k\) sets best to the larger of the old best and \(x_k\), which is the largest of the first \(k + 1\) values. So after all \(n\) values, best is the largest. Counting: the loop body runs once for each of the \(n - 1\) values after the first, and each run makes exactly one comparison. So the count is \(n - 1\). Since \(n - 1 \le 1 \cdot n\) for every \(n \ge 1\), Definition 1.1 holds with \(c = 1\) and \(n_0 = 1\). \(\blacksquare\)
44: Proposition 1.7 (a nested loop over ordered pairs)
45: Assume \(n\) is an integer with \(n \ge 1\) and a nested loop runs its outer index \(i\) over \(0, \dots, n - 1\) and, for each \(i\), its inner index \(j\) over \(0, \dots, n - 1\), with one step per inner iteration. Then the loop performs \(n \cdot n = n^2\) steps. Hence the count is in \(O(n^2)\), but by Proposition 1.3 it is not in \(O(n)\).
46: Proof
47: The outer loop has \(n\) iterations. Each one runs the inner loop for \(n\) iterations, one step each, so the total is \(n\) times \(n\). The bound \(n^2 \le 1 \cdot n^2\) gives the \(O(n^2)\) statement with \(c = 1\). The statement that the count is not in \(O(n)\) is Proposition 1.3 applied to the same count. \(\blacksquare\)
48: Lab 1 · Operation counts of a scan and of a nested loop
49: Predicted from Propositions 1.6 and 1.7 before running. For \(k = 2, \dots, 10\), the comparison ratio on doubling from \(2^{k-1}\) to \(2^k\) is \[(2^k - 1)/(2^{k-1} - 1) = 2 + 1/(2^{k-1} - 1)\], which falls toward 2 from above. The formula is undefined at \(k = 0\) and \(k = 1\), where the denominator is not positive, so the lab prints no ratio there. The first integer \(n\) with \(n^2 > 1000\, n\) should be \(n = 1001\). 131: 2 Reading a bound: witnesses and thresholds
132: Example 2.1 (a witness that is larger than the function)
133: Let \(f(n) = 3n + 7\). Then \(f \in O(n)\), with witness \(c = 10\) and threshold \(n_0 = 1\). For \(n \ge 1\) we have \(7 \le 7n\), so \(3n + 7 \le 10 n\). The inequality \(f(n) \le n\) fails for every \(n \ge 1\), because \(3n + 7 > n\). The definition asks for \[f(n) \le c\, g(n)\] with some constant \(c\), so the constant \(c\) is what makes the claim true.
134: Remark 2.2 (the threshold)
135: A bound may fail for small \(n\) and hold from a threshold on. For \(n^2\) and \(c = 1000\), the bound \[n^2 \le 1000\, n\] holds for \(n \le 1000\) and fails from \(n = 1001\). Its failure at \(n = 1001\) is the first value in Lab 1. For \(n\) below the threshold the inequality can run either way, so a claim of big-O says nothing about \(n\) below the threshold.
136: Proposition 2.3 (the crossover of a linear constant and a square)
137: For integers \(n \ge 1\), \(1000\, n > n^2\) holds exactly when \(n < 1000\), holds with equality when \(n = 1000\), and fails when \(n > 1000\).
138: Proof
139: Since \(n > 0\), the inequality \(1000\, n > n^2\) is equivalent to \(1000 > n\), and the equality case is \(n = 1000\). \(\blacksquare\)
140: 3 Where the canon breaks
141: Big-O is a statement about a count in a stated model, and it has four limits.
142: A bound is not a time. A count of comparisons and assignments is one model of cost. Two operations with equal counts can take different times on a real machine, and Lab 1 measures none. A claim about time needs a separate model that this lesson does not supply.
143: Constants decide small inputs. By Proposition 2.3, the count \(1000\, n\) exceeds \(n^2\) for every \(n\) from 1 to 999. So for those inputs the linear bound is the larger count, and the asymptotic order does not rank the two methods there.
144: A bound is an upper bound. Proposition 1.2 says \(f \in O(n)\) and says nothing about how small \(f\) is. A bound can be true and far from exact, and a tight count needs its own proof.
145: Memory layout is not counted. The model counts comparisons, assignments and loop steps only. The cost of reading a slot far from the last one read is not in the model, so a count says nothing about that cost.
146: 4 Misconceptions
147: “Big-O measures running time.”
148: Big-O bounds a count in a stated model. Lab 1 counts comparisons and steps and prints no time, and the lab prints counts only, so its output does not depend on the machine. A bound on a count becomes a bound on time only through a separate model that assigns a time to each counted operation.
149: “\(f \in O(g)\) means \(f(n) \le g(n)\) for every \(n\).”
150: Definition 1.1 allows a constant \(c\) and a threshold \(n_0\). Example 2.1 takes \(f(n) = 3n + 7\) and \(g(n) = n\). The inequality \(f(n) \le g(n)\) fails for every \(n \ge 1\), but \(f \in O(g)\) holds with \(c = 10\) and \(n_0 = 1\).
151: “A nested loop always costs quadratic time.”
152: The shape of the loops does not decide the bound, and the count does. A loop of \(n\) iterations whose inner loop always runs for 2 steps makes \(2n\) steps. Proposition 1.2 with \(a = 2\) and \(b = 0\) gives \(2n \in O(n)\). The quadratic count of Proposition 1.7 needs an inner loop whose length grows with \(n\).

155: Mechanics
156: M1 · Witnesses for a linear count
157: Show that \(f(n) = 5n + 3\) is in \(O(n)\). Give one witness pair \((c, n_0)\) with \(c = 8\), and one with \(c = 6\).
158: Solution
159: For \(n \ge 1\), \(3 \le 3n\), so \(5n + 3 \le 8n\). Thus \((c, n_0) = (8, 1)\) works. For \(c = 6\), the inequality \(5n + 3 \le 6n\) is equivalent to \(3 \le n\), so \(n_0 = 3\) works, and it holds for every \(n \ge 3\).
160: M2 · Refuting a witness
161: Show that \[n^2 \le 1000\, n\] fails for every \(n \ge 1001\), so that no threshold \(n_0\) works with \(c = 1000\) for \(g(n) = n\). Name the first failing integer.
162: Solution
163: Dividing by \(n > 0\) turns \[n^2 \le 1000\, n\] into \(n \le 1000\). So the inequality fails at \(n = 1001\), and for every \(n \ge 1001\). Since it holds at \(n = 1000\), the first failing integer is 1001, the value Lab 1 prints.
164: M3 · A triangular loop as a closed form
165: The loop for i in range(n): for j in range(i): runs its inner body once per pair with \(0 \le j < i < n\). Give its step count in closed form and a witness for its big-O bound.
166: Solution
167: The inner loop for a given \(i\) runs \(i\) times, so the total is \(\sum_{i=0}^{n-1} i\). By Proposition 1.4 this is \(n(n-1)/2\). Since \(n(n-1)/2 \le n^2 / 2 \le 1 \cdot n^2\) for \(n \ge 1\), the count is in \(O(n^2)\) with witness \(c = 1\) and threshold \(n_0 = 1\).
168: Proof
169: P1 · The sum of the first odd numbers
170: Prove by induction that \[1 + 3 + \dots + (2n - 1) = n^2\] for every integer \(n \ge 1\).
171: Solution
172: Base case \(n = 1\): the sum is 1, and \(1^2 = 1\). Inductive step: assume the sum to \(n\) terms is \(n^2\). The sum to \(n + 1\) terms adds the term \[2(n + 1) - 1 = 2n + 1\], giving \[n^2 + 2n + 1 = (n + 1)^2\]. This is the formula for \(n + 1\).
173: P2 · Transitivity of the bound
174: Assume \(f \in O(g)\) and \(g \in O(h)\), with \(h(n) > 0\) for every \(n\). Prove that \(f \in O(h)\).
175: Solution
176: Let \(f(n) \le c_1 g(n)\) for \(n \ge n_1\) and \(g(n) \le c_2 h(n)\) for \(n \ge n_2\), with \(c_1, c_2 > 0\). For \(n \ge \max(n_1, n_2)\), \(f(n) \le c_1 g(n) \le c_1 c_2 h(n)\), where the second step uses \(c_1 > 0\). The witness \(c_1 c_2 > 0\) and the threshold \(\max(n_1, n_2)\) satisfy Definition 1.1.
177: P3 · Scan correctness on a single list
178: State the loop invariant (a statement about the variables that holds before each pass of the loop) of the maximum scan of Definition 1.5 and use it to prove that the scan returns the largest value of a list of \(n \ge 1\) values.
179: Solution
180: The invariant is that after the first \(k\) values have been read, best equals the largest of those \(k\) values. It holds for \(k = 1\) because best is the first value. If it holds for \(k\), the comparison for the next value sets best to the larger of the old best and that value, so the invariant holds for \(k + 1\). At \(k = n\) it says that best is the largest value.
181: Empirical
182: E1 · The comparison ratio at the last doubling
183: Lab 1 prints a comparison ratio of 2.0020 for the doubling from \(2^9\) to \(2^{10}\). Compute the exact ratio and state whether 2.0020 is its correct four-decimal value.
184: Solution
185: The counts are \(2^{10} - 1 = 1023\) and \(2^9 - 1 = 511\), so the ratio is \(1023 / 511 = 2 + 1/511\). Since \(1/511\) is about 0.0019569, the ratio is about 2.0019569. To four decimals that is 2.0020, the value Lab 1 prints. The lab computes the counts itself, and this check uses only the two counts it prints.
186: E2 · The pair-step count at \(n = 1024\)
187: Lab 1 prints 1048576 pair steps at \(n = 1024\). Confirm that this equals \(n^2\), and say which proposition makes the count exact.
188: Solution
189: \(1024^2 = 2^{20} = 1\,048\,576\), so the printed count equals \(n^2\). Proposition 1.7 makes the count exact: the outer loop has \(n\) iterations and each runs the inner loop \(n\) times. The lab's count agrees with the formula at every row it prints.
190: E3 · What the check on 1000 values establishes
191: Lab 1 prints "comparisons at most \(1 \cdot n\) for \(n = 1\) to \(1000\): 1000 of 1000". State what this line establishes about the maximum scan, and what it does not.
192: Solution
193: It establishes that the scan's comparison count is at most \(n\) for each of the 1000 values of \(n\) that the lab tests. It does not establish the bound for \(n > 1000\). The bound for every \(n \ge 1\) comes from Proposition 1.6, where the count is exactly \(n - 1 \le n\), not from the check.
194: Research
195: R1 · A linear count that exceeds a quadratic one
196: For which integers \(n \ge 1\) is \(1000\, n\) larger than \(n^2\)? Explain why this matters for choosing between two methods on small inputs.
197: Solution
198: By Proposition 2.3, \(1000\, n > n^2\) exactly for \(1 \le n \le 999\). So for those inputs the method with count \(1000\, n\) makes more steps than the one with count \(n^2\). A method with the better big-O bound can be the slower one on inputs below the crossover, which is one reason the constants of a real implementation are measured separately.
199: R2 · Two counts that bound each other
200: Show that \(f(n) = n\) and \(g(n) = n + 5\) are each big-O of the other.
201: Solution
202: Since \(n \le n + 5\) for every \(n\), \(f \in O(g)\) with \(c = 1\) and \(n_0 = 1\). For \(n \ge 1\), \(n + 5 \le 6n\) because \(5 \le 5n\), so \(g \in O(f)\) with \(c = 6\) and \(n_0 = 1\).
203: R3 · The triangular count is not linear
204: Prove that \(n(n-1)/2 \notin O(n)\).
205: Solution
206: Suppose \(c > 0\) and \(n_0 \ge 1\) satisfy \(n(n-1)/2 \le c\, n\) for every \(n \ge n_0\). Dividing by \(n > 0\) gives \((n - 1)/2 \le c\). Let \(n = \max(n_0, \lfloor 2c \rfloor + 3)\). Then \(n \ge \lfloor 2c \rfloor + 3 > 2c + 2\), so \((n - 1)/2 > c\), a contradiction. Hence no such \(c\) and \(n_0\) exist.
