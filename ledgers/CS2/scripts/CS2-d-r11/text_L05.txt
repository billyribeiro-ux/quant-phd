21: A search makes one comparison per step down a single path, so a taller tree can take more comparisons. Keys inserted in sorted order make a tall tree: each key goes to the right of the one before. This lesson studies a rule that keeps the two sides below every key within one level of each other. It proves in Proposition 2.4 of this lesson that \(n\) keys then give a height of at most \(\log_{\varphi}(n+1)\), where height is defined in Section 1 and \(\varphi = (1 + \sqrt{5})/2\) is the golden ratio. Lab 1 checks the insertion step on 500 seeded keys; it is not proved here.
22: 1 Binary search trees and why height matters
23: A binary search tree stores one key in each node. Every key in the left subtree of a node is smaller than the node's key, and every key in the right subtree is larger. A search starts at the root and compares the key with the node, then goes to the left or right subtree, or stops. The height of a tree is the number of nodes on its longest path from the root down to a leaf, so the empty tree has height 0 and a single node has height 1. The in-order sequence of a tree lists the keys of its left subtree, then its own key, then the keys of its right subtree; in a binary search tree it is the keys in increasing order. A search that ends at a node compares the key with the nodes on one path, so it makes at most as many comparisons as the height. The comparisons are the comparisons of L04's model.
24: Remark 1.1 (sorted insertion makes a path)
25: Insert the keys \(1, 2, \ldots, n\) in that order into an unbalanced binary search tree. The first key is the root. Each later key is larger than every key present, so it goes to the right of its predecessor, and the tree is a path of \(n\) nodes. Its height is \(n\). The argument is an induction on the number of keys: after \(k\) insertions the tree is a path of \(k\) nodes, and the next key extends the path. Lab 1, Part B, prints height 64 for the keys 1 to 64.
26: 2 The AVL rule and the height bound
27: Definition 2.1 (balanced search tree, AVL variant)
28: The balanced search tree is a binary search tree that restructures itself after each change in order to keep its height logarithmic in the number of its keys. This unit uses the AVL variant. For a node, the balance factor is the height of its left subtree minus the height of its right subtree, with the height of an empty subtree equal to 0. An AVL tree is a binary search tree in which every node has balance factor \(-1\), \(0\) or \(1\).
29: Definition 2.2 (the recurrence for N(h))
30: For an integer \(h \ge 0\), let \(N(h)\) be defined by \(N(0) = 0\), \(N(1) = 1\), and \(N(h) = 1 + N(h-1) + N(h-2)\) for \(h \ge 2\). These are recurrence values. Lemma 2.3 shows that every AVL tree of height \(h\) has at least \(N(h)\) nodes; this page does not show that an AVL tree with exactly \(N(h)\) nodes exists for each \(h\). The first values are \(N(0), \ldots, N(7) = 0, 1, 2, 4, 7, 12, 20, 33\), and Lab 1, Part C, computes them.
31: Lemma 2.3 (the recurrence bounds every AVL tree)
32: Let \(h \ge 0\) and let \(\mathcal{A}\) be an AVL tree of height \(h\). Then \(\mathcal{A}\) has at least \(N(h)\) nodes. Also \(N(h)\) is nondecreasing in \(h\).
33: Proof
34: First, \(N\) is nondecreasing. For \(h \ge 2\), \(N(h) - N(h-1) = 1 + N(h-2) \ge 1 > 0\), and \(N(1) = 1 > 0 = N(0)\). Now the bound, by strong induction on \(h\). For \(h = 0\) the tree is empty and has \(0 = N(0)\) nodes. For \(h = 1\) the tree is a single node, which has \(1 = N(1)\) node. Let \(h \ge 2\), and assume the bound for every height below \(h\). Let the root of \(\mathcal{A}\) have subtrees \(L\) and \(R\) with heights \(h_L\) and \(h_R\). The height of the root is \(1 + \max(h_L, h_R) = h\), so one subtree has height \(h - 1\), and the other has height \(h_2\) with \(h - 2 \le h_2 \le h - 1\), because the balance rule gives \(|h_L - h_R| \le 1\). Both subtrees are AVL trees, since each node of a subtree has the same balance factor as in \(\mathcal{A}\). Both heights are below \(h\), so by induction the subtree of height \(h - 1\) has at least \(N(h-1)\) nodes, and the other has at least \(N(h_2) \ge N(h-2)\) nodes, using that \(N\) is nondecreasing. Adding the root gives at least \(1 + N(h-1) + N(h-2) = N(h)\) nodes.
35: Proposition 2.4 (the height bound)
36: Assume the following. (1) \(\mathcal{A}\) is an AVL tree with \(n \ge 0\) nodes and height \(h\). (2) The symbol \(\varphi = (1 + \sqrt{5})/2\) denotes the golden ratio. Then \(\varphi^{h} \le n + 1\), and so \(h \le \log_{\varphi}(n+1) = \log_2(n+1) / \log_2 \varphi\).
37: Proof
38: Let \(M(h) = N(h) + 1\). Then \(M(0) = 1\), \(M(1) = 2\), and for \(h \ge 2\), \(M(h) = M(h-1) + M(h-2)\), because \(N(h) + 1 = 1 + N(h-1) + N(h-2) + 1\). We show \(M(h) \ge \varphi^{h}\) for every \(h \ge 0\). For \(h = 0\) both sides are 1. For \(h = 1\), \(\varphi < 2\) because \(\sqrt{5} < 3\), so \(M(1) = 2 \ge \varphi\). For \(h \ge 2\), assume \(M(h-1) \ge \varphi^{h-1}\) and \(M(h-2) \ge \varphi^{h-2}\). Then \(M(h) \ge \varphi^{h-1} + \varphi^{h-2} = \varphi^{h-2}(\varphi + 1)\). Since \(\varphi^{2} = \varphi + 1\), which follows from \((1 + \sqrt{5})^{2}/4 = (6 + 2\sqrt{5})/4 = (3 + \sqrt{5})/2 = \varphi + 1\), this equals \(\varphi^{h}\).
39: By Lemma 2.3, \(n \ge N(h)\), so \(n + 1 \ge M(h) \ge \varphi^{h}\). Taking \(\log_2\) and dividing by \(\log_2 \varphi > 0\) gives the second form.
40: Remark 2.5 (the constant is not 1)
41: The bound is \(\log_{\varphi}(n+1)\), and \(1 / \log_2 \varphi\) equals 1.440420 to six decimal places, as Lab 1, Part C prints. So the height of an AVL tree can exceed \(\log_2 n\). With two nodes, the tree with root 2 and left child 1 has height 2, and \(\log_2 2 = 1\). Proposition 2.4 gives \(\log_{\varphi} 3 = \ln 3 / \ln \varphi = 2.28\), which is at least 2, so the example is consistent with the bound. Lab 1, Part C, prints this two-node height.
42: 3 Insertion and rotations
43: Insertion into an AVL tree has two stages. First the key is inserted as in a plain binary search tree, at a leaf. Then the heights are updated on the path from the new leaf back to the root. The first node on that path whose balance factor is \(2\) or \(-2\) is the lowest unbalanced node . A rotation re-links a node and one of its children so that the child takes the parent's place; Proposition 3.1 shows that it keeps the search order. The heavy child of a node with balance factor \(2\) is its left child, and of a node with balance factor \(-2\) it is its right child. A child leans the way its own balance factor points: a balance factor of \(1\) leans left, \(-1\) leans right, and \(0\) leans neither. If the heavy child's balance factor is \(0\) or has the same sign as the unbalanced node's, one single rotation at the unbalanced node is made. If it has the opposite sign, a double rotation is made: first a rotation at the child, then a rotation at the node. Remark 3.2 says what is and is not proved about this repair.
44: Proposition 3.1 (a rotation keeps the keys in order)
45: Let \(y\) be a node with left child \(x\), and let \(A\), \(B\) and \(C\) be the subtrees with keys in that order: \(A\) under \(x\)'s left side, \(B\) under \(x\)'s right side, and \(C\) under \(y\)'s right side. The right rotation makes \(x\) the root with left subtree \(A\) and right subtree \(y\), where \(y\) has left subtree \(B\) and right subtree \(C\). The in-order sequence of keys is the same before and after the rotation.
46: Proof
47: Before the rotation the in-order sequence of the subtree at \(y\) is the in-order sequence of \(A\), then \(x\), then \(B\), then \(y\), then \(C\). After the rotation, the in-order sequence of the subtree at \(x\) is the in-order sequence of \(A\), then \(x\), then the in-order sequence of the subtree at \(y\), which is \(B\), then \(y\), then \(C\). The two sequences are the same. The left rotation is the mirror image of this argument.
48: Remark 3.2 (what this page proves about insertion)
49: Proposition 3.1 shows that a rotation keeps the search order. This page does not prove that one single rotation or one double rotation restores the AVL rule after every insertion. That claim is checked, not proved: Lab 1, Part A, checks it after each of 500 seeded insertions, and only that check is stated here.

296: 4 Where the canon breaks
297: Deletion is not covered. This lesson proves a height bound for trees built by insertion and checks the insertion rule. Removing a key needs its own rotations and its own check, and the page makes no claim about them.
298: The insertion rule is checked, not proved. Remark 3.2 states the gap. The lab's 500 insertions are one seeded run, so they show the rule held on that run and do not show that it holds for every sequence of insertions.
299: The bound is a worst case. Proposition 2.4 bounds the height from above. The lab's AVL tree on keys 1 to 64 has height 7, and the bound is 8.6747. The bound does not say that the average height has any particular value.
300: Comparisons are not time. A search in a tree of height \(h\) makes at most \(h\) comparisons, by the argument of §1. The lab counts rotation calls and checks shapes. It measures no time, and it says nothing about memory layout or disk access.
301: 5 Misconceptions
302: “Keys inserted in sorted order leave a binary search tree balanced.”
303: Sorted insertion makes a path (Remark 1.1). For the keys 1 to 64 in increasing order, the plain tree has height 64, and the AVL tree on the same keys has height 7 (Lab 1, Part B). Balance is a property of the shape, and the insertion order can destroy it.
304: “An AVL tree rotates on every insertion.”
305: Most insertions need no rotation. In the run of Lab 1, Part A, 272 of 500 insertions needed none, and the lab made 340 rotation calls in total for the 500 insertions. A rotation is made at a node whose balance factor has reached 2 or \(-2\).
306: “The height of an AVL tree is at most \(\log_2 n\).”
307: The bound is \(\log_{\varphi}(n+1)\), which is about 1.44 times \(\log_2(n+1)\) (Remark 2.5). The two-node AVL tree has height 2, and \(\log_2 2 = 1\). Lab 1, Part C, prints that height.

310: Mechanics
311: M1 · Balance factors of a small tree
312: A tree has root 5, whose left child is 3 and right child is 7. The node 3 has left child 2 and no right child. The node 7 is a leaf. Compute the height and balance factor of every node, and say whether the tree is AVL.
313: Solution
314: The leaves 2 and 7 have height 1 and balance factor 0. The node 3 has left subtree height 1 and empty right subtree height 0, so its height is 2 and its balance factor is \(1 - 0 = 1\). The root has left subtree height 2 and right subtree height 1, so its height is 3 and its balance factor is \(2 - 1 = 1\). Every balance factor is in \(\{-1, 0, 1\}\), so the tree is AVL.
315: M2 · Inserting 1, 2, 3 into an empty tree
316: Insert 1, 2 and 3 in that order into an empty AVL tree. Which rotation is made, and what is the root afterwards?
317: Solution
318: After 1 and 2, the root 1 has a right child 2, so its balance factor is \(0 - 1 = -1\). Inserting 3 makes the right child 2 have right child 3, and the root 1 gets balance factor \(0 - 2 = -2\). The heavy child 2 leans right, the same way as the root, so one single left rotation at 1 is made. The new root is 2, with left child 1 and right child 3. The height is 2, and every balance factor is 0.
319: M3 · The recurrence N(h)
320: Compute \(N(5)\) from Definition 2.2, and check the value against Lab 1, Part C.
321: Solution
322: From the definition, \(N(2) = 1 + N(1) + N(0) = 2\), \(N(3) = 1 + N(2) + N(1) = 4\), \(N(4) = 1 + N(3) + N(2) = 7\), and \(N(5) = 1 + N(4) + N(3) = 12\). Lab 1, Part C, prints \(N_h = 12\) for \(h = 5\).
323: Proof
324: P1 · A left rotation keeps the order
325: State the left rotation and prove that it keeps the in-order sequence of keys, by the argument of Proposition 3.1 with left and right exchanged.
326: Solution
327: A left rotation at \(x\) with right child \(y\) makes \(y\) the root, with \(x\) as its left child. The subtree \(B\) that was the left subtree of \(y\) becomes the right subtree of \(x\). Before the rotation the in-order sequence is \(A\), \(x\), \(B\), \(y\), \(C\), where \(A\) is the left subtree of \(x\) and \(C\) is the right subtree of \(y\). After the rotation the in-order sequence of the subtree at \(y\) is that of \(x\) with \(A\) and \(B\), which is \(A\), \(x\), \(B\), followed by \(y\) and \(C\). The two sequences agree.
328: P2 · The recurrence N(h) is nondecreasing
329: Show that \(N(h) - N(h-1) \ge 1\) for every \(h \ge 2\), and that \(N(1) \ge N(0)\).
330: Solution
331: For \(h \ge 2\), \(N(h) - N(h-1) = (1 + N(h-1) + N(h-2)) - N(h-1) = 1 + N(h-2)\). Since \(N(h-2) \ge 0\) (each term is a count of nodes), this is at least 1. Also \(N(1) = 1\) and \(N(0) = 0\), so \(N(1) - N(0) = 1\).
332: P3 · The golden ratio identity
333: Let \(\varphi = (1 + \sqrt{5})/2\). Show that \(\varphi^{2} = \varphi + 1\) and that \(\varphi < 2\).
334: Solution
335: Squaring, \(\varphi^{2} = (1 + 2\sqrt{5} + 5)/4 = (3 + \sqrt{5})/2\). Also \(\varphi + 1 = (1 + \sqrt{5})/2 + 1 = (3 + \sqrt{5})/2\), so the two are equal. Since \(\sqrt{5} < 3\), \(\varphi = (1 + \sqrt{5})/2 < 2\). With \(\varphi^{2} = \varphi + 1\), this is the identity used in the proof of Proposition 2.4.

342: Read Lab 1, Part B. The AVL height on 64 sorted keys is 7. How does it compare with \(\log_2 64\)?
343: Solution
344: \(\log_2 64 = 6\) exactly, since \(64 = 2^{6}\). The AVL height is 7, which is one more than \(\log_2 64\). The bound of Proposition 2.4 is \(\log_{\varphi} 65\), which Part B prints as 8.6747, so 7 satisfies it.
345: E3 · How tall a 376-node AVL tree can be
346: Read Lab 1, Part C, at \(h = 12\). By Proposition 2.4, what upper bound on the height does an AVL tree with 376 keys have, and what integer height does that bound allow?
347: Solution
348: Part C prints \(N_{12} = 376\), and Lemma 2.3 gives that a tree of height 12 has at least 376 nodes, so the count does not rule out height 12. The bound is \(\log_{\varphi}(377)\). Computed as \(\ln 377 / \ln \varphi\), with \(\ln 377 = 5.932\) and \(\ln \varphi = 0.4812\), this is \(12.33\). So the height is at most 12.33, and an integer height of at most 12 is allowed. This page does not show that a tree with 376 nodes and height 12 exists.
349: Research
350: R1 · A double rotation
351: Insert 3, then 1, then 2 into an empty AVL tree. Identify the case of the rebalancing step and give the tree after it.
352: Solution
353: After 3 and 1, the root 3 has left child 1. Inserting 2 puts it as the right child of 1, so the root 3 has balance factor \(2 - 0 = 2\). Its heavy child 1 leans right, the other way from the root, so this is the left-right case and a double rotation is made. A left rotation at 1 makes 2 the left child of 3, with 2 having left child 1. Then a right rotation at 3 makes 2 the root, with left child 1 and right child 3. The tree has height 2 and every balance factor is 0.
354: R2 · An AVL tree of height 4 with 7 nodes
355: Describe an AVL tree of height 4 with exactly 7 nodes, and explain why no AVL tree of height 4 has fewer nodes.
356: Solution
357: Take a root \(R\) whose left subtree is the tree of Problem M1 (root 5, left child 3 with left child 2, right child 7), which has 4 nodes and height 3, and whose right subtree is a node \(s\) with one left child \(t\), which has 2 nodes and height 2. Every balance factor is listed: \(R\) has \(3 - 2 = 1\), 5 has \(2 - 1 = 1\), 3 has \(1 - 0 = 1\), 2 and 7 have 0, \(s\) has \(1 - 0 = 1\), and \(t\) has 0. All lie in \(\{-1, 0, 1\}\), so the tree is an AVL tree with root height \(1 + 3 = 4\) and \(1 + 4 + 2 = 7\) nodes. By Lemma 2.3 every AVL tree of height 4 has at least \(N(4) = 7\) nodes.
358: R3 · No AVL tree of height 5 with 7 nodes
359: Show that no AVL tree with 7 nodes has height 5, using Proposition 2.4 or Lemma 2.3.
360: Solution
361: Lemma 2.3 gives \(N(5) = 12\), so an AVL tree of height 5 has at least 12 nodes, and no AVL tree of height 5 has 7 nodes. Proposition 2.4 gives the same conclusion: with \(n = 7\), \(\log_{\varphi} 8 = \ln 8 / \ln \varphi = 4.32\), so the height is at most 4. Both arguments agree, and R2 shows that height 4 is attained with 7 nodes.
