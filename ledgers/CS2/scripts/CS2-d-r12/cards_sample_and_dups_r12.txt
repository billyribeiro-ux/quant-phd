CS2-c001 L01 T 
  F: What does f in O(g) mean?
  B: There are a constant c > 0 and an integer n0 >= 1 with f(n) <= c g(n) for every integer n >= n0, where g(n) > 0 for every n. The definition uses no limit. c is the witness and n0 the threshold (Definition 1.1).
CS2-c011 L01 T 
  F: Does f in O(g) mean f(n) <= g(n) for every n?
  B: No. Definition 1.1 allows a constant c and a threshold n0. For f(n) = 3n + 7 and g(n) = n, the inequality f(n) <= g(n) fails for every n >= 1, yet f is in O(g) with c = 10 and n0 = 1 (Example 2.1).
CS2-c021 L02 T 
  F: Under Assumption 2.1, what bounds the average search cost of a family of tables with n <= c m at every size n >= 1?
  B: Assume Assumption 2.1 and a constant c with n <= c m at every size n >= 1. Every average search cost is at most 1 + c, so the average cost is in O(1) with witness 1 + c and threshold 1 (Corollary 2.3).
CS2-c031 L03 T 
  F: How many comparisons can a pop make in a binary min-heap?
  B: Assume distinct keys in the array shape of Definition 1.1 with s >= 1 keys, and a comparison as one test of two keys. A pop makes at most 2 floor(log2 s) comparisons (Proposition 1.3(b)).
CS2-c041 L04 T 
  F: What does insertion sort do?
  B: It keeps a sorted prefix. For each new key, it compares the key with the last element of the prefix, moves larger elements one place right while the key is smaller, and stops at the first element not larger than the key (Definition 1.1).
CS2-c051 L04 T 
  F: How many probes can an unsuccessful binary search make on n sorted keys?
  B: At most floor(log2 n) + 1, which is the number of binary digits of n, and some absent key takes exactly that many. Assume n >= 1, a strictly increasing list, an absent key, and probes counted as comparisons of y with list elements (Proposition 3.2).
CS2-c061 L05 T 
  F: What height bound holds for an AVL tree with n nodes?
  B: h <= log_phi(n + 1) = log2(n + 1) / log2(phi), with phi = (1 + sqrt 5)/2. Equivalently phi^h <= n + 1. Assume an AVL tree with n >= 0 nodes and height h (Proposition 2.4).
CS2-c072 L06 T 
  F: What does breadth-first search do?
  B: BFS starts at the source s and keeps the discovered vertices in a first-in, first-out queue. It repeatedly removes the front vertex u and, for each undiscovered neighbour v, marks v discovered with distance dist(u) + 1, records u as its parent, and adds v to the back of the queue (Definition 1.1).
CS2-c082 L06 T 
  F: Does a traversal cost the same on adjacency lists as on an adjacency matrix?
  B: No. Lists cost at most |V| + 2|E| operations (Proposition 2.3). With an adjacency matrix a dequeued vertex reads its full row of |V| entries, so the row reads are |V| times the number of dequeued vertices, which is at most |V|^2.
CS2-c092 L07 T 
  F: Does filling the LCS table row by row give lambda(i, j) for every entry?
  B: Assume finite sequences compared by exact equality. Then dp[i][j] = lambda(i, j) for all 0 <= i <= m and 0 <= j <= n. The boundary entries are 0, and the proof is by induction on i + j (Corollary 3.4).

  B: No. Assume a book that starts empty, with each message a submission matched by Definition 2.1 or a cancellation of a live order. An incoming buy above the best ask trades first, and only its unfilled remainder rests, as a bid at its own price, below the best ask (Proposition 1.3).

  F: Does the head of a price-level queue pass a live order?

  F: Which rotation does an AVL insertion make at a node whose balance factor is 2 or -2?
  B: Let the heavy child be the left child for balance factor 2, and the right child for -2.
