[51] A debt fixed in cents does not stay fixed in what it can buy. When the price index (defined in Section 2) falls, the same nominal payment buys more goods, so the real burden of the debt rises. This lesson defines the gold standard as a commitment to a fixed parity, proves the identity that links the real value of a fixed nominal debt to the price index, and shows that the real value rises in exactly the periods in which the index falls. The results are algebra on positive numbers. They say nothing about which economies had falling prices, or why.
[53] 1Convertibility at a fixed parity
[56] Definition 1.1 (gold standard)
[57] A gold standard is a monetary regime in which the issuer fixes a parity \(\kappa > 0\), a quantity of gold in grams for one unit of the currency, and makes the currency convertible at that parity: the issuer stands ready to buy and sell gold at the parity on demand.
[60] The definition fixes one price, the price of gold in the currency, and nothing else. Proposition 1.2 states what it implies, and only under an explicit assumption about the issuer's conduct.
[63] Proposition 1.2 (the currency price of gold)
[65] (A1) The issuer keeps the parity at every date \(t\): one unit of the currency is convertible into \(\kappa\) grams at every \(t\), with \(\kappa\) as in Definition 1.1.
[67] Conclusion: at every date \(t\), one gram of gold costs \(1/\kappa\) units of the currency.
[71] Proof
[72] Fix a date \(t\). Under (A1), one unit of the currency buys \(\kappa\) grams at the parity. So \(\kappa\) grams cost one unit, and one gram costs \(1/\kappa\) units. The argument uses only the parity at date \(t\), and (A1) gives the parity at every date, so the price is \(1/\kappa\) at every date. \(\blacksquare\)
[76] Remark 1.3 (what Proposition 1.2 does not say)
[77] Proposition 1.2 is a statement about one price, the currency price of gold. It says nothing about the prices of goods, and so nothing about the price index \(P_t\) of Section 2. The hypothesis (A1) does not involve \(P_t\), so the conclusion holds whatever path \(P_t\) follows.
[80] 2Nominal debt, real value and the price index
[82] A nominal debt is an amount of currency that the debtor owes at each date of a contract, stated in the currency's own units and not indexed to prices. Here the amount is \(D\) cents. The price index is \(P_t\) at date \(t\), with base date \(0\). Its values are positive numbers, and \(P_0\) is the base value. The real value of the debt at date \(t\), in base-date cents, is the nominal amount divided by the index relative to its base:
[83] \[ V_t = \frac{D\,P_0}{P_t}. \]
[84] Proposition 2.1 uses two assumptions, numbered (A2) and (A3) and used throughout Sections 2 and 3.
[87] Proposition 2.1 (the real-value identity)
[89] (A2) \(D\) is a fixed nominal debt: \(D\) is a positive integer number of cents, the same at every date, and the debtor pays it in full. The contract is not renegotiated.
[90] (A3) \(P_t\) is a positive real number for every date \(t\), and \(P_0\) is the base value.
[92] Conclusion: (a) for every date \(t \ge 1\), \(V_t / V_{t-1} = P_{t-1} / P_t\); (b) for every \(H \ge 1\), \(V_H / V_0 = P_0 / P_H\).
[96] Proof
[97] (a) By (A2) and (A3), \(D\,P_0\) is a positive number, and \(V_t\) and \(V_{t-1}\) are defined and positive. Then \(V_t / V_{t-1} = (D\,P_0 / P_t) / (D\,P_0 / P_{t-1}) = P_{t-1} / P_t\), because the factor \(D\,P_0\) cancels.
[98] (b) Multiply the equalities of (a) for \(t = 1, \dots, H\). The left side telescopes: \(\prod_{t=1}^{H} V_t / V_{t-1} = V_H / V_0\). The right side telescopes the same way: \(\prod_{t=1}^{H} P_{t-1} / P_t = P_0 / P_H\). Both products are equal, so \(V_H / V_0 = P_0 / P_H\). \(\blacksquare\)
[102] Remark 2.2 (the index can be any positive path)
[103] For a debt that satisfies (A2), Proposition 2.1 holds for every index path that satisfies (A3). The conclusion does not depend on how the index moves, or on what caused its movement. The positivity of \(D\) is needed: with \(D = 0\), the ratio in (a) is \(0/0\), and the identity is not defined.
[106] 3Debt deflation
[109] Definition 3.1 (debt deflation)
[110] Debt deflation is the rise in the real value \(V_t\) of a fixed nominal debt that a fall in the price index \(P_t\) implies by the identity of Proposition 2.1, with \(D\) held fixed. It is an arithmetic consequence, not a claim about the cause of any fall.
[114] Corollary 3.2 (a fall in the index raises the real value)
[116] (A2) and (A3) of Proposition 2.1.
[118] Conclusion: for every date \(t \ge 1\), \(V_t > V_{t-1}\) if and only if \(P_t < P_{t-1}\).
[122] Proof
[123] By Proposition 2.1(a), \(V_t / V_{t-1} = P_{t-1} / P_t\). Since \(V_{t-1} > 0\), the inequality \(V_t > V_{t-1}\) holds exactly when \(V_t / V_{t-1} > 1\). Since \(P_t > 0\), the inequality \(P_{t-1} / P_t > 1\) holds exactly when \(P_{t-1} > P_t\), that is, when \(P_t < P_{t-1}\). \(\blacksquare\)
[127] Remark 3.3 (what the corollary does not give)
[128] Corollary 3.2 gives the direction of the change in \(V_t\), not its size. For a fall from \(P_{t-1}\) to \(P_t\), the real value is multiplied by \(P_{t-1} / P_t\), which is larger than one. The corollary says nothing about the cause of a fall, and nothing about whether any economy had one.
[131] Lab 1 checks Proposition 2.1 and Corollary 3.2 on one simulated path, and checks the identity in part (b) as well.

[183] """Return (P_0 .. P_horizon, percentage changes c_1 .. c_horizon) for a seeded simulated index.
[185] The index P_t = P_(t-1) * (1 + c_t / 100) is exact. Each change c_t is an integer percent drawn uniformly from

[198] def real_value(debt_cents: int, base: Fraction, price: Fraction) -> Fraction:
[199] """Real value of a fixed nominal debt, in base-date cents: D * P_0 / P_t.
[201] Raises ValueError when the price index is not positive, because the real value is then undefined.
[202] """
[203] if price <= 0:
[204] raise ValueError("the price index must be positive")
[205] return Fraction(debt_cents) * base / price
[208] def gram_price(kappa: Fraction) -> Fraction:
[209] """Currency units per gram at a parity of kappa grams per currency unit: 1 / kappa, exact.
[211] Raises ValueError when the parity is not positive, because the price is then undefined.
[212] """
[213] if kappa <= 0:
[214] raise ValueError("the parity must be positive")
[215] return 1 / kappa

[304] 4Where the canon breaks
[305] The identity of Proposition 2.1 is algebra. Each of the following shows what the algebra does not cover.
[307] The real value depends on the index. The formula uses one index, \(P_t\). A second index, built from a different basket of goods, gives a different real value, and Proposition 2.1 holds for each index separately. Nothing in this lesson relates the two. The index is the quantity linked in the header to the E5 concept of measured prices. Its choice is an input to this lesson, not a result of it.
[308] A debtor who does not pay in full. Assumption (A2) requires full payment and no renegotiation. Without it, the formula still gives the contract's real value \(V_t\), but the real value of the payment received is a different quantity, and Corollary 3.2 does not describe it.
[309] A fixed nominal amount. A contract with payments indexed to prices has \(D\) changing with \(P_t\). Under that contract the real value is constant, and Corollary 3.2 does not apply. Problem R2 works this case.
[310] The cause of the index path. Proposition 2.1 takes the path \(P_t\) as given. It does not say why the index fell, and the lesson takes no position on the causal role of the gold standard in any historical fall in prices. This lesson cites no source for a causal claim, so none is made here.
[315] 5Misconceptions
[318] “When prices fall, a fixed debt becomes cheaper to repay.”
[319] Corollary 3.2 gives the opposite direction for the real value. A fall in \(P_t\) raises \(V_t\), because the same nominal payment buys more goods. Lab 1, Part C, prints six periods with a falling index and six with a rising real value, and the two sets of periods are equal.
[322] “Fixing the gold price of the currency fixes the price level.”
[323] Proposition 1.2 gives one price, the currency price of gold, and Remark 1.3 says that it implies nothing about \(P_t\). The simulated index in Lab 1, Part A, changes in each of its twelve periods, while the index path of Parts A to D is not linked to the gold price that Part E computes, so the lab does not link the two prices.
[326] “A fixed nominal debt has a fixed real value.”
[327] The nominal amount \(D\) is fixed, but the real value \(V_t = D\,P_0 / P_t\) changes whenever \(P_t\) changes. Lab 1, Part B, prints a real value that differs from its predecessor in each of the twelve periods. For a fixed nominal debt, the real value is constant exactly when the index is constant, because \(V_t = D\,P_0 / P_t\) equals \(V_0 = D\) only when \(P_t = P_0\). An index-linked payment (Problem R2) is not a fixed nominal debt, so its real value can be constant while the index moves.

[337] Mechanics
[339] M1 · The real value after one fall in the index
[340] A fixed nominal debt is \(D = 2{,}000\) cents, the base index is \(P_0 = 100\), and the index falls to \(P_1 = 80\). Compute \(V_1\) in base-date cents.
[341] Solution
[342] \(V_1 = D\,P_0 / P_1 = 2000 \cdot 100 / 80 = 200000 / 80 = 2500\) cents. The division is exact, so no rounding is needed. The real value rose from 2000 to 2500 cents, a factor of \(100/80 = 1.25\), as Corollary 3.2 requires for a fall in the index.
[346] M2 · A one-period ratio with the debt cancelled
[347] With \(P_0 = 100\), \(P_1 = 90\) and \(P_2 = 85\), find \(V_2 / V_1\) as an exact fraction, without computing \(D\).
[348] Solution
[349] By Proposition 2.1(a), \(V_2 / V_1 = P_1 / P_2 = 90 / 85 = 18 / 17\). The debt \(D\) cancels, so the answer does not depend on it. As a check, \(V_1 = D \cdot 100 / 90\) and \(V_2 = D \cdot 100 / 85\), and their ratio is \((100 / 85) / (100 / 90) = 90 / 85\).
[353] M3 · A rounded real value
[354] A fixed nominal debt is \(D = 2000\) cents, the base index is \(P_0 = 100\), and the index at date 1 is \(P_1 = 95\). Compute \(V_1\) to the nearest cent, with ties going up.
[355] Solution
[356] \(V_1 = 200000 / 95 = 2105.2631\ldots\) cents. The unrounded value is kept until the last step, and the fractional part \(0.263\ldots\) is below one half, so the nearest cent, with ties up, is 2105 cents.
[362] Proof
[364] P1 · The direction of the real-value change
[365] Under (A2) and (A3), show that \(P_t = P_{t-1}\) implies \(V_t = V_{t-1}\), and that \(P_t > P_{t-1}\) implies \(V_t < V_{t-1}\).
[366] Solution
[367] If \(P_t = P_{t-1}\), then \(V_t = D\,P_0 / P_t = D\,P_0 / P_{t-1} = V_{t-1}\) directly from the definition. If \(P_t > P_{t-1}\), both are positive, so \(1 / P_t < 1 / P_{t-1}\). Multiplying by the positive number \(D\,P_0\) gives \(V_t < V_{t-1}\).
[371] P2 · The telescoped identity by induction
[372] Prove Proposition 2.1(b) for every \(H \ge 1\) by induction on \(H\), using only Proposition 2.1(a) and (A2), (A3).
[373] Solution
[374] For \(H = 1\), (a) gives \(V_1 / V_0 = P_0 / P_1\), which is (b). Suppose \(V_H / V_0 = P_0 / P_H\). By (a) at \(H + 1\), \(V_{H+1} / V_H = P_H / P_{H+1}\). Multiplying the two equalities gives \(V_{H+1} / V_0 = (P_0 / P_H)(P_H / P_{H+1}) = P_0 / P_{H+1}\), which is (b) at \(H + 1\). The factors \(P_H\) and \(V_H\) are positive, so the divisions are defined.
[378] P3 · Rescaling the index leaves the real value unchanged
[379] Let \(c > 0\) and replace every index value \(P_t\) by \(c P_t\), keeping \(D\) fixed. Show that every real value \(V_t\) is unchanged.
[380] Solution
[381] The new base value is \(c P_0\), and the new index at date \(t\) is \(c P_t\). The new real value is \(D \cdot (c P_0) / (c P_t) = D \cdot P_0 / P_t = V_t\), because the factor \(c\) cancels. So the real value depends on the index only through the ratio \(P_0 / P_t\), and not on the units in which the index is quoted.

[390] Lab 1, Part C prints six periods with a falling price index out of twelve. Count the negative percentage changes in Part A, and say which periods they are.

[396] E2 · The first real value by hand
[397] Lab 1, Part B prints \(V_1 = 1010101\) cents. Compute \(V_1\) from \(D = 1{,}000{,}000\) cents and the index \(P_1 = 99\), and state the rounding rule you use.
[398] Solution
[399] \(V_1 = 1000000 \cdot 100 / 99 = 1010101.0101\ldots\) cents. Rounded to the nearest cent, with ties up, this is 1010101 cents, which agrees with the printed value. The index \(P_1 = 99\) is exact, because \(100 \cdot (1 - 0.01) = 99\), and the rule is applied once, at the last step.
[403] E3 · The horizon ratio to six decimals
[404] Lab 1, Part D prints \(V_{12} / V_0\) to six decimals as 1.055909, and Part A prints \(P_{12}\) as 94.7051. Compute \(P_0 / P_{12}\) from the printed index, and say why it agrees with the printed ratio to six decimals.
[405] Solution
[406] From the printed index, \(100 / 94.7051 = 1.0559093\ldots\), which is 1.055909 to six decimals. The printed index is itself a four-decimal display. The lab uses the unrounded index, which is \(94.70509914\ldots\), and \(100 / 94.70509914\ldots = 1.05590935\ldots\), which is also 1.055909 to six decimals. The two agree to six decimals because the index rounding changes the ratio by less than one part in a million.
[412] Research
[414] R1 · What a finite check cannot show
[415] Lab 1 checks the identity on twelve periods of one path. Explain why this check cannot establish Proposition 2.1 for all paths, and identify the step of this lesson that does.
[416] Solution
[417] The lab checks finitely many dates on one path, so it covers a finite set of cases. Proposition 2.1 is a statement about every path that satisfies (A3). Its proof uses only the cancellation of the positive factor \(D\,P_0\) in the ratio, which holds for any positive values. That algebra, in Proposition 2.1(a), covers all paths at once, and the lab serves as a numerical check of it.
[421] R2 · An index-linked payment
[422] Suppose the payment at date \(t\) is \(D_t = D\,P_t / P_0\), so the nominal payment moves with the index. Compute the real value \(D_t \cdot P_0 / P_t\), and say which assumption of Proposition 2.1 fails.
[423] Solution
[424] The real value is \(D_t \cdot P_0 / P_t = (D P_t / P_0) \cdot P_0 / P_t = D\), the same at every date. Assumption (A2) fails, because the nominal amount \(D_t\) is no longer the same at every date. Corollary 3.2 does not apply: the real value does not rise when the index falls, since it does not change at all. When the index falls, the nominal payment falls with it.
[428] R3 · Two indices and one debt
[429] Let \(Q_t\) be a second positive index, built from a different basket, and let \(W_t = D\,Q_0 / Q_t\) be the real value measured with it. Suppose \(P\) rises in a period in which \(Q\) falls. State what Corollary 3.2 says about each real value, and say whether the lesson's results relate the two.
[430] Solution
[431] Corollary 3.2 applies to each index separately, given (A2) and (A3) for that index. For \(P\), the real value falls in that period, because the index rose. For \(Q\), the real value rises, because the index fell. Both statements are true, and they concern different measures of the same nominal debt. The lesson's proofs use only the one index that the definition names, so they establish no relation between \(V_t\) and \(W_t\). Such a relation would need a separate assumption about the two baskets.
