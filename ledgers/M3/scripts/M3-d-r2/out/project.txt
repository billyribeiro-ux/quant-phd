240:         Conventions
242:           Unit-diagonal matrix. A symmetric matrix whose diagonal entries are all 1. The repairs are specified for symmetric matrices with a positive diagonal. Each seeded instance that the autograder builds with make_instance in grader/instance.py is unit-diagonal, by construction. The tests also use planted spectra and small hand-made matrices, some of which are not unit-diagonal, such as diag(3, −2, 5) for min_eigenvalue.
243:           Positive semidefinite. A symmetric matrix is positive semidefinite (PSD) when every eigenvalue is at least zero, the form this specification uses; Lesson 5 gives the definition by the quadratic form. The PSD verdict of this specification is the test of is_psd: the smallest eigenvalue is at least -tol. The autograder accepts a repaired matrix as PSD when its smallest eigenvalue is at least -1e-9 for clipping and at least -1e-8 for the projection.
244:           Frobenius distance. For matrices A and B of the same size, the square root of the sum of the squared differences of their entries, written \(\lVert A-B\rVert_F\). A repair is nearer the input when this distance is smaller. The Frobenius-nearest repair is the PSD unit-diagonal matrix with the smallest distance from the input.
245:           Clipping. Write the eigendecomposition of the input as \(A = V\Lambda V^{\top}\), with V orthogonal. Clipping sets \(\Lambda_{ii}\) to \(\max(\Lambda_{ii}, f)\) for the floor \(f\), gives \(X = V\Lambda_f V^{\top}\), and then rescales to \(Y = D^{-1/2} X D^{-1/2}\) with \(D\) the diagonal of \(X\). Clipping at a floor \(f \ge 0\), followed by rescaling, is a valid repair whenever the clipped matrix has a positive diagonal (A1 and A2 in the appendix); Lab 3 shows that it is not the nearest one on its input. For an input with a negative eigenvalue and floor 0, the clipped matrix \(X\) is singular (A4 in the appendix). If its diagonal is also positive, the rescaled matrix \(Y\) is singular too (A4), and the weights formula gives no weights for it (see the weights bullet below).
246:           Weights. With \(S = \diag(v_1,\dots,v_k)\) for the volatilities \(v_i > 0\) and a symmetric unit-diagonal matrix \(C\), let \(\Sigma = SCS\), and let \(\boldsymbol{\iota}\) be the vector of \(k\) ones, the constant vector whose entries all equal 1. Where \(\Sigma\) is invertible and \(\boldsymbol{\iota}^{\top}\Sigma^{-1}\boldsymbol{\iota} \ne 0\), the weights are \(w = \Sigma^{-1}\boldsymbol{\iota} / (\boldsymbol{\iota}^{\top}\Sigma^{-1}\boldsymbol{\iota})\). They sum to 1, and a weight may be negative. The formula does not require \(C\) to be positive semidefinite. Where \(\Sigma\) is singular, or \(\boldsymbol{\iota}^{\top}\Sigma^{-1}\boldsymbol{\iota} = 0\), the formula gives no weights, and the function's behaviour there is not specified: no test asserts a value or an exception for either case.
247:           The four named ValueError conditions. (1) A matrix that is not square: a row has a number of entries other than the number of rows. (2) A matrix that is not symmetric beyond 1e-9: some pair of entries \(m_{ij}\) and \(m_{ji}\) differ by more than 1e-9. (3) A volatility that is not strictly greater than zero, in comparison_weights. (4) A volatility list whose length differs from the number of rows of the correlation matrix. No other input is named, and no test asserts an exception for one.
248:           Precision. Results are floats. The tests compare them with the tolerances the conventions and the test file state, and a result that is correct to the tolerance passes.

351: def clip_repair(a: Matrix) -> Matrix:
352:     """Eigenvalue clipping at 0, then rescaling to unit diagonal: D^(-1/2) X D^(-1/2) with D the diagonal of X."""
353:     n = len(a)
354:     values, vectors = jacobi_eigen(a)
355:     clipped = [max(x, 0.0) for x in values]
356:     x_matrix = [[sum(vectors[i][k] * clipped[k] * vectors[j][k] for k in range(n)) for j in range(n)] for i in range(n)]
357:     d = [x_matrix[i][i] for i in range(n)]
358:     return [[x_matrix[i][j] / math.sqrt(d[i] * d[j]) for j in range(n)] for i in range(n)]
361: def projection_repair(a: Matrix, tol: float = 1e-10, max_iter: int = 500) -> Matrix:
362:     """Alternating projections, with correction terms, between the positive semidefinite and unit-diagonal matrices."""
363:     n = len(a)
364:     x = [row[:] for row in a]
365:     corr_s = [[0.0] * n for _ in range(n)]
366:     corr_u = [[0.0] * n for _ in range(n)]
367:     for _ in range(max_iter):
368:         y = psd_projection([[x[i][j] + corr_s[i][j] for j in range(n)] for i in range(n)])
369:         corr_s = [[x[i][j] + corr_s[i][j] - y[i][j] for j in range(n)] for i in range(n)]
370:         new_x = [[y[i][j] + corr_u[i][j] for j in range(n)] for i in range(n)]
371:         for i in range(n):
372:             new_x[i][i] = 1.0
373:         corr_u = [[y[i][j] + corr_u[i][j] - new_x[i][j] for j in range(n)] for i in range(n)]
374:         gap = math.sqrt(sum((new_x[i][j] - y[i][j]) ** 2 for i in range(n) for j in range(n)))
375:         step = math.sqrt(sum((new_x[i][j] - x[i][j]) ** 2 for i in range(n) for j in range(n)))
376:         x = new_x
377:         if gap <= tol and step <= tol:

382: def comparison_weights(corr: Matrix, vols: list[float]) -> list[float]:
383:     """Weights proportional to Sigma^(-1) 1, with Sigma = S C S and S = diag(vols), normalised to sum to 1."""
384:     n = len(corr)
385:     sigma = [[vols[i] * corr[i][j] * vols[j] for j in range(n)] for i in range(n)]
386:     aug = [[*sigma[i], 1.0] for i in range(n)]
387:     for col in range(n):
388:         pivot = max(range(col, n), key=lambda r: abs(aug[r][col]))
389:         aug[col], aug[pivot] = aug[pivot], aug[col]
390:         for r in range(n):
391:             if r != col:
392:                 factor = aug[r][col] / aug[col][col]
393:                 aug[r] = [p - factor * q for p, q in zip(aug[r], aug[col], strict=True)]
394:     solution = [aug[i][n] / aug[i][i] for i in range(n)]

401:     n = len(a)

634:               Appendix A · Proofs
635:               A1. Assuming F1 to F4 of Lesson 4, let \(A\) be a real symmetric matrix and \(f \ge 0\). The spectral theorem (Theorem 2.3 of Lesson 4, which holds under F1 to F4) gives \(A = V\Lambda V^{\top}\) with V orthogonal and \(\Lambda\) diagonal and real. Let \(\Lambda_f = \diag(\max(\Lambda_{ii}, f))\) and \(X = V\Lambda_f V^{\top}\). X is symmetric. For any vector z, \(z^{\top}Xz = \sum_i \max(\Lambda_{ii}, f)\,(V^{\top}z)_i^2 \ge 0\), since each \(\max(\Lambda_{ii}, f) \ge f \ge 0\). So X is PSD.
636:               A2. Let X be symmetric and PSD, with \(d_i = X_{ii} > 0\) for every i, D = diag(d), and \(Y = D^{-1/2}XD^{-1/2}\). Then \(Y_{ii} = X_{ii}/(\sqrt{d_i})^2 = 1\). For any z, \(z^{\top}Yz = q^{\top}Xq \ge 0\) with \(q = D^{-1/2}z\), so Y is PSD. The positivity of \(d_i\) is needed for the division.
637:               A3. Let C have unit diagonal and off-diagonal entries \(\rho\), with \(|\rho|  0\). Then \(\Sigma\) has diagonal entries \(a^2\) and \(b^2\) and off-diagonal entries \(\rho ab\), and \(\det\Sigma = a^2b^2(1-\rho^2) > 0\), so \(\Sigma\) is invertible. Its inverse has diagonal entries \(b^2/\det\Sigma\) and \(a^2/\det\Sigma\) and off-diagonal entries \(-\rho ab/\det\Sigma\), so \(\Sigma^{-1}\boldsymbol{\iota} = (\det\Sigma)^{-1}(b(b-\rho a),\, a(a-\rho b))\). Normalising, the \(\det\Sigma\) cancels, and the sum of the two components is \(a^2+b^2-2\rho ab\), which is positive because \(a^2+b^2-2\rho ab = (a-b)^2 + 2ab(1-\rho) > 0\). For \(c > 0\), replacing \((a, b)\) by \((ca, cb)\) multiplies every component and the sum by \(c^2\), so the normalised weights do not change. A4 Assuming F1 to F4 of Lesson 4, let \(C = V\Lambda V^{\top}\) be a spectral decomposition with \(V\) orthogonal, let \(\Lambda_{ii} = \lambda_i  0\), \(S_v = \diag(v)\) and \(\Sigma = S_vYS_v\), the vector \(S_v^{-1}z\) satisfies \(\Sigma S_v^{-1}z = S_vYz = 0\), so \(\Sigma\) is singular and the weights formula gives no weights.
